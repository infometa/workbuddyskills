# 安全说明

## 信任边界

包内 Python 脚本仅使用标准库，不联网、不上传、不启动外部程序、不调用外部 Skill/Connector/MCP/其他专家。WorkBuddy 宿主对模型或多模态内容的处理不属于包内脚本控制范围，使用者应按宿主当前隐私设置选择本地或云端能力。

## 文件与路径

项目必须含 `.mom-dialogue-project.json`，且标记声明原始资料只读、输出仅项目目录。`common.py` 在每次读写前检查项目边界、盘符/UNC 路径、符号链接、junction 和 Windows reparse point；扫描不跟随链接。输出使用同目录临时文件、flush、fsync 和 `os.replace`，事务另用 OS 文件锁和不可覆盖的 prepared/terminal 回执。

一个工作区模式允许项目目录位于来源根的子目录，但扫描会排除已标记项目目录；来源根不得位于项目目录内部。`--scope` 只能是来源根内的相对路径，不能使用盘符、UNC 或 `..`。

## 来源与完整性

来源身份是 `root_id::relative_path`。SCAN 同时生成 inventory 与 hashes，并由回执绑定两份文件的 SHA-256、组合摘要、范围、错误和跳过数量。DIFF 绑定扫描回执和提交前来源账摘要；COMMIT 必须提供用户复核的 DIFF 摘要，并按需要显式确认空扫描、缺失和同根迁移。跨根同哈希不会自动复用 `SRC`。

## 数据与公开

观察、讲述、元数据、确认、推断、冲突和未知分开记录；未确认人物不能写成真实姓名。公开或成稿导出必须冻结 `delivery-selection.json`，重新核对所选文件哈希、对象存在、每一条适用许可和匿名/敏感复核。没有成功回执不得声称保存、导出、发布或上架。删除只生成建议，原件零移动、零覆盖、零删除。

## 失败处理

单文件读取失败进入质量问题和待处理队列；扫描为 partial 时不产生缺失判断。写入中断由 `recover_source_commit.py` 根据物理 pre/post 摘要分类，无法匹配时停止并要求人工处理。测试、宿主演练、官方列表和市场上架属于不同证据层，任何一个通过都不能替代另一个。
