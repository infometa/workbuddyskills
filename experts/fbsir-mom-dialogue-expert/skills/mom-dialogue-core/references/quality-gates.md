# 质量门

## 工程

- name、plugin、agentName、Agent 文件名一致。
- Agent frontmatter 不含 `tools`。
- tags 和 quickPrompts 各 3 条。
- 第一条 quickPrompts 与 defaultInitPrompt 一致。
- Skill 存在 SKILL.md、references、scripts、templates。
- 脚本只使用标准库，不联网、不上传、不删除原件。

## 产品

- 妈妈为叙事主轴，家庭结构可变。
- 所有资料有来源编号；视频有时间码。
- 未确认人物不使用真实姓名。
- 观察、陈述、元数据、确认、推断、冲突和未知分离。
- 原始资料零覆盖、零删除。
- 私密内容不自动进入公开稿。
- 能力不足有待处理队列并继续可做部分。
- 项目可中断续接，导出清单与实际文件一致。
