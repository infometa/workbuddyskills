# 统一术语

| 术语 | 定义 |
|---|---|
| 生活资料 | 照片、视频、录音、手稿、书信、证件、聊天记录、文档和旧稿 |
| 妈妈 | 一位或多位主要叙事对象，不限定年龄、辈分和亲缘形式 |
| 家庭成员 | 与妈妈有关系或共同生活经历的人 |
| 家庭主编 | 负责组织、整理、校对、编排和成稿确认的人 |
| 生活轨迹 | 地点、关系、工作、家庭和重要事件的阶段性记录 |
| 故事卡 | 可独立整理、追问和编入作品的故事单元 |
| 家庭回声 | 其他成员对同一人物或事件的补充讲述 |
| 来源锚点 | 文件名、页码、照片编号、音频或视频时间码 |
| 成稿 | 故事集、专题文章、家庭书稿、图文集或回忆录 |

## 状态词

`observed` 直接看到；`stated` 明确说出；`metadata` 文件元数据；`confirmed` 家庭确认；`inferred` AI 推断；`disputed` 存在冲突；`unknown` 无法判断。
