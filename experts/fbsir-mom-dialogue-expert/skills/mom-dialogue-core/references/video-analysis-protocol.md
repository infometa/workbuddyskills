# 视频分析协议

## 顺序

1. 建立文件轨：文件名、时长、分辨率、来源、质量和可读性。
2. 切分镜头和话题，记录起止时间码与关键帧。
3. 分别记录画面轨、声音轨、事件轨和故事轨。
4. 做跨片段人物候选对齐，但不把候选写成确认姓名。
5. 逐段分析完成后再生成全片摘要，并记录覆盖率。

## 长视频与异常

长视频按固定时长或自然场景分批；每批交界处保留重叠缓冲，避免切断说话和事件。老 DV、音画不同步、画外音、多人重叠讲话、字幕、桌牌、横幅、片头片尾、转发视频和二次剪辑分别标记质量问题。时间码精度写入 `timecode_precision`，缺失时为 `unknown`。

## 片段状态

每段记录 `source_id`、`segment_id`、六轨内容、人物候选、故事价值、来源状态、覆盖状态和待确认问题。整片摘要只有在所有计划片段完成或明确标记缺失后才可生成。
