# 贴图头条 - 输出规格

## 输入状态

渲染器只接受经过 `validate_content_state.py` 校验的 `content-state.v1`。关键文字字段必须包含原文、置信度和确认状态；无法确认的内容不得伪装成确定文本。

## 画布规格

| 项目 | 默认值 | 说明 |
|------|--------|------|
| 宽度 | 1080 px | 竖版宽度，适合手机信息流 |
| 高度 | 1920 px | 竖版高度，适合手机信息流 |
| 背景色 | #FFFFFF | 纯白，保持正式媒体感 |
| 边距 | 40 px | 左右边距，保证文字不被裁切 |

固定模板以 1080×1920 为设计基准；当前版本不接受随意改变画布尺寸。若未来支持多尺寸，必须整体同比缩放并增加独立测试。

## 字体层级

| 层级 | 字号 | 用途 |
|------|------|------|
| 报头 | 72 px | 媒体名称或报头 |
| 主标题 | 64–72 px | 核心新闻标题 |
| 辅助标题 | 36–40 px | 次要信息或副标题 |
| 日期/期号 | 28–32 px | 日期、期号等元信息 |
| 标签 | 28 px | “今日关注”等标签文字 |

字体必须从系统中文字体文件路径加载，例如 Windows 的 `C:\Windows\Fonts\simhei.ttf`、`msyh.ttc` 或 `simsun.ttc`。找不到可用中文字体时必须失败，不得静默回退到 Pillow 默认字体。

## 图片处理

- 核心新闻图片保持原始比例，使用 cover-fit 等比缩放后裁切；
- 支持 `focal_point` 控制人物或主体保留区域；
- 禁止直接把原图 resize 到目标框造成拉伸；
- 缺少未确认图片时使用带文字的占位区；正式交付前必须补齐并确认核心图片。

## 输出格式

- 文件格式：PNG
- 色彩模式：RGB
- 透明度：不透明（背景为纯色）
- 文件命名：`cover_<type>_<revision_id>.png`

## 版本管理

- 每次用户确认或生成新版本时，保存 `state.json`、`layout.json` 和 `cover.png`；
- 版本目录：`<workspace>/.tietu_versions/`；
- 版本记录只保存相对路径、内容哈希、修订 ID、父版本和修改摘要；
- 版本名禁止包含路径分隔符，任何输出必须位于当前会话工作目录内。
