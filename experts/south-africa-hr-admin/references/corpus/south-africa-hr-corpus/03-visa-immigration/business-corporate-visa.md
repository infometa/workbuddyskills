# 商务签证与企业签证：投资移民与批量外籍员工引进

> 来源：DHA官网、DIRCO、Wesgro Visa Guide 2025、SAvisas、IBN
> 最后更新：2025年4月（含2025年4月在线申请系统上线）
> 用途：南非人力行政专家语料库 — 签证移民板块

---

## 1. 商务签证（Business Visa / Investor's Visa）

### 1.1 适用对象
外国投资者拟在南非**设立企业或投资现有企业**并参与经营管理。

### 1.2 法律依据
- Immigration Act 13 of 2002, **Section 15**
- Regulation 13

### 1.3 核心要求

| 要求 | 标准 |
|------|------|
| **最低投资额** | **R5,000,000**（外币转入，非南非本地资金） |
| **雇员比例** | ≥**60%**员工为南非公民或永久居民 |
| **资金来源** | 须由注册特许会计师(SAICA/SAIPA)验证资金合法来源 |
| **商业计划** | 须提交详细商业计划（含可行性分析） |
| **DTIC推荐** | 须获贸工部(DTIC)正面推荐函 |

### 1.4 投资额豁免行业
以下行业可申请**减免R5,000,000投资门槛**（waiver）：
- 信息与通信技术 (ICT)
- 服装纺织制造
- 化工与生物技术
- 农产品加工 (Agro-processing)
- 金属与矿物精炼
- 汽车制造
- 旅游
- 手工艺品

### 1.5 禁止行业
以下行业**不接受**商务签证申请：
- 进口二手车转售至南非境外
- 异国娱乐业 (Exotic entertainment)
- 安保行业 (Security industry)

### 1.6 申请流程

```
第1步：DTIC推荐 (约45个工作日)
  → 提交商业计划 + 会计师证书 + 资质/CV + 60%雇员承诺
  → 通过DTIC在线系统(Business Visa Recommendation System, VRS)

第2步：DHA签证申请 (约8-12周)
  → 获DTIC推荐后提交DHA-1738表
  → 如需减免投资额，先申请waiver
  → 通过VFS Global或南非使领馆递交

第3步：签证获批
  → 有效期最长3年，可续签
  → 可申请永久居留（满足投资和雇员条件后）
```

### 1.7 签证费用
- DHA申请费：**R1,520**
- VFS递交融担费（如在南非境内）：R1,550
- DTIC推荐：免费（但准备文件有成本）

### 1.8 续签与永久居留
- **续签**：须重新走DTIC推荐 + DHA申请全流程
- **永久居留**：满足投资和雇员条件后可申请
- **资金锁定**：投资资金须绑定5年（获永居或取消签证后方可撤回）

### 1.9 获批后合规
- 签证获批**1年内**须向DHA提交DOL信函，确认≥60%员工为南非公民/永久居民
- 须维持投资资金在企业中
- 须持续满足60%雇员比例

## 2. 企业签证（Corporate Visa）

### 2.1 适用对象
企业实体（如矿业集团、农场等）需**批量引进**外籍熟练/半熟练/非熟练工人。

### 2.2 核心要求

| 要求 | 标准 |
|------|------|
| **有效期** | 最长**3年** |
| **DOL证明** | 须获DOL证明——尽管尽力搜寻仍无法找到合适的南非公民/永久居民 |
| **薪资平等待遇** | 外籍员工薪资不得低于同等职位南非员工的平均水平 |
| **雇员比例** | ≥**60%**员工为南非公民或永久居民 |
| **企业注册** | 须已注册SARS/UIF/COIDA/CIPC |

### 2.3 申请所需文件

| 文件 | 说明 |
|------|------|
| 企业签证申请表 | 完整填写并签署 |
| 雇用外籍员工需求证明 | 说明为何需要外籍员工 |
| DOL证书 | 确认无法找到本地合适人选 + 职位描述+薪酬标准 + 薪资不低于本地同等水平 |
| SARS注册证明 | 企业税务注册 |
| UIF注册证明 | — |
| COIDA注册证明 | 工伤赔偿基金注册 |
| CIPC注册证明 | 公司注册（如法律要求） |
| 60%雇员证明 | 至少60%员工为南非公民/永久居民 |
| 遣返承诺书 | 企业承担外籍员工遣返费用 |
| 护照有效性承诺 | 确保护照始终有效 |
| 非禁止行业确认 | 确认不在部长公告的禁止行业清单内 |

### 2.4 企业签证 vs 个人附属签证
- 获批企业签证后，仍须为**每名外籍员工**单独申请附属工作签证
- 附属签证与企业签证有效期一致
- 员工离职/合同到期须离境

## 3. 公司内部调动签证（Intra-Company Transfer Visa）

### 3.1 适用对象
跨国公司内部从海外母公司/分公司**调动**至南非子公司/分支。

### 3.2 核心要求

| 要求 | 标准 |
|------|------|
| **有效期** | **4年** |
| **不可续签** | 到期必须离境或转换签证类型 |
| **母公司雇用证明** | 须由海外分支机构出具调任信，注明职位和角色 |
| **技能转移计划** | 须制定向南非公民/永久居民转移技能的计划 |
| **遣返承诺** | 雇主承诺承担遣返费用 |

### 3.3 与2024年积分制的关系
- ICT签证**不受**积分制100分门槛限制
- 但仍须满足上述全部文件要求
- 2024年Gazette No. 51416积分制适用于关键技能和一般工作签证

## 4. 2025年在线申请系统

### 4.1 重大变更
- **2025年4月1日**起，商务签证申请**全面转为在线提交**
- 不再接受邮件申请
- 2025年3月10日在线系统上线

### 4.2 影响
- 所有文件须电子化提交
- 流程更标准化，但初期可能存在系统磨合期
- 建议使用移民律师/顾问确保文件合规

## 5. 各类签证对比汇总

| 签证类型 | 有效期 | 最低投资/门槛 | 续签 | 永久居留 |
|----------|--------|-------------|------|----------|
| **商务签证** | 3年 | R5,000,000 | ✅ 可续 | ✅ 可申请 |
| **企业签证** | 3年 | DOL证明+60%雇员 | ✅ 可续 | — |
| **关键技能工签** | 5年 | 职业在清单上+100分 | ✅ 可续 | ✅ 5年后可申请 |
| **一般工作签证** | 3年 | 100分+DOL推荐 | ✅ 可续 | ⚠️ 有限制 |
| **ICT签证** | 4年 | 母公司调任 | ❌ 不可续 | ❌ 不可直接申请 |

## 6. 中资企业实操要点

1. **商务签证先走DTIC推荐**：45个工作日，是整个流程的瓶颈
2. **R500万投资额可减免**：如属ICT/汽车/旅游等8大行业，可申请waiver
3. **60%本地雇员是硬指标**：须在获批1年内向DHA证明
4. **资金锁定5年**：投资款不可随意撤回，须提前规划资金流
5. **企业签证适合批量引进**：如矿业/农业大批量用工
6. **ICT签证4年不可续**：到期须离境或转签证类型——中资外派人员须提前规划
7. **2025年4月全在线**：文件须电子化，建议找专业移民顾问
8. **禁止行业**：安保/二手车转售/异国娱乐——中资须避开
9. **永久居留路径**：商务签证持有者满足条件后可转永居，是长期规划选项
10. **遣返承诺是标配**：几乎所有签证都要求雇主承诺承担遣返费用
