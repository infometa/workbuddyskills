# 南非工作签证体系 — 关键技能/一般工作/内部调动/企业签证（2024改革）

> 来源：immigrationconsultantsa.com / into-sa.com / rsm.global / kpmg.com / savisas.com / ibn.co.za / iob.co.za / idchecker.co.za
> 核实建议：以 DHA（内政部）官网及最新 Gazette 为准；2024年10月改革变动大，旧资料可能过时

## 一、签证类型总览（Immigration Act 13 of 2002, Section 19）
| 签证 | 有效期 | 可续 | 永久居留路径 | 适用 |
|---|---|---|---|---|
| 关键技能工签 Critical Skills | 最长5年 | 是 | 5年相关经验可直申永居 | 职业在关键技能清单上 |
| 一般工作签 General Work | 最长5年 | 是 | 连续持签5年可申 | 非关键技能但有雇主offer |
| 公司内部调动签 ICT | 最长4年 | 否（可重新申请新签但常被拒） | 无 | 跨国公司内部调动 |
| 企业签证 Corporate | 雇主持有 | — | — | 批量引进外籍员工 |

## 二、2024年10月积分制改革（重大变化）
- **2024年10月9日/18日**（Gazette No. 51416, GN 5448），内政部长 Dr. Leon Schreiber 公布**积分制系统（PBS）**，立即生效，适用于关键技能工签和一般工作签。
- **ICT 签证不受 PBS 影响**，仍按原规则。
- 关键变化：
  - **废除劳工部推荐信（Letter of Recommendation）和雇主审查**——原 General Work 须证明本地招不到人，现由 PBS 替代。
  - **关键技能工签现在必须有确认的雇佣合同**（2024年10月前可无 offer 先入境求职的"Job Seeker Visa"选项已废除）。
  - **SAQA 学历评估**：部分豁免——可先提交 SAQA 申请回执，DHA 先发12个月签证，取得 SAQA 证书后再延期至4年。
  - 警局无犯罪证明（过去5年居住超12个月的每个国家）+ 体检报告仍为强制文件，但不计入积分。

## 三、积分制评分表（须达100分）
| 标准 | 积分 | 说明 |
|---|---|---|
| 职业在关键技能清单上 | **100** | 单项即达阈值 → 关键技能工签 |
| 学历 NQF 9–10（硕士/博士） | 50 | |
| 学历 NQF 7–8（学士/荣誉） | 30 | |
| 年薪 > R976,194 | 50 | 雇佣 offer 的薪资带为强制评分项 |
| 年薪 R650,976–R976,194 | 20（部分源写30） | |
| 工作经验 10年以上 | 30 | |
| 工作经验 5–10年 | 20 | |
| 受信雇主（Trusted Employer）offer | 30 | 由 DHA 认定，雇主持有，申请人不能自申 |
| 至少一种官方语言熟练 | 10 | 多语言不叠加，最高10分 |

- 关键技能清单上的职业 = 100分 = 关键技能工签；其他组合达100分 = 一般工作签。
- 雇佣 offer 为强制项，薪资低于适用带则不满足 PBS（不论其他积分）。

## 四、关键技能清单（Critical Skills List）
- 依据：Immigration Regulations 2014, Regulation 18(4), Section 19(4)。
- 现行版本：Government Gazette 47182, Notice 2306 of 12 August 2022（2024年有小幅更新，2026年仍有效）。
- 按 OFO 代码（6位）分类，每项含：职业名、最低NQF等级（通常NQF7+）、须注册的专业机构。
- 覆盖领域：IT、工程、医疗、金融（投资分析师、财务投资顾问、企业总经理、内审、经济学家）、生物技术等142类。
- 持关键技能工签满5年相关经验可直申**永久居留**（Section 27(b)）。

## 五、申请流程要点
1. 确认职业在关键技能清单上 / 或满足 PBS 100分
2. SAQA 学历评估（可先提交申请回执）
3. 专业机构注册/会员证明（如 IOBSA、ECSA、SACPCMP 等）+ Critical Skills Support Letter
4. 确认雇佣合同（关键技能与一般工作均强制）
5. 准备文件：护照（≥3空白页，签发<10年，有效期超停留30天）、2张证件照、警局无犯罪证明、体检报告、住宿证明
6. 通过 **VFS Global** 递交（VFS 仅收件采集生物识别，DHA/使领馆裁决）
   - 境内申请：VFS → DHA 裁决
   - 境外申请：南非使领馆裁决

## 六、处理周期
- 签证本身处理：6–8周
- 警局无犯罪证明：长达2个月
- SAQA 评估：3–6个月
- 专业机构注册：3–6个月
- **总周期可达14个月**，须提前规划

## 七、内部调动签证（ICT）特别要点
- 须在境外母公司连续雇用≥6个月。
- 最长4年，**不可续签、不可境内转换身份**。
- 须有**技能转移计划**：调任外籍员工须培训/提升一名南非公民或永久居民接任该岗位。
- 雇主须承担所有遣返费用。
- 4年后可重新申请新 ICT，但常被拒（理由：已有4年时间培训本地继任者）。

## 八、企业签证（Corporate Visa）
- 雇主持有，覆盖多名外籍员工。
- 雇主先获企业签证，再为个人申请企业工人证书（corporate worker certificates），按核定人数封顶。

## 九、拒签常见原因
- 缺少专业机构的 Critical Skills Support Letter
- 文件不齐/翻译不规范
- SAQA 评估未完成
- 经验与职位不匹配
- 薪资低于 PBS 适用带

⚠️ 2024改革信息更新快，各源对薪资带积分（20 vs 30）有分歧，引用前核对 DHA 官方 Gazette No. 51416。
