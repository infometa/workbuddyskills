## 一、VFS Global 递交流程

### Step 1：在线预约
- 访问 VFS 官网：`visa.vfsglobal.com/zaf/en/dha`
- 注册账户 → 选择签证类别 → 选择申请中心
- 预约时段以 15 分钟为间隔，新名额通常在**早上06:00（南非时间）**批量释放

### Step 2：在线支付
- VFS 服务费：R1,350 – R1,550（取决于签证类别）
- 支付方式：信用卡/借记卡、即时 EFT、Standard Bank 预存

### Step 3：到场递交
- 携带打印的预约确认单（含 AURN 参考号）
- 携带原件 + 一套清晰复印件（VFS 现场扫描）
- 采集生物识别信息（指纹和照片）

### Step 4：追踪申请
- VFS 追踪门户状态流转：Submitted → Despatched to DHA → Under Adjudication → Decision Made → Ready for Collection
- 可选 SMS 通知服务：R85
- 可选快递护照回邮：R230

### 增值服务

| 服务 | 费用 |
|------|:---:|
| 贵宾室（Premium Lounge） | R500 – R1,000 |
| SMS 状态更新 | R85 |
| 快递护照回邮 | R230 |

## 三、无犯罪证明（Police Clearance Certificate）

### 申请渠道对比

| 渠道 | SAPS 费 | 服务费 | 总费用 | 周期 |
|------|:---:|:---:|:---:|------|
| SAPS 直接申请 | R150 – R190 | — | R150 – R190 | 4-12周 |
| VFS Global 递交 | R150 | ~R200 | ~R350 | 6-8周 |
| 南非驻外使馆 | R150（等值） | 各国不同 | 各国不同 | 更长 |

### SAPS 直接申请流程
1. 前往任一 SAPS 警察局采集指纹（SAPS 91(a) 表格）
2. 准备 ID/护照复印件、动机信、联系方式
3. 支付费用（EFT 或银行存款，参考号格式："PCC+姓名首字母+姓氏"）
4. 邮寄或亲自递交至 Pretoria CRC
5. 等待 4-12 周，证书仅纸质领取或快递

**官方地址**：
- 邮政：Private Bag X308, Pretoria, 0001
- 实体：Bothongo Plaza West, 271 Francis Baard Street, Pretoria

## 四、各类签证对比

### 4.1 一般工作签证（General Work Visa）

**2024年10月重大变更**：取消 DEL 推荐信要求，替换为**100分积分制系统**。

### 100分积分评估标准

| 评分项 | 最高分 |
|--------|:---:|
| 职业在关键技能清单上 | 100分（自动获关键技能签证） |
| NQF 9-10级学历（硕士/博士） | 50分 |
| NQF 7-8级学历（荣誉学士/学士） | 30分 |
| 年薪 ≥ R976,194 | 50分 |
| 年薪 R650,976 – R976,194 | 20分 |
| 10年以上工作经验 | 30分 |
| 5-10年工作经验 | 20分 |
| 可信雇主（Trusted Employer）offer | 30分 |
| 官方语言能力 | 10分 |

> 如 100 分来自关键技能清单 → 获关键技能签证；其他组合达到 100 分 → 获普通工作签证。

### 4.2 公司内部调动签证（ICT）

| 项目 | 详情 |
|------|------|
| 法律依据 | Section 19(5) of Immigration Act 13 of 2002 |
| 有效期 | 最长 **4年** |
| 续签 | **不可续签/延期**（到期必须离境或转其他类别） |
| 前置条件 | 在海外母公司连续工作至少 **6个月** |
| 额外要求 | 雇主须提交技能转移计划（培训本地员工） |
| DHA 费用 | R1,520 – R1,775 |
| PR 路径 | 无直接 PR 路径 |

### 4.3 远程工作签证（Digital Nomad）

| 项目 | 详情 |
|------|------|
| 法律依据 | Section 11(1)(b)(iv)（2025年3月正式运行） |
| 年收入门槛 | 最低 **R650,976/年** |
| 收入来源 | 必须来自**南非境外**的雇主或客户 |
| 初始有效期 | **12个月**（可续签） |
| 最长总期限 | **3年**（连续续签） |
| 工作限制 | 不得为南非雇主工作 |
| PR 路径 | **无**（不可转永久居留） |
| 申请地点 | 须在**南非境外**申请 |

**税务规则**：
- 每年停留 < 183天 且母国有 DTA → 可能免税
- 超过 183天 → 须注册 SARS 并可能产生税务责任
- 无 DTA 国家 → 无论停留多久均需注册 SARS

### 4.4 企业签证（Corporate Visa）

| 项目 | 详情 |
|------|------|
| 法律依据 | Section 21 of Immigration Act |
| 有效期 | 最长 **3年** |
| 适用对象 | 矿业集团、农场等需批量引进工人的企业 |
| 审批要求 | 需 DTIC 推荐 + DOEL 证书 |
| 申请主体 | 企业申请，获批后个人再申请个人工作授权 |
| 改革方向 | 白皮书提议替换为 Sectoral Work Visa |

### 4.5 商务签证（Business Visa）

| 项目 | 详情 |
|------|------|
| 法律依据 | Section 15 of Immigration Act |
| 最低投资额 | **R5,000,000**（可从海外转入的现金、设备或材料） |
| 有效期 | 最长 **3年**（可续签） |
| 本地雇佣要求 | 获批后12个月内，至少 **60%** 的员工须为南非公民或永久居民 |
| 审批机构 | 需 DTIC 推荐信 |
| 资金认证 | SAICA 注册会计师须认证资金可用性 |
| DHA 审批周期 | 官方目标 **8周** |

**DTIC 减免行业**：农业加工、BPO和IT服务、汽车及零部件、纺织服装、绿色经济、先进制造、旅游、基础设施、ICT、化工/塑料/制药、创意设计、石油天然气
