## 一、现行关键技能清单

| 项目 | 详情 |
|------|------|
| 现行版本 | 2022年8月12日发布于政府公报 Government Gazette 47182, Notice 2306 |

## 三、申请条件

1. **职业必须在关键技能清单上**（以 OFO 编码匹配为准）
2. **SAQA 学历认证**（强制性）
3. **职业机构注册/确认函**
4. **无需事先获得工作 offer**（获批后12个月内在南非找到工作即可）

### 职业机构注册对照

| 职业 | 机构 |
|------|------|
| 工程师 | ECSA (Engineering Council of South Africa) |
| 医生 | HPCSA (Health Professions Council) |
| 护士 | SANC (South African Nursing Council) |
| 药剂师 | SAPC (South African Pharmacy Council) |
| 会计师 | SAICA / SAIPA |
| 自然科学 | SACNASP |
| 教师 | SACE |
| IT专业 | IITPSA（非强制性，确认函即可） |
| 建筑师 | SACAP |
| 审计师 | IRBA |

## 四、签证有效期

| 条件 | 有效期 |
|------|--------|
| 无工作 offer 时申请 | 1年（用于找工作） |
| 有长期工作合同 | 最长 **5年** |
| 永久居留路径 | 5年后通过 Section 26(a) 申请 PR；或直接通过 Section 27(b) 申请 PR |

## 六、DHA 审批周期（2026/2027年度）

根据 DHA 于 2026年6月27日发布的 **Immigration Circular No 08 of 2026**：

| 签证类别 | 官方目标 | 实际经验值 |
|---------|:---:|:---:|
| 关键技能签证 (S19(4)) | **4周** (APP) | 8-10周 |
| 普通工作签证 (S19(2)) | **4周** (APP) | 12-16周 |
| 商务签证 (S15) | **8周** | 8-12周 |
| 永久居留 (S26(a)/S27(b)/(c)) | **8个月** (APP) | 12-24个月 |

> 处理时间按**工作日**计算，不含周末和南非公共假日。

## 七、SAQA 评估详情

| 服务项目 | 2026/27 费用 | 2027/28 费用 |
|---------|:---:|:---:|
| 首学历评估 | R2,361 | R2,455 |
| 每额外学历 | R988 | R1,028 |
| 仅验证外国学历 | R1,038 | R1,080 |
| 上诉第一阶段 | R2,558 | R2,661 |
| 上诉第二阶段 | R3,838 | R3,991 |

**处理周期**：
- 标准：最长 **65个工作日**（约3个月）
- 实际经验：4-8周（简化申请），复杂案例 12-18周
- 加急服务：2-3周（费用更高）
- 所有费用**不可退款**

## 八、2025-2026年 DHA 白皮书改革

### 时间线

| 时间节点 | 事件 |
|---------|------|
| 2024年4月 | 内阁批准原始白皮书 |
| 2025年12月 | 发布修订白皮书草案征求公众意见 |
| 2026年1月30日 | 豪登省/全国公众咨询会 |
| 2026年2月15日 | 公众意见征询截止 |
| **2026年4月8日** | **内阁正式批准修订白皮书** |
| 2026年7月 | 立法修正案起草阶段，待提交议会 |

### 核心改革提议

| 改革领域 | 具体内容 |
|---------|---------|
| 技术工人签证 | 合并关键技能签证和普通工作签证为统一类别 |
| 积分制系统 | 基于资格、薪资、经验、语言能力的100分评估体系 |
| 远程工作签证 | 新的独立签证类别 |
| 创业签证 | 新的独立签证类别 |
| 行业工作签证 | 替代现有企业签证 |
| 电子旅行授权(ETA) | 全面数字化签证申请流程 |
| 移民从业者制度 | 只有持牌移民从业者、律师可代理客户 |
| 专业移民法院 | 专门司法机制处理移民争议 |

## 九、ETA 电子旅行授权进展

| 阶段 | 详情 |
|------|------|
| Phase 1 (2025年10月) | 面向 G20 峰会代表开放 |
| Phase 2 (2025年11月) | 扩展至印度游客 |
| Phase 3 (2026年) | 进一步扩展至所有符合条件的旅客 |
| 技术特点 | AI和机器学习驱动，面部识别生物识别 |
| 目标 | 数字化签证结果在 **24小时内** 完成 |
| 实施机构 | 边境管理局 (BMA) 与 SARS 协作 |
| 当前状态 | 逐步推广中，已在主要口岸部署面部识别摄像头 |
