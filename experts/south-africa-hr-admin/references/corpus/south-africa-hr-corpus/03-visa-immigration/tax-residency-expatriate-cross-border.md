# 南非税务居民身份与外派人员跨境税务

> **数据来源**：SARS官网（sars.gov.za）、Financial Migration、Ibex Consulting、FinGlobal、Greenback Tax Services
> **更新日期**：2025年7月（SARS 2025申报季新规）
> **时效提示**：DTA条款和SARS审查政策可能变化，以SARS官网和持牌税务师为准

---

## 一、南非税制概述

### 居住地原则（Residence-Based Taxation）
南非采用**居住地原则**征税：
- **税务居民**：就**全球收入**（worldwide income）纳税 + 全球资本利得
- **非居民**：仅就**南非来源收入**（South African source income）纳税

### 与中国的税收协定
- 南非与中国签有《避免双重征税协定》（DTA）
- DTA确定哪国对特定收入有征税权
- DTA可覆盖南非国内法的居民判定

## 二、税务居民身份判定（两项测试）

### 测试1：通常居住测试（Ordinarily Resident Test）— 普通法概念

**核心标准**：南非是否是该个人"自然且理所当然地回归之处"（the country to which that individual will naturally and as a matter of course return after his or her wanderings）——即"真实家园"（real home）。

#### SARS考量的因素
| 因素 | 说明 |
|------|------|
| 最固定居所 | 主要居住地在哪里 |
| 习惯性居所 | 最常居住之处 |
| 个人物品位置 | 家具/车辆/物品存放地 |
| 国籍 | 南非国籍倾向居民 |
| 商业与个人利益 | 主要业务和利益所在地 |
| 家庭社会关系 | 家庭、学校、教会、社区 |
| 政治/文化活动 | 参与的活动所在地 |
| 永久居留申请 | 是否在其他国家申请永居 |
| 海外停留性质 | 时长、目的、性质 |
| 返回南非频率 | 回访频率和原因 |

> ⚠️ **主观性测试**：即使海外居住多年，若家庭、商业、长期计划仍与南非相关，SARS可继续认定为居民。

### 测试2：物理在场测试（Physical Presence Test）— 客观标准

**前提**：仅当个人非"通常居住"于南非时适用。

#### 三项条件（须全部满足）
| 条件 | 要求 |
|------|------|
| 当年 | 在南非停留超过 **91天** |
| 前5年每年 | 每年停留超过 **91天** |
| 前5年累计 | 累计停留超过 **915天** |

#### 退出规则
- 满足物理在场测试的居民，若**连续离开南非330天以上**，自离开之日起不再视为居民

#### 测试失败
- 三项中任何一项不满足 → 不满足物理在场测试
- 若也不"通常居住"于南非 → **非居民**

## 三、非居民的南非税务义务

### 应税收入（南非来源）
| 收入类型 | 是否应税 |
|----------|----------|
| 南非就业收入（在南非提供服务） | ✅ 应税 |
| 南非银行利息 | ✅ 应税（部分豁免） |
| 南非房产租金 | ✅ 应税 |
| 南非股息 | 通常免税（DTA可能另有规定） |
| 外国来源收入 | ❌ 不应税 |

### DTA下的就业收入豁免（重要！）

非居民在南非提供服务的就业收入，**默认在南非应税**。但若满足DTA下**全部三个条件**，可免于南非税：

| 条件 | 要求 |
|------|------|
| 1. 在场时间 | 12个月内在南非停留**不超过183天** |
| 2. 雇主 | 雇主为**非南非居民** |
| 3. 常设机构 | 报酬不由雇主在南非的**常设机构**（PE）承担 |

> **实务意义**：中国外派人员短期在南非工作（<183天/12个月），若雇主为中国公司且无南非常设机构，可能免南非个税。但须审慎评估DTA具体条款。

## 四、SARS 2025年外派人员审查新规

### 2025年6月30日起的新措施

1. **非居民税务状态确认函**增加"合格依据"标注：
   - **金融移民（永久停止）**：离开南非无意永久返回 → 仅须申报南非来源收入
   - **DTA途径（临时停止）**：依据DTA暂时停止居民身份 → **须每年向SARS证明DTA资格**，须申报全球收入（但DTA保护下外国收入免税）

2. **居民身份恢复追踪**：
   - RAV01表新增"南非税务居民恢复日期"字段
   - 返回南非的非居民须正式通知SARS恢复居民身份
   - 未正式停止居民身份者 → SARS可将全部海外期间视为持续居民身份 → 追溯评估+罚款+利息

3. **SARS加强执法**：
   - 获得财政部额外拨款加强外派人员审查
   - 重点审查以非正确依据停止居民身份的纳税人

### 对中国外派人员的实务影响
- **中国外派至南非的中国籍员工**：
  - 若中国是"通常居住"地 → 可能非南非税务居民 → 仅南非来源收入应税
  - 但若在南非停留超过物理在场测试门槛 → 可能被认定为南非税务居民
  - 须评估中南DTA条款确定居民身份

- **南非籍华人回南非工作**：
  - 须正式恢复税务居民身份
  - 海外期间收入可能被追溯征税

## 五、中南避免双重征税协定（DTA）要点

### DTA的居民身份"打破平局"规则
当一个人同时满足中南两国国内法的居民标准时，DTA按以下顺序确定居民身份：

1. **永久性住所**（permanent home）→ 在哪国有永久性住所
2. **重要利益中心**（center of vital interests）→ 个人/经济关系更密切的国家
3. **习惯性居所**（habitual abode）→ 通常居住在哪国
4. **国籍**（nationality）→ 哪国国籍
5. **双方协商**→ 两国税务机关协商解决

### DTA下的就业收入规则
- 一般规则：就业收入在**实际提供服务地**征税
- 183天豁免：满足上述三条件可在居住国征税（非服务提供国）

### DTA下的董事费
- 董事费在**公司所在国**征税（不同于一般就业收入）

## 六、中资企业外派人员税务实操

### 场景1：中国外派南非（短期 < 183天/12月）
- **中国税务居民**：全球收入在中国纳税
- **南非非居民**：若满足DTA三条件 → 南非就业收入免税
- **PAYE**：南非雇主仍须预扣PAYE，非居民须事后通过ITR12申报申请退税
- **实操建议**：保留入境/出境记录作为停留天数证据

### 场景2：中国外派南非（长期 > 183天/12月）
- 可能成为南非税务居民（若满足物理在场测试或通常居住测试）
- **双重居民身份** → 依DTA打破平局规则确定
- **实务建议**：
  - 聘请中南双重持牌税务师评估居民身份
  - 考虑税收均等化协议（tax equalization agreement）
  - 利用外国税收抵免避免双重征税

### 场景3：南非籍员工外派中国
- 若正式停止南非税务居民身份 → 仅南非来源收入在南非应税
- 须通过金融移民或DTA途径正式停止
- **2025年新规**：须每年证明DTA资格（DTA途径）或一次性完成金融移民
- 中国税务义务：依中国税法确定（通常183天以上构成中国税务居民）

### 场景4：南非本地雇员（南非籍）
- 南非税务居民 → 全球收入在南非纳税
- 中国来源收入（如中国母公司支付的津贴）须申报南非
- 可利用DTA外国税收抵免

## 七、外派人员薪酬结构税务考量

### 需关注的薪酬要素

| 薪酬要素 | 税务考量 |
|----------|----------|
| 基本薪资 | 在哪国提供服务 → 该国征税权 |
| 住房津贴 | 若由南非雇主支付 → 南非应税 |
| 差旅津贴 | Travel Allowance 80%计入PAYE |
| 公司车 | 3.5%/3.25%月价值计入PAYE |
| 子女教育津贴 | 通常为应税附加福利 |
| 离境津贴 | 视性质可能应税或免税 |
| 股票期权 | 行权时按服务提供地征税 |

### 税收均等化（Tax Equalization）
- 外派员工税负与留在本国时相同
- 雇主承担东道国额外税负
- 需要详细的薪酬和税务追踪

## 八、合规建议

### 对中资企业
1. **外派前评估**：聘请税务师评估外派人员的居民身份和两国纳税义务
2. **DTA利用**：合理利用中南DTA避免双重征税
3. **PAYE合规**：南非雇主须对南非来源就业收入预扣PAYE
4. **记录保存**：保留入境/出境记录、薪酬明细、DTA申请文件（至少5年）
5. **年度审查**：每年审查外派人员居民身份变化（尤其是DTA途径者）
6. **恢复申报**：外派人员返回南非时须正式通知SARS恢复居民身份
7. **2025年新规**：关注SARS非居民确认函新格式和RAV01恢复日期字段

### 对外派个人
1. **了解两项测试**：通常居住+物理在场
2. **正式程序**：不要仅凭物理离开就认为已停止居民身份
3. **DTA途径vs金融移民**：DTA途径须每年证明，金融移民一次性完成但不可逆
4. **海外资产结构**：返回南非前重组海外资产
5. **专业咨询**：聘请持牌跨境税务师
