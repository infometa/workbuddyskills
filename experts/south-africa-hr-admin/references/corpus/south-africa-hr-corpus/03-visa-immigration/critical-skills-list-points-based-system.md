# 南非关键技能清单与积分制详解（2024-2025）

> 来源：Department of Home Affairs (DHA)、Government Gazette No. 47182/51416、SAQA、各移民事务所公开资料
> 最后更新：2025年（含2024年10月积分制改革）
> 用途：南非人力行政专家语料库 — 签证移民板块

---

## 1. 关键技能清单概述

**关键技能清单（Critical Skills List）** 是南非内政部（DHA）发布的官方职业注册表，列出南非经济急需的技能短缺职业。当前版本于2022年8月12日发布（Government Gazette 47182, Notice 2306），2023年10月3日通过Government Notice R3934更新修订，为2024-2026年在效版本。

### 法律基础
- Immigration Act 13 of 2002, Section 19(4)
- Immigration Regulations 2014, Regulation 18(4)
- 2024年10月18日发布积分制框架：Government Gazette No. 51416, GN 5448

---

## 2. 积分制框架（Points-Based System, PBS）

2024年10月18日，DHA发布积分制框架，适用于**关键技能工作签证**和**一般工作签证**。申请人须达到 **100分** 门槛。

### 2.1 评分表

| 评分项 | 条件 | 分值 |
|--------|------|------|
| **职业在关键技能清单上** | 是 | **100分**（单独达标） |
| **学历** | NQF 9-10（硕士/博士） | 50分 |
| **学历** | NQF 7-8（学士/荣誉） | 30分 |
| **薪资** | 年薪 > R976,194（税前） | 50分 |
| **薪资** | 年薪 R650,976 – R976,194 | 20分 |
| **工作经验** | 10年以上 | 30分 |
| **工作经验** | 5-10年 | 20分 |
| **受信雇主录用** (Trusted Employer) | 是 | 30分 |
| **语言能力** | 至少1种官方语言 | 10分 |

### 2.2 签证类型判定
- **100分全部来自"职业在清单上"** → 获批 **关键技能工作签证**
- **100分通过其他组合达到** → 获批 **一般工作签证**
- **无论积分多少，录用通知书（offer of employment）为强制要件**

### 2.3 语言能力
- 南非11种官方语言均可计分：Afrikaans, English, isiNdebele, isiXhosa, isiZulu, Sepedi, Sesotho, Setswana, siSwati, Tshivenda, Xitsonga
- 多语言不叠加，最高10分
- 对关键技能清单上的申请人，语言分通常不需要（职业分已满100）

## 3. 关键技能工作签证申请要求

### 3.1 基本要求
| 要求 | 说明 |
|------|------|
| **职业在清单上** | OFO代码匹配 |
| **SAQA学历认证** | 南非资格管理局评估外国学历，需4-8周（可先提交申请证明获取12个月临时签证） |
| **职业机构注册** | 如适用（见下表） |
| **录用通知** | 必须有南非雇主的有效offer（2024年Regulation 18(5)修订后强制） |
| **无犯罪证明** | 所有居住超过12个月的国家 |
| **体检报告** | 指定医疗机构 |
| **有效护照** | 有效期>30天 |

### 3.2 职业机构注册对照

| 职业类别 | 注册机构 |
|----------|----------|
| 工程师 | **ECSA** (Engineering Council of South Africa) |
| 医疗专业人员 | **HPCSA** (Health Professions Council of SA) |
| 会计师 | **SAICA** (South African Institute of Chartered Accountants) |
| 建筑项目经理 | **SACPCMP** (SA Council for the Project and Construction Management Professions) |
| IT专业人员 | 行业协会（按具体领域） |
| 律师 | **LSSA** (Legal Practice Council) |

### 3.3 签证有效期与PR路径
| 项目 | 详情 |
|------|------|
| 有效期 | 最长 **5年**，可续签 |
| 永久居留(PR) | 持关键技能签证工作满 **5年** 后可申请PR（Section 27(b)） |
| 家属 | 配偶及子女可申请附属签证 |
| 工作权利 | 仅限关键技能领域内工作 |

## 5. Trusted Employer（受信雇主）制度

| 项目 | 说明 |
|------|------|
| 定义 | DHA认定的合规南非雇主，可为其外籍员工额外贡献30分 |
| 认定标准 | 企业运营合规性、税务合规、B-BBEE评级、雇员规模等 |
| 持有方 | **雇主**（非申请人），申请人无法自行申请 |
| 影响 | 非关键技能清单上的申请人，若雇主非Trusted Employer，可能无法达到100分门槛 |

## 6. 部长豁免令（Ministerial Waivers）

2024年积分制实施同步发布的豁免：
1. **DOL推荐信豁免**：部分一般工作签证不再需要DOEL（劳动就业部）推荐信
2. **SAQA部分豁免**：可凭SAQA申请受理证明获批12个月临时签证，待SAQA完成后延期
3. 目的：减少积压、加快审批

---

## 7. 申请流程

```
1. 确认职业在关键技能清单上
2. SAQA学历评估（4-8周）
3. 职业机构注册（如适用）
4. 获取雇主录用通知书
5. 准备文件（无犯罪证明、体检报告、护照）
6. 通过VFS Global递交申请
7. DHA审批（通常8-12周，复杂案件更长）
8. 获批签证（有效期最长5年）
9. 入境后12个月内须确认为雇主工作
```

## 8. 与一般工作签证的对比

| 特征 | 关键技能工作签证 | 一般工作签证 |
|------|----------------|-------------|
| 职业清单要求 | 必须在清单上 | 不要求 |
| DOL推荐信 | 不需要 | 部分豁免后仍可能需要 |
| 有效期 | 最长5年 | 最长3年 |
| PR路径 | 5年后可申请 | 需更长居住期 |
| 录用通知 | 强制 | 强制 |
| 积分制 | 职业分=100分即达标 | 需其他组合达100分 |

## 9. 中资企业实务要点

1. **识别关键技能岗位**：提前核对外籍员工的OFO代码是否在清单上
2. **SAQA评估先行**：这是最耗时的前置步骤，建议提前3个月启动
3. **职业机构注册**：工程师须注册ECSA，流程约4-12周
4. **薪资门槛策略**：年薪>R976,194可获50分，有助于非清单职业的一般工作签证申请
5. **Trusted Employer申请**：中资企业达到标准后申请此认定，为后续外籍员工签证提供便利
6. **12个月临时签证**：SAQA评估期间可先获取临时签证，避免合法工作真空期
7. **PR规划**：关键技能签证满5年可申请PR，须保持连续就业记录
