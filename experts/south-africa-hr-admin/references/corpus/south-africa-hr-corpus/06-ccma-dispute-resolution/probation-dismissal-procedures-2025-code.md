# 试用期管理与解雇程序 — 2025年新准则

> **来源**：LRA Schedule 8 (已被取代); Code of Good Practice: Dismissal 2025 (2025年9月4日生效); DLA Piper; Laboured.org.za; Van Deventers Law; Kaplan Blumberg; Kern Attorneys
> **最后更新**：2025年9月（新准则已生效）

---

## 一、2025年新《Code of Good Practice: Dismissal》

### 生效信息
- **生效日期**：2025年9月4日
- **取代文件**：
  - Schedule 8: Code of Good Practice: Dismissal (1996年起实施)
  - Code of Good Practice on Dismissal Based on Operational Requirements (1999年)
- **意义**：南非30年来首次全面修订解雇准则

### 新准则四大变化

| 变化 | 说明 |
|------|------|
| **小企业灵活性** | 首次明确承认小企业无需耗时调查，可采用更简化非正式程序 |
| **试用期扩展** | 试用期目的扩展为评估"适用性"（suitability）而非仅绩效 |
| **不相容性** | 首次将"文化不适配"（incompatibility）认可为解雇理由（归入绩效不胜任） |
| **裁员合并** | 裁员准则合并到统一文件，含结构化通知模板（Annexure A） |

## 二、试用期（Probation）管理

### 试用期法律性质
> **核心原则**：试用期不影响员工免受不当解雇的保护。

- 试用期不是"随意解雇"的通行证
- 试用期员工仍享有LRA下的公平程序权利
- 但试用期解雇的门槛**低于**转正后解雇

### 2025年新准则对试用期的要求

#### 1. 试用期须预先确定
- 须在雇佣合同中明确约定试用期长度
- 试用期长度须与工作性质和评估所需时间合理对应

#### 2. 典型试用期长度
| 岗位类型 | 建议试用期 |
|----------|-----------|
| 基层操作岗 | 3个月 |
| 中层管理岗 | 3-6个月 |
| 高级管理岗 | 6个月（可延长） |

#### 3. 雇主义务
- 提供合理的评估、指导、培训或辅导
- 根据雇主规模和岗位性质调整支持程度
- 设定清晰的绩效标准
- 定期反馈和评估
- 记录所有指导和评估过程

#### 4. 延长试用期
- 须有合理理由
- 须以书面形式通知员工
- 须说明延长原因和改进期望

#### 5. 试用期解雇程序
- **必须**给予员工陈述意见的机会（make representations）
- 雇主须**真正考虑**员工的陈述
- 须有合理的绩效或行为相关理由
- 解雇门槛低于转正后（reasons may be less compelling）
- 但不可无故随意解雇

### 试用期常见误区

| 误区 | 正确做法 |
|------|---------|
| 试用期可随意解雇 | 须有理由+给员工陈述机会 |
| 无需提供改进机会 | 须提供指导、培训和合理改进时间 |
| 不需要正式程序 | 须有基本公平程序（小企业可简化） |
| 口头通知即可 | 建议书面通知，说明理由 |
| 试用期=临时合同 | 试用期是永久合同的一部分 |

## 三、解雇的四大理由（2025年新准则）

### 1. 不当行为（Misconduct）

#### 渐进式纪律（Progressive Discipline）
- 新准则明确支持渐进式纪律作为主要方法
- 从辅导 → 口头警告 → 书面警告 → 最终书面警告 → 解雇
- 小企业可采用更简化的非正式方式
- 解雇仅适用于：行为导致继续雇佣不可容忍

#### 纪律程序
- 通知员工不当行为指控（**尽量以书面形式，用员工能理解的语言**）
- 给予准备和陈述的机会
- 调查应与指控性质和雇主规模相适应
- **新准则未明确要求正式纪律听证会**，但CCMA通常将听证会视为程序公正的重要因素
- 若有被挑战风险，建议举行正式纪律听证会

#### 公平测试（Item 7测试）
1. 是否存在合理的工作场所规则？
2. 员工是否知道该规则？
3. 规则是否一致执行？
4. 员工是否有机会解释？
5. 解雇是否为适当处罚？

#### 严重不当行为（可立即解雇）
- 盗窃、欺诈、暴力
- 严重醉酒/吸毒
- 故意损坏财产
- 仍须给予解释机会，但可跳过渐进式纪律

### 2. 绩效不胜任（Incapacity: Poor Performance）

#### 新准则变化
- 首次将**"不相容性"**（incompatibility with employer's business culture or fellow employees）纳入绩效不胜任类别
- "文化不适配"可作为解雇理由，但须按绩效管理程序处理

#### 程序要求
1. 明确告知绩效标准
2. 提供适当的指导、培训或辅导
3. 给予合理改进时间
4. 进行绩效评估并记录
5. 给予员工回应绩效指控的机会
6. 若改进无望，方可解雇

#### PIP（绩效改进计划）
- 建议正式书面PIP
- 明确改进目标、时间表、支持措施
- 定期评估和反馈
- PIP失败后方可解雇

### 3. 健康原因不胜任（Incapacity: Ill Health or Injury）

#### 程序要求
1. 获取医疗信息（须获员工书面同意，遵守POPIA）
2. 确定问题是暂时性还是永久性
3. 探索合理便利（reasonable accommodation）：
   - 调整岗位
   - 减少工时
   - 轻体力工作
4. 仅当无合适替代岗位时方可解雇

#### 严重情况
- 永久性完全丧失工作能力 → 可较快解雇
- 暂时性疾病 → 须等待康复或提供临时调整

### 4. 运营需求（Operational Requirements / Retrenchment）

#### 新准则合并
- 裁员准则合并到统一文件（Part G）
- 含**结构化书面通知模板**（Annexure A），须覆盖9类信息

#### LRA Section 189 协商程序
1. 发出书面协商通知
2. 与受影响员工或工会协商
3. 讨论替代方案（如调岗、减少工时）
4. 适用公平选择标准
5. 提供遣散费

#### 选择标准建议
- 技能：40%
- 绩效：40%
- 服务年限：20%
- 禁止基于：个人偏好、年龄、工会身份

#### 遣散费
- 法定最低：每满1年1周工资
- 合同可约定更高标准
- 2025年新准则未提高法定最低

## 四、程序公正 vs 实体公正

### 程序公正（Procedural Fairness）
- 员工理解指控内容
- 给予回应时间
- 可带同事或工会代表
- 获得书面结果
- 建议提供内部申诉渠道

> **CCMA大多数不当解雇裁决源于程序错误，而非实体理由不成立。**

### 实体公正（Substantive Fairness）
- 解雇理由必须合理
- 处罚必须与过错成比例
- 解雇须为"合理回应"（Sidumo原则）

## 五、CCMA争议解决流程

### 时间线

| 步骤 | 期限 |
|------|------|
| 员工被解雇 | Day 0 |
| 向CCMA提交争议 | **30天内** |
| CCMA安排调解 | 提交后**30天内** |
| 调解不成→仲裁 | 调解后启动 |
| 仲裁裁决 | 通常1-3个月内 |
| 向劳动法院上诉 | 仲裁后**6周内**（特定情况） |

### 补偿上限

| 解雇类型 | 补偿上限 |
|----------|---------|
| 不当解雇（普通） | **12个月**工资 |
| 自动不当解雇（Section 187） | **24个月**工资 |
| 复职（Reinstatement） | 补发全部工资（无上限） |

### 自动不当解雇（Section 187）
以下理由解雇**自动违法**：
- 怀孕
- 家庭责任
- 工会成员身份
- 合法罢工参与
- 受保护举报（Protected Disclosures Act）
- 歧视（种族、性别、宗教等）

## 六、小企业特殊条款（2025年新准则）

### 适用对象
- 新准则Section 3专门为小企业提供灵活性
- 未明确具体人数门槛，但以"无法配备专业HR"为判断标准

### 灵活性内容
- 无需进行耗时的正式调查
- 可采用更简化非正式程序
- 仍须保证员工有真正回应指控的机会
- 仍须公平决策

### 限制
- 灵活性不等于豁免公平原则
- CCMA将根据企业规模和情境评估合理性
- 大型企业仍须遵循完整正式程序

## 七、对中资企业的实务建议

### 1. 试用期管理清单
- [ ] 合同中明确试用期长度
- [ ] 设定清晰绩效标准并书面告知
- [ ] 安排定期评估和反馈
- [ ] 记录所有指导和评估
- [ ] 解雇前给予陈述机会
- [ ] 书面通知解雇决定和理由

### 2. 纪律程序建议
- 采用渐进式纪律（辅导→口头警告→书面警告→最终警告→解雇）
- 所有通知尽量书面化，用员工能理解的语言
- 严重不当行为仍须给予解释机会
- 建议举行正式纪律听证会（即使新准则未强制要求）
- 保留完整记录

### 3. 绩效管理建议
- 设定明确KPI和绩效标准
- 提供PIP并给予合理改进时间
- 定期反馈并记录
- 绩效评估须有员工签字确认
- "文化不适配"可作为理由但须按绩效程序

### 4. 裁员建议
- 严格遵循LRA Section 189协商程序
- 使用新准则Annexure A模板发出通知
- 选择标准须客观公平（技能40%+绩效40%+服务20%）
- 提供法定遣散费（至少每满1年1周工资）
- 建议提供再就业支持

### 5. 紧急更新事项（2025年9月后）
- **立即更新内部纪律政策和程序**
- 将新准则的要求纳入HR手册
- 培训管理层和HR人员
- 特别关注小企业灵活性条款是否适用

> ⚠️ 2025年9月4日新准则生效后，所有解雇程序将按新标准评判。使用旧政策的企业面临CCMA败诉风险。
