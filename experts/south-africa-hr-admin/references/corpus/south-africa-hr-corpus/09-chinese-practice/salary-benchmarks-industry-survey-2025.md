3. **金融业增幅最低**：5.0%，行业成熟+成本压力
4. **通胀驱动**：SARB目标区间3%-6%，薪酬增幅须覆盖通胀

## 四、薪酬结构参考

### 南非典型薪酬包组成

```
Cost to Company (CTC) = 基本工资 + 津贴 + 福利 + 奖金
```

| 组成 | 典型占比 | 说明 |
|---|---|---|
| 基本工资 | 70-80% | PAYE计税基础 |
| 住房津贴 | 5-10% | 或提供住房 |
| 交通津贴 | 3-5% | 或公司车 |
| 医疗援助 | 5-8% | 雇主缴费部分 |
| 退休金 | 7-10% | 雇主缴费（通常薪15-20%） |
| 13薪/奖金 | 5-10% | 年终一次性 |

### 入门级到高管层薪酬分布

| 层级 | 月薪区间 | 占劳动力比例 |
|---|---|---|
| 最低工资 | R4,737 - R5,610 | ~15% |
| 入门级 | R8,000 - R15,000 | ~35% |
| 中级专业 | R15,000 - R35,000 | ~30% |
| 高级职位 | R35,000 - R80,000 | ~15% |
| 高管层 | R80,000+ | ~5% |

### 中产阶级门槛

UCT Liberty Institute研究：家庭月收入约 **R22,000** 被视为中产阶级门槛

## 五、人才市场趋势（2025）

### 雇佣需求

- **2025年hiring demand低**：所有领域"very easy to hire"
- 仅 **29%** 专业人士在找新工作（2024年为46%），流动性下降
- 平均任期 **1.5年**（1.2-2.6年按行业）
- **50%** 企业计划加薪 vs **48%** 员工期望加薪

### 技能需求热点

1. **技术人才**：网络安全、数据科学、全栈开发
2. **可再生能源**：绿能转型推动工程需求
3. **金融合规**：风险管理、合规官
4. **销售与领导力**：business leaders持续短缺

### GNU影响

2024年民族团结政府（GNU）成立后市场信心提振，预计2025下半年招聘需求回暖
