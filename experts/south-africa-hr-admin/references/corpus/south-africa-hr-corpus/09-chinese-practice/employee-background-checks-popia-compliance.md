## 一、POPIA 对背景调查的影响

### 四项核心要求

| 原则 | 具体要求 |
|------|---------|
| 合法性 | 检查目的必须合法且合理必要（岗位确实需要） |
| 同意 | 检查前须获得**书面、具体、知情同意** |
| 目的限制 | 结果仅可用于声明目的，不得留存用于未来招聘或分享第三方 |
| 主体访问权 | 受检人可要求查看结果副本；不利决定须通知并赋予回应权 |

> **犯罪记录**在 POPIA 第26条下被归类为**特殊个人信息**，处理须获得明确同意。

### 同意书五大要素
1. 书面记录并签名
2. 列出具体检查项目
3. 自愿同意
4. 知情（说明用途）
5. 可撤回

## 三、犯罪记录检查（通过 AFIS）

| 检查方式 | 费用（2026年） | 处理时间 |
|---------|:---:|----------|
| SAPS 警察证明函（PCC）自查 | **R190**（官方规费） | 8-20周 |
| 经认证指纹供应商代办 PCC | R350-R650 | 2-8周 |
| 雇主背景检查（数字指纹，PSIRA 持牌） | **R150-R350** | 24-72小时 |
| 雇主背景检查（滚动指纹） | R200-R450 | 3-14天 |
| 综合筛查包（犯罪+身份+学历+信用） | **R450-R1,500** | 3-7天 |

### 关键技术要点
- AFIS 通过**指纹匹配**，非姓名或 ID 号匹配
- 仅返回**定罪记录**，不含未定罪逮捕、待审案件或指控
- 已清除（expunged）的记录不应出现
- SAPS 不提供加急付费通道
- 私人机构更快但无法提供海外当局要求的官方信头文件

## 五、ITC 信用查询要求

### 法律限制（《国家信用法》第19(3)条）
- 信用局**仅可在职位涉及信任、诚实及处理现金或财务**时释放消费者信用信息
- 一般办公室职位**不符合**信用检查条件
- 须获得候选人**特定书面同意**
- 须从**注册信用局**获取（TransUnion、Experian、XDS、Compuscan）

### 信用检查返回内容
- 付款历史记录
- 判决（judgments）
- 违约（defaults）
- 管理令（administration orders）

### 合规步骤
1. 确认职位符合第19(3)条相关性测试
2. 获得特定书面同意
3. 从注册信用局获取报告
4. 审查付款历史和判决
5. 按比例适用决策并记录理由
6. 须告知候选人如决策基于信用信息

## 七、犯罪记录清除（Expungement）

| 项目 | 详情 |
|------|------|
| 等待期 | **10年**（刑事诉讼法第271B条） |
| DIY 申请费 | R260-R490 |
| 处理时间 | 6-12个月 |
| 提交对象 | 司法总长 |
| 适用条件 | 仅罚款定罪、R20,000以下刑罚、特定政治时代定罪 |
| 排除项 | Schedule 6 罪行和性犯罪**不可清除** |
| 大麻定罪 | 根据第271DA条**自动移除**（无需申请） |

## 八、法律框架

| 法律 | 适用范围 |
|------|---------|
| POPIA | 个人信息处理，犯罪记录为特殊个人信息 |
| 国家信用法 | 限制信用检查用于就业目的 |
| 就业公平法 | 禁止不公平歧视；犯罪记录非自动雇佣障碍 |
| 刑事诉讼法 | 犯罪记录检查和清除 |
| 国家资格框架法/SAQA法 | 学历验证 |
| FICA | 金融机构须保留记录5年 |
