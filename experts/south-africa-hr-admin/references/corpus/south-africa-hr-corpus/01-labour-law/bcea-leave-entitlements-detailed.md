# BCEA 休假权益详解：年假/病假/产假/家庭责任假/育儿假

> 来源：Basic Conditions of Employment Act 75 of 1997 Chapter 3、Elaine Jordaan Attorneys、Justine Delmonte、Jibble、AfricaCarrières
> 最后更新：2025年（含2023年BCEA修订案新增育儿假）
> 用途：南非人力行政专家语料库 — 劳动法板块

---

## 1. 休假类型全景

| 休假类型 | 时长 | 薪酬 | 周期 |
|----------|------|------|------|
| **年假** (Annual Leave) | 21连续天 = 15工作日（五天制） | 全薪 | 每12个月 |
| **病假** (Sick Leave) | 30工作日 = 6周（五天制） | 全薪（须医疗证明） | 36个月周期 |
| **产假** (Maternity Leave) | 4个月连续 | **无薪**（可领UIF津贴） | 每次怀孕 |
| **家庭责任假** (Family Responsibility Leave) | 3天/年 | 全薪 | 每12个月 |
| **育儿假** (Parental Leave) | **10天**（2023年新增） | **无薪**（可领UIF津贴） | 每次生育/收养 |
| **收养假** (Adoption Leave) | **10周**（<2岁儿童） | **无薪**（可领UIF津贴） | 每次收养 |
| **代孕育儿假** (Commissioning Parental Leave) | **10周** | **无薪**（可领UIF津贴） | 每次代孕 |

> **适用门槛**：月工作超过24小时的雇员适用年假/病假/产假；家庭责任假须受雇≥4个月且每周≥4天。

---

## 2. 年假（Annual Leave）详解

### 2.1 权益标准
- **21连续天**（含周末）= 五天制工作**15个工作日**
- 替代计算方式（须合同约定）：
  - 每17天工作 = 1天年假
  - 每17小时工作 = 1小时年假

### 2.2 累积与使用
- 年假按**12个月周期累积**（非周期开始即分配）
- 雇主须在休假周期结束后**6个月内**批准年假
- **6个月规则**：保护雇员权益——要求雇主在6个月内批假，**不是**要求雇员6个月内休完否则作废
- 在职期间**不得以薪代假**，仅终止雇佣时可支付未休年假

### 2.3 终止时支付
- 离职时须支付**当前及上一周期**累积的未休年假
- 计算公式：未休天数 × 日工资率

### 2.4 超额年假
- 雇主可给予超过BCEA最低的年假（如20天而非15天）
- 超额部分可附条件（如当年不休则作废）
- 须在合同/政策中明确说明先使用哪部分

## 3. 病假（Sick Leave）详解

### 3.1 权益标准
- **36个月周期**内享有**30个工作日**（五天制）或**6周**（六天制）带薪病假
- 病假在周期开始时**即全额分配**（非累积）——"use it or lose it"

### 3.2 前6个月特殊规则
- 受雇前6个月：每工作26天 = 1天带薪病假
- 6个月后：可使用整个周期剩余额度

### 3.3 医疗证明要求
| 缺勤天数 | 医疗证明 |
|----------|----------|
| 1-2天 | 不要求（但雇主政策可规定） |
| >2连续天 | **必须**提供医疗证明 |
| 周一或周五缺勤 | 雇主可要求医疗证明 |

### 3.4 雇主拒付条件
- 雇员未提供要求的医疗证明 → 可拒付
- 缺勤非因疾病/伤病 → 可拒付
- 雇员提供有效医疗证明 → 雇主**不得**拒付

## 4. 产假（Maternity Leave）详解

### 4.1 权益标准
- **4个月连续**（16周）产假
- **无薪**——但可申请UIF maternity benefit（UIF覆盖约38%-60%工资）
- 最早可在预产期前**4周**开始
- 产后须休至少**6周**（除非医生证明可提前恢复）

### 4.2 工作保护
- 产假期间**不得解雇**（自动不当解雇，LRA Section 187）
- 产后返回须恢复原职位或同等职位
- 怀孕/哺乳期雇员**禁止**从事危险工作

### 4.3 UIF产假津贴
- 须在产假开始前向UIF申请
- 津贴额取决于缴费历史
- 须提交UI-19（雇主出具）+ 医疗证明 + 银行确认

---

## 5. 家庭责任假（Family Responsibility Leave）详解

### 5.1 适用条件
- 受雇≥**4个月**
- 每周工作≥**4天**

### 5.2 适用情形
| 情形 | 说明 |
|------|------|
| 雇员子女出生 | — |
| 雇员子女生病 | — |
| 配偶/伴侣/父母/养父母/祖父母/子女/养子女/孙子女/兄弟姐妹死亡 | 雇主可要求合理证明 |

### 5.3 特点
- 3天/年，**不累积**——"use it or lose it"
- 终止雇佣时**不支付**未使用天数
- 雇主可要求合理证明（如死亡证明、出生证明）

---

## 6. 育儿假/收养假/代孕假（2023年BCEA修订新增）

### 6.1 育儿假（Parental Leave）
- **10天**全薪假（配偶/父亲/伴侣适用）
- 无薪——可申请UIF parental benefit
- 适用于：雇员的伴侣生育、收养<2岁儿童

### 6.2 收养假（Adoption Leave）
- **10周**假（收养<2岁儿童的一方适用）
- 无薪——可申请UIF adoption benefit
- 如双方均为雇员，仅一方可申请

### 6.3 代孕育儿假（Commissioning Parental Leave）
- **10周**假（代孕协议中的委托父母）
- 无薪——可申请UIF commissioning parental benefit

## 7. 公共假日

南非每年**12个法定公共假日**：

| 假日 | 日期 |
|------|------|
| 新年 | 1月1日 |
| 人权日 | 3月21日 |
| 耶稣受难日 | 变动 |
| 家庭日 | 变动（复活节周一） |
| 自由日 | 4月27日 |
| 劳动节 | 5月1日 |
| 青年节 | 6月16日 |
| 全国妇女节 | 8月9日 |
| 遗产日 | 9月24日 |
| 和解日 | 12月16日 |
| 圣诞节 | 12月25日 |
| 善意日 | 12月26日 |

### 公共假日工作薪酬
- 假日不上班 → 照付日工资
- 假日上班 → 正常日工资 + 工作所得（或双倍工资，如该日为正常工作日）
- 假日逢周日 → 次周一为公共假日

## 8. 休息时间

| 类型 | 标准 |
|------|------|
| 每日休息 | 连续**12小时** |
| 每周休息 | 连续**36小时**（通常含周日） |
| 用餐休息 | 工作5小时后休息**1小时**（可协议减至30分钟） |

---

## 9. 终止雇佣通知期

| 服务年限 | 法定最低通知期 |
|----------|---------------|
| ≤6个月 | **1周** |
| >6个月但<1年 | **2周** |
| ≥1年 | **4周** |

> 可支付代通知金（payment in lieu of notice）代替通知期。

---

## 10. 中资企业实操要点

1. **年假6个月规则**：不是"过期作废"，而是雇主有义务6个月内批假
2. **病假医疗证明**：>2天必须要求，周一/周五缺勤可要求——写进公司政策
3. **产假4个月无薪**：须提前告知雇员可申请UIF津贴，避免纠纷
4. **新增育儿假10天**：2023年修订案新增，须更新HR政策和薪酬系统
5. **公共假日工作**：须双倍薪酬，合同须明确
6. **终止通知期**：≥1年服务须4周通知，不可缩短
7. **休假记录**：须保存完整休假记录供DOL检查
