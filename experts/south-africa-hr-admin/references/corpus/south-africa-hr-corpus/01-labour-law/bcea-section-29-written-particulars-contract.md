# BCEA Section 29：雇佣书面条款与合同要求

> **数据来源**：BCEA Act 75 of 1997（gov.za）、CCMA/SME Labour Support、DOL Basic Guide、Conviction法律评论
> **立法**：Basic Conditions of Employment Act 75 of 1997, Section 29
> **时效提示**：BCEA条款可能修订，以DOL官网最新版本为准

---

## 一、Section 29 法定要求

### 核心义务
**雇主必须在员工开始工作时，以书面形式向员工提供以下雇佣条款。**

> 这是法定强制义务，不依赖合同是否为口头或书面。即使雇佣合同是口头的，雇主仍须提供书面条款。

### 法律形式
书面条款可以以下任一形式提供：
- 正式雇佣合同（Employment Contract）
- 雇佣要约函（Letter of Employment）
- 其他书面文件

> **建议**：双方签署文件以避免未来误解和争议。

---

## 二、必须包含的16项书面条款

### Section 29(1) 完整清单

| 序号 | 条款 | 说明 |
|------|------|------|
| (a) | **雇主全名和地址** | 法定全称 + 物理地址 |
| (b) | **员工姓名和职业**（或工作简述） | 姓名 + 职位或工作描述 |
| (c) | **工作地点** | 若多地点须说明 |
| (d) | **雇佣开始日期** | 入职日 |
| (e) | **普通工作时间和工作日** | 每日/每周工时 + 工作日 |
| (f) | **工资或工资计算方法** | 金额或计算方式 |
| (g) | **加班工资率** | 加班费率（法定1.5倍） |
| (h) | **其他现金支付** | 津贴/奖金等 |
| (i) | **实物支付及其价值** | 住房/餐饮等 |
| (j) | **薪酬支付频率** | 日/周/双周/月 |
| (k) | **薪酬扣减项** | 法定扣减（PAYE/UIF/SDL）+ 约定扣减 |
| (l) | **休假权益** | 年假/病假/产假/家庭责任假天数 |
| (m) | **终止通知期**（或固定期限终止日） | 按Section 37法定通知期 |
| (n) | **适用的Council或Sectoral Determination** | Bargaining Council/SD覆盖说明 |
| (o) | **前雇主工龄累计** | 若适用（如转让/继承） |
| (p) | **构成合同的其他文件清单** | 手册/政策/行为准则等 |

## 三、适用范围与豁免

### 完全适用
- 所有雇主和员工
- 包括永久、固定期限、临时、兼职员工

### 部分豁免

#### 每月工作不足24小时的员工
- Section 29整体不适用（Chapter 4不适用）
- 但仍受BCEA其他章节保护

#### 雇用少于5名员工的雇主
- Section 29(1)(n)、(o)、(p)不适用
- 即：不须说明Council/SD覆盖、前雇主工龄、其他文件清单
- 其他13项仍须提供

> **注**：家政工人原被排除，现已纳入Section 29保护（但(n)(o)(p)因少有5+家政工人而实际很少适用）

#### 收入超过BCEA门槛的员工（2025年4月起R261,748.45/年）
- Section 29仍适用（书面条款要求不因收入豁免）
- 但工时/加班等BCEA条款部分不适用

## 四、变更与更新

### Section 29(2) — 变更要求
- 任何条款变更 → **书面条款须更新反映变更**
- **更新后的文件副本须交付员工**

### Section 29(3) — 语言理解
- 若员工无法理解书面条款 → **雇主须以员工理解的语言和方式解释**
- 南非有11种官方语言，须考虑员工母语

### Section 29(4) — 保存期限
- 书面条款须由雇主保存至**雇佣终止后3年**

## 五、BCEA其他相关条款

### Section 30 — 告知员工权利
- 雇主须在工作场所**显眼位置张贴**员工权利声明
- 须以工作场所使用的**官方语言**展示

### Section 31 — 记录保存
- 雇主须保存记录：员工姓名/职业、工作时间、薪酬、未满18岁员工出生日期
- 保存期限：**最后记录之日起3年**

### Section 32 — 薪酬支付
- 以南非货币支付
- 日/周/双周/月频次
- 现金/支票/银行转账

### Section 33 — 工资条
- 每次支付薪酬时须提供工资条
- 须包含：雇主名称、员工姓名、薪酬期间、薪酬金额、扣减项、实发金额

### Section 34 — 薪酬扣减
- 仅在法定授权或员工书面同意下可扣减
- 扣减金额不得超过法定限额

## 六、合同条款的法定最低 vs 最佳实践

### BCEA法定最低（Section 29要求）
16项书面条款——这是法律底线，不满足即违法。

### 建议补充条款（超出法定最低，防止争议）

| 建议条款 | 重要性 |
|----------|--------|
| **试用期条款** | 期限、评估标准、延长条件 |
| **固定期限合同理由** | LRA Section 198B要求，防止不当解雇 |
| **保密义务** | 保护商业秘密 |
| **竞业禁止** | 须合理限制（时间/地域/行业），仅在离职后有效 |
| **知识产权归属** | 明确职务作品归属 |
| **远程工作安排** | 工时/设备/数据安全 |
| **绩效标准** | KPI/评估方式 |
| **工作工具** | 笔记本电脑/手机/车辆/数据补贴 |
| **佣金结构** | 计算方法/支付时间/追回条款 |
| **加班安排** | 同意/费率/法定上限 |
| **退休年龄** | 明确退休年龄 |
| **纪律/申诉程序** | 引用公司纪律政策 |

### 2025-2026年最新判例提醒

#### Dladla v Motor Industries Bargaining Council (2026, LAC)
- 若工作场所行为创造合理预期固定期限合同将被续签 → 仅依赖合同到期日不保护雇主免受不当解雇索赔

#### Backsports (Pty) Ltd (2026, LAC)
- 被解雇员工仍受有效竞业禁止约束——即使因不当行为被解雇

#### Lucchini SA v CCMA (2025, LC)
- 合同中禁止寻求替代就业的条款**违反公共政策，不可执行**
- 不可因员工寻求新工作（含与竞争对手）解雇

## 七、劳动监察与执法

### 劳动监察员权力
- **无须搜查令或事先通知**即可进入任何工作场所（私人住宅除外）
- 在合理时间进入
- 可就任何雇佣法事项提问并要求披露信息
- 可检查书面条款和记录

### 不合规后果
- 未提供书面条款 → 违反BCEA
- 劳动监察员可发出合规令（Compliance Order）
- 不遵守合规令 → 可被起诉至劳动法院
- 雇主可能面临罚款

## 八、中资企业合同合规清单

### ✅ 入职前检查
- [ ] 准备包含16项法定条款的书面合同
- [ ] 确定合同类型（永久/固定期限/试用期）
- [ ] 明确工资率不低于NMW/PSIRA/Bargaining Council费率
- [ ] 包含BCEA Section 37法定通知期
- [ ] 列明所有法定扣减项（PAYE/UIF/SDL）

### ✅ 入职时
- [ ] 员工入职第一天提供书面条款
- [ ] 双方签署合同
- [ ] 以员工理解的语言解释条款
- [ ] 员工保留一份签署副本

### ✅ 持续合规
- [ ] 任何条款变更后更新书面文件并交付员工
- [ ] 保存书面条款至雇佣终止后3年
- [ ] 工作场所张贴员工权利声明
- [ ] 每次支付薪酬提供工资条
- [ ] 保存工时/薪酬记录3年

### ✅ 合同质量提升
- [ ] 试用期条款（期限/评估标准/延长条件）
- [ ] 固定期限合同理由（Section 198B合规）
- [ ] 保密义务与竞业禁止（合理限制）
- [ ] 纪律/申诉程序引用
- [ ] 绩效标准明确
- [ ] 退休年龄明确

### ⚠️ 常见错误
- ❌ 从互联网复制粘贴合同（不反映实际岗位）
- ❌ 合同与公司政策矛盾
- ❌ 合同与BCEA矛盾（如低于法定标准）
- ❌ 合同不反映员工实际职责
- ❌ 合同从未更新
- ❌ 依赖"常识"而非书面条款
- ❌ 合同中含禁止寻求替代就业条款（不可执行）
