# CIPC 公司注册与 SARS 税务登记流程

> 来源：sikatrix.com / attorneys-sa.co.za / lekkerlaw.co.za / cipc.co.za / sczil.com（中文）
> 核实建议：以 cipc.co.za 与 BizPortal 最新流程为准

## 一、公司类型选择
| 类型 | 说明 |
|---|---|
| **私人公司 Pty Ltd** | 最常见，独立法人，有限责任，≥1董事+≥1股东（可同一人），外资企业首选（占83%） |
| 独资 Sole Proprietorship | 非独立法人，无限责任，无须CIPC注册 |
| 合伙 Partnership | 非独立法人，无限连带责任，建议书面协议 |
| 非营利公司 NPC | 慈善/公益，利润不得分配 |
| 个人责任公司 Inc. | 律师等专业人士用 |
| 外部公司 External Company | 外国公司分支机构，母公司直接担责 |

## 二、Pty Ltd 注册流程（CIPC）
### 步骤1：名称预核准（可选但推荐）
- 通过 CIPC e-Services（eservices.cipc.co.za）或 BizPortal（bizportal.gov.za）提交 **CoR 9.1**，最多4个备选名。
- 费用 **R50**，处理5–7个工作日，获 CoR 9.4 确认，有效期6个月。
- 名称要求：以"(Pty) Ltd"结尾，不得与现有公司重复/混淆，不得含受限词（Bank/University/National/SA 等须特批）。
- 也可不预核准，CIPC 直接以注册号作为公司名（如 2024/123456/07）。

### 步骤2：准备章程 MOI（Memorandum of Incorporation）
- CIPC 提供标准 MOI（**CoR 15.1A**），多数中小企业够用。
- 可定制（股东权利、董事权限、决策门槛等），定制版须经 CIPC 审核。
- MOI 是公司"宪法"，具法律约束力。

### 步骤3：在线注册
- 登录 CIPC/BizPortal，提交 **CoR 14.1** 注册申请。
- 所需信息：公司名（或同时申请）、股份类别与数量、每个创办人（ID/联系方式）、南非注册办公地址。
- 注册费 **R175**（标准Pty Ltd），通过 CIPC 门户支付。
- 处理时间：在线1–3个工作日（资料正确），实际常5–10个工作日。
- 2024年新规：外籍董事可通过电子董事身份验证（e-DIV）视频公证完成认证。

### 步骤4：领取注册文件
- **CoR 14.3 注册证书**（含公司注册号）+ MOI。
- 外部公司注册：2025年9月29日起 CoR 20.1 全程电子化，注册费 R400。

## 三、注册后合规（60天内）
1. **开立企业银行账户**（公司名）：FICA 要求 KYC 文件、董事决议、注册文件。南非四大行（Standard Bank/FirstRand/FNB/ABSA）要求董事现场面签；持股超25%须披露最终受益所有人。
2. **SARS 税务注册**：CIPC 与 SARS 共享数据，但仍须完成 IT77C 注册或经 eFiling 确认。获取所得税参考号。
3. **税号 Clear Certificate**：税务档案激活后申请。
4. **PAYE 注册**（SARS）：拟发工资则须注册。
5. **VAT 注册**：年应税营业额超 **R1,000,000** 强制注册。
6. **UIF/COIDA 注册**：见社保板块。BizPortal 可一步完成 CIPC+SARS+UIF+COIDA 注册。

## 四、年度合规
- **CIPC 年度申报**：公司成立周年日后 **30个工作日内** 提交，费用按营业额 R100–R450。
- 连续2年不申报将被**注销**，恢复昂贵耗时。
- 会计：所有公司须按 IFRS 记账；公共利益实体（上市公司等）强制审计，其他可选审计或审阅。
- 报税：会计年度结束后6个月内完成报税。

## 五、外籍企业特别要点（中文实务）
- 外商独资企业须在贸工部（DTIC）备案特定行业经营许可。
- 外籍董事须公证护照文件；母公司营业执照须海牙认证。
- 注册地址须为实际地址（虚拟地址须持特许牌照）。
- 建议预留约 R100,000 初始存款激活银行账户。
- 2024年7月起所有企业须启用电子发票系统。

## 六、相关机构
- **CIPC**（公司与知识产权委员会）：cipc.co.za，公司注册、商标、专利。
- **SARS**（南非税务局）：sars.gov.za，所得税/VAT/PAYE/UIF/SDL。
- **DTIC**（贸易工业竞争部）：行业许可、投资促进。
- **BizPortal**：bizportal.gov.za，一站式注册。

⚠️ 注册费、处理时间等可能随政策调整，引用前核对 cipc.co.za 最新公告。
