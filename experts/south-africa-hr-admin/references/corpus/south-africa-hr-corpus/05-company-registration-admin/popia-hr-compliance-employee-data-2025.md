# POPIA HR合规 — 员工个人数据处理（2025年修订）

> **来源**：POPIA Act 4 of 2013; 2025年4月POPIA法规修订; Information Regulator; Oaklaw; Securepath Consulting; Infoserv; Baker McKenzie; Legal Dynamix
> **最后更新**：2025年4月（法规修订已生效）

---

## 一、POPIA概述与2025年修订

### POPIA基本信息
- **全称**：Protection of Personal Information Act
- **全面生效**：2021年7月1日
- **监管机构**：Information Regulator（信息监管局）
- **类似法规**：欧盟GDPR

### ⚠️ 2025年4月法规修订（即时生效）

| 修订项 | 旧规 | **新规（2025年4月）** |
|--------|------|---------------------|
| 异议渠道 | 须用Form 1书面提交 | 可通过手递/传真/邮件/SMS/WhatsApp提交，**免费** |
| 更正/删除请求 | 须用Form 2书面提交 | 同上多元化渠道，**免费** |
| 直接营销同意 | 须用Form 4书面同意 | 多渠道同意，电话同意须录音保存 |
| 信息官PAIA手册 | 须编制PAIA手册 | **取消PAIA手册义务**，但须维持合规框架 |
| 行政罚款 | 一次性缴纳 | **可分期缴纳** |
| CIPC合规标记 | 无 | **CIPC公开标记未注册信息官的企业** |

## 二、HR数据处理的特殊性

### 员工数据属于"个人信息"
HR处理的员工数据包括：
- 姓名、身份证号、联系方式
- 银行账户信息
- 健康记录（病假、体检）
- 就业历史、薪酬记录
- 绩效评估、纪律记录
- 生物识别数据（指纹/面部识别门禁）

### 特殊个人信息（需更严格保护）
- 种族/民族
- 宗教信仰
- 健康信息
- 生物识别数据
- 犯罪记录

> HR处理的很多数据属于"特殊个人信息"，须遵守Section 26-32的额外保护要求。

## 三、HR合规八大条件

### 1. 问责制（Accountability）
- 须指定**信息官**（Information Officer）
- 私人企业默认CEO为信息官，除非另行指定
- 信息官须在Information Regulator在线注册
- CIPC现已公开标记未注册信息官的企业

### 2. 处理限制（Processing Limitation）
- 须有合法处理依据
- 员工数据处理的合法依据通常为：**合同必要性**（ employment contract）
- 不一定需要员工同意（但特殊信息须获同意）
- 须最少化收集——仅收集必要信息

### 3. 目的明确（Purpose Specification）
- 须为特定、明确目的收集数据
- 须告知员工数据收集目的
- 不得超出原定目的使用数据
- 须在不再需要时删除

### 4. 进一步处理限制
- 额外使用须与原始目的兼容
- 如将员工数据用于新目的 → 须获员工同意

### 5. 信息质量
- 须确保数据准确、完整、最新
- 须定期更新员工信息
- 须提供更正机制

### 6. 公开性（Openness）
- 须发布**隐私政策**
- 须以简明语言编写
- 须说明数据收集、处理目的、数据主体权利

### 7. 安全保障（Security Safeguards）
- 须实施技术和管理措施
- 包括：访问控制、加密、备份、多因素认证
- 须有数据泄露应对计划
- **数据泄露须72小时内报告Information Regulator**

### 8. 数据主体参与
- 员工有权：
  - 访问自己的数据
  - 要求更正
  - 要求删除
  - 反对处理
- 须建立数据主体请求处理流程

## 四、HR专属合规要点

### 1. 招聘阶段
- 求职者简历须获得同意后处理
-  unsuccessful candidates的简历须按政策删除
- 背景调查须获书面同意
- 不得收集与岗位无关的特殊个人信息

### 2. 雇佣期间
- 员工档案须安全存储
- 薪酬信息须限制访问
- 医疗信息须与一般人事档案**分开存储**
- 绩效和纪律记录须准确记录
- 监控（邮件/摄像头）须告知员工

### 3. 离职后
- 离职员工数据须按保留政策管理
- 不得无故保留离职员工数据
- 参考信息（reference check）须获前员工同意
- 须遵守数据保留最短期限要求

### 4. 跨境数据传输
- 外派人员数据传至海外母公司 → 须确保接收方有充分保护
- 南非母公司与中国总部之间的数据传输须有数据传输协议
- 须评估接收国数据保护水平

## 五、信息官（Information Officer）

### 指定与注册
- Section 55要求每个企业指定信息官
- 须在Information Regulator在线注册（inforegulator.org.za）
- 注册免费，约30-60分钟完成
- 须提供公司注册号、信息官ID号、联系方式

### 信息官职责
- 推动内部POPIA合规
- 处理数据主体请求
- 配合Information Regulator调查
- 制定和实施合规框架
- 管理数据泄露应对

### 2025年修订变化
- **取消PAIA手册编制义务**（减轻负担）
- 仍须维持合规框架的制定、实施、监控和持续改进

## 六、数据泄露应对

### 法定义务
- **72小时内**向Information Regulator报告
- 须通知受影响的数据主体
- 须记录泄露详情和应对措施

### HR数据泄露场景
- 员工薪酬信息被泄露
- 纪律记录被未授权人员访问
- 医疗信息被不当披露
- 生物识别数据被窃取

### 应对步骤
1. 发现泄露 → 立即评估影响范围
2. 72小时内报告Information Regulator
3. 通知受影响员工
4. 采取补救措施
5. 记录全文并审查

## 七、处罚与执法

### 行政罚款
- 最高**R1,000万**每次违规
- 2025年起可分期缴纳

### 刑事处罚
- 严重违规可处**最高10年监禁**（Section 107）
- 适用于董事和管理人员

### 其他后果
- 执法通知（Enforcement Notice）
- 合规命令（Compliance Order）
- 公开调查
- 员工/前员工的民事赔偿索赔
- CIPC公开标记 → 影响商业信誉

### 2024-2025年执法趋势
- Information Regulator执法力度持续加强
- 多家企业已收到执法通知
- 数据泄露报告数量显著增加

## 八、对中资企业的实务建议

### 1. 立即行动清单
- [ ] 指定信息官并向Information Regulator注册
- [ ] 进行员工数据审计（收集了什么、存在哪里、谁有访问权）
- [ ] 制定隐私政策并发布
- [ ] 制定员工数据处理政策
- [ ] 更新员工合同加入数据处理条款
- [ ] 制定数据泄露应对计划
- [ ] 实施技术安全措施（加密、访问控制、多因素认证）
- [ ] 培训全体员工POPIA基础知识
- [ ] 建立数据主体请求处理流程
- [ ] 审计第三方数据处理者（HR软件、云服务商、会计等）

### 2. 中资企业特殊风险
- **跨境数据传输**：南非子公司员工数据传至中国总部 → 须有数据传输协议
- **集中式HR系统**：若使用中国总部的HR系统 → 须评估POPIA合规性
- **语言障碍**：隐私政策须用员工能理解的语言（英语/当地语言）
- **监控文化**：中国企业的监控习惯可能与POPIA冲突 → 须告知员工并获得同意

### 3. 常见误区
- ❌ "员工数据不需要同意" → 特殊个人信息仍需同意
- ❌ "信息官只是挂名" → 须有实际履职能力
- ❌ "离职后可永久保留员工数据" → 须按保留政策定期删除
- ❌ "数据泄露不影响HR" → HR数据是最敏感的数据之一
- ❌ "中国总部的系统不受POPIA管" → 处理南非员工数据即适用

### 4. 与其他法规的协同
| 法规 | 关系 |
|------|------|
| BCEA | 员工记录保留要求 |
| EEA | 就业公平数据收集（种族/性别）→ 属特殊信息须获同意 |
| COIDA | 工伤记录（健康信息）→ 须安全存储 |
| POPIA | 统筹所有员工个人数据处理合规 |

> ⚠️ POPIA执法在2025年持续加强，CIPC公开标记未注册信息官的企业。中资企业须将POPIA合规作为HR管理的核心要素，不可视为"可选项"。
