# FICA 合规与企业银行开户

> 来源：Financial Intelligence Centre Act 38 of 2001、Sumsub、Vutivi Business、Smile ID、iTransact
> 最后更新：2025年（含CIPC受益所有权新规）
> 用途：南非人力行政专家语料库 — 公司注册与行政板块

---

## 1. FICA法律框架

### 1.1 什么是FICA
**《金融情报中心法》** (Financial Intelligence Centre Act, No. 38 of 2001, FICA) 是南非反洗钱(AML)和反恐融资(CFT)的核心立法。

### 1.2 监管机构
- **Financial Intelligence Centre (FIC)** — 金融情报中心
- **South African Reserve Bank (SARB)** — 南非储备银行（监管银行合规）
- **Financial Sector Conduct Authority (FSCA)** — 金融行业行为管理局

### 1.3 适用机构
FICA适用于以下"问责机构" (Accountable Institutions)：
- 银行
- 赌场
- 货币兑换公司
- 经纪人
- 律师
- 保险公司
- 金融顾问
- 房地产代理
- 投资公司
- 贵金属交易商
- 支付服务提供商

## 2. FICA合规要求

### 2.1 核心义务

| 义务 | 说明 |
|------|------|
| **MLRO任命** | 任命反洗钱报告官(Money Laundering Reporting Officer) |
| **客户尽职调查(CDD)** | 识别和验证客户身份 |
| **风险评估** | 对客户进行风险评级 |
| **简化尽职调查(SDD)** | 低风险客户适用简化程序 |
| **强化尽职调查(EDD)** | 高风险客户适用增强程序 |
| **制裁/PEP筛查** | 筛查制裁名单和政治公众人物 |
| **交易监控** | 持续监控客户交易行为 |
| **记录保存** | 保存客户信息和交易记录 |
| **可疑交易报告(STR)** | 15天内提交可疑交易报告 |
| **现金阈值报告(CTR)** | 交易超R49,999.99须提交 |
| **员工培训** | 定期AML/CFT培训 |

### 2.2 处罚
- 未提交STR/CTR：罚金最高 **R1亿** 或**15年监禁**
- 未能保持合规体系：重大罚款 + 牌照风险

## 3. 企业银行开户FICA要求

### 3.1 南非注册公司（Pty Ltd）

| 所需文件 | 说明 |
|----------|------|
| **注册证书** (Certificate of Incorporation, CoR 14.3) | CIPC签发 |
| **注册地址通知** (Notification of Registered Address, CoR 21) | — |
| **名称变更证书**（如适用） | CoR 15.1C |
| **每位董事的身份证/护照** | 认证副本 |
| **授权签字人决议** (Resolution) | 公司信头纸，注明授权签字人 |
| **每位授权签字人的身份证/护照** | 认证副本 |
| **最新股东登记册** | 反映最终受益所有权/控制结构 |
| **Annexure A** | 新业务申请表附件（所有董事和签字人） |
| **公司地址证明** | 水电费账单/租赁协议（3个月内） |

### 3.2 外国注册公司

| 所需文件 | 说明 |
|----------|------|
| 公司注册文件（英文） | 注册国官方文件 |
| 董事/成员名单 | — |
| 每位董事身份证/护照 | — |
| 授权签字人决议 | 公司信头纸 |
| 每位签字人身份证/护照 | — |
| 最新股东登记册 | 反映最终受益所有权 |
| **持股≥5%的自然人**身份证/护照 | 最终受益所有权识别 |
| Annexure A | 所有董事和签字人 |

### 3.3 个体工商户（Sole Proprietor）
- 身份证副本
- 居住证明
- 银行确认信或银行对账单（反映姓名和账号）

## 4. CIPC受益所有权新规（2024年4月起）

### 4.1 重大变更
- **2024年4月1日**起，CIPC系统**不允许**未完成受益所有权信息的企业提交年度申报
- 银行须验证企业的**最终受益所有人** (Ultimate Beneficial Owner, UBO)

### 4.2 受益所有权阈值
- 目前：持股**≥25%** 须披露
- FIC新指引建议降低至**≥5%**
- 银行须验证UBO的身份信息

### 4.3 不合规后果
- CIPC **不予受理年度申报**
- 企业被视为**不合规**
- 银行**拒绝开户**或冻结已有账户
- CIPC可：**注销注册** + 罚款 + 执行通知

## 5. 中资企业银行开户实操

### 5.1 推荐开户银行

| 银行 | 特点 |
|------|------|
| **Standard Bank** | 南非最大银行，中资企业常用 |
| **FNB** (First National Bank) | 数字化程度高，在线银行体验好 |
| **ABSA** | 巴克莱背景，国际业务强 |
| **Nedbank** | 企业银行服务全面 |
| **Investec** | 私人银行/高净值客户 |

### 5.2 开户流程

```
第1步：准备FICA文件（2-4周）
  → 公司注册证书 + MOI + 董事ID + 决议 + 股东登记册 + UBO信息
  → 中国母公司文件须公证+认证+英文翻译

第2步：提交银行开户申请（1-2周审核）
  → 预约银行客户经理
  → 提交全套FICA文件
  → 银行进行KYC/AML审查

第3步：账户激活（1-2周）
  → 审核通过后激活账户
  → 获取账号/网银/银行卡
  → 首笔入金激活

总周期：4-8周（文件齐全情况下）
```

### 5.3 常见障碍与对策

| 障碍 | 对策 |
|------|------|
| 中国母公司文件未公证认证 | 在中国做公证→外交部认证→南非驻华使馆认证 |
| UBO信息不完整 | 持股≥25%（或5%）的自然人须全部披露 |
| CIPC不合规 | 先完成CIPC年度申报+受益所有权信息 |
| 董事不在南非 | 须提供认证护照副本+地址证明 |
| 地址证明不足 | 水电费账单/租赁协议/警察局宣誓书 |
| FICA合规官未任命 | 须任命MLRO（可为内部员工） |

### 5.4 外汇管制提示
- 南非外汇管制仍在部分适用（虽已大幅放松）
- 大额跨境汇款须通过授权交易商(Authorised Dealer)
- 中国母公司注资须走正规渠道（银行入资+CIPC股东登记）

## 6. FICA与POPIA的交叉合规

| FICA要求 | POPIA影响 |
|----------|-----------|
| 保存客户身份信息5年 | 须同时遵守POPIA数据最小化原则 |
| 向FIC提交STR/CTR | 须确保个人信息处理合法 |
| 客户尽职调查 | 须告知客户数据处理目的 |
| 员工AML培训 | 须包含POPIA意识培训 |
