## 二、"收入"定义

收入 = **扣除前毛收入**（即所得税、养老金、医疗保险等扣除之前的金额），但**不含**雇主为雇员缴纳的对应款项。

**不计入收入的项目**：
- 差旅补贴
- 成就奖
- 加班费

## 三、对 BCEA 保护的影响

### 收入**超过**门槛的员工 — 被排除的 BCEA 条款

| BCEA 条款 | 内容 |
|---------|------|
| 第9条 | 普通工作时间 |
| 第10条 | 加班 |
| 第11条 | 压缩工作周 |
| 第12条 | 工时平均化 |
| 第14条 | 用餐休息 |
| 第15条 | 每日和每周休息时间 |
| 第16条 | 周日工作薪酬 |
| 第17(2)条 | 夜班交通和夜班津贴 |
| 第18(3)条 | 公共假日（非通常工作日）薪酬 |

超门槛员工上述条款**无法定强制权**，条件可由劳资双方协商（可能低于法定标准）。

### 收入**低于**门槛的员工 — 享有 BCEA 全部保护 + LRA 额外保护

## 四、对 LRA 非标准雇佣安排的影响（第 198A-D 条）

收入低于门槛的员工被视为"弱势员工"（vulnerable employees），享有 LRA 额外保护：

### 第198A条 — 劳务派遣/TES（劳动中介）
- **3个月推定条款（deeming provision）**：若 TES 员工被派往同一客户**超过3个月**，且非替代临时缺勤员工，该员工**被视为客户公司的雇员**
- 宪法法院在 Assign Services v NUMSA 案中裁定：3个月后客户公司成为**唯一雇主**（非双重雇佣）
- 被推定员工不得受到比客户公司同类员工更差的待遇

### 第198B条 — 固定期限合同
- **3个月规则**：固定期限合同不得超过3个月（含续签），除非工作性质有有限/确定期限或有正当理由
- 超过3个月且无正当理由 → **视为无限期雇佣**（deemed indefinite）
- **正当理由**包括：
  - 替代临时缺勤员工
  - 临时工作量增加（预期不超12个月）
  - 学生/毕业生实习
  - 有限期限项目
  - 季节性工作
  - 公共就业计划
- **24个月后**终止可能需支付遣散费
- **不适用于**：超门槛员工；雇员少于10人的雇主；运营不足2年且雇员少于50人的雇主

### 第198C条 — 兼职员工
- 低于门槛的兼职员工不得比同等全职员工受到更差待遇
- 须享有同等的培训和技能发展机会

### 第198D条 — 争议程序
- CCMA 可作出宣告性裁决（认定身份、平等待遇）
- 但 CCMA **无权**裁定金钱赔偿（Bata SA v SACTWU 案，劳工上诉法院裁定）
- 金钱救济须通过 LRA 第191条、BCEA 或合同义务途径寻求
