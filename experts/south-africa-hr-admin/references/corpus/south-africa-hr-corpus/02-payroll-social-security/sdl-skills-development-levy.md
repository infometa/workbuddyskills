# SDL 技能发展税 (Skills Development Levy)

> 来源：South African Revenue Service (SARS)、Skills Development Levies Act 9 of 1999、各SETA官方指南
> 最后更新：2024年（2024/25税年）
> 用途：南非人力行政专家语料库 — 薪酬社保板块

---

## 1. 概述

**技能发展税（SDL）** 依据《技能发展法》（Skills Development Levies Act, No. 9 of 1999）征收，旨在资助南非国家技能发展战略（NSDS），通过各SETA（Sector Education and Training Authorities）分配培训和技能发展资源。

---

## 2. 缴费义务判定

### 2.1 强制注册条件
雇主满足以下**任一条件**即须注册缴纳SDL：
- 年度预计应付薪酬（total remuneration）**超过 R500,000**
- 已注册PAYE并有雇员

### 2.2 豁免情形
以下雇主**免缴SDL**：
- 年度应付薪酬 ≤ R500,000
- 纯粹由外交使团/国际组织雇佣
- 雇主为公立学校、公共福利组织（PBO）、市政当局（部分豁免）
- 雇员全部为家政工人（domestic worker）且薪酬低于门槛（2024年起家政工人纳入UIF但SDL仍按雇主总薪酬判定）

> **注意**：即使雇主薪酬低于R500,000，若已注册PAYE，部分SETA仍建议自愿注册以获取培训补助资格。

---

## 3. 缴费标准

| 项目 | 标准 |
|------|------|
| **缴费比例** | 月薪总额的 **1%** |
| **缴费方** | **雇主全额承担**（非雇员分摊） |
| **计算基数** | 总薪酬（total remuneration）= 基本工资 + 津贴 + 奖金 + 佣金 + 其他现金报酬 |
| **免征项** | 雇主缴纳的退休金/医疗援助（employer contributions to pension/medical aid）不计入SDL基数 |
| **月薪上限** | 无上限（与UIF不同，SDL不设薪酬上限） |

### 计算示例
```
月薪总额 = R30,000（基本工资R25,000 + 交通津贴R3,000 + 奖金R2,000）
SDL = R30,000 × 1% = R300/月
```

---

## 4. 注册与申报流程

### 4.1 注册步骤
1. 向SARS提交 **SDL101** 注册表（可与PAYE/UIF同步注册）
2. 获取SDL号（通常与PAYE注册号关联）
3. 指定所属SETA（按行业分类）：
   - **SERVICES SETA** — 服务业（含多数中资企业）
   - **CHIETA** — 化学工业
   - **MERSETA** — 制造工程
   - **MICT SETA** — 信息技术/通信
   - **BANKSETA** — 银行金融
   - **TETA** — 运输物流
   - **CETA** — 建筑业
   - **AgriSETA** — 农业
   - **ETDP SETA** — 教育培训
   - **HWSETA** — 健康卫生
   - 完整SETA列表：[SETA列表](https://www.dhet.gov.za/)

### 4.2 申报与缴纳
- **频次**：按月申报缴纳
- **截止日**：每月 **15日** 前缴纳上月SDL（与PAYE/UIF同期）
- **申报方式**：
  - SARS eFiling 在线申报（EMP201表）
  - 或通过银行电子转账（EFT）至SARS指定账户
- **逾期处罚**：利息按法定利率计算 + 可能面临10%罚金

## 5. SETA补助申请（Grants）

缴纳SDL的雇主可向所属SETA申请培训补助，分两类：

### 5.1 强制性补助（Mandatory Grant）
| 项目 | 标准 |
|------|------|
| **返还比例** | 缴纳SDL的 **20%** |
| **申请条件** | 按时提交 **WSP**（Workplace Skills Plan，年度工作技能计划）和 **ATR**（Annual Training Report，年度培训报告）|
| **提交截止** | 每年 **4月30日** |
| **审批周期** | SETA审核后分季度拨付 |

### 5.2 自主性补助（Discretionary Grant）
| 项目 | 标准 |
|------|------|
| **返还比例** | 最高 **49.5%**（合计强制+自主可达69.5%） |
| **申请条件** | SETA发布的优先技能项目、实习项目（learnership）、学徒项目（apprenticeship）、bursary等 |
| **竞争性** | 非自动返还，需提交项目提案由SETA审批 |

### 5.3 补助实际返还率
- 实际操作中，仅提交WSP/ATR的雇主通常可回收 **20%**（Mandatory Grant）
- 积极申请Discretionary Grant的雇主可回收 **30%-50%**
- 剩余SDL资金分配：SETA行政费10% + NSDS国家技能基金20% + QCTO质量保障0.5%

---

## 6. WSP与ATR核心内容

### 6.1 WSP（年度工作技能计划）包含：
1. 雇主与雇员信息
2. 技能审计结果（skills audit）
3. 优先培训需求
4. 年度培训计划（含预算）
5. 职业发展路径规划
6. 就业公平（EE）相关培训需求

### 6.2 ATR（年度培训报告）包含：
1. 上年度实际完成的培训记录
2. 培训支出明细
3. 培训效果评估
4. WSP执行情况对照

> **合规要点**：WSP/ATR须由雇主与**工作场所技能委员会（Workplace Skills Forum/Committee）**共同制定，该委员会须包含雇员代表，体现协商原则。

---

## 7. 不合规后果

| 违规行为 | 后果 |
|----------|------|
| 未注册SDL | SARS追缴欠款 + 利息 + 罚款（最高10%） |
| 逾期缴纳 | 法定利息 + 滞纳金 |
| 未提交WSP/ATR | 丧失Mandatory Grant资格（20%返还） |
| 虚假申报 | SETA追回已发放补助 + 黑名单 |
| 未指定SETA | SDL仍须缴纳但无法申请补助 |

---

## 8. 与B-BBEE的联动

SDL缴费及WSP/ATR提交直接影响 **B-BBEE技能发展要素（Skills Development）** 评分：
- B-BBEE技能发展要素权重：**20分**（QSE）/ **25分**（Generic）
- WSP/ATR合规是技能发展要素得分的基础前提
- 实际培训支出须达到薪酬总额的 **3%-6%**（视企业规模与等级目标）方可获得满分
- Learnership吸收残障人士/黑人可获额外加分
