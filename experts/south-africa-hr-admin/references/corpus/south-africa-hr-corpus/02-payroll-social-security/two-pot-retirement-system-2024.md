# 两罐退休系统（Two-Pot Retirement System）详解

> 最后更新：2026-07-27 | 数据来源：Revenue Laws Amendment Bill 2023、SARS、Sanlam、National Fund
> ⚠️ 系统已于2024年9月1日生效，规则可能微调

---

## 一、改革背景

### 立法历程
- **Revenue Laws Amendment Bill 2023** + **Pension Laws Amendment Bill**
- 总统签署成法
- **2024年9月1日**：正式实施
- 南非一代人以来最重要的退休金制度改革

### 改革目的
1. **允许紧急提取款**：无需辞职即可访问部分退休金
2. **强制保留**：大部分退休金锁定至退休，防止退休前提取
3. **改善退休保障**：减少"辞职提款"的税务低效

---

## 二、三罐结构

### 2024年9月1日起，所有新缴费分为三罐：

```
┌─────────────────────────────────────────────┐
│              退休金基金账户                   │
├──────────┬──────────┬───────────────────────┤
│ Vested   │ Savings  │ Retirement            │
│ Pot      │ Pot      │ Pot                   │
│ (既得罐) │ (储蓄罐) │ (退休罐)              │
├──────────┼──────────┼───────────────────────┤
│2024.9.1前│ 新缴费   │ 新缴费                │
│的所有缴费│ 的1/3    │ 的2/3                 │
│+投资收益 │          │                       │
├──────────┼──────────┼───────────────────────┤
│ 旧规则   │每年可提1次│退休时才能提取         │
│保留      │(边际税率)│(须买年金)             │
└──────────┴──────────┴───────────────────────┘
```

### 各罐详解

#### 1. Vested Pot（既得罐）
- **内容**：2024年8月31日前的所有缴费+投资收益
- **规则**：适用旧规则（辞职时可提取，使用SARS提款税表）
- **保护**：成员既有权利受保护
- **种子资本**：2024年9月1日，将既得罐的10%（上限R30,000）转入储蓄罐

#### 2. Savings Pot（储蓄罐）
- **资金来源**：新缴费的1/3 + 种子资本
- **提取规则**：
  - 每个税务年度可提取**1次**
  - 最低提取额：**R2,000**
  - 须余额≥R2,500才能提取
  - **按边际税率征税**（无免税额）
- **用途**：紧急财务需求时提供"安全阀"

#### 3. Retirement Pot（退休罐）
- **资金来源**：新缴费的2/3
- **提取规则**：
  - **退休前不可提取**
  - 退休时如余额>R165,000，**须购买年金**（annuity）
  - 如余额≤R165,000，可一次性提取
- **税务优惠**：
  - 工作期间免税增长
  - 退休时仅年金收入按较低税率征税
  - 一次性提取适用退休Lump Sum税表（R550,000免税）

---

## 三、种子资本（Seed Capital）

### 规则
- **2024年9月1日**：自动将既得罐的10%转入储蓄罐
- **上限**：R30,000
- **可立即提取**（须满足R2,000最低额）

### 提取条件
- 既得罐余额须≥R20,000（才能有R2,000种子资本可提）
- 须有税号（SARS tax number）
- 须无SARS欠税（如有，从提取额中扣除）

---

## 四、税务处理对比

### 三种提取方式税务对比

| 提取类型 | 税表 | 免税额 | 税率 |
|---|---|---|---|
| **储蓄罐提取** | 边际税率 | **无免税** | 按个人边际税率 |
| **既得罐提取**（辞职时） | 退休基金提款税表 | R27,500 | 18%起累进 |
| **退休时Lump Sum** | 退休Lump Sum税表 | **R550,000** | 更优惠 |

### 储蓄罐提取税务示例

```
员工年收入 R600,000
储蓄罐提取 R30,000
→ 边际税率约31%
→ 税款 R9,300
→ 实收 R20,700
```

### 既得罐提款税表（辞职时）

| 提款金额 | 税率 |
|---|---|
| R0 - R27,500 | 0%（免税） |
| R27,501 - R700,000 | 18% |
| R700,001 - R1,050,000 | 27% |
| R1,050,001+ | 36% |

### 退休Lump Sum税表

| 提款金额 | 税率 |
|---|---|
| R0 - R550,000 | 0%（免税） |
| R550,001 - R2,475,000 | 18% |
| R2,475,001 - R5,250,000 | 27% |
| R5,250,001+ | 36% |

## 五、55岁以上特殊规则

### 适用条件
- **2021年3月1日时年满55岁**的公积金/保全公积金成员
- **不自动纳入**两罐系统

### 选择权
- **可选择加入**（opt-in）
- **截止日期**：2025年8月31日
- 一旦加入**不可退出**

### 不加入的后果
- 账户继续按旧规则运营
- 不受两罐系统影响

## 六、对雇主的影响

### 1. 工资系统更新
- 须更新工资系统支持两罐分配
- 新缴费自动1/3储蓄罐 + 2/3退休罐

### 2. 员工沟通
- 须向员工解释新系统
- 提供退休金结单供员工查看
- 提醒税务影响

### 3. 退休金基金管理
- 与基金管理人协调系统更新
- 确保种子资本正确分配
- 处理员工提取请求

### 4. SARS税务指令
- 储蓄罐提取须通过SARS税务指令
- 须确保员工有税号
- 须扣除SARS欠税

---

## 七、对员工的影响

### 正面影响
1. **紧急时可提取**：无需辞职即可获取储蓄罐资金
2. **退休保障增强**：退休罐锁定，防止退休前挥霍
3. **税务灵活**：储蓄罐提取按边际税率，退休时Lump Sum更优惠

### 风险提示
1. **储蓄罐提取非免费**：按边际税率征税，无免税额
2. **每年仅1次**：用完后本年度不可再提
3. **复利损失**：R30,000在35岁提取=65岁时少约R230,000（7%实际回报）
4. **影响退休金**：每次提取减少退休时可用的Lump Sum

## 八、中资企业实务建议

### 1. 外派员工退休金安排
- 如外派员工参加南非退休金基金，适用两罐系统
- 须了解回国时退休金处理规则
- 中国籍员工55岁以上特殊规则

### 2. 本地员工退休金
- 强烈建议为本地员工提供退休金基金
- 作为B-BBEE技能发展要素的加分项
- 提升员工留存率

### 3. 工资系统
- 确保工资系统支持两罐分配
- 与退休金基金管理人协调
- 员工教育必不可少

## 九、常见问题

| 问题 | 回答 |
|---|---|
| 储蓄罐每年能提几次？ | 1次 |
| 储蓄罐最低提取额？ | R2,000（余额须≥R2,500） |
| 退休罐退休前能提吗？ | 不能 |
| 种子资本是多少？ | 既得罐的10%，上限R30,000 |
| 储蓄罐提取免税吗？ | 不免税，按边际税率 |
| 55岁以上自动加入吗？ | 不自动，须选择加入 |
| 退休罐退休时怎么拿？ | 余额>R165,000须买年金 |
