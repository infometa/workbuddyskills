# SARS 雇主税务申报：EMP201月度申报与EMP501年度对账

> 来源：SARS官网、XRA Accounting、Comprehensive Accounting、Sparrows Accounting、Uytenbogaardt
> 最后更新：2025年5月（2024/25税务年度）
> 用途：南非人力行政专家语料库 — 薪酬社保板块

## 1. 雇主税务申报体系全景

```
月度申报          半年度对账           年度对账
EMP201    →     EMP501(中期)    →    EMP501(年度)
(每月7日前)      (9月提交)            (4月1日-5月31日)
```

---

## 2. EMP201 月度雇主申报

### 2.1 什么是EMP201
EMP201是雇主**每月**向SARS提交的申报表，汇总当月扣缴的：
- **PAYE**（个人所得税）
- **UIF**（失业保险基金，雇主1% + 雇员1%）
- **SDL**（技能发展税，雇主1%，年薪总额>R500,000时适用）

### 2.2 提交截止日
- **每月7日**前提交并缴款
- 如7日为周末/公共假日 → 截止日提前至前一工作日

### 2.3 提交渠道
- SARS eFiling（在线）
- e@syFile™ Employer（桌面软件）
- 经批准的第三方薪酬软件（Sage、SimplePay、Odoo等）

### 2.4 逾期后果
- 逾期付款 → **10%罚金** + 日利息
- 无宽限期——必须在7日前完成

## 3. EMP501 雇主年度对账申报

### 3.1 什么是EMP501
EMP501是雇主**半年一次**的对账申报，核验：
- 全年月度EMP201申报总额
- 实际支付给SARS的金额
- 员工税证（IRP5/IT3(a)）的准确性

### 3.2 两次对账周期

| 对账类型 | 提交窗口 | 覆盖期间 |
|----------|----------|----------|
| **中期对账** | 9月（具体日期SARS公布） | 3月1日-8月31日（半年） |
| **年度对账** | **4月1日 - 5月31日** | 3月1日-次年2月28日（全税务年度） |

### 3.3 年度对账2025（2024/25税务年度）

| 项目 | 详情 |
|------|------|
| 提交窗口 | 2025年4月1日开放 |
| 截止日 | **2025年5月31日** |
| 覆盖税务年度 | 2024年3月1日 - 2025年2月28日 |
| 提交工具 | e@syFile™ Employer **v8.0**（最新版） |

### 3.4 EMP501须包含的内容
1. 全年**月度EMP201**申报记录
2. 向SARS的**实际付款记录**（不含罚金和利息）
3. 全部员工的**IRP5/IT3(a)税证**（覆盖完整税务年度）
4. 员工信息更新（ID号、税号、地址等）

### 3.5 提交前检查清单
- [ ] 所有月度EMP201已提交
- [ ] 所有SARS款项已结清
- [ ] 员工税号已注册（未注册的用ITREG/Bundled ITREG注册）
- [ ] IRP5/IT3(a)信息准确（收入代码、扣除项、福利）
- [ ] 使用e@syFile™ Employer v8.0

## 4. IRP5 / IT3(a) 员工税证

### 4.1 区别
| 证书类型 | 条件 |
|----------|------|
| **IRP5** | 雇员已注册个人所得税税号，雇主扣缴了PAYE |
| **IT3(a)** | 雇员未注册税号或收入低于纳税门槛，未扣缴PAYE |

### 4.2 IRP5必含信息
- SARS收入源代码（如3601=工资、3602=奖金、3701=交通津贴等）
- 雇员税号
- 雇佣起止日期
- 全部收入、扣减项和福利
- PAYE扣缴总额
- UIF缴费总额
- SDL缴费总额

### 4.3 常见源代码

| 代码 | 含义 |
|------|------|
| 3601 | 普通工资 |
| 3602 | 年度奖金/13薪 |
| 3605 | 佣金 |
| 3701 | 交通津贴 |
| 3702 | 旅行津贴 |
| 3801 | 退休金缴费 |
| 3810 | 医疗援助缴费 |
| 4001 | PAYE扣缴 |
| 4142 | UIF扣缴 |
| 4125 | SDL缴费 |

### 4.4 发放时间
- 年度EMP501对账完成后须及时向员工发放
- 员工须凭IRP5提交个人年度纳税申报表（ITR12）

## 5. 雇主注册义务

### 5.1 注册条件

| 税种 | 注册条件 |
|------|----------|
| **PAYE** | 任何员工收入超过年度纳税门槛（2024/25: **R95,750**） |
| **UIF** | 所有雇主（含1名雇员即须注册） |
| **SDL** | 年薪总额超过 **R500,000** |
| **VAT** | 年营业额超过 **R1,000,000**（强制）/ 超R50,000（自愿） |

### 5.2 注册流程
1. 登录SARS eFiling
2. Register Tax Types → 选择PAYE/UIF/SDL
3. SARS分配PAYE参考号
4. 后续通过eFiling/e@syFile提交申报

## 6. 处罚

### 6.1 EMP501逾期/不完整处罚
- 首月逾期：**全年PAYE负债的1%**
- 每月递增1%，最高**10%**

> **示例**：全年PAYE负债R500,000，逾期3个月 → 罚金R15,000（3%×500,000）

### 6.2 EMP201逾期付款
- **10%罚金** + 日利息

### 6.3 其他后果
- SARS审计或合规审查
- 员工税证处理延误
- 影响企业税务合规状态（Tax Compliance Status）

### 6.4 刑事犯罪
- 故意提交虚假信息 → 刑事追诉
- 未注册/未申报 → 罚款 + 可能监禁

## 8. 记录保存

- 雇主须保存以下记录至少**5年**：
  - IRP5证书
  - 工资单
  - EMP201和EMP501提交确认
  - 薪酬汇总和计算
  - 签署的合同及修订

## 9. 中资企业实操要点

1. **月度7日deadline无宽限**：设好提醒，确保6日完成提交+付款
2. **用合规薪酬软件**：Sage/SimplePay自动生成IRP5源代码，避免手动错误
3. **年度对账4月1日就开始**：不要等到5月底，留时间修正错误
4. **及时注册员工税号**：未注册的用e@syFile的ITREG功能
5. **核对EMP201与实际付款**：金额不一致会触发SARS查询
6. **源代码易出错**：3601 vs 3602、3701 vs 3702须准确使用
7. **兼职/合同工也要报**：漏报是常见审计触发点
8. **5年记录保存**：电子+纸质双备份
9. **保持Tax Compliance Status有效**：影响招投标和银行开户
