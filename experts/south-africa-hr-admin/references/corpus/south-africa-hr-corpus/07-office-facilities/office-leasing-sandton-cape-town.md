## 2. 办公等级分类（Office Grading）

南非商业地产按 **SAPOA（南非地产所有者协会）** 标准分为四个等级：

| 等级 | 说明 | 典型特征 |
|------|------|----------|
| **P-Grade (Premium)** | 顶级甲级 | 标志性建筑、大堂挑高、高速电梯、备份电力、光纤、24小时安保、绿色认证 |
| **A-Grade** | 甲级 | 现代化设施、良好维护、中央空调、充足停车位 |
| **B-Grade** | 乙级 | 功能完备但装修标准略低，性价比高 |
| **C-Grade** | 丙级 | 基本办公条件，适合预算有限企业 |

## 3. 商业租赁关键条款

### 3.1 租期与续约
| 项目 | 惯例 |
|------|------|
| 标准租期 | **3-5年**（新企业可争取1-2年短租） |
| 年度递增 | **8%-10%**（CPI+2%至3%或固定比例） |
| 续约选择权 | 通常含1次续约权，需提前6-12个月通知 |
| 提前终止 | 需协商，通常支付剩余租期租金的50%-100%违约金 |

### 3.2 租金结构

| 费用类型 | 说明 | 谁承担 |
|----------|------|--------|
| **Base Rental** | 基础租金 (R/m²/月) | 租户 |
| **Operating Costs** | 物业运营费 (R/m²/月) | 租户 |
| **Rates & Taxes** | 市政房产税 | 租户（Triple Net租约） |
| **Utilities** | 水电费 | 租户（按表计费或按比例分摊） |
| **Parking** | 停车费 (R/bay/月) | 租户（R850 – R1,900/bay） |
| **VAT** | 增值税15% | 租户（可抵扣） |

### 3.3 租约类型

| 类型 | 说明 |
|------|------|
| **Gross Lease（毛租约）** | 租金含运营费，房东承担大部分费用 |
| **Net Lease（净租约）** | 租户另付运营费 |
| **Triple Net (NNN)（三净租约）** | 租户承担物业税+保险+维护费，**南非最常见** |

### 3.4 押金
- 标准押金：**2-3个月租金**
- 部分房东接受银行保函（Bank Guarantee）替代现金押金
- 押金须存入计息信托账户，退租时连息退还

## 6. 合规要求

### 6.1 入驻前合规
| 项目 | 说明 |
|------|------|
| **Occupancy Certificate（消防安全证书）** | 由市政消防部门签发，确认建筑符合消防法规 |
| **Zoning Compliance（分区合规）** | 确认建筑所在区域规划允许商业办公用途 |
| **Utilities Connection（水电开通）** | 市政水电账户过户或新开 |
| **Fibre/Internet** | 南非主要ISP：Vodacom Business、MTN Business、Seacom、Frogfoot |

### 6.2 运营期合规
- 定期消防安全检查（年度）
- 电梯合格证（Lift Inspection Certificate）
- 建筑保险（Building Insurance，房东或租户按租约约定）
- 公共责任险（Public Liability Insurance）

## 7. 中资企业选址建议

### 7.1 按行业推荐

| 行业 | 推荐区域 | 理由 |
|------|----------|------|
| 金融/投资 | Sandton CBD | 银行/金融机构聚集，品牌形象 |
| 科技/IT | Cape Town CBD / Century City | 科技生态圈，人才集中 |
| 矿业/能源 | Sandton / Rosebank | 总部经济，靠近证交所 |
| 制造业/物流 | 德班 Umhlanga / 约堡 East Rand | 港口/工业区便利 |
| 贸易/批发 | 约堡 Rivonia / Midrand | 仓库+办公混合需求 |

### 7.2 选址实操要点
1. **优先P-Grade或A-Grade**：中资企业形象需要，且备份电力（Load shedding期间至关重要）
2. **确认Load shedding应对方案**：南非电力短缺，须确认建筑是否有发电机/太阳能备份
3. **Gautrain可达性**（约堡）：员工通勤和客户拜访便利性
4. **停车位充足**：南非通勤以自驾为主，停车位不足会严重影响招聘
5. **谈判空间**：Post-Covid市场空置率高（约15%-20%），租户议价能力较强
6. **租约审查**：聘请商业地产律师审查租约条款（费用约R5,000-R15,000）
7. **B-BBEE考量**：选择B-BBEE认证的房东/物业管理公司可贡献企业B-BBEE采购得分
