## 1. BCEA — Basic Conditions of Employment Act 75 of 1997（基本雇佣条件法）

**管什么**：最低雇佣条件——工时、加班、休息、休假、薪酬支付、书面条款、离职通知、裁员遣散费。

| 条款 | 要点 |
|---|---|
| 收入门槛（Earnings Threshold） | 2026-05-01 起 **R269,600.90/年（≈R22,466.74/月）**。低于此门槛者受 BCEA 第二章全面保护；高于者不适用第 9–18 条（工时上限、加班、用餐间隔、休息、周日、夜班、公共假期非排班薪酬）。每月工作 < 24 小时者多数保护不适用。（语料库旧文载 2024 门槛 R254,371.67，以当年公报为准） |
| 工时（s9–s12） | 普通上限 **45 小时/周**（5 天制 9h / 6 天制 8h）；加班须雇员同意，上限 **10h/周**（可临时 15h），每天 ≤ 12h（含加班），加班费 **1.5×** |
| 休息与用餐（s14–s15） | 连续工作 5h 后至少 **60min** 用餐（可书面减至 30min）；每日连续休息 **12h**；每周连续 **36h** |
| 周日 / 公共假期（s16–s18） | 周日非排班 **2×**、排班 **1.5×**；公共假期（通常工作日）**2×** |
| 休假（s19–s27） | 年假 **21 连续日/年**；病假 36 个月内 **30 天**；产假 **4 个月**无薪；育儿/陪产假 **10 连续日**无薪；家庭责任假 **3 天/年** |
| 书面条款（s29） | 月工时 ≥ 24h 的雇员，雇主须提供书面主要雇佣条款声明 |
| 工资单（s33）/ 服务证明（s35） | 须提供工资单；离职须出具服务证明（certificate of service） |
| 通知期（s37） | ≤ 6 月 **1 周**；6 月–1 年 **2 周**；> 1 年 **4 周**（可付代通知金） |
| 遣散费（s41） | **1 周薪酬 × 完整受雇年数**；仅适用于「基于运营需求（operational requirements）」的解雇，须连续受雇 ≥ 12 个月；不含 misconduct / incapacity。周薪 = 月薪 × 12 ÷ 52；remuneration 含基本 + 经常性津贴 + 定期奖金 + 常规加班费 |
| 不付遣散费（s41(3)–(6)） | 拒合理替代职位 / 不当行为解雇 / 达退休年龄 / 固定期限自然到期 |

**关联**：LRA s189/189A（裁员协商程序）、LRA s198B（固定期限合同遣散费：1 月薪酬 × 超 24 个月的每一年，2025 门槛 R261,748.45）。

## 2. LRA — Labour Relations Act 66 of 1995（劳动关系法）

**管什么**：集体权利、不当解雇、工会与罢工、CCMA / 劳动法庭、裁员、劳务派遣。

| 条款 | 要点 |
|---|---|
| 结社自由（s4–s5） | 雇员 / 雇主自由组建、加入工会 / 雇主组织；禁止因工会身份歧视 |
| 工会组织权利（s11–s22） | 接触权、扣缴会费、代表权、信息权、办公设施 |
| 受保护罢工（s64） | 前置：先调解 → 取得调解不成立证明 → **48h 书面通知** → 生效 |
| 不得罢工（s65） | 权利争议且已有仲裁途径 / 集体协议在有效期内 / Essential Service（须仲裁） |
| 不当劳动行为（s186） | 非解雇的不公对待（暂停、降职、拒晋升、因工会活动报复等） |
| 裁员 < 50 人（s189） | 书面通知 → 协商（避免 / 减员 / 选择标准 / 遣散费）→ 决定通知 → 通知期 |
| 大型裁员 ≥ 50 人（s189A） | 强制 **60 天**协商期 + 同步通知 DEL（Department of Employment and Labour） |
| 劳务派遣（s198A） | 劳务外包（TES / labour broker）雇员连续服务超 **3 个月**视为客户公司雇员 |
| 固定期限合同（s198B） | 低收入者续签 ≤ 3 次且累计 ≤ 3 年，否则视为永久雇员 |
| 公平解雇准则 | 旧 Schedule 8 已由 **2025-09-04 新《解雇良好实践准则》** 替代 |
| 争议流程 | 30 天内提交 CCMA → 调解（30 天）→ 不成 → 仲裁；劳动法庭复审；> 50 人裁员归劳动法庭 |

**关联**：BCEA s37（通知期）、s41（遣散费）。

## 3. EEA — Employment Equity Act 55 of 1998（就业公平法，2022 修正案 Act 47 of 2023，2025-01-01 生效）

**管什么**：反就业歧视 + 平权措施（affirmative action）+ 就业公平报告。与 B-BBEE 并行但体系独立。

| 条款 | 要点 |
|---|---|
| 反歧视（s6） | 所有雇主适用：禁止基于种族 / 性别 / 怀孕 / 残疾 / 年龄 / HIV 状态 / 宗教等歧视；真实职业资格与法定平权为例外 |
| 指定雇主（designated employer） | **2025 修正案起 = 雇员 ≥ 50 人（不再看营业额）**；须全面合规（平权 + 报告） |
| 就业公平计划（s20） | 须含各职业等级指定群体（黑人 / 女性 / 残障）代表性目标、时间表（3–5 年）、措施、监督机制 |
| 报告义务（s21） | **EEA2** 年度报告 + **EEA4** 收入差异分析 |
| 5 年 EE 计划期 | **2025-09-01 至 2030-08-31**，须对齐 18 个经济部门法定数值目标 |
| 残疾目标 | 由 **2% 升至 3%**（2025 修正案） |
| 合规证书（Compliance Certificate） | **12 个月有效**，是取得政府合同的强制条件 |
| 罚则（2025 修正案） | 首犯 **R150 万 或 年营业额 2%**（取大）；再犯 **4%**；三犯 **R270 万 或 10%** |

**关联**：B-BBEE「管理控制」要素（EEA2 提交是其得分前提）。

## 4. B-BBEE — Broad-Based Black Economic Empowerment Act 53 of 2003（2013 修正案 Act 46 of 2013）+ Codes of Good Practice

**管什么**：经济赋权评级（所有权 / 管理 / 采购 / 技能 / 社会贡献），影响政府标案、牌照、客户采购认可度。

**评分卡五要素（Generic：年营业额 > R50m；QSE：R10m–R50m）**

| 要素 | 权重（+加分） |
|---|---|
| 所有权 Ownership | 25（+5） |
| 管理控制 Management Control | 15（+5） |
| 技能发展 Skills Development | 20（+5） |
| 企业与供应商发展 ESD | 40 |
| 社会经济发展 SED | 5 |
| **合计** | **109（含加分）** |

**等级与采购认可**：L1 ≥100（135%）/ L2 95–99.99（125%）/ L3 90–94.99（110%）/ L4 80–89.99（100%）/ L5 75–79.99（80%）/ L6 70–74.99（70%）/ L7 55–69.99（50%）/ L8 40–54.99（10%）/ 非合规 <40（0%）。

**关键概念**：Empowering Supplier（参评前提）、Discounting Principle（扣减原则）、Flow-Through Principle（穿透计算）、Y.E.S Initiative（青年就业服务加分）。

**行业法典（Sector Codes）**：金融、建筑、农业、矿业、ICT、旅游等各有专属评分卡，权重不同。

> ⚠️ **2026 草案（GG 54032，2026-01-29 发布，尚未通过）**：拟引入转型基金（3% NPAT 换 ESD 全部 20 分）、采购目标转向 100% 黑人持有供应商、ESD 从「投入」转向「成果验证」。行业章程暂不受影响。**草案 ≠ 法律**，生效前仍按现行 Codes 执行。

**与 EEA 区别**：B-BBEE 是经济赋权**评级**体系；EEA 是反歧视 / 公平就业**法律义务**，二者不可混淆。

## 5. COIDA — Compensation for Occupational Injuries and Diseases Act 130 of 1993（工伤赔偿法，2026 修正）

**管什么**：工伤 / 职业病补偿（医疗、康复、收入损失），雇主**强制注册**。未注册 = 刑事罪 + 自担工伤成本。

| 条款 | 要点 |
|---|---|
| 注册 | 雇用第一名雇员后 **7 天内**向 Compensation Fund 注册（W.As.2 表，在线 cfonline.labour.gov.za）；获 **12 位 CF 号（99 开头）**；业务变更须 7 天内通知 |
| 收入申报 ROE（W.As.8） | 评估期 **3 月 1 日 – 次年 2 月 28/29 日**；每年申报窗口（近年为 5/1 – 7/31） |
| 关键金额（2026/27） | 每雇员年收入上限 **R668,000**；最低评估费 **R1,621** |
| 评估费 | = 总收入 ÷ 100 × 评估税率（按行业风险 **0.11% – 7.79%**） |
| LOGS（Letter of Good Standing） | 合规雇主可申请，政府标案 / 工地准入必备；每年 **4 月 30 日**到期须更新 |
| 逾期与连带责任 | 逾期申报处评估额 **10% 罚款 + 利息**；**2026 修正**：分包商违规 → 主承包商承担连带责任 |
| 2026 修正要点 | 收入定义对齐《所得税法》第四附表 |

**关联**：UIF（失业 / 产假 / 病假津贴另算，不属 COIDA）。
