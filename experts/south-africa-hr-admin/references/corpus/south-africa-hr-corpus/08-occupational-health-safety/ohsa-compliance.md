# OHSA 职业健康安全法合规指南

> 来源：Occupational Health and Safety Act 85 of 1993、Department of Employment and Labour、Cliffe Dekker Hofmeyr、Ensemble Africa
> 最后更新：2025年3月（含2024年Physical Agents Regulations）
> 用途：南非人力行政专家语料库 — 职业安全板块

---

## 1. 法律框架

**《职业健康安全法》（Occupational Health and Safety Act, No. 85 of 1993, OHSA）** 是南非职业安全核心立法，适用于**除矿业以外**的所有工作场所。

### 1.1 适用范围
- 所有行业工作场所（办公室、工厂、建筑工地、仓库等）
- **排除**：矿业（受Mine Health and Safety Act 29 of 1996管辖）

### 1.2 配套法规体系
| 法规名称 | 管辖领域 |
|----------|----------|
| General Administrative Regulations | 安全委员会、事故报告、记录保存 |
| General Safety Regulations | 急救、PPE、危险区域防护、受限空间作业 |
| Facilities Regulations | 饮用水、卫生设施、员工便利设施 |
| Ergonomics Regulations | 人体工程学风险识别与控制 |
| **Physical Agents Regulations, 2024** | 冷/热应力、照明、室内空气质量、振动、非电离辐射（2025年3月6日发布，Gazette No. 52226） |
| Construction Regulations | 建筑行业安全 |
| Major Hazard Installation Regulations | 重大危险设施 |
| Driven Machinery Regulations | 机械驱动设备 |
| Electrical Machinery Regulations | 电气设备 |

## 2. 雇主核心义务（Section 8）

### 2.1 基本义务
雇主必须：
1. **提供并维持**安全的工作环境
2. 确保工作系统、设备和机械**安全且无健康风险**
3. **消除或减轻**工作场所危险源
4. 确保 生产、加工、使用、存储或运输 物品/物质的方式不构成健康风险
5. **进行风险评估**并实施预防措施
6. 向雇员**提供信息、指导、培训和监督**
7. 采取一切必要措施确保OHS法合规
8. 不得允许非法化学品或危险机械在无监督情况下使用

### 2.2 风险评估与管理
所有工作场所必须定期进行风险评估：

| 步骤 | 内容 |
|------|------|
| **危险识别** | 系统识别滑倒/坠落、高空作业、化学暴露、机械危险等 |
| **风险评价** | 评估事件发生概率和严重程度 |
| **控制实施** | 按控制层级（消除→替代→工程控制→行政控制→PPE）实施措施 |
| **定期复审** | 持续监控和更新风险评估 |

> **Physical Agents Regulations 2024新要求**：风险评估须文档化，每**24个月**至少更新一次，暴露监测同样每24个月进行。

### 2.3 健康安全管理体系统
- 近年修订要求企业实施**全面健康安全管理体系**（不仅限于政策文件）
- 建议对齐 **ISO 45001** 国际标准
- 从被动政策文件向主动管理框架转变

## 3. 安全人员与委员会

### 3.1 安全代表（Health & Safety Representative）
| 条件 | 要求 |
|------|------|
| 雇员 ≥ 20人 | **必须**任命至少1名安全代表 |
| 雇员 < 20人 | 可应劳动监察员要求任命 |
| 选举方式 | 由雇员**提名选举**产生（非管理层指定） |
| 职责 | 定期安全检查、事故调查、向雇主报告隐患 |
| 培训 | 雇主须提供必要培训 |

### 3.2 健康安全委员会（H&S Committee）
| 条件 | 要求 |
|------|------|
| 雇员 ≥ 20人 | **必须**建立健康安全委员会 |
| 组成 | 管理层代表 + 安全代表（雇员代表须占多数） |
| 会议频次 | 至少**每3个月**召开1次 |
| 职责 | 审议安全报告、协调安全措施、处理雇员安全关切 |

### 3.3 专项安全任命
根据企业风险画像，可能需要任命：
- **First Aider（急救员）**：每50名雇员至少1名持证急救员
- **Fire Marshal（消防员）**：负责消防应急
- **Safety Officer（安全官）**：高风险行业强制
- **Lifting Machine Operator（起重设备操作员）**：持证上岗

## 4. 事故报告与记录

### 4.1 强制报告事项

| 事件类型 | 报告时限 | 表格 |
|----------|----------|------|
| **死亡事故** | 立即电话报告 + 7天内书面报告 | **WCL 2** |
| **重伤事故** | 7天内 | WCL 2 |
| **职业病诊断** | 确诊后14天内 | **ODC 1** |
| **危险事件** (Dangerous Occurrence) | 7天内 | WCL 2 |
| **年度安全统计** | 每年3月31日前 | **WCL 3** |

### 4.2 报告对象
- 向 **Department of Employment and Labour**（劳动就业部）报告
- 可通过 Provincial Director / 首席职业安全官报告

### 4.3 记录保存
- 事故记录、风险评估、培训记录、医疗监测、安全委员会会议记录
- **Physical Agents Regulations 2024**：记录保存期限 **40年**
- 训练记录、风险评估、暴露监测、医疗筛查、控制措施均须保存

## 5. Physical Agents Regulations 2024（新规）

2025年3月6日发布于Government Gazette No. 52226，核心内容：

### 5.1 管辖范围
适用于：雇主、自雇人士、设计者、制造商、进口商、设备供应商（噪音暴露除外）

### 5.2 具体管制领域
| 物理因素 | 管制要求 |
|----------|----------|
| **冷应力** (Cold Stress) | 控制措施+PPE |
| **热应力** (Heat Stress) | 控制措施+PPE |
| **照明** (Illumination) | 最低照度标准 |
| **室内空气质量** (Indoor Air Quality) | 通风、空气质量监测 |
| **振动** (Vibration) | 暴露限制+控制措施 |
| **非电离辐射** (Non-ionising Radiation) | 暴露限制+控制措施 |

### 5.3 雇主额外义务
- 向雇员提供信息和培训，包括**年度更新培训**
- 雇员义务：遵守指令、报告缺陷、配合暴露评估、正确使用PPE
- 实施医疗筛查项目（针对暴露员工）
- 风险评估每**24个月**更新一次

---

## 6. 雇员义务（Section 14）

雇员须：
1. 对自身及他人的健康安全**采取合理注意**
2. 遵守工作场所安全程序
3. 正确使用PPE（如必要）
4. 向雇主**报告不安全条件**
5. 配合雇主满足OHS法要求

## 7. 执法与处罚

### 7.1 劳动监察员权力
- 无预先通知进入工作场所检查
- 要求出示文件、记录
- 发出**合规令**（Compliance Order）
- 发出**禁止通知**（Prohibition Notice）— 立即停止危险作业
- 直接开具行政罚款

### 7.2 处罚标准

| 违规类型 | 处罚 |
|----------|------|
| 一般违规 | 罚款最高 **R50,000**（行政罚款，监察员直接开具） |
| 严重违规 | 罚款最高 **R1,000,000** 和/或**2年监禁** |
| 拒不执行合规令 | 劳动法庭强制执行 + 进一步处罚 |

### 7.3 近期执法动态
- 2024年7月起，DOL联合内政部和执法机构开展**全国突击检查**
- 仅夸祖鲁-纳塔尔省就检查了**535家企业**
- 发现违规包括：工资低于最低标准、非法扣款、安全措施不足
- 罚款及纠正金额超过 **R1,000万**
- 最新统计：南非年度报告**2,023起**工伤死亡、**18,370起**工伤伤害

### 7.4 典型案例
- Zenco Engineering公司案：工人因机械事故死亡，雇主未做风险评估、未采取预防措施，被判罚款R50,000或12个月监禁

## 8. 与其他法规的联动

| 法规 | 联动关系 |
|------|----------|
| **COIDA** | OHSA事故报告与COIDA工伤赔偿申请互为前提 |
| **UIF** | 工伤导致的病假可同时申请UIF疾病津贴 |
| **EEA** | 残障人士安全保护与EEA平权措施协同 |
| **BCEA** | 安全培训时间计入工作时间 |
| **LRA** | 拒绝执行不安全工作的雇员受LRA保护（不应被视为不当行为） |

## 9. 中资企业合规要点

1. **优先任命安全代表**：雇员≥20人即强制，且须雇员选举产生
2. **建立安全委员会**：每季度开会，保留完整会议记录
3. **完成风险评估**：聘请专业安全顾问（Safety Practitioner），费用约R5,000-R20,000
4. **配置急救员和急救箱**：每50人1名持证急救员，费用约R1,500/人培训
5. **PPE配备**：按风险评估结果配发，保留签收记录
6. **事故报告零延误**：死亡事故须立即电话报告，7天内提交WCL 2
7. **关注Physical Agents Regulations 2024**：新规已发布，涉及室内空气质量、照明等办公室环境因素
8. **培训记录留存**：所有安全培训须文档化，保存期40年
9. **DOL突击检查准备**：2024年起检查力度加大，建议定期自查
10. **与COIDA联动**：OHSA事故报告是COIDA工伤理赔的前置条件
