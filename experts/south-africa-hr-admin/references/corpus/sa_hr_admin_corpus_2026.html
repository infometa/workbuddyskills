2. 劳动合同与劳动法 (Labor Contracts & Law)

2.1 BCEA法定最低条件

条款标准备注
普通工时45小时/周（5天工作=9小时/天；6天=8小时/天）收入超门槛者豁免

2.2 2026年BCEA收入门槛

指标2025年2026年（5月1日起）
年收入门槛R261,748.45R269,600.90
月收入门槛≈R21,812.37≈R22,466.74
增幅—≈3%
重要影响：
  • 收入低于门槛=适用全部BCEA第二章保护（工时/加班/用餐休息/周日付酬/公共假日付酬）
  • 低于门槛+固定期限合同超3个月且无正当理由→视为永久雇员（LRA s198B）
  • 低于门槛+劳务派遣超3个月→视为客户公司的雇员（LRA s198A）
  • 收入高于门槛→加班费/工时限制的豁免，但保留年假/病假/产假/通知期/禁止童工的权利
  • EEA歧视纠纷：低于门槛可由CCMA仲裁；高于门槛须向劳工法院诉讼（除非涉及性骚扰或各方同意仲裁）

2.3 合同类型

  • 永久合同： 无时限，解雇须遵循公平程序（LRA Schedule 8）
  • 定期合同： 收入≤门槛者连续续签≤3次或累计≤3年，否则视为永久。门槛以上无此限制。
  • 试用期： 通常3个月，可延长至6个月（经理/专业岗）。试用期内解雇仍需程序公正。
  • 临时工： 每周工作≤24小时，每次指派≤3个月。

2.4 2026年劳工法修正案草案 (Labour Law Amendment Bill, GG 54220, 2026年2月26日)

仍在草案阶段，公共评论已截止，尚未提交议会。关键提案：
  • 遣散费翻倍： 从每服务满1年支付1周工资→2周工资（仅对法案生效日后的服务年限）
  • 高收入员工复职限制： 年收入>R180万者，不公平解雇索赔不再适用复职/重新雇佣（自动不公平解雇除外），补偿上限R180万+CPI
  • 共享育儿假： 将宪法法院2025年裁决编入法典——双方就职父母共享4个月10天产假，单亲/唯一就职父母=4个月，UIF支付66%收入（上限R17,712/月）
  • 零小时/待命合同新规： 合同须写明最大工时、待命时间窗口、最少通知期；雇主取消排班须补偿；每工作26天获1天雇主带薪病假
  • 新创企业豁免： 运营<2年且<50人的企业，2年内不受行业集体协议的雇佣条款约束
  • 排他性限制： 禁止无正当理由限制员工为其他雇主工作
  • 演员/影视从业者： 重新分类为雇员，终结独立合同人错分类

注意：上述均为草案提案，尚未成为法律，最终内容可能经议会修改。企业应先进行影响建模，但不得按草案执行。

2.5 CCMA争议解决

劳动争议首先须经CCMA（调解仲裁委员会）调解。典型时间线：立案→调解（30天内）→未解决→仲裁（14天内）。CCMA仲裁裁决可向劳工法院复核（仅程序问题/裁决不合理）。

3.5 福利体系（市场标准）

  • 医疗援助(Medical Aid)： 主要保险公司包括 Discovery Health、Bonitas、Momentum Health、Medihelp。雇主通常补贴50%保费。
  • 退休基金： 公积金(Provident Fund)/养老金(Pension Fund)。RA(退休年金)个人缴纳上限：年应税收入或薪酬的27.5%，上限R430,000/年，可抵扣应税收入。
  • 风险福利： 团体寿险/残疾险/丧葬险，市场标准=2-3倍年薪（寿险）。
  • 13薪(13th Cheque)： 非法定，但多数行业惯例提供。可纳入CTC(cost-to-company)或单独支付。

3.6 岗位定级体系

  • Paterson Grading： A(操作员) → F(高管)，6大等级18细分。南非最广泛使用的定级系统。
  • Hay Grading： 基于Know-How/解决问题/问责三要素，适合专业/管理层。
  • Peromnes： 19级体系，常用于政府和半国有企业。

4. 签证与工签 (Visa & Work Permits)

4.1 签证类型速览

签证类型有效期关键条件可否转永居
关键技能工签 (Critical Skills Work Visa)最长5年职业在技能清单上 + SAQA认证 + 专业机构注册。无job offer可先获1年缓冲期入境找工。满5年后可直接申请
一般工作签证 (General Work Visa)最长3年须有job offer + DOEL推荐信（证明无法招到本地人）。2024年10月引入分数制(PBS)。不直接，需转其他类别
公司内部调动 (Intra-Company Transfer)4年不可续签跨国公司内部调动，须母公司在海外雇用满6个月。4年期满必须离境重新申请。不可
企业签证 (Corporate Visa)视计划雇主先获批企业签证，再为个人签发附属工作签证。适合批量引进外籍员工。视情况
商务签证 (Business Visa)最长3年投资R500万+（部分行业豁免）+ 投资计划 + 警察无犯罪证明。某些行业被视为不受欢迎（二手汽车出口/异域娱乐/安保/酒店/快餐/美容）。可
远程工作签证 (Remote Work Visa)12个月，可续至3年2025年3月正式开放申请。年收入≥R650,976（≈R54,248/月），为海外雇主远程工作。不直接
电子旅行授权 (ETA)短期2025年末启动试点，类似于ESTA/ETIAS的预旅行在线授权系统。不适用

4.3 申请流程

  1. 确认职业是否在关键技能清单上
  2. SAQA学历评估（12-16周）
  3. 专业机构注册（如适用：ECSA/SAICA/SACPCMP等）
  4. 准备文件：护照、无犯罪证明（18岁后居住超12个月的所有国家）、体检+胸片、雇佣合同/offer
  5. 填写DHA-1738申请表
  6. 通过VFS Global预约生物识别+递交（或境外通过南非使领馆）
  7. 审批：8-12周（完整申请）
  8. 入境后12个月内向DHA提交专业注册证明+就业证明
时效性提醒： DHA白皮书持续推进签证数字化审批；关键技能清单正在审查中，预计2026年发布更新版；分数制工签系统(PBS)于2024年10月引入，持续细化中。建议提交前向VFS Global/DHA官网确认最新收费和流程。

6.2 商业租赁要点

  • 租期： 通常3-5年
  • 年递增： 8%-10%（通常挂钩CPI+固定点差）
  • 三净租约(Triple Net)： 租户承担物业税+保险费+公共区域维护费（除租金外）
  • 押金： 2-3个月租金
  • 关键条款： 可使用面积(GLA)、停车位配比（通常1:15-1:20㎡）、空调运行时间、续租选择权、提前终止条款、复原义务

  • 分区合规(Zoning)： 确认物业用途允许办公/商业
  • 市政服务开通： 水/电账户过户至租户名下
  • 健康与安全法(OHSA)： 办公室须符合工作场所安全标准

7. 行政流程与公司注册 (Administrative Procedures)

7.1 公司注册 (CIPC)

  1. 公司类型： 私人公司(Pty Ltd) — 最常见形式
  2. 名称预核准： CoR 9.1（3-5个工作日）

  6. 年度申报： 每年向CIPC提交年度申报+缴费，否则面临自动除名

8. 员工管理与劳动关系 (Employee Management)

8.1 公平解雇程序 (LRA Schedule 8)

  1. 调查： 全面收集事实，通知员工指控
  2. 纪律听证会： 员工有权陈述、传唤证人、由工会代表陪同
  3. 裁决： 基于证据和案件情况
  4. 上诉权： 须给予员工上诉机会

8.2 纪律处分层级

口头警告 → 书面警告 → 最终书面警告 → 解雇

严重不当行为（盗窃/欺诈/暴力/严重玩忽职守）可直接解雇，但仍须遵循程序公正。

8.3 裁员 (Retrenchment — LRA s189/s189A)

义务要求
信息官(IO)必须指定并向信息监管机构注册（通过e-Services Portal）
8项处理条件问责制 / 处理限制 / 目的说明 / 进一步处理限制 / 信息质量 / 开放性 / 安全保障 / 数据主体参与
2025年4月修订更严格的直接营销同意（明确opt-in + consent register）；安全漏洞全部须报告（不是仅"重大"漏洞）；儿童数据/特殊个人信息额外保护
处罚行政处罚最高R1,000万；刑事处罚含监禁（严重违规）；数据主体可提起民事诉讼

大规模裁员s189A适用：≥50人（大型雇主）或特定比例。可邀请CCMA调解员参与。程序结束后方可实施。

选择标准LIFO（后进先出）常用，但须公平+经协商

8.4 绩效管理

  • KPI设定： 年度/半年绩效合同
  • PIP绩效改进计划： 通常30-90天，明确目标+定期评审+支持措施
  • 因绩效解雇： 须证明已给予合理机会改善（培训/指导/警告），程序公正不可跳过

8.5 就业公平报告

  • 指定雇主（≥50人）须提交EEA2（年度报告）和EEA4（收入差异分析）
  • 2026年线上提交截止：2027年1月15日
  • 须展示对18个部门目标的进展或提供正当理由

8.6 内部申诉程序

  • 非正式渠道→正式书面申诉→管理层回应→升级至HR/高管→如未解决可转CCMA
  • 性骚扰申诉可直接转CCMA
