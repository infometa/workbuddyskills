# SVG 图表生成规范（南非人力行政专家版）

本文件随专家包发布，供生成任何 `show_widget` 内联 SVG 图表时自检使用。
记录自越南专家包验证的 4 类渲染 bug，适配南非场景后作为可视化功能的"防错清单"。

## 四个必犯 bug 与修复

### Bug 1 — 色块渲染成黑色（属性名拼写错误）
- **原因**：`fill` 拼错，例如写成 `fit="#BA7517"` 或 `filll="..."`。无效属性被忽略 → 默认黑色填充。
- **修复**：每个需要上色的 `<rect>/<circle>/<path>` 必须有精确的 `fill="#RRGGBB"`。发出 SVG 前逐一核对所有 fill。

### Bug 2 — 右侧数值标签被截断
- **原因**：柱状图太宽，柱尾 (x+width) 与右侧标签 x 重叠或超出可视安全区（680 宽画布安全区 x=40~640）。
- **修复**：
  - 可用内部宽度 = 600px（x 从 40 到 640）。
  - 若数值标签放在柱右侧，柱必须在该标签之前结束。预算：`柱最大宽 + 标签宽(≈90px) ≤ 600`。
  - 按比例缩短柱子。例：三根柱合计约 500px，可在 x≈516 放 "R234万"。

### Bug 3 — 文字溢出卡片边框
- **原因**：卡片 `height` 小于内部文字行数所需；或 viewBox `H` 过短导致底部文字被裁。
- **修复**：
  - 卡片高度 ≥ `24 + 行数×16`。2 行→≥56，4 行→≥88。
  - viewBox H = 最低元素 y + 20。任何 `<text>` 的 y 不得超 H-20。
  - 内容长就加大 H，不要把文字缩到 10px 以下。

### Bug 4 — 箭头与文本框重叠
- **原因**：箭头线从上一框底边直接连到下一框顶边，无间隙，线段/箭头压在框上。
- **修复**：
  - 每个节点之间留可见间隙：`节点高(52) + 22px 箭头段`。
  - 箭头线只画在间隙内：`y1 = 上框底`，`y2 = 下框顶`，且 `上框底 < 下框顶`。
  - 用 `marker-end` 画箭头；线 `stroke="#888780"` `stroke-width="1.5"`。

## 发出 SVG 前自检清单
- [ ] 每个上色图形都有正确 `fill=`（不是 `fit`/`filll`）
- [ ] 没有 `<text>` 的 x 超 640 或 y 超 H-20
- [ ] 柱子 + 右侧标签在 600px 可用宽度内（不够就缩短）
- [ ] 卡片高度能容纳其文字行
- [ ] 箭头在间隙内，不压框
- [ ] viewBox = `0 0 680 H`，H = 最低元素 y + 20

## 南非专用数值缩写规则
- 兰特金额：`R X万`（万兰特，如 R 35万 = R350,000）、`R Xk`（千兰特，如 R25k = R25,000）
- 百分比：直接用 `XX%`（如 18%、45%）
- 税率档位：`R245k–R383k: 26%` 而非全写 `R245,100–R383,100: 26%`
- 多列对比图：viewBox ≥ 1700、每列净宽 ≥ 440px（防文字遮挡硬约束）

## 南非特色图表场景
1. **PAYE累进税表** — 7档税率横向条形图，每档标注税率+区间+退税额
2. **薪酬分解环形图** — 基本薪资/PAYE/UIF/SDL/COIDA/净薪 占比
3. **B-BBEE评分卡雷达图** — 五要素得分 vs 满分
4. **合规日历时间线** — 12个月申报节点纵向流程图
5. **签证申请流程图** — 6类签证从申请到获批的步骤对比
6. **ETI激励对比柱状图** — 有ETI vs 无ETI的雇主月成本对比
