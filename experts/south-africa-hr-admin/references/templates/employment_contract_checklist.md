# 南非劳动合同必备条款检查清单

> 依据：BCEA §29 书面权利声明、LRA §198B（固定期限）、PCA 判例。
> 用法：逐项核对后勾选；中方外派员工另需叠加母国与跨境税务条款。

## 一、主体与岗位（BCEA §29 强制书面）
- [ ] 雇主全称、注册号、经营地址
- [ ] 雇员姓名、身份证号 / 护照号、住址
- [ ] 职位描述（job description）与工作地点
- [ ] 雇佣起始日；是否试用期（Probationary）及转正比例
- [ ] 合同类型：永久 / 固定期限 / 临时 / 实习

## 二、工时与报酬
- [ ] 普通工作时间（周 ≤45h；超时须书面约定）
- [ ] 基本薪资、支付周期（月薪 / 周薪）、支付方式
- [ ] 津贴：住房 / 交通 / 通讯（如有）
- [ ] 13薪 / 绩效奖金条款（如有）
- [ ] 加班、周日、公共假日付酬规则（BCEA §10/§15/§18）

## 三、休假与社会保障
- [ ] 年假（≥21 连续工作日）、病假、产假（4 个月，可带薪部分）、家庭责任假
- [ ] UIF：雇主+雇员各 1%，月薪上限 R17,711.76
- [ ] SDL：年薪酬 >R500,000 才缴 1%
- [ ] COIDA：雇主全额，行业费率 0.11%–7.79%
- [ ] 医疗援助 / 退休金（如提供，写明供款比例）
- [ ] 退休年龄

## 四、终止条款
- [ ] 通知期（对照 BCEA §37 法定最低）
- [ ] 固定期限合同：月收入 <BCEA 门槛者，续签 ≤3 次 / 累计 ≤3 年，否则视为永久雇员（LRA §198B）
- [ ] 派遣（TES）：超 3 个月视为客户公司雇员（LRA §198A）
- [ ] 遣散费标准（法定 ≥1 周/服务年）

## 五、合规与跨境（中资特别）
- [ ] POPIA 数据处理同意条款、信息官告知
- [ ] 外派：母国社保/税、南非 PAYE、汇率结算币种
- [ ] 工作签证状态（关键技能 / 一般 / ICT）及续签责任方
- [ ] 争议解决：CCMA 管辖、适用法律（南非法）

---
*本清单为起草辅助，不构成法律意见；正式合同须经南非雇佣法律师审阅。*
