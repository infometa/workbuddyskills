# 南非工作签证申请检查清单

> 适用：中资企业向南非派遣/雇佣外籍员工。签证类型见 `references/data/visa_checklist.json`。
> 通用流程：SAQA 学历认证 → 体检+无犯罪证明 → 材料公证翻译 → VFS 预约 → DHA 审批（8–12 周）。

## 一、按签证类型准备
- [ ] **关键技能工签（Critical Skills）**：职业在关键技能清单；SAQA 认证；专业注册（如适用）
- [ ] **一般工作签证（General Work）**：雇主要证本地招不到（DoL 推荐信）；分数制（PBS，2024-10 起）
- [ ] **公司内部调动（ICT）**：集团内部调动函；有效期 4 年不可续签
- [ ] **远程工作签证（Remote Work，2025-03 开放）**：年收入 ≥R650,976；12 个月可续至 3 年
- [ ] **企业签证（Corporate）**：批量引进，按人头计
- [ ] **商务/投资签证（Business）**：投资 ≥R5,000,000（部分行业豁免）

## 二、通用材料
- [ ] 护照（有效期 >6 个月）+ 近照
- [ ] SAQA 学历评估证书（关键技能/一般工签）
- [ ] 体检报告（R500–1,200，指定机构）
- [ ] 无犯罪证明（南非本地 + 原籍国，R180–190，需公证）
- [ ] 婚姻/出生证无删节公证 + 英文翻译
- [ ] DHA 申请费 R1,520 + VFS 服务费 R1,550
- [ ] 工作 offer / 雇佣合同（含薪资、职位）
- [ ] 公司 CIPC 注册文件、税务合规证明

## 三、审批与后续
- [ ] VFS 生物信息采集预约
- [ ] DHA 审批周期 8–12 周；ETA 电子旅行授权试点（2025 末）留意
- [ ] 获批后：UIF/SDL/COIDA 注册、POPIA 信息官、银行账户 FICA
- [ ] 续签提醒：关键技能/一般 3 年；远程 12 个月；ICT 不可续
- [ ] 关键技能清单预计 2026 年更新，申请前查 DHA 实时源

---
*本清单为申请辅助，不构成移民法律意见；以 DHA/VFS 当期官方要求为准。费用数据见 `references/widgets/visa_cost_calc.html`。*
