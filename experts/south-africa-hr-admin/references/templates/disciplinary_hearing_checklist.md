# 纪律听证与公平解雇检查清单

> 依据：LRA Schedule 8（行为守则 / 公平程序）、Code of Good Practice on Dismissal、CCMA 判例（Sidumo 标准）。
> 原则：**程序公正（procedural fairness）+ 实质公正（substantive fairness）** 二者缺一不可。

## 一、纪律处分层级（递进）
- [ ] 口头警告（Oral warning）
- [ ] 书面警告（Written warning）
- [ ] 最终书面警告（Final written warning）
- [ ] 解雇（Dismissal）—— 严重不当行为可即时，但须留程序

## 二、公平调查程序（Schedule 8）
- [ ] 指控书面化、具体、可核实
- [ ] 告知雇员指控 + 拟采取措施 + 听证权
- [ ] 雇员有权带代表 / 工会代表
- [ ] 独立、无偏见的调查人
- [ ] 证据呈现、交叉核对、给予陈述机会
- [ ] 裁决书面化 + 上诉权（appeal）

## 三、严重不当行为（可解雇但须程序）
- [ ] 盗窃 / 欺诈 / 腐败
- [ ] 暴力 / 职场骚扰（含 2022 反骚扰守则）
- [ ] 反复无故旷工 / 严重失职
- [ ] 醉酒 / 毒品上岗
> 注：即便严重，仍须走调查与听证，否则易被 CCMA 判不当解雇。

## 四、解雇争议防范
- [ ] 解雇前已用尽渐进纪律（除非严重不当行为）
- [ ] 留痕：警告信、听证记录、裁决、上诉结果 全套存档（POPIA 合规）
- [ ] 通知期遵守 BCEA §37
- [ ] 遣散费（如适用）：法定 ≥1 周/服务年（裁员 LRA §189 另计）
- [ ] 争议时效：**CCMA 不当解雇须 30 天内**提交（referral）

## 五、裁员（Retrenchment，LRA §189）
- [ ] 书面告知 + 协商义务（consultation）
- [ ] 遴选标准公平（LIFO 等）
- [ ]  alternatives to dismissal 已考虑
- [ ] 遣散费 + 优先再雇佣（recall）条款

---
*本清单为流程辅助，不构成法律意见；正式解雇建议经南非雇佣法律师与 CCMA 合规核对。争议解决首选 CCMA 调解仲裁。*
