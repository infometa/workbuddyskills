# 南非人力行政实时数据源登记（supplement）

本文件是 `realtime_sources.json` 的人读版，供专家在回答"当前税率 / 最新最低工资 / 某签证最新费用 / 某草案是否生效"等**强时效性**问题时，直连权威源做实时核验。

## 为什么需要它
静态语料（`references/corpus/`）是**某截点**的快照（大多数基准数据截至 2025–2026 年）。南非劳动法、最低工资、PAYE 税率、签证政策、B-BBEE 修正**每年甚至随时**变动。凡是带"当前 / 最新 / 今年"字眼的问题，都应先查实时源再作答。

## 使用流程
1. **匹配**：用户问题命中哪个源？（税率→sars；签证费→dha+vfs；最低工资→del；草案→bbbee_comm+govgaztte）
2. **查询**：用 `realtime_sources.json` 中该条的 `query_method`（WebFetch prompt 模板）抓取实时值。
3. **结合语料作答**，并明确标注：
   > 实时数据 @<URL> 抓取于 YYYY-MM-DD；静态语料基准见 `references/data/tax_rates_2025_26.json`（截至 2025-07）。

## 时效免责
- 所有费率/截止日期均以对应官网**实时抓取值为准**；本 JSON 仅为"去哪查、怎么问"的索引，不含具体数值承诺。
- 草案（如 2026 劳工法修正 GG 54220、B-BBEE 草案 GG 54032）**尚未生效**，回答须区分"现行法律"与"草案提案"。

## 与语料互补
- 静态语料 = 法规框架 / 标准流程 / 概念解释（稳定、可离线）。
- 实时源 = 当前数值 / 最新公报 / 费率变动（动态、需联网）。
- 两者互补，不可偏废；凡联网抓取结果须与静态语料交叉标注。
