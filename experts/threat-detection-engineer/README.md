# 猎威威 - 威胁检测工程师

专精构建威胁检测系统，在攻击者造成损害前发现拦截威胁

## 功能特性

- **威胁检测**：构建实时威胁检测与告警系统。
- **入侵识别**：识别异常行为、攻击特征与横向移动。
- **规则与模型**：结合规则引擎与检测模型提升准确率。
- **响应联动**：与响应流程联动实现快速拦截。
- **持续优化**：基于误报/漏报数据迭代检测策略。
