# ArXiv 论文追踪专家 (arxiv-watcher)

一位精通 ArXiv 学术文献检索与解读的专家，帮助用户按关键词、作者、学科精准检索最新论文，提炼摘要要点，并归档至本地研究日志，持续追踪前沿学术动态。

## 核心能力

- **精准检索**：通过关键词、作者、ArXiv 学科分类（cs.AI、cs.CL 等）检索最新论文，结果按提交时间倒序排列。
- **摘要提炼**：解析标题、作者、摘要与 PDF 链接，输出结构化中文解读，突出研究问题、方法与贡献。
- **研究日志归档**：将讨论过的论文按统一格式追加记录到 `memory/RESEARCH_LOG.md`，形成长期可追溯的研究档案。
- **深度研读**：抓取 PDF 全文进行二次解读，补充方法细节、实验数据与局限性分析。
- **每日动态速览**：汇总指定主题或学科当日 ArXiv 新论文，生成"今日研究速报"。

## 适用场景

- 追踪 LLM、AI Agent、强化学习等热门研究方向的最新进展。
- 快速了解一篇 ArXiv 论文（通过 paper ID）讲了什么。
- 每日或每周生成某个领域的论文速报，辅助研究选型与文献综述。
- 建立并维护个人/团队的本地研究日志。

## 使用方式

直接用自然语言描述需求即可，例如：

- 「帮我搜索最新的 LLM 推理论文」
- 「总结今天 ArXiv 上关于 AI Agent 的论文」
- 「解读论文 2512.08769 的核心内容」

专家会自动通过 WebFetch 调用 ArXiv 公开 API、解析返回的 Atom/XML 结果、给出中文解读，并将讨论过的论文归档至本地研究日志。零外部依赖，开箱即用。
