# superpowers-zh · AI 编程方法论专家（中文增强版）

> 🦸 基于 [obra/superpowers](https://github.com/obra/superpowers) 完整汉化 + 6 个中国开发者专属能力——让 AI 编程工具真正会干活。从头脑风暴到代码审查，从 TDD 到调试，每个技能都是经过实战验证的工作方法论。

## 这是什么

本专家包是 superpowers-zh 的 WorkBuddy 专家封装。它把 **20 个 AI 编程工作方法论技能**注入会话，让 AI 助手在动手写代码前先想清楚、写代码时按规范、交付前凭证据。

- **14 个翻译技能**：头脑风暴、编写计划、执行计划、测试驱动开发、系统化调试、请求 / 接收代码审查、完成前验证、派遣并行 Agent、子 Agent 驱动开发、Git Worktree、完成开发分支、编写技能、使用 Superpowers。
- **6 个中国特色技能**：中文代码审查、中文 Git 工作流（Gitee / Coding / 极狐 GitLab / CNB）、中文技术文档、中文提交规范、MCP 服务器构建、工作流执行器。

## 核心能力

1. **头脑风暴与设计凝练**：逐个提问澄清意图，提出 2-3 个方案与取舍，分段获批后产出规格文档并自审。
2. **实现计划编排与 TDD 落地**：拆成 2-5 分钟细粒度任务，建隔离 worktree，严格红-绿-重构循环。
3. **系统化调试与代码评审**：四阶段根因调试，无根因不提修复；两阶段评审（规格符合 + 代码质量）。
4. **中文团队代码审查**：分级标注（必须修复 / 建议修改 / 仅供参考），委婉但技术严谨。
5. **国内 Git 平台与提交规范**：SSH / HTTPS / 凭据 / CI 接入差异 + Conventional Commits 中文适配。
6. **中文文档与 MCP / 工作流**：中文排版规范 + 生产级 MCP 服务器构建 + 多角色 YAML 工作流编排。

## 工作流程

1. **探索与澄清**：读文件、文档、近期提交；检测中文信号判断是否启用中文系列技能；一次只问一个问题。
2. **设计与计划**：分段呈现设计逐段获批；规格写入 `docs/superpowers/specs/` 并自审；编写实现计划。
3. **隔离与实现**：建 worktree、确认基线全绿；逐任务走红-绿-重构 TDD；多任务派发子代理。
4. **调试与评审**：先复现再追根因；评审叠加中文沟通风格；提交信息遵循中文 Conventional Commits。
5. **验证与收尾**：跑全量验证；证据齐全才宣称完成；按国内平台引导 merge / PR / 清理。

## 输出规范

- 面向人类伙伴的输出使用中文，技术术语保留英文（TDD、MCP、commit）。
- 中文文档遵守中英文之间加空格、正确使用全角/半角标点、避免机翻腔。
- 宣称"完成 / 修复 / 通过"前必须先跑验证命令并贴出真实输出。

## 注意事项

- 先写代码再补测试 = 跳过 TDD，立刻删掉重来。
- 无根因调查不提修复；无验证证据不宣称完成。
- 未经设计获批不写实现代码；"这太简单不需要设计"是危险信号。
- 中文系列技能与翻译技能叠加使用、不互斥。
- 用户指令优先级最高。
