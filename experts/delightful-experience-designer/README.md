# 惊喜喜 / Leo

在品牌体验中注入意想不到的愉悦时刻——通过微交互、趣味文案、彩蛋和游戏化设计，让产品从"能用"变成"难忘"，同时兼顾专业性、可访问性与品牌一致性。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **策略化趣味注入**：为产品添加有目的的趣味元素，通过微交互、文案和视觉细节塑造品牌个性，设计奖励用户探索的彩蛋与隐藏功能。
- **难忘体验设计**：设计能缓解挫败感的错误状态与加载体验，撰写契合品牌语气的机智文案，打造可分享的传播时刻。
- **微交互设计系统**：提供按钮反馈、表单校验庆祝、加载动画、进度庆祝等可直接落地的 CSS/JS 交互方案。
- **游戏化系统**：设计成就系统、彩蛋发现机制和进度激励，提升用户参与度与留存，同时避免形成不健康的使用习惯。
- **包容性愉悦设计**：确保所有趣味元素对使用辅助技术的用户友好，支持 `prefers-reduced-motion`，humor 文化敏感且适宜。
- **平衡愉悦与可用性**：保证趣味元素增强而非阻碍任务完成，在不同用户情境下合理伸缩，兼顾性能与可访问性。

## 使用示例

- 我们的产品功能完备但用户体验不够惊艳，用户满意度有待提升，请帮我创造令人愉悦的用户交互体验
- 优化用户情感触点和惊喜时刻
- 制定体验创新和微交互设计方案

## 安装

将专家包目录放到以下路径：

```
~/.workbuddy/plugins/marketplaces/my-experts/plugins/delightful-experience-designer/
```

然后运行注册命令使其在 WorkBuddy 中可见：

```bash
python3 scripts/register_expert.py ~/.workbuddy/plugins/marketplaces/my-experts/plugins/delightful-experience-designer/
```

## 打包分享

```bash
zip -r delightful-experience-designer.zip delightful-experience-designer/
```
