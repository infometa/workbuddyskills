# 股票智能分析

本技能提供多市场股票分析能力，支持个股分析、多股批量分析和大盘复盘。

## 分析结果结构 (AnalysisResult)

分析输出为结构化的「决策仪表盘」，包含四个核心部分：

1. **`core_conclusion`** — 核心结论：一句话总结、信号类型（买入/观望/卖出）、仓位建议
2. **`data_perspective`** — 数据透视：趋势状态、价格位置、量能分析、筹码结构
3. **`intelligence`** — 情报面：新闻摘要、风险警报、积极催化剂
4. **`battle_plan`** — 作战计划：狙击点（买/卖目标价）、仓位策略、风险控制清单

## 功能说明

### 1. 分析单只股票

**触发时机：** 用户要求分析特定股票时

**输入：**
- `stock_code` (str): 股票代码
- `strategy` (str, 可选): 指定分析策略，默认使用"多头趋势"

**输出：** 完整的决策仪表盘

**示例用法：**
- "帮我分析一下 600519"
- "用缠论分析平安银行"
- "AAPL 现在能买吗"

### 2. 分析多只股票

**触发时机：** 用户要求一次分析多只股票时

**输入：**
- `stock_codes` (List[str]): 股票代码列表

**输出：** 汇总决策仪表盘

**示例用法：**
- "帮我分析 600519, 000001, 300750"
- "对比一下茅台和五粮液"

### 3. 大盘复盘

**触发时机：** 用户要求市场概览、大盘总结或复盘时

**输出：** 结构化的市场复盘报告（指数表现、板块排行、资金流向、情绪指标）

**示例用法：**
- "今天大盘怎么样"
- "帮我复盘一下今天的市场"
- "A股市场概览"

### 4. 策略问股（多轮对话）

**触发时机：** 用户指定策略进行深度分析或多轮追问

**输入：**
- `stock_code`: 股票代码
- `strategy`: 策略名称

**示例用法：**
- "用波浪理论分析 000001，现在处于第几浪？"
- "从事件驱动角度看，最近的利好能支撑多少涨幅？"

## 可用策略

- `name`: 唯一标识

## 自定义策略编写指南

用户可以用自然语言描述自己的交易策略，系统会将其作为分析框架使用。

### 最简模板

```yaml
name: my_strategy          # 唯一标识（英文，下划线连接）
display_name: 我的策略      # 显示名称（中文）
description: 简短描述策略用途

instructions: |
  你的策略描述...
  用自然语言写出判断标准、入场条件、出场条件等。
```

### 完整模板

```yaml
name: my_strategy
display_name: 我的策略
description: 简短描述策略适用的市场场景

# 策略分类：trend（趋势）、pattern（形态）、reversal（反转）、framework（框架）
category: trend

# 关联的核心交易理念编号（1-7），可选
core_rules: [1, 2]

# 可选别名（用于自然语言策略选择）
aliases: [我的战法, 我的模型]

# 适配的市场状态标签
market_regimes: [trending_up]

# 策略详细说明（自然语言，支持 Markdown 格式）
instructions: |
  **我的策略名称**

  判断标准：

  1. **条件一**：
     - 描述你期望看到的趋势特征...

  2. **条件二**：
     - 描述量能要求...

  评分调整：
  - 满足条件时建议的 sentiment_score 调整
  - 在分析结论中注明策略名称
```

### 核心交易理念参考

| 编号 | 理念 | 说明 |
|------|------|------|
| 1 | 严进策略 | 乖离率 < 5% 才考虑入场 |
| 2 | 趋势交易 | MA5 > MA10 > MA20 多头排列 |
| 3 | 效率优先 | 量能确认趋势有效性 |
| 4 | 买点偏好 | 优先回踩均线支撑 |
| 5 | 风险排查 | 利空新闻一票否决 |
| 6 | 量价配合 | 成交量验证价格运动 |
| 7 | 强势趋势股放宽 | 龙头股可适当放宽标准 |

### 策略编写技巧

1. **写明判断标准** — 越具体越好，避免模糊描述
2. **给出评分调整** — 告诉系统满足条件时如何影响评分
3. **包含风险条件** — 什么情况下策略失效或需要止损
4. **关联核心理念** — 与 7 条核心理念建立联系，系统会据此协调
5. **指定适用行情** — 避免在不适合的市场环境中误用

### 自定义策略与内置策略的关系

- 用户在对话中描述的策略会被实时解析和应用
- 如果自定义策略名称与内置策略冲突，自定义策略优先
- 用户可以要求"组合使用"多个策略（如"同时用缠论和情绪周期分析"）
- 多策略分析时，各策略独立评分，最终取加权综合
