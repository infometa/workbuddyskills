# Visual QC

视觉 QC 在 S4 机读门禁之后执行，不能用“脚本成功”代替真实视觉检查。

## 1. 三秒测试

逐页用三秒回答：

1. 第一眼看到的是否是行动标题或唯一视觉锚点？
2. 能否说出本页唯一主张？
3. 正文/图表是否明显在证明标题，而非提供旁支信息？

任一答案为“否”，返回 Page Brief 调整层级、版式或信息密度。

## 2. Storyline 与标题

- 标题连读可独立讲清背景、发现、含义、建议与行动。
- 每个内容页只有一个主张；标题不是“市场概览”等标签。
- Executive Summary 与正文关键结论、数字和建议一致。
- Hero / Supporting / Transition 与 Peak / Valley / Transition 有节奏变化。
- Hero 建议占 20%-30%；非对称版式建议不少于 40%；相邻版式不机械重复。

## 3. 网格、字体与颜色

- 16:9 页面；主网格、左右边距、标题线和页脚线全篇一致。
- 使用包内统一主题与可用系统字体；不依赖麦肯锡定制字体。
- 字号层级有限且稳定：封面、行动标题、分组标题、正文、来源。
- 正文不得靠缩到 8pt 以下解决溢出。
- 一页以中性色为主，仅用一个强调色指出唯一信息。
- 深色背景文字具有足够对比度；无随机渐变、阴影和装饰图标堆砌。

## 4. 图表

- 图表类型匹配比较关系：趋势、类别、构成、归因或相关性。
- 标题直接陈述图表结论；图表只强调一个信息。
- 坐标轴、单位、时间范围、预测区间和口径完整。
- 颜色具有语义且跨页一致；不使用彩虹配色。
- 数据标签不重叠、不截断，图例不溢出。
- [A]/[E] 数据在图表或脚注明示，不伪装为事实。

## 5. Source、Footnote 与页码

- 每个内容页有可读 Source；来源与 Evidence Map 一致。
- Footnote 解释定义、范围、舍入和预测方法，不替代 Source。
- 页码连续并显示 `N/total`；Appendix 延续同一总页数。
- 封面、章节、结束页可不显示 Source，但不得破坏页序。

## 6. 占位符与完整性

逐页扫描：`TODO`、`TBD`、`[Insert`、`lorem`、`source=xx`、孤立 `xx`、空图表、空表格、默认示例数据、图片占位框。任何明显占位符均为阻断项。

同时检查：

- 同一数字跨页口径一致，合计与分项可调和。
- 标题数字与图表数字一致。
- 目录、章节名、Executive Summary、正文和 Appendix 互相引用正确。
- 无截字、乱码、越界、意外重叠、大面积无意留白。

## 7. 可编辑性

- 文本、图表、表格和基础图形保持可编辑；不得把整页栅格化伪装成 PPT。
- 图片有清晰用途和合法来源；无低分辨率截图替代可编辑图表。
- 打开、保存、复制页面后文件结构正常，XML 中无 `<p:cxnSp>` connector。

## 8. 渲染与降级

### 标准门禁

使用 PowerPoint、LibreOffice 或等价真实渲染器将所有页面输出到 `preview/`，按页检查并记录阻断项。机读 `gate_result.json.passed=true` 与全量视觉检查均通过，才可声称视觉门禁通过。

### 降级门禁

真实渲染工具不可用时：

1. 优先用 `qlmanage` 生成 Quick Look 首屏预览。
2. 用 python-pptx 逐页读取标题、文字、页码、形状和图表结构，输出 `structure_preview.json`。
3. 若 Quick Look 也失败，标记 `mode=structure_only`，不得把结构报告称为视觉预览。
4. 在交付说明中明确写：`视觉门禁已降级：仅完成首屏/结构化逐页检查，未完成全量真实渲染。`
5. 不得写“全量渲染通过”“逐页视觉确认通过”等无法证实的结论。

降级不是自动通过；发现阻断项仍须返回 D3-D5 修复。
