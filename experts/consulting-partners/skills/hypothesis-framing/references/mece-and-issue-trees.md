# MECE 与议题树拆解

## MECE 是什么

MECE（Mutually Exclusive, Collectively Exhaustive，互斥穷尽）是一种分解原则：把一个问题、一组选项或一个群体拆成若干子部分，子部分之间不重叠（互斥），子部分加起来覆盖全部相关范围（穷尽）。核心检验方法是"加总检验"——把所有子部分加起来，是否等于原本的整体；加不回去，说明分解本身是错的，不是数据的问题。

MECE 不是分析本身，它是分析的骨架。一个漂亮的 MECE 分解图如果没有配上真实的调查和判断，只是"墙上的装饰画"——好看但不产生洞察。

## 什么时候需要 MECE 拆解

- 问题的范围大到无从下手，需要先划清楚看的维度
- 手头有一堆选项，彼此界限模糊、有重叠
- 分析陷入循环，同样的争议反复出现，因为没有把它们真正分开
- 团队正在收敛到一个假设，但没有先看过完整的可能性空间

不需要 MECE 的场景：问题本身很小（决定中午吃什么不需要议题树）；处于纯发散、创意生成阶段（过早的结构化会限制探索）；分解方式已经是行业公认的标准做法（不需要每次重新发明）。

## 拆解流程

1. **精确定义整体**。"我们公司的问题"不是一个可拆解的整体，"本财年按客户细分的营收"才是。整体必须是可测量、有边界的对象。
2. **提出一个顶层拆分**（2-7 个类别）。常见的拆分维度：客户细分、地域、产品线、时间周期、公式成分（如收入=价格×数量）、生命周期阶段、原因类型。
3. **检验互斥性**：任取两个分支，是否存在同时属于两者的情形？如果存在，说明分类边界没画对，需要重新调整（比如按量化阈值重新划分，而不是用"大客户"和"重要客户"这种天然重叠的模糊说法）。
4. **检验穷尽性**：有没有一种情况不属于任何一个分支？如果有，明确加一个"其他"分支，或者重新考虑拆分维度本身是否合适。
5. **加总检验**：所有分支加起来是否等于整体？这是最可靠的检验，跳过它，破损的分解看起来会"感觉上没问题"。
6. **按需递归**：对承载了主要信息量的分支继续做下一层 MECE 拆解，直到每个叶子节点都是可以直接采取行动的具体问题。
7. **识别载重分支**：按照二八原则，通常有一到两个分支承载了不成比例的信息量和决策权重，找出它是分析优先级排序的关键。

## 常见的假 MECE（容易踩的坑）

- **声称 MECE 但没做检验**："这三个选项"不因为你说了它是 MECE 就真的是——必须做重叠检验和缺口检验。
- **分类之间明显重叠**："大客户"和"重要客户"——这两个词描述的是同一批人,需要按量化指标重新切分直到互不重叠。
- **遗漏了残余类别**：地域拆分成"北美/欧洲/亚洲"却漏掉了拉美和非洲——加一个显式的"其他"分支。
- **选错了拆分维度**：按产品线拆分本身没毛病，但真正决定结果的是客户购买模式这个维度——尝试2-3种不同拆分方式再决定用哪个。
- **对琐碎问题动用 MECE**：午饭吃什么不需要议题树，把 MECE 用在真正复杂的问题上。
- **拆得太深**：超过可执行层级继续往下拆，只会制造复杂度而不产生新洞察。
- **"其他"分支占比过大**：如果"其他"类别囊括了超过三成的整体，说明拆分维度本身选错了，需要换一个维度重新来。
- **不做加总检验**：算术检验是最可靠的 MECE 检验，跳过它会让破损的分解看起来没问题。
- **把 MECE 本身当成分析**：MECE 产出的是结构，真正的分析发生在结构内部——一张 MECE 图没有配合调查，只是墙上的装饰画。
- **只考虑一种分解方式**：多数分析上的分歧本质是"该按哪个维度拆"的分歧，考虑 2-3 种维度再决定用哪个。

## 议题树 vs 假设树

议题树拆解的是**问题空间**——用于团队还不确定该看哪个维度的阶段，穷尽列出所有可能相关的子问题，暂不下结论。

假设树承诺的是**一个答案**——用于团队已经有较强直觉、想高效验证的阶段，顶层是一个具体的 Day-1 猜测，往下拆成 2-3 个支撑性子命题，每个子命题配一个能证伪它的具体测试。

两者是互补关系：通常先做议题树摸清问题的完整范围，再在议题树的某个分支上做假设树，快速验证一个具体方向，而不是对整个问题空间做同等深度的调研。跳过假设树、只停留在议题树阶段，是很多战略分析拖延数周却拿不出决定性结论的常见原因——因为议题树只回答"我们该看什么"，不回答"答案更可能是什么"。

## 验证清单

- [ ] 整体被精确定义且可测量
- [ ] 顶层拆分维度已明确说明，并考虑过至少一种备选维度
- [ ] 每一对分支之间都做过互斥检验
- [ ] 做过穷尽检验（缺口测试）
- [ ] 分支加总能还原到整体（算术检验）
- [ ] 每个叶子节点都是可执行的，而不是继续可拆解的
- [ ] 已识别出承载主要信息量的载重分支
