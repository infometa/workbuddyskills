# 框架库速查（14类核心分析框架）

本文档给出常用管理咨询框架的原理、适用场景和常见误用，作为选型时的快速参考。每个框架只用一段话讲清楚"什么时候该用、什么时候不该用",不做教科书式的展开——框架的价值在于应用，不在于背诵。

## 一、战略与环境分析

**PESTEL（政治/经济/社会/技术/环境/法律）**：用于判断宏观环境对一个市场进入或长期战略决策的影响。误用：把它当成万能的"背景介绍"章节，塞进每一份报告里但不影响任何结论——如果某个维度对当前决策没有实质影响，就不必展开。

**波特五力模型**：分析一个行业的结构性盈利能力（供应商议价权、买方议价权、新进入者威胁、替代品威胁、同业竞争烈度）。误用：把它当成每个战略问题的默认起手式。只有当"这个行业结构本身是否吸引人"是真正的决策问题时才用。

**VRIO（价值/稀缺性/难以模仿/组织化）**：判断企业的某项资源或能力是否构成真正的竞争优势。适合尽职调查和核心竞争力评估,不适合用来分析市场机会本身。

## 二、市场与增长分析

**安索夫矩阵（市场渗透/市场开发/产品开发/多元化）**：用于选择增长路径。四个象限风险递增,应当按顺序考虑,而不是一上来就跳到风险最高的多元化选项。

**波士顿矩阵 / GE-麦肯锡九宫格**：多产品组合的资源配置决策。误用：只有单一产品线的企业用这个框架毫无意义——它解决的是"钱该投在哪个业务"而不是"这个产品该不该做"。

**TAM-SAM-SOM（潜在市场/可服务市场/可获得市场）**：市场规模测算,用于判断一个机会值不值得投入。必须同时做自上而下和自下而上两种测算并交叉验证,只做一种容易被极端假设带偏。

**产品生命周期**：判断产品/市场处在导入期、成长期、成熟期还是衰退期,影响该用进攻性还是防御性策略。

## 三、消费者与行为分析

**消费者决策旅程（认知→考虑→评估→购买→忠诚）**：用于定位用户流失或转化的关键卡点,比笼统地问"用户体验怎么样"更精准。

**用户待办任务模型（JTBD）**：从"用户想完成什么任务"而不是"用户的人口统计特征"出发理解需求,适合产品创新方向判断,不适合精细化的营销渠道分配。

**RFM 模型（最近购买/购买频率/购买金额）**：客户价值分层,适合精细化营销和客户分级运营,不适合判断整体市场机会大小。

## 四、财务与估值分析

**杜邦分析（净利率×资产周转率×权益乘数）**：把 ROE 拆解成可归因的驱动因素,用于财务健康诊断,快速定位"利润下滑是因为利润率、周转效率、还是杠杆变化"。

**DCF（自由现金流折现）**：企业或项目的内在价值测算,核心风险是对长期增长率和折现率的假设高度敏感,必须配合敏感性分析使用,不能只给一个点估计。

**可比公司分析（PE/PB/EV-EBITDA倍数）**：相对估值,依赖找到真正可比的同业公司,选错可比公司组会导致结论系统性偏差,选择可比公司的逻辑本身要在报告里说清楚。

## 五、竞争与战略定位

**标杆对比**：逐项对比关键指标找差距,适合发现"具体哪个指标落后",但发现差距之后需要归因分析,不能停留在"我们比对手差"这一步。

**战略群组图**：把竞争者按两个关键维度分布在图上,用于发现"空白定位区间",适合竞争格局梳理,前提是选对两个真正区分竞争者的维度,而不是随手选两个容易画图的指标。

**价值链分析**：把企业活动拆成主要活动和支持活动,定位成本优势或差异化优势的真正来源,常与利润树配合用于成本削减类问题。

**蓝海战略（四动作框架：剔除-减少-提升-创造）**：用于寻找差异化的新市场空间,只有当"开辟新价值曲线"是真实可行的选项时才用,不要把它硬套在渐进式产品改进上。

## 六、产业与供应链分析

**产业价值链拆解（上游-中游-下游）**：理解一个行业的结构和利润分布,是行业研究报告最基础也最容易做糙的部分——真正有价值的产出是指出"哪个环节的利润弹性最大",而不是罗列每个环节有哪些公司。

**技术成熟度曲线（技术触发→期望膨胀顶点→泡沫破裂低谷→稳步爬升→生产成熟高原）**：判断一项新兴技术当前所处的采用阶段,用于新技术投资时机判断。

## 框架组合的原则

单个框架很少能独立解决一个真实的商业问题,通常需要2-4个互补框架组合使用,例如:
- 市场进入决策 = 五力模型（行业是否值得进入）+ TAM-SAM-SOM（市场够不够大）+ 安索夫矩阵（用什么姿势进入）
- 组织变革诊断 = 7S框架（内部一致性问题在哪）+ 利益相关方图谱（谁会推动/阻碍变革）
- **竞争格局/行业结构题（structure）= 波特五力（结构性盈利能力）+ 集中度与份额演变（CRn、HHI、各梯队份额趋势）+ 价值链利润分布（微笑曲线，哪个环节利润弹性最大）+（可选）战略群组图**。这是"问题决定框架"的标准动作。**严禁用"个股风控决策仪表盘/评分环/核心配置·弹性配置·回避清单/看多看空触发价位"这类选股模板回答格局题**——那是"模板决定问题"，把行业结构命题稀释成配置建议的注脚，属于投研串戏，一律禁止。

选择组合时要检查两点:框架之间是否真的互补而非重复覆盖同一个维度;每个框架所需要的数据是否真的能获取到,拿不到数据支撑的框架就要降级或替换,不要为了"看起来全面"硬凑。
