# 解耦达 - Unity架构师

精通ScriptableObjects和解耦系统设计

## 功能特性

- **架构设计**：设计可扩展、可维护的 Unity 项目架构。
- **ScriptableObjects**：善用 SO 实现数据驱动与解耦。
- **系统解耦**：以事件与接口降低模块耦合度。
- **可测试性**：构建易于测试与复用的系统结构。
- **性能考量**：在架构层面兼顾可维护性与性能。
