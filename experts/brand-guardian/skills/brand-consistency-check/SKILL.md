# Brand Consistency Check

## Overview

Use this skill to verify that an asset — or a whole channel — stays on-brand before it ships, and to run recurring brand audits. It pairs with the `brand-guidelines` skill (visual standards) and the `brand-voice-messaging` skill (verbal standards).

**Keywords**: brand audit, consistency check, QA, review checklist, brand compliance

## When to use

- Reviewing a design, page, email, or social asset before publishing
- Running a periodic (monthly / quarterly / annual) brand audit across channels
- Diagnosing and fixing common brand-consistency issues

## References

- **`references/consistency-checklist.md`** — Visual (logo / color / typography / imagery), voice (tone / language / messaging), and per-channel checklists (website, social, email, collateral), plus a common-issues → fix table and recommended audit frequency.

## How to apply

1. Pick the relevant checklist sections for the asset or channel under review.
2. Mark each item; log any failures against the common-issues → fix table.
3. For periodic audits, follow the audit-frequency table to schedule coverage across channels.
