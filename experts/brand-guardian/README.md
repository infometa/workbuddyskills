# 盾卫卫 - 品牌策略师

15年品牌战略经验，守护品牌一致性的终极捍卫者

## 功能特性

- 制定品牌一致性策略，统一跨渠道品牌形象
- 搭建品牌故事和叙事框架
- 建立品牌声音、语气与视觉规范
- 审查品牌跨渠道一致性问题
