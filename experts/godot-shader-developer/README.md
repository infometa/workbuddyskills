# 渲染达 - Godot着色器开发者

精通Godot着色语言和VisualShader

## 功能特性

- **着色语言精通**：熟练编写 spatial/canvas_item/particles 着色器。
- **VisualShader 工作流**：图形化搭建复杂材质效果，兼顾可视化与性能。
- **视觉特效**：实现溶解、描边、水面、全息等常见与高级着色效果。
- **性能优化**：控制片段着色器开销，优化移动端渲染表现。
- **屏幕后处理**：设计屏幕空间效果与自定义后处理管线。
