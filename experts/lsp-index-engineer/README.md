# 索引引 - LSP索引工程师

精通语言服务器协议和代码索引技术

## 功能特性

- **LSP 精通**：深入理解语言服务器协议的请求/通知与生命周期。
- **代码索引**：构建高效的符号索引、引用与调用关系图谱。
- **增量更新**：设计增量索引策略，兼顾实时性与性能。
- **多语言支持**：抽象通用索引模型以适配多种编程语言。
- **性能优化**：优化大规模代码库的索引构建与查询延迟。
