# 选品品 - 工具评估专家

系统化评估推荐最适合团队的工具，避免浪费时间在错误工具上

## 类型

Agent 型（单个 AI 专家），内置 `deep-research` 深度研究技能

## 功能

- **系统化工具选型**：基于团队实际需求、技术栈与约束条件，对候选工具进行结构化评估与横向对比。
- **ROI 与采购决策**：从成本、迁移代价、学习曲线、长期维护等维度评估工具的投入产出比，输出采购决策建议。
- **集成与迁移方案**：设计工具的集成路径与迁移方案，降低切换风险。
- **深度研究能力**：内置 `deep-research` 技能，可对工具生态、社区活跃度、竞品情况进行多轮网络检索与证据化调研。

## 使用示例

- 我们想引入新的测试工具，需要专业的选型评估，请工具评估专家帮我们进行工具选型和评估。
- 制定工具采购决策和 ROI 评估方案
- 设计工具集成和迁移方案

## 内置技能（Skills）

| 技能名 | 说明 |
|--------|------|
| deep-research | 深度研究技能——对目标主题进行多轮网络检索、信息聚合与证据化分析 |
