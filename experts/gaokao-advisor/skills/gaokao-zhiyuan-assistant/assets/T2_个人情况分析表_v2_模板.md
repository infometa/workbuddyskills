# T2 · 个人情况（软画像）字段清单

> **用途**：本文件登记「软画像」评估维度，作为 SKILL.md **阶段三对话探索**时软画像话术的**字段参考**。
> **使用方式**：软画像**不再单独收表/发卡**——分数情况（省份/选科/分数/位次/各科成绩/可接受亏分）在阶段二对话内复述核对；下方软画像维度在阶段三对话里**自然穿插问出**，聊到即记录，作为专业解读与匹配说明的依据。
> **不必逐项追问**：四组（地域倾向 / 经济能力 / 个人偏好 / 未来规划）每组至少了解到 1 项即可；MBTI / 霍兰德仅在用户主动提及时作辅助参考。

## 使用要点

- 软画像是**解读与匹配说明的依据**，不是硬过滤条件；主观信息在产物中标"仅供参考"。
- 用户已在对话里表达过的软画像项，直接记入偏好清单（第四节），不必再问。
- 分数情况、选科等硬约束以阶段一对话收集与阶段二对话核对为准，软画像不覆盖硬约束。
