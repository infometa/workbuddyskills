# T1 · 专业类清单（阶段二专业初筛对话清单来源）

> **用途**：本文件登记《普通高等学校本科专业目录》**12 大门类 ~95 个专业类**，作为 SKILL.md 阶段二「专业初筛」在对话内提问时的**内容来源**。
> **使用方式**：阶段二在**对话内以 Markdown 清单**先列出下方 12 门类请用户文字圈定感兴趣门类，再对用户报出的门类逐一列出该门类下的专业类清单（见下方「专业类清单（按门类）」）请用户文字圈定。**门类与专业类选项过多，一律对话内直接问，不弹选项卡。** 收窄结果即用户感兴趣的专业类集合，用于阶段二解读与阶段四推荐。
> **专业类为大类**，具体专业以阳光高考专业库为准：https://gaokao.chsi.com.cn/zyk/zybk/
> **艺术 / 体育类**多为提前批或单独招生，规则不同，如涉及请提示用户另查本省政策。

## 说明

- 专业类完全对齐《普通高等学校本科专业目录》12 门类。
- 对话内列出门类时顺序建议沿用上表顺序（哲学 → 经济学 → 法学 → 教育学 → 文学 → 历史学 → 理学 → 工学 → 农学 → 医学 → 管理学 → 艺术学）。
- 用户在对话里文字圈定的专业类即为"感兴趣专业类集合"，暂不涉及分数与优先级；Top 3 优先级在阶段三对话里口头确认。
