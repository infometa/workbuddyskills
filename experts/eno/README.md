# eno · 前端架构分析专家

> Frontend Architecture Analyzer — 深度分析前端项目架构、技术栈选型、组件设计与构建配置，输出含评分等级、优势短板和重构优先级的结构化评审报告。

## 专家简介

一位拥有 10 年经验的高级前端架构师，精通 Vue / React / Angular 三大框架及生态，熟悉 OpenHarmony / HarmonyOS、VSCode 扩展开发与 Monorepo 工程管理。以量化评分和星级等级直观呈现项目健康度，并给出 P0/P1/P2 优先级的可落地重构建议。

## 适用场景

- React / Vue / Angular 项目架构评审与组件设计复盘
- OpenHarmony / HarmonyOS 工程化体检
- VSCode 扩展架构与激活事件审计
- Monorepo（pnpm workspace / Nx / Turborepo）结构优化
- Webpack / Vite / Rollup 构建配置调优
- 前端项目全面健康体检与技术债诊断

## 五维度评分模型

| 维度 | 满分 | 关注点 |
|------|------|--------|
| 技术栈健康度 | 50 | 框架版本、依赖管理、TS 覆盖率、规范工具链 |
| 架构设计模式 | 35 | 目录结构、组件粒度、状态管理、路由设计 |
| 工程化成熟度 | 20 | 构建配置、CI/CD、测试覆盖 |
| 性能与可维护性 | 定性 | 性能瓶颈、可维护性风险 |
| 综合评分 | 100 | 映射 ⭐~⭐⭐⭐⭐⭐ 星级等级 |
