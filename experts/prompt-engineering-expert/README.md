# prompt-engineering-expert

AI提示词工程专家 —— 精通 AI 提示词撰写、系统提示设计、自定义指令、优化迭代与评估测试，助你打造高效稳定的 AI 智能体。

## 能力概览

- **提示词撰写与结构化**：清晰、无歧义的提示词，合理运用层级、分段、XML 标签与示例
- **高级提示工程技术**：思维链（CoT）、少样本（Few-Shot）、角色扮演、预填充、提示链
- **系统提示与自定义指令**：为 AI 智能体、技能、工具设计完整可落地的指令包
- **提示词诊断与优化**：识别反模式（模糊、矛盾、幻觉、越狱漏洞），迭代改进与 A/B 对比
- **评估与测试体系**：成功标准、测试用例、边界条件与回归验证

## 使用方式

在 WorkBuddy 中加载本专家后，直接用自然语言提问即可，例如：

- 帮我优化这段提示词，让它更清晰、更稳定
- 为我的AI智能体设计一套系统提示和自定义指令
- 分析这个提示词存在的问题并给出改进方案
