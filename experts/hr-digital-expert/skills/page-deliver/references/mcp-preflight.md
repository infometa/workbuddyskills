# MCP 服务预检（HARD-GATE）

> ⚠️ 启动序列首要步骤。失败即**阻塞 skill**，不落盘，每次进入流程都重检（含断点续传/重新部署）。先于"快速跳过"规则。
>
> 本文件只描述**怎么执行**预检；预检失败的诊断输出与修复指引由 `handbook.md` 接管。

## 必查项

| 服务 | tool | 用途 |
|------|------|------|
| `hr_data_service_v1` | `check_version` | 数仓元数据 / 代码生成（数仓场景必需） |

## 流程

1. 检查会话内是否存在目标 tool（`hr_data_service_v1.check_version`）
2. 全在 → 通过，输出"通过输出"，继续后续启动步骤
3. 任一缺失 → 进入错误处理（按全局错误处理规则查 handbook）

## 通过输出

```
✅ MCP 服务检查通过：
   - ✅ hr_data_service_v1
```
