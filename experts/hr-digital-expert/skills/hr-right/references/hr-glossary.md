本知识库包含人力资源领域的专业术语、简称及其同义词映射。在理解用户问题时，请参考此知识库进行术语识别和意图理解。

> 共收录 **249** 条术语，其中 **138** 条包含同义词映射。

## 通用术语（50条）

人力资源领域的通用专业术语，包括岗位分类、管理层级、绩效评估、招聘类型等基础概念。

### PA
- **解释**：人力分析。人力分析是指用大数据的方式去尝试解决一些HR领域里面的问题的岗位。

### 中高干
- **解释**：管理职级L3及以上管理者，含L3、L4、L5、L6

### 飞龙计划
- **解释**：公司内部针对高潜总监（基干）的培训课程

### 保温
- **解释**：保温就是人才保温，比如候选人接受offer到入职这段时间，我们需要去做保温的工作来让候选人不撤销offer，增强对人才的保留与吸引

### 二合一项目
- **解释**：二合一项目 为月薪调整 (薪酬回顾）与年度授予，一般在年中（7/8月份）进行

### 选育用留
- **解释**：指人才的选拔、培育、任用、和保留

### 主兼岗
- **解释**：指员工在公司内，同时担任1个主要岗位（主岗）和多个兼任岗位（兼岗）。兼职指的是在公司外，兼岗指的是在公司内担任职务。

### 兼岗
- **解释**：除了主岗外，兼任集团内其他岗位，它与兼职完全不同。

### 管理者
- **解释**：通常用是否拥有【管理职级】判断员工是否为管理者，特殊情况下，也有按照汇报链通过是否有汇报下级的定义口径
如果用户提到的是管理者，则指所有管理者，无需填充管理职级字段。当用户指定特定的管理职级时，如L2-1、组长级（L1-1，L1-2）时，才需要按枚举值填充管理职级字段。
- **同义词**：干部 / leader / 团队负责人 / 管理干部 / 负责人

### 高绩效
- **解释**：指"绩效等级"为"Outstanding"，"5星"、"优秀"是绩效等级的历史码值，除非指定历史码值查询，常规不使用
- **同义词**：5星 / outstanding

### Underperform
- **解释**：【绩效等级】=Underperform
- **同义词**：2星 / 2星及以下

### 异动
- **解释**：员工异动活动包含调动、管理晋升降免、专业晋升降职、入职、离职等任职变动活动。

### 专家
- **解释**：指专业职级在12级及以上的集团正式员工，是员工的子集。

### 专业员工
- **解释**：专业员工是指不包含管理者在内的各职位族的员工，例如 T族(技术族)、S族(交付族)、P族(产品族)

### 专业职级

## 数据分析报告术语（47条）

常见的人力资源数据分析报告类型及其核心分析维度说明。

### 人才结构分析
- **解释**：1. 职级/层级结构，组织内不同职级（如高层、中层、基层）、职等（如P7/P8/P9、M1/M2/M3等）的人员分布情况
2. 年龄结构，员工按年龄段（如25岁以下、26-35岁、36-45岁、46岁以上）划分的分布。
3. 学历/专业结构，员工学历分布（如博士、硕士、本科、大专及以下）、所学专业类别（如计算机、工程、管理、人文等）。
4. 职能/部门结构，人才在不同职能部门（如研发、产品、运营、市场、销售、HR、财务、行政等）的分布。
5. 司龄/入职时间结构，员工按照入职时长（如0-1年、1-3年、3-5年、5年以上）分组。
6. 性别/地域/民族等多元结构（可选），性别比例、工作地点（如一线/二线城市、海外/国内）、民族、国籍等。
- **同义词**：人员结构 / 人力盘点

### 离职分析
- **解释**：流失规模：总离职人数、各部门/岗位离职人数、离职率（离职人数/平均人数）。
群体特征：离职员工的职级、司龄（如0-1年/1-3年）、年龄、岗位类型。
时间趋势：离职率的时间变化（如近6个月/年度同比）。
原因分析：主动离职 vs 被动离职（裁员）、常见离职原因（薪资低/晋升难/工作强度大）。

### 绩效分析
- **解释**：1. 绩效等级分布，不同绩效等级的员工人数及占比。
2. 部门绩效差异，各职能部门或业务部门的整体绩效水平对比。
3. 岗位绩效表现，不同岗位（如技术岗、销售岗、运营岗等）的绩效分布情况。
4. 绩效随时间变化，员工个人或团队绩效在多个考核周期（如季度、年度）的变化趋势。
5. 绩效与司龄关系，不同司龄段（如0 - 1年、1 - 3年、3 - 5年等）员工的绩效表现。
6. 绩效与职级关系，不同职级员工的绩效分布。
7. 绩效与薪酬关联，绩效结果与薪酬调整、奖金发放的对应关系。
8. 绩效影响因素，影响员工绩效的内外部因素（如培训情况、团队氛围、业务难度等）。

### 异动分析
- **解释**：1. 晋升分析：各层级/职级的晋升人数、晋升比例、晋升周期（从入职或上一职级到当前职级的时间）、晋升的主要岗位和部门分布。  
2. 降职/职级调整分析：降职或职级下调的人数、涉及的部门与岗位、降职的主要原因（绩效不达标、组织架构调整等）。  
3. 流入流出分析  
4. 异动时间规律：员工异动（晋升、调岗、降职等）的时间分布（如季度、年度高峰期）、与业务周期或组织调整的关联。  
5. 异动人群特征：发生异动的员工的年龄、司龄、学历、性别等基本属性分布，以及与异动类型之间的关系。  
6. 异动原因分类：主动申请 vs 被动安排（如组织安排、绩效调整）、具体原因细分（如职业发展、业务需要、绩效不佳等）。  
7. 异动对组织的影响：异动后员工绩效变化、留任率、对部门或团队运作的影响评估。

### 合同续签分析
- **解释**：1. 续签情况：合同续签率（续签人数/到期合同总数）、不同部门/岗位的续签率、续签员工与未续签员工比例。  
2. 离职规模：总离职人数、各部门/岗位离职人数、离职率（离职人数/平均在职人数）。

## 改写规则（6条）

### 美洲

- **解释**：如出现“城市名称+办公室”、“城市名称+office”、“base+城市名称”、“base地+城市名称”，都是指“工作地”=“城市名称”

## 权限业务术语（26条）

HR权限申请场景中涉及的专业术语、系统简称、领域名称与角色/权限包名称的同义词映射。用于智能填单时的语义匹配扩展。

### 激励
- **解释**：指薪酬激励领域。在HR权限体系中，"激励"是"薪酬"领域的官方名称前缀，用于角色名和权限包名。
- **同义词**：薪酬 / 薪资 / 工资 / 薪酬激励 / 薪酬运营 / Compensation / comp / C&B

### CoE
- **解释**：Center of Excellence，专家中心/卓越中心。在HR权限体系中常作为角色名称后缀，表示某领域的专家角色，如"激励COE-海外角色"。
- **同义词**：COE / coe / 专家中心 / 卓越中心

### E系统
- **解释**：组织与人员调整系统(E系统)，用于管理组织架构调整和人员异动操作。
- **同义词**：组织与人员调整系统 / 组织人员调整 / 组织调整系统 / 组织架构调整 / 人员调整系统 / 组织与人员调整系统(E系统)

### 权限平台
- **解释**：HR权限平台，用于管理HR系统的角色权限、权限包、权限项配置。
- **同义词**：HR权限平台 / 权限中台 / 权限管理平台 / 权限管理系统

### SSC
- **解释**：Shared Service Center，HR共享服务中心。在权限体系中有多个SSC相关角色和权限包。
- **同义词**：共享服务中心 / HR共享 / 共享中心 / HR-SSC / HRSSC

### 小T
- **解释**：SSC智能问询机器人的名称，在权限包中与"SSC知识运营人员"关联。
- **同义词**：SSC机器人 / 问询机器人 / SSC智能机器人

### 伯乐

### HRBP

### 核心人事

### 学发

### 权限资源

### 面试官

### 单据查询

### 管理主体
- **解释**：HR权限维度之一，用于区分员工的管理归属。常见码值包括"全资-直管"、"合资"等。
- **同义词**：管理归属 / 管理实体

### 海外HR权限
- **解释**：指海外体系HR业务权限，通常涉及的维度包括"合同地"、"工作地"等，码值使用地区名称（如"亚太"、"美洲"、"欧洲"、"中东及非洲"）。
- **同义词**：海外权限 / 海外人力资源权限 / 海外体系权限

### 扩充
- **解释**：在权限申请场景中，"扩充"表示对已有权限范围进行扩大，属于"变更"场景而非"新增"场景。
- **同义词**：扩大范围 / 扩展范围 / 扩大权限 / 增加范围 / 范围扩充
