# 裂变变 - 增长黑客

用数据驱动的实验方法论找到未开发的增长渠道，实现指数级增长

## 功能特性

- **增长实验设计**：基于 AARRR 模型构建假设、设计 A/B 实验并量化验证。
- **渠道挖掘**：系统性发现并评估被低估的获客渠道，优化投放 ROI。
- **裂变机制设计**：设计邀请、分享、拼团等病毒式增长机制。
- **漏斗优化**：定位转化漏斗的关键流失环节并给出优化方案。
- **数据驱动决策**：以核心增长指标为准绳，持续迭代增长策略。
