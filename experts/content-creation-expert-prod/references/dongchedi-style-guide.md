# 懂车帝博主写作风格指南

> 本文档从懂车帝博主(ID: 99436225486)的5篇代表性文章中提取，作为"懂车帝"平台风格的写作规范。auto-writer 选用 D 模板时**必须**严格遵守本指南。

## 一、标题公式

### 格式模式

```
{事件/状态}+{车型全称}{核心亮点}，{参数卖点1}+{参数卖点2}，{补充信息}
```

### 标题特征

- 用逗号分隔 2-3 个信息块
- 核心参数前置（尺寸/续航/动力）
- 善用感叹号或问号增强情绪（本代最后一次改款！）
- 具体数字优先于模糊表述（"车长近5.3米" 而非 "超大车身"）
- 用加号 `+` 连接并列卖点

### 样本标题

- "魏牌V9X实拍曝光，车长近5.3米+2.0T插混，纯电续航超400km"
- "瞄准25万级年轻人市场，问界M6大量实车曝光，有爆款气质吗？"
- "2026年重磅MPV车型盘点，都有增程动力，智界V9/问道V9/零跑D99"
- "升级双14.6英寸大屏+Flyme车机，新款星越L长风版配置曝光"
- "本代最后一次改款！2026款奔驰GLB实车到店，取消四驱/配置升级"

## 二、文章结构（固定顺序）

### 单车型文章结构

```
1. 引入段（1段）
2. 外观 - 车头（1段）
3. 外观 - 侧面（1段）
4. 外观 - 车尾（1段）
5. 内饰（1-2段）
6. 配置亮点（1段）
7. 动力（1段）
8. 市场定位/竞品分析（1段）
9. 互动结尾（1-2句）
```

### 盘点类文章结构

```
1. 引入段（行业背景+盘点主题）
2. 车型A：简介 → 外观 → 内饰（可选）→ 动力
3. 车型B：简介 → 外观 → 内饰（可选）→ 动力
4. 车型C：简介 → 外观 → 内饰（可选）→ 动力
5. 总结段（简短收尾+引导关注）
```

## 三、段落写作规范

### 引入段

- **第一句**：时事/新闻引入（"近日，网络上频繁曝出..."/"XX上市在即，..."）
- **中间**：一句话概括产品核心卖点
- **最后一句**（固定）："下面，一起来了解了解。"

### 外观段

- 每段对应一个视角（车头/侧面/车尾），使用固定过渡词引入
- 车头段开头："外观方面，..." 或 "新车前脸..."
- 侧面段开头："转至侧面，..." 或 "车身侧面..."  或 "车辆侧面..."
- 车尾段开头："车尾来看，..." 或 "车尾部分，..." 或 "车尾依旧..."
- 描述顺序：整体印象 → 具体部件细节 → 尺寸数据（如有）
- 每段 3-5 句话

### 内饰段

- 开头："内饰方面，..." 
- 描述顺序：整体设计语言 → 屏幕/中控布局 → 座椅/空间 → 用料/氛围

### 动力段

- 开头："动力方面，..." 或 "动力上，..." 或 "动力是XX的核心亮点，..."
- 必须包含：发动机排量/类型、最大功率(kW)、变速箱类型、电池容量(kWh)、续航里程(km)
- 数据格式严格：`最大功率XXXkW`、`XXXkm`、`XX度电池`

### 配置段

- 开头："配置上，..." 或 "配置是XX重点升级之处，..."
- 列举具体配置项，使用顿号分隔
- 区分版本差异（标配/高配独有）

### 结尾段

- **市场分析**：预测售价区间 + 列举 3-5 款竞品车型名
- **互动引导**（必须有，固定句式）：
  - "大家认为，以XX的产品力，能够和各家友商较量吗？评论区聊一聊！"
  - "那么大家对XX期待吗？评论区聊一聊！"
  - "如果是你，现在手握XX万，会选择XX吗？"

## 四、语言风格规范

### 自称与口吻

- 自称"小编"
- 口吻：专业但亲切，不端着也不过分随意
- 适度使用口语化表达："主打一个XXX"、"值得好评"、"让人眼前一亮"

### 形容词使用

- 车头常用：犀利、扁平、圆润、宽大、运动
- 侧面常用：修长、硬朗、流畅、动感
- 车尾常用：饱满、简洁、克制、层次感
- 内饰常用：豪华、科技感、精致、时尚

### 数据表达格式

- 尺寸：`长宽高分别为XXX/XXX/XXXmm，轴距为XXXmm`（固定句式）
- 功率：`最大功率XXXkW`（千瓦）或 `最大马力XXX匹`
- 续航：`CLTC纯电续航XXXkm` 或 `工信部最大续航XXXkm`
- 电池：`XX度电池` 或 `XXkWh的XX电池组`
- 扭矩：`峰值扭矩XXX牛·米`
- 售价：`XX万元级别` 或 `指导价XX万元起`

### 过渡词库

| 位置 | 过渡词 |
|------|--------|
| 引入→外观 | "外观方面，" |
| 车头→侧面 | "转至侧面，" / "车身侧面，" |
| 侧面→车尾 | "车尾来看，" / "车尾部分，" |
| 外观→内饰 | "内饰方面，" |
| 内饰→配置 | "配置上，" / "配置方面，" |
| 配置→动力 | "动力方面，" / "动力上，" |
| 动力→结尾 | "结合XX来分析，" / "值得一提的是，" |

### 禁忌项

- ❌ 不使用"笔者"、"本文"等书面化表达
- ❌ 不使用英文缩写开头的句子（"SUV采用..." → "该车采用..."）
- ❌ 不使用过度营销用语（"颠覆性"、"划时代"、"遥遥领先"）
- ❌ 不使用"首先/其次/最后"这类列举词
- ❌ 不做主观评价性结论（"这车值得买"），而是抛出问题让读者自己判断

## 五、配图规则

### 数量与分布

| 文章类型 | 总配图数 | 分布 |
|---------|---------|------|
| 单车型文章 | 6-8 张 | 封面1 + 车头1 + 侧面1 + 车尾1 + 内饰1-2 + 细节1-2 |
| 盘点类文章 | 每车2-3张 | 每车至少覆盖车头+侧面或车尾 |

### 配图位置规则

- 引入段后紧跟封面/主图
- 每个外观维度段落后各配 1 张对应角度图
- 内饰段配 1-2 张（中控全景+后排/细节）
- 动力/配置段一般不配图

### IMAGE 标记描述规范

描述应简洁具体，包含角度+车型名：
- `[IMAGE:1:魏牌V9X车头正面实拍]`
- `[IMAGE:2:魏牌V9X侧面45度角实拍]`
- `[IMAGE:3:魏牌V9X车尾实拍]`
- `[IMAGE:4:魏牌V9X内饰中控全景]`
- `[IMAGE:5:魏牌V9X后排空间]`

## 六、篇幅与字数指引

| 文章类型 | 目标字数 | 段落数 |
|---------|---------|--------|
| 单车型新车实拍/曝光 | 800-1200 字 | 7-9 段 |
| 盘点类（3款车） | 1200-1800 字 | 10-14 段 |
| 深度评测/对比 | 1500-2500 字 | 12-16 段 |
