## 二、工具选择决策树

```
需求分析：
├─ 文生图
│   ├─ 高质量/复杂场景/中文文字渲染/漫画 → HY-Image-V3.0
│   ├─ 快速出图/电商素材 → HY-Image-Lite

│
├─ 图片编辑（基于已有图片）
│   ├─ 风格转换/局部修改 → ImageEdit
│   └─ 基于原图重新创作 → HY-Image-V3.0（图生图模式）
│
└─ 批量生成
    └─ 根据场景选择合适工具，保持风格锚定词一致
```

### 汽车场景专用决策

```
汽车图片生成：
├─ 车辆外观（车头/侧面/车尾/45度角）→ ImageGen（写实摄影风格）
├─ 车辆内饰（中控/座椅/空间/后排）→ ImageGen（写实摄影风格）
├─ 场景图（行驶/停靠/展厅/山路/城市）→ ImageGen 或 HY-Image-V3.0（复杂场景）
├─ 细节特写（灯组/轮毂/Logo/车标）→ ImageGen
├─ 对比/多角度拼图 → ImageGen（保持风格一致）
├─ 带文字的海报/Banner → HY-Image-V3.0（文字渲染最强）
└─ 漫画/插画风格汽车图 → HY-Image-V3.0
```

## 三、核心创作原则

> **描述场景，不要罗列关键词。叙事性描述始终优于关键词堆叠。**

### 对比示例

❌ **错误（关键词堆叠）**：
```
BMW, X5, car, SUV, front, road, photography, no text, no watermark
```

✅ **正确（场景描述）**：
```
宝马X5 车头正面实拍，展示前脸双肾格栅和天使眼大灯组，低角度仰拍，城市CBD背景。无文字无水印，真实摄影质感。
```

## 四、七种场景创作策略

### 策略一：写实摄影（Photorealistic）⭐ 汽车文章首选

**核心要点**：加入摄影术语——镜头类型、光线条件、拍摄氛围

**Prompt 结构**：`[车型全称] + [具体场景描述] + [摄影设置: 角度/光线] + [环境氛围]。无文字无水印，真实摄影质感。`

**汽车场景示例**：

| 图位类型 | Prompt 示例 |
|---------|------------|
| 车头正面 | `比亚迪汉EV 车头正面实拍，展示前脸设计和贯穿式灯带，低角度仰拍，专业汽车摄影。无文字无水印，真实摄影质感。` |
| 侧面 | `比亚迪汉EV 车身侧面45度角实拍，展现修长车身线条和轮毂细节，城市街道背景。无文字无水印，真实摄影质感。` |
| 车尾 | `比亚迪汉EV 车尾实拍，展示贯穿式尾灯和后包围设计，停车场环境。无文字无水印，真实摄影质感。` |
| 内饰中控 | `比亚迪汉EV 内饰中控全景，展示旋转大屏和方向盘，驾驶座视角。无文字无水印，真实摄影质感。` |
| 后排空间 | `比亚迪汉EV 后排空间实拍，展示腿部空间和座椅材质。无文字无水印，真实摄影质感。` |
| 行驶场景 | `比亚迪汉EV 在城市快速路上行驶，动态追拍，展现运动姿态。无文字无水印，真实摄影质感。` |

**关键术语**：镜头（50mm/85mm/广角/微距）、光线（自然光/黄金时段/影棚灯光）、景深（浅景深/虚化/锐利对焦）

---

### 策略二：风格化插画（Stylized Illustration）

**核心要点**：明确指定风格名称、视觉特征、背景处理方式

**Prompt 结构**：`[风格名称] + [车型/主体详细描述] + [视觉特征: 线条/着色/色板] + [背景]`

**示例**：
```
一幅扁平设计风格的宝马X5侧面图，线条简洁流畅，采用蓝灰主色调搭配橙色点缀，几何化的车身轮廓。纯白色背景。
```

**适用**：社交媒体配图、品牌宣传、趣味性内容

**风格关键词**：可爱风、动漫、Q版、扁平设计、矢量插画、水彩、铅笔素描、复古

---

### 策略三：文字精准图（Text-Accurate）

**核心要点**：指定字体风格、设计方法、配色方案。**推荐 HY-Image-V3.0，文字渲染最强。**

**Prompt 结构**：`[设计类型] + [文字内容（引号）] + [字体风格] + [设计方法] + [配色]`

**示例**：
```
设计一张汽车评测封面海报，标题文字"2026年度最佳电动轿车"使用粗体黑色无衬线字体，底部搭配比亚迪汉EV的侧面剪影。配色为深蓝到黑色渐变背景，金色标题文字。
```

**适用**：封面海报、Banner、文字排版设计

---

### 策略四：产品摄影（Product Photography）

**核心要点**：描述工作室布局、灯光配置、镜头角度、材质质感

**Prompt 结构**：`[车型描述+材质] + [摆放场景] + [灯光方案] + [镜头角度] + [背景]`

**示例**：
```
一张高端影棚产品摄影图，展示宝马X5的前脸特写，车漆反射柔和的影棚灯光。三点布光方案：左上方45度角柔和主光，右侧补光勾勒车身线条，背后轮廓光突出格栅细节。30度微仰视角。纯黑背景，车身映射环境光。
```

**适用**：车型展示图、品牌物料、高端车评

---

### 策略五：极简设计（Minimalist Design）

**核心要点**：主体定位策略、大量负空间保留

**示例**：
```
极简构图，一辆白色比亚迪汉EV侧面轮廓位于画面下方三分之一处。大面积留白，使用浅灰色(#F5F5F5)背景，车辆仅占画面总面积的30%。车身下方有柔和的倒影。
```

**适用**：封面、壁纸、高端品牌视觉

---

### 策略六：连续画/漫画/分镜（Sequential Art）

**核心要点**：角色一致性、各面板场景描述。**推荐 HY-Image-V3.0，漫画能力强。**

**示例**：
```
制作一幅3格漫画，展示电动车充电趣事。第1格：车主焦虑地看着仅剩5%的电量表。第2格：远处出现一个充电站的标志，车主露出欣喜表情。第3格：车辆正在充电，车主悠闲地喝咖啡看手机。卡通风格，暖色调。
```

**适用**：趣味性内容、故事板、社交媒体段子配图

---

### 策略七：搜索驱动图形（Search-Grounded Graphics）

**核心要点**：结合时事、数据、趋势等信息创作

**示例**：
```
制作一张精美的汽车销量信息图，展示2026年上半年新能源车销量TOP5品牌对比。使用深蓝色科技感背景，彩色柱状图搭配品牌Logo剪影，数据用大号粗体白色字呈现。
```

**适用**：数据可视化配图、行业报告插图、热点海报

## 五、图片编辑与图生图（C类图位核心能力）

> **核心场景**：从公网搜索到真实车型照片后，以其为参考基底进行图生图，保持车辆主体造型和品牌标识不变，调整场景/光线/背景/角度。

### 5.1 工具选择（图生图场景）

| 需求 | 推荐工具 | 说明 |
|------|----------|------|
| 微调（光线/背景/角度/裁切） | **ImageEdit** | 保持主体高度一致，只做环境调整 |
| 复杂重构（换整个场景/多元素/大幅风格化） | **HY-Image-V3.0**（图生图模式） | 以原图为参考生成新构图，主体特征保留 |

### 5.2 图生图 Prompt 规范

**ImageEdit Prompt 模板**：
```
基于这张{车型全称}照片，{调整描述}。保持车辆主体造型和品牌标识不变。{新场景/光线描述}。
```

**ImageEdit 示例**：
- `"基于这张比亚迪汉EV车头照片，将背景替换为城市CBD夜景。保持车辆主体造型和品牌标识不变。增加路面反射效果。"`
- `"基于这张宝马X5侧面照片，调整为黄金时段暖色光线。保持车辆主体造型和品牌标识不变。背景改为海滨公路。"`
- `"基于这张宝马X5照片，将白天场景改为雨天行驶效果。保持车辆主体造型和品牌标识不变。增加路面水渍反射。"`

**HY-V3.0 图生图 Prompt 模板**：
```
{车型全称} {新场景描述}。保持车辆主体外观特征和品牌标识完全不变，调整{背景/光线/角度}。无文字无水印，真实摄影质感。
```

**HY-V3.0 图生图示例**：
- `"比亚迪汉EV 在雪山公路疾驰，动态追拍，车身有轻微运动模糊。保持车辆主体外观特征和品牌标识完全不变，调整为雪山环境和动态行驶姿态。无文字无水印，真实摄影质感。"`
- `"宝马X5 停靠在高端别墅门前，展现豪华生活方式。保持车辆主体外观特征和品牌标识完全不变，调整为别墅花园背景和柔和自然光。无文字无水印，真实摄影质感。"`

### 5.3 图生图关键原则

1. **主体不可变**：车辆的外形轮廓、车标Logo、车身比例、关键设计特征（如格栅形状、灯组造型）必须保持不变
2. **可调整范围**：背景/场景、光线/色调、拍摄角度、天气效果、地面/路面、周围环境元素
3. **禁止过度修改**：不能改变车辆颜色（除非用户明确要求）、不能增删车身部件、不能改变车型比例
4. **明确指出保留项**：Prompt 中必须包含"保持车辆主体造型和品牌标识不变"这类明确约束

### 5.4 传统图片编辑（非图生图）

通过 **ImageEdit** 工具对已有图片进行局部修改：

**编辑示例**：
- **添加元素**：`"在车辆背景天空添加一道绚丽的晚霞，保持车辆和前景不变。"`
- **风格转换**：`"将这张汽车实拍照转换为水彩画风格的插画，保持构图和车型特征。"`
- **背景替换**：`"将背景替换为雪山公路场景，保持前景车辆不变。"`

**关键原则**：编辑时明确指出「保持其他元素不变」，避免过度修改。

## 八、画面约束（强制）

- **不生成文字**：画面中不出现任何文字、标语、水印、logo 文字（除非使用策略三明确要求文字）
- **不生成原理图**：不生成流程图、信息图、示意图等抽象图形
- **聚焦真实感**：侧重真实摄影质感的汽车图片（策略一为默认）
- **保持品牌识别**：车标 LOGO 需清晰可识别（通过描述暗示，如"展示前脸设计和品牌Logo"）
- **无文字无水印**：所有 Prompt 末尾强制附加"无文字无水印，真实摄影质感"

## 九、公网图片搜索策略（C类/D类图位）

> 适用于需要真实车型照片的场景（C类：搜索+图生图，D类：搜索直接使用）。

### 9.1 搜索词构造最佳实践

| 目标内容 | 推荐搜索词格式 | 示例 |
|---------|--------------|------|
| 车型外观 | `{车型} {年款} {角度} 高清 实拍` | "宝马X5 2026款 车头正面 高清 实拍" |
| 内饰 | `{车型} {年款} {部位} 内饰 实拍` | "比亚迪汉EV 中控台 内饰 实拍" |
| 技术原理图 | `{技术名称} 工作原理图` | "ESP电子稳定系统 工作原理图" |
| 结构图 | `{车型/部件} 结构 剖面图 官方` | "比亚迪刀片电池 结构剖面图 官方" |
| 发动机舱 | `{车型} {发动机型号} 发动机舱 实拍` | "宝马X5 B58发动机舱 实拍 高清" |
| 官方图 | `{车型} {年款} 官方图/官图/Press Photo` | "比亚迪汉EV 2026款 官方图" |
| 碰撞测试 | `{车型} C-NCAP/E-NCAP 碰撞测试` | "比亚迪汉 C-NCAP 碰撞测试结果" |
| 仪表盘/中控屏 | `{车型} 仪表盘/中控屏 界面 实拍` | "比亚迪汉EV 仪表盘界面 实拍" |

### 9.2 图片筛选优先级

1. **来源权威性**（权重最高）：
   - 品牌官方（官网/官方社媒）> 垂直媒体（汽车之家/懂车帝/太平洋汽车）> 新闻媒体 > 车主论坛/个人博客

2. **图片质量**：
   - 高清大图 > 标清图；无水印 > 轻水印角标 > 重水印（重水印不选）

3. **内容匹配度**：
   - 精确匹配（角度/部位/年款完全一致）> 近似匹配

4. **时效性**：
   - 新款 > 旧款（⚠️ 注意年款匹配，2026款文章搜2026款图）

### 9.3 版权注意事项

- ✅ 优先使用：品牌官方发布的 Press Photo / 媒体资源
- ✅ 可以使用：汽车媒体评测文中的图片（通常允许引用）
- ⚠️ 谨慎使用：有"版权所有"/"禁止转载"明确声明的图片
- ❌ 禁止使用：有明确署名/版权声明的个人摄影师作品

### 9.4 搜索失败重试策略

| 失败原因 | 重试方案 |
|---------|---------|
| 搜索词太具体无结果 | 去掉"实拍"/"高清"等修饰词，只保留核心词 |
| 年款搜不到 | 去掉年款，搜通用版本 |
| 角度搜不到 | 换近义词（如"正面"→"前脸"→"车头"） |
| 整体搜不到 | 拆分为品牌+车型搜索（如"比亚迪 汉EV"拆开搜） |

## 十、降级机制（CRITICAL）

### C类降级

```
C类图位降级链路：
├─ 搜索成功 + 图生图成功 → ✅ 正常C类产出
├─ 搜索成功 + 图生图失败 → 重试图生图 1 次
│   ├─ 重试成功 → ✅ 正常C类产出
│   └─ 重试失败 → 直接使用搜索到的原图（标注来源）
├─ 搜索失败 → 换关键词重试 1 次
│   ├─ 重试成功 → 继续图生图流程
│   └─ 重试失败 → ⚠️ 降级为B类（纯AI生图）
│       标注改为: *（AI 生成示意图，仅供参考。未找到该车型真实参考图）*
│       回传中注明降级原因
```

### D类降级

```
D类图位降级链路：
├─ 搜索成功 + URL可访问 → ✅ 正常D类产出
├─ 搜索成功 + URL不可访问 → 尝试其他搜索结果中的备选图片
│   ├─ 备选可用 → ✅ 正常D类产出
│   └─ 全部不可用 → 换关键词重搜
├─ 搜索失败 → 换关键词重试 1 次
│   ├─ 重试成功 → ✅ 正常D类产出
│   └─ 重试失败 → 🚫 保留原始 [IMAGE:n:描述] 标记不替换
│       ⚠️ D类绝不降级为AI生图（因为内容要求100%真实）
│       回传中注明: "D类图位 #{n} 真实图搜索失败，保留标记待人工处理"
```

### 降级统计

回传时必须完整统计降级情况，供主理人和质检官参考：
- C→B 降级数量 + 具体图位编号
- D类搜索失败保留标记的图位编号
- 图生图失败使用原图的情况

## 十一、注意事项

1. **语言匹配**：图中所有文字必须匹配用户语言（中文用户→图中文字为中文）
2. **内容安全**：严禁生成违规内容
3. **品牌一致**：系列图片保持风格锚定词一致
4. **文字渲染**：需要精准文字时推荐 HY-Image-V3.0
