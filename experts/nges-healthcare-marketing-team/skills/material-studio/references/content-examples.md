# 四种物料类型 content.json 范例（简报版式）

> 目标是做出"简报级"的信息密度：**开场导语 → 分板块 → 本期小结**，条目用结构化多行（rows）展开，**带具体数据**（样本量/PFS/OS/HR/ORR/P值），附来源。research/news 类内容须先联网核实、过合规自检。导语用代表口吻，勿用"编者按"。
> 每份都带 `gen_date`（生成日期）和 `fresh_tag`（新鲜度标签），显示在刊头徽标，体现时效。缺省 `gen_date` 时脚本自动取今天。

## 通用字段
- `type`：`greeting` | `news` | `research` | `education`
- `column`：刊头栏目名（缺省按类型取默认）
- `issue`：期号（可选，如 `第 12 期`）
- `headline`：大标题
- `gen_date`：生成日期 `YYYY-MM-DD`（缺省=今天）
- `fresh_tag`：新鲜度标签（缺省按类型取，如 `报告研读`/`热点速递`）
- `lead`：开场导语（可选，代表口吻）
- `sections[]`：板块数组，每个 `{name, items[]}`；`item` = `{title, rows[]?, text?, src?}`，`row` = `{lbl, val}`
- `summary`：本期小结（可选）
- `greeting`：仅 type=greeting，`{festival, lines[]}`

---

## 1. 🎊 节日问候（greeting）
```json
{
  "type": "greeting",
  "column": "节日问候",
  "headline": "端午安康",
  "gen_date": "2026-06-19",
  "fresh_tag": "诚挚祝福",
  "greeting": {
    "festival": "端午安康",
    "lines": [
      "粽叶飘香，又是一年端午时。",
      "感谢您一直以来对临床工作的坚守与付出，",
      "愿您工作顺遂、家人安康，",
      "诸事皆顺，安康常伴。"
    ]
  }
}
```

## 1b. 🎂 生日问候（greeting 子类型）
```json
{
  "type": "greeting",
  "occasion": "birthday",
  "column": "生日问候",
  "headline": "生日快乐",
  "gen_date": "2026-06-28",
  "fresh_tag": "生日祝福",
  "recipient": {"dept": "上海市胸科医院", "name": "YY教授"},
  "greeting": {
    "festival": "生日快乐",
    "lines": [
      "陆主任：",
      "欣闻今日是您的生日，谨致上最诚挚的祝福。",
      "感谢您在临床与科研一线的耕耘，",
      "愿您身体康健、笑口常开，新的一岁所求皆所愿。"
    ]
  }
}
```
> `occasion:"birthday"` 触发暖色玫瑰粉 + 🎂 蛋糕主视觉。祝福得体、不夹带产品。

## 合规自查（写内容时对照）
- [ ] 无"最好/第一/唯一/根治/首选"等绝对化表述
- [ ] 未超出已获批适应症范围
- [ ] research 类每条 item 均有真实 `src`
- [ ] 产品内容为学术陈述，非促销话术
- [ ] 无带金/回扣/馈赠暗示
- [ ] 已设置 `gen_date` 体现新鲜度
