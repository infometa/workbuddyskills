# 主题配色方案参考

## 使用方法

将对应主题的 CSS 变量替换到`:root` 中即可切换整体风格。

## 学术蓝 (Academic Blue) - 默认

```css
:root {
    --primary: #185FA5;
    --primary-light: #2E7BC9;
    --primary-dark: #0D4A82;
    --primary-bg: #E8F2FC;
    --accent: #F59E0B;
    --text: #1E293B;
    --text-secondary: #475569;
    --bg: #F8FAFC;
    --card-bg: #FFFFFF;
    --border: #E2E8F0;
}
```
适用：正式学术场景、CME、学术会议、医学培训
