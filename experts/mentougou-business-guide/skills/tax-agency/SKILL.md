# 代办税务服务（建设中）

## 当前状态

⚠️ **本 Skill 正在建设中，暂不提供任何代办税务服务。**

当用户咨询代办税务、代账、报税、记账等需求时：
1. 明确告知用户"代办税务服务正在建设中，暂不提供服务"
2. 记录用户需求（姓名、联系方式、需求描述）
3. 告知用户"服务上线后会第一时间通知你"

## 触发关键词

- 代办税务 / 代账 / 代理记账
- 报税 / 申报 / 纳税申报
- 记账 / 建账 / 账务处理
- 发票 / 开票 / 进项票 / 销项票

未来本 Skill 将提供：
- 代理记账服务
- 税务申报代办
- 发票管理
- 年度汇算清缴
- 税务合规咨询

## 话术参考

> "代办税务服务我们正在建设中，暂时还不能提供。你的需求我记下来了，等服务上线后第一时间通知你。如果你现在急需办税，建议联系门头沟区当地的代理记账机构，或者拨打 12366 咨询税务办理流程。"

> "方便留个联系方式吗？服务上线后我通知你。"
