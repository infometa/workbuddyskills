# 门头沟区OPC（一人公司）/个体工商户专项政策

> last_verified_at: 2026-07-30
> 核心结论：门头沟区目前**没有独立发布**专门针对OPC/一人公司的区级政策文件。适用全国通用政策和北京市级政策。

---

## 1. OPC 可用的门头沟区政策

门头沟区产业政策中未明确排除OPC/一人公司/个体户，以下政策按主体类型可适用：

```
■ AI/软件方向的一人公司
  可申请：门头沟区信软产业高质量发展措施
  · 首台套奖励最高60万元
  · AI算力补贴20%
  · 大模型应用补贴20%

  可申请：算法人才十条
  · 前3年免费入驻算法创客空间

  可申请：三个一计划
  · 5000万智谷计划基金，最高50万支持
```

```
■ 制造业方向的企业
  可申请：门经信文〔2025〕65号 工业高质量发展措施
  · 首次入列奖励10万元
  · 达标奖励最高500万元
  · 固定资产投资10%支持
```

```
■ 所有符合条件的小微企业（含一人公司）
  可享受全国通用税收优惠：
  · 企业所得税实际税负5%（年应纳税所得额≤300万）
  · 六税两费减半
  · 小规模纳税人增值税1%
```

## 2. 个体工商户专属政策

```
■ 门头沟区个体户
  区级专项：目前未检索到门头沟区个体户专项政策

  全国通用（全部适用）：
  · 增值税：月销≤10万免税，3%减按1%（至2027年底）
  · 个税：年应纳税所得额≤200万部分减半（至2027年底）
  · 六税两费：减半征收（至2027年底）

  注意：
  · 个体户不享受企业所得税优惠（因不缴企业所得税）
  · 个体户可选择核定征收或查账征收，核定征收税负更低
  · 核定征收政策各地执行不同，需咨询门头沟区税务局确认
```

## 4. 新《公司法》对一人公司的影响

```
■ 2024年7月1日起施行的新《公司法》要点：

  · 允许设立一人股份有限公司（旧法只允许一人有限责任公司）
  · 一人有限责任公司股东仍承担有限责任
  · 一人公司需在营业执照中载明"独资"或"一人"
  · 注册资本5年内缴足（新规定）
  · 一人公司无需设监事会，可设一名监事或经全体股东同意不设监事

  对OPC创业者的影响：
  · 注册门槛降低，形式更灵活
  · 但一人公司仍需建立规范的财务制度
  · 建议咨询注册地市场监管局了解最新注册流程
```
