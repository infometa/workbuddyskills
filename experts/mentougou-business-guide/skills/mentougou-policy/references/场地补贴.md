## 1. 创业空间支持

```
■ 算法创客空间（免费租用）
  来源：算法人才十条 + 门科信文〔2024〕5号

  · 算法人才在中关村门头沟科技园创办企业 → 前3年免费入驻
  · 配套：优先使用区内算力资源 + 三年期算力补贴

  适用主体：算法/AI方向创业者
```

```
■ 高新产业青年人才安居保障
  来源：三个一计划（2025年）

  · "一免两补"：第一年租金全免，第二年梯次补贴，第三年50%补贴
  · 纳入"京西聚智计划"人才可享受
```

## 2. 产业空间扩展支持

```
■ 工业企业生产/研发空间支持
  来源：门经信文〔2025〕65号 | 有效期至2026-12-31

  · 新扩建/租赁/购置生产及研发办公空间 → 经营性贷款贴息
  · 担保、保险、融资租赁贴费支持
  · 总额不超过200万元/年

  适用条件：
  · 首次列入重点跟踪范围的工业企业
  · 或2025年起实现年度产值增长的企业

  申请入口：门头沟区经信局 | 电话：010-69842592
```

## 4. 北京市级场地/空间政策

```
■ 中关村科技型小微企业研发支持
  2025年度项目
  · 对符合条件的小微企业给予研发资金后补助
  · 申报平台：https://mis.kw.beijing.gov.cn/

■ 老旧厂房更新利用奖励
  来源：2025年高精尖产业发展资金实施指南（第一批）
  · 固定资产投资≥500万元
  · 按不超过总投资10%奖励，单项目≤1000万元
```

## 5. 对OPC/个体户创业者的场地建议

```
■ 选址方案：

  科技/AI方向 → 中关村门头沟科技园（享受政策叠加 + 算力资源）
  制造方向 → 军庄医疗器械基地或区内存量厂房
  一般服务业 → 区内存量商业空间（可关注老旧厂房更新政策）
  初创小微 → 优先申请算法创客空间或三个一计划安居保障

  · 门头沟相较海淀/朝阳：租金低50-70%，且有区级补贴
  · 劣势：距市中心较远，交通配套仍需完善
```
