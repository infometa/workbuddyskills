# 门头沟区企业注册流程

> last_verified_at: 2026-07-30

---

## 1. 企业注册基本流程

```
■ 门头沟区企业注册步骤：

  1. 确定主体类型
     · 个体工商户 / 个人独资企业 / 一人有限责任公司 / 一人股份有限公司 / 有限责任公司

  2. 获取注册地址（关键一步）
     · 本专家可免费提供门头沟区注册地址 → 使用 address-registration skill 申请
     · 或自行租赁商业地址

  3. 名称核准
     · 通过"北京市企业服务e窗通"平台：https://ect.scjgj.beijing.gov.cn/
     · 在线核名（确保名称不与已有企业重名）

  4. 提交设立登记材料
     · 线上：通过e窗通平台全程电子化办理
     · 线下：门头沟区市场监督管理局

  5. 领取营业执照
     · 电子营业执照（即时获取）
     · 纸质执照（可选择邮寄）

  6. 刻章备案
     · 公章、财务章、法人章、发票章

  7. 税务登记
     · 门头沟区税务局
     · 核定税种、纳税人身份（小规模/一般纳税人）

  8. 银行开户
     · 开立基本户

  9. 社保/公积金开户（如需要）
```

## 2. 线上注册平台

```
■ 主要办理平台：

  北京市企业服务e窗通：https://ect.scjgj.beijing.gov.cn/
  · 企业开办全程电子化
  · 支持名称核准、设立登记、刻章、税务、社保、公积金一网通办
  · 支持电子营业执照即时下载

  北京市政务服务网：https://banshi.beijing.gov.cn/
  · 门头沟区入口

  国家税务总局北京市电子税务局：https://etax.beijing.chinatax.gov.cn/
  · 税务登记、申报、缴税
```

## 4. 注册所需材料

```
■ 一人有限公司注册材料：

  必交：
  · 《公司登记（备案）申请书》
  · 公司章程（一人股东签署）
  · 股东身份证明
  · 法定代表人、董事、监事、经理任职文件及身份证明
  · 住所使用证明（注册地址证明）

  注意：
  · 新《公司法》施行后，注册资本须5年内缴足
  · 一人公司营业执照须载明"一人有限责任公司"或"独资"
  · 住所使用证明 → 本专家可协助提供（免费注册地址）
```

```
■ 个体工商户注册材料：

  · 《个体工商户登记申请书》
  · 经营者身份证明
  · 经营场所使用证明

  较一人公司优势：材料更少、流程更简、无需章程
  较一人公司劣势：经营者承担无限责任、不能引入股东
```

---

## 5. 注册后事项

```
■ 注册完成后需办理：

  1. 银行开户（注册后30日内）
  2. 税务报到（注册后30日内）
     · 核定税种、选择征收方式
     · 申请发票（数电票/纸质票）
  3. 社保/公积金开户（如有员工）
  4. 会计制度建立
     · 个体户：可选择核定征收（简单）或查账征收
     · 公司制：须建账，按查账征收
  5. 工商年报（每年1月1日-6月30日）

  重要提醒：
  · 代办税务服务本专家目前不提供（建设中），需自行或委托代理机构
  · 门头沟区注册地址审核通过后才能用于注册，建议提前申请
```

## 6. 注册费用概算

```
■ 门头沟注册费用估算：

  政府费用：
  · 营业执照工本费：免费
  · 电子营业执照：免费

  第三方费用：
  · 刻章：约200-500元（部分园区/政策可免费）
  · 注册地址：本专家免费提供（门头沟地址）
  · 代理注册（如委托代办）：市场价500-3000元

  合计：门头沟注册一家一人公司，若不委托代办，基本零成本
```
