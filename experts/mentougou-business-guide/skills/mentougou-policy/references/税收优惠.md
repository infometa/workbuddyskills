## 2. 适用于门头沟注册企业的全国通用税收优惠

以下政策对门头沟区注册的所有符合条件的小微企业、个体工商户、一人有限公司**全面适用**。

```
■ 小规模纳税人增值税减免
  财政部 税务总局公告2023年第19号
  发文：2023年8月1日 | 执行至：2027年12月31日
  时效：[现行]

  · 月销售额≤10万元（季度≤30万元）→ 免征增值税
  · 3%征收率 → 减按1%征收
  · 3%预征率 → 减按1%预征

  适用主体：增值税小规模纳税人（含个体工商户）
```

```
■ 小型微利企业所得税优惠
  财政部 税务总局公告2023年第12号
  发文：2023年8月2日 | 执行至：2027年12月31日
  时效：[现行]

  · 减按25%计入应纳税所得额，按20%税率缴纳 → 实际税负5%
  · 判定条件（"335"标准）：年应纳税所得额≤300万 + 从业人数≤300人 + 资产总额≤5000万

  适用主体：小型微利企业（含一人有限公司、有限责任公司）
  注意：个体工商户、个人独资企业、合伙企业不适用
```

```
■ 个体工商户个人所得税减半
  财政部 税务总局公告2023年第12号 + 国家税务总局公告2023年第12号
  发文：2023年8月2日 | 执行至：2027年12月31日
  时效：[现行]

  · 年应纳税所得额≤200万元部分 → 减半征收个税
  · 不区分征收方式（查账/核定均可）
  · 可与其他个税优惠叠加

  适用主体：个体工商户
```

```
■ "六税两费"减半征收
  财政部 税务总局公告2023年第12号
  执行至：2027年12月31日
  时效：[现行]

  减半税种：资源税（不含水资源税）、城市维护建设税、房产税、
           城镇土地使用税、印花税（不含证券交易）、耕地占用税、
           教育费附加、地方教育附加

  适用主体：增值税小规模纳税人 + 小型微利企业 + 个体工商户
```

```
■ 小规模纳税人增值税起征点
  · 按期纳税：月销售额5000-20000元
  · 按次纳税：每次（日）销售额300-500元
```
