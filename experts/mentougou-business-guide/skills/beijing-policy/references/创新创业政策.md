## 3. 专精特新梯度培育

```
■ 北京市优质中小企业梯度培育
  来源：北京市经信局

  培育路径：
  创新型中小企业 → 专精特新中小企业 → 国家专精特新"小巨人"

  "专精特新"专板：
  · 全国首批设立的九家专板之一
  · 截至2024年底：板内企业522家
  · 2025年目标："挂牌倍增"行动，突破1000家
  · 在板企业股权融资奖励：≤30万元

  政策倾斜：
  · 新增"创客北京"大赛获奖和"首都医学科技创新成果转化优促计划"获奖指标
```

## 4. 重点群体创业就业税收优惠

```
■ 重点群体创业税收扣减
  财政部 税务总局 人力资源社会保障部 农业农村部公告2023年第15号
  执行至：2027年12月31日
  时效：[现行]

  适用人群：
  · 脱贫人口（含防止返贫监测对象）
  · 持《就业创业证》或《就业失业登记证》人员
  · 毕业年度内高校毕业生

  优惠内容：
  · 从事个体经营 → 3年内每户每年20000元限额依次扣减
    （增值税、城建税、教育费附加、地方教育附加、个税）
  · 限额标准最高可上浮20%，各省可在幅度内确定具体限额
```

## 5. 数据要素市场示范奖励

```
■ 数据要素市场示范奖励
  来源：2025年高精尖产业发展资金实施指南
  时效：[现行]

  · "首登记"：首次数据资产登记 → 登记费30%奖励，单企年度≤10万
  · "首交易"：首个数据产品交易 → 交易额4%奖励，单企≤200万
  · "首入表"：首次数据资源入表>500万 → 入表金额10%奖励，单企≤100万

  可叠加申报多个方向
```

```
■ 北京市AI创新策源地
  文件：《北京市加快建设具有全球影响力的人工智能创新策源地实施方案（2023-2025年）》

  · 北京市通用人工智能产业创新伙伴计划
```
