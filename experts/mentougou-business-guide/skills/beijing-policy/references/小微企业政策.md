## 1. 中小微企业首次贷款贴息

```
■ 北京市中小微企业首次贷款贴息实施细则（2025年修订版）
  文号：京经信发〔2025〕4号
  发文：2025年2月19日 | 发文机关：北京市经信局等六部门
  时效：[现行]

  贴息标准：
  · 一般中小微企业：按实际贷款利息的20%贴息
  · 创新型中小企业：按实际贷款利息的40%贴息（重点扶持）
  · 资金直达企业账户

  适用条件：
  · 注册在北京市的中小微企业
  · 通过北京市贷款服务中心或"北京企业融资综合信用服务平台"办理的首贷业务
  · 判定标准：人民银行征信系统查询"中长期借款"与"短期借款"均为零

  申请入口：
  · 北京市贷款服务中心
  · https://www.smeservice.com/
  · "北京金融大数据"小程序

  排除项：
  · 房地产公司贷款、融资平台公司贷款、非生产经营性固定资产投资项目贷款
  · 已获其他同类市级财政资金支持的首贷业务
```

## 2. 高精尖产业发展资金和中小企业发展资金

```
■ 2025年北京市高精尖产业发展项目资金和支持中小企业发展资金实施指南（第一批）
  发文：2025年1月20日 | 发文机关：北京市经信局 + 北京市财政局
  时效：[现行]

  与小微企业相关的支持方向（共18个方向中精选）：

  方向1 企业培育奖励：
  · 先进制造业首次提升至2000万+收入 → 奖励≤30万
  · 新建投产先进制造业首次提升至2000万+ → 奖励≤50万
  · 信息软件业首次由2000万以下升至1亿+ → 奖励≤50万

  方向4 中小企业服务体系绩效评价奖励：
  · 示范平台/示范基地/未来产业育新基地 → 择优奖励≤50万

  方向5 中小企业创新创业奖励：
  · "创客北京2025"大赛：
    - 企业组特等奖 100万元
    - 创客组特等奖 50万元
    - 其他奖项标准另行发布

  方向6 北京"专精特新"专板股权融资奖励：
  · 在板创新型/专精特新/"小巨人"企业 → 按私募股权融资额奖励≤30万

  方向7 "创赢未来"项目奖励：
  · 未来产业早期创新创业项目 → 奖励≤100万
  · 通过市场化公开路演遴选方式

  申请平台：
  · 北京通企服版APP
  · https://www.smebj.cn/
  · https://zhengce.beijing.gov.cn/
```

## 3. 科技型小微企业关键技术创新支持

```
■ 2025年中关村国家自主创新示范区科技型小微企业关键技术创新支持项目
  发文：2025年 | 发文机关：北京市科委、中关村科技园区管委会
  时效：[现行]（2025年度申报期：7月2日-7月31日）

  支持内容：
  · 对科技型小微企业的研发投入给予资金支持（后补助形式）

  申报条件：
  · 中关村示范区范围内注册
  · 注册时间：2023年1月1日之前（成立满2年）
  · 完成2024会计年度税前研发费用加计扣除申报
  · 2023年1月1日后成立的企业也可申报（须完成2024会计年度研发加计扣除）

  申报平台：
  · https://mis.kw.beijing.gov.cn/
  · https://zhengce.beijing.gov.cn/

  注意事项：
  · 不接受线下申报
  · 材料须字迹清晰、签章完备
  · 伪造材料将追回资金+3年不得申报+信用记录
```

## 4. 中关村门头沟园的政策叠加

```
■ 适用政策层级（由高到低）：
  1. 中关村国家自主创新示范区政策（国家级）
  2. 北京市级产业/科技/人才政策
  3. 门头沟区级产业政策

  关键：
  · 三类政策可叠加享受
  · 原则："从优、从高、不重复"
  · 中关村门头沟科技园入驻企业可同时申报中关村+北京市+门头沟区三级政策
```
