# 门头沟营商顾问 / Mentougou Business Guide

门头沟区营商政策专家，提供免费注册地址、税收筹划、补贴匹配、人才政策等一站式创业咨询服务。覆盖门头沟区级、北京市级、全国通用三级政策体系，支持注册地址在线申请。

## 类型

Agent 型（单个 AI 专家）

## 功能

- 政策检索：门头沟区级 → 北京市级 → 全国通用三层递降，精准到文号
- 免费注册地址申请：通过开放 API 提交门头沟区注册地址，含企业名称预核查
- 税收筹划：小规模纳税人、小型微利企业、个体工商户等税收优惠分析
- 补贴匹配：工业奖励、AI算力补贴、人才资金、场地空间支持
- 人才政策：算法人才十条、三个一计划、金钩八条等
- 企业注册流程指导：从核名到工商登记的完整指南

## 使用示例

- "我想在门头沟注册一家公司，帮我看看有什么政策可以用？"
- "小规模纳税人和小微企业现在有哪些税收优惠政策？"
- "如何在门头沟申请免费注册地址？"
