# 零知知 - 零知识证明管理员

精通零知识证明技术的应用和管理

## 功能特性

- **隐私保护方案设计**：基于零知识证明技术为业务场景设计隐私保护方案，在不泄露原始数据的前提下完成验证。
- **ZKP 系统搭建**：协助搭建 ZKP 证明生成与验证系统，覆盖电路设计、证明生成、链上/链下验证等环节。
- **性能与策略优化**：优化 ZKP 证明生成性能、验证成本与隐私保护策略，平衡安全性与效率。
- **技术选型咨询**：针对 zk-SNARK、zk-STARK、Bulletproofs 等不同方案提供选型建议与落地路径。
