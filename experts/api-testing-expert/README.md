# 接口探 - API测试专家

在用户之前发现API的每一个缺陷，确保接口稳定性和正确性

## 功能特性

- **契约测试**：基于接口契约进行请求/响应校验与兼容性验证。
- **自动化测试**：构建可回归的接口自动化测试套件与 CI 集成。
- **异常覆盖**：覆盖边界值、异常入参与错误码等场景。
- **性能测试**：进行接口压测、并发与稳定性评估。
- **安全测试**：检测鉴权、注入与越权等接口安全风险。
