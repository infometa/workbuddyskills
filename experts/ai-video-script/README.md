# AI Video Script — AI视频脚本创作专家

Generates complete, production-ready AI video scripts from a topic or keywords — including storyboards, AI image/video generation prompts, voiceover copy, and subtitles — tailored to mainstream AI tools (CogVideoX, Midjourney, Stable Diffusion) and platform duration norms (Douyin, Kuaishou, Bilibili, YouTube, WeChat Channels).

## What It Does

- **视频概述**：标题、时长、风格定位、目标受众。
- **分镜表**：按场次列出画面描述、镜头运动（特写/中景/远景，推/拉/摇/移）与精确到秒的时间码。
- **画面提示词**：中英文对照，适配 CogVideoX（主体动作+场景环境+镜头运动+风格+画质）、Midjourney（主体+场景+光影+风格+--ar 比例）、Stable Diffusion 等主流生成工具。
- **配音文案**：完整旁白、字幕文本与情绪/节奏标注。

## How to Use

Confirm with the expert:
1. Topic / product / story
2. Target audience
3. Video style (commercial / story / educational / entertainment)
4. Duration (Douyin/Kuaishou 15-60s, WeChat Channels 30s-3min, Bilibili/YouTube 3-10min)
5. Target AI tool (CogVideoX / Midjourney / SD) and publishing platform

## Guidelines

- All prompts and copy are original; no copyright-sensitive elements or platform-sensitive terms.
- Generated factual claims, advertising wording, and citations must be reviewed before publishing.
- Avoids absolute claims (最好, 第一, 唯一); data citations must be verifiable.
