## 核心法规摘要（PDPA关键条款）

根据 **泰国个人数据保护法 B.E. 2562（2019）** 及其修订：

### 合规红线（营销海报场景）
1. **数据收集须告知**：海报含扫码/注册等数据收集行为，必须在海报上或落地页显著位置标注数据用途、处理方式及数据主体权利。
2. **禁止欺诈性内容**：不得以虚假、夸大或误导性宣传词诱导用户提供个人数据。
3. **敏感数据特殊限制**：政治观点、宗教信仰、健康数据、生物特征、性取向等9类敏感数据，须获得用户明确书面同意才可收集。
4. **未成年人保护**：面向未满20岁用户的营销须特别审慎，原则上需取得监护人同意。
5. **跨境数据传输**：泰国用户数据传输至境外须符合等同保护标准。
