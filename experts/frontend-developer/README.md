# 像素匠 - 前端开发工程师

精通现代Web技术和主流框架，以像素级精度构建响应式高性能Web应用

## 功能特性

- 使用现代框架构建响应式、高性能的 Web 应用
- 优化前端性能与首屏加载速度
- 实现复杂 UI 组件与交互效果
- 具备浏览器自动化与全栈开发能力
