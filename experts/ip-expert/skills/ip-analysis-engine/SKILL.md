# 知产 · 分析研判引擎

> 这是知识产权专家的**研判工序**——在 `ip-intake` 确认立场口径、`ip-legal-research` 取回法条与登记/技术事实之后，对本案做实质分析。覆盖五类研判：①确权与权属 ②相似度/近似性比对 ③侵权/FTO 技术特征比对 ④可注册性与效力研判 ⑤构成要件涵摄。核心是**站在已确认的立场口径**，把"事实 + 依据"涵摄成有理有据的结论，并**永远附律师复核提示、绝不预测胜诉率**。

## 零、前置：立场口径确认（研判的命门）

同一事实，权利人视角与被控方视角结论可能相反。进入研判前，必须已通过 `ip-intake` 确认：
- **视角**：本方是**权利人**（主张确权/维权/侵权）还是**被控方/自由实施方**（防被诉/FTO/无效/抗辩）？
- **权利类型与客体**：著作权/专利/商标/商业秘密/域名 + 具体客体。
- **目标**：确权？打侵权？防侵权？申请？无效？维权？

口径未明时不得开始研判。研判所依据的法条效力、登记状态、检索事实，必须来自 `ip-legal-research` 的真实返回；缺口标"待核验"。

## 一、确权与权属分析

判断"权利是否存在、归属于谁、是否有效"。按权利类型分流：

| 权利类型 | 确权要点 | 依赖事实/库 |
|---|---|---|
| 著作权/软著 | 独创性（独立完成+最低限度创造性）、作品类型归类、思想表达二分、权属（职务作品/委托作品/合作作品/法人作品）、是否登记（登记为初步证据非确权要件）| DB9/DB10 登记、创作证据链 |
| 专利 | 权利是否授权且有效、法律状态（是否失效/未缴年费/被无效）、权利要求保护范围、发明人/申请人/权利人链条、职务发明归属 | DB5/DB8/DB7 法律状态与权利要求 |
| 商标 | 是否注册、专用权范围（核定商品服务+核准标识）、专用期、是否被撤三/无效/异议、注册人链条 | DB4/DB1 注册簿 |
| 商业秘密 | 三要件：不为公众所知悉（秘密性）、具商业价值、权利人采取保密措施；信息载体与秘密点界定 | 事实+保密措施证据 |
| 域名 | 注册人、注册时间、是否与在先权利冲突、是否恶意 | DB12 WHOIS、DB4 在先商标 |

**权属链条核查**：原始取得（创作/申请/注册）→ 继受取得（转让/继承/许可）逐环有无书面依据；职务成果、委托成果、合作成果按法定/约定规则定归属。

## 二、相似度 / 近似性比对

### 2.1 著作权实质性相似（抄袭比对）

采用"**接触 + 实质性相似**"框架：
1. **接触可能性**：被告是否有机会接触原告作品（已发表、曾提供、公开传播）。
2. **实质性相似**：先做**思想表达二分**（过滤不受保护的思想、通用表达、公有领域、有限表达/场景原则），再就**受保护的独创性表达**逐一比对（整体观感 + 具体元素：情节结构/人物设定/代码结构与序列/画面构图/旋律等）。
3. **结论**：列出相同/近似的具体表达点与其独创性，标注哪些属思想不受保护，给出实质性相似程度判断（不下"必侵权"绝对结论）。

### 2.2 商标近似 + 混淆可能性

两步走，近似是手段、混淆是落脚点：
1. **标识近似比对**：文字（读音/字形/含义）、图形（构图/着色/外观）、组合商标整体与主要部分；隔离观察 + 整体比对 + 主要部分比对。
2. **商品/服务类似判断**：参照区分表 + 实际关联（功能、用途、渠道、消费群体）。
3. **混淆可能性综合判断**：显著性与知名度、相关公众注意程度、实际混淆证据、被告主观意图；驰名商标做跨类混淆/淡化分析。

### 2.3 专利/外观相同或近似

- **发明/实用新型**：见第三节技术特征比对（不用"近似"，用权利要求落入判断）。
- **外观设计**：以一般消费者的知识水平和认知能力，就整体视觉效果做**相同/近似**判断（整体观察、综合判断，关注设计要点，忽略惯常设计与功能性特征）。

## 三、侵权 / FTO 技术特征比对（专利核心）

### 3.1 保护范围确定
以**授权公告的权利要求**为准，说明书及附图用于解释。确定独立权利要求的全部技术特征，必要时做权利要求解释（含功能性特征、上下位概念）。

### 3.2 全面覆盖原则（字面侵权）
把被诉技术方案分解为技术特征，与权利要求逐一特征比对：
- **全部特征都能对应 → 落入保护范围（字面侵权）**。
- **缺少任一特征 → 不构成字面侵权**，转等同分析。

### 3.3 等同原则
对不完全相同的特征，判断是否"以基本相同的手段、实现基本相同的功能、达到基本相同的效果，且本领域技术人员无需创造性劳动即可联想到"。同时核查**禁止反悔**（申请/无效程序中放弃的技术方案不得再纳入等同）与**捐献规则**（说明书公开但未写入权利要求的方案）。

### 3.4 FTO（自由实施 / 被控方视角）
被控方或产品上市前评估：
1. 锁定目标专利集合（现有技术检索 + 目标专利权利要求，走 `ip-legal-research` DB8/DB13/DB14）。
2. 对每件目标专利做落入判断（3.1–3.3）。
3. 落入的，评估规避设计空间、无效可能（现有技术抗辩/新颖性创造性缺陷）、许可可能。
4. 输出 FTO 结论：高/中/低风险专利清单 + 应对建议（规避/无效/许可/放弃）。

### 3.5 现有技术 / 先用权抗辩（被控方）
被诉落入时，检索被诉方案是否属申请日前的现有技术（现有技术抗辩），或本方在申请日前已制造/使用或已做必要准备（先用权）。

## 四、可注册性与效力研判

### 4.1 专利可专利性
- **客体适格**：是否属不授予专利权的客体（智力活动规则方法、疾病诊疗方法、纯算法等）。
- **新颖性**：与现有技术/抵触申请比对，是否已被单篇公开。
- **创造性**：三步法（确定最接近现有技术 → 确定区别特征与实际解决的技术问题 → 判断对本领域技术人员是否显而易见）。
- **实用性**：能否制造使用并产生积极效果。
- 结论给"具备/可能不具备/待检索确认"某要件，并指出补强方向。

### 4.2 商标可注册性
- **绝对理由**：显著性（通用名称/描述性/缺乏显著特征）、禁用标志（国家标志、误导、不良影响、地名等）、功能性。
- **相对理由**：与在先商标相同近似（第二节）、损害在先权利（字号/著作权/姓名/外观等）、抢注他人在先使用有一定影响商标。
- 结论给"可注册/存在障碍/建议修改或先撤障"。

### 4.3 权利效力/无效研判
针对已授权权利评估被无效/撤销风险：专利（新颖性/创造性/公开不充分/超范围/权利要求不清楚）、商标（撤三未使用、绝对/相对理由无效、恶意注册）、著作权（独创性不足/权属瑕疵）。

## 五、构成要件涵摄（通用研判方法）

对侵权认定、商业秘密认定、不正当竞争认定、驰名认定等，统一用**要件涵摄**：

```
①拆解法律构成要件（来自 ip-legal-research 的现行法条/司法解释）
  → ②本案事实逐项对照每个要件
  → ③缺口分析：全满足→成立；部分不明→标"待确认/待补证"；不满足→不成立或标"不适用"；边界→保留并标争议
  → ④给出结论 + 依据 + 风险提示（不下绝对结论、不预测胜诉率）
```

> 示例（商业秘密侵权）：要件=①存在符合三要件的商业秘密 ②被告实施了法定侵犯行为（不正当获取/披露/使用）③（如需）损害。逐项对照：秘密性—信息是否公知？（待检索/待举证）；保密措施—有无保密协议、权限管控、加密？（依 intake 事实）；侵权行为—员工离职带走并用于竞品？据此得出"就现有事实，②较可能成立，①中秘密性尚需证明信息非公知，建议补强保密措施证据"，并附律师复核提示。

## 六、输出结构（交 ip-output-formatter 适配）

研判结论统一按以下骨架组织，再由 `ip-output-formatter` 套用对应模板：

```
1. 问题定位 / 思考过程：本案权利类型、立场视角、要研判的核心问题
2. 整体结论意见：一句话核心结论（带不确定性表述，不绝对化）
3. 具体分析：
   - 法律依据（现行法条/司法解释，带效力状态；专利/商标/著作权用现行修正版条号）
   - 事实与登记状态（引用 ip-legal-research 核验结果；未核验标"待核验"）
   - 逐项分析（要件涵摄 / 特征比对 / 近似比对 / 可注册性分析）
4. 实操建议 / 注意事项：按立场给可执行下一步（取证/规避/无效/申请/协商/维权路径）
5. 律师复核提示：本分析为专业辅助，具体决策请由执业律师结合完整材料复核
```

## 关键约束

- **立场口径优先**：所有研判基于已确认视角，权利人 vs 被控方结论可能相反，不得混用。
- **依据真实**：每条结论尽量给现行有效法条/司法解释，来自 `ip-legal-research` 真实检索；专利/商标/著作权用现行修正版条号，不臆造。
- **事实必核**：权利登记状态、权利要求文本、在先权利等以官方登记库为准；未核验标"待核验"，不臆造编号/状态/检索结果。
- **不越权、不预测胜诉率**：揭示风险与法律分析，给方向；不替用户做最终商业/诉讼决策，不给胜诉概率。
- **不下绝对结论**：相似性、创造性、混淆可能性等均带程度与不确定性表述（"较可能构成""存在较大风险""尚需补证"）。
- **必附律师复核提示**：每份研判结论末尾附专业辅助免责与律师复核提示。
- **研判后交付**：交 `ip-output-formatter` 适配为分析意见 / FTO 报告 / 检索意见 / 风险清单等。
- **核验触发**：涉及大量法条/案例/登记事实引用的重要交付物，交 `ip-verification-workbench` 做溯源核验（已关联/弱关联/待核验三标签，不判对错）。
