# 知识产权法源与构成要件速查（ip-law-map）

> 六大权利板块 → 核心适用法律法规/司法解释 + 关键构成要件 + 研判要点。**仅作检索方向与研判框架的快速锚点，不作正文依据**；正文引用一律经 `ip-legal-research` 真实检索并核对现行效力与现行修正版条号。

---

## 一、著作权（含计算机软件）· IP-A

**核心法源**
- 《著作权法》（现行 2020 修正）
- 《著作权法实施条例》
- 《计算机软件保护条例》
- 《信息网络传播权保护条例》
- 最高法《关于审理著作权民事纠纷案件适用法律若干问题的解释》《关于审理侵害信息网络传播权民事纠纷案件适用法律若干问题的规定》
- 《民法典》侵权责任编（损害赔偿）

**关键构成 / 研判要点**
- 作品要件：独创性（独立完成 + 最低限度创造性）+ 可复制的智力成果；思想表达二分法。
- 作品类型：文字/美术/音乐/视听/图形/模型/计算机软件等，类型影响权利内容。
- 权属：职务作品、委托作品、合作作品、法人作品的归属规则；登记为初步证据而非确权要件。
- 侵权判定：接触 + 实质性相似；合理使用（法定情形）、法定许可抗辩。
- 软件特有：源代码/目标代码、非字面相似（结构序列组织）、开源许可证合规。

## 二、专利权（发明·实用新型·外观设计）· IP-B

**核心法源**
- 《专利法》（现行 2020 修正）
- 《专利法实施细则》
- 《专利审查指南》（可专利性、审查标准）
- 最高法《关于审理侵犯专利权纠纷案件应用法律若干问题的解释（一）(二)》
- 最高法《关于审理专利授权确权行政案件适用法律若干问题的规定（一）》

**关键构成 / 研判要点**
- 授权要件：新颖性、创造性（三步法）、实用性；客体适格（第 25 条排除项）。
- 保护范围：以权利要求为准，说明书附图解释；独立/从属权利要求。
- 侵权判定：全面覆盖原则（字面）→ 等同原则 → 禁止反悔 / 捐献规则。
- 抗辩：现有技术抗辩、先用权、合法来源（销售者）、权利无效。
- FTO：目标专利落入判断 + 规避/无效/许可路径。
- 外观：一般消费者、整体观察综合判断、设计要点、忽略功能性与惯常设计。

## 三、商标权 · IP-C

**核心法源**
- 《商标法》（现行 2019 修正）
- 《商标法实施条例》
- 《商标审查审理指南》
- 最高法《关于审理商标民事纠纷案件适用法律若干问题的解释》《关于审理商标授权确权行政案件若干问题的规定》
- 《驰名商标认定和保护规定》
- 《反不正当竞争法》（未注册标识、字号冲突）

**关键构成 / 研判要点**
- 可注册性：绝对理由（显著性、禁用标志、功能性）+ 相对理由（在先相同近似商标、在先权利、抢注在先使用有一定影响商标）。
- 近似 + 混淆：标识近似（音形义）+ 商品服务类似 + 混淆可能性（显著性、知名度、注意程度、意图）。
- 驰名商标：相关公众广为知晓；已注册驰名跨类保护、未注册驰名同类保护；个案认定、被动认定。
- 侵权类型：相同商品相同商标（直接）、类似/近似 + 混淆、反向假冒、帮助侵权。
- 抗辩：正当使用（描述性/指示性）、在先使用、连续三年不使用撤销（撤三）、注册商标专用权范围。

## 四、商业秘密 · IP-D

**核心法源**
- 《反不正当竞争法》（第 9 条商业秘密条款）
- 最高法《关于审理侵犯商业秘密民事案件适用法律若干问题的规定》
- 《劳动合同法》（竞业限制、保密义务）
- 《民法典》（保密义务、损害赔偿）；情节严重涉《刑法》侵犯商业秘密罪

**关键构成 / 研判要点**
- 秘密三要件：不为公众所知悉（秘密性）+ 具有商业价值 + 权利人采取相应保密措施。
- 秘密点界定：技术信息 / 经营信息的具体载体与边界。
- 侵权行为：不正当手段获取、披露、使用、允许他人使用；违反约定或保密要求。
- 抗辩：信息已公知、反向工程、独立研发、无保密措施、非秘密点。
- 竞业限制：范围/期限/补偿的合法性；保密义务与竞业限制区分。

## 五、域名 · IP-E

**核心法源**
- 最高法《关于审理涉及计算机网络域名民事纠纷案件适用法律若干问题的解释》
- 《中国互联网络域名管理办法》、CNNIC《国家顶级域名争议解决办法》
- ICANN 统一域名争议解决政策（UDRP，涉外通用顶级域名）
- 《反不正当竞争法》《商标法》（在先权利）

**关键构成 / 研判要点**
- 争议要件（近似三要件）：争议域名与投诉人权利标识相同/混淆性近似 + 注册人对域名无权利或正当利益 + 恶意注册或使用。
- 在先权利核查：在先商标、字号、知名标识（DB4 商标 + 企业信息）。
- WHOIS 事实：注册人、注册时间（判断在先性）、备案主体（DB12/DB11）。
- 救济：停止使用、注销/转移域名、赔偿。

## 六、其他知识产权需求（综合/战略/维权/管辖）· IP-F

**核心法源（视具体需求组合）**
- 上述各单行法 + 司法解释
- 《民事诉讼法》及其解释（管辖：知产案件级别与地域管辖、知产法院/法庭管辖）
- 最高法关于知识产权民事诉讼证据、行为保全（诉前禁令）、惩罚性赔偿的司法解释
- 《海关法》《知识产权海关保护条例》（海关备案与边境保护）
- 反不正当竞争法（兜底保护）

**研判要点**
- 维权路径选择：行政投诉 / 民事诉讼 / 刑事报案 / 海关查扣 / 平台投诉 的适用与组合。
- 赔偿计算：权利人损失 / 侵权获利 / 许可费倍数 / 法定赔偿 / 惩罚性赔偿 + 合理开支。
- 管辖：确定级别管辖与地域管辖、专门知产法院/法庭、被告住所地/侵权行为地/侵权结果地。
- 战略与治理：企业 IP 布局、尽调、许可交易、合规体系、海关备案、预警监测。
