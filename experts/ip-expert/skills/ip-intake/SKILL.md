# 知产 · 交互式信息采集

> 这是知产专家在场景识别之后、进入实质工序之前的**强制前置工序**（单点知识咨询除外）。知产结论高度依赖具体标的与事实——问错标的、缺失编号、搞反立场，后面再精细的检索与分析都会跑偏。**信息不足先问，绝不臆造权利事实。**

## 一、采集总原则

1. **缺什么问什么，不做无关追问**：只收集本场景实质工序真正需要的事实（见下方各场景清单），不堆砌问题。
2. **对话式优先，必要时清单式**：一次问 2–5 个关键问题；事实维度多时用编号清单让用户逐项回填。
3. **绝不臆造权利事实**：专利号、商标注册号/申请号、软著登记号、作品、当事人、市场范围、金额等，必须来自用户提供或标为"待确认/待补充"；严禁虚构具体编号、当事人或标的冒充真实信息。
4. **能用互斥假设覆盖的先并行**：如"按已书面约定 / 仅口头约定"、"权利人立场 / 被控方立场"两分支，可先并行给假设、标注由后续工序处理，不必每次停下追问。
5. **对抗性场景先定立场**：侵权/维权/抗辩/异议/无效等场景，必须先确认本方是**权利人（维权）**还是**被控方/被申请人（抗辩）**。
6. **鼓励用户上传凭证**：权利证书、专利/商标公告、软著登记证、涉嫌侵权的产品/文案/截图、对方的投诉函/警告函/起诉状——原件比转述准确得多。

## 二、通用采集要素（所有场景先扫一遍）

| 要素 | 说明 | 缺失影响 |
|---|---|---|
| 权利类型 | 著作权/专利/商标/商业秘密/域名/综合 | 决定适用法与工序 |
| 权利凭证与编号 | 专利号、商标注册号/申请号、软著登记号、作品名称、争议域名 | 决定能否溯源官方登记 |
| 当事人 | 权利人、对方主体（企业全称/个体户/个人）| 主体核查与管辖 |
| 涉案标的 | 具体技术/作品/标识/信息/域名内容 | 比对与涵摄的基准 |
| 市场/地域范围 | 涉及地域、目标市场、是否涉外 | 布局、管辖、涉外程序 |
| 时间线 | 创作/申请/授权/注册日、纠纷发生时间 | 保护期、时效、优先权 |
| 诉求与立场 | 想达到什么目的、权利人还是被控方 | 分析方向 |

## 三、分场景采集清单

### 著作权（IP-A）

| 场景 | 必收集的关键事实 |
|---|---|
| A1 作品检索与比对 | 待检索作品名称/作者/创作时间/类型；如需比对，提供比对目标作品 |
| A2 作品类型识别 | 作品具体内容、创作形式、是否依赖已有素材、是否 AI 生成参与 |
| A3 著作权归属认定 | 创作时间、参与人员、资金来源、物质技术条件提供方、创作指令发出方、书面约定、职责范围 |
| A4 著作权登记辅助 | 作品类型、创作完成时间、发表情况、商业用途 |
| A5 软件著作权保护专项 | 开发方式（自主/委托/合作/职务）、完成时间、发表情况、是否用开源组件（及许可证）、商业用途 |
| A6 授权方案 | 授权商业目的与场景、授权方主体资格、原始权利完整性、是否具转授权权利、对价预期 |
| A7 保护规划 | 整体创作计划（形式/参考材料/成品类型/数量/预计完成时间）|
| A8 侵权识别 | 使用主体、使用方式、使用场景、是否经许可、原作与被控作品 |
| A9 侵权抗辩（被控方）| 侵权通知/起诉状内容、被控使用行为、使用作品情况、是否有上游授权 |
| A10 维权（权利人）| 维权目标、可投入资源、急迫性、侵权主体身份/规模 |

### 专利权（IP-B）

| 场景 | 必收集的关键事实 |
|---|---|
| B1 专利内容检索 | 专利号、名称、申请人、公告号 |
| B2 专利布局检索 | 检索模板（竞对监控/技术全景/合作方尽调）、目标企业主体、技术关键词、时间跨度 |
| B3 专利侵权风险分析 | 待分析产品/技术的核心技术特征（逐项）|
| B4 专利申请策略规划 | 技术信息、创新点、预期技术效果、竞品态势、是否出海 |
| B5 申请文件撰写 | 技术交底书、创新点描述、预期保护范围 |
| B6 审查意见答复 | 审查意见通知书全文、原申请文件、对比文件 |
| B7 专利运营支持 | 运营核心目标与路径（交易/转化/融资/产业化）、拟运营专利清单 |
| B8 许可/转让方案 | 拟交易专利清单、商业变现/合作目标、交易对象、预期对价 |
| B9 维持与年费管理 | 专利号、授权日、已缴年费情况、技术当前使用价值 |
| B10 侵权认定（FTO）| 涉案专利号/权利要求、被控产品或方法的技术特征（逐项）、立场、起诉状/侵权主张 |
| B11 无效宣告策略 | 涉案专利授权文件、审查档案、提起/应对无效的背景、已知在先技术线索 |

### 商标权（IP-C）

| 场景 | 必收集的关键事实 |
|---|---|
| C1 商标内容检索 | 商标图样/标识、外文中文释义、拟保护核心商品/服务类别 |
| C2 商标布局检索 | 检索目标（竞争监测/全景规划/行业扫描）、目标企业主体、品牌矩阵、核心业务 |
| C3 注册可行性评估 | 拟注册商标类型（文字/图形/组合/立体/颜色/声音）、指定商品/服务、显著性素材 |
| C4 续展与变更 | 商标注册号、注册日期、注册人信息、是否发生名称/地址/主体变更 |
| C5 驰名商标认定 | 商标使用情况、知名度证据、市场覆盖、广告投入、获奖情况、被诉/维权背景 |
| C6 商标运营 | 运营核心目标、转化模式（许可/转让/出资/质押/特许）、商标现状 |
| C7 商标授权方案 | 授权核心目的、预期对价、拟交易商标权利有效性 |
| C8 商标侵权认定 | 涉案商标权属证明、被控标识、商品/服务类别、是否有授权、是否存在混淆、立场 |
| C9 商标维权（权利人）| 维权目标、可投入资源、急迫性、侵权主体与规模 |
| C10 驳回复审/异议应对 | 驳回通知书或异议裁定文书、核心审查意见 |
| C11 撤销/无效应对 | 撤销/无效申请书及通知文书、对方主张理由 |

### 商业秘密（IP-D）

| 场景 | 必收集的关键事实 |
|---|---|
| D1 构成认定 | 信息类型、形成过程、公开程度、价值体现、已有保密措施（合同/制度/技术/空间/载体）|
| D2 员工离职防控 | 离职员工岗位（接触秘密范围/职责/权限）、已有保密措施、竞业限制协议情况 |
| D3 保护体系建设 | 现有信息概况、已有保密措施、行业领域、企业发展情况、核心业务板块 |
| D4 侵害行为分析 | 所涉主体、行为、方式、信息 |
| D5 维权全流程（权利人）| 侵权行为线索、维权目标、损失情况、是否涉刑 |

### 域名（IP-E）

| 场景 | 必收集的关键事实 |
|---|---|
| E1 域名保护规划 | 企业品牌信息、业务范围、目标市场、拟注册域名 |
| E2 域名争议解决 | 争议域名、注册时间、注册人信息、自身商标权等在先权利证明、对方使用情况 |

### 其他（IP-F）

| 场景 | 必收集的关键事实 |
|---|---|
| F1 企业 IP 战略 | 企业信息、行业领域、核心商业模式、技术研发路线、行业地位、资本运作规划、现有 IP 资产 |
| F2 保护方式规划 | 拟保护技术内容、应用领域、商业价值、是否属必须公开的外部特征或可长期隐藏的内部秘密 |
| F3 知产尽调 | 交易背景（并购/投融资/合作）、目标主体、核查范围、核心目标 |
| F4 海关保护 | 知识产权权属信息、进出口业务情况、主要侵权风险来源 |
| F5 诉讼管辖选择 | 案由、标的金额、被告主体及所在地、涉及平台、与管辖确定相关信息 |

## 四、采集执行方式

1. **先扫通用要素，再补场景清单**：先看通用七要素哪些已知、哪些缺；再对照命中场景的专属清单补齐关键项。
2. **一次问清、分组提问**：把缺口按"最关键的先问"分组，一次问 2–5 项，避免挤牙膏式反复追问。
3. **凭证优先**：能让用户上传权利证书/公告/登记证/涉案材料的，优先请其上传，减少口述误差。
4. **信息足够即停**：达到"可以进入实质工序而不臆造"的最低门槛即可停止采集，进入 `ip-legal-research`。
5. **缺口标注移交**：仍缺失但可用互斥假设覆盖或后续检索能补的，在任务单里标注"待确认"移交下一工序，不阻塞。

## 关键约束

- 只做信息采集与澄清，不做实质检索/分析/起草。
- 绝不虚构权利凭证编号、当事人、标的、金额、市场范围。
- 对抗性场景务必先定立场口径。
- 采集完成后回填任务单的【关键缺口】字段，交接 `ip-legal-research`。
