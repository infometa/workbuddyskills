# 知产 · 场景化输出适配

> 这是知识产权专家的**正文定稿工序**。研判/起草引擎产出结论后，本 skill 按"场景识别"命中的场景，套用从 **6 份真实知产工作成果模板**提炼出的统一体例，把结果格式化成用户真正想要的样子。若任务单标记【核验工作台：必用】，本 skill 完成正文定稿后必须交给核验工作台，不得作为最终收尾。

## 一、统一输出骨架（六模板共性，所有交付默认遵循）

从 A2/B1/C5/D1/E1/F5 六份模板提炼出的通用结构，是知产交付物的标准体例：

```
1. 问题定位 / 思考过程
   - 一句话点明本案核心法律焦点、权利类型、立场视角
   - 若关键事实缺失，说明"将基于现行法与司法实践作一般性分析"，并引导用户补充

2. 整体结论意见
   - 先给核心结论（带不确定性表述，如"若满足…则可以…""具有可行性，但取决于…"）
   - 不绝对化、不预测胜诉率

3. 具体分析
   - 一、法律依据（书名号全称 + 现行修正版年份 + 条款序号 + 效力状态；引原文）
   - 二、逐项/分要件分析（要件涵摄 / 特征比对 / 近似比对 / 可注册性 / 管辖规则）
     · 每个子问题先给"结论"，再展开论证
     · 有司法解释、指导案例的，引具体条文与案号
   - （事实/登记状态：引用经核验的专业库结果；未核验标"待核验"）

4. 实操建议 / 注意事项
   - 按立场给可执行的下一步（取证清单 / 维权路径 / 补强措施 / 注册策略 / 管辖选择）
   - 分点、可操作，必要时给"路径一/二/三"并列 + 推荐策略

5. 律师复核提示（强制，每份必附）
   - 固定表述见下
```

> **律师复核提示标准表述**（六模板一致，可微调）：
> 「本内容由 AI 工具自动生成，仅为法律思路参考初稿，不构成正式的法律意见或法律建议。AI 生成内容可能存在分析不全面等"幻觉"风险。建议在采纳或应用本内容前咨询专业律师审核。」
> 专利/技术类另加："涉及专利侵权风险、无效可能性、权利要求解读等重大事项，强烈建议委托具有资质的专利代理机构或知识产权律师复核。"

## 二、输出形态选择（按场景 → 形态）

读取任务单命中的场景与【输出档位】，从下列形态选一种或组合，套用统一骨架并按形态要点微调。详见 `references/ip-output-modes.md`。

| 形态 | 适用场景 | 参考模板 | 要点 |
|---|---|---|---|
| 1. 确权/可保护性意见 | IP-A 确权、著作权保护性判断 | **A2 UI图标** | 独创性/思想表达二分/过滤测试 → 作品类型 → 权属（自然人/委托/职务）→ 权利内容与期限 → 注意事项 |
| 2. 专利内容检索报告 | IP-B 专利检索/状态核实 | **B1 CN专利** | 报告头（专利号/公告号/名称/检索日）→ 法律状态 → 基础信息 → 权利要求范围 → 官方查询链接 → 重要提示 |
| 3. 近似/驰名跨类保护意见 | IP-C 商标近似、驰名认定 | **C5 驰名商标** | 法律基础与适用条件 → 裁判考量因素 → 证据固定（驰名证据+侵权证据）→ 维权路径（行政/民事/异议无效）+ 推荐策略 |
| 4. 构成要件认定意见 | IP-D 商业秘密、各类侵权认定 | **D1 商业秘密** | 客体适格 → 三要件/构成要件逐项评估（结论先行）→ 认定难点（最弱要件）→ 补强建议 |
| 5. 注册成功率+保护策略 | IP-E 域名、注册可行性 | **E1 域名** | 成功率评估（先申请先注册/合法性/在先权利）→ 检索建议 → 系统性保护策略（防御注册/商标固本/监测续费/备案存档）|
| 6. 诉讼管辖/维权策略备忘 | IP-F 管辖、维权路径 | **F5 管辖** | 案件信息梳理 → 级别管辖 → 地域管辖（分案由）→ 管辖法院建议（选项+推荐/不建议+理由）→ 风险评估（分级⚠️）→ 实务建议 |
| 7. 侵权/FTO 比对说明 | IP-B FTO、各板块侵权比对 | 复用骨架 | 权利要求特征比对表 / 商标近似比对表 / 实质性相似比对；风险分级 + 应对 |

> 形态可组合（如"确权意见 + 维权策略"）。始终以统一骨架为底，形态要点为该场景的具体内容侧重。

## 三、工作步骤

### 0. 交付门禁（先判断，后输出）
- 若任务单【输出档位】为重量，或【核验工作台】为必用（如全面 FTO 报告、侵权比对素材汇编、维权诉讼支撑、重大确权意见），本 skill 只生成正文所需 `answer.md`，不得作为最终回复；必须交 `ip-verification-workbench` 脚本化生成 HTML。
- 门禁命中时，先确认检索资料已经核验工作台 capture/persist 形成段落库、audit 无 blocker，再生成报告；**不得手写 HTML，不得先写 HTML 再验收**。
- 无法运行核验工作台时，如实报告"重量级报告未完成"，不生成替代 HTML。

1. **取回命中场景**：从任务单读出场景、输出标准、输出档位、【核验工作台】字段。
2. **选定输出形态**：查上表与 `references/ip-output-modes.md`。
3. **套统一骨架 + 形态要点格式化**：结论先行、分要件/分项、引现行法条与案号。
4. **执行路由动作**：轻/中量对话内联输出并附来源；重量或核验必用交核验工作台。
5. **统一规范化引用**：
   - 法条：书名号全称 + **现行修正版年份**（如《中华人民共和国商标法（2019 修正）》）+ 条款序号 + 效力状态。
   - 司法解释：全称 + 条号；指导/参考案例：标准案号（如（2020）最高法知民终 538 号）。
   - 专业库事实：权利状态标注来源与检索时点，附官方查询链接；未核验标"待核验/以官方登记为准"。
6. **来源呈现克制**：正文只呈现法规/案例/登记信息名称、条号、状态与必要链接；**不说明用了哪个数据库/MCP/Skill/Web**，不写"因未接入 XX 改用公开检索"。**唯一例外**：需登录库的手动查询指引本身要写给用户（用户需自查回填）。

## 四、输出质量铁律

- **匹配场景标准**：结构命中任务单锁定的输出标准，不多不少。
- **结论先行 + 不确定性表述**：每个子问题先给结论；相似性/创造性/混淆/驰名等带程度表述，不绝对化、不预测胜诉率。
- **效力必标**：每条法律依据带现行效力状态与现行修正版条号；失效依据剔除或显著标注。
- **事实可溯源**：法条原文逐字准确；专利号/商标号/软著号/案号可核对；权利状态以官方登记为准，未核验明确标注。
- **必附律师复核提示**：每份交付末尾附标准免责与复核提示（专利技术类加代理师复核）。
- **输出介质克制**：轻/中量对话内联输出；重量或核验必用交核验工作台渲染 HTML，禁止手写 HTML。
- **手动查询指引例外**：需登录专业库时，给出面向用户的查询步骤（网址+入口+字段+操作），让用户回填，绝不谎称已查询。
