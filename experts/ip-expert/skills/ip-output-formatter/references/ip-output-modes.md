# 知产输出形态手册（ip-output-modes）

> 7 种输出形态的详细要点、场景映射与体例参考。全部以统一骨架为底（问题定位/思考过程 → 整体结论意见 → 具体分析 → 实操建议/注意事项 → 律师复核提示），下列为各形态在"具体分析"与"实操建议"部分的内容侧重。对应的真实模板骨架见 `../templates/`。

---

## 形态 1 · 确权 / 可保护性意见（参考模板 A2·UI 图标）

**适用**：IP-A 著作权确权、作品可保护性判断、软著独创性、权属确认。

**具体分析侧重**
1. **法律依据**：作品构成要件（著作权法第 3 条独创性 + 一定形式表现）。
2. **独创性判断三步**：①思想表达二分法（功能/概念不保护，具体表达保护）②过滤测试（剥离功能性、行业惯常表达、平台规范、公有领域）③"独 + 创"（独立完成 + 最低限度创作高度）。
3. **作品类型归类**：美术作品 vs 图形作品 vs 计算机软件等（依实施条例第 4 条），给出倾向性结论与理由。
4. **权属与权利内容**：分自然人作品 / 委托作品 / 职务作品（一般 vs 特殊）三种情形，分别给权利归属 + 权利内容 + 保护期限。

**实操建议侧重**：签书面协议明确权属、保留创作过程文件（源文件/草稿/带时间截图）、重要作品做著作权登记（初步证据）。

## 形态 2 · 专利内容检索报告（参考模板 B1·CN 专利）

**适用**：IP-B 专利状态核实、权利人/有效性确认、专利内容检索。

**报告结构**（此形态用"报告"体例，非纯意见）
- **报告头**：专利号、授权公告号、专利名称、检索日期、报告说明。
- **一、法律状态说明**：专利类型与保护期、当前法律状态（有效/失效）、是否有 PCT/同族、专利权人（含共有）。
- **二、专利基础信息**：申请日、申请人、发明人、IPC 分类等。
- **三、权利要求范围分析**：权利要求总数、独立/从属数量与类型（方法/设备/介质）、保护范围宽窄。
- **四、官方查询链接**：给 CNIPA 等官方核实入口（DB5/DB7/DB8）。
- **五、重要提示**：数据以官方实时为准、检索时点声明、AI 生成风险 + 专利代理师复核。

> **强约束**：专利号、公告号、权利人、法律状态必须经专业库真实核验（DB5/DB8），需登录时走手动查询指引让用户回填；**绝不臆造编号/状态/权利人**。

## 形态 3 · 近似 / 驰名跨类保护意见（参考模板 C5·驰名商标）

**适用**：IP-C 商标近似、混淆判断、驰名认定与跨类保护。

**具体分析侧重**
1. **法律基础与适用条件**：商标法第 13 条第 3 款（已注册驰名跨类）；逐项列适用条件（已注册 + 驰名 + 复制摹仿翻译 + 误导公众致损）。
2. **驰名认定因素**：商标法第 14 条 + 最高法驰名保护解释（知晓程度、使用/宣传持续时间程度地域、受保护记录等）；"按需认定""个案认定"原则。
3. **裁判考量因素**：显著程度、相关公众知晓、商品关联程度等。

**实操建议侧重**
- **证据固定**：驰名证据（市场份额/销售/宣传/持续使用/受保护记录/声誉+用户误认公证）+ 侵权证据（主体行为/规模获利/主观恶意）。
- **维权路径三选**：路径一行政查处（快速制止）、路径二民事诉讼（获赔）、路径三异议/无效宣告；末给**推荐策略**（如"行政投诉+民事诉讼并行"）。

## 形态 4 · 构成要件认定意见（参考模板 D1·商业秘密）

**适用**：IP-D 商业秘密认定、各类侵权构成认定、不正当竞争认定。

**具体分析侧重**
1. **客体适格**：先定性客体是否属受保护对象（如算法属"技术信息"，引反法 + 最高法商业秘密规定第 1 条列举）。
2. **构成要件逐项评估（结论先行）**：每个要件先给"结论"，再引法条与司法解释论证 + 本案事实对照。商业秘密即三要件：秘密性（不为公众所知悉）、价值性、保密性。
3. **认定难点**：点出**最弱要件**（如商业秘密中保密措施常最弱），引反面案例说明证据不足的后果（如（2020）京 0105 民初 68246 号、（2020）最高法知民终 538 号）。

**实操建议侧重（补强建议）**：针对最弱要件给可落地补强清单（完善保密制度文件、签专项保密协议+竞业限制、访问控制/物理隔离/代码加密混淆/离职审计并留痕）。

## 形态 5 · 注册成功率 + 保护策略（参考模板 E1·域名）

**适用**：IP-E 域名注册可行性与保护、注册成功率评估。

**具体分析侧重**
1. **成功率评估三条件**：①尚未被他人注册（先申请先注册，互联网域名管理办法第 26 条）②合法性（第 28 条禁止性内容 + 第 30 条真实身份信息）③未侵犯在先权利（最高法网络域名解释第 4、5 条四要件与恶意情形）。

**实操建议侧重**
- **检索建议**：域名 WHOIS 查询（DB12）、商标权冲突检索（DB4，需登录走手动指引）、企业名称冲突检索（企业信用系统）。
- **系统性保护策略**："注册先行、商标固本、使用留痕、积极维权"：全类覆盖+防御注册（.cn/.net/中文域名/错拼变体）、商标同步注册、明晰注册主体、信息安全与域名锁定、续费管理、ICP 备案、档案管理、监测维权机制。

## 形态 6 · 诉讼管辖 / 维权策略备忘（参考模板 F5·管辖）

**适用**：IP-F 诉讼管辖选择、维权路径与诉讼策略。

**具体分析侧重**
1. **案件基本信息梳理**：案由、被告主体与住所地、平台、标的额。
2. **级别管辖**：依最高法知产案件管辖规定 + 各地基层法院管辖标的额通知，判由基层/中院管辖。
3. **地域管辖（分案由）**：商标侵权（侵权实施地/储藏地/查封扣押地/被告住所地）、不正当竞争（一般侵权规则）、合并审理处理（按主要法律关系）。

**实操建议侧重**
- **管辖法院建议**：给**选项 + 推荐/不建议 + 理由**（如"选项一 被告住所地—推荐；选项二 平台所在地—不建议，案件量大周期长"）。
- **风险评估分级**：管辖异议风险、审理周期、审判经验、合并审理风险，各标⚠️低/中低/中/高。
- **实务建议**：诉讼策略（主诉/补充诉请、平台是否列共同被告、证据准备）+ 保全建议（财产/证据/行为保全）+ 立案注意事项。

## 形态 7 · 侵权 / FTO 比对说明（复用骨架，无单独模板）

**适用**：IP-B FTO、专利/商标/著作权侵权比对。

**具体分析侧重**
- **专利**：权利要求技术特征分解 → 被诉方案特征 → **逐特征比对表**（全面覆盖/等同/不落入）→ 禁止反悔/捐献核查。
- **商标**：标识近似（音形义）+ 商品服务类似 + 混淆可能性比对表。
- **著作权**：接触 + 实质性相似（先思想表达二分过滤，再比对受保护表达）。
- **FTO**：目标专利清单 + 逐件落入判断 + 风险分级（高/中/低）+ 应对（规避/无效/许可/放弃）。

**实操建议侧重**：按风险等级给应对优先级；证据固定与专业复核提示。

---

## 通用规范（所有形态）

- 结论先行、分要件/分项；法条用现行修正版全称+条号+效力状态；案号标准格式。
- 权利登记事实经专业库核验，未核验标"待核验/以官方登记为准"；需登录库给手动查询指引。
- 不预测胜诉率、不绝对化；每份必附律师（及专利代理师）复核提示。
- 重量级/核验必用交 `ip-verification-workbench` 渲染 HTML，禁止手写 HTML。
