# 知识产权专业数据库目录（DB1–DB24）

> 本目录汇集人类知产律师/代理师开展工作会用到的**权威与专业数据库**，供 `ip-legal-research` 按场景指引检索或调用。
> **落地方式两类**：
> - **【可自动化】**：有 MCP/Skill 或公开可抓取网页时，由检索引擎直接调用取回可核验正文。
> - **【手动查询指引】**：需登录/验证码/付费/仅人工可查（多数官方权属库属此类）时，**生成面向用户的查询步骤（网址+入口+检索字段+操作），让用户自查后回填，绝不谎称已查询**。
> 注：sheet 中「境内商用数据库」（智慧芽 PatSnap、incoPat、佰腾网、壹专利、科睿唯安 Clarivate）按用户要求**不整合进强制工作流**，仅在用户已购买/已配置对应工具时作为可选增强来源，本目录列于末尾备查。
>
> **铁律**：无论哪种落地方式，专利号/商标号/软著登记号/域名等权利登记信息，最终都以官方登记库为准；无法核实的一律标注"以官方登记为准 / 待核验"，绝不臆造编号或状态。
>
> **官方域名锚定（防幻觉）**：凡向用户输出官方查询网址，**必须逐字复制本目录 DB1–DB24 的链接**，禁止凭记忆生成或改写域名。特别注意以下高频错误：
> - 国家知识产权局现行域名为 **`cnipa.gov.cn`**，机构改革前的旧域名 **`sipo.gov.cn` 已停用，禁止使用**（如错误的 `epub.sipo.gov.cn` 应为 `epub.cnipa.gov.cn`）。
> - 中国专利审查信息查询请用 DB5 **`tysfjk.cponline.cnipa.gov.cn/portal/`**，**不存在** `cpquery.cnipa.gov.cn` 这一域名，禁止编造。
> - 中国专利公布公告用 DB7 `epub.cnipa.gov.cn`；专利检索与分析用 DB8 `pss-system.cponline.cnipa.gov.cn`；商标查询入口用 DB4 `sso.cnipa.gov.cn/am/#/login`。
> - 输出网址前若无法在本目录中逐字匹配到，宁可只给"库名 + 进入路径"文字指引，也不得杜撰 URL。
