# 知识产权场景决策表

> 本表是场景识别的核心知识库。命中某个三级场景后，即可确定该场景的「核心应用目的」「输出标准」「典型工作流」「专业数据库映射」，直接驱动后续交互采集、专业检索、分析与实质工序。
> 三级结构：场景分类（一级：著作权/专利权/商标权/商业秘密/域名/其他）→ 二级场景 → 三级场景（IP-A~IP-F 编号）。
> 数据库落地：每个场景末尾标注【专业库】，指引"去哪个库、查什么"；详见 `ip-database-directory.md`（本表引用其编号 DB1–DB24）。带 ⭐ 的场景在 sheet 中附有官方模板示例，输出请参照对应模板范式（见 ip-output-formatter）。

## 一级场景 A：著作权（IP-A）

### IP-A1. 著作权作品检索与比对
- **二级场景**：检索与分析
- **核心目的**：检索特定作品的著作权登记信息、权属状态，并与用户提供的作品做原创性比对，辅助判断潜在侵权或权属冲突。
- **输出标准**：检索结果汇总（登记信息/权属状态/公开情况）+ 原创性比对分析表 + 风险提示 + 引导用户通过官方途径核实。
- **是否交互采集**：是。需收集待检索作品名称、作者、创作时间、作品类型；如需比对，收集比对目标作品。
- **典型工作流**：①引导提供作品名称/作者/创作时间/类型 → ②调用著作权登记数据库及公开网络检索登记状态、权属、公开传播情况 → ③若有比对目标，提取两作品独创性表达要素做实质性相似初步比对 → ④识别潜在权属冲突或侵权风险点 → ⑤出具《著作权检索与比对报告》附官方查询链接，提示以官方数据为准。
- **典型提问**：请帮我检索一款名为 XXX 的游戏软件是否进行了著作权登记，以及其著作权人是谁？
- **输出档位**：中量　**主导工序**：research + analysis-engine
- **专业库**：DB9 中国版权保护中心著作权登记系统、DB10 全国作品登记信息数据库（需登录/手动查询）。

### IP-A2. 作品类型识别 ⭐
- **二级场景**：确权与登记
- **核心目的**：辅助判断某创作成果是否构成受著作权法保护的作品，明确作品类型及可能涉及的权利类型，提示保护期限。
- **输出标准**：总结性说明（是否构成著作权作品）+ 法律依据 + 作品类型定性 + 权利类型说明 + 保护期限计算 + 权属确认注意事项 + 律师复核提示。
- **是否交互采集**：是。需收集拟确权作品的具体内容、创作形式、是否依赖已有素材。
- **典型工作流**：①引导提供作品内容/创作形式/是否依赖素材 → ②依《著作权法》审查独创性，剥离思想、法律文件、单纯事实消息、通用表格公式等不受保护元素 → ③确定法定类别（文字/美术/音乐/视听/计算机软件等）→ ④按自然人/法人/职务作品明确人身权与财产权内容、保护期起算与终止 → ⑤提示不同类型作品权属确认注意事项 → ⑥提示登记/时间戳/区块链/公证等权利证明方式优缺点 → ⑦输出总结（定性结论+依据+权利清单+保护期+确权指导）→ ⑧提示复杂权属需律师确认。
- **典型提问**：我设计了一套 UI 界面图标，请问其可以被著作权法保护吗？
- **输出档位**：中量　**主导工序**：analysis-engine（确权/涵摄）
- **专业库**：DB9（软著/作品登记查询辅助佐证）。

### IP-A3. 著作权归属认定
- **二级场景**：确权与登记
- **核心目的**：针对职务作品、委托作品、合作作品等特殊情形，辅助判断著作权归属主体。
- **输出标准**：总结性结论 + 法律依据 + 归属类型判断 + 权利内容说明 + 权属确认注意事项 + 律师复核提示。
- **是否交互采集**：是。需查明创作时间、参与人员、资金来源、物质技术条件提供方、创作指令发出方、书面约定、职责范围。
- **典型工作流**：①引导提供创作背景（时间/人员/资金/条件/指令/约定/职责）→ ②对照《著作权法》穿透审查作品性质，认定类别（个人/职务/委托/合作/法人）→ ③区分财产权+人身权归属、法定归属与约定归属的优先顺序 → ④核查转让、许可、继承、演绎、汇编导致的复合权利冲突 → ⑤输出初步归属结论并提示合同约定优先性 → ⑥提示复合权利冲突需律师深度审查。
- **典型提问**：公司安排我业余时间为甲方客户设计 LOGO，设计稿著作权归我还是归公司？
- **输出档位**：中量　**主导工序**：analysis-engine（权属涵摄）
- **专业库**：DB9/DB10。

### IP-A4. 著作权登记辅助
- **二级场景**：确权与登记
- **核心目的**：为原创作品提供著作权登记策略建议（必要性、类型、材料、流程）。
- **输出标准**：登记必要性评估 + 登记类型建议 + 材料准备 + 办理流程 + 办理入口指引 + 费用预估 + 时限与结果 + 注意事项。
- **是否交互采集**：是。需收集作品类型、创作完成时间、发表情况、商业用途。
- **典型工作流**：①引导提供作品类型/完成时间/发表/用途 → ②评估登记必要性（非强制但有初步证据效力），分析对维权、交易的价值 → ③按作品类型建议登记类型与机构（中国版权保护中心/各省版权局）→ ④输出材料清单（申请表/样本/身份证明/权属证明）→ ⑤提供流程时间表与费用估算 → ⑥出具《著作权登记策略建议书》。
- **典型提问**：我设计了一款软件，该如何申请著作权登记，需要什么材料？
- **输出档位**：中量　**主导工序**：drafting-engine（策略/办理指引）
- **专业库**：DB9 中国版权保护中心著作权登记系统（办理入口，需登录/手动）。

### IP-A5. 软件著作权保护专项
- **二级场景**：确权与登记
- **核心目的**：针对计算机软件作品，提供软著确权、登记、源代码保护、开源合规专项分析。
- **输出标准**：软件权属分析结论 + 登记建议 + 源代码保护方案 + 开源许可证合规分析（如适用）+ 第三方组件风险清单 + 引导补充完善。
- **是否交互采集**：是。需收集开发方式（自主/委托/合作/职务）、完成时间、发表情况、是否用开源组件、商业用途。
- **典型工作流**：①引导提供软件信息 → ②依《计算机软件保护条例》分析权属（区分开发情形）→ ③评估软著登记必要性与材料指引 → ④如涉开源组件，分析许可证类型（GPL/LGPL/MIT/Apache）合规要求与传染性风险 → ⑤输出源代码保护建议（混淆/加密/访问控制）与软著+商业秘密双重保护策略 → ⑥出具《软件著作权保护方案》。
- **典型提问**：自主开发的 roguelike 游戏用了开源组件，是否需要软著登记？如何保护？
- **输出档位**：重量　**主导工序**：analysis-engine + drafting-engine
- **专业库**：DB9 著作权登记系统。

### IP-A6. 著作权授权方案规划与审查
- **二级场景**：运营与管理
- **核心目的**：针对具体作品对外授权需求，输出合规授权方案并审查细节（范围/类型/对价）。
- **输出标准**：总结性说明 + 总体方案及细节 + 不同模式风险提示 + 合同核心条款建议 + 引导补充 + 律师复核提示。
- **是否交互采集**：是。需收集授权商业目的、应用场景、授权方主体资格与原始权利完整性、是否具转授权权利。
- **典型工作流**：①提取授权目的与场景，核实授权方主体资格、原始权利、转授权权利 → ②拆解设计授权权利清单（作品/权利种类/地域/期限/性质：独占/排他/普通）→ ③引导补充费用结构（一次性/版税/保底+提成），设支付节点与审计权 → ④设计履约风控与质量控制（使用标准/审核/修改权限/转授权限制）→ ⑤检索该作品类型主流授权模式 → ⑥出具《著作权授权方案法律意见书》，提示转授权与终止条款需律师审核。
- **典型提问**：我方美术作品想授权合作方做周边产品，如何设计授权方案保护我方利益？
- **输出档位**：重量　**主导工序**：drafting-engine
- **专业库**：DB9（核实原始权利登记）。

### IP-A7. 著作权保护规划
- **二级场景**：运营与管理
- **核心目的**：为创作初期的后期权属认定需求规划路径，建立从创作到维权的全链条保护框架。
- **输出标准**：总结性说明（核心原则/可行性）+ 保护措施清单 + 实施时间表 + 预算估算 + 风险预警机制 + 引导补充。
- **是否交互采集**：是。需收集整体创作计划（形式/参考材料/成品类型/数量/预计完成时间）。
- **典型工作流**：①识别目标，引导补充创作计划 → ②对照《著作权法》受保护作品规定，结合创作场景判断可保护性空间 → ③输出实操方案（保护措施清单：创作记录留存/登记/存证/合同安排；实施时间表；预算）→ ④建立风险预警机制识别权属风险点 → ⑤出具《著作权保护规划建议书》。
- **典型提问**：我想创作一个 AI 生成的漫画，怎么做才能被认定我对其有著作权？
- **输出档位**：重量　**主导工序**：drafting-engine
- **专业库**：DB9。

### IP-A8. 著作权侵权行为识别
- **二级场景**：侵权与维权
- **核心目的**：辅助判断某行为是否构成著作权侵权，识别侵权类型、主体，排查抗辩事由。
- **输出标准**：侵权定性结论 + 侵权行为类型 + 实质性相似比对明细 + 抗辩事由排查结论 + 法律依据 + 维权路径建议 + 律师复核提示。
- **是否交互采集**：是。需收集使用主体、使用方式（复制/发行/改编/信息网络传播）、使用场景、是否经许可。
- **典型工作流**：①提取涉嫌侵权行为基础信息 → ②用"思想与表达二分法"提取原作独创性表达要素 → ③与被控作品做深度实质性相似逐一要素比对 → ④结合"接触"可能性综合判定 → ⑤定性侵权类型（直接/间接/帮助/教唆），识别被侵害权利种类 → ⑥审查合理使用、法定许可等抗辩事由 → ⑦出具《著作权侵权认定法律意见书》→ ⑧提示实质性相似结论需律师复核。
- **典型提问**：有人在电商平台未经授权出售印有我绘画作品的抱枕，构成著作权侵权吗？
- **输出档位**：重量　**主导工序**：analysis-engine（实质性相似比对）
- **专业库**：DB9/DB10。

### IP-A9. 著作权侵权抗辩策略制定
- **二级场景**：侵权与维权
- **核心目的**：为被控侵权方提供抗辩策略分析（合理使用/法定许可/权利用尽/不侵权等）。
- **输出标准**：抗辩策略总体结论 + 各抗辩事由可行性分析 + 证据准备清单 + 反诉/反制建议 + 应对步骤。
- **是否交互采集**：是（被控方立场）。需收集侵权通知/起诉状内容、被控使用行为、使用作品情况。
- **典型工作流**：①引导提供被控事实基础 → ②审查对方权利基础是否稳定（是否享有著作权/是否在保护期/权属瑕疵）→ ③逐一分析抗辩事由（不侵权/合理使用《著作权法》第24条12种/法定许可/权利用尽/诉讼时效）→ ④梳理各抗辩所需证据清单 → ⑤评估反诉或主动无效对方权利可能性 → ⑥出具《著作权侵权抗辩策略方案》。
- **典型提问**：收到字体公司律师函说公众号海报字体侵权，但海报是合作方出具且有授权，如何抗辩？
- **输出档位**：重量　**主导工序**：analysis-engine + drafting-engine
- **专业库**：DB9/DB10。

### IP-A10. 著作权维权策略制定
- **二级场景**：侵权与维权
- **核心目的**：针对确认的侵权情形，制定全面维权策略与行动路径（证据保全/途径选择/执行）。
- **输出标准**：维权路径选择建议（民事/行政/刑事）+ 具体行动步骤 + 证据保全方案 + 诉讼时效提示 + 引导补充。
- **是否交互采集**：是（权利人立场）。需收集核心维权目标、可投入资源、急迫性、侵权主体情况。
- **典型工作流**：①引导输入维权目标（停止侵权/赔偿/消除影响），评估资源与急迫性 → ②结合侵权主体身份/规模/偿付能力评估严重程度 → ③综合评估发函/平台投诉/行政举报/民事诉讼/刑事报案可行性 → ④制定分层阶梯维权路线图，规划证据保全 → ⑤提示维权风险（时效/赔偿年限/败诉/执行不能/反诉/商誉）→ ⑥出具《著作权维权策略方案》。
- **典型提问**：一家公司长期大量使用我的绘画作品制作商品全网销售，如何最有效维权？
- **输出档位**：重量　**主导工序**：drafting-engine（策略）
- **专业库**：DB9/DB10。

## 一级场景 B：专利权（IP-B）

### IP-B1. 专利内容检索 ⭐
- **二级场景**：检索与分析
- **核心目的**：检索确认某项专利的当前法律状态及权利要求范围，提供专利基础信息汇总。
- **输出标准**：法律状态说明 + 专利基础信息（申请号/授权公告号/名称/申请日/授权日等）+ 权利要求范围分析 + 引导官方途径查询。
- **是否交互采集**：是。需收集专利号、名称、申请人、公告号。
- **典型工作流**：①引导提供专利号/名称/申请人/公告号 → ②调用专利库做标题/摘要/权利要求/全文组合检索 → ③提取基础信息与优先权日，核实法律状态、存续期、年费缴纳 → ④输出《专利内容检索报告》（法律状态/保护范围）附官网查询链接，提示以官方实时数据为准。
- **典型提问**：确认专利 CN202512036978.4 的状态、权利人及是否有效。
- **输出档位**：中量　**主导工序**：research + analysis-engine
- **专业库**：DB5 专利业务办理统一认证平台（审查/法律状态）、DB7 中国专利公布公告、DB8 专利检索与分析系统；境外 DB13 PATENTSCOPE、DB14 Espacenet。

### IP-B2. 专利布局检索
- **二级场景**：检索与分析
- **核心目的**：检索某公司/技术的专利申请、授权、使用情况，提供专利布局全景分析。
- **输出标准**：专利申请情况汇总 + 年度趋势 + IPC 分类技术分布 + 地域布局 + 法律状态分布 + 可视化布局图谱 + 引导官方查询。
- **是否交互采集**：是。需明确检索模板（竞对监控/技术全景/合作方尽调）、目标企业主体、技术关键词、时间跨度。
- **典型工作流**：①明确检索模板与核心要素 → ②构建多重组合检索（名称变体/发明人/分类号）→ ③检索去重生成专利清单 → ④统计年度趋势/IPC分布/地域/法律状态，绘制布局图谱 → ⑤关联许可备案/转让/质押记录研判运营策略，比对行业标杆识别技术空白 → ⑥形成《专利布局检索分析报告》附官网链接。
- **典型提问**：xx 公司截至 2026 年 7 月申请了哪些专利，是否存在对外授权？
- **输出档位**：重量　**主导工序**：research + analysis-engine
- **专业库**：DB8 专利检索与分析系统（申请人分析/同族/法律状态）、DB2 权利人图谱查询（许可/转让/质押图谱）、境外 DB13/DB14。

### IP-B3. 专利侵权风险分析
- **二级场景**：检索与分析
- **核心目的**：产品上市或技术实施前，分析是否存在侵犯他人专利权的风险，提供风险等级与规避方案。
- **输出标准**：相关专利清单 + 权利要求比对分析 + 侵权风险等级（高/中/低）+ 规避建议 + 律师复核提示。
- **是否交互采集**：是。需收集待分析产品/技术的核心技术特征。
- **典型工作流**：①提取核心技术特征形成清单 → ②以关键词/IPC 检索相关领域有效专利 → ③初筛形成高相关目标专利清单 → ④依《专利法》对技术特征与目标专利权利要求逐一拆解比对 → ⑤对高风险专利做法律稳定性评估（调审查历史/确权文书研判无效概率）→ ⑥排查免责情形（现有技术抗辩/先用权/权利用尽/科研实验/行政审批例外）→ ⑦评估风险等级并制定规避设计/无效/许可谈判方案 → ⑧交付《专利侵权分析报告》→ ⑨提示律师复核。
- **典型提问**：新型扫地机器人量产前，帮我分析是否侵犯竞对专利风险。
- **输出档位**：重量　**主导工序**：analysis-engine（技术特征比对+稳定性）+ drafting-engine（规避）
- **专业库**：DB8 专利检索与分析系统、DB5 审查信息、境外 DB13/DB14；商用库（智慧芽/incoPat/科睿唯安）可选。

### IP-B10. 专利侵权认定分析（FTO） ⭐（方法论核心）

- **典型提问**：竞对起诉我公司产品侵犯其专利，帮我分析侵权是否成立及我方抗辩策略。
- **输出档位**：重量　**主导工序**：analysis-engine（技术特征逐项比对+稳定性）+ drafting-engine（抗辩/应对）

## 一级场景 F：其他知识产权需求（IP-F）

### IP-F1. 企业知识产权战略规划
- **二级场景**：知识产权综合管理
- **核心目的**：帮助企业梳理 IP 资产，制定覆盖或着重于专利/商标/著作权/商业秘密的整体 IP 战略。
- **输出标准**：企业 IP 现状诊断 + IP 战略目标设定 + 各类知识产权组合保护方案 + IP 运营建议 + 风险防控措施 + 引导补充。
- **是否交互采集**：是。需收集企业信息、行业、商业模式、技术研发路线、行业地位、资本运作规划。
- **典型工作流**：①引导补充企业信息与战略核心目标 → ②梳理现有 IP 资产（数量/规模/质量/权属/运营/保护）→ ③结合核心商业目标制定 IP 竞争策略 → ④设计适配的保护战略与方案，输出《企业知识产权战略规划方案》。
- **典型提问**：主营电子器械研发、有些 IP 制度但无专人负责、存在技术被竞对抢先申请专利问题，如何设计 IP 管理制度？
- **输出档位**：重量　**主导工序**：drafting-engine（战略设计）
- **专业库**：DB8/DB4（现有资产盘点）、企业信息（qcc-company）。

### IP-F2. 知识产权保护方式规划
- **二级场景**：知识产权综合管理
- **核心目的**：针对具体内容，分析判断应采用哪种保护方式（专利/商业秘密/著作权/商标权等）。
- **输出标准**：总结性说明 + 不同保护方式核心差异对比 + 不同方案分析 + 推荐策略 + 总结 + 引导补充。
- **是否交互采集**：是。需收集拟保护技术内容、应用领域、商业价值、是否属必须公开的外部特征或可长期隐藏的内部秘密。
- **典型工作流**：①引导描述技术内容/领域/价值/公开属性 → ②对比不同保护方式在法律层面的核心差异 → ③统筹测算不同路径保护优势/成本差异/潜在障碍/风险 → ④输出《知识产权保护规划建议书》（优劣对比/推荐模式/实施方案）。
- **典型提问**：一套神经外科医疗器械技术，是公司核心 IP 资产，应采用专利保护还是商业秘密保护？
- **输出档位**：重量　**主导工序**：analysis-engine（保护方式比较）+ drafting-engine
- **专业库**：DB8、法规（pkulaw）。

### IP-F3. 知识产权尽职调查
- **二级场景**：知识产权综合管理
- **核心目的**：在企业并购、投融资 IPO、重大商业合作前，对目标主体进行知识产权尽职调查。
- **输出标准**：IP 尽调报告框架 + 尽调检查清单（专利权/商标权/著作权/商业秘密）+ 关键风险点提示 + 交割建议 + 引导补充。
- **是否交互采集**：是。需收集交易背景、核查范围、核心目标。
- **典型工作流**：①收集交易背景，明确核查范围与核心目标 → ②核查目标主体名下专利/商标/著作权/域名权属证明与法律状态 → ③审查法律风险（权属不清/专利即将到期/商标在撤销无效程序中/侵权纠纷），逐项标注风险并评估是否构成实质性障碍 → ④提交《知识产权尽职调查报告》（权属图谱+风险评级+风险提示+交割建议）。
- **典型提问**：准备收购一家医疗器械研发生产公司，签约前帮我制定知识产权尽调方案。
- **输出档位**：重量　**主导工序**：research + analysis-engine + drafting-engine
- **专业库**：DB8/DB4/DB9/DB1（各权利核查）、企业信息（qcc-company/tyc-mcp）。

### IP-F4. 知识产权海关保护策略
- **二级场景**：海关保护
- **核心目的**：为企业提供知识产权海关备案策略和边境保护方案，防范进出口环节侵权风险。
- **输出标准**：海关备案建议 + 备案清单 + 边境保护方案 + 维权流程指引 + 引导补充。
- **是否交互采集**：是。需收集知识产权权属信息、进出口业务情况、主要侵权风险来源。
- **典型工作流**：①引导提供权属/进出口业务/风险来源 → ②依《知识产权海关保护条例》评估备案必要性与可备案类型（商标/专利/著作权）→ ③设计备案策略，输出备案清单与材料指引 → ④制定边境保护方案（主动依申请扣留 vs 被动依职权扣留）→ ⑤提供查获侵权后维权流程指引（担保金/调查/处置）→ ⑥出具《知识产权海关保护策略方案》。
- **典型提问**：产品大量出口，发现一批海外产品配件使用了我们商标，如何进行知识产权海关保护？
- **输出档位**：重量　**主导工序**：drafting-engine
- **专业库**：法规《海关保护条例》（pkulaw）、DB4/DB8/DB9（权属核查）、海关总署备案系统（手动）。

### IP-F5. 知识产权诉讼管辖选择 ⭐
- **二级场景**：诉讼程序性策略
- **核心目的**：为知识产权纠纷提供诉讼管辖法院策略。
- **输出标准**：管辖法院建议 + 具体分析 + 风险评估 + 实务建议 + 律师复核提示。
- **是否交互采集**：是。需收集案由、标的金额、与管辖确定相关的案件信息。
- **典型工作流**：①识别关键信息（案由/标的金额/管辖相关信息）→ ②检索最新知识产权管辖规定，分析不同管辖选择的理由与风险 → ③检索实务考虑或风险 → ④出具《知识产权诉讼管辖选择方案》，建议专业人士确认。
- **典型提问**：侵害商标权和不正当竞争的案子想起诉，侵权主体是成都市金牛区个体工商户，平台是淘宝，预计起诉金额80万，如何选择管辖？
- **输出档位**：中量　**主导工序**：research（管辖规定）+ analysis-engine
- **专业库**：法规/司法解释/管辖规定（pkulaw）、企业信息（qcc-company 核查被告主体）。

## 输出档位与交付形态规则

| 输出档位 | 交付物形态 | 是否交互采集 | 主导工序 |
|---|---|---|---|
| 轻量 | 单点 IP 知识咨询、概念解释 | 通常否 | 直接回答 / 轻量检索 |
| 中量 | 检索比对报告、注册可行性评估、年费/续展建议、管辖建议 | 是 | research / analysis-engine |
| 重量 | 侵权/FTO 分析意见、无效策略、维权方案、申请文件撰写、战略规划、尽调报告、体系建设方案 | 是 | analysis-engine / drafting-engine（+ 核验工作台）|

> 重量级场景任务单必须写明完整技能链，并经交互采集补齐关键事实后再进入实质工序；标记【核验工作台：必用】的须最终路由到 `ip-verification-workbench`。
