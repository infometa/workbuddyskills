# 知产 · 起草与策略引擎

> 这是知识产权专家的**起草与策略工序**——承接 `ip-intake` 的事实、`ip-legal-research` 的依据/事实、`ip-analysis-engine` 的研判结论，产出具体交付物。覆盖：①申请导向文书 ②审查/争议答复文书 ③布局与组合设计 ④维权文书与方案 ⑤战略与治理设计 ⑥管辖选择 ⑦体系建设。核心是把研判结论严谨落地为可执行文书或方案，**并始终附律师/专利代理师复核提示——本引擎为专业辅助，不替代执业律师或专利代理师**。

## 零、起草前必做

1. **确认立场与目标**（来自 intake）：权利人 / 被控方；申请？答复？维权？布局？战略？
2. **优先加载用户自有模板/范本**（若有）：用户提供的申请模板、警告函范本、公司 IP 管理制度等，优先套用其惯用体例与表述，缺口才用通用体系补齐并标注来源。
3. **依据就位**：涉及法律主张的，先经 `ip-legal-research` 取回现行法条/司法解释与登记事实；涉及技术/近似判断的，先经 `ip-analysis-engine` 得出研判结论。**不得凭记忆编造法条、专利号、案号、检索结果。**

## 一、申请导向文书（IP-B 申请 / IP-A 登记 / IP-C 注册）

> **边界**：正式专利申请文件、商标注册申请的实质定稿属执业代理师/律师职责范围。本引擎提供**结构化辅助与思路**，并强提示由专业代理机构定稿提交。

| 交付类型 | 内容 | 强提示 |
|---|---|---|
| 专利交底书组织 / 权利要求思路 | 梳理发明点、现有技术区别、技术方案层次；提示独立/从属权利要求布局思路、保护范围与稳定性平衡 | 权利要求撰写与提交由专利代理师定稿 |
| 商标注册申请方案 | 商品服务类别选择（区分表）、指定商品项、防御性注册与近似规避、申请主体选择 | 提交前做近似检索（DB4/DB22/DB24，多需手动查询指引）|
| 著作权/软著登记指引 | 登记材料清单、作品类型选择、权属证明、登记流程（DB9/DB10）| 登记为初步证据，非确权要件 |

## 二、审查 / 争议答复文书

| 场景 | 起草要点 |
|---|---|
| 专利审查意见（OA）答复思路 | 针对新颖性/创造性/公开不充分/超范围审查意见，组织争辩理由 + 修改方向（缩小/澄清权利要求）；结合三步法逐条回应 |
| 商标驳回复审 / 异议 / 无效答辩 | 针对绝对/相对理由组织理由与证据（使用证据、知名度证据、显著性论证、共存说明）|
| 专利无效答辩 / 请求 | 权利人：维持有效的争辩与证据；请求人：无效理由（现有技术/公开不充分等）+ 证据组织 |
| 著作权/商业秘密/域名争议答辩 | 按 `ip-analysis-engine` 的要件涵摄结论组织抗辩或主张 |

> 答复文书须逐条对应审查/争议意见，理由与证据挂钩；法条用现行修正版条号。

## 三、布局与组合设计（IP-B 布局 / IP-F 战略）

- **专利布局**：核心专利 + 外围专利 + 防御性公开；技术分解 → 申请时机 → 申请类型（发明/实用新型/外观组合）→ 地域布局（本土 + PCT/巴黎公约海外）。
- **商标布局**：核心类别 + 关联类别防御注册、多要素（文字/图形/组合）、跨境（马德里体系）。
- **组合协同**：同一产品用专利+商标+著作权+商业秘密多重保护的搭配设计。

## 四、维权文书与方案（IP-F 维权 / 各板块侵权）

| 交付类型 | 内容 |
|---|---|
| 侵权警告函 / 律师函 | 权利基础（登记事实经核验）、侵权事实与比对、法律依据、诉求与期限、后果告知；措辞留有协商空间 |
| 侵权比对说明 | 依 `ip-analysis-engine`：权利要求特征比对表 / 商标近似比对 / 作品实质性相似比对 |
| 维权路径方案 | 行政投诉 / 民事诉讼 / 刑事报案 / 海关查扣 / 平台投诉 的适用、组合、优劣与建议顺序 |
| 证据固定建议 | 公证购买、时间戳、区块链存证、侵权网页/实物取证清单（提示由律师主导取证合法性）|
| 赔偿主张思路 | 权利人损失/侵权获利/许可费倍数/法定赔偿/惩罚性赔偿 + 合理开支的计算路径与举证方向 |

## 五、战略与治理设计（IP-F）

- **企业 IP 战略**：结合业务与竞品，规划确权、布局、运营（许可/转让/质押）、维权、预警的整体方案。
- **IP 尽职调查**：交易/投融资中的知产尽调清单（权利有效性、权属、许可负担、诉讼、侵权风险）。
- **海关备案与边境保护**：备案要点与查扣流程指引。
- **合规与预警**：上市/投放前的 FTO 与合规审查安排、侵权监测预警机制。

## 六、管辖选择备忘（IP-F 诉讼管辖）

依 `ip-legal-research` 的现行管辖规定，输出管辖分析备忘：
1. **级别管辖**：案件类型对应的一审法院层级（部分专利等技术类案件由中院/知产法院一审，最高法知产法庭二审）。
2. **地域管辖**：被告住所地 / 侵权行为地（实施地）/ 侵权结果地；网络侵权特殊规则。
3. **专门管辖**：知识产权法院（北上广）、知产法庭；跨区域管辖安排。
4. **策略考量**：结合便利性、地方裁判倾向、保全便利、执行便利给出建议（客观提示，不预测结果）。

> 模板示例（F5 诉讼管辖，如"成都金牛区、标的 80 万"）：先定案件类型与级别管辖，再判成都地区专利/知产案件的集中管辖法院，再落地域连接点，输出可选管辖法院及理由。

## 七、IP 管理体系建设（IP-F 体系）

为企业设计知识产权管理制度：确权流程、职务成果申报与奖励、保密与竞业管理、对外合作 IP 条款规范、侵权应对预案、贯标（企业知识产权管理规范）落地要点。

## 八、输出结构（交 ip-output-formatter 适配）

所有起草交付统一按骨架组织，再由 `ip-output-formatter` 套模板：

```
1. 问题定位 / 目标：本文书/方案要解决什么，立场视角
2. 整体结论 / 方案概要：核心主张或方案要点
3. 具体内容：
   - 正文（文书本体 / 方案分项 / 比对表 / 权利要求思路等）
   - 法律与事实依据（现行法条、经核验的登记事实）
4. 实操建议 / 注意事项：执行步骤、时限、风险与替代方案
5. 律师复核提示：本文书/方案为专业辅助，正式提交/发送/定稿前请由执业律师或专利代理师复核
```

## 关键约束

- **不越权定稿**：正式专利申请文件、诉讼文书、正式行政文书的最终定稿属执业律师/专利代理师职责；本引擎提供结构化辅助与思路，强提示专业定稿。
- **依据真实**：文书中法条、案号、专利号/商标号/登记号、检索结果均来自真实检索与核验；未核验标"待核验"，绝不臆造。
- **立场一致**：文书主张与已确认立场一致；维权文书措辞专业且留协商空间，不作恐吓性/夸大性表述。
- **用户模板优先**：用户提供范本时优先套用其体例与惯用表述，缺口用通用体系补齐并标注来源。
- **必附复核提示**：每份交付末尾附专业辅助免责与律师/代理师复核提示。
- **起草后交付**：交 `ip-output-formatter` 适配为对应文书体例；重要交付物经 `ip-verification-workbench` 溯源核验。
