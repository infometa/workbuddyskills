# 知产专家（IP Expert）

面向中国法律场景的全链条知识产权专家，覆盖**著作权、专利、商标、商业秘密、域名**及综合战略，从"确权—用权—维权"帮你把知产工作做全做准。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **场景识别与路由**：用大白话说需求即可，自动判断落在著作权/专利/商标/商业秘密/域名/综合战略的哪类工作（44 个三级场景决策表）。
- **交互采集**：知产结论高度依赖立场（权利人 vs 被控方）与关键事实，先问清再动手。
- **专业库检索与调查**：整合 24 个权威/专业 IP 数据库（专利文献、商标注册簿、著作权登记、域名 WHOIS 等）。能自动化的直接取回可核验正文；需登录/验证码的**生成手动查询指引让你自查回填，绝不臆造**；法律法规走北大法宝，主体资格走企查查。
- **分析研判**：确权与权属、相似度/近似性比对、侵权/FTO 技术特征比对、可注册性与效力研判、构成要件涵摄。
- **起草与策略**：申请文件思路、审查意见答复、布局组合、维权文书、战略治理、诉讼管辖备忘、IP 管理体系建设。
- **场景化输出 + 溯源核验**：按 6 类真实工作成果体例输出；重量级交付经核验工作台溯源（已关联/弱关联/待核验三标签，不判对错）。
- **反幻觉铁律**：专利号/商标号/软著登记号/域名等权利登记信息强制溯源官方登记来源；每份交付附律师（及专利代理师）复核提示。

## 使用示例

- 我公司自主研发了一款 App，想全面梳理涉及的知识产权保护（软件著作权、商标、专利怎么布局），请帮我规划一套整体保护方案。
- 我们有一款新产品即将上市，想在投产前做一次专利侵权风险排查（FTO 分析）。
- 有同行在卖跟我们商标很像的产品，请帮我判断是否构成商标侵权，以及应采取什么维权策略。

## 依赖

- 推荐连接器：北大法宝 `pkulaw`（法律法规/司法解释/案例）、企查查 `qcc-company`（企业主体资格与信用）。
- 可选：浏览器自动化用于公开专业库网页检索；需登录的库改走手动查询指引。

## 安装

将专家包目录放到：

```
~/.workbuddy/plugins/marketplaces/my-experts/plugins/ip-expert/
```

然后注册使其在 WorkBuddy 中可见。
