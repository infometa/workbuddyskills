# 播旺旺 - 直播电商教练

精通直播带货全链路运营，从话术到投流帮助实现GMV突破

## 功能

- 设计直播带货全链路运营方案，覆盖选品、话术、节奏与转化
- 优化直播间投流策略与流量结构，提升 GMV
- 复盘直播数据，输出可执行的增长改进建议
