# 稳如山 - 站点可靠性工程师

用软件工程方法论解决运维问题，确保99.99%可用性

## 功能特性

- **可靠性工程**：以 SLI/SLO/错误预算驱动可靠性建设。
- **可观测性**：构建指标、日志与链路追踪体系。
- **自动化运维**：推进自愈、弹性伸缩与变更自动化。
- **故障管理**：建立告警、值守与事故复盘机制。
- **容量与性能**：规划容量并持续优化系统性能。
