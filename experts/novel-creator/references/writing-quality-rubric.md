# 写作质量评分标准

> 综合参考：Save the Cat! 检查表、John Truby 22 步骤、Robert McKee 故事原理。融入 [novel-writer-skills](https://github.com/wordflowlab/novel-writer-skills) 的 `/analyze` 双模式（框架/内容）+ 智能检查系统、[ClawHub novel-writing](https://clawhub.ai/zton100/novel-writing) 的 7 大痛点检查。

---

## 一、评分维度与权重

| 维度 | 权重 | 说明 |
|------|------|------|
| 情节结构 | 25% | 故事骨架是否完整、有力 |
| 角色塑造 | 25% | 角色是否立体、一致、有辨识度 |
| 文风一致性 | 20% | 全篇风格是否统一 |
| 节奏把控 | 15% | 松紧是否合理、是否抓住读者 |
| 连续性 | 15% | 是否有前后矛盾 |

---

## 二、维度1：情节结构（25%）

| 分数 | 标准 |
|------|------|
| 9-10 | 冲突链完整紧密，每个事件都是前一个的因果后果，伏笔全部回收，结局既意外又合理 |
| 7-8 | 主线清晰有力，有 1-2 处精彩的转折和伏笔，整体逻辑自洽 |
| 5-6 | 有完整的起承转合，但部分衔接靠巧合而非因果，伏笔回收不完全 |
| 3-4 | 情节碎片化，事件之间缺乏因果联系，多处逻辑漏洞 |
| 1-2 | 无清晰主线，事件堆砌，前后矛盾严重 |

### 扣分项

- 出现"天降解决"（突然冒出来的救兵/能力解决了问题）→ -2 分
- 核心冲突被轻易解决（没有付出代价）→ -1 分
- 主线外的支线占比超过 40% 且不与主线交汇 → -1 分
- 关键转折点没有铺垫 → -1 分
- 伏笔遗漏（埋了不收）→ 每个 -0.5 分

### 情节自检 Checklist

- [ ] 每个章节是否推进主线？（无推进 = 注水）
- [ ] 主角的每个决定是否有"代价"？（没代价 = 没张力）
- [ ] 第一幕末尾是否有"不可逆"的事件？
- [ ] 中点是否有重大转折？
- [ ] 第二幕末尾是否有"一切失去"时刻？
- [ ] 高潮是否同时解决"外在冲突"和"内在冲突"？
- [ ] 伏笔回收清单：每个伏笔的回收章节是否已确定？

---

## 三、维度2：角色塑造（25%）

| 分数 | 标准 |
|------|------|
| 9-10 | 角色像真人——行为可被动机解释，有矛盾性，对话有辨识度，有成长弧线 |
| 7-8 | 主角立体有魅力，配角各有特色，行为基本合理 |
| 5-6 | 角色有基本人设，但偶尔"为了剧情需要"做不合理的事 |
| 3-4 | 角色扁平/脸谱化，行为靠作者操控而非角色自身逻辑驱动 |
| 1-2 | 无法区分不同角色，行为随机，"工具人"感严重 |

### 扣分项

- 主角性格前后不一致（无合理铺垫的突变）→ -2 分
- 对话遮住名字无法辨认是谁说的 → -1 分
- 反派/对手动机纯粹是"因为他是坏人" → -1 分
- 重要配角无独立目标（只为主角服务）→ -1 分
- 角色弧线缺失（结局和开局没变化）→ -1 分

### 角色自检 Checklist

- [ ] 主角有明确的 Want（表层目标）和 Need（深层需求）吗？
- [ ] 主角有 Fatal Flaw（致命缺陷）吗？
- [ ] 主角有 Lie（错误信念）吗？
- [ ] 角色弧线是否清晰：起点 → 中点觉醒 → 终点变化？
- [ ] 反派从他的视角看，行为合理吗？
- [ ] 重要配角是否有自己的小弧线？
- [ ] 对话辨识度测试：遮住名字能否分辨说话人？

## 四、维度3：文风一致性（20%）

| 分数 | 标准 |
|------|------|
| 9-10 | 全篇有统一的"声音"，像同一个作者写的，风格鲜明且稳定 |
| 7-8 | 整体风格统一，偶有 1-2 处风格偏移但不影响阅读 |
| 5-6 | 风格基本一致，但部分段落明显像"另一个人写的" |
| 3-4 | 风格混乱——时而口语化时而文绉绉，时而幽默时而严肃 |
| 1-2 | 完全没有统一风格，像多人拼凑 |

### 检查维度

- 用词层次是否一致（不能一会儿大白话一会儿文言）
- 比喻/修辞风格是否一致
- 幽默感的密度和风格是否一致
- 叙述距离是否一致（不突然从近距离变成上帝视角）
- 句式偏好是否一致（长句/短句比例）

### 文风一致性自检

- [ ] 第一章和最后一章对比，文风是否一致？
- [ ] 同一角色不同章节的对话风格一致吗？
- [ ] 叙述视角（第一/第三/全知）全程统一吗？
- [ ] 时态全程统一吗？（过去时 / 现在时）
- [ ] 章节标题/分节符等结构形式一致吗？

### 文风指南模板

每本书必备 `style-guide.md`，定义：

```markdown
## 文风指南

### 核心定位
- 整体调性：[简洁/华丽/悬疑/热血/温暖/冷峻]
- 节奏类型：[紧凑/舒缓/张弛有度]
- 情感浓度：[克制/外放/中等]

### 句式偏好
- 长短句比例：长句:短句 = [N:M]
- 复杂句使用：[多用/少用/几乎不用]
- 短句出现时机：[紧张时刻/对话/情绪爆发]

### 用词层次
- 主要层次：[书面/口语/文言/俚语/方言]
- 禁忌词表：
  - [词1]
  - [词2]

### 比喻偏好
- 比喻类型：[自然/科学/日常/古典/网络]
- 比喻密度：[每 N 段一次]

### 标点习惯
- 省略号使用：[多/少]
- 破折号使用：[多/少]
- 感叹号使用：[少用，仅强调]
```

## 五、维度4：节奏把控（15%）

| 分数 | 标准 |
|------|------|
| 9-10 | 松紧得当，每次"松"都是为下一次"紧"蓄力，读者想一口气读完 |
| 7-8 | 整体节奏好，高潮段落有力，过渡自然 |
| 5-6 | 基本流畅，但有 1-2 处明显拖沓或突然加速 |
| 3-4 | 节奏失控——长段落的无事发生，或高潮堆得太密没有喘息 |
| 1-2 | 全篇平淡如水，或全程紧绷让人疲惫 |

### 节奏自检

- 是否连续超过 3000 字没有任何冲突/变化/新信息？→ 拖沓预警
- 是否连续超过 3 个高潮场景没有任何喘息？→ 疲劳预警
- 章末是否有"钩子"让人想翻下一章？

### 节奏调节工具

| 想加快节奏 | 想放慢节奏 |
|-----------|-----------|
| 短句、短段落 | 长句、长段落 |
| 减少描写 | 增加描写 |
| 多对话 | 多内心独白 |
| 多动词 | 多形容词 |
| 多场景切换 | 单一场景细节展开 |
| 删减过渡 | 增加过渡 |
| 直接进入冲突 | 铺垫氛围 |

### 网文节奏黄金公式

```
每3000字一个小爽点
每10000字一个中爽点
每30000-50000字一个大爽点
每章末尾一个钩子（必须）
```

## 六、维度5：连续性（15%）

| 分数 | 标准 |
|------|------|
| 9-10 | 零矛盾，所有设定前后一致，时间线精确，伏笔全部合理回收 |
| 7-8 | 无明显矛盾，偶有微小的时间/细节模糊但不影响阅读 |
| 5-6 | 有 1-2 处可被读者注意到的小矛盾（如角色年龄/地点前后不一） |
| 3-4 | 明显的"吃书"——之前确立的设定被遗忘或违反 |
| 1-2 | 严重前后矛盾，多处设定冲突，已死角色突然出现等 |

### 连续性检查清单

- [ ] 角色年龄/生日在全文中一致
- [ ] 角色外貌描述前后一致
- [ ] 世界观规则没有自我矛盾
- [ ] 时间线逻辑通顺（A 事件到 B 事件过了多久？）
- [ ] 伏笔有回收或有意保留（不是遗忘）
- [ ] 角色知道的信息与其经历匹配（不全知）
- [ ] 地理位置一致（A 城在 B 城东边就一直在东边）
- [ ] 角色能力等级递增（修真/玄幻题材）
- [ ] 物品/道具不"凭空消失/出现"

### 追踪系统（来自 novel-writer-skills）

```
spec/tracking/
├── plot-tracker.json        # 情节追踪
├── timeline.json            # 时间线
├── character-state.json     # 角色状态
└── relationships.json       # 关系网络
```

每写完一章自动更新，避免：
- 昨天死了的角色今天又出场
- A 城在第 3 章是首都，第 30 章变成边陲小镇
- 主角第 5 章学会的技能，第 50 章又"第一次见到"

## 七、综合评分公式

```
总分 = 情节(×0.25) + 角色(×0.25) + 文风(×0.20) + 节奏(×0.15) + 连续性(×0.15)
```

| 总分 | 等级 | 判定 |
|------|------|------|
| 9.0+ | S | 出版/上架水准 |
| 7.5-8.9 | A | 优秀，可打磨后发表 |
| 6.0-7.4 | B | 合格，需要针对性修改 |
| 4.0-5.9 | C | 骨架有但问题多，需要大改 |
| <4.0 | D | 需要重新构思 |

## 八、双模式分析（来自 novel-writer-skills）

### 框架模式（Frame Analysis）

适用：**草稿阶段、大纲阶段**

检查项：
- [ ] 三幕结构是否完整？
- [ ] Save the Cat 15 节拍是否齐全？
- [ ] 主角弧线是否清晰？
- [ ] 主线/B 故事是否平衡？
- [ ] 关键转折点是否到位？

输出：**结构性建议**（不评价文笔）

### 内容模式（Content Analysis）

适用：**正稿阶段、修订阶段**

检查项：
- [ ] 五维评分（情节/角色/文风/节奏/连续性）
- [ ] AI 痕迹检测
- [ ] 对话辨识度
- [ ] 比喻独特性
- [ ] 章节钩子质量

输出：**逐章打分 + 具体改进建议**

## 九、7 大痛点检查（来自 ClawHub novel-writing）

每写到关键节点（每 5 章/每卷末/每 5 万字）必须检查：

### 1. 上下文丢失检查
- [ ] 5 章前的伏笔记得吗？
- [ ] 10 章前的角色现在在哪？
- [ ] 上一卷的核心冲突解决了吗？还在持续？

### 2. 文风一致性检查
- [ ] 把第 1 章和最新章对比，文风一样吗？
- [ ] 主角的语气还是那个语气吗？
- [ ] 描写密度有没有变化（一开始详细后面糙）？

### 3. 设定冲突检查
- [ ] 新设定与既有世界规则一致吗？
- [ ] 新角色能力没破坏世界平衡吧？
- [ ] 新出场的地理位置与之前一致吗？

### 4. 节奏检查
- [ ] 最近 5 章爽点节奏正常吗？
- [ ] 有没有连续 3 章无大事件？
- [ ] 章末钩子还在持续吗？

### 5. 多线检查
- [ ] 每条线最近一次推进是哪章？
- [ ] 是否有线索"断了"超过 10 章？
- [ ] 不同线最终汇合的时间点定了吗？

### 6. 质量稳定检查
- [ ] 最近 5 章评分平均值是多少？
- [ ] 有无某一章明显"水"？
- [ ] 字数/章是否正常（突然变短/变长？）

### 7. 反馈内化检查
- [ ] 读者反馈最多的问题处理了吗？
- [ ] 反馈中提到的角色/线，最近章节有照顾吗？
- [ ] 有没有反馈被简单忽略？

## 十、章节级评分模板

每章末填写：

```markdown
## 第 N 章 自评

**字数**：[X] 字
**主要事件**：[一句话]
**推进的线**：[主线/B 故事/支线 X]
**埋的伏笔**：[列表]
**回收的伏笔**：[列表]
**章末钩子**：[类型 + 内容]

### 五维评分

| 维度 | 得分 | 备注 |

| 节奏 | /10 | |
```
