## 一、Save the Cat! 节拍表（Beat Sheet）

最实用的商业小说/网文结构框架，15 个节拍点：

| 节拍 | 占比 | 功能 | 示例（50万字长篇） |
|------|------|------|-----------------|
| 开场画面 | 1% | 展示"改变前"的世界 | 第1章：主角平凡日常 |
| 主题陈述 | 5% | 暗示作品主题 | 某人说了一句话暗示核心主题 |
| 铺垫 | 1-10% | 建立世界/角色/关系 | 1-5万字：日常+人设+关系+世界观 |
| 催化剂 | 10% | 打破平衡的事件 | 5万字：激励事件发生 |
| 犹豫期 | 10-20% | 主角抗拒改变 | 5-10万字：纠结要不要踏入新世界 |
| 进入第二幕 | 20% | 主角做出决定 | 10万字：正式踏入新世界 |
| B故事 | 22% | 副线开启（常是感情线） | 11万字：出现感情线/师徒线 |
| 游戏时间 | 20-50% | "这本书的承诺"兑现 | 10-25万字：爽点密集输出 |
| 中点 | 50% | 假胜利或假失败 | 25万字：重大转折 |
| 坏人逼近 | 50-75% | 压力升级，内部瓦解 | 25-37万字：外部压力+内部矛盾 |
| 一切失去 | 75% | 最大危机 | 37万字：主角失去一切 |
| 暗夜灵魂 | 75-80% | 最低谷，顿悟前夜 | 37-40万字：黑暗时刻 |
| 进入第三幕 | 80% | 找到新力量/新方法 | 40万字：转折重生 |
| 终极对决 | 80-99% | 最终战斗/对抗 | 40-49万字：高潮 |
| 终场画面 | 99-100% | 展示"改变后"的世界 | 50万字：新的平衡 |

### 使用规则
- 中点必须是全书的"假高潮"或"反转" — 它把第二幕一分为二
- "游戏时间"是读者买这本书的核心原因 — 类型承诺在这里兑现
- "一切失去"必须让读者觉得"完了，主角真的没救了"
- 终场画面必须与开场画面形成对照（展示变化）

### Save the Cat! 10 大类型（Genres）
不是按题材分类，而是按"故事DNA"分类：

| 类型 | 核心 | 代表作 |
|------|------|--------|
| Monster in the House | 封闭空间+怪物+原罪 | 《异形》《大白鲨》 |
| Golden Fleece | 寻宝/旅程+蜕变 | 《指环王》《哈利波特》 |
| Out of the Bottle | 愿望+反噬+学到真相 | 《大话西游》《黑客帝国》 |
| Dude with a Problem | 普通人+突发危机 | 《虎胆龙威》《疾速追杀》 |
| Rites of Passage | 人生过渡期+痛苦+成长 | 《死亡诗社》《伯德小姐》 |
| Buddy Love | 二人组+对立→互补 | 《肖申克的救赎》《绿皮书》 |
| Whydunit | 不是"谁干的"而是"为何" | 《利刃出鞘》《消失的爱人》 |
| The Fool Triumphant | 弱者vs体制，靠"傻"赢 | 《阿甘正传》《楚门的世界》 |
| Institutionalized | 个人vs组织/家族 | 《教父》《飞越疯人院》 |
| Superhero | 异能者+使命+牺牲 | 《钢铁侠》《海王》 |

## 二、三幕式结构

最经典的叙事结构，适用于所有故事形态：

```
第一幕（25%）：建立
├── 日常世界（读者认识主角）
├── 激励事件（打破平衡）
└── 第一转折点（主角被迫行动）

第二幕（50%）：对抗
├── 上升行动（试探+小胜）
├── 中点（假胜利/假失败）
├── 下降行动（代价升级）
└── 第二转折点/最低谷（一切失去）

第三幕（25%）：解决
├── 高潮（终极对决）
├── 结局（冲突解决）
└── 新常态（改变后的世界）
```

### 三幕式的核心是"不可逆"
- 第一转折点后，主角无法回到旧生活
- 中点后，赌注升级到不可退缩
- 第二转折点后，只有终极对决一条路

### 三幕式 vs Save the Cat! 映射

| Save the Cat | 三幕式 |
|-------------|--------|
| 开场画面 → 进入第二幕 | 第一幕 |
| B故事 → 暗夜灵魂 | 第二幕 |
| 进入第三幕 → 终场画面 | 第三幕 |

## 三、英雄之旅（Hero's Journey）

Joseph Campbell 的单一神话原型，12 个阶段：

1. **普通世界** — 主角的日常
2. **冒险召唤** — 问题/挑战出现
3. **拒绝召唤** — 主角害怕/犹豫
4. **遇见导师** — 获得帮助/指引
5. **跨越第一道门槛** — 进入新世界
6. **试炼、盟友、敌人** — 新世界的考验
7. **接近最深洞穴** — 靠近核心危险
8. **磨难** — 生死考验
9. **报酬** — 获得"宝藏"
10. **归途** — 带着收获回归
11. **复活** — 最终考验/净化
12. **带着万灵药回归** — 改变了的英雄回到普通世界

### 适用场景
- 奇幻/冒险/成长类题材首选
- 网文"升级流"本质上是英雄之旅的变体
- 可与三幕式叠加使用

### 内/外双线
真正的英雄之旅有**内在旅程**和**外在旅程**两条线：

| 阶段 | 外在 | 内在 |
|------|------|------|
| 普通世界 | 现实环境 | 主角的"伪自我" |
| 冒险召唤 | 外部事件 | 内心的不安 |
| 磨难 | 生死考验 | 旧自我的死亡 |
| 复活 | 战胜对手 | 新自我的诞生 |
| 万灵药 | 物质收获 | 精神觉醒 |

## 四、Dan Harmon 故事圆环（Story Circle）

英雄之旅的简化版，8 步循环，最适合短篇/单元剧/章节级结构：

```
        1. YOU（一个人）
        ↓
8. CHANGE（改变了）  →  2. NEED（需要某物）
        ↑                  ↓
7. RETURN（回归）    3. GO（进入新世界）
        ↑                  ↓
6. PAY（付出代价）  ←  4. SEARCH（寻找）
        ↓
        5. FIND（找到）
```

### 8 步详解

| 步骤 | 含义 | 关键问题 |
|------|------|---------|
| 1. YOU | 主角处于舒适区 | 他是谁？日常什么样？ |
| 2. NEED | 出现欲望/缺失 | 他想要什么？为什么？ |
| 3. GO | 跨入未知 | 进入了什么新环境？ |
| 4. SEARCH | 适应新环境 | 遇到什么困难？ |
| 5. FIND | 得到想要的 | 但代价是什么？ |
| 6. PAY | 付出代价 | 失去了什么？ |
| 7. RETURN | 回到熟悉环境 | 带着什么回来？ |
| 8. CHANGE | 不再是原来的他 | 内在变化是什么？ |

### 应用建议
- **每章用一次**：每个章节就是一个小型 Story Circle
- **每卷用一次**：分卷结构按 Story Circle 设计
- **整书用一次**：与三幕式叠加使用

## 五、雪花法（Snowflake Method）— Randy Ingermanson

适合长篇前期规划，从"一句话"逐层展开到全书。

### 10 步雪花

| 步骤 | 产出 | 字数 | 时间 |
|------|------|------|------|
| 1. 一句话总结 | 全书核心 | <15字 | 1小时 |
| 2. 一段话总结 | 三幕骨架 | 5句 | 1小时 |
| 3. 角色摘要 | 每个主要角色1页 | 1页/人 | 1天 |
| 4. 段落扩展 | 每句话扩展为一段 | 1页 | 数小时 |
| 5. 角色卡 | 每个角色完整背景 | 多页 | 1周 |
| 6. 大纲扩展 | 每段扩展为1页 | 4页 | 1周 |
| 7. 角色档案 | 角色全维度档案 | 长 | 1周 |
| 8. 场景列表 | 每个场景1行 | 100+行 | 1周 |
| 9. 场景描述 | 每个场景1段 | 多页 | 2周 |
| 10. 开始写作 | 正式动笔 | — | — |

### 雪花法的核心理念
- **从一句话开始** — 如果一句话讲不清，整本书也讲不清
- **逐层展开** — 像雪花从中心向外生长
- **修改是核心** — 每一步都允许回头修改前一步

## 六、网文特有结构：爽点节奏公式

网文与传统文学的核心区别在于**爽点密度和频率**：

### 黄金节奏
```
每3000字一个小爽点（解决一个小问题/展示一次能力）
每10000字一个中爽点（赢得一场冲突/获得重要收获）
每30000-50000字一个大爽点（大转折/大突破/打脸高潮）
```

### 钩子设计（防弃书）

| 位置 | 钩子类型 | 作用 |
|------|---------|------|
| 第一章结尾 | 悬念钩 | 决定读者是否看第二章（=短视频前3秒） |
| 每章结尾 | 小钩子 | 牵引读者翻下一章 |
| 每卷结尾 | 大悬念 | 防止读者在卷间流失 |
| 免费章节末尾 | 核心悬念 | 决定是否付费（最关键的钩子） |

### 网文"开局公式"

前 3 章（≈1万字）必须完成：
1. **主角人设立住**（读者知道我在跟着谁）
2. **金手指出现**（读者知道这本书的"承诺"是什么）
3. **第一个爽点**（证明这本书值得看下去）
4. **第一个悬念**（让读者想知道"然后呢"）

### 网文常见 5 种爽点结构

| 类型 | 结构 | 示例 |
|------|------|------|
| 打脸流 | 装B → 被嘲笑 → 反转打脸 | 战神归来、扮猪吃虎 |
| 升级流 | 觉醒 → 历练 → 突破 → 更强 | 仙侠、修真、玄幻 |
| 系统流 | 触发任务 → 完成 → 奖励 → 变强 | 系统签到、无敌系统 |
| 重生流 | 重活一次 → 利用先知 → 复仇/逆袭 | 都市重生、宫斗重生 |
| 反派流 | 视角反转 → 主角是反派 → 走自己的路 | 我，反派他爸 |

### 章节末钩子的 7 种类型

| 类型 | 例子 |
|------|------|
| 危机钩 | "他刚转身，背后传来一声低吼。" |
| 悬疑钩 | "她终于说出了那个名字——" |
| 反转钩 | "他没想到，对方居然是…" |
| 信息钩 | "原来这一切，从一开始就是个陷阱。" |
| 情感钩 | "那一刻，他知道自己再也回不去了。" |
| 时间钩 | "三天后，他将面对最强的对手。" |
| 选择钩 | "现在，他必须做出抉择。" |

## 七、冰山理论（海明威）

**原则**：作者知道的要比写出来的多 10 倍。

### 实操指南
- 世界观设定写 10 页，正文只展示 1 页 — 但读者能感到"这个世界是完整的"
- 角色背景写 5000 字，正文只暗示几处 — 但角色行为逻辑自洽
- 不要"解释给读者听"，要"让读者自己发现"
- 留白 > 说明 — 读者脑补出来的永远比你直接说更有冲击力

### 冰山理论的误区
- ❌ 不是"写得越少越好" — 是"底下的东西要存在但不全展示"
- ❌ 不是"什么都不解释" — 关键信息要让读者获取到
- ❌ 不是"故意模糊" — 是"精确的省略"

### 冰山法则的 8/2 拆分

| 比例 | 内容 | 是否写出 |
|------|------|---------|
| 80% | 世界观/历史/人物背景 | 作者知道，读者不知道 |
| 20% | 关键信息/当下情节 | 作者写出，读者看到 |
| 100% | 行为逻辑 | 必须自洽（80%支撑20%） |

## 八、场景节拍（Scene Beats）设计

每个场景都是一个微型故事：

```
目标（Goal）→ 冲突（Conflict）→ 灾难/转折（Disaster/Turn）
     ↓
反应（Reaction）→ 困境（Dilemma）→ 决定（Decision）
     ↓
新目标 → 新冲突 → ...循环推进
```

### 场景类型

| 类型 | 功能 | 节奏 |
|------|------|------|
| 行动场景 | 推进情节、展示冲突 | 快节奏、短句、紧张 |
| 反应场景 | 消化情绪、做出决定 | 慢节奏、内心、过渡 |
| 信息场景 | 揭示关键信息 | 中等、对话为主 |
| 转折场景 | 改变局面/认知 | 先慢后快、爆发式 |

### 节奏黄金比例
- 行动场景 : 反应场景 ≈ 2:1
- 连续不超过 3 个行动场景不给"喘息"
- 反应场景不超过 1 个不接行动（否则拖沓）

### MRU 单元（Motivation-Reaction Unit）

每个段落都遵循"刺激→反应"模式：

```
[Motivation 外部刺激] 客观、可见
     ↓
[Reaction 角色反应] 按以下顺序：
  1. 感觉（心跳加快、出汗）— 0.1秒级
  2. 反射动作（后退、皱眉）— 0.5秒级
  3. 理性思考（"这是陷阱"）— 1秒级
  4. 言语和行动（"我不去"+转身）— 数秒级
```

**新手最常错的**：跳过感觉/反射，直接理性思考 → 显得不像真人。

## 九、七步方法论（来自 novel-writer-skills 223⭐）

工程化的小说创作流程，把"灵感写作"变成"项目管理"：

```
1. /constitution    创建创作宪法（核心原则、风格定位、不可违反的边界）
2. /specify         定义故事规格（一句话→大纲→冲突核心→关键场景）
3. /clarify         澄清模糊点（5个关键问题，必答）
4. /plan            制定创作计划（章节切分、时间节点、字数目标）
5. /tasks           分解任务清单（每章的写作单元）
6. /write           执行章节写作（结合追踪系统的智能辅助）
7. /analyze         质量验证分析（双模式：框架检查 / 内容打分）
```

### 关键产出物

| 阶段 | 产出 | 作用 |
|------|------|------|
| constitution | `.specify/memory/constitution.md` | 全书的"宪法"，所有创作不得违反 |
| specify | `stories/[name]/specification.md` | 故事 DNA |
| plan | `stories/[name]/creative-plan.md` | 写作计划 |
| tasks | `stories/[name]/tasks.md` | 任务拆分 |
| write | `stories/[name]/content/chapter-XX.md` | 章节正文 |

### 追踪系统（防止"吃书"）

```
spec/tracking/
├── plot-tracker.json        # 情节追踪（伏笔、冲突、转折点）
├── timeline.json            # 时间线（按时间维度的事件序列）
├── character-state.json     # 角色状态（位置、心情、关系、能力）
└── relationships.json       # 关系网络（角色之间的连接）
```

每写完一章自动更新，避免"昨天死了的角色今天又出场"等低级错误。

## 十、ClawHub novel-writing 的"7 大痛点 + 结构化外脑"

### 7 大痛点（必须解决）

1. **上下文丢失** — 50万字后期忘了10万字时埋的伏笔
2. **文风不一致** — 不同时间写的章节风格漂移
3. **设定冲突** — 新内容与既有世界观矛盾
4. **节奏失控** — 情节推进缺乏把控
5. **多线混乱** — 多条剧情线交织难管理
6. **质量不稳** — 批量创作时章节水平波动
7. **读者反馈无法内化** — 反馈难系统融入后续创作

### 结构化文件系统（外置作者大脑）

```
novel/
├── settings/              # 世界观设定档案
│   ├── world.md           # 世界观总览
│   ├── characters/        # 角色声线卡
│   ├── geography/         # 地理/势力
│   └── rules.md           # 世界规则
├── chapters/              # 章节档案
│   ├── outline.md         # 大纲
│   └── arc-N/             # 分卷
├── tracker/               # 追踪器
│   ├── foreshadowing.md   # 伏笔追踪
│   ├── conflicts.md       # 冲突记录
│   └── feedback.md        # 读者反馈
└── state.json             # 当前写作状态
```

**设计哲学**：通过结构化文件系统**外置作者大脑**，把易丢失的上下文、设定、伏笔全部沉淀为可检索文档。

### 伏笔追踪规则（强制格式）

每埋一个伏笔必须登记：
```
- [章X] 事件A → 预期回收章Y
```

**预警机制**：连续 3 章未回收 → 触发提醒。

## 十一、不同篇幅的结构选择

| 篇幅 | 推荐结构 | 原因 |
|------|---------|------|
| 短篇（<1万字） | Story Circle / 单一场景节拍 | 8 步即可承载 |
| 中篇（1-10万字） | 三幕式 | 经典框架最稳 |
| 长篇（10-50万字） | Save the Cat! 15 节拍 | 节拍密度合适 |
| 超长篇（>50万字） | 多 Save the Cat! 嵌套 + Story Circle 章节 | 分卷、分弧线管理 |
| 网文连载（无限） | 爽点节奏 + 章节钩子 + 卷弧线 | 用"延迟满足"维持阅读 |
