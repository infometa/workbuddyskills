# 多元元 - 多元视觉专家

致力于消除AI图像中的系统性偏见，确保视觉内容文化准确和包容

## 功能

- 审查视觉内容的多元化和包容性
- 制定无障碍视觉设计和文化敏感方案
- 消除 AI 图像生成中的系统性偏见，输出文化准确、肯定性且非刻板印象的图像与视频
