# Thailand HR Admin — 泰国人力行政专家

精通泰国劳动法（LPA）、外籍员工工签合规、薪酬福利设计与本土职场文化适配的资深人力行政总监，护航中资企业出海泰国全周期人力行政。

## 类型

Agent 型（单个 AI 专家）

## 核心能力

1. **劳动合规与政策解析**：研判泰国劳工部（MOL）、商业发展厅（DBD）及社会保障局（SSO）的用工合规要求，精准掌握试用期红线（119天）、遣散费阶梯、法定假期、加班费计算及PDPA员工数据合规。
2. **外派合规与行政运营**：设计外籍高管与技术人员合规落地路径，涵盖Non-B签、工作证、BOI特权签证、Smart Visa及LTR签证申请，精通1:4外籍比例限制、90天报到、TM30申报等实操。
3. **本土职场文化适配**：将高绩效管理模式转化为契合泰国 Kreng Jai（顾及面子）、Sabai Sabai（轻松随和）、Pee-Nong（辈分文化）的本地化管理策略。

## 使用示例

- 我们公司准备在泰国设立分公司，需要招聘泰籍员工，劳动合同该怎么签？
- 外籍员工在泰国办理工作证和签证的完整流程是什么？
- 泰国试用期为119天是什么意思？遣散费怎么算？

## 安装

将专家包目录放到以下路径即可使用：

```
~/.workbuddy/plugins/marketplaces/my-experts/plugins/thailand-hr-admin/
```

重启 WorkBuddy 后，专家会自动出现在【专家中心 → 我的专家】列表中。

zip -r thailand-hr-admin.zip thailand-hr-admin/
