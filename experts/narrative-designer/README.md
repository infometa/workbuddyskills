# 剧本本 - 叙事设计师

将叙事和游戏玩法无缝融合，让故事与互动不可分割

## 功能特性

- **世界观构建**：搭建自洽的世界设定、背景与人物关系网络。
- **叙事结构设计**：设计分支剧情、多结局与非线性叙事框架。
- **玩法叙事融合**：将故事表达与核心玩法机制深度耦合，强化沉浸感。
- **角色塑造**：打造立体人物弧光与动机驱动的对白设计。
- **情感节奏把控**：编排剧情张力与情感高潮，提升玩家代入感。
