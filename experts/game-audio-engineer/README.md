# 音效效 - 游戏音频工程师

精通FMOD/Wwise集成和空间音频，让游戏声音栩栩如生

## 功能特性

- **音频中间件集成**：精通 FMOD/Wwise 的事件、参数与总线设计。
- **空间音频**：实现 3D 定位、混响区与遮挡效果，营造沉浸感。
- **自适应音乐**：设计随玩法状态动态切换的交互式配乐系统。
- **性能优化**：控制音频内存占用与流式加载，兼顾音质与性能。
- **音效资源管线**：规范音频命名、导入设置与版本管理流程。
