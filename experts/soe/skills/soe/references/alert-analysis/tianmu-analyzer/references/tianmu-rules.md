# 天幕安全治理规则参考

## 规则编号体系

天幕规则编号格式: `GB` + 6位数字

| 前缀 | 类型 | 误报风险 | 典型场景 |
|---|---|---|---|
| GB0xxxx | 黑名单类 | 低 | 已知恶意IP/域名阻断 |
| GB1xxxx | 特征匹配类 | 中 | SQL注入/XSS/命令注入特征 |
| GB2xxxx | 行为类 | 中 | 频率异常/扫描行为/CC攻击 |

## 常见规则

### 黑名单类 (GB0xxxx)

| 规则ID | 说明 | 典型来源 |
|---|---|---|
| GB00001 | 黑名单IP阻断 | 黑名单 |
| GB00002 | 黑名单IP阻断 | 黑名单 |
| GB00005 | 黑名单IP阻断 | 黑名单 |

> 黑名单类阻断通常合理, 阻断的IP已在威胁情报中标记为恶意.

### 特征匹配类 (GB1xxxx)

> 基于请求特征匹配 (SQL注入/XSS/路径遍历等), 需确认是否误报.
> 误报常见原因: 正常请求中包含敏感关键词 (如搜索框输入 `select`).

### 行为类 (GB2xxxx)

| 规则ID | 说明 | 典型场景 |
|---|---|---|
| GB200161 | 频率异常 | 短时间大量请求 (CC/爬虫) |
| GB200163 | 频率异常 | 短时间大量请求 (CC/爬虫) |

> 行为类规则需结合业务场景判断. 例如:
> - 正常监控/健康检查可能触发频率规则 → 误报
> - 真实CC攻击 → 正确阻断

## 误报识别策略

1. **黑名单类 (GB0xxx)**: 阻断合理, 无需确认
2. **特征类 (GB1xxx)**: 检查 HTTP 请求内容 (HOST/CGI), 确认是否为正常业务
3. **行为类 (GB2xxx)**: 检查源IP是否为已知监控/爬虫, 确认是否为正常业务

## 处置建议

| 场景 | 处置 |
|---|---|
| 高频黑名单命中 | 永久加黑源IP |
| 多规则命中 (多向量攻击) | 重点排查, 拉取跨产品告警 |
| 单规则高频命中 | 确认规则效果, 考虑升级处置 (从阻断到封禁) |
| 误报 (正常业务触发) | 加白源IP / 调整规则阈值 |
