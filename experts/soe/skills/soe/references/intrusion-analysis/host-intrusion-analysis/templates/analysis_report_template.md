### 📊 攻击时间线

>>> **Mermaid `graph LR`，≤8 节点**。同类事件合并为一个节点并注明次数。
>>> **classDef（必须原样复制）**：
>>> `classDef normal fill:#4CAF50,stroke:#388E3C,color:#fff` / `classDef suspicious fill:#FF9800,stroke:#F57C00,color:#fff` / `classDef critical fill:#F44336,stroke:#D32F2F,color:#fff`
>>> 颜色：normal=绿(正常) / suspicious=橙(可疑) / critical=红(高危)
>>> **语法要点（渲染兼容性）**：
>>> 1. **箭头必须用 `---` 而非 `-->`**。原因：渲染引擎会将 `>` 转义为 `&gt;`，导致 `-->` / `==>` 解析失败。`---` 是唯一全场景兼容的连接符。
>>> 2. 边标注使用 `---|文本|` 格式，`|` 必须成对。
>>> 3. 节点标签用 `["文本"]`，ID 只用英文字母。
>>> 4. `class` 语句放在所有节点和边之后。
>>> 按攻击阶段用 subgraph 分组。无攻击时呈现运维时间线，全部 normal 色。
>>>
>>> 正确示例：
>>> ```mermaid
>>> graph LR
>>>     classDef normal fill:#4CAF50,stroke:#388E3C,color:#fff
>>>     classDef suspicious fill:#FF9800,stroke:#F57C00,color:#fff
>>>     classDef critical fill:#F44336,stroke:#D32F2F,color:#fff
>>>     A["04-02 首次暴力破解"] ---|192.168.1.101| B["04-05 大规模暴力破解"]
>>>     B --- C["04-07 最终入侵"]
>>>     C --- D["04-07 持久化后门"]
>>>     class A,B,C critical
>>>     class D suspicious
>>> ```
