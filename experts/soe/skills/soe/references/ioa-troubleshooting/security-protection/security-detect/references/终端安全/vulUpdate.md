## 〇、服务定位（工单："漏洞修复失败/漏洞库没更新"）

vulUpdate = **漏洞补丁库更新**。定时取最新补丁包→读时间戳→解析 TVL(漏洞库)与 VUL(补丁库) XML/zip→写库→SaveTimeStamp 落地；状态机 NEW→CONF_DONE→CORE_PATCH_DONE→MOVE_DONE→DONE。

### 日志文件

| 用途 | 路径 |
|---|---|
| 主日志 | `/data/services/pcmgr_enterprise/logs/vulUpdate/vulUpdate.log` |
| 错误 | `.../vulUpdate/error_vulUpdate.log` |
| fatal | `.../vulUpdate/fatal_vulUpdate.log` |

### 串联查询字段：补丁文件名 `PatchStatus.FileName`、`TimeStamp`、状态 `PatchStatus.Status`。
