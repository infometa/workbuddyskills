# iOA 云规范接口调用速查

> 全量接口清单见技能内置目录 `references/api-docs/云规范接口/版本：2022-06-01/`，本表仅列常用动作与调用要点，供本技能快速取用。

## 1. 调用约定

- 请求：`POST {base_url}/capi/<Module>/<Action>`，body 为 JSON
- 签名：TC3-HMAC-SHA256，必带头 `X-TC-Version: 2022-06-01`、`X-TC-Timestamp`、`X-TC-SecretId`、`Authorization`
- 成功响应：`{"Response": {"Data": ..., "RequestId": ...}}`
- 失败响应：`Response.Error.Code` 非空，配合 `Response.Error.Message`、`RequestId` 排查
- 查询类统一用 `Condition`：`{"PageNum":1,"PageSize":50,"FilterGroups":[{"Filters":[{"Field":"UserId","Operator":"eq","Values":["x"]}]}],"Sort":{"Field":"Status","Order":"asc"}}`
- 常见操作符：`eq` / `like` / `ilike` / `nlike` / `gt` / `egt` / `lt` / `elt` / `array_any`

## 2. 常用只读动作（无需 --confirm-write）

| 模块 | Action | 说明 |
|---|---|---|
| 公共 | `common/DescribePublicEncryptKey` | 获取 RSA 公钥（加密 Password 等字段用）|
| 身份与权限 | `Assets/Account/DescribeLocalAccounts` | 获取账号列表 |
| 身份与权限 | `Assets/DescribeAccountGroups` | 获取账号分组（组织架构）|
| 身份与权限 | `Assets/DescribeAccountDirectResources` | 账户直接关联的资源 |
| 身份与权限 | `GatewayResource/DescribeResourceModules` | 资源组（资源模块）列表 |
| 身份与权限 | `GatewayResource/DescribeBusinessResources` | 业务资源列表 |
| 终端资产 | `Assets/Device/DescribeDevices`（8.0+ 默认；参数放顶层 OsType+GroupId，总数取 Data.Paging.Total）| 终端列表 |
| 终端资产 | 平台默认分组 ID 枚举（见 SKILL.md「版本约定」节）；`Assets/DescribeDevicesGroups` 8.0+ 常返回空/路由错误 | 终端分组列表 |
| 终端资产 | `Assets/DescribeSoftwares` | 软件统计 |
| 合规 | `EndpointControl/DescribeCompliances` | 终端合规状态 |
| EDR | `EDR/ListEvents` | EDR 事件列表（8.6P1+）|

## 3. 常用写动作（需 --confirm-write）

| 模块 | Action | 说明 |
|---|---|---|
| 身份与权限 | `Assets/Account/CreateLocalAccount` | 创建本地账号（Password 需 RSA 加密）|
| 身份与权限 | `Assets/Account/ModifyLocalAccount` | 修改本地账号 |
| 身份与权限 | `Assets/Account/ResetLocalAccountPassword` | 重置密码 |
| 身份与权限 | `GatewayResource/CreateBusinessResource` | 创建业务资源 |
| 身份与权限 | `NGN/SaveAccountResources` | 给账号授权资源 |
| 身份与权限 | `NGN/DeleteAccountResources` | 解绑账号资源 |
| 准入 | `NGN/AddBlackDevices` / `NGN/RemoveBlackDevices` | 设备加/移黑名单 |
| 数据安全 | `DSC/CreateDataSecurityPolicy` 等 | 数据安全策略 |

## 4. 敏感字段加密

创建账号等接口的 `Password` 字段需用后台公钥 RSA(PKCS1v15) 加密：

```bash
# 方式一：让 call 自动加密指定字段
python ioa_cli.py call --action Assets/Account/CreateLocalAccount \
    --body-file create.json --pwd-field Password --confirm-write --config xxx.json

# 方式二：先单独加密，再手动填入 body
python ioa_cli.py encrypt --text 'Ioa@2026!' --config xxx.json
```

## 5. 私有化 vs SaaS

| 场景 | base_url 形如 | service | path_prefix |
|---|---|---|---|
| 私有化 | `https://<内网域名>:8443` | 留空（自动 capi）| `/capi` |
| SaaS | `https://ioa.tencentcloudapi.com` | `ioa` | 视接口而定 |

## 6. 自然语言 → 调用示例（可直接套用）

> 统一前缀：`cd scripts && python ioa_cli.py call --config ../configs/<customer>.json`，下方省略。

### 查账号「张三」
> “帮我查一下账号 zhangsan”
```bash
--action Assets/Account/DescribeLocalAccounts \
--body '{"Condition":{"PageNum":1,"PageSize":10,"FilterGroups":[{"Filters":[{"Field":"UserId","Operator":"eq","Values":["zhangsan"]}]}]},"ShowFlag":1}'
```

### 列出某分组下的账号
> “看看分组 ID 260 下面有哪些账号”
```bash
--action Assets/Account/DescribeLocalAccounts \
--body '{"Condition":{"PageNum":1,"PageSize":50},"AccountGroupId":260,"ShowFlag":2}'
```

### 查组织架构 / 账号分组
> “iOA 的组织架构是怎样的”
```bash
--action Assets/DescribeAccountGroups --body '{"Condition":{"PageNum":1,"PageSize":200}}'
```

### 查终端（按登录名）
> “查 atao 登录的终端”
```bash
--action Assets/Device/DescribeDevices \
--body '{"OsType":0,"GroupId":1,"PageNum":1,"PageSize":50,"Filters":[{"Field":"IoaUserName","Operator":"eq","Values":["atao"]}]}'
```
> 默认按 8.0+ 写法：新路径 `Assets/Device/DescribeDevices`、参数放**顶层**（不能用 Condition 包裹）、总数在响应 `Data.Paging.Total`；`OsType`/`GroupId` 平台分组常量见 SKILL.md「版本约定」节。仅当新路径报 `InvalidRequestRoute`（8.0 以前环境）时才退回旧写法：
> `--action Assets/DescribeDevices --body '{"Filters":[{"Field":"IoaUserName","Operator":"eq","Values":["atao"]}],"PageSize":50,"PageNum":1}'`

### 查某终端装的软件
> “看看这台设备装了什么软件”（DeviceId 放 query 不便时也可置于 body 过滤）
```bash
--action Assets/DescribeDeviceSoftwares \
--body '{"Filters":[{"Field":"Name","Operator":"like","Values":["WeChat"]}],"PageSize":50,"PageNum":1}'
```

### 查终端合规状态
> “有哪些终端端口不合规”
```bash
--action EndpointControl/DescribeCompliances \
--body '{"Filters":[{"Field":"PortStatus.Status","Operator":"eq","Values":[0]}],"PageSize":50,"PageNum":1}'
```

### 查 EDR 事件
> “最近的 EDR 高危事件”
```bash
--action EDR/ListEvents \
--body '{"Condition":{"PageNum":1,"PageSize":50,"FilterGroups":[{"Filters":[{"Field":"RiskLevel","Operator":"eq","Values":[3]}]}],"Sort":{"Field":"OccurTime","Order":"desc"}}}'
```

### 查业务资源（按名）
> “有没有叫 OA系统 的资源”
```bash
--action GatewayResource/DescribeBusinessResources \
--body '{"ServiceName":"OA系统","Condition":{"PageNum":1,"PageSize":50}}'
```

### 查账号已授权的资源（先解析 AccountId）
> “张三现在有哪些资源权限” —— 第一步查 AccountId，第二步：
```bash
--action Assets/DescribeAccountDirectResources --body '{"AccountId":1001}'
```

### 创建本地账号（写操作 + 密码加密）
> “新建一个账号 wangwu，密码 Ioa@2026!，放到分组 260”
把以下存为 `create.json`（GroupId 来自分组查询）：
```json
{"UserId":"wangwu","UserName":"王五","Password":"Ioa@2026!","GroupId":260,"Status":1,"IsValidTime":0}
```
```bash
--action Assets/Account/CreateLocalAccount --body-file ./create.json --pwd-field Password --confirm-write
```

### 重置账号密码（写操作 + 密码加密）
```bash
--action Assets/Account/ResetLocalAccountPassword \
--body '{"AccountId":1001,"Password":"NewPwd@2026!"}' --pwd-field Password --confirm-write
```

### 禁用 / 启用账号（写操作）
> “把张三禁用”（Status 0=禁用 1=启用）
```bash
--action Assets/Account/ModifyLocalAccount --body '{"AccountId":1001,"Status":0}' --confirm-write
```

### 设备加 / 移黑名单（写操作）
> “把这台设备加黑名单”
```bash
--action NGN/AddBlackDevices --body '{"device_ids":["DEVICE_MID"]}' --confirm-write
--action NGN/RemoveBlackDevices --body '{"device_ids":["DEVICE_MID"]}' --confirm-write
```

### 解绑账号资源（写操作）
> “把张三的 OA系统 权限收回”（rid 来自资源查询）
```bash
--action NGN/DeleteAccountResources \
--body '{"AccountId":1001,"ResourceList":[{"ResourceId":62,"ResourceType":1}]}' --confirm-write
```

> 授权（SaveAccountResources）优先直接用 `grant` 子命令，它会自动完成名称→ID 解析。

## 7. 名称 → ID 解析速记

| 名称 | 解析接口 | body 关键 | 取字段 |
|---|---|---|---|
| 账号名/UserId | `Assets/Account/DescribeLocalAccounts` | `FilterGroups…Field=UserId` | `AccountId` |
| 账号分组名 | `Assets/DescribeAccountGroups` | `Filters…Field=Name` | `Id` |
| 资源名 | `GatewayResource/DescribeBusinessResources` | 顶层 `ServiceName` | `ServiceId` |
| 资源组名 | `GatewayResource/DescribeResourceModules` | `Filters…Field=Name` | `AreaId` |
| 终端 | `Assets/Device/DescribeDevices`（8.0+ 默认）| 顶层 `OsType`+`GroupId`+`Filters` | `DeviceId` |
| 终端分组 | 平台默认分组 ID 枚举（8.0+，见 SKILL.md「版本约定」节）| — | `GroupId` |
