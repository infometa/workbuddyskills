## 〇、服务定位

ou-query = **组织架构与账号查询服务**。按 uid/mid/loginKey 查账号、批量查账号组/虚拟组、查在线状态、查账号可见范围(含继承)、查菜单 id 列表等。**内存缓存型**：组织/账号/组关系全量加载进内存，按 DB 表版本号(count/maxSeq/maxModifyTime)判断是否需刷新（默认周期刷新）。被 account-info、登录、鉴权链路广泛调用。
