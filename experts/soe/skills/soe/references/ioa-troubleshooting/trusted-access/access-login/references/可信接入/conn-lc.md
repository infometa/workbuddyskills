## 二、故障场景库

### 场景 A：客户端频繁断连 / 显示离线（心跳超时）

**② 大概原因**：客户端网络不稳/进程异常导致心跳中断；或连接被对端关闭。

### 场景 B：客户端显示离线但连接看似正常（上线失败）

**① 功能逻辑**：conn-lc 上线要经 conn-sc（6700）通知 conn-mgr 更新在线状态。
**② 大概原因**：conn-lc→conn-sc→conn-mgr 这条上线链路失败（网络/conn-mgr异常/6700路由缺失）。

### 场景 C：conn-lc 启动即失败 / 反复重启（注册 conn-mgr 失败）

**① 功能逻辑**：主长连接角色启动时必须向 conn-mgr 注册成功，重试 50 次仍失败则进程退出。
**② 大概原因**：conn_mgr 地址配置错 / conn-mgr 或 conn-sc 不可达 / 6700 路由缺失。
**③ 排障方式**：在 `error_conn-lc.log` 搜 `register failed:` / `[conn_lc_mgr] register info to conn_lc manager fail:` / `conn manager register fail`；若见 `cmd(6700) route config is empty` 则是 route_lc.json 缺 6700 dispatch。
