## 二、故障场景库

### 场景 A：客户端连接正常但控制台显示离线（上线未生效 · 头号根因）

**① 功能逻辑**：conn-mgr 收到 MidOnline 时 `UPDATE devices ... WHERE mid=..`，若该 mid 在 `devices` 表无记录，更新影响 0 行，上线不生效。
**② 大概原因**：设备 mid 不在 `devices` 表 / mid 不一致（设备未正确注册进库）。
> [安全化移除] 原始资料中的执行片段、敏感材料索取或变更步骤已删除；仅可按公共规范进行只读、限时、脱敏核实。

### 场景 B：下线不生效（设备已断仍显示在线）

**① 功能逻辑**：MidOffline 下线 SQL 需 `mid + conn_key` **双条件**匹配，conn_key 不一致则下线不生效。
**② 大概原因**：conn_key 与上线时不一致（换连接节点）/ 下线 SQL 执行失败。
