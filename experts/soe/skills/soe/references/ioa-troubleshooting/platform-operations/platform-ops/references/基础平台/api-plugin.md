## 〇、服务定位（⚠️日志命名特殊）

api-plugin = **NGN 资源权限授予 + 自定义字段插件**。以 ioaapi 插件形式实现"给用户授予 NGN 资源权限"组合动作：判断用户→创建/复用资源组→创建/授权域名与 IP 资源。

### 日志文件

|---|---|
| 主日志 | `/data/services/pcmgr_enterprise/logs/api-plugin/api-plugin.log` |
| 错误 | ⚠️ **连字符**：`.../api-plugin/error-api-plugin.log`（非下划线） |

> ⚠️ **error 日志用连字符 error-api-plugin.log、无 fatal**。

### 串联查询字段：UserId、资源组 Name、CommonHeader。
