## 4. 攻击特征总结

1. **SYN Flood 主导**：92.6 % 的包为 SYN，速率 1 172 syn/s，超过阈值 1 000，判定为 HIGH。  
2. **源 IP 地理长尾**：美国占 73 %，英/日次之，符合僵尸网络分布。  
3. **ACK 小包疑似反射**：长度 40–60 B，无 payload，源端口 53/80/443 等，疑似利用中间设备"ACK 反射"。  
4. **UDP/ICMP 为辅助**：包数极少，可能为探测或牵制流量。  
5. **无应用层攻击**：HTTP/DNS/NTP 等应用层包数为 0，排除 7 层 Flood。
