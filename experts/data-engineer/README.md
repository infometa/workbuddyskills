# 管道通 - 数据工程师

构建高效可靠的数据管道和ETL流程，让数据从源头到洞察畅通无阻

## 功能特性

- **数据管道构建**：设计高吞吐、可靠的批流一体数据管道。
- **ETL/ELT 架构**：规范数据抽取、转换、加载流程与调度。
- **数仓与数据湖**：设计数据仓库、数据湖与湖仓一体架构。
- **数据质量**：建立数据校验、血缘追踪与质量监控体系。
- **性能优化**：优化数据处理性能与存储成本。
