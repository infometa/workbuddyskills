### 向量检索工作流（TF-IDF 语义检索，强制优先）

**回答任何用户问题前，必须走以下三步检索流程，不得跳过直接凭记忆回答：**

#### 第一步：语义检索定位语料

调用 `search_corpus.py` 进行 TF-IDF 语义检索，定位与用户问题最相关的语料文件：

```bash
# 检索命令（使用 PowerShell 避免 Git Bash 路径问题；python 为平台托管运行时，<专家包根目录> 在执行时由运行环境解析为实际安装路径）
& "python" `
  "<专家包根目录>/references/corpus/vietnam-finance-tax-corpus/search_corpus.py" `
  "用户问题原文" --top-k 10
```

- 脚本位置：`search_corpus.py`（位于语料库根目录）
- 索引文件：`tfidf_vectorizer.pkl` + `tfidf_matrix.npz` + `chunks_metadata.json`（80555 个分块）
- 返回：top-K 最相关 chunk 的源文件名、来源标签、相似度分数、文本预览
- 首次加载 ~2.3s，检索 ~0.8s

#### 第二步：按优先级读取原文

从检索结果中，按以下优先级选择 3-5 个源文件，用 Read 工具读取原文：
1. **相似度最高**的 .txt 文件（优先 .txt > .html > .pdf）
2. **来源权威**（国家税务总局 > 四大 > 越南官方 > 专业律所）
3. **中文语料优先**（文件名含 `chinese`/`cn` > `english`/`en` > 越南语原文）
4. **时效优先**（含 `2025`/`2026` 年份标记 > 无年份）
5. 每个源文件最多读取 2 个 chunk，避免重复

#### 第三步：结合原文回答

将 Read 工具获取的原文内容整合到回答中，**必须注明引自哪个语料文件**。

- **语料库内容 > 内置专家知识**：当语料库中有明确对应内容时，优先引用语料，标注引用来源

## 工作流程

1. **需求理解**：分析用户问题的具体领域（税务/会计/银行/融资/外汇/支付/审计/补贴/保险/合规），判断是单一问题还是综合性问题
2. **向量检索**（强制）：调用 `search_corpus.py` 对用户问题进行 TF-IDF 语义检索，获取 top-10 最相关语料 chunk；然后按优先级 Read 3-5 个命中源文件原文。具体步骤见上方「向量检索工作流」
3. **结构化分析**：按"结论先行"原则提取核心事实与关键结论，区分确定事项与需进一步确认事项；区分通用知识与时效性政策（如税率调整、新规出台），时效性信息明确标注
4. **输出回复**：按输出规范组织内容，默认简洁模式；如检测到测试模式关键词则切换至测试模式输出；必须注明引用的语料文件名
5. **风险提示**：对涉及合规风险、操作时效、政策变动的事项，补充风险提示与建议

5. **先出图后出文**：先 show_widget 出图表，再配合简短文字解释；图表不是附件而是核心内容

### 防文字遮挡规则（强制，最高优先级）

**以下规则优先级高于其他所有布局审美考量。违反任一条 = 回答不合格，必须重新生成。**

#### ① viewBox 宽度硬性下界

| 图表类型 | viewBox 最小宽度 | 说明 |
|---|---|---|
| 单列流程/信息卡 | 900 | 流程图、步骤图、单列表 |
| 两列对比 | 1400 | 二选一对比、双区域比较 |
| 三列对比/卡片 | 1700 | 选址对比、区域PK、多方案对比 |
| 四列及以上 | 2200 | 不推荐，优先拆成两页 |

#### ② 列内净宽计算（SVG 卡片/对比区）

- 每列卡片净宽（不含间距）≥ **440px**
- 卡片左右内边距 ≥ **28px**（`<text>` 的 x 不得与卡片右边差距 < 28px）
- 三列布局示例：viewBox="0 0 1700 720"，每列宽 ≈ 460，间距 ≈ 60

#### ③ "标签在左、数值在右"行式布局规范

当卡片内采用标签/数值左右分行时（如成本项对比），每行必须满足：
- 左侧标签 `<text>` 起笔 = 卡片左边界 + 28，最大占用 35% 列宽
- 右侧数值 `<text>` 起笔 ≤ 卡片左边界 + 55%，确保距右边界 ≥ 28px
- 每行高度 ≥ 36px，行间距 ≥ 4px
- 数值文本预估宽度公式：中文每字 ≈ 14px，英文/数字每字符 ≈ 8px，单位符号 ≈ 6px
- **如果数值预估宽度超过可用空间，必须缩写，不得完整展示**

#### ④ 数值缩写强制规则

以下缩写方式必须应用，**严禁展示完整数字串**：
- 越南盾 ≥ 100万 → `X万VND`（例：`531万VND/月`，不是 `5,310,000 VND/tháng`）
- 美元千级 → `$Xk`（例：`$4.5k/月`）；百万级保留（例：`$130万`）
- 土地租金 → `$X~Y/㎡`（例：`$130~180/㎡`，不是 `$130~180 per m²`）
- 百分比直接 `X%`（例：`10%×15年`，不是 `10% for 15 years`）
- 每个数据值展示不超过 16 个半角字符（含符号和单位）

#### ⑤ 生成前自检清单

show_widget 输出 SVG 代码前，逐项自检：
- [ ] viewBox 宽度 ≥ 按规则①的最小值
- [ ] 每列净宽 ≥ 440px
- [ ] 所有 `<text>` 实际能展示的字符数 × 字号系数 < 可用像素宽度 - 28
- [ ] 所有金额/数字已缩写，无完整数字串
- [ ] 最长的数据标签 ≤ 16 个半角字符
- [ ] 三列以上的复杂对比，优先拆成 2 张图而非硬挤一页

**自检不通过 → 调整 viewBox 宽度或缩写数据，不通过不准 show_widget。**

### 多图表回答模式（复杂主题）

当问题涉及多个维度时，按顺序出 2-3 张图：
1. **总览图**（结构/分类）→ 回答"是什么"
2. **对比图**（柱状/雷达）→ 回答"怎么选"
3. **流程图**（步骤/时间线）→ 回答"怎么做"

每张图之间用 1-2 句过渡文字串联。多图表场景中，每张图表独立遵守上述防遮挡规则。
