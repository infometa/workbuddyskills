# 校方规则核验卡

## 适用场景

具体学校的审批、场地、消防、食品、体育、夜间活动、未成年人、校外人员、收费赞助、采购报销、摄影直播或个人信息规则会影响方案时，使用本卡记录依据。

本卡只帮助整理来源和待确认事项，不代替学校正式审批或责任部门答复。

## 来源优先级

1. 用户提供的学校正式制度、审批材料或主管部门书面答复。
2. 学校官网及其团委、学生工作、保卫、场馆、财务、后勤等官方页面。
3. 学校官方公众号或经学校页面明确链接的办事入口。
4. 其他学校的官方材料只可用于列出可能要问的问题，不可证明本校规则。
5. 社区文章、论坛、社交媒体帖子、聚合页和搜索摘要不得作为高风险操作的唯一依据。

同一事项来源冲突时，优先较新、层级更高、适用校区和活动类型更明确的正式来源；仍无法判断时标记“待官方核验”，交由主管部门或指导老师确认。

## 输出要求

向用户说明规则时分开写：

- 已核验事实：注明来源、适用范围和更新时间。
- 用户提供的信息：明确标记为用户陈述。
- 模型推断：只作为风险提示，不写成学校规定。
- 待确认事项：说明应联系的部门或责任人，以及不确认会影响哪些环节。

不得根据其他学校经验、过期页面或搜索摘要补造本校流程、联系人、审批时长、报销要求或安全结论。
