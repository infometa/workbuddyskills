# 相似性报告审阅与正当修订

## 定位与边界

本流程用于解读用户合法取得的查重/相似性报告，区分规范引用与不当重复，并制定基于理解、证据和作者原创分析的修订计划。报告分数不是学术不端的单独结论；不同系统、库范围、算法和文件版本不可直接横比。

不提供同义词机械替换、打乱语序、插入无关或不可见字符、翻译回译掩饰来源、删引文逃避识别等规避技巧；不预测或保证复检重复率。用户若要求“过检测”，拒绝该部分并转为来源核验、规范引用和实质修订。

## 所需输入

- 报告工具与版本/入口、检测日期、提交文件版本和检测范围
- 总体指标及学校阈值说明，仅作背景
- 标红/相似段落、对应来源、相似类型和位置
- 论文原文及其上下文、当前引文和参考文献
- 学校规则、导师要求、允许排除项

只有总百分比而无段落和来源时，不猜测原因；请用户提供可见报告页或导出的段落明细。

## 重复分类

| 类别 | 识别特征 | 处理 |
|---|---|---|
| 正当的固定表达 | 学科术语、标准名称、公式、法律/政策原名、方法必要固定表述 | 核对准确性和学校规则；通常保留，不为降数字破坏术语 |
| 规范直接引用 | 引号/块引、来源、页码或定位信息完整，引用比例合理 | 核对原文和引用标准；必要时缩短引文并增加作者解释 |
| 规范转述或综合 | 用作者自己的论证结构准确转述，来源清楚，不扩大结论 | 核对是否过度贴近句法；补足来源间比较和本研究连接 |
| 模板性部分 | 声明、目录、参考文献、调查说明等可能被系统计入 | 依据学校与报告排除规则判断，不擅自删除必需内容 |
| 不当大段搬运 | 连续句群与单一来源高度接近，缺引号、缺来源或引用不足 | P0/P1；回到原文理解后重建段落，规范引用，必要时删除 |
| 改写不充分 | 仅替换少量词、句法和论证顺序仍复制来源 | 中度或深度改写；重新组织主张—证据—解释—边界 |
| 拼接式转述 | 多来源句子串联，缺少作者比较、解释和连接 | 按问题重新综合多来源，增加作者分析，不隐藏来源 |
| 自我重复 | 与作者已提交、发表或前期文本高度重合 | 核对学校/期刊自我引用规则，透明引用或说明，不假装新作 |
| 来源或引文异常 | 标红来源与正文引文不一致、二手引文伪装原始来源 | 核对原始出处，修正或删除无法验证的内容 |

“正当”不等于必然不计入系统；判断目标是合规和论证质量，不是操纵指标。

## 高优先级定位

按以下顺序处理：

1. **P0**：未标注直接复制、来源伪造/错配、数据和结论挪用、规避痕迹、可能违反学校纪律的段落。
2. **P1**：核心论点、文献综述、方法和讨论中的长段重复；单一来源占比高；改写不充分；引用虽有但无法定位。
3. **P2**：通用句式、局部冗余、格式导致的识别、对论证影响较小的短语。

同级内优先处理：篇幅长且连续 → 位于核心章节 → 来源集中 → 无规范引用 → 影响主张真实性。不得只按颜色深浅或系统百分比排序。

## 逐段修订计划

每个段落建立稳定 ID，并沿用 `drafting-and-revision.md` 的八维修订与改写等级。

### 八维诊断

1. 结构：段落是否服务研究问题，功能是否清楚。
2. 论证：主张、证据、解释和边界是否完整。
3. 证据：来源是否真实、相关、可定位，是否需要直接引语。
4. 概念：术语、对象、时段和分析单位是否一致。
5. 方法：表述是否与真实研究过程一致。
6. 语言：是否准确简洁，是否保留来源句法。
7. 衔接：与前后段关系是否明确。
8. 格式：引号、引文、页码和参考文献是否合规。

### 改写等级

- **轻度**：重复属于通用或局部表达，修正语法、冗余和衔接，不改变主张、证据和边界。
- **中度**：改写不充分或拼接明显；先提取来源要点，再按本段任务重组句子与段落，保留准确引用。
- **深度**：段落功能、论证或来源依赖有根本问题；重建段落或调整章节顺序，先说明影响并请用户确认。

### 段落计划表

| 段落 ID/位置 | 报告来源与相似片段 | 正当/不当分类 | P级 | 八维问题 | 改写等级 | 保留的事实/术语 | 来源与原文位置 | 修订动作 | 需作者补充 | 复核标准 |
|---|---|---|---|---|---|---|---|---|---|---|

实质修订顺序：确认段落任务 → 阅读并核对来源 → 用一句话写作者自己的主张 → 选择必要证据并规范引述/转述 → 增加比较、解释、反例或边界 → 与本研究连接 → 核对引用和参考文献。不得在不理解来源时直接“洗句子”。

## 复检建议

- 保存初检报告、原稿、修订计划和修订后版本，记录段落 ID 与改动理由。
- 完成 P0/P1 实质修订后，先人工核对引用、事实和论证，再按学校允许的工具与流程复检。
- 复检使用与提交要求一致的文件范围和版本；工具或库范围变化时，不把指标差异全归因于修订。
- 若正当引文仍被标记，保留规范引用和必要原文，不为降低数字删除来源；按学校流程向导师或教务说明。
- 复检仍高时回到具体段落和来源诊断，不连续多轮机械改词。达到合规、证据准确和论证清楚后停止。
- 只报告“已完成哪些实质修订、仍有哪些风险、需谁确认”，不预测下一次百分比。

## 交付

- 报告范围与局限摘要
- 正当/不当重复分类清单
- P0/P1/P2 高优先级段落表
- 沿用八维修订和改写等级的逐段计划
- 引用/来源异常表
- 复检前人工核对清单与过程留痕建议
