# 文献建议与证据矩阵

## 默认处理顺序

1. 先检查用户是否提供论文 PDF、引用导出、DOI、稳定链接、摘要页、关键章节或学校图书馆永久链接。
2. 已有可信材料时，优先整理这些材料，不为增加数量额外搜索。
3. 没有材料时，将研究问题拆成对象、现象、情境、理论和方法五组概念，给出中文与英文关键词、同义词、布尔检索式、年份和学科筛选建议。
4. 请用户在学校图书馆或本人有权使用的知网、万方、维普及其他数据库中检索并导出结果。
5. 只有用户明确要求核验已知文献，且开放来源能够直接访问时，才按 `trusted-accessible-sources.md` 做少量查询。
6. 找不到可靠来源或拿不到任务需要的原文时，请用户补充可信材料；无法补充则跳过该条，把对应内容保留为待补证据的写作框架。

## 不做的事情

- 不主动登录、抓取或绕过知网、万方、维普及其他付费、机构授权、验证码或受限数据库。
- 不用全网泛搜代替学术检索，不把聚合下载站、网盘转载、自媒体和搜索摘要当作可信论文来源。
- 不因用户需要“更多文献”就生成看似合理的作者、题名、期刊、年份、DOI 或页码。
- 不用相近题名、相似论文、模型记忆或二手博客替代缺失的原始来源。
- 不把元数据、摘要、AI TLDR 或引用网络升级为全文证据。

## 开放来源路由

- DOI 与出版元数据：Crossref
- 摘要、外部标识与开放全文线索：Semantic Scholar
- 预印本身份、版本、摘要与 PDF：arXiv
- 开放获取期刊文章线索：DOAJ
- 生物医学元数据：PubMed E-utilities
- 生物医学开放全文：PubMed Central，仅限可访问全文并核对许可证的文章
- OpenAlex：有可用免费 API Key 时作为补充，不作为无配置默认依赖

调用条件、实测状态和限制见 `trusted-accessible-sources.md`。

## 内容使用等级

- **M1 元数据**：题名、作者、DOI、出版源、日期等身份字段已核验。只能用于文献身份和格式检查。
- **M2 摘要**：元数据和数据库原始摘要可见。只能转述摘要明确写出的研究目的、方法概况、结果或结论，并标注“基于摘要”；不记录直接引语、页码、详细样本、方法细节、结果数值和作者限制。
- **F 全文**：原文可访问，版本和许可证已记录。可以在定位原文后分析方法、结果、限制、直接引语和页码。
- **U 未核验**：只有搜索线索、AI 摘要、二手转述或冲突记录。不得写入正式参考文献和正文事实。
- **X 排除**：身份错误、重复、与主题无关或可靠性不足。

## 停止检索规则

出现任一条件即停止继续检索：

- 连续两个可信开放来源无法确认文献身份。
- 任务需要全文、页码、详细样本、方法细节、结果数值、作者限制或全文层面分析，但只能取得 M1 或 M2。
- 页面要求登录、订阅、验证码、机构网络或其他访问权限。
- 文献身份、版本、作者、年份或 DOI 存在无法解释的冲突。
- 当前来源不在可信清单内，且无法从官方页面确认其身份与用途。

停止后只做三件事：说明缺少的材料；给出用户可执行的检索式和筛选方式；请用户提供可信源或跳过该文献。

## 证据矩阵字段

| 字段 | 内容 |
|---|---|
| 文献编号 | L1、L2 等 |
| 完整身份 | 作者、年份、题名、来源、DOI/稳定 URL |
| 内容等级 | M1/M2/F/U/X |
| 来源位置 | 用户材料编号或可信开放来源 |
| 可见范围 | 元数据、摘要、全文章节、页码、表图 |
| 研究问题 | 仅写当前可见内容明确表达的研究问题 |
| 对象与样本 | 只有原文或摘要明确提供时填写 |
| 方法 | 只有当前可见内容明确提供时填写 |
| 主要发现 | 只写可定位内容；M2 必须标注“基于摘要” |
| 限制 | 只有 F 全文明确提供时填写，不从摘要或模型判断补充作者限制 |
| 论文用途 | 可支持论文哪一节、哪一主张 |
| 原文位置 | 页码、章节、表图或段落；无法取得则留空 |
| 待补材料 | 需要用户补充的 PDF、页面、数据或引用导出 |

## 综述组织

优先按主题、机制、理论、方法、研究对象或争议设计综述框架，不按“某某认为”逐篇罗列。每节设计：

1. 本节需要回答的问题
2. 需要哪类证据
3. 用户已提供并可核验的证据
4. 尚缺的证据和建议检索式
5. 与本研究的连接

只有证据矩阵中存在 M2 或 F 内容时，才能写具体文献综合。证据不足时输出综述提纲和待补证据清单，不生成带文献事实的成稿。

## 引用规则

- 直接引语和页码必须来自 F 全文，并能定位原文。
- M1 只用于身份和格式，不用于内容主张。
- M2 内容明确标注“基于摘要”，只转述摘要明确写出的研究目的、方法概况、结果或结论；不推断全文因果、详细样本、方法细节、结果数值、作者限制和论证过程。
- 找不到原始出处时标为 U，不补写完整引文。
- 二手引用明确标识，不把二手作者改成原始研究作者。
- 数字、量表、政策条款和研究结果必须有可定位来源。
- 翻译外文原意时标明为译述，不使用虚构引号。

## 回填材料批量解析

### 接受范围与批次

- 可处理用户合法导出的 RIS、ENW/EndNote Tagged、NoteExpress 导出文本，以及结构清晰的 CSV/表格。
- 单批最多处理 50 条记录；超过 50 条时按原导出顺序分为 `B01`、`B02` 等批次，每批独立解析、去重和报错，全部批次完成后再做跨批去重。
- 不主动登录或访问知网、万方、维普及其他付费或机构授权数据库；需要原文或更完整字段时，由用户在其有权使用的数据库中导出并回填。
- 解析不等于内容核验。每条新记录只按 M1 建档；不得因导出文件含摘要或关键词而自动升级。

### 字段映射

同一字段出现多次时保留全部值并按原顺序记录；冲突值进入“待核验字段”，不静默覆盖。

| 证据矩阵字段 | RIS 常见标签 | ENW/EndNote Tagged 常见标签 | NoteExpress 常见导出字段 | 处理规则 |
|---|---|---|---|---|
| 文献类型 | `TY` | `%0` | 文献类型/Type | 保留原类型，同时映射为期刊、专著、学位论文等标准类别 |
| 作者 | `AU`/`A1` | `%A` | 作者/Author | 多作者逐条保留，不自行改写姓名顺序 |
| 题名 | `TI`/`T1` | `%T` | 题名/Title | 去除首尾空白；原始题名另存，不翻译替代 |
| 来源/期刊 | `JO`/`JF`/`T2` | `%J`/`%B` | 期刊/出版物/来源 | 按文献类型解释，不能把会议名误作期刊名 |
| 年份/日期 | `Y1`/`PY`/`DA` | `%D`/`%8` | 年/日期/Year | 优先保留完整日期；年份冲突时待核验 |
| 卷、期、页码 | `VL`、`IS`、`SP`、`EP` | `%V`、`%N`、`%P` | 卷、期、起止页 | 页码按原记录保存，不猜测缺失终页 |
| DOI | `DO` | `%R` 或 DOI 自定义字段 | DOI | 规范化为小写标识串，去除 `doi:` 和解析网址前缀后用于匹配；展示时保留可核验形式 |
| URL | `UR` | `%U` | 链接/URL | 记录稳定链接；访问权限不改变内容等级 |
| 摘要 | `AB`/`N2` | `%X` | 摘要/Abstract | 仅作为待核验内容保存；确认是数据库原始摘要后才可升级 M2 |
| 关键词 | `KW` | `%K` | 关键词/Keywords | 多值分列，保留中英文原词 |
| 出版者/地点 | `PB`、`CY` | `%I`、`%C` | 出版者、出版地 | 仅使用导出值，缺失则标“待补” |
| 学位/学校 | `M3`、`PB` 等 | `%9`、`%I` 等 | 学位、授予单位 | 标签因导出样式差异较大，必须结合文献类型人工核对 |
| 备注/附件 | `N1`、`L1`、`L2` | `%Z`、`%>` | 笔记、附件 | 不作为学术证据；仅记录用户材料位置和附件线索 |

NoteExpress 的标签名称与导出样式可能被用户自定义。无法确定的标签保留“原标签—原值”，请用户提供一条带字段说明的样例，不凭字段位置猜测。

### 去重与编号

1. 对 DOI 做大小写、空格、`https://doi.org/`、`http://dx.doi.org/` 和 `doi:` 归一化；归一化 DOI 完全相同，判为高置信重复。
2. DOI 缺失或冲突时，对题名做次级匹配：Unicode 归一化、转小写、去首尾空白、合并连续空格、统一全半角并忽略不承载语义的标点。仅题名相同但年份、作者或类型冲突时标“疑似重复”，不得自动合并。
3. 合并记录时保留字段更完整且来源可追溯的主记录，其他记录写入“合并来源”；冲突字段全部进入待核验表。
4. 去重后按首次出现顺序分配稳定编号 `L001`、`L002`……。既有编号不得因排序、合并或删除而复用；跨批重复沿用首次编号。
5. 输出去重报告：输入数、唯一记录数、DOI 重复、题名疑似重复、冲突字段、排除记录及原因。

### 内容等级与升级

- 每条解析成功的记录初始为 **M1**，只支持身份与格式核对。
- 用户提供数据库原始摘要页或可确认的原始摘要后，可升级为 **M2**；使用时明确“基于摘要”，仍受本文件 M2 边界约束。
- 用户提供可访问全文，并确认文献身份、版本、可见范围和原文位置后，才可升级为 **F**。
- 只有搜索线索、来源不明摘要或字段冲突未解的记录标 **U**；身份错误、重复或不相关记录标 **X**。
- 每次升级记录“原等级、目标等级、核验材料、核验位置、日期”；不得批量越级。

### 回填输出

每批至少输出：字段解析异常表、去重报告、带 `L` 编号的证据矩阵、等级升级待办、缺失字段清单和下一批衔接信息。若任务需要研究问题、方法逻辑、证据链、结论边界、批判性分析或原文定位，则在达到相应内容等级后调用 `output-templates.md` 的“文献精读卡”；只有 M1 时不得生成内容型精读结论。

## 检索审计

每次检索或用户回填均使用 `output-templates.md` 的“检索审计记录”，记录检索源、原样检索式、检索日期、筛选条件、命中数、保留数、排除理由、材料批次和责任边界。原检索式与筛选条件必须可复现，不用事后美化后的检索式替换实际记录。“本轮交付摘要”中列出审计记录 ID、已纳入的 `L` 编号和待补材料。

## 文献管理工具选择与基本路径

实际菜单名称可能随软件版本、语言和学校授权变化，以软件当前官方帮助和用户界面为准。

| 工具 | 更适合 | 主要注意点 |
|---|---|---|
| Zotero | 跨平台、浏览器采集、团队共享、开放生态 | 中文数据库元数据需人工核对；样式与插件版本应留痕 |
| NoteExpress | 中文文献与国内高校常见工作流 | 导出字段和样式可能自定义；跨软件交换优先使用 RIS 并抽查字段 |
| EndNote | 英文数据库、机构授权和期刊投稿工作流 | 版本与授权差异明显；样式文件和共享库操作前先备份 |

### 导入与导出

1. 从数据库导出时优先选择 RIS；PubMed 等提供 NBIB/Medline 时，可按目标工具支持格式导入。保留原始导出文件，不覆盖。
2. Zotero：`文件 → 导入` 选择 RIS/EndNote XML 等受支持文件；交换给其他工具时使用 `文件 → 导出文库`，选定格式并确认是否包含笔记/文件。
3. NoteExpress：通过 `文件/导入题录` 选择正确过滤器导入；导出时选择 RIS 或目标过滤器，先用 3—5 条样例核对作者、题名、来源、年份、DOI。
4. EndNote：`File → Import → File` 选择文件与匹配的 Import Option；导出时按目标格式选择 Output Style，再保存为文本或交换格式。
5. 任一工具导入后，都按本文件的 DOI/题名规则去重，并抽查不少于作者、题名、年份、来源、卷期页和 DOI 字段；不得把“成功导入”视为“字段已核验”。

### Word 插件基本路径

- Zotero：在 Word 的 `Zotero` 选项卡使用 `Add/Edit Citation` 插入引文、`Add/Edit Bibliography` 生成文后表，并在 `Document Preferences` 选择学校要求的样式。
- NoteExpress：在 Word 的 NoteExpress 选项卡中选择输出样式，使用“插入引文/插入题录”与“格式化参考文献”等对应命令；生成后抽查正文序号与文后条目。
- EndNote：在 Word 的 `EndNote` 选项卡通过 `Insert Citation` 插入引文，在 `Style` 选择输出样式并用 `Update Citations and Bibliography` 更新。
- 学校模板、学院细则和导师明确要求始终高于软件内置样式。样式生成结果必须人工核对，不直接作为最终合规证明。

本专家只指导文献工作流、字段核验和基本菜单路径；安装、插件不显示、加载项被禁用、权限、同步、崩溃或系统兼容故障，转交“电脑操作顾问”处理，并向其提供软件名称与版本、操作系统、Word 版本、报错原文和已尝试步骤。
