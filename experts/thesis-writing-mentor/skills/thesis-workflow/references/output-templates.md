## 开题报告逐节模板

开题内容必须基于选题定稿包、证据矩阵和真实研究条件。缺少材料时保留待填字段，不承诺研究结论。

### 1. 基本信息

- 论文题目（中/英文）：

- 主研究问题与子问题：

### 2. 背景与意义

- 背景链：现实/学术情境 → 具体现象 → 可核验证据 → 待研究问题
- 理论意义：对概念、关系、机制或边界可能提供何种增量，不预写结果
- 实践意义：面向谁、支持何种决策或改进、适用边界是什么
- 必需证据与 `L` 编号：
- 待补字段：

### 3. 国内外研究现状

- 综述问题与组织维度：主题/机制/理论/方法/对象/争议
- 每一主题：已有共识｜分歧｜证据等级｜限制｜与本研究连接
- 证据矩阵定位：`L___`
- 候选增量/创新点：`I___`
- 缺失证据与检索审计：`Q___`

## 学校开题表字段对接

不同学校可能合并、拆分或改名。先保留学校表单原字段，再将内容映射到本模板，不用通用模板覆盖学校栏目。

| 学校常见字段 | 对接章节 | 处理说明 |
|---|---|---|
| 选题依据/研究背景 | 背景与意义 | 区分事实背景、问题与证据，不堆政策口号 |
| 目的与意义 | 背景与意义、研究目标 | 意义不写成已实现效果 |
| 国内外研究现状/文献综述 | 研究现状 | 调用证据矩阵与综述规则 |
| 主要内容/拟解决问题 | 研究内容与目标 | 对应主问题、子问题和内容 ID |
| 研究方法 | 研究方法与技术路线 | 写选择理由、材料、步骤和限制 |
| 技术路线/研究思路 | 技术路线文字结构 | 给出主线、分支和反馈环，可供用户绘图 |
| 创新点/特色 | 创新点 `I___` | 必须定位 `L` 编号；不足时标候选增量 |
| 可行性/已有条件 | 可行性分析 | 区分已有条件、缺口和降级方案 |
| 进度计划 | 进度安排 | 以学校硬节点为准，按真实剩余时间调整 |
| 预期成果 | 研究目标/可检查产出 | 写计划交付物，不承诺研究结论 |
| 参考文献 | 参考文献 | 仅列可核验身份和字段 |
| 指导教师意见/审核意见 | 不代填 | 预留学校和导师填写，不模拟签字或意见 |
