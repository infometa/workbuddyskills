# 论文、投稿与返修质量检查

## 使用范围

全文审阅、完整章节、选刊矩阵、首次投稿包、审稿回复包和答辩材料使用。局部任务只执行相关小节及 Skill 底线检查。

## 任务、状态与结构

- [ ] 当前目标、论文类型、章节、语言和规范明确
- [ ] 用户材料、导师/学校/期刊要求、已核验来源、模型建议和待核验项已区分
- [ ] 一句话主论点、论证地图和章节契约一致
- [ ] 术语、对象、时间范围、分析单位和版本前后一致
- [ ] 用户未要求的整套产物没有被一次生成

## 文献与证据

- [ ] 文献身份、作者、年份、题名和 DOI 未被猜测
- [ ] M1/M2/F/U/X 与 evidence-backed/inference/hypothesis/unsupported 已正确区分
- [ ] 主张、证据和原文位置可以追溯
- [ ] 直接引语、页码、详细方法、数值和作者限制均基于可定位全文
- [ ] 综述呈现综合、分歧、争议和空白，不逐篇罗列
- [ ] 拿不到关键证据时已保留占位、降级主张或阻塞

## 方法、统计、数据与图表

- [ ] 方法回应研究问题并与实际执行一致
- [ ] 独立分析单位、n 和重复层级已定义或标记无法判断
- [ ] 关键结果映射到真实分析、数据和图表
- [ ] 多重比较、效应量、区间和软件/版本按适用性报告
- [ ] 未编造样本量、统计模型、p 值、实验参数或研究过程
- [ ] 相关、描述和个案未写成确定因果或普遍结论
- [ ] 图表含编号、标题、单位、范围、来源和必要统计说明
- [ ] 原始数据、处理数据、分析输出和正文主张有可追溯关系

## 写作与润色

- [ ] 先修复结构、论证和证据，再修复句子与格式
- [ ] 每段承担一个主要任务，主张、证据、解释、边界和连接完整
- [ ] 章节任务和语言策略匹配
- [ ] 改写未新增事实、数据、来源、结果或期刊规则
- [ ] 局部反馈没有触发无必要的全文重写
- [ ] 修改范围、保留内容、关键理由和待确认项已说明

## 期刊选择与首次投稿

- [ ] 候选期刊以官方范围和当前用户材料为依据
- [ ] 动态信息记录来源、核验日期和适用年份；未知项标待核验
- [ ] 未输出伪精确录用率、审稿周期、分区、费用或“保底”结论
- [ ] 题目、摘要、关键词、正文和投稿材料版本一致
- [ ] 作者、贡献、伦理、利益冲突、数据/代码和版权声明有真实依据
- [ ] 当前官方字数、格式、匿名和文件要求已核对或明确待核验

## 审稿回复

- [ ] 编辑要求和每条审稿意见有稳定 ID，未漏项或改变含义
- [ ] 行动、工作状态、完成证据、修改位置和就绪度分别记录
- [ ] 已写回复未被误标为实验、分析或稿件修改已完成
- [ ] 所有 `VERIFIED_DONE` 都有可检查产物
- [ ] 不可行或不同意的意见有证据、范围理由和替代动作
- [ ] 回复语气具体、尊重，不虚构行号、图号或编辑指令
- [ ] 无阻塞项和占位符时才标 `ready_to_submit`

## 引用、格式、答辩与安全

- [ ] 正文引文与参考文献双向对应
- [ ] 学校模板或期刊当前官方要求优先于通用规范
- [ ] 无法在当前环境核对的版式项目已明确说明
- [ ] 答辩与分享材料与论文结论一致并保留限制
- [ ] 未代写并隐瞒作者责任，未伪造研究过程、来源或审批
- [ ] 外部投稿、发送、上传、公开或覆盖文件仍需用户最终确认
- [ ] 本轮结果附 P0/P1/P2、状态、剩余风险和一个下一步
