# 可访问的可信学术来源

核验日期：2026-07-17

本清单只用于少量、必要的文献身份核验和开放全文定位。每次调用仍需检查当前响应、许可证和内容层级。访问失败时不更换为不明聚合站，不通过高频重试、登录绕过或反爬对抗继续获取。

## 默认可用来源

### Crossref REST API

- 官方入口：`https://api.crossref.org/works/{DOI}`
- 实测：无需 API Key 可返回已知 DOI 的结构化记录
- 可核验：题名、作者、DOI、期刊或出版社、日期、卷期页、许可和资源链接等注册元数据
- 不代表：已读取全文、已核对论文具体方法和结论
- 使用：已知 DOI 核验优先；按题名搜索只用于发现候选，需再核对 DOI 与出版页面
- 限制：部分字段由出版方提供，可能缺失或不一致；不要根据返回的全文链接推定链接一定可访问
- 风险：低，用于元数据；用于内容证据时为高风险

### Semantic Scholar Academic Graph API

- 官方入口：`https://api.semanticscholar.org/graph/v1/`
- 实测：单篇 DOI 查询无需 Key 成功返回题名、作者、年份、摘要、外部标识和开放 PDF 线索
- 可核验：论文身份、摘要、DOI、arXiv/PMID 等外部标识、引用网络和开放全文线索
- 不代表：摘要准确覆盖全文、开放链接的版权状态已最终确认
- 使用：Crossref 后的交叉核对、摘要线索和开放全文定位
- 限制：官方支持 `x-api-key`；无 Key 的速率限制未在接口文档中给出，失败或限流时立即降级，不连续重试
- 风险：中；模型生成的 TLDR、学科分类和影响指标不得作为论文事实

### arXiv API

- 官方入口：`https://export.arxiv.org/api/query?id_list={arxiv_id}`
- 实测：无需 Key 返回题名、作者、版本、摘要、分类和 PDF 链接
- 可核验：arXiv 预印本身份、版本、摘要和公开 PDF
- 不代表：同行评审状态、正式出版版本或最终结论
- 使用：计算机、数学、物理等学科的已知 arXiv ID 核验
- 限制：引用时标注预印本身份与版本；有正式出版版时优先核验 DOI 和出版页面
- 风险：中

### DOAJ API

- 官方入口：`https://doaj.org/api/search/articles/{query}`
- 实测：无需 Key 返回开放获取文章的题名、作者、DOI、期刊、摘要和全文链接
- 可核验：DOAJ 收录的开放获取期刊与文章元数据、开放全文线索
- 不代表：所有学科文献均收录、返回链接当前一定可下载
- 使用：开放获取期刊文章的补充核验
- 限制：需再检查文章页面和具体许可证
- 风险：低到中

### PubMed E-utilities

- 官方入口：`https://eutils.ncbi.nlm.nih.gov/entrez/eutils/`
- 实测：`esummary.fcgi?db=pubmed&id={PMID}&retmode=json` 无需 Key 返回题名、作者、期刊、卷期页、PMID、PMCID 和 DOI
- 可核验：生物医学论文身份与书目元数据
- 不代表：已获得全文或可据此检查全文方法和结果
- 使用：已知 PMID 或生物医学论文身份核验
- 限制：大量请求应遵守 NCBI 使用规则；本专家只做少量查询
- 风险：低，用于元数据

### PubMed Central 开放全文

- 官方入口：PMC 文章页及 NCBI BioC PMC OA 接口
- 实测：开放全文文章可通过 BioC JSON 返回题名、摘要、正文段落、图注、参考文献和许可证信息
- 可核验：属于 PMC 开放全文范围的文章正文
- 不代表：所有 PubMed 或 PMC 文章都允许同等方式复用
- 使用：已有 PMCID 且确认开放全文和许可证后，核对具体表述、章节和参考文献
- 限制：逐篇检查许可证；BioC 是结构化文本，不保留完整 PDF 版式，复杂公式和表格需回到原文核对
- 风险：低到中

## 条件可用来源

### OpenAlex API

- 官方入口：`https://api.openalex.org/`
- 实测：已知 DOI 查询当前成功返回作品、摘要倒排索引、开放获取状态和全文位置
- 官方要求：文档说明 API 免费但需要免费 API Key，并提供每日免费额度
- 使用：当前环境已有可用 Key 时，辅助交叉核验作品身份、开放获取状态和全文位置
- 默认规则：没有 Key 时不把 OpenAlex 作为必须依赖，不要求用户为了单次任务注册
- 风险：中

### DOI 落地页、出版社和期刊官网

- 可核验：最终出版页面、版本、勘误、许可、作者和期刊信息
- 限制：可能需要订阅、登录或机构权限；页面可见不等于全文可见
- 默认规则：遇到付费墙时停止，不尝试绕过；请用户通过学校图书馆合法获取并提供原文
- 风险：低，用于身份；无法读取正文时不可用于内容证据

## 不主动访问的来源

- 中国知网
- 万方数据
- 维普
- 需要学校统一身份认证、个人付费、验证码或机构网络的数据库
- 论文下载聚合站、网盘转载、来源不明镜像和搜索结果摘要

用户需要中文论文时，提供关键词、同义词、检索式、年份与学科筛选建议，请用户在本人有权使用的平台检索后提供以下任一材料：

- PDF 或可阅读全文
- 数据库导出的标准引用记录
- DOI、PMID、arXiv ID 或出版社稳定链接
- 题名页、摘要页、方法、结果和参考文献关键页面
- 学校图书馆的合法永久链接

## 内容使用等级

| 等级 | 当前拿到的内容 | 可以做 | 不可以做 |
|---|---|---|---|
| M1 | 可靠元数据 | 核验文献身份、格式化已有字段 | 写论文结论、引语、页码和方法细节 |
| M2 | 元数据与数据库原始摘要 | 转述摘要明确写出的研究目的、方法概况、结果或结论并标注“基于摘要” | 直接引语、页码、详细样本、方法细节、结果数值、作者限制和全文论证 |
| F | 可访问全文 | 在核对原文位置后做内容分析、译述和引文检查 | 超出原文、忽略版本与许可证 |
| U | 线索、搜索摘要或冲突记录 | 记录待核验、请用户补充 | 写入正式参考文献或正文事实 |

## 固定查询模板与字段记录

只在用户要求核验已知文献、当前任务确实需要且来源可访问时使用。所有占位符必须进行 URL 编码，不批量扩大搜索。

| 已知信息 | 首选查询 | 最少记录字段 |
|---|---|---|
| DOI | `https://api.crossref.org/works/{DOI}` | DOI、题名、作者、出版源、日期、卷期页、类型、许可、查询日期 |
| 题名 | Crossref 题名搜索，仅发现候选；再以 DOI 或出版页面复核 | 查询题名、候选 DOI、题名相似性、作者与年份冲突 |
| DOI / Semantic Scholar ID | `https://api.semanticscholar.org/graph/v1/paper/{ID}?fields=title,authors,year,abstract,externalIds,openAccessPdf,url` | 题名、作者、年份、摘要是否原始字段、外部标识、开放全文线索 |
| arXiv ID | `https://export.arxiv.org/api/query?id_list={arxiv_id}` | ID、版本、题名、作者、更新时间、摘要、分类、PDF 链接 |
| PMID | `https://eutils.ncbi.nlm.nih.gov/entrez/eutils/esummary.fcgi?db=pubmed&id={PMID}&retmode=json` | PMID、PMCID、DOI、题名、作者、期刊、卷期页、日期 |
| PMCID | PMC 文章页或 BioC PMC OA 接口 | 全文可见性、许可证、章节或段落位置、图表与参考文献范围 |

字段冲突时保留原始返回值并标记 U，不自行选择“看起来更合理”的版本。全文链接存在不等于全文已读取；只有实际取得并核对正文及版本后才能记为 F。

## 失效与重新核验

出现以下任一情况时，将来源状态降为“待重新核验”，本轮不沿用旧结论：

- 接口返回结构、认证要求、额度或许可证信息变化；
- 官方入口连续失败、限流或返回与既有记录冲突；
- 距上次核验超过 90 天且本轮需要依赖该来源执行查询；
- 用户任务需要比既有记录更高的内容等级，例如从 M1/M2 升到全文分析。

重新核验仍遵守少量查询和停止条件；不通过高频重试或切换到来源不明站点维持可用性。

## 固定降级规则

1. 先检查用户是否已提供可信原文、引用导出或稳定标识。
2. 已知 DOI 优先查 Crossref；按学科再用 Semantic Scholar、arXiv、DOAJ 或 PubMed/PMC 交叉核验。
3. 只得到元数据时停在 M1；只得到摘要时停在 M2，不升级为全文证据。
4. 连续两个可信开放来源无法确认身份，或任务需要原文但只有元数据/摘要时，停止继续搜索。
5. 告知用户缺少什么，并请用户提供可信材料；用户无法提供时跳过该文献或把相应段落改为待补证据的写作框架。
6. 不用模型记忆、相似题名、搜索摘要、二手博客或其他论文替代缺失来源。
