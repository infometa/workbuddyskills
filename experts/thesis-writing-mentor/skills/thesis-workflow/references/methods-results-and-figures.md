# 方法设计匹配

## 研究问题类型

先识别描述、比较、关联、解释、评估或设计问题，再识别人文文本、定性、定量、实验/准实验、工程设计、算法或综述方法域。

本模块默认检查“研究问题—方法—材料—分析—结论”是否一致，并辅助方法章节表达；不等同于覆盖所有学科的方法设计。

## 方法章节字段

- 研究设计与选择理由
- 对象、样本或语料范围
- 纳入与排除标准
- 数据来源和收集过程
- 变量、指标、编码或访谈框架
- 分析步骤、工具与版本
- 质量控制、可信度、效度或复现条件
- 伦理、隐私和授权
- 方法限制

只有用户提供学科背景、现实条件、导师要求或可信方法依据时才给具体方案。样本量、统计模型、量表效度、实验参数、专业软件和学科规范应给候选方案、适用条件和需确认项，不给伪精确结论。

涉及独立分析单位、重复层级、多重比较、效应量、区间、p 值、图注或结果主张时，进一步读取 `statistics-results-and-figures.md`。涉及执行过程、原始数据、异常和批次追踪时，读取 `research-execution-and-data-traceability.md`。

## 图表呈现自查

先读取学校模板；下列为无明确校规时的检查框架，不替代学科规范。

| 检查项 | 自查规则 |
|---|---|
| 编号 | 统一采用学校要求的连续编号或分章编号，例如 `图 1-1`、`表 3-2`；编号不得跳号、重复，正文交叉引用与题注一致 |
| 题注位置 | 通常图题置于图下，表题置于表上；学校另有规定时从其规定 |
| 标题内容 | 题注应能独立说明对象、范围或条件，避免只有“结果图”“数据表”等空标题 |
| 来源 | 非作者自制图表标出可核验来源；改绘或据某来源整理时如实写明，不把改绘写成原创 |
| 单位 | 数值列、坐标轴或表头明确单位；整表同一单位可集中标注，不同单位分别标注 |
| 图注/表注 | 缩写、符号、显著性标记、样本口径、误差线含义和必要的数据处理在注释中说明 |
| 清晰度 | 轴名、图例、线型和数据标签可辨；不依赖颜色作为唯一编码，黑白打印仍可区分 |
| 字体字号 | 图内字体与正文及学校模板协调，中文、英文、数字和符号体例一致；最终以实际版面可读性人工复核 |
| 跨页表 | 优先避免拆断关键行；跨页时重复表头，按学校要求添加“续表”，不得遗漏题注或单位 |
| 版面 | 图表尽量在正文首次引用之后就近出现；不超出版心，不用截图替代可编辑表格来掩盖格式问题 |
| 数据一致性 | 图表值、正文值、统计输出、单位、小数位和样本口径一致；修改数据后同步更新题注与主张 |

输出逐条使用“符合/不符合/无法核验/不适用”，并给出证据位置。纯文本或未见版面时，不断言题注位置、字体、跨页和清晰度符合。

## 问卷设计规范

### 量表与构念

- 从研究问题和概念定义出发列出构念，不为凑题量增加无关维度。
- 优先使用有明确来源、适用人群、语言版本和使用条件的成熟量表；记录原作者、版本、翻译/回译、授权要求及改动。
- 改写、删减、拼接量表时，明确改动理由和可能影响，不再把修改版直接宣称为原量表。
- 自编题项应给出构念—维度—题项映射，并请导师或领域人员审阅内容覆盖。

### 题项与选项

- 每题只测一个意思，避免双重问题、双重否定、绝对化词语、专业黑话和暗示“正确答案”的措辞。
- 明确时间范围、行为对象和判断口径，如有必要提供“不适用/不知道/不愿回答”。
- 类别选项应尽量互斥且穷尽；有序选项保持方向一致；数值区间不得重叠或断档。
- 量表锚点、计分方向和呈现顺序保持清晰；反向题仅在有方法依据时使用，并记录反向编码。
- 人口学与敏感题只收集研究所必需的信息，说明匿名、用途、保存与退出机制。

### 预调研

1. 先做理解性检查：请目标人群说明其如何理解题意、选项和作答过程。
2. 再进行小规模预调研，记录招募方式、完成时间、漏答、极端集中、选项失效、开放反馈和技术问题。
3. 根据预调研证据修订题项，并保存版本号、修改理由和受影响构念；正式调研后不得为迎合结果静默改题。
4. 涉及人体参与者、未成年人或敏感数据时，在预调研前确认伦理、知情同意与授权要求。

### 信效度与数据字段

至少保留以下真实字段，未完成分析时只列计划，不预填结果：

| 类别 | 字段 |
|---|---|
| 量表身份 | 构念、维度、量表来源、版本、语言、授权、改动说明 |
| 题项字典 | 题项 ID、题干、选项/锚点、计分方向、反向编码、所属维度 |
| 样本与过程 | 目标总体、抽样框、招募方式、纳排标准、回收与有效判定规则、缺失处理 |
| 预调研 | 版本、对象特征、反馈、删改题项、删改理由 |
| 信度 | 采用的指标、计算对象、软件/版本、输出位置、结果与解释边界 |
| 效度 | 内容效度依据、结构效度方案、聚合/区分或效标效度所需变量、输出位置、结果与解释边界 |
| 可追溯性 | 原始数据 ID、清洗规则、分析脚本/操作记录、表图 ID、支持主张 |

不能只凭某个阈值宣称量表“可靠有效”；需结合构念、样本、模型假设、指标适用性和实际输出解释。统计细节进一步读取 `statistics-results-and-figures.md`。

## 半结构化访谈提纲

### 开场

- 说明研究者身份、研究目的、预计流程、录音/记录方式、保密与匿名安排、数据用途、退出权利和联系方式。
- 在需要时取得书面或明确记录的知情同意；未授权不得录音或公开可识别引语。
- 用中性暖场问题确认参与者理解，不暗示期望结论。

### 主问题

- 主问题按研究问题分组，每个问题聚焦一个经验、过程、判断或事件。
- 优先使用开放、非评价性措辞，例如“请描述一次……的经历”“当时发生了什么”“你如何理解……”。
- 区分参与者亲历、听闻和推测；涉及时间、角色和情境时请求具体化，但不替参与者下结论。

### 追问

可使用“能否举例”“当时你做了什么”“还有其他情况吗”“你所说的 X 指什么”“哪些条件使它不同”等澄清、细化、对比和反例追问。避免诱导式问题，如“这个系统是不是明显提高了效率”；改为“这个系统对效率有什么影响？也可能没有影响，请说明具体经历”。

### 收尾

- 询问是否有遗漏、是否需要更正前述内容、是否允许后续联系和引用匿名化片段。
- 重申数据处理方式和退出/撤回边界，感谢参与；不承诺研究结论或个体收益。
- 访谈后记录访谈 ID、提纲版本、日期、情境、授权状态、录音/转写位置、异常和研究者反思。

## 样本量边界

样本量只给决策原则，不给脱离研究设计的固定数字、保证性区间或伪精确结论。需综合研究问题、总体与抽样框、分析单位、变量数量、预期分析方法及其假设、效应与不确定性、非响应/脱落、资源、伦理和学科惯例；定量研究优先依据预先的功效或精度分析，定性研究依据样本信息丰富度、异质性、分析深度和主题饱和记录。缺少这些信息时，输出待确认字段，并建议由导师或方法专家确定。
