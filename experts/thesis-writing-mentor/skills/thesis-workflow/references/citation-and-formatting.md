# 引用、参考文献与格式检查

## 适用顺序

1. 用户提供的学校模板、学院细则和导师明确要求
2. 用户指定的引用标准与版本
3. 通用标准示例

学校要求缺失时提供暂定格式，并标记“需按学校模板核对”。

## 引用完整性

检查：

- 正文每条引文是否在参考文献表中
- 参考文献表条目是否在正文中实际引用
- 作者、年份、题名、来源、卷期、页码、DOI 或 URL 是否来自可核验元数据
- 直接引语是否有页码、段落或可定位信息
- 转述是否准确反映原文，不扩大结论
- 二手引用是否按适用规范标识
- 同一来源的作者名和年份是否一致

## 常见标准

- GB/T 7714：先确认学校要求的版本及顺序编码制或著者—出版年制
- APA：先确认版本，常见为第 7 版
- MLA：先确认版本，常见为第 9 版
- Chicago：先确认注释书目制或作者日期制

不得凭记忆补齐看似合理的作者、年份、题名、卷期、页码和 DOI。M1 元数据只用于核对身份与已有字段；没有可靠元数据时不生成完整参考文献。用户无法提供可信来源时，删除该条或保留“待补来源”占位，不用相似论文替代。

## 格式检查清单

- 封面、声明、摘要、关键词和目录
- 标题层级、编号、字体、字号、行距和段前段后
- 页眉、页脚、页码、分节和奇偶页
- 图表编号、题注、来源、单位和跨页处理
- 公式编号、变量体例和符号说明
- 脚注、尾注、附录和致谢
- 正文引用与参考文献
- 中英文标点、空格、全半角和专有名词

只对用户提供或工具实际读取的页面下结论。纯文本环境无法核对字号、边距、分页和题注位置时，提供检查项并说明需在排版软件中复核。

## 输出

- 引用对应异常表
- 元数据待核验表
- 参考文献格式修订稿
- 学校模板差异清单
- 排版软件中的逐项操作建议

## GB/T 7714—2015 著录模板

先确认学校是否采用 GB/T 7714—2015、顺序编码制还是著者—出版年制，以及学校是否有对标点、责任者数量、文献类型标识、电子资源引用日期等作出的本校细化要求。**学校模板、学院细则和导师明确要求具有最高优先级。**

下列模板用于字段组织，不替代标准原文或学校模板。示例中的人名、题名、机构、号码和网址均为格式演示占位，不是真实来源，不得直接放入论文。字段缺失时写入待补表，禁止猜测补齐。

| 类型 | 格式模板（顺序编码制示意） | 演示示例 | 必查字段 |
|---|---|---|---|
| 期刊文章 | `[序号] 主要责任者. 题名[J]. 刊名, 年, 卷(期): 起止页码.` | `[1] 张某, 李某. 本科生学习行为研究[J]. 某教育研究, 2024, 12(3): 15-24.` | 作者、题名、刊名、年、卷、期、页码；有 DOI 时核对 DOI |
| 专著 | `[序号] 主要责任者. 书名[M]. 版本项. 出版地: 出版者, 出版年: 引用页码.` | `[2] 王某. 社会调查方法[M]. 2版. 某地: 某出版社, 2023: 45-52.` | 作者/编者、书名、版本、出版地、出版者、出版年；按学校要求决定是否列引用页码 |
| 学位论文 | `[序号] 主要责任者. 题名[D]. 保存地: 保存单位, 年.` | `[3] 陈某. 大学生数字学习体验研究[D]. 某地: 某大学, 2024.` | 作者、题名、文献类型、城市/保存地、授予或保存单位、年份 |
| 会议论文 | `[序号] 析出文献责任者. 析出题名[C]//论文集责任者. 论文集名. 出版地: 出版者, 出版年: 起止页码.` | `[4] 赵某. 混合教学评价框架[C]//某学会. 某教育技术会议论文集. 某地: 某出版社, 2023: 88-94.` | 论文作者与题名、会议/论文集名、编者或主办者、出版项、年份、页码；缺失项待补 |
| 电子文献 | `[序号] 主要责任者. 题名[EB/OL]. (更新或发表日期)[引用日期]. 获取和访问路径.` | `[5] 某机构. 某数据使用说明[EB/OL]. (2024-03-01)[2026-08-10]. https://example.invalid/item.` | 责任者、题名、载体标识、更新/发表日期、引用日期、稳定 URL；示例网址不可使用 |
| 标准 | `[序号] 主要责任者. 标准名称: 标准号[S]. 出版地: 出版者, 出版年.` | `[6] 某标准化机构. 某信息描述规范: XX/T 0000—2024[S]. 某地: 某出版社, 2024.` | 标准责任者、标准名称、标准号、出版地、出版者、年份 |
| 专利 | `[序号] 专利申请者或所有者. 专利题名: 专利号[P]. 公告或公开日期.` | `[7] 李某. 一种教学数据处理方法: CN000000000A[P]. 2024-01-01.` | 申请者/所有者、专利题名、国家/地区与专利号、文献类型、公告/公开日期 |

处理不完整条目时按以下顺序执行：识别文献类型 → 逐字段核对用户材料和可信元数据 → 输出“已有字段/缺失字段/冲突字段/可信来源” → 仅格式化已核验字段。缺作者、题名、来源、年份等关键字段时，不交付伪完整条目，使用 `[待补：字段名]` 或放入元数据待核验表。

## 学校模板核对工作流

1. **确认效力与版本**：记录学校、学院、专业、届别、文件名称、生效日期和导师补充要求；冲突时请用户确认适用文件。
2. **提取要求**：逐项提取封面字段、原创性/授权声明、摘要与关键词、目录、标题层级、字体字号、行距与段距、页边距、页眉页脚、页码、图表编号与题注、公式、脚注、参考文献体例、附录和装订/提交要求。
3. **建立核对卡**：调用 `output-templates.md` 的“学校模板核对卡”，每项记录模板原文位置、当前稿件状态、差距、Word 操作路径和人工复核项。
4. **分级处理**：影响提交、声明、目录、页码或引用体例的冲突列 P0/P1；纯视觉微调列 P2。先处理全局样式与分节，再处理局部格式。
5. **逐项验证**：只对实际读取的页面或用户确认的信息标“符合”；纯文本无法核验的项目标“需在 Word 人工复核”。
6. **模板不可读**：不猜测要求，输出要素提取清单，请用户转述或提供可复制文字、清晰截图、可读取的 PDF/Word 文件。
7. **交付**：输出差异摘要、学校模板核对卡、格式逐项操作卡和仍需作者/教务确认的问题。

## 本科论文高频格式错误对照

菜单名称以用户当前 Word 版本为准；批量修改前先保留副本。若学校模板另有规定，以学校模板为准。

| # | 错误示例 | 正确做法 | Word 基本操作路径 |
|---|---|---|---|
| 1 | 用空格和多次回车“推”出封面位置 | 用段落、制表位、表格或学校封面模板定位，不用空白字符模拟布局 | `开始 → 段落` 调整间距；必要时 `插入 → 表格` 后隐藏边框 |
| 2 | 各章标题手工改字号，外观相同但没有层级 | 将一级、二级、三级标题分别绑定统一样式 | `开始 → 样式 → 标题 1/2/3 → 修改` |
| 3 | 标题编号逐条手输，增删章节后序号错乱 | 使用与标题样式关联的多级列表 | `开始 → 多级列表 → 定义新的多级列表 → 将级别链接到标题样式` |
| 4 | 目录靠手敲标题和页码，页码变化后未更新 | 使用标题样式生成自动目录，定稿前更新整个目录 | `引用 → 目录 → 自动目录`；右键目录 `更新域 → 更新整个目录` |
| 5 | 前置部分和正文页码连续且格式相同，不符合学校要求 | 在前置部分与正文之间插入分节符，分别设置页码格式和起始值 | `布局 → 分隔符 → 分节符（下一页）`；`插入 → 页码 → 设置页码格式` |
| 6 | 改后一节页眉时前一节也同步改变 | 先分节，再关闭“链接到前一节”，分别设置页眉页脚 | 双击页眉/页脚 → `页眉和页脚 → 链接到前一节` 取消 |
| 7 | 中文摘要后写“关键词:”且数量、分隔符和字体不符合模板 | 按学校规定统一中英文摘要标题、关键词标签、数量、分隔符与格式 | 选中文本后 `开始 → 字体/段落`；将标签样式统一，逐项人工核对 |
| 8 | 图题放在图上方，表题放在表下方，编号手写 | 通常图题在下、表题在上；使用题注并按学校要求选择章节编号 | 选中图/表 → `引用 → 插入题注`；`编号 → 包含章节号` |
| 9 | 图表编号与正文引用不一致，如正文写“下图” | 使用交叉引用引用图表编号，增删后统一更新域 | `引用 → 交叉引用 → 引用类型：图/表`；`Ctrl+A → F9` 更新域 |
| 10 | 跨页表第二页没有续表标识或重复表头 | 按学校规则设置重复标题行；需“续表”时拆分并明确标识，避免一行被跨页拆开 | 选中表头 → `表格布局 → 重复标题行`；`表格属性 → 行 → 取消允许跨页断行` |
| 11 | 正文中文标点混用英文逗号句号，括号和空格全半角混乱 | 中文语境使用学校规定的中文全角标点；英文、公式、代码按相应规则 | `开始 → 替换` 分项查找；每次替换先预览，不全局盲替 |
| 12 | 参考文献用空格对齐，换行后第二行顶格 | 按学校规定设置悬挂缩进，不用空格模拟 | 选中文献 → `开始 → 段落` 对话框 → `特殊格式：悬挂` |
| 13 | 用回车控制分页，前文修改后章节首行漂移 | 章节起始使用分页符或标题样式的“段前分页” | `插入 → 分页`，或 `段落 → 换行和分页 → 段前分页` |
| 14 | 页边距、纸张大小和装订线沿用 Word 默认值 | 按学校模板统一设置纸张、页边距、装订线和方向 | `布局 → 大小/页边距 → 自定义页边距` |
| 15 | 公式、图、表、参考文献序号直接键入，修改后不同步 | 对需自动更新的对象使用题注、编号和交叉引用；定稿前更新域并人工复核 | `引用 → 插入题注/交叉引用`；`Ctrl+A → F9` 后检查目录、图表和引文 |

## LaTeX 场景边界

LaTeX 用户以学校提供的类文件、模板和实际编译结果为准。本专家仅提供 GB/T 7714 字段规则、引用完整性和内容层建议，不处理模板编译、宏包冲突、字体、分页、构建环境或排版故障；此类问题转交熟悉该模板的技术支持或电脑操作顾问。
