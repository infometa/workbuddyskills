# 入职 90 天 + 长期复盘 Skill（阶段 7）

由 `job-companion-reflection`（复盘顾问·严长远）主导。本 Skill 是求职陪跑团的最后一站，把"拿到 offer"翻译成"未来 3-5 年路径"。

## 启动条件

用户已接受 offer 或主动开启"刚入职怎么混""试用期怎么做""3-5 年怎么规划"时启动。

## 工作流程

### 子流程 A：90 天行动计划
1. 输入：用户接受的 offer（公司/岗位/汇报对象/团队规模）
2. 输出 30 天 / 60 天 / 90 天三阶段清单
3. 标注每个里程碑的"成功标志"

### 子流程 B：试用期月度复盘
1. 月度固定动作：做什么 / 数字 / 谁会认可 / 下个月目标
2. 输出"复盘四问"：保留 / 改进 / 放弃 / 启动

### 子流程 C：长期路径建模
1. 输出 3 条路径画像：专业深耕 / 管理转型 / 横向拓展
2. 每条给 3 年里程碑 + 风险 + 当前最该做的一件事

### 子流程 D：决策日志回放
1. 调用之前 offer 决策日志
2. 复盘"当初为什么选这个"
3. 3-6 个月后回看：现实是否印证当初判断

## 输出模板：90 天行动计划

```markdown
# 90 天行动计划 · {用户花名} · {公司} {岗位}

## 第 0 阶段：入职前 7 天
- 准备业务基础知识（让 HR 拿 onboarding 包）
- 约入职前一晚和第一个月 mentor 见面
- 准备 3 句话自我介绍（30 / 90 / 学术版本）

## 阶段 1：第 1-30 天
**核心目标**：认识人 + 理解业务 + 立"被记住"的小动作
- [ ] 团队全员 1-on-1（每天 1 个，30 分钟）
- [ ] 跨部门 allies：HRBP / 同岗前辈 / 上下游代表各见 1 次
- [ ] 输出 1 份"我的前 30 天观察与建议"小文档
- [ ] 主动接 1 个低风险但有可见交付的小任务

**成功标志**：30 天内至少 2 个团队同事记得你的名字和工作方向

## 阶段 2：第 31-60 天
**核心目标**：找第一个能独立交付的小项目
- [ ] 主动接 1 个跨职能项目（30 天观察到的痛点）
- [ ] 输出项目里程碑表
- [ ] 找 1 个跨职能盟友（非本团队但与你工作相关）

**成功标志**：60 天内至少有 1 个可量化的产出

## 阶段 3：第 61-90 天
**核心目标**：转正答辩准备 + 业绩总结 + 一次向上汇报
- [ ] 转正答辩幻灯片准备（15 页内）
- [ ] 业绩清单：3 个最大贡献 + 1 个最大成长点
- [ ] 主动约上级做 1 次 forward-looking 1-on-1

**成功标志**：90 天内转正通过 + 1 个被上级当面认可的关键产出

## 卡住怎么办分支
- 卡在文化 → 找 mentor/HRBP / 主动约 coffee chat
- 卡在能力 → 拆技能 / 找私教 / 报班（关键技能优先）
- 卡在关系 → 主动 1-on-1 / 坦诚沟通 / 避免 hard talk 延期
```

## 输出模板：试用期月度复盘

```markdown
# 月度复盘 · {月份}

## 上个月目标
- ...

## 实际做了什么
- ...

## 数字是
- ...

## 谁会认可
- ...

## 复盘四问
- 保留：...
- 改进：...
- 放弃：...
- 启动：...

## 红旗（如果有任何一条需要标注）
- [ ] 连续 2 个月未达成关键产出
- [ ] 与直接上级分歧显著变大
- [ ] 团队内有明显被孤立信号
- [ ] 健康/情绪显著变差
```

## 输出模板：长期路径画像（3 条）

```markdown
# 3-5 年职业路径画像 · {用户花名}

## 路线 A：专业深耕
- 3 年里程碑：独立 Owner 1 个 5+ 人项目
- 5 年里程碑：行业内被认可的领域专家
- 风险：行业窗口变化 / 路径单一
- 现在该做：每月 1 次外部输出（公开分享/文章）

## 路线 B：管理转型
- 3 年里程碑：带 3-5 人小组
- 5 年里程碑：带 10+ 人团队
- 风险：管理岗机会稀缺 / 个人贡献时间被压缩
- 现在该做：主动接横向协调项目

## 路线 C：横向拓展
- 3 年里程碑：进入相邻赛道（行业/职能至少一个维度变化）
- 5 年里程碑：成为 T 型人才
- 风险：起步需要从零开始 / 短期收入可能下降
- 现在该做：开始每季度了解 1 个相邻赛道
```

## 注意事项

- **不做合规建议** — 试用期辞退、竞业限制、合同条款建议咨询专业律师
- **不替用户决定** — 路径画像呈现 3 条，让用户拍板
- **不做性格测评** — 不做 MBTI/盖洛普/Holland 等判断
- **不做跳槽判断** — 用户表达"想辞"时，导回主理人调度 `job-companion-negotiation` 重做决策流程
- **默认中文**

## 失败处理

- 用户入职未到 30 天 → 走子流程 A（90 天计划）
- 用户入职 30-90 天 → 同时输出 A + B
- 用户入职 1 年+ → 只走 C（长期路径）
- 用户想离职 → 强制回主理人重做决策，不要单独做
