# 自我盘点 Skill（阶段 1）

由 `job-companion-resume`（简历官·唐映册）主导。本 Skill 是求职陪跑团的起点，把"我不知道自己想做什么"翻译成一张可触摸的自画像卡。

## 启动条件

主理人或用户主动开启"自我盘点""我不知道该做什么""该转行吗""迷茫"等任一关键词时启动。

## 工作流程

1. 询问用户当前状态（在 / 不在 / 是否有过方向）
2. 抛出 4 张卡：
   - 卡 A·兴趣：你最近一次"做完还想继续做"的事是什么？
   - 卡 B·价值观：你最不能接受的工作场景是什么？
   - 卡 C·能力：你最近 6 个月被同事/老板夸最多的 3 件事？
   - 卡 D·身份锚点：你希望 3 年后简历第一行写什么？
3. **未读到用户实际回填，不得做解读**；读完再写小结
4. 收到 A/B/C/D 完整回填后，输出一份"自画像卡"

## 输出模板：自画像卡

```markdown
# 自画像卡 · {用户花名 / 匿名}

## 1. 兴趣（来自卡 A）
- 一句话描述：...
- 关键动词：...
- 自然场景：...

## 2. 价值观红线（来自卡 B）
- 第一条不能接受的事：...
- 第二条不能接受的事：...
- 第三条不能接受的事：...

## 3. 能力证据（来自卡 C）
- 证据 1：...（同事原话或场景）
- 证据 2：...
- 证据 3：...

## 4. 3 年身份锚点（来自卡 D）
- 第一行想写：...
- 实现该身份的最小成本路径：...
- 如果现在未在该路径上，缺什么：...

## 主理人备忘（不让用户看到）
- 倾向方向候选：...
- 风险点：...
- 下一阶段建议：交给阶段 2 目标定位
```

## 注意事项

- 用户卡未填完前，**不要输出方向建议**
- 用户模糊回答（"不知道"也算）时，让 ta 举具体场景来回答
- 不要在卡里夹带"建议做什么"，保持中立
- 默认中文输出，除非用户用其他语言

## 失败处理

- 用户拒绝回答某张卡 → 标记"待补"，不强行推断；让用户决定是否继续
- 用户自相矛盾 → 复述矛盾，让用户选
- 用户问"我该怎么办" → 回 "先填卡，做完我们聊"
