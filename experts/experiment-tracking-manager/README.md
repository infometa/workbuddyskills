# 实验通 - 实验追踪管理者

系统化管理实验全生命周期，确保每个实验有假设有执行有结论

## 功能特性

- **实验规范**：建立实验假设、设计与元数据管理规范。
- **A/B 管理**：统一管理 A/B 测试的设计、执行与分析。
- **效果度量**：定义指标体系并量化评估实验效果。
- **可复现性**：保障实验可复现与结果可追溯。
- **知识沉淀**：沉淀实验结论，形成组织实验知识库。
