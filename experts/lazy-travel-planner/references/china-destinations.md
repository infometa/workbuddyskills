## 一、按主题分组

### 自然风光主线
- **庐山**（江西九江）：5-10 月最佳；雾天概率高；五老峰 / 三叠泉 / 芦林湖
- **黄山**（安徽）：4-10 月；冬季雾凇但封山概率高；前山光明顶 / 后山始信峰
- **张家界 + 凤凰**（湖南）：3-11 月；雨季 6-8 月有阻挡风险；天门山玻璃栈道（怕高慎入）
- **九寨沟**（四川阿坝）：5-10 月；旺季 9-10 月；地震后部分线路调整
- **稻城亚丁**（四川甘孜）：5-6 / 9-11 月；高反；牛奶海 / 五色海徒步重
- **林芝桃花**（西藏）：3 月底 4 月初；进藏 7 日游核心
- **三亚**（海南）：10 月-次年 4 月；夏季多台风
- **大理 + 丽江**（云南）：3-10 月；冬季偶有雪线封路
- **青海湖 + 茶卡盐湖**：6-9 月；油菜花 7 月；环湖自驾

### 古城文化主线
- **西安**：四季皆可；春秋最佳；兵马俑 / 城墙 / 大雁塔 / 回民街（避雷洒金桥替代）
- **平遥**（山西）：春秋；和云冈石窟、五台山可串
- **婺源**（江西）：3 月底 4 月油菜花；秋季篁岭晒秋；其他时段一般
- **凤凰古城**（湖南）：春秋；夜景为主
- **苏州 + 杭州**：3-5 / 9-11；桂花季（中秋前后）；西湖太热门
- **泉州**（福建）：春秋；非遗火爆；近年挤
- **北京**：春秋；故宫必预约；夏季暴热避开

### 城市深度
- **上海**：四季；外滩 / 武康路 / 思南路 / 1933
- **广州**：秋冬；早茶文化 + 沙面 + 永庆坊
- **成都**：春秋；熊猫基地早起；本地玉林路替代宽窄巷子
- **重庆**：春秋；山城步道 + 江景；夏季 40℃ 慎入
- **长沙**：春秋；湖南菜 + 文和友 + 橘子洲
- **厦门**：春秋；鼓浪屿要预约

## 三、避坑常识（v1.0 已沉淀进 risk_knowledge.json，这里只放总纲）

详见 `data/risk_knowledge.json`。本文件只补充**目的地相关**的高阶建议：

- 山岳类：必查雷雨预报，雨天封山概率高，索道也会停
- 海岛类：7-9 月查台风路径
- 高原类：海拔 > 3000m 全部需要 24 小时缓冲
- 古城类：清明 / 五一 / 国庆人爆炸，建议提前避开
- 边境类：办证/通行证/边防证（如墨脱 / 阿里 / 新疆部分县）
