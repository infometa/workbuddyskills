# Transport Tips · 火车 / 飞机 / 打车实战经验

> 兜底知识，transport-plan 在主源失败时引用。

## 一、高铁

### 抢票节奏
- 普通日：提前 7 天稳
- 节假日：12306 放票时间错峰，0:00 / 6:00 / 6:30 / 7:00 / 7:30 / 12:00 / 13:00 等都有
- 抢不到：候补 + 同方向不同始发站 + 改签策略

### 座位选择
- 二等座 ABC + DF 靠窗；一等座 AC + DF 靠窗；商务座 ACF
- 长途选靠窗+插座侧；带娃选靠走廊（方便去厕所）
- 避开车厢两头（颠簸大）+ 餐车隔壁（人流大）

### 改签 / 退票
- 开车前 8 天以上：免费退
- 8 天-48 小时：5%
- 48-24 小时：10%
- 24 小时内：20%
- 改签免费且可降低损失（用不上的票优先改签到便宜车次）

### 中转技巧
- 跨线接续 30 分钟内有保底机制
- 大站换乘比小站快（北京西 / 南京南 / 杭州东等）
- 行李件数 >2 件 → 至少留 45 分钟缓冲

## 二、飞机

### 比价
- 携程 / 飞猪 / 去哪儿 三家交叉
- 国际段试 Skyscanner / Google Flights
- 信用卡里程 + 联程值得算账

### 选位
- 经济舱：太平出口 + 舱前几排腿空间大
- 前轮上方 + 翼上：颠簸最小
- 长途选 11A / 11K 类（有些机型该排紧急出口腿无限）

### 退改
- 经济舱越便宜越严苛（变更费高）
- 提前一周改签 vs 当日改签：差价可能 ≥ 票价
- 黑卡 / 联名卡 / 高级会员能减免

## 三、打车 / 网约车

### 防黑车
- 机场只走官方排队点（注意"出租车"和"网约车"分流）
- 上车第一句问"打表吗"
- 不打表 / 价格离谱 / 路线绕远 → 拍车牌投诉 12345
- 一线城市出租车基本规范，三四线 + 旅游城市要小心

### 网约车
- 滴滴覆盖最广，机场专车排队稍长但稳
- 三四线城市晚上 22 点后等车 30 分钟正常
- 高峰打车价 = 平时 1.5-2 倍

### 共享单车 / 滑板
- 一线城市覆盖全；三四线少
- 古城内地形复杂，建议步行
- 雨雪天不要骑

## 四、自驾

### 免费高速
- 春节 / 清明 / 五一 / 国庆共 4 个免费时段（小型客车）
- 国庆首日 + 末日返程必堵

### 限行
- 上海 / 广州 / 深圳 / 北京 / 成都 等多市有外地车限行
- 出发前查"{城市} 限行 + 出发月份" 最新规则
- 节假日大部分城市暂停限行（但要核实）

### 加油 / 充电
- 高速服务区充电桩偶有占用，导航前看"小桔充电 / 特来电"等 App 实况
- 油车在三四线选中石化 / 中石油（少踩雷）

### 异地还车
- 一嗨 / 神州 / 携程异地还车费 100-500 不等
- 飞猪整车租赁有时比单租便宜

## 五、行李规则

| 模式 | 免费托运 | 手提行李 |
|---|---|---|
| 国内经济舱 | 20kg | 5kg + 20×40×55cm |
| 国际经济舱 | 23kg×1-2 件 | 7kg |
| 高铁二等座 | 20kg + 体积 130cm 以内 3 边和 | 同 |
| 国际邮政（带娃带宠） | 单查规则 | — |

## 六、行李丢失 / 延误

- 飞机：到达后立即去航司柜台办丢失登记，留下托运凭条副本
- 高铁：到站后立即找站台值班员，超过 3 小时找派出所
- 一律拍照所有内容物 + 行李箱外观（值钱物品另留照片）
- 电脑 / 相机 / 贵重物品：永远不要托运
