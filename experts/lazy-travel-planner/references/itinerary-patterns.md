# Itinerary Patterns · 行程编排模板（节奏 / 主题 / 单日骨架）

> 给 itinerary-optimize 提供"模板形状"。脚本是骨头，本文是肉。
> 不要在脚本里硬编码这些模板 — 脚本只编时间轴，模板规则放这里。

---

## 一、三种节奏的单日模板

### Walker Intense（暴走打卡）· 每日上限 5 个景点

```
07:30-08:30  早餐（街边小吃，快速）
09:00-11:00  景点 A（文化大类，2 小时）
11:00-12:30  景点 B（轻量，1.5 小时）
12:30-13:30  午餐（路边面馆 / 当地小吃）
14:00-16:00  景点 C（户外，2 小时）
16:00-17:30  景点 D（轻量，1.5 小时）
18:00-19:30  晚餐（正餐 / 网红店）
20:00-22:00  夜间活动（夜市 / 灯光秀 / 酒吧）
```

总步数 ≈ 25,000-30,000 步 / 体力指数 0.85+

### Normal（正常游览）· 每日 3-4 个景点

```
08:00-09:30  早餐 + 起床（不要赶）
10:00-12:00  景点 A（重头，2 小时）
12:00-13:30  午餐（讲究的本地店）
14:00-15:30  休整 / 咖啡 / 短逛
15:30-17:30  景点 B（中等强度，2 小时）
18:00-19:30  晚餐（正餐）
20:00-22:00  可选夜活动（不强求）
```

总步数 ≈ 15,000-20,000 步 / 体力指数 0.5-0.7

### Relaxed（慢游躺平）· 每日 1-2 个景点

```
09:30-11:00  早餐 + 早咖啡
11:00-13:00  景点 A（精挑，深度体验，2 小时）
13:00-15:00  长午餐（1.5h+ 当地正餐）
15:00-17:30  自由时间 / 咖啡馆 / 小店逛
18:00-20:00  晚餐 + 散步
20:00 后    随意
```

总步数 ≈ 8,000-12,000 步 / 体力指数 0.3-0.5

## 二、四种主题的"骨架"

### 文化深度型
- D1：大型博物馆/博物院（半日）+ 老城步行（半日）
- D2：历史街区 + 名人故居 / 故居改造的咖啡店
- D3：周边古镇 / 文化遗址 一日游

### 自然风光型
- D1：核心山岳 / 湖泊（重点景区 1 天）
- D2：周边小景 / 徒步线 / 拍照点
- D3：温泉 / 度假村休整 + 城区返程

### 美食打卡型
- D1：早餐街 + 中午本地老店 + 晚上正餐 + 夜市
- D2：菜市场 + 网红打卡店 + 米其林 / 黑珍珠
- D3：地道苍蝇馆子 + 手作店 / 茶馆 + 散步

### 拍照出片型
- D1：天际线机位（高视角）+ 古建筑 + 网红打卡
- D2：日出/日落机位（早出晚归）+ 中午城内
- D3：自然/人文小众点 + 棚拍/民俗服饰体验

## 三、关键约束

### 时间窗
- 博物馆类：周一闭馆（多数）
- 大型景区：营业 8/9 点开始，建议早到避人流
- 网红店：避开节假日午餐 12:00-13:30 / 晚餐 19:00 高峰
- 夜市：20:00 后人最多

### 体力分配
- D1：刚到达，预留 1 小时调整
- 末日：返程当天景点减半，留出去机场/火车站时间
- 中段：体力自由发挥，但不要连续 3 天暴走

### 餐厅类型搭配
- 1 天：1 顿正餐 + 2 顿轻餐（小吃 / 面食）
- 不要连续 2 顿网红（排队累 + 不饿）
- 留 1 顿"附近随便吃"（应对突发情况）

## 四、跨城接续的"折损"日

每次换城市那天：
- 上午：办退房 + 大交通（80% 时间消耗）
- 下午：到达 + 入住 + 周边轻活动
- 晚上：开新城

**这一天景点能塞的最多 1 个**，不要硬塞。

---

## 五、备选方案规则

最终 itinerary 必须有 backup_pool：

| 场景 | 备选 |
|---|---|
| 下雨 | 室内大型景点 / 博物馆 / 商场 / 茶馆 |
| 体力不支 | 缩短一天 / 换休整日 |
| 多出半天 | 周边 1-2h 车程的小众点 |
| 必去景点闭馆 | 同类目第 2 选项 |

## 六、用户偏好的"硬规则"

| profile 字段 | 模板调整 |
|---|---|
| `physical.no_long_walk` | 单日 max 步数 < 12000 |
| `physical.fear_of_heights` | 排除塔类 / 玻璃栈道 / 高空缆车 |
| `physical.no_high_altitude` | 排除海拔 > 2000m POI |
| `tastes.scene_dislikes` 含 "long_queue" | est_queue_min > 30 全部排除 |
| `constraints.must_have_starbucks_or_equivalent` | 每天至少 1 个咖啡 slot |
| `tastes.scene_likes` 含 "photo" | 每天加 1 个拍照机位 |
