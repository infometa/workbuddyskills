# 输出模板

## 使用原则

根据当前阶段只选一个层级，不同时堆叠全部模板：

- **简版**：信息不足、用户焦虑、救急入口或只需马上开始。
- **标准版**：信息基本充分的初次规划、七天安排或日常执行。
- **展开版**：用户明确要求完整方案，或多科、多阶段确实需要覆盖清单和状态表。

所有任务预计时长之和不得超过净容量。暂定信息标记“待确认”。

## 一、简版入口

```markdown
## 先做什么
- 当前判断：规划 / 执行 / 复盘 / 修复 / 收口
- 主要风险：
- 现在先做：
- 预计时长：
- 完成标准：

## 只补一个信息
- 请回复：
```

适合“下周考试，救救我”这类信息很少的请求。不得在信息不足时生成伪精确长期计划。

## 二、标准版初次规划

```markdown
# 备考方案｜计划 v1

## 结论与风险
- 推荐模式：学期 / 冲刺 / 救急
- 当前主攻：
- 排序依据：
- 每日总时间 / 净容量：
- 主要风险：
- 待确认：

## 阶段安排
| 阶段 | 目标 | 任务范围 | 完成标准 | 时间 |
|---|---|---|---|---|

## 未来七天
| 日期 | A 类任务 | B 类任务 | 复习或验证 | 预计总时长 |
|---|---|---|---|---|

## 今天先做
- 任务 ID：
- 动作与对象：
- 预计时长：
- 完成标准：
- 完成后回复：任务 ID｜完成度｜掌握度｜实际耗时｜卡点
```

信息不足或用户只要求今天安排时，不强制输出阶段安排和未来七天。

## 三、今日任务

```markdown
# 今日备考任务｜计划 vN

- 总可用时间：
- 预留缓冲：
- 净容量：
- 今日主目标：

## A 类｜必须优先
- [ ] 任务 ID：
  - 动作与对象：
  - 预计时长：
  - 完成标准：
  - 所需资料：

## B 类｜完成后有明确增益
- [ ] 任务 ID：
  - 动作与对象：
  - 预计时长：
  - 完成标准：

## C 类｜时间允许再做
- [ ] 任务 ID：
  - 动作与对象：
  - 预计时长：
  - 完成标准：

## 今日收口
- 主动回忆或自测：
- 打卡格式：任务 ID｜完成度｜掌握度｜实际耗时｜卡点
```

没有 B 或 C 类任务时省略对应章节，不为填满模板制造任务。

## 四、每日复盘与差异

```markdown
# 每日复盘｜计划 vN → vN+1

## 结论
- 今日状态：按计划 / 部分偏离 / 需要重排
- 触发原因：
- 明日最优先：

## 执行与掌握
- 已完成：
- 部分完成：
- 已验证掌握：
- 仍未验证或新增弱项：
- 预计与实际耗时差异：

## 计划变化
- 保留：
- 后移：
- 删除：
- 替换：
- 新增：
- 变化原因：

## 下一步
- 明日 A 类任务：
- 完成后回复：任务 ID｜完成度｜掌握度｜实际耗时｜卡点
```

没有实质重排时保持原版本，并把标题写为“计划 vN 复盘”。

## 六、展开版覆盖清单

仅在用户明确需要完整规划或多科状态管理时使用。

| 科目 | 章节 | 知识点 | 范围依据 | 权重 | 掌握 | 估时 | 状态 | 下一步 |
|---|---|---|---|---|---|---|---|---|
| 示例 | 第一章 | 核心概念 | 用户提供：老师范围 | 高 | 模糊 | 30 分钟 | 待复习 | 讲解后独立完成 5 道专项题 |

## 七、下轮状态摘要

在没有持久化文件时附在形成计划或重排后的回复末尾：

```markdown
【下轮状态摘要｜计划 vN】
- 考试与日期：
- 每日净容量：
- 当前主攻：
- 今日任务 ID：
- 已验证掌握：
- 待确认：
- 下次反馈：任务 ID｜完成度｜掌握度｜实际耗时｜卡点
```
