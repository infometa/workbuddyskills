---
name: layer2-policy-event-brief
description: "当用户问具体政策事件、官方会议表态或监管动向时——如'这次降准对市场意味着什么''最近重要会议释放了什么信号''这个行业政策变化影响哪些方向'。侧重政府/监管发布的具体政策解读；宏观国际风险只在有明确公开事件证据时做有限背景说明。"
---

Use when:
- 需要解读降息、降准、货币政策、财政政策等金融政策事件
- 需要解读重要官方会议、政策文件、监管表态
- 需要回答“这个政策意味着什么”“对哪些方向影响更大”
- 对应场景：
  - 央行降息 / 降准或其他金融政策事件
  - 重要官方会议指引
  - 行业政策颁布 / 变化
  - 近期消息面意义及影响

Not for:
- 不要把它写成纯宏观数据综述
- 不要在没有政策文本或新闻支撑时硬写政策结论
- 不要直接推导成个股推荐或短线交易建议
- 用户可见输出必须保留政策/新闻来源、时间窗口和影响边界；本技能仅做公开信息整理，非投资建议，不输出买入、卖出、目标价或个股推荐。

Depends on:
- `layer1-doc-search`
- `layer1-fin-data`
- `layer1-fin-graph`

Workflow:
1. 先调用政策/新闻相关检索工具，确认事件本身、发布时间和核心表述。
2. 如果用户问“最近”“当前”“这次”，优先使用 `search_events` 或 `search_hot_news` 获取近 `7-30` 天公开信息，不要先凭常识复述政策。
3. 只有在政策影响确实依赖宏观金融变量时，才补 `1-2` 个相关宏观指标或市场数据工具作为背景。
4. 如果涉及明确行业方向，再调用图谱或行业相关工具补充行业框架；不要在行业不明确时默认展开图谱。
5. 如果用户问“影响哪些产业链环节”“是否真催化”“事件怎么传导”，必须补传导链路，不要只写新闻摘要：
   - 事件本身和已确认表述
   - 直接影响对象：需求、供给、价格、库存、成本、政策约束或融资条件
   - 二阶传导对象：上游 / 中游 / 下游、替代技术、竞争格局或资本开支
   - 受益 / 承压方向的证据强弱
   - 后续验证指标和可能证伪信号
6. 如果用户问“历史相似事件”“事件后走势”“有没有回测”，读取 `layer1-doc-search/references/announcements-events.md`，优先调用 `aggregate_similar_event_backtest`；主窗口使用 3/5/7/20 日，`20d` 标注为“约 1 个月 / 20 个交易日”。只有用户明确问 3 个月或长周期验证时，再显式请求 `60d` 并标注为“约 3 个月 / 60 个交易日”。不要因为 60d 缺失丢弃普通 3/5/7/20 日有效样本。
7. 输出时明确区分：
   - 政策说了什么
   - 为什么市场在意
   - 影响如何传导
   - 影响更大的资产 / 行业 / 风险点
   - 当前仍需继续跟踪什么

Output structure:
- `policy_core`
- `market_focus`
- `affected_areas`
- `follow_up_points`
- `brief_summary`

Rules:
- 先复述政策核心，再解释影响，不要直接跳到主观结论。
- 对政策影响要区分“短期情绪影响”和“中期基本面影响”。
- 事件解读不能只覆盖 `1-2` 天新闻。若证据主要集中在短窗口，应明确它更像“新闻催化观察”，并列出缺少哪些中期验证证据。
- 涉及行业主题时必须输出“事件 -> 直接机制 -> 二阶传导 -> 相关行业/标的 -> 待验证变量”；无法建立链路时要明确写“传导链路证据不足”。
- 历史相似事件和回测统计只能来自 `aggregate_similar_event_backtest`、`get_event_backtest` 或已取证材料；不要自行编造相似度、胜率、均值收益或样本数。
- 如果用户问“最近/当前/这次”，至少要有 `1` 条近期事件或新闻证据，缺少时不要把回答写成“近期已确认发生的政策事实”。
- 不要默认调用全量宏观面板；只补和这次政策最相关的 `1-2` 个数据点或市场反应。
- 如果已经拿到政策事件和热点新闻，不要再对同一关键词重复做多轮泛搜索。
- 如果没有足够公开信息，不要编政策细则。
- 默认从市场、行业、资产框架解释，不要主动引导到单一个股。
- 面向客户时，先一句人话讲清”这事对市场大概偏什么方向”，再补两句原因；不要写成政策纪要或事件点评报告。
- 少用”传导路径、预期差、情绪面、基本面修复”等报告腔；尽量改成客户一听就懂的说法。
- 除非用户明确要细节，不要罗列多条政策原文或时间线；默认只保留最关键的 `1-2` 个点。
- 落点是”这件事您现在先怎么理解、接下来重点看什么”，不要停留在政策知识讲解。

Examples:
- `这次降准对市场意味着什么`
- `最近的重要会议释放了什么信号`
- `这个行业政策变化主要影响哪些方向`
