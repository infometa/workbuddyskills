name: layer2-announcement-brief
description: "当用户询问某条公告的内容或含义时——如'帮我看一下这条股权激励公告''腾亚精工最近公告说了什么''这条业绩预告主要说了什么'。必须先获取公告原文再展开分析，不是泛新闻或研报综述。"
---

Use when:
- 需要解读一条公告对公司的含义
- 需要围绕公告补充公司近期背景
- 需要做财报季、激励、减持、回购、业绩预告类的快速解读
- 典型场景：
  - 公司定期报告 / 预告 / 业绩修正
  - 利润分配类公告
  - 股权交易类公告
  - 资产重组 / 并购类公告
  - 重大合同 / 项目类公告
  - 股权激励 / 员工持股计划类公告

Not for:
- 不要在没有获取到真实公告时，仅凭新闻或研报代替公告内容直接作答
- 不要把公告解读当成策略推荐入口，只做信息整合，不做买卖指令
- 不要用于非公告类的市场分析（用 `layer2-stock-brief` 或 `layer2-industry-brief`）
- 用户可见输出必须保留公告来源、时间和证据边界；本技能仅做公开信息整理，非投资建议，不输出买入、卖出、目标价或个股推荐。

Depends on:
- `layer1-doc-search`
- `layer1-fin-data`

Workflow:
1. 先调用 `search_announcements` 找到目标公告。
   - 港股公司要先说明当前公告源以巨潮资讯为主、不包含港交所披露易原生公告；检索为空时停止公告解读，不得推断公司没有公告。
2. 调用 `get_document` 获取公告正文或摘要。
3. 优先识别公告类型，例如：
   - 业绩类
   - 分红送转类
   - 再融资类
   - 增减持 / 回购类
   - 并购重组类
   - 合同项目类
   - 管理层与治理类
4. 如果用户问的是“最近公告/业绩预告/业绩修正/财报主要说了什么”，先把公告本身讲清楚，再决定是否补其他来源，不要一上来扩成泛新闻综述。
5. 调用 `search_events` 查找同类结构化事件。
6. 调用 `get_security_profile` 与 `get_latest_snapshot` 补充公司背景和市场表现。
7. 如公告较重要，再调用 `search_research_reports` 看是否已有研报或点评；公司级研报必须使用已确认的 `company` 和/或 `ticker` 做 scoped search，不要只把公司名放进 `query` 后配长时间窗。
8. 输出“公告解读摘要”。

Output structure:
- `announcement_core`
- `announcement_type`
- `related_events`
- `market_context`
- `related_research`
- `brief_summary`

Rules:
- 公告原文只摘关键点，不要整段照搬。
- 优先说明：
  - 公告是什么类型
  - 发生了什么
  - 时间点
  - 是否有后续事件或市场反馈
- 如果问题核心是“公告主要说了什么”，至少要先拿到一条真实公告，再展开解读；不要仅凭新闻或研报代替公告本身。
- 对财报、业绩预告、业绩修正类问题，优先从公告中提炼核心数字变化、原因解释、同比/环比方向，再补一句市场或行业背景。
- 如果用户没有指定公告类型，优先返回最近信息密度高、影响大的公告，而不是机械按时间堆叠。
- 如果是财报、业绩预告、分红、回购、减持、重组等典型高频问题，要主动把公告类型写在标题或开头。
- 如果 scoped 公司级研报检索成功但结果为空，不要硬补观点。
- 如果研报检索返回 `INVALID_BROAD_TIME_RANGE`、`MISSING_RESEARCH_FILTERS` 或其他参数/范围错误，这是调用参数问题，不是“没有研报”；先用 `company`/`ticker` 重试，只有 scoped 检索成功且结果为空，才说明暂无命中。
- 不要在公告未确认前，直接写“近期业绩如何”“管理层怎么看”“机构怎么看”这类二手结论。
- 不要把原始公告全文、HTML/JSON 样式正文、内部文档主键或 `virtual_table` 暴露给用户。
- 如果只拿到公告摘录，也要明确说明“以下为摘要/节选”，不要伪装成完整法律文本。
- 港股公告空结果只能表述为“当前公告源未覆盖或未命中”，不能表述为“公司没有公告”；需要港交所原文时应说明当前能力缺口。

Suggested output template:
1. 公告核心内容
2. 公告类型与常见含义
3. 公司近期背景与市场表现
4. 是否已有配套新闻 / 研报
5. 一句话总结

Examples:
- `帮我看一下这条股权激励公告`
- `腾亚精工最近的公告值不值得关注`
- `这条业绩预告主要说了什么`
