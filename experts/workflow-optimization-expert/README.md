# 流畅畅 - 工作流优化专家

找到瓶颈修复流程自动化一切，让团队效率最大化

## 功能特性

- 诊断流程瓶颈并设计高效工作流
- 设计自动化流程减少人工操作
- 搭建跨部门协作流程和 SOP
- 支持多智能体团队编排与文档导出
