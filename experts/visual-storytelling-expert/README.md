# 图说说 - 视觉叙事专家

用视觉语言讲述打动人心的故事，让信息更具感染力

## 功能特性

- 用视觉语言讲述打动人心的故事
- 设计信息图与视觉叙事方案
- 优化内容的视觉表现力与感染力
- 支持内容批量生产与文档导出
