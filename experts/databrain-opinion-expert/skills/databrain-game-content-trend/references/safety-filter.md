# 安全过滤规则

内容推荐前必须经过安全过滤。有疑虑时宁可不推荐。

---

## 硬过滤（直接剔除，不输出）

以下类型内容无论热度多高，一律不推荐：

| 类型 | 判断标准 |
|------|---------|
| 政治敏感 | 涉及选举、政府批评、地缘政治冲突、台湾/西藏/新疆相关 |
| 宗教争议 | 对宗教的嘲讽/攻击，或宗教极端主义内容 |
| 种族歧视 | 含有歧视性语言、刻板印象攻击 |
| 性/色情 | 任何程度的露骨内容 |
| 暴力血腥 | 真实暴力事件记录（游戏暴力画面不在此范围） |
| 品牌危机 | 发帖方正处于公关危机期（抵制、造假丑闻等） |
| 过时内容 | 发布超过5天且 `growth_24h < 0`（热度下降） |

---

## 软过滤（标注风险，由运营决定是否使用）

以下类型内容可以推荐，但必须附加 `⚠️ 风险提示`：

| 类型 | 风险提示示例 |
|------|------------|
| 争议性社会话题 | "⚠️ 该话题在XX地区存在立场分歧，建议评估本地团队意见后决策" |
| 竞品敏感话题 | "⚠️ 该热点已与竞品形成强绑定，跟进可能引发对比讨论" |
| 版权不明音乐/素材 | "⚠️ 视频使用的背景音乐版权状态不明，素材借鉴前需确认授权" |
| 昙花一现热点 | "⚠️ 该热点增速已开始放缓，建议评估制作周期是否来得及" |
| 未成年人相关 | "⚠️ 视频主角为未成年人，官号互动需谨慎避免误解" |
| 平台规则灰色地带 | "⚠️ 该类内容形式在部分地区平台存在限流风险" |

---

## 竞品判断逻辑

基于以下字段综合判断视频发帖方身份：

**判断为游戏官号的信号**：
- `anchor_name` 包含已知游戏名称
- `description`（来自 `marketing_hub_kol_info` 表）包含 "official"、"官方"、"game"、"studio" 等词
- `video_title` 包含游戏版本号、活动名称、下载引导

**判断为游戏 KOL 的信号**：
- `description`（来自 `marketing_hub_kol_info` 表）包含 "gamer"、"gaming"、"player"、"主播"、"攻略" 等词
- 历史发帖以游戏内容为主（如有历史数据）

**无法确定时**：不标注，避免误判。

---

## 地区敏感词快查

以下地区需要额外谨慎：

| 地区 | 额外注意事项 |
|------|------------|
| 中东 / MENA | 宗教节日（斋月等）期间内容适配；服装/行为规范 |
| 韩国 | 历史/政治话题极易引发舆论；本地游戏竞争敏感 |
| 日本 | 知识产权保护意识强，素材仿制要谨慎 |
| 东南亚 | 各国差异大，不能用统一标准；部分国家政治敏感 |
| 德国/欧洲 | GDPR 数据隐私；部分游戏内容（暴力/纳粹符号）有法律限制 |

---

## 端内落地风险评估

对所有端内资源建议（动作/皮肤/BGM/活动），必须额外进行以下专项风险评估。

### 风险类型总览

| 风险类型 | 评估内容 | 标注方式 |
|---------|---------|---------|
| 版权风险 | 舞蹈编排版权、音乐授权、IP 所有权 | `⚠️ 版权：{具体说明}` |
| 宗教/文化风险 | 宗教符号、文化挪用争议、地区差异 | `⚠️ 文化：{具体说明}` |
| 平台合规 | 各平台对特定内容的限流/禁止规则 | `⚠️ 合规：{具体说明}` |
| 时效风险 | 梗的生命周期 vs 端内开发周期是否对得上 | `⚠️ 时效：预计梗热度剩余X天，端内上线可能滞后` |

### 硬过滤（绝不做，无论热度多高）

以下内容**严禁**作为端内资源的参考来源：

- **宗教仪式动作**：刀马舞（Dabke，部分变体含宗教仪式意义）、苏菲旋转舞（Sufi whirling）、佛教/印度教仪式手势等
- **有公开版权诉讼的编舞**：如已有编舞师公开维权的 TikTok 舞蹈（例：Renegade 编舞争议）
- **政治符号/手势**：任何可被解读为政治立场表达的手势或动作
- **真人肖像直接复制**：将真人面部特征直接做成游戏角色皮肤

### 软过滤（需法务/本地团队确认后方可推进）

以下内容可以建议，但**必须**标注风险并注明需要的确认流程：

| 场景 | 需确认事项 | 标注示例 |
|------|-----------|---------|
| 知名编舞家的舞蹈 | 联系编舞方确认授权意愿和费用 | `⚠️ 版权：需联系编舞方 {名字} 确认授权` |
| 热门歌曲改编为 BGM | 确认音乐版权方、授权范围（游戏内使用 vs 仅社媒） | `⚠️ 版权：需确认音乐授权，版权方为 {厂牌}` |
| 地区性文化符号 | 由该地区本地运营团队评审是否存在文化挪用争议 | `⚠️ 文化：需 {地区} 本地团队评审` |
| 真人肖像参考 | 确认肖像权、避免过度相似 | `⚠️ 肖像权：参考了 {人物}，需确认肖像授权` |
| 热度周期短的梗 | 评估端内开发周期（通常 2-4 周）是否来得及 | `⚠️ 时效：梗已热 {N} 天，端内开发周期约 {M} 周` |
