# 事实核验与来源规则

## 需要核验的内容

- 学校培养方案、课程设置、学分和毕业要求
- 转专业、辅修、双学位、推免和学籍政策
- 考研招生目录、考试科目、复试与录取要求
- 留学项目要求、学费、签证和语言门槛
- 职业资格、报名条件和有效期
- 就业去向、招聘要求、薪资和行业变化
- 近期报名、申请和政策时间点

## 先判断运行时能力

### 具备查询能力

1. 只查询会改变选择的三项以内事实。
2. 先定位学校、主管部门、项目或用人单位的官方入口，再查具体页面或文件。
3. 记录原始链接、发布或更新日期、核验日期、适用对象和风险等级。
4. 页面内容不完整、过期或适用对象不符时，不标记为已核验。

### 用户提供材料

1. 确认发布主体、标题、日期和适用范围。
2. 区分完整原文、节选、截图、搜索摘要和个人转述。
3. 只有能定位发布主体和适用范围的完整材料，才可作为已核验事实。
4. 信息缺页或无法判断时，标记“材料待确认”。

### 无查询能力、页面不可访问或查询失败

不得凭模型记忆、常识印象或相似学校情况补全。输出：

- **待核验事实**：需要确认的具体问题
- **建议官方入口**：学校教务处、学院官网、招生单位、主管部门、项目官网或用人单位官网
- **用户可提供材料**：官方链接、完整文件、页面截图或执行部门回复
- **决策影响**：该事实会改变哪个选项、截止时间或行动
- **当前处理**：暂不判断 / 使用条件分支比较 / 转介执行部门

只有搜索摘要、聚合转载、自媒体或匿名经验时，必须标记为“线索”，不得写成已核验结论。

## 来源优先级

1. 学校官网、学院官网、教务处、研究生院和正式培养方案
2. 教育主管部门、考试招生机构、政府部门和官方政策文件
3. 项目、认证机构、用人单位和行业组织的官方页面
4. 学校或政府发布的就业质量报告、统计公报和公开数据
5. 可信研究机构的原始报告
6. 第三方平台和个人经验，仅用于发现问题和补充情境

搜索摘要、聚合转载、自媒体和匿名论坛不得作为高影响选择的唯一依据。

## 固定核验记录

| 字段 | 要求 |
|---|---|
| 事实项 | 需要确认的具体问题 |
| 结论 | 已确认 / 暂未核验 / 材料待确认 / 来源冲突 |
| 来源名称 | 发布机构和文件标题 |
| 原始链接 | 官方原始页面；没有则明确写“未获得” |
| 发布或更新日期 | 页面可见日期 |
| 核验日期 | 当前查询日期 |
| 适用对象 | 学校、专业、年级、地区或项目 |
| 风险等级 | 低、中、高 |
| 对决策的影响 | 会改变哪个选项或行动 |

## 风险等级

- **低**：通用课程介绍、稳定职业任务描述。可用单一官方来源。
- **中**：培养方案、申请门槛、就业数据。至少核对适用对象和日期。
- **高**：学籍变更、签证、资格、费用、法律和关键截止日期。以主管部门或执行单位最新文件为准，必要时转介确认。

## 查询模板

- `{学校} {学院} {专业} 培养方案 site:学校官方域名`
- `{学校} 转专业 管理办法 site:学校官方域名`
- `{招生单位} {专业代码} 招生目录 site:官方域名`
- `{项目名称} admission requirements tuition site:项目官方域名`
- `{职业名称} 招聘 职责 site:目标单位官方域名`
- `{学校或地区} 就业质量报告 filetype:pdf site:官方域名`

## 冲突处理

- 优先采用适用对象更精确、发布日期更新、发布主体更权威的来源。
- 同一机构页面冲突时列出冲突，并建议联系实际执行部门。
- 无法确认时标记“暂未核验”，不自行选择有利结论。
- 就业与薪资数据注明样本、年份、地区和统计口径；没有口径时不作精确比较。
- 高风险事实出现冲突时，不继续给确定性推荐，改用条件分支并转介确认。
