# 结构化自我盘点

## 盘点维度

### 兴趣线索

记录用户愿意主动投入、持续关注或完成后仍想深入的具体活动。区分喜欢结果、喜欢过程、喜欢环境和喜欢被认可。

### 能力证据

记录课程、项目、比赛、社团、实习和日常任务中的可观察表现。优先使用作品、结果、反馈、持续进步和独立完成情况。

### 价值排序

从成长、稳定、收入、影响力、自主、创造、合作、生活节奏、地域和安全感中选出当前最重要的两至四项。遇到冲突时要求用户明确取舍。

### 工作偏好

记录用户更适应的任务类型、协作方式、反馈周期、结构程度、表达方式和压力环境。用具体情境描述，不使用人格定型。

### 现实约束

记录时间、经济、学籍、成绩、家庭责任、健康、地域、语言、资格门槛和可用资源。区分硬约束、可协商约束和暂定假设。

## 证据卡

| 字段 | 内容 |
|---|---|
| 具体经历 | 发生了什么 |
| 用户承担的任务 | 实际做了什么 |
| 可观察结果 | 作品、成绩、反馈或完成情况 |
| 主观体验 | 哪部分有投入感、疲惫或排斥 |
| 支持的方向 | 这项经历支持哪些候选 |
| 反证或限制 | 哪些现象削弱候选 |
| 证据强度 | 强、中、弱 |
| 待验证问题 | 下一步还要确认什么 |

## 追问顺序

1. 请用户描述一项最近真实发生的经历。
2. 询问用户具体承担了什么任务。
3. 询问哪部分最投入、最困难、最想继续或最想避开。
4. 询问是否有结果、反馈或重复出现的表现。
5. 将线索映射到候选方向并保留反证。

一次只问一个问题。用户已有清晰选项时不强制完成全量盘点。

## 使用测评结果

- 用户提供霍兰德、MBTI、优势测评或学校测评时，记录其结果和测评日期。
- 将结果转化为待验证假设，不直接生成职业结论。
- 使用真实课程、项目、实习和协作经历交叉核验。
- 结果与现实经历冲突时，保留冲突并设计验证行动。
- 不声称自制问卷具有信度、效度、常模或诊断能力。
