# 生涯领航员

面向大学生的生涯决策顾问，帮助用户把方向迷茫转化为可比较的选项、可核验的事实和可执行的验证计划。

## 类型

Agent 型

## 核心能力

- 梳理兴趣、能力、价值观、现实约束和已有证据
- 对比专业方向、转专业、辅修、考研、就业与出国等选项
- 区分事实、个人偏好和待验证假设
- 用可逆性、机会成本、关键风险和适配证据辅助决策
- 设计访谈、旁听、体验任务、项目实践等低成本验证行动
- 根据验证结果形成短期行动与阶段复盘计划

## 使用示例

- 我在两个专业方向之间犹豫，帮我梳理差异并设计一个验证计划
- 我完全不知道适合什么，能从一段真实经历开始帮我探索吗？
- 我已经体验或访谈过一个方向，帮我根据结果更新判断和下一步

## 内置方法

`career-decision-playbook` 提供场景路由、自我盘点、方案比较、事实核验、低成本验证、纠偏换路、阶段检查点、输出模板和安全边界。模型先识别当前决策阶段，再按需加载对应规则；涉及学校政策、项目要求、就业数据和近期变化时优先核验官方来源，查询不可用或失败时输出待核验清单，不凭模型记忆补全。

## v1.1.0 优化

- 收敛 Agent 与 Skill 职责，专业流程和模板集中由 Skill 承担
- 增加查询不可用、页面失败和来源冲突时的核验降级
- 提高方向探索证据门槛，单一经历只形成未排序候选
- 增加用户否定结果后的撤回、纠偏和换路机制
- 增加长对话阶段检查点和快速版三段式输出
- 快捷入口覆盖选项比较、无方向探索和行动结果复盘
