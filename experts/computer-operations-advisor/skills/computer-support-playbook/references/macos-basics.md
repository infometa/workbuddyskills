# macOS 基础排障

- 资料类型：官方资料摘要 + 专家经验规则
- 官方入口：https://support.apple.com/zh-cn/mac
- 使用手册：https://support.apple.com/zh-cn/guide/mac-help/welcome/mac
- 适用范围：Apple 当前支持的 macOS 与 Apple 芯片、Intel Mac
- 来源访问核验：2026-07-17
- 内容状态：通用分流已整理；启动、诊断、恢复和固件步骤必须按芯片与系统版本核验
- 风险等级：查看状态为低；恢复、抹掉磁盘、固件操作为高

## 先确认

- `苹果菜单 > 关于本机`：机型、芯片、macOS 版本
- `系统信息`：准确型号标识、存储、硬件和外设信息
- Apple 芯片还是 Intel 处理器
- 问题是否发生在系统更新、软件安装、权限变更或外设接入之后

## 卡顿与高占用

1. 打开活动监视器，查看 CPU、内存、能耗和磁盘占用。
2. 确认异常进程属于哪个应用，不结束不认识的系统进程。
3. 检查启动磁盘剩余空间、系统更新和登录项。
4. 先退出异常应用，再重启 Mac。
5. 清理个人文件、移除登录项或卸载应用前进入授权流程。

## 网络异常

1. 判断所有网络还是单个网络、所有设备还是单台 Mac。
2. 关闭再开启 Wi-Fi，重新选择网络并检查校园认证页面。
3. 检查 VPN、代理、描述文件和日期时间。
4. 删除网络、移除描述文件或更改 DNS 前说明影响并确认。

## 软件无法打开

1. 确认软件来源、版本、macOS 要求和芯片架构。
2. 记录系统提示全文，区分安全拦截、权限、损坏、兼容或服务异常。
3. 优先更新软件并查开发者官方兼容说明。
4. 不指导绕过 Gatekeeper 或关闭系统完整性保护作为常规方案。

## 音频、摄像头与外设

1. 在系统设置中确认输入、输出和应用权限。
2. 断开并重新连接，检查接口、线缆、供电和转换器。
3. Apple 芯片和 Intel Mac 的启动、诊断与恢复流程不同，必须按机型核验。
4. 固件、扩展和专用驱动只使用设备厂商官方来源。

## 启动与恢复

- 先确认 Apple 芯片或 Intel Mac，再提供安全模式、Apple Diagnostics 或恢复模式步骤。
- FileVault 恢复密钥、Apple 账户和重要数据状态必须先确认。
- 抹掉磁盘、重新安装 macOS、恢复备份和固件恢复属于高风险操作，逐项授权。
- 进液、异常发热、电池鼓包、无法供电或硬件诊断报错时转 Apple 或授权服务商。
