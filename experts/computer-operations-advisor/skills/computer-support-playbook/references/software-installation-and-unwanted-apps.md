## 安装前规则

1. 先确认用户真正需要的功能，不因为“必装软件清单”重复安装同类工具。
2. 优先顺序：系统内置功能 → 系统应用商店或学校正版平台 → 软件开发者官网。
3. 搜索软件时先确认官网域名，不直接点击带“广告”“推广”标记的下载结果。
4. 拒绝聚合下载站、所谓高速下载器、破解站、网盘转存和弹窗中的“立即更新”。
5. 安装前检查软件名称、发布者、数字签名、适用系统和版本；无法确认发布者时停止安装。
6. 选择自定义安装时逐页查看勾选项，取消无关软件、浏览器插件、首页、搜索引擎、默认应用和开机启动授权。
7. 不要求用户为了安装而关闭 Windows 安全中心、SmartScreen、macOS Gatekeeper 或浏览器安全浏览。
8. 免费下载不等于免费使用。推荐前说明核心功能是否收费、是否试用、是否带广告和是否需要账号。

## 基础软件推荐原则

- ZIP 压缩和解压优先使用 Windows 或 macOS 内置功能。
- 需要 7z、RAR 等更多格式时，可推荐 7-Zip 官网 `https://www.7-zip.org/`；不要把带捆绑、广告或强制会员的解压软件作为默认推荐。
- PDF 阅读优先使用系统浏览器或软件厂商官方阅读器。
- 浏览器、办公、会议、显卡、打印机和外设软件从产品官网、官方应用商店或学校正版平台获取。
- 同类软件通常推荐一个主选项和一个备选项，说明免费功能和限制，不堆叠安装多个管家、杀毒、驱动或优化工具。

## 现象分流

| 现象 | 首查来源 |
|---|---|
| 只在某个网页内出现广告 | 网页内容、弹出窗口权限 |
| 右下角出现浏览器图标通知 | 网站通知权限 |
| 浏览器首页、搜索或新标签页被改 | 扩展、浏览器设置、第三方软件 |
| 桌面定时弹出独立广告窗口 | 已安装应用、后台进程、启动项 |
| 开机自动运行陌生软件 | Windows 启动应用、Mac 登录项、软件自身设置 |
| 文件双击后被陌生软件打开 | 系统默认应用关联 |
| 已卸载但仍持续出现 | 残留组件、计划任务、服务或另一个关联软件；需进一步核验 |
| 安全软件提示 PUA | 查看检测名称、路径、来源和保护历史，再选择处置动作 |

## 处置流程

### 1. 记录与定位

- 让用户截取完整弹窗，包括标题栏、图标、任务栏图标和出现时间。
- 确认广告只在浏览器内、系统通知区域还是独立程序窗口出现。
- 询问最近安装或更新的软件、下载来源及是否勾选过附加选项。
- 用户要求本地检查时，可在说明范围后读取启动项、最近安装应用和 PUA 防护状态；不自动修改。

### 2. 浏览器侧

- 检查首页、启动页、新标签页、默认搜索引擎和未知扩展。
- 检查网站通知、弹出窗口和重定向权限，撤销不认识网站的允许项。
- 先单独禁用可疑扩展验证，不一次移除全部扩展。
- 浏览器重置会影响启动页、搜索引擎、网站权限和扩展状态；执行前说明影响并取得确认。
- 如果设置修改后又自动恢复，说明系统中可能仍有第三方软件，不反复重置浏览器。

### 3. 系统侧

- 在 Windows `设置 > 应用 > 已安装的应用` 中按安装日期查看最近软件；在 macOS 检查“应用程序”文件夹。
- 在 Windows `设置 > 应用 > 启动` 或任务管理器“启动应用”检查自启动；在 macOS 检查登录项与后台项目。
- 核实软件发布者、安装日期、来源和用户是否需要，再决定保留、禁用或卸载。
- 优先使用系统“已安装的应用”或软件自带卸载程序，不直接删除安装目录。
- 恢复默认应用通过系统设置完成，不用注册表脚本或第三方“修复工具”。

### 4. 安全扫描

- Windows 优先使用 Windows 安全中心的病毒和威胁防护、保护历史及基于信誉的 PUA 防护。
- Microsoft 说明 PUA 可能导致变慢、非预期广告或安装其他软件；检测后仅被阻止不等于已移除，需要用户选择动作。
- macOS 优先更新系统、重启、检查不需要的应用和 Safari 扩展；持续异常时联系 Apple 支持或可信维修服务。
- 不同时安装多个常驻杀毒、管家、驱动和优化工具，避免冲突与新的捆绑。

## 本地执行授权

以下动作默认先指导用户自行完成：

- 卸载软件
- 禁用启动项或后台项目
- 移除浏览器扩展
- 撤销网站通知权限
- 重置浏览器
- 恢复默认应用
- 对 PUA 执行隔离、删除或允许

用户明确要求代执行时，逐项列出对象、发布者、来源、动作、影响和恢复方式。对象无法确认、涉及学校管理软件、远程考试软件、安全软件或系统组件时停止并转管理员。

## 禁止做法

- 不按“助手、管家、优化、Update、Helper”等名称关键词批量删除。
- 不把未知发布者自动判为恶意，也不因有数字签名就自动判为安全。
- 不先修改注册表、组策略、Hosts、任务计划或系统服务。
- 不直接删除程序文件夹代替卸载。
- 不推荐来源不明的专杀、弹窗拦截、驱动、清理和优化工具。
- 不把正常网站广告、系统通知和恶意广告软件混为一类。
