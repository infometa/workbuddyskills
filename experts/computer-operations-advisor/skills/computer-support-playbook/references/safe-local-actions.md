# 本地操作授权规则

- 资料类型：专家风险控制规则
- 设计依据：最小权限、知情同意、可撤销操作、个人文件保护和诊断数据最少化
- 适用范围：本地 Agent 对用户设备执行检查和修改
- 整理日期：2026-07-17
- 风险等级：按 L0 至 L4 分级

## 风险等级

| 等级 | 操作 | 默认行为 |
|---|---|---|
| L0 | 解释概念、提供步骤 | 直接回答 |
| L1 | 查看版本、状态、日志、目录清单 | 说明检查范围后执行 |
| L2 | 禁用启动项、撤销网站通知、恢复默认应用、禁用扩展、可撤销设置修改 | 先给用户自行操作步骤；代执行需明确确认 |
| L3 | 安装卸载、移除扩展、重置浏览器、隔离 PUA、移动覆盖文件、驱动和账号配置 | 备份并逐项确认后执行 |
| L4 | 删除个人文件、注册表、分区、格式化、重装、固件、恢复出厂 | 默认不代执行；确有必要时单独警示并再次确认 |

## 授权规则

以下表达只代表请求指导：

- “怎么修”
- “如何处理”
- “帮我看看是什么问题”
- “给我一个解决方案”

以下表达可以进入代执行确认流程：

- “由你执行这些步骤”
- “直接帮我修改这个配置”
- “按刚才列出的方案执行”

宽泛的“全部帮我修好”不授权 L3 或 L4 操作。

## 执行前清单

必须向用户列明：

1. 操作对象和完整路径或配置项。
2. 将执行的动作。
3. 预期效果和验证方法。
4. 可能中断的应用、网络或系统。
5. 备份位置和恢复步骤。
6. 无法完全撤销的影响。

## 个人文件与批量操作

- 扫描桌面、下载、文档、用户主目录等个人目录时只生成路径、大小、日期报告。
- 明确告诉用户：未经逐项确认，不会移动、改名或删除报告中的文件。
- 修改前先建立备份并确认可读取。
- 删除个人文件进入系统回收站，不永久删除。
- 每批最多处理 10 个对象，每批后核验。
- 受影响对象变化、出现失败或结果与预期不符时立即停止。

## 完成报告

- 实际执行的动作
- 未执行或失败的动作
- 验证结果
- 备份位置
- 恢复方法
- 是否需要重启或继续观察
