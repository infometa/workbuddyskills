# 校园网络与外设排障

- 资料类型：专家经验规则
- 依据范围：操作系统官方支持、设备厂商支持流程和高校网络服务共性
- 适用范围：用于问题分流与风险判断，不作为任何具体学校的配置方案
- 学校事实来源：用户所在学校官网、信息化部门或网络中心
- 整理日期：2026-07-17
- 内容状态：具体认证方式、客户端、设备数量、VPN、代理和宿舍路由策略必须在线核验
- 风险等级：连接检查为低；网络重置、驱动和固件为中高

## 校园网

1. 先查学校信息化部门或网络中心公告，确认维护、认证方式和允许的设备数量。
2. 判断其他同学、其他设备或其他网络是否正常。
3. 确认有线、无线、网页认证、客户端或 802.1X 中的实际接入方式。
4. 检查账号状态、日期时间、代理、VPN、随机 MAC 或私有 Wi-Fi 地址设置。
5. 保留完整错误码、认证页面地址、客户端版本和系统版本。
6. 不指导绕过认证、设备数量限制、访问控制或学校安全策略。

转学校网络中心：账号被锁、认证服务器异常、宿舍端口未开通、策略限制、多人同时故障。

## 宿舍路由器

- 先确认学校是否允许自建路由器及指定接入模式。
- 不把路由器接入校园网当作通用方案。
- 修改 WAN、DHCP、DNS、桥接、MAC 克隆或恢复出厂前先备份配置并取得授权。
- 管理密码不让用户发送到对话中。

## 打印机

1. 确认打印机型号、连接方式、系统版本和是否有纸张或耗材告警。
2. USB 打印先检查线缆、接口和设备是否被系统识别。
3. 网络打印先确认电脑和打印机是否处于允许互通的网络。
4. 清除打印队列、移除打印机、重装驱动前提示会影响未完成任务。
5. 驱动从打印机厂商官方型号页面获取。

## 投屏和显示器

1. 确认 HDMI、USB-C、DisplayPort、无线投屏中的实际方式。
2. 检查线缆、转换器、输入源、显示模式和分辨率。
3. USB-C 外形相同不代表支持视频输出，按电脑和扩展坞型号核验。
4. 教室中控或接收端异常转现场管理员。

## 蓝牙、耳机、麦克风和摄像头

1. 检查设备电量、配对模式、系统输入输出选择和应用权限。
2. 排除设备已连接到手机或另一台电脑。
3. 在另一个应用测试，区分系统、应用和硬件问题。
4. 删除配对、重置设备、修改驱动或固件前进入授权流程。
