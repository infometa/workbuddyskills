# 学习软件与文件处理

- 资料类型：官方资料摘要 + 专家经验规则
- 官方入口：Microsoft 365 Support、WPS 学堂、Adobe Help 和主流浏览器官方帮助
- 适用范围：Office、WPS、PDF、浏览器、课程文件、压缩与云同步
- 来源访问核验：2026-07-17
- 内容状态：通用分流与安全规则已整理；菜单路径、兼容性、修复和重置步骤需按软件版本核验
- 风险等级：基础操作低；重置、卸载、同步和批量文件操作为中高

## Office 与 WPS

1. 确认软件名称、版本、授权类型、系统版本和文件格式。
2. 排版变化先检查字体缺失、页面尺寸、默认字体、兼容模式和导出方式。
3. 软件打不开先重启、更新并检查账号或服务状态，再考虑修复安装。
4. 快速修复、在线修复、重置或卸载前说明对插件、模板、缓存和登录状态的影响。
5. 激活只使用购买账号、学校正版平台或官方授权流程。

## PDF

- 区分查看、编辑、扫描、表单、签名、压缩和格式转换。
- 含个人身份、成绩、合同或签名的文件不上传到不明在线转换站。
- 转换前保留原文件，输出到新文件名并核对页数、字体和图片。
- 密码保护文件只处理用户有权访问的内容，不提供绕过密码方案。

## 浏览器与插件

1. 确认浏览器和插件精确版本、问题网站和是否只影响单个配置文件。
2. 先使用隐私窗口或禁用单个扩展验证，不一次清空所有数据。
3. 清除 Cookie 会退出账号，清除浏览器配置会影响书签、密码和扩展；执行前说明范围并确认同步状态。
4. 教务系统兼容问题优先查学校官方要求和浏览器支持范围。
5. 插件只从浏览器官方扩展商店或厂商官网安装。

## 文件与文件夹

- 先解释当前文件所在位置、扩展名和目标位置。
- 建议课程目录：`学年-学期/课程名/课件`、`作业`、`资料`、`提交版`。
- 文件名包含日期、课程和版本，例如 `2026-09-18_课程名_作业1_v2.docx`。
- 移动、重命名、覆盖和批量整理前列出完整路径和冲突处理方式。
- 扫描个人目录只生成报告，未经逐项确认不修改。

## 压缩与提交

1. 确认学校要求的格式、文件大小、命名和目录层级。
2. 压缩后重新打开检查，避免空压缩包、路径过深或乱码。
3. 提交前保留本地副本和提交成功凭证。
4. 不建议为减小体积而删除原始课程文件。

## 云同步与备份

- 区分“同步”和“备份”，同步删除可能传播到云端和其他设备。
- 操作前确认同步状态、账号、剩余空间和版本历史。
- 停止同步、解除账号、按需文件、释放空间和批量删除均需说明影响并取得授权。
- 重要作业至少保留本机和另一处独立副本。
