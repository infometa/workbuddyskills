# Windows 11 基础排障

- 资料类型：官方资料摘要 + 专家经验规则
- 官方入口：https://support.microsoft.com/zh-cn/windows
- 版本健康：https://learn.microsoft.com/zh-cn/windows/release-health/
- 适用范围：受支持的 Windows 11 家庭版和专业版
- 来源访问核验：2026-07-17
- 内容状态：通用分流已整理；具体版本、错误码、驱动和恢复步骤需按官方文章另行核验
- 风险等级：查看状态为低；重置、驱动、系统恢复为中高

## 先确认

- `设置 > 系统 > 系统信息`：版本、设备名称、处理器、内存、系统类型
- `Win + R` 后输入 `winver`：版本和 OS 内部版本
- 问题是否发生在更新、驱动、软件安装或配置修改之后
- 是否有未备份的重要文件

## 卡顿与高占用

1. 打开任务管理器，按 CPU、内存、磁盘排序。
2. 确认高占用进程名称和发布者，不直接结束不认识的系统进程。
3. 检查系统盘剩余空间和 Windows 更新状态。
4. 先重启异常应用，再重启电脑。
5. 启动项调整、卸载软件或清理个人文件前进入授权流程。

停止条件：磁盘持续 100%、设备掉盘、异响、频繁卡死或 SMART 告警。

## 网络异常

1. 判断所有网络还是单个网络、所有设备还是单台电脑。
2. 检查飞行模式、Wi-Fi 开关、网线和校园认证页面。
3. 查看是否启用了代理或 VPN，不直接重置网络。
4. 使用系统网络疑难解答并记录结果。
5. 网络重置会移除网络适配器配置，执行前说明影响并确认。

## 声音、摄像头与蓝牙

1. 检查输出或输入设备是否选择正确、是否静音。
2. 检查 `设置 > 隐私和安全性` 中应用权限。
3. 断开后重新连接设备，换接口或排除其他设备占用。
4. 驱动问题优先查整机品牌型号页面；不要先用第三方驱动工具。

## 软件无法运行

1. 记录软件名称、版本、来源和完整错误信息。
2. 确认系统版本、架构和软件最低要求。
3. 先重启应用、更新软件、检查账号和服务状态。
4. 修复、重置、清缓存、卸载重装前说明可能影响的本地数据和登录状态。

## 蓝屏与异常重启

1. 记录停止代码、失败模块和出现频率。
2. 核对近期系统、驱动、硬件或外设变化。
3. 一次只回退或调整一个变量。
4. 反复蓝屏、无法启动、存储或内存诊断异常时转品牌售后。

## 更新与恢复

- 更新前连接电源并备份重要文件。
- 已知问题先查 Windows release health。
- 系统还原、重置电脑、回退版本和重装均需明确授权。
- 不以关闭安全中心、内存完整性或更新服务作为常规方案。
