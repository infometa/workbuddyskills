# 问题分流矩阵

- 资料类型：专家经验规则
- 设计参考：Microsoft、Apple 与主流设备厂商支持流程；社区 Skill 的最小充分诊断和逐步决策树
- 适用范围：Windows 11、当前受支持的 macOS、大学生常用软件与外设
- 整理日期：2026-07-17
- 内容状态：用于分流和选择下一步，不作为错误码或根因知识库
- 风险等级：低至高，按具体操作标注

## 首轮信息

只询问与当前问题相关的项目：

- 电脑品牌、准确型号、是否为学校或个人设备
- Windows 或 macOS 及版本
- 软件、插件或驱动名称与版本
- 完整错误文字、错误码、截图
- 问题从何时开始，是否在更新、安装、跌落、进液或修改设置后出现
- 是否影响所有应用、所有网络、所有账号或仅单个对象
- 是否有重要未备份数据

## 分流表

| 现象 | 首查方向 | 只读验证 | 升级条件 |
|---|---|---|---|
| 系统或软件卡顿 | CPU、内存、磁盘、启动项、剩余空间 | 任务管理器或活动监视器 | 掉盘、异响、频繁死机转售后 |
| 单个软件打不开 | 版本、权限、缓存、更新、安装损坏 | 版本号、官方状态、错误日志 | 需卸载重装前先确认数据和账号 |
| 无法联网 | 影响范围、校园认证、IP、DNS、代理 | 网络状态、其他设备、学校公告 | 服务端策略转学校网络中心 |
| 蓝屏或异常重启 | 停止代码、近期驱动或硬件变化 | 错误码、可靠性记录、诊断信息 | 反复蓝屏或硬件告警转售后 |
| 黑屏或不开机 | 电源、亮度、外接显示、启动状态 | 指示灯、风扇、外接屏表现 | 进液、异味、鼓包立即断电送修 |
| 外设不可用 | 接口、供电、连接模式、权限、驱动 | 换接口、系统设备状态 | 固件或专用驱动按型号核验 |
| 文件打不开或丢失 | 扩展名、权限、同步、回收站、版本历史 | 文件属性、云同步状态 | 不覆盖原盘，重要数据转专业恢复 |
| 网页或桌面广告弹窗 | 网页内容、网站通知、扩展、已安装应用、启动项 | 完整截图、出现位置、最近安装应用 | 疑似恶意软件、远控或勒索立即断网并转专业处理 |
| 浏览器首页、搜索或新标签被改 | 浏览器设置、扩展、第三方软件 | 当前设置、扩展列表、修改是否自动恢复 | 受管策略或持续恢复时转管理员或安全支持 |
| 陌生软件自启动或后台运行 | 安装来源、发布者、启动项、软件自身设置 | 启动项名称、安装日期、发布者、PUA 状态 | 系统组件或学校管理软件无法确认时停止 |
| 默认应用被更换 | 文件关联、安装程序授权、系统默认应用 | 受影响的扩展名和当前默认应用 | 组织策略控制时转管理员 |
| 可疑弹窗或远控 | 来源、进程、账号、网络连接 | 截图、安全软件状态、登录记录 | 疑似被控或勒索立即断网并转专业处理 |

## 排查顺序

1. 确认是否存在人身、供电、硬件或数据风险。
2. 判断影响范围：单文件、单软件、单账号、单网络、整台设备。
3. 检查最近发生的变化。
4. 先检查无需修改的状态和版本信息。
5. 再尝试重启应用、重新连接、切换端口等可逆步骤。
6. 需要修改配置、重置、卸载或删除时进入授权流程。
7. 每一步验证结果后再继续，不并行改动多个变量。

## 立即停止条件

- 冒烟、异味、进液、电池鼓包、异常高温或触电风险
- 硬盘异响、频繁掉盘、重要数据无法读取
- 勒索提示、账号被盗、持续远程控制
- 无备份且下一步可能覆盖或删除数据
- BIOS、固件、分区或驱动与准确型号无法对应
