# 诊断数据与隐私

- 资料类型：专家风险控制规则
- 适用范围：本地健康快照、日志查看、诊断报告保存与分享
- 整理日期：2026-07-17

## 默认采集范围

只读健康快照默认可以采集：

- 操作系统名称、版本和架构
- CPU 名称和逻辑处理器数量
- 内存总量与当前使用率
- 本地磁盘总量、剩余空间和使用率
- 网络适配器名称、连接状态和速率
- 当前存在的异常设备名称、状态和错误码
- 完整模式下的高内存进程名称、进程 ID 和内存占用

## 默认不采集

- 文档、图片、聊天、邮件和课程文件内容
- 浏览器历史、Cookie、密码和扩展数据
- Wi-Fi 密码、账号密码、令牌、密钥和恢复密钥
- 完整环境变量、完整网络配置和公网 IP
- 用户目录递归清单
- 事件日志正文

## 可选软件清单

只有捆绑安装、弹窗来源或自启动问题需要且用户同意时使用 `--include-software`：

- 读取启动项名称和位置，不读取启动命令。
- 读取最多 40 条已安装应用的名称、版本、发布者和安装日期。
- 读取 Windows PUA 防护状态；读取失败时只记录失败，不修改设置。
- 软件清单可能暴露用户使用的软件，不保存、不上传，排查结束后不继续使用。
- 软件名称、发布者缺失、启动状态或安装日期只能作为线索，不能单独判定流氓软件。

## 可选事件摘要

只有问题需要且用户同意时使用 `--include-events`：

- 只读取最近 24 小时、最多 20 条 Windows 系统错误的时间、事件 ID、级别和提供程序名称，不读取消息正文。
- 完整模式中的进程名称和可选事件摘要仍可能暴露正在使用的软件或系统组件。
- 不自动上传或分享。
- 分享给学校、厂商或维修人员前，先由用户检查并删除无关标识。

## 保存规则

- 默认只输出到当前会话，不创建文件。
- 使用 `--save` 前明确保存路径和内容范围。
- 不保存到桌面、下载或文档目录，除非用户明确指定。
- 报告只用于当前故障，不收集与问题无关的数据。

## 解释规则

- CPU、内存和磁盘百分比是当前快照，不代表持续故障。
- 设备状态和事件数量是线索，不是根因。
- 端口、进程和服务必须结合用途、网络范围和管理策略判断。
- 脚本失败或字段为空时明确标注，不用推测值补齐。
