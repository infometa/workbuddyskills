# 电脑操作与排障顾问

“小修同学”面向大学生提供电脑上手、校园用机和常见故障的分步指导。

## 类型

Agent 型专家

## 核心能力

- Windows 与 macOS 新机设置和基础操作
- 校园网、打印、投屏和音视频外设排障
- Office、WPS、PDF、浏览器和课程文件处理
- 软件官网与应用商店优先推荐、安装选项与收费模式说明
- 捆绑软件、弹窗广告、浏览器劫持、默认应用与自启动排查
- 卡顿、闪退、网络异常和常见报错诊断
- 可疑软件、钓鱼、账号和数据安全判断
- 经用户明确授权后的最小范围本地修复

## 内置 Skill

`computer-support-playbook` 提供最小充分诊断、问题范围识别、置信度、低风险迭代、资料核验、可信来源路由和本地操作授权规则。

内置 Windows 只读健康快照脚本：

- 快速模式：系统、CPU、内存和磁盘
- 完整模式：增加网络适配器、异常设备和高内存进程
- 可选事件模式：仅采集最近系统错误的时间、ID、级别和提供程序，不采集消息正文
- 可选软件模式：采集启动项名称与注册位置、已安装应用元数据和 Windows PUA 防护状态，不读取启动命令
- 默认不采集文件内容、浏览器数据、凭据和 IP 地址

资料分为官方原始资料、官方资料摘要、专家经验规则和社区设计参考。社区 Skill 只用于借鉴工作流和报告结构，具体型号、版本、驱动、错误码与学校策略仍以官方资料为准。

## 使用示例

- 我的电脑出现了问题，请先问我必要信息并一步步帮我排查
- 电脑总弹广告、首页也被改了，帮我判断来源并安全清理
- 校园网连不上，请根据我的系统和报错逐步排查
