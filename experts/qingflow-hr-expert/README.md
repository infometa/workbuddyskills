# 人力资源 HR 专家 — 小Q

基于轻流（QingFlow）无代码平台的人力资源数字化专家，覆盖招聘、培训、绩效、入职与人力分析，基于轻流 MCP 直接搭建应用、配置流程、分析数据。

## 类型

Agent 型（单个 AI 专家）

## 核心能力

- **HR 场景翻译**：听懂 HR 业务场景，快速匹配 5 个预置 Skill
- **轻流全栈搭建**：表单设计、流程引擎、数据视图、权限模型
- **MCP 直接操作**：通过 `qingflow` 连接器下的 app-builder / app-user 工具集操作轻流
- **5 个 HR 场景 Skill** + 1 条人才管理端到端协作链路

## 覆盖场景

| # | 场景 | 核心工作流 |
|---|------|-----------|
| 01 | 智能招聘引擎 | 简历解析 → JD匹配 → 面试题生成 → 候选人评估 → 人才库入库 |
| 02 | 培训设计师 | 培训需求诊断 → 大纲生成 → 讲义制作 → 测试题 → 考核评估 |
| 03 | 绩效管理助手 | 目标拆解 → 进度跟踪 → 达成差距分析 → 面谈提纲 |
| 04 | 入职流程搭建器 | 材料收集 → 审批 → 任务清单 → 试用期跟踪 |
| 05 | 人力数据看板 | 人员结构 / 流失率 / 招聘漏斗 / 培训完成率 |

## 使用示例

- 帮我解析这份简历，匹配产品经理岗位 JD，并生成结构化面试题
- 帮我搭建一个员工入职审批应用，包含材料收集、审批、任务清单和试用期跟踪
- 帮我在轻流搭建人力分析看板，包含人员结构、流失率、招聘漏斗和培训完成率

## 依赖连接器

使用前可在 WorkBuddy **连接器** 中授权（用户也可选择不连接，仅作咨询）：

- `qingflow`（含 app-builder 与 app-user 工具能力）

未连接时：专家提供方案与建议；已连接时：可直接通过 MCP 搭建。
