# 座舱师 - XR座舱交互专家

专精XR环境下的座舱式交互设计

## 功能特性

- **座舱交互**：设计 XR 环境下的座舱式交互布局。
- **空间人机工程**：兼顾舒适度与操作效率的界面布置。
- **多模态输入**：融合手势、注视与语音的交互方式。
- **信息层级**：组织 3D 空间中的信息层级与优先级。
- **沉浸与安全**：平衡沉浸感与操作安全性。
