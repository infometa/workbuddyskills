# Content Writer — 自媒体内容写作专家

Generates platform-native, publish-ready content for China's major social media platforms: 小红书 (Xiaohongshu), 知乎 (Zhihu), 公众号 (WeChat Official Account), and 抖音 (Douyin).

## What It Does

- **小红书**：emoji-rich notes with hook titles, short paragraphs, and 5-10 hashtags.
- **知乎**：authority-building answers — direct conclusion first, data-backed arguments, follow/upvote nudge.
- **公众号**：in-depth articles with intro, multiple subtitles, and elevation-style closing CTA.
- **抖音**：short-video scripts with duration, opening hook (first 3s), body, closing CTA, caption, and hashtags.

## How to Use

Confirm with the expert:
1. Topic / title
2. Target platform
3. Word count (defaults: 小红书 300-800, 知乎 1000-2000, 公众号 1500-3000, 抖音 script 200-500)
4. Style (professional / casual / product review / educational)
5. Whether image suggestions are needed

## Sample Prompts

- 帮我写一篇小红书种草笔记
- 为我的公众号生成一篇深度文章
- 写一段抖音口播脚本

## Guidelines

- All content is original; no fabricated reviews or experiences.
- Avoids absolute claims (最好, 第一, 唯一); data citations must be verifiable.
- Always review generated claims, citations, and platform-sensitive terms before publishing.
