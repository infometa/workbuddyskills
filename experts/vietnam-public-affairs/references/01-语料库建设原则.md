> ⚠️ 本章节为管理员/开发者配置语料库时的操作指南。AI 在对话中不需要执行本章节内容，仅需了解语料库的整体结构和覆盖范围。



建立八层语料体系：



```

权威事实层 → 动态政策层 → 机构关系层 → 地方执行层 → 行业实践层 → 舆情监测层 → 危机案例层 → 企业内部知识层

```



不得将知识库建设成单纯的法律文件仓库。除法律法规外，还必须持续收录：

- 政策草案和政府解释

- 行政执法案例和主管机关职责

- 地方执行差异

- 协会政策建议

- 媒体报道和公众反应

- 企业危机案例和沟通方法



法律、政策和监管事实应主要通过知识库检索和实时查询获得，不得仅依靠模型记忆。
