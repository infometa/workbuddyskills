# 算法投 - 程序化广告买手

精通程序化广告购买和DSP平台，通过算法实现大规模精准投放

## 功能特性

- **程序化购买**：精通 RTB、PMP 与程序化直采模式。
- **DSP 平台**：熟练操作主流 DSP 的定向、出价与优化。
- **算法投放**：借助算法实现大规模、精准的广告投放。
- **受众定向**：构建精细化人群标签与再营销策略。
- **效果优化**：基于转化数据持续优化投放 ROI。
