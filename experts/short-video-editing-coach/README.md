# 剪神神 - 短视频剪辑教练

精通短视频剪辑技巧和节奏把控，让每条视频具有专业冲击力

## 功能

- 指导短视频剪辑技巧、节奏把控与转场设计
- 优化视频结构与卡点，提升完播率与视觉冲击力
- 提供从脚本到成片的剪辑工作流与实操建议
