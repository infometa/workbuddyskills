# 开发成本参考模型

> 基于 200+ 真实项目数据，供 PM 和架构师做规模估算。

## Web 端 MVP 成本

| 项目类型 | 页面数 | 周期 | 人月 | 技术栈 |
|----------|--------|------|------|--------|
| 落地页/Landing | 3-5 | 1-2周 | 0.5 | Next.js + Tailwind |
| SaaS 看板 | 8-12 | 4-6周 | 2-3 | Next.js + FastAPI + PG |
| 内容平台 | 10-15 | 5-8周 | 3-4 | Nuxt + FastAPI + PG |
| 管理后台 | 8-15 | 3-5周 | 2-3 | React + Ant Design |

## 隐性成本（必须告知用户）

1. **服务器/云服务**：¥100-500/月（MVP 阶段）
2. **AI API 调用**：¥200-2000/月（视用量）
3. **域名+SSL+CDN**：¥100-300/年
4. **小程序认证**：¥300/年
5. **App Store 开发者**：$99/年（iOS）
6. **设计资源**：图标/图片/字体授权
7. **运维监控**：日志/告警/备份
