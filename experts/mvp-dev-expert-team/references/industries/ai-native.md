# AI 原生产品设计规范

> 基于 Excellent AI商业落地经验 + SuperDev设计系统 + WorkBuddy实战蒸馏

## 行业特征

- **用户**：AI工具使用者、开发者、企业决策者
- **核心诉求**：AI能力可感知、交互直觉化、结果可信赖
- **设计风格**：科技感+专业感、信息层次清晰、交互流畅
- **关键挑战**：AI黑盒的透明化表达、生成结果的信任建立、多模型路由的无感切换

## 设计规范

### 配色方向
- 主色：深蓝/靛蓝（#1a56db / #3b82f6）——传达智能、可信
- 强调色：翠绿（#10b981）——用于AI生成标识、成功状态
- 中性色：大面积浅灰白（#f8fafc / #f1f5f9）
- AI标识色：渐变细线（蓝→绿），仅用于AI生成内容的视觉标识
- 禁止：紫色→粉色渐变主视觉（AI模板味）
- 每屏强调色≤2处

### 布局模式
- **对话式交互**：聊天窗口 + 侧边结果面板
- **工作台模式**：左侧工具栏 + 中央工作区 + 右侧AI助手面板
- **生成式界面**：输入区 + 实时预览区 + 参数调控面板
- **多模型仪表盘**：模型状态卡片 + 路由可视化 + 成本监控

### 组件模式
- **AI输出区**：打字机效果 + 生成进度条 + 置信度指示
- **流式响应**：逐Token渲染 + 中间结果折叠 + 完整结果展开
- **多模型切换**：下拉选择 + 性能对比 + 实时状态灯
- **Token计数器**：输入/输出Token实时显示 + 成本估算
- **生成质量反馈**：点赞/点踩 + 具体问题标注 + 改进建议

### 交互规范
- AI生成中：进度指示 + 中止按钮 + 估计剩余时间
- AI生成完成：结果高亮 + 一键复制 + 继续追问入口
- AI生成失败：明确错误原因 + 重试按钮 + 降级方案提示
- 多轮对话：上下文保持指示 + 话题切换 + 历史回溯

## AI原生产品技术架构参考

### 多模型路由架构
```typescript
interface ModelRoute {
  taskType: 'code' | 'writing' | 'analysis' | 'multimodal';
  primary: ModelConfig;
  fallback: ModelConfig[];
  circuitBreaker: { threshold: number; timeout: number };
}
```

### 流式 Function Calling
- 增量tool_calls按index累积
- 递归_stream_with_tools，max_depth=3
- 前端逐Token渲染 + 工具调用可视化

### 5态覆盖（AI产品必须）
1. **Loading**：AI思考中 + 骨架屏 + 预计时间
2. **Empty**：首次使用引导 + 示例提示 + 快速开始
3. **Error**：错误分类（模型/网络/权限）+ 降级方案
4. **Populated**：结果展示 + 交互操作 + 继续追问
5. **Edge**：超长输出截断 + 成本上限提醒 + 内容安全过滤

## 反模式警告
- 不要用emoji做AI功能图标（用Lucide：Sparkles/Brain/Wand2）
- 不要用"Welcome to Our AI"等空洞占位（展示真实AI能力）
- 不要硬编码颜色（Design Token引用）
- 不要弹跳缓动（用150ms收敛值）
- 不要千篇一律Hero（展示真实AI交互场景）
