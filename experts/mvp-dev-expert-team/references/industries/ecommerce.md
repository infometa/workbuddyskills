# 电商 / 消费 — 行业设计规范

## 行业特征
- 目标用户：消费者（C端）
- 核心诉求：快速找到商品、顺畅下单、信任保障
- 转化率是第一指标

## 设计风格
- **风格**：柔和进化风
- **主色**：Warm Orange `#F97316` / Red `#EF4444`（促销）
- **对标品牌**：淘宝、京东、拼多多、小红书商城
- **字体**：DM Sans / Noto Sans SC
- **氛围关键词**：活力、亲切、转化、信任

## 布局模式
- **首页**：Banner 轮播 + 金刚区 + 商品瀑布流
- **分类页**：左侧分类树 + 右侧商品列表
- **商品详情**：图片轮播 + 规格选择 + 评价 + 推荐
- **购物车**：商品列表 + 金额汇总 + 结算按钮
- **订单流程**：地址 → 支付 → 确认 → 结果

## 核心页面清单
1. 首页（发现/推荐/活动）
2. 分类页（搜索 + 筛选）
3. 商品详情页（SKU + 加车）
4. 购物车
5. 订单列表 + 详情
6. 个人中心
7. 搜索结果页
8. 支付页

## 交互规范
- 加入购物车有弹窗确认 + 动画
- 规格选择联动价格和库存
- 倒计时/限时促销实时更新
- 下拉刷新 + 无限滚动
- 图片懒加载 + 预加载首屏

## 微信小程序特殊规范
- 底部 TabBar 2-5 个
- 导航栏自定义需兼容安全区
- 支付走微信支付 API
- 分享走 onShareAppMessage
- 订阅消息需用户授权

## 技术架构建议
- **前端**：Taro 3 / uni-app / 原生小程序
- **状态管理**：Zustand / Pinia
- **后端**：FastAPI / Spring Boot + MySQL
- **支付**：微信支付 / 支付宝
- **搜索**：ES / MeiliSearch
- **部署**：CloudBase / 腾讯云

## 行业数据参考
- 转化率：1-5%（搜索流量），8-15%（直接访问）
- 客单价：¥50-500（大众电商）
- 跳出率基准：30-50%
- 购物车放弃率：60-80%
