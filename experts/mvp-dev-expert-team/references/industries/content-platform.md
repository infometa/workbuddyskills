# 内容 / 社区平台设计规范

> 基于 Excellent SEO Agent框架 + 公众号运营 + 优码云官网实战蒸馏

## 行业特征

- **用户**：内容创作者、读者、社区成员
- **核心诉求**：内容发现高效、创作体验流畅、互动即时感
- **设计风格**：留白充足、阅读舒适、视觉层次分明
- **关键挑战**：信息密度与阅读舒适度的平衡、个性化推荐的UI表达

## 设计规范

### 配色方向
- 主色：品牌色（根据产品调性，蓝/绿/橙皆可）
- 背景：大面积暖白/冷白（#fafafa / #f8fafc）
- 文字：深灰（#1a1a2e / #334155），正文#475569
- 强调色：1个，用于CTA和关键交互
- 每屏强调色≤2处

### 布局模式
- **Feed流**：卡片瀑布流 + 无限滚动 + 下拉刷新
- **编辑器模式**：沉浸式写作 + 工具栏 + 实时预览
- **社区模式**：话题分组 + 帖子列表 + 侧边栏热门/推荐
- **阅读模式**：宽屏阅读 + 字号调节 + 侧边目录

### 组件模式
- **内容卡片**：封面图 + 标题 + 摘要 + 标签 + 作者/时间
- **富文本编辑器**：Markdown + 所见即所得切换 + 图片拖拽上传
- **互动组件**：点赞/收藏/评论/分享 + 动画反馈
- **推荐组件**：猜你喜欢 + 相关内容 + 热门排行

### 交互规范
- 内容加载：骨架屏 + 渐显动画
- 图片：懒加载 + 渐显 + 点击放大
- 长文：目录导航 + 阅读进度条 + 字号调节
- 评论：实时更新 + 折叠子评论 + @提及

## SEO Agent 架构参考

### 6角色Agent系统
| 角色 | 职责 | 触发条件 |
|------|------|----------|
| Strategist | SEO策略、关键词规划 | 每周自动触发 |
| Writer | 内容撰写 | 策略确认后 |
| Auditor | 质量审核（3轮Critic） | Writer完成后 |
| Pusher | 发布推送 | Auditor通过后 |
| Analyst | 数据分析 | 发布48小时后 |
| HomeOptimizer | 首页优化 | Analyst报告后 |

### 关键设计模式
- **48小时延迟反馈**：SEO效果需时间，不能立即判断
- **Critic三轮挑战**：每篇文章3轮自我批判才发布
- **月度Supervisor评分**：长期效果评估
- **OODRA闭环**：Observe→Orient→Design→Review→Act

## 反模式警告
- 不要用emoji做功能图标
- 不要千篇一律的内容卡片（区分不同内容类型的视觉表达）
- 不要忽视空状态设计（新用户首次看到的空Feed需要引导）
