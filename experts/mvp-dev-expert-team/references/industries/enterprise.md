# 企业管理 / ERP 行业设计规范

> 基于 Excellent 9年OPC交付经验 + 828 API / 68万行代码企业ERP实战蒸馏

## 行业特征

- **用户**：企业管理层、部门主管、一线操作员
- **核心诉求**：流程标准化、数据可视化、权限分级、审批流转
- **设计风格**：专业稳健、信息密度高、操作路径短
- **关键挑战**：复杂业务逻辑的简化呈现、多层权限的直觉化表达

## 设计规范

### 配色方向
- 主色：深蓝/藏青（#1e3a5f / #2c3e50）——传达专业、可信
- 辅色：琥珀/橙色（#f59e0b）——用于警告、待审批等需关注状态
- 中性色：大面积灰白（#f8fafc / #e2e8f0）
- 语义色：绿（通过）/ 红（拒绝）/ 蓝（进行中）/ 灰（草稿）
- 每屏强调色≤2处

### 布局模式
- **经典后台布局**：左侧导航 + 顶部面包屑 + 右侧内容区
- **工作台模式**：Dashboard 卡片网格 + 快捷入口 + 待办列表
- **表单密集型**：分步表单（Step Indicator）+ 实时校验 + 草稿自动保存
- **数据密集型**：高级筛选栏 + 可配置列表格 + 导出功能

### 组件模式
- **数据表格**：支持排序/筛选/分页/行内编辑/批量操作
- **审批流**：可视化流程图 + 节点状态标记
- **权限矩阵**：角色×功能交叉表格，勾选式配置
- **仪表盘**：KPI 卡片 + 趋势图 + 占比图 + 排行榜
- **组织架构**：树形结构 + 拖拽调整

### 交互规范
- 表格行操作：悬浮显示操作按钮，避免视觉噪音
- 批量操作：勾选后顶部浮动操作栏
- 表单校验：失焦校验 + 提交前全量校验
- 审批操作：一键通过/拒绝 + 可选审批意见
- 数据导出：支持 Excel / CSV / PDF

## ERP 级技术架构参考

### 权限感知 Function Calling
```
用户请求 → RBAC权限过滤 → LLM只能看到有权使用的工具 → 生成调用
```
- LLM 不知道被限制的工具存在，而非"知道但不能用"
- 每个API端点绑定权限标签，运行时动态过滤

### 自研 RAG 管道
- 分块：滑动窗口 + 语义断点分块
- 存储：pgvector + HNSW 索引
- 检索：三层漏斗（向量Top-50 → BM25重排 → 业务规则过滤）

### 四闭环进化
1. 代码质量闭环：lint → type-check → test → fix
2. 架构一致性闭环：Spec ↔ Code 双向校验
3. 用户体验闭环：设计Token ↔ 渲染结果对比
4. 商业逻辑闭环：PRD ↔ 实现功能验证

## 反模式警告
- 不要用紫色/粉色渐变做ERP（企业用户会觉得不专业）
- 不要过度追求视觉花哨，信息密度和操作效率才是核心
- 不要忽视权限体系的UI表达——权限管理是ERP的灵魂
- 不要用emoji做功能图标——用Lucide图标传达专业感
