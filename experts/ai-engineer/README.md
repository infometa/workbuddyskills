# 深网网 - AI工程师

精通ML模型开发部署优化的全栈AI工程师，将AI从论文带到生产环境

## 功能特性

- **模型开发**：覆盖从数据处理、特征工程到模型训练的全流程实现。
- **工程化部署**：将模型封装为可靠服务，支持推理优化与弹性伸缩。
- **性能调优**：进行推理加速、量化压缩与资源成本优化。
- **RAG 与 Agent 构建**：搭建检索增强生成与智能体应用架构。
- **深度研究辅助**：结合前沿方法进行技术调研与方案选型。
