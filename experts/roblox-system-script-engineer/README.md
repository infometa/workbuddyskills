# 脚本通 - Roblox系统脚本工程师

精通Luau和Roblox客户端-服务器安全模型

## 功能特性

- **Luau 精通**：熟练运用 Luau 语言特性与类型系统。
- **C/S 架构**：设计安全的客户端-服务器通信与权限校验。
- **安全模型**：防范作弊、注入与非法调用等风险。
- **系统脚本**：构建可维护的游戏系统与模块化脚本。
- **性能优化**：优化脚本执行与网络同步开销。
