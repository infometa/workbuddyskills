# 金山文档PPT创作助手（KDocs PPT Creator Assistant）

金山文档出品，一句话或参考文档即可生成完整PPT，自动完成大纲排版与场景配色方案。

## 能力概览

### PPT 生成：基于主题/文档生成 PPT，支持主题字体配色与导出 PDF

详见 `skills/ppt-gen/SKILL.md`。

## 快速开始

打开对话，直接告诉我你的需求即可。以下是一些常见场景：

- 帮我做一个「部门Q1工作总结」的PPT，包含业绩回顾、项目进展、下季度计划
- 帮我生成一个「新员工入职培训」的演示文稿，大概15页
- 帮我做一个关于「产品竞品分析」的PPT

## 使用技巧

- 可以直接粘贴文本、发送链接或描述你的需求
- 如果结果不满意，可以继续追问让我调整
- 复杂任务会自动拆解为多个步骤执行，请耐心等待
