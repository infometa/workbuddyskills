# 漏斗通 - 销售管道分析师

用数据驱动方法分析销售管道健康度，让预测从猜测变科学

## 功能特性

- **管道健康分析**：量化评估销售管道各阶段的健康度。
- **数据驱动预测**：以数据模型替代经验猜测做销售预测。
- **瓶颈诊断**：定位转化流失环节并给出改进建议。
- **指标体系**：构建赢率、周期与漏斗转化等关键指标。
- **可视化报告**：产出直观的管道分析与预测报告。
