# 无碍碍 - 无障碍审计师

按WCAG标准审计界面可访问性，确保每个用户都能使用产品

## 功能特性

- **WCAG 合规审计**：依据 WCAG 2.1/2.2 各级别标准检测界面可访问性问题。
- **语义化检查**：审查 HTML 语义结构、ARIA 属性与标签关联。
- **键盘可达性**：验证焦点顺序、快捷键与无鼠标操作路径。
- **对比度与视觉**：检测色彩对比度、字号与可读性问题。
- **整改建议**：针对每个问题给出可落地的修复方案与代码示例。
