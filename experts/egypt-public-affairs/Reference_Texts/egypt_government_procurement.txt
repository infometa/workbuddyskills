# 来源：eps-gags.gov.eg + 公开采购法规

## 一、体系概述

**主管机构**：
- **政府采购中央局**：隶属财政部
- **电子采购系统**：eps-gags.gov.eg
- **政府招标门户**：egypt-eprocurement.org

**法律基础**：
- 政府采购法（Government Procurement Law）
- 公共财政法（Public Finance Law）
- 电子交易法（Electronic Transactions Law）

## 二、电子采购系统（e-Procurement）

### 2.1 系统架构

**核心平台**：
- **公共电子采购系统**（eps-gags.gov.eg）
- **政府电子采购门户**（213.55.73.249:8080/egp/）

**功能模块**：
| 模块 | 功能 |
|------|------|
| 招标公告 | 发布 tenders、RFP、EOI |
| 投标管理 | 在线提交、文件上传 |
| 开标记录 | 公开开标记录 |
| 评标报告 | 发布评标结果 |
| 合同授予 | 公布中标信息 |
| 供应商注册 | 企业注册、资质审核 |

### 2.2 注册要求

**必须注册**：
- 埃及公司（Tax ID + Commercial Register）
- 外国公司（需本地代表或分支机构）

**注册信息**：
- 公司法律信息（注册证书、税号）
- 银行信息（保函/保证金账户）
- 业绩记录（过往合同）
- 技术资质（ISO、行业认证）
- 财务资质（审计报告、银行资信证明）

## 三、招标类型

### 3.1 按采购方式

| 类型 | 适用场景 | 最低报价数 |
|------|----------|------------|
| 公开招标（Open Tender） | 大型项目、标准货物 | 无限制 |
| 限制性招标（Restricted Tender） | 专业服务、技术复杂 | 至少3家 |
| 竞争性谈判（Competitive Negotiation） | 紧急采购、独特技术 | 至少2家 |
| 单一来源（Single Source） | 专利产品、紧急需求 | 1家（需批准） |
| 询价（Request for Quotation） | 小额采购（<50万EGP） | 至少3家 |

### 3.2 按采购类别

| 类别 | 定义 | 规模门槛 |
|------|------|----------|
| 工程（Works） | 基建、施工 | 通常>500万EGP |
| 货物（Goods） | 设备、材料 | 通常>50万EGP |
| 服务（Services） | 咨询、维护 | 通常>100万EGP |

## 四、招标流程

### 4.1 标准流程（公开招标）

```
Step 1: 招标公告发布（Tender Notice）
  - 公告期：通常30-60天
  - 发布渠道：e-Procurement系统 + 官方公报

Step 2: 资格预审（Pre-qualification，如适用）
  - 技术资质审核
  - 财务能力审核
  - 过往业绩审核

Step 3: 投标书提交（Bid Submission）
  - 技术标书
  - 商务标书（价格）
  - 保证金（通常2-5%）
  - 有效期：通常90-180天

Step 4: 开标（Bid Opening）
  - 公开开标
  - 记录所有报价

Step 5: 评标（Evaluation）
  - 技术评审（通常70%权重）
  - 价格评审（通常30%权重）
  - 最低价格并非唯一标准

Step 6: 合同授予（Award）
  - 中标通知
  - 合同谈判
  - 履约保证金（通常5-10%）

Step 7: 合同执行
  - 项目执行
  - 阶段性验收
  - 最终验收
  - 质保期（通常1-2年）
```

## 五、关键规则

### 5.1 本地化要求（Local Content）
- 政府采购优先考虑本地产品/服务
- 本地成分证书（Local Content Certificate）可增加竞争力
- 由FEI（埃及工业联合会）颁发

### 5.2 中小企业（SME）优先
- SME Law No. 152 of 2020
- 政府合同的一定比例（约20%）优先分配给SME
- 中小型企业可联合体投标

### 5.3 外国企业参与

**直接参与**：
- 在埃及注册分支机构或子公司
- 持有有效的Commercial Register和Tax ID
- 满足本地化要求

**间接参与**：
- 与埃及本地企业组成联合体（Joint Venture）
- 作为分包商参与
- 技术转让协议（可增加评分）

**限制领域**：
- 国家安全相关项目（外国企业受限）
- 某些军工/通信项目
- 西奈半岛项目（特殊审批）

## 七、对中资企业的建议

### 7.1 进入策略
| 策略 | 适用场景 | 优势 |
|------|----------|------|
| 本地注册 | 长期运营 | 直接投标、品牌建立 |
| 联合体 | 大型项目 | 互补能力、降低风险 |
| 代理/分销 | 设备供应 | 低成本进入 |
| 技术转让 | 制造业 | 增加评分、政策支持 |

### 7.2 关键成功因素
1. **本地合作伙伴**：与埃及企业建立长期合作关系
2. **资质认证**：获取ISO、行业认证、本地成分证书
3. **业绩记录**：在埃及或中东地区积累项目经验
4. **投标团队**：配备熟悉阿拉伯语的商务/技术人员
5. **融资能力**：提供买方信贷或融资方案（增加竞争力）
6. **技术转移**：承诺培训本地员工、技术转让

### 7.3 风险提示
| 风险 | 描述 | 应对 |
|------|------|------|
| 评标不透明 | 非价格因素权重高 | 确保技术标书完善 |
| 付款延迟 | 政府预算周期 | 合同约定付款条款 |
| 合同变更 | 频繁的设计变更 | 保留变更索赔权利 |
| 本地竞争 | 本地企业优先 | 强调技术/质量优势 |
| 汇率风险 | EGP贬值 | 合同锁定汇率或美元计价 |
| 履约担保 | 高比例保证金 | 准备充足资金 |

## 九、投标保证金与履约担保

| 类型 | 比例 | 形式 | 退还条件 |
|------|------|------|----------|
| 投标保证金 | 2-5% | 银行保函/现金 | 未中标后退还 |
| 履约保证金 | 5-10% | 银行保函 | 项目验收后退还 |
| 预付款担保 | 等额 | 银行保函 | 按进度抵扣 |
| 质保金 | 5-10% | 银行保函 | 质保期结束后退还 |
