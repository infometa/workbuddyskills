## 一、机构概述

**全称**：Central Agency for Public Mobilization and Statistics（CAPMAS）
**中文**：埃及中央公共动员与统计局
**阿拉伯语**：الجهاز المركزي للتعبئة العامة والإحصاء
**成立时间**：1964年（基于1964年第2915号法令）
**隶属**：埃及内阁（Council of Ministers）
**性质**：埃及唯一的官方统计机构

**法律基础**：
- 1964年第2915号法令：机构成立
- 1996年第5号法令：职能扩展（新增人口普查、劳动力调查等）
- 2017年第72号投资法：数据服务商业化

**核心使命**：
- 收集、处理、分析和发布埃及官方统计数据
- 为政府决策、学术研究、国际组织和公众提供可靠数据
- 支持埃及可持续发展战略（SDGs）数据监测

## 二、组织架构

### 2.1 核心部门

| 部门/领域 | 职能 | 关键数据产品 |
|-----------|------|-------------|
| 人口与劳动力统计 | 人口普查、劳动力调查、移民数据 | 人口金字塔、失业率、就业结构 |
| 经济统计 | GDP、工业产值、农业产值、贸易 | 季度GDP、工业生产指数 |
| 价格统计 | CPI、PPI、进出口价格指数 | 月度通胀率 |
| 家庭调查 | 收入、支出、消费、贫困 | HIECS（家庭收支调查） |
| 环境与能源统计 | 能源生产/消费、环境指标 | 能源平衡表 |
| 信息通信统计 | ICT普及率、互联网使用 | 数字生态数据 |
| 教育统计 | 入学率、文盲率、教育支出 | 教育统计年鉴 |
| 卫生统计 | 出生率、死亡率、医疗覆盖 | 健康统计报告 |
| 建筑与住房统计 | 建筑许可、住房条件 | 住房普查 |
| 交通统计 | 交通流量、事故、运输 | 交通统计报告 |

### 2.2 关键领导
- **CAPMAS主席**：由总理任命
- **技术与统计局**：负责方法论和国际标准对齐
- **数据发布局**：负责官方公报和网站发布

## 三、主要统计领域与数据

### 3.1 人口统计

| 指标 | 最新数据（2024/2025） | 来源 |
|------|---------------------|------|
| 总人口 | ~1.07亿（2024年中估算） | CAPMAS |
| 人口增长率 | 约1.6%/年 | CAPMAS |
| 城镇化率 | 约43% | CAPMAS |
|  median age | 约24.5岁 | 联合国估算 |
| 劳动力 | 约3,100万 | 劳动力调查 |
| 失业率 | 约6.5-7.0% | 季度劳动力调查 |
| 贫困率 | 约29.7%（2019/2020 HIECS） | HIECS |

### 3.2 经济统计

| 指标 | 说明 |
|------|------|
| GDP | 季度/年度发布，现价和不变价 |
| 产业结构 | 农业、工业、服务业的增加值占比 |
| 工业生产指数 | 月度发布，主要制造业产出 |
| 贸易统计 | 进出口总值、主要贸易伙伴、商品结构 |

### 3.3 价格统计

| 指标 | 发布频率 | 说明 |
|------|----------|------|
| CPI（消费者价格指数） | 月度 | 核心通胀/整体通胀 |
| PPI（生产者价格指数） | 季度 | 工业投入品价格 |
| HIECS | 2-3年一次 | 家庭收入与支出调查 |

### 3.4 人口普查

- **频率**：每10年一次
- **最近一次**：2017年人口普查
- **下一次**：预计2027年
- **数据内容**：人口、住房、教育、就业、残疾等

## 六、对中资企业的价值

### 6.1 市场研究
- 人口结构数据：消费者画像、市场容量估算
- 收入与支出数据：购买力评估、定价策略
- 产业数据：竞争格局、产业链分析

### 6.2 投资选址
- 地区人口密度、经济活跃度
- 劳动力供给与成本
- 基础设施数据（电力、交通、通信）

### 6.3 政策评估
- 经济数据验证：GDP增长、通胀趋势
- 政策效果跟踪：新行政首都人口迁移、经济特区就业
- 风险监测：失业率、贫困率变化

## 八、数据使用注意事项

| 注意事项 | 说明 |
|----------|------|
| 数据滞后 | 月度数据通常滞后2-4周，季度数据滞后2-3个月 |
| 数据修订 | 历史数据可能修订，需确认版本 |
| 官方语言 | 阿拉伯语为主，部分数据有英语版 |
| 数据获取 | 基础数据免费，详细数据/定制报告可能需要付费 |
| 国际对齐 | 部分指标采用国际标准（SDGs、IMF、World Bank），部分为埃及本土定义 |

---

## 备注
- CAPMAS是埃及最权威的数据来源，但数据发布频率和详细度有限
- 建议将CAPMAS数据与IMF、World Bank、UN等数据进行交叉验证
- 部分敏感数据（如军事、安全相关）不公开
- 数据更新请以官网最新发布为准
