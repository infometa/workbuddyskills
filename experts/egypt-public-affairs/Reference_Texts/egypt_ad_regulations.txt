埃及广告法规与内容合规 — 不出事的底线
来源: 埃及广告协会、埃及消费者保护法、行业指南
获取时间: 2026-07-02
================================================================================

## 一、监管框架

### 1.1 主要监管机构

- 埃及消费者保护局 (CPA): 广告内容监管、虚假宣传处罚
- 国家电信监管局 (NTRA): 电信/短信营销
- 埃及中央银行 (CBE): 金融服务广告审批
- 卫生部: 药品/保健品/食品广告
- 最高媒体监管委员会: 广播电视广告

### 1.2 核心法规

- 消费者保护法 (第 181 号/2018): 禁止虚假/误导广告
- 电子支付法 (第 18 号/2019): 支付服务商需持牌
- 数据保护法 (第 151 号/2020): 个人数据处理原则
- 反垄断法: 禁止不公平竞争

## 二、广告内容红线

### 2.1 宗教与文化

禁止:
- 任何对伊斯兰教、基督教的不敬
- 使用宗教符号/经文做商业推广
- 斋月白天公开展示饮食 (电视广告除外，但需注意时段)
- 性暗示/裸露/亲密行为展示
- 对传统家庭价值观的挑战

要求:
- 女性形象需得体 (避免过度暴露)
- 尊重宗教节日和习俗
- 涉及宗教元素前咨询本地顾问

### 2.2 竞品比较广告

- 明文禁止直接贬低竞品
- 可以宣称"更好"，但不能点名竞品
- 不能使用竞品商标/包装做对比
- 比较性声明需有证据支撑

### 2.3 健康/食品声明

- 食品标签需有阿拉伯语
- 禁止虚假健康功效宣传
- "有机""天然"等声明需认证
- 保健品不得宣称治疗功效
- 婴幼儿食品广告受严格限制

### 2.4 促销/抽奖

- 抽奖/竞赛需提前报批
- 必须公布中奖概率（如适用）
- 奖品价值限制（视具体活动类型）
- "免费"声明需真实无附加条件

### 2.5 儿童广告

- 不能直接催促儿童购买 ("告诉爸妈买这个")
- 不能利用儿童的不成熟做诱导
- 玩具广告需标注适用年龄
- 教育类广告不能夸大效果

## 三、数字广告合规

### 3.1 社媒广告

- 必须明确标注为广告 (标签 #إعلان / "广告")
- KOL 合作内容必须标注为赞助
- 不得使用虚假粉丝/刷量
- 不得盗用他人内容

### 3.2 数据隐私 (第 151 号/2020)

- 收集个人信息前需获同意
- 需告知数据用途
- 用户有权要求删除数据
- 跨境数据传输有限制
- 违规罚款可达 EGP 500 万

### 3.3 SMS/WhatsApp 营销

- 需用户主动 opt-in
- 必须提供退订方式
- 发送时段限制 (避免深夜)
- NTRA 可封禁违规号码

## 四、特殊品类限制

| 品类 | 限制 |
|------|------|
| 酒类 | 完全禁止广告 |
| 烟草 | 完全禁止广告 (电视/广播/户外) |
| 药品 | 需卫生部预审批 |
| 金融产品 | 需央行审批，风险提示必标 |
| 房地产 | 需有实际项目，禁止虚假宣传 |
| 加密货币 | 央行禁止，广告风险极高 |
| 赌博 | 伊斯兰法禁止，不可涉及 |

## 五、广告标识与语言要求

- 所有面向消费者的广告必须有阿拉伯语版本
- 外文广告可存在，但需有阿拉伯语同等信息
- 价格必须用 EGP 标价 (可同时标注外币)
- 促销条款需用阿拉伯语清晰说明
- 退换货政策需公示

## 六、处罚与后果

- 虚假广告: 最高 EGP 200 万罚款 + 撤广告
- 屡犯: 关停业务许可
- 消费者集体诉讼: 近年增多
- 舆论惩罚: 社媒舆情可能是更大的打击

## 七、合规自查清单

任何 Campaign 上线前:
- [ ] 内容经本地文化顾问审核
- [ ] 无宗教冒犯元素
- [ ] 女性形象得体
- [ ] 所有声明有证据支撑
- [ ] KOL 内容标注了广告标签
- [ ] 价格/促销条款用阿拉伯语清晰说明
- [ ] 退换货政策在广告中可及
- [ ] 数据收集有用户同意
- [ ] SMS/WhatsApp 有退订方式
- [ ] 如涉及特殊品类，已获审批
