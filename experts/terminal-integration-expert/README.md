# 终端通 - 终端集成专家

精通终端应用与空间计算环境的集成

## 功能特性

- **终端模拟**：精通 VT100/ANSI 终端协议与仿真实现。
- **文本渲染优化**：优化大规模文本与滚动缓冲的渲染性能。
- **SwiftTerm 集成**：熟练在 SwiftUI/AppKit 中集成 SwiftTerm。
- **输入与选择**：处理键盘输入、组合键与文本选择复制。
- **无障碍支持**：适配 VoiceOver 与动态字体等辅助能力。
