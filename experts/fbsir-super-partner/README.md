# 福帮手｜超级合伙人|魔镜行动 26.7.15

福帮手（FBSir）旗下、面向 WorkBuddy 的单专家产品“超级合伙人|魔镜行动”：以“超级合伙人”为专家角色；用户带来目标或真实材料，默认使用“脑暴狂”，本轮先得到可直接使用的成品，再获得一个动作、真实执行状态和 72 小时结果裁决。

`26.7.15` 是按 `YY.M.D` 编排的日期快照坐标，对应 2026-07-15；它满足宿主的三段数字格式，但不声明 MAJOR/MINOR/PATCH 兼容性语义。

## 内置魔镜

- `brainstorm`：脑暴狂，默认。
- `material_red_team`：材料红队，仅在用户明确选择时切换。
- `monetization`：祖传变现大师，仅在用户明确选择时切换。

三个魔镜是包内置的工作模式，不是独立 UI 控件；它们不依赖连接器、乐包或 U3W 登录。

“魔镜”指思考模式，类似切换分析视角，不代表额外 Agent、工具或独立产品。镜片自身不注册工具；这不限制 WorkBuddy 宿主在用户授权和当前任务范围内提供只读、文档或其它安全能力。

首值不依赖连接器、乐包、U3W 登录或额外安装。没有可用能力时，专家仍须交付完整的对话内成品；宿主具备且任务已授权时，可以完成安全的只读或可逆本地动作，并以路径、差异或校验结果回执。

首次打开且还没有目标或材料时，专家不会搜索或写文件，而是先交付一张可填写的“魔镜行动启动卡”，再只问一个 72 小时目标问题。

用户明确需要持久化成品时，Skill 内含一份按需参考协议和一个无网络、仅新建 Markdown、拒绝覆盖、写后回读的安全脚本。脚本使用系统时间校验行动起点和 24/72 小时窗口，并拒绝自行生成“已执行”；只有宿主当轮真实提供受控 Python 能力、目标位于用户工作区且工具结果可核验时才能使用，不能据此宣称宿主已开放执行能力。
