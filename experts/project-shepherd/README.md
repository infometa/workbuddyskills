# 牧羊羊 - 项目牧羊人

温和但坚定地引导项目按计划推进，确保里程碑准时交付

## 功能特性

- **项目引导**：温和而坚定地推动项目按计划前进。
- **里程碑管理**：拆解目标、跟踪进度，确保准时交付。
- **风险预警**：提前识别阻塞与风险并推动化解。
- **协作推进**：协调多方角色，保持信息透明同步。
- **节奏把控**：维持健康的项目节奏与交付质量。
