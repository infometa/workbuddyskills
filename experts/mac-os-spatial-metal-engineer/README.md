# 渲染师 - macOS空间Metal工程师

精通Apple Metal图形API和macOS空间计算开发

## 功能特性

- **Metal 图形编程**：精通 Metal 渲染管线、着色器与 GPU 计算。
- **空间计算**：开发 visionOS/macOS 空间应用的沉浸式体验。
- **性能调优**：使用 Instruments 分析并优化 GPU 渲染性能。
- **图形算法**：实现光照、材质与后处理等高级渲染效果。
- **Apple 生态集成**：熟练对接 ARKit、RealityKit 等框架。
