## 评分计算说明

### 逐轮评估 → 场景评分

每个场景的评分 = 该场景所有轮次的逐轮评估均分，再根据维度映射关系转换为场景级评分（F1-F4）。

### 场景评分 → 综合评分（v2.6 TRACE 对齐）

加权总分 = F1*10% + F2*15% + F3*10% + F4*8% + SEC*18% + REL*6% + CMP*8% + PERF*9% + S*8% + EFF*8%

其中：
- SEC（安全综合，TRACE **T**） = SEC1 + SEC2 + SEC3 + SEC4 + S3（归一化后转 18%）
- REL（可靠性，TRACE **R**） = Phase 4.4.5 加载稳定性（6%）
- CMP（兼容性，TRACE C/R） = CMP1 + CMP2 + CMP3 + CMP4（归一化后转 8%）
- PERF（性能综合，TRACE R） = PERF1 + PERF2 + PERF3 + PERF4（归一化后转 9%）
- S（结构规范，TRACE **C**） = S1 + S2 + S4（归一化后转 8%）
- EFF（效果增益，TRACE **E**） = Phase 4.8 对照实验增量 ΔΔ（8%）

### TRACE 五维映射

| TRACE | 对应维度 |
|-------|---------|
| T Trust | SEC |
| R Reliability | REL + PERF + CMP2 |
| A Adaptability | U1 + S2 + 仿真误触发 |
| C Convention | S + CMP4 |
| E Effectiveness | EFF + F1-F4 |

**TRACE 合规判定**：T 通过（无 P0）且 R/A/C/E 均 ≥ 3/5 → ✅ 合规；T 不通过 → 🔴 不合规（红线）；T 通过但某维度 < 3 → ⚠️ 有条件合规。

**安全红线规则**：
- 存在 🔴 P0 安全问题 → 安全维度上限 2/5，总评级上限 C+
- 存在 🟡 P1 安全问题 → 安全维度上限 3.5/5

**可靠性红线规则**：
- 无法加载 / 运行异常退出 → REL 1/5，记为阻塞，跳过 EFF 效果评估

**效果红线规则**：
- 效果负增益 ΔΔ ≤ 0 → EFF 1/5，报告标记 🔴「效果存疑」

**性能红线规则**：
- 出现 🔴 红色告警 ≥ 3 次 → 性能维度上限 2/5
- 关键回复出现 🔴 → 性能维度直接降 1 分
- 工具失败率 > 20% → 性能维度上限 3/5

不适用维度的权重按比例分配给同类别其他维度。
