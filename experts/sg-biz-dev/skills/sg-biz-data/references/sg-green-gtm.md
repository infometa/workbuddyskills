## 6. 中国新能源企业 GTM 路径

| 中国企业类型 | 新加坡切入点 | 关键资源 |
|-------------|-------------|----------|
| **光伏制造商** | SolarNova 政府招标 → HDB/政府机构屋顶项目 → 私营工商业 PPA | EMA Solar + SolarNova Tender |
| **储能企业** | 区域电网储能项目 → EMA 试点 | EMA Regional Power Grids |
| **电动车/充电桩** | LTA EV 充电标准 → 与 SP Group 合作 | LTA EV Regulatory |
| **碳资产管理** | CIX 自愿市场交易 → ICC 碳税合规咨询 | CIX + ICC Framework |
| **ESG 咨询/数据** | ACRA/SGX 强制报告的咨询需求 → Green FinTech | ACRA + SGX + Enterprise SG Grant |
| **绿色建筑技术** | BCA Green Mark 认证 → 新建/改造项目 | BCA Green Mark |
