#### 第二层：实际报价标注

> ⚠️ **不得长期保存"中行比工行便宜"或固定 RMB/SGD 费用排名。**
>
> - ICBC 官方汇率页面明确说明其汇率仅为 indicative 且可随时变化
> - BOC 也说明交易时实际汇率可能不同
> - 实际开户、企业汇款和大额 FX **最终以银行实时交易或 RM/分行报价为准**

#### 费率比较规则

银行比较**必须**统一交易场景后再比较：
- 示例："企业账户、SGD→CNY、S$100,000、线上电汇、OUR 费用方式"
- 不同场景（如金额不同、渠道不同、费用承担方不同）**不得直接排名**
- 每次输出必须注明 **查询日期** 和 **"官方公布费率 / 实际银行报价"类型**

### 5.2 商务实务要点（经验语料）

> **标注**：以下内容为"实务建议"，不是法律规定。

**会议礼仪**：
- 新加坡商务会议高度准时，迟到被视为不尊重
- 首次会面通常以简短寒暄开场（天气、航班等中性话题）
- 会议议程通常提前发送，偏离议程需提前说明

**决策习惯**：
- 新加坡企业（尤其跨国公司）决策流程较长，涉及多层级审批
- 中国式"饭桌上拍板"在新加坡较少见
- 书面确认（email/minutes）是决策闭环的必要步骤

**合同习惯**：
- 新加坡偏好详尽书面条款，口头约定不被视为有效
- 中英双语合同以英文版本为准（法定语言）
- 争议解决条款通常指定新加坡国际仲裁中心（SIAC）

**语言陷阱**：
- "没问题" ≠ 完全同意，可能仅是"我听到了"
- "考虑一下" / "再研究" ≈ 婉拒或需要内部讨论
- "We'll get back to you" ≠ 承诺回复，需主动跟进
- 商务邮件英文表达：避免过于直接的拒绝，使用 "we would suggest..." 而非 "you should..."

> 以上经验内容必须标注"实务建议"，不得伪装成法律规定。

### 6.2 销售话术模板

建立"中国能力 → 新加坡客户痛点 → 量化业务价值 → 本地证明 → POC → 风险消除"框架：

1. **识别痛点**：从 SBF 调查提取（当前新加坡企业最关心：成本压力、数字化、人才短缺）
2. **量化价值**：ROI 计算、"如果不用我们的方案，贵司每年损失 S$X"
3. **本地证明**：已有新加坡客户的 case study > 东南亚客户 > 中国客户
4. **POC 方案**：新加坡 B2B 客户普遍期望 Proof of Concept 后再签约
5. **风险消除**：数据安全（PDPA 合规）、SLA 保障、本地支持团队

> ⚠️ B2B 决策链、POC 习惯和信任障碍属于**实务框架**，应标明"经验性建议"，不得伪装成新加坡统一市场规则。

> 新加坡**并非**所有外资收购都统一进行一般性外资审批。

- **SIRA** 重点管理 **critical entities** 的重大投资（如电信、能源、金融等关键基础设施相关实体）
- 同时存在**行业特定 ownership/control 规则**（如 MAS 对金融机构的审批、IMDA 对电信的审批）

### 8.3 竞争审查

CCS 并购申报一般采取 **self-assessment 和自愿通知制度**。但 Competition Act **Section 54** 禁止造成或可能造成实质性减少竞争的并购。

### 8.4 JV 关键条款框架（实务建议，需法律尽调）

| 条款 | 说明 |
|------|------|
| Shareholding 比例 | 无统一最佳比例，取决于贡献和谈判结果 |
| Reserved Matters | 哪些决策需双方一致同意 |
| Board Control | 董事会组成和表决机制 |
| Deadlock 处理 | 僵局时的仲裁/买断/清算路径 |
| ROFR / Tag-along / Drag-along | 股东转让时的权利义务 |
| Put / Call Option | 退出定价机制 |
| Exit 条款 | IPO / Trade Sale / 股份回购条件 |

> ⚠️ **不得给出统一"51/49 最佳股权结构"**。涉及实际交易必须提示法律尽调。

### 12.3 跨境裁决执行

> ⚠️ 不得表述为"中新之间存在统一双边仲裁裁决互认"。
