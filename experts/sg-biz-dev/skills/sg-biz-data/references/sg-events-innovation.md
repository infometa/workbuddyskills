## 4. Open Innovation Network — 企业技术需求

### 4.1 使用场景

寻找明确存在商业问题或技术需求的企业。提取关键信息：
- Challenge Owner（需求方企业）
- Business Problem（业务问题）
- Sector（所属行业）
- Required Solution / Technology Requirement（解决方案/技术要求）
- Deadline（截止日期）
- 合作模式

### 4.2 核心资源

| 资源 | 链接 |
|------|------|
| Open Innovation Network | https://www.enterprisesg.gov.sg/grow-your-business/innovate-with-us/market-access-and-networks/open-innovation-network |
| Explore Innovation Partnerships | https://www.enterprisesg.gov.sg/grow-your-business/partner-with-singapore/innovation-and-startups/explore-innovation-partnerships |
| Market Access & Networks | https://www.enterprisesg.gov.sg/grow-your-business/innovate-with-us/market-access-and-networks |

### 4.3 商务拓展价值

OIN 官方定位即连接企业、创业者、创新者和研究人员开发及测试解决方案。对中国企业而言：
- 可发现新加坡企业对技术解决方案的明确需求
- 可作为进入新加坡市场的 "合作切入点" 而非冷销售
- 挑战信息公开透明，降低了初次接触的门槛

## 5. Global Innovation Alliance — 跨境创新合作

### 5.1 使用场景

寻找跨境创新伙伴、国际科技合作和市场进入支持。重点识别：
- 目标国家
- 合作生态（incubators、accelerators、enterprise partners）
- Acceleration Programme 详情
- 潜在客户连接和合作伙伴连接机会

### 5.2 核心资源

| 资源 | 链接 |
|------|------|
| Global Innovation Alliance | https://www.enterprisesg.gov.sg/grow-your-business/innovate-with-us/market-access-and-networks/global-innovation-alliance |
| GIA Acceleration Programmes | https://www.enterprisesg.gov.sg/grow-your-business/innovate-with-us/market-access-and-networks/global-innovation-alliance/acceleration-programmes |

### 5.3 商务拓展价值

GIA Acceleration Programmes 明确涉及：
- 市场进入辅导（Market Entry Mentorship）
- 潜在客户连接（Potential Client Connections）
- 合作伙伴连接（Partner Connections）

对于希望通过新加坡进入东南亚市场的中国企业，GIA 是优先探索的渠道。

## 6. GeBIZ 政府招标

### 6.1 使用场景

寻找新加坡政府部门采购需求、Tender、Quotation 和公共项目机会。分析维度：
- Current opportunities（当前招标）
- Closed opportunities（历史招标）
- Award status（中标状态）

### 6.2 核心资源

| 资源 | 链接 |
|------|------|
| GeBIZ | https://www.gebiz.gov.sg/ |
| GeBIZ Opportunities | https://www.gebiz.gov.sg/ptn/opportunity |
| GeBIZ Announcements / IPO | https://www.gebiz.gov.sg/announcements.html |
| Guide to Singapore Procurement | https://www.gebiz.gov.sg/singapore-government-procurement-regime.html |
| Supplier Guide 详细版 PDF | https://www.gebiz.gov.sg/docs/supplier_guide_detailed.pdf |
| Supplier Guide 简化版 PDF | https://www.gebiz.gov.sg/docs/Supplier_Guide_Summarised.pdf |
| GeBIZ Awarded Results 说明 | https://www.gebiz.gov.sg/cmw/content/4/page16/View_Oppo_Award.html |

### 6.3 策略准则

- 历史中标企业可作为 **潜在 local partner、system integrator 或 subcontractor 候选**
- **不得**自动认定历史中标企业为合作意向方
- 官方供应商指南明确涉及机会搜索、历史机会及 award status
