# 备课易（Beike Yi）

> 福帮手（FBSir）旗下的本地工作区教学设计决策与成果交付专家。

## 定位

备课易不是“上传文件后生成教案”的云端生成器，而是教师在 WorkBuddy 本地电脑模式下使用的备课助手：

```text
选择备课工作区
→ 选择本次材料
→ 生成材料理解卡
→ 比较少量教学方案
→ 教师选择
→ 交付一个高价值教学成果
→ 写回本地新版本
→ 复核、试教与资产复用
```

## 主要能力

- 读取教师明确选择的本地教材、旧教案、课件、作业摘要和培训材料；
- 将材料区分为事实、教师说明、教学推断、假设和待确认项；
- 生成 2—3 个可比较的教学方案，说明适用条件、代价和失败信号；
- 交付教案草稿、课堂流程卡、课例改造版或分层任务包；
- 写回本地备课工作区的新版本，默认不覆盖原文件；
- 生成教师复核卡、试教复盘卡和可选的模板 / Skill 草案；
- 在权限、格式、模型服务或写回失败时保留任务状态，从当前阶段继续。

## 开始使用

建议使用 WorkBuddy 本地电脑模式。首次使用只需要：

1. 选择一个备课工作区；
2. 选择本次要读取的 1—3 个本地材料；
3. 用一句话说明想解决的教学问题。

示例：

> 读取我选中的教材摘录和旧教案，先告诉我你理解的教学问题，再给出两个教学方案；不要直接覆盖原文件。

## 推荐问法

- “请先读我选择的教材页和旧教案，做一张材料理解卡，标出待教师确认项。”
- “请只修改导入环节，保留教学目标、评价和其他章节不动，给出完整替换段和变更说明。”
- “我已经选定方案，请生成教案草稿和教师复核清单，并写回本地工作区的新版本。”

## 本地文件边界

- “选择本地材料”不等于上传；“写回工作区”不等于下载；
- 选择工作区不等于读取全部文件；每次任务都有明确读取范围；
- 默认新建版本，不覆盖原件；分享、同步、发布和保存为长期资产需要单独确认；
- 本地优先不等于端到端离线，模型服务、网络处理和组织政策以 WorkBuddy 当前设置与正式说明为准；
- 不自动扫描、整理、移动、重命名或删除教师文件。

## 人工复核边界

备课易不能代替教师、备课组或教研员完成学科事实核验、教材版本确认、学情判断、学生最终评价、心理判断、版权确认、学校审批或外部发布。

## 目录结构

- `agents/`：专家角色定义
- `skills/lesson-planning-core/`：材料理解、方案决策、交付、复核和复用流程
- `contracts/`：首值、材料范围、方案决策、写回和交付状态合同
- `examples/`：成功、失败、冲突和越权写入回归案例
- `references/`：本地工作区边界、来源台账和用户可见文案
