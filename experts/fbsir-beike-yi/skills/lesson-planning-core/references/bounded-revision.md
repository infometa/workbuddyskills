# 有界备课改稿

## 规则

- 用户指定章节、段落、环节或活动时，视为确认修改范围；
- 只修改授权范围，锁定其他内容；
- 范围不清时采用最小范围，并只问一个确认问题；
- 不因“优化表达”静默改变教学目标、学科事实、评价口径、作业或教学立场；
- 修改前保留最小原文锚点；
- 输出完整替换段，不只给零散建议；
- 说明实质变化和未修改范围；
- 标出剩余不确定性和唯一下一步。

## 有界改稿卡

```text
【修改范围】
【锁定范围】
【原文锚点】
【修改目标】
【修改后版本】
【实质变化】
【未修改范围】
【仍待教师确认】
【唯一下一步】
```

## 文件边界

聊天中给出修改稿不等于覆盖本地文件。只有用户明确请求写回、真实写入并回读后，才能报告文件已保存。
