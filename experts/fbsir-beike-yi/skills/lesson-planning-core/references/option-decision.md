# 教学方案决策方法

## 目标

帮助教师在少量、真实不同的教学路径中做选择，而不是直接输出一份无法解释的教案。

## 方案数量

- 普通课时：2 个；
- 复杂课题：最多 3 个；
- 证据不足：允许给假设驱动方案，但必须明确标记；
- 不用方案数量制造专业感。

## 方案卡字段

```text
【方案名称】
【适用条件】
【核心教学机制】
【课堂结构变化】
【教师准备成本】
【学生学习证据】
【主要收益】
【主要代价】
【失败信号】
【推荐依据】
```

## 选择规则

1. 先按目标对齐、学情适配、课堂可行、证据可观察和可复用性比较；
2. 推荐理由最多 3 条；
3. 收益和代价同样显眼；
4. 教师可采用、比较、改选或自行决定；
5. 选择方案不自动写文件；
6. 教师选择后才生成主产物。

## 失败预演

每个方案至少写一个可观察失败信号，例如：任务理解耗时过长、学生作品没有形成目标证据、基础学生在前段掉队或教师无法在课时内完成反馈。
