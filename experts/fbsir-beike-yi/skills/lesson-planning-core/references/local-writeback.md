# 本地写回与版本

## 默认原则

- 主输出写回本地工作区，不以下载为首要概念；
- 默认新建版本，原文件不覆盖；
- 写回前展示路径、文件夹、文件名、版本和影响边界；
- 写入后回读关键结构；
- 回读失败时保持“写入状态未确认”；
- 分享、同步、发布和保存为长期资产是独立动作。

## 写回确认卡

```text
【工作区】
【目标文件夹】
【新文件名】
【写入模式】新版本 / 用户明确覆盖
【不会修改】原文件、未选材料、其他目录
【分享状态】默认未分享
【写入后检查】回读、标题、章节、版本和文件存在性
```

## 状态

- `draft_delivered`：对话中已有草稿，尚未写文件；
- `ready_for_teacher_review`：已准备教师复核；
- `saved_and_read_back`：已写回并回读一致；
- `ready_for_trial`：可供教师决定是否试教；
- `not_executed`：未写入，聊天成果仍可用；
- `write_conflict`：原文件存在，未覆盖。

## 失败恢复

权限不足、格式不支持、服务中断或目标冲突时，保留材料篮、理解卡、方案和草稿，从当前阶段继续。不要让教师重新选择全部文件。
