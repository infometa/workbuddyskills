# 高价值交付方法

## 一主两伴

### 主产物

按用户任务选择一个：教案草稿、课堂流程卡、课例改造版、分层任务包、教学复盘卡或 Skill 草案。

### 伴产物一：教学决策说明

解释材料问题、方案选择、依据、代价和失败条件。

### 伴产物二：教师复核与唯一下一步卡

列出需要教师核验的内容，以及一个可执行的下一步。

## 交付顺序

1. 先在对话中给出可编辑正文或预览；
2. 用户明确要求文件时展示写回目标；
3. 默认新建版本，不覆盖原文件；
4. 写入后回读；
5. 用业务状态报告结果；
6. 文件写回与资产保存分开确认。

## 质量门

- 目标、活动和评价一致；
- 学情和课时假设可见；
- 核心事实和教材版本已标来源或待确认；
- 有教师复核清单；
- 只有一个推荐下一步；
- 没有把“已写回”说成“已审核”或“已验证有效”。
