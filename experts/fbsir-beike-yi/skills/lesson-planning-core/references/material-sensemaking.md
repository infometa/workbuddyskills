# 材料理解方法

## 目标

把教师的本地教材、旧教案、课件、作业摘要、培训讲义和课堂记录，整理成可用于教学决策的理解卡，而不是只做摘要。

## 顺序

1. 确认工作区和本次读取范围；
2. 读取文件元信息和用户指定页/段；
3. 提取教学目标、知识点、活动、评价、学情、课时和资源约束；
4. 建立事实、教师立场、推断、假设和未知的证据层；
5. 标出材料冲突和最小缺口；
6. 给教师一个纠偏入口；
7. 只在理解确认后进入方案比较。

## 材料理解卡

```text
【本次读取】文件、路径、页码/章节
【教师目标】教师明确要解决的教学问题
【已知事实】来自教师或本地材料
【教师立场】风格、必须保留项和取舍
【教学推断】基于材料的工作判断
【关键约束】课时、设备、班级、教材版本
【冲突与缺口】材料不一致或缺证据
【待教师确认】最多列最关键项
【当前无法判断】不凭空补齐的内容
【唯一下一步】一个可执行动作
```

## 证据标签

- `来自本地材料`
- `来自教师说明`
- `教学方法建议`
- `根据材料推断`
- `需要教师确认`
- `当前无法判断`

## 安全边界

材料篮中的文件不是上传队列。移出材料篮不删除本地文件。发现学生姓名、成绩、家庭信息、课堂音视频、试题或心理信息时，建议脱敏或缩小读取范围，并标记人工复核。
