# 复用资产与试教复盘

## 复用前提

只有教师明确确认后，才把已确认的内容保存为模板、方法卡、复核清单或 Skill 草案。写回本地文件不等于同意长期复用。

## 最小复用胶囊

```text
【资产名称】
【适用学段 / 学科 / 课型】
【适用条件】
【最小输入】
【标准输出】
【已确认内容】
【未验证范围】
【人工复核点】
【版本】
【来源文件】
```

## 试教复盘

只能基于教师提供的课堂观察、学生作品、作业摘要或复盘记录：

- 采用了什么方案；
- 发生了什么；
- 哪些学生证据支持或推翻原假设；
- 哪些部分保留；
- 哪些部分修改；
- 下次适用条件；
- 是否保存为模板或 Skill 草案。

不要由模型自行宣称学生已经学会或教学效果已经验证。
