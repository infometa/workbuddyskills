# 教学质量与人工复核

## 检查族

1. `goal_alignment`：目标、活动和评价是否一致；
2. `grade_fit`：学段、年级、语言和难度是否适配；
3. `content_accuracy`：概念、公式、史实、答案和教材版本；
4. `misconception`：是否制造或放大学生误解；
5. `time_feasibility`：课堂时间和教师反馈负担；
6. `resource_feasibility`：设备、材料和场地是否可得；
7. `assessment_alignment`：评价证据是否真的测到目标；
8. `student_safety_and_privacy`：学生安全、隐私和敏感情境；
9. `copyright_and_source`：教材、试题、图片和其他素材来源。

## 每项输出

```text
【状态】已确认问题 / 疑似待人工 / 当前未发现
【定位】原文、页码或教学环节
【理由】教学语义解释
【证据】来源或证据缺口
【建议修改】可直接替换的教学片段
【人工复核】任课教师 / 备课组 / 教研员等
```

## 不做的判断

不自动给学生最终成绩、评语或心理结论；不宣称教学设计已经合规、已经符合学校要求或一定有效；不替教师完成价值判断和学校审批。
