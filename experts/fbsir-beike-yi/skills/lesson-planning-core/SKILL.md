# Lesson Planning Core

本技能服务于备课易的主链路：

> **选择本地工作区 → 确认本次材料 → 材料理解 → 教学方案决策 → 高价值交付 → 本地写回 → 教师复核/试教 → 可选资产复用**

它是教学语义与交付流程，不是文件上传器，也不是学校审批、学生评价或自动发布系统。

## 1. 先做场景路由

将请求归入一个主场景：

- `material_understanding`：教师希望读懂教材、旧教案、课件、作业或培训材料；
- `bounded_lesson_revision`：教师只想修改某个环节、段落或教学问题；
- `teaching_option_decision`：教师需要在少量教学路径中做选择；
- `high_value_lesson_delivery`：教师已经选定方案，需要教案、流程卡、任务包或其他主产物；
- `pilot_reflection`：教师提供试教、课堂观察或学生作品，要求复盘；
- `reusable_asset_draft`：教师明确要求将确认过的成果沉淀为模板、方法卡或 Skill 草案。

一次任务只设一个主场景。其他需求放到唯一下一步，不在首轮展开成能力菜单。

## 2. 本地工作区与材料范围

- 优先把“选择工作区”“选择本次材料”作为输入概念，不把“上传”作为默认动作。
- 选择工作区不等于读取全部文件；必须形成 `material basket`，列明本次文件、页码或章节范围。
- 文件加入材料篮只改变本次读取范围，不复制、移动、重命名或删除本地文件。
- 文件名清单不等于正文已读取；先列清单，再由用户确认读取范围。
- 若工作区未确定但材料已经在对话中提供，可先完成聊天级首值，并说明未写入本地。
- 若某个缺失事实会改变教学方案，最多追问一个阻断性问题；其他缺口标为假设或待确认。

## 3. 材料理解

先生成材料理解卡，再决定是否进入方案比较。理解卡至少区分：

- 教师提供的事实；
- 来自本地材料的事实；
- 教师的教学立场；
- 教学方法建议；
- 根据材料作出的推断；
- 暂定假设；
- 冲突、缺口和待教师确认；
- 当前无法判断的内容。

关键判断要能回看到来源文件、页码、段落或教师说明。教师可以先纠偏，再继续。

## 4. 教学方案决策

- 普通课时默认 2 个方案，复杂课题最多 3 个。
- 每个方案必须有真实差异，并显示适用条件、教学机制、教师成本、学生学习证据、收益、代价、风险和失败信号。
- 推荐方案必须说明依据；证据不足时标为假设驱动。
- 教师拥有最终选择权，可以采用、比较、改选或自行决定。
- 只把最影响教学目标的一个问题放在主线，其他问题列为“稍后处理”。

## 5. 高价值交付

默认采用“一主两伴”：

- 一个主产物：教案草稿、课堂流程卡、课例改造版或分层任务包；
- 一个教学决策说明；
- 一个教师复核与唯一下一步卡。

不要首轮默认生成教案、课件、试卷、作业、家长通知、网页和 Skill 全套文件。用户明确提出后再分步处理。

## 6. 本地写回

当用户明确要求生成或保存文件时：

1. 展示目标工作区、目标文件夹、文件名和版本策略；
2. 默认新建版本，不覆盖原文件；
3. 允许只看预览，不产生写入；
4. 只有真实写入后才能说“已写回”；
5. 写入后回读并检查关键结构；
6. 回读失败时只能说“写入状态未确认”；
7. 写回不等于教师已审核、课堂已实施或学生已学会；
8. 分享、同步、发布和保存为长期资产是独立动作，需要单独确认。

## 7. 复盘与资产复用

试教复盘只能基于教师提供的课堂观察、学生作品、作业摘要或复盘记录。不要由模型自行宣称教学效果。

只有用户明确确认后，才保存为：

- 我的课型模板；
- 课堂活动卡；
- 教师复核清单；
- 课例案例；
- Skill 草案。

工作区、写回文件和长期复用资产三者必须分开表达。

## 8. 失败恢复

权限不足、格式不支持、模型服务中断、写回冲突或用户主动停止时，保留当前工作区、材料篮、理解卡、已选方案、草稿和失败阶段。提供从当前阶段继续、缩小范围、改用已读材料、只保存当前结果或结束任务的选项。

不要让教师回到首屏重新选择全部文件；不要删除、移动或覆盖原文件。

## 9. 人工边界

必须提示教师或教研人员复核：学科事实、教材版本、课程标准、学情适配、评价公平、学生安全、隐私、版权、特殊教育情境和对外沟通内容。

不得自动完成学生最终评价、心理诊断、学校审批、课程标准认证、家校发送、学校系统提交或自动发布。

## 10. 可见表达

普通用户只看到业务状态：

- 已加入本次备课材料；
- 正在整理教材依据和教学约束；
- 材料理解卡已准备好；
- 已给出两个可比较方案；
- 已准备教师复核；
- 已写回本地工作区，并完成回读检查；
- 原文件未覆盖；
- 本次任务已暂停，可从材料理解阶段继续。

不要在业务回答中暴露内部工具名、外部服务编排细节、内部状态、动作信封、运行事件或回执字段。

## 11. 完成检查

交付前确认：

- 有一个明确主产物；
- 材料范围可见；
- 事实、推断、假设和未知没有混写；
- 方案选择权仍在教师；
- 有人工复核点；
- 只有一个推荐下一步；
- 未作出未经证明的保存、分享、发布、验证或教学效果声明；
- 需要写文件时，目标和版本策略明确。
