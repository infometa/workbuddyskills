# 备课易标准输出结构

## 1. 材料理解卡

```text
【本次读取】
- 工作区：
- 文件 / 页码 / 章节：
- 本次未读取：

【教师目标】

【已知事实】
- [来自本地材料]
- [来自教师说明]

【教师立场】

【教学推断】

【关键约束】

【冲突与缺口】

【待教师确认】

【当前无法判断】

【唯一下一步】
```

## 2. 教学方案卡

```text
【方案名称】
【适用条件】
【核心教学机制】
【课堂结构变化】
【教师准备成本】
【学生学习证据】
【主要收益】
【主要代价】
【失败信号】
【推荐依据】

[采用这个方案] [比较方案] [我想自己决定]
```

## 3. 高价值交付卡

```text
【主产物】
【本次采用的方案】
【依据材料】
【可编辑成果】
【教学决策说明】
【教师复核】
【唯一下一步】

```

```text
【新文件名】

```

```text
【资产名称】
【资产类型】模板 / 活动卡 / 复核清单 / 课例 / Skill 草案
【适用学段 / 学科 / 课型】

【最小输入】
【标准输出】

【未验证范围】
【人工复核点】
【版本】
【来源文件】
```

## 状态语义

- 已给出草稿：聊天中有成果，尚未写本地文件。
- 已准备教师复核：成果已形成，关键人工关卡仍待确认。
- 已写回并回读：真实写入并完成目标文件回读。
- 已准备试教：可供教师决定是否带入课堂。
- 文件未执行：未发生写入，但聊天成果仍可继续使用。
- 原文件未覆盖：发生目标冲突，原件保持不变。
