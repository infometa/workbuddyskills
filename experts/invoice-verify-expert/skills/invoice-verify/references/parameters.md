# 发票查验参数说明

## 参数列表

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| invoiceTypeNo | String | **必填** | 发票类型代码 |

| invoiceNo | String | **必填** | 发票号码 |
| billingDate | String | **必填** | 开票日期，格式：20220419（8位数字） |
| invoiceAmount | Double | **条件必填** | 发票不含税金额，以元为单位 |
| checkCode | String | **条件必填** | 校验码后六位 |
| invoiceFee | Double | **条件必填** | 发票价税合计，以元为单位 |
| totalAmount | Double | **条件必填** | 总金额，以元为单位 |

## 判参逻辑速查

1. **所有类型**都需要 `invoiceTypeNo`、`invoiceNo`、`billingDate`
2. **发票代码**：01、03、04、08、10、11、14、CZEI013、深圳区块链发票 需要
3. **不含税金额**：01、03、08、深圳区块链发票 需要
4. **校验码**：04、10、11、14、深圳区块链发票 需要。04 类型若为"全电纸质普通发票"，取"全电发票号码"作为校验码
5. **价税合计**：112、113、CZEI013、CZEI112、CZEI212、CZEI313、CZEI312 需要
6. **总金额**：CZEI113 需要

## 常见错误码速查

| 结果码 | 含义 | 排查方向 |
|--------|------|----------|
| 121800 | 查验成功，发票一致 | ✅ 直接通过 |
| 121802 | 查验失败，参数与票面不一致 | 核对开票日期/金额/号码（用乘车日期会触发此错） |
| 121803 | 税局没有查到该发票 | 号码在系统中不存在（可能是样票/OCR 号码识别有误） |
| 121981 | 参数格式有误 | 字段类型/位数不合法（详见各类型备注列） |
| 121984 | 不存在的发票类型 | 检查 `invoiceTypeNo` 拼写（如 CZEI112 写错会触发） |

## OCR 读图容错提醒

从发票图片识别参数时注意：
1. **开票日期 vs 乘车日期**：电子客票有两类日期（乘车日期、开票日期），查验 API 只认**开票日期**（billingDate）
2. **发票号码位数**：CZEI112 必须 20 位；其他电子发票 20 位是常见标准
3. **"01" 容易被 OCR 误读为 "10" 或 "1"**：月日两位数字务必核对
4. **复核机制**：先看是否有"统一社会信用代码"15/18/20 位 + "价税合计"金额 + "发票号码"，三者互相对得上才调用 API
