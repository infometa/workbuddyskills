# 票证核验专家 (Invoice Verify)

专注于商旅费控领域的发票真伪查验专家，支持增值税发票、全电发票、区块链电子发票等 17 种发票类型的核验与明细解析。

## 类型

Agent 型（单个 AI 专家）

## 功能

- 多类型发票真伪查验（17 种）
- 支持发票图片、PDF、文本多模态输入
- 结构化输出发票基本信息和货物/服务明细
- 异常发票状态风险提示

## 使用示例

- 帮我查验这张发票的真伪
- 我有一张增值税专用发票，帮我核实是否真实有效
- 请帮我解析这张电子发票的完整明细信息

## 依赖

- Python 3.6+
- 汇联易查验服务 — 需在汇联易 PC 端「个人设置 → MCP 服务」获取 API Key

## 头像

头像已自动生成在 `avatars/` 目录下。如需替换为自定义头像，要求：
- 格式：PNG（推荐）或 JPG
- 尺寸：512×512 px
- 大小：单张不超过 500KB

## 安装

将专家包解压到平台的专家目录下即可使用。具体路径请参考平台文档中"导入专家包"的相关说明。

## 打包分享

```bash
zip -r invoice-verify.zip invoice-verify/
```
