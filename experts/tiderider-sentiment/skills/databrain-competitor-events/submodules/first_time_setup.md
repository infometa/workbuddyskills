# 首次配置流程

## 第一步：输出欢迎信息

将以下内容**原封不动地**输出给用户：

---

👋 **欢迎使用 DataBrain 竞品活动报告工具！**

在开始之前，需要先完成一次平台配置（仅需一次，之后自动读取）。本SKILL针对不同平台进行了结果输出和展示的优化。

**请告知您当前使用的平台名称**（直接回复即可）：

- `WorkBuddy`
- `Openclaw`
- 其他平台名称

---

## 第二步：规范化平台名称

收到用户回复后，先将输入规范化为标准平台名，再执行后续分支。规则如下：

| 用户输入示例 | 标准化结果 |
|---|---|
| `openclaw`、`Openclaw内网版`、`open claw`、`oc` 等含 "openclaw"（不区分大小写）的变体 | `Openclaw` |
| `workbuddy`、`work buddy`、`WorkBuddy`、`wb` 等含 "workbuddy" 或 "work buddy"（不区分大小写）的变体 | `WorkBuddy` |
| 其他无法归入以上两类的输入 | 保留用户原始输入（去除首尾空白） |

> 规范化后，将标准平台名用于后续所有步骤和 `.env` 写入，不得使用用户的原始输入。

## 第三步：引导用户输入TOKEN

向用户输出以下内容，等待其提供 Token：

> 请提供您的 **DATABRAIN_TOKEN**：
>
> 可前往 [DataBrain 用户中心 - 个人令牌中心](https://databrain.woa.com/v2/user-center/personal-tokens-center)，创建一个新的个人令牌。
> 复制 token 原始值，**不要加** `Bearer ` 前缀，直接发给我：
>
> ```
> DATABRAIN_TOKEN=你的token值
> ```

## 第四步：写入规范化平台名称和TOKEN值
收到 Token 后，写入 Skill 目录下的 `.env`：

```
PLATFORM=<平台名称>
DATABRAIN_TOKEN=<token值>
```

告知用户信息已保存，并展示skill的示例用法：

> ✅ 平台与 Token 已保存！现在可以开始使用了。
>
> **使用示例：**
> ```
> 帮我分析以下游戏2026-01-01的活动表现：
> - Honkai: Star Rail
> - Genshin Impact
> ```
> （可选）若需要通过分析竞品游戏活动，得到服务于某个特定游戏的"启发建议"，可注明 `针对 XX 游戏`；
> （可选）分析游戏活动时，若希望聚焦特定关注方向，可加上 `重点关注` 说明。默认情况下会从活动运营与宣发策略、品牌联动、梗传播方式、UGC 活动运营等方面入手。

## 第五步：配置完成，询问是否继续执行初次输入的任务

复述一遍用户初次输入的任务内容，询问是否继续执行，或是想要重新输入。
