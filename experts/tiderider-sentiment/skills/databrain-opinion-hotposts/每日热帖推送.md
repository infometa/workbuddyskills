热帖推送
4.1 推送设置
时间范围
过去 24h发布的热帖(以推送时刻为锚点向前回溯 24h)。
●09:00 推送 → 覆盖前一日 09:00 至今日 09:00 的帖子
●不做"自然日 00:00–24:00"——会割裂跨零点的热度

热度定义
热度值 = 互动量

4.2  榜单结构
分榜展示,不做全局榜:
┌─ Reddit 榜 ─── Top 5 ───┐
│ 1. 帖子 A · 互动 1,240   │
│ 2. 帖子 B · 互动  980    │
│ 3. 帖子 C · 互动  750    │
│ 4. 帖子 D · 互动  620    │
│ 5. 帖子 E · 互动  510    │
└──────────────────────────┘
┌─ X 榜 ─────── Top 5 ───┐
│ 1. 帖子 F · 互动 4,300   │
│ ...                      │
└──────────────────────────┘


每个订阅的平台出一个榜,每个榜 Top 5(可配置 Top 3 / Top 5 / Top 10)。
为什么分榜:平台间互动量单位不可比。Reddit 1,000 已经是爆款,X 1,000 算中等。混排会让小平台永远占不到位次。

4.3 入榜规则

4.3.1 入榜最低门槛
避免冷门时段推送"互动 50 的 Top 5 帖子",各平台设最低门槛:
平台	入榜最低互动量
Reddit	200
X	500
YouTube / TikTok	1000
Discord / 官方论坛	50
Instagram / Facebook	300

4.3.3 去重规则
同一事件在同一平台可能有多个帖子高互动,榜单容易被单一事件填满。规则:
●同一平台的 Top 5 中,高相似度帖子最多保留 2 条(相似度 = 标题 + 正文关键词重叠)
●被挤出的位置由下一位候选帖子补齐
●推送时标注:"同一话题 N 条相关讨论已合并展示 2 条"

4.4 内容呈现
4.4.1 每条热帖的字段
字段	必选	说明
排名	✅	"1." / "2." 等,直观体现名次
标题	✅	原文标题,不翻译，超出 20个字显示...
作者	✅	用户名 + 粉丝量
互动量	✅	按平台口径的总互动数
发布时间	✅	帖子发布时间
情感标签	✅	正面 / 中性 / 负面(单词级,不给具体分数)
一句话摘要	✅	AI 生成,≤ 30 字,概括帖子主题
链接	✅	直接跳转原帖
2.4.2 AI 摘要的设计要点
●对标题党防御:AI 摘要基于标题 + 正文前 200 字,不只看标题
●语种处理: 原文非中文时,摘要直接输出中文(方便运营快速扫)
●失败兜底:AI 失败时，该模块不做展示
●禁止渲染观点:摘要只描述帖子内容,不做评价
