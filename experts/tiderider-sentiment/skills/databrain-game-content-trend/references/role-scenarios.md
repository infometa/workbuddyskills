# 场景分析体系

根据用户指定的场景（或从 prompt 推断），聚焦对应分析维度。场景分为两大方向：**社媒内容制作**（外部平台内容）和**端内资源跟进**（游戏客户端内功能）。

---

## 场景识别关键词

| 用户说了什么 | 判定场景 |
|------------|---------|
| "社媒"、"TikTok"、"短视频"、"内容"、"表情包"、"挑战赛" | → 社媒内容制作 |
| "端内"、"emote"、"皮肤"、"动作"、"游戏里"、"做进去" | → 端内资源跟进 |
| "BGM"、"音乐"、"音效" | → 两者都评估（社媒BGM + 端内BGM） |
| "买量"、"素材"、"UA"、"投放" | → 社媒内容制作-短视频 |
| "官号"、"整活"、"发帖"、"运营" | → 社媒内容制作-短视频/挑战赛 |
| "KOL"、"达人"、"网红"、"合作" | → 社媒内容制作 |
| "品牌"、"联动"、"跨界" | → 社媒内容制作-挑战赛/互动 |
| "本地化"、"出海"、"海外"、特定地区名 | → 两者都评估，结合地区特性 |
| 未指定 | → 输出全场景，每条推荐标注最适配场景 |

---

## 一级：社媒内容制作

面向 TikTok、Instagram、YouTube 等外部社媒平台的内容制作，不需要游戏客户端改动。

### 短视频/剧情

**核心问题**：这个热梗/趋势如何改编成游戏相关的社媒短视频？

分析维度：
- **梗的可迁移性**：核心叙事结构能否自然嫁接到游戏角色/剧情/玩法
- **游戏化改编角度**：用游戏素材替换原始视频的哪些元素最有效
- **参考脚本框架**：前3秒钩子 → 游戏代入 → 结尾互动引导
- **受众匹配**：参与这个话题的用户与游戏目标用户的重合度

输出格式：
> [社媒-短视频] {一句话创意方案，直接说怎么和游戏结合}

---

### 表情包/贴纸

**核心问题**：这个热梗的视觉元素能不能用游戏素材做成传播力强的表情包？

分析维度：
- **核心视觉元素**：梗的标志性画面/动作/表情是什么
- **文字梗改编**：能否把流行文案与游戏角色/场景结合
- **传播性评估**：做出来后用户会不会主动分享

输出格式：
> [社媒-表情包] {一句话创意方案}

---

### BGM/音效

**核心问题**：这个热门音频怎么结合游戏内容做社媒传播？

分析维度：
- **音频特征**：节奏型、旋律型还是语音梗
- **游戏搭配**：配合什么游戏画面/操作最有传播力
- **版权状态**：音频来源是否可以安全使用

输出格式：
> [社媒-BGM] {一句话创意方案}

---

### 挑战赛/互动

**核心问题**：游戏官号能不能发起或跟进这个挑战/互动形式？

分析维度：
- **参与门槛**：普通用户参与这个挑战需要什么（是否需要游戏内截图/录屏）
- **UGC 潜力**：用户是否有动力自发创作内容
- **标签矩阵**：主标签 + 游戏标签 + 地区标签的搭配

输出格式：
> [社媒-挑战赛] {一句话创意方案}

---

## 一级：端内资源跟进

面向游戏客户端内的功能开发，需要开发资源投入。

**通用分析框架**：对所有端内建议，必须评估以下三个维度：

1. **趋势→资源映射**（基于 `meme_elements` 自动匹配）：

> 完整映射（含社媒方向）见 [data-sources.md](data-sources.md) 的 `meme_elements` 映射表。下表仅展示端内优先映射方向。

| meme_elements | 优先映射到 | 说明 |
|---------------|-----------|------|
| ACTION_GESTURE | 端内-动作/表情 | 舞蹈、手势可做进游戏 emote |
| AUDIO_SIGNATURE | 端内-BGM/音效 | 热门音频引入端内 |
| VISUAL_IDENTITY | 端内-皮肤/装扮 | 视觉梗做成皮肤/喷漆 |
| NARRATIVE_DRIVEN | 不建议端内 | 叙事结构更适合社媒短视频 |
| TEXT_EXPRESSION | 不建议端内 | 文字梗更适合社媒表情包 |
| ABSTRACT_HYBRID | 综合评估 | 复合型梗需 case-by-case |

2. **版权/IP 风险**（参考 safety-filter.md 端内落地风险章节）
3. **文化敏感性**（地区差异 + 宗教/民族因素）

---

### 动作/表情（Emote）

**核心问题**：这个热门舞蹈/手势能否做成游戏内的 emote？

分析维度：
- **动作复杂度**：能否简化到游戏角色骨骼可执行的程度
- **版权归属**：是否有明确的编舞版权方，是否有公开授权争议
- **文化风险**：动作是否涉及宗教仪式、文化符号
- **技术可行性**：参考游戏现有 emote 系统的表现力

输出格式：
> [端内-动作] {创意方案}（⚠️ 风险：{如有}）

---

### 皮肤/装扮

**核心问题**：这个热门造型/视觉元素能否转化为游戏皮肤或装饰？

分析维度：
- **视觉元素提取**：标志性的颜色、图案、服饰特征
- **IP 侵权风险**：是否涉及已注册的商标/设计专利
- **与现有皮肤体系的兼容性**：是否符合游戏美术风格

输出格式：
> [端内-皮肤] {创意方案}（⚠️ 风险：{如有}）

---

### 活动/玩法

**核心问题**：这个热门互动形式能否转化为端内活动或玩法？

分析维度：
- **玩法核心**：互动形式的核心机制是什么，能否映射到游戏系统
- **开发复杂度**：需要新开发 vs 复用现有系统
- **时效匹配**：梗的热度周期 vs 开发上线周期是否对得上

输出格式：
> [端内-活动] {创意方案}（⚠️ 时效：{评估}）

---

### BGM/音效

**核心问题**：这个热门音频能否引入游戏作为 BGM 或音效？

分析维度：
- **音频适配性**：适合做大厅BGM、战斗音效还是 emote 配乐
- **音乐版权**：授权来源、签约可行性、授权范围
- **地区限制**：音乐授权是否覆盖游戏运营的所有地区

输出格式：
> [端内-BGM] {创意方案}（⚠️ 版权：{状态}）

---

## 端内落地方案输出模板

当分析结论包含端内资源建议时，使用以下结构：

```
🎮 端内落地方案：
资源类型：{动作/皮肤/BGM/活动}
创意概要：{一句话说明做什么}
映射依据：{meme_elements} → {资源类型}
⚠️ 风险评估：
  - 版权：{状态}
  - 文化：{评估}
  - 时效：{梗热度预估 vs 开发周期}
```
