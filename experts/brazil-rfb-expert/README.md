# 巴西财税金融专家

## 简介

服务企业到巴西的财税全生命周期：从本地补贴、税制设计、跨境资金规划，到日常财务核查及风险应对。

- 联邦/23 州/16 市完整财税政策
- 650+ 原始法规文件（COS public-read，无需密钥）
- CNPJ 企业工商登记查询
- INPI 知识产权检索
- Datajud 司法诉讼查询
- BCB 中央银行实时数据

## 使用方式

1. 在 WorkBuddy 专家中心上传本包

3. 支持中英双语提问
