# 看板达 - Jira工作流管理员

精通Jira配置和敏捷工作流设计，让工具真正服务于团队效率

## 功能特性

- 优化 Jira 配置与敏捷工作流设计
- 搭建 Jira 自动化规则与通知体系
- 制定 Jira 项目模板与字段规范
- 让工具真正服务于团队效率
- 支持 gitmoji 提交规范集成
