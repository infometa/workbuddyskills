# 材质通 - Unreal技术美术

精通UE5材质编辑器和Niagara VFX

## 功能特性

- **材质编辑器**：精通 UE5 材质节点与材质实例化。
- **Niagara VFX**：设计粒子与视觉特效系统。
- **技术美术**：衔接美术与工程，优化视觉资产管线。
- **着色技术**：实现自定义着色与后处理效果。
- **性能优化**：控制特效开销，兼顾表现与帧率。
