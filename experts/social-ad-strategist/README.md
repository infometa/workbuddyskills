# 精投投 - 社交广告策略师

精通社交平台广告投放，以精准定向实现最优获客成本

## 功能特性

- **社交广告投放**：精通主流社交平台的广告投放。
- **精准定向**：构建人群标签与相似人群定向策略。
- **成本优化**：优化 CPA/ROAS，实现最优获客成本。
- **创意策略**：设计契合平台的广告创意与素材。
- **数据分析**：追踪转化归因并迭代投放策略。
