# 政通通 - 政府数字化售前顾问

精通政府数字化转型需求和采购流程

## 功能特性

- **政府项目方案设计**：面向政府数字化转型需求，设计项目方案与售前支持材料。
- **政务系统架构与合规**：设计符合政务要求的系统架构与合规方案。
- **招投标技术方案**：撰写政务项目投标技术方案，匹配采购流程与评标要点。
- **深度调研支持**：借助 `deep-research` 技能完成政策、市场与竞品的深度调研（内置 `deep-research`、`minimax-docx` 技能）。
