# 路演研究报告标准结构

8章 + 封面 + 目录 + 免责声明。章节编号不可变。

## 章节层级

- 一级标题（HeadingLevel.HEADING_1）：章标题
- 二级标题（HeadingLevel.HEADING_2）：节标题

## 标准结构

```
封面
  - 标题："公司名 资本市场路演时间线研究报告"
  - 副标题：年份范围
  - 公司代码
  - 报告日期

目录（TOC）

第一章 公司概况
  1.1 基本信息表（公司名称/代码/行业/总部/上市日期/主要业务）
  1.2 近三年关键财务数据表（年度营收、归母净利润、毛利率、研发费用）

第二章 三大年度业绩说明会
  2.1 年度业绩说明会对比表（日期/类型/参与方/核心要点）
  - 通常3场：对应2024、2025、2026年度

第三章 2024年时间线
  表格：编号 | 时间 | 活动类型 | 主要内容/特点
  要点总结段落

第四章 2025年时间线
  4.1 上半年时间线（表格同上）
  4.2 下半年时间线（表格同上）
  各节+要点总结段落

第五章 2026年时间线
  表格：编号 | 时间 | 活动类型 | 主要内容/特点
  要点总结段落

第六章 主题演变
  按时间分段的主题变化描述段落
  + 关键战略转折点汇总表

第七章 统计分析
  7.1 活动频次统计（bullet列表或段落）
  7.2 主要参与机构类型（bullet列表，4类：境内公募/境外机构/券商研究/其他机构）
  7.3 核心接待人员（表格：姓名/职务/出席频率/备注）

第八章 总结与展望
  8.1 路演活动整体特征（bullet列表，5条）
  8.2 展望与关注要点（bullet列表，下半年+长期）

页末：免责声明
```

## 表格辅助函数

```js
function buildTimelineTable(rows) {
  const header = ["编号", "时间", "活动类型", "主要内容/特点"];
  return buildTable([header, ...rows]);
}
```

## 重要提醒

- 7.2、8.1、8.2 使用 `numbering: { reference: "bullet-main", level: 0 }` 的 bullet 列表
- 这些 bullet 文本必须是纯字符串，不得用 `["..."]` 包裹
- 使用 `Microsoft YaHei` 字体
