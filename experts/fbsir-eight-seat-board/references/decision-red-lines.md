# 经营决策筛查信号与阈值使用规则

> 本文件提供的是筛查信号，不是通用红线。任何信号命中都仅触发核验，不自动定级，也不得单独决定赞成、反对、交易否决或法律结论。

## 一、阈值分类

- **权威阈值**：来自当前适用且已核实的法律法规、监管规则、合同、授信约束、安全标准、公司章程或经正式批准的内部政策。引用前必须确认现行有效性与适用范围。
- **情景阈值**：为压力测试、试点止损或经营观察而设的假设条件。它不是外部强制标准，必须由用户数据、企业承受力和决策目标校准，并明确标注“情景假设”。
- **经验信号**：用于提示补数或进一步核验的方向，不带默认数值，不得包装成行业标准或法律红线。

## 二、每次引用的必填字段

任何席位引用阈值或触发条件时，必须同时填写：

| 字段 | 要求 |
|------|------|
| 信号编号与名称 | 使用本议案内唯一编号，名称应描述变量而非预设结论 |
| 阈值类型 | 权威阈值 / 情景阈值 / 经验信号 |
| 当前值与口径 | 写明单位、统计范围、币种、会计口径或计算方法；未知就写“待补” |
| 触发条件 | 填入本议案实际采用的条件；不得照搬未校准的网络经验值 |
| 适用法域与主体 | 涉法律、税务、劳动、数据或跨境事项时必填 |
| 依据来源 | 法律条文、合同条款、授信文件、公司政策、用户材料或公开数据的可追溯索引 |
| 数据日期 | 当前值和外部数据各自的日期或期间 |
| 校准责任人 | 用户指定的业务、财务、法务、安全或治理责任人；未指定写“待确认” |
| 复核日期 | 最近一次核验日期，以及规则或数据何时需要再次复核 |
| 命中后的动作 | 补数、复核、压力测试、暂停高风险执行或提交执业专业人士，不得直接自动定级 |

## 三、分域筛查信号

### 现金流与资本

- 现金储备相对刚性支出的覆盖能力，以及现金流断点。
- 应收账款相对合同账期、历史回款和客户信用的偏离。
- 债务偿付、担保和授信约束是否逼近合同触发条件。
- 客户、供应商、融资来源或收入结构是否过度集中。
- 大额投资是否超出公司已批准的风险预算或流动性承受力。

### 税务、合规与交易

- 税负、申报、发票、社保或个税口径是否与适用规则及真实业务一致。
- 关联交易是否完成识别、授权、披露与公允性核验。
- 合同相对方、实际控制人、受益所有人及签约权限是否已核实。
- 重大交易是否完成与风险相称的法律、财务和业务尽调。
- 回购、担保、连带责任、数据使用和争议解决条款是否触发已核实的合同或法律约束。

### 组织与人事

- 关键岗位流失、汇报跨度、激励稀释或交接安排是否偏离公司已批准政策。
- 行为记录与访谈陈述是否冲突；冲突只触发核验，不自动判定任何一方失实。
- 招聘、解聘、降薪、竞业和股权激励是否需要 HR、法务及有权人复核。

### 数智化与数据

- 项目是否有业务目标、验收标准、退出条件和完整成本口径。
- 自动化决策是否保留适当的人工复核、申诉与审计轨迹。
- 供应商条款是否明确数据归属、模型训练使用、保密、迁移和退出安排。
- 个人信息、重要数据或跨境处理是否已确认适用法域、处理角色与合法性基础。

## 四、引用模板

```text
[S-编号] 信号名称：
- 类型：权威阈值 / 情景阈值 / 经验信号
- 当前值与口径：
- 本议案触发条件：
- 适用法域与主体：
- 依据来源：
- 数据日期：
- 校准责任人：
- 复核日期：
- 命中后的核验或人工审批动作：
- 结论边界：仅触发核验，不自动定级
```

未能填齐权威性、适用性或时效字段时，只能作为待验证假设进入证据台账，不得称为“红线”。
