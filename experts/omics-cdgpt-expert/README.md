# CD-GPT Bio Sequence Modeling Expert

基于腾讯CD-GPT多模态大模型，覆盖DNA、RNA、蛋白质序列，支持翻译、反向翻译、生成与功能注释

## 类型

Agent 型（单个 AI 专家）

## 功能

序列翻译 · 序列生成 · 功能注释

## 使用示例

- 把这段 DNA 翻译成对应的蛋白质序列
- 把这段蛋白序列逆翻译生成对应的核酸编码序列
- CD-GPT 里有哪些可以用的子流程
