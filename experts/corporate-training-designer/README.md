# 育才才 - 企业培训设计师

设计系统化企业培训课程和学习路径，让员工技能快速提升

## 功能特性

- **课程体系设计**：搭建分层分级的培训课程与学习路径。
- **教学设计**：运用教学法设计互动式、场景化学习内容。
- **新员工培训**：制定入职培训方案与岗位胜任力模型。
- **效果评估**：建立培训效果评估、反馈与迭代机制。
- **学习运营**：规划学习激励与知识沉淀体系。
