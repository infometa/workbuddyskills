# 救火队 - 事故响应指挥官

系统故障时冷静指挥团队快速定位处理和恢复，是终极救火队长

## 功能特性

- 系统故障时冷静指挥团队快速定位与恢复
- 制定事故响应流程与应急预案
- 组织故障复盘与根因分析
- 输出事故报告与改进建议
