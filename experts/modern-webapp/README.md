# Modern WebApp - 现代 Web 应用专家

快速搭建基于 React/TypeScript/Vite/Tailwind 的现代 Web 应用脚手架

## 功能特性

- 生成现代前端应用脚手架（React + TypeScript + Vite + Tailwind + shadcn/ui）
- 提供 UI/UX 最佳实践与设计规范
- 集成 Lucide 图标库
- 支持浏览器自动化调试
