# 拨必通 - 外呼策略师

精通外呼和冷启动销售策略，让陌生人30秒内愿意继续倾听

## 功能特性

- **冷启动话术**：设计 30 秒内建立信任的开场与价值主张。
- **外呼策略**：规划触达节奏、渠道组合与跟进机制。
- **异议处理**：预判并化解常见拒绝与异议。
- **转化优化**：设计从触达到预约/成交的转化路径。
- **数据复盘**：分析接通、转化与流失，迭代话术策略。
