| # | 场景 | 核心价值 |

### 场景一：智能客服与售后自动化
- 核心能力：自动识别订单号调取购买记录、关联退换货政策判断是否符合条件、一键生成工单对接物流、7×24在线、复杂问题自动升级转人工
- 对话示例：客户问"衣服小了能换吗"→ AI 自动定位订单#20240528001 → 确认换货码数 → 生成换货工单 → 告知上门取件时间

### 场景二：私域直播全链路
- **播前（1小时→15分钟）**：自动生成直播脚本（话术框架+互动节点）、智能排品（基于历史销售推荐上品顺序）、预热文案一键生成（朋友圈+社群+公众号）
- **播中**：实时弹幕监控识别高意向客户推专属优惠券、智能商品讲解（按实时库存调整话术）、突发状况3秒给应对话术
- **播后**：数据自动汇总（观看/峰值/成交转化）、用户分层打标（谁看了没买/谁加购物车）、复购跟进（自动推回放+限时优惠给未成交客户）

### 场景三：商品文案批量生成（落地最快，1天上手）
输入一个产品 → 批量输出：天猫详情页（品牌调性+卖点拆解+尺码表）/ 小红书笔记 / 朋友圈文案 / 社群推送（拼团话术+接龙模板）/ 直播话术（3分钟讲解框架+互动预案）
- 自动提取卖点匹配人群痛点、支持批量、保持品牌语言风格一致
- 内容团队 5人 → 1人+WorkBuddy

### 场景四：数据洞察与决策辅助
- 一句话分析："帮我分析上周销售数据，对比上上周，找出下降最多的品类和上升最快的单品"
- 自动化报表：日报（每日9:00 GMV/订单量/客单价/TOP10单品）、周报（周一 品类趋势/竞品动态/投放ROI）、活动复盘（目标达成率/爆品分析/用户画像）

### 场景五：社群运营与CRM
- 日常互动：定时群发早安/天气/行业资讯、常见问题自动应答、活跃度监测（沉默用户自动触发唤醒）
- 精准触达：客户标签体系（购买偏好/消费能力/活跃度/生命周期）、个性化推荐、复购提醒（计算消耗周期自动推送）

### 电商落地路径建议
第1天文案生成 → 第3天智能客服 → 1周数据报表 → 2周社群运营 → 1月私域直播全链路

## 二、跨境电商 13 个场景（OZON 实例，含指令）

> 真实案例：中俄跨境电商（OZON 平台，宠物电子用品），每步附"给WorkBuddy说的话"

### 调研阶段（还没投钱先探路）
**① 竞品价格监控**
```
帮我监控OZON上搜索关键词'умный ошейник'的前20个产品，每天记录一次价格、评分、评价数量，保存到腾讯文档表格，如果某个竞品降价超过10%就微信通知我。
```
（browser-use 技能抓取 → 腾讯文档 → 规则触发微信通知）

**② EAC 认证合规咨询**
```
帮我找3家有对俄EAC认证资质的代理机构，整理他们的联系方式、报价范围、办理周期，并帮我起草一封询盘邮件（中文+俄文对照）。
```
（AI 锁定 TR CU 004/2011 和 TR CU 020/2011 法规号，生成认证需求说明+询盘模板）

**③ 利润测算模型**
- 把采购成本、物流报价、OZON佣金比例丢给 AI → 生成腾讯文档含所有成本项和自动计算公式（采购180元+运费48元+佣金12%+汇率实时抓取 → 净利润自动更新）
- ⚠️ 数据准确度取决于输入，正式发货后要回来修正

### 启动阶段
**④ 俄语 Listing 自动生成**
```
帮我生成宠物GPS电子项圈的OZON俄语Listing: 产品功能: GPS定位、电子围栏、IP67防水、续航7天、支持App。目标关键词: умный ошейник, GPS ошейник для собак, влагозащита。请生成: 标题(60字符内)、5条Bullet Points、详细描述、以及OZON后台的Search Term关键词(共255字符内)。
```
（比 Google Translate 地道；专业性强内容建议花 50-100 元找母语者校对）

**⑤ 产品主图/包装设计**
```
帮我生成一张宠物电子项圈的主图：白色背景，项圈正面展示，有GPS图标和防水IP67标识，俄文标语Безопасность вашего питомца，电商风格，比例1:1。
```
（AI 图用于定设计方向/给设计师 Brief，不直接商用）

**⑥ OZON 店铺注册指导**：让 AI 按 SOP 一步步讲注册材料、填写步骤、审核不通过原因和申诉方式

### 日常运营
**⑦ 俄语客服话术**：把客户问题原文丢给 AI 生成俄语回复（不用雇月薪 8000 的专职俄语客服）

**⑧ 广告数据分析**
```
这是我OZON Ads过去30天的数据（上传Excel文件），帮我分析：哪些关键词ACOS超过35%，建议如何处理；哪些产品广告转化率最高，建议增加多少预算；整体广告策略下一步怎么调整。
```
（建议不能全信，但可排查烧钱关键词——曾发现 ACOS 60% 的词没停）

**⑨ 销售数据周报自动生成**：自动化任务每周一9:00自动抓取上周销售数据生成周报（销售额/订单量/客单价/环比/ACOS/库存预警）
- ⚠️ 自动抓取需店铺 API 权限；无 API 时用浏览器自动化模拟登录（账号密码妥善保管）

**⑩ 库存预警与补货提醒**
```
我的宠物项圈SKU目前库存85件，过去7天日均销售4.2件，物流时效15天，安全库存30天，帮我计算：什么时候需要补货，建议补货多少件?
```

### 增长阶段
**⑪ VK/Telegram 站外引流内容**：俄罗斯用户主阵地是 VK 和 Telegram（非 Ins/FB），生成俄语 VK 帖子（280字符+话题标签）、TG 频道消息、晒单配文、短视频脚本

**⑫ 新品选品分析**：让 AI 分析平台市场容量、竞争强度、价格区间，**抓取竞品 1-2 星差评提取高频负面关键词**（知道竞品在哪翻车，产品就在哪发力）——选品最有价值的一招

**⑬ 净利润月度核算**：列完整隐形成本清单（退款损耗/广告超支/汇率损失/包装耗材），每月自动出净利润报告
- ⚠️ 核心提醒：跨境"账面盈利、实际亏钱"就是因为没算隐形成本，至少加退款+广告超支+汇率损失三项

### 6 个自动化任务模板
| 任务 | 频率 | 内容 | 难度 |
|---|---|---|---|
| 竞品价格监控 | 每天1次 | 抓Top10价格，变动时记录通知 | 中等 |
| 销售周报 | 每周一9:00 | 汇总销售/广告/库存发微信 | 较难 |
| 库存预警 | 每天1次 | 可售天数<15天自动通知 | 简单 |
| 汇率预警 | 每小时 | USD/RUB、CNY/RUB波动>5%通知 | 简单 |
| 评价监控 | 每天1次 | 新差评(3星及以下)第一时间提醒 | 中等 |
| 利润月报 | 每月1日 | 汇总上月完整财务算净利润 | 简单 |

### WorkBuddy 做跨境目前不能做的事（需人工）
1. 不能直接操作 OZON 后台（API 权限有限）
2. 不能替代俄语母语校对（尤其合规类内容）
3. 不能处理物流异常（丢件/清关找货代）
4. 不能替你做最终决策（给建议，你做主）

## 三、电商竞品动态日报自动化（含避坑）

### 搭建 4 步
1. **腾讯文档数据底座**：新建在线表格，按竞品分 Sheet，列：SKU编号/名称/价格/活动标签/库存状态/采集日期/备注
2. **配置自动化任务**：左侧「自动化」→新建→定时触发→每天8:30执行；提示词列出竞品 URL 和 SKU，要求写入腾讯文档，输出格式严格匹配列名
3. **配连接器（最易忽略）**：腾讯文档连接器（读写数据）+ 沙箱浏览器权限（访问网页）
4. **试跑验证**：手动触发检查写入正确性，选3个SKU人工核对；配结果推送（企微群日报摘要+文档链接）

### 效果对比
手动 3小时/日 → 自动 40分钟/日（首次搭建2小时）；SKU覆盖 20→50 个；出错率 15%→8%

### 三大隐藏限制（官方文档没写）
1. **反爬虫**：验证码/动态渲染/频率限制→可能拿不到数据，优先选无反爬竞品
2. **SKU 上限**：超50个受上下文限制，拆2个任务分批跑
3. **写入延迟**：5个竞品同时写入偶现5-10秒延迟

### ⚠️ 翻车实录与避坑
竞品改了页面结构（价格字段"¥299"变"特惠价¥299"）→ 采集规则跟着调：更新提示词加"去掉文字前缀只保留数值"
- 竞品页面每季度至少改1次版，改版=采集规则要跟着调
- 适用条件自查：竞品页面3个月没大改？SKU月变动<20%？竞品≤5个？有2小时搭建时间？每月花30分钟检查？

## 一、人力资源规划（20 个用法精选）

### 用法1：批量盘点全公司人力结构
上传员工花名册+组织架构图+岗位清单 → 设定员工编号为唯一索引 → 指令：字段智能匹配、重复人员筛查、缺失字段补全、异常标注 → 自动输出全员基数/年龄分层/司龄分布/职级结构/用工类型 → 异常台账+可视化图表（直接用于管理层汇报）

### 用法3：根据业务数据倒推科学人员需求
上传在岗台账+营收+订单+人均产能 → 搭建「部门业务总工作量÷标准人均产出」测算模型 → 自动输出三套方案：现有效率配置/效率提升5%精简/效率提升10%最优 → 留存公式和数据来源，审批可举证

### 用法4：一键生成保守/基准/增长三套人力规划方案
搭建《人力规划核心参数配置表》（三类业务增长系数+招聘周期+人力成本单价+到岗节奏）→ 自动并行生成三套完整方案（新增编制/月度到岗排期/全年度人力总成本/核心岗位人才缺口）→ 后续仅微调参数一键更新全量

### 用法5：自动精准测算年度人力成本预算
上传在职台账+薪酬等级标准+福利制度+调薪方案+新增编制 → 先生成核算规则白皮书确认口径 → 按员工个体+自然月度双维度拆解 → 输出月度明细台账/部门分级汇总/全年总表/成本异常预警

### 用法11：搭建关键岗位风险地图
生成《关键岗位风险评分量表》（业务影响权重/外部替代难度/招聘周期/知识集中度/后备成熟度）→ 部门填报后自动量化分级 → 高风险清单+岗位知识沉淀/人才培养/外部储备建议

### 用法15：自动生成年度人力规划汇报报告+管理层PPT
建【标准汇报模板】【原始数据】两文件夹 → AI 先输出高管汇报逻辑大纲（HR 确认）→ 自动填充数据+可视化图表 → 一键输出 Word 正式报告+高管汇报 PPT

### 用法16：常态化跟踪人力规划落地执行进度
绑定年度规划台账+实时花名册+月度成本报表为固定数据源 → 配置自动化按月更新编制使用率/招聘完成率/预算偏差率/结构达成率 → 封装为 Skill，仅替换数据文件即可一键生成月度复盘

## 二、招聘与配置（20 个用法精选）

### 用法21：按需定制标准化岗位说明书（JD）
上传部门业务目标+权责清单+用人经理访谈纪要 → AI 先拆解岗位要解决的核心业务问题 → 输出岗位使命/核心职责/可量化产出 → 任职条件分三类：硬性必备/优先加分/入职后可培养

### 用法24：大批量智能简历初筛
JD+批量简历导入专项项目 → 把筛选标准转化为量化评分量表 → 自动萃取学历/履历/岗位匹配/项目经历/数据化成果 → 输出：匹配综合结论+原始佐证依据+面试待核实风险点（**AI 仅辅助研判，面试准入决策权保留给 HR**）

### 用法25：从简历萃取可视化能力佐证材料
按五大字段拆解：工作任务/执行行动/落地结果/个人权责角色/量化数据证据 → 区分客观事实/模糊美化/关键缺失三类 → 存疑信息自动转面试追问题目 → 生成一页式候选人能力证据卡片

### 用法28：针对候选人履历定制专项面试追问题库
导入 JD+能力素质模型+完整简历 → 针对每项核心能力生成：基础原题/深度追问/反向风险验证 → 绑定真实履历场景 + 优质作答判定标准 + 高危风险信号

### 用法32：关键岗位 Offer 薪酬多方案智能测算
上传薪酬带宽+候选人预期+同岗位薪酬+福利体系 → 自动生成三套方案：保守控本/标准合规/高薪竞争 → 拆解月固定薪酬/年度综合现金/福利/综合用工成本 → 预警预算超标和内部薪酬倒挂

### 用法34：全自动生成标准化全链路招聘漏斗
统一候选人状态标签（已触达/已邀约/已预约/按时到面/Offer通过/正式入职）→ 去重后生成可视化漏斗 → 测算各环节转化率/平均停留周期 → 高亮低于均值的薄弱节点

### 用法37：多平台适配版 JD 批量生成
标准母版 JD+雇主品牌卖点 → 生成四类版本：长文本招聘平台标准版/轻量化社交传播版/简洁员工内推版/专业猎头对接专项版 → 核心职责和薪酬福利全局统一

### 用法40：搭建长效可迭代企业私有人才储备库
归集历史落选候选人台账 → 自动打多维标签（适配岗位/行业/技能/职级/属地/薪酬预期/入职意愿）→ 新增候选人自动归档迭代 → 规避重复检索重复破冰

## 三、AI 招聘流水线完整实战（叶小钗，简历处理 8小时→0分钟）

> 核心公式：**技能（怎么做）+ 连接器（外部系统交互）+ 自动化（什么时候做）** = 招聘流程全自动

### 招聘流程拆解（哪些环节给 AI）
| 环节 | 是否适合AI | 说明 |
|---|---|---|
| 简历自动化采集 | ✅ AI | 从邮箱/平台获取 PDF/Word |
| 简历内容识别 | ✅ AI | 提取姓名/联系方式/学历/经历/技能/项目 |
| 结构化存储 | ✅ AI | 写入人才跟踪表 |
| 简历评分 | ✅ AI | 按事先定义的评分标准 |
| 面试问题准备 | ✅ AI | 按简历内容生成 |

### ⑤ 封装为 Skill（hr-resume）完整流程
1. 阅读附件信息 → 2. 结构化提取 → 3. 按岗位名在飞书拿评分标准和岗位描述 → 4. 评分+总结+面试问题 → 5. 写入飞书多维表 → 6. 得分>8分自动推送业务负责人

**落地节奏建议**：不必一开始覆盖全流程，先把高频环节跑通，效果稳定后再逐步接入后续流程（渐进式推进更稳妥）。
**校准提醒**：岗位要求会变、负责人判断会变，评分标准要同步调整（如推了10份高分只有2份符合，说明评分标准需调整）。
