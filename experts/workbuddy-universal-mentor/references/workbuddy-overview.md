## 一、WorkBuddy 是什么

WorkBuddy 是腾讯云 CodeBuddy 团队推出的 **AI 原生桌面智能体工作台**，2026年3月正式发布。核心定位不是单纯的"聊天AI"，而是"干活AI"——能实际执行任务、操作本地文件、交付可验收的结果。

**一句话定义**：你说指令 → AI规划拆解 → 自动操作电脑执行 → 交付可验收文档/报表/PPT成品

**与传统 AI 对话工具的根本区别**：

| 对比维度 | 传统对话AI（ChatGPT/Kimi） | WorkBuddy |
|---|---|---|
| 核心能力 | 输出文字建议 | 实际执行任务、操作文件 |
| 文件处理 | 无法读写本地文件 | 授权后直接读写本地文件 |
| 多步骤任务 | 需要分步手动操作 | 自主规划、链式执行 |
| 交付方式 | 文字回复 | 生成可直接使用的文档/图表/代码 |
| 远程操控 | 不支持 | 手机端远程指挥电脑干活 |

**产品家族生态（腾讯三剑客）**：
- **WorkBuddy**：企业/职场桌面办公智能体（文档处理、数据分析、汇报制作、流程自动化）
- **QClaw**：个人本地AI助手（微信端，日常生活、手机远程操控）
- **CodeBuddy**：代码开发智能体（代码生成、调试、项目开发）
- 三者共享 OpenClaw 技能生态，技能可互相迁移复用

## 二、四大核心能力

1. **理解自然语言**：一句话描述任务，AI自动拆解并执行多步骤操作。任务描述越具体输出越精准，建议包含四要素：目标（要生成什么）、输入（处理什么文件/数据）、格式（Word/Excel/PPT/HTML）、约束（风格、字数、谁来看）
2. **自主规划执行**：支持长链条复杂任务自主执行，自动完成"读取文件→数据清洗→汇总计算→图表生成→PPT排版→文件发送"全流程闭环。核心流程：下达指令→确认计划→执行反馈（沙箱环境实时进度）→交付结果
3. **多模态任务处理**：支持文本、图片、音频、视频输入，实现 OCR识别、语音转文字、图片生成、视频制作
4. **本地文件操作**：这是与市面上99% AI工具最大的区别。授权后可读取操作本地文件夹——批量重命名、按规则整理、提取信息、格式转换。操作方式：@引用本地文件 / 拖拽文件到输入框 / 任务开始时选择工作空间目录

## 三、三大工作模式

| 模式 | 适用 | 积分消耗 | AI行为 |
|---|---|---|---|
| **Ask**（只聊不动手） | 纯咨询、信息查询、概念解释 | 最低（10-30积分） | 只回答问题，不操作文件 |
| **Plan**（先规划再执行） | 复杂任务、需要确认方案再动手 | 中 | 先分析需求给出方案计划，确认后再动手 |
| **Craft**（直接干活）最常用 | 你很清楚要什么，让AI直接交付结果 | 视任务而定 | 一句话→拆解→规划→执行→交付成果 |

**推荐习惯**：日常80%任务用Craft模式，不确定方案时切Plan确认，纯查资料用Ask省积分。

## 五、安装与配置

- **系统要求**：Windows 10/11 或 macOS 10.15+；存储约150-180 MB；需要网络
- **官网**：https://www.codebuddy.cn
- **Windows**：下载 WorkBuddySetup.exe（150-180MB）→ 按向导安装 → 登录腾讯账号（建议企业微信或QQ）→ 首次使用授权本地文件夹访问
- **macOS**：下载 WorkBuddy.dmg → 拖入应用程序 → 如提示"无法打开"，进入 系统设置→安全性与隐私→允许 → 登录授权
- **模型选择建议**：
  - 日常办公 → 混元模型（响应快）
  - 复杂任务 → DeepSeek / GLM（理解强）
  - 创意写作 → Kimi（文本质量高）
  - 超长文档 → Kimi
  - 代码开发 → DeepSeek

## 六、界面功能详解

- **左侧边栏**：任务列表（按文件夹分组+搜索）、专家入口（140+领域专家）、技能（Skills）市场、连接器（MCP管理）、自动化（定时任务）、用户头像/个人中心（积分、邀请好友、Claw设置）
- **中间对话区**：任务标题栏、消息列表（实时显示执行进度）、输入框（支持@引用文件、拖拽上传）
- **右侧结果区**：产物展示（文件/图表/报告预览）、全部文件列表、变更记录（实时）、实时预览（PPT/图表等）

## 七、Skills 技能系统

- 技能是 WorkBuddy 的插件机制，安装不同技能包，AI 获得不同专业能力（就像手机装微信能聊天、装抖音能刷视频）
- **内置分类**：文档处理（PPT生成/Word/Excel/思维导图）、数据分析（报表/可视化/统计）、图像视频（AI绘画/封面/视频）、金融投资（股票/基金/行情）、专业领域（专利/法律/需求分析）
- **安装方式**：①对话直接说"帮我安装XX技能"；②左侧技能市场搜索安装；③SkillHub网页版复制安装指令；④CLI命令行 `npx clawhub@latest install <技能名>`；⑤GitHub `npx skills add <作者>/<仓库> --skill <技能名>`
- **自建技能**：点击"添加技能"，用内置 skill-creator 辅助创建，自然语言描述想要的技能即可生成专属技能包
- **技能开发（进阶）**：通过 .codebuddy-plugin/plugin.json 定义插件元数据，skills/ 目录添加AI技能模板，commands/ 目录添加自定义斜杠命令

## 八、专家中心

- **什么是专家**：针对特定领域深度调优的AI分身，每个专家背后灌入对应领域的专业知识体系和实战方法论，相当于一人调用多角色AI团队并行处理复杂工作
- **专家分类**：内置140+垂直领域AI专家，覆盖12大行业（产品/设计/开发/营销/金融/法律/HR/运营等）
- **使用方式**：左侧菜单"专家"→按分类浏览或搜索→直接对话→对话中支持快速切换
- **专家团模式**：多个专家并行协作处理复杂任务（一个分析数据、一个生成报告、一个排版美化，同时开工）

## 九、连接器系统（MCP）

- Skills是给AI装"技能"，MCP连接器是给AI装"手脚"，直接接入外部工具和服务
- **已支持**：腾讯生态（腾讯文档/会议/QQ邮箱/企业微信/TAPD/乐享）、代码托管（GitHub/CNB）、协作工具（飞书/钉钉/Notion/金山文档）、云存储（百度网盘/微云）、商业数据（企查查/天眼查/销售易CRM）
- **连接后能力**：从腾讯会议拉取纪要生成周报、读腾讯文档加工存回、GitHub拉代码分析提交PR、企微群自动推送任务结果
- **配置方式**：连接器管理页面→找到服务→点击授权→开启Trust，无需开发

## 十、自动化工作流

- **什么是自动化**：让 WorkBuddy 自动定期执行重复性工作，到点自动执行，不用守着
- **调度方式**：DAILY每天定时 / WEEKLY每周定时 / MONTHLY每月定时 / ONCE一次性
- **额度**：个人体验版3个/月（限时可至99）、标准版15个/月、高级版30个/月、旗舰版更多

## 十一、小程序功能

3. 优先消耗临近过期积分（积分页面查看过期倒计时）
4. 用自己的API Key（配置DeepSeek/OpenAI的Key，不消耗WorkBuddy积分）

## 十四、FAQ 速答

- **WorkBuddy免费吗**：有免费体验版，新注册送2000积分，轻度办公够用；付费版99元/月起
- **不联网能用吗**：需要网络调用AI模型，离线仅支持简单文档处理
- **文件安全吗**：沙箱隔离机制，本地文件操作需授权，腾讯云安全体系背书
- **能替代ChatGPT/Kimi吗**：定位不同——它们是对话型AI，WorkBuddy是执行型AI智能体（读文件、写文件、连外部服务、自动执行多步骤）
- **支持移动端吗**：2026年6月已推出移动端，微信小程序"腾讯WorkBuddy"远程指挥电脑干活
- **和QQ小龙虾区别**：WorkBuddy面向办公场景（复杂任务/文件操作/企业集成），小龙虾面向生活场景（轻量任务/QQ内集成）
