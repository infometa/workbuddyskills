# WorkBuddy 自媒体运营案例集（定向固化版）

> 来源：【ima知识库】WorkBuddy实战手册·进阶版 + WorkBuddy入门指南（每天更新）· 自媒体运营专题定向检索
> 已固化本地，专家不再调用 IMA。整理时间：2026-08-07

## 📌 核心方法论速记

**自媒体 AI 心法**：你负责想清楚定位和受众，WorkBuddy 负责快速出内容。先出初稿再迭代（70分→90分），比追求一步到位高效得多。
**内容生产五环节**：选题策划（20%精力）→ 内容撰写（40%）→ 素材包装（15%）→ 迭代优化（15%）→ 发布排期（10%）。效率瓶颈不在拍摄剪辑，在文案。
**三个原则**：① 先定平台再写内容 ② 先出初稿再迭代优化 ③ 先明确人群与风格再让 AI 动笔。

## 一、小红书运营全链路（官方实践四精华）

### 1. 选题策划（选题决定 80% 流量）

**基础指令**：
```
请根据我提供的产品卖点，帮我写3个适合小红书发布的选题，并为其中1个选题生成标题、正文、话题标签和封面文案，语气自然、真实、适合种草场景。
```

**进阶指令**：
```
请帮我围绕[产品名]的[核心卖点]，生成5个小红书选题方向，分别覆盖种草测评、使用教程、对比横评、场景带入和情绪共鸣5种内容类型，每个选题附推荐标题和切入点。
```

**五种高流量选题类型**：
- 种草测评："用了30天，说说真实感受"（最主流）
- 使用教程："3步搞定XX，小白也能学会"（搜索长尾强）
- 对比横评："5款XX横评，最值得买的是..."（决策型）
- 场景带入："上班族通勤必备的3个神器"（代入感）
- 情绪共鸣："被同事问爆的XX，真的太绝了"（互动率最高）

> 小红书是搜索驱动平台，选题要考虑搜索关键词。爆款选题 = 痛点/痒点 + 产品解决方案 + 情绪钩子。

### 2. 正文撰写（小红书有自己的"语法"）

**特征**：短句为主（每句≤15字）、emoji点缀（每段1-3个）、分段清晰（每2-3句一段）、真实感优先（第一人称"我用了"而非"本产品"）、痛点开头。

**进阶指令**：
```
请为[选题]写小红书正文，要求：①开头2句点出痛点②中间分享3个使用感受③结尾1句行动引导 ④每句<15字 ⑤适当使用emoji ⑥第一人称
```

**黄金公式**：痛点钩子(2句) + 真实体验(3-5句) + 推荐理由(2句) + 行动引导(1句) = 完美种草文

**二次修改**：直接说差异即可——"语气再随意一些""第三段加个对比""结尾加优惠信息"（增量修改不必重写）

### 3. 话题标签与封面文案

**标签策略**：3-8个（太多被判spam，5个是甜点区）；大流量词+精准词+长尾词三层漏斗（如 #好物推荐 + #平价护肤 + #学生党百元面霜）

**封面文案**：≤10字（越短越有冲击力）；情绪词优先（震惊/绝了/踩雷/宝藏）；数字+结论（"5款横评，只推荐这1款"）

**生成指令**：
```
请为这篇小红书内容生成5个话题标签(大流量+精准+长尾组合)和3个封面文案选项(10字以内，强情绪)。
```

### 4. 60秒短视频脚本四段式

| 段落 | 时间 | 要点 |
|---|---|---|
| 开头钩子 | 0-3秒 | 提出问题/展示冲突/制造悬念 |
| 口播主体 | 3-45秒 | 每15秒一个节奏点，短句为主 |
| 镜头建议 | 全程 | 特写/全景/字幕叠加/转场配合 |
| 结尾CTA | 45-60秒 | 关注/点赞/评论/购买/收藏 |

**官方指令**：
```
请帮我生成一份60秒短视频脚本，包含开头钩子、口播文案、镜头建议和结尾行动引导，整体节奏适合信息密度较高的内容账号。
```

**进阶版**：
```
请生成60秒短视频脚本：①钩子用反常识提问 ②口播分3个信息点递进 ③每个信息点配镜头建议 ④CTA引导关注+收藏 ⑤平台：抖音 ⑥受众：25-35岁职场人
```

### 5. 跨平台内容适配

| 平台 | 特征 | 内容要点 |
|---|---|---|
| 小红书 | 图文为主，搜索驱动，长尾流量强 | 300-800字，emoji+短句+分段 |
| 抖音 | 短视频，推荐算法驱动 | 前3秒决定完播率，15-60秒钩子+口播+CTA |
| B站 | 中长视频，弹幕文化 | 5-15分钟深度+数据+观点 |
| 视频号 | 社交推荐，熟人传播 | 30秒-3分钟，生活化+社交化，标题引发分享欲 |

**跨平台改写指令**：
```
请将以下内容改写为小红书种草文，语气真实自然，300字以内，加emoji和话题标签。
请将以下内容改写为60秒抖音脚本，开头3秒钩子，口播短句节奏，结尾CTA引导关注。
请将以下内容改写为B站视频脚本，5分钟以内，加入数据对比和深度分析，口语化但不失专业。
请将以下内容改写为视频号文案，30秒以内，生活化语气，标题引发分享欲。
```

### 6. 迭代优化三步法

1. **出初稿**：一次说清所有要求，先跑起来（70分）
2. **说差异**：增量修改，"语气再随意一些""第三段加个对比"（效率10倍）
3. **分轮打磨**：每轮聚焦一个维度——第1轮标题、第2轮正文、第3轮标签、第4轮封面（90分）

**标题A/B测试指令**：
```
请为这篇内容生成5个不同风格的标题：①数字型 ②反问型 ③对比型 ④情绪型 ⑤悬念型
```

**能力升级路线图**：P0今天选5个选题→P1本周四段式脚本实战→P2第2周跨平台改写→P3持续建流水线（选题库→批量出稿→分轮优化→排期发布）

## 二、小红书 30 天起号：3 个 AI 同事流水线

**核心思路**：把一件事拆成三个岗位，每个岗位只负责最窄的一块（比一个 AI 全包更专业）：

| 专家 | 角色 | 负责解决 |
|---|---|---|
| 爆款选题策划专家 | 选题同事 | 热点、选题、标题方向 |
| 自媒体内容写作专家 | 文案同事 | 正文、钩子、转化引导 |
| 小红书运营专家 | 运营同事 | 小红书格式、封面、发布策略 |

### 第一步：出 30 天选题库（一次性）

```
我的赛道是：______（如职场效率工具/家居好物/个人成长）
目标人群：______（如25-35岁一线城市打工人）
变现方式：______（如接商单/引流私域/卖课程）
请帮我生成30个小红书选题，要求：
1. 前10个追近期热点或平台常见痛点；
2. 中间10个做我的产品/服务相关内容；
3. 后10个做个人故事或经验分享，建立信任；
4. 每个选题给出3个标题方向，并标注"资讯型/种草型/信任型"。
```

### 第二步：文案变成"小红书体"（每天写）

```
选题：______（从30天选题表复制）
平台：小红书
目标人群：________
笔记类型：种草型/避坑型/经验型/教程型（四选一）
请帮我写一条小红书笔记，要求：
1. 开头30字内有一个具体痛点或反常结论；
2. 正文用短段落，每段不超过3行；
3. 中间有1个可截图的"前后对比"或"清单"位置；
4. 结尾留一个互动问题，引导评论；
5. 总字数控制在300-600字。
```

⚠️ 必须删掉AI味重的词："赋能""底层逻辑""引爆"这类。自己读一遍，不像你会发的朋友圈就重写。

### 第三步：封面和标题做成"能点的样子"（每天发）

```
笔记标题：__________
核心卖点：__________（一句话说清帮读者解决什么）
目标人群：__________
请帮我：
1. 优化3个封面标题版本，每个不超过8个字；
2. 给出配色建议（在小红书信息流中显眼但不过分刺眼）；
3. 指出标题中是否有违反小红书规范或容易被限流的词；
4. 给一条发布时间的建议。
```

**封面标题优化示例**：原句"周报从2小时缩到20分钟，这3个工具帮我省下一半时间"→"周报20分钟"/"3个工具省时间"/"打工人周报"（数字前置、人群点名）

### 每周节奏

- **每周日（30分钟）**：选题会，按 35% 热点痛点型 + 40% 种草产品型 + 25% 信任故事型 备 7 个选题
- **每天**：早上 30 分钟写文案（选选题→写作专家出正文→人工润色），中午/晚上 30 分钟做封面+发布（运营专家优化→图片工具生成 3:4 或 1:1 封面→发布）

## 三、公众号全流程自动化（四步法 + 8步流水线）

### 方案 A：四步法（张 sir 实测，全程约 20 分钟）

**第一步：配置公众号（5分钟，只做一次）**
1. 微信公众平台 mp.weixin.qq.com →「开发」→「基本配置」拿到 AppID、AppSecret
2. 把 WorkBuddy 要求的 IP 地址加入 API 白名单
3. 对话里直接贴："我的公众号 AppID 是 wxXXXXXXXX, AppSecret 是 XXXXXXXX"
4. 建议先添加"微信公众号运营专家"到专家库，后期直接调用

**第二步：自然语言让 AI 写文章**
```
我的微信公众号主要针对[人群]，请帮我围绕[主题]写一篇微信推文，要求标题有吸引力，内容能让[人群]有共鸣，针对现实情况给出中肯建议。
```
（AI 会：搜同类文章避免撞车 → 生成初稿 → 自动去 AI 味润色）

**第三步：封面图不用管** — 说"推送草稿箱"，AI 自动理解文章主题配什么风格、生成匹配封面（自动对齐微信尺寸比例）、和文章一起上传。

**第四步：一句话推送** — 说"推送草稿箱"（4个字），AI 自动：调用微信 API 获取上传权限 → 上传封面作为永久素材 → 推送文章到草稿箱 → 返回草稿ID。你去后台确认后手动点发布。

**三点避坑**：① AI 出初稿 → 你补个人案例 → AI 润色（AI 是助手不是替身）② 只推草稿箱不群发，人工确认再发 ③ 推送时英文双引号/特殊符号可能被过滤，后台手动加回。

### 方案 B：8 步流水线（巨飞 AI 实测，半天压到 1 小时）

| 步骤 | 指令模板（原样可抄） |
|---|---|
| 1 找热点 | 搜索 AI 领域今天的热点，给我 5 条，每条标出为什么值得写、谁在看。 |
| 2 选题 | 基于这5条热点，给3个候选标题+角度。标题用数字+结果、反差劝退、实测陪伴、悬念代入这四种公式，不超过20个字。 |
| 3 搜素材 | 按这个选题找官方文档、实测数据、真实案例，标清楚来源，别用没出处的数据。 |
| 4 成稿 | 按这个选题写1200字推文: 开头3句钩子, 正文用二级标题分节、加粗强调关键点、引用块放金句, 结尾留互动问题, 正文不重复标题。 |
| 5 人工打磨 | 删空话套话（"值得注意的是""综上所述"）；核实所有数字；改成人话语气。 |
| 6 配图 | 按每300-500字一张图，分布全文：开篇钩子后、章节转折、结尾升华前。封面单独做，带标题字。（提示词加"无文字、无乱码"） |
| 7 三栏预览 | 生成预览页：左栏创作流程、中栏正文、右栏手机预览，图片本地化内嵌。 |
| 8 发布草稿箱 | 发布到公众号草稿箱，只进草稿不群发，确认后手动发。 |

**流水线 4 坑**：
1. **IP 白名单会变**：公众号 API 要求公网 IP 在白名单，但 WorkBuddy 出网 IP 会变 → 发布前 curl ifconfig.me 实测，不在就先加再发
2. **加粗闭合坑**：`**文字**` 闭合星号后不能紧跟汉字，否则星号原样显示 → 闭合后必须是标点/空格/行尾
3. **生图乱码坑**：AI 出底图会在背景里编文字 → 提示词加"无文字无乱码纯抽象"
4. **纯段落没排版**：连续段落后台是平文本 → 必须 ## 分节、** 强调、> 金句

## 四、31 个新媒体运营提示词（精选核心场景）

> 完整 31 个见上文各节与下方精选。核心原则：提示词 = 场景名 + 使用时机 + 可复制指令。AI 产出多个草稿，**最终判断（哪个选题有品牌感、哪个标题有真人温度）由人定夺**。

**01 账号定位选题库**：你是一名资深新媒体选题策划。我的账号定位是【】；目标用户是【】；主要平台是【公众号/小红书/视频号/抖音/B站】；账号希望给人的感觉是【专业/真实/有趣/犀利/温暖】。请围绕这个账号生成30个内容选题：①分为痛点型、经验型、热点型、故事型、争议型、工具型 ②每个选题说明用户为什么会点 ③给出适合的平台和内容形式 ④输出为表格。

**02 用户痛点选题**：你是一名用户洞察专家。目标用户【】；内容方向【】；用户所处场景【工作/学习/生活/创业/消费】。请从日常焦虑、想要结果、常见误区、偷懒需求、虚荣心理、恐惧担忧、社交表达需求7个角度生成20个选题，每个包含：选题标题、对应痛点、具体场景、用户为什么会收藏或转发。

**03 热点借势选题**：你是一名热点内容策划。当前热点【】；账号方向【】；目标用户【】。请拆出10个可写选题，每个含标题、关联点、切入角度、用户关心原因、内容大纲，覆盖普通解读、反常识、情绪共鸣、方法论、商业分析5类角度。

**04 小红书种草选题**：你是一名小红书内容运营。我要种草的是【产品/工具/服务】；目标用户【】；最想解决的问题【】。请生成20个种草选题，覆盖：新手避坑、真实体验、前后对比、清单推荐、低成本方案、懒人方法、反向种草、使用场景。每个给出标题、正文开头、核心卖点、配图方向、评论区引导。

**05 公众号深度长文选题**：你是一名公众号深度文章策划。主题【】；目标读者【】；希望带来的感受【震撼/启发/焦虑/希望/反思】。请生成12个长文选题，每个含标题、核心观点、开头切入、文章结构、可引用案例、读者收获、结尾升华方向。

**06 爆款选题反推**：你是一名爆款内容分析师。下面是我收集的爆款标题【粘贴】；我的账号方向【】；目标用户【】。请分析这些标题的用户情绪、标题结构、选题方向、表达风格和点击原因，然后基于我的账号仿写20个新选题。要求：不要照抄，只学习结构和情绪。

**08 冷启动选题计划**：你是一名新媒体冷启动顾问。账号方向【】；目标用户【】；主要平台【】；30天目标是【涨粉/测试定位/提升互动/建立专业感】。请设计前30天内容计划：每天1个选题；标注内容类型（涨粉型/信任型/收藏型/互动型/转化型）；给出标题、开头钩子、冷启动作用；输出表格。

**09 标题矩阵**：你是一名标题策划专家。选题【】；平台【】；目标用户【】。请生成30个标题，分为痛点型、结果型、反差型、争议型、清单型、故事型6类，每类5个。要求标题具体、有点击欲、不夸大、不虚假。

**13 去AI味标题**：你是一名真人感标题编辑。下面这些标题太像AI写的【粘贴】。请把它们改得更具体、更口语、更有场景感。要求：少用套路词；少用夸张表达；保留点击欲；每个标题给出3个改写版本。

**15 口播脚本**：你是一名短视频口播编导。主题【】；目标用户【】；视频时长60秒；平台【】。请写一条口播脚本：开头3秒钩子；中间3个要点；结尾互动引导。要求语言口语化、每句话适合真人说出口、不要像新闻稿。
