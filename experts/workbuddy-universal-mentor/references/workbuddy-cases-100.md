## 通用使用逻辑（所有案例共用）

1. 打开WorkBuddy → 新建对话 → 切换 Craft 模式（复杂任务先 Plan 确认）
2. 选择工作空间目录 / 上传文件（@引用或拖拽）
3. 输入结构化指令（目标+输入+格式+约束四要素）
4. AI 自动执行 → 右侧预览 → 下载/推送结果
5. 高频重复任务 → 封装为 Skill 或设置自动化定时

## 📋 办公自动化类（案例1-15）

### 案例1：每日早会速报生成器
- **场景**：每天早上汇总昨日进展、今日待办、团队指标用于早会
- **指令要点**：读取工作日志目录昨日记录 → 生成速报含：昨日关键进展3-5条/今日重点待办3-5条/风险异常/核心数据变化 → Markdown输出，3分钟口头汇报
- **涉及**：文件读取、文档生成Skill、Git连接器（可选）
- **提效**：30分钟→3分钟；可配自动化每天早上8:30自动生成

### 案例2：会议纪要自动加工流水线
- **场景**：录音/草稿自动转标准纪要并提取待办
- **指令要点**：语音转文字（如含音频）→ 提取核心议题 → 整理讨论要点 → 标注决策结论 → 行动项列表（责任人/截止日期/优先级）→ Word输出
- **涉及**：语音转文字、文档生成Skill、腾讯文档/飞书连接器
- **提示**：音频不超过30分钟，过长分段；草稿越完整纪要质量越高

### 案例3：周报四步工作流
- **场景**：每周五基于零散记录生成标准周报
- **指令要点**：指定工作日志文件夹 → Craft模式 → 粘贴记录 → AI按"完成/问题/计划"三板块整理 → 可指定输出PPT直接用于周会
- **提效**：2小时→5分钟；日常养成记录习惯，周报素材越丰富越精准

### 案例4：周报搭配ima知识库（微信小程序版）
- **场景**：微信小程序记录工作+结合知识库模板生成个性化周报
- **指令要点**：ima知识库上传周报模板和优秀样本 → 小程序粘贴本周记录 → 要求基于知识库模板风格生成
- **提效**：2小时→8分钟

### 案例5：日报一键生成
- **场景**：零散记录快速整理成标准日报
- **指令要点**：粘贴今日工作记录 → AI归类任务/标注完成状态/提取成果/识别待跟进 → 标准日报：完成事项(含耗时成果)/问题及处理/明日计划前3项/协调事项
- **提效**：30分钟→2分钟；可配自动化每天17:30触发

### 案例6：工作待办清单自动管理
- **场景**：散落邮件/会议纪要/聊天中的待办自动收集排序
- **指令要点**：上传会议纪要/邮件/聊天截图 → 提取待办事项/责任人/截止日期 → 按紧急度排序 → Excel含状态列；可同步飞书/钉钉
- **提效**：1小时→5分钟

### 案例7：邮件批量处理与自动回复
- **场景**：大量重复性邮件批量分类+标准化回复
- **指令要点**：QQ邮箱连接器拉取或上传 → 分类（询价/投诉/咨询/通知）→ 每类生成回复模板 → 可选直接发送
- **涉及**：QQ邮箱连接器、文档/Excel生成Skill

### 案例8：文件批量整理归档
- **场景**：桌面/下载文件夹混乱自动分类归档
- **指令要点**：指定目录 → 按规则分类（文档/图片按月/压缩包/代码/其他）→ 自动建子文件夹移动 → 生成归档报告
- **安全**：首次用Plan模式确认规则、重要文件先备份
- **提效**：2小时→3分钟；可配自动化每月1号整理

### 案例9：文件批量重命名
- **指令要点**：指定文件夹 → 按规则生成新名（如「日期-序号」「项目名-文档类型-版本号」）→ 输出新旧名对照表
- **安全**：Plan模式预览、备份、避免特殊字符
- **提效**：1小时→2分钟

### 案例10：文件格式批量转换
- **指令要点**：Word→PDF、PNG→JPG（压缩质量80%）、Excel→CSV → 输出转换统计报告
- **提示**：复杂排版有小差异关键文件人工检查；大批量分批执行
- **提效**：3小时→10分钟

### 案例11：桌面文件智能分类（按内容语义）
- **场景**：按内容语义而非类型分类（区分"合同"和"报告"PDF）
- **指令要点**：读取文件内容（OCR/解析）→ 语义分类（合同/报告/数据/通知/个人/待分类）→ 移动+分类报告
- **提效**：建议先少量测试；可封装为Skill一键执行

### 案例12：截图OCR识别与文字提取
- **指令要点**：拖入截图 → OCR提取文字按文件名分组 → 发票/合同进一步提取金额/日期/编号等 → Excel/Word
- **提示**：清晰度直接影响准确率；可封装"发票OCR提取器"Skill
- **提效**：1小时→3分钟

### 案例13：语音转文字会议记录
- **指令要点**：上传录音(mp3/wav/m4a) → 转文字 → 按议题整理 → 提取决策和行动项（责任人+截止日期）→ Word含转写原文+结构化纪要

### 案例14：多文档合并与对比
- **指令要点**：合并（按章节顺序合并统一格式）/ 对比（v1 vs v2逐段标注新增绿/删除红/修改黄 → 差异表格含变更影响分析）
- **提示**：法律合同对比调用法律专家；对比类用Plan模式确认维度
- **提效**：1.5小时→8分钟

### 案例15：跨语言文件翻译与排版
- **指令要点**：上传外文文档 → 逐段翻译 → 保持标题层级/表格/列表 → 专业术语用标准译名 → 不确定处标注原文 → Word输出

## 📱 内容创作与自媒体类（案例16-25）

### 案例16：小红书图文种草内容生成
- **指令要点**：产品/话题+账号定位 → 3个标题候选（悬念/数字/痛点）→ 正文500字口语化每段2-3句带emoji → 3张配图文案 → 10个标签 → 结尾互动引导
- **关键**：先上传3-5篇爆款笔记让AI学习账号风格；避免AI味可要求"拒绝生硬AI话术"
- **提效**：2小时→15分钟

### 案例17：公众号全自动运营（Playwright浏览器方案）
- **指令要点**：安装浏览器自动化Skill → 选题→写文→封面图→浏览器登录公众号后台→创建草稿→填标题正文→传封面→存草稿 → 输出操作截图确认
- **安全**：涉及账号操作用Plan模式；草稿发布前人工审核

### 案例18：公众号全自动运营（API草稿箱方案）
- **指令要点**：配置公众号API（AppID/AppSecret）→ 写文→封面→API创建草稿绑定素材 → 返回media_id确认

### 案例19：公众号"一人编辑部"工作流
- **核心**：创建自建Skill"公众号一人编辑部"：每日选题→初稿→多版标题→校对→排版→草稿推送→发布后数据复盘
- **提效**：每天4小时→30分钟（仅审核）

### 案例20：短视频选题清单生成
- **指令要点**：账号定位/受众/方向 → 一周7天选题，每个含：标题/核心观点/预估时长/拍摄形式/爆款概率评估 → 避免同质化（痛点/干货/情绪三种类型）→ Excel

### 案例21：短视频口播稿多Agent并行生成
- **指令要点**：多条选题 → 多Agent并行撰写 → 每条：3秒hook/干货/结尾引导/200-250字（45-60秒）→ 5个独立文件

- **提效**：5小时→15分钟

### 案例22：视频号内容创作辅助
- **指令要点**：账号定位 → 分析视频号推荐机制 → 3条选题（标题带情绪触发词/45秒口播脚本/封面文案/3秒hook）→ 避免敏感词

### 案例23：抖音脚本批量生成
- **指令要点**：账号定位 → 10条脚本（标题带数字悬念/3秒hook/15-30秒每5秒一个信息点/BGM建议/字幕要点/结尾引导）→ Excel

### 案例24：微博热搜文案快速产出
- **指令要点**：浏览器自动化抓热搜 → 筛相关话题 → 每话题3条文案（吐槽/科普/互动）→ 140字内带话题标签

### 案例25：SEO关键词文章批量生成
- **指令要点**：关键词列表+网站定位 → 10篇SEO文章（标题含主词/1500字关键词密度2-3%/H2H3层级/元描述150字/内链2-3条/避免AI痕迹）

## 📊 数据分析与可视化类（案例26-35）

### 案例26：5分钟Excel数据清洗分析
- **指令要点**：删重复行/空行/空列 → 统一日期YYYY-MM-DD → 统一数字格式 → 修正错位 → 基础统计（总和/占比/最大最小）→ 清洗后Excel+分析摘要Word
- **提示**：清洗前备份；复杂规则用Plan；人工抽查10-20行
- **提效**：3小时→5分钟

### 案例27：交互仪表板生成
- **指令要点**：上传Excel → 月度趋势折线图(可按区域筛选)/区域占比饼图/Top10柱状图/关键指标卡片/点击联动筛选 → 单HTML文件
- **提示**：HTML无需服务器浏览器打开即用
- **提效**：1天→10分钟

### 案例28：科技炫酷可交互数据看板
- **指令要点**：深色主题(#0a0a2e)霓虹蓝绿 → 数字滚动/渐变图表/发光边框/粒子动画/三栏布局/hover交互 → HTML

### 案例29：Excel秒变数据看板+报告
- **指令要点**：一份Excel同时生成：交互式看板HTML+文字分析报告Word（看板图表+报告解读趋势），结论一致

### 案例30：一键数据清洗分析（含Skill封装）
- **核心**：创建自建Skill"一键数据清洗分析"：上传Excel自动清洗→识别维度→统计分析→3个核心图表→输出清洗后Excel+摘要Word
- **提示**：先手动验证流程再封装；可团队共享（企业版）

### 案例31：学生成绩分析报告
- **指令要点**：各科平均/最高/最低/标准差 → 班级对比 → 优秀率(≥90)及格率(≥60) → 分布直方图 → 异常识别（单科<40或波动>30）→ Word+HTML图表看板
- **提示**：成绩涉隐私注意授权范围
- **提效**：4小时→10分钟

### 案例32：销售数据趋势分析与预测
- **指令要点**：清洗→趋势→同比环比→季节分析→增长率 → 预测未来6个月（乐观/保守/悲观三档）→ 标注异常月份 → Word+HTML趋势看板
- **提示**：至少12个月历史数据；重大市场变化需人工修正

### 案例33：问卷调查数据自动统计
- **指令要点**：每题频次/百分比 → 交叉分析（年龄×满意度/性别×购买意愿）→ NPS → 开放题关键词 → Top3洞察 → 异常模式 → Word+HTML看板
- **提示**：先清洗无效回答（全选同一项/时间过短）

### 案例34：财务报表自动化分析
- **指令要点**：收入/成本/利润趋势及同比环比 → 毛利率/净利率/ROI → 现金流（经营/投资/筹资）→ 成本拆解（增长超20%标红）→ 利润下滑风险 → Word+HTML指标看板
- **提示**：财务数据敏感注意访问控制

### 案例35：市场调研数据整合报告
- **指令要点**：多源数据（问卷Excel/访谈Word/报告PDF）→ 市场概况→竞争格局→用户洞察→趋势预测→策略建议 → 跨源交叉验证标注可靠性 → Word+HTML看板
- **提示**：多源结论冲突需标注分析原因

## 👥 HR人力资源类（案例36-45）

### 案例36：写JD（岗位描述）
- **指令要点**：岗位核心信息 → 标准HR格式（岗位职责5-8条/任职要求硬性+加分/团队介绍/发展路径）→ 同步生成含权重的简历筛选标准Excel
- **提示**：硬性条件少而精（3-5条）

### 案例37：简历搜集筛选打分
- **指令要点**：邮箱拉取或上传简历文件夹 → 批量解析提取30+字段 → 按评分标准（硬性40分/匹配35分/加分25分）打分排序 → 每份标注亮点风险点 → 评分Excel+筛选报告Word
- **提效**：150份简历从1天→40分钟；进阶：5-10份优秀简历AI比对加权热力图匹配率96%

### 案例38：面试问题自动生成
- **指令要点**：JD+候选人简历 → 按岗位关键能力出考察维度标准问题（每维度3-5题）→ 差异化问题（有电商经验→高并发方案）→ 标准化评分表1-5分 → 长期复用面试题库
- **提效**：3小时→15分钟

### 案例39：面评一键生成
- **指令要点**：JD+简历+面试记录 → 候选人特点总结/岗位适配分析/核心能力评估（附评价依据）/明确录用建议（推荐/待定/不推荐附理由）→ 标准化Word

### 案例40：人才Mapping
- **指令要点**：目标公司/岗位/行业 → 浏览器自动化搜公开信息 → 学历分布/技能分布/项目经历/工作轨迹/软素质/匹配度分析 → Word+HTML人才分布看板
- **提示**：遵守平台规则和隐私法规；侧重画像模式而非个人信息

### 案例41：新员工入职引导手册生成
- **指令要点**：知识库上传公司资料 → 公司简介→组织架构→制度规范→工作流程→工具系统→FAQ20条→成长路径 → Word/PDF

### 案例42：员工满意度调查分析

### 案例43：薪酬方案对比分析
