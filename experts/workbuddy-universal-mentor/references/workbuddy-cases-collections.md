## 📌 通用提示词公式（全行业通用，核心心法）

**一句话公式**：`你是{行业}里的{专家角色} + 我的业务背景是{背景} + 当前目标是{目标} + 已有信息包括{数据/素材} + 限制条件是{预算/时间/人员/合规边界} + 请输出{表格/清单/话术/SOP/方案} + 每条标注优先级、资源、风险和检查标准`

**使用口诀**：
1. **指定路径**：不说"我的数据"，说"D:\工作\Q1销售.xlsx"
2. **明确格式**：不说"给个图表"，说"柱状图 + PDF"
3. **说明要求**：不说"分析一下"，说"算环比、标Top10、输出结论"
4. **重要任务开 Plan 模式**：涉及删文件、改数据的，先看方案再执行

**迭代追问**：先让 WorkBuddy 输出第一版，然后追问"再具体一点""给我表格""写成可执行SOP"。
**核心发现**：带"角色设定"的指令，输出质量比直接提问高出至少 60%。
