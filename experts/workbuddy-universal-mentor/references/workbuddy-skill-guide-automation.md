## 一、Skill 体系全指南（3 分钟入门）

### 1.1 Skill 是什么
Skill 是 WorkBuddy 的能力扩展模块——没有 Skill，AI 只会"说"；装了 Skill，AI 才能真正"做"。类比：WorkBuddy 是智能手机，Skill 是 App；Skill 是工程师的扳手/锤子/电钻。

对比：无 Skill 时 AI 说"你可以用 VLOOKUP"；装 Excel Skill 后 AI 直接写好公式、清洗数据、生成图表一步到位。

### 1.2 三种 Skill 类型
| 类型 | 说明 | 代表 | 适合人群 |
|---|---|---|---|
| 🔧 内置技能 | 默认集成，开箱即用 | Weather、基础文件操作 | 所有用户 |
| 🌐 社区技能 | SkillHub/ClawHub 开源技能，一键安装 | PDF、XLSX、浏览器自动化 | 进阶用户 |
| ✏️ 自定义技能 | 自己编写，适配专属工作流 | 个性化工作流、专属工单系统 | 高级用户/开发者 |

### 1.3 四种安装方式
1. **SkillHub 在线安装（新手首选）**：左侧"技能"图标 → SkillHub 市场 → 搜索关键词 → 点"安装"。10 秒完成，官方安全扫描
2. **ZIP 包手动导入**：头像 → Claw 设置 → 技能管理 → "+ 导入技能" → 选 ZIP。适合网络受限场景
3. **Git 仓库直拉（开发者用）**：技能管理 → "从 Git 仓库导入" → 粘贴 HTTPS 地址
4. **.skill.json 文件拖拽（最轻量）**：直接把 .skill.json 拖进主窗口中央，松手即校验。文件需含 name/description/mcp_version/actions 四个必需字段

**验证安装成功**：以 PDF Skill 为例，发指令"帮我读取桌面的'测试.pdf'，提取第一页的文字内容"，能正确读取即成功。

### 1.4 新手必装 7 个核心 Skill
| Skill | 能做什么 | 适用场景 |
|---|---|---|
| ① PDF 处理 【必装】 | 读文字、合并、拆分、OCR 转文字、提取表格 | 合同/报告/发票/研报，使用频率最高 |
| ② Excel/XLSX 【必装】 | 清洗、公式、跨表匹配、图表、筛选高亮 | HR 考勤、财务报表、数据分析 |
| ③ DOCX/Word 生成 | 智能生成（目录/封面/页码）、格式统一替换、纪要合并 | 周报/方案/合同底稿 |
| ④ 联网搜索（tavily-search） | 实时查资料、多源整合摘要 | 行业报告、政策数据、竞品动态 |
| ⑤ 浏览器自动化（agent-browser） | 操控浏览器：点按钮/填表单/截图/下载/采集 | 自动登录、批量下载、竞品价格 |
| ⑥ 永久记忆（agent-memory）【必装】 | 记住名字/习惯/常用指令/历史任务 | 人人都需要，"个人专属 AI"关键 |
| ⑦ PPT 自动生成（pptx-generator） | 主题→框架→每页标题→可编辑 PPT | 汇报、方案、培训材料 |

**不同岗位首装速查**：上班族/行政（PDF+XLSX+记忆）；产品/项目经理（DOCX+PPT+XLSX）；HR/财务（XLSX+PDF）；运营/市场（浏览器自动化+搜索）；新手（PDF+记忆）。

### 1.5 三种自定义 Skill 创建方式
1. **图形化界面新建（零代码）**：Claw 设置 → Skills 管理 → "+ 新建技能" → 填名称+触发关键词+执行动作类型。适合文件归档、文本改写、字段提取
2. **导入 YAML 模板（复杂逻辑）**：编写标准 YAML 技能定义文件（name/version/description/triggers/actions）后导入
3. **指令反向生成（最智能）**：连续三次发送结构相似指令，系统自动识别模式，主动提示帮你生成带变量参数的 Skill。如每天发"整理今天的会议记录为标准格式"，AI 会问"要不要创建技能？"

进阶：创建后可发布到 SkillHub 社区（官方已收录 13000+ 社区技能）。

### 1.6 Skill 安全使用指南
| 安全维度 | 核验要点 | 建议 |
|---|---|---|
| 病毒扫描 | 官方扫描"无风险" | 优先 SkillHub/ClawHub 已扫描技能 |
| 权限声明 | 申请权限与功能匹配 | 文档技能申请全盘读写权限需警惕 |
| 开发者认证 | 官方/高星开发者稳定版 | 零下载无评论的陌生技能慎装 |
| 来源渠道 | 内置市场优先 | 内置 > SkillHub 官方 > ClawHub 社区 |

特别提醒：装任何非官方技能前，先装 skill-vetter（安全审查官），可拦截 98% 以上的第三方恶意技能包。

### 1.7 FAQ 与技巧
- **装了没反应**：发验证指令 → 重启 WorkBuddy → 确认技能"启用"状态 → 部分技能需配 API Key
- **越多越好？** 不是。过多技能让 AI 判断混乱甚至冲突。按需安装，每场景 1-2 个
- **更新/卸载**：技能管理支持版本更新、一键卸载、版本回滚
- **自动推荐**：装 find-skills 技能后，直接问"有没有适合处理 XX 任务的技能？"AI 自动搜索推荐

## 二、10 个必装技能实操 + 10 条使用心法（6000 字手册精华）

### 2.1 底层心法
指令越具体，结果越精准。官方万能公式"**做什么 + 有什么 + 怎么样**"：把目标、输入、格式、约束四要素写全。

### 2.2 三种运行模式
| 模式 | 行为 | 适用 |
|---|---|---|
| Ask（问答） | 只聊天不读写文件 | 咨询、想方案、写初稿 |
| Plan（规划） | 先给步骤你确认再动手 | 报表/合同/项目文档等"出错代价大"场景 |
| Craft（实干） | 直接执行操作文件 | 标准化批量活 |

新手建议：先 Ask/Plan 熟悉，再用 Craft，避免一上来大改文件。

### 2.3 10 个必装技能实操指令模板

**① Web Search（联网搜索）**：安装：技能市场搜索"Web Search"。
```
请联网搜索 2026 年 Q2 中国 SaaS 行业融资事件，
按公司名/融资金额/投资方/赛道四列整理成表格，
并提炼 3 条行业趋势，输出为 Markdown 文件保存到桌面。
```
要点：明确时间/地区/行业边界；指定表格列结构；让 AI 给来源链接复核。

**② Agent Browser（浏览器自动化）**：
```
请登录 XX 业务后台，在搜索框输入"供应商A"，点击搜索，
等待页面加载数据后，截取指定区域，保存到"D:\供应商截图\供应商A.png"。
然后依次处理供应商B、供应商C......（共47个）
```
关键技巧：先小范围试跑 5 个确认步骤 → 再批量执行。真实案例 47 个供应商截图全程静默执行。

**③ PDF 处理**：
```
批量读取"D:\政策文件"文件夹下的所有 PDF，去重整合、提炼核心信息，按以下维度拆分：
核心背景/关键要求/执行要点/截止时间/注意事项
输出一份结构化笔记，保存为"政策要点汇总.md"到桌面。
```
进阶：多份合并成一份、批量转 Word/Markdown。

**④ Excel 数据清洗**（用 Craft 模式）：
```
读取桌面"2026Q1销售数据.xlsx"，完成全自动数据处理：
1. 清理全部空白无效行 2. 剔除重复数据 3. 统一字体与单元格格式
4. 按"地区"维度分类汇总 5. 统计核心数据总量
最终输出一份整洁、可直接用于汇报的规范表格，并简要说明数据结论。
保存为"2026Q1销售数据_清洗后.xlsx"。
```
真实效果：上传季度销售数据，Plan 模式下自动"数据清洗→6 张图表→2000 字运营报告"，3-5 分钟出可编辑 Word。

**⑤ PPT 生成标准流程**：信息前置输入 → Plan 模式生成目录架构 → 按公司规范调目录 → 确认后一键生成内容页。
```
基于以下信息生成一份 15 页的产品路演 PPT：
- 产品：XX SaaS 工具 - 目标受众：投资人
- 核心卖点：AI 自动化、效率提升 10 倍 - 风格：科技感、深色背景、蓝色主色调
输出为 .pptx 文件保存到桌面。
```
⚠️ 重要提醒：AI 生成 PPT 不能直接定稿——它不了解公司产品真实功能边界，可能"承诺无法实现的功能"。必须人工对照产品手册修正；提前投喂全套产品资料做知识库训练可减少 50% 修改量。

**⑥ Word 周报**：
```
基于桌面"本周工作记录.docx"的内容，生成一份技术运营岗位的周报，包含：
1. 本周重点工作（分点） 2. 遇到的问题 3. 下周计划
输出为 Markdown 格式。
```

**⑦ 数据分析与可视化**：
```
读取"performance.xlsx"，计算各团队的同比环比变化，构建可视化图表，
生成包含以下内容的分析报告：1. 核心指标概览（KPI 卡片）2. 团队维度对比（柱状图）
3. 趋势分析（折线图）4. 异常数据预警 5. 改进建议（3-5 条）
输出为 .pptx 文件，并自动排版。
```
真实案例：售前工程师招投标参数对比（近百条指标、6 款产品），人工 1-2 小时 → WorkBuddy 几分钟，时间成本压缩 90%+。

**⑧ 文件批量整理**：
```
扫描"D:\Downloads"文件夹：
1. 所有图片文件(.jpg/.png)移动到"D:\图片"文件夹，按"YYYY-MM-DD"格式重命名
2. 所有 PDF 按月份和项目名称分类归档
3. 删除所有空文件和重复文件
4. 处理过程中不要删除任何未确认的文件
```
真实效果：桌面百余张截图按型号分类 2 分钟；几百个 PDF 归档十几秒。
⚠️ 安全红线：只授权必要文件夹；改文件前先备份；大批量用 Plan 模式预览；任务沙箱运行定期审查日志。

**⑨ 专家调用（Expert Center）**：内置 100+ 预置领域专家（招聘/投研/前端/法务/营销），也可上传岗位说明书/SOP/知识库构建专属专家。
```
作为 HR 专家，请帮我撰写一份武汉本地公司"行政专员"岗位的招聘 JD。
要求：坐班光谷、周末双休、入职缴纳五险一金，月薪 4500-5500 元。
重点突出包午餐、靠近地铁站、团队氛围轻松等福利亮点。
语言风格接地气、有网感，适合 BOSS 直聘和本地微信求职群发布。
```
价值：设定身份后回答的用词、思考框架自动对齐该行业，输出质量高一档。

**⑩ 自定义技能**：把反复使用的流程封装成 Skill。真实案例：某用户定期从邮件下载供应商附件并归类，先逐步执行发现两坑（AI 会把正文图片当附件→告诉它"只认 .xlsx 或 .pdf"；多附件堆一起→让 AI 自动新建文件夹），跑通后封装成 Skill 批量执行。精髓：**把一次性的成功流程沉淀成可复用资产**。

### 2.4 10 条使用心法
1. **清晰表达**：下达明确任务
2. **小步快跑**：一次搞定一件事（别丢"重构整个项目"这种大需求）
3. **换说法效果天差地别**：别写"帮我写篇产品介绍"，要"参考这段文案的风格和节奏：[示例]，请为 XX 写产品介绍，目标用户是职场白领，风格活泼不失专业"
4. **从桌面端开始**：别一来就远程，先熟悉边界
5. **用 @ 引用提供精确上下文**
6. **一个样本胜过十行要求**：AI 擅长模仿不是从零想象，给锚点
7. **不同任务开不同会话**：写方案一个、整理数据一个，专注一件事
8. **改文件前先备份**：初稿"存档1"、改一轮"存档2"，改崩能回退
9. **善用自动化**：重复性高、规则明确、不用实时盯的交给定时任务
10. **检查变更视图（Changes View）**：接受结果前审查修改是否符合预期

附：并行任务（同时启动多个任务切换，省时间）；迭代优化（继续对话优化而非从头新开）。

### 2.6 新手避坑准则
1. 涉密信息绝对不上传（客户信息、内部底价、未发布方案）
2. 机械工作放手 AI，专业核心工作守住人（数据对比/排版/初稿交 AI；产品选型/定价/方案承诺/风险决策人终审）
3. Craft 批量操作前务必备份
4. AI 不是万能的（硬件成本、实体物料选型有明显偏差，需人工专项核验）

### 2.7 第一天行动清单（30 分钟跑通闭环）
下载安装 → 切换 Plan 模式 → 装 5 个核心技能（Web Search/PDF/Office/数据分析/文件整理）→ 试手小任务（整理图片按日期分类）→ 配第一个自动化任务（每晚 23:00 归档 PDF）→ 配连接器（企微/飞书/钉钉）体验远程 → 把顺手流程封装成自定义技能 → 加入社区签到领积分/发布教程获 500-1000 积分。

## 三、自动化任务（定时任务）实战

### 3.1 一句话说透
WorkBuddy 能把"时间固定、步骤相似、结果可检查"的重复活儿，配成定时自动跑的 Agent 任务。区别于传统自动化（要写代码控制每步），WorkBuddy 把"定时调度"+Agent 的理解/调工具/处理文件能力拧在一起——你只要说清目标、输入、边界、结果。

### 3.2 五个要素（任务才稳）
1. 明确的触发时间
2. 可重复的输入来源
3. 够具体的 Prompt
4. 固定且受控的工作目录
5. 能判成功失败的验收条件

### 3.3 七大类自动化场景
| 场景 | 自动做啥 | 产出 |
|---|---|---|
| 资讯情报 | 定时搜行业新闻/政策/竞品 | 每日简报、风险提示 |
| 日报周报 | 汇总任务/日历/文档变化 | 日报、周报、进度表 |
| 数据表格 | 合并表格、清洗、查异常 | 对账表、异常清单 |
| 文件管理 | 按日期归档、批量重命名、抽 PDF 文字 | 归档目录、处理日志 |
| 内容运营 | 收集选题、生成标题、整理素材 | 选题库、内容草稿 |
| 知识管理 | 整理收藏、会议纪要、补标签 | 知识卡片、每周回顾 |
| 个人事务 | 学习计划、阶段复盘、提醒 | 学习清单、执行记录 |

### 3.4 六问筛选法（该不该自动化）
1. 会重复吗（至少每周一次）？2. 输入稳定吗？3. 步骤相似吗？4. 结果可验收吗（查条数/字段/时间/文件）？5. 失败可恢复吗？6. 权限可控制吗？
"是"越多越适合。起点建议："每天 8 点收 10 条 AI 新闻，去重留链接，生成简报到指定目录"。

### 3.5 七问 Prompt 模板（每日 AI 行业简报）
```
任务名称：每日 AI 行业简报
触发时间：每天 08:00，时区 Asia/Shanghai
工作目录：automation/ai-daily
输入：检索过去 24 小时 AI 产品/模型/行业新闻，只用可保留链接的公开来源。
处理：合并重复，按产品/技术/商业三类整理；每条含标题、100字摘要、来源、时间、链接；
来源或时间不明的放"待核验"，不编造。
输出：存为 YYYY-MM-DD-ai-daily.md，最多 10 条，末尾附来源清单。
```
七件事：何时执行、读什么、怎么处理、输出到哪、怎样算完成、失败怎么办、哪些动作禁止。

### 3.6 配置项清单
| 配置项 | 怎么填 |
|---|---|
| 名称 | 写清对象和频率，如"每日AI简报" |
| 工作空间 | 每项用独立目录，别互相覆盖 |
| 提示词 | 套七问模板，别只写口号 |
| 模型和技能 | 只选任务真需要的 Skill 和连接器 |
| 定时规则 | 先低频试运行，再提频 |
| 推送到小程序 | 开前确认哪些结果走安全链路同步云端 |

官方模板覆盖：每日 AI 新闻推送、每日 5 个英语单词、儿童睡前故事、每周工作周报、经典电影推荐、历史上的今天、父母联系提醒、体检预约提醒、面试准备提醒、会议前准备、可爱萌宠手机壁纸等。选了模板仍要改数据来源、时间范围、输出位置、验收标准和禁止动作。

## 四、Claw 助理远程控制（把 AI 装进微信）

### 4.1 助理是什么
WorkBuddy 的"手机遥控器"：手机上给 IM（微信/企微/钉钉/飞书等）里的机器人发消息，电脑上跑着的 WorkBuddy 自动接任务、执行、回传结果。入口：左下角头像 → 设置 → 助理设置。

**易混点**：助理接的是"即时通讯工具"（让你手机远程下指令）；连接器接的是"服务"（腾讯文档/QQ邮箱/TAPD/腾讯会议等数据读写）。目前支持的平台：微信、企业微信、QQ、元宝、钉钉、飞书。

典型用法：出门在外处理文件；开会时现场出会议纪要；通勤路上安排明天材料；随时随地甩任务回来直接看结果。

**两个前提**：电脑保持开机 + WorkBuddy 在运行；网络要通。

### 4.2 微信绑定（官方推荐通道，扫码最省心）
前置条件：WorkBuddy >= 4.6.4；微信 >= 8.0.70；同一账号；网络正常。

四步：
1. 打开 WorkBuddy → 左下角头像 → 设置 → 助理设置
2. 集成列表找到「微信助理集成」→ 点「配置」（按钮变"绑定中..."）
3. 二维码显示后，手机微信扫码
4. 状态变「已绑定」。换账号点「解绑」重扫

**开聊测试**：微信里发「你好」试水；支持文字、图片、文件、语音（语音转文字可读）。电脑端「助理」标签页自动出现微信会话可继续追问。注意二维码有时效，过期重扫。

### 4.3 企业微信（WebSocket 长连接最简）
1. 建机器人：管理员（管理后台 → 安全与管理 → 管理工具 → 智能机器人 → 创建机器人）；普通成员（客户端 → 工作台 → 智能机器人应用 → 创建机器人）
2. 切到「API 模式」（否则接不上）
3. 填基本信息保存（名称/可见范围；先保存右侧 API 配置才亮）
4. 拿钥匙：「API 配置」选「使用长连接」，复制 Bot ID，点「点击获取」生成并复制 Secret（只显示一次）
5. WorkBuddy 助理设置 →「企微 AIBot 集成」→ 配置 →「WebSocket 长连接」标签页 → 填 Bot ID 和 Secret → 注册（不用配回调地址）
6. 通讯录「企业创建的」分组下发消息测试

### 4.4 飞书
创建企业自建应用 → 加「机器人」能力 → 权限管理导入官方权限列表 → 拿 App ID/App Secret → WorkBuddy 助理设置「飞书集成」填凭证注册拿 Webhook → 飞书开放平台「事件与回调」选"将事件发送至开发者服务器"粘 Webhook → 添加「接收消息」事件和「卡片回传交互」回调 → 创建版本并发布。

### 4.5 钉钉
开发者后台创建应用加「机器人」→ 开通三个权限（Card.Streaming.Write、Card.Instance.Write、qyapi_robot_sendmsg）→ 拿 Client ID/Client Secret → WorkBuddy「钉钉集成」注册复制 Webhook → 钉钉后台消息接收从「Stream 模式」切「HTTP 模式」粘 Webhook（**注意地址开头 http 改 https**，否则收不到）→ 发布版本，群聊/单聊 @它下指令。

### 4.6 QQ
QQ 开放平台注册入驻创建机器人应用等审核 →「开发管理」拿 AppID/AppSecret → WorkBuddy「QQ 集成」注册复制 Webhook → QQ 开放平台机器人「Webhook 设置」粘「请求地址」（**去掉 https:// 前缀只留域名和路径**）→ 勾选单聊权限 → 沙箱环境扫码测试。

### 4.7 元宝
助理设置「元宝机器人集成」按官方指南走即可。

**坑总结**：建应用、拿凭证、填 Webhook、改 https 是四步最容易出错的地方。

## 五、数据分析与可视化全链路（官方 Practice-Four 拆解）

### 5.1 四大典型场景
| 场景 | 输入/输出 |
|---|---|
| 经营分析 | 已有 Excel 数据 → 月/季/年统计 + 趋势图/对比图 + 分析报告 |
| 项目汇报 | 进度/成本/收益 → 图表嵌入 PPT/Word（甘特图+成本柱状+收益折线） |
| 市场调研 | 数据未整理 → 网络搜集 → 结构化数据 → 调研报告 |
| 业务复盘 | 多维度对比 → 增长点/问题点 + 复盘报告 + 行动建议 |

核心判断：数据已有 → 走"Excel 转图表"路径；数据未整理 → 走"搜集数据+生成报告"路径。

### 5.2 三种数据导入方式
1. **拖入文件（最快捷）**：Excel/CSV/TSV 直接拖进对话窗口，零配置秒级识别
2. **指定文件路径**："请读取 D:/data/sales.xlsx"，可精确控制读取范围/工作表/行列
3. **描述数据需求（搜集模式）**："请帮我搜集近1年国内AI办公工具相关的市场信息，重点关注用户规模、应用场景和代表产品"

### 5.3 需求描述四要素（黄金法则）
1. **分析指标**：销售额、利润、客户数、转化率
2. **图表类型**：柱状图、折线图、饼图、散点图、热力图
3. **统计维度**：按月份、按产品线、按区域、Q1-Q4
4. **报告需求**：是否需要报告、格式、受众（"输出 Word 报告，适合管理层阅读"）

示例指令：
```
请读取这份销售数据，按月份统计各产品线的销售额和利润，
分别生成柱状图与折线图，并补充一段结论说明。
```
业务复盘型："请对比Q1和Q2的各维度数据，找出增长Top3和下降Top3，生成对比图表和行动建议"

### 5.4 三条黄金法则
1. **问题先行**：先说清要回答什么业务问题，再决定图表形式。用"我想了解/发现/验证..."开头。反面："帮我画个柱状图"（没说分析问题）；正面："我想了解各产品线的销售趋势差异，请用折线图对比"
2. **小步快跑**：先产出基础版本，再逐轮补充图表与结论。反面：一次要 10 图+5 结论+3 格式；正面：第一轮核心图表→第二轮对比分析→第三轮完整报告
3. **可信度前置**：搜集数据提前写明来源要求。在指令中加"标注来源""优先权威机构""数据截止日期"等约束词

记忆口诀：**问题先行 → 小步快跑 → 可信度前置**，效率提升 3 倍+。

### 5.5 两条路径速查
**路径 A（已有数据 Excel 转图表）**：拖入文件 → "请读取这份数据，按[维度]统计[指标]，生成[图表类型]，并补充结论" → 预览微调导出。3 分钟出基础图，5-10 分钟完整分析。

**路径 B（数据未整理搜集+报告）**："请帮我搜集[主题]相关的[维度]信息，整理成结构化数据" → "请基于数据生成可视化报告，包含[结构]，适合[受众]阅读" → 审查迭代导出。10-15 分钟全流程。

### 5.6 速查指令卡
| 场景 | 指令 |
|---|---|
| 经营分析 | "读取[文件]，按月统计[指标]，生成柱状图+折线图，补充结论" |
| 项目汇报 | "读取[文件]，生成[图表]，输出PPT报告，适合汇报" |
| 市场调研 | "搜集[主题]近1年数据，整理成结构化表格，生成调研报告" |
| 业务复盘 | "对比[A]vs[B]各维度数据，找Top3增长/下降，生成对比报告" |
| 一页纸摘要 | "生成一页纸摘要：3结论+2图表+3建议" |
| 可信度约束 | "标注来源，优先权威机构，数据截止[日期]" |

图表类型：柱状图、折线图、饼图、散点图、面积图、热力图、雷达图等 10+ 种；导出 PNG/SVG 或嵌入 Word/PPT。
