## 一、办公三件套：从"各自为战"到"一条流水线"

### 1.1 动手前先回答五个问题（防止 AI 瞎做）

| 问题 | 要说清什么 | 示例 |
|---|---|---|
| 目标 | 这份材料要帮助谁做什么决定 | 给部门负责人看，判断项目是否继续投入 |
| 受众 | 阅读者是谁，懂不懂背景 | 管理层只看结论；项目组需要过程和责任人 |
| 材料 | 哪些是事实来源，哪些只是参考 | data.xlsx 是唯一数据口径，旧 PPT 只参考结构 |
| 格式 | 要 Word、Excel、PPT 还是三者联动 | 输出项目复盘 Word + 风险台账 Excel + 8 页汇报 PPT |
| 验收 | 怎么判断结果可用 | 数字能回到源文件、公式可刷新、PPT 投屏不溢出 |

### 1.2 先选对 Skill（办公三件套技能地图）

| Skill | 适合处理什么 | 注意点 |
|---|---|---|
| Word / DOCX | 创建、检查、编辑 DOCX，处理标题、编号、表格、修订记录 | 适合本地 docx 文件 |
| Excel / XLSX | 读取、清洗、写入工作簿，处理公式、日期、格式和模板保留 | 先确认数据口径 |
| Powerpoint / PPTX | 创建、编辑、检查 PPTX，处理版式、占位符、备注、图表和视觉质检 | 适合需要可编辑 PPTX |
| Office Document Specialist Suite | 综合处理 Office 文件，自动化报告和多文件联动 | 复杂任务建议分步验收 |
| WPS | 面向中国用户的 WPS Office 工作流（文字/表格/演示） | 适合 WPS 生态用户 |
| 腾讯文档 | 创建、读取、编辑、搜索腾讯文档（在线 Word/Excel/幻灯片） | 通常需要 API Key 或授权 |
| Markdown Converter | 把 PDF/Word/PPT/Excel 转成 Markdown 方便模型先理解 | 适合读材料，不等于最终排版 |
| PPT Generator / Workflow | 从主题、讲稿或材料自动生成演示稿 | 生成后仍要人工审稿 |
| Excel 公式生成 | 自然语言转 Excel/WPS/Google Sheets 公式 | 公式要在样例数据上验证 |
| 腾讯会议 | 预约会议、获取转写、获取 AI 纪要，再转成 Word 纪要/Excel 待办/PPT 汇报 | 需要会议平台授权 |

搭配思路：本地文件优先 Word/DOCX、Excel/XLSX、Powerpoint/PPTX；在线协作优先腾讯文档或金山文档；材料多时先用 Markdown Converter 抽取结构；会议类叠加腾讯会议 Skill。

### 1.3 Word：从空白页到正式文档

**四大痛点**：不知道按什么结构写、语气不够正式、标题编号混乱、内容没有证据来源。

**推荐流程**：
1. 读取材料，列出可用信息和缺失项 → 2. 生成大纲和写作口径 → 3. 按大纲生成初稿 → 4. 根据反馈润色/补充/删减 → 5. 输出可编辑 docx + 修改说明

**提示词示例（团建活动策划）**：
```
帮我生成一份公司团建活动策划的 Word 文档框架。
公司约 80 人，包含：活动目标、活动主题建议、整体流程安排（含时间节点）、
分组与互动游戏建议、预算构成清单、人员分工、风险预案和注意事项。
语言简洁实用，不需要写得过于详细，重点把整体框架和关键决策项列清楚，
适合直接拿去和领导确认活动方向。
```
亮点：生成文档中用红色【待确认】标记所有需领导拍板的决策项，并在文末汇总成"拍板清单"。

**二次修改秘诀——说差异，不要重写**：
```
请在上一版基础上修改，不要重新生成整篇。
- 将活动目标压缩为3条，每条不超过50字；
- 将流程安排改成表格，列为：时间、环节、主要内容、负责人、所需物料；
- 预算构成增加：预算项目、预计金额、数量、单价、备注；
- 新增风险预案部分，覆盖人员迟到、设备故障、节目超时和突发安全问题；
- 整体语言更加正式、简洁，适合直接提交给领导审批。
输出修改后的 v2 版 Word 文档，并列出本次修改内容。
```

**进阶：文档版本对比（制度/合同）**：
```
比较 policy-v3.docx 与 policy-v4.docx。
输出新增、删除、修改和仅格式变化四类差异，附章节和原文定位。
重点标记金额、日期、责任主体、审批条件、例外和否定表达。
生成影响清单和待确认问题，不给法律结论，不修改原文件。
```
实战效果：两份合同修订版 → 自动生成 HTML 可视化对比报告（59 个修订章节、44 个关键金额/比例调整、6 个新增例外条款）。

### 1.4 Excel：把表格变成能回答问题的分析

**核心认知**：先定义业务问题，再决定图表——而不是先生成漂亮图。混着日期/文本/空值/合并单元格/多口径的脏表，直接让 AI 分析只能得到"看似专业、其实无价值"的图。

**五阶段流程**：
| 阶段 | 提示重点 | 输出 |
|---|---|---|
| 读表 | 描述工作簿结构、字段含义、样例行和明显脏数据 | 数据字典、问题清单 |
| 定指标 | 说明要回答的业务问题，不说"分析一下" | 指标口径表 |
| 清洗 | 说明空值、重复值、异常值如何处理 | 清洗后的 xlsx/csv |
| 计算 | 生成公式、透视表或统计表，保留可刷新结构 | 汇总表、公式说明 |
| 可视化 | 根据业务问题选择图表，避免图表堆砌 | 图表、分析结论 |

**提示词示例（销售数据分析）**：
```
请读取 电商销售数据.xlsx，先不要修改原文件。
业务问题：分析本月各产品线的销售表现和盈利能力，判断哪些产品线贡献高、
哪些利润表现较弱，并识别异常波动。
请输出：说明数据字段含义并检查缺失值/重复/异常/格式问题；按产品线统计销售额、
毛利、毛利率、占比并排名；按日汇总销售额和毛利率；生成柱状图对比各产品线、
折线图展示每日变化；识别异常记录；总结表现最好/需关注的产品线 + 3 条业务复盘结论。
要求：保留原始数据，统计过程可追溯；图表标题直接表达主要结论；
无法确认的原因标注为待核实，不要自行编造。
```
实战效果：7284 笔订单、8 条产品线，8 分 39 秒完成全套分析，输出 4 个文件。

**进阶：多表合并与对账**：
```
合并 input/sales 中 6 个区域的周销售表。
先检查列名、数据类型、日期范围、币种和主键，不一致时停止并列差异。
按订单号去重，但保留重复来源；汇总前输出总行数、空值、异常值和重复数。
生成 clean-sales.xlsx、exception-list.xlsx 和 reconciliation.md。
金额汇总必须与各源表合计对账，差异不为 0 时不生成管理结论。
```
实战效果：91 行源数据 → 88 行干净数据，剔除 3 行重复，识别 18 条异常，区域对账差异 -16,741 元被精确定位（西南区金额异常）。

### 1.5 PPT：不是套模板，而是把材料变成叙事

**三个前置问题**：这次汇报给谁看？对方听完要做什么决定？你有多少时间讲？

**推荐流程**：
1. 把 Word/Excel/图片/旧 PPT 转成材料摘要 → 2. 生成 6-10 页故事线和每页标题 → 3. 按确认后的大纲制作 → 4. 补图表、备注、来源映射 → 5. 版式检查（文字溢出、图片缺失、字号、颜色）

**提示词示例（从材料包制作汇报 PPT）**：
```
请根据当前工作区材料制作一份 8 页以内的 AI Agent 主题分享 PPT。
受众：对 AI 有基础认知，但不了解 Agent 的业务和管理人员。汇报时长：10分钟。
目标：让听众理解 AI Agent 是什么、与普通 AI 对话工具有什么区别、
能解决哪些问题，企业应该如何判断是否值得落地。
素材：AI术语全景手册.md 是主要内容材料；不要补充工作区材料之外的事实和数据。
全文控制在 8 页以内，每页只表达一个核心结论；案例、数据和关键判断必须标注素材来源；
PPT 标题尽量直接表达观点，不使用"AI Agent 介绍"这类泛化标题；
生成后检查文字溢出、页面留白、图表口径、图片缺失、字体一致性和页码。
整体风格：专业、简洁、有科技感。
```

### 1.6 三件套联动：把会议变成交付包

技能组合：腾讯会议（获取转写/AI纪要）→ Word/DOCX（生成 PRD）→ Excel/XLSX（生成任务表）→ Powerpoint/PPTX（生成管理层汇报）。

**一次生成 PRD + 任务表 + 汇报**：
```
请读取本次产品评审会议的转写和 AI 纪要，生成一个办公交付包。
目标：把会议内容转成可以推进研发的材料。
请输出：
1. Word: feature-prd.docx，包含背景、目标用户、核心问题、需求列表、流程说明、验收标准、风险和待确认问题；
2. Excel: action-items.xlsx，字段包含事项、负责人、优先级、截止日期、依赖、状态、验收标准；
3. PPT: review-summary.pptx，6 页以内，面向管理层，突出本次会议决议、资源请求和风险。
约束：会议中没有明确确认的内容不要写成既定结论；人名、日期、功能范围必须保留来源；
如果缺少负责人或时间，请标为待确认；先输出大纲和任务表字段预览，等我确认后再生成文件。
```

### 1.7 常见错误对照表

| 常见错误 | 更好的写法 |
|---|---|
| "帮我做个PPT，要高级一点" | 说明受众、汇报时长、页数、决策目标、参考模板和必须保留的数据 |
| "分析一下这个 Excel" | 说明要回答什么问题、统计哪些指标、按什么维度比较 |
| "写一份报告" | 说明是方案/总结/申请/纪要/PRD，并指定读者 |
| "全部自动完成，不用问我" | 先让 WorkBuddy 输出材料清单、风险清单和大纲，确认后再生成 |
| "把这堆材料合成一个文件" | 指定唯一数据源、参考文件和不能编造的字段 |

**三条铁律**：先定义问题再生成内容；二次修改说差异不重写；数字必须可追溯（无法确认的标"待核实"，不编造）。做到这三点效率至少提升 3 倍。

## 二、Excel 秒变数据看板实战（财务看板案例）

### 2.1 案例背景
财务人每月手动分析三大报表、月底加班写报告。用 WorkBuddy 搭建智能财务看板：上传 Excel 自动解析、刷新数据实时更新、一键生成 Word 分析报告 + PPT 演示，全程无代码，效率提升 10 倍。

### 2.2 看板功能全景
| 模块 | 内容 |
|---|---|
| 指标卡片 (5个) | 营业收入、净利润、净利润率、资产总额、经营现金流净额 |
| 数据图表 (2个) | 资产负债结构对比柱状图、利润构成饼图 |
| 预警表格 (1个) | 11 项财务指标条件格式预警（红/橙/绿三色） |
| 报告导出 (2个) | 一键生成 Word 商务分析报告、一键生成 PPT 演示报告 |

### 2.3 三大产出物
- **HTML 数据看板**：上传任意标准格式 Excel（含资产负债表/利润表/现金流量表三个 Sheet），自动解析展示；技术栈 SheetJS + ECharts 5.4.3，纯前端、数据不出浏览器
- **Word 商务报告（7 大章节）**：报告摘要 → 关键财务指标 → 盈利能力分析 → 资产负债结构 → 现金流量分析 → 财务指标预警汇总 → 综合结论与建议（微软雅黑，深蓝表头+条件格式）
- **PPT 演示报告（16 页）**：Midnight Executive 配色（深蓝+金），含封面/目录/5 个分隔页/指标卡片/数据表格/预警表/结语

### 2.4 效率对比
| 传统方式 | 智能看板方式 |
|---|---|
| 手动整理数据 2 小时 | 上传 Excel 1-2 秒 |
| Excel 制图 30 分钟 | 图表自动渲染 |
| Word 写报告 1 小时 | 一键生成 7 章节商务文档 |
| PPT 排版 1 小时 | 一键生成 16 页商务演示 |

### 2.5 提示词要点
- 数据安全：所有解析在浏览器本地完成，不上传服务器（财务数据安全）
- 动态分析：报告内容根据财务数据智能生成，亏损/盈利自动匹配不同分析话术
- 条件格式：预警逻辑覆盖盈利/偿债/运营/现金流四大维度，阈值可自定义扩展
- 一键复用：更换 Excel 文件后，看板、Word、PPT 三端数据同步更新

## 三、腾讯会议 × WorkBuddy：AI 管理会议全自动

### 3.1 接入方式
WorkBuddy 左侧导航栏 →「连接器」→ 找到「腾讯会议」→ 授权。之后即可用自然语言操控腾讯会议，全程不离开工作台。

**场景四：批量面试（一键创建）**

进阶：自动将会议链接写入 Excel 生成面试通知表；连接邮箱后可批量发送面试通知给面试官和候选人。

## 四、腾讯会议进阶技巧（周期会议 + 纪要自动同步）

### 4.1 技巧一：批量/周期会议，一次设置
```
帮我创建每周五下午4点的团队周会，持续3个月。
```
WorkBuddy 自动按规则创建周期会议（如每周五共 13 次）。在左侧边栏「自动化」里可看到该任务，点击可修改提示词或调整执行时间（如让 AI 在会议前几小时完成创建，方便提前通知参会人）。

### 4.2 技巧二：联动 ima 知识库，纪要自动同步
**配置步骤**：
1. 连接 WorkBuddy 小程序：主界面 logo 右侧绿色小程序标识，用注册同一手机号的微信扫码绑定（注意：不能用微信 chatbot，只能用 WorkBuddy 小程序的电脑端模式）
2. 在「电脑」模式下发指令：
```
帮我调取「项目月度复盘」的会议纪要，存入我的 ima 知识库「项目资料」里的 4 月复盘文件夹，
文件命名是「会议日期+会议名称」。
```
3. 第一次成功后再补一句关键指令：
```
请记住刚才的任务流程，把整个任务合并成一个脚本。以后类似的任务只需要点一次「运行」。
把腾讯会议和 ima 的凭证信息保存到长期记忆中。
```
以后同事问"上次怎么定的"，只需回一句："去知识库自己查"。
