# 第一部分：多模态内容生成（图片 / 视频 / 3D）

## 📌 多模态核心认知

**"多模态"** = AI 不再只会输出文字，还能输出图片、视频、3D 模型等多种形态——从"让 AI 帮你想"升级到"让 AI 帮你做"，做出来的东西直接能用。

| 输入 | 输出形态 | 典型场景 |
|---|---|---|
| 文字描述 | 图片 | 公众号封面、产品展示图、头像 |
| 文字描述 | 视频(5-10秒) | 短视频素材、品牌宣传片段 |
| 文字描述 | 3D模型(OBJ/GLB) | 电商展示、3D打印、游戏原型 |
| 一张图片 | 3D模型 | 产品实物照片→可旋转3D展示 |
| 手绘草图 | 3D模型 | 设计概念稿→立体方案 |

- 基于腾讯混元系列模型（HY-Image、HY-Video、混元生3D引擎），**中文语境理解强**，用接地气中文描述比英文 Prompt 效果更好
- **内置能力，无需额外安装插件**：对话框「Skills」搜「多模态内容生成」激活
- 图片约 10-30 积分/张；视频约 100-200 积分/条（2-5 分钟生成）

## 一、文生图：从"帮我画"到"帮我画出好图"

### 最简单的用法
```
帮我画一个洱海边喝咖啡的美女
```
自动调用 ImageGen 工具，10-30 秒出图，保存到工作区，小程序可查看下载。

### Prompt 决定 80% 出图质量（三原则）
**原则一：细节要具体**
| 差的描述 | 好的描述 |
|---|---|
| 一个美女 | 一个美丽的中国女孩，穿着oversize白衬衫，袖子卷起，坐在洱海边的木椅上喝咖啡，夕阳暖光 |

**原则二：指定技术参数**
| 关键词 | 效果 |
|---|---|
| photorealistic | 照片级真实感 |
| 8k ultra detailed | 8K超高清细节 |
| shallow depth of field | 浅景深人像虚化 |
| golden hour lighting | 黄金时段暖色调 |
| portrait photography | 人像摄影构图 |
| cinematic composition | 电影级构图 |

**原则三：否定描述避免 AI Bug**（多肢体/嘴里异物）
```
only TWO hands visible, anatomically correct hands, no extra limbs
mouth is completely empty, no objects in mouth
```

### 实操：公众号封面图
```
帮我生成一张公众号封面图：一个年轻的中国职场人在现代化的办公室里使用笔记本电脑，屏幕上有AI对话界面，窗外是城市天际线，科技感，蓝色调，商务专业风格，photorealistic, 8k ultra detailed
```
不满意直接迭代："光线太暗了，把办公室的灯光调亮一些，窗外的天空改成蓝天白云"（迭代比重写高效得多）

### 系列图创作：统一关键词模板前缀
```
统一前缀: ultra slow motion macro photography, grey-blue color palette, minimalist, photorealistic, 8k
+ 不同场景描述（坠落/触水/涟漪...）
```
统一前缀保证色调风格一致性，只改场景部分。

## 二、文生视频：让静态画面动起来

### 触发方式
```
生成一个视频:一个女孩在落地窗前光脚转圈跳舞，窗外是洱海和苍山，阳光洒进来，电影感，慢动作
```
约 5-10 秒 MP4，2-5 分钟生成，100-200 积分。

### 视频 Prompt 技巧（比图片多时间维度）
| 技巧 | 示例 |
|---|---|
| 明确镜头角度 | 全身镜头，从头顶到脚尖 |
| 描述动作细节 | 俏皮地转圈跳跃，像蝴蝶一样轻盈 |
| 加入环境描写 | 窗外是洱海和苍山，阳光洒进来 |
| 指定节奏风格 | 慢动作或电影感 |
| 强调构图 | 全身构图，人物始终在画面中央 |

**注意**：文生视频对全身构图掌控不如图片，多次强调；场景复杂（多人多动作）效果不理想，一个视频聚焦一个主体一个动作。

### 图生视频
```
帮我把这张图片变成视频：@/workspace/cover.png，让画面中的女孩轻轻转头看向窗外，头发随风飘动，慢动作电影感
```
适合公众号封面动画、产品展示动效、社媒开场视频。

### 特效视频（AI 滤镜）
```
给这段视频加上赛博朋克风格的特效滤镜，增强霓虹灯光效果，增加粒子飘散效果
```

## 三、文生3D：零代码做出专业级 3D 模型（最惊艳）

### 准备工作（一次性约 10 分钟）
1. 注册腾讯云账号（cloud.tencent.com 微信扫码）
2. 获取 API 密钥（登录 API 密钥管理页→新建密钥→**SecretKey 只显示一次立刻保存**）
3. 开通混元生3D（混元生3D控制台→开通服务→领免费资源包）

### 文生3D
```
帮我生成一个3D模型：一只戴着巫师帽的卡通猫咪，手持星星魔杖，可爱风格，圆润饱满，适合3D打印
```
1-3 分钟生成，OBJ/GLB 格式，自动调用多模态技能→连接混元生3D→提交→轮询→保存工作区。

### Prompt 公式：[主体] + [风格/材质] + [细节] + [用途]
| 优秀 | 较差 |
|---|---|
| 一个复古蒸汽朋克风格的机器人, 黄铜与铸铁材质, 齿轮关节外露, 头戴护目镜, 底座为圆形展台, 适合游戏资产使用 | 一个机器人 |

### 图生3D
```
用这张图片帮我生成3D模型：@/workspace/product.png，模型版本用3.1，保持原图的比例和细节
```
适用：产品设计（实物照片→360°展示）、角色设计（原画→3D角色）、建筑概念、LOGO 立体化。**对电商特别有用——一张产品照片生成 360° 旋转展示模型，吸引力比静态图强 10 倍。**

### 草图生3D
```
帮我把这张草图转成3D模型：@/workspace/sketch.jpg，使用草图生3D模式，生成白模即可
```
线条歪歪扭扭也能还原结构完整模型，工业设计师概念草图秒变可评审 3D 方案。

### 智能拓扑
```
帮我生成一个游戏角色的头部模型，写实风格，启用智能拓扑，输出FBX格式
```
自动优化网格布线、UV 展开、组件化，适合动画绑定和 3D 打印。

### 3D 模型应用方向
3D打印（STL）/ 游戏开发（OBJ/FBX 导入 Unity/Unreal）/ 影视动画（Blender/Maya）/ 电商展示（360°）/ 数字孪生 / VR/AR（GLB）

## 四、省积分与高效创作策略
1. **先图片后视频**：图片快 10 倍、积分只要 1/5-1/10，先用图片验证创意
2. **先低质后高质**：测试时去掉"8k""ultra detailed"，满意后再正式生成
3. **善用迭代调整**：不满意说"把光线调亮一些"，别重写重生成
4. **系列创作复用模板**：第一张调好，后续只改场景
5. **积分来源**：每日签到+100、连续7天+1000、邀请新用户、成长任务、投稿社区

## 五、常见问题避坑
- 三只手 → 加 "only TWO hands visible, anatomically correct hands, no extra limbs"
- 嘴里异物 → 加 "mouth is completely empty, no objects in mouth"
- 系列图形象不一致 → 固定关键词模板前缀只改场景
- 3D 失败 → 检查密钥配置/服务是否开通/免费额度是否用完
- 3D 精度不够 → 指令加"模型版本用3.1"
- 视频跑偏 → 多次强调"全身构图,人物始终在画面中央"
- 批量生成 → 直接列需求清单"帮我批量生成以下3D模型：1.北欧风木质餐椅 2.同系列餐桌 3.简约落地灯，统一风格逐个生成"

# 第二部分：浏览器自动化（自动填表、截图、监控）

## 📌 浏览器自动化核心认知

WorkBuddy 可以像真实的人一样打开浏览器、访问网页、点击按钮、填写表单、截图保存——比人快得多，不会累不会出错。
- 统计：上班族每天点开关闭 40-80 个网页，至少一半是重复劳动

## 四个核心能力
1. **自动填表**：批量填写问卷、报名表、数据录入
2. **自动截图**：定时截取网页变化、存档监控
3. **数据采集**：从多个网页提取数据汇总成表格
4. **竞品监控**：定时查看竞品网站，发现变化自动提醒

## 三个实用场景（含指令）

### 场景一：批量填写问卷
```
打开这个Excel名单，对每个学生，自动打开问卷网址，填入姓名，生成带姓名的专属链接，保存结果到新Excel。
```

### 场景二：定时监控网页变化
```
每天早上8点帮我检查XX教育局网站的'通知公告'栏目，如果有新通知，截图并总结要点发给我。
```

### 场景三：多平台比价
```
帮我在京东、当当、淘宝搜一下'大概念教学'这本书，对比价格和评价，给我一个购买建议。
```

## ⚠️ 安全规则（别让 AI 乱点）
1. **不要让它操作涉及金钱的页面**（付款、转账、下单自己来）
2. **敏感信息（密码、验证码）不要让 AI 处理**——让它做的事情不涉及登录最好
3. **一句话原则**：让 AI 帮忙"看"网页没问题，让 AI 帮忙"操作"你的账户要小心

## 更多浏览器自动化索引
- 三步让 WorkBuddy 直接操控你的浏览器（鸿虫龙虾）
- 我给 WorkBuddy 加了一个浏览器 Skill，它开始自己上网干活了（叶小钗）
- 自动化实战：数据汇总、批量处理、信息采集（每年多出一个月）
- 实战测评：清 1797 个浏览器书签挖出 650 个僵尸收藏（腾讯云开发者社区）
- 一条提示词让 AI 每小时发热搜日报邮件（自动化实战）
- 网页变化监控（余远航实用案例）
- 网页智能监控，竞品动态尽在掌握
- 自动采集与更新 ima 知识库（告别手动整理）

# 第三部分：微信小程序开发（WorkBuddy + uni-app）

## 📌 开发核心认知

**关键不是"一句话变应用"**，而是：小步生成、马上预览、看报错再让 AI 修。第一次做小程序卡住的不是代码，是工具链（账号/AppID/开发者工具/HBuilderX/uni-app 模板/AI 生成/调试/上传/审核）。

**核心心法**：把需求写成 WorkBuddy 看得懂的产品说明书——越像产品说明书 AI 越少乱猜，越像一句愿望返工越多。

## 完整流程 8 步

### 1. 注册小程序账号拿 AppID
- 微信公众平台注册小程序（准备没注册过的邮箱）
- 后台找 AppID（建项目/传代码用）；AppSecret 接登录/云函数才用，纯前端 Demo 先不碰
- 练手可用测试号，上传/审核前换成真实 AppID

### 2. 装两套工具（各管一段路）
- **HBuilderX**：管"写和生成"（创建 uni-app 项目、选模板、运行到微信小程序、发行代码）
- **微信开发者工具**：管"跑和发布"（模拟器、调试器、真机预览、上传代码）

### 3. 用 uni-app 模板创建项目
- HBuilderX → 新建项目 → 类型选 uni-app → 从空白/官方基础模板开始
- 项目名用英文（book-market / fitness-helper），路径别太深少用中文空格
- 先运行一次确认环境通：运行到小程序模拟器→目标"微信开发者工具"→配置工具路径

### 4. 把需求交给 WorkBuddy（别只写一句话）
可复制提示词模板：
```
这是一个 uni-app 微信小程序项目。请先阅读项目结构，不要马上改代码。
我要做一个【校园二手书】小程序，第一版只做前端 mock，不接支付、不接真实数据库。
页面包括：
1. 首页：分类、搜索框、推荐书籍卡片。
2. 发布页：书名、价格、成色、联系方式。
3. 详情页：封面、描述、价格、联系按钮。
4. 我的页：我发布的书、使用说明。
设计风格：清爽、学生感、浅蓝和薄荷绿，不要暗黑风。
请先输出你的开发计划和文件修改清单。确认后再开始生成代码。
```
**任务说明五要素**：目标（给谁用解决什么事）/ 页面（首页列表详情我的）/ 数据（字段示例权限边界）/ 风格（行业气质配色）/ 验收（必须能点通的路径）

**分步做更稳**：第一步只做页面结构和 mock 数据 → 第二步补交互（搜索/表单校验/跳转）→ 第三步补空状态/加载/错误提示 → 第四步列测试清单

### 5. 调试：看控制台，把错误原样丢回 WorkBuddy
```
运行到微信开发者工具后报错，错误如下：【粘贴完整控制台错误】
我刚才的操作路径是：首页 -> 点击第一本书 -> 进入详情页。
请定位原因，只修改必要文件，并告诉我修改了哪些地方。
```
重点看：页面是否白屏 / 控制台红错 / 点击路径能否走通。常见问题：图片路径不对、路由没注册、组件名写错、样式真机挤压。

### 6. 真机预览（比模拟器更重要）
- iPhone 和 Android 各扫一次
- 首屏加载速度 / 底部按钮是否被安全区遮住 / 输入框弹窗授权是否正常 / 文字是否被挤出屏幕
- 真机样式崩了可发截图让 AI 修："这是 iPhone 真机预览截图，底部按钮被安全区挡住。请修复样式，要求兼容 iOS 安全区，不影响 Android。"

### 7. 上传代码生成体验版
- 确认 AppID 是真实小程序 AppID（上传按钮点不了=还在用测试号）
- 点击上传 → 填版本号和备注 → 后台版本管理 → 生成体验版二维码
- 体验版阶段先让别人点一遍（首次进入/授权/表单/异常提示），自己写的路径容易"自动绕过坑"

### 8. 提交审核前自查清单
账号（AppID 正确，完成认证/备案）/ 代码（无红错主流程跑通）/ 真机（iOS+Android 各扫一次）/ 权限（隐私弹窗与实际能力一致）/ 包体（图片压缩分包检查）/ 材料（类目截图测试账号版本说明齐全）
- 被驳回：把驳回原因复制给 WorkBuddy 拆成"产品信息要改/代码要改/素材要补"三类，很多时候是页面描述、类目或隐私文案没对齐

## 新手 5 天节奏
第1天注册账号装工具跑通空白模板 → 第2天 AI 生成 3-4 个核心页面 → 第3天调试主流程补空状态 → 第4天真机预览上传体验版 → 第5天整理审核材料提交
