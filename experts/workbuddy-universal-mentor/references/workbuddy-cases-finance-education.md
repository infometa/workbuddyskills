# 第一部分：金融投资案例

## 📌 核心方法论

**AI 投资分析的定位**：AI 不是预测工具，而是"规则执行放大器"。真正的投资收益 = 认知 + 纪律 + 系统化执行。
- **AI 适合做**：数据整合、合规性检查、生成报告、定时提醒
- **AI 不适合做**：预测市场（不了解风险偏好与宏观走向）、代替决策（最终操作必须人工确认，尤其大额调仓）、实时交易（无法自动下单，仅提供策略建议）
- **AI 的核心价值**：冷静、全面、可追溯——严格按规则推理，规避情绪化追涨杀跌

## 一、股票价值投资分析系统（八维度评分框架）

> 不用写代码、不用盯盘，从一句话需求到八维度评分系统全程实录

### 第一步：一句话启动（先跑起来再优化）
```
你是我的价值投资分析师。我给你一批A股自选股，请你从巴菲特和芒格的视角，对每只股票进行综合评分和投资建议分析。
```

### 第二步：补充搜索信息（让它学会时效性）
```
在分析每只股票时，请先搜索以下公开信息：
1. 最近一个季度的机构调研记录
2. 行业近三个月的重要政策变化
3. 公司近期的管理层变动或重大公告
4. 同行业竞争对手的最新动态
然后结合这些信息，更新你的评分和建议。
```
（纯历史数据分析=后视镜开车，加实时信息搜索才是完整判断）

### 第三步：持续迭代框架
每次有新想法就加给它（看到自由现金流文章→加维度；聊到管理层诚信→加维度；读到行业周期框架→加维度）。AI 会比较新旧框架差异，保留有价值改进，淘汰不适用的——它比人更"熟悉"模型全貌，取舍更客观。

### 第四步：季报窗口期大规模刷新评分
```
现在所有上市公司年报季报已全部披露。请对我的自选股列表进行一次全面的评分刷新：
1. 重新抓取每只股票最新的财务数据（营收、净利润、ROE、资产负债率、自由现金流）
2. 对比上一期财报的变化趋势
3. 根据最新的估值水平（PE/PB/股息率）调整评分权重
4. 输出更新后的综合评分表和投资建议
重点关注：哪些公司的基本面发生了实质性变化？
```
（季报窗口期是更新框架的最佳时机——数据全、信息新、分析质量最高）

### 第五步：融合知识库，让 AI "进化"
```
我整理了一份投资思维知识库，包含以下框架：
- 巴菲特的护城河理论 - 格雷厄姆的安全边际原则
- 芒格的多元思维模型 - 塔勒布的反脆弱思维
请扫描这些内容，提取与股票评分相关的要素，融入现有的八维度分析框架中，然后重新刷新所有自选股的评分。
```
（AI + 专业知识库 = 从"数据分析"升级为"投资决策"）

### 最终形态：八维度评分系统

| 维度 | 核心指标 | 评分逻辑 |
|---|---|---|
| 盈利能力 | ROE、净利润率、毛利率 | 连续3年趋势+行业对比 |
| 成长性 | 营收增速、利润增速 | 复合增长率+未来预期 |
| 估值水平 | PE/PB/股息率 | 历史分位+同行对比 |
| 财务健康 | 资产负债率、现金流 | 偿债能力+现金流质量 |
| 护城河 | 品牌/专利/网络效应 | 行业地位+竞争优势 |
| 管理层 | 诚信度、执行力 | 历史行为+机构评价 |
| 行业前景 | 政策、周期、竞争格局 | 行业趋势+政策风险 |
| 安全边际 | 当前价格VS内在价值 | 折现估值+安全空间 |

### 三步搭建法总结
1. **一句话启动**：告诉 AI 身份和任务，先跑起来
2. **持续喂信息**：每次有新想法/数据/框架都加给它，让模型越来越完善
3. **融合知识库**：把专业知识/经验教训整理成知识库，让 AI 用思维框架做判断

> AI 负责执行和计算，你负责思考和决策——这才是正确分工。甚至可以把别人的研究报告发给它，它会提取关键信息影响对应股票的评分。

## 二、基金投资分析完整案例（三步流程）

> 100 万模拟基金组合、15 只公募基金、覆盖 A股宽基/美股标普500/国内债券/黄金

### 背景设定（投资原则示例，必须可量化）
```
· 调仓时间：只允许6月底和12月底大规模调仓
· 仓位上限：股票≤50%，债券≥40%
· 加仓条件：有知有行温度≤30°，且股票仓位<40%
· 减仓条件：有知有行温度≥60°，且股票仓位>45%
· 定投规则：每月第一个交易日定投固定金额（如5000元）全天候策略
```

### 三步分析流程（系统化投资体检）
**第一步：读取实时市场数据**（AI 自动搜索公开数据）
| 指标 | 数值 | 解读 |
|---|---|---|
| 有知有行全市场温度 | 54° | 中估偏暖 |
| 银行螺丝钉星级 | 3.6星 | 适中偏高 |
| 中证800 | 已高估 | A股大盘偏贵 |

**第二步：读取个人持仓数据**（上传持仓截图，OCR 识别整理）
- 关键发现①：实际股票仓位 41% < 50% 合规上限 ✅
- 关键发现②：美股持仓碎片化（4 只标普500基金，3 只金额极小）
- 关键发现③：黄金仓位仅 1.8%，低于 10% 目标配置，需补充

**第三步：对照投资原则，生成调仓建议**
| 原则 | 当前状态 | 是否触发 |
|---|---|---|
| 6月底允许大规模调仓 | 现在是6月 | 允许，但需看市场 |
| 股票仓位≤50% | 41% | 合规 |
| 市场温度≤30°时加仓 | 当前54° | 不触发 |
| 全天候再平衡 | 规定12月底 | 6月不可操作 |

**最终建议**：6月底无需大规模调仓（温度54°非极端、仓位合规、未触发操作条件）；可选择性清理美股小份额基金合并到主仓，补充黄金配置。

### WorkBuddy 四大关键能力
1. **多源数据整合**：实时搜索公开数据 + 自动读腾讯文档持仓表 + OCR 识别同花顺持仓截图
2. **原则驱动决策**：读取预设投资原则 → 代入市场数据+持仓状态 → 生成可追溯、可解释的调仓建议（避免追涨杀跌）
3. **错误修正与智能记忆**：记录错误模式（如"禁止编造数据，必须实时读取"）→ 生成可复用 Skill 确保后续分析正确
4. **定时自动化任务**：每月首交易日自动读持仓+检查买卖信号+定投提醒；每年6月底/12月底自动生成调仓报告；温度<30°时微信推送低估提醒

### 三大避坑指南
1. **防 AI 编造数据**：强制要求注明数据来源（指定从在线文档读取最新数据），调仓前人工复核关键数据
2. **防规则过时**：投资原则随时在在线文档维护最新版，显式要求每次从云端实时读取，不依赖历史对话记忆
3. **防数据延迟**：温度计每日 20:00 更新、星级收盘后发布——重要调仓等待日终数据确认，不基于盘中数据操作

### 行动指南
1. 把投资原则与持仓数据记录到在线文档
2. 让 WorkBuddy 读一次在线文档，生成第一份持仓报告
3. 配置定时任务，每月自动提醒定投
4. 定期自动生成调仓建议，经人工复核确认后执行

# 第二部分：教育教学案例

## 📌 教育核心方法论

**AI 不会替代教师的判断力，但可以帮你把机械重复的活儿先干了**——省下的时间，留给课堂，留给学生。
**价值主张**：不是帮你省几小时，而是让你有底气去做以前"一个人肯定做不完"的事（整套课程体系/有凝聚力的教研团队/可传承的教学经验/拿得出手的成果展示）。

---

## 一、教育教学 10 个实战应用（煮鹤斋）

### 场景1：10分钟搭出一周备课包
```
按第X周教学计划，生成三件套：教师版教案、学生版学案、课后练习版。
```
（读取学期计划→教案含教学目标/师生互动/板书→学案去答案留空白可打印→练习分层配套；传统6-8小时→约15分钟，任何学科可套）

### 场景2：把任意课文/知识点变成三层任务链
```
把《XX》/'XX知识点' 转化为三层递进任务：基础理解→分析应用→拓展创造，并配评价标准。
```
（三层由浅入深适合不同水平学生；每层配评价量规，学生自评互评可用；语文套课文/数学套定理/英语套语篇/理化生套实验）

### 场景3：课后练习——不超纲、不重复、分层出
```
根据今天讲的'XX知识点'，出一份30分钟练习单，分基础/提高/挑战三层。
```
（紧扣当天内容不超纲、自动难度梯度、对标考试题型；小学字词/初中几何/高中化学都适用）

### 场景4：把教学经验变成"智能体"（数字分身）
```
把我教XX学科X年的经验，整理成一个教学智能体，能按我的风格出教案、出题、评学情。
```
（把你的教学理念和方法结构化为可执行规则→生成可加载的智能体模块→以后备课加载它按你的风格出活；"即使你不在了，你的教法还能帮到后来的人"）

### 场景5：散落教学资料变成可检索知识库
```
扫描我电脑里的教案、课件、试卷，按学科/年级/知识点分类，建一个知识库。
```
（自动读取本地文件→按维度分类→生成结构化索引，搜"第三单元""期末复习"秒达）

### 场景6：教研组任务自动分发、自动汇总
```
把本周教研任务按分工发给组内每位老师，完成后自动汇总进度。
```
（按分工表自动生成任务卡→提交后自动汇总完成率→谁完成/谁没完成/卡在哪一目了然；把"人盯人"变"系统盯人"）

### 场景7：定时自动化——周报、总结自己长出来
```
每周五下午自动汇总本周教学进度，生成教研组周报。
```
（教学进度表/教研总结/学期教学计划等重复性文字工作交给定时任务）

### 场景8：用 IMA 知识库让 AI 真正"懂你"
```
根据我电脑里的教学资料，帮我建立 IMA 知识库——先确定建库方案，再执行建库。
```
（教案/课件/试卷/论文全变成 AI 可理解的"知识"，之后出教案出题都基于你的真实资料；"AI 是厨师，知识库就是你家的米面粮油"）

### 场景9：带一支教研团队（从一个人干到一群人协作）
```
帮我设计一套教研组协作方案：怎么分工、怎么降门槛、怎么让新老师快速上手。
```
（生成各学科/年级分工方案和任务模板→把验证过的教研流程写成可复制 SOP→新老师拿到就能上手）

### 场景10：一键生成教学展示材料
```
把这套教学方案排版成公众号文章 / 宣传海报 / 汇报PPT / 成果册。
```
（一次输入多格式输出：公众号排版/PPT汇报/成果画册；评优评先/成果推广/公开课展示直接用）

## 二、教师备课全流程指南（可可，五段式）

### 第一步：装好需要的 Skill（三类起步）
- 网页搜索类（查课程标准/公开课/教学资料）
- 文档处理类（读 Word/PDF/表格，生成可修改文件）
- PPT 类（制作导出课件）
- 自检指令："请检查当前任务可以调用的Skill。我接下来要为【年级】【学科】【课题】备课，需要搜索资料、读取文档、生成教学设计和PPT。请告诉我现有Skill能否完成，缺少什么先列出来，不要直接开始生成。"

### 第二步：新建备课任务，资料放对位置
- 每个课题单独文件夹，让 AI 先建目录：01_原始资料 / 02_搜索资料 / 03_教学设计 / 04_课件 / 05_音频与练习
- 自己的资料先放进去（AI 能找到网上内容，但不知道学校真实要求和学生情况）
- 指令："请为【年级】【学科】【课题】建立一个备课项目，先检查'01_原始资料'中的文件并列出已有材料。缺少的内容单独列出，先不要写教案，也不要修改原始文件。"

### 第三步：一次说清楚资料怎么搜（要求要具体）
```
帮我整理【年级】【学科】【课题】的备课资料。请分别查找【5份完整教学设计】【5个公开课或说课视频】【5份板书或课件参考】。每份资料保留标题、来源、可打开的原文链接和一句话摘要，按类别整理成汇总表，保存到"02_搜索资料"。先把搜索计划给我确认，再开始执行。
```
- 两个细节不能省：保留原文链接（方便核对）；先确认搜索计划
- 权威来源建议：国家中小学智慧教育平台、人民教育出版社、教育资源网、教师吧、学科网、B站、国家教育资源平台

### 第四步：先分析再生成，教案和 PPT 分开确认（关键）
**先只做分析**：
```
请阅读"01_原始资料"和"02_搜索资料"，分析不同教学设计的导入方式、主问题、课堂活动和板书思路。先给出3种可选的教学主线，说明各自适合什么学情，不要直接生成完整教案。
```
**老师选定主线后再生成教案**：
```
按我确认的第【X】种主线生成教学设计。必须保留【学校要求或教师个人要求】，内容包括教学目标、重点难点、教学过程、师生活动、设计意图、时间安排和作业。引用资料时标注来源，无法确认的内容不要补写。先生成Word初稿，等我确认后再制作PPT。
```
**教案确认后再做课件**：
```
根据已经确认的教学设计制作【12至15页】PPT。页面只保留课堂需要呈现的内容，讲解提示放进演讲者备注。先给我看PPT大纲和页面风格，确认以后再生成可编辑的PPTX文件。
```
（可续：生成朗读音频、课堂练习、课后任务、学情分析表）

### 第五步：同类任务做熟后保存为 Skill
```
请把刚才的备课流程整理成一个可复用的Skill。触发词设置为"开始备课"和"教学设计"。固定步骤包括检查原始资料、列出缺失内容、制定搜索计划、整理资料、提供3种教学主线、生成教学设计和PPT大纲。任何文件写入和成品生成都要先经过我确认。请先展示完整配置，不要直接安装。
```

### 三条安全线
1. 学生姓名尽量换成代号，不把真实身份和敏感信息交给 AI
2. 成绩分析必须依据原始表格，不能让 AI 自行补出结论
3. 教学资料保留来源，生成的教案课件检查后再使用

## 三、5 个教师自动化工作流（师易讲应用，照着做就能用）

### 基础准备（10分钟）
1. 下载安装 WorkBuddy 桌面客户端（自动化任务需客户端后台运行，建议开机自启）
2. 领积分：免费版每月 500 积分，新用户「个人中心→用量管理」领 1500 新人礼包；简单任务选快思考模型（Deepseek-V4-Flash）更省
3. 两个入口：对话框直接说"帮我创建一个自动化任务，每天X点做XXX"；或「自动化」面板管理

### 工作流一：成绩分析→Word报告→PPT 一条龙
**一句话创建**：
```
帮我创建一个自动化任务，任务内容是：分析这份Excel成绩表，计算平均分、及格率、优秀率；找出进步最大的5个学生和退步最大的5个学生；按知识点维度做失分分析。然后把分析结果写成一式期末质量分析报告（Word格式），包含整体概况、班级对比、典型学生分析、教学建议。最后根据报告生成15页PPT，适合教职工大会汇报。
```
- 触发方式：第一次选"立即执行"现场看效果
- 提速技巧：跑通后输入"把上面指令保存为快捷指令 /成绩分析"，以后拖入新 Excel 输 /成绩分析 即可

### 工作流二：作业批改+学情报告（手写试卷自动识别）
1. 获取智谱 API Key（glm-4v-flash 模型目前免费支持手写体 OCR）
2. 创建技能："帮我创建一个技能，功能是批改数学试卷。流程是：用户上传试卷图片 → 调用智谱API识别手写答案 → 比对标准答案 → 生成HTML学情报告。报告包含：成绩总览卡、逐题诊断表、知识点强弱项分析、学习建议、需人工复核标记。"
3. 使用：拍照上传试卷 → 提供标准答案 → 说"调用批改技能，按这份标准答案批改"
- 使用建议：选择题识别准确率 95%+；填空题/解答题 AI 初判后人工复核；报告 HTML 可直接打印或发家长群

### 工作流三：从课题到课件 PPT 一键生成
1. 准备素材（Word 教案/教材扫描件/知识点列表/课题描述）
2. 生成大纲："根据这份教案生成PPT大纲，包含封面、学习目标、背景导入、文本分析、课堂讨论、拓展延伸、作业。"（可追加调整"第6-9页压缩到4页，加一页人物形象分析"）
3. 生成 PPT："大纲OK了，生成.pptx文件。风格简洁大方，适合课堂投影。每页要点不超过5条，字号不小于24pt。"
- 提速技巧：分环节生成质量更高；AI 完成约 70% 工作量，剩下 30%（动画顺序/图片位置/字体微调）定风格

### 工作流四：定时自动学习+知识沉淀
**每日学习任务**：
```
今天是自动化学习任务的第{循环次数}次执行。请学习关于[某学科/某教学法]的最新理念或案例。要求覆盖：核心理念、课堂应用案例、与当前教学的结合点。用Markdown格式，每个维度用二级标题分隔。末尾附「今日要点速览」表格。将学习笔记追加到工作区的.workbuddy/memory/下的当日日志文件中。
```
（每天 22:00 执行；{循环次数} 占位符让 AI 知道第几次学习）

**每周回顾任务**（周日 20:00）：
```
请读取 .workbuddy/memory/ 中最近7天的日志文件，提炼本周学到的3个最重要的知识点，用一问一答形式输出，方便我自测回顾。
```
（形成 学习→沉淀→回顾 完整闭环；省积分：日常学习任务切 Deepseek-V4-Flash，每月仅 800-1200 积分）

### 工作流五：接入 ima 知识库，写方案不再从零开始
1. 左侧「资料库」→「ima知识库」OAuth 授权绑定（支持 pdf/docx/xlsx/pptx/txt/md）
2. 上传教案模板/过往优秀方案/教研活动记录/课程大纲建立索引
3. 对话中引用："@我的教学资料库 根据库里的课程大纲和教案模板，写一份暑期特色课程招生说明初稿。"
4. 保存快捷指令 /写总结 等

### 通用踩坑提醒
| 坑 | 解决办法 |
|---|---|
| 指令太泛，AI 输出质量差 | 提示词写具体：限定输出格式/维度/篇幅 |
| 测试没发现问题，正式跑崩 | 每次新自动化创建后先点"立即执行"验证 |
| 到时间没运行 | 检查 WorkBuddy 客户端是否后台运行（需在线才能触发） |
| 中文笔记乱码 | 指令中明确"使用UTF-8编码写入文件" |
| 积分消耗太快 | 简单任务选快思考模型；优先每日签到（月均约3000分）+写社区教程赚积分（精选3000分/篇） |
