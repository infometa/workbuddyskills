# 第一部分：市场营销 & 获客增长案例

## 📌 营销核心洞察

**企业要的 AI 不是"聪明的聊天机器人"，而是能接业务、搞客户的 AI**：看懂客户微信需求辅助聊天转化、调用真实业务数据实时分析、调用知识库直接回答客户业务问题并给解决方案。
**核心公式**：WorkBuddy = 大脑（理解意图）；SCRM Skill = 手脚（连接真实企微数据+运营能力）；企业微信/SCRM = 真实战场。三者结合 = "能说、能懂、能查、能做"。
**SKill 的价值**：把 SCRM 从"操作后台"升级为"可被 AI 调度的业务能力中心"——原本"打开后台→切页面→设筛选→拉数据→自己总结→定动作"的碎长路径，压缩成"一句自然语言提问→AI理解→调用Skill→返回结构化结果/建议"。

## 一、WorkBuddy + 企业微信：6 个获客转化场景实战

### 场景一：早会前快速盘点新增/待跟进客户
**指令**：
```
帮我查我最近7天新增客户和重点跟进客户情况
```
输出：新增客户、重点客户、待跟进摘要、优先处理建议。
**价值**：让销售负责人从"自己查数据"变成"直接看结论"，省去后台来回切（客户列表→标签→跟进记录→互动情况→人工汇总）。

### 场景二：客户拜访前 5 分钟补齐客户全貌
**指令**：
```
我要去拜访XX客户，帮我准备一下
```
自动整理：客户基本情况、客户标签、历史关键沟通内容、当前商机进展、对接联系人、最近承诺事项、拜访重点话题 → 生成拜访前简报。
**价值**：AI 替代的不是思考，而是你在不同模块之间搬运信息的过程。

### 场景三：复盘客户群效果（不只"发了没有"）
围绕客户群和群发效果提炼：群活跃情况、群发执行情况、重点群表现差异、后续优化建议。
**价值**：把"人工翻后台+汇总表格+写总结"大幅压缩，让复盘从"靠毅力"变"靠工具"。

### 场景四：规划并创建群发任务（从建议到执行）
让 AI 围绕某活动/某类客户/某产品触达任务，梳理内容，确认后创建群发任务。
**适合**：刚开始做企微运营不知怎么规划触达的人；没时间手动创建群发任务的人。

### 场景五：客户分层与标签盘点（找"该服务谁、该转化谁"）
围绕标签、跟进情况、客户状态盘点：
```
哪些客户近期新增但未有效跟进
哪些高价值标签客户需要优先触达
哪些客户沉默时间较长，适合唤醒
哪些客户可以进入下一步成交推进
```
**价值**：让 AI 迅速找到最该动的那批客户，把"沉寂数据"变成"可执行名单"。

### 场景六：一线业务问答助手（新人快速上手 SCRM）
让 WorkBuddy 承担"业务使用助手"：新人从"我想解决什么问题"出发，用自然语言问 AI（如"这个客户怎么看历史记录""群发怎么筛选对象"），不用先学后台路径。
**价值**：降低 SCRM 使用门槛、缩短新人上手周期、让工具真正被用起来。

# 第二部分：供应链 / 采购 / 物流案例

## 📌 供应链核心洞察

**根因不在系统，在数据入口**：供应商送货单格式五花八门（Excel/PDF扫描件/手写拍照），非结构化数据进了 ERP 就等于没进——所以上了 ERP 还在手工对账。
**WorkBuddy 的独特优势**：桌面级智能体，不需要打通 ERP 接口、不需要 IT 开发中间件，直接"看"Excel/PDF/图片，像雇了一个不会累的财务助理逐条比对。
**核心判断**：你缺的不是另一套系统，而是一个能替你"翻单据"的智能工具——它只是在你现有的 Excel 和 PDF 上帮你把比对做了。

## 一、物流/采购/库存 3 步自动对账法（数转笔记）

> 浙江湖州家具厂真实案例（年营收 8000 万，ERP 上了三年）：月底对账 300+ 张供应商单据，2 个财务两天半 → 20 分钟跑完 + 复核标红项；月结对账周期从四天半 → 一天以内。

### 第一步：采购单和供应商送货单自动配对
```
核对送货单上的物料编码、数量、单价是否与采购订单一致，不一致的标红
```
- 把采购订单 Excel + 供应商送货单 PDF/图片放一个文件夹，AI 模拟人操作：打开 Excel、读 PDF 表格、识别手写数字、逐行比对
- **实操关键**：第一次处理新供应商单据格式时"教"它一次（如"A 供应商送货单数量列在第5列、单价在第7列"），之后自动套用
- 效果：300 张单据 20 分钟跑完，财务只复核标红差异项

### 第二步：物流回单和仓库签收记录的差异比对
```
比对同一采购单号下的发运数量和实收数量，差值超过5%的标注出来，并列出对应的物流回单号和仓库签收日期
```
- **语义匹配而非数据匹配**：能理解"物流回单单号 ZW20260528-003"和"仓库台账备注'天正物流5月28日第三车'"可能是同一批次（按日期/供应商名称/物料类别交叉比对）
- 效果：以前 1.5 天 → 半小时出结果，省下的时间做真正需要判断力的事

### 第三步：自动生成对账差异报告和调整建议
按财务制度定制模板输出三部分：
- **采购差异**：哪些送货单与采购订单不符、差异金额、建议（联系供应商确认 / 按实收入账）
- **物流差异**：哪些回单和签收不一致、差异数量、建议（核实在途 / 入库调整）
- **库存差异**：哪些物料系统库存与盘点实存不一致、建议调整分录
- 可定制规则："差异金额500元以内自动标注'小额差异建议直接调整'；超5000元标注'需采购经理确认'"

### 开始之前要注意的三件事
1. **别期望一次性完美**：第一个月跑一遍，把识别不准的案例记下来调指令，第二个月再跑，两个月基本稳定
2. **数据安全底线**：送货单含供应商报价底价，喂给 AI 前脱敏（去掉单价列，只留数量和物料编码）——"最小权限原则"
3. **对完账不是终点**：连续跑三个月会自然看到——哪些供应商单据总出差异、哪些物流回单时效最差、哪些物料库存差异率最高

# 第三部分：项目管理 & 产品研发案例

## 📌 PM 核心洞察

**反共识观点**：大多数团队在"逼大家适应流程"（每天填表、每天站会），其实应该让工具适应团队的沟通习惯。WorkBuddy 帮团队做到的，不是"规范了流程"，而是"不增加额外负担的情况下，自动把信息整理成了结构化的东西"。
**核心定位**：WorkBuddy 不是项目管理工具（没有甘特图/依赖关系/资源分配），而是**"信息整理放大器"**——解决项目管理工具覆盖不到的地方（微信群零散信息、跨部门沟通记录、客户需求变更历史追溯）。

## 一、WorkBuddy 项目管理实战（硅基智见，3 个客户项目）

> 5 人团队（1PM+2执行+1设计+1我），同时跟进 12 个任务节点，0 个漏掉的交付物。PM 信息整理时间从每天 1.5 小时 → 30 分钟。

### 项目一：公众号内容排期管理（最轻量）
- 做法：每天下班前让 WorkBuddy"读今天的微信群聊天记录（复制粘贴进去），总结今天哪些任务有进展、哪些没动、有没有客户反馈需要跟进"
- 总结直接复制到微信群 @相关同学确认
- **成功关键**：不需要大家额外填表，把已存在的聊天记录喂给 AI 即可，工作习惯没变但 PM 信息完整性提升
- **踩坑**：一次粘贴 3 天聊天记录（8000 字）会"串台"——每天记录分开喂

### 项目二：网站重构需求管理（结构化输出）
- 做法：微信语音转文字 → 喂给 WorkBuddy → "把需求整理成结构化列表，按优先级排序，标注哪些是客户明确说的，哪些是推测的"
- **关键技巧**：给明确输出格式要求（如"用markdown表格输出，包含3列：需求描述、优先级、明确/推测"），输出直接能用
- 准确率约 85%，**整理结果必须人工跟客户确认一遍**（语音转文字可能漏信息）

### 项目三：跨部门协作的任务拆解（最复杂）
- 做法：描述宏观目标（如"2周内完成市场活动落地，获取5000个leads"）→ 让 AI 拆解成"市场部负责什么、设计部负责什么、数据部负责什么"，给出每个子任务的时间节点和交付物标准
- 拆解结果与 3 个部门负责人开会调整约 30% 节点（AI 不了解实际产能，时间偏乐观）
- 每天让 WorkBuddy"读一下飞书文档的更新记录，总结哪些任务有风险"

### 三大避坑指南
1. **AI 任务时间估算 ×1.5 安全系数**：AI 按理想情况算（"设计落地页需要2天"），实际反复修改要乘 1.5-2 倍
2. **跨部门沟通需要"翻译"**：AI 输出用标准项目管理术语（交付物/里程碑/风险点），各部门听不懂，要翻译成大白话再确认
3. **一个对话管一个项目**：混多个项目信息会让总结变"混合体"完全没法用

### 核心思路总结
- 不增加额外负担，让 AI 帮你就有的信息做结构化整理
- 轻量排期管理 / 需求结构化整理 / 跨部门任务拆解三种用法
- 专业功能（甘特图/依赖关系/资源分配）配合专业工具（Jira/Monday/飞书项目）用

# 第四部分：政务 / 行政 / 办公案例

## 📌 政务办公核心洞察

**WorkBuddy 十二项核心能力**（一个账号覆盖 80% 桌面工作）：文字创作 / 数据分析 / 文档处理 / 会议助手 / 代码与公式 / 联网检索 / 企业知识库 / 多模态生成 / 翻译沟通 / 流程自动化 / 协同集成 / 企业级安全（ISO27001，支持私有化部署，敏感数据不出网）。

**与云端通用工具的分工**：云端工具做快问快答；WorkBuddy 处理本地大文件、敏感数据、跨系统流程。两个都备上按场景选择效率最高。
**上手四步**：创建工作空间 → 上传材料 → 自然语言下指令 → 追问迭代。

## 一、四大高频办公场景实战（云巴巴保姆级教程）

### 场景一：日常办公——把时间抢回来
**会议纪要（30分钟 → 5秒）**：
```
生成结构化纪要：1.主题/时间/参会人；2.讨论要点；3.决议（责任人+截止日期）；4.待跟进事项。
```
进阶："把待办生成催办邮件发给责任人"（连邮件草稿都写好）。

**跨国邮件**：
```
写一封英文邮件给客户，告知发货延迟5天（原材料延误），表达歉意并承诺加急，语气专业友好不卑微。
```

**周报生成**：
```
按本周完成/下周计划/需协调三段式整理成正式周报。
```
（列要点如"完成A报价、修复B Bug、整理Q1数据"，参考上周格式的细节也能执行）

### 场景二：财务数据——让数字会说话
**报表分析**：
```
分析各区域销售，找出同比增速最快/下降最多的前三区域，指出波动最大的月份，给出3-5句汇报结论，并建议下一步看什么指标。
```
（不仅会算，还能像财务总监一样给建议）

**报销审核（5分钟看完几百单）**：
```
检查重复报销、超标项（机票/酒店/餐费）、日期异常（周末无出差）。列出异常并标注原因。
```
输出高风险/中风险/合规清单；追加"把异常行导出成Excel并标红"直接执行。

### 场景三：文本撰写——从 0 到 1 的飞跃
**方案大纲**：
```
帮我写'企业AI知识库'方案大纲，包含背景痛点、方案概述、技术架构、实施计划、案例。
```
（先确认大纲再逐章细化，避免返工）

**通知公告（双语一键通）**：
```
写端午放假通知：5月31日至6月2日放假，5月30日上班，需值班锁门。风格正式不死板，同时出英文版。
```

### 场景四：合同审核——法务的"火眼金睛"
**审核合同**：
```
审核这份合同，站在我方角度：1.找出不利条款，标注高/中/低风险；2.指出模糊表述；3.列出缺少的关键条款；4.逐条给出修改建议。
```
典型输出示例：
- 交期条款"25天内交货并安装"→ 高风险，建议改 45 天或拆分交货与安装
- 验收条款"以甲方最终确定的标准为准"→ 高风险，建议引用国标或双方确认的规格书
- 违约金"每日按合同总额1%"→ 高风险（年化365%远超惯例），建议日 0.05% 封顶 5%
- 尾款"20%待质保期满后支付"→ 中风险，建议验收后 30 天付清
- 知识产权"定制成果全部归甲方"→ 中风险，建议区分专用成果与通用底层
- 指出缺失：不可抗力、甲方逾期付款责任、保密条款

追问"把以上修改建议整理成一份正式修改意见函"→ 直接生成可发给对方的 Word 草稿。

**起草合同**：
```
起草采购合同：甲方XX，乙方XX。标的：企业级AI应用套件，金额300万，交期签约后45天，质保3年，付款比例3-6-1。必须包含以下章节：标的、交付验收、质保、违约、知识产权、争议解决。
```
（重大合同仍需法务或律师终审——AI 帮你完成从 0 到 80%，避免遗漏明显风险）

## 二、提示词技巧六要点（让输出质量翻倍）
1. **给角色**："你是十年经验的法务专家"比"帮我审合同"效果好得多
2. **给背景**："我们是设备制造商，客户是政府部门"比"写产品介绍"精准
3. **给格式**："用表格""500字以内""分三个要点"
4. **给示例**：贴一份满意的过往文档，说"参考这个格式来写"
5. **分步走**：复杂任务先出大纲，确认后逐节展开
6. **追问**："更简洁一些""换个视角""再加一版对比"

## 三、新手最容易犯的 5 个错（避坑指南）
1. **当成搜索引擎用**：拿到回答就走不追问 → 养成"追问三轮"习惯（复述需求/自我评价/再优化一版），90% 提升发生在第二三轮
2. **一个对话聊到底**：上午聊合同下午问周报 → 切换主题就新建工作空间
3. **复杂任务一句话扔过去**：直接说"帮我写Q2销售策略"只能靠猜 → 先让它问你五个问题，或先出大纲
4. **拿第一版直接用**：→ 让它自我批判+优化一轮，你再扫一遍，60 分初稿拉到 85 分
5. **半文半白客气话**："贵AI能否惠赐高见"→ 像跟同事说话一样自然、直接、具体、带数字
