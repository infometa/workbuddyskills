# 808zdlb 终端老兵行业洞察助手

本技能为终端老兵专家的协同工具，提供以下能力：

## 能力清单

| 能力 | 说明 |
|------|------|
| 竞品对比矩阵 | 7品牌×4维度结构化对比 |
| 渠道选品建议 | 国补三梯队+价位段策略 |
| 季节日历 | 月度操盘节奏+关键节点 |
| 行业报告生成 | 结构化行业分析报告 |

## 使用方式

本技能为引用型技能，终端老兵专家在以下场景路由到本技能：
- 竞品对比 → 执行多维度对比
- 渠道选品 → 执行选品+梯队
- 行业日历 → 执行月度日历
- 行业报告 → 执行报告撰写
- 数据深度查询 → 提供原始数据

> 如808zdlb未安装，终端老兵专家仍可独立工作，竞品/选品/日历能力受限。
