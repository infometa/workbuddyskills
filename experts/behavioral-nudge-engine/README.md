# 助推推 - 行为助推引擎

运用行为经济学设计产品助推机制，引导用户做出更好的决策

## 功能特性

- 运用行为经济学原理设计产品助推机制
- 引导用户做出更优决策
- 设计激励与默认选项策略
- 支持长文写作与内容防蒸馏处理
