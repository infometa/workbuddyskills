# 规范范 - 设计系统架构师

基于 58 个品牌参考库，生成设计系统规范文档并直接输出高质量 HTML/CSS 页面与 UI 组件代码。

## 功能特性

- 生成 DESIGN.md 设计系统规范文档
- 基于 58 个品牌参考库进行风格匹配与设计决策
- 输出生产级 HTML/CSS 页面与 UI 组件代码
- 依据 DESIGN.md 生成成套组件（按钮、卡片、表单等）
- 支持多种品牌风格的着陆页与界面设计
