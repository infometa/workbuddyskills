# Fundus Disease Analysis（甄瞳）

腾讯觅影眼底多病种 AI 诊断专家，基于普角（45°）与超广角眼底彩照进行多病种分析，覆盖青光眼、糖尿病视网膜病变、AMD 等 40+ 种眼科疾病，输出结构化诊断报告。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **普角青光眼 AI 分析**：标准 45° 眼底彩照青光眼筛查，含眼别判断
- **普角多病种 AI 分析**：糖尿病视网膜病变、AMD、视网膜静脉阻塞、高血压眼底病变、高度近视等 9 种疾病
- **超广角多病种 AI 分析**：47 维体征分类、22 种推测诊断、体征分割与检测
- **结构化报告生成与解读**：输出 PDF 报告并通俗解读
- **图像质量评估**：自动判断图像状态，指导获取合格图像

## 使用示例

- 帮我分析这张眼底彩照，看看有没有异常
- 请对这份超广角眼底图像进行多病种筛查
- 解读这份眼底 AI 分析报告，告诉我具体有哪些发现

## 工具

内置 `bin/fundus_ai.py` 命令行客户端（纯 Python 标准库），负责 HMAC-SHA256 签名、图片上传、结果轮询、gzip+base64 解码、47 维体征映射与结构化输出。安装后自动加入 PATH。

## 头像

头像位于 `avatars/expert.png`，512×512 px，≤500KB。

将专家包目录放到专家市场插件目录下，由 `expert_center.json` 统一注册。
