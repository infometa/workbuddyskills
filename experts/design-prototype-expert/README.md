# 小花创意 / Xiaohua Creative

设计系统驱动的高保真原型专家——先建规范再出页面，提供多方向选择，交付前做 AI 味检测。帮你找到自己的视觉风格，而不是套模板。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **设计系统先行**：任何高保真页面产出之前，先建立完整的配色方案（4-6 色）、字体配对、间距规则、组件规范和交互状态定义。没有设计系统就不出高保真。
- **双路径美学方向**：10 个预制美学模板（编辑极简/电影深空/暖纸手作/数据终端/粗野撞色/液态玻璃/杂志编辑/游戏活泼/日式禅意/复古未来）快速启动；不满意则从零定制 3-4 个方向。
- **低保真线框先行**：高保真前用 ASCII 线框快速验证布局和信息层级，产出 3+ 变体。
- **高保真原型输出**：基于设计系统产出工程可用的 HTML/CSS 原型，响应式、语义化、尊重 prefers-reduced-motion。
- **实时调参迭代**：原型上叠加浮动调参面板，实时调整配色/间距/字号。
- **局部修补**：用户提出修改只做局部 Patch，不整页重写，保持设计系统一致性。
- **反 AI 味工程化**：强禁止清单精准点名紫蓝渐变、奶油底配赤陶橙、近黑底配酸性绿等默认审美套路，给出可执行的检测方法（色相角度范围、色值近似区间）。
- **交付前五道 QA**：AI 味检测 → 可访问性审查 → 层级与节奏审查 → 交互状态审查 → 终检汇总，产出含 P0/P1/P2 优先级的 QAReport。

## 使用示例

- 帮我做一个落地页设计，产品是一个面向年轻人的 AI 文艺生活助手，要东方纸墨质感
- 为我的品牌 RIVET 建立一套赛博朋克废土风的品牌识别系统，要有 Logo、配色、字体和完整 Brand Book
- 给我 2-3 个设计方向让我选择，这是一个金融数据仪表盘，要专业但不沉闷

## 安装

将专家包目录放到以下路径：

```
~/.workbuddy/plugins/marketplaces/my-experts/plugins/design-prototype-expert/
```

然后运行注册命令使其在 WorkBuddy 中可见：

```bash
python3 scripts/register_expert.py ~/.workbuddy/plugins/marketplaces/my-experts/plugins/design-prototype-expert/
```

## 打包分享

```bash
zip -r design-prototype-expert.zip design-prototype-expert/
```
