# 思维蒸馏方法论（女娲核心）

本技能沉淀女娲把「人」蒸馏成「可运行视角」的完整方法论。执行任何蒸馏任务前，先读完 references 两份文件，再按四阶段推进。

## 何时用

- 用户要蒸馏某个公开人物的思维方式（人物视角）
- 用户要蒸馏某个领域的方法论工具箱（主题视角）
- 用户要求「用某人的视角」分析问题——若该视角尚未蒸馏，先走本流程蒸馏再对话

## 四阶段流程

1. **Phase 1 · 六路并行采集**：著作/长文、播客/访谈、社交媒体、批评者视角、决策记录、人生时间线六路同时调研，各自存档，标注来源与时间，一手来源优先。
2. **Phase 2 · 三重验证提炼**：对每个候选观点跑跨域复现 / 有生成力 / 有排他性三重验证（详见 extraction-framework.md 第一节）。三过收录为心智模型，一过降级为决策启发式，零过不纳入。同步量化表达DNA、按三类保留内在矛盾。
3. **Phase 3 · 构建视角**：按 skill-template.md 的结构组织产物（角色扮演规则 + 身份卡 + 3-7 心智模型 + 5-10 决策启发式 + 表达DNA + 时间线 + 价值观反模式 + 智识谱系 + 诚实边界 + 来源）。
4. **Phase 4 · 质量验证**：用质量自检清单逐条打勾；3 个已知问题反测方向、1 个未知问题测适度不确定性；删名后仍能认出是谁。

## 关键判定标准（速查）

- **心智模型 vs 随口一说**：必须同时满足「≥2 领域复现 + 能推断新立场 + 有排他性」三条。
- **人物视角 vs 主题视角**：人物=模拟一人表达、保留个人矛盾、对比其已知立场验证；主题=综合多人、风格中性、呈现流派分歧、对比领域共识。
- **矛盾不修复**：时间性/领域性/本质性三类矛盾都要如实保留，禁止选边、禁止编调和解释、禁止假装不存在。
- **信息不足要标注**：某维度信息少→标「推测」；仅二手→降置信度标来源；矛盾无法判断→并列呈现；刻意不公开→注明「保持沉默」。

## 诚实边界（必须写进每个产物）

- 蒸馏不了直觉；捕捉不了突变（快照）；公开表达 ≠ 真实想法。
- 只蒸馏公开领域留有充分材料的人物，拒绝用于冒充、误导、造谣或蒸馏普通私人个体。
- 如实呈现争议与批评者视角，不美化不洗白。
