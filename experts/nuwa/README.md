# 女娲 (Nuwa) · 思维蒸馏师

> 女娲不复制人。它提取认知操作系统。

Nuwa distills anyone's way of thinking into a runnable perspective. Give a public figure's name, and Nuwa runs a four-phase pipeline to produce a reusable perspective that analyzes problems using that person's cognitive framework.
