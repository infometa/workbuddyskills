# 秘宝 26.9.2 专家提交范围

本文件是专家 ZIP 内的提交范围投影。仓库中的完整任务书、历史研究和后续版本候选不属于本包的能力声明。

## 当前能力

26.9.2 只提供 `execution_core_v1`：

- `inventory_build`：在用户授权目录上创建或打开本地私密项目，执行只读增量扫描、媒体类型识别、严格 SHA-256、精确重复识别、SQLite FTS5 关键词索引，并生成可回读盘点报告；
- `inventory_search`：只在既有项目内执行 SQLite FTS5 关键词检索，返回相对路径、稳定资产标识和证据引用。

盘点允许安全排除单个路径策略违规文件名或 reparse 条目并返回 `partial + scan.issues`；这些条目不读取、不跟随、不哈希、不入索引。不可读、离线、身份漂移和预算失败仍阻断。已有完全空项目目录可初始化。文件名查询中的点只作白名单 token 分隔符。

两项操作均由包内固定 one-shot 入口执行。请求通过严格 JSON Schema 传入，不把用户输入拼接到 Shell 参数；请求路径必须精确绑定当前会话 Workspace Folder 下的绝对请求根和 `session-workspace` 固定作用域。包内脚本只由 WorkBuddy 加载 Skill 时解析的 `${CODEBUDDY_SKILL_DIR}` 固定定位。严格有效、单物理链接且无重解析点的请求会在源/项目访问前被原子 claim、复核并删除；无效或清理失败请求不作自动清理承诺。执行结束后退出，不安装本地 MCP、连接器或常驻服务，也不修改 WorkBuddy 配置。

请求只允许当前 WorkBuddy 会话 Workspace Folder 下的 session-owned fallback，不运行 Shell/PowerShell 环境发现、目录遍历、Skill 列表、源码扫描或版本探针。每项 operation 只允许一次 request write 和一次固定 native Bash one-shot；禁止其他 Shell、`-c`、管道、重定向和拼接。报告只读回，宿主强制 memory 必须单独披露且不构成秘宝 operation。

## 本版本不包含

- 本地大模型、视觉向量或混合向量检索；
- 模型状态、硬件选型、下载、安装、修复、卸载或自检入口；
- FFmpeg、PyAV、模型权重、wheel、虚拟环境或缓存载荷；
- 转换、OCR、ASR、片段导出、素材包或成片的产品承诺。

仓库中保留的后续版本研究代码与失败回执不进入本专家 ZIP，也不构成本版本能力。

## 安全与证据边界

- 原件默认只读；源目录与项目目录不得重叠；
- `inventory_search` 只接受 `local-private`，在同一已审计只读连接上查询并返回该模式；旧隐私模式失败关闭且不自动迁移；
- 成功必须有真实项目、索引和报告回读，不能用方案或说明代替执行；
- 当前包仍是候选。源码测试、独立解压或临时宿主审计不能证明活动安装、前台可见、真实专家会话、企业上传接受、可提审、已上架或自然使用；
- 用户无需另装 Python 是发布目标，但须由干净 Windows 与 WorkBuddy 生命周期回执证明；未通过前保持未证明。
