# crm-visit-sync · 使用说明

> 搬运式跟进记录同步技能：将分散在 iWiki / 腾讯文档 / 企微文档 / 粘贴文本 / 企微聊天合并转发中的跟进记录，自动搬运录入到腾讯云磐石 CRM 的跟进数据库。

## 一、技能简介

本技能面向销售人员、售前架构师，解决"跟进内容已记录在文档或聊天中、但需要手动重复录入磐石 CRM"的痛点。输入一份已写好的拜访纪要或一段聊天记录，技能自动抽取结构化字段、校验权限、关联打卡，并在两次确认后写入磐石。

与"对话式创建跟进记录"技能（`crm-create-visit-skill`）的核心区别：本技能**严禁 AI 加工内容**——文档类输入一律原文摘取，仅对话流/纯文本输入允许对"沟通进展/下一步计划"做忠于输入的总结提炼，其余字段读不到即留空，绝不编造。

## 二、功能特性

- **多源输入**：iWiki 链接、腾讯文档链接、企微文档链接直接解析；支持粘贴结构化纪要文本、聊天对话流合并转发、自由叙述纯文本。
- **双分支处理**：
  - 分支 A（文档类）：原文摘取，禁止 AI 加工；
  - 分支 B（对话流 / 纯文本）：允许对"沟通进展 / 下一步计划"做忠于输入的总结提炼。
- **必填字段保底**：写入前无法从输入确认的字段逐一向用户确认，优先保障表单必填项；跟进人与创建时间由系统自动生成。
- **权限校验**：自动校验跟进对象是否在当前用户名下（客户按销售/架构师权限过滤，商机校验主销售/架构师/项目成员），不在名下时列出相近对象供重选，绝不代填他人客户。
- **打卡关联**：仅查询并关联用户名下已有打卡记录，不伪造、不创建；无可用打卡时引导补打卡或改判"跟进进展"。
- **仅两次交互**：全程只需「选跟进对象」和「确认职位+打卡+预览提交」两步，其余全自动；以对话形式回复序号或名称选择，回复"提交"确认。

## 三、支持的输入来源

| 来源 | 说明 |
|------|------|
| iWiki 文档链接 | `iwiki.woa.com/p/...` |
| 腾讯文档链接 | `docs.qq.com/...` |
| 企微文档链接 | `doc.weixin.qq.com/...` |
| 粘贴文本 | 结构化纪要 / 对话流合并转发 / 自由叙述纯文本 |
| 企微聊天合并转发 | 用户把与客户的聊天合并转发到企微号助手 |
| 图片 | 拜访纪要截图 / 聊天记录截图 / 手写纪要照片 / 表格截图（多模态识别后按分支 B 清洗） |

## 四、前置依赖（连接器与权限）

使用本技能前，请确保以下连接器已在当前工作区「信任」并正确授权。**所有磐石 CRM 接口调用统一经 WorkBuddy 平台的 `omp-service` MCP 转发（对应磐石规范的 panshi-mcp 角色），禁止裸调 HTTP / curl。**

1. **omp-service（必需）**：磐石 CRM 接口连接器，所有读写操作依赖它。需在连接器管理页「信任」omp-service 并配置 dev 环境令牌；若提示未连通或令牌失效，请检查令牌后重试。
2. **来源类连接器（取决于输入类型，按需启用）**：
   - iWiki 连接器：提供 iWiki 文档链接解析；
   - 腾讯文档连接器（tencent-docs）：提供腾讯文档链接解析，需完成 `TENCENT_DOCS_TOKEN` 授权（未授权会返回 400006）；
   - 企业微信连接器（wecom-cli）：提供企微文档链接解析，需其「文档」机器人权限未过期（权限过期返回 `851014` authorization expired，请运行 `wecom-cli init` 扫码重新接入授权）。
3. **角色与数据权限**：
   - 仅支持 **Sales（销售）** 和 **Owner（国内售前架构师）** 两种角色，其余角色终止；
   - 需在磐石 CRM 具备跟进记录写入权限；
   - 跟进对象（客户 / 商机）必须处于当前用户名下：客户按销售/架构师权限过滤命中即在名下，商机需为负责人/架构师/项目成员之一；不在名下则无法代填。
4. **其他限制**：
   - 仅允许同步距今 **15 天**内的跟进记录；
   - 拜访对象职位须从标准枚举选择（25 个销售默认值 + 6 个 Owner 额外值）；
   - 关联打卡需用户名下已存在 15 天内未关联的打卡记录（无则可去磐石小程序补打卡）。

## 五、使用步骤

1. **触发技能**：向 WorkBuddy 发送 iWiki / 腾讯文档 / 企微文档链接，或粘贴跟进记录文本 / 对话内容，并说明需要同步到磐石 CRM（如"把这条跟进记录传到磐石""录入磐石跟进记录"）。
2. **确认跟进对象**：系统从源文档提取对象名称 + 搜索用户名下客户 / 商机，合并候选列表供回复序号选择。
3. **确认并提交**：查看全字段预览（含拜访对象职位枚举菜单、可关联打卡候选），确认无误后回复"提交"完成写入。

## 六、注意事项

- 源文档中未提及的字段留空，绝不编造。
- 对象名称须经磐石搜索匹配后由用户选定，不会直接把源文名称当作磐石对象提交。
- 打卡只能关联不可伪造；无可用打卡时不提交空值或假值。
- 如来源链接读不到内容，请检查对应连接器授权后重试，或直接粘贴文档正文。
- 若角色鉴权未通过（非 Sales / Owner），技能会明确告知并终止，不会越权写入。
