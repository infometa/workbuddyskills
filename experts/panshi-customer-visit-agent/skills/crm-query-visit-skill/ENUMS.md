## 产品跟进类型

### 产研商机（from_type=10）
```
内部启动会、需求调研、方案研讨、方案讲解、进展推进、对接测试、问题解决、
需求&问题反馈、风险处理、双周关键进展、POC关键进展、日常联系、销售拜访支持、
专项推进、推广实施、交付信息收集、续费增购商机、流失调研、QBR、其它
```

### POC（from_type=11）
```
内部启动会、对接测试、进展推进、需求&问题反馈、POC关键进展、测试方案评估、现场部署
```
