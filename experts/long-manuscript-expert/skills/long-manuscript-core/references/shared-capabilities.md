# Shared capabilities

The expert owns sixteen package-local capabilities:

1. `scene-router` — resolve operation mode and domain scene, with explicit ambiguity.
2. `scene-composer` — combine scene contracts without lowering risk.
3. `material-activation` — inventory materials and return one blocking fact; it does not generate a draft.
4. `multimodal-normalizer` — normalize descriptors and degrade unsupported formats honestly; it does not extract file content.
5. `research-verification` — bind source receipts and produce a verification plan; the active package-local source-quality gates make the final delivery decision.
6. `source-ledger-claim-graph` — link claims, sources, and chapters.
7. `entity-timeline-continuity` — detect alias, entity, and temporal conflicts.
8. `scope-lock-diff` — reject changes outside the authorized scope.
9. `voice-profile-humanizer` — assess required/forbidden voice markers and fact anchors; it does not claim to transform prose.
10. `chapter-planning-expansion` — produce schema-valid chapter plan states; it does not claim to generate expansion text.
11. `review-revise-quality-loop` — keep review, revision, and residual warnings explicit.
12. `rights-privacy-consent` — validate locally bound consent/privacy/review receipts and fail closed; it is not legal advice.
13. `multi-format-rendering` — produce local Markdown/HTML and explicit format fallbacks.
14. `media-illustration-planning` — plan media, captions, sources, placements, and rights.
15. `continuation-recovery` — create and validate user-copyable continuation capsules.
16. `asset-repurposing` — create adaptation briefs only after quality gates; it does not claim channel content generation.

Each helper returns `connectorRequired=false`, `donorSkillUsed=false`, and `externalActionCount=0`. Model-authored prose remains governed by the Skill instructions and user materials; deterministic helpers do not invent prose, facts, citations, permissions, or approvals.
