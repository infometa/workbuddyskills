# 天御对公信贷 · 信贷尽调专家

> 腾讯云天御对公信贷专家 — 对公信贷全流程尽调助手，覆盖行业研究、财务核查、实控人画像与风险预警，依托腾讯云天御风控输出结构化信评报告，助力授信决策。

## 类型

Agent 型专家（单个 AI 专家 + 配套技能）。用户提供**企业名称**即可启动全流程尽调，最终产出一份可在聊天窗口呈现、并支持导出为 HTML / PDF 的信用评估报告。

## 核心能力

| 能力 | 说明 |
|---|---|
| 行业研究 | 宏观环境（PEST）、行业生命周期、波特五力、行业财务特征与关键变量敏感性分析、竞争格局与监管政策 |
| 财务核查 | 三大表勾稽、营运资金与现金流分析、人效基准对标、民企财务偏差与关联交易风险识别 |
| 实控人画像 | 实控人背景、涉诉/被执行/对外担保等关键人风险扫描 |
| 风险预警 | 行业共性风险矩阵 + 企业个体风险（诉讼、监管处罚、同业违约匹配），带置信度标注 |
| 信评报告 | 标准化 Markdown 报告，含执行摘要、综合评级、一票否决红线与监控指标，支持渲染 HTML、导出 PDF |

## 内置技能

- `credit-industry-research`：信贷尽调行业研究，7 大分析模块 + 附录，输出面向信贷经理的尽调建议与材料清单。
- `md2pdf`：将 Markdown 报告转换为带专业排版、完整中文支持的交付级 PDF（支持封面、目录、书签）。
- `auth-permission`：业务执行前的认证与鉴权前置步骤，鉴权通过后方可进入尽调流程。

## 使用示例

- "帮我调研下 {企业名}。"
- "帮我对 XX 行业做系统性研究，覆盖竞争格局、监管政策、风险点。"
- "对 XX 公司开展财务核查，重点识别民企财务偏差与关联交易风险。"
- "评估 {企业名} 的授信风险 / {企业名} 能不能授信。"

> 数据来源：企业工商信息优先取自企查查连接器（不可用时通过联网公开搜索获取），其余信息通过联网搜索获取。本报告基于公开信息，不替代人行征信、银行流水等内部资料。
