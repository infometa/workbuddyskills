# 对公信贷标准报告全局规则（v3）

## 1. 数据取数顺序

| 优先级 | 来源 | 处理方式 |
|---|---|---|
| ① 用户材料 | 用户已上传并经核验的材料 | 以可核验材料为准，不臆造、不覆盖 |
| ② 公开兜底 | 政府、司法、监管、企业公告、工商平台及行业公开数据 | 据实填写，注明来源、日期和置信度；内部原件仍需补充时明确提示 |
| ③ 均无则占位 | 用户未提供且公开信息无法取得 | 填写规定占位，不留空、不推测 |

若当前任务选择“不使用企查查”，不得调用或引用企查查。若选择“严格证据”，无法核验的信息必须占位。

## 2. 缺失与待定标记

| 场景 | 占位文案 |
|---|---|
| 用户未提供且公开渠道查不到 | `待客户经理补充` |
| 条件或规则无法判定 | `待确认` |
| 需要人工核实真实性 | `待人工核实` |
| 非订单型企业的在手订单 | `不适用` |

所有 `待客户经理补充` 均必须醒目高亮，避免客户经理漏看：

- Markdown 及用于 PDF 转换的 Markdown：`🔴 **待客户经理补充**`
- HTML：`<span class="manager-input-needed">待客户经理补充</span>`

红色警示必须出现在缺失信息原本所属的位置：表格字段缺失时直接写入对应单元格，正文信息缺失时写在对应段落或清单项中。不得只在第九章或报告末尾补一张汇总表。标记不得改变占位文字本身，也不得把“待确认”“待人工核实”误写成“待客户经理补充”。第九章“需客户经理补充/核实事项汇总”仍须再次集中列示全部标红项，作为复核清单。

## 3. 日期、金额和比例

- 日期统一为 `YYYY-MM-DD`。
- 金额默认以人民币万元整数列示；模板另行标注亿元、万股等单位的除外。
- 百分比原则上保留一位小数。
- 原始来源口径不同且无法可靠换算时，保留原口径并明确说明。

## 4. 来源与冲突

- **正文就地引用优先**：每个互联网事实、数字或结论后立即附原始链接；表格数据的链接放入对应单元格，或放在紧邻该行的来源列。不得只在表格末尾、章节末尾或报告末尾统一列链接。
- 每个数据表或数据块末尾仍可补充来源、查询/截止日期和原始链接，作为整体口径说明，但不得代替正文逐项引用。
- 涉及企业定量信息时标注置信度。
- 多源冲突时展示主要差异，以营业执照、监管披露、审计报告或其他一手材料为优先认定口径，并记录处理结果。
- 所有互联网公开来源必须给出可点击的原始页面 URL。Markdown 使用 `事实（[来源：标题](原始URL)）`，HTML 使用 `事实<a class="source-link" href="原始URL">[来源]</a>`；不得只给网站首页、搜索结果页或来源名称。
- 由新闻、搜索摘要或聚合平台发现的线索，应回溯并链接公告、判决、处罚决定、年报等原文。无法取得原始链接时标注“未取得原始链接，仅作线索”，且不得作为关键结论的唯一证据。
- 用户材料和内部系统数据没有公开 URL 时，写明文件名及页码，或系统名称及查询日期，并标注“无公开原始链接”；严禁猜测或编造 URL。

## 5. 条件路由

| 条件 | 处理方式 |
|---|---|
| 非集团客户 | 所属集团相关章节整项删除 |
| 是否集团客户无法确认 | 不自行认定，保留必要提示并标注`待确认` |
| 非续授信 | 本次与上次授信方案对比整项删除 |
| 非重整授信 | 重整授信说明整项删除 |
| 非订单型行业 | 在手订单章节保留并填写`不适用` |
| 无对外投资或关联企业 | 据证据写明本次检索范围内未发现；不得表述为确认不存在 |
| 无重大投资或在建项目 | 据证据填写本次不涉及；证据不足时填写`待客户经理补充` |

## 6. 企业类型

生产型、贸易型或其他复合型原则上由用户或客户经理确认。未确认时不得仅凭模型推断，标注`待确认`，并选择不造成错误删减的通用表述。

## 7. 财务口径

- 标准范围为近三年审计报表及最近一期，优先同时包含合并和母公司口径。
- 用户未提供完整报表时，不得从零散公开数字拼造完整三张表。
- 公开年报可据实使用，但必须注明报表口径和截止日期。

## 8. 关键公式

```text
刚性负债 = 短期借款 + 应付票据 + 交易性金融负债
          + 其他流动负债中的应付短期债券 + 长期借款 + 应付债券
          + 长期应付款中的融资租赁债务 + 其他应付款中的拆借款
          + 永续债 + 优先股 + 名股实债

现金类资产 = 货币资金 + 应收票据 + 交易性金融资产中的理财

刚性负债净敞口 = 刚性负债 - 同期现金类资产
```

- 资产负债率 = 负债总额 / 资产总额 × 100%
- 流动比率 = 流动资产 / 流动负债
- 速动比率 =（流动资产 - 存货）/ 流动负债
- 应收账款周转天数 = 应收账款平均余额 / 营业收入 × 365
- 存货周转天数 = 存货平均余额 / 营业成本 × 365
- 销售利润率 = 净利润 / 营业收入 × 100%
- 毛利率 =（营业收入 - 营业成本）/ 营业收入 × 100%
- EBITDA = 净利润 + 所得税 + 利息支出 + 折旧 + 摊销

缺少组成项时不得假定为零，应标注无法计算及缺失项。

## 9. 隐私和能力边界

- 不查询、不读取、不填充自然人个人征信。
- 企业征信仅在具备合法授权和合规数据源时使用。
- 公开渠道未检索到信息，不代表相关风险不存在。
- 报告是尽调和风险评估辅助材料，不构成最终授信审批决定。
