# 通用尽调材料清单模板

使用时按行业特点增删，形成最终交给客户的材料清单。

---

## 一、财务类（必须）

### 基础财务报表
- [ ] 最近3年经审计年度财务报告（关注审计师意见类型）
- [ ] 最近1期未经审计中期/季度财务报告
- [ ] 合并报表 + 母公司报表（两者差异揭示子公司/关联方风险）

### 现金流专项
- [ ] 银行存款明细（分账户，区分受限资金与自由资金）
- [ ] 最近12个月银行流水（主要账户）
- [ ] 应收账款账龄分析（1年以内/1-2年/2年以上分层）
- [ ] 应付账款账龄分析

### 债务结构
- [ ] 有息负债明细表（债权人、金额、利率、到期日、是否已抵押、是否已展期）
- [ ] 对外担保明细（被担保方、金额、期限、是否反担保）
- [ ] 表外融资说明（合并范围外的合作项目、SPV、明股实债安排）
- [ ] 近1年新增融资及还款记录

### 资产质量
- [ ] 存货明细及跌价测试说明
- [ ] 固定资产明细及折旧政策
- [ ] 投资性房地产公允价值评估报告（如适用）
- [ ] 商誉减值测试报告（如适用）

---

## 二、经营类（必须）

### 收入与客户
- [ ] 最近3年分业务/产品线收入拆分
- [ ] 前十大客户名单及收入占比（关注集中度）
- [ ] 主要合同/订单列表（金额、履约周期、付款条件）
- [ ] 销售回款对账单（合同销售额 vs 实际回款差异）

### 供应链
- [ ] 前十大供应商名单及采购占比
- [ ] 主要原材料价格走势及锁价安排

### 生产/运营
- [ ] 主要产能、产能利用率（近2年）
- [ ] 在建项目列表（进度、预计完工时间、资金缺口）
- [ ] 员工人数及核心管理层情况

---

## 三、法律与合规类（必须）

### 诉讼与仲裁
- [ ] 在诉/仲裁案件清单（案由、金额、进展、预期结果）
- [ ] 行政处罚记录（近3年）
- [ ] 税务稽查情况

### 抵押担保
- [ ] 拟抵押资产的他项权证（确认是否已向他行设押）
- [ ] 拟抵押资产的评估报告（评估机构资质、评估日期）
- [ ] 土地证/房产证原件核验（或向不动产登记中心查档）

### 公司治理
- [ ] 最新股权结构图（穿透至实际控制人）
- [ ] 工商登记信息（最新版营业执照、公司章程）
- [ ] 近3年股东变更记录

---

## 四、行业特有材料（按需补充）

### 房地产开发
- [ ] 预售许可证及预售监管账户余额
- [ ] 项目去化率及库存清单（分楼盘）
- [ ] 保交楼项目清单及资金缺口
- [ ] 土地储备清单（地块、楼面地价、周边市场价对比）
- [ ] 合作开发项目清单及资金往来

### 制造业
- [ ] 主要生产设备清单及新旧程度
- [ ] 环保许可证及整改记录
- [ ] 专利/核心技术清单

### 科技/互联网
- [ ] 核心产品用户数/活跃度数据
- [ ] 客户续约率、NRR（净收入留存率）
- [ ] 研发费用资本化政策说明

### 金融/融资租赁
- [ ] 监管牌照及合规报告
- [ ] 资产质量分类明细（正常/关注/次级/可疑/损失）
- [ ] 流动性缺口分析报告

### 建筑/工程
- [ ] 在施项目清单及垫资规模
- [ ] 房地产客户应收账款明细（识别传导风险）
- [ ] 建筑资质证书

## 五、现场核查动作清单（通用）

| 核查动作 | 目的 | 判断标准 |
|---------|------|---------|
| 走访主要经营场所 | 核实实际经营规模与报表匹配性 | 人员、设备、库存与报表一致 |
| 银行流水与报表交叉验证 | 识别体外循环、虚假收入 | 回款金额与合同销售额匹配 |
| 向不动产登记中心查档 | 确认抵押物权属及他项权证 | 无重复抵押、产权清晰 |
| 访谈财务负责人/CFO | 了解债务结构、融资计划 | 能清楚说明到期债务安排 |
| 访谈主要客户（如可行） | 验证收入真实性及回款意愿 | 客户对账单与企业一致 |
| 查询企业信用信息（征信） | 了解现有负债全貌 | 与企业披露一致，无隐瞒 |
| 工商/司法查询 | 发现未披露的诉讼、股权冻结 | 无重大未披露法律风险 |
| 压力测试建模 | 悲观情境下现金流缺口估算 | 销售/收入下降20-30%时能否覆盖债务 |

## 六、民营企业/非上市企业尽调补充

> 民营/非上市企业缺乏公开披露、审计报告和交易所监管，信息不对称远高于上市公司。以下核查项是对前五节的必要补充，授信民营企业时**全部适用**。

### 6.1 财务替代核查（替代审计报告的信息源）

- [ ] 最近3年增值税纳税申报表（月度）—— 交叉验证收入真实性（税务口径收入 = 销项税额 ÷ 适用税率）
- [ ] 最近3年企业所得税年度汇算清缴报告 —— 核实利润水平（所得税实缴额倒推利润）
- [ ] 最近24个月**全部银行账户**流水（含实控人个人账户如有经营往来）—— 替代审计报告的核心数据源
- [ ] 银行流水与纳税申报交叉验证工作底稿 —— 三角校验：流水收入 vs 税务收入 vs 报表收入（差异>15%需深究）
- [ ] 内部管理报表（如有）—— 民营企业常有"内账"，与"外账"差异揭示真实经营状况
- [ ] 最近12个月水电费/租金/工资发放记录 —— 经营规模旁证（水电费可倒推产能利用率）

### 6.2 实际控制人专项核查

- [ ] 实际控制人个人征信报告 —— 查个人负债、对外担保、逾期记录
- [ ] 实际控制人及配偶名下房产/车辆/金融资产查询 —— 评估个人兜底偿债能力
- [ ] 实际控制人对外投资企业穿透清单（企查查/天眼查）—— 识别关联方网络、多头经营风险
- [ ] 实际控制人近3年涉诉查询（裁判文书网 + 执行信息网）—— 发现隐性债务/纠纷
- [ ] 实际控制人及关键管理人员背景调查 —— 行业口碑、从业经历、过往信用历史
- [ ] 夫妻共同债务确认函（如适用）—— 防止通过离婚转移资产规避债务
- [ ] 实控人家族企业关系图谱 —— 识别家族式关联交易和利益输送

### 6.3 关联方与资金真实性核查

- [ ] 关联方企业完整清单（含实控人、配偶、直系亲属控制的企业）—— 穿透识别体外循环
- [ ] 关联方之间资金往来明细（近12个月）—— 是否存在资金归集、无商业实质的拆借
- [ ] 主要供应商/客户是否存在关联关系核查 —— 虚构交易识别（交叉比对工商登记信息）
- [ ] 企业账户与实控人个人账户资金混同情况核查 —— 公私不分是民营企业最大风险之一
- [ ] 大额异常交易筛查（单笔>日均交易额5倍的资金进出）—— 识别异常资金流动

### 6.4 非正规融资排查

- [ ] 民间借贷摸底 —— 通过银行流水中频繁大额个人转账识别，补全有息负债真实全貌
- [ ] 担保圈/互保链查询 —— 征信报告 + 企查查穿透，评估区域性担保链风险
- [ ] 商业承兑汇票签发及到期兑付记录 —— 表外融资通道，关注票据逾期情况
- [ ] 融资租赁/商业保理合同明细 —— 隐性负债，需纳入总负债计算
- [ ] 预收账款/预付账款中隐藏的融资安排 —— 是否存在名为贸易实为借贷的资金往来

### 6.5 现场核查强化动作（民营企业专用）

| 核查动作 | 目的 | 判断标准 |
|---------|------|---------|
| 突击走访经营场所（不预约） | 核实日常经营真实性 | 人员在岗、设备运转、库存实物与报表匹配 |
| 银行流水"三角验证" | 收入真实性 | 流水收入 ≈ 税务收入 ≈ 报表收入（差异<15%为合理） |
| 实控人面谈（必须本人到场） | 评估还款意愿、管理能力、风险认知 | 能清晰描述业务模式、债务全貌、还款来源 |
| 上下游实地走访（至少各1家） | 验证业务关系真实性 | 合同签章一致、交易频次/金额匹配、对方确认合作关系 |
| 裁判文书网/执行信息公开网查询 | 发现未披露诉讼及执行 | 无重大未披露纠纷 |
| 水电费/社保人数倒推经营规模 | 交叉验证收入规模 | 推算结果与申报收入量级匹配（差异<30%） |
| 同行/行业协会侧面了解 | 获取第三方视角的企业口碑 | 行业口碑正面、无重大负面传闻 |
