# 各行业财务特征速查表

信贷尽调时用于判断"企业财报是否符合行业规律"的基准参考。

---

## 房地产开发

| 指标 | 典型区间 | 信贷关注点 |
|------|---------|-----------|
| 资产负债率 | 70-85% | 超85%高危；注意表外负债 |
| 毛利率 | 10-25%（2024年后普遍压缩至10%左右） | 低于10%项目可能亏损结转 |
| 存货/总资产 | 50-70% | 存货流动性差，须关注去化周期 |
| 预收账款/营收 | 50-100% | 预售监管资金比例，实际可动用现金 |
| 资金周转 | 预收款模式，回款快但受监管限制 | 区分受限/非受限货币资金 |
| 资本开支 | 轻资产（无固定资产投资），重土地 | 土地款占用大量资金 |
| 典型风险 | 存货跌价、保交楼义务、债务集中到期 | 穿透合并范围外的合作项目债务 |

---

## 制造业（重资产）

| 指标 | 典型区间 | 信贷关注点 |
|------|---------|-----------|
| 资产负债率 | 40-65% | 固定资产可作抵押 |
| 毛利率 | 15-35%（细分差异大） | 与原材料价格强相关 |
| 固定资产/总资产 | 30-60% | 折旧政策、资产新旧程度 |
| 应收账款周转天数 | 30-90天 | 客户集中度高时风险大 |
| 存货周转天数 | 30-120天 | 原材料/在制品/成品比例 |
| 资金周转 | 先采购后销售，有账期 | 营运资金缺口 |
| 资本开支 | 高（产能扩张/设备更新） | CAPEX/折旧比值 |
| 典型风险 | 原材料涨价、产能过剩、技术迭代 | 客户集中度、应收坏账 |

---

## 零售/消费品

| 指标 | 典型区间 | 信贷关注点 |
|------|---------|-----------|
| 资产负债率 | 30-60% | 预收账款（会员充值）可能是负债 |
| 毛利率 | 20-50%（线下零售低端，品牌高端） | 注意线上/线下毛利差异 |
| 存货周转天数 | 30-90天 | 季节性库存风险 |
| 应付账款账期 | 30-60天（对供应商强势则长） | 占压供应商资金是优势 |
| 资金周转 | 收现快（现金/刷卡）、付款慢 | 良性现金流结构 |
| 资本开支 | 中等（门店扩张、装修） | 门店租约是隐性负债（IFRS16） |
| 典型风险 | 渠道变革、库存积压、消费降级 | 线下客流趋势、电商冲击程度 |

---

## 科技/互联网（轻资产）

| 指标 | 典型区间 | 信贷关注点 |
|------|---------|-----------|
| 资产负债率 | 20-50% | 无形资产（专利、用户数据）难抵押 |
| 毛利率 | 40-80% | 边际成本低，规模效应显著 |
| 固定资产/总资产 | <10% | 抵押物价值低 |
| 研发费用/营收 | 10-30% | 资本化vs费用化处理影响利润 |
| 自由现金流 | 盈利期通常很强 | 关注亏损期烧钱速度 |
| 资金周转 | B2B软件：预收年费，现金流好；B2C：获客成本高 | 订阅模式 vs 买断模式 |
| 典型风险 | 监管合规、平台垄断审查、核心人才流失 | 技术迭代风险、客户续约率 |

---

## 金融（银行/保险/租赁）

| 指标 | 典型区间 | 信贷关注点 |
|------|---------|-----------|
| 资产负债率 | 85-95%（高杠杆是行业特性） | 核心资本充足率更有意义 |
| 净息差（银行） | 1.5-3% | 压缩趋势下盈利能力 |
| 不良贷款率 | <2%为健康 | 关注特别关注类占比 |
| 拨备覆盖率 | >150%合规要求 | 低则有利润虚高嫌疑 |
| 流动性比率 | >25%（监管要求） | 资产负债期限错配 |
| 典型风险 | 信用风险、利率风险、流动性风险 | 不良资产出表方式（ABS/核销） |

---

## 建筑/工程

| 指标 | 典型区间 | 信贷关注点 |
|------|---------|-----------|
| 资产负债率 | 60-80% | 应付工程款是大头 |
| 毛利率 | 5-15%（竞争激烈、薄利） | 低毛利对现金流波动极敏感 |
| 应收账款/营收 | 30-60% | 工程款回收周期长，坏账风险 |
| 存货（在建） | 高 | 与房地产开发商深度绑定 |
| 资金周转 | 先垫资施工，后收款 | 垫资规模 = 融资需求来源 |
| 典型风险 | 业主方违约（房地产风险传导）、材料价格上涨 | 前五大客户集中度、房地产客户占比 |

## 农业/食品

| 指标 | 典型区间 | 信贷关注点 |
|------|---------|-----------|
| 资产负债率 | 30-60% | 生物资产估值主观性强 |
| 毛利率 | 10-40%（细分差异大） | 初级农产品低，加工品高 |
| 生物资产/总资产 | 较高（养殖/种植业） | 生物资产价值核实难度大 |
| 季节性 | 明显 | 收入/现金流季节波动 |
| 典型风险 | 疫病、自然灾害、粮价波动 | 保险覆盖情况；生物资产独立核查 |

## 民营/非上市企业财务特征偏差

> 民营企业的财务数据与上市公司存在系统性偏差。以下偏差模式适用于**所有行业**，是判断民企财报可信度的基准参考。

### 通用偏差模式

| 偏差类型 | 表现形式 | 信贷识别方法 | 影响方向 |
|---------|---------|------------|---------|
| **两套账** | 内账（真实经营）vs 外账（税务申报），收入/利润差异可达30-50% | 银行流水 vs 纳税申报 vs 报表三角验证；差异>15%深究 | 真实收入可能高于或低于报表 |
| **税务优化/避税** | 通过关联交易转移利润、个人消费计入企业费用、收入延迟确认 | 毛利率异常偏低（低于行业均值20%+）、费用率异常偏高 | 真实利润通常高于报表利润 |
| **非正规融资** | 民间借贷（月息1-3%）、担保圈互保、个人信用贷转入企业 | 银行流水中频繁大额个人转账、征信查询频次异常 | 真实负债显著高于报表 |
| **公私混同** | 企业账户与实控人个人账户资金频繁往来，企业为个人消费买单 | 银行流水中企业→个人大额转账模式 | 净资产可能被高估 |
| **关联方利益输送** | 通过关联方高买低卖转移利润、关联方长期占用企业资金 | 关联方交易定价 vs 市场价对比；应收关联方账龄 | 利润/资产被掏空 |
| **存货/资产虚增** | 虚构库存、虚增应收、固定资产评估虚高（贷款动机） | 实地盘点 + 行业经验值比对；周转率异常 | 资产被高估 |

### 行业特定偏差补充

| 行业 | 民营企业典型偏差 | 核查要点 |
|------|----------------|---------|
| 制造业 | 产能利用率虚报（实际开工率远低于宣称）；设备账面价值虚高（评估机构配合）；部分货款通过个人账户收取 | 水电费倒推实际产能；设备实地查看新旧程度及使用状态 |
| 零售/餐饮 | 现金收入漏报（POS流水 vs 实际营业额差异大）；加盟商隐性负债；门店经营数据造假 | 抽查门店实际营业额（驻店观察）；对账POS流水 + 银行到账 |
| 建筑/工程 | 挂靠资质（实际施工方非借款企业）；垫资规模远超报表披露；农民工工资欠付形成隐性负债 | 核查施工合同实际签约方 vs 施工方；工资发放银行流水 |
| 农业/养殖 | 生物资产虚报（虚构存栏获取贷款/保险）；补贴收入虚增；土地流转合规风险 | 饲料/水电消耗倒推实际存栏；补贴到账记录核实 |
| 贸易/批发 | 走单/空转贸易虚增收入（收入规模大但毛利极薄<1%）；关联方对敲制造流水 | 毛利率极低 + 周转极快 = 融资性贸易特征；穿透交易对手方 |
| 科技/软件 | 项目收入确认时点操纵（提前确认）；研发费用资本化激进；人员成本真实性（虚报人数骗补贴） | 合同执行进度 vs 收入确认比对；社保缴纳人数 vs 报表人数 |

### 民营企业财务健康度快速评估框架

```
Step 1: 银行流水分析（核心数据源）
  - 汇总近24个月主要账户流水
  - 月均经营性收入 = 来自客户的收款（排除贷款发放、个人转入、退款）
  - 月均经营性支出 = 付给供应商 + 工资 + 租金 + 水电 + 税费
  - 净经营现金流 = 经营性收入 - 经营性支出
  - 核查指标：流水收入 vs 纳税收入偏差率（>20%需深究原因）

Step 2: 纳税数据验证
  - 增值税销项税额 ÷ 适用税率 = 税务口径收入
  - 与银行流水收入、报表收入三角对比
  - 所得税实缴额倒推利润水平（所得税 ÷ 25% = 应税利润近似值）
  - 核查指标：三个口径收入偏差均<15%为合理

Step 3: 负债全貌重建
  - 征信报告显示的有息负债（银行贷款 + 信用卡 + 担保）
  - 银行流水识别的非正规融资（民间借贷、个人转入的经营性借款）
  - 担保圈穿透（企查查担保信息 + 征信对外担保明细）
  - 估算真实资产负债率 = (报表负债 + 表外负债估算) ÷ 真实总资产

Step 4: 实控人偿债能力评估
  - 个人资产：房产（现值）+ 金融资产 + 其他可变现资产
  - 个人负债：房贷 + 信用贷 + 对外担保 + 民间借贷
  - 个人净资产 = 资产 - 负债
  - 评估指标：个人净资产 ÷ 企业授信金额 ≥ 1.0x 为基本安全线
```
