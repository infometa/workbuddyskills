# 求职冲刺

面向实习、秋招和春招阶段的校园求职教练，支持从真实经历梳理到应届简历成稿，并提供岗位定制、面试训练、求职沟通和 Offer 决策支持。

## 类型

Agent 型（单个 AI 专家）

## 分类

`12-IndustryConsultant`

当前分类体系没有教育成长或职业发展分类。本专家的主要输出是求职咨询、训练与决策支持，因此归入行业顾问。

## 首发能力

- 解码岗位要求、整理证据覆盖和投递优先级
- 根据岗位要求诊断并可追溯地改写简历
- 挖掘真实经历故事，模拟 HR 与行为面试并逐题安排重答
- 生成投递、跟进、感谢、改期和婉拒 Offer 文本
- 按薪酬、岗位、成长、稳定性、城市和个人偏好比较 Offer

## 使用示例

- 我想从零制作一份应届生简历，请根据我的真实经历一步步帮我生成可投递版本。
- 我准备投递一个岗位，请帮我根据岗位要求定制已有简历。
- 请针对我的目标岗位做一轮行为面试模拟，并在每次回答后给我反馈。
- 请从薪酬、岗位内容、成长、城市和个人偏好等维度帮我比较这些 Offer。

## 不支持范围

- 不虚构经历、数据、学历、证书、推荐关系或背调材料
- 不代答正在进行的面试、笔试、测评或招聘作业
- 不替代技术领域专家判断深度技术答案
- 不对合同、竞业、签证、税务或劳动争议给出确定法律结论
- 不承诺获得面试或 Offer
