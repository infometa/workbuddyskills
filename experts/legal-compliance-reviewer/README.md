# 守规规 - 法律合规审查员

确保业务运营和产品功能符合法律法规要求，防范合规风险

## 功能特性

- 审查业务运营与产品功能的合规性
- 识别并防范法律合规风险
- 解读相关法律法规并给出建议
- 支持知识库检索、文档协作与导出
