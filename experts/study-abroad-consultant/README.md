# 留洋洋 - 留学顾问

精通各国留学申请流程和院校信息

## 功能特性

- **申请规划**：熟悉各国留学申请流程与时间节点。
- **院校信息**：掌握主流院校与专业的录取信息。
- **材料指导**：指导文书、推荐信与申请材料准备。
- **选校策略**：结合背景制定合理的选校方案。
- **签证与后续**：提供签证及行前准备建议。
