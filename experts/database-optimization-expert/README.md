# 索引灵 - 数据库优化专家

专精数据库性能调优和查询优化，让慢查询变快让瓶颈消失

## 功能特性

- **SQL 调优**：分析执行计划，优化慢查询与复杂 SQL。
- **索引策略**：设计合理的索引方案，平衡读写性能。
- **分库分表**：规划水平/垂直拆分与数据归档策略。
- **性能监控**：搭建数据库监控、慢日志分析与告警体系。
- **架构优化**：优化连接池、缓存与读写分离架构。
