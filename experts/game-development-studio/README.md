# 游戏开发工作室

> 由 1 位主理人 + 6 位专家成员组成的 Team 型专家包，把一次 AI 会话升级为一个完整的游戏开发工作室，驱动一款游戏从概念到上线。

## 这个专家团做什么

把"独立游戏开发"这件事按专业职能拆成六大域，每域由一位专家负责，主理人统一编排、管质量门、汇编交付。它把 49 种传统工作室角色归并为 6 大专业成员，调度更轻、职责更清。

- **游戏策划与叙事设计**（概念/MDA/GDD/关卡/经济/世界观/UX） → 文策渊（Vince Coyer）
- **技术与引擎工程**（架构/ADR/Godot·Unity·Unreal/玩法·引擎·AI·网络代码/性能/DevOps/安全） → 程基岩（Cheng Jiyan）
- **美术与视觉表现**（美术圣经/资产规格/着色器·VFX/技术美术/可访问性） → 林绘澄（Lin Wayson）
- **音频与声效设计**（音乐方向/音效/混音/音频实现/配音） → 阮和鸣（Ruan Hemo）
- **质量保障与测试**（测试策略/QA 计划/烟雾测试/回归/Bug 分级/Playtest） → 严守真（Yan Soujin）
- **发布与运营管理**（发布清单/本地化/Live Ops/社区/热修/回滚） → 路远行（Lu Yuanxing）
- **统一编排、SOP 调度、阶段质量门、最终汇编** → 主理人 游承峰（Yoan Summit）

## 七阶段标准工作流

1. **概念孵化** — 头脑风暴、设计支柱、MDA 分析、美术圣经
2. **系统设计** — 系统拆解、逐系统 GDD、跨 GDD 一致性评审
3. **技术搭建** — 主架构、ADR、控制清单、可访问性分级
4. **预制作** — UX 规格、资产规格、Epic/Story 拆分、测试脚手架、首冲刺
5. **制作** — 按冲刺循环实现 Story、QA、设计评审、范围检查
6. **打磨** — 性能剖析、平衡检查、资产审计、多轮 Playtest
7. **发布** — 发布清单、补丁说明、本地化、上线门控

## 典型用法

| 你想做的事 | 直接说 |
|-----------|--------|
| 不知从哪开始 | "帮我把游戏项目当工作室来推进，先告诉我现在该走哪个阶段" |
| 从零想一个游戏 | "帮我头脑风暴一个游戏概念，含设计支柱、MDA 分析与范围分层" |
| 推进开发 | "规划下一个冲刺：挑选就绪故事、实现、测试并收尾" |
| 准备发布 | "帮我跑一遍发布清单，确认能不能上线" |

## 团队协作机制

主理人亲自建团队并调度；成员只在被 spawn 后工作，产出通过 SendMessage 回传主理人中转，**成员之间不直连**。专业结论以成员为准，主理人只做编排与汇编。所有任务走协作式五步（问→选项→决策→草案→确认），用户始终掌舵，任何文件改动与提交都需用户许可。

## 适用 / 不适用

- ✅ 有结构、多职能、多阶段的游戏项目（从概念到上线）
- ✅ 想用工作室流程约束自己、避免硬编码与跳过设计文档的独立开发者
- ❌ 单一孤立小问题——可直调对应成员，无需走完整 SOP

## 使用方式

1. 确保本专家包已放入 `plugins/game-development-studio/` 目录（含 `.codebuddy-plugin/plugin.json`、`agents/`、`settings.json`）。
2. 在 CodeBuddy / WorkBuddy 中启用本插件，专家入口为 **游戏开发工作室（game-development-studio-team-lead）**。
3. 与主理人游承峰对话，它会先诊断你所在阶段，再按 SOP 调度对应成员。可直接用以下快捷提示开局：
   - "帮我把游戏项目当工作室来推进，先告诉我现在该走哪个阶段"
   - "帮我头脑风暴一个游戏概念，含设计支柱、MDA 分析与范围分层"
   - "规划下一个冲刺：挑选就绪故事、实现、测试并收尾"
