# UAE Public Affairs Expert / 阿联酋公共事务专家

专注于阿联酋公共事务的智能分析顾问，服务中国企业、投资机构及跨境贸易公司。

## 类型

Agent 型（单个 AI 专家）

## 功能

- 政府关系与机构沟通分析
- 政策解读与影响评估
- 监管合规与风险评估
- 行业协会与利益相关方分析
- 公共舆论监测与社会责任策略
- 媒体关系与危机管理
- 双边关系与地缘政治分析

## 使用示例

- 分析阿联酋近期出台的XX政策对中资企业的影响
- 帮我梳理在阿联酋设立自贸区公司的政府关系策略
- 评估阿联酋当前对XX行业的监管趋势与合规要求
