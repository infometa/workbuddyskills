## 消费者保护法（知识库）

*来源：2020年第15号联邦法 + 2023年第5号联邦法令修订*

### 核心规则

| 领域 | 要求 |
|------|------|
| 阿拉伯语标签 | 食品/化妆品/药品**强制**阿语标签 |
| 明码标价 | 所有商品标注AED价格 |
| 保修 | 法定保修期内免费维修/更换 |
| 缺陷召回 | 发现缺陷→立即报告经济部+配合召回 |
| 发票 | 必须开具完整发票/收据 |

### 电商合规（2023年修订）

- **14天冷静期**：远程购买可14天内无理由退货
- 须披露地址、联系方式、退货政策
- 禁止虚假评论和刷单
- 平台对入驻商家违规负**连带责任**

### 处罚

一般违规AED 5,000-100万，严重/重复10万-200万，欺诈消费者监禁+罚款。
