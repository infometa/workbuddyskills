## 反腐败与反贿赂合规体系（知识库）

*来源：联邦2023年第56号法（UAA）+ 2019年第26号法 + Wajib平台 + 联邦刑法典*

### 联邦监管机构

| 机构 | 法律依据 | 职责 |
|------|---------|------|
| **UAA（阿联酋问责局）** | 2023年第56号联邦法令（总统签署，取代2019年第26号法） | 调查联邦实体财务/行政违规、腐败、贪污、挪用公款；有权传唤证人、获取记录；与公诉机关协调刑事移送 |
| **ADAA（阿布扎比问责局）** | 阿布扎比层面 | 原联邦级反腐职能已升至UAA，现专注阿布扎比酋长国 |

**UAA关键权力：**
- 总干事由总统任命，任期4年
- 传唤证人 ✓  强制取证 ✓  完全档案查阅权 ✓
- 年度报告须经行政机关审查后公开（独立性受限）

### 举报机制

| 平台 | 范围 |
|------|------|
| **Wajib**（واجب） | ADAA创建，2023年起推广至**全联邦**各部委和机构——全民举报财务/行政腐败 |
| **Takallam** | ADNOC内部举报平台（第三方托管） |
| UAA官网 | uaa.gov.ae，直接举报通道 |

### ⚠️ 联邦刑法典反贿赂条款

- 阿联酋**新刑法典**（2021年第31号联邦法令）为主管反贿赂/腐败的联邦刑事法律
- 公职人员收受贿赂、私营部门商业贿赂均为刑事犯罪
- 处罚：监禁+罚款，情节严重者从重

### 📌 对中企实操意义

- UAA可**直接传唤**涉及联邦合同的公司和人员配合调查
- 联邦实体投标/履约中任何疑似「关系费」「回扣」均可能触发UAA调查
- Wajib平台覆盖全联邦——**任何阿联酋公民/居民均可匿名举报**
- **ADGM举报人保护新规**（2024年7月生效）：ADGM企业须制定书面举报政策；受保护披露（善意报告）、允许匿名、反报复保护；大型实体须在2025年5月31日前完成

### 执法趋势（2024-2025）

| 领域 | 执法动态 |
|------|---------|
| **贵金属/黄金精炼** | 32家精炼厂执照被暂停，256项违规 |
| **银行AML** | 央行对某本地银行罚款**AED 580万** |
| **DFSA执法** | 2024年对个人和公司罚款总计US$250万，单案最高近US$100万 |
| **虚拟资产** | 比特币诈骗团伙被判刑+罚款（涉案AED 1,000万） |
| **监管趋势** | 2026年FATF下一轮互评估临近，执法将持续高压 |

### 📌 对中企实操补充

- **合规文化是硬门槛**：联邦采购法将反腐败/诚信设为前置资格项，在价格评标前就可能因瑕疵出局
- **贵金属/金融/虚拟资产**是最高风险行业
- **举报机制广泛覆盖**：Wajib+ADGM举报框架意味着内部不当行为面临多重曝光渠道
- **外包IT/第三方尽职调查**：DFSA发现仅75%公司对第三方授予数据访问前做尽职调查——中企供应链管理须关注
- ADNOC供应商须遵守Takallam举报热线 + 供应商道德准则双重合规
