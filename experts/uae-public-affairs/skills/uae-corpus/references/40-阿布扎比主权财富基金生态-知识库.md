## 阿布扎比主权财富基金生态（知识库）

*来源：MDGH 2025年度合并财务报表 + 公开信息*

阿布扎比是全球主权财富基金资本最密集的城市，三大核心基金控制着资本、产业和全球投资的流向：

### Mubadala（穆巴达拉投资公司）

| 维度 | 数据 |
|------|------|
| 法律实体 | Mamoura Diversified Global Holding PJSC（MDGH） |
| 设立依据 | 2002年第12号埃米尔令 |
| 法定资本 | AED **561亿**（股本）+ AED **1,179亿**（股东追加出资） |
| FY2025收入 | AED **509亿** |
| FY2025净利润 | AED **472亿**（+26.7% YoY） |
| AUM（2024） | **USD 3,300亿**（AED 1.212万亿，覆盖六大洲） |
| FY2025投资净收益 | AED **574亿** |
| 总权益（2025.12.31） | AED **3,844亿** |
| 员工 | **156,438人**（含合并子公司） |
| 行业覆盖 | 能源、基础设施、科技、医疗、航空航天、半导体、金融服务 |
| 重大收购2025 | CI Financial Corp.（加拿大财富管理平台） |

**Mubadala 绿色金融（新增）：**

| 维度 | 数据 |
|------|------|
| 首笔绿色债券 | 2023年11月，**USD 7.5亿**（10年期），2024年第二次报告 |
| 发行人 | MDGH GMTN (RSC) LTD，由MDGH无条件不可撤销担保 |
| 绿色框架 | 符合ICMA《绿色债券原则2021》，Sustainalytics第二方意见 |
| 资金分配 | **100%已全部分配**：可再生能源 + 绿色建筑（5个项目） |
| 年度减排 | 约 **383,279吨CO2e**（相当于83K辆汽车年排放） |
| 保证 | PwC独立有限保证 |
| 对标 | MDGH自身净零2050 + 阿联酋净零2050 |

**Mubadala 决策链路**：董事会→投资委员会→各个垂直平台（Mubadala Energy、Mubadala Capital、Mubadala Health等）

### ADIA（阿布扎比投资局，1976年Emiri法令设立）

*来源：ADIA官方介绍文件（2025年2月版）*

- **法律地位**：独立投资机构，由阿布扎比最高金融与经济事务委员会任命董事会
- **政府关系**：**不参与政府支出决策**，也无权知晓政府支出需求——法律保障的投资独立性
- **投资组合**：覆盖**20+**资产类别及子类别（股票、固定收益、对冲基金、私募股权、房地产、基础设施）
- **地理配置区间**：北美45-60%、欧洲15-30%、新兴市场10-20%、发达亚洲5-10%
- **资产类别**：股票→固定收益→金融另类→私募股权→房地产→基础设施（六大部门）
- **人才**：65+国籍员工，全球招聘
- **长期主义**：1976年法律写入的使命——超越市场周期和波动，聚焦长期趋势

**与Mubadala的关键区别：**
| 维度 | ADIA | Mubadala |
|------|------|---------|
| 投资角色 | 纯财务投资者 | 战略性投资者+GP |
| 被投公司参与 | 不参与管理 | 控股运营平台 |
| 透明度 | 不公开AUM | 公开年报/AUM |
| 决策自主权 | 法定独立于政府 | 紧密配合政府战略 |

### ADQ（阿布扎比发展控股公司，2018年设立）

- AUM约$200B，定位偏"战略性"和"实业控股"
- 核心理念：建立阿布扎比关键产业的国家冠军企业
- 主要平台：ADNOC配送、阿布扎比港口集团、Etihad铁路、ADQ Aerospace、PureHealth等

### 📌 对中企的实操意义

- Mubadala的年报是公开的（PwC审计），提供对阿布扎比政府资产配置的最透明窗口
- ICV计分体系通过ADNOC/Mubadala/ADQ的采购链传导，中企要进入这些实体的供应商体系必须先获取ICV认证
- 主权基金对中国市场有战略配置需求——Mubadala和ADIA在北京/香港设有代表处
- 与GREs合作通常需要：ICV认证 + 酋化达标 + 长期承诺
