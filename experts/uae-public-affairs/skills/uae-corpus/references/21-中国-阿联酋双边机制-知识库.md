## 中国-阿联酋双边机制（知识库）

*来源：中阿避免双重征税协定（1993）+ MLI合成文本 + OECD 信息*

### 避免双重征税协定（DTA）

**全称**：中华人民共和国政府和阿拉伯联合酋长国政府关于对所得避免双重征税和防止偷漏税的协定

| 要素 | 内容 |
|------|------|
| **签署日期** | 1993年7月1日 |
| **签署地** | 阿布扎比 |
| **签署人** | 李岚清（中国国务院副总理）/ Sultan Bin Zayed Al Nahyan（阿联酋副总理） |
| **语言** | 中文、阿拉伯文、英文（冲突时以**英文**为准） |
| **生效** | 交换外交照会后第30天 |
| **适用** | 生效后次年1月1日起 |

### BEPS多边公约（MLI）对DTA的修订

| 要素 | 中国 | 阿联酋 |
|------|------|--------|
| **MLI签署日期** | 2017年6月7日 | 2018年6月27日 |
| **批准/接受日期** | 2022年5月25日 | 2019年5月29日 |
| **MLI对该协定生效** | 2022年9月1日 | 2019年9月1日 |
| **对预提税生效** | 2023年1月1日起 | 同 |
| **对其他税生效** | 2023年3月1日起 | 同 |

**MLI核心修订**：
- **第6条（协定的目的）**：新增反协定滥用宗旨——"无意通过条约选购等安排为第三国居民间接获益创造条件"
- **第7条（防止协定滥用/主要目的测试PPT）**：如合理认定主要目的之一是获取协定优惠，且给予优惠不符合协定目的，则**拒绝给予协定优惠**——这对中间控股架构有重大影响

### DTA核心税率表

| 所得类型 | 协定税率 | 条件/备注 |
|----------|---------|----------|
| **股息** | **7%** | 受益所有人持股≥25%时可适用 |
| **利息** | **7%** | 政府/央行/国有金融机构利息免税 |
| **特许权使用费** | **10%** | 发生于一方并支付给另一方居民的 |
| **技术服务费** | 按营业利润/独立劳务 | 常设机构规则 |
| **不动产所得** | 来源国征税 | 包括农业/林业/转让所得 |
| **营业利润** | 仅居民国征税 | 除非通过PE取得 |
| **国际运输利润** | 仅在总机构所在国征税 | 海运/空运 |
| **独立个人劳务** | 原则上仅居民国征税 | 除非固定基地或183天规则 |
| **受雇所得** | 183天 + 非居民雇主 + PE不负担 | 三条件同时满足则仅居民国征税 |
| **董事费** | 公司居民国可征税 | — |
| **艺术家/运动员** | 活动所在国可征税 | 政府文化交流计划免税 |
| **退休金** | **仅居民国征税** | 政府社保计划下的养老金仅支付国征税 |
| **教师/研究人员** | **免税5年**（首次到达起算） | 须在经认证的机构中教学/讲座/研究 |
| **学生/培训生** | 境外汇款+奖学金+个人劳务免税 | 仅限维持生活/教育/培训目的 |

### 消除双重征税方法（第23条）

| 国家 | 方法 | 关键特征 |
|------|------|----------|
| **阿联酋** | 抵免法 | 境内法允许对中国已缴税款给予抵免 |
| **中国** | 抵免法 | (a) 对中国居民从阿联酋取得所得，阿方已缴税款可抵免中国税，限额为按中国税法计算的税额；(b) 对股息间接抵免：持股≥10%，母公司可抵免子公司已缴税款 |
| **税收饶让**（第23.5条） | **中国税收优惠视为已缴** | 股息/利息/特许权使用费的**中国税统一按20%视为已缴纳**——即使实际未缴或减免 |
| **中国免税视为已缴**（第23.6条） | 饶让抵免延伸 | 中国对外商投资企业的免税/减税/退税也视为已缴（依据旧外资企业所得税法） |

### 常设机构（PE）门槛

| 类型 | 时间/条件 |
|------|----------|
| **建筑工地/安装工程** | 连续超过**6个月** |
| **准备/辅助活动** | 不构成PE |
| **代理人** | 有权以企业名义签合同并经常行使的，构成PE（独立代理人除外） |

### 信息交换机制（第26条）

- 双方主管当局交换为执行协定或国内税法所需的**必要信息**
- 不受第1条（人的范围）限制
- 接收信息须视为**机密**，仅可向涉税评估、征收、执行、起诉、裁决的人员和机构披露
- 不可要求提供：违反法律法规的信息、无法正常获取的信息、商业秘密

### 相互协商程序（MUTUAL AGREEMENT PROCEDURE, 第25条）

- 纳税人认为被征税不符合协定的，可在首次收到通知后**3年内**向居民国主管当局提出
- 双方主管当局可直接沟通，必要时口头交换意见
- 达成的协议不受国内法时效限制

### 非歧视条款（第24条）

- 国籍非歧视
- 常设机构非歧视（但个人免税额/扣除额例外）
- 利息/特许权使用费等费用扣除不因收款方为非居民而受限制
- 资本所有权不导致歧视

### 协定议定书（PROTOCOL）——协定的组成部分

签署协定时双方约定以下补充条款（与协定正文具有同等效力）：

| 条款 | 内容 |
|------|------|
| **对第8条（海运空运）的补充** | 中国方面免税范围还包括**工商统一税及其附加**；阿联酋方面如未来开征类似税种也同样豁免 |
| **海湾航空（Gulf Air）** | 第8条第1款仅适用于海湾航空公司利润中**阿联酋持有份额**的部分 |
| **对第15条（受雇所得）的补充** | 一方空运和海运企业派遣至另一方的**雇员**，其报酬仅在派遣国征税（不受183天规则限制） |

### 主管当局（Competent Authority）

| 国家 | 主管当局 |
|------|---------|
| **阿联酋** | 财政与工业部长或其授权代表（Minister of Finance and Industry） |
| **中国** | 国家税务总局或其授权代表（State Tax Bureau） |

### 居民定义（第4条）——含政府实体

协定的"居民"定义特别包括：
- (a) 缔约国政府、政治区划或地方当局
- (b) 上述政府/当局**直接或间接全资拥有**的任何政府机构和实体
- (c) 缔约国境内设立的、全部资本由该国政府**单独或与其他国家政府共同提供**的实体

### 终止条款（第29条）

协定**无限期有效**，但任一方可在协定生效满**5年**后的任何日历年6月30日前通过外交渠道发出书面终止通知，协定将在次年1月1日起停止适用。

### 中阿BIT（双边投资协定）

| 要素 | 内容 |
|------|------|
| **性质** | 双边投资保护与促进协定 |
| **核心保护** | 公平公正待遇、充分保护与安全、不得无理/歧视性征收、征收须给予补偿 |
| **争端解决** | 投资者可将争端提交**ICSID**（国际投资争端解决中心）或**UNCITRAL**仲裁 |
| **中企意义** | 在阿中资企业可援引BIT保护投资免受政府不当干预 |

### 2024年5月联合声明核心承诺（47条要点提炼）

**政治互信与主权支持**
- 阿联酋重申坚定恪守**一个中国原则**，台湾是中国不可分割的一部分，支持中国统一，反对外部势力干涉中国内政（第13条）
- 阿方支持中国在新疆穆斯林公民关怀及维护国内稳定方面的努力，反对一切形式的极端主义和恐怖主义（第14条）
- 中方支持阿联酋根据国际法通过双边谈判**和平解决三岛**（大通布、小通布、阿布穆萨）问题（第26条）
- 在涉及彼此主权、独立、领土完整、安全等问题上继续坚定相互支持（第12条）

**经贸与投资合作**
- 2023年两国非石油贸易额近**810亿美元**，同比增长4.2%，中国多年保持阿联酋第一大贸易伙伴地位（第15条）
- 目标：**2030年双边贸易额达2000亿美元**（第15条）
- 成立**中阿促进投资合作高级别联合委员会**作为投资对话机制（第16条）
- 加强**中阿商务理事会**作用，促进产业链供应链合作（第17条）
- 持续支持**中阿经贸联委会**、中阿经济论坛等平台（第18条）

**金融创新**
- 央行数字货币（CBDC）合作：阿联酋通过**mBridge**平台完成首笔5000万迪拉姆"数字迪拉姆"直接跨境支付（第18条）
- 在两国央行《关于加强央行数字货币合作的谅解备忘录》框架内深化合作

**基础设施与航空**
- 加强航空运输合作，鼓励航空公司增开航线航班（第19条）
- 阿方支持"一带一路"倡议，中方赞赏阿方积极出席第三届高峰论坛（第20条）
- 在第三国开展"一带一路"框架内共同投资合作

**能源合作**
- 可再生能源、石油、天然气、石化、**氢能、氨能**、石油战略存储等领域加强合作（第35条）
- 探讨推动**原油储备合作**（第35条）
- 和平利用核能：探讨**核电建设**等示范性联合项目（第36条）

**科技与创新**
- 创新、数字经济、科学、开源项目孵化（第21条）
- **航天合作**：加强空间探索领域科学合作（第40条）
- 供应链互补，实现经济和投资增长（第21条）

**军事与安全**
- 加强国防、军事和安全领域合作（第42条）
- 2023年8月举行**"猎鹰盾牌-2023"**中阿空军联合训练，未来进行更多联合训练（第42条）
- 打击有组织犯罪、电信网络诈骗、网络赌博、洗钱、贩卖人口、毒品和非法移民（第41条）

**国际事务协作**
- 加沙：立即持久停火，支持两国方案，建立以1967年边界为基础、以东耶路撒冷为首都的独立巴勒斯坦国（第23条）
- COP28：中方祝贺阿联酋成功举办并达成"阿联酋共识"（第24条）
- WTO：维护以世贸组织为核心的多边贸易体制（第28条）
- 金砖国家：加强框架内合作（第29条）
- 海上航道安全：保护航运和供应链畅通（第27条）
- 中阿合作论坛、中阿文明对话研讨会等机制（第31条）

**人文与教育**
- 官方和民间文化艺术交流（第44条）
- 各层次学生、教师、研究人员交流互访（第45条）
- 推进**阿联酋学校中文教育**（第45条）
- 基础教育、高等教育、职业教育、数字教育等领域合作（第45条）
- 旅游合作与人员往来（第44条）

### 📌 对中企的实操意义

1. **2000亿美元贸易目标是政策风向**：双方政府将全力推动，贸易型中企将享有持续利好
2. **投资高级别联合委员会**：中资重大项目可通过该机制获得顶层推动
3. **mBridge数字支付**：数字货币跨境支付已落地，中企可探索利用该通道降低汇兑成本
4. **核电/氢能/航天是新增长极**：高附加值领域合作从意向进入实操
5. **军事安全合作深化**：为国防相关企业拓展阿联酋市场提供政治背书
6. **三岛问题上中方支持阿联酋**：中企在涉及伊朗业务的合规筛查中需注意此政治立场
7. **中文教育推进**：中资企业在阿联酋招聘本地员工的教育基础在改善
8. **航空合作**：中阿航线增加有利于商务往来和成本控制
