## 阿联酋数字政府政策（知识库）

*来源：阿联酋内阁《数字客户与数字政府服务政策》（2021年3月，v2，10页，阿拉伯文）*

### 政策定位

阿联酋政府目标跻身**全球政府服务最佳国家行列**。本政策适用于联邦政府所有实体和全部政府服务。

### 核心原则

| 原则 | 内容 |
|------|------|
| **Digital-First（数字优先）** | 所有政府服务**以数字形式为首要**设计和交付渠道，非数字渠道仅为服务无法获取数字服务的群体而保留 |
| **100%数字化目标** | 所有可转化为数字服务的政府服务必须**100%向数字渠道迁移** |
| **Proactive（主动式）** | 所有可转化为主动式服务的政府服务，必须尽可能向**主动预测和推送**模式转型 |
| **Once Only（一次采集）** | 政府**不得重复索取**已掌握的企业/公民数据和文件，最大化减少表单填写和纸质文件提交 |
| **Seamless（无缝）** | 跨政府实体协同设计服务，按客户生活事件（life events）而非部门边界来设计端到端旅程 |
| **服务连续性** | 每个政府实体必须制定和更新服务连续性计划，确保7×24高可用 |

### 数字政府核心基础设施（6大Enablers）

| 基础设施 | 功能 | 对中企意义 |
|----------|------|-----------|
| **FEDNET**（联邦政府网络） | 联邦政府共享IT基础设施（服务器、网络、存储、应用），为所有政府实体提供安全访问 | 与政府系统对接的基础通道 |
| **GSB**（Government Service Bus） | 政府实体间数据交换的集成平台，**禁止**建立直接点对点数据连接 | 所有政府数据交换必须经此总线 |
| **National CRM** | 统一的客户关系管理系统，管理客户注册、查询、投诉、建议及互动 | 中企与政府互动的记录入口 |
| **UAE Pass**（数字身份） | **阿联酋唯一数字身份工具**（等同于实体身份证），是所有数字政府服务的**唯一入口** | 中企高管/员工必须注册 |
| **数字签名/数字印章** | 通过UAE Pass的数字签名与手写签名**具有同等法律效力**（依据1992年第10号和2006年第1号联邦法） | 合同/政府文件可合法电子签署 |
| **数字文件钱包** | 存放和共享数字政府文件，替代实体文件验证，政府须接受钱包中的数字文件等同于纸质原件 | 无需携带纸质文件跑政府部门 |

### 数据治理

| 规则 | 要求 |
|------|------|
| **权威参考登记册** | 政府维护各类数据的权威参考登记册（Authoritative Reference Registers），作为唯一可信数据源，消除数据重复和冲突 |
| **数据共享** | 所有政府实体间的数据共享必须通过**GSB**进行，遵循相关数据隐私和信息安全法规 |
| **开放数据** | 政府实体应发布开放数据，以最低限制与公众共享，最大化公众参与和经济增长 |
| **数据实时性** | 参考登记册的数据必须保持最新/准确，登记册管理者须制定业务连续性计划确保7×24可用 |

### 📌 对中企的实操意义

1. **UAE Pass是第一优先级**：所有在阿中企的法人和高管必须注册UAE Pass，这是与联邦政府打交道的数字门户
2. **数字签名的法律效力**：通过UAE Pass签署的合同与政府文件与手写签名等效力，可直接用于商业和司法程序
3. **Once Only原则**：政府不会重复索要已提交过的文件——但也意味着你的数据一旦进入系统，所有政府实体都可查阅
4. **GSB强制数据总线**：不可与政府部门建立点对点数据连接，所有数据共享必须通过GSB，中企IT系统集成时须注意合规
5. **数字印章替代传统印章**：中阿合资/合作企业的政府备案文件可使用数字印章
6. **连续性要求**：作为政府IT供应商的中企须满足7×24连续性标准
