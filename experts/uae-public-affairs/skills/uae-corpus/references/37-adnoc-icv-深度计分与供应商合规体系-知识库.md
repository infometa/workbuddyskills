## ADNOC ICV 深度计分与供应商合规体系（知识库）

*来源：ADNOC ICV实施指南 Rev.4（2026年3月15日生效）+ Rev.3.1（2022年2月）+ 供应商FAQ + 付款流程*

ADNOC ICV（In-Country Value）计划于**2017年11月**推出，是阿联酋最严格的采购本地化计分体系，现已扩展至ADNOC集团旗下所有公司的所有招标。

### 三大核心目标

1. **酋化（Emiratization）**：为阿联酋公民创造私营部门就业
2. **GDP多元化**：增加在阿联酋境内采购商品和服务
3. **战略本地化**：将关键价值链环节本土化

### Rev.4 关键变化（2026年3月15日起适用）

| 变化 | 内容 |
|------|------|
| 生效日期 | **2026年3月15日**起所有ADNOC集团新招标 |
| 旧招标过渡 | 该日期前授予的合同继续按原合同条款执行，**不追溯** |
| 本地制造商 | 新增明确的"本地制造商优先"标准 |
| EPC/施工 | 新增专门的EPC和施工项目ICV评估条款 |
| 付款模板 | 新版ICV付款计算模板（Rev.4），仅用于含新版ICV条款的合同 |

### ICV证书（ICV Certificate）

| 维度 | 详情 |
|------|------|
| 签发 | 由认证机构（Certifying Body）签发——**非ADNOC签发** |
| 有效期 | **14个月** |
| 模板 | 认证机构填写ICV证书模板 |
| 认证方 | 工业与先进技术部（MoIAT）认可的认证机构 |
| 更新 | 通过认证机构更新，**不走ADNOC渠道** |

### ICV改进计划（ICV Improvement Plan）

- 供应商须在投标时提交未来年份的ICV**预测数据**（公司级+合同级）
- 含收入/支出/本地制造/本地雇佣/Emirati雇佣等维度的预测
- Rev.4提供两种模板：公司特定（Company Specific）和合同特定（Agreement Specific）

### ⚠️ 本地制造商优先（Rev.4新增）

- 本地制造商满足Rev.4 ICV标准时，在**直接采购货物**招标中获得优先权
- 但在**价格不具竞争力时不会被授予合同**
- 非本地制造商可与本地制造商竞标，但处于**系统性劣势**

### 评标权重（商业评估）

ICV评分按加权公式计入总评标分数：
- ICV总分 = ICV证书分数 + ICV改进计划分数
- 合资/联合体：按比例加权计算
- Ta'ziz工业园（Ruwais）投资可获**额外加分**

### 📋 ICV付款释放——财务要求清单

1. 合同管理员批准的期间ICV付款模板
2. 合同周年期内所有已付发票对账单（Excel）
3. 合同约定的ICV改进计划
4. 在合同年完成日有效的ICV证书
5. 投标阶段的ICV评分
6. 税务发票
7. 提交非PO发票

### 📌 对中企的实操意义

- **必须先拿到ICV证书**才能参与ADNOC集团招标（向MoIAT认证机构申请）
- ICV证书有效14个月，投标时必须处于有效期内
- 非本地制造商投标货物类项目面临**本地制造商优先**条款——需比本地制造商价格更具竞争力
- 在Ta'ziz/Ruwais工业园有投资的可获加分
- 合同履行期ICV付款须按年提供上述完整文件包
- ICV改进计划提交不实数据将影响未来评标资格

### ADNOC iSupplier供应商门户

*来源：ADNOC Distribution iSupplier用户手册（2018版，Oracle EBS平台）*

ADNOC集团通过Oracle iSupplier门户管理供应商的发票、付款和订单：

| 功能 | 路径 |
|------|------|
| 登录 | **eservice.adnocdistribution.ae**（ADNOC Distribution入口），首次登录强制修改密码 |

### ADNOC Distribution 供应商道德准则

*来源：ADD Supplier & Partner Code of Ethics v1（12页，董事长签署）*

ADNOC Distribution要求所有供应商和合作伙伴遵守的最低道德标准：

| 领域 | 核心要求 |
|------|---------|
| **反贿赂/腐败** | **零容忍**——禁止提供、索要、给予或接受任何形式的贿赂 |
| **礼品与招待** | 禁止向ADNOC人员提供奢侈礼品、频繁餐饮或昂贵礼物；所有礼品须合法商业目的 |
| **利益冲突** | 供应商员工与ADNOC人员有任何私人/家庭关系须**主动申报**；禁止利用关系获取商业利益 |
| **劳工实践** | 禁止强迫劳动/童工/贩运劳工；分包商须同样遵守 |
| **反垄断/公平竞争** | 遵守所有反垄断法、进出口海关法规和国际贸易法律 |
| **健康安全环保** | 须遵守所有适用HSE法律、获取环保许可、制定应急预案 |
| **供应链管理** | 须对第三方/承包商/代理进行尽职调查和背景审查 |
| **信息保密** | 保护ADNOC信息和知识产权，禁止不当使用保密信息 |

**举报渠道：**
- 合规邮箱：**ethicsandcompliance@adnocdistribution.ae**
- 独立举报平台：**Takallam**（第三方托管，支持匿名举报）

⚠️ 违反该准则可导致**终止合作关系**乃至法律追诉。中企与ADNOC Distribution建立合作前须确认内部合规体系对标本准则。

### 签证配额规则

大多数自贸区**签证配额与办公室面积挂钩**（非牌照类型）：
- Flexi-desk（灵活工位）：1-3个签证
- 专用办公室：3-50+个签证（按面积递增）
- JAFZA/KIZAD/RAKEZ签证-成本比最优（适合劳动密集型）

### 大陆准入

自贸区企业直接在大陆经营受限，可选路径：
1. **双牌照**（DET-自贸区一体化计划，DMCC等部分自贸区支持）
2. 指定**大陆分销商**/商业代理
3. 设立单独的**大陆LLC实体**或分公司

### 银行开户难度

- **DMCC**：最便利（客户基数大，银行熟悉度高）
- DIFC/ADGM：次之（高净值，银行接受度好）
- RAKEZ/SHAMS/IFZA：须额外解释业务实质，某些银行开户周期较长
- 预算区（UAQ FTZ等）：部分银行不愿开户，须提前确认

### 选自贸区5要素

1. **行业匹配**：选有行业专长的区域
2. **预算**：不仅看启动费，还要看年审续费+签证+办公
3. **银行开户**：DMCC和JAFZA传统上银行认可度最高
4. **地理位置**：接近客户/港口/机场
5. **增值服务**：现成办公室、签证支持、全套商务生态

### 📌 对中企的实操意义

- 贸易/物流类 → **JAFZA**（港区优势）
- 钻石/黄金/大宗商品交易 → **DMCC**（行业地位+银行友好）
- 中小企业/创业 → **IFZA**或**RAKEZ**（成本最低）
- 制造业 → **JAFZA**或**RAKEZ**（工业设施）
- 全阿最便宜 → **Fujairah Creative City**（AED 5,500起）
