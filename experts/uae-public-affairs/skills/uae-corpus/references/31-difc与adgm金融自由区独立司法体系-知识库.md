## DIFC与ADGM——金融自由区独立司法体系（知识库）

*来源：DIFC/ADGM法律框架 + Falcon Law分析*

阿联酋设有两个金融自由区，拥有**完全独立于联邦大陆法系统的普通法司法管辖**：

### DIFC（迪拜国际金融中心，2004年设立）

| 维度 | 详情 |
|------|------|
| 法律体系 | 自定法律（基于英国普通法原则），独立于联邦法 |
| 法院 | **DIFC法院**（独立司法，英语审理），设小额索偿庭 |
| 金融监管 | **DFSA**（迪拜金融服务局） |
| 仲裁 | DIFC-LCIA仲裁中心 |
| 数据保护 | DIFC数据保护法（2020年第5号）——独立于联邦PDPL |
| 侧重 | 传统金融、银行、资本市场、财富管理 |

### ADGM（阿布扎比全球市场，2015年设立）

| 维度 | 详情 |
|------|------|
| 法律体系 | **直接适用英国普通法**（含判例） |
| 法院 | **ADGM法院**（仿英国法院，英语审理） |
| 金融监管 | **FSRA**（金融服务监管局） |
| 仲裁 | ADGM仲裁中心（世界级设施） |
| 侧重 | 金融科技、数字资产、区块链、Web3创新 |

### 📌 对中企的实操意义

- **合同管辖选择**：可约定DIFC/ADGM法律作为合同管辖法，即使业务不在区内
- **判决执行优势**：英语判决，无需翻译认证即可在境外执行
- **金融牌照**：DFSA/FSRA牌照国际认可度高，虚拟资产牌照通过VARA在迪拜拿
- **税收**：区内企业满足经济实质条件可享0%企业税
