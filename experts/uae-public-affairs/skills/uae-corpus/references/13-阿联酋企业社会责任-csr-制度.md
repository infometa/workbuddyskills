## 阿联酋企业社会责任（CSR）制度

*来源：2018年第2号内阁决议《企业社会责任法》*

### 核心制度

| 项目 | 说明 |
|------|------|
| CSR智能平台注册 | **强制性**——所有商事公司年审续牌前须通过平台披露CSR贡献（或无贡献） |
| 实际贡献 | **自愿性**——公司自主选择是否向平台上的项目捐款 |
| 平台注册费 | AED **1,500**/年（强制，视为CSR贡献的一部分） |
| CSR标志申请 | AED **10,000**/年（自愿，获标志后可享激励） |
| CSR大奖角逐 | AED **15,000**/年（自愿，竞争最高荣誉） |

### CSR实践范围（4类）
1. 对平台开发项目的资金/实物捐赠
2. 采用环保友好的生产运营政策
3. 促进创新和科研、解决社会挑战
4. 建立CSR文化、开展人道主义和志愿项目
