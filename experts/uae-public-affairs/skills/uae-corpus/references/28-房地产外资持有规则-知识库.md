## 房地产外资持有规则（知识库）

*来源：DLD + RERA + 各酋长国土地局*

### 迪拜

| 费用 | 比例 |
|------|------|
| DLD登记费 | 房价**4%** |
| 中介佣金 | **2%** |
| 总成本 | 约**6.25%** |
| 贷款首付（首套） | **20%**（≤AED 500万）/ **30%**（>500万） |
| 非居民贷款LTV | 50-60% |

自由持有区60+：Dubai Marina、Palm Jumeirah、Downtown、JLT、Business Bay、JVC、Dubai Hills、Arabian Ranches等。

### 其他酋长国

阿布扎比：Al Reem/Saadiyat/Yas/Al Raha可自由持有。沙迦：Tilal City开放。拉斯海马：Al Hamra/Mina Al Arab。

### 关键提醒

- **期房托管**：所有期房款项入DLD托管账户，开发商按进度提取
- **遗嘱必须**：无遗嘱则按伊斯兰教法继承，外国投资者强烈建议在DIFC/ADJD注册遗嘱
