## NCEMA危机管理与业务连续性体系（知识库）

*来源：AE/SCNS/NCEMA 7000:2021《国家业务连续性管理体系标准》（第三版，58页），NCEMA（国家紧急危机与灾害管理局）发布*

### NCEMA机构概况

| 要素 | 内容 |
|------|------|
| **全称** | National Emergency Crisis and Disaster Management Authority |
| **隶属** | 最高国家安全委员会（Supreme Council for National Security） |
| **主席（国家安全顾问）** | H.H. Tahnoun bin Zayed Al Nahyan |
| **核心职责** | 制定国家危机与灾害管理政策、监督联邦和地方层面业务连续性实施 |
| **标准版次** | AE/SCNS/NCEMA 7000:2021（第三版，前身为2015年第二版） |
| **国际对标** | ISO 22301:2019（业务连续性）+ ISO 31000:2018（风险管理） |
| **语言** | 阿拉伯语和英语（不一致时以**英语版**为准） |
| **标准构成** | 三份独立出版物：（1）规范（Specifications）—合规审计依据；（2）指南（Guidelines）—解释说明；（3）工具包（Toolkit）—模板与实施支持 |

### 适用范围

NCEMA 7000:2021适用于**所有阿联酋实体**，包括：
- 联邦和地方政府机构
- 私营部门（尤其是政府供应商和关键基础设施运营商）
- 履行政府基本职能和社区服务的组织

**核心目标**：确保政府和私营部门在发生突发事件时能维持**关键运营（Essential Operations）**在预定最低可接受水平。

### 实施层级架构

```
国家业务连续性管理体系标准
├── 联邦层面（Federal Level）
│   ├── 部长发展委员会（Ministerial Development Council）
│   │   └── 指定机构 → 联邦实体 + 私营部门
│   └── 地方紧急危机与灾害管理团队
│       └── 指定机构 → 地方实体 + 私营部门
└── 地方层面（Local Level）
    ├── 王储法院（Crown Prince Court）
    │   └── 执行委员会总秘书处（General Secretariat of Executive Council）
    │       └── 地方紧急危机与灾害管理团队
    │           └── 指定机构 → 地方实体 + 私营部门
```

### 第8条：BCMS运营核心流程（6大模块）

#### 8.2 业务影响分析（BIA）
- 识别**优先活动（Prioritized Activities）**
- 对每项活动评估中断1h/4h/24h/48h/72h的影响
- 确定**恢复时间目标（RTO）**
- 识别活动依赖关系（人员、供应商、IT系统、设施）
- **单一依赖外部供应商**的优先活动须额外评估供应商的BC安排
- BIA输出须以适合最高管理层决策的形式呈现

#### 8.3 风险评估（RA）
- 针对优先活动及其依赖的威胁和脆弱性进行识别、分析和评价
- 评估风险发生的**可能性和后果**
- 确定风险优先级，为策略制定提供输入

#### 8.4 业务连续性策略
- **策略识别**（8.4.1）：保护优先活动、缩短中断时间、限制影响
- **评估与选择**（8.4.2）：基于RTO恢复能力、风险匹配度、成本效益
- **资源需求**：人员（含替角）、建筑设施、预算、供应商、信息通信基础设施
- **实施**（8.4.3）：经最高管理层批准后实施

#### 8.5 计划响应

| 响应要素 | 核心要求 |
|----------|----------|
| **响应团队**（8.5.1） | 明确各团队职责、权限与能力，团队间互动清晰定义 |
| **响应结构设计**（8.5.2.1） | 灵活应对不可预见的威胁、聚焦中断影响、支持既定策略 |
| **响应结构内容**（8.5.2.2） | 目的/范围、角色职责、行动指令、所需资源、参考信息、恢复正常程序、行动记录方式 |
| **指挥与控制**（8.5.3.1） | 设立中央团队及时决策、安保信息传递、指令分发 |
| **事件检测与立即响应**（8.5.3.2） | 及时发现评估事件性质、优先保护生命安全、宣布中断并启动响应 |
| **中断期间沟通**（8.5.3.3） | 团队内外沟通、利益相关方沟通、媒体沟通（含模板）、与紧急响应方结构化沟通 |
| **技术系统恢复**（8.5.3.4） | 硬件/网络/软件/数据/物理环境的恢复要求、备份数据访问、替代服务获取 |
| **优先活动恢复**（8.5.3.5） | 在RTO内恢复优先活动的策略和资源需求 |
| **恢复正常**（8.5.3.6） | 返回正常的决策基础、非优先活动的恢复、事件后报告编制 |

#### 8.6 演练与测试
- 必须设计年度演练和测试计划（可跨多年覆盖全部范围）
- 区分**演练**（Exercise—培养团队能力）和**测试**（Test—验证特定成果可达成）
- 使用适当且真实的场景设定
- 产生演练后报告

### 实施指南（实操补充）

*来源：NCEMA BCM实施指南（الدليل الاسترشادي，74页，英文版）*

#### BIA数据收集方法（四种）

| 方法 | 适用场景 | 要点 |
|------|----------|------|
| **一对一访谈** | 关键岗位深度分析 | 可灵活追问、获取细节信息 |
| **管理层/主管工作坊** | 跨部门协同 | 需设定完成标准以确保明确预期成果 |
| **问卷调查** | 大规模数据采集 | 最常见方式；须精心设计问题确保理解准确；问卷后须做面对面访谈澄清疑问 |
| **混合方式** | 大型组织 | 问卷+访谈结合效果最佳 |

#### 风险评估矩阵（5级）

| 风险值 | 等级 | 处理要求 |
|--------|------|----------|
| 1 | 极低（Very Low） | 无需行动 |
| 2 | 低（Low） | 无需行动 |
| 3 | 中（Medium） | 逐案审议是否处理，决策须有说明 |
| 4 | 高（High） | 必须处理（除非：处理成本>影响、不可行、无法律后果、对目标影响可接受） |
| 5 | 极高（Very High） | 灾难性影响，必须处理 |

#### 风险处置四种策略

| 策略 | 方式 | 工具 |
|------|------|------|
| **接受** | 残余风险在风险偏好内可容忍 | 成本效益分析 |
| **降低** | 预防性维护、审计合规、合同条款、培训、技术控制 | 内控体系 |
| **转移** | 保险、外包、合资/合作 | 合同/协议 |
| **规避** | 停止可能产生风险的活动 | 业务决策 |

#### 供应商BCM评估

- 在招标文件和合同中纳入BCM要求描述
- 对供应商BC计划进行**定期审计评估**
- 以法律形式签订SLA（服务水平协议）或MOU

#### 演练与测试关键原则

- 与最高管理层合作确定最需提升的能力领域
- 测试应覆盖计划要素、资源和程序
- 回顾以往测试文档，避免重复场景
- 随时间推移覆盖对优先活动影响最大的场景
- 频率取决于组织性质、规模和复杂性
- **未经过演练的BCM能力不能被认定为可靠**

#### 年度管理评审与认证

- 管理评审**至少每年一次**，是BC能力认证的证据
- 评审输出须包含：评审范围、原因、参与人、问题领域、纠正/预防措施建议、演练测试回顾
- BCM项目每年至少进行一次全面审查（BIA、风险评估、BC策略、BC计划）
- 组织服务/工作变更或最高管理层变更时也须进行审查

### 📌 对中企的实操意义

1. **强制合规对象**：作为阿联酋政府供应商、关键基础设施运营商或在自由区注册的企业的中资公司，**很可能被要求符合NCEMA 7000**
2. **低合规成本高政治收益**：通过NCEMA认证可显著提升在阿政府关系和招投标中的信用评分
3. **BIA是入门门槛**：业务影响分析是所有后续步骤的基础，可聘请本地BCM顾问协助
4. **每年至少一次管理评审**：须纳入企业年度治理日程
5. **单点依赖风险**：对单一外部供应商的关键依赖须有替代方案，这是审计重点
6. **媒体沟通预案**：NCEMA特别强调中断期间的媒体沟通，中资企业应提前准备阿/英双语危机沟通模板
7. **自由贸易区特殊要求**：各自由区可能在此基础上增加额外要求，入驻前应查询
8. **法律衔接**：立法和监管机构可在NCEMA标准之外设定额外要求，如有冲突以NCEMA标准为准
9. **三层文件体系**：规范（审计）+ 指南（解释）+ 工具包（模板），建议从工具包入手

### 政府实体BCM实践案例：阿布扎比海关

*来源：阿布扎比海关2024年业务连续性政策（Business Continuity Policy 2024，1页）*

阿布扎比海关已发布正式BC政策，可作为中企与政府实体签订合同时的合规参考：

**识别的异常事件类型：**
- 恶劣天气条件
- 恐怖袭击
- 疫情
- 基础设施和技术故障
- **主要清关公司的丧失**（大面积服务中断）

**公开承诺（对标NCEMA 7000:2021 + ISO 22301:2019）：**
- 遵守阿联酋法律/监管/立法要求及NCEMA和ISO标准
- 确保持续服务交付和活动运行，防止中断、减少发生概率和影响
- 做好中断准备、响应和高效恢复
- 满足利益相关方需求和期望

> 💡 **启示**：阿布扎比海关已将BC合规纳入自身运营政策。作为其供应商或频繁清关的中资企业，在应急情况下可能被要求具备对应的BC能力以维持清关服务。
