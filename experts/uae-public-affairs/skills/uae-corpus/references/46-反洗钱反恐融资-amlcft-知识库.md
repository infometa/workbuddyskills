## 反洗钱/反恐融资（AML/CFT）（知识库）

| 关键节点 | 详情 |
|---------|------|
| FATF灰名单 | 2022.3进入 → **2024.2出列** |
| 监管机构 | CBUAE（央行）+ FIU（金融情报局）+ 执行办公室 |
| UBO登记 | 强制披露，不合规面临行政处罚 |
| 制裁合规 | 执行UN制裁决议，金融机构须建立OFAC/EU/UK筛查 |
| 可疑交易报告 | 金融/非金融机构均须向FIU报告 |

### 📌 对中企的实操意义

- 2024年出列后银行开户和跨境汇款明显改善
- 大额资金流动须保留完整来源和用途文档
- 与伊朗等制裁对象交易可能触发断开户

### 企业义务

- **强制披露**：每年续牌照前通过CSR平台披露过去一年CSR贡献（含"无贡献"声明的义务披露）
- **受益人实体**每3个月更新项目进展
- 平台项目使用"CSR项目"标签需审批

### CSR标志与奖励体系

| 层级 | 说明 |
|------|------|
| CSR标志（Mark） | 多类别分级，由基金颁发；有效期限制；可享受政府激励和优惠 |
| CSR大奖（Award） | 最高荣誉，授予CSR领域最卓越企业 |
| 国家CSR指数 | 年度发布，基于平台贡献比例排名所有企业 |

### 治理架构

- **国家CSR基金**：隶属经济部，法人资格、财务行政独立
- **董事会**：经济部长主持
- **咨询委员会**：经济部副部长主持，含各行业代表
- **各酋长国商会**：每年举办CSR协调论坛

### 对中企的意义

在阿联酋注册的所有商事公司（含外资分公司）均须在CSR平台注册并年度披露。即使零贡献也需声明。CSR标志和奖励可获得政府认可和激励——这是进入政府合作生态的重要"软实力"通道。

### 阿联酋政府2071未来愿景

*来源：世界政府峰会《Government in 2071 Guidebook》（内阁事务与未来部出版，194页）*

**核心驱动变量预测（至2071年）：**
- 全球升温约2°C，上海/曼谷/孟买/迈阿密等沿海城市将部分淹没
- 世界人口：86亿(2030)→106亿(2071)
- 中产阶级：18亿→49亿(2030)，近90%新增来自亚洲
- OECD国家当前政府岗位约50%将被自动化替代
- 全球年龄中位数：29.6岁(2030)→40岁(2071)

**政府职能的四大变革方向：**

| 变革领域 | 对中企的启示 |
|----------|-------------|
| 气候变化管理（最高优先级新增职能） | 气候难民移民管理、绿色基建、碳中和技术方案将成政府核心需求 |
| AI监管与AI驱动政务服务 | 政府将在AI立法中扮演核心角色；AI政务服务提供商有巨大市场 |
| 网络防御升级为独立国防类别 | 网络安全作为国家级优先事项，市政级攻击防御成新KPI |
| 终身教育/成人再培训成为政府支出重点 | 职业教育、短期虚拟再培训、技能重塑 |

**新型政府KPI：**
- 拦截网络攻击比例（市政级）
- 气候难民移民/10万人
- 可负担住房满意度%
- 与国际生态系统协作水平
- 电力/自来水覆盖率

**2050+年发展路径关键点：** 1/2当前政府岗位将被自动化替代；可能需要设立无党派的"未来部"；混合营利性企业将参与公共服务提供。

### 阿联酋政府创新基准

### 迪拜健康长寿局——重大新机构设立 🔴

*来源：迪拜官方公报第780期，2026年第17号法律（2026年6月13日发布，6月6日签署）*

迪拜统治者谢赫·穆罕默德·本·拉希德签署法律设立**迪拜健康长寿局**（Dubai Health Longevity Authority），配套颁布第14号令（任命主席）和第15号令（组建董事会）。

**机构使命：** 全面覆盖健康长寿需求，通过预防性、治疗性干预延缓衰老迹象，提供临床预防治疗服务，推广先进长寿治疗产品。

**四大战略目标：**
1. 将迪拜打造为**全球长寿治疗和先进疗法领导中心**
2. 通过预防性和创新活动提升居民与访客健康福祉
3. 建立数字技术集成系统和健康长寿临床指标数据库
4. 协调政府与非政府实体在长寿领域的合作

**监管权力：** 可停业（≤6个月）、吊销许可证、罚款。被处罚方可在30天内向执行总监申诉，15天内裁定。

**对中企的意义：** 这是迪拜在**长寿经济/抗衰老/生物科技**领域的标志性布局。中企在基因治疗、抗衰老研发、长寿诊所、数字健康监测等领域的商业机会将直接与该新机构对接。这也是继AI之后迪拜下一个战略性产业方向。
