## 阿联酋国旗使用规范（知识库）

*来源：阿联酋联邦礼宾与战略叙事局《UAE Flag Usage Guidebook》(2023)*

### 国旗历史与法律依据

- **首次升旗**：1971年12月2日，由国父谢赫·扎耶德在国庆庆典上升起
- **设计者**：Abdullah Al Maeena，在《Al-Ittihad》报1971年末举办的设计竞赛中胜出
- **颜色灵感**：源自 Safi al-Din al-Hilli 的诗句（红、绿、白、黑）
- **法律依据**：1971年第2号联邦法，经2019年第13号联邦法令修订

### 技术规格

- 长宽比 2:1（宽度为高度的两倍）
- 红色竖条占旗宽1/4，靠旗杆侧
- 其余三色（绿上、白中、黑下）为平行等高的水平横条

### 颜色含义与色值

| 颜色 | 含义 | Pantone | HEX |
|------|------|---------|-----|
| 白色 | 和平、奉献、支持世界安全与和平的国策 | 000C | #ffffff |
| 绿色 | 成长、繁荣、绿色环境、文化复兴 | 348C | #00843d |
| 黑色 | 国民力量与坚毅、拒绝不公与极端主义 | Black 6C | #000000 |
| 红色 | 建国一代的牺牲、国家烈士为守护成果的献身 | 186C | #c8102e |

### 使用场景与规范

| 场景 | 规范要求 |
|------|---------|
| 街道悬挂 | 垂直悬挂，红色部分朝上，三色朝下 |
| 建筑阳台/窗户 | 可垂直或以一定角度悬挂于旗杆，红色朝上，黑色在观众视角左侧 |
| 官方外访/外宾来访 | 水平升起 |
| 会议桌 | 置于阿联酋代表团正前方；与东道国国旗同时摆放时遵循国际荣誉位 |
| 组织旗与国旗同用 | 仅当组织旗尺寸小于国旗时可同时使用 |
| 围巾 | 垂直放置，红色朝上 |
| 军服/运动服 | 直立位置，红色始终从右侧开始 |

### 旗帜材质要求

- 使用最高比例聚酯混纺面料或可持续聚酯面料，**哑光无光泽**
- 特性：阻燃、抗紫外线、耐土壤酸碱、强度高抗撕裂

### 旗杆与尺寸

| 场景 | 规格 |
|------|------|
| 室内 | 专用旗杆，底座稳固，高度≤3米，金色/银色/木质；旗面采用内衬加固成金字塔形 |
| 室内礼仪 | 旗面不可触及地面，距底座≥20-25cm；旗杆上禁止悬挂除旗帜外的任何物品 |
| 室外 | 仅用白色旗杆；旗帜尺寸参照旗杆高度匹配（标准比例表已提供） |

### 半旗规范（7项铁律）

1. **空旗杆**：先升到顶，再缓降至旗杆中间1/3处
2. **已有旗帜的旗杆**：先降至底部，再升至中间1/3处
3. 全国范围内在政府规定的哀悼期内半旗；驻外使领馆接外交部通知后执行
4. 需更换时，缓慢降下并在触地前折叠收纳
5. 与他国国旗同挂时须同时降半旗；若不可行，阿联酋国旗应**最后**降下
6. 降旗仪式中向国旗行军礼（军人/安全人员）；路人须站立致敬
7. 损坏的旗杆应立即降旗，以防国旗落地，直至修复或更换

### 国旗折叠步骤（6步）

1. 纵向对折（高度方向）
2. 再次对折
3. 横向对折（宽度方向）
4. 再次对折
5. 打结固定，不拖地
6. 放入旗帜保存盒

### 日常维护

- 始终保持清洁和熨烫
- 定期更换以保持色彩鲜亮
- 撕破/褪色/损坏须立即更换
- 强风暴或极端天气后检查旗帜状况
- 如无法飘扬自由（缠绕），须调整解困

### 禁止行为与法律责任

**禁止**：
- 在国旗上加任何标志/LOGO（总统旗除外，国徽在白色区域正中）
- 装饰旗边或添加任何额外元素
- 将国旗印在一次性用品上
- 将国旗用于食物（糖果/蛋糕等）
- 改变国旗比例、尺寸或形状以适应特定用途（装饰物、印刷、标志等）
- 以任何方式侮辱、损坏或蔑视国旗

**法律后果**：根据2019年第13号联邦法令第3条

| 违法行为 | 处罚 |
|----------|------|
| 侮辱、损坏阿联酋国旗（联邦国旗、成员酋长国旗、海合会国旗或任何他国国旗） | 监禁**10~25年** + 罚款**≥50万迪拉姆** |
| 性质认定 | 属于**危害国家安全罪** |
