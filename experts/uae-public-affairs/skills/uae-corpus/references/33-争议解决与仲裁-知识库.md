## 争议解决与仲裁（知识库）

*来源：2018年第6号联邦法《仲裁法》（61条，基于UNCITRAL示范法，2018.5.3发布）*

### 仲裁法律框架

阿联酋联邦仲裁法（Federal Law No. 6 of 2018）以**UNCITRAL示范法**为蓝本，是阿联酋仲裁制度的基石，适用于在阿联酋境内进行的所有仲裁和国际商事仲裁。

### 仲裁协议

| 要素 | 规定（条款） |
|------|------------|
| **形式要求**（第7条） | **必须以书面形式**订立，包括电子邮件、电子通信等 |
| **可分性原则**（第6条） | 仲裁条款独立于主合同，主合同终止/无效不影响仲裁条款效力 |
| **主体资格**（第4条） | 自然人须具备处分权能力；不可和解事项不得约定仲裁 |
| **转让**（第4条） | 一方死亡不导致仲裁协议终止，对继承人/受让人继续有效 |
| **类型**（第5条） | 可在争议发生前（仲裁条款）或发生后（仲裁协议）订立 |

### 仲裁程序

| 环节 | 核心规定 |
|------|----------|
| **语言**（第29条） | 默认**阿拉伯语**；双方可约定其他语言（建议约定**英语**） |
| **开庭**（第33条） | 原则上**不公开**（保密），除非双方另有约定 |
| **仲裁庭组庭**（第11-15条） | 当事人自主选任；司法部备有仲裁员名册；可申请法院指定 |
| **管辖权自决**（第16条） | 仲裁庭有权就自身管辖权作出裁定（Competence-Competence） |
| **临时措施**（第17条） | 仲裁庭可下令采取临时/保全措施，包括财产保全 |
| **证据与专家**（第33-35条） | 仲裁庭可指定专家，当事人可申请法院协助取证（第36条） |
| **缺庭裁决**（第32条） | 申请人不在法定期限内提交申诉书的，仲裁庭可终止程序；被申请人未提交答辩的，不视为承认 |
| **裁决时限**（第42条） | 首次开庭后**6个月内**作出终局裁决，可延期最多6个月 |
| **平等对待**（第26条） | 双方享有完全平等的陈述和辩护机会 |

### 仲裁裁决

| 要点 | 规定 |
|------|------|
| **裁决形式**（第41条） | 书面、由多数仲裁员签署、附具理由（除非双方放弃） |
| **法律效力**（第52条） | 裁决具有**既判力**（res judicata），对双方具有约束力 |
| **当事人和解裁决**（第40条） | 双方可在程序中和解，仲裁庭据此作出合意裁决 |
| **裁决解释**（第49条） | 收到裁决后30天内可申请解释 |
| **更正**（第50条） | 收到后30天内可申请更正计算/笔误 |
| **补充裁决**（第51条） | 申请补充遗漏请求，60天内作出 |

### 裁决的异议与撤销

| 环节 | 规定（第53条） |
|------|---------------|
| **撤销之诉** | **唯一救济途径**，不得通过上诉等其他方式挑战 |
| **申请时限**（第54条） | 收到裁决后**30天内** |
| **撤销理由**（第53条，穷尽列举） | (a) 仲裁协议不存在/无效；(b) 一方无行为能力；(c) 缺乏处分权；(d) 未适当通知/未能陈述主张；(e) 裁决超出仲裁协议范围；(f) 仲裁庭组成或程序违反约定/法律；(g) 裁决作出时仲裁时效已过 |
| **法院依职权撤销**（第53.2条） | (a) 争议事项不可仲裁；(b) 裁决违反阿联酋**公共秩序和道德** |
| **终局性**（第54条） | 撤销之诉判决为**终局判决**，仅可向最高法院提起撤销（cassation） |

### 裁决的承认与执行

| 要点 | 规定 |
|------|------|
| **法院批准**（第55条） | 须向**上诉法院**（或其院长）申请批准裁决并颁发执行令 |
| **申请材料** | (a) 裁决原件/认证副本；(b) 仲裁协议副本；(c) 阿语翻译（非阿语裁决）；(d) 法院存档收据 |
| **审批时限**（第55条） | 法院收到申请后**60天**内裁定是否批准执行 |
| **拒绝执行** | 法院仅在发现第53条所列撤销理由时方可拒绝 |
| **暂缓执行**（第56条） | 提起撤销之诉**不自动中止执行**；法院可依申请在15天内决定是否中止 |
| **执行令上诉**（第57条） | 批准/拒绝执行的裁定可在收到后30天内向上诉法院上诉 |

### 仲裁机构对比

| 机构 | 所在地 | 特点 | 适用法律 |
|------|--------|------|----------|
| **DIAC** | 迪拜 | 阿联酋最大仲裁机构，2023年改革 | DIAC规则 |
| **ADCCAC** | 阿布扎比 | 服务阿布扎比商界 | ADCCAC规则 |
| **DIFC法院** | DIFC | 普通法环境、独立司法、**英语审理**、设小额索偿庭 | DIFC法律（普通法） |
| **ADGM法院** | ADGM | 仿英国法院、独立司法、**英语审理** | 英国法直接适用 |
| **ADGM仲裁中心** | ADGM | 世界级设施 | ICC/LCIA/UNCITRAL规则 |

### 国际公约与中国关联

- **纽约公约**：阿联酋1982年加入，外国仲裁裁决可在170+缔约国（含中国）申请承认与执行
- **投资条约仲裁**：中阿BIT（双边投资协定）允许投资者将争端提交ICSID或UNCITRAL仲裁
- **判决互认**：中国与阿联酋**目前无双边司法协助条约**，法院判决互认执行存在重大不确定性

### 📌 对中企的实操意义

1. **仲裁语言必须约定英语**：默认阿拉伯语，务必在合同中明确约定**英语为仲裁语言**
2. **选DIFC或ADGM为仲裁地**：独立司法体系+英语审理+普通法环境，对中企更友好
3. **法院判决≠可执行**：中方判决在阿联酋执行**目前无条约保障**，应优先选择仲裁
4. **30天撤销窗口**：对裁决不服的只能在收到后30天内提起撤销，过期不受理
5. **6个月裁决时限**：仲裁庭须在首次开庭后6个月内作出裁决，复杂案件可延期
6. **裁决无需上诉即可执行**：经法院批准后即为生效执行依据，具有终局性
7. **合规红线**：裁决内容不得违反阿联酋公共秩序和道德（如涉及利息、赌博等伊斯兰教法问题需注意结构设计）
