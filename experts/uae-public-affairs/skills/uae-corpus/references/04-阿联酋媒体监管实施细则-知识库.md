## 阿联酋媒体监管实施细则（知识库）

*来源：2024年第68号内阁决议——2023年第55号联邦法令《媒体监管法》执行条例（16页）*

**注：此细则原由 UAE Media Council 执行，2026年起由新设的国家媒体局（NMA）接替。**

### 媒体许可制度

| 项目 | 规定 |
|------|------|
| 许可证有效期 | **1年**（公历年） |
| 续期申请 | 到期前 **30天** 内 |
| 逾期处理 | 到期后 **90天** 内未续 = 自动注销 + 罚款 |
| 许可转让 | **禁止**转让/出租/变更合伙人，须获主管机构批准 |
| 继承 | 持证人死亡后继承人 **90天** 内通知，凭法院遗产继承判决转移 |

### 许可吊销条件（5种）

1. 持证人申请注销（须缴清所有罚款 + 相关机构无异议）
2. 最终司法判决或行政处罚决定要求注销
3. 持证人死亡且继承人在90天内未提名替代人
4. 到期后90天未续期
5. 其他主管机构决定的情形

### 内容许可制度

| 项目 | 规定 |
|------|------|
| 审批时限 | **15个工作日**内，逾期未决 = **默示拒绝** |
| 审批延期 | 如需征求其他机构意见可延长 |
| 有效期 | 与活动/许可证一致，每份申请一证 |
| 吊销条件 | 未经批准擅自修改已批内容；连续违反内容标准 |

### 广电许可特殊要求

- 须提交：台名/频道名、广播语言、人员经验数据、节目计划
- 须获 **TDRA（电信与数字政府监管局）** 技术频率审批
- 节目内容须保留 **12个月** 完整录音备查
- 播出时段须显示台标
- 紧急/危机情况须遵守主管机构指令

### 外媒驻阿机构

| 条件 | 详情 |
|------|------|
| 办公室主任 | 年龄 **≥25岁**（可豁免），适当学历，母媒体任命函+使馆认证+公证 |
| 记者/通讯员 | 须获年度许可（可续期），由 NMA 统一注册 |
| 人员变更 | 主任及记者变更均须 NMA 事先批准 |

### 外媒记者行为守则

- 报道须**客观、有据可查**
- **禁止**损害国家安全、阿联酋与他国/国际组织关系
- 须遵守媒体内容标准
- 未注册外国记者：须为特定事件/期限申请临时许可，附母媒体机构委托函

### 媒体内容标准（关键禁止项）

| 禁止内容 | 说明 |
|----------|------|
| 政治/种族/经济/意识形态/社会团体美化 | 特别是反国家、破坏性的团体 |
| 违反阿联酋文化、身份、价值观的广告 | 强制要求尊重本地价值 |
| 违反儿童权利 | 须遵守阿联酋现行法律 |
| 年龄分级违规 | 电影、艺术制品须遵守 NMA 年龄分级制度 |

### 广告监管（10条铁律）

1. 广告不得含糊、模棱两可、指示不清
2. 不得含虚假或误导性声明；不得贬低竞争者
3. 不得含假冒/仿制商标、标志或非法使用的图片
4. 广告须真实不夸大，不得与其他产品/活动混淆
5. 不得含有犯罪行为或违反内容标准/年龄分级
6. 广告须**清晰标识身份**，与编辑内容明显区分
7. 付费推广须**明确披露**与产品/服务方的商业关系
8. 须遵守国旗、国徽、国歌使用规范
9. **严禁**直接或间接推广酒精饮料、毒品、烟草/吸烟
10. 以下行业广告须获相关主管部门额外审批：**房地产、医疗/药品、金融证券、教育、食品**

### 影视制作审批

- **剧本预审**：开拍前须提交剧本电子版获 NMA 批准
- **拒绝依据**：违反公共秩序、公共道德、阿联酋传统习俗的剧本可被拒
- 电影展映：须获内容许可，不得在未获许可前列入放映排期或进行宣传

### 摄影许可

- 地面/空中/海上摄影须提前 **15天** 提交申请
- 须明确拍摄目的（电影/新闻/节目/广告/MV/其它）
- 须附拍摄起止日期和详细地点
- 须附剧本/内容批准书

### 违规外国媒体处理机制（3级）

| 级别 | 措施 |
|------|------|
| 1. 外交渠道 | 通过外交渠道联系对应方，要求阻止或屏蔽违规内容 |
| 2. 法律追诉 | 保留对外国媒体的法律追诉权 |
| 3. 内容屏蔽 | 协调国内相关部门阻止该媒体内容到达阿联酋 |

### 上级法律补充（2023年第55号联邦法令，2023.12.1生效）

*注：此法令为上述执行条例的母法，以下为执行条例中未涵盖的关键条款。*

**媒体所有权资格：**
- 自然人：完全民事行为能力 + 良好品行（无重罪/妨害名誉轻罪前科）+ 相关部门批准
- 法人：须按《商业公司法》形式设立，经营范围仅限于媒体活动

**媒体内容标准（16项法定标准，法律层面）：**

| # | 标准 |
|---|------|
| 1 | 尊重造物主、伊斯兰信仰及其他宗教信仰 |
| 2 | 尊重国家统治体系、象征、机构及最高利益 |
| 3 | 尊重国家对内对外政策与方向 |
| 4 | **不得损害国家外交关系** |
| 5 | 尊重国家认同与文化遗产 |
| 6 | 不得传播损害民族团结与社会凝聚力的内容 |
| 7 | 不得煽动暴力、仇恨、恐怖主义，不挑拨宗派/地区/教派纷争 |
| 8 | 不得冒犯社会主流价值观 |
| 9 | 不得诋毁法律/经济/司法/安全体系 |
| 10 | 尊重隐私权与个人私生活 |
| 11 | 不得煽动犯罪、谋杀、强奸或鼓励毒品/精神药物使用 |
| 12 | 不得刊播违反公序良俗的言行、图片或绘画 |
| 13 | 不得传播虚假新闻、伪造文件或不当归属信息 |
| 14 | 不得损害国家货币或经济状况 |
| 15 | 不得散布谣言和误导性新闻 |
| 16 | 执行条例规定的其他标准 |

**行政处罚（法律层级）：**

| 处罚类型 | 量级 |
|----------|------|
| 警告 | — |
| 行政罚款 | **1,000 ~ 1,000,000 AED**；重犯加倍，**最高 2,000,000 AED** |
| 行政停业 | 最长 **6个月**（可续）；无证机构可**永久关闭** |
| 吊销许可/批准 | 取消已颁发的许可证和批准 |

**自贸区监督：** UAE Media Council（现NMA）有权直接对自贸区内媒体机构实施检查监督；自贸区当局须向NMA提交所有许可数据。

**知识产权保护：** 法律明确要求NMA与相关部门协调加强媒体行业知识产权保护。

**历史意义：** 本法令废止了1980年第15号联邦《印刷与出版法》，标志阿联酋媒体监管体系从传统出版管制迈向全媒体（含数字/社交/游戏）综合监管。
