## 企业税收制度（知识库）

*来源：2022年第47号联邦法令《企业与商业税收法》（2023年6月1日或之后财政年度生效，修正至2024年第40号）*

### 税率结构

| 应税收入 | 税率 |
|---------|------|
| ≤ AED **375,000** | **0%** |
| > AED 375,000 | **9%** |
| 大型跨国企业（全球收入≥EUR 7.5亿） | **15%** DMTT（2025年1月1日起） |

### 纳税人分类

| 类型 | 征税范围 | 说明 |
|------|---------|------|
| 居民法人（含自由区） | 全球收入 | 在阿联酋注册或实际管理控制地在阿联酋 |
| 非居民法人 | 常设机构收入 + 阿联酋来源收入 | 无PE则仅就阿联酋来源收入征税 |

### 自由区0%优惠——合格自由区人士

| 收入类型 | 税率 | 条件 |
|---------|------|------|
| 合格收入 | **0%** | 满足充分经济实质 + 合格收入条件 + 公平交易 + 转让定价文档 |
| 非合格收入 | **9%** | 同上（仅在自由区外交易产生） |

⚠️ 任一时点不满足条件 → 从该税务期**开始**丧失资格；优惠最长50年。

### 转让定价

- 关联方交易须符合**公平交易原则**（Arm's Length）
- 关联方定义极宽：≥50%所有权、控制权、四代亲属、PE与总部间
- 向关联人付款仅在实际服务市场价值范围内可抵扣

### ⚠️ 违规处罚

依据《税务程序法》（2017年第7号法令），由联邦税务局（FTA）执行。具体处罚由后续行政决定明确。

### 📌 对中企的关键意义

- 年利润>375,000 AED即须注册并纳税（大陆和自由区均涵盖）
- 任何跨境关联交易须准备转让定价文档
- 自由区企业2023年后必须重新审视是否符合"充分经济实质"条件
- 未注册或不合规申报面临罚款追溯

| 项目 | 详情 |

### REIT投资者税务规则

*来源：FTA澄清公告 CTP005（2025年5月1日）*

REIT（房地产投资信托）作为合格投资基金（QIF）**免征企业税**。投资者税务处理：

| 规则 | 内容 |
|------|------|
| 法人投资者 | REIT在财年结束后**9个月内**分配不动产收入→投资者免征该部分企业税；若未分配→投资者须将该项收入计入应税所得 |
| 自然人投资者 | **不需**将REIT的不动产收入计入个人应税所得 |
| 处置全部权益 | 投资者出售全部REIT权益且未收到分配→仍免征 |
| 税务折旧 | 投资物业的税务折旧调整为**投资者可选**（非强制） |

📌 REIT是阿联酋房地产投资的税收高效工具。

### 经济实质法规（ESR）

*来源：阿联酋财政部ESR通知指南（2020年第100号部长决议，12页）*

#### 谁需要提交通知（Notification）

持有商业执照且从事以下**9种相关活动**的任何法人实体或合伙企业均须提交ESR通知：

| 相关活动 | 英文 |
|----------|------|
| 银行业务 | Banking |
| 保险业务 | Insurance |
| 投资基金管理 | Investment Fund Management |
| 融资租赁 | Lease-Finance |
| 总部业务 | Headquarters |
| 航运业务 | Shipping |
| **控股公司** | Holding Company |
| **知识产权业务** | IP Business |
| **分销与服务中心** | Distribution & Service Centre |

**关键**：以"实质重于形式"原则判断是否从事相关活动——不能仅看执照上写什么，要看实际做了什么。

#### 通知与报告时间线

| 事项 | 期限 |
|------|------|
| **通知（Notification）** | 财年结束后**6个月内**（例如12月31日年结→次年6月30日） |
| **ESR报告** | 仅在有收入且非豁免时需提交 |
| **罚款** | 未提交通知：**AED 20,000**；提交虚假信息：**AED 50,000**；故意虚报可导致**ESR测试不合格** |

#### 豁免实体（5类）

| 豁免类型 | 条件 |
|----------|------|
| 阿联酋国民/居民全资持有 | 非多国集团成员 + 仅在阿联酋运营 |
| 投资基金 | 非自管理基金 |
| 投资基金的SPV/控股实体 | 唯一功能为便利基金投资 |
| 外国税务居民 | 该实体收入在他国缴纳企业所得税 |
| 外国公司阿联酋分支 | 分支机构全部收入在母公司所在国纳税 |

> ⚠️ 豁免实体**仍需提交通知**，但无需提交ESR报告和证明经济实质。

#### 高风险IP企业

若同时满足：(1) 未自行创建所持IP、(2) 从关联方处获得IP或通过资助境外研发获得、(3) 将IP对外许可且未实质性管理——则被认定为**高风险IP企业**，须满足更严格的实质要求。

#### 📌 对中企的实操意义

1. **控股公司是最常见触发场景**：在阿联酋设立控股公司的中企几乎都会被ESR覆盖
2. **通知≠报告**：每个财年结束6个月内先提交通知，有收入且非豁免时才需提交ESR报告
3. **罚则刚性**：AED 20,000-50,000的罚款直接针对流程性违规，不提交比没通过测试更危险
4. **UBO和最终母公司信息须完整**：通知中须披露直接持有25%以上的实益所有人
5. **实质测试是阿联酋企业税0%税率的前提**：自贸区企业享受0%税率的条件之一就是满足充分经济实质

### ESR报告——经济实质测试

*来源：阿联酋财政部ESR报告指南（2020年第100号部长决议，18页）*

**报告截止**：财年结束后**12个月内**（通知是6个月，注意时间差）

**未提交/虚假信息罚款**：各**AED 50,000**，且可被认定为ESR测试不合格

#### 经济实质测试通过必须满足

| 测试维度 | 具体要求 |
|----------|---------|
| **员工** | 在阿联酋拥有足够的**全职等效员工（FTE）**，按每周40小时标准化计算 |
| **支出** | 在阿联酋发生足够的**运营支出** |
| **有形资产** | 在阿联酋持有足够的**有形资产**（不动产/厂房设备/存货/应收款/现金） |
| **CIGA** | **核心创收活动**（Core Income-Generating Activities）必须在阿联酋执行 |
| **董事会** | 董事会会议**实际在阿联酋召开**，法定人数**实际到场** |
| **战略决策** | 战略决策由**实际在阿联酋的**董事做出 |
| **记录保存** | 董事会会议纪要和公司记录**在阿联酋保存** |

#### 外包安排

CIGA可以外包但须满足：外包商雇员和资产**实际在阿联酋**、被许可方**有能力监督**外包商、外包商在阿联酋注册有VAT号码。

#### 高风险IP企业特殊要求

被认定为高风险IP的企业须提供**反驳证据**，证明其在阿联酋拥有足够数量的常驻合格全职员工，对IP资产的开发、利用、维护、增强和保护行使了**高度控制**。仅由非居民董事定期在阿联酋做决策、或由被动持有IP的本地员工执行活动——**不足以**满足测试。
