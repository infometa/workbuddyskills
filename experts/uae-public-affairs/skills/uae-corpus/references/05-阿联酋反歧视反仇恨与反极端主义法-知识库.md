## 阿联酋反歧视、反仇恨与反极端主义法（知识库）

*来源：2023年第34号联邦法令（2023年9月28日颁布，废止2015年第2号联邦法令）*

### 核心定义

| 术语 | 法定定义 |
|------|---------|
| 歧视 | 基于宗教、信仰、教派、种族、肤色、族裔、性别的任何区分、限制、排斥或偏袒 |
| 仇恨言论 | 任何煽动纷争、偏见或歧视的言论或行为 |
| 极端主义 | 宣扬可能破坏公共秩序、亵渎宗教、歧视或仇恨言论的思想/意识形态/价值观的行为 |
| 亵渎宗教 | 冒犯造物主、宗教、先知、圣书或礼拜场所的任何行为 |

**言论自由不可援引为辩护**（第3条明确规定）。

### 犯罪行为与刑事处罚

| 条款 | 罪行 | 刑罚 |
|------|------|------|
| 第5条 | 亵渎宗教（冒犯宗教仪式/圣地/圣书/礼拜场所） | ≥1年监禁 + **25万~100万 AED** |
| 第5条 | 亵渎宗教（冒犯造物主/先知及其家人同伴） | ≥**2年**监禁 + **50万~200万 AED** |
| 第6条 | 制造歧视 | ≥1年监禁 + 50万~100万 AED |
| 第7条 | 煽动仇恨言论 | ≥1年监禁 + 50万~100万 AED |
| 第8条 | 煽动部落/地区偏见 | ≥6个月监禁 + ≥5万 AED |
| 第10条 | 利用宗教指控他人叛教（takfir）谋私利 | 临时监禁 |
| 第10条 | takfir 引发谋杀并实际发生 | **死刑** |
| 第11条 | 制作/进口/销售含歧视仇恨内容的印刷品/音像/软件 | ≥2年监禁 + 50万~200万 AED |
| 第12条 | 持有上述材料（意图传播） | ≥1年监禁 + 5万~20万 AED |
| 第13条 | 建立/组织歧视仇恨团体 | ≥**10年**监禁 |
| 第14条 | 加入上述团体 | ≤7年监禁 |
| 第15条 | 组织此类会议/集会 | ≥5年监禁 |
| 第16条 | 资助此类犯罪 | 监禁 + 25万~100万 AED |

### 加重处罚情形

- 公务员利用职权实施、具有宗教身份者实施、或在**礼拜场所**实施 → 从重处罚
- 若行为导致破坏公共安宁 → **最高5年**监禁 + ≥50万 AED

### 法人责任

法人代表/经理对其雇员以法人名义或为法人利益所犯罪行，承担**同等刑事责任**；法人对罚款和赔偿承担**连带责任**。

### 极端分子管控机制

| 措施 | 说明 |
|------|------|
| 危险评估 | 罪犯显示出信奉极端思想并可能再次犯罪 → 法院可令其进入**辅导中心**（每3个月评估） |
| 预防措施 | 禁止出境、监控、限制居住区域、指定居住地、禁止出入特定场所、禁止接触特定人员 |
| 极端分子名单 | 内阁建立名单；被列名者可**60天内**申诉 → 可向法院上诉；名单**每年**至少审查一次 |
| 组织处置 | 解散相关团体、没收资产/工具/文件、驱逐被定罪外国人 |

### 豁免条款

- 在犯罪实施前主动举报 → **完全豁免**
- 犯罪后举报协助逮捕其他罪犯 → 可豁免或减轻

### 管辖权

- 普通案件：各酋长国法院
- 涉及极端分子名单或极端主义预防措施的案件：**仅阿布扎比联邦法院**管辖

### 历史沿革

本法取代2015年第2号联邦反歧视法，大幅加重刑罚（旧法最高10年，新法增加死刑条款），新增极端分子名单制度和预防性管控措施。
