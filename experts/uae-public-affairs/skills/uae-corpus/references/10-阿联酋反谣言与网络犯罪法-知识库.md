## 阿联酋反谣言与网络犯罪法（知识库）

*来源：2021年第34号联邦法令（废止2012年第5号联邦法令《信息技术犯罪法》）*

### 法律定位

本法是阿联酋网络空间行为的基本刑事法律，共48条，涵盖从黑客攻击到散布谣言的完整网络犯罪链条。与前续媒体监管法不同，本法**直接规定刑事处罚**（监禁+罚款），而非行政罚款。

### 核心罪行与刑罚

| 条款 | 罪行 | 刑罚 |
|------|------|------|
| 第3条 | 入侵政府数据系统 | ≥1年 + ≥**20万**AED；删除/破坏数据 → ≥5年 + ≥25万；涉及国家安全 → ≥**7年** + ≥25万 |
| 第4条 | 未经授权获取/修改政府数据 | ≥1年 + ≥**50万** AED |
| 第7条 | 网络攻击（破坏系统运行） | ≥**7年** + ≥50万；损害国家利益 → ≥**10年** |
| 第8条 | 破坏信息系统 | ≥5年 + ≥50万 AED |
| 第11条 | 伪造电子账户/网站/邮箱 | ≤5年 + ≥20万 AED |
| 第12条 | 恶意入侵网站 | ≤1年 + ≤**100万** AED |
| 第13条 | 侵犯个人隐私（偷拍/窃听/泄露） | ≥1年 + ≥**30万** AED |
| 第17条 | 利用网络侮辱/诽谤 | ≤1年 + ≤**3万** AED |
| 第21条 | **散布谣言/虚假新闻** | ≤5年 + ≥**50万** AED |
| 第24条 | 鼓动不道德行为/传播色情 | ≤5年 + ≥50万 AED |
| 第29条 | 发布危害公共秩序内容 | ≥1年 + ≥50万 AED |
| 第30条 | 创建运营网站进行人口贩卖/非法活动 | ≥**10年** + 10万~**500万** AED |
| 第36条 | 煽动他人犯罪 | ≤**7年** |
| 第40条 | 未经许可募捐/集资 | ≥1年 + ≥25万 AED |
| 第41条 | 发布煽动推翻政权内容 | ≤5年 + ≥25万 AED |
| 第43条 | **网络敲诈/威胁**（威胁犯罪） | ≤**10年**；如威胁实施犯罪更重 |
| 第44条 | 冒用他人身份开设电子账户 | ≥1年 + ≥25万 AED |

### 对企业公共沟通的关键影响

1. **谣言零容忍**：第21条明确规定散布谣言和虚假新闻最高可判5年监禁+50万AED，企业社媒账号分享未经核实的信息即可能触法
2. **网络侮辱罪门槛低**：第17条≤1年+3万AED，线上与他人纠纷可能升级为刑事犯罪
3. **隐私保护严格**：第13条覆盖偷拍、窃听、泄露个人数据，≥1年+30万AED
4. **网络敲诈重罪**：威胁行为本身最高10年，与实际造成后果分离
5. **境外适用**：本法对境外实施的针对阿联酋的犯罪同样适用
6. **公诉专属**：第28条规定网络犯罪案件仅由联邦总检察长提起公诉

### 历史沿革

本法废止了2012年第5号联邦法令《信息技术犯罪法》，大幅加重了几乎所有罪名的刑罚，并将"谣言"（الشائعات）作为独立罪名纳入法律标题，体现了阿联酋对网络虚假信息的高度关注。
