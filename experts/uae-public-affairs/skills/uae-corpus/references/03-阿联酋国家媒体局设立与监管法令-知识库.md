## 阿联酋国家媒体局设立与监管法令（知识库）

*来源：2025年第11号联邦法令《关于设立和监管国家媒体局》（2025年9月30日颁布，2026年1月1日生效）*

### 机构概况

国家媒体局（National Media Authority, NMA）是依据本法令设立的新联邦公共机构，直接对**内阁**负责，具有法人资格、财政和行政独立性。

| 属性 | 详情 |
|------|------|
| 总部 | 阿布扎比，可在国内外设立分支机构 |
| 法律地位 | 独立联邦公共机构 |
| 生效日期 | **2026年1月1日** |
| 颁布日期 | 2025年9月30日（由总统穆罕默德·本·扎耶德签署） |

### 核心整合：一家机构取代三个旧实体

NMA 整合并继承了以下三个机构的**所有权限、权利和义务**（含合同、协议、谅解备忘录）：

| 被取代机构 | 原设立法令 |
|-----------|-----------|
| 阿联酋媒体委员会（UAE Media Council） | 2022年第57号联邦法令 |
| 国家媒体办公室（National Media Office） | 2022年第55号联邦法令 |
| 阿联酋通讯社（WAM） | 2021年第2号内阁决议 |

三机构员工以同等职级、薪酬和福利转移至 NMA，服务期连续计算。

### 23项核心权限（重点摘要）

**战略与监管层面：**
1. 提出国家媒体战略方向，统一联邦与地方各级媒体话语，提交内阁批准
2. 制定媒体领域政策、立法和战略，提升国家声誉，应对媒体危机
3. 提出媒体机构及媒体活动（含**电子媒体和电子出版**）许可法规，**涵盖自贸区**
4. 制定媒体内容标准
5. 监控和分析国内所有印刷、出版、广播媒体内容（**含自贸区**），掌握公众舆论趋势
6. 准备、评估和监测国家媒体叙事，提升正面形象
7. 制定实施媒体危机管理方案，早期检测数字媒体威胁、负面内容和错误信息

**媒体许可与人才管理：**
8. 为相关部门提供媒体事务咨询，提高国家意识
9. 注册和认证国内媒体从业者及**外国媒体驻阿记者**（含自贸区）
10. 发展区域和国际媒体战略伙伴关系
11. 将阿联酋通讯社（WAM）发展为官方新闻传播渠道

**内容与运营层面：**
12. 管理国内外新闻流传输和再分发，维护国家统一
13. 向签约媒体机构和个人提供本地及国际新闻、文章、图片
14. 以阿语、英语等语言处理和编辑新闻
15. 通过全球记者网络收发新闻报道
16. 签约建立全球记者网络和办事处
17. 管理官方访问的媒体代表团
18. 归档本地和国际新闻，销售新闻服务和媒体内容
19. 培训阿联酋国家媒体人才

**外部与国际层面：**
20. 代表国家参加国内外媒体会议和活动
21. 建立综合信息数据库
22. 开展专业研究和风险趋势分析
23. 其他法定权限

### 治理架构

| 职位 | 产生方式 | 职责 |
|------|---------|------|
| 主席（Chairman） | 联邦法令任命 | 最高权力机构，批准政策/架构/预算/委员会 |
| 副主席 | 联邦法令任命 | 主席缺席时代理，可接受书面特别授权 |
| 董事会（Board of Trustees） | 内阁决议任命 | 3-8人，顾问角色，可提交政策/立法建议 |
| 秘书长（Secretary-General） | 联邦法令任命（主席推荐） | 日常执行，对主席负责 |
| 行政机构 | 依人力资源法律任命 | 协助主席和秘书长 |

### 财政

- 资金来源：国家财政拨款 + 捐赠赠与（需主席接受）+ 机构自主收入
- 受阿联酋问责局（UAE Accountability Authority）监督
- 可聘请外部审计师
- 经内阁批准可**设立或参股有限责任公司**

### 对公共事务的关键影响

1. **媒体监管统一化**：原先分散在三机构的职能合一，简化政企对接
2. **自贸区纳入管辖**：NMA 明确有权监管自贸区内媒体活动，此前自贸区媒体相对独立
3. **外国记者认证集中化**：所有境外媒体驻阿记者统一由 NMA 注册认证
4. **媒体内容全覆盖监控**：涵盖印刷、出版、广播、电子媒体与电子出版
5. **危机应对专业化**：NMA 专设数字媒体威胁早期检测与危机管理机制
6. **媒体叙事统一化**：从联邦到地方层面统一媒体话语，企业公共沟通须与此对齐
7. **可设立商业实体**：NMA 可参股企业，或成为媒体行业合作伙伴
