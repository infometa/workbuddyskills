## 竞争法与反垄断（知识库）

*来源：2023年第36号联邦法令《竞争法》（40条，16页，2023.9.28发布，3个月后生效），取代2012年第4号联邦法*

### 法律框架

阿联酋新竞争法引入现代竞争执法体系，核心目标：保护和促进竞争、打击垄断行为、建立自由市场机制。

### 核心禁止行为

#### 1. 限制性协议（第5条）

禁止企业之间达成以**限制、阻止或扭曲竞争**为目的或效果的协议，包括：

| 禁止行为 | 说明 |
|----------|------|
| **固定价格** | 直接或间接确定商品/服务买卖价格 |
| **串通投标** | 在招标、拍卖、标前实践中合谋 |
| **限制产出** | 冻结/限制生产、分销、营销、研发 |
| **划分市场** | 按地理区域、分销中心、客户类型、季节时间段划分 |
| **拒绝交易** | 约定拒绝与特定企业交易、妨碍其进入市场 |
| **限制自由流动** | 阻止商品/服务自由进入市场（囤积、隐匿、拒售） |
| **选择性限制** | 行业监管机构之外的纵向约束协议 |

#### 2. 滥用市场支配地位（第6条）

市场支配地位的认定门槛由内阁决议确定（市场份额 + 对市场造成损害的能力）。

| 禁止行为 | 示例 |
|----------|------|
| **强制转售条件/价格** | 间接或直接对下游施加价格/条件 |
| **掠夺性定价** | 以低于成本价格销售，意图排挤竞争者 |
| **价格/条件歧视** | 同等交易对客户无合理理由区别对待 |
| **排他性交易/拒绝交易** | 强迫客户不与竞争者交易、无理由拒售 |
| **搭售/捆绑** | 以接受无关商品/服务为订立合同的条件 |
| **谣言传播** | 故意散布关于产品或价格的虚假信息 |
| **囤积/短缺** | 人为制造商品过剩或短缺 |
| **技术锁定** | 控制生产流程、市场或技术发展 |
| **设施壁垒** | 阻止/阻碍竞争者使用必要基础设施 |

#### 3. 经济依赖性滥用（第7条）

当客户/供应商**没有合理替代方案**时，企业不得滥用其经济依赖地位。适用场景类似于支配地位滥用的7种行为。

#### 4. 掠夺性定价（第8条）

- **原则禁止**：以低于成本（含制造、运输、营销成本）的价格销售，意图排斥竞争者或阻止市场进入
- **例外**：一般价格促销（符合消费者保护法的）、清算销售

### 并购控制（Economic Concentration）

| 维度 | 要点 |
|------|------|
| **申报门槛**（第12条） | 参与集中企业上一财年在相关市场的**合计年销售额**或**合计市场份额**超过内阁设定阈值的，须在完成集中前**至少90天**申报 |
| **审查期**（第13条） | 自提交完整申请起**90天**（可延期45天），逾期未决定视为批准 |
| **审批决定**（第15条） | (a) 无附加条件批准；(b) 附条件/承诺批准；(c) 否决；(d) 不适用 |
| **Gun-Jumping禁止**（第13条） | 审查期内不得实施集中 |

### 豁免制度（第9–11条）

企业可申请豁免，需证明协议/行为：
- 促进经济发展
- 提高企业绩效和竞争力
- 改进生产或分销体系
- 给消费者带来特定利益
- **不得**完全排除相关市场竞争

豁免申请由部长在收到通知后90天内（可延45天）决定。逾期未决定**视为驳回**。

### 执法机构

| 机构 | 职责 |
|------|------|
| **经济部竞争与消费者保护司** | 政策执行、调查、执法、受理投诉 |
| **竞争法委员会**（新设） | 政策建议、豁免审查、立法提案、年度报告 |
| **酋长国层面主管部门** | 当涉及企业仅在一酋长国内经营且影响不超出酋长国边界时 |
| **行业监管机构** | 有独立竞争规则的行业（如金融、电信），可在转授权下审理 |

### 处罚与法律责任

| 违规类型 | 罚金 |
|----------|------|
| **违反第5-8条**（卡特尔/支配地位滥用） | AED 100,000起，上限为**违法企业上年境内总销售额的10%**；无法计算时AED 500,000–5,000,000 |
| **未经申报实施集中**（第12条） | 总销售额的**2%**起，上限**10%**；无法计算时AED 500,000–5,000,000 |
| **Gun-Jumping**（审查期内实施） | AED 50,000–500,000 |
| **妨碍执法**（官员阻挠调查/提供虚假信息） | AED 50,000–500,000 |
| **违反保密义务**（第19条） | AED 50,000–200,000 |
| **停业**（第29条） | 法院可判令违法企业**停业3-6个月**，并在两家当地日报刊登判决 |
| **民事诉讼**（第30条） | 受害者可就违法行为造成的损害请求赔偿 |
| **刑事责任**（第33条） | 刑事起诉需**部长书面请求**；可在移送法院前和解，支付不低于罚金下限的和解金 |

### 📌 对中企的实操意义

1. **并购申报是硬义务**：达成市场份额/销售额门槛的交易须提前90天向经济部申报，未经批准不得交割
2. **罚款按销售额比例计算**：上限可达年销售额的10%，对大型企业罚款可能极为巨大
3. **域外管辖权**（第3条）：在阿联酋境外发生但**影响阿联酋市场竞争**的行为同样适用本法
4. **纵向协议也受限**：第5条第2款禁止包括独家分销等纵向约束
5. **政府相关实体豁免**（第4条）：联邦和酋长国政府全资拥有的企业可被豁免
6. **消费者保护并行**：掠夺性定价同时可能触发消费者保护法
7. **投诉渠道**（第32条）：任何利害关系方可向经济部或主管部门投诉
8. **大额并购前务必评估**：尤其是市场集中度高的行业（如电信、能源），须事先评估竞争申报的必要性
