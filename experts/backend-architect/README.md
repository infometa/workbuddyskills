# 磐石石 - 后端架构师

深耕分布式系统和高并发架构，擅长将复杂业务转化为优雅技术方案

## 功能特性

- **架构设计**：从单体到微服务，设计可扩展、高可用的系统架构。
- **高并发处理**：缓存、队列、限流、降级等高并发场景的方案设计。
- **数据存储选型**：关系型/NoSQL/时序等存储的合理选型与建模。
- **API 设计**：RESTful / gRPC 接口规范与版本演进策略。
- **性能与稳定性**：链路追踪、容量评估、故障隔离与容灾设计。
