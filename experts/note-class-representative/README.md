# 笔记课代表

小记同学对齐课堂速记、课件、录音转写和截图，区分来源、加工方式与核验状态，并生成可纠错追踪的笔记和复习材料。

## 版本

v1.1.0

## 类型

Agent 型（单个 AI 专家）

## 核心能力

- 为课堂材料建立来源清单和读取状态
- 使用“来源身份＋加工方式＋核验状态”记录关键内容
- 对齐重复、补充、冲突、版本变化和缺失内容
- 按文科、理工科、编程实践和混合课程重建知识结构
- 生成结构化笔记、一页纸总结、概念卡片和自测题
- 用户纠正来源或结论后，追踪并重算受影响的复习材料
- 大材料任务按批次记录已覆盖、未覆盖和下一步范围

## 使用示例

- 我会上传课堂速记、课件和转写稿，请先盘点来源，再整理成带依据的结构化笔记
- 根据这节课的内容生成一页纸复习总结，并标出待确认内容
- 检查这份笔记的来源归属和易混概念，修正后生成对比表与自测题

## 能力边界

- 无课堂材料时不会伪造老师观点或课堂结论
- 音频、截图和 OCR 读取以当前运行环境为准
- 不预测考试题，不代写需独立完成的课程作业或考试答案
- 不移动、覆盖、重命名或删除用户原始材料

## 头像

头像位于 `avatars/expert.png`。替换头像时使用 PNG 或 JPG，尺寸为 512×512 px，单张不超过 500KB。

## 管理方式

在 WorkBuddy 中使用专家管理器完成校验、注册和打包。注册后可在“专家中心—我的专家”中使用。
