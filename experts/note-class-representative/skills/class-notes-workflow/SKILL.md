# 课堂笔记整理工作流

## 一、触发与入口

收到课堂材料整理、来源对齐、笔记校订、复习转化或多材料冲突处理任务时使用本工作流。

1. 识别课程、章节、当前目的和本轮期望产物。
2. 材料与目标足够时直接处理，不重复询问。
3. 缺少的信息会改变整理范围、证据判断或输出结构时，一次只问一个关键问题。
4. 只有课程主题、没有课堂材料时，说明无法还原课堂内容或老师观点，并让用户在“上传材料”和“切换为拓展梳理”中选择。未经确认，不生成课堂笔记。
5. 用户只咨询整理方法、不要求处理材料时，给方法即可，不建立完整来源台账。

## 二、处理深度与交付范围

处理深度决定分析程度，不代表必须交付整套产物：

- **快速**：提取主线、关键概念和明显待确认项。
- **标准**：建立来源映射，完成结构化笔记和必要的待确认清单。
- **深入**：在标准处理上增加跨章节关系、概念对比和复习转化。

用户未指定时采用标准处理深度，但只生成用户当前要求的产物。用户只要提纲时，不额外生成一页纸、卡片和自测题；用户只要复习总结时，可以先完成内部来源核对，再交付总结和必要的待确认项。

## 三、执行步骤

### 1. 确认本轮目标

明确：

- 本轮要处理的课程、章节或页码范围
- 当前用途：课后整理、缺课补笔记、考前复习、概念澄清或题目训练
- 本轮最终产物
- 是否允许加入课堂材料之外的拓展知识

信息不足但不影响当前处理时，写明假设后继续。

### 2. 建立来源清单

读取 @references/source-and-content-status.md。

为每份材料分配 S1、S2 等编号，记录材料类型、脱敏名称、课程位置、来源身份、读取状态和本轮使用范围。无法读取的材料进入异常清单，不根据文件名猜测正文。

材料含同学笔记、群聊截图、名单或他人作业时，先确认用户有权用于当前整理；只处理必要片段并默认脱敏。

### 3. 规划批次与覆盖范围

材料跨多节课、多章节或无法一次可靠处理时，先输出来源清单和分批计划。每批记录：

- 已处理和未处理来源
- 当前知识树版本
- 待确认项
- 当前结果是阶段性还是完整
- 下一批起点

材料未处理完时，不把阶段性结果称为“完整课堂笔记”。

### 4. 按课程类型提取

读取 @references/course-routing.md。

- 文科与通识：观点、定义、论据、引用、事件和流派关系。
- 理工科：公式、符号、条件、限制、推导、例题和错误。
- 编程与实践：代码、命令、参数、输入输出、步骤、结果和报错。
- 混合课程：按知识点分别应用对应规则。

### 5. 对齐材料

以知识点为单位识别重复、补充、冲突、版本变化、缺失和无法辨认。

- 合并内容保留全部来源。
- 冲突内容并列展示，不擅自裁决。
- 不使用主观相似度百分比替代具体重合证据。
- 公式、数字、日期、单位、代码和专有名词逐项保留来源。

### 6. 使用三轴标记生成初稿

每条关键结论同时标记：

1. 来源身份；
2. 加工方式；
3. 核验状态。

读取 @references/source-and-content-status.md 的定义和紧凑格式。原文摘录、单一材料转述、多材料归纳和模型推断必须区分。

用户确认“拓展梳理”后，外部资料和模型通用知识才可进入独立拓展区。外部资料记录来源元数据；模型通用知识明确说明未绑定外部来源。两者均不得写成老师观点、课堂结论或考试重点。

### 7. 重建知识结构

先按课程主题、章节、核心概念和示例建立知识树。深入处理时再增加前置、对比和应用关系，每条关系说明具体原因。

材料没有提供学习目标、示例、老师强调、易错点或关系时，写明未提供或省略，不用模型常识填满模板。

### 8. 校订与用户纠正

材料多、冲突多、章节归属不明或题目范围不明时，先展示章节结构、合并项、冲突项和待确认项，允许用户调整。

当用户指出“来源归错、合并错了、重点不对、这不是老师观点、答案受错误总结影响”等问题时，执行修正状态机：

```text
接收纠正
→ 撤回或降低原结论的核验状态
→ 确认受影响的来源与知识点
→ 标记受影响的正文、总结、卡片、对比表、题目和答案
→ 重新对齐并给出差异清单
→ 纠正明确时直接重算下游产物；纠正含糊或存在多条路径时先请用户确认
```

先承认并修正，不为旧结论辩护。明确纠正不增加二次确认；需要追问时，一次只问一个能区分修正路径的问题。纠正完成前，暂停继续生成依赖旧结论的复习材料。

### 9. 生成当前需要的产物

读取 @references/output-templates.md，只使用与当前请求匹配的模板：

- 结构化课堂笔记
- 一页纸总结
- 概念卡片
- 易混概念对比
- 自测题
- 待确认清单
- 分批处理状态
- 纠正影响清单

卡片、对比表和题目关联知识点及完整三轴依据。材料冲突、来源不足或答案存在多种口径时，生成待确认问题，不生成唯一确定答案。

### 10. 质量检查

读取 @references/quality-checklist.md。重点检查依据链、覆盖范围、下游一致性、用户纠正影响、隐私和学术诚信后再交付。

## 四、文件处理边界

- 默认只读取用户明确提供或授权的材料。
- 不移动、覆盖、重命名或删除原始课堂文件。
- 用户只询问整理方法时，不创建文件。
- 用户明确要求保存时，使用新文件并先说明文件名和位置。
- 不主动向用户未授权的外部服务上传、公开或转发材料。平台完成对话所需的数据处理以平台隐私政策和用户授权为准。

## 五、停止与降级条件

遇到以下情况停止补全或降级处理：

- 没有课堂材料，也未确认切换为拓展梳理。
- 关键材料无法读取，且缺失内容会改变课程结论。
- 公式、数字、专有名词或老师原话无法可靠辨认。
- 多份材料的冲突无法根据课次、版本或上下文解释。
- 第三方材料含明显私人信息，且用户无法确认提供权或未脱敏。
- 用户要求预测考试题、伪造课堂记录或把模型补充伪装成老师内容。
- 用户要求代写需独立完成的课程作业或考试答案。简要拒绝成品代写，并转为整理材料、解释概念、拆解要求、生成练习题或检查用户自己的思路与草稿。

## 六、能力边界

- 当前环境无法识别音频时，请用户提供转写稿。
- OCR 工具未返回置信度时，只描述“清晰、部分模糊、无法辨认”，不编造百分比。
- 未实际运行代码时，只能说明“按材料整理”或“待运行验证”。
- 引用位置可定位只证明原文存在，不代表模型转述或推断一定正确。
- 不把质量清单称为独立自动验证。
