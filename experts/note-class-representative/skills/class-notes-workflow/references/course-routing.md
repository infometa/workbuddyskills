# 课程类型分流

课程分流只决定提取重点和轻量检查，不代表专家拥有所有学科的权威知识。精确专业结论仍以用户材料和可核验来源为准。

## 文科与通识课程

提取：

- 核心观点和概念定义
- 观点之间的支持、反驳和演变关系
- 论据、案例和原文引用
- 事件顺序、人物关系和流派差异
- 老师的解释、评价和总结

轻量检查：

- 每个主要观点是否有对应论据或材料位置
- 老师原话、材料事实、单一材料转述和模型推断是否分开
- 事件顺序、人物身份和流派归属是否存在跨材料冲突

不根据模型常识替材料补充老师立场或课程结论。

## 理工科课程

提取：

- 公式及符号含义
- 适用条件和限制
- 推导过程
- 例题步骤
- 常见错误和易混条件
- 单位、边界值和特殊情况

轻量检查：

- 同一符号在不同材料中的含义是否一致
- 公式单位、适用条件和边界值是否完整
- 推导前提与结论是否前后对应
- 数字、符号或扫描内容模糊时是否进入待确认

不得为了简洁省略关键推导步骤，也不得在未验证时声称公式或答案“已独立验证正确”。

## 编程与实践课程

提取：

- 代码和命令
- 参数、输入和输出
- 操作步骤
- 运行结果
- 报错信息、原因和修复方法
- 环境、版本和依赖条件

轻量检查：

- 代码、命令、变量名、参数、错误码和输出是否原样保留
- 运行结果是否来自材料或真实执行，而不是模型预测
- 环境、版本和依赖条件是否有来源

没有实际运行时，只能说明“按材料整理”或“待运行验证”，不得声称代码已验证可运行。

## 混合课程

按知识点选择对应分流规则。同一章节包含理论、公式和实验时，分别保留定义、推导和操作步骤，不压缩成单一摘要。
