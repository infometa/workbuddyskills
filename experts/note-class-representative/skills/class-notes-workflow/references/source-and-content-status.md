# 来源、加工与核验状态

## 一、来源卡片

为每份材料建立独立来源卡片。

| 字段 | 取值 |
|---|---|
| 来源编号 | S1、S2、S3 |
| 材料类型 | 速记、课件、转写稿、截图、教材、本人笔记、同学笔记 |
| 来源名称 | 课件标题、用户提供的名称或脱敏后的文件别名 |
| 课程位置 | 课次、章节、课件页码、录音时间点、笔记段落或截图区域 |
| 来源身份 | 老师课件、老师讲解、教材、本人笔记、同学笔记、用户补充、外部资料、模型通用知识 |
| 读取状态 | 完整、部分读取、模糊、无法读取 |
| 使用范围 | 本轮使用的课程、章节或页码范围 |

来源身份只描述材料来自哪里，不自动代表内容正确。没有时间码、页码或区域信息时写“位置待确认”，不得补造。

## 二、三轴内容标记

每条关键结论同时记录三个维度，不再用一个“内容状态”混合表达来源、加工和可信程度。

### 1. 来源身份

- 老师课件
- 老师讲解
- 教材
- 本人笔记
- 同学笔记
- 用户补充
- 外部资料
- 模型通用知识

### 2. 加工方式

| 加工方式 | 使用规则 |
|---|---|
| 原文摘录 | 保持原文，使用引用块，不做同义改写 |
| 单一材料转述 | 只依据一份材料改写，保留该来源位置 |
| 多材料归纳 | 由两份或多份材料共同支持，列出全部来源 |
| 模型推断 | 从材料推导出的解释或关系，必须说明推断依据，不能写成老师原话 |

### 3. 核验状态

| 核验状态 | 使用规则 |
|---|---|
| 已定位 | 结论可定位到明确来源位置 |
| 部分支持 | 只有部分表述得到材料支持，列明支持与缺口 |
| 存在冲突 | 来源之间有不可忽略的差异，并列展示 |
| 模糊 | 原文或截图无法可靠辨认 |
| 缺失 | 需要的信息没有出现在已提供材料中 |
| 待确认 | 当前证据不足以确定，说明用户可补充什么 |

推荐紧凑写法：

- 【S1-p8｜老师课件｜单一材料转述｜已定位】
- 【S2-00:12:30；S3-p4｜老师讲解＋本人笔记｜多材料归纳｜部分支持】
- 【无课堂来源｜模型通用知识｜模型推断｜待确认】

最后一种只能出现在独立的拓展区，不得进入“老师强调”“课堂结论”“考试重点”。

## 三、材料对齐状态

| 状态 | 处理方式 |
|---|---|
| 重复 | 折叠重复表达，保留全部来源位置 |
| 补充 | 合并为主内容和补充说明，分别标明来源 |
| 冲突 | 并列展示原始表述、来源、课次和版本 |
| 版本变化 | 按课次、日期或版本保留新旧表述 |
| 缺失 | 标记材料缺口和影响范围 |
| 无法辨认 | 保留原位置并加入待确认清单 |

## 四、来源名称脱敏

- 文件名含姓名、学号、手机号、邮箱、成绩或学生名单标识时，不原样写入产物。
- 使用“本人课堂笔记”“同学笔记 A”“课件第 3 讲”等别名。
- 真实文件路径和文件名只用于当前读取，不进入共享产物。
- 只有身份会改变内容解释且用户确认时，才保留必要身份。

## 五、第三方材料

- 用户提供同学笔记、群聊截图、名单或他人作业时，先确认其有权用于当前整理。
- 只处理与课程内容直接相关的最少片段。
- 默认去除姓名、账号、头像、联系方式、成绩和其他可识别信息。
- 无法确认提供权且材料含明显私人信息时，停止处理，请用户先获得授权或完成脱敏。

## 六、截图位置

截图使用“来源编号＋图号或页码＋区域描述”定位，例如：

- S2｜第 3 张截图｜右上区域｜公式第 2 行
- S3｜课件第 12 页截图｜下半部分红框内

工具未提供坐标或区域编号时，不编造坐标。

## 七、外部资料与模型知识

用户确认进入“拓展梳理”后，才能加入课堂材料之外的知识。

### 外部资料补充

至少记录：

- 作者或机构
- 标题
- URL 或文件名
- 版本、发布日期或更新时间
- 核验日期
- 适用范围与限制

### 模型通用知识

- 标记为“未绑定外部来源，仅用于帮助理解”。
- 不得写成老师观点、课程结论、教材原文或考试重点。
- 对需要精确版本、公式、政策或专业结论的内容，优先请用户提供可信资料或另行核验。

## 八、引用规则

- 原文摘录保持原文并使用引用块。
- 单一材料转述和多材料归纳不使用引号伪装成原话。
- 公式、数字、日期、单位、代码和专有名词逐项保留来源。
- 多来源合并后，每条关键结论仍能定位到具体来源。
- 引用可定位只证明原文存在，不代表模型转述或推断必然正确。
