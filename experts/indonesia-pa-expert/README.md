# Indonesia Public Affairs Expert / 印尼公共事务专家

## 功能简介

本专家专注于印尼公共事务与政府关系（GR）领域，提供以下核心能力：

- **宏观政策与政治地图研判**：解析印尼中央部委与地方政府（Pemda）的政策风向与利益格局
- **利益相关者实操路径**：梳理行业协会（KADIN, APINDO）、媒体集团及社区的利益诉求，输出针对性沟通策略
- **本土文化适配**：将公关与GR理论转化为契合印尼 Musyawarah Mufakat（协商共识）与 Gotong Royong（互助）文化的落地建议
- **危机公关与舆情管理**：应对宗教文化敏感事件、Buzzer（网军）攻击、Ormas 协调等突发场景

## 使用场景

- 中资企业出海印尼的外资准入与牌照申请咨询
- 印尼新法规快速解读与合规风险评估
- 涉及宗教文化的负面舆情危机应对
- 印尼本土政商关系搭建与 CSR 策略制定
- 行业协会对接与地方审批斡旋实操指导

## 前置依赖

### COS 印尼新闻语料库（已内置，无需额外配置）

专家内置了 2015 年印尼新闻语料库的两级索引搜索流程，**无需登录或安装插件即可直接使用**。语料库包含 94,874 篇新闻，来源覆盖 republika.co.id、tribunnews.com、viva.co.id、kompas.com，涵盖国家政策、社会政治与商业经济内容。

使用方式：在对话中提及印尼历史新闻背景、政策事件或商业动态时，专家会自动通过 WebFetch 搜索语料库的导航索引和月度索引。

### pasal-id MCP 工具（可选）

Agent prompt 中提及了 `pasal-id` 工具用于法规检索，但该 MCP 服务**尚未在 plugin.json 中声明为依赖**。如已配置该工具，可调用其获取法规原文；若未配置，专家将退回到使用 WebSearch/WebFetch 检索印尼政府官方网站（.go.id）获取法规信息。

## 推荐对话

1. "我们是一家科技公司，计划进入印尼市场，请帮我们梳理外资准入政策、牌照申请流程，以及需要重点维护的政商关系。"
2. "印尼政府刚刚发布了一项影响我们行业的新法规，请帮我快速解读其核心条款、政策背景以及可能带来的合规风险"
3. "我们在印尼遭遇了涉及宗教文化的负面舆情事件，请帮我制定紧急危机公关方案"
