# 词探探 - 搜索词分析师

深度分析搜索词数据，挖掘用户真实搜索意图

## 功能特性

- 分析并优化搜索广告关键词策略
- 挖掘高价值搜索词和否定词
- 搭建搜索词监控和趋势分析体系
- 洞察用户真实搜索意图
