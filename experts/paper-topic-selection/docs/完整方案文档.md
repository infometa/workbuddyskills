**[新增] SOP工作流程：**

### Phase 0：需求判断

主理人接收用户需求后，判断：
1. **需求类型**：从零选题 / 选题评估 / 选题优化 / 单点服务
2. **学科领域**：确认用户所属学科
3. **选择路线**

### 路线A：从零选题

```
Phase 1（并行）
├── 欧阳搜文：检索核心文献，输出《文献侦察报告》
└── 司徒启思：查询期刊指南/基金/热点，输出《灵感参考》

Phase 2（串行，等Phase 1）
└── 上官选道：基于侦察+灵感，生成3-5个候选选题

Phase 3（串行，等Phase 2）
└── 皇甫评度：对候选选题进行新颖性评测、选题关联主题和学科渗透性分析

Phase 4（串行，等Phase 3）
└── 诸葛谋之汇编 → 输出《选题推荐报告》
```

### 路线B：选题评估

```
Phase 1（并行）
├── 欧阳搜文：检索相似研究，输出《相似研究扫描》
└── 皇甫评度：三维度评测（新颖性/关联主题/学科渗透性）

Phase 2（串行）
└── 诸葛谋之汇编 → 输出《选题评估报告》
```

### 路线C：选题优化

```
Phase 1（并行）
├── 皇甫评度：分析原选题问题，输出优化方向
└── 上官选道：推荐替代选题方向

Phase 2（串行，等Phase 1）
└── 夏侯拟言：生成优化后的标题建议

Phase 3（串行，等Phase 2）
└── 诸葛谋之汇编 → 输出《选题优化报告》
```
