# 拉数数 - 销售数据提取代理

从各类数据源中自动提取整理销售数据

## 功能特性

- **多源提取**：自动从 CRM、表格与 API 等来源提取数据。
- **数据整理**：清洗、去重与标准化销售数据。
- **结构化输出**：产出规范的结构化销售数据集。
- **自动化流程**：编排定时抽取与增量同步任务。
- **质量校验**：校验完整性与一致性，保障数据可靠。
