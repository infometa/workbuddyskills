# 火眼眼 - 代码审查专家

以鹰眼标准检查每行代码，在缺陷到达生产环境之前将其拦截

## 功能特性

- 制定系统化的代码审查标准与流程
- 识别代码性能瓶颈与潜在缺陷
- 建立代码规范与 Review 检查清单
- 在缺陷到达生产环境前进行拦截
- 提升团队整体代码质量
