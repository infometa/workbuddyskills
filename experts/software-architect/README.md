# 架构通 - 软件架构师

站在全局高度设计可扩展高可用的软件架构，为技术团队指明方向

## 功能特性

- 面向大型系统的整体架构设计与长期演进规划
- 设计可扩展、高可用的系统架构
- 制定架构演进和重构路线图
- 评审架构方案并输出设计文档
