# 画面描述铁律（写 `visual` / story_illustration 时必须遵守）

> 来源：figlens `handdraw_story_visual.md`（Pass2 提示词）。这些是决定「出图像不像手绘、会不会画出文字」的关键效果规则，务必逐条照做。写每页 `visual` 时套用；配合 `build-gen-prompt.mjs`（自动加锁画风尾巴）一起出图。

## 1. 只写「看得见的具体物」，禁抽象总结句
`visual` 是一段**完整具体、名词性**的画面描述：该页画什么场景、什么人物、在做什么、什么光线色调——句句是看得见的具体物。
- **严禁**「呈现/表现/传递/展现/突出/体现/营造 …＋ 氛围/基调/精神/世界观/力量/释然/高效/格局/科技感」这类总结句、情绪句、意义句——既画不出来，其中抽象词（"高效""盯屏""科技基调"…）还会被生图模型当**文字**画进画面。
- 情绪/格调只靠**具体可见的手段**传达（暖黄光、人物舒展的姿态、整洁的桌面、逐渐消散的纸堆…）——只写那个「看得见的手段」，不写它「表达/象征了什么」。每句都应能指着画面说「这里画了 X」。

## 2. 完全不提「文字」相关概念
不写标题/字幕/文案/招牌/书页上的字，**也不要写「无文字」「没有文字」**——一个字都别带到文字话题上（生图无反向提示，出现「文字」二字反而诱导它画字）。

## 3. 画风适配转译（避免画面照片化，最常见的画风崩坏来源）
讲稿里**本质是数字/摄影**的内容——电子屏幕、监控/实时画面、电脑或手机 UI、屏幕里的真人照片/证件照、人像比对、进度条、界面截图——若照字面写进画面会逼出**写实照片**，破坏手绘统一感。处理：
1. **换成该画风画得出来的实体**：屏幕上排查嫌疑人 → 墙上一整排该画风的**人形剪影/画像板**；手机里的实时画面 → 人手中举起的一块**画框**，框里是同画风人形；数据/进度 → 具象实物（卷轴、纸张、台灯）。按画风媒介定（纸艺→纸片人形，木刻→刻痕人像，水彩→晕染人像）。
2. **转译出的实物不带字/数字**：牌子/卡片/纸板/画框表面一律不写字不写数字。要表达数量/规模用**具象的多少**（密密麻麻的众多人形、高高一摞纸卡、铺满整墙的画像），不用写数字的标牌。
3. **删写实诱导词**：不出现「截图/实时回传/监控画面/人像比对/进度条/界面/UI/屏幕显示/电子屏」。
4. **本就是实景**（自然的人、物、风景，无屏幕/界面）照常写，不画蛇添足。

## 4. 人物锁进画风（避免画成真人照片脸）
前景大主角若只写写实外貌，生图模型会按「照片先验」把脸画成真人照片（手绘身体+照片脸，极违和）。所以：
- 每个主要人物**明确写成「以该画风/媒介呈现的形象」，面部和身体都是该画风的一部分**：剪纸→「由层叠卡纸剪贴而成的人物纸偶，面部也是纸片」；木刻→「刀刻线条刻出的人物，面孔由刻痕构成」；水彩→「水彩晕染绘成的人物」。固有外貌（警服、发型等）照常写，但套在「该画风人物形象」的壳里。
- 不要把画风提示词整段抄进描述（画风由 `build-gen-prompt.mjs` 统一附加）。

## 5. 角色与场景一致性（跨页最重要）
1. **严禁指代词**：`visual` 里绝不出现「两人 / 他 / 她 / 它 / 他们 / 祖孙俩 / 这只 / 那个」——模型看不到别页，指代=丢主角。每页把出现的角色**指名道姓、完整画出**，同一句里第二次提到也写全。（错：「爷爷和小明并排坐着，两人望向夕阳」；对：「爷爷和小明并排坐着，爷爷和小明一起望向夕阳」）
2. **先定固定设定**：为每个反复出现的角色定一套固定外貌（年龄、发型/发色、脸部特征、**具体服装与颜色**、随身物），全篇同一套，不每页变样。
3. **每页原样重复**：每页对出现的角色**逐字重复其固定外貌**（如「白发白胡子、戴圆框眼镜、穿浅蓝色短袖衫的爷爷」「扎短发、穿绿色背带裤白T恤的小男孩」），啰嗦也写全；场景也用一致的具体描述。
4. 角色/场景只能来自讲稿或图片参考里真实存在的，不凭空捏造。

## 长度
每页 `visual` 约 **40~180 字**，一段连贯描述，含该页每个角色的固定外貌 + 场景 + 动作，不用任何指代词。
