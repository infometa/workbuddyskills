# API Development Expert / API开发专家

> Scaffold, test, document, and debug REST and GraphQL APIs from the command line.

覆盖HTTP接口全生命周期：端点搭建、curl自动化测试、OpenAPI文档生成、Mock服务搭建及HTTP问题调试。

## 核心能力

- **接口搭建** — 基于 Node.js Express 或 Python 标准库快速搭建 RESTful CRUD 端点。
- **接口测试** — Bash / Python 自动化测试脚本，断言状态码与 JSON 结构。
- **接口文档** — 生成并校验 OpenAPI 3.0 规范文档。
- **Mock 服务** — 轻量 Python Mock 服务器，基于路由模式匹配返回示例数据。
- **问题调试** — 使用 curl 定位 CORS、端口占用、JWT 解析、响应时间回归等问题。

## 使用方式

通过 WorkBuddy 专家市场安装后，以下列提示词触发：

- 帮我搭建一个REST API端点并编写测试脚本
- 用curl测试这个接口并分析返回结果
- 为现有接口生成OpenAPI规范文档

## 技术栈

- curl + jq（请求与JSON处理）
- Node.js + Express（REST服务）
- Python 标准库（测试、Mock服务）
- OpenAPI 3.0 / Swagger（接口文档）
- Bash（测试运行器）
