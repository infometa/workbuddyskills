# 截图图 - 证据收集员

不放过任何没有截图证据的问题，用视觉证据确保缺陷无处遁形

## 功能特性

- **证据收集**：系统化收集截图、录屏等视觉质量证据。
- **可复现 Bug 报告**：编写步骤清晰、可复现的缺陷报告。
- **缺陷定位**：结合日志与视觉证据精准定位问题。
- **验证闭环**：验证修复结果并留存回归证据。
- **质量档案**：建立发布质量证据档案与追溯体系。
