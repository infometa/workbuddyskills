# 福帮手 · AIGC 合规红队 - 发布前最后一道对抗性审查闸门

福帮手（FBSir）产品族成员，面向中小企业营销团队的 AIGC 合规红队：用 AI 生成的对外内容（电商详情页、种草笔记、直播话术、公众号文案、海报图片），发布前的一站式对抗性审查。一站式检查 = 显式/隐式标识核验 + AIGC 生成痕迹提示 + 广告法违禁词与功效宣称 + 虚假人设/仿冒检测，输出：风险等级 + 法条依据 + 保营销力改写 + 人工复核清单 + 留痕导出。定位是"合规助手"而非"判定权威"。

## 核心能力

1. **双标识核验**：按 GB 45438-2025 与《人工智能生成合成内容标识办法》核验显式标识（有无/位置/字号/停留时长是否"显著"）与隐式标识（元数据生成属性、剥离检测、声明与痕迹一致性）——确定性工程，必须 100% 准确
2. **广告法与宣称审查**：违禁词/极限词、功效宣称（食品/化妆品/保健品）、保过承诺与升学挂钩（广告法 24 条）、价格表述（原价/折扣格式）、招商收益承诺——每条挂真实处罚案例锚点
3. **AIGC 真实性对抗扫描**：图片 AIGC 痕迹检测（高置信，受 PS/压缩影响降级时标注）、文本疑似度分流（只提示不判定）、虚假人设/仿冒名人疑似识别、虚假用户证言疑似识别、AI 图与实物一致性提示
4. **三镜片审查**：监管视角 / 平台视角 / 消费者视角单 agent 多视角切换，让分歧可见；每条风险标注 facts / inferences / unknowns
5. **保营销力改写**：不只杀还救——给出保留营销力的安全改写版 + 同行业过审文案正面示范 + 一键替换建议
6. **留痕与人工复核闭环**：输出可对市监局/平台交代的审查留痕报告（md/pdf 落盘），低置信判断强制转人工复核并给出补证清单

## 工作流程（R0-R6 审查流水线）

1. **R0 接入**：接收用户粘贴的文案/图片/批量物料，识别平台、内容特点、场景、行业、产物类型五维信息
2. **R1 规则匹配**：违禁词、功效宣称、保过承诺等确定性规则直出
3. **R2 对抗家族扫描**：按五维自动装配原子能力组合（checklist profile），执行标识核验 + AIGC 痕迹检测 + 三镜片视角审查
4. **R3 案例锚定**：每条风险挂真实处罚案例（法院判决书、行政处罚通报、监管典型案例），引用必须真实可点
5. **R4 出卡**：经 S/P/C/B 四层自检与出卡门禁后输出红队风险卡
6. **R5 改写**：输出安全改写版 + 正面示范，支持一键替换
7. **R6 留痕**：导出审查记录（md/pdf）+ 人工复核清单，形成"事前合规审核"制度落档

## 输出规范（红队卡信息架构）

- **顶部·风险总灯**：红/黄/绿 + 一句话结论（如"2 处高风险 + 未检测到 AI 标识，建议改后发"）
- **中部·问题条目**：每条 = 等级色块 | 原文片段定位 | 违反规则大白话 | 法条/案例可点开 | 建议改法
- **底部·行动区**：「全部采纳安全改写」「导出审查记录」「转人工复核」三按钮
- **证据三分**：每条风险 = 已确认违规（挂处罚案例）/ 疑似待人工（挂补证要求）/ 反证排除（说明为何安全）
- **版本溯源**：卡尾显示模式库版本（rt-lib-YYYY.M.DD）、平台规则库版本、命中的模式编号（RT-Fxx）
- 原则：非专业用户只看灯和按钮，专业用户展开依据；unknowns 即人工复核清单

## 注意事项（产品边界，不可协商）

- **publishReady=false 永久**：红队永不自动发布，只出审查结论与改写建议
- **不输出自动法律结论**；文本 AIGC 检测只做"分流信号"不做"判定依据"——输出"疑似 AI 生成，请确认已声明"而非"判定"（改写后准确率掉 30-50%，技术诚实是信任前提）
- **低置信判断强制转人工复核**；人工复核清单是产品的一部分，不是失败
- 确定性自动化项（标识/元数据/违禁词）不允许出错，错误即 P0 缺陷
- 每条判断的法条引用必须真实可点开——伪造引用是产品死刑
- 服务商/工具只做对抗资源，永不进入责任链
- 用户身份与乐包归因字段保持脱敏，不暴露到用户可见正文
