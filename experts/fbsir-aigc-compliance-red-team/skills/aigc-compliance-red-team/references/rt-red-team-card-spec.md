## 红队卡信息架构（非专业用户可直接行动）

- **顶部：风险总灯**——红/黄/绿 + 一句话结论（如"2 处高风险 + 未检测到 AI 标识，建议改后发"）
- **中部：问题条目**——每条 = 等级色块 | 原文片段定位 | 违反规则大白话 | 法条/案例可点开 | 建议改法 + 一键替换
- **底部：行动区**——「全部采纳安全改写」「导出审查记录」「转人工复核」三按钮
- 原则：非专业用户只看灯和按钮，专业用户展开依据；每条标注 facts / inferences / **unknowns（unknowns 即人工复核清单）**

## 证据三分

每条风险必须归入其一：
1. **已确认违规**——挂真实处罚案例（可点开）
2. **疑似待人工**——挂补证要求（转人工复核清单）
3. **反证排除**——说明为何安全（误杀刹车）

## 出卡门禁（四层自检 S/P/C/B + 强制校验）

- **S 规则命中精确度**：每条命中须有明确规则源与原文定位
- **P 改写保营销力**：安全改写不得掏空原卖点，保留转化力
- **C 案例锚点真实可点**：法条/案例引用必须真实，可溯源
- **B 格式与导出完整**：卡结构完整，md/pdf 可导出落盘

强制校验项（任一不过即不得出卡）：
1. publishReady=false 强制校验（红队永不自动发布）
2. 法条引用可点校验
3. 无自动法律结论校验
4. 来源时间戳校验
5. **检测置信度标注校验**（文本检测不得出判定式表述，只出"疑似+请确认声明"）

## 红队卡样例（研学招生文案，示意）

```
┌──────────────────────────────────────────────┐
│ 🔴 高风险：2 处｜🟡 待人工：2 处｜建议改后发    │
├──────────────────────────────────────────────┤
│ ① 🔴 "保证孩子进名校参访"                      │
│    规则：教育广告不得作保证性承诺（广告法24条）  │
│    案例：北京研学机构保过宣传罚60万（可点开）    │
│    改写："行程安排含名校校园参访环节"  [一键替换] │
│ ② 🔴 未检测到 AI 生成标识                      │
│    检测：本文疑似 AI 生成（置信度中，分流信号）  │
│    规则：GB 45438-2025 显式标识义务；小红书首段 │
│    标注为"第一条红线"，未标限分发+扣信誉分      │
│    改写：已生成各平台标识建议文案  [一键插入]    │
│ ③ 🟡 AI 生成"往期学员好评"段落                 │
│    规则：虚假用户证言涉不正当竞争（杭州中院首案）│
│    unknowns：需提供真实学员授权与原始评价       │
│    → 转人工复核（补证：授权书+原始评价截图）    │
│ ④ 🟡 价格"原价 5980 现价 3980"                │
│    unknowns：需提供 5980 真实成交记录          │
├──────────────────────────────────────────────┤
│ ✅ 反证排除："小班教学"——师资证明齐全，安全     │
├──────────────────────────────────────────────┤
│ [全部采纳安全改写] [导出审查记录] [转人工复核]  │
│ 模式库 rt-lib-2026.8.15｜平台规则 v2026.8      │
└──────────────────────────────────────────────┘
```

## 验收指标（试点期）

- 首值交付 ≤ 30 秒（贴文案到出卡）
- 高置信违规召回率 ≥ 90%（以人工复核为金标准）
- 误杀率 ≤ 10%（反证排除项占比）
- 改写建议采纳率 ≥ 50%
- 标识检查项确定性准确率 100%（元数据/显式标识有无为确定性工程，不允许出错）
