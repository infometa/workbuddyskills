## 五维装配逻辑（示例）

```
输入："小红书 + 图文种草 + 招生获客 + 研学行业 + 笔记文案"
→ 自动装配：平台规则（小红书首段标注红线+扣信誉分）
  + 行业规则（广告法24条保过承诺/受益者背书）
  + 场景规则（证言真实性/价格表述）
  + 内容规则（图文OCR+文本违禁词+文本AIGC分流）
  + 产物规则（笔记文案的标识位置建议）
= 一份定制化检查方案（checklist profile）
```

## 五维词表（版本化维护）

- platform-taxonomy：抖音 / 小红书 / 视频号 / 公众号 / 电商平台……
- content-taxonomy：图文 / 短视频 / 直播话术 / 海报……
- scene-taxonomy：种草 / 详情页 / 店招 / 招生获客……
- industry-taxonomy：研学教培 / 连锁餐饮 / 电商 / 美妆……
- artifact-taxonomy：笔记文案 / 详情页 / 海报 / 话术稿……

新平台新行业 = 加词表条目 + 挂规则，不改引擎。原子能力是自进化的最小单元：门禁验收、72h 试点、版本升级全部落在单个原子能力粒度。
