# frontend-slides

HTML 幻灯片制作专家 —— 创建零依赖、动画丰富的网页演示文稿。

## 能力概览

- **从零创建**：结构化提问（用途 / 长度 / 内容 / 密度）后生成单文件 HTML 幻灯片。
- **PPT 转换**：指导用户提供 PPTX 文本大纲，转为风格化的网页幻灯片。
- **已有幻灯片增强**：读取现有 HTML 演示文稿，按密度上限拆分或增补内容后再交付。
- **视觉风格探索**：生成 3 套真实首屏 HTML 预览，让用户"看见"而非"描述"设计偏好。
- **固定 16:9 舞台**：1920×1080 画布整体等比缩放，手机端不重排内容。
- **独特美学**：拒绝"AI slop"，选用独特字体与坚定配色，编排开场动画与微交互。
- **部署与导出**：引导用户通过 Vercel/Netlify 部署获取跨设备链接，或通过浏览器打印为 PDF。

## 使用方式

通过 WorkBuddy / CodeBuddy 加载本插件后，使用以下任一快捷提示即可：

- 帮我制作一个 HTML 网页演示文稿
- 把这份 PPTX 转换成网页幻灯片
- 生成三套风格预览供我挑选

## 技术要点

- 单一自包含 HTML 文件，全部 CSS/JS 内联。
- 固定 1920×1080 舞台 + 等比缩放方案，用 `.active`/`.visible` 控制显隐。
- 字体取自 Fontshare / Google Fonts，支持 `prefers-reduced-motion`。
- 支持键盘、空格、触屏导航与内联文本编辑。

## 外部依赖说明

专家本身零外部依赖，核心产出为自包含 HTML 文件。以下可选功能需外部工具：
- **PPT 转换**：需用户手动提取 PPTX 文本内容（PowerPoint"导出 > 创建讲义"），或自行安装 python-pptx 库运行提取脚本。
- **PDF 导出**：需浏览器打印功能（Ctrl/Cmd+P），或安装 Playwright/Chrome 实现批量导出。
- **在线部署**：推荐 Vercel CLI、Netlify CLI 或 GitHub Pages。
