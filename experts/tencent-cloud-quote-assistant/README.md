# 腾讯云报价助手

面向腾讯云销售和方案场景的产品咨询、选型与报价助手。它可以把自然语言、已有报价和采购清单收敛为可验证的产品事实、部署位置和实时正式价格，并交付适合继续确认或对外使用的结果。

## 我能帮你做什么

### 产品咨询与选型

不确定应该选什么产品、版本或计费方式时，可以直接问我：

- “Redis 标准架构和集群架构怎么选？”
- “CVM 和 Lighthouse 分别适合什么场景？”
- “MySQL 双节点和一主一从有什么区别？”
- “这个产品覆盖哪些部署地域？”

我会基于已验证的产品资料说明能力边界、适用场景、计费模型和选择条件。明确要求价格区间、预算量级或低中高代表配置时，也可以提供带假设的代表价格样本；这类样本不等于最终报价。

### 正式询价与价格比较

确定产品或采购目标后，可以查询实时刊例价：

- “CVM 4核8G 广州包年包月一年多少钱？”
- “对比 CVM 4核8G 在广州和上海购买一年的刊例价。”
- “帮我核对这份已有报价。”
- “GPU、CVM 或 BM 的不同整机规格分别多少钱？”

支持单一配置、多套独立方案、同一购买对象下的受控比较和已有报价复核。只有购买口径可比时才会比较价格；不同产品或不同购买基础不会被拼成虚假的共同总价。

### 批量采购报价

上传 Excel、CSV、Markdown 表格、图片、扫描件、PDF 或文本采购清单后，我会：

1. 封存来源并确认全局站点等采购口径。
2. 逐行复核产品身份、配置、数量、周期和待确认项。
3. 确认后按产品调度正式询价，并保留可恢复的执行进度。
4. 交付统一的结果 JSON/Excel；长任务完成时可按运行环境发送提醒。

第一轮不会把未经确认的原始清单直接当成报价请求。需要修订时，可在确认和执行过程中继续说明要修改的行或条件。

### 友商 Mapping 与折扣推荐

- 提供友商产品、规格、账单、BOM 或报价文件时，可以先映射为腾讯云产品和待确认业务事实，再决定继续正式询价或批量处理。
- 已有正式报价、已有报价文本或单份候选报价表格时，可以请求折扣推荐、折后试算、目标价/预算报价或官网优惠查询。

Mapping 本身不产生正式价格；折扣建议、官网优惠和用户已有报价也不替代当前正式刊例价。合同专属价格、人工承诺和未经核验的历史价格不会作为正式报价交付。

```text
对比 CVM 4核8G 在广州和上海购买一年的刊例价

把这份阿里云账单映射成腾讯云产品后继续询价
为这份报价推荐折扣，并试算折后价格
```

## 多轮协作

同一会话中可以继续补充、修订或查询进度，例如：

- “第 3 行地域改成上海。”
- “这份确认表跳过待决项后继续询价。”
- “查看当前批量报价的进度。”
- “把刚才的正式报价按 8 折试算。”

活动中的批量、Mapping 或折扣任务会沿用各自已确认的上下文；新的需求会在不改变既有事实的前提下进入相应阶段。

## 关于价格准确性

- 每一个正式金额都来自当前受控询价链路，不使用网页抓取、历史缓存或模型记忆替代。
- 产品文档、SKU 快照、代表价格样本和用户提供的金额只能作为咨询、定位或核对线索，不能替代正式价格。
- 对用户确认的站点、地域、可用区、规格、计费模式、数量和周期会严格保留；需要默认、自动补全或回退时会按结果披露。
- 查不到价格或当前配置不具备正式价格时会如实说明，不会编造金额。

> ⚠️ 输出的是刊例价（目录价）或明确标注的折扣建议/试算，实际成交价以合同折扣和商务流程为准。

## 反馈与支持

- 产品资料、正式价格、配置或交付结果问题：反馈给腾讯云报价助手维护团队。
- Mapping、折扣推荐或官网优惠问题：附上当前对话中的用户可见结果和复现条件反馈；不要提供内部路径、会话 ID 或凭证。
