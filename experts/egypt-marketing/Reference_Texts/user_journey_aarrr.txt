## 一、AARRR 海盗模型全景

```
          Acquisition (获客)
               ↓
          Activation (激活)
               ↓
          Retention (留存)
               ↓
          Revenue (变现)
               ↓
          Referral (传播) → 回到 Acquisition (病毒循环)
```

### 1.1 每个阶段的北极星指标

| 阶段 | 北极星指标 | 二级指标 |
|------|----------|---------|
| 获客 | CAC, 渠道来源占比 | CPM, CPC, CTR, 注册量 |
| 激活 | 激活率, Time-to-Aha | 引导完成率, 首单率 |
| 留存 | D30 留存率, 复购率 | D1/D7 留存, 流失率 |
| 变现 | LTV, ARPU, ROAS | AOV, 毛利率, 付费率 |
| 传播 | K 因子, NPS | 推荐率, 社媒提及量 |

## 三、激活 — 让用户"啊哈"的那一下

### 3.1 激活的定义

激活 ≠ 注册。激活 = 用户第一次体验到核心价值。
- Facebook: 7 天内加 10 个好友
- Twitter: 关注 30 个人
- Dropbox: 上传第一个文件
- 电商: 收到第一单 (第一次满意收货)

### 3.2 激活漏斗诊断

```
访客 100%
  ↓ 流失 (加载慢/第一眼不匹配)
落地页停留 70%
  ↓ 流失 (没找到想要的/不信任)
浏览商品 40%
  ↓ 流失 (价格/评价/犹豫)
加入购物车 15%
  ↓ 流失 (运费/支付方式/注册流程)
完成购买 5%
```

诊断方法: 找漏斗最大流失点 → 专注优化那一层

### 3.3 激活加速器

- 新手引导: ≤3 步，每步一个核心动作
- 进度条: "已完成 1/3 步" > 不显示进度
- 即时价值: 注册后立刻展示个性化推荐 ("为你精选")
- 社交登录: 一键 Google/Facebook 登录 → 注册率 +30%
- 首单优惠: 注册即送 10% off → 首单转化率 +50%
- 信任建立: 首屏展示退货政策/安全认证/真实评价

## 四、留存 — 增长的一切基础

### 4.1 留存曲线类型

| 类型 | D30 留存 | 说明 | 产品例子 |
|------|---------|------|---------|
| 微笑曲线 | > 60% | 越用越离不开 | 微信/WhatsApp |
| 平坦曲线 | 20-40% | 稳定使用 | 电商/外卖 |
| 陡降曲线 | < 10% | 一次性/低频 | 婚礼/家具/旅游 |

### 4.2 留存驱动力

1. 习惯养成: 触发器 + 行动 + 奖励 → 循环
2. 沉没成本: 用户投入越多 (数据/内容/关系) → 越离不开
3. 新鲜感: 持续更新 (内容/功能/活动) → 防止倦怠
4. 社交绑定: 好友在用 → 你也在用
5. 提醒召回: Push/邮件/SMS 精准触达

### 4.3 召回策略

| 时机 | 内容 | 渠道 |
|------|------|------|
| 3 天未访问 | "想你了，有新东西" | Push |
| 7 天未访问 | 个性化推荐 + 优惠券 | Push + 邮件 |
| 14 天未访问 | 大力度优惠 + 社会证明 | SMS + 邮件 |
| 30 天未访问 | "你的账号即将..." (损失厌恶) | 邮件 |
| 60 天未访问 | 最后尝试 / 标记流失 | 邮件 |

## 五、变现 — 从"用"到"买"

### 5.1 变现模式

| 模式 | 例子 | 适合 |
|------|------|------|
| 一次性购买 | 电子产品、家具 | 低频高价 |
| 订阅制 | SaaS、会员、Box | 高频持续 |
| 交易抽成 | 平台、Marketplace | 双边市场 |
| 增值服务 | Freemium 升级 | 基础免费 |
| 广告变现 | 内容/社媒平台 | 流量型 |

### 5.2 提升客单价 (AOV) 战术

- 交叉销售: "买了 X 的人也买了 Y" → +15%
- 向上销售: "升级到 Pro 版只需加 ¥XX" → +20%
- 满减/包邮: "再加 ¥50 免运费" → 客单价 +30%
- 套餐捆绑: "A+B = 省 20%" → 客单价 +40%
- 限时加购: "再加 ¥9.9 换购...仅限本单" → +10%

### 5.3 定价策略决策树

```
你的产品是？
├─ 标准化商品 → 成本加成定价 + 市场对标
├─ 差异化产品 → 价值定价 (用户愿意付多少？)
├─ 平台/服务 → 交易抽成 / 订阅
└─ 内容/IP → 广告 + 增值 + 授权
```

## 六、传播 — 让用户帮你增长

### 6.1 病毒传播的 K 因子

K = 邀请发送量 × 邀请转化率
- K > 1: 每个用户带来 > 1 个新用户 → 指数增长
- K = 0.5-1: 稳定增长
- K < 0.5: 需要付费渠道补充

### 6.2 推荐机制设计

| 类型 | 激励谁 | 例子 |
|------|--------|------|
| 双边奖励 | 推荐人+被推荐人 | "邀请好友各得 ¥50" |
| 单边奖励 | 仅推荐人 | "邀请好友获积分" |
| 非货币激励 | 社交货币 | 独占功能/勋章/排名 |
| 自然传播 | 产品本身 | 好的体验 → 自发推荐 |

### 6.3 口碑触发器

- 使用场景: "你在用什么拍照？" → 人像模式
- 结果可见: "你怎么瘦的？" → 健身 App
- 社交需求: "这个群怎么加？" → 群聊功能
- 身份表达: "你这包哪买的？" → 品牌

### 6.4 埃及市场传播特点

- WhatsApp 转发: 埃及人最自然的传播行为
- 家族/邻里: 社交圈以家庭和社区为中心 → 口碑传播效率极高
- 炫耀型消费: 中产阶级有强烈的社交展示需求 → 设计"值得晒"的体验
- 幽默内容传播: 埃及人热爱幽默 → 有趣的 Campaign 自带传播力

## 七、全渠道触点地图 (User Journey Map)

### 7.1 典型电商用户旅程

```
意识阶段:
  看到 FB/TikTok 广告 → 刷到 KOL 推荐 → 朋友在 WhatsApp 提到

考虑阶段:
  搜索产品名 → 看评价 → 比价格 → 逛竞品 → 加购物车

决策阶段:
  看退货政策 → 算运费 → 选支付方式 → 犹豫...

购买阶段:
  下单 → 收到确认 (WhatsApp/SMS) → 等包裹

体验阶段:
  拆箱 (Unboxing) → 产品体验 → 是否满意

后续阶段:
  好评/晒单 → 复购/推荐 → 或退货/投诉
```

### 7.2 触点清单

| 触点 | 重要性 | 优化重点 |
|------|--------|---------|
| 广告素材 | ⭐⭐⭐⭐⭐ | 3 秒钩子 + 埃及方言 |
| 落地页 | ⭐⭐⭐⭐⭐ | 加载 < 2s + 信任要素 |
| 商品页 | ⭐⭐⭐⭐ | 真实评价 + COD 标识 |
| 购物车 | ⭐⭐⭐⭐ | 运费透明 + 紧急感 |
| 支付页 | ⭐⭐⭐⭐⭐ | 多种支付 + 安全感 |
| 确认通知 | ⭐⭐⭐ | WhatsApp + SMS 双通道 |
| 物流追踪 | ⭐⭐⭐⭐ | 实时更新 |
| 拆箱体验 | ⭐⭐⭐⭐⭐ | 品牌感 + 小惊喜 |
| 客服 | ⭐⭐⭐⭐ | 阿拉伯语 + 快 |
| 复购提醒 | ⭐⭐⭐ | 个性化 + 时机 |
