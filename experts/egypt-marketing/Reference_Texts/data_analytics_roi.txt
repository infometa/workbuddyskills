## 一、核心指标体系

### 1.1 获客端 (Acquisition)

| 指标 | 公式 | 基准 (电商) | 说明 |
|------|------|------------|------|
| CAC | 营销总支出/新客户数 | < LTV/3 | 获客成本 |
| CPM | 广告费/千次展示 | $2-8 (埃及 FB) | 展示成本 |
| CPC | 广告费/点击数 | $0.05-0.30 (埃及) | 点击成本 |
| CTR | 点击数/展示数 | 1-3% (社媒) | 点击率 |
| CVR | 转化数/点击数 | 2-5% (电商) | 转化率 |
| CPA | 广告费/转化数 | < 客单价×30% | 单次获客成本 |

### 1.2 激活端 (Activation)

| 指标 | 公式 | 基准 | 说明 |
|------|------|------|------|
| 注册转化率 | 注册数/访客数 | 5-15% | 落地页→注册 |
| 首单转化率 | 首单数/注册数 | 10-30% | 注册→首次购买 |
| 激活时间 | 注册到首次关键行为 | < 24h 最佳 | Ah-Ha Moment |
| 引导完成率 | 完成引导/开始引导 | > 70% | Onboarding |

### 1.3 留存端 (Retention)

| 指标 | 公式 | 基准 | 说明 |
|------|------|------|------|
| D1/D7/D30 留存 | 第 N 天回归用户/总用户 | 40%/20%/10% | 日/周/月留存 |
| 流失率 | 流失用户/期初用户 | < 5% (月) | Churn Rate |
| 复购率 | 重复购买用户/总购买用户 | 20-40% | Repeat Purchase |
| NPS | 推荐者%-贬损者% | > 30 良好 | 净推荐值 |

### 1.4 变现端 (Revenue)

| 指标 | 公式 | 基准 | 说明 |
|------|------|------|------|
| LTV | 平均客单价 × 购买频次 × 生命周期 | > CAC×3 | 客户终身价值 |
| ARPU | 总收入/总用户数 | — | 每用户平均收入 |
| AOV | 总收入/订单数 | — | 平均客单价 |
| ROAS | 广告收入/广告支出 | > 3 (电商) | 广告支出回报率 |
| ROMI | (收入-营销成本)/营销成本 | > 100% | 营销投资回报率 |

### 1.5 传播端 (Referral)

| 指标 | 公式 | 基准 | 说明 |
|------|------|------|------|
| K 因子 | 邀请数 × 转化率 | > 1 = 病毒增长 | 病毒系数 |
| 推荐率 | 推荐用户/总用户 | > 10% | 自发传播 |
| NPS | 见上 | 见上 | 口碑代理 |

## 二、渠道效率矩阵

### 2.1 各渠道典型 CAC (埃及市场参考)

| 渠道 | 典型 CAC | LTV:CAC | 适用品类 |
|------|----------|---------|---------|
| Facebook 广告 | $2-8 | 3-5x | 大众消费品 |
| Instagram 广告 | $3-10 | 2-4x | 时尚/美妆/生活方式 |
| TikTok 广告 | $1-5 | 2-3x | 年轻消费品 |
| Google 搜索 | $5-15 | 3-6x | 高意图品类 |
| KOL 合作 | $3-20 | 1.5-3x | 信任型品类 |
| WhatsApp 私域 | $0.5-2 | 5-10x | 复购/服务型 |
| SEO/内容 | $1-3 | 8-15x | 长期品牌建设 |

### 2.2 归因模型

- 末次点击归因: 给最后一个触点 100% 功劳（默认但偏颇）
- 首次点击归因: 给第一个触点 100% 功劳（品牌认知维度）
- 线性归因: 平均分配（中庸）
- 时间衰减: 越靠近转化权重越大（推荐，平衡版）
- 数据驱动: 算法分配（最准确，需足够数据）

建议: 同时看首次+末次，交叉验证

## 三、A/B 测试框架

### 3.1 测试优先级 (按 ROI 从高到低)

1. 价格/优惠 → 最高影响
2. 标题/文案钩子 → CTR ±30%
3. CTA 按钮 (颜色/文案/位置) → CVR ±15%
4. 落地页布局 → CVR ±20%
5. 图片/视频 → CTR ±10%
6. 表单字段数量 → 提交率 ±25%

### 3.2 A/B 测试 SOP

```
阶段 1: 假设
"将 CTA 从'了解更多'改为'立即领取'，预计 CVR 提升 10%"

阶段 2: 样本量计算
需要多少流量才能置信？→ 在线计算器或工具
典型: 每版本至少 1,000 次展示，100 次转化

阶段 3: 运行
- 只改一个变量 (否则无法归因)
- 随机分流 50/50
- 运行至少 1-2 个完整商业周期 (避免周末偏差)

阶段 4: 解读
- 统计显著性 p < 0.05
- 置信区间不重叠
- 警惕: 显著性 ≠ 商业意义 (0.1% 提升可能没价值)

阶段 5: 行动
- 胜出版本全量上线
- 将洞察写入知识库
- 基于学习设计下一轮测试
```

### 3.3 常见 A/B 测试清单

- [ ] 标题: 问题型 vs 陈述型 vs 数字型
- [ ] CTA: "立即购买" vs "加入购物车" vs "了解更多"
- [ ] CTA 颜色: 橙色 vs 绿色 vs 蓝色
- [ ] 价格呈现: ¥99 vs ¥99/月 vs 每天 ¥3.3
- [ ] 紧迫感: 有倒计时 vs 无倒计时
- [ ] 社会证明: 显示"XX 人已购买" vs 不显示
- [ ] 图片: 产品图 vs 场景图 vs 人物图
- [ ] 表单: 3 字段 vs 5 字段 vs 分步表单

## 四、ROI 评估决策树

```
是否可测量？ → 否 → 品牌类 Campaign (NPS/Brand Lift)
    ↓ 是
CAC < LTV/3？ → 否 → 停止/优化
    ↓ 是
ROAS > 3？ → 否 → 检查创意/定向/落地页
    ↓ 是
有规模空间？ → 否 → 维持预算
    ↓ 是
→ 加预算，规模化！
```

## 五、埃及特殊考量

- COD 影响 LTV 计算：COD 拒收率 15-25% → 实际收入 = 订单额 × (1-拒收率)
- 埃及镑波动: 预算和 ROI 最好按 USD 基准计算
- 支付延迟: COD 回款周期 7-14 天 → 现金流模型需调整
- 归因困难: WhatsApp 下单无法追踪 → 用专属折扣码/链接
- 数据质量: GA4/Facebook Pixel 在部分埃及网络不稳定 → 建议多渠道交叉验证
- 隐私: 埃及数据保护法在制定中 → 留出合规空间
