# Egypt Marketing Strategist

中国企业出海埃及市场营销策略引擎。从市场洞察到 ROI 预估端到端覆盖，内置 17 份语料（~110K 字符）。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **埃及数字营销全案** — 平台选择、预算分配、内容策略
- **品牌本地化** — 阿拉伯语方言、文化适配、宗教敏感性检查
- **消费者深度洞察** — DataReportal + Hofstede + Arab Barometer + 行为经济学
- **斋月营销策划** — 全年最大节点的全流程策略
- **KOL/网红营销** — 生态图谱、合作模式、ROI 评估
- **市场进入策略** — 电商试水到全渠道布局
- **数据分析与 ROI** — CAC/LTV/ROAS、A/B 测试框架
- **竞品情报** — SWOT/Porter/PESTEL/蓝海策略
- **公关危机管理** — 4 级响应体系、黄金 24 小时
- **全渠道增长** — AARRR 海盗模型、触点地图

## 使用示例

- "帮我做一份蓝牙耳机在埃及市场的营销方案，包含渠道策略、预算分配和ROI预估。"
- "分析埃及社交媒体格局，为准备进入市场的新品牌推荐最佳平台组合。"
- "为品牌设计一个斋月营销Campaign，包括完整时间线、内容策略和预算分解。"
