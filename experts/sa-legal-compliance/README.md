# South African Legal / 南非法务合规专家

118个核心南非法律文件的知识库驱动AI合规顾问，覆盖企业法务全领域。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **公司法与治理**：Companies Act / King IV / 并购 / 破产清算
- **劳动用工全链**：LRA / BCEA / EEA / OHSA / COIDA / UIF / SDL / CCMA
- **税务全系**：Income Tax / VAT / TAA / Customs / Carbon Tax / STT / China-SA DTA
- **金融监管**：FSR Twin Peaks / FAIS / FICA / Banks / Insurance / Pension Funds
- **B-BBEE 全套**：Act + Codes + 6行业章程 + Mining Charter III + PPPFA
- **数据隐私**：POPIA + Regulations / PAIA / Cybercrimes Act
- **矿业能源**：MPRDA / Mining Charter / Electricity / NERSA / Petroleum Pipelines
- **环境资源**：NEMA / Waste / Air Quality / Water / Biodiversity
- **争议解决**：Arbitration / Criminal Procedure / CCMA / High Court / Magistrates Court
- **实务工具**：CIPC费用 / SARS税率 / 签证费 / 合规检查清单 / 监管目录 / 中资踩坑指南
