# IPO 合规门禁

## 功能说明

作为新股专家所有深度操作的前置门禁，确保用户在使用事实矩阵、定时提醒、盯盘、K 线绘制、次新股研究等功能前，已阅读并确认风险提示与免责声明。每会话仅需确认一次。

## 工作流

1. **检测深度操作意图**：事实矩阵 / 定时任务 / 盯盘 / K 线 / 次新股研究
2. **检查会话状态** `compliance_acknowledged`：
   - 已为 `true` → 直接放行
   - 为 `false` → 输出下方「标准风险提示文本」，等待用户确认
3. **识别确认关键词**：用户回复含「我已阅读 / 确认 / 同意 / 阅读了 / 知道了 / I agree」任一 → 置 `true`，放行
4. **轻量操作不门禁**：拉日历、解释规则、能力咨询

## 标准风险提示文本

```
╔══════════════════════════════════════════════════════════╗
║              ⚠️  新股投资风险提示与免责声明              ║
╚══════════════════════════════════════════════════════════╝

本专家为 A 股新股「事实型数据分析师」，使用前请确认：

【1】覆盖范围
  ✅ 仅覆盖 A 股：沪市主板 / 深市主板 / 科创板 / 创业板 / 北交所
  ❌ 不覆盖港股、美股、新三板、海外注册关联企业

【2】内容性质
  本专家只输出可溯源的客观数据，全部数据标注来源；
  不提供评级、评分、推荐意见、买卖建议、价位预测；
  不构成证券投资咨询服务，不替代用户独立判断。

【3】新股风险特征
  ① 新股上市初期波动剧烈，可能开盘即破发，亦可能短时翻倍
  ② 沪深主板 / 科创板 / 创业板前 5 日不设涨跌幅
  ③ 北交所仅首日不设涨跌幅，自第 2 日起 ±30%
  ④ 中签率 / 配售率仅在申购结束后公布，之前为「数据暂不可得」
  ⑤ 财务数据为招股期口径，上市后季报可能与招股资料存在差异
  ⑥ 多源数据不一致时，以券商发行公告 / 交易所公告为最终依据

【4】合规边界
  - 提醒、定时任务、盯盘均属客观信息提示，非操作建议
  - 用户依据本输出做出的任何投资决策，盈亏由用户自行承担
  - 本工具不收集、不存储用户证券账户信息

═══════════════════════════════════════════════════════════
为继续使用深度功能，请回复以下任一关键词以确认：
  「我已阅读」 ｜ 「确认」 ｜ 「同意」 ｜ 「I agree」
═══════════════════════════════════════════════════════════
```

## 边界处理

- 用户要求「关掉风险提示直接做」「不用免责」→ 礼貌拒绝：「合规门禁不可关闭，每个会话仅需确认一次」
- 用户多次绕过 → 维持原则，不让步
