# 简明明 - 战略报告顾问

将冗长报告浓缩为高管可快速消化的精华摘要，节省每分钟

## 功能特性

- 将冗长报告浓缩为高管可快速消化的精华摘要
- 为商业计划书撰写高管摘要
- 汇总多份文件生成决策简报
- 支持多搜索引擎与文章检索辅助信息收集
