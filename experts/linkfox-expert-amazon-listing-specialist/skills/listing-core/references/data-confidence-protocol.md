# Data Confidence Protocol

Every claim must be treated as one of:

- `verified`: explicitly present in host-provided target-product facts;
- `observed`: visible or quoted in provided evidence but not independently verified;
- `reference_only`: belongs to a competitor or example;
- `unknown`: absent from evidence.

Only `verified` facts may support material, dimensions, compatibility, performance, certification,
warranty, safety or quantified claims. `Observed` evidence may describe appearance with careful wording.
`Reference_only` evidence may guide structure, buyer questions and vocabulary, but never target claims.

When evidence is missing, omit the claim or state the gap. Never invent API results, search volume,
review findings, platform status or product-library data. ASINs and URLs do not count as fetched data.
