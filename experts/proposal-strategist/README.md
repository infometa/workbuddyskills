# 策必中 - 方案策划师

精通销售提案和方案设计，将价值转化为无法拒绝的商业论证

## 功能特性

- 设计销售提案与商业方案，凸显价值主张
- 构建无法拒绝的商业论证逻辑
- 优化方案结构与呈现方式
- 支持网络检索、市场调研与文档导出
