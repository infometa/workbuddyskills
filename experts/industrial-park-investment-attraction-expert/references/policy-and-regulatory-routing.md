# 政策与监管路由

> 版本：26.7.27；公开资料复核日：2026-07-27（Asia/Shanghai）。
>
> 本文件只提供“找对企业”所需的公开政策线索、约束路由和复核动作，不提供法律意见，不替代属地主管部门、园区工程团队或专业机构的正式判断。政策匹配不能证明企业有落地意愿，也不能证明补贴、税收、用地、能耗、环评或安全条件已经获得批准。

## 运行时边界

- 涉及政策适用性时确定实际 `jurisdiction`，可按国家、省级、市县、具体园区或地块追溯；任何全国规则都不能自动替代属地细则。纯主体核验或材料摘录不必为了填满层级虚构地域。
- 硬约束适用时应在园企适配或交付结论前完成相应核验。市场准入、产业限制、规划用途、环评、能耗、安全、消防、危化、特种设备、保税/跨境等只是开放目录；本次不适用的项目不进入检查表，适用但不明的项目标为 `unknown` 或 `incomplete`。
- 政策目录、认定名单和公示平台只用于发现候选、解释产业角色或提出核验问题；不得据此声称企业符合某项政策、将获得优惠或已经决定选址。
- 涉及招商引资优惠、行政协议或排他条件时，只能形成适用的合规复核项。涉及经营者经济活动的政策措施需关注公平竞争审查要求，不代替法务审查。
- 易变记录只有在将被当前重要判断引用时才需重新打开原始公开来源；页面不可访问、只有搜索摘要或存在新修订草案时，不得写成“现行已确认”。

## `KnowledgeRecord` 字段说明

每条运行时知识至少保留以下字段；时间使用 ISO 8601：

| 字段 | 写法与失败关闭规则 |
|---|---|
| `jurisdiction` | 法域和地域适用范围，例如“中华人民共和国/全国”或“上海市”；未知不得默认全国适用。 |
| `effectiveAt` | 正式生效时间；统计、案例或尚未生效草案可为 `null`，但须在 `claim` 解释。 |
| `expiresAt` | 明示失效时间；无明示期限写 `null`，`null` 不等于永远有效。 |
| `sourceRef` | 本文件使用的稳定来源标识，指向“公开 URL + 标题”；落入结构化 Schema 时分别写入 `sourceUrl`、`sourceTitle`。 |
| `evidenceClass` | 仅用 `observed / inferred / hypothesis / not_proven`；法规原文可为 `observed`，适用性判断通常仍是 `inferred`。 |
| `nextReviewAt` | 下一次复核时间；草案、年度名单、地方政策和高波动规则应缩短周期。 |
| `supersedes` | 被本记录替代的旧 `recordId` 数组；没有则为 `[]`，不得只写文件名。 |

同时记录 `recordId`、`topic`、`claim`、`retrievedAt`，并固定
`usePolicy=recheck_current_public_source_before_material_decision`。

示例：

```yaml
recordId: POL-2026-SME-LADDER
jurisdiction: 中华人民共和国/全国；认定实施仍按属地
effectiveAt: 2026-04-01T00:00:00+08:00
expiresAt: null
sourceRef: SRC-MIIT-SME-LADDER-2026
evidenceClass: observed
nextReviewAt: 2026-10-01T00:00:00+08:00
supersedes: []
```

## 按任务依赖组合

以下单元不是固定三步流程。仅选择本次请求需要的单元；材料事实摘录可以直接形成受限结论，纯园区约束卡不要求发现候选，候选发现也不能强制生成招商策略。

### 可选单元：冻结适用的园区约束

只记录会改变本次结论的已知事实或关键未知；下面是开放问题目录，不是最低字段清单：

- 具体行政区、园区和地块；
- 规划用途、可承载空间类型和交付期；
- 能耗、排放、危化、安全、消防、洁净、层高、荷载、物流等已知边界；
- 园区能兑现的服务和其责任主体；
- 当前任务意图；可以是材料审计、主体核验、建立园区条件、发现企业、适配判断、组合建议或用户明确的其他目标，不限于招商经营模板。

无公开证据的字段写 `unknown`，不得按同类园区常识补齐。

### 可选单元：把政策线索转成候选问题

政策/名单只能派生“值得找什么”，例如：

- 产业目录或地方产业规划 → 目标链节与反向淘汰词；
- 优质中小企业名单 → 技术型、配套型候选池；
- 孵化器/中试平台规则 → 需要专业服务、验证或毕业承接的企业角色；
- 项目备案、环评公示、公共资源交易 → 扩建、设备、工程或区域布局线索。

需要判断候选资格时，才应用主体可区分、无已证实硬约束失败、符合本次任务适用条件、关键判断有可回读证据这些资格底线。纯材料审计和纯园区条件任务不应伪造候选资格条件。下一核验动作、公开入口和建议渠道属于行动准备度；缺少这些信息只形成待补任务，不得据此剔除已经通过资格底线的企业。

### 可选单元：形成当前可证明的结论

只允许以下状态：

- `observed`：原始公开文件或公示直接支持；
- `inferred`：从多个公开事实推导，并写替代解释；
- `hypothesis`：可测试的招商假设，并写反证条件；
- `not_proven`：当前公开资料不能证明。

推荐表达：

> 公开项目公示显示该主体在目标区域有技改活动（`observed`）；这可能带来新增工程或配套需求（`inferred`），也可能只是既有产线改造。下一步需核验新增面积、时间窗口和实际用房主体。

## 事实、假设与禁止推断

### 可作为事实

- 文件发布机关、文号、公开日期、生效日期和原文明确条款；
- 公示名单中的主体名称、批次和公示状态；
- 官方平台公开的项目、采购、许可或处罚信息及其明确时间。

### 只能作为假设

- 政策方向会使某企业更愿意迁入；
- 获得某项认定意味着企业当前有扩租或选址需求；
- 园区资源与政策叠加会缩短决策周期；
- 某种奖励一定能兑现或构成企业的首要决策因素。

### 不得输出

- “已获批”“可享受”“零门槛”“保证拿到补贴”等未被当前、属地、主体级证据直接支持的表述；
- 用征求意见稿替代现行规则；
- 用园区名称或产业标签替代地块、工程、环保和安全核验；
- 任何已代表用户提交申请、联系主管部门、承诺条件或完成外联的说法。
