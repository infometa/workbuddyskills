# 行业信号与创新研究

> 版本：26.7.27；公开资料复核日：2026-07-27（Asia/Shanghai）。
>
> 本文件把行业政策、统计趋势和创新方向转换为“找什么企业、搜什么事件、验证什么需求”。宏观增长、产业热度和技术前沿都不能直接证明某家企业正在选址、扩产或愿意入园。

## 运行时原则

1. 先用趋势构造查询族，再用企业级公开事实决定是否入池；不得用热门赛道直接代替主体、项目、空间和时间证据。
2. 当本轮缺口涉及企业任务、地点或载体时，“企业 + 事件 + 地点/载体”通常比只搜产业名更有信息增益；若其他查询更能闭合当前主张，应采用其他查询。事件示例包括扩产、技改、项目备案、环评、设备采购、客户订单、研发招聘、实验室、中试和区域中心。
3. 同时搜索反证：项目终止、处罚、停产、业务收缩、基地出售、注销/吊销、招聘冻结等。
4. 政策导向、统计增长和媒体热度只属于发现层；候选资格仍须绑定法定主体、直接来源、发布日期和证据主张，下一核验动作另记为行动准备度。
5. 趋势与创新记录按法定有效期、来源实际更新频率、主张波动性、当前决策风险和重大变更事件安排复核，不设统一季度周期；地方产业、工程和项目判断在每次任务中按属地与日期重新核验。

## `KnowledgeRecord` 字段说明

| 字段 | 使用要求 |
|---|---|
| `jurisdiction` | 数据或政策覆盖的地域；全国统计不能自动代表目标城市。 |
| `effectiveAt` | 政策生效时间；统计事实、研究报告可为 `null` 并在主张中写观察期。 |
| `expiresAt` | 明示终止时间；没有则为 `null`，但仍受 `nextReviewAt` 约束。 |
| `sourceRef` | “公开 URL + 标题”的稳定引用；结构化记录映射到 `sourceUrl`、`sourceTitle`。 |
| `evidenceClass` | `observed / inferred / hypothesis / not_proven`；趋势到企业的映射通常是 `hypothesis`。 |
| `nextReviewAt` | 下一复核时间；按来源更新周期、信号波动和本次决策风险确定，不设统一季度或年度间隔。 |
| `supersedes` | 被当前记录替代的旧 `recordId`；无则 `[]`。 |

还应保存 `recordId`、`topic`、`claim`、`retrievedAt`，并使用
`recheck_current_public_source_before_material_decision`。

```yaml
recordId: SIG-2026-MFG-PILOT
jurisdiction: 中华人民共和国/全国；平台落地仍按行业与属地
effectiveAt: null
expiresAt: null
sourceRef: SRC-MIIT-PILOT-2024
evidenceClass: observed
nextReviewAt: 2026-10-15T00:00:00+08:00
supersedes: []
```

## 信号层级

| 层级 | 典型公开材料 | 能支持什么 | 不能支持什么 |
|---|---|---|---|
| 方向层 | 国家/地方产业政策、行动方案、产业目录 | 构造行业、技术、链节和约束查询词 | 单家企业的需求、意愿和可落地性 |
| 总量层 | 国家统计、行业主管部门统计 | 识别结构变化和需要进一步研究的方向 | 把全国增速分配给城市或企业 |
| 生态层 | 产业集群、孵化器、中试平台、创新中心和公开名单 | 发现节点企业、平台与合作关系 | 平台能力已被某企业使用或产生效果 |
| 企业层 | 官网、法定公告、年报、项目/环评/采购、招聘、专利 | 支持企业行为、项目和能力主张 | 未公开的选址预算、决策人和真实意愿 |
| 需求层 | 明确采购、挑战题、招标、场景需求和公开联系入口 | 支持渠道选择与核验准备 | 已接洽、已报名、已成交或已入园 |

只有企业层或需求层的直接证据，才可承担候选卡的关键主张。

## 当前观察锚点与可证伪假设

### 1. 装备制造与高技术制造

`observed`：工业和信息化部公布的 2025 年工业和信息化发展情况显示，规模以上装备制造业、高技术制造业增加值增速高于全部规模以上工业；国家统计局已发布 2025 年国民经济和社会发展统计公报。

`hypothesis`：目标城市若具有相应链主、人才、试验验证或供应链资源，部分企业可能存在研发、区域交付、技改或配套基地任务。

反证与核验：

- 企业只有行业标签，没有近两年项目、客户、招聘或研发活动；
- 其增长来自既有地区且没有目标区域任务；
- 工程、用途、能耗或交付期不适配；
- 主体是品牌/销售公司，不是实际研发或生产主体。

### 2. 制造业中试与成果产业化

`observed`：《制造业中试创新发展实施意见》把中试界定为试制阶段新产品转向生产过程的过渡性试验；《制造业中试平台建设指引（2025版）》进一步列出设计、功能性能、工艺、适配和生产验证等服务。

`hypothesis`：若用户明确本轮要验证中试平台需求，可把处于样品—工艺—小批量过渡期且自建平台成本高作为待核企业假设；只有用户明确或确认它是优先标准后，才改变业务顺序。“中试园区”标签本身不能自动排除其他企业。

企业级证据组合：

- 样机/新产品或工艺公开；
- 中试、验证、试生产、可靠性或注册检验任务；
- 设备、工艺、质量或生产工程岗位；
- 融资/订单与产业化时间窗口；
- 对应平台能力、工程边界和责任主体可被园区真实兑现。

### 3. 人工智能与制造融合

`observed`：国家和工业和信息化部门已发布“人工智能+”及制造专项行动；2026 年“模数共振”行动列出多个行业模型、专用模型、智能体和高质量数据集应用方向。

`hypothesis`：园区不应只找通用 AI 公司，而应按“制造需求方—行业模型/软件—数据与集成—设备与边缘—测试场景”形成角色组合。

关键反证：

- 只有概念宣传，没有产品、客户、部署或行业数据能力；
- 园区没有真实场景、数据责任人或测试授权；
- 企业只能远程交付，不需要本地团队或空间；
- 数据、安全和行业合规边界不清。

### 4. 绿色低碳与工业改造

`observed`：国务院常务会议审议通过《制造业绿色低碳发展行动方案（2025—2027年）》；工业和信息化部后续文件持续覆盖绿色制造、能效、碳足迹和绿色工厂等方向。

`hypothesis`：在高能耗制造园区，客户组合可同时包含改造需求方、节能环保装备、能源/碳管理软件、检测认证和系统集成企业。

必须核验：

- 园区和企业的真实工艺、负荷、排放与改造计划；
- 解决方案是否有可回读案例和适用边界；
- 商业模式、交付周期和本地服务必要性；
- “绿色”“零碳”称谓是否有明确标准与核算边界。

### 5. 未来产业

`observed`：七部门《推动未来产业创新发展的实施意见》明确未来产业处于孕育萌发或产业化初期，具有显著不确定性。

`hypothesis`：未来产业园区应把目标拆成“成果源—验证平台—场景方—产业化团队—专业服务”，并提高未知和观察池占比。

禁止把赛道名单、论文、专利或获奖直接写成可产业化、可融资或可入园；必须补齐团队、权利归属、验证阶段、工程条件和市场任务。

## 趋势到候选的转换卡

每个方向按以下顺序生成，不直接生成企业名单：

```text
趋势锚点
→ 目标链节/角色
→ 企业级事件词
→ 公开来源组合
→ 园区资源交换
→ 硬约束
→ 反证
→ 可执行的下一核验动作
```

示例（不是企业事实）：

```text
中试能力建设
→ 新材料工艺验证企业
→ “中试/试生产/工艺放大/设备工程师/新基地”
→ 企业官网 + 项目/环评公示 + 招聘
→ 园区共享中试平台和下游验证场景
→ 用途、能耗、排放、安全、平台档期
→ 已自建产线或项目已在异地落地
→ 按本次任务时限核验验证批次、面积、工艺和决策窗口
```

## 创新信号强度

### 较强组合

- 主体明确的项目备案/环评/采购或基地公告；
- 企业一手材料与政府/监管公示相互支持；
- 事件时间、地点、工艺/产品和责任主体可绑定；
- 存在清晰的空间、平台、场景或供应链任务。

### 中等线索

- 研发/生产招聘连续出现；
- 专利、标准、检测、样机或客户案例与产业化任务一致；
- 融资、订单或合作公告能被其他直接来源补强；
- 上下游、投资机构或高校公开材料能确认关系。

### 弱线索

- 榜单、奖项、搜索摘要、媒体转述；
- 单个专利、单次活动、泛招聘或无时间的官网介绍；
- 全国行业增长、产业热词或园区自述。

弱线索可进入发现账本，不得独立支撑合格候选。

## V1 交付动作

1. 按本次任务目标和已知上下文选择真正有判断价值的趋势主题，不设固定主题数；
2. 按主题与当前证据缺口构造必要的产业链、事件、工程、资源或反证查询族；不为凑固定类别发起无效查询；
3. 先交付本批满足本次条件的候选，再按数量目标或覆盖要求继续；用户没有明确或确认优先标准时，显示顺序不代表业务优先级；
4. 每家只写本任务适用的判断项；涉及公司阶段、信号或证据质量的结论必须引用企业级来源；
5. 行动准备充分时给出有证据的渠道建议、入口状态和渠道理由；入口暂缺不影响企业资格，趋势本身不能作为渠道；
6. 新查询主要返回重复、关键来源不可访问或预算触顶时保存进度并暂停；只有冻结范围内形成穷尽证明才能停止并报告未覆盖范围。

## 事实与假设的全局分界

- `observed`：公开文件确实发布、公开统计的口径和值、企业/项目页面直接显示的内容；
- `inferred`：多个企业级事实共同指向某项任务，但仍存在其他解释；
- `hypothesis`：某趋势与园区资源结合后可能产生招商机会；
- `not_proven`：真实空间需求、预算、决策窗口、落地意愿、工程可行性、服务使用和商业效果。

不得使用“赛道爆发，所以该企业必然扩张”“有专利，所以适合入园”“融资后一定找场地”“列入名单，所以可获得政策”等推断。
