# 结果工件渲染

把已有语义结果转换为用户需要的格式，同时保持内容哈希边界。

## 触发

- 用户明确要求 JSON、CSV、Markdown、表格或可交接文件；
- 用户要求逐企业核验清单、`VerificationPreparationPack`、触达草稿或 `AuthorizationDraft`；
- 当前任务需要结构化 `ProgressCard`，或跨会话/导入续作确实需要 `ResumeCapsule`。

默认首值在聊天中；不要因为存在文件工具就自动写盘。

## 输入

- 已完成的任务适用语义资产，例如 `ParkBrief`、`KnowledgeRecord`、`EvidenceLedger`、`TaskAssessment` 或 `TargetPortfolio`；
- 质量门回执；
- 目标格式和用户明确的写入意图；
- 能力与权限状态。

## 不可变语义

渲染前计算或记录输入语义摘要。输出必须保持本任务实际存在的语义；以下关系仅在适用时保留：

- 企业集合与顺序；
- 法定主体和实体关系；
- 排名、排名理由、适配带和候选状态；
- 证据、反证、未知和来源链接；
- `TaskGoal`、批次边界、累计合格数量、覆盖评估和任务状态；
- 暂停原因或经证明的未覆盖范围、结果层和下一动作；
- 行动准备度、建议渠道、公开入口状态、渠道理由、客户运营顺序和速度观测状态。

发现输入内部矛盾时停止并退回唯一语义写者，不自行修正。

## 格式

### 聊天

先给一句本任务结论或真正阻断交付的问题，再给当前最有用的结果和关键依据。企业组合任务才展示候选及后续批次；用户没有明确或确认优先标准时，必须直说“显示顺序不代表业务优先级”，只有存在可回显的优先标准时才可称“优先批次”。政策、材料、园区条件或一般事实任务直接交付相应结论与证据，不套候选表。普通聊天默认只使用中文业务标签，不展示内部对象名、字段名、英文枚举或 D/O 代码。

按用户请求的载体和本任务实际产物选择零个、一个或多个视图，不预设固定版块或固定顺序。可选视图包括：

- 本轮结论与真正影响判断的关键假设；
- 当前候选或审计结果：候选编号、法定主体、资格结论、适配理由、公开证据、不利信息与待确认项；入口状态和核验动作仅在本任务适用且有依据时出现；
- 与冻结目标有关的排除或还需核验原因、累计进度和未覆盖范围；
- 只有目标尚未满足且仍有可执行路径时才出现的后续任务、动作或继续提示。

具体视图和先后关系由依赖关系与用户价值决定；任务已完成时可以没有后续动作，纯材料审计也不必生成园区招商批次视图。只有存在用户明确或确认的优先标准时才展示相应的推荐含义。

候选编号、实体引用和证据引用必须稳定，便于后续批次、CSV、JSON 和 Markdown 复用；普通聊天只展示有助于交接的编号。

### JSON

严格使用包内 Schema 字段，禁止未知字段和未定义完成态。

### CSV

对以 `= + - @` 开头的单元格进行公式注入防护；保留 UTF-8；复杂证据使用引用 ID，不把长正文塞入单元格。

### Markdown

使用紧凑表格和贴近主张的可点击来源；不复制长篇原文。

### 前台翻译

- `businessPriorityState=criterion_based` 且有用户明确或确认的优先标准时，才使用该标准本身定义的通俗优先标签；任务特定的适配或证据标签不能自动翻译成推荐程度；
- `in_progress` 且存在宿主可见交付回执 → “当前批次已在对话中展示，正在按这次目标继续”；
- `in_progress` 但只有生成/准备记录 → “当前批次已准备，尚未确认在对话中展示，任务仍在继续”；
- `completed` → “已达到你这次的目标”；
- `stopped_with_gap` → “本轮已停止，仍有未覆盖范围”；
- `paused` → “已暂停并保留进度”；
- `superseded` → “原目标已被新目标取代”；
- `prepared_not_contacted` → “已准备，尚未联系”；
- `not_measured` → “本轮未记录耗时”。

只有用户明确要求 JSON、Schema、调试信息或技术审计时，才附原始字段和枚举。

### 授权准备包

只生成草稿、对象、内容摘要、核验项和缺失权限。不得包含执行回执，不得写 `succeeded`。

### 核验准备包

按 `../../schemas/verification-preparation-pack.schema.json` 生成逐对象价值主张、核验问题、可用渠道、材料、责任人和由当前任务决定的里程碑；不套固定日程。需要任何外部动作时另按 `../../schemas/authorization-draft.schema.json` 生成授权草稿；两者都不代表已联系。

## 输出

- `RenderedArtifact`；
- 可选 `ProgressCard`；
- 可选 `ResumeCapsule`；
- 可选 `VerificationPreparationPack`；
- 可选 `AuthorizationDraft`；
- `semanticInputHash` 与 `semanticOutputHash`（宿主或工具可计算时）。

## 写权与禁止

- 只改格式；
- 不新增、删除、替换或重排语义对象；
- 不写新证据；
- 不改变候选状态或结果层；
- 不自动写文件；
- 不发送、不写 CRM、不创建日历；
- `executedActions` 必须为空；
- 没有真实执行回执时不得使用“已完成外部动作”的措辞。

## 停止与回退

- 目标格式不可用：在聊天交付等价结构；
- 用户未明确写文件：先展示，不写盘；
- 输入未过质量门或哈希不一致：退回相应单写者；
- 外部动作请求：输出失败关闭边界和 `AuthorizationDraft`。
