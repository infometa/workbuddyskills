# 经营分析阈值规则

## 集中度阈值

| 指标                 | 正常   | 关注      | 警告   |
| -------------------- | ------ | --------- | ------ |
| 前五大供应商合计占比 | < 40%  | 40%-60%   | > 60%  |
| 前五大客户合计占比   | < 40%  | 40%-60%   | > 60%  |
| 第一大客户占比       | < 20%  | 20%-35%   | > 35%  |
| 第一大供应商占比     | < 20%  | 20%-35%   | > 35%  |
| HHI 指数             | < 0.15 | 0.15-0.25 | > 0.25 |

## 账税一致性阈值

| 差异率  | 评估     | 风险等级 | 处理建议                  |
| ------- | -------- | -------- | ------------------------- |
| < 5%    | 可接受   | 无       | 正常                      |
| 5%-10%  | 需关注   | low      | 要求说明差异原因          |
| 10%-20% | 异常     | medium   | 要求提供差异明细 + 调节表 |
| > 20%   | 严重异常 | high     | 建议拒绝或要求第三方审计  |

## 产销率阈值

| 产销率    | 评估     | 风险等级 | 含义                   |
| --------- | -------- | -------- | ---------------------- |
| 95%-105%  | 健康     | 无       | 产销平衡               |
| 90%-95%   | 正常偏低 | 无       | 轻微库存积压           |
| 80%-90%   | 需关注   | low      | 库存积压，关注去化能力 |
| < 80%     | 异常     | medium   | 严重滞销，关注存货减值 |
| 105%-120% | 需关注   | low      | 库存消耗，关注补货能力 |
| > 120%    | 异常     | medium   | 超卖，关注交付风险     |

## 库存周转天数阈值（按行业）

| 行业   | 正常    | 关注     | 警告    |
| ------ | ------- | -------- | ------- |
| 制造业 | < 60 天 | 60-90 天 | > 90 天 |
| 贸易业 | < 30 天 | 30-60 天 | > 60 天 |
| 服务业 | N/A     | N/A      | N/A     |

## 流水阈值

| 指标         | 正常  | 关注    | 警告  |
| ------------ | ----- | ------- | ----- |
| 我行结算占比 | ≥ 60% | 40%-60% | < 40% |
| 进账集中度   | < 0.5 | 0.5-0.7 | > 0.7 |
| 月度波动率   | < 0.3 | 0.3-0.5 | > 0.5 |
| 支出收入比   | < 0.9 | 0.9-1.0 | > 1.0 |

## 风险等级判定

综合各维度风险信号：

- **高风险**：任一维度出现 high 级别信号
- **中风险**：2 个及以上维度出现 medium 级别信号
- **低风险**：仅有 low 级别信号
- **正常**：无风险信号
