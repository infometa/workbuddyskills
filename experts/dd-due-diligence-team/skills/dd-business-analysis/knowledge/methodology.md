# 经营分析方法论

## 核心分析框架

经营分析采用"布局-模式-质量-集中度-一致性-产销-流水"七维框架：

1. **经营布局** — 企业物理布局是否合理，产能是否匹配业务规模
2. **管理模式** — 管控是否有效，信息化水平是否支撑管理需求
3. **营收质量** — 主营是否集中，毛利率趋势是否健康
4. **集中度** — 供应/客户是否过度依赖少数对手方
5. **账税一致** — 账面收入与税务申报是否匹配
6. **产销匹配** — 产量与销量是否匹配，库存是否合理
7. **流水验证** — 银行流水是否与经营数据交叉验证

## 指标定义

### 集中度指标

- **前五大合计占比** = Σ(前五大对手方金额) / 总金额 × 100%
- **HHI 指数**（赫芬达尔指数）= Σ(各对手方占比²)，> 0.25 为高度集中

### 账税一致性指标

- **差异率** = |账面营业收入 - 增值税申报收入| / 账面营业收入 × 100%
- 差异来源分类：收入确认时点 / 免税收入 / 跨期调整 / 其他

### 产销指标

- **产销率** = 年销量 / 年产量 × 100%
- **库存周转天数** = 平均库存余额 / (年销售成本 / 365)
- **原材料单价波动** = (本期单价 - 上期单价) / 上期单价 × 100%

### 流水指标

- **进账集中度** = 最大进账对手方金额 / 总进账 × 100%
- **我行结算占比** = 我行流水总进账 / 企业总营收 × 100%
- **月度波动率** = std(月进账) / mean(月进账)
- **支出收入比** = 总出账 / 总进账

## 交叉验证规则

| 验证项 | 数据源 A         | 数据源 B         | 容差           |
| ------ | ---------------- | ---------------- | -------------- |
| 营收   | 年报营业收入     | 流水总进账       | ±20%           |
| 客户   | 年报前五大客户   | 流水前五大收款方 | 名称匹配 ≥ 3/5 |
| 供应商 | 年报前五大供应商 | 流水前五大付款方 | 名称匹配 ≥ 3/5 |
| 账税   | 年报营业收入     | 纳税申报收入     | ±10%           |
| 产销   | 销售台账总额     | 流水收款总额     | ±15%           |

交叉验证不通过时，在 judgments 中标注 warn。
