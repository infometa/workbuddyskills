# 经营分析 — 文档类型与字段映射

## 文档类型清单

| 文档类型 ID     | 文档名称     | 对应 Tab    | 关键字段                                  |
| --------------- | ------------ | ----------- | ----------------------------------------- |
| annual_report   | 企业年报     | C1/C3/C4/C5 | 主营构成/前五大供应商/前五大客户/经营场所 |
| purchase_ledger | 采购台账     | C4/C7       | 供应商明细/原材料/数量/金额/单价          |
| sales_ledger    | 销售台账     | C5/C7       | 客户明细/产品/数量/金额/单价              |
| tax_return      | 纳税申报表   | C6          | 增值税申报收入（12 个月累计）             |
| bank_statement  | 银行流水     | C8          | 交易日期/进出/金额/对手方/用途            |
| site_survey     | 现场调查报告 | C1/C2       | 经营场所/管理模式/数字化                  |

## 字段映射

### 年报 → C3 营收质量

| 年报章节                       | 目标字段              |
| ------------------------------ | --------------------- |
| "主营业务分析" → 产品/服务分类 | composition[].product |
| "主营业务分析" → 营收占比      | composition[].ratio   |
| "主营业务分析" → 同比变化      | composition[].change  |
| "盈利能力" → 毛利率            | marginTrend[].margin  |

### 年报 → C4 供应集中度

| 年报章节                       | 目标字段     |
| ------------------------------ | ------------ |
| "前五大供应商" → 供应商名称    | top5[].name  |
| "前五大供应商" → 采购金额/占比 | top5[].ratio |

### 年报 → C5 客户集中度

| 年报章节                     | 目标字段     |
| ---------------------------- | ------------ |
| "前五大客户" → 客户名称      | top5[].name  |
| "前五大客户" → 销售金额/占比 | top5[].ratio |

### 纳税申报表 → C6 账税一致

| 申报表字段                           | 目标字段         |
| ------------------------------------ | ---------------- |
| 增值税申报表 → 销售额合计（12 个月） | declared_revenue |
| 年报 → 营业收入                      | book_revenue     |

### 采购台账 → C7 产销

| 台账字段             | 目标字段                     |
| -------------------- | ---------------------------- |
| 原材料名称           | purchaseLedger[].name        |
| 采购数量             | purchaseLedger[].qty         |
| 采购金额             | purchaseLedger[].amount      |
| 单价（本期 vs 上期） | purchaseLedger[].priceChange |

### 销售台账 → C7 产销

| 台账字段             | 目标字段                  |
| -------------------- | ------------------------- |
| 产品名称             | salesLedger[].name        |
| 销售数量             | salesLedger[].qty         |
| 销售金额             | salesLedger[].amount      |
| 单价（本期 vs 上期） | salesLedger[].priceChange |

### 银行流水 → C8 流水

| 流水字段  | 目标字段              |
| --------- | --------------------- |
| 交易日期  | date                  |
| 进出标志  | type (income/expense) |
| 金额      | amount                |
| 余额      | balance               |
| 对手方    | counterparty          |
| 用途/摘要 | purpose               |
