# 经营分析逻辑

> 8 大块分析的逻辑、步骤、证据、结论。集中度/差异率/产销率等数字由沙箱计算，LLM 只负责语义抽取和研判。

## 一、经营布局（C1）

### 逻辑

从年报"公司概况"章节 + 现场调查报告中抽取企业经营基地信息。

### 步骤

1. 识别企业所有经营场所（总部/生产基地/销售中心/研发中心/仓储物流）
2. 抽取每个场所的：位置、功能定位、产能状态
3. 如有分支机构，从工商登记中补充

### 结论

输出 `{bases: [{location, function, capacity}], source}`。

## 二、管理模式（C2）

### 逻辑

从年报"公司治理"章节 + 章程中抽取管控模式信息。

### 步骤

1. 识别管控模式（集团化/事业部制/扁平化）
2. 识别子公司管控方式（财务管控/战略管控/运营管控）
3. 识别数字化水平（ERP/MES/OA 等系统使用情况）
4. 给出研判结论

### 结论

输出 `{mode, subsidiary, digitalization, judgments, source}`。

## 三、营收质量（C3）

### 逻辑

从年报"主营业务分析"章节抽取产品/服务构成及毛利率趋势。

### 步骤

1. 抽取主营业务构成（产品/服务名称 + 营收占比 + 同比变化）
2. 抽取近 3 年毛利率数据
3. 判断毛利率趋势（上升/平稳/下滑）
4. 给出研判结论

### 结论

输出 `{composition: [{product, ratio, change}], marginTrend: [{year, margin, status}], judgments, source}`。

## 四、供应集中度（C4）

### 逻辑

从年报"前五大供应商"章节 + 采购台账中抽取供应商数据。

### 步骤

1. 抽取前五大供应商名称 + 采购金额/占比
2. **沙箱计算**：前五合计占比 + 评估结论
3. 交叉比对采购台账验证数据一致性

### 评估规则

| 前五合计占比 | 评估结论 | 风险等级 |
| ------------ | -------- | -------- |
| > 60%        | 偏高     | medium   |
| 40%-60%      | 适中     | -        |
| < 40%        | 分散     | -        |

### 结论

输出 `{top5: [{rank, name, ratio}], total, assessment, source}`。

## 五、客户集中度（C5）

### 逻辑

从年报"前五大客户"章节 + 销售台账中抽取客户数据。

### 步骤

1. 抽取前五大客户名称 + 销售金额/占比
2. **沙箱计算**：前五合计占比 + 评估结论
3. 交叉比对销售台账验证数据一致性

### 评估规则

同 C4 供应集中度。

### 结论

输出 `{top5: [{rank, name, ratio}], total, assessment, source}`。

## 六、账税一致（C6）

### 逻辑

对比年报账面收入与纳税申报表申报收入，计算差异率。

### 步骤

1. 从年报抽取账面营业收入
2. 从增值税纳税申报表抽取申报收入（12 个月累计）
3. **沙箱计算**：差异率 = |账面收入 - 申报收入| / 账面收入 × 100%
4. 分析差异来源（收入确认时点/跨期/免税收入等）
5. 给出评估结论

### 评估规则

| 差异率 | 评估结论 | 风险等级    |
| ------ | -------- | ----------- |
| < 5%   | 可接受   | -           |
| 5%-10% | 需关注   | low         |
| > 10%  | 异常     | medium/high |

### 结论

输出 `{diffRate, diffSource, assessment, judgments, source}`。

## 七、产销（C7）

### 逻辑

从采购台账 + 销售台账中抽取产销数据，计算产销率和库存周转。

### 步骤

1. 从销售台账汇总年销量
2. 从采购台账/生产报表获取年产量
3. **沙箱计算**：产销率 = 销量/产量 × 100%
4. **沙箱计算**：库存周转天数 = 平均库存/日均销售成本
5. 抽取采购台账明细（原材料名/数量/金额/单价波动）
6. 抽取销售台账明细（产品名/数量/金额/单价波动）
7. 给出研判结论

### 评估规则

| 产销率               | 评估结论 | 风险等级 |
| -------------------- | -------- | -------- |
| 90%-105%             | 健康     | -        |
| 80%-90% 或 105%-120% | 需关注   | low      |
| < 80% 或 > 120%      | 异常     | medium   |

### 结论

输出 `{metrics, purchaseLedger, salesLedger, judgments, source}`。

## 八、流水（C8）

### 逻辑

从银行流水明细中统计进出账指标，识别对手方集中度。

### 步骤

1. 抽取流水交易记录为 JSON
2. **沙箱计算**：8 项统计指标（总进账/总出账/净流量/日均余额/我行结算占比/进账集中度/月度波动率/支出收入比）
3. **沙箱计算**：对手方 TOP5（收款/付款分别）
4. 交叉比对：流水对手方 vs 销售台账客户 / 采购台账供应商
5. 给出研判结论

### 结论

输出 `{metrics, topCounterparties, judgments, source}`。
