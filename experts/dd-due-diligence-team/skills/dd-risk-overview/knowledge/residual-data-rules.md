# 剩余数据分析规则

## 一、材料覆盖度检测

### 各模块已使用的文档类型

| 模块                | 主要使用的文档类型标签                             |
| ------------------- | -------------------------------------------------- |
| 企业画像 (profile)  | 工商信息、股权结构、企业征信、司法信息、舆情报告   |
| 财务分析 (finance)  | 财务报表、审计报告、纳税申报、银行流水             |
| 经营分析 (business) | 经营数据、合同台账、客户清单、供应商清单、产能报告 |
| 行业分析 (industry) | 行业报告、政策文件、竞品信息                       |

### 可能未被充分使用的材料类型

| 材料类型          | 可能包含的风险信息                     | 优先级 |
| ----------------- | -------------------------------------- | ------ |
| 担保合同/质押协议 | 限制性条款、交叉违约、担保范围         | 高     |
| 补充说明文件      | 企业自述的特殊情况、在建项目、计划变更 | 中     |
| 合同附件/补充协议 | 价格调整条款、违约金、特殊约定         | 中     |
| 外部评估报告      | 资产评估、环评报告、安全评估           | 中     |
| 会议纪要/决议     | 重大决策、投资计划、人事变动           | 低     |
| 其他未分类材料    | 需逐一检查                             | 低     |

## 二、定向风险扫描规则

### RD-01：限制性条款检测

**扫描目标**：担保合同、借款合同、质押协议

**关注内容**：

- 财务指标维持条款（净资产、资产负债率、利息保障倍数等）
- 交叉违约条款（其他债务违约是否触发本合同违约）
- 限制性条款（限制分红、限制对外投资、限制资产处置）
- 提前还款触发条件

**判定逻辑**：

- 若财务指标维持条款的安全边际 < 30%：medium
- 若存在交叉违约条款且企业有其他高风险债务：high
- 若限制性条款与企业当前经营计划冲突：medium

---

### RD-02：担保/质押条件检测

**扫描目标**：担保合同、质押清单、抵押物评估报告

**关注内容**：

- 担保范围是否覆盖全部债务
- 质押物价值是否充足（覆盖率）
- 质押物是否存在贬值风险
- 是否存在重复质押

**判定逻辑**：

- 质押覆盖率 < 120%：medium
- 质押物为易贬值资产（如存货、应收）：medium
- 发现重复质押迹象：high

---

### RD-03：未披露关联方检测

**扫描目标**：所有材料中出现的公司名称、自然人名称

**关注内容**：

- 材料中频繁出现但未在企业画像关联方清单中的公司
- 与企业有资金往来但未披露关联关系的主体
- 担保方/被担保方中未在画像中体现的关联方

**判定逻辑**：

- 发现未披露关联方且有资金往来：high
- 发现未披露关联方但无直接资金往来：medium

---

### RD-04：矛盾信息检测

**扫描目标**：所有材料

**关注内容**：

- 不同材料中同一指标的数值不一致
- 企业自述与第三方数据矛盾
- 时间线不合理（如合同日期早于公司成立日期）

**判定逻辑**：

- 关键财务数据矛盾（如营收、利润）：high
- 非关键数据矛盾：medium
- 时间线异常：medium

---

### RD-05：特殊风险事件检测

**扫描目标**：补充说明、外部报告、舆情材料

**关注内容**：

- 环保处罚或环保风险
- 安全生产事故
- 行政处罚记录
- 税务稽查或处罚

**判定逻辑**：

- 重大处罚（罚款>100万或停产整顿）：high
- 一般处罚：medium
- 历史处罚已整改完毕：low

---

### RD-06：或有负债检测

**扫描目标**：审计报告附注、担保合同、法律意见书

**关注内容**：

- 对外担保总额及占净资产比例
- 未决诉讼的预计负债
- 承诺事项（如回购承诺、差额补足）
- 或有事项的披露完整性

**判定逻辑**：

- 对外担保/净资产 > 50%：high
- 未决诉讼预计负债/净资产 > 10%：medium
- 存在未充分披露的或有事项：medium

---

### RD-07：经营异常信号检测

**扫描目标**：合同附件、客户投诉记录、退货记录

**关注内容**：

- 大额退货或合同取消
- 客户投诉集中
- 供应商纠纷
- 产品质量问题

**判定逻辑**：

- 退货率异常高（>行业均值2倍）：medium
- 存在批量客户投诉：low
- 供应商纠纷影响正常经营：medium

## 三、输出要求

1. 每条发现必须标注来源文件和具体位置
2. 必须与已有模块结论进行对比，避免重复
3. 对于矛盾信息，需同时列出两方数据
4. 建议必须具体可执行，不得泛泛而谈
