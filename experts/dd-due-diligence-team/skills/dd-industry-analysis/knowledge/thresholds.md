# 行业风险阈值标准

## 1. 增速类阈值

| 指标         | 正常            | 关注          | 风险                |
| ------------ | --------------- | ------------- | ------------------- |
| CAGR(3y)     | > 15%           | 5%-15%        | < 5%                |
| 同比增速趋势 | 稳定或上升      | 连续 2 年下降 | 连续 3 年下降或转负 |
| 增速 vs GDP  | > GDP 增速 2 倍 | 接近 GDP 增速 | < GDP 增速          |

## 2. 集中度类阈值

| 指标               | 正常    | 关注                          | 风险                        |
| ------------------ | ------- | ----------------------------- | --------------------------- |
| CR5                | 40%-70% | > 70%（寡头垄断，进入壁垒高） | < 20%（过度竞争，盈利承压） |
| 本企业市占率分位   | Top 10% | Top 25%                       | Top 50% 以下                |
| 市占率 vs 龙头差距 | < 3pp   | 3-8pp                         | > 8pp                       |

## 3. 政策类阈值

| 指标            | 正向      | 中性         | 负向               |
| --------------- | --------- | ------------ | ------------------ |
| 产业政策方向    | 鼓励/补贴 | 中性/过渡    | 限制/淘汰          |
| 贸易壁垒        | 无        | 单一市场摩擦 | 多市场贸易战       |
| 环保/碳排放要求 | 适度趋严  | —            | 突然收紧，成本骤增 |

## 4. 产能类阈值

| 指标                 | 正常    | 关注     | 风险               |
| -------------------- | ------- | -------- | ------------------ |
| 行业开工率           | > 80%   | 60%-80%  | < 60%              |
| 产能增速 vs 需求增速 | 匹配    | 略快     | 远超需求（> 2 倍） |
| 库存周期             | < 30 天 | 30-60 天 | > 60 天            |

## 5. 技术类阈值

| 指标           | 正常     | 关注               | 风险               |
| -------------- | -------- | ------------------ | ------------------ |
| 主流技术路线   | 成熟稳定 | 迭代期（新旧并存） | 颠覆性替代出现     |
| 本企业技术路线 | 主流路线 | 次主流但兼容       | 非主流且无转型计划 |
| 研发投入占比   | > 5%     | 3%-5%              | < 3%               |

## 6. 风险等级综合判定

| 等级 | 触发条件                                     |
| ---- | -------------------------------------------- |
| 高   | 命中任一"风险"列 + 影响企业核心业务          |
| 中   | 命中 2+ 个"关注"列，或单一"风险"列但影响可控 |
| 低   | 命中 1 个"关注"列，影响有限                  |
| 关注 | 主动补充材料建议（不构成风险，仅提示）       |
