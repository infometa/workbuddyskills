# 行业分析方法论

## 1. 市场规模分析

### 数据口径

- **统一单位**：全球市场用 GW / 万吨 / 亿元，国内市场用相同单位
- **时间跨度**：近 3-4 年历史数据 + 未来 1-2 年预测
- **数据来源优先级**：行业协会报告 > 第三方研究机构 > 企业年报披露

### 饱和度判定

| 渗透率  | 饱和度                |
| ------- | --------------------- |
| < 10%   | 低（导入期）          |
| 10%-20% | 低-中（成长期前半段） |
| 20%-50% | 中（成长期后半段）    |
| > 50%   | 高（成熟期）          |

## 2. CAGR 复合增长率

### 计算口径

- **3 年 CAGR** = (末年值 / 首年值)^(1/年数) - 1
- 仅用连续 3 年数据计算，缺失年份不补
- 负增长行业 CAGR 为负值

### 增速判定

| CAGR    | 判定     |
| ------- | -------- |
| > 20%   | 高速增长 |
| 10%-20% | 稳健增长 |
| 0%-10%  | 低速增长 |
| < 0%    | 衰退     |

## 3. CR5 集中度

### 计算口径

- **CR5** = 前 5 名企业市占率之和
- 按出货量或销售额口径（需标注）
- 标的企业是否在 CR5 内需明确

### 集中度判定

| CR5     | 集中度   | 竞争格局 |
| ------- | -------- | -------- |
| > 70%   | 高度集中 | 寡头垄断 |
| 40%-70% | 中高集中 | 头部集中 |
| 20%-40% | 中低集中 | 自由竞争 |
| < 20%   | 分散     | 完全竞争 |

## 4. 市占率分位

### 计算口径

- 按全行业企业市占率降序排列
- 本企业排名 / 总企业数 = 分位
- Top 10% / Top 25% / Top 50% / Bottom 50%

### 地位判定

| 分位       | 地位     |
| ---------- | -------- |
| Top 5%     | 龙头     |
| Top 10%    | 第一梯队 |
| Top 25%    | 第二梯队 |
| Top 50%    | 中游     |
| Bottom 50% | 长尾     |

## 5. 产业链议价能力分析

### 五力模型简化版

| 方向       | 关注点                    | 议价能力判定                   |
| ---------- | ------------------------- | ------------------------------ |
| 上游供应商 | 原料集中度 / 替代品数量   | CR5 > 60% → 弱；CR5 < 30% → 强 |
| 下游客户   | 客户集中度 / 客户切换成本 | CR10 > 50% → 弱；分散 → 强     |
| 替代品     | 技术替代风险              | 存在成熟替代 → 弱              |
| 新进入者   | 门槛（资金/技术/政策）    | 门槛低 → 弱                    |

## 6. 发展周期判定

| 周期阶段 | 特征                                     |
| -------- | ---------------------------------------- |
| 导入期   | 渗透率 < 10%，增速波动大，技术未定型     |
| 成长期   | 渗透率 10%-30%，CAGR > 20%，技术路线收敛 |
| 成熟期   | 渗透率 30%-60%，CAGR 5%-15%，格局固化    |
| 衰退期   | 渗透率 > 60% 或负增长，产能过剩          |
