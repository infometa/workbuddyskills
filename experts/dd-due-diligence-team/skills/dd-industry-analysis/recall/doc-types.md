# 行业分析所需材料

## 核心材料（必需）

| 材料类型         | 文档类型标识             | 用途                                  | 缺失影响           |
| ---------------- | ------------------------ | ------------------------------------- | ------------------ |
| 行业研究报告     | industry_research_report | E1 市场规模 / E2 增长率 / E3 发展趋势 | 无法生成市场数据   |
| 竞争对手数据     | competitor_data          | E5 竞争格局 / E7 行业地位             | 无法生成竞争者对标 |
| 产业政策文件     | industry_policy          | E4 监管政策                           | 无法生成政策分析   |
| 上下游产业链图谱 | supply_chain_map         | E8 上下游产业链                       | 降级为行业常识推断 |

## 可选材料

| 材料类型     | 用途                            |
| ------------ | ------------------------------- |
| 技术路线报告 | E3 发展趋势（技术迭代判断）     |
| 行业白皮书   | E1-E5 补充数据源                |
| 企业年报     | E7 行业地位（本企业市占率口径） |

## 数据来源优先级

1. **官方统计**：国家统计局 / 行业协会（CPIA / 中汽协等）
2. **第三方研究**：IEA / TrendForce / IDC / Gartner 等
3. **企业披露**：上市公司年报 / 公告
4. **政策文件**：发改委 / 工信部 / 海关总署
5. **行业常识推断**（标注为推断，非权威数据）

## 文档类型与 E 维度映射

| E 维度          | 主要数据源                  |
| --------------- | --------------------------- |
| E1 市场规模     | 行业研究报告（IEA / CPIA）  |
| E2 增长率       | 行业研究报告（历史数据）    |
| E3 发展趋势     | 行业研究报告 + 技术路线报告 |
| E4 监管政策     | 产业政策文件                |
| E5 竞争格局     | 竞争对手数据（出货排名）    |
| E6 风险因素     | E1-E5 综合识别              |
| E7 行业地位     | 竞争对手数据 + 企业年报     |
| E8 上下游产业链 | 产业链图谱 + 行业研究报告   |
