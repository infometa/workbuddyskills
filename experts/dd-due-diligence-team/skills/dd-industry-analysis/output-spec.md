# 行业分析输出规范

Skill 为每个 E section 生成两个文件：**MD 源文件**（自由格式）+ **HTML 渲染文件**（模板映射）。

## 沙箱文件清单

```
/workspace/industry/
├── e0.md    E0 行业定位（7 字段 + 确认状态 + 补充说明）
├── e0.html  E0 HTML 渲染
├── e1.md    E1 市场规模
├── e1.html  E1 HTML 渲染
├── e2.md    E2 增长率
├── e2.html  E2 HTML 渲染
├── ...
├── e8.md    E8 上下游产业链
└── e8.html  E8 HTML 渲染
```

## MD 文件格式

自由格式 Markdown，但建议包含以下结构：

```markdown
# E{N} {维度名}

## 概览

- 指标1: 值
- 指标2: 值

## 数据表

| 列1 | 列2 | 列3 |
| --- | --- | --- |
| ... | ... | ... |

## AI 研判结论

- ✓ 正向判断
- △ 关注判断
- ● 信息说明

## 证据链

- [1] 来源名 · P.页码
- [2] 来源名 · P.页码
```

### 各 section 建议内容

| Section | 标题         | 必含内容                                                                           |
| ------- | ------------ | ---------------------------------------------------------------------------------- |
| e0      | 行业定位     | 7 字段（代表产品/ISIC/细分行业/发展周期/产业链位置/行业梯队/市占率口径）+ 补充说明 |
| e1      | 市场规模     | 4 年市场数据表 + 细分领域渗透 + 证据链                                             |
| e2      | 增长率       | 3 年增速表 + CAGR + 判断项 + 证据链                                                |
| e3      | 发展趋势     | 概述 + 判断项清单 + 证据链                                                         |
| e4      | 监管政策     | 政策表 + 判断项 + 证据链                                                           |
| e5      | 竞争格局     | 集中度 + 竞争者对标表（含标的企业）+ 判断项 + 证据链                               |
| e6      | 风险因素     | 判断项清单（价格战/贸易摩擦/技术迭代/产能过剩等）                                  |
| e7      | 行业地位     | 市占率/排名/分位/龙头对比 + 判断项                                                 |
| e8      | 上下游产业链 | 上游供应链表 + 下游需求链表 + 判断项                                               |

## HTML 文件格式

使用 `templates/e{N}.html` 模板，将 MD 内容映射到占位符：

- `{{PLACEHOLDER}}` — 大写占位符，agent 用 MD 中对应内容替换
- HTML 必须自包含（内联 CSS，不依赖外部资源）
- 表格用 `<table>` 标签，判断项用带颜色的 `<div>`

## 红线

1. **每个 E section 必须同时有 .md 和 .html 文件**
2. **MD 必须人可读**（标准 Markdown 语法）
3. **HTML 必须自包含**（内联 CSS）
4. **E1-E5 必须有证据链**（`[N] 来源 · P.页码`）
5. **E5 competitors 必须包含标的企业**（`isTarget: true` 或标注"标的"）
6. **缺失数据标注"行业常识推断"**，不编造
