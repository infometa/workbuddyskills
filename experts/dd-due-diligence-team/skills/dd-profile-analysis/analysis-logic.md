# 企业画像抽取逻辑

> 5 大块抽取的逻辑、步骤、证据、结论。所有数字 / 比例 / 校验由沙箱执行，LLM 只负责语义抽取。

## 一、基础信息抽取

### 逻辑

从营业执照正本抽取法定登记信息。营业执照是工商总局统一格式，字段位置固定。

### 步骤

1. OCR 营业执照 → 定位 9 个字段（名称 / 统一社会信用代码 / 类型 / 住所 / 法定代表人 / 注册资本 / 成立日期 / 经营期限 / 经营范围）
2. 按字段名映射到 JSON（见 `knowledge/extraction-schema.md`）
3. 注册资本数值化 — 去掉"万人民币"等后缀，转换为元
4. 日期统一为 `YYYY-MM-DD` 格式

### 证据

每个字段必须标注来源文档（`source: business_license`）。

### 结论

基础信息块输出 `{basic_info: {...}}`。若 9 个字段有缺失，对应字段填 `null` 并在 warnings 中说明。

## 二、股权结构抽取

### 逻辑

从公司章程 + 年报 + 工商登记材料抽取股东列表。三份材料交叉验证：

- 章程 — 初始股东结构 + 出资方式 + 出资时间
- 年报 — 最新股东结构 + 实缴情况 + 年内变更
- 工商登记 — 变更记录（验证时效性）

### 步骤

1. 以年报为基准（最新），列出所有股东
2. 对照章程验证出资方式（货币 / 实物 / 知识产权等）
3. 对照工商变更记录，标注近 1 年的股权变动
4. 计算各股东出资比例（认缴 / 实缴分别计算）
5. **沙箱校验**：比例求和必须 = 100%（容差 0.01%）

### 证据

每位股东必须标注：

- `source` — 数据来源文档
- `capital_type` — 认缴 `subscribed` / 实缴 `paid`
- `change_flag` — 是否近 1 年有变更

### 结论

股权结构块输出 `{shareholders: [{name, type, subscribed_amount, paid_amount, ratio, capital_type, source, change_flag}]}`。

**异常情形**：

- 比例求和 ≠ 100% → warning
- 实缴 < 认缴 50% → warning（出资不到位）
- 自然人股东持股 > 50% → info（一人控股，需穿透实控人）
- 股东类型为"合伙企业"/"信托" → info（需进一步穿透）

## 三、实控人抽取

### 逻辑

实控人识别由沙箱 `ownership-trace` 端点计算，LLM 只提供股东数据。规则见 `knowledge/ownership-rules.md`。

### 步骤

1. LLM 整理股东列表（含中间层股东，如存在合伙企业 / 投资公司）
2. 若股东是自然人 → 直接列入候选实控人
3. 若股东是法人 → 标注"需穿透"，在年报 / 工商材料中找该法人的股东
4. 重复步骤 3 直到穿透到自然人或国资 / 公众公司
5. **沙箱计算**：`POST /profile/ownership-trace` 传入完整股东树，沙箱按规则算实控人

### 证据

实控人必须有完整控制路径：

```json
{
  "controller": "张三",
  "basis": "直接持股 35% + 一致行动协议 20%",
  "evidence_chain": [
    { "level": 1, "entity": "目标公司", "shareholder": "张三", "ratio": 0.35, "source": "年报" },
    { "level": 1, "entity": "目标公司", "shareholder": "李四", "ratio": 0.2, "source": "年报" },
    { "note": "张三与李四签订一致行动协议", "source": "章程附件" }
  ]
}
```

### 结论

实控人块输出 `{controllers: [{name, basis, evidence_chain}]}`。

**异常情形**：

- 无自然人控股股东且无一致行动协议 → 标注"无实际控制人"
- 国资委持股 > 50% → 标注"国有控股"
- 穿透层级 > 5 层 → warning（结构复杂，关注规避监管意图）

## 四、对外投资抽取

### 逻辑

从年报"对外投资"章节 + 工商登记"对外投资"查询抽取。

### 步骤

1. 列出所有控股（>50%）和参股（20-50%）子公司
2. 抽取字段：被投资企业名称 / 统一社会信用代码 / 投资金额 / 持股比例 / 投资日期 / 是否合并报表
3. 交叉比对工商登记，验证投资是否最新

### 证据

每项投资标注 `source` + `consolidated`（是否并表）。

### 结论

对外投资块输出 `{investments: [{name, credit_code, amount, ratio, invest_date, consolidated, source}]}`。

**异常情形**：

- 对外投资总额 > 净资产 50% → warning（投资激进）
- 持股 20-50% 但未并表 → info（关注关联交易）
- 投资领域与主业无关 → info（关注多元化风险）

## 五、关联交易抽取

### 逻辑

从年报"关联交易"章节抽取，同时交叉比对股权结构自动发现潜在关联方。

### 步骤

1. 抽取年报披露的关联方清单 + 交易明细
2. **自动发现**：基于股权结构，将持股 >20% 的股东及其控制的企业自动标记为关联方
3. 比对披露清单 vs 自动发现清单，找出**未披露的关联方**
4. 抽取关联交易字段：关联方 / 交易类型（采购 / 销售 / 资金往来 / 担保）/ 交易金额 / 定价政策 / 占同类交易比例

### 证据

每笔关联交易标注 `source` + `disclosed`（是否年报披露）+ `auto_detected`（是否自动发现）。

### 结论

关联交易块输出：

```json
{
  "related_parties": [{name, relationship, disclosed, source}],
  "transactions": [{counterparty, type, amount, pricing_policy, ratio_of_similar, source, disclosed, auto_detected}]
}
```

**异常情形**：

- 未披露关联方数量 > 0 → warning（信息披露不完整）
- 关联交易占营收比 > 30% → warning（业务独立性风险）
- 关联方资金往来 > 净资产 10% → warning（资金占用风险）
- 关联担保 > 净资产 50% → warning（隐性负债风险）
