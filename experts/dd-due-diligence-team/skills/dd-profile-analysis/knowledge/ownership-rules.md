# 实控人穿透规则

> 沙箱 `/profile/ownership-trace` 按以下规则计算实控人。LLM 不自行判定实控人，只提供股东数据给沙箱。

## 一、认定标准（参照《公司法》第 265 条）

实际控制人是指通过投资关系、协议或者其他安排，能够实际支配公司行为的人。

**核心判定**：持股 / 表决权 > 25% 或 实际支配公司行为。

## 二、穿透规则

### 规则 1：直接持股 > 50% → 控股股东

若某股东直接持股 > 50%，认定为控股股东。若该股东是自然人，即为实际控制人。

```
目标公司
├── 张三 55% → 张三是控股股东 + 实控人
└── 其他 45%
```

### 规则 2：直接持股 25-50% → 推定实控人

若某股东直接持股 25-50%，且无其他股东持股更高，推定为实际控制人（除非有反证）。

```
目标公司
├── 张三 35% → 推定实控人
├── 李四 25%
└── 其他 40%
```

### 规则 3：一致行动协议 → 合并计算

若多个股东签订一致行动协议，表决权合并计算。合并后 > 25% 则认定一致行动人为共同实控人。

```
目标公司
├── 张三 30% ┐
├── 李四 20% ├─ 一致行动协议 → 合并 50% → 张三 + 李四为共同实控人
└── 其他 50% ┘
```

### 规则 4：法人股东 → 穿透到自然人

若股东是法人（公司 / 合伙企业 / 信托），需穿透到最终自然人。穿透时：

- 递归查找该法人的股东
- 按 1-3 规则认定该法人的实控人
- 该实控人即目标公司的实控人

```
目标公司
└── 某某投资公司 60%
    ├── 张三 70% → 张三控制投资公司 → 张三是目标公司实控人
    └── 李四 30%

穿透路径：目标公司 → 投资公司（60%）→ 张三（70%）→ 张三为实控人
```

### 规则 5：国资持股 > 50% → 国有控股

若穿透后是国资委 / 国有企业持股 > 50%，认定"国有控股"，实控人填"XX 国资委"。

```
目标公司
└── 某某国有投资集团 65%
    └── XX省国资委 100% → 实控人为 XX省国资委
```

### 规则 6：无控股股东且无一致行动 → 无实际控制人

若股权分散（最大股东 < 25%），且无一致行动协议，认定"无实际控制人"。

```
目标公司
├── 张三 15%
├── 李四 12%
├── 王五 10%
└── 公众股东 63% → 无实际控制人
```

### 规则 7：信托 / 合伙企业 → 按 GP / 受托人穿透

若股东是合伙企业，按 GP（普通合伙人）穿透；若股东是信托，按受托人穿透。

```
目标公司
└── 某某合伙企业 40%
    ├── GP: 张三 1% → 张三控制合伙企业 → 张三是实控人
    └── LP: 其他 99%
```

## 三、特殊情况

### VIE 架构

若发现 VIE 协议（协议控制而非股权控制），实控人按协议方认定。LLM 在抽取时若发现 VIE 相关协议，标注 `vie_structure: true`，沙箱不自动穿透，由人工判定。

### 一致行动协议过期

一致行动协议有期限，过期后不再合并计算。LLM 在 evidence_chain 中标注 `agreement_date` 和 `expiry_date`，沙箱检查协议是否在有效期内。

### 委托代持

若发现委托代持协议，实际出资人为实控人。LLM 在 evidence_chain 中标注 `nominee: true`，沙箱按实际出资人计算。

## 四、沙箱计算逻辑

`POST /profile/ownership-trace` 入参：

```json
{
  "shareholders": [...],
  "agreements": [
    {
      "type": "consert_action",
      "parties": ["张三", "李四"],
      "agreement_date": "2020-03-15",
      "expiry_date": "2025-03-14"
    }
  ],
  "vie_structure": false
}
```

沙箱返回：

```json
{
  "controllers": [
    {
      "name": "张三",
      "basis": "直接持股 35% + 一致行动协议 20% = 55% 表决权",
      "evidence_chain": [...]
    }
  ],
  "rationale": "按规则 3 合并计算一致行动人表决权，张三 + 李四合计 55% > 25%，认定为共同实控人"
}
```

## 五、LLM 配合规则

1. **提供完整股东树** — 若股东是法人，LLM 需在年报 / 工商材料中找到该法人的股东，递归提供到自然人或国资
2. **标注一致行动协议** — 若发现协议，提供 parties / agreement_date / expiry_date
3. **标注 VIE / 代持** — 若发现特殊结构，标注 vie_structure / nominee
4. **不自行判定** — 实控人结论由沙箱输出，LLM 只提供数据
5. **穿透层级 ≤ 5** — 若穿透超过 5 层仍未到自然人，标注"结构复杂"，由人工介入
