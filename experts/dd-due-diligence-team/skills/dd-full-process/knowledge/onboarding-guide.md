# 新手引导层（Onboarding Guide）

本文件定义 dd-full-process 的引导能力，解决"第一次进来不知道能做什么、下一步怎么走"的问题。

**两层引导**：

- **轻引导（默认）**：打开工作台 / 新建项目时，给一句"你能做什么 + 提示语 + 场景罗列"，不阻塞、不弹面板。
- **完整引导（按需）**：用户明确说"介绍 / 怎么用 / 我需要帮助"，或纯新手无项目时，展开 4 选项卡详解。

**触发前提**：轻引导面向所有人（含老手）；完整引导仅当用户表达求助/介绍意图，或纯新手无项目时。

---

## 一、引导开关（onboarding.level）

| 档位      | 行为                                    | 适用                       |
| --------- | --------------------------------------- | -------------------------- |
| `full`    | 首轮渲染完整引导面板（4 选项卡）        | 纯新手（无项目）或用户求助 |
| `compact` | 不渲染面板，但保留节点提示徽标 + 轻引导 | 轻度 / 有项目用户（默认）  |
| `off`     | 走标准流程，无引导                      | 老手                       |

**开关判定**：

- 无历史项目 → 默认 `full`
- 有历史项目 / 多次交互 → 默认 `compact`
- 用户说"我是老手 / 跳过引导" → `off`
- 用户说"介绍 / 怎么用 / 我需要帮助" → 强制 `full`（单次）

---

## 二、轻引导（默认，打开工作台 / 新建项目即现）

无论新手老手，在**打开工作台**或**新建项目**的第一条回复，先给一段轻引导（不超过 6 行），不弹面板、不阻塞：

```
🧭 AI 尽调总控已就绪。把对公授信尽调从建项→报告全自动编排，你只管说目标。

你可以直接说：
· 对【XX公司】发起尽调         → 新建全流程
· 继续上次项目                  → 断点恢复
· 查项目进度                    → 看七步走到哪
· 做一项专项分析（画像/行业…）  → 定向产出

下一步，告诉我企业名或选一项即可 👇
```

轻引导之后，正常进入对应流程（建项 / 恢复 / 查询），不再追问。

---

## 三、完整引导面板（按需，用户求助 / 纯新手时）

仅当用户说"这是什么 / 怎么用 / 介绍 / 我需要帮助"，或纯新手无项目时，在第一条回复渲染 4 选项卡面板（点击切换）：

### 选项卡 ① 这是什么

AI 尽调流程总控，帮你把"对公授信尽调"从建项 → 进件 → 分析 → 报告 全流程走完。它是银行对公信贷的 AI 助手：你要做的就是把目标说出来，其余交给它编排。

### 选项卡 ② 怎么用（三步上手）

第一步：告诉我"要对 XX 公司做尽调"（或点胶囊「发起尽调」）
第二步：把进件材料拖给我（营业执照 / 财报 / 征信 / 流水等）
第三步：我逐步产出分析，你在每个【需要你确认】的地方拍板即可
补充：支持"继续上次项目"断点恢复，随时说"继续"就能接着做。

### 选项卡 ③ 支持什么场景

见下文"五、场景清单"。

### 选项卡 ④ 我要做什么（快速入口 · 可点即发）

> 以下按钮与首页快捷胶囊共用同一份 `prompt`，点击即注入对话、加载 `dd-full-process` + `aidd-saas`，真实可用。

- **〔发起全新尽调〕** → `我要发起一个全新的对公授信尽调，请帮我开始完整的尽调流程，先从确认目标企业开始。`
- **〔继续已有项目〕** → `继续上次那个尽调项目，从上次停下的地方接着做。`
- **〔查看项目进度〕** → `看看我现在有哪些尽调项目，每个项目做到哪一步了。`
- **〔修改已有报告〕** → `我要修改一个已有的尽调报告，请帮我定位报告并告诉我可以调整哪些部分（段落、结论、风险等级等）。`
- **〔先听听我能做什么〕** → `我想了解一下 AI 尽调能做什么、怎么用、支持哪些场景，给我一份引导说明。`

## 四、新手引导胶囊（首页快捷入口）

首页「新手引导」场景提供 4 个快捷胶囊，与下方快捷命令共用同一份 prompt：

- **系统介绍**：fetch 读取 https://aidd-saas.txfc.cloud/guide/system-intro.html → 总结核心能力与七步流程 → 打开工作台查项目列表 → 介绍使用方法后继续对话
- **示例项目演示**：list_projects 传入 search 搜索「某能源科技」定位示例项目（项目列表输出不含 demo 标记，需按企业名称匹配）→ present_files 打开项目工作台 → 输出详情与建议任务 → 引导逐步执行风险分析旅程；无匹配则引导走「快速体验」新建
- **快速体验（在线尽调）**：从备选公司（无锡烨隆精密机械/君乐宝乳业集团/博瑞生物医药（苏州）/中润光能（江苏中润光能科技）/比格披萨（北京比格餐饮）/金桥德克新材料/南京海纳医药科技/苏州锦艺新材料科技/巴奴火锅（巴奴国际）/惠科股份）创建项目 → 基于公开数据逐步执行画像/财务/经营/行业/风险分析；非上市或披露不足的企业，数据缺失环节据实给"公开信息有限"结论
- **注册与登录指引**：fetch 读取 https://aidd-saas.txfc.cloud/guide/auth-guide.html → 总结注册登录步骤 → 引导进入工作台

> 注意：`/guide/` 静态页不在 create_embed_code 白名单内，必须用完整 URL（https://aidd-saas.txfc.cloud/guide/...）fetch 读取，不要在回复里输出裸相对路径。

## 五、场景清单（轻量罗列）

- 🆕 新建对公授信尽调 — 从零建项到最终报告（新客户 / 新授信）
- 🔁 续作 / 增额尽调 — 老客户新增额度（财报 + 流水）
- 🔍 专项分析 — 画像 / 财务 / 经营 / 行业单项深度（对应材料）
- ⚠️ 风险排查 / 贷后预警 — 快速风险扫描（基础信息）
- ⚡ 无材料快速研判 — 公开数据先行（首贷 / 预评估）

## 六、专业术语释义（首次出现附一行白话）

| 术语          | 白话解释                                                            |
| ------------- | ------------------------------------------------------------------- |
| stage / S1~S7 | 尽调拆成 7 步进度条：建项→进件→财务→分析→专项报告→风险总览→最终报告 |
| P0 / P1       | 财务核验两道关：P0 对齐格式，P1 核对三表勾稽                        |
| riskOverview  | 所有分析里的风险汇总成一张清单，去重、分级                          |
| complete 确认 | 你点头"结论可用"，系统才当正式结论                                  |
| 带风险继续    | 问题暂无法解决，你确认"可接受风险先往下走"                          |
| 进件材料      | 客户原始资料（执照/财报/征信/流水），分析依据                       |

## 七、关键节点提示徽标（贯穿全流程）

每个环节「当前环节」区追加一行，明确这步谁来做：

| 徽标              | 含义                         | 出现环节           |
| ----------------- | ---------------------------- | ------------------ |
| 🤖 系统自动       | 系统自动完成，无需操作       | 材料解析、勾稽计算 |
| 👤 需要你确认     | 已产出，需你拍板采纳         | 结论、风险等级     |
| 📎 需要你补充     | 缺材料，需你上传             | 进件不齐、财务缺失 |
| ⚠️ 需要你判断风险 | 有风险项，评估可否带风险继续 | 勾稽差异、高风险项 |
| ✅ 已完成可继续   | 本环节闭环，可推进           | 各环节完成后       |

格式：`📍 本环节提示：👤 需要你确认 企业画像结论与风险等级`

---

## 八、与现有架构的兼容

- 引导层是总控专家的横向扩展，不侵入专项 Skill 分析逻辑。
- 轻引导默认即现、不阻塞；完整面板仅按需展开。
- 数据获取严格"MCP 优先、禁网页搜索"；引导只输出文案与选项，不新增数据源。
