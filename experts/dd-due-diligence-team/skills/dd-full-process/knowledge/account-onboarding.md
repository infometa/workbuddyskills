# 账号开通与 MCP 授权引导（Account Onboarding）

解决「用户没有 aidd-saas 账号 / MCP 授权失败 / 授权过期」时的引导，让用户按正确路径开通账号并完成授权。

## 触发条件

以下任一情形，优先走本引导：

- MCP 工具调用返回未认证 / 401 / 授权已失效（**任何 aidd-saas MCP 工具都可能触发**）
- 用户说"没有账号 / 怎么注册 / 怎么开通 / 连不上 / 无法授权 / 授权失败 / 授权过期 / 让我重新授权"
- 用户完成注册等待审核后回访（引导状态查询）

## 授权过期 / 401 时的引导（核心场景）

**任何 aidd-saas MCP 工具返回 401 / 未认证 / 授权失效时，一律按此处理**：

1. **打开 MCP 连接指引页（产物方式）**：`present_files({ url: "https://aidd-saas.txfc.cloud/guide/mcp-guide.html" })`，请用户在右侧面板按页面步骤重新授权（删除旧连接 → 重新连接 → 完成登录与 OAuth 授权）
2. **未开通账号时**：若用户尚未注册，先用 `present_files({ url: "https://aidd-saas.txfc.cloud/guide/auth-guide.html" })` 展示注册登录指引，引导开通账号
3. **授权完成后**：告知用户重新发起对话即可继续使用，等待用户回复

## 授权 Buddy 失败 / 无账号时的引导

**用户授权 Buddy（应用）失败、或当前无账号时，按此处理**：

1. **打开授权处理指引页（产物方式）**：`present_files({ url: "https://aidd-saas.txfc.cloud/guide/buddy-auth-guide.html" })`，请用户在右侧面板查看处理步骤与截图
2. **核心动作**：引导用户**取消/断开对「AI 尽调助手」的授权** → **关闭当前页面** → 等账号状态正常后**从 WorkBuddy 客户端重新进入** → 系统会**重新弹出授权登录页** → 完成授权
3. **无账号场景**：当前无账号无法授权时，关闭当前页面 → 申请账号（`/login?mode=register`，用户名建议手机号）→ 等管理员审核（一般 1 个工作日内）→ 审核通过后按取消授权步骤重进并授权
4. **明确提示**：告知用户「取消授权后，重新进入 WorkBuddy 就会重新弹出授权登录页面」

## 引导话术模板

用户没账号 / 授权失败时，按此结构回复（控制在 6 行内，避免冗长）：

```
使用「AI 尽调助手」需要先完成连接授权，两步即可：

1️⃣ 我在右侧打开了《MCP 连接指引》👉 按页面步骤删除旧的 AI 尽调助手连接，
   重新发起连接并完成登录授权。
2️⃣ 还没有账号？先按《注册与登录指引》申请账号（用户名建议用手机号），
   提交后等管理员审核（一般 1 个工作日内），审核通过后再回来连接。

如果提示「账号已绑定其他 WorkBuddy 账号」，请联系管理员解除绑定。
```

> 说明：授权/注册指引页均为公开静态页，**必须用 `present_files` 打开完整 URL** 展示给用户，不要在回复里输出裸相对路径。账号开通页 `https://aidd-saas.txfc.cloud/guide/guide.html` 仅在用户需要完整开通流程时打开。

## 状态识别与跟进

- 用户说"已提交申请" → 引导等待审核，可提示"审核通过后回来跟我说一声，我带你完成授权"
- 用户说"审核通过了" → 引导按 mcp-guide.html 步骤重新授权，并说明完成后就能正常调用尽调功能
- 用户卡在授权页（/oauth/authorize）→ 提示先登录；没有账号则引导申请
