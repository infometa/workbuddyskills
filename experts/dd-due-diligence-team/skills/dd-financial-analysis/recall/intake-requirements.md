# 财务分析进件材料要求

## 结论先行

仅凭一份当期三表无法生成标准版报告。完整执行业务规则至少需要“最近三个完整年度 + 最近一期 + 上年同期”的三表、各期平均余额所需的期初资产负债表、完整附注，以及税务和银行流水等外部验证材料。

## A. 基础必需材料

| 材料                               | 最低时间范围                                       | 支持内容                                         |
| ---------------------------------- | -------------------------------------------------- | ------------------------------------------------ |
| 盖章资产负债表、利润表、现金流量表 | 最近 3 个完整年度、最近一期、上年同期              | 三张财务简表、同比、偿债/营运/盈利/成长指标      |
| 最早年度计算基期                   | 再前一年年末资产负债表，并至少提供该年收入和净利润 | 第一年度平均余额及收入/利润增长率                |
| 完整审计报告及附注                 | 对已经审计的年度逐年提供                           | 审计意见、会计政策、合并范围、科目明细和或有事项 |
| 企业盖章/审计签章页                | 与对应报表一致                                     | 资料有效性核验                                   |
| 营业执照、企业/产品介绍、收入分部  | 当前有效版本及报告期                               | 行业分类、商业模式和收入来源                     |
| 有息债务和利息明细                 | 覆盖全部分析期间及未来到期日                       | 利息保障、融资成本和到期压力                     |
| 授信申请资料                       | 本次申请                                           | 用途、金额、期限、还款来源、担保安排             |

三张报表必须统一企业主体、合并/单体口径、会计准则、币种和期间。口径变化需提供书面说明及可比口径数据。

抽取时每个期间还必须登记财务报表单位、币种、合并/母公司口径，以及利润表/现金流量表实际覆盖起止日和天数。税表、流水、发票汇总等外部数据若使用不同单位，必须逐表单独登记，不能默认沿用财务报表单位。

## B. 标准报告必需的附注明细

| 材料                           | 关键字段/证据                                                      |
| ------------------------------ | ------------------------------------------------------------------ |
| 应收账款明细                   | 期初期末、账龄、逾期、前五客户、关联方、坏账准备、期后回款         |
| 存货明细                       | 原材料/在产品/产成品或行业特有分类、库龄、盘点、跌价准备、期后销售 |
| 预付及其他应收明细             | 对手方、账龄、用途、关联关系和回收安排                             |
| 固定资产/在建工程/无形资产台账 | 原值、折旧摊销、资本支出、工程进度、验收和转固                     |
| 现金及受限资金证明             | 银行余额、受限原因、期限和权利人                                   |
| 借款、租赁和授信清单           | 金融机构、余额、利率、起止日、还本付息、担保、逾期                 |
| 对外担保、诉讼和或有事项       | 对手方、金额、进展、可能损失和会计处理                             |
| 关联方和资金占用明细           | 交易性质、余额、定价、账期及回收情况                               |
| 非经常性损益明细               | 政府补助、投资/处置、公允价值、营业外收支及扣非净利润              |
| 主要客户/供应商、合同和订单    | 集中度、结算条款、收入确认、履约/验收和在手订单                    |

## C. 真实性与交叉验证材料

以下材料是完整执行 Excel “外部交叉验证”规则所必需；缺少时只能写“未执行该项验证”。

- 同期增值税申报表、企业所得税申报表、完税证明。
- 同期全部主要经营账户银行流水、银行对账单和余额证明。
- 销项/进项发票明细、主要合同、订单、出库/物流/验收和回款记录。
- 工资表、个税、社保申报及缴费材料。
- 水电气账单、产量/工时等经营数据（适用于成本与产能验证）。
- 工商年报和企业征信；必要时补充司法、执行和监管信息。

## D. 行业对标材料

行业数值不得由模型记忆生成。每组基准需记录：行业分类标准及层级、指标定义、样本范围、统计年度、均值/中位数/分位数或可比公司值、发布机构和来源链接/报告页码。

可接受来源包括银行已授权的 Wind/iFinD 等数据库、国家/行业协会统计、券商研报及可比公司公开年报。基准年度或口径与企业不一致时不得直接比较。

## E. 行业条件材料

| 行业        | 追加材料                                                 |
| ----------- | -------------------------------------------------------- |
| 制造业      | 产能产量、BOM/成本台账、水电气、存货盘点、在建工程和转固 |
| 贸易        | 上下游合同、发票、物流、资金闭环、终端客户和应收账龄     |
| 建筑施工    | 项目合同、进度/监理签证、结算、合同资产负债、垫资和回款  |
| 房地产      | 预售/网签、监管账户、项目货值与去化、合同负债、项目融资  |
| 科技/互联网 | 研发立项、人员工时、费用/资本化底稿、履约和验收依据      |
| 农业        | 生物资产盘点估值、土地/养殖资料、产销记录和现金销售台账  |

## F. 材料分级与降级输出

- **完整分析**：A-D 均具备，并按行业补齐 E。
- **标准财务分析**：A+B 具备；行业数值对标和外部真实性验证可标为未执行。
- **有限分析**：只有三表、期间不足或外部验证材料缺失。先用全部已有材料完成可计算的三表、趋势、指标、风险线索和审慎结论，再披露不可计算项、材料缺口和结论边界；不得只返回缺件清单。Word 开头简列补件类别，结尾完整列出具体补充资料及当前影响。报告必须为 `verified: false`，不得冒充标准报告或给出强结论。
- **停止并重抽**：已提供材料能够勾稽但抽取结果出现 critical 不平；先核对单位、符号、合并口径和漏项。

## G. 缺件获取路径

| 缺件                     | 可公开补充                               | 仍需企业/银行提供                        |
| ------------------------ | ---------------------------------------- | ---------------------------------------- |
| 年报、季报和重大异动附注 | 交易所、法定披露平台、企业官网的公开文件 | 未公开底层台账和管理口径说明             |
| 应收账款质量             | 公开账龄、坏账准备、前五大及关联披露     | 逐户明细、逾期原因、期后回款             |
| 存货质量                 | 公开分类、跌价准备和减值说明             | 库龄、盘点底稿、期后销售                 |
| 债务与受限资产           | 公开借款余额、担保和受限资金披露         | 合同条款、逐笔到期、还款安排和抵质押底稿 |
| 行业基准                 | 政府统计、协会、授权数据库、可比公司财报 | 银行内部行业参数和未授权数据库内容       |
| 税务                     | 公开税率、优惠和财报税费                 | 申报表、完税证明、应纳税所得额           |
| 发票与交易链             | 公开重大合同和经营公告仅作背景           | 发票底账、订单、出入库、物流和验收       |
| 银行流水与资金证明       | 无                                       | 流水、对账单、余额和受限证明             |
| 授信方案                 | 无                                       | 用途、金额、期限、还款和担保安排         |

公开资料增强只补充“可公开补充”部分，不能据此删除右栏缺件。默认 `auto-enrich` 仅搜索首次计算确认会影响报告的公开缺口；用户要求不联网时使用 `provided-only`，明确要求全面研究时使用 `full-research`。
