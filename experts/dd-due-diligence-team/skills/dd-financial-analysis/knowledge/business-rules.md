## 2. 确定性计算范围

`calculate.py` 必须计算并留痕：

- 盈利：毛利率、销售净利率、ROA、ROE、成本费用利润率。
- 营运：应收/存货周转率与天数、流动/总/固定资产周转率、应付周转天数及现金转换周期。
- 偿债：流动、速动、现金比率，营运资金，资产负债率，产权比率，利息保障，权益乘数，负债与有形净资产比率。
- 成长：营业收入、净利润、总资产和净资产增长率。
- 现金流：销售回款率、CFO/流动负债、全部负债/CFO、自由现金流、现金储备、CFO/总资产和利润现金转化。
- 结构与质量：应收/存货/预付占资产、流动负债占比、扣非净利润、非经常损益贡献、客户集中度和账龄占比。
- 规则：期间变化、行业基准差异、税务/流水/工商差异和所有硬阈值命中。
- 异动（P3，输出于 `statement_changes`）：近三个连续完整年度三表科目金额、最近年度同比 `yoy_change`、跨三年复合变化 `compound_change`、绝对变动 `abs_change`。显著异动 `significant_items` 需同时满足纵向双重过滤——同比绝对变动超过 `threshold`（默认 15%）且绝对变动金额过 `abs_threshold`（`passes_abs_gate=true`），以剔除小基数放大比率的噪声。分级 `severity`：`mild`（|同比|∈[15%,30%)）、`severe`（|同比|≥30% 或关注科目由正转负 `direction_reversed=true`）。有合格行业基准时把相关比率 `outside_two_std` 挂到科目 `horizontal`，纵向显著且横向 `outside_two_std=true` 时 `dual_trigger=true`（高风险）。`attribution` 给出确定性归因：`dupont`（ROE=净利率×总资产周转率×权益乘数）与 `profit_cash_divergence`（`cfo_to_net_profit`、`low_earnings_quality`）。最近一期为中期时异动终点使用最近完整年度；对命中科目匹配 `note_details`，由脚本计算明细占比和对科目变动的贡献。绝对额门槛可由输入 `statement_change_abs_thresholds`（键为 `bs_`/`inc_`/`cf_` 前缀或具体 fact key）覆盖，未提供时用默认值。

平均余额指标优先读取每期 `opening_balance_sheet`。缺少期初值时不得用期末值替代。

## 3. Excel 阈值信号

脚本输出 `rule_signals`，只说明条件是否命中，不生成综合评分或风险等级。LLM 必须结合行业、企业阶段和证据解释。

| 规则 ID | 机械条件                                                |
| ------- | ------------------------------------------------------- |
| BR-P01  | 销售净利率连续 3 个年度低于 5%                          |
| BR-P02  | 当期毛利率低于 20%                                      |
| BR-P03  | 毛利率连续下降                                          |
| BR-S01  | 当期流动比率低于 1.5                                    |
| BR-S02  | 速动比率连续 2 个年度低于 0.8                           |
| BR-C01  | CFO 连续 2 个年度为负                                   |
| BR-C02  | 现金及现金等价物/总资产低于 10%                         |
| BR-O01  | 最近完整年度应收账款周转率低于 4 次或 DSO 高于 90 天    |
| BR-G01  | 营业收入增长率连续 2 个年度低于 5%                      |
| BR-Q01  | 应收账款/总资产高于 20%                                 |
| BR-Q02  | 存货/总资产高于 15% 且应收/总资产高于 5%                |
| BR-Q03  | 预付款项/总资产高于 10%                                 |
| BR-Q04  | 净利润为正而 CFO 为负                                   |
| BR-Q05  | 前五大客户应收占比高于 50%                              |
| BR-Q06  | 一年以上应收占比达到或高于 10%                          |
| BR-X01  | 财务收入与增值税申报收入差异高于 20%                    |
| BR-X02  | 银行流水回款率低于 70%                                  |
| BR-I01  | 企业毛利率变动相对行业毛利率变动均值超出正负 2 个标准差 |

规则表中未覆盖的区间只返回比较结果，不擅自补充标签。对 Excel 写明严格“大于”的上界，等于阈值时返回 `equal_upper_threshold`，不并入“高于”区间。大于阈值也不等于正常，例如高现金可能受限，高毛利可能源于一次性确认。

## 4. 行业对标与交叉验证

行业基准仅在 `industry_benchmarks` 提供行业分类、统计年度、样本口径及可核验来源时计算。统计年度必须与报告使用的最近完整年度一致，比例统一用小数口径；错年或比例尺度异常时脚本拒绝比较。脚本计算企业指标相对均值、中位数、优秀分位、较差分位和可比公司的差异率；标准差必须为正数。毛利率正负 2 个标准差规则比较的是“毛利率变动”，不是毛利率绝对水平。LLM 解释定价、成本、费用、资产模式和增长来源。

### 4.1 行业基准来源（全自动，不经人工填写）

行业基准由**后端全自动解析**，不再要求用户或 Agent 填写行业分类与基准数值。
取数由后端直连联网检索（TokenHub）完成 —— 该链路是 headless 的（企业档案落地即预热，
此时还没有任何 Run/turn 可挂靠），因此不经 Agent、也不经 MCP：

| 环节     | 取值规则                                                                                                                                                                                                                                                                |
| -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 对标行业 | 取项目**企业档案** `company_info.industry` 的**最细粒度分段**（按 `>` 等层级符切分后取最右段）。例：「制造业>食品制造业>方便食品制造>速冻食品制造」→「速冻食品制造」；「制造业>电气机械和器材制造业>电池制造」→「电池制造」。不做行业代码映射——联网检索用的是中文行业名 |
| 基准年度 | 取铺底材料的**最近完整年度**。材料含中期（如 2025H1）时仍取最近完整年度（2024）——同业基准是年度口径，与中期数据不可比                                                                                                                                                   |
| 样本     | 同小类 A 股上市公司，目标 10 家。取数分两阶段：①检索确定候选池（本企业年报点名同业优先 ∪ 行业代表性公司）②**逐家单独检索**原始三表科目，允许部分失败                                                                                                                    |
| 基准数值 | 由 `scripts/peer_benchmark.py` 从各家**年报原始三表科目**计算 mean/median/p25/p50/p75/std_dev                                                                                                                                                                           |
| 缓存     | 按「分类标准 + 行业小类 + 年度」缓存 90 天（不含租户/项目，全平台同行业共享）。企业档案落地后即自动预热，用户点进同业对标通常直接命中                                                                                                                                   |

**分析 Agent 与本链路无关**：基准由后端算好后注入 baseline，Agent 只消费 `baseline.benchmark`，
不得自行检索同行、不得编造基准数值。baseline 里没有 benchmark 时直接标 `limited`。

**检索侧只提供原始科目，禁止提供比率**：分位数与所有比率一律由脚本计算（「确定性的归代码，语义性的归大模型」）。

**必须取原始科目，禁止采用年报披露的现成比率**：年报「主要会计数据和财务指标」中的净资产收益率是「加权平均」口径（证监会规定），资产负债率部分行业按「剔除预收款」口径披露，毛利率可能是分部口径——与本 Skill 的「净利润÷简单平均净资产」「负债合计÷资产总计」不同。混用会造成「同行加权口径 vs 本企业简单平均口径」的错配，使对标失真。样本口径同时必须与本企业配对：取合并口径的「净利润」「所有者权益合计」，**不是**「归属于母公司…」。

### 4.2 样本量门槛与降级

| 有效样本 | 输出                              | 状态      |
| -------- | --------------------------------- | --------- |
| ≥10 家   | 均值、中位数、P25/P50/P75、标准差 | `ready`   |
| 5-9 家   | 仅均值与中位数，不输出分位数      | `limited` |
| <5 家    | 不做数值对标，不得补数            | `limited` |

样本剔除规则（由脚本执行，不插补）：ST/\*ST/退市整理期、上市不足一个完整会计年度、当年重大资产重组、非标审计意见、标的企业自身、4 个指标在目标年度未能全部算出（含缺上年末资产负债表导致平均余额不可算）。

主样本**不做规模裁剪**——分位数须反映行业真实分布，按营收区间硬筛会让 P25/P75 失真；样本量级差异通过 `sample_revenue_profile`（营收 min/median/max）标注。

### 4.3 行业未命中与年度错配

- 企业档案缺行业分类或分类未映射到标准分类：P4 标 `limited` 并提示补全企业档案，**不猜测行业**。
- 小类未收录时逐级上溯（小类 → 大类 → 门类），并以 `match_level` 标注降级程度，提示「对标口径较粗」。
- 基准年度与企业最近完整年度不一致：标 `limited` 并提示「跨年对标仅供参考」，不静默按同年处理。

外部验证使用同期间、同主体、同口径数据：

- 营业收入 vs 增值税申报收入。
- 营业收入 vs 银行经营进账/销售回款。
- 利润总额 vs 应纳税所得额、所得税费用和实缴税款。
- 营业成本 vs 水电气/产量的趋势；没有多期经营量时不判断相关性。
- 工资 vs 社保仅列差异，必须考虑缴费基数和法定费率。
- 资产总额 vs 工商年报，必须对齐年末和合并/单体口径。

差异只能形成核验信号，不能直接认定虚增收入、两套账或造假。

## 5. 已消解的规则冲突

- **维度数量**：Excel 文本称“四大维度”但实际列出盈利、营运、偿债、成长、现金流五类；脚本按五类计算，Word 指标表按四个分析能力分组展示，并把现金流放入偿债/现金流分析。
- **杜邦分析**：Excel 未给完整公式。脚本提供销售净利率、总资产周转率、权益乘数及其乘积；只有三者均可算时才输出杜邦 ROE，不凭空补项。
- **速动比率**：按 Excel 明示口径 `(流动资产-存货-预付款项)/流动负债`，不照抄 Word 示例值。
- **ROA/ROE**：按 Excel 使用平均总资产/平均净资产。若银行另有“总资产报酬率”EBIT 口径，须作为独立政策字段提供，不与 ROA 混用。
- **现金储备**：统一为现金及现金等价物/总资产；Excel 后文写成 CFO/总资产的项目另命名 `operating_cash_to_assets`。
- **DPO/CCC**：Excel 未定义 DPO。脚本只在提供采购额时按 `报告期天数/(采购额/平均应付账款)` 计算；没有采购额则 CCC 不可计算，不用营业成本静默替代。
- **全部债务与资本支出**：“全部债务/CFO”按负债合计计算；需要有息债务口径时使用独立指标。FCF 的资本支出取现金流量表“购建固定资产、无形资产和其他长期资产支付的现金”。
- **主营业务利润**：只有材料明确披露 `core_business_profit` 才计算贡献度，不用营业利润或毛利静默替代。
- **净利润增长**：为避免亏损基期导致方向颠倒，标准报告使用 `(本期-上期)/|上期|`；脚本在公式和限制中明确记录。
- **最近一期**：不自动年化。同比只与上年同期比较，平均余额用当期期初和期末。
- **中期比较缺口**：找不到 `prior_year_same_period` 时同比保持不可计算，不允许退回最近年度或任意上一期。
- **连续年度规则**：连续 2 年/3 年规则必须对应相邻完整年度且每个期间数值均可计算；缺期或 `null` 时返回不可计算，不能跳过缺失年度拼接。
- **周转阈值**：标准表保留最近一期未年化周转率，但“每年 4 次/6 次”的规则信号只评价最近完整年度，避免用季度值直接套年度阈值。
- **周转天数**：DSO、DIO、DPO 的分子使用各期 `period_days`；年度可为 365/366 天，中期用实际覆盖天数。脚本不自动年化。
- **负权益与无效分母**：平均净资产、期末净资产或有形净资产非正时，ROE、产权比率、权益乘数或负债与有形净资产比率保持不可计算，不输出看似精确但经济含义失真的比率。
- **勾稽容差**：只按披露单位的舍入精度设置绝对容差，不使用按报表规模放大的百分比容差；汇率影响缺失不能按零处理。脚本另列货币资金变动与现金净增加额的差异，并核对相邻完整年度及当前中期期初余额与上一年末余额的衔接；因现金等价物或重分类口径可能不同，这两类先作为 warning 交由 LLM 查附注解释。
- **外部单位**：税务、流水等外部数据必须通过 `table_units.cross_validation` 明确自身单位，不能沿用财务报表单位进行猜测。
- **异动阈值与门槛**：P3 显著异动采用“变化率阈值 + 绝对额门槛”双重过滤，避免对比期接近零时小额变动放大成夸张比率；两者均由脚本判定，`abs_threshold` 优先取输入 `statement_change_abs_thresholds` 的精确 fact key，其次前缀，最后默认值。轻/重度分级与方向逆转（盈转亏、CFO 转负、权益侵蚀）判定固化在脚本，LLM 不得改判。
- **异动双判据**：纵向（自身比）与横向（同业比）分别由 `significant` 与 `horizontal.outside_two_std` 表达；只有同时命中才置 `dual_trigger=true`。无合格行业基准时横向判据为 `null`，只按纵向识别，不得用模型知识补同业分位。
- **异动归因**：`attribution.dupont` 与 `profit_cash_divergence` 是脚本给出的确定性分解，LLM 据此定位主因，不得自行重算杜邦乘积或利润现金转化比。
- **行业冲突**：贸易等行业的特殊特征优先于通用阈值解释；通用阈值仍作为规则命中保留，但不得机械下结论。
- **行业数据**：不得按模型知识推断数值；无可靠来源即留空。行业基准由后端自动解析注入（见 4.1），Runtime/LLM 只消费已注入的 `industry_benchmarks`，不得自行检索同行或编造分位数。

## 6. LLM 解释边界

LLM 负责说明：

- 指标组合和趋势对第一还款来源、债务到期、资产变现和融资需求的含义。
- 可能的业务原因、替代解释及其证据强度。
- 需要核实的合同、附注、台账、流水、税表、发票和访谈问题。
- 贷前落实、授信条件和贷后监控建议。

LLM 不得：

- 心算、估算、反推、年化或自行比较阈值。
- 把阈值命中直接写成造假、违约或风险等级。
- 把行业常识写成该企业事实。
- 使用没有来源的行业均值、分位数或竞争对手指标。
