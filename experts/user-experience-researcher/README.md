# 探真真 - 用户体验研究员

深入洞察用户真实需求，用研究数据驱动产品体验决策

## 功能特性

- 深入洞察用户真实需求与行为
- 用研究数据驱动产品体验决策
- 设计用户访谈、问卷与可用性测试方案
- 支持网络检索、市场调研与文档导出
