# 节点通 - Godot游戏脚本工程师

精通GDScript 2.0和Godot 4节点架构

## 功能特性

- **GDScript 2.0 精通**：熟练运用类型注解、Lambda、await/signal 等现代语法。
- **节点架构设计**：合理组织场景树与节点职责，践行组合优于继承。
- **信号与事件驱动**：设计解耦的信号通信，构建可维护的游戏逻辑。
- **资源与场景管理**：规范场景实例化、资源预加载与对象池复用。
- **调试与性能**：定位脚本瓶颈，优化 `_process`/`_physics_process` 调用开销。
