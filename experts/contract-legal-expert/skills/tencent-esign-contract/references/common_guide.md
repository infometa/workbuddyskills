# 腾讯电子签 — 公共操作指南

本文档为各子 Skill（合同起草 / 合同审查 / 合同发起签署 / 法条法规检索）共享的公共操作指南，由对应 SKILL.md 引用。执行业务前先阅读本文档中的相关章节。

## 鉴权

除「产品引导」外，业务操作前必须鉴权：

```bash
python3 scripts/tencent_esign.py auth-check
```

- `"success": true` → 继续
- `"success": false` → 引导：「请前往 **https://qian.tencent.com/aiSkill** 获取 SIGN-TOKEN，然后粘贴给我。」

收到 Token 后：

```bash
python3 scripts/tencent_esign.py auth-validate <token>
```

验证通过后继续原业务流程。

**错误处理**（任何 API 调用返回错误时，取 `resp["Response"]["Error"]["Code"]`）：

| 错误码 | 处理 |
|--------|------|
| `UnauthorizedOperation` / `AuthFailure` | Token 过期，引导重新获取 |
| 其他 | 展示 `Error.Code` + `Error.Message`，建议调整后重试 |

## 文件上传

```bash
python3 scripts/tencent_esign.py upload /path/to/file.pdf
```

返回 `Response.ResourceId`（多文件返回 `ResourceIds` 数组）。

- 用户给出路径 → `ls` 确认存在
- 只给文件名 → 在当前目录、Desktop、Downloads 查找
- 上传失败 → 展示错误，引导检查格式和大小
- 文件限制：图片 ≤5M，PDF/Word/Excel ≤60M

## 跨技能需求处理

本技能只覆盖自身范围的能力。当用户提出范围外的需求（如起草技能收到审查、签署、法条检索请求），或 `_next_steps` 选项指向其他技能时：

1. 先运行 `python3 scripts/cross_skill.py list` 查看全部技能；若能确定目标能力，直接运行 `python3 scripts/cross_skill.py <能力键>`（能力键：`draft` / `review` / `compare` / `sign` / `law`）获取衔接话术
2. 将脚本输出的衔接话术**原样**回复给用户（包含技能标题、技能包名与安装指引）
3. 不调用本技能范围外的接口，不自行模拟对应能力；具体触发点以本技能私有指南中的「跨技能衔接」章节为准

## 文件下载与迁移

**脚本行为**：导出文件类链接（起草合同 docx、审查批注文件与摘要 Excel、对比批注报告 PDF 与差异明细 Excel）在获取成功后由脚本**立即自动下载**到技能根目录 `downloads/` 下（下载链接为短时效预签名 URL，拿到即下载）。在线预览链接（WebUrl）与签署、法条检索链接**不下载**，保留原样展示。

**失败静默原则（必须遵守）**：自动下载失败对用户**完全不可见**——回退输出的链接文案与没有自动下载功能时**逐字一致**；所有用户可见文案（含获取失败提示、`_next_steps` 菜单）一律沿用改造前的原话术（「刷新链接」等），**严禁出现「下载失败」「重新下载」「自动下载」等字样**；下载失败原因只记录在 stderr，不写入任何给用户的回复。

**输出契约**：

| 字段 | 含义 | 缺失/为空时 |
|------|------|-------------|
| `_downloaded_files` | 已下载文件的本地绝对路径数组 | 本次无文件落地（已回退为链接展示），跳过迁移，按原规则直接输出 |

**向用户输出路径前，必须先把文件迁移到当前会话工作区根目录的 `downloads/` 子目录**：

```bash
mkdir -p "<工作区根目录>/downloads" && mv "<_downloaded_files 中的路径>" "<工作区根目录>/downloads/"
```

- 「工作区根目录」= 当前 agent 会话的工作区路径；无工作区概念的环境使用用户当前项目目录
- 多个文件合并为一条 `mv`（多个源 + 目标目录）
- 迁移成功后，向用户展示**必须是迁移后的最终路径**——将预渲染文案（`_links_md`/`_links_block`/`_links_output`）中的原始路径替换为迁移后的最终路径，其余文案原样保留（这是「预渲染内容原样输出」原则的**唯一例外**）
- **agent 的 `mv` 失败是预期内的回退路径**（沙盒权限、跨设备、只读插件目录等）：脚本侧的下载已经成功（`_downloaded_files` 非空即为证据），失败的是 agent 端的环境限制，不代表脚本无能力。迁移失败时按以下顺序处理（**禁止臆断、禁止向用户解释失败原因**）：
  1. 保留原始路径（即技能目录 `downloads/` 下的路径）展示
  2. 给用户的可执行兜底话术：「文件已下载到脚本目录 `<原始路径>`，如需复制到当前工作区可执行 `cp <原始路径> ./downloads/`」
  3. 严禁说“脚本无下载能力”“下载失败”
- `_downloaded_files` 缺失或为空数组时跳过迁移（说明脚本侧下载也未成功，按各业务的回退规则展示原下载链接）

**文件命名规则**：按「业务名_类型」语义化命名（如 `采购合同_起草合同.docx`、`合同A_审查批注.docx`、`合同A_审查摘要.xlsx`、`合同A_对比报告.pdf`、`合同A_差异明细.xlsx`），同名文件自动加 `(1)(2)` 序号，不会覆盖已有文件。用户选择「刷新链接」时重新执行对应命令即可（脚本会重新调导出接口获取新链接并自动下载，新下载的文件同样按上述规则迁移后展示）。

**🪟 文件卡片渲染（必须调用 `present_files`）**：WorkBuddy 客户端对「本地文件交付」走 **`present_files`** 工具做专属卡片渲染（图标、文件名、大小、可点击下载等均由客户端 UI 负责，agent 不再依赖纯文本路径展示）。**凡是交付本地文件（不论是迁移后的最终路径，还是迁移失败回退使用的技能目录原始路径），均须调用 `present_files` 把这些路径交给客户端渲染**：
- **调用时机**：在交付内容里出现本地文件路径之前（典型场景：审查/对比输出的「📝 批注文件已下载到本地：…」、起草输出的合同文件、对比报告与明细等）。
- **调用方式**：传入本会话上下文里的本地文件**绝对路径数组**（即 `_downloaded_files` 迁移到工作区 `downloads/` 后的最终路径列表；`mv` 失败回退时则用技能目录 `downloads/` 下的原始路径列表）；客户端据此把每个文件渲染成可点击下载卡片。
- **与纯文本路径的关系**：调用 `present_files` 仍按原规则在交付内容里给出路径反引号（如 `` `downloads/采购合同_起草合同.docx` ``）作为兜底描述——但**主展示由 `present_files` 渲染的卡片承担**，纯文本仅作伴随。
- **严禁**漏调 `present_files`（漏调会退化为当前行为：路径只在文本里出现、不渲染卡片，导致用户看不到可下载文件入口，与产品体验不符）；仅在 `_downloaded_files` 为空、`_next_steps` 回退到 20 分钟链接的情形下不做 `present_files` 调用（此时没有本地文件，回退链接由 Markdown 链接承接）。
- **失败静默延伸**：若客户端 `present_files` 调用失败（如工具不可用、路径异常），按下方"在线链接回退"的口径静默交付，不向用户解释失败原因。

## 运行环境

- 命令从技能根目录执行：`python3 scripts/tencent_esign.py <command>`，不可用时回退 `python`
- 导出文件（合同/批注/摘要/对比报告与明细）由脚本自动下载到技能根目录 `downloads/`，agent 负责迁移到工作区 `downloads/`（详见上方「文件下载与迁移」）；仅当自动下载失败时才回退输出 20 分钟有效期的下载链接（文案与原版一致），此时提醒用户及时下载
- Web 预览链接有效期 3 小时，保留展示、不下载
- Token 统一从 `~/.esign-token` 文件读取（由 `auth-save` / `auth-validate` 命令写入，权限 600），不使用环境变量——写入即生效，不存在环境变量旧值遮蔽问题
- 调用起草/审查/对比/法条检索接口时，在 JSON 参数中传入 `"SkillPlatformName":"<你所在的平台名>"`（如 `claude code`、`codebuddy`、`workbuddy`、`qclaw`、`codex`）。脚本会校验：值有效则保留，无效或未传则自动替换为 `"其它"`
