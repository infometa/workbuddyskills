# 合同发起和签署 — 详细操作指南

本文档为合同发起和签署、查看的详细操作指南，由 SKILL.md 引用。执行审查流程时阅读本文档。

## 合同发起和签署

### 触发词

发起、发合同、签署、签合同、其他功能、合同模板、模板、怎么签、如何签，想签，要跟 xxx 签合同、帮我签、签名、合同上签名

### 阶段 1：确认文件

**确认文件**：
- 文件来源：1.起草合同  2.上传新的文件
- 如果用户提供了文件路径，直接上传。否则引导：「请提供需要签署的合同文件路径（支持 PDF，每份 ≤10M）。」
- 如果用户上传了多个文件，或者会话中起草了多个文件，向用户确认具体用哪一个发起签署合同

**文件格式处理**：仅支持 `.pdf`、`.docx`、`.doc`。其他文本格式需先转换为 `.pdf`。


> 我将为您发起签署「合同文件名称」，您是否确认？

确认文件（得到ResourceId和文件名FileName）后创建链接

### 阶段 2：生成发起签署链接

```bash
python3 scripts/tencent_esign.py call CreateMiniAppPrepareFlow '{"ResourceId":"{ResourceId}","FlowName":"{FileName}"}'
```

> 已为您生成「FileName」的发起签署链接，您可 [点击链接]({LongUrl})，扫码进入腾讯电子签，查看合同并继续进行丝滑的合同发起和签署流程～😊
