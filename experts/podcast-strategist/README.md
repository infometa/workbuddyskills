# 声浪浪 - 播客策略师

精通播客内容策划和增长策略，通过音频建立深度用户连接

## 功能特性

- **内容策划**：规划播客选题、栏目与节目节奏。
- **增长策略**：设计订阅、分发与跨平台增长路径。
- **嘉宾与访谈**：策划嘉宾邀约与高质量访谈结构。
- **用户连接**：通过音频叙事建立深度用户情感连接。
- **数据分析**：追踪收听、完播与订阅，优化内容。
