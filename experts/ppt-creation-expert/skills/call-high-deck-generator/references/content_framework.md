# 调研 Query 构造指南与内容组织指南（高拜材料）

本文档为 Agent 在 Phase 2（调研）和 Phase 3（内容组织）阶段的详细参考。

> ⚠️ 高拜材料面向客户高层（一把手/二把手），全程以**宏观、战略视角**组织，弱化技术 benchmark 细节。

---

## 一、调研 Query 构造指南

当用户给出 `{客户}` + `{行业}` +（可选）`{重点项目}` 后，Agent 需要构造高质量的检索 query。

### 构造原则

1. **结构化描述**：query 中明确列出需要调研的维度和期望信息类型
2. **维度完整**：确保 7 个维度在 1-2 次调研中全部覆盖
3. **宏观优先**：强调趋势、格局、政策、战略成果，而非技术参数
4. **时效性要求**：明确要求最近 1-2 年的数据
5. **来源优先级**：优先腾讯云官方资料、行业权威报告（信通院/IDC/Gartner）、客户公开信息（财报/官网）

### 第一次调研 Query 模板（腾讯云 + 行业趋势）

**覆盖维度**：① 腾讯云概览、② 行业角色、③ 行业趋势、④ 场景全景

```
围绕"{客户}所在的{行业}高层拜访"进行系统性深度调研，需要覆盖以下方面：

1. 腾讯云宏观概览（面向高层视角）
   - 腾讯集团组织架构与 CSIG（云与智慧产业事业群）定位
   - 腾讯云全栈技术能力矩阵（AI、安全、大数据、音视频、中间件、数据库、PaaS、SaaS）
   - 自研上云等战略成果与代表性数据（规模、成本节省、能力反哺）

2. 腾讯云在{行业}的角色定位
   - 腾讯云作为{行业}数字化转型"实践者/助力者/连接器"的定位与依据
   - 已服务的{行业}标杆客户（3-5 家，各自合作场景与价值）

3. {行业}宏观发展趋势
   - {行业}当前所处发展阶段、市场判断（最近 1-2 年）
   - 3-5 个核心趋势方向、政策导向、技术演进路线、行业发展共识

4. {行业}重点业务场景全景
   - {行业}的主要业务场景图谱（分领域/分场景，从行业实际业务与发展重点出发）
   - 各重点场景的解决方案概览

请重点关注最近 1-2 年的信息，站在战略/宏观视角组织，优先使用腾讯云官方资料和行业权威报告。
```

### 第二次调研 Query 模板（客户理解 + 重点项目/全场景 + 案例）

**覆盖维度**：⑤ 客户理解、⑥ 重点项目/全场景方案、⑦ 标杆案例

```
围绕{客户}的合作探索进行深度调研：

1. 客户理解（表象→症结→入口）
   - {客户}的业务现状、公开动态、面临的痛点（表象，来自财报/官网/新闻）
   - 这些痛点背后的根本原因（症结，从客户/行业实际出发分析，不预设为"数字化/智能化"，可能是增长/成本/效率/体验/安全/数据/组织/竞争等任意维度）
   - 腾讯云能切入、帮客户解决该症结的合作方向（入口）

2. 重点合作项目 / 行业全场景（按板块三模式二选一）
   【模式A · 用户已指定项目】围绕"{重点项目1}""{重点项目2}""{重点项目3}"逐一调研：各自的背景意义、腾讯云对应方案概要、客户价值/预期收益、需高层决策的关键点
   【模式B · 用户未指定项目】调研{行业}腾讯云能提供的全场景解决方案（分场景，如运营商六大场景）：各场景的定位与子方案要点，并结合{客户}特点给出建议优先推进的 2-3 个场景方向及理由

3. 标杆案例
   - {行业}领域腾讯云公开客户合作案例（至少 2-3 个）
   - 每个案例：客户名称、合作内容、量化成效

请提供可用于高层决策的宏观信息，方案概要不必展开技术细节，突出价值与决策点。
```

### Query 构造的场景化调整

#### 用户未提供重点项目时（走模式 B · 行业全场景）

```
{客户}未指定具体重点项目。请调研{行业}腾讯云能提供的全场景解决方案总览
（分场景，从行业实际业务出发，如运营商六大场景），给出各场景的定位、子方案要点与代表案例；
并结合{客户}的业务特点，给出建议优先推进的 2-3 个场景方向及理由（供高层圈定，不替客户拍板）。
```

#### 首次拜访（无合作历史）时

```
{客户}为首次拜访客户，无既往合作历史。请重点调研：
- 腾讯与{行业}的接触历程、行业洞察
- 已服务的{行业}同行业 2-3 个标杆（用于建立行业共鸣）
不要虚构与{客户}的合作历史。
```

## 二、内容组织详细指南

### 板块一：腾讯云介绍（宏观，目标 5-7 页）

#### 页面 A：腾讯集团组织架构 + CSIG 定位

**信息组织方式**：
```
上半部分：腾讯集团六大事业群组织架构
→ CDG / CSIG / PCG / WXG / IEG / TEG
下半部分：CSIG（云与智慧产业事业群）定位高亮
→ 一句话定位 + CSIG 旗下核心业务（腾讯云、行业解决方案等）
```
**推荐布局**：组织架构树/矩阵，CSIG 用品牌蓝高亮

#### 页面 B：腾讯云全栈能力 + 自研上云

**信息组织方式**：
```
上半部分：自研上云战略成果
→ 自研上云规模（如"突破 X 万核"）、成本节省、能力反哺三大驱动
下半部分：全栈能力矩阵
→ AI / 安全 / 大数据 / 音视频 / 中间件 / 数据库 / PaaS / SaaS
→ 每类 3-5 个关键能力 + 代表数据
```
**推荐布局**：分层色块能力矩阵 + 关键数字突出

#### 页面 C：腾讯云在【行业】的角色定位

**信息组织方式**：
```
三角色并列：
→ 实践者：将客户需求变成技术要求，把握行业趋势形成技术优势
→ 助力者：贴身服务客户，打造行业标杆案例
→ 连接器：连接产业数字化转型（应用/数据/账号/场景连接器）
每个角色配 1-2 个佐证点
```
**推荐布局**：三栏/三角色卡片

#### 页面 D：行业标杆案例速览（可选）

**信息组织方式**：
```
网格卡片（2×2 或 3×2）：
每卡片：客户名 + 行业标签 + 一句话成效（选客户能直接对标的）
```
**推荐布局**：等宽卡片网格

---

### 板块二：行业趋势与理解（宏观，目标 6-9 页）

#### 页面 E：行业宏观趋势判断

**信息组织方式**：
```
上半部分：一句话大判断
→ "{行业}正进入 XX 阶段"（30 字内精准立论）
下半部分：三重驱动
→ 政策驱动 / 技术驱动 / 市场驱动，各一句话
```
**推荐布局**：大字立论 + 三重驱动横向排列

#### 页面 F-H：关键趋势拆解（2-4 页）

**信息组织方式**：
```
3-5 个核心趋势，每个趋势：
→ 趋势名（4-8 字）
→ 趋势描述（1-2 句）
→ 对行业的影响 + 隐含的合作机会

可用趋势卡片（一页放 2-3 个）或趋势时间线（演进路线）
```
**推荐布局**：趋势卡片 / 水平时间线

#### 页面 I：行业场景全景图谱

**信息组织方式**：
```
图谱式布局：
→ 按领域/场景分区（如运营商：自主创新/云网服务/无界安全/人工智能/异构算力/ICT合作）
→ 每个领域下列 2-4 个重点场景
→ 建立"行业全貌"认知，为板块三重点方向铺垫
```
**推荐布局**：分区图谱/网格

#### 页面 J：腾讯对【客户】的理解 ⭐ 核心衔接页

**信息组织方式**：见 `signature_pages.md`「客户理解三栏」。
```
表象（客户/行业痛点）→ 症结（痛点背后的根本原因，从客户实际分析，不预设方向）→ 入口（腾讯云能帮解的合作方向）
底部承上启下："基于以上理解，我们认为可以一起做的事是…"
```
**推荐布局**：三栏对照，入口列须对应板块三重点方向（模式A 对应重点项目，模式B 对应全场景中的建议优先方向）

---

### 板块三：重点合作项目与探讨（需拍板，目标 7-11 页，占比最大）

> 板块三分两种模式：**模式 A**（用户给了重点项目）走页面 K→L→M-P→Q；**模式 B**（用户未给重点项目）走页面 K→L'→M'-P'→Q'。二选一，不混用。

#### 页面 K：合作回顾 / 接触历程（两模式通用）

**信息组织方式**：按合作深度选变体，见 `signature_pages.md`「合作回顾三变体」。

---

#### 【模式 A · 用户给了重点项目】

##### 页面 L：合作蓝图金字塔 ⭐

**信息组织方式**：见 `signature_pages.md`「合作蓝图金字塔」。
```
1 个目标 + 3-4 个业务方向 + N 个场景 + 技术基础（底座）
```

##### 页面 M-P：重点项目逐一展开（每项目 1-2 页）⭐ 主体

**信息组织方式**：
```
每个重点项目四段式：
1. 项目背景与意义（为什么现在做，1-2 句）
2. 腾讯云方案概要（不深挖技术，说清"怎么做"）
3. 客户价值/预期收益（量化优先，如"降本 X%""效率提升 Y%"）
4. ⭐ 需高层决策的关键点（要老板拍板的是什么：资源投入/组织保障/合作范围/时间节奏）

可穿插 1 个代表案例佐证
```
**推荐布局**：上背景+方案，下价值+决策点；或左方案右价值/决策点

---

#### 【模式 B · 用户未给重点项目】

##### 页面 L'：行业全场景解决方案图谱 ⭐

**信息组织方式**：
```
该行业腾讯云能提供的多场景解决方案总览（对标高拜运营商模板"六大场景解决方案图谱"）：
→ 按行业实际业务划分场景（如运营商：自主创新/云网服务/无界安全/人工智能/异构算力/ICT合作）
→ 每个场景一句话定位，图谱式排布
→ 让高层一页看清"腾讯云在本行业能做的全貌"
```
**推荐布局**：分区图谱/网格（一屏容纳全部场景）

##### 页面 M'-P'：逐场景方案概览（每场景 0.5-1 页）

**信息组织方式**：
```
每个场景概览级展开（不深挖技术）：
1. 场景定位（一句话：这个场景帮客户解决什么）
2. 2-3 个子方案要点
3. 代表案例（如有，一句话成效）

⚠️ 概览级即可——高层看全貌，逐场景不超过 1 页
```
**推荐布局**：每场景标题 + 要点 + 案例，卡片式或双栏

##### 页面 Q'：合作探讨（收口）⭐

**信息组织方式**：
```
对标高拜模板"合作探讨"页：
→ 请高层从上述全场景中圈定近期优先推进方向
→ 腾讯云建议优先级：哪 2-3 个场景最适合本客户先落地（附理由，措辞"建议探讨"，不替客户拍板）
→ 下步动作：深度交流 / 联合专班 / 小步 POC（带时间表 + 牵头人）
```
**推荐布局**：左"全场景回顾/建议优先"+ 右"下步动作"；或上建议下动作

---

#### 页面 Q：下步建议 / 合作探讨（模式 A 用）

**信息组织方式**：
```
已有合作 → 行动四件套：
→ 邀请客户走进腾讯做深度技术交流
→ 双方成立合作专班 / 资源保障机制
→ 近期 1-2 个具体 POC（带时间表 + 牵头人）
→ 长期合作探索方向

首次拜访 → 三步法：
→ 技术深度交流 → 小步 POC → 基于打样建立长效机制
```
**推荐布局**：四件套卡片 / 三步递进箭头

---

### 收尾

#### 页面 R：心法金句页（可选）

```
一句体现服务心态/战略判断的金句
（如"上心入定，扮演好能力提供者"——心态思考 + 战法战力）
```
**推荐布局**：大字金句居中

#### 页面 S：致谢页

```
THANK YOU + 日期 + 腾讯/腾讯云双品牌落款
```
**推荐布局**：大留白居中
