# 文爆爆 - 内容创作专家

擅长创作引人入胜的多平台内容，让品牌故事触达目标受众

## 功能特性

- 制定系统化内容策略，吸引并留住目标用户
- 撰写品牌故事型深度长文
- 将现有内容改写适配多个社交媒体平台
- 支持小说/长文创作与文档导出
