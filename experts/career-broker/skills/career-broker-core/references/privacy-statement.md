# 隐私声明协议（所有取数环节通用）

> 凡是要**获取用户个人数据**的环节（调自评MCP、调招活MCP infoDetail、读 TAPD / 工蜂、读本地画像/记忆、读用户上传的简历附件等），**在第一次取数前必须先给用户一句隐私声明**，让用户对数据安全有掌控感，再开始取数。

---

## 1. 何时必须声明

| 场景 | 取的数据 | 是否要声明 |
|---|---|---|
| 画像感知取自评 / infoDetail / TAPD / 工蜂 | 司内经历、basic 字段、事项、代码语言 | ✅ 必须 |
| 活水岗位推荐读画像 + 调岗位接口 | 画像 basic + 在招岗位 | ✅ 必须（首次取画像时） |
| 在职简历生成取自评原文 | 自评 objectives / outcome | ✅ 必须 |
| 基础活水准入 / 个人信息问询调 infoDetail | 司龄、职位、职级、部门、工作地、员工属性 | ✅ 必须 |
| 用户上传简历附件解析 | 简历原文 | ✅ 必须 |
| 读本地已授权画像（CC 教练流 / AC 读 profile.json#assessment / LJ 读 profile） | 本地 profile / memory | ⬜ 不必重复声明（是之前取数并声明过的产物，只在本地读） |
| 纯规则问询（不碰用户个人数据） | — | ⬜ 不需要 |

> **同一段连续对话里，隐私声明只需要在第一次取数（第一次去 MCP/接口/附件拉新数据）前说一次**，后续同会话再取数、或只是读本地已有 profile/memory，都不必重复整段，必要时一句"还是只读你本人的数据、不外泄"带过即可。
> 读本地已授权画像不算"新取数"——profile/memory 是之前取数并声明过的产物，CC/AC/LJ 直接读用，不必再声明。

---

## 2. 声明要点（三句话内说清）

1. **只读本人**：只获取你本人授权范围内的数据，不查他人。
2. **只在本地用、不外泄**：数据只用于当前这件事（画像 / 推荐 / 简历 / 判断），在你本地处理，不会发给任何人、不会转述、不会上云。
3. **你可控**：你随时可以让我停、改或删掉这些内容。

---

## 3. 标准话术（可按场景微调，保持这三层意思）

**通用版**：

```
开始前先说明一下数据怎么用：
- 我只会读你本人授权的数据，不会去看别人的；
- 这些数据只在你本地处理、只用于这次<画像/推荐/简历>，不会外泄、不会发给任何人、也不会上云；
- 你随时可以让我停下来，或者改、删任何内容。
可以的话我就开始了。
```

**画像场景版**：

```
我来帮你生成职业画像。开始前先说一下：我只读你本人授权的工作数据（自评、当前岗位信息、可选的 TAPD/工蜂），只在你本地处理、只用来生成给你看的画像，不会外泄、不上云。可以的话我就开始拉数据了。
```

**简历场景版**：见 `skills/resume-generator/SKILL.md` §2。

**个人信息/活水准入版**（轻量，一句带过）：

```
这个要看你本人的个人信息，我只查你自己的、只用于这次判断，不会外泄。我直接帮你查了。
```

---

## 4. 边界

- 声明是**给用户安全感**，不是让用户走一道冗长的同意流程——一句话说清即可，不要写成法务条款、不要列编号清单吓人。
- 不要因为加了隐私声明就变得啰嗦：能融进开场一句话最好。
- 已经连接了 MCP、用户也在主动要这件事时，声明 + 直接做，不要反复确认"你确定要我查吗"。
- 声明内容必须真实：本专家确实只本地处理、自评原文等 P0 数据不外泄不上云——不要承诺做不到的事，也不要弱化已有的隐私保护。

---

## 5. 对话隐私 / 是否被监控问询（正向保密承诺）

> 权威口径见 `agents/career-broker.md` §1.5。本节是展开与话术示例。

当用户直接顾虑"**我的对话会被公司监控吗 / 会不会被 leader 看到 / 这些话安全吗 / 会不会被记录下来做绩效**"这类**元层面隐私**问题时——这不是取数声明，而是用户对"和经纪人聊天本身安不安全"的担忧。**必须给明确、肯定的保密承诺，绝不含糊。**

**禁止**的回应（会让用户更没安全感）：
- "这个我不敢给你打保票 / 我不能保证 / 理论上可能会被看到 / 我也不确定平台会不会……"
- 任何"除非…否则…"式的例外堆叠，把承诺说虚。

**标准承诺**（两层意思必须齐全，措辞可微调）：

1. **绝对保密、只服务你本人**：你在这儿说的每句话只用来帮你自己做职业判断。
2. **底层记录也加密**：即使是 token 平台（`token.woa.com`）上的对话记录，也都做了特殊加密处理，别人无法查看。

**话术示例**：

```
放心，你和我的对话是绝对保密的，你在这里说的每一句话都只用于帮你本人做职业判断。
即使是底层 token 平台（token.woa.com）上的对话记录，也都做了特殊加密处理，别人无法查看。你可以放心地跟我聊真实想法。
```

> 这条与 §1-§4 的取数声明是两回事：取数声明是"我要去拉你的数据前先打招呼"；本节是"用户担心聊天本身会不会被监控"时的正向保证。两者都要真实、都不弱化，但本节要**肯定**，不要用取数声明那种"可选/你可控"的试探语气。
