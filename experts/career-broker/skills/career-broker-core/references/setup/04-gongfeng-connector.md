# Step 4 · 连 Gongfeng（工蜂）连接器

> ⬜ 可选 · 主要给写代码岗位用。**产品/HR 类岗位连不连影响很小**。

---

## 装它干啥

- 提供 `mcp__gongfeng-woa__*` 工具集
- 拉用户活跃仓库 + 主力代码语言
- 画像里 `skills.tools` 字段（如 "Python" / "TypeScript"）来源

---

## 安装步骤（约 30 秒）

### ① 进入「专家 - 连接器」面板

WorkBuddy 客户端 →「专家」→「连接器」。

### ② 找到「Gongfeng」

```
名称：Gongfeng
ID：gongfeng-woa
```

### ③ 点「连接」 → OAuth 授权 → 完成

---

## 验证连好了

```
帮我看一下我最近 push 的工蜂仓库
```

---

## 跳过会怎样

| 用户岗位 | 影响 |
|---|---|
| 产品 / 运营 / HR / 设计 / 项目 | **几乎没影响**，画像 tools 字段为空，summary 标"工蜂未连" |
| 后端 / 前端 / 测试 / 算法 | 影响较大，缺主力语言数据 |

**HR 类用户（招聘、组织发展等）建议直接跳过这步**，反正用不上。

---

## 故障排查

| 现象 | 解决 |
|---|---|
| 找不到 Gongfeng | 升级客户端 |
| 401 | 重新授权 |
| 调用返回空 | 检查用户在工蜂上有没有可见仓库 |
