# Step 3 · 连 TAPD（司内版）连接器

> ⬜ 可选 · 不连画像也能跑，连了能多一份"做过的需求/任务"细节支撑。

---

## 装它干啥

- 提供 `mcp__tapd-woa__*` 工具集
- 画像感知 skill 用它拉用户在自评周期内的 stories / tasks / bugs
- 给画像里的"业务推进力强"等 trait 提供事项级证据

---

## 安装步骤（约 30 秒）

### ① 进入「专家 - 连接器」面板

WorkBuddy 客户端 →「专家」→「连接器」。

> 注意：TAPD 是**官方内置连接器**，不用进「自定义连接器」，在连接器主列表里找。

### ② 找到「TAPD（司内版）」

主列表里搜索或下拉找：

```
名称：TAPD（司内版）
ID：tapd-woa
```

### ③ 点「连接」

→ 弹 OAuth 授权页 → 同意 → 完成。状态点变绿。

---

## 验证连好了

在 WorkBuddy 主对话输入：

```
帮我看一下我最近 owner 的 TAPD story 有几个
```

应该能正常返回。

---

## 故障排查

| 现象 | 原因 | 解决 |
|---|---|---|
| 「连接器」面板找不到 TAPD（司内版） | 客户端未更新 | 升级 WorkBuddy 到最新版 |
| 连接失败 / 授权页 404 | TAPD OAuth 暂时不通 | 5-10 分钟后重试 |
| 工具调用报 401 | OAuth 授权过期 | 在「连接器」面板点"重新连接" |
| 工具调用返回空 | 用户没有任何参与项目权限 | 让用户先在 TAPD 上加入项目 |

---

## 跳过会怎样

不连 TAPD，画像 skill 仍可跑：
- 主干仍来自自评 MCP
- 但 traits 的 evidence 字段会少"完成 X 条 story"这类硬数据
- summary 里会标注"TAPD 未连，已跳过"

可以先跑画像，发现需要再回来连。
