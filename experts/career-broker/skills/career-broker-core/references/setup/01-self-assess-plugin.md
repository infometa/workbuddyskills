# Step 1 · 连接「自评 MCP」

> 腾讯 HR Tech 提供的**自评 MCP**——本职业经纪人的画像主干就来自这里。

---

## 装它干啥

- 提供 `mcp__自评MCP__listMyAssessments / getSelfAssess / getMyCurrentAssess`
- 拉用户**全部历史自评数据**（KR / Outcome / 重点标记）
- 这是画像的"主干数据源"，**不连画像就只剩 TAPD / 工蜂的事项级细节，质量大打折扣**

---

## 连接方式（推荐：一键授权，约 10 秒）

自评 MCP 已接入 WorkBuddy 一键授权（OAuth，**不需要手填 token、不需要装套件**）：

- **召唤职业经纪人时会自动弹出连接卡片** → 点「连接」→ 走腾讯 SSO 授权 → 状态变绿即可用。
- **一开始跳过了、后面想连**：切到别的对话、再切回这个对话，连接卡片就会自动重新弹出来，点「连接」完成 SSO 授权即可（不用自己进设置里找）。

> 服务端点 `https://self-assess.mcp.it.woa.com`，已在专家 plugin.json 的 `mcpServers` 里声明，所以能自动弹窗。

---

## 兜底方式（旧客户端不支持弹窗时：装套件）

个别旧版客户端不支持一键弹窗，可走「技能-套件」安装：

1. 客户端左侧「技能-套件」面板（**不是**「连接器」）→ 右上角「添加套件」
2. 填地址 `https://cnb.woa.com/hrssc/emp-service` → 点「安装」
3. 装完再去「专家 → 连接器 → 自定义连接器」找到「自评MCP」点「连接」授权

完成后，状态点变绿 = 可用。

---

## 验证装好了

WorkBuddy 主对话输入：

```
请帮我看一下我历年自评有几期
```

应该能正常返回。如果报"工具不存在"或"未授权"，按下面排查。

---

## 故障排查

| 现象 | 原因 | 解决 |
|---|---|---|
| 「技能-套件」搜不到「绩效自评 AI 助手」 | 没填 marketplace 地址 | 用「添加套件」填 `https://cnb.woa.com/hrssc/emp-service` |
| 套件装了但调工具报"工具不存在" | 没在「专家→连接器→自定义连接器」连 | 去那个面板找自评MCP 点连接 |
| 调用报 401 / 403 | 腾讯 SSO 登录态过期 | 打开 https://it.woa.com 重新登录 |
| 状态点是红的 | MCP 服务暂时不可用 | 等 5-10 分钟重试，或联系 HR Tech 团队 |
| 不在公司内网 | mcp 网关访问不到 | 走 SSL VPN 接入内网 |

---

## 隐私说明

- 自评 MCP **只能拉登录用户本人的数据**（staffId 由后端从 SSO 注入，参数侧无法传别人）
- 这个机制天然保证了"画像感知不会误读别人的自评"
