# Step 6 · 连「招活MCP」（一键授权）

> ✅ 推荐 · 不连招活MCP，画像 basic 拿不到当前职位/职级/工作地/员工属性；活水/招聘问询不能查招活知识库，活水机会推荐也没法拉到真实在招岗位列表。

---

## 装它干啥

- 画像阶段用 `get_personal_api_web_personal_infoDetail` 获取当前用户 basic：职位、职级、工作地、员工属性、部门、司龄，以及入司前经历补充
- 问询主要用 `SearchAPI` + `CallAPI` 调 `recruit.recruit-ai-service.search_knowledge`
- 活水机会推荐能力用 `PostAdvancedSearch` 查内部在招职位（含部门/职级/工作地等字段）
- 没它，经纪人不能自动补画像 basic、不能查招活知识库，也只能给方向建议、给不了真实在招岗位

> 技术标识仍是 `recruit-mcp`（mcp.json 里的 key / 工具前缀 `mcp__recruit-mcp__*`），对用户展示统一叫「招活MCP」。

---

## 接入方式（一键授权，约 30 秒）

招活MCP 已经接入 WorkBuddy 一键授权，**不需要申请 token、不需要走审批、不需要手填 mcp.json**。太湖访问凭证由平台一键注入。

有两种触发方式，按你当前在哪儿来：

### 方式一、召唤专家时自动弹出（最常见）

第一次召唤「鹅厂职业经纪人」时，会**自动弹出连接招活MCP 的提示**——直接点「连接 / 授权」，按提示完成即可，不用自己去翻设置。

### 方式二、一开始跳过了，中途想连

如果第一次召唤时点了「暂不连接」、后面又想连——**最简单的办法：切到别的对话、再切回这个对话，招活MCP 的连接卡片就会自动重新弹出来**，点「连接」完成授权即可。

（原理：连接卡是"进入本对话"时自动检测触发的，切走再切回会重新检测未连接的 MCP 并再次弹出。）

### 方式三、切走再切回没弹出来（兜底）

如果方式二切走再切回仍然没弹出连接卡（旧客户端 / 已连过被回收），去「**专家 → 连接器**」面板（不是"自定义连接器"），手动找到「**腾讯招聘**」连接器，点「连接」完成授权即可。

> 招活MCP 在客户端的显示名是「**腾讯招聘**」（技术标识 `recruit-mcp`），在"连接器"主面板里找，不在"自定义连接器"里。

授权完成后状态变绿即可用。

> 如果你之前是手填 token 的老配置（mcp.json 里 `recruit-mcp` 段是明文 Bearer），可以删掉那段改用一键授权；也可以保留，二者不冲突。

---

## 验证连好了

在 WorkBuddy 主对话输入：

```
活水有试用期吗
```

或者直接让经纪人推岗：

```
看看活水现在有什么岗适合我
```

能正常回答活水规则，或能正常返回岗位列表；画像阶段也能自动补当前职位/职级/工作地 = 连好了。

---

## 故障排查

| 现象 | 原因 | 解决 |
|---|---|---|
| 召唤专家时没弹出连接卡 | 客户端版本旧 / 已连过 | 升级客户端；或切走再切回本对话让连接卡重新弹出 |
| 点了「连接」但状态没变绿 | 授权弹窗被拦 / 授权未完成 | 重新点一次「连接」，完成授权流程 |
| 调用报 401 / 403 | 授权过期或被回收 | 切走再切回本对话，让连接卡重新弹出，重新点「连接」授权 |
| 画像 basic 为空 | infoDetail 调用失败或招活MCP 未授权 | 确认招活MCP 已授权后重跑画像 |
| 推荐结果空 | 你的画像职级/职位/工作地/员工属性字段为空，或过滤后无候选 | 先重跑画像感知补完 basic 字段；必要时放宽工作地 |

---

## 跳过会怎样

不连招活MCP，画像 basic 只能靠用户口头补充；活水/招聘问询会尝试小Q兜底，如果兜底也不可靠，经纪人不会凭训练知识编答案。活水机会推荐也会兜底成"只给方向建议、不给具体岗"——具体在招岗位需要真实接口返回。

教练对话 / 测评解读不依赖招活MCP，可正常用。
