## 路由判断伪代码

```python
# §5 已覆盖的基础活水事实（broker-professional-standards.md §5）一律由主入口直答，不进 career-qa / 不调知识库。
# 含：准入资格、流程步骤、保密、调出权限/交接、调动区别、投递数量、绩效归属。
BASIC_LIVEFLOW_ELIGIBILITY_PATTERNS = [
    # 准入资格
    "我现在可以活水", "我是否有资格活水", "我能不能申请活水", "我满足活水条件", "我能入池", "我能活水吗",
    # 发起入口 / 流程 / 步骤
    "活水流程", "活水步骤", "活水分几步", "活水怎么走", "活水要经过", "活水有哪些环节", "活水步骤是什么",
    "从哪申请活水", "从哪里申请活水", "在哪申请活水", "在哪发起活水", "从哪发起活水", "活水在哪申请", "活水在哪个平台", "怎么申请活水", "活水入口",
    # 保密机制
    "leader 会知道", "上级会知道", "原部门会知道", "投递了会知道", "申请阶段谁知道", "leader 会不会知道",
    # 调出部门权限 / 交接挽留期
    "调出部门", "不放我", "不放人", "交接期", "交接多久", "挽留期", "部门能不能不放",
    # 调动与活水区别（替代路径）
    "调动和活水", "转岗和活水", "活水和调动", "调动 活水 区别",
    # 投递数量 / 绩效归属
    "能投几个", "同时投几个", "同时面几个", "面试中几个", "调动绩效", "绩效算谁的", "评估期调动",
]

RECRUIT_KNOWLEDGE_KEYWORDS = ["活水", "入池", "冷却", "匿名池", "内推", "调岗", "转岗", "跨BG",
                              "校招", "社招", "Offer鹅", "智能问询"]

XIAOQ_KEYWORDS = ["年假", "病假", "产假", "工龄", "司龄", "离职流程", "转正",
                  "公积金", "社保", "VPN", "工位", "会议室", "班车", "门禁",
                  "报销", "差旅", "采购", "合同",
                  "新人", "入职", "导师", "带教",
                  "课程", "学习积分", "QLearning", "学堂", "行家"]

def route(query: str) -> str:
    for pattern in BASIC_LIVEFLOW_ELIGIBILITY_PATTERNS:
        if pattern in query:
            return "main_basic_liveflow_eligibility"  # 主入口直答，不进 career-qa
    for kw in RECRUIT_KNOWLEDGE_KEYWORDS:
        if kw in query:
            return "recruit_knowledge"
    for kw in XIAOQ_KEYWORDS:
        if kw in query:
            return "xiaoq"
    return "xiaoq"   # 默认小Q（覆盖广）
```

## 维护规则

- 添加关键词：先判断是否属于基础活水准入直答；是 → 加 `BASIC_LIVEFLOW_ELIGIBILITY_PATTERNS`，由主入口处理；否则再看招聘问询知识库能不能答好；能 → 加 `RECRUIT_KNOWLEDGE`；不能且属于其他职场制度 → 加 `XIAOQ`
- 关键词冲突：基础活水准入直答优先，其次招聘问询知识库（活水/招聘专精）
- 招聘问询知识库 `confidenceLevel=zero` 或明显跑偏时，静默降级小Q；两边都不可靠时不凭训练知识兜底
