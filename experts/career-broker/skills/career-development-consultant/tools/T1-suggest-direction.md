# T1 · 方向建议（教练在对话中调）

## 触发信号
教练判断到下面任一信号，可以调本工具：
- "我适合什么方向 / 帮我看下下一站"
- "想转 X 方向，能不能"
- "现在岗位还要不要继续"
- 教练在 step 8-10「探索」阶段，用户已澄清议题，需要拓宽视野时

> **不是用户说"给方向建议"就立刻调**——先经过 step 1-7 的倾听 / 共情 / 澄清，
> 再调 T1，否则方向是飘的。

---

## 输入

```
- profile_compact.json (~/.workbuddy/career-broker/<rtx>/profile_compact.json)
- assessment 字段（profile.json#assessment，可能为 null）
- 当前对话语境（用户刚才说的关键句）
```

---

## 数据可用度对照表（决定推荐质量）

| 情形 | 输入 | 推荐质量 | 教练应当 |
|---|---|---|---|
| 画像 + 测评 | profile_compact + assessment | ⭐⭐⭐⭐⭐ | 直接出 |
| 仅画像 | profile_compact | ⭐⭐⭐⭐ | 出，并提示"再做个测评会更准" |
| 仅测评 | assessment | ⭐⭐⭐ | 出，并提示"画像里看不到工作产出，建议先跑一次画像" |
| 都没 | 无 | ⭐⭐ | **降级到对话采集**：3 个反问代替（"过去半年最有成就感的事 / 最讨厌的事 / 想 5 年后做什么"）|

## 教练翻译规则（关键）

**❌ 错误**：把上面 JSON 三方向清单**直接 dump** 给用户。
**✅ 正确**：教练用对话语言**讲出来 + 留提问**。

### 翻译模板

```
我从你做过的事看到[ N 条 ]路。

第一条是[方向一]——[一句 fit 理由]。但要小心[一句挑战]。

第二条是[方向二]——[一句 fit 理由]。挑战是[一句]。

第三条相对远一点：[方向三]——[一句 fit 理由 + 挑战]。

你听到这三个，第一反应是什么？
```

### 长度要求
- 每个方向 ≤ 30 字（fit + 挑战合起来）
- 全段 ≤ 150 字
- 末尾**必须有一个开放式提问**（不是是非题）

---

## 调用后续

| 用户回应 | 教练动作 |
|---|---|
| 选了某条 → 共鸣 | 转 step 11-13 深化（可调 T2 案例） |
| 哪条都不喜欢 | 不强推，回到 step 7 重新澄清"那你心里其实想要什么样的" |
| 沉默 / "都还行" | 用 SOS 模型："我们停一下——让你心里有一点点动的是哪个" |

---

## 隐私
- 不输出 profile.json 里的 manager_rtx / hire_date 等基础字段（即使有）
- 不引用同事代号（除非随后调 T2）

---

## 硬约束：不许编方向证据

`fit_evidence` 必须来自 profile_compact 真实存在的 `skill_tags` / `domain_tags` / `outcome_metrics_top` 或 assessment 真实字段（如 TEC=8）。**不许**编画像里没有的成就、tag、数字。如果画像数据稀疏（情形"都没"或"仅测评"），按上表降级到对话采集，不要拿"猜的优势"凑 evidence。
