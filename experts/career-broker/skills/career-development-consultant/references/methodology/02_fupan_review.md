# 《复盘》· 做事复盘方法论蒸馏

> 用途：员工问"我上个项目怎么总结 / 这次没做好想复盘 / 团队怎么开复盘会 / 90天后怎么回看"这类**过程复盘、经验提取**类问题时召回。
>
> **边界提示**：这本书讲的是"做事复盘"，不是"职业选择"。用它来做**行动之后的经验提取**，不用它来做方向选择。

---

## 一句话内核

**怎么让"做过的事"真正变成"长在身上的能力"**——把做过的事再从头过一遍，但知易行难，藏着一整套逻辑。

复盘本质是**面向未来**——不是为总结而总结，是为下一轮铺路。

---

## 核心心智模型（每次复盘都要用）

### 1. 想到—做到—得到（三段差异分析）

```
预期（想到） ← 比较差异 → 结果（得到）
             ↑
           做到（过程）
```

- 现实里"三到"经常断链：**想到做不到、做到得不到、甚至想都不想就开干**。
- 一发现断链就该复盘。
- 联想的口诀：**"提升'瞄着打'的能力"**（立靶子 = 想到，瞄准扣扳机 = 做到，击中靶心 = 得到）。

### 2. 目的 ≠ 目标（全书最锋利的一刀，也是经纪人最该内嵌的心智模型）

|  | 目的 | 目标 |
|---|---|---|
| 比喻 | 一直盯着看的地方 | 眼睛能看到的标志 |
| 特点 | **有意义的模糊**（领先/一流） | **受控制的明确**（具体/可衡量/自己能掌控） |
| 例子 | 博尔特"成为传奇"；助理"去上海" | "破9秒58"；"买高铁票" |

- 助理只盯"买高铁票"（目标）忘了"去上海"（目的），就想不到还能坐飞机。
- **牢记目的才不被目标带偏**。
- 一个目的一套体系（最多 2-3 个目的）。

### 3. 五反机制：`反馈 → 反思 → 反本 → 反应 → 反复`

- **反馈**：把客观结果和当初预期作比较，正视差异。
- **反思**：对差异进行思考。
- **反本**：返回本源，挖根本原因。
- **反应**：针对根因采取行动，光想不做等于零。
- **反复**：循环往复，认知螺旋上升（上一轮结论只是新假设）。

## 复盘 5 硬步骤 + 5 软原则

外圈 5 步骤（招式），内核 5 原则（内功）。

| 5 硬步骤（顺序不能乱） | 5 软原则（态度） |
|---|---|
| 1. 梳理过程 | 开放心态（不刚愎自用） |
| 2. 回顾目标 | 坦诚表达（不欲言又止） |
| 3. 评估结果 | 实事求是（不自欺欺人） |
| 4. 分析原因 | 反思自我（不诿过推责） |
| 5. 总结经验 | 集思广益（不事不关己） |

### 步骤 1：梳理过程（先还原事实，别急着想象）

- 人天生主观、会先入为主陷入想象，不先摆事实，后面分析全建在幻觉上。
- 做法：按"时间为主、业务逻辑为辅"记流水账（抓关键节点）；专人统筹、会前整理成文档；团队互相校正。
- **要避的坑：基本归因谬误** —— 旁观者爱把别人的行为归于"人品"，当事人其实是被"情境"逼的。

### 步骤 2：回顾目标（搭"目的—目标—举措"一致性体系）

- 事分两类：**拥抱随机性的事**（自由探索）别硬套目标；**强化目标感的事**（日常多数工作）认真定。
- 即使当初没定目标，也可"重温初心"找回**目的**。
- 三个要点：① 一个目的一套体系；② 还原不完整体系（靠访谈发起人补"目的"）；③ 重点关注变化点。

### 步骤 3：评估结果

**核心口诀**：无法衡量就无法评估，无法评估就无法管理。

- **难点一：要评估得深** —— 别只看表面目标（"销售没到 1 亿就完了"没用），必须深入**举措层**评估"管住嘴迈开腿"。
- **难点二：把"不可评估"变"可评估"** —— 三种解法：
  - **结果描述法**：几个要素全达成才算成功（阿波罗：时间+载人+登月+返回+安全）。
  - **间接代表法**：易测先行指标代替难测（瓷窑看火焰颜色测温）。
  - **创新指标法**：基于业务洞见造新指标（NPS；面试问"愿不愿和这人一起去旅游"）。
- **单环 vs 双环学习**：
  - 单环：只看目标达没达成（复盘执行力）
  - 双环：追问"这目标当初该不该定"（刷新假设）
- 顺序：**先目标 → 深入举措 → 上堆目的**（先单环后双环）。

**经典案例**：销售超额完成销量，庆功后经理一问"当初为啥定这目标"——目的是"成为领先品牌"，可销量榜前十没他们。**完成了目标，没实现目的。**

### 步骤 4：分析原因（最关键一步）

**思路 A · 看墙（聚焦问题）**：
1. 定义问题（客观描述偏差）
2. 原因分析（**鱼骨图**画两遍，第二遍加当初没想到的因素）
3. 根本原因（**5 个为什么**，逼出隐藏假设；当"因为"后是"认识"而非"行动"就停）
4. 解决方案（双组脑暴防互相批评）
5. 决策判断（**复杂度 × 耗时矩阵**，首选"低复杂 + 短耗时"的捷胜）

**思路 B · 看路（聚焦解决）**：
1. 找亮点（必须是**系统内**成功个案，非外部标杆）
2. 描述亮点（关注"做法"非"想法"）
3. 推广（讲清因果、鼓励创新）
4. 持续点亮（变长效机制）

**取舍**：有条件两组同时做；没条件就**先看路再看墙**（研究特例更简单、更易催生洞见）。

**三个铁律**：
- **仁者如射，反求诸己** —— 失败重点看主观、成功别忘看客观（跟本能相反）。
- 锅甩到企业外，问题就不可解了。
- 解决方案 = 一套新的"目的-目标-举措"体系（绕回步骤 2），执行前都只是假设。

### 步骤 5：总结经验（好复盘的标志是"生成新洞察"）

**判断标准**：复盘前后观点有没有变化？花一下午却"一条新结论都没有"——那基本是失败的复盘。

**洞察力 = 对"核心假设"的三种动作**：

| 动作 | 含义 | 例子 |
|---|---|---|
| 重构 | 改写旧假设 | "可浪费的低成本"→"不浪费的低成本" |
| 放弃 | 抛弃旧假设 | "各部门各自负责数据"→"汇总团队对最终报告负责" |
| 新增 | 补上没想到的假设 | 发现"教会客户用产品"是销售关键 |

**组织结构：事为先，人为重**
- 先理清对"事"的洞见（第一要务），再理清对"自己和组织"的认识（借事修己）。
- 铁律：**事为先的洞察必须有，人为重的可以有**。

**「事为先」四层洞察**（自下而上挖，越往上层影响越大）：

| 层 | 名称 | 定义 |
|---|---|---|
| 4 | **意图** | 究竟想要什么（体系统领） |
| 3 | **目标** | 衡量目的的标尺 |
| 2 | **打法** | 实现目标的策略选择（最易出洞察） |
| 1 | **执行** | 具体做的事、做事诀窍 |

## 关键红线与常见坑

- 复盘会最大的风险是开成**批斗会/甩锅会**——一旦变成追责，没人再说真话。
- 基本导向是**对事不对人**、失败时先反求诸己。
- 别照搬旧经验（"人不能两次踏进同一条河"）——要提炼**洞察力**，不是具体经验。

## 与其他方法论的咬合点

- **想到-做到-得到 → Plan 模式**（上场）：Plan 模式的三段结构与之完全同构。
- **失败归类 → 失败三类免疫**（斯坦福）：斯坦福的"失误/弱点/成长机会"三类归类，是复盘"分析原因"步骤的极简版。
- **目的 ≠ 目标 → 不变量**（上场）：不变量近似于长期"目的"，具体转岗目标是"目标"。
