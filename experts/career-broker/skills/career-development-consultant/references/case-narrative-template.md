# 案例陪伴叙事模板

> 案例库召回后**不是 dump**，要按这个模板渲染成"陪伴式"叙事。
> 调用方：M2 方向建议、M3 教练对话引子。

---

## 模板 A · 完整陪伴（M2 用，1-2 段）

```
有个像你的同事——{code}（{脱敏标签}），他/她{从 X 跨到 Y}。

当时 ta 也在想"{用户当下的核心纠结}"，后来想清楚了一件事：

> "{从 quotes 选 1 条最匹配场景的金句}"

ta 给后来人的话是这样：

> "{advice 截前 1-2 句}"

听到这里，你心里浮出什么。
```

**示例**（用户问"我做了 3 年还能转吗"）：

```
有个像你的同事——CASE-003（校招 3 年临界点），ta 也卡在第一次活水选择上。

当时 ta 也在想"是再熬一年还是现在动"，后来想清楚了一件事：

> "3 年是个魔咒数字，但你卡的不是年限，是你在这个岗位上还学不学得到东西。"

ta 给后来人的话是这样：

> "先别问'还能转吗'，问'我已经会了什么、还想学什么'——
>  这两个清楚了，转不转就不是个问题。"

听到这里，你心里浮出什么。
```

---

## 模板 B · 教练引子（M3 用，1 句金句即可）

不展示完整故事，只用金句作为提问素材：

```
我有个同事在资深阶段转向 AI 基础设施，ta 给我说过一句话——

> "{quote}"

这句话落到你身上，会让你想到什么。
```

---

## 严禁

1. ❌ **不暴露真名 / 花名 / RTX**——只用中性 code（如 `CASE-001`），不写任何真实姓名、花名或可反查身份的信息。
2. ❌ **不暴露真实业务 / 产品 / 团队名**——统一写成「某游戏项目」「某内容产品」「某企业协作产品」「某管理平台」这类泛化描述。
3. ❌ **不替来访者解读**——讲完故事 + 金句，**问**用户"你怎么看"，**不**告诉用户"所以你应该 X"
4. ❌ **不超过 2 个案例**——一次只引 1 个最匹配的，最多 2 个对比
5. ❌ **不给"成功学"鸡汤**——案例里的人也有阵痛期、绩效折损，要诚实讲

## 隐私保护逻辑

```python
def render_case_safe(case: dict, mode: str) -> str:
    """
    渲染时永远不暴露 case['rtx_name']（含真名）
    只用 case['code'] + 脱敏的角色描述
    """
    portrait = {
        "🔍挑剔型": "挑剔型画像",
        "🌱开放型": "开放型画像",
        # ...
    }.get(case['portrait_type'], "")

    return f"{case['code']}（{case['tenure']}, {portrait}）"
```
