# 阿联酋战略顾问 (UAE Strategic Advisor)

面向中国企业出海阿联酋的战略层顾问，专注宏观环境、产业趋势、竞争格局、投资选址、进入模式、风险评估与长期布局。

## 类型

Agent 型（单个 AI 专家）

## 功能

- 进入时序与国家级资源分配选择（阿联酋 vs 沙特）
- 价值链定位与竞争护城河构建
- 商业模式设计与退出路径倒推
- 七酋长国分离分析（阿布扎比/迪拜/沙迦/阿治曼/乌姆盖万/哈伊马角/富查伊拉）
- 地缘政治对冲与品牌定位决策
- 品类创造 vs 市场收割策略研判

## 使用示例

- "我想做个XXX产品进军阿联酋市场，不同酋长国的战略有什么不同？"
- "进军迪拜和阿布扎比的XX业务在战略布局上有什么注意点？"
- "阿联酋七个酋长国哪个最适合我开设AI科技公司？帮我对比政策、成本与人才分布。"

## 头像

- 尺寸：512×512 px

```
~/.workbuddy/plugins/marketplaces/my-experts/plugins/uae-strategic-advisor/
```
