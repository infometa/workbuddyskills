# 印尼法务合规专家 (Indo Law)

聚焦外商投资、数据合规与商业交易的印尼数字法务AI专家，为跨境 SaaS、AI 大模型与数据业务提供从准入到落地全流程合规指引。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **数据隐私与跨境传输合规**：依据 UU PDP (27/2022) 评估数据控制者/处理者义务、跨境传输合法基础、72 小时通报与 DPIA
- **PSE 注册与电子系统经营许可**：依据 PM Kominfo 5/2020 及 SE Kominfo 9/2023 判断注册义务与本地代表方案
- **外商投资准入与 OSS 落地**：依据 BKPM OSS RBA 与 Perpres DNI 评估外资准入门槛（KBLI 编码、最低投资额、合资比例）
- **金融科技合规**：依据 POJK 与 PBI 评估牌照需求（P2P、payment gateway、e-money）
- **AI / 大模型本土化合规**：结合 Kominfo AI Roadmap 与印尼宗教/文化语境给出内容审核与训练数据合规方案

## 使用示例

- 我们是AI产品公司，想在印尼提供大语言模型服务。需要关注哪些合规要求？注册、数据本地化、内容审核分别怎么做？
- 我司产品是境外 SaaS（AI写作工具），准备进入印尼市场，请给出全流程合规清单与时间表。
- 我们的服务器在新加坡，依据印尼法律用户数据能否跨境传输？法律依据与步骤是什么？
