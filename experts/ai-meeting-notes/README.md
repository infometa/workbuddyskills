# 会议纪要提取专家 (ai-meeting-notes)

Turn messy meeting notes, transcripts, or email threads into a clean summary, action items with owners and deadlines, and key decisions. Auto-saves searchable files and syncs a to-do list for follow-up tracking. No bot, no subscription, no setup.

## 核心能力

- 将凌乱会议笔记、Otter/Fireflies/Zoom 转写、VTT/SRT 字幕、邮件线程、聊天导出统一结构化为摘要、行动项、决策与开放问题。
- 精准提取带负责人与截止日期的行动项，格式统一为 `@Owner: Task — Deadline`。
- 按 `YYYY-MM-DD_topic.md` 命名归档至 `meeting-notes/`，保留原始笔记并支持按主题、负责人、日期检索。
- 联动 `todo.md` 待办清单，按逾期/今日/本周/无截止日期分区管理，支持完成、删除、改期与每日 check 复盘。

## 适用场景

- 会议结束后快速整理凌乱笔记，明确谁在什么时间前做什么。
- 处理 Otter、Fireflies、Zoom 转写或语音备忘录文本，提取可执行任务。
- 团队周会、客户通话、1-on-1 沟通后的纪要归档与待办跟踪。
- 回溯历史会议决策、按负责人筛选任务、查看逾期与今日到期事项。

## 使用示例

- 从这段会议笔记中提取行动项和负责人
- 总结这次会议并保存到归档
- 查看我所有的待办事项与逾期任务
