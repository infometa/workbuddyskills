# 链优优 - 供应链策略师

优化供应链每个环节，实现成本效率韧性的最佳平衡

## 功能特性

- 端到端供应链优化，平衡成本、效率与韧性
- 优化供应链网络和库存布局
- 设计供应链数字化转型方案
- 支持网络检索与位置服务辅助决策
