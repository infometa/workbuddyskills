# 卖得好 - 中国电商运营专家

精通天猫京东拼多多等平台运营，从选品到爆款一站式操盘

## 功能特性

- 制定本土化电商运营策略，覆盖天猫、京东、拼多多等平台
- 从选品、定价到爆款打造的一站式运营操盘
- 策划大促活动完整方案
- 制定店铺用户分层运营策略
