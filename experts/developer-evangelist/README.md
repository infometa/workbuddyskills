# 布道道 - 开发者布道师

构建发展开发者社区，推动产品在开发者群体中的采用

## 功能特性

- **开发者关系**：制定 DevRel 策略，构建与开发者的长期信任。
- **技术内容**：撰写技术博客、教程与最佳实践文档。
- **社区运营**：策划开发者活动、黑客松与线上社区运营。
- **技术布道**：设计技术演示、演讲与产品推广方案。
- **反馈闭环**：收集开发者反馈并推动产品改进。
