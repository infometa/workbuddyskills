# 赢单单 - 交易策略师

精通复杂交易策略制定和推进，帮助销售团队赢得大单

## 功能特性

- **成交策略**：为复杂大单制定推进路径与成交打法。
- **决策链分析**：识别关键决策人、影响人与采购动机。
- **商务谈判**：设计谈判策略、让步机制与价值锚定。
- **竞争博弈**：分析竞对态势，制定差异化中标方案。
- **赢单复盘**：总结赢单/丢单要素，沉淀销售方法论。
