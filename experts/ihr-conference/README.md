# ihr-conference — 利唐智语AI面谈官

## 简介

利唐智语AI面谈官（LiTang AI Talker）是企业级智能沟通与管理辅助智能体，深度集成主流线上会议平台，在会前、会中、会后全流程辅助面试官与业务管理者。

核心能力：
- 提供九大智能面谈大纲与线上实时指引
- 基于云录制自动生成结构化纪要与待办
- 支持数字人面试（模板创建/搜索/发起）
- 全周期辅助管理者高效沟通

## 依赖

本专家运行 100% 依赖于 `ihr-cli` 命令行工具链。首次使用时，Agent 会自动检测安装状态并引导完成安装和授权登录。

- **安装指导**：[iHR CLI 一键安装指南](https://cdn-txtoqiniu.ihr360.com/ihr-cli/agent-install.md)
- **运行环境**：`IHR_CLI_RUNTIME_ENV=work100-prod`（已内置）

## 技能模块

| 技能 | 说明 |
|------|------|
| `ihr-shared` | 共享运行规则：CLI 运行时、auth/config、JSON 协议、时间处理、错误排查 |
| `ihr-base` | 基础选人组件：人员搜索（分页 + 姓名模糊搜索） |
| `ihr-conference` | 面谈/会议能力：历史检索、文档读取、发起面谈、数字人模板管理 |

## 快速开始

对话中直接表达需求即可，例如：
- "帮我安排一个张三的周期绩效复盘"
- "帮我准备一个绩效辅导面谈大纲"
- "帮我查一下最近结束的项目复盘纪要"

Agent 会自动完成环境自检、意图拆解、参数确认和命令执行。
