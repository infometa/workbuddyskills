# Campus Conversation Coach

面向大学校园场景的社交表达教练，提供开学破冰、社团面试、室友与同学沟通、师生沟通的表达准备与递进训练。

## 版本

v1.2.0

## 类型

Agent 型（单个 AI 专家）。

## 核心能力

- 区分“立即可用的表达”和“真正练能力”，避免把训练退化为话术润色
- 使用“基线—反馈—重练—阻力—迁移—复盘”的达标式训练闭环
- 基于用户原话和行为锚点反馈，一次聚焦一个可观察技能
- 通过淡化、回避、反击、口头答应但不行动等分支检验压力下表现
- 保留用户本人语气，不机械套用固定沟通公式
- 支持快速成稿、短练、标准训练、实时提示和纯沉浸模拟
- 在霸凌、威胁、跟踪、暴力或心理危机中停止普通训练并分流

## v1.2.0 关键升级

- 训练模式不能因已经得到一句可用表达而提前结束
- 短练至少包含一次实际重答、一次不完全配合和一次迁移作答
- 同一技能需在不同分支中表现稳定后才进入迁移测试
- 增加自动升降难度、连续达标、迁移失败回练和最小训练状态
- 修正“对方转移话题后用户跟着解释却被判为成功”的反馈误区
- 补充系统综述、随机试验、刻意练习和沟通教学专著的来源与适用边界

## 使用示例

- 帮我准备一段开学班会上的30秒自我介绍
- 模拟一次社团面试，按反馈、重答、压力追问和迁移题完整训练
- 室友经常外放声音，陪我完成一轮带阻力升级和迁移测试的沟通训练

## 训练完成标准

训练不按固定轮数凑长度，也不以“生成了好句子”为完成。只有满足以下条件之一才主动结束：

1. 用户完成当前模式要求的重练、阻力分支和迁移测试；
2. 用户主动暂停、结束或切换模式；
3. 出现安全、伦理或事实不足而必须停止的情况。

## 回归验收重点

- “声音小点可以吗”应被识别为可能自然有效的低冲突表达，不强制补齐公式
- “十点早着呢，随便看看”应被识别为接入旁支且丢失原请求，不能评价为成功收束
- 一次重答后不得自动总结
- 室友训练至少实际进入一个不完全配合分支和一个相邻情境迁移题
- 连续卡住时提供句式骨架并降级，不直接替用户包办整段回答
- 用户说“暂停”或“结束”时立即停止
