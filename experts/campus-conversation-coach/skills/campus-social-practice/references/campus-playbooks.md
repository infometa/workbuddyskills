# 校园场景练习库

## 使用原则

- 场景库提供训练变量，不提供现实人物预测。
- 每次只引入一个主要变化，保证反馈能定位到具体技能。
- 阻力用于测试技能在压力下是否稳定，不为刁难用户而羞辱、激怒或操控。
- 短练至少使用一个阻力分支和一个迁移题；标准训练使用两个分支或两个关键技能。

## 开学破冰

### 基础技能

1. 一句必要的基本信息；
2. 一个具体兴趣、经历或近期目标；
3. 一个方便别人接话的开放点；
4. 根据对方回应继续，而不是背完整段落。

### 难度分支

| 难度 | 场景变化 | 训练目标 |
|---|---|---|
| L1 | 对方正常回应并介绍自己 | 自然开场并留下接话口 |
| L2 | 对方只说“哦”“挺好” | 用轻量追问或新信息继续 |
| L3 | 兴趣不重合 | 不硬找共同点，转向开放问题 |
| L3 | 已有多人正在聊天 | 先承接当前话题再加入 |
| L4 | 用户忘词或说得过长 | 简短收束并重新给对方空间 |

迁移示例：从班会自我介绍改为宿舍第一次见面；或从一对一改为加入三人聊天。一次只改变一个变量。

反馈重点：自然度、是否给对方接话空间、是否过度自我展示、遇到短回应后能否调整。

## 社团面试

### 一次一问顺序

1. 30—60 秒自我介绍；
2. 为什么想加入；
3. 一段真实经历；
4. 对岗位或活动的理解；
5. 一个临场追问；
6. 一个相邻问题作为迁移测试。

### 无相关经历

不编造。使用“相近经历—可迁移能力—愿意补足的具体行动”回答。

### 压力分支

| 难度 | 面试官变化 | 训练目标 |
|---|---|---|
| L2 | 追问一个具体细节 | 用真实事实支撑 |
| L3 | “这个经历和岗位关系不大吧” | 说明可迁移能力，不强行包装 |
| L3 | 打断并要求更简短 | 快速提炼主线 |
| L4 | “如果和课程冲突怎么办” | 给可执行安排，不空泛承诺 |
| L4 | 连续追问同一薄弱点 | 保持一致、承认边界并补行动 |

反馈重点：切题、具体事实、本人行动、自然可信、追问后能否修正。每题必须完成重答再换题。

## 室友沟通

### 可观察技能

1. 提出具体请求；
2. 保持自然简洁，不机械套公式；
3. 承接对方但不丢失当前目标；
4. 把反击中的另一个议题与当前问题分开；
5. 对口头答应但未行动做二次提醒；
6. 必要时提出可协商选项、暂停或现实支持。

### 准备

1. 写出摄像机可以记录的事实；
2. 判断对方是否已经知道现场情况，避免不必要的长解释；
3. 提出一个具体、可执行的请求；
4. 需要时准备一个可协商选项；
5. 约定或观察何时确认行动。

### 阻力阶梯

| 难度 | 室友回应 | 训练目标 |
|---|---|---|
| L1 | “好，我调小点” | 清楚提出请求 |
| L2 | “也没多大声吧” | 简短说明影响并重复具体请求 |
| L3 | “十点了你还看什么书” | 承接一句后拉回请求，不争论时间 |
| L3 | “以后再说，我这条马上看完” | 把“以后”变成当前可执行动作 |
| L4 | “你昨晚也吵到我了” | 分开两个议题，先处理当前请求，再约后续讨论 |
| L4 | 口头答应但继续外放 | 做二次提醒并确认动作 |
| L4 | “凭什么都听你的” | 说明共同空间影响并提出协商选项 |
| L5 | 持续拒绝但无威胁 | 尊重无法达成一致，讨论替代安排、暂停沟通或使用宿舍协商渠道 |
| 安全分流 | 辱骂伴随恐吓、威胁、破坏物品、跟踪或报复 | 停止训练式对质，转现实支持和安全分流 |

### 反馈误区

- “声音小点可以吗”在低冲突场景中可能已经清晰自然，不能仅因没说原因就判为命令。
- “十点早着呢，随便看看”进入了对方设定的旁支，并弱化自身需求；不能评价为“没有被带跑”。
- 对方第一句答应不代表用户已掌握沟通能力；还需测试至少一个变化和一个迁移题。

### 迁移题

只改变一个变量：

- 从刷短视频外放改为打游戏语音；
- 从晚上复习改为午休；
- 从第一次请求改为答应后仍未改变的二次提醒；
- 从当面沟通改为宿舍群消息。

## 同学与小组合作

### 表达骨架

当前事实 → 对任务的影响 → 希望确认的责任或时间 → 对方可回应的问题 → 记录共识。

### 阻力分支

- 对方说“我最近很忙”但不给时间；
- 对方认为任务已经做完；
- 对方把责任推给另一位同学；
- 群聊中不回应，私聊后仍模糊；
- 对方反指用户也有延期。

训练目标：确认具体责任与时间、区分不同议题、保留书面共识、拒绝代做。迁移可从私聊改为群聊，或从第一次分工改为截止日前催进度。

## 师生沟通

### 即时消息

称呼 + 简短身份 + 具体事项 + 已做尝试 + 明确请求 + 必要时限 + 感谢。只加入当前需要的部分，不把每条消息写成固定长模板。

### 邮件

主题明确；正文写清课程或项目、事实、材料、请求和时限。不使用过度客套，不把紧急程度隐藏在长背景中。

### 当面请教

先说明问题和已尝试内容，再问一个具体问题。老师时间有限时，主动询问更合适的沟通时间。

### 训练分支

- 老师只回复“看通知”；
- 老师误解用户要申请例外；
- 对方没有回应，但截止时间临近；
- 老师要求用户先补材料；
- 用户需要拒绝不合理但非危险的额外安排。

涉及奖惩、申诉、住宿管理、纪律处理或权力不对等风险时，读取安全资料，不把问题简化为“说得更好听”。

## 拒绝表达

1. 明确答复，不制造虚假期待；
2. 必要时给简短原因，不进行过度辩解；
3. 能提供且愿意提供替代方案时再提供；
4. 对方继续施压时重复边界，不追加新的解释；
5. 出现威胁或报复时停止普通练习并转现实支持。

压力分支：追问原因、情绪绑架、承诺“就这一次”、转向群体压力、指责不够朋友。迁移题应换一个相邻拒绝场景，不复用刚刚的完整答案。

拒绝代签到、作弊、泄露作业答案、借用账号等违规请求时，不协助规避规则。
