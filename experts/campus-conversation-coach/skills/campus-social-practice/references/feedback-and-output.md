# 反馈、评分、达标与输出

## 一、反馈证据链

每个判断都呈现三层：

1. **输入**：用户本轮说了什么；
2. **锚点**：当前观察哪个维度和行为标准；
3. **解释**：为什么这段表达符合或不符合标准，以及下一步练什么。

只评价本轮可观察行为。对现实人物使用“可能”“仅凭当前信息无法确认”；对模拟对象使用“在本次模拟中”。

## 二、五维行为锚点

使用 0—3 级，不使用百分制和人格排名。信息不足时不评分不相关维度。

### 清晰度

| 等级 | 可观察表现 |
|---|---|
| 0 | 核心事项或诉求无法识别 |
| 1 | 能识别大致诉求，但被过多背景、多个重点或跳跃表达遮蔽 |
| 2 | 重点明确，结构基本顺畅，对方知道发生了什么和需要回应什么 |
| 3 | 重点明确且精简，并能根据对方回应补充或收束信息 |

### 自然度

| 等级 | 可观察表现 |
|---|---|
| 0 | 明显不是用户会使用的表达，或含虚构、夸大和强模板腔 |
| 1 | 基本意思真实，但措辞生硬、过度正式或与场景不匹配 |
| 2 | 符合用户原意和场景，表达自然可信 |
| 3 | 保持本人语气的同时，能根据对象、渠道和现场反应灵活调整 |

### 倾听与回应

| 等级 | 可观察表现 |
|---|---|
| 0 | 未回应对方关键信息，或只重复自己的立场 |
| 1 | 注意到部分信息，但错过关键点、跟随旁支或没有回应入口 |
| 2 | 承接必要信息，同时保留当前目标并给出回应入口 |
| 3 | 准确承接信息、确认理解，并根据新回应调整下一步而不丢失目标 |

### 边界感

| 等级 | 可观察表现 |
|---|---|
| 0 | 含操控、羞辱、威胁、绕过拒绝，或把请求表达成对方无法拒绝的要求 |
| 1 | 意图合理，但事实、影响、请求或可协商范围不清楚 |
| 2 | 请求或拒绝明确具体，尊重双方选择，并说明必要边界 |
| 3 | 在防御、回避或施压下仍能稳定重复边界、提出选择或安全退出 |

### 目标达成度

| 等级 | 可观察表现 |
|---|---|
| 0 | 表达与当前目标无关或明显阻碍目标 |
| 1 | 提到目标，但缺少必要请求、行动或下一步，或回应旁支后丢失原目标 |
| 2 | 表达能够推动当前目标，并给出对方可以回应的具体入口 |
| 3 | 推动目标，并能依据回应确认共识、调整方案或约定下一步 |

## 三、评分与达标规则

- 单轮训练只选择一个最相关维度，不强制展示五维总表。
- 当前锚点达到 2 级表示本轮基本达标，不代表技能已经稳定。
- 同一目标在两个不同阻力分支中分别达到 2 级，或在一个阻力分支与后续迁移中均达到 2 级，才记为训练内暂时掌握。
- 完成迁移题并达到 2 级或以上，才允许主动总结该技能已通过本次训练。
- 完整复盘按需要展示多维结果；没有证据的维度标记“本次未观察”。
- 分数后必须附用户原句或可观察行为，不只给数字。
- 相同表达在相同场景与锚点下应保持基本一致；需要改分时说明新增证据。
- 不把停顿、短回复、拒绝、内向或慢热解释为人格和心理诊断。

## 四、自然表达校准

- 不要求每次都包含事实、感受、需要、请求和替代方案。只使用当前场景需要的元素。
- “声音小点可以吗”在关系正常、低冲突且对象知道现场情况时，可以是清晰、自然的请求；若要判断稳健性，应加入阻力分支，而不是先把原句判成错误。
- 建议表达不能因为更长就被视为更好。“我在看书，你声音可以小一点吗”中的“你声音”可能生硬，应优先使用符合口语习惯的说法。
- 保留用户本人语气。如果示范与用户习惯明显不符，先降自然度，再提供方向而非强迫模仿。

## 五、转移话题与反击校准

判断“有没有被带跑”时，检查两件事：

1. 用户是否承接了必要信息；
2. 用户是否仍保留、拉回或推进原目标。

例如：

- 室友：“十点了你还看什么书？”
- 用户：“十点早着呢，随便看看。”

这句话语气轻松，但进入了“十点晚不晚”的旁支，且没有保留降噪请求；目标达成度不应判为 2 级或 3 级。反馈应指出“承接了旁支但原请求消失”，随后只练“承接一句后拉回请求”。

面对“你昨晚也吵到我了”等反击，用户不必否认或立刻辩论。训练目标可以是把两个议题分开：承认可以稍后处理对方的反馈，同时先确认当前请求。

## 六、重练比较

记录并比较：

- 原始表达中的一个证据片段；
- 本轮唯一训练目标；
- 用户重答中的对应片段；
- 同一锚点下发生的变化；
- 下一分支需要继续保持的一点。

如果重答没有改善，先缩小目标或提供句式骨架，不叠加第二个新技巧。句式骨架只给结构，例如“承接一句 + 拉回请求”，不直接给完整标准答案。

## 七、快速成稿模板

### 推荐表达

可直接使用的版本。

### 更短版本

保留核心诉求，减少铺垫。

### 使用提醒

说明适合渠道、语气或需要现场调整的地方。

## 八、训练反馈模板

1. **证据**：引用用户本轮一个具体片段。
2. **效果**：说明它让当前目标前进还是偏离。
3. **唯一训练点**：绑定一个行为锚点。
4. **现在重练**：给同题或最小变体并等待用户作答。
5. **前后比较**：用户重答后再输出，不提前宣布完成。
6. **下一挑战**：达标后进入一个匹配难度的阻力分支。

示例：

> 你说“十点早着呢，随便看看”，语气保持得很轻松；但你开始解释“十点晚不晚”，降噪请求消失了。本轮只练“承接一句后拉回请求”。现在室友还是这句话，请你再答一次。

## 九、完整复盘模板

1. 场景与目标；
2. 本次实际训练的技能；
3. 基线证据与最终证据；
4. 已通过的阻力分支；
5. 迁移题表现；
6. 有证据的维度反馈，未观察项明确标注；
7. 仍未达标或尚未测试的能力；
8. 一句现实使用提醒；
9. 下一次建议练的相邻技能。

复盘使用“本次模拟中已观察到”，不宣称现实中必然有效。

## 十、行动收尾

快速成稿收尾：

- 一句可用表达；
- 一个现场观察点；
- 一个下一步动作。

训练收尾：

- 一项已通过技能；
- 一项未观察或待继续技能；
- 一个现实应用提醒。

结尾提供自然入口，不罗列全部功能菜单，也不在证据不足时写“你已经掌握”。
