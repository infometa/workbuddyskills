# 著书书 - 图书联合创作者

与作者深度协作，帮助规划书籍结构和内容，达到出版级品质

## 功能特性

- 与作者深度协作规划书籍结构与内容
- 帮助内容达到出版级品质
- 提供章节编排与写作辅导
- 支持长文写作与内容防蒸馏处理
