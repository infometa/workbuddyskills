# 腾讯云知识问答专家

基于腾讯云知（乐享）知识库的检索增强问答专家，封装乐享 MCP 的语义向量检索能力（`search_kb_embedding_search`），提供端到端的「权限校验 → 意图门控 + 查询改写 → 并行检索（按 mode 分流）→ 引用式回答」流水线。在纯站内 RAG 之上，额外支持**竞品对比模式**（站内乐享 + 站外竞品官网双通道）与**国际化 / 海外定向检索**（国际版 UDF 过滤）。

## 类型

Agent 型（单专家）

## 功能

- **MCP 权限判断（前置门禁）**：调用 `whoami` 校验是否绑定乐享 MCP 个人 Token；未绑定 / 401 时按规范话术引导用户去 `https://lexiangla.com/mcp?company_from=CSIG` 获取 LEXIANG_TOKEN（默认 `COMPANY_FROM=CSIG`，无需用户提供）。**权限判断永远是第一步，未通过不进入检索。**
- **意图门控 + 查询改写**：先判定 `mode`（standard / competitive）与 `intl`（on / off）两个正交开关，再覆盖主关键词保留、缩写补全、子问题拆解、意图补全、同义词扩展、时间语义转换共 6 条规则，输出 3~6 条并行检索 Query。
- **并行语义检索**：每次问答默认且仅调用 `mcp__lexiang__search_kb_embedding_search` 进行多路召回；**仅在 embedding 完全无召回 / 全部低相关 / 缺精确实体命中时**，才兜底启用 `search_kb_search` 关键词检索。按 `target_id` 去重并按相关性过滤排序。（实测校准：正文默认返回，无需传 `_mcp_fields`。）
- **竞品对比模式（意图门控 · 唯一联网例外）**：仅当问题**同时命中「对比动作 + 外部友商实体」**时切 `mode=competitive`，走「站内乐享 + 站外竞品官网」双通道；`site:` + 白名单双重过滤、逐厂商独立检索、来源分级、实体防污染。其余意图严格纯站内。
- **国际化 / 海外定向检索（正交叠加 · 不联网）**：命中「海外 / 国际版 / 出海 / 多语言 / 翻译 / overseas / international」等场景时置 `intl=on`，对每条检索注入「国际版=是」UDF 过滤定向召回，并强制二次筛选剔除国内版内容。与 `mode` 正交，仍属纯站内链路。
- **引用式答案生成**：严格基于检索片段，使用**学术风数字角标 `[1][2]`**（禁用 WorkBuddy 不渲染的 `[citation:X]`）内联引用，「参考资料」用可点 Markdown 链接列出文档标题与原文链接。
- **拒答策略**：`mode=standard` 下知识库无相关结果则回复"未检索到相关内容"，**禁止使用联网检索兜底**；唯一例外是 `mode=competitive` 竞品对比的站外通道。

## 技能

| 技能名 | 说明 |
|--------|------|
| `yunzhi-qa` | 云知知识问答能力封装，含查询改写、答案生成、竞品对比、国际化/海外检索、整体架构五份参考文档 |

## 使用示例

- WorkBuddy售前介绍资料
- 腾讯云在海外金融行业的客户案例有哪些
- 腾讯云智能体开发平台相比竞对产品有哪些优势?
