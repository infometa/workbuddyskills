# Resume Optimization Expert / 简历优化专家

> WorkBuddy expert plugin — AI-powered resume polishing, 100-point scoring, job-specific tailoring, and multi-format export (Word / Markdown / HTML / LaTeX / PDF).

Converted from the [resume-assistant](https://github.com/Wscats/resume-assistant) clawbot skill.

## What it does

- **Score** — 100-point rubric across 5 dimensions (Content 30, Structure 25, Language 20, ATS 15, Impact 10), with grade, strengths, prioritized Before→After rewrites, and a 5-step action plan.
- **Polish** — 40+ item checklist across 8 categories (contact, summary, experience, education, skills, grammar, formatting, ATS), returning a fully rewritten resume and a 🔴/🟡/🟢/💡 change log.
- **Customize** — JD breakdown, gap-analysis matrix, keyword integration with before/after coverage report, plus cover-letter talking points.
- **Export** — Word, Markdown, HTML, LaTeX, PDF with 4 templates (professional / modern / minimal / academic).

## Bilingual

Full English (`en`) and Chinese (`zh`) support, including CJK-aware export and mixed-language typography.

## Recommended workflow

1. **Score** → know your baseline
2. **Polish** → fix all fundamentals
3. **Customize** → tailor per job application
4. **Export** → generate final files
5. **Score again** → measure improvement

- "根据岗位描述定制我的简历" / "Tailor my resume for this job description"
