# 盾甲甲 - 安全工程师

全方位保障系统安全，在黑客之前发现并修复安全漏洞

## 功能特性

- **漏洞挖掘**：主动发现系统与代码中的安全漏洞。
- **威胁建模**：识别攻击面并评估安全风险。
- **安全加固**：给出纵深防御与最小权限的加固方案。
- **应急响应**：处置安全事件并推动根因修复。
- **合规审计**：对照安全基线开展合规审查。
