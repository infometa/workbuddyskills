# 输出模板

只选择当前任务需要的一个主模板，不一次展开全部产物。完成训练后可追加简短的“会话内复盘”。

## 学习诊断

```text
本次目标
已有证据
初步薄弱项（1—2 个）
为什么优先练它
本次训练任务
完成标志
```

没有标准化测试时注明“基于当前材料/作答的初步判断”，不输出精确等级或分数。

## 考试作文批改

```text
评分范围与限制
考试级别 / 题型 / 依据版本
总词数 / 排除词数 / 有效词数（无法可靠计算时注明限制）
基准档与原始分或区间
独立扣分及依据（没有则写“无独立扣分”）
最终模拟分
支持当前档的原句证据
排除相邻高档的依据
最影响提分的 1—3 个问题
本轮提分动作
报告或改写入口
```

## 快速修改

```text
本轮目标
整体判断
最影响结果的问题
1. 原句/位置
   问题
   建议改法
2. ...
最小修改版（诚信边界允许时）
关键改动
下一步入口
```

## 引导训练

```text
本轮只练
材料 / 原句 / 题目
你已做得好的地方
优先调整点
提示
请你重做
```

用户重做后：

```text
验证结果
具体进步
仍需调整的一点
局部参考（仅在需要且允许时）
本轮错误卡
```

## 阅读理解

```text
本组范围与答案来源
结果（有可靠答案时）
题号 / 题型 / 用户答案 / 可靠答案
题干限制词
原文证据与位置
正确路径
干扰项错因
主错误标签
同能力点重练题
```

原创选择题标注“原创练习”；无法保证唯一答案时改为开放题。

## 语境词汇

```text
本轮词汇目标
原文位置与语境
先回忆
语境义 / 搭配 / 词形 / 易混点
回忆题
新语境使用题
本次掌握证据：能认出 / 能回忆 / 能使用
```

一轮默认不超过 8 个词或短语。

## 语法专项

```text
本轮知识点
原句与最小问题片段
通俗规则
识别题
改错题
用户产出
新语境验收
本轮错误卡
```

## 翻译训练

```text
场景 / 方向 / 依据限制
总体判断
原文片段
用户译文片段
问题标签：遗漏 / 增添 / 误解 / 逻辑 / 语法 / 搭配 / 语域
修改提示
请你重译
重译验证
参考译法（按需，且注明不是唯一答案）
```

## CET 文本题型会话总结

```text
级别与题型
依据版本
材料来源状态
写作 / 阅读 / 翻译的本次证据
1—3 个优先问题
已完成重练
下一步
范围说明：未覆盖听力和真实口语；不推算官方总分
```

## 独立提交作业训练

```text
任务理解
最影响结果的 1—3 个问题及位置
结构提示、证据问题或检查清单
局部骨架/不同主题示例
请你先完成的部分
复核入口
```

不附完整答案、完整译文或全文替换版。

## 邮件或摘要修改

```text
写作目的与语域
最小修改版
关键改动对照
需用户确认的事实或承诺
```

## 范文精读

```text
本轮范围与粒度
原文编号
逐句/逐段分析
长难句主干与修饰
上下文词义与原文例句
全文脉络
```

## 范文迁移卡

```text
原文表达与位置
结构或搭配
适用场景
使用限制
换主题仿写任务
```

## 会话内学习卡

```text
学习目标
目标场景
本次材料
优先薄弱项与证据
已完成训练
重练结果
错误卡
下一步
```

注明：本卡未自动跨会话保存；用户可自行复制到下次会话继续。

## 错误卡

```text
主错误标签
次标签（可选）
本次证据
判断规则
正确示例或正确路径
下一次自检问题
```
