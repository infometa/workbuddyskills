# 语境词汇学习

## 1. 目标

词汇训练以“在当前语境中理解并能再次使用”为目标，不以一次展示大量释义为完成。优先从用户材料、阅读错题、作文或译文中选择真正影响理解与表达的词。

## 2. 选择范围

未指定数量时，一轮选择不超过 8 个词或短语，优先级如下：

1. 影响主旨、题目或任务完成的词；
2. 用户在当前语境中理解错误的词；
3. 高频搭配或构词能带动多个表达的词；
4. 用户反复误用的词；
5. 与本次考试或写作目标直接相关的词。

不因为单词生僻就自动纳入，不机械解释全文所有生词。

## 3. 单词卡字段

每项按需包含：

- 原文位置与原句；
- 词性；
- 本句语境义；
- 影响理解的搭配或结构；
- 词形变化；
- 易混点；
- 一个基于当前材料改写的回忆题；
- 一个不同主题的使用题。

原文没有的信息不得伪装成原文结论。词源、词频、考试等级和大纲归属无法核验时不确定标注。

## 4. 三级掌握度

- **能认出**：看到词能选出当前语境义。
- **能回忆**：不给答案时能说出语境义、搭配或完成句子。
- **能使用**：能在新语境中准确、自然地造句或改写。

掌握度只基于本次作答证据，不外推为长期掌握。

## 5. 训练闭环

1. 先给原句或提示，让用户回忆，不先展示完整词卡。
2. 根据回答指出正确部分和一个主要缺口。
3. 展示当前需要的语境义、搭配或辨析。
4. 给一个新语境填空、改写或造句。
5. 按意义、语法、搭配和语域验证。
6. 形成会话内词汇错误卡。

用户明确只要快速查义时，可直接给语境义和简短说明，并提供可选练习入口。

## 6. 易混词与同义词

- 只比较当前表达中真正可能替换的词。
- 说明意义、搭配、语域或句法位置中的至少一个差异。
- 不把同义词列表当作可互换清单。
- 例句优先使用用户材料；原创例句标明为示例，不冒充权威语料。

## 7. 复习边界

- 当前包只维护本会话内的“待复习 / 已重练 / 本次能使用”。
- 没有宿主授权存储与调度能力时，不承诺跨会话间隔复习、到期提醒或自动词库。
- 用户下次要继续时，可保存并粘贴本次词汇卡；专家再先测后教。

## 8. 默认输出

- 本轮词汇目标；
- 需要用户先回忆的词；
- 最多 8 张语境词汇卡；
- 一组回忆或使用题；
- 重练结果；
- 会话内待复习清单。
