# 营销诊断 / 复盘 / 预算ROI

## 三种模式（先分清，不要混）

用户说的是哪件事，决定走哪条线，不要把诊断、复盘、预算混成一个回答：

- **诊断 diagnose（事中）**：当前营销链路哪里断了。基于实时漏斗数据定位断点（曝光高线索少 / 线索多到店少 / 到店多成交少 / 渠道 ROI 低），输出"断点 → 主因 → 修复顺序"。问的是"现在哪里出问题"。
- **复盘 review（事后）**：一场活动 / 一个渠道 / 一家门店 / 一个车型的结果对基准。核心是**用行业基准值区间判断异常**——不看基准的复盘只会说"不够好"，看了基准才能说"留资到店率 8% 是偏低还是正常"。问的是"过去的结果怎么解读、下一轮怎么改"。
- **预算 ROI budget ROI（事前）**：钱怎么分、花多少换多少线索和成交。建立"预算分配 → 成本测算 → ROI 评估"闭环。问的是"该花多少、怎么分、划不划算"。

三件事可以串起来（先算预算 → 投放中诊断断点 → 事后复盘对基准），但每一步要明确自己在哪种模式。

## 触发场景

- 诊断：曝光高线索少、线索多到店少、到店多成交少、单场活动效果差、某渠道 ROI 低。
- 复盘：复盘某场活动 / 某个渠道 / 某家门店 / 某个车型的增长结果，要数据解释、问题定位、下一轮动作。
- 预算 ROI：做营销预算分配、评估渠道投入产出、测算一场活动或一个季度的获客成本与 ROI，或向管理层汇报"花了多少钱、换来多少线索和成交"。

## 功能说明

把汽车营销拆成"目标 - 漏斗 - 渠道 - 客群 - 内容 - 承接 - 成本 - 下一步"来处理。三种模式共用一套底层逻辑（漏斗 + 基准 + 成本），但输出重点不同：诊断输出"断点 + 修复顺序"，复盘输出"目标 vs 实际 vs 基准 + 下轮计划"，预算输出"分配表 + 成本预期 + ROI 预判"。

## 输入

- 车型、区域、门店、活动或渠道名称
- 当前目标：曝光、留资、到店、试驾、成交、复购或品牌声量
- 关键数据：曝光、点击、留资、到店、试驾、成交、成本、成交额
- 已采取动作：渠道、内容、活动、跟进节奏、销售政策
- 当前困惑：哪一段不达标、和历史/竞品差在哪里
- 预算模式额外需要：营销总预算与周期、可用渠道、客单价与毛利、历史或行业成本参考

## 🔴 关键核验点

回答前先核验，缺一不可，缺了先要数据不要硬编：

1. **营销阶段**：用户是在事中诊断、事后复盘、还是事前做预算？三条线输出不同，先锁定模式。
2. **关键数据**：曝光 / 点击 / 留资 / 到店 / 试驾 / 成交 / 成本是否齐备？缺哪段漏斗就先要哪段，不能跳过断点直接下结论。
3. **客单价与毛利**：算 ROI 必须有毛利，缺毛利算不出 ROI 和 CAC 健康度，先要客单价、让利空间、金融保险售后留存口径。
4. **历史对照**：有没有目标值、环比、同店 / 同活动 / 同车型基线？没有基准值无法判断"8% 是低还是正常"，先用历史均值或行业基准作基线。

数据不足时不伪造结论，先列出需要补的数据；用户需要快速判断时，可基于明确假设给初版结论并标注假设。

## 暂停与降级条件

- 模式不清时，先暂停：明确是诊断、复盘还是预算 ROI。
- 缺关键漏斗数据时，先暂停：至少确认曝光、留资、到店、试驾、成交、成本中已知项。
- ROI 缺毛利或成交口径时，先暂停：只输出成本测算，不下 ROI 健康结论。
- 数据口径冲突时，先暂停：统一时间范围、去重规则、渠道归因和门店范围。

## 一、诊断框架（diagnose）

### 工作流程

1. 识别营销阶段与目标
2. 找出漏斗断点
3. 判断主因和次因
4. 给出修复顺序
5. 输出短期动作和中期优化

### 判断框架（按顺序逐项排除）

1. **目标是否清晰**：品牌曝光、线索获取、到店转化、试驾成交、车主激活不能混成一个目标。
2. **客群是否匹配**：预算、家庭结构、能源接受度、城市和用车场景是否对路。
3. **产品表达是否对路**：是否把参数翻译成用户利益，是否有真实到店理由。
4. **渠道是否合适**：渠道质量如何，线索来源是否注水、意向是否真实、渠道成本是否失衡。
5. **活动是否能承接**：活动热闹但留资差、现场没有转化机制也是断点。
6. **跟进是否跟得住**：首呼时效、邀约话术、试驾安排、成交推进是否断档。
7. **转化是否有阻力**：到店多成交少要看配置讲解、竞品压制、金融方案、价格口径。

### 漏斗断点

- 曝光→点击：内容钩子弱、客群不准、渠道错位
- 点击→留资：表单重、利益点不清、落地页承接差
- 留资→到店：邀约弱、时机慢、门店承接差、线索质量差
- 到店→试驾：试驾没安排、配置讲不透、销售促单弱
- 试驾→成交：竞品压制、金融方案弱、价格口径混乱、决策链长（家庭多人）

### 常见断点速查

| 症状 | 一线判断 | 优先修复 |
|---|---|---|
| 曝光高线索少 | 内容钩子弱、客群不准、渠道错位 | 换素材角度，重定人群和渠道 |
| 线索多到店少 | 首呼慢、邀约弱、线索质量差 | 压缩首呼时效，重写邀约理由，校验来源 |
| 到店多成交少 | 配置讲不透、竞品压制、成交政策弱 | 统一销售口径，补竞品对比和成交动作 |
| 活动热闹但无结果 | 目标模糊、现场留资差、复盘缺失 | 重设活动目标、留资机制和复盘指标 |
| 渠道 ROI 低 | 预算分配失衡、归因口径不清 | 按成本和转化重排预算，建立归因表 |

### 诊断 if-then（症状 → 一线动作 → 仍异常深入）

| 症状 | 一线判断 | 仍异常深入 |
|---|---|---|
| 曝光高线索少 | 内容钩子弱/客群不准 → 换素材测 | 渠道本身错位，停投换渠道 |
| 线索多到店少 | 邀约时效慢 → 压首呼到 15 分钟内 | 线索质量差（来源注水），换渠道 |
| 到店多成交少 | 配置讲不透/竞品压制 → 培训+话术 | 价格/金融方案没竞争力，调政策 |
| 数据不足以诊断 | 先补漏斗各段数据 | 用同店/同活动历史数据对比推演 |

## 二、复盘框架（review）

### 工作流程

1. **对齐目标与实际**：列出关键指标的目标值、实际值、基准区间。
2. **定位异常**：哪些指标显著偏离基准或环比下滑。
3. **解释原因**：沿漏斗（曝光→线索→到店→试驾→成交）逐段归因，区分主因次因。
4. **排序动作**：按"影响面 × 可执行性"排优先级。
5. **形成下轮计划**：明确动作、负责人、目标值、复盘时间。

### 汽车营销基准值区间表（参考区间，因品牌/城市/车型而异，非硬标准）

| 指标 | 参考区间 | 说明 |
|---|---|---|
| 曝光→留资转化率 | 0.5%–3% | 线上广告口径 |
| 留资→到店率 | 8%–25% | 低于 8% 多为邀约或线索质量问题 |
| 到店→试驾率 | 50%–80% | 试驾是强成交信号 |
| 试驾→成交率 | 15%–40% | |
| 留资→成交周期 | 7–45 天 | 新能源通常更短 |
| 单条线索成本（CPL） | 50–500 元 | 看渠道，信息流偏高 |
| 单到店成本（CPD） | 300–2000 元 | |
| 单成交获客成本（CAC） | 1500–8000 元 | |
| 老带新占比 | 10%–30% | 健康私域能拉高 |

**基准使用规则**：低于或高于区间不代表好坏，要看车型定位（豪华车到店率天然低但客单高）和对比基线（环比 / 同店 / 同活动类型）。基准值是参考区间不是硬标准，需结合车型定位和对比基线解读。

### 异常诊断对照（指标偏离 → 可能原因 → 关联模式）

- 留资多到店少 → 邀约话术 / 时效 / 线索质量（回诊断模式逐段查）
- 到店多成交少 → 配置讲解 / 竞品压制 / 金融方案 / 价格口径
- 成本高转化低 → 渠道错位 / 客群不准 / 内容钩子弱（回预算模式重排）
- 成交周期长 → 跟进断档 / 竞品干扰 / 决策链长（家庭多人）

### 复盘 if-then（情况 → 一线应对 → 仍失败兜底）

| 情况 | 一线应对 | 仍失败兜底 |
|---|---|---|
| 没有目标值，无法判异常 | 用历史均值/行业基准作目标 | 先建基线，下轮再严格复盘 |
| 数据不全（缺某段漏斗） | 用已有段先复盘，标注缺口 | 补埋点/采集，延后完整复盘 |
| 指标都达标但业绩没涨 | 查指标是否选错（北极星） | 重定指标体系 |
| 找不出原因 | 列假设，下轮 A/B 验证 | 外部归因（市场/竞品/政策） |

### 复盘输出模板

- 目标 vs 实际 vs 基准（指标表）
- 主要差异 + 原因分析（主因/次因）
- 优化动作（按优先级）
- 下轮执行重点 + 负责人 + 目标值
- 复盘时间点

## 三、预算与 ROI 测算（budget ROI）

### 功能定位

把营销从"花钱"变成"算账"。建立**预算分配 → 成本测算 → ROI 评估**的闭环，让每一笔投入都能对应到线索、到店、成交和获客成本。没有这一步，营销方案花多少钱都说不清，复盘也没有基准。

### 预算分配框架表（按"目标 × 渠道"分配，不要平均撒胡椒面）

| 渠道类型 | 适合目标 | 成本特征 |
|---|---|---|
| 信息流广告（抖音/微信/头条） | 曝光+线索 | 单线索 100-500 元，量大质杂 |
| 搜索广告 | 高意向线索 | 单线索 200-800 元，意向强 |
| 小红书种草 | 内容+口碑 | 单线索 150-600 元，长尾 |
| 短视频/直播 | 曝光+线索+成交 | 看达人量级，波动大 |
| 线下活动（试驾会/商超展） | 到店+成交 | 单到店 300-2000 元，精准 |
| 私域/老带新 | 复购+转介绍 | 单线索成本最低，50-200 元 |

**分配原则**：
- 效果导向：60-70% 投效果渠道（能直接算线索/成交）
- 内容种草：15-25% 投品牌内容（长尾，难短期归因）
- 留 10-15% 做测试和机动

### 成本与 ROI 公式

- **CPL（单条线索成本）** = 渠道投入 / 留资线索数
- **CPD（单到店成本）** = 渠道投入 / 到店数（或 = CPL / 留资到店率）
- **CAC（单成交获客成本）** = 总营销投入 / 成交数
- **ROI** = （成交毛利 - 营销投入）/ 营销投入
- **ROAS（广告投入产出比）** = 成交收入 / 广告投入

测算时沿漏斗逐段算：投入 → 线索 → 到店 → 试驾 → 成交，每段乘转化率（参考上方基准值区间表）。

### ROI 评估规则

- 单看 CPL 不够，要算到 CAC：线索便宜但成交差也是亏。
- 要算"全链路 ROI"而非单渠道：线下活动线索贵但成交率高，可能总 ROI 更好。
- 品牌内容投入的 ROI 看长尾（3-6 个月后的搜索/自然流量提升），不苛求短期。
- **对比基准**：CAC 应低于单车毛利的 30-50%，否则营销吃掉利润。
- ROI 判断需结合单车毛利、金融保险、售后留存和车主转介绍，不只看当期成交。

### 不同业务角色的预算视角

- **主机厂（OEM）**：看全国预算大盘与区域分配，重品牌 + 效果组合；关注全国线索量、区域差异、品牌声量与效果的平衡。
- **经销店（Dealer）**：看单店预算，重本地效果渠道和线下活动；关注到店成本、成交转化、本地私域复购与老带新。

### 预算工作流程

1. 明确预算总额、周期、目标
2. 按渠道类型分配预算（用分配框架表）
3. 沿漏斗测算线索/到店/成交与各项成本（用公式 + 基准区间）
4. 算 ROI 和 CAC，对比毛利基准（CAC < 单车毛利 30-50%）
5. 输出预算表 + 成本预期 + ROI 预判 + 风险点

### 预算输出模板

- 预算分配表（渠道 × 金额 × 占比 × 目标）
- 漏斗测算（投入 → 线索 → 到店 → 试驾 → 成交）
- 成本指标（CPL/CPD/CAC/ROAS）
- ROI 预判与盈亏平衡点
- 风险与优化建议（哪些渠道该加/该砍）

## 可视化输出

默认输出 Markdown。当出现以下情况时，直接输出 HTML 可视化报告：

- **多渠道对比**：6 个以上渠道的成本 / 转化 / ROI 需要横向对比，表格 Markdown 难以一眼看出差异。
- **多区域 / 多门店 / 多车型**：需要按区域、门店或车型切片看分布与排名。
- **汇报材料**：用户明确说要给管理层 / 区域总 / 经销商大会汇报，需要图表化呈现（漏斗图、渠道对比柱图、ROI 散点）。
- **三种模式串联**：一次任务同时做了预算 + 诊断 + 复盘，内容较长，HTML 能分章节导航。

不涉及上述情况时，Markdown 即可，不要为可视化而可视化。

## 输出形式（默认 Markdown 结构）

- 一句话结论（落在哪种模式 + 核心断点 / 异常 / 预判）
- 模式专属输出（诊断给断点修复、复盘给目标 vs 实际 vs 基准、预算给分配表 + ROI）
- 主要原因与次要原因
- 立刻修复 / 优化动作（按优先级）
- 需要补充的数据
- 下轮观察指标 / 复盘时间点

## 失败分支

| 情况 | 处理 |
|---|---|
| 缺关键漏斗数据 | 只做已有数据诊断，并列出必须补齐的字段 |
| 用户只给结论不给数据 | 先反推可能断点，明确是假设，不做确定判断 |
| ROI 缺毛利口径 | 先输出成本测算，不下 ROI 健康结论 |
| 指标互相矛盾 | 优先核对口径、时间范围和去重规则 |

## 反例（不要做）

- 不用“活动不够吸引人”替代具体断点。
- 不只看 CPL，不算到到店、试驾和成交。
- 不把行业基准当作硬标准套所有车型和城市。

## 边界

- **不伪造结论**：数据不足时先列需要补的数据，可基于明确假设给初版结论并标注假设。
- **不把单一指标当成全部原因**：到店少不一定是邀约差，也可能是线索质量或客群错位。
- **不用泛化术语替代具体断点**：要落到渠道、客群、内容、时效、话术等可动作层面。
- **不承诺真实成交或 ROI**：所有成本和转化率是参考区间，实际以历史数据和门店校准为准；不编精确的成交预测，给区间和假设。
- **基准是参考不是硬标准**：基准值区间需结合车型定位（豪华车到店率天然低但客单高）和对比基线（环比/同店/同活动）解读。
- **品牌投入短期 ROI 可能为负**：要说明长尾逻辑（3-6 个月后搜索/自然流量提升），不苛求当期。
- **涉及价格、补贴、金融、库存、政策时**，以主机厂/门店实际口径为准，预算建议不当成硬指标，最终以客户实际承受和战略意图为准。
- **适用范围**：仅主机厂（OEM）和经销店（Dealer）两类业务角色。不覆盖直营、二手车商、营销服务商三类场景。
