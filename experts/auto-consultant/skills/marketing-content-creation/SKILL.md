# 营销内容创作

通过 MCP `agent_invoke` 调用新致汽车新灵 AI 营销智能体，生成专业营销**内容**（种草/文案/话术/脚本/直播/GEO 文章）。

**本 skill 只管"内容创作"**——选车对比走消费者侧 skill、数据分析走营销诊断 skill，不在本 skill 重复。

## 🔴 关键核验点

先确认：品牌/车型（未指定先追问）、内容类型（种草/文案/话术/脚本/直播/GEO）、风格要求、发布平台、是否涉及具体数据（涉及则先 `cars` 查车型参数）。

## 渠道内容矩阵

多渠道分发不是把同一段内容复制粘贴，而是按各平台心智换表达。每个渠道都要明确三件事：用户为什么会停留、看完后想做什么、内容怎么导向留资/到店/私信。本 skill 的口径是——**先按渠道定内容策略，再用 `agent_invoke` 调对应智能体生成**。同一卖点换表达方式但不换内容核心，不同平台 CTA 不一样，每个平台都要保留品牌和车型准确性。

### 渠道内容矩阵表（渠道 → 心智 → 内容 → 调用智能体）

| 渠道 | 内容心智 | 适合内容 | CTA | 调用智能体 |
|---|---|---|---|---|
| 小红书 | 真实体验、场景种草 | 家庭场景、用车细节、避坑对比、提车日记 | 私信预约 / 到店试驾 | 种草达人 |
| 抖音 | 强钩子、短节奏 | 亮点演示、价格政策、试驾体验、冲突对比 | 评论 / 留资 | 视频创意导演 |
| 视频号 | 本地信任、熟人传播 | 门店活动、客户故事、直播预告、车主证言 | 预约到店 | 视频创意导演 / 直播策划师 |
| 朋友圈 | 熟人触达、关系链 | 活动海报、交车案例、限时权益、日常动态 | 企微咨询 | 私域文案师 |
| 社群 | 信息密度高、参与感 | 邀约、答疑、试驾提醒、政策解释、互动抽奖 | 确认时间 | 私域文案师 |
| 企微私聊 | 一对一推进 | 个性化邀约、政策说明、试驾确认、订单跟进 | 下一步动作 | 金牌销售教练 |
| 短信 | 一句话直达 | 召回、提醒、活动通知、政策到期提醒 | 回 T 预约 | 私域文案师 |
| GEO/AI搜索 | 被搜到、被引用 | 品牌深度文章、车型对比长文 | 搜索曝光 | GEO 内容策划师 |

### 各平台表达差异

- 小红书：场景种草，强调体验和细节，重图文与笔记
- 抖音：前三秒抓注意力，强调冲突和对比，重短平快
- 视频号：信任感和解释成本更低，依托熟人社交链扩散
- 朋友圈：短、准、带关系链语境，一屏内说清利益点
- 社群：信息密度高，强调参与感和行动，适合政策 + 互动
- 企微私聊：一对一推进，强调下一步动作，话术要个性化
- 短信：一句话直达，强调召回和提醒，附带明确动作

### 渠道内容生成模板（每个渠道一份）

调用 `agent_invoke` 时，按以下结构组装 prompt（平台目标 / 受众心智 / 内容角度 / 标题或开头 / 正文或脚本 / CTA / 注意事项）：

- 小红书 → `agent_invoke("种草达人", "渠道：小红书。心智：场景种草。主题：比亚迪海豹家庭用车细节。CTA：私信预约试驾。风格：轻松活泼、emoji、笔记")`
- 朋友圈 → `agent_invoke("私域文案师", "渠道：朋友圈。心智：熟人触达。主题：周末试驾会限时权益。CTA：企微咨询。一屏内说清利益点")`
- 抖音 → `agent_invoke("视频创意导演", "渠道：抖音。心智：强钩子短节奏。主题：海豹续航亮点演示，30秒。CTA：评论留资")`
- 企微私聊 → `agent_invoke("金牌销售教练", "渠道：企微私聊。心智：一对一推进。主题：试驾后跟进。CTA：确认下一步动作")`
- GEO 文章 → `agent_invoke("GEO 内容策划师", "渠道：AI搜索。心智：被搜到被引用。主题：海豹品牌深度。CTA：搜索曝光")`

## 路由决策（意图 → 智能体）

| 用户意图关键词 | 调用智能体 | 擅长 |
|---|---|---|
| 小红书/种草/测评/笔记/提车日记 | 种草达人 | 小红书种草笔记 |
| 朋友圈/社媒/社群/公众号/私域 | 私域文案师 | 朋友圈/公众号/社群文案 |
| 销售/话术/逼单/客户回访/试驾邀约/促单 | 金牌销售教练 | 全链路销售话术 |
| 直播/直播脚本/直播话术/带货 | 直播策划师 | 直播全流程脚本 |
| 短视频/视频脚本/分镜/抖音/快手 | 视频创意导演 | 短视频分镜脚本 |

## 调用方式（MCP）

### agent_invoke 调新灵AI营销智能体生成内容

用 MCP `agent_invoke` 调对应智能体：

```
agent_invoke(agentName="<智能体全名>", message="<品牌> + <场景/主题> + <风格要求> + <补充信息>")
```

**示例**（指引 AI 调用对应智能体）：
- 种草笔记 → `agent_invoke("种草达人", "写一篇比亚迪海豹的深度种草笔记，突出续航和智能化，风格轻松活泼")`
- 朋友圈文案 → `agent_invoke("私域文案师", "特斯拉 Model Y 降价，写一条朋友圈引导到店")`
- 销售话术 → `agent_invoke("金牌销售教练", "客户对比汉和 P7，怎么引导选汉")`
- 直播脚本 → `agent_invoke("直播策划师", "比亚迪海豹直播脚本，2小时，含互动抽奖")`
- 短视频脚本 → `agent_invoke("视频创意导演", "拍一条海豹抖音种草短视频，30秒，突出续航")`
- GEO 文章 → `agent_invoke("GEO 内容策划师", "写一篇海豹品牌深度文章，能被豆包和 DeepSeek 引用")`

### cars 查车型数据（辅助）

涉及具体车型参数时，先 `cars_search`/`cars_get` 查真实数据，再融入 agent_invoke 生成：
```
cars_search("比亚迪海豹") → 查续航/配置/价格 → 融入 agent_invoke prompt
```

### inspiration 查热点（辅助）

涉及热点选题时，先 `search_hot_topics`/`hot_topic_marketing_advice` 查行业热点：
```
search_hot_topics("新能源 SUV") → 查热点 → 融入选题方向
```

## 提示词组装规则（按优先级）

1. 未指定品牌/车型 → 追问后再生成
2. 涉及具体数据 → 先 `cars` 查车型参数
3. 涉及热点选题 → 先 `inspiration` 查热点
4. 未指定风格 → 用 智能体默认风格
5. 用户指定风格 → 用用户的

🔴 涉及具体车型/数据的内容创作，**必须先 cars 查真实数据再生成**（不编造参数/价格）。

## 失败模式与恢复

| 情况 | 一线应对 | 兜底 |
|---|---|---|
| 智能体输出为空 | 重试 agent_invoke | 换 AI 营销助手（默认） |
| 找不到智能体 | agents_list 查全名 | 用 AI 营销助手 |
| 内容偏离意图 | 补充风格/场景约束 | 用户原话完整传入 |
| 涉及数据但 cars 无 | 标注"以官方为准" | 不编造 |
| 网络超时 | 重试 | 告知用户稍后 |

## 反例黑名单（不要做）

| ❌ 不要 | ✅ 要 | 原因 |
|---|---|---|
| 编造参数/价格 | `cars` 查真实数据 | 虚假数据损害信誉 |
| 用违禁词（最/第一/唯一/顶级/销量冠军） | 客观表述（"行业领先""口碑好"） | 违反广告法 |
| 贬低竞品 | 客观对比（A 续航 650 vs B 600） | 陈述事实 |
| 未确认车型就生成 | 先追问品牌车型 | 避免错误内容 |
| 智能体名简称 | 用全名（"金牌销售教练"非"金牌销售"） | 避免误选 |
| 原样堆砌 智能体输出 | 组织为连贯内容并适配用户场景 | 片段不可直接用 |
| 在本 skill 做选车对比/数据分析 | 转走消费者侧/营销诊断 skill | 避免路由歧义 |

## 边界

- 不编造车型参数/价格/政策（用 `cars` 查或标注"以官方为准"）
- 不生成非汽车行业内容
- 不用广告法违禁词
- 不贬低竞品
- 涉及时效性内容（政策/价格），标注"以官方发布为准"
- 智能体输出需组织适配用户场景，不原样堆砌
- **选车对比/数据分析不在本 skill**（走消费者侧/营销诊断 skill）
