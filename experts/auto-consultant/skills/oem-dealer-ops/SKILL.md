# 主机厂品牌·新车上市·经销商网络管理

## 触发场景

主机厂/品牌方需要做三类核心职能之一：(1) 品牌定位、品牌战役、企业宣传、官方账号矩阵运营、公关发声与品牌资产沉淀；(2) 新车（全新车型/改款/年款）上市的 GTM 策略、节奏、传播矩阵、全国资源调配；(3) 经销商网络的规划选址、招商建店、商务政策、赋能培训、绩效考核与治理。这三件事都是品牌方/主机厂层面的职能，按"主机厂 → 经销体系"的逻辑贯穿。

## 功能说明

把主机厂的两类核心业务能力打通：**品牌与上市**是把产品势能和品牌资产转化为声量与订单，**经销网络**是把声量与订单沉淀为可持续的渠道能力。整体闭环为：品牌定位 → 品牌战役 → 新车上市 GTM → 经销网络承接 → 绩效考核 → 反哺品牌资产。严格区分品牌层动作（长期、全国、心智）与效果层动作（短期、本地、转化），以及主机厂管网络与单店自运营的边界。

## 🔴 关键核验点

启动前必须先确认以下五项，缺一就先补问，否则方案会失焦或与现实打架：

1. **品牌当前阶段**：新建 / 成长 / 成熟 / 焕新——决定声量级别和动作侧重。
2. **网络现状**：网点数 / 区域覆盖 / 产能利用率 / 空白市场——决定扩张、优化还是收缩。
3. **商务政策空间**：指导价体系、返利结构、补贴预算——决定激励和价格底线的设计空间。
4. **上市时间窗口**：避开竞品强势期 / 借势行业节点、产能爬坡节奏、是否全新品牌或全新车型。
5. **产能与交付**：订单-交付节奏管理（等车过久会流失订单并反噬口碑），首销期产能是否跟得上。

## 暂停与降级条件

- 品牌阶段不清时，先暂停：区分新建、成长、成熟、焕新后再定传播强度。
- 产能与交付节奏不清时，先暂停：不写全国上市承诺和首销目标。
- 商务政策空间不明时，先暂停：只写政策框架，不写返利、补贴和考核数值。
- 网络数据缺失时，先暂停：先补网点、销量、库存、满意度、空白城市和竞品网点密度。

## 一、品牌侧：品牌建设与企业宣传

### 1. 品牌定位与资产
- **品牌定位**：在消费者心智中的差异化位置（核心价值 + 个性 + 人群）。
- **品牌资产**：知名度、认知度、美誉度、忠诚度、品牌联想，定期用调研量化。
- **品牌故事与叙事**：支撑情感连接的长期叙事，不是单次广告片。
- **品牌主张 / 口号**：一句可传播的核心表达。

### 2. 品牌战役（Campaign）
- 年度 / 季度品牌大事件（上市、周年、行业节点）。
- 主题统一、多渠道协同（TVC + 社交 + 线下 + 公关）。
- 品牌层 KPI：品牌声量、搜索指数、心智占有率、NPS——不只看短期线索。

### 3. 官方账号矩阵运营

| 平台 | 定位 | 内容方向 |
|---|---|---|
| 微博 | 品牌发声 / 公关 / 热点 | 官方立场、事件、互动 |
| 微信公众号 | 深度 / 官方 / 服务 | 品牌故事、技术解读、车主服务 |
| 抖音 | 品牌年轻化 / 种草 | 短视频、直播、技术可视化 |
| 视频号 | 私域 / 微信生态 | 品牌内容触达微信用户 |
| 小红书 | 种草 / 女性 / 生活 | 用车场景、车主故事 |
| B 站 | 深度 / 技术 / 年轻 | 技术解析、UP 主共创 |

- **KOL/KOC 合作**：头部 KOL 做声量，KOC 做真实口碑，达人矩阵长期合作。
- **用户共创**：邀请车主参与内容创作（UGC 征集、自驾路书、用车故事）。
- **热点借势**：结合社会 / 行业热点做品牌传播（时效性 + 相关性 + 调性匹配）。

### 4. 企业公关与发声
- **媒体关系**：汽车媒体、财经媒体、行业媒体的日常维护与发声。
- **危机公关**：负面事件响应口径、声明、善后。
- **高管 IP**：企业高管对外发声、行业大会、采访。
- **品牌大事件传播**：发布会、车展、行业峰会。

## 二、上市侧：新车上市 GTM 策略

新车上市是主机厂最高频、最重资源的营销战役。核心是用"预热 → 发布 → 上市 → 首销 → 长尾"五阶段节奏，把产品势能转化为订单和声量，并协调全国资源（媒介 / 渠道 / 产能）。

### 1. 上市节奏五阶段

| 阶段 | 时长（参考） | 核心动作 | 目标 |
|---|---|---|---|
| 预热期 | 上市前 30-60 天 | 谍照 / 技术预热 / 盲订 | 制造期待、收盲订 |
| 发布期 | 上市前 7-15 天 | 发布会 / 价格公布 / 媒体试驾 | 价格锚定、声量峰值 |
| 上市期 | 上市当月 | 全国到店 / 大定转化 / 首发活动 | 订单转化 |
| 首销期 | 上市后 1-3 月 | 交付 / 口碑 / UGC | 交付与口碑沉淀 |
| 长尾期 | 上市后 3-12 月 | 内容 / 竞品应对 / 年款 | 持续获客 |

### 2. 传播矩阵
- **媒介组合**：TVC/OTV + 信息流 + 社交（微博 / 抖音 / 小红书 / B 站）+ 汽车 / 财经媒体 + 公关。
- **内容分层**：品牌层（发布会 / TVC）、产品层（技术解析 / 卖点）、口碑层（KOC / 媒体测评 / UGC）。
- **借势**：行业节点 / 车展 / 社会热点（与品牌调性匹配）。

### 3. 全国资源调配
- **媒介资源**：全国品牌投放 vs 区域效果投放的比例。
- **渠道资源**：首批到店车型 / 展车 / 试驾车的分配。
- **产能与交付**：订单-交付节奏管理（避免等车过久流失）。
- **区域策略**：重点城市 / 区域的资源倾斜。

### 4. 跨职能协同
- **联动部门**：产品（卖点 / 配置）、市场（传播 / 活动）、销售（渠道 / 订单）、交付（产能 / 物流）、售后（质保 / 服务）。
- **上市 SOP**：各部门时间表与里程碑，明确接口与责任人。

## 三、经销侧：经销商网络管理

主机厂对经销体系的"建-管-赋能-考"闭环。和门店执行协同 skill（单店内部运营）不同，本模块是主机厂对整个网络的规划与治理。

### 1. 网络规划与选址
- **区域市场分析**：城市级别 / 销量潜力 / 竞品网点密度 / 空白市场。
- **选址标准**：商圈类型、客流、面积、投资回报模型。
- **网络密度规划**：避免内耗（同城过多网点互相分流）。

### 2. 招商与建店
- 投资人画像与招募标准。
- 建店标准（形象 / 面积 / 功能分区：展厅 / 维修 / 交车 / 配件）。
- 验收与开业流程。

### 3. 商务政策设计
- **定价与指导价体系**：统一指导价 + 区域弹性空间。
- **返利结构**：销量返利 / 满意度返利 / 达标返利。
- **促销与补贴政策**：金融贴息 / 置换补贴 / 库存融资支持。
- **激励机制**：引导经销商做主机厂想要的行为（不只是压库）。

### 4. 经销商赋能与培训
- **产品培训**：新车 / 技术 / 卖点。
- **销售与运营培训**：流程 / 话术 / DMS 使用。
- **市场与数字化赋能**：线索运营 / 私域 / 新媒体。
- **考核认证体系**：分岗位、分级别认证。

### 5. 绩效考核与分级治理

考核维度：销量达成、市占率、满意度（CSI/NPS）、库存健康、资金状况、违规。分级管理（A/B/C/D），差异化资源投入：

| 等级 | 标准 | 资源投入 | 治理动作 |
|---|---|---|---|
| A（标杆） | 销量超额 + 满意度高 + 合规 | 新车首发、政策倾斜、返利上浮 | 树标杆、扩网点 |
| B（健康） | 达标、运营正常 | 常规资源 | 持续赋能 |
| C（预警） | 部分指标不达标 | 资源收紧、重点帮扶 | 整改计划、限期提升 |
| D（退出） | 长期不达标 / 严重违规 | 冻结政策、终止合作 | 退出 / 重组 |

- **预警与退出**：长期不达标网点的整改 / 退出机制。
- **防窜货、防乱价、防违规**：价格底线、跨区销售管控。

## 可视化输出

当用户要"上市节奏甘特图""经销商看板""网络地图"等可视化交付物时，输出**单文件 HTML**（内联 CSS/JS，可在浏览器直接打开），不要只给文字。常见类型：

- **上市节奏甘特图**：五阶段 × 动作 × 里程碑的时间轴，标注关键节点（发布会 / 价格公布 / 首批交付 / 长尾内容）。
- **经销商绩效看板**：A/B/C/D 分级分布、关键指标（销量达成 / 满意度 / 库存健康）的可视化卡片与图表。
- **网络覆盖地图**：网点在城市 / 区域的分布、空白市场标注。
- **传播矩阵热力图**：媒介 × 内容分层的预算或声量分布。

HTML 要：响应式、配色与品牌调性一致、关键数字突出、表格可读、必要时引入轻量图表（如 Chart.js CDN）。

无网络环境或审核要求离线可读时，不依赖外部 CDN；改用内联 CSS 和静态表格/简易 SVG 图表。

## 失败分支

| 情况 | 一线处理 | 仍失败兜底 |
|---|---|---|
| 产能不足 | 上市节奏降速，先保交付和口碑 | 减少承诺，分区域分批上市 |
| 商务政策空间不明 | 先输出政策框架，不写返利/补贴数值 | 要求财务和销售确认后再定稿 |
| 网络数据缺失 | 先列需补数据：网点、销量、库存、满意度、空白城市 | 用区域潜力假设版，不做最终选址 |
| 上市窗口撞竞品强势期 | 调整预热节奏和差异化话题 | 避开硬碰或转为区域试销 |
| 单店日常运营误入 | 转向营销内容创作能力 | 本技能只保留主机厂网络治理层判断 |

## 工作流程

1. 🔴 核验品牌阶段 / 网络现状 / 商务政策空间 / 上市时间窗口 / 产能。
2. （品牌侧）明确品牌定位与核心价值主张 → 规划品牌战役节奏 → 设计官方账号矩阵与 KOL/KOC 策略 → 定品牌资产监测指标。
3. （上市侧）规划上市五阶段节奏与目标 → 设计传播矩阵与内容分层 → 调配全国资源（媒介 / 渠道 / 产能）→ 定跨职能协同 SOP 与首发效果复盘指标。
4. （经销侧）网络规划与选址标准 → 设计商务政策（返利 / 补贴 / 激励）→ 规划赋能培训体系 → 定绩效考核与分级治理规则。
5. 三侧联动：品牌战役承接上市节奏、上市节奏通过经销网络落地、经销绩效反哺品牌资产。

## 输出模板

- 品牌定位一句话 + 核心价值主张；品牌战役规划（主题 / 节奏 / 渠道 / KPI）；官方账号矩阵分工表；KOL/KOC 合作策略；品牌资产监测指标（声量 / 搜索指数 / 心智 / NPS）。
- 上市节奏甘特图（五阶段 × 动作 × 里程碑）；传播矩阵（媒介 / 内容 / 预算）；全国资源调配计划；跨职能协同 SOP；首发效果复盘指标（声量 / 订单 / 转化 / 口碑）。
- 网络规划（区域 / 密度 / 选址标准）；商务政策框架（定价 / 返利 / 补贴）；经销商赋能培训计划；绩效考核体系（维度 / 权重 / 分级）；网络治理规则（预警 / 退出 / 防违规）。

## 边界

本技能聚焦**主机厂（OEM/品牌方）+ 经销商网络**两类业务角色，以下不在范围内：

- **不涵盖直营零售模式**（新能源直营门店、品牌自建零售的日常运营、直营店选址与人员管理）——直营体系职能需重新定义，不在本技能。
- **不涵盖二手车业务**（二手车评估、置换定价、二手车经销商运营、残值管理）。
- **不涵盖第三方服务商**（广告代运营、MCN、DSP、CRM SaaS、经销商集团层面的集团化管理）。
- **不涵盖单店内部运营**（单家 4S 店的展厅接待、销售流程、DMS 日常录入、交车流程）——这类问题由营销内容创作能力处理；本技能只做主机厂对整个网络的规划与治理。
- **不做具体媒介采买执行**（不替代媒介计划工具，只给组合策略与预算比例参考）。
- **不做财务级别的成本核算与税务规划**（返利 / 补贴给框架与方向，具体数额以财务模型为准）。

## 反例（不要做）

- 不把品牌动作和效果动作混为一谈（KPI 不同）。
- 不做无差异的"全平台搬运同一内容"。
- 不只追热点不顾品牌调性；品牌投入不苛求短期线索 ROI（看长尾声量与心智）。
- 不夸大、不攻击竞品、不虚假宣传（公关合规底线）。
- 不把上市当成单次发布会（节奏和长尾同样重要）。
- 不只看声量不看订单（声量高转化低是常见陷阱）。
- 不忽视产能与交付（订单来了交不出会反噬口碑）。
- 不在竞品强势窗口硬碰（择时）；不夸大配置 / 续航 / 智驾（上市承诺要兑现，否则口碑崩）。
- 不靠单纯压库驱动销量（伤网络健康）。
- 不忽视经销商盈利性（不赚钱的网点会反水 / 退网）。
- 不一刀切政策（不同区域 / 级别网点差异大）。
- 不重招商轻赋能（建店不等于会卖车）。
