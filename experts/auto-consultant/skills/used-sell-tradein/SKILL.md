# 旧车流转与家庭购车决策

覆盖消费者在二手车买卖、置换和家庭选车全链路上的判断与防坑：买二手车怎么核车况、防事故/水泡/调表；卖私家车怎么定价、选渠道、谈判过户；置换和单卖哪个划算；家庭多人意见不一致怎么收敛。

## 触发场景

- 用户准备**买二手车**，需要判断车况、价格是否合理、有没有事故/水泡/火烧/调表风险，以及交易和过户怎么防坑。
- 用户想**卖掉私家车**、做置换、比较单卖和置换哪个划算。
- **家庭成员意见不一致**（出资者/使用者/决策者），需要一份清晰的选车或卖车决策材料。

## 功能说明

二手车决策先看车况真实性，再看价格和交易安全；不能只因为便宜就推荐，也不能用新车配置逻辑替代二手车判断。卖车决策先定价、再选渠道、最后防坑；置换必须看"旧车估价 + 新车优惠"总账，不能只比旧车估价。家庭决策必须先识别出资者、使用者、决策者三重角色，再排序预算、安全、空间、补能和保值，不能写成"少数服从多数"。

## 🔴 关键核验点

不同起点给不同方案，别一上来就堆渠道对比或检测清单。

**买二手车先确认**：车型、年份、里程、报价、车源渠道、所在地、是否有检测报告、维保记录、出险记录和过户次数。

**卖车先确认**：用户是想卖车、置换、还是纠结两者哪个划算；车况（车龄/里程/事故/维保）；卖车原因和急迫度；是否同时在看新车；家庭是否多人决策（出资者/使用者意见）。

## 暂停与降级条件

### 买二手车

- 没有 VIN、拒绝查出险/维保、拒绝第三方检测时，停止给购买建议。
- 抵押未解、查封、无法正常过户时，停止交易推进。
- 价格明显低于行情时，先排查事故、水泡、调表、手续和金融陷阱。

### 卖车与置换

- 钱款未到账、过户节点不清时，停止交车或签署交付确认。
- 贷款车未解押、违章未处理、资料不齐时，停止过户推进。
- 家庭决策中预算红线不清时，先确认出资者承受上限，再比较车型。

## 路径分流

1. **买二手车**：先核车源信息和 VIN，再查历史记录，再按事故/水泡/火烧/调表/新能源专项检查车况，最后对比行情判断价格。
2. **卖车**：先估价，再选渠道，再做钱款和过户风控。
3. **置换**：先算旧车估价 + 新车优惠总账，再判断是否省心划算。
4. **家庭决策**：先识别出资者、使用者、决策者，再排序预算、安全、空间、补能和保值。

## 一、二手车买家决策

二手车决策先看车况真实性，再看价格和交易安全。不能只因为便宜就推荐，也不能用新车配置逻辑替代二手车判断。

### 检查维度

- 车况：结构件、漆面、底盘、发动机/电机、电池、内饰磨损
- 历史：出险、维保、过户、营运属性、抵押/查封
- 风险：事故、水泡、火烧、调表、重大维修
- 价格：同款同年同里程行情、车况溢价/折价
- 交易：合同、付款、过户、质保、平台/车商责任

### 必查资料

| 资料 | 用途 | 风险信号 |
|---|---|---|
| 行驶证 / 登记证 | 核对车主、过户次数、车辆性质 | 营运转非、过户频繁 |
| VIN / 车架号 | 查询出险、维保、召回 | 信息对不上 |
| 出险记录 | 判断事故和赔付金额 | 大额理赔、结构件维修 |
| 维保记录 | 判断保养连续性和里程 | 里程跳变、长期断保 |
| 第三方检测报告 | 辅助判断车况 | 报告过旧、检测项少 |
| 贷款/抵押状态 | 确认能否过户 | 抵押未解除、查封 |

### 看车重点

- **事故风险**：看前后纵梁、A/B/C 柱、翼子板内侧、焊点、胶线、螺丝拆卸痕迹。
- **水泡风险**：看座椅滑轨、安全带根部、地毯下方、后备箱备胎槽、线束泥沙。
- **火烧风险**：看机舱线束、保险盒、内饰异味、熏黑痕迹。
- **调表风险**：看方向盘、座椅、踏板、轮胎、维保里程与表显是否匹配。
- **新能源专项**：看电池健康、快慢充记录、底盘电池包磕碰、三电质保是否跟车。

### 二手新能源专项

- 电池健康：SOH、快慢充比例、是否长期高压快充。
- 质保权益：三电质保是否跟车、是否有首任车主限制。
- 底盘电池包：托底、磕碰、拆装痕迹。
- 充电记录：异常中断、频繁快充、冬季续航衰减。
- 软件和召回：是否完成官方升级和召回。

### 价格判断

| 情况 | 判断 |
|---|---|
| 价格明显低于市场 | 优先怀疑事故、水泡、调表、手续或金融陷阱 |
| 价格高于市场 | 需要车况、保养、低里程、官方认证或质保支撑 |
| 车商只谈月供 | 要求还原总价、利息、手续费和提前还款规则 |
| 拒绝第三方检测 | 高风险，建议放弃或换车源 |

### 工作流程

1. 核验车源基础信息和 VIN。
2. 查出险、维保、过户、抵押/查封状态。
3. 按事故、水泡、火烧、调表和新能源专项检查车况。
4. 对比同款同年同里程行情，判断价格是否合理。
5. 给继续看、复检、压价或放弃建议，并输出过户付款节点。

### 常见问题应对（if-then）

| 情况 | 一线应对 | 仍失败兜底 |
|---|---|---|
| 发现调表（维保里程与表显不符）| 按真实里程重估、查调表对残值和质保影响 | 放弃（调表车隐患大、残值虚高）|
| 车商拒绝第三方检测 | 坚持检测或自费请检测师陪同 | 放弃（拒绝检测多隐瞒重大问题）|
| 出险记录显示大额理赔 | 查结构件是否维修、判定是否事故车 | 按事故车大幅压价或放弃 |
| 过户发现抵押/查封未解 | 要求车主先解押、款项走第三方监管 | 中止交易（抵押车过不了户）|
| 车商压价套路（挑小毛病夸大成本）| 用检测报告+同款行情撑价 | 换车商或换车源 |
| 合同无车况承诺 | 要求补"无事故/无水泡/无调表"书面条款 | 不签（口头承诺维权无据）|

## 二、卖私家车

先定价、再选渠道、最后防坑。

### 渠道对比

| 渠道 | 到手价 | 速度 | 省心度 | 风险 |
|---|---|---|---|---|
| 4S/直营置换 | 偏低但可叠加新车补贴 | 快 | 高 | 低 |
| 二手车商收车 | 中低 | 快 | 高 | 压价 |
| 平台寄售/拍卖 | 中高 | 中 | 中 | 平台费、周期 |
| 个人交易 | 高 | 慢 | 低 | 过户/钱款风险 |

### 定价依据

- 同款同年同里程多平台行情
- 车况、事故、维保、过户次数
- 车龄、里程、品牌残值和当地需求
- 置换时看"旧车估价 + 新车优惠"总账

### 卖前准备

- **整备**：清洗内饰、处理小划痕、补齐随车工具。
- **资料**：登记证、行驶证、购车发票、保养记录、保险、钥匙。
- **手续**：清违章、确认贷款解押、确认指标和过户政策。
- **车况**：如实披露事故、大修、泡水等情况，避免后续纠纷。

## 三、置换总账

不要只看旧车估价，要看完整总账：

| 项目 | 置换方案 | 单独卖车 + 买新车 |
|---|---|---|
| 旧车到手价 | 4S/直营估价 + 置换补贴 | 平台/车商/个人成交价 |
| 新车优惠 | 是否因置换绑定优惠 | 可独立谈价 |
| 时间成本 | 通常省心省时 | 需要看车、谈价、过户 |
| 风险 | 手续代办，风险较低 | 钱款、过户、纠纷风险更高 |
| 最终判断 | 看总到手和省心度 | 看用户是否愿意多花时间 |

**判断规则**：

- 置换估价低但新车优惠高，要算总账。
- 单卖价格高但周期长，要看用户是否急用车/急用钱。
- 个人交易价高但风险高，必须优先保障过户和钱款安全。
- 贷款车要先确认解押流程和时间。

## 四、家庭购车决策

当家庭成员对预算、品牌、动力、空间、配置或风险意见不一致时，输出一页式决策材料。

### 决策材料要素

- 家庭真实需求
- 候选车型/方案
- 支持理由
- 反对理由
- 成本和风险
- 推荐优先级
- 试驾验证项

### 家庭分歧处理

| 分歧 | 处理方式 |
|---|---|
| 出资者重价格，使用者重体验 | 分开列"预算红线"和"高频体验"，先守预算再选体验 |
| 一方想纯电，一方担心长途 | 用通勤、家充、长途频率和补能路线判断，不争概念 |
| 老人/孩子乘坐需求被忽略 | 把上下车、后排舒适、晕车、儿童座椅纳入试驾 |
| 品牌偏好冲突 | 先回到安全、售后、成本和使用场景，而不是品牌情绪 |

## 失败分支

### 二手车（调表 / 拒检测 / 事故 / 抵押）

| 情况 | 处理 |
|---|---|
| 没有 VIN 或拒绝查记录 | 判定为高风险，不继续做价格判断 |
| 报价明显低于行情 | 优先排查事故、水泡、调表、抵押和手续问题 |
| 检测报告与卖家描述冲突 | 以第三方检测和记录为准，要求复检或放弃 |
| 发现调表 | 按真实里程重估残值，隐患大时直接放弃 |
| 出险记录显示大额理赔 | 查结构件是否维修，按事故车压价或放弃 |
| 无法当天过户 / 抵押未解 | 不交全款、不交车，明确尾款和过户节点；抵押车中止交易 |

### 卖车（压价 / 合同 / 过户）

| 情况 | 处理 |
|---|---|
| 车况资料不完整 | 先按保守区间估价，并列出需要补齐的资料 |
| 车商临场压价 | 要求列明压价原因，拿检测项逐条核对，不接受笼统压价 |
| 买方要求先过户后付款 | 拒绝；采用银行转账留痕和过户节点付款 |
| 合同无车况/无事故承诺 | 要求补书面条款，口头承诺维权无据则不签 |
| 家庭意见僵持 | 回到预算红线、安全底线、使用者高频需求三项排序 |

## 反例（不要做）

### 买二手车

- 不因为价格低就建议捡漏。
- 不用"看着挺新"替代记录和检测。
- 不帮助买方或卖方隐瞒事故、调表、水泡。

### 卖车与置换

- 不只比较旧车估价，不算新车优惠和时间风险。
- 不为了更高卖价隐瞒事故或重大维修。
- 不把家庭决策写成"少数服从多数"，要回到真实使用和预算约束。

---

## 边界

### 通用

- 不替代专业线下检测。
- 不保证车况真实性，也不保证最终成交价。
- 价格给区间和判断逻辑，不给绝对成交价。

### 买二手车

- 不帮助隐瞒事故、调表或车况问题。
- 不建议购买无法正常过户、手续不清或拒绝检测的车源。

### 卖车与置换

- 不诱导隐瞒车况。
- 不忽视过户、钱款和贷款解押风险。
- 不为了让家庭快速达成一致而忽略关键安全和预算风险。
- HTML 报告只在复杂对比、家庭沟通或用户明确要求时输出。
