# 客群分层 · 车型卖点 · 活动策划（前端营销表达）

把"这款车卖给谁、怎么讲、用什么活动承接"打通成一条前端营销链路：先用可执行维度对目标客群分层，再用 FAB 把车型参数翻译成客群能感知的利益卖点，接着用试驾会、团购会、商超展、置换季等活动把卖点变成到店理由。分层的目的不是贴标签，而是让后续活动、话术、线索跟进都能"对人说人话"；活动的目的是把卖点变成可量化的线索与成交。

渠道内容（每个渠道生成什么、怎么按平台心智换表达）不在本 skill，走 `marketing-content-creation`：本 skill 只在活动方案里给出"用哪些渠道触达、什么节奏"，具体内容矩阵和文案由内容创作 skill 调智能体生成。

本 skill 聚焦主机厂与经销体系（含区域/门店上市承接），不覆盖直营、二手车、服务商等其他角色，不制定全国上市 GTM 策略，不写购车消费者侧的选车砍价避坑指南（那是消费者侧 skill）。

## 触发场景

- 定义汽车营销目标客群、拆分不同人群打法，给不同渠道配置不同画像
- 新车卖点提炼、竞品差异化对标、发布话术、销售统一口径、内部培训材料
- 策划试驾会、商超展、团购会、置换季、交车仪式、车主活动、区域联动
- 给销售顾问可直接使用的一句话口径、邀约话术、跟进 SOP

> 为小红书/抖音/视频号/朋友圈/社群/企微/短信等渠道**生成具体内容矩阵和文案**，走 `marketing-content-creation`（本 skill 只定渠道触达节奏，不生成内容）。

## 🔴 关键核验点

拆解前必须先确认，缺一不可。车型/客群/竞品/用途缺失会输出空泛画像和万能话术；活动目标/预算/时间/渠道缺失会做成热闹型无结果活动。

**车型与卖点侧**

1. 车型定位与价格带：主力走量车型、利润车型还是形象车型
2. 目标客群：参考下方七大分层维度，至少明确主客群
3. 主要竞品：用于差异化对标，不做攻击性表达
4. 用途：销售口径 / 上市传播 / 活动主题 / 内部培训（具体渠道内容生成走 marketing-content-creation）
5. 用户业务角色：主机厂看全国大盘与区域，经销店聚焦门店 3-5 公里辐射圈，两者分层侧重和输出颗粒度不同

**活动与渠道侧**

6. 活动目标：曝光 / 留资 / 到店 / 试驾 / 成交 / 车主转介绍
7. 主 KPI（可量化）：留资数、到店数、试驾数、订单数、转化率
8. 城市 / 门店 / 区域范围
9. 预算与人手、场地、礼品、政策资源
10. 时间节点：含预热、现场、收尾节奏
11. 活动预热与传播节奏：预热—现场—收尾的渠道触达安排（具体渠道内容生成走 marketing-content-creation）

无车型定位、无客群、无用途就拆卖点 → 输出万能话术套所有客群；目标不可量化 → 活动做成热闹无结果。

## 暂停与降级条件

- 车型配置/价格带不确定：先暂停，只输出假设框架，不写确定卖点，标注需用官方配置校准
- 目标客群缺失：先暂停，至少确认主客群和使用场景，或先用七大维度生成候选客群让用户选
- 竞品缺失：用同价位同能源车型作参考，不做"领先竞品"式表述
- 主 KPI 不明确：把"热度、曝光、蓄客"转成留资、到店、试驾、订单或转介绍指标
- 预算/人手/场地/政策资源缺失：输出资源缺口表，不直接给满配活动方案
- 渠道选择不明确：按目标客群和门店资源确定 2-4 个主渠道
- 活动无线索承接人：先指定跟进责任和 CRM 状态，再写活动流程
- 用户要求精确占比或转化率但无数据：改用区间和假设，标注需用 CRM/调研数据校准

## 三个核心问题（先回答）

1. 这款车卖给谁（客群分层）
2. 凭什么买它（差异化卖点 + FAB）
3. 凭什么现在买（活动时机钩子：政策/上市/换购周期/限时权益）

## 输入

- 车型/品牌、价格带、能源类型、关键配置
- 用车场景假设、目标城市级别、门店/网点类型
- 当前客群描述、已有线索标签或老客数据
- 竞品车型和客户常问问题
- 活动车型或主题、活动目标与主 KPI
- 城市/门店/渠道范围
- 预算与人手、场地、礼品、政策资源
- 现有素材或核心卖点
- 想覆盖的平台与内容目标（种草/留资/到店/成交/维护）

## 客群分层

按可执行维度交叉分层，至少给出**主客群（1 个）+ 次客群（2-3 个）+ 高价值人群（1-2 个）**。分层的目的不是贴标签，而是让后续卖点匹配、活动到场理由、渠道触达、话术口径都能差异化。

### 客群七大分层维度

| 维度 | 典型切分 |
|---|---|
| 预算 | 10 万以下 / 10-15 / 15-25 / 25-40 / 40 万+ |
| 家庭结构 | 单身或双人 / 三口 / 二孩 / 三代同堂 |
| 用车场景 | 首购代步 / 家庭主力 / 增购第二台 / 越野露营 / 商务接待 |
| 购车阶段 | 认知期 / 对比期 / 决策期 / 复购换购 |
| 意向强度 | 泛兴趣 / 有预算无方向 / 已对比竞品 / 临门一脚 |
| 城市级别 | 一线 / 新一线 / 二三线 / 下沉县乡（补能、停车、限行差异大） |
| 价值贡献 | 一次性成交 / 售后高毛利 / 转介绍源 / 品牌裂变 KOC |

### 高价值人群判定标准

不是"买得起的"就是高价值。高价值 = 满足以下任一：

- 转介绍源：已购且社交圈重合度高（同小区/同公司/同车友会），老带新成本低
- 售后高毛利：倾向原厂保养、装潢、延保、金融保险打包
- 品牌 KOC：愿意产出 UGC（小红书/抖音/车友圈），天然传播节点
- 复购周期近：车龄或里程接近换购临界，置换概率高

### 按业务角色适配客群侧重

- 主机厂：看全国客群大盘与区域分布，输出商务政策、投放策略、车型定位建议；关注品牌长线与渠道赋能
- 经销店：聚焦门店 3-5 公里辐射圈的本地客群，重到店、试驾与转化；关注线索质量、到店率、成交周期、售后转化

### 客群分层卡（每个客群一张）

客群名称 + 占比估计 / 画像特征（预算·家庭·场景·城市）/ 核心诉求（一句话）/ 主要购买顾虑 / 推荐触达渠道（线上线下）/ 关键话术切入点 / 是否高价值人群及原因。

## 车型卖点拆解

每个卖点按"属性-优势-利益"三层写。参数是事实，利益才是卖点——营销侧要把参数翻译成客群能感知的购车理由，而不是堆砌技术参数。

### FAB 卖点拆解法

| 参数（属性 Feature） | 优势 Advantage | 用户利益（话术 Benefit） |
|---|---|---|
| 800V 高压平台 | 充电快 | "一杯咖啡充到一周通勤量" |
| 轴距 2900mm | 后排空间大 | "后排能翘腿，全家不憋屈" |
| 续航 700km | 少焦虑 | "跨城往返不用找桩" |
| 高强度钢车身 | 被动安全好 | "全家出行更放心" |

### 卖点分类（避免堆砌）

- 核心卖点（1-2 个）：最强、最差异化的，所有渠道都打
- 差异化卖点（2-3 个）：相对竞品的独特优势
- 防御卖点：回应常见顾虑（续航/安全/保值/补能）
- 场景卖点：按人群匹配（家庭/通勤/年轻/企业）

### 按人群匹配表达

| 人群 | 关注 | 话术角度 |
|---|---|---|
| 家庭用户 | 空间、安全、舒适 | "全家坐得舒服、开得放心" |
| 通勤用户 | 能耗、补能、好开 | "省心省钱，每天通勤不心疼" |
| 年轻用户 | 颜值、智能、社交 | "好看好玩，发朋友圈有面" |
| 企业用户 | 成本、稳定、效率 | "TCO 低、可靠、出勤率高" |

### 客群-卖点匹配表

| 客群 | 关键诉求 | 主推卖点（FAB） | 销售口径 | 风险/不适合 |
|---|---|---|---|---|
| 家庭用户 | 安全、空间、舒适 | ... | ... | ... |
| 通勤用户 | 能耗、补能、好开 | ... | ... | ... |
| 年轻用户 | 颜值、智能、社交 | ... | ... | ... |
| 企业用户 | 成本、稳定、效率 | ... | ... | ... |

### 车型卖点总表

一句话定位 / 3 个核心卖点（FAB）/ 2-3 个差异化卖点（对标竞品）/ 适合人群 / 不适合人群 / 渠道表达差异（销售口径 vs 短视频 vs 小红书）/ 竞品对比时的表达边界 / 销售培训重点。

## 活动策划

把活动目标、车型卖点、目标客群、渠道预热、现场承接和后续跟进串成闭环。活动不只是热闹，必须明确收什么线索、怎么邀约、谁跟进、用什么指标复盘。

### 活动类型

- 周末试驾会
- 商超展 / 城市展厅活动
- 区域上市承接活动（承接主机厂上市节奏，不制定全国上市 GTM 策略）
- 置换季 / 以旧换新
- 团购会 / 限时政策活动
- 交车仪式 / 车主活动
- 区域联动 / 社区地推

### 活动工作流

1. 明确活动目的和主 KPI
2. 选定客群和到场理由（联动客群分层卡）
3. 设计主题、利益点和现场流程（联动车型卖点）
4. 拆解现场执行与线索转化路径
5. 安排活动预热与传播节奏（具体渠道内容生成走 marketing-content-creation）
6. 设计现场留资、试驾、成交和转介绍动作
7. 输出人员分工、物料清单和复盘指标

### 执行清单

逐条核验，任何一条缺失都要补上：

- 活动目标是否可量化
- 目标客群是否清晰
- 物料是否围绕主卖点
- 现场是否有留资入口
- 试驾或到店是否有承接动作
- 现场动线是否清晰
- 销售动作是否与活动节奏同步
- 复盘指标是否提前定义

### 现场设计要点

- 入口要有明确主卖点，第一眼即传递价值
- 现场要有清晰动线，引导留资—试驾—洽谈—成交
- 线索收集路径要尽量短，减少跳失
- 主持话术要统一，避免不同销售口径冲突
- 销售动作要与活动节奏同步（暖场—高潮—逼单—收尾）
- 礼品/政策要设置阶梯，对应留资、试驾、下定等节点

### 活动方案模板

活动一句话目标（可量化）/ 目标客群 / 主推车型与卖点 / 活动主题 / 传播节奏（预热—现场—收尾）/ 现场流程 / 人员分工 / 物料清单 / 线索收集和跟进 SOP / 转化动作 / 复盘指标。

## 工作流程（端到端）

1. 🔴 核验车型定位/价格带、客群、竞品、用途、业务角色 + 活动目标/KPI/预算/时间/渠道
2. 从七大维度交叉分层，定主客群 + 次客群 + 高价值人群
3. 提炼产品事实（参数），用 FAB 翻译成利益卖点，分核心/差异化/防御/场景卖点
4. 为每个客群匹配核心诉求、顾虑、触达渠道、话术口径
5. 选定活动类型和客群到场理由，设计主题、利益点、现场流程
6. 拆解现场留资、试驾、成交、转介绍动作和线索跟进 SOP
7. 定活动预热与传播节奏（用哪些渠道触达、什么节点），具体内容生成交 marketing-content-creation
8. 输出客群卡、卖点总表、活动方案、复盘指标

## 输出要求

- 每个客群给 2-4 个核心购买理由，每个卖点落到真实用车场景
- 明确"不适合人群"，避免过度推销
- 给销售顾问可直接使用的一句话口径
- 涉及竞品做场景化差异表达，不攻击竞品
- 占比和转化率没数据时用区间或假设标注，不编精确数字
- 活动目标必须可量化，每个动作对应到线索或成交

## 可视化输出

当出现复杂对比或多模块交付时，输出 HTML 可视化报告，便于培训和传播物料直接使用：

- 客群-卖点-渠道-话术矩阵
- 车型卖点图谱（核心/差异化/防御/场景）
- 多客群对照表、竞品对比卡片
- 活动排期甘特图（预热/现场/收尾节点）
- 区域/门店活动承接看板

## 失败分支

| 情况 | 一线处理 | 仍失败兜底 |
|---|---|---|
| 无车型配置 | 只按价格带和能源类型做假设版 | 标注需补官方配置后再定稿 |
| 无目标客群 | 先用七大维度生成候选客群 | 让用户选择主客群后再拆话术 |
| 无竞品 | 用同价位同能源车型作参考 | 不做"领先竞品"式表述 |
| 配置不确定 | 不写具体参数承诺 | 改写为待确认卖点 |
| 只给活动主题 | 追问目标、车型、客群、渠道和主 KPI | 缺数据时先给假设版框架 |
| 目标只写"提升热度" | 转成留资、到店、试驾、订单或转介绍指标 | 拒绝输出无 KPI 的热闹方案 |
| 渠道资源不足 | 优先做少数高确定性触达渠道 | 不铺满所有平台 |
| 有线索无人跟进 | 补跟进 SOP 和责任人 | 拒绝输出无线索承接的活动方案 |

## 反例（不要做）

- 只列参数不写用户收益（参数 ≠ 卖点）
- 把万能话术套给所有客群
- 给所有人群推同一款配置
- 用"年轻白领""成功人士"这类空泛标签替代真实画像
- 只写活动主题口号和海报文案，把现场热闹当转化结果
- 夸大安全、续航、智驾、保值等能力，堆砌技术参数当卖点
- 做贬低竞品的攻击性表达，生成虚假承诺

## 边界

- 不用空泛标签替代真实画像
- 不夸大能力、不堆砌参数、不攻击竞品、不虚假承诺
- 不把同一句卖点塞给所有人群和渠道
- 每个客群必须能对应到具体内容和动作，否则不成立
- 占比、转化率没数据时用区间或假设标注，不编精确数字
- 不确定配置和价格时，提醒以官方和门店实际信息为准
- 不把活动写成只有主题和口号的"热闹型活动"，每个动作都要能对应到线索或成交
- 不为流量牺牲车型信息准确性
- 不承诺虚假优惠、库存或交付周期
- 所有价格、金融、权益和补贴以官方/门店实际政策为准
- 不制定全国上市 GTM 策略（仅做区域/门店上市承接）
- 不覆盖直营、二手车、服务商等其他角色，聚焦主机厂与经销体系
- 不写购车消费者侧的选车、砍价、避坑指南（那是消费者侧 skill）
