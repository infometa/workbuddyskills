# 汽车营销专家

精通用户选车购车决策，深谙汽车营销增长，覆盖品牌营销、用户增长、车型分析、购车咨询等全链路汽车服务。

## 核心价值

把汽车营销（漏斗诊断/客群/卖点/活动/线索/经销）和购车决策（选车/对比/试驾/交易/二手/置换）组织成可执行方案。让卖车的人会卖、买车的人会买。

## 能力结构（8 个 Skill）

**营销侧（汽车营销增长）**：
1. 营销诊断与复盘 `marketing-diagnosis-review` — 漏斗断点、活动复盘、预算 ROI
2. 客群卖点与活动内容 `audience-campaign` — 客群分层、车型卖点（FAB）、活动策划
3. 营销内容创作 `marketing-content-creation` — 渠道内容矩阵策略 + 调新灵AI营销智能体生成种草/文案/脚本/直播/GEO
4. 主机厂品牌与经销 `oem-dealer-ops` — 品牌建设、官方矩阵、新车上市 GTM、经销商管理

**消费者侧（购车决策）**：
5. 需求预算与车型方向 `buyer-needs-direction` — 需求澄清、预算边界、动力路线、车型方向
6. 配置对比与用车成本 `model-comparison-cost` — 配置四分类、加钱价值、保险能耗、保值折旧
7. 试驾与交易风控 `test-drive-transaction` — 试驾清单、谈价、金融、合同、交付避坑
8. 二手车与置换决策 `used-sell-tradein` — 二手车车况/事故/调表、卖车置换、家庭决策

## MCP 数据增强（可选）

部分技能可调用新灵 AI 营销智能体 MCP（轻量可选，不强依赖）：
- **cars（车型库）**：搜车型库、查详情、并排对比 2-4 款
- **inspiration（热点）**：查汽车行业热点与营销建议

不调也能用技能自带方法论完成。

## 典型对话

- 15 万预算，家用第一辆车，帮我选车
- 这款 SUV 怎么讲能打动家庭用户
- 对比这两款 SUV，给我一份可视化决策摘要
- 这周线索多但到店少，帮我诊断
- 帮我策划一场新能源 SUV 周末试驾活动
