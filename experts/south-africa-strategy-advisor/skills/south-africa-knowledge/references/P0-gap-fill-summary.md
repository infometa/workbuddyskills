## 一、公正能源转型投资计划（JET-IP 2023-2027）

> 来源：JET-IP FINAL, 216页 | COP26产物

### 核心框架

| 维度 | 数据 |
|------|------|
| 执行期 | 2023-2027（5年） |
| IPG初始承诺 | **USD 85亿**（法/德/英/美/欧盟） |
| 总投资需求 | **~R1.5万亿** |
| 三大优先行业 | 电力/新能源汽车(NEV)/绿色氢能(GH2) |
| 交叉投资 | 技能发展/经济多元化/社会支持 |

### JETP背景

- COP26期间南非与IPG（国际合作伙伴集团）签署政治宣言
- 总统气候融资工作组(PCFTT)领导制定
- 内阁级部际委员会(IMC)监督
- 与NDC（国家自主贡献）及2050低排放发展战略对齐

### 电力脱碳

- 煤电退役：普马兰加省是地面零位(mpumalanga)
- 可再生能源替代+公正转型（煤矿社区经济多元化）
- Eskom JET项目管道

### 融资框架

| 类别 | USD 85亿来源 |
|------|------------|
| 优惠贷款 | 主要占比 |
| 商业贷款 | 部分 |
| 赠款 | 少量 |
| 担保 | 技术援助 |

### 战略启示

- **IPG USD 85亿只是催化剂**，实际需求R1.5万亿 — 投资缺口巨大
- 煤电退役集中在普马兰加 — 该国转型的社会经济脆弱性最高
- NEV和GH2作为新兴产业纳入 — 非纯电力故事
- 这是中资企业参与SA绿色转型的**最大政策框架入口**

## 二、银行业与金融稳定

> 来源：SARB FSR 2024 / Banking Peer Report / SARB Annual Report / BASA

### 银行业健康度

| 银行 | 半年度核心盈利(R百万) | 数字客户(百万) | 定位 |
|------|-------------------|-------------|------|
| Standard Bank | 21,231 | 16.2 | 非洲最大 |
| FirstRand | 36,735(FY) | 10.4 | 最高盈利 |
| Absa | 11,159 | 2.8 | 零售强 |
| Nedbank | 7,329 | 2.76 | 绿色金融领先 |

### 金融稳定（SARB FSR 2024）

- **四大行均盈利且资本充足** — CET1比率远超监管要求
- **主权-银行关联风险**是最大系统性风险（银行资产中政府债券占比高）
- 不良贷款ECL覆盖率逐步提高
- 影子银行监管加强中
- FATF灰名单**已于2025年10月移除** — 重大正面信号
- 家庭负债/GDP比率可控但上升

### SARB货币政策

- 双重使命：物价稳定 + 金融稳定
- 通胀目标：**3%**（2025年正式调整）
- 政策利率正常化路径渐进
- 外汇储备提升中

### 战略启示

- **金融服务业占GDP 20%+** — 是南非最具全球竞争力的产业
- 四大行健康 → **项目融资可获得性强**
- 主权-银行关联意味着财政改善直接利好金融股/债券
- 数字银行爆发（Standard Bank 16.2M数字客户）→ Fintech竞合

## 三、资本市场 / JSE

> 来源：JSE Integrated Annual Report 2024

### JSE核心数据

| 指标 | 2024数据 |
|------|---------|
| **总市值** | **R19.23万亿** |
| 上市企业 | 280家（含131两地上市） |
| 全球排名 | Top 20 |
| 非洲排名 | **第1**，无可争议 |

### 三大市场

| 市场 | 功能 |
|------|------|
| 公开市场 | 股权+债券一级/二级交易 |
| 私募市场 | 未上市企业融资 |
| 自愿碳市场 | 碳信用交易（非洲首个） |

### ESG披露

- **可持续发展披露指南**：对标ISSB/IFRS S1 S2
- **气候披露指南**：范围1/2/3碳排放强制/建议披露
- JSE是非洲ESG标杆交易所

### 战略启示

- R19万亿规模意味着**退出通道充足**（私募→IPO）
- 碳信用交易平台是非洲唯一 — 绿色项目可在此变现
- 上市企业须符合ISSB全球基准 — 倒逼企业ESG治理提升

## 四、绿色金融分类法

> 来源：SA Green Finance Taxonomy 1st Ed (2022年3月)

### 核心定义

- **南非国家财政部发布**的官方"绿色"经济活动标准
- 对标EU Taxonomy框架
- 覆盖行业：能源/交通/水务/建筑/制造/农业/ICT

### 绿色资格（部分示例）

| 行业 | 绿色活动 |
|------|---------|
| 能源 | 光伏/风电/储能/水电（需满足生态标准） |
| 交通 | 零排放车辆/充电基础设施/铁路电气化 |
| 建筑 | 绿色建筑认证/能效改造 |
| 水务 | 废水处理/海水淡化（可再生能源驱动） |
| 制造 | 循环经济/低碳材料生产 |

### 战略启示

- **绿色债券/绿色贷款发行**以此分类法为准
- 非"绿色"的项目无法获得绿色融资标签
- 2022年第一版，仍在迭代中 — 政策方向只会更严
- 中资绿色项目（可再生能源/储能/电动车）基本全覆盖

## 五、AfCFTA深度分析

> 来源：AfCFTA协定全文 + CIS + 补充研究

### 协定框架

| 维度 | 内容 |
|------|------|
| 签署国 | 54个非盟成员国 |
| 覆盖人口 | **13亿** |
| 目标 | 建立单一大陆商品和服务市场 |
| 关税削减 | 90%商品关税逐步取消 |
| 覆盖领域 | 商品/服务/投资/知识产权/竞争/电子商务 |

### 对南非的战略意义

- 南非是非洲最工业化经济体 → **最大受益方之一**
- 为SA制造品（汽车/化工/钢铁/农产品加工）打开大陆市场
- 南部非洲关税同盟(SACU)与AfCFTA规则衔接是关键议题
- CIS六大投资驱动因素排名第三（非洲一体化）

### 主要机会行业

| 行业 | AfCFTA优势 |
|------|----------|
| 汽车 | 南非是唯一有规模整车制造能力的非洲国家 |
| 钢铁 | 非洲每年进口R4000亿钢铁 |
| 农产品加工 | SA食品加工业全非洲最成熟 |
| 化工/塑料 | 本地原料+制造基础 |
| 服务贸易 | 金融/电信/物流辐射全非洲 |

### 风险

- 原产地规则谈判尚未完成 — 关税优惠的不确定性
- 非关税壁垒（清关/标准/许可）仍然是最大障碍
- 基础设施差距（港口/铁路/公路）限制贸易通畅
