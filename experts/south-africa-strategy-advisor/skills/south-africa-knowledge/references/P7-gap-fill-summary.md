# P7 B级实操补充

## 一、知识产权注册（CIPC）

### 注册体系

| 类型 | 法律 | 期限 | 审查制 | 周期 |
|------|------|------|-------|------|
| 专利 | Patents Act 1978 | 20年 | **非实审(登记制)** | 8-18月 |
| 商标 | Trade Marks Act 1993 | 10年(可续) | 实质审查 | 24-36月 |
| 外观设计 | Designs Act 1993 | 美学15年/功能10年 | 形式审查 | 6-9月 |

### 核心注意

| 要点 | 详情 |
|------|------|
| 专利非实审 | **授予≠有效**——只在撤销/侵权诉讼中检验。容易获得但维权时被反诉无效风险高 |
| 商标在先权 | 先申请制+非使用5年撤销 |
| 国际条约 | PCT成员(30月)/巴黎公约/TRIPS/**非马德里成员**(2015年加入但未执行) |
| 非Madrid | 商标必须本地申请 |
| 费用 | 商标单类约R590/专利约R3K-8K |

### 知识产权执法

| 执法工具 | 说明 |
|---------|------|
| 禁令 | 制止持续侵权 |
| 损害赔偿/合理许可费 | 民事救济 |
| 海关干预 | 可申请扣押进口假冒商品 |
| 《反假冒商品法》 | 假冒商标刑事责任 |
| 实务 | 执法效率中等——海关扣押需主动提供侵权信息 |

## 二、反垄断申报（Competition Act）

### 2026年5月1日新版门槛

| 合并类型 | 双方合计 | 目标公司 | 申报费 |
|---------|---------|---------|-------|
| **小合并** | <R10亿 或 | <R2亿 | 无需申报 |
| **中级合并** | ≥R10亿 且 | ≥R2亿 | **R22万** |
| **大型合并** | ≥R95亿 且 | ≥R2.8亿 | **R73.5万** |

小合并豁免但竞争委员会可在6个月内追索。

### "公共利益测试"独特框架

| 维度 | 评估因素 |
|------|---------|
| 竞争影响 | 市场集中度/单边效应 |
| 公共利益 | **就业影响/特定产业影响/中小企业影响/全国经济利益/历史上受歧视群体** |
| B-BBEE | 并购后BEE结构变化是核心考量 |

### 审查周期

| 阶段 | 时间 |
|------|------|
| Phase I(中级) | 20个工作日 |
| Phase II(扩展) | +40个工作日 |
| 大型合并Commission | 同上 + Tribunal审批 |
| 实务周期(简单) | 25-30工作日 |
| 复杂/争议 | 60+工作日 |
| 大型(Tribunal) | 4-8个月 |

### 处罚
实施未申报 = 合并总营收**10%罚款** + 强制剥离 + 撤销交易。

### 外资并购特别提示
- **任何涉及SA营业额/资产的交易都要评估申报义务**
- 即使海外两家公司合并——只要一方在SA有≥R2亿营收/资产 → 触发中级合并
- 就业+公共利益测试——SA是全球最严格之一

## 三、POPIA数据保护

### 合规框架

| 维度 | 要求 |
|------|------|
| 信息官 | **必须注册IO**(CEO默认担任) |
| 八项条件 | 问责/处理限制/目的特定/进一步处理限制/信息质量/公开/安全/数据主体参与 |
| 安全事件报告 | 自2025年4月起**必须通过电子门户**

### 跨境数据传输(§72)

允许条件（五选一）：
1. 接收方有充分法律保护
2. 数据主体同意
3. 为履行合同所必需
4. 为数据主体利益订立合同
5. 为数据主体利益且无法合理获取同意

### 处罚力度

| 类型 | 上限 |
|------|------|
| 行政罚款 | **R1,000万** |
| 刑事责任 | **最高10年监禁** |
| 民事诉讼 | 数据主体可在无过错责任下提起诉讼 |
| 监管态势 | 2026年从"过渡期"→"系统性执法期" |

### 2025年4月修订
- 安全事件必须电子门户通报(284件/月)
- 直接营销须获得明确明示同意
- 更便捷的数据主体反对/删除/更正请求通道

## 四、物流通关实操

### Durban港口现状

| 指标 | 数据 |
|------|------|
| CPPI排名 | 398/405(2024) |
| 处理能力 | SA集装箱运输60% |
| 实际清关周期 | 3-10天（理想）/拥堵期可20+天 |
| 风天停工 | 常见（港口建筑设计缺陷） |

### 保税仓操作

| 类型 | 用途 |
|------|------|
| 海关保税仓(OSBL) | 延期缴纳关税/增值税 |
| 保税制造仓(Storage in Bond) | 进口原料→制造→出口 |
| SARS监管 | 定期审计/保证金要求 |

### SARS海关估值争议

| 步骤 | 内容 |
|------|------|
| 1. 估价方法 | WTO估价协定六法（交易价值为主） |
| 2. 异议 | 收到估值通知后30天内提出 |
| 3. 内部申诉 | SARS内部审查 |
| 4. 税务法庭 | 不服→Tax Court |
| 实务建议 | 保留完整进口文档/关联交易要有同期转让定价文档 |

### 清关加速实务

- **优先通道**(Preferred Trader)：AEO认证——合规进口商优先放行
- SARS电子清关系统(eCN)
- 预清关申报
- 考虑替代港口：Richards Bay/Ngqura(Coega)/Maputo(莫桑比克)
