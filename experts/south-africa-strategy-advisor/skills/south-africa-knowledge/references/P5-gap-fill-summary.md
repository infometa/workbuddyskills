# P5实操缺口补充

## 一、签证/移民实操指南

### 关键技能签证(Critical Skills Work Visa)

| 项目 | 详情 |
|------|------|
| 法律依据 | Immigration Act 13/2002 §19(4) |
| 有效期 | 最长5年 |
| 官方处理周期 | **4周**（DHA 2026/27目标） |
| 实际处理周期 | 6-10周（含SAQA+专业注册前置） |
| 费用 | DHA R425 + VFS ~R1,550 |
| SAQA学历评估 | R2,270(首份)/R950(附加)/4-6周 |
| 关键优势 | 无需job offer/可自由换雇主/满5年可申PR |

### 商务签证(Business Visa)

| 项目 | 详情 |
|------|------|
| 最低投资 | **R500万**（可申请DTIC豁免） |
| DTIC推荐信 | 必须（2-4周处理） |
| 本地雇佣要求 | ≥60%南非员工 |
| 官方处理周期 | **8周**（2026/27目标） |
| 实际处理周期 | 8-12周（DTIC+VFS合计） |
| 费用 | VFS R1,520 + DHA R1,550 |

### 可信雇主计划(Trusted Employer Scheme)

- DHA推出的快速通道，面向合规大型雇主
- 需要DTIC推荐信+良好合规记录
- 可加速技能签证审批

### 实际处理周期现实

| 签证类型 | 官方目标 | 实际经验 |
|---------|---------|---------|
| 关键技能 | 4周 | 6-10周（不含SAQA） |
| 商务签证 | 8周 | 8-12周（含DTIC） |
| 访客签证 | 60天 | — |
| 永久居留 | 240天 | 6-12个月常见 |

### 全套前置文件清单
警察无犯罪证明（2-8周）+ SAQA学历评估（4-6周）+ 专业注册（2-8周）+ VFS预约 → 总前置流程：2-4个月

## 三、环境合规流程

### EIA（环境影响评估）

| 步骤 | 时间 |
|------|------|
| 提交申请 | Day 0 |
| 基础评估报告(BAR)提交 | 90天内 |
| 公众参与期 | ≥30天 |
| CA审批(BAR) | 107天内 |
| **BAR全程** | **~4-6个月** |
| 范围界定报告(Scoping) | 44天内提交 |
| CA接受范围报告 | 43天 |
| 完整EIA报告 | 106天内 |
| CA审批(S&EIR) | 107天 |
| **S&EIR全程** | **~10-12个月** |

### 用水许可证(WUL)

- 监管：Department of Water and Sanitation (DWS)
- 矿业/农业/工业用水必须申请
- 审批周期：6-18个月（取决于复杂性和水资源紧缺程度）
- 战略性水资源评估前置

### 矿业权获取步骤

| 步骤 | 内容 | 周期 |
|------|------|------|
| 1. 勘探权申请 | DMR提交+环境授权 | 3-6个月 |
| 2. 勘探完成 | 地质报告+可行性研究 | 1-3年 |
| 3. 采矿权申请 | 含Mining Charter BEE计划+社会劳工计划(SLP) | 6-12个月 |
| 4. 采矿权授予 | DMR部长审批 | — |
| 5. 环境管理计划(EMP) | 须与采矿权同时审批 | 同步 |
| 6. 财务拨备 | Environmental Financial Provisioning | 授权前置 |

### 关键合规节点
- **BAR(基础评估)**= 低影响项目，4-6个月
- **S&EIR(范围+完整EIA)**= 高影响项目，10-12个月
- **Water Use License**= 补充，可能6-18个月
- **Mining Right**= 从头到尾3-5年

## 四、制药/医疗本地化

### SAHPRA药品注册

| 项目 | 详情 |
|------|------|
| 性质 | WHO认可的Stringent Regulatory Authority(SRA) |
| 格式 | ICH CTD/ eCTD接受 |
| 审批周期 | **12-24个月**（新药） |
| 费用 | ~$3,000-$6,000 |
| 快速通道 | HIV/TB/疟疾优先级药品可加快 |
| 国际依赖 | 被EMA/WHO批准的药品可走依赖路径 |
| ISO 13485 | 2028年4月1日起所有新申请必须包含 |

### 本地制药产能

| 企业 | 领域 | 备注 |
|------|------|------|
| Aspen Pharmacare | 通用名药/ARV/疫苗 | JSE上市/全球Top 10通用药企 |
| Adcock Ingram | OTC/医院产品 | — |
| Biovac | 疫苗(Covid/常规) | PPP公私合作模式 |
| Cipla SA | ARV/通用名药 | 印度母公司 |

### ARV本地化采购政策

- SA是全球最大ARV采购国之一
- 国家卫生实验室(NHLS)+卫生部门联合招标
- 本地制造优先：ARV招标含本地化含量要求
- Aspen + Cipla SA 承担主要ARV国内供应
- 与NHI法案联动：未来本地化采购比例将进一步上升

### 医疗技术Master Plan 2027
- 目标：本地市场份额从6%→**20%**
- 鼓励中小企业在本地生产和出口
- 对标SAHPRA注册+ISO认证
