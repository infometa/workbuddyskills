## 一、Northern Cape — 矿业+可再生能源超级大省

| 指标 | 数据 |
|------|------|
| GDP | R1640亿，目标2030→R2000亿 |
| 人口 | 稀疏（南非面积最大/人口最少） |
| 矿业 | 世界最大锰矿/铁矿石/钻石/锌/稀土/铜 |
| 可再生能源 | **SA 60% IPP集中于此** / 太阳能26%容量因子/风电37% |
| 新投资承诺 | **R1050亿+**（2026年4月投资大会）/ 19,800新岗位 |
| 失业率 | 全国最低之一 |
| 犯罪率 | 全国最低 |

### 重点项目

| 项目 | 投资(R) |
|------|------|
| Vedanta锌矿扩产+Gamsberg→世界最大锌矿 | 170亿 |
| Anglo American/Kumba铁矿扩产 | 112亿 |
| IPPO Upington能源园 | 300亿 |
| Ando Energy绿色能源 | 168亿 |
| Mulilo绿色能源 | 130亿 |
| Prieska Power Reserve绿氢/氨(2030投产) | 120亿 |
| Boegoebaai深水港+绿氢枢纽 | 1229亿 |
| 南非大西洋三文鱼水产园 | 15亿 |

### 战略定位
- **全球能源转型的"矿区+绿电"双料冠军**
- Kathu工业园/Namakwa SEZ驱动本地选矿
- 稀土项目(Frontier Rare Earths)获IDC R3亿支持
- 农业：最大雇主→葡萄干/柑橘/牛肉/羊肉/卡拉库尔

## 二、Mpumalanga — 煤炭中心转型Just Transition地面零位

| 指标 | 数据 |
|------|------|
| GDP占比(全国) | 7.7%（第五大） |
| 人口 | 508万(2025)，全国8% |
| 失业率 | 32.3%（Q4 2025，第四低） |
| 三大产业 | 个人服务18.7%/金融18.2%/矿业15.2% |
| 就业 | 128万(Q4 2025) |
| 基尼系数 | 0.541（全国最低） |

### 经济结构
- 煤炭价值链根深蒂固：Sasol Secunda（世界最大合成燃料厂，日产6000万升）
- 铁合金+不锈钢：Columbus Stainless(非洲唯一)、Samancor（世界第二大铬铁）
- 旅游：Kruger国家公园年收入R20亿，260万国际游客(2024)
- 农业：甘蔗/亚热带水果/澳洲坚果加工

### JET转型
- **南非公正能源转型的核心省份**
- UK Growth Gateway识别9个活跃经济部门
- 四大优先：可再生能源/非煤采矿与选矿/绿氢/水务
- SMME高度依赖煤炭→转型期最脆弱
