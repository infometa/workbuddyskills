## 三、技能开发SDL & SETA

### SDL框架

| 维度 | 内容 |
|------|------|
| 税率 | **1%工资总额** |
| 收缴 | SARS每月 |
| 分配 | 80%→SETA + 20%→国家技能基金 |
| 用途 | 培训拨款/学徒制/实习/工作整合学习 |

### 企业回收路径

| 途径 | 覆盖率 |
|------|--------|
| 强制拨款 | 20% SDL自动分配给企业 |
| 自主拨款(Pivotal) | 49.5%→企业可按获准培训计划申请 |
| 行政拨款 | 10.5%→SETA行政 |
| 策略拨款 | 20%→国家NSF |

### 外国企业替代方案

| 方案 | 详情 |
|------|------|
| **YES Program** | 青年雇用计划—不用送SETA培训 |
| YES税收优惠 | 每YES青年→ETI激励(≤R1000/月×12月) |
| B-BBEE技能分 | YES+学徒制双轨获取技能分 |
| 外部培训 | 向SETA注册培训机构外包 |

### YES Program（技能开发+BEE双重分）

| 维度 | 内容 |
|------|------|
| 目标 | 12个月工作经验的18-35岁青年 |
| B-BBEE分 | 技能开发项+企业供应商发展项（双重分） |
| YES名额 | QSE≥1-2人/Generic≥5-15人 |
| ETI扣除 | 每YES青年R1000/月(ETI) |
| 截止 | 2027年3月（可续） |

## 五、中资企业深度

### ICBC-Standard Bank 20%持股

| 维度 | 内容 |
|------|------|
| 持股 | 工商银行2007年以$55亿收购Standard Bank 20% |
| 意义 | 中国在非洲最大的单一金融投资 |
| 融资便利 | ICBC+SB联合银团贷款/贸易融资/人民币清算 |
| 人民币 | SA是非洲最大人民币清算中心 |

### 经典踩坑案例

- **CAPM双轮模式** → 关键教训：不能派中国团队成建制(详见P4)
- **海信家电产业园** → 工会谈判经验/罢工应对
- **中钢Samancor** → BEE转型压力的应对
- 通用教训：本地化管理团队/BEE合作伙伴/工会关系三大支柱缺一不可

### 中国BIT实践

- **1997年BIT**已经止（2014年SA废止了大部分BIT）
- 2015年《投资保护法》取代BIT→无ISDS/国家规制权
- **无已知国际投资仲裁案件中国胜诉南非**
- 当前保护：DTA的税收条款+合同仲裁条款
