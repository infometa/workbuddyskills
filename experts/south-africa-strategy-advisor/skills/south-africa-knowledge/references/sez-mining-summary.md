# SEZ与矿业专题报告

> 来源：GIBS SEZ Report (Oct 2025) + Mining Charter 2018
> 价值：独立学术评估 + 矿业合规实操

## 一、经济特区（SEZ）——GIBS独立评估 Oct 2025

### 核心结论

> "SEZ项目**对GDP没有产生可测量的影响**。好处高度集中于少数几个特区和少数几个投资者。政府投入超过R250亿，仅创造27,000个就业岗位，**每个岗位成本约R92.6万**。"

### 总体数据

| 指标 | 数据 |
|------|------|
| 特区总数 | 11个（6个获15%CIT批准） |
| 投资者总数 | 约216家 |
| 私人投资总额 | ~R300亿 |
| 政府投入 | >R250亿 |
| 直接就业 | 约27,000人 |
| 每岗位政府成本 | ~R925,926 |

### 投资集中度

| SEZ | 运营投资(R) | 占比 |
|-----|-----------|------|
| **Coega** (东开普) | 115亿 | **37.2%** |
| East London IDZ | 58亿 | 18.8% |
| Tshwane Automotive (Tasez) | 56亿 | 17.9% |
| Dube TradePort (KZN) | 30亿 | 9.7% |
| Richards Bay IDZ | 19亿 | 6.2% |
| 前4名合计 | — | **74%** |

### 各特区就业

| SEZ | 就业 |
|------|------|
| Coega | 10,154（~40%总就业） |
| East London | 5,270（峰值2021/22） |
| Dube TradePort | 增长势头最强 |
| Richards Bay | 147运营+1,137建设中 |

### 关键发现

1. **"特殊"性不足**：SEZ与非SEZ区域内企业没有显著绩效差异——仅是投资转移而非新增
2. **关税退税几乎未被使用**：491.00号退税条款利用率极低
3. **少数投资者集中获益**：东伦敦和伊丽莎白港港口是主要进口口岸
4. **数据缺失严重**：缺乏统一、可比、公开的SEZ绩效数据
5. **激励未与绩效挂钩**：缺少日落条款，没有"不达标则退出"机制

### SEZ激励包

| 激励 | 内容 |
|------|------|
| **CIT减免** | 15%（普通28%/27%） |
| **关税退税** | CCA内进口生产物资免关税 |
| **VAT优惠** | 进口免VAT + 区内供应VAT暂免 |
| **基建拨款** | SEZ基金提供道路/水电/区内外包 |
| **就业税收补贴(ETI)** | 雇用年轻工人可享受 |

### 四项战略建议

1. **建立国家SEZ数据看板** — 标准化季度/年度绩效报告
2. **激励与绩效挂钩** — 日落条款：不达标即终止优惠
3. **聚焦基础设施和治理** — 不只靠税收优惠
4. **对接全球价值链** — 学习摩洛哥Tanger Med模式

### 国际对标：摩洛哥Tanger Med

| 指标 | 数据 |
|------|------|
| 企业入驻 | 1,300+ |
| 直接就业 | 115,000人 |
| 公私资本支出 | USD 38亿 |
| 税收优惠 | 5年CIT全免 + 后续20年8.75% |

## 二、矿业章程（Mining Charter 2018）

> 来源：Government Gazette No. 41714, 15 June 2018 (Draft)
> 定位：矿业BEE赋权的法律框架，基于MPRDA第100条

### 七项核心要素

| 要素 | 基准要求 |
|------|---------|
| **1. 所有权** | 新矿权≥30% BEE持股 → 8%员工(5%无偿+3%)+8%社区+14%企业家 |
| **2. 采购** | 70%矿用物资从SA制造商采购（60%+本地含量）；80%服务从SA公司采购 |
| **3. HRD** | 年薪总额3.5%用于HRD + 1.5%投向SA公立学术机构/科学委员会 |
| **4. 就业公平** | 董事会50%黑人(20%黑人女性)；高管/高级管理层各50%；核心关键技能60% |
| **5. 社区发展** | 通过社会劳动计划(SLP)实施，强制社区参与 |
| **6. 住房与居住条件** | 住房与居住条件计划，与劳工部+人居部协商 |
| **7. 可持续发展** | 环境修复+可持续增长 |

### 评分权重

| 要素 | 权重 |
|------|------|
| 所有权 | **环锁(YES/NO)** |
| 采购与供应商发展 | **60%** |
| 就业公平 | 20% |
| 人力资源发展 | 20% |

**所有权不达标 = 整体不合格**，无论其他要素得分多高。

### 采购细则（最重权重60%）

| 类别 | 要求 |
|------|------|
| 矿用物资 | ≥70%从SA制造商采购（本地含量≥60%） |
| 其中BEE企业家 | 占SA制造的21% |
| 其中BEE女性/青年 | 各5% |
| 服务 | ≥80%从SA公司采购 |
| 其中BEE企业家 | 60% |
| 其中BEE女性/青年 | 10%+5% |
| 研发 | ≥70%研发预算在SA境内 |
| 样品分析 | **100%在SA实验室** |
| 外资供应商贡献 | 年收入0.5% |

### 合规后果

- 不达标：影响采矿权续期/新权申请
- BEE评分卡level 6-8（<50%）：不达标
- 年度审计和报告义务
- 含过渡期安排：采购5年/所有权按矿权期限

### 所有权细则

- 现有矿权：维持26% BEE持股视为合规（含"持续后果"认定）
- 新矿权：**≥30%** BEE持股
- BEE企业家处置：需持股≥矿权期限1/3且至少3年
- **股权等价机制**：可替代最多11个百分点（通过选矿投资）

## 对战略顾问的关键启示

1. **SEZ不是万能药**：GIBS结论是SEZ没有拉动GDP增长 → 选址不应只看SEZ标签，需个案评估
2. **Coega是唯一验证成功的SEZ**：R115亿投资/10,154就业/持续出口增长
3. **Tasez（汽车SEZ）是最快投产的**：得益于已有产业集群
4. **SEZ 15% CIT是真实利好**：但需确认目标SEZ是否已获财政部批准
5. **矿业投资绕不开30% BEE所有权**：8%员工+8%社区+14%企业家，结构必须合规
6. **采购权重60%是矿业运营的核心成本**：70%矿用物资必须本地采购
7. **外资矿用供应商需贡献年收入0.5%** 作为南非本地发展投入
8. **样品必须100%在南非实验室分析**：不可外包海外
9. **建议学习Tanger Med模式**：先建基础设施再引产业，而非反之
