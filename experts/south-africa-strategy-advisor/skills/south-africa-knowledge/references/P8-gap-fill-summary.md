## 一、消费市场分层

### LSM vs SEM

| 指标 | LSM(旧) | SEM(新,2017起) |
|------|--------|--------------|
| 基础 | 家庭资产(冰箱/汽车/TV) | 教育/服务获取/住房类型 |
| 缺陷 | 人为钟形曲线/掩盖极端不平等 | — |
| 核心发现 | — | **44%家庭属于低收入SEM** |

### 零售渠道结构

| 渠道 | H1 2025增速(值) | 特征 |
|------|---------------|------|
| 正规超市 | +5% | Shoprite/PnP/Spar/Woolworths/Massmart |
| **Spaza/传统贸易** | **+15%** | Spaza+superettes+taverns |
| 电商 | +5% | Takealot主导 |
| FMCG总额 | **R3,244亿** (+7.4%) | — |
| 技术耐用 | R605亿 (-1%) | 手机升级周期终结 |

### 消费行为特征

| 维度 | 数据 |
|------|------|
| 通胀 | 3.0%(2025),峰值7.8%(2022)→降级消费持续 |
| 失业 | 32%总体/60%青年 |
| 非正式收入者 | ~800万人(StatsSA) |
| 价格敏感 | 促销驱动/私有品牌增速7.5% |
| 小额纵容 | 酒/饮料/零食/烟草两位数增长 |
| 信用 | 信用获取是理解消费者的最有力维度 |

### 区域消费差异
- Gauteng：最大消费市场(34% GDP)
- WC：高收入/进口倾向
- KZN：大市场/物流中心/传统零售强
- Township/农村：传统贸易主导

### 战略启示
- Spaza渠道(+15%)是进入township的关键
- SEM 44%低收入→可负担产品市场巨大
- 促销+忠诚度是核心竞争手段

## 二、JSE上市要求

### Main Board vs AltX

| 要求 | Main Board | AltX |
|------|-----------|------|
| 利润路径 | **税前利润R1500万** | 无要求 |
| 资产路径 | **净资产R5亿** | 弹性要求 |
| 审计年限 | 3年 | **1年** |
| 自由流通 | 10%(≥100股东) | 同 |
| 指定顾问(DA) | 保荐人(Sponsor) | **指定顾问** |
| 加权表决 | 允许(有限制) | **不允许** |
| SPAC | ✅允许 | ✅允许 |
| 上市周期 | 3-6个月 | **8-12周** |
| 首次上市费 | 滑动制(R2,264起至R470万+) | 更低 |
| 年费 | 同滑动制 | 更低 |

### 费用估算

| 类别 | 成本 |
|------|------|
| 上市首费(中型IPO) | ~R50万-R200万 |
| 保荐人/DA费 | R100万-R300万 |
| 律师+审计 | R200万-R500万 |
| **IPO全部落地** | **R500万-R1000万** |
| 持续年费+合规 | R200万-R500万/年 |

### SPAC可行性

| 要点 | 详情 |
|------|------|
| 状态 | JSE允许SPAC上市 |
| 净资产要求 | 科学计算(NAV代替认购资本) |
| 现实 | 2026简化改革后首例待测，但SA投资者胃口不确定 |
| 挑战 | SA机构资本深度不足→SPAC估值难与国际竞争 |

### 最新改革（2026年1月13日生效）

| 改革 | 影响 |
|------|------|
| 现金发行决议 | 75%→普通决议 |
| 回购 | 同样降低门槛 |
| 关联方交易 | **免公平意见**(董事会独立评估即可) |
| 市场分层 | 一般段(General Segment)降低披露要求 |
| 二次上市 | 本地→Main/AltX均可行 |

## 三、争议解决实务

### 仲裁机构选择

| 机构 | 费用 | 周期 | 适用 |
|------|------|------|------|
| **AFSA** | R50K-R500K(按争议额) | 6-12月 | SA本地/快速/成本友好 |
| **ICC** | $50K-$500K+ | 12-24月 | 国际/复杂 |
| **SIAC** | $30K-$200K | 8-18月 | 亚洲相关交易 |
| 临时仲裁 | 可变 | 可变 | 双方约定 |

### 判决执行现实

| 维度 | 现实 |
|------|------|
| SA法院判决 | 执行率中等——被告资产追踪是核心挑战 |
| 外国仲裁裁决 | SA是纽约公约成员→外国裁决可申请SA法院承认 |
| 承认成功率 | 高（除非违反公共政策） |
| 执行周期 | 3-12个月(承认后+执行) |
| 核心风险 | 被告转移资产/公司已注消 |

### 合同条款建议

| 要素 | 推荐 |
|------|------|
| 适用法 | SA法（本地对手）或英国法（国际） |
| 仲裁地 | 约翰内斯堡(AFSA)或伦敦(ICC) |
| 语言 | 英语 |
| 仲裁员人数 | 1或3人（根据争议额） |
| 前置 | 调解+仲裁分层条款 |
