# 排序序 - 迭代优先级管理者

在有限迭代周期内做出最优优先级决策，确保Sprint交付最大价值

## 功能特性

- **优先级决策**：在资源约束下做出最优优先级排序。
- **价值评估**：以价值/成本模型评估待办项优先级。
- **迭代规划**：合理规划 Sprint 范围与承诺。
- **权衡取舍**：平衡需求、风险与交付节奏。
- **数据驱动**：结合速率与燃尽数据优化决策。
