# 交易结构图工作流

本工作流用于把用户已经说明的交易主体、持股关系、交易步骤和协议安排，忠实转换为可编辑的 SVG 交易结构图。它负责画清楚、对数字、标假设，不替用户决定应采用哪一种交易结构。

## 一、先判断能否直接作图

### 可以直接作图

用户已提供以下核心信息时，按既定结构作图：

- 交易前后涉及的股东、公司、SPV、基金或资产
- 每条股权关系的持股比例，或明确说明比例待确认
- 交易步骤及先后顺序
- 现金、股份、资产出资或协议安排的方向
- 希望展示交易前、某一步完成后或交易终局

缺少非关键展示信息时，可以使用 `[待确认]`，并在图下注明假设。不得补造主体、比例、注册地、控制权或监管结论。

### 必须先澄清

出现以下情况时，先列出最少必要问题，不直接画成“已确定方案”：

- 同一层持股比例明显超过 100%
- 正文、股权表和用户描述使用不同股本分母
- 交易步骤前后无法解释新增股份、转让股份或注销股份
- 付款方向、资产流向和股权取得方互相矛盾
- 用户要求精确比例，但只提供了模糊范围

### 结构选项与专业判断

用户要求设计或优化交易结构时，先整理结构备选方案，逐项写明目标、约束、适用条件、利弊和待核查事项。可以把每个选项画成“讨论稿”，但不替用户推荐或确定最终结构。

涉及控制权、要约义务、监管路径、税务、牌照或反收购规则时，只标出可能影响和待核查问题，不自动下专业结论。最终结构由用户决定，是否申请 MAI 人工复核也由用户决定。

## 二、默认交付物

除非用户另有要求，生成两份文件：

1. `outputs/deal-structure-diagram.svg`：可编辑的主图，所有样式写在 SVG 元素的 inline 属性中。
2. `outputs/deal-structure-diagram-notes.md`：图例、数据口径、待确认项、每一步股本变化和自检结果。

WorkBuddy 无法可靠渲染或转换格式时，仍须保留 SVG 源文件，不要声称已经生成 PNG、PDF 或 PPTX。用户只要求聊天预览时，也应优先创建 SVG 文件，再在回复中给出简短说明。

## 三、MAI 标准画法

### 节点

- 股东、自然人或股东组：椭圆。
- 公司、SPV、基金、上市平台或资产载体：矩形。
- 全部节点使用白色填充，描边 `#2E5090`，文字 `#1a4d8f`。
- 公司名称长时分成两行，不能缩到无法阅读，也不能溢出节点。
- 同一张图中的同类节点保持相同高度、圆角和字号。

### 连线

- 股权关系：蓝色实线，箭头从持有人指向被持有实体。
- 同 X 坐标的上下级节点使用直线，也就是 0 折。
- 不同 X 坐标使用 H 型正交折线：垂直下降、水平母线、垂直进入目标节点。
- 禁止为了装饰增加无意义折点，禁止斜箭头穿过节点。
- 协议控制、质押、对赌、期权、待完成或其他非股权关系使用虚线，并设置 `stroke-dasharray="5,4"`。
- 一张图中的 marker id 必须唯一，避免多个 SVG 同页时箭头样式冲突。

### 标签

- 持股比例放在对应连线旁，不悬空，不让读者猜属于哪条线。
- 比例文字下先放白色矩形遮住连线，再放文字。
- 现金对价、股份对价、资产出资和协议安排必须写明方向。
- 同一图内使用同一股本分母和同一估值时点。
- 未确认数字统一标为 `[待确认]`，不得用看似精确的估算值填空。

## 四、数据勾稽

作图前先建立内部关系表，至少包含：

| 字段 | 要求 |
|------|------|
| 起点主体 | 持有人、付款方或出资方 |
| 终点主体 | 被持有实体、收款方或资产接收方 |
| 关系类型 | 股权、现金、资产、协议、质押、期权或待完成 |
| 数量 | 股数、金额或资产数量 |
| 比例 | 按明确股本分母计算 |
| 生效步骤 | 交易前、Step 1、Step 2 或终局 |
| 来源状态 | 用户明确、文件直接证据、推断或待确认 |

每一步完成后重新计算总股本、各方持股数和持股比例。交付前检查“图、注、文、步骤、终局”五层一致性：

1. 图中比例与箭头关系一致。
2. 图注中的口径与图中数字一致。
3. 正文描述与图中主体、方向和数字一致。
4. 分步交易的增减变化能从上一步推到下一步。
5. 终局各方比例与最后一步的计算结果一致。

若只展示主要股东而非完整股东名册，应在图注写明“仅列示主要股东，未展示部分合并为其他股东”，不得假装图中比例已经覆盖 100%。

## 六、交付前自检

先运行结构校验：

```bash
svg_validate.py outputs/deal-structure-diagram.svg
```

只有退出码为 `0` 时，才能说明 SVG 已通过结构校验。结构校验通过后，仍要在 WorkBuddy 产物预览中打开主图，检查节点、文字、连线和标签是否存在重叠、截断或画布溢出。机器结构校验不能替代视觉预览。

- [ ] 主体没有遗漏，名称与用户材料一致
- [ ] 股东与公司节点形状使用正确
- [ ] 股权实线、特殊关系虚线，方向正确
- [ ] 直连使用 0 折，跨列使用 H 型正交连线
- [ ] 无连线穿过节点，无标签压线或重叠
- [ ] 所有 SVG 样式均为 inline
- [ ] `svg_validate.py` 退出码为 `0`
- [ ] 已打开产物预览，确认没有文字或连线重叠
- [ ] 每一步股本分母、股数和比例重新计算
- [ ] 图、注、文、步骤、终局五层数字一致
- [ ] 待确认项明确可见，没有补造事实
- [ ] 仅按既定结构作图；需要专业判断的部分已触发 `[ESCALATE]`
