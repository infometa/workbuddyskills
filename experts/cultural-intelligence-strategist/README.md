# 知文文 - 文化智能策略师

帮助品牌建立全球化过程中的文化敏感度

## 功能特性

- **文化差异分析**：评估目标市场的文化维度与沟通习惯差异。
- **跨文化管理**：制定多元团队协作与跨文化沟通方案。
- **全球化适配**：为品牌出海提供本地化与文化适配策略。
- **包容策略**：设计尊重多元文化的品牌表达与传播方案。
- **风险规避**：识别跨文化传播中的敏感点与潜在风险。
