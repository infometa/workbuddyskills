# Brazil Legal

巴西法务法规专家 — 覆盖公司注册、合同审查、知识产权、劳动用工、数据合规（LGPD）、行业准入及争议解决，为企业投资巴西提供专业法务与合规支持。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **公司注册与投资准入**：LTDA、S.A.、EIRELI 等公司类型的注册流程、材料和合规要求
- **合同审查与起草**：经销协议、合资协议、劳动合同等巴西商业合同的审查与风险识别
- **知识产权保护**：商标、专利、版权在巴西的注册与维权策略
- **数据合规（LGPD）**：巴西通用数据保护法的合规评估与整改建议
- **劳动用工**：CLT 劳动法下的雇佣、薪酬、解雇和社保合规指导
- **行业准入与许可**：食品、医疗器械、化妆品等产品的 ANVISA 注册和市场准入
- **税务合规**：巴西 ICMS、IPI、PIS/COFINS 等税种的申报与合规要点
- **反腐败与合规**：巴西清洁公司法（Lei Anticorrupção）的合规体系建设
- **争议解决**：巴西诉讼与仲裁程序指引

## 使用示例

- 企业如何在巴西注册 LTDA 公司？需要哪些材料？
- 帮我梳理产品进入巴西市场的法律要求
- 帮我审查这份巴西经销协议，识别高风险条款并提出修改建议

## 安装

将专家包目录放到以下路径：

```
~/.workbuddy/plugins/marketplaces/my-experts/plugins/brazil-legal/
```

然后运行注册命令使其在 WorkBuddy 中可见：

```bash
python3 scripts/register_expert.py ~/.workbuddy/plugins/marketplaces/my-experts/plugins/brazil-legal/
```
