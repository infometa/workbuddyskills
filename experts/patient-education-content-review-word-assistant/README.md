# 腾讯健康药箱-私域患教内容审核助手（Word 输出版 · v1.0）

在"腾讯健康药箱-私域患教内容审核专家"基础上派生的**同源助手**，审核逻辑（六维度 + 数据/文献一致性核验 + 分级校准口径）与审核专家完全一致，**唯一区别在交付形态**：

> 审核结果不再输出 Markdown 报告，而是把审核意见以 **Word 原生批注（右侧批注气泡）+ 问题句高亮** 的形式，直接标注回原文所在的 `.docx` 上，用户在 Word / WPS 打开即可像收到人工审稿一样看到每处问题的定位、分级、修改建议，并可直接在文档上采纳修改。文末追加一页结构化审核结论表与明细清单。

## 类型

Agent 型（单个 AI 专家）

## 交付形态对比

| | 审核专家（原） | 审核助手（本包） |
|---|---|---|

## 六大审核维度

审核逻辑与审核专家完全一致，按以下顺序依次独立审核，每个维度单独输出结论与修改建议：

### 一、严重问题审核

政治/法律红线、低俗内容、医疗高风险、商业推广、版权侵权。合规"一票否决"层，触碰即判🔴。

### 二、科学性审核

数据与参考文献一致性（最高优先级）、医学概念/观点/数据准确性、内容客观性。重点核查数据能否溯源、有无概念偷换、有无绝对化夸大表述。

### 三、出版规范审核

结构规范、文字表达、符号及格式、参考文献著录。检查错别字病句、草稿残留、编号断裂、引用标注与著录格式。

### 四、语言风格审核

语言是否适合目标受众，允许适度口语化、禁止低俗网络用语。患教友好的口语与比喻可保留，医护视角"给药"等需改。

### 五、医学逻辑审核

因果关系、数据与结论一致性、推荐方案与指南一致性、关键内容完整性。防止相关当因果、结论超出数据支撑、缺失关键安全信息。

### 六、参考文献审核

来源级别、时效性、格式规范、可访问性、相关性、引用标注。知网/万方可查（含报刊、科普期刊）属可接受来源，公众号等禁用来源判🔴。

三级结论：🔴 需修改（P0）/ 🟡 建议优化（P1）/ 🟢 备注（P2）

## 工作机制

1. 接收待审 docx / zip → 解压取正文与参考文献
2. 完成六维度审核 → 整理为 `issues.json`（每条含 anchor 定位锚点、分级、维度、问题、建议）
3. 调用随包脚本 `skills/review-to-word/scripts/review_to_word.py` → 生成带批注高亮的 `.docx`
4. 呈现 Word 文件

### 随包脚本（review-to-word 技能）

脚本随包以 Skill 形式分发，位于 `skills/review-to-word/scripts/review_to_word.py`：把 issues.json 应用到原文，高亮问题片段并挂 Word 原生批注，文末生成结论表+明细。

```bash
python skills/review-to-word/scripts/review_to_word.py --src 待审文章.docx --issues issues.json --out 已审核_带批注.docx
```

## 环境准备

本助手的 Word 批注生成依赖一个 Python 脚本，运行前需准备：

- **Python**：3.7 及以上（推荐随 WorkBuddy 内置的 Python 3.13）
- **依赖库**：`python-docx>=1.1`（必须，`Document.add_comment` 在 1.1+ 才可用）

安装与验证：

```bash
# 安装依赖
pip install "python-docx>=1.1"

# 验证版本（应输出 1.1.0 或更高）
python -c "import docx; print(docx.__version__)"
```

若运行脚本时报 `AttributeError: 'Document' object has no attribute 'add_comment'`，即为 python-docx 版本过低，升级即可解决。
