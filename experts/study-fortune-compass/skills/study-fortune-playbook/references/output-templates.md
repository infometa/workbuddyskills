# 输出模板

## 一、今日学运日签

### 默认紧凑版

```markdown
## 今日卦｜{本卦全名} → {变卦全名}

**起卦摘要**
- 报数：{reported_number}
- 时间：{datetime}（UTC{utc_offset}，{earthly_branch_hour}时）
- 上卦：{upper_trigram_formula}
- 下卦：{lower_trigram_formula}
- 动爻：{moving_line_formula}
- 卦序：{本卦符号}{本卦全名} → {互卦符号}{互卦全名} → {变卦符号}{变卦全名}

### 学业情境解读
{用 2—3 句解释当前结构、内部过程和变化方向；没有现实信息时不推断用户状态}

### 今日留意
- {一个可由用户自行观察、可以不成立的分支}

> 以上为传统起卦计算与学业情境解读，不预测具体分数或考试结果。需要时可以继续展开卦辞、爻辞和体用依据。
```

```markdown
### 完整卦象
{本卦六爻图}

- 本卦：{本卦符号} {本卦全名}
- 卦辞：{本卦卦辞}
- 动爻：{爻名}：{爻辞}
- 互卦：{互卦符号} {互卦全名}
- 变卦：{变卦符号} {变卦全名}
- 体用：{体卦五行} / {用卦五行} / {关系}
- 原文来源：{source}
```

```markdown
{当前结构，只引用本卦和用户已提供的现实信息}

{内部过程和最可能变化的环节，给出两个可辨别分支}

{一周内值得观察的方向，不写成结果预测}

### 现实校准
- 卦象提出的假设：{可被否证的假设}
- 用户已经确认：{科目、进度、时间或卡点}
- 低成本验证动作：{只依据现实事实设计的动作}

### 七日观察线
- 前段：{可观察的起势信号}
- 中段：{可观察的转折信号}
- 后段：{可观察的收束信号}

```

## 三、学期学运深读

```markdown
# 学运深读｜{标题}

## 解读条件
- 时间尺度：{本月/本学期}
- 用户已确认：{目标、阻力、现实条件}
- 解读依据：{象征种子/真实盘面/用户事实}
- 口径：{象意演绎/已有盘面解释}

## 第一镜头｜{主体系与主题}

### 象征铺垫
{2—3 句直接陈述用户情况在主体系框架中的对应关系。不使用"我在看/翻/读取"的拟人表述。}

- 主象：{主题}
- 优势：{具体条件}
- 阻力：{具体条件}
- 可校准分支：A {分支一} / B {分支二}

## 第二镜头｜{辅助体系与暗线}
- 暗线：{不同层次的新信息}
- 转机：{可控变量}
- 限制：{不可由象征判断的事项}

## 呼应与冲突
{说明两个镜头在哪个层次相互呼应或存在张力；不称为准确性验证}

## 七日观察线
1. {前段可能出现的可观察信号}
2. {中段可能出现的可观察信号}
3. {后段用于检验本轮解读是否贴合的问题}

## 现实待确认
- {与象征解读分开列出的成绩、课程规则、申请门槛、考试日期等}

## 下一入口
{继续深读 / 换体系 / 转现实计划}

> 这是传统象征框架下的娱乐性反思，不预测成绩、录取或必然事件。
```

## 七、质量检查

交付前逐项检查：

- 第一屏是否已有实际内容，而不只是连续提问
- 是否明确当前是象意演绎还是已有盘面解释
- 日签或周签是否显示正整数、起卦时间、UTC 偏移和脚本卦象
- 是否至少引用一项用户现实信息或主动选择
- 是否给出可被用户否证的分支
- 是否包含一个限制条件或不利面
- 行动是否来自用户现实事实，而不是直接由象征结论推出
- 是否给出动作、时长或完成标志
- 是否列出现实待确认项
- 是否避免分数、概率、录取和保证性结论
- 是否避免伪造宫位、星曜、干支、门星和相位
- 是否给用户继续、换模式和退出入口
