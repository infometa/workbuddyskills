# 梅花易数一数成卦

## 适用场景

用户明确报出一个正整数并要求日签、考试运势或当下趋势时使用。

本方法只负责起卦、查卦与展示传统结构。模型不得自行改写卦名、动爻、卦辞、爻辞、互卦、变卦或体用关系。

## 起卦规则

采用梅花易数常见的“一数成卦”规则：

1. 用户报数为上卦。
2. 起卦时辰的地支序数为下卦。
3. 报数与时辰序数之和除以六，余数为动爻。
4. 卦数大于八时除以八取余；余零按八计。
5. 动爻余零按六计。

先天八卦数：

| 数 | 卦 | 象 | 五行 |
|---|---|---|---|
| 1 | 乾 | 天 | 金 |
| 2 | 兑 | 泽 | 金 |
| 3 | 离 | 火 | 火 |
| 4 | 震 | 雷 | 木 |
| 5 | 巽 | 风 | 木 |
| 6 | 坎 | 水 | 水 |
| 7 | 艮 | 山 | 土 |
| 8 | 坤 | 地 | 土 |

时辰序数：子1、丑2、寅3、卯4、辰5、巳6、午7、未8、申9、酉10、戌11、亥12。

## 派生结构

- 本卦：下卦三爻在下，上卦三爻在上。
- 动爻：自下而上为初爻、二爻、三爻、四爻、五爻、上爻。
- 变卦：本卦动爻阴阳翻转。
- 互卦：本卦二三四爻组成下卦，三四五爻组成上卦。
- 体用：动者为用，静者为体；再按五行生克列出体用关系。

## 确定性

- 同一报数、同一时辰得到相同本卦、动爻、互卦和变卦。
- 跨时辰结果会变化，这是该起卦方法使用时辰数的直接结果。
- 不得加入随机数，不得让模型重新抽签，不得为了“更贴合”而换卦。
- 用户在同一时辰重复询问同一问题时，直接复用原卦，不重新起卦。

## 执行命令

```bash
python scripts/meihua_divination.py --number 7 --format json
```

需要复现实测结果时传入 ISO 8601 时间：

```bash
python scripts/meihua_divination.py --number 7 --datetime "2026-07-18T18:56:00+08:00" --format text
```

默认起卦地使用 UTC+08:00。用户明确在其他时区时，传入 `--utc-offset`。脚本会在 `input.utc_offset` 中返回实际采用的 UTC 偏移，展示结果时不得省略。

## 展示顺序

脚本返回结果后，按用户需要渐进展示依据。

默认紧凑版：

1. 报数、起卦时间、UTC 偏移与时辰。
2. 上卦、下卦和动爻公式。
3. 本卦、互卦、变卦的卦名与动爻位置。
4. 学业主题解读和一个可否证的观察点。

用户追问“怎么算的”、要求完整解读或需要复核时，再展开：

5. 本卦卦形、卦辞与动爻爻辞。
6. 互卦、变卦与体用关系。
7. 古籍原文来源。

紧凑展示不是隐藏依据；所有结论仍须可由脚本输出复现。

解读必须引用脚本返回的具体字段。不得用模型印象补出不存在的星曜、宫位、相位、门星或干支。

## 签库

`hexagram-library.json` 包含通行本六十四卦：

- 六十四卦卦序、卦名、卦符与六爻阴阳。
- 上下卦组合。
- 卦辞。
- 六爻爻辞；乾坤另含用九、用六。

签库用于确定性查表，不包含模型生成签文。
