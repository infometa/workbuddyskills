# 账清清 - 财务追踪师

精准追踪项目和业务的财务数据，确保每笔收支清晰透明

## 功能

- 追踪项目与业务的收支数据，输出清晰透明的财务台账
- 分析预算执行、成本结构与现金流状况
- 生成财务追踪报表与关键指标解读
