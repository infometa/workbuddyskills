# Brazil Business Development Expert — 巴西商务拓展专家

巴西商务拓展专家是一个聚焦巴西市场商务拓展、企业尽调与风险筛查的 WorkBuddy 专家智能体，主要面向计划进入或拓展巴西市场的中国企业、投资机构与跨境贸易公司。

## 类型

Agent 型（单个 AI 专家）

## 功能

- 巴西企业工商与信用风险排查（CNPJ 查询）
- 巴西企业背景尽调与合作伙伴筛选
- 专利/商标/工业设计/软件等知识产权尽调
- 技术转让合同与产权传承链分析
- 巴西市场拓展路径与行业/城市分析
- 商务法律案例参考与风险提醒

## 使用示例

- 请帮我查询XX公司的经营现状，历史诉讼记录，评估合作风险
- 这个专利最初是谁申请的？现在归谁？
- XX 公司名下有哪些技术转让合同？分别转给谁？
- 巴西建材行业有哪些潜在代理商或合作伙伴？
- 在圣保罗和里约热内卢注册公司，哪个更适合外资企业？

## 数据说明

本专家完全**零配置、零手动下载**——AI 会自动处理数据。

### 首次使用流程

```
装好专家 → 问第一个问题
  ↓
AI: "正在查询...（首次使用，后台从巴西政府官网自动下载所需数据）"
  ↓ 5~10 秒
返回初步查询结果
  ↓ 30~60 秒
数据缓存完成 → 后续查询毫秒级响应
```

### 数据来源

| 数据 | 大小 | 来源 | AI 处理方式 |
|:----|:---:|:----|:-----------|
| **RFB CNPJ 企业登记** | ~7.5GB（压缩） | 巴西联邦税务局 SERPRO+ WebDAV | **按需下载分片**（首次约500MB）+ 缓存 |
| **INPI 商标/专利/合同/程序** | ~15GB（文本） | INPI 开放数据门户 (dadosabertos.inpi.gov.br) | **按需下载**（商标835MB/专利138MB/合同302MB）|
| **BCB 汇率/Selic/IPCA** | 零 | 巴西央行 API | 实时 API 查询 |
| **World Bank 经济指标** | 零 | 世界银行 API | 实时 API 查询 |
| **语料库参考文本** | ~3MB | 专家包自带 | 已包含在包内 |

### 缓存位置

数据自动缓存到 `~/.workbuddy/brazil-data/`（底层使用 `os.path.expanduser()`，兼容 Windows/macOS/Linux 跨平台路径展开）。缓存后可离线使用。

- **Windows**: `C:\Users\<用户名>\.workbuddy\brazil-data\`
- **macOS/Linux**: `~/.workbuddy/brazil-data/`

### 卸载

删除 `~/.workbuddy/brazil-data/` 目录即可释放磁盘空间。
