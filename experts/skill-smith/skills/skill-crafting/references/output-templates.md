# 标准输出模板

制作、测试、评分、修复和交付时使用本文件。按对应模板输出，不省略状态、证据和未覆盖范围。

## 需求确认卡

### 模板

```markdown
## 需求确认
- 当前状态：待确认
- Skill 要做什么：填写单一核心任务
- 谁会使用：填写目标用户
- 用户会怎样说：列出 3—5 句真实原话
- 输入：填写用户提供内容和可访问数据
- 输出：填写交付格式和验收标准
- 绝不做什么：填写边界和禁止操作
- 预计文件：列出 SKILL.md、scripts、references、assets
- 交付目录：填写拟写入目录
- 未决问题：只保留影响下一步的事项

请确认以上需求。此次确认只代表需求确认，不代表同意写入文件或安装。
```

### 完整示例

```markdown
## 需求确认
- 当前状态：待确认
- Skill 要做什么：扫描用户指定的下载目录，先生成分类预览，确认后按扩展名和用户规则移动文件。
- 谁会使用：希望定期整理下载文件的个人用户。
- 用户会怎样说：“整理一下下载文件”“把下载目录分类”“先看看哪些文件该放哪”“下载文件太乱了”。
- 输入：用户明确指定的单个目录、分类规则和冲突处理偏好。
- 输出：分类规则、移动预览、冲突清单、执行摘要和回滚清单。
- 绝不做什么：不删除文件，不读取未指定目录，不静默覆盖同名文件，不在未确认时移动文件。
- 预计文件：SKILL.md、scripts/plan_downloads.py、scripts/apply_plan.py、references/rules.md。
- 交付目录：D:/Work/example/downloads-organizer。
- 未决问题：同名文件采用跳过还是追加序号。

请确认以上需求。此次确认只代表需求确认，不代表同意写入文件或安装。
```

请确认是否按以上计划写入。此次确认不代表同意安装。

## 环境检查结果

### 模板

```markdown
## 环境检查
- 总体状态：ready / partial / needs_setup / unavailable
- 本次功能：列出当前请求涉及的能力
- 已通过：只列名称和版本，不输出凭据值
- 缺失必需项：列出依赖和精确配置入口
- 缺失可选项：列出受影响功能和降级
- 故障项：区分登录、权限、额度、版本、网络和服务异常
- 下一步：直接执行 / 配置后重检 / 降级执行 / 停止
```

### 完整示例

```markdown
## 环境检查
- 总体状态：partial
- 本次功能：读取公开仓库 README 并给出结构建议
- 已通过：Python 3.13；网络可用
- 缺失必需项：无
- 缺失可选项：GitHub CLI 未登录；无法读取私有仓库、Issue 和 PR
- 故障项：无
- 降级：由用户提供公开仓库 URL，只分析公开内容
- 限制：不验证私有数据、权限状态和线上 Issue
- 下一步：直接进入公开仓库分析；用户需要私有数据时再运行 `gh auth login --web`
```
