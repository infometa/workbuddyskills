# 平台兼容规则

## 当前目标

- 目标平台：WorkBuddy
- 规则核验日期：2026-08-10
- 规范来源：当前运行环境的 WorkBuddy Skill 管理与专家开发规范
- 安装范围：用户级
- 安装根目录：`~/.workbuddy/skills/`
- Python 基线：3.10 及以上
- 脚本依赖：仅 Python 标准库

## WorkBuddy 本地 Skill

| 项目 | 当前规则 |
|---|---|
| name | 必填，kebab-case，与目录名一致 |
| description | 必填，承担触发描述，20—1024 字符 |
| version | 本专家制作与更新流程必填；新建从 1.0.0 开始 |
| agent_created | 模型创建并需要后续管理的本地 Skill 必须为布尔值 true |
| SKILL.md | 根目录必备，大小写精确 |
| 安装位置 | `~/.workbuddy/skills/<name>/` |
| 项目级安装 | 本专家不执行 |
| reference 加载 | 只由顶层 SKILL.md 发起 |

`agent_created: true` 是 WorkBuddy 本地模型创建 Skill 的平台字段，不声明为所有平台的通用必填字段。目标为其他平台时，先核验该平台当前规则；无法核验时只提供未验证适配建议，不执行安装。

## 版本规则

- 新建：1.0.0
- PATCH：不改变能力和兼容性的文案或缺陷修正
- MINOR：新增向后兼容能力、脚本或模板
- MAJOR：删除能力、改变输入输出或引入不兼容结构

更新安装前比较新旧 version。新版不高于旧版时拒绝覆盖。

## 路径规则

- 文档使用 `~/.workbuddy/skills/` 或相对路径，不写具体用户名和盘符。
- 包内脚本使用 `Path.home()` 和 `pathlib` 解析路径。
- 安装目标必须规范化为用户级根目录下的单个 Skill 目录。
- 拒绝 `..` 逃逸、软链接目标、通配符集合路径和根目录级操作。
- 临时目录和备份目录使用脚本生成的唯一名称，不复用用户输入作为完整路径。

## 编码与文件名

- 文本统一 UTF-8。
- JSON 使用 UTF-8 和标准双引号。
- Python 文件使用 `.py`，入口兼容 Windows、macOS 和 Linux。
- 不写只适用于单一 shell 的安装脚本。
- ZIP 内统一使用 `/` 分隔，保留顶层 Skill 目录。
