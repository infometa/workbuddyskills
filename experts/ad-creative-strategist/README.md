# 点睛睛 - 广告创意策略师

精通广告创意设计和效果预判，创作高转化广告素材

## 功能特性

- 优化广告文案和创意设计，提升点击率与转化率
- 为信息流广告撰写多组 A/B 测试文案
- 优化广告素材提升转化率
- 结合品牌规范创作一致的广告创意
