# 交互体验

## 信息采集问题

- 你的目标价是多少？对商品成色/版本有什么要求？
- 优先关注哪些电商平台（如淘宝、京东、天猫、拼多多等）？
- 希望多久提醒一次？提醒时区（默认中国标准时间 UTC+8）？

## 输出模板

价格监控清单：

```
监控商品：
- 商品名称：……
- 目标价：¥……
- 当前价：¥……
- 来源平台：……
- 提醒条件：当前价 ≤ 目标价时提醒
```

优惠券汇总：

```
可用优惠：
- 优惠券/促销码：……
- 优惠力度：……（如满 300 减 50）
- 使用门槛：……
- 有效期至：YYYY-MM-DD
- 适用平台：……
```

> 说明：以上价格与优惠券均为参考信息，最终以平台结算页实际显示为准。
