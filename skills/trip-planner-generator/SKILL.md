# Trip Planner Generator

本 skill 通过交互式问答，帮助用户生成结构化、详尽的旅行计划。

## 何时调用

在以下情况调用本 skill：
- 用户想制定旅行计划或行程
- 用户需要帮助规划一次出行
- 用户提供了旅行目的地并希望得到结构化的方案
- 用户提到"旅行计划"、"行程规划"、"travel plan"、"itinerary"
- 用户需要把零散的出行信息整理成结构化格式

## 交互式问答流程

**重要：使用 AskUserQuestion 工具引导用户完成规划过程。**

### Phase 1: 基础信息

使用 AskUserQuestion 依次提出以下问题：

```
Question 1: 目的地
- Header: "目的地"
- Question: "请问您的旅行目的地是哪里？"
- 说明：目的地因人而异，属于开放性问题，不预设固定选项。
  请直接引导用户在 AskUserQuestion 的输入框中自由填写目的地
  （如"广州+深圳"、"成都"、"日本东京"等）。

Question 2: 旅行主题/人群
- Header: "主题"
- Question: "本次旅行的主题或同行人群是？"
- Options: 
  - "亲子游" (带孩子出行)
  - "情侣/夫妻游" (浪漫之旅)
  - "家庭游" (全家出行)
  - "朋友游" (结伴同行)

Question 3: 出行时间
- Header: "时间"
- Question: "请问您的出行日期和天数？"
- Options:
  - "周末2天" (短途游)
  - "3-4天" (小长假)
  - "5-7天" (长假)
  - "7天以上" (深度游)
  - 用户可在选项下方自由填写具体日期

Question 4: 出行人数
- Header: "人数"
- Question: "请问出行人数和人员构成？"
- Options:
  - "2人" (情侣/夫妻)
  - "2大1小" (三口之家)
  - "2大2小" (四口之家)
  - "4人以上" (多人出行)
  - 用户可在选项下方自由填写具体构成（如"2大1小(10岁)"）

Question 5: 交通方式
- Header: "交通"
- Question: "请问您计划使用什么交通方式？"
- Options:
  - "高铁/火车" (铁路出行)
  - "飞机" (航空出行)
  - "自驾" (汽车出行)
  - "混合交通" (多种方式)
```

### Phase 2: 偏好与预算

```
Question 6: 旅行偏好
- Header: "偏好"
- Question: "您更偏好哪种旅行风格？"
- Options:
  - "轻松休闲" (每天1-2个景点)
  - "深度体验" (慢慢逛，重质量)
  - "打卡观光" (多看几个景点)
  - "冒险探索" (尝试新体验)

Question 7: 预算范围
- Header: "预算"
- Question: "您的预算范围大概是多少？"
- Options:
  - "经济型" (人均1000-2000/天)
  - "舒适型" (人均2000-3000/天)
  - "品质型" (人均3000-5000/天)
  - "奢华型" (人均5000+/天)
```

### Phase 3: 特殊需求

```
Question 8: 特殊需求
- Header: "需求"
- Question: "是否有特殊需求需要考虑？"
- Options:
  - "有老人同行" (需要照顾老人)
  - "有小孩同行" (亲子友好)
  - "有饮食限制" (素食/过敏等)
  - "无特殊需求" (常规安排)
```

## 信息收集汇总

完成问答后，汇总已收集的信息：

```markdown
📋 旅行计划信息确认

- 目的地：[目的地]
- 主题：[旅行主题]
- 日期：[开始日期] - [结束日期]
- 天数：[X天X夜]
- 人数：[人数构成]
- 交通：[交通方式]
- 偏好：[旅行风格]
- 预算：[预算范围]
- 特殊需求：[如有]

确认以上信息后，我将为您生成详细的旅行计划。
```

## 必备信息清单

| 类别 | 必填字段 |
|----------|-----------------|
| 基础 | 目的地, 主题, 日期, 天数, 人数 |
| 交通 | 出发地, 交通方式, 车次/航班 |
| 每日 | 日期, 星期, 主题, 住宿, 时间线 |
| 预算 | 交通, 住宿, 门票, 餐饮, 合计 |
| 准备 | 证件, 衣物, 防护, 药品, 电子 |
| 注意 | 重要提醒, 注意事项 |

## 制定优质计划的要点

1. **合理的时间安排**
   - 计入地点间的交通时间
   - 为延误预留缓冲
   - 考虑用餐时间
   - 安排休息时段

2. **儿童友好**（如适用）
   - 适龄的活动
   - 休息时段
   - 加餐时间
   - 互动体验

3. **实用细节**
   - 预订要求
   - 开放时间
   - 门票价格
   - 交通选择

4. **本地知识**
   - 最佳游玩时间
   - 避开人流的技巧
   - 当地美食推荐
   - 免费与付费景点

```markdown
🍜 饮食 清淡为主 街边少吃生冷
💰 预算 约7050-8800 备少量现金
```

## 后续使用

输出的 Markdown 采用清晰的分区结构（每日行程 📅、预算 💰、行前清单 🎒、注意事项 ⚠️），层次分明、字段统一，便于直接阅读，也方便后续转换为网页、导入笔记或其他行程管理工具中使用。
