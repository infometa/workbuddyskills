# 输出格式模板

> 原则：所有字段**只填充 MCP 返回数据中实际存在的内容**。历史最低价、近期均价、价格趋势等字段，**取决于搜索工具返回数据是否提供**；若未提供，写"数据未提供"或省略该行，**严禁编造数字**。

## 模板：单品价格与优惠分析

```
📊 商品价格分析
━━━━━━━━━━━━━━━━━
商品：[商品名 / 型号]
当前价：¥XXX（[平台]）
其他平台：¥XXX（[平台]）…（如返回多平台）
历史最低：¥XXX（[日期]）        ← 仅当返回数据提供时填写，否则写"数据未提供"
近期均价：¥XXX                  ← 仅当返回数据提供时填写，否则省略
价格趋势：[上涨/下降/平稳]        ← 仅当返回数据可推断时填写

💡 判断（基于现有返回数据）：
- 是否历史低价：[结论 / "暂无历史数据，无法判断"]
- 是否先涨后降嫌疑：[结论 / "数据不足以判断"]
- 是否建议入手：[基于上述的客观建议，不强推]

🎫 可用优惠：
- [隐藏优惠券 / 渠道补贴信息]（如返回提供）

🔗 渠道链接：
- [链接]（⚠️ 如为推广/导购链接，须在此明确标注"推广链接"）

⚠️ 声明：价格与优惠数据来源于慢慢买，仅供参考，可能存在延迟，实际以电商平台结算页为准。
```

## 模板：仅搜索结果（无历史数据时）

当返回数据只有实时价格/优惠而无任何历史信息时，使用简化版，避免给用户"已做历史分析"的错觉：

```
🔍 全网优惠搜索结果
━━━━━━━━━━━━━━━━━
商品：[商品名]
- [平台 A]：¥XXX（[优惠/券信息]）
- [平台 B]：¥XXX（[优惠/券信息]）

🎫 隐藏优惠：[如有]
🔗 链接：[如有，推广链接须标注]

ℹ️ 说明：本次返回数据未包含历史价格，暂无法判断是否为历史最低或是否先涨后降。
⚠️ 价格仅供参考，以平台结算页为准。
```

## 撰写要求

- 缺数据时如实标注，不要用"约""大概"去填补一个并不存在的历史价。
- 涉及"建议入手/再等等"的结论，须明确是基于有限数据的参考意见。
- 任何推广/导购/返利链接，必须显式披露（见 disclaimer.md）。
