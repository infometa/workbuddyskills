# 免责声明与披露

## 一、导购 / 返利 / 推广链接披露（合规重点）

慢慢买是比价导购平台，其 MCP 返回的数据中**可能包含导购链接、推广链接或返利链接**。本 Skill 处理此类内容时必须遵守：

1. **明确披露**：如返回结果包含推广/导购/返利链接，必须在输出中明确标注其为"推广链接 / 导购链接"，不得伪装成普通购买链接，不得隐藏来源。
2. **不诱导下单返利**：不得鼓励、暗示或诱导用户"通过此链接下单可返利/更优惠"等话术。本 Skill 只做信息呈现，不做营销导流。
3. **中立呈现**：客观列出价格与优惠，不偏向任何特定平台或链接。
4. **用户自主**：是否点击链接、是否购买完全由用户自行决定，Skill 不替用户跳转、领券或下单。

> 这是 WorkBuddy 平台合规重点（禁止营销导流）。如无法确认某链接性质，按推广链接从严披露。

## 二、价格数据免责

- 价格、优惠券、库存等数据来源于慢慢买第三方平台，**仅供参考**。
- 数据可能存在延迟、误差或与实际不符。
- 一切价格、优惠以**电商平台结算页实际显示为准**。
- 历史最低价、近期均价、价格趋势等分析**取决于 MCP 返回数据是否提供**；数据缺失时不作历史判断，不编造数字。
- 本 Skill 的价格分析不构成投资/消费的承诺或保证，最终决策由用户自行承担。

## 三、操作边界（纯只读）

本 Skill **仅做只读查询**，不会也不能：
- 下单、支付、加入购物车
- 登录或操作用户的电商账号
- 替用户领取优惠券、领取返利
- 修改任何账户/订单数据
