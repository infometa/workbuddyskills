# 求职诈骗识别素材库

## 最高原则：付费一票否决

腾讯校园招聘、实习招聘、官方内推、简历投递、笔试、面试、录用、签约等面向求职者的流程 **全程 0 收费**。

凡用户提供的信息中出现任何与「实习 / 内推 / 求职辅导 / 简历优化 / 课程包 / offer / 留用 / 转正」挂钩的金钱往来，无论金额多少、是否承诺退款、是否声称「很便宜」，均按 **求职诈骗** 处理。

官方事实：

- 唯一官方入口：`https://join.qq.com`
- 官方流程：简历投递 → 笔试 → 多轮面试 → offer
- 官方内推：只通过腾讯实名员工系统，不影响候选人正常考核流程，不向候选人收费
- 官方 HR 邮箱：以 `@tencent.com` 等官方邮箱为准；不会用私人微信/QQ 单独沟通入职流程
- offer 形式：通过 `join.qq.com` 平台或官方邮箱发放，不通过个人账号发送「offer 截图」

## 风险识别维度

| 维度 | 触发条件 | 风险等级 | 处理原则 |
|---|---|---|---|
| 付费/价格信号 | 金额、课程包、报名费、服务费、押金、定金、退费、不过退款、辅导费等 | 极高风险 / 一票否决 | 可直接说明「确认为求职诈骗」 |
| 承诺/兜底话术 | 保 offer、保过、包录用、100% 上岸、稳进、不过退款等 | 极高风险 | 正规招聘不可能承诺结果 |
| 内部资源/免流程承诺 | 内部名额、绿色通道、VIP 通道、免笔试、免 HR 面、免简历筛选等 | 极高风险 | 腾讯校招无绕过笔面试的内部通道；正常内推/伯乐码本身不是风险，只有与收费、保过或免流程承诺绑定时才升级 |
| 课程/培训形态 | 1v1、陪跑、训练营、集训营、课程包、在职导师辅导、上岸率等 | 极高风险 | 腾讯实习是真实岗位，不需要先付费上课 |
| 冒充身份 | 前腾讯、前 HR、在职导师、鹅厂 HR、员工内推、学姐学长带等 | 高风险 | 官方不会通过个人身份代办招聘流程 |
| 私域引流 | 私信、加微信、+v、扫码、二维码、进群、主页找我、评论领等 | 中高风险 | 脱离官方平台后风险显著升高 |
| 异常实习形态 | 远程实习、线上日常实习、0 元免费实习、全国可远程、100% 转正等组合 | 高风险 | 需回到官网核实，不因「免费」降低警惕 |
| 伪装避雷/吐槽 | 避雷、踩坑、被骗、维权、退款经历，同时引导私信/加微信/主页 | 极高风险 | 典型「骗子打骗子」反向引流 |
| 账号命名异常 | 账号名含实习/求职/招聘/Hub/Career/接 offer，或「XX(接offer版)」等模板 | 中高风险 | 结合正文模板化和引流行为判断 |

## 决策流程

1. **Step 0：付费检测**  
   只要出现任何付费、金额、课程包、服务费、押金、退费等信号，并与实习/内推/求职辅导相关，直接判定极高风险。

2. **Step 1：品牌锚定**  
   如果文本提到腾讯、鹅厂、BG、腾讯音乐、QQ 音乐、微信、腾讯云等，进入招聘诈骗重点判断。

3. **Step 2：极高危词筛查**  
   保 offer、内部名额、绿色通道、免笔试、1v1 陪跑、训练营等任一命中，直接极高风险。

4. **Step 3：伪装避雷识别**  
   同时出现「避雷/踩坑/被骗/退款」和「私信/加微信/主页/评论领/扫码」时，按伪装诈骗变体处理。

5. **Step 4：高危组合判定**  
   同时出现两类及以上信号（冒充身份、引流、异常实习形态、留学生/海归受众、品牌锚定），判定高风险。

6. **Step 5：账号名辅助判断**  
   账号名命中机构词、括号模板、英文名+地点+随机后缀、反诈避雷马甲时，风险等级上调。

7. **Step 6：输出建议**  
   根据风险等级输出提醒，统一引导 `https://join.qq.com` 官方渠道核实。

## 风险等级与输出话术

### 极高风险：涉及付费

```
这条信息可按求职诈骗处理。

关键风险：涉及付费实习/内推/课程/服务费。腾讯校招和实习招聘全流程 0 收费，任何「内推费、课程费、服务费、押金、退费、辅导费」都不是官方流程。

建议你不要付款、不要继续添加私人微信/QQ群；如果已经付款，请保留聊天记录、转账记录，尽快通过对应平台举报。求职请只通过官方渠道：https://join.qq.com
```

### 极高风险：伪装避雷/吐槽

```
这条信息高度疑似「骗子打骗子」的诈骗变体。

它表面是在避雷、吐槽或分享被骗经历，但如果文末/评论区继续引导你私信、加微信、进群或领取资料，本质仍是在把你导向另一个付费机构。

请记住：所有付费实习、付费内推、付费保过都不是腾讯官方流程。求职请回到官方渠道：https://join.qq.com
```

### 极高风险：承诺/绿通/课程

```
这条信息高度疑似求职诈骗。

识别到的关键风险包括：保 offer、内部名额、绿色通道、免笔试、1v1 陪跑或训练营等。腾讯校招没有「内部名额」「保过」「免笔试免面试」机制，所有候选人都需要通过官方流程评估。正常官方内推/伯乐码不收费，也不能承诺跳过流程或保证结果。

建议不要加私人联系方式、不要付费，先到 https://join.qq.com 核实岗位和流程。
```

### 高风险

```
这条信息存在较明显的求职诈骗特征。

建议你先做四件事：
1. 不添加私人微信/QQ/群聊。
2. 不支付任何费用，即便对方说很便宜、可退或不过退款。
3. 到 https://join.qq.com 核对岗位是否真实存在。
4. 收到 offer 或 HR 联系时，以官方平台和官方邮箱为准。
```

### 中风险

```
这条信息建议谨慎判断。

目前没有足够证据直接判定为诈骗，但出现了引流、账号模板化或非官方渠道等风险信号。建议先通过 https://join.qq.com 或腾讯招聘官方账号核实，不要先交钱或提交敏感个人信息。
```

### 低风险/正常

```
暂未发现明显诈骗特征，但仍建议遵守三条原则：
1. 腾讯校招/实习全流程 0 收费。
2. 投递与流程查询走 https://join.qq.com。
3. 不向陌生个人账号提供身份证、银行卡、验证码等敏感信息。
```

## 院校/学校层级中性表达

即使用户在防诈骗场景中提到「包装院校背景」「学校层级不够所以要付费内推/保过」等说法，也只提醒官方流程免费和求职准备建议；不得顺着诈骗话术对学校或学生做优劣、档次、含金量等价值评判。

## 使用建议

- 命中付费类硬规则时，可以明确说「可按求职诈骗处理」。
- 其他风险仅说「高度疑似」「建议警惕」，避免误伤正常信息。
- 如果用户贴出长文、截图转写、社交平台帖子或账号名，优先运行 `python scripts/fraud_checker.py "<文本>" --account "<账号名>"` 做第一层判断。
- 不保存用户贴出的原始聊天记录、截图文字或账号信息到求职记忆。
