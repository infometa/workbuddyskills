# 飞常准机票查询

## 能力边界

本 Skill 使用当前 Connector 暴露的 MCP Tool 完成三类查询：

- 查询指定城市对和单个日期的逐航班机票、价格和售罄状态。
- 查询日期范围内的单程低价参考或指定去返日期的往返价格参考。
- 查询某个机场或城市出发的低价目的地。
- 从机票结果中读取航班四要素，并在用户继续询问动态时核验航班状态。
- 不创建订单，不锁价，不占座，不代付，不确认出票，也不收集姓名、证件号、手机号等乘机人信息。
- MCP 返回的价格和 `soldStatus` 是本次查询结果，不等于最终成交价、实时座位库存或可出票承诺。不要补造税费、行李额、退改规则或剩余座位数。

## 鉴权

WorkBuddy 通过本机保存的 C 端用户 MCP Key 连接服务。出现未授权或 401 时，提示用户在 Connector 设置中更新或重新填写 MCP Key；不要让用户在对话中发送完整 Key。

## 可用 Tool

### `searchAirport`

根据机场名、城市名或模糊关键词查询机场和城市代码。

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | :---: | --- |
| `name` | string | 是 | 机场或城市名称关键词 |
| `region` | string | 否 | `CN` 表示中国大陆，`INT` 表示全球；不传默认全球 |

返回 `kind=collection` 和 `items[]`。每项通过 `type=city` 或 `type=airport` 区分城市与机场：

- `code`：当前结果的三字码。
- `cityCode`：机场所属城市三字码。
- `name`、`cityName`：机场或城市名称。

`getRouteFlightTickets` 只接受城市三字码。用户输入城市时使用城市结果的 `code`；用户输入具体机场时保存机场 `code` 作为结果筛选条件，同时使用该项的 `cityCode` 发起城市级查询。

### `getRouteFlightTickets`

查询指定出发城市、到达城市和单个航班日期的逐航班机票列表。

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | :---: | --- |
| `dep` | string | 是 | 出发城市三字码，例如北京 `BJS`；不直接传机场码 |
| `arr` | string | 是 | 到达城市三字码，例如上海 `SHA`；不直接传机场码 |
| `date` | string | 是 | 航班日期，`yyyy-MM-dd`；只查询单个日期 |

主要返回内容：

- `fnum + date + dep + arr`：用于唯一识别航班航段；返回的 `dep`、`arr` 是实际机场三字码。
- `depPlanTime`、`arrPlanTime`：计划起降时间。
- `airlineName`、`aircraft`：航司和机型。
- `FPrice`、`EPrice`、`minPrice`：头等舱/公务舱、经济舱和该航班最低价格。
- `soldStatus`：`0` 表示在售，`1` 表示已售罄。
- `wifi`、`meal`、`age`、`size`：上游原始值；没有正式枚举说明时不自行翻译 `0`、`1`、`-1`。

在售记录排在售罄记录之前，但返回顺序不代表价格从低到高。用户询问“最便宜且可以买”时，只比较 `soldStatus=0` 且 `minPrice` 为有效数值的记录；缺失值不按 `0` 处理，价格为 `0` 也不能解释为免费。

用户明确指定机场时，本 Tool 仍按机场所属城市查询。返回后使用实际 `dep`、`arr` 机场码筛选，并向用户说明采用了城市级查询。`channelCode` 是服务端配置，不由 Skill 传入。

### `getFlightTicketPrice`

查询指定出发地到目的地的单程日期范围或往返价格参考。它用于低价和日期范围查询，不用于替代 `getRouteFlightTickets` 的单日逐航班结果。

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | :---: | --- |
| `dep` | string | 是 | 出发城市代码优先；指定机场时使用机场代码 |
| `arr` | string | 是 | 到达城市代码优先；指定机场时使用机场代码 |
| `type` | string | 是 | `1` 单程，`2` 往返 |
| `depDateBegin` | string | 否 | 单程起始日或往返去程日，`yyyy-MM-dd`；默认明天 |
| `depDateEnd` | string | 否 | 单程结束日；不传默认等于起始日；往返不使用 |
| `arrDate` | string | 条件必填 | `type=2` 时的返程日，不得早于去程日 |

主要返回 `EPrice`、`FPrice`、`minPrice` 以及单程 `flightList` 或往返 `detailList`。这些结果用于价格参考；用户要比较某一天每个具体航班时改用 `getRouteFlightTickets`。

该 Tool 的出发日期从明天开始。用户查询今天或历史日期时，先说明实际查询日期会调整为明天；完全未给日期时说明采用接口默认的明天，不把默认日期说成用户选择。

### `getAirportLowPriceRoutes`

查询指定机场或城市出发的低价航线和目的地榜单。

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | :---: | --- |
| `dep` | string | 是 | 出发城市代码优先；指定机场时使用机场代码 |
| `depDateBegin` | string | 是 | 查询窗口起始日，`yyyy-MM-dd` |
| `depDateEnd` | string | 是 | 查询窗口结束日，`yyyy-MM-dd` |

返回低价目的地、`EPrice`、`FPrice`、`minPrice` 以及对应航班。它只用于“从这里最便宜能飞哪里”，不用于已指定目的地的逐航班机票查询。

### `getFlightStatus`

核验机票结果中航班的完整动态。只有用户继续询问状态、航站楼、登机口、准点率、延误率、取消率或是否正常执行时使用。

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | :---: | --- |
| `fnum` | string | 条件必填 | 航班号；航班号查询时与 `date` 组合使用 |
| `date` | string | 是 | 航班日期，`yyyy-MM-dd` |
| `dep` | string | 条件必填 | 起飞机场三字码；航线查询时必填，可用英文逗号拼接多个机场 |
| `arr` | string | 条件必填 | 到达机场三字码；航线查询时必填，可用英文逗号拼接多个机场 |

从逐航班机票列表继续比较详情时，提取候选项实际出现的出发和到达机场码，分别去重并用英文逗号拼接，连同原日期一次调用 `getFlightStatus`；不要逐航班重复调用。使用 `fnum + date + dep + arr` 关联两个 Tool 的结果，不能依赖数组下标或展示顺序。

## 查询流程

1. 提取出发地、目的地、去程日期、返程日期和单程/往返意图。缺少必要条件时只追问缺失项，不猜地点或日期。
2. 用户提供中文地点或模糊地点时先调用 `searchAirport`。多结果且无法判断时列出候选并追问。
3. 已指定目的地、查询单程且只涉及一个明确日期时，调用 `getRouteFlightTickets` 返回逐航班价格和售罄状态。
4. 用户查询单程日期范围、低价日期参考或往返组合时，调用 `getFlightTicketPrice`。
5. 未指定目的地且询问低价灵感时，确认日期范围后调用 `getAirportLowPriceRoutes`。
6. 比较价格时只使用实际返回的有效字段。逐航班查询先排除 `soldStatus=1`，再比较有效 `minPrice`；任何缺失值都不得当作 `0`。
7. 用户继续询问某个候选航班的动态或运行质量时，再调用 `getFlightStatus` 补充并按四要素关联。

## 多轮对话

- 保留上一轮已经确认的地点代码、日期、机场筛选条件和单程/往返类型；用户只修改一个条件时只替换该条件。
- “最便宜”“更早”“换成某机场”等追问必须基于本轮结构化结果重新筛选；“往返”或日期范围变化需要改用 `getFlightTicketPrice` 重新查询。
- 用户追问准点率、延误率等运行字段时，保持机票候选集合不变，只用 `getFlightStatus` 补充信息，避免把查询范围外的航班加入比较。
- 不把上一轮价格当作当前价格。用户要求刷新时重新调用对应机票 Tool。
- 不展示 MCP Key、内部错误堆栈、原始请求头或完整原始 JSON。

## 回复要求

- 单日逐航班查询先给可售航班数量和最低可用价格，再列出与决策直接相关的航班号、计划时间、航司、最低价和售罄状态。
- 日期范围或往返查询明确说明它是价格参考，并标明实际采用的日期。
- Tool 未明确货币、税费、库存或退改口径时不自行补充。
- 没有可售记录时说明“本次查询未返回可售航班”；仍有售罄记录时可以单独列出，但不要说航线不存在。
- 用户要购买或下单时，说明当前 Connector 只提供价格与航班信息查询，不能完成交易。
