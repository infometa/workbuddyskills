# 修订操作

> WPS 文字文档 revisions 域相关操作。

| 工具 | 功能 |
|------|------|
| [`wps.revisions.accept`](revisions.accept.md) | 接受指定修订 |
| [`wps.revisions.accept_all`](revisions.accept_all.md) | 在线文字文档接受全部修订：支持 查询/设置 |
| [`wps.revisions.accept_by_author`](revisions.accept_by_author.md) | 在线文字文档按作者接受修订：支持 查询/设置 |
| [`wps.revisions.all`](revisions.all.md) | 查询全部修订 |
| [`wps.revisions.by_author`](revisions.by_author.md) | 按作者查询修订 |
| [`wps.revisions.reject`](revisions.reject.md) | 拒绝指定修订 |
| [`wps.revisions.reject_all`](revisions.reject_all.md) | 在线文字文档拒绝全部修订：支持 查询/设置 |
| [`wps.revisions.reject_by_author`](revisions.reject_by_author.md) | 在线文字文档按作者拒绝修订：支持 查询/设置 |
| [`wps.revisions.status`](revisions.status.md) | 设置在线文字文档的修订模式状态 |
