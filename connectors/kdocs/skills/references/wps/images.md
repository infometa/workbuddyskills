# 图片操作

> WPS 文字文档 images 域相关操作。

| 工具 | 功能 |
|------|------|
| [`wps.images.all`](images.all.md) | 删除全部图片 |
| [`wps.images.border`](images.border.md) | 设置图片的边框 |
| [`wps.images.count`](images.count.md) | 查询图片数量 |
| [`wps.images.crop`](images.crop.md) | 设置图片的裁剪 |
| [`wps.images.crop_to_shape`](images.crop_to_shape.md) | 设置图片的按形状裁剪 |
| [`wps.images.data`](images.data.md) | 删除图片数据 |
| [`wps.images.info`](images.info.md) | 查询图片信息 |
| [`wps.images.insert`](images.insert.md) | 在文档、段落或区间插入图片（file_path 为图片 URL） |
| [`wps.images.list`](images.list.md) | 查询图片列表 |
| [`wps.images.locate_paragraph`](images.locate_paragraph.md) | 查询图片所在段落 |
| [`wps.images.move_to_paragraph`](images.move_to_paragraph.md) | 将图片移动到段落 |
| [`wps.images.resize`](images.resize.md) | 设置图片尺寸 |
| [`wps.images.wrap`](images.wrap.md) | 设置图片的环绕方式 |
