# 超链接操作

> WPS 文字文档 hyperlinks 域相关操作。

| 工具 | 功能 |
|------|------|
| [`wps.hyperlinks.address`](hyperlinks.address.md) | 更新超链接地址 |
| [`wps.hyperlinks.all`](hyperlinks.all.md) | 删除全部超链接 |
| [`wps.hyperlinks.count`](hyperlinks.count.md) | 查询超链接数量 |
| [`wps.hyperlinks.data`](hyperlinks.data.md) | 在线文字文档超链接数据：支持删除/查询 |
| [`wps.hyperlinks.insert`](hyperlinks.insert.md) | 在段落或区间插入超链接 |
| [`wps.hyperlinks.list`](hyperlinks.list.md) | 查询超链接列表 |
