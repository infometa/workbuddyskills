# wps.tocs.data

#### 功能说明

查询、插入或删除在线文字文档目录。

> 目录更新前文档须已有标题结构；删除目录用 documents/delete。

#### 支持功能

| 功能简述 | 详情 |
|--------------|------|
| 按文档删除目录 | [tocs-data/documents_delete.md](tocs-data/documents_delete.md) |
| 按文档插入目录 | [tocs-data/documents_insert.md](tocs-data/documents_insert.md) |
| 按文档查询目录 | [tocs-data/documents_query.md](tocs-data/documents_query.md) |
| 按段落插入目录 | [tocs-data/paragraphs_insert.md](tocs-data/paragraphs_insert.md) |
| 按字符区间插入目录 | [tocs-data/ranges_insert.md](tocs-data/ranges_insert.md) |
