# 批注操作

> WPS 文字文档 comments 域相关操作。

| 工具 | 功能 |
|------|------|
| [`wps.comments.add`](comments.add.md) | 在在线文字文档中插入批注 |
| [`wps.comments.author`](comments.author.md) | 按作者查询批注 |
| [`wps.comments.count`](comments.count.md) | 查询批注数量 |
| [`wps.comments.data`](comments.data.md) | 查询批注数据 |
| [`wps.comments.delete`](comments.delete.md) | 删除在线文字文档指定批注 |
| [`wps.comments.delete_all`](comments.delete_all.md) | 删除在线文字文档全部批注 |
| [`wps.comments.list`](comments.list.md) | 查询批注列表 |
| [`wps.comments.modify_text`](comments.modify_text.md) | 修改在线文字文档批注文本 |
| [`wps.comments.paragraph_insert`](comments.paragraph_insert.md) | 在在线文字文档指定段落插入批注 |
| [`wps.comments.range_insert`](comments.range_insert.md) | 在在线文字文档字符区间插入批注 |
| [`wps.comments.reply`](comments.reply.md) | 回复在线文字文档批注 |
| [`wps.comments.resolve`](comments.resolve.md) | 解决在线文字文档批注 |
| [`wps.comments.set_done`](comments.set_done.md) | 设置在线文字文档批注完成状态 |
