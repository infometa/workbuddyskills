# 文字文档文本操作

> WPS 文字文档中与段落、字符区间相关的文本格式与内容操作。

| 工具 | 功能 |
|------|------|
| [`wps.texts.alignment`](texts.alignment.md) | 设置在线文字文档文本的段落对齐 |
| [`wps.texts.border`](texts.border.md) | 在线文字文档文本的段落边框：支持 插入/设置/查询 |
| [`wps.texts.builtin_properties`](texts.builtin_properties.md) | 在线文字文档文本的内置文档属性（标题、作者等）：支持 查询/设置 |
| [`wps.texts.char_border`](texts.char_border.md) | 设置文本的字符边框 |
| [`wps.texts.char_case`](texts.char_case.md) | 设置文本的更改大小写 |
| [`wps.texts.char_spacing`](texts.char_spacing.md) | 设置文本的字符间距与缩放 |
| [`wps.texts.clear_format`](texts.clear_format.md) | 设置在线文字文档文本的清除段落格式 |
| [`wps.texts.content`](texts.content.md) | 在线文字文档文本内容：支持查询/插入/设置/删除 |
| [`wps.texts.count`](texts.count.md) | 查询段落数量 |
| [`wps.texts.effect`](texts.effect.md) | 设置文本的文字效果（阴影/隐藏等） |
| [`wps.texts.emphasis_mark`](texts.emphasis_mark.md) | 在线文字文档文本的着重符号：支持 设置/查询 |
| [`wps.texts.enclosed_char`](texts.enclosed_char.md) | 设置文本的带圈字符 |
| [`wps.texts.font`](texts.font.md) | 在线文字文档文本的段落字体：支持 查询/设置 |
| [`wps.texts.font_batch`](texts.font_batch.md) | 设置在线文字文档文本的批量修改段落字体 |
| [`wps.texts.font_color`](texts.font_color.md) | 设置在线文字文档文本的段落字体颜色 |
| [`wps.texts.font_gradient`](texts.font_gradient.md) | 按字符区间设置文字双色渐变填充 |
| [`wps.texts.format`](texts.format.md) | 在线文字文档文本的段落格式：支持 查询/设置 |
| [`wps.texts.format_batch`](texts.format_batch.md) | 设置在线文字文档文本的批量修改段落格式 |
| [`wps.texts.format_copy`](texts.format_copy.md) | 将源段落格式复制到目标段落范围（格式刷） |
| [`wps.texts.heading`](texts.heading.md) | 在线文字文档文本的标题段落：支持插入/设置 |
| [`wps.texts.highlight`](texts.highlight.md) | 设置在线文字文档文本的段落高亮 |
| [`wps.texts.indent`](texts.indent.md) | 设置在线文字文档文本的段落缩进 |
| [`wps.texts.info`](texts.info.md) | 查询文本的文档信息 |
| [`wps.texts.line_spacing`](texts.line_spacing.md) | 设置在线文字文档文本的段落行距 |
| [`wps.texts.page_count`](texts.page_count.md) | 查询文本的页数 |
| [`wps.texts.page_number`](texts.page_number.md) | 查询段落页码 |
| [`wps.texts.range`](texts.range.md) | 查询段落文本范围 |
| [`wps.texts.replace`](texts.replace.md) | 查找并替换文本 |
| [`wps.texts.search`](texts.search.md) | 搜索文本 |
| [`wps.texts.shading`](texts.shading.md) | 在线文字文档文本的段落底纹：支持 插入/设置/查询 |
| [`wps.texts.structure`](texts.structure.md) | 批量查询段落结构 |
| [`wps.texts.style`](texts.style.md) | 查询段落样式 |
| [`wps.texts.tab_stops`](texts.tab_stops.md) | 在线文字文档文本的制表位：支持 插入/设置 |
| [`wps.texts.tab_stops_clear`](texts.tab_stops_clear.md) | 在线文字文档文本的制表位：支持 插入/设置 |
| [`wps.texts.theme_color`](texts.theme_color.md) | 设置文本的主题色 |
| [`wps.texts.two_lines_in_one`](texts.two_lines_in_one.md) | 设置文本的双行合一 |
| [`wps.texts.underline_color`](texts.underline_color.md) | 在线文字文档文本的下划线颜色：支持 设置/查询 |
| [`wps.texts.word_count`](texts.word_count.md) | 查询文本的字数统计 |
