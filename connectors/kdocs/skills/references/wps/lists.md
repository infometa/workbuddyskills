# 列表操作

> WPS 文字文档 lists 域相关操作。

| 工具 | 功能 |
|------|------|
| [`wps.lists.apply_with_level`](lists.apply_with_level.md) | 批量按级别为多个段落应用列表模板 |
| [`wps.lists.blocks`](lists.blocks.md) | 枚举文档内列表块 |
| [`wps.lists.custom_bullet`](lists.custom_bullet.md) | 设置自定义项目符号 |
| [`wps.lists.data`](lists.data.md) | 在线文字文档段落或范围列表属性：支持 查询/设置 |
| [`wps.lists.level_style`](lists.level_style.md) | 按级别定向设置列表编号样式 |
| [`wps.lists.multilevel`](lists.multilevel.md) | 对字符区间应用大纲多级列表模板 |
| [`wps.lists.number_format`](lists.number_format.md) | 为段落设置自定义编号格式 |
| [`wps.lists.remove`](lists.remove.md) | 移除列表格式 |
