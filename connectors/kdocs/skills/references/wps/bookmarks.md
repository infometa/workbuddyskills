# 书签操作

> WPS 文字文档 bookmarks 域相关操作。

| 工具 | 功能 |
|------|------|
| [`wps.bookmarks.content`](bookmarks.content.md) | 在线文字文档书签内容：支持查询/设置 |
| [`wps.bookmarks.count`](bookmarks.count.md) | 查询书签的数量 |
| [`wps.bookmarks.delete`](bookmarks.delete.md) | 删除书签 |
| [`wps.bookmarks.exists`](bookmarks.exists.md) | 查询书签的是否存在 |
| [`wps.bookmarks.goto`](bookmarks.goto.md) | 跳转到书签 |
| [`wps.bookmarks.insert`](bookmarks.insert.md) | 在段落或区间插入书签 |
| [`wps.bookmarks.list`](bookmarks.list.md) | 查询书签的列表 |
| [`wps.bookmarks.rename`](bookmarks.rename.md) | 重命名书签 |
