# wps.texts.shading

#### 功能说明

在线文字文档文本的段落底纹：支持 插入/设置/查询。query 读回段落底纹（shading_info 专用字段 paragraph_index/background_pattern_color_index，与写侧 value 口径一致）。

**幂等性**：是 — safe
