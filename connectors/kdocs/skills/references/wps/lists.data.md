# wps.lists.data

#### 功能说明

在线文字文档段落或范围列表属性：支持 查询/设置。查询仅支持按段落（paragraphs/query），返回段落当前列表信息。

**幂等性**：是 — safe

| 按字符区间设置列表属性 | [lists-data/ranges_update.md](lists-data/ranges_update.md) |
