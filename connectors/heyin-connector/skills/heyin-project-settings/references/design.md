# 方案设计使用说明

使用 `heyincli req` 查询和维护当前项目的方案版本、分组、事件、表单、字段、结构矩阵、自动计算、逻辑控制和逻辑核查，并按指定方案版本导出 eCRF 或核查定义。执行用户已明确要求的设计配置操作；本技能不代替临床、统计或 eCRF 设计方法学判断。

项目凭证、GET/POST 调用示例、响应封装和错误处理见 [项目设置使用指南](../SKILL.md)。先使用属于目标项目的 `--token-id`；项目由凭证确定，接口不接收 `project_id`。表中 GET 参数组成 JSON 传入 `--query`，POST 参数组成 JSON 传入 `--body`；点号表示嵌套对象字段。需要测试环境时使用 `--test-env`，并在同一目标环境读取、演练、写入和回读。

## 权限与状态

当前分组、事件、表单设计列表与表单设计详情、设计态名称树及两类设计态结构 Grid 是项目设置公共只读资源，持有任一项目级 `PRJ_SETTINGS_` 权限即可读取。定义态读取、方案版本列表、自动计算、逻辑控制、逻辑核查及分组事件差异模式读取需要 `PRJ_SETTINGS_DESIGN_ACCESS`；当前分组事件差异模式的 GET 还要求项目处于 `DESIGNING`。

设计态写入需要 `PRJ_SETTINGS_DESIGN_EDIT`，并受项目可写状态约束。本技能仅在项目方案处于“设计中”时执行创建、更新、排序、删除、关系维护及其演练；该执行准则不表示所有写接口都已统一校验设计阶段，不能以请求成功代替写前状态核验。

版本创建、改名、发布、进入设计、正式发布、撤销和导出不统一套用“设计中”前置条件，按 [方案版本与生命周期](design-version.md) 核对状态跳转和目标；系统级预置宏和文本校验规则属于不绑定项目 ID 的只读目录。平台拒绝时保留实际错误，不通过换 ID、换接口或重复请求绕过。

分组、事件、表单、字段组和字段的设计态 `vid` 写入值长度为 1–32，必须匹配 `^[A-Z_][A-Z0-9_]*$`：以大写字母或下划线开头，后续仅大写字母、数字或下划线。后端不接受小写，也不自动转换；大小写不敏感判重用于防止与存量 VID 冲突，不表示小写写入有效。按各领域规定的对象范围检查唯一性；需要调整用户提供的 VID 时先明确最终值，不静默改名。

版本、分组、事件、表单、字段组、字段、计算、逻辑和核查 ID 均从当前项目最新读取结果唯一定位。设计态 `*_dsn_id` 与方案版本定义态 `*_def_id` 不可混用；名称可重复时结合 VID、所属层级和状态定位。候选不唯一、分页未读完或必要字段缺失时，先补足信息，不猜测默认对象或状态。

## 演练、授权与结果核验

先读取完整目标和现状，按领域要求执行创建、删除、发布或撤销演练，展示实际影响；演练成功不表示正式操作已经完成，演练授权也不代替正式操作授权。用户仅查询影响时止于演练。目标、参数、依赖或状态变化后重新演练，正式操作必须使用该次演练覆盖的相同目标。

写入前核对已有授权是否覆盖同一目标及实际影响；已覆盖时继续执行，无需重复确认，未覆盖时补充确认。发布草稿、正式发布、重新进入设计和撤销是不同意图，不相互替代。没有演练接口的操作使用最新读取结果说明可识别影响，不编造影响计数。

写后按领域要求回读完整对象或矩阵，比较实际差异与依赖失效状态。请求成功、演练零计数或公式试跑通过都不能单独证明最终配置生效或业务判断正确。必要响应字段缺失时明确哪些内容无法核验；结果不确定时先回读，不盲目重复写入。

导出请求仅取得响应，`req` 不负责下载导出文件，也不提供文件上传。返回的签名下载地址属于短期授权材料，不在对话中公开；不能宣称 CLI 已保存文件或已经核验导出内容。
