# 数据分析配置说明

按 [功能配置入口](feature.md) 与 [项目设置使用指南](../SKILL.md) 选择当前项目凭证，使用 `heyincli req`。项目由凭证确定，不传 `project_id`；文中 `123` 仅为示意。GET 参数放入 `--query`，POST 参数放入 `--body`。下文授权核对包含已有明确授权，只有未覆盖相同目标和实际影响时才另行确认；演练授权不等于正式操作授权。

## 功能总览

| 功能 | 说明 | 可修改 |
| --- | --- | --- |
| 查询数据分析状态 | 读取当前项目是否开启数据分析功能 | 否 |
| 更新数据分析状态 | 显式开启或关闭当前项目的数据分析功能 | 是 |

本领域只管理项目级功能开关，不授予、撤销或证明任何用户、角色、中心或数据集的分析访问权限，也不执行分析任务。

## 对象与状态模型

数据分析配置只有一个可信状态字段 `is_analysis_on`：`false` 表示功能关闭，`true` 表示功能开启。状态必须来自当前项目实时读取；字段缺失、不是布尔值或读取失败时均属于状态无法确认，不能解释为关闭。

目标状态与实时状态相同表示无变化，不需要发送写请求。平台也会把相同值拒绝为对象未变化；不得为了制造成功而反转目标值、重复请求或改用其他项目。

## 接口一览

| 用途 | 方法 | 路径 | 请求参数 |
| --- | --- | --- | --- |
| 获取数据分析开关状态 | `GET` | `/api/project/settings/data_analysis/get_is_analysis_on/` | 无 |
| 更新数据分析开关 | `POST` | `/api/project/settings/data_analysis/set_is_analysis_on/` | `--body`：`is_analysis_on`（boolean，可选）：仍必须显式传目标 `true` 或 `false` |


## 操作流程

### 查询数据分析状态

使用当前项目凭证读取一次，只返回用户问题需要的开启或关闭状态。`is_analysis_on=true` 只说明项目功能配置已开启，不能据此宣称当前用户能读取、导出或分析任何业务数据。

### 开启或关闭数据分析

1. 读取实时 `is_analysis_on`，确认当前项目为唯一目标。目标与现状相同时报告无变化，不发送 POST。
2. 展示当前状态、开启或关闭方向，以及 `{ "is_analysis_on": <目标布尔值> }`。必须显式包含布尔值，不能依赖 参数定义 省略后的默认行为。
3. 说明开启不改变用户权限，关闭也不等于删除分析结果或业务数据；确认本次状态变化在授权范围内后只调用一次。
4. 写入失败、超时或结果未知时停止，不反转布尔值、不更换项目、不自动重试。

## 结果核验

写入返回成功后立即重新读取当前项目状态。只有回读字段存在、类型为布尔值且等于批准的目标值时，才报告开关切换完成。若请求成功但回读失败、字段缺失或仍为旧值，只报告“写入请求成功但核验未完成”；不得用写接口通用成功响应替代最终状态。

## 共同安全边界

- GET 与 POST 均不接收 `project_id`，项目由已选项目凭证确定，不从自由文本推断项目。
- 更新数据分析开关的 POST 必须在真实请求前取得针对当前方向和完整请求体的批准；参数变化后重新核对授权。
- 最终权限、项目状态和业务规则由平台校验。权限不足、对象未变化、项目不可用、响应非法或服务不可用时保留稳定错误语义并停止。
- 开关结果不是授权凭证，不把“已开启”扩展解释为可访问敏感分析数据，也不输出任何与本次开关任务无关的研究、参与者、中心或分析内容。
