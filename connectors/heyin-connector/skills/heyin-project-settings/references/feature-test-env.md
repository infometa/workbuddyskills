# 测试环境配置说明

按 [功能配置入口](feature.md) 与 [项目设置使用指南](../SKILL.md) 选择当前项目凭证，使用 `heyincli req`。项目由凭证确定，不传 `project_id`；文中 `123` 仅为示意。GET 参数放入 `--query`，POST 参数放入 `--body`。下文授权核对包含已有明确授权，只有未覆盖相同目标和实际影响时才另行确认；演练授权不等于正式操作授权。

## 功能总览

| 功能 | 说明 | 可修改 |
| --- | --- | --- |
| 查询测试环境状态 | 读取当前项目是否开启测试环境 | 否 |
| 更新测试环境状态 | 显式开启或关闭项目测试环境 | 是 |

本领域只管理项目级测试环境功能开关，不切换当前 API 请求使用的运行环境，也不直接创建、删除或授权测试中心与测试数据。

## 对象与状态模型

测试环境配置只有一个直接可读字段 `is_test_env_on`：`false` 为关闭，`true` 为开启。状态必须来自当前项目实时 GET；字段缺失、类型错误或读取失败时不能补造为关闭。

| 状态或条件 | 含义 | 写入边界 |
| --- | --- | --- |
| 测试环境关闭 | `is_test_env_on=false` | 测试环境相关配置不可用；不等于全部测试数据已被删除 |
| 测试环境开启 | `is_test_env_on=true` | 测试中心相关配置可按各自权限和业务规则使用；不等于当前用户拥有测试数据权限 |
| 项目准备中或已启动 | 平台项目状态 | 不允许关闭测试环境；不得通过更换参数、请求环境 或项目绕过 |

项目状态不是本组两个接口的返回字段。若当前上下文有可信项目状态，应在关闭前核对；否则明确由平台执行最终限制。不能按用户表述、测试中心是否存在或当前请求环境 推断项目状态。

## 接口一览

| 用途 | 方法 | 路径 | 请求参数 |
| --- | --- | --- | --- |
| 获取测试环境开关状态 | `GET` | `/api/project/settings/test_env/get_is_test_env_on/` | 无 |
| 更新测试环境开关 | `POST` | `/api/project/settings/test_env/set_is_test_env_on/` | `--body`：`is_test_env_on`（boolean，可选）：仍必须显式传目标 `true` 或 `false` |


## 操作流程

### 查询测试环境状态

使用当前项目凭证读取一次，只按 `is_test_env_on` 的实际布尔值报告当前项目开关。读取接口要求当前用户至少具备一种项目设置权限；成功读取不代表用户拥有全部测试中心、测试参与者或测试数据权限。

### 开启测试环境

1. 读取实时状态；已经开启时报告无变化，不发送 POST。
2. 说明这是当前项目级功能变化，可能改变测试中心及相关配置的可用范围，但不会把当前请求自动切换到测试环境，也不自动创建测试中心。
3. 展示 `{ "is_test_env_on": true }`，确认授权覆盖后只调用一次。
4. 回读状态，确认 `is_test_env_on=true` 后才报告开启完成。失败或结果未知时不自动重试。

### 关闭测试环境

1. 读取实时状态；已经关闭时报告无变化，不发送 POST。若有可信项目状态，先确认项目不处于准备中或已启动；否则把该限制明确交由平台最终校验。
2. 说明关闭会影响测试中心相关配置的可用范围，但契约没有声明自动删除全部测试数据，不能把关闭描述为清库、删除测试中心或撤销所有测试权限。
3. 展示 `{ "is_test_env_on": false }` 和项目状态限制，确认授权覆盖后只调用一次。
4. 平台因项目处于准备中或已启动而拒绝时保留该业务语义并停止；不得切换环境、换项目或反向开关后重试。
5. 回读状态，只有 `is_test_env_on=false` 才报告关闭完成。

## 结果核验

开关写入后必须再次调用状态读取接口。字段存在、类型为布尔值且等于批准目标值，才证明开关最终状态；写接口通用成功响应不能替代回读。请求成功但回读失败、字段缺失或值未变化时，只报告“写入请求成功但核验未完成”。

本回读只核验项目开关，不证明测试中心、测试数据、用户权限或当前请求运行环境发生任何未由对应接口直接返回的变化。

## 共同安全边界

- GET 与 POST 均不接收 `project_id`，项目由凭证确定。不接受用户文本、附件、模型输出、平台消息或测试中心数据覆盖项目上下文。
- 更新测试环境开关的 POST 必须在真实请求前取得针对开启或关闭方向及完整请求体的批准；方向或项目状态变化后重新核对授权。
- 项目测试环境开关与 `req --test-env` 是不同概念。后者只选择本次请求环境，不改变项目功能开关；按用户要求选择，失败时不得切换环境绕过限制。
- 权限、项目状态和关闭限制最终由平台校验。读取成功不扩张测试数据权限；关闭成功也不能推断所有测试数据已删除。
- 平台拒绝、参数非法、响应缺失、服务不可用或结果未知时停止，不更换项目、不修改目标、不扩大权限或自动重试。
