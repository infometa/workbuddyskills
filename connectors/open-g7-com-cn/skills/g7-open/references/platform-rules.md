# 平台级规则（G7易流开发者平台）

来源：官方接入指南（`https://open.g7.com.cn/docs/llms.txt`）。这些规则不随单个接口变化，接口级细节请以 `describe_platform_api` 返回为准。

## 环境：沙箱 vs 正式

| 用途 | 地址 |
|---|---|
| 控制台 | https://open.g7.com.cn/console |
| 正式环境 API | https://api.open.g7.com.cn |
| 沙箱 API | https://api-sandbox.open.g7.com.cn |

- **MCP 连接器只有一个 endpoint**（`https://open.g7.com.cn/open-mcp/mcp`），环境由**授权凭证**决定，不是工具参数，也无法靠 URL 区分。
- 当前环境写在 `initialize` 响应的 `instructions` 里（例如"当前授权凭证环境：沙箱"）。**回答用户前先确认环境**，沙箱数据是演示租户，不是企业真实数据。
- 沙箱按企业共享，同一企业的开发者看到同一套模拟数据，管理员重置会清空自建数据，也会影响其他人。
- 沙箱凭证只能访问沙箱，正式凭证只能访问正式环境，两者不能互换。

## 权限与准入

- 接口分两档「授权对象」：**普通开发者**（查详情、检索主数据、拉位置、消费事件增量）和**企业开发者**（创建/更新/删除、下发媒体与播报指令）。
- **身份 ≠ 权限**：成为企业开发者只是获得"能勾选"的资格，具体接口仍要在凭证里逐条勾选，没勾的照样 403。
- 调用限制（如 10 次/秒、1000 次/天）在接口详情页标注，超限返回 429。
- 在 MCP 里对应字段：`authorized: false` = 凭证没勾这个接口；`callable: false` = 当前不能执行，看 `blocked_reason`（`discovery_only` 表示是写接口）。

## 限流与重试

- 只对 **429、5xx、网络超时** 重试；400/401/403/404 重试没有意义，先改请求。
- 429 优先看响应里的 `Retry-After`；没有就用指数退避 + 随机抖动（1s / 2s / 4s），**最多 3 次**。
- 批量同步用游标分页顺序推进，**不要并发扫全量**；实时类查询优先用事件/增量接口替代轮询。
- 多个实例不要同时退避到同一秒。

## 敏感数据

| 数据 | 注意 |
|---|---|
| 司机手机号、证件号 | 按需最小化字段；展示和日志都脱敏 |
| 车辆位置与轨迹 | 长期保存、转发给无关系统都有风险，按业务需要查询 |
| 媒体下载地址 | 当临时链接用，用媒体 ID 重新申请，不要当永久链接存 |
| 事件回调内容 | 日志只留事件 ID 和必要字段 |

- 响应里的 `LFW**********4567`（VIN）、`GRnchQa63rB5JK77Bgpg7w==(Rg==)`（用户名）是平台脱敏/加密值，**原样透传，不尝试解码，也不要推断**。
- 不要把整段原始响应贴进工单或日志；提工单只给 `trace_id` + 请求时间 + 接口路径。

## 时间与时区

- 时间字段统一带时区偏移，形如 `2026-10-22T15:09:50+08:00`（北京时间）。
- 事件类查询时间范围最长 **31 天**，超出要分段查再自行汇总。
- 事件检索的 `filter` 必须包含 `start_time` / `end_time`（实测缺省会返回 8800018069 / 8800018070）。

## 认证方式说明

- **MCP 连接器走 OAuth（Bearer Token）**：授权、续期、注入都由 WorkBuddy 自动完成，用户不需要配置 Access Key / Secret Key，也不涉及请求签名。
- 如果用户问"要不要配 AK/SK"，回答：MCP 场景不需要；只有自己直连 OpenAPI 时才需要 AK/SK 签名。
