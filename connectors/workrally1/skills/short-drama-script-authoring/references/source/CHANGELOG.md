## v3.2.0 (2026-06-17) · 核心骨架锁定节点 + 三大结构性通病治理

### 新增
- **步骤 2.5 核心骨架锁定确认（必经节点）**：在步骤 2 与步骤 3 之间插入强制确认门，仅输出「精简版骨架」三件套——核心事件锚点表（精简）、冲突路径轮换表（精简）、核心能力/资源边界总纲；未确认不得进入剧本生成。从结构端解决剧情崩坏、叙事模板化、能力膨胀三大通病。
- **大纲（`1-outline.md`）升级为五层结构**：新增第三层「核心事件锚点表（细化展开版）」、第四层「冲突路径轮换表（细化展开版）」，均为 2.5 骨架的字段补全，不重复产出。
- **人设（`2-character.md`）新增「能力/资源边界铁律」（条件必填）**：战力/金手指类用能力模板，甜宠/种田/年代/悬疑等非战力题材用「核心资源/优势」替代模板，避免无效套话；新增反派能力边界校验。

- **自审（`4-review.md`）新增评分子项**：结构与节奏加「锚点对齐度」8 分，标签与逻辑加「能力边界合规性」5 分；顺带修复原版结构维度子项总和不足 40 的算术问题，两个维度现精确等于满分。
- **剧本生成（`3-script.md`）同步骨架约束**：生成铁律 8→10 项（新增禁止锚点偏离、禁止能力越界）；写作工作流新增第 0 步骨架校验与能力边界校验；检验清单与内部自检底稿新增锚点对齐、能力合规两项；内部设计说明新增「对应锚点」「能力阶段」字段。
