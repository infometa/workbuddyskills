# 短剧通用规格（所有题材共用）

任何题材模块都默认遵循本文件的形式规格与单集硬指标。题材模块只写"差异化"内容，通用规格不再重复。

## 形式规格

| 项目 | 标准 |
|---|---|
| 单集时长 | 1-2 分钟（90-120 秒） |
| 单集篇幅（硬性 · v8.8.0 修订） | **每集 200-448 词（英文词数口径，目标 320 词）** |
| 总集数 | 80-100 集（爽剧）/ 50-80 集（情感） |
| 单集结构 | 钩子（5s）→ 主体（90s）→ 再钩子（最后 5-10s） |
| 拍摄比例 | 9:16 竖屏，特写 + 快剪为主 |

> ⚠️ **篇幅红线（所有题材通用，不得违反 · v8.8.0 修订）**：
>
> 每集 **200-448 词**（目标 320 词，允许向两端浮动）。**篇幅一律以英文词数（words）为口径衡量，不再使用任何中文字数（字）口径。**
>
> **换算依据（对应完整 1-2 分钟时长区间）**：
> - 英文朗读约 150-160 wpm，1 分钟纯台词 = 150-160 词，2 分钟 = 300-320 词，加 30-40% 动作描写 → 1-2 分钟对应约 **195-448 词**，取整 **200-448 词**
> - 区间与时长区间严格对齐：1 分钟短集对应 200-292 词，2 分钟满集对应约 448 词，不得非法砍掉短集
>
> **节拍类型篇幅下限（防偷懒护栏）**：下限与节拍类型联动——
> - **转集 / 合集**（放弹簧 + 收口，情绪密度高）：≥ **300 词**
> - **起集 / 承集**（只压不放，情绪密度低，允许短集）：≥ **200 词**
> - **但起/承集少出来的篇幅必须用"压弹簧的细节"填满**（人物微表情、压抑的动作、未说出口的潜台词外化），**不是用"放点"填满**——不是允许写水戏，是允许写短戏
>
> **第 1 集不特殊加长**——首集靠钩子密度抓住观众，不靠篇幅，与其它集同体量（拍出来 1-2 分钟）。

## 单集硬指标（每集必须满足）

1. **情绪二选一**：每集要么压弹簧、要么放弹簧，不允许中间状态（详见 `frameworks/emotion-spring.md`）
2. **钩子前置**：开篇 5 秒内建立微型冲突或悬念（详见 `frameworks/hook-design.md`）
3. **信息前置**：第一句台词抛出身份/冲突/目标，不绕弯
4. **动作可视化**：动作和环境互动代替形容词
5. **付费卡点**：商业短剧通常第 10/20/30 集设付费点，每个卡点 = 放弹簧高潮 + 更大悬念

## 通用必备角色框架

| 角色 | 通用职能（题材模块会细化） |
|---|---|
| 主角 | 承载观众代入与情绪释放 |
| 核心反派/阻力 | 制造压弹簧的来源 |
| 见证人 | 目睹主角高光/反派崩溃，放大爽感 |
| 助力者 | 推动关键反转 |

## Logline 变体模板库（v3.4 新增）

一句话故事（logline）不得每次用同一句式。从以下变体中选取，**同题材连续 2 次不得用同一种**。

| 编号 | 句式结构 | 示例 |
|---|---|---|
| T1 经典式 | 被XX的XX因为XX必须XX但XX | 被退婚的落魄少爷因为一通神秘来电必须重新证明自己，但全城都等着看他笑话 |
| T2 反差式 | 所有人都以为XX只是XX直到XX | 所有人都以为上门女婿只是废物，直到他一个电话调动千军 |
| T3 时间式 | XX年后XX回到XX却发现XX | 十年后战神回到故乡，却发现女儿被欺辱、妻子跪在岳母门前 |
| T4 悬念式 | 当XX发现XX时XX是她/他最后的XX却不知道XX | 当裴念发现丈夫的背叛时离婚是她最后的体面，却不知道有人已为她布下天罗地网 |
| T5 反讽式 | XX以为XX就能XX没想到XX | 温衍舟以为把裴念绑在身边就能掌控她，没想到自己先沦陷 |
| T6 倒叙式 | 谁能想到此刻XX的XX曾经XX | 谁能想到此刻跪地求饶的谢家大少，曾经把卫瑶踩在脚下 |

**使用规则**：
1. 子方向选定后，优先匹配与子方向情绪底色最搭的句式（如：隐忍爆发→T2/T3，错位复仇→T4/T6，治愈偏爱→T5）
2. 同题材连续 2 次不得用同一 T 编号
3. 可根据内容微调句式细节，但骨架结构必须对应选定 T 编号
4. 🔴 **编号严禁泄漏给用户（全局 · 一票否决）**：T1-T6 是**内部句式编号**，交付给用户的 logline 成品里**绝对不能出现** `(T4 悬念式)` `(T4 Suspense Style)` 这类标注。用户看到的只是一句干净的故事梗概，看不到任何编号/句式名/风格说明。编号只在你内部选句式时用，写完即丢。

## 🔴🔴 交付正文禁泄漏内部骨架标注（全局 · 一票否决 · v8.8.0 新增）

**所有内部结构/节拍/骨架标注，绝对不能出现在交付给用户的正文里**——无论是大纲、分集正文还是剧本。这是与 T/G 编号泄漏并列的一票否决红线，且**在英文项目里尤其致命**（模型极易把内部中文骨架标签直接抄进英文成品）。

**被禁止泄漏的内部标注（黑名单，含中英任何写法）**：

| 类别 | 禁止出现的字样（示例） |
|---|---|
| 起承转合 | `起` `承` `转` `合`、`转-合`、`(转 · 放)`、`Beat: 转-合`、`Setup/Development/Turn/Resolution` 标签 |
| 压放（弹簧） | `压` `放`、`压弹簧` `放弹簧`、`(转 · 放)`、`Press/Release` 标签 |
| 情节单元 | `Plot Unit 2` `情节单元 2`、`Plot Unit 2 — The First Reveal (EP 4-5)` |
| 关键节点 | `关键节点` `Key Node`、`节点表` |
| 集号+节拍混排 | `EP 4 · "One Wrench, One God" (转 · 放)`、`EP 4-5 · Beat:...` |
| 冲突轮换/能力边界 | `冲突轮换表` `能力边界` 等五件套内部表名 |

**真实反面案例（本次触发本条红线的泄漏）**：
- ❌ `Plot Unit 2 — The First Reveal (EP 4-5) · Beat: 转-合`
- ❌ `EP 4 · "One Wrench, One God" (转 · 放)`
- ✅ 正确：交付正文只有 `EP 4 · "One Wrench, One God"` 这样干净的集号 + 集标题，**后面不带任何括号里的节拍/压放/起承转合标注**。

**根因与铁律**：
1. 步骤 2.5 五件套（节点表/情节单元规划表/逐集节拍表等）是**内部底稿**，起承转合、压放、情节单元、关键节点都是**给你自己排结构用的中文骨架标签**，选完即用于指导写作，**写完即丢，绝不誊抄进正文**。
2. 英文项目：五件套底稿用中文写没问题，但**切到步骤 3 写正文那一刻，所有中文骨架标签必须清零**。正文里出现任何一个上表中的中文字/骨架英文标签 = 一票否决重写。
3. 交付前**逐行扫描正文**：凡出现 `起/承/转/合/压/放/情节单元/关键节点/Plot Unit/Beat:/Key Node` 或"集标题后括号里的结构标注"，一律删除后再交付。
4. 用户看到的正文只应有：集号、集标题、场景描述、动作、台词。**没有任何一处结构注解**。

## 梗概开头变体库（v3.4 新增）

故事梗概（300-500 字）的叙事切入方式不得每次相同。从以下 5 种中选取，**同题材连续 2 次不得用同一种**。

| 编号 | 切入方式 | 说明 | 适用子方向 |
|---|---|---|---|
| G1 顺叙式 | 开场处境→金手指/转折→主要冲突→爽感释放→高潮→结局 | 经典线性叙事 | 通用 |
| G2 悬念倒叙式 | 从高潮/绝境开场→闪回交代起因→回到现场→走向结局 | 先抛结果再讲过程 | 隐忍爆发、错位复仇 |
| G3 双线并行式 | 两条线同时展开→某刻交汇→双重爆发 | 两条叙事线互不交代 | 双线并行、暗线反转 |
| G4 反讽对比式 | 先讲"所有人都以为"→逐层揭示真相→反转清零 | "以为vs实际"的反差 | 隐藏身份碾压、蛰伏蓄力 |
| G5 命运转折式 | 从"命运的一步"切入→分叉前后对比→新路径展开 | 聚焦改变一切的那个瞬间 | 赎罪型、治愈偏爱 |

**使用规则**：
1. 子方向选定后，优先匹配 G 编号
2. 同题材连续 2 次不得用同一 G 编号
3. G 编号决定梗概的**叙事结构**，不改变故事内容要素
4. 🔴 **编号严禁泄漏给用户（全局 · 一票否决）**：G1-G5 是**内部叙事结构编号**，交付给用户的 synopsis 成品里**绝对不能出现** `(G5 命运转折叙事风格)` `(G5 Fate's Turning Point Style)` 这类标注。用户看到的只是一段干净的剧情梗概。编号只在你内部选切入方式时用，写完即丢。
