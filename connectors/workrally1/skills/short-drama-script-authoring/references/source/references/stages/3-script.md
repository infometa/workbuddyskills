# 步骤3：短剧剧本生成（标签化适配+反AI通病版）
主SKILL.md步骤3在内容类型为「竖屏短剧」且需要写剧本时读本文件。同时必读frameworks/emotion-spring.md和frameworks/hook-design.md。**写第 1 集时额外必读 `frameworks/first-episode.md`（第一集专项创作法）——第一集是独立引流集，"起承转合俱全的单集闭环"是它的义务，不受 R13/反模式13/铁律14「禁一集一事件」约束；情节单元制从第 2 集起生效。**
> 执行顺序：在步骤 2.5 核心骨架确认后执行。所有内容必须严格对齐 2.5 确认的节点表、冲突轮换表与能力/资源边界总纲，偏离框架的内容必须自行重写。

## 单集硬性规定（通用底座，所有标签通用）

| 项目 | 规定 |
|---|---|
| 篇幅（硬性 · 英文词数口径 · v8.8.0 修订） | **每集 200-448 词（目标 320）**。**节拍类型下限**：转/合集 ≥300词；起/承集 ≥200词。低于此判不合格，必须补写（详见 `shared/base.md` 篇幅红线）。第1集不特殊加长 |
| 时长 | 1-2分钟（90-120秒） |
| 弹簧类型 | 压 / 放 / 压放结合（必须明确选一种，不允许中间状态） |
| 开篇钩子 | **每集5秒内必须出现；首集前3-10秒必须是强冲突/强情绪爆点（被打/被甩/被夺/被羞辱/被背叛/生死危机/身份秘密当场揭穿），严禁慢热铺垫——详见 hook-design.md「首集开篇黄金3-10秒」（v6.1 强化 · 一票否决）** |
| 结尾钩子 | 最后5-10秒必须有更大悬念 |
| 信息前置 | 第一句台词就抛出身份/冲突/目标 |
| 视觉化（动作优先 · v5.6 改）| **动作 > 表情 > 台词 > 环境**。可视化优先写人物动作和表情，环境只在"剧情必需"时点一句。**禁止为氛围而写环境** |
| 环境描写预算（硬性 · v5.6 新增）| **单集纯环境/氛围描写累计不超过 2 句，且每句不超过 15 字**。环境只允许用于：① 场次头必需的地点信息（"办公室·夜"已够，不再描写办公室陈设）；② 与剧情直接相关的环境信号（如"雨"是因为剧情需要淋雨/湿透的关键道具）。**禁止**天气渲染、光影氛围、季节感、城市风貌等纯情绪性环境铺陈——交给镜头语言和配乐 |
| Show not tell | **全程只写可拍摄的画面：动作、表情、台词、环境。禁止任何"总结型/抒情型"叙述句（见铁律12）** |

## 标签化风格适配规则
### 1. 叙事视角适配
- 男频/大男主：偏上帝视角，主角内心戏少，多行动多侧面烘托
- 女频/大女主：强主角视角，情感细腻——**但细腻靠动作细节和台词潜台词实现，不靠氛围铺陈和感官堆砌**。内心活动一律翻译成可拍摄的外部信号（铁律12），感官描写每集不超过 2 处且必须服务剧情（如"手在发抖"是因为要拿不稳东西这个剧情，不是为表现紧张）（v5.6 改）
- 悬疑/灵异：限知视角，信息克制，悬念感强

### 2. 台词调性适配
- 甜宠/情感向：台词有温度、细节感强，爽感/心动感足
- 爽文/打脸向：反派台词欠打，主角台词装逼简短，打脸干脆
- 权谋/商战：台词信息密度高，潜台词丰富，话里有话
- 喜剧/搞笑向：台词接地气，梗密集，反差感强
- 古风/民国：台词符合时代语境，避免现代网络用语

### 3. 场景节奏适配
- 战神/动作：动作场面占比高，节奏快，台词少
- 种田/家长里短：生活场景多，节奏偏缓，烟火气重
- 脑洞/悬疑：反转密集，信息密度高，每集钩子强度更高

## 生成铁律（AI通病10项禁令 · 新增4项）
1. **禁止连续同路径**：同类型冲突，相邻两轮解法必须来自《冲突解法变体库》不同分类
2. **禁止万能兜底**：同一配角连续兜底≤1次，全剧外力兜底占比≤40%，必须有主角独立破局
3. **禁止表达重复**：同一微表情/动作全剧≤2次，必须调用《情绪表达变体库》轮换
4. **禁止金手指公式化**：金手指出场模式必须轮换，重大金手指必须有≥3集铺垫
5. **禁止配角工具人**：每10集至少1段配角独立剧情，体现其个人动机与成长
6. **禁止长弧平推**：长线冲突必须分阶段，同类型场景连续出现≤3轮
7. **禁止逻辑硬伤**：解决方案必须符合对应背景的世界观能力上限
8. **禁止人设漂移**：所有人物行为必须符合「人设铁律」，重大转变必须有过渡
9. **禁止关键节点偏离**（v3.2）：核心事件必须严格落在关键节点集数范围内，偏差不得超过±2集，不得擅自替换关键节点功能
10. **禁止能力越界**（v3.2）：不得出现预设外的能力升级，不得突破能力/资源边界总纲的终极上限，不得凭空消除能力代价
11. **禁止副线掉线**（v3.3 新增）：存在独立副线（配角线/感情副线/复仇副线等）的剧集，每批次必须同步推进副线，不得让副线全程依附主线或中途消失；副线必须有自己的小关键节点与回收
12. **禁止叙述性文字（Show not tell · v5.5 新增）**：剧本是给镜头看的，不是给读者读的。**只允许写出"摄像机能直接拍到、麦克风能直接收到"的内容——动作、表情、台词、可见的环境与道具**。严禁出现以下小说化叙述句：
    - ❌ 总结型抒情：「没有回头。没有再提过去的三年。」「剑还在腰间，但不再是复仇的剑了。」「那一刻，她终于释怀了。」
    - ❌ 上帝视角心理旁白：「他心里清楚，这一战躲不过去。」「她知道，自己再也回不到从前。」
    - ❌ 抽象定性概括：「三年来的恩怨在此刻烟消云散。」「这是一场注定没有赢家的较量。」
    - **改写铁律**：任何内心活动、时间流逝、关系转变，都必须翻译成"可拍摄的外部信号"——
      - 「不再是复仇的剑了」→ 动作：`他解下腰间的剑，轻轻放在桌上，转身没有再看一眼。`
      - 「她终于释怀了」→ 表情+动作：`她怔了两秒，嘴角慢慢松开，长出一口气，把那张旧照片放回了抽屉。`
      - 「他心里清楚这一战躲不过」→ 台词/动作：`他攥紧拳头，低声：「躲不掉了。」`
    - **唯一例外**：标准格式中"人物动作和状态描写"行可写客观可见的状态（如`他满身是血，靠墙喘气`），但不得写不可见的心理与抽象总结。
    - **环境氛围型废戏（v5.6 扩展）**：以下环境描写视为废戏，即使"能拍"也必须删除——
      - 连续 2 句以上的纯环境描写（天气/光影/风景/城市风貌），且与剧情无因果
      - 用环境渲染情绪（如"暴雨如注，仿佛在为她的命运哭泣"）——短剧的情绪靠剧情和表演，不靠环境烘托
      - 场景转换时的"氛围过渡段"（如从办公室切到家里，写一大段家里的陈设氛围）——场景转换只需一行场次头"地点·时间·内外景"
      - **唯一允许的环境描写**：作为剧情道具的环境信号（如"地上有滩水"是因为有人要滑倒/留脚印，是剧情需要，不是氛围）
    - **网文腔专项清除（v6.1 新增 · 一票否决）**：以下四类是"网络小说叙述腔"，即使每句看似"能拍"，但整体是写给读者读的文学修辞，不是写给镜头拍的剧本，**一律禁止，命中即重写**——
      - ❌ **病征一·短句留白堆叠**：用断句+句号制造文学节奏与"留白"。如「没有认出的反应。只有陌生人之间本能的防备。」「他的字。他的笔迹。」——这是小说的气口，不是台词也不是动作。
        → 改写：翻译成**演员能演的单一动作/表情 + 台词**。`她皱眉，后退半步，手悄悄按住门把。\n女人：（警惕）你是谁？`
      - ❌ **病征二·通感比喻抒情**：用"像……""仿佛……""能感受到……"做文学通感。如「能感受到落笔时的力道——很重，像在刻。」「笑得很温暖，像冬天的太阳。」——比喻和通感无法被拍摄，是纯文字修辞。
        → 改写：只写**镜头能拍到的客观细节**。`她的指尖划过纸上的字，停住。纸被笔尖戳破了几个洞。`（"力道很重"用"戳破纸"这个可拍的物证表达，不用比喻）
      - ❌ **病征三·设问句留悬念**：用问句自问自答替演员"想心事"。如「是谁把它从显眼的位置……藏了起来？」「难道……他早就知道了？」——这是旁白在替观众提问，是小说腔。
        → 改写：把疑问变成**人物的动作选择或一句外化台词**。`她把相框翻过来，背面贴着一张便签。她念出声：\n女人：（声音发紧）"别让她看见。"——谁写的？`（疑问交给人物当面说出，不交给旁白）
      - ❌ **病征四·省略号气口/破折号抒情**：用「……」「——」制造停顿、欲言又止、拖长情绪。如「藏了起来……」「他望着她——千言万语，最终化作沉默。」——这是文字排版上的情绪暗示，镜头拍不出省略号。
        → 改写：停顿用**括号里的表演提示**承载，不用标点。`女人：（顿了顿，别开脸）……没什么。` 中的停顿应写成 `女人：（别开脸，没接话）`，或给一句实在的台词收口。
      - **网文腔总判据**：写完一段，自问「这是在**描写一个画面给读者想象**，还是在**指挥摄像机和演员**？」——凡是在"替读者营造氛围、留白、暗示、抒情"的，都是网文腔，删除或改写成动作/表情/台词。
13. **禁止水词（每句台词、每个 action 必须带情绪 + 关系姿态 · v7.2.6 新增 · 全局 · 中英通用）**：短剧是情绪过山车，观众滑走只需 3 秒。**每一句人物台词、每一处动作描写，都必须携带明确的情绪指向 + 人物之间的关系/权力姿态**，禁止"平淡式"的中性功能性表达。
    - **判据（三选一即为水词，必须改写）**：① 这句话删掉，人物关系和情绪状态毫无变化；② 换任何一个角色来说都成立（没有专属立场）；③ 只传递信息、不传递态度（谁高谁低、谁进谁退、谁在忍谁在压，一概读不出）。
    - **注意不是"全程强情绪"**：情绪是过山车不是全程尖叫。**"带情绪"≠"拉满"**——隐忍、克制、假装平静、暗中试探，都是明确情绪；强情绪只放在关系/权力**发生位移**的节点（压制/反抗/反转/臣服/独占），靠"承"集的压抑衬托"转"集的爆发（节奏口径对齐 `emotion-spring.md` 与 hook-design.md，不额外造节拍规则）。全程无差别高音=情绪过载，与本铁律同等不合格。
    - **情绪必须有"因"**：所有情绪都依附于人物当下的关系/权力位置与处境，不是凭空宣泄——上位者的态度、下位者的反应，都要落在他此刻的站位上。**（"关系/权力姿态"是通用底线；"权力动态如何组织成一条爽感链"是女频爱情/权力落差赛道的专属引擎，见 `frameworks/narrative-loop.md` 第八节，本铁律不把它升级为全局。）**
    - **赛道中立正反例**（不锁定任何题材/性别/中外）：

    | ❌ 中性平淡 | ✅ 带情绪 + 关系姿态（示例，非模板） |
    |---|---|
    | A：你找我什么事？ | A 攥着门框，眼睛没敢抬。<br>A：（声音压得低）……您叫我，是我哪里做错了？ |
    | B 坐在桌子后面。 | B 靠进椅背，指尖慢悠悠转着笔，眼皮都没抬。 |
    | A：这份文件我看过了。 | A 把文件推回去，指节压在最后一页上。<br>A：（不轻不重）第三条，你自己再念一遍。 |
    | 两人走进电梯。 | 电梯门合上。A 往角落缩了半步，B 却正好堵在她面前，居高临下看着她。 |

    - **改写口令**：写完每句台词/动作，自问「这句话读得出谁高谁低、谁进谁退、谁在压谁在忍吗？读不出——补一个情绪指向或一个姿态动作，或直接删。」
    - **例外**：纯场次头（`办公室·夜`）与"人物动作和状态描写"行的客观物理状态（`他满身是血，靠墙喘气`）不受本铁律约束——它们本就不承载台词态度。
14. **禁止跨集硬切（v8.1 新增 · 全局 · 治"一集一个剧情,下一集跳到下一时间地点"的阅读断裂）**：每集开头如果切换场景/时间,必须用以下四种方式之一承接上一集末尾——
    - ① **时间锚定句**：本集开头第一句 action 显式承接上集末尾的时间差。如上集末尾"雨夜在医院",本集开头"Six hours later. The rain stopped. Leo's room, morning light."（一句点出"几小时后/次日早晨/三天后"+ 承接上集场景的角色位置）
    - ② **场景延续**：本集开头仍在上一集末尾的同一场景/同一时间,直接接着上文动作往下写,不再重设场次头。如上集末尾"Emma 站在雨里",本集开头直接"Rain still falling. Emma still standing there. Her phone buzzes."——观众读起来是连续画面,不是切镜
    - ③ **角色状态承接**：本集开头第一句承接上一集末尾某个角色的动作/表情/未说完的话。如上集末尾"Leo's eyes fly open. He gasps, once, then goes still.",本集开头"Ethan's hand finds his son's. Cold. Too cold. He shakes him, once."——用角色的下一个动作接续,不用场次头硬切
    - ④ **情节单元边界硬切**：仅当上一情节单元已合集收口 + 本集是下一情节单元的起集时,允许场次头硬切（`INT. NEW SCENE — DAY` 直接开新戏）——因为这是结构上的合理换章,不是阅读断裂
    - **禁止**：场次头硬切（`INT. X — DAY` 直接开新戏,不接上文）,且本集与上集在同一情节单元内（非边界）
    - **判据**：写完本集开头,问自己「这一句是接着上一集末尾写的,还是凭空开了一个新场景?」凭空开新场景=硬切,必须改写
    - **配套**：本铁律与步骤 2.5 逐集节拍表的"承接上集方式"列联动——该列必须填写①②③④之一,写"硬切"必须同时满足④的边界条件
    - **本铁律治的病**：v8.0 实测产物表现为"每集一个独立小事件 + 场次头硬切到下一个时间地点",观众读完上集钩子后,下集开头完全跳脱,阅读体验断裂——这是单集自闭环（R13）的孪生病,必须同治
15. **禁止情节跳跃/beat 密度过载（v8.4 新增 · 全局 · 中英通用 · 治"强情绪场景被压成电报体、剧情跳跃性大"）**：短剧的"快"是**跨集的快**（靠悬念和跨集事件推进），**不是"往一集里塞很多情节点"**。把 5-6 个情节点塞进一集 → 每个点只分到 1-2 句 → 强情绪爆点还没铺开就跳走 = 观众感觉"跳跃性特别大、剧情赶"。**字数预算必须花在"情绪停留"上，不是"情节覆盖"上。**
    - **🔴 单集 beat 密度上限**：一个 1-2 分钟的集，**只承载 1-2 个 beat（情绪节拍），并把它写满**，严禁塞 3 个以上情节点。（beat = 一次情绪单元，如"撞见背叛"是一个 beat，"立赌注"是另一个 beat。）
    - **🔴 强情绪场景的"停留"义务**：凡是强情绪爆点（撞破背叛/被羞辱/生离死别/亮身份/绝境抉择），**必须在这个爆点里"待住"**，用以下手段把它写满，而不是 2 句就跳到下一个情节点——
      - **层层反应**：情绪不是一句到位，是递进的。震惊→不信→质问→崩溃/爆发，每一层给具体的动作+台词，不要一句"Six years."就跳到电话。
      - **对手戏拉扯**：让在场的人各说各的、互相激，把冲突"炒"起来（Sophie 挑衅→Emma 反击→Daniel 甩锅→Emma 再顶回去），一来一回，不是每人只有一句。
      - **微动作外化**：颤抖的手、扶住门框、指甲掐进掌心、慢慢摘下戒指的每一个停顿——这些可拍的细节是"停留"的血肉，把 15 秒的情绪撑成有质感的一场戏。
      - **潜台词与沉默**：一句话说不出口、欲言又止后憋出一句狠话——这些"演得出来"的停顿，比直接跳到下一个情节点更有冲击力（注意：这不是好莱坞式空镜留白，是有明确情绪指向的表演停顿，仍符合铁律13）。
    - **判据（写完每场自问）**：① 这一场我塞了几个情节点？超过 2 个 → 砍到 1-2 个，把砍掉的挪到下一集/下一场。② 这一场最强的那个情绪爆点，我给了它几句？少于 6-8 句（含反应+对手戏+微动作）→ 没写满，回去把它"炒"开。③ 这场戏删掉一半台词，观众还能感受到情绪的层层递进吗？不能 → 说明我写的是骨架不是戏。
    - **与字数红线的关系（关键）**：单集 200-448 词的预算，**要花在"1-2 个 beat 写满"上，不是"5-6 个 beat 各写一句"上**。如果一集自然写出了 4-5 个情节点，不是"字数不够"，是**beat 太多**——砍情节点，别砍情绪停留。宁可一集只讲"撞见背叛"这一个 beat 写到淋漓尽致，把"立赌注/签约"挪到下一集。
    - **与"首集 4-5 场"的关系（修正 v8.3 前的旧规则）**：3-script.md 写作工作流第 8 步"首集 4-5 场"是**上限不是义务**——首集若一个强情绪 beat 值得用 2-3 场写满（如"撞见背叛"这一场就用 200 词铺开），就用 2-3 场，不要为了凑"4-5 场"把情节点摊薄。**场次数服从情绪停留，不是情绪停留服从场次数。**
    - **本铁律治的病**：EP1 实测——"撞见出轨(2句)→怼Sophie(1句)→医院电话立赌注(1句)→Daniel甩锅(1句)→摘戒指走人(1句)"6 个情节点塞进半场戏，最强的"撞见背叛"只有 2 句就跳走，观众感觉剧情跳跃、赶、没有情绪。正确写法：EP1 上半场就"撞见背叛"这**一个 beat**——进门→僵住→颤抖→质问→Sophie 挑衅→Emma 反击→Daniel 冷漠→Emma 情绪崩到顶→摘戒指的每个停顿，写满 150-200 词；医院电话/签约挪到本集下半场或直接 EP2。

## 标准格式

```
场次编号. 场景地点 时间 内外景
人物动作和状态描写。
人物 A：（情绪/动作）台词内容。
人物 B：（情绪/动作）台词内容。
[动作/转换描写]
```

> 🔴 **结尾转场词铁律（v6.9 新增）**：
> - **禁止在每集结尾使用 `CUT TO BLACK.` / `END OF EPISODE X.` / `FADE OUT.` / `淡出` / `切黑` / `第 X 集完` 之类的转场/分集标记**。
> - **这些不是格式要求**。`CUT TO BLACK` 是好莱坞剧本肌肉记忆，`END OF EPISODE X` 是电视分集标记——都不是竖屏短剧的交付物。海外 / DramaBox / 国内等平台的 UI 自己会显示"Episode 1/80"或"第 1 集"，剧本里再写一遍是冗余。
> - **每集固定切黑会变机械感**，反而消解了悬念的冲击力——同一个钩子用 50 次观众就免疫了。
> - **正确收尾**：让最后一行角色**动作/表情/台词**停在最爽的钩子上，**让观众自己滑入下一集**。强收尾靠钩子内容本身（见 `frameworks/hook-design.md`），不靠转场词。
> - **唯一例外**：英文/海外项目若用户明确要求"好莱坞格式/标准剧本格式"且项目是横屏长片（非竖屏短剧），按 `formats/hollywood-script.md` 第 6 节保留转场排版。

## 写作工作流（分批制 · v3.3）

剧本采用**分批生成制**对抗长上下文遗忘：默认单批最多 10 集。每批次走「批次前置注入 → 逐集写作 → 批次审计」三段。

### A. 批次前置注入（每批开写前必做一次）

```
0a. 注入结构宪法：重新载入步骤 2.5 确认的节点表 + 冲突轮换表 + 能力/资源边界总纲 + **情节单元规划表（含"关系副线相位"字段 · v7.2.2 新增）** + **逐集节拍表（v8.1 新增 · 第五件套 · 含"承接上集方式"列 · 治单集自闭环 + 跨集硬切）**
0b. 注入上一批审计结论：上批是否有偏离、遗留伏笔、待回收副线
0c. 注入前情摘要：上一批末尾的人物状态、能力阶段、未解悬念、副线进度 + **上一集末尾的场景/时间/角色状态（用于本集开头的"承接上集方式"列校验）**
0d. 批次级发散（v5.2 新增）：为本批次核心冲突强制分配 3 种不同解路径大类（如：靠信息差解决/靠人脉资源解决/靠对手内部矛盾解决），相邻批次不得连续使用同一解路径大类
```

14.5 **英文/海外项目专项·好莱坞腔扫描（v6.2 / v6.8 强化 · 仅英文海外项目）**：写英文短剧时,额外按 `formats/english-short-drama.md` 第七节自检——分两层：**①定性层（9 项闸门）**逐项扫：是否有 `she felt / he realized / something shifted` 类拍不出的心理旁白；情绪是否外放说出来(不是好莱坞式沉默留白)；台词是否短而狠、信息前置(不是大段内省独白)；反派是否够欠揍(不是被洗白成复杂可怜)；是否拥抱了狗血巧合/强反转(没有被逻辑洁癖删掉)；通读这集像 海外 爆款还是像 HBO 迷你剧——像后者即重写。**②量化层（好莱坞腔量化阈值表 H1-H6）**：逐句机械扫 6 项硬阈值（单句>25词 / Perhaps·Maybe等委婉词 / 隐喻抽象抒情 / she felt等心理旁白 / 情绪靠潜台词不直说 / 连续2句无动作纯氛围段），**命中任一即当场重写**。阈值表定义在 english bible 第七节(唯一真相源),此处只引用不复制。**一票否决:把英文短剧写成美剧 = 不合格**
（漫剧载体额外执行：补写本集「核心分镜提示」三镜，见 formats/manga-drama.md）
