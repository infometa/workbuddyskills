# 人物设计方法（标签化适配+AI通病优化版）

> 执行顺序：在步骤 2.5 核心骨架确认后执行。核心能力/资源边界需与 2.5 确认的总纲保持一致，不得突破。
> 归属主流程：SKILL.md 步骤 3 的人设子任务。

## 命名红线（v6.6 升级为硬约束 · 全局 · 扣分项）

> 模型训练语料里短剧高频人名/标题词的"先验引力"极强，软提示拦不住。以下升级为**硬黑名单 + 扣分项**。

### 人名硬黑名单（中文项目 · 出现即扣分重起）
以下是短剧最高频、几乎成为"默认值"的人名，**禁止使用**（含其明显变体）：
- **女主名黑名单**：苏念念、苏念、苏暖暖、苏婉、陆念念、林晚、沈梦、顾（念念/暖暖）系列
- **男主名黑名单**：陆景琛、陆景深、陆砚（洲/辰）、顾（北/深/沉）、霍（廷/野）、沈（亦/砚）、贺（言/廷）、傅（廷/深）
- **高频姓黑名单（主要角色避免扎堆）**：苏、陆、沈、顾、傅、霍、贺、慕（容）

**命名正面要求**：
1. 主要角色姓氏互不相同，避开上面高频姓
2. 名字避开言情高频字（辰/宸/轩/泽/瑶/汐/瑾/晚/念/暖/砚）
3. 优先选贴合人物背景、有辨识度的名字（参考方向：江、温、裴、卫、谢、薄、闻、宋、程、纪 等中频姓 + 不烂大街的名）
4. **同一会话内多次创作，主角名不得复用**

### 标题词黑名单（全局 · 中英通用）
短剧标题高频套路词，**禁止作为标题主词**（含英文直译）：
- 中文：满分、宠上天、上瘾、甜上天、独宠、专宠、真香、翻车、马甲掉了（已烂大街的）
- 英文（直译泄漏）：`satisfies` / `Satisfaction` / `to the Top` / `Spoils Me` ——尤其 `satisfies` 是"满分"被英文化的典型泄漏，严禁出现
- 标题要求：用**具体钩子/反差/悬念**做标题，不用空泛的程度副词堆砌

> 命名/标题检测纳入步骤 4「硬指标与表达」的命名多样性子项扣分（见 4-review.md）。撞黑名单 = 该子项 0 分并重起名。

## 人物生成逻辑（标签叠加法）
按「受众 > 设定 > 主题 > 背景」优先级，逐层修正人物设定：
1. 受众标签：决定主角视角、核心动机偏向
2. 核心设定标签：决定主角核心人设、金手指、反派标配
3. 主题标签：决定人物弧光方向、核心冲突关系
4. 背景标签：决定人物职业、身份、生活场景

## 人物三件套（严格保留）
每个主要角色至少包含：人物小传 + 人物关系定位 + 人物弧光。

- 出身：

- 次要特质：[补充性格]

【非战力类替代模板（甜宠/种田/年代/悬疑等）】
- 核心优势/资源：
- 初始边界（第1-10集）：能调动的资源、能解决的问题范围
- 核心限制/短板：至少 1 条硬约束（如资金不足、人脉有限、信息差）
- 资源扩张节点1（第XX集，对应关键节点X）：新增资源/能力 + 新增限制
- 资源扩张节点2（第XX集，对应关键节点X）：新增资源/能力 + 新增限制

- 成年关键事件：
- 当下处境：

- 内在需求（need）：[人物自己未必意识到的真正需求，如"被无条件接纳""证明自己值得被爱"]
- 核心目的（这一程到底为了什么）：[贯穿全剧的终极驱动力，是 want 背后的"为什么"。一句话能说清——他/她做这一切，归根结底是为了______]
- 恐惧（fear）：[最害怕失去的东西/最不愿面对的处境]

## 标签化人设校验规则
### 受众校验
- 男频：主角行动力强、话少、核心动机为事业/复仇/守护
- 女频：主角情感细腻、有韧性、核心动机为成长/情感/守护家人
### 设定校验
- 每个核心设定标签，必须在人设中体现对应特征（如重生标签必须有前世记忆痛点）
- 马甲/神医/战神等人设标签，必须有明确的表层身份与里层身份
- **边界校验**：核心能力/资源必须有明确上限与代价，升级/扩张节点必须与节点表对应（新增）
### 主题校验
- 女性成长：女主必须有从依附到独立的完整弧光
- 商战/权谋：主角必须有对应的专业能力与动机
### 背景校验
- 人物职业、身份、生活习惯必须符合对应时代/场景背景
- 避免出现背景与人设违和的设定
### 反派校验（新增）
- 反派能力/资源也需设定边界与上限，不得为凑冲突随意强化
- 反派升级必须有明确的资源/势力来源，不得凭空变强

## 配角立体度强制规则（AI工具人化治理）
### 核心配角三要素（缺一不可）
1. **独立目标**：不依附主角的个人诉求（如攒钱养老、报仇、证明自己）
2. **分层反应**：至少3种不同程度的反应模式，对应不同事件强度
3. **人物弧光**：从开场到结局有明确的认知/立场/能力变化
### 反派非脸谱化规则
> 🔴 **短剧化边界（v6.6 · 全局 · 优先于本节）**：短剧反派的"立体"= **够欠揍 + 诉求清晰 + 能力在线不降智**，**不等于**"给反派可怜前史、被裹挟苦衷、救赎闪回"。后者是电视剧手法（违反 anti-tv-drama R4），会拖慢节奏、削弱打脸爽感。短剧反派要"装到最后一刻、被打脸时崩溃认输"，观众要的是看 ta 被收拾，不是同情 ta。
1. 有清晰的诉求与立场（要什么、为什么挡主角的路），但**不需要洗白式前史**
2. 可以有"在乎的人/软肋"作为主角破局的抓手，但**软肋服务于剧情爆点，不是用来博同情**
3. 反派"高光"= 嚣张到极致/手段狠辣到让观众恨得牙痒，**不是**展现其"格局/无奈/善良的一面"
4. 反派能力必须在线，不能全程降智送人头
5. **禁止**：第X集闪回揭示反派"其实也是受害者/被父辈裹挟"、反派临崩溃前的"自我和解/砸镜子忏悔"——这类一律删除（anti-tv-drama R4）

## 人物关系矩阵
绘制N×N关系矩阵：

|   | 主角 | 反派 | 配角1 | 配角2 |
|---|---|---|---|---|
| 主角 | - | 仇人 | 盟友 | 师徒 |
| 反派 | 仇人 | - | ... | ... |

每个关系填入：
- 关系类型（亲情/爱情/友情/仇敌/合作/背叛）
- 亲疏程度（1-5）
- 起点状态 → 终点状态
- 关键转折场景

## 内部自评闭环（v5.5 · 人物设定 必走）

> 人物设定是全剧地基，直接决定角色能不能立住。生成时走「**内部生成草稿 → 内部自评 → 不达标重写 → 达标再输出**」闭环。**草稿与自评过程是内部工作底稿，绝不展示给用户**——用户只看到达标后的成品。不达标就定向重写、重新自评，循环到全部达标（最多 5 轮）。

### 人物设定自评标准

每条标注「达标/不达标 + 理由」，有任一不达标即重写对应部分：

> **推导提示（多标签时，自评前先做，不展示）**：先用一句话写出 A×B 怎么**共同塑造**了这个人物——主角的哪个身份/动机/困境是两个标签"乘"出来才有的，删掉任一标签就失去这个特质？写不出→说明融梗还没落到人身上，先想通再进入自评。
> 示例：战神×甜宠 → "战神的战力让他能保护女主，但甜宠让他选择隐藏战力甘当小人物——'藏锋'这个核心人设是两个标签共塑的，删掉任一都不成立"。

- [ ] **主角有缺陷**：主角是否有真实的性格缺陷/破绽，而非完美工具？完美无瑕→重写
- [ ] **want 与 need 分离**：外在目标与内在需求是否不同、能制造内心张力？两者雷同→重写
- [ ] **核心目的清晰**：能否一句话说清主角"做这一切归根结底为了什么"？want 背后的"为什么"缺失→补写（v6.1 新增）
- [ ] **stakes 具体可兑现**：主角（尤其非大女主女频女主）是否写明"失败会具体失去什么"？stakes 是抽象的（"失去幸福"）或反派根本无法兑现→重写；非大女主女频缺 stakes→一票否决重写（v6.1 新增）
- [ ] **人设铁律可证伪**：人设铁律是否具体到"遇到 X 绝不做 Y"，能在剧情里被检验？空泛→重写
- [ ] **能力/资源边界封顶**：核心能力/资源是否有量化上限与硬代价，升级节点与关键节点对应？无边界/无代价→重写
- [ ] **反派不脸谱化**：反派是否有自洽动机 + 软肋 + 至少 1 个高光，能力全程在线？降智工具→重写
- [ ] **配角不工具人**：核心配角是否有独立目标 + 分层反应 + 自己的弧光？纯依附主角→重写
- [ ] **融梗落到人身上**（多标签时）：主角的核心选择、核心困境是否由融梗特性共同决定？删掉任意一个主标签，人物动机就不成立→达标；删掉后人设仍成立→融梗没落到人物，重写
- [ ] **命名有记忆点**：是否避开网文高频姓氏与言情高频字、主要角色姓氏有区分度？扎堆→改名

> 全部达标后，才把人物设定成品交付用户。**不要把"改了几版、哪里不达标"告诉用户**——那是你的内部工作。
