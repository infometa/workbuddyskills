# 自审标准（量化评分+AI反模式版 v5.3）

> 归属主流程：SKILL.md 步骤 4。
每一份初稿均按本标准百分制量化打分，输出评级与爆款概率预估，同时包含AI创作通病专项检测。

## 评分总分与权重
总分100分，五大维度加权计算，AI反模式扣分从对应维度中直接扣除：

| 维度 | 分值 | 核心考察 |
|---|---|---|
| 结构与节奏 | 40分 | 卡点、钩子、弹簧节奏、爽点密度、模式重复、长弧单一、节点对齐度、副线推进 |
| 人物与人设 | 20分 | 人设一致性、配角立体度、反派丰满度、性格漂移 |
| 标签与逻辑 | 20分 | 标签匹配度、融梗抽离测试、创意差异化、金手指合规、世界观逻辑硬伤、能力边界合规性 |
| 创意差异化 | 5分 | 核心设定差异化、跨维度创新度 |
| 硬指标与表达 | 15分 | 字数、格式、信息前置、表达重复度 |

## 分项评分细则
### 一、结构与节奏（40分）

| 子项 | 分值 | 评分标准 |
|---|---|---|
| 三付费卡点有效性 | 8分 | 3个卡点均为高潮+强钩子=8分；2个达标=5分；1个达标=2分；0个=0分 |
| 节点对齐度（新增） | 8分 | 核心事件全部命中、集数偏差≤±1集=8分；偏差≤2集=5分；偏差>2集=2分；核心事件缺失=0分 |
| 钩子强度 | 6分 | 每集开篇5秒+结尾10秒双钩子全覆盖=6分；80%覆盖=4分；50%覆盖=2分 |
| 情绪弹簧合理性 | 6分 | 压放交替、无连续3集同类型、曲线阶梯上升=6分；局部问题=3分；整体混乱=1分 |
| 爽点密度 | 6分 | 每5集1个大爽点、每集1个小爽点=6分；密度不足=3分；几乎无爽点=0分 |
| 付费钩密度（v6.6 新增 · 短剧性红线 R6） | — | **扣分项**：付费钩平均>3集/个=严重（结构维度-8，一票否决降级）；前3集无每集爽点=-4。参照 anti-tv-drama.md R6：80-100集需25-35个钩子 |
| 爽点机制多样性（v6.6 新增 · 短剧性红线 R7） | — | **扣分项**：同一爽点机制（KO/亮身份打脸/被压爆发）全剧≥4次=严重（结构维度-8，一票否决降级）；全剧爽点机制<4种=-5。参照 anti-tv-drama.md R7 |

| 短剧性红线（v6.6 新增 · 最高优先级） | — | **专项扣分**：Read anti-tv-drama.md 第四节逐条核——R1分幕/R6付费钩稀/R7爽点复读为一票否决；R2设定过载/R3宏大叙事/R5证据链查案/R8多阵营/R10解释型反转按对应维度扣分 |
| 反模式扣分项 | - | 按互斥规则执行，单问题最高扣10分 |

### 二、人物与人设（20分）

| 子项 | 分值 | 评分标准 |
|---|---|---|
| 主角人设一致性 | 6分 | 全程符合人设铁律、转变有过渡=6分；轻微漂移=4分；明显割裂=2分 |
| 配角立体度 | 6分 | 核心配角有独立目标+弧光+分层反应=6分；部分工具人=3分；全员工具人=0分 |
| 反派丰满度 | 5分 | **短剧标准（v6.6 修正）**：反派够欠揍、有清晰诉求、能力在线不降智=5分；脸谱化降智送人头=3分；**反过来给反派"可怜前史/被裹挟/洗白闪回"使其立体化（电视剧手法，违反 anti-tv-drama R4）=扣分**。短剧反派要"装到最后被打脸认输"，不要"复杂到值得同情" |
| 人物关系合理性 | 3分 | 情感转变有铺垫、关系逻辑自洽=3分；局部突兀=2分；全程生硬=0分 |
| 反模式扣分项 | - | 性格漂移最高扣5分；配角工具人化最高扣5分 |

### 三、标签与逻辑（20分）

| 子项 | 分值 | 评分标准 |
|---|---|---|
| 核心标签爽点命中 | 3分 | 必备桥段100%覆盖、核心爽点打透=3分；80%覆盖=2分；50%覆盖=1分 |
| 融梗抽离测试（v5.4 替代有机度3分） | 3分 | 对多标签组合做抽离测试——删掉标签A后B的核心冲突坍塌=融梗成功=3分；不坍塌但有关键转折是A×B产物=2分；不坍塌且无A×B产物=0分触发反模式12扣分；单标签作品=不适用，3分自动给满分 |
| 创意差异化（v5.0 替代子类型匹配度） | 2分 | 选题与同赛道常见套路有本质区别=2分；有一定差异但不够突出=1分；与常见套路无本质差异=0分 |
| 人物设定符合标签 | 2分 | 主角/反派完全符合标签标配=2分；基本符合=1分；偏差大=0分 |
| 金手指合理性 | 3分 | 有铺垫、有代价、不公式化=3分；部分突兀=2分；强行开挂=0分 |
| 能力边界合规性 | 4分 | 全程未突破上限、升级均对应关键节点、代价全程有效=4分；1次无铺垫升级扣2分；突破终极上限=0分 |
| 世界观逻辑合规 | 3分 | 无时代/战力/制度硬伤=3分；轻微bug=2分；严重逻辑崩坏=0分 |
| 反模式扣分项 | - | 金手指公式化最高扣6分；世界观逻辑硬伤最高扣8分；能力无度膨胀最高扣8分；融梗生硬拼接最高扣6分 |

> **创意差异化评分要点**：① 核心设定（主角身份/核心冲突/爽点机制）是否与同赛道最常见套路有本质不同；② 是否有跨赛道混搭、反常识人设、非常规爽点等创新元素；③ 同一用户同一会话内多次创作同题材时，产出之间是否有至少 2 个维度的差异（主角身份/冲突类型/爽点机制/开局方式/叙事结构）。

### 三点五、创意差异化（5分，独立加分维度 · v5.2 新增）

| 子项 | 分值 | 评分标准 |
|---|---|---|
| 核心设定差异化 | 3分 | 核心爽点触发机制跳出本标签 Top3 经典套路=3分；1-2个维度有微创新但整体仍有套路感=1分；完全沿用经典套路无任何差异化=0分 |
| 跨维度创新度 | 2分 | 实现了标签间的创造性碰撞（如霸总×种田、重生×悬疑）=2分；融入了其他标签的1个元素=1分；纯单标签逻辑=0分 |

> 判定依据：每个标签文件第二节「Top3 经典套路」为固定对照关键节点，核心爽点机制必须跳出该 Top3 才算差异化达标。

## 评级与爆款概率对应

| 总分 | 评级 | 爆款概率预估 | 处理建议 |
|---|---|---|---|
| 90-100分 | S级 | 高（高于大盘平均30%+） | 可直接成稿，优先投产 |
| 80-89分 | A级 | 较高（高于大盘平均10%-30%） | 局部优化后可投产 |
| 60-79分 | B级 | 中等（接近大盘平均） | 需重点修改结构与标签匹配度 |
| 60分以下 | C级 | 低（低于大盘平均） | 建议重写核心框架 |

## 评审注意事项
1. **必须给出具体位置**——不能只说"节奏有问题"，要指出"第12-15集节奏拖沓"
2. **必须给出改进方向**——不能只说问题，要给可执行建议
3. **严重程度分级**——区分必须改 / 建议改 / 可选改
4. **避免泛化评价**——"对白不够好"是无效评价，"第7场反派的台词缺乏威胁感，建议改成简短的暗示性威胁"才是有效

## 多轮评审
如果用户希望对初稿进行多轮深度评审，可分轮次输出：
- 第一轮：结构层（大纲/分集是否成立、标签匹配是否准确、关键节点是否对齐、是否有模式重复）
- 第二轮：人物层（人物动机/弧光/对白是否符合人设、是否工具人化、能力边界是否合规）
- 第三轮：场景层（具体场次的戏剧设计、标签桥段植入、解路径是否重复）
- 第四轮：技术层（字数、格式、节奏曲线、表达重复度、逻辑硬伤）
