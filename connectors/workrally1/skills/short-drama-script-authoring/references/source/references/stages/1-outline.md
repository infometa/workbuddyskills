# 短剧大纲生成方法

> 执行顺序：在步骤 2.5 核心骨架确认后执行。本文件所有关键节点、冲突路径均为 2.5 确认骨架的细化展开，不得推翻核心设定。
> 归属主流程：SKILL.md 步骤 3 的大纲子任务。

## 适用阶段

- 全流程从零写：作为骨架展开阶段，基于 2.5 确认的精简骨架，补充完整字段后输出完整大纲，再走人设、剧本
- 仅大纲：单独输出大纲后即交付步骤 4 评审

## 大纲五层结构（强制层级，不得省略）

短剧大纲按五层输出，**核心关键节点层为步骤 2.5 骨架的细化展开，不得变更核心事件、集数范围与戏剧功能**，不得跳步：

### 第一层：一句话故事（logline）

从 `shared/base.md` 的 Logline 变体模板库中选取句式，**不得与同题材上次产出用同一 T 编号**。子方向选定后，优先匹配与子方向情绪底色最搭的句式。

```
T1 经典式：[处境的主角] 因为 [激励事件]，必须 [追求目标]，但是 [核心障碍]。
T2 反差式：所有人都以为 [主角] 只是 [表面]，直到 [转折]。
T3 时间式：[X年]后 [主角] 回到 [地点]，却发现 [核心冲突]。
T4 悬念式：当 [主角] 发现 [事件] 时，[某事] 是她/他最后的 [倚仗]，却不知道 [暗线]。
T5 反讽式：[角色] 以为 [计划] 就能 [目标]，没想到 [反转]。
T6 倒叙式：谁能想到此刻 [现状] 的 [角色]，曾经 [过去]。
```

**子方向适配指引**：
- 隐忍爆发→T2/T3，治愈偏爱→T5，暗线反转→T4/T6，蛰伏蓄力→T3/T6，智谋设局→T4，错位复仇→T4/T6

### 第二层：故事梗概（300-500 字）

从 `shared/base.md` 的梗概开头变体库中选取叙事切入方式，**不得与同题材上次产出用同一 G 编号**。

```
G1 顺叙式：开场处境→金手指/转折→主要冲突→爽感释放→高潮→结局
G2 悬念倒叙式：从高潮/绝境开场→闪回交代起因→回到现场→走向结局
G3 双线并行式：两条线同时展开→某刻交汇→双重爆发
G4 反讽对比式：先讲"所有人都以为"→逐层揭示真相→反转清零
G5 命运转折式：从"命运的一步"切入→分叉前后对比→新路径展开
```

梗概核心要素（不管哪种切入方式，以下要素必须覆盖）：
- 主角是谁、处于什么困境
- 核心爽点设定（隐藏优势/金手指/逆袭资本）
- 主线冲突与解法方向
- 情绪高潮与结局

### 第三层：全剧核心事件节点表（细化展开版）

基于步骤 2.5 确认的精简关键节点补充完整字段，全剧 **5-12 个**里程碑关键节点（**= 大 loop 数 = 情节单元数，一一对应**；每个关键节点 = 一个大 loop 的**终局反转里程碑，由大 loop 结尾派生**，不独立预设数量；短剧取 5-8 / 80-100集长剧取 10-12，详见 `frameworks/loop-model.md`），固定全剧节奏骨架，后续分集大纲与剧本不得偏离。

**节点表强制字段**：

| 关键节点序号 | 核心事件名称 | 集数范围 | 弹簧类型 | 戏剧功能 | 对应付费点 | 能力变化 | 解路径类型 |
|---|---|---|---|---|---|---|---|
| 1 | | 第1-3集 | | 建置 | 无 | 初始状态 | - |
| 2 | | 第8-10集 | | 第一次小高潮 | 第1付费点 | 无/首次显露 | |
| ... | | | | | | | |
| 12 | | 第75-80集 | | 收尾 | 无 | 终极状态 | - |

**戏剧功能固定选项（不得自定义，强制覆盖全弧光）**：建置 / 激励事件 / 小高潮 / 低谷 / 反转 / 揭秘 / 中期转折 / 第二次高潮 / 终极低谷 / 大高潮 / 收尾

**刚性校验规则**：

0. 🔴 **短剧性红线校验（v6.6 · 全局 · 最先做）**：节点表成型后立即对照 `references/anti-tv-drama.md` 跑"崩坏自查13问"——有没有分幕/设定过载/宏大叙事/反派洗白/证据链查案/付费钩稀疏/爽点机制复读/多阵营/配角抢戏/解释型反转？命中任一先改节点表再往下。
1. 必须覆盖完整情绪弧光，**不得连续 3 个关键节点同为高潮类功能（小高潮/第二次高潮/大高潮）**；
2. 第 10/20/30 集付费点必须对应关键节点，且为「放弹簧 + 强钩子」组合；
3. 全剧必须预埋至少 2 个「意外变量关键节点」（功能：低谷/反转），彻底打破「反派打压→主角打脸」单循环；
4. 能力变化必须与关键节点一一对应，无关键节点不得出现能力升级。

### 第四层：核心冲突路径轮换表（细化展开版）

基于步骤 2.5 确认的精简轮换表补充细节，全剧 8-10 轮核心冲突的解路径提前分配，从根源杜绝模板化循环：

| 冲突轮次 | 对应集数范围 | 冲突类型 | 解路径大类 | 备注 |
|---|---|---|---|---|
| 第1轮 | | | | |
| 第2轮 | | | | 必须与上一轮不同大类 |
| ... | | | | |

**强制规则**：

1. 相邻两轮核心冲突，解路径必须来自《冲突解法变体库》不同大类；
2. 同一种经典解路径（如被动打脸）全剧最多出现 2 次；
3. 至少 1 轮采用「主角失误/暂时失败」的非常规路径，打破爽感单循环。

### 第五层：分集大纲（情节单元 → 单集节拍 · v5.6 新增中间层）

> 🔴 **分集大纲交付规则（v6.6 改 · 全局 · 省上下文）**：**默认成品只输出到"情节单元层"（一个大 loop = 2-8 集，长度不均分的小闭环）**，不再一次性全量铺开 80-100 集的逐集大纲——逐集大纲极占上下文，且大纲期写满逐集反而容易在剧本期被遗忘/漂移。
> - **大纲阶段交付给用户**：一句话故事 + 梗概 + 节点表 + 冲突轮换表 + 情绪曲线 + **情节单元规划表（到"每个大 loop 2-8 集（不均分）+ 单元核心事件 + 节拍分配"为止）**
> - **逐集节拍（每集核心动作/钩子）**：降级为**内部底稿**，只在步骤 3 分批生成正文时，每批开写前临时展开当前 10 集的逐集设计，写完即用、不全量留存
> - **例外**：用户**明确要求**"给我完整分集大纲/每集梗概"时，才全量输出逐集大纲
> - 🔴 **例外只解锁"是否输出逐集"，不解锁"逐集形态"**（v6.7 补 · 全局）：即使全量铺逐集，每集仍必须按节拍归属格式（"属于情节单元 N · 节拍：起/承/转/合" + 1 句话核心动作）。写成"第N集 [独立事件名] + 完整起承转合 + 钩子"的单集自闭环形态 = 反模式 #13 命中（一票否决）。例外解锁的是"是否铺逐集"，不是"是否遵守情节单元铁律"——形态约束在例外下依然全效。
> - 好处：上下文省一大截 + 骨架更聚焦 + 逐集设计紧贴正文生成时刻、不会提前写死又遗忘

| 内容类型 | 输出粒度 |
|---|---|
| 竖屏短剧 | 80-100 集，按"情节单元（2-8 集一个小闭环）→ 单集节拍"两层组织 |

## 分集大纲模板（情节单元 + 单集节拍 · v5.6 重构）

### 情节单元层（先规划跨集闭环）

```
情节单元 N [单元名] · 第 X-Y 集（跨 2-8 集）
- 单元核心事件：[1 句话讲清这个跨集事件]
- 单元节拍分配：
  - 第 X 集 · 起：[事件触发，本集只负责"起"，不要求收口]
  - 第 X+1 集 · 承：[压力升级，只压不放]
  - 第 X+2 集 · 转：[反转/打脸/真相，放弹簧]
  - 第 X+3 集 · 合：[余波 + 下一单元的"起"埋点]（可选，或并入下一单元的"起"）
- 单元内压放分配：如 压-压-放
- 关系副线相位（v7.2.2 新增 · 双线交替铁律）：[本单元结束时,关系副线 推进到哪个相位?选一种 loop 形态:男女主拉扯型/主角+跟班互动型/主角内心自洽型。相位受本单元外冲突节拍影响。例:男女主拉扯型,本单元外冲突是"打脸反派",相位"误解→被迫靠近"。loop 是跨情节单元长线,不是每单元独立闭环]
- 所属关键节点：[关键节点序号]
- 对应付费点：[若有]
```

### 单集层（在情节单元内标注节拍）

> 🔴 **大纲层"单集"≠"一个完整故事"（v6.7 补 · 全局）**：单集条目禁止用独立动作名作标题（如"绝境/交易/登场"这种每集自成一事的命名）——必须显式标"所属情节单元 + 节拍"。单集自闭环形态（第N集 + 完整事件名 + 起承转合 + 钩子、无情节单元归属）即反模式 #13 命中（一票否决），无论大纲是全量铺还是按情节单元铺都适用。

```
第 N 集 [集标题]（属于情节单元 N · 节拍：起/承/转/合）
- 本集在情节单元中的位置：起 / 承 / 转 / 合
- 本集核心动作：[1 句话，只写本集发生的事，不写成完整事件；起/承集只写"压到什么程度"，转集写"怎么放"]
- 弹簧类型：压 / 放 / 压放结合
- 开篇钩子：[5 秒内的冲突/悬念]
- 结尾钩子：[最后 10 秒留什么悬念——起/承集必须是悬念型/危机型，把爽留到转集]
- 对应付费点：[若是付费集，标注是第几个付费点]
- 对应关键节点：[所属核心关键节点序号]
- 融梗交互自问：[若多标签组合，自问：本集有没有A×B共同作用的桥段？没有→只是各演各的，需重构]  ← v5.4 精简
```

> **节拍铁律（v5.6 新增）**：起/承集只负责"压"，**禁止提前完成"转/合"**（即禁止在铺垫集内打脸/反转/收口）——否则就是"一集完成起承转合"。转集才负责"放"。合集收束本单元并埋下一单元的因。

## 必须满足的硬指标

- **每集都有明确情绪功能**——压弹簧或放弹簧，不允许中间状态
- **冲突必须升级**——后一集的冲突/爽点强度 ≥ 前一集
- **付费点位置必须明确**——通常第 10/20/30 集，每个 = 放弹簧高潮 + 更大悬念
- **核心爽点必须在前 3 集预埋**——短剧没时间慢热，开篇即抓人
- **节点对齐强制要求**——分集事件必须严格落在对应关键节点的集数范围内，偏差不得超过 ±2 集
- **遵循所选题材模块的卡点表**——对照 `domestic/combos/{题材}.md` 的"节奏卡点表"（注意按子方向选A版/B版）
- **子方向一致性**——选定子方向后，人物身份、桥段选择、节奏模板必须与该子方向的身份池和桥段池对应，不得跨子方向混搭核心设定

## 内部自评闭环（v5.5 · 一句话故事 + 故事梗概 必走）

> 一句话故事与故事梗概是全剧地基。生成它们时走「**内部生成草稿 → 内部自评 → 不达标重写 → 达标再输出**」闭环。**草稿与自评过程是内部工作底稿，绝不展示给用户**——用户只看到达标后的成品。不达标就定向重写、重新自评，循环到全部达标（最多 5 轮）。

### 一句话故事（logline）自评标准

每条标注「达标/不达标 + 理由」，有任一不达标即重写：

> **推导提示（多标签时，自评前先做，不展示）**：直接复用步骤 2 用户已确认的「融梗一句话」作为自评基准——用户已确认了 A×B 的新叙事特性，不需要重新推导。仅在用户未确认或融梗方向已调整时，才重新写这句话。
> 示例：重生×种田 → "重生者知道未来但种田需要慢周期，'知道三年后粮价暴涨却得先熬过眼前的穷'——这种'先知与慢钱'的拉扯是单独没有的"。

- [ ] **5 秒抓人**：一句话里有没有立刻勾起好奇的强信息（身份反差/激励事件/悬念）？平淡无钩→重写
- [ ] **冲突清晰**：主角追求的目标与核心障碍是否一句话说清？模糊→重写
- [ ] **融梗三问**（多标签时）：删掉 A 后 B 崩不崩？转折有没有 A×B 产物？三问任一不过→重写
- [ ] **非套路**：是否跳出同标签组合的烂大街句式（如复仇=隐忍爆发、战神=兵王归来）？雷同→换方向重写
- [ ] **配方差异化**（若 Read 了配方）：本方案的核心冲突、主角动机与参考配方是否存在本质差异？照搬配方方向→重写
- [ ] **句式不雷同**：T 编号是否与同题材上次产出不同？重复→换句式

### 故事梗概（300-500 字）自评标准

- [ ] **四要素齐全**：主角与困境 / 核心爽点设定 / 主线冲突与解法 / 情绪高潮与结局，缺一→补写
- [ ] **爽点前置**：核心爽点是否在开篇段落就预埋？慢热→重写
- [ ] **融梗有机**（多标签时）：梗概里的主线冲突是不是 A×B 共同作用的产物，而非"先讲 A 的事再讲 B 的事"？物理拼接→重写
- [ ] **情绪曲线有起伏**：是否有明确的压—放节奏，而非平推？平推→重写
- [ ] **结局有钩子/反转**：结尾是否落在有记忆点的高潮或反转上？平淡收尾→重写
- [ ] **切入方式不雷同**：G 编号是否与同题材上次产出不同？重复→换切入

> 全部达标后，才把一句话故事与梗概成品交付用户。**不要把"我改了几版、哪里不达标"告诉用户**——那是你的内部工作。

## 输出格式

> 🔴 **交付洁净度铁律（全局 · 一票否决）**：交付给用户的 logline 和 synopsis 是**给观众/制片看的干净文本**，严禁夹带任何内部标注——
> - ❌ 禁止句式/结构编号：`(T4 悬念式)` `(T4 Suspense Style)` `(G5 命运转折式)` `(G5 Fate's Turning Point Style)`
> - ❌ 禁止任何"风格说明/叙事手法说明"后缀
> - ✅ logline 就是一句干净的话；synopsis 就是一段干净的梗概，读起来像正式企划案，不像内部工作表
> 编号是你内部选模板用的，选完即丢，**绝不出现在交付文本里**。

```
# [作品名] 短剧大纲

## 一句话故事
...

## 故事梗概
...

## 核心事件节点表（细化版）
[10-12 行表格]

## 核心冲突路径轮换表（细化版）
[8-10 行表格]

## 情绪曲线规划
[标出每 5-10 集的情绪值与压/放类型，付费点位置]

## 融梗方向说明（v5.4 精简 · 多标签时必填）
- 融梗一句话：[这个组合产生了什么两个标签单独都没有的新东西？]
- 融梗核心冲突：[由融梗产生的新冲突/新困境]
> 单标签作品填"不适用"。不需要填反应式模板、招牌桥段分布等——想清楚一句话和核心冲突即可。

## 情节单元规划表
[全剧 **5-12 个**情节单元（**= 大 loop，与关键节点一一对应**；数量由故事状态跃迁点决定=反派阵营数/身份跃迁数/权力倒置次数，**非集数除法**），每个跨 **2-8 集、长度按剧情松紧不均分**（重头戏弧 6-8 集、过场弧 2-3 集）：单元序号 + 集数范围 + 单元核心事件 + 所属关键节点(=本单元终局反转) + 节拍分配 + **关系副线相位**(v7.2.2 新增,双线交替铁律,详见 `frameworks/emotion-spring.md` 「情节单元双线交替结构」段) + **逐集节拍表**(v8.1 新增,第五件套,含"承接上集方式"列)。**密度靠承段小 loop（跨2-3集攻防回合）+ 逐集节拍表承接，不靠多切情节单元**；情节单元规划表到此为止不再全量铺逐集,但逐集节拍表必须全量铺到每集]

## 核心爽点清单
[本剧的主要爽点 + 对应集数 + 爽点机制类型（核对：全剧≥4种不同机制，同机制≤3次）]
```

> **逐集大纲不在大纲成品里**（v6.6）：逐集的每集核心动作/钩子在步骤 3 分批写正文时再展开为内部底稿。仅当用户明确要"完整分集大纲"时，才在此处追加 `## 分集大纲 [80-100集逐集]`。
