## 创作方向指引（v5.2 重构）

> 马甲是短剧核心爽感主题，同质化严重。以下不提供"选一个方向"的选项，而是提供**差异化思考框架**，帮你跳出经典套路。

### 核心公式
多重隐藏身份 → 逐层揭露 → 每揭一层震撼一次

**爽感公式**：爽感 = 马甲数量 × 反差强度 × 马甲揭露方式的意外性

### 高频套路提示（非禁用，但需差异化翻转）
以下路径在同题材作品中出现频率极高，你可以使用，但必须至少在 1 个核心维度做本质翻转：
1. **有人质疑主角某领域→主角正是该领域顶尖** → 翻转：质疑→证明的方式可以不是直接展示实力，而是更曲折的路径
2. **"别人不知、观众知道"的信息差名场面** → 翻转：信息差可以不是观众全知，而是更复杂的视角设计
3. **反派炫耀某身份→被主角更高马甲碾压** → 翻转：碾压可以不是更高马甲，而是更意想不到的维度
4. **终极马甲压轴揭晓（最显赫身份）** → 翻转：压轴可以不是最显赫身份，而是最意想不到的身份

### Top3 经典套路（差异化检测对照关键节点 · v5.2 新增）
> 步骤 4 创意差异化评分时，核心爽点机制必须跳出以下 3 种，才算差异化达标。
1. 多重马甲连爆型：被低估→揭第一个马甲→逐层揭露→终极马甲压轴→全场震撼
2. 扮猪吃虎型：极度低调→被全方位轻视→一个契机被迫露真容→反差炸裂→碾压全场
3. 马甲情缘型：隐藏身份接近→真心相爱→身份险些暴露的拉扯→揭晓→爱的考验通过

### 创作思考步骤（按此流程推导，不套用现成套路）
1. 先确定你想卖的「爽感亚型」——除了上述 Top3 之外的任何方式
2. 回答三个关键问题：① 隐藏身份的动机？（动机翻转）② 什么触发了揭露？（触发翻转）③ 震撼如何实现？（方式翻转）
3. 三个回答中至少有一个不在 Top3 套路中
4. 检验：把你的核心设定发到短剧社群，观众会说"这种马甲我没见过"吗？
5. 确认翻转后仍能交付该题材的情绪内核

## 人物配置（差异化）

| 角色 | 本题材特殊要求 |
|---|---|
| 主角 | **多个叠加马甲**（既是神医，又是首富，又是黑客之王，又是隐世家族继承人……） |
| 多组不知情的人 | 每组对应一个马甲的揭露场景 |
| 踩雷反派/配角 | 质疑主角某领域，结果主角正是该领域顶端 |
| 专属见证人 | 每个马甲揭露都要有人目睹崩溃 |

与相邻题材区别：
- vs 复仇：马甲是复仇的"加强版"，把单一隐藏身份扩展成多重连爆
- vs 战神：战神是单一军方身份，马甲是跨领域多重身份

## 节奏卡点表（80 集模板 · 按 A/B 两版）

### A 版（高密度小循环，适配多重马甲连爆/其他创新方向）

| 集数 | 事件 | 弹簧类型 |
|---|---|---|
| 1 | 主角被低估（钩子） | 压 |
| 5 | 揭第一个马甲（最小的） | 放（小） |
| 10 | 付费点 1：揭第二个马甲 | 放 |
| 20 | 付费点 2：揭第三个马甲 | 放 |
| 30 | 付费点 3：揭核心大马甲 | 放（极） |
| 40-70 | 各马甲叠加发酵 + 群众反复被震撼 | 放为主 |
| 75-80 | 终极马甲（全剧最强反差）揭晓 | 放（顶） |

节奏特征：**高密度小循环**。几乎每 2-3 集揭一个马甲/打一个脸，单元性极强。

### B 版（蓄势爆发/情感节奏，适配扮猪吃虎/马甲情缘）

| 集数 | 事件 | 弹簧类型 |
|---|---|---|
| 1 | 主角低调入场+被轻视/隐藏身份相遇 | 压/放（小） |
| 5-10 | 铺垫伏笔/感情升温（暗藏身份张力） | 压+悬念 |
| 15-20 | 付费点 1-2：小范围露锋芒/身份险暴露 | 压→放 |
| 30 | 付费点 3：核心身份炸裂揭晓/感情大考 | 放（极） |
| 40-65 | 反差余波/爱的考验与重建 | 压放交替 |
| 70-80 | 全面碾压圆满/身份与真心两全 | 放→平稳 |

节奏特征：**扮猪吃虎蓄势一击，马甲情缘情感拉扯**。比 A 版揭露更集中、铺垫更长。

## 必备桥段清单（每部至少命中 5 个）

- [ ] 有人质疑主角某领域 → 主角正是该领域顶尖
- [ ] "别人不知道、观众知道"的信息差名场面
- [ ] 不同人群各自震惊于不同马甲
- [ ] 反派炫耀某身份 → 被主角更高马甲碾压
- [ ] 马甲之间产生奇妙联动（多个身份同时被需要）
- [ ] 专属见证人目睹身份崩塌
- [ ] 终极马甲压轴揭晓（最显赫身份）

## 差异化着重注意点（v5.2 更新）

1. 管理好**揭露顺序**——由小到大，越揭越炸，最后一个必须是全剧最强反差
2. 每个马甲都要有**专属见证人**目睹崩溃
3. 核心快感是"**上帝视角看群众被震撼**"的信息差
4. **核心设定必须跳出 Top3 套路**——你不需要选一个方向，你需要创造一个新方向
5. **马甲揭露方式的差异化是最大的差异化**——同样卖马甲，"怎么揭露"比"揭露什么"更决定观众记忆点

## 避坑清单

- 马甲太多记不住 → 控制在 3-5 个核心马甲
- 揭露顺序混乱（高潮前置）→ 后续乏力
- 马甲之间逻辑矛盾（首富+隐世家族+战神不自洽）→ 设定崩
- 没有见证人 → 反差无处释放
- 核心设定完全复刻 Top3 套路（多重马甲连爆/扮猪吃虎/马甲情缘）→ 创意差异化不达标
