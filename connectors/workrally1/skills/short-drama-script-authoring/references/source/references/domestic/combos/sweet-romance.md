## 创作方向指引（v5.2 重构）

> 甜宠是女频核心爽感主题，同质化严重。以下不提供"选一个方向"的选项，而是提供**差异化思考框架**，帮你跳出经典套路。

### 核心公式
身份悬殊 → 靠近契机 → 情感拉扯 → 极致宠爱

**爽感公式**：爽感 = 男主地位高度 × 宠溺排他性 × 心动方式的意外性

### 高频套路提示（非禁用，但需差异化翻转）
以下路径在同题材作品中出现频率极高，你可以使用，但必须至少在 1 个核心维度做本质翻转：
1. **契约/替嫁/救命恩情强制绑定同居** → 翻转：靠近的契机可以不是强制绑定，而是自主选择或偶然交错
2. **对外冷若冰霜只对她温柔的反差** → 翻转：反差可以不是"冷热切换"，而是更复杂的双面性或渐进转变
3. **她受伤他失控发怒暴露在乎** → 翻转：在乎的暴露方式可以不是暴怒，而是更微妙的细节
4. **公开宣示主权/霸气护短** → 翻转：独宠的证明可以不是当众宣示，而是私密中的极致偏爱

### Top3 经典套路（差异化检测对照关键节点 · v5.2 新增）
> 步骤 4 创意差异化评分时，核心爽点机制必须跳出以下 3 种，才算差异化达标。
1. 强宠占有型：霸道总裁强势入侵女主生活→女主抗拒→沦陷→极致独宠
2. 治愈偏爱型：双方各有伤痕→被迫靠近→看见对方脆弱→相互治愈→极致偏爱
3. 亏欠追妻型：深度误会/偏心→女主受伤离开→男主觉醒真相→追悔+加倍独宠

### 创作思考步骤（按此流程推导，不套用现成套路）
1. 先确定你想卖的「爽感亚型」——除了上述 Top3 之外的任何方式
2. 回答三个关键问题：① 核心冲突的动机？（动机翻转）② 什么触发了靠近？（触发翻转）③ 宠爱如何交付？（方式翻转）
3. 三个回答中至少有一个不在 Top3 套路中
4. 检验：把你的核心设定发到短剧社群，观众会说"这种甜宠我没见过"吗？
5. 确认翻转后仍能交付该题材的情绪内核

## 差异化着重注意点（v5.2 更新）

1. 爽是**情感代偿**不是智力碾压，宠的方式要**具体可视**（包场、护短、无条件信任）
2. 男主的宠要有**排他性**——独宠才有供养感，雨露均沾立刻崩盘
3. 女主要"普通但有闪光点"，太完美则代入感差
4. **核心设定必须跳出 Top3 套路**——你不需要选一个方向，你需要创造一个新方向
5. **心动方式的差异化是最大的差异化**——同样卖甜宠，"怎么心动"比"为什么心动"更决定观众记忆点

## 避坑清单

- 女主恋爱脑无脑 → 招女性观众反感
- 男主油腻强势 → 变骚扰非宠爱
- 虐过头 → 甜宠核心是甜，虐只是调料
- 男主花心暧昧 → 供养感崩盘
- 核心设定完全复刻 Top3 套路（强宠占有/治愈偏爱/亏欠追妻）→ 创意差异化不达标
