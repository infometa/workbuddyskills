## 二、创作框架（替代变体素材库 · v5.2）

### 情绪内核（必须交付）
观众看玄幻仙侠，要的是「修炼越级的碾压征服感」——不管你用什么方式讲这个故事，以下内核必须达成：
1. **境界碾压的台阶感**：修炼有清晰层级，每次突破必须有过程与代价，越级碾压靠机缘+领悟而非金手指躺赢，让观众感到"一步步强起来"的踏实
2. **世界观的沉浸质感**：修炼体系自洽、世界有纵深，不止于升级数字，观众要"信这个世界"

### 高频套路提示（非禁用，但需差异化翻转）
以下路径在同标签作品中出现频率极高，你可以使用，但必须至少在 1 个核心维度做本质翻转（翻转修炼动机/翻转碾压方式/翻转世界观形态，不是只换表面形式）：
1. 陨落强者重修归来→带经验越级碾压 → 高频有效，翻转例：重修者的经验反而是枷锁，新世界的规则与旧经验冲突，他必须"忘掉"才能突破
2. 天赋异禀一日千里→同侪震惊 → 高频，翻转例：主角并非天赋异禀，而是靠"悟"出别人不敢走的路，碾压来自认知差异而非天赋碾压
3. 宗门斗争→夺取资源→越级打脸 → 高频，翻转例：斗争不围绕资源，而围绕"修炼理念的根本分歧"——两条路之争
4. 机缘秘境获宝→实力暴涨 → 高频，翻转例：秘境不是获宝之地而是试炼之境，得到的不是力量而是代价，真正的突破在付出之后

### Top3 经典套路（差异化检测对照关键节点 · v5.2 新增）
> 步骤 4 创意差异化评分时，核心爽点机制必须跳出以下 3 种，才算差异化达标。
1. 逆天奇才型：天赋逆天→入门即碾压→机缘连连→越级无敌
2. 重修归来型：陨落强者→重修碾压→经验碾压→重回巅峰
3. 苦修顿悟型：资质平凡→苦修积累→绝境顿悟→一举突破反超

### 创作思考步骤（按此流程推导，不套用现成套路）
1. 先确定你想卖的「爽感亚型」——除了上述 Top3 之外的任何方式
2. 构想一个能交付情绪内核但不在 Top3 中的具体场景
3. 检验：这个场景如果发到短剧社群，观众会说"这种仙侠我没见过"吗？
4. 如果不会，回到步骤 1，翻转一个核心特质再试（翻转修炼动机/翻转碾压实现方式/翻转世界观设定）
5. 确认翻转后的设定仍能交付「境界碾压台阶感+世界观沉浸质感」两个内核

### 钩子参考（仅启发）
- 开篇钩子参考：主角身处修炼世界底层，因一桩机缘命运齿轮开始转动
- 集末钩子参考：突破式/机缘式/强敌式——具体台词按剧情原创

## 五、红线与反模式
> 红线severity：弱

### 1. 避坑提示（不挂质检号、不扣分，仅创作提醒）
1. 避免修炼体系混乱、境界模糊、战力忽高忽低，台阶感缺失。
2. 避免升级过快、一路躺赢，缺乏瓶颈与代价。
3. 避免世界观空洞，只有升级数字、没有沉浸质感。
4. 避免全靠金手指、无感悟，主角成长缺乏内在驱动。

### 2. AI通病专项检测（弱红线级别·创作提醒，不独立扣分）

## 七、融梗亲和性（v5.3 新增）

### 增强型
- **重生** → fusion/recipes/fantasy-rebirth.md：重生记忆为修炼提供"已知大道方向"的先知优势，让越级突破有了机缘关键节点，但需让旧经验与新世界规则碰撞，避免躺赢，境界台阶感与逆天改命双重强化。
- **系统** → fusion/recipes/system-counterattack.md：系统把修炼层级转为可视化数值与任务进度，让"一步步强起来"的踏实感落地，越级碾压有了清晰的阶段目标与即时反馈。
- **战神归来**：陨落强者重修归来，旧日巅峰经验加速境界跃升，身份反差与境界碾压叠加，碾压来得更有宿命张力。

### 对冲型
- 无（玄幻仙侠的情绪内核偏正向升级燃感，不与其他标签产生情绪对冲）

### 裂变型
