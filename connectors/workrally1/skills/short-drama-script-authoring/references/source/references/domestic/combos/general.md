# 通用兜底

> **国内标签组合**（平台路由标识 · v6.0）
> - **说明**：完全识别不了的创意走通用框架
> - **命中规则**：步骤 0 推断出标签组合未命中任何预设 → Read 本文件作兜底参考

当用户的短剧需求**无法归入 12 个题材**（题材冷门、混合无主类、全新创意）时，使用本模块。本模块只提供**短剧通用创作框架**，不含特定题材的爆款公式。

## 触发条件

- 步骤 0 题材识别后，确认不属于：复仇/逆袭/霸总甜宠/大女主/战神/马甲/重生/豪门认亲/古装玄幻/狼人/先婚后爱/追妻火葬场
- 或多题材混合且无明显主题材
- 或用户主动要求"不要套路、做点新的"

**注意**：先尽力归类。只有确实无法归入任一类时才用兜底。归类不确定时优先提问用户。

## 创作方向指引（v5.2 重构）

> 通用兜底不等于没有方向。以下提供**差异化思考框架**，帮你在无题材公式的情况下跳出短剧最常见的经典套路。

### 核心公式
核心情绪确立 → 冲突建立 → 弹簧压放 → 碾压/反转实现 → 余波收束

**爽感公式**：爽感 = 情绪精准度 × 冲突烈度 × 反转实现方式的意外性

### 高频套路提示（非禁用，但需差异化翻转）
以下路径在短剧中出现频率极高，你可以使用，但必须至少在 1 个核心维度做本质翻转：
1. **开篇被欺压 → 获得金手指 → 翻身** → 翻转：金手指本身有代价/限制，不是免费午餐
2. **误会推动剧情 → 最后和解** → 翻转：误会不解开，变成真正的分歧与成长
3. **阶段性反派 → 逐级升级 → 碾压终极 boss** → 翻转：最大对手是主角自己/制度/认知局限
4. **旁观者震惊 → 打脸** → 翻转：不需要旁观者认可，主角追求自我实现

### Top3 经典套路（差异化检测对照关键节点 · v5.2 新增）
> 步骤 4 创意差异化评分时，核心爽点机制必须跳出以下 3 种，才算差异化达标。
1. 低位逆袭打脸型：低位开局→被欺压→获得力量/资源→碾压→打脸质疑者
2. 误会甜宠型：冲突/误会→逐渐靠近→真相揭露→双向奔赴
3. 隐忍复仇型：被害→蛰伏→布局→反杀→真相揭露

### 创作思考步骤（按此流程推导，不套用现成套路）
1. 先确定你想卖的「爽感亚型」——除了上述 Top3 之外的任何方式
2. 回答三个关键问题：① 核心冲突的动机？（动机翻转）② 什么触发了转变？（触发翻转）③ 高潮如何实现？（方式翻转）
3. 三个回答中至少有一个不在 Top3 套路中
4. 检验：把你的核心设定发到短剧社群，观众会说"这种短剧我没见过"吗？
5. 确认翻转后仍能交付该题材的情绪内核

## 通用短剧创作框架

### 第一步：提炼核心情绪

任何短剧都要先明确"卖什么情绪"。常见情绪类型：

| 情绪 | 满足的心理需求 |
|---|---|
| 解气/爽 | 不公被纠正 |
| 甜/宠 | 被爱被重视 |
| 虐/泪 | 情感宣泄 |
| 燃/热血 | 自我激励 |
| 悬疑/好奇 | 探索欲 |
| 治愈/共鸣 | 情感慰藉 |

先和用户确认这部剧的**主导情绪**，它决定整体节奏。

### 第二步：套用情绪弹簧通用结构

无论什么题材，短剧都遵循"压弹簧/放弹簧"（详见 `frameworks/emotion-spring.md`）：

- 确定每集是压还是放
- 设计全剧情绪曲线（每 5-10 集一个高潮）
- 付费点 = 放弹簧高潮 + 更大悬念

### 第三步：搭建通用人物框架

| 角色 | 职能 |
|---|---|
| 主角 | 承载观众代入与情绪释放 |
| 核心阻力（反派/困境） | 制造压弹簧 |
| 见证人 | 放大情绪释放 |
| 助力者 | 推动关键反转 |

### 第四步：通用卡点模板（80 集）

| 集数 | 功能 | 弹簧 |
|---|---|---|
| 1 | 强钩子开场，建立核心冲突/悬念 | 压/放 |
| 10 | 付费点 1：第一次情绪高潮 | 放 + 悬念 |
| 20 | 付费点 2：冲突升级/危机 | 压→放 |
| 30 | 付费点 3：重大转折/反转 | 放（极） |
| 40-70 | 冲突持续升级 + 反复 | 压放交替 |
| 75-80 | 收束圆满 | 平稳 |

### 第五步：通用必备要素

- [ ] 开篇 5 秒强钩子
- [ ] 每集明确压/放
- [ ] 信息前置（第一句台词抛冲突）
- [ ] 动作可视化
- [ ] 每集结尾再钩子
- [ ] 冲突逐步升级
- [ ] 付费点对应情绪高潮

## 创作中的注意（v5.2 更新）

1. 即使无成熟套路，也要保证"**每集一个情绪点**"的短剧基本节奏
2. 没有题材爆款公式时，更要靠**创意新鲜感**和**情绪精准度**取胜
3. 完成初稿后，若发现其实接近某个题材，可回头读对应题材模块补强
4. **核心设定必须跳出 Top3 通用套路**——通用兜底不代表套用经典款，而是创造新方向

## 反哺建议

如果某类"兜底"需求反复出现（用户多次要做某种新题材），建议：

1. 为它新建专属标签组合模块
2. 在 `domestic/INDEX.md` 登记
3. 让兜底逐步沉淀为正式题材
