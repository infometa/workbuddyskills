## 创作方向指引（v5.2 重构）

> 打脸虐渣是短剧第一爽感赛道，同质化严重。以下不提供"选一个方向"的选项，而是提供**差异化思考框架**，帮你跳出经典套路。

### 核心公式
极致压抑 → 实力反差 → 当众碾压 → 第三方见证

**爽感公式**：爽感 = 压抑深度 × 释放速度 × 打脸实现方式的意外性

### 高频套路提示（非禁用，但需差异化翻转）
以下路径在同题材作品中出现频率极高，你可以使用，但必须至少在 1 个核心维度做本质翻转：
1. **装穷/装弱被嘲笑→被关键人物认出** → 翻转：身份暴露可以不是被认出，而是主角自选时机
2. **反派当众宣判主角"完了"→大佬集体支持主角** → 翻转：反转可以不是大佬集体站队，而是更出人意料的碾压方式
3. **反派对主角动手→主角随手化解** → 翻转：碾压可以不是随手化解，而是精心设计的回击
4. **前任/对手炫耀→主角带更强实力/配偶出现** → 翻转：打脸可以不是带更强配置出现，而是更高级的降维打击

### Top3 经典套路（差异化检测对照关键节点 · v5.2 新增）
> 步骤 4 创意差异化评分时，核心爽点机制必须跳出以下 3 种，才算差异化达标。
1. 隐藏身份碾压型：极致压抑→隐忍不发→身份/实力曝光→见证人崩溃→反派社死
2. 智谋设局型：被算计→看穿布局→将计就计→引诱反派入局→反派自食恶果
3. 蛰伏蓄力型：被毁掉一切→谷底求生→蛰伏蓄力→一砖一瓦重建→用自己的实力碾压

### 创作思考步骤（按此流程推导，不套用现成套路）
1. 先确定你想卖的「爽感亚型」——除了上述 Top3 之外的任何方式
2. 回答三个关键问题：① 压抑的动机？（动机翻转）② 什么触发了反转？（触发翻转）③ 碾压如何实现？（方式翻转）
3. 三个回答中至少有一个不在 Top3 套路中
4. 检验：把你的核心设定发到短剧社群，观众会说"这种打脸我没见过"吗？
5. 确认翻转后仍能交付该题材的情绪内核

## 节奏卡点表（80 集模板 · 按 A/B 两版）

### A 版（忍-爆节奏，适配隐藏身份碾压/蛰伏蓄力）

| 集数 | 事件 | 弹簧类型 |
|---|---|---|
| 1 | 主角被极度羞辱（开篇钩子拉满） | 压 |
| 5 | 第一次小反击（轻微露能力） | 放（小） |
| 10 | 付费点 1：身份初次暴露给一个见证人 | 放（中）+ 大悬念 |
| 20 | 付费点 2：核心反派对主角下狠手 | 压（极） |
| 25-30 | 付费点 3：身份大公开 + 第一次大规模打脸 | 放（极） |
| 40-50 | 反派绝地反扑，主角看似失败 | 压 |
| 60-70 | 终极反转，反派彻底崩溃 | 放 |
| 75-80 | 余波处理 + 圆满结局 | 平稳 |

### B 版（渐进/反转节奏，适配智谋设局/错位复仇）

| 集数 | 事件 | 弹簧类型 |
|---|---|---|
| 1 | 主角被算计/被害（痛点开场） | 压 |
| 5 | 看穿布局/发现线索 | 放（小） |
| 10 | 付费点 1：第一次反击成功（但只是第一步） | 放 |
| 15-20 | 设局/复仇推进 | 压放交替 |
| 25-30 | 付费点 2-3：对A的清算/真相浮出 | 放→压（反转） |
| 35-55 | 新阶段博弈（对付更深层/发现真凶） | 压 |
| 60-75 | 终极清算 | 放 |
| 75-80 | 余波 + 圆满 | 平稳 |

**节奏特征**：**低频大爆**（A 版）/ **阶梯式推进+反转**（B 版）。A 版前置压抑最重，打脸分段释放；B 版步步为营，每一步都有策略快感。

## 目标市场与语言

- 主力市场：国内。
- **海外慎用本套路**：欧美观众更吃"前任后悔追妻"而非"女主带新欢打脸"。面向海外时改走 `win-back.md`。
- **差异化方向市场适配**：隐藏身份碾压型国内核心；智谋设局型权谋/商战受众；蛰伏蓄力型逆袭共鸣（可海外）。

## 人物配置（通用框架）

| 角色 | 本题材特殊要求 |
|---|---|
| 主角 | 必须**双层身份**或**深层能力**或**执着信念**。具体身份按创意方向自由设计，不受预设池限制 |
| 核心反派 | **蠢且嚣张**（经典型）/ **狡猾且强大**（智谋型）/ **多层级**（蓄力型） |
| 见证人 | **命脉角色**。目睹打脸全过程。无见证人爽感打 5 折 |
| 助力者 | 揭穿主角真实身份/协助设局/在关键时刻站出来的"工具人" |

与相邻题材区别：
- vs 战神：复仇靠**商业/智力**碾压，战神靠**武力**碾压
- vs 重生：复仇靠**当下实力**翻盘，重生靠**未来信息**预判
- vs 马甲：复仇是单一隐藏身份，马甲是多重身份连爆

## 差异化着重注意点（v5.2 更新）

1. 前期不公必须"**合理且具体**"（有动机，不是无脑欺负），否则观众觉得假
2. 打脸后反派反应要**身体化**：腿软、瘫坐、喷饭、后退打翻东西——禁止长篇忏悔台词
3. 每次反派反扑要被打得**更惨**，形成递进
4. **核心设定必须跳出 Top3 套路**——你不需要选一个方向，你需要创造一个新方向
5. **打脸实现方式的差异化是最大的差异化**——同样卖打脸，"怎么打脸"比"为什么打脸"更决定观众记忆点

## 避坑清单

- 打脸过早（第 3 集揭身份）→ 后续无爽点可写
- 反派无脑（一开始就明显智障）→ 观众不解恨反觉假
- 主角全程开挂（无被压制过程）→ 无共情
- 打脸后台词冗长 → 节奏崩溃
- 见证人缺失 → 爽感打折
- 核心设定完全复刻 Top3 套路（隐藏身份碾压/智谋设局/蛰伏蓄力）→ 创意差异化不达标
