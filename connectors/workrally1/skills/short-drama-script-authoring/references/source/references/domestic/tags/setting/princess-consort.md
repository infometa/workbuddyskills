## 二、变体素材库（仅参考·可自由组合·可原创·可豁免）
> 本节全部为灵感启发，**不强制命中、不作评分依据**，可自由组合/原创/豁免。

### 1. 节奏适配逻辑
常见节奏：入府受压 → 宅斗破局 → 立威固宠 → 执掌中馈。付费节点可落在入府立威、识破阴谋、当众打脸、固宠高光等处——仅为参考。

### 2. 核心变体素材（任选，不限数量）
#### 宅斗爽点变体
1. 智斗破局型：用心计识破后宅算计，反将一军
2. 立威打脸型：被侧妃/管事刁难，当众反转打脸
3. 当家理事型：执掌中馈井井有条，以能力服众
4. 隐藏身手型：王妃身负医术/武艺/才学，关键时刻惊艳

#### 冲突模式变体
1. 侧妃争宠型：后宅女眷构陷，王妃见招拆招
2. 长辈刁难型：王府长辈不认可，立规矩下马威
3. 母族博弈型：娘家与王府势力角力，王妃周旋
4. 夺嫡牵连型：卷入王爷夺位之争，并肩破局

#### 人设风格变体
1. 清冷智谋型：表面温婉，暗藏锋芒与心计
2. 飒爽硬气型：不忍气吞声，有仇当场就报
3. 才女型：以才学治家，气度不凡
4. 双强王妃型：与王爷并肩，而非依附后宅

#### 付费卡点变体
1. 立威节点：入府初次反击，震慑后宅
2. 打脸节点：识破构陷，当众反转打脸
3. 固宠节点：以能力与魅力稳固地位的高光

### 3. 钩子参考模板
- 开篇钩子参考：女主入王府即遭排挤刁难，埋下宅斗破局、立威固宠的预期
- 集末钩子参考（仅启发）：
  1. 立威式：这王府的水再深，也淹不死她
  2. 打脸式：想算计她的人，没一个有好下场
  3. 悬念式：她藏起来的本事，马上要让满府刮目相看

## 三、人设加成参考
1. 女主：从入府新人成长为执掌中馈的王妃；有智谋有能力，宅斗靠脑子不靠王爷代劳。
2. 王爷：女主的盟友/后盾，并肩而非全程拯救；专一不花心。
3. 对照组：争宠侧妃、刁难长辈、构陷管事，反衬王妃的智谋与格局。
> 仅为方向参考，具体设定可自由发挥。

## 五、红线与反模式
> 红线severity：弱

### 1. 避坑提示（不挂质检号、不扣分，仅创作提醒）
1. 避免宅斗降智，算计幼稚、破局靠巧合，斗争失去看点。
2. 避免全靠王爷出面摆平一切，女主沦为被宠的花瓶，丢失成长。
3. 避免王爷花心、后宅雨露均沾，破坏专一与爽感。
4. 避免礼仪硬伤、称谓错乱，古装质感崩塌出戏。

> 弱红线标签不挂全局质检号；上述风险若上升为崩级问题（如女主靠男人赢的价值观红线、世界观硬伤），由 anti-patterns.md 通用反模式兜底检测。
