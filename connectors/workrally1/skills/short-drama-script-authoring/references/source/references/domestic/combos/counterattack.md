# 逆袭 + 神豪 + 小人物

> **国内标签组合**（平台路由标识 · v6.0）
> - **主标签**：逆袭
> - **辅标签**：神豪, 小人物
> - **受众**：男频 ｜ **背景**：都市 · 职场
> - **国内漫剧**：主题=商战 ｜ 设定=小人物+暴富+逆袭 ｜ 背景=都市
> - **命中规则**：步骤 0 推断出上述标签组合 → Read 本文件作主轴参考

## 一句话定位

卖"草根逆天改命"的奋斗爽感。与复仇最大区别：逆袭靠**后天能力/机遇**，不是隐藏身份。

## 爆款内核公式

草根起点 → 关键机遇/能力觉醒 → 阶层跨越 → 碾压曾经看不起自己的人。强调**成长过程**而非身份揭露。

爽感公式：**爽感 = 阶层落差 × 成长可信度 × 逆袭实现方式的意外性**。

## 创作方向指引（v5.2 重构）

> 逆袭是男频核心爽感主题，同质化严重。以下不提供"选一个方向"的选项，而是提供**差异化思考框架**，帮你跳出经典套路。

### 核心公式
草根起点 → 关键机遇 → 阶层跨越 → 碾压旧人

**爽感公式**：爽感 = 阶层落差 × 成长可信度 × 逆袭实现方式的意外性

### 高频套路提示（非禁用，但需差异化翻转）
以下路径在同题材作品中出现频率极高，你可以使用，但必须至少在 1 个核心维度做本质翻转：
1. **获得金手指/系统后靠本事翻盘** → 翻转：能力来源可以不是系统/金手指，而是更真实的积累
2. **曾经看轻自己的人来求合作** → 翻转：旧人的态度转变可以不是求合作，而是更复杂的关系重构
3. **台阶式上升每5-8集上一个台阶** → 翻转：成长路径可以不是线性上升，而是有回撤和转型
4. **登顶后清算旧债碾压旧人** → 翻转：逆袭的终点可以不是碾压旧人，而是更高的格局选择

### Top3 经典套路（差异化检测对照关键节点 · v5.2 新增）
> 步骤 4 创意差异化评分时，核心爽点机制必须跳出以下 3 种，才算差异化达标。
1. 能力觉醒型：草根受辱→觉醒能力/获得系统→靠本事变现→阶层跨越→碾压旧人
2. 风口创业型：看准风口→孤注一掷→商战博弈→做大做强→成为行业霸主
3. 双向救赎型：低谷相伴→共同奋斗→主角崛起→不忘旧情→携手登顶

### 创作思考步骤（按此流程推导，不套用现成套路）
1. 先确定你想卖的「爽感亚型」——除了上述 Top3 之外的任何方式
2. 回答三个关键问题：① 逆袭的动机？（动机翻转）② 什么触发了转变？（触发翻转）③ 碾压如何实现？（方式翻转）
3. 三个回答中至少有一个不在 Top3 套路中
4. 检验：把你的核心设定发到短剧社群，观众会说"这种逆袭我没见过"吗？
5. 确认翻转后仍能交付该题材的情绪内核

## 目标市场与语言

- 主力市场：国内（"打工人共鸣"是隐藏燃料）。
- 海外可用，但需替换为当地职场/阶层语境。

## 人物配置（差异化）

| 角色 | 本题材特殊要求 |
|---|---|
| 主角 | **真草根**，逆袭靠本事/机遇，不是隐藏大佬（这是与复仇的分水岭） |
| 导师/贵人 | 给主角能力或机会的人，逆袭题材独有 |
| 核心反派 | "阶层固化的既得利益者"，代表主角要打破的天花板 |
| 见证人 | 早期看轻主角的同事/同学/亲戚 |

与相邻题材区别：
- vs 复仇：复仇是"我本来就强只是装弱"，逆袭是"我真的从零变强"
- vs 战神：战神是隐藏的既有强者，逆袭是后天成长的新人

## 节奏卡点表（80 集模板 · 按 A/B 两版）

### A 版（台阶式上升，适配能力觉醒/风口创业/双向救赎）

| 集数 | 事件 | 弹簧类型 |
|---|---|---|
| 1 | 主角窘迫处境 + 被看轻（房租/加班/被PUA） | 压 |
| 5-8 | 获得能力/机遇/看准风口（金手指给规则） | 放（小） |
| 10 | 付费点 1：赚到第一桶金/第一次升职/首单告捷 | 放（中） |
| 20 | 付费点 2：第一次反超曾经的对手 | 放 |
| 25-40 | 遭遇更高阶打压，台阶式上升受阻 | 压放交替 |
| 30 | 付费点 3：突破关键阶层 | 放（极） |
| 50-70 | 登顶之路 + 清算旧债 | 放 |
| 75-80 | 登顶圆满 | 平稳 |

节奏特征：**台阶式上升**。每 5-8 集上一个台阶（升职/赚钱/地位），靠"持续变强"累积爽感。

### B 版（奋斗+情感双线，适配其他创新方向）

| 集数 | 事件 | 弹簧类型 |
|---|---|---|
| 1 | 两人共同陷入低谷（患难钩子） | 压 |
| 5-8 | 抱团取暖 + 第一个小机遇 | 压→放（小） |
| 10 | 付费点 1：第一次共同翻盘 + 情感升温 | 放 |
| 20 | 付费点 2：主角崛起 + 旁人离间考验 | 压→放 |
| 30 | 付费点 3：登顶关键战 + 信任名场面 | 放（极）+暖 |
| 40-65 | 更高阶博弈 + 情感线深化 | 压放交替 |
| 70-80 | 携手登顶 + 回馈真心 | 放→平稳 |

节奏特征：**奋斗为骨、情感为肉**。逆袭台阶照走，但每个台阶都有情感温度回扣。

## 必备桥段清单（每部至少命中 5 个）

- [ ] 早期窘迫真实细节（付不起房租/被领导当众羞辱）
- [ ] 获得金手指/贵人相助的关键转折
- [ ] 第一次靠本事赚钱/解决难题
- [ ] 曾经看轻自己的人来求合作
- [ ] 反超昔日同窗/同事
- [ ] 面对更高阶对手的碾压式打压
- [ ] 关键一战奠定地位
- [ ] 登顶后回馈早期帮过自己的人

## 差异化着重注意点（v5.2 更新）

1. 必须让观众**相信主角靠本事**——能力获得过程要有逻辑（金手指也要给规则）
2. 早期窘迫要**贴近真实生活**（房租、加班、被PUA），这是打工人代入的燃料
3. 爽点是"成长的回报"，不是"装弱后的揭露"
4. **核心设定必须跳出 Top3 套路**——你不需要选一个方向，你需要创造一个新方向
5. **逆袭实现方式的差异化是最大的差异化**——同样卖逆袭，"怎么逆袭"比"为什么逆袭"更决定观众记忆点

## 避坑清单

- 金手指无规则 → 变成无脑爽文
- 跳过奋斗直接成功 → 失去逆袭内核
- 忘记给草根细节 → 观众不代入
- 主角其实是隐藏富豪 → 跑题成了复仇/马甲
- 核心设定完全复刻 Top3 套路（能力觉醒/风口创业/双向救赎）→ 创意差异化不达标
