## 二、变体素材库（仅参考·可自由组合·可原创·可豁免）
> 本节全部为灵感启发，**不强制命中、不作评分依据**，可自由组合/原创/豁免。

### 1. 节奏适配逻辑
常见节奏：乱世相遇 → 身份/立场纠葛 → 时代洪流冲击 → 宿命抉择。民国背景重在时代氛围与家国情怀，台词行为要符合时代。付费节点可落在身份揭露、立场抉择、生离死别、家国大义等处——仅为参考。

### 2. 核心变体素材（任选，不限数量）
#### 场景素材
1. 都市风情：洋楼、舞厅、租界、黄包车的民国都市
2. 宅门深院：大户人家的庭院、太太小姐的闺阁
3. 时局场景：码头、车站、报馆、戏院的时代风云
4. 乱世场景：动荡、离别、家国变故的时代洪流

#### 台词风格素材
1. 文雅旧式：半文半白、讲究称谓的民国腔调
2. 中西交融：新派知识分子的中西夹杂用语
3. 含蓄深情：符合时代的含蓄克制情感表达
4. 时代金句：体现家国情怀、新旧观念碰撞的台词

#### 行为逻辑素材
1. 礼教约束：旧式礼教、门第观念对行为的约束
2. 新旧碰撞：新思想与旧传统的观念冲突
3. 家国大义：个人情感与家国命运的取舍
4. 阶层分明：少爷小姐、佣人、军阀等阶层行为逻辑

#### 付费卡点变体
1. 身份揭露节点
2. 立场抉择节点
3. 生离死别节点

### 3. 钩子参考模板
- 开篇钩子参考：乱世之中男女主因一桩时局变故相遇，埋下宿命纠葛
- 集末钩子参考（仅启发）：
  1. 身份式：他的真实身份，足以改变两人的命运
  2. 抉择式：家国与爱情，他必须做出选择
  3. 离别式：这一别，或许就是永诀
