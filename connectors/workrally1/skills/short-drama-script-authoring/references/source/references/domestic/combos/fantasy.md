## 一句话定位

卖"等级跃迁 + 实力打脸"。环比 +56% 走强，武侠/仙侠/志怪接棒已疲劳的"宫斗"。也是 AI 漫剧的机会点（真人拍古装贵，AI 漫剧适合玄幻修仙）。

## 爆款内核公式

架空设定 → 修炼/权谋升级 → 逆天改命 → 登顶。

爽感公式：**爽感 = 等级跃迁幅度 × 升级体系爽感 × 碾压实现方式的意外性**。

## 创作方向指引（v5.2 重构）

> 玄幻仙侠是男频核心爽感主题，同质化严重。以下不提供"选一个方向"的选项，而是提供**差异化思考框架**，帮你跳出经典套路。AI 漫剧尤其适配本题材，详见 `formats/manga-drama.md`。

### 核心公式
架空设定 → 获取力量/洞察 → 跃迁升级 → 碾压实现 → 登顶

**爽感公式**：爽感 = 等级跃迁幅度 × 升级体系爽感 × 碾压实现方式的意外性

### 高频套路提示（非禁用，但需差异化翻转）
以下路径在同题材作品中出现频率极高，你可以使用，但必须至少在 1 个核心维度做本质翻转：
1. **废柴被轻视 → 觉醒逆天功法/血脉 → 境界飞升 → 打脸** → 翻转：力量来源不是功法/血脉，是认知/选择/牺牲
2. **宗门大比/擂台 → 当众碾压轻视者** → 翻转：碾压方式不靠战力等级，靠智谋/规则/非战斗手段
3. **秘境夺宝 → 获得逆天机缘** → 翻转：机缘本身有代价/副作用/道德困境
4. **灭门血仇 → 复仇线** → 翻转：复仇对象可以是自己的师父/宗门/信仰

### Top3 经典套路（差异化检测对照关键节点 · v5.2 新增）
> 步骤 4 创意差异化评分时，核心爽点机制必须跳出以下 3 种，才算差异化达标。
1. 废柴逆袭修仙型：废柴受辱→觉醒逆天功法/血脉→境界飞升→实力打脸→登顶/飞升
2. 权谋宫廷型：卷入权力漩涡→步步为营→识破阴谋→反客为主→执掌权柄
3. 仙侠虐恋型：命定相遇→身份对立→深爱却阻隔→宿命考验→跨越生死/位面

### 创作思考步骤（按此流程推导，不套用现成套路）
1. 先确定你想卖的「爽感亚型」——除了上述 Top3 之外的任何方式
2. 回答三个关键问题：① 力量/地位的动机？（动机翻转）② 什么触发了跃迁？（触发翻转）③ 碾压如何实现？（方式翻转）
3. 三个回答中至少有一个不在 Top3 套路中
4. 检验：把你的核心设定发到短剧社群，观众会说"这种玄幻我没见过"吗？
5. 确认翻转后仍能交付「等级跃迁爽感 + 实力碾压震撼」

## 目标市场与语言

- 主力市场：通用（偏男频）。
- **海外不走东方修仙**——欧美玄幻偏好狼人吸血鬼（→ `werewolf.md`）。本模块主要面向国内及华人市场。

## 人物配置（差异化）

| 角色 | 本题材特殊要求 |
|---|---|
| 主角 | "废柴逆袭"或"绝世天才"两条路线之一 |
| 反派 | 门派/家族/仙界的压迫者，配宿命对手 |
| 宿命对手 | 贯穿全剧的竞争者/夙敌 |
| 引路人 | 给主角功法/机缘的角色 |

与相邻题材区别：
- vs 海外狼人：都是超自然，但古装走东方修仙体系，狼人走西方种族+爱情
- vs 都市逆袭：古装要先建世界观，逆袭是现实背景

## 节奏卡点表（80 集模板 · 按 A/B 两版）

### A 版（升级慢热后劲足，适配废柴逆袭修仙/其他创新方向）

| 集数 | 事件 | 弹簧类型 |
|---|---|---|
| 1 | 主角废柴受辱 + 世界观一句话立住 | 压 |
| 5 | 获得功法/觉醒天赋/经营起步 | 放（小） |
| 10 | 付费点 1：首次境界突破 + 打脸/首单告捷 | 放 |
| 20 | 付费点 2：夺宝/秘境奇遇/产业突破 | 放 |
| 30 | 付费点 3：灭门复仇/宗门大比夺魁/势力成型 | 放（极） |
| 40-70 | 更高境界博弈 + 宿命对决 | 压放交替 |
| 75-80 | 登顶/飞升/富甲一方圆满 | 平稳 |

节奏特征：**慢热后劲足**。前几集交代设定，升级/经营体系本身就是爽感来源。

### B 版（权谋/虐恋节奏，适配权谋宫廷/仙侠虐恋）

| 集数 | 事件 | 弹簧类型 |
|---|---|---|
| 1 | 主角入局/命定相遇 + 危机/羁绊钩子 | 压/悬念 |
| 5-8 | 卷入漩涡/感情升温（暗藏对立） | 压+悬念 |
| 10 | 付费点 1：首次破局/身份揭晓冲击 | 放/虐 |
| 20 | 付费点 2：反客为主/虐心抉择 | 压→放 |
| 30 | 付费点 3：惊天反转/为爱逆天 | 放（极） |
| 40-65 | 多回合博弈/虐恋拉扯升级 | 压放交替 |
| 70-80 | 执掌权柄/终成眷属或凄美结局 | 放→平稳 |

节奏特征：**权谋宫廷重智斗回合，仙侠虐恋重虐心起伏**。比 A 版更曲折，靠"谋略"或"情感"驱动。

## 差异化着重注意点（v5.2 更新）

1. **世界观轻量化**——短剧没时间做宏大设定，规则"一句话讲清"（如"灵气复苏，强者为尊"）
2. **视觉成本**是双刃剑——真人服化道贵，但 AI 漫剧反而适合玄幻修仙
3. 规避已疲劳的宫斗，往**武侠/仙侠/志怪**靠
4. **明确"升级/权谋/虐恋"主轴**，以其核心公式为骨架自由发挥，不强制按预设桥段填空——你有更创新的桥段组合尽管用
5. **核心设定必须跳出 Top3 套路**——你不需要选一个方向，你需要创造一个新方向

## 避坑清单

- 世界观太复杂 → 短剧观众没耐心
- 升级无目标（为升级而升级）→ 失去爽点方向
- 宫斗老套 → 市场已审美疲劳
- 设定前几集铺太满 → 开篇劝退
- 核心设定完全复刻 Top3 套路（废柴逆袭修仙/权谋宫廷/仙侠虐恋）→ 创意差异化不达标
