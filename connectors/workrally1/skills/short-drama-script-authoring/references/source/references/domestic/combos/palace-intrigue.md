## 一句话定位

卖"后宅/后宫中的智斗逆袭"——被困在方寸之地的女性，靠脑子和手腕翻盘。2025-2026 国内新增热门标签，6月18部新剧热度4.76亿，4部闯入 TOP10。

## 创作方向指引（v5.2 重构）

> 宫斗宅斗是女频核心爽感主题，同质化严重。以下不提供"选一个方向"的选项，而是提供**差异化思考框架**，帮你跳出经典套路。

### 核心公式
低位受困 → 看穿布局 → 借力打力 → 翻盘上位 → 余波收束

**爽感公式**：爽感 = 困境封闭度 × 翻盘智巧度 × 翻盘实现方式的意外性

### 高频套路提示（非禁用，但需差异化翻转）
以下路径在同题材作品中出现频率极高，你可以使用，但必须至少在 1 个核心维度做本质翻转：
1. **重生带记忆精准拆局** → 翻转：不靠重生记忆，靠当下一己之智翻盘
2. **继母/嫡姐/正妃设局陷害 → 将计就计反杀** → 翻转：反派可以是主角自身的执念/心魔/制度本身
3. **被当众羞辱 → 贵人撑腰/亮底牌 → 翻身** → 翻转：翻盘靠信息差/规则利用，不靠外力撑腰
4. **庶女/低位逆袭 → 身份逆转 → 打脸** → 翻转：终点不是身份逆转，而是对制度本身的颠覆

### Top3 经典套路（差异化检测对照关键节点 · v5.2 新增）
> 步骤 4 创意差异化评分时，核心爽点机制必须跳出以下 3 种，才算差异化达标。
1. 重生后宅逆袭型：带记忆回到被害前→精准拆局→反杀陷害者→掌控后宅
2. 宫中位份晋升型：从最低位入局→看穿格局→结盟借力→逐个击破→登顶后位
3. 庶女翻身型：最卑微身份→发现自身价值→借势不被势吞→以弱胜强→身份逆转

### 创作思考步骤（按此流程推导，不套用现成套路）
1. 先确定你想卖的「爽感亚型」——除了上述 Top3 之外的任何方式
2. 回答三个关键问题：① 核心冲突的动机？（动机翻转）② 什么触发了转变？（触发翻转）③ 高潮如何实现？（方式翻转）
3. 三个回答中至少有一个不在 Top3 套路中
4. 检验：把你的核心设定发到短剧社群，观众会说"这种宫斗我没见过"吗？
5. 确认翻转后仍能交付「困境封闭感 + 翻盘智巧爽感」

## 人物配置

| 角色 | 功能 | 铁律 |
|---|---|---|
| 主角 | 智斗核心 | 必须有自己的底线和主动决策，不得成为被动棋子 |
| 大反派（继母/正妃/皇贵妃） | 核心压迫源 | 必须足够聪明，不是纯恶蠢角；要能对主角构成真实威胁 |
| 盟友/贵人 | 破局关键 | 不能无条件帮忙，必须有交换条件或自身利益 |
| 男主 | 情感线+助力 | 不得成为"救世主"——主角靠自己翻盘，男主是锦上添花 |
| 中层反派（庶妹/妾室/嫔妃） | 阶段性障碍 | 每个必须有独立动机，不是大反派的提线木偶 |

## 差异化着重注意点（v5.2 更新）

- **宫斗 vs 宅斗**：宫斗=皇权体系+后妃等级+朝堂暗线，宅斗=家族内宅+嫡庶+婆媳妯娌，节奏和格局差异大
- **智斗型 > 互害型**：不要让宅斗沦为"你害我我害你"的无脑互撕，每次出手必须有策略深度
- **女主独立性**：宫斗宅斗的女主必须靠脑子和手腕，不能靠男主翻盘——这是2025-2026女频核心趋势
- **空间封闭感**：利用"方寸之地"的压迫感——后宅/后宫是牢笼，翻盘才有爽感
- **等级制度**：明确等级体系（妃嫔等级/嫡庶尊卑），翻盘才有落差感
- **核心设定必须跳出 Top3 套路**——你不需要选一个方向，你需要创造一个新方向

## 避坑清单

| ❌ 避免 | ✅ 应该 |
|---|---|
| 女主全靠男主救场 | 女主有独立破局能力，男主是助力非救世主 |
| 反派纯恶无脑 | 反派有动机有逻辑，构成真实威胁 |
| 宅斗变成互撕流水账 | 每次出手都有策略，层级递进 |
| 前世回忆拖沓占用大量篇幅 | 前世只在关键节点闪回，每次闪回都有新信息 |
| 后宫格局扁平化 | 明确后/妃/嫔等级与势力分布，格局越清晰翻盘越爽 |
| 重生后无任何困难 | 重生改变起点不改变格局，对手必须同步升级 |
| 核心设定完全复刻 Top3 套路（重生后宅逆袭/宫中位份晋升/庶女翻身）→ 创意差异化不达标 | 核心爽点机制必须跳出 Top3，创造新方向 |
