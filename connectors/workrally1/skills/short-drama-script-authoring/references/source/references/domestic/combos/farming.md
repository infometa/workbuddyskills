## 一句话定位

卖"白手起家的经营快感"——从一无所有到富甲一方，靠双手和脑子一步步建设。2025-2026 国内新增热门标签，6月6部新剧热度1.38亿，头部作品热度超4000万。

## 创作方向指引（v5.2 重构）

> 种田经营是女频核心爽感主题，同质化严重。以下不提供"选一个方向"的选项，而是提供**差异化思考框架**，帮你跳出经典套路。

### 核心公式
赤贫开局 → 发现资源/机遇 → 第一桶金 → 滚雪球扩张 → 碾压实现 → 富甲一方

**爽感公式**：爽感 = 起点之低 × 增长速度 × 打脸实现方式的意外性

### 高频套路提示（非禁用，但需差异化翻转）
以下路径在同题材作品中出现频率极高，你可以使用，但必须至少在 1 个核心维度做本质翻转：
1. **穿越赤贫农家 → 现代知识改良 → 滚雪球致富** → 翻转：致富不靠现代知识，靠对人心/规则的洞察
2. **激活系统 → 完成任务 → 产业扩张** → 翻转：系统不是助力而是限制/双刃剑
3. **极品亲戚来占便宜 → 智慧反制** → 翻转：极品亲戚不是障碍而是资源/盟友
4. **早期质疑者 → 来求合作 → 大度处理** → 翻转：主角不选择原谅，而是建立全新规则体系

### Top3 经典套路（差异化检测对照关键节点 · v5.2 新增）
> 步骤 4 创意差异化评分时，核心爽点机制必须跳出以下 3 种，才算差异化达标。
1. 穿越种田发家型：穿越赤贫农家→发现可利用资源→改良农作→滚雪球→成地方首富
2. 系统流种田型：激活系统→完成新手任务得第一桶金→系统升级解锁新模块→产业扩张→终极奖励
3. 乡村女强人型：被抛弃/被看轻→发现身边资源→小本经营→遭遇地方势力→智斗破局→成功

### 创作思考步骤（按此流程推导，不套用现成套路）
1. 先确定你想卖的「爽感亚型」——除了上述 Top3 之外的任何方式
2. 回答三个关键问题：① 经营的动机？（动机翻转）② 什么触发了起步？（触发翻转）③ 碾压如何实现？（方式翻转）
3. 三个回答中至少有一个不在 Top3 套路中
4. 检验：把你的核心设定发到短剧社群，观众会说"这种种田我没见过"吗？
5. 确认翻转后仍能交付「白手起家成就感 + 打脸爽感」

## 差异化着重注意点（v5.2 更新）

- **种田经营 vs 逆袭**：种田核心是"经营建设+白手起家"，逆袭核心是"地位攀升+打脸"——种田更重过程和成就感，逆袭更重爽感爆发
- **系统流平衡**：系统是辅助不是代替——主角的决策和努力必须是成功的关键，系统只提供信息/奖励/加成
- **经营真实感**：即使是古代/架空，经营逻辑要自洽——不能种一棵树下一集就果实累累
- **极品亲戚节奏**：极品亲戚打脸是种田文核心爽点，但不能无限循环——每次打脸必须升级，对手必须变强
- **乡村 vs 古代**：乡村种田偏生活化+方言+烟火气，古代种田偏等级制度+家族规矩+商贸博弈
- **核心设定必须跳出 Top3 套路**——你不需要选一个方向，你需要创造一个新方向

## 避坑清单

| ❌ 避免 | ✅ 应该 |
|---|---|
| 系统包办一切，主角躺赢 | 系统提供信息/奖励，关键决策和努力由主角完成 |
| 极品亲戚反复出现但打脸永远一样 | 每次极品打脸必须升级手段、升级烈度 |
| 经营过程跳过（"三个月后..."） | 关键经营节点必须有过程展示 |
| 乡村背景沦为装饰 | 乡村环境参与叙事——天气、节气、人情世故都是情节 |
| 种田写成"流水账发家史" | 每个经营阶段必须有冲突和危机 |
| 无脑配角占大量篇幅 | 极品亲戚每次出场必须有新花招，不是重复犯蠢 |
| 核心设定完全复刻 Top3 套路（穿越种田发家/系统流种田/乡村女强人）→ 创意差异化不达标 | 核心爽点机制必须跳出 Top3，创造新方向 |
