## 二、变体素材库（仅参考·可自由组合·可原创·可豁免）
> 本节全部为灵感启发，**不强制命中、不作评分依据**，可自由组合/原创/豁免。

### 1. 节奏适配逻辑
常见节奏：无敌登场 → 不断挑衅 → 轻松碾压 → 笑傲群雄。付费节点可落在身份揭晓、一招碾压、群敌环伺反杀、镇压全场等处——仅为参考。

### 2. 核心变体素材（任选，不限数量）
#### 碾压爽点变体
1. 一招制敌型：对手还没看清，胜负已分
2. 越级碾压型：以低姿态硬刚高位者，反手秒杀
3. 群敌反杀型：被围攻，一人横扫全场
4. 实力震慑型：气场一放，挑衅者瞬间怂

#### 冲突模式变体
1. 不知天高型：新贵不识泰山，挑衅被教做人
2. 旧仇上门型：宿敌找茬，被无敌者轻松镇压
3. 守护出手型：为护重要之人，雷霆亮剑
4. 身份质疑型：众人不信其无敌，被打脸

#### 人设风格变体
1. 高冷无敌型：寡言少语，出手即终结
2. 痞帅嚣张型：张扬却有绝对实力撑腰
3. 扮猪吃虎型：藏拙被轻视，亮剑炸场
4. 淡然枭雄型：云淡风轻，俯视众生

#### 付费卡点变体
1. 揭晓节点：无敌身份/实力首次曝光，全场震动
2. 碾压节点：一招制敌，挑衅者毫无还手之力
3. 反杀节点：被群敌环伺却完成横扫

### 3. 钩子参考模板
- 开篇钩子参考：主角实力深不可测却被轻视，埋下身份揭晓、全程碾压的预期
- 集末钩子参考（仅启发）：
  1. 揭晓式：他们挑衅的对象，是这个世界的天花板
  2. 碾压式：他出手，从不需要第二招
  3. 震慑式：在绝对的实力面前，所有阴谋都是笑话

## 三、人设加成参考
1. 主角：开局即巅峰，实力碾压一切；碾压有梗、不滥用降智对手，姿态淡然不油腻。
2. 挑衅者/对手：不断登场的踏脚石，须有合理动机，不为衬托强行降智。
3. 守护对象：主角出手的理由，赋予无敌以温度。
> 仅为方向参考，具体设定可自由发挥。

## 五、红线与反模式
> 红线severity：弱

### 1. 避坑提示（不挂质检号、不扣分，仅创作提醒）
1. 避免强行降智憋屈，无敌主角却处处受气、被迫装弱，违背标签爽感。
2. 避免战力崩坏，无敌人设却出现五五开对手，碾压感荡然无存。
3. 避免装逼油腻、嘴炮浮夸，主角变成令人反感的中二角色。
4. 避免反派同质化，挑衅者千篇一律送人头，碾压沦为重复流水线。

> 弱红线标签不挂全局质检号；上述风险若上升为崩级问题（如战力崩坏属世界观硬伤），由 anti-patterns.md 通用反模式（#7 世界观硬伤等）兜底检测。
