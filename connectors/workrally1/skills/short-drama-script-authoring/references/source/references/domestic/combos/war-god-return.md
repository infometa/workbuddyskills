## 创作方向指引（v5.2 重构）

> 战神归来是男频顶级爽感主题，同质化严重。以下不提供"选一个方向"的选项，而是提供**差异化思考框架**，帮你跳出经典套路。

### 核心公式
王者归来 → 隐忍有因 → 触发转变 → 碾压实现 → 余波收束

**爽感公式**：爽感 = 隐忍合理度 × 战力反差 × 碾压实现方式的意外性

### 高频套路提示（非禁用，但需差异化翻转）
以下路径在同题材作品中出现频率极高，你可以使用，但必须至少在 1 个核心维度做本质翻转：
1. **上门女婿+废物+电话千军** → 翻转：隐忍身份不限于"上门女婿"，碾压不限于"电话调动千军"
2. **反派动了家人→触怒底线→爆发** → 翻转：爆发的触发可以是主角自身的认知转变，不依赖外部欺压
3. **旧部跪拜→身份曝光→全场震惊** → 翻转：身份揭露可以通过敌人恐惧/无意细节/主角自选时机
4. **地方恶霸层层升级→碾压终极boss** → 翻转：对手可以是战神自己的过去/心魔/制度/信仰

### Top3 经典套路（差异化检测对照关键节点 · v5.2 新增）
> 步骤 4 创意差异化评分时，核心爽点机制必须跳出以下 3 种，才算差异化达标。
1. 隐忍爆发型：低调归来当废物→被欺压→电话/令牌→旧部跪拜→碾压
2. 暗中守护型：默默保护某人→屡次出手被误会→身份意外暴露→守护变征服
3. 赎罪归来型：因过去失误赎罪→从最低做起→被当窝囊废→真相揭开→终极救赎

### 创作思考步骤（按此流程推导，不套用现成套路）
1. 先确定你想卖的「爽感亚型」——除了上述 Top3 之外的任何方式
2. 回答三个关键问题：① 战神为什么隐忍？（动机翻转）② 什么触发了他的转变？（触发翻转）③ 碾压如何实现？（方式翻转）
3. 三个回答中至少有一个不在 Top3 套路中
4. 检验：把你的核心设定发到短剧社群，观众会说"这种战神我没见过"吗？
5. 确认翻转后仍能交付「隐忍合理性+碾压震撼感」

## 节奏卡点表（80 集模板 · 按 A/B 两版）

### A 版（忍-爆节奏，适配隐忍爆发/赎罪归来）

| 集数 | 事件 | 弹簧类型 |
|---|---|---|
| 1 | 战神低调归来，被当废物欺压（装弱有理由） | 压 |
| 5 | 第一次露手制服小混混 | 放（小） |
| 10 | 付费点 1：身份初现端倪/旧部出现 | 放（中）+ 悬念 |
| 20 | 付费点 2：反派对主角家人下手 | 压（极） |
| 25-30 | 付费点 3：战力大公开 + 碾压实现方式揭晓 | 放（极） |
| 40-55 | 更大势力现身，主角受挫 | 压 |
| 60-75 | 终极对决，碾压终极大佬 | 放 |
| 75-80 | 守护家人圆满 | 平稳 |

### B 版（渐进守护/双线节奏，适配暗中守护/其他创新方向）

| 集数 | 事件 | 弹簧类型 |
|---|---|---|
| 1 | 战神归来，默默守护/双线开始 | 压（温和） |
| 5 | 守护初见效/暗线首次浮现 | 放（小） |
| 10 | 付费点 1：守护的痕迹被误解/暗线加剧 | 压+悬念 |
| 15-20 | 守护累积+暗线推进 | 压放交替 |
| 25-30 | 付费点 2-3：身份暴露/暗线与主线交汇 | 极放 |
| 35-55 | 真相扩散+更大危机 | 压 |
| 60-75 | 终极救赎/双线合流碾压 | 放 |
| 75-80 | 圆满 | 平稳 |

**节奏特征**：**忍—爆结构**（A 版）/ **渐进—交汇—爆发**（B 版）。A 版主角主动隐忍，B 版主角被动暴露。

## 目标市场与语言

- 主力市场：国内（男频）。
- 海外可转化为"退伍特种兵/黑帮归来"，但欧美男频体量小于女频，谨慎投入。
- **差异化方向市场适配**：隐忍爆发型国内男频核心；暗中守护型国内+日韩（守护深情可跨受众）；赎罪归来型国内+海外（救赎叙事更普世）；其他创新方向需自行验证受众匹配。

## 人物配置（通用框架）

| 角色 | 本题材特殊要求 |
|---|---|
| 主角 | 隐藏身份是**军事/暴力体系顶端**（战神、龙王、兵王、佣兵之王），不是商业大佬。具体身份按创意方向自由设计，不受预设池限制 |
| 旧部 | **必备"认主"角色**——曾经的下属/战友，制造身份反差；认主方式不限（跪拜/敬礼/恐惧/服从），按创意方向自由设计 |
| 核心反派 | 可逐级递增（地方豪强+背后更大势力），也可设为战神自身的过去/心魔/制度性对手——按创意方向自由设计 |
| 家人/兄弟 | 主角归来的动机来源（尽孝/报仇/护国） |

与相邻题材区别：
- vs 复仇：都靠隐藏身份，复仇是商业/智力碾压，战神是**武力**碾压
- vs 马甲：战神是单一军方身份，马甲是多重叠加

## 差异化着重注意点（v5.2 更新）

1. **忍要有理由**（陪家人、低调做人、答应过谁），否则观众嫌窝囊
2. 武力展示要**视觉化、有层次**——递进展开，不是一上来就碾压到底
3. 男频要的是"代入强者"的征服感，不是成长；台词要有**威压感**
4. **核心设定必须跳出 Top3 套路**——你不需要选一个方向，你需要创造一个新方向
5. **碾压实现方式的差异化是最大的差异化**——同样卖爽感，"怎么碾压"比"为什么碾压"更决定观众记忆点

## 避坑清单

- 忍得没理由 → 观众嫌窝囊
- 战力崩坏（一会儿无敌一会儿被绑架）→ 设定塌方
- 旧部智商掉线（为捧主角强行降智）→ 出戏
- 装弱期太长 → 观众等不及
- 核心设定完全复刻 Top3 套路（隐忍爆发/暗中守护/赎罪归来）→ 创意差异化不达标
