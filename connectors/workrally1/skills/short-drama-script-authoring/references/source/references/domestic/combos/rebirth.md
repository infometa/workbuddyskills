# 重生 + 穿越 + 穿书

> **国内标签组合**（平台路由标识 · v6.0）
> - **主标签**：重生
> - **辅标签**：穿越, 穿书
> - **受众**：不限 ｜ **背景**：不限
> - **国内漫剧**：主题=剧情 ｜ 设定=重生+穿越+打脸虐渣 ｜ 背景=不限
> - **命中规则**：步骤 0 推断出上述标签组合 → Read 本文件作主轴参考

## 一句话定位

卖"先知视角的掌控感"。常与复仇/甜宠叠加（重生复仇、重生甜宠）。

## 爆款内核公式

带着记忆/经验回到过去（或异世）→ 信息差碾压 → 改写命运 → 复仇/逆袭/护家。

爽感公式：**爽感 = 前世痛点深度 × 预判精准度 × 改命实现方式的意外性**。

## 创作方向指引（v5.2 重构）

> 重生是跨受众核心爽感主题，同质化严重。以下不提供"选一个方向"的选项，而是提供**差异化思考框架**，帮你跳出经典套路。

### 核心公式
带着信息差回到过去/异世 → 精准预判 → 改写命运 → 碾压实现 → 余波收束

**爽感公式**：爽感 = 前世痛点深度 × 预判精准度 × 改命实现方式的意外性

### 高频套路提示（非禁用，但需差异化翻转）
以下路径在同题材作品中出现频率极高，你可以使用，但必须至少在 1 个核心维度做本质翻转：
1. **前世被害惨死 → 重生 → 精准复仇仇人** → 翻转：重生动机不是复仇，是弥补/守护/创造
2. **信息差全知 → 提前布局 → 仇人按前世剧本落空** → 翻转：信息差有缺口/对手也重生/预判失误
3. **重生甜宠 → 弥补前世遗憾 → 双向奔赴** → 翻转：重来一次遇到全新的人/做出前世不可能的选择
4. **穿越 → 现代知识降维碾压古人** → 翻转：现代知识在异世水土不服/反被异世规则教育

### Top3 经典套路（差异化检测对照关键节点 · v5.2 新增）
> 步骤 4 创意差异化评分时，核心爽点机制必须跳出以下 3 种，才算差异化达标。
1. 重生复仇型：前世被害→重生回关键点→预判布局→提前反杀仇人→改写结局
2. 重生甜宠型：前世错爱/错过→重生醒悟→主动靠近真爱→改写感情线→双向奔赴
3. 穿越降维型：穿越异世→现代知识降维→解决时代难题→步步高升→改变格局

### 创作思考步骤（按此流程推导，不套用现成套路）
1. 先确定你想卖的「爽感亚型」——除了上述 Top3 之外的任何方式
2. 回答三个关键问题：① 重生的动机？（动机翻转）② 什么触发了改变？（触发翻转）③ 改命如何实现？（方式翻转）
3. 三个回答中至少有一个不在 Top3 套路中
4. 检验：把你的核心设定发到短剧社群，观众会说"这种重生我没见过"吗？
5. 确认翻转后仍能交付「信息差碾压爽感 + 改命成就感」

## 目标市场与语言

- 主力市场：通用（偏女频）。
- 海外"重启人生（second chance）"在东南亚受欢迎，可本土化。

## 人物配置（差异化）

| 角色 | 本题材特殊要求 |
|---|---|
| 主角 | 核心道具是**记忆/信息差**——知道未来会发生什么 |
| 前世今生对照组 | 前世害过主角的人，今生提前布局反制 |
| 关键转折人 | 前世错过、今生抓住的机遇/贵人 |

与相邻题材区别：
- vs 复仇：复仇靠当下实力，重生靠**未来信息**预判
- 常作为"叠加层"：重生+复仇、重生+甜宠、重生+逆袭。此时主题材按叠加对象走，重生作机制补充

## 节奏卡点表（80 集模板 · 按 A/B 两版）

### A 版（预判碾压，适配重生复仇/穿越降维）

| 集数 | 事件 | 弹簧类型 |
|---|---|---|
| 1 | 前世惨死/被害（痛点钩子） → 重生/穿越 | 压→放（小） |
| 5 | 第一次预判改命/降维立威（小爽点） | 放 |
| 10 | 付费点 1：阻止前世某悲剧/降维首秀 | 放 |
| 20 | 付费点 2：提前扳倒前世仇人/破解难题 | 放 |
| 30 | 付费点 3：抓住前世错过的关键机遇 | 放（极） |
| 40-70 | 命运彻底改写 + 反派措手不及 | 放为主 |
| 75-80 | 圆满新结局 | 平稳 |

节奏特征：**预判碾压**。开篇快速建立痛点，重生后立刻改命给爽感。善用"前世后世对比蒙太奇"。

### B 版（情感/博弈节奏，适配重生甜宠/其他创新方向）

| 集数 | 事件 | 弹簧类型 |
|---|---|---|
| 1 | 前世遗憾/宿敌同生（钩子） → 重生 | 压→悬念 |
| 5 | 主动改写关系/发现对手也重生 | 放+悬念 |
| 10 | 付费点 1：感情主动出击/博弈第一回合 | 放 |
| 20 | 付费点 2：弥补前世遗憾/识破对手布局 | 放 |
| 30 | 付费点 3：双向奔赴名场/棋高一着 | 放（极） |
| 40-70 | 感情深化/多回合博弈升级 | 压放交替 |
| 75-80 | 圆满（甜）/终局胜负（智斗） | 放→平稳 |

节奏特征：**重生甜宠重情感节拍，创新方向重博弈回合**。比 A 版更曲折，靠"关系演进"或"智斗回合"驱动。

## 必备桥段清单（每部至少命中 5 个）

- [ ] 前世惨死/被背叛的痛点开场
- [ ] 重生睁眼回到关键时间点
- [ ] 前世吃亏 vs 今生反杀的对比蒙太奇
- [ ] 精准预判某事件，抢先一步
- [ ] 提前识破前世信任的反派
- [ ] 抓住前世错过的人/机遇
- [ ] 让前世的悲剧变成今生的喜剧
- [ ] （穿越）现代知识降维碾压古人

## 差异化着重注意点（v5.2 更新）

1. 善用"**前世后世对比蒙太奇**"——同一场景前世吃亏 vs 今生反杀
2. 信息差要**用得巧**——关键节点精准预判，不是无脑全知
3. （穿越）额外处理"**现代知识降维**"
4. **明确"重生+什么"**，以叠加对象的核心公式为骨架自由发挥，不强制按预设桥段填空——你有更创新的桥段组合尽管用
5. **核心设定必须跳出 Top3 套路**——你不需要选一个方向，你需要创造一个新方向

## 避坑清单

- 重生后还是慢半拍 → 浪费金手指
- 信息差万能（全知全能）→ 无悬念无紧张
- 前世铺垫过长 → 观众等不及看改命
- 重生但不改命 → 失去题材意义
- 核心设定完全复刻 Top3 套路（重生复仇/重生甜宠/穿越降维）→ 创意差异化不达标
