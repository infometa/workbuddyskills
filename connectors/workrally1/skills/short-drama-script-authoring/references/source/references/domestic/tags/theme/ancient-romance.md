## 二、变体素材库（仅参考·可自由组合·可原创·可豁免）
> 本节全部为灵感启发，**不强制命中、不作评分依据**，可自由组合/原创/豁免。

### 1. 节奏适配逻辑
常见节奏：古风相遇 → 含蓄生情 → 宿命与阻隔拉扯 → 相守或遗憾，意境与情感交织。付费节点可落在初遇心动、身份阻隔、宿命抉择等处——仅为参考位置，不强制。

### 2. 核心变体素材（任选，不限数量）
#### 古典爱情甜点变体
1. 含蓄克制型：以诗意含蓄表达深情的古典美
2. 宿命羁绊型：因缘分注定相系的命定之恋
3. 患难相守型：乱世或困境中携手的深情
4. 才子佳人型：以才情相知相惜的雅致之恋

#### 冲突模式变体
1. 身份阻隔型：因门第/阵营对立的爱恨
2. 家国抉择型：在情与家国大义间的取舍
3. 误会错过型：因误解错失的遗憾与重续
4. 权谋裹挟型：身处宫廷权谋中的情感坚守

#### 人设风格变体
1. 清冷克制型：含蓄内敛、深情不外露
2. 温润如玉型：儒雅守礼、以诚动人
3. 飒爽明媚型：明朗果敢、不失古典韵味

#### 付费卡点变体
1. 初遇心动节点：古风相遇的意境冲击
2. 身份阻隔节点：门第或阵营的情感考验
3. 宿命抉择节点：情与义间的关键抉择

### 3. 钩子参考模板
- 开篇钩子参考：从古风相遇或宿命缘起切入，建立意境与心动预期
- 集末钩子参考（仅启发）：
  1. 宿命式：这一眼,便是一生的牵绊
  2. 阻隔式：身份的鸿沟，让这段情注定坎坷
  3. 抉择式：情与义之间，他终须做出选择

## 五、红线与反模式
> 红线severity：弱

### 1. 避坑提示（不挂质检号、不扣分，仅创作提醒）
1. 避免古风感缺失，台词现代化破坏古典意境。
2. 避免情感过于直白，丢失古风含蓄克制之美。
3. 避免时代背景虚化，架空到毫无质感与代入。
4. 避免人设不符古代逻辑，行为观念违和出戏。

> 说明：古风言情即使不守这些点，通常只是"不够美"而非"剧情崩塌"，故定为弱红线、不挂全局质检号。人设违和若达崩级，由 anti-patterns.md #8 性格漂移兜底。
