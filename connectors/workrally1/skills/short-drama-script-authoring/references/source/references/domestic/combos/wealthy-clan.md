## 创作方向指引（v5.2 重构）

> 豪门恩怨是女频核心爽感主题，同质化严重。以下不提供"选一个方向"的选项，而是提供**差异化思考框架**，帮你跳出经典套路。

### 核心公式
身世之谜 → 错位人生 → 真相揭露 → 归位清算

**爽感公式**：爽感 = 真假对比强度 × 身份反转 × 真相揭露方式的意外性

### 高频套路提示（非禁用，但需差异化翻转）
以下路径在同题材作品中出现频率极高，你可以使用，但必须至少在 1 个核心维度做本质翻转：
1. **DNA/信物认证身份** → 翻转：身份认证可以不是DNA/信物，而是更意想不到的方式
2. **假千金当众羞辱真千金** → 翻转：冲突可以不是当众羞辱，而是更隐蔽的压迫形式
3. **势利家族捧假踩真→后期反转打脸** → 翻转：家族态度转变可以不是简单反转，而是更复杂的分化
4. **假千金恶行被逐一揭穿、彻底下场** → 翻转：假千金的结局可以不是恶有恶报，而是更人性的处理

### Top3 经典套路（差异化检测对照关键节点 · v5.2 新增）
> 步骤 4 创意差异化评分时，核心爽点机制必须跳出以下 3 种，才算差异化达标。
1. 真假千金型：真假错位→真千金受苦→信物/真相浮现→身份认证→假千金下场
2. 错抱归来型：多年错抱→父母觉察→双线寻找/相认→亲情修复→假象崩塌
3. 豪门联姻博弈型：卷入豪门→派系倾轧→步步为营→掌握话语权→重定格局

### 创作思考步骤（按此流程推导，不套用现成套路）
1. 先确定你想卖的「爽感亚型」——除了上述 Top3 之外的任何方式
2. 回答三个关键问题：① 身世错位的动机？（动机翻转）② 什么触发了真相揭露？（触发翻转）③ 归位如何实现？（方式翻转）
3. 三个回答中至少有一个不在 Top3 套路中
4. 检验：把你的核心设定发到短剧社群，观众会说"这种豪门恩怨我没见过"吗？
5. 确认翻转后仍能交付该题材的情绪内核

## 差异化着重注意点（v5.2 更新）

1. "**真假对比**"是命脉——真千金隐忍懂事 vs 假千金嚣张愚蠢，对比越强越爽
2. 兼顾"**爽**"和"**泪**"——认亲催泪 + 打脸解气，双情绪供给
3. 下沉市场最吃，冲突与台词可"狗血浓度高一点"
4. **核心设定必须跳出 Top3 套路**——你不需要选一个方向，你需要创造一个新方向
5. **真相揭露方式的差异化是最大的差异化**——同样卖豪门恩怨，"怎么揭露"比"揭露什么"更决定观众记忆点

## 避坑清单

- 真千金太圣母（一味隐忍）→ 观众憋屈
- 假千金没下场 → 恶人不被罚遭差评
- 认亲过早 → 失去身世悬念张力
- 缺亲情线 → 沦为普通打脸，丢了催泪卖点
- 核心设定完全复刻 Top3 套路（真假千金/错抱归来/豪门联姻博弈）→ 创意差异化不达标
