## 二、变体素材库（仅参考·可自由组合·可原创·可豁免）
> 本节全部为灵感启发，**不强制命中、不作评分依据**，可自由组合/原创/豁免。

### 1. 节奏适配逻辑
常见节奏：受困蛰伏 → 朝堂博弈 → 权倾天下 → 登基称帝。付费节点可落在初次立威、权谋破局、平定叛乱、登基高光等处——仅为参考。

### 2. 核心变体素材（任选，不限数量）
#### 掌权爽点变体
1. 权谋登顶型：步步为营，以谋略扫平朝堂阻力
2. 御下立威型：恩威并施收服群臣，掌控大局
3. 平乱定鼎型：力挽狂澜平定动乱，奠定帝位
4. 格局制胜型：以天下为棋局，运筹帷幄定乾坤

#### 冲突模式变体
1. 权臣掣肘型：朝中老臣阻挠，女帝以智破局
2. 夺嫡之争型：与诸王争位，凭实力服众
3. 内忧外患型：边疆与内政双重危机，女帝统筹应对
4. 性别偏见型：朝野质疑女子称帝，以政绩打脸

#### 人设风格变体
1. 杀伐果断型：雷霆手段，霸气威严
2. 智谋深远型：谋定后动，掌控全局
3. 仁威并济型：以德服人又有铁腕
4. 孤勇登顶型：力排众议，独自扛起江山

#### 付费卡点变体
1. 立威节点：初掌权柄震慑群臣的高光
2. 破局节点：权谋反转扫平关键政敌
3. 登基节点：力排众议登顶帝位的名场面

### 3. 钩子参考模板
- 开篇钩子参考：女主身处权力漩涡被低估，埋下权谋登顶、女子称帝的强烈预期
- 集末钩子参考（仅启发）：
  1. 立威式：这朝堂的规矩，从今往后由她来定
  2. 破局式：满朝文武都没料到，这盘棋的执棋人是她
  3. 登顶式：史书会记住，这是第一位君临天下的女帝

## 五、红线与反模式
> 红线severity：弱

### 1. 避坑提示（不挂质检号、不扣分，仅创作提醒）
1. 避免恋爱脑女帝为男人弃江山，本末倒置，格局崩塌。
2. 避免权谋降智，夺权全靠男主出谋划策或出手，女帝名存实亡。
3. 避免登基过早，前期铺垫不足，权力来得突兀缺乏说服力。
4. 避免格局太小，只困于后宫争斗，撑不起"帝"的天下视野。

> 弱红线标签不挂全局质检号；上述风险若上升为崩级问题（如女性靠男人赢的价值观红线），由 anti-patterns.md 通用反模式兜底检测。
