## 二、变体素材库（仅参考·可自由组合·可原创·可豁免）
> 本节全部为灵感启发，**不强制命中、不作评分依据**，可自由组合/原创/豁免。

### 1. 节奏适配逻辑
常见节奏：入局 → 古风世界矛盾 → 情感/权谋博弈 → 收束。古装架空自由度高，重在古风美感与世界沉浸，称谓礼仪需自洽。付费节点可落在身份揭露、情感高潮、权谋反转、武侠对决等处——仅为参考。

### 2. 核心变体素材（任选，不限数量）
#### 场景素材
1. 宫廷场景：宫闱、御花园、宫宴的宫斗舞台
2. 江湖场景：客栈、山庄、门派、江湖集市的武侠世界
3. 宅门场景：高门内宅、闺阁、庭院的古言场景
4. 山水场景：竹林、湖畔、古镇的古风写意场景

#### 台词风格素材
1. 古风雅韵：诗意含蓄、古意盎然的台词风格
2. 称谓得体：符合架空古代的尊称、自称体系
3. 江湖快意：武侠向的洒脱、豪迈对白
4. 古言深情：古风浪漫、含蓄克制的情感表达

#### 行为逻辑素材
1. 礼仪规范：架空古代的尊卑、礼数行为逻辑
2. 江湖道义：恩怨情仇、侠义为先的武侠逻辑
3. 情感含蓄：符合古风基调的含蓄情感行为
4. 世界自洽：架空设定内部规则统一、不古今错乱

#### 付费卡点变体
1. 身份揭露节点
2. 情感高潮节点
3. 权谋/武侠对决节点

### 3. 钩子参考模板
- 开篇钩子参考：古风世界中一场相遇或变故，建立古韵氛围与悬念
- 集末钩子参考（仅启发）：
  1. 身份式：她的真实身份，将掀起一场风波
  2. 情感式：那一眼，注定了一生的纠缠
  3. 江湖式：一场江湖恩怨，即将拉开序幕

## 五、红线与反模式
> 红线severity：弱

### 1. 避坑提示（不挂质检号、不扣分，仅创作提醒）
1. 避免古装感缺失：台词、行为现代化，古风韵味荡然无存。
2. 避免世界观混乱：古今元素生硬拼接，架空设定自相矛盾。
3. 避免称谓礼仪错误：尊称、自称、礼数张冠李戴。
4. 避免背景虚化：只有古装皮、无场景落地，世界感空洞。

> 弱红线标签不挂全局质检号；上述风险若上升为崩级问题（如世界观硬伤），由 anti-patterns.md 通用反模式兜底检测扣分。
