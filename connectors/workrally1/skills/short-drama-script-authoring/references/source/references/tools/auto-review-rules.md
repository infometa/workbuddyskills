# 自动化质检规则手册（可脚本化落地）
## 检测逻辑说明
基于关键词频次、结构模式匹配、规则校验三层实现，对接现有文本拆分工具即可批量运行，输出初检报告，人工仅需复核异常项。

---

## 一、可100%自动化检测项
### 1. 表达重复检测
- 检测逻辑：统计固定短语、动作描写的出现频次
- 关键词库：耳尖泛红、大人英明、不可能、倒吸一口凉气等高频AI表达
- 判定规则：同一短语出现≥3次标记异常，连续2集出现标记严重
- 输出：重复短语+出现次数+对应集数

### 2. 篇幅合规检测（英文词数口径 · v8.8.0）
- 检测逻辑：按集拆分后统计每集英文词数（`wc -w` 口径）
- 判定规则：每集 <200 词标记不合格；转/合集 <300 词标记不合格（下限与节拍类型联动；篇幅一律按英文词数衡量，无中文字数口径，详见 `shared/base.md`）
- 输出：每集词数+不合格集数列表

### 3. 钩子合规检测
- 检测逻辑：匹配每集开头/结尾的冲突/悬念关键词
- 判定规则：开篇300字无冲突词、结尾无悬念词标记不合格
- 输出：钩子缺失集数列表

### 4. 人设铁律命中检测
- 检测逻辑：提取人设文件中的「人设铁律」关键词，反向检测剧本中是否出现违背行为
- 判定规则：出现明确违背铁律的行为标记人设漂移
- 输出：疑似漂移位置+对应铁律

### 5. 世界观逻辑检测
- 检测逻辑：匹配背景标签的「违禁词库」，如古代背景下检测：手机、电报、微信、公司等现代词汇
- 判定规则：出现违禁词标记逻辑硬伤
- 输出：违禁词+位置+违规说明

### 6. 能力膨胀通用检测（v3.2 新增）
- 检测逻辑：匹配通用超纲/万能化表述词库（无所不能、天下无敌、只手遮天等），全题材适配
- 判定规则：出现越界表述标记疑似能力膨胀；0 处满分，≤2 处中等，>2 处严重
- 输出：越界词+对应集数
- 局限：仅能抓显式膨胀表述；"突破前期终极上限""无关键节点凭空升级"需对照节点表人工复核

## 二、半自动化检测项（需简单模式匹配）
### 1. 剧情循环检测
- 检测逻辑：提取每轮冲突的「触发词-解法宝典词」二元组，对比结构相似度
- 模式示例：反派上门羞辱→身份曝光打脸；反派使坏→女主暗中救场
- 判定规则：相同二元组出现≥3次标记模式循环
- 输出：重复模式+对应轮次集数

### 2. 兜底依赖检测
- 检测逻辑：统计危机解决时，「配角出手」vs「主角自救」的次数占比
- 关键词库：暗中、悄悄、秘密、派人、男主/女主恰好赶到
- 判定规则：外力兜底占比>品类阈值标记异常
- 输出：兜底次数+占比+对应集数

### 3. 金手指公式化检测
- 检测逻辑：匹配发明/金手指出场的固定流程词：被质疑→成功→震惊
- 判定规则：相同流程出现≥3次标记公式化
- 输出：重复流程+对应集数

## 对接说明
- 可直接对接现有 `text_splitter.py`，按集拆分后逐集检测
- 支持批量跑批，一次检测100部剧本仅需数分钟
- 阈值可配置，不同品类/市场自动切换对应阈值

## 预留接口（v3.3 实现）
- **节点对齐检测**：需配套输入「关键节点关键词 + 对应集数范围」，检测核心事件是否落在关键节点集数区间内
- **相邻冲突路径重复检测**：需配套剧本的「冲突轮次」边界标记；按集检测会把正常的跨集冲突弧误判为重复，故待轮次标记格式确定后再实现
- 在此之前，节点对齐度、叙事单循环、能力越界（对照节点表）均列为人工复核项
