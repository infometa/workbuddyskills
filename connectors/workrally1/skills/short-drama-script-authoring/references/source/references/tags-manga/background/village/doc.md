## 一、创作素材指引

### 1. 节奏适配逻辑
常见节奏：返乡触发 → 被轻视/冲突 → 抓住机遇 → 致富/带富 → 打脸翻盘。付费节点可落在身份反差初显、首个致富突破、宗族冲突高潮等处。

### 2. 核心变体素材
#### 场景类型变体
1. 返乡创业型：城归者带资源/技术返乡
2. 种田致富型：经营田园、产业升级
3. 宗族恩怨型：家族权力、人情博弈
4. 田园治愈型：质朴生活、情感疗愈

#### 冲突模式变体
1. 城乡反差型：归来者与乡土观念的碰撞
2. 致富争利型：资源/土地/产业的争夺
3. 宗族压制型：旧势力对主角的打压与反击

### 3. 钩子参考模板
- 开篇钩子：衣锦还乡却被当成失败者
- 集末钩子参考：
  1. 反差式：被嘲笑的"穷小子"，签下了全村人的订单
  2. 反转式：那块没人要的荒地，藏着惊人价值

## 二、人设加成参考
1. 主角：低调返乡、暗藏实力或机遇，反差立人
2. 反派：宗族旧势力/势利同乡，动机贴合人情
3. 配角：质朴乡邻，承载情感共鸣与口碑反转
