## 一、创作素材指引

### 1. 节奏适配逻辑
常见节奏：乱世登场 → 冲突/危机 → 博弈/坚守 → 反转翻盘 → 情感/家国升华。付费节点可落在身份初露、首次反击/反转、情感关键转折等处。

### 2. 核心变体素材
#### 题材类型变体
1. 乱世情感型：豪门深情、聚散离合
2. 谍战悬疑型：身份伪装、情报博弈
3. 豪门恩怨型：世家权力、爱恨纠葛
4. 时代奋斗型：乱世中的个人命运

#### 冲突模式变体
1. 身份悬疑型：伪装/反间的多层反转
2. 情感坚守型：乱世中的深情相守
3. 权力博弈型：豪门/势力的明争暗斗

### 3. 钩子参考模板
- 开篇钩子：乱世之中，她嫁给了最危险的男人
- 集末钩子参考：
  1. 身份式：枕边人的真实身份，足以掀起惊涛骇浪
  2. 反转式：那场看似意外的相遇，原来步步是局
