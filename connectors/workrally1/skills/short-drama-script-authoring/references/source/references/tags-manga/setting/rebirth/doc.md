# 设定标签：重生 · 创作素材与采样库（漫剧）

> 本文全部为灵感启发，**不强制命中、不作评分依据**，可自由组合/原创/豁免。
> 权威规则（红线/互斥/叠加/融梗）见同目录 `meta.yaml`。

## 一、创作素材指引

### 1. 节奏适配逻辑
常见节奏：前世惨死/遗憾 → 重生回到关键节点 → 利用预知规避悲剧 → 布局改写命运。付费节点可落在重生瞬间、首次改变剧情、关键危机规避、前世仇人打脸等处。

### 2. 核心变体素材
#### 重生动机变体
1. 复仇型：前世被陷害致死，重生复仇打脸
2. 弥补型：前世错过重要的人/事，重生弥补遗憾
3. 逆袭型：前世底层落魄，重生抓住机遇登顶
4. 保命型：前世死于非命，重生规避危机活下去

#### 时间节点变体
1. 少年/学生期：回到人生起点，全面改写人生
2. 关键事件前：回到悲剧发生前夕，精准改变结局
3. 几年前：回到事业/感情转折点，重新选择

### 3. 钩子参考模板
- 开篇钩子：前世惨死/遗憾场景，紧接着重生回到过去
- 集末钩子参考：
  1. 预知式：这件事，和前世一模一样
  2. 反转式：她这一次，选了完全相反的路
  3. 危机式：她改变了一件事，却引出了更大的麻烦

## 二、人设加成参考
1. 主角：带着前世记忆，心智更成熟，行事有目标
2. 前世仇人/遗憾对象：重生后的核心目标人物
3. 变数人物：前世没有交集的人，成为新的剧情变量
