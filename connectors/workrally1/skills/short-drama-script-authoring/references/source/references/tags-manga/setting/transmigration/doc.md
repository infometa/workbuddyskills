## 一、创作素材指引

### 1. 节奏适配逻辑
常见节奏：穿越附身 → 接受身份与世界观 → 利用现代优势破局 → 立足新世界。付费节点可落在穿越身份揭晓、首次用现代知识打脸、核心危机化解、身世真相揭露等处。

### 2. 核心变体素材
#### 穿越类型变体
1. 魂穿型：附身到他人身上，继承原主恩怨
2. 身穿型：整个人穿越过去，身份成谜
3. 穿书型：穿进书本/剧情，知道剧情走向
4. 互穿型：与古代/异世界人互换身体，双向反差

#### 身份反差变体
1. 废柴逆袭型：穿越到废柴身上，靠现代知识逆袭
2. 冷宫后妃型：穿越到失宠后妃身上，靠智慧翻盘
3. 寒门士子型：穿越到穷苦书生身上，靠知识改变命运
4. 反派炮灰型：穿越成剧情反派/炮灰，规避死亡结局

### 3. 钩子参考模板
- 开篇钩子：现代场景意外死亡/昏迷，醒来身处异世界
- 集末钩子参考：
  1. 剧情式：她发现，自己穿进了看过的那本书里
  2. 身份式：原主的身份，根本不是普通人
  3. 危机式：她改变了剧情，剧情开始反噬了

## 二、人设加成参考
1. 主角：具备现代知识/技能，适应力强，破局有支撑
2. 原主：留下恩怨与伏笔，推动前期剧情
3. 本土角色：作为世界观对照组，反衬主角的特殊
