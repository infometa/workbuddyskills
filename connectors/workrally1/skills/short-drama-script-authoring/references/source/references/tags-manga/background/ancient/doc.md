## 一、创作素材指引

### 1. 节奏适配逻辑
常见节奏：身份/困境登场 → 冲突触发 → 智计布局 → 反转打脸 → 权力/情感升级。付费节点可落在身份初露、首次智计反击、核心反转揭晓等处。

### 2. 核心变体素材
#### 场景类型变体
1. 宫廷宫斗型：后宫权谋、帝王心术
2. 世家宅斗型：嫡庶之争、家族博弈
3. 江湖武林型：恩怨情仇、武力争锋
4. 朝堂权谋型：党争布局、家国天下

#### 冲突模式变体
1. 复仇翻盘型：含冤/落魄到逆袭雪耻
2. 智计博弈型：步步为营的权谋对决
3. 情感纠葛型：古风强强CP、爱恨交织

### 3. 钩子参考模板
- 开篇钩子：重生归来，这一世我要让负我之人血债血偿
- 集末钩子参考：
  1. 反转式：她设的局，对方到死都没看穿
  2. 身世式：那枚玉佩，揭开了惊天身世

## 二、人设加成参考
1. 主角：智计/隐忍/反差，避免无脑爽
2. 反派：高智商对手，动机与手段自洽
3. 配角：助力/阻力分明，服务权谋与情感
