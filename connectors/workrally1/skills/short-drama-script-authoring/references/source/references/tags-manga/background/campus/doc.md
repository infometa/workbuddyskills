## 一、创作素材指引

### 1. 节奏适配逻辑
常见节奏：校园日常 → 冲突/心动触发 → 成长/破局 → 蜕变升级 → 情感/热血高潮。付费节点可落在心动瞬间、首次逆袭、成长转折等处。

### 2. 核心变体素材
#### 题材类型变体
1. 青春纯爱型：心动、暗恋、双向奔赴
2. 热血逆袭型：学渣翻身、竞赛/体育热血
3. 成长治愈型：自我和解、友情羁绊
4. 校园悬疑型：青春外壳下的反转谜题

#### 冲突模式变体
1. 心动悸动型：情感拉扯与甜蜜
2. 逆袭蜕变型：从弱势到闪耀
3. 友情羁绊型：青春同行与成长

### 3. 钩子参考模板
- 开篇钩子：重回十七岁，这一次我不会再错过你
- 集末钩子参考：
  1. 心动式：他低头的瞬间，整个世界都安静了
  2. 逆袭式：被嘲笑的差生，模考杀进了年级前三

## 二、人设加成参考
1. 主角：青春质感、成长弧光清晰
2. 反派/对手：竞争或误会驱动，避免脸谱化
3. 配角：友情/情感的青春共鸣载体
