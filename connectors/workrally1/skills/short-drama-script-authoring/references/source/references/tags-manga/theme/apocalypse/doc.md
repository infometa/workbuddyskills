## 一、创作素材指引

### 1. 节奏适配逻辑
常见节奏：灾变爆发 → 初期求生 → 组队/建基地 → 资源争夺 → 危机升级。付费节点可落在首次直面灾变、核心物资争夺、异能/能力觉醒、终极危机暴露等处。

### 2. 核心变体素材
#### 灾变类型变体
1. 丧尸异种型：怪物侵袭，武力生存为主
2. 天灾末日型：极寒/洪涝/辐射等环境灾变，资源求生为主
3. 秩序崩塌型：社会规则瓦解，人性与权力博弈为主
4. 神秘复苏型：灾变伴随超自然觉醒，能力升级为主

#### 冲突模式变体
1. 资源争夺型：基地间为食物/武器/安全区爆发冲突
2. 人性考验型：绝境下的信任背叛、善恶抉择
3. 怪物攻坚型：对抗高阶异种/尸潮，武力突破
4. 基地建设型：从无到有搭建安全区，经营成长

#### 付费卡点变体
1. 灾变爆发节点：秩序瞬间崩塌的冲击感
2. 能力觉醒节点：绝境中获得生存底牌
3. 基地失守/夺回节点：核心生存地的存亡转折

### 3. 钩子参考模板
- 开篇钩子：日常场景突然爆发灾变，瞬间打破平静
- 集末钩子参考：
  1. 危机式：外面的敲门声，不是人
  2. 反转式：他以为的安全区，才是最危险的地方
  3. 觉醒式：濒死之际，他的身体发生了变化

## 二、人设加成参考
1. 主角：具备某类生存优势（能力/经验/信息差），但非无敌，成长有代价
2. 队友团：功能互补，各有立场与软肋，避免工具人
3. 反派：依托秩序崩塌攫取权力，动机符合人性逻辑
