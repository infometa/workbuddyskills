## 一、创作素材指引

### 1. 节奏适配逻辑
常见节奏：弱小时期受辱 → 获得机缘觉醒 → 快速升级打脸 → 进入更广阔舞台。付费节点可落在首次越级打脸、获得核心机缘、境界突破、大势力身份揭晓等处。

### 2. 核心变体素材
#### 体系方向变体
1. 宗门修仙型：宗门内竞争、秘境探险、正邪大战
2. 洪荒封神型：上古神话背景，圣人博弈、种族大战
3. 都市修仙型：现代都市背景，修仙者入世，反差爽感
4. 无敌流变体：开局较强，侧重格局展开与势力博弈

#### 爽点模式变体
1. 升级打脸型：境界提升后碾压曾经的对手
2. 秘境机缘型：探险获得宝物/传承，实力跃升
3. 身份反转型：隐藏的大佬身份/特殊血脉逐步揭露
4. 宗门争霸型：带领弱势宗门崛起，登顶势力之巅

#### 付费卡点变体
1. 境界突破节点：关键大境界突破，战力质变
2. 身份揭晓节点：隐藏血脉/传承曝光，全场震动
3. 大战转折节点：关键战役反败为胜，格局改写

### 3. 钩子参考模板
- 开篇钩子：主角受辱场景，埋下逆袭与升级的预期
- 集末钩子参考：
  1. 觉醒式：他体内的封印，终于裂开了
  2. 震惊式：废物？他竟是千年难遇的先天道体
  3. 危机式：宗门大劫，只有他能救

## 二、人设加成参考
1. 主角：有明确的升级目标，心性符合设定，升级有逻辑支撑
2. 对手：同境界有来有回，高境界有压迫感，不强行降智
3. 引路人/长辈：提供机缘与指引，非纯工具人送装备
