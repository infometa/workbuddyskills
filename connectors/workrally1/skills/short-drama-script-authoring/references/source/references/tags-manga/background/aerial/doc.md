# 背景标签：架空 · 创作素材与采样库（漫剧）

> 本文全部为灵感启发，**不强制命中、不作评分依据**，可自由组合/原创/豁免。
> 权威规则（红线/互斥/叠加/融梗）见同目录 `meta.yaml`。

## 一、创作素材指引

### 1. 节奏适配逻辑
常见节奏：世界登场 → 规则展现 → 主角破局 → 设定升级反转 → 权力/冒险高潮。付费节点可落在世界规则揭晓、首次借规则破局、世界观反转等处。

### 2. 核心变体素材
#### 世界类型变体
1. 架空王朝型：自设朝代权谋、宫斗宅斗
2. 玄幻世界型：力量体系、修炼争锋
3. 规则世界型：独特规则驱动的玩法
4. 多元宇宙型：跨世界、平行设定

#### 冲突模式变体
1. 规则博弈型：利用世界规则破局制胜
2. 身份逆袭型：架空阶层中的跃迁翻盘
3. 世界揭秘型：层层揭开世界观真相

### 3. 钩子参考模板
- 开篇钩子：这个世界的规则，和你想的完全不同
- 集末钩子参考：
  1. 设定式：原来整个世界，都是一场设定
  2. 反转式：他遵守的规则，本就是为他量身设计

## 二、人设加成参考
1. 主角：适应/利用世界规则，成长有逻辑
2. 反派：世界规则的既得利益者，动机自洽
3. 配角：承载世界观展示与情感推进
