## 一、创作素材指引

### 1. 节奏适配逻辑
常见节奏：反常现象出现 → 主角发现规则 → 利用规则破局 → 设定升级反转。付费节点可落在核心设定揭晓、首次利用设定破局、设定反转升级等处。

### 2. 核心变体素材
#### 设定类型变体
1. 规则类：世界存在隐藏规则，摸清规则才能生存/获利
2. 身份类：身份错位/灵魂互换/时间循环，认知反差
3. 能力类：非常规奇葩异能，副作用与收益并存
4. 世界观类：常识反转的平行世界，认知冲击

#### 爽点模式变体
1. 信息差型：主角独知设定，利用信息差碾压他人
2. 反转型：设定层层反转，每次以为懂了都有新真相
3. 猎奇型：反常识设定带来的新鲜感与冲击感

### 3. 钩子参考模板
- 开篇钩子：日常场景出现反常细节，勾起观众好奇心
- 集末钩子参考：
  1. 揭秘式：原来，这个世界的规则根本不是这样
  2. 反转式：他以为自己卡了bug，其实是掉进了陷阱
  3. 规则式：第三条规则，千万不要违反

## 二、人设加成参考
1. 主角：观察力强、逻辑在线，靠智商而非武力破局
2. 配角：作为普通认知对照组，反衬设定的反常
3. 规则制定者：隐藏的幕后存在，制造悬念
