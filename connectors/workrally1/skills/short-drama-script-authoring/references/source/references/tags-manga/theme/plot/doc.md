## 一、创作素材指引

### 1. 节奏适配逻辑
常见节奏：事件触发 → 矛盾升级 → 转折拉扯 → 结局闭环。付费节点可落在核心冲突爆发、关键真相揭晓、人物命运转折等处。

### 2. 核心变体素材
#### 叙事侧重变体
1. 家庭伦理型：亲情纠葛、家庭矛盾，贴近生活共鸣强
2. 情感纠葛型：多角情感拉扯，虐心与治愈交织
3. 命运沉浮型：人物人生起落，时代背景下的个人命运
4. 社会现实型：贴近现实议题，引发观众共情与讨论

#### 冲突模式变体
1. 误会拉扯型：信息差导致的误会，层层解开推动剧情
2. 抉择两难型：人物面临道德/情感两难选择，制造张力
3. 真相探寻型：隐藏真相逐步揭露，悬念贯穿始终

### 3. 钩子参考模板
- 开篇钩子：一个打破平静的突发事件，直接切入核心冲突
- 集末钩子参考：
  1. 真相式：他一直找的人，就在自己身边
  2. 抉择式：这一次，她必须选一个
  3. 反转式：原来所有的巧合，都是有人故意安排的

## 二、人设加成参考
1. 主角：有明确的目标与软肋，人物弧光清晰
2. 配角：各有立场与动机，不单纯为推动主角存在
3. 对立角色：有合理的行为逻辑，非脸谱化恶人
