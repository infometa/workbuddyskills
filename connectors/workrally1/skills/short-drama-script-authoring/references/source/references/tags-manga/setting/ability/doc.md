## 一、创作素材指引

### 1. 节奏适配逻辑
常见节奏：能力觉醒 → 隐藏试探 → 借能力破局 → 能力升级与代价显现。异能与现实生活的反差是爽点核心。付费节点可落在能力首次显威、身份/能力曝光、能力升级、对手同类异能者出现等处。

### 2. 核心变体素材
#### 异能爽点变体
1. 读心型：洞悉他人心声，先人一步
2. 预知型：预见危险或结果，提前布局
3. 操控型：操纵物体/元素，化解危机
4. 治愈型：异能救人于危难，扭转局面

#### 冲突模式变体
1. 隐藏暴露型：极力隐藏异能却险些曝光
2. 同类对决型：遇到另一异能者，能力正面碰撞
3. 被利用型：异能被觊觎，主角陷入被追猎处境
4. 代价反噬型：使用异能付出代价，制造两难

#### 人设风格变体
1. 低调藏拙型：能力强大却深藏不露
2. 反差萌型：普通身份反差出惊人异能
3. 成长觉醒型：从弱小异能逐步进化变强

### 3. 钩子参考模板
- 开篇钩子参考：平凡场景中主角不经意展露异能，建立反差与神秘感
- 集末钩子参考：
  1. 觉醒式：他发现自己，能听见别人心里的声音
  2. 危机式：有人盯上了他的能力
  3. 同类式：原来，世界上不止他一个人有异能

## 二、人设加成参考
1. 主角：异能有明确规则与边界，强而不无敌，使用有代价
2. 对手：同类异能者或觊觎能力者，制造对等张力
3. 知情者：少数知晓秘密的同伴，作为情感与剧情支点
