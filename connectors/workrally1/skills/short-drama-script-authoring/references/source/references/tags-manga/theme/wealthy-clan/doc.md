# 主题标签：豪门 · 创作素材与采样库（漫剧）

> 本文全部为灵感启发，**不强制命中、不作评分依据**，可自由组合/原创/豁免。
> 权威规则（红线/互斥/叠加/融梗）见同目录 `meta.yaml`。

## 一、创作素材指引

### 1. 节奏适配逻辑
常见节奏：底层闯入豪门 → 阶层冲突爆发 → 身份/能力反转 → 掌控格局。付费节点可落在身份揭晓、家族夺权、打脸名场面、身世真相等处。

### 2. 核心变体素材
#### 核心冲突变体
1. 真假千金型：身世错位，身份反转打脸
2. 家族夺权型：家产继承、派系斗争，权力博弈
3. 婚约拉扯型：商业联姻、先婚后爱，情感+利益交织
4. 上流打脸型：底层主角被轻视，凭实力碾压圈层偏见

#### 人设风格变体
1. 落魄真千金型：流落在外的豪门子女，回归后搅动格局
2. 豪门继承人型：背负家族责任，在权力与情感中抉择
3. 嫁入豪门型：普通女主闯入顶层，凭智商情商立足
4. 商界大佬型：杀伐果断的掌权者，掌控全局

#### 付费卡点变体
1. 身份揭晓节点：真千金/隐藏大佬身份曝光的瞬间
2. 夺权转折节点：核心权力交接的关键博弈
3. 打脸名场面：当众撕破伪装、碾压圈层偏见

### 3. 钩子参考模板
- 开篇钩子：底层女主意外闯入豪门场景，阶层反差瞬间拉满
- 集末钩子参考：
  1. 身份式：她才是老爷子找了二十年的亲孙女
  2. 反转式：这场宴会，就是为她设的局
  3. 打脸式：他看不起的穷丫头，竟是董事会新主席

## 二、人设加成参考
1. 主角：具备对应阶层的能力/气场，逆袭有支撑，不强行开挂
2. 反派：豪门内部竞争者，动机围绕利益/权力，而非纯坏
3. 长辈角色：家族掌权者，权衡利弊，推动核心剧情
