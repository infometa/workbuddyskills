## 一、创作素材指引

### 1. 节奏适配逻辑
常见节奏：身份铺垫 → 冲突触发 → 落差展现 → 反转打脸 → 情感/事业升级。付费节点可落在身份初露、首次打脸、核心反转、情感关键转折等处。

### 2. 核心变体素材
#### 场景类型变体
1. 豪门世家型：家族权力与情感纠葛
2. 商战职场型：职场博弈、商业对决
3. 市井烟火型：底层奋斗、邻里人情
4. 时尚名利型：娱乐/时尚圈的浮华与真实

#### 冲突模式变体
1. 阶层落差型：底层与上层的碰撞与跨越
2. 身份隐藏型：马甲大佬，层层揭晓
3. 情感纠葛型：豪门恩怨、爱恨情仇
4. 事业逆袭型：从谷底到巅峰的奋斗

#### 付费卡点变体
1. 身份初露节点：隐藏实力首次外显
2. 打脸高潮节点：反派认知崩塌的爽感
3. 情感反转节点：关系骤变的张力

### 3. 钩子参考模板
- 开篇钩子：被轻视的小人物，藏着惊人身份
- 集末钩子参考：
  1. 反转式：他随手掏出的，是足以颠覆全场的东西
  2. 悬念式：那个电话打来时，所有人都变了脸色
  3. 落差式：她以为攀上高枝，却不知对方深不可测

## 二、人设加成参考
1. 主角：明线弱势、暗线强大，反差塑造记忆点
2. 反派：依托阶层/资源傲慢，动机现实可信
3. 配角：服务阶层反差与情感推进，避免纯工具
