## 一、创作素材指引

### 1. 节奏适配逻辑
常见节奏：接到冒险任务 → 进入未知区域 → 遭遇危机解谜 → 获得收获+新线索。付费节点可落在进入核心区域、遭遇致命危机、关键解谜突破、宝物/真相揭晓等处。

### 2. 核心变体素材
#### 场景类型变体
1. 古墓探险型：盗墓寻宝，机关解谜+古墓危机
2. 荒野求生型：野外/无人区冒险，生存+探索
3. 秘境寻宝型：隐藏秘境探险，宝物+奇遇
4. 世界环游型：多地冒险解谜，单元化剧情

#### 团队模式变体
1. 专业小队型：各领域专家组队，功能互补闯关
2. 单人成长型：主角独自冒险，逐步成长变强
3. 意外卷入型：普通人意外卷入冒险，被动成长

### 3. 钩子参考模板
- 开篇钩子：一张地图/一个委托，开启未知冒险
- 集末钩子参考：
  1. 解谜式：机关的答案，他终于想通了
  2. 危机式：他们惊动了这里的守护者
  3. 真相式：这座墓的主人，根本不是普通人

## 二、人设加成参考
1. 主角：有对应冒险技能，成长弧线清晰
2. 队友：各有专长与软肋，团队互动有看点
3. 守关者/反派：守护秘密/争夺宝物，动机合理
