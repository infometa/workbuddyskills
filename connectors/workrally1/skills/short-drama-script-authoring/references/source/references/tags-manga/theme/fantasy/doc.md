# 主题标签：奇幻 · 创作素材与采样库（漫剧）

> 本文全部为灵感启发，**不强制命中、不作评分依据**，可自由组合/原创/豁免。
> 权威规则（红线/互斥/叠加/融梗）见同目录 `meta.yaml`。

## 一、创作素材指引

### 1. 节奏适配逻辑
常见节奏：进入异世界/觉醒魔法 → 组建队伍 → 冒险历练 → 对抗终极黑暗。付费节点可落在魔法觉醒、种族身份揭晓、关键战役、世界观真相揭露等处。

### 2. 核心变体素材
#### 世界观变体
1. 西幻魔法型：魔法师、骑士、龙族，经典剑与魔法体系
2. 种族共存型：人类、精灵、兽人等多种族博弈与冒险
3. 学院奇幻型：魔法学院背景，学习+竞争+冒险
4. 都市奇幻型：现代都市隐藏魔法世界，双线并行

#### 爽点模式变体
1. 魔法升级型：魔法能力从弱到强，解锁高阶法术
2. 组队冒险型：伙伴互补，共同闯关成长
3. 身份宿命型：特殊血脉/预言之子，背负宿命成长
4. 奇观探索型：探索异世界秘境，展现奇幻世界观

### 3. 钩子参考模板
- 开篇钩子：普通人闯入奇幻世界，或日常场景暴露魔法存在
- 集末钩子参考：
  1. 觉醒式：她的眼睛里，浮现出了龙族的竖瞳
  2. 宿命式：预言里的救世主，就是他
  3. 危机式：魔法结界破了，人类城市暴露了

## 二、人设加成参考
1. 主角：有特殊天赋/身份，成长有弧线，非开局无敌
2. 伙伴团：不同种族/职业互补，各有性格与故事
3. 反派：有自身立场与目标，非单纯的邪恶符号
