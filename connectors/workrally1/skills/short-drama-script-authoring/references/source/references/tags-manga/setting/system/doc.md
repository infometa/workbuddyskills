# 设定标签：系统 · 创作素材与采样库（漫剧）

> 本文全部为灵感启发，**不强制命中、不作评分依据**，可自由组合/原创/豁免。
> 权威规则（红线/互斥/叠加/融梗）见同目录 `meta.yaml`。

## 一、创作素材指引

### 1. 节奏适配逻辑
常见节奏：系统绑定 → 新手任务试水 → 任务升级成长 → 系统终极真相。付费节点可落在系统激活、首次任务奖励、关键能力解锁、系统升级等处。

### 2. 核心变体素材
#### 系统类型变体
1. 升级流系统：量化能力/修为，完成任务升级变强
2. 资源发放系统：以金钱/装备/资源为奖励，获取即变强（神豪、囤货、抽奖等均属此类，机制可自由原创）
3. 定时反馈系统：以固定周期或固定动作触发奖励，强调"稳定累积、轻松成长"（每日打卡、定点领取、连续坚持等均属此类，触发方式可自由原创——切忌套用"签到"这一种固定包装）
4. 任务惩罚系统：完不成任务有惩罚，倒逼主角行动

#### 任务模式变体
1. 打脸任务：完成打脸场景获得奖励
2. 选择任务：多选项抉择，不同选择不同奖励
3. 主线任务：贯穿全程的大目标，分步解锁
4. 随机任务：突发任务制造意外剧情

### 3. 钩子参考模板
- 开篇钩子：主角低谷时，脑海中响起系统提示音
- 集末钩子参考：
  1. 激活式：【叮！系统已绑定成功】
  2. 奖励式：【任务完成，获得终极奖励】
  3. 真相式：系统的来历，根本不简单

## 二、人设加成参考
1. 主角：借助系统成长，但自身有主观能动性，不全靠系统
2. 系统：有明确的规则与语气设定，服务剧情而非喧宾夺主
3. 任务目标人物：推动剧情发展，形成核心冲突
