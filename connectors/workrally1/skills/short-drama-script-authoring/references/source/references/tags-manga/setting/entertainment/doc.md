# 设定标签：娱乐圈 · 创作素材与采样库（漫剧）

> 本文全部为灵感启发，**不强制命中、不作评分依据**，可自由组合/原创/豁免。
> 权威规则（红线/互斥/叠加/融梗）见同目录 `meta.yaml`。

## 一、创作素材指引

### 1. 节奏适配逻辑
常见节奏：入行/低谷 → 凭借实力崭露头角 → 应对黑料与竞争 → 登顶巅峰。付费节点可落在首次爆红、打脸黑料、奖项加冕、身份揭晓等处。

### 2. 核心变体素材
#### 成长路线变体
1. 逆袭爆红型：十八线小透明靠实力/机遇逆袭成顶流
2. 重生归来型：前世被陷害，重生复仇+重回巅峰
3. 隐藏身份型：大佬隐退/新人入行，真实身份震惊娱乐圈
4. 双强联手型：两位顶流强强联合，事业爱情双丰收

#### 冲突模式变体
1. 竞品拉踩型：同期艺人互撕、买黑料、抢资源
2. 狗仔八卦型：恋情/身份被曝光，公关危机
3. 资本博弈型：资本介入行业，主角对抗资本
4. 粉丝风波型：粉丝互撕、塌房危机等现实向冲突

### 3. 钩子参考模板
- 开篇钩子：主角低谷/被黑场景，埋下逆袭爆红预期
- 集末钩子参考：
  1. 爆红式：一夜之间，她全网爆火了
  2. 身份式：那个新人，竟是隐退三年的影后
  3. 危机式：她的恋情，被狗仔拍下来了

## 二、人设加成参考
1. 主角：有对应专业能力，成名有支撑，人设不悬浮
2. 对家/反派：同赛道竞争者，动机围绕资源与名气
3. 大佬/资本方：行业顶层力量，推动核心剧情
