## 一、创作素材指引

### 1. 节奏适配逻辑
常见节奏：谷底受辱 → 获得转机 → 逐步翻盘 → 巅峰打脸。付费节点可落在首次打脸、身份揭晓、核心对决、登顶巅峰等处。

### 2. 核心变体素材
#### 逆袭驱动变体
1. 能力觉醒型：获得异能/系统/传承，能力驱动阶层跨越
2. 信息差型：重生/穿越带来预知，靠信息差快速崛起
3. 身份揭晓型：隐藏的真实身份曝光，地位反转
4. 奋斗成长型：靠自身努力与智商，一步步逆袭登顶

#### 低谷类型变体
1. 废柴流：被轻视的底层/废物，证明自身价值
2. 落魄流：曾经辉煌跌落谷底，东山再起
3. 替罪流：被陷害背锅，沉冤得雪+实力反杀
4. 赘婿流：上门女婿被轻视，隐藏实力展露反转

#### 付费卡点变体
1. 首次打脸节点：第一次正面碾压曾经的欺凌者
2. 身份揭晓节点：隐藏身份/实力曝光，全场震惊
3. 终极翻盘节点：彻底扭转局面，登顶巅峰

### 3. 钩子参考模板
- 开篇钩子：主角受辱/低谷场景，埋下逆袭预期
- 集末钩子参考：
  1. 觉醒式：三年期满，他的真实身份藏不住了
  2. 打脸式：刚才看不起他的人，现在高攀不起了
  3. 反转式：这场局，从一开始就是他布的

## 二、人设加成参考
1. 主角：低谷时心性坚韧，逆袭后不悬浮，成长有迹可循
2. 反派：前期足够嚣张，形成强烈反差，行为逻辑自洽
3. 旁观者：作为态度反转的对照组，放大逆袭爽感
