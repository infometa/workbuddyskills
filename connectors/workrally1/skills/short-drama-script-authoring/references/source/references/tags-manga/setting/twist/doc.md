## 一、创作素材指引

### 1. 节奏适配逻辑
常见节奏：建立初步认知 → 出现疑点 → 第一层反转 → 更深层真相揭露。付费节点可落在首次反转、身份真相揭晓、终极反转等处。

### 2. 核心变体素材
#### 反转类型变体
1. 身份反转：人物真实身份与表象完全不同
2. 立场反转：好人变坏人、反派变正派，立场颠覆
3. 剧情反转：事件真相与表象完全相反
4. 世界观反转：整个世界的设定被推翻重构

#### 反转层级变体
1. 单层反转：一个核心真相，结尾揭晓
2. 多层反转：层层递进，每次以为是真相都有新反转
3. 循环反转：无限套娃，真相不断颠覆

### 3. 钩子参考模板
- 开篇钩子：看似正常的场景，埋下一个可疑细节
- 集末钩子参考：
  1. 身份式：他的真实身份，所有人都猜错了
  2. 真相式：原来，他才是幕后黑手
  3. 颠覆式：我们所以为的真相，全是假的

## 二、人设加成参考
1. 主角：观察力强，逐步接近真相
2. 反转核心人物：表象与真实身份有反差，铺垫合理
3. 线索提供者：释放真假参半的信息，引导观众判断
