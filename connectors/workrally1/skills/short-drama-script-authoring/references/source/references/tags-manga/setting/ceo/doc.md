## 一、创作素材指引

### 1. 节奏适配逻辑
常见节奏：意外相遇 → 身份反差冲突 → 男主动心反差 → 情感拉扯确定关系。付费节点可落在总裁身份揭晓、首次强势护妻、心动名场面、关系确认等处。

### 2. 核心变体素材
#### 人设风格变体
1. 霸道冷总型：杀伐果断不近人情，唯独对女主例外
2. 腹黑隐忍型：心思深沉布局，女主是唯一变数
3. 温柔总裁型：成熟稳重温柔治愈，默默守护女主
4. 契约婚姻型：先婚后爱，协议关系逐步动心

#### 互动模式变体
1. 契约关系型：协议恋爱/婚姻，假戏真做
2. 职场上下级型：女主是员工/助理，办公室恋情
3. 英雄救美型：女主遇困，总裁强势出手解围
4. 追妻火葬场型：前期冷漠伤害，后期卑微追回

### 3. 钩子参考模板
- 开篇钩子：普通女主意外得罪大佬，埋下身份反差预期
- 集末钩子参考：
  1. 身份式：她得罪的人，竟是集团总裁
  2. 心动式：他第一次，对一个女人动了心
  3. 反转式：这场契约婚姻，他早就动了真心

## 二、人设加成参考
1. 男主：商业能力在线，行事符合身份，爽感不油腻
2. 女主：有独立人格与闪光点，不是纯依附男主
3. 男配/情敌：作为对照组，反衬男主的优势与特殊
