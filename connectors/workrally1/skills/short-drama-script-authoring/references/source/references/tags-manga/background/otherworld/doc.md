## 一、创作素材指引

### 1. 节奏适配逻辑
常见节奏：穿越/降临 → 适应世界 → 力量成长 → 冒险征服 → 世界高潮。付费节点可落在初入异界冲击、首次力量觉醒、关键冒险突破等处。

### 2. 核心变体素材
#### 世界类型变体
1. 魔法奇幻型：魔法体系、骑士/法师争锋
2. 兽人精灵型：多种族世界、种族博弈
3. 剑与魔法型：冒险打怪、副本征服
4. 异界经营型：种田/建国/经营成长

#### 冲突模式变体
1. 力量成长型：从弱到强的修炼逆袭
2. 世界探索型：未知地图与谜题征服
3. 种族争锋型：势力/种族间的博弈

### 3. 钩子参考模板
- 开篇钩子：睁眼已是异世界，而我手握逆天金手指
- 集末钩子参考：
  1. 觉醒式：濒死之际，他体内的力量彻底苏醒
  2. 反转式：他以为的新手村，竟是世界的中心

## 二、人设加成参考

3. 配角：异界伙伴，承载世界观与情感
