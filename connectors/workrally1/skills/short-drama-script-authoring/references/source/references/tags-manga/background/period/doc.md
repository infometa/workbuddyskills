## 一、创作素材指引

### 1. 节奏适配逻辑
常见节奏：时代登场 → 困境/机遇 → 抓住红利 → 奋斗逆袭 → 家国/情感升华。付费节点可落在机遇初现、首次创业突破、命运转折等处。

### 2. 核心变体素材
#### 时代类型变体
1. 改革创业型：下海经商、抓住政策红利
2. 知青返城型：时代洪流中的个人奋斗
3. 工厂大院型：集体生活、人情冷暖
4. 家庭奋斗型：几代人的命运变迁

#### 冲突模式变体
1. 时代机遇型：先知/眼光带来的信息差爽感
2. 阶层跃迁型：白手起家到事业有成
3. 情感坚守型：年代纯爱、聚散离合

### 3. 钩子参考模板
- 开篇钩子：重回那个一切都还来得及的年代
- 集末钩子参考：
  1. 先知式：所有人都不看好的生意，他偏要做
  2. 转折式：一封信，改变了整个家庭的命运

## 二、人设加成参考
1. 主角：怀揣远见/坚韧奋斗，贴合时代精神
2. 反派：守旧势力/投机者，动机符合年代逻辑
3. 配角：承载亲情/爱情/友情的时代共鸣
