## 一、创作素材指引

### 1. 节奏适配逻辑
常见节奏：科技事件爆发 → 主角卷入危机 → 利用技术破局 → 揭示科技真相。付费节点可落在核心科技揭晓、首次技术对抗、危机升级、真相揭露等处。

### 2. 核心变体素材
#### 科技方向变体
1. 星际机甲型：宇宙航行、机甲战斗、星际文明博弈
2. 赛博朋克型：近未来都市、义体改造、资本与科技垄断
3. 时间空间型：时间穿越、平行宇宙、空间折叠
4. 生物科技型：基因改造、意识上传、变异进化

#### 冲突模式变体
1. 文明对抗型：人类与外星文明、AI与人类的生存博弈
2. 技术阴谋型：科技公司隐藏阴谋，主角揭露真相
3. 末世危机型：科技灾难导致世界崩坏，绝境求生
4. 竞技升级型：机甲/异能竞技，技术成长升级

### 3. 钩子参考模板
- 开篇钩子：日常场景出现超现实科技事件，打破认知
- 集末钩子参考：
  1. 真相式：这项技术，根本不是人类发明的
  2. 危机式：AI觉醒了，它的第一个目标是他
  3. 反转式：他以为的现实，其实是虚拟世界

## 二、人设加成参考
1. 主角：具备对应科技领域能力/特殊体质，破局有支撑
2. 技术方：科技公司/科研组织，立场复杂，非纯善恶
3. 对立者：掌握更高科技的对手，形成压迫感
