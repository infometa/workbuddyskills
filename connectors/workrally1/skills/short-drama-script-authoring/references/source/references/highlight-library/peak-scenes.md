# 高光名场面范式库（peak-scenes）

> **状态：v6.0.0 空骨架（待填充）。** 录入规范见 `INDEX.md` 第 3 节。
> 本库提炼名场面的**情绪曲线与调度技法**，不照搬具体剧情。仅供采样，不参与评分。

## 使用说明

名场面 = 情绪积累到临界点的集中释放。本库按"场面类型"分区，每条拆解：**情绪铺垫 → 引爆点 → 调度/视觉呈现 → 余韵**。漫剧场景额外标注"分镜/视觉钩子"。
