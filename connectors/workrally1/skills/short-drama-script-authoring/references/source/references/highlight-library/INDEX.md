# 高光范式素材库 · 总索引（INDEX）

> **状态：v6.0.0 空骨架（待填充）。** 本目录用于沉淀顶级爆款的「高光片段 / 神台词 / 反转设计 / 名场面」，作为创作时的**采样灵感库**。
> 当前内容为空，仅搭建结构与录入规范，后续逐步人工/半自动填充。

## 1. 定位与原则

- **采样而非命中**：本库内容是灵感启发，**不强制命中、不参与评分、不作质检依据**。与 `tags/` 的强规则体系严格分离。
- **去时效化偏见**：大模型知识有滞后性且偏大众，难以稳定给出"真正顶级"的片段。本库用于补足——沉淀经人工确认的高质量范式，对冲模型的平庸与滞后。
- **版权安全**：录入时**只提炼"范式/结构/技法"，不照搬原文台词**。神台词以"句式模板 + 改写示例"形式存储，规避版权风险。
- **可溯源**：每条素材标注来源类型（剧名打码/题材/年份段），便于评估时效与代表性。

## 3. 录入规范（填充时遵循）

每条素材统一字段：

```
- id: HL-<类别><编号>          # GL=神台词 RV=反转 PS=名场面
  category: 神台词|反转设计|名场面
  tags: [关联标签id ...]         # 对齐 tags/ 或 tags-manga/ 的 id
  scene: 适用场景              # 如：打脸高潮 / 身份揭晓 / 绝境翻盘
  pattern: 范式提炼            # 结构/技法的抽象描述（非原文）
  template: 句式/结构模板       # 可复用的填空式模板
  example: 改写示例            # 原创改写，规避版权
  source_type: 来源类型        # 题材/年份段，不写完整剧名
  note: 使用提示/避坑
```

## 4. 后续填充路径（备忘）

1. 人工精选：团队挑选确认的爆款，按范式拆解录入（最高质量，慢）。
2. 半自动：用模型批量产出候选 → 人工筛选确认后入库（量大，需把关）。
3. 反馈回流：实际生成中表现好的桥段/台词，回流沉淀为新素材。
