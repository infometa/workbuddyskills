> 本库提炼反转的**结构与铺垫技法**，不照搬具体剧情。仅供采样，不参与评分。

## 使用说明

反转的爽感 = 意料之外 + 情理之中。本库按"反转类型"分区，每条拆解：**铺垫埋点 → 误导手法 → 揭晓时机 → 二次冲击**。
