# 竖屏漫剧创作规范

> 命中漫剧载体（漫剧/动态漫/漫画剧本/分镜/条漫）时，由 `decision-tree.md` 载体分流加载本文件。
> **复用关系**：漫剧 = 竖屏短剧全部节奏规则（步骤 0-5、弹簧、钩子、关键节点、冲突轮换、反模式全部继承）+ 本文件的视觉化补充。本文件**只写差异项**，不重复短剧通用规则。

## 定位

适配竖屏动态漫、条漫剧本创作。漫剧靠"画面 + 分镜 + 强反差视觉冲击"承载爽点，对白承载比短剧更低，因此在标准短剧剧本之上强化视觉化表达。

## 人设强制新增字段（在 `2-character.md` 基础上）

所有核心角色除短剧标准字段外，必须补充「视觉识别特征」，便于分镜稳定作画：

- **标志性外形**：发色 / 瞳色 / 纹饰 / 体格
- **标志性服饰道具**：可一眼认出该角色的服装、配饰、武器或随身物
- **能力触发视觉变化**：异能觉醒（瞳孔变色 / 纹路浮现）、系统激活（弹窗特效 / 光效），形成可重复的视觉记忆点

## 剧本格式补充（在 `3-script.md` 标准格式基础上）

每集剧本正文不变（场次 + 动作 + 台词），但**每集末尾新增「核心分镜提示」**，供作画/分镜参考：

```
【分镜提示】
1. 开篇镜头：（画面描述 + 运镜，对应 5 秒钩子）
2. 高潮镜头：（画面描述 + 特效要求，对应放弹簧爽点）
3. 结尾定格：（钩子画面 + 留白设计，对应结尾悬念）
```

> 注意：分镜提示属于"漫剧专属交付物"，与短剧"设计说明为内部底稿"不同——漫剧的分镜提示**需要交付给用户/作画方**，因为它是漫剧的核心生产指令。

## 漫剧专属子类型库（v4.0 新增）

> 漫剧除继承所有真人短剧题材的子方向菜单外，因 AI 作画的视觉优势，另有**漫剧更适配的专属子类型**。步骤 0 选题时，若用户选漫剧载体且说"随意"，优先从下列漫剧高适配子类型中按"三分类策略"展示选项（详见 `references/domestic/INDEX.md`）。

漫剧的视觉化优势使其在以下题材上比真人短剧更具性价比与表现力：

| 漫剧专属子类型 | 关联真人题材 | 适配理由 | 推荐子方向 |
|---|---|---|---|
| **玄幻修仙升级** | 古装传奇/玄幻 | 真人服化道/特效贵，AI 漫剧可低成本呈现境界/法术/秘境 | 废柴逆袭修仙型、仙侠虐恋型 |
| **异能觉醒** | 马甲/逆袭 | 异能视觉符号（瞳变/纹路/光效）是漫剧记忆点核心 | 能力觉醒型、多重马甲连爆型 |
| **末世废土** | 都市逆袭（延伸）| 大场景废墟/丧尸/机甲，真人难拍，漫剧沉浸感强 | 末世求生型、末世囤货种田型 |
| **星际/科幻** | 古装玄幻（延伸）| 飞船/星球/未来战争，AI 漫剧视觉天花板高 | 星际争霸型、星际联姻型 |
| **神话志怪** | 古装传奇/玄幻 | 神兽/妖魔/上古神祇造型自由度高 | 神话宿命型、人妖虐恋型 |
| **国风古言** | 豪门恩怨/大女主 | 古装造型唯美，漫剧条漫质感佳 | 乱世大女主型、权谋宫廷型 |

### 漫剧专属子类型的视觉桥段补充

漫剧专属子类型在继承关联真人题材子方向桥段池的基础上，强化以下**视觉化桥段**（每部至少命中 3 个）：

*视觉爽点桥段池*：
- 能力/法术释放的标志性视觉特效（专属符号重复出现）
- 境界突破/形态进化的画面蜕变
- 大场景全景镜头（秘境/废土/星海/仙山）与人物特写交替
- 反差对比的视觉冲击（破衣↔华服、废柴↔大佬、凡人↔神祇）
- 终极形态/终极马甲揭晓的"满屏震撼"定格

### 漫剧子类型差异化提醒

1. 漫剧子类型选定后，**视觉识别特征与能力视觉符号必须先于剧情设计确定**（写进人设强制字段）
2. 末世/星际/科幻等"漫剧原生子类型"无真人对标，需自建世界观一句话规则（参考 `domestic/combos/ancient-fantasy.md` 世界观轻量化原则）
3. 同一漫剧子类型连续创作时，**视觉符号体系必须差异化**（同为异能不得都用"瞳孔变红+黑色纹路"），避免漫剧层面的视觉同质化

## 漫剧专属标签库（v6.0.0 新增 · 强制对接）

漫剧创作的题材标签**不再复用国内真人标签库 `tags/`，改用独立的漫剧标签库 `references/tags-manga/`**（25 个标签：主题 8 + 设定 8 + 背景 9）。该库专为漫剧的视觉化优势设计，每个标签含 `manga` 扩展块。

- **加载方式**：步骤 1 选定标签时，先读 `references/tags-manga/registry.yaml` 全局索引定位目录 → 再读 `tags-manga/{category}/{id}/meta.yaml` 取权威规则（红线/互斥/叠加/融梗 + `manga` 视觉块）→ 需灵感时读同目录 `doc.md` 采样。
- **数据契约**：所有 meta.yaml 受 `references/common-tags/schema/tag.schema.json` 约束，`carrier` 字段固定为 `manga`。
- **视觉块直接喂分镜**：每个标签 `meta.yaml` 的 `manga.visual_signature` / `manga.visual_hooks` 直接作为本文件「核心分镜提示」与「视觉识别特征」的素材来源，避免凭空设计视觉符号。
- **索引自动派生**：新增/修改标签后须重跑 `scripts/build_registry.py` 重建索引，保证"索引永远指向真实文件"。

> 真人短剧仍走 `tags/`；漫剧走 `tags-manga/`。两库结构同构（meta.yaml + doc.md），但题材偏好与视觉块不同，不得混用。

## 漫剧爽点强化规则

1. **异能 / 系统 / 玄幻类**：能力释放设计专属视觉符号，重复出现形成记忆点（呼应 `shared/conflict-variants.md` 觉醒类差异化模板，避免每次释放画面雷同）
2. **豪门 / 总裁类**：反差场面强化视觉对比（破衣 vs 西装、出租屋 vs 别墅全景、地铁 vs 私人飞机）
3. **末世 / 冒险类**：大场景与人物特写交替，营造沉浸感与压迫感

## 避坑红线（漫剧专项，叠加在短剧反模式之上）

1. 禁止大段纯对话且无画面变化（漫剧最忌"广播剧配静图"）
2. 内心独白单集不超过 3 句，能用动作/画面/分镜表达的不写独白
3. 能力 / 反转场面必须有明确视觉冲击设计，不能只靠台词描述"很强"
4. 视觉识别特征前后必须一致（同一角色发色/标志道具不得无理由变化）

## 与短剧的硬指标对齐

- 单集时长、篇幅下限（英文词数口径）、弹簧二选一、5 秒钩子、付费点位置等硬指标**与短剧完全一致**（见 `shared/base.md` 与 `stages/3-script.md`）
- 节点对齐、能力边界、冲突轮换、AI 反模式检测**全部沿用短剧体系**，不另设标准
