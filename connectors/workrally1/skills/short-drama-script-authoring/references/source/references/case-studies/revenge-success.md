# 短剧·复仇题材成功案例库

> 本文件为模板，待用户填充真实爆款案例。每个案例按下面的结构填写。

## 一、爆款共性公式（基于行业观察总结）

### 1. 标准开场结构

```
0-15s：主角在最低处被极度羞辱（前未婚妻嘲讽 / 同事踩踏 / 亲戚势利）
15-45s：主角默默承受，但一个细节暗示其不一般（手机来电显示"董事长"/西装内衬绣字/接到神秘电话）
45-90s：羞辱升级到顶点
90s-末：第三方人物出现，瞬间揭穿主角身份
```

### 2. 人物配置黄金组合

- **主角**：表面身份（穷小子/服务员/落魄老人）+ 隐藏身份（千亿集团董事长/家族唯一继承人/传奇战神）
- **核心反派**：嚣张气焰拉满 + 人品恶劣 + 能力其实有限
- **关键见证人 A**：早期质疑主角的群众（前同事/前未婚妻/势利亲戚）
- **关键见证人 B**：突然出现揭穿主角身份的"工具人"（董秘/总裁/老朋友）

### 3. 卡点位置（80 集模板）

| 集数 | 事件 | 类型 |
|---|---|---|
| 1 | 主角被极度羞辱（开篇钩子拉满） | 压 |
| 5 | 第一次小反击（轻微露能力） | 放（小） |
| 10 | **付费点 1**：身份初次暴露给一个见证人 | 放（中）+ 大悬念 |
| 20 | **付费点 2**：核心反派对主角下狠手 | 压（极） |
| 25-30 | **付费点 3**：身份大公开 + 第一次大规模打脸 | 放（极） |
| 40-50 | 反派绝地反扑，主角看似失败 | 压 |
| 60-70 | 终极反转，反派彻底崩溃 | 放 |
| 75-80 | 余波处理 + 圆满结局 | 平稳 |

### 4. 必备打脸桥段（每部至少 5 个）

- [ ] 餐厅装穷被嘲笑 → 经理认出 90 度鞠躬
- [ ] 前任带新欢炫耀 → 主角带更强配偶/伴侣出现
- [ ] 同学聚会被看不起 → 接到下属"X 总，公司急事"电话
- [ ] 反派对主角动手 → 主角随手化解 + 反派惨叫
- [ ] 反派家族施压 → 主角一通电话让对方家族崩盘
- [ ] 反派拿合同/视频威胁 → 主角早有更狠的反制
- [ ] 反派当众宣判主角"完了" → 大佬集体出现支持主角
- [ ] 反派炫耀名表名车 → 主角的座驾/收藏让反派脸绿
- [ ] 反派踩踏主角自尊 → 主角揭露反派的破产真相

## 三、反面案例（避坑）

### 常见失败模式

| 失败模式 | 具体表现 | 后果 |
|---|---|---|
| 打脸过早 | 第 3 集就揭身份 | 后面 70 集没爽点可写 |
| 反派过弱 | 一开始就明显智商不在线 | 主角打脸不够爽 |
| 无脑爽 | 主角全程开挂没有"被压制"过程 | 观众无共情 |
| 打脸后台词冗长 | 反派长篇道歉、主角长篇说教 | 节奏崩溃 |
| 见证人缺失 | 打脸场景没有第三方目睹 | 爽感打折 |
| 套路重复 | 每集都是"被嘲笑→揭身份" | 第 10 集观众弃剧 |
| 主角身份变化 | 一会儿是董事长一会儿是战神 | 设定崩坏 |
