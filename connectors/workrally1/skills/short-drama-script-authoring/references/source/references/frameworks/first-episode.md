# 第一集专项创作法（引流集 · 独立结构 · 最高优先级）

> **[作用域：全局 · 中英通用 · 短剧+漫剧通用]** 本文件是**第一集**创作的唯一真相源。步骤 3 写第 1 集时必读；hook-design.md「首集开篇黄金 3-10 秒」是本文件第二节模块1的细化，不重复维护。

## 🔴 第一集的定位：它不是"第 1 个情节单元"，是独立引流集

竖屏付费短剧（单集 1-2 分钟，前 2-5 集免费引流）的第一集逻辑和传统影视剧**完全不同**：传统剧可以慢慢铺垫人物与世界观，短剧第一集的唯一核心使命是**「3 秒留人、结尾勾人」**，所有内容都服务于用户留存与后续付费转化。

**结构上的关键裁定（治规则打架）**：
- **第一集是一个"起承转合俱全的独立引流集"**——它自己就要在 90 秒内完成"钩住→立人→引爆→留悬念"的完整闭环，**这是唯一允许、且必须的单集闭环**。
- **情节单元制（一个事件跨 2-8 集）从第 2 集起才生效**。第一集不受"禁一集一事件 / 禁单集自闭环"（R13 / 反模式13 / 铁律14）约束——那几条针对的是第 2 集起的正片节奏。
- **第一集埋下的核心主线矛盾，从第 2 集开始才展开为跨 2-8 集的情节单元**。即：第一集"引爆"矛盾（如复仇剧第1集就被害），第2集起进入"隐忍取证→步步紧逼→当众反击"的跨集单元。
- 一句话记忆：**第一集独立打透钩子，第二集起接情节单元制。**

## 一、第一集必须完成的 4 件核心事（缺一即不合格）

### 1. 秒级留存功能
短剧是信息流分发场景，用户是"刷到"而非"主动点开"，**前 3 秒决定 80% 的去留**。第一集必须在用户划走之前，用强视觉、强情绪、强冲突拦住用户，让他产生"这是怎么回事"的好奇心。

### 2. 叙事奠基功能
用最少的信息快速完成三件事：**立住主角人设、讲清核心处境、奠定全剧调性**（虐恋/爽剧/悬疑/玄幻），让观众立刻知道"我该代入谁、这剧是什么路子"，精准筛选目标受众。

### 3. 冲突引爆功能
第一集必须把全剧的**核心主线矛盾直接打透**，绝不能"先铺垫两集再出事"——复仇剧第一集就要被害，赘婿剧第一集就要受辱，虐恋剧第一集就要被抛弃，把主角直接逼到绝境。

### 4. 下集转化功能
第一集结尾是第一道留存关口。**一个足够硬的悬崖式悬念**，直接决定下一集播放率，是用户从"随便看看"到"追更"、从免费集到付费集的关键转折点。

## 二、第一集必须包含的 5 个核心模块（以 90 秒单集为例的时间轴）

> 时间节点按 90 秒（1 分 30 秒）标准单集给。85 秒不是硬边界，随单集时长按比例缩放；模块顺序与功能不可省、不可乱。篇幅口径仍按 `shared/base.md`：**首集与其它集同体量 200-448 词（英文词数口径），不特殊加长**。

### 模块1 · 开篇黄金 3 秒：暴击钩子
- **内容**：零铺垫直接上最强冲突画面、最炸裂台词、最反常识场景。
- **作用**：拦住划屏用户，强制停留。
- ✅ 正面：婚礼现场新娘被当众甩耳光 / 浑身是血的女人从悬崖边抬头 / 废柴女婿一巴掌打在总裁岳父脸上。
- ❌ 反面：主角起床刷牙 / 开车赶路 / 风景空镜 / 慢镜头走路。
- 细化见 `hook-design.md`「首集开篇黄金 3-10 秒」（3 秒法则 + 10 秒法则 + 零铺垫检测）。

### 模块2 · 5-30 秒：主角身份 + 核心困境
- **内容**：用最少信息讲清「主角是谁、为什么在这里、当下最惨的处境是什么」，只保留和当前强相关的背景，多余前史全部砍掉。
- **作用**：快速建立共情，让观众明确代入对象和情绪立场。
- 示例："她是苏家不受宠的大小姐，为了救重病的母亲，被迫替妹妹嫁给传闻中残废暴戾的傅总。"

### 模块3 · 30-70 秒：核心冲突爆发（情绪最高点）
- **内容**：反派登场，当众给出极致压迫，完成第一次公开羞辱 / 致命危机，把主角逼到退无可退的绝境。
- **作用**：把观众情绪（愤怒、心疼、紧张）拉满，强化"想看主角翻盘"的欲望。
- **要点**：冲突一定要**具象、公开、有强羞辱感 / 危机感**——私下吵架张力远远不够。

### 模块4 · 70-85 秒：转机伏笔 / 金手指初现
- **内容**：给观众半个"主角要翻盘了"的信号，但**绝不揭开谜底**。可以是一个眼神、一枚信物、一句暗语、身体的一丝异动。
- **作用**：给观众明确的爽点预期，让他确信"下一集就要反转了"。
- 示例：女主低头时露出颈后的梅花胎记，正是男主找了十年的救命恩人标记 / 男主攥紧的拳头泛起金光，神力即将觉醒。

### 模块5 · 最后 5 秒：悬崖式悬念收尾
- **内容**：在冲突最顶点、危机最紧要的瞬间**戛然而止**，配一句钩子台词。
- **作用**：强制用户点击下一集，是第一集最重要的转化节点。
- ✅ 正面："就在保镖的手要碰到她脸的时候，门外突然传来一声——'总裁到了！'"
- ❌ 反面：事情解决、情绪平复、主角安然无恙再结束（等于直接把观众放走）。
- 收尾**禁用转场词**（`CUT TO BLACK` / `第 1 集完` 等），靠钩子内容本身停在悬念上（见 `3-script.md` 结尾转场词铁律）。

## 三、主流题材第一集的侧重点

| 赛道 | 核心 | 第一集必须完成 |
|---|---|---|
| **女频虐恋/替嫁/弃妇** | 虐点前置 | 最极致的羞辱（拒婚/背叛/冤枉），把女主的惨拉到极致，让观众心疼到想看反击 |
| **男频逆袭/赘婿/战神** | 羞辱前置 | 把男主踩到底（当众骂废物/被戴绿帽/被赶出门），同时埋下身份伏笔，爽感预期拉满 |
| **复仇爽剧** | 仇恨值拉满 | 家破人亡、被最信任的人背叛，把"为什么复仇"讲死，让观众和主角共情恨意 |
| **悬疑/奇幻** | 怪事立刻发生 | 出现核心谜题（死人/失踪/诡异事件），抛出第一个悬念，不要铺垫世界观 |

## 四、第一集常见致命雷区（命中即重写首集）

1. **铺垫过长**：前 30 秒还在讲背景、介绍人物，用户早已划走。
2. **人物太多**：第一集出场超过 3 个核心人物，观众记不住、分不清主次。
3. **信息过载**：大段讲世界观设定、家族恩怨、人物前史，观众没耐心消化。
4. **钩子太软**：开篇是日常场景，全靠旁白讲故事，没有视觉冲击。
5. **结尾无悬念**：第一集就把事情解决了，观众没有任何看下一集的动力。
6. **对话堆砌**：竖屏短剧靠视觉冲击驱动，大段静态对话极度无聊。

## 五、第一集专属自检 Checklist（写完首集必过，不过即重写）

- [ ] **秒级留存**：第 3 秒内是否已出现具体可拍的强冲突动作 / 强情绪炸点（非对话、非空镜、非介绍）？
- [ ] **叙事奠基**：主角人设、核心处境、全剧调性是否在前 30 秒内立住？观众知道"代入谁、这是什么路子"？
- [ ] **冲突引爆**：全剧核心主线矛盾是否在本集直接打透（而非留到第2集才出事）？冲突是否具象、公开、有强羞辱/危机感？
- [ ] **转机伏笔**：70-85 秒是否给了"要翻盘"的半个信号，且没揭开谜底？
- [ ] **悬崖收尾**：最后 5 秒是否停在冲突/危机最顶点 + 一句钩子台词？（禁转场词）
- [ ] **人物 ≤ 3**：本集核心出场人物是否不超过 3 个？
- [ ] **零信息过载**：有没有大段世界观 / 家族恩怨 / 前史独白？
- [ ] **结构衔接**：本集引爆的矛盾，是否在第 2 集起展开为跨 2-8 集的情节单元（而非本集就彻底解决）？

> 第一集的"起承转合俱全"是**豁免项、也是义务**——它是唯一允许的单集闭环。但这不等于把主线矛盾在第一集解决：第一集只"引爆并埋伏笔"，真正的隐忍→反击→打脸从第 2 集起按情节单元制跨集展开。
