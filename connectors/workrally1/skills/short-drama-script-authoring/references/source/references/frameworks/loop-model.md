# Loop 模型（短剧节奏统一真相源 · 全赛道通用）

> **[作用域：全局 · 中英通用 · 短剧+漫剧通用 · 全部赛道]** 本文是短剧节奏概念的**唯一层级真相源**。此前 skill 里「情节单元 / 关键节点 / 事件 / loop / 起承转合 / 压放弹簧」散落在 emotion-spring、narrative-loop、SKILL.md 步骤2.5、stages/3-script 各处，互不对齐、同词多义。本文把它们**归位到一个统一模型**：一切都是 loop，只分两级、按主角数分两型。其它文件保留原有细则，遇到概念归属以本文为准。

---

## 一、核心：一切都是 loop，只有两级

短剧的节奏引擎只有一个词——**loop（循环）**。它分大小两级，是**嵌套**关系（大 loop 里套若干小 loop），不是并列的两种东西。

| 层级 | 定义 | 跨度 | 数量 | 结尾标志 |
|---|---|---|---|---|
| **小 loop（= 一次"攻防回合"）** | **反派出一招施压 + 主角应对一招**（反抗/化解/隐忍蓄势/反击）。大 loop"承"段的基本砖块，**不是完整事件弧** | **通常跨 2-3 集**（压集 + 放集）；单集只承担一段，**禁一集完成完整攻防** | 每个大 loop 的承段含 1-3 个 | 这次攻防见分晓 + 钩子 + 下一招更狠 |
| **大 loop（= 一个情节单元）** | 一个**完整故事弧**：反派发难 → 承段 N 个小 loop 逐级加码 → **终局反转**（反派败退/身份揭晓/权力倒置） | **2-8 集**（按剧情松紧调整，**不均分**——重头戏可 7-8 集，过场弧 2-3 集） | **一部剧 5-12 个** | **大反转**（终局胜负分晓，全弧最高点） |

> **一句话记住**：`大 loop（情节单元）= 一个 2-8 集的完整故事弧（反派发难→承段多次攻防→终局反转败退）；小 loop = 弧里的一次攻防回合。一部剧 5-12 个大 loop，每个长度按剧情松紧定、不均分。大 loop 收尾放缓呼吸，小 loop 之间只喘几秒。`

> **数量定法（核心 · 不是集数除法）**：大 loop 数量 = 故事有几个**完整状态跃迁**——按反派阵营数 / 主角身份跃迁数 / 权力倒置次数来定，不是"总集数÷平均长度"。定完个数，再按每个弧的戏剧分量**不均分**集数（关键弧给足 7-8 集，铺垫/过场弧压到 2-3 集）。
> - 30 集短剧示例：3 个反派阵营 → 3 个大 loop 是一种合理切法；但若中间某反派戏份重，也可拆成 2 个大 loop，变成 4-5 个。**没有唯一解，由故事的跃迁点决定。**
> - 一部剧 5-12 个是常见区间：短剧（20-40集）偏 5-8 个；长剧（80-100集）偏 10-12 个。

> **实证（用户 Dart 定义）**：反派试图害女主（一个大 loop）→ 承段女主反抗数次、反派危机越来越大（数个小 loop）→ 男主来救、反派祭招男主应对（又数个小 loop）→ 反派失败离开（大 loop 终局反转）。

### loop 就是原来的"情节单元"（术语对齐）

- **大 loop ≡ 情节单元 ≡ narrative-loop 里的一圈"4拍 loop"**——三个名字指同一个东西（一个 2-8 集的完整故事弧），只是不同文件的历史叫法。以后统一理解为「大 loop」。**二者跨度一致（都是 2-8 集），不存在"大 loop 比情节单元粗"的层级差**——这是本 skill 的设定，一个大 loop 就是一个情节单元，一一对应。
- **小 loop ≡ 一次攻防回合 ≡ 一个"事件"**——别把"事件"当成独立于 loop 的另一个概念。一个事件就是一轮攻防（反派一招 + 主角一招），即一个小 loop。
- **"关键节点" ≡ 大 loop 的终局反转里程碑**——**关键节点由每个大 loop 的结尾派生，不独立预设数量**：切几个大 loop，就有几个关键节点（每个大 loop 的"转/合"收尾 = 一个关键节点）。故 **关键节点数 = 大 loop 数 = 情节单元数 = 5-12 个**，三者一一对应（SKILL.md 步骤2.5 早期说的"10-12 个"是 80-100 集默认长剧的取值；短剧按剧长取 5-8 个）。**"关键节点"作为"大 loop 收尾"的别名保留**（全库引用不动），二者可互指。**不要反过来先定死 N 个关键节点再往里塞单元**——那是旧两层设计（关键节点粗层 10-12 个 + 情节单元细层 25-40 个）的残留，v8.7.2 起两层已合并为一层。

## 二、按主角数量分两型（取代难懂的"单轨/双轨"）

loop 内部装几条冲突线，**只看主角数量**：

### 型 A · 单主角剧（只有外部 loop）

- **代表**：`No Time to Apologize`、多数男频爽文/复仇/打脸/战神。
- **结构**：只有一条**外部冲突 loop**——主角 vs 反派/环境/危机。主角内核**全程稳定不变**，不需要成长弧。
- **动力**：靠反派/危机**单方面逐轮加码**推进（每轮打压量级、赌注更大）。
- **`No Time to Apologize` 实证**：全剧基本是 1 个大 loop（路口冲突 EP1-12），内嵌 6 轮小 loop，统一模式「主角自证 → 反派毁证 → 升级打压」，每轮只升级打压强度，Grace 内心不动。矛盾**全来自外部**，没有内部关系 loop——所以硬套"双螺旋内变化"是错的。

### 型 B · 双主角剧（外部 loop + 内部关系 loop 咬合）

- **代表**：`How to Tame a Silver Fox`、霸总/契约婚/追妻/甜宠等（双主角可以是男女、男男等任意组合）。
- **结构**：一条**外部冲突 loop** + 一条**两人内部关系 loop**，二者**咬合驱动**（不是各转各的）：
  - 外部危机把两人逼到一起 → 内部关系推进一步（如心动/靠近）
  - 内部关系变化又招来新的外部冲突（情敌眼红/反派针对/家族施压）→ 开启下一轮
- **`Silver Fox` 实证**：3 个递进大 loop（相遇→拉扯→确认），每个内嵌 2-3 轮小 loop，外部危机与内部关系每轮咬合升级。
- **咬合铁律**：外部事件必须**撬动**内部关系变化，内部变化必须**催生**新外部冲突。**没有咬合 = 无效注水**（打脸打完两人关系毫无变化 = 白打）。

### 型 B 的特例 · 镜像 loop（方向反转）

- **代表**：`Goodbye After 99 Forgiveness`、追妻火葬场。
- **结构**：两个方向相反的大 loop 拼接，中间以"关系彻底破裂"为反转点。
  - 上半段：男伤女（男主抛下女主，女主攒失望，99 次计数清零）
  - 下半段：女反噬（男主追妻，女主拒绝，权力关系倒置）
- 本质仍是型 B 的内部关系 loop，只是**关系相位从"下行"转为"上行"**。不是新结构，是双主角 loop 的一个变体。

> **判型口令**：写剧前先问一句——**这剧是几个主角？** 单主角→型 A，只需设计外部 loop 逐轮加码；双主角→型 B，必须让外部 loop 和内部关系 loop 咬合。

## 三、起承转合 = 大 loop 的四段（内部校验锚点，不必对创作者展示）

「起/承/转/合」是 skill 里已用的节拍词汇，它描述的是**一个完整故事弧（大 loop）的四段**，**不是小 loop 的内部结构**——小 loop 是更细的攻防砖块。二者是不同粒度：起承转合是粗粒度骨架校验，小 loop 是承段里的细粒度操作单位。

| 大 loop 四段 | 含义 | 对应弹簧 | 对应 narrative-loop 4拍 | 装什么 |
|---|---|---|---|---|
| **起**（发难） | 反派发难/危机降临，点燃这一弧的冲突 | 压 | 压 Humiliate | 大 loop 的开局 1 集左右 |
| **承**（交锋逐级加码） | N 个小 loop 逐级加码的攻防回合 | 压 | 蓄 Tease | 大 loop 的主体，小 loop 全在这里反复 |
| **转**（终局反转） | 终局爆发——反派败退/身份揭晓/危机解除 | 放 | 弹 Release | 大 loop 的最高点 1 集 |
| **合**（收尾埋钩） | 收口 + 埋下一个大 loop 的起 | 放 | 埋 Re-load | 大 loop 结尾，衔接到呼吸集 |

> **两套"四拍"至此对齐**：起=压（发难）、承=蓄（交锋加码）、转=弹（终局爆发）、合=埋（收口+埋钩）。这是**大 loop 层面**的对齐，不是小 loop 内部。

> **小 loop 装在"承"段里**：一个故事弧的"承"段，就是若干小 loop（攻防回合）逐级加码的过程——反派出一招、主角应一招、反派更狠、主角再应……直到"转"段一次性引爆。**小 loop 本身只有"压（反派施压）+ 反应（主角应对）"两拍**，不是完整四拍。把起承转合硬塞进小 loop 内部会把颗粒度搞错（这是早期一版写错过，已修正）。

> **单集 vs 小 loop vs 大 loop 的粒度**（三层，别混）：
> - **单集**（1-2 分钟）：最细，只承担一个小 loop 的一段（压集 / 放集）或大 loop 的一拍。
> - **小 loop**（攻防回合，通常跨 2-3 集）：反派一招+主角一招，承段的基本砖块。**压集**（1-2 集，反派出招主角陷困）+ **放集**（1 集，主角应对反转）。
> - **大 loop**（故事弧，数集~整部）：起承转合四段，含 N 个小 loop。

> 🔴🔴 **小 loop 跨集铁律（v8.7.1 补 · 治"小 loop 一集闭环=换皮的一集一事件"）**：
> 这是 loop-model 引入小 loop 后必补的铁律——**emotion-spring 的"禁一集一事件"原本针对情节单元（大 loop），小 loop 成为新操作单位后，该铁律必须同步下沉到小 loop 颗粒度**，否则模型会把"一集完成一个完整攻防、下一集换新攻防"当成合规——那是换皮的一集一事件，节奏病没治。
> - **① 禁一集完成一个完整小 loop**：一个攻防回合（反派出招→主角应对→见分晓）必须**跨 2-3 集**。单集只承担"压"（反派出招、主角陷困、不解决）或"放"（主角应对、反转见分晓）之一，**不允许一集内既出招又见分晓**。
> - **② 压集只加压不解决**：小 loop 的压集（1-2 集）只让反派施压、主角陷困或隐忍蓄势，**不在当集给出反转**。反转留到放集。
> - **③ 放集承接压集、不另起炉灶**：小 loop 的放集（1 集）开头必须直接承接压集的困境，在当集给出反转见分晓，结尾埋下一招的钩子。
> - **④ 自检三问**（每集写完）：本集是某个小 loop 的压集还是放集？如果是压集，有没有提前给反转（违规）？如果是放集，开头是否承接了上一压集的困境（不是新攻防）？下一集开头能否直接接本集结尾？
> - **⑤ EP1 豁免（第一集专项）**：**第一集是独立引流集，单集闭环**（钩住→立人→引爆→留悬念），**豁免本铁律①②③**——它必须当集完成"暴击钩子/身份困境/冲突爆发/转机伏笔/悬崖收尾"5 模块（详见 `first-episode.md`）。**情节单元制（小 loop 跨集）从第 2 集起生效**。EP1 同时点燃全剧核心冲突，是首个大 loop"起"的开端，但不受压/放跨集约束。
> - 一集装不下一整个大 loop；一个小 loop 也可能跨集。**不要求一集自成闭环**（详见 emotion-spring.md「一集一事件」禁令）。

## 四、逐级加码：loop 是螺旋不是圆（全赛道通用）

平移重复，观众三集就腻。**每转一圈（无论大小 loop）必须加码**，否则触发疲劳。加码沿三条轴（原 narrative-loop 第三节，现升级为全赛道通用）：

1. **身份/实力逐级加码**：揭一层身份永远暗示"上面还有一层"。
2. **代价/赌注逐级加码**：把伤害量化成可耗尽的额度（99 次 / 还剩 3 天 / 唯一药剂），每扣一次=逼近爆发。
3. **危机/反派接力螺旋**：多个反派用不同手段轮番施压，压戏不重样。

> **禁无效循环（质检项）**：每一轮 loop（大或小）必须有**可量化的升级项**（冲突量级 / 赌注代价 / 情绪浓度，至少一项递增）。原地重复同一种冲突 = 注水，命中即重写。

## 五、大 loop 的"呼吸感"铁律（本次新增 · 治全程高压看剧累）

**[作用域：全局 · 全赛道]** 这是此前 skill 缺失的一块——现有全剧曲线只讲"每 5-10 集一个高潮"，却没区分小 loop 收尾和大 loop 收尾的节奏差别，导致 AI 生成时容易**全程高压、不给喘息，观众看着累**。

**两种"休息"强度不同，不要混：**

| 收尾类型 | 休息强度 | 怎么写 |
|---|---|---|
| **小 loop 收尾** | 几秒喘息，立刻接下一个 | 反转爽点后马上埋更大的钩子，不停 |
| **大 loop 收尾** | **真休息一集（或半集）** | 大反转/大爽点爆发后，安排 1 个**低强度缓冲集**——关系甜、日常温情、主角短暂安稳、轻喜过渡 |

**呼吸集铁律：**
1. **大 loop 的大反转（最高点）之后，必须有 1 个缓冲集/半集**，情绪强度明显降下来，让主角和观众都歇一口，再启动下一个大 loop 的"压"。
2. **禁大高潮接大高潮**——两个大 loop 的收尾爆点之间若没有任何缓冲，观众情绪来不及消化，疲劳弃剧。
3. 缓冲集**不是废戏**：它承担"回甜/回暖/回稳"的情绪功能，且结尾仍要埋下一个大 loop 的起（轻钩子）。
4. **双主角剧**的呼吸集通常用来**兑现内部关系 loop 的甜**（外部危机暂歇，两人关系进入短暂甜蜜期），这也是型 B 特有的留存利器。

> **节奏总口诀**：小 loop 之间不停歇、逐级加码往上冲；大 loop 收尾放缓一集喘口气；喘完再起一个更大的 loop。

## 六、极简工作流（用 loop 一个概念跑通全流程）

1. **判型**：几个主角？单主角→型 A（只设外部 loop）；双主角→型 B（外部 loop + 内部关系 loop 咬合）。
2. **切大 loop**：把全剧切成若干个大 loop（= 情节单元 = 关键节点里程碑），每个大 loop 完成一次完整状态跃迁（身份反转/关系升级/权力倒置）。
3. **填小 loop**：每个大 loop 的"承"段内铺 N 轮小 loop（反派一招 + 主角一招的攻防回合），逐轮加码——loop 越大塞越多。
4. **咬合校验（仅型 B）**：每轮外部事件是否撬动内部关系？内部变化是否催生新外部冲突？断了就重写。
5. **呼吸校验**：每个大 loop 收尾后是否安排了缓冲集？大高潮有没有硬接大高潮？
6. **调素材**：从 Shared（人物/世界观/道具/台词/红线）取料填充，Shared 不参与叙事结构、只做填充与约束。

## 七、检验清单（写戏/拆条时对照）

- [ ] 本段属于哪个大 loop？在大 loop 的哪段（起/承/转/合）？"承"段里是第几轮小 loop？
- [ ] 本轮小 loop（攻防回合）比上一轮**加码了吗**？（反派招数更狠/赌注更大/主角应对更难，至少一项升级）
- [ ] 小 loop 结尾有没有"暂时见分晓 + 钩子 + 升级到下一招"？（钩子最高频漏项）
- [ ] 🔴 **小 loop 跨集合规**：每个小 loop 是否跨 2-3 集？有没有"一集完成一个完整攻防（既出招又见分晓）"？压集有没有提前给反转？放集开头是否承接压集困境（不是另起新攻防）？（v8.7.1 · 治换皮的一集一事件）
- [ ] **型判定对不对**：单主角剧有没有硬塞不存在的内部关系 loop（`No Time` 陷阱）？双主角剧有没有漏掉内部关系 loop、写成单轨？
- [ ] **咬合（仅型 B）**：外部事件撬动了内部变化吗？内部变化催生了新外部冲突吗？还是两张皮？
- [ ] **呼吸感**：大 loop 大反转之后有没有缓冲集？有没有大高潮硬接大高潮？
- [ ] 有没有无效循环（原地重复、无可量化升级项）？

任何一项不通过，重写。
