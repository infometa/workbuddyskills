# 情绪弹簧理论（短剧核心方法论）

> **概念层级归属**：本文管的是**单集尺度**——一集怎么"压/放"。它是 `loop-model.md` 的单集落地层：压/放对应小 loop 内部的"升级段/反转段"，"情节单元"= loop-model 里的**大 loop**，"节拍（起/承/转/合）"是小 loop 内部四段的内部锚点。跨集/跨单元的 loop 层级、单主角/双主角两型、大 loop 呼吸感，统一见 `loop-model.md`。

短剧的灵魂。**每一集只能"压弹簧"或"放弹簧"，不允许中间状态。**

## 压弹簧（情绪积蓄）

通过制造误会、主角被压制、反派嚣张、危机降临，**积蓄观众的负面情绪**（愤怒、憋屈、紧张、好奇）。

### 常见手法

| 手法 | 操作 |
|---|---|
| **身份压制** | 利用阶层、地位、财富差距制造不公平 |
| **能力质疑** | 公开质疑主角的能力、判断、决策 |
| **情感伤害** | 伤害主角的亲人、朋友、爱人 |
| **尊严践踏** | 公开羞辱、嘲笑、贬低主角 |
| **困境叠加** | 连续倒霉事件，让观众同情累加 |

### 情绪曲线

集开始：3 → 集结尾：8-9（满分 10）

## 放弹簧（情绪释放）

通过主角反转、打脸反派、揭露真相、化解危机，**将积蓄情绪在瞬间彻底释放**。

### 常见手法

| 手法 | 操作 |
|---|---|
| **身份揭晓** | 揭露主角隐藏身份或真实实力 |
| **实力碾压** | 用绝对优势击败反派 |
| **智慧反击** | 用智谋让反派自食其果 |
| **真相大白** | 揭露被隐瞒的真相，平反冤屈 |
| **终极反转** | 意想不到的反转，震撼观众 |

### 情绪曲线

集开始：8-9 → 瞬间冲到 10 → 回落到 3-4（为下一轮压弹簧做准备）

## 单集执行规则

每集必须明确属于以下四种之一：

| 类型 | 描述 | 占比建议 |
|---|---|---|
| **情节单元内单节拍集**（默认主流 · v5.6 新增） | 一集只承担情节单元的一个节拍（起/承/转/合之一），**不要求集内闭环**。压弹簧集可只压不放、留到下一集放；放弹簧集可承接上一集的压 | 50-60% |
| **压放结合集**（集内闭环） | 前半压、后半放，单集完成闭环。**仅用于付费点当集等需要提速的节点** | 20-30% |
| **纯压弹簧集** | 全集只积蓄，不释放（情节单元的"起/承"集） | 10-15% |
| **纯放弹簧集** | 全集只释放，爆发爽感（情节单元的"转"集） | 10-15% |

> **情节单元铁律（v5.6 / v6.1 强化 · 短剧节奏基本单位）**：短剧一个完整事件（一个情节单元）通常**连贯横跨 2-8 集**走完"起→承→转→合"。**单集只是情节单元的一个节拍，绝不要求每集自成闭环**。一集可以只压不放（留给下一集放）、只放不压（承接上一集的压），这是短剧的正常节奏，**不是"废戏"**。只有当一集既不推进情节单元的"起承转合"、又没有钩子/悬念时，才是废戏。

### ⛔ 严禁"一集一事件"（v6.1 新增 · 一票否决）

这是把短剧写成传统影视剧的头号通病，**命中即整段重写**。

> 🔵 **第一集豁免（v8.6 新增）**：本禁令**从第 2 集起生效，不约束第 1 集**。第一集是独立引流集，必须在单集内"起承转合俱全"地完成钩住→立人→引爆→留悬念——它的单集闭环是义务不是缺陷。第一集"引爆"主线矛盾并埋伏笔，第 2 集起才把这个矛盾展开为跨 2-8 集的情节单元。第一集创作法见 `frameworks/first-episode.md`。

- **什么是"一集一事件"**：一集之内完整起一个事件、解决它、收尾；下一集换一个全新的、与上一集无直接因果的事件，并伴随**时间/空间的大跳转**（"三天后……""与此同时，另一边……""第二天，公司里……"）。这是电视剧/单元剧的写法，不是短剧。
- **为什么禁止**：短剧一集只有 1-2 分钟（每集 200-448 词，英文词数口径），根本装不下一个完整事件的起承转合。强行塞进去 → 每个节拍都被压缩成几秒 → 没有压弹簧的积蓄、没有放弹簧的爽感 → 观众无感，完播率崩盘。
- **正确做法（事件横跨集）**：一个有冲击力的事件（如"当众揭穿假千金"），要**把它的起→承→转→合拆开，铺在连续 2-8 集里**：
  - 第1集（起）：埋下假千金的破绽，主角察觉，但隐忍不发——只压。
  - 第2集（承）：主角暗中取证，假千金步步紧逼、嚣张羞辱——继续压，压到最深。
  - 第3集（转）：当众甩出铁证，假千金当场崩溃——放，爆点。
  - 第4集（合）：余波处理 + 揭开下一个更大的局——收口并埋下一个"起"。
- **场景连续性铁律**：相邻两集之间，**时间和空间默认是连续承接的**（上一集结尾的场景/危机，直接是下一集开头的延续）。除非进入新的情节单元，否则**禁止在集与集之间做"三天后""另一边"这类大跳转**。下一集开头要能接住上一集结尾的钩子，而不是另起炉灶。
- **自检三问**：① 本集要解决的事件，是不是上一集就已经起了头的同一个事件？② 这个事件是不是要到后面某集才真正解决（而不是本集就收完）？③ 下一集开头能不能直接承接本集结尾的场景/危机？——三问中只要有"否"，大概率犯了"一集一事件"。

### 🔴 根因在骨架期：单元核心事件命名（v8.2 新增 · 与 SKILL.md 步骤2.5「单元核心事件填写铁律」互为表里）

"一集一事件"的病根**不在剧本期，在骨架期把情节单元的"核心事件"字段填成了话题/场合名词**——剧本期只是照着错骨架把每集写成独立故事。剧本期读到本节禁令时，若发现骨架的单元核心事件是话题名词，**必须回骨架期重填，不能带病硬写**。

- **❌ 假单元（话题/场合名词，天然可塞多个独立小事件）**：`The Contract`、`The Gala`、`同居生活`、`初遇`、`公司风波`。一个话题底下 EP1/EP2/EP3 各讲一个能自我了结的冲突，"起承转"标签一贴就假装跨集，实则每集自闭环、换事件换地点。
- **✅ 真单元（单一贯穿冲突句）**：`女主为救母被迫签约、并在契约束缚下逐步卷入男主世界`——**一个**"契约束缚"矛盾贯穿全单元：起集点燃(签约但矛盾未解)、承集加压(束缚下第一次冲撞)、转集才引爆(束缚逼出第一次心动/反抗)。同一矛盾跨集，时间地点自然连续。
- **冲突守恒铁律**：一个单元只有**一个**核心矛盾。它在**起集点燃、承集只加压不解决、转集才第一次也是唯一一次引爆**。若某一集内这个矛盾"既点燃又解决"=该集自闭环=违规。**地点连贯是冲突守恒的副产品**——同一个矛盾持续燃烧，场景自然承接，不会每集跳新地点。
- **拆分口令（写骨架时）**：先写死"这个单元只讲一个冲突"→ 再问"这一个冲突从点燃到引爆要几集(2-8)"→ 最后把这几集标起/承/转/合。**绝不能反过来**：先攒 N 个想写的独立事件，再打包硬贴一个单元名——那就是假单元。

### 🔴 情节单元双线交替结构（v7.2.2 新增 · 治"情节单元内部只有外冲突一引擎"根因 · 全局）

**[作用域：全局 · 中英通用 · 短剧+漫剧通用]** 这是治"2-8 集一单元写了但还是像美剧"的根因修复。仅讲"事件跨几集"不够——模型默认会把"跨集事件"理解为**单一外部冲突**的起承转合铺长版,于是每集只有外冲突一拍,节奏像慢速电视剧。真正的短剧情节单元必须**双线交替交替推进**。

**双线交替定义**：

| 引擎 | 内容 | 节奏功能 | 爽感来源 |
|---|---|---|---|
| **主冲突线** | 主角 vs 反派/危机/对手:打脸、反转、揭穿、碾压、危机化解 | 推进情节单元"起承转合"四拍 | **爽感**(即时满足) |
| **关系副线** | 主角团内部的小循环:男女主拉扯、主角与跟班分歧、主角内心自洽冲突 | 填充外冲突节拍之间的"呼吸感" | **情绪供给**(粘性留存) |

**双线交替交替规则**(核心铁律):

1. **外冲突压时,内冲突放**:外冲突节拍处于"起/承"集(主角被压、反派嚣张)时,**关系副线 必须提供情绪供给**——男女主的甜虐拉扯/主角与跟班的拌嘴分歧/主角自我怀疑与坚持。**只有外冲突一拍而没有内冲突填充 = 单线剧 = 像美剧**。
2. **外冲突放时,内冲突压或悬**:外冲突节拍处于"转"集(爽点爆发)时,关系副线 应暂时悬置或推进到自己的小高潮,让外冲突爽感不被内冲突稀释。
3. **合集必须同时收口**:情节单元的"合"集,**主冲突线收尾 + 关系副线 推进到下个相位**(不是内冲突也闭环——关系副线 是跨情节单元的长线)。

**关系副线 的三种典型形态**(按受众赛道选):

| 形态 | 适用赛道 | loop 内容 |
|---|---|---|
| **男女主拉扯型** | 女频爱情赛道(霸总/契约/追妻/萌宝/狼人) | 他护短/她误解;他冷待/她死心;他悔悟/她已走远——**情感相位轮换**(亲密→疏离→误解→和解→新亲密)跨多个情节单元 |
| **主角+跟班互动型** | 男频战神/赘婿/神豪/逆袭/复仇 | 跟班小弟崇拜/质疑/被欺负→主角撑腰;主角对跟班嫌弃→信任;跟班成长线——**忠诚相位轮换**(陌生人→试探→认可→生死相托)跨多个情节单元 |
| **主角内心自洽型** | 大女主/复仇/独立成长(无双男主或男主非核心) | 主角自我怀疑→坚持→觉醒;复仇决心动摇→强化;身份认同挣扎——**自我相位轮换**(迷茫→坚守→笃定)跨多个情节单元 |

**反模式(必避)**:

- ❌ 情节单元只有主冲突线(打脸反派 2-8 集),没有关系副线——**单线剧,节奏像慢速电视剧**
- ❌ 关系副线 只在"合"集出现一次(凑一次拌嘴就过)——**loop 没跨情节单元长线化**,情感无相位轮换
- ❌ 关系副线 与主冲突线无因果(完全独立的副线)——**两引擎割裂**,应让内冲突相位受外冲突节拍影响(如:外冲突压时男女主被逼到一起/外冲突放时两人价值观分歧浮现)

**双线交替校验(每集写完自检)**:

- [ ] 本集有外冲突节拍推进吗?(起/承/转/合之一)
- [ ] 本集有关系副线 的相位变化吗?(无论多小,哪怕一句拌嘴/一个误解加深)
- [ ] 关系副线 的相位,是不是受本集外冲突节拍影响产生的?(不是完全独立的副线)
- [ ] 跨情节单元看,关系副线 是不是在相位轮换?(不是原地踏步的同一个矛盾)

> **关键判据**:把主冲突线全部删掉,这集还剩什么?如果只剩"什么都没有"=单线剧;如果还有男女主拉扯/主角团互动/主角内心戏=双线交替成立。短剧爽感靠外冲突,留存靠内冲突——**单线必然掉留存**。

## 全剧情绪曲线设计

### 80 集模板（爽剧）

```
集数：1   5   10  15  20  25  30  ...  70  75  80
情绪：3 → 7 → 10 → 5 → 9 → 4 → 10 → ... → 9 → 4 → 平稳
类型：压  放  放    压  放  压  放    ...  放  放  收
                  ↑    ↑       ↑                  ↑
               付费1 大压    付费2-3              收尾
```

### 设计要点

1. **每 5-10 集一个情绪高潮**
2. **大爆发前必有大压抑**（爆发力 = 压抑深度 × 释放速度）
3. **付费卡点必须是放弹簧 + 更大悬念**（让用户既爽又想继续）
4. **避免连续 3 集同类型**（连续 3 集压会让用户弃剧）
5. **🔴 大 loop 收尾后必须放缓呼吸（v8.3 新增 · 治全程高压看剧累 · 详见 `loop-model.md` 第五节）**：区分两种"休息"——**小 loop 收尾**只喘几秒立刻接下一轮（反转爽点后马上埋更大钩子，不停）；**大 loop 收尾**（大反转/身份揭晓/权力倒置等最高点爆发之后）**必须安排 1 个低强度缓冲集/半集**，情绪明显降下来，让主角和观众都真正歇一口，再启动下一个大 loop 的"压"。**禁大高潮硬接大高潮**——两个大 loop 的爆点之间无缓冲=观众情绪来不及消化=疲劳弃剧。缓冲集不是废戏：它承担"回甜/回暖/回稳"功能（双主角剧常用来兑现两人关系的甜），且结尾仍埋下一个大 loop 的起（轻钩子）。

## 检验清单

写完每集，对照以下问题：

- [ ] 这一集主导情绪是压还是放？
- [ ] 集开始的情绪值是多少？集结尾呢？
- [ ] 集结尾的钩子是悬念型、危机型、还是反转型？
- [ ] 与上一集的情绪类型是否过于雷同？
- [ ] 是否有"中间状态"段落（既不压也不放的废戏）？
- [ ] 本集是否推进了所属情节单元的节拍（起/承/转/合之一）？如果本集是情节单元内部的"承"或"转"的铺垫集，允许只压不压或只放不压——这不是废戏。废戏的判定是：本集既不推进情节单元节拍、又无钩子/悬念（v5.6 新增）
- [ ] **反"一集一事件"：本集要处理的事件，是否是前面某集就起头的同一连贯事件（横跨2-8集）？有没有"一集起一个全新事件并当集收尾"的电视剧式写法？（v6.1 新增 · 一票否决）**
- [ ] **场景连续性：下一集开头能否直接承接本集结尾的场景/危机？除进入新情节单元外，有无"三天后/另一边/第二天"这类集间大跳转？（v6.1 新增）**

任何一项不通过，重写。
