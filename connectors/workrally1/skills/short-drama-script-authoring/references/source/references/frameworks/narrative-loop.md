# 叙事循环引擎（拆条 / 节奏校验器）

> **先读**：本文的**底层引擎（第一至五节：4拍 loop、三层分形、逐级加码、双螺旋咬合）现已升级为全短剧赛道通用**——所有短剧都是 loop 在转，节奏统一真相源见 `loop-model.md`。**本文的「6 触发器 / 5 权力钩子」（第四、八节）是 loop-model 型 B「双主角内部关系 loop 咬合」的女频爱情具体化层**——供女频爱情赛道（霸总/强制爱/契约婚/豪门甜虐/狼人羁绊/追妻火葬场/萌宝等）落地"内部关系怎么一句句拉扯"。**其余赛道**（单主角爽文/复仇、大女主自洽、群像、纯功能向）用 loop-model 的通用规则即可，**不必套用第四、八节的情感触发器**——单主角剧只有外部 loop，硬塞内部关系触发器会写虚（见 loop-model 型 A 与 `No Time to Apologize` 实证）。
>
> 本文是「情绪弹簧」（emotion-spring.md）的**结构上层**：情绪弹簧管"单集压还是放"，本文管"压放如何串成一条停不下来的链"。概念层级归属以 `loop-model.md` 为准。提炼自 53 部真实 海外/DramaBox/FlexTV 爆款。

## 一、底层引擎：4 拍循环单元「压 → 蓄 → 弹 → 埋」

女频爱情短剧剥到最里层，是同一个四拍循环在反复转。**任意一段戏都应能对上其中一拍。**

| 拍 | 动作 | 作用 | 典型手法 |
|---|---|---|---|
| **① 压** Humiliate/Threaten | 羞辱、委屈、危机、被踩 | 把观众的"替她不值/愤怒/揪心"充满 | 当众拒绝命定 / 卑微妻穿女仆装 / 萌宝濒死 / 债主上门 |
| **② 蓄** Tease the Card | 暗示底牌、设倒计时、内心预告 | 让观众知道"她有牌/快翻盘了"，建立期待 | "等她发现我是CEO的脸"/"还有三天我就走"/撞脸钩 |
| **③ 弹** Release | 反转、打脸、揭身份、认亲 | 一次性兑现，情绪弹射到顶 | 揭身份全场石化 / 揭隐藏萌宝 / 财力轻碾 |
| **④ 埋** Re-load | 在爽点峰值立刻种下更大的不平衡 | 不让观众喘气，启动下一圈 | "反派跑了还在外面"/暗示更大身份/甜完即插新威胁 |

> **核心铁律**：第 ④ 拍是 loop 之所以是 loop 的命门。**释放永远不画句号**，必须在最爽的一秒挖下一个坑。少了第 ④ 拍，链条就断了，观众就退出了。

## 二、三层分形：同一引擎在三个尺度上自相似

同一个 4 拍引擎在三个时间量级上重复，节拍完全相同、只是振幅不同。**这是短剧高度模块化、任意切片都像全剧缩影的原因。**

| 尺度 | 周期 | 一圈长什么样 |
|---|---|---|
| **微观**（场景级） | 2-3 分钟 | 小羞辱 → 小反击 → 小爽 → 小钩 |
| **中观**（付费点级） | 每 3 集 / 8-12 分钟 | 压戏密集 → 预告钩 → 大揭晓 → cliffhanger 停在"答案揭晓前 1 秒" |
| **宏观**（全剧级） | 整剧 | 卑微底色 → 中点身份反转大爆破 → 后段火葬场/终极打脸 → 结尾留更大 boss |

校验用法：写到任何一段，先定位"这是哪个尺度的第几拍"，再检查这一拍有没有做到位。

## 三、逐级加码：loop 是螺旋不是圆（防疲劳）

平移重复，观众三集就腻。**每转一圈必须加码**，否则触发器会钝化（吃醋一次新鲜、三次发腻）。加码沿三条恒定轴线：

1. **身份逐级加码**：女佣→Luna→更大的 pack；揭一个身份永远暗示"上面还有一层"。身份落差是可叠加的爽感燃料。
2. **代价逐级加码**：把伤害量化成可耗尽的额度（99 次原谅 / 6 年×每次都选她 / 还剩 3 天），每扣一次=逼近归零=逼近爆发。
3. **危机/反派接力螺旋**：4 个反派用 4 种不同手段（性/暴力/社交/权力）轮番施压，压戏不重样，对应多波打脸（言语→角色互换→公共舞台终极）。

> **一句话公式**：`爽感 =（受辱深度 × 身份落差量级 × 打脸公开度）↑ 每圈递增`

## 四、触发器工具箱：外部事件如何撬动内部关系质变（核心查表区）

**元规律**：短剧人物自带心理防御（嘴硬/傲娇/自卑/伪装冷漠），时长短到来不及靠自省推进关系——**全靠外力打破防御**。外部事件的真正功能 = **强迫角色暴露或改写其隐藏的情感真相**。台词可以撒谎，被外力逼出的行为不会。

**判定标准**：真正的触发器必须制造关系的**「关系留痕」**——触发后，即便角色回头，关系也回不到"什么都没发生"的原始状态（说出口的吃醋收不回、认下的孩子赖不掉、揭穿的牺牲恨不起来）。**回头可以，但必须有留痕；无留痕的回头就是无效戏。**

### 6 触发器速查表（3 大类）

| 类 | 触发器 | 外部事件 | 内部质变 | 有留痕关键节点 |
|---|---|---|---|---|
| **拉近** | **①危险逼出保护** | 反派/外敌施压、生死重病天灾 | 距离 → 公开宣示主权/守护 | 当众狠话立 flag，外人默认"她是他的人" |
| | **②情敌逼出独占** | 白月光/前任/第三者挑衅 | 嘴硬否认 → 行为暴露在意 | 吃醋被戳穿，"我不在乎你"人设自己拆了 |
| | **③捆绑逼出锚定** | 契约假婚/政治联姻/被迫同居/孩子炸弹/生死陪护 | 敌对或陌生 → 无法理性退出的情感绑定 | 每次"差点"抬高基线；认下孩子是主动选择，赖不掉 |
| **推远** | **④背叛逼出决绝** | 偏心白月光/为反派站台/苛待真心 | 隐忍讨好 → 额度耗尽、决意离开 | 额度归零，女主亲手封死退路（订单程票/递协议） |
| **翻转** | **⑤真相逼出释怀** | 揭穿"当年的渣行为其实是牺牲/被逼" | 恨 → 痛（情绪极性翻转） | 真相一旦知道无法装作不知，恨的地基被抽掉 |
| | **⑥落差逼出追悔** | 女主隐藏身份/华丽归来当众揭晓 | 无视 → 追悔（永远慢观众半拍） | 身份是客观事实，男主再无法用"她配不上我"自欺 |

### 三个关键边界（防混用）

- **⑤真相 vs ⑥落差**：⑤改的是"**事情为什么发生**"（归因：分手原来是牺牲），⑥改的是"**她到底多珍贵**"（估值：原来是高攀不起的人）。一个改归因、一个改估值。
- **①危险 含超自然借口型**：狼人 bond 需肌肤相亲、男主恐女症唯独对她免疫——本质都是"外力给一个不算主动示爱的行动借口"，统一归入①，不另立类。
- **③捆绑 含生死类**：重病抢救/车祸/亲人离世逼出彻夜陪护、放下怨恨——本质是"创造一个无法理性退出的绑定"，归入③。

### 触发器赛道权重（不同赛道高频项不同，别乱用）

| 赛道 | 高频触发器 | 几乎不用 |
|---|---|---|
| 强制爱/契约婚/狼人 | ①③（②） | ⑥ |
| 追妻火葬场 | ④⑤⑥ | —— |
| 欢喜冤家轻甜 | ②③ | ④⑥（强虐项会破坏轻喜调性） |
| 萌宝/隐婚 | ③①⑥ | —— |

## 五、双螺旋咬合：完整永动机（外↔内双向）

外部冲突线是**主轴**（所有女频爱情剧都有，负责节奏与付费点）；内部拉扯线是**副轴**（爱情赛道专属）。二者**不是平行交替，是咬合齿轮**——外部是泵，内部是被泵推动的水：

```
外部事件 →（①-⑥触发器）→ 内部关系质变 →（反向触发）→ 新外部冲突 → 循环
```

### 反向半圈：内部质变催生哪些新外部冲突（4 类固定模式）

| 内部质变 | 催生的新外部冲突 |
|---|---|
| 关系升温/确认 | 招来情敌眼红、白月光出手、反派针对"她"下手 |
| 男主认领孩子 | 引来血缘生父/家族争夺抚养权、身世反派登场 |
| 身份/秘密曝光 | 商业对手/宿敌家族浮现、更大势力盯上 |
| 女主觉醒变强 | 旧施害者反扑报复、新一轮更高规格的打压 |

> 两个半圈合起来才是永动机：关系每往前一步，必然引来新矛盾。这就是短剧能无限续冲突、持续勾人的结构原理。

## 六、三条使用禁忌（守下限 · 防悬浮狗血）

1. **禁同一触发器无脑加码**：反复吃醋 → 男主从"占有"变"偏执疯子"（OOC）；反复护短 → 暴戾失去好感。同一触发器复用必须换量级、换手法，且全剧总量有限。
2. **禁排布顺序错乱**：火葬场必须"先④背叛、后⑥落差/⑤真相"——若先揭身份反转再写背叛，悔意提前透支，火葬场张力大幅泄掉。拉近型(①②③)打底，推远(④)制造低谷，翻转(⑤⑥)收高潮，顺序错则情绪曲线崩。
3. **禁强触发器集中堆砌**：一段戏内塞 3 个以上强触发器 → 剧情过载、逻辑割裂、观众情绪来不及消化。一个中观 loop（约 3 集）原则上主推一个触发器，其余作辅。

## 七、检验清单

拆条/写戏时对照：

- [ ] 这一段在转 4 拍中的哪一拍（压/蓄/弹/埋）？
- [ ] 这是微观/中观/宏观哪个尺度的循环？
- [ ] **有没有忘了第 ④ 拍**——释放后是否立刻埋了下一个更大的坑？（最高频漏项）
- [ ] 这一圈比上一圈**加码了吗**？（身份/账单/反派接力，三选一必须升级）
- [ ] 本段的内部质变用了哪个触发器（①-⑥）？是否符合该赛道权重？
- [ ] 质变是否**有留痕不可回滚**？（回头可以，但必须有留痕；关系无留痕甚至回到原点=无效戏）
- [ ] 关系质变后，是否催生了**新的外部冲突**（反向半圈）？还是断在了原地？
- [ ] 有没有踩三条禁忌（触发器无脑加码 / 顺序错乱 / 集中堆砌）？

任何一项不通过，重写。

## 八、Power Dynamic 落地范式：5 种权力钩子模型（触发器工具箱的相位细化）

> **作用域**：仅女频爱情 / 权力落差赛道（本文适用边界内）。这是第四节 6 触发器工具箱在"每一句台词/动作如何体现权力位移"这个微观尺度上的落地范式——触发器管"外部事件撬动关系质变"，本节管"质变过程中，上下位如何在对话里逐句拉扯"。**不是全局规则**：大女主自洽、群像、纯功能向赛道不套（那些赛道的动力学不是权力落差）。台词/动作"必须带情绪+姿态"是全局底线（见 `stages/3-script.md` 铁律13），但"权力如何组织成爽感链"是本赛道专属，落在这里。

强情绪永远绑定权力关系的**变化**，而非凭空宣泄。女频爱情/落差赛道里，关系拉扯可拆成 5 种经典权力钩子相位，对应 4 拍循环里"压/弹"两拍的内部质地：

| 钩子模型 | 权力流向 | 情绪质地 | 4拍对位 | 典型落地 |
|---|---|---|---|---|
| **① 压制型** | 上位者向下施压 | 轻蔑 + 掌控感 | ①压 | 降维打击、当众羞辱，为后续反转蓄势 |
| **② 反抗型** | 下位者向上顶 | 不甘 + 孤注一掷 | ①压→②蓄 | 以卵击石制造张力，埋反转伏笔 |
| **③ 反转型** | 高低位瞬间调换 | 错愕 + 扬眉吐气 | ③弹 | 核心爽点爆发点，权力关系当场颠倒 |
| **④ 试探型** | 双方争夺话语权 | 玩味 + 戒备 | ②蓄 / 微观循环 | 来回博弈维持张力，暧昧拉扯常用 |
| **⑤ 臣服型** | 下位认输 / 上位接纳 | 屈辱 / 宠溺 | ④埋 或 loop 收束 | 一段权力关系闭环，同时埋下一圈失衡 |

### 与触发器工具箱的对位（别重复造轮子）

- **①压制 / ②反抗** = ①危险、④背叛 的**施压侧质地**——压戏怎么压得有权力味，不是单纯惨。
- **③反转** = ⑥落差、⑤真相 的**兑现瞬间**——打脸/揭身份那一下的权力颠倒。
- **④试探** = ②情敌逼出独占、③捆绑 前期的**拉扯质地**——暧昧期、契约期的话语权博弈。
- **⑤臣服** = 火葬场追妻的**收束相位**，也是"关系留痕"的落点（认输/接纳都留痕，回不到从前）。

### 使用禁忌（承接第六节）

- **禁权力位移与情绪脱节**：下位者无来由嚣张、上位者无来由懦弱=权力逻辑崩。每一次强情绪都要问"此刻谁的权力更高，这句话是在争夺还是让渡"。
- **禁 5 钩子平铺拉满**：不是每句都要强权力对抗——试探型（弱拉扯）打底，压制/反抗蓄势，反转型只在③弹拍爆发。全程③反转=爽点通货膨胀，观众免疫（对齐第三节逐级加码：每圈换量级，不平移复读）。
- **性别/位置可翻转**：模型默认写"低位女+高位男"，但 CEO 女×弱势伴侣、双强拉扯等结构同样适用——把"上位/下位"按剧情实际关系代入，不锁死性别。
