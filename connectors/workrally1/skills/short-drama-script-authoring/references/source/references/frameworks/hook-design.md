# 钩子设计法则

钩子是观众继续观看的唯一理由。竖屏短剧每集都需要三类钩子。

## 首集开篇黄金 3-10 秒（v6.1 新增 · 最高优先级 · 一票否决）

> 本节只细化**首集开篇 3-10 秒**这一个点。第一集的完整创作法（4 大使命 / 5 模块时间轴 / 题材侧重 / 6 大雷区 / 独立引流集定位）见 `frameworks/first-episode.md`——写第 1 集以该文件为准，本节是其模块1的放大细则。

首集前 3-10 秒决定**完播率与付费率**，是整部剧的生死线。竖屏短剧没有"慢热回甘"的空间——观众的拇指随时在划走。

### 铁律：首集第 1 个镜头就是爆点

- **3 秒法则**：开播第 3 秒内，必须出现**一个具体的强冲突事件或强情绪炸点**（被打、被甩、被夺、被羞辱、被背叛、惊天身份/秘密当场揭穿、生死危机当场发生）。
- **10 秒法则**：第 10 秒内，主角的**核心困境/赌注**必须已经摆到观众面前（她要失去什么、被谁逼到绝境）。
- **严禁慢热铺垫**：禁止用"风景空镜 + 人物介绍 + 日常铺陈 + 缓慢入戏"开场。背景信息必须**塞进冲突里边打边交代**，绝不允许先讲背景再起冲突。

### 弱开场 vs 强开场（真实改写对照）

| ❌ 慢热弱开场（禁止） | ✅ 前3-10秒爆点强开场（正确） |
|---|---|
| 缆车缓缓升上雪山，男女主角并肩看风景，台词介绍各自身份、职业、来这里的原因，气氛温馨——第 40 秒才出现第一个矛盾。 | **0-3s**：缆车在半空猛地一震，急停。<br>女人：（抓住扶手，惊）怎么回事？！<br>**3-8s**：男人冷笑，手里举着剪断的安全绳。<br>男人：三年前你害死我妹妹的时候，有没有想过会有今天？<br>**8-10s**：缆车厢门被他一脚踹开，脚下是万丈深渊。女人脸色惨白往后缩。 |
| 女主早晨醒来，洗漱、做早餐、回忆和老公的甜蜜往事，出门上班路上接到一个电话说公司有事。 | **0-3s**：女主推开卧室门，老公和闺蜜赤身躺在她的床上。<br>**3-8s**：闺蜜拉过被子，慢悠悠笑：姐，姐夫说你早就是个空壳豪门，签了离婚协议吧。<br>**8-10s**：女主低头，看见自己刚验出的孕检单——两条杠。她攥碎了它。 |
| 老人衣着朴素在公司门口被保安拦下，保安态度恶劣，老人解释自己是来找人的，来回拉扯了半分钟。 | **0-3s**：保安一把推倒老人，老人摔在地上，手里的工牌甩了出去。<br>**3-8s**：工牌上写着"董事长 周振山"。保安没看见，抬脚就要踹。<br>**8-10s**：一排黑西装狂奔而来跪倒一片：周董！全场死寂。 |

### 首集开篇硬性 Checklist（不过即重写首集）

- [ ] **第 3 秒**：是否已出现一个具体的、可拍摄的强冲突动作或强情绪炸点（不是对话、不是空镜、不是介绍）？
- [ ] **第 10 秒**：主角的核心困境/赌注是否已经清晰摆出（观众已经知道 ta 要失去什么、被谁逼）？
- [ ] **零铺垫检测**：开篇有没有任何"先介绍后冲突"的段落？背景信息是否全部塞进冲突里交代？
- [ ] **情绪强度**：开篇炸点是否属于"被打/被甩/被夺/被羞辱/被背叛/生死危机/身份秘密当场揭穿"这一级别（而非普通的小摩擦）？
- [ ] **首镜即钩**：第一个镜头是否本身就是钩子（而不是钩子前还有一个过渡镜头）？

## 三类钩子

### 1. 开篇钩子（吸引观众进入）

**5 秒内必须出现**

| 类型 | 触发观众情绪 | 示例 |
|---|---|---|
| 冲突钩子 | 紧张 | 主角刚出场就被人推搡、踹门、扇耳光 |
| 悬念钩子 | 好奇 | 主角看一封信脸色大变，但镜头不给信的内容 |
| 危机钩子 | 担忧 | 主角站在天台，下一秒可能跳下去 |
| 身份钩子 | 期待 | 普通装扮的主角接到电话："裴总，集团那边等您决策" |
| 反差钩子 | 惊讶 | 邋遢老人转身一拳放倒三个壮汉 |

### 2. 中段钩子（维持注意力）

**30-45 秒处必须有小反转**

中段钩子的作用是**承接开篇情绪 + 推进新一轮悬念**。

### 3. 结尾钩子（推动观众继续）

**最后 5-10 秒必须有**

| 类型 | 描述 |
|---|---|
| 悬念延续 | 揭露一半，藏一半（"原来你就是……"切镜头） |
| 反转预告 | 一个意外事件，下一集才解释 |
| 危机升级 | 比开篇更大的危机出现 |
| 身份逼近 | 距离揭晓真相只差一步 |

## 钩子的反模式

- **过度铺垫**：给钩子之前先讲 30 秒背景——观众已经划走
- **答案太快**：开篇悬念在第 2 集就揭晓——失去后续动力
- **钩子太弱**：只是普通对话，没有情绪冲击
- **重复钩子**：每集都用同一种钩子（永远是身份钩子）——观众腻
- **钩子断层**：结尾钩子和下一集开头无关联——观众感觉被骗

## 单集钩子结构（短剧）

```
0-5s：开篇钩子（强冲突 / 强悬念）
5-30s：背景快速建立 + 矛盾升级
30-45s：中段反转 / 小高潮
45-90s：主体内容 + 推进核心冲突
最后 5-10s：结尾再钩子（更大悬念 / 危机升级）
```

## 检验清单

- [ ] 开篇 5 秒内是否抓住注意力？
- [ ] 中段是否有小反转？
- [ ] 结尾是否有更大悬念？
- [ ] 三个钩子的类型是否多样化？
- [ ] 钩子是否与本集核心情绪（压/放）匹配？
