# 欧美市场规则

> **写英文/海外短剧前，必读 `references/formats/english-short-drama.md`（英文短剧创作圣经）建立语感关键节点。** 本文件只管「本土化换皮」，不管腔调；腔调以英文短剧圣经为准。

## 0.0 最高心法：本土化是换皮，不是换骨（v6.2 新增 · 凌驾全文）

> **短剧就是短剧，换成英文还是短剧——狗血、强反转、即时爽点、脸谱反派、隐忍后爆发、巧合驱动，这些是短剧的「骨」（爽感内核），跨语言不变。本土化只换「皮」（人名、场景、文化逻辑），绝不能把短剧的骨给净化成好莱坞剧。**

这是本文件最高优先级心法,凌驾下方所有具体规则。理解这条,才不会把短剧写成 HBO：

| 该本土化的（换皮 · 强约束保留） | 不该净化的（换骨 · 严禁好莱坞化） |
|---|---|
| 人物姓名 → 西方地道姓名 | ✅ **保留**「隐忍后爆发」的爽感曲线（这是短剧灵魂,不是缺点） |
| 场景地名 → 美国都市/小镇 | ✅ **保留**狗血巧合（撞见出轨/隐藏富豪/突然怀孕/身份反转） |
| 家庭/职场/制度逻辑 → 西方 | ✅ **保留**脸谱化欠揍反派（观众要的就是看 ta 被打脸） |
| 文化细节 → 本地饮食/节庆/社交 | ✅ **保留**每集强反转、强钩子、即时爽点的高密度节奏 |
| 价值观表达 → 个人主义包装 | ✅ **保留**强情绪外放、打脸直给、台词短而狠 |

> **判据**：本土化做得好 = 「一个土生土长的西方爽剧」；做过头（净化成好莱坞）= 「一集没人想看完的 HBO 文艺片」。前者是目标,后者是事故。
>
> ⚠️ 模型最容易犯的错：一看英文项目,就自动切换到「高级、克制、逻辑自洽、政治正确、反派要立体」的好莱坞模式,把短剧的爽感全阉割掉。**英文短剧不是低配美剧,是视频版英文爽文。** 详见英文短剧圣经第二节「致命对照」。

## 0.1 中式故事套英文皮零容忍（v6.3 新增 · 一票否决）

> **"中式故事套英文皮"是假本土化：把一个中式故事，主角设成华裔，用中文名配英文别名，再贴上唐人街/玉佩/华裔世家，假装本土化了。这是中式内核换了张英文标签，比直接写中文还隐蔽，必须根除。**

### 🚫 明令禁止的具体模式（出现任一即重写）
1. **中文名配英文别名**：`苏念(Susan Su)`、`陆景深(Ethan Lu)`、`苏暖暖(Amy Su)` 这类「中文名（英文别名）」双名写法——**绝对禁止**。人名就是纯西方名（Emma Carter），不带任何中文。
2. **拼音名 / 中英混搭**：`Li Wei`、`David Wang`、`Lu Niannian`——禁止。
3. **把主角设成"华裔世家"以合理化中式元素**：用"主角是华裔"当借口塞进唐人街、中餐馆继承战、华裔参议员家族、家族祠堂、玉佩传家宝——禁止。英文短剧主角默认是**土生土长的西方人**，其故事**不需要任何中国元素来解释他是谁**。
4. **中式家庭/宗族逻辑套西方壳**：婆媳斗法、嫡庶之争、跪拜长辈、家族逼婚、认回豪门亲生——这些是中式内核，换成英文名也还是中式，禁止。改用西式等价物（prenup 博弈、继姐妹争产、mother-in-law 嫌弃儿媳、收养/secret baby 反转）。

### ✅ 正确做法
- 主角 = 纯西方人，纯西方名，故事 100% 发生在西方语境（曼哈顿、Hamptons、小镇狼群）。
- 需要"家族""传承""信物"时，用西式版本：old-money family、heirloom ring、trust fund、family estate、慈善晚宴。
- 美式人设按 `references/formats/english-short-drama.md` **第八节「美式角色原型库」**选角。

> **自检口令**：遮住所有人名，问"这个故事去掉中国元素还成立吗？"——若必须靠"主角是华裔"才能解释剧情里的中式元素，就是中式故事套英文皮，重写。正确的英文短剧里根本不需要"华裔"这个设定。

## 0. 全盘本土化铁律（v6.0.0 · 仅约束「换皮」层）

> **写海外短剧/海外内容，故事必须 100% 设定在海外（尤其美国），从里到外彻底本土化，不允许任何中式外壳换皮。**
>
> ⚠️ 注意：本节约束的是「场景/人名/文化外壳」的本土化,**不约束短剧的爽感骨架**（见 0.0 心法）。别把"去中式"误读成"去爽感"。

这是一条**前置硬约束**，优先级高于本文件其余具体规则。任一条不满足即判定为「中式换皮剧」，**不得输出，必须重写**：

1. **地理与场景**：故事发生地、地名、街区、地标、住宅形态（独栋/公寓/郊区）、通勤方式全部为目标国真实形态；禁止出现中式小区、单位大院、城中村等。
2. **人物姓名**：全部使用目标文化地道姓名（名+姓），禁止拼音名、禁止 "Li Wei / David Wang" 这类中英混搭，禁止中式辈分取名逻辑。
3. **人物性格与行为动机**：情感表达、冲突处理、亲子/两性相处方式符合当地文化心理；禁止中式隐忍、孝道压制、婆媳嫡庶、面子文化驱动的行为。
4. **社会与制度背景**：家庭、职场、法律、教育、医疗、阶层逻辑对齐目标国真实制度；禁止户口、编制、单位分房、高考、居委会等中国特有设定。
5. **文化细节**：饮食、节庆、社交礼仪、宗教、消费习惯、流行文化全部本地化；禁止春节/中秋/中式宴席/中式人情往来串味。
6. **价值观包装**：爽点（复仇/打脸/逆袭/宠妻）的**包装话术**按当地偏好（个人赋权/据理力争）,**而非把爽点本身删掉**（见 0.0 心法与第 2 节）。

> 自检口令：把剧本里所有人名、地名、文化符号遮住，单看人物动机与冲突，是否仍像一个土生土长的当地故事？若仍能闻到"中式味"，即未通过。

## 1. 尺度规则（v6.0.0 新增）

- **暴力/血腥**：欧美对动作、犯罪、惊悚的尺度容忍度高于国内，可保留更写实的冲突与后果，但避免无意义的残虐展示。
- **两性/亲密**：可有更直接的亲密关系表达与成人话题，但服务剧情而非堆砌；遵守投放平台分级（TV-14 / TV-MA 等）与各国监管。
- **语言**：允许符合人物身份的粗口与俚语以增强真实感，但匹配目标分级，不滥用。
- **底线**：始终规避未成年相关越界、仇恨歧视、违法行为美化等全球通用红线。

## 2. 价值观规则（v6.2 修订 · 区分「包装」与「爽感」）

> **核心：价值观只改「爽点的包装话术」，不改「爽点本身」。** 西方观众一样爱看复仇、打脸、逆袭、虐渣——只是要用西方能接受的方式包装（个人选择、自我赋权、据理力争的姿态）。但**爽感的内核（隐忍→爆发、当众打脸、坏人付出代价）必须保留**,这是短剧的命。

- **个人主义包装**：主角驱动力包装成自我实现、个人选择与边界（而非家族责任/集体期待）——但这是**话术包装**,逆袭/复仇/打脸的爽感内核照样要给足。
- **情感平等的底色**：两性、亲子关系底色平等尊重；但**霸总宠妻、命定狼人、强势追妻**这类 海外 头部爽点完全成立——西方观众照样吃"强大男主只对女主温柔"。平等是底色,不是去掉爽点。
- **爽点保留（关键修订）**：
  - ✅ **复仇/打脸/虐渣照写**——西方观众一样爱看坏人当众翻车,只是主角姿态包装成"据理力争/掌控全局"而非"泼妇撒泼"。
  - ✅ **"隐忍后爆发"照写**——这是短剧灵魂。区别只在:西方版的"隐忍"更短、爆发更主动(不是默默忍三年,是忍三集就出手)。
  - ✅ **霸总宠妻/灰姑娘逆袭/命定虐恋照写**——这些是 海外 现实款头部赛道,不要因为"独立女性"就删掉。让女主既被宠又有自我,而不是二选一。
  - ⚠️ 仅需注意:女主的逆袭最好**有自己的主动出手**(不能100%全靠男主送),但"有贵人/霸总助力"完全允许,且是爽点来源。
- **政治正确边界**：尊重多元（种族/性别/信仰），避免恶意刻板印象；但**不为正确而正确**,不能让"政治正确"成为删减爽点、把反派洗白、把节奏拖慢的借口。服务爽感优先。

## 3. 世界观轻量化规则（v6.0.0 新增）

- **低门槛入戏**：欧美短剧观众对复杂设定耐心低，世界观信息要边走边给，禁止开篇大段设定铺陈。
- **现实基底优先**：优先选用都市、家庭、职场、悬疑等贴近现实的轻世界观；超自然/架空元素需用一两句即可理解的"一句话规则"承载。
- **规则极简**：金手指/超能力/特殊设定遵循"一条核心规则 + 明确代价"，避免国产玄幻式的庞大体系与术语。
- **即时可信**：任何超现实设定都要在出现后极短时间内给出可信逻辑，不留长悬置。

## 4. 节奏规则（v6.2 修订 · 短剧节奏不打折）

- **强开场**：前 **3-10 秒**（不是15秒）内必须抛出核心冲突或反常爆点,欧美观众划走速度极快。开场即爆点,详见英文短剧圣经第四节。
- **每集有反转/爽点**：每集围绕清晰的小冲突推进,**且每集至少1个反转或爽点释放**。"目标导向"不等于"温吞渗透"——短剧的目标是让观众点下一集。
- **拥抱戏剧巧合（关键修订）**：短剧靠强戏剧性驱动,**狗血巧合是特征不是缺点**——撞见出轨、隐藏富豪身份、突然继承、命定相遇等该用就用。不要套用好莱坞"避免巧合"的洁癖。仅需注意:女主的**关键逆袭出手**最好有自己的能动性(不能全程纯靠天降外力),但助攻型巧合/贵人完全允许且是爽点来源。
- **留钩要狠不要"克制"（关键修订）**：集末钩子就是要**反转、要悬念升级、要勾人**。不要套用"避免为反转而反转"的好莱坞教条——短剧的钩子密度正是来自高频反转。唯一底线:钩子别和已建立的设定硬冲突(逻辑别穿帮),但"出乎意料"本身是优点不是缺点。

## 反模式规则适配（v6.2 修订 · 本地优化但不阉割爽感）

欧美市场偏好逻辑相对自洽、人物有记忆点、情感平等的**包装**,但**短剧爽感骨架照旧**。通用反模式阈值做以下适配（注意:是适配不是净化）：
1. **剧情循环阈值**：同一种解法（路径）连续用≤2次——这是防套路重复,**不是禁止强反转**。反转和爽点该给照给,只是手法要轮换。
2. **外力兜底**：女主的**核心终局逆袭**应有自己的能动性,不要100%靠天降救兵收尾。但**助攻型贵人/霸总/巧合完全允许且鼓励**(它们是爽点来源),不设僵硬的"≤30%"百分比红线——只要女主在关键节点有主动出手即可。
3. **反派要"立体的欠揍"而非"洗白的复杂"**：反派可以(也应该)脸谱化地嚣张欠揍,这是打脸爽感的前提。"自洽动机"的要求降为:给反派一个**一句话能说清的动机**(贪婪/嫉妒/虚荣)即可,**不要求把反派写得让观众同情**——观众要的是看 ta 翻车,不是理解 ta。
4. **表达重复阈值**：同一微表情/动作全剧≤2次,调用情绪表达变体库轮换(此条保留,防机械重复)。
5. **核心保留**：女主要有成长弧光和闪光点(防工具人),但**"被宠/被助力"与"独立成长"可以并存**,不是二选一。禁止的是把女主写成全程被动的花瓶,不是禁止她接受帮助。

## 本土化强制校验清单（必过 · v3.3 新增）

所有欧美项目生成前必须逐项校验，**任一项不合格不得输出**：

1. ☐ 人物姓名为本土姓名，无拼音、无中英混搭（如 "Li Wei" 这类一律不行）
2. ☐ **无中式故事套英文皮**（v6.3）：无「中文名（英文别名）」双名写法（如 苏念(Susan Su)）、无"主角是华裔"借口塞中式元素、无唐人街/玉佩/华裔世家/中餐馆继承战（详见 0.1 节，一票否决）
3. ☐ 家庭/职场/社交逻辑符合欧美文化，无中式婆媳、家族嫡庶、单位体制、户口/编制等设定
4. ☐ 爽点逻辑对齐本地偏好：复仇/打脸/逆袭/霸总宠妻照写,只是**包装**成西方姿态（据理力争/掌控全局/个人赋权,而非泼妇式撒泼）；女主关键逆袭有自己的能动性（可有贵人助攻,但非全程被动）
5. ☐ 场景、地名、生活细节符合当地现实，无中式美食、中式节庆、中式社交习俗串味
6. ☐ 反派动机一句话能说清（贪婪/嫉妒/虚荣即可），脸谱化欠揍是优点不是缺点——不要求把反派写复杂到让观众同情（与 0.0 心法、第 2/4 节联动）

> 注：东南亚、拉美、日韩市场参照本清单，按各自 `markets/` 文件的偏好做对应文化的本土化校验。要求好莱坞格式排版时，另见 `references/formats/hollywood-script.md`。
