## 一句话定位

卖"被弃单亲妈妈+天才萌宝，多年后撞上隐藏富豪生父，孩子牵线+身份反转双爆点"。萌宝是**情感关键节点+剧情引擎**，不是单纯卖萌。欧美吃 single-dad/secret-baby，东南亚拉美吃带球跑团宠。

> ⚠️ **本土化铁律（最高优先级）**：英文输入下，萌宝叫 Liam / Lily / Emma，**绝不叫陆念念/苏暖暖**；爹是 Ethan Sterling 不是陆景深；场景在曼哈顿 penthouse / 德州小镇，不在中式豪门大宅。人名/场景/制度 100% 西方化，骨架（孩子认爹+打脸+团宠）是海外 secret-baby 原生爽感结构。详见 `formats/english-short-drama.md` 第八节美式角色原型库。

## 爆款内核公式

被弃/分离 → 单亲妈带娃苦撑 → 撞上隐藏富豪生父 → 孩子撞脸+认亲 → 身份反转打脸 → 假家庭变真。

爽感公式：**爽感 = 母子受苦的深度 × 生父身份落差 × 孩子认亲的催泪强度 × 打脸羞辱者的解气度**。

## 目标市场与语言

- 主力市场：海外·欧美（single-dad/secret-baby）+ 东南亚拉美（带球跑团宠）。
- 本土化：萌宝名/生父身份/场景全西式；亲子鉴定走 DNA test 美式逻辑，不走中式"抱错认孙"。
- 输出语言：按用户语言（英文为主）。

## 必备桥段清单（每部至少命中 6 个）

- [ ] 母子受难开场（渣爹弃子/萌宝求救，1分钟立反派+真男主）
- [ ] 撞脸认亲（孩子长得和生父一模一样，信息差埋钩）
- [ ] 萌宝护母怼成人（早熟挡场面，反差萌+催泪）
- [ ] 绝境签约/求助（孩子医药费逼女主接受男主帮助，"I'll do it"两字定格）
- [ ] 富豪扮穷/隐藏身份（卧底查案动机）
- [ ] 财力轻碾打脸（反派炫富，男主随手更高一级碾压）
- [ ] DNA 亲子鉴定反转
- [ ] 口误叫"Dad"→ 全场静默（情感临界）
- [ ] 仪式揭身份（婚礼/继任仪式当众揭真身，反派石化）
- [ ] 结尾"nobody corrected him"（孩子再叫 Dad 无人纠正=家庭达成，终极泪点）

## 可直接调用的爽句式（详见 `formats/english-short-drama.md` 第六节萌宝/契约/身份反转类）

- 撞脸认亲：`"Why does [that kid] look just like [you when you were young]?"`【认亲前摇】
- 萌宝护母：`"We don't have a dad. [Mommy] will always love us, so be polite."`【早熟催泪】
- 绝境签约：长时间沉默后一句 `"I'll do it."`【妥协爽点·付费点定格】
- 身份反转：`"How did [a janitor / a nobody] end up married to the richest man in the world?"`【旁人震惊·万能反转句】
- 认爹高潮：`"This time, nobody corrected him."`【家庭达成·终极泪点】

## 差异化着重注意点

1. **苦情敢上强度**——海外版可用儿童濒死/家暴/灵魂出窍视角开场，不铺垫直接上压戏
2. **萌宝是引擎不是装饰**——孩子的病情/认亲推动主线，每个萌宝金句都服务于"母子被看见"
3. **多反派接力**——替身/势利眼/渣前任用不同手段轮番施压（社交→权力→暴力），打脸分波次
4. **女主要有能动性**——新版趋势让女主主动调查翻案，避免纯被拯救的花瓶
5. **生父马甲动机要具体**——扮穷绑定"查罪案/避杀/夺权"，比"考验真心"更有情节驱动力

## 避坑清单

- 萌宝叫中文名/出现中式豪门大宅 → 中式故事套英文皮，整体重写（一票否决）
- 萌宝纯卖萌不推动剧情 → 沦为工具，失去引擎功能
- 认亲拖太久不揭 → 观众失去耐心，DNA/撞脸钩子要在付费点兑现
- 女主全程被动等救 → 不符合现代海外女性观众偏好
- 苦情过度变虐儿 → 把握平台尺度，濒死/受难点到为止，重点在反转释放
