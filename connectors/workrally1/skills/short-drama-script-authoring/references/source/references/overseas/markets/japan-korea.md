# 日韩市场本土化规则

## 市场画像
- 覆盖区域：日本、韩国
- 核心受众：20-40岁女性为主，日本偏写实悬疑，韩国偏狗血爽感
- 平台特征：日本以垂直短剧APP、漫画改编为主；韩国以抖音式竖屏爽剧为主
- 付费习惯：中后段付费意愿强，看重剧情逻辑与人物成长

## 分区域偏好修正
### 韩国市场
#### 标签偏好
- 高爆标签：豪门复仇、狗血换身、财阀秘辛、姐弟恋、重生逆袭
- 接受度高：强反转、强狗血、女主黑化复仇、婆媳大战
- 需弱化：过度傻白甜、无脑甜宠、过于含蓄的情感表达

#### 内容规则
- 人物：女主必须有成长弧光，从隐忍到黑化复仇，全程爽感递增
- 节奏：反转密度极高，每5集一个大反转，不拖沓
- 尺度：接受适度狗血、肢体冲突，拒绝过于低俗的内容
- 反派：坏得彻底，最终惩罚要足够解气，不能轻易原谅

### 日本市场
#### 标签偏好
- 高爆标签：职场写实、悬疑志怪、校园纯爱、家庭伦理、异世界穿越
- 接受度高：细腻情感、职场成长、志怪恐怖、轻喜剧
- 需弱化：过度狗血、强行打脸、悬浮金手指

#### 内容规则
- 人物：行为逻辑要写实，符合日本社会规则，不能过于跳脱
- 节奏：前期慢热铺垫，中期集中爆发，注重细节与情绪
- 风格：氛围感强，台词克制，注重留白与潜台词
- 价值观：重视职场伦理、家庭责任，拒绝过度拜金与炫富

## 通用避坑红线
1. 严格规避历史敏感问题、领土争议内容
2. 尊重当地社会文化与职场规则，避免常识错误
3. 日本市场禁止过度渲染暴力、血腥
4. 韩国市场财阀设定要符合当地认知，不能过于脱离现实
5. 严格遵守当地放送伦理，避免低俗擦边内容

## 反模式适配
- 韩国：剧情循环阈值可放宽至3-4次，兜底占比≤50%，强爽感优先
- 日本：剧情循环严格≤2次，逻辑自洽优先级高于爽感，禁止强行开挂
