## 一句话定位

卖"男方后悔的解气 + 女主清醒的掌控感"。**这是国内"打脸前任"的镜像反转**——海外爱看男方后悔，不是女主带新欢打脸。

## 爆款内核公式

男主辜负/误解女主 → 女主离开/重生 → 男主追悔莫及 → 卑微追妻。

爽感公式：**爽感 = 男主悔悟卑微度 × 女主清醒飒爽度 × 男主付出的代价**。

## 目标市场与语言

- 主力市场：海外·欧美。
- 输出语言：默认英文（按用户语言），人名场景本土化。

## vs 国内同类的关键差异（最容易翻车的点）

| 维度 | 国内打脸流 | 海外追妻火葬场 |
|---|---|---|
| 女主爽感来源 | **带新霸总打脸前任** | **看前任/前夫后悔卑微** |
| 男主角色 | 被碾压的反派 | **悔悟的男主角**（仍是男主） |
| 情感落点 | 女主开启新恋情 | 女主"虐渣"或"有限度回头" |
| 观众爽点 | 解气（换更好的） | 解气（让你后悔）+ 掌控感 |

**照搬国内"带新男友打脸"套路会翻车**——海外观众想看的是旧爱后悔。

## 人物配置（差异化）

| 角色 | 本题材特殊要求 |
|---|---|
| 男主 | **先贱后悔**型——前期辜负（忽视、误解、偏心白月光），后期觉醒疯狂追妻 |
| 女主 | **清醒离开**型——不哭不闹，转身变强/变美/离开，让男主后悔 |
| 白月光/小三 | 前期男主犯错的诱因，后期被打脸 |

与相邻题材区别：
- vs 国内复仇：国内女主"换更好的打脸"，本题材男主"后悔追妻"
- vs 霸总甜宠：甜宠是全程被宠，本题材是先虐（被辜负）后爽（看后悔）

## 节奏卡点表（80 集模板）

| 集数 | 事件 | 弹簧类型 |
|---|---|---|
| 1 | 男主辜负女主（忽视/偏心白月光，钩子） | 压（极） |
| 5 | 女主清醒，决意离开 | 压→放（小） |
| 10 | 付费点 1：女主华丽转身/变强 | 放 |
| 20 | 付费点 2：男主开始后悔、察觉失去 | 放 |
| 30 | 付费点 3：男主当众卑微挽回 | 放（极） |
| 40-65 | 男主持续追悔 + 女主清醒应对 | 放为主 |
| 70-80 | 虐渣到底 或 有限度回头（男主付足代价） | 放→平稳 |

节奏特征：**悔悟流**。男主犯错（压）→ 女主离开觉醒（小放）→ 男主追悔（持续放）。男主越卑微追、女主越清醒走，越爽。

## 必备桥段清单（每部至少命中 5 个）

- [ ] 男主忽视/误解/偏心白月光，伤害女主
- [ ] 女主不哭不闹、清醒决意离开
- [ ] 女主华丽变身（变强/变美/事业成功）
- [ ] 男主第一次察觉"她好像不一样了"
- [ ] 男主醒悟真爱、追悔莫及
- [ ] 白月光真面目暴露、被打脸
- [ ] 男主当众卑微挽回
- [ ] 女主清醒回应（"我过得很好，与你无关"）

## 差异化着重注意点

1. **核心反转是"男主后悔"而非"女主换人打脸"**——这是和国内最大区别，照搬必翻车
2. 女主的"飒"要**克制高级**——不是泼妇式报复，是"我过得很好与你无关"的清醒
3. 结局可虐渣到底也可有限度回头，但回头必须让男主**付出足够代价**

## 避坑清单

- 直接用国内"带新男友打脸"套路 → 海外观众想看旧爱后悔
- 女主歇斯底里 → 要清醒飒爽
- 男主追悔不够卑微 → 爽感不足
- 男主无代价就复合 → 观众不买账
