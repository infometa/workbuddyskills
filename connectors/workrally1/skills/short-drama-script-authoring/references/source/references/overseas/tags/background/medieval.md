## 二、变体素材库（仅参考·可自由组合·可原创·可豁免）
> 本节全部为灵感启发，**不强制命中、不作评分依据**，可自由组合/原创/豁免。

### 1. 节奏适配逻辑
常见节奏：卑微出身/失落身份 → 卷入王权或骑士纷争 → 凭勇气与谋略攀升 → 加冕/复仇/守护登顶。付费节点可落在身份揭晓、决斗胜利、宫廷反杀、加冕时刻——仅为参考。

### 2. 核心变体素材（任选，不限数量）
#### 场景素材
1. 城堡场景：王座厅、地牢、护城河、塔楼、宴会大厅
2. 骑士场景：比武场、战场、圆桌、授勋仪式
3. 市井场景：铁匠铺、酒馆、集市、修道院
4. 权谋场景：密室议事、联姻谈判、加冕典礼

#### 台词风格素材
1. 骑士誓言：忠诚、荣耀、守护的正式化语言
2. 宫廷辞令：迂回、克制、暗藏机锋的贵族对话
3. 平民口吻：质朴直接，带时代粗粝感
4. 誓死宣言：为荣誉/王权/爱人赴死的悲壮台词

#### 行为逻辑素材
1. 阶层跨越：以军功、联姻、血脉揭晓改变身份
2. 荣誉驱动：骑士为誓言与荣耀行动
3. 王权博弈：继承权、联姻、叛乱的权力逻辑
4. 生存抗争：底层在封建秩序下的挣扎与突围

#### 付费卡点变体
1. 身份揭晓节点（失落的王子/私生血脉）
2. 决斗/攻城胜利节点
3. 宫廷反杀节点
4. 加冕/复仇达成节点

### 3. 钩子参考模板
- 开篇钩子参考：一个卑微者在城堡阴影下立誓，或一场改变命运的决斗前夜
- 集末钩子参考（仅启发）：
  1. 身份式：原来他才是真正的王位继承人
  2. 背叛式：最信任的骑士，剑却指向了她
  3. 逆袭式：这一战，落魄骑士要夺回一切

## 五、红线与反模式
> 红线severity：弱

### 1. 避坑提示（不挂质检号、不扣分，仅创作提醒）
1. 避免时代错乱：混入火器/现代观念/东方元素（如玉佩、中式称谓）。
2. 避免世界观悬浮：城堡权力逻辑不成立，加冕/继承规则随意。
3. 避免文化贴皮：只有中世纪外壳，行为逻辑仍是现代/中式。
4. 避免过度血腥或渲染封建压迫为正面价值。

> 弱红线标签不挂全局质检号；上述风险若上升为崩级问题（如世界观硬伤），由 anti-patterns.md 通用反模式兜底检测扣分。
