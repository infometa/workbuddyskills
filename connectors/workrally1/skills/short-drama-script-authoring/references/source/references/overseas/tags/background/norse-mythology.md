## 二、变体素材库（仅参考·可自由组合·可原创·可豁免）
> 本节全部为灵感启发，**不强制命中、不作评分依据**，可自由组合/原创/豁免。

### 1. 节奏适配逻辑
常见节奏：凡人/半神觉醒 → 卷入神界纷争或命运预言 → 对抗宿命/诸神 → 牺牲或改写命运。付费节点可落在血脉觉醒、神器夺取、诸神对决、命运逆转——仅为参考。

### 2. 核心变体素材（任选，不限数量）
#### 场景素材
1. 神域场景：阿斯加德、彩虹桥、英灵殿、世界树
2. 凡界场景：维京长屋、峡湾、战船、符文石
3. 战斗场景：诸神黄昏战场、巨人国、冥界
4. 仪式场景：符文占卜、血祭、英灵宴饮

#### 台词风格素材
1. 神谕预言：晦涩、宿命、不可违逆的命运宣告
2. 维京豪言：崇尚勇武与荣耀战死的粗犷宣言
3. 神祇辞令：高傲、疏离、带神性威压
4. 悲壮独白：明知宿命仍抗争到底的觉悟

#### 行为逻辑素材
1. 血脉觉醒：凡人发现半神/英灵血统
2. 命运抗争：对抗预言中注定的结局
3. 荣耀至上：为战死英灵殿而无畏赴战
4. 神界博弈：神祇间的权谋、背叛与结盟

#### 付费卡点变体
1. 血脉/神性觉醒节点
2. 神器（雷神之锤等）夺取节点
3. 诸神对决节点
4. 改写命运/诸神黄昏逆转节点

### 3. 钩子参考模板
- 开篇钩子参考：一个凡人在符文石前触发神性觉醒，或诸神黄昏预言降临
- 集末钩子参考（仅启发）：
  1. 觉醒式：他掌心浮现的符文，是神的血脉
  2. 宿命式：预言说她将亲手毁灭所爱之人
  3. 逆天式：诸神注定的黄昏，他偏要改写

## 五、红线与反模式
> 红线severity：弱

### 1. 避坑提示（不挂质检号、不扣分，仅创作提醒）
1. 避免神话体系混淆：北欧神祇与希腊/东方神祇混用。
2. 避免神性悬浮：神力规则随意、诸神黄昏逻辑不成立。
3. 避免文化贴皮：只借神名，故事内核仍是现代都市剧。
4. 避免过度宿命论导致主角失去能动性。
