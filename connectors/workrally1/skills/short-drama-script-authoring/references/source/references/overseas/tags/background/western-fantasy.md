## 二、变体素材库（仅参考·可自由组合·可原创·可豁免）
> 本节全部为灵感启发，**不强制命中、不作评分依据**，可自由组合/原创/豁免。

### 1. 节奏适配逻辑
常见节奏：平凡者觉醒魔法/被卷入异世界 → 组队冒险/对抗黑暗势力 → 力量成长与羁绊建立 → 击败魔王/拯救世界。付费节点可落在魔法觉醒、龙/魔物讨伐、力量升级、终极对决——仅为参考。

### 2. 核心变体素材（任选，不限数量）
#### 场景素材
1. 奇幻场景：魔法学院、精灵森林、矮人矿坑、龙巢
2. 冒险场景：地下城、魔王城、远古遗迹、魔法塔
3. 城镇场景：冒险者公会、魔法商店、酒馆
4. 战斗场景：魔法对决、屠龙战场、种族大战

#### 台词风格素材
1. 咏唱台词：魔法吟唱、咒语、契约誓言
2. 冒险者口吻：热血、直率、重视伙伴的江湖气
3. 异种族辞令：精灵的高雅、矮人的粗豪、龙族的威严
4. 中二宣言：觉醒力量或立誓守护的热血台词

#### 行为逻辑素材
1. 魔法觉醒：平凡者发现魔法天赋/血脉
2. 组队冒险：与异种族伙伴结成羁绊征战
3. 力量成长：等级/魔法/装备的可视化升级
4. 拯救世界：对抗魔王/黑暗势力的宏大目标

#### 付费卡点变体
1. 魔法/血脉觉醒节点
2. 龙/强大魔物讨伐节点
3. 力量突破升级节点
4. 魔王终极对决节点

### 3. 钩子参考模板
- 开篇钩子参考：一个平凡少年觉醒禁忌魔法，或被传送到剑与魔法的异世界
- 集末钩子参考（仅启发）：
  1. 觉醒式：他体内封印的，是失传的龙族血脉
  2. 危机式：魔王的军队，已兵临王国城下
  3. 逆袭式：被嘲笑的废柴，魔法天赋竟是传说级

## 五、红线与反模式
> 红线severity：弱

### 1. 避坑提示（不挂质检号、不扣分，仅创作提醒）
1. 避免体系混淆：西方魔法与东方修真/灵气混用。
2. 避免力量崩坏：魔法/等级规则前后矛盾，升级无代价。
3. 避免文化贴皮：只有奇幻外壳，行为仍是现代校园/都市。
4. 避免设定过载：种族/魔法/势力堆砌过多，解释成本过高（对齐设定过载红线）。

> 弱红线标签不挂全局质检号；上述风险若上升为崩级问题（如世界观硬伤），由 anti-patterns.md 通用反模式兜底检测扣分。
