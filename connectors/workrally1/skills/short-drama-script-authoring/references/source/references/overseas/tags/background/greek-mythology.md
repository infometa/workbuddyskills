## 二、变体素材库（仅参考·可自由组合·可原创·可豁免）
> 本节全部为灵感启发，**不强制命中、不作评分依据**，可自由组合/原创/豁免。

### 1. 节奏适配逻辑
常见节奏：凡人/半神受神眷或诅咒 → 踏上英雄试炼或卷入神祇爱恨 → 对抗命运/怪物/神谕 → 封神、殒落或改写神谕。付费节点可落在神谕降临、怪物讨伐、神祇现身、命运逆转——仅为参考。

### 2. 核心变体素材（任选，不限数量）
#### 场景素材
1. 神域场景：奥林匹斯山、神殿、德尔斐神谕所
2. 凡界场景：城邦、竞技场、爱琴海、迷宫
3. 冒险场景：冥界、怪物巢穴、英雄试炼地
4. 仪式场景：神谕占卜、献祭、英雄加冕

#### 台词风格素材
1. 神谕辞令：模糊双关、暗藏悲剧的预言
2. 英雄豪言：追求荣耀与不朽之名的宣言
3. 神祇口吻：任性、善妒、掌控凡人命运的傲慢
4. 悲情独白：与神抗争或被命运捉弄的哀叹

#### 行为逻辑素材
1. 英雄试炼：完成神话式伟业证明价值
2. 神人纠葛：与神祇的爱恨、恩怨、契约
3. 命运抗争：对抗神谕预言的悲剧结局
4. 半神成长：从凡人成长为封神的英雄

#### 付费卡点变体
1. 神谕/预言降临节点
2. 怪物讨伐（美杜莎/牛头人等）节点
3. 神祇现身/干预节点
4. 命运逆转/封神节点

### 3. 钩子参考模板
- 开篇钩子参考：一则德尔斐神谕预示悲剧命运，或一个半神被抛入英雄试炼
- 集末钩子参考（仅启发）：
  1. 神谕式：预言说他终将弑父，命运已然启动
  2. 神眷式：奥林匹斯之神，选中了这个凡人
  3. 逆命式：神注定的悲剧，她要亲手打破

## 五、红线与反模式
> 红线severity：弱

### 1. 避坑提示（不挂质检号、不扣分，仅创作提醒）
1. 避免神话体系混淆：希腊神祇与北欧/罗马/东方神祇混用（宙斯≠朱庇特混称）。
2. 避免神话悬浮：神谕/试炼逻辑随意，神力规则不自洽。
3. 避免文化贴皮：只借神名，故事仍是现代言情套壳。
4. 避免弱化英雄能动性，全靠神祇施舍。

> 弱红线标签不挂全局质检号；上述风险若上升为崩级问题（如世界观硬伤），由 anti-patterns.md 通用反模式兜底检测扣分。
