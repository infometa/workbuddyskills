## 二、变体素材库（仅参考·可自由组合·可原创·可豁免）
> 本节全部为灵感启发，**不强制命中、不作评分依据**，可自由组合/原创/豁免。

### 1. 节奏适配逻辑
常见节奏：抛出脑洞 → 建立规则 → 围绕设定制造冲突 → 反转兑现，新奇感快速立住。付费节点可落在脑洞揭示、规则反转、设定驱动的高潮等处——仅为参考位置，不强制。

### 2. 核心变体素材（任选，不限数量）
#### 新奇设定爽点变体
1. 超能设定型：独特能力/规则带来反常识体验
2. 异空间型：进入特殊空间或位面的奇遇
3. 时间循环型：循环或倒流机制下的博弈
4. 身份互换型：灵魂互换/身份错位的奇趣

#### 冲突模式变体
1. 规则博弈型：在设定规则内寻找破局之道
2. 代价权衡型：使用能力需付出对应代价
3. 异类排斥型：因特殊设定遭遇外界阻力
4. 失控危机型：脑洞设定失控带来的挑战

#### 人设风格变体
1. 机智探索型：在新规则中快速适应破局
2. 反差萌型：平凡外表与奇幻能力的反差
3. 冷静掌控型：从容驾驭设定的优势

#### 付费卡点变体
1. 脑洞揭示节点：核心设定亮相的惊喜
2. 规则反转节点：设定带来的意外转折
3. 设定高潮节点：围绕脑洞的关键爆发

### 3. 钩子参考模板
- 开篇钩子参考：从反常识设定切入，建立新奇与好奇预期
- 集末钩子参考（仅启发）：
  1. 新奇式：这个世界的规则，远比想象中疯狂
  2. 悬念式：触发这个设定后，一切都将改变
  3. 反转式：原来这个能力，还藏着惊人的代价

## 五、红线与反模式
> 红线severity：弱

### 1. 避坑提示（不挂质检号、不扣分，仅创作提醒）
1. 避免脑洞无规则、逻辑崩盘，设定前后自相矛盾。
2. 避免只停留概念、无法落地为具体戏剧冲突。
3. 避免设定过于复杂、理解门槛高，劝退观众。
4. 避免高开低走，开篇惊艳后期设定后继乏力。

> 说明：奇幻脑洞即使不守这些点，通常只是"不够好"而非"剧情崩塌"，故定为弱红线、不挂全局质检号。设定不自洽若达崩级，由 anti-patterns.md #7 世界观硬伤兜底。

## 七、融梗亲和性（v5.3 新增）

### 增强型
- **系统** → fusion/recipes/system-counterattack.md：系统为脑洞设定提供可视化的规则与数值反馈，让反常识创意从"抽象概念"落地为可操作、可升级的戏剧机制，新奇感更具体可感。
- **穿越** → fusion/recipes/time-travel-system.md：穿越把脑洞设定嵌入跨时空语境，时间循环/位面差异带来天然的反常识冲突场，惊喜感倍增。

### 对冲型
- 无（奇幻脑洞的情绪内核偏正向的新奇与惊喜，不携带对立情绪，不与其他标签产生情绪对冲）

### 裂变型
- 穿越/系统 × 奇幻脑洞：当脑洞与穿越或系统叠加时，原本静态的"反常识设定"会裂变为可成长、可博弈的动态规则体系，叙事重心从"展示设定之奇"转向"在规则中破局升级"。
