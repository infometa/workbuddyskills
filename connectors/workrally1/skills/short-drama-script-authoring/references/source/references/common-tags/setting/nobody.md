## 二、变体素材库（仅参考·可自由组合·可原创·可豁免）
> 本节全部为灵感启发，**不强制命中、不作评分依据**，可自由组合/原创/豁免。

### 1. 节奏适配逻辑
常见节奏：平凡受挫 → 契机起势 → 努力积累 → 逆袭翻身。付费节点可落在首次破局、能力被认可、当众逆转、阶层跃迁等处——仅为参考。

### 2. 核心变体素材（任选，不限数量）
#### 逆袭爽点变体
1. 努力起家型：从最底层靠勤奋与脑子一步步打拼
2. 技能傍身型：凭一技之长被伯乐发现，迎来转机
3. 隐忍蓄力型：受尽白眼默默积累，关键时刻一鸣惊人
4. 草根智斗型：用接地气的智慧破解高位者的算计

#### 冲突模式变体
1. 阶层歧视型：被瞧不起、被刁难，逆袭后打脸
2. 资源碾压型：对手有背景，小人物以弱胜强
3. 信任危机型：被构陷背锅，自证清白后翻盘
4. 抉择考验型：在利益与底线间坚守本心

#### 人设风格变体
1. 憨厚踏实型：老实肯干，靠人品与坚持赢得机会
2. 机灵市井型：嘴甜脑活，左右逢源化险为夷
3. 倔强硬气型：不服输、不低头，越压越强
4. 平凡英雄型：普通身份却有不凡担当

#### 付费卡点变体
1. 起势节点：抓住关键契机迎来人生转折
2. 打脸节点：当众逆转，曾经看轻者哑口无言
3. 跃迁节点：完成阶层跨越的高光时刻

### 3. 钩子参考模板
- 开篇钩子参考：主角被生活与他人按在谷底，埋下逆袭翻身的强烈预期
- 集末钩子参考（仅启发）：
  1. 起势式：所有人都没想到，这个不起眼的人会是变数
  2. 打脸式：你看不起的人，正在变成你高攀不起的人
  3. 悬念式：他手里的那张底牌，足以掀翻整个局面

## 三、人设加成参考
1. 主角：出身平凡、起点低，但有韧性与成长性；逆袭靠自身努力而非纯外挂。
2. 伯乐/盟友：发现并助力主角的关键人物，但不替主角完成关键胜利。
3. 对照组：高位刁难者、势利眼，反衬主角的逆袭与品格。
> 仅为方向参考，具体设定可自由发挥。

## 四、标签规则体系
### 1. 强互斥（不可叠加）
开局即巅峰（与"底层起点"冲突）、纯躺赢无成长设定。
### 2. 兼容增强（推荐叠加）
逆袭打脸、扮猪吃虎、马甲、强者回归、赘婿、复仇。
### 3. 优先级排序
- 逆袭（主题主线）> 小人物（小人物为身份底色，成长弧光优先）。

## 五、红线与反模式
> 红线severity：弱

### 1. 避坑提示（不挂质检号、不扣分，仅创作提醒）
1. 避免刻意卖惨堆砌苦难，为惨而惨，削弱逆袭爽感。
2. 避免无成长秒变强，缺乏过程铺垫，逆袭悬浮不可信。
3. 避免性格割裂，从懦弱到强势转变生硬，人设不连贯。
4. 避免全靠外挂/贵人躺赢，主角自身能力缺位，丢失代入感。

> 弱红线标签不挂全局质检号；上述风险若上升为崩级问题（如人设漂移），由 anti-patterns.md 通用反模式（#8 性格漂移等）兜底检测。

## 七、融梗亲和性（v5.3 新增）

### 增强型
- **逆袭打脸** → fusion/recipes/system-counterattack.md：逆袭主线为小人物的代入感提供"从低到高"的爽感曲线，打脸高光让底层翻身的扬眉吐气有了集中爆发点。
- **马甲** → fusion/recipes/mask-face-slap.md：隐藏底牌的层层揭晓为草根逆袭加挂反转，越被轻视、揭晓时的反差打脸越解气，强化"高攀不起"的逆袭快感。

### 对冲型
- 无（小人物的情绪内核偏正向逆袭成长，不与其他标签产生情绪对冲）

### 裂变型
- 无（小人物作为身份底色型标签，其核心机制"底层凭努力逆袭"不被其他标签根本改变）

### 互斥标签
- 开局即巅峰、纯躺赢无成长设定——与"底层起点+成长弧光"冲突，已列入强互斥。其余大多数标签可兼容。
