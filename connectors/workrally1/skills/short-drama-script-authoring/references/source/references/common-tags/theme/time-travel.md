# 主题标签：穿越
> 官方标签映射：主题 · 穿越
> 定位属性：level-2 弱红线 · 现代灵魂在异世界的降维优势与身份错位
> 核心情绪：开天眼、异世降维、已知未来、身份错位

> 映射说明：穿越映射 domestic/rebirth combo——穿越与重生共享"重来/已知"的情绪内核，穿越侧重跨世界降维，重生侧重同世界重来。

## 二、变体素材库（仅参考·可自由组合·可原创·可豁免）
> 本节全部为灵感启发，**不强制命中、不作评分依据**，可自由组合/原创/豁免。

### 1. 节奏适配逻辑
常见节奏：穿越落地 → 身份错位/适应期 → 现代知识降维 → 本地规则碰撞 → 身份回归/世界融合。穿越的核心爽感来自"信息差碾压"和"身份错位"——她/他知道别人不知道的事，但她/他也要面对自己不熟悉的规则。付费节点可落在穿越初期身份揭露、现代知识首次降维、世界规则碰撞反转等处——仅为参考。

### 2. 核心变体素材（任选，不限数量）

#### 情绪内核
穿越的情绪引擎：开天眼（知道未来的走向和人物的命运）、异世降维（现代知识在古代/异世界的碾压感）、已知未来（预判事件走向的爽感）、身份错位（不属于这个世界的孤独与适应）。核心爽感来自"信息差+降维"，但也要有"知识失效"的反转来制造冲突。

#### 高频套路提示（非禁用需翻转）
1. 穿越即开挂型：穿越后凭借现代知识无限制碾压 → 需翻转：必须有本地规则让现代知识失效或受限，否则无冲突
2. 穿越即原主型：穿越后继承原主身份和麻烦 → 需翻转：原主的烂摊子必须真有难度，不是轻松就能解决
3. 穿越即失忆型：穿越后失去现代记忆 → 需翻转：记忆恢复必须有节奏，不能一口气全回来
4. 穿越即任务型：穿越有必须完成的任务/使命 → 需翻转：任务必须有代价，失败有真实后果

#### Top3 对照关键节点
1. 《庆余年》——穿越降维天花板：现代知识在古代的碾压与局限，有知识也有无能为力
2. 《赘婿》——商战穿越型：现代商业思维在古代的降维打击，知识落地有逻辑
3. 《传闻中的陈芊芊》——穿书型：知道剧情走向但发现自己改变了剧情，已知变未知

#### 创作思考步骤
1. 先确定"穿到哪里"——穿越目标世界的规则是什么，现代知识的优势和局限分别在哪
2. 再确定"穿成谁"——原主身份带来了什么麻烦和什么资源
3. 然后确定"穿来干什么"——穿越的驱动力（回家/生存/改变命运/完成任务）
4. 最后确定"穿不过什么"——现代知识在哪里失效，让穿越者也有困境

#### 穿越类型变体
1. 穿古型：现代灵魂穿入古代身体，现代知识降维
2. 穿书型：穿入小说/剧本世界，已知剧情走向
3. 穿异界型：穿入完全不同的世界体系（修仙/魔法/异能）
4. 穿未来型：穿入未来世界，过去知识反而成为独特优势
5. 反穿型：古代/异世界灵魂穿入现代，文化冲击型

#### 信息差利用变体
1. 预知型：知道未来事件走向，提前布局
2. 技术型：掌握现代技术/知识，在异世界降维
3. 视角型：上帝视角看人物关系，识破阴谋
4. 文化型：现代思维/价值观在异世界的降维

#### 付费卡点变体
1. 首次降维节点：穿越者首次用现代知识碾压，爽感爆发
2. 知识失效节点：现代知识首次碰壁，身份/世界观危机
3. 身份揭露节点：穿越者身份被发现的危险时刻

### 3. 钩子参考模板
- 开篇钩子参考：穿越者在新世界醒来的第一个危机——身份/处境/规则的多重冲击
- 集末钩子参考（仅启发）：
  1. 身份式：她的真实身份一旦暴露，将万劫不复
  2. 预知式：她知道明天会发生什么，但改变它的代价超乎想象
  3. 失效式：当她最引以为傲的现代知识，在这个世界彻底失效

## 三、人设加成参考
1. 主角：穿越者必须有现代人的思维特征和行为惯性，同时在适应异世界的过程中展现成长。现代知识不是全知全能，而是一把有局限的利器。
2. 配角：异世界原住民，代表本地规则和价值观，与穿越者形成文化碰撞。
3. 对立方：利用本地规则压制穿越者的角色，或者同样具有信息优势的对手（如穿书中的原书女主/反派）。
> 仅为方向参考，可自由组合与原创。

## 四、标签规则体系
### 1. 强互斥（不可叠加）
重生（同一主角）——重生=同一世界重来，穿越=进入不同世界，不可同时作用于主角（除非"重生到穿越前"的特殊设定，需明确概念边界）。

### 2. 兼容增强（推荐叠加）
系统（穿越+系统任务裂变）、甜宠（穿越者情感上的局中人）、种田（现代知识降维农业）、宫斗（现代职场思维处理后宅）、玄幻仙侠（现代灵魂修仙世界）。

### 3. 优先级排序
- 受众 > 设定 > 主题 > 背景：穿越作为主题维度，提供信息差爽感和世界观碰撞。
- 穿越为辅轴时，其"信息差"功能为主轴标签服务（如穿书+甜宠→已知结局的恋爱）。
- 穿越为主轴时，信息差和降维碾压是核心爽点，其他标签为穿越提供冲突和落地场景。

## 五、红线与反模式
> 红线severity：弱

### 1. 避坑提示（不挂质检号、不扣分，仅创作提醒）
1. 避免无限制降维：穿越者的现代知识无任何限制和失效场景，全剧无冲突无困境。
2. 避免穿越感缺失：穿越者的现代人特征消失，行为完全融入异世界无文化碰撞。
3. 避免信息差浪费：穿越者的"已知未来"信息未被有效利用，或预知后无改变/无后果。
4. 避免原主身份虚化：穿越后的原主身份/社会关系/麻烦全部被轻易解决，无真实困境。
5. 避免世界观不自洽：穿越的规则设定前后矛盾（如穿越原因、回去的条件等）。

> 弱红线标签不挂全局质检号；上述风险若上升为崩级问题（如世界观硬伤），由 anti-patterns.md 通用反模式兜底检测扣分。

## 七、融梗亲和性（v5.3 新增）

### 增强型
- 无（穿越作为世界观载体型标签，其功能是为其他标签提供降维场景，而非被增强）

### 对冲型
- 无（穿越的情绪内核偏正向降维爽感，与大多数标签不产生对冲）

### 裂变型
- **系统** → fusion/recipes/time-travel-system.md：现代灵魂+系统任务在异世界，任务变更驱动命运改写。系统为穿越提供节奏框架，穿越为系统提供世界观载体，产生"异世界任务流"新特性。
- **甜宠** → fusion/recipes/time-travel-sweet.md：穿越者自带上帝视角但情感上是局中人——知道剧情走向却不知道自己的心。"我知道我们会相爱但不知道中间会怎样"。
- **种田** → fusion/recipes/farming-time-travel-system.md：现代知识降维古代农业，跨时代经营爽感。穿越的降维+种田的经营+系统的升级三重叠加。
- **宫斗** → 现代职场思维处理后宅博弈：不是"穿越的宫斗"而是"现代996思维的后宅生存"，跨时空思维碰撞产生新玩法。

### 互斥标签
- **重生（同一主角）**：重生=同一世界重来，穿越=进入不同世界，概念混淆不可同时作用于主角。
