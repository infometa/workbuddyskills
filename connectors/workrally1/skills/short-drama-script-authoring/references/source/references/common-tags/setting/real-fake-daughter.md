## 二、变体素材库（仅参考·可自由组合·可原创·可豁免）
> 本节全部为灵感启发，**不强制命中、不作评分依据**，可自由组合/原创/豁免。

### 1. 节奏适配逻辑
常见节奏：身份错位 → 真千金受压 → 真相浮现 → 反转打脸。付费节点可落在认亲、假千金露馅、真千金立威、身份反转等处——仅为参考。

### 2. 核心变体素材（任选，不限数量）
#### 反转爽点变体
1. 真才实学型：真千金不靠血缘靠实力，处处碾压假千金
2. 扮猪吃虎型：被当成乡下来的土包子，实则深藏不露
3. 打脸立威型：假千金当众挑衅，被真千金反手教做人
4. 多马甲型：真千金身负隐藏身份，揭晓层层炸场

#### 冲突模式变体
1. 偏心打压型：家人偏袒假千金，真千金硬实力突围
2. 假千金构陷型：假千金设局陷害，真相反转打脸
3. 抢夺资源型：争夺继承权/资源，真千金以实力服众
4. 身世悬疑型：抱错/掉包真相一步步揭开

#### 人设风格变体
1. 清醒飒爽型：不内耗、不哭穷，有仇当场就报
2. 高智谋略型：步步为营，让算计者自食恶果
3. 外柔内刚型：表面温和，反击毫不手软
4. 独立硬气型：不稀罕豪门施舍，靠自己赢得认可

#### 付费卡点变体
1. 认亲节点：真假身份浮出水面，家族震动
2. 露馅节点：假千金真面目/无能被当众揭穿
3. 立威节点：真千金凭实力当众反转打脸

### 3. 钩子参考模板
- 开篇钩子参考：真千金被当作冒牌货排挤，埋下真相反转、打脸立威的强烈预期
- 集末钩子参考（仅启发）：
  1. 反转式：你们捧上天的千金，才是真正的冒牌货
  2. 打脸式：她不需要这个家的认可，是这个家高攀不起她
  3. 悬念式：当年抱错孩子的真相，马上要瞒不住了

## 三、人设加成参考
1. 真千金：独立清醒、有真本事，逆袭不靠血缘靠实力；不圣母、不轻易原谅伤害者。
2. 假千金：占据身份却心虚算计，是主要对照与冲突源；不降智、有一定威胁性。
3. 家人/对照组：偏心长辈、势利亲戚，反衬真千金的格局与实力。
> 仅为方向参考，具体设定可自由发挥。

- 真假千金（设定）> 普通豪门情感主题。

## 五、红线与反模式
> 红线severity：弱

### 1. 避坑提示（不挂质检号、不扣分，仅创作提醒）
1. 避免真千金圣母、轻易原谅伤害者（注：此为崩级风险，由 anti-patterns.md 价值观/性格漂移项兜底覆盖）。
2. 避免家人全员无脑偏心，毫无层次，沦为降智工具。
3. 避免假千金降智，反派毫无威胁，打脸失去张力。
4. 避免认亲无伏笔，真相揭晓全靠巧合，逻辑突兀。

> 弱红线标签不挂全局质检号；上述崩级风险（圣母无底线原谅）由 anti-patterns.md 通用反模式（#8 性格漂移 / 价值观红线）兜底检测。
