> 官方标签映射：主题 · 虐恋
> 定位属性：level-1 强红线 · 虐必须有情感逻辑支撑，虐后必须有甜做回报

> 映射说明：虐恋为 level-1 强红线标签，挂 AP-NL 质检号。映射 overseas/chase-regret（追妻火葬场）combo——虐恋与追妻天然耦合，虐是追的前因，追是虐的补偿。

## 二、变体素材库（仅参考·可自由组合·可原创·可豁免）
> 本节全部为灵感启发，**不强制命中、不作评分依据**，可自由组合/原创/豁免。

### 1. 节奏适配逻辑
常见节奏：甜蜜铺垫 → 误会/伤害 → 虐心高潮 → 醒悟追悔 → 甜虐交替 → 大甜收束。虐恋的核心在于"甜→虐→追→甜"的情绪曲线，虐是手段不是目的，甜是回报不是施舍。付费节点可落在虐心反转、真相揭露、追悔高潮等处——仅为参考。

### 2. 核心变体素材（任选，不限数量）

#### 情绪内核
虐恋的情绪引擎：心碎拉扯（爱而不得的撕扯感）、错过遗憾（本可避免却阴差阳错）、痛并深爱（越痛越证明爱得深）、虐心催泪（让观众为角色哭）。核心爽感不来自"虐本身"，而来自"虐后的弥补与甜蜜"——观众忍虐是为了等甜。

#### 高频套路提示（非禁用需翻转）
1. 误会型虐恋：一方误会另一方背叛/不忠 → 需翻转：误会不能靠"一句话就能解释清楚"的方式持续，误会必须有结构性原因（如承诺不可说、证据确凿无法自辩）
2. 替身型虐恋：男主把女主当替身爱 → 需翻转：替身真相揭露后必须有反转（他早已爱上她本人而不自知）
3. 身份对立型虐恋：两人立场/阵营对立 → 需翻转：对立本身制造虐，和解必须靠双方各自让步而非单方投降
4. 伤害清零型虐恋：男主对女主造成实质性伤害 → 需翻转：伤害必须被真诚弥补而非被遗忘，复合必须在伤害清零之后

#### Top3 对照关键节点
1. 《东宫》——虐恋天花板：灭族之仇+真心相爱，选择型虐（不是误会而是命运），虐后无法挽回的痛
2. 《香蜜沉沉烬如霜》——甜虐振荡：前期甜→中期虐→后期追悔，情绪曲线教科书
3. 《何以笙箫默》——破镜重圆型虐恋：时间造成的错过+等待的深情，虐在"七年"而非伤害

#### 创作思考步骤
1. 先问"虐的原因是什么"——必须有不可调和的情感矛盾，不能只是"沟通不畅"
2. 再问"虐的回报是什么"——虐后必须有等量或超量的甜/追悔/弥补
3. 然后问"虐的节奏怎么排"——不能连续虐超过3集（短剧体量），必须有甜虐交替
4. 最后问"虐的结束方式"——伤害必须被弥补，误会必须被澄清，不能草率收尾

#### 情感冲突变体
1. 误会型：信息差造成伤害，真相揭露后追悔莫及
2. 替身型：被当作替身的爱，发现真心后的崩溃与觉醒
3. 立场型：阵营/身份对立，爱与恨的撕扯
4. 误解型：一方深爱但表达方式被对方解读为伤害
5. 失忆型：记忆缺失造成情感断裂，重逢时身份/处境已变

#### 虐心模式变体
1. 追妻火葬场型：男主伤害女主 → 女主离开 → 男主追悔 → 艰难复合
2. 双向暗恋型：两人互相深爱却因各种原因无法在一起
3. 错过型：时间/命运造成的阴差阳错
4. 牺牲型：一方为另一方默默付出却不被知晓
5. 反转型：以为是虐恋实则是深情守护

#### 付费卡点变体
1. 虐心反转节点：误会揭露/真相大白
2. 追悔高潮节点：男主终于意识到伤害/失去
3. 甜虐交替极值节点：虐到极致时突然给一颗糖

### 3. 钩子参考模板
- 开篇钩子参考：一场看似甜蜜的相遇，但暗藏虐的种子（身份不对等/替身暗示/立场对立）
- 集末钩子参考（仅启发）：
  1. 误会式：他看到的画面，恰恰是最深的误解
  2. 心碎式：她转身离开的那一刻，他才发现自己失去了什么
  3. 反转式：他以为的背叛，其实是她最深的守护

## 三、人设加成参考
1. 男主：虐恋男主必须"有虐的理由"（信息差/误解/被迫），不能是"为了虐而伤害"。追悔阶段必须有真诚的弥补行动，不是几句甜言蜜语就能翻篇。
2. 女主：虐恋女主必须有独立人格和底线，不能无限承受伤害。离开必须有充分理由，复合必须有前提条件。
3. 对立方：虐恋的"虐源"——制造误会的配角、立场对立的势力、替身原型的存在。虐源必须有逻辑，不能纯粹为了推动剧情而工具人化。
> 仅为方向参考，可自由组合与原创。

## 四、标签规则体系
### 1. 强互斥（不可叠加）
喜剧（沙雕向）——沙雕喜剧的轻松基调与虐恋的心碎拉扯根本冲突，观众情绪无法同时成立。

### 2. 兼容增强（推荐叠加）
甜宠（甜虐振荡放大器）、追妻（虐后追回）、破镜重圆（虐后重逢）、霸总（权力不对等加剧虐感）、重生（重来一次弥补遗憾）、马甲（身份揭露制造虐）。

### 3. 优先级排序
- 受众 > 设定 > 主题 > 背景：虐恋作为主题维度，服务于受众的情绪需求。
- 与追妻的优先级：虐恋为追妻提供"追"的情感动因，追妻为虐恋提供"偿"的情绪出口，两者耦合时虐恋为主轴（虐在先，追在后）。
- 与甜宠的优先级：虐恋与甜宠为对冲型关系，甜虐交替，不可一方全程主导。

## 七、融梗亲和性（v5.3 新增）

### 增强型
- 无（虐恋不增强其他标签，而是需要其他标签增强虐恋的情感深度）

### 对冲型
- **甜宠** → fusion/recipes/sweet-abusive.md：甜虐振荡放大器，甜时更甜虐时更虐，情绪反差产生双重快感。主轴交替主导，不可一方全程压制。
- **追妻** → 虐后追回：虐恋提供"追"的情感动因，追妻提供"偿"的情绪出口。虐在前追在后，追妻阶段必须体现真诚弥补。

### 裂变型
- 无（虐恋情绪内核方向明确，与大多数标签不产生裂变新特性）

### 互斥标签
- **喜剧（沙雕向）**：沙雕喜剧的轻松基调与虐恋的心碎拉扯根本冲突，不可叠加。
- **纯甜宠（无虐）**：情绪方向完全相反且都要求全程主导，只能走对冲型交替，不可纯叠加。
