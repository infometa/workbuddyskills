## 二、变体素材库（仅参考·可自由组合·可原创·可豁免）
> 本节所有内容均为灵感启发，**不强制命中、不作评分依据**，LLM 可自由组合/原创/豁免。

### 1. 情绪内核 + 高频套路提示（非禁用需翻转）

**情绪内核**：觉醒蜕变、自我价值、破茧成蝶、独立人格、由弱到强

**高频套路提示**（非禁用，但需翻转或原创升级，避免模板化）：
1. 被渣男伤害后觉醒 → 翻转：觉醒的触发不一定是被伤害，可以是目睹他人命运/自我反思/价值观碰撞等多元路径
2. 原来我自己也很强 → 翻转：不是突然发现"我也能打"，而是一步步在困境中建立能力与自信，成长有迹可循
3. 从家庭走向职场/社会 → 翻转：不一定是"从家庭逃到社会"，也可以是"在家庭中夺回话语权"或"重新定义家庭角色"

### 2. Top3 对照关键节点

| 关键节点 | 核心爽感 | 对照学习要点 |
|---|---|---|
| 《觉醒之后》型 | 从被操控到夺回人生主导权，每一步都是自己争来的 | 觉醒后的每一步胜利必须是女主自己完成，不可由男主力挽狂澜 |
| 《不做金丝雀》型 | 从豪门附庸到独立人格，物质自由+精神自由双线 | 成长不是换一个男人依靠，而是真正不需要依靠任何人 |
| 《她能赢》型 | 在男性主导的领域凭实力碾压，靠能力而非魅力 | 胜利的方式是"我比你强"而非"有人帮我" |

### 3. 创作思考步骤

1. **定起点**：女主初始状态——依附/蒙昧/自卑/被动，起点越低成长弧光越大
2. **定觉醒**：觉醒触发事件——什么是让她"不再忍受"的那个瞬间？触发逻辑是否足够有力？
3. **定路径**：成长路径——从觉醒到胜利之间，她自己做了什么？每一步是否是她自己走的？
4. **定代价**：成长代价——觉醒不是免费的，她失去了什么？代价让成长更真实
5. **定胜利**：关键胜利——最终战胜困难/对手的关键一击，必须是女主自己完成
6. **定新局**：成长后的新格局——不是回到原点换个男人，而是真正进入了新的人生阶段

### 4. 核心变体素材（任选，不限数量）
#### 觉醒触发变体
1. 伤害型：被背叛/被抛弃/被欺骗后认清现实
2. 目睹型：看到他人（母亲/姐妹/朋友）的悲剧命运而觉醒
3. 价值观碰撞型：遇到独立女性/进入新环境，认知被冲击
4. 自我反思型：某个瞬间回望人生，发现从未为自己活过

#### 成长路径变体
1. 能力觉醒型：发现自己的才华/能力，从附庸变主力
2. 经济独立型：从依赖他人到实现经济自由
3. 精神独立型：从讨好他人到坚守自我，不再为他人改变
4. 身份重建型：从"某人的妻子/女儿"到"我自己"

#### 付费卡点变体
1. 觉醒瞬间——"我再也不要这样活了"
2. 第一次独立胜利——"原来我自己也能赢"
3. 关键转折战胜——凭自己力量击败曾无法对抗的人/困境
4. 成长宣言——在众人面前确立自我价值

### 5. 钩子参考模板
- 开篇钩子参考：女主处于依附/被动状态，一次事件让她开始质疑现状
- 集末钩子参考（仅启发）：
  1. 觉醒式：她终于看清了真相/看清了自己
  2. 反击式：她决定不再退让，第一次为自己而战
  3. 成长式：她做出了一个所有人都意想不到的决定

## 三、人设加成参考
1. 女主：起点状态与终点状态反差清晰——从依附到独立、从蒙昧到清醒、从被动到主动
2. 男主：可以是成长路上的支持者/同行者，但绝不能是"替她解决问题的人"——帮助可以，代劳不行
3. 对立方：压制女主独立的力量（控制型伴侣/父权家庭/职场歧视），越强大成长越有张力
4. 对照组：与女主起点相似但未觉醒的女性（闺蜜/姐妹/母亲），她的"另一种可能"让女主的觉醒更有分量

### 2. 兼容增强（推荐叠加）

### 3. 优先级排序
- 受众 > 设定 > 主题 > 背景：女性成长作为主题标签，服务于女频受众的情感需求
