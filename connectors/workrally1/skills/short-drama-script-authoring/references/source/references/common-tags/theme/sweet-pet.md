# 主题标签：现言甜宠
> 官方标签映射：主题 · 现言甜宠
> 定位属性：level-2 弱红线 · 现代言情背景下的高甜宠溺，以"被偏爱"为核心爽感
> 核心情绪：被偏爱、心动感、安全感、治愈温暖、甜度爆表

> 映射说明：现言甜宠映射 domestic/sweet-romance combo，是国内平台核心题材之一。现代背景+高甜+宠溺是其三要素，区别于古装甜宠（走 palace-intrigue）和纯虐恋（走 chase-regret）。

## 二、变体素材库（仅参考·可自由组合·可原创·可豁免）
> 本节全部为灵感启发，**不强制命中、不作评分依据**，可自由组合/原创/豁免。

### 1. 节奏适配逻辑
常见节奏：心动初遇 → 甜蜜升温 → 误会/外力打断 → 信任加深 → 高甜收束。甜宠的核心在于"持续供甜"——不能长时间无甜，每集至少有一个心动/宠溺瞬间。但纯甜无冲突易腻，需要适度加入轻虐/误会/外力来制造节奏波动。付费节点可落在心动名场面、宠溺高潮、轻虐反转后加倍甜等处——仅为参考。

### 2. 核心变体素材（任选，不限数量）

#### 情绪内核
甜宠的情绪引擎：被偏爱（全世界只对你好的专属感）、心动感（每次接触都是电流）、安全感（有他在什么都不怕）、治愈温暖（所有疲惫都有人懂）、甜度爆表（酥到骨子里的宠溺）。核心爽感不是"得到完美男人"，而是"被真切看见、被独特偏爱"的情感价值确认。

#### 高频套路提示（非禁用需翻转）
1. 霸总无脑宠型：男主无理由无底线地宠女主 → 需翻转：宠必须有情感基础（为什么宠她），否则空洞无代入感
2. 全程发糖型：从头甜到尾无任何波澜 → 需翻转：纯甜无冲突易审美疲劳，需要轻虐/误会制造节奏
3. 灰姑娘型：普通女孩被顶级男人看上 → 需翻转：女主必须有被爱的独特价值，不能只因"善良"
4. 荤段子型：靠擦边/暧昧台词推甜 → 需翻转：真正的心动感来自细节和氛围，不是荤段子

#### Top3 对照关键节点
1. 《你是我的荣耀》——甜宠天花板：双向奔赴+各自独立+相互成就，甜而有质感
2. 《致我们暖暖的小时光》——日常甜宠型：生活细节中的心动和宠溺，烟火气甜
3. 《微微一笑很倾城》——游戏甜宠型：线上线下的双重心动，游戏世界的独特宠溺场景

#### 创作思考步骤
1. 先确定"甜的核心"——是什么让这段感情甜？专属偏爱/互相治愈/日久生情/命中注定？
2. 再确定"宠的方向"——他怎么宠她？行动宠/言语宠/细节宠/霸道宠/温柔宠？
3. 然后确定"甜的节奏"——纯甜持续多久会腻？什么时候需要轻虐来打断再加倍甜？
4. 最后确定"甜的落地"——甜宠场景要有生活细节和具体画面，不能只靠台词喊甜

#### 甜宠类型变体
1. 霸道宠型：男主强势霸道地宠，女主被保护被征服
2. 温柔宠型：男主细腻温柔地宠，细节中的心动
3. 双向甜型：互相宠爱互相心动，势均力敌的甜
4. 治愈甜型：一方治愈另一方创伤，温暖感主导
5. 反差甜型：外表冷漠/凶悍的人私下极致宠溺，反差萌

#### 心动场景变体
1. 偶遇型：命运的巧合制造心动瞬间
2. 日久型：日常相处中心动慢慢积累
3. 危机型：危险时刻的保护，安全感暴击
4. 细节型：不起眼的细节被注意到，被看见的感动
5. 宣言型：当众/对全世界宣示"她是我的"，被偏爱的极致

#### 付费卡点变体
1. 心动名场节点：第一次心动/告白/初吻等名场面
2. 宠溺高潮节点：极致宠溺的集中爆发
3. 加倍甜节点：轻虐后的加倍甜蜜回报

### 3. 钩子参考模板
- 开篇钩子参考：一个让心跳加速的初遇——可以是偶然/故意/意外，但必须有"电光火石"的瞬间
- 集末钩子参考（仅启发）：
  1. 心动式：他做了一件她没想到的事，心突然漏跳一拍
  2. 宠溺式：他给她的是全世界只有她才有的偏爱
  3. 反差式：那个所有人都怕的人，只对她一个人温柔

## 三、人设加成参考
1. 男主：甜宠男主的核心魅力不是"有钱有权"而是"只对她好"。宠的方式要符合人设——霸道的宠、温柔的宠、傲娇的宠各有各的爽点。
2. 女主：甜宠女主必须有"被爱的理由"——不是因为她完美，而是因为她独特的闪光点被男主看见。不能是毫无魅力的工具人。
3. 对立方：甜宠的对立不是大反派，而是制造轻虐/误会的外力（情敌/家人/旧情），用以打断纯甜、制造节奏波动。
> 仅为方向参考，可自由组合与原创。

## 四、标签规则体系
### 1. 强互斥（不可叠加）
纯虐恋（无甜）——纯虐恋与甜宠情绪方向完全相反且都要求全程主导，不可纯叠加，只能走对冲型交替。

### 2. 兼容增强（推荐叠加）
虐恋（甜虐振荡放大器）、霸总（权力庇护强化被偏爱感）、重生（已知结局的恋爱）、穿越（穿越者情感上的局中人）、追妻（先虐后甜，追妻卑微让后面的甜更珍贵）。

### 3. 优先级排序
- 受众 > 设定 > 主题 > 背景：甜宠作为主题维度，服务于受众的"被偏爱"情感需求。
- 甜宠与虐恋对冲时，甜宠通常为主轴（甜宠受众看甜是为了治愈），虐恋提供节奏波动。
- 甜宠与霸总叠加时，甜宠为主轴（情感是核心），霸总为辅轴（权力设定增强被偏爱感）。

## 五、红线与反模式
> 红线severity：弱

### 1. 避坑提示（不挂质检号、不扣分，仅创作提醒）
1. 避免空洞甜：甜宠场景缺乏情感基础，只有台词喊甜没有行动和细节支撑。
2. 避免无脑宠：男主无理由无底线地宠，缺乏"为什么宠她"的情感逻辑，沦为假甜。
3. 避免纯甜无波：全程发糖无任何冲突/误会/外力，审美疲劳导致甜感贬值。
4. 避免女主工具化：女主毫无魅力和主体性，只是"被宠的容器"，观众无法代入。
5. 避免擦边替代：靠荤段子/擦边画面代替真正的心动和宠溺，低质感。

> 弱红线标签不挂全局质检号；上述风险若上升为崩级问题（如人物与人设崩坏），由 anti-patterns.md 通用反模式兜底检测扣分。

## 七、融梗亲和性（v5.3 新增）

### 增强型
- **霸总** → 霸总设定强化"被征服+被守护"的心动感。霸总的权力和资源为甜宠提供更极致的宠溺场景，"全世界他只对你好"的专属感倍增。

### 对冲型
- **虐恋** → fusion/recipes/sweet-abusive.md：甜虐振荡放大器，甜时更甜虐时更虐，情绪反差产生双重快感。交替主导，甜虐比例不低于4:6。
- **追妻** → fusion/recipes/chase-wife-sweet.md：先虐后甜，追妻的卑微让后面的甜更珍贵。追妻阶段制造虐，复合后加倍甜。

### 裂变型
- **重生** → fusion/recipes/rebirth-sweet.md：已知结局的恋爱——"我知道我们会相爱但不知道中间会怎样"。重生的信息差让甜宠多了"命中注定"的宿命感。
- **穿越** → fusion/recipes/time-travel-sweet.md：穿越者自带上帝视角但情感上是局中人。知道剧情走向却不知道自己的心，跨时空的心动。

### 互斥标签
- **纯虐恋（无甜）**：情绪方向完全相反且都要求全程主导，只能走对冲型交替，不可纯叠加。
