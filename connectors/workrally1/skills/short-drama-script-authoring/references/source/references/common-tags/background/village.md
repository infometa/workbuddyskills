## 二、变体素材库（仅参考·可自由组合·可原创·可豁免）
> 本节全部为灵感启发，**不强制命中、不作评分依据**，可自由组合/原创/豁免。

### 1. 节奏适配逻辑
常见节奏：返乡/扎根 → 乡情矛盾 → 经营/逆袭翻盘 → 乡村振兴或扬眉吐气。乡村背景重在烟火气与共鸣，场景要落地、不能全程对话。付费节点可落在矛盾激化、翻盘时刻、致富突破、当众正名等处——仅为参考。

### 2. 核心变体素材（任选，不限数量）
#### 场景素材
1. 农家院落：土灶、晒谷场、菜园、村口大槐树等生活场景
2. 田间劳作：插秧、收割、果园、养殖等农事场景
3. 集市庙会：赶集、红白事、村委会等乡村公共场景
4. 经营场景：农家乐、合作社、电商助农、特色种养等

#### 台词风格素材
1. 乡土口语：接地气的方言味、俗语谚语，不端着
2. 家常拌嘴：邻里间的拌嘴打趣、东家长西家短
3. 朴实真挚：情感表达直接质朴，不矫情
4. 反差金句：返乡能人不经意露出的格局感台词

#### 行为逻辑素材
1. 乡情人情：讲人情、重面子、爱看热闹的乡土逻辑
2. 务实生存：围绕收成、生计、致富的现实行为动机
3. 宗族观念：辈分、家族、邻里关系的行为约束
4. 闲言碎语：流言传播快、舆论压力大的乡村生态

#### 付费卡点变体
1. 乡情矛盾激化节点
2. 经营翻盘节点
3. 当众正名节点

### 3. 钩子参考模板
- 开篇钩子参考：主角返乡或扎根乡村，因一桩乡情矛盾被卷入是非
- 集末钩子参考（仅启发）：
  1. 翻盘式：看不起他的乡亲，马上要刮目相看
  2. 矛盾式：这场宅基地的纠纷，眼看要闹大
  3. 致富式：他要带着全村人，干一件大事

## 三、人设加成参考
1. 主角：返乡能人或本土青年，有格局但接地气，行为符合乡土逻辑。
2. 村民：有正面有反面、群像鲜活，避免全员恶人或全员工具人。
3. 对立方：刁难者/竞争者动机现实（利益、面子、嫉妒），不脸谱化。
> 仅为方向参考，可自由组合与原创。

## 五、红线与反模式
> 红线severity：弱

### 1. 避坑提示（不挂质检号、不扣分，仅创作提醒）
1. 避免乡村悬浮：台词都市精英范，人物不像乡村人。
2. 避免全员恶人：村民群像一边倒，缺乏正面村民与人情温度。
3. 避免经营细节离谱：种养/致富情节不符农业常识。
4. 避免场景缺失：全程对话、没有乡村实景的烟火气支撑。

> 弱红线标签不挂全局质检号；上述风险若上升为崩级问题（如世界观硬伤），由 anti-patterns.md 通用反模式兜底检测扣分。
