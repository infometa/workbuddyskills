## 二、变体素材库（仅参考·可自由组合·可原创·可豁免）

### 1. 节奏适配逻辑
常见节奏：闪婚契约 → 同居磨合 → 心动错位拉扯 → 日久生情打破契约，由冷到热渐进。付费节点可落在闪婚冲击、契约拉扯、心动暴露等处——仅为参考位置，不强制。

### 2. 核心变体素材（任选，不限数量）
#### 先婚后爱爽点变体
1. 契约升温型：从契约关系到真心相付的渐变
2. 同居日常型：婚后相处中的甜与心动累积
3. 护短宠妻型：闪婚对象意外地温柔护短
4. 双向暗恋型：表面契约实则彼此早有好感

#### 冲突模式变体
1. 契约博弈型：围绕契约条款的拉扯与试探
2. 外人误会型：闪婚关系遭遇外界质疑搅局
3. 身份反差型：闪婚对象隐藏的惊人身份
4. 旧情干扰型：前任或追求者介入考验感情

#### 人设风格变体
1. 高冷渐融型：婚后外冷内热逐步沦陷
2. 傲娇别扭型：嘴硬心软暗自心动
3. 温柔守护型：以行动默默宠爱对方

#### 付费卡点变体
1. 闪婚冲击节点：突然结婚的强反差开局
2. 契约拉扯节点：条款博弈的张力
3. 心动暴露节点：真心藏不住的甜点

### 3. 钩子参考模板

## 五、红线与反模式
> 红线severity：弱

### 1. 避坑提示（不挂质检号、不扣分，仅创作提醒）
1. 避免结婚理由牵强，闪婚动机经不起推敲。
2. 避免婚后关系无进展，长期停留契约不升温。
3. 避免节奏过快，刚结婚就深爱缺乏铺垫。
4. 避免契约规则形同虚设，设了契约却毫无约束力。

> 说明：闪婚即使不守这些点，通常只是"不够爽"而非"剧情崩塌"，故定为弱红线、不挂全局质检号。动机不合理若达崩级，由 anti-patterns.md 通用反模式兜底。
