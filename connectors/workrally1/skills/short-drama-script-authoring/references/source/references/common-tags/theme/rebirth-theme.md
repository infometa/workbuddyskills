# 主题标签：重生
> 官方标签映射：主题 · 重生
> 定位属性：level-2 弱红线 · 同一世界重来一次，用信息差碾压命运
> 核心情绪：遗憾弥补、精准预判、命运重写、信息差碾压

> 映射说明：重生映射 domestic/rebirth combo——重生是国内平台核心题材之一。重生=同一世界重来，区别于穿越（跨世界）。文件名加 `-theme` 后缀避免与 combos/rebirth.md 撞名。

## 二、变体素材库（仅参考·可自由组合·可原创·可豁免）
> 本节全部为灵感启发，**不强制命中、不作评分依据**，可自由组合/原创/豁免。

### 1. 节奏适配逻辑
常见节奏：前世遗憾 → 重生节点 → 信息差碾压期 → 改变引发的蝴蝶效应 → 新困境/新选择 → 命运重写。重生的核心爽感来自"已知未来"的信息差——她/他知道谁会背叛、哪个选择是错的、什么时机最关键。但重生后改变的每一个决定都会引发蝴蝶效应，原本"已知"的未来开始变得不确定。付费节点可落在首次信息差碾压、蝴蝶效应反转、前世遗憾弥补等处——仅为参考。

### 2. 核心变体素材（任选，不限数量）

#### 情绪内核
重生的情绪引擎：遗憾弥补（前世最深的遗憾这次一定要弥补）、精准预判（知道下一步会发生什么的掌控感）、命运重写（这一次我要走不同的路）、信息差碾压（她/他知道别人不知道的事）。核心爽感来自"第二次机会"的珍贵和"改变命运"的掌控感——但真正的戏剧张力在于"改变了之后，新的命运会是什么"。

#### 高频套路提示（非禁用需翻转）
1. 全知碾压型：重生后对一切了如指掌无任何意外 → 需翻转：蝴蝶效应让"已知"变"未知"，改变引发新变量
2. 纯复仇型：重生只为复仇无其他成长 → 需翻转：复仇必须与自我成长/情感救赎并行，否则格局小
3. 前世全错型：前世的所有选择都是错的 → 需翻转：前世不可能全错，有些选择是对的但被误解/被利用
4. 重生即无敌型：重生后所有困难轻松解决 → 需翻转：新的困境必须出现，否则无戏剧张力

#### Top3 对照关键节点
1. 《重生之将门毒后》——重生复仇天花板：前世被辜负→重来步步为营→精准复仇+命运重写
2. 《庆余年》——重生/穿越混合型：带着前世记忆降生，信息差+蝴蝶效应的双重博弈
3. 《你好，李焕英》——情感重生型：重来一次只为弥补遗憾，核心不是碾压而是珍惜

#### 创作思考步骤
1. 先确定"前世遗憾"——前世最痛的是什么？背叛/错过/选错/被辜负？
2. 再确定"重生节点"——回到哪个时间点？为什么是这个时候？这个节点的选择决定了信息差的范围
3. 然后确定"改变路径"——重生后要改变什么？怎么改？改变引发了什么蝴蝶效应？
4. 最后确定"新的困境"——改变后出现了什么前世没有的新问题？这才是重生剧的真正看点

#### 重生类型变体
1. 复仇型：前世被害/被辜负，重来精准复仇
2. 弥补型：前世错过/遗憾，重来珍惜弥补
3. 预判型：前世失败/被骗，重来利用信息差翻盘
4. 成长型：前世懦弱/无知，重来觉醒成长
5. 商战型：前世破产/被骗，重来用未来知识布局

#### 信息差利用变体
1. 人物预判型：知道谁会背叛/谁可信任
2. 事件预判型：知道什么事件会发生/何时发生
3. 商业预判型：知道什么投资/机会最值
4. 情感预判型：知道谁是真心/谁是假意
5. 技术预判型：知道什么技术/知识未来最有用

#### 付费卡点变体
1. 首次碾压节点：重生者首次用信息差碾压，爽感爆发
2. 蝴蝶效应节点：改变引发意料之外的新问题
3. 遗憾弥补节点：前世最深的遗憾终于被弥补

### 3. 钩子参考模板
- 开篇钩子参考：前世的至暗时刻——被背叛/被辜负/被抛弃的绝望瞬间，然后"睁开眼，回到了那一天"
- 集末钩子参考（仅启发）：
  1. 蝴蝶式：她改变了前世的轨迹，但新的命运比前世更危险
  2. 预判式：她知道下一刻会发生什么，但这一次有人也在预判她
  3. 遗憾式：前世最大的遗憾，这次她绝不放手——但命运给她出了新题

## 三、人设加成参考
1. 主角：重生者必须有"前世记忆"带来的成熟和痛感，行为逻辑要有"经历过才会有的老练"。但不能变成全知全能，蝴蝶效应必须制造新的盲区。
2. 配角：前世记忆中的关键人物——谁是敌谁是友，重生后判断可能有变。人物关系的重新认知是重生爽感的重要来源。
3. 对立方：前世的加害者/背叛者，或者因蝴蝶效应出现的新威胁。反派必须有智能——不是等着被碾压，而是也会调整策略。
> 仅为方向参考，可自由组合与原创。

## 四、标签规则体系
### 1. 强互斥（不可叠加）
穿越（同一主角）——重生=同一世界重来，穿越=进入不同世界，概念不可混淆。不可同时作用于主角（除非"重生到穿越前"的特殊设定）。

### 2. 兼容增强（推荐叠加）
打脸虐渣（重生信息差让打脸更精准更解气）、甜宠（已知结局的恋爱）、玄幻仙侠（修仙者重生的修炼捷径）、宫斗（重生让宫斗从惊心变为成竹）、悬疑（已知凶手但无证据的逆推理）。

### 3. 优先级排序
- 受众 > 设定 > 主题 > 背景：重生作为主题维度，提供信息差爽感和命运重写体验。
- 重生为辅轴时，其"信息差"功能为主轴标签服务（如重生+打脸→精准预判打脸）。
- 重生为主轴时，信息差碾压和蝴蝶效应是核心看点，其他标签为重生提供落地场景。

## 五、红线与反模式
> 红线severity：弱

### 1. 避坑提示（不挂质检号、不扣分，仅创作提醒）
1. 避免全知碾压：重生者对一切了如指掌无任何意外和困境，全程碾压无张力。
2. 避免蝴蝶效应缺失：重生改变后无任何新的变量/困境出现，仿佛世界围着她/他转。
3. 避免前世记忆浪费：前世经历的核心教训/信息未被有效利用，重生只是换个方式重复。
4. 避免重生感缺失：重生者的行为与普通人无异，前世记忆只是设定背景未体现为行动逻辑。
5. 避免重生规则矛盾：重生的时间节点/记忆范围/物理规则前后矛盾。

> 弱红线标签不挂全局质检号；上述风险若上升为崩级问题（如世界观硬伤），由 anti-patterns.md 通用反模式兜底检测扣分。

## 七、融梗亲和性（v5.3 新增）

### 增强型
- **打脸虐渣** → fusion/recipes/rebirth-revenge.md：重生信息差让打脸更精准更解气——"我都知道你会做什么"。重生的预判让打脸的时机、方式、力度都恰到好处，爽感倍增。
- **宫斗** → fusion/recipes/palace-rebirth.md：重生让宫斗从"步步惊心"变为"胸有成竹"。前世踩过的坑今生全避开，前世不知道的暗线今生全看清。

### 对冲型
- 无（重生的情绪内核偏正向掌控感，不与其他标签产生情绪对冲）

### 裂变型
- **甜宠** → fusion/recipes/rebirth-sweet.md：已知结局的恋爱——"我知道我们会相爱但不知道中间会怎样"。重生的宿命感让甜宠多了"命中注定"的浪漫。
- **玄幻仙侠** → fusion/recipes/fantasy-rebirth.md：修仙者重生回练气期——前世记忆+修炼捷径。修仙的升级体系与重生的信息差完美耦合，"这一世我绝不会走弯路"。
- **悬疑** → 已知凶手但无证据的逆推理——重生者知道"是谁干的"但"没有证据"，必须从结果倒推过程，信息差反转推理。

### 互斥标签
- **穿越（同一主角）**：重生=同一世界重来，穿越=进入不同世界，概念混淆不可同时作用于主角。
