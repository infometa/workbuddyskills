## 二、变体素材库（仅参考·可自由组合·可原创·可豁免）
> 本节全部为灵感启发，**不强制命中、不作评分依据**，可自由组合/原创/豁免。

### 1. 节奏适配逻辑
常见节奏：暗恋酸涩铺垫 → 试探靠近 → 心意揭晓 → 双向奔赴成真，由酸到甜层层递进。付费节点可落在暗恋暴露危机、双向心意揭晓、成真甜蜜处——仅为参考位置，不强制。

### 2. 核心变体素材（任选，不限数量）
#### 暗恋甜点变体
1. 细节藏心型：通过小动作细节悄悄关注对方
2. 默默守护型：暗中付出不求回报的深情
3. 醋意萌动型：因对方与他人接触泛起酸意
4. 双向暗恋型：彼此心动却都不敢点破

#### 冲突模式变体
1. 误会错过型：因不敢表白险些错过
2. 情敌出现型：竞争者倒逼心意浮出水面
3. 距离阻隔型：身份/距离造成的暗恋障碍
4. 试探拉扯型：欲说还休的试探与靠近

#### 人设风格变体
1. 内敛克制型：暗恋深藏、含蓄而酸涩
2. 笨拙真诚型：不善表达却真心满满
3. 傲娇别扭型：嘴硬心软的暗恋反差

#### 付费卡点变体
1. 暗恋暴露节点：心意险些被发现的紧张
2. 心意揭晓节点：双向暗恋点破的甜
3. 成真节点：双向奔赴在一起的释放

### 3. 钩子参考模板
- 开篇钩子参考：从暗恋的酸涩细节切入，建立心动与期待
- 集末钩子参考（仅启发）：
  1. 酸涩式：原来喜欢一个人，是这样小心翼翼
  2. 反转式：她不知道，对方其实也在偷偷喜欢她
  3. 甜蜜式：藏了这么久的心意，终于要说出口了

## 五、红线与反模式
> 红线severity：弱

### 1. 避坑提示（不挂质检号、不扣分，仅创作提醒）
1. 避免暗恋感缺失，主角过于主动直白丢失酸涩张力。
2. 避免细节糖不足，全靠台词表白缺乏含蓄铺垫。
3. 避免双向暗恋过早揭晓，提前消解拉扯与期待。
4. 避免成真过于轻易，无试探无拉扯直接在一起。

> 说明：暗恋成真即使不守这些点，通常只是"不够甜"而非"剧情崩塌"，故定为弱红线、不挂全局质检号。情感空洞若达崩级，由 anti-patterns.md 通用反模式兜底。

## 七、融梗亲和性（v5.3 新增）

### 增强型
- **现言甜宠**：甜宠的独宠氛围放大暗恋成真后的甜蜜释放，让酸涩铺垫的克制与揭晓后的双向奔赴形成更强反差。
- **欢喜冤家**：斗嘴拌嘴的张力为暗恋的"口是心非"提供天然戏剧场，嘴硬心软的别扭感强化藏心的酸甜拉扯。

### 对冲型
- 无（暗恋成真的情绪内核偏正向治愈，由酸到甜单向递进，不与其他标签产生情绪对冲）

### 裂变型
- 无（暗恋成真作为情感主题标签，其核心机制"酸涩克制→双向成真"不被其他标签根本改变）
