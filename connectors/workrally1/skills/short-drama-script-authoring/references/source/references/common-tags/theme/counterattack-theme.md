# 主题标签：逆袭
> 官方标签映射：主题 · 逆袭
> 定位属性：level-2 弱红线 · 从低位到高位的阶层翻转，以逆袭翻盘为核心爽感
> 核心情绪：从低位攀升、扬眉吐气、阶层翻转、逆袭翻盘

> 映射说明：逆袭映射 domestic/counterattack combo——逆袭是国内平台核心爽感引擎之一。文件名加 `-theme` 后缀避免与 combos/counterattack.md 撞名。逆袭是过程型标签，打脸是瞬间型标签——逆袭提供积累过程，打脸提供爆发瞬间。

## 二、变体素材库（仅参考·可自由组合·可原创·可豁免）
> 本节全部为灵感启发，**不强制命中、不作评分依据**，可自由组合/原创/豁免。

### 1. 节奏适配逻辑
常见节奏：低谷开局 → 隐忍/挣扎 → 机会/转折 → 逐步攀升 → 关键翻盘 → 巅峰逆袭。逆袭的核心在于"台阶感"——不是一步登天，而是一步一个台阶往上走，每上一个台阶都有对应的爽感释放。台阶不能太少（一步到位无过程），也不能太碎（每步太微小无爽感）。付费节点可落在每个台阶的攀升、关键翻盘、巅峰逆袭等处——仅为参考。

### 2. 核心变体素材（任选，不限数量）

#### 情绪内核
逆袭的情绪引擎：从低位攀升（一步步往上走的成就感）、扬眉吐气（终于让看不起我的人闭嘴）、阶层翻转（从最底层到最高层的震撼反差）、逆袭翻盘（绝境中翻转命运的燃感）。核心爽感来自"不认命"——起点越低、障碍越大、翻盘越震撼，爽感越强。

#### 高频套路提示（非禁用需翻转）
1. 贵人提携型：逆袭全靠贵人帮忙自己没成长 → 需翻转：逆袭必须靠自身实力，贵人只能提供机会不能包办
2. 一帆风顺型：逆袭过程毫无挫折一路顺风 → 需翻转：必须有低谷反弹，每次翻盘前要有真实困境
3. 运气逆袭型：靠运气/巧合完成逆袭 → 需翻转：核心翻盘必须靠实力/智慧/努力，运气只能做辅助
4. 一步登天型：从底层直接到顶层无过程 → 需翻转：逆袭必须有台阶感，每一步都是实力积累

#### Top3 对照关键节点
1. 《赘婿》——逆袭天花板：从被人看不起的赘婿到商业帝国缔造者，台阶清晰
2. 《当幸福来敲门》——现实逆袭型：从无家可归到成功入职，每一步都靠真实努力
3. 《赘婿之天眼开局》——爽感逆袭型：天眼赋能+自身布局，能力+工具的逆袭组合

#### 创作思考步骤
1. 先确定"起点"——主角的最低点在哪里？穷/弱/被看不起/被抛弃？起点越低逆袭越燃
2. 再确定"台阶"——逆袭分几步？每一步靠什么翻上去？能力/智慧/人脉/资源？
3. 然后确定"阻碍"——每一步有什么阻碍？阻碍必须有力度，翻过去才有爽感
4. 最后确定"终点"——逆袭到什么程度？巅峰是什么？终点要超出观众预期

#### 逆袭类型变体
1. 财富逆袭型：从穷到富，经济阶层跨越
2. 权力逆袭型：从无权到有权，社会地位翻转
3. 能力逆袭型：从弱到强，实力碾压翻盘
4. 身份逆袭型：从被看低到身份揭露震撼
5. 知识逆袭型：从无知到有知，信息差翻盘

#### 阶段推进变体
1. 蛰伏型：表面隐忍暗中蓄力，一击翻盘
2. 步步为营型：每个阶段稳扎稳打，渐进式攀升
3. 逆境反弹型：每次被打压后更强力反弹
4. 借势型：借助外部机会/资源实现跨越
5. 破局型：打破规则/框架实现翻盘

#### 付费卡点变体
1. 首次翻盘节点：主角首次展现真正实力，一鸣惊人
2. 关键跨越节点：跨越重要阶层/实力门槛
3. 巅峰逆袭节点：最终的大翻盘，从最低到最高

### 3. 钩子参考模板
- 开篇钩子参考：主角处于人生最低谷——被所有人看不起/被抛弃/一无所有，但眼中还有不认命的光
- 集末钩子参考（仅启发）：
  1. 翻盘式：所有人都以为他完了，但他刚刚翻开了底牌
  2. 阶层式：从今天起，他站的位置将超过在场所有人
  3. 觉醒式：她终于明白，没有人能替她站起来——除了她自己

## 三、人设加成参考
1. 主角：逆袭主角必须有"不认命"的精神内核和真实的成长弧线。起点可以很低，但内心不能弱。成长必须靠自身实力，不能全靠外挂/贵人。
2. 配角：逆袭路上的助力者/阻碍者——助力者提供机会但不包办，阻碍者提供困境但不降智。
3. 对立方：原有阶层的既得利益者——他们维护现有秩序，自然成为逆袭的阻碍。反派的实力要有分量，打倒他才有成就感。
> 仅为方向参考，可自由组合与原创。

## 五、红线与反模式
> 红线severity：弱

### 1. 避坑提示（不挂质检号、不扣分，仅创作提醒）
1. 避免一步登天：逆袭缺乏台阶感和成长过程，从底层直接到顶层无积累。
2. 避免全靠贵人：逆袭过程全靠他人提携帮助，主角自身无真实成长。
3. 避免阻碍虚化：逆袭路上的阻碍缺乏力度，轻易翻过无爽感。
4. 避免运气主导：关键翻盘靠运气/巧合而非实力/智慧，成就感打折。
5. 避免台阶断裂：逆袭的阶段性跳跃不清晰，观众感受不到"一步步往上走"的递进爽感。

> 弱红线标签不挂全局质检号；上述风险若上升为崩级问题（如人物与人设崩坏），由 anti-patterns.md 通用反模式兜底检测扣分。
