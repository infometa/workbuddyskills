# 主题标签：马甲
> 官方标签映射：主题情节 · 马甲
> 定位属性：level-1 强红线 · 多重隐藏身份的层层揭露，反差震撼驱动
> 核心情绪：身份反差、多重震撼、上帝视角、扮猪吃虎、层层揭露

## 二、变体素材库（仅参考·可自由组合·可原创·可豁免）
> 本节所有内容均为灵感启发，**不强制命中、不作评分依据**，LLM 可自由组合/原创/豁免。

### 1. 情绪内核 + 高频套路提示（非禁用需翻转）

**情绪内核**：身份反差、多重震撼、上帝视角、扮猪吃虎、层层揭露

**高频套路提示**（非禁用，但需翻转或原创升级，避免模板化）：
1. 装穷/装弱被嘲笑 → 翻转：赋予装弱更深层动机（保护某人/试探人心/执行任务），而非单纯"等打脸"
2. 身份一个接一个揭露 → 翻转：在揭露节奏上做文章——某次揭露是假的/他人冒充/马甲被提前触发，制造意外
3. 最后一个大马甲全场跪 → 翻转：最强马甲揭露时的反应不仅仅是"跪"，而是让此前所有误解产生全新含义

### 2. Top3 对照关键节点

| 关键节点 | 核心爽感 | 对照学习要点 |
|---|---|---|
| 《隐世大佬》型 | 三重身份层层揭露，每层都让对手崩溃 | 揭露间距控制——每层之间至少隔2-3个事件，不做连续轰炸 |
| 《天降神医》型 | 低调身份救人后深藏功与名 | 低调与揭露的节奏——低调越久，揭露爆发力越强 |
| 《她是谁》型 | 全剧所有人都在猜身份，观众开了上帝视角 | 信息差操控——观众知道但剧中人不知道的悬差感 |

### 3. 创作思考步骤

1. **定层**：设计马甲层级（2-4层），每层身份的震撼度递增，最强层压轴
2. **定序**：编排揭露顺序与触发条件——每个马甲为什么在这时候被揭露？触发逻辑是否自洽？
3. **定效**：每层揭露的后果是什么——不仅是对手反应，更要推动剧情走向下一阶段
4. **定距**：揭露间隔至少隔2-3个事件节点，避免连续轰炸导致麻木
5. **定核**：最强马甲揭露时的"核爆效应"——此前所有伏笔同时引爆，产生1+1>2的震撼

### 4. 核心变体素材（任选，不限数量）
#### 身份反差变体
1. 隐世强者型：表面废物/普通人，实为巅峰强者
2. 多重身份型：同时拥有2-4个隐藏身份，层层剥开
3. 世代传承型：背负家族/门派传承，身份即责任
4. 跨界通才型：在不同领域各有顶级身份（医神/战神/商业巨头）

#### 揭露模式变体
1. 被迫揭露型：危机中不得不亮出身份
2. 主动亮牌型：关键时刻强势登场，扭转乾坤
3. 他人揭露型：第三方认出身份，主角被动曝光
4. 误打误撞型：意外暴露线索，逐步被拼凑出真相

#### 付费卡点变体
1. 第一层马甲揭露节点——观众等了许久的"原来他是……"
2. 中层马甲揭露——比预期更高，震撼升级
3. 最终马甲揭露——核爆级反转，此前一切有了新含义
4. 马甲冲突节点——两个身份同时被需要，只能选一个

### 5. 钩子参考模板
- 开篇钩子参考：主角以最低调姿态登场，被轻视/嘲笑/欺负，观众已知其真实身份（上帝视角悬差）
- 集末钩子参考（仅启发）：
  1. 揭露式：某条线索即将指向他的真实身份
  2. 危机式：只有他的隐藏身份才能解决眼前的绝境
  3. 对峙式：对手即将触碰他的马甲底线

## 三、人设加成参考
1. 主角：表层人设与真实身份反差越大越好——反差即张力。表层越弱/越普通，揭露越震撼。
2. 配角：有人猜疑、有人信任、有人利用——对马甲的不同态度形成人物弧光。
3. 对立方：轻视/打压/威胁→逼迫马甲揭露的推手，越嚣张反差越大。
4. 对照组：同样有秘密的人（盟友或对手），形成"谁先被揭穿"的博弈张力。
> 仅为方向参考，可自由组合与原创。

## 四、标签规则体系
### 1. 强互斥（不可叠加）
无强互斥标签——马甲兼容性极强，可叠加绝大多数主题与设定标签。

### 2. 兼容增强（推荐叠加）
- 打脸虐渣：多重马甲连爆比单一身份更震撼（增强型）
- 强者回归：回归身份+隐藏马甲双重反差（增强型）
- 追妻：隐藏身份的男主追妻——她不知道她拒绝的人是她最大的靠山（裂变型）
- 甜宠：隐藏身份的恋爱——身份揭晓是终极反转（裂变型）
- 重生：重生者以新马甲重回旧局，信息差+身份差双重碾压

### 3. 优先级排序
- 受众 > 设定 > 主题 > 背景：马甲作为主题标签，服务于受众爽感需求
- 马甲 weight=high，与打脸虐渣、强者回归同权重时，以受众基调决定主轴（男频→打脸主轴，女频→马甲反差主轴）
- 马甲 + 追妻：追妻主轴（情感驱动），马甲为辅轴（身份反差增量）

## 五、红线与反模式
> 红线severity：强

### 1. AI通病专项检测（挂质检号，作扣分项，对接 4-review.md + anti-patterns.md）
| 编号 | 反模式 | 判定标准 | 扣分权重 | 挂靠维度 |
|---|---|---|---|---|
| AP-MJ01 | 最强马甲前置 | 最强身份在前期或中段即已揭露，后续无更震撼身份支撑，观众期待落空 | 极高 | 标签与逻辑 |
| AP-MJ02 | 揭露顺序无递进 | 多个马甲的揭露震撼度无递进关系，时强时弱，缺乏"一层比一层炸"的节奏 | 高 | 结构与节奏 |
| AP-MJ03 | 马甲揭露无触发逻辑 | 马甲揭露不是由剧情因果驱动，而是强行"需要就亮"或"巧合暴露" | 高 | 标签与逻辑 |
| AP-MJ04 | 揭露后果空心化 | 马甲揭露后仅停留于对手震惊，无实质剧情推动（不改变关系/不扭转局势/不制造新冲突） | 中 | 结构与节奏 |
| AP-MJ05 | 马甲设定自相矛盾 | 不同马甲的设定逻辑冲突（如同时是某组织首领又是其死敌），世界观无法自洽 | 高 | 标签与逻辑 |
| AP-MJ06 | 连续轰炸麻木 | 两个以上马甲在同一场景/同一集内连续揭露，观众无消化时间，震撼递减 | 中 | 结构与节奏 |

> 注：本表只扣分不加分；扣分挂靠 4-review.md 对应维度，不另设加分关键节点。
