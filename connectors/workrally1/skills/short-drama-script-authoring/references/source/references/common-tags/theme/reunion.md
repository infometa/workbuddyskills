## 二、变体素材库（仅参考·可自由组合·可原创·可豁免）
> 本节所有内容均为灵感启发，**不强制命中、不作评分依据**，LLM 可自由组合/原创/豁免。

### 1. 情绪内核 + 高频套路提示（非禁用需翻转）

**情绪内核**：久别重逢、旧情难忘、物是人非、重新选择、失而复得

**高频套路提示**（非禁用，但需翻转或原创升级，避免模板化）：
1. 多年后重逢发现还爱着 → 翻转：重逢不是简单确认"还爱"，而是"我变了你也变了，我们是否还是对的？"——成长后的重新选择比单纯旧情复燃更有深度
2. 当初的误会终于解开 → 翻转：不一定是误会，可能是真实的选择分歧——复合不是"原来都是误会"，而是"即使当初没有误会，现在我们也能做出不同的选择"
3. 一次意外/危机拉近了距离 → 翻转：危机只是催化剂，真正的拉近距离是看到对方与从前不同的那一面——"你变了""你也变了"

### 2. Top3 对照关键节点

| 关键节点 | 核心爽感 | 对照学习要点 |
|---|---|---|
| 《重逢那天》型 | 多年后的重逢，物是人非中仍有心动 | 重逢的"时间感"要具体——不是抽象的"多年后"，而是生活中具体的变化展示时间的流逝 |
| 《我们回不去了》型 | 双方都变了，但变好后的重新选择比旧情复燃更珍贵 | 分开时的"不够好"→重逢时的"各自成长"→重新选择时的"现在的我们更配" |
| 《兜兜转转还是你》型 | 经历了其他人/其他事，最终还是选择彼此 | 不是"没得选所以回来"，而是"见过了世界，还是你最对"——主动选择比被动回归更有分量 |

### 3. 创作思考步骤

1. **定分**：分手原因——为什么分手？原因是否有足够重量？不能是"为分而分"的狗血误会
2. **定距**：分开期间——这段时间双方各自经历了什么？成长了什么？时间不能是空白
3. **定逢**：重逢场景——如何重逢？重逢时的情感冲击点是什么？双方状态的反差？
4. **定拉**：重新靠近的拉扯——从重逢到复合之间的情感拉锯，不可太快（无张力）也不可太久（观众疲）
5. **定变**：双方的成长——分开这段时间每个人变成了什么样？成长是否让复合成为"更好的选择"？
6. **定圆**：复合的逻辑——为什么"现在的我们"可以在一起而"当时的我们"不行？复合有成长支撑

### 4. 核心变体素材（任选，不限数量）
#### 分手原因变体
1. 价值观分歧型：人生选择不同，无法妥协而分开
2. 外力介入型：家庭/事业/第三者等外部力量导致的分离
3. 时机不对型：对的人出现在错的时间，彼此不够成熟
4. 信任崩塌型：一次事件摧毁了信任基础，无法在当下修复

#### 重逢模式变体
1. 偶然重逢型：命运安排的意外相遇，心跳加速
2. 必然重逢型：工作/社交圈/家族等必然路径的再遇
3. 刻意寻找型：一方主动寻找另一方，带着未了的心结
4. 第三方牵线型：共同的朋友/家人/事件将两人重新连接

#### 付费卡点变体
1. 重逢瞬间——"你还是……""你变了"
2. 发现旧情未了——某个细节暴露了心底的牵挂
3. 最大考验——复合前的最后一个障碍/选择
4. 复合确认——"这次，我不会再放手"

### 5. 钩子参考模板
- 开篇钩子参考：已经分开的两人即将/已经重逢，旧情与现状的碰撞即将开始
- 集末钩子参考（仅启发）：
  1. 重逢式：他们再次遇见了——各自带着不同的身份和经历
  2. 心动式：一个不经意的瞬间，旧情翻涌
  3. 选择式：复合的路上，还有最后一个必须面对的真相

## 三、人设加成参考
1. 双方：分开前后必须有变化——不是同两个人再演一遍，而是"变了的人重新选择彼此"
2. 新关系/新身份：重逢时一方或双方已有新的社会关系（新恋人/新家庭/新身份），制造选择张力
3. 共同记忆关键节点：某件物品/某个地方/某段记忆，是两人之间的"秘密通道"，触动即翻涌
4. 对照组：一段新的恋情（与新人在一起很安稳但缺了什么），反衬"重新选择旧人"的合理性

## 四、标签规则体系
### 1. 强互斥（不可叠加）
纯甜宠无冲突——破镜重圆需要"分→痛→圆"弧光，纯甜无冲突则"分"与"痛"全无，核心机制崩塌。

### 2. 兼容增强（推荐叠加）
- 追妻：破镜重圆+追妻=先分后追再到圆，情感弧光更长更虐（增强型）
- 虐恋：破镜的痛+重圆的甜=情绪振荡（对冲型）
- 重生：重生后的破镜重圆——"我知道我们会分手但这次我要改写结局"（裂变型）
- 豪门恩怨：家族恩怨导致分离，成长后以新姿态回归
- 马甲：分手后以新身份重逢——"你不知道现在的我是谁"

### 3. 优先级排序
- 受众 > 设定 > 主题 > 背景：破镜重圆作为主题标签，服务于女频受众"失而复得"的情感需求
- 破镜重圆 weight=high，与追妻同权重时：追妻主轴（行动驱动），破镜重圆辅轴（情感深度增量）
- 破镜重圆 + 重生：重生主轴（信息差驱动），破镜重圆辅轴（情感张力增量）
