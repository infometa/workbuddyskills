## 二、变体素材库（仅参考·可自由组合·可原创·可豁免）
> 本节所有内容均为灵感启发，**不强制命中、不作评分依据**，LLM 可自由组合/原创/豁免。

### 1. 情绪内核 + 高频套路提示（非禁用需翻转）

**情绪内核**：悔悟弥补、卑微求全、迟来的深情、伤害清零、重新追回

**高频套路提示**（非禁用，但需翻转或原创升级，避免模板化）：
1. 渣男后悔下跪求原谅 → 翻转：悔悟不是一跪了之，而是持续的、有代价的改变行为——"下跪容易，改变难"
2. 女主铁了心不原谅 → 翻转：不原谅不是目的，清零伤害才是——女主的"冷"不是因为恨，是因为还没看到真正的改变
3. 各种花式讨好被拒 → 翻转：被拒要有递进——从冷漠拒绝→犹豫动摇→心软考验→最终接纳，不可原地踏步

### 2. Top3 对照关键节点

| 关键节点 | 核心爽感 | 对照学习要点 |
|---|---|---|
| 《火葬场》型 | 男主从高高在上到卑微求全，反差极致 | 渣的程度与卑微的程度必须成正比——当初多狠现在多惨 |
| 《迟来的深情》型 | 男主悔悟后的深情与女主的冷漠形成强烈反差 | 女主的冷漠不是矫情，是伤害的真实后果——不轻易原谅才有价值 |
| 《她走了以后》型 | 男主在失去后才意识到她有多重要 | 失去后的"空"要具体——不是抽象的"想她"，而是生活中每个细节都在提醒她不在了 |

### 3. 创作思考步骤

1. **定伤**：男主对女主造成了什么伤害？伤害越深，追妻的难度和爽感越大
2. **定悟**：悔悟的触发——什么让他意识到自己错了？触发是否有说服力？
3. **定卑**：卑微的呈现——他做了什么来弥补？是否足够卑微？卑微与曾经的高高在上是否形成足够反差？
4. **定零**：伤害清零的标准——什么才算"伤害被清零"？不是男主觉得够了，而是女主感受到"伤害被真正弥补"
5. **定拒**：女主的拒绝逻辑——每一次拒绝都有具体原因，不是"矫情"，是"还没看到真正的改变"
6. **定纳**：最终接纳——不是因为心软，而是因为伤害确实被清零+看到了持久的改变

### 4. 核心变体素材（任选，不限数量）
#### 悔悟模式变体
1. 痛失型：彻底失去后才知道珍贵
2. 真相型：发现误会/被蒙蔽，才知自己伤了她
3. 对比型：看到别人如何珍视她，才知自己多混蛋
4. 重现型：她走后生活中处处是她的影子，终于意识到无法替代

#### 追妻行为变体
1. 公开认错型：当众承认错误，放下所有面子
2. 默默守护型：不求回报地在她身边做事，用行动而非言语
3. 自我惩罚型：主动承受与当初伤害同等的痛苦，以示悔改
4. 改变本质型：从根本上改变导致伤害的行为模式/性格缺陷

#### 付费卡点变体
1. 悔悟瞬间——"我到底做了什么"
2. 第一次卑微——他放下尊严的那一刻
3. 最大牺牲——他愿意为她付出最大的代价
4. 伤害清零——女主真正感受到"这扇门可以重新打开了"

### 5. 钩子参考模板
- 开篇钩子参考：女主决定离开/已经离开，男主尚未意识到严重性
- 集末钩子参考（仅启发）：
  1. 悔悟式：他终于明白自己失去了什么
  2. 卑微式：他第一次放下了所有尊严
  3. 希望式：她的冷漠出现了一丝裂缝

## 四、标签规则体系
### 1. 强互斥（不可叠加）
纯甜宠无虐——追妻需要"虐→追→甜"弧光，纯甜无冲突则追妻无起点，核心机制崩塌。

### 2. 兼容增强（推荐叠加）
- 甜宠：先虐后甜，追妻的卑微让后面的甜更珍贵（对冲型）
- 马甲：隐藏身份的男主追妻——她不知道她拒绝的人是她的靠山（裂变型）
- 战神归来：武力碾压的爽感与追妻的卑微形成身份反差张力（对冲型）
- 虐恋：虐恋的伤害深度为追妻提供更强烈的悔悟动力
- 重生：重生后的追妻——"上辈子我伤害了你，这辈子我要弥补"

### 3. 优先级排序
- 受众 > 设定 > 主题 > 背景：追妻作为主题标签，服务于女频受众"看男主卑微"的情感需求
- 追妻 weight=high，与虐恋同权重时：虐恋提供伤害深度（前半段），追妻提供卑微弥补（后半段），按剧情阶段交替主导
- 追妻 + 马甲：追妻主轴（情感驱动），马甲为辅轴（身份反差增量）
