# 设定标签：神豪
> 官方标签映射：角色设定 · 神豪
> 定位属性：level-2 弱红线 · 金钱碾压的极致爽感，以无限财力实现即时正义
> 核心情绪：金钱碾压、财富自由、挥金如土、金钱打脸

> 映射说明：神豪映射 domestic/face-slapping combo——神豪的核心爽感是"金钱打脸"，与打脸虐渣天然耦合。神豪与打脸的区别：神豪用"钱"碾压，打脸用"实力/身份"碾压，两者可叠加产生叠加冲击。

## 二、变体素材库（仅参考·可自由组合·可原创·可豁免）
> 本节全部为灵感启发，**不强制命中、不作评分依据**，可自由组合/原创/豁免。

### 1. 节奏适配逻辑
常见节奏：穷困开局 → 获得财富来源 → 首次金钱碾压 → 财富升级/新挑战 → 极致金钱打脸 → 巅峰财富地位。神豪的核心节奏是"穷→富→更富"的递进——每次金钱碾压的力度都要升级，从买得起一顿饭到买得起一栋楼到买得起一座城。付费节点可落在首次金钱碾压、财富升级、极致打脸等处——仅为参考。

### 2. 核心变体素材（任选，不限数量）

#### 情绪内核
神豪的情绪引擎：金钱碾压（用钱解决问题/碾压对手的粗暴爽感）、财富自由（再也不用为钱发愁的自由感）、挥金如土（想买什么买什么的放纵感）、金钱打脸（用钱让看不起自己的人闭嘴的解气感）。核心爽感来自"钱能解决的问题都不是问题"——这是现实中"一分钱难倒英雄汉"的补偿性体验。

#### 高频套路提示（非禁用需翻转）
1. 无限刷题型：系统/金手指无限刷钱无任何限制 → 需翻转：财富必须有来源逻辑和获取条件，不能凭空无限
2. 纯砸钱型：只靠砸钱解决一切问题无策略 → 需翻转：金钱碾压也需要智慧和策略，纯砸钱会腻
3. 买断人格型：用钱买断所有人的尊严和人格 → 需翻转：必须有金钱买不到的东西，否则格局太低
4. 无脑消费型：花钱只为炫耀无实质用途 → 需翻转：花钱要有策略性和目的性，投资/打脸/守护有意义

#### Top3 对照关键节点
1. 《西虹市首富》——神豪喜剧型：突然暴富的消费爽感+金钱买不到真情的底线
2. 《重生之超级富翁》——重生神豪型：信息差+财富积累的双线爽感
3. 《我真是大富豪》——系统神豪型：系统任务驱动财富升级，节奏清晰

#### 创作思考步骤
1. 先确定"财富来源"——钱从哪来？系统/重生信息差/传承/奇遇？来源必须有逻辑
2. 再确定"花钱方式"——钱怎么花？打脸/投资/守护/享受？花钱要有创意和策略
3. 然后确定"金钱边界"——什么买不到？感情/尊严/真相/生命？边界让金钱有温度
4. 最后确定"财富节奏"——从多少到多少？每级财富对应的碾压力度要递进

#### 神豪类型变体
1. 系统神豪型：系统任务驱动财富升级
2. 重生神豪型：信息差投资/预判致富
3. 传承神豪型：继承顶级财富/商业帝国
4. 逆袭神豪型：从贫穷到首富的阶层跨越
5. 女首富型：女频方向——财富独立+商业帝国

#### 金钱打脸变体
1. 拍卖碾压型：在拍卖场上用钱碾压对手
2. 商业收购型：收购曾经看不起自己的公司/品牌
3. 慈善碾压型：用慈善/投资让对手无话可说
4. 全包型：包场/包机/包岛，极致排场碾压
5. 对赌型：用商业对赌让对手输得心服口服

#### 付费卡点变体
1. 首次碾压节点：神豪首次用金钱碾压，从穷到富的反差爆发
2. 财富升级节点：财富量级质变，碾压力度升级
3. 极致打脸节点：最大规模的金钱打脸名场面

### 3. 钩子参考模板
- 开篇钩子参考：穷到极致的屈辱——被钱逼到绝境，但下一刻财富来了
- 集末钩子参考（仅启发）：
  1. 碾压式：那个曾经看不起他的人，现在他可以买下对方整个公司
  2. 升级式：他的财富刚刚升了一个量级，碾压力度即将翻倍
  3. 边界式：他发现有些东西，即使有再多钱也买不到

## 三、人设加成参考
1. 主角：神豪主角必须有"穷过"的底色——知道没钱是什么滋味，有钱后才懂得钱的真正价值。不能暴富后变成无脑暴发户。
2. 配角：被金钱碾压的对象——势利眼/拜金者/商业对手，他们的存在感越强打脸越爽。
3. 不可买型角色：金钱买不到的真心/真情/真相——这些角色让神豪有温度，不只是冷冰冰的数字。
> 仅为方向参考，可自由组合与原创。

- 神豪叠加马甲时，隐藏首富身份=最强马甲，身份揭露=极致打脸。

## 五、红线与反模式
> 红线severity：弱

### 1. 避坑提示（不挂质检号、不扣分，仅创作提醒）
1. 避免凭空刷钱：财富无来源逻辑，系统/金手指无限刷钱无任何条件和限制。
2. 避免纯砸钱无脑：所有问题只靠砸钱解决无策略无智慧，沦为数字游戏。
3. 避免金钱万能：金钱可以解决一切包括感情/尊严/真相，格局降低。
4. 避免花钱无创意：花钱方式单一重复（每集都是拍卖场/刷卡），审美疲劳。
5. 避免暴发户人格：主角暴富后人设变为无脑炫耀，缺乏格局和温度。

> 弱红线标签不挂全局质检号；上述风险若上升为崩级问题（如性格漂移），由 anti-patterns.md 通用反模式兜底检测扣分。
