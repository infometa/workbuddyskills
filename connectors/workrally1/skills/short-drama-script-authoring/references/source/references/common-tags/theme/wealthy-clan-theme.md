## 二、变体素材库（仅参考·可自由组合·可原创·可豁免）
> 本节全部为灵感启发，**不强制命中、不作评分依据**，可自由组合/原创/豁免。

### 1. 节奏适配逻辑
常见节奏：身份入局 → 家族矛盾激化 → 权力/财产博弈 → 真相反转与清算。豪门题材重在权谋层次与情感纠葛交织。付费节点可落在身世曝光、继承权之争、联姻博弈、家族反转等处——仅为参考。

### 2. 核心变体素材（任选，不限数量）
#### 博弈爽点变体
1. 继承权之争型：围绕家产继承的明争暗斗
2. 商战联动型：家族恩怨延伸到商场对决
3. 身世反转型：隐藏的血脉身份揭开，格局重洗
4. 联姻博弈型：政治联姻下的情感与利益拉扯

#### 冲突模式变体
1. 嫡庶之争型：家族内部派系倾轧
2. 外敌入侵型：竞争家族觊觎，内外交困
3. 联手反目型：曾经的盟友因利益翻脸
4. 旧仇清算型：上一辈的恩怨延续到下一代

#### 人设风格变体
1. 冷面继承人型：城府深、手段硬的家族掌权者
2. 隐忍复仇型：背负血仇潜伏家族伺机而动
3. 清流改革型：想打破家族陈规的异类

#### 付费卡点变体
1. 身世曝光节点
2. 继承权之争节点
3. 家族反转节点

### 3. 钩子参考模板
- 开篇钩子参考：豪门宴会暗流涌动，主角因一桩旧事被卷入家族漩涡
- 集末钩子参考（仅启发）：
  1. 身世式：她的真实身份，足以掀翻整个家族
  2. 博弈式：继承权的争夺，今晚见分晓
  3. 反转式：原来真正的幕后黑手，就在饭桌上

## 五、红线与反模式
> 红线severity：弱

### 1. 避坑提示（不挂质检号、不扣分，仅创作提醒）
1. 避免豪门悬浮：商业逻辑出错，家族运作不符现实常识。
2. 避免人物脸谱化：非黑即白、反派只剩恶、正派只剩善。
3. 避免斗争低级：明争暗斗全靠嘴炮叫嚣，无真正的谋略层次。
4. 避免狗血过度：为反转而反转，剧情靠堆砌巧合与撕扯支撑。

> 弱红线标签不挂全局质检号；上述风险若上升为崩级问题（如世界观硬伤），由 anti-patterns.md 通用反模式兜底检测扣分。
