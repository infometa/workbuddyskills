## 二、变体素材库（仅参考·可自由组合·可原创·可豁免）
> 本节全部为灵感启发，**不强制命中、不作评分依据**，可自由组合/原创/豁免。

### 1. 节奏适配逻辑
常见节奏：能力觉醒 → 隐藏试探 → 借能力破局 → 能力升级与代价显现。异能与现实生活的反差是爽点核心。付费节点可落在能力首次显威、身份/能力曝光、能力升级、对手同类异能者出现等处——仅为参考。

### 2. 核心变体素材（任选，不限数量）
#### 异能爽点变体
1. 读心型：洞悉他人心声，先人一步
2. 预知型：预见危险或结果，提前布局
3. 操控型：操纵物体/元素，化解危机
4. 治愈型：异能救人于危难，扭转局面

#### 冲突模式变体
1. 隐藏暴露型：极力隐藏异能却险些曝光
2. 同类对决型：遇到另一异能者，能力正面碰撞
3. 被利用型：异能被觊觎，主角陷入被追猎处境
4. 代价反噬型：使用异能付出代价，制造两难

#### 人设风格变体
1. 低调藏拙型：能力强大却深藏不露
2. 反差萌型：普通身份反差出惊人异能
3. 成长觉醒型：从弱小异能逐步进化变强

#### 付费卡点变体
1. 能力首次显威节点
2. 能力/身份曝光节点
3. 能力升级节点

### 3. 钩子参考模板
- 开篇钩子参考：平凡场景中主角不经意展露异能，建立反差与神秘感
- 集末钩子参考（仅启发）：
  1. 觉醒式：他发现自己，能听见别人心里的声音
  2. 危机式：有人盯上了他的能力
  3. 同类式：原来，世界上不止他一个人有异能

### 1. 强互斥（不可叠加）

- 当玄幻仙侠等更宏大的能力体系命中时，由其定调，异能退为都市向变体。

## 五、红线与反模式
> 红线severity：弱

### 1. 避坑提示（不挂质检号、不扣分，仅创作提醒）
1. 避免异能无规则、随心所欲，能力边界模糊导致剧情失控。
2. 避免异能无代价、无敌流，主角靠能力躺赢、失去拉扯。
3. 避免能力靠嘴说、无视觉化，异能场面缺乏画面呈现。
4. 避免异能与主线脱节，能力沦为炫技摆设、不推动剧情。

> 弱红线标签不挂全局质检号；上述风险若上升为崩级问题（如世界观硬伤、金手指失控），由 anti-patterns.md 通用反模式兜底检测扣分。
