# 主题标签：打脸虐渣
> 官方标签映射：主题 · 打脸虐渣
> 定位属性：level-2 弱红线 · 以身份反差和实力碾压实现即时正义的爽感引擎
> 核心情绪：不公被纠正、解气快感、身份反差、当场社死

> 映射说明：打脸虐渣映射 domestic/face-slapping combo——打脸是国内平台核心爽感引擎之一。文件名加 `-theme` 后缀避免与 combos/face-slapping.md 撞名。打脸虐渣是纯爽感供给标签，与其他标签叠加时通常做主轴。

## 二、变体素材库（仅参考·可自由组合·可原创·可豁免）
> 本节全部为灵感启发，**不强制命中、不作评分依据**，可自由组合/原创/豁免。

### 1. 节奏适配逻辑
常见节奏：被看低/受委屈 → 隐忍蓄力 → 实力揭露/身份反转 → 当场打脸 → 渣人连环社死。打脸的核心结构是"压→放"——压得越深，放的时候越爽。每次打脸都是一个完整的情绪回路：不公→隐忍→爆发→正义伸张。付费节点可落在打脸瞬间、身份揭露、连环社死等处——仅为参考。

### 2. 核心变体素材（任选，不限数量）

#### 情绪内核
打脸虐渣的情绪引擎：不公被纠正（终于有人主持公道了）、解气快感（替天行道的爽）、身份反差（原来她/他比你们所有人都厉害）、当场社死（让所有看不起她/他的人无地自容）。核心爽感来自"即时正义"——不需要等很久，坏人的报应马上就到。这是现实中"好人总被欺负"的补偿性体验。

#### 创作思考步骤
1. 先设计"压"的深度——主角被看低/受委屈到什么程度？压得越深打脸越爽
2. 再设计"打"的方式——用什么打脸？实力/身份/人脉/知识/证据？方式要有创意
3. 然后设计"脸"的反应——被打脸的人什么反应？震惊/恐惧/崩溃/求饶？反应要有层次
4. 最后设计"打脸节奏"——必须是层层递进。大Boss要留到最后

#### 打脸类型变体
1. 身份打脸型：真实身份/背景揭露，所有人震惊
2. 实力打脸型：真正实力碾压，以弱胜强反转
3. 智力打脸型：用智商/策略碾压，让对手无话可说
4. 人脉打脸型：原来她/他的靠山是最强的人
5. 道德打脸型：对方恶行被当众揭穿，道德审判

#### 渣人类型变体
1. 拜金势利型：以貌取人/以钱取人，被打脸后无地自容
2. 绿茶白莲型：表面无辜背地使坏，真面目被揭穿社死
3. 渣男/渣女型：感情背叛者，被当众揭穿崩溃
4. 恃强凌弱型：仗势欺人，被实力碾压反杀
5. 虚伪型：人前一套背后一套，伪装被撕碎

#### 付费卡点变体
1. 首次打脸节点：主角首次反击碾压，爽感爆发
2. 身份揭露节点：真实身份/背景当众曝光
3. 大Boss打脸节点：最终反派的社死名场面

### 3. 钩子参考模板
- 开篇钩子参考：一场极不公平的对待——主角被看低/被欺负/被冤枉，观众怒气值拉满
- 集末钩子参考（仅启发）：
  1. 反转式：所有人都看不起她，但下一刻她将让所有人闭嘴
  2. 身份式：她的真实身份，比在场所有人都要尊贵
  3. 复仇式：她忍了这么久，就是为了这一刻让他们无地自容

## 三、人设加成参考
1. 主角：打脸主角必须有"被看低的理由"——可以是隐藏实力/隐藏身份/低调做人。关键是观众知道她/他有多厉害，但剧中人不知道，信息差制造期待。
2. 配角：看低主角的人——他们的势利/偏见/傲慢越真实，打脸时越爽。
3. 对立方：主要反派/渣人——需要有足够的存在感和作恶力度，打倒他才有分量。不能是降智工具人。
> 仅为方向参考，可自由组合与原创。

## 四、标签规则体系
### 1. 强互斥（不可叠加）
无绝对互斥标签。打脸虐渣作为纯爽感供给标签，可与大多数标签兼容。

### 2. 兼容增强（推荐叠加）
重生（信息差让打脸更精准）、马甲（多重马甲连爆更震撼）、豪门恩怨（豪门场景让打脸更华丽）、逆袭（打脸是逆袭的高潮形式）、神豪（金钱碾压式打脸）。

### 3. 优先级排序
- 受众 > 设定 > 主题 > 背景：打脸虐渣作为主题维度，提供核心爽感供给。
- 打脸虐渣叠加其他标签时，通常做主轴——打脸是情绪回报，其他标签提供打脸的"素材"和"场景"。
- 与逆袭叠加时，打脸是逆袭的高潮表现形式，逆袭提供积累过程，打脸提供爆发瞬间。

## 五、红线与反模式
> 红线severity：弱

### 1. 避坑提示（不挂质检号、不扣分，仅创作提醒）
1. 避免降智反派：反派/渣人智商突然降低配合打脸，打脸失去挑战感和真实感。
2. 避免机械重复：打脸场景套路雷同、策略单一，审美疲劳导致爽感递减。
3. 避免无铺垫碾压：主角无被看低/受委屈的铺垫直接碾压，缺乏"压→放"的情绪回路。
4. 避免纯爽无脑：只顾打脸不管逻辑、情感和人物成长，沦为低智爽文。
5. 避免打脸过快：反派一集就被打脸下线，缺乏拉扯和递进，浪费了反派的戏剧价值。

> 弱红线标签不挂全局质检号；上述风险若上升为崩级问题（如人物与人设崩坏），由 anti-patterns.md 通用反模式兜底检测扣分。

## 七、融梗亲和性（v5.3 新增）

### 增强型
- **重生** → fusion/recipes/rebirth-revenge.md：重生信息差让打脸更精准更解气——"我都知道你会做什么"。重生的预判让打脸的时机、方式、力度都恰到好处。
- **马甲** → fusion/recipes/mask-face-slap.md：多重马甲连爆比单一身份揭露更震撼。每个马甲揭露都是一次打脸，连爆产生叠加冲击波。
- **豪门恩怨** → 豪门场景让打脸更华丽更解气——身份/财富/地位的反差在豪门背景下被放大。
