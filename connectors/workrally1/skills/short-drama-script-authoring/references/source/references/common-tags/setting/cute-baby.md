# 设定标签：萌宝
> 官方标签映射：角色设定 · 萌宝
> 定位属性：level-2 弱红线 · 亲情+爱情双线助攻人设，女频高人气标签
> 核心情绪：萌、暖、亲情治愈、追妻助攻、双向奔赴

---

## 一、标签基础属性
| 项目 | 规则 |
|---|---|
| 适配受众 | 女频 |
| 适配背景 | 都市、豪门、年代适配度最高 |
| 权重等级 | high |
| 核心底线 | 萌宝助攻爹妈复合/追妻，亲情与爱情双线并行；萌宝须符合年龄认知，不工具化 |

---

## 二、变体素材库（仅参考·可自由组合·可原创·可豁免）
> 本节全部为灵感启发，**不强制命中、不作评分依据**，可自由组合/原创/豁免。

### 1. 节奏适配逻辑
常见节奏：萌宝登场 → 牵线爹妈 → 误会拉扯 → 一家团圆。付费节点可落在父子/父女相认、萌宝助攻名场面、身世揭晓等处——仅为参考。

### 2. 核心变体素材（任选，不限数量）
#### 萌点爽点变体
1. 神助攻型：萌宝机灵牵线，制造爹妈独处与心动契机
2. 高情商型：童言童语戳中要害，替妈妈出气、替爸爸表白
3. 团宠萌娃型：被全家宠爱，软萌可爱治愈观众
4. 小大人型：超龄懂事护着妈妈，反差萌爆棚

#### 冲突模式变体
1. 隐瞒身世型：女主独自抚养，男主不知有娃，相认前的张力
2. 阻碍认亲型：长辈/情敌阻挠父子相认，制造冲突
3. 错认双胞型：双胞胎/抱错娃误会，认亲一波三折
4. 守护亲情型：萌宝遇险，激发男主父爱与责任

#### 人设风格变体
1. 奶萌软糯型：年龄小、爱撒娇，主打治愈可爱
2. 鬼马机灵型：点子多、嘴皮溜，制造笑点与助攻
3. 早慧懂事型：替妈妈分忧，懂事到让人心疼
4. 高冷小奶包型：对外冷对妈热，反差萌

#### 付费卡点变体
1. 相认节点：男主得知萌宝是亲生骨肉
2. 助攻节点：萌宝牵线促成爹妈关键和解
3. 守护节点：萌宝陷入危机，一家人合力守护

### 3. 钩子参考模板
- 开篇钩子参考：萌宝意外撞见"陌生爸爸"，埋下相认与追妻的双线预期
- 集末钩子参考（仅启发）：
  1. 相认式：那个总裁看着孩子的脸，瞳孔猛地一缩
  2. 助攻式：妈妈，我帮你把那个坏阿姨赶跑了
  3. 悬念式：孩子的身世，马上要瞒不住了

## 三、人设加成参考
1. 萌宝：剧情黏合剂，串联亲情与爱情双线；性格符合年龄，软萌或机灵，不成人化。
2. 女主：独立抚养或被误解的妈妈，坚韧温柔。
3. 男主：失而复得的爹，因萌宝softening，重新追回女主。
> 仅为方向参考，具体设定可自由发挥。

### 3. 优先级排序

## 五、红线与反模式
> 红线severity：弱

### 1. 避坑提示（不挂质检号、不扣分，仅创作提醒）
1. 避免萌宝成人化，台词心机过重、不符年龄认知，失去萌感。
2. 避免写成熊孩子，无礼任性惹人厌，破坏治愈基调。
3. 避免萌宝工具人化，只为推进剧情、缺乏独立性格与可爱细节。
4. 避免年龄与行为严重不符（如三岁娃说成熟情话），逻辑出戏。

> 弱红线标签不挂全局质检号；上述风险若上升为崩级问题（如人设漂移），由 anti-patterns.md 通用反模式（#8 性格漂移等）兜底检测。
