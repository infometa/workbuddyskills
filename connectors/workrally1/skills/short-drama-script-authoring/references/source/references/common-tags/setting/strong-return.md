# 设定标签：强者回归
> 官方标签映射：角色设定 · 强者回归
> 定位属性：level-2 弱红线 · 曾经的强者以新身份归来，用实力碾压清算旧账
> 核心情绪：强者回归、迟来的正义、隐忍爆发、身份回归

> 映射说明：强者回归映射 domestic/war-god-return combo——强者回归与战神归来共享"强者隐忍→回归碾压"的核心结构。强者回归比战神归来更广义——不限于战力，可以是商业/医术/权势等任何领域的顶尖强者。

| 项目 | 规则 |
|---|---|

## 二、变体素材库（仅参考·可自由组合·可原创·可豁免）
> 本节全部为灵感启发，**不强制命中、不作评分依据**，可自由组合/原创/豁免。

### 1. 节奏适配逻辑
常见节奏：曾经辉煌 → 被迫离开/隐忍 → 以新身份出现 → 小范围展露实力 → 旧人旧事碰撞 → 身份揭露/实力全面爆发 → 碾压清算。强者回归的核心结构是"旧王归来"——曾经的巅峰+被迫的离开+归来的碾压，每一个环节都有对应的爽感释放。付费节点可落在小实力展露、身份揭露、全面碾压等处——仅为参考。

### 2. 核心变体素材（任选，不限数量）

#### 情绪内核
强者回归的情绪引擎：强者回归（曾经的王回来了）、迟来的正义（当年被夺走的一切现在夺回来）、隐忍爆发（隐忍越深爆发越强）、身份回归（原来他/她才是最强的）。核心爽感来自"正义虽迟但到"——当年的不公终于被纠正，当年的强者终于回到他/她应有的位置。

#### 高频套路提示（非禁用需翻转）
1. 无限隐忍型：回归后仍然隐忍不出手 → 需翻转：隐忍必须有触发点，关键时刻必须出手碾压
2. 战力崩坏型：回归后实力夸张到离谱无逻辑 → 需翻转：实力展示要有合理性，不能无限升级
3. 旧怨轻放型：对当年加害者轻易原谅无清算 → 需翻转：旧账必须清算，正义必须有力度
4. 身份轻揭型：回归身份轻易被识破无悬念 → 需翻转：身份揭露要有节奏和仪式感

#### Top3 对照关键节点
1. 《战神归来》——战力回归天花板：战神隐姓埋名→被迫出手→身份揭露→碾压全敌
2. 《赘婿》中的宁毅——商业强者回归：现代商业思维在古代的降维打击
3. 《叶问》——武术强者回归：隐忍的武者被迫出手，以实力捍卫尊严

#### 创作思考步骤
1. 先确定"曾经的巅峰"——他/她曾经有多强？在什么领域？巅峰描述要让观众心生敬服
2. 再确定"离开的原因"——为什么离开？被迫/承诺/任务/保护？原因要有分量
3. 然后确定"回归的触发"——什么让他/她决定回归？旧人被欺负/承诺到期/任务完成？触发要有情感力度
4. 最后确定"清算的方式"——怎么清算旧账？碾压/智取/对峙/揭露？方式要有仪式感

#### 强者回归类型变体
1. 战力回归型：武力/战力领域的顶尖强者归来
2. 商业回归型：商业帝国的缔造者/顶级商人归来
3. 医术回归型：神医/医学泰斗归来
4. 权势回归型：曾经的权力巅峰者归来
5. 才学回归型：某领域顶级人才/天才归来

#### 隐忍蓄力变体
1. 假死隐遁型：假死后以新身份出现
2. 离开历练型：离开后变得更强再回来
3. 承诺约束型：因承诺暂不出手的隐忍
4. 保护型隐忍：为保护某人而隐藏实力
5. 布局型隐忍：暗中布局等待时机成熟

#### 付费卡点变体
1. 小实力展露节点：回归者首次小范围展露真正实力
2. 身份揭露节点：真实身份被当众认出
3. 全面碾压节点：实力全面爆发，碾压所有对手

### 3. 钩子参考模板
- 开篇钩子参考：一个看似平凡的人出现——但他的眼神/习惯/细节暗示着不凡的过去
- 集末钩子参考（仅启发）：
  1. 身份式：他看似普通，但他曾经站在这个世界最高的位置
  2. 碾压式：那些欺负他家人的人不知道，他们惹了最不该惹的人
  3. 归来式：曾经的王回来了，而这一次他不会再离开

## 三、人设加成参考
1. 主角：强者回归主角必须有"沧桑感"——经历过巅峰和低谷的人，行为举止有底蕴。看似平凡但关键时刻的从容和碾压力暴露真实实力。不能全程装弱无层次。
2. 配角：不认识主角的"新世界"角色——他们的看低和无知制造信息差爽感。以及认识主角旧身份的人——他们的震惊和恐惧制造身份揭露的冲击力。
3. 对立方：当年逼迫主角离开的人/势力——他们的存在感越强、越嚣张，回归清算时越爽。
> 仅为方向参考，可自由组合与原创。

## 四、标签规则体系
### 1. 强互斥（不可叠加）
无绝对互斥标签。强者回归作为设定标签，可与大多数主题兼容。

### 2. 兼容增强（推荐叠加）
马甲（隐藏身份的强者=最强马甲）、战神归来（战力型强者回归）、逆袭（回归是逆袭的极致形式）、赘婿（强者隐藏身份入赘=强反差）、打脸虐渣（回归碾压即打脸）。

### 3. 优先级排序
- 受众 > 设定 > 主题 > 背景：强者回归作为设定维度，提供角色身份和隐忍爆发的基础。
- 强者回归与战神归来：强者回归是广义设定（任何领域的强者），战神归来是狭义主题（战力型回归）。两者叠加时，战神归来为强者回归提供具体领域。
- 强者回归与马甲：强者回归天然包含马甲设定——隐藏身份=隐藏马甲，身份揭露=马甲揭露。

## 五、红线与反模式
> 红线severity：弱

### 1. 避坑提示（不挂质检号、不扣分，仅创作提醒）
1. 避免战力崩坏：回归后的实力展示夸张到无逻辑，无限升级无边界。
2. 避免隐忍无限期：回归后仍然隐忍不出手，每集都被欺负却始终不爆发，观众情绪耗尽。
3. 避免旧怨轻放：对当年加害者轻易原谅无清算，正义感缺失。
4. 避免回归无触发：强者回归缺乏明确的触发事件和情感动因，"为什么现在回来"未回答。
5. 避免实力无参照：强者的实力缺乏参照体系，"到底有多强"观众感知不到。

> 弱红线标签不挂全局质检号；上述风险若上升为崩级问题（如战力崩坏/性格漂移），由 anti-patterns.md 通用反模式兜底检测扣分。
