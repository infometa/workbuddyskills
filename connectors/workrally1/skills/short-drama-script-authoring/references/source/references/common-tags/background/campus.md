## 二、变体素材库（仅参考·可自由组合·可原创·可豁免）
> 本节全部为灵感启发，**不强制命中、不作评分依据**，可自由组合/原创/豁免。

### 1. 节奏适配逻辑
常见节奏：校园相遇 → 青涩互动 → 成长/逆袭挑战 → 蜕变收获。校园背景重在青春质感与成长，行为符合学生身份。付费节点可落在心动名场面、逆袭翻盘、竞赛/考试关键、成长蜕变等处——仅为参考。

### 2. 核心变体素材（任选，不限数量）
#### 场景素材
1. 教室场景：课堂、自习室、黑板报、座位安排的校园日常
2. 校园角落：操场、图书馆、天台、小卖部、林荫道
3. 活动场景：运动会、文艺汇演、社团、竞赛、毕业典礼
4. 青春场景：补习、晚自习、骑车放学、宿舍夜谈

#### 台词风格素材
1. 青涩直白：符合学生年龄的青涩、直接表达
2. 校园流行语：贴合年轻人的网络与校园用语
3. 热血励志：追梦、奋斗、不服输的青春台词
4. 暗恋心声：青涩心动的内心独白与小心思

#### 行为逻辑素材
1. 学生身份：以学业、竞赛、社团为核心的行为动机
2. 同窗情谊：友情、暗恋、竞争交织的青春关系
3. 成长烦恼：升学压力、家庭、自我认同的现实困扰
4. 青涩边界：符合学生身份的行为边界，不超纲

#### 付费卡点变体
1. 心动名场面节点
2. 逆袭翻盘节点
3. 成长蜕变节点

### 3. 钩子参考模板
- 开篇钩子参考：校园里一次青涩的相遇或一场逆袭挑战，建立成长预期
- 集末钩子参考（仅启发）：
  1. 心动式：那个少年的目光，让她脸红了
  2. 逆袭式：这次考试/比赛，他要逆袭翻盘
  3. 成长式：青春的这道坎，他必须跨过去

## 三、人设加成参考
1. 主角：符合学生身份，言行贴合年龄，成长有真实的青春质感。
2. 同窗：好友、对手、暗恋对象，构成青春群像。
3. 师长/家长：作为成长引导或阻碍，制造合理的校园冲突。

## 五、红线与反模式
> 红线severity：弱

### 1. 避坑提示（不挂质检号、不扣分，仅创作提醒）
1. 避免校园悬浮：学生行为超纲，如在校经商上亿、脱离学生身份。
2. 避免台词违和：过于成熟老成或过于低幼，不符学生年龄。
3. 避免校园背景名存实亡：全程谈恋爱，校园沦为空壳。
4. 避免霸凌过度、价值观偏差，渲染欺凌或传递错误导向。

> 弱红线标签不挂全局质检号；上述风险若上升为崩级问题（如价值观偏差），由 anti-patterns.md 通用反模式兜底检测扣分。
