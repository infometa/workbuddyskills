## 二、变体素材库（仅参考·可自由组合·可原创·可豁免）
> 本节全部为灵感启发，**不强制命中、不作评分依据**，可自由组合/原创/豁免。

### 1. 节奏适配逻辑
常见节奏：相遇交集 → 年龄差拉扯 → 包容动心 → 双向奔赴。付费节点可落在首次心动、突破年龄隔阂、公开关系、守护名场面等处——仅为参考。

### 2. 核心变体素材（任选，不限数量）
#### 情感爽点变体
1. 初遇解围型：女主遇麻烦，男主成熟出手解决
2. 包容宠爱型：女主闯祸，男主兜底不指责只解决
3. 安全感名场型：女主低谷时，男主是最坚实后盾
4. 反差萌型：稳重大叔在女主面前露出吃醋/幼稚一面

#### 冲突模式变体
1. 外界质疑型：被议论年龄差、不般配，两人共同面对
2. 父母反对型：女主家长坚决反对，制造阻碍
3. 同辈竞争型：年轻追求者出现，激发男主危机感
4. 阅历落差型：观念/生活习惯差异碰撞，有代沟也有萌点

#### 人设风格变体
1. 事业有成型：总裁/教授/律师，事业稳定有底气
2. 退伍硬汉型：铁血外表下的细腻包容
3. 温润学者型：儒雅克制，润物无声地照顾

#### 付费卡点变体
1. 心动节点：成熟男主第一次为小姑娘破例
2. 阻碍节点：女主父母登门反对
3. 守护节点：女主陷入危机，男主倾力托底

### 3. 钩子参考模板
- 开篇钩子参考：女主闯祸被刁难，成熟男主从容解围，建立反差印象
- 集末钩子参考（仅启发）：
  1. 拉扯式：他们相差十二岁，注定要面对很多流言
  2. 心动式：活了三十多年，他第一次对一个小姑娘这么上心
  3. 危机式：她的父母，坚决反对他们在一起

## 三、人设加成参考
1. 男主：30-45岁，比女主成熟一截；有社会地位与经济基础；成熟稳重、情绪稳定、会照顾人，有阅历不油腻。
2. 女主：年轻鲜活、有朝气，能治愈男主的沧桑。
3. 阻碍角色：女主父母、男主同辈、外界议论，制造年龄差冲突。
> 仅为方向参考，具体设定可自由发挥。

## 五、红线与反模式
> 红线severity：弱

### 1. 避坑提示（不挂质检号、不扣分，仅创作提醒）
1. 避免男主油腻爹味、说教感强，把控制当包容。
2. 避免年龄差毫无体现，人设和年轻男主无区别，标签名存实亡。
3. 避免女主低龄化、价值观导向偏差（女主必须成年）。
4. 避免阻碍过于刻意、为虐而虐、逻辑生硬。

> 弱红线标签不挂全局质检号；上述风险若上升为崩级问题（如人设漂移），由 anti-patterns.md 通用反模式（#8 性格漂移等）兜底检测。

## 七、融梗亲和性（v5.3 新增）

### 增强型
- **破镜重圆** → fusion/recipes/chase-wife-sweet.md：多年后重逢的设定让大叔更显成熟稳重，重新追回女主时阅历加持的包容与守护，把年龄差拉扯转化为追妻线的安全感名场面。
- **现言甜宠** → fusion/recipes/sweet-abusive.md：甜宠基调放大大叔的爹系宠爱与兜底感，女主闯祸男主不指责只解决，反差萌与成熟魅力的暖感双增。

### 对冲型
- **虐恋**：大叔的情绪内核偏正向安全感，与虐恋的负向拉扯构成对冲——叠加时需把握"虐而不伤包容感"的配比，让阻碍来自外界（年龄非议、父母反对）而非男主油腻爹味，对冲得当则张力更足。

### 裂变型
- 无（大叔作为人设表现形式型标签，其核心机制"成熟年龄差恋爱"不被其他标签根本改变；情感基调由甜宠/虐恋主线主导）

### 互斥标签
- 校园背景、少年男主——与年龄差及成熟人设内核冲突，已列入强互斥。其余大多数标签可兼容。
