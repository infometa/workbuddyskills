## 二、变体素材库（仅参考·可自由组合·可原创·可豁免）
> 本节全部为灵感启发，**不强制命中、不作评分依据**，可自由组合/原创/豁免。

### 1. 节奏适配逻辑
常见节奏：奇幻设定立底 → 宿命相遇 → 因设定生情与阻隔 → 突破宿命相守，奇幻与情感交织。付费节点可落在宿命标记、设定带来的情感危机、突破阻隔等处——仅为参考位置，不强制。

### 2. 核心变体素材（任选，不限数量）
#### 宿命爱情爽点变体
1. 命定羁绊型：因奇幻设定注定相系的宿命之恋
2. 标记结合型：狼人/吸血鬼式标记带来的强绑定
3. 异种相恋型：跨越种族/位面的禁忌之爱
4. 守护契约型：因契约或誓言绑定的深情

#### 冲突模式变体
1. 设定阻隔型：奇幻规则成为爱情的阻力
2. 身份对立型：因种族/阵营对立的爱恨
3. 代价考验型：相守需付出奇幻设定的代价
4. 宿命抗争型：与命运安排的对抗与突破

#### 人设风格变体
1. 强势宿命型：因命定而强烈占有与守护
2. 隐忍克制型：因身份阻隔压抑深情
3. 双向救赎型：彼此因爱治愈奇幻设定的伤痛

#### 付费卡点变体
1. 宿命标记节点：命定绑定的强冲击
2. 情感危机节点：设定引发的情感考验
3. 突破宿命节点：跨越阻隔相守的释放

### 3. 钩子参考模板
- 开篇钩子参考：从宿命设定或命定相遇切入，建立奇幻浪漫预期
- 集末钩子参考（仅启发）：
  1. 宿命式：从被标记那一刻起，他们的命运再难分开
  2. 禁忌式：明知不该，却还是无可救药地沦陷
  3. 抗争式：为了相守，他们要对抗整个命运

## 五、红线与反模式
> 红线severity：弱

### 1. 避坑提示（不挂质检号、不扣分，仅创作提醒）
1. 避免奇幻与爱情两张皮，设定与情感各走各的。
2. 避免奇幻设定无代价，能力宿命毫无约束与张力。
3. 避免宿命感薄弱，命定感不足沦为普通言情。
4. 避免情感线薄弱，全程讲设定而忽略爱情主线。

> 说明：奇幻爱情即使不守这些点，通常只是"不够好"而非"剧情崩塌"，故定为弱红线、不挂全局质检号。设定不自洽若达崩级，由 anti-patterns.md #7 世界观硬伤兜底。

## 七、融梗亲和性（v5.3 新增）

### 增强型
- **虐恋** → fusion/recipes/sweet-abusive.md：奇幻设定的阻隔（种族对立、宿命代价）为虐恋提供天然且不可抗的痛源，命中注定却难相守的撕裂感让虐与甜的落差更极致。
- **破镜重圆** → fusion/recipes/chase-wife-sweet.md：宿命标记让分离后的彼此始终命脉相连，追悔重逢叠加奇幻牵引，虐后相守的释放更具宿命浪漫。

### 对冲型
- 虐恋 × 甜宠：奇幻爱情内核同时含"虐与甜"，叠加时需把控配比——宿命阻隔带来的虐感与突破相守的甜感互为张力，过虐则失浪漫、过甜则失宿命重量，二者需交替释放而非同时拉满。

- 无（奇幻爱情作为情感主题标签，其核心机制"奇幻设定服务宿命爱情主线"不被其他标签根本改变，设定标签叠加时仍以情感为主线）
