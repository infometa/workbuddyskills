# 主题标签：系统
> 官方标签映射：主题 · 系统
> 定位属性：level-2 弱红线 · 任务驱动的规则框架，为故事提供节奏骨架与即时爽感
> 核心情绪：任务驱动、规则约束、升级爽感、即时反馈

> 映射说明：系统无对应预置combo，走通用规则组装。系统作为"节奏驱动型"标签，其核心功能是为其他标签提供清晰的升级路径和任务节奏框架，是天然的辅轴选择。

## 二、变体素材库（仅参考·可自由组合·可原创·可豁免）
> 本节全部为灵感启发，**不强制命中、不作评分依据**，可自由组合/原创/豁免。

### 1. 节奏适配逻辑
常见节奏：系统激活 → 新手任务/入门 → 任务升级/难度递增 → 规则碰撞/代价显现 → 终极任务/系统真相。系统的核心功能是"节奏驱动"——每个任务就是一个付费卡点，每次升级就是一个爽感节点。系统为故事提供天然的"起承转合"框架。付费节点可落在任务完成/升级、规则反转、系统代价揭晓等处——仅为参考。

### 2. 核心变体素材（任选，不限数量）

#### 情绪内核
系统的情绪引擎：任务驱动（有明确目标不迷茫）、规则约束（有边界才有策略空间）、升级爽感（数值提升的即时满足）、即时反馈（做完任务立刻看到结果）。核心爽感来自"努力即有回报"的确定性和"升级变强"的成长感——这是现实中最稀缺的体验。

#### 高频套路提示（非禁用需翻转）
1. 无脑升级型：系统任务只管升级不管代价 → 需翻转：必须有任务代价/规则限制，否则升级无张力
2. 全能系统型：系统什么都能做无任何局限 → 需翻转：系统必须有功能边界和故障可能，否则无困境
3. 系统保姆型：系统替主角做所有决策 → 需翻转：主角必须有自主选择空间，否则只是系统傀儡
4. 规则透明型：系统规则全部已知无悬念 → 需翻转：必须有隐藏规则/规则变体，制造惊喜和反转

#### Top3 对照关键节点
1. 《全职高手》——升级系统天花板：任务→升级→装备的即时反馈循环，爽感密度极高
2. 《我的治愈系游戏》——恐怖系统型：系统任务在恐怖场景中完成，任务奖励与风险对等
3. 《全球高武》——全民系统型：所有人都有系统但主角的系统独特，竞争型系统

#### 创作思考步骤
1. 先设计"系统规则"——任务机制、升级路径、奖励/惩罚、功能边界，开局必须交代清楚
2. 再设计"系统代价"——每个任务/升级有什么代价？代价递增制造张力
3. 然后设计"系统边界"——系统不能做什么？边界之外是主角的自主空间
4. 最后设计"系统与人的关系"——系统是工具/伙伴/敌人/谜题？关系决定故事走向

#### 系统类型变体
1. 升级型：打怪/做任务升级，数值成长爽感
2. 攻略型：攻略目标人物，恋爱/社交任务
3. 经营型：经营产业/资源，建设成就感
4. 生存型：系统发布生存挑战，淘汰压力
5. 辅助型：系统提供信息/技能辅助，不主导决策

#### 任务机制变体
1. 每日任务型：日常任务驱动节奏，稳定输出爽感
2. 紧急任务型：突发事件触发，紧张刺激
3. 链式任务型：一系列关联任务，剧情连续性
4. 选择任务型：多选一，选择影响后续走向
5. 惩罚任务型：不做任务有惩罚，被迫行动的张力

#### 付费卡点变体
1. 升级突破节点：数值/能力的质变提升
2. 规则反转节点：隐藏规则/系统变异的揭露
3. 代价兑现节点：任务代价的集中爆发

### 3. 钩子参考模板
- 开篇钩子参考：系统首次激活——规则初现、第一个任务发布、奖励的诱惑
- 集末钩子参考（仅启发）：
  1. 任务式：下一个任务的难度，超出他所有预期
  2. 规则式：他发现系统有一条隐藏规则，而他刚刚触犯了它
  3. 代价式：升级的代价，是他最不想失去的东西

## 三、人设加成参考
1. 主角：系统持有者，需要在系统规则框架内展现主观能动性——利用规则、突破限制、发现系统漏洞。不能沦为系统的执行傀儡。
2. 系统人格（可选）：系统可以有人格特征（冷漠/活泼/毒舌/傲娇），增加互动趣味。
3. 对立方：同样拥有系统或了解系统规则的对手，系统规则内的竞争比纯武力对抗更有策略性。

## 五、红线与反模式
> 红线severity：弱

### 1. 避坑提示（不挂质检号、不扣分，仅创作提醒）
1. 避免规则自相矛盾：系统规则开局设定后中途随意增删，前后矛盾导致逻辑崩塌。
2. 避免升级无代价：系统任务完成和升级过于轻松，无风险无代价，爽感贬值。
3. 避免主角变傀儡：主角完全被系统牵着走，无自主决策和主观能动性。
4. 避免系统全能化：系统功能无限扩展无所不能，失去功能边界和策略空间。
5. 避免任务与剧情脱节：系统任务与主线剧情/角色情感无关，变成纯数值游戏。

> 弱红线标签不挂全局质检号；上述风险若上升为崩级问题（如世界观硬伤），由 anti-patterns.md 通用反模式兜底检测扣分。

## 七、融梗亲和性（v5.3 新增）

### 增强型
- **逆袭** → fusion/recipes/system-counterattack.md：系统任务为逆袭提供节奏框架+即时反馈，升级爽感倍增。系统让逆袭的"从低到高"有了可视化的数值进度和阶段性目标。
- **种田** → fusion/recipes/farming-time-travel-system.md：系统任务让种田经营有清晰升级路径。种田的"白手起家"有了系统任务的可量化进度。

### 对冲型
- 无（系统的情绪内核偏正向任务驱动，不与其他标签产生情绪对冲）

### 裂变型
- **穿越** → fusion/recipes/time-travel-system.md：现代灵魂+系统任务在异世界，任务变更驱动命运改写。穿越提供世界观载体，系统提供节奏框架，产生"异世界任务流"新特性。
- **甜宠** → 恋爱变成任务——攻略目标但真心爱上就失去系统。系统的规则约束改变了甜恋的玩法，产生"真心 vs 任务"的新困境。

### 互斥标签
- 无绝对互斥标签。系统作为节奏驱动型标签，与大多数标签可兼容。
