## 二、变体素材库（仅参考·可自由组合·可原创·可豁免）
> 本节全部为灵感启发，**不强制命中、不作评分依据**，可自由组合/原创/豁免。

### 1. 节奏适配逻辑
常见节奏：被当替身 → 隐忍受虐 → 觉醒离场 → 追悔挽回。付费节点可落在替身真相揭破、女主清醒离开、男主追悔、白月光对照崩塌等处——仅为参考。
> 注：白月光作为本标签的对照变体并入说明——她是替身关系的参照系，其形象塑造直接决定替身虐恋的张力。

### 2. 核心变体素材（任选，不限数量）
#### 虐恋爽点变体
1. 错位深情型：男主把对白月光的情投射到替身身上，求而不得
2. 真心错付型：女主以为被爱，实为他人影子，发现真相心碎
3. 反向救赎型：相处中男主真正爱上"她本人"而非影子
4. 觉醒反杀型：女主认清替身处境后清醒抽身，不再卑微

#### 冲突模式变体
1. 真相揭破型：女主发现自己只是替身，信念崩塌
2. 白月光归来型：本尊回归，替身处境尴尬，激化矛盾
3. 比较折磨型：男主有意无意拿女主与白月光比较，造成伤害
4. 身份反转型：女主另有身份/价值，不再仰人鼻息

#### 人设风格变体
1. 清醒觉醒型：识破真相后果断离场，掌握主动
2. 隐忍渐醒型：从卑微忍受到逐渐清醒反抗
3. 反差白月光型：白月光并非完美，打破滤镜（对照变体）
4. 双向救赎型：男主真心悔悟，女主有底线地回应

#### 付费卡点变体
1. 揭破节点：替身真相被揭开，女主心碎觉醒
2. 离场节点：女主清醒抽身、不再卑微的高光
3. 追悔节点：男主认清真心后卑微追悔

### 3. 钩子参考模板
- 开篇钩子参考：女主察觉自己处处像另一个人的影子，埋下替身真相、觉醒反转的预期
- 集末钩子参考（仅启发）：
  1. 揭破式：原来从头到尾，他爱的从来都不是她
  2. 觉醒式：她终于明白，自己不该活成别人的替代品
  3. 追悔式：等他真正看清自己的心，她已经转身离开

## 三、人设加成参考
1. 女主：被当作替身却有底线与自我，觉醒后不卑微隐忍；成长是核心弧光。
2. 男主：错位投射深情，须有真悔悟与转变，不能纯渣到底。
3. 白月光（对照变体）：替身关系的参照系，不脸谱化、与替身有本质区别，塑造立体方能撑起虐恋张力。

## 四、标签规则体系
### 1. 强互斥（不可叠加）
女主全程无底线隐忍设定、男主纯渣无悔悟设定——与"觉醒+救赎"内核冲突。
### 2. 兼容增强（推荐叠加）
虐恋、追妻火葬场、破镜重圆、马甲、大女主（觉醒线）、豪门恩怨。
### 3. 优先级排序
- 虐恋（情感主线）> 替身（替身为关系设定，虐恋节奏与救赎内核优先）。
- 大女主觉醒线叠加时，强化女主主动抽身，弱化卑微隐忍。

## 五、红线与反模式
> 红线severity：弱

### 1. 避坑提示（不挂质检号、不扣分，仅创作提醒）
1. 避免女主无底线隐忍、心甘情愿当替身，价值观跑偏、爽感全无。
2. 避免男主纯渣无悔悟，从头虐到尾不转变，情感无落点。
3. 避免白月光脸谱化，沦为单薄工具人，撑不起对照与虐恋张力。
4. 避免替身与白月光完全一样，毫无区分，替身设定失去意义。

> 弱红线标签不挂全局质检号；上述风险若上升为崩级问题（如价值观红线、性格漂移），由 anti-patterns.md 通用反模式兜底检测。
