## 二、变体素材库（仅参考·可自由组合·可原创·可豁免）
> 本节全部为灵感启发，**不强制命中、不作评分依据**，可自由组合/原创/豁免。

### 1. 节奏适配逻辑
常见节奏：童年羁绊 → 分别成长 → 久别重逢 → 宿命相守。付费节点可落在重逢相认、信物呼应、暗恋揭晓、宿命双向等处——仅为参考。

### 2. 核心变体素材（任选，不限数量）
#### 宿命爽点变体
1. 信物呼应型：童年信物多年后成为相认与心动的钥匙
2. 暗恋成真型：藏了多年的喜欢终于双向奔赴
3. 守护承诺型：童年许下的约定，成年兑现的浪漫
4. 命运纠缠型：兜兜转转，无论如何都会重逢相守

#### 冲突模式变体
1. 重逢不识型：多年后相遇却没认出，制造误会与拉扯
2. 身份落差型：成长后境遇悬殊，跨越差距重续前缘
3. 情敌横插型：第三人介入，反衬青梅竹马的羁绊深厚
4. 误会分别型：当年因误会分开，重逢后解开心结

#### 人设风格变体
1. 双向暗恋型：彼此心动却都没说破，甜中带糖
2. 守护型竹马：从小护着对方，长大继续宠
3. 重逢反差型：童年与成年判若两人，认出后惊喜
4. 宿命牵绊型：命中注定式的相互吸引

#### 付费卡点变体
1. 重逢节点：多年后久别重逢，宿命感拉满
2. 相认节点：认出彼此/信物呼应的心动时刻
3. 揭晓节点：藏了多年的双向暗恋被点破

### 3. 钩子参考模板
- 开篇钩子参考：童年那段刻骨的羁绊埋下伏笔，多年后重逢，埋下宿命相守的预期
- 集末钩子参考（仅启发）：
  1. 重逢式：兜兜转转这么多年，原来命运早就写好了答案
  2. 相认式：他手里那枚旧信物，她一眼就认了出来
  3. 暗恋式：原来喜欢这件事，他们都藏了整整十年

## 三、人设加成参考
1. 男女主：童年有扎实共同记忆，羁绊与信物贯穿全程；成年后性格与童年有呼应、不割裂。
2. 信物/约定：串联童年与当下的情感纽带，须有实际作用而非摆设。
3. 对照组：横插的情敌、不知情的旁人，反衬青梅竹马的宿命羁绊。
> 仅为方向参考，具体设定可自由发挥。

## 五、红线与反模式
> 红线severity：弱

### 1. 避坑提示（不挂质检号、不扣分，仅创作提醒）
1. 避免童年羁绊薄弱，仅靠一句"小时候认识"敷衍，宿命感立不住。
2. 避免相认过早或过晚，时机失衡导致拉扯不足或铺垫拖沓。
3. 避免成年性格与童年严重割裂，人设前后断裂，缺乏呼应。
4. 避免信物/约定形同虚设，立了flag却无实际作用，浪费伏笔。

> 弱红线标签不挂全局质检号；上述风险若上升为崩级问题（如人设漂移），由 anti-patterns.md 通用反模式（#8 性格漂移等）兜底检测。
