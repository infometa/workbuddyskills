## 二、变体素材库（仅参考·可自由组合·可原创·可豁免）
> 本节全部为灵感启发，**不强制命中、不作评分依据**，可自由组合/原创/豁免。

### 1. 节奏适配逻辑
常见节奏：悬案登场 → 线索铺陈 → 抽丝剥茧 → 真相反转。每集留钩子、埋线索，反转要有伏笔支撑。付费节点可落在关键线索揭露、嫌疑反转、真凶揭晓、惊天反转等处——仅为参考。

### 2. 核心变体素材（任选，不限数量）
#### 解谜爽点变体
1. 抽丝剥茧型：从细微线索逐步逼近真相
2. 反转打脸型：看似铁证的嫌疑人被翻盘
3. 隐藏真凶型：最不起眼者竟是幕后黑手
4. 双线交汇型：两条看似无关的线索最终交汇

#### 冲突模式变体
1. 时限追凶型：限时破案，争分夺秒
2. 罗生门型：多方证词矛盾，真相扑朔迷离
3. 连环案件型：案件接连发生，凶手步步紧逼
4. 内鬼博弈型：身边人有内鬼，信任危机

#### 人设风格变体
1. 冷静推理型：观察入微、逻辑缜密
2. 直觉敏锐型：靠直觉与经验破局
3. 双雄搭档型：理性与感性互补的搭档

#### 付费卡点变体
1. 关键线索揭露节点
2. 嫌疑反转节点
3. 真凶揭晓节点

### 3. 钩子参考模板
- 开篇钩子参考：一桩离奇案件突然发生，主角被卷入抽丝剥茧的追查
- 集末钩子参考（仅启发）：
  1. 反转式：他一直怀疑的人，其实是清白的
  2. 线索式：那个被忽略的细节，藏着真相
  3. 危机式：凶手，就在他们身边

## 五、红线与反模式
> 红线severity：弱

### 1. 避坑提示（不挂质检号、不扣分，仅创作提醒）
1. 避免推理降智：逻辑漏洞百出，破案全靠巧合而非推演。
2. 避免真凶过于明显、毫无反转，悬念失去张力。
3. 避免伏笔不回收、线索矛盾，前后设定自相打架。
4. 避免主角上帝视角，跳过推理过程直接得出真相。

> 弱红线标签不挂全局质检号；上述风险若上升为崩级问题（如逻辑硬伤），由 anti-patterns.md 通用反模式兜底检测扣分。
