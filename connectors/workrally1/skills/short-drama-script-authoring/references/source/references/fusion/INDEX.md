## 一、配方使用规则

| 场景 | 操作方式 |
|---|---|
| 配方命中 | **可选** Read 配方文件做参考——了解市面成熟写法和招牌桥段 |
| 配方未命中 | 直接走 `_METHODOLOGY.md` 融梗三问 |
| 命中后推导方向 | **禁止**直接使用配方的 3 个方向；推导方向必须与配方方向在身份/冲突/爽点至少 2 维有本质差异 |
| 强模型/创新导向 | 跳过配方，直接走融梗三问自行推导 |
| 弱模型/稳健导向 | 先 Read 配方获取起跳参照，在配方基础上做迭代（翻转/碰撞/视角切换） |

> **配方是"素材库"不是"菜单"**——告诉你市面上有什么鱼，不是替你决定钓什么鱼。

- 配方文件命名规则：`<标签A>-<标签B>[-<标签C>].md`，按标签权重排序（高权重在前）
