# 公共提示词规则

仅在启动菜单已确认后，与唯一所选分支一起读取。此处存共性流程与唯一质感词库，不定义默认风格。

## 1. 七模块结构（1/3/4号分支）

**风格 — 相机/胶片模拟或渲染方式 — 打光 + 色彩 + 构图 + 视觉参考 + 主体/场景/氛围 — 兼容质感尾缀。**

将具体人物、道具或场景写进结构，而不是只给风格标签。用户已有信息直接沿用；不改变已确定身份与叙事事实。具名作品和创作者是美学参考，不复制具体人物身份；参考名旁同时写可观察的视觉特征。

相机、胶片、渲染器词作为生成提示词中的模拟目标，不声称真实采集或执行了该设备。单张图中的“手持”“长镜头”只表达观察视角与定帧构图，不替代视频运镜脚本。

## 2. 统一质感词库（源文完整保留）

```text
soft focus edges, gentle edge falloff, film-like softness, halation on highlights, photochemical softness, analog edge bloom, no digital sharpening, restrained detail, minimalist texture, large color blocks, negative space, graphic simplicity, hierarchy of focus, single focal point, unified material, smooth surfaces, clean rendering, matte finish, cohesive texture language, subdued micro-detail
```

### 使用优先级

1. 将此串视为可复用质感词库，**不是所有分支均无条件拼接的强制串**。这是对原稿公共柔化词与各分支细节要求冲突的显式合并裁决。
2. 先保用户主体事实与选定分支的材质/信息锚点，再表达共同的注意力层次、光学柔和与克制锐化。
3. 每份最终提示词仅追加一组兼容尾缀，不同时输出一串又复制相同词。
4. 表述尽量肯定且具体，例如“光学柔和边缘，主体结构清楚，材质纹理可辨”。分支2的固定英文画质尾缀例外：必须逐字保留。

| 分支 | 保留的共性 | 削弱或移除的冲突词及适用范围 |
| --- | --- | --- |
| 1 硬科幻 | 胶片柔和边缘、高光晕染、克制数字锐化、单一视觉焦点 | 不用smooth surfaces/unified material抹掉航天器的多材质和真实接缝；不以minimalist texture删掉功能硬件 |
| 2 废土3D | 主体分离、层次统一、无过度锐化、外围柔化 | 不把matte finish强加金属，不以subdued micro-detail消灭锈蚀、划痕和PBR粗糙度；主体清晰优先 |
| 3 电影写实 | 胶片高光溢出、细腻颗粒、柔和边缘、自然焦点 | 不以smooth surfaces磨皮，不以clean rendering暗示CG，不把肤质统一成塑料 |
| 4 2D动画 | 光学光晕、通透色块、清晰主体、层次组织 | 极简/大色块可用于人物或远景；不得削掉源文要求的精细城市背景与云层 |

## 3. 输入与一致性

- 必需：主体/任务类型。可选：外貌或物件形制、服装装备、动作表情、环境、光线、机位、构图、比例、参考图、用途。
- 同一个角色复用身份事实；未经用户明确要求不改变脸型、比例、发色、肤色、标志性服装与装备。
- 只把与当前任务有关的字段暴露给用户。物品、场景不生成不存在的“肤色”“眼瞳”。
- 批次保持同一分支；每张只改用户允许变化的内容。更换风格须回到启动菜单。
- 缺模型名称时提供通用语义提示词；不随意附加模型专属参数或假定支持时长/像素数。

## 4. 质量与交付

先检查可见事实、光源逻辑、渲染媒介、角色一致性与中英语义，再交付。避免只有“高级”“史诗”等抽象评价而没有形体、空间、光线和材质描述。

默认以两个独立代码块给中英提示词；用户只要短版时可以缩短解释，但不跳过启动选择。明确请求文字提示词时不得自动生图。
