# 资产四风格选择器 · V01 / v1.0.0

## 1. 核心定位与边界

将四个资产风格技能合并为一个入口：共用提示词工作流，风格规则按需加载。**合并技能，不混合画风。**

- 适用：角色、场景、道具、关键帧的图像提示词；同一资产的多图一致性；已有提示词的定向微调。
- 不适用：剧本创作、视频时间轴、自动批量生成、模型/API参数探测、文件清理。
- 只编写提示词。只有用户另外明确要求实际生成，才交接当前环境可用的生成能力；选择风格本身不代表授权上传参考图或消耗生成额度。
- 本包自包含，无运行时外部依赖。所有相对路径均以本 SKILL.md 所在目录为基准。

## 2. 架构与启动门禁

```text
新任务 / 重新启动 / 切换风格
        ↓
展示四选一菜单 → 等待用户选择（无默认项）
        ↓
锁定 style_id，确认实际风格名称
        ↓
读取 common.md + 唯一选中风格文件
        ↓
补齐主体需求 → 拼接提示词 → 分支质量检查
        ↓
输出中英提示词 → 同任务微调沿用选择
```

### 2.1 每次启动先选择

1. 将新任务的 `style_id` 初始化为空。即使开场提到某种风格，也先展示菜单、请用户确认该项；不得从题材、参考图、长期记忆或上一任务推断默认值。
2. 优先用当前环境的单选问答组件（支持时使用 AskUserQuestion，`multiSelect: false`）；否则直接输出下方文字菜单。组件包含四个选项，不额外手写「其他」项、不预选、不标推荐。
3. 首轮只说明菜单与必要的命名差异，随后等待用户。不得提前读四个分支、产出正式提示词或启动生成。
4. 仅在收到菜单后的明确编号或唯一名称后确认选择；自然语言如「选第二个」也有效。单独的「继续」「随便」、无效编号、多选或含糊反馈不算确认，继续询问。

**固定菜单，编号顺序不可变：**

> 这次使用哪一种资产风格？请选择 1–4：
>
> 1. **硬科幻（纪实写实）** — 真人航天、真实硬件、失重纪实；原目录名含“太空歌剧”，但本分支不含太空歌剧。
> 2. **硬核废土3D** — 灵笼级3D CG、末世机械、NPR面部与PBR服饰装备。
> 3. **电影写实（剧情片质感）** — 自然动机光、真实人物、克制的生活叙事。
> 4. **2D动画（新海诚式）** — 赛璐璐人物、精细城市背景、通透天空；原目录名为“主流国漫”，实际内容偏日系。

### 2.2 单一分支映射

| 选择 | style_id | 唯一风格文件 | 确认别名 |
| --- | --- | --- | --- |
| 1 | hard-scifi | [01-hard-scifi.md](references/01-hard-scifi.md) | 硬科幻、纪实硬科幻、1 |
| 2 | wasteland-3d | [02-wasteland-3d.md](references/02-wasteland-3d.md) | 废土3D、硬核废土、灵笼、2 |
| 3 | cinematic-realism | [03-cinematic-realism.md](references/03-cinematic-realism.md) | 电影写实、剧情片、3 |
| 4 | anime-2d | [04-anime-2d.md](references/04-anime-2d.md) | 2D动画、新海诚、4 |

- 菜单后输入旧目录全名时，明确对应分支的实际内容，再问一次是否确认；不要把「太空歌剧」或「国漫」当成已具备的新增能力。
- 同一任务中「继续」「换姿态」「只改光线」沿用已确认分支，不反复弹菜单。
- 「重新开始」「换个风格」、新资产任务或新会话重新进入菜单；不复用上次默认值。已约定批次中的下一张属于同一任务。
- 切换风格先保留用户主体事实，清除旧分支的渲染、布光、色彩与质感词；确认新选择后再重建。不得把上一分支词串追加到下一分支。
- 请求四种对照时仍先选一项，逐项完成、逐项确认；不一次加载四种。请求混搭时说明本技能为单选模式，不默默融合。
- 需要真正太空歌剧或另一套国漫画风时说明当前包未收录，等待用户决定是否另行扩展；不伪造第五分支。

## 3. 统一执行流程

1. **确认选择**：回复「已选：编号 / 风格名」，在本任务中记录 `style_id` 与 `selection_confirmed=true`。
2. **读取规则**：完整读取 [公共规则](references/common.md) 和映射表中的唯一风格文件。未选分支保持不读取；`sources/` 中的原稿只用于审计，不作为运行时指令。
3. **补齐输入**：沿用用户已有主体、动作、场景、机位、比例、参考图和输出语言。缺主体则只问“这次要做什么角色、场景或道具？”。可选项未指定时采用所选分支默认值，不反复问卷。
4. **区分参考角色**：角色图锁身份、场景图锁空间、风格图锁画风。若参考风格与已选分支冲突，先问以哪一个为准，不擅自覆盖选择。
5. **组装内容**：1/3/4号用七模块结构；2号角色任务使用九层框架。避免强行把废土的CG词套到真人或2D分支。
6. **处理公共尾缀**：依 common.md 选取兼容词，只追加一次；分支特有强制尾缀按分支规则保留。落实细节优先级而非机械堆砌互斥词。
7. **质量门禁**：逐项检查第5节。未通过先修复，不将冲突稿作为成品。
8. **交付或迭代**：按第4节交付；微调每轮只改1–2项，标明改动，其他身份与未修改字段保持不变。

## 4. 输出格式

默认用中文说明，并给中英文两份可复制完整提示词；用户明确仅要一种语言时只出该语言。

```text
已选风格：编号 / 名称
资产对象：主体与任务类型

中文提示词
[已替换所有占位符的完整提示词]

English Prompt
[语义与中文一致的完整提示词]

锁定项：身份、服装、装备、关键材质与风格事实
可调项：本轮允许变化的姿态、表情、场景、打光或机位
规格：已知比例/用途；未知时写“未指定”，不虚构工具参数
```

- 角色多图任务额外提供可重复粘贴的「角色锚点串」。场景、道具任务不强加角色字段。
- 对单轮改稿增加「本轮仅改：…；其余保持不变」。
- 不输出内部 style_id、原始路径、未选分支内容或审计原稿，除非用户询问结构。
- 8K/UE5/ARRI等描述属于画面目标或视觉模拟，不构成实际模型分辨率、真实渲染器或拍摄器材的承诺。

## 5. 必须通过的质量检查

- [ ] 新任务已展示四选一且得到明确确认；不存在默认选择。
- [ ] 只加载 common.md 与一个分支；只输出一种画风。
- [ ] 未把硬科幻扩展成太空歌剧，未把新海诚式2D误称通用国漫。
- [ ] 中文与英文的主体、动作、颜色、光向、机位、材质和约束相同；无未填占位符。
- [ ] 真人分支无UE5/赛璐璐皮肤；2D分支无写实SSS皮肤；废土分支保持3D体积。
- [ ] 公共尾缀只出现一次，不与材质辨识、真实硬件、精细背景相互抵消。
- [ ] 2号角色分支保留九层顺序、角色锚点与不可修改画质尾缀。
- [ ] 迭代仅改指定字段；跨风格切换不残留旧风格约束。
- [ ] 未擅自调用生成服务、上传文件或声称已产出图片。
