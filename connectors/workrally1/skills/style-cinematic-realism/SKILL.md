# 电影写实（剧情片质感） · 固定风格技能

## When to use

用户2026-09-17指定：生成写实风格都使用本技能。涵盖人物、独立道具、无人无道具的纯环境场景和写实视频的风格描述；不是只在用户再次点名时才加载。非写实项目不强套；本次用户明确另指定风格或修改长期规则时，以该次明确要求为准。

完整原件逐字节保存在 [references/source-skill.md](references/source-skill.md)，仅供来源追溯，不是另一套活动规则。原件的英文风格与质感尾缀保留于下方，接入层只处理用户资产规范冲突；不执行原件之外的脚本或网络命令。

## 高优先例外：群演与 layout 风格隔离（2026-09-18）

唯一活动规则见 [workrally-brand-film-pipeline §0D](../workrally-brand-film-pipeline/SKILL.md#0d-高优先规则群演资产与-layout-空间隔离2026-09-18)，冲突时优先于本文通用人物三视图和剧情风格模块，不在本技能复制空间方法。

- 原演员/有台词角色保持单人三视图；**CHAR:crowd、逻辑CROWD-xx** 使用每组单张16:9、count=1的多人同框正面全身群像，头手脚完整、灰底柔光、个体不同，不裁头、不做三视图。人数与身份服装按项目，不默认9人或复制示例警服；不新增剧情环境、动作/表情库，道具仍独立PROP，全部资产去噪后缀不变。
- 视频只接收 §0D 白名单导出的 layout 空间文字，图片形式layout默认不上传；不继承其 `lighting/style/color/material/render` 或情绪媒体。最终风格仍用原独立配置，SC结构位置可用，不把灰模、线框、灰底或群像合影队形带入成片；固定世界坐标、组内四字段与跨组成员连续性均按§0D，不由风格改站位/朝向/明确表演。
- `scope=spatial_only`、`style_influence=none` 仅为本地记录，不是API参数或完全防止图像泄漏的保证。模型与生成授权取当前项目有效确认，不把某次季宝-2选择或暂停状态固定为通用默认；仅规则修订不触发媒体生成，不安装或修改源layout文件，缺机器scene_desc不冒充已取画布。来源与执行边界见§0D-1。
- 空间状态重放、成员按时点拆分/合并、落脚位/通路、朝向及换装绑定统一引用§0D-3；文字/空间/资产/提交就绪分层与旧复制脸指令检查见§0D-6。风格适配不能把这些待核项标为已通过，也不因layout接入改词、改说话人或改当前声音策略。

## 流程与职责

```text
写实请求 → 加载本技能 → 遵循pipeline §0D群演例外（有剧情走位时做空间计划）
                        ├─ 资产图：原始基底 + CHAR（含crowd）/PROP/SC规范
                        │          → 不加颗粒 + 固定英文去噪末句
                        └─ 视频：分镜 + layout空间文字 + 独立风格
                                   → 按分镜组合人物、群演、道具与环境
                                   → Seedance 2.5提示词格式
                                   → 视频默认摄影整句（含轻微颗粒）
两条路径分别交给生成流程；视频不追加资产去噪末句
```

本技能只负责视觉风格，不自动提交生成、不选模型、不选分辨率、不重生成旧媒体。完整制作先把自然语言转为文字分镜并保存展示Markdown，按pipeline §0D完成空间文字计划与组内状态，再选择资产模型、G1视频模型和G2原生视频分辨率，生成后按分镜剪辑成片。人物、独立道具与纯环境场景资产可按用户选择使用贝宝PRO（平台名贝宝-Pro）或季宝的具体版本，允许统一或分类型选择；有多个季宝版本时先澄清，不默认季宝2.5。模型与能力动态核验，风格不得覆盖已确认路由。已有确认只在原作用范围内有效，新增道具类别不能自动继承仅针对人物/场景的选择；道具视图、数量、背景和规格依任务方案确认，不套用人物三视图。此规则替代旧场景固定贝宝PRO的限制；资产拆分以workrally-brand-film-pipeline的CHAR/PROP/SC规范为准。

## 原始风格基底

参考：《海边的曼彻斯特》《白日焰火》、Roger Deakins摄影、Edward Hopper的光影关系。后者只作为光色参考，不转换成油画、插画或CG材质。

| 模块 | 原始设定 |
| --- | --- |
| 风格 | Cinematic photorealistic drama |
| 相机与胶片观感 | ARRI Alexa LF + Kodak Vision3 500T 35mm film, 40mm anamorphic |
| 打光 | soft motivated natural window light, low-key practical fill |
| 色彩 | desaturated teal-amber, refined low-contrast grade |
| 构图 | balanced rule-of-thirds, shallow depth of field, story-driven framing |
| 光影参考 | Roger Deakins, Edward Hopper light |
| 场景氛围 | intimate everyday urban realism, quiet emotional moment |

Alexa LF与胶片名称表达数字摄影搭配胶片色彩模拟的视觉目标，不声称由数字摄影机实际装载胶片。场景/光线/构图模块按原包允许的方式适配任务；时代、空间、天气和叙事情绪来自脚本，不把所有题材强改成现代都市、窗光或忧郁场景。

```text
Cinematic photorealistic drama - ARRI Alexa LF + Kodak Vision3 500T 35mm film, 40mm anamorphic - [soft motivated natural window light, low-key practical fill] + [desaturated teal-amber, refined low-contrast grade] + [balanced rule-of-thirds, shallow depth of field, story-driven framing] + [Roger Deakins, Edward Hopper light] + [intimate everyday urban realism, quiet emotional moment], soft focus edges, gentle edge falloff, film-like softness, halation on highlights, photochemical softness, analog edge bloom, no digital sharpening, restrained detail, minimalist texture, large color blocks, negative space, graphic simplicity, hierarchy of focus, single focal point, unified material, smooth surfaces, clean rendering, matte finish, cohesive texture language, subdued micro-detail
```

### 中文 · 与资产规则兼容的风格表述

```text
电影级写实剧情片质感，ARRI Alexa LF摄影观感与Kodak Vision3 500T胶片色彩模拟，40mm变形镜头观感，低饱和青橙色与克制低对比调色，真实且有来源的柔和光线，沉稳的叙事构图，胶片般柔和边缘与轻微高光晕染，不作数字锐化，微细节克制，材质统一、真实，视觉层次清楚，保留关键轮廓和几何结构。
```

原件中文中的“细腻颗粒”与当前资产去噪规则冲突，活动资产提示词不沿用；“4K超清”不作为实际输出尺寸或分辨率授权。视频按下节用户新指定的默认摄影常量启用轻微胶片颗粒；资产与视频分别适配，原始风格原件保持不变。

### 视频默认摄影常量（2026-09-17，视频专用）

视频提示词使用Seedance 2.5格式，按生成单元组织参考绑定、整体叙事、局部时间轴镜头、声音、一致性约束及默认摄影；具体结构见workrally-brand-film-pipeline §4a。这是用户工作流格式，不冒充官方唯一语法，也不等于选择生成渠道或绕过G1/G2。

每条独立视频提示词默认原样追加以下整句一次，保留大小写、措辞和标点；原文是活动常量的唯一来源，引用它的流程不另改写一套：

```text
电影质感，arri 65拍摄，24fps，180度快门，轻微胶片颗粒，黑位保留层次，肤色自然低饱和，自然光照。
```

适配与优先级：
- 此句是当前视频默认，高于旧基底中冲突的Alexa LF及视频不加颗粒表述；生成视频prompt时替换冲突模块，不同时声称两套主相机。arri 65不改写成65mm焦距，不擅自补成某具体型号；原始基底仅保留来源追溯。
- 轻微胶片颗粒仅用于视频。人物CHAR、道具PROP、纯环境SC图片仍按资产规范去掉颗粒要求，末尾保留固定英文去噪两句，不加入这条视频常量。
- 自然光照按故事时间、天气、空间落实为自然可信的照明；不把夜景改为白昼或取消脚本必要的霓虹、路灯、车灯等画内光源。肤色低饱和不自动将环境变为单色。
- 24fps与180度快门作为生成运动观感目标，不证明实际摄影或物理曝光；不凭提示词宣称输出已是24fps。接口参数按真实能力和本次授权设置，输出帧率仍需实测，不自动变速、补帧或编造快门API字段。
- 后续用户明确指定不同视频风格时按当次覆盖，不重复叠加冲突默认。只更新规则时不重生成或后期添加颗粒到已有成片。


### 原始统一质感尾缀

```text
soft focus edges, gentle edge falloff, film-like softness, halation on highlights, photochemical softness, analog edge bloom, no digital sharpening, restrained detail, minimalist texture, large color blocks, negative space, graphic simplicity, hierarchy of focus, single focal point, unified material, smooth surfaces, clean rendering, matte finish, cohesive texture language, subdued micro-detail
```

英文整段已内置质感尾缀，不能重复叠加；单独拼装模块时再加入。人物三视图需覆盖single focal point、浅景深和三分构图等冲突项，三视图区都必须清楚，不能只保留一个视图清晰。柔焦仅用于非关键边缘，不能糊掉脸部、衣物边界或场景结构。

## Steps

1. 确认任务属于写实并加载本技能；提取主体、时代、环境、画幅和既定生成配置。记录style_skill=style-cinematic-realism及本次版本。
2. 将原始风格作为基底，按资产职责替换可变模块，而不是叠加互相矛盾的整段模板：
   - **演员/有台词角色资产（CHAR非crowd）**：每角色直接生成一张16:9横图、count=1；左正面全身取景裁头（肩部以下和双手双脚完整）、中背面全身含头、右3/4侧脸特写；同人同服装。纯中性灰背景、柔和均匀光，无强阴影或高光。不采用窗光、低调戏剧补光、青橙染色灰底、单焦点或浅景深糊掉其他视图，不增加表情图、身份锚点图或剧情画面。保留写实材质、克制细节、柔和边缘，身份轮廓必须清晰。
   - **群演（CHAR:crowd）**：按上方优先例外及pipeline §0D-4使用单张多人正面全身群像；覆盖单焦点、浅景深等会糊掉其他个体的基底模块，所有个体和关键轮廓清楚，不套上一条裁头三视图。
   - **独立道具（PROP）**：按分镜提取汽车、手机、包等需要复用与保持一致的物件，只呈现物件本体；不带人物、手部或剧情场景。使用确认的隔离背景与清晰布光，保留真实比例、结构、材质和颜色，不以剧情染色或浅景深遮蔽关键部件；背景、视图和数量按任务确认，不强制人物三栏模板。汽车座舱是同一车辆道具的内饰视图，不归场景；内外饰共享主体标识，不能变成不同车型。道具与环境分离不等于使用透明背景，也不保证像素级无损抠图。项目禁止logo/文字时须在道具资产层验收。
   - **纯环境场景（SC）**：使用用户已选的贝宝PRO或季宝具体版本，按该模型当前能力核验参数，不因风格覆盖选择；只承载空间、天气、时间、材质与环境光，保留适配后的青橙低对比和剧情片质感。无人、无人体局部、剪影或人物倒影；不含汽车等道具及其局部、倒影、投影或残留。保留必要建筑、道路、桥梁、墙地面等固定空间设施；无道具不等于无建筑。不套人物灰底，不为“情绪瞬间”添加人物或道具。
   - **写实视频**：使用Seedance 2.5提示词格式，先依“视频默认摄影常量”替换旧基底中冲突的相机/颗粒描述，再结合兼容的风格模块与已确认脚本、动作、运镜、空间和声音。每条视频提示词原样追加默认摄影常量一次；按镜头需求组合人物、道具与环境输入。layout只用pipeline §0D白名单空间文字，不参与本条风格配置。不得把人物资产的三栏排版、群像合影队形、layout灰模/线框/灰底、资产隔离背景或场景资产的无人无道具限制带入成片。图片去噪后缀不自动加入视频。
3. 资产图片提示词按“主体内容 + 适配后的风格/质感 + 类别规范 + 固定去噪后缀”组合。末尾原样追加一次以下两句，不翻译、不改写、不再追加其他内容。已含后缀的角色模板只保留一份。

```text
Remove the noise and high-frequency details from the image. Keep all the lines, colors, and brightness unchanged.
```

4. 优化提示词后复查三类资产的原文后缀、演员三视图与群演群像例外、道具隔离及主体一致性、场景无人无道具与各类模型配置；视频按pipeline §0D复查layout白名单及风格隔离，再交给现有生成流程。风格技能不是模型：不能因原包提及其他平台而改渠道，也不能把“4K”当作G2确认。
5. 生成后核验关键轮廓、身份、材质和色彩。提示词只是目标，不能据此保证去噪、像素不变、人物一致性或实际分辨率。规则更新不授权重生成旧图、重写已完成项目记录。

## Pitfalls

- 原包分类“都市/当代现实”不是把所有写实故事改成现代都市的指令；保留剧本事实。
- 剧情构图与资产排版不是同一职责；演员三视图、群演群像例外和灰底柔光高于通用剧情布光。
- 群演不因归CHAR就裁头或复制角色脸；layout图片不因标注spatial_only就不会泄漏风格。只用pipeline §0D的空间导出与验收，不让群像排版或灰模观感代替视频摄影。
- 原包英文与中文并非逐句等价，中文还包含颗粒和4K；资产使用兼容版本，不叠加冲突。
- 质感尾缀不等于最后的固定去噪后缀。资产提示词最后必须是用户指定的英文两句。
- 只改风格，不改用户已确认的资产模型路由（贝宝PRO/季宝具体版本）、视频G1/G2或Seedance-2.5不超过30秒一次请求规则。
