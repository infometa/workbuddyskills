# 公募基金与 ETF

本数据域覆盖当前纯净版目录中的公募基金、基金经理、基金公司、ETF、QDII 和基础设施公募 REITs，包含档案、净值、业绩风险、持仓、资产配置、归因、标签、份额和结构化解读。私募、券商资管及未接入产品不在当前范围内。

## 当前覆盖

| 内容 | 结构化对象与字段 |
| --- | --- |
| 基金与主体 | 基金代码/名称、类型、成立日、状态、管理人、经理任职、基金公司关系 |
| 净值与业绩 | 净值日期、单位/累计净值、收益率、滚动相关性、区间统计、回撤和风险指标 |
| 持仓与配置 | 报告期、证券代码/名称、数量、市值、净值占比、资产类型、行业/主题和跨期变化 |
| 基金经理 | 任职区间、在管产品、经理日频业绩、资产配置、季度暴露和行业变动 |
| ETF 与份额 | ETF 日行情、标签、跟踪指数、份额及滚动变化；以实际返回日期为准 |
| QDII | QDII 持仓、行业持仓和原币种/地区信息 |
| 公募 REITs | 申报/扩募、项目、项目公司财务和收益分配 |
| 结构化标签/解读 | 基金标签、AI 年度解读、券商观点及证券关联；不等于研报或原文 |

## 标的、报告期和份额

| 项目 | 规则 |
| --- | --- |
| 基金代码 | 场外基金通常使用 `.OF`；场内 ETF 使用 `.SH/.SZ`。只给 6 位代码时要求匹配并返回完整代码 |
| 报告期 | 常见为 `03-31`、`06-30`、`09-30`、`12-31`，以实际披露期为准 |
| 季报持仓 | 通常只披露前十大重仓，不得称为完整持仓 |
| 半年报/年报持仓 | 可查询披露的全持仓；仍需说明报告期和披露滞后 |
| QDII | 持仓、交易时区和币种口径可能不同；保留原币种或说明汇率日期 |
| A/C 等份额 | 汇总基金数量或规模时按主基金去重，不能把同一产品不同份额重复相加 |
| 最新报告期 | 以本次 MCP 返回的最新实际披露期为准，不根据当前日期自行推断 |

名称、经理或基金公司有重名时，先通过完整代码、管理人和任职期消歧。

## 基金、经理和公司档案

可尝试查询：

- 基金代码、名称、类型、投资类型、成立日期、管理费、托管费、业绩基准、是否 QDII、运行状态。
- 现任/历任基金经理、任职起止日、任职天数和任职回报。
- 基金与管理公司的关系，以及经理在管产品和规模。
- 最新基金规模和对应日期；场外基金通常来自定期报告，ETF 可使用较高频的份额/规模口径。

规模汇总时：

1. A/C 等份额按主基金去重。
2. “非货基金”剔除货币基金；如用户要求排除 ETF 联接基金，应同时按产品类型和名称识别。
3. 不同日期的规模不可直接相加；保留统一统计日或分别列示。

## 净值、收益与风险

| 查询目标 | 推荐口径 |
| --- | --- |
| 净值展示 | 单位净值或累计净值，并返回净值日期 |
| 区间收益 | 优先使用复权累计净值或服务端预计算收益，不用未复权净值首尾直接计算 |
| 滚动收益和风险 | 使用服务端预计算窗口；返回实际窗口、起止日和有效样本数 |
| 自然年度表现 | 按自然年度收益、最大回撤、波动率、夏普等查询 |
| 同类排名 | 在同类型基金、同一期间内排序，返回名次、样本总数和分位 |
| 相关性 | 明确基金/指数对和滚动窗口，不把短期相关性写成长期稳定关系 |

常用滚动窗口可表达为近 1 月、3 月、6 月、1 年、2 年、3 年、5 年和 10 年；要求服务端返回实际交易日窗口。历史数据不足时，不得把不完整样本当作完整窗口。可要求有效净值点不少于目标窗口交易日数的 80%。

常见指标包括：区间/年化收益率、最大回撤、年化波动率、夏普比率、卡玛比率、索提诺比率、信息比率、月胜率、盈亏比、溃疡指数和 UPI。只有本次返回实际包含的指标才能进入答案。

## 持仓和资产配置

可尝试查询：

- 最新或指定季报的前十大重仓股。
- 半年报/年报的披露全持仓。
- 个股持有数量、市值、净值占比和跨期增减变化。
- 基金持有哪些行业/主题，以及跨期配置变化。
- 某股票被哪些基金持有。
- 股票、债券、现金和其他资产的市值与占比。
- 基金经理或基金公司的合并持仓视角。

必须区分：

- 季报前十大与半年报/年报全持仓。
- 正式披露持仓与模型推断/模拟持仓。
- 单基金持仓与基金经理/公司合并持仓；多经理共管可能重复计入。
- 申万不同级别的行业分类；不同级别不可相加。
- 主题标签可能重复覆盖同一股票，不能直接把标签权重相加到 100%。

持仓披露有滞后，只能表述为“截至某报告期披露的持仓”，不能写成当前实时仓位。

## 调仓信号和风格归因

如服务返回真实净值、模拟净值或行业/赛道暴露，可用于识别潜在调仓信号，但属于统计推断：

- 真实与模拟收益显著偏离，可能意味着披露期后发生调仓。
- 行业或赛道暴露权重连续变化，可用来判断潜在方向。
- QDII 受时区和汇率影响，短期偏离阈值应更宽松。

输出必须使用“可能、推断、信号”等措辞，不得写成已披露调仓事实；同时展示观察窗口、阈值和数据截止日。

## ETF 专项

可尝试查询：

- ETF 日线行情、成交量/额、换手率和资金流。
- 最新份额、规模、份额变化和一段时间资金净流入。
- 资产类型、规模风格、行业/主题、跟踪指数、发行人、是否 QDII/LOF 等标签。
- 跟踪基准和同类 ETF 的规模、费用、流动性及业绩对比。

若服务未返回 IOPV 或折溢价率，不用收盘价自行伪造。跨市场 ETF 还要说明时区、汇率和底层资产交易时间错位。

目录中的美国 ETF 标签只表示可用于基金标签和分类，不代表当前 DA 已开放美股公司主档、行情或财务。

## 典型路由

| 用户问题 | 查询重点 |
| --- | --- |
| 基金基本资料 | 完整代码、类型、成立日、费率、基准、现任经理和最新规模日期 |
| 近 1/3/5 年表现 | 预计算收益风险指标、实际窗口、有效样本数 |
| 最新重仓 | 先取最新实际披露期，再按季报前十大或半年/年报全持仓查询 |
| 哪些基金持有某股票 | 明确报告期、基金样本池和持仓披露范围 |
| 行业/主题配置 | 分类体系、级别、报告期、权重和跨期变化 |
| 是否可能调仓 | 真实/模拟净值偏离与行业/赛道暴露，标记为推断 |
| ETF 市场规模 | 同一统计日汇总规模、份额和数量，完成份额去重 |
| 基金经理比较 | 任职期、管理产品、规模、业绩窗口和重复管理口径 |

```text
查询易方达蓝筹精选的完整基金代码、类型、成立日期、管理费率、现任基金经理和最新规模；A/C 份额按主基金去重，注明规模日期和报告期。
```

```text
查询基金 720001.OF 最近 3 年的滚动收益率、年化收益率、最大回撤、年化波动率、夏普、卡玛、溃疡指数和 UPI；返回实际窗口、数据截止日和有效净值点数量。
```

```text
查询基金 720001.OF 最新一期季报前十大重仓股，返回实际报告期、股票代码、简称、持有市值和净值占比，按净值占比降序。
```

```text
统计最近可得统一日期的全市场 ETF 总规模、总份额和 ETF 数量，按主基金口径去重，并返回统计日。
```

## 校验边界

- 不同基金类型不可直接混排排名；跨基金比较先对齐类型、基准、期间和币种。
- 成立时间短于目标窗口的基金不能当作完整长期样本。
- 季报前十大不能代表完整持仓；持仓披露不能代表当前实时仓位。
- 模拟持仓、回归暴露和调仓信号是推断，不是披露事实。
- 缺失指标不得填 0；没有 IOPV/折溢价率时明确数据缺口。
- ETF 日行情、净值和份额变化必须保留各自日期；不得称为盘中实时数据。
- REITs 项目公司财务与基金净值、份额和二级市场行情分开查询。
- 基金 AI 解读、券商观点和公告元数据是结构化摘要或线索，不等于原文。
- 基金报告原文或经理“小作文”不是结构化数据，应使用当前已开放的文档/召回能力；不要通过本工具索要原文。
