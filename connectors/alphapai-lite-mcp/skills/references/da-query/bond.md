# 固收与债券

本数据域用于当前纯净版目录中的债券基础资料、二级日行情、收益率曲线、主体/债项评级、发债主体信用、信用风险事件、发债人财务、现金流、公告元数据、特殊条款和可转债结构化查询。

## 当前覆盖与公共字段

当前目录覆盖债券基本信息、债券行情、发债主体信用、可转债监控、付息兑付、债券公告元数据、发债企业财务、主体/债项评级和违约风险。

跨表常见身份与时间字段包括债券市场代码、债券名称/简称/类型、发行人代码和名称、交易日、业务截止日、信息发布日期、事件日和生效日。查询时先锁定债券或发行人身份，再区分以下日期角色：

- 交易日：价格、收益率、久期和成交等行情。
- 截止日/观察日：规模、余额、触发进度和风险状态。
- 事件日/生效日：付息、兑付、评级、违约或条款状态变化。
- 信息发布日期：外部可得时间；不能用业务截止日替代。

## 二级定价和信用利差

信用利差常按以下口径计算：

```text
信用利差 = 债券同日到期收益率 - 同期限基准曲线到期收益率
```

问题中应明确：

- 债券代码/名称。
- 估值或交易日期。
- 使用哪一种收益率：到期、行权、赎回或回售。
- 基准曲线。
- 剩余期限与标准期限不一致时的插值或近似方法。
- 输出单位，通常为基点 `bp`。

不能未经说明用最近标准期限替代真实剩余期限，也不能混用净价、全价和应计利息。

## 信用排雷

- 主体评级和债项评级分别查询并分别展示。
- 评级下降需要返回原评级、新评级、机构、日期和评级对象。
- 城投和流动性压力结合平台属性、授信、未使用授信、担保与财务指标判断。
- 已发生违约、展期或逾期使用风险事件数据，并区分未清偿、部分清偿和已展期。
- “未披露”的金额不能按 0 处理。

## 发债人财务

- 已有的风险比率优先直接查询，如现金短债比和 EBITDA 利息保障倍数。
- 用户点名原始科目时再查三大报表。
- 报告期、合并口径、单位和币种必须明确。
- 发债人与上市公司证券不是同一标识时，先定位唯一发行人主体。

## 可转债

- 双低筛选、转股溢价率、剩余规模/期限和强赎/下修/回售临界状态可作为结构化筛选条件。
- “累计触发天数”必须结合具体条款的观察窗口、阈值和当前状态解释。
- 接近触发条件不等于发行人必然行权，不能把条件判断写成确定事件。

## 推荐问题

```text
查询“XX债”最近可得交易日的到期收益率、修正久期和有效凸性，并匹配同日同期限中债国债收益率曲线，按明确插值口径计算信用利差，单位 bp。
```

```text
查询 2026-01-01 以来主体评级或债项评级被下调的信用债，分别标明评级对象、原评级、新评级、评级机构、变动日期和发行人，按日期降序取前 50 条。
```

```text
筛选最近可得交易日双低指标最低的 20 只存续可转债，返回代码、简称、收盘价、转股溢价率、双低、剩余规模、剩余期限、条款临界类型和数据日期。
```

```text
查询某发行人最近 3 个已披露年报的货币资金、短期有息债务、现金短债比、资产负债率、EBITDA 利息保障倍数和经营活动现金流净额，注明单位并按报告期升序。
```

## 校验边界

- 主体评级和债项评级不能互相替代。
- 净价、全价、应计利息和不同收益率不得混用。
- 利差必须匹配同日基准曲线和期限/插值口径。
- 风险事件金额中的“未披露”不得填 0。
- 财务科目、比率、评级和事件都要保留各自日期。
- 最新债券状态、可转债触发进度和余额应在同一债券与事件类型内取最近截止日，不能跨日求和。
- 债券公告标题、分类、日期和关联债券是结构化元数据；公告正文和附件仍使用公告工具。
- 债券指数按指数域查询；单券与发行人按本文件处理。
