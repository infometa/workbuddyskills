# A 股、公司行为与指数

本 Reference 用于通过 `query_financial_data(question)` 查询当前纯净版目录中的 A 股公司、历史日频行情、财务、股东股本、公司行为和指数结构化数据。港股读取 [hong-kong-stock.md](hong-kong-stock.md)；公告及其他原文仍使用专用工具。

## 当前覆盖

A 股相关结构化内容主要包括：

- 公司与证券身份、上市状态、代码变更、行业、概念和经营范围。
- 历史日频行情、最近交易日日终快照、复权因子、技术指标和预计算区间表现。
- 日度估值、市值、股息率、融资融券、北向/南向资金、大宗交易和龙虎榜。
- 合并财务报表、单季利润表、TTM/PIT 财务、综合指标、财务附注、审计与披露状态。
- 股本股东、实际控制人、增减持、质押、限售解禁、回购、分红、股东大会和董监高。
- IPO/增发、重大事项、投资、关联交易、诉讼处罚、风险警示和退市信息。
- A 股一致预期业绩与估值的有限结构化字段；只有当前返回明确包含时才可使用。
- 指数身份、日行情、表现、估值、成分权重、资金流、聚合财务指标，以及部分全球指数日行情。

当前不含个股分钟分时或盘中实时行情。“最新行情”是每只证券自身最近交易日的日终快照，必须展示实际交易日，不能称为实时。

## 行情、表现与估值

当前目录中的常见字段簇包括：

- 身份：证券代码、简称、全称、市场和交易所。
- 日行情：交易日、昨收、开盘、最高、最低、收盘、涨跌额、涨跌幅、成交量、成交额和换手率。
- 日终快照与区间表现：近一周/一月/三月/六月/十二月、本周、本月和年初至今表现，以及实际返回的 Alpha、Beta、波动率和夏普。
- 估值与市值：PE、PB、PS、PCF、股息率、总市值和流通市值；具体静态/TTM/动态口径以返回列名为准。
- 技术指标：日/周/月频 BBI、布林带及实际目录中的其他技术指标。
- 资金与交易公开信息：融资融券、北向/南向资金、大宗交易、龙虎榜和交易所公开信息。

历史行情和财务数据拆分调用。长期收益涉及复权时，问题中写明前复权、后复权或服务实际口径。

## 财务报表和报告期

| 数据类别 | 口径 | 常见指标 |
| --- | --- | --- |
| 资产负债表 | 合并口径为主；时点值 | 货币资金、应收、存货、固定/无形资产、总资产、短期/长期负债、总负债、归母权益 |
| 利润表 | 通常为年初至报告期末累计 | 营业收入、成本、期间费用、营业利润、净利润、归母净利润、扣非净利润 |
| 单季利润表 | 单季度、非累计 | 单季收入、成本、费用和利润 |
| 现金流量表 | 通常为累计 | 经营、投资和筹资活动现金流及净额 |
| TTM/PIT | 滚动或历史时点可得口径 | TTM 财务衍生指标、PIT 报表、历史可得日期 |
| 综合财务指标 | 累计/单季需明确 | ROE、ROA、毛利率、净利率、资产负债率、流动/速动比率、成长和营运指标 |
| 财务附注/经营分析 | 报告期 | 应收、存货、减值、研发、非经常性损益、主营和地区分布等 |
| 金融机构专项 | 银行/证券/保险 | 贷款、资本、内含价值、证券业务及专项报表科目 |

标准报告期常见为 `03-31`、`06-30`、`09-30`、`12-31`。利润表和现金流量表默认累计；需要单季时必须明确写“单季度/单季口径”。

同时保留业务报告期、首次/最新信息发布日期和历史可得日期。历史 as-of 查询优先使用 PIT 或可得日期，不能用报告期假装当时已披露。

## 公司、股本和事件

可查询的结构化对象包括：

- 公司资料、行业概念、子公司、参控股和经营范围。
- 董监高任职、员工、薪酬、持股和变动。
- IPO、增发、定期报告预约和披露更正。
- 总股本、流通股、限售股、股东、实际控制人和一致行动关系。
- 分红送转、增减持、回购、质押、限售解禁和再融资。
- 重大资产交易、对外投资、关联交易、诉讼、处罚、担保、风险警示和停复牌。
- 业绩预告的上下限、类型和公告日期。
- 结构化一致预期业绩与估值；必须返回预测机构/样本、预测期、统计日期和指标口径后才能引用。

一致预期不等于已披露实际值，也不等于确定性“超预期”。用户问超预期时，需要同时取得可比预测口径与实际披露。

## 指数

当前目录覆盖：

- 指数身份：代码、名称、发布机构、基期及实际返回的分类信息。
- 日线行情：开高低收、涨跌、成交量和成交额。
- 行业/概念/商品/债券及部分全球指数日行情。
- 样本和权重：成分证券、报告期或权重日期和权重。
- 估值：PE、PB、PS、PCF、PEG、股息率、风险溢价及市值。
- 聚合财务指标：指数成分的累计或单季盈利、成长、偿债和营运指标。
- 资金流：融资融券、总流入与分档资金流向。

指数行情、样本清单和权重宜分开查询。当前成分权重以报告期/月末等实际权重日期为准，不得当作盘中实时权重。

## 校验边界

- 当前 DA 不提供 A 股分钟分时或盘中实时行情。
- 累计财务不得当成单季值；PIT/可得日期、报告期和披露日不得混用。
- 金额、百分比、估值倍数和指数权重保留单位。
- 一致预期、评级和目标价只有实际结构化返回时可用，并与已披露值分开。
- 公告、研报、新闻和会议纪要原文不属于本数据域。
- 指数成分和权重必须保留样本/权重日期。
