# 宏观经济、外汇与利率

本 Reference 描述当前纯净版目录中的国内、区域、全球和行业宏观指标、外汇汇率、经济日历和美国国债收益率曲线。

## 当前覆盖

| 内容 | 主要结构化字段 |
| --- | --- |
| 国内宏观 | 指标、所属期、数值、单位、币种、发布日期、来源 |
| 区域宏观 | 地区、指标、所属期、数值、单位和发布日期 |
| 全球宏观 | 国家/地区、指标、衍生口径、所属期、数值、单位、币种和发布日期 |
| 行业经济 | 农业、汽车、医药、建材等行业分区指标及其所属期、数值、单位和发布日期 |
| 宏观指标字典 | 指标名称、定义、频率、单位、币种、来源和衍生代码 |
| 经济日历 | 国家/地区、事件或指标、公布时间、实际值、前值、预测值及实际返回状态 |
| 外汇 | 币种对、参考买卖价、结算买卖价、中间价、交易日和通道 |
| 海外利率 | 美国国债期限、收益率和交易日 |

## 时间、单位和修订

宏观数据至少区分：

- `指标所属期`：数据描述的月份、季度或年度。
- `发布日期/公布时间`：市场何时能够获知该数据。
- `交易日`：汇率或收益率曲线的市场日期。
- `事件时间`：经济日历中的预定或实际公布时间。

分析数据发布后的市场反应时，以发布日期或公布时间建立事件窗口，不能用所属期作为事件日。

指标值必须与同行单位和币种一起使用。目录中的宏观指标可能按原值保存，单位字段可能已经包含万、亿、指数点或百分比；不能看到数值后再次猜测倍率。不同衍生代码可能代表原值、同比、环比、累计或季调口径，必须分开。

## 查询路径

### 单一指标时间序列

```text
查询中国 CPI 同比最近 36 个已公布月份的数据，返回指标名称、指标所属期、数值、单位、发布日期和来源，按所属期升序；只保留同一衍生口径。
```

### 经济日历

```text
查询未来两周中国和美国的重要宏观数据日历，返回国家/地区、事件或指标、计划公布时间、报告期及实际可用的前值和预测值，按公布时间升序。
```

### 外汇与利率

```text
查询最近 20 个交易日人民币对美元的官方中间价，以及同日美国 2 年、10 年国债收益率，分别返回交易日、单位和来源；不要把缺失日期向前填充。
```

## 校验边界

- 宏观所属期、发布日期、事件时间和市场交易日不得混用。
- 同名指标先核对地区、频率、单位、币种、季调方式和衍生口径。
- `null`、尚未公布或修订前缺失值不得填 0。
- 经济日历中的预测值不是实际值；前值可能经过修订。
- 美国国债收益率曲线和全球宏观指标不代表已开放美股公司行情或财务。
- 宏观新闻、政策文件和央行讲话原文不属于本结构化域。
