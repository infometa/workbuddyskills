# 港股结构化数据

本 Reference 描述当前纯净版目录中的港股公司、日频行情、财务、股东股本、公司行为、IPO、权证、卖空和有限一致预期数据。港股公告、短新闻或经营述评即使有结构化目录，也不等于已开放原文；阅读原文使用对应专用工具。

## 标的和基本口径

- 港股代码写为 5 位数字 + `.HK`，如腾讯控股 `00700.HK`、美团 `03690.HK`。
- 名称和代码尽量同时提供；A/H 两地上市公司按市场分别查询。
- 多数港股以中报和年报披露为主，不默认存在季报。
- 财务报表分一般企业、银行、证券、保险及简表等口径，并可能同时存在香港会计准则和中国会计准则版本。
- 币种可能是港币、人民币或美元；非自然年公司使用实际财年报告期。

## 当前覆盖

| 内容 | 常见结构化字段 |
| --- | --- |
| 公司与证券身份 | 代码、名称、公司画像、上市状态、代码/联系资料变更、行业 |
| 历史日行情 | 交易日、昨收、开高低收、成交量额、涨跌额/幅、复权因子和区间表现 |
| 财务报表 | 报告期、币种、金融/非金融资产负债表、利润表、现金流量表和简表 |
| 财务指标与附注 | 毛利率、净利率、ROE、ROA、资产负债率、研发、贷款分类、分部资料 |
| 股本股东 | 法定/实收/自由流通股本、主要股东、董事权益、CCASS 持股、限售解禁 |
| 公司行为 | 分红、回购、换股合并分拆、特别提示和其他股本事件 |
| 发行上市与融资 | IPO 审核、招股、基石投资者、公开发售分配、新股重点指标 |
| 交易专项 | 卖空、暗盘、权证、牛熊证和市场参与者资料 |
| 治理与风险 | 高管任职、员工、股东大会、违规、风险个股和违规当事人 |
| 结构化预期 | 业绩预告、盈利预测统计、评级和目标价；仅在实际返回时使用 |

当前不含港股分钟级分时或盘中实时行情。回答“最新价”时只能使用实际返回的最近交易日日频数据，并明确交易日。

## 行情和估值

可查询的日频字段通常包括：

- 昨收、开盘、最高、最低、收盘、成交量、成交额、涨跌额和涨跌幅。
- 复权因子、近 5/20/60 日及其他实际返回的区间表现。
- PE、PB、PS、PCF、PEG、股息率、总市值和流通市值等实际返回字段。
- CCASS 持股、卖空申报/成交和实际返回的市场持仓指标。

日行情、财务、股东持仓和公司行为拆分查询，不能把最近交易日当作财报报告期或披露日。

## 非金融公司财务

| 报表 | 常见指标 |
| --- | --- |
| 利润表 | 营业收入、营业成本、毛利、行政开支、销售费用、经营利润、归属股东净利润、每股基本盈利 |

| 衍生指标 | 毛利率、净利率、ROE、ROA、资产负债率、权益乘数、流动/速动比率和增长率 |

## 金融公司财务

| 报表 | 常见指标 |
| --- | --- |
| 利润表 | 净利息收入、非利息收入、营业支出、拨备、归属股东净利润 |
| 资产负债表 | 客户存款、贷款及垫款、投资证券、总资产、总负债、股东资金 |
| 现金流量表 | 经营/投资/筹资活动现金流和现金余额 |

查询时明确一般企业、银行、证券或保险口径；不确定时先定位公司类型或让服务返回报表类型。

## 一致预期、评级与目标价

当前目录存在港股盈利预测统计、评级和目标价等结构化内容，但不能泛化为完整卖方覆盖。引用时至少保留：

- 证券与公司身份。
- 预测指标和预测期。
- 机构、样本数或统计方法（实际返回其一或多项）。
- 评级/目标价/预测值的日期和币种。

没有机构、预测期或日期时，不把单个数值写成“市场一致预期”；目标价和评级也不等于事实或投资建议。

## 校验边界

- 当前 DA 不提供港股分钟分时或盘中实时行情。
- 港股不存在与 A 股完全相同的“扣非净利润”强制口径，不直接套用。
- 同一公司跨年可能改变披露币种和报表准则，跨期比较前必须核对。
- A/H 报表、股本、交易币种和披露期不同，不能直接混用。
- 评级、目标价和盈利预测必须保留机构/样本、预测期和日期，不写成确定性判断。
- 港交所公告、年报 PDF、新闻和经营述评原文不属于结构化查询结果。
