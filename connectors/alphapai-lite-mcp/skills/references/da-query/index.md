# `query_financial_data` 详细 Reference 索引

本目录描述 Alpha派 Lite MCP 中 `query_financial_data` 的当前业务数据域、查询写法、统计口径和结果校验方法。它是面向自然语言工具调用的业务指南，不是底层数据库、SQL 或 HTTP API 手册。

实际字段、非空率和日期覆盖以本次 MCP 返回为准。Reference 中列出的对象和指标表示当前纯净版授权目录中的结构化范围，不保证每个标的、期间和字段都有值；未在本次结果中出现的字段不得写成确定可用。

## 读取顺序

1. 先读本索引，判断请求是否属于当前结构化范围。
2. 只读取与当前问题相关的一个或多个数据域 Reference。
3. 跨域问题拆成多次 `query_financial_data` 调用，再在答案层对齐日期、币种、单位和统计口径。
4. Reference 与真实 Tool Schema 或当前返回冲突时，以实测为准，并说明覆盖缺口。

## 明确不在当前 DA 范围

- 美股公司主档、行情、估值和财务报表。美股公开会议纪要仍可使用会议工具，研报/路演/新闻线索仍可使用召回或专用工具；这些能力不能反推 DA 已开放美股财务。
- 一级市场公司、融资、投资机构、产品、竞品和组织关系。
- A 股、港股或其他市场的分钟级分时与盘中实时行情。当前“最新行情快照”是各证券最近交易日的日终快照，不能称为实时。
- 私募、券商资管以及未接入的另类产品，除非当前结构化结果明确返回。
- 公告、研报、路演、新闻、公众号文章或会议纪要原文。结构化元数据不替代专用原文工具。

## 能力边界

适合：

- 查询可筛选、排序、聚合和对比的结构化行情、财务、持仓、评级、宏观指标或事件数据。
- 使用自然语言指定对象、时间、指标、口径、单位、排序和返回数量。
- 对 MCP 返回的结构化表格做核验、计算和解释。
- 查询实际返回的 A/H 股一致预期、评级或目标价，并保留机构、预测期、样本与日期。

不适合：

- 请求 SQL、物理表、内部主键、任务 ID、工作区路径或连接配置。
- 把结构化摘要或元数据当作公告、研报、路演、新闻或会议纪要原文。
- 在单次问题中混合跨度很大的数据域或把不同时间角色直接关联。
- 把未返回的卖方观点、目标价、评级或一致预期用模型记忆补齐。

## 通用提问模板

```text
查询{对象名称}（{代码/唯一标识}）{时间范围或最近 N 期已披露数据}的
{指标1、指标2、指标3}，采用{业务口径}，保留{币种/单位}，
按{排序字段}{升序/降序}，最多返回{N}条；同时返回实际数据日期和口径。
```

问题应尽量包含：

- 对象：名称 + 代码/唯一标识；同名主体、合约、基金或指标先消歧。
- 时间：交易日、报告期、指标所属期、事件日、发布日期或最近可得日；不要混用。
- 指标：逐项列出，避免“相关数据”“全部指标”。
- 口径：累计/单季、合并/母公司、金融/非金融、披露持仓范围、币种、单位或合约类型。
- 排序和数量：排序字段、方向、最大条数。

## 跨域拆分

| 用户需求 | 推荐拆分 |
| --- | --- |
| 公司历史行情与财务趋势 | 先查日频行情，再查财务；按交易日或报告期分别解释 |
| 基金业绩与重仓股 | 先查业绩风险指标，再查对应披露期持仓 |
| 债券利差与发行人信用 | 先查单券行情和基准曲线，再查主体/债项评级或发行人财务 |
| A/H 两地上市对比 | 按市场分别查询，再对齐币种、会计期间和证券代码 |
| 期货行情与仓单/持仓 | 日行情、仓单和会员持仓排名分别查询，统一交易日、合约和单位 |
| 宏观数据与市场表现 | 先查指标所属期和发布日期，再查发布日期后的市场日行情 |
| 指数表现、成分和权重 | 行情、成分清单、权重时点分别查询，再按样本日期关联 |

## 结果校验

1. 同时检查 MCP `isError` 与业务返回；若出现 `code != 200000`，按业务失败处理。
2. 若同时返回结构化表格和文字解释，关键数字以表格为准。
3. 核对列名与每行值，保留交易日、报告期、事件日、发布日期、单位、币种和统计口径。
4. “最近 N 期”按每个对象各自已披露期间取数，展示实际期间。
5. `null`、空白或“未披露”不得改成 0，也不得用模型记忆或网页数字补齐。
6. 预测、解释和自主测算与已披露实际值分开；测算展示输入、公式、单位和假设。
7. 删除返回文字中的内部任务 ID、SQL、物理表、内部路径和连接信息。

## 空结果、超时与过量结果

- 空结果：先检查是否超出当前授权域，再检查对象/代码、日期、指标、口径和筛选条件，最多改写一至两次。
- `504`：缩小到单数据域、单对象、单期间和少量指标后最多重试一次。
- 返回过量：收紧日期、样本池、排序和最大条数，不在本地默默丢弃影响结论的记录。
- 仍失败：明确说明覆盖缺口或服务超时，不补造数据。
