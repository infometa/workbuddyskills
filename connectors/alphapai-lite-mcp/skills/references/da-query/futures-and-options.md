# 期货与期权

本 Reference 描述当前纯净版目录中的期货和期权结构化数据。当前主要是合约身份、日频行情、交易统计、持仓、仓单、标的、行权和风险指标，不包含盘中逐笔或分钟级实时行情。

## 期货覆盖

| 内容 | 常见字段 |
| --- | --- |
| 合约与品种 | 合约代码/简称/全称、品种、交易所、币种、报价单位、交割方式、上市/退市日、保证金率、合约状态 |
| 日行情 | 交易日、昨结、开高低收、结算价、涨跌、成交量、成交额、持仓量及变化 |
| 连续/主力合约 | 连续合约类型、对应月合约、映射交易日和连续合约日行情 |
| 交易统计 | 统计期间、地区、交易所、品种/合约、区间价格、成交量额和持仓量 |
| 会员持仓排名 | 合约、交易日、会员、成交量、持买仓、持卖仓、名次和较前日变化 |
| 仓单 | 交易日、品种、仓库/地区、注册/注销/预报量、昨日/当日仓单和增减 |
| 国债期货 | 可交割券、基差、发票价格、隐含回购率、理论/活跃 CTD 和交易日 |
| 合约指标 | 指标名称、数值/比率、单位、生效日和失效日 |

常见身份字段是合约代码、合约内部标识、合约名称、品种和交易所；常见时间字段是交易日、业务截止日、报告期、生效日和信息发布日期。内部标识仅用于服务匹配，不对用户输出。

## 期权覆盖

| 内容 | 常见字段 |
| --- | --- |
| 合约与品种 | 合约交易代码、简称、品种类别、交易所、认购/认沽、欧式/美式、合约单位、状态 |
| 标的关系 | 标的代码/名称/类别、证券/指数/期货身份、关联生效期和匹配状态 |
| 行权与到期 | 行权价、上市日、最后交易日、到期日、行权日、交割方式和有效期 |
| 日行情 | 交易日、昨结、开高低收、结算价、成交量、持仓量、行权量、涨跌幅和隐含波动率 |
| 风险指标 | Delta、Gamma、Vega、Theta、Rho 和发布日期 |
| 盘前静态资料 | 每日合约、标的、执行方式、到期和可交易状态；不是盘中行情 |
| 调整事件 | 调整日期、调整前后代码/简称/行权价/合约单位和调整原因 |
| 交易统计 | 标的/合约类型、会员、成交量、买卖持仓和排名 |

## 查询口径

1. 合约名称、交易代码和交易所尽量同时提供；同一品种的连续合约、主力合约和具体月份合约必须分开。
2. 日行情使用交易日；区间统计使用统计期间；合约状态和规格使用生效/失效日。
3. 价格必须结合币种、报价单位和合约单位解释；成交量、持仓量、仓单量可能使用手、张、份或品种单位。
4. 期货结算价与收盘价、期权行权价与市场价格不得混用。
5. 仓单跨品种汇总前统一品种和单位；会员排名不能跨指标类型直接相加。
6. Greeks 和隐含波动率是特定交易日、合约和模型口径下的风险指标，不写成未来价格预测。

## 推荐问题

```text
查询沪深 300 股指期货指定合约最近 20 个交易日的开盘、最高、最低、收盘、结算价、成交量和持仓量，返回合约代码、交易所、交易日和单位，按交易日升序。
```

```text
查询指定商品期货品种最近 10 个交易日的注册仓单、注销量、预报量和日增减，保留交易所、品种、统计口径和仓单单位。
```

```text
查询指定 ETF 期权合约最近 10 个交易日的收盘价、结算价、隐含波动率、Delta、Gamma、Vega、Theta、成交量和持仓量，返回行权价、到期日和实际交易日。
```

## 校验边界

- 当前期货和期权行情是日频或统计期间数据，不称为实时或分钟行情。
- 连续合约是分析用序列，不能与具体月份合约无条件拼接或重复汇总。
- 主力标识和连续映射随交易日变化，历史分析保留映射日。
- 仓单、成交量和持仓量跨品种前必须统一单位。
- 期权标的可能是证券、指数或期货；不能用相似名称或同主题 ETF 静默替代。
- 接近到期、行权或条款条件不等于事件必然发生。
