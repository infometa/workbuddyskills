#### 经营看板类 → 诊断规则见「场景 1」

> 经营日报/周报/月报按**成交、流量、用户、商品**四个角度组织回复。

| 经营月报快览 | 月报快览、本月表现、这个月怎么样 | Q-1(大盘) → A-2(环比) → A-3(趋势) → Q-4(新老客) → Q-2(品类 TOP) | 同周报 |

#### 维度下钻类 → 诊断规则见「场景 2~5」

| 场景 | 触发词 | SQL 组合 | 输出结构 | 诊断规则 |
|------|--------|---------|---------|---------|
| 流量下钻 | 流量分析、PV UV、渠道流量、引流效果 | Q-1(流量部分) → A-6(渠道分布) → A-7(商品漏斗) | 流量概览 → 渠道对比 → 转化漏斗 | 场景 2 |
| 支付下钻 | 支付分析、GMV 拆解、订单分析 | Q-1 → A-4(品类分布) → A-9(SPU TOP) | 支付概览 → 品类排行 → TOP 商品 | 按数据描述 |
| 用户下钻 | 用户分析、新老客、用户画像、用户结构 | Q-4(新老客) → A-5(分群分布) → A-10(留存复购) | 分群概览 → 结构分布 → 留存趋势 | 按数据描述 |
| 商品下钻 | 商品分析、品类表现、品类转化、SPU 分析 | Q-2(品类) → A-7(漏斗) → A-9(SPU TOP) | 品类排行 → 转化漏斗 → TOP 商品 | 场景 3 |
| 营销下钻 | 营销分析、活动效果、优惠券分析 | A-6(渠道) → A-11(优惠券漏斗) | 渠道分布 → 券漏斗 → ROI | 场景 4 |
| 分销下钻 | 分销分析、推广效果、佣金分析 | Q-1(大盘GMV) → Q-5b(分销大盘) → Q-5(推广人排行) | 分销概览 + 占比 → 推广人排行 → ROI | 场景 5 |

#### 归因诊断类 → 诊断规则见「场景 6」

> **核心方法论**：L1 问题发现（趋势+异常检测）→ L2 问题定位（杜邦分解+多维平行归因）→ L3 深度理解（分布+漏斗）→ L4 行动建议。
> 交易域归因必须走三因子杜邦分解，按主因子智能分支选择下钻方向。

| 场景 | 触发词 | SQL 组合 | 输出结构 |
|------|--------|---------|---------|
| 交易域归因 | GMV 为什么跌/涨、下降原因、业绩下滑 | D-9(逐日趋势) → D-1(三因子杜邦) → **按主因子分支**（见下方分支表） | 趋势定位 → 三因子拆解 → 主因子下钻 → 集中度检查 → 建议 |
| 商品域归因 | 品类为什么跌、商品异常、哪个品类拖了后腿 | D-2(品类贡献) → D-3(头部SPU异动) | 品类贡献度 → TOP SPU 异动排查 |
| 用户域归因 | 用户为什么少了、留存下降、复购下降 | D-4(新老客) → D-5(生命周期/RFM) → D-6(留存) | 新老客拆解 → 分群变化 → 留存趋势 |
| 渠道归因 | 渠道为什么跌、转化率下降、哪个渠道出了问题 | D-7(渠道贡献) → D-8(活动/券效果) | 渠道贡献度 → 活动效果诊断 |
| **兜底：其他指标归因** | 转化率为什么降、客单价为什么降、复购率为什么降、ROI 为什么降… | 读 `references/analysis_methods.md` 查该指标的分解公式，按公式选对应 SQL 模板 | 找拐点 → 按公式拆解 → 维度归因 → 建议 |

**交易域归因——主因子分支表**：

D-1 完成三因子杜邦（`GMV = browse_uv × 转化率 × 客单价`）后，按贡献度最大的主因子选择下钻 SQL：

| 主因子 | 下钻 SQL 组合 | 下钻逻辑 |
|--------|-------------|---------|
| **UV 是主因**（贡献 > 50%） | D-7(渠道贡献) → D-4(新老客) → D-2(品类UV对比) | 哪个渠道 UV 掉了？新客还是老客？哪个品类引流少了？ |
| **转化率是主因**（贡献 > 50%） | D-1(构建漏斗: visit→browse→click→order→pay) → D-2(品类转化率对比) → D-4(新老客转化率) | 漏斗哪步断了？哪个品类拖了转化？新老客谁的转化降了？ |
| **客单价是主因**（贡献 > 50%） | D-1(件单价+连带率计算) → D-2(品类客单价+GMV占比) | 是件单价降了还是连带率降了？哪个品类结构变了？ |
| **双因子均贡献**（各 30~50%） | 全展开：D-7 + D-2 + D-4 | 两条线并行归因 |

> 交易域归因尾部追加品类集中度检查，详见场景 6 第四步。

## 二、各场景诊断规则（怎么分析）

### 场景 1：经营日报 / 经营概览

**触发词**：昨天数据/日报/经营概览/近7天/本周经营/周报快览/月报快览

> 从**成交、流量、用户、商品**四个角度全景呈现经营状况。
> **不做深度归因**——GMV 环比降 > 20% 或用户明确问"为什么"时，导向场景 6。

### 诊断规则

> 拿到 Q-1 + Q-4 + Q-2 数据后，**按四个角度逐一扫描下表**，命中的信号输出诊断结论，未命中的跳过。

#### 成交角度（Q-1）

| 数据信号 | 诊断结论 | 前置条件 |
|---------|---------|---------|
| GMV 环比下降 > 10% | 拆解主因子（三因子或二因子），标注变化率最大的因子 | 有环比 |
| 客单价环比下降 > 5% | 进一步看件单价(`gmv/sales_qty`)和连带率(`sales_qty/pay_cnt`)哪个降了 | sales_qty > 0 |
| 退款率 > 8% | 退款率偏高（{rate}%），需排查高退款品类 | refund_amt > 0 |
| 支付人数下降但客单价上升 | 高单价商品占比提升但流量不足，属结构性变化 | pay_uv > 0 |

#### 流量角度（Q-1）

| 数据信号 | 诊断结论 | 前置条件 |
|---------|---------|---------|
| browse_uv 环比下降 > 15% | 流量不足，需加强引流 | browse_uv > 0 |
| 转化率环比下降 > 3个百分点 | 转化链路可能有断点 | browse_uv > 0 |
| register_uv = 0 | 无新注册用户，获客链路可能缺失 | — |

#### 用户角度（Q-4）

| 数据信号 | 诊断结论 | 前置条件 |
|---------|---------|---------|
| 新客占比变动 > 5个百分点 | 客群结构异动：新客占比从 {base}% 变为 {cur}% | 有环比 |
| 新客人数 = 0 | 无新客成交，获客或转化存在问题 | — |
| 老客人数环比下降 > 20% | 老客流失严重，需排查复购激励 | 有环比 |
| 新客客单价远低于老客（< 50%） | 新客购买力偏弱，可能是低价引流导致 | 新老客均有值 |

#### 商品角度（Q-2）

| 数据信号 | 诊断结论 | 前置条件 |
|---------|---------|---------|
| 品类数 < 3 | 品类数过少（{n}个），商品丰富度不足 | — |
| 单品类 GMV 占比 > 50% | 品类结构集中：{品类}占 {x}%，抗风险能力弱 | — |
| 某品类 CVR 低于均值 50% | {品类}转化率偏低（{cvr}%），建议优化该品类商品详情页 | cvr 有值 |
| TOP1 品类 GMV 环比下降 > 15% | 头部品类{品类}表现下滑，拉低整体 | 有环比 |

### 建议模板

四角度异常信号汇总后，从以下建议库中选取 **2~3 条最相关的**输出：

| 条件 | 建议 |
|------|------|
| UV 低或下降 | 商城引流不足，建议引入分销员推广、社群推广等方式加大外部流量 |
| 品类数过少 | 当前商城在售品类较少（{n}个），建议补充上架更多品类，提升商品丰富度 |
| 转化率低（< 3%） | 商品基础信息可能不完善，建议优化商品主图、标题、主图视频、卖点、详情页 |
| 连带率下降 | 每单件数减少，建议设置"凑单满减""搭配推荐"等组合优惠 |
| 件单价下降 | 商品价格下移，建议检查促销折扣力度是否过大，适当引入中高价商品曝光权重 |
| 退款率 > 8% | 退款率偏高（{rate}%），建议排查高退款品类和具体商品 |
| 无新客 | 获客链路缺失，建议拓展拉新渠道或设置新人专属活动 |
| 老客流失 | 老客回访不足，建议设置复购券、会员积分等留存手段 |
| 品类集中度高 | 过度依赖单一品类，建议培育第二增长品类，分散经营风险 |

**数据可用性**：某角度数据为空时跳过并标注；`gmv=0 且 pay_uv=0` 时终止，输出"暂无成交数据"。

## 场景 2：流量分析

**触发词**：流量/页面浏览次数/页面浏览人数/PV/UV/访客/引流/渠道流量

### 诊断规则

| 数据信号 | 诊断结论 |
|---------|---------|
| 总 UV 环比下降 | 整体流量萎缩，需加强引流 |
| 某渠道占比 > 60% | 流量来源过度集中于{渠道}，风险较高 |
| 某渠道 UV 环比下降 > 20% | {渠道}流量下滑明显 |
| 注册人数为 0 或极低 | 新用户获取不足 |

### 按渠道建议模板

查到各渠道页面浏览次数/浏览人数数据后，**逐渠道给针对性建议**：

| 渠道 | 建议（有数据时输出占比+建议） |
|------|------|
| 自然流量 | 引入页面浏览次数（占比{x}%）、页面浏览人数（占比{x}%）。建议优化小程序名称、关键词，贴合用户搜索习惯（行业词、核心商品词），提升主动搜索曝光 |
| 分销渠道 | 引入页面浏览次数（占比{x}%）、页面浏览人数（占比{x}%）。建议拓展内外部分销员数量，设置合理的商品佣金激励，引导分销员主动推广 |
| 微信社群 | 建议定期发放专属社群福利（如社群优惠券），活跃社群氛围，引导群成员点击进入商城 |
| 朋友圈 | 建议每日发布 1-2 条商城相关内容（商品亮点、优惠活动），搭配小程序卡片/海报，提升朋友圈引流效果 |
| 公众号 | 建议在公众号推文、菜单栏植入商城小程序卡片，结合推文内容引导用户点击进入 |
| 视频号 | 建议利用视频号直播带货，挂载商城小程序链接；发布短视频内容（商品展示、使用教程），植入小程序短链接 |

## 场景 3：商品分析

**触发词**：商品分析/商品表现/转化漏斗/低转化/品类表现/商品榜单

### 诊断规则

先输出全链路转化漏斗（曝光→点击→加购→支付），逐步计算转化率并与基期对比，**偏差最大的步骤为断点**（不是绝对值最低的步骤）：

| 环节 | 断点判定 | 核心影响因素 |
|------|---------|------------|
| 曝光→点击 | 环比偏差最大 = 断点 | 商品主图、标题、价格 |
| 点击→加购 | 同上 | 商品卖点、详情页、规格参数 |
| 加购→支付 | 同上 | 商品价格、优惠活动、评价、支付体验 |

### 低转化商品诊断模板

| 低转化类型 | 诊断话术 |
|-----------|---------|
| 点击转化率低（曝光→点击） | 原因可能包括：主图质量不佳、标题未包含核心关键词、无主图视频 |
| 加购转化率低（点击→加购） | 原因可能包括：商品卖点不突出、详情页未展示使用场景及核心优势、规格参数缺失 |
| 支付转化率低（加购→支付） | 原因可能包括：未设置任何优惠活动、支付方式可用性问题、库存不足提示 |
| 全链路转化低 | 原因可能包括：商品基础信息缺失（标题、主图、详情页均不完善）、无任何推广曝光 |

### 榜单输出规则

- 类目榜单：按成交金额排序，区分优势类目（转化高）与薄弱类目（商品少、转化弱），标注核心表现
- 商品榜单：输出点击 TOP10 和成交 TOP10，标注低转化原因及推广建议

## 场景 4：营销分析

**触发词**：营销/优惠券/秒杀/满减/活动效果/营销推广

### 分支判断

先查 `app_market_stat_promotion_di`、`app_market_stat_coupon_overview_di` 和 `app_market_stat_coupon_di` 是否有数据：

| 条件 | 输出 |
|------|------|
| **活动表和券表均无数据**（查询返回空） | "商城当前未设置任何营促销活动，营销引流及转化助推作用缺失，需快速搭建基础营销体系。" + 通用建议 |
| **有活动数据** | 输出营销投入金额、产出 GMV、ROI + 诊断建议 |

### 有活动时的诊断规则

| 数据信号 | 建议 |
|---------|------|
| ROI < 1.5 | 营销 ROI 偏低（{roi}），投入产出不成比例，建议优化活动力度或缩减低效活动 |
| ROI 1.5~3 | 营销 ROI 一般（{roi}），建议优先搭配高转化商品 |
| ROI > 3 | 营销 ROI 良好（{roi}），可适当加大投入 |
| 核销率 < 15% | 优惠券核销率偏低（{rate}%），建议优化券门槛或推送时机 |

### 通用建议

> 建议联动商品、流量运营，活动优先搭配高转化商品。

## 场景 5：分销分析

**触发词**：分销/推广/佣金/推广人/CPS

### 分支判断

先查 `app_market_stat_cps_di` 是否有数据：

| 条件 | 输出 |
|------|------|
| **无分销数据**（表为空或查询返回 0 行） | "商城当前未设置分销推广。分销可给商城带来更多的流量及转化增量，建议尽快开启分销推广工具。" |
| **有分销数据** | 输出分销订单量/金额/占比/ROI + 诊断建议 |

### 有分销数据时的诊断规则

| 数据信号 | 建议 |
|---------|------|
| 推广人数 < 5 | 分销员数量不足（{n}人），建议借助"人人都是分销员"能力，扩大外部分销员招募范围 |
| 分销 ROI < 1.5 | 分销 ROI 偏低（{roi}），建议优化佣金结构，平衡激励和成本 |
| 分销订单占比 < 5% | 分销渠道贡献占比较低（{pct}%），建议为核心爆品设置更有吸引力的佣金比例 |
| 点击→支付转化率 < 3% | 分销链接转化率偏低（{cvr}%），建议优化推广素材和落地页 |
| 分销员数量正常 | 建议结合商品利润，设置 3-5 款爆品佣金，更多商品加入分销商品池扩大覆盖 |

### 场景 6：GMV 归因诊断

**触发词**：GMV 为什么跌/涨、业绩下滑、下降原因、GMV 异常、交易归因

> 完整归因分析，按 **找拐点 → 三因子拆解 → 按主因子下钻 → 结构风险 → 建议** 的顺序执行。

### 诊断规则

#### 第一步：找拐点（D-9 逐日趋势）

拉逐日 GMV 走势，标注环比变化最大的那天为拐点。计算当期均值 vs 基期均值的偏离度：

| 偏离度 | 判定 |
|--------|------|
| < ±10% | 正常波动，告知用户无需归因 |
| ±10% ~ ±20% | ⚠️ 值得关注，继续第二步 |
| > ±20% | 🔴 显著异常，必须继续 |

基期为空 → 只输出当期走势，标注"暂无基期"。数据 < 3 天 → 标注"拐点识别精度受限"。

#### 第二步：GMV 变化拆解——是什么原因导致 GMV 变化？（D-1）

GMV 的变化可以从三个角度拆解：来了多少人（浏览人数）、有多少人买了（转化率）、每人花了多少（客单价）。分别计算三个因子的环比变化率，量化贡献度（三者之和 ≈ 100%），贡献度最大的标记为主因。

> **贡献度说明**：贡献度 = 该因子变化对 GMV 总变化的拉动占比。例如"转化率贡献约 80%"表示：假设其他两个因子不变，仅转化率的变化就能解释本次 GMV 下跌的约 80%。

#### 第三步：按主因子下钻

**UV 是主因** → 查 D-7(渠道) + D-4(新老客) + D-2(品类)

| 数据信号 | 诊断结论 | 数据为空时 |
|---------|---------|----------|
| 某渠道 UV 降幅最大 | {渠道}是 UV 下降主因 | 渠道数据为空，跳过 |
| 新客 UV 贡献降幅 > 50% | 获客端萎缩 | 新老客数据为空，跳过 |
| 老客 UV 贡献降幅 > 50% | 用户留存/回访不足 | — |
| 某品类 UV 降幅最大 | {品类}引流缩水 | 品类数据为空，跳过 |

> 当前数据表为单维度聚合，无法做渠道×用户×品类的交叉下钻。以上三个维度为平行归因，分别给出各自的贡献度。

**转化率是主因** → 用 D-1 数据构建漏斗 `visit→browse→click→order→pay`

| 数据信号 | 诊断结论 |
|---------|---------|
| 某步骤转化率偏差最大 | 该步骤是漏斗断点 |
| 有效漏斗步骤 < 3 | 标注"漏斗不完整，精度受限" |

断点定位后，若断点涉及 click 或 pay 环节，可查 D-2 按品类对比该步骤转化率（品类表有 expose/click/addcart/pay_uv）。visit→browse 和 order→pay 的断点无品类对比数据。

**客单价是主因** → 用 D-1 数据计算件单价和连带率

| 数据信号 | 诊断结论 | 前置条件 |
|---------|---------|---------|
| 件单价(`gmv/sales_qty`)降幅大 | 商品价格下移 | sales_qty > 0 |
| 连带率(`sales_qty/pay_cnt`)降幅大 | 每单件数减少 | pay_cnt > 0 |
| 某低价品类 GMV 占比上升 > 5个百分点 | 品类结构拉低客单价 | D-2 有数据 |

**双因子均贡献（各 30~50%）** → UV 和转化率/客单价的下钻都做。

#### 第四步：品类集中度检查（D-2 数据）

| 数据信号 | 诊断结论 | 前置条件 |
|---------|---------|---------|
| 单品类 GMV 占比 > 50% | ⚠️ 品类过度集中，抗风险弱 | 品类数 ≥ 2 |
| Top3 品类占比 > 80% | ⚠️ 高度集中，建议培育长尾 | — |
| 集中度环比上升 > 5个百分点 | ⚠️ 在恶化 | 有环比 |

### 建议模板

| 根因类型 | 建议 |
|---------|------|
| UV↓ 渠道萎缩 | 恢复/加大该渠道投入，排查渠道策略变更 |
| UV↓ 新客不足 | 拓展获客渠道，优化拉新活动/分销佣金 |
| 转化率↓ 浏览→点击断点 | 优化商品卡主图、标题、价格竞争力 |
| 转化率↓ 下单→支付断点 | 排查支付通道/优化支付体验/检查库存提示 |
| 客单价↓ 件单价降 | 检查促销折扣力度，引入中高价商品曝光 |
| 客单价↓ 连带率降 | 设置凑单满减、搭配推荐等组合优惠 |
| 客单价↓ 品类结构变动 | 提升高客单品类曝光权重，培育高毛利品类 |
| 品类集中度过高 | 分散品类依赖，培育第二/三增长品类 |

### 输出结构

找拐点 → 三因子拆解（标注主因）→ 主因子下钻结论 → 集中度风险 → 2~3 条建议
