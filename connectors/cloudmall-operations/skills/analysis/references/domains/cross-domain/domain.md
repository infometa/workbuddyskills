# 🟪 跨域综合 域知识

> 全域联合分析：综合周报 + 综合归因 + 购物篮 + 季节性 + 健康度评分卡，回答"整体经营怎么样、该往哪使劲"。

---

## 一、域定位

**业务定位**：跨域综合是管理层视角，将交易/商品/用户/营促销四域数据联合分析
**核心问题**：整体经营评分多少？经营周报要点？综合归因根因是什么？
**分析能力数**：5 个（能力 23-27）

---

## 二、数据基础

全部 8 张核心表联合查询。各表详情参见对应域 domain.md。

### 能力 27：经营健康度评分卡 🆕

**定位**：最高层级总览，五维度加权 → 一个总分

**组件链**：

| 序号 | 组件 | 章节 | 数据来源 |
|------|------|------|---------|
| 1 | C01 | S1 总分摘要 | 全部 8 表 |
| 2 | C11 | S2 五维雷达图 | 交易力/商品力/用户力/营销力/效率力 |
| 3 | C11 | S3 维度明细 | 各维度子指标得分 |
| 4 | C03 | S4 评分趋势 | 近 N 周走势 |
| 5 | C08 | S5 短板下钻 | 自动触发最低维度深度分析 |
| 6 | C05 | S6 对标基线 | 行业基线对比 |
| 7 | C12 | S7 洞察建议 | 最薄弱环节 + 优先改善 |

**五维评分体系**：

| 维度 | 满分 | 子指标 |
|------|------|--------|
| 🟦 交易力 | 25 分 | GMV达成率(10) + 增速(8) + 客单价健康(7) |
| 🟩 商品力 | 20 分 | 品类集中度(5) + 新品占比(5) + CVR(5) + 退款率反向(5) |
| 🟨 用户力 | 25 分 | 新老客结构(6) + D7留存(7) + 复购率(6) + RFM高价值占比(6) |
| 🟥 营销力 | 15 分 | 渠道ROI(5) + 补贴率反向(5) + 流量增长(5) |
| 🟪 效率力 | 15 分 | 转化率(5) + 连带率(5) + 退款率反向(5) |

等级：≥80→🟢优秀 / 60~79→🟡良好 / 40~59→🟠需关注 / <40→🔴预警
