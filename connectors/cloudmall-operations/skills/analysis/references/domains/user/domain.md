# 🟨 用户域 域知识

> 客群健康度 + 留存复购 + RFM 运营 + 生命周期流转 + CLV 分层 + 客群归因，回答"用户从哪来、留不留、值不值"。

---

## 一、域定位

**业务定位**：用户域聚焦人群资产的获取、留存、价值分层和流转
**核心问题**：新老客结构是否健康？留存率和复购率如何？高价值用户有无流失？
**分析能力数**：6 个（能力 13-18）

---

## 二、域特有分析模式：复购与留存（BITMAP_AND）

复购率和留存率属于**跨周期 UV 重合度**指标，核心用 `BITMAP_AND` 计算两个 BITMAP 字段的交集。完整 SQL 示例见 `references/sql-few-shots.md` 示例 2。

**关键规则**：
1. 用 **BITMAP_AND**（非 `BITMAP_INTERSECT`）计算两个独立 BITMAP 的交集
2. 分母为基准期人数：`复购率 = 交集人数 / 基准期总人数`
3. 同表不同时间段，CTE 分别聚合后计算交集
4. 参与交集运算的两个 BITMAP 必须基于相同的用户 ID 编码体系

## 四、Gate Check 域专项规则

| 检查项 | FAIL 条件 | 意义 |
|--------|-----------|------|
| dim_type 过滤 | SQL 无 WHERE dim_type= | 防跨维度混合 |
| 新老客人数校验 | 新客+老客 vs 总人数误差 > 10% | 分群覆盖完整性 |
| 留存率上限 | D7留存率 > 100% | 计算错误 |

## 五、健康基线阈值

| 指标 | 警戒 ⚠️ | 红线 🔴 |
|------|---------|---------|
| 新客占比 | > 40% 或 < 10% | > 60% 或 < 5% |
| D7 访问留存率 | < 30% | < 15% |
| D30 复购率 | < 15% | < 8% |
| Top 20% 用户 GMV 占比 | > 80% | > 90% |
