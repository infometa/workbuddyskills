# 场景 2：流量下钻

> 触发词：流量分析、PV UV、渠道流量、引流效果

## SQL 组合

Q-1（流量部分）→ A-6（渠道分布, dim_type=channel）→ A-7（商品漏斗）

**输出结构**：流量概览 → 渠道对比 → 转化漏斗

---

## 诊断规则

| 数据信号 | 诊断结论 |
|---------|---------|
| 总 UV 环比下降 | 整体流量萎缩，需加强引流 |
| 某渠道占比 > 60% | 流量来源过度集中于{渠道}，风险较高 |
| 某渠道 UV 环比下降 > 20% | {渠道}流量下滑明显 |
| 注册人数为 0 或极低 | 新用户获取不足 |

---

## 建议模板

查到各渠道页面浏览次数/浏览人数数据后，**逐渠道给针对性建议**：

| 渠道 | 建议（有数据时输出占比+建议） |
|------|------|
| 自然流量 | 引入页面浏览次数（占比{x}%）、页面浏览人数（占比{x}%）。建议优化小程序名称、关键词，贴合用户搜索习惯（行业词、核心商品词），提升主动搜索曝光 |
| 分销渠道 | 引入页面浏览次数（占比{x}%）、页面浏览人数（占比{x}%）。建议拓展内外部分销员数量，设置合理的商品佣金激励，引导分销员主动推广 |
| 微信社群 | 建议定期发放专属社群福利（如社群优惠券），活跃社群氛围，引导群成员点击进入商城 |
| 朋友圈 | 建议每日发布 1-2 条商城相关内容（商品亮点、优惠活动），搭配小程序卡片/海报，提升朋友圈引流效果 |
| 公众号 | 建议在公众号推文、菜单栏植入商城小程序卡片，结合推文内容引导用户点击进入 |
| 视频号 | 建议利用视频号直播带货，挂载商城小程序链接；发布短视频内容（商品展示、使用教程），植入小程序短链接 |
