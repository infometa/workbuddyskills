# 场景 4：用户下钻

> 触发词：用户分析、新老客、用户画像、用户结构、留存、复购、RFM

## SQL 组合

Q-4（新老客, dim_type=user_order_type）→ A-5（分群分布, 分别查 user_order_type/lifecycle/rfm）→ A-10（留存复购）

**输出结构**：新老客结构 → 生命周期/RFM 分布 → 留存复购趋势 → 诊断建议

---

## 诊断规则

### 一、增长结构（Q-4 → dim_type=user_order_type）

| 数据信号 | 诊断输出 |
|---------|---------|
| 新客 GMV 占比 > 60% | "成交主要依赖新客拉动（{pct}%），需关注新客留存以避免增长不可持续" |
| 老客 GMV 占比 > 70% | "成交主要依赖老客复购（{pct}%），新客引入不足可能导致长期增长乏力" |
| 新客人数环比下降 > 20% | "新客人数环比下降 {rate}%，拉新能力减弱，建议检查引流渠道和注册转化" |
| 老客客单价 < 新客客单价 | "老客客单价（{old_aov} 元）低于新客（{new_aov} 元），老客复购偏向低价商品" |

### 二、用户结构健康度（A-5 → lifecycle + rfm）

| 数据信号 | 诊断输出 |
|---------|---------|
| 流失期用户占比 > 30% | "⚠️ 流失期用户占比 {pct}%，流失风险较高，建议加强沉默用户召回" |
| 引入期用户占比 > 50% | "大量用户停留在首购阶段（{pct}%），建议设计二单激励促进转化" |
| 成熟期用户占比 < 10% | "成熟期用户仅占 {pct}%，高频忠实用户过少" |
| 高价值用户 GMV 占比 > 40% 但人数占比 < 5% | "高价值用户仅 {pct}% 但贡献 {gmv_pct}% GMV，需重点维护防止流失" |

### 三、留存复购（A-10 → dws_user_cohort_metrics_di）

| 数据信号 | 诊断输出 |
|---------|---------|
| D+7 留存率 < 15% | "7 日留存率 {rate}%，用户回访意愿弱" |
| D+7 复购率 < 5% | "7 日复购率 {rate}%，建议在首购后 3~5 天推送关联商品或复购优惠" |
| D+30 复购率 < 10% | "30 日复购率 {rate}%，月度复购偏低" |
| 新客复购率远低于老客 | "新客复购率（{new_rate}%）远低于老客（{old_rate}%），新客转化为回头客的能力不足" |
