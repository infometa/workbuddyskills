# 场景 1：经营概览（日报/周报快览/月报快览）

> 触发词：日报、今天表现、昨天怎么样、周报快览、上周表现、这周怎么样、月报快览、本月表现、这个月怎么样

## SQL 组合

| 子场景 | SQL 序列 | 输出结构 |
|--------|---------|---------|
| 经营日报 | Q-1(大盘) → A-2(环比) → A-7(漏斗) → Q-4(新老客, dim_type=user_order_type) → Q-2(品类 TOP) | 四角度概览（成交→流量漏斗→用户→商品）+ 异常信号 + 建议 |
| 经营周报快览 | Q-1(大盘) → A-2(环比) → A-3(趋势) → A-7(漏斗) → Q-4(新老客) → Q-2(品类 TOP) | 四角度概览 + 趋势图 + 异常信号 + 建议 |
| 经营月报快览 | Q-1(大盘) → A-2(环比) → A-3(趋势) → A-7(漏斗) → Q-4(新老客) → Q-2(品类 TOP) | 同周报 |

## 诊断规则

从**成交、流量、用户、商品**四个角度全景呈现经营状况。
**不做深度归因**——GMV 环比降 > 20% 或用户明确问"为什么"时，导向场景 8（归因诊断）。

拿到 Q-1 + Q-4 + Q-2 数据后，**按四个角度逐一扫描下表**，命中的信号输出诊断结论，未命中的跳过。

### 成交角度（Q-1）

| 数据信号 | 诊断结论 | 前置条件 |
|---------|---------|---------|
| GMV 环比下降 > 10% | 拆解主因子（三因子或二因子），标注变化率最大的因子 | 有环比 |
| 客单价环比下降 > 5% | 进一步看件单价(`gmv/sales_qty`)和连带率(`sales_qty/pay_cnt`)哪个降了 | sales_qty > 0 |
| 退款率 > 8% | 退款率偏高（{rate}%），需排查高退款品类 | refund_amt > 0 |
| 支付人数下降但客单价上升 | 高单价商品占比提升但流量不足，属结构性变化 | pay_uv > 0 |

### 流量角度（Q-1 + A-7）

用 Q-1 数据输出流量趋势诊断表，用 A-7 数据输出访问人数→浏览人数→点击人数→支付人数的转化漏斗图（`funnel` 类型）：

| 数据信号 | 诊断结论 | 前置条件 |
|---------|---------|---------|
| 浏览人数 环比下降 > 15% | 整体流量萎缩，需加强引流 | 浏览人数 > 0 |
| 转化率（支付人数/访问人数）环比下降 > 3个百分点 | 转化链路可能有断点，建议排查各环节 | 访问人数 > 0 |
| 点击人数/浏览人数（点击率）< 15% | 商品吸引力不足，建议优化商品主图和标题 | 点击人数 > 0 |
| 支付人数/点击人数（点击转化率）环比下降 > 10个百分点 | 点击→支付断点，建议排查优惠活动、价格、库存 | 点击人数 > 0 |
| 注册人数 = 0 | 无新注册用户，获客链路可能缺失 | — |
| 注册人数 环比下降 > 30% | 拉新能力下滑，建议检查分销/推广渠道 | 有环比 |

### 用户角度（Q-4）

| 数据信号 | 诊断结论 | 前置条件 |
|---------|---------|---------|
| 新客占比变动 > 5个百分点 | 客群结构异动：新客占比从 {base}% 变为 {cur}% | 有环比 |
| 新客人数 = 0 | 无新客成交，获客或转化存在问题 | — |
| 老客人数环比下降 > 20% | 老客流失严重，需排查复购激励 | 有环比 |
| 新客客单价远低于老客（< 50%） | 新客购买力偏弱，可能是低价引流导致 | 新老客均有值 |

### 商品角度（Q-2）

| 数据信号 | 诊断结论 | 前置条件 |
|---------|---------|---------|
| 品类数 < 3 | 品类数过少（{n}个），商品丰富度不足 | — |
| 单品类 GMV 占比 > 50% | 品类结构集中：{品类}占 {x}%，抗风险能力弱 | — |
| 某品类 CVR 低于均值 50% | {品类}转化率偏低（{cvr}%），建议优化该品类商品详情页 | cvr 有值 |
| TOP1 品类 GMV 环比下降 > 15% | 头部品类{品类}表现下滑，拉低整体 | 有环比 |

## 建议模板

四角度异常信号汇总后，从以下建议库中选取 **2~3 条最相关的**输出：

| 条件 | 建议 |
|------|------|
| UV 低或下降 | 商城引流不足，建议引入分销员推广、社群推广等方式加大外部流量 |
| 品类数过少 | 当前商城在售品类较少（{n}个），建议补充上架更多品类，提升商品丰富度 |
| 转化率低（< 3%） | 商品基础信息可能不完善，建议优化商品主图、标题、主图视频、卖点、详情页 |
| 连带率下降 | 每单件数减少，建议设置"凑单满减""搭配推荐"等组合优惠 |
| 件单价下降 | 商品价格下移，建议检查促销折扣力度是否过大，适当引入中高价商品曝光权重 |
| 退款率 > 8% | 退款率偏高（{rate}%），建议排查高退款品类和具体商品 |
| 无新客 | 获客链路缺失，建议拓展拉新渠道或设置新人专属活动 |
| 老客流失 | 老客回访不足，建议设置复购券、会员积分等留存手段 |
| 品类集中度高 | 过度依赖单一品类，建议培育第二增长品类，分散经营风险 |

**数据可用性**：某角度数据为空时跳过并标注；`gmv=0 且 pay_uv=0` 时终止，输出"暂无成交数据"。

## 趋势诊断表格式规范

趋势诊断表**必须**使用以下列结构，输出"本期均值 / 上期均值 / 变化率 / 判定"四列：

| 指标 | 本期均值 | 上期均值 | 变化率 | 判定 |
|------|---------|---------|--------|------|
| 浏览人数 | 352 | 350 | +0.6% | ✅ 持平 |
| 转化率 | 16% | 30% | -14个百分点 | 🔴 显著下降 |

**判定标准**：✅ 正常（UV ±15% 以内 / 转化率 ±3个百分点以内）｜ ⚠️ 轻微异常 ｜ 🔴 显著异常（UV ±30% 以上 / 转化率 ±8个百分点以上）
