# 场景 6：营销下钻

> 触发词：营销分析、活动效果、优惠券分析、渠道效果、渠道转化

## SQL 组合

A-6c（渠道维度）→ A-6a（活动维度）→ A-6b（优惠券概览）→ A-11（券批次列表）→ MK-2（活动×商品 TOP）

**输出结构**：渠道效率 → 活动 ROI → 券漏斗 → 活动商品 TOP → 诊断建议

---

## 诊断规则

### 一、渠道维度（A-6c）

计算每个渠道 CVR = pay_uv / browse_uv：

| 数据信号 | 诊断输出 |
|---------|---------|
| 存在渠道 CVR > 10% | "**高质量渠道**：{渠道} 转化率 {cvr}%，建议加大投入" |
| 存在渠道 browse_uv 排前3 但 CVR < 2% | "**高流量低转化**：{渠道} 浏览 {uv} 人但转化率仅 {cvr}%，建议检查承接页和素材质量" |
| 存在渠道 CVR < 1% | "**低效渠道**：{渠道} 转化率 {cvr}%，低于红线，建议缩减投放或优化落地页" |

### 二、活动维度（A-6a）

无数据时输出："商城当前未配置营销活动，建议搭建基础营销体系。"

有数据时按活动类型聚合 ROI = pay_amt / subsidy_amt：

| 数据信号 | 诊断输出 |
|---------|---------|
| 某活动类型 ROI > 5 | "**高效活动**：{活动类型} ROI = {roi}" |
| 某活动类型 ROI < 1.5 | "**低效活动**：{活动类型} ROI = {roi}，建议降低补贴力度或缩小覆盖范围" |
| 补贴率 > 15% | "补贴率 {rate}% 偏高（警戒线 15%），关注可持续性" |
| 补贴率 > 20% | "补贴率 {rate}% 超红线（20%），建议立即收紧补贴策略" |

### 三、优惠券维度（A-6b / A-11）

先用 A-6b 看券类型概览，再用 A-11 下钻券批次列表；核销率 = 核销量 / 领取量：

| 数据信号 | 诊断输出 |
|---------|---------|
| 某券领取量高但核销率 < 15% | "**低效券**：「{券名或券类型}」领取 {领取量} 张但核销率仅 {rate}%，建议降低门槛或缩短有效期" |
| 某券核销率 > 50% 但用券成交金额低 | "「{券名}」核销率高但带来成交仅 {amt} 元，券未有效促成交" |
| 整体核销率 < 15% | "整体核销率偏低（{rate}%），建议优化推送时机和券门槛设置" |

---

## 建议模板

> 将高转化渠道与高 ROI 活动联动，低效渠道缩减投放，低核销券调整门槛或面值。
