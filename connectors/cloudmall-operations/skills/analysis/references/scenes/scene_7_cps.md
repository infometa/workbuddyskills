# 场景 7：分销下钻

> 触发词：分销分析、推广效果、佣金分析、推广人、分销员

## SQL 组合

Q-1（大盘 GMV）→ Q-5b（分销大盘汇总）→ Q-5（推广人排行 TOP 20）

**输出结构**：分销概览（贡献占比）→ ROI → 推广人排行 → 转化漏斗 → 诊断建议

---

## 诊断规则

无数据时输出："商城当前未开启分销推广，建议开启分销工具为商城带来额外流量和成交增量。"

有数据时按 4 个维度诊断：

### 一、分销贡献度

分销 GMV / 大盘 GMV（Q-5b vs Q-1）：

| 数据信号 | 诊断输出 |
|---------|---------|
| 占比 > 20% | "分销贡献占比 {pct}%，是重要成交渠道" |
| 占比 5%~20% | "分销贡献占比 {pct}%，有增量价值，仍有提升空间" |
| 占比 < 5% | "分销贡献占比仅 {pct}%，对商城拉动有限，建议提升核心商品佣金比例" |

### 二、投产分析

ROI = 分销订单金额 / 佣金总额：

| 数据信号 | 诊断输出 |
|---------|---------|
| ROI > 5 | "分销 ROI = {roi}，投入产出优秀" |
| ROI 1.5~5 | "分销 ROI = {roi}，投产比正常" |
| ROI < 1.5 | "分销 ROI = {roi}，低于警戒线，建议逐商品审视佣金比例，削减低 ROI 商品佣金" |

### 三、分销员团队（Q-5 推广人排行）

| 数据信号 | 诊断输出 |
|---------|---------|
| 推广人数 < 5 | "分销员仅 {n} 人，团队规模不足，建议扩大招募范围或降低准入门槛" |
| TOP1 推广人订单占比 > 50% | "头部依赖风险：{name} 占比 {pct}%，建议培养更多中腰部推广人" |
| 推广人产出差异 > 5 倍 | "推广人产出差异大（最高 {max} 元 vs 最低 {min} 元），建议提炼高产出推广人的推广方式赋能低产出推广人" |

### 四、转化漏斗（点击→支付）

| 数据信号 | 诊断输出 |
|---------|---------|
| click_pv = 0 | "分销点击数据暂无，无法分析转化漏斗" |
| 点击→支付转化率 > 5% | "分销转化率 {cvr}%，流量质量良好" |
| 点击→支付转化率 1%~3% | "分销转化率 {cvr}%，偏低，建议优化推广素材和商品落地页" |
| 点击→支付转化率 < 1% | "分销转化率 {cvr}% 低于红线，建议检查推广链接指向和商品详情页" |
