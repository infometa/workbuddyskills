# 动态 HTML 报告技术规范

> L3-dynamic 路径：AI 直接生成完整 HTML 报告（内嵌 CSS + Chart.js）。
> 视觉风格 MUST 与经营周报（`ecommerce_report.py`）**完全一致**。

## 链路

```
SQL 结果 → AI 组织摘要 → AI 生成完整 HTML → html2pdf.js → PDF
```

## 设计系统

**主题色**：深海军蓝 `#0F172A`（主色）、`#1E3A8A`（亮蓝）、`#CA8A04`（金色强调）
**语义色**：涨绿 `#22C55E`、跌红 `#EF4444`、警橙 `#F59E0B`、弱灰 `#6B7B8D`
**图表 8 色**：`#1E40AF #22C55E #F59E0B #EF4444 #8B5CF6 #06B6D4 #EC4899 #0F172A`
**字体**：`-apple-system, "SF Pro Display", "PingFang SC", "Microsoft YaHei", sans-serif`；15px；行高 1.7
**布局**：max-width 1080px 居中，padding 40px；**不用 Tailwind**，自写 CSS 变量

## 报告结构

```
封面(.cover) → S1 核心结论 → S2 分析发现 → S3 建议 → S4 附录（指标说明）→ 页脚(.footer)
```

每个 section 偶数章节交替 `#F8FAFC` 浅灰背景。

## 组件库（HTML 结构 + 风格要点）

### 封面

深蓝渐变（`#0F172A→#1E3A8A`），底部 3px `#CA8A04` 金色线，装饰性白色光晕。

```html
<div class="cover">
  <div class="container">
    <div class="brand">云Mall商城 · AI 数据分析</div>
    <h1>报告标题</h1>
    <div class="subtitle">分析维度描述</div>
    <div class="meta">统计周期：XX-XX ~ XX-XX</div>
  </div>
</div>
```

### 章节

标题左侧圆形编号（深蓝底白字 32px），标题下 3px 深蓝底线。

```html
<div class="section" id="s1">
  <div class="container">
    <div class="section-header">
      <h2><span class="section-number">1</span>核心结论概览</h2>
    </div>
    <!-- KPI 卡片 / 图表 / 表格 -->
  </div>
</div>
```

### KPI 卡片

白底卡片网格（auto-fit, minmax 160px），**每张卡片顶部 4px 彩色条纹**，按序：深蓝/蓝/绿/紫/金/青/红/橙。数值 28px 粗体，等宽数字。

```html
<div class="kpi-grid">
  <div class="kpi-card">
    <div class="kpi-label">GMV</div>
    <div class="kpi-value">¥45.67万</div>
    <div class="kpi-change up">▲ +5.3% 环比</div>
  </div>
</div>
```

变化 class：`up`（绿）、`down`（红）、`warn`（橙）、`neutral`（灰）。

### 表格

**深蓝 `#0F172A` 实底表头 + 白字**，斑马纹偶数行 `#F8FAFC`，hover `#E2E8F0`。合计行加粗 + 顶部 2px 分隔线 + `#F0F3F7` 背景。

```html
<div class="table-container">
  <table>
    <thead><tr><th>品类</th><th>GMV</th><th>环比</th></tr></thead>
    <tbody>
      <tr><td>食品饮料</td><td>¥12.3万</td><td><span style="color:#22C55E">▲ +8.2%</span></td></tr>
      <tr style="font-weight:700;border-top:2px solid #E2E8F0;background:#F0F3F7">
        <td><strong>合计</strong></td><td><strong>¥45.67万</strong></td><td></td>
      </tr>
    </tbody>
  </table>
</div>
```

### 图表

白底圆角卡片，标题居中 15px 粗体。双列并排用 `.charts-pair-grid`（2-col grid）。

```html
<div class="chart-container">
  <div class="chart-title">逐日 GMV 走势</div>
  <canvas id="chart_1"></canvas>
</div>
```

Chart.js 规则：CDN `chart.js@4.4.7` + `chartjs-plugin-datalabels@2.2.0`。本周线 `#1E40AF`（蓝），上周对比 `#94A3B8`（灰虚线）。柱圆角 4px，折线张力 0.3，网格 `#F0F3F7`，图例底部圆点。

### 洞察框

浅蓝渐变背景（`#F0F7FF→#E8F4FD`），左侧 4px `#334155` 灰蓝边框，8px 圆点列表。

```html
<div class="insight-box">
  <h3>关键洞察</h3>
  <ul class="insight-list">
    <li>客单价提升 8.5%，高客单品类占比提升驱动</li>
  </ul>
</div>
```

### 高亮框

正向：`#F0FFF4` 绿底 + 绿边 + `▲`。负向：`#FFF5F5` 红底 + 红边 + `▼`。

```html
<div class="highlight-positive">
  <div class="highlight-label">亮点</div>
  <div class="highlight-text">客单价提升 8.5%</div>
</div>
```

### 建议卡

单列排列，左侧 4px 彩色条（红/橙/绿/蓝/紫），圆形编号（32px 同色底白字）。

```html
<div class="rec-grid">
  <div class="rec-card">
    <div class="rec-number">1</div>
    <div><h4>🔴 P0 紧急：标题</h4><div class="rec-content"><ul><li>建议内容</li></ul></div></div>
  </div>
</div>
```

### 页脚

居中灰字 12px，60px 分割线。

```html
<div class="footer"><div class="container"><div class="divider"></div>
  <p>Generated by AI · ecommerce-data-analyst Skill</p>
  <p style="opacity:0.6">本报告由 AI 自动生成 · 时间</p>
</div></div>
```

## 数值格式

| 类型 | 格式 | 示例 |
|------|------|------|
| 金额 ≥1万 | ¥X.XX万 | ¥45.67万 |
| 金额 <1万 | ¥X,XXX | ¥8,900 |
| 人数 | 千分位 | 12,580 |
| 环比 | ▲/▼ ±X.X% 环比 | ▲ +5.3% 环比 |
| 百分点 | ▲/▼ ±X.X个百分点 | ▼ -2.1个百分点 |

> 禁 `pp` 缩写。颜色随语义色。

## 数据注入

SQL 结果通过 `<script>` 内嵌为 JS 对象，Chart.js 直接使用。数据 MUST 来自 SQL，禁止编造。

## 复用

`html2pdf.js` / `sql_templates` → 复用。`ecommerce_report.py` / `report_plugins/` → 不使用（动态报告 AI 直接生成 HTML）。报告文件存入 本地工作目录，无需 COS 上传。
