# 直播域 — 运营流程

> 对应契约：直播间/主播/分类查询=`../apis/live/room-anchor-category-query.md`、直播间与分类写操作=`../apis/live/room-anchor-category-action.md`；场次与场次商品查询=`../apis/live/session-goods-query.md`、场次与场次商品写操作=`../apis/live/session-goods-action.md`；回放/统计/场次数据=`../apis/live/replay-stat-data.md`。概念知识：`../domains/live-concepts.md`，状态与枚举：`../domains/live-enums.md`；写操作共同纪律（风险档位/超时不重试）见入口 Skill 护栏段。

## 通用写操作闭环

1. 用搜索/列表定位对象，复述业务名称与十进制字符串 ID。
2. 核对当前状态、关联对象和用户期望；不得把页序号、房间码、会员 ID 当业务 ID。
3. 遇到 🔴 操作，列出完整对象、字段、影响并取得用户明确确认。
4. 单次调用写能力，不自动重试。
5. 用安全列表或关联查询回读。超时先回读；无法唯一确认时报告“结果不确定”，不得重复写。

## 准备新建直播间与首场排期

1. 查询启用分类；标题、封面 URL、分类编码为必填。封面必须是用户提供的可信可访问 URL；当前 Capability Catalog 未登记素材上传。
2. 搜索同名直播间避免重复；确认标签、简介、直播价有效分钟数。
3. 当前开放能力集不能创建直播间：该操作会创建外部 IM 群、推流资源并返回流/群标识。整理表单后交由直播运营台执行。
4. 查询启用主播并确认会员绑定，整理首场排期的计划开始、结束、主播与有效时长。
5. 当前开放能力集不能创建场次：创建结果含 `streamName`。由运营台创建后，再用场次分页定位并继续后续编排。

## 编辑直播间

- 只改静态配置。先用分页定位；标题/简介/分类/标签等可选字段只传用户要求变更的部分。
- Java 运行时允许状态范围必须以实际写入结果为准；不能从注释推断。直播中/暂停中不代为编辑（服务端实际仅拦截直播中）；守卫触发时业务原因不透出（按 500「系统异常」返回），须靠前置查询核验。
- 更新成功后回读列表；详情能力因敏感字段未开放。
- 删除直播间（🔴 不可逆）：仅对已结束/已过期且服务端允许的对象执行；会级联清理回放分片并物理删除外部点播媒资，须向用户明确告知并取得确认；执行后以分页查不到该对象核验。

## 主播查看与分类维护

- 主播仅开放启用中的简表与关联直播间查询，用于场次选择和影响梳理。`anchorId` 与会员 `userId` 不可混用。
- 主播创建、编辑、启停、删除均未开放；整理对象、期望动作与关联直播间后交由运营台处理，不猜测 capability。
- 分类停用/删除前用直播间分页按分类编码核对使用情况。停用不会自动迁移已有直播间。
- 分类删除按不可逆操作确认；执行后用分类列表核验对象已不存在。

## 场次排期

- 创建未开放；只能整理计划开始、结束、主播和有效时长，交由运营台创建后再查询。
- 编辑：只面向已排期场次；先从场次列表核对状态 0。任何时间、主播、有效时长变更均为商业影响写，逐字段复述确认。服务端还有同直播间时间段重叠与乐观锁并发守卫，冲突时刷新后重试。
- 取消：仅状态 0已排期 / 1准备中 可取消（准备中场次取消会释放直播间当前场次占用）；必须确认场次标题、直播间、计划时间和原因。取消后用场次列表确认状态 6。
- 不开放结束、恢复、禁播或开播准备。用户提出时转人工运营台，不组合其他能力模拟。

## 场次商品编排

1. 查询场次列表确认目标场次与状态，再查询现有场次商品。
2. 到商品域查询 SPU 与 SKU，核对：SPU 存在、SKU 属于该 SPU、规格可售、用户选择清晰。构造非空 `items:[{spuId,skuIds:[...]}]`；所有 ID 为字符串。
3. 添加前复述每个 SPU 与 SKU 清单；添加后回读场次商品。
4. 排序必须基于回读结果提交完整、不重复的 `sortedSpuIds`，不能只传移动项——未传入的 SPU 保持旧排序值，部分提交会产生顺序碰撞；服务端对未知 ID 与不存在的场次均静默成功。
5. 移除按不可逆商业影响确认；按 SPU 从目标场次移除，不代表删除商品域商品；移除不存在的商品静默成功，回读是唯一验证。
6. 修改 SKU 直播价/库存前核对 SKU 归属。null 只表示“不更新该字段”，不能用于清空或恢复默认；至少提交一个非 null 的非负数值，且具体数字必须来自用户。执行后回读对应 SKU——该修改不产生商品变更记录（变更记录仅覆盖房间维度价格/库存变更）。
7. 不开放 room 旧维度写入，也不开放“讲解中”切换。

## 直播复盘

- 总览/趋势/排行/旧场次统计用于宏观看板；场次数据中心用于单场复盘，禁止混算。
- 先查场次数据分页，再按 `sessionId` 查详情、五分钟趋势和商品转化。
- null（或字段缺失）表示未采集或不可用，不替换成 0。`paidAmountFen` 与 `totalAmount` 单位均为分，可按分换算为元并明确换算。
- 回放列表只能说明生成状态；不可取得或展示私有播放地址。
- 内容审核查询与处理均未开放：原始查询包含流名和审核截图，当前执行器无法裁剪敏感字段。

## 高危确认清单

- 删除：对象名称 + ID + 不可恢复提示。
- 排期：直播间 + 场次 + 主播 + 起止时间 + 有效时长。
- 商品添加/移除/排序：场次 + 完整 SPU/SKU 清单。
- 价格/库存：场次 + SPU + SKU + 原值（若可见）+ 新值/null 语义。
- 取消场次：场次 + 当前状态 + 计划时间 + 原因。

## 异常处理

- 权限不足：停止，不寻找其他能力绕过。
- 输入无效：对照契约修正一次；涉及用户未提供的价格、库存、时间或理由时询问用户。
- 超时：先查列表/商品现态；创建类可按标题+时间组合查重。
- 回读未变化：报告服务端未确认生效，不宣称成功。
