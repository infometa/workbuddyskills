> 以下能力均使用完整 `ops.trade.` 前缀；查询只取事实，写入必须遵守入口 SKILL.md 的风险档位。示例中的号码只是格式示意，不是可执行目标。

## 执行闭环

定位唯一对象 → 读取当前事实 → 判断适用状态与字段来源 → 确认具体影响 → 执行一次 → 回读核验。

- 多个候选对象：列出必要的业务差异请用户选定，不取第一条。分页翻完前不宣称不存在。
- 系统可读的 ID 和状态由读取结果取得；用户确认金额、数量、真实收货或服务事实，不要求用户猜系统标识。
- 写入前状态改变：重新说明影响。输入缺失、未知嵌套结构或未开放依赖：停止对应写入，明确缺什么。
- 超时、网络中断、返回不确定：先回读，禁止自动重复执行。追加备注、创建申请尤其不能盲重试。
- 回读仍不明确：报告“已提交，结果待核验”；不以列表延迟或空结果断言失败，不通过执行反向动作试探。
