# 通话处理量场景

用于销售经理查看团队或某员工在指定时间段内的电话过程量：拨打次数、接通次数、通话时长、接听量、联系客户数，并按指定指标排行（排行与衍生指标由 AGENT 本地计算，工具一次返回全部员工数据，无需分页）。

典型问题示例：
- "看下我们团队这个月的电话过程量，谁打得最多？"
- "小王上周的接通率怎么样？"
- "电销组本月有效通话排行前 10 是谁？"

## 场景工具

参数结构以工具 schema 为准，本文档不写死字段。

| 工具 | 用途 |
|---|---|
| whoami | 查询当前登录用户的简要信息（pid/did/姓名），用于确认当前登录身份 |
| findPersons / getAllPerson | 按姓名批量查找成员 / 获取部门（含子部门）或全公司成员，解析员工范围与 pid→姓名 |
| getCallStat | 按时间范围获取权限范围内员工的电话过程量统计（每人整个区间的聚合值，一次全量返回，按拨打次数降序） |

## 工作流

### 1. 确认身份与员工范围

先调用 whoami 确认当前授权账号：

- 用户指定了员工姓名时，用 findPersons 解析为 pid；用户指定部门/团队时，用 getAllPerson 解析成员范围（取 gid）。
- 用户未指定员工范围时，不传 pids/gids，查权限范围内全部员工。

### 2. 确认统计口径

向用户确认（用户未明说时按默认口径，不必反复追问）：

| 口径项 | 取值 | 说明 |
|---|---|---|
| 时间范围 | 必须明确 | 如"本月""上周"，换算为 GMT 毫秒时间戳（左闭右开） |
| 员工范围 | 默认权限范围内全部 | 姓名→pids，部门→gids |
| 有效通话 | 默认不启用 | 用户提到"有效通话"时，用 talkLenMin（如 1 秒以上算有效则传 talkLenMin=1）过滤单次通话时长；该过滤会同时作用于拨打/接通/时长等所有计数 |

### 3. 获取电话过程量

调用 getCallStat：

- 入参：statStime/statEtime（GMT 毫秒时间戳，左闭右开）、pids/gids（可选）、talkLenMin/talkLenMax（可选，秒）。
- **无需分页**：工具内部自动分批拉取全部员工，一次返回完整列表。
- 每个员工返回：pid、callAcnt（拨打次数）、callCustmCnt（拨打客户数，去重）、callScnt（接通数）、callLen（拨打总时长，秒）、roundCallLen（计费总时长，秒，拨打时长不足 1 分钟按 1 分钟计）、listenAcnt（接听电话数）、listenCustmCnt（接听客户数，去重）、listenLen（接听总时长，秒）。字段口径与业务端"我的通话统计"一致。

### 4. 计算排行与衍生指标并输出

getCallStat 只返回原始过程量，**排行与衍生指标由本地计算**（用户想按什么指标排就按什么排）：

- 接通率 = callScnt / callAcnt（拨打次数为 0 时记为 0 或 "-"）。
- 平均拨打时长 = callLen / callScnt（按接通算）或 callLen / callAcnt（按拨打算），输出时注明口径；平均接听时长 = listenLen / listenAcnt 同理。
- 日均拨打 = callAcnt / 区间天数。
- 排行：按用户指定的指标降序编号；未指定时默认按拨打次数。

pid 转姓名：用步骤 1 的 findPersons/getAllPerson 结果映射；映射不到的 pid 显示原始 pid 并提示。

输出示例（按拨打次数排行）：

```
名次  员工    拨打次数  接通次数  接通率   通话总时长  平均时长  联系客户数
1     小王    320      156      48.8%   5400秒      35秒      89
2     小李    280      120      42.9%   4200秒      35秒      76
```

### 5. 简要点评（可选）

- 结合排行与衍生指标指出：拨打量高但接通率低的（话术/号码质量）、接通率高但时长短的（通话质量）、拨打量明显偏低的（工作量）。
- 只基于已获取的数据点评，不编造；需要更多数据（如通话明细）时向用户说明本场景暂不支持。

## 常见异常

| 现象 | 处理方式 |
|---|---|
| 401 / 未授权 | 提示用户重新发起扫码授权（AGENT 会自动打开授权页） |
| getCallStat 返回空列表 | 输出"该时间范围内无电话过程量数据"（区间内无通话，或权限范围内无电销数据） |
| 员工不在返回列表中 | 服务端会剔除"无数据且不在电销成员配置内/已离职"的员工，属正常口径，向用户说明 |
| 某员工数据全为 0 | 该员工在电销成员配置内但区间内无通话，正常展示 0 值 |

## 注意事项

- **时间范围必须明确**：statStime/statEtime 为必填（GMT 毫秒时间戳，左闭右开），用户只说"本月"时按当前日期换算并复述确认。
- **无需分页**：getCallStat 一次返回全部员工，不要自己拼分页参数（schema 中没有 size/skip）。
- **排行口径**：用户说"排行"但未指定指标时，默认按拨打次数（服务端返回顺序即此排序），并在输出中注明；用户指定其他指标时本地重排。
- **有效通话口径**：默认 callScnt 即为接通次数（接通=状态为成功）；用户定义的"有效通话"如指时长门槛（如超 30 秒），才用 talkLenMin 过滤，且过滤后所有计数都会变化，输出时注明口径。
- **时长单位为秒**：callLen/listenLen/roundCallLen 均为秒，输出可换算为分钟但需注明。
- **计费时长**：roundCallLen 为计费口径（拨打时长不足 1 分钟按 1 分钟计），与实际拨打总时长 callLen 不同，输出时按用户语境选用。
