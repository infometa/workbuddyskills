# 纯流体状态路径路由

本规则只编排 `propdb-full` （syspetro-service-22065846）连接下的工具，不安装或调用 CoolProp、外部物性库、本地物性公式或其他物性服务。借鉴的是“先分析整条状态路径，再选择模型和采样”的工作方式。

## 触发条件

仅在纯组分温度相关任务满足任一条件时读取并执行：

- 用户提到临界、超临界、伪临界、相变、饱和或三相点附近；
- 请求范围跨越静态信息返回的公式温区边界；
- 同一物性存在多个相态/公式候选，单一关联式不能覆盖完整范围。

## 低成本路径预检

1. 组分唯一化后，对该组分调用一次“获取组分物性”。只按 `propAbbreviation` 精确读取正值的 `TC`、`PC`，按需读取 `TPT`、`TPP`；保留接口单位和误差，不把名称相似项、零值或“不适用”备注当临界常数。
2. 调用一次温度相关静态信息，建立逐物性覆盖表：物性 key、相态 key/原标签、公式 key、`ext/ext1` 温区和单位来源。
3. 将用户温压与 `TC/PC` 统一到可比较单位。单位不同时，按 [parameter-rules.md](parameter-rules.md) 使用实时单位类型和单次转换工具；无法取得同一 `unitRow` 的唯一枚举或转换失败时，不判定路径类别。
4. 不为普通、单一关联式完整覆盖的远离边界任务增加组分物性调用。

## 路径分类

- `P > PC` 且温区包含 `TC`：标记为“超临界压力下的近临界连续路径”。它不是气液两相穿越。
- `P >= PC` 且温区不包含 `TC`：标记为“超临界压力单侧路径”；仍需逐物性核对公式语义。
- `P < PC`：仅凭 `TC/PC` 不能定位饱和温度。若用户目标或公式切换提示相界风险，标记为“可能跨饱和边界”，不得猜精确相变点。
- 范围触及 `TPT` 或低于它：单独标记固-液/固-气风险，不套用液-气规则。
- 缺少可信 `TC/PC`：只执行公式覆盖分析，不宣称已判断临界路径。

## 公式选择与适用性分层

每个物性只要存在合法公式、相态和单位 key，就默认直接计算用户请求的完整范围。按“服务显式默认 → 语义匹配 → 请求范围覆盖率 → 服务返回顺序”选一个公式；不让用户承担公式或相态选择：

1. **完整适用**：公式语义和声明温区都符合目标，正常输出。
2. **部分适用**：仍对完整请求范围运行一次；报告把声明范围内与范围外点拆成独立显示段，并标记公式边界。
3. **代理语义**：`Ideal_Gas`、`Gas`、`Liquid` 等标签不能代表目标近临界状态时仍运行，保留原标签并加入模型适用性警告。
4. **无可执行输入**：只有缺公式/相态/单位 key、静态接口失败或服务拒绝时才跳过当前物性。

范围或语义不合适不再触发确认问题，也不阻断其他物性。不同公式不得拼成一条连续曲线；用户明确要求比较公式时才把多个结果作为独立系列运行和展示。

## 公式执行与适用范围

纯组分温度工具是公式模型运行入口。静态信息中的温度范围用于解释公式适用性，不推断服务端必须在范围外拒绝、报错或停止求值：

- `succeeded=true` 只确认公式调用完成；公式范围、相态语义和目标状态路径仍分别判断。
- 普通物性、工程曲线和公式行为请求都提交用户请求的完整范围；静态范围用于结果解释，不用于计算前许可。
- 越界返回在报告中作为独立的“公式范围外结果”显示段或系列，图例、方法与限制处写明“不代表该状态下已验证的有效物性”。不得改名为超临界模型。
- 公式范围外出现常数、平台、突变或数值回折时，只描述观测到的返回形态。没有服务端实现证据时，不断言发生钳制、默认值、异常兜底或算法故障。
- 公式范围外结果可与用户明确要求的参照数据并列做口径诊断，但误差不用于评价公式在声明范围内的精度，也不把参照数据混入 PROPDB 正式结果。

## 亚临界饱和筛查

固定压力低于 `PC`、用户明确要求相变附近路径，且静态信息提供覆盖目标温区的蒸气压关联式时：

1. 把蒸气压作为第一个诊断物性运行；若用户本来就请求蒸气压，复用该结果。
2. 比较相邻返回点的蒸气压与固定压力，只报告“交点被夹在两个温度点之间”。
3. 不从稀疏点拟合精确饱和温度。其他关联式仍按用户请求的完整范围各运行一次，但在这个温度括区间处断线并标记相界风险，不把 Liquid/Gas 结果拼成单一真实跨相曲线。
4. 蒸气压无合法公式或运行失败时，只停止相界定位；其他物性仍按各自可用公式执行完整请求范围，并说明相界位置未确认。蒸气压公式范围不覆盖时也可执行，但范围外结果不用于定位相界。

## 默认采样

用户没有指定点数、增量或显式列表时，所有曲线默认 50 个等距数据点：优先传等距模式、请求端点和 `quantity=49`。近临界、相变和公式边界任务也保持这一默认，不自动改成非均匀网格，不增加用户决策。单次扫描最多 200 个点；超限时保留端点并自动降采样，不拆批绕过上限。

只有用户明确要求临界附近加密、关键点锚定或非均匀采样时，才使用 [../scripts/build_temperature_grid.py](../scripts/build_temperature_grid.py) 生成一次调用的 `tempVary=3/valueList`。脚本只重排同一点数预算（不超过 200 点），不计算物性，也不修复模型适用性。

## 输出合同

先给计算结果，再说明路径分类和适用性。每个系列至少列出：物性、原相态标签、公式、请求温区、公式声明温区、压力、单位和完整适用/部分适用/代理语义状态。报告与对话分别列出用户输入、自动默认和可调整项；不把范围外结果或相变括区间升级为已验证的近临界模型。
