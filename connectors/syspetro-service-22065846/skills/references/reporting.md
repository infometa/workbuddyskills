# PROPDB （syspetro-service-22065846）曲线图片、多曲线 HTML 与结果数据导出

## 1. 先按独立曲线族分类

成功取得有效主数据后，先数“独立物性或业务曲线族”，不要数 SVG 中的线条、公式系列或相态分段：

| 结果形态 | 判定 | 默认交付 |
| --- | --- | --- |
| 单一曲线 | 一个物性或一个扫描目标；同一坐标中的多压力、多公式、液/气支线或范围内外系列仍算一个 | 一张单面板 SVG 图片，不生成 HTML |
| 同族耦合曲线组 | 同一业务族中共同回答一个目标的固定组合；当前明确包括同一二元体系的 Txy+Pxy | 一张双面板 SVG 图片，不生成 HTML |
| 多曲线集合 | 两个及以上独立物性或业务曲线族；包括“全部/所有可用物性曲线”和用户通过对话明确选中的多个不同曲线类别 | 一个离线 HTML 报告及一个同源 XLSX；每个独立单位/曲线族各占章节/工作表 |

用户明确要求 HTML、网页报告或正式报告时，即使只有一个曲线族也按显式要求进入 HTML：单曲线使用 `calculation-result`，`property-curve` 仅用于两个及以上独立曲线族。多曲线集合默认必须生成 HTML；用户另外明确要求图片时，可以在 HTML 之外附带各曲线 SVG，但不能用一张拥挤的多单位图片替代报告。

曲线任务优先使用本节规则。不要因为它同时属于混合物分析、二元相平衡、纯组分温度计算或其他实质计算，就套用普通计算结果的自动 HTML 规则。非曲线实质计算、有多对象/多字段结果集或用户明确要求报告时，仍可生成 `calculation-result` 或 `query-result` HTML。

所有曲线缺省采用 50 个等距数据点，单次扫描最多 200 个数据点。用户请求超限时保留端点并自动降采样到 200 点，在条件和结果中披露请求点数与实际点数；不拆批绕过上限，也不为点数增加确认问题。

## 2. 数据门禁

目标未命中、无权限、工具失败、无解、只有错误包装或没有至少两个有效业务点时，不检测渲染环境，不生成成功图片或报告。部分结果仍足以回答主问题时可以生成 `partial` 图片/报告，但必须说明实际影响。

只投影已允许展示的 MCP 业务字段、用户输入和不新增事实的 Agent 摘要。不得写入原始响应、工具名、认证信息、端点、错误堆栈、`siM_LEVEL`、`proP_LEVEL` 或其他内部调优字段。

两个数据合同都只作生成中间层，默认不交付用户：

- 单一/同族曲线组：`assets/chart/curve-image-data.schema.json`，模板 `propdb-curve-image-v1.0`；
- 多曲线或其他 HTML：`assets/report/report-data.schema.json`，模板 `propdb-report-v1.1`。

## 3. 单一与同族曲线组：SVG 图片

按以下固定快速路径生成：

1. 将本次已验证曲线一次性投影为 `curve-image-data 1.0`；不得启动子代理、按点分析或复制完整原始响应。
2. 运行 `python3 scripts/render_curve_image.py --self-check`。不得安装 Python、第三方绘图库、浏览器、Node 或联网依赖。
3. 自检成功时优先经标准输入执行 `python3 scripts/render_curve_image.py --input - --output <新文件.svg>`。数据校验错误最多修正一次；脚本或资源失败时不现场修改运行时文件。
4. 宿主没有可用 Python、但能够创建文件时，直接按相同数据合同和 `assets/chart/curve-image.css` 一次性生成静态 SVG；不得改成 HTML，也不得输出示意图。
5. 最终只交付 `.svg` 图片和聊天中的关键结论；不生成网页、图片数据 JSON 或临时文件。

SVG 固定要求：

- `single-curve` 恰好 1 个面板；`coupled-curve-group` 恰好 2 个面板；超过 2 个面板必须重新判定是否属于多曲线 HTML；
- 采用 PROPDB 蓝青视觉、深炭灰品牌栏、固定字体栈、网格、坐标轴、图例和边界标记；
- 图中显示分析对象、范围、单位集、生成时间、用户输入与自动默认条件、可调整项；`partial` 时显示实质性适用性说明；
- 使用 MCP 成功返回的真实 x/y 值；每条序列至少 2 个有效点，保持返回点序；
- 二元 Txy/Pxy 面板必须同时绘制液相线（泡点线）和汽相线（露点线）。优先从 `items` 中成对读取 `liquid_MOLEFRAC_n`、`vapor_MOLEFRAC_n` 与 `temp/pres`；服务的 `series` 只有一条时不得直接当作完整二元曲线；
- 当两相横坐标不同，使用两相真实横坐标的排序去重并集；各系列只在自己的坐标位置填值，其余位置填 `null` 断线，禁止插值、平滑或复制另一相。并集仍限制为 200 个成图点，超限按端点优先等距抽取并标注；
- `null`、失败点、两相区和公式/相态边界必须断线；不平滑、不拟合、不插值、不补点；
- 不同 y 单位不得放进同一面板。Txy 与 Pxy 因 y 单位不同而使用双面板，但仍属于一个二元相平衡曲线组；
- 最终 SVG 无 JavaScript、外部 URL、远程字体、外部图片或中间 JSON，拒绝覆盖已有文件。

用户明确要求 PNG/JPEG 时，不安装转换工具。宿主已有经过验证的离线 SVG 转换能力时可转换一次；否则交付 SVG 并简要说明它是可直接查看、缩放和插入文档的图片格式，不为格式选择追问用户。

## 4. 多曲线集合：HTML 报告

借鉴 CLEVA 的“紧凑数据 → 固定模板 → 确定性组装”方式，当前 PROPDB 使用一次投影加 Python 标准库渲染器作为快速路径：

1. 同一执行链内将全部曲线一次性投影为紧凑 `report-data 1.1`。不得启动子代理、为每个物性单独生成 HTML、反复遍历宽响应或让另一模型润色整页。
2. `report.type=property-curve` 时必须声明 `curveFamilyCount`，值为 2–12；曲线章节数不得少于该数量。Txy+Pxy 本身只算一个曲线族，不应单独进入本路径。
3. 运行一次 `scripts/render_report.py --self-check`；成功时优先经标准输入生成单文件 HTML。相同数据确定性生成相同正文结构。
4. 确定性路径不可用但宿主能创建文件时，读取 `assets/report/report-static-template.html`，沿用固定设计 token、曲线目录、章节结构和安全规则一次性生成；不在写出后反复完整读取和重写。
5. 最终 HTML 离线可打开，无 JavaScript、外部资源或网络请求；不向用户交付中间 JSON。

多曲线 HTML 固定框架：

```text
深色品牌栏与 PROPDB 蓝青强调线
标题、对象、范围、单位集和生成时间
2–4 条结论摘要
曲线总览：固定索引到每个曲线章节
2–8 项关键指标
计算条件：区分用户输入与自动默认
每个独立物性/业务族的曲线、图例和默认折叠的同源数值表
方法与口径、实质性限制、可调整项
```

不同 y 单位必须使用独立曲线章节，不使用多 y 轴、归一化综合分数或跨单位叠图。公式覆盖不完整或只有代理语义时仍展示完整请求范围，但报告标记 `partial`，并把声明范围内与范围外点拆成独立显示段；范围外系列名称和限制必须说明它不代表该状态下已验证的有效物性。

`property-curve` 报告至少包含两个独立曲线族；计算条件表必须用键为 `source` 的列把每行标成“用户输入”或“自动默认”；同时包含标题严格为“可调整项”的章节。固定渲染器自动生成曲线总览，不让 Agent 手写导航 HTML。

每个曲线章节的数据表必须使用原生 `<details>/<summary>`，默认不带 `open`，用户点击“查看数据表”后展开；不添加 JavaScript。打印样式隐藏折叠控件并完整显示表格。条件、指标和短结果表保持直接展示。品牌栏只显示真实公司 Logo、“辛孚科技”和“PROPDB 物性数据库”；右侧只显示 `PROPDB REPORT`。报告不显示 schema/template 版本、范围说明或其他页脚小字。

## 5. CSV/XLSX 导出

脚本同时接受 `curve-image-data 1.0` 与 `report-data 1.1`：

- 单一数据集可直接导出 UTF-8 BOM CSV；多个面板、表格或曲线时，CSV 必须用 `--dataset N` 指定一个数据集；
- 多曲线 HTML 默认输出同名 XLSX，每个曲线面板/结果表使用独立工作表，不询问用户是否需要；用户明确拒绝数据文件时跳过；
- 单曲线/同族 SVG、普通查询或计算报告仅在用户明确要求数据文件时导出；单一数据集可选 CSV，多个数据集或明确要求 Excel 时输出 XLSX；
- SVG、HTML、CSV 和 XLSX 必须来自同一组已验证曲线数据，点序、数值、空值和单位完全一致；
- 不从图片像素或 HTML 反取数值，不重新计算，不生成公式、宏、外链或隐藏工作表；

## 6. 安全与交付检查

用户可见 SVG 和 HTML 统一使用 `PROPDB` 产品名。标题、品牌栏、图例、章节、表格和图片说明不得出现内部版本称呼、接口数量、连接命名空间、Skill 名、技术工具名或未请求的功能选项。

所有 MCP 和用户文本必须先经过 XML/HTML/CSV 安全处理。交付前只做一次轻量检查：

1. SVG 含 `propdb-curve-image-v1.0`、真实 path、坐标单位、图例、默认条件和可调整项，且无外部 URL、脚本或占位符；
2. 多曲线 HTML 含 `propdb-report-v1.1`、曲线总览、至少两个独立曲线章节、静态 SVG、默认折叠同源数值表和默认条件披露，并同时生成同源 XLSX；
3. `partial` 交付包含实质性限制；
4. CSV/XLSX 与源曲线数据的行数、列名、点序、单位和数值一致；
5. 只交付最终 SVG、HTML、多曲线默认 XLSX 及用户明确要求的其他数据文件，不交付中间 JSON。
