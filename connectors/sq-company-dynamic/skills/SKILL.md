# 上奇产业通-企业动态追踪

上奇产业通-企业动态追踪技能，提供企业全生命周期的动态事件流监控能力，覆盖上市进展、行业榜单、资质认定、投资扩张、项目中标、工商变更、区域迁移、人才招聘、知识产权、土地购置、股权变动、创新平台及标准制定等 13 个关键维度的近期动态。旨在帮助用户实时掌握企业最新发展动向，捕捉商业机会或预警潜在风险。

## 可用工具

### get_company_listing_events - 企业上市动态查询

查询企业上市相关动态事件，包含国内A股上市、海外上市等详情。用于了解企业的融资渠道拓展、资本市场表现及上市进程。

**参数说明**：

| 参数         | 类型    | 必填 | 说明                                 |
| :----------- | :------ | :--: | :----------------------------------- |
| credit_code  | string  |  -   | 企业统一社会信用代码                 |
| company_name | string  |  ✅   | 企业完整名称（与信用代码二选一提供） |
| month        | integer |  -   | 回溯月数（1-24，默认6）              |

**使用示例**：

- **资本运作监控**：查询某拟上市公司最近6个月是否有提交IPO申请或辅导备案的动态。

## 注意事项

- **时间窗口限制**：除 `get_company_migration_overview` 外，绝大多数动态查询工具均包含 `month` 参数，用于指定回溯时间范围（1-24个月），默认值为6个月。请根据分析需求合理设置，避免数据量过大或遗漏关键信息。
- **参数互斥**：所有工具均支持 `credit_code`（信用代码）或 `company_name`（企业名称）作为入参，二者选其一即可。为确保数据精准匹配，建议优先使用统一社会信用代码。
- 动静态结合：
  - **知识产权**：建议结合 `get_company_ipr_events`（动态新增）与 `get_company_ipr_assets`（静态存量）使用，全面评估技术实力。
  - **创新平台**：建议结合 `get_company_innovation_platform_events`（平台资质）与 `get_company_innovation_relations`（合作关系）使用，深入分析研发生态。
- **迁移分析互补**：`get_company_migration_overview` 侧重于单个企业的历史迁移轨迹，若需分析整个产业的迁移趋势，请配合 `analyze_industry_migration_metrics`（产业迁移监测）使用。
- **URL中的路径标识**：mcp.json 中 URL 为 https://api.chanyedata.com/mcp/c3f5924cc60dbe1729f5cc332e627304/mcp，其中 32 位字符串 c3f5924cc60dbe1729f5cc332e627304 是服务端分配给本连接器的路由标识（Route ID），用于服务端将请求路由到正确的 MCP Server 实例。该标识为非敏感信息，所有安装本 Connector 的用户均使用相同的路由标识，不构成安全风险，非密钥/令牌，因此以明文写入配置属于预期行为（"硬编码"实为服务端分配的公开路由参数）。
