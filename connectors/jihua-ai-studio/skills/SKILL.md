# 极画AI设计室

本 Skill 指导 AI 使用极画AI设计室的 MCP 工具。工具访问的是当前已授权的极画账号，不接受或传递 `userId`。

## 可用工具

| Tool | Scope | 用途 |
|---|---|---|
| `jihua_get_profile` | `profile.read` | 查看当前账号昵称、头像和用户编号 |
| `jihua_get_points_balance` | `points.read` | 查看当前积分余额 |
| `jihua_list_works` | `works.read` | 分页查看当前账号作品 |
| `jihua_list_generations` | `generations.read` | 分页查看自由创作任务 |
| `jihua_get_generation` | `generations.read` | 查询一个创作任务的状态、进度、扣费和结果 |
| `jihua_create_image` | `generations.create` | 提交纯文生图任务，会消耗积分 |

## 参数

查询列表工具支持 `status`、`pageNo`（默认1）和 `pageSize`（默认20，最大50）。

`jihua_get_generation` 必填 `creationId`。

`jihua_create_image` 参数如下：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|---|---|:---:|---|---|
| `prompt` | string | 是 | - | 创作描述，最多4000字符 |
| `outputCount` | number | 否 | 1 | 生成数量，1至4 |
| `imageRatio` | string | 否 | `1:1` | 支持 `1:1`、`16:9`、`9:16`、`4:3`、`3:4`、`3:2`、`2:3`、`5:4`、`4:5`、`21:9`、`9:21`、`1:2`、`2:1`、`1:3`、`3:1` |
| `resolution` | string | 否 | `1K` | `1K`、`2K`或`4K`，分辨率越高通常消耗积分越多 |
| `requestId` | string | 否 | 自动生成 | 重试同一请求时必须复用，最多64字符 |

## 使用规则

- 首次使用前完成 WorkBuddy OAuth 授权。Token 过期时提示用户重新连接，不要求用户填写 Token。
- 查看积分、作品和任务不会创建任务，也不会消耗积分。
- 只有用户明确要求生成图片时才调用 `jihua_create_image`。调用前说明会按极画AI现有规则消耗积分；不要因推荐、查询或失败自动创建。
- 生成参数不完整时，先引导用户选择并等待确认，禁止直接猜测参数后提交。至少确认以下三项：生成数量、图片比例、分辨率。用户已经明确给出的参数不再重复询问。
- **优先依赖服务端参数表单**：如果客户端支持 MCP 表单交互，调用 `jihua_create_image`（不传参数）就会自动弹出比例/张数/分辨率的选择表单，用户提交后工具直接完成提交。此时不要在对话里再重复问一遍参数，直接调用工具把表单交给用户操作即可。用户关闭表单时工具返回"未提交、未消耗积分"，如实转述，不要自行重试。
- 若工具返回 `confirmation_required`（说明当前客户端不支持表单），改用下面的文字确认格式；数量默认只能推荐为1张，不能把"做一张图""生成一个风景照"等自然语言误解为多次提交：
  ```text
  我可以帮你生成。请确认以下参数（生成会消耗积分）：
  - 数量：1张（可选1-4张）
  - 比例：1:1（可选16:9横图、9:16竖图、4:3、3:4、3:2、2:3、5:4、4:5、21:9、9:21、1:2、2:1、1:3、3:1）
  - 分辨率：1K（可选2K、4K，通常分辨率越高消耗越多）
  回复“确认”或直接修改以上参数即可。
  ```
- 用户仅说“生成图片”或描述过于笼统时，先询问图片内容和上述参数；在用户确认前不得调用工具。
- 一次用户生成请求最多调用一次 `jihua_create_image`，即使模型认为多个版本更合适也必须先询问用户数量，不得拆成多次调用。提交后如需等待，只能使用 `jihua_get_generation` 查询，不能再次创建。
- 调用前再次复述最终参数；只有用户明确确认后提交。若用户在确认后修改参数，视为新的待确认请求，仍需先确认再提交。
- 创建工具立即返回 `creationId`。不要等待创建调用本身完成图片生成。
- 需要等待结果时，首次约等待5秒，再按约10秒间隔调用 `jihua_get_generation`。状态为 `SUBMITTED`、`GENERATING`或`SETTLING`时继续查询；`SUCCESS`、`FAILED`或`VIOLATION`时停止。最多跟踪5分钟，超时返回 `creationId` 并说明任务可能仍在后台执行。
- `SUCCESS` 时展示结果图片 URL；若成功数少于请求数，同时说明失败数和退款积分。
- 遇到积分不足、权限不足、参数错误、授权失效、违规或生成失败时，直接解释原因，不暴露内部异常或供应商信息。
- 网络超时或不确定是否提交成功时，使用同一个 `requestId` 查询或重试，禁止生成新的 requestId 导致重复扣费。
