# 万方文献检索与下载

通过本连接器的两个 MCP 工具完成检索和下载；当前开放期刊和学位论文的全文下载，且必须先通过全文核验。其他资源待服务端开放并在运行时工具定义中明确后再纳入流程。**一次检索** 是默认策略：同一用户请求只发起一次检索调用，并完整复用该结果。

## 1. 确定工具与目标

使用当前会话已提供的工具定义识别检索工具和下载工具。调用名、参数、资源类型和格式以运行时 schema 为准。

- 仅检索：用户泛称“检索文献”“找论文”“查学术资料”时即可使用本连接器；根据其提供的主题、题名、作者或文献标识检索。
- 期刊分析：用户提及“期刊发文趋势”“历年发文量”“期刊影响因子变化”时即可使用本连接器。使用检索结果中的年份和期刊字段统计；影响因子仅在结果明确返回对应字段时分析。
- 下载：确定用户指定的条目或批量范围。明确要求下载的唯一匹配条目直接继续；多个候选且无法确定目标时，展示候选供用户选择，不继续检索。用户给出的文献标识已明确为专利、会议、标准或其他当前未开放资源时，直接说明当前仅开放期刊和学位论文下载，不调用检索或下载工具。
- 用户仅要求检索时，交付检索结果后结束。

完成条件：已识别两个工具及必填参数，并确定本次操作范围。

## 2. 检索并核验全文

先构造一个覆盖用户条件的检索请求，再调用。若支持 `returned_fields`，在该次调用中一并请求展示字段及 `Id`、`Type`、`HasFulltext`；默认返回字段可能不含全文判定字段。用户没有指定数量时，使用工具允许的适中结果数（优先 10 条，或最接近的更小支持值），避免无目的地获取大量结果。

期刊趋势分析时，在这一轮检索中同时限定期刊和用户要求的时间范围，并使用工具允许的最大单页结果数。根据返回记录的年份统计发文量；若结果不足以覆盖时间范围，明确说明结论基于已返回的样本，不翻页或补查。仅当运行时 schema 支持且结果确实返回影响因子字段时，才分析影响因子变化；否则说明“当前检索结果未提供影响因子数据”。

检索结果是本轮唯一的判断依据：下载目标已有同一条目的字段时直接复用。用户仅给出文献 ID、链接或题名时，以该标识构造这一次精确检索；返回记录仍缺少判定字段时，标记为“无法确认全文”，不发起补查、翻页、改写关键词或重试。

逐条应用以下全文门槛：

| 资源类型 | 通过条件 |
| --- | --- |
| 期刊、学位论文 | `HasFulltext` 为布尔值 `true` |
| 其他类型 | 当前未开放全文下载，不核验全文，也不调用下载工具；服务端开放后，以新的运行时工具定义和全文条件更新本规则 |

- 通过：允许进入下载步骤；全文存在仍以服务端权限和下载结果为准。
- 不满足：跳过下载，说明该记录暂无可下载全文。
- 未知：补查后仍缺字段、值为 null、类型不明或没有适用规则时，说明无法确认，跳过下载。只有工具说明明确约定时才转换字符串或数字形式的布尔值。
- 未开放：资源类型不是期刊或学位论文时，说明“当前仅开放期刊和学位论文全文下载”，跳过下载。

不得通过试调用下载工具来探测是否有全文。标题、摘要、DOI 或文献 ID 的存在不能替代全文门槛。一次检索返回零结果、结果不唯一或未包含所需字段时，如实告知用户；只有用户补充条件、选择候选或明确要求再次检索时，才开始新的检索调用。

完成条件：检索结果已对应用户条件；下载范围内每条记录均已归为通过、不满足、未知或未开放，并保留判定字段作为依据；本轮没有额外检索调用。

## 3. 下载通过核验的条目

仅对用户要求下载、资源类型为期刊或学位论文且通过门槛的记录调用下载工具。

1. 在当前会话中保存“检索结果序号—原始标识”的内部映射。用户按序号或唯一题名选择下载时，取对应原始标识；只有 schema 明确要求时，才按其资源类型映射组装 `docId`（如“资源类型_文章ID”）。已有完整前缀的标识原样使用，不向用户展示。
2. 当前下载工具参数如下，仍以连接时的 schema 为准：
   - `docId`：必填字符串，使用检索结果中的原始文献标识；其格式为“资源类型前缀_文章 ID”。
   - `format`：可选字符串，接口默认 `markdown`；支持 `pdf`、`json`、`markdown`、`docx`。本 skill 默认下载 PDF：用户未指定格式时显式传入 `pdf`；用户明确要求 Word、JSON、Markdown 或其他支持格式时传入相应值。
   - `image`：可选布尔值，默认 `false`。仅在用户明确需要文中插图、图表或图片时传 `true`。
   不添加 schema 未声明的参数；若运行时 schema 增加必填参数，按其定义填写。
3. 批量下载逐条核验、调用并记录结果；单条文献失败后继续处理其余符合条件的条目；余额不足时按下一节处理。

完成条件：每条通过核验且被要求下载的记录，都有对应的工具响应或明确的调用失败原因。

## 4. 面向用户的结果展示

使用清晰的中文展示结果，不输出 `HasFulltext`、`SourceDB`、HTTP 状态码、工具参数、`docId` 或原始响应 JSON。原始文献标识仅在会话内用于后续下载。

检索结果使用以下格式，按相关性排序，默认最多展示 10 条：

| 序号 | 文献 | 作者 | 来源与年份 | 全文 |
| --- | --- | --- | --- | --- |
| 1 | 题名 | 作者或“未提供” | 期刊/学位/会议名称，年份 | 可下载 / 暂无全文 / 无法确认 / 暂未开放 |

结果超过展示上限时，说明“共找到 N 条，以上展示前 10 条”。用户可说“下载第 3 篇”或提供唯一题名；使用序号下载时复用本轮保存的内部映射，不再次检索。不要展示、解释或要求用户输入下载标识。

期刊趋势分析使用“年份｜发文量”表格，并注明统计时间范围、返回记录数和数据范围。影响因子有有效字段时，另列“年份｜影响因子”；没有字段时只说明数据未提供，不估算或引用外部数值。

下载结果按文献逐条展示：

- 成功：`《题名》：已生成 PDF 下载链接。` 其他格式如实说明文件格式；文件名、大小和有效期仅在服务端提供时展示。
- 未下载：`《题名》：暂无可下载全文。` 或 `《题名》：无法确认全文可用性。`
- 暂未开放：`《题名》：该资源暂未开放全文下载，当前可下载期刊和学位论文。`
- 失败：`《题名》：下载未完成，原因：…`，将服务端原因转换为简明中文。
- 余额不足：`当前账户余额不足，请前往[万方 MCP 套餐购买页面](https://my.wanfangdata.com.cn/user/mcp/sale/index)购买套餐后再重试。`

## 5. 交付结果

读取 MCP 内容项（通常位于 `content` 或响应封装的 `result.content`）。成功响应对应 PDF、JSON、Markdown 或 DOCX：PDF、JSON、DOCX 的文件流以服务端下载链接交付；Markdown 可直接交付正文。以实际返回内容为准：

- `resource_link`：直接交付服务端资源链接，原样使用 `uri`，保留 `name`、`mimeType` 及可用的 `size`、`_meta`。PDF、JSON 或 DOCX 的资源链接均表示文件已可下载，即使外层是 JSON 也算交付成功。链接交付与保存到本地分别报告。
- 若 `_meta` 包含 `cn.com.wanfangdata.gateway/expiresAt`，说明实际有效期；没有则省略有效期。
- Markdown 正文：直接交付 Markdown 内容，并说明已获取 Markdown 全文。
- 图片内容：仅在请求 `image: true` 时交付服务端返回的文中插图或图片链接，并保持与正文的对应关系。
- 其他文件或正文：按实际 MIME 类型交付并如实标明格式。
- 余额不足：接口明确返回余额不足（包括 HTTP 452 或响应中的余额不足错误）时，停止本次后续下载及替代格式重试，按上一节的提示告知用户。已完成的结果正常交付，剩余条目标记为“余额不足，未继续下载”。
- 错误响应：优先读取服务端错误码，按下表转为用户提示；不要把状态码或错误码直接展示给用户。

| 服务端错误码 | 用户提示 |
| --- | --- |
| `parameterEmpty`、`docIdFormatError` | 文献选择信息不正确，请从检索结果中重新选择文献。 |
| `paperNotFound` | 未找到该文献，请确认所选题名或序号。 |
| `fulltextNotFound` | 该文献暂未提供可下载全文。 |
| `userExpired` | 当前机构交易账号已过期，请联系所属机构处理后再试。 |
| `moneyNotEnough` | 当前账户余额不足，请前往[万方 MCP 套餐购买页面](https://my.wanfangdata.com.cn/user/mcp/sale/index)购买套餐后再重试。 |
| `downloadError` | 下载服务暂时不可用，请稍后重试。 |

错误码未在表中或缺少可交付内容时，报告服务端提供的实际原因；不要自动重试或自动改用其他格式。用户明确要求其他格式且工具支持时，才发起新的下载调用。

完成条件：检索和下载均按上一节的面向用户格式展示，覆盖全部请求范围；原始链接和服务端提供的文件元数据已如实交付。
