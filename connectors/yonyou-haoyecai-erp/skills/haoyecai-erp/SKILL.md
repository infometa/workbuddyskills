# 用友好业财 ERP 连接器使用指南

## 适用范围
用户明确提出查询或处理好业财 ERP 中的采购、销售、库存、生产、项目、财务、往来及报表业务时使用。所有结果以实际 MCP 返回数据为准，不得编造。

## 必须遵守的调用顺序
1. 首先调用 `accountingOpenapiCcAiBookQueryV1` 获取用户有权访问的账套及 `book-id`，如存在多个账套，先让用户选择，不得擅自跨账套查询。
2. 不确定接口或业务动作时，调用 `accountingOpenapiCcAiOperateGuide` 按关键词检索接口及调用说明。
3. 不了解业务对象（BO）及字段时，调用 `accountingOpenapiCcAiQueryboV60` 获取定义；尽量只查询 `id`、`name`、`code` 等必要字段。枚举字段以 `Enum{label value}` 形式查询，外键字段以 `Id{id name}` 形式查询（以实际 schema 为准）。
4. 查询业务单据、档案及其他业务事实时，按工具返回的调用说明使用 `accountingOpenapiCcAiExcutefn`。
5. 查询经营报表前，先调用 `accountingOpenapiCcAiQueryDesc` 获取报表定义，再调用 `accountingOpenapiCcAiQueryreport` 查询报表数据。
6. 明确标注账套、时间范围、查询条件、数据来源及是否成功；没有数据时说明无结果，不推断为零。

## 安全与确认
- 仅在用户授权范围内调用；不得泄露 API Key、Token、个人敏感信息。
- 创建、修改、删除、提交、审核等写入动作前，先说明操作对象、关键字段及影响并取得用户明确确认；未确认不得执行。
- 不自行推断接口参数或构造未经 schema 验证的操作。
- 若授权过期，提示用户重新连接；若无账套权限，停止操作并说明原因。
- 超时或接口报错时，展示可理解的错误；对非幂等写操作不得盲目重试。

## 典型问法
- “查询本月销售收入和应收情况。”
- “查一下这个商品当前库存。”
- “帮我看某张采购订单的执行情况。”
- “查询某个生产订单的材料损耗率。”
- “查看本季度项目成本报表。”

## 输出建议
优先给出简明结论、关键数据、查询范围与来源。报表数据注明统计口径；未能核实的计算指标须明确说明。实际工具参数和返回结构由 MCP 动态发现，不在本文件中假设。
