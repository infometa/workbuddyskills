# Moka 组织

以人事与组织管理视角查询组织数据，全部只读。只编排以下两个工具：

- `mcp__moka__search_org_entities`
- `mcp__moka__get_org_management_info`

## 选择工具

组织主数据用 `mcp__moka__search_org_entities`，覆盖部门、职位、职务、职级、成本中心、项目组六类实体：

- 按名称消歧：名称可能重复时先消歧，换取唯一标识。
- 分页清单：含停用清单、空部门等专项清单，可按关键词与启停用状态筛选。
- 单实体详情：按消歧或清单返回的标识查详情，可带版本日期看历史版本。
- 局部树：以某节点为根逐层下钻（部门、成本中心、项目组支持树形浏览）。
- 变更记录：查某实体改过哪些内容。
- 动作必须与实体类型匹配，可用组合以工具实时 description 为准。

适用于「查找某个部门」「盘点停用项目组」「查看某成本中心的局部树」等问题。

编制、汇报关系与调整方案用 `mcp__moka__get_org_management_info`，按信息类别（view）选择：

- 编制：编制记录 → 编制详情 → 编制变更记录，可按周期名称与范围（全部/按周期）查询，支持只看计划编制数大于 0 的记录。
- 汇报关系：汇报关系列表（按汇报口径筛选），以及以某员工为根、可控展开深度的局部关系图。
- 组织架构调整：调整方案中的子部门、员工（可按直属上级、职务、办公地点、任职类型筛选）、职务、办公地点，以及方案的架构预览与预览下的员工。

适用于「查当前编制」「看某人的汇报关系」「查看调整方案里的直属员工」等问题。

易混辨析：「组织主数据」是现状的静态台账（有哪些部门/职位/成本中心），「组织管理信息」是围绕人和编制的管理视图（编多少人、谁向谁汇报、调整方案打算怎么改）；用户问「现在架构长什么样」用主数据的树与清单，问「架构要怎么调」用调整方案视角。

员工个人档案、花名册名单、考勤薪酬等非组织数据的问题，不要用本技能的工具。这些问题应由当前可用的其他 Moka 工具处理。

## 调用规范

1. 使用 Moka 连接器提供的工具（本技能内的工具名即实际注册名）；连接器未安装或未连接时如实告知用户，不改用其他来源。
2. 通过当前平台的工具发现能力读取实时 description 与参数 Schema，以它们为入参事实源。
3. 只传用户明确给出的条件，不自行扩展生效日期、版本日期或启停用筛选。
4. 主数据的查询顺序：
   - 名称可能重复时先调用对应实体的消歧动作；消歧只在候选总数恰好为 1 时选中实体，多候选必须由用户确认。
   - 拿到唯一标识后再查详情、局部树或变更记录；各类标识必须来自对应消歧或清单结果，禁止手写或猜测。
   - 局部树用展开深度与节点数上限控制体量，需要更深层级时以已返回节点为根继续下钻，不要一次性索取全树。
5. 编制的查询顺序：
   - 先查编制记录；编制详情与编制变更记录所需的定位字段（维度拆解标识、周期标识等）来自编制记录的返回项。
   - 周期名称缺省时使用唯一默认周期，存在多个周期时向用户确认。
6. 汇报关系图的根员工标识需来自已唯一确认的员工记录；展开深度有限，逐层扩展而不是猜测层级。
7. 调整方案的查询顺序：
   - 先确定方案（`schemeId`），再查方案内的部门、员工、职务、办公地点或架构预览。
   - 审批中的方案需要额外的实例标识，已完成方案不传。
   - 方案内筛选（直属上级、职务、办公地点）使用方案内查询返回的标识。
8. 列表结果按页返回，只汇报实际取到的范围；有下一页时递增页码继续查询。
9. 相对日期先按用户所在时区换算成绝对日期再调用，回答里说明实际使用的日期。

## 结果与权限

- 空结果只表示本次未返回数据，不代表没有查看权限，不得反推，也不要断言「确实没有」。
- 工具返回的 notices 与 message 如实转达，先读 notices 再组织回答。
- 结果受当前账号在 Moka 中的数据与功能权限约束，各类查询分别校验权限；无权限时如实转述提示，不要绕行。
- 调整方案是「方案内容」而非既成事实：架构预览与方案内名单描述的是调整后的目标状态，转述时说明这是方案数据；本技能不提供方案的操作记录与变更记录。
- 变更记录如实按返回内容转述变更前后值，不要推断变更原因。

## 安全边界

- 不向用户展示访问令牌、内部标识符或原始技术响应；部门、方案、编制等标识句柄只用于串联工具，不出现在回答里。
- 不虚构工具未返回的字段；电话、证件、头像等隐私字段与内部标识不会出现在结果中，不要向用户许诺提供。
- 调整方案与编制属于组织敏感信息，只在用户为管理目的提问时使用，不扩散与问题无关的方案内容，不把调整安排转述给无关的人。
- 全部只读：不新增、修改、删除或审批任何组织数据与调整方案；用户要改数据时引导其在 Moka 页面操作。
