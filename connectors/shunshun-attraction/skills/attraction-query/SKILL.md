# 景点数据查询

通过 MCP 工具访问景点库，覆盖全球城市景点数据。适用于行程规划、景点清单整理、城市景点概览。

## 连接时填写的配置

连接器只要求用户填写一项：

| 字段 | 含义 | 用途 |
| --- | --- | --- |
| `SSLQAPITOKEN` | 接口 Token | 请求鉴权，随请求头发送 |

国家与城市**不在连接时配置**，由用户在每次查询时通过对话说明，agent 转换为工具参数传入。

## 可用工具

### query_attractions — 查询景点（推荐）

按国家 / 城市检索景点，返回结构化清单（同时提供 `structuredContent` 便于程序化使用）。

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| country | string | 推荐 | 国家中文名称，如「法国」。由用户在对话中说明后传入 |
| city_name_cn | string | 推荐 | 城市中文名称，模糊匹配，如「巴黎」。由用户在对话中说明后传入 |
| city_name_en | string | 否 | 城市英文名称，模糊匹配，如「Paris」 |
| weekday | string | 否 | 按开放日过滤，支持 `MON` / `周三` / `3`（1-7 对应周一至周日） |
| limit | number | 否 | 最多返回条数，默认 50；传 `0` 表示不限制 |

典型用法：用户说「查一下巴黎的景点」→ 传 `city_name_cn=巴黎`；「日本东京周三开放的景点」→ 传 `country=日本, city_name_cn=东京, weekday=周三`。

返回字段：`attraction_name_cn` / `attraction_name_en`、`latitude`、`longitude`、`city_name_cn` / `city_name_en`、`country_code`、`is_full_day`（是否需整天游玩）、`order_no`（路线内顺序编号）、`open_days` / `open_days_cn`（每周开放日）、`addr_en`、`note`。

### query_attractions_raw — 原始响应

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| country | string | 条件必填 | 国家中文名称 |
| city_name_cn | string | 条件必填 | 城市中文名称，模糊匹配 |
| city_name_en | string | 条件必填 | 城市英文名称，模糊匹配 |
| limit | number | 否 | 最多返回条数，默认 100；传 `0` 表示不限制 |

返回接口未处理的完整 JSON。**必须至少提供一个筛选条件**——完全无条件会拉取全库 3 万+ 条数据（约 14MB），此时工具不报错，而是返回引导文案（提示改用 `query_attractions` 或补充条件）。仅在需要排查字段异常或核对原始值时使用。

### setup_token — 配置接口凭证

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| token | string | 是 | 接口 token（SSLQAPITOKEN），由接口提供方发放 |

保存前会用真实请求验证有效性，验证失败不会保存。token 仅明文保存在本机，不会上传。若用户在连接器表单中已填写 token，则无需调用本工具。

## 使用要点

- 国家和城市来自用户在对话中的表述：先确认用户想查哪个国家/城市，再转为工具参数调用；用户没说清时先询问，不要盲猜。
- 只传 `country` 会返回该国所有城市的景点，数据量可能很大，建议配合 `limit`。
- 城市名支持模糊匹配，写「巴黎」即可，不需要精确全称。
- 结果按城市归组，`order_no` 是景点在推荐路线中的顺序编号，可据此安排游览先后。
- `is_full_day` 为 true 表示该景点需要花一整天，排程时不要与其他景点挤在同一天。
- 接口对每个城市返回的第一条记录可能是名称为空的占位数据（`order_no` 为 1），做行程时应忽略。
- `open_days` 为空表示接口未提供开放日信息，不等于不开放。

## 常见错误

| 现象 | 原因与处理 |
| --- | --- |
| 提示「尚未配置接口 token」 | 未配置凭证：先向用户询问 SSLQAPITOKEN，再调用 setup_token 保存 |
| 提示「接口返回 HTTP 401 / 403」 | Token 无效或已过期，请联系提供方重新获取 |
| 提示「接口业务错误 code=…」 | 接口返回的业务错误，按 msg 提示处理 |
| 返回「未查询到景点」 | 条件过窄或无数据，放宽为只传 `country` 重试 |
