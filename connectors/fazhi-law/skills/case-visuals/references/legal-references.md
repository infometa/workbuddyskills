## §1 证据强度分级框架

本框架参考《中华人民共和国民事诉讼法》及相关司法解释，为图表中的证据节点提供可视化强度标注。

### 1.1 三级分级

| 等级 | 标记 | 定义 | 判定标准 | 图表配色 |
|------|------|------|----------|----------|
| 🟢 强 | strong | 证明力较强，可独立证明待证事实 | 1. 原始书证/物证<br>2. 公证文书<br>3. 机关出具的公文<br>4. 鉴定意见 | 绿色填充 |
| 🟡 中 | medium | 有一定证明力，需结合其他证据 | 1. 复印件（无原件核对）<br>2. 电子数据（部分）<br>3. 证人证言（单一）<br>4. 当事人陈述（部分） | 黄色填充 |
| 🔴 弱 | weak | 证明力较弱，需谨慎采信 | 1. 无法核实的电子数据<br>2. 利害关系人证言<br>3. 存在矛盾的证据<br>4. 待确认的来源 | 红色填充 |

### 1.2 证据类型参考

| 证据类型 | 默认强度 | 说明 |
|----------|----------|------|
| 书证-原件 | 🟢 强 | 最常见的高强度证据 |
| 物证-原物 | 🟢 强 | 原始物证 |
| 公证文书 | 🟢 强 | 经公证的证据 |
| 鉴定意见 | 🟢 强 | 有资质机构出具 |
| 书证-复印件 | 🟡 中 | 需与原件核对 |
| 电子数据-完整 | 🟡 中 | 完整提取的电子证据 |
| 证人证言 | 🟡 中 | 需结合其他证据 |
| 当事人陈述 | 🟡 中 | 己方陈述证明力有限 |
| 电子数据-不完整 | 🔴 弱 | 提取过程有瑕疵 |
| 利害关系人证言 | 🔴 弱 | 存在利益关联 |
| 来源不明 | 🔴 弱 | 无法确认来源 |

### 1.3 标注使用规则

- **默认标注**：根据证据类型自动分配默认强度
- **用户覆盖**：用户可手动指定证据强度
- **组合标注**：同一证据在不同事实主张中可能有不同强度
- **争议标注**：对方有异议的证据强度自动降一级

### 1.4 图表中的标注方式

在证据节点标签中附加强度标记：

```
e1[买卖合同原件 🟢强]
e2[送货单复印件 🟡中]
e3[聊天记录截图 🔴弱]
```

或在 classDef 中通过颜色区分（推荐）。

## §2 时间精度标注体系

### 2.1 五级精度定义

| 级别 | 标记 | 精度范围 | 典型来源 | 图表处理 |
|------|------|----------|----------|----------|
| 精确 | ✅ | 精确到日 | 合同、判决书、公文 | 使用 YYYY-MM-DD 格式 |
| 近似 | 📅 | 精确到月 | 当事人回忆、一般性文件 | 使用 YYYY-MM 格式 |
| 模糊 | 🌫️ | 精确到季度/半年 | 口头陈述、模糊记录 | 使用 YYYY年X月左右 |
| 期间 | 📏 | 时间区间 | 法定期限、合同约定 | 使用 ~ 连接起止日期 |
| 未知 | ❓ | 无法确定 | 逻辑推断、信息缺失 | 标注（待确认） |

### 2.2 标注决策规则

```
有确切日期的书面记录 → ✅ 精确
有月份但无日期的记录 → 📅 近似
含"大约""左右""前后""差不多" → 🌫️ 模糊
明确为时间段或期限 → 📏 期间
仅有间接推断 → ❓ 未知
```

### 2.3 时间轴中的标注

在时间轴事件中附加精度标记：

```
✅ 2023-01-15 : 签订合同
📅 2023-02月约 : 支付首付款
🌫️ 2023年4月左右 : 乙方延迟交付
📏 2023-06 ~ 2023-07 : 协商阶段
❓ （待确认） : 收到催告函
```

### 2.4 精度对选型的影响

- 精确度高的时间序列（多数为 ✅）→ 适合时间轴图
- 精确度低的时间序列（多数为 🌫️/❓）→ 不适合时间轴图，建议用流程图或关系图
