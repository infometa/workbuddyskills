# 对话内渲染适配器

conversation_inline 交付时必须读取本文件。工具调用与业务图表生成分离：Skill 决定画什么，适配器决定如何在当前平台的回复流中显示。

## 适配器选择

1. 枚举当前会话已注册的渲染工具，不得仅凭工具名称猜测可用性。
2. 已注册 `PureShowWidget` 时，设置 `render_adapter=pureshow_widget`。
3. 否则依次选择平台原生内联组件、Markdown 图片、可预览附件。
4. 所有方式不可用时降级为精简文字；仅当 `include_source=true` 时附 Mermaid 源码。

## PureShowWidget 契约

对每个入选图表独立执行：

1. 生成 Mermaid 并完成语法校验。
2. 将 Mermaid 渲染为完整 SVG，确保 SVG 与该段文字结论一致。
3. 在该图对应的回复段落位置调用已注册的 `PureShowWidget`，至少传递 SVG 内容并设置 `mode=inline`；其他字段严格遵循平台实际工具 schema，不得臆造参数。
4. 等待工具成功结果和回复流中的 Widget 块，再继续写该图解读。
5. 禁止把 SVG 包装成独立 HTML，禁止用 HTML 报告、网页截图、资源目录或裸路径代替 Widget。

## 成功门控

维护两个计数：

- `planned_visual_count`：最终计划展示的图片或大型表格数量，范围 1-3。
- `successful_inline_count`：已收到成功工具结果且已进入回复流的视觉单元数量。

最终回复前必须满足两者相等。若不相等：

1. 对失败项按适配器降级链重试一次。
2. 仍失败则删除该项图名和图示解读，改写为精简文字并说明平台未能内联渲染。
3. 不得输出孤立图名、拆散节点文字、`100%`、工作区路径、“点击放大”或“源码见注释区”。

## 输出顺序

严格交错输出，不要先调用完所有图再集中解释：

```text
总述文字
图1前置结论
[图1内联 Widget/图片块]
图1解读
过渡文字
[图2内联 Widget/图片块]
图2解读
风险与建议
```

只有 `include_source=true` 时，才在全部分析之后追加可编辑源码。
