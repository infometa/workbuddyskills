# 模板与业务模块路由

## 模板选择

| 判断维度 | 通用专项法律意见书 | 咨询回复式法律意见书 |
|---|---|---|
| 问题数量 | 多个相互关联的争点 | 一个或少量明确问题 |
| 材料规模 | 合同、章程、业务材料或尽调文件较多 | 主要依赖用户陈述及少量文件 |
| 用途 | 交易决策、内部审批、项目合规或正式复核 | 快速咨询、内部判断和行动指引 |
| 结构重点 | 材料、声明、事实、逐项论证、风险和结论 | 直答、条件、风险等级和下一步 |
| 不宜选择 | 事实极少且无法界定项目范围 | 多主体、多交易或需要系统尽调 |

只能选择一种母版。边界模糊时，若存在多主体、多交易、三个以上争点或管理层风险矩阵需求，选择通用专项模板；否则选择咨询回复式模板。

## 必选结构

### 通用专项模板

保留：封面、重要声明、委托事项与范围、材料与核查方式、声明假设与保留、事实背景、适用法律依据、法律分析、结论、用途与法律基准日。适用法律依据最多引用六个具体法律条款；同一规范性文件的不同条款分别计数。候选条款按与委托问题的直接相关性、对结论的决定性及是否在后续分析中实际使用排序，仅保留最切合问题的条款，并按“核心条、款或项原文＋同段规则适用说明”组织；每项引文结束后紧接 1—3 句规则适用说明，不另起“简析”段落或保留“简析：”“简析、”标签，不得变成法规清单。存在三个以上可比较风险或管理层决策需求时保留风险矩阵。

### 咨询回复模板

保留：封面、重要声明、问题摘要、简要结论、事实基础与待核验事项、法律分析、风险等级、行动建议、保留事项。咨询回复式不适用六条总量上限；各争点按需使用 `根据《法规全称》第×条，[准确概括的规则]。[结合本事项事实说明法律影响]。` 的连续正文，将规则摘要直接融入分析，不整段堆叠条文、不保留独立“简析：”标签，也不另建冗长的适用法律章节。问题不超过三个；超过时改用通用专项模板。

## 业务模块

| 模块 | 主要争点 | 关键材料 |
|---|---|---|
| 公司治理与投资 | 设立、增减资、治理、关联交易、国企审批、总分公司管理 | 章程、议案、制度、登记资料、可研、审批文件 |
| 合同 | 成立生效、授权、履行、解除、违约、担保、争议解决 | 合同正本、补充协议、凭证、通知、往来文件 |
| 数据合规 | 角色、合法性基础、目的限制、安全、出境、自动化决策、行业规则 | 数据字典、流程图、隐私政策、授权链、委托协议、PIPIA、安全测试 |
| 劳动用工 | 用工关系、制度、调岗解除、竞业限制、外包 | 合同、制度、考勤薪资、通知、工会程序、外包协议 |
| 知识产权 | 权属、许可、职务成果、开源、商业秘密 | 登记证书、研发记录、合同、许可协议、开源清单 |
| 行政许可 | 准入、许可、备案、经营范围、处罚整改 | 许可证、批文、监管函、检查记录、整改证明 |
| 一般经营合规 | 广告、消费者、竞争、供应链、内部控制 | 业务规则、宣传材料、客户协议、投诉、制度文件 |

只加载与项目有关的模块。不得为了显得完整而保留无关章节。

## 章节删除规则

- 风险矩阵仅用于三个以上可比较风险或明确的管理决策场景。
- 材料清单、声明与假设在通用专项中必选；咨询回复中可合并为“事实基础与待核验事项”。
- 交付前删除所有“按项目选用”提示、空标题、示例行和未使用模块。
- 适用法律只保留实际用于后续分析或结论的决定性条文；删除未被论证使用的原则条款、定义条款和程序条款。
- 签署页必须与实际身份一致；无正式签发权限时删除或改为待复核初稿标识，不保留虚假律所、证号或印章字段。
