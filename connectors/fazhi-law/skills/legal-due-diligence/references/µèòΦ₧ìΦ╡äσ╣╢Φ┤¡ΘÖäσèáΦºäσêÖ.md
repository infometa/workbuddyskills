# 投融资并购附加规则

仅在 `engagementType=投融资尽调` 或 `并购尽调` 且具体交易结构需要时读取。本文件承接原 skill 中的 PE/VC 和交易处置能力，不属于通用核心。

## 1. 交易上下文

补充识别：交易类型、投资/收购方式、新股或老股、交易对价、交割安排、前轮权利、控制权变化、融资协议限制、监管审批、拟签交易文件和投后/整合安排。

## 2. 处置工具

| 工具 | 适用条件 | 最低输出要求 |
|---|---|---|
| 交割先决条件 | 问题可在交割前补救且不解决将影响交易基础 | 明确完成标准、证明文件、截止时间和未完成后果 |
| 陈述与保证 | 交易方掌握事实且投资/收购方需要风险分配 | 明确主体、时间点、披露例外、存续期和责任边界 |
| 专项赔偿 | 风险已识别但金额或发生时间未确定 | 明确触发、损失口径、上限/下限、期限和追索主体 |
| 价格调整/Holdback | 可量化或有负债或交割后验证事项 | 明确计算方式、托管/暂扣、释放条件和争议机制 |
| 交割后义务 | 不影响交割基础且可在合理期限整改 | 明确责任人、期限、证据、违约后果和监控方式 |
| 交易结构调整 | 风险无法通过一般承诺有效隔离 | 评估股权/资产交易、剥离、分步交割或范围调整 |
| 放弃/暂停交易 | 风险实质损害交易基础且不可接受或不可核实 | 说明证据、未决缺口和必须由律师/决策机构复核的判断 |

不得用风险等级机械替代条款选择，也不得把市场惯例的期限、比例或阈值写成法律要求。

## 3. 投融资附加关注

- 历次融资、优先权、回购/对赌、清算优先、反稀释、最惠待遇、董事席位、否决权、知情权和退出安排；
- 新股与老股的出资、股权权属、转让限制、税务及公司法责任；
- 估值所依赖的许可、知识产权、数据、客户和核心资产事实；
- 控制权变更、再融资、担保、负面承诺和第三方同意；
- 交易文件、公司章程、股东协议和工商登记的一致性；
- 投后报告、整改、审计、信息权和持续合规监控。

## 4. 并购适配

并购项目将“投资人”替换为收购方/受让方，并根据股权收购、资产收购或合并选择责任承接、资产剥离、员工安置、合同转移、许可延续和交割整合措施。不得直接沿用早期 VC 的期权池、前轮估值或投后席位假设。

## 5. 证据和人工复核

回购/对赌可执行性、公司承担回购责任、减资程序、股权转让出资责任、税收优惠和监管审批均属于时效性法律问题。须绑定 `法律来源与核验台账.md` 的官方来源和核验日期；缺少适用条件或最新核验时标 `待人工复核`。
