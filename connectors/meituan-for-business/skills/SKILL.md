# 美团企业版认证连接器

## 可用命令

所有操作通过 `sqt-auth-cli` 命令行工具执行，使用 Bash 工具调用：

```bash
# 查看登录状态
sqt-auth-cli status

# 查看版本号
sqt-auth-cli version

# 显示帮助
sqt-auth-cli help
```

`login` 与 `logout` 由 WorkBuddy 连接器托管，不要手动执行（见下节）。

## 用途

`sqt-auth-cli` 是美团企业版的统一本地认证入口。完成登录后，`sqt_tk` / `mt_c_token` 等凭据由 CLI 自行存入本机安全存储（系统钥匙串等），下游所有依赖企业版登录态的能力可直接复用登录态，无需再次登录。

## 登录态管理（由 WorkBuddy 连接器托管）

登录、登出、状态检查由 WorkBuddy 通过本连接器统一托管：

- 绑定/重新授权：WorkBuddy 调用 `sqt-auth-cli login`，从 stdout 提取登录链接并打开浏览器，用户在企业版登录页输入手机号完成确认后，CLI 轮询到登录成功并自行退出。
- 状态轮询：WorkBuddy 定期执行 `sqt-auth-cli status`，输出包含 `已登录` 即视为连接有效。
- 解绑：执行 `sqt-auth-cli logout` 清除本机登录态。

**不要手动执行 `sqt-auth-cli login`**。当 `status` 显示未登录时，引导用户在 WorkBuddy 中对本连接器执行重新授权，而不是由你直接运行登录命令。

## 判断登录态

执行任何依赖企业版登录态的命令前，先确认登录态：

```bash
sqt-auth-cli status
```

- 输出包含 `✔ 已登录`：登录态有效，直接执行下游任务。
- 输出为未登录或命令失败：停止下游任务，提示用户「请点击连接器『美团企业版』重新授权」。

## 当前能力边界（重要）

本连接器当前版本**只提供登录态维护能力**：安装 sqt-auth-cli、登录授权、登出、登录状态检查。连接成功后并不代表可以直接使用差旅预订、发票体检等企业服务——这些下游能力尚未接入，需要相应能力上线后才可用。用户请求超出此范围时，如实说明当前仅支持登录态维护，不要虚构或代执行任何企业服务功能。

## 下游能力使用

登录态就绪后，依赖企业版登录态的下游能力（如数据查询、差旅、发票等）尚未随本连接器接入；后续接入时以对应技能文档为准。在此之前，本连接器的价值是为这些能力提前准备好可复用的本机登录态。

## 安全红线

- 任何情况下不读取、打印、复制、记录 `sqtTk`、`mtCToken`、`wToken`、Cookie 或登录链接中的敏感参数。
- 不将登录链接或凭据写入任何文件、日志或对话输出。
- 用户主动要求退出登录态时，告知其可通过 WorkBuddy 连接器解绑（等价于 `logout`），而不是要求其手工导出或删除凭据。

## 常见失败处理

- **命令不存在**：说明 CLI 未安装，引导用户在 WorkBuddy 中重新初始化本连接器（触发 init 安装）。
- **登录超时或失败**：登录链接一次性有效，不能复用旧链接；引导用户重新授权。
- **本地凭证存储失败**：登录可能已在服务端成功但本机无法持久化；建议检查系统钥匙串权限后重新授权。
- **下游提示未登录但 status 显示已登录**：确认下游工具与当前用户、机器一致；不要手工注入 Cookie。
