# 视频生成

## 使用时机

用于根据提示词、参考图/视频/音频或首尾帧生成 1～12 条商品视频。如用户要先拆解一条爆款参考视频，再为目标商品生成结构同类视频，使用 `viral-video-copy`。

## 调用流程

1. 收集提示词、模型、模式、时长、分辨率、比例、数量和可选参考素材；本远程 Connector 只传 HTTPS URL。
2. 首次调用 `create_video_generation_task`时传 `dryRun=true`。预检只校验权限、素材、能力和价格，不创建任务、不调供应商、不占用积分。
3. 向用户明确展示 `estimatedCredits`、生成数、时长、分辨率和固定后比例。用户未确认时立即停止。
4. 确认后用与 dryRun 相同的业务参数正式调用，并传入稳定唯一的 `idempotencyKey` 和用户允许的 `maxCredits`。重试网络请求时复用同一幂等键。
5. 用返回的 `taskId` 和 `taskType=video_generation` 调用 `get_user_tasks`到终态。
6. 只对 completed 结果，用该 `taskId`、结果 `resultId` 和 `taskType=video_generation` 调用 `get_video_result_download_url`。

## 提交前确认与任务跟踪

- 仅在用户明确要求生成或提交后创建任务；用户只咨询能力、费用、输入要求或方案时不创建任务。
- 必填或条件字段缺失、输出参数尚未确认、取值冲突或用户意图有歧义时，一次性询问最少必要信息并等待确认；schema 默认值和推荐值仅作待确认候选，不代替用户选择，不猜测商品事实、素材含义或付费参数。
- 创建或提交成功后记录返回的 `taskId` 和对应 `taskType`；处理中始终用同一 `taskId + taskType` 精确查询，不使用模糊列表，也不因查询重试创建新任务。
- 持续查询直到 `completed`、`failed`，或分步流程进入需要用户操作的节点；只报告当前任务的实际结果以及服务端返回的成功、失败和待处理数量。
- 本轮等待超时时告知任务可能仍在后台处理，返回并保留 `taskId` 供后续查询；不得自动重建、重复提交或追加扣费。

## 参数核验与询问

- 动态计费：本文的历史价格示例不构成当前报价。生成扣分以服务端当前报价及任务价格快照为准；充值套餐、活动、资格和有效期以官网实时可售目录为准，不根据 Skill 中的数字承诺费用或优惠。视频必须按真实 dryRun 结果确认费用。

### WorkBuddy 交互式参数收集




- `ask_human` 是 WorkBuddy 宿主提供的交互能力，不属于本 Connector 的 MCP 工具。仅在运行时明确提供 `ask_human` 时直接调用，并严格遵循当前运行时 schema；不要把 `ask_human` 作为连接器的远程 MCP 工具调用。
- 调用前读取已授权连接器的当前工具 schema；下文参数表仅作说明，必填条件、枚举、默认值和模型能力以本次 schema 为准。业务操作只调用本连接器暴露的工具；素材直传仅按下述 agentUpload 协议使用宿主实际提供的执行工具，不自行配置服务、提取 OAuth 凭据或调用其他 API。
- 先检查用户在本次对话中已提供的附件或图片；已有可读取公网 HTTPS 地址时直接使用，不再上传。附件尚无 HTTPS 地址时，按下述自动上传流程处理，不把已有附件当成素材缺失。确实没有必需素材时，先提示用户在当前对话上传或提供 HTTPS 地址，收到后再收集其他字段；不重复要求选择或上传同一素材。
- 对用户本次提供但没有 HTTPS 地址的图片，先确认当前已授权连接器实际暴露 `create_material_upload` 和 `get_material_upload`；仅在两者均可用时，按宿主实际工具 schema 和调用方式调用连接器 `create_material_upload(maxImages=<本批图片数，上限 20>)`，保存实际返回的 `id` 作为 `sessionId`。响应包含 `agentUpload` 且宿主实际提供读取附件与联网的执行工具时，由宿主执行工具读取这些图片，在执行进程内编码并将 `{files:[{filename,data:"data:image/<实际格式>;base64,..."}]}` 作为 JSON，使用 `agentUpload.method` 和 `agentUpload.headers` 向 `agentUpload.url` 提交一次；不得让模型生成、抄写或在聊天、日志、工具输出中打印 base64，不把图片字节放进 MCP 参数。
- 上传前核对 `agentUpload.url` 为 HTTPS、与本次响应 `uploadUrl` 同源且未过 `agentUpload.expiresAt`；禁止携凭证重定向。只使用本次响应的短期上传凭证，不读取、索要或传递 OAuth Token、Cookie、浏览器存储及其他长期凭据；不使用网盘或静态站点发布，不向其他地址发送图片或凭证。执行结果仅保留 `id/status`，不展示上传凭证；生图工具仍只接收完成后的 HTTPS URL。
- 只有响应没有 `agentUpload`、宿主无法读取本次附件或没有联网执行能力时，才把实际 `uploadUrl` 展示给用户，提示登录同一账号选图上传；不编造附件读取工具或上传地址。宿主确实未提供可读取图片时说明限制，不假装已完成自动上传。纯文生图不申请上传会话，视频和音频不走此图片上传入口。
- 上传完成后，或 HTTP 超时、结果不明时，先用 `get_material_upload(sessionId=<原 id>)` 查询同一会话，不重复 POST。`pending`/`uploading` 只表示等待，可每 5 秒查询、最多等待 2 分钟后说明当前状态并保留原会话；不得创建生成任务。仅 `completed` 时读取 `images[].url`，按 `filename` 和用户指定用途区分商品图/参考图，歧义先问，不能自行混用。`failed` 或 `MATERIAL_UPLOAD_EXPIRED` 时不生成，说明错误并重新申请会话，不重复提交旧会话。自动上传后继续原任务；已确认的素材用途、参数和费用不重复询问，仍有缺项时才补问。
- 短期上传凭证仅 5 分钟有效，与 30 分钟会话期限不同。HTTP 明确返回 `MATERIAL_UPLOAD_CAPABILITY_EXPIRED`，或上传前发现 `agentUpload.expiresAt` 已过时，先用 `get_material_upload` 查询原会话：`completed` 复用已上传图片，`uploading` 继续等待；仅确认 `pending` 且凭证已失效时，申请新会话并重新自动上传。HTTP 超时或结果不明不能当作凭证失效，不按此分支重新上传。
- 上传工具未出现在当前 schema 时，说明连接器版本尚未提供入口并请用户使用已有 HTTPS 素材；不编造工具或固定链接。本入口首版只收 JPG/PNG/WebP/静态 GIF 图片，单张最多 20 MB、合计 40 MB、会话 30 分钟有效；视频和音频仍需已有可读取 HTTPS 地址。超过 20 张时分批申请链接，并分别保存会话与文件用途。上传成功不代表参数已确认或生成已提交。
- 用户已明确提供且合法的值不重复询问；必填或条件字段的缺失、冲突、歧义，以及未明确的适用输出参数，统一纳入询问。非输出类可选项未提供时可省略，或按用户授权进行创意规划；输出参数即使在 schema 中可选或有默认值，也须按下述规则确认。
- 多个字段缺失、有歧义或尚待确认且运行时 schema 支持 `question_type="form"` 时，一次性展示表单；不支持多字段表单时，用一条紧凑文本列出全部缺口并等待，不逐项连问。单字段用当前支持的选择方式；仅在工具 schema 允许时提供“自定义 / 添加选项”。
- 本 Skill 重点收集：画面/运镜描述、模型、模式、时长、分辨率、比例、数量和音轨设置；参考媒体仍通过附件或 HTTPS 素材提供。选项按当前 schema、已选模型能力和本 Skill 的工作流边界生成；不展示本 Skill 未开放的模式，不写死历史枚举，不把显示名称直接当作模型参数。
- `ask_human` 不可用或调用失败时，在一条消息中给出紧凑编号选项并允许合法自定义回答，然后等待；不得猜值或创建任务。

### 输出参数确认

- 创建前核对当前 schema 和本 Skill 实际支持的输出参数：模型、比例、分辨率、数量（含图片数、视频数、包数及包内图数）、质量、输出语言，以及适用的视频时长、音轨等。未明确的可变参数列为“待确认”；不适用或不支持的字段不询问，固定输出在方案中说明，不编造选择。
- “已确认”只包括用户明确给出的本次具体值，或用户看过具体值后明确选择、回复接受的字段。schema 默认值、模型偏好和 AI 规划值都不自动算已确认；只确认风格、数量，不代表同时确认模型、比例或分辨率。只回复部分字段时，保留已确认项，仅补问其余待确认项。
- 询问时一次列出全部待确认输出参数，每项按“中文名称—当前合法选项或范围—必要说明”展示，尚未选择时标注“待选择”；选项中性呈现、不预选，已确认项只作摘要。用户可逐项选择，也可在看过完整具体组合后明确回复“全部按以上参数提交”。表单或文本发出后必须等待用户回答，不以展示摘要、表单预选值或省略字段触发服务端默认值代替确认。
- “直接生成”“不用问”“按你理解来”“AI 自动规划”以及未展示具体值前的“都按推荐”，只表示生成意图或创意委托；有待确认输出参数时仍先询问，不创建任务。全部适用输出参数均已明确或确认后，才进入方案确认和创建步骤。

### 模型、分辨率与可选创意

- 用户未指定模型时，将 **Seedance 2.0** 列为“Skill 预设模型偏好，待确认”；这只是产品预设，不表示本次效果最好、费用最低或最适合当前用途。只有当前工具 schema 明确支持、且满足本次素材和参数要求时才列为候选，经用户确认后使用 schema 对应的模型值。用户已经指定的合法模型和分辨率优先保留，不擅自替换。
- 用户未指定且预设模型不可用，或用户指定值不受支持、参数组合冲突时，说明具体限制，只询问冲突字段并提供当前可用选项；不得静默降级、缩短时长或改变数量。用户已选其他合法模型时，不因预设模型不可用而追问。
- 比例、分辨率、数量等参数按当前 schema 和已选模型能力提供选项，经用户明确确认后才能使用，不自动采用或省略字段来跳过确认，不默认追求最高规格。接口默认值仅是省略参数时的处理规则，风格等 schema 示例仅作取值说明，都不是推荐依据；确需展示默认值时标注“接口默认，非推荐”。模型或模式变化导致已有值不适用时，只重新确认受影响字段，不静默替换。
- 参数建议按请求提供：用户未请求建议时，除前述模型偏好外，只展示合法选项和必要说明；用户明确请求建议且已有具体用途、版位或素材约束时，给出符合约束的合法值，说明所依据的用户要求或已核验信息，并标注“AI 建议，待确认”。请求建议但依据不足时，提供中性选项或询问必要用途，不强行为每项生成推荐值，不编造效果、费用优势或平台规范；任何建议仍须用户确认。

## 工具与参数

### `create_video_generation_task`

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| `prompt` | 是 | 视频画面、镜头、动作和商品约束 |

| `mode` | 是 | `all_in_one` / `first_last_frame` |
| `durationSeconds` | 是 | 2.0 / Fast / Mini：4～15 秒整数；2.5：4～30 秒整数；H3：4～15 秒整数；H3 Max：5～15 秒整数；Gemini Omni Flash：3–10 秒整数 |
| `resolution` | 是 | Fast / Mini：`480p` / `720p`；Seedance 标准版另支持 `1080p`；H3：`768p` / `2k`；H3 Max：`480p` / `768p`；Omni：固定 `720p` |
| `aspectRatio` | 是 | `21:9` / `16:9` / `4:3` / `1:1` / `3:4` / `9:16` / `adaptive`；Omni 仅支持 `16:9` / `9:16` / `adaptive` |
| `outputCount` | 是 | 1～12 |
| `referenceImages` | 否 | HTTPS 图片；数量与能力按模型校验 |
| `referenceVideos` | 否 | HTTPS 视频；时长、编码与数量按模型校验 |
| `referenceAudios` | 否 | HTTPS 音频；2.0 / Fast / Mini 不允许纯音频输入 |
| `generateAudio` | 否 | 是否生成音轨，默认 true；H3 / H3 Max / Omni 固定 true |
| `dryRun` | 是（预检） | 首次必须 true；正式创建为 false/省略 |
| `idempotencyKey` | 正式必填 | 稳定客户端幂等键 |
| `maxCredits` | 正式必填 | 用户确认的最大整单积分，不小于已接受估价 |

`first_last_frame` 只接受按顺序的 1～2 张首/尾帧图，不传参考视频或音频。`adaptive` 只自适应画幅，分辨率仍必须明确指定。H3 / H3 Max 首尾帧仅支持 `adaptive`，比例跟随首帧。H3 / H3 Max 全能参考支持 9 图、3 视频、3 音频；图片不超过 20 MiB，MP4 不超过 50 MB，MP3/WAV 不超过 15 MB；视频、音频分别每段 2～15 秒且各自合计不超过 15 秒，音频不能单独使用。无素材走文生视频。H3 768P 为 $0.08/秒、2K 为 $0.13/秒；输出与参考视频时长计费，每结果前 5 张参考图免费，超出 $0.04/张，音频免费。成本按美元 × 6.78 × 1.3 ÷ 0.1 整单取整锁价，最终仅收成功结果。

H3 Max 三类参考素材合计最多 12 个文件。文生/首尾帧 480P 的 5/10/15 秒为 21/43/64 积分；768P 为 35/71/106 积分，768P 使用平台销售基准，不是官方成本。全能参考取官方整单费用与 SandBase 折前预估成本较高者 ×1.3÷0.1 后整单四舍五入；每次生成独立享有 4,096 参考 tokens 免费额度。图片尺寸和音视频时长由服务端探测，不能传入 tokens 或成本覆盖报价。素材准备后成本变化由平台承担，不追加扣分；多结果累计精确金额后取整，部分成功只结算成功结果。正式创建及主动重试前重新 dryRun 并确认 maxCredits。

## 权限、积分与安全边界

- OAuth 获取与刷新：首次连接时由 WorkBuddy 打开浏览器完成 OAuth；access token 到期后由客户端使用 refresh token 自动轮换；授权失效后重新连接。
- OAuth 绑定用户、空间和 operator，不索要 Token；创建、查看、下载均由服务端分别鉴权。
- 生成工具只传 HTTPS URL，禁止本地路径、`file:`、`data:`/base64、localhost、私网/保留地址或供应商临时 URL。
- 素材的 MIME/magic、尺寸、时长、FPS、codec 和信任边界以服务端 probe 为准。
- 积分以 dryRun 估价、服务端 hold 和终态结算为准；不修改用户已确认的参数，不隐式追加输出或扣费。
- 不生成仿冒他人、未授权人像/品牌或违法内容；结果只从可信存储签发短时下载链接。

## 视频模型与素材边界

当前模型：`seedance_2_0` / `seedance_2_5` / `seedance_2_0_fast` / `seedance_2_0_mini` / `minimax_h3` / `minimax_h3_max` / `gemini_omni_flash`。能力以当前 schema 为准。

Gemini Omni Flash（`gemini_omni_flash`）只用于普通视频生成，不支持爆款视频复制、视频编辑或延长。3–10 秒整数、固定 720p、含音频，画幅仅支持 16:9、9:16 和自适应；自适应按参考图选择这两种比例之一。全能参考无图走文生，有图走图片参考生成，最多 9 图且单图不超过 20 MiB；首帧模式只收 1 图，不支持尾帧、参考视频或参考音频。销售基准文生 $0.125/秒、图生 $0.13/秒，美元 × 6.78 × 1.3 ÷ 0.1 整单四舍五入一次，部分成功只收成功结果，同一任务重试沿用冻结价格，再创作重新报价；供应商实际成本另行核验，不将销售基准当成本。切换模型后保留不兼容素材并提示处理，不自动删素材或提交。

## 任务状态查询

### 精确查询与完整性

- 只用 `get_user_tasks(taskId=<创建返回值>, taskType=video_generation)` 查询同一任务；`limit` 取当前 schema 允许的最大值以避免漏掉子结果，轮询不传 `status` 筛选。不得用模糊列表、创建时间、商品类目或相似参数匹配其他候选任务。
- 按当前工具的结构化结果或文本 JSON 解包，不假设固定外层结构；核对任务类型及当前 schema 定义的任务/父任务 ID 关系。没有精确匹配、空列表或暂未返回结果，只说明当前尚未查到，不代表失败或完成。
- 视频按同一任务的 `progress.total/completed/failed/pending` 和 `results` 判断；`percent=100` 包含失败项，不代表全部成功。 “包数”“图片数”“视频数”保持各自语义，未返回或语义不明的计数标为未知，不编造零值。
- 只要本任务还有待处理项就继续等待，不能因为第一条子记录完成或出现一个 URL 就结束；只有任务级终态或完整结果证实全部结束才收尾。全部结束后仍有失败项时，明确部分成功并交付成功项；`failed` 时也保留已确认可用的成果。
- 返回条数达到上限、统计与子结果不一致或成功数大于可用成果数时，不能声称全部交付。仅在当前 schema 支持分页时继续精确取齐；没有分页能力则说明返回不完整、列出已知缺口并保留任务 ID，不自造分页参数。

### 等待节奏与停止条件

- 创建后立即查询一次；未到终态时，优先遵守工具实际返回的有效 `pollAfterSeconds` 或限流重试间隔，未提供时以 60 秒为参考间隔。本轮累计等待最多约 20 分钟，宿主时限更短时以宿主为准；本地计时只用于等待预算，不用于判断任务成功。
- 仅通过当前运行时已有的等待或异步续跑能力安排下一次查询，并按其真实 schema 使用；不编造等待工具，不用紧密循环刷接口，也不为轮询读取 OAuth 凭据或另建直连脚本。宿主没有等待能力或本轮无法继续时，如实说明本轮已停止查询，不声称仍会后台轮询。
- 首次等待提示“任务已提交至云端执行，预计需要数分钟，请耐心等待。”；后续在进度有实质变化或宿主要求更新时，用一句“任务仍在执行中，继续为您等待结果。”等友好提示。不要逐次刷屏、展示内部轮次/技术字段，或反复问“是否继续等待”。
- 遇到任务终态、需要用户操作的节点、用户要求停止等待、授权/素材/权限错误、无法继续查询或等待预算耗尽时停止自动轮询。查询暂时失败不等于生成失败；临时网络或限流错误只在剩余预算内按允许间隔重试查询，不重试创建。
- 等待超时只表示本轮结束：保留同一 `taskId + taskType`、最后可确认状态及已得到的成果，告知任务可能仍在后台处理。用户之后明确要求继续时，只恢复该任务的查询；不得自动重建、重复提交或追加扣费。用户停止等待也不等于已取消服务端任务，不虚构取消结果。

## 结果交付

- 对 `results` 中每个 `status=completed` 且 `downloadable=true` 的结果，用同一 `taskId`、`taskType=video_generation` 及该 `resultId` 调用 `get_video_result_download_url`，只使用真实返回的 `url` 和 `fileName`。不对失败或未就绪结果申请下载，不从任务状态拼接视频地址；链接失效时重新获取授权链接。
- 交付顺序为简短状态、全部可用成果、简短建议；成果必须出现在用户聊天消息中，不以文字描述替代媒体或链接。只有工具描述明确用于向用户发送媒体消息时，才按其实际 schema 优先调用；仅供模型读取、查看或分析文件的工具不是用户预览，调用成功不代表用户已经看到成果。
- 视频：取得真实下载地址后，使用宿主明确支持的视频消息或播放器交付，并在回复中逐项附上 `[播放 / 下载视频 1](<真实 url>)`。没有此能力或发送失败时，提供全部可点击链接并说明当前无法内嵌播放；不把 MP4 当普通图片嵌入，不伪造封面、播放器或已播放状态。
- 收尾前逐项核对：每个已取到的成果都有本次实际发送的媒体消息、正文预览或可点击链接；仅有编号、画面描述、查看工具成功或文件记录不算交付。按实际方式写“已提供预览”或“已提供链接”，无法验证客户端渲染时不声称“已显示 / 已打开 / 已播放”。消息长度受限则分批编号，未发出的不计入已提供数量。
- 默认不保存到本机、不创建结果目录或报告，不以本地文件路径代替聊天交付。没有拿到的图片、视频、文案和下载地址不得用占位内容补齐；返回不完整时说明“已提供 / 已取到 / 服务端成功数”的区别，不把交付计数当成计费依据。
- 每个成果附简短编号；主题、顺序或用途说明须来自工具、用户资料或实际可见内容，不能仅凭文件名猜测画面。按本任务适用情况给出简短使用建议：首图/首屏选择、排序或播放节奏、平台版位、文案搭配和后续优化；不适用项省略，不代用户发布或承诺投放效果。
- 失败只说明工具提供的公开原因及适用建议；未提供安全的原因时直说未返回公开详情，不引用供应商报文或内部堆栈。完成后不额外查询余额、不推算扣费或退款；创建前的必要估价与积分不足处理仍按原规则执行。
