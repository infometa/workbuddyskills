# 从公开证据到可执行动作

## 1. 按经营目标找机会，不凭公开内容判经营好坏

用户只给店铺号/名称即可启动。先检查八类任务的公开线索，再聚焦最有支撑的1–3个议题；不强制全部分析，不替用户断言当前订单少、利润低。把“增加合适客户的购买意愿”等写为建议改善方向，不能当作已经测量的经营问题。

| 经营任务 | 公开原因证据与分析信息 | 可交付的动作／边界 |
|---|---|---|
| ① 选对商品和客群 | 内容定位、购买场景、实际规格、顾客购买理由/未满足需求、替代品差异 | 场景与卖点方案、规格候选、套装或小批量测款方案；不凭评论断定需求规模 |
| ② 让目标客户看到 | 搜索表达、内容主题、商品关联、潜在客群诉求 | 关键词/选题与场景内容试验；搜索结果不等于曝光份额，无归因数据不评渠道效率或加预算 |
| ③ 让客户愿意点进来 | 封面可辨识性、标题相关性、差异与展示价格条件 | 同一商品封面/标题备选及测试方案；不能由互动低推出点击低 |
| ④ 让进店客户愿意买 | 重复疑问、选款障碍、缺失规格、价值比较、实拍、服务和交付顾虑 | 商品说明、规格指引、效果演示、咨询回复样稿；不能断言存在真实漏斗流失率 |
| ⑤ 让每笔成交更赚钱 | 套餐结构、优惠规则、购买组合需求、同条件价值差异 | 组合候选与价格试验方案，列出实施前需确认的成本约束；无成本不算利润，不直接降价或提高包邮门槛 |
| ⑥ 交付好、减少退货 | 质量/预期不符/选错规格/物流/使用困难的公开反馈及说明 | 质检重点、描述修订、包装试验、使用指引、售后流程；未知损耗规模不判断退货率高 |
| ⑦ 让老客再买、带新客 | 品类购买周期、公开复购意愿、后续需求、关联商品与服务体验 | 下一次购买理由、关联推荐和回访文案样稿；不联系客户、不推断真实复购率或可触达人群规模 |
| ⑧ 管好备货、资金和人手 | 公开缺货/预售说明、规格需求、重复基础疑问 | 备货验证清单、常见问答和流程简化试点；不能诊断实际压货、现金缺口或人员效率 |

## 2. 为关键发现比较候选原因

形成原因工作表：经营目标｜已观察事实与来源｜可能影响｜候选原因｜支持证据｜反证｜未知项｜下一步验证｜对应动作。已观察事实、经营推断与动作建议分开。

只对核心议题检查真正合理的竞争解释，不机械凑原因数量。例如有人提“贵”：核验是否同款同数量、含运费与优惠条件是否一致、差异价值是否讲清、组合是否适用。价值不清先优化表达，组合不适先试组合；确认可比价格缺乏竞争力后，也需成本约束才能提出实际调价。

针对“顾客反复问数量”：检查完整可访问首图、规格与详情是否已写明；若已有答案，可能是位置不显眼或表达难懂，而不是缺少规格。评论只能证明该问题存在，不能证明因此没有成交。

优先将顾客声音与实际页面相互核对，再用可比商品找不同解决方式。不能仅凭一条差评推荐换供应商，不能以竞品画面更好看推导其转化更高。经营影响无法量化时描述作用机制和适用范围，不伪造损失金额、行业均值或优先级评分。

## 3. 将建议做成任务与交付物

每轮1–3项；综合证据强度、潜在影响、投入、依赖及可验证性说明先后。大幅调价、换商品、扩渠道、增加投放等动作先做小范围方案，不由公开线索直接建议全面实施。

每项任务包含：
- **目标与证据**：希望改变的结果、具体商品/页面/场景、事实及来源。
- **原因判断**：为何可能有效、反证或关键未知项，标记待验证原因。
- **具体动作**：改哪里、改成什么；责任角色、建议节奏和实施依赖。
- **直接交付**：可审核的改图/文案/详情模块，或测款表、组合方案、关键词选题、质检清单、服务流程、回访文案。无法直接完成时给具体执行建议，不只交空字段。
- **验证方案**：基线如何记录、比较对象、观察信号、潜在副作用，以及继续/调整/停止条件。

效果样张不是实测改善。已核实参数直接写入；未核实成本、规格、时效、赔付在稿外列确认项。只用假设才能完整演示时醒目标明，不能将其用于诊断本店。

## 4. 公开可做的验证与未来数据验证分开

本次可以完成：检查改后信息一致性、答案能否找到、路径是否明确、同类替代方案是否可比；交付完整样张和试验设计。后续可在相同采样规则下观察公开提问主题，但评论构成会变化，不据此宣称转化或利润改善。

需商家实施或未来授权才能完成：记录上线时间、流量与成交、退款、成本、复购等。任务卡把这些标为“实施后建议验证”，不能写成已监测或作为本次交付前提。没有基线不编达标比例；观察周期结合内容发布节奏、购买周期与样本量，样本不足先延长，不强行给成功结论。

例如补数量说明：本次交付已核实数量的首图/规格/详情样张并核对一致性；后续观察同类咨询，在获得后台数据时比较相近流量下的下单和数量相关退款。不以咨询减少单独证明经营改善。

每项试验只改少数关键变量，记录季节、促销和商品变化。改善目标信号且无明显副作用时继续；证据不足时调整或延长；增加误解、投诉或已知成本风险时停止该方案并复盘。具体规则按该动作设计，不机械复用固定周期或阈值。
