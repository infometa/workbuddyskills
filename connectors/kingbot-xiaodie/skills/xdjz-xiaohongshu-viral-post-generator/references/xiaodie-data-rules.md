# 小蝶记账数据规则与挂车参考价

## 一、数据源命名（强制）

凡是笔记预览页、对话回复里提到后台 / 系统 / 数据源的位置，一律写作：

```
小蝶记账（小程序）数据中心
```

- 禁止出现「帐套」「账套」「后台系统」「经营系统」等字样。
- 字段没维护时写「小蝶记账（小程序）数据中心未维护」。
- 覆盖位置：商品信息卡、挂车表、合规结论、发布前确认清单、对话回复全文。
- 商品在数据中心里的**登记名**若与用户口头叫法不一致（例如少了品牌前缀），
  必须在商品信息卡标注差异，并提示「挂车时按数据中心登记名对应，避免对不上」。

---

## 二、何时读商品档案

| 场景 | 是否读取 |
|------|---------|
| 用户只说「帮我写个小红书笔记」 | 不读，按用户提供的信息创作 |
| 用户说「按我的小蝶记账 / 按帐套数据确认/更新待确认项」 | **读** |
| 用户要经营分析、利润测算、数据查询 | 不读，转对应 Skill |

读取前先确认「小蝶记账」连接器已连接。未连接时**禁止编造任何数据**，
先引导用户连接，连接成功后再取数。

## 三、取数与回填边界

### 取数

- 用「小蝶记账」连接器查询商品档案。
- 会话标识取自当前工作目录路径中的 UUID 段；若路径中不存在 UUID，
  **传空字符串（新建会话），禁止伪造 UUID**。
- 一次问不清就换角度再查一次（例如先按商品名精确查，再按品类名模糊查），
  不要一次失败就下结论说「没有这个商品」。

### 回填边界（红线）

只回填**真实读到的字段**，其余保持原状：

| 字段状态 | 处理方式 |
|---------|---------|
| 读到具体值（如库存 776） | 写入商品信息卡与挂车清单 |
| 字段为空 / 未维护（如售价、规格） | 保留「待补录」，正文维持价位带表述，**禁止补一个假数字** |
| 无销售记录 | 全文**不写任何销量话术**，并在商品信息卡注明原因 |
| 数据中心没有的商品 | 挂车里不出现，禁止虚构 |

- 回填后若用户要求撤销，整块恢复到回填前状态，并说明已核实的结论仍然有效。
- 回填前主动列出将要写入的字段值，让用户确认——避免反复来回。

## 四、挂车参考价区间（必做）

### 为什么用代理数据

小红书店铺的商品价格没有可直接访问的公开接口。统一用**同源供应链平台的公开在售价**作代理：

- 淘宝 / 天猫（含天猫超市）
- 京东（含自营与第三方）
- 品类垂直电商（如酒类的酒圈网、也买酒等）

这些是小红书店铺常见的货源来源，价格带具有参考性。

### 取样

1. 先确认商品的**准确身份**（品牌 + 型号 + 规格），例如
   「卢士涛菩托干型雪莉」= Lustau Puerto Fino Solera Reserva，750ml。
2. 检索式组合：
   - `<商品名> 价格`
   - `<品牌> <型号> 售价`
   - `<同类品类> <规格> 在售价格`
3. 样本口径必须**同品类 + 同规格 + 同档位**（如「进口干型雪莉 Fino 750ml」），
   不同规格或不同档位（甜型 vs 干型）不能混进样本。
4. 收集 8–15 个价格点即可，记下每个的来源。

### 计算

- **最低价** = 样本最小值
- **最高价** = 样本最大值
- **中位数** = 排序后取中间值；样本为偶数时取中间两个的均值（可四舍五入到整数）

### 写法

挂车表售价列：

```html
<td data-page-node-id="...">参考 ¥155–298<br><span style="font-size:11px;color:var(--text-3)">中位 ¥230 · 实际挂车价待补录</span></td>
```

挂车表下方说明（模板占位符 `{{CART_NOTE}}`，样式类 `.cart-note`）：

```html
<p class="cart-note">同类商品参考价区间（取小红书店铺同源供应链：淘宝 / 天猫 / 京东 / 酒类垂直电商在售与历史价，样本为进口干型雪莉 Fino 750ml 同类商品，共 12 个价格点）：<b>最低 ¥155</b> ｜ <b>中位数 ¥230</b> ｜ <b>最高 ¥298</b>。注：¥155 为京东「买 2 件」单件到手促销价，常规在售中位数约 ¥230；实际挂车价请以店铺为准。</p>
```

### 必须遵守

- 促销到手价（买 N 件、券后、会员价）**单独注明**，避免被当成常规售价。
- 「实际挂车价以店铺为准 / 待补录」必须出现，参考区间**不得冒充本店售价**。
- 参考区间与正文里的价位带表述冲突时，**向用户点名提示**并请其决定是否统一，**不擅自改正文**。
- 搭配档若只是泛称（如数据中心里叫「红酒」，无具体 SKU），给不出可靠参考价，
  售价列保留「待补录」，不要硬套主推的区间。

## 五、已踩坑清单

| 坑 | 处理 |
|----|------|
| 把「帐套」写进预览页 | 全局替换为「小蝶记账（小程序）数据中心」 |
| 商品口头叫法与数据中心登记名不一致 | 商品信息卡标注差异，挂车按登记名 |
| 售价字段为空就自己估一个数 | 禁止；保留待补录 + 给参考区间 |
| 无销售记录却在文案里写「热销」 | 禁止；销量话术整体不写 |
| 参考区间比正文价位带更窄 | 提示用户，不自行统一正文 |
| 把促销到手价当最低常规价 | 单独注明促销条件 |
