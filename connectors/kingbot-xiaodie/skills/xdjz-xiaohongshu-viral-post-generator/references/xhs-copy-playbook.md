# 小红书爆款创作 Playbook

## 一、平台硬约束（不可违反）

| 项 | 限制 | 说明 |
|----|------|------|
| 标题字数 | **≤ 20 字** | 含标点。超过在列表页会被截断，等于白写 |
| 封面首屏可读性 | 主文案 ≤ 12 字，字号占画面宽 70%+ | 用户在信息流里只给 0.5 秒 |
| 正文字数 | 300-800 字最佳，上限 1000 | 太短没信息量，太长没人读完 |
| 正文段落 | 每段 ≤ 3 行，段间空行 | 手机阅读，大段文字直接划走 |
| 话题标签 | 5-8 个 | 3 个大词 + 3-5 个精准长尾词 |
| Emoji | 每段 1-2 个，禁止堆砌 | 作用是被当作分隔符和视觉锚点 |
| 联系方式 | 正文禁出现微信/手机号/外链 | 违规限流风险 |

## 二、三种钩子类型（本次三套方案的差异化维度）

三套方案**必须**分别是这三种钩子，不能在同一个钩子里换三种说法。

### 方案 1：痛点共鸣型

**核心逻辑**：先说出用户正在经历的困扰，让他觉得"你懂我"，再引出商品作为解法。

**适用**：功能性明确、用户痛点清晰的品（护肤、母婴、收纳、办公用品、健康食品）。

| 组成 | 写法规范 | 示例（护肤精华油） |
|------|---------|------------------|
| 封面主文案 | 痛点直述，称呼 + 困扰，≤12 字 | 「干皮姐妹，别再乱补水了」 |
| 封面视觉 | 人物/生活场景为主，情绪偏低落或思考感，暖色调，留白放文案 | 清晨梳妆台前的女性侧影，逆光，驼色暖调 |
| 标题公式 | 「{人群}的{困扰}，其实只要{动作}」/「{困扰}？我用了 X 天才敢说」 | 「干到起皮别急着敷面膜，先看这个」 |
| 正文骨架 | ① 痛点场景（3 行内，具体到时间地点）② 踩过的坑（2-3 个）③ 转折：遇到它 ④ 用了之后的变化 ⑤ 怎么用（步骤）⑥ 挂车引导 | 见下方模板 |
| 正文语气 | 第一人称，口语，像跟朋友吐槽 | "我之前真的傻，天天敷面膜…" |
| 话题标签 | 人群词 + 痛点词为主 | #干皮护肤 #换季起皮 #护肤踩坑 |
| 挂车侧重 | **主推 + 搭配**：痛点解决后顺势给完整方案 | 主推精华油 + 搭配洁面 |

**正文模板**：

```
{具体场景描述，越具体越真}
例：上周降温，我早上化妆又卡粉了，鼻翼两侧起皮到没法看。

试过的方法：
· {踩坑1}
· {踩坑2}
· {踩坑3}
全都没用。

后来才知道，问题不在补水，在{核心认知}。
{此处嵌入用户提供的商品信息：名称/规格}

这段时间我在用的搭配：
① {使用步骤1}
② {使用步骤2}
③ {用后观察到的事实性变化，不涉及虚夸功效}

两个灵敏提醒：
· {注意事项1}
· {注意事项2}

我把自己在用的这套放下面了 👇
{挂车商品清单}
```

### 方案 2：效果反差型

**核心逻辑**：用强烈的"前后对比 / 反直觉事实"制造好奇，让人忍不住点进来。

**适用**：视觉对比明显的品（清洁、收纳、美妆、厨具、家居改造）；或价格/认知有反差的品（高价款用平替、便宜货效果惊艳）。

| 组成 | 写法规范 | 示例 |
|------|---------|------|
| 封面主文案 | 数字感 + 结果，制造"怎么做到的"疑问，≤12 字 | 「30 天，从卡粉到奶油肌」 |
| 封面视觉 | **左右分屏对比** / 前后状态同框，高对比明暗或冷暖差，数字要大 | 左半脸干燥卡粉 vs 右半脸服帖光泽，分屏构图 |
| 标题公式 | 「{时间/成本}，{从 A 到 B}」/「没想到{低价/简单方法}，居然{结果}」 | 「30 天，我把干皮救回来了」 |
| 正文骨架 | ① 抛出反差结果（数据或画面）② 拆解怎么做到的（分步）③ 关键变量（为什么有效）④ 适用范围与不适用范围 ⑤ 挂车 | 见下方模板 |
| 正文语气 | 干脆、有节奏，短句多，善用换行制造推进感 | "第 7 天：没变化。第 14 天：…第 30 天：…" |
| 话题标签 | 效果词 + 方法词 | #干皮逆袭 #护肤前后对比 #换季护肤 |
| 挂车侧重 | **主推单品**：反差归因单一，集中火力推一个 | 主推精华油 |

**正文模板**：

```
先说结果：{一句话概括反差，带可感知的量}
例：30 天，从每天卡粉到现在素颜敢出门。

在此之前：
{状态描述，1-2 行}

我做的就一件事：{核心动作}
{此处嵌入用户提供的商品信息：名称 + 规格}

时间线记录：
· 第 1-7 天：{客观描述}
· 第 8-14 天：{客观描述}
· 第 15-30 天：{客观描述}

为什么这次有效：
{讲清楚机制/关键差异点，1-3 条}

坦白说，不适合谁：
· {不适用人群1}
· {不适用人群2}

同款 👇
{挂车商品清单}
```

⚠️ **反差型的高压线**：涉及功效、医疗效果、减肥、祛斑、抗炎等断言时会踩广告法红线。没有检测报告支撑的功效，一律用「我个人的使用感受」表述，禁止写成客观功效承诺。详见合规检查脚本。

### 方案 3：权威测评型

**核心逻辑**：用"我认真比过 / 我看过参数 / 我算过账"建立理性信任，适合高客单、决策周期长、需要说服的品。

**适用**：中高客单价（> ¥200）、技术参数多的品（家电、数码、器材）、原料导向的品（成分党护肤、保健品、食品）。

| 组成 | 写法规范 | 示例 |
|------|---------|------|
| 封面主文案 | 清单感 + 结论，≤12 字 | 「测评了 8 款，只留这 3 款」 |
| 封面视觉 | 干净白底/浅灰底的产品平铺俯拍 + 标注线条，或网格化多品排列，理性冷静色（白、米、浅木） | 多瓶精华一字排开俯拍，侧光，标注标签 |
| 标题公式 | 「测评了{X}款{品类}，只有{X}款值得买」/「{品类}怎么选？看这 {X} 个参数就够」 | 「评测 8 款护肤油，这瓶性价比最高」 |
| 正文骨架 | ① 评测背景（买了什么、花了多久）② 评判维度（3-4 个，列出）③ 逐款结论（表格化程度越高越好）④ 结论与推荐理由 ⑤ 挂车 | 见下方模板 |
| 正文语气 | 克制、有据、少形容词多数据。**每个结论都要有依据**（用户提供的信息或合理的品类常识），禁止编造数据 | "售价 ¥189，质地流动性强，60 秒内基本吸收" |
| 话题标签 | 品类词 + 选购攻略词 | #护肤油测评 #护肤攻略 #成分党 |
| 挂车侧重 | **主推 + 搭配（对比款）**：给想横向比较的人一个参照物 | 主推雪莉 + 对比款红酒 |

**正文模板**：

```
花了 {时间}，把 {范围} 的 {品类} 摸了一遍。
先说结论：{一句话结论}

我按这几个维度去比：
① {维度1}
② {维度2}
③ {维度3}
④ {维度4}

逐款结论：

【{商品A}】¥{售价}
· {维度表现}
· 适合：{人群}
· 一句话：{结论}

【{商品B}】¥{售价}
· …（同上）

最终推荐：
预算充足 → {商品}
追求性价比 → {商品}
想先试试 → {商品}

都在下面 👇
{挂车商品清单}
```

📌 **测评型的特殊要求**：出现的每一款商品都必须是用户确认过真实存在的。禁止为了凑"测评了 8 款"而编造不存在的商品。实际只有 3 款，就写"测评了 3 款"。

## 三、标题公式库

写标题时从下面挑适配的骨架，再填商品信息。写标题时从下面挑适配的骨架，再填商品信息。优先套用转化率靠前的几条公式。

| # | 公式 | 适配钩子 | 示例 |
|---|------|---------|------|
| 1 | {人群}别再{错误做法}了 | 痛点 | 干皮别再狂敷面膜了 |
| 2 | {困扰}？我用了{X}天才敢说 | 痛点 | 卡粉脱皮？我用了 30 天才敢讲 |
| 3 | 为什么{常见现象}总发生在{人群}身上 | 痛点 | 为什么你补水越补越干 |
| 4 | {时间}，{从 A 到 B} | 反差 | 30 天，从卡粉到奶油肌 |
| 5 | 没想到{低门槛做法}，效果居然{X} | 反差 | 没想到一滴油，比我全套精华管用 |
| 6 | 花{X}元买的教训：{品类}别这么选 | 反差 | 花了 2000 才懂：护肤油别这么挑 |
| 7 | 测评{X}款{品类}，只有{X}款值得买 | 测评 | 测评 8 款护肤油，只留这 3 款 |
| 8 | {品类}怎么选？看这{X}个参数 | 测评 | 护肤油怎么挑？看这 4 个点 |
| 9 | {预算}预算，{品类}买到这份上就够了 | 测评 | 300 块，护肤油买到这份上够了 |
| 10 | {反常识断言} | 通用 | 贵的护肤油不一定适合干皮 |

**标题自检（写完必过）**：

1. 字数 ≤ 20 → 超了砍修饰词
2. 有没有极限词（最/第一/绝对/100%）→ 有就换
3. 有没有说清"给谁看"→ 没有就加人群词
4. 会不会显得像广告 → 会的话去掉品牌主语，改成第一人称体验

## 四、封面生成规范

### 调用方式

**必须同时生成 3 张封面，与三套方案一一对应，缺一不可**（方案1→图1，方案2→图2，方案3→图3）。禁止只出一部分、禁止同一张图复用给多个方案、禁止用占位图。

竖版 3:4，建议直接传 `1024x1536`，出图后统一裁切（见下方水印处理）。

### 商品必须在场

封面必须让用户看出「这是在推什么」：

| 钩子 | 商品如何出现在封面 |
|------|------------------|
| 痛点共鸣 | 人物场景为主，但要在画面中自然带出商品：桌面上的产品瓶身/包装、手边正在使用、或窗台/梳妆台上的道具位 |
| 效果反差 | 人物对比为主，可在画面下缘或角落放产品小图；或用「产品 + 前后对比」双元素构图 |
| 权威测评 | 商品直接做主体：多件平铺俯拍，商品即画面 |

### prompt 实操要点

- **描述主体不要写成最终成品图**：prompt 描述的是「画面里有什么」，不要试图让模型把中文字也画出来（中文渲染极易出错），文字交给 HTML 叠加或后期加。
- **必须写"留白"**：不写这句，模型会把画面填满，没有地方放封面文案。写明具体位置，如 `large clean empty negative space in the lower third of the frame`。
- **不要出现具体品牌 Logo 要求**：会生成畸形字形。
- 生成失败 / 额度不足 → 走降级（见下）。

### 生图已踩坑清单（每次都要照做）

| 坑 | 现象 | 对策 |
|----|------|------|
| **右下角带水印** | 出图右下角带「AI生成」字样，直接发布很难看 | 出图后裁切：按 3:4 从顶部保留（1024×1536 → 1024×1365），底部 171px 直接切掉，**同时修正比例和去水印** |
| **负面皮肤描述会跑偏** | 写 `dry flaky skin with caked foundation` 会生成「脸上糊泥膜 / 敷面膜 / 涂层剥落」，完全不是想要的东西 | 不要用皮肤微观纹理描述「前」状态。改用**光线与情绪对比**：左半冷调暗光、低头、疲惫，右半暖调亮光、抬头、微笑 |
| **真人痛点场景会画出皮肤病灶** | `dry skin` 可能生成痘印、伤口、红斑，对护肤品种草是劝退级素材 | 显式加排除词：`no acne, no blemishes, no skin lesions, no redness, no disease` |
| **真人特写会自造彩妆** | 写 `bare face` 仍可能生成浓妆或泥膜 | 显式加：`absolutely no makeup, no foundation, no facial mask, no clay mask, no product applied on the skin` |
| **商品数量不可控** | prompt 写「5 瓶」实际生成 6 瓶 | **出图后按图上实际数量改文案**。标题里尽量不写具体数字，或写完后核对一遍图 |
| **一次出多版** | 可能返回多个候选 | 选定后重命名为语义化文件名（如 `封面-方案1-痛点共鸣.png`），废弃版本删掉，不要都留在目录里 |

### 三种钩子对应的推荐 prompt 骨架（已验证可用）

### 降级：HTML 内嵌排版封面（仅兜底）

**只有某张封面重试一次后仍失败**，才允许该张降级为 CSS 排版封面，且必须向用户说明是哪张、什么原因。其余方案的封面照常出图。

在 HTML 预览页里用 CSS 画封面：

- 尺寸容器 `aspect-ratio: 3/4`，宽 100%
- 背景：`linear-gradient` 渐变，按钩子类型选色
  - 痛点：暖色 `#F5E6DA → #E8C9B0`
  - 反差：左右两块对比色各占 50%
  - 测评：素净 `#F7F7F5 → #EDEDEA` + 细网格背景线
- 主文案：`font-size: clamp(28px, 7vw, 48px)`，加粗，行高 1.25，白色或深色视背景而定
- 加一个「贴纸标签」元素（如 `¥189 起`、品类标签）提升真实感

降级必须在回复里明确告知用户，不要假装这是生图产物。

## 五、正文写作铁律

1. **第一段决定生死**：前 3 行必须出现「具体场景」或「反差结果」，不能开场介绍品牌。
2. **用事实不用形容词**：写"用了 30 天"，不写"效果超好"；写"售价 ¥189"，不写"性价比超高"。
3. **主动交代不适用人群**：反向筛选反而提高可信度与转化，且规避虚假宣传风险。
4. **挂车商品清单放在正文末尾**，格式统一：

```
🛒 笔记里提到的：
· {商品名} ¥{售价}  —  主推
· {商品名} ¥{售价}  —  搭配
· {商品名} ¥{售价}  —  想先试试的选这个
```

5. **禁止虚构**：买家评价、销量量级、检测报告、明星同款、第三方排名——没有真实来源的一律不写，标待确认。
6. **价格必须与用户提供的一致**：文案里出现的价格必须等于用户给的售价。促销价若为假设，必须标注"（此价格为假设，请确认）"。

## 六、合规红线（速查，完整词库在 scripts/check_copy.py）

| 类别 | 禁用示例 | 替代写法 |
|------|---------|---------|
| 极限词 | 最好、第一、顶级、唯一、绝无仅有 | 更适合、我个人偏爱、在我用过的里面… |
| 绝对化 | 100%、永远、绝对、彻底、根治 | 大部分情况下、目前看、对我而言 |
