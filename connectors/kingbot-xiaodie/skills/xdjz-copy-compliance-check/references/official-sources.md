> 本文件汇总 Skill 所依据的官方法规原文，供检查时引用法条依据。

## 一、内容社区平台官方文件

### 1.1 社区规范
- **原文位置**：平台官方协议中心在线页面（登录后可见）
- **核心精神**：真诚分享、禁止冒充身份、禁止伪科学与迷信、禁止编造经历

### 1.2 社区公约 2.0
- **核心原则**：真诚、友善、多元
- **禁止行为**：冒充他人身份、传播伪科学/迷信/未经证实偏方、煽动群体对立、网络暴力、滥用技术手段伪造内容
- **商业化规则（首次纳入公约）**：严禁虚构产品功效或伪造数据；禁止伪装个人或操纵评价进行恶意营销；要求提供真实体验，拒绝生硬包装

### 1.3 蒲公英平台内容审核规范
- **原文位置**：平台商家规则中心在线页面（登录后可见）
- **核心规则**：品牌合作笔记须在文首标注 "#本笔记已参与品牌合作"；禁止评论区诱导私下交易；促销活动须标明期限

### 1.4 商业导流治理规则
- **来源**：内容社区商家规则中心（需登录查看，路径：内容社区App → 我 → 创作中心 → 规则中心）
- **禁止行为**：
  - 发布或推送第三方商品信息
  - 诱导用户至第三方平台（提供微信号/电话、发送其他平台链接）
  - 在评论区或私信发送外部电商链接
- **处罚措施**：限制账号流量 → 限制内容/商品发布 → 违约金 → 店铺清退 → 封号

### 1.5 私信导流新规（2025年1月7日生效）
- **来源**：内容社区专业号后台通知（非公开页面），媒体参考报道见 https://finance.sina.cn/2025-01-09/detail-ineekuyn9300352.d.html
- **适用范围**：内容社区专业号
- **核心条款**：
  - 禁止在自动回复组件及欢迎语话术中展示微信号或电话号码
  - 导流只能使用平台官方的"社媒名片"方式
  - 须使用平台提供的"私信获客工具"进行客户获取
- **处罚措施**：未及时删除自动回复中的微信号 → 账号禁言
- **合规方式**：使用内容社区站内"社媒名片"功能进行引流，不在文字中直接暴露联系方式

**引用格式**：`内容社区《私信导流新规》（2025.1.7）：专业号禁止在自动回复/欢迎语中展示微信号或电话`

## 二、《中华人民共和国广告法》（2021修正）

> 来源：北京市市场监督管理局 https://scjgj.beijing.gov.cn/cxfw/flfgcxfw/ggl/202204/t20220401_2646388.html
> 市场监管法律法规规章数据库：https://sjfg.samr.gov.cn

### 第九条（绝对化用语禁止）
广告不得有下列情形：……（三）使用"国家级"、"最高级"、"最佳"等用语。

**违规依据引用格式**：`《广告法》第九条第（三）项：禁止使用"国家级""最高级""最佳"等用语`

### 第十七条（医疗用语限制）
除医疗、药品、医疗器械广告外，禁止其他任何广告涉及疾病治疗功能，并不得使用医疗用语或者易使推销的商品与药品、医疗器械相混淆的用语。

**违规依据引用格式**：`《广告法》第十七条：非医疗广告不得涉及疾病治疗功能`

### 第二十四条（教育培训广告）
教育、培训广告不得含有下列内容：
（一）对升学、通过考试、获得学位学历或者合格证书，或者对教育、培训的效果作出明示或者暗示的保证性承诺；
（二）明示或者暗示有相关考试机构或者其工作人员、考试命题人员参与教育、培训；
（三）利用科研单位、学术机构、教育机构、行业协会、专业人士、受益者的名义或者形象作推荐、证明。

### 第二十五条（招商投资广告）
招商等有投资回报预期的商品或者服务广告，应当对可能存在的风险以及风险责任承担有合理提示或者警示，并不得含有下列内容：
（一）对未来效果、收益或者与其相关的情况作出保证性承诺，明示或者暗示保本、无风险或者保收益等；
（二）利用学术机构、行业协会、专业人士、受益者的名义或者形象作推荐、证明。

### 第二十八条（虚假广告认定）
广告以虚假或者引人误解的内容欺骗、误导消费者的，构成虚假广告。
具体情形包括：商品或服务不存在、关键信息与实际不符且实质性影响购买行为、使用伪造证明材料、虚构使用效果。

### 第八条（赠品明示）
广告中对商品的性能、功能、产地、用途、质量、成分、价格、生产者、有效期限、允诺等有表示的，应当准确、清楚、明白。附带赠送的，应当将赠品的品种、规格、数量、期限和方式等表达准确、清楚、明白。

### 第十一条（引证内容）
广告内容涉及的事项需要取得行政许可的，应当与许可的内容相符合。广告使用数据、统计资料、调查结果、文摘、引用语等引证内容的，应当真实、准确，并表明出处。引证内容有适用范围和有效期限的，应当明确表示。

**违规依据引用格式**：`《广告法》第十一条：广告引证内容须真实准确并表明出处`

### 第五十五条（虚假广告处罚）
违反本法规定，发布虚假广告的，由市场监督管理部门责令停止发布广告，责令广告主在相应范围内消除影响，处广告费用三倍以上五倍以下的罚款，广告费用无法计算或者明显偏低的，处二十万元以上一百万元以下的罚款；两年内有三次以上违法行为或者有其他严重情节的，处广告费用五倍以上十倍以下的罚款，广告费用无法计算或者明显偏低的，处一百万元以上二百万元以下的罚款，可以吊销营业执照。

> 来源：https://amr.sz.gov.cn/xxgk/zcwj/scjgfg/gggl/jlglfl/content/post_12438601.html

**后果引用格式**：`《广告法》第五十五条：虚假广告 → 罚款广告费3-5倍或20万-100万元；情节严重5-10倍或100万-200万元，可吊销营业执照`

### 第五十八条（特定行业广告违规处罚）
有下列行为之一的，由市场监督管理部门责令停止发布广告，责令广告主在相应范围内消除影响，处广告费用一倍以上三倍以下的罚款，广告费用无法计算或者明显偏低的，处十万元以上二十万元以下的罚款；情节严重的，处广告费用三倍以上五倍以下的罚款，广告费用无法计算或者明显偏低的，处二十万元以上一百万元以下的罚款，可以吊销营业执照：
（二）违反第二十三条规定发布酒类广告的。

**后果引用格式**：`《广告法》第五十八条第（二）项：酒类广告违规 → 罚款广告费1-3倍或10万-20万元；情节严重3-5倍或20万-100万元`

### 第五十九条（一般违规处罚）
有下列行为之一的，由市场监督管理部门责令停止发布广告，对广告主处十万元以下的罚款：
（一）广告内容违反第八条规定的（表述不清楚、不明白）；
（二）广告引证内容违反第十一条规定的；
（三）广告涉及专利内容违反第十二条规定的；
（四）违反第十三条规定的（贬低其他生产经营者）；
（五）变相发布医疗、药品、医疗器械、保健食品广告的。
广告违反第九条第（三）项规定（使用绝对化用语），由市场监督管理部门责令停止发布广告，对广告主处二十万元以上一百万元以下的罚款。
广告发布者、广告经营者未依法标明"广告"的，由市场监督管理部门责令改正，对广告发布者处十万元以下的罚款。

> 来源：https://amr.sz.gov.cn/xxgk/zcwj/scjgfg/gggl/jlglfl/content/post_12438601.html

**后果引用格式**：`《广告法》第五十九条：绝对化用语 → 罚款20万-100万元；引证不实/表述不清/未标"广告" → 罚款10万元以下`

### 第二十三条（酒类广告）
酒类广告不得含有下列内容：
（一）诱导、怂恿饮酒或者宣传无节制饮酒；
（二）宣传饮酒有消除紧张和焦虑、增加体力等功效；
（三）明示或者暗示饮酒有保健功能；
（四）驾驶车、船、飞机等活动；
（五）诱导未成年人饮酒或者以未成年人为目标受众。

**违规依据引用格式**：`《广告法》第二十三条第（X）项：[具体违规情形]`

## 二点五、《广告引证内容执法指南》

> 来源：市场监管总局发布
> 参考：https://policy.mofcom.gov.cn/claw/clawContent.shtml?id=106104

### 核心规则
- 广告中借用外部统计、文献或测试结论，必须列明单位名称、期刊期号或网址等溯源信息
- 引证内容应当真实、准确、合法，提供结论的第三方须有合规资格
- 数据有地域/时效/条件限制时，必须显著提示，禁止用排版掩盖不利条件

### 处罚依据
- 未标明出处或隐瞒限制条件 → 《广告法》第五十九条
- 定性为虚假宣传 → 《广告法》第五十五条

**引用格式**：`《广告引证内容执法指南》：广告引用数据/统计须标明出处`

## 三、《广告绝对化用语执法指南》（2023）

> 市场监管总局发布，市监广〔2023〕12号
> 参考：http://news.cnnb.com.cn/system/2023/03/21/030468194.shtml

### 第二条（概念界定）
绝对化用语包括"国家级""最高级""最佳"以及与其含义相同或者近似的其他用语。

### 第四条（非广告情形豁免）
商家在自有媒介发布关于自身名称、简称、标识等信息，且未直接或间接推销商品的，一般不视为广告。

### 第五条（未指向商品的豁免）
用语未指向推销商品时可豁免，包括：
- 展现服务态度或经营理念
- 表达企业目标追求
- 与性能无关且不会对消费者产生误导的表述

### 第六条（指向商品但无不良后果的豁免）
- 同类商品的自我比较
- 使用方法的消费提示
- 有依据的商品分级用语
- 区分商品的名称或专利
- 官方奖项、称号
- 限定条件下的事实信息

### 处罚裁量规则
- **不予处罚**：初次违法 + 危害后果轻微 + 及时改正
- **应当不予处罚**：自有媒介发布 + 持续时间短或浏览人数少 + 无危害后果 + 改正
- **从轻/减轻处罚**：整体危害后果轻微的情形

**引用格式**：`《广告绝对化用语执法指南》第X条：[具体情形说明]`

## 四、《互联网广告管理办法》（2023）

> 来源：https://amr.hunan.gov.cn/amr/zwx/xxgkmlx/zcfgx/flfggzx/202303/t20230331_29302232.html

### 种草/测评标注要求
通过知识介绍、体验分享、消费测评等形式推销商品或者服务，并附加购物链接等购买方式的，广告发布者应当显著标明"广告"。

### KOL/达人代言责任
直播营销人员以自己的名义或者形象对商品、服务作推荐、证明，构成广告代言的，应当依法承担广告代言人的责任和义务。

### 禁止变相广告
禁止以介绍健康、养生知识等形式，变相发布医疗、药品、医疗器械、保健食品、特殊医学用途配方食品广告。

### 直播带货责任
商品销售者或者服务提供者通过互联网直播方式推销商品或者服务，构成商业广告的，应当依法承担广告主的责任和义务。

## 五、行业专项法规

### 5.1 化妆品监管
- **《化妆品监督管理条例》**（国务院令第727号，2021年1月1日施行）
  - 来源：https://www.mofcom.gov.cn/zcfb/zgdwjjmywg/art/2020/art_84de7c838e384abeadb1ce38f4596b72.html
  - 不得标示或暗示产品具有医疗作用
  - 不得使用医疗术语或易与药品混淆的用语
  - 特殊化妆品须有注册证编号方可发布功效广告

- **《化妆品功效宣称评价规范》**（国家药监局 2021年第50号公告）
  - 来源：https://www.nmpa.gov.cn/xxgk/fgwj/xzhgfxwj/20210409160321110.html
  - 功效宣称须有评价依据并标明出处
  - 不得夸大或引人误解

- **化妆品广告发布指引**（上海市市场监管局）
  - 来源：https://fw.scjgj.sh.gov.cn/alc/standard/cosmetic.jsp

### 5.2 食品安全
- **《食品安全法》**（2021修正）
  - 来源：https://flk.npc.gov.cn （全国人大法律数据库）
  - 第七十三条：食品广告不得涉及疾病预防、治疗功能
  - 保健食品须标明"本品不能代替药物"
  - 保健食品广告须经审批

### 5.3 其他相关法律
- **《消费者权益保护法》**（2013修正）
  - 来源：https://flk.npc.gov.cn
  - 第二十条：经营者提供商品信息应当真实、全面，不得作虚假或引人误解的宣传
- **《反不正当竞争法》**（2019修正）
  - 来源：https://flk.npc.gov.cn
  - 第八条：经营者不得对其商品的性能、功能、质量等作虚假或引人误解的商业宣传
- **《电子商务法》**（2019施行）
  - 来源：https://flk.npc.gov.cn
  - 第十七条：电商经营者发布的商品或服务信息应当真实、准确

## 六、法规引用规范

检查报告中引用法规时，使用以下格式：

```
【严重】"全网最低价" → 违反《广告法》第九条第（三）项（绝对化用语禁止）
【警告】"加我看更多款" → 违反内容社区《商业导流治理规则》（站外引流禁止）
【建议】体验分享未标注广告 → 参考《互联网广告管理办法》第九条（种草标注要求）
```
