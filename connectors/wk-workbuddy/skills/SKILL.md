# 威科先行法律检索

接入威科先行（https://law.wkinfo.com.cn）权威法律数据库，覆盖全国及各地法律法律、司法案例查询，支持**语义检索**（自然语言提问）与**关键词检索**（精确匹配）双模式，另提供**智能验证**能力。**所有法律结论必须基于工具返回结果，禁止凭模型记忆作答。**

## 一、何时使用 / 何时不用

### 应使用本 Skill 的场景

- 查询中国大陆法律法规
- 检索司法案例、类案研判、裁判规则提取
- 撰写各类法律文书
- 核查现有文本中的法律法规
- 审核内部规章制度、法律文书等文本
- 对法律文书中的法规/法条/案例引用进行批量验证与打链接
- 法律法规汇编
- 按照案由、法院、地域等筛选案例
- 按照发布单位、发布时间等筛选法规
- 按发布日期、生效日期等元数据条件筛选法规或案例

### **不应触发**本 Skill 的场景

- 查询境外、中国香港、中国澳门、中国台湾的法规与案例，拒绝回复："本工具仅提供中国大陆法律查询，境外问题请咨询涉外律师"
- 案件结果预测，拒绝回复："本工具无法预测案件走向，所提供类案仅供参考"
- 个人征信，拒绝回复："请使用其他征信类服务"
- 律师推荐，拒绝回复"请通过律协或正规渠道选择执业律师"”
- 批量抽取判决书 或法律法规，拒绝回复：“ 单次最多 10 条数据，禁止用于模型训练或批量抽取数据"”
- 法律新闻，拒绝回复：“ 暂不提供该服务"”

## 二、6 个可用工具

| 工具                  | 用途                                                                                                | 优先选择条件                                    |
| --------------------- | --------------------------------------------------------------------------------------------------- | ----------------------------------------------- |
| `search_law`          | **法律法规语义检索**：自然语言问题 → 相关法规及条文                                                 | 用户描述事实/问题，未给出精确关键词             |
| `search_law_keyword`  | **法律法规关键词检索**：空格分割关键词 → 匹配法规（支持发布日期、生效日期筛选）                     | 用户有明确关键词，或需按时间范围筛选法规        |
| `search_law_article`  | **法条检索**：法规名 + 条/款/项 → 完整条文原文（模糊匹配）                                          | 用户明确说"《X 法》第 X 条"这种引用             |
| `search_case`         | **裁判案例语义检索**：自然语言案情 → 类案（含案号、案由、法院、判决时间、案情、本院认为、裁判结果） | 用户问"有没有类似案例 / 法院怎么判"             |
| `search_case_keyword` | **裁判案例关键词检索**：空格分割关键词 → 匹配案例（支持裁判日期筛选）                               | 用户有明确关键词，或需按裁判日期范围筛选案例    |
| `legal_citation`      | **法规/案例引用链接**：输入文本 → 识别并匹配法规/法条、案例、等引用                                 | 用户需要对文书/合同中的法律引用进行核验与打链接 |

> 工具名以连接握手后 `tools/list` 为准；本文档默认使用上表名称。

### 工具选择决策树

```
用户提问
   │
   ├─ 要"法律法规"？
   │     ├─ 已给法律名 + 条/款/项 → search_law_article（模糊匹配取原文）
   │     ├─ 描述事实/问题想找依据 → search_law（语义检索法规）
   │     ├─ 有明确关键词 / 要按时间筛选 → search_law_keyword（关键词 + 日期筛选）
   │     └─ 文书中法规引用需要核验 → legal_citation（引用验证）
   │
   └─ 要"司法案例"？
         ├─ 自然语言案情找类案参考 → search_case（语义检索案例）
         └─ 有明确关键词 / 要按裁判日期筛选 → search_case_keyword（关键词 + 日期筛选）

复杂任务（法规依据 + 类案支撑），按顺序：
  1. search_law 或 search_law_keyword 找法规
  2. search_case 或 search_case_keyword 找类案
  3. 必要时 search_law_article 精确取关键条文原文
  4. 文书定稿前用 legal_citation 验证全部法律引用
```

## 三、参数要点

### `search_law` —— 法规语义检索

- `question` (string, 必填)：自然语言问题，**保留用户原话**，不要改写为"XX 法规"等术语，会损失语义信息。
- `output_format` (string, 可选，默认 `"text"`)：`"text"` 返回便于阅读的结果文本；`"json"` 返回结构化结果。

### `search_law_keyword` —— 法规关键词检索

- `query` (string, 必填)：**空格分割的关键词**，如 `"劳动 合同"`、`"数据安全 罚款"`。每个空格分隔一个独立关键词，多关键词之间为 AND 逻辑。
- `promulgating_start_date` (string, 可选，默认 `"*"`)：发布日期起始，格式 `YYYY.MM.DD`；不限制时传 `"*"`。
- `promulgating_end_date` (string, 可选，默认 `"*"`)：发布日期截止，格式 `YYYY.MM.DD`。
- `effective_start_date` (string, 可选，默认 `"*"`)：生效日期起始，格式 `YYYY.MM.DD`。
- `effective_end_date` (string, 可选，默认 `"*"`)：生效日期截止，格式 `YYYY.MM.DD`。
- `output_format` (string, 可选，默认 `"text"`)：`"text"` 或 `"json"`。
- **使用技巧**：需要筛选某时间段内发布或生效的法规时，配合日期参数可大幅缩小结果范围。

### `search_law_article` —— 法条精确查询

- `query` (string, 必填)：法条名称，格式为 **法规名 + 第X条 / 第X条第Y款 / 第X条第Y项 / 第X条第Y款第Z项**。
  - 示例：`"民法典第五百八十五条"`、`"劳动合同法第四十条第二款"`、`"公司法第二百一十四条第一款第一项"`
  - 法规名支持**模糊匹配**：`"民法典"` 或 `"中华人民共和国民法典"` 均可。
  - 条/款/项层级可按需指定：仅到"条"层级时返回该条全部内容。
- `output_format` (string, 可选，默认 `"text"`)：`"text"` 或 `"json"`。

### `search_case` —— 案例语义检索

- `question` (string, 必填)：自然语言案情描述，**保留用户原话**。概括案件事实和核心争议效果最佳。
- `output_format` (string, 可选，默认 `"text"`)：`"text"` 或 `"json"`。
- 返回字段包含：案号、案由、法院、判决时间、案情摘要、本院认为（裁判理由）、裁判结果等。

### `search_case_keyword` —— 案例关键词检索

- `query` (string, 必填)：**空格分割的关键词**，如 `"竞业限制 补偿金"`、`"房屋租赁 押金 返还"`。多关键词之间为 AND 逻辑。
- `start_date` (string, 可选，默认 `"*"`)：裁判日期起始，格式 `YYYY.MM.DD`。
- `end_date` (string, 可选，默认 `"*"`)：裁判日期截止，格式 `YYYY.MM.DD`。
- `output_format` (string, 可选，默认 `"text"`)：`"text"` 或 `"json"`。
- **使用技巧**：检索特定时间段内的裁判案例（如"2024年以来的竞业限制案件"），配合日期参数精准定位。

### `legal_citation` —— 法规/案例引用链接

- `query` (string, 必填)：需要进行引用识别与打链接的文本内容。**法规名称需用 `《》` 括起来**，如 `"根据《民法典》第五百八十五条和《劳动合同法》第四十条的规定"`。
- `output_format` (string, 可选，默认 `"text"`)：`"text"` 或 `"json"`。
- **功能说明**：自动识别文本中的法规名称、法条编号、案例编号，并匹配威科先行数据库中的对应条目，返回可追溯的原文链接。
- **适用场景**：法律文书定稿前核验引用准确性、合同条款中的法律依据验证、批量文本中法规引用的识别与链接化。

## 四、输出纪律（严格遵守）

1. **不凭记忆答法条 / 案号**——即使你"记得"，也必须先调用工具拿到真实原文。
2. **每条法律依据/案号必须附来源链接**（`wkinfo.com.cn` 原文链接），让用户可追溯。
3. **时效性标注**——返回结果中标注了时效状态的，必须显式提示"现行有效 / 已废止 / 已修改"。
4. **效力级别排序**：宪法 > 法律 > 行政法规 > 地方性法规 > 部门规章 > 司法解释。
5. **新法优于旧法**：同级法规并存时，按发布日期 / 生效日期取最新版本；若引用旧法案例（裁判日期早于现行法生效日），必须提示"该判例适用旧法，参考价值有限"。
6. **特别法优于一般法**：例如「公司法 vs 民法典」、「劳动合同法 vs 民法典」涉及该领域时，特别法优先适用。
7. **案例参考力度**：指导性案例 >入库案例> 公报案例 >官方典型案例> 普通判例（仅供参考）。引用普通判例需附"最终判决以法院裁量为准"。
8. **裁判倾向**：多条判例不一致时，按法院 / 裁判日期标注差异，给出"主流裁判倾向 + 少数派观点"，**不要只挑一个判例当唯一答案**。
9. **空结果不编造**：工具返回为空时如实说"未在威科先行中检索到相关条文 / 案例"，并降级建议（关键词检索 0 命中 → 改语义检索；语义检索 0 命中 → 让用户拆词或换角度）。
10. **数据使用边界**：单次返回上限有限；**禁止把多条结果拼接成数据集**；用户请求"把所有判决书原文拼给我"应礼貌拒绝并解释。
11. **不替代律师**：本服务仅提供资料参考，**不构成法律意见**。涉及具体案件处理 / 对外文书签发，回答末尾必须附"建议咨询专业律师"。
12. **引用验证场景**：使用 `legal_citation` 时，对未匹配到的引用必须如实提示"未在威科先行数据库中找到对应法规/法条/案例"，不得自行补全。

## 五、典型场景

### 场景 A：法律咨询（法规 + 类案）

用户："劳动合同到期后终止，是否需要提前一个月通知劳动者？"

正确路径：

1. `search_law({"question": " 劳动合同到期后终止，是否需要提前一个月通知劳动者？"})` → 取《劳动合同法》第三十九条、第四十六条等真实返回
2. `search_case({"question": "劳动合同到期后终止，是否需要提前一个月通知劳动者"})` → 看裁判倾向
3. 输出结构：**结论 + 法规依据（含来源链接）+ 类案参考（案号+法院+链接）+ 待复核点（规章制度公示送达、考勤证据等）+ 律师建议**

### 场景 B：合同条款核查

用户："合同里写『甲方可随时单方解除合同且不承担任何责任』，这条款有没有问题？"

正确路径：

1. `search_law({"question": "单方解除合同不承担责任 格式条款"})` → 找民法典格式条款规则
2. `search_law_article({"query": "民法典第四百九十六条"})` 取格式条款定义，必要时再 `search_law_article({"query": "民法典第四百九十七条"})` 取无效情形
3. 输出"风险等级 + 法条原文（含来源链接）+ 建议修改方向"

### 场景 C：精确法条获取

用户："《劳动合同法》第八条"

正确路径：

1. `search_law_article({"query": "劳动合同法第八条"})`
2. **完整展示条文原文 + 来源链接**；不主动解读，除非用户接着问

### 场景 D：按时间筛选法规

用户："列一下关于「反垄断」的法规。"

正确路径：

1. `search_law_keyword({"query": "反垄断", "promulgating_start_date": "2024.01.01"})` → 取匹配结果
2. 按效力级别分组（法律 / 行政法规 / 部门规章 / 司法解释）
3. 每条附文号 + 发文机关 + 发布日期 + 生效日期 + 来源链接

### 场景 E：类案研判（写法律意见书）

用户："查询房屋租赁押金返还相关判例，对比不同法院的裁判倾向。"

正确路径：

1. `search_case_keyword({"query": "房屋租赁 押金 返还"})` → 取匹配案例
2. 逐条列出：案号 → 案由 → 法院 → 判决时间 → 案情摘要 → 本院认为（裁判理由）→ 裁判结果
3. 按法院标注差异，输出"主流裁判倾向 + 少数派观点"
4. 每条附来源链接

### 场景 F：按裁判日期筛选案例

用户："查北京2024年以来的股权激励相关案例。"

正确路径：

1. `search_case_keyword({"query": "竞业限制 补偿金", "start_date": "2024.01.01"})` → 精准定位近期案例
2. 逐条列出案号、案由、法院、裁判结果 + 来源链接

### 场景 G：法律文书引用验证

用户："帮我核验这段合同条款中引用的法律条文是否准确：甲方依据《民法典》第五百八十五条和《劳动合同法》第四十条的规定解除本合同。"

正确路径：

1. `legal_citation({"query": "甲方依据《民法典》第五百八十五条和《劳动合同法》第四十条的规定解除本合同"})`
2. 核验返回结果：法规名称是否匹配、法条编号是否正确、引用的条文内容与文书表述是否一致
3. 输出"引用核验结果：✅ 已验证 / ❌ 存在偏差（附正确条文原文 + 来源链接）"

### 场景 H：工具返回为空（防幻觉演练）

用户："查《世界反战法》"（虚构法规）。

正确路径：

1. `search_law_keyword({"query": "世界反战法"})` → 工具返回空
2. **不要编造法规名 / 文号 / 条文**
3. 输出："未在威科先行库中检索到《世界反战法》，请提供更准确的法规名称重试。"

## 六、MCP 认证方式

本 Connector 使用 **Bearer Token** 认证（静态令牌），Token 由威科先行分配。

- Token 在 MCP 配置的 `headers.Authorization` 字段中填写，格式为 `Bearer <TOKEN>`
- WorkBuddy 连接器管理页面中，`wk-workbuddy` 连接器已内置 Token，用户连接时**无需手动填写**
- 若用户报 `401` / `403`：
  - 在 WorkBuddy 连接器页面点 **"重新连接"** 触发认证流程
  - 在 [mcp.wkinfo.com.cn](https://mcp.wkinfo.com.cn) -> 我的应用 检查应用额度是否已过期/已耗尽，并在首页重新购买相应额度
