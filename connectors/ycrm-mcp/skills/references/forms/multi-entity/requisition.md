# 调拨单：调拨安排与分批执行

## 识别依据

独立调拨编号、明确分别建立或独立调拨安排支持候选；调出/调入仓组合、需求来源、调拨目的、类型及日期辅助判断，不要求所有属性同时不同。

## 合并与明细

- 同一调拨单多物料是明细；一单可以涉及多个用途描述，不按用途词数量拆分。
- 同调拨安排的分批发货/收货不必然新增调拨主单；具体调拨出库、入库记录与主单要分开识别。
- 两个来源需求可以合并也可以分别调拨，按明确范围及当前契约决定。

## 澄清重点

只列多组仓库或多天安排时，确认是多个调拨计划还是原单分批；物料尚未归属时保留待分配。创建计划调拨看当前支持状态，不要求已有正式单据，不伪造已出入库事实。
