# 报价单：独立报价与打包方案

## 识别依据

独立报价编号、明确分别报价，或客户/商机与独立报价范围支持候选；同客户可以有多份报价。日期、有效期及内容性质差异只辅助，不直接决定数量。

## 合并与明细

- 同一整体解决方案中的产品和服务归入报价明细，不能按项目名称个数拆报价单。
- 两个方案可能是同单选项，也可能是两份独立报价；不同有效期也可能是修订，需结合维护意图。
- 关联商机不同可以提示独立范围，但仍不能替用户决定分单或合并。

## 澄清重点

“标准方案与高级方案”未说明报价单数量时问清单据边界；产品/服务未归属报价时保留待分配。明确“准备给 A、B 分别报价”可以准备新增，当前必填不足再补问，不要求已有单据。
