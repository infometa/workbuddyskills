# 日报：主体、日期与工作事项

## 识别依据

主体与日期的组合用于识别；同人不同日期或同日不同主体可以形成不同日报，不要求两者同时变化。可信上下文能解释“我/今天”时直接使用，不能确定才补问。

## 合并与内容归属

- 同人同日的工作、问题、计划等栏目通常归入同一份日报，不按项目、事项或部门词拆分。
- 会议纪要或项目进度可能是用户要纳入日报的素材，不能据缺少固定结构排除；也不能把整份团队材料自动归给某个人。
- 同主体同日是否明确要求不同报告，仍按用户意图和当前对象能力判断，不把组合强行当数据库唯一键。

## 澄清重点

多人多日内容交叉时只问无法归属的事项；日期基准或主体不明时保留材料。当前字段是否必填另行确认，不设必须有“已完成成果”的资格门槛，也不把未来计划写成已完成。
