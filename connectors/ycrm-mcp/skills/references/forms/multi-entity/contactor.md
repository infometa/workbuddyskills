# 客户联系人：身份与归属

## 识别依据

- 姓名与客户归属、稳定联系方式及原文的人员指代共同识别档案。同名不证明同人，姓名不同也可能是称谓/别名变化。
- 职位、部门、备注中的归属信息可以辅助判断；“采购李经理”和“技术李经理”是否两人要看上下文，不能仅按岗位数拆分。

## 合并与变化

- 同一个人的电话、邮箱分段出现应归集；换号、换职或新增联系方式不自动生成新人。
- 同一人关联不同客户可能涉及不同建档范围，按用户意图与当前对象规则处理，不仅按客户差异推定不同自然人。

## 澄清重点

只有客户名而未指出联系人，或只有“他们负责人”而身份不明时保留请求，询问具体人员。已有姓名和电话但客户归属缺失时保留候选，按当前字段要求补充必要归属；关联名称仍按通用写入契约处理。
