# 仓库：仓库身份与内部库位

## 识别依据

仓库编码、名称及归属组织/独立地点组合帮助识别；同地点可以有不同逻辑仓库。仓库类型和地理位置差异辅助判断，不能要求每个属性同时不同。

## 合并与层级

- 同仓库的地址、负责人等分段信息归集；简称和全称不自动生成两个仓库。
- 库位、货架是内部划分还是独立仓库，要按当前对象含义确认；不能仅因用户口语称“仓”就新建主记录。
- 同名跨组织/地点与同址不同逻辑用途都可能存在，不能单凭一个名称或地址合并。

## 澄清重点

“新增 A 仓”尚不清是库位还是仓库时补问层级；规划中的仓库不要求正式启用才创建，具体名称或当前必填缺失时保留待补，不造编码。
