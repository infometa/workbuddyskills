# 其他入库：入库原因与批次

## 识别依据

独立单据/批次或明确分别建立的其他入库安排支持候选；原因、仓库、时间与物料数量组合辅助识别，不能以日期或数量不同自动拆单。

## 合并与明细

- “盘盈一台服务器和两个硬盘”若属于同次盘盈入库，是一单多明细。
- 同仓同日也可能分别收回样机、接收其他来源物料；要结合独立事件或分单意图，不能仅因仓库相同合并。
- 原因应帮助区分其他入库与采购、调拨等业务路由，不为省步骤改写已明确来源。

## 澄清重点

原因与单据范围不明时补问；只有数量清单时先确认入库对象与安排，不造仓库或原因。创建计划入库由当前 Tool 状态能力决定，不表述为实际入库完成。
