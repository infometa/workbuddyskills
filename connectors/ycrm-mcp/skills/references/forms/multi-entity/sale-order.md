# 合同订单：下单边界与交付明细

## 识别依据

独立订单编号或明确分别下单支持候选；没有编号时结合客户、下单/创建意图、报价或商机来源及产品范围判断。日期、地址、交期差异只作辅助。

## 合并与明细

- 同一订单多个产品/服务归入明细；同编号的分句补充先合并，不重复建单。
- 两个交付地址可能是同单收货安排，也可能是分别下单；两个来源报价也不自动等于两份订单。
- 同客户同日期可以有独立订单；字段值相同不抵消明确的分别建单意图。

## 澄清重点

只有不同地址/日期而边界未明时问同单还是分单；产品未归属时保留待分配。意向/草稿是否可创建看当前能力，不能自动改建商机；编号及金额解释见[合同订单 Profile](../sale-order.md)。
