# 周报：汇报主体与报告周期

## 识别依据

主体与报告周期组合帮助识别；同主体不同周可分别建档，同周也可有多个明确主体。不同汇报单元是线索，不能仅按部门词出现就拆分。

## 合并与范围

- 同份周报的项目进度、成果、风险与下周计划是栏目，不按主题生成多份。
- 个人、团队或部门报告按用户范围及当前字段能力处理，不限个人；整体汇总不自动拆成成员报告。
- 日报素材可以被用户用于整理周报，无结构化复盘不构成候选无效；没有事实的成果或计划不能自动补写。

## 澄清重点

“本周”有可信基准时可解释；多个周期或主体混写时，只补问无法归属的内容。缺主体/周期保留待确认，不恢复强制目标回顾、风险、计划齐备的质量门槛。
