# 拜访签到：事件边界（查询与解释）

本文件只用于查询或解释时判断材料描述的是同次还是多次拜访。记录事实以可信 Tool 返回为准；材料中的事件线索不证明记录已存在，也不构成新增或更新授权。

## 识别依据

独立拜访动作、时间、客户/地址及明确事件分段共同帮助区分。同客户不同时间可多次拜访，不要求客户、地址、动作同时变化。说话人变化、拍照次数和重复字段只作辅助；不因材料含多人就自行拆成多条签到。

## 合并与待明确

- 同次拜访的签到/签退、多议程、照片和反馈归于该事件，不按字段数解释为多个事件。
- 不同人复述同次拜访可能是补充；不同时间提及同客户也可能是在回顾，不能仅按叙述顺序拆分。
- “最近跑了几趟”保留多次但未明的描述，不猜具体时间、客户或次数。拜访计划不能变为已签到事实，也不需要事件“闭环”才保留已明确内容。
