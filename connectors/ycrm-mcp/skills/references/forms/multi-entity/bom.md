# BOM：成品、版本与组成

## 识别依据

- 独立 BOM 编号或成品与明确独立版本/适用范围的组合用于识别；同一成品的两个独立版本可以分别建档。
- 用量比例、结构层级、生效时间与适用场景是辅助信号，先判断是新版本、修改旧版本还是同一 BOM 的选项。

## 合并与明细

- 同一版本分句描述的物料归入其组成明细；替代料没有形成独立配方时先按可选组成理解，当前结构不能承载时说明，不能自行拆主记录。
- “标准版/高级版”只是名称时不足以判断两个独立 BOM；用户明确分别维护时保留两个候选，版本能力由当前 Tool 确认。

## 澄清重点

物料尚未归属成品时补问归属；版本或适用范围冲突时问新建还是变更。组成字段缺失不使已明确的候选消失，也不能把模型熟悉的配方补进去。
