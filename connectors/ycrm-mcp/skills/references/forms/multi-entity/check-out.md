# 结账/反结账：期间与操作事件

## 能力边界

区分读取/维护记录与实际执行结账、反结账。通用表单写入不能证明期间已锁定或解锁；执行财务动作须有 Tool 明确支持。

## 识别依据

- 会计期间、操作方向及明确独立事件用于区分候选。不同期间的分别处理意图、同一期间不同操作时间和结果都可提供边界证据。
- 操作原因与状态差异只作辅助。“12 月结了，确实结了”是同一次操作的重复说明；“先结账，随后反结账”描述两个动作，不能归并为一个方向。
- 状态历程不自动授权重放操作，也不等于用户要求新建历史记录。

## 澄清重点

先确认用户是查状态、整理操作记录还是要求执行动作；期间基准不明时补问。“上个月”有可信时间基准时可解析，不为解析日期而索取多余字段。
