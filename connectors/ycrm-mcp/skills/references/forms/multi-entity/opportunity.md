# 销售机会：独立目标与阶段流转

## 识别依据

独立商机编号、名称与客户/销售目标组合用于识别。同客户不同明确采购目标可以对应多个商机，不要求客户也变化；仅有几个产品名不能证明多个目标。

## 合并与辅助信号

- 销售阶段、预计成交时间、金额、负责人或团队变化可能属于同一机会的流转，只辅助识别。
- “上周演示、本周报价”可能是同一机会的历程，不能据此创建两条，也不自动把最后提到的阶段写回。
- 一个采购目标涉及多个需求或产品时先在该机会内保留；明确独立预算/目标可以支持候选，但不据单个属性自动拆分。

## 澄清重点

同客户多段需求未交代目标关系时，问是同一销售机会还是独立机会；客户或需求归属缺失时保留候选，缺新增字段再按当前契约补齐。
