# 采购退货：退货单与原采购来源

## 识别依据

独立退货编号或明确分别向供应商退货支持候选；没有编号时结合退货动作/创建意图、供应商、原采购来源与分段判断。日期、原因、类型或来源不同只辅助识别。

## 合并与明细

- “同一退货单退一台坏设备和一台多余设备”是一单不同原因的明细，不按原因数拆分。
- 原采购单不同不自动等于两张退货单，能否合并来源按用户范围和当前契约处理。
- 同供应商也可有独立退货事件；同编号补充物料应归入对应明细。

## 澄清重点

多来源或多原因未说明单据边界时问合并还是分别退货；缺供应商/物料归属时保留候选。拟退货可以形成创建意图，不能要求正式退货单已存在，也不能声称已完成实物退货。
