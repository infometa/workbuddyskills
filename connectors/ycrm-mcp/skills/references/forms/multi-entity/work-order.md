# 工单：独立问题与生命周期

## 识别依据

独立工单编号或明确不同服务问题支持候选；客户/申请方、设备/产品、问题描述及服务请求关系辅助判断。同客户可以多个问题，不要求申请方同时变化。

## 合并与变化

- 同问题受理、处理、关闭及重开可能属于一条工单，不能按处理阶段或时间拆分。
- 多设备可能涉及一个共同问题，也可能需要分别处理；设备数量不自动决定工单数。
- “又报修”可能是旧问题复发或新问题，结合编号及问题描述判断，不能只凭副词新增。

## 澄清重点

先明确新问题还是原工单继续处理、多设备是否分别建单；只有“有客户报修”而客户/问题不明时保留任务并补问。明确创建服务请求不要求工单此前已存在，草稿状态看当前 Tool。
