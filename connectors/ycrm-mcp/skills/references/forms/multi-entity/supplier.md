# 供应商：主体、集团与别名

## 识别依据

独立供应商编码、法定名称或统一社会信用代码是主体线索；明确列出的合作方及原文指代帮助分组。税号/名称有冲突时保留冲突，不用模型判断擅自合并。

## 合并与区别

- 同主体的地址、电话、银行等分段信息归集；属性变化不自动形成新供应商。
- 集团、子公司和品牌称呼可能指不同建档主体，按用户实际范围区分，不机械要求都有独立税号才能形成候选。
- 明确枚举有助于识别，但多个名称仍可能是别名；不能仅按标点拆记录。

## 澄清重点

只说“华为”等集团称呼而涉及多个账户/公司时问对应主体；只说“多家供应商”时保留任务与数量不明状态，不生成虚构名称或静默忽略。
