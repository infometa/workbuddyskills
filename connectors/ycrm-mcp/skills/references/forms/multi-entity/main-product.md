# 产品：产品身份与计价属性

## 识别依据

独立产品编码/SKU 或明确不同产品身份可形成候选；名称、规格、品牌及别名用于核对。名称不同不能直接证明产品不同，编码相同但材料冲突时也不能自行拆分掩盖冲突。

## 合并与区别

- 同产品按月/年收费、多单位或多个价格条件不自动变成多个产品，按当前字段判断属性、明细或独立 SKU。
- 所属组织或可见性差异不构成跨权限发现依据，也不证明存在两个产品；只能使用当前可见数据判断。
- 同产品属性分段出现归集，不按每个配置选项分别新建。

## 澄清重点

“协同平台”与“办公云”是否别名不明时补问；同款不同规格未说明是否分别建档时明确 SKU 边界，不能把通用产品功能描述变成主数据。
