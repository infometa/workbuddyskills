# 拜访计划：参与人员、目标与安排

## 识别依据

独立计划编号或明确分别安排支持候选；客户、日期、执行人员及拜访目标的组合帮助区分。上述任一属性变化都不能单独决定新计划，同客户也可以有多个独立计划。

## 合并与区别

- “张三、李四一起拜访 A，谈需求并演示产品”通常是一项安排、多参与人和多议程。
- “张三周一谈需求，李四周五做验收，分别建计划”明确两项；缺“分别”且关联不明时保留可能分组，请用户确认。
- 多日期可能是系列安排，也可能是独立计划；目标不同可辅助判断，不能要求客户也变化。
- 电话、线上会议是否归入拜访计划按用户语义及当前对象能力，不设线下限定，也不自动把所有沟通安排纳入。

## 澄清重点

先问一起执行还是各自安排、同计划多议程还是独立目标；主体或日期无法从可信上下文确定时补必要事实。缺项保留候选，不以“计划尚未发生”排除。
