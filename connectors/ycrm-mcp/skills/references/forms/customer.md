# 客户 Profile

## 对象识别

客户表示业务往来的客户主体；简称、品牌和集团名可能指向同一主体，也可能涉及不同法人，按用户上下文和当前对象结果区分。

## 易混字段语义

| 概念 | 识别与边界 |
| --- | --- |
| 客户名称、简称 | 表示本条客户主体；不能因同时出现全称与简称新增两条客户 |
| 关联客户 | 表示本客户与另一客户的关系；不能拿它代替本条客户名称，也不能由名称相似推断关系 |
| 负责人、协作人 | 表示负责或协作该客户业务的人员；不能将客户侧联系人自动作为负责人或协作人 |
| 客户联系人 | 表示客户侧对接人员；“增加联系人”需结合已有上下文和当前字段判断是独立联系人建档还是客户联系人子表，已明确时不重复澄清 |
| 级别、行业、分类 | 按各自字段与当前选项匹配；不能用名称相近的分类字段承接另一业务含义 |

## 操作差异与条件入口

- 新增可能涉及多个模板；仅在必需模板无法唯一确定时请求选择，查询不受模板数量阻塞。客户名称及其他字段是否必填由当前新增字段决定。
- 涉及联系人等子表行时读[子表写入](../subform-write-rules.md)，展示或核验行时读[子表读取](../subform-read-rules.md)；不把联系人姓名列表压成客户名称。
- 导入图片/附件时读[文件规则](../file-assets.md)；图片区分 URL 数组与附件对象，文件成功导入仍需单独写入客户记录。
- 人员或关联客户按[写入规则](../form-data-write.md)区分服务端解析的自然值和实际被修改的目标；不为同名回传无条件增加组织查询。
