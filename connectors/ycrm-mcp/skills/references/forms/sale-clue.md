# 线索 Profile

## 对象识别

线索描述潜在客户的留资、需求与跟进信息，可能以联系人姓名显示。含公司名称不代表用户要求客户建档；创建或更新线索不自动授权线索转客户。

## 易混字段语义

| 概念 | 识别与边界 |
| --- | --- |
| 联系人姓名、公司名称 | 分别指人员与企业；公司名称不能补作联系人姓名，同公司也可能有不同联系人的线索 |
| 线索池 | 线索的归属或管理范围；不能用来源渠道或跟进状态替代 |
| 来源 | 线索获得渠道或来源事实；不因出现展会、电话等词就猜选项，先确认文本语义与当前选项一致 |
| 跟进状态 | 表示进展；材料中表达意向不自动等于某个当前状态值 |
| 负责人、跟进人、线索联系人 | 分别按对应业务角色识别；一个角色已知不能补齐其他角色 |
| 跟进时间、下次跟进时间、创建时间 | 分别表示发生时间、未来安排和系统建档时间；不能相互替代或统一填当前时间 |

## 操作差异与条件入口

- 姓名、联系方式、线索池等是否必填由当前新增元数据决定，不恢复固定必填清单；只更新一个字段时不索取未变化的旧字段。
- 线索池等关联值使用当前字段允许的自然值。人员选择、存在性验证或限定范围确有需要时才读[组织规则](../organization.md)；其他关联处理按[写入规则](../form-data-write.md)。
- 图片、附件及子表只有当前字段存在且任务涉及时才进入[文件规则](../file-assets.md)或[子表写入](../subform-write-rules.md)，不预设每个模板均提供。
