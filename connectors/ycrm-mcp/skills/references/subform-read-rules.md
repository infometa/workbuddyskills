# 子表单读取

仅在展示、查询核验或写后核验涉及 `SUB_FORM` 时加载；主表查询不需要本文件。

## 元数据与行

1. 当前场景字段 Tool 的 `needChildField=true` 展开一层子表字段；`ycrm_form_detail_field_list` 默认不展开，需要时显式设置。
2. 识别 `fieldDomType=SUB_FORM` 父字段，从其 `referRule` 取得确切关系 key，使用对应子表元数据解释行字段。父字段 `fieldName`、关系 key 与行 ID 不能互相替代。
3. `ycrm_form_data_dtl(needSubForm=true)` 展开一层业务行；它与 `needChildField` 分别控制数据和元数据。
4. 多个子表按各自关系 key 分开解释。子表内再有 `SUB_FORM` 时需重新确认下一层能力，不默认递归。

## 完整性

| 返回状态 | 解释及处理 |
| --- | --- |
| 未请求展开 | 未读取子表，不能说没有行 |
| 已展开、结构完整且对应集合为空 | 本次返回该子表无行 |
| 缺字段、结构不完整或疑似截断 | 证据不完整，不能认定为空、已删除或已经全量 |

当前 `ycrm_form_data_dtl` 只按对象和记录读取详情，并可用 `needSubForm` 控制是否展开子表；没有子表筛选或分页参数。疑似截断时报告未核验部分，停止相同请求的无效重发。

列表保持父记录粒度；子表过滤与主表候选范围按[查询规则](form-data-query.md)处理。读取本身不产生写入意图，也不组装写入参数。
