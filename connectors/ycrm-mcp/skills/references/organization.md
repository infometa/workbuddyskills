# 组织架构查询

组织 Tool 只返回业务名称和权限范围内的必要展示信息。

纯组织查询不加载表单、模板或对象索引；组织信息仅用于用户请求的范围，不能扩大关联业务数据权限。

## 人员

- `ycrm_org_user_list` 支持人员名称包含匹配、部门名称精确匹配、在职状态过滤和分页（`page`/`pageSize` 默认 1/20）。
- 人员查询返回人员及其全部有效所属部门路径。
- `staffStatus` 默认 `true`；查询离职人员使用 `ycrm_org_user_list(staffStatus=false)`（详情接口只覆盖有效人员）。
- 按部门名称过滤人员时显式传 `needSubDept`：仅当用户明确要求包含下属部门时为 `true`，否则显式传 `false`。缺省值依赖服务端语义，显式传参让请求自描述、可审计。
- `needSubDept=true` 时必须同时提供部门名称。
- `ycrm_org_user_detail` 按人员名称查询有效人员详情；名称重名时按当前权限范围内的服务返回顺序取第一条，多条同名时向用户说明实际使用的是哪一位（可展示其部门路径辅助确认）。
- 组织查询使用组织 Tool 的查询参数；表单过滤、写入和审批下一节点人员解析分别遵循对应 Tool 的字段/参数约束。解析结果以名称传递给下游 Tool，不使用或推导内部用户 ID。

## 部门

- `ycrm_org_dept_list` 支持按部门名称和直接父部门名称过滤（`page`/`pageSize` 默认 1/20）。
- 部门名称支持包含匹配，直接父部门名称按 Tool 约定精确匹配。
- 部门查询返回扁平分页列表，不返回树形结构；需要层级时逐层按 `parentDeptName` 查询，每层检查全部必要分页；使用返回可区分的业务名称/路径记录已访问节点，遇到重复节点停止该分支，不重复遍历。同名导致层级无法区分时说明返回能力边界，不猜内部 ID，不补权限外父节点。
- `needManager=true` 时返回主管名称列表；该参数不是按主管名称过滤条件。
- `needRoot=true` 用于真实企业根部门，不能与 `parentDeptName` 同时使用。
- `ycrm_org_dept_detail` 按部门名称查询详情；名称重名时按当前权限范围内的服务返回顺序取第一条。
- 部门列表不支持人员查询的 `needSubDept`；不能向部门 Tool 添加该参数。
- 不额外排序，保留服务端返回顺序。

## 分页与范围

按 `list/count/page/pageSize/hasMore` 处理人员和部门分页。用户要求全部或层级覆盖时完成必要分页；部分结果不能当作全部组织，路径仅解释权限内返回信息。

## 输出边界

不展示 `userId`、`deptId`、`deptParentId`、`managerIds`、内部权限字段或无关技术字段。
