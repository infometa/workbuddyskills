# 表单数据查询

## 查询流程

1. 按[发现规则](form-discovery.md)确认对象和当前可读字段；元数据复用与刷新按[共享规则](shared-rules.md)。需要主表字段时显式传 `needChildField=false`。
2. 分清过滤条件、返回字段 `fieldNames`、排序 `orderList` 与分页 `page/pageSize`，不能互相替代。
3. 有过滤时读取[条件规则](query-condition-rules.md)，完成唯一的条件门禁后调用 `ycrm_form_data_list`；合法条件下空结果表示无匹配。
4. 需要子表详情时按[子表读取规则](subform-read-rules.md)调用 `ycrm_form_data_dtl(needSubForm=true)`；列表始终保持主记录粒度。

## 参数与分页

- `fieldNames` 不传或传空数组时使用服务端缺省投影，当前为 `id`、可读名称字段和已转换有效条件字段。显式投影只改变返回字段。
- 可选展示字段无法确认时可以省略并说明；过滤或排序字段无法确认时停止并澄清，不能静默忽略。排序字段使用当前可读字段或 Tool 明确允许的系统字段。
- `fieldNames` 最多 100 个，条件最多 20 组、每组 20 条，`orderList` 最多 20 项。超限不能截断以改变请求语义。
- `page/pageSize` 默认 1/20，`pageSize` 最大 100。按返回的 `list/count/page/pageSize/hasMore` 翻页，`hasMore=false` 时结束。
- 未指定排序时当前默认 `modified DESC, id DESC`。保持翻页条件和排序一致；不承诺跨请求快照隔离，实时变化影响汇总时说明。
- 用户只要首屏或指定范围时按其范围返回；要求全部、总和、去重或全量判断时读取全部必要分页及字段。中途失败、截断或工具无法覆盖时说明已覆盖范围，不用首屏代表全量。

## 子表过滤的两步分支

当前列表不支持 `SUB_FORM` 行字段过滤主表。即使元数据展开了子表，也不能把子表字段放入主表 `filterGroupList`。

“包含产品 X 的订单”需要先取得主表候选，再逐条详情核验子表存在性：

- 用户范围明确、工具能完整覆盖时按已有授权执行，不为同一查询额外确认。
- 改变范围、需要大量调用或只能部分完成时，说明候选范围、完整性与成本，确认具体方案后执行。
- 将用户条件分别映射为主表筛选与子表详情核验；主表候选必须覆盖所有可能命中的记录。`主表条件 AND 子表条件` 可先按主表条件缩小候选；`主表条件 OR 子表条件` 不能只查询主表条件分支。没有主表过滤条件时可按接口契约查询可见主记录，但应评估范围和调用成本；不能伪造条件或把候选结果当成最终匹配结果。
- 子表行数不作为主记录数。单详情仍截断且无细粒度读取能力时停止重复调用，说明不能给出完整结论。

## 结果说明

按用户需要展示字段。复杂查询简述实际条件、排序及分页范围，不将权限条件或未支持条件表述为已执行的用户筛选；字段 null 按返回含义展示，无数据按空列表解释。
