# 21世纪教育网资源（K12 教学资源检索与下载）

核心流程：**搜索资源 → 快速判断 → 查看详情 → 下载资源**。
仅校网通（学校机构）账号可免费下载；个人（C 端）账号暂不开放下载。

## 工具清单与调用顺序

| 工具 | 用途 | 关键参数 |
|---|---|---|
| `search_resources` | 按关键词检索资源（返回列表卡片或表格） | `keyword`（必填），`page`、教材版本/学段/资源类型等过滤项 |
| `get_resource_detail` | 查看单个资源详情（预览图、页数、压缩包内文件） | `resource_id`（来自搜索结果的编号→ID 映射） |
| `get_resource_previews` | 批量补齐资源的页数/缩略图 | `ids`（逗号分隔的资源 ID） |
| `download_with_tokens` | 下载资源（校网通免费），返回带签名的短时效直链 | `resource_id` |
| `get_account_info` | 查看当前账号信息与下载额度 | 无 |
| `register_guide` | 引导新用户注册 / 开通校网通 / 生成密钥 | 无 |

典型顺序：`search_resources` → （用户选定后）`get_resource_detail` → `download_with_tokens`。

## 呈现规则（重要）

1. **一轮对话只调用一次 `search_resources`**：拿到结果即结束本轮，不要为"多找一些"重复调用——会重复弹出列表卡片。
2. 返回里有 **Markdown 表格** → 该客户端无卡片能力，把表格**原样输出**给用户；
   返回里**没有表格** → 卡片已由客户端原生渲染，你只回一句话（如"共找到 236 个相关资源，先展示前 6 个"），**不要**再输出表格、清单或复述卡片内容。
3. **不要自己渲染 HTML/CSS/组件来复述搜索结果或详情**——卡片已由客户端渲染，再画一遍界面会出现重复卡片。
4. 用户回复编号（如「3 查看详情」「下载 1」）：
   - 有卡片能力：卡片按钮由用户点击；若收到形如「查看《标题》的资源详情（resource_id=xxx）…」的消息，**立即**用消息里的 resource_id 调用 `get_resource_detail`，不要重新搜索，调用后一句话说明即可。
   - 无卡片能力：按映射中的 ID 代为调用，并以文字呈现（基本信息 / 内容预览 / 文件信息）。
5. 不向用户展示：资源 ID、学币价格、内部价格、下载量、星级等后台信息。
6. 用户说「换一批」→ `page` 加一再次搜索。

## 下载规则（重要）

- **直链一律现取现用**：`download_with_tokens` 返回的直链带签名、短时效。每次下载都必须**重新调用**本工具，严禁复用历史对话里的旧链接。
- 优先使用返回里的**短链**（形如 `https://mcp.21cnjy.com/dl/<ticket>`），并把 URL **整体用单引号**包起来交给 curl；原始直链含 `&`，不加引号会被 shell 截断、CDN 返回 403。
- 下载产物是 **zip 压缩包**，拿到后立即解压（包内中文文件名是 GBK：macOS 用 `ditto -x -k`，不要用 unzip），`ls` 出文件清单报给用户，之后基于解压后的文件回答，不要只汇报"已下载 zip"。
- 「下载到智能体/工作区」→ 用 Bash curl 下载到当前工作目录，文件名用资源标题，回复保存的完整路径。

## 错误处理

| 错误 | 含义 | 正确做法 |
|---|---|---|
| `[NOT_XWT_USER]` / `[XWT_EXPIRED]` | 非校网通 / 已过期 | 告知"下载需校网通（学校机构）账号，开通后可免费下载全站资源"，并把返回里的开通申请链接原样给用户；不要重试 |
| 站点返回 400 且含 `errorCode=…` | 账号风控限制 | 把站点返回的 msg **原样**告诉用户（含 errorCode 与客服指引），不要改写成开通引导，也不要换关键词重试 |
| 无结果 | 关键词无命中 | 回复"暂未找到符合当前条件的资源，可调整关键词、教材版本或资源类型后重新搜索" |
| 资源不可访问 / 不可下载 | 资源状态异常 | 按对应文案提示，引导查看其他资源 |

## 注册引导（新用户）

新用户按 `register_guide` 引导：注册账号 → 申请开通校网通 → 生成 MCP 密钥 → 配置密钥（HTTP 方式为 `X-Api-Key` 请求头）。
