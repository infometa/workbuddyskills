# position_recommend — 个性化岗位推荐

## 定位

结合考生画像（学历、专业、户籍、生源地、意向城市等）推荐适合报考的岗位，每个岗位带**推荐值（0-99）**和**推荐理由标签**，按匹配度从高到低排序。

**触发话术**：「推荐」「适合我」「帮我推荐」「我能报什么」「有什么好岗位」「哪些岗位适合我」等综合推荐意图。

> ⚠️ 语义是**推荐**（不是精确检索）。单一维度检索（竞争比/进面分/薪资/岗位名查询）请用对应专用工具，见 SKILL.md 工具路由。

## 入参（共 13 个，全部可选，不传则不限制）

| 参数 | 类型 | 说明 |
|------|------|------|
| position_name | string | 职位名称关键词，如「教师」「财务」。不确定时留空 |
| exam_type | string | 考试类型，仅可填：`公务员`(1)、`事业单位`(2)、`军队文职`(3)、`国企`(4)、`银行`(5)、`选调`(6)、`教师`(7)、`选调生`(8)、`遴选`(9)、`医疗`(10)、`三支一扶`(11)、`基层工作者`(12)、`公益性岗位`(13)、`大学生村官`(14)；同义词：`教师编`/`教师招聘`→教师、`事业编`→事业单位、`医疗卫生`→医疗、`国考`/`省考`→公务员。⚠️ 6=选调、8=选调生是两个不同条目 |
| position_area_list | string[] | 意向工作地区列表，**必须传 JSON 数组**：✅ `["安徽省"]`、`["上海市-上海市", "江苏省-南京市"]`；❌ `"[\"安徽省\"]"`（数组套引号变成字符串）、`"安徽省"`（裸字符串）。元素格式为 `省-市-区`、`省-市` 或 `省`，例如：`["上海市-上海市-虹口区"]`、`["河南省-南阳市-方城县"]`、`["上海市-上海市"]`、`["安徽省"]`。支持传入多个地区，如 `["上海市-上海市", "江苏省-南京市"]`。注意：非省/市简称，需使用完整名称，字段自带「省」「市」字样；口语城市要补全成标准形式（「合肥」→`安徽省-合肥市`）。用户没提地区就不传 |
| education | string | **考生本人的最高学历**（是考生的学历，不是岗位要求的学历——工具据此筛出够格报考的岗位）。仅可填：`普通本科`、`硕士研究生`、`博士研究生`、`高职本科`、`专科（大专）`（全角括号，不要简写成"大专"）、`中专`、`高中`、`不限` |
| major | string | 考生本人的专业（**非必问**，仅用户主动提及专业时传入）。**只能传 1 个值**：专业大类、专业小类或专业名称任选其一，如「工学」「计算机类」「软件工程」「计算机科学与技术」。粒度越粗命中越广（传小类比传具体专业名命中多）。禁止并列传多个词 |
| political_status | string | 政治面貌（**非必选**），仅可填：`群众`、`共青团员`、`中共预备党员`、`中共党员`、`民革会员`、`民盟盟员`、`民建会员`、`民进会员`、`农工党党员`、`致公党党员`、`九三学社社员`、`台湾盟员`、`无党派民主人士`。**用户未提供时不要主动询问**，避免匹配面过窄 |
| graduate_year | string | 毕业年份，四位数字如「2026」，用于判定应届生身份 |
| certifications | string[] | 考生持有的证书（开放集），**必须传 JSON 数组**：✅ `["教师资格证", "计算机二级"]`；❌ `"[\"教师资格证\"]"`（数组套引号变成字符串）。语言类证书：`普通话证书`、`英语四级`、`英语六级`、`英语专业四级`、`英语专业八级`；其余按专业类证书传入，如 `["教师资格证", "计算机二级"]`。语言类和专业类各取第一个参与筛选 |
| score_range | string | 往年进面分数区间，用于找分数够得着的岗位，仅可填：`120以下`、`121-130`、`131-140`、`141-150`、`150以上`、`暂无历史进面信息` |
| max_competition_ratio | string | 往年报录比区间，用于避开竞争过于激烈的岗位，仅可填：`0-50:1`、`50:1-100:1`、`100:1-300:1`、`300:1-500:1`、`500:1-1000:1`、`1000以上:1`；比值越大竞争越激烈 |
| recruitment_status | string | 报名状态，仅可填：`即将报名`、`报名中`、`即将截止`、`报名结束`。用户说「现在能报的」时填「报名中」或「即将截止」；「报名结束」是已结束、「即将报名」是未开始 |
| page | int | 页码，从 1 开始，默认 1，**传数字**（如 `1`），不要传字符串 `"1"` |
| page_size | int | 每页条数，**固定传 5**——只取前 5 条推荐结果，不查多余的职位数据；**传数字**（如 `5`），不要传字符串 `"5"` |

## 返回结构

返回 JSON：`{"total": <总数>, "items": [...], "note": <给模型的处理提示，不展示给用户>}`

每条 item 字段：

| 字段 | 说明 |
|------|------|
| position_id | 职位 ID |
| position_name | 职位名称 |
| department | 单位/用人司局（部门名称或用人司局，哪个有值取哪个） |
| region | 职位地区（如"甘肃省-平凉市-庄浪县"） |
| status | 报名状态（"报名中"/"即将截止"等） |
| recommend_score | **推荐值 0-99**，代表与考生画像的匹配程度 |
| recommend_reasons | **推荐理由标签列表**（如"限中共党员""离家近"），原样透出 |
| exam_type / recruitment_num / notice_title / notice_id | 溯源字段：考试类型、招录人数、公告标题/ID，用于追问详情或查公告原文 |

## 使用流程

1. **条件不明确时先问**：用户未提供学历、意向地区时，先问清这两项，不要用空条件全量推荐。**专业不必主动询问**，仅用户主动提及专业时才传 major
2. 解析用户画像信息，映射为上述参数（position_area_list 用「省-市-区」完整名称、education 精确取值、exam_type 用自然语言词）
3. 调用工具获取推荐列表（含 total/items/note），**page_size 固定传 5**，只取前 5 条，不查多余的职位数据
4. **展示规则**：
   - **主要字段**（必显示）：职位名、部门/单位名称、岗位地区、报名状态
   - **次要字段**（可选显示）：推荐值、推荐理由、其他（考试类型、招录人数等）
   - 推荐结果按推荐值从高到低排序
   - **查多少显示多少（强制）**：`page_size` 固定传 5，本批查 5 条就**完整展示** 5 条并说明总数（total），**禁止多查之后只挑一部分展示**（用户翻下一页会错位）；用户想看更多时传 `page=2` 再查下一批 5 条，`page_size` 保持不变；总数较多时，问用户是否按地区或考试类型缩小范围
   - **推荐值只代表与考生画像的匹配程度，不是录取概率**，不要这样表述
   - 个别岗位没有推荐理由时，只陈述客观信息，不要编造推荐理由

## 注意事项（强制遵守）

- **政治面貌不是必选项**，用户未提供时不要主动询问，避免匹配面过窄。仅当用户主动提及或明确有政治面貌要求时才使用此参数
- **推荐理由和推荐分数是工具返回值，必须原样展示，不得猜测、编造或自行生成**
- `position_area_list` 必须用完整名称格式：`省-市-区`（如"上海市-上海市-虹口区"）、`省-市`（如"河南省-南阳市"）或 `省`（如"安徽省"），地区粒度按用户表述对齐，不要随意补齐更细层级
- 枚举字段取值必须与本文件完全一致（education 的"专科（大专）"为全角括号；exam_type 用自然语言词）。**不在枚举里的值会被静默忽略**——过滤条件不生效但不报错，查出比预期多的结果
- 用户问到学历要求、专业要求、政治面貌要求、报录比和报名时间等详情时，说明需查阅招考公告原文
- 岗位是否接受某个专业，需让用户核对公告原文
- 结果为空时：若传了专业条件，很可能是岗位库专业数据不全（约 75% 岗位未登记专业要求），建议先去掉专业条件再推荐，并提醒用户"专业是否符合以公告原文为准"；**学历、政治面貌是硬性资格，不要放宽**。**放宽重查最多 2 次**（含首次查询累计不超过 3 次调用），2 次重查后仍无结果即停止查询，如实告知用户暂无匹配岗位，请用户调整条件，不得反复重试
- **结果字段为空时如实告知**：进面分、竞争比、招录人数、推荐理由等字段为空，表示该岗位无此项数据——如实告知用户，不得估算补充，**也不得为补全该字段擅自放宽条件、扩大查询范围或改用其他工具重查**（「结果列表为空」= 一条都没有时，才建议放宽条件）
- **查看职位详情**：用户想深入了解某个推荐职位时，调用 `open_job_detail` 工具（`jobId` 传该职位的 `position_id`）打开详情页，含报考要求、薪资、往年进面分/报录比等
- 服务异常时只以用户视角话术告知暂时无法获取数据（如「暂时没能获取到相关信息，请稍后再试」），不得向用户提及接口、工具、MCP、服务异常等技术细节，不得基于推测提供任何岗位、推荐理由或报名状态信息
- **数组参数必须传真正的 JSON 数组**：`position_area_list`、`certifications` 传 `["安徽省"]`、`["教师资格证", "计算机二级"]`；禁止传 `"[\"安徽省\"]"`（数组序列化成字符串，外层带引号即错）或裸字符串。`page`/`page_size` 传数字（`1`、`5`），不要传字符串
