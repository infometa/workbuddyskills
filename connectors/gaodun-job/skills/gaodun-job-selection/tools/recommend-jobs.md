# recommend_jobs — 职位卡片列表

## 定位

以**卡片列表**形式在会话中展示招考职位：调用后前端把返回的职位渲染成卡片（职位名、考试类型、招考人数、报名状态、工作单位、来源公告、专业标签、地区），用户点卡片或「查看详情」按钮即可在右侧侧栏打开职位详情。本工具按条件**筛选职位列表，不做个性化打分**；「哪些岗位适合我」这类个性化推荐用 `position_recommend`。

**触发话术**：「查询xx的岗位/职位」「查一下XX的职位」「XX有什么职位/岗位」「有哪些招考职位」「帮我看看xx地区的职位」「找工作」等查询/浏览类意图（原 `position_quick_search` 的查询类场景统一改走本工具，`position_quick_search` 已下线）。

**关键词映射**：用户查询里的**职位名、招录单位名、企业名**（如「教师」「税务局」「上海烟草」）作为 `positionName` 关键词传入，模糊搜索；用户没提名称就不传。

## 入参（全部可选；数组参数可多选，用户没提到的不要传，表示不限）

| 参数 | 类型 | 说明 |
|------|------|------|
| positionName | string | 职位名称关键词，模糊搜索。**职位名、招录单位名或企业名均可作为关键词**（如「教师」「财务」「税务局」「上海烟草」），沿用原 `position_quick_search` 的 `position_key` 语义；用户没提名称就不传 |
| examBizType | int[] | 考试业务类型：1=公务员、2=事业单位、4=国企、5=银行。可多选（「公务员和银行」→ `[1,5]`）。**必须传真正的 JSON 数组**：✅ `[1,5]`；❌ `"[1,5]"`（数组序列化成字符串）、`1`（裸数字）。⚠️ 与 `position_recommend` 的 `exam_type`（自然语言词）不是一套口径 |
| targetYearList | int[] | 招考年份，4 位整数，可多选如 `[2025,2026]`；用户没提年份就不传。同样必须传 JSON 数组 |
| positionAreaList | string[] | 地区，标准地域串（`省-市-区` / `省-市` / `省` 均可，带完整「省」「市」字样），如 `["上海市-上海市-虹口区"]`、`["福建省-福州市-鼓楼区"]`、`["广东省"]`；口语城市要补全成标准形式（「合肥」→`"安徽省-合肥市"`、「福建」→`"福建省"`）。可多选。⚠️ 与专项 3 工具的 `region`（省份简称）不是一套格式 |
| recruitmentStatus | string[] | 报名状态，仅可填：`即将报名`、`报名中`、`即将截止`、`报名结束`；可多选；不传返回全部。必须传 JSON 数组 |
| pageNum | int | 页码，从 1 开始，默认 1，**传数字**（如 `1`），不要传字符串 `"1"` |
| pageSize | int | 每页条数，默认 6，最大 50，**传数字**（如 `6`），不要传字符串 `"6"` |

## 返回结构与展示

- 返回 `content`（给模型的一句话摘要，如「本页展示 6 个招考职位，共 120 个」）和 `structuredContent.jobs`（卡片数据，由前端渲染成卡片）
- **卡片已展示给用户，模型不要逐条复述卡片里的职位明细**，只做一句话引导（如说明本次按什么条件筛选、可点击卡片查看详情）
- **查多少显示多少（强制）**：卡片会渲染**全部**返回条目，`pageSize` 传多少就展示多少（默认 6），**禁止多查之后只挑一部分展示**；用户想看更多时传 `pageNum+1` 翻页重查，`pageSize` 保持不变
- 摘要里会带总数（total）和下一页页码提示，按提示转达即可，不要自行编造总数
- 卡片字段（仅供模型理解返回内容，无需复述）：`id`、`positionName`、`examBizTypeName`、`recruitmentNum`、`recruitmentStatus`、`division`、`noticeTitle`、`majorTag`、`regionList`

## 职位详情

用户点卡片或「查看详情」按钮，前端自动打开右侧侧栏详情，**模型无需调用任何工具**。只有 `position_recommend` / 专项 3 工具返回的**文本列表**职位要看详情时，才由模型调用 `open_job_detail`（见 [open-job-detail.md](open-job-detail.md)）。

## 注意事项（强制遵守）

- **空结果**：返回会提示「当前条件下没有查到招考职位」，如实告知用户并建议放宽地区或考试类型、更换关键词，不要编造职位
- **数组参数必须传真正的 JSON 数组**：外层带引号的 `"[1,5]"`、`"[\"安徽省\"]"` 都是错误写法（数组序列化成了字符串）
- 服务异常时只以用户视角话术告知暂时无法获取数据（如「暂时没能获取到相关信息，请稍后再试」），不得向用户提及接口、工具、MCP、服务异常等技术细节，不得基于推测提供任何职位、招考人数或报名状态信息
