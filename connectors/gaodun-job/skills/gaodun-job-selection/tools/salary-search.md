# salary_search — 薪资查询

## 定位

按薪资区间检索岗位。薪资是**月薪，单位元**，区间为模糊匹配。

**触发话术**：「帮我查下工资高的岗位」「月薪 5000 以上的」「工资高的岗位」「薪资高的岗位」「薪资范围 6000-8000 的岗位」等。

> 「薪资」「工资」「待遇」为**等同义词**：用户用任一说法表达薪资意图（如「工资高的」「待遇好的」「薪资多少」），均命中本工具。

## 入参（全部可选，不传则不限制）

| 参数 | 类型 | 说明 |
|------|------|------|
| project_id | string | 考试类型，仅可填：`公务员`、`事业单位`、`国企`、`银行`、`选调`、`教师`、`医疗`、`基层工作者`、`公益性岗位`（自然语言词；同义词：教师编/教师招聘/事业编/选调生/医疗卫生/国考/省考 均可识别）。不传默认按公务员查询 |
| region | string | 意向考试地区，填**省份简称，不带「省」「市」后缀**（正确：北京 / 江苏 / 广东），仅可填：`"国家"`、`"安徽"`、`"北京"`、`"福建"`、`"甘肃"`、`"广东"`、`"广西"`、`"贵州"`、`"海南"`、`"河北"`、`"河南"`、`"黑龙江"`、`"湖北"`、`"湖南"`、`"吉林"`、`"江苏"`、`"江西"`、`"辽宁"`、`"内蒙古"`、`"宁夏"`、`"青海"`、`"山东"`、`"山西"`、`"陕西"`、`"上海"`、`"四川"`、`"天津"`、`"西藏"`、`"新疆"`、`"云南"`、`"浙江"`、`"重庆"`、`"新疆兵团"`；不传表示不限地区 |
| salary_min | int | 薪资下限（最低月薪），如 `5000`，取值范围 0-50000；**传数字**（如 `5000`），不要传字符串 `"5000"` |
| salary_max | int | 薪资上限（最高月薪），如 `10000`，取值范围 0-50000；**传数字**（如 `10000`），不要传字符串 `"10000"` |
| page | int | 页码，从 1 开始，默认 1，**传数字**（如 `1`），不要传字符串 `"1"` |
| page_size | int | 每页条数，最大 50，默认 10，**传数字**（如 `10`），不要传字符串 `"10"` |

> 用户口语里的「月薪 5000 以上」→ `salary_min=5000`；「6000 到 8000」→ `salary_min=6000, salary_max=8000`。

## 返回结构

返回 JSON：`{"total": <总数>, "items": [...], "note": <给模型的处理提示，不展示给用户>}`

每条 item 字段（与其他快速查询工具一致）：

| 字段 | 说明 |
|------|------|
| **position_name** | 职位名称——主要输出字段（必显示） |
| **salary_range** | 薪资区间（如"5000-8000"，月薪，单位元）——**主要输出字段（必显示）** |
| position_id | 职位 ID |
| department | 单位/用人司局 |
| region / province | 职位地区 / 招考省份 |
| exam_type | 考试类型 |
| recruitment_num | 招录人数 |
| competition_ratio | 竞争比/报录比（如"8:1"） |
| interview_min_score | 往年进面分数线 |
| status | 报名状态 |
| notice_title / notice_id | 公告标题/ID |

### 展示规则（强制）

- **主要字段（必显示）**：职位名、**薪资（`salary_range`）**——用户按薪资查询，结果里**每一条都必须带薪资**；值为空的那一格写「暂无数据」，**即使整批结果该字段全部为空，薪资这一列也必须保留在输出里（每格标「暂无数据」），禁止因空值把整列去掉**，不得估算
- **次要字段（可选显示）**：单位、地区、招录人数、竞争比、进面分、报名状态等

## 注意事项（强制遵守）

- 薪资数据为**岗位登记的参考值**，实际待遇以招考公告和用人单位为准；个别岗位无薪资数据时只陈述客观信息、如实标注「暂无数据」，不要估算，**也不得为补全数据擅自放宽条件、扩大查询范围或改条件重查**
- **查多少显示多少（强制）**：`page_size` 传多少（默认 10）就**完整展示**多少条并说明总数（total），**禁止多查之后只挑一部分展示**（用户翻下一页会错位）；用户想看更多时传 `page=2` 翻页重查，`page_size` 保持不变
- 结果为空时建议放宽——优先放宽地区，其次放宽薪资区间。**放宽重查最多 2 次**（含首次查询累计不超过 3 次调用），2 次重查后仍无结果即停止查询，如实告知用户未搜到匹配岗位，请用户调整条件，不得反复重试
- **本工具不返回学历要求、专业要求、政治面貌要求、报名时间等信息**，用户问到这些时说明需查阅招考公告原文，不要推测
- **查看职位详情**：用户想查看某个职位的完整详情时，调用 `open_job_detail` 工具（`jobId` 传该职位的 `position_id`）在侧栏打开详情页，含报考要求、薪资、往年进面分/报录比等
- 服务异常时只以用户视角话术告知暂时无法获取数据（如「暂时没能获取到相关信息，请稍后再试」），不得向用户提及接口、工具、MCP、服务异常等技术细节，不得基于推测提供任何岗位或薪资信息
