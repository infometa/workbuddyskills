# open_job_detail — 打开职位详情侧栏

## 定位

在右侧侧栏打开招考职位的完整详情页：职位信息、招考要求（学历/专业/政治面貌等）、薪资区间、往年进面分/报录比等。

**两个触发路径**：

1. **recommend_jobs 卡片（用户触发，模型不调用）**：用户点击卡片或「查看详情」按钮，前端自动调用本工具打开侧栏，模型无需参与
2. **文本列表职位（模型调用）**：`position_recommend` / `competition_ratio_search` / `interview_score_search` / `salary_search` 返回的职位，用户说「看看这个职位的详情」「第一个岗位具体什么要求」等时，由模型调用本工具

## 入参

| 参数 | 类型 | 必填 | 说明 |
|------|------|:----:|------|
| jobId | string | ✅ | 职位 ID：文本列表职位传该职位的 `position_id`；`recommend_jobs` 卡片传卡片里的 `id` 字段（同一 ID 体系） |

## 返回与展示

- 成功：侧栏渲染完整详情（`structuredContent.job`），`content` 为职位名称——**详情页已展示，模型不要整页复述字段**，可基于返回内容做一句话说明或回答用户的具体追问
- 失败（isError，如职位已下架）：如实告知用户，请其返回列表重新选择；同一 `jobId` 最多重试 1 次，不要反复尝试

## 注意事项（强制遵守）

- **仅支持公考招考类职位**：本组选岗工具返回的职位 ID 可用；实习、校招职位的 ID 体系不同，传入无法打开——不要对实习/校招职位调用（引导学员前往 Hi实习小程序查看详情）
- 不要向用户展示工具名或「侧栏」「MCP」「接口」等内部实现字样，用「打开职位详情」等用户视角表述
- 服务异常时只以用户视角话术告知暂时无法获取数据（如「暂时没能获取到相关信息，请稍后再试」），不得提及技术细节，不得基于推测编造详情内容
