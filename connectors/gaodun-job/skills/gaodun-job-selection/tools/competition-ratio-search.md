# competition_ratio_search — 竞争比（报录比）查询

## 定位

按报录比/竞争比区间检索岗位。比值越大竞争越激烈，通常 **50:1 以上算高竞争**。

**触发话术**：「竞争小的岗位」「报录比低的」「哪些岗位竞争不太激烈」「报录比低于 50:1 的岗位」等。

## 入参（全部可选，不传则不限制）

| 参数 | 类型 | 说明 |
|------|------|------|
| project_id | string | 考试类型，仅可填：`公务员`、`事业单位`、`国企`、`银行`、`选调`、`教师`、`医疗`、`基层工作者`、`公益性岗位`（自然语言词；同义词：教师编/教师招聘/事业编/选调生/医疗卫生/国考/省考 均可识别）。不传默认按公务员查询 |
| region | string | 意向考试地区，填**省份简称，不带「省」「市」后缀**（正确：北京 / 江苏 / 广东），仅可填：`"国家"`、`"安徽"`、`"北京"`、`"福建"`、`"甘肃"`、`"广东"`、`"广西"`、`"贵州"`、`"海南"`、`"河北"`、`"河南"`、`"黑龙江"`、`"湖北"`、`"湖南"`、`"吉林"`、`"江苏"`、`"江西"`、`"辽宁"`、`"内蒙古"`、`"宁夏"`、`"青海"`、`"山东"`、`"山西"`、`"陕西"`、`"上海"`、`"四川"`、`"天津"`、`"西藏"`、`"新疆"`、`"云南"`、`"浙江"`、`"重庆"`、`"新疆兵团"`；不传表示不限地区 |
| ratio_min | int | 竞争比下限（最低竞争比），如 `10` 表示 10:1，取值范围 0-150000；**传数字**（如 `10`），不要传字符串 `"10"` |
| ratio_max | int | 竞争比上限（最高竞争比），如 `50` 表示 50:1，取值范围 0-150000；**传数字**（如 `50`），不要传字符串 `"50"` |
| page | int | 页码，从 1 开始，默认 1，**传数字**（如 `1`），不要传字符串 `"1"` |
| page_size | int | 每页条数，最大 50，默认 10，**传数字**（如 `10`），不要传字符串 `"10"` |

> 用户口语里的「竞争比 50 以下」→ `ratio_max=50`；「竞争比 100 到 300 之间」→ `ratio_min=100, ratio_max=300`。

## 返回结构

返回 JSON：`{"total": <总数>, "items": [...], "note": <给模型的处理提示，不展示给用户>}`

每条 item 字段（与其他快速查询工具一致）：

| 字段 | 说明 |
|------|------|
| **position_name** | 职位名称——主要输出字段（必显示） |
| **competition_ratio** | 竞争比/报录比（如"8:1"）——**主要输出字段（必显示）** |
| position_id | 职位 ID |
| department | 单位/用人司局 |
| region / province | 职位地区 / 招考省份 |
| exam_type | 考试类型 |
| recruitment_num | 招录人数 |
| interview_min_score | 往年进面分数线 |
| salary_range | 薪资区间（月薪，单位元） |
| status | 报名状态 |
| notice_title / notice_id | 公告标题/ID |

### 展示规则（强制）

- **主要字段（必显示）**：职位名、**竞争比（`competition_ratio`）**——用户按竞争比查询，结果里**每一条都必须带竞争比**；值为空的那一格写「暂无数据」，**即使整批结果该字段全部为空，竞争比这一列也必须保留在输出里（每格标「暂无数据」），禁止因空值把整列去掉**，不得估算
- **次要字段（可选显示）**：单位、地区、招录人数、进面分、薪资、报名状态等

## 注意事项（强制遵守）

- 竞争比是**往年历史数据**，仅作参考，不等于今年实际竞争情况
- **查多少显示多少（强制）**：`page_size` 传多少（默认 10）就**完整展示**多少条并说明总数（total），**禁止多查之后只挑一部分展示**（用户翻下一页会错位）；用户想看更多时传 `page=2` 翻页重查，`page_size` 保持不变
- 结果为空时建议放宽——优先放宽地区，其次放宽竞争比区间。**放宽重查最多 2 次**（含首次查询累计不超过 3 次调用），2 次重查后仍无结果即停止查询，如实告知用户未搜到匹配岗位，请用户调整条件，不得反复重试
- **本工具不返回学历要求、专业要求、政治面貌要求、报名时间等信息**，用户问到这些时说明需查阅招考公告原文，不要推测
- **结果字段为空时如实告知**：进面分、竞争比、薪资等字段为空表示该岗位无此项数据，如实告知用户，不要估算补充，**也不得为补全数据擅自放宽条件、扩大查询范围或改条件重查**
- **查看职位详情**：用户想查看某个职位的完整详情时，调用 `open_job_detail` 工具（`jobId` 传该职位的 `position_id`）在侧栏打开详情页，含报考要求、薪资、往年进面分/报录比等
- 服务异常时只以用户视角话术告知暂时无法获取数据（如「暂时没能获取到相关信息，请稍后再试」），不得向用户提及接口、工具、MCP、服务异常等技术细节，不得基于推测提供任何岗位、招录单位或报录比信息
