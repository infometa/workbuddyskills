# 面试刷题 · Buddy 应用胶囊配置清单

> 交付对象:WorkBuddy Buddy 应用产品配置侧。用于在 market/branding 配置层创建"一键入口胶囊"(用户点击直接进入对应场景,无需打字)。
> 本清单每条参数均经**线上 DMS 复核 + 接口实测**,点下去不会报错。验证出处见文末。

> 运行时唯一事实源为 `data/capsules.json`；本文件保留产品说明、容量提示和验证出处。应用侧注入稳定的 `capsuleId`（A1-A4、B1-B8），skill 不接受同次注入再覆盖抽题过滤参数。

## 0. 支持范围与注入约定

### 支持的项目(仅三个)

| 项目 | projectId | 线上可用题数(status=4) |
|---|---|---|
| 公务员 | 100520929 | 12436 |
| 事业单位 | 100523443 | 3693 |
| 银行 | 1000648 | 169 |

**央国企(100534841)、实习/校招(100535479)不在支持范围内,不提供胶囊。**

### 注入约定

每个胶囊点下去注入两类参数:

| 参数类 | 字段 | 说明 |
|---|---|---|
| 抽题参数 | `projectId` / `questionTag` | 喂给后端刷题抽题接口 |
| 会话初始态 | `mode` / `plannedQuestionCount` | 喂给 session-protocol |

**铁律**:`questionTag` = 题型配置关联表(rel 表)的主键 rel_id,**必须与 projectId 配对传**——同一题型在不同 project 下 rel_id 不同。单独传 rel_id 会跨方向串味。

- `mode=练习`:单题作答,答完出单题报告
- `mode=模拟`:默认 3 题连答,答完出整场总结
- 胶囊已定死 mode,进入后 session-protocol 的"未指明模式只问一次"逻辑应跳过,别再问"练习还是模拟"

## 5. 落地提醒(给产品配置侧)

1. 每个胶囊在 branding/input 配置里写死两组值:抽题参数 + 会话初始态。`mode` 是关键——练习胶囊触发单题报告,模拟胶囊触发整场总结,别配反。
2. `questionTag` 的 rel_id 必须与 projectId 同源配置,不可跨 project 混用。
3. 胶囊点进去后首条话术已给出(见各表"进入后首条话术"列),可直接填入 input 配置。
4. 上线后如遇 `NO_QUESTION` 空题,是题库侧问题不是胶囊配置问题,转后端补题。
5. 仅支持公务员/事业单位/银行三项目,其他方向不提供胶囊入口。
