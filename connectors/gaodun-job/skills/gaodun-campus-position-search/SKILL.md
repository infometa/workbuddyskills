# 校招职位搜索（gaodun-campus-position-search）

基于 `search_campus_position` MCP 工具，从高顿业务系统检索校园招聘岗位（正式秋招/春招，区别于实习岗位），帮助用户了解校招机会。

## 触发场景（强制关键词门槛）

**本技能有强制触发条件**：用户查询中必须明确包含"校招""校园招聘""秋招""春招"字样之一，否则一律不得使用本技能。

- ✅ 可触发："2026 届银行校招""字节跳动校招""有哪些春招岗位""上海烟草校招"
- ❌ 禁止触发："上海烟草的职位""字节跳动有什么岗位"——虽涉及企业职位，但未出现校招类字样，不得调用本工具，更不得自行推测用户想查校招

满足关键词门槛后，适用场景：

- 用户查询校招岗位，如"2026 届银行校招""字节跳动校招"
- 用户想了解某企业/行业的校园招聘机会
- 用户想查看最新上架的校招信息（不传关键词时按更新时间倒序返回全部）

## 核心能力

1. **关键词检索**：按校招或企业名称模糊搜索，如"银行""字节"
2. **最新优先**：不传关键词时返回全部上架校招，按更新时间倒序
3. **信息精简**：每条校招仅含校招名称、工作地点，便于快速浏览

## 调用方式

调用 `search_campus_position` 工具：

| 参数 | 类型 | 必填 | 说明 |
|------|------|:----:|------|
| position_name | string | - | 校招职位名称关键词，模糊搜索，传校招或企业关键词（如"银行""字节"）；不传则返回全部上架校招（按更新时间倒序） |
| page_num | int | - | 页码，从 1 开始，默认 1，**传数字**（如 `1`），不要传字符串 `"1"` |
| page_size | int | - | 每页条数，**默认传 10**，与一次打算展示的条数一致；仅当用户明确要求一次看更多时才增大，**传数字**（如 `10`），不要传字符串 `"10"` |

## 使用流程

1. 解析用户查询中的企业/行业/校招关键词 → `position_name`
2. 调用工具获取校招列表（含分页信息 total/pageNum）
3. 向用户呈现：按列表展示校招名称 + 工作地点。**查多少显示多少（强制）**：`page_size` 传多少（默认 10）就**完整展示**多少条，**禁止多查之后只挑一部分展示**（用户翻下一页会错位）；用户想看更多时传 `page_num=2` 翻页重查，`page_size` 保持不变。**校招名称 + 工作地点就是全部信息，没有更多详情可查**，展示完即结束，不要追问「需要我查看某个校招的更多信息吗」之类的话术
4. **用户指定城市时**：在**当页返回结果内**按 `workCity` 字段本地过滤（如"北京"匹配"北京，上海，深圳"中的"北京"），仅展示含目标城市的条目，并向用户说明已按城市筛选（如「本页按城市筛选后 N 条」）；翻页时传 `page_num+1` 重查并对新一页同样过滤——**始终以工具分页为准翻页，不要为了凑满一页而多查数据再挑着显示**
5. 结果为空时返回提示文本，建议更换关键词后重试

## 注意事项

- `position_name` 为模糊搜索，传企业名或岗位关键词均可
- 该工具仅返回校招名称与工作地点两个核心字段，不要虚构返回中不存在的字段
- 用户未给关键词时，直接不传 `position_name` 获取最新校招列表即可，无需追问
- 返回结果中的 `workCity` 字段可用于本地城市筛选
- **校招职位不支持打开详情**：打开职位详情的工具仅支持公考招考类职位，校招职位的 ID 体系不同，传入无法打开——不要对校招职位调用任何打开详情的工具；用户想看校招职位详情（如何进入详情）时，**引导学员前往 Hi实习小程序 查看详情**
- **校招没有详情数据，不得暗示可查看更多信息**：工具仅返回校招名称与工作地点，没有职位详情、岗位要求、薪资等任何额外信息。展示结果时只客观罗列名称和地点，**不要追问「需要我查看某个校招的更多信息吗」、不要说「可查看详情」等暗示存在更多信息的表述**；用户追问某个校招的详情时，引导学员前往 Hi实习小程序 查看，不要虚构详情内容
- **报名引导**：用户询问「如何报名」「怎么投递」校招时，**引导学员进入 Hi实习小程序 进行报名操作**，不要编造其他报名入口、链接或操作流程

## 禁止行为（强制遵守）

- ❌ **禁止引申工具不支持的参数/功能**：当用户提出工具不支持的需求时（如某种排序/筛选方式），不得说"试试XX参数/可以用XX"，应直接说明当前支持的选项
- ❌ **建议后续操作时禁止推荐别的工具或技能**：只说明操作本身，不得说"可使用XX工具/建议用XX技能"（Hi实习小程序为官方操作渠道，引导学员前往它查看详情/报名不属于此禁止范围）
- ❌ **查询无结果时禁止暴露内部实现**：结果为空时只用用户视角话术告知未找到匹配结果（如「暂时没有找到匹配的校招信息，建议换个关键词再试试」），禁止出现「接口未命中」「接口未返回数据」「数据源无数据」等任何提及接口、工具、MCP、服务或系统内部实现的表述
- ❌ **禁止向学员显示工具名或内部实现字样**：回复中不得出现 `open_job_detail` 之类工具名，以及 MCP、接口、服务端等任何内部实现表述；涉及详情/报名时只用用户视角话术（如「请前往 Hi实习小程序 查看详情/报名」）
- ❌ **工具/MCP 未连接或调用异常时禁止告知用户**：不得向用户提及「MCP 未连接」「工具调用失败」「服务异常」「接口报错」等技术细节，只以用户视角话术回复（如「暂时没能获取到相关信息，请稍后再试」），也不得基于推测编造数据
