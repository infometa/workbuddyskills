# 专业查询（gaodun-major-search）

基于 `search_major` MCP 工具，按学历、专业名从高顿公考业务系统检索专业目录及其下的专业列表，帮助用户核对专业代码、判断所学专业是否符合岗位要求。

## 触发场景

- 查询专业代码、专业大类、专业属于哪类
- 核对所学专业是否符合岗位的专业要求
- 关键词：专业代码、专业大类、专业属于、公考专业目录

## 核心能力

1. **专业目录检索**：按学历 + 专业名精确检索，返回按专业目录（如"2026 年教育部专业指导目录"、"2026 国家公务员考试专业参考目录"）分组的专业列表
2. **目录结构展示**：每项含专业大类（代码）、专业小类（代码）、专业名、专业代码
3. **精确筛选**：支持按地区、专业代码进一步筛选；专业名与专业代码可同时传，实现交集筛选

## 调用方式

调用 `search_major` 工具：

| 参数 | 类型 | 必填 | 说明 |
|------|------|:----:|------|
| education | string | ✅ | 学历，仅可填：`"普通本科"`、`"硕士研究生"`、`"博士研究生"`、`"高职本科"`、`"专科（大专）"`（全角括号）、`"中专"`、`"高中"` |
| major | string | ✅ | 专业名，精确搜索，需传入完整专业名称 |
| region | string | - | 地区，仅可填：`"全部"`、`"国家"`、`"安徽"`、`"北京"`、`"福建"`、`"甘肃"`、`"广东"`、`"广西"`、`"贵州"`、`"海南"`、`"河北"`、`"河南"`、`"黑龙江"`、`"湖北"`、`"湖南"`、`"吉林"`、`"江苏"`、`"江西"`、`"辽宁"`、`"内蒙古"`、`"宁夏"`、`"青海"`、`"山东"`、`"山西"`、`"陕西"`、`"上海"`、`"四川"`、`"天津"`、`"西藏"`、`"香港"`、`"新疆"`、`"云南"`、`"浙江"`、`"重庆"`、`"澳门"`、`"深圳"`、`"新疆兵团"`；不传或传"全部"表示不限地区 |
| major_code | string | - | 专业代码，精确搜索，需传入完整专业代码 |

## 使用流程

1. **确认必填项**：学历（education）和专业名（major）为必填。若用户未提供其中任一项，**先向用户询问，拿到明确取值后再调用**，不要自行猜测或用空值调用
2. 构造参数调用工具（region、major_code 可选）
3. 向用户呈现结果：按专业目录分组展示，每组列出专业大类（代码）、专业小类（代码）、专业名、专业代码
4. 结果为空时返回提示文本，建议放宽筛选条件后重试

## 返回结构说明

返回为按目录分组的 JSON：`{"totalGroups": <目录数>, "groups": [{"majorTable":..., "majorList":[...], "majorCount":...}]}`

- `majorTable`：专业目录（如"2026 年教育部专业指导目录"、"2026 国家公务员考试专业参考目录"）
- `majorList`：该目录下的专业项列表，每项含 `majorCategory`（大类）、`majorCategoryCode`（大类代码）、`majorSubCategory`（小类）、`majorSubCategoryCode`（小类代码）、`major`（专业名）、`majorCode`（专业代码）
- `majorCount`：该目录下返回的专业项数

## 注意事项

- **每次必须调用接口获取专业数据，不得基于记忆或训练数据回答问题**，避免信息过期或错误
- **education 与 major 必填**，用户未提供时先询问，禁止猜测或空值调用
- education 枚举值文字需完全一致（"专科（大专）"为全角括号）
- major 为精确搜索，需完整专业名称
- 不要虚构返回中不存在的字段
