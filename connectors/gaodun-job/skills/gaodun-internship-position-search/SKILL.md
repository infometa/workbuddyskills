# 实习职位搜索（gaodun-internship-position-search）

基于 `search_internship_position` MCP 工具，从高顿业务系统检索实习岗位（数据以实习岗为主，含少量应届全职岗），帮助用户找实习机会。

## 触发场景（强制关键词门槛）

**本技能有强制触发条件**：用户查询中必须明确包含"实习"字样，或明确表述要找"应届全职"岗，否则一律不得使用本技能。

- ✅ 可触发："财务实习""上海烟草实习""本科以上、互联网行业的实习""找应届全职岗"
- ❌ 禁止触发："上海烟草的职位""字节跳动有什么岗位"——虽涉及企业职位，但未出现"实习"字样，不得调用本工具，更不得自行推测用户想找实习

满足关键词门槛后，适用场景：

- 用户查找实习岗位：如"财务实习""产品运营实习"
- 用户带筛选条件找实习：薪资区间、学历要求、行业、城市、企业规模等
- 用户明确要找应届全职岗（`work_type="全职"`，数量较少）

## 核心能力

1. **多维筛选**：按职位名、工作性质、薪资、学历、经验、行业、企业规模、融资阶段、地点组合筛选
2. **分页浏览**：支持页码与每页条数控制，展示 total 总数
3. **结果精简**：每条职位展示职位名、薪资、城市、公司名、公司规模、标签等核心字段

## 调用方式

调用 `search_internship_position` 工具，所有筛选条件均为可选，不传则不限制：

| 参数 | 类型 | 说明 |
|------|------|------|
| position_name | string | 职位名称关键词，模糊搜索，如"财务""运营" |
| work_type | string | 工作性质，单选，仅可填：`"实习"`、`"全职"`（应届全职岗，数量较少）。**默认不传（不限）**：仅当用户明确限定"只看实习"时传 `"实习"`，明确限定"只看应届全职"时传 `"全职"` |
| salary | string | 薪资，单选，仅可填：`"4千以下"`、`"4千-6千"`、`"6千-8千"`、`"8千-1万"`、`"1万-1.5万"`、`"1.5万-2.5万"`、`"2.5万-3.5万"`、`"3.5万-5万"`、`"5万以上"` |
| education | string | 学历，多选（逗号分隔），仅可填：`"初中及以下"`、`"高中"`、`"中专/中技"`、`"大专"`、`"本科"`、`"硕士"`、`"MBA/EMBA"`、`"博士"` |
| experience | string | 经验，多选，仅可填：`"应届生"`、`"毕业1年内"`、`"无经验"`、`"1年以下"`、`"1-3年"`、`"3-5年"`、`"5-10年"`、`"10年以上"` |
| industry | string | 行业，多选，仅可填：`"互联网/游戏/软件"`、`"金融/经济/投资/财会"`、`"广告/传媒/公关/展览"`、`"企业服务/咨询"`、`"教育/培训"`、`"房产/家居/物业/建筑"`、`"快消/百货/批发/零售"`、`"医疗/健康/制药/生物"`、`"电子/通信/硬件"`、`"汽车/机械/制造"`、`"交通/贸易/物流"`、`"化工/能源/环保"`、`"餐饮/酒店/旅游/娱乐"`、`"公共事业/NGO/政府"`、`"农林牧渔/其他"` |
| company_scale | string | 企业规模，多选，仅可填：`"15人以下"`、`"15～50人"`、`"50～150人"`、`"150～500人"`、`"500～2000人"`、`"2000人以上"` |
| finance_stage | string | 融资阶段，多选，仅可填：`"未融资"`、`"天使轮"`、`"A轮"`、`"B轮"`、`"C轮"`、`"D轮及以上"`、`"已上市"`、`"不需要融资"` |
| area | string | 地点，**必须遵循 `"省-市-区/县"`、`"省-市"` 或 `"省"` 格式**，用 `-` 连接层级（如"上海市-上海市-浦东新区"、"河南省-南阳市"、"河南省"）；**不能只传区/县**（如只传"浦东新区"无效），可省略市级或区县级；省、市名称须含"省/市/自治区"等字样，与行政区划全称一致；工具自动解析为城市 id 再筛选；不传或传"全部"表示不限 |
| page_num | int | 页码，从 1 开始，默认 1，**传数字**（如 `1`），不要传字符串 `"1"` |
| page_size | int | 每页条数，**默认传 10**——不查多余的职位数据；仅当用户明确要求一次看更多时才增大；**传数字**（如 `10`），不要传字符串 `"10"` |

## 使用流程

1. 解析用户需求，将自然语言映射为上述筛选条件（严格使用枚举取值，文字需完全一致）
2. 调用工具获取职位列表（含 total/pageNum 分页信息），**`page_size` 默认传 10**，不查多余的职位数据
3. 向用户呈现：按职位列出职位名、薪资、城市、公司名、公司规模、标签等核心字段。**查多少显示多少（强制）**：`page_size` 传多少（默认 10）就**完整展示**多少条，**禁止多查之后只挑一部分展示**（用户翻下一页会错位）；用户想看更多时传 `page_num=2` 翻页重查，`page_size` 保持不变
4. 无匹配时返回提示文本，建议放宽筛选条件后重试

## 注意事项

- **`work_type` 默认不传（不限）**：学生说"查实习岗位""帮我找实习"属于泛指，**不要**传 `work_type="实习"`——数据本身以实习岗为主、含少量应届全职岗，不传即返回全部；仅当用户明确表达"只要实习岗/只看实习"时才传 `"实习"`，明确"只看应届全职"时才传 `"全职"`
- **所有枚举字段取值必须与上文完全一致**，违反约束可能导致查不到结果或服务端报错
- 地区字段需用行政区划全称（"上海市"而非"上海"，"河南省"而非"河南"），格式为 `"省-市-区/县"` / `"省-市"` / `"省"`，**不能只传区/县**
- 无法确定用户想搜的具体省/市时，按用户原话原样传入即可，不要自行猜测
- 不要虚构返回数据中不存在的字段
- **实习职位不支持打开详情**：打开职位详情的工具仅支持公考招考类职位，实习职位的 ID 体系不同，传入无法打开——不要对实习职位调用任何打开详情的工具；用户想看实习职位详情（如何进入详情）时，**引导学员前往 Hi实习小程序 查看详情**
- **报名引导**：用户询问「如何报名」「怎么投递」实习职位时，**引导学员进入 Hi实习小程序 进行报名操作**，不要编造其他报名入口、链接或操作流程

## 禁止行为（强制遵守）

- ❌ **禁止引申工具不支持的参数/功能**：当用户提出工具不支持的需求时（如某种排序/筛选方式），不得说"试试XX参数/可以用XX"，应直接说明当前支持的选项
- ❌ **建议后续操作时禁止推荐别的工具或技能**：只说明操作本身，不得说"可使用XX工具/建议用XX技能"（Hi实习小程序为官方操作渠道，引导学员前往它查看详情/报名不属于此禁止范围）
- ❌ **查询无结果时禁止暴露内部实现**：结果为空时只用用户视角话术告知未找到匹配结果（如「暂时没有找到匹配的职位，建议放宽筛选条件后再试试」），禁止出现「接口未命中」「接口未返回数据」「数据源无数据」等任何提及接口、工具、MCP、服务或系统内部实现的表述
- ❌ **禁止向学员显示工具名或内部实现字样**：回复中不得出现 `open_job_detail` 之类工具名，以及 MCP、接口、服务端等任何内部实现表述；涉及详情/报名时只用用户视角话术（如「请前往 Hi实习小程序 查看详情/报名」）
- ❌ **工具/MCP 未连接或调用异常时禁止告知用户**：不得向用户提及「MCP 未连接」「工具调用失败」「服务异常」「接口报错」等技术细节，只以用户视角话术回复（如「暂时没能获取到相关信息，请稍后再试」），也不得基于推测编造数据
