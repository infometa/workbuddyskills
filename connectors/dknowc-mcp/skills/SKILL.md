# 深知可信工作台 MCP

当用户咨询政策、法律法规、行业标准、办事事项或其他需要可信依据的问题时，按下述规则选择工具。一般情况下优先使用轻量工具，避免不必要的长耗时调用。

当前 MCP Server 提供 3 个工具：

- `credible_chat`：可信问答
- `trusted_search`：可信搜索
- `deep_query`：深度搜索

工具调用时使用原始 MCP Tool 名称。WorkBuddy 界面里可能会自动显示连接器前缀，例如：

- `dknowc-mcp_credible_chat`
- `dknowc-mcp_trusted_search`
- `dknowc-mcp_deep_query`

## 工具选择

### 工具选择规则

按以下优先级判断：

1. 一般咨询、解释政策或办事流程、回答用户提出的具体问题，使用 `credible_chat`。
2. 用户要求搜索材料、查找政策文件、法律法规、标准、原文、依据或链接时，使用 `trusted_search`。
3. 只有用户明确要求“深度研究”“深入分析”“多地区/多政策对比”“系统梳理”或类似复杂研究任务时，才使用 `deep_query`。
4. 不要仅因为问题涉及政策、地区较多或需要引用来源就调用 `deep_query`；可以先用 `credible_chat` 或 `trusted_search` 完成的，优先使用前两者。
5. 如果用户没有明确要求深度研究，默认不要调用 `deep_query`，以降低耗时和超时风险。

### credible_chat

用于一般性的政策、法律、标准或办事咨询，直接回答用户问题。

适合：

- 政策问答
- 办事咨询
- 材料清单说明
- 需要可信溯源报告链接的回答

最小参数：

```json
{
  "query": "深圳公积金租房提取需要哪些材料？"
}
```

常用参数：

```json
{
  "query": "深圳公积金租房提取需要哪些材料？",
  "area": "深圳",
  "interpretation_model": "autoModel",
  "show_reasoning": false
}
```

### trusted_search

用于搜索权威材料、政策文件、事项、知识专库和原文链接。

适合：

- 用户要求搜索材料
- 用户要求查找原文
- 用户要求列出政策依据
- 用户要求返回知识专库链接

最小参数：

```json
{
  "query": "重庆市智能化改造技改补贴政策"
}
```

常用参数：

```json
{
  "query": "重庆市智能化改造技改补贴政策",
  "service_area": "重庆",
  "eff_time": "2026年",
  "max_articles": 3
}
```

### deep_query

仅用于用户明确要求的复杂政策研究、跨地区材料梳理和较长链路查证。该工具耗时较长，存在超时风险，不作为默认工具。

适合：

- 多政策综合研究
- 多地区政策对比
- 需要检索过程和证据材料
- 需要形成研究基础材料

最小参数：

```json
{
  "question": "北京市人才引进政策有哪些类型，分别适合哪些人群？"
}
```

常用参数：

```json
{
  "question": "北京市人才引进政策有哪些类型，分别适合哪些人群？",
  "area": "北京市",
  "show_materials": 5
}
```

## 调用示例

### 示例 1：可信问答

用户问：

```text
深圳公积金租房提取需要哪些材料？
```

调用 `credible_chat`：

```json
{
  "query": "深圳公积金租房提取需要哪些材料？",
  "area": "深圳"
}
```

### 示例 2：可信搜索

用户问：

```text
搜索重庆市智能化改造技改补贴政策，给我政策材料和原文链接。
```

调用 `trusted_search`：

```json
{
  "query": "重庆市智能化改造技改补贴政策",
  "service_area": "重庆",
  "eff_time": "2026年",
  "max_articles": 3
}
```

### 示例 3：用户明确要求深度研究

用户问：

```text
请深度研究并对比北京市、上海市和深圳市的人才引进政策，梳理适用人群、核心条件和主要差异。
```

调用 `deep_query`：

```json
{
  "question": "请深度研究并对比北京市、上海市和深圳市的人才引进政策，梳理适用人群、核心条件和主要差异。",
  "area": "北京市、上海市、深圳市",
  "show_materials": 5
}
```

## 回答要求

- 调用工具后，基于工具返回结果回答用户。
- 如果工具返回了可信溯源报告、知识专库或原文链接，应在回答中保留链接。
- 如果用户明确要求“只调用工具，不要自行回答”，则只展示工具返回结果。
- 不要向用户索要 API Key、access token 或其他连接凭证。
- 如果工具返回空结果，明确说明未检索到可用材料，并建议用户补充地区、时间范围或更具体的关键词，不要编造结论。
- 如果工具调用失败、超时或触发限流，简要说明当前查询未完成，可建议稍后重试或缩小查询范围，不要把认证凭证或服务端内部错误直接展示给用户。
- 涉及政策时，区分工具返回的原文、检索摘要和模型归纳；不要把摘要当作政策原文，不要擅自补充工具未返回的具体条件。
