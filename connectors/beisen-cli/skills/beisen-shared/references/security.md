# 安全规则

> 本文档是 beisen-shared 的子参考。

## 数据分级

| 级别 | 示例 | 展示规则 |
|:---:|------|---------|
| L0 | 组织架构、部门名称 | 正常展示 |
| L1 | 员工姓名、职位、工号 | 正常展示，批量时摘要 |
| L2 | 考勤记录（他人）、绩效结果、晋升记录、候选人/求职者信息（招聘域） | 仅本人可查全部，他人查摘要 |
| L3 | 薪酬、工资条、身份证号、合同 | 二次验证，脱敏展示 |

## 高风险写操作门禁

当前版本所有 CLI 方法均为读操作，不会触发写操作门禁。写方法上线后的 `exit 10` 强制确认协议与批量写规则详见 [write-protocol.md](write-protocol.md)。
