# 安全规则与门禁协议

> 本文档是 beisen-shared 的子参考。

## 数据分级

| 级别 | 示例 | 展示规则 |
|:---:|------|---------|
| L0 | 组织架构、部门名称 | 正常展示 |
| L1 | 员工姓名、职位、工号 | 正常展示，批量时摘要 |
| L2 | 考勤记录（他人）、绩效结果 | 仅本人可查全部，他人查摘要 |
| L3 | 薪酬、工资条、身份证号、合同 | 二次验证，脱敏展示 |

## 高风险操作门禁（exit 10）

> **说明**：v0.2.13 的方法均为读操作，不会触发 exit 10。以下为写方法上线后的预留设计。

### 触发条件（写方法上线后）

- 批量写入 / 删除员工数据
- 管理员修改他人数据
- 其他被 CLI 标记为 `risk: "high-risk-write"` 的写操作

### Agent 处理流程

1. 收到 exit 10 + `type == "confirmation"`
2. 解析 `action` 获取操作名称
3. 解析 `risk` 获取风险等级
4. 向用户展示："即将执行 [action]，风险等级 [risk]，是否确认？"
5. 用户确认 → 追加 `--yes` 重试
6. 用户拒绝 → 终止

### --dry-run 预览

写操作支持 `--dry-run` 模式，预览请求详情而不执行（仅读方法，此能力为预留）：

```bash
beisen-cli <service> <method> --data '<JSON>' --dry-run
```
