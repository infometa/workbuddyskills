# 触发测试清单

用于验证 [SKILL.md](../SKILL.md) 的 `description` 是否能覆盖“做账 / 记账 / 查账”主场景。

## 判定口径

- 句子里明确出现“做账”“记账”“帮我做账”“帮我记账”等动作词，应触发
- 句子里虽然没写“凭证”，但明显是在要求把业务记成账，也应触发
- 纯会计准则咨询、纯解释题、不要求执行做账或查账，不应触发

## 不应触发样例

| 编号 | 用户说法 | 预期 | 原因 |
|------|----------|------|------|
| N1 | 小企业会计准则下，预收款为什么要先挂预收账款？ | 不应触发 | 纯规则咨询，不要求执行做账 |
| N2 | 销售费用和管理费用有什么区别？ | 不应触发 | 纯会计知识问答 |
| N3 | 银行存款科目编码是多少？ | 不应触发 | 纯科目知识查询，不是做账或查余额表 |
| N4 | 明细账怎么查？ | 不应触发 | 当前 skill 明确不处理明细账 |
| N5 | 总账能查吗？ | 不应触发 | 当前 skill 明确不处理总账 |

## 结论

- 这 20 条一句话做账样例，按当前 `description` 应全部覆盖
- 查余额表相关 4 条样例，按当前 `description` 应覆盖
- 纯准则解释、纯科目知识、明细账/总账类请求应排除
