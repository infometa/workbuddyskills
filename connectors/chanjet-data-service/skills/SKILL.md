# 用友发票查验

> 本 Skill 适用于 connector `chanjet-data-service` **v5.0.0+**，要求 WorkBuddy 客户端 **≥ 5.0.0**。

本 Skill 指导你在 WorkBuddy 对话中调用用友发票查验，完成**单张发票真伪查验**。

本 Connector 通过**畅捷通开放平台统一授权**接入（MCP 端点 `https://mcphub.chanapp.chanjet.com/175/mcp`），鉴权模式为**网关托管（`auth_mode: gateway`）**，用户凭证由平台统一签发与注入，无需手动填写。每次请求生成不同的请求流水号，长度不超过35个字符，由开放平台网关完成鉴权。每个用户**每天可免费查验 50 次**，次日零点自动恢复。

用户只需用自然语言描述票面信息；你根据特征收集字段并调用工具。**不要**让用户选择「发票类型」或填写任何内部编码，**不要**给用户暴露任何请求的参数数据 。

## 何时调用

- 用户要求「验真」「查验真伪」「是否真票」「核验发票」
- 用户提供了足以查验的结构化字段（见下表）

**不要**在以下场景调用：

- 无结构化字段，仅咨询政策、税率等
- 仅有图片且尚未识别出代码、号码、日期等关键字段
- 用户一次提交多张发票（当前仅支持单张，需逐张调用）

## 工具：发票查验（chanjet-data-service_chanjetzsApiMcpInvoiceContext）

| 参数            | 必填  | 说明                                |
| ------------- |:---:| --------------------------------- |
| invoiceNo     | ✅   | 发票号码（传统票通常 8 位；**全电票 20 位**）      |
| invoiceDate   | ✅   | 开票日期，**YYYYMMDD**（如 20231011）     |
| invoiceCode   | 视票面 | 传统票：10/12 位发票代码；**全电票传空字符串**      |
| checkCode     | 视票面 | 普票/电子普票/卷票/通行费：**校验码后 6 位**；专票可传空 |
| invoiceAmount | 视票面 | 发票金额                              |

**校验码与金额**：至少提供 `checkCode` 或 `invoiceAmount` 之一。

### 按票面类型向用户提问

| 用户描述 / 票面特征       | 向用户收集                  | 参数填写要点                |
| ----------------- | ---------------------- | --------------------- |
| 增值税专票、电子专票        | 代码、号码、日期、**不含税金额**     | `checkCode` 留空        |
| 增值税普票、电子普票、卷票、通行费 | 代码、号码、日期、**校验码后 6 位**  | `invoiceAmount` 留空或省略 |
| 全电票（20 位号码、无代码）   | 号码、日期、**价税合计**         | `invoiceCode` 留空      |
| 机动车 / 二手车等        | 代码、号码、日期、**不含税价或车价合计** | 金额填入 `invoiceAmount`  |

缺字段时**只追问缺少项**，不要问「你的发票类型是什么」。

## 使用说明

- 需通过畅捷通开放平台统一授权后使用；安装 Connector 并按提示完成开放平台授权即可。**用户无需手动填写任何 Token / API Key**，凭证由平台统一签发与注入。
- **每日免费额度 50 次**（次日零点恢复）。返回有效查验结果时消耗 1 次额度。
- 遇到 **503 / 超时**：建议稍后重试。
- 遇到 **429 / 2003 / 2004**：说明请求过频，请稍后重试。
- 遇到 **`MCP_QUOTA_PACKAGE_UNAVAILABLE`**：说明**当日 100 次免费额度已用完**，告知用户次日自动恢复。（中转层以 HTTP 409 透传，连接器侧以 MCP 错误体呈现，即该 JSON 错误码与文案。）

## 结果呈现

- **成功**：概括真伪结论，可摘要销方、购方、金额、开票日期等；勿编造。
- **失败**：转述服务返回的错误说明，并结合下表给出可操作建议。

## 常见返回码

| 码                             | 含义         | 建议话术             |
| ----------------------------- | ---------- | ---------------- |
| 0000                          | 查验成功       | 正常呈现结果           |
| 1004                          | 校验码或金额错误   | 请核对校验码/金额是否与票面一致 |
| 1005                          | 当日开具发票次日可查 | 建议次日再试           |
| 2006                          | 查验数据不一致    | 请核对票面信息后再试       |
| 2007                          | 查无此票       | 请核对五要素是否有误       |
| 2003/2004                     | 请求过频       | 稍后重试             |
| MCP_QUOTA_PACKAGE_UNAVAILABLE | 当日免费额度已耗尽  | 按实际返回文本回复用户      |

## 常见错误

| 情况       | 处理                     |
| -------- | ---------------------- |
| 号码/日期缺失  | 列出缺失项，说明传统票需代码、全电票只需号码 |
| 金额与校验码都缺 | 说明普票要校验码、专票/全电票要金额     |
| 查验失败     | 转述错误说明，勿伪造结果           |
| 超时       | 建议稍后重试                 |

## 限制

- 仅支持**单张**发票查验；多张需逐张调用。
- 每日免费额度 **50 次**，超限返回 `MCP_QUOTA_PACKAGE_UNAVAILABLE`，次日自动恢复。
- **不要**向用户暴露内部技术细节。
