# WorkBuddy 专家与场景交接

本 Connector 是共享的 Flova 运行层。由 WorkBuddy 专家承接时，先读取该专家实际选择的场景 Skill，核对目标、素材、限制及是否指定服务端 Flova Skill；不要假设宿主已自动加载。

- 场景没有指定服务端 Skill 或项目流程时，仍按[入口 Skill 的双模式规则](../SKILL.md)选择，普通单项媒体默认快速生成。快速生成由当前 Agent 组织创意和模型调用，不强制交给 Flova 项目。
- 已选场景明确要求服务端 Skill 时，核对其生产 ID 或分享码，走项目工作流；新项目首次运行按工具支持通过结构化参数绑定。身份不明时说明缺口，不猜 ID 或替换为相似 Skill。
- 已有项目先读取实际状态，沿用已有会话和 Skill 绑定；不因本 Connector 更新而重建项目或重选 Skill。用户明确要求切换时，按实际工具支持处理。
- 区分专家的场景 Skill、本 Connector 的运行指引与服务端 Flova Skill；各自的名称或标识不能相互替代。项目制由 Flova Agent 负责项目内制作；当前 Agent 传达需求、跟踪状态、呈现结果并取得用户决定。
