# 使用 Flova 灵感

用户选择 Flova 灵感时阅读。灵感定义的是完整任务，可能涉及分析、外部工具及多种交付物；它不构成快速生成、项目制之外的第三种模式。

通过当前连接的灵感工具查找对象并读取完整发布指令，例如 `creation_inspiration_categor_items` 和 `creation_inspiration_batch_get`，参数以实际 schema 为准。名称有歧义时澄清；卡片摘要或启动提示词不能替代完整流程。

保留真实灵感 ID、发布版本和附件相对路径。按依赖顺序完成必需步骤，条件满足时再执行可选步骤，复用用户提供的输入和已完成工作。用户约束和授权优先，不重复索取已经给予的同一项授权。

灵感明确指定模式时按其要求执行；未指定时按[入口 Skill 的模式选择规则](../SKILL.md)选择，默认优先快速生成。分镜、评审和多轮修改不自动触发项目制。

核对所需工具、连接和访问能力。缺少完整指令、必要附件、授权或宿主能力时，说明具体缺口，不编造流程或静默省略必需步骤；替代方案需要符合灵感条件或用户选择。

安装在宿主的本地辅助 Skill 不等于服务端创作 Skill ID。灵感已提供足够方法时直接遵循，不强制用户寻找某个固定名称的辅助 Skill。

交付前对照灵感要求及用户本轮范围，区分完成项、缺失输入和已同意替代项。必需工作仍未完成时，不将部分结果称为完整任务完成。
