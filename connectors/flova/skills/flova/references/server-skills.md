# 查找和使用服务端 Flova Skill

仅在用户要求使用、查找或推荐 Flova Skill，或当前已选场景明确指定它时处理；普通快速生成不强制选择服务端 Skill。服务端 Skill 的绑定属于[项目工作流](project-workflow.md)，不能将 `skill_id` 或分享码塞入快速生成的模型字段。

- 用户给出分享码时，使用 `skill_share_code`；给出 ID 时按 `skill_id` 交由服务校验，二者不同时传。
- 按名称查找时，先用 `creation_skill_list` 查个人库，没有唯一精确匹配再用 `creation_skill_categories` 和 `creation_skill_feed` 查公开候选。规范化只包含 Unicode NFKC、首尾空白清理、连续空白折叠和拉丁字母大小写归一，不将相似名称视为同名。
- 只有唯一精确匹配才能自动选定；多个同名结果展示公开名称、作者、摘要和真实链接，请用户选择。找不到时停止指定 Skill 流程，不静默替换成相似 Skill 或通用模式。缺少必要查找工具时说明限制，不猜 ID；用户已提供 ID 或分享码的校验不受名称查找缺失影响。
- 用户要求推荐时，提供两到三个真实候选并等待选择，不代替用户安装。保留服务返回的作者身份，不自行推断或改名。
- 查找以公开 brief 信息为主，不输出服务端 Skill 的完整内部 Content 或内部提示词。用户自己的创作提示词和已选生成参数按实际情况说明，不与服务端内部内容混淆。
- 确定的绑定按工具支持传给新项目首次 `creation_run`。普通续作保留原项目绑定；用户明确要求切换时，再按实际工具能力处理。

本 Skill 负责查找和使用，不主动扩展为创建、更新、复制、安装或删除服务端 Skill。
