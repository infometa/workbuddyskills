# 更新

用户要求升级或同意处理兼容性问题时，先查询当前安装渠道的更新语义，再执行更新：

```bash
gd-cli update --help
gd-cli update
```

参数、安装来源、lifecycle 开关和 Skill 同步行为以 `update --help` 及命令返回为准；不要复制旧版本的安装命令。

普通版本提示不等于已经升级，也不表示 Skill 已同步；能力发现基于本机实装版本，不为查询能力自行升级。

安装由 WorkBuddy 等宿主管理时，按命令返回的渠道指引处理。不要绕过托管升级、覆盖宿主 Skill 或借其他宿主的全局安装修复；CLI 与 Skill 不必具有相同版本号，兼容性由该渠道的最低版本和验收保证。

若 CLI 已更新但 Agent Skill 验收失败，保留已更新版本，按 stderr 的下一步修复后重新执行更新；不要把失败报告成完整成功。
