# 图片与视频处理

先按 [创作](creation.md) 判断 Agent / Tool 路由。以下选择适用于单次 Tool 任务；业务编排仍交给 Agent，用户明确指定的路线与模型优先。

## 按目的选择 Tool

| 用户目标 | 发现方向 |
| --- | --- |
| 生成新图，依参考图重新创作、整体换风格或融合多图 | `image.generate`；有参考图或使用“改”字不等于必须走 `image.edit` |
| 生成新视频，包括文生、图生、首尾帧或参考素材生成 | `video.generate`；具体素材组合看所选模型 Schema |
| 在现有图片上做有明确目标或选区的编辑 | `image.edit` |
| 去背景、消除物体、修复清晰度、扩画布、改字/识字、分层或转矢量 | 按目的查询相应专用 Tool；不把全部图片操作归为 `image.edit` |
| 以已有视频为主体修改内容，或提升已有视频清晰度 | 分别查询 `video.edit` 或 `video.enhance`；从图片生成视频仍属 `video.generate` |

查询 `tool list`，再按相关 Tool 查询 `model list --tool <tool>` 与 `model get <model> --tool <tool>`。读取完整 `inputSchema`、用途与费用；模型可用性、参数及档位以本次查询为准。不能把某个模型的字段套到另一 Tool。

## 选择模型与准备素材

读取公开模型标识及用途，不依赖后端展示名称做字符串匹配。“标准”和“智能”是稳定的公开分类，但每个工具的具体差异仍看模型详情：标准抠图分离原图可见像素，智能抠图先重绘补全；标准超分和生成式修复的保真边界也不同。标准改图、消除和扩图同样可能生成内容，不能把“标准”理解成所有工具都无损。用户要求保真时核对可保留的范围；重绘可能改变商品结构、文字、人脸或纹理，补全细节是推测。抠图另读 [抠图](matting.md)。

确认本次主图/原视频、修改目标和需保留内容。只带完成任务必需的参考，每张参考明确提供主体、风格、配色或布局中的哪一项；无关参考不上传。Prompt 按“修改对象 → 需要的变化 → 保留内容 → 各参考用途 → 输出要求”组织，取自用户需求与已确认素材。对于只参考风格的图片，说明借鉴范围；通常选语义相关的参考，减少一边提供强主体、一边要求忽略主体的冲突。模型已有的结构化参数放入对应字段。

扩图用自然像素明确目标画布和原图左上角位置，不隐式缩放。主图、选区与参考图各自放入 Schema 指定字段，参考图不能代替 mask。

## 提交前复核 mask

1. 读取所选模型的 mask 说明，确认必填/可选、文件要求及选区语义；按该说明准备与本次原图对应的文件。文件格式合格不代表选区位置正确。
2. 实际查看自动转正后的原图和 mask，再将选区叠加到原图上做预览。逐项确认白区覆盖需处理的主体/部位、没有漏选，黑区包含需保护的内容；核对轮廓、孔洞、边缘及坐标，没有平移、拉伸或选到背景。叠加预览只供复核，提交的仍是 Schema 要求的原始 mask。
3. 白区须非空；全白仅适用于用户明确要处理全图。局部物体需要对应目标轮廓，不能用随意矩形代替；若用户本来指定矩形区域，则按其区域。发现选错先修正再提交，无法可靠定位时请用户圈选或补充目标。
4. 智能模型的可选 mask 可能仅转换成视觉边界提示；按模型详情判断，不能保证选区外像素完全不变。对保护内容有要求时，交付前实际对比。

## 执行与交付

按 [Tool](tool.md) 提交一次并等待同一任务。计量模型先看当前单价与公式；估价不是实扣。未知或中断时查原任务，查询不会补做处理、上传或结算。

结果的视觉/声音效果由调用 Agent 或用户查看，不由 CLI 的效果阈值判通过：改图/消除对比保护区；扩图核对位置及画布；改字核对目标及其他文字；OCR 使用返回识别图坐标；分层检查原生模板和资源；矢量查看实际 SVG 内容；视频查看时长、画面与声音。音轨存在不能证明原声保持。保留服务返回的实际结果，说明观察到的偏差；后续修改按用户授权执行，不因效果不理想自动换模型或重跑。

分层时区分用途：图文分层侧重文字、图片与版式的可编辑结构；智能分层侧重把物件拆成独立图层。层数上限不是实际图层数的保证，不把智能分层当逐字 OCR。交付原生 JSON 及资源，不能称为 PSD。用户要求导入编辑器时，按 [编辑器](editor.md) 发现实际支持的导入/编辑流程，确认可编辑文字、图层与字体替换情况。

多参考改视频时，按模型 Schema 中的素材编号写清每份参考的用途及需保留的原片内容。CLI 会补充原文件名与编号映射；用户文件名在上传后会变化，引用不能只靠下载链接中的文件名判断。
