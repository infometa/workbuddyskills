# 结果解读红线细则

> 本文是 SKILL.md「结果解读红线」的展开细则。核心原则：**预测分数 ≠ 实验事实**，所有输出必须区分数据来源层级并标注来源、版本与查询截止日期。
>
> **适用范围**：第 1、3、4 节（来源分层、标注模板、绝对禁止）为跨模式通用红线，适用于所有模式，包括未来通过 Gateway 新增的模式；第 2 节仅展开当前已稳定的三个模式（分子设计、转化研究、数据智能）。**未列出模式的工具结果，直接套用第 1、3、4 节通用原则执行，无需等待本文更新。**

## 1. 数据来源四级分层

每条结论必须能归入以下层级之一，并在表述中明确区分：

| 层级 | 含义 | 示例 |
| --- | --- | --- |
| 数据库事实 | 来自权威数据库的收录事实 | UniProt 条目、PDB 结构、ClinVar 分级、专利文本 |
| 文献证据 | 已发表文献/临床试验中的报道 | 引文、临床试验分期与状态 |
| 计算推断 | 模型预测或算法分析结果 | pLDDT、亲和力评分、生成序列、突变预测概率 |
| 待验证假说 | 基于证据提出的、尚无直接验证的主张 | 候选靶点机制假说、成药性推测 |

## 2. 分模式表述规范（当前已稳定模式）

> 以下细则按模式展开，仅覆盖分子设计、转化研究、数据智能三个已稳定模式。新增模式上线后若无专节，按第 1、3、4 节通用原则执行。

### 分子设计

- pLDDT、PAE 等置信度指标反映**模型对自身预测的置信**，不得表述为结构正确性的实验证明。
- 生成序列（抗体/多肽/酶）不得表述为已验证的亲和力、稳定性、催化活性或成药性。
- 亲和力评分、热稳定性/可溶性比较为**相对计算指标**，不得写成绝对实验值。
- 只有返回中确实存在结构坐标时，才向用户展示 3D 结构。

### 转化研究

- 病理 WSI 质控结果是对图像质量的算法评估，不构成病理诊断。
- 基于病理图像的基因突变预测、虚拟空间转录组为计算推断，必须标注"算法预测，需实验验证"。
- 病理与基因突变相关结论仅作科研参考，**不得表述为临床诊断结论**。

### 数据智能

- 检索结果标注数据库名称、版本与查询截止日期。
- 变异临床意义以 ClinVar 等收录分级为准；人群频率注明队列来源。
- 检索无结果时明确标记 `not_found`，**禁止编造**蛋白条目、文献编号、专利号或临床数据。

## 3. 标注模板

输出结论时建议包含：

- **来源层级**：数据库事实 / 文献证据 / 计算推断 / 待验证假说
- **数据来源**：数据库名 + 版本，或文献引用
- **时效**：查询/证据截止日期
- **置信与边界**：预测指标的适用范围、反证、外推风险

## 4. 绝对禁止

- 把预测分数写成实验实测值。
- 编造不存在的条目、编号、文献或数据。
- 将病理/突变相关输出表述为临床诊断。
- 在检索无结果时用通用知识"补全"具体编号或数据。
