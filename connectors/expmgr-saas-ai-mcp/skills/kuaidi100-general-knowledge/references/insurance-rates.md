# 保价费率与赔付口径

> 已收录 13 个品牌的保价费率规则。对外答复应提示「以系统实收为准」。
> 计算请调用 `@//scripts/quote_insurance.py`，不要手算。

## 一、通用计算规则

### 1.1 三种计费形态

| 形态 | 判定 | 计算 |
|---|---|---|
| 固定保费档 | 区间内直接定价（如「保价 500 元以内收 1 元」） | 取该档固定金额，不再套最低保费 |
| 费率档 | 按声明价值比例计费（如 0.005） | `保价费 = 声明价值 × 费率`，再与最低保费取大 |
| 免费档 | 固定保费为 0（仅德邦零担 2000 元以内） | 保价费 = 0 元 |

### 1.2 最低保费

```
保价费 = max(声明价值 × 费率, 最低保费)
```

- 最低保费只在**费率档**生效；固定保费档本身就是最终金额。
- 京东重货 / 顺丰卡航的最低保费**按重量分档**：≤40kg 收 2 元，40–100kg 收 4 元，>100kg 收 12 元。未提供重量时按 ≤40kg 档估算并提示。

### 1.3 区间边界

本库统一采用**左开右闭** `(下限, 上限]`：

- 顺丰「0-500 元」指 `0 < 声明价值 ≤ 500`，恰好 500 元仍收 1 元。
- 501 元起进入 2 元档。


### 1.4 单票上限

声明价值超过该品牌上限时**不得保价**，应明确告知超限，不可拆分成多票规避（拆分需按承运方实际规则确认）。

### 1.5 取整

费率档计算结果四舍五入保留两位小数（ROUND_HALF_UP）。例：`1001 × 0.003 = 3.003 → 3.00 元`；`10001 × 0.005 = 50.005 → 50.01 元`。

## 三、品牌易错点

| 品牌 | 易错点 |
|---|---|
| 顺丰 / 京东 | 两档固定保费后直接跳 0.5%，1000 元是分界点而非 1000 元以上才收 2 元 |
| EMS | 固定档只到 300 元；上限 30000 元，超过即不可保 |
| 申通 | 上限仅 10000 元，是全部品牌中最低的，报价前先判上限 |
| 圆通 / 极兔 | 规则完全一致，但都设 30000 元上限 |
| 菜鸟速递 | 无上限标注，10000 元起费率从 0.3% 升到 0.4% |
| 德邦 | 存在易碎易损专用费率 0.8%，且是三段中最高的；上限 100 万元 |
| 德邦零担 | 2000 元以内**完全免费**，这是唯一有免费档的渠道 |
| 京东重货 / 顺丰卡航 | 规则完全相同；最低保费取决于**重量**而非声明价值，漏问重量会算错 |
| 壹米滴答 | 最低保费 3 元为最高，小额保价会被最低保费吃掉 |

## 五、报价应答流程

### 第 1 步：补齐要素

1. **品牌** —— 快递100 平台可选多家，必须问清，不可默认顺丰。
2. **声明价值**
3. **重量** —— 仅京东重货、顺丰卡航需要（决定最低保费）。
4. **是否易碎易损** —— 仅德邦需要。

### 第 2 步：先判上限

声明价值超过该品牌单票上限时，直接告知超限，不进入计算。

### 第 3 步：调脚本计算

```bash
python scripts/quote_insurance.py --brand <品牌> --value <声明价值> [--weight <kg>] [--fragile] [--json]
```

- 返回 `brand_not_found` → 该品牌未收录费率，**禁止估算**，转第六节未收录应答。
- 返回 `over_cap` → 超上限，按超限话术回复。

### 第 4 步：按格式输出

```markdown
**品牌：** 顺丰
**声明价值：** 5000 元
**适用档位：** 1000 元以上，费率 0.5%
**保价费：** 25 元（5000 × 0.005）
**提示：** 实际以系统实收为准；保价为赔偿上限，非保多少赔多少。
```

禁止做法：

- ❌ 费率已过期仍沿用而不提示。

## 七、保价与保险的区别（可答口径）

| 维度 | 保价（声明价值） | 商业保险 |
|---|---|---|
| 性质 | 承运方对丢损赔偿责任的约定，属运输合同条款 | 独立保险合同 |
| 赔付上限 | 不超过声明价值 | 按保额与条款 |
| 举证 | 通常需提供价值证明（发票、订单截图、付款记录） | 按保险条款 |
| 赔付方式 | 按实际损失与声明价值孰低赔付，部分渠道有免赔或折旧 | 按保险条款 |

答复用户时强调两点：

1. 保价金额是**赔偿上限**，不是「保多少赔多少」。
2. 未保价的快件按承运方规则赔付，通常远低于物品实际价值。
