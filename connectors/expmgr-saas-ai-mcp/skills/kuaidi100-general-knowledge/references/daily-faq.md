# 日常快递信息咨询应答口径

> 原则：**能答的答口径，不能答的给路径。**
> 凡涉及具体数值（价格、时效天数、赔付金额、网点数量），一律标注为「须查官方」，不得用经验值代替。
>
> 本文档只覆盖「快递业务常识」。**产品操作类问题**（地址簿、寄件审批、云打印机、高拍仪、到件异常等）见 `@//references/product-ops-setup.md` 与 `@//references/printer-ops-faq.md`。

## 2. 运费与计费重量

**可答 —— 计费逻辑**

```
计费重量 = max(实际重量, 体积重量)
体积重量 = 长(cm) × 宽(cm) × 高(cm) ÷ 抛比系数
```

- 抛比系数由各承运方与产品线决定（行业通行取 6000 / 8000 / 12000 三档），**具体系数须按渠道确认**。
- 运费 = 首重价格 + 续重价格 × 续重单位数，再叠加保价费、包装费、偏远地区附加费等。
- 同一票多件、超长超重件、偏远地区通常触发额外附加费。

**须查官方**：具体首重/续重价格、区域分区表、附加费标准、协议客户折扣。

**应答要点**：先解释「为什么体积大但很轻也贵」，再给查询路径。不要用「一般十几块」这类表述。

## 3. 时效

**可答 —— 影响因素**

- 运输方式：空运 vs 陆运（含液体的快件通常只能走陆运，时效更长）。
- 距离与线路：省内、跨省、偏远地区差异明显。
- 收件时间：错过当日截单时间顺延一天。
- 外部因素：节假日、大促、极端天气、安检升级。
- 特殊品类：酒类推荐陆运，时效按陆运口径。

**须查官方**：具体「X 天送达」承诺、时效产品（次日达/隔日达）的覆盖范围与截单时间。

**禁止**：给出具体天数承诺，或把某家承运方的时效套用到其他渠道。

## 4. 网点与上门取件

**可答**

- 网点、驿站、快递柜的准确位置与营业时间，以快递100 App / 小程序的定位查询结果为准。
- 上门取件需在下单时填写准确地址与联系方式，取件时段以系统展示的可选时段为准。
- 部分区域（偏远、园区、写字楼）存在上楼限制或需到指定地点交接。

**须查官方**：某地址是否在派送范围、具体取件时段、是否支持上门。

---

## 5. 单号与轨迹

**可答**

- 单号由承运方生成，一票一号；转寄或更换承运方会产生新单号。
- 轨迹节点通常包括：已揽收 → 运输中 → 到达派送网点 → 派送中 → 已签收。
- 轨迹长时间不更新，常见原因是干线中转、面单信息异常、超区待转。

**须查官方**：任何具体单号的实时状态。本技能不查单、不推断轨迹。

**应答方式**：引导用户到快递100 App / 小程序 / 官网输入单号查询，或联系承运方客服。

## 6. 签收异常

**可答 —— 处理顺序**

| 情形 | 建议动作 |
|---|---|
| 显示签收但本人未收到 | 先查是否有他人代收、驿站/快递柜、门卫；再联系派件员；仍无结果报承运方客服 |
| 包裹外包装明显破损 | **当场拒收或要求开箱验货**，拍照留存外包装与内件 |
| 内件短少/损坏但外包装完好 | 保留包装与填充物，拍照，尽快报承运方，按要求提供价值证明 |
| 派送地址填错 | 联系承运方改址，是否可改与是否收费由承运方判定 |
| 多次派送失败被退回 | 联系承运方协商重派或自取，退回后重寄需重新下单 |

**关键提醒**：验货与拍照的时间窗口很关键，越早报案越有利于定责。

## 7. 丢损理赔

**可答 —— 流程**

1. 在承运方规定期限内提交理赔申请（**具体时限须查官方条款**）。
2. 提交材料：运单号、价值证明（发票 / 订单截图 / 付款记录）、损坏照片、身份信息。
3. 承运方定责：全损、部分损失、延误，对应不同赔付口径。
4. 赔付金额：保价件按「声明价值与实际损失孰低」，未保价件按承运方未保价赔付规则。

**须查官方**：报案时限、赔付上限、免赔额、到账周期。

**禁止**：承诺赔付金额，或暗示「一定能赔」。

## 8. 包装要求

**可答**

| 品类 | 包装要点 |
|---|---|
| 液体（酒、油、化妆品） | 瓶口二次密封 + 防漏袋 + 独立缓冲，避免与衣物混装；多为陆运 |
| 易碎品（玻璃、陶瓷、屏幕） | 内层气泡膜/珍珠棉包裹，外层硬质箱，标注「易碎、向上」 |
| 3C 与含电池物品 | 保持原包装或用绝缘材料隔离电极，防短路 |
| 粉末类 | 双层密封袋，防撒漏污染其他快件 |
| 贵重品 | 建议保价 + 加固包装 + 拍照留证（含装箱过程） |

**提醒**：包装不合格时取件员可拒收，属正常收寄判定，不是针对个人。

## 9. 寄件准备

**可答**

- 寄件需实名登记（出示有效身份证件），这是收寄验视制度的常规要求。
- 需准备：寄件人/收件人姓名、电话、详细地址、物品名称与大致价值。
- 物品名称要如实填写，不得笼统写「日用品」「礼品」，否则影响安检与理赔定责。
- 取件员会执行开箱验视，拒绝验视的物品不予收寄。

**须查官方**：具体证件类型要求、企业月结账户的开户材料。

---

## 10. 跨境与国际件

**可答 —— 差异要点**

- 国际件禁限寄规则比国内更严，且按目的地国家/地区规定执行，同一物品在不同目的地结论可能相反。
- 需申报品名、数量、价值，用于清关；低报或错报可能导致扣关、退运、罚款。
- 木质包装可能需熏蒸证明；食品、药品、化妆品、电池类通常受限。
- 寄往中国香港、中国台湾、中国澳门按跨境件处理，需报关申报，不属于国内件。

**须查官方**：目的地国家/地区的具体禁限寄清单、申报要求、关税起征点。

**禁止**：对国际件给出「肯定能寄」的结论，或套用国内规则。

## 11. 应答模板

```markdown
**结论：** <能答的结论 / 需核实>
**口径：** <算法、流程或影响因素>
**须核实：** <现有资料无法确定的部分 + 查询路径>
```

## 12. 禁止编造清单（红线）

- ❌ 具体运费金额、首重续重价格、分区价格
- ❌ 具体送达天数承诺
- ❌ 具体理赔金额、赔付比例、报案时限
- ❌ 具体保价费率（未收录品牌的费率，或超出脚本数据范围的估算）
- ❌ 某地址是否在派送范围（除定位查询结果外）
- ❌ 任何单号的实时轨迹

遇到以上问题，统一回复「该数据需以官方渠道为准」，并给出对应查询路径。
