## 6. 寄件订单状态 `status`（寄件列表 / 寄件详情 / 费用订单）

> 接口返回大小写不统一：`querySentCount` 返回 camelCase（`sentWait`、`unPass`），费用统计返回大写（`SENTWAIT`、`UNPASS`）。匹配本表时**不区分大小写**，展示统一用中文分组名，不输出枚举本身。

### 6.1 状态分组（展示口径）

| 分组（展示名） | 包含枚举值                                                                             |
| ------- | --------------------------------------------------------------------------------- |
| 待寄出     | `PRINTWAIT`、`SENTWAIT`、`GOTWAIT`、`UNKNOWN`                                        |
| 已揽件     | `SENTGOT`                                                                         |
| 在途中     | `SIGNEDWAIT`、`TRANS`、`SENDING`、`NATIVE_SIGNED`、`FOREIGN_SEND`、`RELEASED`、`GOBACK` |
| 异常件     | `PROBLEM`                                                                         |
| 已签收     | `SIGNED`                                                                          |
| 已取消     | `CANCEL`                                                                          |
| 待审核     | `CHECKWAIT`                                                                       |
| 已驳回     | `UNPASS`                                                                          |

> **在途统计口径**：异常件是在途中的一种特殊状态。**统计在途数量时必须把「异常件」计入**，即 `在途数 = 在途中（7 个值） + 异常件（PROBLEM）`。分组展示时两者分列，合计才是在途总数。

### 6.2 单值映射

| 枚举值             | 展示中文 |
| --------------- | ---- |
| `PRINTWAIT`     | 待寄出  |
| `SENTWAIT`      | 待寄出  |
| `GOTWAIT`       | 待寄出  |
| `UNKNOWN`       | 待寄出  |
| `SENTGOT`       | 已揽件  |
| `SIGNEDWAIT`    | 在途中  |
| `TRANS`         | 在途中  |
| `SENDING`       | 在途中  |
| `NATIVE_SIGNED` | 在途中  |
| `FOREIGN_SEND`  | 在途中  |
| `RELEASED`      | 在途中  |
| `GOBACK`        | 在途中  |
| `PROBLEM`       | 异常件  |
| `SIGNED`        | 已签收  |
| `CANCEL`        | 已取消  |
| `CHECKWAIT`     | 待审核  |
| `UNPASS`        | 已驳回  |

### 6.3 两个必须注意的点

- **`PROBLEM` 展示为「异常件」，但统计在途时要算进去**：单条记录展示用「异常件」；做在途数量汇总时，在途数 = 在途中 + 异常件。分组明细里两者分列，合计不能漏掉异常件。
- **`GOTWAIT` ≠ `GOT_WAIT`**：前者是寄件（无下划线，归「待寄出」），后者是到件（有下划线，归「待取件」），不要混用。

### 6.4 补充说明

| 枚举值 | 展示中文 | 说明 |
|---|---|---|
| `DEALWAIT` | 待处理 | **未纳入上述 8 个分组**，做分组汇总时单列或忽略 |

- **寄件维度没有 `GOT` 状态**。`GOT`（已取件）只用于到件，不要把到件的状态词套到寄件上。寄件已揽收后的节点用 `SENTGOT`（已揽件）。
- `querySentCount` 的返回体中可能仍出现 `got` 字段，该字段在寄件维度无对应状态，**展示时直接忽略**，不要输出「已取件 0 件」这类结果。

## 7. 到件订单状态 `status`

### 7.1 状态分组（展示口径）

| 分组（展示名） | 包含枚举值 |
|---|---|
| 待取件 | `GOT_WAIT` |
| 到件异常 | `ABNORMAL` |
| 到件退出 | `BACK` |
| 已取件 | `GOT` |
| 已取消 | `CANCEL` |

> **`RECEIVE_WAIT` 与 `GOT_WAIT` 必须区分**：
> - `RECEIVE_WAIT`（待接收）**只用于回寄类型订单**，不适用于普通到件。
> - `GOT_WAIT`（待取件）才是常规到件中「已入库、等人来取」的状态。
> - 用户问「还有几个快递没取」「有多少待取件」时，**必须按 `GOT_WAIT` 统计**，不得用 `RECEIVE_WAIT` 代答，也不得把两者合并计数。

### 7.2 单值映射（`queryRecCount` 返回体字段口径）

| 枚举值 | 展示中文 |
|---|---|
| `RECEIVE_WAIT` | 待接收 |
| `AUDIT` | 待审核 |
| `GOT_WAIT` | 待取件 |
| `GOT` | 已取件 |
| `BACK` | 已退回 |
| `CANCEL` | 已取消 |
| `ABNORMAL` | 异常 |

### 7.3 两处口径差异与汇总规则

**字段中文与分组名不完全一致**，按用途取用：

| 枚举值 | 单条记录展示用（字段中文） | 分组汇总用（分组名） |
|---|---|---|
| `BACK` | 已退回 | 到件退出 |
| `ABNORMAL` | 异常 | 到件异常 |

> 展示单条到件记录时用左列；做状态分组统计时用右列，不要混用。

**`RECEIVE_WAIT` ≠ `GOT_WAIT`**：前者是回寄单的「待接收」，后者是常规到件的「待取件」。回答「没取的快递有几个」只用 `GOT_WAIT`；两者分属不同业务场景，不合并、不互替、不作口径换算。

**`ALL_COUNT` 是计算属性**：表示总数，且**不含 `AUDIT`**。因此不要把各状态相加后与 `ALL_COUNT` 对账，也不要把 `ALL_COUNT` 当订单状态展示。
