# 得到大脑搜索

## 选择工具

- 用户说“找找、搜一下、关于某主题、我以前记过什么”时，使用 `recall`。
- 用户明确指定知识库时，先用 `list_topics` / `list_subscribe_topics` 查到真实 `topic_id`，再使用 `recall_knowledge`。
- 用户只想浏览最近笔记时使用 `list_notes`，不要把列表当成语义搜索。
- 用户选中结果后，用 `get_note` 或对应的原文/转写工具读取详情；搜索本身不修改笔记。

## 参数

### `recall`

- `query`：必填，保留用户的原始检索意图。
- `top_k`：可选；未指定时使用服务默认值，不自行放大结果数量。

### `recall_knowledge`

- `topic_id`：必填，只能来自知识库列表的真实字符串 ID。
- `query`：必填。
- `top_k`：可选。

## 结果处理

- 所有笔记、知识库和内容 ID 均按不透明字符串原样传递，绝不转换为数字或从 URL 猜测。
- 只使用结构化结果中真实返回的标题、摘要/片段、`note_id` 和链接；无链接时不拼接链接。
- 同一笔记命中多个片段时按字符串 `note_id` 去重；摘要或命中片段不能冒充全文。
- 空结果表示本次搜索成功但未找到内容，可以建议调整关键词或限定知识库，不能编造结果。
- 在群聊或共享会话中默认只展示必要标题、短摘要和链接，不主动展开私密全文。
- 工具失败时说明真实错误、是否可重试及 `request_id`；超时不等于没有结果。
