# 公司回报计算 Skill

## 适用场景

当用户想看某家公司的融资信息、融资回报、投资倍数，或想在公司未收录时直接按金额和估值计算回报时，使用本 Skill。

典型问题：

- 帮我看智元机器人的融资信息和各轮回报。
- 某个公司名查出来有多个候选时，先帮我确认是哪一家。
- 这家公司没收录，帮我按投资金额和投后估值算回报倍数。

## 核心规则

1. 公司命中时，必须同时返回公司画像和融资信息。
2. 公司命中多个候选时，不要猜，列出候选让用户确认。
3. MCP 未收录公司时，切到纯公式计算模式。
4. 不要自行补全未披露金额、投后估值或股权比例。

## 可调用 MCP 工具

优先使用 IT桔子 MCP：

- `resolve_companies`
  - 先把用户输入的公司名解析为 `company_id`。
  - 如果返回多个候选，先让用户确认。

- `get_company_profile`
  - 返回公司画像、行业、地区、发展阶段、最新融资摘要等。

- `get_company_funding_events`
  - 返回公司融资历史、轮次、金额、投资方和时间线。

- `search_events`
  - 需要补充同赛道近期事件时使用。

- `search_tags`
  - 需要标准化赛道词或标签词时使用。

- `get_lookup_options`
  - 需要标准化行业、轮次、地区等字典时使用。

## 工作流

### 1. 先识别公司

调用 `resolve_companies`。

返回 1 家时，进入公司模式。

返回多家时，输出候选列表，并要求用户确认具体公司。

没有命中时，进入纯公式计算模式。

### 2. 公司模式必须返回的内容

先返回公司画像，再返回融资信息。

公司画像建议包含：

- 公司名
- 工商名
- 行业
- 子行业
- 地区
- 成立时间
- 发展阶段
- 最新融资时间
- 最新融资轮次
- 最新融资金额

融资信息建议包含：

- 融资时间线
- 轮次
- 金额
- 币种
- 等值人民币
- 投资方
- 累计披露融资额

如果公司有公开画像但没有融资事件，不要推断没有融资，只能说明“未检索到公开融资记录”。

如果字段权限缺失，要明确说明，不要假装没查到。

### 3. 纯公式计算模式

当 MCP 没收录公司时，按用户输入做计算。

支持的输入：

- 投资金额
- 投后估值
- 股权比例
- 退出估值
- 回报倍数

计算公式：

- `回报倍数 = 退出估值 / 投后估值`
- `投后估值 = 投资金额 / 股权比例`
- `退出估值 = 投后估值 × 回报倍数`
- `收益率 = 回报倍数 - 1`

约定：

- “赚34%”按 `1.34x` 处理。
- “赚152%”按 `2.52x` 处理。
- 若输入不够，先补问最少缺失项，不要硬算。

## 输出结构

推荐按以下顺序输出：

1. 公司确认结果或候选列表
2. 公司画像
3. 融资信息
4. 回报计算结果
5. 数据口径说明

## 默认假设

- 这个 Skill 只负责“公司识别 + 融资信息 + 回报计算”。
- 如果公司有多个候选，不自动猜。
- 如果公司未收录，就不再强行查融资，直接切到公式计算。
