# 机构投资分析 Skill

## MCP 连接信息

本 Skill 由 WorkBuddy 连接器自动携带 `Authorization: Bearer ${ITJUZI_MCP_API_KEY}`。不要向用户索要 API Key，也不要在工具参数里传 `api_key`。

## 适用场景

当用户希望了解某家投资机构的投资方向、近期活跃度、投资案例、轮次偏好或是否适合某类项目时，使用本 Skill。

典型问题：

- 红杉中国最近投了哪些项目？偏什么行业？
- 启明创投近几年投过哪些机器人或具身智能公司？
- 帮我分析某某机构的投资风格和代表案例。
- 某某国资背景机构最近在投哪些方向？
- 我是做医疗 AI 的创业者，某某机构适合优先接触吗？

## 目标输出

输出一份机构投资分析，重点回答：

1. 这家机构是什么类型、是否有国资或政府引导基金属性。
2. 最近有哪些投资案例。
3. 主要投哪些行业、标签和轮次。
4. 有哪些代表性项目。
5. 对创业者、FA、投资人或 LP 有什么行动建议。

## 可调用 MCP 工具

优先使用 IT桔子 MCP：

- `search_investors`
  - 用于把机构名称解析为 `investor_id`。
  - 查询国资背景、政府引导基金、FA、VC、PE 等机构类型。

- `get_investor_profile`
  - 查询机构画像、机构类型、案例数、活跃行业、最近投资时间等。

- `search_investor_cases`
  - 查询某机构投资案例。
  - 可按行业、子行业、轮次、被投公司标签过滤。

- `search_tags`
  - 用户指定赛道词时，先解析成 `company_tag_ids`。

- `get_lookup_options`
  - 用户指定机构类型、行业、轮次但不知道 ID 时，查询字典。

- `get_company_profile`
  - 对重点被投公司补充公司画像。

- `get_company_funding_events`
  - 对重点被投公司补充融资历史。

## 输入信息

用户可能给出：

- 机构名称：如红杉中国、启明创投、深创投。
- 赛道关键词：如人工智能、机器人、医疗健康、低空经济。
- 时间范围：如最近 1 年、最近 3 年、2026 年以来。
- 轮次偏好：如天使轮、A 轮、B 轮以后。
- 使用目的：创业者找投资人、FA 匹配机构、投资人研究竞品机构、LP 做 GP 初筛。

如果用户没有给出时间范围，默认先看最近 3 年案例；如果案例数量不足，再放宽到全部可见案例。

## 工作流

### 1. 解析机构

先调用 `search_investors` 搜索机构名称。

示例：

```json
{
  "keyword": "启明创投",
  "page_size": 10
}
```

如果返回多个候选，结合机构名称、机构类型、案例数和用户上下文选择最匹配的一家；无法判断时，把候选列出让用户确认。

### 2. 查询机构画像

调用 `get_investor_profile`。

建议字段：

```json
[
  "investor_id",
  "investor_name",
  "investor_type",
  "prop_names_text",
  "is_fa",
  "is_state_owned",
  "is_government_guidance_fund",
  "case_count",
  "latest_case_time",
  "active_scope_text"
]
```

### 3. 解析赛道和筛选条件

如果用户限定赛道，调用 `search_tags` 解析赛道词。

如果用户限定行业、轮次或机构类型，调用 `get_lookup_options` 获取对应 ID。

筛选策略：

- 明确标签优先传 `company_tag_ids`。
- 明确行业优先传 `scope_ids` 或 `sub_scope_ids`。
- 明确轮次传 `round_ids`。
- 多个标签默认使用 `company_tag_match_mode="union"`，用户要求“同时满足”时才用 `intersection`。

### 4. 查询投资案例

调用 `search_investor_cases`。

建议字段：

```json
[
  "investor_id",
  "investor_name",
  "event_id",
  "event_time",
  "company_id",
  "company_name",
  "scope_name",
  "sub_scope_name",
  "round_name",
  "amount",
  "currency_name",
  "standard_rmb"
]
```

查询建议：

- `page_size` 第一版建议 50，套餐允许时可到 100。
- 不要为了凑结论连续翻很多页。
- 如果结果很少，说明样本有限，并说明已使用的筛选条件。

### 5. 归纳投资偏好

基于案例列表归纳：

- 最近投资时间和活跃度。
- 行业和子行业分布。
- 轮次分布。
- 披露金额区间和大额案例。
- 代表项目。
- 是否明显偏早期、成长期、后期或战略投资。

金额规则：

- `amount` 是展示文本，可写入报告。
- `standard_rmb` 是数值字段，单位为万人民币，可用于排序和统计。
- 金额缺失或“未透露”时，不要自行估算。

### 6. 补充重点项目

挑选 3-5 个代表案例。必要时调用 `get_company_profile` 和 `get_company_funding_events` 补充：

- 公司简介。
- 行业、标签、地区。
- 最新融资和历史融资。
- 投资方组合。

选择代表案例时优先：

1. 最近发生。
2. 金额较大且已披露。
3. 与用户指定赛道高度相关。
4. 轮次能代表机构偏好。
5. 投资方组合有参考价值。

### 7. 输出机构投资分析

按固定结构输出：

```markdown
# {机构名称}投资分析

## 一句话结论

## 机构画像

## 近期投资案例

## 行业和轮次偏好

## 代表项目

## 投资风格判断

## 对用户的建议

## 数据口径和限制
```

## 输出要求

- 所有结论必须基于 MCP 查询结果。
- 不要把历史案例说成当前正在募资或正在接触。
- 不要编造机构联系方式、合伙人姓名或未返回的基金信息。
- 如果样本较少，明确提示“样本有限”。
- 对未披露金额、缺失字段、权限导致的字段省略，要明确说明。
- 给创业者建议时，使用“可能适合优先关注”“需要进一步验证”，不要承诺投资意向。

## 当前 MCP 能力边界

当前版本适合分析“已公开可见投资案例”和机构画像，不适合直接输出完整 GP 尽调结论。

暂不做：

- 基金业绩和 DPI/TVPI 分析。
- LP 出资结构和募资状态。
- 投资经理个人关系网络。
- 机构联系方式抓取。
- 自动判断真实投资意向。
