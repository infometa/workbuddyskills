# 企业关闭案例库

使用 MCP 中的关闭公司与融资事实数据，把“公司关闭”还原为可验证的融资和经营研究样本。所有结论必须区分事实、归纳和待验证事项。

## 使用模式

- 问“有哪些”“列出案例”“多少家”：使用关闭案例检索。
- 问“某公司为什么关闭”“复盘某案例”：使用单公司复盘。
- 问“某赛道失败路径”“融资后多久关闭”：使用关闭样本 cohort 分析。
- 问“目标项目有哪些历史风险参照”：使用反证尽调。

除单公司精确名称外，先用 `search_tags` 或 `get_lookup_options` 将自然语言赛道、行业、关闭原因和轮次转换为 ID。用户说“海外”时传 `location="out"`；国内省市使用 `location="in"`、`provinces` 或 `cities`。

## 关闭案例检索

1. 用户问数量时调用 `count_closed_companies`，不要遍历分页结果计数。
2. 用户问案例时调用 `search_closed_companies`，请求公司名称、行业、标签、关闭日期、关闭原因和最新融资摘要。
3. 用户要求关闭原因时，先调用 `get_lookup_options(lookup_type="company_closure_type")` 获取字典，再传 `closure_type_ids` 或 `closure_parent_type_ids`。
4. 原因字段为空时写“暂未收录关闭原因”，不要以新闻、标签或融资状态推断原因。

## 单公司复盘

1. 用户给公司名称时先调用 `resolve_companies`。存在多个候选时，展示公司简称、工商全称、行业、地区和成立年份，请用户确认；不得自行按名称猜测。
2. 确认公司后调用 `get_company_profile` 与 `get_company_funding_events`，按时间正序整理融资历史。
3. 同时用 `search_closed_companies(keyword=...)` 核验其是否为关闭样本，读取关闭日期和原因。
4. 计算最后一笔可见融资至关闭日的自然日间隔；融资事件晚于关闭日时列为数据待核实，不纳入该间隔。

## 样本融资复盘

当问题包含“主要集中在哪一轮”“融资后多久关闭”“失败路径”“赛道复盘”“中位数”等聚合诉求时，优先调用 `analyze_closed_company_cohort`，不要逐家公司调用融资历史。

- `summary`：样本数、已融资样本数、融资事件数、披露金额覆盖及最后融资至关闭间隔统计。
- `last_round_distribution`：关闭前最后一笔可见融资的轮次分布。
- `closure_reason_distribution`：结构化关闭原因分布。
- `representative_cases`：可用于深入复盘的代表公司。

筛选规则：

- 按“融资后关闭”筛选时传 `funded_only=true`。
- 按关闭前最后融资轮次筛选时传 `last_round_ids`，轮次 ID 从 `get_lookup_options(lookup_type="round")` 获取。
- 按融资后存续期筛选时传 `last_funding_gap_days_min` 或 `last_funding_gap_days_max`。
- `total_standard_rmb` 的单位是万人民币，只统计有数值的披露金额；`amount`、`last_amount` 只用于展示。

## 反证尽调

1. 用公司画像确定行业、标签、地区和融资阶段。
2. 以标签优先、行业补充的方式检索关闭样本。样本太少时放宽地区或成立年份，并明确说明口径变化。
3. 调用 `analyze_closed_company_cohort` 获取融资与关闭模式，再从 `representative_cases` 选择 3 至 5 个最相近案例。
4. 把共性转化为可核验问题，例如收入兑现、客户集中度、现金可支撑月数、续投依赖和回款质量。

不得输出“目标公司会关闭”“倒闭概率”等预测结论。应使用“历史相似样本中的风险信号”“建议核验”的表述。

## 输出格式

```markdown
# {公司或赛道}关闭案例复盘

## 结论摘要
## 查询口径与样本边界
## 融资路径与关闭时间线
## 关闭原因与证据完整度
## 典型案例
## 失败模式归纳
## 公开风险与待核实事项
## 投资关注点与下一步建议
## 数据口径与限制
```

- 明确区分“样本事实”“基于样本的归纳”“目标项目待核验事项”。
- 将关闭原因缺失、融资金额未披露、字段权限省略和样本量不足写入限制。
- 不把关闭样本数量视为关闭率；需要风险率时必须另有同口径存续公司的分母。
- 所有金额汇总仅使用 `standard_rmb` 或 `total_standard_rmb`，不将“未透露”“数千万”等展示文本转为精确金额。
