# 烯牛数据使用指南

## 概述

烯牛创投数据 MCP 提供 21 个专业工具，覆盖公司、投资机构、基金、基金管理人、LP 五类主体的数据查询，以及地区市场统计、政府投资分析、事件追踪、榜单和研报。

## 通用前置规则

- **名称验证**：用户给出的名称不确定时（简称、模糊名称），先用 `名称模糊匹配`（name_match）工具获取精确全称，再调用其他工具。返回空 = 未找到；返回单个 = 直接使用；返回多个 = 展示候选或选最匹配项。
- **结构化查询**：使用 `结构化数据查询`（structured_query）前，必须先用 `数据表字段查询`（table_schema）确认字段名和支持的操作类型。建议先取 5 条预览，确认无误后再取全量（每页 ≤500 条）。
- 回答涉及风险、舆情数据时注明来源为烯牛数据，并提示可能存在更新延迟。

## 工具目录

### 基础查询

| 工具 | 用途 | 关键参数 |
| --- | --- | --- |
| 公司信息查询 (company_info) | 单公司全貌入口，7 个分析维度：基本信息、融资状况、产品、竞品、股东、核心团队、风险信息 | 必填：公司全称或统一社会信用代码 + 分析维度（7 选 1） |
| 机构信息查询 (entity_profile) | 投资机构/基金/基金管理人/LP 四类主体画像 | 必填：主体类型（4 选 1）+ 主体名称 |
| 名称模糊匹配 (name_match) | 模糊名称 → 精确全称，所有查询的前置验证步骤 | 必填：实体类型（6 选 1）+ 模糊名称 |
| 数据表字段查询 (table_schema) | 查看数据表字段结构（9 张表） | 必填：表名 |
| 结构化数据查询 (structured_query) | 核心工具：9 张表（公司、投资事件、投资机构、基金、基金管理人、LP、公司类投资实体及其投资事件、LP出资事件）的筛选/排序/分页/多表关联 | 查询参数数组 + 每页条数 + 分页起始 |

### 地区统计

| 工具 | 用途 | 关键参数 |
| --- | --- | --- |
| 地区私募股权市场统计 (region_pe_stat) | 省/市/区级私募股权市场全维度统计，12 个目录（市场概览、LP 分析、备案基金、投融资、IPO/并购/老股转让/回购退出、S 基金等） | 必填：统计目录（12 选 1）+ 统计周期「起始年月~结束年月」；可选：国家/省/市/区县 |
| 统计工具 (stat_tools) | 项目、基金、管理人、LP、投资机构及事件的多维统计 | 临时数据数组（查询参数 + 临时表名） |

### 政府投资

| 工具 | 用途 | 关键参数 |
| --- | --- | --- |
| 国资核心指标概览 (gov_core_metrics) | 6 项国资核心指标及全国排名（管理人/基金/LP 数量、规模、直投数） | 可选：省份 |
| 国资统计列表 (gov_stat_list) | 10 个标签页分页查询国资实体列表（管理人、LP、引导基金、直管基金、投资平台及各类穿透在投项目） | 必填：标签页（10 选 1）；可选：省份、分页 |
| 政府投资图谱 (gov_investment_map) | 按控股/参股关系列出政府投资图谱实体 | 可选：省份、持股类型、分页 |

### 公司深度

| 工具 | 用途 | 关键参数 |
| --- | --- | --- |
| GP 推荐匹配 (gp_recommend) | 为公司推荐匹配的基金管理人（前 20 家，含多维度评分） | 必填：公司全称或统一社会信用代码 |
| 融资机会历史评分 (financing_score) | 指定时间段内公司融资机会评分趋势 | 必填：公司全称 + 起始/结束日期（年-月-日） |

### 穿透式监管（事件追踪）

公司/机构/基金/LP/基金管理人事件追踪（event_tracking / investor_event_tracking / fund_event_tracking / lp_event_tracking / gp_event_tracking）：批量查询指定主体在日期范围内的新闻与事件，返回标题、日期、类型（融资、经营动态、风险信息、舆情、公告）、重要性、情感倾向、摘要。必填：名称数组 + 起止日期；可选：重要性、情感倾向、事件类型、分页。

### 榜单分析

- 榜单企业查询 (ranking_companies)：查榜单（如专精特新）企业列表，可按城市筛选。
- 榜单分布分析 (ranking_distribution)：榜单的地区/行业分布。

### 研报

- 研报搜索 (report_search)：按关键词、来源类型、行业、日期搜索研报。
- 研报详情 (report_detail)：按研报编号获取全文和下载链接（编号来自研报搜索结果）。

## 典型工作流

1. **公司尽调**：name_match 确认全称 → company_info 依次查基本信息/融资/股东/风险 → event_tracking 查近期事件 → gp_recommend 看匹配机构。
2. **地区市场报告**：region_pe_stat 选目录 + 周期 + 地区 → 需要明细时 stat_tools / structured_query 补充。
3. **国资分析**：gov_core_metrics 看指标 → gov_stat_list 分标签细查 → gov_investment_map 看关系。
4. **行业研究**：report_search 搜研报 → report_detail 读全文 → ranking_companies 查相关榜单企业。

## 常见错误与处理

| 错误 | 处理方式 |
| --- | --- |
| API Key 无效/过期（401/403） | 引导用户在烯牛开放平台重新获取 API Key 并更新连接配置 |
| 请求频率超限 | 稍等后重试，告知用户存在限频 |
| 企业/机构未匹配 | 用 name_match 换用简称或去掉「有限公司」等后缀重试 |
| 字段不支持的操作类型 | 先调 table_schema 确认字段定义后调整查询 |
| 查询超时/数据量大 | 缩小时间范围、增加筛选条件、分页获取 |
