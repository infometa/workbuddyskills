# kling-ai（可灵 AI 技能）

在对话里直接生成并监控 **可灵 AI（Kling AI）** 的图片与视频——通过可灵官方、基于 OAuth 的 MCP 服务。

## 能做什么

- 文生图 / 图生图
- 文生视频 / 图生视频（单镜头与多分镜）
- 查询剩余额度与任务状态

## 安装与授权

1. 将 Connector 目录提交或导入 WorkBuddy。
2. 打开宿主的 **MCP / 插件连接** 面板，找到 `kling-ai`，点击 **信任 / 连接**，登录可灵账号同意授权即可。
   授权走 OAuth，技能**绝不会**在聊天里向你要 API key。

## 怎么用

直接用自然语言描述需求。技能会展示最终参数，并在任何消耗 credits 的生成前等你确认。

- *「生成一张 16:9 电影感海报：白色摄影棚里一只玻璃茶壶。」*
- *「把这张照片做成 5 秒、720p 的图生视频，保持人物稳定。」*
- *「查询 generationId 的状态。」*

提交后技能会自动轮询任务状态，直到成功或失败，并自动返回结果用于展示。

## 注意事项

- 生成结果的签名链接（图片/视频）**24 小时后过期**，请及时下载。
- 每个任务在每次确认意图下**最多提交一次**，技能不会自动重试失败的任务。
- 切勿在日志中暴露 token、cookie 或签名输出链接。
