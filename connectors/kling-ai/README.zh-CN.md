# Kling AI（可灵 AI）

Kling AI 连接器通过可灵官方 OAuth MCP 服务，让 WorkBuddy 可以创建和查询图片、视频生成任务。

## 功能

- 文生图、图生图
- 文生视频、图生视频
- 查询积分与任务状态
- 持续查询生成进度并返回结果

## 连接账号

在 WorkBuddy 中安装连接器，点击 **连接**，然后在打开的可灵网页中完成 OAuth 授权。
授权和续期由 WorkBuddy 管理，不需要 API Key。切换账号时，请先断开当前账号，再连接目标账号。
不要在对话中粘贴账号凭据、Token 或 Cookie。

## 使用

直接用自然语言描述想要生成的图片或视频。例如：

- “生成一张 16:9 电影感海报：白色摄影棚里一只玻璃茶壶。”
- “把这张照片做成 5 秒、720p 的视频，保持人物稳定。”
- “查询这个任务编号的状态。”

每次只提交一个生成任务，并按服务允许的间隔持续查询，直到成功或失败。如果当前轮次先结束，
会返回**任务编号**，之后可继续查询同一任务。积分不足时，请充值后再试。

完成后会返回可灵提供的主要图片、视频或结果链接。结果链接可能临时有效；失效后可使用原任务编号
重新查询，作品也可以在已授权账号的可灵生成记录中找到。
