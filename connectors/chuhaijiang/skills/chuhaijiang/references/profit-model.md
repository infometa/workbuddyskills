# 利润测算 SOP（TikTok Shop 跨境）

目标：对候选商品算清单件净利润和保本售价，回答"这个品到底赚不赚钱"。
选品清单（product-selection.md）筛出候选后，重点候选应过一遍利润测算再做最终推荐。

## 数据分工（先分清哪些数从哪来）

| 来源 | 数据项 |
|---|---|
| 平台工具查 | 售价、销量、评分、评论（get_detail / get_related reviews）；同类达人带货情况（get_related creators） |
| **必须问用户** | 1688/工厂进货价、单件重量和体积、头程方式（海运/空运）、计划达人佣金率、是否投广告 |
| 行业默认值 | 下方基准表，用户没有实际报价时用，产出中必须标注"估算值" |

用户连进货价都没有时，只能算"平台侧到手率"（售价扣掉平台费用后剩多少），明确告诉用户这不是完整利润。

## 单件利润公式

```
单件净利 = 售价
  − 货物成本（1688进货价 ÷ 汇率）
  − 头程运费分摊（单件重量kg × 头程单价）
  − 海外仓成本（上架费 + 仓租分摊 + 出库操作费）
  − 履约/尾程（FBT费 或 海外仓一件代发尾程）
  − 平台佣金（售价 × 6%）
  − 达人佣金（售价 × 佣金率，仅达人出单部分）
  − 广告分摊（广告花费 ÷ 广告带来订单数）
  − 退货准备金（见下方）
```

保本售价：令净利 = 0 反解。建议同时给出目标毛利率 ≥30% 对应的定价。

## 行业基准值（2026-07 网络调研采集，均为估算，随时间变化）

### 平台费用（TikTok Shop 美区）

- 平台佣金：**6%**（珠宝类 5%；已含支付手续费）。新卖家首销后 30 天优惠期 3%
- 达人佣金类目中位数：美妆个护 ~15%、健康 ~20%、女装内衣 ~10%、运动户外 ~10%、配饰 ~8%（范围很宽，以 get_related creators 看到的同类实际水平为准）
- 广告（可选）：CPM 约 $9–30；Smart Promotion 约 GMV 的 3.5%；GMV Max 学习期最低 ~$50/天
- 结算周期：新卖家 31 天起，现金流要预留

### 物流费用（中国 → 美国）

- 头程：海运约 ¥15/kg（30–45 天），空运约 ¥40/kg（5–10 天）
- FBT（平台仓配）：约 **$2.86–4.28/件**（按重量分档）；2026 年起美区强制走 FBT / 升级版物流 / CBT
- 第三方海外仓：上架 ~$0.5/kg，仓租 ~$0.1/kg/月，出库操作 ~$0.3–1/件，尾程 USPS ≤1kg ~$10/件
- 轻小件优先 FBT；大件/异形件才考虑第三方海外仓+尾程快递

### 退货成本

平台规则（美区）：
- 退款管理费：佣金的 20%，上限 $5/SKU
- 退货运费分摊：店铺评分 SPS ≥4 时卖家承担 20%，否则承担 50%
- FBT 退货处理费：约 $3/件

```
退货准备金 = 预估退货率 × (货物成本 + 头程分摊 + 履约费 + 退货处理费)
```

（保守口径：退回的货默认不可二次销售；可翻新类目可酌情打折）

## 退货率估档（结合评分和评论）

没有实际店铺数据时，用商品评分 + 差评内容 + 类目基准估档：

| 信号 | 预估退货率 |
|---|---|
| 评分 ≥4.5，差评无质量/尺寸主诉 | 类目基准下限 |
| 评分 4.0–4.5 | 类目基准中值 |
| 评分 <4.0，或差评集中在质量/与描述不符/尺寸 | 类目基准上限甚至上浮 |

类目基准（估算）：服装鞋帽 10–25%（尺寸问题主导）、3C 电子 5–10%、美妆个护 3–8%、家居日用 2–8%。

操作：get_related(products, id, "reviews") 拉差评，看主诉是否是"质量/尺寸/与描述不符"（这些会转化为退货）还是"物流慢"（通常不退货）。深度分析可用 ai_generate(type="review_analysis")。

| 项目 | 金额($) | 占售价% | 来源 |
|---|---|---|---|
| 售价 | | 100% | 平台数据 |
| 货物成本 | | | 用户提供 |
| 头程分摊 | | | 估算(海运¥15/kg) |
| 履约(FBT) | | | 估算 |
| 平台佣金 | | 6% | 平台规则 |
| 达人佣金 | | | 用户设定 |
| 退货准备金 | | | 估算(退货率x%) |
| **单件净利** | | **净利率%** | |

表后必须给：① 保本售价；② 敏感性提示（达人佣金 +5pp / 退货率翻倍时净利变化）；③ 哪些数是估算值、建议用户拿实际报价复核。

## 硬性要求

- **每个数字标来源**：平台数据 / 用户提供 / 行业估算，三类分开，不许混
- 基准值会过时：产出里注明"费率基准采集于 2026-07，下单前以平台最新规则和物流商实际报价为准"
- 净利率 <15% 的品要明确提示风险（广告一投就亏）；≥30% 才算健康
- 汇率用测算当天的近似值并注明；不要用记忆里的旧汇率硬算
