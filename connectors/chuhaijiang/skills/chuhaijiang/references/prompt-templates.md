# 画板与视频 Prompt 模板

在画布中创作图片、分镜画板、视频或口播时阅读本文件；调用工具前先读 [出海匠画布操作契约](canvas-operations.md)，并严格遵守其中由用户完成的骨架视觉确认与付费生成确认门禁。模板用于组织创作判断，不是固定镜头数、固定模型或必须逐字照抄的 prompt。

## 从意图选择创作路线

先判断用户希望观众看见、相信或感受什么，再选内容形式：

| 意图 | 内容路线 |
|---|---|
| 让人相信真实商品 | 用可见外观、一个使用动作、细节或结果做证明；优先生活化 UGC、演示或对比。 |
| 建立品牌气质 | 以人物、空间、色彩、构图和节奏建立情绪；可先出概念图对齐风格，再做视频。 |
| 讲剧情或口播对话 | 先明确人物关系、一个主冲突或变化，再安排镜头。台词要像目标用户自然会说的话。 |
| 借鉴爆款结构 | 提取 hook、冲突、节奏和证明方式，改写成独立人物、场景和台词；不复制原人物、品牌、素材或逐字台词。需要更细的拆解时，先核实视频，再基于可见内容手动整理结构。 |
| 快速探索画面或单一动作 | 直接做单图或单镜视频；不为了形式创建脚本或画板。 |

用户已有脚本、台词、CTA 或参考图时，先继承它已明确的剧情、语言、行动目标和禁止项；不要自行添加更强冲突、购买引导或第二条故事线。信息缺失且会实质改变结果时，只问一个最关键的问题。用户要求直接生成时，可以用合理默认值完成零成本草稿，但仍须展示最终创意、prompt、参考素材职责和生成参数，获得明确确认后才能提交付费任务。

## 素材与一致性

真实商品、人物和场景素材先回答三个问题：哪些外观/细节确实可见，用户还确认了什么，什么会影响准确性但需要补充。它们是代理内部判断，不是要求用户填写的表单。

素材不足时，直接说明补哪类素材以及它解决哪个画面问题：细节图用于还原结构，规格页用于支撑口播，场景图用于确定使用环境。用户不补时仍可做概念图或氛围片，只不把 AI 补出的细节说成真实商品实拍或已确认规格。

多张图按职责使用：主商品/人物图锁定整体身份，细节图锁定对应部件，场景图锁定空间，风格图只影响美学。参考职责必须写进 prompt，并在画布中以真实节点和边实现；不能让风格图改写产品或人物身份。

## 先组织内容，再写 prompt

无论做哪种成片，先确定以下内容；按任务取用，不要求每次全写：

- **核心目的**：观众最后应记住的一个好处、情绪或转折。
- **主体与场景**：谁/什么出现，在哪里，哪些外观不能漂移。
- **可见证据**：一个能看见的动作、细节、对比、反应或结果，不用口号替代画面。
- **视觉语言**：生活化手机感、受控广告感、第一视角、特写、跟拍、静态构图等，选择一个与目的匹配的方向。
- **声音与语言**：自然口播、环境音、音乐或无声；口播语言与画板说明、视频指令分开处理。
- **连续性与禁止项**：主体、服装、产品结构、空间关系要保持什么；不要出现什么虚构功能、画面文字、UI 或不可能动作。

视频镜头数和节奏服从目的：证明动作可以一镜到底；剧情可按“吸引 → 情境/问题 → 行动或证据 → 结果/记忆点”组织，但只保留实际需要的节拍。每个镜头承担一个观众能看清的主要动作，避免同一时刻塞进互相冲突的动作、运镜和文字。

## Prompt 模板库

将方括号或花括号替换为当前任务信息；删去不适用段落，不提交未替换占位符。以下三套来自下载 skill 的画板/视频 prompt 正文完整保留：它们是可选模板，不要求每个任务都使用完整母版、五区画板或固定 8 镜。

### 单图

```text
[主体与参考职责]
目标：[观众应感到/理解什么]。
画面：[主体、关键动作或状态、场景]。
构图与视觉语言：[景别、机位、色彩、光线、质感]。
保持：[不可改变的外观、比例、材质、人物或空间关系]。
避免：[与任务有关的错误、额外文字、UI 或虚构功能]。
```

### 轻量分镜画板

```text
Create a storyboard production board, not a poster or a text-only page.
[参考职责与主体锁定]
主题与观众目标：[主题 / 情绪 / 一个核心好处]。
场景与视觉语言：[空间、时间、光线、色调、镜头气质]。
镜头节拍：[每个需要的节拍分别写 Visual / Dialogue-Sound / Purpose]。
成片目标：[视频类型、比例、时长、节奏或口播语言]。
保持：[主体身份、产品外观、服装、空间关系、连续性]。
避免：[画板 UI 或文字进入缩略图、乱码、无关镜头、虚构功能]。
```

画板只在需要连续叙事、镜头节奏或主体锁定时使用。它应让人看清主体、场景、镜头和成片目标；画板的说明文字、边框和卡片不能被带入最终视频。

### 轻量视频

```text
[参考职责；若有专属画板，说明它锁定哪些主体、场景和镜头信息]
Create a [时长 / 比例 / 清晰度] video for [受众或内容类型]。
主体与连续性：[人物、产品、服装、空间、光线中必须保持的内容]。
BEATS
[每个节拍：Visual: 一个主要动作、景别或运镜。]
[Dialogue/Sound: 精确台词、环境音或无口播。]
[Purpose: 该节拍要证明、推进或留下什么。]
语言：[实际口播的语言、口音或“exactly as written”要求]。
避免：[身份漂移、产品变形/复制、虚构功能、关键动作被遮挡、字幕、价格、链接、按钮、UI]。
```

单一动作使用支持单镜的模型即可；多镜节奏需要选择支持多镜的模型，或按镜头拆成片段再组合。模型、时长、分辨率和输入模式始终以当前工具 schema 为准，不在模板中写死。视频时长必须与用户确认的时间轴总长一致；若当前模型不支持该时长，先调整或拆分脚本并重新确认。

### 完整电影级画板母版

完整保留；它是设计规则源。实际提交可以改用下一节紧凑模板，或按当前任务删去不适用模块。

```text
{项目主题/视频主题}分镜画板

作为资深影视美术指导、商业短视频导演和视觉提案设计师，请根据我上传的参考素材，以及我提供的创意方向，生成一张高逼格、多模块排版的“电影级画板 / storyboard production board”。

这不是普通海报，也不是单张主体展示图，而是一张完整的专业视觉提案板，类似影视项目提案板、导演分镜板、商业短视频脚本板、广告创意 production board。请基于上传素材的真实视觉信息，结合我给出的需求，自动补全合理的主体设定、场景设定、镜头语言、光影、色调、构图和分镜内容。

【输入信息】

主题/剧情：{填写视频主题、情绪方向、故事核心}

主体设定：{填写主角、产品、人物、道具、品牌物、空间或核心视觉对象；人物背景和场景信息不足时可合理补全，但产品外观、结构、功能和规格只能使用参考图可见事实或用户明确提供的信息}

场景设定：{填写主要场景，例如家庭客厅、浴室、户外庭院、厨房、车库、办公室、街头、酒店房间等}

视频类型：{填写类型，例如真实短视频、电影广告、ASMR、开箱、清洁挑战、生活方式、剧情反转、教程演示、测评、Vlog、TikTok UGC 等}

镜头语言：{填写镜头风格，例如手机实拍、轻微手持、极致微距、平滑推拉、跟拍、固定镜头、慢动作、延时摄影、第一视角等}

光影设定：{填写光线，例如自然日光、清晨柔光、黄金时刻、室内暖光、浴室顶灯、阴天漫射光、夜间霓虹等}

核心色调：{填写主色调和辅助色，例如高级灰、暖白、深蓝、干净白、生活化杂色、低饱和自然色等}

构图方式：{填写构图要求，例如极简主义、真实家庭生活感、信息图式排版、左右分栏、强 before/after 对比、产品居中、人物前景等}

分镜数量：{填写数量，默认 8 Shots}

输出格式：{填写比例与质量，例如 9:16 竖屏，4K，电影级清晰度；或 16:9 横屏；或 1:1 方图}

【核心排版与视觉要求】

采用高度结构化的极简 UI 网格化排版。整体美学必须高级、精致、专业，运用高级灰、透明 UI 元素、细线框、半透明信息卡片和清晰模块分区来构建画面框架，呈现类似顶级设计工具、影视提案板、广告创意板的干净视觉。

画板说明文字默认中文；用户明确指定其他画板语言时服从当前请求，锁定台词始终保留原文。排版必须干净整齐，信息图表化，可读性强。画面必须像一张真实可用于提案的完整 storyboard production board，而不是纯文字说明。

请保证上传参考素材中的主体外观、颜色、比例、材质、关键结构和识别特征保持一致。严禁出现 AI 变形、物理破绽、结构错误、材质错乱、文字乱码、主体漂浮、比例失真或不合理透视。

【画板结构定义（Grid Layout）】

严格输出以下 5 个区域：

一、顶部（Header）

居中大标题：
《{项目标题}》

标题应具有商业短视频提案感，简洁、有记忆点，能概括视频主题、情绪和核心卖点。

二、左侧（主角与主体设定 / Character & Subject Reference）

展示上传素材中的核心主体参考，包括主体外观、关键部位、材质、颜色、比例和可识别特征。

如果是人物，请展示人物造型、服装、表情气质和身份设定。

如果是产品或道具，请展示主体本身、关键配件、参考图可见或用户确认的功能细节和材质特征；不得补造看不到或未经证实的功能。

如果是空间或场景，请展示空间结构、风格参考、核心视觉元素和使用氛围。

左侧区域应像“视觉身份参考板”，用于锁定主体一致性，不要生成与参考素材冲突的新造型。

三、中间（场景设定 / Environment + Set Design）

展示主要拍摄场景和环境氛围，包括空间布局、道具布置、光线来源、生活痕迹、天气/时间、色彩气氛和镜头可拍摄区域。

场景必须服务于视频主题，不要只是漂亮背景。请让场景能够自然承载后续分镜动作和剧情推进。

中间区域需要有真实布景感、导演分镜感和可执行的拍摄空间逻辑。

四、右侧（分镜脚本区 / Storyboard & Shots）

严格输出 {分镜数量} 个分镜缩略图。每个分镜都必须有对应画面缩略图，并标注“镜头1、镜头2、镜头3……”或“Shot 1、Shot 2、Shot 3……”。

每个镜头必须包含：
[画面] 具体画面内容、动作、主体位置、镜头运动、景别、场景变化。
[台词/字幕/声音] 对应的台词、字幕、旁白、音效或 ASMR 声音提示。
[卖点/情绪] 此镜头要传达的功能、情绪、冲突、反转或记忆点。

请让分镜具有连续性：从开场吸引、问题建立、主体出现、过程演示、细节强化、情绪推进、结果展示，到结尾记忆点或行动引导。

分镜模板如下：

镜头1：[画面] {开场钩子画面：用强问题、强视觉、强情绪或强动作吸引注意力。} / [台词/字幕/声音] {一句短而有记忆点的开场字幕或声音。} / [卖点/情绪] {此镜头建立的问题或情绪。}

镜头2：[画面] {主体第一次清晰出现，展示关键外观或使用状态。} / [台词/字幕/声音] {突出主体身份或核心变化。} / [卖点/情绪] {观众知道这条视频要解决什么。}

镜头3：[画面] {进入核心动作或核心场景，展示使用前状态、冲突或痛点。} / [台词/字幕/声音] {短字幕说明问题。} / [卖点/情绪] {强化真实感和代入感。}

镜头4：[画面] {展示主体参与解决问题的过程，动作清楚，细节真实。} / [台词/字幕/声音] {突出一个核心优势。} / [卖点/情绪] {建立可信度。}

镜头5：[画面] {微距或细节镜头，展示材质、功能、动作变化或关键瞬间。} / [台词/字幕/声音] {用简短语言强化细节。} / [卖点/情绪] {让观众看到具体证据。}

镜头6：[画面] {切换第二场景或第二用途，证明适用范围或剧情递进。} / [台词/字幕/声音] {突出多场景、多用途或更深层价值。} / [卖点/情绪] {扩大说服力。}

镜头7：[画面] {结果对比、人物反应、环境变化或情绪释放。} / [台词/字幕/声音] {一句总结性台词或字幕。} / [卖点/情绪] {形成 before/after 或情绪回报。}

镜头8：[画面] {结尾定格、完整展示、品牌感画面、行动引导或反转笑点。} / [台词/字幕/声音] {结尾 CTA、记忆点或最后一句 punchline。} / [卖点/情绪] {让观众记住并产生行动。}

五、底部（核心参数卡片区）

横向整齐排列以下 10 项数据，每一项都用独立信息卡片呈现：

主题/剧情：{填写或自动总结核心主题}

主体设定：{填写或自动总结主体身份、外观和关键特征}

场景设定：{填写或自动总结主要环境}

视频类型：{填写或自动总结视频类型}

镜头语言：{填写或自动总结镜头风格}

光影设定：{填写或自动总结光线氛围}

核心色调：{填写或自动总结色彩系统}

构图方式：{填写或自动总结构图逻辑}

分镜数量：{填写分镜数量，例如 8 Shots}

输出格式：{填写输出比例、清晰度和风格，例如 9:16 竖屏，4K，真实短视频质感}

【风格要求】

整体画板必须具备：
- 专业电影级画板感
- 商业广告提案感
- 导演分镜感
- 多模块网格化排版
- 图文混排
- 大量画面缩略图
- 清晰中文信息层级
- 真实可信的主体和场景
- 可直接指导后续视频生成或拍摄

【一致性要求】

所有分镜中的主体必须保持一致，包括颜色、比例、材质、结构、服装、配件、发型、年龄、空间位置关系和关键识别特征。

如参考素材信息不足，只能合理补全非产品场景和人物背景；产品未知信息保持未知，不要改变主体本质，不要添加未经证实的结构、功能或与主题无关的复杂元素。

【负面要求】

不要生成普通海报。
不要生成单张主体图。
不要只输出纯文字。
不要让画板像 PPT 截图。
不要让画面拥挤混乱。
不要出现英文乱码或无意义文字。
不要出现 AI 感人物、塑料皮肤、手指畸形、结构变形、主体比例错误、材质错误、漂浮物体、不合理透视、过度磨皮、卡通感、CGI 感、棚拍感过重、虚假夸张表演。
不要改变上传参考素材中的核心主体。
不要把分镜做成彼此无关的漂亮图片，必须是连续视频脚本。

【最终输出目标】

请生成一张完整、清晰、专业、中文信息完整的“电影级画板 / storyboard production board”。画板需要让人一眼看懂：主体是谁、场景在哪里、视频讲什么、镜头怎么拍、情绪如何推进、最终输出什么风格。
```

### 紧凑画板运行模板

完整母版约 9KB，只用于约束设计。实际 `board.prompt` 可使用下列模板；方括号内容全部替换，不得把占位符提交。

```text
[DYNAMIC IMAGE MENTION PREFIX, OMIT WHEN NO REFERENCES]
生成一张横向16:9、2K、目标2048×1152的电影级分镜画板；它是完整production board，不是海报、单张主体图、PPT截图或纯文字页。采用高级灰、透明UI、细线框、半透明卡片和紧凑网格，缩略图为连续真实电影画面，所有说明放在缩略图外。

【参考职责】图片1：[ROLE/SCOPE/PRIORITY]；图片2：[ROLE/SCOPE/PRIORITY]。主身份参考覆盖细节、尺度、风格图；每张图只控制声明范围。
【事实边界】可见事实：[VISIBLE FACTS]；用户确认：[CONFIRMED CLAIMS OR NONE]；未知/禁止声称：[UNKNOWN OR PROHIBITED].

【顶部/Header】《[PROJECT TITLE]》
```

## 生成后的判断

画板生成后先检查主体一致性、镜头可读性和文字层级，再交给用户视觉确认；只有用户明确认可，才能把它作为视频参考。视频提交后区分“已提交”和“已完成”；用户要求质检时，检查身份漂移、形变、动作完成、连续性、画面文字和口播。发现问题先判断是素材、创作方向、画板、prompt 还是模型能力造成，再改对应一层；任何重做或变体都重新展示变更与费用并获得确认，不原样盲抽。
