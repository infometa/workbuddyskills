# 实词/成语积累 Skill

指导 Agent 用 `word_accumulate_practice` 生成一组待积累的实词或成语,渲染成会话内的可交互练习页,**用户在页面里完成「词义掌握 + 例句应用」并本地判分**。

> 参数取值、不剧透约束、空数据兜底都写在 `word_accumulate_practice` 的工具说明里,本 skill 不重复,只补:**怎么从用户话术判断练实词还是成语**、**答完之后怎么用返回数据讲解**。

## 何时使用

- 「帮我积累几个实词 / 背几个成语」「每天学几个词」(要词汇积累)
- 「词汇量不够,言语题老栽在词上」(备考场景要打底)
- 「给我几个成语,带意思和例句的」(要释义+例句素材)

**与 confuse-word skill 的分工**:
- 目的是**记住词**(释义、用法、例句)→ 本 skill。
- 目的是**分辨几个近义词的差别**、想做辨析题 → **confuse-word skill**。
- 用户两者都想要时,先积累再辨析,分两次调用。

## 判断练习类型(exerciseType 路由)

| 值 | 含义 | 用户话术信号 |
|---|---|---|
| 5 | 实词积累 | 实词、词语、词汇、近义词 |
| 7 | 成语积累 | 成语、四字词、典故 |

- 用户没说清是实词还是成语时**先追问一句**,不要默认。
- 用户笼统说「积累词汇 / 背词」且无成语信号时,按 `5` 处理。
- `count` 是**词的个数**(每个词配一道例句应用题),不是题目数;用户要「多来点」时传 `count=10`(上限),并说明一次最多 10 个词。

## 答完之后:用 items 里的字段讲解

渲染后只说一句引导语(如"给你挑了 5 个实词,在下面的练习页边记边练"),**不要把词逐个讲一遍,也不要提前说答案或解析**。

用户答完追问某个词时,再取 `items[]` 里该词的字段展开:

| 字段 | 讲解时怎么用 |
|---|---|
| `paraphrase` | 该词释义,回答"这个词到底什么意思" |
| `sentences[]` | 本词例句,`content` 是句子、`origin` 是出处(如"2019 国考"),讲用法时带上出处更有说服力 |
| `confuseWordName` / `confuseSentences[]` | 易混词及其例句,**可空**——不是每个词都有,为空时不要硬凑易混词对比 |
| `question.solution` | 该词例句应用题的解析,用户问"为什么选这个"时用 |

练习是**匿名无状态**的:每次调用重新选词,不记录已积累的词,也不做记忆曲线/错题跟踪——用户问"我昨天学的词"时如实说明。
