# 商拍创意手法与品类匹配库

业务来源：商拍需求 v0.15（2026-10-15）；手法仍待真实成片验收。

## 使用方式

本文件服务于[大牌同款·AI爆款产品商拍库](../SKILL.md)，仅负责产品分析、生活场景匹配及品牌氛围创意设计。输入职责、三选一交互、画面比例、单张交付、产品保真、修改与异常处理统一遵循主文档。所有手法均以产品外观不变为最高前提，服从[摄影规则 P01](./photography-guide.md) 与摆放适配规则；用户偏好、场景与创意不得覆盖保真要求。

1. 白底棚拍使用[摄影模板 T01](./photography-guide.md)，不套用场景或创意手法。
2. 生活场景图从 L 系列选择叙事或取景手法，组合真实生活片刻与地点；品牌氛围图从 B 系列选择创意手法，以视觉概念组织画面。默认内部完成，不要求用户再选一次风格。
3. 品类用于检查合理性，不能直接决定创意。结合产品形态、材质、可见特征与用户偏好确定一个方案。
4. 用户指定的参考图可以超出库内分类；未命中条目时，按相同规则设计，不强行套模板。
5. 每次只选一个主手法，必要时搭配一个辅助手法，填入 T02 或 T03 后删除候选项和内部说明。品牌氛围不强制配置承载台，不默认居中直立。

## 产品分析维度

| 维度 | 内容 | 作用 |
| --- | --- | --- |
| 品类 | 护肤、服装、饰品、电子数码等 | 选择合理环境和展示目的 |
| 形态 | 瓶、盒、袋、软管、平铺衣物、链状饰品等 | 决定摆放、视角与构图 |
| 可见材质 | 玻璃、金属、哑光塑料、纸、织物等 | 决定高光、边缘与阴影处理 |
| 已知状态 | 包装闭合、屏幕关闭、服装平铺等 | 避免无依据改变状态 |
| 外观重点 | 标识、标签、按键、图案、珠宝镶嵌等 | 明确生成提示词中的外观保留重点 |
| 不确定信息 | 实际尺寸、模糊文字、背面、内部、成分等 | 避免通过生成擅自补全 |
| 创意依据 | 可观察的形状、纹理、配色、透光特征，或用户提供的品牌信息 | 提出具体主题，不冒充官方品牌定位 |
| 既有方案 | 已认可的主题、手法、摆放、构图与空间关系 | 续作保持一致性，换风格时避免重复 |
| 用户偏好 | 配色、风格、场景、参考图、留白等 | 决定最终配方与调整 |

只记录能从图片或用户陈述得到的信息。不能将图中看起来像金属的表面直接认定为某种贵金属，也不能由品类推断防水、食用成分等属性。

## 匹配顺序

前置条件：各图用途与展示商品已由用户说明或确认。多图上传、单图含多个产品但意图未明确时，先按主文档询问；不得先按系统猜测匹配产品或参考风格。已确认的信息直接复用。

1. 锁定图片类型与用户偏好，保留已确定比例；先按[素材规则“摆放适配规则”](./conversation-rules.md)核对外观依据与支撑可行性，悬浮原图应在保持商品外观的前提下主动调整为物理合理的姿态，不锁定原角度，直接进入后续流程，不因悬浮展示询问或提醒补图。
2. 白底棚拍直接使用 T01；生活场景按“产品用途与偏好 → 一个生活情境 → 一种主手法 → 填入 T02”匹配。
3. 品牌氛围先提取创意依据，提出一个具体主题，再选 B 系列主手法，明确一个视觉记忆点以及产品与环境的关系，最后安排摆放、构图与布光。
4. 优先排除改变商品外观的方案，再核对物理支撑；允许依据可见结构调整姿态与视角，冲突时先自主换方案，只有无法绕开的关键细节缺失才补图。未知成分、尺寸或功能不能作为画面事实。
5. 比对已有成片，尊重系列一致性或换风格要求；确定一个方案后，按主文档简述画面与真实报价，取得确认再生成一张图。

同一品类可匹配多种手法。例如相机的镜头圆形可引出光学折射或色彩图形；香水玻璃的透光特征可引出光学折射，标签与瓶身的材质差异可引出材质对照。不得固定为“香水＝大理石”“数码＝黑展台”“美妆＝粉色圆台”。

用户偏好与产品真实性冲突时，说明具体冲突并采用最接近的合理方案；如果会实质改变用户想要的效果，再补问。例如纸盒要求布满水珠，可提出改用背景水光，但不自行宣称包装防水。

仅在用户已指定某张图为风格参考后，提取其光线、背景、构图、配色与道具关系。产品外观来自已确认的产品照片，展示范围按用户选定商品或组合执行。即使图片看起来明显是一张白底商品图加一张场景图，也不能自行分配角色。

## 生活场景与品牌氛围创意手法索引

L 系列与 B 系列各包含八种创意手法。以下为待实测业务设计，不宣称已验证效果。L 系列在 v0.8 重新定义；窗边、梳妆台、厨房、运动场、营地等都是可组合的地点，不再独立充当手法。B 系列沿用 v0.7 的定义，柔白、暗调、暖石、织物等仍是色调与材质选项。

### L 系列：生活场景创意手法库

生活场景回答“产品为何在这里、此刻发生了什么”。按上方匹配顺序选择一种主手法，再用[摄影模板 T02](./photography-guide.md) 统一组装提示词。居家、户外、运动与出行都是场景选项，不另设流程；产品保真、环境接触、修改与交付规则统一遵循主文档。

| 编号 | 手法 | 画面做法 | 场景举例 |
| --- | --- | --- | --- |
| L01 | 行动前奏 | 用就绪摆放和少量准备线索，表达活动即将开始 | 早餐准备、运动前、出门前、露营整理 |
| L02 | 片刻暂停 | 用暂放位置、留白和背景延续感，表现活动中的休息 | 工作间歇、场边休息、步道休憩、旅途停留 |
| L03 | 收纳与展开 | 用有序排列、布面层次和收纳边缘表达整理 | 梳妆整理、衣物平铺、旅行打包、装备归位 |
| L04 | 空间借景 | 近处产品清晰，用少量可识别的背景线索交代地点 | 阳台、公园、球场、城市街角、营地 |
| L05 | 路径引导 | 利用环境边线、纹理或透视，将视线引向合理放置的产品 | 跑道边、步道休息区、长凳、通勤空间 |
| L06 | 日光叙事 | 通过具体时段的自然光与活动联系，表达生活节奏 | 晨间洗漱、午后阅读、清晨运动准备、傍晚野餐 |
| L07 | 近景与纵深 | 用局部环境形成前景，中景产品清晰，后景交代活动 | 布巾边缘后的茶歇、椅背侧的休憩、帐篷入口内的整理 |
| L08 | 日常呼应 | 用真实环境中的形状、颜色或材质与产品形成呼应 | 球拍圆弧与球场线、衣物与布面纹理、包装配色与野餐布 |

场景举例可按产品用途替换，不是固定模板。品类适配与特有易错点统一查[摄影规则“品类范围”表](./photography-guide.md)，不另维护一套场景匹配表。

### B 系列：品牌氛围创意手法库

| 编号 | 主手法 | 匹配依据 | 画面组织与视觉记忆点示例 | 边界 |
| --- | --- | --- | --- | --- |
| B01 | 光影构成 | 轮廓清晰、线条或几何形状突出 | 斜向光带穿过背景，与产品长边呼应；弧形投影围合圆形主体 | 光影要与产品形成关系；不靠压暗主体制造质感，标签可读 |
| B02 | 光学折射 | 透明材质、镜面细节、镜头或光学视觉主题 | 前景玻璃、棱镜或透镜产生折射光斑，光弧与主体轮廓呼应 | 光学道具不视为商品配件；不折歪主体、不重影标签，不暗示实际产品光学性能 |
| B03 | 材质对照 | 可见表面之间具有清晰差异 | 光滑金属与粗纸形成触感对比；透明瓶体与柔软织物形成疏密关系 | 不改变产品材质，不让辅助材料覆盖结构；不是简单换一块台面 |
| B04 | 自然意境 | 产品颜色、纹理或用户主题适合自然元素 | 沙纹延伸至远处地平线，产品轮廓与起伏线条呼应；树影横跨风化岩面 | 自然元素只用于造境，不暗示香调、成分、防水或耐候性能；无依据不浸水、不埋入商品 |
| B05 | 色彩图形 | 包装配色鲜明、轮廓或印刷图形可提炼 | 提取商品配色用于纸面色块，以平铺或斜向布局连接弧线与投影 | 色块服务构图，产品不改色、不拉伸；不默认变成几何展台 |
| B06 | 编辑式静物 | 适合平放、组合或非对称展示，材质细节有层次 | 非对称布局、前景遮挡环境、克制道具与留白形成杂志静物节奏 | 不遮挡关键商品部位，不引入人物；保留已确认数量，不添加广告排版 |
| B07 | 尺度与空间 | 轮廓清晰、适合环境纵深和透视引导 | 重复环境线条延伸至远处，产品成为透视焦点；以深远背景形成疏密对比 | 产品比例不变，不把商品做成巨物或用已知尺寸道具制造尺寸误导；不复制产品充当背景 |
| B08 | 超现实广告 | 用户明确要求或认可具体创意合成方案 | 真实产品与悬浮纸带、非现实空间或已说明的悬浮关系形成广告概念 | 非默认；报价确认中说明具体非写实效果，不用于功能证明；仍保持商品结构、颜色、数量与文字 |

示例只用于说明手法，不要求每次复刻。展台可以作为必要的空间元素，但必须说明其构图作用，不能成为所有品牌氛围图的固定答案。

### 创意选择与变化规则

- 每个方案必须能用一句话描述视觉记忆点，例如“前景折射出的弧形光带与镜头圆形呼应”。仅写“暗调高级、电影感”不算完成创意设计。
- 依据可见结构选择保持商品设计与比例的平放、直立或合理倚靠，允许调整姿态与视角；非对称布局通过位置与留白实现，不要求重画商品。不为了新构图生成无依据的背面、内部或改变已知开合状态。服装继续采用平铺。
- 道具必须有明确作用，数量克制。玻璃、镜面反射不得造成商品数量误解；自然素材不得被当作未经证实的成分。
- B08 的例外仅针对已认可的非现实环境或支撑关系，不扩展到产品保真、人体交互或未知功能展示。非 B08 仍保持写实支撑、接触与光照。
- 用户要求“换个风格”时，品牌氛围在摆放、构图、主手法、空间关系中至少改变两项；生活场景按主文档“按反馈修改”处理；只换底色不算新的整体创意；但保真优先于变化数量。角度调整会涉及未知关键结构时，优先改变构图与环境关系，不为创意变化默认要求补图。
- 用户只改颜色或亮度时，不触发整体变化；要求系列一致时，延续已认可方向，不强行追求差异。
- 创意方案与报价合并确认，不新增八选一、候选图审批或多张输出步骤。

## 配方与创意手法维护结构

每个条目按以下字段细化。生活场景重点维护生活片刻、叙事手法与环境关系，品牌氛围重点维护主题、视觉记忆点与关系，不能只积累抽象形容词。

| 字段 | 内容 |
| --- | --- |
| 身份 | 编号、名称、所属图片类型 |
| 适用条件 | 形态、材质、已知状态、素材支持程度、不适用情况；品类只是候选线索 |
| 创意依据与主题 | 可观察产品特征或用户信息，以及由此提出的具体主题；生活场景记录活动、具体片刻及用途依据 |
| 主手法与记忆点 | 一个主手法、必要时一个辅助手法，一句可直接描绘的核心画面 |
| 空间与视觉关系 | 产品与光影、材质、环境的位置或形状关系；写实方案说明支撑方式，不强制使用展台 |
| 环境与道具 | 具体地点、时段、天气或室内光照、户外接触边界及背景、辅助元素及位置和作用，不遮挡产品，不暗示未知成分或功能 |
| 布光与色彩 | 主光方向、软硬、补光目的、阴影、反射、主辅色；产品本色保持准确 |
| 摆放与构图 | 按主文档摆放适配规则确定的接触面、支撑关系、姿态、视角、景别、主体位置与留白，分别说明三种比例的适配 |
| 保真与边界 | 标签、结构、数量、状态、品类限制；B08 另记已认可的非现实关系 |
| 可调与变化维度 | 可调整的摆放、构图、手法、空间关系及配色；记录系列保留项与换风格差异 |
| 实测记录 | 实际输入、输出、适用边界、失败案例与修正方式；未实测不填虚构效果 |

八种生活场景手法与八种品牌氛围手法均需后续接入测试；本索引不代表已具备样片或通过质量验证。
