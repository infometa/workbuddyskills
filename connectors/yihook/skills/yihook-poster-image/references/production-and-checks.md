# 海报制作与核验

规划、报价、制作和交付时按对应章节读取；设计时同时完整读取[默认风格提示词](./poster-style.md)。当前对话由宿主维护文字、素材、确认与结果版本，不新增项目存储或持久流程。

## 制作路径与付费前检查

| 情况                                   | 制作路径                                                                                                                                 |
| -------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| 纯文案，或获准生成配图且无须保护原素材 | 可用图片模型制作完整海报，文字仅限确认清单；不虚构真实人物、产品或场地                                                                   |
| 含真实照片、Logo或二维码               | 宿主已有本地图像处理能力直接排版合成。需要模型时仅生成独立背景、装饰或获准新视觉，再合成原素材与文字；不能将整张受保护照片送入模型重生成 |
| 修改已有海报                           | 核对原成品、可编辑文件及原素材，确定只改项和可靠保留范围；扁平图整体重生成不能冒充局部编辑                                               |
| 仅需本地排版、合成或导出               | 不调用付费图片接口、不创建占位任务或虚构任务ID，仍遵守整卡确认与交付后不擅自修复规则                                                     |

本Skill不携带专用合成脚本或新增后端服务。付费前实际核对完整文件读取、查看图片、所需裁剪／等比缩放、文字及原图合成、PNG或高质量JPEG导出与实际文件交付能力。按原文检查字体、Emoji、圈号和特殊符号能否准确渲染；用户指定字体却无字体文件时说明具体缺口，不谎称使用某款字体。

原素材缺失、必要字符无法显示、无法保护主体或无法导出时，在付费前说明具体问题及可行选择并停止相关制作；不能先收费再舍弃素材、换字或改成整图重绘。仅有实际影响结果的选择才补问，不重复索要已授权信息。

## 原文与画布

1. 保存准确原文，对照确认卡逐页建立文字清单，保持用词、数字、标点、Emoji及阅读顺序。只划分原文已有层级，不擅自增加标题、编号、英文或口号；文案截图模糊处先核实。长文不按固定字数自动删减。
2. 默认9:16、2K，依据现有模型推荐可规划1152×2048画布，此为目标像素，交付必须重新读取最终文件验证。指定其他画幅时服从确认方案，分别记录模型参数与最终画布，不能为适配静默拉伸或裁断主体。
3. 按实际排版判断承载，先减少装饰、优化分区及图文比例；仍难读时提出保留全文拆页。确认后逐页排版并保留顺序，系列配色、字体系统和品牌位置统一。重复标题、页码和“续”均属新增文字，必须获准；精简与改幅同样先确认并更新报价。
4. 实际打开原文件，按EXIF方向解码，记录角色、取景、缩放与允许调色。照片必须以真实字节参与合成，不以描述或相似生成图代替。非生成式裁剪、等比缩放及整体亮度色调调整仅在确认范围内；人物外貌动作、宠物、产品结构、场地布局和相互关系受保护。
5. 背景处理或抠图须获准且可靠隔离，不自动修脸、改体型或擦标牌。默认优先在照片外加色块与文字，不能让文字遮挡关键主体。处理能力不足先说明，不通过整图生成绕过。
6. Logo原文件只等比缩放及移动，保留完整形态、颜色和留白。二维码保留码点及必要安静区，采用不会模糊码点的缩放方式；解码原图与成品中的二维码，能取得编码内容时比较一致性，不能重画一个貌似相同的码。无法检测时标记未验证，不声称可扫。
7. 本地按确认风格绘制完整文字，标题允许受控大小／位置变化，正文清楚规整；不能为了装饰破坏字形结构。保存本次可读原素材、生成层和布局所需文件，导出新版本，不覆盖原文件或旧成品；跨会话只有实际保存且可读时才承诺复用。

## 实际生成层与报价

每个真实调用记录图层用途、比例、分辨率、质量、提示词和参考列表；模型输出张数与最终海报张数分别计算。一个模型背景再合成照片和文字只计一次模型生成；复用已生成层不重复报价，也不能为省调用破坏已确认的逐页设计。不自动增图、补做或为选优多生成。

按实际图层职责组装提示词：任务及画幅 → 本次图层用途 → 完整确认文字或“无新增文字” → 素材角色与保护范围 → 具体字形、色彩用途及图文分区 → 检查要求。

- **完整海报**使用逐页完整原文清单，落实默认风格的标题、色面、图文关系和密度要求，不重复、润色、翻译或补装饰性文字。
- **独立无字层**仅使用对应背景、色块、材质和分区约束，预留实际标题／正文／照片区域；明确不生成文字、受保护人物、产品、Logo或二维码。不能照搬参考的“完整海报／标题设计”要求与图层职责冲突；字形、全部原文及真实素材在最终合成落实并检查。
- **指定风格参考**先实际查看，接口支持时作为真实参考传入，只提取设计方向，不复制图中人物、品牌、文案、水印或二维码。不能查看或传入时如实说明，不声称已参考。

受保护照片、Logo及二维码只参与本地合成时不送模型，不计入模型参考数；用户明确放开某项改绘才按实际需求传入，其他素材继续保护。模型参考先经本渠道上传／完成确认，不能把来源URL当作已完成的本人托管引用。

报价按所属runtime复用实时规则，实际参考数、参数及调用次数必须一致。免费报价不证明素材字节或制作能力已校验；必用素材失败不能忽略后继续付费。拆页整套与修改各自集中确认单项及合计费用，无确定报价不提交。纯本地任务明确“本次不调用付费生成接口，无模型调用费用”，不为获取报价创建无用任务，不扩大为宿主整体价格承诺。

## 核验真实成品

实际导出并重新打开最终文件，预览、下载及费用对应本次准确版本：

| 项目         | 核验重点                                                                                                                                                                                         |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 原文         | 与确认文字逐项核对，检查漏字、错字、多字、重复、数字、标点、Emoji及阅读顺序；既有step①等标签不自动再加编号                                                                                       |
| 原始主体     | 核对原文件真实进入合成。程序可验证时将保留区域与采用相同方向、裁剪、缩放及获准调色后的原图比较，记录操作；确认新增图文区域另行检查。相似外观或提示词不能证明保真，抠图无法可靠隔离时不冒充已验证 |
| Logo与二维码 | 原文件合成、形态颜色文字与比例不变、留白完整；二维码实际解码并核对可得内容，未测说明未验证                                                                                                       |
| 阅读与密度   | 以手机尺度实际查看标题、正文、步骤和分区，检查对比、行距、留白及遮挡，不用缩小正文掩盖承载不足                                                                                                   |
| 风格         | 对照确认卡，检查利落标题、主辅色用途、图文关系、分区和少量装饰；未要求时不滑向水彩粉彩、花草填充、大面积白底密集黑字或重复卡片                                                                   |
| 系列         | 逐页全文完整、顺序正确、风格统一、素材对应；新增重复文字均已获准                                                                                                                                 |
| 文件         | 解码读取实际像素、比例、格式、张数和可访问性，不由请求值推断；独立背景URL不等于最终海报，预览与高清文件同版                                                                                      |
| 费用与状态   | 读取本渠道实际任务及结算数据，未取得实扣明确说明；不将输入预算或预估当实扣，不推定失败已退款                                                                                                     |

OCR仅辅助，不能只凭提示词宣称逐字正确；目视不冒充精确测量，无法查看或可靠核验的项目明确标记。

## 交付及修改边界

展示可读取成品与高清文件，附实际规格、版本及可核实费用。存在偏差仍交付可用结果，简短客观指出实际偏差，不说完全通过。**不自行修复、修改或重生成，即使免费也不执行；不主动提出修复方案、报价或修改卡，不要求回复“确认修改”。** 可用“如需修改或重做，随时告诉我”收尾。

只有用户明确提出修改／重做才确认只改项、沿用项、必要联动及实际费用；本地修改不虚构模型收费，新增生成须重新报价及确认。部分成功先保留成功项，未知创建按原协议查询恢复，不能自动重发。返回旧版使用实际旧文件，不重新生成冒充历史版本。
