# 封面制作与核验

本文件在规划、报价、制作及交付时按对应章节读取；设计时同时读取[默认风格提示词](./cover-style.md)。首版仅支持图片和文字，长文／视频脚本作为文字资料处理；不读取视频选帧、解析视频分享页或制作视频。收到视频时说明本次需要用户选好的图片附件或图片文件直链，不自行扩大范围。

## 制作路径与付费前检查

使用宿主已有本地图像处理能力，不新增专用合成脚本或后端服务。单次对话由宿主维护素材映射、文案和版本；不新增项目存储或持久流程。

| 情况                                       | 制作路径                                                                                                                             |
| ------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------ |
| 纯文字、无需原样保留的生成配图或无字新视觉 | 可用图片模型制作完整封面，文字限定为已确认清单；只生成用户明确授权的视觉，不虚构真实素材                                             |
| 含真实照片、Logo或二维码                   | 原始素材直接本地排版合成。需要模型时仅生成独立背景／装饰／获准新视觉，再合成文字及原素材；不能将整张含受保护内容的成品送入模型重生成 |
| 已有原成品／可编辑文件上的局部修改         | 检查图层、原素材及指定区域能否可靠保留，说明只改项、沿用项与必要联动；不能将扁平图整体重生成称为精确局部编辑                         |
| 仅需本地排版、合成或导出                   | 不调用图片接口、不创建占位任务，不虚构价格、积分扣费或任务ID；仍遵守整卡确认及交付后不擅自修复规则                                   |

含真实素材时，生成前必须实际确认宿主可读取完整文件、查看图片、进行所需裁剪／等比缩放、绘制图文及原图合成、导出PNG或高质量JPEG并交付。按实际需要检查字体、Emoji和指定符号的渲染能力；用户指定字体时无该文件不能假称已使用，先说明具体缺口。禁止让模型仿造字体文件、二维码或原照片。

本地图形能力不足、原文件缺失、必用素材不清晰、要求精确局部修改却没有可保留源文件时，付费前说明具体问题与可行选择并停止相关制作，不能先收费再降级。用户已授权的处理范围不重复询问，不附通用制作方式免责声明。只有实际存在影响结果的选择才集中澄清。

## 原始素材与输出画布

1. 实际打开源文件，按EXIF方向解码；记录文件角色、取景、坐标、缩放及允许调色。照片直接用于合成，不以描述代替实际字节。主体、风格图、Logo、二维码与已有成品逐项对应，不擅自丢弃指定素材。
2. 默认3:4、2K，按现有模型推荐可规划1536×2048最终画布。此为目标像素，必须重新读取最终文件证明实际尺寸；不把“2K”称为平台全入口标准。用户指定其他画幅时服从确认方案，模型参数和最终画布分别记录，不能为适配而静默拉伸、裁主体或更改比例。
3. 原照片等比缩放及确认范围内裁剪，不裁断人物、宠物、产品关键部位及关系；默认优先在照片外增加标题色块。整体亮度色调只在确认范围内调整。背景删除、换背景及抠图只在已授权且能可靠隔离时执行，保留主体像素，不自动修脸、夸张表情、改体型、改产品结构或场地标牌。
4. 本地按已确认字形气质绘制完整文案，不更换文字。没有指定字体文件可采用宿主实际可用字体及有控制的尺度／位置变化落实设计，不能谎称使用某款字体；Emoji无法准确显示时在制作前提出具体缺口，不能擅自删换。
5. Logo原文件只等比缩放、移动，保留颜色、形态与留白。二维码使用原始图像，避免模糊插值破坏码点，保持必要安静区；解码原图及最终成品中的二维码，能取得编码内容时比较一致性，不重新生成一个看似相同的码。无法实际解码或验证时明确标记，不声称已经验证可扫。
6. 保存生成层、原素材和已确认布局所需的本次可读取文件，导出新版本，不覆盖原稿、素材或旧成品。不要求建设可编辑产品页面或后端版本库。跨会话只有用户授权实际保存、且文件可读取时才承诺复用。

## 模型生成层与费用

需要生成层时，先把确认方案映射为每个真实调用：比例、分辨率、质量、完整提示词与实际参考列表。纯文字完整封面使用确认文字清单；合成模式只生成独立背景／装饰，不在生成层绘制原照片、Logo、二维码或文字。确定图层用途、标题区与原照片区，使最后本地合成仍满足确认的构图。

风格图必须先实际查看，接口支持时作为风格参考传入，并说明只提取设计方向，不复制图中内容；无法读取或传入时如实说明，不声称已参考。主体素材仅在本地使用时不为“保护原图”而提交给模型，不计为模型参考；用户明确允许改绘某项时，才按该项真实需要传入，其他素材仍直接合成。模型参考按本渠道完成上传，不以原始来源URL冒充托管引用。

一个模型背景加本地照片／文字构成一张成品，不算两次模型生成；不默认为了选优多生成。多个版本逐张列明文案、素材、差异、实际调用及报价，统一确认总价；共用已生成层时不重复收费，也不能为了省调用而破坏用户已确认的版本差异。新付费调用只在本次授权内执行。

完整读取默认风格参考，按本次实际图层职责组装提示词：任务和画幅、图层用途、具体字形／颜色／拼贴布局、已确认文字或“无新增文字”、素材角色及保护范围、检查要求。完整封面任务使用完整的适用视觉约束；独立无字层只使用对应背景与拼贴约束，明确不生成文字或原主体，不能照搬“完整封面／排印标题”要求与图层职责冲突。标题字形、文字准确性及原素材保护由宿主在最终合成阶段落实和检查，不能因模型只做背景就免检成品默认风格三项。原始长文不放入上图文字清单，必要背景资料标为“仅供理解，不印入画面”。不得在制作阶段再次提炼、补字、加英文或消解已确认风格；用户明确其他风格则按确认方案覆盖。

免费预检／报价、素材上传、付费创建及原任务查询按所属runtime执行，不新增生成接口、业务请求键、报价凭证或确认表。纯本地任务无需借一个无用生成任务获取报价，确认卡如实列明“本次不调用付费生成接口，无模型调用费用”，不将其扩大为宿主服务的价格承诺。

## 验证真实文件

导出后重新读取真实成品，预览与高清下载必须对应同一版本：

| 项目         | 检查方法与边界                                                                                                                                                                                                                   |
| ------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 文案         | 逐项对照锁定文字，检查漏字、错字、多字、重复、数字、标点、Emoji与阅读顺序；无字检查未经要求的新增文字，原图受保护标牌不自动擦除                                                                                                  |
| 资料支持     | 标题保留必要限定，无编造数字、经历、优惠或效果；开业等核心主题由图文或已确认标签表达，或用户明确选择氛围表达                                                                                                                     |
| 密度         | 主标题建议6—14字／最多两行、全图建议24字／默认上限30字；检查实际占宽，例外以确认方案为准，不靠小字或隐藏正文规避                                                                                                                 |
| 默认风格     | 对照确认卡和可读参考，检查标题字形、明确实色色块、清晰拼贴关系三项；普通照片加标题不能自动判定通过；无字免检标题，指定其他风格按其方案                                                                                           |
| 原素材       | 核对原文件实际进入合成。程序可验证时，将保留区域与采用相同方向、裁剪、缩放和获准调色处理后的原图比较，记录操作；排除已确认新增图文遮盖区域，不能仅凭提示词或相似外观称保真。抠图核对受保护内部区域，无法可靠隔离时不得冒充已证明 |
| 品牌与二维码 | 原文件完整合成，比例颜色未变、留白完整；二维码实际解码并核对可得内容，未检测不得称可扫码                                                                                                                                         |
| 缩略与边缘   | 默认3:4约240×320预览，其他比例按相近宽度等比缩小。标题、主体清楚且焦点明确；约8%—10%关键内容边距仅为内部设计参考，不是官方安全区，不保证全入口无裁切                                                                             |
| 文件         | 解码读取实际像素、比例、格式、张数、可用性和预览／下载版本；不能从请求参数反推输出，不能把独立背景URL当成已合成封面                                                                                                              |
| 多版本       | 逐张检查本轮文字与对应素材，系列风格一致、各版差异符合确认；成功项保留，不补做或重跑                                                                                                                                             |

OCR仅辅助；不声称目视等于精确测量，不把尚未执行的检查写成通过。无法查看或核验时如实标记具体项目及影响。

## 交付与修改边界

可读结果即展示预览及高清文件，附实际规格、版本和可核实费用；结果有偏差时简短指出实际缺失，不说完全通过。不因文字错误、风格缺项、素材偏差或缩略效果不好而自行修复、改图、重生成，即使本地修改免费也不自动执行；不主动发修改卡或报价。可说“如需修改或重做，随时告诉我”。

用户明确提出修改后才进入本轮方案：确认只改项、沿用项、必要联动和实际费用。本地修改不虚构模型费用，新增模型调用先按真实调用重新报价并确认；不拿旧报价授权另一张图。部分成功先交付已有结果，未知创建及链接失效按原任务处理，不重新生成。
