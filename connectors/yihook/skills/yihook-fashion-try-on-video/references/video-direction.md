# 试穿视频规划、提示词与检查

图片确认后新建或修改视频前读取；交付时读取检查要求，单纯续查不重新规划。以当前已确认试穿图为主要视觉参考，默认10秒、720p、9:16、参考生成、声音开启，实际参数见所属渠道runtime。初次完整报价只计算费用，不提前向用户展开镜头、动作或配乐。

只选定一个明确方案。V01加V02／V03／V04中适用的一个模块，替换占位并删除其他候选。图1明确为已确认试穿图，其余参考仅补充真实服饰细节或已确认的同一视觉方案；提示词中图序与真实数组一一对应，不把商品原穿着者或未确认的人像当作起始人物。

## 场景、时长与镜头

| 维度         | 业务规则                                                                                 |
| ------------ | ---------------------------------------------------------------------------------------- |
| 默认时长     | 10秒，不用静帧长时间停留、机械慢放或重复片段凑时长                                       |
| 时长扩展     | 用户明确要求时可规划5秒快速展示或15秒扩展展示，更新相应范围与费用；不主动增加时长选择题  |
| 默认镜头数   | 一至两个，按商品类别、素材清晰度和展示重点自动确定，不强制切镜                           |
| 简约棚拍     | 保持安静背景，按服装结构安排插兜、轻扶腰、整理领口或自然侧身，突出商品                   |
| 街景展示     | 简洁街边步行区域、柔和日光；短距离慢走后停步，避免人群、车辆或明显招牌抢占注意力         |
| 运镜         | 固定机位或一种克制的缓慢运动；人物动作复杂时减少镜头运动                                 |
| 切镜         | 同一人物、同一服装、同一场景和光线；允许从整体切到目标商品中近景                         |
| 细节特写     | 必须有足够清晰的商品参考；不能把全身图中不可辨识的细节放大补画后视为真实                 |
| 缺少背面参考 | 不默认360度旋转或背面展示，不编造背部结构作为商品卖点                                    |
| 背景音乐     | 轻量纯音乐，音量克制、节奏适配动作；不含歌词、口播或人物发声，不默认增加环境音及夸张音效 |

人物不默认拉扯面料、解扣、拉拉链、脱穿衣服、跳跃、深蹲或大幅甩裙。默认动作展示可见穿着效果，不演示未经依据支持的弹性、防水等功能。

### 自然展示动作规划

动作不按性别固定分配。根据服装结构、展示重点、参考图起始姿态与人物气质，选择一至两个协调的主要动作。用户明确指定的动作优先；不因性别默认加入夸张叉腰、扭胯或刻意展示肌肉。

| 服装与展示条件 | 可选动作及约束                                                                 |
| -------------- | ------------------------------------------------------------------------------ |
| 有真实口袋     | 单手插入对应口袋，配合重心移动或侧身；明确使用哪只手和哪个口袋，不凭空新增口袋 |
| 有翻领或门襟   | 轻整领口或轻触门襟，随后松手露出商品；不拉扯变形，不默认解扣或操作拉链         |
| 重点展示腰线   | 单手轻扶腰侧或自然叉腰，肘部舒适展开，不持续遮挡腰部设计                       |
| 裙装或宽松下装 | 自然迈步、侧身，展示轮廓和随动作形成的褶皱，不强行甩裙                         |
| 携带包袋等配饰 | 根据手部占用选择动作，使用空闲的手，不堆叠复杂手势                             |

人物气质只调整动作力度、节奏与神态：甜美亲和可采用轻柔动作和浅笑；休闲随性可采用松弛站姿、插兜和短暂低头整理衣服；利落干练可采用明确动作、舒展姿态与从容视线。上述气质不限性别，由系统依据已有要求选择，不新增用户选择题。

以真人日常整理衣服的实时速度展示，小幅度不等于慢速度。动作轻松但干脆，具有正常的启动、加速和收势，不让全身持续匀速漂动。主要动作完成后自然展示商品，不把一个动作拉长到填满整个镜头。

| 节奏规划                   | 默认规则                                                                               |
| -------------------------- | -------------------------------------------------------------------------------------- |
| 换站姿、重心移动或小幅侧身 | 约1–1.5秒完成一组动作，随后自然站定，不反复左右晃动                                    |
| 轻整领口等简短服装互动     | 抬手、短暂接触、松开和放手约1.5–2秒连贯完成；不捏住衣领长时间停留或反复摩挲            |
| 动作协调                   | 低头与抬手可以同时发生，放手时自然抬眼；不将头部、肩部、手臂拆成依次执行的慢速步骤     |
| 展示时间                   | 完成动作后保持松弛站姿、自然呼吸与视线变化，必要时衔接一次站姿调整，不靠慢动作填充时间 |
| 语言约束                   | 避免反复堆叠“缓慢、轻轻、停留”等词；区分接触力度轻与执行速度慢，保持轻触但利落完成     |

上述时长是简短动作的节奏目标，不是所有动作的硬性时间限制，也不保证逐秒执行。自然迈步等动作按实际动作长度安排，不强行加速。写清动作起点、接触与结束状态，同时允许协调重叠。不要求全程盯镜头或双臂垂放；手部可短暂遮挡接触部位，松手后露出商品重点。开场自然进入动作，结尾不刻意定格，不固定首尾各静止数秒。

两个镜头要承接同一只手的位置、身体朝向与动作状态，不能切镜后突然换手、恢复初始姿势或改变配饰。动作不得改变服装结构；若没有合适口袋、领口或腰部条件，换成有依据的动作，不机械套用。

### 按商品规划默认10秒内容

| 商品               | 推荐内容                                                                 | 镜头规划                               |
| ------------------ | ------------------------------------------------------------------------ | -------------------------------------- |
| 上衣、针织衫、外套 | 根据真实口袋与领型选定插兜、整理领口等动作，配合侧身展示领口、肩线及门襟 | 素材清晰时两镜头；否则单镜头           |
| 裤装               | 重心移动、单手插入真实裤袋或自然迈步，展示腰部至裤脚的版型               | 可切到下装中近景，完整保留目标裤装     |
| 连衣裙、整套穿搭   | 按服装结构选择轻扶腰、自然迈步与侧身，连贯展示整体轮廓                   | 默认连续全身镜头，保留整体轮廓         |
| 明确细节卖点       | 整体穿着与有参考支持的局部设计                                           | 可安排两镜头；15秒扩展时再按需增加内容 |

单镜头以一至两个主要动作连贯展示，动作利落完成，其余时间保持放松的展示状态。两镜头节奏参考：0–4秒为整体构图，在开场约1–1.5秒完成换站姿；4–10秒承接动作状态，在商品中近景中用约1.5–2秒完成一次简短服装互动，再自然展示。镜头长度不等于动作时长，不要求动作持续到切镜或片尾。时间段是创作规划，不代表仅靠提示词可保证逐秒精准执行；最终按实际视频检查。

### 图片与分镜衔接

已确认试穿图始终是视频视觉依据，首个画面从其姿态和场景自然开始。可对清晰区域进行构图裁切，不能裁掉目标商品关键部位或放大到模糊。

如需要生成新角度或额外细节参考图，应提前纳入方案与费用，并与主试穿图在同一图片验收节点展示。首次默认不增加多张参考图；素材不足时改用已有依据支持的单镜头方案。不得在图片确认后，未经说明自行新增付费参考图。

用户在确认棚拍图后改为街景，或要求更换人物、商品、搭配时，先更新对应试穿图并再次确认，再生成视频。仅调整视频动作且不改变已确认视觉内容时，不要求重做试穿图。

## V01 视频基础模板（Wan 3.0）

```text
基于【已确认试穿图】制作10秒写实服装展示视频，固定9:16竖屏。
从已确认图中的人物姿态、穿搭和场景自然开始。
【原始服饰及其他已确认参考】用于维持已有商品设计和可见细节。

一致性：
保持同一人物的面部身份、发型、肤色、体型与身体比例。
保持目标商品【明确列出的关键结构和图案】、配色、长度和配件数量。
保持配套穿搭，不新增或移除配饰。
衣物随动作产生自然褶皱，不改变款式和结构。

场景：
【已确认场景与光线】。保持空间布局、色彩和光照方向稳定。

镜头与动作：
【插入一个已确定的单镜头或两镜头模块】。
以真人日常动作的实时速度完成一至两个主要动作，小幅度不等于慢速度。
换站姿约1–1.5秒，整理领口等简短互动约1.5–2秒连贯完成，
接触短暂，随即松手放下，不将动作拖满整个镜头。
头部、肩部、手臂与重心协调重叠，低头可同时抬手，放手时自然抬眼。
动作具有正常启动、加速和收势，不全程慢动作、匀速漂动或僵硬站立。
允许手部短暂接触或遮挡局部，动作完成后清楚露出商品重点，人物不出画。
只展示参考支持的角度，不擅自转到背面。
动作结束后自然展示，保留呼吸和视线变化，不反复摆动。
开场自然进入动作，结尾不刻意定格，不用慢放或长时间僵站凑时长。

声音：
轻量、无歌词的纯音乐背景，【适合当前场景的克制风格】，
节奏与动作协调，开头和结尾自然过渡。
无口播、无人物说话，无额外环境音或夸张音效。

画面要求：
不新增字幕、标题、水印、贴纸或品牌标志。
保持面部、手脚、服装边缘和图案稳定，无突然变形、衣物穿插、
图案漂移、背景闪烁或新增人物。
```

## V02 单镜头模块：连衣裙／整套展示

```text
一个连续全身镜头，固定机位，不切镜。
从参考姿态自然开始，【按服装结构选定一个明确动作，如左手轻扶腰侧】，
同时自然转移重心，另一只手舒适放松，头肩随身体协调移动。
随后【选定一个衔接动作，如向侧前方自然迈出一小步并轻微侧身】，
接触衣物的手自然松开或顺势调整位置，清楚展示商品轮廓。
每个简短动作利落完成，不拉长到填满镜头；重心移动与手部动作协调发生。
动作之间自然展示，有呼吸和视线变化，不夸张扭胯、不拉扯衣物。
结尾松弛、不刻意定格，全程保留头顶与鞋底，人物尺度和透视自然。
```

## V03 两镜头模块：整体＋商品重点

```text
两个镜头，人物、服装、场景和光线连续一致，不更换造型。
前约4秒：全身或中全景，从参考姿态自然进入【一个具体动作】，
换站姿等简短动作约1–1.5秒完成，随后松弛展示，不持续缓慢转身。
明确手部接触的真实部位，配合重心移动和侧身展示整体版型。
后约6秒：自然切到【按商品选定的中近景范围】，
承接上一镜头的身体朝向和手部位置，再完成【一个衔接动作】。
整理领口等简短动作的抬手、接触、松开和放手约1.5–2秒完成，
接触短暂，不捏住衣物停留。低头与抬手同时发生，放手时自然抬眼。
随后自然展示商品，可顺势调整一次站姿，不连续堆叠新动作，结尾不刻意定格。
不在切镜时突然换手或复位。手部接触后露出商品重点。
第二镜头不新增纹理、标识或结构，不使用缺少依据的极近特写。
```

适配示例：有斜插口袋和翻领的外套，可先右手插入真实右侧口袋并自然侧身；切镜后右手保持插兜，左手轻整左侧翻领，松开后自然放下。该动作组合不是通用必选项，需根据参考图与服装结构调整。

## V04 街景单镜头模块

```text
一个连续镜头，固定机位，保持已确认街景与柔和日光。
从参考姿态自然开始，沿画面预留方向正常速度迈出一至两步，
手臂随步伐自然摆动，肩部和重心协调变化。
停步后顺势完成【一个适合服装的明确动作】，自然调整朝向，
简短服装互动约1.5–2秒利落完成，手部接触后及时松开，
动作结束后自然展示商品，结尾不刻意定格。
人物始终完整入镜，不突然改变行走方向，不机械慢放，
不出现行人或车辆遮挡。
```

模块按实际试穿图适配：无行走空间就安排原地重心移动与合适的服装互动；起始姿态已插兜时，不要求第一帧突然双手垂放。不要同时拼接多个互不兼容的模块。声音随Wan视频生成：实际参数开启声音，模板指定轻量纯音乐，交付前完整播放并听检。不独立创建音乐或换轨；声音不满意引导重新生成视频，保留已确认试穿图，先核价确认，不自动重试。

## 视频检查

- 核对实际10秒时长、9:16比例、文件可播放性及下载入口。
- 检查人物身份、脸、发型和身体比例在运动中是否变化。
- 对照原始商品图与已确认试穿图，检查领型、衣长、口袋、纽扣、图案、颜色等是否漂移或改变。
- 检查简短动作是否及时完成、是否被拖满镜头，是否长期僵站、机械慢动或全身匀速漂动；检查低头、抬手、放手与视线变化是否协调，是否在接触衣物后过久停留；检查手与口袋、领口等接触是否合理、松手后商品是否露出，手脚与衣物有无穿插，人物有无出画，是否出现无依据的背面或细节。
- 两镜头检查切换前后的身份、穿搭、场景、光线和商品结构一致性，以及手部位置、身体朝向和动作状态是否连续。
- 检查背景闪烁、新增物体、异常运镜、模糊或压缩导致的商品细节丢失。
- 听检轻量纯音乐是否存在、无歌词及人声、无口播，衔接和音量是否合适；检查没有新增字幕。

核对视频任务使用“参考生成”模式，并检查实际输出为720p；生成模式应以任务设置记录为准，不能仅凭画面推断。

至少完整播放检查；具备抽帧或逐帧检查能力时，重点检查切镜和动作变化位置。仅完成抽帧检查时不得声称逐帧全部通过。不能只检查首尾静帧就认定整个视频合格。明显偏差如实报告，保留可用成果，不以“生成成功”代替验收。

宿主无法完整播放、听检或读取实际规格时，明确哪些项目未验收，不宣称全片／逐帧检查通过。声音不满意时说明可调整声音要求重新生成视频，范围与费用确认后才执行，不保证沿用原画面，不自动重试。
