# 摄影处理与结果检查

分析、规划和交付时按需读取。本规则不触发额外模型调用；所选路径、费用与失败语义遵守主文及所属渠道运行契约。

### 入口 1：AI图活人感修复

目标是可信的真实摄影效果，不是柔滑精修。采用五层方法：光影、主体物理关系、材质微观、光学成像、色彩相互配合，不能只处理皮肤就视为完成活人感修复。

每次内部逐层记录“原图观察 → 保留或调整 → 对应提示词”，五层均须覆盖；正常层落实为保留约束，不为了覆盖检查项强行修改。最终提示词按 L1→L5 写出适用于本图的物理关系，而非仅列五个名称。对用户仍只展示有价值的结论。

“增强活人感／去 AI 感”使用 R01，“抓拍感重构”使用 C01；两者均默认整合 T01 共用肤质规则，由五层诊断决定处理重点。默认评估、按图调整，不统一全脸减亮或减纹理。用户提出均匀肤色、减弱油光等要求时，用于确定重点与强度，不是启用肤质处理的前提；肤质处理不能取代其余光影、主体、材质、成像与色彩检查。

肤色均匀指消除突兀的色块和斑驳，不等于表面光滑、全脸同色或全面压低纹理。保留由皮肤结构、血色、环境反射和光照产生的合理区域差异。高光本身不是缺陷：保留能解释光源、曲面与材质的正常反光，仅处理孤立、失真或破坏细节的亮斑。

采用参考技能中的光影一致性、区域肤质、材质反射与焦平面原则，不机械套用新增雀斑、痘印、痣、衰老、改变表情或统一铺颗粒等做法。真实感不以瑕疵数量或毛孔强度衡量。

| 维度       | 调整方向                                                                                                                 | 保留边界                                                             |
| ---------- | ------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------- |
| 光影       | 柔化不合理高光，使局部阴影、反射和环境色协调                                                                             | 保持主光方向，不默认重新布光                                         |
| 主体与服装 | 检查姿态、衣物褶皱及接触关系                                                                                             | 不借去 AI 味改变身体比例、姿势或五官结构                             |
| 皮肤       | 协调异常色块，同时保留随部位、光照与焦平面变化的毛孔、唇纹和细绒毛；过平滑区域可克制重建摄影尺度的细节，不统一增强或抹除 | 保留原有痣、疤、年龄观感和妆容，不凭空加瑕疵                         |
| 头发与材质 | 保留自然飞发、轻微毛躁和不规则发束，避免过度柔顺与整片光滑高光；区分金属、缎面、皮肤等反射                               | 保留发型、发量、发色、发际线与卷曲程度，保留饰品结构、服装款式与褶皱 |
| 成像       | 减少硬锐化、蜡质降噪和假虚化边缘                                                                                         | 不统一铺噪点或毛孔，不强加模糊                                       |
| 色彩       | 自然肤色与环境色协调                                                                                                     | 不默认美白、变更肤色或强烈电影调色                                   |

默认锁定五官、表情、目光、姿态、人物大小位置、画幅、裁切、顶部留白、背景、服装与饰品。轻度修复即可，不要求缩略图上必须出现强烈差异。

细节强度随景别和光线变化：远景不强求毛孔，暗部不过度锐化，纹理不能像覆盖在皮肤上的贴图。自然感不等于油亮、疲惫、衰老或粗糙，也不强制去妆。

明显畸形肢体等结构问题需结合用户请求判断；未获相应修改授权时说明问题，不自动拓展为人体重塑。

### 头发质感：两个入口的共用规则

两个入口均检查头发是否过度柔顺、发束排列过于整齐或高光连成光滑片状。保留原有自然散丝；需要调整时，允许适量飞发、轻微毛躁、发束间疏密差异与局部不规则走向，使头发有真实纤维感、蓬松层次和轻微凌乱感。发丝遵循生长方向与重力，反光随发束朝向和光照自然变化，不统一消光，也不做成丝绸或塑料般的整片亮面。

按原图发质、发型与场景控制程度，不把自然等同于蓬乱、干枯或脏污。已自然的头发保留，不机械添加飞发；不改变发量、发色、发际线、长短和卷曲程度，不用细碎噪点或满头等强锐化模拟发丝。入口 1 仅调整局部质感，保持整体轮廓；入口 2 只有已确认的动作或环境依据时才增加相应的轻微动态，不默认添加风吹效果。用户明确要求头发保持原样时优先遵守。

### 面部肤质自然化：两个入口的默认规则

AI图活人感修复与抓拍感重构均默认评估肤质，并按原图实际状态采用 T01 共用规则，不需要用户额外提出肤质优化，也不需要先识别、命名或定位特定纹路。用户提出“优化皮肤质感”“肤色均匀”“减轻油光”等要求时，只调整本轮处理重点与强度。用户明确要求皮肤保持原样时优先遵守，不新增产品入口。

| 原图肤质状态     | 默认处理方向                                                               |
| ---------------- | -------------------------------------------------------------------------- |
| 肤色斑驳         | 协调突兀色块，保留原本肤色、自然血色与合理区域差异                         |
| 反光异常         | 修正不合光照与曲面的亮斑，保留正常皮肤高光和立体感                         |
| 皮肤过平、呈蜡感 | 克制改善符合景别与光线的微观起伏，不以粗糙、强毛孔代替真实                 |
| 纹理过强或重复   | 局部减弱突出的细节，保留正常毛孔、褶皱与稳定特征                           |
| 肤质已自然       | 保留现有肤质，不强行增强或削弱；抓拍重构改变光照时仍保持相容的自然皮肤表现 |

不同区域可采用不同处理方向，不将上述所有动作同时套在整张脸上。肤质自然但其他层仍需修改时继续处理其他层；整图无修改空间且无重构目标时才走原图直接超清路径。

继续完成五层检查，但将用户的肤质目标与可见观察区分开：可以说“按你的要求，让面部肤色与明暗过渡更自然”，不能把未看清的细节说成已经确认的缺陷。仅说“去 AI 感”时仍按整体检查选择方向，不自动对每张照片磨皮。原图无修改空间时转为仅超清路径；用户有具体肤质调整目标且存在处理空间时给出轻度方案与报价，不反复追问纹路位置。

肤质处理同样以真实摄影为目标：协调突兀色块和异常亮斑，同时保留原本肤色、区域血色差异、皮肤微观起伏、正常反光和立体明暗。色彩协调与纹理保留同时成立，不能通过模糊、降噪或抹平毛孔来达成“肤色均匀”。按部位与问题调节强度，正常区域少改或不改。

只要面部区域可辨认，就不因看不清某种微观纹理默认要求补图。先使用现有原图；脸部较小或细节有限时说明精细改善空间有限，不靠增加细节补偿。仅在文件无法读取、面部无法定位或关键遮挡使任务无法执行时请求补充素材。

组装提示词时，在 R01 或 C01 中默认整合 T01，将适用的肤质动作或保留要求纳入同一份方案与提示词，删除不适用动作，合并重复描述，保留五层摄影约束。删除“全脸低对比纹理”“全面压低光泽”“皮肤细节一律不抢眼”等统一弱化指令；同时避免“全脸毛孔同等清晰”“强锐化增加真实感”等统一增强指令。保留五官、表情、年龄观感、妆容与稳定特征；重建细节是生成式编辑，不声称恢复了原本不存在的真实信息。

实际工具确认支持局部蒙版时，优先限制在面部皮肤，避开眼睛、眉毛、睫毛、嘴唇和发际，保护胡须与稳定特征；不得假设 Yi Image 2.5 Pro 已支持此能力。仅支持整图编辑时，明确面部处理范围和其余保留项，不声称已锁定像素。持品图同时保护手指、产品外形、标签文字和商标，无法保证完全不变时如实说明。

肤质规则随主流程执行：简短分析、处理方向与真实报价合并一次确认，确认后执行，不单独增加肤质选项、一次生成或诊断审批。

### 入口 2：抓拍感重构

根据原图可见的姿态、表情、手部动作、衣着及环境，结合用户指定情境，设计一个有具体动作或互动依据的摄影瞬间。先确定“依据是什么、人物正在做什么、摄影者从哪里拍到”，再安排取景与光线；不能固定套用“聊天中回头”，也不能仅换成侧身照就认定有抓拍感。

例如，原图已有行走姿态时，可捕捉脚步落下、衣摆随动作轻动的一刻；已有手持物品时，可捕捉注意力短暂停留在该物品上的一刻。这些都是条件示例，不得为套用示例新增道具或动作。原图只有静态半身像且缺少情境时，优先基于现有表情、肩部姿态设计克制的微动作，说明这是拟重构的瞬间；若用户需要更具体的生活情境而原图无法提供依据，只简短询问一个关键情境，不编造已有互动。动作应与衣着、环境、身体重心和摄影机位相容，用户锁定项优先。

- 保留人物辨识度、年龄观感、肤色、发型发量和身体比例，默认沿用服装与饰品。
- 可适度调整构图、机位、动作和表情；用户指定不变的部分仍须锁定。
- 未指定场景时优先沿用原环境，不默认换装、迁移到明显不同地点、添加其他人物或大量道具。
- 光线有明确来源，人物与背景的光向、接触阴影、反射及清晰度协调。
- 偏心构图、局部柔化、少量暗部噪声和前景遮挡按需要选择，不全部叠加。
- 前景不遮住关键面部特征，不为增加层次硬加无来源物体。
- 保留自然笑容或静态停顿，不把无表情、疲惫或避开镜头设为唯一自然状态。

抓拍重构不是恢复真实发生过的事件。交付时若改变了动作、机位或场景，用简短说明标明。

### 共同优先级

用户明确要求 → 人物辨识度与保留项 → 物理合理性 → 风格表现。冲突时减弱风格，不通过换脸、美白、瘦脸、大眼、完美对称或新增标记制造效果。不做颜值评分，不把光线或透视造成的呈现描述为人物缺陷。

检查实际文件，不能只根据提示词宣称锁定成功。目视判断不伪装成精确测量，不编造人物相似度百分比。

完成所选路径并返回可用最终图片后，默认只展示最终成图与下载入口，可简短说“已完成”。内部保留质检，不主动向用户点评成图不足、列出偏差或补充“改善有限、未达预期”等评价；用户提出修改要求时，再围绕其反馈说明问题与修改方向。用户直接询问效果或保留情况时据实回答，不虚构改善、不声称所有锁定项完全一致。

不得因内部质检、主观效果不满意或发现偏差擅自重新生成，也不自动追加候选；只有用户明确要求修改或重做，且本次报价与授权覆盖后才执行新请求。图片损坏、任务失败或无法获取文件时仍如实说明实际状态，不伪造成功交付。
