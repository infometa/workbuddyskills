# 活人感照片提示词

以下为业务模板，两个入口均用于 Yi Image 2.5 Pro。实际提交时填写本张图的观察和锁定项，仅纳入已确认的优化方向，删除不适用段落，不提交占位、候选清单或整份设计稿。图片引用和输出参数同步落实到真实接口。R01 与 C01 均默认整合 T01，按原图选用调整或保留动作；用户的肤质要求只决定重点和强度。合并相同约束，删除不适用或相冲突的描述，不把 T01 作为额外一次生成。原图直接超清路径不提交生成提示词。

### R01 AI图活人感修复

```text
以【原图】为唯一编辑目标与人物身份依据，目标是未经重度美颜的真实摄影质感。保留五官比例、年龄观感、原本肤色、妆容、发型发量与【稳定特征】，严格保留表情、目光、姿态、人物位置与大小、原画幅、裁切、顶部留白、场景、服装和饰品。额外锁定：【本次保留项】。

L1 环境光影：沿用【原图可判断的主光方向、软硬程度与环境反射关系】。保持阴影与接触关系连贯。保留鼻梁、颧骨、额头等曲面上与光源一致的反光，明暗随曲面自然衰减；仅对【已确认不合理的光影问题，无则删除】做局部修正，不全脸消光或重新布光。

L2 主体与物理关系：保持原有身体比例、姿态和重心，保留【衣物褶皱、皮肤接触、饰品或持品关系】。不以换脸、改变表情、完美对称或重新取景制造真实感。

L3 材质微观：皮肤呈现随部位、曲面和光照变化的真实细节。按【原图景别与实际问题】保留或克制重建细小毛孔、细绒毛、自然唇纹和已有细纹，鼻部、脸颊、额头的表现不完全一致；细节属于皮肤表面，不像贴图、重复线条或统一噪声。保留原有痣与稳定标记，不新增瑕疵。头发保留原有发型轮廓、发量、发色和发际线，沿生长方向呈现真实纤维与发束层次；允许适量自然飞发、轻微毛躁、疏密变化和局部不规则走向，不要求根根顺滑或整齐排列。高光随发束朝向变化，避免整片光滑、油亮或塑料般反射；已有自然散丝保留，不强行蓬乱、干枯或增加噪点；【实际衣料】呈现对应的织纹、纤维或沿褶皱变化的反射；【实际金属、玻璃等】保留各自反光特征与结构，不能和皮肤一样柔滑。只调整本次已确认的材质问题，不强制所有细节同等清楚。

L4 光学成像：沿用原图【景别、透视与人物占比】，保持【可观察的焦平面和景深关系】。对焦区域有自然解析力，离焦与暗部细节逐渐减弱，皮肤不能因磨皮而比同焦平面的眉毛、嘴唇异常光滑。保留自然边缘，不全图锐化、假虚化、统一加颗粒或添加无依据的镜头缺陷。

L5 色彩与影调：保持原本肤色与【场景白平衡、环境色关系】。协调突兀的色块或斑驳，同时保留合理的血色、区域色彩差异和环境反射。肤色协调不等于全脸同色；皮肤、头发、衣料与背景保持不同的色调和明暗层次，不套重度滤镜。

本次主要改善：【五层诊断得到并已确认的重点】。真实皮肤起伏、合理反光与材质差异优先于柔滑精修；禁止蜡质磨皮、瓷质皮肤、全脸同色、过度降噪、夸张毛孔、浮在表面的斑点和重复纹理。身份与构图优先，冲突时减弱处理。输出一张完整独立照片，不添加文字、水印或拼图。
```

### C01 抓拍感重构

```text
以【原图】确定唯一人物身份，保留其五官特点、脸型、年龄观感、肤色、发型发量、身体比例和【稳定标记】。沿用【服装与饰品】，严格保留用户指定的【锁定项】。其他参考图仅用于【已明确的参考职责】，不复制其中人物身份。

设计依据：【原图可见的姿态、表情、动作或环境线索，以及用户明确指定的情境】。画面呈现【据此设计的一个具体动作或互动瞬间】，人物正在【具体行为】，动作与【沿用或用户指定的场景】一致。仅采用已确认的变化幅度，不默认添加回头、交谈或侧身动作。摄影者处于【观察位置与高度】，采用【景别与自然透视观感】，以【具体取景方式】呈现人物。空间层次通过【必要的实际场景关系】形成，不添加无来源遮挡或道具。

以真实摄影为目标，不做柔滑精修。使用【一个主导光线及方向】，人物、服装与环境的阴影和反射一致；色彩采用【与场景一致的克制色彩】。保留按部位和光照变化的肤质、合理的皮肤反光、唇纹、发丝，以及与皮肤不同的衣料反射；不将肤色协调处理成表面光滑。头发保留原有发型、发量、发色、发际线与卷曲程度，允许适量自然飞发、轻微毛躁与不规则发束，呈现真实纤维感和轻微凌乱感；反光随发束走向变化，避免过度柔顺、整齐梳理或整片光滑亮面。不强行制造蓬乱与干枯，仅在已确认动作或环境支持时呈现相应的轻微动态。成像表现为【零至少量合理的柔化或暗部噪声】，全图清晰度协调。

不重新设计五官，不改变未授权的服饰或场景，不靠重度滤镜、脏污或衰老制造真实感。风格与身份冲突时优先保留人物。输出一张独立照片，不添加文字、水印或拼图版式。
```

### T01 面部肤质自然化共用规则（两个入口默认整合）

```text
依据原图肤质状态与本次确认的光照、场景关系，执行【适用的肤质调整或保留要求】；用户特别指定的重点为【有则填写，无则删除】。目标是肤色协调、细节真实的摄影皮肤，不是柔滑精修。肤质自然的区域保留，不强行增加或削弱细节；用户明确锁定皮肤时服从锁定要求。

协调面部突兀的红、黄、灰色块与斑驳，让肤色过渡连贯；保持原本肤色深浅、自然血色和不同部位的合理差异。不美白、不全脸同色，不通过模糊或抹除细节实现肤色均匀。

保留由光源和曲面形成的正常皮肤反光、细微高光及立体阴影。仅减弱孤立突兀、失真或淹没肤质细节的亮斑，使其与周围反射衔接；不预设所有额头、鼻尖和颧骨高光都需要压低，不把全脸处理成哑光。

保留随部位、光线与焦平面变化的细小毛孔、细绒毛、唇纹与正常褶皱。清晰区域应有自然的皮肤起伏，远景、暗部和离焦处不过度强化；不统一压低全脸细节对比。若局部纹理过强或重复，仅修正该处；若局部呈蜡质平面，可克制重建符合景别的微观起伏，不声称精确恢复原始细节。禁止全脸磨平、强降噪、强锐化、颗粒覆盖、重复盘绕线条和新增瑕疵。

保留五官、表情、目光、年龄观感、妆容、胡须、痣、疤与稳定特征。只调整已确认肤质范围，不改变【实际存在的手部、产品外形与标签、饰品、衣物、背景等保护对象】。姿态和取景只采用本次已确认方案。肤色协调、合理反光与真实纹理必须同时成立，不以光滑无瑕作为完成标准。
```

此模块不需要填写特定纹路名称或异常坐标。保护对象按原图填写，不添加不存在的产品或饰品；已有细节有限时不要求模型凭空补出皮肤信息。

模板中的相机语言描述目标观感，不冒充原图 EXIF 或实际拍摄数据。不同照片按实际问题编写，不将试用图的黑发、耳环、项链或单肩服装固化为默认人物。
