# 主播形象画面模板

新建或修改画面时读取；身份、服装、费用与重做边界遵循 Skill 正文。按人物来源及坐姿／站姿选择适用分支，最终只提交清理后的确定提示词。

## 提示词组装

1. **确定开头**：新人物从风格库取得一套明确方案，把整体画幅下可见的 2–3 个主特征放在最前；首次将上传人像制作成主播图时，按下方取景规则先写画面构图，再简述身份保留，不逐项重写五官。不要把全部候选项或内部编号交给生图模型。
2. **画面段**：选择 T01 或 T02，填入最终服装、一个手势和一套场景。模板中的肤质与光线段只使用一次，不从风格库重复叠加。
3. **清理与提交**：替换全部占位符，删去未选分支及内部处理说明，检查人物、姿态、服装与构图是否矛盾。商品图优先转成场景风格文字，不作为商品复现参考提交。

坐姿手势从双手并排、轻轻交叠、松弛轻握、指尖轻触中选一种；允许自然遮挡，要求可见手指解剖正确，不强求所有手指同时展示。默认不指点、挥手、握拳或把手靠近脸。修改已有图时保留未要求改变的手势。

直播间通过空间配色、墙面、柜体材质和照明表达品类，例如美妆的柔和精致、数码的利落简洁、运动的清爽活力；不以商品、包装、商品海报或促销文字表达品类，不固定每个品类只能采用一种风格。

### 上传人物图的取景规则

首次将指定身份人像制作成绿幕图或直播间图时，将实际人物图与最终提示词一起提交。使用“画面类型与构图 → 简短身份保留 → 服装、肤质、姿态、场景与成像”的顺序。参考图用于身份、发型和服装，取景与人物大小由本次构图指定，不逐项重写眉眼、鼻形和唇形。仅作造型风格参考时使用新人物开头，明确该图只借鉴造型、不保留原身份，不套用本节“同一人物”的身份段；新人物仍采用对应模板的统一构图。

标准坐姿使用以下开头，替换 T01 或 T02 的人物开头及完整“构图与桌面”段，不能在后文重复追加原构图段。填写本次输出类型与保留特征，示例中的手势可替换为本次选定的一种手势：

```text
生成一张宽松取景的【品类】直播间环境人像，固定 9:16 竖屏。主播自然坐在桌后，人物以较小比例出现在完整空间中，画面两侧保留宽裕背景。镜头接近人物眼睛高度，透视自然。

构图目标：
以画面顶部为 0%、底部为 100%，头顶位于高度约 28%，下巴位于约 47%；头顶至下巴的完整头部高度约占画面高度的 19%。
人物水平居中，包含头发、肩部和双臂的主体最外缘位于画面宽度约 18%–82%之间，左右各保留约 18%的背景空间。
桌面上边界位于画面高度约 84%，横向铺满并延伸至底边。完整呈现头部、肩部、桌面以上躯干、前臂、手腕和双手，下半身由桌子遮挡。双手靠近桌面上边界且完整落在可见桌面内，下方留出适量桌面。桌面干净无物，颜色与材质按场景确定。

上传照片用于确定同一人物的身份、发型和服装。保留参考人物的五官比例、肤色与年龄感，以及【原发型和服装的简短描述】；拍摄距离、人物大小、姿态和背景按本次构图重新安排。

通过扩大取景使整个人物等比例缩小，保持自然头身比例，合理补全参考图未展示的身体。双肘自然收拢，双手轻叠在桌面上。不要沿用参考照片的近景裁切，不要仅在原照片上方增加空白，也不要单独缩头或收窄肩膀。
```

后续服装段仅补充必要细节；姿态段沿用开头选定的手势，不另选第二种。

上传人物图制作标准坐姿时，将所选模板“姿态与手势”段开头的“自然端坐，身体正对镜头，肩颈放松”替换为以下限定，只使用一次，后接原有前臂落桌与手势要求：

> 参考图仅用于保留人物身份与造型，不继承原动作。人物正面端坐，头部竖直、下巴自然平收，双眼连线与肩线基本水平，躯干端正朝向镜头；不歪头、不侧身、不耸肩，肩颈保持自然放松。

站姿将“正面端坐”改为“正面自然站立”，手臂按站姿要求处理。用户明确指定姿态或要求保留已有成图姿态时遵循其要求，不擅自归正。

绿幕版将首句改为“生成一张宽松取景的单人写实绿幕主播图”，桌面明确为哑光白色，并接入 T01 的纯绿背景及成像要求。两版共用上述坐姿构图目标。

站姿不使用以上坐姿开头中的头部高度、桌面或坐姿坐标，改用下方站姿规则，并保持构图前置、身份说明简短。用户要求保持已有成图构图时，不套用首次取景规则。

上述比例与原创人物模板统一，仅通过提示词表达，不要求上传额外的构图参考图，也不在最终提示词中写“参照图三”。指定人物照片仍须与提示词一起提交，用于保留身份与造型。构图数值为待验证目标，不代表模型能够精确执行。检查时同时核对头部大小、人物外缘宽度、头顶与桌面位置；仅增加顶部空白或换背景不算完成缩小取景。不自动付费测试或重做，仍遵循真实费用与重做授权规则。

### 站姿替换规则

用户要求站姿时，用自然站姿与确定的空手手势替换模板坐姿段，移除桌面及所有坐姿坐标。全身从头顶至脚底占画面高度约 70%–75%，完整保留双脚与适量地面留白；通过取景控制人物大小，不改变人体比例。仍固定 9:16、2K；绿幕保留纯绿背景，直播间保留对应空间风格。

以下两份为标准坐姿基础模板，实际生成只使用其中一份。创建新人物时按模板组装；首次使用上传人物图时，必须按上方取景规则替换开头与构图段，并按上传人物图规则替换姿态开头，共用要求不重复叠加。

### T01 绿幕主播图通用提示词

```text
【本次确定的人物描述，主特征在前。】
生成该人物的单人写实绿幕主播图。保留已确定的脸型、五官比例、肤色、年龄感及自然不对称，目光直视镜头，表情遵循人物设定。

服装：【最终款式、颜色、材质及领型。】
【按本次服装来源填入需要保留的标志或图案；无此要求时删除本占位。】保留面料纹理与自然褶皱。

肤质与人物光线：
皮肤有区域性的细微纹理：鼻翼和鼻侧毛孔略可见，面颊纹理更细，眼下保留轻微细纹，嘴唇有自然唇纹。鼻翼、面颊与耳部有细微血色色差，面部、颈部和双手肤色协调。纹理按当前景别与分辨率呈现，不放大毛孔或叠加颗粒噪点。
皮肤以柔和漫反射为主，额头和鼻梁有小范围受控高光。略偏镜头一侧的大面积柔光主光搭配正面弱补光，鼻侧、面颊和下颌有柔和明暗过渡，暗部保留细节。妆容轻薄，保留原生肤质，避免磨皮蜡感及全脸油亮。

姿态与手势：
自然端坐，身体正对镜头，肩颈放松，双侧前臂落在桌面上。【仅写本次选定的一种空手手势。】
双手和手腕完整可见，可见手指及关节结构正确，允许自然遮挡。手臂与桌面接触关系真实，双手不持物。

构图与桌面：
固定 9:16 竖屏，采用宽松取景的坐姿直播画面，人物水平居中，镜头与眼睛基本等高，透视自然。
以画面顶部为 0%、底部为 100%：头顶位于高度约 28%，下巴位于约 47%，完整头部高度约占画面高度的 19%。包含头发、肩部和双臂的主体最外缘位于画面宽度约 18%–82%之间，左右各保留约 18%的背景空间。
桌面上边界位于画面高度约 84%，横向铺满并延伸至底边。桌面为哑光白色，干净无物，仅保留前臂与双手的轻微接触阴影。
完整呈现头部、肩部、桌面以上躯干、前臂、手腕和双手，下半身由桌子遮挡。双肘自然收拢，双手空手、轻松放在桌面上，靠近桌面上边界且完整落在可见桌面内，下方保留充足桌面。
通过扩大取景使人物整体按自然比例缩小，不单独缩头、收窄肩膀或拉长躯干，面部、双手与主要识别特征仍须清晰。

绿幕与成像：
背景独立均匀照明，纯绿目标色值 RGB（32, 244, 32）、HEX #20F420，无纹理、渐变、褶皱、背景阴影或物体。人物、头发、服装和桌面无绿色溢色，边缘自然。
呈现自然人像摄影质感，面部、发丝、衣物和双手有清晰但不过度锐化的细节，浅色衣物与桌面保留高光层次。
输出 1 张 2K 图片，实际像素以工具输出为准。画面只含一位主播，不生成字幕、直播界面、水印或装饰边框。
```
