# UGC 创意与内置提示词

更新：2026-09-28｜本轮优化口播信息量、声画同步与时长匹配。

新建或修改创意时先读取本文件，再根据真实素材写出最终 prompt。模板和例子用于组织创意，不能原样套入未提供的商品事实；最终提交前替换所有方括号槽位，并使时长、画幅、声音与渠道参数一致。纯查询原任务不需要重写提示词。

## 从素材形成创意

1. 先识别商品及用途，区分图片可见信息、用户明确提供的信息与未知信息。卖点文案选填，不要求用户先写好；用途明确且用户说“你看着做”时，用可见外观和基础使用演示。功能或操作不明时只补齐必要信息，不从外观推断续航、静音、认证等性能。
2. 选择一个与商品用途匹配的生活场景，把有依据的展示重点转成可看见的操作和细节。用自然光、手机拍摄感、自然表情与手部动作表达生活化 UGC，避免只有静物展示或全程念卖点。场景和虚拟人物是创意设定，不能据此编造商品事实或真实使用经历。
3. 先确定一个明确的观看理由、一个核心卖点和一次主要产品互动，再按下方规则写口播、配镜头。开头直接进入问题或演示，中段补充具体信息，结尾完成明确推荐。2–5秒短片只保留一个信息点和一个动作，不强塞三段结构。镜头切换服务于信息变化，不为快而快；时间段覆盖全片且不重叠越界。
4. 默认中文口播，表达自然但信息完整，每句承担新的信息任务。沿用用户指定语言、台词和声音要求；区分必须原样保留与允许润色，未明确且需要改动时再问。先完成有依据的口播，再按实际音频时长或自然朗读估算推荐2–30秒；待用户确认或自行指定后使用。按下方规则压缩空白，不靠加速口播强塞内容；30秒仍放不下时让用户选择精简或拆条，不擅自删词或增加条数。
5. 明确口播、环境音与背景音乐。默认人声清楚、轻微自然环境音，不主动添加背景音乐、字幕、价格或促销花字；用户指定时按要求安排。“无人声”不等于完全无声；完全静音时提示词写无任何声音，并令声音参数关闭。口播/画外音必需时不能关闭声音参数，要求冲突先澄清。

## 口播规则：每句话都有作用

将口播组织成三个连续的信息任务：

1. **观看理由**：第一句直接说具体问题、场景需求或值得注意的外观细节。避免“大家好”“今天给大家介绍”以及先念品牌名的铺垫。
2. **核心卖点与演示**：选择一个最重要、有依据的卖点，用具体动作或细节讲清楚为什么值得关注。台词不能只报“好看、方便、好用”，也不要逐字复述画面中的拿起、放下；让画面展示操作，口播补充特点、选择理由或使用场景。
3. **明确推荐**：给出具体搭配、使用或查看建议，如“通勤包里可以留个位置”“日常白T就这样搭”。不要只剩“你觉得呢”或数秒微笑摆拍；购买引导、价格与优惠必须有用户提供的依据。

短句、自然语气不等于少写内容。保留必要换气与语义停顿，避免每句话后都留空拍。信息不足时围绕可见外观、已确认操作与适用场景组织表达，不用空泛夸赞或虚构功效凑字。

**口播长度参考**：约12秒中文口播可先按55—60字估算，可作为检查信息量的起点，不是硬性配额，也不是 Wan 的语速保证。字数按实际说出的内容估算，数字、英文与停顿需单独考虑；其他语言不能套中文标准。最终以所选声音的实际时长为准，未取得音频时明确标注为估算。

## 时长与镜头：贴近口播，减少空白

- **先口播，后定时长**：已有最终口播音频时，以实际时长为依据；没有音频时，按自然语速、换气和停顿估算，不将字数换算称为实测。无需为了估时额外生成付费配音。
- **选择贴近的可用时长**：在当前支持的2–30秒范围内，选择能容纳完整口播和必要动作的最短可用时长。通常只留约0.5—1秒自然收尾余量，不额外安排数秒无信息定格；余量是设计建议，需按内容调整。
- **声画同时推进**：将每段台词与对应画面写在一起。说到特点时展示对应细节；说到场景时完成相应使用动作。不要先等动作做完才开口，也不在每次切镜后重新停顿。涂唇、试吃等不便开口的动作可用同一声音画外讲解。
- **不拖长简单动作**：拿起、转头、放入包中只占实际需要的时间，不默认拉长成数秒展示。一个场景和一次主要互动也能完成有推进的口播，不强制增加镜头数量。
- **动作确实需要时间**：保留必要操作长度，用相关讲解同时覆盖；不能压缩的无口播操作段需说明用途，不能用无关台词填空。
- **用户指定时长优先**：在指定时长内组织有效信息；内容明显不足时提出缩短建议，不悄悄改时长。内容较多时可建议延长至最多30秒；仍不够时让用户选择精简或拆条，必须原样保留的内容不得擅自改动。
- **无口播或静音**：按实际演示动作决定时长，不套口播字数或声音时长规则。

## 素材分支与澄清

| 情况 | 如何处理 |
| --- | --- |
| 有人物图 | 按实际图片编号引用人物，保持面部特征、发型、整体形象及跨镜头一致性，不编写与图片冲突的外貌。多张人物图或合照的出镜对象不明确时先定位，不混合不同人的脸。 |
| 无人物图 | 只引用商品图，在方案中说明拟定虚拟人物的年龄段、外观、服装与状态，全片一致。不能写“参考人物图”，也不保证不同任务是同一人物。默认不强调毛孔、皮肤瑕疵或保留自然皮肤纹理；用户要求时再补充。 |
| 不露脸 | 使用手部或第一视角演示，不描述面部、安排露脸镜头。默认中文口播改为画外讲解；用户明确不要口播时去掉人声。不因为不露脸而强制索要人物图。 |
| 只有人物图 | 补充商品图，人物图不能替代商品素材。 |
| 多件商品 / 多款式 | 先确认主推对象，以及同片展示或分别制作，不混款、混用卖点。 |
| 商品图含模特 / 促销字 / 背景 | 默认只参考商品。沿用图中模特需用户明确选择，促销文案不能直接当已确认事实，背景不自动照搬。 |
| 人物图只有面部但需要全身 | 说明服装、身体与图外部分由模型补全；有特殊要求再补图或描述。 |
| 商品描述与图冲突 / 试用动作不明 | 指出具体矛盾并确认真实用途或操作；不能演示时可建议手持介绍，不编造使用方式。 |

参考图按全部商品图在前、人物图在后排列。提示词使用与实际列表一致的“图1、图2……”标识，并逐张说明用途；有多张商品图时，人物图编号顺延，不固定写成图2。

> [用户指定的字幕/文字要求；未指定则不添加字幕、价格或促销文字]。避免商品变形、手指穿模、不合理操作与夸张效果；不加入未经提供的性能、优惠或真实试用经历。

## 提交前展示与修改

一次展示简短创意、逐张图片用途、完整最终提示词、用户选择的时长、口播全文及实际或估算时长、规格与声音、当前渠道报价。说明推荐的视频时长如何覆盖口播与必要动作，不把估时写成实测。完整提示词须同时包含所有适用模板内容，不能只展示“按 UGC 风格生成”或让用户自行填模板。提交前检查：第一句是否有观看理由；中段是否讲清一个核心卖点；结尾是否有具体推荐；台词与动作是否同步；是否存在口播结束后无信息的长尾。再核对时间段、图片编号和事实依据，不把模板槽位或示例专属卖点提交给模型。

用户可修改方案后生成；已有授权且预算覆盖、时长已明确时沿用渠道规则，不额外增加逐步确认。重新制作时沿用已知素材和设置，只修改用户提出的部分，说明本次变化与新增费用。仅说“换个版本”而修改方向不明时，再问是按原方案重做还是换开头、场景或台词。生成完成后交付视频及实际规格，不要求宿主观看或检查成片内容，也不自动付费重做。
