# 极简插画提示词

新建前完整使用T02；只有用户要求修改且对应模型费用已确认后才使用M01／M02。原照片始终是内容依据，当前插画仅作为修改对象。

## T02 实际插画生成模板

调用设置：选择 Yi Image 2.5 Pro，分辨率设为 2K。模型比例参数必须使用布局计算所得的受支持面板比例，并与下方提示词一致。模型和分辨率通过实际工具参数设置，画风、内容和布局通过下方提示词控制。

提交前替换全部方括号字段，只保留本次确定内容。主体事实精简填写：每人通常一句，只写位置、主要动作、发型和服装主色；多人分别覆盖，不能为缩短提示词漏人。道具仅保留影响动作理解或数量关系的对象；背景选择零至两组必要线索，无必要则不添加。不要把完整视觉分析逐项堆入提示词，也不要追加“丰富细节”“精致人物”“清晰呈现全部配饰”等冲突要求。

以下 T02 作为完整首轮提示词使用，布局段固定置顶，不用一句“主体小一点”代替；不要在末尾另接一套写实描绘要求。原照片只提供内容，不能提供主体占画面的比例。画风和布局由文字控制，不增加风格素材。

```text
【先排版：大纸面中的小幅插画】
生成一张[插画面板宽高比]的温暖米白纸面，中央放置一组小型平面剪纸插画。
这是有充足页边留白的完整纸页；不要将插画主体放大来填满画布。
画布比例指整张纸面，不是内部插画组的形状。

先留出四周连续纸面，再安排内容。完整插画组以纸面宽、高各40%–45%为目标，
任一方向不要超过50%；保持人物与物体的自然比例，较窄方向可以更小，不拉宽或拉高凑数。
整组中心约在纸面横向50%、纵向46%，上方至少约21%、左右各至少约25%的纸面连续留空。
这些边界不可见，不得画框、画底板或沿边界裁切主体。
人物、宠物、背景、道具、地面、植物和所有延伸线条都计入同一组，不能只缩小人物却保留巨大的背景。
人物与宠物或多人组成密实色块时，整组尺度优先靠近40%，不要因内容多而放大。
英文小字另放下方留白。画面边缘不接触人物、背景或道具，不以组内缝隙替代四周留白。

【原照片只决定内容，不决定占比】
[原照片标签]是唯一内容来源。重新安排这张纸页上的主体尺度，
不要继承原照片的近景构图、人物占比、满幅背景或延伸到照片边缘的线条。
保留人数、姿态、相对位置、前后遮挡和关键接触关系。
多人作为一组整体缩放，不挤压间距；近景和局部照片保留可见范围，不补画未出现的身体。
原本被画面截断的衣物或前臂在小型插画组内部自然收住，边缘轻微干刷，不延伸到纸页边缘。

【本次内容，仅保留识别要点】
主体：[人数及逐人简短描述；无人物时描述主要物件、数量和关系]。
关键动作与连接：[必须保留的手势、遮挡、支点或握持关系]。
必要道具：[必要形状、数量与主色；无则省略]。
环境：[零至两组来自原照片的简洁色块线索；无则直接留白]。

【固定画风：平面剪纸与轻微印刷感】
人物以自然外轮廓和连贯平涂色块表现，保留动作、发型、服装轮廓与主色。
面部省略全部五官，皮肤均匀平涂；不画眼鼻口、肌肉、关节明暗、高光或渐变。
衣服使用主色块，仅以必要分区区分领口、叠层和遮挡，不画褶皱、缝线或材质塑形。
头发为整体剪影，手脚概括且自然，道具只保留用途与连接，不逐个精绘小配件。
物体用轮廓和少量色形表达，不画镜面反射、精细表面纹理或写实体积。
辅助色块用于区分对象，不用于塑造光照。辨识性图案只保留少量色形，不编造文字。
保留原图主色关系，适当降饱和但不统一灰化、不漂白肤色。
色块带细微油墨不均、局部漏印和柔和干刷边缘，纸纹细腻轻微，不做浮雕或满幅噪点。
不要写实人物缩小版、照片滤镜、精细水粉塑形、光滑矢量或粗黑描边。

【背景与细节服从尺度】
环境仅用少量连贯色块交代，不重建完整场景，不逐一画树叶、砖石或纹理。
外轮廓错落、局部开放，纸面可穿入；不形成方形、圆形、椭圆或拱形底板。
不添加无来源装饰或飞溅。所有背景及线条在整组边界内自然收住。
内容多时先删除非必要背景、图案和微细节，不扩大整组，不删主要人物或关键物品。
动作可辨依靠轮廓与色彩对比，不依靠放大人物或恢复写实细节。

【小字】
在纸面下方约84%高度的留白中，以小巧纤细的褐灰衬线体排一至两行：
[最终英文文案，通常6–14词]。
文字像画册注释，不抢镜，不加标题、日期、编号、签名或其他文字。
用户要求无字时，此段替换为“无任何文字”，不保留冲突文案。

【完成前检查】
先检查整组宽、高各以40%–45%为目标、任一方向不超过50%，四周有连续空白，再检查人数、物品数量、动作和文字。
在本次输出中使背景和人物服从规定的小型整组尺度，不扩大画布中的插画占位。
保持自然动作与平面色块。只输出一张完整插画面板，不生成照片或上下对照图。
```

以上百分比是生成指导，不能代替实际看图核验，也不承诺一次必定成功。首轮按本模板完整提交，不预设“先生成大图、再调用一次缩小”的两轮流程。成功返回图片后即进入拼接展示；即使主体比例未达标，也不阻断拼接、不擅自调整插画或二次生成，不宣称未达标项通过。用户提出修改后才进入修改流程，任何再次调用 Yi Image 2.5 Pro 的行为均先取得对应报价并确认。无可用图片时如实说明失败，不自动重新提交模型请求。

## 文案生成规则

执行助手先根据当前照片的动作、空间和人物互动写出一句英文，再将确定文案放进 T02。选择照片中可见的具体线索，表达轻柔、自然的感受；不虚构人物经历、地点或关系，不使用空泛口号。不同照片各自组织文案，不使用固定句式批量套用，不把候选列表交给图片模型选择。

用户提供文字时优先逐字采用；指定中文、无字或仅插画时，同步替换相关段落，不能保留冲突的英文默认要求。

## 修改前的报价与任务延续

仅在用户提出修改后启动本节流程。首轮可用图片先拼接展示，模型输出检查不授权额外调用；下方 M01、M02 不得作为自动质检后的重生成步骤。

用户说“去掉文字”“人物再简化一点”等时，沿用已有照片、目标版本、比例与其他要求，只识别本轮改动；不重新走首次比例选择。目标不明确时仅询问修改哪张。

先判断修改是否需要调用 Yi Image 2.5 Pro。需要调用时，取得本轮真实报价，展示修改内容、涉及数量、总价及计价单位，等待确认后调用下方修改模板；不向用户展示模型名称和分辨率。需要模型的重做与首轮修正同样先报价确认，真实零费用也明确展示并确认；无法取得报价时不调用模型。

不调用模型的裁剪、等比缩放、拼接、导出或独立文字层修改直接执行，不报价、不要求费用确认。去除已融入图片的文字若需调用模型，仍须先报价确认；不能仅凭修改名称判断。执行中发现必须调用模型时，在调用前取得报价并确认。只修改约定范围，保留旧版，同时更新对照图与独立插画下载；仅插画任务只更新插画。

## M01 只增加留白

```text
仅调整当前插画面板的主体尺度与留白，保持已确认画风。
把人物、背景、地面及所有延伸线条作为一个整体等比缩小，
将完整组宽、高控制在面板的40%–45%，任一方向不超过50%；保持自然比例，较窄方向可以更小，四周留出连续纸面。
先减少过大的背景，不改变人物动作、服装、相互位置或肢体比例。
不要为了留白继续将人物简化为几何符号。
英文保留原文，安静地放在下方或侧方空白中。
只输出修改后的独立插画面板。
```

## M02 画风恢复

```text
将当前插画调整为温暖克制的平面剪纸色块与轻微手工印刷画风。
保留自然动作、发型与穿搭轮廓，删除人物内部的写实细节。
默认省略全部五官，皮肤为均匀肤色色块，无高光、渐变或肌肉明暗。
衣服使用连贯主色块，只保留辨识必需的领口、分区与遮挡，不画褶皱、缝线或阴影。
头发为简洁剪影，手脚只保留动作轮廓，道具只保留必要形状与连接。
人物与背景采用统一、轻微的油墨不均和细腻纸纹，不形成浮雕材质。
保持已达标的主体尺度和留白；若超出面板任一方向50%的上限，将整组调整至40%–45%目标范围，不改变成品比例或上方照片。
只输出独立插画面板，照片由程序重新拼接。
```

## 提交与版本记录

制作时保留最终实际提示词和原照片路径，记录实际调用模型、分辨率档位与输出像素、面板宽高比、成品尺寸、裁剪坐标、文案及结果版本，以支持本次任务修改。只调整拼接尺寸时，不额外改写固定画风段。版本信息属于任务执行数据，不加入用户可见的画面或默认交付文案。
