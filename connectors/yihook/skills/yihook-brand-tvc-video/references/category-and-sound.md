# 品类创意与声音匹配库

按当前品类查阅对应行。通用创作方法、人物规则、事实边界与质量检查统一遵循当前 Skill 正文中的素材、创作与检查规则；本库只补充品类差异。以下内容是创作候选，不是固定模板或产品功能事实。

## 1. 品类创意与操作参考

| 品类           | 创意切入点                         | 可尝试的事件／机制                         | 品类专属提醒                                                             |
| -------------- | ---------------------------------- | ------------------------------------------ | ------------------------------------------------------------------------ |
| 香水香氛       | 私人仪式、气质、想象、瓶身视觉资产 | 人物探索、生活向往、超现实空间、感官转译   | 不从包装或场景联想推断香调、留香；喷雾前确认瓶盖与喷头状态               |
| 运动相机／数码 | 行动、记录、共同经历               | 都市出行、真实运动小故事、朋友视角接力     | 防水、防抖等演示需有依据；镜头朝被摄对象，不虚构配件                     |
| 饮料食品       | 味觉联想、清凉、分享               | 开罐声音组织剪辑、自然社交、明确的幻想段落 | 不猜零糖零卡；开罐后保持开启，倒液时跟踪液面与杯子数量                   |
| 唇蜜美妆       | 色彩、水光、自我表达               | 人物主动改变拍摄、光线关联、色彩空间       | 唇色是参考表达，不演示即时修复／丰唇；刷杆与刷盖连接，刷头接触唇面不穿模 |
| 家居清洁       | 布置、整理与维护空间，获得舒适生活 | 阅读角整理、新家布置、自然生活切片         | 吸头经过后才清理；不吸未知液体或大件物品，不让无支撑的机器自动站立       |

## 2. 声音匹配参考

节奏数值是候选表达，不限制其他合理编排；具体选择遵循主文档的声音规则。

| 创意情绪／常见品类             | 音乐与乐器候选                                | 节奏参考  | 存在感与关键变化                                                         |
| ------------------------------ | --------------------------------------------- | --------- | ------------------------------------------------------------------------ |
| 克制情绪／香水、珠宝           | 氛围电子、极简器乐或爵士质感；钢琴、弦乐泛音  | 约90 BPM  | 留出空间；关键揭示时声场展开，情绪段抬升，结尾短收束                     |
| 行动与出行／运动相机、潮流数码 | 动感电子、轻盈Breakbeat、电子摇滚；温暖合成器 | 约105 BPM | 旋律与鼓点明确，准备动作和转场可踩点，进入开阔场景时展开                 |
| 轻松社交／饮料、零食           | Nu-disco、放克流行、明快电子                  | 约118 BPM | 抓耳旋律、弹跳贝斯、清晰鼓点；开罐建立节奏，分享时高潮，产品段不提前拖慢 |
| 自我表达／美妆、时装           | 俏皮放克、时尚流行电子                        | 约116 BPM | 鲜明短旋律与轻巧节奏；转折时短暂停顿，随人物主动行动重新推进             |
| 温暖日常／家居清洁             | 器乐流行；吉他、键盘、轻巧鼓点                | 约102 BPM | 轻快清晰；清洁时音乐为工作声让位，任务完成后舒展                         |
