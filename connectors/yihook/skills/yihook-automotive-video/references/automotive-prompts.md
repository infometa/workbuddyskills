# 汽车创意与场景模板

### 通用约束

- **素材与车辆**：逐张写清车辆外观、内饰或人物用途；每辆车分别与对应素材一致，不混车型、配置、颜色、轮毂或可辨认车牌，不自行改造或补造细节。单车型任务才要求“全片同一辆车”；多车型任务逐车列出对应图片与镜头，不增加无关车辆。
- **事实依据**：仅使用可见或用户明确提供的事实，不虚构配置、性能、优惠、政策、客户证言或代言关系。未提供的内饰与功能不直接展示；需要时补素材或提出替代镜头。
- **目标与替代方案**：先判断现有资料能否完成用户核心目标。缺少性能依据时说明具体缺项；如提出外观或氛围方向，须在完整方案中明确标为“替代方案”，写清保留与未实现的目标，纳入统一确认，不将氛围展示算作性能展示完成。用户未接受替代且原目标缺乏依据时，继续补资料，不擅自弱化目标。
- **参考角度覆盖**：编写分镜前逐张识别图片支持的车辆角度与细节，镜头优先在已有参考覆盖范围内安排。仅有正面图时不直接安排侧后方环绕或车尾特写；只有核心目标必须展示缺失角度时才请用户补图，其余用已有角度调整镜头。
- **画面与文字**：动作、轮胎接地与空间关系合理，主体清晰；CG 默认用于环境。未要求时不新增字幕、标题、价格花字、品牌浮层或二维码；用户明确要求文字时列入方案并核对实现方式。

通用规则适用于全部模板，最终提示词须展开适用内容，不能只写“遵守通用规则”。

### 内置模板选择规则

先识别营销目标，再选一个主模板；节日、地域、人物和视觉风格作为附加元素，不将多个模板机械拼接。比如“国庆门店直播讲权益”选择门店引流模板，再添加国庆氛围。车型名称不作为性能依据，也不固定绑定某个品牌。

| 用户表达或目标 | 主模板 | 可扩展方向 |
|---|---|---|
| 主播、销售、直播、到店、预约、权益 | T01 门店口播引流 | 车旁口播、权益说明、看车接待、交车仪式、直播预热 |
| 省油、混动、四驱、空间、安全、配置 | T02 车型卖点讲解 | 通勤、装载、舒适乘坐、外放电、功能演示 |
| 皮卡、拉货、建材、农资、工地、集市 | T03 商用皮卡干活 | 建材送货、农资运输、工具运输、摆摊、家商两用 |
| 自驾、露营、越野、山路、泥路、雪地 | T04 越野与户外旅行 | 周末露营、山顶日出、海边公路、有依据的通过性展示 |
| 老乡、县城、下乡、补贴、以旧换新 | T05 本地化区域营销 | 本地门店、乡镇集市、区域活动、亲切口吻 |
| 七夕、中秋、国庆、购车节、春节 | T06 节日节点营销 | 双人出行、返乡团圆、假期自驾、节日邀约 |
| 足球、球场、观赛、奖杯、运动氛围 | T07 赛事热点 | 门店观赛、球迷聚会、运动风介绍、胜利氛围 |
| 科幻、机甲、赛博、CG、车型家族 | T08 科技 CG 品牌片 | 未来城市、发布平台、环境机械装置、多车型亮相 |
| 亲子、家庭、老人、孩子、送车惊喜 | T09 家庭温情用车 | 家庭出游、陪伴父母、亲子露营、惊喜交车 |
| 穿越、古今、平行宇宙、变装、反转 | T10 剧情创意 | 古今反差、生活场景切换、轻喜剧、反套路销售 |

只提供车辆图、没有其他要求时，采用 T02 的外观展示分支，不强行补出性能卖点。明确要无口播氛围片时，按场景选模板并去掉口播。节日按用户指定节点使用，不沿用参考资料中的固定年份或历史排期。

### 卖点转画面的内置规则

按“已确认卖点 → 用户需求 → 生活场景 → 可呈现的画面 → 自然口播”组织内容。下表是创作路径，不是对任意车辆的默认性能描述。

| 已确认信息 | 可用画面方向 | 需要避免 |
|---|---|---|
| 油耗或用车成本资料 | 通勤、返乡，口播准确表达已有资料 | 没有对比依据就声称一周少加几次油、节省具体金额 |
| 四驱或通过性资料 | 与已知能力相符的路况、低速行驶及车身姿态 | 把四驱等同于任意陡坡、深水或冰面的通行保证 |
| 空间及装载资料、对应内饰图 | 家人上车、适量行李或装备放入实际空间 | 放大车厢、虚构座位数量、无限装载 |
| 外放电资料及操作参考 | 停车后按实际方式连接适配设备 | 编造接口、操作或供电功率 |
| 舒适配置与内饰图 | 静态体验、真实座椅与乘坐动作 | 无依据地承诺长途不累或绝对静音 |
| 驾驶辅助或安全配置资料 | 明确功能边界的日常用车场景 | 将辅助驾驶描绘成无人驾驶或保证恶劣天气安全 |

资料不足时可按“目标与替代方案”规则提出外观、生活方式或情绪方向，不直接替换用户目标，也不用虚构的结果画面证明卖点。“以门店实际政策为准”不能替代活动真实性依据。

### 内置通用提示词骨架

按“场景模板 + 通用约束 + 人物规则 + 用户要求”形成一份完整提示词。替换所有占位符，按实际任务展开；设置以默认设置表和用户最终选择为准。

```text
制作一条{已确定时长}、{画幅}的汽车营销短视频，风格为{视觉风格}。
目标与核心内容：{营销目标、表达类型、已确认卖点或情绪主题}。
素材用途：{每辆车分别列出对应的真实素材引用及用途；人物素材另列}。
车辆一致性：每辆车分别与对应素材一致，保持可见颜色、外观、车标、可辨认车牌、轮毂与比例，不补造或改造细节，不混入无关车辆。{单车型任务补充“全片同一辆车”；多车型列明逐车身份与镜头关系}。
人物：{依照人物规则展开实际形象、主角或辅助讲解者定位，以及推动情节的行动或讲解安排}。
场景：{地点、时间、光线与氛围}。
分镜与口播：{按最终稿逐段写清时间、画面、动作、镜头及对应台词；无人声时写清声音安排}。
声音：{展开口播语言、表达方式、轻微场景环境音，以及与场景、情绪和节奏相符的背景音乐；配乐不盖过口播，用户明确不要时关闭}。
收尾：{与表达类型匹配的行动引导、情绪记忆点或剧情落点}。
约束：{展开通用事实、动作与文字限制及场景特有限制}。
```

### 口播与镜头规则

**按营销目的组织表达，不统一套用 UGC 三段式。**

| 表达类型 | 内容推进 | 收尾方式 |
|---|---|---|
| 转化类：门店、卖点、商用、本地活动等 | 具体观看理由 → 一个有依据的利益点或细节 → 行动建议 | 看车、试驾、咨询或实际使用建议 |
| 氛围类：科技、家庭、户外、节日等 | 具体场景或情绪 → 车辆与生活/视觉的联系 → 情绪记忆点 | 画面与短句形成记忆，不强行导购或提供教程式建议 |
| 剧情类：反转、穿越、轻喜剧等 | 冲突或悬念 → 车辆参与的情节推进 → 反转或落点 | 情节闭合；仅在目标需要时附自然邀约 |

分类由本次营销目的决定，同一模板可用于不同表达类型。口播面向潜在购车用户，不讲“模型如何生成”“特效如何制作”等创作方法；用户明确要制作教程时除外。

- **逐次生成**：口播示例只参考表达方式，实际按车辆素材、事实与本次创意重写，不只替换车型名。用户指定原文或要求按原方案重做时依其要求保留。
- **目标字数**：15秒门店引流、车型讲解等以口播为主的视频，默认以60—65个口播文字为创作目标，不含标点；这是信息量参考，不是硬性下限，不为凑字数补空话。氛围片、剧情片按表达需要安排，不设最低字数；较短视频不照搬该目标。用户指定原文时按其要求保留，超时按内容缩减规则处理。
- **信息有效**：开头直接进入需求、细节、情绪或冲突，不空泛铺垫。销售与讲解类每句话至少承担一项明确作用：提出具体购车关注点、介绍有依据的车辆细节、说明该细节与用户需求的关系，或给出明确行动建议；氛围与剧情类每句推进情绪或情节。避免重复夸赞、复述简单动作、泛泛提问，以及连续使用“亲自看看、亲自感受、试试就知道”等同义表达。
- **事实不足时**：围绕可见外观细节和具体看车、试驾关注点展开，不为增加信息量编造配置或体验，也不强行凑足目标字数。试驾关注点以邀请用户核对或体验的方式表达，不预先承诺车辆表现。
- **时长检查**：有最终音频则使用实际时长；否则按实际读音、自然语速、换气与停顿逐段估算，车型名称、数字与英文单独考虑，并标注“估算”。目标字数服从时长检查，不因达到60—65字就认定符合15秒；自拟稿超时须在展示前精简，不靠加速或截断完成。不将字数换算当实测，不为估时额外付费配音。口播与并行画面按较长者安排，另计不能并行的动作及收尾；整体与每段都必须容纳完整内容，拿不准时精简并留余量。该检查约束写稿与提交，不代表模型成片必然无截断。
- **先内容后分段**：转化类可先写口播再配镜头；氛围或剧情类先确定视觉/情节推进，再配必要台词。无口播按动作安排。模板中的固定秒数仅为示意，最终根据本次内容重新分配，不强制四镜头或最后2秒才开始行动引导。
- **声画同步**：对应台词和画面写在一起，动作与讲解可并行；保留必要停顿，不逐句空拍，不拖长简单动作。通常预留约0.5—1秒自然收尾，不追加无信息定格；其他声音遵循默认设置或用户要求。
- **展示前检查**：事实、素材、表达类型、台词与画面匹配；全部时段连续且不越界，口播、动作完整结束。检查不通过先自行修订，涉及用户指定内容的删改才进入“内容较多时如何处理”。

### 十类场景内置提示词

以下十类模板保留为场景素材库。口播示例仅参考表达方式，不固定复用。实际制作时先提取“开场—展示/推进—收尾”的内容意图，再按上方规则生成最终方案；原有秒数、口播示例、单车型措辞不直接作为执行要求。多车型应用逐车对应规则，口播按转化、氛围或剧情目的重写，时间按本次内容分配。原文中的“确认”表示需要明确的信息，不新增逐步审批；模板特殊限制仍保留。声音安排统一以默认声音规则与用户明确要求为准；用户要求无口播仅删除口播，用户未指定其他声音时仍保留默认配乐和环境音。

#### T01 门店口播引流

**场景正文**：在整洁的门店展示区，以参考车辆为主体，人物站在车旁自然介绍。0—3秒低机位推近车辆前侧，人物进入画面；3—8秒中景介绍{已确认的一个展示重点}，穿插有素材支持的细节；8—13秒继续展示口播对应的可见轮毂与车身细节，人物自然示意；13—15秒回到人车同框，以{已确认的行动引导}收尾。人物不遮挡车辆，不编造门头、优惠或客户证言。

**口播示例**：“照片看中了，到店还要看什么？绕车看比例，近看轮毂细节，再坐进驾驶位，试试视野和操作是否顺手。欢迎预约看车试驾，把每天用车的需求一起带来。”

**替换规则**：直播导流仅在渠道与目标明确时替换收尾；不默认“点击左下角”。讲权益须有真实活动内容，无依据时保留普通看车邀约。交车仪式可创作情景，不冒充真实成交记录。

#### T02 车型卖点讲解

**场景正文**：围绕{已确认卖点}和{日常用车需求}，在{对应生活场景}展示参考车辆。0—3秒通过生活动作引出需求；3—8秒拍摄{有资料与素材支持的功能或细节}；8—13秒展示合理的使用过程与结果，不夸张性能；13—15秒回到车辆整体，以预约体验或记忆点结束。缺少卖点资料时，改为车身整体、可见细节和整体回看的外观展示，不生成未经提供的内饰。

**口播组织骨架（按事实填充，不直接提交）**：“{具体问题或用车需求}？{已确认功能及具体细节，说明与该需求的关系}。{对应的查看或体验建议}。”

**口播示例（空间分支）**：仅在用户已确认后排支持比例放倒、提供对应内饰素材并明确操作方式时使用以下信息结构：“露营想带长件装备，又要给家人留座位？这款车后排支持比例放倒，可按乘坐和装载需要调整。带上装备尺寸到店，核对放倒后的空间，再选适合的装法。”其他车型不得继承本例配置；画面须同步展示实际放倒操作与空间变化。

**口播示例（外观分支）**：“选车，先找到让你心动的细节。从前脸看到侧面，车身比例、线条和轮毂一起看，才是完整的第一印象。欢迎到店对照实车，看看这份眼缘能不能留下来。”

#### T03 商用皮卡干活

**场景正文**：以参考皮卡为主体，场景设在乡镇店铺或日常送货地点，纪实写实光线。0—3秒车辆停在装货位置，人物拿起适量货物；3—8秒展示货箱及合理装载动作，货箱结构须有参考；8—13秒货物固定后车辆沿平整道路行驶，稳定侧前方跟拍；13—15秒车辆停稳到达目的地，人物准备卸货。货物体积、重量与装载方式合理，不描绘超载，不虚构油耗或耐用性。

**口播示例**：“每天拉工具，周末还要送货，选皮卡先把装载需求说清楚。货物放不放得下，搬进搬出顺不顺手，都值得核对。带上常拉货物的实际尺寸，到店看看这台车。”

**替换规则**：可换建材、农资、工具或集市货物；缺少货箱参考则补图或仅展示运输场景的车辆外观。外放电需另有功能依据，不因车型是皮卡就自动加入。

#### T04 越野与户外旅行

**场景正文**：以参考车辆拍摄轻松的户外出行。0—3秒晨光下车辆从停车点准备出发；3—8秒在平整郊外道路平稳行驶，低机位稳定跟拍；8—13秒停在开阔停车区，镜头带出山景、海岸或营地远景；13—15秒缓慢拉远，以车辆和自然环境形成收尾构图。不表现竞速，不加入未经确认的涉水、脱困或极限爬坡。

**口播示例**：“工作日的路，通向办公室。周末的路，也可以通向山野。把车停好，让风吹散一周的忙碌。这一程，目的地是放松下来的自己。”

**替换规则**：泥地、雪地、坡道、涉水等挑战只在用户明确要求且能力依据、场景条件足够时设计，不据车辆品类推定极限性能。

#### T05 本地化区域营销

**场景正文**：以{真实地区或不指名的县城场景}为背景，参考车辆停在门店或乡镇展示区，人物语气亲切。0—3秒用车辆与街景建立地方氛围；3—8秒人物围绕用户的日常用车需求或{有依据的主要信息}介绍；8—13秒以自然接待和人车同框承接看车建议，不据此展示未经提供的配置；13—15秒回到人车同框，邀请到店咨询。不虚构地标、店名、政策、补贴额度或申请条件。

**口播示例**：“每天跑乡镇，还是接送家人？路况、乘车人数不同，看车的重点也不同。来店里聊聊常走的路线和停车环境，核对需要的配置，再约次试驾，选车心里更有数。”

**替换规则**：默认自然普通话；方言、地区名称与具体门店按用户要求加入。补贴活动须有实际依据，未提供时不暗示存在补贴。

#### T06 节日节点营销

**场景正文**：围绕{用户指定节日}与{团圆、出游或到店活动目标}布置适量节日元素。0—3秒由节日道具过渡到车辆；3—8秒拍摄准备出发或走向车辆的动作；8—13秒展示车辆与节日生活场景，人物互动自然；13—15秒以车辆整体及节日口播收尾。节日装饰不遮挡车型，不生成促销标语；没有内饰或后备箱参考时不安排内部装载镜头。

**口播示例**：“平时总说等有空，这个假期，就把出发提上日程。开上车，去见惦记的人。节日最好的安排，是把一句想念，变成一句我们到了。”

### 人物处理规则

先选营销场景，再决定人物的叙事作用与素材引用方式。用户明确指定人物为主角时，由其目标、选择或行动推动情节，让车辆参与该过程，不能仅在开头和结尾站在车旁摆拍。用户只要求有人介绍时，可安排辅助讲解者，不必额外编造人物故事。人物处理是各场景共用规则，不另设两套素材模板。

| 情况 | 处理方式 |
|---|---|
| 需要人物，已提供人物图 | 明确引用实际人物素材，保持面部特征、发型与整体形象及跨镜头一致性，不另写冲突外貌，不虚构其代言或真实车主身份。 |
| 需要人物，未提供人物图 | 根据场景设计虚拟人物，在方案中说明年龄段、外观、服装与状态；全片形象一致，不写不存在的人物图引用，不保证不同任务为同一个人。形象自然协调即可，未要求时不特别强调毛孔或皮肤瑕疵。 |
| 不需要人物 | 聚焦车辆、场景和细节，不强行加人；默认中文口播采用画外音。 |
| 用户要求不露脸 | 用背影、局部动作或车辆镜头表达，不描述面部，不在倒影中意外露出人脸；默认采用中文画外音，不强制补人物图。 |

调整人物时保留营销目标、车辆素材与内容重点；从辅助讲解者改为主角时，同步调整情节、镜头与台词，使其行动真正推动内容；声音统一按默认设置或用户明确要求处理。
