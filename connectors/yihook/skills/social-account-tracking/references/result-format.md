# 结果与数据口径

在展示账号列表、概览、作品或详情前读取本文件。指标来自公开主页，非平台官方后台；只整理当前业务结果，不推导赞评率公式，不补算接口未提供的增量、排名或趋势。缺失与确切的0分别处理；累计指标不能称为近7天新增。

## 研策权益与积分

查询当前权益使用 `get_social_monitoring_access`，从同次返回的 `status` 展示：

| 展示项 | 来源与口径 |
| --- | --- |
| 档位与状态 | `planId/tierId/renewalState`，档位名从同次 `plans` 匹配；`status=null` 为未开通，不等于余额为 0 |
| 周期与到期 | `currentPeriodStart/currentPeriodEnd` 为订阅周期；专用积分到期取 `researchCredits.expiresAt`，不自行用当前时间加 30 天 |
| 专用积分 | `researchCredits.granted/reserved/committed/available` 分别为本期赠送、预占、已用、可用；独立展示预占，不与已用合并，不把目录的 `researchCreditsGranted` 当成余额 |
| 监控席位 | `seats.used/total/pendingRelease/nextReleaseAt/frozen` 按真实状态说明，待释放不算空闲，冻结不称为持续监控 |
| 续费 | `autoRenew/nextRenewalCredits/currentPeriodEnd/retryAt`，关闭时不承诺下期扣款；重试时间仅使用实际返回值 |

`renewalState=renewal_retrying` 说明续费重试中、权益暂停；`expired` 说明已过期，续开或恢复到网页操作。仍返回的赠送量或历史用量不代表可继续消费。字段缺失标注暂未提供，不能填成 0。当前工具没有通用积分钱包余额，不从专用余额、开通费用或下期费用推算。

套餐选择展示实时 `plans[].credits/periodDays/seats/platforms/researchCreditsGranted`：开通扣通用积分，获得本周期监控席位与专用积分。专用积分到期重置、不结转；按需操作专用优先、通用补差。已有套餐查询用 `status.autoRenew`，不把目录 `autoRenewDefault` 当成当前设置。购买与席位绑定仍各自确认，不因查询积分执行付费操作。

## 账号列表

展示账号编号、名称、平台/标识、实际席位状态、有效期和最后成功同步时间。保存编号与订阅ID映射；冻结说明需网页处理，已取消的不列为正在监测。分页未结束时说明尚有更多账号。列表后引导“查看账号1的概览”或“看看账号1的内容”；取消与席位管理只给网页入口。

## 账号表现概览

表格前展示账号名称、平台、所选统计周期、实际数据覆盖日期。返回分为两张表：指标表和监测信息表。

| 指标         | 当前数据                     | 数据说明                         |
| ------------ | ---------------------------- | -------------------------------- |
| 当前粉丝     | {最新粉丝数}                 | 最新公开账号快照                 |
| 粉丝变化     | {已提供的变化值或暂不可计算} | {统计时段或不可计算原因}         |
| 窗口内发布   | {已监测作品数量或暂无数据}   | 当前统计窗口内已监测到的公开作品 |
| 单篇中位播放 | {统计值或暂无数据}           | {有效样本覆盖情况}               |
| 单篇中位赞评 | {统计值或暂无数据}           | {有效样本覆盖情况}               |
| 赞评率中位数 | {统计值或暂无数据}           | {有效样本覆盖情况}               |

| 监测信息     | 时间 / 状态                                        |
| ------------ | -------------------------------------------------- |
| 开始监控     | {实际开始监控时间}                                 |
| 最后成功同步 | {最后成功时间；从未成功则显示“暂无，等待首次同步”} |
| 当前同步状态 | {实际状态；发生失败时明确说明}                     |
| 自动更新安排 | 每日 09:00、14:00、20:00；实际调整时以当前安排为准 |
| 下次计划更新 | {实际计划时间；没有该信息时不编造}                 |

有粉丝快照数量、播放数据、赞评数据和赞评率等样本覆盖信息时，在对应说明中展示；“有效样本 0 / 0”不能解释为播放量或互动率为 0。粉丝趋势已有业务数据时可按日期列表展示；仅有一个快照时说明“样本积累中”，不推断上涨或下降。

固定提示：“数据来自公开主页，仅统计已监测到的公开样本，非平台官方后台数据。”用户可以继续说“看近 30 天”或“看全部监控期”，无需重新提供账号。

## 样本不足与失败

按指标分别判断可用性，不能因为作品样本为零就隐藏已有粉丝数，也不能把缺失指标填成 0。

概览返回 `insights=null` 和 `insightsError` 时，统计表标注尚未就绪；当前粉丝可取本次 `account.followers`，监测时间与同步状态取本次 `subscription/latestSync`。其他缺失统计不补造，作品列表独立查询与展示。

| 情况                         | 展示方式                                                                   |
| ---------------------------- | -------------------------------------------------------------------------- |
| 尚无任何有效数据             | 显示正在同步或实际失败状态，展示开始监控时间、最后成功同步状态及更新安排。 |
| 只有一个粉丝快照             | 正常展示当前粉丝；粉丝变化显示“暂不可计算，目前仅有 1 个有效快照”。        |
| 作品指标有效样本为零         | 播放、赞评、赞评率统计显示“暂无数据”，并标注对应有效样本数量。             |
| 窗口内发布明确返回 0         | 显示“0 条”，解释为当前窗口内已监测作品为 0，不断言账号没有历史作品。       |
| 部分指标缺失                 | 已有指标正常展示，缺失项单独标注，不让单项失败遮蔽全部结果。               |
| 最新一次同步失败但有历史结果 | 展示仍可查询的已有数据及最后成功时间，明确最新同步失败，不写“数据最新”。   |

适用于刚开通、没有同步失败且作品样本不足的提示：

> 该账号刚开始监控，目前已获取粉丝快照，作品指标的有效样本仍为 0，暂时无法展示相关统计。这不代表账号没有历史作品或作品没有播放。
>
> 开始监控：{实际时间}；最后成功同步：{实际时间}。系统每日 09:00、14:00、20:00 自动更新，下次计划更新为 {实际计划时间}。可以在该时间之后再次询问“查看这个账号的表现概览”，具体以同步成功后的结果为准。

同步失败时改用失败说明，不仅用“样本积累中”解释。缺少下次计划时间时仅提示按更新安排稍后查询，不承诺“等一次就会有完整数据”。概览周期内无作品，但内容列表存在其他日期作品时，两部分分别说明范围，不擅自改写统计结果。

## 已采集作品列表

默认标题为“最近 5 条已采集作品”，实际不足 5 条时按实际数量修改。每条至少尽量呈现标题或文案摘要、发布时间、已有指标和原链接；封面有则展示。

| 作品编号 | 标题 / 文案摘要 | 发布时间   | 已有指标                         | 原链接         |
| -------- | --------------- | ---------- | -------------------------------- | -------------- |
| 1        | {标题或摘要}    | {发布时间} | {例如点赞数；按实际可用数据展示} | {可用原文链接} |

列表只展示已有数据，不默认逐条获取详情以填满指标。不承诺每个平台、每条作品都有播放量、分享或收藏数据。没有原链接时标注暂不可用，不构造链接。

- “继续看”只返回同一账号、同一筛选范围的下一批已存作品；需要额外采集时停止并说明限制，编号连续；无更多作品时明确结束。
- “展开作品 2”依据此前实际展示的作品定位，后续排序或同步变化不能让同一追问误指向另一条作品。
- 切换账号或筛选范围时明确告知新列表范围；编号有歧义时只核对目标作品。
- 未能确认数据完整时，不把“已采集作品列表”称为该账号全部历史作品。
- 不额外输出表现评价、选题观察、入选理由或制作建议。

## 选中作品详情

优先展示作品标题、封面、完整文案、发布时间，再展示指标表、详情更新时间和原链接。完整文案保留原语言及话题标签，不自动翻译或改写；列表中的摘要不能代替详情全文。

示例指标展示方式：

| 播放量  | 点赞 | 评论 | 分享  | 收藏  |
| ------- | ---- | ---- | ----- | ----- |
| 38.1 万 | 1 万 | 76   | 6,769 | 9,203 |

> 发布于：2026-10-07。详情指标更新于：2026-10-10 10:24。  
> 数据来自公开主页，非平台官方后台。

正式结果使用实际数据和可用原链接。原数据为“1 万”等展示值时不补造更精确数字；某项缺失时标注“暂无数据”。不根据详情中的累计指标推算概览增量，也不因详情更新较晚而声称账号概览同步完成。
