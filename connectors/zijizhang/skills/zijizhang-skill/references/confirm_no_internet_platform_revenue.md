## 确认公司无互联网平台收入（一次性确认）

```shell
zijizhang-cli todo confirm_no_internet_platform_revenue --uid='<uid>'
```

> ⚠️ 本命令仅支持确认"公司在互联网平台没有收入"（一次性确认，不分月份）。如确认公司存在互联网平台收入，请到「自记账」App 内填写未开票未转公收入。

### 参数说明

| 参数    | 类型     | 必填 | 说明                                                                                            |
|:------|:--------|:---|:----------------------------------------------------------------------------------------------|
| uid   | string  | ❌  | 公司唯一标识，可以不指定；不指定时使用当前已切换在用的 `uid`，参见 `zijizhang-cli account get_cpy_list` 中 `active=true` |

### 使用示例

```shell
zijizhang-cli todo confirm_no_internet_platform_revenue
```

### 返回参数

| 参数   | 类型     | 说明                      |
|:-----|:-------|:------------------------|
| code | int    | 状态码，`200` 代表成功，其他代表失败   |
| msg  | string | 提示信息，失败时为异常信息           |
| data | dict   | 数据                       |

data 参数说明

| 参数   | 类型     | 说明                                |
|:-----|:-------|:----------------------------------|
| uid  | string | 当前查询所属的 `uid`                     |

### 返回例子

#### 确认成功

```json
{
    "code": 200,
    "msg": "确认成功",
    "data": {
        "uid": "123451c07f47435e12a34111"
    }
}
```

#### 确认失败

```json
{
    "code": 500,
    "msg": "确认失败，请稍后重试",
    "data": {}
}
```
