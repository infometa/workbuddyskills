## 标记某个月份无互联网平台收入

```shell
zijizhang-cli todo set_month_no_internet_revenue '<year>' '<month>' --uid='<uid>'
```

> ⚠️ 本命令仅支持确认"无互联网平台收入"。如确认本月存在互联网平台收入（淘宝、京东、抖音、拼多多等平台的非对公收入），请到「自记账」App 内填写未开票未转公收入。

### 参数说明

| 参数    | 类型     | 必填 | 说明                                                                                            |
|:------|:--------|:---|:----------------------------------------------------------------------------------------------|
| year  | int     | ✅  | 年份，如 2026                                                                                    |
| month | int     | ✅  | 月份(1-12)，如 3                                                                                  |
| uid   | string  | ❌  | 公司唯一标识，可以不指定；不指定时使用当前已切换在用的 `uid`，参见 `zijizhang-cli account get_cpy_list` 中 `active=true` |

### 使用示例

```shell
zijizhang-cli todo set_month_no_internet_revenue 2026 3
```

### 返回参数

| 参数   | 类型     | 说明                      |
|:-----|:-------|:------------------------|
| code | int    | 状态码，`200` 代表成功，其他代表失败   |
| msg  | string | 提示信息，失败时为异常信息           |
| data | dict   | 数据                       |

data 参数说明

| 参数   | 类型     | 说明                                |
|:-----|:-------|:----------------------------------|
| uid  | string | 当前查询所属的 `uid`                     |
| year | int    | 年份                                |
| month | int   | 月份                                |

### 返回例子

#### 确认成功

```json
{
    "code": 200,
    "msg": "确认成功",
    "data": {
        "uid": "123451c07f47435e12a34111",
        "year": 2026,
        "month": 3
    }
}
```

#### 确认失败

```json
{
    "code": 500,
    "msg": "确认无收入失败",
    "data": {}
}
```
