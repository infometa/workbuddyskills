# 互联网平台收入待办处理流程（code=INTERNET_REVENUE）

> **能力边界**：本 skill-cli **仅支持确认"无互联网平台收入"**。
> 若用户确认本期/本公司**存在**互联网平台收入（淘宝、京东、抖音、拼多多等平台的非对公收入），
> CLI 无法填写，必须引导用户到「自记账」App 内填写未开票未转公收入，流程到此终止。

> **阻塞说明（重要）**：该待办**会阻塞**提交审账。
> CLI 端审账守卫（`todo before_set_month_audited`）会检查本项：
> 待办未完成（含平台收入收据"审核中"）时直接返回 `state=不能提交审账`，
> 必须先完成互联网平台收入确认，才能进入审账流程。
> 因此本项属于**主流程前置项**，处理待办时应优先完成，不可跳过。

## Step 1：定位待办并判断形态

先查询待办列表：

```shell
zijizhang-cli todo get_todo_list --uid='<uid>'
```

在 `data.todo_list` 中找到 `code == 'INTERNET_REVENUE'` 的条目，记录：
- `name`：用于判断待办形态
- `desc`：当前状态描述
- `state`：`0` 未完成 / `1` 已完成
- `tips`：未完成时提示"如有互联网平台收入，请在自记账app内填写"
- `data.year` / `data.month`：当前记账期

| `name` 取值 | 形态 | 适用命令 |
| --- | --- | --- |
| `是否有互联网平台收入` | ① 公司级初始确认（一次性，不分月份） | `confirm_no_internet_platform_revenue` |
| `N月份互联网平台收入`（N 为具体月份） | ② 月度确认 | `set_month_no_internet_revenue '<year>' '<month>'` |

若 `state == 1`（已完成），无需处理，直接向用户说明已完成并结束。

### 特殊情况：收据"审核中"

若 `desc` / `right_content` 显示**审核中**，说明用户已在 App 内填写了未开票未转公收入、等待审核：

- **无需**在 CLI 执行任何写操作（既不能标记无收入，也无需重复填写）
- 该状态**仍然阻塞提交审账**，后端会返回"N月份互联网平台收入审核中，请稍后再提交审账"
- 处理方式：告知用户"平台收入收据正在审核中，请等待审核通过后再提交审账"，并结束本项

## Step 2：向用户确认是否有互联网平台收入

📌 **必须询问用户，不得自行假设**：

- 形态①：询问"贵公司是否在淘宝、京东、抖音、拼多多等互联网平台有收入？"
- 形态②：询问"本期（YYYY年M月）贵公司是否在互联网平台有收入？"

---

## 分支 A：用户确认"没有互联网平台收入"

### A-1：回显关键信息并向用户确认（写操作必需）

至少回显：
- 当前公司 `uid`
- 待办形态与操作对象（形态①为公司级一次性确认；形态②为年月）
- 即将执行的命令

**等待用户明确回复"确认/是"后**，才执行下方命令。

### A-2：执行确认命令

形态①（公司级一次性）：

```shell
zijizhang-cli todo confirm_no_internet_platform_revenue --uid='<uid>'
```

形态②（月度，year/month 取 `get_todo_list` 返回的 `data.year` / `data.month`）：

```shell
zijizhang-cli todo set_month_no_internet_revenue '<year>' '<month>' --uid='<uid>'
```

### A-3：校验结果

- 检查返回 `code`
- `code == 200`：确认成功
- `code != 200`：停止后续流程，向用户反馈 `msg`

### A-4：重新查询待办确认状态

```shell
zijizhang-cli todo get_todo_list --uid='<uid>'
```

确认该条目 `state` 已变为 `1`，再向用户汇报完成。

---

## 分支 B：用户确认"有互联网平台收入"

CLI 不支持填写互联网平台收入，必须引导到 App：

1. 明确告知用户："确认有互联网平台收入需要在「自记账」App 内填写未开票未转公收入，CLI 无法完成此操作"
2. **同时说明后果**：本项会阻塞提交审账，未完成前无法提交审账（硬阻塞，CLI 无绕过方式）
3. 提示用户打开「自记账」App，找到「互联网平台收入」待办，按页面提示填写
4. 用户回到 App 完成填写或确认后，重新执行 `todo get_todo_list` 确认状态
5. **流程终止**，不执行任何写操作

> 严禁在 CLI 中把"有收入"当作"无收入"提交，这会导致记账数据错误。

---

## 注意事项

- 不得为了凑齐 `year` / `month` 自行补值，必须从 `get_todo_list` 返回的 `data.year` / `data.month` 取值
- 形态②的 `month` 是记账期月份，与待办 `name` 中的月份一致
- 用户表述模糊（如"应该有吧""我不清楚"）时，必须进一步确认，不可默认按"无收入"提交
