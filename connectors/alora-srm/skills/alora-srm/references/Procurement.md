# 招采 — 强制首步操作

**当触发本模块或用户要求进行招采业务时，Agent 必须首先执行以下步骤以探测可用表单：**

## 步骤 1：调用工具

通过 HTTP 直连调用 `crud_get_yidea_func_list`：
参数说明：
参数名 : "menuArray"
参数内容 : "招采管理,供应商档案,供应商扣款,物料档案,AI采购申请,AI询价邀请,AI询价结果确认,AI合同起草,AI采购订单,价格库管理,配额管理,收货管理,付款计划,付款申请"

> **使用的脚本位置**：`references/yidea-http.js`（相对 skill 目录）

## 步骤 2：展示结果并匹配业务模块

获取结果后，将返回的表单列表展示给用户，并询问用户想要操作哪一个。

可参照如下说明，帮用户快捷选择要操作的单据：

### 供应商管理


**description**：【供应商档案】当用户需要创建和修改供应商档案时，提供供应商档案字段说明与填写规范。

**examples**：
- "创建/注册供应商"
- "修改供应商信息"

## ⚠️ 全局规则：displayForAI 字段过滤

本 skill 中的所有表单定义（`crud_get_yidea_table_def` 返回）中，每个字段的 `options.displayForAI` 标记控制该字段是否对 AI 操作可见。

**强制性行为规则**（详见 `protocol.md` 规则 4 和 `workflow.md` Step 2/3）：

| 阶段 | 规则 |
| :--- | :--- |
| 展示 Schema | 仅展示 `displayForAI === true` 的字段 |
| 新增/修改数据 | 仅提交 `displayForAI === true` 的字段 |
| 查询展示 | 仅请求 `displayForAI === true` 的列 |

> `displayForAI: false` 或缺失该标记的字段一律过滤，禁止展示和提交。
