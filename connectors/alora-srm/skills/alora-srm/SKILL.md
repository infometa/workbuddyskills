## 🛠 yidea-http.js 调用规范

`references/yidea-http.js` 是**所有业务操作**的统一 HTTP 直连调用入口。以下场景必须使用此脚本：

### 何时调用

| 场景         | 工具名示例                                                 | 说明                                               |
| :----------- | :--------------------------------------------------------- | :------------------------------------------------- |
| 首次登录     | `yidea-provision.js`（非 http.js）                         | 登录走 `yidea-provision.js`，登录后自动生成 config |
| 查询表单列表 | `crud_get_yidea_func_list`                                 | 探测可用菜单                                       |
| 获取表单定义 | `crud_get_yidea_table_def`                                 | 查看字段结构（Schema）                             |
| 查询数据     | `crud_yidea_table_search`                                  | 查询主表/子表数据                                  |
| 新增数据     | `crud_yidea_table_add`                                     | 新增主表+子表数据                                  |
| 修改数据     | `crud_yidea_table_update` / `crud_yidea_main_table_update` | 修改主表/主子表                                    |
| 删除数据     | `crud_yidea_table_delete`                                  | 删除主表数据                                       |
| 子表新增     | `crud_yidea_sub_table_add`                                 | 追加子表单行                                       |
| 子表修改     | `crud_yidea_sub_table_update`                              | 修改子表单行（需 subId）                           |
| 子表删除     | `crud_yidea_sub_table_delete`                              | 删除子表单行                                       |
| 查询员工     | `crud_get_yidea_employee_list`                             | employeeSelect 前缀字段                            |
| 查询公司     | `crud_get_yidea_company_list`                              | companySelect 前缀字段                             |
| 查询部门     | `crud_get_yidea_department_list`                           | departmentSelect 前缀字段                          |

### 调用方式（推荐：stdin 模式）

```powershell
# stdin 模式（推荐，支持中文、任意复杂嵌套，无编码问题）
'{"menuArray":"招采管理"}' | node yidea-http.js crud_get_yidea_func_list --stdin

# 直接传参模式（仅适用于纯 ASCII 参数，含中文会解析失败）
node yidea-http.js crud_get_yidea_func_list '{ "menuArray": "招采管理" }'

# 文件模式
node yidea-http.js crud_get_yidea_table_def --file ./args.json
```

### ⚠️ 关键规范

1. **stdin 优先**：参数含中文时必须用 `--stdin` 管道模式，直接传参在 PowerShell 下会因编码问题报 `JSON 解析失败`
2. **所有 value 为 String**：协议要求所有值必须是字符串类型，禁止数字/布尔
3. **表单ID硬编码**：`crud_get_yidea_func_list` 返回的 `tableId` 即表单ID，后续操作直接使用
4. **`query_` 字段**：值用关联记录的原始 ID（UUID 字符串），不要用名称
5. **子表 model**：`subTable` 的值是表单定义中的 `model` 字段（如 `table_1698131215396`）
6. **失败排查**：400 错误通常是（a）字段名(model)拼错 （b）`query_`值格式不对 （c）必填字段遗漏
