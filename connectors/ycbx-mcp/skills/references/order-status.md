# 单据状态

`ycbx_order_list` 的 `statusName` 参数和返回值都使用下表的中文名称，以有成报销的状态定义为准。

| 状态 | 含义 | 归类 |
| --- | --- | --- |
| 待提交 | 草稿，还没提交 | 未生效 |
| 待审批 | 已提交，正在审批流中 | 在途 |
| 驳回 | 被审批人驳回，需要修改后重新提交 | 未生效 |
| 撤销 | 提交人自己撤回 | 未生效 |
| 待支付 | 审批通过，等待财务付款 | 在途 |
| 支付中 | 正在付款 | 在途 |
| 完成 | 已付款或流程已结束 | 已完成 |
| 拒绝 | 审批被拒绝，流程终止 | 未生效 |
| 待处理 | 需要提交人处理（例如补充材料） | 在途 |
| 合同待支付 | 合同类单据，等待付款 | 在途 |
| 合同待收款 | 合同类单据，等待收款 | 在途 |
| 合同完成 | 合同类单据已完成 | 已完成 |
| 结束 | 流程结束 | 已完成 |

## 统计口径

- “我报了多少钱”：默认统计**在途 + 已完成**的单据金额，不含未生效的单据；回答时写明口径，例如“统计了待审批、待支付、支付中、完成等状态，不含草稿和被驳回的单据”。
- “我已经拿到多少钱”：只统计“完成”“合同完成”“结束”。
- “还有多少在审批”：统计“待审批”“待处理”。
- 用户的说法和上面的口径对不上时，先说明你采用的口径，或者问一句。

`ycbx_order_progress` 只在“待审批”“待处理”时返回当前审批节点和到达时间；其他状态下节点为空属于正常情况。
