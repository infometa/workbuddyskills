# 工具与参数

9 个工具全部只读，都只返回当前连接员工本人的数据。所有工具都没有身份参数，不要传 `corpId`、`userId` 之类的字段。

## ycbx_user_profile：员工档案

查询姓名、工号、所属部门、角色、成本中心、常驻城市。无参数。

## ycbx_order_list：报销单列表

返回单据号、名称、模板、金额（元）、状态、提交日期，分页。

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | :---: | --- |
| `startDate` | string | - | 开始日期 `yyyy-MM-dd`；不传时为结束日期往前 90 天 |
| `endDate` | string | - | 结束日期 `yyyy-MM-dd`；不传时为今天 |
| `templateName` | string | - | 单据模板名称，例如「差旅报销单」；名称不对时会返回可选模板 |
| `statusName` | string | - | 单据状态中文名，取值见[单据状态](order-status.md) |
| `page` | integer | - | 页码，从 1 开始，默认 1 |
| `pageSize` | integer | - | 每页条数，默认 20，最大 50 |

查询跨度不超过 366 天。`hasMore` 为 true 时还有下一页。

## ycbx_order_detail：报销单详情

返回表头、各字段的展示值、包含的每笔消费、关联单据号。

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | :---: | --- |
| `orderCode` | string | ✅ | 单据号，例如 `BX2608261602387327`；可从 `ycbx_order_list` 获得 |

## ycbx_order_progress：审批进度

返回当前状态；审批中时给出当前审批节点和到达时间。只到当前节点，没有逐级审批记录。

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | :---: | --- |
| `orderCode` | string | ✅ | 单据号 |

## ycbx_order_budget：单据预算占用

返回预算名称、期间、总额、已用、本单占用、剩余，以及是否超预算。

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | :---: | --- |
| `orderCode` | string | ✅ | 单据号 |

## ycbx_fee_unused_list：没报销的消费

返回已经记录、但还没挂到任何报销单上的消费：费用类型、金额、日期、说明，以及提交前还需补填的字段 `missingFields`。

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | :---: | --- |
| `page` | integer | - | 页码，从 1 开始，默认 1 |
| `pageSize` | integer | - | 每页条数，默认 20，最大 50 |

## ycbx_invoice_unused_list：没用的发票

返回发票夹里已上传、但还没生成消费的发票：金额、开票日期、销售方、开票内容。发票号码只给后 4 位。

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | :---: | --- |
| `page` | integer | - | 页码，从 1 开始，默认 1 |
| `pageSize` | integer | - | 每页条数，默认 20，最大 50 |

## ycbx_cost_standard：差旅费用标准

返回企业已启用的住宿、交通、补贴等标准，每条按城市等级、城市、日期类型给出金额上限。结果没有按个人的角色、部门筛选，实际以 App 提交时的校验为准。

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | :---: | --- |
| `cityName` | string | - | 城市名，例如「上海」「杭州市」；不传返回全部 |

## ycbx_loan_list：借款记录

返回借款单号、名称、借款金额、剩余未核销金额 `remainingAmount`、是否已还清、借款日期、应还日期。

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | :---: | --- |
| `page` | integer | - | 页码，从 1 开始，默认 1 |
| `pageSize` | integer | - | 每页条数，默认 20，最大 50 |
