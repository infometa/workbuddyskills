# Wind 金融数据工具指南

# 总述：何时使用 Wind 金融数据 MCP

当用户需要**可追溯的证券、基金、指数、债券、公告、财经新闻或宏观经济结构化数据**时，使用本 Connector。它适合获取事实、行情、指标、筛选结果和时间序列；不要把它当作通用投资建议工具，也不要在未调用工具时编造实时数据或历史数据。

## 路由与调用原则

1. **先识别对象。** 股票、基金、指数、债券、公司公告/新闻、宏观经济数据分别使用对应分类工具；若用户没有给出具体证券、基金或指数，只描述筛选条件，先用 `search_stocks` 或 `search_funds` 取得候选代码。
2. **再匹配时间粒度。** 分钟级日内序列用 `*_quote`；多日 OHLC/K 线用 `*_kline`；只要最新快照或指定指标点用 `*_price_indicators`；技术指标、风险指标、基本面指标分别用 `*_technicals`、`get_risk_metrics`、`*_fundamentals`。
3. **股票主题按意图路由。** 公司身份、上市与行业用 `get_stock_basicinfo`；股本、股东和限售解禁用 `get_stock_equity_holders`；报表、盈利和估值用 `get_stock_fundamentals`；公司重大事项、违规和分红用 `get_stock_events`。
4. **区分信息来源。** 查询上市公司披露文件、定期报告或公告正文时用 `get_company_announcements`；查询媒体报道、市场动态和新闻时用 `get_financial_news`。
5. **宏观数据显式指定 EDB 模式。** 找指标用“仅搜索”；已知 EDB 代码取数用“仅提数”；自然语言找指标并返回数值用“搜索并提数”。取数时传 `beginDate`/`endDate`，或传 `observation`，两者不可同时传。
6. **多标的汇总或计算用 `get_financial_data`。** 将需要的实体、指标、日期、筛选或计算口径写清楚。工具返回空数据或错误时，说明结果并收窄对象、指标或时间范围后再尝试。

# 股票工具

## `search_stocks`

从全市场 A 股中筛选符合条件的股票，返回股票代码列表。适用于用户描述选股条件、但未指定具体股票的场景。

> **适用场景：** 当用户没有给出具体股票代码，而是描述市值、涨跌幅、行业、上市板、连续上涨、资金流入等选股条件时使用。适合先生成候选 A 股代码列表，再继续调用基本面、行情或事件类工具做深入分析。

> **适合的问法：** “帮我找出沪深市场市值超过500亿、最近5日上涨的股票。”

**输入参数**

| 参数       | 类型     | 必填  | 说明        |
| -------- | ------ |:---:| --------- |
| question | string | 是   | 自然语言选股条件。 |

**返回内容**

符合条件的 A 股代码列表。

**调用示例**

```json
{
  "name": "search_stocks",
  "arguments": {
    "question": "筛选沪深市场市值超500亿且近5日上涨的A股"
  }
}
```

## `get_stock_basicinfo`

获取股票基本档案及上市信息，包括公司名称、历史曾用名、法定代表人、注册地址、成立日期、经营范围、主营产品、IPO/上市板、行业分类、指数成份归属、概念标签及风险标识等。

> **适用场景：** 查询公司身份、上市和行业档案。

**输入参数**

| 参数       | 类型     | 必填  | 说明                        |
| -------- | ------ |:---:| ------------------------- |
| question | string | 是   | 自然语言查询，应包含对象、指标和需要时的时间范围。 |

**返回内容**

中英文名称、曾用名、主营业务、上市板、行业、指数成分和概念标签。

**调用示例**

```json
{"name":"get_stock_basicinfo","arguments":{"question":"查询贵州茅台股票的基本档案，包括上市日期、所属行业和主营业务"}}
```

| begin    | string | 否   | 开始日期，格式 yyyy-MM-dd。 |
| end      | string | 否   | 结束日期，格式 yyyy-MM-dd。 |


## `get_stock_kline`

获取指定股票在给定区间内的日、周或月 K 线，包含开高低收、成交量、成交额、涨跌幅和换手率等。

> **适用场景：** 查询股票日/周/月等 K 线。

**输入参数**

| 参数         | 类型      | 必填  | 说明                    |
| ---------- | ------- |:---:| --------------------- |
| windcode   | string  | 是   | Wind 代码或工具支持的名称。      |
| begin_date | string  | 是   | 开始日期，格式 yyyy-MM-dd。   |
| end_date   | string  | 是   | 结束日期，格式 yyyy-MM-dd。   |
| count      | integer | 否   | 正数向后取、负数向前取。          |
| period     | string  | 否   | 周期：10 日K、11 周K、12 月K。 |
| aftype     | string  | 否   | 0 前复权，1 后复权。          |
| issusp     | string  | 否   | 0 不含停牌，1 包含停牌。        |
| afdate     | string  | 否   | 复权基准日期。               |

**返回内容**

开盘价、最高价、最低价、收盘价、成交量、换手率、涨跌幅和均价。

**调用示例**

```json
{"name":"get_stock_kline","arguments":{"begin_date":"2026-07-20","end_date":"2026-07-27","windcode":"600519.SH","period":"10","aftype":"0","issusp":"1"}}
```

| indexes  | string | 否   | 所需行情指标；多个指标使用英文逗号 `,` 分隔。             |

**返回内容**

各股票的最新交易日、交易时间、最新价、涨跌幅、成交量、换手率或指定指标快照。

**调用示例**

```json
{"name":"get_stock_price_indicators","arguments":{"windcode":"600519.SH","indexes":"最新交易日,交易时间,最新成交价,成交量,涨跌幅"}}
```

## `natural_language_get_edb_data`

根据自然语言问句或 EDB 指标代码，从 Wind EDB 经济数据库中搜索指标并获取时间序列数据，支持仅搜索、仅提数和搜索并提数。

根据自然语言问句或 EDB 指标代码，从 Wind EDB 经济数据库中搜索指标并获取时间序列数据。支持仅搜索、仅提数、搜索并提数三种模式。

> **适用场景：** 当用户查询宏观经济指标或 Wind EDB 时间序列时使用。仅想找指标用“仅搜索”；已知 EDB 代码直接取数用“仅提数”；自然语言找指标并返回数值用“搜索并提数”。取数时显式传日期或期数。

> **适合的问法：** “帮我搜索中国GDP相关的Wind EDB指标。”

**输入参数**

| 参数            | 类型     | 必填  | 说明                                     |
| ------------- | ------ |:---:| -------------------------------------- |
| executionMode | string | 是   | 仅搜索、仅提数或搜索并提数。                         |
| question      | string | 是   | 搜索描述；仅提数时填 EDB 指标代码，多个代码使用英文逗号 `,` 分隔。 |
| beginDate     | string | 否   | 开始日期，格式 `yyyyMMdd`；与 `observation` 互斥。 |
| endDate       | string | 否   | 结束日期，格式 `yyyyMMdd`；与 `observation` 互斥。 |
| observation   | string | 否   | 最近 N 期或 `all`；与日期范围互斥。                 |

**返回内容**

指标代码、名称、频率、单位和时间序列数值。

**调用示例**

```json
{
  "name": "natural_language_get_edb_data",
  "arguments": {
    "question": "中国GDP",
    "executionMode": "仅搜索"
  }
}
```
