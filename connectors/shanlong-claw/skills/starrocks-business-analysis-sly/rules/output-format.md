# 输出格式规范

## 📐 格式总则

每次输出遵循以下结构：

```
## [分析标题]（[时间范围]）

[数据主体：表格 / 图表描述 / KPI卡片]

[单位说明]（金额单位：元；占比单位：%；时长单位：分钟）

[分析建议]（可选，1-3条）
```

---

## ✅ 集团名称标注规范

### 可以在回复中标注的内容

| 内容 | 示例 | 说明 |
|------|------|------|
| 当前所属集团名称 | "广西圣膳集团控股有限公司" | ✅ 可以在标题中标注 |
| 数据范围 | "数据范围：2026-04-01 ~ 2026-04-07" | ✅ 必须标注 |
| 权限范围说明 | "💡 仅显示您权限范围内的数据" | ✅ 必须标注 |

### 推荐标题格式

```
✅ 推荐：
## 九田家集团 营收汇总（2026年3月）
## 广西圣膳集团 经营指标汇总（2026年3月）

✅ 推荐（含时间）：
📊 数据范围：2026-04-01 ~ 2026-04-07 | 广西圣膳集团
```

### 禁止在回复中暴露的内容

| 禁止内容 | 示例 | 正确做法 |
|---------|------|---------|
| group_code 数值 | "group_code=41526" | ❌ 绝对不能暴露 |
| 其他集团名称 | "九田家集团的数据..."（用户不属于九田家） | ❌ 只能提当前所属集团 |
| SQL 内部参数 | 展示 group_code 的实际值 | ❌ SQL 不展示给用户 |

## 📊 数据截止时间自动告知

每次输出结果时，**自动在末尾附加数据时间范围说明**：

```
---
📊 数据范围：2026-04-01 ~ 2026-04-07 | 【集团名称】
💡 提示：数据为 T-1 日结，今日实时数据暂不可用
💡 仅显示您权限范围内的数据
```

**规则**：
- 始终显示查询的 `start_date` 和 `end_date` 范围
- 告知数据为"昨日结账"（T-1），暗示用户若需要当天数据暂不可用
- ⚠️ 即使查到当天数据，也仅代表「已日结」的记录，不包含当天未完成或待调整的订单
- 若用户问"今天"但数据只到昨天，主动说明

## 🎯 精度要求

| 指标类型 | 精度要求 | 示例 |
|---------|---------|------|
| **金额**（实收/营业额/纯收） | 保留 **2 位小数**，加 ¥ 前缀 | ¥12,345.68 |
| **单均消费 / 人均消费** | 保留 **2 位小数**，加 ¥ 前缀 | ¥73.60 |
| **占比 / 百分比**（开台率/上座率/折扣率/营收占比） | 保留 **2 位小数**，加 % 后缀 | 42.35% |
| **折扣率** | 保留 **1 位小数**，加 % 后缀 | 8.5% |
| **时长**（平均就餐时间等） | 保留 **2 位小数**，加"分钟"后缀 | 28.58分钟 |
| **坪效 / 人效** | 保留 **2 位小数**，加 ¥/㎡ 或 ¥/人 | ¥128.35/㎡ |
| **门店数 / 订单数 / 账单数 / 客流量** | **整数**，不保留小数 | 243 单 |
| **排名 / 序号** | **整数** | 1 |
| **面积** | 保留 **2 位小数**，加 ㎡ | 128.50 ㎡ |

**特殊说明**：
- `NULL` 值显示为 `—`（短横线），不显示为 0 或空白
- 环比/同比增长率：保留 **2 位小数**，增长 🔴+X.XX%，下降 🟢-X.XX%
- 表格合计行加粗
