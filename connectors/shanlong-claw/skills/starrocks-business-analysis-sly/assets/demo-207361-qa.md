# 某烧烤酒馆品牌 问数测试集

> 共 15 个问题，覆盖 Intent 1-50 全分析场景。
> 数据基础：260 家门店，直营，覆盖 137 个城市，营业数据从 2024 年至今。

## Q01 — 门店总数与地理分布
**Intent**：Intent 01 + Intent 03
**触发词**：「有多少家门店」「分布在哪些城市」

```sql
SELECT
    COUNT(DISTINCT store_code) AS 门店总数,
    COUNT(DISTINCT province) AS 省份数,
    COUNT(DISTINCT city) AS 城市数
FROM dm.v_pos_corp_sale_analysis_with_sly
WHERE group_code = '#{SL_UNIFIED_G_ID}'
    AND store_code IN (#{omShopCodes})
    AND settle_biz_date >= DATE_SUB(CURDATE(), INTERVAL 30 DAY);
```

```sql
SELECT
    province AS 省份,
    city AS 城市,
    COUNT(DISTINCT store_code) AS 门店数
FROM dm.v_pos_corp_sale_analysis_with_sly
WHERE group_code = '#{SL_UNIFIED_G_ID}'
    AND store_code IN (#{omShopCodes})
    AND settle_biz_date >= DATE_SUB(CURDATE(), INTERVAL 30 DAY)
GROUP BY province, city
ORDER BY 门店数 DESC
LIMIT 20;
```

**回答要点**：260 家门店，覆盖宁夏/浙江/海南/黑龙江等省份，重点在宁夏（根据地）和海南（三亚）等旅游城市。

## Q02 — 哪些门店营收最高？
**Intent**：Intent 07 — 营收门店排名
**触发词**：「营收最高的门店」「最赚钱的店」

```sql
SELECT
    store_name AS 门店名称,
    city AS 城市,
    SUM(bill_count) AS 账单数,
    ROUND(SUM(busi_income), 2) AS 实收金额,
    ROUND(SUM(busi_income) / SUM(bill_count), 2) AS 客单价
FROM dm.v_pos_corp_sale_analysis_with_sly
WHERE group_code = '#{SL_UNIFIED_G_ID}'
    AND store_code IN (#{omShopCodes})
    AND settle_biz_date >= '2026-03-01'
    AND settle_biz_date < '2026-04-01'
GROUP BY store_name, store_code, city
ORDER BY SUM(busi_income) DESC
LIMIT 10;
```

**回答要点**：三亚/银川/杭州等旅游城市的门店通常营收较高，可体现门店分层。

```sql
    AND store_code IN (#{omShopCodes})
    AND settle_biz_date >= '2026-03-01'
    AND settle_biz_date < '2026-04-01';
```

**回答要点**：烧烤业态折扣率通常较低（5-10%），过高说明促销过度。

## Q07 — 3月份卖得最好的20道菜是什么？

**回答要点**：烧烤品类核心品项（如羊肉串/牛肉串/啤酒）的销售排行。

## Q08 — 3月份菜品各大类营收占比是多少？
**Intent**：Intent 43 — 菜品大类占比分析
**触发词**：「大类营收占比」「品类分析」「各类占比」

```sql
WITH t AS (
    SELECT
        big_class_name AS 大类名称,
        ROUND(SUM(income_money), 2) AS 纯收金额
    FROM dm.v_item_sale_analysis_with_sly
    WHERE group_code = '#{SL_UNIFIED_G_ID}'
        AND settle_biz_date >= '2026-03-01'
        AND settle_biz_date < '2026-04-01'
        AND last_qty > 0
    GROUP BY big_class_name
)
SELECT
    大类名称,
    纯收金额,
    ROUND(纯收金额 * 100.0 / SUM(纯收金额) OVER(), 2) AS 营收占比_pct
FROM t
ORDER BY 纯收金额 DESC;
```

**回答要点**：烧烤/酒水/凉菜等品类结构，烧烤通常占 40-60%。

## Q09 — 哪些菜毛利率最高？给我看毛利率最高的10道菜
**Intent**：Intent 46 — 菜品毛利分析
**触发词**：「毛利率最高」「哪道菜利润高」「毛利排行」

```sql
SELECT
    item_name AS 菜品名称,
    small_class_name AS 小类,
    ROUND(SUM(last_qty), 2) AS 销售数量,
    ROUND(SUM(income_money), 2) AS 纯收金额,
    ROUND(SUM(cost_money), 2) AS 理论成本,
    ROUND(SUM(income_money) - SUM(cost_money), 2) AS 折后理论毛利,
    ROUND((SUM(income_money) - SUM(cost_money)) / NULLIF(SUM(income_money), 0) * 100, 2) AS 折后毛利率_pct
FROM dm.v_item_sale_analysis_with_sly
WHERE group_code = '#{SL_UNIFIED_G_ID}'
    AND store_code IN (#{omShopCodes})
    AND settle_biz_date >= '2026-03-01'
    AND settle_biz_date < '2026-04-01'
    AND last_qty > 0
    AND cost_money > 0
GROUP BY item_name, small_class_name
ORDER BY (SUM(income_money) - SUM(cost_money)) / NULLIF(SUM(income_money), 0) DESC
LIMIT 10;
```

**回答要点**：酒水/自制饮品的毛利率通常极高（90%+），可作为利润引擎。

## Q10 — 哪些菜退得最多？有没有需要重点关注的？
**Intent**：Intent 45 — 菜品退菜明细分析
**触发词**：「退菜最多」「退菜率」「哪些菜被退回」

```sql
SELECT
    item_name AS 菜品名称,
    big_class_name AS 大类,
    ROUND(SUM(last_qty), 2) AS 实售数量,
    ROUND(SUM(return_qty), 2) AS 退菜数量,
    ROUND(SUM(return_subtotal), 2) AS 退菜金额,
    ROUND(SUM(return_qty) * 100.0 / NULLIF(SUM(last_qty) + SUM(return_qty), 0), 2) AS 退菜率_pct
FROM dm.v_item_sale_analysis_with_sly
WHERE group_code = '#{SL_UNIFIED_G_ID}'
    AND store_code IN (#{omShopCodes})
    AND settle_biz_date >= '2026-03-01'
    AND settle_biz_date < '2026-04-01'
    AND return_qty > 0
GROUP BY item_name, big_class_name
HAVING SUM(return_qty) > 0
ORDER BY SUM(return_subtotal) DESC
LIMIT 10;
```

**回答要点**：退菜率高的品项需关注出品质量或定价合理性。
