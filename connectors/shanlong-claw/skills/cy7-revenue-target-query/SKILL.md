# CY7 营收目标查询

## 使用场景

用户询问“本月有哪些营收目标”“查询某月某店营收目标”时使用本技能。先确认月份；指定门店时先通过门店搜索取得选择引用。

## 固定调用

所有查询通过连接器安装的 `sl-sea` 二进制和 AI Gateway 执行。`<sl-sea-absolute>` 是按当前系统运行规则解析出的绝对路径占位符；不要改用旧的 `sl`、`sl.cmd` 或开发版入口。

```text
<sl-sea-absolute> analytics get-department-pagelist --skill-ref cy7-revenue-target-query@1.0.174 --params '{"month":"2026-09","pageNo":1,"pageSize":20}' --format json
```

将示例月份替换为用户所问月份（`YYYY-MM`）；未指定月份时使用当前月份。指定门店时增加 `--selection-token <门店搜索返回的选择引用>`，不能提交原始门店 ID。未指定门店时由网关选择当前账号的默认授权 CY7 门店。`pageNo` 必须为 1～1000，`pageSize` 必须为 1～100，默认 20。接口不支持关键词筛选。

## 安全与输出规则

1. 只允许上述固定命令，不搜索或尝试其它 CY7 接口。
2. 门店组织节点、产品凭据和门店请求头由 AI Gateway 从当前授权范围注入；不得从本地文件、环境变量或历史回答读取原始 ID。
3. 只展示目标名称、目标值、周期、状态等业务必要字段。集团 ID、品牌 ID、门店 ID、用户 ID、手机号、卡号、身份证号、Token 等禁止展示。
4. 接口失败与合法空列表必须区分；失败时不伪造“没有目标”。
5. 不输出命令、原始 JSON、内部路径、请求头、鉴权信息或底层错误堆栈。
6. 当前页不等于全部数据；需要更多结果时按用户要求逐页查询，单页不得超过 100 条。
