# 法规关键词检索

使用连接器的 `get_law_list`，参数全部放在 `lawInput` 对象中。

## 输入

- 已知法规名称或标题词：使用 `Title`。正文中的主题词：使用 `Fulltext`。至少填写一个；同时填写时共同筛选。
- 关键词为连续字面文本，不是整段自然语言问题，不做语义扩展。正文仅匹配单个已入库正文块，跨块可能漏检。
- `StartImplementDate`、`EndImplementDate` 是施行日期范围，支持 `YYYY.M.D` 或 `YYYY-MM-DD`，包含边界。
- `Timeliness` 是中文时效性数组，例如 `["现行有效"]`；`Effectiveness` 是中文效力位阶数组，例如 `["法律"]`。按库内名称精确匹配，数组内任一值可命中，字段之间共同筛选。没有可靠标签时省略该筛选，不猜数字编码，也不把主题词填入时效性。
- 每次最多返回十个去重法规版本，无分页、集合选择、任意表达式或自定义返回数量。

示例：

```json
{"lawInput":{"Title":"行政处罚法","Timeliness":["现行有效"]}}
```

## 调用与结果

优先将筛选合并成一次调用，不并发批量检索。全局两次查询开始时间至少间隔三秒；收到 `rate_limited` 或 `busy` 时告知用户等待，不立即循环重试。超时或后端错误不当作无结果。

成功返回 `Message` 和 `Data`。依据 `Title`、`LawVersionID`、`IssueDepartment`、`IssueDate`、`ImplementDate`、`TimelinessDic`、`EffectivenessDic`、`RegionCode`、`RegionName` 展示法规列表；说明时效性来自库内标记。缺值如实保留。

结果不包含原文链接、发文字号、分类或完整正文；只引用实际返回的信息，不拼造链接或条文。排名不保证权威优先，也不代表所有匹配记录。空列表仅表示本次条件下未命中；建议调整条件时，应说明调整内容，不能静默放宽时效性。

401/403 表示需要检查连接器表单中的 MCP 访问令牌。请用户在密码输入框中更新，不要求在聊天中发送令牌。此工具仅提供检索参考，不生成确定性的法律结论。
