# 腾讯地图·指南制作 Skill

本 Skill 提供「腾讯地图行程指南」的完整制作与管理能力：根据用户的出行想法生成攻略、保存为地图行程指南，并支持后续查询、更新与删除。适合"帮我做一份 XX 几日游攻略""把这份攻略存到我的地图"这类需求。

## 指南数据格式转换

本 Skill 的核心能力之一是**指南数据格式转换**：把用户提供的自由文本 / Markdown 攻略内容，智能转换为腾讯地图可识别的**结构化行程指南数据格式**，再落库同步到用户的地图指南。转换过程包括：

- **地点解析与 POI 补全**：识别正文中的地点标注（形如 `[地点名](city=..&country=..&day=..&num=..)`），自动匹配并补全腾讯地图 POI 信息（坐标、类别等）。
- **分天 / 分段结构化**：将攻略按天、按行程段拆分为 `routes` / `routes_seg` 等结构化字段。
- **路线生成**：在保存时可同步生成行程路线（`sync_save_route`）。
- **格式兼容**：`markdown_content` 支持 Markdown（按服务要求可能需 Base64 编码后传入）或 JSON 原文两种形态，由服务端统一转换为内部结构。

因此当用户给出一段现成的攻略文本、或希望"把这段内容做成地图指南"时，本 Skill 会完成"文本 → 结构化地图指南数据"的转换与保存（见 `save_guide_ai` 与 `create_guide`）。

## 认证说明

- 本 Connector 使用标准 MCP OAuth 2.1（PKCE）认证，由 WorkBuddy 自动完成：首次使用或授权失效时会自动打开浏览器，引导用户用**微信扫码**关联腾讯地图账号。
- 授权成功后，WorkBuddy 会自动为每次工具调用注入访问令牌，**用户无需手动填写任何 Token**。
- 用户身份（`user_id`）由网关根据授权令牌自动注入，**调用工具时无需、也不应由 AI 填写 `user_id`**。
- 如遇 401 / 授权失效，请提示用户重新完成扫码授权。

## 使用建议

- 用户描述"做一份 XX 攻略/几日游/行程"时，优先使用 **create_guide**（一步生成并保存）。
- 用户已经有一段现成的攻略文本、希望"保存/同步到地图"时，使用 **save_guide_ai**。
- "看看/查询"已有指南用 **get_guide**，"改标题/内容"用 **update_guide**，"删掉"用 **delete_guide**。
- 行程指南 ID（travel_guide_id）通常形如字符串 ID，创建或查询后可获得，更新/删除时需带上。

## 可用工具

> 说明：以下参数为工具的业务入参；`user_id` 等身份字段由 WorkBuddy 网关按授权令牌自动注入，AI 无需填写。实际字段以工具运行时暴露的 schema 为准。

### create_guide — 创建行程指南（推荐入口）

根据标题与内容一步生成并保存一份行程指南，内部会调用 AI 生成、补全地点信息并落库。适合"帮我做一份 XX 攻略"。

**参数**：
| 参数 | 类型 | 必填 | 说明 |
|------|------|:----:|------|
| travel_guide_title | string | ✅ | 行程指南标题，如"北京三日游 · 经典深度指南" |
| travel_guide_content | string | ✅ | 行程内容正文（Markdown）。文中地点可用 `[名称](city=..&country=..&day=..&num=..)` 形式标注，系统会解析并补全 POI 信息 |
| travel_guide_id | string | - | 目标行程指南 ID；用于把生成结果写回指定指南。新建可留空由系统分配 |

### save_guide_ai — 保存 AI 攻略内容

将一段现成的攻略/行程文本通过 AI 能力保存为行程指南，支持"仅校验能否保存"模式。适合用户已有攻略文本、想直接同步到地图的场景。

**参数**：
| 参数 | 类型 | 必填 | 说明 |
|------|------|:----:|------|
| user_query | string | ✅ | 用户的原始需求或标题 |
| markdown_content | string | ✅ | 攻略正文内容（Markdown 文本；按服务要求可能需 Base64 编码后传入） |
| is_check | boolean | - | 为 true 时仅校验该内容能否保存为行程指南（不落库）；默认 false 表示真正保存 |
| sync_save_route | boolean | - | 是否同步保存路线，默认 true |

**返回**：成功时返回生成的行程指南 ID（`travel_guide_id`，多方案时返回 `travel_guide_ids` 列表）；`is_check` 模式返回是否可保存。

### get_guide — 查询行程指南

根据行程指南 ID（或城市码）查询指南的完整信息。

**参数**：
| 参数 | 类型 | 必填 | 说明 |
|------|------|:----:|------|
| travel_guide_ids | string[] | - | 行程指南 ID 列表（与 city_codes 至少提供一项） |
| city_codes | string[] | - | 城市码列表（与 travel_guide_ids 至少提供一项） |
| guide_status | number[] | - | 按行程状态过滤 |

### update_guide — 更新行程指南

更新一份已存在的行程指南（整体覆盖式更新，需提供完整的指南对象）。

**参数**：
| 参数 | 类型 | 必填 | 说明 |
|------|------|:----:|------|
| travel_guide | object | ✅ | 完整的行程指南对象，至少含 `travel_guide_id`；可更新 `title`、`sub_title`、`brief`、`cover`、路线等字段 |

### delete_guide — 删除行程指南

删除指定的行程指南。

**参数**：
| 参数 | 类型 | 必填 | 说明 |
|------|------|:----:|------|
| travel_guide_id | string | ✅ | 要删除的行程指南 ID |

## 注意事项

- 创建/保存攻略后，请把返回的 `travel_guide_id` 告知用户，便于后续查询、更新或删除。
- 更新为整体覆盖式：建议先用 get_guide 拿到当前指南对象，改动后再调用 update_guide，避免遗漏字段。
- 删除操作不可逆，执行前请与用户确认。
- 所有操作都在用户已授权的腾讯地图账号下进行，生成的内容会同步到用户的「地图指南」。
