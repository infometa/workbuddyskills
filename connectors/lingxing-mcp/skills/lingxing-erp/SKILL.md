# 领星ERP

通过领星ERP MCP 获取当前账号权限范围内的跨境电商业务数据，并使用 MCP Server 返回的工具参数定义发起调用。

## 工具用途

- 店铺：查询 ERP 店铺、多平台店铺和广告授权店铺。
- 库存与商品：查询 FBA 库存、补货建议和 Listing。
- 经营分析：查询产品表现、MSKU 利润、订单利润和自定义报表。
- 广告：查询 Amazon 和 Walmart 的广告活动、广告组、广告商品、投放、关键词和搜索词报告。
- 运营监控：查询或新增关键词排名、跟卖、店铺和竞品监控。
- 自定义指标：查询字段和指标，新增或更新自定义指标。

## 使用说明

- ERP 店铺类查询使用工具返回的 `sid`；Amazon 广告查询使用 `ad_auth_shops` 返回的 `profile_id`。
- 按工具参数要求传递日期、分页、排序和筛选条件。
- 数据为空或报错时，原样说明接口结果，不推测不存在的数据。
- 如果提示 `X-Mcp-Key` 无效或过期，引导用户进入领星ERP「AI助手 > 管理MCP」重新生成或复制鉴权密钥，然后在 WorkBuddy 中更新连接配置。
