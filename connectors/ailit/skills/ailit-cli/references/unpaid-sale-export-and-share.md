# 批量未结清销售单导出与分享

## 何时读取

只有用户要求完成“指定客户未结清销售单查询”之后的批量打印、下载、整理或微信分享时读取本文件。

不要为以下简单请求读取：

- “查张三今天的销售单金额。”
- “查张三本月未结清销售单。”
- “获取这张销售单的PDF。”（已知数字单据ID时直接用 `sale print pdf`）

本场景只查询和导出，绝不修改销售单收款状态。

## 识别交付目标

提取客户、日期范围、输出格式、保存目录、文件命名和微信分享要求。

- “本月”解析为当月1日至最后一天。
- “未结清”只映射为 `--pay-status unpaid`。
- 不得因为示例话术出现“结清”而创建收款或修改状态；明确要求修改状态时停止并说明不属于本流程。

## 确认客户

`sale list --customer` 多匹配时可能按最近销售单择优。为避免静默选错，先运行：

```powershell
ailit customer search "张三" --format json
```

- 零结果：请用户补充关键词。
- 唯一结果：使用确认后的 `displayName`。
- 多结果：展示 `selectToken`、名称、电话和当前欠款等字段，等待用户选择。
- 多个完全同名客户且 `sale list` 无法按客户ID筛选时，说明当前限制，不要假装唯一命中。

## 查询未结清销售单

```powershell
ailit sale list --customer "张三" --pay-status unpaid -s 2026-08-01 -e 2026-08-31 --format json
```

处理结果：

1. 零条：说明日期范围内没有未结清销售单。
2. 一条或多条：记录数字单据ID、单据编号、日期和客户名称。
3. 后续 `print` 和 `share` 使用数字ID，不使用单据编号。
4. 超过一页时继续处理分页，或明确提示结果未覆盖全部数据。

## 批量生成图片或 PDF

逐张销售单执行用户要求的格式：

```powershell
ailit sale print image <单据ID> --format json
ailit sale print pdf <单据ID> --format json
```

命令返回 URL；取得 URL 后下载并验证文件。默认文件名：

```text
<客户名称>_<单据编号>.png
<客户名称>_<单据编号>.pdf
```

默认一张销售单对应一个文件，不擅自合并。目标文件重名时不得静默覆盖。

## 微信分享

```powershell
ailit sale share <单据ID> -o <二维码保存路径>
```

该命令返回分享凭证、链接和微信小程序码，不会直接发送给微信联系人。

- 宿主具备微信发送能力，且用户明确了收件对象时，才使用宿主能力发送。
- 宿主没有发送能力时，把链接、二维码或本地文件交付用户自行发送。
- 客户与微信联系人不能唯一对应时必须让用户选择。
- 没有发送成功回执时不得回复“已发送到微信”。

## 验证与汇总

- 核对每个文件对应的客户和单据编号。
- 文件存在且大小大于0后才算下载成功。
- 记录查询单据数、生成成功数、下载成功数、分享成功数及失败项。
- 单项失败可以继续处理其他单据，但不要自动重试。
- 最终回复列出日期范围、客户、单据、格式、路径或分享产物。

## 场景示例

会触发：

- “查询张三本月所有未结清销售单，每张生成PDF并保存到这个文件夹。”
- “把张三未结清销售单按单据逐张生成图片，然后准备微信分享。”

不会触发：

- “张三今天有多少销售额？”
- “查张三所有未结清销售单。”
