# 根据文字或图片创建销售单

## 何时读取

用户提供自然语言订货明细、聊天记录、纸质单据图片或其他非结构化内容，并要求生成销售单草稿、预览或创建销售单时读取。

不要为以下请求读取：

- 查询已有销售单、金额或详情。
- 已知数字单据ID后获取图片/PDF。
- 用户已经提供完整、已校验的销售单 JSON，只要求执行一次基础试运行。

用户只要求预览时停在试运行阶段。

## 提取输入

从文字或图片中提取：

- 客户名称；未指定时保留为空，由 CLI 回退到内置零售客户。
- 商品名称、规格、条码或编号等线索。
- 数量；未提供时默认1。
- 用户明确给出的单价；未提供时交给 CLI 解析。
- 结算方式：全额结算或挂账。
- 日期、运费、备注和交货信息等可选字段。

标记图片中的模糊、冲突或低可信字段。商品名称不能可靠识别时必须询问，不得用相似商品代替。

## 解析客户和商品

客户规则：

- 指定客户时优先在草稿中写 `customer: {"name":"<名称>"}`，由 CLI 解析ID。
- 多客户候选时按 `SKILL.md` 的选择规则消歧。
- 未指定客户时完全省略 `customer`；不要写 `id: 0`。
- 不得把名称、手机号或其他非数字内容写入 `customer.id`。

逐行搜索商品：

```powershell
ailit product search "<商品关键词>" --format json
```

确认后使用：

- `meta.productId` → `lines[].productId`
- `meta.productSkuId` → `lines[].productSkuId`
- `displayName` → `lines[].productName`
- `meta.retailPrice` → 价格参考

必要字段齐全时不要重复调用 `product get`。

商品不存在时暂停销售单流程并询问是否创建。创建前先用更宽的关键词再搜索一次，确认商品确实不存在。用户同意后由 `SKILL.md` 路由到商品创建 Reference；创建完成后重新搜索真实ID，再返回本流程。用户不同意时移除该行或请求替代商品。不得编造商品ID。

## 构建草稿

复制相应模板到临时文件后再填写：

- 全额结算：`templates/sale-quick-create-full.json`
- 挂账：`templates/sale-create-on-account.json`

不得修改模板原文件，也不得直接执行未替换示例值的模板。

CLI 默认值：

- `shopId`：`DefaultShopID`
- `warehouseId`：`DefaultWarehouseID`
- `operatorId`：`DefaultOperatorID`，再回退到认证用户UID
- `billDate`：当天
- `quantity`：1
- `unitPrice`：最新报价 > 零售价 > 0.00；零售客户跳过报价
- `settlement.mode`：省略时为 `FULL`
- `accountId`：`FULL` 时尝试解析现金优先账户；`ON_ACCOUNT` 不使用账户

每个商品行必须包含真实、非空数字字符串形式的 `productId` 和 `productSkuId`，并填写 `productName`。

## 试运行与预览

```powershell
ailit sale create --json <临时草稿文件> --dry-run
```

向用户展示客户、业务员、日期、结算方式、账户、运费、交货信息、商品明细、数量金额汇总和总金额。展示前检查 CLI 解析出的客户名称及所有商品、数量和金额。

当前 `--dry-run` 输出文字表格，不生成正式销售单图片：

- 文字表格是创建前的权威预览。
- 宿主可渲染图片时标注“草稿预览，非正式销售单打印件”。
- 创建前不得调用 `sale print image`，也不得为了获得正式图片而先创建。

## 确认与创建

用户最初说“直接创建”或“没问题就保存”也不能代替预览后的确认。只有看到本次预览后回复“确认”，才执行：

```powershell
ailit sale create --json <临时草稿文件>
```

用户要求修改时更新草稿、重新试运行并重新确认。仅要求预览、未确认或否定时不创建。

## 失败处理

- 成功后优先返回单据编号、客户和金额，不主动暴露内部ID。
- 创建失败时报告 CLI 错误并停止，不自动重试。
- 只有创建成功取得数字单据ID后，才能获取正式图片/PDF。
- 不展示令牌、内部支付记录或无关隐私字段。

## 场景示例

会触发：

- “我发一张客户订货单照片，你识别后给我生成销售单预览。”
- “根据下面这段订货文字开销售单，先让我确认再保存。”

不会触发：

- “查询今天的销售单。”
- “获取单据12345的PDF。”
