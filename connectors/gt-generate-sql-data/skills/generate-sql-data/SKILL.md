# GenerateSQL 智能数据查询

使用此连接器回答用户关于业务数据的自然语言问题。服务端会根据当前登录用户身份生成只读 SQL、施加部门和租户权限过滤，并执行查询。

## 使用规则

1. 用户提出数据查询、统计、趋势、分类对比或业务明细需求时，调用 `query_database_data`。
2. 将用户的原始自然语言问题逐字填入 `original_user_input`；不要改写成 SQL、补充假设、扩大时间范围，或传入你的分析过程。
3. 一次 `query_database_data` 调用即为该问题的最终查询。收到结果后直接展示结果正文、表格和“下载完整结果”链接；不要为验证、解释或排查而自动再次查询。
4. 0 条记录、空表或指标为 0 是有效结果。如实说明没有匹配数据，不能自行改查相邻月份、其他年份或全量数据。
5. 仅当用户明确要求查看上一条聚合结果中某一行、某一指标的明细，并且上一条结果提供了下钻上下文时，调用 `drilldown_query`。必须原样使用上一结果中的 `queryId`、完整 `row` 和 `metric`。
6. 如结果中带有 `[下载完整结果](...)` 链接，必须原样保留。不要用其他工具重建 CSV、Excel 或下载文件。

## 展示建议

- 普通明细、单一指标或数据量很少时，直接展示查询结果即可。
- 仅在用户明确需要图表，或结果是时间趋势、分类比较、占比分布时，才基于本次返回的真实表格数据生成图表。
- 图表标题、图例、字段和数值必须忠实于返回数据，不能推断或补造数据。

## 数据边界

- 此连接器只执行只读查询，不应用于写入、删除、更新或修改数据库结构。
- 返回的下载链接默认有效期为 15 分钟；提醒用户及时下载即可。
