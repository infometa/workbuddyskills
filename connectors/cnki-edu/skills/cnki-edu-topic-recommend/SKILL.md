# cnki-edu-topic-recommend（WorkBuddy 版 · 可公开发布 · 中小学定向）

知网 edu 中小学教研选题推荐技能。面向 **K-12（小学/初中/高中）教师、教研组长、学科带头人、名师工作室** 等基础教育教研工作者，基于 CNKI 基础教育文献数据，以「方向探索 → 深度聚焦 → 价值评估 → 确定方向」四阶递进式方法论，为教研选题提供从启蒙到落地的全流程智能推荐与评估。支持首轮广谱推荐、多轮细化聚焦、单选深入评估与双选对比分析。

## 发布说明与前置依赖

- **适用人群（明确聚焦）**：K-12 中小学教师、教研组长、备课组长、学科带头人、名师工作室成员、区县教研员等基础教育教研工作者。本技能**不面向**高校硕博学术科研选题（此类需求请用通用学术选题技能）。
- **典型产出场景**：区级/市级/省级教育科学规划课题与小课题申报、教学论文撰写、校本教研案例、教学设计/公开课/优质课、作业设计、新课标/核心素养落地实践、大单元教学、项目式学习（PBL）、跨学科主题学习、学业评价改革等。
- **前置依赖（必读）**：本 skill 的文献检索统一通过 **「知网 edu」MCP 连接器**（CNKI 基础教育 / 研学文献检索）完成，且须账号具备「知网基教」权益（`mcp__<SERVER>__userState` 返回 `true`）方可生成选题 / 评估内容。未连接连接器或未通过权益校验时，**按「前置权限校验」强制中止、不生成任何内容并输出转化卡，不降级、不给出通用建议**（降级策略仅适用于"已通过校验后"检索临时失败，见下方说明）。
- **工具名前缀说明**：WorkBuddy 中 MCP 工具名格式为 `mcp__<SERVER>__<工具名>`。本环境中该连接器显示名为 `edu`，故文献检索工具为 `mcp__<SERVER>__searchVectorBJ`；若你的环境中连接器显示为其他名称（如「知网基教」），前缀会相应变化，请按实际可用工具名调用。下文统一以 `mcp__<SERVER>__searchVectorBJ` 指代。
- **降级策略（仅限已通过权限校验之后）**：MCP 未连接或检索返回为空时，按「2.3 子程序」容错规则将文献变量置空并标注"未基于知网实时数据"，仍可给出通用选题建议（失去文献佐证）。**注意：本降级策略与「前置权限校验」是两件不同的事——`mcp__<SERVER>__userState` 返回 `false`（无基教权益）不属于降级范围，而是强制中止，严禁用任何替代方法生成结果（见上第 3 条）。**
- **提示词加载**：选题 / 评估所需的提示词模板存放于 `references/` 目录，运行时通过 WorkBuddy 的 **Read 工具**按需加载（硬性前置，见步骤 0）。**注意：模板加载（步骤 0）必须在「前置权限校验（mcp__<SERVER>__userState）」通过后执行；未通过权益校验时禁止加载任何模板、禁止生成内容。**

## 2. 核心配置

### 2.1 文献检索接口（知网 edu MCP）

> 所有文献检索统一调用「知网 edu」MCP 连接器的 `mcp__<SERVER>__searchVectorBJ` 工具（按文本向量检索 CNKI 基础教育文献库，返回文献列表）。

**工具名**：`mcp__<SERVER>__searchVectorBJ`

| 参数 | 类型 | 必填 | 说明 |
|:---|:---|:---|:---|
| `text` | string | ✅ | 检索文本。通常为 `FETCH_LITERATURE` 提取并拼接的 3 个核心关键词，或用户给定的研究方向短语 |
| `maxRecallNumber` | integer | 否 | 最大返回文献数，默认 20；本 skill 统一取 50 |
| `query_type` | integer | 否 | 查询类型：0 篇名 / 1 摘要 / 2 小标题 / 3 主题。选题发散推荐用 **3（主题）** 最合适；也可按场景选 0/1/2 |
| `type` | string | 否 | 文献类型：0 期刊 / 1 硕士 / 2 博士 / 3 会议 / 4 报纸，多值用逗号隔开。本技能统一取 `"0,1,3"`（覆盖基础教育期刊 + 学科教学硕士 + 教研会议），**不选博士（2）** 以免偏理论，可按需追加 `4`（报纸） |

**返回**：文献条目列表，每条含篇名、正文（摘要）、小标题、文件名、url、DOI、来源（期刊名/会议/授予单位）、年份、作者等字段（**不返回卷、页码**）。其中 `文件名` 为 CNKI 内部编号（形如 `<刊码+年份+期号+序号>`），**禁止直接写入用户可见产出，引用一律使用 `篇名`**（见 R11）；`url` 为 CNKI 在线阅读链接，可写成可点击形式 `[篇名](url)` 便于溯源（见 R12）。

**容错**：返回为空或报错时，将文献变量置空，标注"未基于知网实时数据"。

### 2.1.1 课标原文接口（知网 edu MCP · mcp__<SERVER>__standardSearch）

> 凡生成"新课标/课标"类表述，优先从此接口取**逐字原文**（见 R15、子程序 `FETCH_STANDARD`）。该接口按向量检索标准文档（课标/教材等），返回命中的文档块正文 + 元数据。

**工具名**：`mcp__<SERVER>__standardSearch`

| 参数 | 类型 | 必填 | 说明 |
|:---|:---|:---|:---|
| `query` | string | ✅ | 检索文本。通常传入与选题相关的课标查询短语，如"化学 核心素养 科学探究与实践""家庭实验 教学建议""做中学 用中学 创中学" |
| `topK` | integer | 否 | 返回数量，默认 10；本 skill 统一取 5 |
| `minScore` | number | 否 | 最低相关性阈值，默认 0.3；低于此值的结果被过滤。本 skill 保留默认 0.3 |

**返回**：命中块列表，每条含 `content`（课标逐字正文片段）、`score`（相关性，0~1）、`metadata`（`title` 标准名、`curriculumStandardId`、`chunkIndex`、`chunk_total` 等）。

**解析与引用规范**：
- 取 `score ≥ 0.3` 的块作为权威原文；引用时在产出中**直接引用其逐字短语并注明出处**，格式：`《标准名（版本）》"章节名"`（如 `《义务教育化学课程标准（2022年版2025年修订）》"课程理念4"`）。
- 接口正文版本显示为 **"2022年版2025年修订"**（日常修订版），引用统一用此版本表述。
- **接口无 `url`/页码字段，禁止虚构页码或条目号**；只能用标准名 + 章节名定位。
- 多套标准并存（不同学科对应不同的内部标准 ID，例如化学 / 生物 / 课程方案等，实际值以接口返回为准），查询时应带学科名以提升命中精度。

**容错**：返回空或全低于阈值时，按 R15 回退互联网（WebSearch）检索官方课标并标注"课标导向（待官网核实）"。

### 2.2 状态与变量

#### 2.2.1 全局状态（会话内维护）

```json
{
  "session_id": "<自动生成>",
  "current_step": "intro",
  "all_topics": [],
  "topic_counter": 0,
  "topic_id_mapping": {},
  "current_round": 1,
  "max_rounds": 4,
  "history": [],
  "final_topic": null,
  "evaluation_result": null
}
```

| 字段 | 说明 |
|:---|:---|
| `current_step` | 当前步骤：`intro` / `collecting` / `recommending` / `refining` / `evaluating` / `done` |

| `topic_id_mapping` | 编号分配记录，如 `{"1":"首轮-选题名","11":"第2轮-来自#1-选题名"}` |

| `history` | 交互历史 `{step, user_input, system_response_summary}` |
| `final_topic` | 最终确定选题，初始 null |
| `evaluation_result` | 评估结果，初始 null |

#### 2.2.3 文献检索变量

| 变量 | 产出步骤 | 描述 |
|:---|:---|:---|
| `USER_LITERATURE` | 步骤2 | 用户关键词对应的文献数据 |
| `REFINE_LITERATURE` | 步骤3 | 细化方向对应的文献数据 |
| `EVAL_LITERATURE` | 步骤4 | 评估选题的文献数据，键为选题ID；对比评估时取 `EVAL_LITERATURE_A` / `EVAL_LITERATURE_B` |
| `STANDARD_LITERATURE` | 步骤2/3/4 | 选题/评估涉及的课标逐字原文块（来自 `FETCH_STANDARD` 子程序，基于 `mcp__<SERVER>__standardSearch`），用于第3、7（及评估"课标契合度"）部分的"新课标/课标"表述，作为唯一权威依据 |

#### 2.2.4 编号规则

> 用于保证推荐/细化选题在输出时编号连续、全局唯一。

| 规则 | 内容 |
|:---|:---|
| **NR1** | `topic_counter` 是会话内全局唯一编号源，初始值为 0，永不回退 |
| **NR2** | 每生成一个新选题，必须先执行 `topic_counter += 1`，再使用该值作为选题编号 |
| **NR3** | 首轮推荐的 NUM 个选题，编号从 **#1** 开始，依次为 **#1, #2, #3, ..., #NUM**，必须连续 |
| **NR4** | 细化推荐的 5 个选题，编号从当前 `topic_counter + 1` 开始，依次为 **#(N+1), #(N+2), #(N+3), #(N+4), #(N+5)**，必须连续 |
| **NR5** | 多次细化过程中，编号继续递增，不重置、不复用、不跳号 |
| **NR6** | 用户触发"重新推荐"时，重置 `topic_counter = 0`、`all_topics = []`，新推荐从 #1 开始 |
| **NR7** | 输出列表时，必须按编号升序排列，不可打乱顺序 |

### 2.4 子程序：INJECT_LINKS

> 产出写盘后，把所有文献引用统一注入可点击的知网在线阅读链接，并做覆盖率校验（**R12 强制**）。这是产出交付前的最后一道关卡，不可跳过。
> 配套脚本：`scripts/inject_cnki_links.py`（本技能自带，无需额外依赖，兼容 Python 3.8+）

**为什么需要它**：写作时容易只在表格里带链接、正文里留裸名，或遗漏后续补充的文献；人工逐条补 URL 既慢又容易拼接出错。该脚本从检索结果反向建立「篇名 → url」映射，只注入**确实检索到**的文献，杜绝编造链接。

**入参**

| 参数 | 说明 |
|:---|:---|
| `report` | 产出 Markdown 文件路径 |
| `--results` | `mcp__<SERVER>__searchVectorBJ` 检索结果来源，**可多个、可为目录**（工具输出过大时会被持久化到 `tool-results/*.txt`，该文件即此处输入） |
| `--exclude` | 不参与注入的《》名称：课标标准名（如《义务教育语文课程标准》）、阅读作品书名（如《西游记》《宝葫芦的秘密》） |
| `--check-only` | 只校验不改写，用于交付前复核 |
| `--dump-map` | 只导出「篇名 → url」映射，供生成报告前查看本次可链文献清单 |

**执行步骤**

| 步骤 | 操作 | 说明 |
|:---|:---|:---|
| 1 | 保留检索原始返回 | `mcp__<SERVER>__searchVectorBJ` 每条含 `url` 字段即在线阅读页；工具输出被截断/持久化时，记下 `tool-results` 目录路径 |
| 2 | （可选）生成前先 `--dump-map` | 提前掌握可链文献清单，写作时直接带上链接 |
| 3 | 产出写盘后执行注入 | `python scripts/inject_cnki_links.py <报告.md> --results <检索结果> --exclude <课标名/作品名>` |
| 4 | 读校验输出 | 脚本会打印：解析出多少条映射、新注入几处、**仍未覆盖的裸露《》清单**、报告内链接总数 |
| 5 | 逐条确认残留 | 残留是文献名 → 说明漏链，补检索后重跑；残留是课标标准名或作品书名 → 加入 `--exclude` 重跑 |
| 6 | 通过标准 | 残留清单为空，或仅含已确认的非文献名称 |

**硬约束**

- **只注入映射中确实存在的篇名**，禁止凭记忆或按刊码规律拼接 URL（违反即 R12 违规）
- 引用文字始终是 `篇名`，**禁止**把 `文件名`、`DOI` 等内部字段写进产出（R11）
- 已带链接的引用不会被重复包裹，可安全重复执行

**命令行示例**

```bash
# 生成前：查看本次可链文献
python scripts/inject_cnki_links.py --dump-map --results <tool-results目录>

# 写盘后：注入 + 校验
python scripts/inject_cnki_links.py 选题建议.md \
  --results <tool-results目录> \
  --exclude "《义务教育语文课程标准》" "《西游记》" "《宝葫芦的秘密》"

# 交付前复核（不改写）
python scripts/inject_cnki_links.py 选题建议.md --check-only --results <tool-results目录> --exclude "..."
```

- [ ] 已保留 `mcp__<SERVER>__searchVectorBJ` 原始返回（含 `url` 字段）
- [ ] 注入脚本已执行
