# 资料检索与配图策略（步骤 3）

本文件定义第三步"联网检索文字资料 + 配图"的执行细则。文字资料仍走联网检索；**配图统一由 ImageGen 生图提供（本技能的 PPT 渲染工作流 明确取消"搜图"，配图只能来自 ImageGen 或 SVG）**，并采用"配图前置 + L1/L2/L3 分级"。

## 一、文字资料检索（保留联网）

- 工具：WebSearch / WebFetch。优先权威来源（官网、学术期刊、政府/教育机构、百科条目）。
- 每页要点对应 1–3 条可引用内容；内部留档只在 `STORY.md` 记**来源名称（机构/平台/期刊名）+ 标题**，**严禁落 URL / 域名 / 网页地址**（STORY.md 属中间产物，不得出现链接地址、检索语句或查询原文）。
- 不编造数据、定义、人名。检索不到的内容用"通用常识 + 注明待核实"处理，不要伪造。
- 同一概念多源交叉验证；数值、年份、比例须有出处。

## 二、配图：ImageGen 生图前置 + L1/L2/L3 分级

> **取消搜图**（本技能的 PPT 渲染工作流 强制）：配图**只来自 ImageGen 生图或 SVG**，禁止联网搜图、禁止引用在线图片 URL / `image://` 占位符。用户明确提供的材料图/品牌图/人物场景图可复制到 `assets/` 后使用。

### 2.1 配图前置（写每页前，强制）

循环到某一页时：

1. **先生成该页所需图**：按 `DESIGN.md` 配图清单，调用 **ImageGen** 生成该页的 L1/L2 图（prompt 必须含：主体 + 场景 + 构图 + 风格 + 色彩 + 禁忌）。
2. **逐张 Read 核对**：确认四件事——内容正确、比例可用、清晰不糊、风格全篇统一（同一视觉类型，禁止摄影/插画/3D 混用）。生图返回顺序常与 prompt 错位，**必须逐张 Read 真实内容后再重命名**，禁止按时间戳盲映射。
3. **落盘 `assets/`**：文件名英文短名（禁中文/空格），如 `scene_chloroplast.png`。
4. **再写该页 SlideDSL**：在 `.slide` 中用 `<Image src="assets/xxx.png" ...>` 引用。

**严禁先写 JSX 占位后补图**——会导致布局比例与图片不匹配。

### 2.2 三级分类（L1/L2/L3）

| 等级 | 用途 | 最小尺寸/占比 | 接入方式 |
|---|---|---|---|
| **L1 · 主视觉** | 承担页面主要叙事 | B 内容区 ≥40%（常见 560×420 / 半屏） | 封面主图、章节过渡主图、左右图文主图、卡片整体背景 |
| **L2 · 支撑图** | 强化某段落 | ≥280×180 | 段落旁、卡片头部、与正文并排 |
| **L3 · 母版徽标** | 全篇统一角标 | ≤64×64 | 页脚条 C 区左侧或印章位，全篇位置固定 |

严禁把 200×70 小图塞进标题块右侧当装饰；不同页 L3 位置须固定；全篇 L1 视觉类型须一致。

### 2.3 生成失败兜底（绝不中断）

- ImageGen 最多重试 2 次；仍不合格才允许 **SVG 兜底**（仅限流程图/时间轴/矩阵/图表底图/巨型数字等结构化低语义元素，见 `component-svg.md`），并在 `DESIGN.md` 配图清单记录失败原因。
- **务必生图的 L1/L2** 只有在 ImageGen 2 次重试仍不符合时，才允许 SVG 兜底；禁止用几个圆/线冒充具象主视觉。
- 完全无图时该页退化为纯文字版式。

> **严禁向用户确认是否生图**：检索优先已取消，生图是默认动作；判定需要配图时**直接调用 ImageGen 生成**，不要询问用户、不要在确认卡片出现"生成图片/是否生图/配图确认"等字样。整步在步骤 3 内一次性完成。

> **绝不中断 PPT 生成**：无论 ImageGen 成功/失败/SVG 兜底/完全无图，都**不得中断或回退** PPT 生成流程。缺图时对应页退化为同主题纯文字/SVG 版式（如 image_right→text），流程继续直至产出 `.pptx`。

## 三、图片合规与风格要求

- 配色与步骤 1 选定风格一致；低饱和、简洁，避免花哨；全篇同一视觉类型（插画/3D/摄影）统一。
- 图片不得自带页面需精确控制的文字/Logo；需精确文字时用干净背景图 + Slide 文本叠加。
- 每张内容页配图 ≥1 张（L1/L2），封面/过渡/总结页可配主题图；不堆砌，单页图数 ≤3、总面积 ≤内容区 60%。
- 禁止用通配符删除 `assets/` 图片；替换时优先覆盖明确文件，确需删除逐个指定路径。

## 四、步骤 3 执行说明（无中途确认）

步骤 2 确认后直接进入本步骤，不再向用户确认。按以下计划直接执行：
- 资料检索范围：官网/学术/百科等权威来源；允许联网内容，文字须标注来源。
- 配图策略：ImageGen 生图前置（写每页前先生成本页图→核对→落 assets→再写页）；**禁止搜图、禁止确认、绝不中断**；L1/L2/L3 分级；缺图退化为文字/SVG 版式。
- 关键页内容要点：依据确认后的大纲逐页填充真实内容，并按语义选用多样版式（图文/卡片/时间轴/对比/数据大字/表格/引言/双栏），保证内容丰富。
- PPT 渲染：按本技能内置 PPT 渲染工作流执行（见 `generate-pptx-tencent.md`）。
- 知网推荐：调用 `edu` MCP 的 `mcp__<SERVER>__searchVectorBJ` 检索最多 6 篇相关文献，于最终交付时**紧接 PPT 卡片下方直接展示**；每条**仅展示文献名、作者、来源三项文字**，**严禁在可见文案中暴露知网任何元数据**（发表时间、卷期、doi、数据库名、检索语句、内部 id、链接地址明文等一律不可见），**仅文献名可点击**且**带跳转链接**、点击**一次直达该篇在知网研学平台的研读页面**（**直接取用检索接口返回的 `url` 字段，原样使用**），且**不附带悬停提示**（**保点击跳转、放弃悬停提示**）（不进入 PPT，且**不暴露任何检索原始细节**）。详见 `cnki-guide.md`。
