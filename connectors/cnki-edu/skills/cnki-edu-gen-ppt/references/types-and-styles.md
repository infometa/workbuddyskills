# PPT 类型、风格与基础信息

本文件供步骤 1 使用：识别 PPT 类型、匹配风格与默认页数、收集基础信息。

## 一、PPT 类型清单

按用户意图归类（可多选或自定义"其它"）。每个类型给出**默认页数区间**与**典型结构**，仅作起点，用户可覆盖。

| 类型 | 适用场景 | 默认页数 | 典型结构（一级章节示意） |
|---|---|---|---|
| 教学课件 | 中小学/培训课堂授课 | 12–18 | 课标导入 → 知识讲解(多章) → 例题/活动 → 小结 → 作业 |
| 工作汇报 | 周/月/季度/年度汇报 | 10–15 | 工作概览 → 成果展示 → 问题与挑战 → 下阶段计划 |
| 教研分享 | 教研组/公开课经验交流 | 12–16 | 研究背景 → 方法路径 → 实践案例 → 成效反思 |
| 班会主题 | 班级德育/主题活动 | 8–12 | 主题引入 → 现象/故事 → 讨论互动 → 行动倡议 |
| 活动策划 | 校园/机构活动方案 | 10–14 | 活动背景 → 目标 → 流程 → 分工 → 预算/风险 |
| 产品介绍 | 产品/项目宣讲 | 10–14 | 痛点 → 方案 → 功能亮点 → 案例 → 行动号召 |
| 其它 | 用户自定义主题 | 10–15 | 由用户指定或按主题自拟 |

> 类型识别不明确时，给出 2–4 个候选供选择；不要默认假设。

## 一·补：主题 → 模板自动映射（步骤 1 自动匹配，无需用户设计）

依据主题/类型**自动选定风格预设与版式组合倾向**，作为确认卡片中的"推荐风格/版式倾向"呈现（不暴露内部实现名词）。映射为起点，用户可覆盖。

| 类型 | 推荐风格 | 版式组合倾向（内容页轮换使用） |
|---|---|---|
| 教学课件 | 清新绿 | 图文右图、卡片、时间轴、引言、双栏 |
| 工作汇报 | 商务蓝 | 数据大字、对比、图文、表格、时间轴 |
| 教研分享 | 科技紫 | 图文、对比、时间轴、表格、引言 |
| 班会主题 | 中国风/卡通风 | 引言、卡片、图文、时间轴 |
| 活动策划 | 商务蓝/清新绿 | 时间轴、卡片、表格、图文 |
| 产品介绍 | 科技紫 | 数据大字、卡片、对比、图文 |
| 其它 | 简约白（或按主题自拟） | 依内容语义从下方版式中自选 |

**主题微调**：如主题明显偏"数据/成果"则在组合中提高"数据大字/表格"权重；偏"叙事/德育"则提高"引言/时间轴/卡片"权重。

## 二、页面类型与配比（五类页面）

一份完整 PPT 由以下五类页面构成，以**内容页为主体**分配篇幅：

| 页面类型 | 作用 | 出现位置 | 是否必需 |
|---|---|---|---|
| 封面 | 主题与风格定调，一句话点题 | 第 1 页 | 必需 |
| 目录页 | 列出一级章节导航 | 封面之后 | 通常必需（≤12 页可省，直接进内容） |
| 过渡页 | 章节分隔/转场，标注章节名 | 章节之间 | 按需，可省去 |
| 内容页 | 承载知识点/数据/论点，主体 | 目录后至尾页前 | 必需（主体，占比最高） |
| 尾页 | 总结核心结论与要点回顾 | 末页 | 必需（即"总结页"） |

原则：**内容优先**——过渡页、目录页等"框架页"服务于内容，不喧宾夺主；章节较少或页数偏紧时，省去过渡页、以内容页直接推进；尾页为固定总结页（文献推荐不进入 PPT，不单独成页）。

## 三、风格预设（默认低饱和、简洁统一）

配色克制、与页面整体一致；分类标识统一用 **tag/badge** 样式。下方为可选预设，用户可指定或自定义：

| 风格 | 主色（低饱和） | 点缀色 | 适用类型 |
|---|---|---|---|
| 简约白 | #F7F8FA 底 / #2B2F36 字 | #6B7280 | 通用、工作汇报 |
| 商务蓝 | #EAF1F8 底 / #2C4A6E 字 | #4A7AB5 | 工作汇报、产品介绍 |
| 清新绿 | #EDF5EE 底 / #2F4A3A 字 | #5E8C6A | 教学课件、班会 |
| 科技紫 | #F1EDF8 底 / #3B2F4A 字 | #7A5FA5 | 产品介绍、教研 |
| 中国风 | #F5F1E8 底 / #3A3327 字 | #9C7A4A | 班会、文化主题 |
| 卡通风 | #FEF6F0 底 / #4A3F3A 字 | #E8A87C | 低龄教学、班会 |
| 手绘风 | #FBFBF7 底 / #3D3A33 字 | #C9B79C | 创意、班会 |

> 字体：中文优先思源/系统默认无衬线；英文无衬线。避免过度装饰。

> **与本技能的 PPT 渲染工作流 的衔接**：上表低饱和配色将作为步骤 3 生成阶段 `DESIGN.md` 的「色彩池（≤4 hex）」直接输入；推荐风格与版式组合倾向则落入 `DESIGN.md` 的版式映射表与配图 L1/L2/L3 清单（详见 `generate-pptx-tencent.md`）。

## 四、基础信息收集卡（步骤 1 确认用）

向用户确认的字段（缺失才问，单轮 ≤ 3 问）：

```
【PPT 基础信息确认】
• 类型：<教学课件 / 工作汇报 / 教研分享 / 班会主题 / 其它：___>
• 风格：<简约白 / 商务蓝 / 清新绿 / 科技紫 / 中国风 / 卡通风 / 手绘风 / 自定义：___>
• 页数：<默认 N 页；用户可改，含封面+目录+过渡+内容+尾页>
• 语言：<中文 / 中英双语 / 其它>
• 特殊要求：<配色偏好 / 必须包含的章节 / 禁用元素 / 受众年级或对象 / 其它>
```

默认假设写法示例："未指定风格，默认『简约白』；未指定页数，按教学课件默认 14 页。如需调整请告诉我。"
