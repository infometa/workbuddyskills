# 09 · 练习题目来源：CNKI 基教题库接口（edu 连接器）

> 动画里的当堂练习来源：**默认走 CNKI 基教题库真题（②，来源可溯源、可审计）**。
> 仅在「账号已开通权益」且「用户明确要求自编题」时，才可用 **① LLM 自编仿真题** 作即时反馈补充，且必须如实标注"自编仿真题（无出处）"。**缺权益时题目层一律停止、不产出任何题目（含自编题）；动画本体仍按通用版兜底照常生成。**

---

## 零 · 权益校验（技能触发即查，不是等调接口才查）

> **时机：使用本技能时第一时间就查**，而不是"要调用 `mcp__<SERVER>__tkSearchQuestion` 了才想起来查"。
> 是否有权益决定整个 edu 链路（题库真题、`mcp__<SERVER>__tkQuestionAnalysis` 解析、`mcp__<SERVER>__tkPoint` / `mcp__<SERVER>__tkBook` 等）能不能用，属于**开工前的定调动作**。
> 一次会话查一次即可，后续沿用结论；中途 edu 调用报权限错误时重查一次再下结论。

**执行**：

1. `ToolSearch` 精确查 `mcp__<SERVER>__userState`（前缀漂移处理同 §二），**无参数**直接调用。
2. 返回形态：`{"data":true,"code":200,"msg":"查询成功！"}`——**只看 `data` 字段**。
3. **`data === true`**：账号有 CNKI 基教数据权益，edu 能力可用，按 §一～§五正常检索与呈现。
4. **`data === false`**：题库链路**立即硬中止**——**不产出任何练习 / 小测题目**、不调用任何 edu 接口、不重试、不换关键词试探；但本技能**动画本体为纯模型、照常生成**（通用版兜底，不依赖知网数据），仅缺「知网题库真题」练习层、并附强制「解锁知网数据增强层」。向用户原样输出 `_shared.md`「权限固定提示」的转化卡（⛔ 红线不展示给用户）：
   > 固定提示三条原文**统一引用** [_shared.md](_shared.md)「权限固定提示」，本文件不复写——改提示只改 `_shared.md` 一处。

### 禁止绕过（红线）

无权益时**不允许**用下列任何方式顶替，也不得让用户误以为结果来自知网：

- ❌ 改用 WebSearch / 网络抓题，或从第三方题库站点复制题目；
- ❌ 用 LLM 自编题**冒充**真题，并在页面或交付说明里标注"选自 CNKI 题库""来源：知网"等字样；
- ❌ 申请 / 调用其它非 edu 连接器的数据源当"等价替代"；
- ❌ 用既有缓存数据（本次会话之外的历史检索结果）继续充当本次产出。

（缺权益时本技能的**题库练习层已在 §零 闸门处停止**——不进入本步骤、不产出任何练习题目；动画本体仍按通用版兜底照常生成。自编仿真题仅在「已开通权益且用户明确要求」时按上条规则使用，不得当作缺权益的顶替。）

> **未连接 / 调用失败同样走通用版兜底 + 转化卡**：本技能闸门不区分"无权益"与"未连接"——`mcp__<SERVER>__userState` 工具查不到（即 `edu` 连接器未安装 / 未启用）或调用报错，与 `data:false` 等价，**题库练习层一律停止、不产出任何练习题目**；但动画本体仍照常生成（纯模型通用版兜底），并提示用户到连接器管理页启用 `edu` 连接器、确认账号拥有「知网基教」权益后重试，不要据此判定为"接口偶发故障"而绕过。只有在 `edu` 连接器已连接、且明确拿到 `data:false` 时，才额外提示前往 e.cnki.net 购买 / 开通权益。

## 一、何时调用

生成任何含"练习 / 小测 / 闯关 / 选一选"的动画，且用户未明确要求自编题时，**沿用 §零 已得出的权益结论**：有权益则检索题库，无权益则按 §零 提示购买、不进 edu 链路。
若用户问"这些题是哪来的"，如实说明来源；要真题就现检，不要拿自编题冒充。

## 二、工具与调用（实测要点，2026-10 验证）

**前缀会漂移**：工具名前缀来自 edu 连接器的**显示名**，会随用户重命名变化（已实测：`edu` → `知网基教` → `edu`）。
**不要写死前缀**：

1. 先用 `ToolSearch` 精确查 `mcp__<SERVER>__tkSearchQuestion`；
2. 查不到再按关键词搜（`queries: ["题库 搜题", "mcp__<SERVER>__tkSearchQuestion"]`）；
3. 仍拿不准时跑 `reconcile --tools tools.json`，它用观测到的工具名反推真实前缀并在 `PREFIX-DRIFT` 段直接给出应改成的 `MCP_PROVIDER`。

**主力接口 `mcp__<SERVER>__tkSearchQuestion`**：

| 参数 | 说明 |
|---|---|
| `keyword` | **不能带空格**（带空格会 400）。用连写关键词，如"铁丝燃烧现象""氧气化学性质" |
| `subjectCode` | 学科码。**化学 = 22 已实测**；其余学科使用前先验证，不要猜 |
| `type` | 题型。**1 = 选择题**——要"能直接用的单选题"就传 1 |
| `ps` / `pi` | 每页条数（上限 10）/ 页码 |

**返回字段**：

| 字段 | 含义 |
|---|---|
| `Label` | 出处，如"2023·宝山区二模""2025 秋·漳州期中"，**标注来源就取这个** |
| `Content` | 题干（HTML，含 `<del>` 检索高亮标签与 `<img>` 插图外链，需清洗） |
| `Options` | 选项数组 |
| `Answers` | **索引数组**，"0" = A、"1" = B……与 `DisplayAnswer` 相互校验 |
| `DisplayAnswer` | 形如 "B" |
| `Degree` | 难度（0–1） |
| `PaperCount` / `RealCount` | 被试卷引用次数 / 真题计数，越大越"经典" |
| `SID` | 题目唯一 ID，用于向用户定位原卷 |
| `ParentContent` / `ParentSID` | 材料题的共用材料，子题需带上才完整 |
| `Analyse` / `Method` / `Discuss` | **在 `mcp__<SERVER>__tkSearchQuestion` 里恒为空**；要官方解析走 `mcp__<SERVER>__tkQuestionAnalysis` |

**其他可用接口**：`mcp__<SERVER>__tkSearchSubjectQuestion`（按考点 `point` 数组取题，支持难度档 / 年份 / 来源，比关键词准；考点 ID 来自 `mcp__<SERVER>__tkPoint`，返回体 30 万字符级，**勿内联进生成链**）。

## 三、入库前三道闸（硬性，缺一不可）

1. **只取文字，图片外链一律剔除**
   `Content` / `Options` 中常见 `<img src="http://img.jyeoo.net/...">`。外链既破坏"单文件零外部依赖"硬标准，又涉第三方图版权。
   做法：删除 `<img>`、把表格化内容改写成文字叙述，并在页面注明"原卷插图略去"。

2. **题干与答案必须二次核验（血泪案例）**
   题库答案偶有与学科常识冲突者。实锤一例：
   （2025 秋·正阳县期末）"下列对有关物质燃烧的现象描述，错误的是" —— 接口 `Answers=["1"]`（B 木炭…发出白光）；但按教材，A"红磷…产生大量白色烟雾"把"烟"说成"烟雾"才是错项，B 的描述本身正确。**该题弃用、未入卷。**
   规则：凡"选错误的/不正确的/不可能的"类题目，逐项核对后再用；拿不准就不收，宁缺。

3. **标注出处 + 标明是否改编**
   每题下方写"来源：2023·宝山区二模（选择题）"。
   - 题干、选项、答案**未改动** → 标"（题库原题）"
   - 填空 / 探究 / 多选改为单选以适配即时反馈 → 标"（改编）"，并在区块顶部说明条里写明改了什么

## 四、筛题偏好（经验）

- 检索时直接限定 `type=1`，效率最高；再筛**无 `<img>`**（可离线、无版权风险）+ `PaperCount`/`RealCount` 高（反复被选的经典题）。
- 现象描述类、操作细节类考点在各地"**期中 / 月考 / 二模**"卷里量最大，且多为纯文字，命中率高。
- 一套练习 **4–6 题**：现象辨识 / 原理理解 / 操作细节 / 异常分析各一，再加 1 道教材基础（如配平、默写）。
- 检索 1–2 组关键词即可，不要反复轮询同一接口。

## 五、页面呈现规范

- 题目区顶部加**说明条**：题目来源、是否改编、插图已略去——口径透明，教师一眼可查。
- 反馈语写成**针对选项的诊断式**，而不是只判对错：
  - 好："不对。产生大量白烟是红磷在空气中燃烧的现象。"
  - 坏："回答错误！"
- 出处用灰色小字放在每题下方，不抢主视觉。
- 自编题混入时也要如实标注（如"教材基础（非题库题）"），不能与真题混为一谈。
