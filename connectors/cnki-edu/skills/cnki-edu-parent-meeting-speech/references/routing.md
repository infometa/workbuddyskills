# 路由判定细则 · 发言稿形态

本文件是「家长会发言稿」技能的分流中枢。**每次接到用户输入，先在此完成路由，再进入成稿。**

---

## 一、先确认：这个活归本技能吗？（越界转交，硬性）

本技能**只做发言稿**。以下情况**不属于本技能**，应提示用户改用 **「日常家校沟通话术」技能**：

| 用户实际要的是 | 判据 | 转交 |
|---|---|---|
| 一条发到群里 / 发给个别家长的消息 | 交付物落在**家长的对话框**，不是耳朵 | → 话术技能 |
| "写个**家长会通知**""通知家长开会" | 有"家长会"三字，但交付物是**通知消息** | → 话术技能 A1 |
| 已有草稿求把关 / 家长已发来消息求回复 | 见第三节形态判定 | → 话术技能（③④ 形态） |

> **一句话判据**：交付物最终落在**家长的耳朵里** → 本技能；落在**家长的对话框里** → 话术技能。
> **⚠️ 场合名词不作数**：出现「家长会 / 班会」**不等于**发言稿形态——它只说明场合，不说明交付物形态。

**转交话术（直接用）**：

> 这个看起来是**要发给家长的消息**，不是会上念的稿子——我这边是专门写发言稿的。要发消息的话，请改用「日常家校沟通话术」技能，我把需求说明给你：〔简述用户需求〕。

反向：若用户在话术技能里其实要整篇发言稿，那边会转回本技能。

## 二、第一级路由 · 任务形态判定

| 形态 | 判定信号（命中任一即归入） | 典型表述 | 后续路径 |
|---|---|---|---|
| **① 发言稿（本技能主营）** | 面向全班家长的一次性**口播**；提到时长、PPT、流程、章节 | "家长会发言稿""家长会讲话""讲 20 分钟""要个 PPT 大纲" | → 角色路由（第三节） |
| ③ 草稿把关 | 用户**已给成段草稿**，求检查 / 润色 / 把关 | "这样写行吗""帮我改改" | → 话术技能（本技能不主营） |
| ④ 应答 / 降温 | 家长**已发来消息**求回复，或群里**已出现争论** | "家长这么问我怎么回""群里吵起来了" | → 话术技能 |

### 2.1 强信号词表（互斥）

| ✅ 归本技能（发言稿） | ❌ 归话术技能 |
|---|---|
| 发言稿 / 讲话稿 / 讲稿 / 逐字稿 | 通知 / 群公告 / 发一条 / 发个微信 / 私信 |
| 家长会**上讲** / 上台讲 / 说点什么 / 讲 20 分钟 | 怎么回复 / 回家长 / 措辞怎么说 |
| PPT 大纲 / 幻灯片 / 分几页 | 催 / 提醒 / 接龙 / 收款 / 报名 |
| 开场 / 结尾 / 五段式 / 时间分配 | 约谈 / 家访邀约 / 私信怎么说 |

### 2.2 高频误判对照（**逐条记住**）

| 用户原话 | ❌ 易误判成 | ✅ 实际归属 | 判据 |
|---|---|---|---|
| "写个**家长会通知**" / "通知家长开家长会" | 本技能 | **话术技能 A1** | 交付物是发到群里的消息 |
| "家长会上我想**说说**手机管理" | 话术 | **本技能** | "会上说"= 口播，且有主题 |
| "我这样写行吗"+ 贴了一段话 | 重写一份 | **草稿把关 → 话术技能** | 已有文本 + 求判断 |
| "帮我写个**家访**后的小结发群里" | 本技能 | **话术技能 F4** | 落点是"发群里" |
| "把上次那篇发言稿**改一改**" | 草稿把关 | **本技能** | 用户既给草稿又要发言稿 → 判 ①，原稿作素材 |

### 2.3 短路判定顺序

1. 用户提供了既有文本 + 求把关，且**没有说要发言稿** → 转话术技能（③）。
2. 用户转述了家长已发来的话 / 群里吵架 → 转话术技能（④）。
3. 否则 → ① 发言稿，进入角色路由。

## 三、第二级路由 · 角色路由

按「短路判定」顺序，命中即停：

| 顺序 | 判定来源 | 命中信号 | 结果 |
|---|---|---|---|
| ① | 用户显式声明 | "我是班主任 / 语文老师 / 带班又教数学" | 直接采用，不再追问 |
| ② | 会议性质 | 面向全班家长的班会式家长会 | 班主任 |
| ② | 会议性质 | 面向本学科的学科家长会 | 学科老师 |
| ③ | 数据口径 | 全班全科综合数据（出勤、纪律、各科汇总） | 班主任 |
| ③ | 数据口径 | 单科成绩 / 作业 / 课堂数据 | 学科老师 |

### 3.1 冲突处理

- ① 与 ②/③ 冲突 → 以 ① 为准。
- ② 与 ③ 冲突 → 以 ② 为准，并在成稿时向用户说明所选角色。
- 显式声明"兼任" → 兼任模式（班主任主干 + 本学科专区）。

### 3.2 无法判断时（强制询问）

**只有三种来源全部无信号时**才走本节；任一来源命中即为已确定，**不得再开面板确认**（见 SKILL.md §4.3.1）。

> 「这份发言稿是您以班主任身份面向全班家长，还是以某学科老师身份讲本学科？如果两者兼有，也请告诉我主次。」

若回答模糊，再补一问：

> 「那这次发言的主线是班级整体情况，还是某一个学科？我会按主线来组织内容。」

### 3.3 常见歧义场景

| 场景 | 处理 |
|---|---|
| 班主任兼某学科老师，只开一场家长会 | 兼任模式：班主任主干 + 学科专区 |
| 学科老师受邀在班主任家长会上讲 10-15 分钟 | 学科老师模式，走**短时压缩版** |
| 用户只说"家长会发言稿"未提角色 | 强制询问（见 3.2） |
| 用户提供的是**全班各科汇总表 / 全班成绩单** | 命中 ③ **即确定为班主任**，直接采用、不再确认；成稿时一句说明依据（"按您提供的全班各科汇总表，走班主任口径"）。**不得写成"默认倾向班主任，但仍需确认"** |
| 用户提供的是一份**单科**成绩 / 作业 / 课堂数据 | 命中 ③ **即确定为学科老师**，直接采用、不再确认 |
| 附件或同工作区历史成稿里已写明角色（如文件名"…（班主任·45分钟）"） | 命中 ①/③ **即确定为该角色**，直接采用、不再确认 |

## 四、叠加维度

- **会议主题**：开学动员 / 期中分析 / 期末汇报 / 升学衔接（小升初、初升高、高三动员）/ 专项主题（青春期、网络使用、心理健康）/ 月考后沟通会。
- **学段基调**：按小学 / 初中 / 高中读取 `stage-primary.md` / `stage-junior.md` / `stage-senior.md`，**三选一，不得全读**。
- **政策维度（触发式）**：主题落在**升学衔接 / 志愿填报 / 中考·高考改革 / 指标到校 / 新高考选科**，或内容将涉及**作业时长、考试排名、手机管理、课标、收费**时，**即触发政策类前置项**——先落实政策依据来源（用户 / 官方文件），再成稿。见 `SKILL.md` §5。
