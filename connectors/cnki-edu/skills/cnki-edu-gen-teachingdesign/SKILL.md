# 教学设计生成（单节课备课）

## 定位

为中小学教师生成结构完整、符合新课标理念的**单节课**教学设计，**直接交付 .docx**：文档以**左侧 Word 卡片 + 右侧预览面板**呈现（可预览、编辑、下载、导出）。卡片**正下方**附一份**独立的**"知网推荐"列表（最多 6 条）：**仅《文献名》可点击，点击一次直达该篇在知网研学平台的研读页面**（**直接取用文献检索接口返回的文献链接**；登录且有阅读权益即可在线阅读全文）；**《文献名》须带跳转链接**（**不附带悬停提示**——对话渲染环境不呈现 `title` 提示，写了也无效）。

主链路：收集课程信息 → 消化参考资料/附件 → 生成纯教案 → 检索文献推荐 → 交付 Word 文档 → 卡片下方列出知网推荐。

## 铁律（最高优先级；与文档其他表述冲突时，一律以本节为准）

| # | 铁律 | 具体含义 |
|---|---|---|
| **R1** | **Word 文档零"编写说明"** | .docx 内**绝对不得**出现任何**编写说明类内容**——指的是"解释文档自身怎么用 / 怎么来的"的整段或整行文字：`编写说明`、`说明：`、`注：`、`备注：`、`提示：`、`填写说明`、`补充说明`、`使用说明`、假设标注、取舍说明、`{占位符}`、「此处可…」「以下内容参考…」类提示句、`待补充`、`TBD`、批注、生成说明、作者/日期署名。**判定口径：判断"这段话是不是在解释文档本身"，而不是字面比对关键词**——不得做关键词字面批量删除。学科正文中出现的同形词**一律保留**：语文的**说明文 / 说明方法 / 说明顺序 / 说明性文字**，练习中的**示例 / 示例题 / 例题示例**，课堂用语中的**温馨提示 / 提示语 / 提示卡**，板书中的**注释 / 注解 / 备注性知识**等。**需要向用户交代的假设、取舍、来源，一律写在对话正文里，不写入文档。** |
| **R2** | **纯净教案** | .docx 只含教学设计本体：默认七个一级标题，或模板型附件的既定板块，或用户确认过的大纲。不含文献推荐、参考资料、提示语、工具说明等任何文档外板块。该文档可直接交付教师使用。 |
| **R3** | **元数据封禁** | 检索接口名、服务名、域名、字段名（`filename`/`dbcode` 等）、链接拼接逻辑、检索报文、内部推荐理由等，**严禁以任何形式出现在用户可见输出中**（对话、卡片、列表、文档皆然）。 |
| **R4** | **文献名带跳转链接 · 点击一次直达知网研学研读页面 · 未登录可登后查看** | 知网推荐每条**仅《文献名》可点击**，**点击一次即落在该文献在知网研学平台的研读页面**——跳转目标**直接取用文献检索接口返回的 `url` 字段**（该字段即研读页地址），**原样使用：不改写、不精简参数、不替换字段值、不自行拼接、不解析**（详细见"内部实现说明"）。**已登录且有阅读权益**（机构授权、个人／团队会员、文献流量包等）时**直接在线阅读全文**；**未登录时由研学平台弹出登录框，登录完成后自动校验该篇阅读权限**——有权限即展示全文，无权限给出平台自身的获取指引。**不得因"可能要登录"就改写、隐藏、弃用或降级该链接，也不做点击前拦截**；**列表下方统一附一句**中立文案「**点击文献名可在线阅读全文；未登录时登录知网账号后即可查看**」（文案中不得出现接口名/服务名/域名/字段名）。**《文献名》必须带跳转链接**——默认写法为 **Markdown 链接** `[《文献名》](接口返回的研读页地址)`（兼容性最好，点击一次直达研读页）；内联 HTML 锚点**仅在确知渲染环境会执行 HTML 时使用**（对话/卡片类环境会剥离内联锚点，会被剥成纯文本、点不动）；仅在链接完全无法渲染时，才**退为无链接纯文本**（只写《文献名》）。**不要求、也不附加悬停提示**——`title` / 链接标题在对话渲染环境中不呈现，属无效信息，**一律不写**。**跳转地址只作「文献名」的跳转目标，不得以明文形式进入可见文案**：严禁把 URL / 域名直接写在条目文本里，严禁附"点击查看原文""链接：""地址："等提示语，严禁整行（含作者、来源）都做成链接。作者、来源为链接外的纯文本。 |
| **R5** | **交付物只有三样** | ① 教学设计 Word 文档（左卡片 + 右预览）；② 卡片正下方的知网推荐列表；③ 未通过权益校验 / 未连接时：走`references/_shared.md`「一、权限固定提示」「通用版兜底 + 强制转化卡」——**教学设计 Word 文档照常交付**（纯模型生成，不依赖知网），仅「知网推荐」列表不产出（改为说明"需接入知网后获取"），并原样输出「解锁知网数据增强层」。其余内容（推理过程、中间草稿、工具调用等）一律不输出。 |

## 🔐 前置权限校验（最高优先级，必须最先执行）

> 权限校验的「三态诊断 / 通用版兜底 / 强制转化卡 / 连接器加载指引」统一见本技能 `references/_shared.md`「一、权限固定提示」，本章节仅保留本技能专属说明，不重复展开。

> **权益 ≠ 引用（本技能适用）**：教学设计正文（Word 文档本体）**纯模型生成、不依赖知网**；「知网推荐」才是依赖 `mcp__<SERVER>__searchVectorBJ` 的增强层，缺失不影响教案本体。权益是"能不能用知网推荐"的闸门，不是"该不该生成教案"的开关（无权益时教案照出、仅省知网推荐）。

## 信息收集清单

**不得在信息严重不足时直接生成**，但也要避免逐项追问——用**一条消息**一次性补齐缺口。

| # | 信息项 | 必需性 | 说明 |
|---|--------|--------|------|
| 1 | 学段学科 | 路径A必需 | 小学/初中/高中 × 语数英/理化生/政史地/科学/音体美等 |
| 2 | 教材版本 | 路径A必需 | 人教版、统编（部编）版、北师大版、苏教版、外研版等 |
| 3 | 分册信息 | 路径A必需 | 某年级上册/下册，或必修第一册/选择性必修第二册等 |
| 4 | 课文名称 | 必需（二选一路径） | 路径A：教材目录级联选定；路径B：用户直接输入课文名 |
| 5 | 课时数 | 可选，**默认 1 课时** | 非用户特殊说明，一律按 1 个课时设计；用户指定 N 课时时按 N 拆分 |
| 6 | 教学设计大纲 | 可选 | 默认七个一级标题，可增删维度或自定义 |
| 7 | 附加要求 | 可选 | 篇幅、风格、信息化手段、德育融合等，用分号/逗号分隔 |
| 8 | 附件 / 参考资料 | 可选 | 未说明类型时主动确认：(A) 内容型——作素材；(B) 模板型——严格按其结构填充。也可仅提供文献链接 |

**两条选题路径：**

- **路径 A（级联选择）**：学段学科 → 教材版本 → 分册 → 课文目录某一课。课文名称与教材目录须对照国家中小学智慧教育平台的教材数据核实，操作见 `references/smartedu-cascade.md`。
- **路径 B（直接输入课文名）**：用户直接给出课文名（如"帮我写《背影》的教案"）。据课文名推断可能的学段学科版本；存在多版本/多学段歧义（同名课文出现在不同教材）时列出候选让用户确认；**确实无法确认时**按最常见版本生成，并在**对话正文**（不是文档）中说明所采用的假设，请用户核对。

**信息确认句式**（收集完成后向用户复述一次）：

> 您好，我是一名 {学段}{学科} 教师，使用 {教材版本}{分册} 教材，正在备《{课文名称}》这节课（{课时数}课时），教学内容包括 {维度列表}；其他更多要求：{附加要求}；参考资料：{资料来源}。现在开始为您生成教学设计。

## 工作流程

### 第 1 步：收集课程信息

1. 从用户消息中抽取已有信息项（学段学科、版本、分册、课文名、课时数、大纲、要求、资料）。
2. 走路径 A 时，先按 `references/smartedu-cascade.md` 核实课文确属该教材目录；核实失败时列出相近目录条目供用户确认。
3. 关键信息缺失（课文名未知且无级联信息）时，**一次性**询问缺口，不连环追问。
4. **课时默认 1 课时**：未明确说明时按 1 课时设计（教学过程呈现为单列完整环节链）；指定 N 课时时拆为"第一课时/第二课时…"，每课时均含完整环节链。
5. 大纲未指定时用默认七个一级标题：教材分析、学情分析、教学目标、教学重难点、教学过程、板书设计、教学反思。可增选 `references/dimensions.md` 中的扩展维度或自定义标题。

### 第 2 步：处理参考资料 / 附件

先判断附件类型，再分别处理：

- **(A) 内容型附件**（素材/参考资料）：用 Read 读取（PDF/Word/图片/文本均可），提取与本课相关的课标要求、知识点、习题、范文等要点，供第 3 步使用。
- **(B) 模板型附件**（教学设计模板）：识别其占位符与标题层级（如 `## 一、教材分析`、`{填写此处}`），记录板块顺序与格式，第 3 步严格填充。**模板自带的填写说明、示例文字、提示句一律不得进入最终文档（R1）**；若模板结构与默认七维度差异较大，以模板为准，差异说明写在对话正文。
- **文献资料**：用户提供文献链接时先尝试 WebFetch 取标题与摘要；若需登录或反爬拦截，明确告知无法抓取全文，请用户导出 PDF/CAJ 上传或粘贴摘要。
- **其他网页资料**：WebFetch 抓取正文，提炼可用要点。
- 素材只在对应维度中**自然融入**（如论文观点用于教材分析、名师案例用于教学过程），**不**在教案末尾单列"参考资料"小节（R2）。

### 第 3 步：生成教学设计正文（docx 的生成源）

1. **结构组织**：有模板型附件时按其板块顺序与层级严格填充（不增删既定板块）；否则按 `references/lesson-plan-template.md` 的七维度结构组织。
2. **写作规范**：各维度的定位、内容要求、篇幅基准与常见误区见 `references/dimensions.md`，逐条对照执行。
3. **教学目标**：核心素养导向（义务教育 2022 年版课标 / 高中 2017 年版及修订课标），可观测、可评价；仍以"三维目标"作标题框架的旧式表述视为不合格。
4. **不许编造**：课标条目、教材单元位置、页码等只写有把握的内容；把握不足时改为概括性表述，不得虚构条目编号。不确定之处在对话中提示用户核对。
5. **教学过程**：默认按 1 课时展开——导入新课 → 探究新知 → 巩固练习 → 课堂小结 → 布置作业；每个环节写明**教师活动**（含关键提问原句）、**学生活动**（含预设回答）、**设计意图**（对应哪条目标/如何突破重难点）。用户指定多课时时按课时拆分，每课时均含完整环节链。
6. **落实附加要求**；与常规结构冲突时以用户要求优先，取舍理由写在**对话正文**（R1 明确禁止写进文档）。
7. **一次成稿**：生成**完整教案全文**作为第 5 步的 docx 生成源，不要只给大纲、也不要让用户二次确认后才写。
8. **零说明自检（按语义判断，禁字面删除）**：成稿后逐段通读，排查并清除——残留的 `{`/`}` 占位符、`注：`/`备注：`/`提示：`/`说明：` 行首标注、`待补充`/`TBD`、作者/日期署名、批注，以及"本维度依据…""以下内容参考…""此处可…"类**解释文档自身**的句子。**只删"解释文档本身"的内容，绝不误删学科正文**：`说明文`/`说明方法`/`说明顺序`/`说明性文字`、`示例`/`示例题`/`例题示例`、`温馨提示`/`提示语`、`注释`/`注解` 等均为合法教学内容，**必须原样保留**；**严禁用关键词字面匹配做批量替换或删除**（R1）。
9. 全文**默认不贴进对话**（Word 卡片即交付物，重复贴造成冗余）；仅当用户明确要求"先看文字版"时，才在卡片外另附一次全文。

### 第 4 步：检索文献推荐（文档之外的独立列表）

1. 调用文献检索能力，以本课主题发起检索（检索词建议组合「课文名称 + 学段学科 + 教学主题/关键词」）。
2. 最多取 6 条。
3. **若文献检索能力未连接 / 鉴权失败 / 网络不可用**（本分支仅适用于已通过入口 `mcp__<SERVER>__userState` 权益校验之后、单次文献检索临时不可用的情形；入口即未通过权益校验 / 未连接时已在上方权限校验处走通用版兜底——**教案照常交付、仅省知网推荐**，不进入本步）：
   - **不得**在教案中编造文献，也**不得**静默跳过；
   - 直接在界面呈现一张**连接/授权卡片**（或同等引导提示），让用户可点击连接或完成授权；文案保持中立，**不暴露**任何接口名、服务名、域名等元数据（R3），仅说明"连接后可获取文献推荐"之类；
   - 用户连接/授权后重试本步；用户暂不连接则本步结束，不展示推荐列表、不编造。
4. 每条整理出题录：文章名称、作者、来源/期刊（字段缺失则标"未获取"）。明显不相关或重复的条目剔除，最终不超过 6 条。
5. 同步为每条取用**接口返回的文献链接**（`url` 字段）作为跳转目标（规则见内部实现说明）：该字段即该篇在**知网研学平台的研读页面**地址，**原样使用——不改写、不拼接、不解析、不做任何额外网页请求**。**某篇未返回链接时不得臆造**，该篇退为无链接纯文本（只写《文献名》）。
6. **登录态与阅读权益（点击后登录即可）**：点击后进入知网研学研读页——**已登录且有阅读权益时直接在线阅读全文**；**未登录时由平台弹出登录框，登录完成后自动校验该篇阅读权限**（有权限即展示全文，无权限给出平台自身的获取指引）。以上均为**平台侧正常流程**，**本步不做任何前置拦截**：照常给「文献名」挂上链接即可。**列表下方统一附一句**中立文案「**点击文献名可在线阅读全文；未登录时登录知网账号后即可查看**」（**文案中不得出现任何接口名、服务名、域名、字段名**，R3）。
7. 本步涉及的全部技术细节均属元数据，**严禁出现在用户可见输出中**（R3）。

### 第 5 步：生成并交付 Word 文档（左侧卡片 + 右侧预览）

1. 调用 `tencent-docx`，把第 3 步的**纯教案全文**生成 .docx 并交付（present_files）。文档只含教学设计内容，不含文献推荐、参考资料、编写说明或任何无关内容（R1/R2）。
2. **排版要求**：标题使用 Word 内置**标题样式**（一级/二级，形成导航大纲），正文为段落文本；**不得把 Markdown 标记**（`##`、`**`、`-`、表格管道符）原样留在文档里；长段落正文不用表格承载（仅"基本信息"可用表格）。
3. **"左侧卡片 + 右侧预览"布局**：Word 文档以卡片形式呈现在左侧，宽度适中（约 600–800px 或随容器自适应），不拉伸至整屏；右侧展开预览面板，卡片内支持预览、下载与导出。环境/预览组件不支持该布局时，回退为常规文档预览，不影响交付。
4. 用户如需在对话内直接编辑，再调用 `tencent-local-office-edit` 打开该 .docx 实时编辑。

### 第 6 步：在 Word 卡片正下方呈现知网推荐列表

> **渲染顺序（重要）**：先在第 5 步调用 `present_files` 交付 Word 卡片，再在**同一条回复中、卡片之后**输出本列表（用 Markdown，文献名处按 R4 的写法 A/B 处理），列表即自然位于卡片正下方。切勿把列表与卡片拆成两次无关输出，也不要把列表写进 .docx。

1. 把第 4 步检索到的文献整理为**独立的"知网推荐"列表，位于 Word 卡片正下方**，不写入 .docx。
2. 每条**仅《文献名》可点击**，**点击一次即直达该篇在知网研学平台的研读页面**（**直接取用检索接口返回的文献链接**）；**《文献名》须带跳转链接**；写入格式按渲染环境自适应：
   - **写法 A（默认首选 · Markdown 链接）**——**兼容性最好，点击一次即直达**：
     ```markdown
     [《文献名》](<接口返回的研读页链接>)，作者，来源
     ```
   - **写法 B（仅在已确认"渲染环境会执行内联 HTML"时使用 · 内联锚点）**——**带 `href`（= 接口返回的研读页链接，原样使用）、`target="_blank"`、`rel="noopener noreferrer"`**：
     ```html
     <a href="<接口返回的研读页链接>" target="_blank" rel="noopener noreferrer">《文献名》</a>，作者，来源
     ```
     （⚠️ 实测提示：**对话/卡片类渲染环境普遍会剥离内联 HTML 锚点**——HTML 写法放上去会被剥成纯文本、**点不动**。**除非确知环境会执行内联 HTML，否则一律直接用写法 A**；若写法 B 落地后出现"点不动"，立即改回写法 A。）
   - **写法 C（兜底）**——**仅当连链接都无法渲染时**，才退为**无链接纯文本**：`《文献名》，作者，来源`。
   - **不附加悬停提示**：**一律不写 `title` / 链接标题**（对话渲染环境不呈现该提示，写了也无效，反而增加冗余）；本技能**只保证"点文献名即跳转"**，不为悬停提示做任何额外处理。
   - 各写法共同硬约束：锚文本仅限"文献名"（含书名号）；作者、来源为链接外的纯文本、不可点击；**跳转地址只作为「文献名」的跳转目标存在，严禁把 URL / 域名明文写进条目文本**（如 `《文献名》 https://...`、`点击查看原文`、`链接：` 一类）；**严禁整行（含作者、来源）都做成链接**；**严禁把接口名 / 服务名 / 字段名 / 其它任何元数据带入可见文案**（R3/R4）。
   - 每条**仅展示三项**：文献名（可点击，进知网研学研读页）、作者、来源（缺失标"未获取"）。
   - **不展示**发表时间、推荐理由、检索报文、接口原始字段、内部标识等任何额外信息（R3）。
3. 文末附一句提示：可继续要求调整某一维度、增删维度，或重新检索文献推荐。
4. **未登录 / 无权益时**：点击《文献名》后进入知网研学研读页，**已登录且有阅读权益时直接在线阅读全文**；**未登录时由平台弹出登录框，登录完成后自动校验阅读权限**——属**正常现象**，**无需为此改写列表或删掉链接**。**列表下方统一附一句**中立文案「**点击文献名可在线阅读全文；未登录时登录知网账号后即可查看**」；**列表中一律不得出现任何接口名、服务名、域名、字段名或链接原文**（R3）。

## 内部实现说明（仅 Agent 可见，严禁出现在任何用户可见输出中）

> 以下为技能内部实现细节，**绝不可**写入对话、卡片、列表、文档等任何用户可见位置（R3）。

- **文献检索**：通过名称为 `edu` 的 MCP 提供的文献检索接口 **`mcp__<SERVER>__searchVectorBJ`** 获取候选文献，以本课主题发起检索，最多取 6 条。
- **取用字段（2026-10-13 实调复核）**：`mcp__<SERVER>__searchVectorBJ` 返回字段为 `相关度`、`resource`、`小标题`、**`篇名`/`Title`**、`正文`、`Summary`、`Author`、`JournalName`/`Source`、`JournalName_EN`、`AuthorAffiliation`、`ResourceType`、`Year`、`PubDate`、`Keyword`、`Fund`、`DownloadedTimes`、`CitedTimes`、**`url`**（段落接口另有 `章节序号`、`当前小标题`）。
- **链接取值（唯一 · 直接取用接口返回的文献链接）**：每条「文献名」的跳转目标**直接取用返回的 `url` 字段**——该字段即该篇在**知网研学平台的研读页面**地址，形如 `https://ix.cnki.net/read/article/readonline?dbcode=…&tablename=…&filename=…&fileSourceType=1`。**原样使用：不改写、不精简参数、不替换字段值、不自行拼接、不解析、不做任何额外网页请求**，直接作为「文献名」的跳转链接目标（锚点 `href` / Markdown 链接地址）。
  - ⚠️ **已废弃的旧做法**：本技能旧版本"以**完整篇名**拼接知网官网检索页地址（`kns.cnki.net/kns8s/defaultresult/index?kw=…`）"**已整体废弃**，不再采用。
  - ⚠️ `篇名` 是**文献标题**，**不是**知网的文件标识——**严禁**拿篇名去拼任何地址（旧版本曾把篇名当 `filename` 拼详情页，实测落到"知网节 文献 Sorry, no content available."错误页，已废弃）。
  - ⚠️ **不得用非浏览器请求去抓该地址或知网接口**：本流程**只取接口返回值**，**不发起任何额外网络请求**。
- **链接缺失降级（保证不中断、不暴露）**：某篇若**未返回 `url`**，该篇**不挂链接、退为无链接纯文本**（此时无跳转目标，只写《文献名》），**流程继续**，不得中断知网推荐产出；**不得臆造地址**。全程属内部流程，**不得**在用户可见处出现"取值 / 拼接 / 解析 / 抓取 / 检索页 / 链接"等字样。
- **点击行为（一次直达研读页面）**：**仅「文献名」为可点击锚文本**，点击后**一次即落在该文献在知网研学平台的研读页面**：
  - **已登录且有阅读权益**（机构授权、个人／团队会员、文献流量包等）→ **直接在线阅读全文**；
  - **未登录** → 由研学平台**弹出登录框**（账号登录、扫码、微信/QQ 等），**登录完成后平台自动校验该篇阅读权限**——有权限即展示全文，无权限则给出平台自身的获取指引。
  - 以上均为**平台侧正常流程**：**链接照挂——不预先拦截、不改写、不删除、不降级为纯文本**（仅"渲染环境不支持链接"时的纯文本退路除外）。**列表下方统一附一句**中立文案「**点击文献名可在线阅读全文；未登录时登录知网账号后即可查看**」。
- **链接写法（保点击跳转 · 不附加悬停提示）**：链接**默认用 Markdown 链接** `[《文献名》](研读页链接)`（**兼容性最好，点击一次直达该篇在知网研学平台的研读页面**）。内联 HTML 锚点（`<a href="研读页链接">《文献名》</a>`）**仅在确知渲染环境会执行内联 HTML 时才用**——**实测（2026-10-13）：对话/卡片类渲染环境会剥离内联锚点，落地后表现为"纯文本、点不动"，届时立即改回 Markdown 链接写法**。**仅在链接完全无法渲染时**，才退为**无链接纯文本**（只写《文献名》）。**不写 `title` / 链接标题**：悬停提示在对话渲染环境中不呈现，一律不做（**需求口径 = 保点击跳转、放弃悬停提示**）。**可见文案中一律不得出现 URL / 域名明文**——跳转地址只作为「文献名」的跳转目标存在。
- **元数据封禁**：接口名（`mcp__<SERVER>__searchVectorBJ`）、服务名（`edu`）、域名（`ix.cnki.net` / `kns.cnki.net` / `www.cnki.net` / `oversea.cnki.net` / `login.cnki.net` / `x.cnki.net` 等）、字段名（`url` / `dbcode` / `tablename` / `filename` 等）、链接取值规则、检索报文（JSON）、内部推荐理由，严禁以任何形式出现在用户可见输出中。跳转链接仅作为「文献名」的跳转目标，**不得以明文形式出现在列表文本、卡片或文档里**。
