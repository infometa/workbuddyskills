# 知识卡片 · cnki-edu-knowledge-cards

面向中小学教师、学生与家长的知识卡片生成技能包。按「学段 + 学科 + 教材版本/单元 + 知识点」四个变量，把学科知识体系中相对独立的最小知识点（概念、公式、字词、名句、事件、易错点等）按「一卡一点」做成可直接用于备课、课堂呈现、课后复习与碎片自测的记忆卡片，支持 Markdown / 图片 / PDF / 文档 / 网页 / 思维导图（知识图谱）六种形态导出。思维导图形态默认采用**贴纸·手帐·生动化**视觉风格（发光中心节点 + 彩色贴纸分支 + 手帐贴纸卡 + ★重点星标 + 星点涂鸦），告别方框网格堆砌。

## 五条硬约束

1. **一卡一核心**——一卡只考一件事，出现两个独立问题立刻拆开。
2. **课标合规**——不超前、不超纲，术语与篇目严格落在所选学段的课标与教材范围内。
3. **事实优先**——无法确认的一律标"待核实"，严禁编造史料、条文、实验现象与教材页码。
4. **易错点必填且具体**——写"漏解：忽略 a=0 的情形"，不写"注意分类讨论"这类空话。
5. **安全前置**——涉加热、酸碱、明火、玻璃器皿、活体观察、体育动作的卡片，必须写明安全提示。

## 可选增强：中国知网文献辅助（edu 连接器）

本技能可**可选接入中国知网（CNKI）文献库**（需已连接知网教育 MCP，服务名 `edu`，且经 `mcp__<SERVER>__userState` 校验用户具备**基教权益**）。开启后：

- 当卡片的"解释 / 释义 / 权威定义 / 易错辨析 / 背景依据"需要权威佐证时，自动检索知网文献，**期刊（核心/普刊均可）、报纸、会议、博硕士、工具书—相关即收**（推荐 `type=0,1,2,3,4` 全量召回后分流）；非核心普刊不再单独剔除，凡相关即收。
- 对应用了知网文献知识的卡片，在**正文引用处用上标角标〔n〕**标注（如"……须依托语篇展开〔1〕"）。
- 卡片组**文末**统一附「参考资料」列表（标号 / 篇名〔超链接·指向知网在线阅读页或知网节〕/ 作者 / 来源(含年期) / 发表时间 / 类型），去掉独立"阅读"项、篇名即点击入口（链接取检索返回的 `url`），与正文〔n〕一一对应、可点开。
- 检索接口不返回 `作者` 与可读的 `来源全称`，这两项保留字段但标注"在知网平台阅读页查看完整题录"，**绝不编造**；检索不到则跳过，不影响正常出卡。

完整接口用法、检索式模板、来源筛选与年份/年期解析、降级策略见技能包内 `references/cnki-literature.md`。

## 安装到 WorkBuddy

**方式一：个人技能（推荐）**

把整个 `cnki-edu-knowledge-cards` 文件夹放到用户级技能目录：

- Windows：`C:\Users\<你的用户名>\.workbuddy\skills\cnki-edu-knowledge-cards\`
- macOS / Linux：`~/.workbuddy/skills/cnki-edu-knowledge-cards/`

**方式二：项目级技能（团队共享）**

放到当前项目的 `.workbuddy/skills/cnki-edu-knowledge-cards/`，同一项目内的成员即可共享。

**方式三：从 WorkBuddy 上传**

在技能管理界面选择「导入 / 创建技能」，上传本文件夹（或打包后的 `cnki-edu-knowledge-cards.zip`），按提示确认后启用。

> ⚠ 上传后用对话试一句触发语验证，例如：「帮我把七年级上册《观沧海》做成预习卡」。
