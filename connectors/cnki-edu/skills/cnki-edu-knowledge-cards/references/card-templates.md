# 卡片模板与结构骨架

本文件管**结构**：一张卡长什么样、必含哪些部件、生成后怎么自检。
各学科**卡片类型与逐项字段**见 [prompt-library.md](prompt-library.md) 对应学科章节，本文件不重复。

---

## 一、卡片通用结构（所有学科共用）

无论哪种卡片类型，一张合格的知识卡片必须包含六个部件：

| 部件 | 要求 |
|---|---|
| ① 类型与标签 | 卡片类型名 + 学科·学段标签，如【初中·化学·方程式卡】 |
| ② 正面（问句） | 是**问句**不是标题；≤30 字；一卡只问一件事（语文背诵卡除外，见学科规则） |
| ③ 背面（答案） | 按该卡片类型模板逐项填写，**字段不得删减**；核心记忆点加粗或分行突出 |
| ④ 易错点 | **必填且具体**，落到具体情形；不写"注意区分"这类空话 |
| ⑤ 标签与出处 | 标签：`[内容域] + [册次单元] + [知识类型]`；出处：如"统编八上 第 11 课《三峡》" |
| ⑥ 检索提示 | 首字、类别、对仗关系、记忆口诀等，帮助学生定位与回忆 |

**按需附加**：`安全提示`（实验/操作/体育必填）、`教师提示`（用于备课与分层）、`分层标注`（基础/提升/挑战）、`使用场景`（预习/课堂/复习/自测）。

## 二、单卡 Markdown 模板（默认输出格式）

```markdown
### 卡 03 ｜【小学·语文·字词卡】

**正面**
"潜伏"的"潜"读第几声？

**背面**
- 读音：qián（第二声）
- 提示：与"潜（qián）水艇"同音；不是"qiǎn"
- 易错字：右边是"替"，不是"赞"
- 出处：统编语文 五年级上册 第 5 课

**易错点**
读成第三声 qiǎn——受"浅"影响而误读（"潜/浅"形近义不同）。

**标签**：`[字词句] + [五上 第 5 课] + [字音]`
**检索提示**：第二声；右边是"替"
**使用场景**：预习速查 / 早读抽卡
```

批量时，每张卡之间用 `---` 分隔；卡片组开头加封面块（见下）。

## 三、卡片组封面 / 清单模板

批量任务在正式生成前先给用户确认这张清单：

```markdown
## 卡片组：〈学段〉〈学科〉〈教材版本/单元〉〈知识点范围〉
- 学段：初中 八年级上
- 学科：物理
- 教材版本：人教版
- 内容范围：第十章 浮力
- 卡片类型：公式与定理卡 + 易混概念辨析卡
- 数量：8 张
- 输出格式：Markdown（默认）

| 编号 | 标题 | 卡片类型 | 学段 | 备注 |
|---|---|---|---|---|
| 01 | 阿基米德原理的适用条件 | 公式与定理卡 | 初中 | — |
| 02 | 浮力产生的原因 | 基础概念卡 | 初中 | 需结构图 |
| ... | ... | ... | ... | ... |

> ⚠ 教材版本按〈统编版/人教版〉默认处理，请按实际所用教材核对。
```

**确认后方可逐卡生成**；用户说"就这样"或"开始生成"即视为确认。

## 五、常见卡片形态对照（用户口语 → 落地类型）

| 用户说的 | 实际落地 |
|---|---|
| 预习卡 / 导学卡 / 课前预习卡 | 核心概念卡 + 少量提示性问句卡，正面问句、背面要点，配"带问题读教材"的引导语 |
| 复习卡 / 单元过卡 / 期末过卡 | 知识汇总卡组合：每个知识点一张，或按"概念—公式—易错"三连 |
| 分层练习卡 / 分层任务卡 | 同一知识点出基础/提升/挑战三档，用 `分层标注` 区分 |
| 实验流程卡 / 操作流程卡 / 安全核对卡 | 实验要点卡 或 操作要点卡；**安全提示必须显式成块** |
| 抽卡问答 / 课堂互测 / 随堂卡 | 只出正面的问句卡集合，背面答案折叠或单独成页 |
| 口袋卡 / 碎片卡 / 手机翻卡 / 数字卡 / Anki 卡 / Quizlet 卡 | 短卡 + 网页/CSV 形态；字段压缩到"正/背/标签"三列，便于导入背诵软件 |
| 速查卡 / 知识清单卡 / 简练汇总 | 知识汇总卡：3—5 个要点，不展开 |
| 对比卡 / 易混卡 | 各学科的"易混概念/易混词/易混知识点辨析卡"，必须给对比表 + 口诀 + 自测题 |
| 时间线卡 | 时间节点卡，必含时间轴定位（前接 → 本事件 → 后续） |
| 概念卡 / 术语卡 | 核心概念卡 / 专业术语卡 |
| 作品知识卡 / 文学常识卡 / 篇目知识卡 / 章节知识卡 | 作品·人物识记卡 / 文学常识卡 / 课文阅读卡 |

## 六、知网文献标注（可选增强，需已连接 edu MCP）

开启知网文献辅助时，凡卡片正文（背面答案 / 释义 / 易错点）**应用了某篇知网文献的知识**，必须在知识处用**上标角标〔n〕**标注，并在卡片组**文末**统一附「参考资料」列表（不另设独立的"文献支撑/知网文献标注块"模块，也不在卡片右上角加角注徽标）。编号 n 跨整组卡片连续；被引文献须为相关文献（期刊/报纸/会议/博硕士/工具书相关即收），详见 [cnki-literature.md](cnki-literature.md)。

### 6.1 正文内上标角标〔n〕（必做）

在应用了文献知识的句子末尾加 〔n〕（即用户要求的"引用处标注角标"），如"……须依托语篇展开〔1〕"。角标落在内容句末，不另起一块：

```markdown
**背面**
- 释义：浮力是浸在液体或气体中的物体受到向上托的力〔1〕；其大小等于物体排开液体所受的重力（阿基米德原理）〔1〕。
- 易错点：误以为"浮力大小与物体自身重力有关"——浮力只与液体密度和排开体积有关〔2〕。
```

### 6.2 文末「参考资料」列表（必给）

> **定位**：卡片内容（知识点、释义、易错点）永远是主角；参考资料只是**辅助厘清**的从属板块，**不可喧宾夺主**。故：置于**卡片组最末尾**、数量 **1–3 篇**克制、**每条一行轻量紧凑**、用**小级别标题**、不做面板不加粗重边框。

卡片组**文末**统一附「参考资料」，按正文〔n〕顺序排列。每条**一行**，格式：

```
〔n〕《篇名》 · 作者 · 来源(含年期) · 类型 · 发表时间
```

**篇名为超链接**（指向知网在线阅读页/知网节，取检索返回的 `url` 字段），不设独立"阅读"项。

```markdown
#### 参考资料

〔1〕《浮力产生的原因与大小决定因素辨析》 · 〔在知网平台阅读页查看完整题录〕 · 《物理通报》2023年第05期 · 期刊 · 2023年
〔2〕《……》 · …… · 《……》2024年会议 · 会议论文 · 2024年
```

- 标号：与正文上标角标〔n〕一致。
- 篇名：取自 `篇名`（文献标题），并渲染为超链接（链接构造见 [cnki-literature.md](cnki-literature.md) 7.3，优先 `url` 字段——知网单篇在线阅读页 `ix.cnki.net/read/article/readonline?...`（与"投稿选刊"一致），否则题名检索入口 `kns.cnki.net/kns8s/defaultresult/index?kw=篇名`（与 `ix.cnki.net` 同属知网主站、共用统一登录））。
- 作者：取 `Author`（接口已返回，可直接写入）；仅当确为空时标注"在知网平台阅读页查看完整题录"，**严禁编造**。
- 来源(含年期)：取 `Source`/`JournalName`(来源/刊名) + 年期，年期从 `PubDate`/`Year` 解析；字段确为空才标"详见阅读页题录"。
- 发表时间：从 `PubDate`/`Year` 解析；取不到写"未确认"。
- 类型：按 `resource` 标注为 期刊 / 报纸 / 会议论文 / 学位论文 / 工具书（期刊核心/普刊均可，相关即收）。
- 篇名超链接：指向该篇目在知网平台的在线阅读页/知网节，链接取检索接口返回的 `url` 字段（构造见 [cnki-literature.md](cnki-literature.md) 7.3）。不设独立的"阅读"项。

> 被引文献**期刊（核心/普刊均可）、报纸、会议论文、博硕士论文、工具书—相关即收**：期刊不再要求核心（核心/普刊均相关即收），不作核心期刊过滤；报纸、会议论文、博硕士论文、工具书只要与知识点相关即纳入。作者与来源全称接口不返回，保留字段但标注"在知网平台阅读页查看完整题录"，**绝不编造**。

### 6.3 卡片级轻量「依据」行（推荐，保持卡片洁净）

每张**引用了文献**的卡片，可在卡片末尾加一行轻量依据，只列篇名不展开完整题录，让印刷/速查时卡片本身也有即时权威感（完整题录仍在组末「参考资料」）：

```markdown
**依据**：〔1〕《浮力产生的原因与大小决定因素辨析》〔2〕《……》
```

- 只列该卡正文〔n〕对应的篇名（保留《》），不写作者/来源/链接，保持一行干净。
- 卡片未引用文献时不加此行。
- 网页/可交互形态：正文〔n〕渲染为可点击角标，点击跳转到组末对应题录（见 [references/card-page-template.html](../references/card-page-template.html)）；卡片底「依据」行同样可点。

## 七、生成后自检清单（逐卡过一遍）

- [ ] 一卡只问一件事；出现两个独立问题已拆开。
- [ ] 正面是问句（≤30 字），不是标题、不是陈述句。
- [ ] 模板字段**逐项齐全**，无缺项、无"略"。
- [ ] 适用条件/成立条件已写（数学、理科尤其致命，缺失即废卡）。
- [ ] 易错点具体到情形，不是空话。
- [ ] 涉实验/操作/体育动作的卡片，安全提示已成块写明。
- [ ] 标签（内容域＋册次单元＋知识类型）与出处标注齐全。
- [ ] 术语在本学段准入范围内，无超纲、无超前概念。
- [ ] 无法确认的信息已标"待核实 / ⚠请按所用教材版本核对"，没有编造。
- [ ] 卡片篇幅在一张 A6 或 16:9 卡片内排得下。
- [ ] （若启用知网辅助）应用了知网知识的卡片在正文引用处用**上标角标〔n〕**标注；卡片组**文末**统一附「参考资料」列表，（标号 / 篇名〔超链接〕/ 作者 / 来源(含年期) / 发表时间 / 类型）齐全，篇名为链接、不设独立"阅读"项；作者/来源全称缺失时标注"在知网平台阅读页查看完整题录"，未编造；正文〔n〕与文末参考资料一一对应。
- [ ] （若启用知网辅助）**被引文献均为相关文献**（期刊/报纸/会议/博硕士/工具书相关即收，核心/普刊均可），**不限出版年份**（任何年份的相关文献均可纳入），无跨类顶替、无编造文献。
