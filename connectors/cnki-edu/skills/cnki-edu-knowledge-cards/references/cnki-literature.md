# 知网文献辅助（CNKI Literature Assistance）

本文件教本技能如何**借中国知网（CNKI）文献库，给知识卡片里的"解释 / 释义 / 权威定义 / 易错辨析 / 背景依据"补一条可溯源的证据**，并以"正文引用处上标角标〔n〕 + 卡片组文末「参考资料」列表"的方式融入卡片组。**被引文献须为相关文献**，不另设独立的"文献支撑 / 知网文献标注块"模块，也不在卡片右上角加角注徽标。

> 本文件只负责"检索 + 引用 + 标注"，不做内容生成。检索到的观点必须与卡片正文分开标注，不得混为一谈；且任何文献元数据（题名 / 作者 / 来源 / 年期 / 发表时间）**一个都不能编造**。
>
> 本能力是**可选增强**：未通过 `mcp__<SERVER>__userState` 基教权限校验（未连接 `edu` MCP / 用户无知网基教权限）时，本技能照常出卡，只是不出现角标与参考资料列表；**并提示用户前往 e.cnki.net 开通 / 购买基教服务**。

---

## 一、什么时候检索（触发条件）

知识卡片的核心诉求是"一卡一点、准确无误"。当某张卡片的"背面答案 / 释义 / 易错点"属于下列情形，且已连接 `edu` MCP，就检索知网文献做权威佐证：

| 场景 | 是否检索 | 说明 |
|---|---|---|
| 字词 / 文言字词 / 术语的**权威释义、歧义辨析**（如多义字、古今异义、专业术语界定） | ✅ 建议检索 | 用知网文献佐证，避免自说自话 |
| 概念 / 公式 / 定理的**内涵界定、来龙去脉、学界共识**（如"浮力""浮力产生的原因""质量守恒定律的提出"） | ✅ 建议检索 | 找权威释义与背景依据 |
| 名句 / 古诗文 / 文学常识的**赏析、主旨、创作背景** | ✅ 建议检索 | 找**文学赏析 / 鉴赏 / 创作背景**类**纯知识**文献（非教学/教研类） |
| 历史事件 / 制度 / 地理事物的**解读、因果、背景** | ✅ 建议检索 | 找**史实考证 / 制度释义 / 地理成因解读**类**纯知识**文献（非教研类） |
| 实验原理 / 现象结论的**权威解释** | ✅ 建议检索 | 找**科学原理阐释 / 现象科普解读**类**纯知识**文献（非教学类） |
| 单纯照教材默写、拼音、字形、计算步骤、课标原文摘引 | ⛔ 不检索 | 教材/课标原文即可，文献不能替代原文 |
| 用户已上传教材 / 课标原文且只问单条 | ⚪ 可选 | 原文够用时不必检索；用户要求"补依据"再检索 |
| 纯速查、纯抽卡问答（只要正面问句） | ⚪ 可选 | 只在用户明确要"参考资料/文献依据"时检索 |

> ⚠️ **内容性质红线（与来源类型约束并列的硬约束）**：上述"建议检索"场景一律**只取关于知识内容本身的纯知识文献**，**排除一切教学/教研类文献**——即排除以"如何教、怎么学、教材怎么处理、课程怎么设计"为对象的文献（教学设计、教法、教材分析、课标/课程解读、学业评价、试题研究等）。即便来源再权威，只要落脚点是"教"而非"知"，一律不纳入。可纳入的纯知识资料类型见第三节 3.1（科普 / 时政 / 文艺文化 / 政治法律 / 学科本体研究等）。

**默认策略**：命中上述"建议检索"场景即检索，检索有相关结果就在对应卡片正文加〔n〕角标、文末附「参考资料」；检索失败或无相关结果则省略角标与参考资料——**不得因为检索不到就编造文献**。

## 二、可用接口（edu MCP，2026-10 实测复核）

知网教育 MCP（服务名 `edu`）提供两个检索接口。**其余接口（mcp__<SERVER>__tkBook / mcp__<SERVER>__tkPoint / mcp__<SERVER>__tkSearchQuestion / mcp__<SERVER>__tkSubject 等）是题库与教材接口，与文献辅助无关，不要调用。**

### 2.1 文献库检索（推荐首选）

`mcp__<SERVER>__searchVectorBJ` —— 按文本向量检索文献库，返回**篇名级**结果（含篇名、`Author`、`Source`/`JournalName`、`PubDate`、`Year`、`ResourceType`、正文/摘要、小标题等；⚠️ 当前响应**不返回** `url` / `文件名`）。

| 参数 | 说明 |
|---|---|
| `text` | **必填**，查询文本 |
| `query_type` | 0 篇名 / 1 摘要 / 2 小标题 / 3 主题（**推荐 1**："摘要"召回质量最稳） |
| `maxRecallNumber` | 最大返回数，默认 20；推荐 **20–30** |
| `nprobe` | 最近邻聚类中心数，默认 15；召回不足时可提到 30 |
| `type` | 文献类型过滤：`0 期刊` `1 硕士` `2 博士` `3 会议` `4 报纸`。本技能**期刊（核心/普刊均可）、报纸、会议、博硕士、工具书—相关即收**，推荐传 `0,1,2,3,4` 全量召回，再按来源类型分流：期刊（核心或普刊，相关即收）、报纸/会议/博硕士/工具书相关即收；若仅想先查期刊释义，也可只传 `type=0` |

### 2.2 段落库检索（需要具体段落时用）

`mcp__<SERVER>__searchVectorBJPara` —— 按文本向量检索段落库，返回**段落级**结果（含父文献篇名、当前小标题、章节序号、文件ID）。

| 参数 | 说明 |
|---|---|
| `text` | **必填**，查询文本 |
| `query_type` | 0 篇名小标题 / 1 段落主题（**推荐 1**） |
| `maxRecallNumber` | 同 2.1 |
| `nprobe` | 同 2.1 |
| `type` | 同 2.1，可用，覆盖四类文献资源 |

**两者怎么选**：
- 想知道"**有哪些文献**谈过这个知识点" → `mcp__<SERVER>__searchVectorBJ`（文献库）
- 想直接拿到"**某段具体论述**"（如某概念的界定、某名句的主旨赏析） → `mcp__<SERVER>__searchVectorBJPara`（段落库）
- 两者可以**各查一次再合并**，效果最好。

### 2.3 返回字段解读（实测）

> ⚠️ **字段现实（2026-10 实测 `mcp__<SERVER>__searchVectorBJ` 真实响应）**：接口**直接返回** `Author`(作者)、`Source`/`JournalName`(来源/刊名)、`PubDate`(发表日期)、`Year`(年)、`ResourceType`/`resource`(类型) 等结构化字段——这些可直接写入卡片，不必标"在知网平台阅读页查看完整题录"（仅当字段确为空时才标"详见阅读页题录"）。**真正的缺口是 `url` 与 `文件名`**：当前响应**不返回**直链 `url` 与内部文章键 `文件名`，故无法拼出"本篇在线阅读直链"，链接统一走 7.3 的「`url` 优先（`ix.cnki.net/read/article/readonline?...`，与"投稿选刊"一致）、否则题名检索 `kns.cnki.net/kns8s/defaultresult/index?kw=篇名`（与 `ix.cnki.net` 同属知网主站、共用统一登录）」方案。

| 字段 | 含义 | 用途 |
|---|---|---|
| `篇名` | 文献标题 | → 卡片/网页之「篇名」；判断是否切题 |
| `Author` | 作者 | 直接写入「作者」字段（接口已返回，无需标"查看题录"） |
| `Source` / `JournalName` | 来源/刊名 | 直接写入「来源（年期）」字段 |
| `PubDate` | 发表日期（如 `2026-09-10`） | → 解析「年期/发表时间」的**可靠来源**（见第四节）；同时用于排序 |
| `Year` | 年（如 `2026`） | 发表时间年份；`PubDate` 缺失时兜底 |
| `正文` | 摘要或正文片段 | 判断是否为该知识点的权威释义/解读；偶尔含作者/出处线索，仅作辅助，**不得据此编造作者/来源** |
| `小标题` | 目录/小标题串 | 看文献结构覆盖面 |
| `ResourceType` / `resource` | `期刊`/`中国会议`/`硕士`/`博士` 与 `JOURNAL`/`CONFERENCE`/`DISSERTATION`/`NEWSPAPER` | 类型判定；期刊（核心/普刊）相关即收、其余（会议/博硕士/报纸/工具书）相关即收 |
| `coreJournals` | 是否核心期刊（`"Y"` 表示核心） | 仅作参考标签，本技能不据此过滤期刊（核心/普刊均相关即收） |
| `文件名` | ⚠️ **当前 `mcp__<SERVER>__searchVectorBJ` 响应不返回此字段** | 旧文档曾用其解析年期，现改由 `PubDate`/`Year` 解析；不再依赖、也不再用于对外展示或拼接链接 |
| `url` | ⚠️ **当前 `mcp__<SERVER>__searchVectorBJ` 响应不返回此字段** | 若未来接口返回，则作为篇名 `href` 直链（见 7.3）；当前统一走题名检索入口 `kns.cnki.net/kns8s/defaultresult/index?kw=篇名` |
| `文件ID` | 段落库中父文献编号（当前通常不返回） | 仅内部定位，不对外展示 |
| `CoreIndex` | 核心索引（如 `P01` 北大核心、`CSSCI` 等） | 仅作参考标签，本技能不据此过滤期刊 |
| `CSSCI` | 是否 CSSCI（`"Y"` 表示 CSSCI） | 仅作参考标签，本技能不据此过滤期刊 |
| `相关度` / `距离` | 相关度百分比 / 余弦距离（越小越近） | 排序参考 |

> **期刊核心判定**（三者命中其一即为核心；本技能不再据此过滤，核心/普刊均相关即收，仅作参考）：`coreJournals = "Y"`、或 `CoreIndex` 非空（北大核心 / AMI 核心等）、或 `CSSCI = "Y"`。

## 三、筛选约束（内容性质 + 来源类型，均为硬约束）

知网文献能否纳入，必须**同时满足**两条硬约束：① **内容性质约束**（3.1，排除教学/教研、只取知识本体）；② **来源类型约束**（3.2，期刊/报纸/会议/博硕士/工具书相关即收）。任一不满足即剔除——**来源再权威，只要是教学/教研类也排除；内容再是纯知识，只要来源类型不相关也排除**。

### 3.1 内容性质约束（排除教学/教研，只取关于知识内容本身的纯知识资料）

本技能引用知网文献的目的是"**辅助厘清知识内容本身**"，**不是**提供教法参考。因此参考文献必须是**关于本知识内容本身的纯知识资料**，主题以"知识本体"为核心，而非"如何教"。

**❌ 一律排除（不纳入）—— 以"教学/教研"为对象的文献**：凡标题或正文落脚点落在"怎么教、怎么学、教材怎么处理、课程怎么设计"的，即便来自核心期刊也剔除。典型判定关键词（标题/正文含其一即高度可疑，需人工确认落脚点）：`教学设计`、`教学策略`、`教学方法`、`教学模式`、`教学建议`、`教材分析`、`教材解读`、`课程/课标解读`、`教学案例`、`课堂实录`、`学业评价`、`试题研究`、`作业设计`、`教学反思`、`微课`、学科教学（如"XX 教学研究""XX 概念的教学建议"）、`教研`。

> **判定口诀**：看文献是在"**讲知识**"，还是在"**讲怎么教知识**"。前者可纳入，后者一律排除——即便文献标题含知识点名称，只要落脚点是"教"而非"知"，仍排除。

**✅ 优先纳入（只要相关即收）—— 关于知识内容本身的纯知识资料**，例如：
- **科普类**：科学原理阐释、自然/生活现象解读、技术应用与进展介绍；
- **时政类**：时事政策解读、新闻事件背景与来龙去脉；
- **文艺文化类**：文学赏析/鉴赏、创作背景、文化源流、艺术作品与文物解读；
- **政治法律类**：制度释义、法条/法理辨析、政策背景、历史事件考证；
- **学科本体研究**：概念界定、定理/定律的来龙去脉、史实考证、地理事物成因、术语释义、实验/现象的科学解释等（即"知识本体"文献）。

### 3.2 来源类型约束（硬约束，优先于一般筛选）

本技能输出的知网文献按"**期刊（核心/普刊均可）、报纸、会议论文、博硕士论文、工具书—相关即收**"处理——期刊类不再要求核心（核心/普刊均相关即收），不作核心期刊过滤；**报纸、会议论文、博硕士论文、工具书**只要与知识点相关即纳入。

| 来源类型 | 本技能处理 |
|---|---|
| 期刊（核心） | ✅ 纳入（相关即收） |
| 期刊（非核心/普刊） | ✅ 纳入（相关即收） |
| 报纸 | ✅ 相关即收 |
| 会议论文 | ✅ 相关即收 |
| 博硕士论文 | ✅ 相关即收 |
| 工具书 | ✅ 相关即收 |

若两条约束过滤后无合格结果，明确写出"本次未检索到关于知识内容本身的纯知识（非教学/教研）文献"，不跨级顶替、不编造。

## 四、年限、年期与发表时间解析（核心约束）

接口没有年份参数，只能在拿到结果后**按返回的时间字段（`PubDate` / `Year`）解析并过滤**（⚠️ 实测 `mcp__<SERVER>__searchVectorBJ` 当前**不返回 `文件名` / `url`**，旧的"按文件名解析"口径已失效）。

### 4.1 `PubDate` / `Year` → 年期 / 发表时间 解析规则（按真实返回字段）

> ⚠️ 实测 `mcp__<SERVER>__searchVectorBJ` 响应**不返回 `文件名` / `url`**，故不再按文件名解析；统一用 `PubDate`(如 `2026-09-10`)、`Year`(如 `2026`)、`ResourceType`/`resource` 判定。

| 文献类型 | 取值来源 | 年期 / 发表时间 解析 |
|---|---|---|
| 期刊 | `PubDate` + `Year` | 年期 = `{Year}年第{MM}期`（`MM` 取 `PubDate` 月）；发表时间 = `Year年` |
| 会议（中国会议） | `PubDate` + `Year` | 年期 = `{Year}年会议`；发表时间 = `Year年` |
| 报纸 | `PubDate` | 年期与发表时间 = `PubDate`（报纸按刊发日） |
| 博硕士（硕士/博士） | `PubDate` + `Year` | 发表时间 = `Year年`；`PubDate` 含月日则保留 |
| 工具书 | — | 以阅读页题录为准，标注「详见阅读页题录」 |

> `PubDate` 缺失时回退用 `Year` 给到"XXXX年"即可；仍缺失才标注「发表时间未确认，详见阅读页题录」。

### 4.2 出版年门槛（**已取消：不限年份**）

本技能**不设出版年门槛**——任何年份出版的相关文献均可纳入，**不限年份**。文献取舍只看三项：**切题度、来源类型（相关即收）、权威度**，不再以"是否落在某课标颁布年之后"作为过滤条件。

> 旧版曾按学段设硬门槛（义教 ≥ 2022 年、高中 ≥ 2017 年），现已移除；历史、学科史、人物类等早年期文献（如经典学科史梳理、奠基性研究）只要切题且来源合规，即可正常引用。

**优先级排序（同等切题度下，软偏好而非硬约束）**：年份新 → 相关度高 → 期刊核心级别高（CSSCI / 北大核心优先，仅作排序加分、非纳入门槛）。年份仅作排序参考，**不作为纳入或剔除的门槛**。

## 五、检索式构造（4 段式模板）

把知识点要素填进模板，**可辨识度最高**：

```
{学科} + {学段/年级} + {知识点/术语} + {意图词}
```

| 位置 | 取值示例 |
|---|---|
| 学科 | `语文` / `初中物理` / `高中历史` |
| 学段/年级 | `小学` / `初中` / `高中` / `高一` |
| 知识点/术语 | `浮力` / `潜（qián）` / `赤壁赋` / `辛亥革命` |
| 意图词 | `释义` / `内涵` / `辨析` / `解读` / `背景` / `赏析` / `科普` / `成因` / `考证` |

**组合示例**（可直接用）：

| 目的 | 检索文本 | 建议 `type` |
|---|---|---|
| 全类型（期刊/其余均相关即收） | `初中物理 浮力 产生的原因 释义` | `0,1,2,3,4` |
| 只看期刊权威释义 | `高中语文 赤壁赋 主旨 赏析` | `0` |
| 学科本体 / 科普类文献 | `初中化学 质量守恒定律 内涵 科普` | `0,1,2` |

**检索次数建议**：一般 **1–2 次**（文献库 1 次 + 段落库 1 次）足够；话题偏冷或首轮切题率低于 1/3 时，换意图词或换 `type` 再查一次，**最多 3 次**，避免无谓开销。

## 六、结果筛选（**必须做，向量检索会误召回**）

实测中会出现与知识点无关的"语义近邻"。按下列顺序筛：

0. **看内容性质（排除教学/教研）**：文献落脚点是"讲知识"还是"讲怎么教"？凡教学/教研类（教学设计、教法、教材分析、课标/课程解读、学业评价、试题研究等）**一律剔除**，无论来源与是否核心；只保留关于知识内容本身的纯知识资料（科普 / 时政 / 文艺文化 / 政治法律 / 学科本体等）。
1. **看 `正文` 是否真的谈这个知识点**：篇名/正文明显切题 → 保留；完全不相关（如查"浮力"却返回无关段落）→ 直接剔除。
2. **看学科是否对上**：正文出现目标学科术语（或通用/跨学科研究）→ 保留；学科明确不符 → 剔除。
3. **看学段是否对上**：小学 vs 初中 vs 高中不得串味。
4. **按来源类型分流**：经"3.2 来源类型约束"过滤——期刊（核心或普刊，相关即保留）、报纸、会议论文、博硕士论文、工具书只要相关即保留；不相关来源剔除，不得跨类顶替。（内容性质约束已在第 0 步完成。）
5. **出版年不再设门槛**（详见 4.2：不限年份，任何年份的相关文献均可纳入，仅以切题度与来源类型约束取舍）。
6. **排序**：切题度 → 年份新 → 相关度高 → 期刊核心级别高（软偏好）。
7. **取用数量**：单卡引用 **1–3 篇**文献为宜，宁精勿多；整组卡片合计不超过 8 篇；期刊（核心/普刊）均可、其余相关即可；若合格结果不足，按实际合格数量引用，不得用无关文献凑数。

## 七、上标角标〔n〕与文末「参考资料」列表（新引用方式，替代旧的"右上角角注块 + 知网文献标注块"）

本技能已取消"卡片右上角角注块 + 文末「📚 知网文献标注块」"的旧呈现。改为：

- **正文上标角标〔n〕**：在卡片正文**引用了知网文献的具体句子末尾**加 〔n〕（即用户要求的"引用处标注角标"），如"……须依托语篇展开〔1〕"。角标落在内容处，而非另起一块。
- **文末「参考资料」**：卡片组末尾集中列出全部被引文献（标号 / 篇名〔超链接〕/ 作者 / 来源 / 发表时间 / 类型），与正文〔n〕一一对应、可点开。
- 二者编号一致，做到"正文哪里引用、文末哪里可查"。**不另设独立的"文献支撑"模块"。

### 7.1 正文内上标角标〔n〕（必做）

```markdown
**背面**
- 释义：浮力是浸在液体或气体中的物体受到向上托的力〔1〕；其大小等于物体排开液体所受的重力（阿基米德原理）〔1〕。
- 易错点：误以为"浮力大小与物体自身重力有关"——浮力只与液体密度和排开体积有关〔2〕。
```

### 7.2 文末「参考资料」列表（必给）

> **定位铁律**：本技能的主角永远是**卡片内容本身**（知识点、释义、易错点）。参考资料只是**从属、辅助**板块，用于"辅助解释 / 厘清知识点"，**不可喧宾夺主**。

据此执行四条约束：

- **位置从属**：永远置于卡片组**最末尾**（全部卡片之后），不插在卡片中间、不前置。
- **数量克制**：够用即可，一个卡片组 **1–3 篇**；不堆量、不为凑数而引用。
- **版式轻量**：用**小级别标题**（`#### 参考资料`）、小字号/弱化色呈现；**每条一行紧凑排列**，去掉冗长的"作者：/来源：/发表时间：/类型："字段标签；不做大标题、不做面板卡片、不加粗重边框。
- **不打断主线**：文献只在"需要佐证或厘清"处出现〔n〕角标，卡片正文始终占据主要篇幅与视觉重心。

卡片组**文末**统一附「参考资料」，按正文〔n〕顺序排列。每条**一行**，格式为：

```
〔n〕《篇名》 · 作者 · 来源(含年期) · 类型 · 发表时间
```

其中**篇名为超链接**（指向该篇目在知网平台的在线阅读页/知网节，链接取检索接口返回的 `url` 字段，构造见 7.3）；不设独立的"阅读"项。

```markdown
#### 参考资料

〔1〕《浮力产生的原因与大小决定因素辨析》 · 〔在知网平台阅读页查看完整题录〕 · 《物理通报》2023年第05期 · 期刊 · 2023年
〔2〕《……》 · …… · 《……》2024年会议 · 会议论文 · 2024年
```
> ⚠️ 篇名须满足 3.1 内容性质约束：**纯知识、非教学/教研**（示例〔1〕为"知识本体"类释义，而非"XX 概念的教学建议"之类的教研类题名）。

- 标号：与正文上标角标〔n〕一致。
- 篇名：取自 `篇名`，并渲染为超链接（链接构造见 7.3）。
- 作者：接口不返回，标注"在知网平台阅读页查看完整题录"，**严禁编造**。
- 来源(含年期)：取 `Source`/`JournalName`(来源/刊名) + 年期（年期从 `PubDate`/`Year` 解析，见第四节）；字段确为空才标"详见阅读页题录"。
- 发表时间：从 `PubDate`/`Year` 解析；取不到写"未确认"。
- 类型：按 `resource` 动态标注——`JOURNAL`→期刊、`NEWSPAPER`→报纸、`CONFERENCE`→会议论文、`DISSERTATION`→学位论文；工具书单独标为"工具书"。期刊项对外只写"期刊"，不显示是否核心。
- 篇名超链接：指向该篇目在知网平台的在线阅读页/知网节，链接取检索接口返回的 `url` 字段（构造见 7.3）。不设独立的"阅读"项。

### 7.3 篇名超链接构造（知网平台阅读/下载入口）

每条文献的**篇名**即点击入口，链接指向该篇目在知网平台的在线阅读页 / 知网节。**篇名 `href` 优先取用检索接口返回的 `url` 字段**（知网单篇在线阅读页 `https://ix.cnki.net/read/article/readonline?dbcode=…&tablename=…&filename=…&fileSourceType=1`，与"投稿选刊"的 `readUrl` 完全一致，点击由知网负责登录 / 鉴权，本技能不自行拼装、也不展示登录说明）；⚠️ 实测当前 `mcp__<SERVER>__searchVectorBJ` 响应不含 `url` / `文件名` 字段，此时**回退到按题名检索的知网主站官方入口**（与 `ix.cnki.net` 同属知网主站、共用统一登录，未登录时登录页与"投稿选刊"一致）：

```
https://kns.cnki.net/kns8s/defaultresult/index?kw=＜题名＞
```

- 在线阅读与全文/PDF 下载由知网平台负责，本技能本身不托管全文。
- 不再使用 `文件名`（文章键）拼接文章详情页链接：该类链接经实测会 404 无法打开，且文件名属内部标识、不宜对外展示。
- 若按题名检索结果较多，可在检索页用「作者 / 来源(年期)」进一步定位到本篇。

### 7.4 卡片底轻量「依据」行 与 网页〔n〕可点击（推荐）

- **卡片底「依据」行**：每张引用了文献的卡片，可在卡片末尾加一行轻量依据，只列篇名不展开完整题录，让印刷/速查时卡片本身也有即时权威感；完整题录仍在组末「参考资料」。
  ```markdown
  **依据**：〔1〕《浮力产生的原因与大小决定因素辨析》〔2〕《……》
  ```
  规则：只列该卡正文〔n〕对应的篇名（保留《》），不写作者/来源/链接；卡片未引用文献时不加此行。
- **网页/可交互形态〔n〕可点击**：在 HTML 网页模板（[references/card-page-template.html](../references/card-page-template.html)）中，正文〔n〕与卡片底「依据」行均渲染为可点击角标，点击平滑跳转到组末「参考资料」对应题录（题录 `<li>` 带 `id="ref-n"`），兑现"可查、可点"。

### 7.5 输出呈现纪律（接口元数据零暴露，安全红线）

> 跨场景统一版「干净输出红线」见 [_shared.md](_shared.md)「干净输出红线」；本节为本技能场景化补充，不得与 _shared 冲突。

> **本条红线的本质**：面向用户的输出中**不得出现任何知网接口响应的元数据字段名或字段值**，此类内部标识只可存在于超链接 `href` 属性与锚点 `id` 属性中（渲染后不可见），仅供底层链接构造与 Agent 内部决策使用。

生成的 md / HTML 卡片与导图中，参考资料部分只呈现"干净的教师 / 学生可读内容"，**严禁在最终文档中出现任何涉及知网接口的元数据字段名、字段值或内部实现机制的敏感信息 / 代码符号**，具体：

- ❌ 不显示 `文件名` / `filename` / `文件ID` 等知网内部文章键；
- ❌ 不把 `url` 字符串本身作为**可见文字**展示（如把 `https://ix.cnki.net/...` 写成正文 / 说明文字），也不标注"阅读地址链接"；但 `url` 作为超链接 `href` 属性（仅底层、渲染不可见）是**允许且推荐**的（见 7.3）。
- ❌ 不出现任何代码符号 / 标签文本，如 `<a>`、`id="ref-n"`、`<code>`、HTML 片段；
- ❌ 不出现说明性技术文字，如"篇名为指向知网平台在线阅读页的超链接""同时设锚点 `id="ref-n"`""文件名用于解析年期"等；
- ❌ 不在「参考资料」标题上附加"（知网文献 · 辅助解读）""（知网文献）"之类的修饰性括注，标题只用 `#### 参考资料`；
- ❌ 不向用户展示任何检索 / 筛选过程的说明性文字（如"本次文献检索以博硕士论文、会议论文为主""文献作者与来源取自检索返回题录""年份/年期由返回数据解析"等）；此类内部口径只用于 Agent 内部决策，严禁进入面向用户的输出；
- ❌ 不暴露类型 / 来源库内部代码（`type=0,1,2,3,4`、`CJFD`/`CAPJ`/`CPFD`/`CMFD`/`CCND`、`JOURNAL`/`CONFERENCE`/`DISSERTATION`/`NEWSPAPER`）与 `coreJournals`/`CoreIndex`/`CSSCI` 判定字段值，对外只写人读的"期刊 / 会议论文 / 博硕士 / 报纸"与"（核心）"结论；
- ❌ 不暴露内部阅读直链 URL（即 `url` 字段的字符串本身）——仅作为 `href` 属性使用（渲染不可见），严禁作为可见文字出现；且**禁止**用 `dbcode`/`tablename`/`filename` 自行拼装该链接（接口当前不返回这些参数，无法可靠构造，统一走 `url` 字段或题名检索官方入口即可）。
- ❌ **篇名不加下划线**——HTML 中篇名链接须显式 `text-decoration:none`（仅用颜色 + 加粗区分可点击，绝不依赖浏览器默认下划线）。

✅ 允许且必须保留的"不可见"功能：篇名本身是可点击的超链接（链接写在标记 `href` 中、不显示为文字），以及向内锚点 `id="ref-n"`（写在标记属性中、不显示为文字），使正文〔n〕能跳到文末对应篇名——这些仅存在于文档底层标记，**渲染后不可见**，不违反上述红线。

## 八、安全约束（铁律）

- **文献不编造**——题名、作者、来源、年期、发表时间一个都不能猜。检索接口不返回 `作者` 与可读的 `来源全称`，这两项在参考资料中必须保留但标注"在知网平台阅读页查看完整题录"，绝不编造；检索不到就写"本次未检索到相关的切题文献"。
- **来源类型约束**：参考资料中期刊（核心/普刊均可）、报纸、会议论文、博硕士论文、工具书只要相关即收（见 3.2），不作核心期刊过滤。
- **内容性质约束**：参考资料仅收关于知识内容本身的纯知识资料，**排除一切教学/教研类文献**（教学设计、教法、教材分析、课标/课程解读、学业评价等），即便核心也不纳入（见 3.1）。
- **年份/年期取不到就写「未确认」**，不得猜测。
- **不得改写文献结论**：概括只能压缩，不得加料；原话标「原文摘录」。
- **文献观点与卡片正文分区**：正文写卡片答案，文献证据以正文带〔n〕角标的句子呈现，文末「参考资料」给题录与链接，不混写；文献与教材/课标冲突时以教材/课标原文为准。
- **不超纲**：引用的文献解读深度须落在所选学段内，不得把高学段论述塞进低学段卡片。

## 九、降级策略

| 情况 | 处理 |
|---|---|
| 未通过 `mcp__<SERVER>__userState` 基教权限校验（未连接/无基教权益） | **先输出 e.cnki.net 购买引导**，再跳过检索；卡片组不出现正文〔n〕角标与「参考资料」列表，其余出卡正常（不编造文献） |
| 接口返回 `{"code":500,"msg":"检索失败！"}` | 先去掉 `type` 重试 1 次；仍失败则降级跳过检索 |
| 返回 0 条 / 全部误召回 | 换意图词或换 `type` 重试至多 2 次；仍无 → 按无结果处理 |
| 结果全部为不相关 / 跨学段 / 跨类 | 明确写明"仅检索到不相关或跨类文献，未纳入"，**不做跨类顶替** |
| 结果全部为教学/教研类（无纯知识资料） | 明确写明"本次未检索到关于知识内容本身的纯知识（非教学/教研）文献"，**不纳入教研类结果做顶替** |
| 结果无合格项（含其余类型不相关 / 仅教学教研类） | 明确写明"本次未检索到相关的切题/纯知识文献"，不跨类顶替 |
| 用户明确说"不用查文献" | 跳过检索，直接按教材/模型知识出卡 |

## 十、在卡片中的落位示例

```markdown
### 卡 03 ｜【初中·物理·基础概念卡】

**正面**
什么是浮力？它的大小由什么决定？

**背面**
- 释义：浮力是浸在液体或气体中的物体受到液体或气体向上托的力〔1〕。
- 决定因素：大小等于物体排开的液体（或气体）所受的重力，即阿基米德原理〔1〕；只与液体密度和排开体积有关，与物体自身重力、深度无关〔2〕。
- 出处：人教版 八年级物理 下册 第十章

**易错点**
误以为"浮力大小等于物体重力"或"与浸没深度有关"——浮力由排开液体重力决定，深度只改变压强不改变浮力〔2〕。

**标签**：`[力学] + [八下 第十章] + [概念]`
**检索提示**：向上托的力；F浮 = ρ液gV排

#### 参考资料

〔1〕《浮力产生的原因与大小决定因素辨析》 · 〔在知网平台阅读页查看完整题录〕 · 《物理通报》2023年第05期 · 期刊 · 2023年
〔2〕《……》 · …… · 《……》2024年会议 · 会议论文 · 2024年
```
