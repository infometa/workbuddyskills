# 知识卡片（cnki-edu-knowledge-cards）

把中小学各学科知识点做成「一卡一点、短少精、可速查可背诵可导出」的轻量学习载体，一次调用完成"识别意图 → 确认要素 → 检索生成 → 格式化 → 迭代 → 导出"的全流程。

核心原则：**一卡一核心，语言简洁，准确无误，符合课标，不超纲，不杜撰**。涉实验必写安全提示，不生成与课堂场景无关的长篇内容。

## Quick Start

1. 从用户输入识别**四要素**：学段、学科、教材版本/单元、知识点（+ 期望的卡片类型与输出格式）。
2. 缺要素就**先问一句**（最多一次问齐），不要自行假设学段与学科。
3. 按学科加载对应系统提示词，检索课标与教材内容，生成卡片核心内容并标注出处。
4. 按卡片类型套模板输出；多卡任务**先给清单供确认，再逐卡生成**。
5. 输出后引导迭代；需要图片/PDF/文档/网页时按下文格式分流执行。

> **样式前置（必做）**：生成任何卡片 / 导图 / 图谱前，先按【学科】【学段】【内容类型】跑「输出样式决策逻辑」（见下文"输出样式系统"节），并在输出**首行**打印样式声明行；未指定样式时走默认组合。样式不是自由发挥。

## 🔐 前置权限校验（最高优先级，必须最先执行）

> 权限校验的「三态诊断 / 通用版兜底 / 强制转化卡 / 连接器加载指引」统一见本技能 `references/_shared.md`「一、权限固定提示」，本章节仅保留本技能专属说明，不重复展开。

> **权益 ≠ 引用（本技能适用）**：卡片**核心内容**（解释 / 释义 / 权威定义 / 易错辨析 / 背景依据）来自「课标与教材通用知识 / 模型知识」，**纯模型生成、不依赖知网**；「知网文献辅助」才是依赖 `mcp__<SERVER>__searchVectorBJ` 的增强层，缺失不影响卡片本体。权益是"能不能用知网文献增强"的闸门，不是"该不该生成卡片"的开关（无权益时卡片照出、仅省知网文献）。

- **本技能被触发后第一步即执行**：无外部依赖，不需要 API Key，不需要命令行工具（指模型自身出卡能力）。**注意**：**触发即调** `edu` 连接器的 `mcp__<SERVER>__userState` 校验（在调用任何知网接口之前，也是整个技能的第一个动作）；校验非 `true` 时按`references/_shared.md`「一、权限固定提示」三态诊断处理——**态 A｜工具不可达**（`ToolSearch` 查不到 `userState`）给「连接器加载指引」、**不**输出转化卡；**态 B｜明确 `false`** 走「通用版兜底 + 强制转化卡」：先向用户原样输出 [_shared.md](references/_shared.md)「权限固定提示」的「解锁知网数据增强层」，**不调用任何知网接口**（不编造文献、不以模型知识冒充知网文献）；卡片核心内容（来自课标与教材通用知识 / 模型知识）照常生成，仅「知网文献辅助」增强层不产出（改为说明"需接入知网后获取"），通用版完成不依赖知网数据的部分。

## Prerequisites

- `references/card-page-template.html` 为自带的可翻卡网页模板（纯 HTML/CSS/JS、无外部 CDN 依赖，可离线使用），做网页输出时直接复制改写，不要另造轮子。
- `references/knowledge-graph-template.html` 为自带的知识图谱 / 思维导图 / 思维外化图模板（纯 HTML/CSS/JS、零依赖、可离线、可打印）：中心发光星球节点 + 绕中心均匀分布的彩色贴纸分支（曲线胶带连线）+ 手帐贴纸卡（彩色横幅标题 + 凸起 emoji 徽章 + 胶带角 + 轻微旋转），金色"★重点"星标贴纸、星点背景涂鸦、学科主题色、A4 横向打印样式齐备。做思维导图 / 知识图谱输出时直接复制改写 `const GRAPH = {...}`，**不要另造方框网格排版**。视觉生动化规范见 [references/output-formats.md](references/output-formats.md) 第 ⑦ 节。
- 知识来源优先级：**用户上传的教材/课标原文 → 课标与教材通用知识 → 模型知识**。前两级都缺失且无法确认时，标注 `⚠请按所用教材版本核对`，宁缺毋滥。
- **可选增强（推荐，已接入中国知网）**：已连接中国知网教育 MCP（服务名 `edu`，提供 `mcp__<SERVER>__searchVectorBJ` 文献库检索与 `mcp__<SERVER>__searchVectorBJPara` 段落库检索，推荐 `type=0,1,2,3,4` 全量召回后按来源类型分流：期刊（核心/普刊均可）、报纸、会议、博硕士、工具书相关即收）时，可在卡片生成阶段检索知网文献，为"解释 / 释义 / 权威定义 / 易错辨析 / 背景依据"补一条可溯源证据，引用处在正文句末加**上标角标〔n〕**，卡片组**文末**统一附「参考资料」列表（标号 / 篇名〔超链接·指向知网在线阅读页或知网节〕/ 作者 / 来源(含年期) / 发表时间 / 类型），去掉独立"阅读"项、篇名即点击入口（链接优先取检索返回的 `url` 字段（知网单篇在线阅读页 `ix.cnki.net/read/article/readonline?...`，与"投稿选刊"的 `readUrl` 完全一致）；⚠️ 实测当前 `mcp__<SERVER>__searchVectorBJ` 不返回 `url`，统一回退知网主站标题检索入口 `kns.cnki.net/kns8s/defaultresult/index?kw=篇名`（与 `ix.cnki.net` 同属知网主站、共用统一登录，未登录时登录页与"投稿选刊"一致））；**被引文献须为相关文献**，期刊（核心/普刊均可）、报纸、会议、博硕士、工具书相关即收；**且一律排除教学/教研类文献**（以"如何教"为对象的文献——如教学设计、教法、教材分析、课标/课程解读、学业评价、试题研究等，即便核心期刊也剔除），只选用关于知识内容本身的纯知识资料（科普、时政、文艺文化、政治法律、学科本体研究等）。**未通过 `mcp__<SERVER>__userState` 基教权限校验（未连接 / 无基教权益）时**按`references/_shared.md`「一、权限固定提示」「通用版兜底 + 强制转化卡」处理：先输出「解锁知网数据增强层」，不调用任何知网接口（不编造文献、不以模型知识冒充"知网文献"）；**卡片核心内容（课标与教材通用知识 / 模型知识）照常生成**，仅「知网文献辅助」增强层不产出（改为说明"需接入知网后获取"），通用版完成不依赖知网数据的部分。完整接口用法、检索式模板、PubDate/Year 年期解析、筛选与引用规范见 [references/cnki-literature.md](references/cnki-literature.md)。
- 生成的文件统一落到用户指定路径；未指定时落到当前工作目录，并在交付时说明文件名与保存路径。

| 要素 | 说明 | 缺失时 |
|---|---|---|
| 学段 | 小学 1–2 / 3–4 / 5–6 年级、初中 7–9 年级、高中（必修/选择性必修/选修） | **必须追问**，不得假设 |
| 学科 | 语文·数学·英语·物理·化学·生物·道法/政治·历史·地理·科学·音乐·美术·体育 | **必须追问**，不得假设 |

| 知识点 | 知识点名称 / 篇目 / 章节 / 专题 | 可从上下文推断，推断后向用户复述确认 |

## Example Prompts

- `帮我做一张八年级物理「浮力」的知识卡片，要能贴在教室里。`
- `把七年级上册《观沧海》做成预习卡，6 张左右，打印成 A4 双面。`
- `九年级化学「质量守恒定律」易错点太多了，做成对比辨析卡给我。`
- `给我一份高中历史「辛亥革命」时间节点卡，要有时间轴。`
- `小学数学三年级长度单位换算，做成能打印裁切的卡片。`
- `英语 say / speak / tell / talk 老是混，做个辨析卡加快速自测。`
- `我要一个网页版知识卡片，能点击翻卡、随机抽卡、还能收藏错题。`
- `把这些零散的知识点汇总成速查卡，3—5 个要点就行。`
- `帮我把四年级上册语文《田忌赛马》做成一幅思维导图。`

## Workflow

> **参考资料的定位（从属，不可喧宾夺主）**：卡片内容（知识点、释义、易错点）永远是主角，参考资料只用于**辅助厘清知识点**。它永远置于**卡片组最末尾**、**1–3 篇克制**、每条**一行轻量紧凑**、用**小级别标题**（`#### 参考资料`）、不做面板与粗重边框，不抢占卡片正文的篇幅与视觉重心。

1. **意图识别与信息确认**
   识别学科、学段、卡片类型（知识卡片 / 复习卡片 / 教研卡片）、具体内容。
   信息不全时主动追问，例如："请问您需要为哪个学科、哪个学段制作知识卡片？是关于什么知识点的？您希望是单知识点卡片还是单元复习卡片？"
   弱触发场景（用户只给范围、没提"知识卡片"）先确认一句："要不要做成简练知识卡片？3—5 个要点，可速查、可背诵、可导出。"

2. **加载学科规则**
   按学科加载 [references/prompt-library.md](references/prompt-library.md) 中对应的系统提示词（含学段边界红线、术语准入、编写规范、事实性安全规则）。
   卡片字段模板见 [references/card-templates.md](references/card-templates.md)；**模板字段为核心内容，不得删减**。

2.5. **样式决策与声明（必做）**
   调用 [references/style-system.md](references/style-system.md) 与 `references/style-library.css`：按【学科】【学段】【内容类型】选定"学科风格 / 学段密度 / 图形结构 / 配色方案"，**先在输出首行打印声明行**：
   `本次样式：学科风格=？；学段密度=？；图形结构=？；配色方案=？`。
   未指定样式时默认"手绘笔记风 + 经典思维导图结构 + 按学段自动调字号"。生成网页 / 导图时通过 `<html data-style="键">` 套用对应风格（详见"输出样式系统"节第五节与样式库）。

3. **内容检索与生成**
   从课标与学科知识体系检索对应内容，生成卡片核心内容，**内容须标注课标/教材出处**。
   批量任务（>5 张）先输出卡片清单（编号 + 标题 + 学科 + 学段）供用户确认，确认后逐卡生成。
   **知网文献辅助（可选，推荐）**：当卡片的"解释 / 释义 / 权威定义 / 易错辨析 / 背景依据"命中 [references/cnki-literature.md](references/cnki-literature.md) 的"建议检索"场景，且已连接 `edu` MCP 时，按 4 段式检索式（`学科 + 学段 + 知识点 + 意图词`）调用文献库（`mcp__<SERVER>__searchVectorBJ`）与段落库（`mcp__<SERVER>__searchVectorBJPara`）各一次，推荐传 `type=0,1,2,3,4` 全量召回后按来源类型分流：期刊（核心/普刊均可）、报纸、会议、博硕士、工具书相关即收；按 `PubDate`/`Year` 解析出年期/发表时间（仅用于题录展示，**不再作为纳入门槛**），剔除误召回与跨学段/跨学科结果，取 1–3 篇相关文献（**须排除教学/教研类文献、只取关于知识内容本身的纯知识资料（详见 cnki-literature.md 第三节 3.1）**）；在正文引用了该文献知识的句末加**上标角标〔n〕**（如"……须依托语篇展开〔1〕"），卡片组文末统一附「参考资料」列表（标号 / 篇名〔超链接〕/ 作者 / 来源 / 发表时间 / 类型），篇名为链接、不设独立"阅读"项（链接优先取检索返回的 `url` 字段（知网单篇在线阅读页 `ix.cnki.net/read/article/readonline?...`，与"投稿选刊"的 `readUrl` 完全一致）；⚠️ 实测当前 `mcp__<SERVER>__searchVectorBJ` 不返回 `url`，统一回退知网主站标题检索入口 `kns.cnki.net/kns8s/defaultresult/index?kw=篇名`（与 `ix.cnki.net` 同属知网主站、共用统一登录，未登录时登录页与"投稿选刊"一致）），与正文〔n〕一一对应、可点开。未通过 `mcp__<SERVER>__userState` 基教权限校验（未连接 / 无基教权益）时走通用版兜底——**卡片核心内容（解释 / 释义 / 权威定义 / 易错辨析 / 背景依据，来自课标与教材通用知识 / 模型知识）照常生成**，仅「知网文献辅助」增强层不产出（改为说明"需接入知网后获取"），并原样输出「解锁知网数据增强层」；不得编造文献。检索失败或用户明确不需要时，则跳过该条文献、卡片其余内容照常生成。细则见 [references/cnki-literature.md](references/cnki-literature.md)。

4. **格式化输出**
   套用该卡片类型的模板，默认输出结构化 Markdown（含卡片类型、适用学段/学科、知识点、使用场景、教师提示、分层/安全标注）。

5. **迭代与导出**
   输出后引导追问："是否需要调整详略？""是否再来一张对比辨析卡？""是否生成同单元分层复习卡？"
   确定导出格式后按 [references/output-formats.md](references/output-formats.md) 执行：Markdown / 图片 / PDF / 文档 / 网页；多卡可批量导出或打包；完成后提示文件名、保存路径与打开方式。

## 输出格式分流

| 用户要的 | 做法 | 关键约束 |
|---|---|---|
| Markdown（默认） | 直接输出结构化 Markdown | 结构清晰，便于复制到备课文档、班级群、学习平台 |
| 图片 | 生成 HTML 卡片页后预览 → 导出 PNG/JPG/SVG/长图 | 手机长图 1080×1920；方形卡 1080×1080；A4 打印图 2480×3508（300dpi）；低段大字号、拼音、图标、高对比 |
| PDF | A4 打印版 / A4 多卡裁切版 / A5 / 名片卡 / 折叠卡 / 双面卡 | 必含裁切线、页边距、双面校准、打印说明 |
| 文档 | DOCX / Word / txt | 可编辑，保留样式、表格、文本框、占位符，教师可增删卡片 |
| 网页 | 基于 `references/card-page-template.html` 产出完整 HTML/CSS/JS | 点击翻卡、显示/隐藏答案、随机抽卡、计时、收藏、错题标记、搜索、打印；支持公式渲染、化学式、图片嵌入、离线使用；响应式、无障碍（字体可调、高对比、键盘操作） |
| 思维导图 | 知识图谱 / 思维导图 / 思维外化图（HTML/SVG 优先） | 属本技能支持的卡片形态；用 `references/knowledge-graph-template.html` 产出（中心发光节点 + 彩色贴纸分支 + 手帐贴纸卡，**拒绝方框网格堆砌**）；中心节点=篇目/专题，分支=知识维度；可用 Markdown 树状作轻量备选；可浏览、可打印、可导出 PDF；低段大字号、图标、高对比、活泼生动 |

卡片尺寸统一按"一张卡片能排下为准"：**A6 或 16:9**。化学式、数学符号必须正确渲染，不得出现乱码或裸 LaTeX。

## 输出样式系统（决策逻辑 + 样式库 + 学科模板）

> **核心原则：样式不是自由发挥，必须"先决策 → 再声明 → 后生成"。** 每次生成前，按【学科】【学段】【内容类型】选定样式组合，并在输出首行打印声明行；未指定样式时使用默认组合。目标：输出既符合一线师生教与学需求，又丰富多彩、生动活泼，做到"一图三用"——**教师能讲**（结构清晰、有考点）、**学生能填**（留白可书写）、**考前能背**（关键词突出、层级短）。

### 一、输出样式决策逻辑（每次必做）

生成任何卡片 / 导图 / 图谱前，先跑一遍决策，并**先输出一行声明**（固定格式）：

```
本次样式：学科风格=？；学段密度=？；图形结构=？；配色方案=？
```

决策表（按【学科】【学段】【内容类型】综合判断；用户可在 `{{样式偏好}}` 中直接指定风格，优先级最高）：

| 维度 | 取值与决策 |
|---|---|
| 学科风格 | 由"按学科匹配图形结构 + 样式库"得出（见二、五）；`{{样式偏好}}` 指定时从其指定 |
| 学段密度 | 小学 = 图多字少；初中 = 逻辑 + 考点；高中 = 网络 + 题型（见三） |
| 图形结构 | 由"按学科 + 按内容类型"得出（见二、四） |
| 配色方案 | 与所选风格绑定（见五每风格配色）；颜色总数 ≤6 |

> 即使生成的是"网页可翻卡"或"Markdown 卡片"，也要先决策并声明；网页 / 思维导图 / 图谱类默认走"经典思维导图风 + 对应图形结构"，纯 Markdown 复习卡默认走"手绘笔记风 / 卡片拼贴风"。

### 二、按学科匹配图形结构

1. **文科**（语文 / 英语 / 历史 / 道法·政治）：优先用 **时间轴、人物关系网、情节山、议论文树、对比双气泡图**。
2. **理科**（数学 / 物理 / 化学 / 生物 / 科学）：优先用 **概念树、公式网络图、流程图、对比表、鱼骨图、模型图**。
3. **跨学科**（如地理、综合实践、STEAM）：优先用 **地图 + 事件、时间线 + 因果链、概念 + 应用迁移图**。

### 三、按学段调整视觉密度

1. **小学**：图多字少，中心图大；简笔画 / 表情 / 贴纸风；**字号 ≥14pt**；关键词 ≤5 字；分支少而大。
2. **初中**：增加逻辑层级与考点；引入**公式框、易错标注**；**字号 ≥12pt**。
3. **高中**：**知识网络 + 题型模型**；信息密度高但**留白 ≥25%**；**字号 ≥10.5pt**；一级分支可多但不超过 7 个。

### 四、按内容类型切换图形

| 内容类型 | 首选图形 |
|---|---|
| 时间 / 事件类 | 时间轴 |
| 因果 / 过程类 | 鱼骨图 或 流程图 |
| 对比 / 辨析类 | 双气泡图 或 对比表 |
| 分类 / 层级类 | 树状图 |
| 公式 / 定理类 | 中心公式辐射网络 |
| 实验类 | 流程 + 装置 + 易错图 |

### 五、样式库（5 种风格，至少包含以下）

| # | 风格 | `data-style` 键 | 适用场景 | 关键视觉特征（背景 / 字体 / 配色 / 装饰） |
|---|---|---|---|---|
| 1 | 手绘笔记风 | `handdrawn` | 预习、课堂笔记 | 米白背景 `#FBF7EE`；手写体标题；荧光笔高亮（黄/绿/粉）；便签·简笔画·贴纸 |
| 2 | 卡片拼贴风 | `collage` | 知识点卡、复习卡 | 圆角卡片 + 柔和阴影；便签排版；浅彩底（绿/蓝/橙/紫） |
| 3 | 极简杂志风 | `magazine` | 初高中复习 | 纯白背景；蓝 `#1E66F5` / 橙 `#FF7A1A` 对比色块；大标题 + 短关键词；无衬线 |
| 4 | 黑板粉笔风 | `blackboard` | 理科公式推导、实验流程 | 深绿/深灰背景 `#1f3a2e`；粉笔质感线条（近白描边·虚线）；浅色粉笔字 |
| 5 | 经典思维导图风 | `mindmap` | 单元整体梳理 | 中心图 + 彩色分支；枝干粗细递减；6 色系分支 |

- 每种风格的具体 CSS（`--deck`/`--theme`、背景、`--font-head` 等变量与组件类）见 `references/style-library.css`；生成网页 / 导图时通过 `<html data-style="键">` 套用，无需重写渲染逻辑。
- **配色纪律**：任一风格颜色 ≤6 种、一色一义；同主题同色系，不同主题不同色。
> ⚠️ **样式库 CSS 为技能内部资产，不向用户输出**：`references/style-library.css` 的 5 种风格已**内联**进两个 HTML 模板的 `<style>` 中，交付的 HTML 单文件即自包含、可离线渲染；生成交付物时**严禁**把 `style-library.css` 单独复制到用户目录。

### 六、文科 / 理科输出模板

**文科模板（中心主题 → … → 考点 → 迁移）**——必须含「主题、考点、迁移区」三块：

```
中心主题
 ├─ 背景 / 时间 / 空间
 ├─ 人物 / 事件
 ├─ 原因 / 经过 / 结果
 ├─ 主题 / 情感 / 观点
 ├─ 手法 / 语言
 ├─ 考点 / 易错        ← 必含
 └─ 联系 / 迁移        ← 必含（学生能填、考前能背）
```

**理科模板（中心主题 → … → 公式框 → 易错）**——必须含「公式框、适用条件、单位、易错点」四项：

```
中心主题
 ├─ 概念定义
 ├─ 公式 / 定理        ← 公式框（醒目）
 ├─ 适用条件          ← 必含
 ├─ 单位              ← 必含
 ├─ 推导 / 实验
 ├─ 图像 / 模型
 ├─ 典型题型
 ├─ 易错点            ← 必含
 └─ 跨章联系
```

### 七、强制约束

1. 一张图一级分支 **5—7 个**；层级 **不超过 4 级**；每节点关键词尽量 **≤7 字**。
2. 颜色 **不超过 6 种**，一色一义；同主题同色系，不同主题不同色。
3. 字体统一：**标题与正文不混用衬线体 / 非衬线体**（`--font-head` 与 `--font-body` 同族）。
4. **图标作锚点**：时间 ⏳、人物 👤、情感 💡、考点 🔴、实验 🧪、公式 📐（在节点/分支上固定使用，便于速记）。
5. **留白 ≥30%**；可打印、可黑白辨认；重要分支用**形状区分**（圆/方/菱形），不只靠颜色。
6. 支持变量：`{{学科}}`、`{{学段}}`、`{{内容类型}}`、`{{样式偏好}}`、`{{输出格式}}`（生成时逐项替换，未指定项走默认）。
7. 未指定样式时，默认 **"手绘笔记风 + 经典思维导图结构 + 按学段自动调整字号"**。

### 八、避坑

- ❌ 不要文字堆砌（节点应是关键词，不是段落）。
- ❌ 不要只抄目录（要有释义、考点、易错、迁移）。
- ❌ 不要颜色超过 6 种。
- ❌ 不要字体混乱（标题/正文混用衬线 + 非衬线）。
- ❌ 理科不要只堆公式缺条件（公式框必带适用条件 + 单位）。
- ❌ 文科不要缺主题和考点（模板六的必含块不可省）。
- ❌ 小学不要信息过密（图多字少、字号大、分支少）。
- ❌ 高中不要没有留白（密度高但留白 ≥25%）。

## 质量红线

- **一卡一核心**：一张卡出现两个独立问题立刻拆开。
- **课标合规**：深度、术语、篇目严格落在所选学段的课标与教材范围内，不超前、不超纲；学段边界红线以 [references/prompt-library.md](references/prompt-library.md) 为准。
- **事实优先**：年代、条约、公式、常量、人名、作品、数据逐条核对；无法确认的标注"待核实"，严禁编造史料、条文、实验现象、教材页码。
- **文献不编造（知网引用红线）**：开启知网文献辅助时，题名、作者、来源、年期、发表时间一个都不能猜。检索接口不返回 `作者` 与可读的 `来源全称`，这两项在参考资料中必须保留但标注"在知网平台阅读页查看完整题录"，绝不编造；检索不到就写"本次未检索到相关的切题文献"。**被引文献须为相关文献**，期刊（核心/普刊均可）、报纸、会议、博硕士、工具书相关即收；**且排除教学/教研类文献**（以"如何教"为对象的文献，如教学设计/教法/教材分析/课标解读/学业评价，不予纳入），只选关于知识内容本身的纯知识资料（科普/时政/文艺文化/政治法律/学科本体研究等）。凡应用了知网知识的卡片，须在正文引用处用**上标角标〔n〕**标注，卡片组**文末**统一附「参考资料」列表（标号 / 篇名〔超链接·指向知网在线阅读页或知网节〕/ 作者 / 来源(含年期) / 发表时间 / 类型），去掉独立"阅读"项、篇名即点击入口（链接优先取检索返回的 `url` 字段（知网单篇在线阅读页 `ix.cnki.net/read/article/readonline?...`，与"投稿选刊"的 `readUrl` 完全一致）；⚠️ 实测当前 `mcp__<SERVER>__searchVectorBJ` 不返回 `url`，统一回退知网主站标题检索入口 `kns.cnki.net/kns8s/defaultresult/index?kw=篇名`（与 `ix.cnki.net` 同属知网主站、共用统一登录，未登录时登录页与"投稿选刊"一致）），与正文〔n〕一一对应（详见 [references/cnki-literature.md](references/cnki-literature.md)）。
- **易错点必填且具体**：写"漏解：忽略 a=0 的情形"，不写"注意分类讨论"这类空话。
- **安全前置**：涉及加热、酸碱、明火、玻璃器皿、活体观察、体育动作的卡片，必须写明安全提示，不得省略。
- **立场规范**：涉及国家主权、领土、民族、宗教、党史的内容，严格依据国家标准与官方表述；涉及中国地图的必须完整、合规、无领土争议错误。
- **样式合规（输出样式红线）**：每次生成前须先决策并在首行打印样式声明行；图形结构 / 学段密度 / 配色方案须匹配学科与学段；严禁违反第七节的强制约束（一级分支 5–7、层级 ≤4、关键词 ≤7 字、颜色 ≤6、字体统一、留白 ≥30%、图标锚点到位）；文科模板必含主题/考点/迁移，理科模板必含公式框/适用条件/单位/易错点；严禁文字堆砌、只抄目录、字体混乱、小学过密、高中无留白等第八节列明的坑。
- **知网接口元数据零暴露（输出呈现红线，不可违反）**：生成物中参考资料只呈现"干净的教师 / 学生可读内容"，**严禁向用户暴露任何知网接口元数据字段名/值、代码符号或说明性技术文字**。此「干净输出红线」的完整字段清单与写法统一见 [_shared.md](references/_shared.md)，本 skill 不再重复；场景化的文献选择规则（排除教学/教研类文献等）见本文件上文与 [references/cnki-literature.md](references/cnki-literature.md)。

## When Not to Use

- 用户要的是**整堂课的教学设计/教案/课件**（应转备课技能，本技能只做知识点卡片）。
- 用户要的是**成套试题、作业布置、错题本管理**（应转出题/作业/错题本技能）。
- 用户只是**查询一个知识点**、不需要卡片形态（直接回答即可，不要强行套卡片）。
- 需要**引用教材/课标原文逐字精确对照**却未提供原文时：只做通用表述并标注待核对，不要假装引用了具体页码。
- 与课堂内场景无关的长篇内容（论文、政策解读、教研报告）——超出本技能边界。

## Definition of Done

- 卡片组标题含**学段、学科、教材版本、内容范围**，并在缺版本时带核对提示。
- 每张卡：一卡一点；正面是问句（≤30 字）或明确的记忆触发式；字段与该卡片类型模板逐项对齐，**无缺项**。
- 每张卡带标签（`[内容域] + [册次单元] + [知识类型]`）与出处标注。
- 每张卡均有**具体**易错点；涉实验/操作/体育动作的卡片均有安全提示。
- 批量任务的卡片数量落在合理区间（默认 15–30 张，>50 张已拆分成多个卡片组）。
- 按用户指定格式产出文件，文件可打开、可读、内容与 Markdown 版一致；导出后已告知文件名、保存路径与打开方式。
- 无超纲术语、无编造数据、无未标注的不确定信息。
- **若生成了导图 / 卡片 / 图谱形态**：已按"输出样式系统"决策并声明——输出首行含样式声明行；图形结构 / 学段密度 / 配色方案匹配学科与学段；一级分支 5–7、层级 ≤4、关键词 ≤7 字、颜色 ≤6、留白 ≥30%、字体统一、图标锚点（⏳👤💡🔴🧪📐）到位；文科含主题/考点/迁移区、理科含公式框/适用条件/单位/易错点；未落入第八节任何坑。
- **若启用了知网文献辅助**：应用了知网知识的卡片均在正文引用处用**上标角标〔n〕**标注；卡片组**最末尾**以**小级别标题**附「参考资料」（每条**一行轻量紧凑**、**1–3 篇克制**、不喧宾夺主），每条含**标号 / 篇名（超链接·指向知网平台本篇目在线阅读页或知网节）/ 作者 / 来源(含年期) / 发表时间 / 类型，不另设"阅读"项**，与正文〔n〕一一对应、可点开；**被引文献均为相关文献**，期刊（核心/普刊均可）、报纸、会议、博硕士、工具书相关即收；**且均非教学/教研类文献**（排除以"如何教"为对象的文献），仅为关于知识内容本身的纯知识资料；作者与来源全称接口未返回时标注"在知网平台阅读页查看完整题录"、不编造；文献**不限出版年份**（任何年份的相关文献均可纳入）且未跨类顶替；无任何编造文献；未检索到时明确写出"本次未检索到相关的切题文献"。
