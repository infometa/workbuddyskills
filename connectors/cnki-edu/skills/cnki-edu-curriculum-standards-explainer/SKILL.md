# 课标解读（cnki-edu-curriculum-standards-explainer）

面向中小学教师，围绕国家课程标准提供**专业化、场景化、落地化**的解读服务：解决教师"课标理解模糊、落地脱节、场景适配不足"三大核心问题，最终辅助教师完成教学备课、教研发展、课程开发、评价设计、自我提升等全流程教学工作。

核心方法：**双提示词组合 + 一层文献证据** —— 用「总控系统提示词」保证全局约束（不越界、原文优先、学段学科双适配、安全标注），再叠加「专用系统提示词」保证单方面解读深度；在此基础上，可用**中国知网（CNKI）文献检索**补充权威解读与修订依据，形成"课标原文 + 知网文献"的双层依据（文献为可选层，缺失不影响主流程）。

> **权益 ≠ 引用（本技能适用）**：本技能**课标解读本体**（课标原文 + 模型通用知识）纯模型生成、不依赖知网；「知网文献证据」才是可选增强层，缺失不影响主流程。权益是"能不能用知网文献增强"的闸门，不是"该不该做课标解读"的开关（无权益时解读照出、仅省文献证据层）。

## Prerequisites

- **🔐 前置权限校验（最高优先级，必须最先执行）**：**本技能被触发后第一步即调用** `edu` 连接器的 **`mcp__<SERVER>__userState`** 工具查询当前账号权益（在任何知网接口调用与内容生成之前，也是整个技能的第一个动作）。

> 权限校验的「三态诊断 / 通用版兜底 / 强制转化卡 / 连接器加载指引」统一见本技能 `references/_shared.md`「一、权限固定提示」，本章节仅保留本技能专属说明，不重复展开。

## 知网文献引用（可选增强）

课标原文负责"**是什么**"，知网文献负责"**专家怎么解、这次为什么这么改、一线怎么落**"。**被引用的知网文献：期刊只收核心，其余相关类型（报纸/会议/博硕士/工具书）相关即收（北大核心 / CSSCI / AMI 核心等，以接口 `coreJournals=Y` 或 `CoreIndex` / `CSSCI` 命中为准）**，非核心期刊（普刊）不纳入参考资料；报纸/会议/博硕士/工具书相关即收。启用条件与边界：

| 场景 | 是否检索知网 |
|---|---|
| 版本对比（2022版 vs 2025年修订版 / 2017版 vs 2025年修订版） | ✅ 必检索 |
| 要权威释义、学界共识、修订依据 | ✅ 必检索 |
| 要落地路径、教研范例、教学建议佐证 | ✅ 必检索 |
| 问课标原文、章节、页码 | ⛔ 不检索（文献替代不了原文） |
| 用户说"不用查文献" | ⛔ 跳过 |

**年限门槛（硬约束，先过滤后引用）**：

- **义务教育**相关课标解读文献 → 只取 **2022 年及以后**（2022 年是义教课标颁布年，更早的针对旧版课标）。
- **普通高中**相关课标解读文献 → 只取 **2017 年及以后**（2017 年是高中课标颁布年，更早的针对实验版）。
- **2025 年日常修订版**是最新版本，其解读文献（含新旧修订对比、变化阐释）**优先级最高、重点采用**。

**参考资料的定位（从属，不可喧宾夺主）**：

课标解读本身是主角，参考资料**只用于辅助解读 / 厘清知识点**，是从属板块。因此它永远**置于报告最末尾**（「⑥ 安全标注」之后）、用**小级别标题**（`#### 参考资料`）、每条**一行轻量紧凑**呈现、**3–5 篇克制**不堆量；不前置、不打断解读主线、不做面板与粗重边框。

**六条不可违反的约束**：

1. **不编造文献**——题名、作者、来源、年期、发表时间一律不得猜测；检索接口**直接返回** `Author`(作者) 与 `Source`/`JournalName`(来源/刊名)，可直接写入引用卡片；仅当某字段确为空时才标"详见阅读页题录"，绝不编造；检索不到就写"本次未检索到符合年限要求的文献"。
2. **正文引用 + 文末集中**——课标原文进「课标依据」，文献观点在正文对应处用**右上角上标序号 `[n]`（超链接，点击跳转文末「参考资料」对应篇名）**标注、并在文末"参考资料"列表集中呈现；文献与原文冲突时以原文为准，不把文献说法写成"课标规定"。
3. **逐年过滤**——接口无年份参数，须按返回的时间字段（`PubDate`/`Year`）解析出年期/发表时间（规则见 cnki-retrieval.md 第三节），剔除早于门槛的文献。
4. **参考资料列表（篇名即链接）**——每条被引文献在文末"参考资料"中按「序号 / 篇名（超链接·安全入口）/ 作者 / 来源(年期) / 发表时间 / 类型」呈现，且**每条篇名所在条目设锚点 `id="ref-n"`**（n 与正文 `[n]` 对应，仅作标记属性、渲染后不可见）；**不设独立的"阅读"项**，篇名本身即为点击入口，**篇名 `href` **优先取检索返回的 `url` 字段**（知网单篇在线阅读页 `ix.cnki.net/read/article/readonline?...`，与"投稿选刊"的 `readUrl` 完全一致，由知网负责登录 / 鉴权）；⚠️ 实测当前 `mcp__<SERVER>__searchVectorBJ` 不返回 `url`，统一回退 `https://kns.cnki.net/kns8s/defaultresult/index?kw=篇名`（知网官方入口，登录由知网接管）；**严禁用 `dbcode`/`tablename`/`filename` 自行拼装**；正文中借用的观点用**右上角上标序号 `[n]`（超链接指向 `#ref-n`）**回指文末对应条目，做到"这个观点来自知网某篇文献"清晰可查、可点开。篇名渲染样式（无下划线超链接、不向用户暴露 `filename`/`dbcode` 等内部标识）等「干净输出红线」统一见 [_shared.md](references/_shared.md)。

5. **面向用户只给干净结果（禁止暴露检索 / 筛选机制与接口元数据字段值）**——文末「参考资料」仅按「序号 / 篇名（超链接）/ 作者 / 来源(年期) / 发表时间 / 类型」一行式呈现；**不得**向用户展示任何检索或筛选过程的说明性文字（如"本次文献检索以博硕士论文、会议论文为主""期刊类因接口未返回核心期刊判定字段、无法核验限核心要求，故未纳入""文献作者与来源取自检索返回题录""年份/年期由返回数据解析"等），也**不得**在「参考资料」标题上附加"（知网文献 · 辅助解读）"之类的修饰性括注（标题只用 `#### 参考资料`）。检索机制、来源类型约束、字段缺口等内部口径只用于 Agent 内部决策，严禁进入面向用户的输出；该禁令与下方「输出呈现安全红线」（cnki-retrieval.md 6.5）一致。**尤其严禁向用户暴露任何知网接口元数据字段名/值、代码符号或说明性技术文字——此「干净输出红线」全文与字段清单统一见 [_shared.md](references/_shared.md)，本 skill 不再重复。**

6. **「参考资料」篇名超链接必须指向知网官方入口**——每条被引文献的篇名 `href` **优先取检索返回的 `url` 字段**（知网单篇在线阅读页 `ix.cnki.net/read/article/readonline?...`，与"投稿选刊"的 `readUrl` 完全一致，由知网负责登录 / 鉴权）；⚠️ 实测当前 `mcp__<SERVER>__searchVectorBJ` 不返回 `url` / `文件名`，统一回退为标题检索入口 `https://kns.cnki.net/kns8s/defaultresult/index?kw=篇名`（知网官方入口，登录由知网接管）；**不得**指向其他平台，也**不得**用 `dbcode`/`tablename`/`filename` 自行拼装直链。

完整接口用法、检索式模板、PubDate/Year 年期解析规则、筛选与引用规范见 [references/cnki-retrieval.md](references/cnki-retrieval.md)。

## 输入四要素

解读必须锚定四个变量，缺一不可（缺失就主动追问，不要凭猜测补全）：

| 变量 | 取值 |
|---|---|
| 学段 | 小学1-2年级 / 小学3-4年级 / 小学5-6年级 / 初中7-9年级 / 高中必修 / 高中选择性必修 / 高中选修 |
| 学科 | 语文、数学、英语、道德与法治·思想政治、历史、地理、物理、化学、生物学、科学、信息科技、体育与健康、艺术、劳动等 |
| 课标版本 | 默认 **2025年日常修订版**；义务教育→《义务教育XX课程标准（2022年版）及2025年日常修订版》；高中→《普通高中XX课程标准（2017年版2020年修订）及2025年日常修订版》 |
| 解读方面 | 核心素养 / 课程性质 / 课程理念 / 课程目标 / 课程内容 / 学业质量 / 课程实施（七选一，可循环多次） |

补充变量：年级（可选，用于进一步细化）、课标文档（已上传 / 未上传）、其他要求。

## 七条总原则（硬约束，任何一次输出都不得违反）

1. **只输出**该学段、该学科的内容，不混入其他学段、其他学科。
2. **课标原文优先**：能引用则引用；不能引用时做忠实概括，不得杜撰、不得增删课标未有的要求。
3. **先定位章节，再输出**：若课标中该方面未单列，明确标注"该课标未单列，可参考……"。
4. **学段适配**：小学低段重感受、认读、说出、复述；小学中高段重理解、概括、初步运用；初中重理解、概括、品味、初步分析；高中重鉴赏、评价、比较、梳理、探究。
5. **学科适配**：按学科自身的组织方式呈现，如语文按学习任务群、数学按领域、英语按级别、科学按核心概念、艺术按艺术实践等。
6. **事实性安全**：不确定的原文、章节、水平划分、行为动词，一律标注 `⚠请核对`，宁缺毋滥。
7. **教师可读**：语言简洁，能直接用于备课或教研。

## Workflow

1. **解析输入** —— 从用户消息中抽取四要素；缺失项一次性问清（例：`请告诉我要解读的学段、学科和方面，例如"初中数学·学业质量"`）。
2. **加载总控提示词** —— 读取 [references/prompt-library.md](references/prompt-library.md) 中的「总体系统提示词」，确立总原则与通用输出结构。
3. **沿用入口权限结论 + 判断课标来源** —— 技能入口第 1 步已调用 `mcp__<SERVER>__userState` 校验知网基教权限，此处直接沿用其结论判断课标来源：
   - **未通过基教权限校验（未连接 / 无基教权益）** → 按 `references/_shared.md`「一、权限固定提示」「通用版兜底 + 强制转化卡」处理，不交付任何依赖知网的课标解读产物（不调用 `mcp__<SERVER>__standardSearch` 等任何知网接口、不生成任何说明）；不编造文献、不以模型知识冒充"课标依据"，通用版完成不依赖知网数据的部分，并原样输出「解锁知网数据增强层」。本技能不据此产出解读，用户可自行查阅其上传的课标原文。
   - **已通过基教权限校验** → 用户已上传课标文档则解析原文并定位章节；**未上传 → 调用 `mcp__<SERVER>__standardSearch`（edu 连接器）检索"课标 / 教材"标准文档块作为课标依据辅助解读（命中处注明来源）**，并在全文末尾统一标注 `⚠请按所用课标版本核对`。
4. **选择专用提示词** —— 按「解读方面」从 7 个专用系统提示词中取一个（同名段落）。
5. **组合提示词** —— 总控 + 专用拼接，把 `{学段} {学科} {课标版本}` 填入占位符。
6. **定位课标章节** —— 在该学科课标中定位对应章节（核心素养内涵 / 课程性质 / 课程理念 / 课程目标 / 课程内容 / 学业质量 / 课程实施）；未单列则按原则 3 标注。
7. **检索知网文献（可选，推荐）** —— 命中「知网文献引用」表中的必检索场景时，按 4 段式检索式（`课标全称 + 学段 + 解读方面 + 意图词`）调用文献库（`mcp__<SERVER>__searchVectorBJ`）与段落库（`mcp__<SERVER>__searchVectorBJPara`）各一次，传 `type` 覆盖所需资源类型（期刊 `0` / 报纸 `4` / 会议论文 `3` / 博硕士论文 `1,2`，全量用 `0,1,2,3,4`）；**期刊只收核心，其余相关类型（报纸/会议/博硕士/工具书）相关即收**——按 `coreJournals` / `CoreIndex` / `CSSCI` 命中筛选，非核心（普刊）剔除；报纸/会议/博硕士/工具书相关即收（详见 [references/cnki-retrieval.md](references/cnki-retrieval.md) 的"来源类型约束"）；按返回的时间字段（`PubDate`/`Year`）解析出年期/发表时间（见 cnki-retrieval.md 第三节），**义教只留 2022 年起、高中只留 2017 年起**，2025 年日常修订版相关文献优先；剔除误召回与跨学段/跨学科结果，取 3–5 篇。**在正文对应观点处用**右上角上标序号 `[n]`（超链接，点击跳转文末「参考资料」对应篇名）**标注引用**，并在报告**文末**集中生成「参考资料」列表（标号 / 篇名〔超链接·安全入口〕/ 作者 / 来源(年期) / 发表时间 / 类型），篇名为链接、不设独立"阅读"项（篇名 `href` **优先取检索返回的 `url` 字段**——知网单篇在线阅读页 `ix.cnki.net/read/article/readonline?...`（与"投稿选刊"的 `readUrl` 完全一致），由知网负责登录 / 鉴权；⚠️ 实测当前 `mcp__<SERVER>__searchVectorBJ` 不返回 `url`，统一回退知网主站标题检索入口 `https://kns.cnki.net/kns8s/defaultresult/index?kw=篇名`（与 `ix.cnki.net` 同属知网主站、共用统一登录），**严禁用 `dbcode`/`tablename`/`filename` 自行拼装**）。未通过 `mcp__<SERVER>__userState` 基教权限校验、检索失败、无相关文献结果或用户明确不需要时**直接跳过，不得编造文献**；无权限时同步输出「解锁知网数据增强层」。细则见 [references/cnki-retrieval.md](references/cnki-retrieval.md)。
8. **逐项生成** —— 按「通用输出结构」+「专用输出结构」逐条产出，专用结构在通用五项之外追加该方面特有字段（如核心素养的名称与内涵、本学段具体表现、教学落点）；有文献时，在正文借用观点处用**右上角上标序号 `[n]`（超链接，点击跳转文末「参考资料」对应篇名）**标注，文献观点与课标原文分区（原文进「①课标依据」、文献佐证进正文带角标的句子），文末统一附「参考资料」列表。
9. **学段学科双适配** —— 对照 [references/subject-adaptation.md](references/subject-adaptation.md) 校正用词与要求层级，去掉超出本学段的行为动词。
10. **安全校验** —— 逐条自查：是否有跨学段/跨学科串味？是否有未标注的不确定表述？是否出现课标未有的术语？文献是否在年限门槛内、篇名与年份是否可核查、是否把文献观点写成了课标原文？发现问题就地修正。
11. **输出结构化报告** —— 使用 [references/output-templates.md](references/output-templates.md) 的报告骨架，教师可直接用于备课、教研、课程开发、评价设计。
12. **支持追问循环** —— 教师换一个方面追问时，回到第 3 步（若同一份课标已解析则直接复用）重复 4-11 步，输出新的解读；文献检索结果在同一会话内可复用，不必重复检索。

详细分步说明与流程关键点见 [references/workflow.md](references/workflow.md)。

## Example Prompts

- `帮我解读一下小学语文 3-4 年级的核心素养，要能直接用在我的单元教学设计里。`
- `初中数学"学业质量"这块课标怎么说的？达标是什么样，评价怎么评？`
- `我是高中物理老师，想看看新课标里"课程内容"的要求、学业要求和教学提示分别是什么。`
- `课标里关于"跨学科主题学习"是怎么要求的？在哪一章哪一页？`
- `2022版和2025年日常修订版的英语课标有什么区别？`
- `课标要求怎么分解到单元和课时？给我个可操作的路径。`
- `帮我查一下知网上关于义务教育语文课程标准核心素养的权威解读文献，2022年之后的，最好有2025年修订版的。`
- `高中化学课标 2025 年日常修订版改了什么？有没有解读文章支撑？`

## 触发判断

- **强触发（立即进入本场景）**：课标解读、解读课标、帮我解读课标、课程标准解读、课标要求解读、课标原文解读、查课标原文、课标第几页、课标章节、课标里怎么写的、课标原文怎么说、新旧课标对比、课标变化、课标2022版和2025版区别、课标2017版和2025版区别、课标修订变化、课标演变、核心素养解读、本学科核心素养、核心素养内涵、核心素养落点、核心素养课堂体现、课程性质解读、这门课是什么、课程定位、课程育人价值、学科本质、课程理念解读、课程基本理念、为什么教、课程目标解读、学段目标、课标总目标、课标目标分解、目标与核心素养对应、课程内容解读、课程内容要求、课程学业要求、课程教学提示、课程内容框架、学习任务群、学业质量解读、学业质量标准、课程水平划分、课程达标要求、课程评价标准、课程实施解读、课程教学建议、课程评价建议、资源开发建议、课程教研建议；以及"小学语文课标解读""初中数学课标要求""高中物理核心素养""义教英语课程内容"等**学段+学科+方面**的组合说法。
- **弱触发（先确认一句再用）**：课标、课程标准、新课标、义教课标、高中课标、学科核心素养、学习任务群、跨学科主题、课标怎么落地、课标怎么教、课标怎么评、课标要求怎么分解到单元、课标与备课、以前课标怎么要求、课标变化、课标修订、新老教材对比、课标评价建议、学业质量与命题、课标资源建议、教材编写建议、课程资源开发、课标与教研、教师课标理解、课标培训等。
- **文献检索型触发（进入本流程并启用知网检索）**：查课标解读文献、知网检索课标、搜课标相关论文、课标解读有哪些文献、专家怎么解读课标、课标修订依据、课标变化的研究、有没有相关研究支撑、参考资料、权威解读、教研文献、最新解读文章、2025年修订版解读文献、课标解读研究现状等。
- 命中弱触发时，先用一句话确认："你是想解读课标原文与要求，还是只想聊聊教学思路？"再决定是否进入本流程。

完整关键词清单见 [references/triggers.md](references/triggers.md)。

## Definition of Done

- 输出中同时明确写出**学段、学科、课标版本、解读方面**四个要素，且全文不出现其他学段/其他学科的要求。
- 输出包含通用输出结构的全部条目（课标依据 / 核心要点 / 教师解读 / 学段学科落点 / 常见误区 / 安全标注），并包含所选方面的专用输出条目。
- 每一条"课标依据"都给出了课标名称 + 章节名；章节页码可知则给出，不可知则说明原因。
- 所有不确定内容均带 `⚠请核对` 或 `⚠请按所用课标版本核对` 标记；全文无杜撰的课标原文。
- 若课标未单列该方面，输出中出现"该课标未单列，可参考……"的明确说明。
- **若启用了知网检索**：被引文献**均为相关文献（期刊限核心）**（以 `coreJournals=Y` 或 `CoreIndex` / `CSSCI` 命中为准，期刊须核心、其余相关即收），满足年限门槛（义教 ≥ 2022 年、高中 ≥ 2017 年），2025 年日常修订版相关文献被优先采用；正文借用观点处用**右上角上标序号 `[n]`（超链接，点击跳转文末「参考资料」对应篇名）**标注、报告最末尾以**小级别标题**附「参考资料」（每条**一行轻量紧凑**、**3–5 篇克制**、不喧宾夺主），每条含**标号 / 篇名（超链接·点击直达知网本篇阅读页）/ 作者 / 来源(年期) / 发表时间 / 类型，不另设"阅读"项**；篇名 `href` 为检索返回的本篇在线阅读直链（内部标识仅存属性），库未收录回退安全搜索入口；HTML 中篇名显式 `text-decoration:none`（无下划线）；作者与来源全称接口未返回时标注"在知网平台阅读页查看完整题录"、不编造；文献观点与课标原文分区呈现、无混淆；无任何编造文献；无相关文献结果时明确写出"本次未检索到符合年限要求的相关文献"。
- 教师可直接复制该输出用于备课、教研或评价设计，无需二次追问即可获得可操作建议。
- 文末「参考资料」呈现**干净**：只有「序号 / 篇名（超链接）/ 作者 / 来源(年期) / 发表时间 / 类型」一行式列表，**不出现**任何检索/筛选过程的说明性文字，也**不附加**"（知网文献 · 辅助解读）"等修饰性括注（标题只用 `#### 参考资料`）；检索机制、来源类型约束、字段缺口等内部口径只用于 Agent 内部决策，不进入面向用户的输出。

## When Not to Use

- 只想**聊教学思路 / 教学设计**，不需要课标依据时——那是常规教学设计任务，不走本流程。
- 需要**命题、试卷生成、作业设计**的成品——本技能只给课标依据与评价建议，不出题。
- **教材内容讲解、知识点答疑**（如"这道题怎么做"）——不属于课标解读。
- 非 K-12 学段（高校、职教、成人教育）的课程标准解读——不在本技能覆盖范围。
- 需要**课标全文检索**（如"把语文课标全文给我"）——本技能包不含课标全文，应引导用户上传原文或查阅官方渠道。
- 只想做**纯文献综述 / 论文检索**、不需要课标解读时——知网检索在本技能中仅作为课标解读的证据支撑，不承担独立的综述写作任务。
