# 数据与知识库需求

## 一、所需知识库资源

| 知识库 | 内容 | 用途 |
|---|---|---|
| **知网文献库（在线，无需随包分发）** | 中国知网（CNKI）收录的课标解读期刊论文、会议论文、学位论文、报纸文章（通过知网教育 MCP `edu` 的 `mcp__<SERVER>__searchVectorBJ` / `mcp__<SERVER>__searchVectorBJPara` 在线检索） | 提供课标顶层权威释义、官方教学导向与教研落地范式，让解读更权威、贴合一线教学实操。**这是"课标解读文献"的首选来源，见 [cnki-retrieval.md](cnki-retrieval.md)** |
| **课标标准文档库（在线，mcp__<SERVER>__standardSearch）** | 中国知网教育 `edu` 连接器的 `mcp__<SERVER>__standardSearch` 向量检索"课标/教材"等标准文档块（用于用户未上传课标原文**且已通过 `mcp__<SERVER>__userState` 基教权限校验**时取权威「课标依据」来源；无基教权限时不以模型知识冒充） | 提供权威"课标依据"兜底，命中块注明来源、无法定位章节时标注 `⚠请按所用课标版本核对`；见 [cnki-retrieval.md](cnki-retrieval.md) 第十节 |
| **课程方案** | 义务教育课程方案日常修订版（2022年版2025年修订）；普通高中课程方案日常修订版（2017年版2025年修订） | 支撑培养目标、课程设置等宏观层面的课标解读工作 |
| **各学科课标全文** | 义务教育和高中学段各学科课程标准全文 | 支撑用户需求的快速检索、精准课标匹配，提升解读效率 |
| **课标解读文献（本地兜底）** | 学科专家、教研员发表的课标官方权威解读期刊论文、教研文献、专项解读成果（目前已积累语文学科 300 余篇解读文献可用）。**注意：若能连通知网 MCP，应优先走在线检索，本地文献仅作离线兜底** | 提供课标顶层权威释义、官方教学导向与教研落地范式 |
| **关键概念词典** | 课标中出现的重要概念的定义和解释 | 支撑课标概念辨析、答疑解惑等概念解释功能 |
| **学科映射表** | 学科与课标文件、章节的对应关系 | 精准定位对应学科、学段课标原文及对应章节，保障检索准确性 |

> 原产品文档中标注为"尚无"的项目，以实际部署时的资源到位情况为准；本技能包**不随包分发上述任何本地知识库文件**。知网文献库是**在线服务**，不占包体、无需分发，只要连接了 `edu` MCP 即可用。

## 二、降级策略（知识库缺失时的处理）

本技能包默认在**无知识库**环境下工作，按下列优先级取用课标依据：

> **🔒 权限前置**：取用第 3 级（mcp__<SERVER>__standardSearch）之前，必须先经 `edu` 连接器的 `mcp__<SERVER>__userState` 校验确认账号具备**基教权益**；未通过校验（未连接 / 无基教权益）时**不得调用任何知网接口**，直接提示用户前往 **e.cnki.net** 开通 / 购买基教服务，且第 4 级仅可作明确标注的通用性说明，**绝不以模型知识冒充"课标依据"**。

| 优先级 | 课标来源 | 输出要求 |
|---|---|---|
| 1 | 用户当轮上传的课标文档（docx / pdf / txt） | 按原文引用，给出章节名与页码；**不标注**核对提示（原文即依据） |
| 2 | 会话上下文中已出现过的课标原文 | 可直接引用；首次引用处标注来源 |
| 3 | 经 `mcp__<SERVER>__userState` 校验**具备基教权限**、且已连接 `edu` MCP、`mcp__<SERVER>__standardSearch` 可用（用户未上传原文时） | 调用 `mcp__<SERVER>__standardSearch` 取"课标/教材"标准文档块作为「课标依据」并注明来源；无法精确定位章节时标注 `⚠请按所用课标版本核对`（见 cnki-retrieval.md 第十节） |
| 4 | 经 `mcp__<SERVER>__userState` 校验**确无基教权限**，且用户未上传原文时（**不得主动以模型知识冒充"课标依据"**） | 仅可作**明确标注"通用版（未接入知网基教，知网数据增强层暂未启用）"的通用性说明**；**全文末尾统一标注** `⚠请按所用课标版本核对`，并提示前往 **e.cnki.net** 开通基教权益；绝不编造章节 / 页码 / 原文表述 |
| 5 | 上述均不可用 | 明确告知用户"未获取到对应课标原文"，请其上传文档或指明版本，**不臆测、不编造** |

**关键约束**：整个解读中**唯一不允许降级**的是"不杜撰"。凡章节号、页码、水平划分、行为动词、原文表述，只要不能确认，一律回到第 3、4 级处理并标注。

### 知网文献引用的独立降级链（正文角标 + 文末参考资料，与课标依据分开）

「正文 `[n]` 右上角上标序号（超链接）+ 文末参考资料」是**可融入报告的可选引用方式**，其取用顺序为：

| 优先级 | 文献来源 | 输出要求 |
|---|---|---|
| 1 | 知网在线检索（`edu` MCP，`mcp__<SERVER>__searchVectorBJ` / `mcp__<SERVER>__searchVectorBJPara`） | 按 [cnki-retrieval.md](cnki-retrieval.md) 过滤年限门槛后引用；给出篇名 + 类型 + 年份 |
| 2 | 本地 `assets/kb/literature/` 下的解读文献（若已部署） | 引用时标注为本地知识库文献 |
| 3 | 上述均不可用 | 写出"本次未检索到符合年限要求的相关文献"，**不出现正文 `[n]` 角标（超链接）与「参考资料」列表，也不得编造文献** |

**注意**：课标依据降级到"模型知识"时，知网文献引用**不得**跟着降级为"凭记忆编造文献篇名"——两者互不替代。

## 三、如何让知识库生效

若后续要为本技能补充知识库，推荐存放位置与命名：

```
cnki-edu-curriculum-standards-explainer/
└── assets/
    └── kb/
        ├── curriculum-plan/        # 课程方案（义务教育 / 普通高中）
        ├── standards/              # 各学科课标全文，按 学段-学科 命名，如 义教-语文.txt
        ├── literature/             # 课标解读文献，按学科分目录
        ├── glossary/               # 关键概念词典（术语 → 定义 → 出处章节）
        └── subject-map.json        # 学科 ↔ 课标文件 ↔ 章节 的映射表
```

`subject-map.json` 建议结构：

```json
{
  "义教-数学": {
    "file": "standards/义教-数学.txt",
    "sections": {
      "核心素养": "第二部分 核心素养内涵",
      "课程性质": "第一部分 课程性质",
      "课程理念": "第一部分 课程理念",
      "课程目标": "第二部分 课程目标",
      "课程内容": "第三部分 课程内容",
      "学业质量": "第四部分 学业质量",
      "课程实施": "第五部分 课程实施"
    }
  }
}
```

补充知识库后，把 SKILL.md 的 `Prerequisites` 与 [workflow.md](workflow.md) 的 Step 3 一并更新，并在 `metadata.openclaw.requires` 中登记所需文件。
