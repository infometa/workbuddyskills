# 输出模板（Output Templates）

## 一、用户输入模板

教师可直接复制填写，或口头表达同样的信息。

```text
- 学段：
- 年级：
- 学科：
- 课标版本：
- 课标文档：已上传 / 未上传
- 是否需要知网文献引用（正文右上角 `[n]` 超链接序号 + 文末参考资料）：需要（默认，知网检索）/ 不需要
- 任务：请解读本学段学科的核心素养 / 课程性质 / 课程理念 / 课程目标 / 课程内容 / 学业质量 / 课程实施……
- 其他要求：
```

**填写示例**

```text
- 学段：初中7-9年级
- 年级：八年级
- 学科：数学
- 课标版本：2025年日常修订版（默认）
- 课标文档：未上传
- 任务：请解读本学段学科课程内容中的"图形与几何"领域
- 其他要求：希望能给出可直接用于单元设计的落点
```

## 二、通用输出结构（每次输出必含）

| 序号 | 条目 | 内容要求 |
|---|---|---|
| ① | 课标依据 | 课标名称、章节、页码（若可知） |
| ② | 核心要点 | 该方面在本学段本学科的关键内容 |
| ③ | 教师解读 | 内涵阐释、教学意义、与相邻方面的关系 |
| ④ | 学段学科落点 | 本学段本学科的具体表现、教学建议或评价提示 |
| ⑤ | 常见误区 | 教师容易混淆或过度拔高的地方 |
| ⑥ | 安全标注 | ⚠需要核对的内容 |

> **知网文献以"正文右上角 `[n]` 超链接序号 + 文末参考资料"方式呈现（可选）**：启用了知网检索且有相关文献结果时，在正文借用观点的句末用右上角上标序号 `[n]`（超链接，点击跳转文末「参考资料」对应篇名）标注，报告**文末**统一附「参考资料」列表（标号 / 篇名（超链接·含锚点 `id="ref-n"`）/ 作者 / 来源 / 发表时间 / 类型），篇名即点击入口、不设独立"阅读"项（篇名 `href` **优先取检索返回的 `url` 字段**——知网单篇在线阅读页 `ix.cnki.net/read/article/readonline?...`（与"投稿选刊"的 `readUrl` 完全一致），由知网负责登录 / 鉴权；⚠️ 实测当前 `mcp__<SERVER>__searchVectorBJ` 不返回 `url`，统一回退知网主站标题检索入口 `https://kns.cnki.net/kns8s/defaultresult/index?kw=篇名`（与 `ix.cnki.net` 同属知网主站、共用统一登录，登录页与"投稿选刊"一致）；**严禁用 `dbcode`/`tablename`/`filename` 自行拼装**，详见 cnki-retrieval.md 6.4）。**不另设独立的"文献支撑"模块**。被引文献须为相关文献（期刊限核心）（见 cnki-retrieval.md 来源类型约束），满足年限门槛（义教 ≥ 2022 年、高中 ≥ 2017 年），2025 年日常修订版相关文献优先；作者（`Author`）与来源（`Source`/`JournalName`）接口已直接返回，可直接写入，仅字段确为空时标"详见阅读页题录"，绝不编造。未检索、检索失败、无相关文献结果时**不出现角标与参考资料列表**，仅在安全标注或说明处写"本次未检索到符合年限要求的相关文献"，**不得编造文献**。

**对话 / 网页等非长文档场景的引用格式（优先"内联可读"，不用编号间接引用）**：在聊天或网页回答中，超链接锚点跳转并不可靠、且「参考资料」列表位于文末较远，读者难以把正文〔n〕与文末篇名对应。因此聊天场景**默认不用"〔n〕编号 + 文末列表"的间接方式**，改为**正文内联引用**：在借用语料的句末直接写『(作者,年期)《题名短标识》』，并**整体设为指向该篇知网阅读页的可点击超链接**——"谁说的、哪篇、点哪"在同一处完成，零跳转、零对照表。此时文末「参考资料」列表在聊天中可省略（内联已自包含，避免重复）；**仅当导出为 Word / PDF 等长文档时**，才启用"〔n〕上标 + 文末「参考资料」"的文档式格式。

## 三、七个方面的专用输出结构

在通用结构之上追加的条目（字段名与 [prompt-library.md](prompt-library.md) 一一对应）：

| 解读方面 | 追加条目 |
|---|---|
| 核心素养 | 核心素养名称与内涵、本学段具体表现、与课程目标·内容的关系、教学落点 |
| 课程性质 | 学科定义与课程属性、独特育人价值、本学段体现、与相邻学科/活动的关系、教学落点 |
| 课程理念 | 理念条目、每条理念的内涵、本学段学科落实、与目标·内容·实施的关系 |
| 课程目标 | 总目标概览、本学段目标逐条、与核心素养对应、可观测行为、教学落点 |
| 课程内容 | 内容框架、内容要求、学业要求、教学提示、本学段重点与衔接、教学落点 |
| 学业质量 | 学业质量内涵、水平划分、本学段典型表现、评价方式、与考试评价的关系、教学落点 |
| 课程实施 | 教学建议、评价建议、教材与资源建议、教研与教师发展、本学段学科落地、常见问题与对策 |

## 四、报告骨架（输出时套用）

````markdown
# {学科} · {学段} · {解读方面}解读报告

> 课标版本：{课标版本}
> 课标来源：{已上传文档 / 知网教育数据检索（经知网基教权益校验） / 通用性说明（仅限无基教权限且未上传原文时，明确标注"通用版（未接入知网基教，知网数据增强层暂未启用）"）}（后两者标注 ⚠请按所用课标版本核对）

## ① 课标依据
- 课标名称：
- 对应章节：
- 页码：（可知则给出；不可知写明"未能确认，⚠请核对"）

## ② 核心要点
（该方面在本学段本学科的关键内容，逐条列出）

## ③ 教师解读
（内涵阐释 / 教学意义 / 与相邻方面的关系；凡借鉴知网文献观点的句末加 `[n]` 右上角上标序号（超链接，点击跳转文末「参考资料」对应篇名））

## ④ 学段学科落点
（本学段本学科的具体表现、教学建议或评价提示；尽量可直接转成单元或课时动作；引用知网文献处用 `[n]` 右上角上标序号（超链接）标注）

## ⑤ 常见误区
（教师容易混淆或过度拔高的地方，逐条列出并给出纠正方向）

## ⑥ 安全标注（仅承载"版本声明 + ⚠请核对"，不写文献/接口细节）
- 课标版本：本报告依据《义务教育/普通高中XX课程标准（……年版）及2025年日常修订版》；2025年日常修订版为日常修订，核心要求保持连续，具体修订细节以官方文本为准。
- ⚠请按所用课标版本核对：课标原文、章节、页码与学段划分（未上传课标原文时依通识整理，未逐字引用、不标页码，请勿当官方原文照搬）。

> 口径纪律：安全标注只放"版本声明 + ⚠请核对"，是对读者的诚信护栏；**文献筛选口径（如"期刊限核心、普刊剔除"）、检索接口字段、引用诚信声明等一律不写入安全标注**，归入下方「参考资料」小节（最多一句话带过）或直接省略，避免对一线教师喧宾夺主。

#### 参考资料

> 每条篇名所在条目设锚点 `id="ref-n"`（n 与正文 `[n]` 对应）；正文 `[n]` 以 `<sup><a href="#ref-n">[n]</a></sup>` 渲染，点击跳转到本条篇名处。

1. <a id="ref-1"></a>[《……》](检索返回的 url 字段) · 〔在知网平台阅读页查看完整题录〕 · 《……》2026年第XX期 · 期刊 · 2026年
2. <a id="ref-2"></a>[《……》](检索返回的 url 字段) · …… · 《……》2025年第XX期 · 期刊 · 2025年

> 🔒 **铁律**：篇名必须是可点击超链接（**`href` 优先取用检索返回的 `url` 字段**——知网单篇在线阅读页 `ix.cnki.net/read/article/readonline?...`（与"投稿选刊"的 `readUrl` 完全一致），由知网负责登录 / 鉴权，本技能不自行拼装、也不展示登录说明；`url` 字段缺失时回退 `https://kns.cnki.net/kns8s/defaultresult/index?kw=篇名`（与 `ix.cnki.net` 同属知网主站、共用统一登录，登录页与"投稿选刊"一致），仍以知网官方入口落点），**不能是纯文本**；同时保留 `id="ref-n"` 锚点供正文 `[n]` 跳入。**输出呈现安全红线（详见 cnki-retrieval.md 6.5）**：篇名在 HTML 中必须显式 `text-decoration:none`（**无下划线**）、不把 `文件名`/`url` 作为可见文字展示、不出现代码符号/`id` 等技术文字；`id` 与 `href` 仅存在于标记属性、渲染后不可见。

（无相关文献结果时整节省略；若确需说明只写"本次未检索到符合年限要求的相关文献"。）
````

> 具体到某一方面时，在 ①④ 之间插入该方面的专用条目（见表三），并保持 ⑤⑥ 收尾。

## 五、写作口径建议

- **行为动词**要和学段匹配：低段用"感受、认读、说出、复述"，中高段用"理解、概括、初步运用"，初中用"理解、概括、品味、初步分析"，高中用"鉴赏、评价、比较、梳理、探究"。
- **一条要点一行**，避免长段落；教师需要能快速扫读。
- **落点要可执行**：写"可设计 3 课时的'……'任务"比写"要注重实践"有用。
- **不确定就标注**：宁可写 `⚠请核对`，也不要编造章节号或页码。
- **文献与原文分区、引用处角标**：课标原文放「①课标依据」，文献佐证以正文带 `[n]` 右上角上标序号（超链接）的句子呈现，不要把文献里的说法写成"课标规定"。
- **参考资料从属且可核查**：参考资料是置于报告最末尾、用**小级别标题**、每条**一行轻量紧凑**、**3–5 篇克制**，不喧宾夺主。每条含标号 / 篇名（超链接）/ 作者 / 来源(年期) / 发表时间 / 类型，不设独立"阅读"项；均为相关文献；年期/发表时间从 `PubDate`/`Year` 解析（见 cnki-retrieval.md 第三节），取不到就写"未确认"；作者（`Author`）与来源（`Source`/`JournalName`）接口已直接返回，可直接写入，仅字段确为空时标"详见阅读页题录"，**不猜、不凑、不编**。
- **观点溯源**：③教师解读 / ④学段学科落点中凡借鉴某篇文献观点，在句末用右上角上标序号 `[n]`（超链接，点击跳转文末「参考资料」对应篇名）标注，文末「参考资料」按同一编号给出完整题录（设锚点 `id="ref-n"`），篇名即指向知网官方入口的链接（优先取 `url` 字段直链、否则题名检索入口 `kns.cnki.net/kns8s/defaultresult/index?kw=篇名`，登录由知网接管），做到"这个观点来自知网某篇文献"可查可点开。
