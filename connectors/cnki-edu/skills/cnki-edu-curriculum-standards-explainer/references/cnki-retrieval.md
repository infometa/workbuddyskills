# 知网文献检索（CNKI Retrieval）

用中国知网（CNKI）文献库为课标解读补一条**权威证据链**：课标原文说"是什么"，知网文献说"专家怎么解、教研怎么落、这次修订为什么这么改"。

本文件是检索操作手册。**只做检索与引用，不做内容生成**——检索到的观点必须与课标原文分开标注，不得混为一谈；且任何文献元数据（题名 / 作者 / 来源 / 年期 / 发表时间）**一个都不能编造**。

---

## 一、什么时候检索（触发条件）

| 场景 | 是否检索 | 说明 |
|---|---|---|
| 用户要做**版本对比**（如"2022版 vs 2025年修订版有什么区别"） | ✅ 必检索 | 修订版变化类文献是最直接的依据 |
| 用户要**权威释义 / 学界共识**（如"核心素养内涵""这个词课标为什么这么表述"） | ✅ 必检索 | 用专家论文佐证，避免自说自话 |
| 用户要**落地路径 / 教研范例**（如"课标要求怎么分解到单元""教学建议怎么落地"） | ✅ 必检索 | 找一线教研与实践类文献 |
| 用户问**课标原文、章节、页码** | ⛔ 不检索 | 这是课标文本问题，文献不能替代原文；走原文/上传文档路径 |
| 用户已上传课标原文，且只问单条要求 | ⚪ 可选 | 原文已够时不必检索；用户要求"补充依据"时再检索 |
| 纯概念辨析、快速答疑 | ⚪ 可选 | 只在用户明确要"参考资料/知网文献依据"时检索 |

**默认策略**：检索到的文献以"正文右上角上标序号 `[n]`（超链接，点击跳转文末「参考资料」对应篇名） + 文末「参考资料」列表"方式融入报告。**期刊只收核心，报纸、会议论文、博硕士论文、工具书相关即收**——即期刊须为核心（经 `coreJournals`/`CoreIndex`/`CSSCI` 命中），其余类型相关即可纳入。检索有相关结果就引用，检索失败或无相关结果就省略角标与参考资料——**不得因为检索不到就编造文献**。

## 二、可用接口（2026-10 实测复核）

知网教育 MCP（服务名 `edu`）提供两个检索接口。**其余接口（mcp__<SERVER>__tkBook / mcp__<SERVER>__tkPoint / mcp__<SERVER>__tkSearchQuestion / mcp__<SERVER>__tkSubject 等）是题库与教材接口，与课标解读无关，不要调用。**

### 2.1 文献库检索（推荐首选）

`mcp__<SERVER>__searchVectorBJ` —— 按文本向量检索文献库，返回**篇名级**结果（含篇名、`Author`、`Source`/`JournalName`、`PubDate`、`Year`、`ResourceType`、正文/摘要、小标题等；⚠️ 当前响应**不返回** `url` / `文件名`）。

| 参数 | 说明 |
|---|---|
| `text` | **必填**，查询文本 |
| `query_type` | 0 篇名 / 1 摘要 / 2 小标题 / 3 主题（**推荐 1**："摘要"召回质量最稳） |
| `maxRecallNumber` | 最大返回数，默认 20；推荐 **20–30** |
| `nprobe` | 最近邻聚类中心数，默认 15；召回不足时可提到 30 |
| `type` | ✅ **可用（2026-10 复核：传值可正常返回，旧文档"传 type 报错"的说法已过时）**。文献类型过滤：`0 期刊` `1 硕士` `2 博士` `3 会议` `4 报纸`，多值逗号隔开。**四类资源对应**：期刊=`0`、报纸=`4`、会议论文=`3`、博硕士论文=`1,2`（硕士+博士合并为"博硕士论文"）。建议传 `0,1,2,3,4` 全量召回后再按 `resource` 分组，或按用户偏好的类型定向检索 |

### 2.2 段落库检索（需要具体段落时用）

`mcp__<SERVER>__searchVectorBJPara` —— 按文本向量检索段落库，返回**段落级**结果（含父文献篇名、当前小标题、章节序号、文件ID）。

| 参数 | 说明 |
|---|---|
| `text` | **必填**，查询文本 |
| `query_type` | 0 篇名小标题 / 1 段落主题（**推荐 1**） |
| `maxRecallNumber` | 同 2.1 |
| `nprobe` | 同 2.1 |
| `type` | ✅ 同 2.1，可用，覆盖四类资源 |

**两者怎么选**：
- 想知道"**有哪些文献**谈过这个问题" → `mcp__<SERVER>__searchVectorBJ`（文献库）
- 想直接拿到"**某段具体论述**"（如学业质量的内涵界定、水平划分说明） → `mcp__<SERVER>__searchVectorBJPara`（段落库）
- 两者可以**各查一次再合并**，效果最好。

### 2.3 返回字段解读（实测）

> ⚠️ **字段现实（2026-10 实测 `mcp__<SERVER>__searchVectorBJ` 真实响应）**：接口**直接返回** `Author`(作者)、`Source`/`JournalName`(来源/刊名)、`PubDate`(发表日期)、`Year`(年)、`ResourceType`/`resource`(类型)、`CitedTimes`(被引)、`DownloadedTimes`(下载)、`Keyword`、`Summary`(摘要)等结构化字段——这些可直接写入报告，**不必再标"在知网平台阅读页查看完整题录"**（仅当某字段确为空时才标"详见阅读页题录"）。**真正的缺口是 `url` 与 `文件名`**：当前响应**不返回**直链 `url` 与内部文章键 `文件名`，故无法拼出"本篇在线阅读直链"，链接统一走 6.4 的「`url` 优先、否则题名检索 `kns.cnki.net/kns8s/defaultresult/index?kw=篇名`」方案。

| 字段 | 含义 | 用途 |
|---|---|---|
| `篇名` | 文献标题 | → 四维之「题名」；判断是否切题 |
| `正文` | 摘要或正文片段 | 判断是否为课标解读类文献的关键证据；偶尔含作者/出处线索，仅作辅助，**不得据此编造作者/来源** |
| `小标题` | 目录/小标题串 | 看文献结构覆盖面（如是否含"学业质量""教学建议"章节） |
| `PubDate` | 发表日期（如 `2026-09-10`） | → 解析「年期 / 发表时间」的**可靠来源**（见第三节）；同时用于年限过滤 |
| `Year` | 年（如 `2026`） | 发表时间年份；`PubDate` 缺失时兜底 |
| `ResourceType` / `resource` | `期刊`/`中国会议`/`硕士`/`博士` 与 `JOURNAL`/`CONFERENCE`/`DISSERTATION`/`NEWSPAPER` | → 四维之「类型」（期刊 / 会议论文 / 博硕士论文 / 报纸） |
| `文件名` | ⚠️ **当前 `mcp__<SERVER>__searchVectorBJ` 响应不返回此字段** | 旧文档曾用其解析年期，现改由 `PubDate`/`Year` 解析；不再依赖、也不再用于对外展示或拼接链接 |
| `url` | ⚠️ **当前 `mcp__<SERVER>__searchVectorBJ` 响应不返回此字段** | 若未来接口返回，则其形态为知网单篇在线阅读页 `ix.cnki.net/read/article/readonline?dbcode=…&tablename=…&filename=…&fileSourceType=1`（与"投稿选刊"的 `readUrl` 完全一致），直接作为篇名 `href` 直链（见 6.4）；当前统一走题名检索入口 `kns.cnki.net/kns8s/defaultresult/index?kw=篇名` |
| `相关度` / `距离` | 相关度百分比 / 余弦距离（越小越近） | 排序参考 |

### 2.4 标准文档检索 `mcp__<SERVER>__standardSearch`（课标原文兜底，详见第十节）

`mcp__<SERVER>__standardSearch` 与上面两个文献检索接口**不同**：它检索的是"课标 / 教材"等**标准文档**块（而非期刊 / 会议等文献），用于**用户未上传课标原文时**取「课标依据」来源。参数：`query`（必填，查询文本）、`topK`（默认 10）、`minScore`（默认 0.3，最低相关度阈值）。其落位、标注与安全约束见第十节，降级处理见第七节。

## 三、年限、年期与发表时间过滤（本技能核心约束）

接口没有年份参数，只能在拿到结果后**按返回的时间字段解析并过滤**。

> ⚠️ **字段现实（2026-10 实测 `mcp__<SERVER>__searchVectorBJ` 真实响应）**：实际返回的是 `PubDate`（如 `2026-09-10`）、`Year`（如 `2026`）、`ResourceType`（如 `期刊`/`中国会议`/`硕士`）、`resource`（如 `JOURNAL`/`CONFERENCE`/`DISSERTATION`）等结构化字段；**并不返回 `文件名` / `url` 等内部文章键**。因此年期 / 发表时间一律从 `PubDate` / `Year` 解析，类型从 `ResourceType` / `resource` 判定，不要再依赖 `文件名`。

### 3.1 `PubDate` / `Year` → 年期 / 发表时间 解析规则（按真实返回字段）

| 文献类型 | 取值来源 | 年期 / 发表时间 解析 |
|---|---|---|
| 期刊 | `PubDate`(如 `2026-09-10`) + `Year` | 年期 = `{Year}年第{MM}期`（`MM` 取自 `PubDate` 月）；发表时间 = `Year年` |
| 会议（中国会议） | `PubDate` + `Year` | 会议论文按年计，年期 = `{Year}年会议`；发表时间 = `Year年` |
| 报纸 | `PubDate`(如 `2026-01-27`) | 年期与发表时间 = `PubDate`（报纸按刊发日） |
| 博硕士（硕士/博士） | `PubDate` + `Year` | 发表时间 = `Year年`；`PubDate` 含月日则保留 |

> `PubDate` 缺失时回退用 `Year` 给到"XXXX年"即可，不强行补月期；仍缺失才标注「发表时间未确认，详见阅读页题录」。

### 3.2 年限门槛（**硬约束**）

按学段分别设有效区间，**取出文献后先过滤再引用**：

| 解读对象 | 文献出版年门槛 | 说明 |
|---|---|---|
| **义务教育**课标解读 | **≥ 2022 年** | 对应《义务教育课程方案和课程标准（2022年版）》颁布年，2022 年前的义教文献针对旧版课标，不适用 |
| **普通高中**课标解读 | **≥ 2017 年** | 对应《普通高中课程方案和课程标准（2017年版）》，2017 年前的文献针对 2003 实验版，不适用 |
| **2025 年日常修订版**解读 | **重点关注 2025 年及以后** | 目前最新修订版本，义教（2022年版2025年修订）与高中（2017年版2025年修订）均有 |

**优先级排序（同等切题度下）**：

```
2025 年（含 2025 年修订版解析、新旧修订对比）
  > 2023–2024 年（2022版义教 / 2017版高中的深度解读）
    > 2022 年（义教课标颁布年的权威解读）
      > 2017–2021 年（高中课标解读，仅高中话题可用）
```

**判定"是否针对 2025 年修订版"的方法**（不必只看年份）：
- `正文` 中出现 `日常修订版`、`2022年版2025年修订`、`2017年版2025年修订`、`2025年修订` → **强信号，重点采用**
- `正文` 中出现 `2020年修订` → 高中旧修订版（次新，可作对比基线）
- `正文` 中出现 `2022年版`（义教）/`2017年版`（高中）但无 2025 字样 → 该版本文献，仍可用，但需注明"针对 XX 年版，2025 年日常修订后是否变化 ⚠请核对"

### 3.3 博硕士论文的年限处理

文件名无年份 → 用 `正文` 中的课标版本表述间接判断：
- 正文提到 `2025年修订` → 最新，可用
- 正文提到 `2022年版2025年修订` / `2017年版2020年修订` → 对应版本年度，可用
- 正文只提旧版课标（如"2011年版""2003年版"）→ **剔除**
- 完全无法判断 → 报告中**标注"博硕士论文，发表年度未确认"**后作为参考，或直接弃用（宁缺毋滥）

## 四、检索式构造（4 段式模板）

把四要素填进下面模板，**可辨识度最高**：

```
{课标名称全称} + {学段/年级} + {解读方面} + {意图词}
```

| 位置 | 取值示例 |
|---|---|
| 课标名称全称 | `义务教育语文课程标准`、`普通高中物理课程标准`、`义务教育数学课程标准日常修订版` |
| 学段/年级 | `小学`、`小学低段`、`初中`、`高中`、`高一`（义教用小学/初中，高中用高中） |
| 解读方面 | `核心素养` / `课程性质` / `课程理念` / `课程目标` / `课程内容` / `学业质量` / `课程实施` |
| 意图词 | `解读` / `内涵` / `变化` / `修订` / `对比` / `教学建议` / `落地` / `实施` / `评价` |

**组合示例**（可直接用）：

| 目的 | 检索文本 | 建议 `type` |
|---|---|---|
| 全类型广撒网 | `义务教育语文课程标准 核心素养 内涵 解读` | `0,1,2,3,4` |
| 只看期刊权威释义 | `普通高中语文课程标准 核心素养 内涵` | `0` |
| 要学位论文深度研究 | `义务教育数学课程标准 学业质量` | `1,2` |
| 要会议/报纸快讯型 | `2025年修订 课程标准 变化` | `3,4` |

**检索次数建议**：一般 **1–2 次**（文献库 1 次 + 段落库 1 次）足够；话题偏冷或首轮切题率低于 1/3 时，换意图词或换 `type` 再查一次，**最多 3 次**，避免无谓开销。

## 五、结果筛选（**必须做，向量检索会误召回**）

实测中会出现与教育无关的"语义近邻"（例如查"学业质量"却返回畜牧养殖类段落）。按下列顺序筛：

> **来源类型约束（硬约束，优先于一般筛选）**：本技能输出的知网文献按"**期刊限核心、其余相关即收**"处理——**期刊类**须以 `coreJournals = "Y"` 或 `CoreIndex`（如 `P01` 北大核心）、`CSSCI` 字段命中为准（非核心普刊不纳入）；**报纸、会议论文、博硕士论文、工具书**只要与课标解读相关即纳入，不做核心等级限制。全量召回（`type=0,1,2,3,4`）后先按来源类型分流，期刊再用核心字段过滤。若全部类型过滤后无合格结果，明确写出"本次未检索到符合年限要求的相关文献"，不跨级顶替。

1. **看 `正文` 是否提到课标**：出现课标名称/版本年份 → 保留；完全不提课标 → 直接剔除。
2. **看学科是否对上**：正文出现目标学科术语（或明确是通用/跨学科研究）→ 保留；学科明确不符 → 剔除。
3. **看学段是否对上**：小学 vs 初中 vs 高中不得串味（与总原则第 1 条一致）。
4. **看是否课标解读类**：篇名/小标题含"解读""变化""修订""对比""内涵""实施要义" → 高度契合；纯教学策略类 → 作为"教学落点"参考，不作为"课标释义"依据。
5. **按来源类型分流**：经"来源类型约束"过滤——期刊保留 `coreJournals=Y` / `CoreIndex` / `CSSCI` 命中的核心期刊论文；报纸、会议论文、博硕士论文、工具书只要相关即保留；非核心普刊剔除，不得跨类顶替。

> **用户引用偏好（本技能默认规则 · 2026-10-13 追加，适用于所有使用者）**：默认要求"参考资料优先参考期刊（七k=期刊）"。在同等相关度下，优先以**期刊论文（尤其是核心期刊）**作为解读与落地案例的主证锚点，**硕士论文（博硕士）降级为补充、不列为主证**。本偏好与上述"期刊须核心"质量门并存，执行顺序：① 优先选用核心期刊；② 若仅检索到普通期刊（非核心），在"相关"前提下可优先于硕士论文采用，但条目须标注「普通期刊」以保持透明；③ 硕士论文仍可作落地案例的延伸/补充阅读，不喧宾夺主。若用户后续要求"仅限核心"，则回到本条⑤的严格核心门槛。
6. **按年限门槛过滤**（第三节）。
7. **排序**：切题度 → 是否针对 2025 年修订版 → 年份新 → 相关度高。
8. **取用数量**：报告正文引用 **3–5 篇**文献为宜，宁精勿多；按切题度从高到低取用，期刊须为核心、其余相关即可；若合格结果不足 3 篇，按实际合格数量引用，不得用无关文献凑数。

## 六、参考资料列表格式、观点溯源与知网平台阅读链接

### 6.1 文末「参考资料」列表（每条被引文献必给）

> **定位铁律**：本技能的主角永远是**课标解读本身**（课标依据 / 核心要点 / 教师解读 / 学段学科落点）。参考资料只是**从属、辅助**板块，用于"辅助解读 / 厘清知识点"，**不可喧宾夺主**。

据此执行四条约束：

- **位置从属**：永远置于报告**最末尾**（「⑥ 安全标注」之后），不前置、不插在解读条目之间。
- **数量克制**：够用即可，一份报告 **3–5 篇**；不为凑数堆量。
- **版式轻量**：用**小级别标题**（`#### 参考资料`）、小字号/弱化色呈现；**每条一行紧凑排列**，去掉冗长的"篇名：/作者：/来源：/发表时间：/类型："字段标签；不做大标题、不做面板、不加粗重边框。
- **不打断主线**：文献只在"需要佐证或厘清"处出现`[n]` 角标（超链接，点击跳转文末「参考资料」对应篇名），解读正文始终占据主要篇幅与视觉重心。

报告**文末**统一附「参考资料」列表，按正文`[n]` 角标（超链接，点击跳转文末「参考资料」对应篇名）顺序排列。每条**一行**，格式为：

```
`[n]`《篇名》 · 作者 · 来源(年期) · 类型 · 发表时间
```

其中**篇名为可点击超链接**（`href` 优先取检索返回的 `url` 字段；当前 `mcp__<SERVER>__searchVectorBJ` 不返回 `url`，统一回退标题检索入口 `https://kns.cnki.net/kns8s/defaultresult/index?kw=篇名`，知网官方入口、登录由知网接管，构造见 6.4）；不设独立的"阅读"项。

**锚点（超链接落点）**：文末「参考资料」每条篇名所在条目须设锚点 `id="ref-n"`（n 与正文 `[n]` 一一对应）；正文 `[n]` 以 `<sup><a href="#ref-n">[n]</a></sup>` 形式渲染，点击即跳转到本条篇名处，实现"引用处右上角序号 → 文末篇名"的可点跳转。

> 🔒 **铁律（生成时不可违反）**：「参考资料」中**每一条篇名都必须渲染为可点击超链接（绝不可以是纯文本）**，指向知网官方入口，**篇名 `href` 优先取检索返回的 `url` 字段**（知网单篇在线阅读页 `ix.cnki.net/read/article/readonline?...`，与"投稿选刊"的 `readUrl` 完全一致，由知网负责登录 / 鉴权）；⚠️ 实测当前 `mcp__<SERVER>__searchVectorBJ` 不返回 `url`，统一回退知网主站标题检索入口 `https://kns.cnki.net/kns8s/defaultresult/index?kw=篇名`（与 `ix.cnki.net` 同属知网主站、共用统一登录，登录页与"投稿选刊"一致）；**严禁用 `dbcode`/`tablename`/`filename` 自行拼装直链**。同时该条目保留锚点 `id="ref-n"`（仅作标记属性、渲染后不可见），供正文 `[n]` 点击跳入。两条跳转职责不同、二者都要有：正文 `[n]` → 文末篇名（`#ref-n`），文末篇名 → 知网官方入口（直链 `href` / 回退搜索入口）。**输出呈现的安全红线与版式要求见 6.5**：篇名在 HTML 中必须显式 `text-decoration:none`（无下划线）、不得把 `文件名`/`url` 作为可见文字展示、不得暴露代码符号等敏感信息；`id` 与 `href` 仅写在标记属性中、渲染后不可见。

**实际渲染示例**（同时含"向内锚点"与"向外链接"，`url` 或题名检索入口仅存 `href` 属性、渲染后不可见）：

```markdown
1. <a id="ref-1"></a>[《篇名示例》](检索返回的 url 字段) · 作者 · 《来源》2026年第XX期 · 期刊(核心) · 2026年
2. <a id="ref-2"></a>[《篇名示例》](检索返回的 url 字段) · 作者 · 单位(硕士) · 2026年
```

```html
<li><a id="ref-1" href="检索返回的 url 字段">《篇名示例》</a> · 作者 · 《来源》2026年第XX期 · 期刊(核心) · 2026年</li>
<li><a id="ref-2" href="检索返回的 url 字段">《篇名示例》</a> · 作者 · 单位(硕士) · 2026年</li>
```

- 标号：与正文右上角上标序号 `[n]`（超链接，点击跳转文末「参考资料」对应篇名）一致。
- 篇名：取自 `篇名`，并渲染为可点击超链接（`href` 见 6.4，用本篇在线阅读直链，内部标识仅存属性）。
- 作者：接口不返回，标注"在知网平台阅读页查看完整题录"，**严禁编造**。
- 来源(年期)：取 `Source`/`JournalName`(来源/刊名) + 年期（年期从 `PubDate`/`Year` 解析，见第三节）；字段确为空才标"详见阅读页题录"。
- 发表时间：从 `PubDate`/`Year` 解析；取不到写"未确认"。
- 类型：按 `resource` 动态标注——`JOURNAL`→期刊、`NEWSPAPER`→报纸、`CONFERENCE`→会议论文、`DISSERTATION`→学位论文；工具书单独标为"工具书"。期刊项已确认为核心（经 `coreJournals`/`CoreIndex`/`CSSCI` 命中），但对外只写"期刊"，不显示是否核心。
- 篇名超链接：指向知网平台本篇在线阅读页直链（点击直达阅读页，`href` 见 6.4；库未收录回退安全搜索入口）。不设独立的"阅读"项。

### 6.2 正文内 `[n]` 上标序号（必做，超链接）

凡正文解读（③ 教师解读 / ④ 学段学科落点）中引用或借鉴某篇文献观点，须在句末用**右上角上标序号 `[n]`（超链接，点击跳转文末「参考资料」对应篇名）**标注（如 ``[1]``），并在文末「参考资料」给出对应编号 n 的完整题录，篇名即指向该篇目在线阅读页/知网节的超链接，做到"这个观点来自知网某篇文献"清晰可查、可点开。

### 6.3 安全约束

- **年份/年期取不到就写「未确认」**，不得猜测。
- **作者、来源全称缺口处理**：保留字段并标注「在知网平台阅读页查看完整题录」，**绝不编造**——这是本技能"不编造文献"铁律的延伸。
- 不得改写文献结论：概括只能压缩，不得加料；原话标「原文摘录」。
- 文献观点与课标原文**分区呈现**：原文进「① 课标依据」，文献佐证以正文带`[n]` 角标（超链接，点击跳转文末「参考资料」对应篇名）的句子呈现，不混写；文献与原文冲突**以课标原文为准**，在「⑤ 常见误区」提示。
- **来源类型约束**：参考资料中期刊须为核心，其余相关类型（报纸/会议论文/博硕士论文/工具书）相关即收（见第五节），非核心普刊不纳入。
- ⛔ **严禁编造文献**：题名、作者、来源、年期、发表时间一个都不能猜。检索不到就写"本次未检索到符合年限要求的相关文献"。

### 6.4 篇名超链接构造（知网平台入口）

每条文献的**篇名**即点击入口，指向知网平台（cnki.net）。**链接构造优先级**：

1. **优先**：若检索结果返回了 `url` 字段，直接取用该字段作为 `href`——其形态为知网单篇在线阅读页 `https://ix.cnki.net/read/article/readonline?dbcode=…&tablename=…&filename=…&fileSourceType=1`（**与"投稿选刊"技能的 `readUrl` 完全一致**），点击即直达本篇阅读页，**登录 / 鉴权由知网官方链路自动接管，本技能不自行处理、也不向用户展示任何登录说明**。
2. **回退**：若接口**未返回 `url`**（⚠️ 实测当前 `mcp__<SERVER>__searchVectorBJ` 响应不含 `url` / `文件名` 字段），则回退为知网主站标题检索入口 `https://kns.cnki.net/kns8s/defaultresult/index?kw=＜篇名＞`（以篇名检索知网，本篇通常置顶；该入口与 `ix.cnki.net` 同属知网主站、共用知网统一账号登录，**未登录时弹出的登录页与"投稿选刊"一致**）。

- ⚠️ **严禁用 `dbcode` / `tablename` / `filename` 自行拼装链接**：当前接口既不返回这些参数也无法据此可靠构造直链，强行重拼既冗余又易错，且违背"不暴露内部元数据"的红线精神；统一走上述 1 / 2 两种官方入口即可。
- 在线阅读与全文 / PDF 下载由知网平台负责，本技能本身不托管全文。

### 6.5 输出呈现纪律（安全红线，不可违反）

> 跨场景统一版「干净输出红线」（完整字段清单与写法）见 [_shared.md](_shared.md)「干净输出红线」；本节为本技能场景化补充与渲染示例，不得与 _shared 冲突。

生成的 md / html 解读报告中，参考资料部分只呈现"干净的教师可读内容"，**严禁在最终文档中出现任何涉及知网内部结构与实现机制的敏感信息或代码符号**——**本条红线的本质：面向用户的输出中不得出现任何知网接口响应的元数据字段名或字段值**（如 `url` / `filename` / `文件名` / `文件ID` / `dbcode` / `tablename` / `coreJournals` / `CoreIndex` / `CSSCI` / `resource` / `product` / `相关度` / `距离`、内部文章键 `SDJX…` 之类、类型 / 来源库内部代码、以及内部阅读直链 URL 模板与查询参数 `ix.cnki.net/read/article/readonline?dbcode=…&tablename=…&filename=…` 等）；此类内部标识**只可存在于超链接 `href` 属性与锚点 `id` 属性中（渲染后不可见）**，仅供底层链接构造与 Agent 内部决策使用，严禁作为可见文字 / 代码符号出现在最终文档。具体禁令：

- ❌ 不显示 `文件名` / `filename` 等知网内部文章键；
- ❌ 不把 `url` 字符串本身作为**可见文字**展示（如把 `https://ix.cnki.net/...` 写成正文/说明文字），也不将其标注为"阅读地址链接"；但 `url` 作为超链接的 `href` 属性（仅底层、渲染不可见）是**允许且推荐**的（见 6.4）。
- ❌ 不出现任何代码符号 / 标签文本，如 `<a>`、`id="ref-n"`、`<code>`、HTML 片段；
- ❌ 不出现说明性技术文字，如"篇名为指向知网平台在线阅读页的超链接（点击直达本篇阅读页）""同时设锚点 `id="ref-n"` 供正文 `[n]` 跳入""ID地址"等；
- ❌ 不在「参考资料」标题上附加"（知网文献 · 辅助解读）"之类的修饰性括注，标题只用 `#### 参考资料`。
- ❌ 不向用户展示任何检索 / 筛选过程的说明性文字（如"本次文献检索以博硕士论文、会议论文为主""期刊类因接口未返回核心期刊判定字段、无法核验限核心要求，故未纳入""文献作者与来源取自检索返回题录""年份/年期由返回数据解析"等）；此类内部口径只用于 Agent 内部决策，严禁进入面向用户的输出。
- ❌ 篇名超链接不得指向知网以外的平台；篇名 `href` **优先取用检索返回的 `url` 字段**（知网单篇在线阅读页 `ix.cnki.net/read/article/readonline?...`，由知网负责登录 / 鉴权），**严禁用 `dbcode`/`tablename`/`filename` 自行拼装**；`url` 字段缺失时回退知网主站标题检索入口 `kns.cnki.net/kns8s/defaultresult/index?kw=篇名`（与 `ix.cnki.net` 同属知网主站、共用统一登录，登录页与"投稿选刊"一致）。
- ❌ **篇名不加下划线**——HTML 中 `.ref-title` 必须显式写 `text-decoration:none`（仅用颜色 + 加粗区分可点击，绝不依赖浏览器默认下划线）。

✅ 允许且必须保留的"不可见"功能：篇名本身是可点击的超链接（链接写在标记的 `href` 中、不显示为文字），以及向内锚点 `id="ref-n"`（写在标记属性中、不显示为文字），使正文 `[n]` 能跳到文末对应篇名——这些仅存在于文档底层标记，**渲染后不可见**，不违反上述红线。

## 八、在报告中的落位

知网文献**不再以独立"文献支撑"模块呈现**，改为"正文右上角上标序号 `[n]`（超链接，点击跳转文末「参考资料」对应篇名） + 文末「参考资料」列表"方式融入报告：

## 十、未上传课标原文时的标准文档检索（mcp__<SERVER>__standardSearch）

当用户**未上传**课标原文 / PDF / txt 等文件时，本技能不再仅靠"调用模型知识"兜底，而是优先调用 **`edu` 连接器（中国知网教育）的 `mcp__<SERVER>__standardSearch`** 检索"课标 / 教材"等**标准文档**块，作为「课标依据」辅助解读（对应 Workflow 第 3 步的"未上传 → 调用 `mcp__<SERVER>__standardSearch`"分支）。

### 10.1 接口说明

`mcp__<SERVER>__standardSearch` —— 按查询文本向量检索**标准文档**（课标 / 教材等），返回命中的**文档块内容**与其**元数据**（文档名 / 章节 / 相关度等）。

| 参数 | 说明 |
|---|---|
| `query` | **必填**，查询文本（建议填"课标全称 + 学段 + 解读方面"，如"义务教育语文课程标准 核心素养 内涵"） |
| `topK` | 最大返回数，默认 10 |
| `minScore` | 最低相关度阈值，默认 0.3（低于此分的块不返回；命中稀少时可下调或提高 `topK` 重试） |

### 10.2 与文献检索（mcp__<SERVER>__searchVectorBJ / mcp__<SERVER>__searchVectorBJPara）的关系

三者都来自 `edu` 连接器，但**职责不同、不可混用**：

| 接口 | 检索对象 | 在报告中的落位 | 引用方式 |
|---|---|---|---|
| `mcp__<SERVER>__standardSearch` | 课标 / 教材等**标准文档**块 | 进入「① 课标依据」作为原文来源 | 在「课标依据」处注明"来源：知网教育数据检索（文档名 / 章节）"；**不占用 `[n]` 序号** |
| `mcp__<SERVER>__searchVectorBJ` / `mcp__<SERVER>__searchVectorBJPara` | 期刊 / 报纸 / 会议 / 博硕士等**文献 / 论文** | 进入文末「参考资料」作为证据支撑 | 正文引用处用**右上角上标序号 `[n]`（超链接）**标注，`[n]` 对应文末「参考资料」篇名（见第六、九节） |

> 一句话：**`mcp__<SERVER>__standardSearch` 解决"课标原文从哪来"，`mcp__<SERVER>__searchVectorBJ/Para` 解决"专家怎么解读"**。标准文档本身即课标依据，无需用 `[n]` 角标；`[n]` 角标专用于 CNKI 文献（即本文件第二~九节所述的文献检索结果）。

### 10.3 用法与标注

1. **触发**：Workflow 第 3 步判定"用户未上传课标文档"且 `edu` MCP 已连接 → 调用 `mcp__<SERVER>__standardSearch`，`query` 用"课标全称 + 学段 + 解读方面"，`topK` 取 10、`minScore` 取 0.3（命中稀少时下调 `minScore` 或提高 `topK` 重试）。
2. **落位**：命中的标准文档块内容写入「① 课标依据」，并在该条下方注明来源为"知网教育数据检索（文档名 / 章节 / 相关度）"，做到"这段课标依据来自知网标准文档库"可核查。
3. **安全标注**：mcp__<SERVER>__standardSearch 命中的是"标准文档块"，**不一定能精确对应到具体章节页码**；无法精确定位时，在「课标依据」处与报告末尾统一标注 `⚠请按所用课标版本核对`，与"调用模型知识"兜底时的标注一致。
4. **降级**：未通过 `mcp__<SERVER>__userState` 基教权限校验、检索失败或返回 0 条 → **先输出 e.cnki.net 购买引导**；仅在用户未上传原文且确无权限时，允许一段明确标注"通用版（未接入知网基教，知网数据增强层暂未启用）"的通用性说明，绝不编造章节与页码、不以模型知识冒充"课标依据"（见第七节降级策略）。
5. **不喧宾夺主**：mcp__<SERVER>__standardSearch 只是"课标原文来源"的增强，主流程仍是七条总原则与通用 / 专用输出结构；若用户已上传课标原文，则优先用上传原文，跳过 mcp__<SERVER>__standardSearch。
