# 工作流程详解（Workflow）

流程围绕 **学段 + 学科 + 课标版本 + 解读方面** 四个关键变量展开，确保输出内容精准、可落地、不越界。

## 总览

```
用户输入 → 初始化总控 → 课标来源判断 → 解读方面选择 → 组合提示词
        → 定位课标章节 → 知网文献检索（可选） → 提取与解读
        → 学段学科适配 → 安全校验 → 输出结果 → 支持追问与循环
```

## 分步说明

### Step 1. 用户输入

教师填写：学段、年级、学科、课标版本、课标文档（已上传/未上传）、任务（解读哪个方面：核心素养 / 课程性质 / 课程理念 / 课程目标 / 课程内容 / 学业质量 / 课程实施）、其他要求。

若四要素不全，先追问补齐，不要自行假设。

### Step 2. 初始化总控提示词

加载「总控系统提示词」，明确总原则：只输出指定学段学科、课标原文优先、学段适配、学科适配、安全标注等。

### Step 3. 课标来源判断

- 若用户**已上传**课标文档 → 解析文档，提取对应章节，引用时给出章节名与页码。
- **先经 `mcp__<SERVER>__userState` 校验基教权限**：未通过（未连接 / 无基教权益）→ **输出 e.cnki.net 购买引导**，不调用 `mcp__<SERVER>__standardSearch`；若用户已上传原文则按原文解读，否则仅可作明确标注"通用版（未接入知网基教，知网数据增强层暂未启用）"的通用性说明，绝不编造章节 / 页码。已通过 → 若**未上传**则调用 `edu` 连接器的 `mcp__<SERVER>__standardSearch` 检索"课标/教材"标准文档块作为课标依据（命中处注明来源），并标注 `⚠请按所用课标版本核对`。

### Step 4. 解读方面选择

根据用户「任务」字段，从 7 个专用提示词中选择对应的一个：

- 核心素养
- 课程性质
- 课程理念
- 课程目标
- 课程内容
- 学业质量
- 课程实施

### Step 5. 组合提示词

将「总控系统提示词」与所选「专用系统提示词」组合，填入 `{学段}` `{学科}` `{课标版本}`。

### Step 6. 定位课标章节

在课标文档中定位与该方面对应的章节（如"核心素养内涵""课程性质""课程内容"等）。若课标未单列该方面，则标注"该课标未单列，可参考……"。

### Step 7. 知网文献检索（可选，推荐）

**目的**：为解读补一条权威证据链——课标原文说"是什么"，文献说"专家怎么解、这次为什么这么改、一线怎么落"。

**执行**：

1. 判断是否检索。版本对比、要权威释义、要修订依据、要落地路径佐证 → **检索**；只问原文/章节/页码、或用户明确不要文献 → **跳过**。
2. 构造检索式：`{课标名称全称} + {学段} + {解读方面} + {意图词}`（意图词：解读 / 内涵 / 变化 / 修订 / 对比 / 教学建议 / 落地）。
3. 调用知网教育 MCP（`edu`）：
   - `mcp__<SERVER>__searchVectorBJ`（文献库，`query_type=1` 摘要）——查"有哪些文献"；
   - `mcp__<SERVER>__searchVectorBJPara`（段落库，`query_type=1` 段落主题）——查"某段具体论述"。
   - 传 `type=0,1,2,3,4` 全量召回（覆盖期刊/博硕士/会议/报纸），再按来源类型分流：期刊用 `coreJournals`/`CoreIndex`/`CSSCI` 过滤出核心，报纸/会议/博硕士相关即收；`query_type` 用 1（摘要）召回最稳。
4. 按返回的时间字段（`PubDate`/`Year`）解析出版年（规则见 cnki-retrieval.md 第三节，不再依赖 `文件名`）。
5. **年限门槛过滤**：义务教育 ≥ 2022 年、普通高中 ≥ 2017 年；**2025 年日常修订版**相关文献（正文含"日常修订版""2022年版2025年修订""2017年版2025年修订"）优先级最高。
6. 剔除误召回（向量检索会召回与教育无关的语义近邻）、跨学段、跨学科结果。
7. 取切题的 **3–5 篇相关文献**，在正文引用处用右上角上标序号 `[n]`（超链接，点击跳转文末「参考资料」对应篇名）标注，文末「参考资料」列出完整题录与阅读链接（每条篇名条目设锚点 `id="ref-n"`）。

**硬约束**：不编造文献；文献观点与课标原文分区呈现；文献与原文冲突时以原文为准；检索不到就写"本次未检索到符合年限要求的相关文献"。

完整细则（接口字段、检索式库、解析规则、筛选清单、降级策略）见 [cnki-retrieval.md](cnki-retrieval.md)。

### Step 8. 提取与解读

按「通用输出结构 + 专用输出结构」逐项生成：

- 课标依据（名称、章节、页码）
- 正文 `[n]` 右上角上标序号（超链接）+ 文末参考资料（**可选**，Step 7 有相关文献结果时插入）
- 核心要点
- 教师解读
- 学段学科落点
- 常见误区
- 安全标注

专用提示词还会增加：核心素养名称与内涵、本学段具体表现、教学落点等。

### Step 9. 学段与学科适配

- **学段适配**：小学低段重感受、认读、说出；中高段重理解、概括、初步运用；初中重理解、概括、品味、初步分析；高中重鉴赏、评价、比较、梳理、探究。
- **学科适配**：语文按学习任务群，数学按领域，英语按级别，科学按核心概念，艺术按艺术实践等。

详见 [subject-adaptation.md](subject-adaptation.md)。

### Step 10. 安全校验

对不确定的原文、章节、水平划分、行为动词，一律标注 `⚠请核对`，宁缺毋滥。自查清单：

- [ ] 是否混入了其他学段的要求？
- [ ] 是否混入了其他学科的术语？
- [ ] 引用的原文是否真实存在、逐字准确？
- [ ] 不确定项是否都已标注？
- [ ] 是否出现课标中不存在的概念或要求？
- [ ] 文献是否满足年限门槛（义教 ≥ 2022 年、高中 ≥ 2017 年）？
- [ ] 文献的篇名与年份是否可核查、有无编造？
- [ ] 是否把文献观点误写成了课标原文？

### Step 11. 输出结果

生成结构化解读报告，教师可直接用于备课、教研、课程开发、评价设计等。报告骨架见 [output-templates.md](output-templates.md)。

### Step 12. 支持追问与循环

教师可继续追问其他方面，系统重复 Step 4-11，输出新的解读。同一会话内的课标文档解析结果与文献检索结果可复用，不必重复检索。

## 流程关键点说明

- **双提示词组合**：总控保证全局约束，专用提示词保证解读深度。
- **课标原文优先**：能引用则引用，不能引用则忠实概括，绝不杜撰。
- **文献只作证据**：知网文献是可选增强层，用于佐证与补充视角；不替代课标原文，也不得反过来覆盖原文表述。
- **学段学科双适配**：避免高中要求下放小学、避免学科术语混用。
- **安全标注机制**：不确定处必须标注，确保教师使用时能自行核对。
- **可循环追问**：支持教师从不同方面反复解读同一课标，形成完整认知。
