# 学术溯源著录规范

**什么时候读**：要给题挂 `sources`、或校验器报了溯源提醒时。

---

## 一、按文献类型分流（GB/T 7714—2015 简化版）

用户要求知网来源按「**作者、篇名、来源期刊、年份、期**」呈现。这句话只对**期刊论文**成立，
所以按 `type` 分流。**严禁给专著套上期刊名和期号**——那是编造，比没有溯源更糟。

| type | 必填字段 | 渲染样式 |
|---|---|---|
| `journal` | author·title·container·year·issue（pages 可选） | `谭霈生．论戏剧性[J]．语文建设，2023(5)：18-22．` |
| `book` | author·title·publisher·year | `杨建文．中国古典悲剧史[M]．人民教育出版社，1994．` |
| `chapter` | author·title·container·publisher·year | `谭霈生．“戏”在内心[M]//谭霈生文集．北京大学出版社，2005：112．` |
| `thesis` | author·title·publisher·year | `作者．篇名[D]．授予单位，年．` |
| `newspaper` | author·title·container·year | `作者．篇名[N]．报名，年．` |
| `textbook` | title·publisher·year | `普通高中教科书·语文（必修 下册）．人民教育出版社，2019．` |

实现落在 `scripts/homework_kit.py` 的 `SOURCE_TYPES` / `_fmt_source()` / `_source_gaps()` 三处，
改格式只动这一处，不要在渲染层另写一套。

---

## 二、来源优先级：期刊论文第一

```
SOURCE_PRIORITY = ["journal", "thesis", "newspaper", "book", "chapter", "textbook"]
```

为什么期刊排第一：

- 只有期刊能给出完整的「**作者·篇名·来源期刊·年份·期**」——教师可在 CNKI 精确定位；
- 专著版本多、定位困难；教材**不是学术来源**，只在题目本身引用教材原文时才算出处，不许拿教材冒充溯源。

优先从学科包 `sources.venues` 里取刊物（语文=《中学语文教学》《语文建设》）。
`_venues_for()` 会按学段过滤掉含"小学""幼"字样的刊物，避免给高中推《小学语文教学》。

校验器对"学术性溯源里一条期刊/学位论文都没有"的题出**提醒**（非阻塞，退出码仍为 0）。

---

## 三、三条铁律

1. **按真实类型填**。拿不准一篇是论文还是专著，用 `chapter` 兜底（只缺 container/publisher，
   不会声称它发表在某刊上）。
2. **缺字段留 null，渲染成灰色 `【待补充】`**，校验器记为溯源提醒。**缺=待补，填错=编造**，两码事。
   教师看到【待补充】知道要做什么，看到假的刊名只会信以为真。
3. 旧格式 `{name, year}` 向后兼容并降级渲染，但会被提示补 `type`。

`validate` 输出示例：

```
共 12 题 · 预计 89 分钟 · 校验 通过 · 溯源提醒 16 项
  ~ 第 5 题 溯源（专著）著录缺：出版社、年份
  ~ 第 5 题溯源未含期刊论文（当前最优为专著），建议改引 CNKI 期刊论文（优先《中学语文教学》、《语文建设》）
  ~ ...
  + 全部通过（有溯源提醒，见上方 ~ 行）
```

**唯一绝对禁止**：编一个看起来很像的文献名。编造的溯源比没有溯源更糟，它是这套差异化方案的地基。

## 四、文献从哪来：edu MCP 的 mcp__<SERVER>__searchVectorBJ

文献检索**唯一入口**是 `mcp__<SERVER>__searchVectorBJ`。
早期文档里出现过的 `mcp__<SERVER>__searchLiteratureKnowledge` 在当前 edu MCP 中**不存在**（`ToolSearch` 精确查名无结果），
已登记在 `scripts/mcp_adapters.py` 的 `DEPRECATED_TOOLS` 里，别照抄。

### 接口只给一半字段

返回字段只有：`篇名 / 正文(摘要) / 小标题 / 文件名 / product / resource / 相关度 / 距离`。
**不含作者、刊名、卷、页码**。所以：

| 字段 | 从哪来 |
|---|---|
| 篇名 | 接口直接给 |
| 年份、期号 | 从 `文件名` 解析：刊码 + 年份 + 期号 + 序号（形如 `<刊码>+2023+10+004`，可解析出年份与期号） |
| 作者、刊名、卷、页码 | 接口不给 → 留 `None` → 渲染成灰色【待补充】，按篇名核实后回填 |

**文件名解析只对 `product=CJFD` 成立**。`CAPJ`（优先出版）的编码规则不同、期号不可信，一律不解析并标 `provisional:true`。

补齐流程：
1. `python scripts/mcp_adapters.py lit --raw raw_lit.json --out lit.json` 标准化，并打出体检报告（完整 / 待补 / 优先出版各几条）。
2. 按篇名核实真实作者与刊名，写成 `fill.json`（键为篇名）。
3. `... lit --raw raw_lit.json --out lit.json --fill fill.json` 回填。**只补空位**，不覆盖已有值。
4. 若外部核实的年份/期号与 CNKI 文件名解析值冲突，**保留文件名的值**并把分歧写进 `notes`——CNKI 自己的编码更可信。

## 五、拿不到 CNKI 文献时怎么降级

| 优先级 | 做法 |
|---|---|
| 1 | 把情境/材料题**改成无情境题**（纯计算/纯技能题不需溯源，校验器不拦） |
| 2 | `gen_cap=0`，全走题库，用 `Label` 试卷出处（如"（2025秋•嘉定区校级月考）"）替代学术溯源 |
| 3 | 保留情境题但标 `generic:true` 并在交付说明写"素材待核实"——**此路会被校验器拦**，必须同时改题 |

降级时用题库材料末尾**明写的**摘编出处作锚点（那些是真实的），不要凭印象补字段。

**绝不能用公开网络检索结果冒充 CNKI 文献**：换个检索入口只改变"谁说的"，不改变"能不能在 CNKI 定位"。
教师点溯源按钮是要跳回 CNKI 看原文的，跳不过去的溯源等于没有。
