>    - **零修正**（最常见）→ 写一行：`/* @@NO_CHANGE@@ */`
>    - **有修正** → 写：
>      ```
>      /* @@CHANGES_BEGIN@@ */
>      <<<OLD
>      <原片段：必须与代码逐字一致，且全文唯一>
>      OLD>>>
>      <<<NEW
>      <修正后的片段>
>      NEW>>>
>      （可多组，重复 OLD>>> / <<<NEW 结构）
>      /* @@CHANGES_END@@ */
>      ```

## ★ 0.1 构造方式校验（最优先）

| ★ 内核原样 | 内核函数**未自创同名函数**；产物中内核 `BEGIN→END` 之间**非空代码 313 行** | 数产物里内核段的非空行数；搜 `function ` 在 `LIB` IIFE **之外**有无重复定义。⚠️ **本步不比对逐字**——第3.5步正文不含内核正文（无从"对照"）；**逐字一致性由装配侧 `同步内联库.js --check` 机械校验，本步不重复** |

# ★ 第零步 0.10：语音可播性校验（v6.7 新增）

> **为什么需要这一步**：`voiceText` 是给 TTS（Web Speech API）播放的。TTS 引擎**只识汉字和字母**，遇到 `△`、`∠`、`⊥`、`∽` 等数学符号时，可能读成奇怪音、可能跳过、可能读成英文符号名（如 "triangle"）。**必须在 Step 2 就写成中文**，Step 3.5 再核对一遍。

## 0.10.1 检查项

| 检查项 | 通过标准 | 检测方法 |
|---|---|---|
| ★ **`voiceText` 无数学符号** | `questionData` 中所有 `subQuestions[*].stages[*].voiceText` 与 `stages[*].subSteps[*].voiceText` **不含任何数学符号** | 正则搜索 `/[\u25b3\u2220\u22a5\u2225\u223d\u224c\u00b0\u221a\u03c0\u2299\u00b1\u2260\u2265\u2264\u2234\u2235\u2208\u00b2\u00b3\u00d7\u00f7]/`——**命中即违规** |

> ★ **`$...$` LaTeX 公式是唯一例外（v6.7.1 新增，与第二步对齐）**
>
> `voiceText` 中 **`$...$` 包裹的 LaTeX 公式内部的符号，不算违规**——它们会在播放前被第四步的 `latexToSpeech` / `cleanVoiceText` 自动转成口语（`\frac{1}{2}` → "二分之一"）。
>
> **判定方法**：按上表各条正则搜索时，**先剔除所有 `$...$` 内部字符，再统计命中**；只对 `$...$` **之外**的残留符号判违规。
>
> **为什么必须写这条例外**：第二步明确允许在 `voiceText` 里写 `$...$`。若本步不承认这条例外，第二步合规写下的 `$a^2+b^2=c^2$` 就会被本步判违规并"打回 Step 2"，而 Step 2 改完仍然是合规的 `$...$`——**形成死循环**。**这条例外在第二步「数学公式的边界处理」小节已同步写明。**

## 0.10.4 常见问题与修正（v6.7 明确修复路径）

- **★ 问题：`voiceText` 中残留 `△`（或其他数学符号）** → **处理：打回 Step 2 重做**——让 Step 2 把 `voiceText` 全中文化。
  - **第 3.5 步自身不修 `questionData`**：第 3.5 步的产物是"修正后的绘图代码"，**不包含 `questionData`**；`voiceText` 属于 Step 2 的产出，**只能由 Step 2 修正**。
  - **若整条流水线由同一次 LLM 生成**（questionData 与绘图代码同源）：**打回整套重做**——让 Step 2 先全中文化 `voiceText`，再走后续步骤。
  - **若 questionData 与绘图代码分两次产出**：**只打回 Step 2 重做 `voiceText`**，绘图代码不必动。
  - **检查报告中必须明确写出**："发现问题项：voiceText 中残留 N 处数学符号（逐条列出位置）；处理建议：**打回 Step 2 重做**（本步不自行修改 questionData，因为它不在第 3.5 步的产物范围内）。"
- **问题：`voiceText` 中的方括号标记被删光了** → 修正：这是**反向错误**——标记必须保留。`[pause 2s]` 删除后会让停顿失效，语音变成连珠炮。**打回 Step 2 补回标记**。
- **问题：把 `description` / `solutionLine` 里的 `△` 也当成违规** → 修正：**这三类不是 `voiceText`，可以含符号**。判据是"这段文字会不会被 TTS 朗读"——`voiceText` 会，其他三类不会。

## 0.10.5 与第四步 `cleanVoiceText` 的接口

**第四步模板的 `cleanVoiceText` 是"第二道防线"**：

```javascript
function cleanVoiceText(text){
    if(!text)return '';
    let t=String(text);
    // 1) 去掉所有 [xxx] 方括号标记（[指令性] / [pause 2s] 等）
    t=t.replace(/\[[^\]]*\]/g,'');
    // 2) 把 $...$ 公式转为口语
    t=t.replace(/\$([^$]+)\$/g,function(m,tex){ return latexToSpeech(tex); });
    // 3) ★ 兜底：把可能残留的数学符号转为中文（覆盖约 20 个纯数学符号）
    t=t.replace(/Rt△/g,'直角三角形')  // ← 必须在 △ 之前
       .replace(/△/g,'三角形')
       .replace(/∠/g,'角')
       .replace(/⊙/g,'圆')
       .replace(/⊥/g,'垂直于')
       .replace(/∥/g,'平行于')
       .replace(/∽/g,'相似于')
       .replace(/≌/g,'全等于')
       .replace(/°/g,'度')
       .replace(/√/g,'根号')
       .replace(/π/g,'派')
       .replace(/²/g,'的平方')
       .replace(/³/g,'的立方');
    // 4) 压缩多余空白
    t=t.replace(/\s+/g,' ').trim();
    return t;
}
```

**检查点**：
- [ ] 第四步模板的 `cleanVoiceText` **是否包含**符号转中文的兜底替换？
- [ ] **`Rt△` 的替换是否放在 `△` 之前**？
- [ ] 第四步的 `latexToSpeech` 函数末尾**是否也包含同样的兜底替换**？
- [ ] **第四步兜底是否只覆盖纯数学符号**？（`=` `/` `+` `-` `(` `)` `α` `β` `θ` **不在**兜底范围，由 Step 2 保证）
