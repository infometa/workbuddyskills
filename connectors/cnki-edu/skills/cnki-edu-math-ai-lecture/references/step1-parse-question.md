# 工作流程（重要！按顺序执行）

## 第一步：读取图片内容（主要信息来源）
1. **识别题干文字**：从图片中 OCR 识别完整的题干文字
2. **识别图形信息**：
   - 几何题：识别图形中的点（A、B、C...）、线（AB、BC、AC...）、圆、角度、垂直/平行标记、相等标记、中点标记、切线等
   - 函数题：识别坐标轴、函数图像形状（抛物线/直线）、关键点坐标、交点等
   - 应用题：识别表格数据、图表信息等
3. **识别标注信息**：图形中的数值标注（如"AB=6"、"∠A=30°"、"半径=5"等）
4. **识别问题部分**：明确题目要求证明或求解的内容。**若题目包含多个小问（（1）（2）（3）或①②③），逐一识别每个小问的独立要求**

## 第二步：读取 JSON 数据（辅助验证）
1. 读取 `Content` 字段，与图片 OCR 结果**交叉验证**，确保题干提取准确
2. 读取 `Analyse` 和 `Method` 字段，理解解题思路和完整解答
3. 读取 `Discuss` 字段，了解重难点和易错点
4. 读取 `Points` / `Topics` 字段，确定题目类型（几何/代数/函数/应用/新定义）

## 第三步：整合与校对
1. 将图片识别的题干与 JSON 的 `Content` 字段进行比对
2. 如有不一致，优先采信图片 OCR 结果（因为图片是原始来源）
3. 用 JSON 中的解析和答案验证对题目的理解是否正确
4. **确认小问数量**：明确题目共几个小问，每个小问的目标是什么

## 第四步：拆解句子
将确认后的题干文字按规则拆分为 `sentences` 数组（**重点：遵循下方"多小问拆分规则"**）。

## 第五步：制作翻译器
提取关键条件，制作 `translations` 数组，**特别注意图片中的几何关系**。

# 详细拆分规则

## 一、sentences（句子数组）拆分规则

### 1.1 基础拆分规则

1. **拆分依据**：以句号（。）、分号（；）、问号（？）、感叹号（！）作为主要分隔符。
2. **保持完整**：如果一句话中有逗号（，）但表达的是一个完整条件，不要拆分。
3. **问题句**：题目最后的"求"或"问"句，单独作为一句。
4. **"如图"开头**：如果题干以"如图"开头，应单独成句或与第一句合并。
5. **图片信息**：结合图片内容理解题干中的图形描述（如"AB∥CD"、"∠ABC=90°"等）。

### 1.2 多小问拆分规则（新增，重要！）

**当题目包含多个小问（（1）（2）（3）或①②③）时，必须遵守：**

1. **识别小问**：先识别题目共有几个小问（依据标号"（1）（2）（3）"或"①②③"）。
2. **问题句独立成句**：每个小问的问题句**单独作为一个句子**，并**保留小问标号**在句子开头，例如：
   - `"（1）求证：BD=CD；"`
   - `"（2）若∠B=30°，AB=4，求AD的长。"`
3. **句子顺序固定**：**题干条件句在前、各小问按题目顺序在后**，不得打乱。顺序一旦确定，下游 Step 2 将按此顺序组织讲题方案。
4. **句数控制放宽**：
   - 单小问题：**3~6 句**
   - 多小问题：**4~12 句**（题干条件 2~4 句 + 每个小问 1~2 句）
   - 绝不允许为了凑句数把小问合并成一句。
5. **粒度对齐高亮（关键）**：不同小问**独占**的条件尽量独立成句；所有小问**共用**的条件（如"如图，△ABC 中，∠ACB=90°"）放在题干部分。这样 Step 2 才能清晰地按小问组织讲题方案。
6. **自包含完整**：如果某个小问的标号、条件、问题在语义上不可分割（如"（2）若CE=2，求BF的长"），则该小问可整体作为一个句子，但**必须保留标号**。

### 1.3 拆分质量自检

拆分完成后，问自己：
- [ ] 每个小问都能在 `sentences` 中定位到自己的问题句吗？
- [ ] 每个小问用到的主要条件句，是否与其他小问的条件句可区分？
- [ ] 句子顺序是否"题干在前、小问按序"？
- [ ] 没有漏掉任何小问或条件？

## 二、translations（翻译器数组）制作规则

1. **提取关键条件**：只提取题干中**涉及数量关系、几何关系、变量定义**的句子片段。
2. **原文一致**：`original` 字段必须是 `sentences` 中**真实存在的连续片段**——**逐字复制**，不得改写、不得跨句拼接、不得"凭印象重写"（句末标点可省略）。**这是本步最容易出错的地方**：一旦 `original` 在 `sentences` 中找不到，下游"数学语言翻译器"的对照就会错位，学生看到的是两段对不上的话。
3. **翻译精准**：`math` 字段用简洁的数学符号或文字表达该条件的数学含义。
   - 几何题：翻译为几何符号关系，如 `"BD = DC"`、`"∠AED = 90°"`
   - 函数题：翻译为代数式，如 `"y = x² - 4x + 3"`
   - 应用题：翻译为代数式或等式，如 `"售价 = 进价 × (1+40%)"`
4. **图片关系纳入**：从图片中识别出的关键几何关系（如"AB=6"、"∠A=30°"等）应体现在翻译器中。
5. **多小问标注（建议）**：若某条翻译只属于某个小问，可在 `math` 末尾用括号注明所属小问（如 `"CE=2（第2问条件）"`），方便下游核对；若为共用条件则不必标注。

## 示例：几何证明题（含图片 + JSON 数据，多小问）

**第一部分：用户上传的图片**
图片内容：一个等腰三角形 ABC，AB=AC，AD 为 BC 边上的高，D 为垂足；图中标注了顶点与垂足。

```json
{

1. 从图片中读取到：△ABC，AB=AC，AD⊥BC 于 D。
