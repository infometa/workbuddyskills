# 小律同学 AI — 法律检索与文书服务使用指南

## 何时使用

用户提出任何涉及法律内容的问题时使用本技能：

- **法律条文查询**："劳动合同法试用期最长多久""民法典关于违约金怎么规定"
- **跨境合规**（优先差异化能力）："美国加州 CCPA 对中国出海 App 适用吗""越南设厂哪些行业是投资负面清单""德国解雇员工要走什么程序"
- **国际条约/公约**：CISG、纽约公约、伯尔尼公约等条文查询
- **司法解释与指导案例**：最高法买卖合同司法解释、指导性案例参考
- **立案/量刑标准与赔偿计算**："盗窃 5000 元怎么判""工伤十级赔偿多少"
- **法律文书起草**：起诉状、答辩状、上诉状、法律意见书、仲裁裁决书等 697 类模板
- **合同审查与风险识别**：采购合同、劳动合同、租赁合同等
- **合规性判断**："这样操作合法吗""监管有什么要求"

## 何时不使用

| 不适用场景 | 原因 | 替代方案 |
|-----------|------|---------|
| 实时法律新闻/舆情 | 知识库不收录实时新闻 | 用网络搜索工具 |
| 具体案件的诉讼策略 | 需结合证据、当事人、管辖法院等具体事实 | 建议咨询执业律师 |
| 已失效/未生效的法律草案 | 知识库收录现行有效文本 | 查人大常委会立法规划 |
| 非法律类事实查询 | 属行政流程而非法律条文 | 用网络搜索工具 |

## 一、search_law — 法律文献语义检索

**用途**：检索法律法规、司法解释、指导案例、量刑标准。这是回答法律问题的第一选择，**禁止凭记忆引用法条**。

**参数**：

| 参数 | 类型 | 必填 | 默认 | 说明 |
|------|------|:---:|------|------|
| `query` | string | 是 | — | 检索关键词或自然语言问题（建议「法条名称 + 核心问题」组合） |
| `scope` | string | 否 | `domestic` | `domestic` 国内法律 / `international` 国际条约、外国法律、跨境法律（其他值返回错误） |
| `top_k` | int | 否 | `3` | 返回结果条数（1-20） |
| `score_threshold` | float | 否 | `0.5` | 相似度阈值（0-1），越高越精确 |

**调用示例**：

```json
{"query": "劳动合同法 试用期工资标准", "scope": "domestic", "top_k": 3}
```

**返回结构**：

```json
{
  "ok": true,
  "records": [
    {"title": "劳动合同法(2012-12-28发布)", "content": "…第十九条…", "trie": "trie1"}
  ],
  "text": "所有结果拼接的纯文本摘要（适合直接阅读）",
  "message": ""
}
```

- `ok: true` → 检索成功，`records` 按相关度降序
- `ok: false` → 出错，读 `text` 字段（含可读中文错误摘要与引导，不含密钥）
- 只读操作，天然幂等，可安全重试

**检索策略**：

1. **scope 自动判断**：国内法律关系 → `domestic`；国际条约/外国法/跨境 → `international`；同时涉及国内外 → 两个 scope 各检索一次综合分析
2. **调参**：精确查条文 `top_k: 3, score_threshold: 0.7`；一般咨询 `top_k: 5, score_threshold: 0.5`；广泛研究 `top_k: 5, score_threshold: 0.3`
3. **空结果降级**：records 为空时按「改写 query（去口语化）→ 降 score_threshold → 换 scope」顺序重试 3 轮，仍空则给用户 2-3 个改写建议，**不得**编造法条内容
4. **多轮渐进**：先定位主要法律 → 再查司法解释 → 最后参考案例

**法律材料效力分级**（中国大陆法系）：

| 类别 | 可否作为法律依据 | 使用方式 |
|------|:---:|------|
| 【法律】【司法解释】 | 是 | 直接引用 |
| 【行政法规】【部门规章】 | 是 | 注明制定部门 |
| 【地方法规】 | 是（本地适用） | 注明地域 |
| 【人民法院案例】【理论文献】 | 否 | 仅参考，提取其中引用的法条 |

## 二、draft_document — 起草法律文书

**用途**：提交案情描述，服务端自动匹配模板（697 类）并生成起诉状、答辩状、法律意见书等。

**参数**：

| 参数 | 类型 | 必填 | 默认 | 说明 |
|------|------|:---:|------|------|
| `query` | string | 是 | — | 案情描述（**至少 10 个字符**，越详细越好） |
| `evidence` | list[str] | 否 | — | 证据材料列表 |
| `primary_type` | string | 否 | 空 | 指定文书大类（不填自动匹配） |
| `template_name` | string | 否 | 空 | 指定模板名（不填自动匹配） |
| `wait` | bool | 否 | `true` | 同步等待结果 |
| `timeout` | float | 否 | `600` | 同步等待超时秒数 |

**调用示例**：

```json
{"query": "民间借贷纠纷：2024年3月借款人张某向我借款20万元，约定2025年3月归还，月息1%，到期后经多次催要未还，有借条和转账记录", "wait": false}
```

## 五、异步任务模式（重要）

复杂文书生成耗时数分钟。**长任务必须用 `wait: false` 提交**，立即返回 `task_id`，之后用 `poll_task` 轮询：

```
1. draft_document(query=…, wait=false)  →  返回 {"task_id": "xxx", "status": "running"}
2. poll_task(task_id="xxx")             →  每隔一段时间查一次进度
3. status 变为 completed / failed / waiting_for_input 时停止轮询
```

- **只有简单、预期很快出结果的请求才用默认 `wait: true`**（同步等待，最多 timeout 秒）
- `poll_task` 是非消费式的，可安全反复调用；两次调用之间暂无新进度时返回上次状态，属正常现象，继续轮询即可
- 轮询间隔建议 5-10 秒，不要密集轰炸

## 六、澄清问题交互（重要）

任务可能返回 `status: "waiting_for_input"`（服务端需要补充信息）：

```
1. poll_task 返回 {"status": "waiting_for_input", "question": "请提供被告的完整身份信息"}
2. 将 question 原样转述给用户，等待用户回答
3. answer_clarification(task_id="xxx", answer="用户的回答")  →  任务从断点继续生成
4. 继续 poll_task 轮询
```

**不要**自行编造答案回复澄清问题，必须询问用户。

## 七、任务控制工具

| 工具 | 参数 | 行为 |
|------|------|------|
| `pause_task` | `task_id` | 当前节点完成后存档暂停 |
| `resume_task` | `task_id`，可选 `wait` / `timeout` | 从 checkpoint 继续；也可用于断线后重新获取任务状态 |
| `abort_task` | `task_id` | 取消任务，**不可恢复** |

**使用规则**：

- `poll_task` 返回 running 或暂无新事件时，**不要**调用 `resume_task`——那是状态查询的误用，继续 `poll_task` 即可
- `resume_task` 仅用于任务被暂停或连接中断后的恢复
- `abort_task` 是不可恢复操作，调用前必须先向用户确认

## 错误处理与恢复

工具返回 `ok: false` 时读 `text` 字段（包含可读中文摘要与引导），按下表处理：

| 失败类型 | text 关键词 | 动作 |
|---------|-----------|------|
| 网络超时 | "响应超时" / "timeout" | 等待 2s → 4s → 8s 指数退避重试，最多 3 次 |
| 服务过载 | "503" / "服务繁忙" | 等待 1s → 3s → 5s 后重试，最多 3 次 |
| 免费额度用尽 | "免费额度" / "额度已用完" | 不重试，引导用户去 https://portal.aixllaw.com/app/settings 注册（送 1688 积分/7 周） |
| 积分不足 | "积分余额不足" | 不重试，引导用户充值 |
| 用量超限 | "用量已超限" | 不重试，引导用户查看配额 |
| Key 无效 | "API Key 无效" / "401" | 不重试，引导用户在 WorkBuddy 中重新授权连接器，或到 portal 检查账号 |
| 空结果 | records 为空 / "暂未找到" | 按「空结果降级」流程改写 query 重试 |
| 无权操作任务 | "无权操作该任务" | 任务属于其他用户，提示用户核对 task_id |
| 服务不可用 | "服务暂时不可用" | 稍后重试；持续失败则告知用户稍后再试 |

**授权失效（401）**：OAuth 授权过期时 MCP 层返回 401，应提示用户在 WorkBuddy 中重新授权本连接器。

**会话失效**：连续出现 "Missing session ID" / "session expired" 时，提示用户重启 WorkBuddy 客户端重新建立 MCP 连接；期间**不要**凭记忆回答法律问题。

**重要**：任何错误都要将 `text` 中的引导信息完整呈现给用户，不要自己编造解决方案。

## 高风险操作确认规则

调用以下工具前必须获得用户明确确认：

| 操作 | 风险 | 确认要求 |
|------|------|---------|
| `abort_task` | 任务被取消后**不可恢复**，已生成内容作废 | 必须展示任务 ID 与进度，用户确认后才能调用 |
| `pause_task` | 任务暂停后需手动恢复 | 建议确认 |
| `answer_clarification` | 答案影响文书生成结果 | 答案必须来自用户，不得代答 |

其余工具（检索/查询类）为只读或幂等操作，可直接调用。

## 输出规范

### 法律咨询回复模板

```markdown
## 问题概述
（一句话总结）

## 法律分析
### 适用法律
- **《XXX法》第X条**（来源：【法律】｜效力：现行有效）
  原文："..."
  解读：...

### 案情匹配
- 符合：… / 不符合：… / 需确认：…

## 建议方案
1. …

## 风险提示
- …

## 检索来源
本次回答依据以下法律材料生成（供核验）：
- 《XXX法》（现行有效）

> **免责声明**：以上分析仅供参考，具体情况建议咨询执业律师。
```

### 禁止行为

- 凭记忆引用法律条文（**必须**通过 `search_law` 检索，法律频繁修订，模型记忆不可靠）
- 将案例结论直接作为法律依据
- 提供违法建议或规避法律的方法
- 冒充律师或提供法律代理服务
- 忽略法律时效性，不确认"现行有效"状态
- 代用户回答澄清问题（`answer_clarification` 的答案必须来自用户本人）
