# Picset 风格复刻

将用户商品按一张风格参考图重新生成，每次产出一张图片。默认使用简体中文，不承诺像素级复制或完全还原文字与排版。

## 职责与边界

- **明确复刻意图优先于电商用途**：“复刻一张淘宝主图”走本能力，淘宝主图是用途要求，不改走普通电商或独立单图。
- “用商品图生成一张淘宝主图”没有明确复刻意图，交给 [电商套图 Skill](../picset-commerce-image-suite/SKILL.md)。生成数量不决定能力。
- 普通插画、换背景等编辑交给 [单图 Skill](../picset-single-image-generation/SKILL.md)。“参考这张图做设计”仍有歧义时，先问是保留参考风格复刻还是普通参考生成，不仅凭“参考”一词分流。
- 本能力需要 1 张风格参考图与 1–6 张商品图。素材缺失不改走其他生成工具；商品图数量不是出图数量。
- 复刻生成本身不依赖画布；**交付成功后必须按 [Agent Canvas 共享手册](../shared/agent-canvas-playbook.md) 打开 → 校验 → 缺图再 insert**，此时按手册解析宿主真实 `conversation_id`。替换特定旧图等其他画布操作交给 [Agent Canvas Skill](../picset-agent-canvas/SKILL.md)。
- 开始前读取 [公共交接协议](../shared/handoff-protocol.md)，沿用原商品事实、素材记录与共享偏好，不创建第二套状态。

工具参数、上传登记、轮询及交付细则见 [复刻共享手册](../shared/style-replicate-playbook.md)；费用授权见 [共享积分确认规则](../shared/credit-confirmation-playbook.md)。

## 渐进式首轮

- 没有素材：“请上传一张风格参考图和你的商品图（1–6 张），我会先整理复刻方案供你确认。”
- 只有明确的风格图：“请再上传你的商品图，我会以当前图片作为风格参考。”
- 已有两类素材：直接识别角色并展示方案；无法确定哪个是风格图时，只追问素材角色，不默认第一张就是风格图。
- 不一次性要求填写完整参数表；已提供的信息不重复询问。用户说“查看选项”时再展示模型、比例、分辨率和速度选项。

## 复刻方案

先用简短表格展示以下内容供修改与确认：

| 项目 | 内容 |
| --- | --- |
| 风格参考 | 用户指定的那张图及可见风格特征 |
| 商品素材 | 1–6 张商品图及对应主体，保持原商品事实 |
| 用途 | 如淘宝主图；未指定时不强加电商用途 |
| 保留方向 | 按用户意图描述构图、色调、背景、排版等参考方向，不承诺完全一致 |
| 调整内容 | 用户要求的商品替换、文案或其他调整；不得复制未经证实的商品卖点、认证或性能 |
| 出图规格 | 1 张；默认推荐 nova-2.0 / 2K / 1:1 / fast，用户指定且支持时优先采用 |

补充需求合并为 `requirements`，最多 4000 字符；用途和文案语言可写入该字段，不虚构 `image_type`、`target_language`、风格强度或保色参数。用户没有补充要求时允许空字符串。

## 执行流程

1. **检查与方案确认**：确定两类素材、用途、参考方向和实际规格；重复 OSS 对象、超限或角色不明时先处理，不静默删图。
2. **只读报价**：`quote_image_credits`，`count=1`，与生成使用一致的模型、分辨率、比例和速度，不走电商报价。
3. **费用确认**：展示最新报价及实时扣费说明，按共享偏好执行本次确认或已授权自动确认。
4. **余额校验**：调用 `get_user_credits`，`available_credits` 低于本次预估则打开充值面板并停止。见 [充值手册](../shared/connector-pricing-playbook.md)。
5. **上传登记**：余额足够后，对缺少已登记素材的本地图片复用公共上传器与 MCP 登记；保留角色和原素材记录，已有合法登记可复用。
6. **提交复刻**：`generate_style_replicate`，传风格图、商品图数组、要求、规格、`confirmed: true` 和保存的 UUID v4 `request_id`。
7. **静默查询**：保存 `task_id`（与 `job_id` 相同），使用 `get_generation_task_status` 查询，不用画布单图查询工具。
8. **结果交付**：成功后将 `items[0].image_url` 按 `R1` 等稳定编号安全下载，通过 `present_files` 展示。
9. **画布自动承接**：有成功图时，按 [Agent Canvas 共享手册](../shared/agent-canvas-playbook.md) **打开 → 校验 → 缺图再 insert**；不等待用户要求。须先按手册解析宿主 `conversation_id`；解析失败时跳过并说明。

## 修改与恢复

- 新增独立复刻任务用下一个从未使用的 `R` 编号；用户修改或重新生成某张时保留原编号，使用新的任务目录，不覆盖历史文件。
- 提交中断、结果不明：原参数与 `request_id` 不变，已获得任务 ID 时先查询；不能自动换 ID 补单。
- 已经终态失败：同 ID 重放只返回原任务，不会启动一次新的生成。用户明确要求重新生成时，重新确认方案、报价和授权，再用新 ID 提交。
- 修改提示词、参考素材或规格属于新请求，不把新参数绑到旧幂等键。
- 超时保留原任务，后续恢复查询；不为了继续对话而新建任务。

## 结果与异常

- 成功：按真实编号告知“已生成 R1（1/1 成功）”；提交响应可确认的费用可注明“提交时返回扣费 X 积分”，不把幂等重放金额重复累计。成功交付后须已自动打开画布（或已说明无法打开的原因）。
- 失败：如实说明错误并提供用户主动重新生成入口，不展示失败图片、不宣称退款已到账；失败不打开画布。
- 下载失败：说明生成成功但本地交付未完成，保留 URL/任务记录用于重新下载，不重新生图收费；未完成交付时不强制打开画布。
- 积分不足：生成前余额不足或提交/执行返回不足时，立即停止后续上传、生成与轮询，立即调用 `open_agent_pricing`，不以询问代替调用，不展示充值 URL/ticket。见 [充值手册](../shared/connector-pricing-playbook.md)。
- 工具不可用、鉴权失败、素材未授权：报告实际阻塞，不回退到电商或单图冒充复刻。

## MCP 工具速查

| 工具 | 用途 |
| --- | --- |
| `quote_image_credits` | 单张复刻的物理规格报价，只读 |
| `get_user_credits` | 查询可用积分余额 |
| `get_reference_image_upload_token` | 本地素材上传凭证 |
| `register_reference_image` | 登记已上传素材 |
| `generate_style_replicate` | 提交一次风格复刻 |
| `get_generation_task_status` | 查询复刻任务及一张结果 |
| `open_agent_canvas` | 交付成功后打开/复用画布 Panel（无 `initial_images`） |
| `get_agent_canvas_state` | 校验画布是否已有本批图 |
| `insert_agent_canvas_image` | 校验缺图时兜底插入；或用户明确要求放入未推送图 |
| `open_agent_pricing` | 打开连接器统一充值面板 |

调用前必须 `tool_search` 获取当前工具完整定义。对外工具名以运行时返回为准，不调用旧的专属复刻报价名或自行创造工具。
