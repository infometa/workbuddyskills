# 财务审核规则查询与选择

只读查看企业规则或询问“有哪些可调整，先不要修改”也使用本流程：查询企业规则后，只基于 Tool 实际返回的可见规则说明可调整项和建议，不臆造企业制度，不执行持久修改、发布或自动审核。

## 连接器与 OAuth

关联 `sealai-finance` Connector。初始化连接及查询规则前，如未连接则引导用户通过 SealAI OAuth 登录、选择企业并确认授权。跨行业通用规则本身是公开内容，但通过此 Connector 查询仍需授权；匿名访问仅由独立 public 入口提供。不得要求用户在对话中提供访问令牌。

## 规则来源

- **企业规则**：调用 `financial_audit_prepare` 查询已绑定或最新发布的企业规则；企业规则可用且用户未指定其他来源时，默认采用该版本。
- **跨行业通用规则**：调用 `finance_public_general_rules`，完整展示 SealAI 通用规则和免责声明。
- **行业参考规则**：先调用 `financial_audit_industry_catalog`，再按行业调用 `financial_audit_industry_rule_prepare`，完整展示规则正文、固定参数、建议关注等级、建议凭据和免责声明。行业规则只读，不得改写参数或正文；建议凭据允许可核验的等效材料，个人信息遵循最小必要和脱敏原则。
- **本次临时规则**：接收用户提供的 1–30 条规则，只用于当前审核任务。

## 选择流程

1. 用户明确指定企业、跨行业通用、行业参考或临时规则时，直接查询对应来源，不再询问其他来源。
2. 用户只说“通用规则”而未说明范围时，询问一次要查看跨行业通用规则还是行业参考规则；选择行业参考规则后再询问行业。用户已经提供行业信息时不得重复询问。
3. 用户未指定规则来源、且是在为后续审核选规则时，先调用 `financial_audit_prepare`。企业规则可用时采用返回版本；没有可用企业规则时，让用户在跨行业通用、行业参考和本次临时规则之间选择。
4. 行业不明确时，只询问一次，并列出当前支持的行业。无法匹配时不得擅自归类，应建议使用跨行业通用规则或提供本次临时规则。
5. 查询整个行业时展示完整规则包；用户明确限定费用场景时才筛选对应规则，不得根据推测的常用程度省略规则。
6. 用户选用行业规则时，必须先展示所选规则的完整正文和固定参数，并取得用户对本次所选规则的明确确认；确认前不得启动审核。
7. 用户要求修改任一行业规则时，不得调用行业规则覆盖参数，也不得继续标记为行业来源。应将本次所选规则复制为 1–30 条完整的临时规则，仅修改用户明确指定的内容，标明“已转换为本次临时规则”，展示完整临时规则并再次取得确认。后续使用 `type=custom` 和 `rules`，仅形成任务快照，不保存到行业规则包。
8. 返回安装引导、配置异常、超时或 429 时停止，不编造规则或静默切换来源。

本流程只查询和准备规则来源，不调用 `financial_audit_start`、`financial_audit_status` 或 `financial_audit_comment_writeback`。未修改的行业规则保留规则包 `reference` 和所选规则 ID；由行业规则转换出的临时规则传递完整规则数组，交给对应审核流程。
