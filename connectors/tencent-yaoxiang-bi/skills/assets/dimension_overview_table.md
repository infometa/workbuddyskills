## 两个层面 × 九大维度

### 层面 1 · 整体市场规模和药箱用户分析（共 5 维度）

| 维度 | 时间范围 | 网络数据 | 所需字段（从数据表中提取） |
|---|---|---|---|
| **1.1** 市场规模和药箱用户规模 | 用户查询时间总计 | 全年销量、行业及市场规模走势、企业动态、市场份额占比、销售渠道、患者基数、竞争预警 | ① 用户总计：访问人数、访问次数、深度访问次数<br>② 扫码总计：扫码人数、扫码次数、新用户占比<br>③ 二次扫码人数（非当天）<br>④ 首次-末次扫码时间间隔 |
| **1.2** 皮度量趋势 | 用户查询时间按月堆叠 | 按季度/月度的销量情况 | ① 用户总计：访问次数、访问人数（按月）<br>② 扫码总计：扫码次数、扫码人数（按月） |
| **1.3** Sku 销量和药箱用户扫码分布 | 用户查询时间总计 | 市场各规模销量数据 | ① 扫码药品分析：扫码次数、扫码人数（按 Sku） |
| **1.4** 地域销量和药箱用户地域分布 | 用户查询时间总计 | 市场各区域销量表现 | ① 用户省市分布：省份、城市、访问次数、访问人数 |
| **1.5** 竞品规模和药箱扫描关联用药分析 | 用户查询时间总计 | 竞品市场规模 | 关联药品扫描情况：<br>① top10 病种类及访问人数、占比<br>② top7 同类药品及访问人数、占比<br>③ top7 所有药品及对应人数、占比 |

## 字段提取顺序建议

```
1. 优先提取 1.1 的基础 4 字段（访问人数/次数 + 扫码人数/次数）→ 作为 hero 4 指标数据源
2. 接着 1.1 的派生字段（新用户占比 / 二次扫码 / 首次-末次间隔）
3. 1.2 按月堆叠数据 → 月度趋势
4. 1.3 / 1.4 / 1.5 分别取扫码药品 / 地域 / 关联数据
5. 2.1 用户画像 → 性别 / 年龄 / 地域
6. 2.2 功能使用 → 点击次数 / 人数
7. 2.3 科普 → 用户访问 + 内容 + 文章
8. 2.4 用药打卡 → 8 个子字段 + Top20 用户
```

## 网络数据 vs 产品数据分隔线

| 维度 | 网络数据范围 | 产品数据范围 |
|---|---|---|
| 1.1 市场规模 / 用户规模 | 必须按用户给定时间范围过滤（整年/整月） | 用户原始数据产品部分 |
| 1.2 皮度量趋势 | 按季/月公开市场销量 | 药箱产品月度数据 |
| 1.3 Sku 销量 | 市场规模数据 | 扫码药品分析（按 Sku） |
| 1.4 地域销量 | 区域销量表现 | 用户省市分布 |
| 1.5 竞品 | 竞品市场规模 | 关联药品扫描记录 |
| 2.1 人群画像 | — | 用户画像 |
| 2.2 功能使用 | — | 功能点击次数 / 人数 |
| 2.3 科普访问 | — | 内容访问 + 文章访问 |
| 2.4 用药打卡 | — | 8 子字段 + Top20 用户 |
