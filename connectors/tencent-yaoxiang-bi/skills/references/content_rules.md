# 内容写作规则（中性客观 · 字数 · 缺失处理）

> 本文件定义 `药箱药企数据洞察` 报告的所有文字内容（洞察 / 策略 / 结论）的写作规范。每次生成报告前过一遍。

---

## 1. 字数硬性约束（写死）

> 本 skill 文字产出已从「30~80 字」放宽，鼓励写得更具体、更详细，但**放宽 ≠ 堆砌**——每个数据点必须可追溯，形容词要少、数据事实要多。

| 内容类型 | 字数范围 | 注意事项 |
|---|---|---|
| **洞察** | 每条 **50~150 字** | 多条用 ① ② ③ 列点式，尽量覆盖「量级 / 结构 / 趋势 / 对比」四要素 |
| **策略（企业 / 药箱双侧各算）** | 每条 **60~200 字** | 企业侧与药箱侧各独立列点；药箱侧因需关联「功能 → 用户价值 → 药企价值 → 升级预期效果」完整链条，可自然偏长（80~200 字） |
| **结论** | 每维度 **20~40 字** | 一句话 = 洞察结论 + 策略方向，只写方向性词不展开具体数字 |

> **低于下限视为过简**：单纯「用户较多」这类一句式写法不允许，至少覆盖「数字 + 量级 + 趋势 / 对比」。
> **高于上限视为冗余**：超过上限时收敛形容词与重复表述，只保留数据事实、动作、量化目标与预期效果。
> **参考刻度**：洞察取 80~120 字为最佳区间（四要素齐全但不啰嗦）；策略取 100~160 字为最佳区间（药箱侧可到 180 字）。

---

## 2. 洞察 — 中性客观禁情感词（写死）

### 2.1 强制语气 = 陈述事实 / 量级 / 结构 / 趋势 / 对比

**✅ 合规写法**：
- 「扫码 5.8 万次，月环比 +34%」
- 「老客回扫占比由 7.8% 升至 15%，呈持续上行」
- 「Top3 药品合计扫码占比 58%，集中度较高」
- 「30-39 岁用户占比 41.7%，构成核心人群」
- 「用药提醒弹窗曝光 12.4 万次，icon 点击率 8.2%」

**❌ 不合规写法**：

| 禁词 | 替代写法（陈述事实） |
|---|---|
| 表现优异 | 同比 / 环比 +X% |
| 令人担忧 | X 指标下滑 / 低于均值 Y% |
| 效果显著 | X 绝对值达 N / 增长 X% |
| 明显偏低 | 占比 X%，低于 Top10 均值 Y 个百分点 |
| 值得期待 | 渗透率由 X% 升至 Y% |
| 令人欣慰 | 月环比已连续 3 个月为正 |
| 强势领跑 | 市场份额 X%，排名第 N |
| 远超同行 | 高于 Y 平均 X 个百分点 |

### 2.2 洞察结构公式（写死，四要素尽量齐全）

```
① 量级（绝对数值 + 单位）→ ② 结构 / 分布（谁占主导、构成如何）→ ③ 趋势（环比 / 同比 / 时间轴变化）→ ④ 对比 / 交叉（与同类、与上月、与均值、与另一人群）
```

**完整示例（约 120 字）**：

```
「30 天内累计扫码 23 万次，月环比稳定在 +5%~+15%；其中老客回扫占比由 7.8% 升至 15%，二次扫码渗透持续加深，且回扫老客的打卡频次约为首次扫码用户的 1.4 倍，老客复用价值高于新客拉新。」
```

**写法要点**：

- 单一维度数据单薄时，把 ①②③ 写全即可，不强凑 ④。
- 多维度数据可交叉时，尽量补 ④⑤ 交叉关联（如「深读用户比未读用户打卡频次高 X 倍」「30-39 岁主力人群同时是复购订阅的主要客群」），让洞察更立体。
- 每个数据点标注可回查的维度 / 字段来源，不写无据的推断。
- 同一条洞察内数字控制在 2~4 个，避免堆数字；趋势与对比优先于绝对值罗列。

## 3. 缺失数据处理（写死）

### 3.1 产品数据缺失（用户原始数据表无该字段）

| 缺失情况 | 处理 |
|---|---|
| 整个维度无字段 | **该小节完全不展示**（连标题都不要写），后续维度序号顺延 |
| 维度有字段但部分为空 | 空字段处留空 / 加 N/A 表格行，并在综合洞察里备注「xx 字段本期未覆盖」 |
| 字段存在但全部为 0 | 仍展示数据（0 也是数据），但不再单独写洞察 |

### 3.2 网络数据缺失（公开渠道查不到）

**固定话术（写死，逐字输出）**：

```
暂未在公开渠道查询到 [具体内容] 数据，可直接补充真实数据报告进行分析
```

| 缺失情况 | 处理 |
|---|---|
| 整个维度无网络数据（1.1 是唯一有网络数据的维度，其他维度不一定查） | 在综合洞察里备注，并在该维度末尾的「数据来源」备注缺失 |
| 1.1 内的某小节查不到（份额 / 渠道 / 竞争预警） | 在 1.1 该子小节后写一行「暂未在公开渠道查询到 XX 数据，可直接补充真实数据报告进行分析」 |

### 3.3 时间范围过滤（写死）

网络数据必须按用户给定时间范围过滤：

| 用户问法 | 网络数据范围 |
|---|---|
| 「2025 全年」 | 仅保留 2025 年 1 月—12 月的全年数据，其他时间不算 |
| 「2025-06」 | 仅保留 2025 年 6 月月度数据 |
| 「最近半年」「近一年」 | ❌ 不接受，必须追问整年/整月 |
| 未给时间 | **默认全部时间范围**（对应原始数据表当前表单全部时间，不追问），网络数据按同一默认口径过滤 |

## 4. 策略 — 双侧分组（写死）

### 4.1 分组结构

```
策略
├── 企业侧（3~5 条）
│   ├── 基于洞察发现（点明洞察中的具体问题）
│   ├── 渠道 / 内容 / 数据动作（线下终端 / 私域社群 / 精准营销 / 患教内容 / 店员话术）
│   ├── 量化目标（具体到客群 %、终端数、复购率等）
│   └── 预期业务效果
└── 药箱侧（3~5 条）
    ├── 功能选择（从《药箱产品功能明细表》选 ≥ 1 项，写真实功能名）
    ├── 用户价值（取自明细表「用户价值」列）
    ├── 药企价值（取自明细表「药企价值」列）
    └── 升级预期效果（结合「版本归属」列：基础版→专业版→企业版→定制版/增值服务）
```

### 4.2 药箱侧策略公式（写死，关联《药箱产品功能明细表》）

每条药箱侧策略**必须回查《药箱产品功能明细表.xlsx》原件**，按「功能 → 用户价值 → 药企价值 → 升级预期效果」四段完整展开：

```
[功能名（明细表内真实功能）] → [用户价值（明细表「用户价值」列）] → [药企价值（明细表「药企价值」列）] → [升级预期效果（结合「版本归属」列：基础版→专业版→企业版→定制版/增值服务）]
```

**示例**：

| ❌ 错误 | ✅ 正确（关联明细表） |
|---|---|
| 「做好患者教育」 | 「接入『用药提醒 + 复诊续方提醒』功能：帮患者简化设置、降低漏服并按时续方（用户价值），提升用药依从性、减少脱落并拉动复购（药企价值）；建议由基础版升级至专业版，获取打卡与复购数据看板（升级预期效果）」 |
| 「加强私域运营」 | 「开通『企业私域客服』：扫码即添加品牌客服获得个性化服务（用户价值），沉淀精准患者支撑长期复购（药企价值）；建议升级企业版，实现个体化私域触达与复购闭环（升级预期效果）」 |

> **价值与预期效果均取自明细表原文**，不自己编造；引用时保留「用户价值 / 药企价值」两列的原意，再落到「版本归属」列对应的升级方向。

### 4.3 药箱侧策略硬性要求

每条药箱侧策略必须：
- 含可回查的功能名（来自《药箱产品功能明细表.xlsx》，可回溯「分类 → 功能名称」）
- 含「用户价值 → 药企价值」双价值（取自明细表「用户价值」「药企价值」两列原意）
- 含「升级预期效果」（结合明细表「版本归属」列，引导基础版→专业版→企业版→定制版/增值服务升级）
- 描述要具体到「这个功能怎么落地、解决什么、带来什么变化」，禁用「加强 / 做好」类泛词

## 5. 结论 — 20~40 字方向性词（写死）

### 5.1 结论公式

```
[核心洞察结论 10~20 字] + [策略方向性总结 10~20 字] = 20~40 字
```

### 5.2 禁词与必备词

| 必须 | 禁止 |
|---|---|
| 方向性词（渗透 / 下沉 / 上行 / 集中 / 分布 / 增强） | 具体销售额、用户数、百分比 |
| 行为模式（复访 / 探索 / 转化 / 留存） | 时间范围数字（除非要强调「长期」「短期」） |
| 一句话能独立读懂 | 行业对比词（已超字数边界） |

### 5.3 示例（每个示例 30 字左右）

- 「扫码对新药探索度较高，老客回扫深度持续上行；建议企业侧聚焦同患教复购，药箱侧推送服药提醒并引导私域转化。」
- 「功能渗透集中在打卡与提醒，弹窗曝光转确认率有提升空间；建议企业侧优化首条话术，药箱侧升级打卡奖励并引导增值包。」
- 「Top3 Sku 集中度较高，男性用户占比突出；建议企业侧聚焦头部 Sku 与男性患教，药箱侧强化相关科普卡片落地。」
