# 数据获取层映射（仅 AI 内部使用 · 禁止出现在用户可见内容）

> 本文件是 `药箱药企数据洞察` 的**数据获取层**内部映射。所有真实标识符（MCP 名、接口名、表名、字段名）只在本文件与 SKILL.md 内部推理中使用，**绝不允许**进入对用户的回复、HTML 报告正文、信源清单或任何可见文案。
>
> 对用户一律用业务语言表述：访问量/访问人数/扫码人数/扫码次数/新用户占比/内容访问/科普阅读/点击率等。

## 0. 数据通道（内部）

- 数据统一经由 **eyao 数据网关** 的只读查询接口（`query_table`）拉取。
- 该接口为只读通道，服务端按调用方权限组强制隔离数据，AI 无法指定或绕过隔离维度。
- 入参：`schema_id`（结果表名）、`filter_conditions`（业务筛选，操作符限 `= != > >= < <= in`）、`order_by`、`desc`、`page`、`size`。
- `filter_conditions` 中**不要**传入隔离维度（权限组字段会被服务端忽略）。
- **日期粒度切换**：默认返回「统计周期聚合（年去重）」行；传入 `{"field":"f_date_type","op":"=","value":"月"}` 可切换为**月度粒度**。
  - ⚠️ **当前数据状态（含测试表）**：月度粒度当前**仅 2026-08 一个月份有明细行**，1–7 月无月度行（测试表仅铺设了 8 月数据，属正常状态，非异常缺失）。验证方式：加 `{"field":"f_start_date","op":">=","value":20260101}` 过滤，若仍只回最新月即确认。
  - 因此「逐月趋势线」暂不可得，只能呈现**最新月份快照**（最新月 vs 年度月均对比）。待数据补齐历史月度后，本映射与报告 1.2 节会自动扩展为完整趋势，无需改骨架。

### 可查表发现方式（重要）

接口对未授权表名会返回 `可选: [...]` 白名单。若不确定当前有哪些表，可先带一个猜测的 `schema_id` 试查，从报错里的 `可选` 列表读取当前可用表名，再正式查询。**不要把这次试探的报错内容展示给用户。**

> ⚠️ **红线（与 SKILL.md 连通性闸门一致）**：若本会话未注入数据查询工具（未连接 / 未授权 / 调用报错），**直接告知用户「需要授权 BI 数据 MCP」并停止**；严禁长篇解释平台形态、严禁引导用户上传 Excel/CSV 等常规数据、严禁改用知识库或其他数据源替代取数、严禁臆造数据。用户可上传的仅有画像数据，且仅在成功路径中作为"补充更多维度"的提示。

## 1. 已确认可查表 → 业务指标映射

当前白名单内结果表（品牌访问结果表）字段与 9 维度业务指标映射如下：

| 业务指标（对用户可见的叫法） | 网关字段 | 说明 |
|---|---|---|
| 统计周期标签 / 口径 | `f_date`（如 `20260101~20260831`）、`f_date_type`、`f_start_date`、`f_end_date` | 数据覆盖窗口；用于时间范围校验 |
| 企业（权限组） | `f_group_code`、`f_group_name` | 用于竞品对比、跨企业聚合 |
| 品牌（药品） | `f_brand_name` | 主筛选键，对应用户输入的药品名 |
| 访问人数 | `f_uv` | 去重用户数 |
| 访问次数 | `f_pv` | 页面访问量 |
| 品牌新访问用户 | `f_brand_new_visit_users` | 周期内首次访问该品牌的用户 |
| 访问频次 | `f_vist_frequency` | 人均访问次数 |
| 扫码人数 | `f_scan_uv` | 去重扫码用户 |
| 扫码次数 | `f_scan_pv` | 扫码量 |
| 新用户扫码人数 / 次数 | `f_scan_new_uv` / `f_scan_new_pv` | 首次扫码用户 |
| 老用户回扫人数 / 次数 | `f_scan_old_uv` / `f_scan_old_pv` | 非首次扫码（老客回扫） |
| 新用户扫码占比 | `f_scan_new_ratio` | 新客 / 扫码人数 |
| 二次使用（非当天回扫）次数 / 人数 | `f_secondary_use_pv` / `f_secondary_use_uv` | 次日及以后的复用 |
| 内容访问次数 / 人数 | `f_content_cnt` / `f_content_users` | 药箱内容消费 |
| 内容渗透率 | `f_content_ratio` | 内容访问人数 / 访问人数 |
| 人均内容次数 | `f_content_cnt_per_user` | 内容消费量 |
| 科普文章数 | `f_doc_visit_articles` | 被访问的科普文章数 |
| 科普访问次数 / 人数 | `f_doc_visit_cnt` / `f_doc_visit_users` | 科普内容阅读 |
| 点击次数 | `f_click_pv` | 整体点击量 |
| 点击率 | `f_click_rate` | 点击 / 访问 |

## 2. 9 维度 → 网关覆盖判定（缺失即按 L1 跳过）

| 维度 | 网关是否可支撑 | 取数方式 |
|---|---|---|
| 1.1 市场规模和药箱用户规模 | ✅ 可 | 按 `f_brand_name` 过滤取品牌行：UV/PV/扫码/新客占比/二次使用/频次 |
| 1.2 度量量趋势（按月） | ⚠️ 部分 | 月度粒度（`f_date_type='月'`）当前仅返回最新月份快照（如 2026-08），可呈现「最新月份私域表现 + 与年度月均对比」；完整逐月趋势线待平台开放历史月度后扩展 |
| 1.3 Sku 销量和扫码分布 | ❌ 缺 | 网关为品牌级，无 Sku 明细 → 按 L1 不展示 |
| 1.4 地域销量和用户地域分布 | ❌ 缺 | 网关无省/市字段 → 按 L1 不展示 |
| 1.5 竞品规模和关联用药分析 | ⚠️ 部分 | 仅品牌级竞品对比：拉取同品类多家 `f_group_name` 的 PV/扫码做对比；**无**跨用户 uin 的疾病关联明细 → 关联用药子节按 L1 不展示，仅留品牌竞品对比 |
| 2.1 药箱人群画像 | ❌ 缺 | 网关无性别/年龄/地域字段 → 按 L1 不展示 |
| 2.2 药箱功能使用整体情况 | ❌ 缺 | 网关无单功能点击明细 → 按 L1 不展示 |
| 2.3 药箱科普访问情况 | ✅ 可 | `f_content_*` + `f_doc_visit_*` 直接取 |
| 2.4 药箱用药打卡情况 | ❌ 缺 | 网关无打卡/提醒明细 → 按 L1 不展示 |

> 结论：当前网关实际可产出 **1.1 / 1.2（最新月份快照）/ 1.5（品牌竞品对比部分）/ 2.3** 四个维度；其余维度按「缺失即不展示」处理，并在综合洞察里备注（见内容规则固定话术）。1.2 因月度粒度仅含最新月份，仅以快照呈现，完整逐月趋势待平台开放历史月度后自动扩展。后续网关若开放更多表，按第 0 节「可查表发现方式」补充映射即可。

## 3. 取数调用范例（内部，不展示）

单品牌查询：
```
query_table(schema_id=<品牌访问结果表>, filter_conditions=[{"field":"f_brand_name","op":"=","value":"<用户输入的药品名>"}], size=50)
```

竞品对比（同企业多条品牌）：
```
query_table(schema_id=<同表>, filter_conditions=[{"field":"f_group_name","op":"=","value":"<企业名>"}], size=50)
```

月度粒度查询（最新月份快照，⚠️ 历史月份可能未回灌，仅返回最新月）：
```
query_table(schema_id=<同表>, filter_conditions=[{"field":"f_brand_name","op":"=","value":"<药品名>"},{"field":"f_date_type","op":"=","value":"月"}], size=50)
```

时间范围校验：读取返回行的 `f_start_date`/`f_end_date`（或 `f_date` 标签），判断用户请求的整年/整月是否落在覆盖窗口内；不在窗口内 → 触发「范围无数据」兜底。

授权（品牌）校验：对用户输入药品名执行单品牌查询；若返回 0 行（且非拼写误差）→ 触发「未在当前企业授权列表」兜底。

> 注意：查询结果里的真实字段名只用于 AI 内部计算与映射；**写进报告/回复时必须全部转成业务语言**，不得出现 `f_` 前缀字段名、表名或接口名。
