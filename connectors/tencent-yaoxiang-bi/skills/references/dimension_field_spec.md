# 9 维度字段提取规范（两个层面九大维度）

> 本文件是 `药箱药企数据洞察` 的**最核心字段映射表**。每次接到用户原始数据后，必须按本表逐维度精确取数；缺数据的维度直接不展示。

## 概览图（两个层面 × 九大维度）

```
┌─────────────────────────────────────────┬────────────────────────────────────┐
│  整体市场规模和药箱用户分析（5 维度）    │   药箱功能使用分析（4 维度）        │
├─────────────────────────────────────────┼────────────────────────────────────┤
│  1.1 市场规模和药箱用户规模              │   2.1 药箱人群画像                  │
│  1.2 皮度量趋势                          │   2.2 药箱功能使用整体情况          │
│  1.3 Sku 销量和药箱用户扫码分布          │   2.3 药箱科普访问情况              │
│  1.4 地域销量和药箱用户地域分布          │   2.4 药箱用药打卡情况              │
│  1.5 竞品规模和药箱扫描关联用药分析      │                                    │
└─────────────────────────────────────────┴────────────────────────────────────┘
```

> **缺失即不展示**：若用户原始数据表无 1.3 的 Sku 字段，则整个 1.3 小节不展示；后续 1.4 自动变为「1.3 地域销量和药箱用户地域分布」（2.x 段单独连续计数，互不影响）。

## 1.1 市场规模和药箱用户规模

| 项 | 内容 |
|---|---|
| **时间范围** | 用户查询时间总计（半年/全年聚合） |
| **网络数据** | 全年销量、行业及市场规模走势、企业动态、市场份额占比、销售渠道、患者基数、竞争预警 |
| **数据源标注** | 每个网络数据点必须可追溯到：米内网 / 中康 CMH / 上海医药年报 / 国家心血管病中心 / IQVIA / 灼识咨询 / 弗若斯特沙利文 等公开渠道，附 URL |

### 所需字段（从用户原始数据表提取）

| 序号 | 字段路径 | 字段定义 |
|---|---|---|
| 1-1-1 | 用户分析 → 用户总计 | 访问人数（UV） |
| 1-1-2 | 用户分析 → 用户总计 | 访问次数（PV） |
| 1-1-3 | 用户分析 → 用户总计 | 深度访问次数（停留 > 60s） |
| 1-1-4 | 扫码分析 → 扫码用户总计 | 扫码人数 |
| 1-1-5 | 扫码分析 → 扫码用户总计 | 扫码次数 |
| 1-1-6 | 扫码分析 → 扫码用户总计 | 新用户占比（新用户数 / 扫码人数） |
| 1-1-7 | 二次扫码人数 | 非当天扫码的二次扫码（次日及以后） |
| 1-1-8 | 首次-末次扫码时间间隔 | 用户首次扫码到最后一次扫码的平均天数 |

## 1.5 竞品规模和药箱扫描关联用药分析

| 项 | 内容 |
|---|---|
| **时间范围** | 用户查询时间总计 |
| **网络数据** | 竞品市场规模（公开） |

### 所需字段

> 数据来源说明：根据该药品的「用户uin」查询该用户**其他药品**的扫码记录（药品gtin）。即「用户扫了 A，又扫了哪些其他药」。

| 序号 | 字段路径 | 字段定义 |
|---|---|---|
| 1-5-1 | 所有 qtn → 搜索病种类分类 | top10 病种类 + 访问人数 + 占比 |
| 1-5-2 | 所有 qtn → 按访问人数排名 | top7 同类药品 + 访问人数 + 占比 |
| 1-5-3 | 所有 qtn → 按访问人数排名 | top7 **所有**药品 + 对应人数 + 占比 |

> **可视化**：双表 / 双柱状图（同类竞品 vs 全品类对比）

## 字段完整性校验（写死）

| 检查项 | 命令 / 方法 | 不通过处理 |
|---|---|---|
| 原始数据表每个 sheet 表头已对齐字段名 | 人工对照 | 缺字段则跳过该维度 |
| 9 个维度都尝试过提取 | `grep` 维度块 | 缺失维度不展示 |
| 网络数据每个点有 URL | 人工对照 | 加信源 URL / 改成备注 |
