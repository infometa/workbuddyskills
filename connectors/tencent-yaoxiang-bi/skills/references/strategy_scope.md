# 双侧策略范围 · 企业侧 vs 药箱侧

> 本文件定义 `药箱药企数据洞察` 报告中「策略建议」两侧执行主体的工作边界与典型动作。新报告生成策略时，必须先看本文件确认动作落点。

---

## 总览

| 主体 | 资源能力 | 动作边界 |
|---|---|---|
| **企业侧** | 销量数据、铺货、终端、店员、自有社群 | 依托自有数据 + 自有渠道能直接执行的动作；或与药箱协同规划 |
| **药箱侧** | 腾讯健康药箱小程序 + Agent + 功能矩阵 + 私域 | 帮助企业私域做进一步优化；功能迭代 + 内容运营 + 留存复购 + 商业化引导 |

---

## 一、企业侧（3~5 条）

### 资源池

| 资源 | 描述 |
|---|---|
| **线下终端** | 药店 / 医院 / 互联网医院渠道铺设 |
| **私域社群** | 企业自营公众号 / 视频号 / 企微社群 |
| **精准营销** | DTP / 患者关爱中心 / 复购提醒 |
| **终端物料** | 易拉宝 / 桌牌 / 海报 / 扫码有礼 |
| **店员话术** | 店员培训手册 / 提及规范 / 推荐话术 |

### 企业侧策略公式（写死）

每条企业侧策略按「发现 → 动作 → 量化目标 → 预期效果」四段完整展开，避免只写「做好 / 加强」类泛词：

```
[基于洞察发现 X] → [渠道 / 内容 / 数据动作（线下终端 / 私域社群 / 精准营销 / 患教内容 / 店员话术）] → [量化目标（客群 %、终端数、复购率等具体数字）] → [预期业务效果]
```

**示例（约 110 字）**：

```
「老客回扫占比由 7.8% 升至 15%，二次扫码渗透加深 → 针对 30-39 岁主力客群上线复购激励计划，Top10 城市约 500 家终端配套复购券物料 + 店员话术 → 目标老客 30 天复购率提升 3 个百分点 → 拉高头部 Sku 复购贡献与终端动销。」
```

### 典型动作（按 9 维度选择）

| 场景（基于洞察） | 动作 | 数据支撑 |
|---|---|---|
| 老客回扫渗透加深 | 老客复购计划 / 复购激励 | 二次扫码占比 |
| Top3 Sku 集中度高 | 头部 Sku 重点铺货 + 中尾部 Sku 联合用药内容 | Sku Top10 占比 |
| 30-39 岁用户为主 | 职场人群患教专题 / 复购优惠 | 年龄分布 |
| Top10 病种关联 | Top10 病种对应终端物料 / 联合用药推广 | 关联用药 top10 |
| 地域集中（Top3 省份） | 重点省份铺货 + 其他省份慢病公益 | 地域分布 |
| 科普文章访问高 | 把 Top10 文章改编成终端话术 / 店员培训素材 | 科普 Top10 |
| 打卡用户 Top20 持续久 | 设置打卡奖励（积分 / 兑换 / 患教包） | 打卡 Top20 持续天数 |

### 禁词

- ❌「做好 XX」（不能量化）
- ❌「加强 XX 」（同）
- ✅ 改为：「XX 客群 X% 精准推送复购券」「Top10 城市 X 家终端重点铺货」

## 二、药箱侧（3~5 条）

### 资源池

| 资源 | 描述 |
|---|---|
| **小程序功能矩阵** | 用药提醒 / 复诊续方提醒 / 电子说明书 / 用药问答 / 疾病科普 / 服务指引 / 积分运营 等（见 `references/pharmacy_functions.md`） |
| **Agent 能力** | 智能助手（意图解析→知识库检索→大模型生成→合规审核） |
| **私域沉淀** | 企业私域客服 / 企业私域账号 / 企业品牌专区 / 加入药箱 |
| **商业化钩子** | 版本升级（基础版→专业版→企业版→定制版/增值服务） |

### 典型动作（与功能对应）

> 详细功能清单见 `references/pharmacy_functions.md`（已按《药箱产品功能明细表.xlsx》原件重写）。从中选 ≥ 1 项 / 策略。

| 场景 | 药箱功能（真实功能名） | 用户价值 | 药企价值 | 升级预期效果（版本归属） |
|---|---|---|---|---|
| 用户打卡渗透低 | 用药提醒 + 复诊续方提醒 | 降低漏服、按时续方 | 提升依从性、减少脱落 | 基础版→专业版，获取打卡 / 复购数据看板 |
| 老客回扫渗透深 | 推荐内容 + 定制科普 | 千人千面精准内容 | 提升阅读转化 | 升级企业版，定制内容精准匹配人群 |
| 病种关联集中 | 疾病科普 + 用药问答 | 专业易懂的疾病知识 | 拓宽患教覆盖面 | 接入医典背书，降低内容生产成本 |
| 30-39 岁用户 | 加入药箱 + 健康计划 | 便捷管理、个性化健康管理 | 留存用户、长期触达 | 升级企业版，建立长期触达通道 |
| 科普访问高 | 科普订阅 + 药箱服务号推送 | 不错过新内容 | 建立主动触达通道 | 升级企业版，持续深度患教 |
| 高单价 / 慢病 | 智能助手（Agent） | 大白话问药即时回复 | 激活私域内容为对话式服务 | 增值服务，预估解决 85%+ 用户问题 |

### 药箱侧策略公式（写死）

每条药箱侧策略按「功能 → 用户价值 → 药企价值 → 升级预期效果」四段完整展开，功能与价值**取自《药箱产品功能明细表.xlsx》原件**：

```
[功能名（明细表真实功能）] → [用户价值（「用户价值」列）] → [药企价值（「药企价值」列）] → [升级预期效果（「版本归属」列：基础版→专业版→企业版→定制版/增值服务）]
```

**示例 1（基于打卡渗透洞察）**：

```
【药箱侧】接入「用药提醒 + 复诊续方提醒」：帮患者简化设置、降低漏服概率并按时复诊续方避免断药（用户价值），提升用药依从性、减少脱落并拉动复购（药企价值）；建议企业由基础版升级至专业版，获取分人群打卡与复购数据看板（升级预期效果）。
```

**示例 2（基于关联用药洞察）**：

```
【药箱侧】开通「疾病科普 + 用药问答」：用户获取专业、图文并茂的疾病知识，比说明书更易懂（用户价值），拓宽科普覆盖面、提升患教渗透率，并借力医典专业背书降低内容生产成本（药企价值）；建议企业接入定制科普，按 Top7 同类药做精准人群内容匹配（升级预期效果）。
```

### 必备要素（写死）

每条药箱侧策略**必须包含**：
- [ ] 至少 1 个真实功能名（可回查《药箱产品功能明细表.xlsx》「分类 → 功能名称」）
- [ ] 「用户价值」（取自明细表「用户价值」列原意）
- [ ] 「药企价值」（取自明细表「药企价值」列原意）
- [ ] 「升级预期效果」（结合明细表「版本归属」列，引导基础版→专业版→企业版→定制版/增值服务）

## 三、协同规划（最多 1 条，可选）

如果企业侧与药箱侧需要深度联动，可在策略末尾加 1 条「协同规划」段落：

```
【企业 × 药箱协同】
企业按 Top10 城市供应线下物料 + 店员话术；药箱侧同步推送个体化提醒卡 + 扫码后跳转企微社群。
共同目标：3 个月内重点城市扫码 → 复访转化率提升 X 个百分点。
```

> 协同规划条数 ≤ 1 条，避免与两侧策略重复。

## 四、动作与维度的对应关系（速查表）

| 维度 | 企业侧主战场 | 药箱侧主战场 |
|---|---|---|
| 1.1 市场规模 / 用户规模 | 全年销量 / 渠道 / 竞争 | 整体策略联动 |
| 1.2 趋势 | 季度铺货调整 | 不定期推送策略 |
| 1.3 Sku | 头部铺货 / 中尾部内容 | 推荐内容 / 定制科普 |
| 1.4 地域 | 重点省份铺货 | 附近医院 / 附近药店 / 购药地图 |
| 1.5 竞品关联 | 同类药话术 / 联合用药 | 疾病科普 / 用药问答 / 私域扩列 |
| 2.1 人群画像 | 客群患教 / 终端物料 | 加入药箱 / 健康计划 / 个体化推送 |
| 2.2 功能使用 | 终端引导使用 | 功能渗透 + 智能助手（Agent）接入 |
| 2.3 科普 | 终端话术改编 | 科普订阅 / 药箱服务号推送 / 推荐内容 |
| 2.4 用药打卡 | 复购 / 患者管理 | 用药提醒 / 复诊续方提醒 / 积分运营 |

## 五、避坑

| 错误 | 后果 |
|---|---|
| 把企业侧和药箱侧混着写一段 | 违反「按执行主体分组」要求 |
| 药箱侧策略不含可回查的功能名 | 无法判断落地可行性 |
| 只写「加强沟通」这种泛化词 | 违反中性客观 + 字数约束 |
| 功能 / 价值自创，不回查《药箱产品功能明细表》 | 价值描述与真实功能不符，无法落地 |
| 商业化引导句过于「硬卖」 | 破坏报告专业性，应改为「建议企业接入 XX 服务包 / 升级至 XX 版」 |
