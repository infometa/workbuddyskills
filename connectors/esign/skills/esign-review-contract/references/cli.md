# 已选流程的文件获取

仅取得已明确流程中的文件；本地可访问文件无需执行本节。使用当前用户上下文，不扩大权限或自动切换账号、企业。CLI 不可用时说明受影响的文件暂时无法获取，保留原任务。

## 取得文件元数据

```bash
esign sign qa file --process-id '<上下文中的真实processId>' --format json
```

按真实返回的文件元数据和角色确定目标，提取真实 fileKey；不能把元数据当正文，也不假定所有响应都有相同容器。多个可能目标按文件来源规则处理。

## 取得实际文件

```bash
esign file download --file-key '<真实fileKey>' --output-dir '<该文件本轮独立目录>'
```

- 核对退出状态、业务结果和本次目录中真实可访问文件，不猜下载后的文件名或正文路径。
- 只返回 URL、处理中状态、空文件或失败时，不进入依赖正文的分析步骤。多个文件或版本不能唯一对应时先核对。
- 文件是否需要重新获取按当前 Skill 的文件来源规则处理。取得后返回 SKILL.md 的读取与业务分析步骤。
- 参数使用进程参数数组或正确的 shell 转义，文件名、中文、空格、引号和 `$` 均作为参数数据，不拼成代码。
- 能力未知或参数不兼容时查看对应命令 `--help`。不每次检查版本、不自动升级或修改运行环境；如实反馈兼容性缺口。
- 权限失败、不可见或不存在时停止受影响操作，不以失败冒充空结果，不尝试其他身份。
