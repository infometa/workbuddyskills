# 签署文件选择

按以下顺序使用本任务可确认的文件：

1. 用户明确指定的当前文件、名称或真实列表序号。“只发这份”优先于其他候选。
2. 用户本次已提交的有效文件选择结果，不重新让其选择。
3. 当前输入同时明确发起并携带合同文件时，使用本轮明确作为待签文件的文件，不混入历史附件；用户只限定其中部分就只用该部分。辅助证照、说明材料不能自动当成另一份待签合同。
4. 用户明确指向“刚才那份”，或同一未结束发送任务已有唯一有效合同文件时可继续使用。另一个任务恰有唯一历史文件，不等于本次发送对象。

多个可能目标仅澄清目标；缺文件请上传，不搜索桌面、下载目录、工作区或平台候选合同。用户已明确某流程中的文件时，可使用现有实际可用能力取得该文件，但不以文件名猜流程或扩大检索。读取与文件注册的具体方式见[执行规则](execution.md)。

用户明确多份一起发送时保留其范围与顺序。同批文件的签署名单或发送范围有冲突时只澄清该冲突，不把几份无关合同自动合成同一流程，不默认创建多个发送任务。

文件取得、当前用户可访问、可注册到本次草稿分别核实。真实文件标识、文件名、版本与任务关联保存在内部，不把电脑路径当平台标识。当前正文或文件更新后旧的文件确认失效，不能继续发送旧版本。仅有正文、草稿文字而没有可发送文件时，交给实际文件生成能力，不能在这里伪造PDF或沿用旧产物。
