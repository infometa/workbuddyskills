# 结果交付

默认生成独立HTML报告，对话只给简短主要变化结论和真实报告入口。用户明确只要总结时不运行渲染器、不生成报告，只在对话给总结。

## 生成HTML

读取[比对展示规则](compare-display.md)，在原始`compare_payload.json`之外生成本轮`compare_view.json`。证据数据仍用原校验器；展示文件只补短标题、变化概括、事实确认状态及表格字段，不改写证据引用。

使用当前原始payload与本次两份抽取正文，不用旧结果。传入真实文件显示名称：`files.base`采用用户可识别的基准文件名，不能用内部重命名的base.pdf替代。

```bash
python3 '<本技能目录>/scripts/render_contract_report.py' --kind compare --input-file '<本轮compare_payload.json>' --presentation-file '<本轮compare_view.json>' --source-text '<本轮base.txt>' --compare-text '<本轮compare.txt>' --output-dir '<本轮报告目录>'
```

脚本重用包内原文校验器，核对成功后生成HTML。文件名自动为`合同比对报告-基准文件名（去扩展名）-比对日期.html`；默认取本地实际运行日期，若显式传`--date`须为本次真实比对日期YYYY-MM-DD，不用合同日期。非法文件名字符会替换，超长名称会截短，同名同日放到新子目录，避免覆盖；依据仍保留原文件全名。

输出中`file`为实际文件路径，`file_name`为交付名称。检查退出成功、文件真实存在并可通过实际文件入口访问后再展示；文件名、链接文字与下载名称一致，不只把链接标题改中文。

## 报告与回复

- 目录逐条显示编号和短标题，按合同位置排列；先全部diff明细，再分类总结。每项先短标题、操作及影响分类、一句变化事实，再列对应原文；必要分析留在该项，分类总结使用同一组明细生成短概括和回跳链接，不新增明细以外的变化。表格按行和字段对齐，值变化默认可见，连续原文保留在可展开依据中；不得把尚未核实的空白列标成确定删除。宽屏左右对照、窄屏上下排列，自动换行，高亮真实增删改并保留完整相关原文和位置；空模块不展示。
- `coverage.limitations`只能填写真实影响结论的具体材料缺口，不放“本期不比较印章”等固定说明；未知不能说一致。分析字段只写变化本身及必要影响，不写“我没有合并／没有推及”等自述。
- 独立HTML无外部资源，不上传到公开网站。宿主有HTML预览就使用实际可用入口；若只支持打开文件或下载，如实提供该入口，不假称已内嵌预览。不要为切换格式再问一轮。
- 对话示意：“付款期限由30日改为60日，另有交付安排调整。完整差异请查看《实际报告名称》。”结论必须换成本次事实，不复制示例；不写上方／下方卡片，不粘贴整份明细，不附技术说明或格式升级引导。
- 渲染失败时保留分析，简短说明暂未生成报告并给可用结论；用户要明细时可直接展示，不伪造文件入口，不把失败当已交付。
