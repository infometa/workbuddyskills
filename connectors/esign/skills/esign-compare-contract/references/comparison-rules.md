# 差异判断规则与边界

## 两个独立维度

操作类型回答“怎样改了”：新增、删除、修改、替换。影响分类回答“改变了什么意义”：实质、非实质、不确定。同一变化各选一个；不要把局部字段变化与包含它的整条替换重复计数。独立影响可以分条，但证据范围和位置必须清楚。

替换表示可对应的原条款被另一套内容整体取代；修改表示局部字段或措辞变化。边界模糊时用修改。条款换位置时先对齐，再判断编号、引用和上下文是否变化；纯位置变化无需虚构内容变化。若记录编号或编排差异，操作类型用修改，在解释中说明。

## 实质变更

常见检查项：主体与角色、金额和税费、付款条件、数量和规格、交付验收、期限与续约、权利义务、责任上限、违约救济、解除条件、保密与知识产权、争议处理、定义和适用范围。

一个否定词也可能改变义务。“应当”变为“可以”要结合上下文解释。收款账号、正文所引用的文件编号等变化也不能自动当作小修改。删除违约金条款只说明原明确计算约定被删除，不推断为“不再承担任何责任”。

用户立场未知时客观说明与本次变化相关的必要影响，不逐项强加双方立场长篇分析。若用户要求站在某方审查，可按其明确角色解释，但分类仍基于原文。

## 非实质变更

仅在核实含义不变后使用：文字纠正、编号及交叉引用同步更新、含义等价的表达。标点、编号、排版也可能影响范围或解释，不能按字符数量分类。

本期不识别或比较印章差异；用户明确要求时说明暂不包含该能力，不声称印章相同。扫描件正文继续读取。仅凭文本抽取无法识别字体、颜色、签名、扫描图像等视觉差异。本包不声称发现全部格式变更；抽取文本空白变化不直接证明原文件列宽或版式改变。同类且不改变语义的空白差异可合并呈现并保留各位置；有含义的空白和单元格变化不能忽略。

## 不确定

适用：已定位疑似变化，但 OCR 字符不可靠、条款含义有多种合理解释、关键定义或附件缺失，无法判断实质性。写清楚不确定来源和具体应核实什么，不能只说“建议人工确认”。

确认实质变化但不知道进一步影响时，不必整条降为不确定。例如一次性交付改为分批交付已是明确变化，未提供分批计划写入该条 `questions`。

覆盖不全与条目不确定是不同概念：第 3 页没有读取属于覆盖限制；第 3 页金额有疑似数字差异且无法辨认属于不确定条目。前者不能伪装成已完成全文比较。

## 虚构例子

| 基准 → 比对 | 操作 | 分类与解释 |
|---|---|---|
| 收票后30日付款 → 60日付款 | 修改 | 实质：付款期限延长30日，分别说明双方影响 |
| 第一条标题改为第一条的等价标题 | 修改 | 经核对内容和引用后可为非实质；不能只凭标题短就判定 |
| 10日内一次性交付 → 三批交付、日期另定 | 替换 | 实质：交付方式和期限确定机制发生变化；另列交付计划问题 |
| 明确违约金条款 → 全文无对应约定 | 删除 | 实质：删除原违约金约定，不推断所有责任消失 |
| 无通知条款 → 新增通知义务 | 新增 | 依据义务内容判断实质，不因为只是新增一行而忽略 |
| 100,000元 → OCR为10O,000元且字符不可靠 | 操作待确认 | 不确定：不把字母O当作确定金额；请求清晰原文 |
| 选定文件正文第八条尚未比较 | 不作为虚构差异 | `coverage.status=partial`，说明范围，不出全文一致结论 |

## 发布前人工核对

先确认两份正文来源和顺序，再检查新增／删除是否其实在别处存在，对实质项复核数字、否定词、条件和定义，对非实质项复核交叉引用。逐条证据检查和计数汇总交给脚本；脚本不能代替上述语义核对。

## 解读的方向与确定程度

- 基准方向不等于真实时间顺序。实际新旧版本关系未知时只描述两份文件的差异，不编造修订过程；逆时间比较时明确文件名称。
- 费用、可退保证金等分别说明，不能将加盟费与保证金的增加合称不可退费用；确定计算交代口径，不把可能影响写成必然后果。正文一致不意味着流程状态或角色一致，不扩成税务安排、签章检查或条款修改任务。
- 保护距离从 5 公里到 10 公里只直接证明约定距离增加，不证明商圈面积翻倍、独占地位成立或收入变化。
- 签署栏记载日期不同可以记录文本变化；是否实际签署、生效仍需可靠依据，不能一边待确认一边给出确定生效结论。
- 发货、收货、验收、开票等期限保留谁在何时收到什么的触发条件，不把交付期限缩短直接说成经营风险必然下降。
- 只描述本次两份文件，不能把先前第三份版本混入范围和计数。细小编号变更也需检查引用关系后再判断实质性。
