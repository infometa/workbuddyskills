# 劳动合同起草规则

信息收集遵循 [通用规则](intake-common.md)：下列字段为按场景选用的候选，不要求首稿前补齐；首轮询问缺失立场，回复仍未说明则直接中性起草。初稿后只引导补充 2～4 个真实缺失的重要变量，不足时不凑数，不默认列出全部。

## 适用场景

适用于中国境内用人单位与劳动者建立劳动关系时订立劳动合同，包括新员工入职、劳动合同续签、固定期限劳动合同、无固定期限劳动合同、以完成一定工作任务为期限的劳动合同。

不适用于劳务合同、外包服务合同、顾问服务协议、实习协议、退休返聘协议、劳务派遣三方关系、股权激励或竞业限制专项协议。

如用户表达为"员工入职""雇员工""签劳动合同"，默认识别为劳动合同。如用户表达为"外包项目""按件结算""兼职合作""不缴社保"，应追问是否确认为劳动关系。

## 角色与起草立场

- 代表用人单位：重视岗位职责、绩效考核、规章制度、保密义务、离职交接、违纪处理。
- 代表劳动者：重视工资明确性、发薪时间、工作地点稳定性、加班规则、社保缴纳、休息休假、试用期期限。
- 未说明立场：首轮一并询问；首轮回复仍未说明时直接中性、均衡起草，不提示默认选择。

不得为了保护某一方写入违法或明显不可执行的条款。

## 初稿与信息补充

是否建立劳动关系等用工模型不明确且会影响合同结构时，生成初稿前集中询问；其他信息不要求先补齐。缺失的具体事实先用原子化占位符生成完整初稿，初稿展示后，可按需补充以下信息：

具体信息包括：

1. 用人单位名称。
2. 劳动者姓名。
3. 岗位名称、工作内容、工作地点。
4. 合同期限、入职日期或合同开始日期。
5. 月薪或薪酬结构。
6. 用户代表公司还是员工起草。

对应场景已经出现时，初稿展示后还可补充：

1. 是否约定试用期，试用期多久。
2. 每月几号发薪。
3. 工时是否为标准工时。
4. 是否有绩效、提成、奖金、补贴。
5. 是否有特殊保密、竞业限制、专项培训安排。

正式文件或发起签署前尽量补齐影响主体识别和履行的核心事实：用人单位统一社会信用代码、注册地址、法定代表人或负责人，劳动者身份证号、通讯地址。手机号、电子邮箱等联系方式只有在用户提供、明确要求或通知送达机制确实依赖时才写入，不作为默认待补充项。

## 可默认写入内容

- 用人单位依法为劳动者缴纳社会保险。
- 休息休假、法定节假日、年休假依法执行。
- 劳动保护、劳动条件和职业危害防护依法执行。
- 工资不得低于当地最低工资标准。
- 劳动争议按劳动仲裁前置程序处理。
- 合同解除、终止、经济补偿按法律法规执行。
- 试用期包含在劳动合同期限内。
- 同一用人单位与同一劳动者只能约定一次试用期，此规则仅用于内部规则判断，不作为合同正文默认条款原样输出。

## 条件触发变量

### 竞业限制

仅在高级管理人员、高级技术人员、核心岗位，或用户明确要求时展开。必须写明范围、地域、期限、经济补偿、违约责任；期限不得超过二年；不得写无补偿竞业限制。

### 培训服务期

仅在用人单位提供专项培训费用或用户明确提到培训服务期时展开。必须写明培训项目、培训费用、服务期限、违约金计算方式；违约金不得超过尚未履行服务期所应分摊的培训费用。

### 特殊工时

默认标准工时。不定时或综合计算工时只有在用户明确或岗位明显特殊时写入，并提示应依法履行审批或适用当地规定。

## 条款展开深度规则

劳动合同正文不能只写抽象原则，应把工作内容、薪酬、社保福利、解除终止、离职交接等条款写成可直接审阅的完整段落。

### 岗位职责生成

- 用户提供具体职责时，优先按用户内容整理。
- 用户只提供岗位名称时，可以基于该岗位生成 3-5 条通用职责。
- 通用职责应保持概括、合理、低风险，不编造具体客户、区域、项目、业绩指标、团队人数、职级或管理范围。
- 最后一项通常保留为"完成甲方安排的与本岗位相关的其他工作"。
- 应补充边界句：具体职责、工作标准和考核要求以岗位说明书、录用条件、绩效考核制度、规章制度或双方确认的工作安排为准。

产品经理岗位示例风格：

1. 负责产品需求收集与分析、产品规划、功能设计、版本迭代等产品管理工作；
2. 对接研发、运营、市场等相关部门，推动产品需求落地并协调解决产品推进过程中的问题；
3. 跟踪行业动态及竞品情况，持续优化产品体验；
4. 完成甲方安排的与产品管理相关的其他工作。

销售岗位示例风格：

1. 负责客户开发、客户沟通、销售机会跟进及客户关系维护；
2. 根据甲方销售管理要求推进商务沟通、订单跟进、回款协助等工作；
3. 记录和反馈客户需求、市场信息及销售进展；
4. 完成甲方安排的与销售岗位相关的其他工作。

未覆盖岗位时，按岗位名称生成通用职责，不得因为没有岗位库而只写一句"从事某岗位工作"。

### 劳动报酬展开

劳动报酬条款至少写明：

1. 工资金额及大小写。
2. 工资口径，通常写为税前工资。
3. 工资构成：基本工资、岗位工资、绩效工资、奖金、提成、补贴等；用户未提供构成时，可写"包括基本工资及依法或按甲方制度确定的岗位工资、绩效工资等固定或浮动薪酬部分"。
4. 发薪日和支付方式。
5. 个人所得税、社保和公积金个人承担部分由用人单位依法代扣代缴。
6. 绩效、奖金、提成、补贴没有明确标准时，不编造具体金额或比例，写按依法制定并公示或告知的薪酬绩效制度执行。

### 社会保险和福利展开

社会保险和福利待遇条款应具体列明：

- 基本养老保险、基本医疗保险、失业保险、工伤保险、生育保险。
- 住房公积金。
- 病假、工伤、医疗期、婚假、产假、陪产假、丧假、年休假等依法或按制度执行。
- 其他福利待遇按用人单位依法制定并公示或告知的规章制度执行。

### 解除终止展开

解除和终止条款应拆分写明：

- 双方协商一致解除。
- 劳动者依法提前通知解除。
- 用人单位依法解除。
- 试用期解除。
- 合同期满或法定情形终止。
- 经济补偿、赔偿和离职手续依法执行。

### 离职交接展开

离职交接条款应写明工作资料、文件、设备、账号权限、商业秘密资料、财务款项、客户或项目交接、离职证明和工资结算。

### 试用期展开

试用期条款至少包含 4 款：

1. 试用期起止日期，并说明试用期包含在劳动合同期限内。
2. 试用期工资；用户未另行约定时，可写与转正工资标准一致，不得低于法定标准。
3. 甲方可依据录用条件、岗位职责、考勤记录、工作表现、规章制度遵守情况进行试用期考核。
4. 乙方被证明不满足录用条件的，甲方可依法解除劳动合同；试用期满且乙方满足录用条件的，双方继续履行合同。

不得把"同一用人单位与同一劳动者只能约定一次试用期"作为独立条款写入正文。

### 违约责任展开

违约责任条款至少包含 4 款：

1. 一方违反本合同约定给对方造成实际损失的，应依法承担赔偿责任。
2. 乙方违反保密义务给甲方造成损失的，应依法承担赔偿责任。
3. 培训服务期仅在双方另行签署专项培训服务期协议或本合同已明确专项培训费用时适用；未约定专项培训服务期的，不设置培训服务期违约金。
4. 竞业限制仅在双方另行签署竞业限制协议且依法约定经济补偿时适用；未另行约定的，本合同不设置竞业限制违约责任。

不得设置劳动者一般提前离职违约金。

### 通知与送达展开

通知与送达条款至少包含 3 款：

1. 双方确认合同首部已载明的通讯地址或其他送达方式可用于履行合同、解除通知、续签通知、离职交接、争议处理等事项；首部未提供联系电话或电子邮箱时，不得补造对应字段。
2. 一方联系方式变更的，应在变更后三日内书面通知对方；未及时通知的，原地址或联系方式仍视为有效送达地址。
3. 通知以专人递送、快递、挂号信、电子邮件、短信或即时通讯工具发送的，按签收、退回、系统发送成功或合理到达时间确定送达。

### 劳动争议处理展开

劳动争议处理条款不得写"甲方所在地法院管辖"或直接诉讼管辖。应写：

1. 因履行本合同发生争议的，双方应先协商解决。
2. 协商不成的，任何一方可依法向劳动合同履行地或用人单位所在地有管辖权的劳动争议仲裁委员会申请仲裁。
3. 对仲裁裁决不服的，可依法向有管辖权的人民法院提起诉讼。

## 标准章节结构

首部：标题后直接列明甲乙方信息（不加小标题，不作为编号条款）。生成正式 DOCX/PDF 时，甲乙方信息区默认按无边框双列排版，左列甲方、右列乙方，左右列之间保留清晰留白；缺失字段使用加粗待补充占位，不把 Markdown 标记原样带入正式文件。

1. 合同期限
2. 工作内容和工作地点
3. 工作时间和休息休假
4. 劳动报酬
5. 社会保险和福利待遇
6. 劳动保护、劳动条件和职业危害防护
7. 试用期
8. 劳动纪律和规章制度
9. 保密义务
10. 培训服务期
11. 竞业限制
12. 合同变更、解除和终止
13. 离职交接
14. 违约责任
15. 通知与送达
16. 劳动争议处理
17. 其他约定

尾部：签署区（不作为编号章节）。生成正式 DOCX/PDF 时，签署区默认按双列排版，左列显示甲方（用人单位）名称和独立字段 `盖章：`，右列显示乙方（劳动者）姓名和独立字段 `签字：`；签署区不加中间竖线，填空线保持等长。

生成正文时，甲乙方信息应置于标题之后、第一条之前，不加概括性小标题，不作为编号条款。正式文件生成阶段必须将该信息区转成无边框双列表格，左右列之间保留清晰留白，不保留逐段单列样式。签署区直接放在合同正文尾部，不作为 Markdown 标题或编号条款；正式文件生成阶段必须转成无外框双列表格，只保留甲乙方角色、名称或姓名、`盖章：` / `签字：` 和空白字段 `签署日期：`，不重复首部身份信息，且填空线等长。没有培训服务期或竞业限制时，写为"如双方另行签署专项协议的，以专项协议为准，但不得违反法律法规强制性规定"，不要强行设置重义务。

首部固定格式：

```text
# 劳动合同

甲方（用人单位）：{用人单位名称}
统一社会信用代码：{统一社会信用代码}
注册地址：{甲方注册地址}
法定代表人/负责人：{法定代表人或负责人}
乙方（劳动者）：{劳动者姓名}
身份证号：{乙方身份证号}
通讯地址：{乙方通讯地址}

## 第一条 合同期限
```

## 每章起草要求

- 标题后甲乙方信息：包含单位名称、统一社会信用代码、注册地址、法定代表人或负责人、劳动者姓名、身份证号、通讯地址；联系电话、电子邮箱仅在用户提供或明确要求时加入。该部分不加小标题，不作为第一条。
- 合同期限：写明合同类型、开始日期、终止日期或终止条件、入职日期、试用期是否包含在合同期限内。
- 工作内容和地点：写明岗位、通用岗位职责、工作地点、岗位调整和地点变更规则；重大变更应协商一致。
- 工作时间和休息休假：写明工时制度、休息日、法定节假日、年休假、加班审批、加班工资或调休。
- 劳动报酬：写明基本工资、岗位工资、绩效/奖金/提成/补贴、试用期工资、发薪日、支付方式、个税和社保个人部分扣缴；缺失构成时按薪酬制度概括，不编造具体比例。
- 社会保险和福利：写明养老、医疗、失业、工伤、生育保险和住房公积金；病假、工伤、医疗期、婚假、产假、陪产假、丧假、年休假等依法或按制度执行。
- 劳动保护：写明安全生产、职业健康、必要劳动条件、劳动者安全制度遵守义务。
- 试用期：根据合同期限确定试用期期限上限；超出上限时给一句短提醒。正文应写明试用期起止、包含在合同期限内、试用期工资、考核依据、录用条件、不满足录用条件时依法解除、试用期满后继续履行；不要把"同一用人单位与同一劳动者只能约定一次试用期"这类内部判断规则作为独立合同条款原样输出。
- 规章制度：写明劳动者遵守依法制定并公示或告知的规章制度。
- 保密义务：写明保密信息范围、使用限制、资料返还、期限、泄密责任。
- 解除终止：写明协商解除、劳动者提前通知、用人单位依法解除、试用期解除、期满终止、经济补偿依法执行。
- 离职交接：写明工作交接、资料设备账号归还、财务结算、离职证明。
- 违约责任：按"违约责任展开"生成至少 4 款，仅围绕实际损失、保密、培训服务期、竞业限制等适用场景，不写一般提前离职违约金。
- 劳动争议：按"劳动争议处理展开"生成协商、劳动仲裁、诉讼衔接条款，不写甲方所在地法院管辖。
- 签署区：不作为编号章节。草稿中默认显示甲方（用人单位）名称及独立字段 `盖章：`，乙方（劳动者）姓名及独立字段 `签字：`，不生成甲方法定代表人、负责人或授权代表签字栏；只有用户明确要求对应人员签字时才增加。双方只保留空白字段 `签署日期：`，不自动填写日期值、不追问、不占位；签署地点仅在用户提供、要求或合同期限明确依赖时加入。正式 DOCX/PDF 中默认转为左右双列签署区，且不重复首部的统一社会信用代码、法定代表人或负责人、身份证号、地址和联系方式。

## 禁止写法

- 劳动者自愿放弃缴纳社会保险。
- 试用期不缴纳社保。
- 试用期不计入劳动合同期限。
- 公司可随时解除劳动合同且无需补偿。
- 员工提前离职须支付违约金。
- 所有员工默认竞业限制两年。
- 竞业限制无补偿。
- 工资、岗位、工作地点由公司单方随时调整。
- 发生争议直接由甲方所在地法院管辖。
- 工资只写"按公司制度执行"而没有金额或计算方式。

## 生成前边界

生成草稿时先执行通用合同质量框架的输出前强制自检与自动补写，并覆盖当事人、期限、岗位、地点、薪酬、工时、社保、试用期期限、通知送达、劳动争议处理；避免违法社保、违法解除、违法违约金；仅在触发场景下处理竞业限制和培训服务期。正常规则适配不向用户说明，只有用户信息明显冲突时才简短提醒。

## 待补充信息规则

以下是内部核对用的核心字段候选，初稿后只挑实际缺失的 2～4 项友好引导：用人单位统一社会信用代码、注册地址、法定代表人或负责人、劳动者身份证号、通讯地址。联系电话、电子邮箱等可选字段不得因缺失列入待补充清单；签署区只保留空白字段 `签署日期：`，不列入待补充清单。
