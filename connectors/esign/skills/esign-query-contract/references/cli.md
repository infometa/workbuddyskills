# 流程信息与文件获取 CLI

仅为已明确的流程获取问答信息，或取得已确定的流程文件。本说明不提供合同检索能力。用户上传文件直接进入问答流程。用户只要求解释命令时不执行。

业务调用使用执行环境提供的当前用户上下文。调用失败、无权限或环境不可用时，如实说明原因并停止受影响的操作，不扩大权限或切换身份。

参数取自用户已提供的真实标识、已有目标上下文或真实工具结果，使用参数数组或正确的 shell 转义，避免空格、单引号或含 `$` 的 fileKey 被解释为命令。以下值是形态示例，运行时必须替换。

## 流程上下文与文件列表

```bash
esign sign qa context --process-id '<真实processId>' --format json
esign sign qa file --process-id '<真实processId>' --format json
```

前者用于状态及流程事实；后者用于文件元数据，不是正文。按实际返回的文件容器和角色信息定位用户选定的合同文件及真实 `fileKey`，不假定固定字段一定存在，不自动补取独立附件。

明确不可见、权限失败或文件不存在时停止相关读取。未返回字段不能推断；更不能自行扩大范围、切换账号或租户。

## 取得选定文件

```bash
esign file download --file-key '<真实fileKey>' --output-dir '<本次文件的独立临时目录>'
```

使用文件列表或用户已有上下文中真实的 `fileKey`，不依据名称拼接。指定 `--output-dir` 是为了取得实际文件；只获取下载地址不等于完成文件读取。

- 检查退出状态、实际业务返回与目录中的本次文件，保留文件标识和实际文件路径的对应关系。不猜返回字段，也不猜下载后的文件名。
- 每个目标文件使用独立临时目录；多个输出或文件归属不清时，核对实际结果后再读取，不自动选择第一份，不混用旧文件。
- 命令只返回 URL、异步状态、无权限、空文件或实际下载失败时，不能声称已经取得正文。说明未完成文件获取并停止依赖该文件的问题；其他独立文件可以继续。
- 文件取得后回到 SKILL.md 第 3 步执行统一问答，不要求用户重复上传。流程文件来源与正文引用保持关联。

CLI 能力未知或参数不兼容时查看对应 `--help`，不每次检查版本，不自动升级。业务环境限制由部署方处理，不要求关闭 Agent 的执行隔离。

命令返回结构不符合已知契约时，按实际输出核对，不能编造正文或字段。
