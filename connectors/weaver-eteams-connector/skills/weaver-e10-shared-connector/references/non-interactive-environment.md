# 非交互环境处置（容器 / 沙箱 / CI / 无 GUI）

## 什么时候读取

满足以下任一条件时读取本文件：

- 运行在容器、沙箱、CI、远程执行器或任何无 GUI / 无本地浏览器的环境
- 无法向用户弹出输入框、选择框或确认框（无人值守）
- 只读业务命令超过 60 秒、写入类命令超过 600 秒仍未结束（见 SKILL.md「超时与重试预算」）
- 业务命令报 `authentication` / `session_expired`，或托管目录 / 认证目录报 `EACCES: permission denied`

## 环境判定：可交互 vs 非交互

| 判定项 | 可交互环境 | 非交互环境（按非交互处理） |
| --- | --- | --- |
| 浏览器与授权 | 连接器在用户本机完成浏览器授权，与 Agent 环境无关 | 同样由连接器在用户本机完成；**Agent 环境没有浏览器不影响业务命令** |
| OAuth 回调 | 由连接器侧处理 | 由连接器侧处理；Agent 不参与、不等待 |
| 用户输入 | 可向用户提问并等待回答 | 无人值守，提问不会有人回答：一次把「请回连接器面板断开后重新连接」讲清楚 |
| 安装 / 写入权限 | 可写、可提权 | 只读 HOME、只读配置目录、无 sudo |

判定不了时一律按**非交互**处理：非交互流程在可交互环境下同样安全，反之则会挂起或卡死。

## 认证失败时的处置（不自行登录）

连接器模式下 Agent **不执行任何登录命令**（`auth login` / `auth set` / `auth xiaoe`）。出现认证类错误时：

1. **立即停止**当前业务流程；写入 / 删除类命令不得自动重试。
2. 原样反馈 `error.type` / `error.subtype` / `error.message`，不要猜测原因、不要改写错误文案。
3. 非交互环境：不要替用户等待浏览器授权，也不要把登录命令丢给用户手动执行（域名与宿主标识由连接器固定，用户手搓容易与连接器状态不一致）。统一引导用户：

> 当前连接器的 E10 登录态已失效，请回到连接器面板断开连接后重新点「连接」，连接器会重新打开浏览器完成授权。

4. **禁止**为绕过认证失败而换 `--profile`、换域名、换命令或改走直连接口重试。

## 超时与重试

1. 记录本次结果：成功 / 认证失效 / 权限失败 / 超时，以及**耗时与退出码**。
2. 退出码 **124** 表示命令被外部超时掐断，按超时失败处理，**不得静默重跑**。
3. 只读查询最多重试 1 次（仅限网络类错误且未产生副作用）；写入类**禁止自动重试**，结果不确定时只补一次只读回查。
4. 慢环境（容器冷启动、批量导入）可以撑到上表上限；快环境不要人为等待。

## 可写性相关说明

托管目录或认证目录不可写（报 `EACCES: permission denied`）属于**环境侧**问题，技能侧只能识别与上报：

- 不得为绕过权限而改写其他目录、改用其他路径或使用 `sudo`。
- 反馈时只说失败的动作与 `EACCES: permission denied`，**不打印**目录细节与凭证。
- 不建议反复重试。

## 收尾流程（每次业务尝试后必做）

1. 记录本次结果与耗时、退出码。
2. 非成功结果一律**不自动重试**。
3. 用只读命令确认真实登录态，再决定是否继续业务操作：

```text
weaver-work-cli --version
weaver-work-cli --profile eteams --json auth status --no-check
weaver-work-cli doctor --e10
```

4. 登录未打通前，不执行任何依赖登录态的业务 operation；需要重连时引导用户回连接器面板。
