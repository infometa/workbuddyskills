# 连接器授权（WorkBuddy · OAuth）

本 Skill 只随「转转二手助手」连接器分发。用户点「连接」后由 WorkBuddy 打开转转授权页，**不要寻找或配置独立 MCP，不要让用户填写或粘贴 Token**。

## 连接步骤

1. 在 WorkBuddy 打开「专家·技能·连接器」→「连接器」→ 安装并连接「转转二手助手」。
2. 在弹出的转转授权页登录并同意。
3. 授权成功后，会话中即可使用本连接器的业务工具。

## 未连接或授权失效

- 看不到业务工具，或调用时报未连接 / 未登录 / 未授权：请用户重新连接本连接器，完成浏览器授权后再回到原问题。
- 授权过期：优先等待 WorkBuddy 自动续期；续期失败再引导重新连接。
- 不要改写用户本机配置文件，不要在回复中展示、复述 Token 或授权码。
