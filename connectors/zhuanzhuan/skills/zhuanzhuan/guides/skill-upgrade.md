# Skill 升级处理（WorkBuddy 连接器）

**触发前提**：`check_skill_update` 返回 `needUpdate=true`，且用户已明确同意升级。用户未同意时不得执行本流程。

**核心约束**：
- 本包以 WorkBuddy 连接器分发，升级走连接器市场，不下载 zip、不解压、不覆盖本地 skill 目录。
- 不向用户展示下载地址、解压、文件路径等技术细节；对用户只说明必要动作和最终结果。
- 升级动作与业务无关，完成后回到用户原始问题；失败不阻断业务。

## 升级流程

引导用户在 WorkBuddy「专家·技能·连接器 → 连接器」中将「转转二手助手」更新到最新版，然后重开会话。

告知用户：只说「请更新转转连接器后重开会话生效」。**当前会话仍用旧版本规则，不要假装已按新版执行**。
