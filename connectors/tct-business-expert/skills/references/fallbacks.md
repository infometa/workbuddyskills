# 兜底与不支持（AI-REQ-G，配合 T1–T6）

答不了时：**明确说不支持 + 给替代口径或引导**，计入有效回答；编数=无效。

| ID | 触发 | 怎么说 / 替代 |
|----|------|----------------|
| G01 | 成交额/利润/回款/吨数/成交率/复购/金额 Top/下单 | ERP 暂不可查；可改给询价/报价活跃度（T1–T6 过程数据）；勿用 orderCount 当成交 |
| G02 | 跨月/上月环比/环比骤降 | 线上可查窗口有限，暂不做跨月；给当前可查区间 |
| G03 | 品类聚合 | 无结构化品类；可看 T5 原文 |
| G04 | 行业平均/同行比 | 无行业数据；只给自身+团队内对比 |
| G05 | 我报某品类准不准 | 整体识别准不准（T5）；无法按品类拆 |
| G06 / G17 | 客户为什么不回/拒绝原因 | 无归因；给 T5 status=1 或 T6 名单，不臆测 |
| G07 | 行情/网价 | 本 Skill 不含 |
| G08 | 员工未绑微信 | 提示先绑定 |
| G09 | 区间内无数据 | 「该范围内暂无数据」 |
| G10 | 业务员越权问全队 | 只返回本人 + G11 |
| G11 | 业务员问排名/比同事 | 只能看自己；团队对比找老板 |
| G12 / G14 / G15 | 下单周期/预测成交 | 走 G01；过程用 T1/T4/T5/T6 |
| G13 | 精确响应分钟数 | 无成对时间戳；改 T5 已报未回 |
| G16 | 让 AI 发消息/开单 | 只读；可生成话术 |
| G18 | 超出可查窗口 | 说明窗口有限 |
| G19 | 本地表与口径无关 | 不硬套 |
| G20 | 同名多人 | 请用户确认 |
| G21 | 问法过笼统 | 反问时间/视角 |
| G22 | 主观褒贬词 | 映射客观指标；反因果 |

## 工具失败

「我这边再核一下，稍后发你。」不编数、不猜权限。

## 空结果 / 未查到（G09 强化）

| 情况 | 正确做法 | 禁止 |
|------|----------|------|
| 某次 `total=0` | 明确「该条件下暂无」；可建议换 Tab/时间/重试 | 用另一次查询结果「改分类」填洞 |
| 要报三类资产 | 对 assetTab=1/2/3 **分别调用**后再汇总 | 只查全部，再口头拆成潜在/活跃 |
| 用户纠错后 | **重新调工具**再答 | 未重查就编一份「正确分类」 |

## T6 已知能力限制（非「未上线」）

| 场景 | 说明 |
|------|------|
| 沉睡全量精确名单 | 无法一键按「超 N 天未询价」筛全量；只能排序+分页近似，**必须声明可能不全** |
| 加好友转化率 | 无现成转化率指标；按明细聚合并注明 |
