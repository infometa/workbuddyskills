# 全能参考与 可灵 4.0 视频推荐

`omni_ref_video` 已全量开放，是视频生成的默认推荐入口；直接按本文件推荐 可灵 4.0，并读取实时模型参数。

## 按模型集合选择

候选是当前账号实际返回的“工具 + 模型”组合，并须完整满足素材、声音、时长与输出要求。

先按[视频候选入口](../../kling-ai-plugin/references/capability-discovery.md#视频候选入口)查询包含 `omni_ref_video` 的模型响应。未指定模型时，默认推荐已返回且满足需求的 可灵 4.0 视频模型；实际模型 ID、别名和参数以响应为准。

用户指定且可用的模型优先。没有适用 可灵 4.0 时，使用该入口支持全部必需输入的可用模型。没有兼容模型时说明具体限制，不丢弃主体或音频后提交。

## 路由与输入

- 文本、图片、视频、主体或音频的全能参考使用 `omni_ref_video`；逐项确认所选模型支持输入类型，不能用工具描述中的泛化能力代替模型声明。
- 纯文本与关键帧请求默认使用此入口，按 `who_am_i` 返回的必填输入与帧输入能力构造请求；动作迁移使用实际支持该意图的模型。某入口返回的模型和参数不能移植到其他入口。

选定模型后通过公共参数模块处理规格、素材与声音。本文件不重复这些规则；即使本工具存在，没有使用参考素材或声音时也不加载对应模块。

## 主体库与音频输入

- 用户要求使用主体库角色时，先读[主体复用流程](../../kling-ai-plugin/references/asset-workflows.md#将主体用于生成)：按名称列出并解析真实 ID，读取详情，确认所选全能参考模型支持该资源类型。将主体绑定到 `arguments[]` 的 `elements` JSON 数组字符串，并在提示词用 `<<<实际主体ID>>>` 引用；不要仅写角色名称或要求用户重复上传库中素材。绑定字段与引用语法如有实时更新，以模型声明为准。
- 用户提供音频时，读取[声音与音频](../../kling-ai-plugin/references/audio-options.md)，把素材放入 `inputs[]` 中模型声明的音频槽位，使用真实可访问的素材引用，并按声明在提示词引用。明确其用途是节奏、音乐、声音参考还是其他受支持用途；会影响结果且用途不明时先澄清。音频输入与生成声音开关分别校验，不以打开声音开关代替传入音频。
- 主体库、图片、视频和音频可以按模型声明组合使用；提交前读取[参考输入限制](../../kling-ai-plugin/references/reference-inputs.md)，核对各类上限、组合总量、时长和互斥条件。Element 不替代必填图片，音频不占用图片或视频槽位；不能静默遗漏用户指定的任何参考素材。
