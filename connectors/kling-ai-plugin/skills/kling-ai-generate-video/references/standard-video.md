# 基础视频推荐

仅在当前连接的完整 `tools/list` 没有 `omni_ref_video` 时读取。模型可见性、用户指定优先和单次提交沿用共享规则；此分支无需加载全能参考推荐。

## 入口与模型

| 意图 | 入口与处理 |
| --- | --- |
| 纯文本生成 | `text_to_video`，按文字定义开场，不补造源图 |
| 单图、首尾帧或多图参考 | `image_to_video`，按当前模型声明区分帧控制与身份/风格参考 |
| 动作迁移 | `motion_control`，主体图必填，动作库 `motionId` 与来源视频二选一 |
| 指定全能参考、参考视频或音频等素材 | 当前入口若不能完整支持则说明请求无法满足，不丢弃素材或静默降级 |

沿用这些入口当前可用集合中的 `defaultModel`；它不符合用户指定的速度、预算、声音或素材要求时，从同一入口的可用模型中选择符合需求者。不要仅因不存在全能参考工具而假定其他入口的能力没有变化：某入口实时返回适用的新模型时，仍按核心选型规则选择，参数也重新读取。

选定模型后通过公共参数模块处理实际规格与输入；没有声明的参数不加载、不构造。
速度或预算偏好依据实际模型说明与计费信息，不按名称猜测。不主动提及未返回的型号，也不增加“升级模型”的提示。
