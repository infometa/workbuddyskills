# 图像提示词构建

## 提示词顺序

用户要求原样使用提示词时保留原文；否则按任务选用以下信息，只写影响结果的内容，不机械填满模板。具体事实、准确文字与禁止改动项优先于氛围修饰：

1. 投放位置和媒介：产品照片、编辑人像、海报、缩略图、营销静帧。
2. 主体和锁定事实：身份、产品结构、准确色彩、官方标志或文案。
3. 动作或视觉创意。
4. 环境、时间、天气和氛围。
5. 构图：取景、相机高度、镜头观感、视觉焦点层级、负空间和安全区域；精确宽高比放在结构化参数中。
6. 光线和色彩。
7. 材质、纹理、表面细节，以及写实或风格化程度。
8. 约束：主体数量、禁止改动项、不得添加额外文字或水印、安全区域要求。

## 交付级质量画像

按本次用途选读对应部分，不需要读完所有画像。画像决定提示词要写哪些可见事实，也决定提交前检查什么。不要把所有画像拼接成一段万能提示词。

### 商业产品与电商

- **提示词重点：**锁定产品几何、比例、标签位置和品牌色；说明主视角、表面材质、受控反射、接触阴影和背景分离。
- **成片门槛：**瓶盖、鞋底、按键、接口等结构不漂移；玻璃、金属、塑料、织物的高光宽度和粗糙度可区分；标签可辨认但不虚构文字；主体轮廓适合抠图或版式裁切。
- **避免：**用烟雾、飞溅、悬浮碎片遮挡卖点，或用广角透视夸张产品形状。

### 广告主视觉与海报

- **提示词重点：**只设一个传播焦点；定义前景、中景、背景的层级，品牌主色与对比色机制，以及标题、标志或行动信息的安全区域。
- **成片门槛：**缩小观看时仍能先读到主体再读到辅助元素；视觉隐喻与产品事实有关；负空间可以实际排版，不被高频纹理和装饰填满。
- **避免：**同时竞争的多个主角、没有传播作用的“氛围元素”，以及把营销文案交给模型临场编写。

### 人像、身份与时尚

- **提示词重点：**锁定面部骨骼、年龄呈现、肤色、发际线和显著特征；明确视线、表情、姿态、服装剪裁、主光位置与眼神光。
- **成片门槛：**身份不像被平均化或美化成另一人；皮肤保留自然纹理和体积，手部与肢体可信；面料张力、图案、扣合和标志位置保持准确。
- **避免：**未经用户要求改变年龄、体型或族裔特征，以及用过度磨皮、塑料高光或不合逻辑的轮廓光制造“高级感”。

### 叙事概念与电影剧照

- **提示词重点：**先定义正在发生的叙事瞬间，再写人物与环境的空间关系、场面调度、可见光源、前中后景和色彩脚本；镜头语言服务于情绪或信息揭示。
- **成片门槛：**画面能回答“谁在何处做什么”；光线能追溯到窗、灯具、火焰、霓虹或天空等来源；场景细节属于同一时代、地点和美术体系。
- **避免：**把颗粒、暗调、变形宽银幕光斑、浅景深和雾化全部叠加，替代真实的场面设计。

### 参考图编辑与品牌变体

- **提示词重点：**把源图作为事实基线，明确允许变化的范围；逐项列出身份、产品结构、镜位、透视、标志、文案和背景中必须保持的内容。
- **成片门槛：**未授权区域不发生漂移；新增光线、季节、颜色或环境能与原始透视、遮挡和材质响应一致；变体之间只改变批准的维度。
- **避免：**重新描述整张源图并意外改写事实，或把风格参考误当成身份、产品结构或构图参考。

需要更细的场景选择时，读取[图像场景模式](scene-patterns.md)。

## 局部编辑

素材查看、角色绑定与限制由已加载的参考输入模块处理，不在此重复。

编辑提示词先写允许改变什么，再写必须保留什么。例如“将背景改为浅灰影棚，保留瓶型、瓶盖、标签文字与产品颜色；侧后方柔光勾勒瓶身，正面补光使标签可读”。不把局部编辑改写成重新设计产品；未要求改变的内容不作额外美化。

## 精确文字

- 逐字保留用户提供的文案。
- 用户同意后期排字且存在可用设计工具时，可生成预留文案区的底图；用户要求直接带文字的成品时，不擅自改为无文字底图。
- 用户要求直接生成文字时，明确准确文案、位置、层级和语言，避免重复不同版本；仅需一句标题时禁止新增无关文案，同时保留原有标签。需要多段文字时不自行删减或改写。检查可读性后再评价，不把提示词中的正确文案当作成品正确的证据。

## 受控变体

用户要求不同创意方向时分别构造提示词；要求同一提示词的多个结果时按授权数量与实时批量上限处理，不擅自拆成多次收费请求。受控对比默认每次只改变一个维度，用户明确要求多项变化时遵从，其余锁定事实保持一致：

- 概念：直白展示 / 人物场景 / 隐喻表达
- 镜头：微距 / 中景 / 环境广角
- 构图：居中 / 三分法重点位置 / 俯拍
- 情绪：明亮商业感 / 克制高级感 / 高饱和活力感
- 表情或动作

## 避免

- 缺少视觉依据的空泛赞美，例如“漂亮”。
- “杰作、最佳质量、8K、超高清”等不能说明具体视觉结果的质量标签；应把抽象质量要求落实为可见的光线、材质、景深和构图。
- 把模型、分辨率、宽高比或图片数量等工具参数写进创意提示词；它们只作为结构化参数传递。
- 互相冲突的指令，例如同时要求极简和密集分层，或者同时要求微距和完整环境广角。
- 重复正向需求的冗长负面清单。
- 未经验证的产品功效、医疗效果、价格、奖项、认证或统计数据。
- 未检查实时模式定义，就假设某个模型或参数一定存在。
