# 可灵 AI

使用本包 `mcp.json` 中的 `kling-ai-plugin` 连接器。OAuth 由 WorkBuddy 管理，不索取 API Key、不覆盖客户端注册信息，不在日志中保存凭证、私有账号字段或签名 URL。

## 按请求加载规则

- 图片生成、编辑、海报与参考图创作：使用 `kling-ai-generate-image`。
- 视频生成、关键帧、全能参考、动作控制与分镜：先读取[视频生成 Skill](../kling-ai-generate-video/SKILL.md)，完成其中的新旧入口分流后再选模型；不能只读核心 Skill 和提交流程就调用生成工具。
- 只查进度、展示结果或刷新作品链接：只读[任务结果](references/task-results.md)，不加载生成推荐、模型参数或创作参考。
- 新生成、编辑或已授权重试：按对应创作 Skill 选型，再执行[生成提交](references/tool-workflows.md)；多步骤按依赖顺序执行。
- 主体库、动作库或本地文件上传：读[素材工作流](references/asset-workflows.md)。只读素材查询不提交生成任务。
- 生成前先读[能力发现](references/capability-discovery.md)，选定当前账号可用的模型后，按[参数模块加载表](references/model-parameters.md)只读本次需要且受支持的规则。
- 授权、上传、模型或服务错误：读[故障排查](references/troubleshooting.md)。需要请求示例时读[用法示例](references/prompt-examples.md)。

## 模型可见性与灰度

- 当前账号的模型、参数、规格、输入类型与组合限制，统一以 `who_am_i` 的实时返回为准。`tools/list` 只确认入口存在及调用结构；会员页、工具描述和静态示例不能覆盖账号能力。
- 只有当前连接的 `tools/list` 返回目标工具，且当前账号的 `who_am_i.availableModels` 在该工具下列出目标模型时，才可展示、推荐或调用其模型名。工具数量（即使增加了全能参考工具）、描述中的举例或默认模型字段不能代替模型集合的授权判断。
- “最新”只在上述可用集合中、支持所需输出类型与意图的模型之间比较。图像与视频版本不能混排，`defaultModel` 不等于最新；结论应限定为“当前账号可用的最新图像/视频模型”。没有新模型时正常使用当前可用模型，不主动提及更高版本、未开放的型号、白名单或“还有更好的模型”。不能根据 Skill、历史快照、其他账号或先前会话补出模型。
- 用户点名但当前筛选集合未返回时，按[能力发现](references/capability-discovery.md)补查后再判断。若模型实际可用但仅支持另一输出类型，说明用途不匹配，不说账号无权限，并让用户选择保留作品类型或改做该模型支持的作品；不自动切换媒体类型或模型。完整发现后仍未返回时，只说明当前连接未返回所请求模型，不补充或重复隐藏型号；替代仅列出实际可用且符合需求的模型。
- 重新连接、切换账号或环境后，重新发现工具和模型，不沿用先前账号的能力缓存。能力发现失败或无法确认模型属于当前集合时，不使用静态快照兜底提交。

## 创作与能力选择

视频选型（包括只读选型）也先读取视频 Skill：当前连接有 `omni_ref_video` 时，必须检查其 `who_am_i` 模型集合后再选择或回退。纯文本不等于只能用 `text_to_video`；全能参考是否需要附件取决于所选模型的必填输入与组合约束，不能仅凭工具名称断言必须有图片或视频。

用户已经明确的素材角色、模型、声音、画幅和质量要求直接采用，只询问会实质改变结果的缺失信息。用户指定且当前可用的模型优先；未指定时按以下两条分支选型，不维护两份固定模型清单：

| 实时能力 | 选型行为 |
| --- | --- |
| 当前入口（或支持同一意图的新入口）实际返回适用的新一代模型 | 推荐并优先使用新模型。质量优先按实时模型说明选择；速度优先选实时说明明确适合快速生成的同代模型；预算按实际计费信息比较 |
| 没有返回适用的新模型，包括新工具只返回原有模型 | 沿用原有生成入口与该入口可用集合中的 `defaultModel`；默认模型不符合用户要求时，在当前集合内选择符合要求的模型。不提示未开放型号 |

新旧依据当前返回的模型说明及同系列可比较版本判断；不能仅凭工具数量、新工具出现或名称里的快慢词推断。无法确认新旧时走原有分支，不猜型号。新增入口只有明确支持用户的素材角色与意图时才参与选型；某入口可用的模型不得移到其他入口调用。

这两条分支都服从账号可见性规则。原有分支仍读取实时参数，不能回退到过期快照；能力读取失败时停止选型。先满足身份/产品一致性、文字、动作和声音等必需能力，再比较新旧；默认值或版本偏好不得覆盖用户的素材、时长、速度和预算要求，不自动提高分辨率、数量或降低要求。“效果最好”不等于只选最高分辨率或最快模型，不能承诺尚未检查的成品质量。

查询已有作品与编辑已有作品是不同操作：状态、展示和刷新链接不生成新任务；用户明确要求编辑、变体或制作视频时，按共享流程刷新并选定源作品，再执行已授权的新步骤。多个步骤按依赖顺序执行，前一步未成功时不提交依赖它的下一步。

## 宿主与 UI

使用远端工具实际提供的 `_meta.ui.resourceUri`（兼容 `_meta["ui/resourceUri"]`）及 `text/html;profile=mcp-app` 资源。元数据存在不等于 widget 已成功挂载；刷新与文本回落按任务结果流程处理。包内不复制 widget HTML 或增加第二个 MCP server。

删除主体、退出或切换账号只在用户明确要求且目标清楚时执行。上传素材、查看额度或选中主体不构成生成授权。
