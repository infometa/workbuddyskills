# 输出规格选择

选定模型的画幅、时长、分辨率或数量存在多个允许值时读取；这些字段都只有唯一合法值时才可跳过。本文件不列出静态档位表。

- 分辨率、画幅、时长、数量只使用该模型实际字段名与枚举。没有的参数省略；描述中更高档位的举例不扩展枚举，也不推断账号升级后必定开放。
- 默认值与用户意图相容时保留。明确要求最高分辨率时，从实际可用且不违反预算和其他约束的档位选择；“效果好”本身不授权升档加量，不把提高分辨率当作创作质量保证。
- 画幅根据用户投放用途确定：竖版短视频与故事版用 `9:16`，方形信息流用 `1:1`，横版广告、网页与长视频平台用 `16:9`，超宽幅只在用户明确要求时使用；确实没有投放线索时才用该模型的默认比例。图生视频还要结合首帧构图推导。
- 模型声明了画幅字段就必须显式传值，不能因为它是可选字段而省略——省略会落到模型默认比例，常见后果是竖版需求出成横版。模型未声明该字段时必须省略，不改用其他字段名代替。允许自动比例时先确认它是否要求特定参考输入；不满足时改用符合用户意图的合法显式比例。原图与目标比例不同须保护主体/文字，不通过拉伸或隐含裁切破坏内容。
- 时长须容纳动作、对白、停顿和收尾。单个动作或单一镜头用最短的合法时长；对白、演唱、完整产品动作或两个相连节拍优先更长一档；复杂叙事只在实时枚举支持且确有必要时再加长。不要把所有请求都压到最短一档，也不因时长不够就删台词、加速或拆成多次任务。
- 用户未要求多个结果时不额外加量。请求数量超出单次上限时说明可行范围，未获相应授权不拆成多次收费调用。
- 提示词中的规格与实际参数一致；不把所选模型不支持的规格写进提示词来替代参数。
