# 声音与音频

只在所选模型声明声音控制、原声保留或音频输入，且本次需要选择、输入或处理相关依赖时读取。工具级“支持音频”不等于每个模型都支持。

- 区分生成新声音、保留源视频原声、静音、对白和旁白。各自只映射到声明的参数与允许值；缺少控制开关不保证静音或有声，音频参考也不自动表示支持音色克隆或逐字对白。
- 模型声明 `enable_audio` 与 `keepOriginalSound` 互斥时，不同时为真；仅当两个字段均被该模型声明时才设置二者。用户要求互斥能力同时生效时说明限制，不用提示词假装兼容。
- 音频输入仅使用实时声明的槽位、引用语法、格式与时长限制；没有音频 input 时不借图片或视频槽位传音频。
- 用户提供准确台词时逐字保留，写明说话者、语言、语气和顺序；旁白不改成画内对白，台词不自动变成字幕，不擅自添加口号。
- 估计台词、停顿、动作和收尾能否容纳于目标时长，不用固定字数公式保证结果。明显放不下时先解决冲突，不加速、截句或删字；需重新选择规格时才读[输出规格](output-options.md)。
- 人声、环境声和音乐分别说明目的与轻重；对白需要清楚时让背景声退居次要。需要声音的成品应检查实际音轨，不能以封面或无声预览判定通过。
