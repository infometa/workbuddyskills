# 故障排查

## 安装后缺少 MCP 工具

重新加载 WorkBuddy，并确认连接器内的 `kling-ai-plugin` MCP 服务器已启用。如果工具仍未出现，重启宿主并查看其 MCP 诊断信息。不要把索取 API key 作为替代方案。

## 未授权或未连接

打开 WorkBuddy 的连接器连接入口，选择 Kling AI，并完成浏览器 OAuth 流程。OAuth 客户端注册信息由 WorkBuddy 管理，不手工覆盖。如果 OAuth 返回 `invalid_target`，不要臆造 `oauth_resource` 覆盖值；应报告宿主诊断信息，并验证当前 Kling 受保护资源元数据。

## 模型能力不一致

用户确认已开通，但完整 `who_am_i` 未返回所请求模型时，先核对实际调用的连接器、端点与环境、相关生成入口和 MCP 版本，再刷新连接并重新读取能力。普通会员状态与模型灰度分开判断；另一客户端的可用结果只用于比较，不能替代当前连接的授权能力。

刷新后仍不一致，只报告“当前连接未返回所请求模型，原因待查”，保留脱敏后的端点、版本、查询参数及相关模型列表用于排查。不能把未返回直接解释为未开通，不能自动退出或切换账号，也不能猜模型名试生成或静默改用旧模型。测试方案和产品文档用于核对预期，参数冲突仍以当前模型的实时约束为准。

## 上传或图生视频失败

- 刷新实时模式定义，并确认当前的上传工具及其输出字段。
- 严格按返回内容原样复用上传引用。
- 如果模式定义返回或要求 `taskTraceId`，应在上传和生成过程中保持相同的值。
- 只使用所选实时工具声明的输入名称、值类型和参考素材角色；不要假设一定存在 `file_upload`、`first_image` 或仅接受字符串的参数值。

## 任务仍在运行

按[任务结果](task-results.md)区分已挂载组件、无组件生成和单独查询。保持同一个任务编号，不重新提交。组件无法刷新时按服务允许的间隔查询；查询异常或当前轮次结束时返回当前状态和任务编号。

## 生成后没有显示 widget

确认生成工具的 `_meta.ui.resourceUri`（兼容旧字段 `_meta["ui/resourceUri"]`）指向可读取的 `ui://` 资源，并且资源 MIME 类型为 `text/html;profile=mcp-app`。目标 WorkBuddy 构建必须能够读取资源、挂载沙箱 iframe，并向 widget 传递工具输入和结果。若宿主不支持或资源读取失败，按共享流程提供媒体或结果链接，用户要求多个作品时保留对应结果；不要复制本地 `mcp-app/` 或启动第二个 MCP server 作为替代。

## 生成失败

按[任务结果](task-results.md)报告失败原因并保留各项 ID；服务消息中的凭证或当前账号不可见的型号不原样透出。不要自动创建替代任务，因为这可能再次消耗积分。

## 限流或队列已满

报告服务消息并停止，不等待后自动重试收费生成、不切模型规避限制。状态查询遇到限流也结束本轮查询，保留任务编号。

## 积分不足

以 `query_membership_and_credits` 的当前余额及服务返回为准；套餐每月赠送额度不能替代余额。确实不足时说明情况，可提供当前区域服务返回的充值入口；不要自动重试，也不将余额不足说成模型不支持。

## 会员权益与可用能力

- 用户询问会员、订阅或服务明确提示权益不足时，可参考[官方会员计划](https://klingai.com/app/membership/membership-plan)。价格、活动和权益以用户当前区域与账号页面为准，不在 Skill 保存价格表或会员等级到模型/规格的固定映射，不自动购买。
- 高清生成、单次生成数量、主体库容量、并发和生成通道是不同权益；页面所述适用范围不自动等于 MCP 每个入口的实际能力。不要承诺升级会员一定开放未返回的模型，也不在普通生成中主动推荐升级。
- 用户说明会员已升级但 MCP 未更新时，重新读取相关入口能力；仍未返回则说明当前连接的实际限制。需要排查时核对是否同一账号与区域，不索取账号凭证，不用浏览器登录状态替代 MCP 授权结果。

## 提交超时且无法确定是否已创建任务

不要重放生成调用。按[任务结果](task-results.md)恢复已知任务或报告未知；`taskTraceId` 不能当作幂等键。无法排除原任务已创建时，替代生成必须来自用户明确接受可能重复扣费后的授权。

## 结果链接已过期

签名输出 URL 可能是临时的。重新查询已保留的 `generationId` 以获取当前输出 URL，或者登录已授权账号后，在 Kling 官网查看生成历史记录。URL 过期不代表生成作品已丢失。不要记录签名 URL，也不要把它当作永久资产标识。

## 异常反馈

用户要求上报异常且当前工具列表存在 `feedback` 时，按实时 schema 提交一次必要的脱敏错误信息及任务编号，不包含凭据、上传票据或签名 URL。反馈不代表重试、退款或修复原任务，仍保留原任务状态。
