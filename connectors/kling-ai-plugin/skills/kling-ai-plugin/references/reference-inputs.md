# 参考输入与组合限制

只在所选模型存在实际/必填参考输入，或本次使用其支持的 Element 时读取。

- 有查看/播放能力时先检查实际素材；否则只使用用户明确说明的事实，不凭文件名编造内容。清晰度、裁切或身份冲突会影响必需目标时再补问。
- 建立“素材 → 模型声明的输入槽位 → 提示词引用”的一致映射，区分首帧、尾帧、身份/产品、风格、动作与场景编辑。引用语法按所选模型说明，不从其他入口复制。
- 按指定角色保留身份、产品结构、标签与颜色；风格参考只迁移指定风格特征。目标画幅不同须保护重要内容，不拉伸主体或隐含裁切文字。
- 帧输入只传实时声明的槽位和必填项；保持顺序，描述相邻帧的过渡，不猜中间帧字段、时间戳或帧数公式。首帧只锁定开场，不代表后续禁止运镜。
- Element 先读取详情确认资源类型；模型须同时声明对应主体类型和绑定参数。按要求序列化 ID/绑定名/类型，不拿封面替代视频主体，不用 Element 替代必填图片 input。
- 文件 URL 来源、格式、大小、单段/总时长按所选模型约束核对。优先复用模型接受的现有引用；需要本地上传时再读[素材上传流程](asset-workflows.md#本地素材上传)。
- 图生图与图生视频的参考图当前要求 PNG/JPG、单文件不超过 30 MB、分辨率低于 4K、长短边比不超过 2:1；动作来源视频当前要求 3–30 秒、短边至少 340px、长边不超过 3850px。这些是可提前拦截无效提交的常见门槛，实时工具或模型给出更严格要求时从严，没有声明的工具不套用。宿主无法读取素材元数据时，不声称已完成格式、大小、尺寸或比例检查。
- 存在 `combinedItemCap` 时检查总量；存在 `combinedItemCaps[]` 时按 `whenAnyInputPrefixes` / `whenNoneInputPrefixes` 判断条件，满足所有适用上限。按实际条目数计数，不按最高槽位编号；Element 计入声明的组合数量。
- 存在 `elementSupport` 时同时检查主体类型、分项和总量、参考视频存在时的附加限制；说明中的互斥条件同样生效。不能通过重复输入、删除用户必需素材或换类型绕过约束。
- 主体库可保存的容量与单次生成可引用的主体数量是两种限制；生成按当前模型的 `maxItems` 和组合上限，不用会员页的主体库容量替代。
- 单次请求只提交与目标有关的素材。明确要求的参考不擅自删改；超限或身份/用途冲突时先确定取舍。未检查的属性不宣称已验证。
- 动作迁移须核对主体图与动作来源的可见身体范围、遮挡和连续性；必填主体图与唯一动作来源按实时工具规则提交，不把库动作预览 URL 当作 `motionId`。
