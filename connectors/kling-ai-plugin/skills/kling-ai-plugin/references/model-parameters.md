# 选定模型的参数与按需模块

先完成[能力发现](capability-discovery.md)，再读取本文件。模型参数、输入槽位、枚举、默认值及组合限制均来自当前账号 `who_am_i` 返回的选定模型，不提供静态档位或模型配置。

## 最小请求

1. 目标工具存在且规范 `model` 在其 `models` 中；`defaultModel` 也必须在该集合内。固定“工具 + 模型”后再构造请求，换模型则重新构造。
2. 把该模型的 `arguments` 与 `inputs` 作为字段白名单。没有的字段不传，也不加载该功能模块；必填项必须满足。模型没有输入时省略 `inputs`。
3. 有枚举时只使用精确合法值。仅一个允许值且与用户意图及依赖约束相容时直接采用，不读取选档建议；可选字段无关且无必需依赖时省略。自由文本按说明填写，不虚构枚举。
4. 用户指定/从用途可靠确定的合法值优先，其余保留实时默认值。默认值仍须满足当前输入条件和互斥关系；明显冲突时停止，不丢失要求后勉强提交。
5. 每个参数名只传一次，数字/布尔/JSON 数组按工具要求编码；需要确认外层 payload 时读[请求结构](mcp-contract.md)。

“保留默认值”不适用于会增加成品内容的开关：作品数量、多镜头结构和模型内生成声音都以用户授权为上限。`imageCount`、`prefer_multi_shots`、`enable_audio`、`enable_asmr` 一类字段的实时默认值可能已为开或大于一个结果，用户未要求时不照抄，而是在该模型允许值内显式选择单个结果、单一连续镜头和静音；模型未声明该字段则省略，不用提示词补回。用户明确要求多个作品、多镜头或声音时按其要求设置，无法满足时说明限制，不额外生成。

精简加载不意味着可以忽略必填项或其他参数的依赖条件。

## 只加载适用模块

同时满足“所选模型声明对应能力”和“本次需要处理该能力”才加载；单纯工具存在或描述提及不构成加载条件。所有必填、跨字段依赖和条件上限始终检查，不因用户没点名某参数而跳过。

| 当前请求与模型 | 读取 |
| --- | --- |
| 有实际/必填参考输入，或需要使用模型声明支持的 Element | [参考输入与组合限制](reference-inputs.md)；只用提示词的请求不读 |
| 模型的画幅、时长、分辨率或数量字段存在两个以上允许值，或默认规格因输入条件不适用 | [输出规格选择](output-options.md)；这些字段都只有唯一合法值时才不读 |
| 声音/原声/音频输入能力已声明，且用户提出声音需求、实际传入音频，或需处理相关依赖/互斥 | [声音与音频](audio-options.md)；无需声音决策的请求不读 |

未声明所需能力时，不加载对应功能的写法尝试绕过限制：回到已返回候选中寻找完整满足需求者；没有则说明限制。模型不可用和字段不可用都不能用提示词冒充支持。按需加载以 MD 文件为单位，不按每个分辨率或型号复制文档。
