# 盘发发客户

只读当前用户自己录入的客户，不是全网客源。用户说客户、跟进、今天该跟谁、高优先级、某某要找厂房、按客户配盘时，必须调用本连接器的 MCP 工具，不要用网页搜索。

未授权或旧连接只有盘库权限时，先完成 OAuth。WorkBuddy 会打开浏览器，用户用盘发发小程序扫码确认。客户工具需要 `mcp:customers.read`。已经连过盘库的用户要重新扫码，旧令牌不会自动带上客户权限。遇到 401 或授权失效，提示用户重新授权，不要猜测客户。

客户管理是会员功能。接口返回「客户管理为会员专属功能」时，如实转告用户开通会员，不要编造客户。

## 可用工具

### search_customers - 搜索客户

按关键词或筛选查看当前用户的客户列表。

**参数**

| 参数 | 类型 | 必填 | 说明 |
|------|------|:----:|------|
| query | string | - | 姓名、公司、电话或需求关键词。最长 100 字 |
| status | string | - | 只传中文：`跟进中`、`已暂停`、`已成交` |
| priority | string | - | 只传中文：`普通`、`高意向` |
| dueToday | boolean | - | 只看今天待跟进 |
| relationStage | string | - | 只传中文：`待推荐`、`已推荐`、`待带看`、`已带看`、`洽谈中`、`不合适`、`已成交` |
| page | integer | - | 页码，从 1 开始 |
| size | integer | - | 每页条数，1–20，默认 10 |

**返回**

`总数`、`页码`、`每页条数`、`统计`（今日待办 / 高意向 / 洽谈中）、`客户`。每条含 `客户姓名`、`电话`、`公司`、`意向`、`状态`、`需求摘要`、`关联房源数`，以及可选的焦点房源和焦点待办。

**用法**

- 用户说找某位客户或今天该跟谁：调用 `search_customers`，能确定的筛选再填中文
- 向用户展示时只用 `客户姓名`，不要展示 publicId 或其他内部编号
- 需要看下一页：同一条件增大 `page`
- 不要编造未返回的客户

### get_customer - 读取客户详情

读取当前用户自己的一位客户，含需求、带看关系和跟进记录。先用 `search_customers` 或 `get_customer_workbench` 拿到 `客户姓名`。

**参数**

| 参数 | 类型 | 必填 | 说明 |
|------|------|:----:|------|
| name | string | ✅ | 客户姓名，必须来自工具返回 |

**返回**

`客户`、`需求`、`首次跟进`、`关联房源`、`跟进记录`。带看关系里的 `房源名称` 可再配合盘库工具 `get_listing` 看盘源。同名客户多于一位时，会提示用公司或电话区分。

### get_customer_workbench - 客户工作台

今日待办、逾期、高意向、洽谈中数量，以及待办列表。

**用法**

- 用户问今天跟谁、有没有逾期、工作台时调用
- 列表项的 `客户姓名` 可接着调用 `get_customer`

### search_customer_listings - 按客户配盘

按一位客户的需求，在当前用户自己的盘库里匹配候选盘。先确认客户姓名。

**参数**

| 参数 | 类型 | 必填 | 说明 |
|------|------|:----:|------|
| name | string | ✅ | 客户姓名 |
| query | string | - | 额外关键词，可空 |
| propertyType | string | - | 只传中文：`厂房` / `仓库` / `研发办公` / `其他` |
| page | integer | - | 页码 |
| size | integer | - | 每页 1–20，默认 10 |

**返回**

`房源` 列表，每条含 `房源名称`、`房源类型`、`区域`、面积和租金。`房源类型` 只会是厂房、仓库、研发办公、其他。

## 注意事项

- 本连接器不能创建、修改、删除客户，也不能改带看阶段或写跟进
- 向用户说话只用中文：客户姓名、跟进中/已暂停/已成交、高意向、厂房/仓库/研发办公。禁止输出 publicId、factory、office、warehouse、plant
- `name` 必须来自工具返回；对不上或无权查看时会返回客户不存在
- 结果为空时如实说明盘发发里没有匹配客户，不要补全网客源
- 需要看盘源封面或完整字段时，用盘库工具 `search_listings` / `get_listing`
