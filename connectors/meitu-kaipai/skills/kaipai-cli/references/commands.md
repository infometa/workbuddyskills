# 命令使用补充

通用创作、登记素材或配置诊断时读取本文件。参数和默认值查询当前命令的 `--help`；JSON 请求的字段与限制按[平台说明](platform.md)查询 CLI 契约。业务命令选择、字幕和混剪的确认流程见正文，输出与恢复见[运行说明](runtime.md)。

## 通用创作与续聊

- `chat` 结合自然语言需求和真实附件完成创作；已有固定工具流程的媒体任务按正文选择对应入口。
- 素材先按平台说明准备：远程地址下载原资源后，统一使用 help 列出的文件参数，由 CLI 上传至自有 CDN 再提交。仅将 URL 写入 Prompt 不等于添加附件。不要推导通用 `--file`、独立音频或文档输入能力，也不补造内部 action 或旧卡片参数。
- 新创作省略会话，续聊传实际会话 ID。CLI 自动处理上传和会话内附件登记，无需先创建空会话或 add-media。默认跟进本次任务；分离或断线后按运行说明恢复。

以下两条是新创作与续聊的独立示例。文件和会话 ID 必须替换为实际值，并使用已解析的 CLI 入口及安全参数传递方式：

```bash
kaipai chat -p '根据这段素材做一版竖屏口播视频，增加字幕。' --video-file './source.mp4'
kaipai chat -r '<实际session_id>' -p '开头更简洁，保留产品介绍。'
```

## 空会话与素材登记

- 只有明确需要空会话时才调用 `create-room`；通常的创作、工具、字幕和混剪分析直接接收素材。
- 只有需要先取得媒体 ID 等场景才调用 `add-media`。它上传并登记素材，不创建创作任务；已有真实会话和目标明确后，按平台说明准备本地文件，再按 help 传入附件。
- 每项登记的服务端响应在 stdout，本地 `source:"cli", type:"media"` 在 stderr。保存真实 ID 和完整 URL；中途失败时保留成功项，核对后只处理失败项，不盲目重传整个批次。

## 账号、权益和配置诊断

- 登录按平台说明执行。仅在用户需要或诊断必要时查询 `user-info`；不能仅凭账号标志判断某项工具无权益。
- `purchase` 提供实际购买入口，打开页面不代表已付款；`feedback` 仅返回客户反馈入口，不会代发反馈内容。展示真实响应，不虚构链接或购买结果。
- 常规业务无需修改配置。诊断用 `config list` 查看脱敏结果；需要变更时先核对用户要求和子命令 help，随后检查 `effective_env / env_source` 等实际生效字段，不为绕过业务错误切换环境。
- 使用浏览器授权，不读取原始凭证文件，不把 Token 写入命令、Skill 或日志。只有用户要求退出时才执行 `auth logout`。

## 网感模板

`smartedit --video-file '<本地视频>' [--template-material-id '<真实SEC ID>'] [--detach]` 为每条视频新建独立 Session，省略模板参数显式发送 random。支持参数文件和只读预检，字段按 contracts 查询。以本次 Task 完成且存在 ready 视频确认成功，直接交付成片；不创建或打开编辑项目。恢复时查询原 Session／Task，不重发生成。完整最小流程见入口指南的网感模板部分。
