# superun 连接器

<!-- @author xiuyu.yi -->

通过对话创建应用、继续已有项目，完成需求、设计、研发、测试、发布和运营。

在 WorkBuddy 连接器管理中连接后，宿主准备 Node.js 和 CLI；登录由 CLI 自动打开系统默认浏览器完成，已有 PAT 直接复用。连接成功后直接描述产品需求，或说明要继续的项目。

创作流程沿用[现有 creation 技能](skills/superun-creation/SKILL.md)。连接器提供云端创作能力，原专家团继续按原方式使用。

## 登录与断开

凭据由 CLI 保存在用户级目录，与宿主管理的安装目录分开。相同用户环境中的专家团和连接器共用原有 PAT；重启后无需重复登录。

取消授权会执行 CLI 登出并清除本地保存的 PAT，其他共用入口下次可能需要重新登录；此操作不撤销服务端 PAT。客户端的启停开关仅控制连接器是否启用。单独设置的 SUPERUN_PAT 环境变量不会被子进程清除。

## 版本与使用范围

本包要求 WorkBuddy 5.0.0+，以及包含认证适配的 superun-ai-cli 0.1.44+。WorkBuddy 安装公开 npm 正式版本；本地构建与客户端实际验收分别记录。

本包用于连接器市场；Buddy 应用首页的 OAuth MCP 内置连接器配置是另一个入口。
