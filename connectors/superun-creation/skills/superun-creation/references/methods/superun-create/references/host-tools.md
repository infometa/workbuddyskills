# 当前宿主工具

按当前动作读取提问、展示或后台进程小节；业务材料的处理见 [云端展示](host-presentation.md)。

## 用户提问

### WorkBuddy 提问方式

使用当前真实问题和完整选项，不省略影响选择的费用信息。问题来源由当前执行模式决定。

需要用户补充答案或选择时，按以下优先级调用当前可用且用途匹配的工具：
- `AskUserQuestion`；允许模式：以当前会话声明为准；收答方式：synchronous。


遵守当前工具的 schema、题数、选项数及单/多选限制；不为提问擅自切换模式。工具不可用或无法完整表达题目时，用完整文本收答。异步返回、推荐和控件预选不等于真实用户答案；未收齐必需答案时保持当前交互。

AskUserQuestion 每次最多 4 题，每题 2–4 个选项。options 使用 label、description，header 不超过 12 字符；多选时 multiSelect=true。使用客户端已有的自由输入入口，不自行新增 Other 选项。



## 成果展示

### WorkBuddy 页面展示方式

以下页面工具仅用于业务成果预览。superun 登录/PAT 授权链接必须按认证用法由 CLI 拉起系统默认浏览器，不使用宿主内置浏览器、WebView 或 `present_files` 打开。

每个阶段产生当前可查看的真实预览时，主动调用页面展示工具，不等待用户另说“打开看看”。使用下方已配置的工具，并遵守本端的正文交付顺序；工具支持链接卡时先交付可点击预览卡，不把它说成自动打开。根据实际动作报告“链接已提供”或“页面已打开”。按以下顺序使用当前可用的能力：
- webview：调用 `present_files`，参数结构参考 `{"files":["<当前真实页面 URL>"],"cwd":"<当前任务的绝对工作目录>","explanation":"展示本轮生成的可交互预览页面"}`，将 URL 槽位替换为当前真实地址。
- browser：从当前工具列表识别对应页面打开能力。
- link：在对话中提供可点击的真实链接。


只使用当前阶段允许展示的真实 URL。工具不可用或打开失败时按顺序降级并说明结果；工具回执只证明其实际完成的展示动作；链接卡回执只证明卡片已交付，浏览器回执才证明已打开，不证明关键功能已验收。不伪造控件，不把抓取网页内容当成已向用户打开页面。




## 后台进程

### WorkBuddy 后台进程

通过 `Bash` 启动长命令；将本次实际命令填入 command、操作说明填入 description，附加参数为 `{"run_in_background":true}`。保存工具返回的原任务标识和输出位置。

结果工具为 `TaskOutput`；task_id 使用原后台命令返回值，附加参数为 `{"block":true,"timeout":60000}`。running 只表示部分输出，按原句柄有限等待；不把业务项目 ID 或队友 ID 当后台进程 ID。


后台 Bash 的 TaskOutput 按 block/timeout 读取状态。完成通知出现后读取原任务结果，不循环忙查。队友成果通过 SendMessage/inbox 接收；对队友调用 TaskOutput 只返回快照，不等待。dev 服务使用 TaskOutput(block=false) 查看启动日志，取得实际 URL 后检查页面并展示，不用 block=true 等待服务退出。

有限时命令收到真实终态后保存 stdout、stderr 和退出状态。持续运行的开发服务器以启动日志和实际页面响应确认就绪，读取状态而不等待退出；交付后保留原进程和句柄供后续使用。未完成或结果不明时保留原句柄，不重新提交写操作；已消费的结果不重复取。命令输出的业务含义由对应模式解释，不能从进程退出成功推断业务验收通过。仅在实际支持的原生能力上续接；普通长命令不另外创建 Agent、定时任务，也不通过 &、nohup 或循环 tail 模拟后台。用户取消后不自动重启；停止本地进程不等于取消远端业务。
