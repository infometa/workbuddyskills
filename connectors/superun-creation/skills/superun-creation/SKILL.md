# superun 创作

读取 [云端执行流程](references/methods/superun-create/references/cloud-generation.md)，通过 superun-ai 创建或继续应用。产品、设计、开发、QA 与运营工作由 Superun 完成，当前宿主负责提交、展示、收答和核对。

- 已有项目保留原 sessionId；新诉求原样转交，不重复创建。
- 实际问卷答案回复原交互；检查、修复、发布按对应专用流程执行。
- 需要提问、展示或长命令时读取 [宿主工具](references/methods/superun-create/references/host-tools.md)。
- 当前宿主直接执行，既有授权持续有效；没有明确上线要求不发布。
