# AIGEO GEO 运营

## 使用原则

- 先根据用户意图选择最匹配的 MCP Tool，再按照 Tool 的输入 Schema 传参。
- 涉及新增、修改、删除、启动、暂停、重试或发布等有副作用的操作，执行前必须向用户明确说明目标和影响并获得确认。
- 查询类请求优先使用只读 Tool；需要分页时遵循 Tool Schema 中的 `pageNo` 和 `pageSize` 限制。
- 不向用户展示或索要服务端内部 Token，不在回复中输出完整凭证。
- 上游返回业务错误时，直接说明失败原因，并保留服务返回的 request ID（如果有）。

## 能力范围

连接器提供以下能力域：

- GEO 总览和分析
- 文章与内容管理
- 内容创作与素材处理
- 发布任务、发布记录和发布状态管理
- 网站与页面相关数据
- 关键词查询和管理
- 租户资料、账号和算力信息

## 交互要求

用户没有给出明确时间范围、分页参数或目标对象时，先使用合理默认值或向用户补充确认；不要猜测租户、任务、文章或关键词的唯一标识。
