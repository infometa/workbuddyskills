# 法保案例检索 Skill

## 可用工具

### fbw\_case\_search - 类案智能检索

基于1.6亿+过往裁判案例数据库，根据改写后的法律检索关键词与检索地域，在海量裁判案例库中进行相似度检索，返回最相关的案例列表。

**参数说明：**

| 参数名   | 类型     | 必填 | 描述                                       |
| ------ | ------ | :-: | ---------------------------------------- |
| query  | string |  是  | 将用户案情改写后的法律检索关键词（不超过80字），请勿传入用户原话        |
| region | string |  是  | 检索地域，格式为省（全称）+市（全称），如"北京市"、"广东省深圳市"；案情中未提及地域则传"全国" |

**query 改写规则**（案情收集完成后，先将案情描述与补充信息整合，再改写为法律检索关键词）：

1. 提取用户核心诉求和事实，例如："欠我钱10万元不还怎么办" → "民间借贷 10万元 借贷纠纷"
2. 识别案件类型、争议焦点
3. 提取相关法律条款、法律概念等
4. 转换为法律术语
5. 保持简洁，不超过80字

**改写示例：**

- 用户案情"别人欠我钱不还怎么办" → 传入 query：`民间借贷纠纷 借款合同`

- 用户案情"民间借贷纠纷怎么判" → 传入 query：`民间借贷纠纷 判决结果`

- 用户案情"劳动合同纠纷怎么赔偿" → 传入 query：`劳动合同纠纷 劳动争议 经济赔偿`

- 用户案情"房东不退押金" → 传入 query：`房屋租赁合同纠纷 押金退还 承租人权益`

- 用户案情"工伤赔偿标准" → 传入 query：`工伤认定 工伤保险待遇 工伤赔偿`

**region 提取规则：**

1. 从案情描述中提取地域，格式为"省（全称）+市（全称）"，如"北京市"、"广东省深圳市"
2. 案情中未提及地域时，region 传"全国"

**返回字段说明：**

| 字段名                  | 类型     | 描述                  |
| -------------------- | ------ | ------------------- |
| status\_code         | number | 状态码，200 成功，500 服务异常 |
| msg                  | string | 状态说明                |
| relative\_case\_list | array  | 相似案例列表（可能为空）        |

### fbw\_case\_search\_keywords - 案例关键词检索

将用户问题拆分出的核心关键词作为输入，检索相关的案例关键词。

**参数说明：**

| 参数名   | 类型     |  必填 | 描述                           |
| ----- | ------ | :-: | ---------------------------- |
| query | string |  是  | 从用户问题中拆分出的核心搜索关键词，多个关键词以空格分隔 |

**关键词拆分原则：**

1. 去掉与法律检索无关的口语化表述
2. 提取案件核心行为（如"持刀抢劫"而非"我朋友拿刀抢了银行"）
3. 保留法律术语优先（如"盗窃"优于"偷东西"）
4. 关键词数量控制在 2-4 个

**拆分示例：**

- 用户问"我朋友持刀抢劫银行会被判几年" → 拆分传入 `持刀抢劫 银行`

- 用户问"公司拖欠工资怎么办" → 拆分传入 `拖欠工资`

**返回字段说明：**

| 字段名           | 类型     | 描述                  |
| ------------- | ------ | ------------------- |
| status\_code  | number | 状态码，200 成功，500 服务异常 |
| msg           | string | 状态说明                |
| keyword\_list | array  | 案例关键词列表（可能为空）       |

## 1、正常案例检索流程

### 第一步：搜集需求

向用户搜集案件详情（案情描述）。

### 第二步：确认信息完整

向用户确认是否案情提供完整：

- 若用户告知已提供完整，则询问一次是否有额外补充信息（必问），将补充内容整合至案情描述

- 若用户补充或修改信息，则对第一步中的信息做出调整和补充至案情描述，再次向用户发起确认，直到案件信息确认和补充完毕

### 第三步：改写检索词并提取地域

- 改写 query：将整合后的完整案情按"query 改写规则"改写为法律检索关键词
- 提取 region：按"region 提取规则"从案情中提取地域，未提及地域则用"全国"
- 本步骤为内部处理，**不要向用户输出或展示改写后的关键词与地域**，静默完成后直接进入下一步

### 第四步：类案检索

告知用户正在进行类案检索，请稍后... 然后调用 `fbw_case_search` 工具，传入改写后的 query 与 region。

## 2、案例关键词检索流程

### 第一步：拆分用户问题关键词

对用户的原始问题做关键词拆分：提取案件核心行为、涉及主体等法律要素，转换为规范法律术语，用空格拼接为 query 参数。请勿将用户完整原句直接传入。

### 第二步：调用工具检索

将拆分后的关键词传入 `fbw_case_search_keywords` 工具的 `query` 参数进行检索。

### 第三步：返回关键词检索结果

以 markdown 格式返回检索到的案例关键词结果，便于用户进一步了解相关案例。

## 3、补充/更改检索条件流程

### 第一步：搜集需求

将用户补充的需求/调整的检索条件与历史需求/历史检索条件做整合。

### 第二步：确认信息完整

确认是否还有信息需要补充，若用户需要补充则追加至案件描述，重复该过程直到用户明确表示：没有了或进行类案检索。

### 第三步：改写检索词并提取地域

- 改写 query：将整合后的完整案情按"query 改写规则"重新改写为法律检索关键词
- 提取 region：按"region 提取规则"从整合后的案情中提取地域，未提及地域则用"全国"

### 第四步：类案检索

告知用户正在进行类案检索，请稍后... 然后重新调用 `fbw_case_search` 工具，传入改写后的 query 与 region。

## 终止性错误（收到即停，禁止绕过）

以下三类工具报错是面向用户的处理指令，不是可重试故障。工具返回后必须立即停止调用，不得自行处理：

- 「未检测到 API Key，请前往法保网 API 开放平台获取」
- 「API Key 无效或已过期，请前往法保网 API 开放平台确认账户状态」
- 「积分余额不足，请前往法保网 API 开放平台进行充值」

收到上述报错后禁止以下行为：

- 重试当前工具或修改参数后重试
- 调用其他工具复核该错误
- 绕过 MCP 工具调用，直接向服务端点发送底层 HTTP 请求

正确行为：将报错原文转告用户，等待用户在法保网 API 开放平台处理完毕后重新发起请求。

## 注意事项

- **工具选择**：用户需要相似案例正文/判决参考时使用 `fbw_case_search`；用户需要案例关键词时使用 `fbw_case_search_keywords`。**不适用于法规检索**（请使用法规检索工具）、**法院判决结果预测**（请使用裁判预测工具）

- **信息收集优先**：调用 `fbw_case_search` 前案情缺失时必须反问获取，请勿直接调用工具。全部信息收集完成后再触发工具调用

- **勿传用户原话**：`fbw_case_search` 的 query 必须是按改写规则转换后的法律检索关键词；`fbw_case_search_keywords` 的 query 必须是拆分后的关键词，均不能是用户的完整原话

- **不输出中间过程**：改写后的关键词与提取的地域属于内部检索条件，请勿在对话中向用户展示，仅告知"正在进行类案检索，请稍后..."

- **空结果处理**：若返回 relative\_case\_list / keyword\_list 为空，提示用户"未查到相关案例，请详细描述您的案情，重新检索"

- **鉴权说明**：本工具采用自填 API Key 模式鉴权，首次使用需在连接配置中填写法保网 API Key（在法保网 API 开放平台 https://lawyer.fabao.law/pc/#/mcp 获取）。若返回 msg 包含“积分余额不足”，直接将 msg 内容展示给用户即可（msg 已附带法保网充值地址）。若提示 API Key 无效、已过期或未检测到，属于终止性错误——立即停止调用并将报错原文转告用户，禁止重试或绕过，规则见上方「终止性错误」段。

- **结果展示**：类案检索结果建议以表格或列表形式展示案号、案由、裁判结果等关键字段，便于用户快速浏览；关键词检索结果建议以列表形式展示
