# 法保裁判预测 Skill

## 可用工具

### fbw_judgement_forecast - 裁判方向预测

基于1.6亿+司法裁判文书、百万级现行法律法规资源，通过多维解析案件事实、匹配海量历史判例，智能预判裁判结果，生成《裁判方向分析报告》。

**参数说明：**

| 参数名 | 类型 | 必填 | 描述 |
| --- | --- | :---: | --- |
| case_desc | string | 是 | 一句话案情描述。例如：员工因公司未支付加班费申请仲裁。若未提供需反问获取 |
| legal_position | string | 是 | 用户的法律立场。需从法律角度提炼用户角色立场，如：甲方、乙方、出租方、租赁方、借款方、出借方、受害人等。若未提供需反问获取 |
| supplement_info | string | 是 | 用户说的额外补充信息。未询问过此项不得提取，若缺失需反问获取 |

**返回字段：**

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| result | string | 裁判分析报告下载链接（生成成功）、空字符串（生成失败） |
| msg | string | 状态说明 |

## 预测流程

### 第一步：搜集需求

逐步向用户搜集以下信息：搜集的信息包括：案件描述、法律立场、补充信息

**注意**：若案情描述中可分析出用户所在的法律立场则自动获取，无需额外发问。

### 第二步：确认信息完整

向用户确认是否案情提供完整：
- 若用户告知已提供完整，则直接进入第三步
- 若用户补充或修改信息，则追加至案情描述，再次向用户发起确认，重复该过程直到用户明确表示：没有了或进行裁判预测

### 第三步：生成《裁判方向分析报告》

告知用户《裁判方向分析报告》生成中，需要3分钟左右，请耐心等待。然后调用 `fbw_judgement_forecast` 工具，传入 case_desc、legal_position 和 supplement_info。

## 补充或调整流程

如用户需要补充或调整已生成的报告：

### 第一步：获取修改需求
将用户补充的需求与历史需求做整合。

### 第二步：确认信息完整
确认是否还有信息需要补充，重复该过程直到用户明确表示：没有了或进行裁判预测。

### 第三步：重新生成报告
告知《裁判方向分析报告》生成中，需要3分钟左右，请耐心等待。然后重新调用 `fbw_judgement_forecast` 工具。

## 终止性错误（收到即停，禁止绕过）

以下三类工具报错是面向用户的处理指令，不是可重试故障。工具返回后必须立即停止调用，不得自行处理：

- 「未检测到 API Key，请前往法保网 API 开放平台获取」
- 「API Key 无效或已过期，请前往法保网 API 开放平台确认账户状态」
- 「积分余额不足，请前往法保网 API 开放平台进行充值」

收到上述报错后禁止以下行为：

- 重试当前工具或修改参数后重试
- 调用其他工具复核该错误
- 绕过 MCP 工具调用，直接向服务端点发送底层 HTTP 请求

正确行为：将报错原文转告用户，等待用户在法保网 API 开放平台处理完毕后重新发起请求。

## 注意事项

- **信息收集优先**：信息缺失时必须反问获取，请勿直接调用工具。全部信息收集完成后再触发工具调用
- **补充信息必问**：supplement_info 在调用前必须显式向用户询问"是否有额外补充信息"，未询问过不得提取
- **生成耗时**：报告生成约需3分钟，调用前需告知用户耐心等待
- **结果处理**：若返回 result 为下载链接，告知用户点击链接查看或下载《裁判方向分析报告》；若 result 为空，提示用户稍后重试
- **鉴权说明**：本工具采用自填 API Key 模式鉴权，首次使用需在连接配置中填写法保网 API Key（在法保网 API 开放平台 https://lawyer.fabao.law/pc/#/mcp 获取）。若返回 msg 包含“积分余额不足”，直接将 msg 内容展示给用户即可（msg 已附带法保网充值地址）。若提示 API Key 无效、已过期或未检测到，属于终止性错误——立即停止调用并将报错原文转告用户，禁止重试或绕过，规则见上方「终止性错误」段。
- **法律立场提炼**：legal_position 需从法律角度提炼，如用户说"我是被开除的员工"，应提炼为"劳动者/员工方"
