# 法保单方文书生成 Skill

## 可用工具

### fbw_correspondence_generation - 函告类单方文书生成

生成函件、告示类文书，如催款函、催告函、告知函、提醒函、确认函、变更函、索赔函、答复函等，返回Word文档下载链接。

**参数说明：**

| 参数名 | 类型 | 必填 | 描述 |
| --- | --- | :---: | --- |
| contrast_type | string | 是 | 函告类单方文书类型。如：催款函、催告函、告知函、提醒函、确认函、变更函、索赔函、答复函等。若未提供需反问获取 |
| correspondence_object | string | 是 | 发函对象。如：XXX公司、张三等。需具体到人名和组织名 |
| correspondence_background | string | 是 | 发函背景和具体诉求。如：XXX公司欠我100万长期赖着不还钱；施工方未按工期节点完工，工程质量存在瑕疵拒不返修等 |
| addition_information | string | 是 | 补充信息。如：款项需要打到我的银行账户，不要出现对我不利的说辞，没有了等。未询问过此项不得提取，若缺失需反问获取 |

**返回字段：**

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| status_code | number | 状态码，200 成功，422 参数缺失，500 服务异常 |
| msg | string | 状态说明 |
| result | string | 文档下载链接（成功）、空字符串（失败） |

### fbw_noncorrespondence_generation - 非函告类单方文书生成

生成非函告类单方文书，如遗嘱、欠条、情况说明、通知、借据、授权委托书、承诺书、声明等，返回Word文档下载链接。

**参数说明：**

| 参数名 | 类型 | 必填 | 描述 |
| --- | --- | :---: | --- |
| contrast_type | string | 是 | 单方文书类型（非函告类）。如：遗嘱、欠条、情况说明、通知、借据、授权委托书、承诺书、声明等。若未提供需反问获取 |
| contrast_content | string | 是 | 文书主要内容。如：通告所有居民小区绿化维护建设，近期可能停水；XXX经检验存在二级精神残疾；授权XXX员工代表XX企业驻场办公等 |
| addition_information | string | 是 | 补充信息。如：如果违反你公司规定需按你公司规章制度处理，所有风险由XXX公司承担，没有了等。未询问过此项不得提取，若缺失需反问获取 |

**返回字段：**

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| status_code | number | 状态码，200 成功，422 参数缺失，500 服务异常 |
| msg | string | 状态说明 |
| result | string | 文档下载链接（成功）、空字符串（失败） |

## 单方文书生成流程

### 第一步：获取待生成的单方文书类型

如：催款函、声明、遗嘱等。

### 第二步：根据文书类型选择不同搜集流程

#### 非函告类单方文书信息搜集流程

**注意**：非函告类单方文书包括遗嘱、借条、承诺书、授权委托书、声明、情况说明、借款借据、欠条、借款文书、借据、借条等

**(a)** 向用户询问待生成文书中需体现的主要内容（contrast_content）

> eg: 麻烦您详细告知下《{XXXX}》的主要内容，这将有助于我们为您起草更精准的法律文书

#### 函告类单方文书信息搜集流程

**注意**：函告类文书包括 XXX函、XXX通知、XXX告知等

**(a)** 确认发函对象（correspondence_object）

> eg：向您核实一下您的发函对象哈（需具体到人名和组织名，如：XXX公司，张三等）

**(b)** 向用户询问发函背景和具体诉求（correspondence_background）

> eg: 请详细说明本次发函的背景和具体诉求，这将有助于我们为您起草更精准的法律文书

### 第三步：询问是否有信息需要补充

> eg: 有什么需要补充的吗？

### 第四步：向用户确认是否信息提供完整

- 若用户告知已提供完整则直接进入第五步单方文书生成
- 若用户补充或修改信息，则对第二步中的信息做出调整和补充，再次向用户发起确认，直到文书生成信息确认完毕

### 第五步：生成单方文书

告知用户文书正在生成中，请稍后... 然后根据文书类型选择对应工具：

- **函告类**：调用 `fbw_correspondence_generation` 工具，传入 contrast_type、correspondence_object、correspondence_background 和 addition_information
- **非函告类**：调用 `fbw_noncorrespondence_generation` 工具，传入 contrast_type、contrast_content 和 addition_information

## 返回格式

- **生成成功**：告知用户《XXX》生成成功，提供下载链接
- **生成失败**：提示用户文书生成失败，请稍后重试

## 终止性错误（收到即停，禁止绕过）

以下三类工具报错是面向用户的处理指令，不是可重试故障。工具返回后必须立即停止调用，不得自行处理：

- 「未检测到 API Key，请前往法保网 API 开放平台获取」
- 「API Key 无效或已过期，请前往法保网 API 开放平台确认账户状态」
- 「积分余额不足，请前往法保网 API 开放平台进行充值」

收到上述报错后禁止以下行为：

- 重试当前工具或修改参数后重试
- 调用其他工具复核该错误
- 绕过 MCP 工具调用，直接向服务端点发送底层 HTTP 请求

正确行为：将报错原文转告用户，等待用户在法保网 API 开放平台处理完毕后重新发起请求。

## 注意事项

- **信息收集优先**：信息缺失时必须反问获取，请勿直接调用工具。全部信息收集完成后再触发工具调用
- **补充信息必问**：addition_information 在调用前必须显式向用户询问"是否有补充信息"，未询问过不得提取
- **文书分类**：函告类（催款函、催告函、告知函等）调 `fbw_correspondence_generation`；非函告类（遗嘱、欠条、声明等）调 `fbw_noncorrespondence_generation`
- **生成耗时**：文书生成需要几分钟，调用前需告知用户耐心等待
- **鉴权说明**：本工具采用自填 API Key 模式，首次使用需在连接配置中填写法保网 API Key（在法保网 API 开放平台 https://lawyer.fabao.law/pc/#/mcp 获取）。若返回 msg 包含"积分余额不足"，直接将 msg 内容展示给用户即可（msg 已附带法保网充值地址）。若提示 API Key 无效、已过期或未检测到，属于终止性错误——立即停止调用并将报错原文转告用户，禁止重试或绕过，规则见上方「终止性错误」段。
