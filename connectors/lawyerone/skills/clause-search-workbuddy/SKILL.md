# 法保法规检索 Skill

## 可用工具

### get_law_clause - 法律法规检索

依托百万级法规权威数据库，结合用户实际业务场景智能精准匹配，推送适配度最高的法律法规条文。

**参数说明：**

| 参数名 | 类型 | 必填 | 描述 |
| --- | --- | :---: | --- |
| query | string | 是 | 用户咨询的问题描述 |
| region | string | 否 | 所在地区省市，请勿到地级市。默认值：全国。如：浙江省杭州市、北京市、河北省石家庄市、全国等 |

**返回字段：**

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| status_code | number | 状态码，200 成功，500 服务异常 |
| msg | string | 状态说明 |
| clause_list | array | 相似法规列表（可能为空） |

### fbw_clause_search_keywords - 法规关键词检索

将用户问题拆分出的核心关键词作为输入，检索相关的法规关键词。

**参数说明：**

| 参数名 | 类型 | 必填 | 描述 |
| --- | --- | :---: | --- |
| query | string | 是 | 从用户问题中拆分出的核心搜索关键词，多个关键词以空格分隔 |

**关键词拆分原则：**

1. 去掉与法律检索无关的口语化表述
2. 提取案件核心行为（如"持刀抢劫"而非"我朋友拿刀抢了银行"）
3. 保留法律术语优先（如"盗窃"优于"偷东西"）
4. 关键词数量控制在 2-4 个

**拆分示例：**
- 用户问"我朋友持刀抢劫银行会被判几年" → 拆分传入 `持刀抢劫 银行`
- 用户问"公司拖欠工资怎么办" → 拆分传入 `拖欠工资`

**返回字段：**

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| status_code | number | 状态码，200 成功，500 服务异常 |
| msg | string | 状态说明 |
| keyword_list | array | 法规关键词列表（可能为空） |

## 1、法规检索流程

### 第一步：检索问题相关法律法规

检索前先对用户的原始问题做一句话概括，同时抽取出对应的省份城市（若无省份城市则取：全国）。然后根据概括后的 query 与抽取的 region 调用 `get_law_clause` 工具，获取相应区域的法律法规。

### 第二步：返回法规检索结果

以 markdown 格式返回所有与用户问题相关联的法规检索结果。

## 2、法规关键词检索流程

### 第一步：拆分用户问题关键词

对用户的原始问题做关键词拆分：提取核心行为、涉及主体等法律要素，转换为规范法律术语，用空格拼接为 query 参数。请勿将用户完整原句直接传入。

### 第二步：调用工具检索

将拆分后的关键词传入 `fbw_clause_search_keywords` 工具的 `query` 参数进行检索。

### 第三步：返回关键词检索结果

以 markdown 格式返回检索到的法规关键词结果，便于用户进一步了解相关法规。

## 终止性错误（收到即停，禁止绕过）

以下三类工具报错是面向用户的处理指令，不是可重试故障。工具返回后必须立即停止调用，不得自行处理：

- 「未检测到 API Key，请前往法保网 API 开放平台获取」
- 「API Key 无效或已过期，请前往法保网 API 开放平台确认账户状态」
- 「积分余额不足，请前往法保网 API 开放平台进行充值」

收到上述报错后禁止以下行为：

- 重试当前工具或修改参数后重试
- 调用其他工具复核该错误
- 绕过 MCP 工具调用，直接向服务端点发送底层 HTTP 请求

正确行为：将报错原文转告用户，等待用户在法保网 API 开放平台处理完毕后重新发起请求。

## 注意事项

- **工具选择**：用户需要法条正文时使用 `get_law_clause`；用户需要法规关键词时使用 `fbw_clause_search_keywords`。**不适用于案例相关问题或法院判决结果预测**，此类需求请使用类案检索或裁判预测工具
- **region 规范**：省和一级城市粒度，如"浙江省杭州市"、"北京市"，不到地级市。从用户原话中抽取，用户未提及地区则默认"全国"
- **勿传完整原句**：`fbw_clause_search_keywords` 的 query 必须是拆分后的关键词，不能是用户的完整原话
- **空结果处理**：若返回 clause_list / keyword_list 为空，提示用户"未查到相关法规，请修改问题内容后重新检索"
- **鉴权说明**：本工具采用自填 API Key 模式鉴权，首次使用需在连接配置中填写法保网 API Key（在法保网 API 开放平台 https://lawyer.fabao.law/pc/#/mcp 获取）。若返回 msg 包含“积分余额不足”，直接将 msg 内容展示给用户即可（msg 已附带法保网充值地址）。若提示 API Key 无效、已过期或未检测到，属于终止性错误——立即停止调用并将报错原文转告用户，禁止重试或绕过，规则见上方「终止性错误」段。
- **结果展示**：法规检索结果建议展示法规名称、条款编号、条款内容等关键字段，便于用户快速查阅；关键词检索结果建议以列表形式展示
