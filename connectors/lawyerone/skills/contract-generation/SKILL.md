# 法保合同生成 Skill

## 可用工具

### fbw_contract_generation - 合同文书生成

基于法律大模型与专业合同数据库，根据用户提供的合同类型、法律立场和生成需求，智能生成规范、专业、条款齐全的合同或协议，返回下载链接。

**参数说明：**

| 参数名 | 类型 | 必填 | 描述 |
| --- | --- | :---: | --- |
| contract_type | string | 是 | 合同类型。如：还款合同、合作协议、离婚协议、婚后协议、借款合同等。若未提供需反问获取 |
| legal_position | string | 是 | 用户所在的法律立场。如：甲方、乙方、出租方、租赁方、借款方、出借方、员工、男方等。若未提供需反问获取 |
| contract_content | string | 是 | 合同生成需求描述。如：我是张XX原告，我问我父亲借了点钱。注意：不能仅写"写一份XXX文书"作为主要内容，需包含具体需求。若未提供需反问获取 |

**返回字段：**

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| status_code | number | 状态码，200 成功，500 服务异常 |
| msg | string | 状态说明 |
| result | string | 合同下载链接（成功）、空字符串（失败） |

## 合同生成流程

### 第一步：搜集需求

逐步向用户搜集以下信息：
- **合同类型（contract_type）**：如借款合同、合作协议、劳动合同等
- **法律立场（legal_position）**：用户在合同中的角色（如甲方、乙方、出借方等）
- **合同生成需求（contract_content）**：合同的具体内容需求

注意：如果用户没有提供上述信息则需要反问获取，用户已提供则不再反问。

### 第二步：确认信息完整

向用户确认是否信息提供完整：
- 若用户告知已提供完整，则直接进入第三步
- 若用户补充或修改信息，则对第一步中的信息做出调整和补充，再次向用户发起确认，直到合同生成信息确认完毕

### 第三步：生成合同

告知用户合同/协议正在生成中，请稍后... 然后调用 `fbw_contract_generation` 工具，传入 contract_type、legal_position 和 contract_content，返回生成完的合同下载链接。

## 补充或调整需求重新生成流程

### 第一步：需求整合

将用户补充或调整的需求与历史需求做整合。

### 第二步：确认是否还有信息需要补充

若用户需要补充则追加至合同需求与内容。重复该过程直到用户明确表示：没有了或进行合同生成。

### 第三步：重新生成合同

告知用户合同/协议正在生成中，请稍后... 然后重新调用 `fbw_contract_generation` 工具。

## 返回格式

- **生成成功**：告知用户《XXX合同》生成成功，提供下载链接
- **生成失败**：提示用户合同生成失败，请稍后重试

## 终止性错误（收到即停，禁止绕过）

以下三类工具报错是面向用户的处理指令，不是可重试故障。工具返回后必须立即停止调用，不得自行处理：

- 「未检测到 API Key，请前往法保网 API 开放平台获取」
- 「API Key 无效或已过期，请前往法保网 API 开放平台确认账户状态」
- 「积分余额不足，请前往法保网 API 开放平台进行充值」

收到上述报错后禁止以下行为：

- 重试当前工具或修改参数后重试
- 调用其他工具复核该错误
- 绕过 MCP 工具调用，直接向服务端点发送底层 HTTP 请求

正确行为：将报错原文转告用户，等待用户在法保网 API 开放平台处理完毕后重新发起请求。

## 注意事项

- **信息收集优先**：信息缺失时必须反问获取，请勿直接调用工具。全部信息收集完成后再触发工具调用
- **contract_content 要求**：需包含具体需求内容，不能仅写"写一份借款合同"这样的标题式描述
- **生成耗时**：合同生成需要几分钟，调用前需告知用户耐心等待
- **结果处理**：若返回 result 为下载链接，告知用户点击链接下载合同；若 result 为空，提示用户稍后重试
- **鉴权说明**：本工具采用自填 API Key 模式，首次使用需在连接配置中填写法保网 API Key（在法保网 API 开放平台 https://lawyer.fabao.law/pc/#/mcp 获取）。若返回 msg 包含"积分余额不足"，直接将 msg 内容展示给用户即可（msg 已附带法保网充值地址）。若提示 API Key 无效、已过期或未检测到，属于终止性错误——立即停止调用并将报错原文转告用户，禁止重试或绕过，规则见上方「终止性错误」段。
