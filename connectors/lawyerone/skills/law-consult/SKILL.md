# 法保法律咨询 Skill

## 可用工具

### fbw_consult - 法律咨询

根据用户法律问题，检索相关法律法规、司法解释、规章制度，从多角度援引法规进行详尽法律分析与回复。结论前置、法言法语、客观公正。

**参数说明：**

| 参数名 | 类型 | 必填 | 描述 |
| --- | --- | :---: | --- |
| query | string | 是 | 用户有关法律、政策、法规、流程、规章制度、时政热点等有事实意义的业务问题。例如：打架斗殴最高会被判处几年？行政复议流程是什么？ |
| region | string | 否 | 中国省市，注意：省和一级城市，如：浙江省杭州市、北京市、山西省大同市、江苏省、重庆市等。默认值：全国 |

**返回字段：**

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| status_code | number | 状态码，200 成功，422 参数缺失，500 服务异常 |
| msg | string | 状态说明 |
| return_message | string | AI法律咨询回复内容（成功）、空字符串（失败） |

## 法律咨询流程

### 第一步：问题概括与地区抽取

检索前先对用户的原始问题做一句话概括，同时抽取出对应的省份城市（若无省份城市则取：全国）。

### 第二步：完成法律咨询

根据概括后的 query 与抽取的 region 调用 `fbw_consult` 工具，返回法律咨询回复。

## 返回格式

- **咨询成功**：将 return_message 内容直接回复用户
- **咨询失败**：提示用户"AI法律咨询流量高峰，请稍后再试"

## 终止性错误（收到即停，禁止绕过）

以下三类工具报错是面向用户的处理指令，不是可重试故障。工具返回后必须立即停止调用，不得自行处理：

- 「未检测到 API Key，请前往法保网 API 开放平台获取」
- 「API Key 无效或已过期，请前往法保网 API 开放平台确认账户状态」
- 「积分余额不足，请前往法保网 API 开放平台进行充值」

收到上述报错后禁止以下行为：

- 重试当前工具或修改参数后重试
- 调用其他工具复核该错误
- 绕过 MCP 工具调用，直接向服务端点发送底层 HTTP 请求

正确行为：将报错原文转告用户，等待用户在法保网 API 开放平台处理完毕后重新发起请求。

## 注意事项

- **不适用场景**：用户咨询案例相关问题（如"帮我分析一下这个案件"）或法院判决结果预测时请勿调用此工具，应使用类案检索或裁判预测工具
- **region 规范**：省和一级城市粒度，如"浙江省杭州市"、"北京市"，不到地级市。从用户原话中抽取，用户未提及地区则默认"全国"
- **鉴权说明**：本工具采用自填 API Key 模式鉴权，首次使用需在连接配置中填写法保网 API Key（在法保网 API 开放平台 https://lawyer.fabao.law/pc/#/mcp 获取）。若返回 msg 包含“积分余额不足”，直接将 msg 内容展示给用户即可（msg 已附带法保网充值地址）。若提示 API Key 无效、已过期或未检测到，属于终止性错误——立即停止调用并将报错原文转告用户，禁止重试或绕过，规则见上方「终止性错误」段。
