# 教案 JSON 结构说明

教案 JSON 由 `render_lesson` 工具消费（服务端引擎渲染 Word docx），顶层两个键：`meta` 和 `sections`。

## meta — 封面信息

```json
{
  "meta": {
    "title": "《天地人》教学设计（两课时）",   // 必填，大标题（也是默认文件名）
    "subtitle": "统编版小学语文 · 一年级上册 ...",  // 可选，副标题
    "footer": "页脚左侧文字",                  // 可选，默认取 title
    "author": "教学备课",                      // 可选，文档元数据
    "info": [                                  // 可选，封面信息表（左标签右内容）
      ["课　　题", "识字 1　《天地人》"],
      ["课　　型", "识字课（新授课）"],
      ["课　　时", "2 课时（每课时 40 分钟）"]
    ]
  }
}
```

`info` 表格的标签列宽默认 30mm，可按需在 section 里覆盖。

## sections — 正文块（按顺序渲染）

**必填标注（2026-10-17 起）**：字段标「必填」的缺失会被 `render_lesson` 发送前预检拒绝（报出具体板块位置，按报错补齐即可）；`type` 不在下列十种之内的板块引擎会静默丢弃，预检同样拦下。除标注「必填」外其余字段均可省略。

### 1. `heading` — 小标题

```json
{ "type": "heading", "text": "教学目标" }
```

`text` 必填。

### 2. `info` — 信息表（带标题）

适合：教材分析、学情分析、教学目标、重难点、教学准备、作业与评价。

```json
{
  "type": "info",
  "title": "教学目标",
  "label_w": 30,
  "rows": [
    ["语言积累", "1. 认读 6 个生字…<br />2. 能配对…"],
    ["思维发展", "3. 体会象形…"]
  ]
}
```

`title` 必填；`rows` 必填（每行为 `[标签, 内容]` 两元素数组）；`label_w` 可选（标签列宽 mm）。

### 3. `band` — 章节色块标题

适合：`第一课时`、`第二课时`、`板书设计` 这种大分隔。

```json
{ "type": "band", "text": "第一课时　认读汉字（40 分钟）", "color": "accent" }
```

`text` 必填；`color` 可选：`accent`(赭石·默认) / `ink` / `green` / `dark`。

### 4. `phases` — 教学过程时间轴（核心块）

```json
{
  "type": "phases",
  "rows": [
    {
      "time": "12′",
      "name": "二、分层识字\n先人后天地",
      "items": [
        "1. 学「人」字（6 分钟）",
        "（1）出示字卡，教师范读…",
        "【核心提问】「这个字哪里像人？」",
        "【设计意图】「人」字形象感最强…"
      ]
    }
  ]
}
```

- `rows` 必填；每行的 `time` / `name` / `items` 必填。
- `time`：时长，写 `3′` `12′` 这样。
- `name`：环节名，`\n` 会被识别为**块内换行**。
- `items`：逐条内容，**字符串数组**。**以「【设计意图」开头的条目会自动用小字灰字排版**，用于区分正文与意图说明。
- 段落里的换行用 `<br />`，加粗用 `<b>`。

### 5. `board` — 板书设计

```json
{
  "type": "board",
  "spec": {
    "title": "《天地人》",
    "blocks": [
      { "tag": "（上）", "char": "天", "color": "accent", "bg": "accent_l" },
      { "tag": "（中）", "char": "人", "color": "ink",    "bg": "grey" },
      { "tag": "（下）", "char": "地", "color": "green",  "bg": "grey" }
    ],
    "right": {
      "sections": [
        { "title": "人称三兄弟", "kai": true,  "lines": ["我 —— 说话的人"] },
        { "title": "识字小提示", "kai": false, "lines": ["· 「人」：一撇一捺"] }
      ]
    }
  }
}
```

- `spec` 必填（`spec.title` / `blocks` / `right` 均可整体省略）。
- `blocks`：左侧竖排大字（每个 40mm 宽的楷体方框），适合生字板书——**生字板书用这里的 `blocks`（`char` 必填，`tag` / `color` / `bg` 可选），没有独立的 `characters` 板块类型**。
- `right.sections[].title` 必填（`kai` / `lines` 可选）；`kai`：`true` 用楷体（大些），`false` 用小号宋体。
- `color` / `bg` 取值同 `band` 的色名。

### 6. `rubric` — 评价量规

```json
{
  "type": "rubric",
  "title": "课堂评价量规",
  "head": ["评价维度", "★ 达成", "☆☆ 待加强"],
  "rows": [
    ["认读正确", "6 个生字全部读准", "3～5 个读准"],
    ["表达运用", "能说完整通顺的句子", "需教师引导"]
  ]
}
```

`title` / `head`（表头，非空数组，**2–8 列**——预检约束）/ `rows` 必填。3 列时自动用 `[28, 69, 69]mm`；其它列数等分（问题化单元目标 4 列表即用此泛化）。

### 7. `text` — 段落（标题 + 小字正文）

适合：教学反思提示、附注、数据来源留痕块。

```json
{ "type": "text", "title": "教学反思提示", "text": "① …<br />② …" }
```

`title` / `text` 必填——留痕块等无标题场景也要给个标题（如「数据来源与 AI 辅助」），省略会被预检拒绝。

### 8. `pagebreak` — 强制分页

```json
{ "type": "pagebreak" }
```

### 9. `qsystem` — 问题系统（问题化教案专用）

核心问题＋有序子问题链，两级结构（核心→子问题，不递归）。单元级（unit）用于
「00-单元问题系统」的单元核心问题＋课时分配；课时级（lesson）用于课时问题系统。

```json
{
  "type": "qsystem",
  "variant": "lesson",
  "core": { "text": "作者为什么把秋雨写得像一把钥匙？", "anchor": "课标：文学阅读与创意表达 · 素养：审美创造" },
  "chain": [
    { "text": "秋雨「像钥匙」打开了什么？", "node_id": "chinese_2a_tbb_cpt12" },
    { "text": "这把「钥匙」带来了哪些秋天的色彩与气味？", "node_id": "chinese_2a_tbb_cpt13" }
  ]
}
```

- `variant`（必填）：`unit` | `lesson`。
- `core.text` / `core.anchor` 必填——`anchor` 为课标/素养注记字符串（渲染为小字注）。
- `chain` 必填（非空数组）；每项 `text` 必填，`node_id` 在 **lesson 变体必填**
  （unit 变体可省——单元层子问题按课时分配，锚在课时层落）。
- 渲染：核心问题带底色块＋anchor 小字注，子问题链按序号 Q1/Q2… 列出，node_id 以小字缀于条目后（教研留痕）。

### 10. `qactivity` — 问题化教学过程三栏表（问题化教案专用）

每活动一行三栏：活动 × 互动解问 × 问题化学习力＆学科素养（对应校方模板「学与教过程」表）。

```json
{
  "type": "qactivity",
  "rows": [
    {
      "name": "活动一　整体感知，找到那把「钥匙」",
      "solve": { "text": "秋雨「像钥匙」打开了什么？", "chain_idx": 0 },
      "goal": "能找出全文围绕「钥匙」展开的语句并说出钥匙打开的内容",
      "steps": ["自读圈画：钥匙打开了什么", "同桌互查圈画结果", "全班交流，教师板贴关键词"],
      "interaction": {
        "difficulty": "学生已会找比喻句，但「风怎么能是钥匙」的冲突点说不清",
        "student_questions": ["老师，风又不是钥匙，这不是写错了吗？", "为什么不说秋风很凉快，要说像钥匙？"],
        "guidance": { "text": "「你比较了两种说法，很好。那『钥匙』能做什么，『凉快』能做什么？」", "responds_to": [1] }
      },
      "powers": [
        { "power": "发现力", "level": "A", "competency": "审美创造" },
        { "power": "建构力", "level": "B", "competency": "思维能力" }
      ]
    }
  ]
}
```

- `rows` 必填（非空数组）；每行 `name` / `solve` / `goal` / `steps` / `interaction` / `powers` 必填。
- `solve.chain_idx` 必填：指向**同一 plan 内** lesson 变体 `qsystem.chain` 的序号（0 起）——
  跨板块完备性预检据此校验（链上无孤儿：每条子问题至少被一个活动解决）。
- `interaction.student_questions`：**≥2 条**学生原话（渲染器自动加「预设①」编号与「」引号，契约内存原文）；`guidance.responds_to`：非空、指向预设序号数组（0 起，渲染为「回应①/②」标注）。
- `powers[].power`：五力枚举（发现力/建构力/解决力/反思力/设计力）；`level`：A/B/C/D；
  `competency`：匹配学科素养（来自知识点能力上溯）。水平级回溯
  lesson-prep 技能 `references/question-powers.md` 条目编号（编号记在备课产物，不进本契约）。
- 三栏列宽固定 40%/35%/25%，超长文本自动缩字号。

## 排版提示

- **不要每节前手动加 `pagebreak`**：引擎已自动留 4mm 间距，只在「换课时/换大板块」处显式分页即可，避免出现半空白页。
- 单行内容宽度上限约 **121mm**；超过会自动折行，不会溢出。
- 引擎已自动处理：页脚（左侧文字 + 右侧页码）、页码计数、字体嵌入（KaiTi/SimHei/SimSun）。

## 色名对照

| 色名 | 用途 |
|---|---|
| `accent` | 赭石色，主强调（章节块、标签底色） |
| `ink` | 近黑，正文 |
| `green` | 墨绿，用于对比项（如"地"） |
| `grey` | 浅灰底 |
| `accent_l` | 浅赭石底（信息表标签列） |
| `dark` | 深灰（表格表头） |
