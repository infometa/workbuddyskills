# 问题化教学设计方法论：问题证据链＋教师引导问题顺势生成三步法

> 问题化模式的**内容方法论单一主存储**。三个来源支撑一切问题设计：
> 知识图谱（lesson_context / kg_dependencies / kg_std_items / kg_ability_profile）、
> 《问题化学习能力目标》结构化资产（`question-powers.md`）、本文件的顺势生成三步法。
> 渲染契约（qsystem/qactivity 板块）见 lesson-plan 技能 `references/schema.md`。

## 一、问题证据链——治「为提问而提问」

每个问题（单元核心问题、课时核心问题、子问题、教师引导问题）都必须携带**证据四元组**：

```
问题 = 文本
     + 服务知识点 node_id（图谱真实节点，非虚构）
     + 课标 code（kg_std_items 可回查原文）
     + 素养/能力上溯（builds_to→Ability→Competency，kg_ability_profile 生成）
     + 〔仅教师引导问题〕顺势点依据：它回应哪条预设学生问题、卡在哪个前置知识缺口
```

三条「性」的落地判据：

| 性 | 判据 | 违反即 |
| --- | --- | --- |
| **价值性** | 挂 importance 高的知识点或课标锚定条目，且出现在目标↔问题↔知识点↔素养映射表中 | 删掉不影响课堂＝装饰性问题 |
| **学科性** | 问题措辞从知识点 definition/知识本质出发（分学科要点见 §四），不是任何课都能问的流程套话 | 「同学们发现了什么？」式通用问 |
| **生成性** | 教师引导问题挂顺势点——回应预设学生问题，出现在学生「疑得到、够不着」处 | 凭空硬抛 |

**锚点纪律**：四元组必须来自图谱工具真实返回；找不到锚点 → 产物标注「待锚定」并
`report_gap`，绝不生成不存在的 node_id/code。修订案的映射表（目标↔知识点映射表，
问题化模式扩展两列）无空锚。

## 二、顺势生成三步法——教师引导问题的产生方式

每个活动（= 从前置知识 X 到目标知识 Y 的一次跨越）按三步产出互动解问三件套：

### 第①步 学生困难预判（定位顺势点）

沿 `lesson_context.prerequisites` 前序链（含跨册 dist/book）找 X→Y 边界上的缺口——
学生**疑得到、够不着**的地方。三种典型顺势点：

- **认知冲突点**：已有经验/前序结论与新知识表面矛盾（「之前学的都是……怎么这里……？」）
- **方法缺口点**：目标达成的路径学生还没掌握（知道要做什么，不知道怎么下手）
- **表征转换点**：同一对象换一种表征就卡壳（文字→图形、口语→符号、具体→一般）

供数：`sibling_lessons`＝学生已学起点；单元习题（`kg_anchor_exercises`）＝易错证据；
**前置链为空**时按返回体 `fallback_hint` 降级（同单元前课＋单元语文要素推导），
产物明示「降级推导」并留痕——不自行编造降级策略。

### 第②步 学生提问追问预设（≥2 条具体话术）

在顺势点上推演学生此刻会问什么、卡在哪。**写学生原话**，不写抽象描述
（✗「学生可能对写法有疑问」 ✓「老师，这里为什么不用比喻，偏要用拟人？」）。
水平可参照五力资产的发现力条目（1.1–1.5）判断学生当前能问到哪一层。

### 第③步 教师引导及回应策略（回应式点拨）

引导问题＝**对预设学生问题的回应式点拨**——接住学生的问题，再往前推一步，
不是另起炉灶抛新问。每条引导必须标注回应的是第几条预设（回应①/②）。
话术规范遵守 lesson-plan 技能 `design-principles.md` §三「给话术，不给指示」，
顺势句式见其 §三扩充（认知冲突式/递进追问式/错误资源化）。

**正反对照（语文·写景单元「金色秋天」语境，示例课例，待教研复核）**：

- ✗ 硬抛：活动推进到品析环节，教师突然问「作者用了什么修辞手法？有什么好处？」
  ——与学生的困惑无衔接，为问而问；
- ✓ 顺势：学生刚学会「景物要选典型的」(前序)，读到「秋风像一把钥匙」卡在
  「为什么说像钥匙——风怎么能是钥匙？」（预设②）——教师顺势：
  「你抓到了一个『像』字——那这把『钥匙』打开了什么？打开之前和之后，文章的颜色
  有什么不一样？」（回应②，推向「比喻承载的变化感」这一目标知识点）。

## 三、问题系统的图谱对齐

- **单元核心问题**：从单元学习重点（课标锚＋单元要素）提炼；单元问题系统按
  sibling_lessons 课时结构把核心问题分解到各课时子问题集。
- **课时问题系统**：子问题集合＝本课 Knowledge 集，**排序对齐 `prerequisites_for`
  拓扑**（先解决的子问题＝后者的前置知识）——「子问题逐步推进最终解决核心问题」
  由依赖图的拓扑序保证。
- **每活动解决一个子问题**（qactivity 的 solve 字段指向链上序号）；
  无活动消费的子问题＝装饰性子问题，渲染预检会拦。
- **五力勾选**：每个活动的五力栏给「力＋水平级＋匹配素养」，水平级回溯
  `question-powers.md` 条目、素养取该活动知识点的能力上溯——不凭空编造。

## 四、分学科话语要点与示例（各一完整活动三件套，示例课例，待教研复核）

### 语文（写景单元「金色秋天」· 品析意象活动）

- **学科性审核要点**：问在**文本张力点**——修辞与表达效果、用词的精确性、
  情感与景物的关系；不问「课文写了什么」这类复述型流程问。
- 困难预判：学生已会找比喻句（前序），但「为什么这里用比喻而不用直说」卡在
  修辞与表达意图的关联（方法缺口点）。
- 学生预设：①「老师，说秋风像钥匙，风又不是钥匙，这不是写错了吗？」
  ②「为什么不说秋风很凉快，要说像钥匙？」
- 引导及回应：回应②——「你比较了两种说法，很好。那『钥匙』能做什么，『凉快』
  能做什么？课文里这把钥匙打开了什么？（预设：打开了秋天的门／带来了秋天的色彩）」
  ——把「为什么用比喻」推向「比喻承载了变化与开启的意味」。
- 五力：发现力（√）A「敢于提出自己真实的困惑 1.1.2」；建构力（√）B「能将问题排个序
  2.2.2」；匹配素养：审美创造（经知识点能力上溯）。

### 数学（一元一次方程应用· 行程问题活动）

- **学科性审核要点**：问在**问题化归**的关键步——从实际情境到方程模型的转化处
  （设元、找等量关系），不问「答案是多少」这类终点问。
- 困难预判：学生会算术解（前序），面对「顺流/逆流速度不同」找不到等量关系
  （表征转换点：文字情境→等量关系）。
- 学生预设：①「老师，我不知道该设哪个为 x。」②「为什么来回的路程是一样的？」
- 引导及回应：回应②——「你来画线段图把『去』和『回』各画一条，路程标上去——
  你发现了什么相等？（预设：两条线段一样长）那这个『相等』就是你方程两边。」
  ——把「找不到等量关系」推向「线段图显化等量关系」。
- 五力：解决力（√）B「用学过的方法解决老问题 3.2.1」；反思力（√）C；匹配素养：模型意识。

### 英语（阅读课· 推断作者观点活动）

- **学科性审核要点**：问在**支架链**的台阶处——从字面理解到推断、从句式到语篇，
  用 target language 提问的比重随学段递增；不问中文翻译式检查问。
- 困难预判：学生能定位细节（前序），但「作者没直接说的态度」推断不出来
  （方法缺口点：clue words → inference）。
- 学生预设：①「The writer doesn't say if he likes it. How can we know?」
  ②「Why does the writer use the word “just” here?」
- 引导及回应：回应①——「Writers show feelings, not always tell. Find the words
  that show — is “quiet” a happy word or a lonely word here?（预设：lonely）So the
  feeling is…」——把「没有直接说」推向「showing words 证据链」。
- 五力：发现力（√）B 1.3.1；解决力（√）C 3.3.3；匹配素养：思维品质。

## 五、与既有流程的衔接（lesson-prep 问题化模式）

- 单元问题系统规划（`00-单元问题系统.md`）先于课时规划；三位一体问题、课时问题
  系统进课时产物（机读标题见 `school-templates/_default/统一备课用纸-问题化.md`）。
- AI 研讨第⑦视角「问题三性」逐问题查证据链：无锚/伪问题（答案为是/不是的封闭问、
  删掉无影响的装饰问）点名并给补锚建议。
- 修订案的目标↔知识点映射表扩展两列：`问题（类别）` 与 `回应的预设`
  （仅教师引导问题行填），即目标↔问题↔知识点↔素养四向可审计。
