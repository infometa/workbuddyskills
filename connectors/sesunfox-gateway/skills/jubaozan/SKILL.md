# 聚宝赞数据查询

通过本连接器可用自然语言查询聚宝赞平台的业务数据。所有工具均返回分页结构 `{records, total}`。

## 工具清单

| 工具 | 用途 | 关键说明 |
|---|---|---|
| `orders.search` | 搜索订单 | 支持订单号 / 买家昵称 / 状态 / 下单时间范围过滤 |
| `goods.page` | 商品分页 | 支持名称 / 价格区间 / 商品类型过滤 |
| `stores.page` | 门店列表 | 不接受分页/过滤参数，固定返回前 10 条 |
| `coupons.page` | 优惠券模板 | **pageSize 必须 ≥ 2**；支持名称 / 状态过滤 |
| `refunds.page` | 退款单 | 支持退款单号 / 状态 / 买家昵称 / 商品名过滤 |
| `liverooms.list` | 直播间列表 | 支持标题 / 直播状态过滤 |
| `inventory.search` | 云仓库存 | 分页参数为 `current` / `size`；可按仓库编码过滤（如 `WH-CENTER-00000003`） |

## 使用要点

- 分页从第 1 页开始；用户未指定页码时默认查第 1 页，总数大时告知用户 `total` 并提示可翻页。
- 时间范围参数用开始/结束两个字段表达，用户说「昨天 / 最近一周」时自行换算成具体时间。
- 查询无结果时如实告知「没有查到数据」，不要编造。
- 每个应用（client_id）可用的工具范围由网关管理员分配；收到「Permission denied」说明该工具未授权，应提示用户联系管理员。
- 工具返回的 JSON 里 `records` 为记录数组，直接基于其中的字段回答（如订单号、买家昵称、金额、状态），不要原样粘贴整段 JSON。
