# 商品参数设置

本文档覆盖商品系统全局参数设置接口，用于查询商品基础配置信息。

## 接口目录
- [productSetting](#productsetting) - 获取商品设置（含价格等级、辅助单位、展示分类等全局开关）

---

## productSetting

**功能**：查询商品系统的全局参数设置，包含特殊授权开关、辅助计量单位、展示分类、价格等级等配置信息。

**典型场景**
- 查看当前系统是否启用了特殊授权功能
- 获取商品重量计量单位、辅助计量单位等基础参数
- 查看当前是否启用了展示分类状态
- 查看商品价格等级列表，获取各等级的启用状态和序号

**参数**
- 无参数（直接查询当前机构商品设置）

**响应数据**
- 返回类型：`OBJECT`

| 字段 | 类型 | 说明 |
|------|------|------|
| enabledSingleOrgAuth | BOOLEAN | 是否启用特殊授权 |
| authorizationSkuCount | NUMBER | 授权方案中可设置的sku数量 |
| comboSkuDetailsCount | NUMBER | 套餐商品中明细的最大上限制 |
| weightUnit | STRING | 商品重量计量单位 |
| privateProductSwitch | BOOLEAN | 是否允许门店管理私有商品【默认允许】 |
| auxUnitSetting | BOOLEAN | 是否启用辅助计量单位设置 |
| enabledShowCategory | BOOLEAN | 是否启用展示分类 |
| levelSetting | OBJECT | 价格设置 |
| levelSetting.priceLevels[].id | NUMBER | 价格等级id |
| levelSetting.priceLevels[].name | STRING | 价格等级名称 |
| levelSetting.priceLevels[].status | NUMBER | 是否启用（1=未启用,2=启用） |
| levelSetting.priceLevels[].levelIndex | NUMBER | 价格索引序号（0=基准订货价/市场价） |
| levelSetting.priceLevels[].type | NUMBER | 价格等级类型 |
| levelSetting.priceLevels[].unlimitedPrice | NUMBER | 级别不限调价范围价（0=限制,1=不限） |
