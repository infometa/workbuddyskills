# 等级订货价

本文档覆盖订货价格等级查询接口，用于新建客户/设置定价时获取可用的价格等级 ID。

## 接口目录
- [priceLevelList](#priceLevelList) - 查询指定机构启用的订货价格等级

---

## priceLevelList

**功能**：查询指定机构下已启用的订货价格等级列表，返回等级 ID、名称、序号等信息。

**典型场景**
- 新建客户时，填写 `priceModeInfo.priceLevelId`（定价方式为分销订货价时必填）
- 查看当前系统配置了哪些价格等级

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| orgId | NUMBER | 是 | 否 | 机构ID，路径参数 |

**响应数据**
- 返回类型：`ARRAY`（数组）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | NUMBER | 价格等级ID（用于 `priceLevelId` 入参） |
| name | STRING | 价格等级名称 |
| status | NUMBER | 启用状态（1=未启用，2=启用） |
| levelIndex | NUMBER | 价格索引序号（0=基准订货价/市场价，其余为自定义等级） |
| type | NUMBER | 价格等级类型 |
| unlimitedPrice | NUMBER | 是否不限调价范围（0=限制，1=不限） |
