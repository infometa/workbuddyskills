# 商品基础数据

本文档覆盖商品相关基础查询接口，包含商品列表、商品分类、商品品牌、商品标签。

## 接口目录
- [productList](#productlist) - 查询商品列表（按名称/编码/品牌/分类/状态筛选）
- [findOrderCustomerSku](#findordercustomersku) - 代客户下单商品列表（SKU级，含客户专属价格与库存）
- [productCategoryList](#productcategorylist) - 商品分类列表（获取所有分类树）
- [productShowCategoryList](#productshowcategorylist) - 展示分类列表（获取所有展示分类）
- [productBrandList](#productbrandlist) - 商品品牌列表（获取所有品牌）
- [productTagList](#producttaglist) - 商品标签列表（获取所有标签）

---

## productList

**功能**：查询商品列表(SKU)，支持按名称、编码、品牌、分类、标签、状态等多维度筛选。

**典型场景**
- 查找某个商品是否存在及其ID
- 查看指定品牌/分类下的商品
- 查询某状态（停售/正常）的商品
- 需要商品ID才能执行下游统计时，先用此接口获取ID

**参数**

| 参数               | 类型     | 必填 | 数组 | 说明                                        |
|------------------|--------|----|----|-------------------------------------------|
| q                | STRING | 否  | 否  | 商品名称/编码/简称关键词，模糊搜索                        |
| brandIds         | NUMBER | 否  | 是  | 品牌ID数组，需先用 productBrandList 获取ID          |
| tagIds           | NUMBER | 否  | 是  | 标签ID数组，需先用 productTagList 获取ID            |
| showCategoryCode | STRING | 否  | 是  | 商品展示分类编码，需先用 productShowCategoryList 获取编码 |
| categoryCode     | STRING | 否  | 是  | 商品分类编码，需先用 productCategoryList 获取编码       |
| statuses         | NUMBER | 否  | 是  | 商品状态数组，1=正常,2=停采,3=淘汰,4=停售                |
| shelfStatuses    | NUMBER | 否  | 是  | 商品上架状态数组，1=上架,2=下架,0=无效                   |
| types            | NUMBER | 否  | 是  | 商品类型数组，1=普通商品,2=套餐商品                      |

**响应数据**
- 返回类型：`PAGE`（分页）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | NUMBER | 商品ID（用于下游接口） |
| spuId | NUMBER | SPU ID |
| name | STRING | 商品名称 |
| code | STRING | 商品编码 |
| multiUnitId | NUMBER | 基础单位id |
| baseUnitName | STRING | 基础单位 |
| shortCode | STRING | 简称 |
| spec | STRING | 商品规格 |
| brandId | NUMBER | 品牌ID |
| categoryId | NUMBER | 分类ID |
| status | NUMBER | 商品状态（1=正常,2=停采,3=淘汰,4=停售） |
| type | NUMBER | 商品类型（1=普通商品,2=套餐商品） |
| enableMultiUnit | BOOLEAN | 是否是多单位 |
| multiUnitList | ARRAY | 多单位列表 |
| multiUnitList[].id | NUMBER | 多单位id |
| multiUnitList[].unitName | STRING | 单位名称 |
| multiUnitList[].rate | NUMBER | 换算率 |
| multiUnitList[].barcode | STRING | 条码 |
| multiUnitList[].supplierPrice | NUMBER | 基准进货价 |
| multiUnitList[].basePrice | NUMBER | 基准订货价(市场价) |
| multiUnitList[].minimumPrice | NUMBER | 最低限价 |
| multiUnitList[].maximumPrice | NUMBER | 最高限价 |
| multiUnitList[].levelPrices | ARRAY | 分销级别订货价 |
| multiUnitList[].levelPrices[].index | NUMBER | 分销级别价索引值(`priceLevelList`) |
| multiUnitList[].levelPrices[].price | NUMBER | 等级价格 |
| enableAuxUnit | BOOLEAN | 是否是辅助单位 |
| auxUnit | OBJECT | 辅助单位 |
| auxUnit.id | NUMBER | 辅助单位id |
| auxUnit.unitName | STRING | 单位名称 |
| auxUnit.rate | NUMBER | 换算率 |
| offShelfTime | DATETIME | 下架时间 |
| onShelfTime | DATETIME | 上架时间 |
| origin | STRING | 产地 |
| weight | NUMBER | 重量 |
| qualityGuaranteePeriod | NUMBER | 保质期 |
| qualityGuaranteePeriodUnit | NUMBER | 保质期单位（1=天,2=个月,3=年） |
| createTime | DATETIME | 创建时间 |
| modifyTime | DATETIME | 修改时间 |
| stockVerify | NUMBER | 校验库存（0=跟随系统,1=校验库存,2=不校验库存） |
| taxRate | NUMBER | 销项税率 |
| tagIds | ARRAY | 商品标签ID数组 |
| tagNames | ARRAY | 商品标签名称数组 |

**组合示例**：查询"停售的某品牌商品" → 先用 `productBrandList` 获取品牌ID，再用 `productList` 传 `brandIds` + `statuses=[4]`

## findOrderCustomerSku

**功能**：代客户下单时查询可购商品列表（SKU粒度），结果基于客户的授权方案过滤，并包含客户专属价格、促销信息及库存数据。

**典型场景**
- 代客户创建订单时，按客户ID获取其可购商品列表
- 需要查看某个客户有哪些商品在售、当前库存情况
- 按品牌/分类/关键词搜索客户可订商品

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| targetId | NUMBER | 是 | 否 | 客户组织ID |
| q | STRING | 否 | 否 | 商品名称/编码/条码/规格/简称，模糊搜索 |
| categoryCode | STRING | 否 | 是 | 商品分类编码数组，需先用 productCategoryList 获取 |
| brandIds | NUMBER | 否 | 是 | 品牌ID数组，需先用 productBrandList 获取 |
| tagIds | NUMBER | 否 | 是 | 标签ID数组 |
| statuses | NUMBER | 否 | 是 | 商品状态数组 |
| shelfStatuses | NUMBER | 否 | 是 | 商品上架状态数组，1=上架,2=下架,0=无效 |
| types | NUMBER | 否 | 是 | 商品类型数组，1=普通商品,2=套餐商品 |
| warehouseId | NUMBER | 否 | 否 | 仓库ID，配合 hasAvailableCount 筛选有库存商品，未选择仓库或选择全部仓库时传-1 |
| hasAvailableCount | BOOLEAN | 否 | 否 | 只查有可用库存商品，仅能传true，需同时传 warehouseId |
| ignoreAuthorization | BOOLEAN | 否 | 否 | 忽略授权方案限制，查看所有在售商品 |
| loadComboPrice | BOOLEAN | 否 | 否 | 是否加载组合商品明细市场价，true=加载，false=不加载 |
| currentPage | NUMBER | 否 | 否 | 当前页码，默认1 |
| pageSize | NUMBER | 否 | 否 | 每页条数，默认20 |

**响应数据**
- 返回类型：`PAGE`（分页）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | NUMBER | SKU ID（用于下游创建订单传商品明细） |
| spuId | NUMBER | SPU ID |
| code | STRING | 商品编码 |
| name | STRING | 商品名称 |
| type | NUMBER | 商品类型（1:普通商品 2:套餐商品） |
| spec | STRING | 商品规格（JSON字符串） |
| baseUnitName | STRING | 基础计量单位 |
| shortCode | STRING | 商品简称 |
| masterImgUrl | STRING | 主图地址 |
| brandId | NUMBER | 品牌ID |
| brandName | STRING | 品牌名称 |
| categoryId | NUMBER | 分类ID |
| status | NUMBER | 商品状态（1:正常 2:停采 3:淘汰 4:停售） |
| shelfStatus | NUMBER | 上下架状态（1:上架 2:下架） |
| barcode | STRING | 条形码 |
| amount | NUMBER | 当前总库存量（按基础单位） |
| availableAmount | NUMBER | 库存可用量 |
| minimum | NUMBER | 起订量 |
| orderMultiple | NUMBER | 订货倍数 |
| purchaseLimit | NUMBER | 限订量 |
| multiUnitList | ARRAY | 多单位列表（含各单位价格） |
| promotionDescriptions | ARRAY | 促销描述列表 |

## productCategoryList

**功能**：获取商品分类列表（树形结构），支持按ids筛选。

**典型场景**
- 用户问“有哪些商品分类”
- 需要分类ID/编码用于其他接口时（如 productList 的 categoryCode、productCategoryStatisticsList 的 categoryIds）
- 需要获取某父级分类下的所有叶子节点ID（用于商品关联或按分类ID查询商品）

**响应数据**
- 返回类型：`ARRAY`（数组）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | NUMBER | 分类ID |
| name | STRING | 分类名称（如"酒水饮料"） |
| code | STRING | 分类编码（同一父节点下唯一） |
| level | NUMBER | 层级 |
| parentId | NUMBER | 上级分类ID（一级分类的上级分类id为0） |
| leafFlag | BOOLEAN | 叶子节点标识（true:叶子节点 false:非叶子节点） |

**重要说明**
- **商品只能关联到叶子节点**（`leafFlag=1` 的分类），非叶子节点不能直接关联商品
- 如需获取某父级分类下的所有叶子节点ID：
  1. 调用 `productCategoryList` 获取全部分类树
  2. 递归遍历找到该父级分类的所有后代节点中 `leafFlag=1` 的节点
  3. 收集这些叶子节点的 `id` 作为参数传入

## productShowCategoryList

**功能**：获取全量展示分类列表，支持树形结构的展示层级关系。

**典型场景**
- 用户问“有哪些展示分类”
- 需要展示分类ID/编码用于其他接口时（如 productList 的 showCategoryCode）
- 需要获取某父级展示分类下的所有叶子节点ID

**响应数据**
- 返回类型：`ARRAY`（数组）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | NUMBER | 展示分类ID |
| name | STRING | 分类名称 |
| image | STRING | 分类图片 |
| code | STRING | 分类编码（同一父节点下唯一） |
| level | NUMBER | 层级 |
| parentId | NUMBER | 上级分类ID（一级分类的上级分类id为0） |
| leafFlag | BOOLEAN | 叶子节点标识（true:叶子节点 false:非叶子节点） |

**重要说明**
- **商品只能关联到叶子节点**（`leafFlag=true` 的分类），非叶子节点不能直接关联商品
- 如需获取某父级展示分类下的所有叶子节点ID，参考 `productCategoryList` 的说明进行递归遍历

## 跨接口组合示例

**场景**：查询某品牌下所有正常销售商品的销售统计
1. `productBrandList` → 获取品牌ID
2. `productStatisticsList`（见统计/商品销售统计.md） → 传入 brandIds + rangeTime

**场景**：用户说“帮我看看饮料分类的商品”
1. `productCategoryList` → 找到“饮料”分类的 code
2. `productList` → 传入 categoryCode

**场景**：代客户创建订单时选择商品
1. `customerList` → 获取客户ID（targetId）
2. `findOrderCustomerSku` → 传入 targetId + 可选 q/brandIds/categoryCode/warehouseId，获取客户可购 SKU及其价格、库存
3. `createToBOrder` → 将 SKU ID 传入订单明细（订单/订单.md）
