# 客户调价单

本文档覆盖客户调价单的选品查询与新增、审核接口。客户调价单用于给指定客户设置商品单独定价（新订货价），单据创建后为待审核状态，审核通过后按生效时间参与该客户的订单计价。

## 接口目录
- [customerQuotationSkuList](#customerQuotationSkuList) - 查询客户调价单可选商品（按客户）
- [customerSinglePriceBillSave](#customerSinglePriceBillSave) - 新增客户调价单
- [customerSinglePriceBillSaveAndAudit](#customerSinglePriceBillSaveAndAudit) - 新增客户调价单并审核
- [customerSinglePriceBillAudit](#customerSinglePriceBillAudit) - 审核客户调价单

---

## 业务规则（必读）

| 规则 | 说明 |
|------|------|
| 单据规模 | 单张调价单：`targets` 1~30 个客户、`details` 1~200 个商品，超限服务端拒绝 |
| 单位完整性 | 每个商品的 `multiUnitList` **必须覆盖该商品的全部单位**（基础单位 + 全部副单位），数量与商品多单位数严格一致，缺一不可 |
| 副单位换算 | 副单位价格 = 基础单位价格 × 换算率（rate），与系统多单位计价规则一致 |
| 管控价约束 | 价格低于单位最低限价或高于最高限价时**整单拒绝**（错误码 5031，data 中列出超限商品与单位）；限价为 0 表示不限制 |
| 单独定价数上限 | 每个客户可设置单独定价的商品总数存在租户级上限，超限时服务端报错并列出超限客户名称 |
| 权限要求 | 新增需「管理客户调价单」权限；新增并审核 / 审核需「审核客户调价单」权限，无权限时调用报错 |
| 审核前提 | 仅数据权限覆盖该单全部客户的账号可执行审核 |

### 常见错误解读

| 报错特征 | 原因 | 处理建议 |
|---------|------|---------|
| 错误码 5031，data 含商品与单位列表 | 价格超出管控价（最低/最高限价） | 修正价格或确认限价配置后重试 |
| 提及客户名单的单独定价数量超限 | 该客户已设置的单独定价商品数达到上限 | 减少该客户本次调价商品数 |
| targets / details 数量超限 | 超过 30 客户或 200 商品 | 拆分为多张调价单 |
| 商品单位数量不匹配 | multiUnitList 未覆盖商品全部单位 | 通过 `customerQuotationSkuList` 获取该商品全部单位后补全 |
| 商品不存在或无权限 | skuId 无效或无该商品数据权限 | 复核 skuId 与商品权限 |
| 权限不足 | 账号无对应权限（管理/审核客户调价单） | 联系管理员开通权限 |

## customerSinglePriceBillSave

### 接口描述
新增一张客户调价单，创建后为**待审核**状态，需另行调用 [customerSinglePriceBillAudit](#customerSinglePriceBillAudit) 审核后生效。

**典型场景**
- 给指定客户设置部分商品的单独定价（新订货价）
- 批量调价流程中逐单创建（每单对应一个客户，返回 billId 供后续审核）

### 请求参数

#### Body参数

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| targets | NUMBER | 是 | 是 | 调价客户ID列表（1~30个），可从 `findAclCustomers` 获取 |
| validTime | DATE | 是 | 否 | 调价单生效时间 |
| description | STRING | 否 | 否 | 调价说明（最多100个字） |
| details | OBJECT | 是 | 是 | 调价单明细（1~200个商品） |
| details.skuId | NUMBER | 是 | 否 | 商品SKU ID |
| details.multiUnitList | OBJECT | 是 | 是 | 商品单位价格列表，必须覆盖该商品全部单位 |
| details.multiUnitList.id | NUMBER | 是 | 否 | 多单位ID |
| details.multiUnitList.price | NUMBER | 是 | 否 | 客户单独定价（元） |

### 响应数据

- 返回类型：`NUMBER`

| 字段 | 类型 | 说明 |
|------|------|------|
| （直接返回） | NUMBER | 新建的调价单ID（billId），可用于后续审核 |

## customerSinglePriceBillSaveAndAudit

### 接口描述
新增客户调价单并**立即审核**，一步完成创建与生效。参数与 [customerSinglePriceBillSave](#customerSinglePriceBillSave) 完全一致。

**典型场景**
- 用户明确要求"直接创建并生效、无需审核确认"时使用
- 常规流程（先创建、汇报、确认后再审核）应使用 save + audit 两步，失败隔离更细

### 请求参数

与 [customerSinglePriceBillSave](#customerSinglePriceBillSave) 完全一致。

### 响应数据

- 返回类型：`VOID`（无返回数据；调用成功即创建并审核完成，**不返回 billId**）


---

## customerSinglePriceBillAudit

### 接口描述
审核指定的客户调价单，审核通过后按单据生效时间生效。

### 请求参数

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| billId | NUMBER | 是 | 否 | 调价单ID（`customerSinglePriceBillSave` 返回值） |

### 响应数据

- 返回类型：`VOID`（无返回数据；调用成功即审核通过）

## customerQuotationSkuList

### 接口描述
创建客户调价单前的选品接口：查询可调价的商品，返回商品全部单位、各单位的客户报价与最低/最高限价。**客户调价单场景下获取商品信息、价格信息一律使用本接口，不要用 `productList`**（本接口的限价与客户报价口径与调价单校验规则一致，`productList` 不含客户维度价格）。

**典型场景**
- 按商品名称/编码解析 skuId（`q` 支持名称/编码/简称/条码模糊搜索）
- 获取商品全部单位（`multiUnitList`），用于补全调价单明细的单位价格
- 获取各单位最低/最高限价，预判调价超限项（避免创建时 5031 整单被拒）
- 查看某客户当前的单独报价（传 `targetOrgId`）或客户等级基准价（不传 `targetOrgId`）

### 请求参数

#### Query参数

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| q | STRING | 否 | 否 | 查询关键字（商品名称/编码/简称/条码，模糊搜索） |
| categoryCode | STRING | 否 | 是 | 商品分类编码 |
| codes | STRING | 否 | 是 | 商品编码数组 |
| targetOrgId | NUMBER | 否 | 否 | 客户机构ID（可从 `findAclCustomers` 获取）。传入：按该客户授权商品范围过滤，`price` 回填该客户的企业单独报价；不传：查全部商品，`price` 回填客户等级基准价 |
| shelfStatuses | NUMBER | 否 | 是 | 上下架状态数组，1=上架，2=下架 |
| skuIds | NUMBER | 否 | 是 | 商品SKU ID数组 |
| currentPage | NUMBER | 否 | 否 | 当前页码，默认1 |
| pageSize | NUMBER | 否 | 否 | 每页条数，默认20，最大200 |

### 响应数据

- 返回类型：`PAGE`（分页）

| 字段 | 类型 | 说明 |
|------|------|------|
| skuId | NUMBER | 商品SKU ID（即调价单 details.skuId） |
| spuId | NUMBER | SPU ID |
| code | STRING | 商品编码 |
| name | STRING | 商品名称 |
| spec | STRING | 商品规格 |
| masterImgUrl | STRING | 主图地址 |
| multiUnitName | STRING | 最小单位名称 |
| multiUnitId | NUMBER | 最小单位ID |
| shortCode | STRING | 商品简称 |
| costPrice | NUMBER | 成本价（需成本价字段权限，无权限时为空） |
| lastPurchasePrice | NUMBER | 最近采购价（需成本价字段权限，无权限时为空） |
| multiUnitList | ARRAY | 商品单位列表 |
| multiUnitList[].id | NUMBER | 多单位ID（即调价单 details.multiUnitList.id） |
| multiUnitList[].skuId | NUMBER | 商品SKU ID |
| multiUnitList[].unitName | STRING | 单位名称 |
| multiUnitList[].rate | NUMBER | 换算率 |
| multiUnitList[].barcode | STRING | 条码 |
| multiUnitList[].minimumPrice | NUMBER | 最低限价 |
| multiUnitList[].maximumPrice | NUMBER | 最高限价 |
| multiUnitList[].price | NUMBER | 客户报价：传 `targetOrgId` 时为该客户的企业单独报价，不传时为客户等级基准价 |

**重要说明**
- 仅返回状态为 正常/停采/停售 的商品（不含已淘汰商品）
- 限价为 0 表示不限制；调价价格超出限价时创建调价单会被整单拒绝（错误码 5031），因此建议先预检

## 组合场景：批量客户调价的数据准备

批量创建调价单前，需要把客户名称/编码、商品名称/编码解析为 ID，并获取商品的完整单位列表：

1. **客户解析**：`findAclCustomers`（参数详见 [客户与商机/客户-单据选客户.md](../客户与商机/客户-单据选客户.md)；按名称/编码等筛选）→ 取 `id` 作为 `targets`
2. **商品解析**：`customerQuotationSkuList`（`q` 支持商品名称/编码/简称/条码模糊搜索，建议同时传 `targetOrgId` 锁定客户）→ 取 `skuId`（即调价单的 skuId）、`multiUnitList`（含 `id` 单位ID、`unitName` 单位名、`rate` 换算率、`minimumPrice` 最低限价、`maximumPrice` 最高限价、`price` 当前客户报价）、`multiUnitId`（最小单位ID）、`multiUnitName`（最小单位名称）
3. **价格补全**：副单位价格缺失时按 基础单位价 × rate 推算
4. **预检**：用 `customerQuotationSkuList` 返回的最低/最高限价预判超限项，避免创建时整单被拒
