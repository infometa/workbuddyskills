# 订货模板

本文档覆盖订货模板相关接口，包含订货模板列表分页查询和订货模板详情查询。

## 接口目录
- [orderTemplateSearch](#ordertemplatesearch) - 分页获取订货模板列表（按关键词/状态筛选）
- [getOrderTemplate](#getordertemplate) - 订货模板详情（含客户范围、商品明细等完整信息）

---

## orderTemplateSearch

**功能**：分页查询订货模板列表，支持按关键词、模板状态等条件筛选。

**典型场景**
- 查看当前机构下所有订货模板
- 按模板名称关键词搜索模板
- 按启用/禁用状态过滤模板列表

**参数**

| 参数          | 类型     | 必填 | 数组 | 说明                       |
|-------------|--------|----|----|--------------------------|
| keyword     | STRING | 否  | 否  | 关键词（支持模板 名称/商品/创建人 模糊匹配） |
| ids         | NUMBER | 否  | 是  | 模板ID列表，精确查询多个模板          |
| statuses    | NUMBER | 否  | 是  | 模板状态，0=禁用，1=启用           |
| currentPage | NUMBER | 否  | 否  | 当前页码，默认1                 |
| pageSize    | NUMBER | 否  | 否  | 每页条数，默认20                |

**响应数据**
- 返回类型：`PAGE`（分页）

| 字段               | 类型       | 说明            |
|------------------|----------|---------------|
| id               | NUMBER   | 主键            |
| templateName     | STRING   | 模板名称          |
| status           | NUMBER   | 状态（0=禁用，1=启用） |
| selfOrderEnabled | BOOLEAN  | 自主下单支持按模板选择   |
| skuCount         | NUMBER   | 商品种数          |
| creatorId        | NUMBER   | 创建人id         |
| creatorName      | STRING   | 创建人名称         |
| createOrgId      | NUMBER   | 创建机构id        |
| createOrgName    | STRING   | 创建机构          |
| createTime       | DATETIME | 创建时间          |
| modifyTime       | DATETIME | 修改时间          |
| own              | BOOLEAN  | 是否当前机构创建      |

## getOrderTemplate

**功能**：根据模板ID查询订货模板的详细信息，包含客户范围（conditions）和商品明细（details）等完整数据。

**典型场景**
- 查看某个订货模板的完整配置信息
- 编辑模板前获取当前配置数据
- 查看模板中包含的客户范围和具体商品明细

**参数**

| 参数 | 类型     | 必填 | 数组 | 说明        |
|----|--------|----|----|-----------|
| id | NUMBER | 是  | 否  | 模板ID，路径参数 |

**响应数据**
- 返回类型：`OBJECT`

| 字段               | 类型       | 说明                                                     |
|------------------|----------|--------------------------------------------------------|
| id               | NUMBER   | 主键                                                     |
| templateName     | STRING   | 模板名称                                                   |
| status           | NUMBER   | 状态（0=禁用，1=启用）                                          |
| providerScope    | NUMBER   | 参与机构范围（1=全部，2=限定）                                      |
| accepterScopes   | ARRAY    | 铺货范围类型：HEADQUARTERS=总部，BRANCH=分公司，STORE=门店，CUSTOMER=客户 |
| selfOrderEnabled | BOOLEAN  | 自主下单支持按模板选择                                            |
| skuCount         | NUMBER   | 商品种数                                                   |
| totalMoney       | NUMBER   | 金额小计                                                   |
| creatorId        | NUMBER   | 创建人id                                                  |
| creatorName      | STRING   | 创建人名称                                                  |
| createOrgId      | NUMBER   | 创建机构id                                                 |
| createOrgName    | STRING   | 创建机构                                                   |
| createTime       | DATETIME | 创建时间                                                   |
| modifyTime       | DATETIME | 修改时间                                                   |
| own              | BOOLEAN  | 是否当前机构创建                                               |
| conditions       | ARRAY    | 客户范围（条件），详见下方说明                                        |
| details          | ARRAY    | 商品明细，详见下方说明                                            |

### conditions 客户范围

| 字段                              | 类型     | 说明                                                   |
|---------------------------------|--------|------------------------------------------------------|
| conditions[].id                 | NUMBER | 主键                                                   |
| conditions[].templateId         | NUMBER | 模板id                                                 |
| conditions[].hierarchyCode      | STRING | 组织类型：HEADQUARTERS=总部，BRANCH=分公司，STORE=门店，CUSTOMER=客户 |
| conditions[].conditionScope     | NUMBER | 范围（1=全部，2=指定区域/分类/标签，3=指定具体客户）                       |
| conditions[].conditionType      | STRING | 条件类型                                                 |
| conditions[].conditionTargetIds | ARRAY  | 条件类型对应的条件id值                                         |
| conditions[].conditionNames     | ARRAY  | 条件值对应名称                                              |

### details 商品明细

| 字段                         | 类型       | 说明                  |
|----------------------------|----------|---------------------|
| details[].id               | NUMBER   | 主键                  |
| details[].templateId       | NUMBER   | 模板id                |
| details[].productType      | NUMBER   | 商品类型（1=普通商品，2=套餐商品） |
| details[].productSku       | NUMBER   | 商品SKU ID            |
| details[].productSpu       | NUMBER   | 商品SPU ID            |
| details[].productCode      | STRING   | 商品编码                |
| details[].productName      | STRING   | 商品名称                |
| details[].productShortName | STRING   | 商品简称                |
| details[].productBarCode   | STRING   | 商品条码                |
| details[].productSpec      | STRING   | 商品规格                |
| details[].productImageUrl  | STRING   | 商品主图url             |
| details[].categoryId       | NUMBER   | 商品分类id              |
| details[].categoryName     | STRING   | 商品分类名称              |
| details[].brandId          | NUMBER   | 商品品牌id              |
| details[].brandName        | STRING   | 商品品牌名称              |
| details[].unitId           | NUMBER   | 商品单位ID              |
| details[].unitName         | STRING   | 商品单位                |
| details[].weight           | NUMBER   | 单位重量                |
| details[].numbers          | NUMBER   | 商品数量                |
| details[].marketPrice      | NUMBER   | 市场价                 |
| details[].price            | NUMBER   | 价格                  |
| details[].auxUnitId        | NUMBER   | 辅助单位id              |
| details[].auxUnitName      | STRING   | 辅助单位                |
| details[].auxNumbers       | NUMBER   | 辅助单位铺货数量            |
| details[].baseUnitId       | NUMBER   | 最小单位id              |
| details[].baseUnitName     | STRING   | 最小单位                |
| details[].baseNumbers      | NUMBER   | 最小单位数量              |
| details[].createTime       | DATETIME | 创建时间                |
| details[].modifyTime       | DATETIME | 修改时间                |

## 跨接口组合示例

**场景**：查看某个订货模板的完整详情
1. `orderTemplateSearch` → 查询模板列表，找到目标模板的 `id`
2. `getOrderTemplate` → 传入 `id` 获取该模板的完整信息（含客户范围、商品明细和金额）
