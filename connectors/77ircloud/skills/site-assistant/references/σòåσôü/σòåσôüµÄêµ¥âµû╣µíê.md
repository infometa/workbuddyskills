# 商品授权方案

本文档覆盖商品授权方案相关查询接口，用于管理商品授权方案的查询、创建和维护。

## 接口目录
- [productAuthorizationList](#productauthorizationlist) - 商品授权方案列表（查询授权方案，支持按名称/默认状态/SKU筛选）
- [findOrgAuthorizations](#findorgauthorizations) - 查询指定机构授权方案列表（按机构ID查询授权方案）
- [getProductAuthorizationDetail](#getproductauthorizationdetail) - 查询商品授权方案详情（根据ID获取授权方案完整信息）

---

## productAuthorizationList

**功能**：查询商品授权方案列表，支持按名称模糊匹配、默认状态、授权范围内的SKU等条件筛选，不分页返回所有授权方案。

**典型场景**
- 查看系统中所有的商品授权方案
- 查找某个特定的授权方案及其ID
- 查询包含指定商品的授权方案
- 查看默认授权方案
- 需要授权方案ID才能执行下游操作时（如代客户下单时指定授权方案）

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| name | STRING | 否 | 否 | 授权方案名称，模糊匹配 |
| authorizationIds | NUMBER | 否 | 是 | 授权方案ID列表，精确查询多个授权方案 |
| defaultFlag | BOOLEAN | 否 | 否 | 是否默认授权方案，null=查找全部，true=只查默认，false=只查非默认 |
| skuId | NUMBER | 否 | 否 | SKU ID，查询授权范围内包含指定SKU的方案 |
| currentPage | NUMBER | 否 | 否 | 当前页码，默认1 |
| pageSize | NUMBER | 否 | 否 | 每页数量，默认20 |

**响应数据**
- 返回类型：`PAGE`（分页）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | NUMBER | 授权方案ID（用于下游接口，如代客户下单时指定授权方案） |
| name | STRING | 授权方案名称 |
| defaultFlag | BOOLEAN | 是否默认方案（true:默认 false:非默认） |
| permission | BOOLEAN | 是否有授权范围的全部权限（true:有权限 false:无权限） |
| isSkuAuth | BOOLEAN | 查询的SKU是否有按指定商品授权（当传入skuId时有效） |

**组合示例**：
- 查询“默认授权方案” → 调用 `productAuthorizationList` 传 `defaultFlag=true`
- 查询“包含某商品的授权方案” → 先用 `productList` 获取SKU ID，再用 `productAuthorizationList` 传 `skuId`
- 查询“所有非默认授权方案” → 调用 `productAuthorizationList` 传 `defaultFlag=false`

## findOrgAuthorizations

**功能**：查询指定机构的商品授权方案列表，支持按名称模糊匹配、默认状态、授权范围内的SKU等条件筛选，分页返回授权方案。

**典型场景**
- 查看某个特定机构下的所有授权方案
- 在多级组织管理中，查询子机构的授权方案配置
- 对比不同机构的授权方案差异
- 需要机构维度查看授权方案时

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| orgId | NUMBER | 是 | 否 | 机构ID，路径参数，要查询的机构ID |
| name | STRING | 否 | 否 | 授权方案名称，模糊匹配 |
| authorizationIds | NUMBER | 否 | 是 | 授权方案ID列表，精确查询多个授权方案 |
| defaultFlag | BOOLEAN | 否 | 否 | 是否默认授权方案，null=查找全部，true=只查默认，false=只查非默认 |
| skuId | NUMBER | 否 | 否 | SKU ID，查询授权范围内包含指定SKU的方案 |
| currentPage | NUMBER | 否 | 否 | 当前页码，默认1 |
| pageSize | NUMBER | 否 | 否 | 每页数量，默认20 |

**响应数据**
- 返回类型：`PAGE`（分页）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | NUMBER | 授权方案ID（用于下游接口，如代客户下单时指定授权方案） |
| name | STRING | 授权方案名称 |
| defaultFlag | BOOLEAN | 是否默认方案（true=默认，false=非默认） |
| permission | BOOLEAN | 是否有授权范围的全部权限（true=有权限，false=无权限） |
| isSkuAuth | BOOLEAN | 查询的SKU是否有按指定商品授权（当传入skuId时有效） |

**前置接口**
- `organizationList`：查询机构列表 → 获取机构ID

**后续接口**
- `getProductAuthorizationDetail`：查看授权方案详情 → 传入授权方案ID
- `findOrderCustomerSku`：获取客户可购商品 → 传入授权方案ID

**组合示例**：
- 查询“某机构的默认授权方案” → 调用 `findOrgAuthorizations` 传 `orgId` + `defaultFlag=true`
- 查询“某机构包含某商品的授权方案” → 先用 `productList` 获取SKU ID，再用 `findOrgAuthorizations` 传 `orgId` + `skuId`
- 查询“某机构所有非默认授权方案” → 调用 `findOrgAuthorizations` 传 `orgId` + `defaultFlag=false`

## getProductAuthorizationDetail

**功能**：根据授权方案ID查询授权方案的详细信息，包含授权的品牌、分类、具体商品SKU列表等完整配置。

**典型场景**
- 查看某个授权方案的完整配置信息
- 编辑授权方案前获取当前配置
- 查看授权方案中包含哪些品牌、分类和商品
- 确认授权方案的授权范围

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| id | NUMBER | 是 | 否 | 授权方案ID，路径参数，可从 productAuthorizationList 获取 |

**响应数据**
- 返回类型：`OBJECT`

| 字段 | 类型 | 说明 |
|------|------|------|
| id | NUMBER | 授权方案ID |
| name | STRING | 授权方案名称 |
| defaultFlag | BOOLEAN | 是否默认方案（true:默认 false:非默认） |
| brands | ARRAY | 授权的商品品牌列表（包含品牌ID和名称） |
| categories | ARRAY | 授权的商品分类列表（包含分类ID和名称） |
| skuList | ARRAY | 授权的商品SKU列表（包含SKU ID、名称、编码、规格、主图） |
| allBrand | BOOLEAN | 是否为全部品牌（true:全部 false:不是全部） |
| allCategory | BOOLEAN | 是否为全部分类（true:全部 false:不是全部） |

**组合示例**：
- 查看某授权方案的详情 → 先用 `productAuthorizationList` 获取授权方案ID，再用 `getProductAuthorizationDetail` 传 `id`
- 编辑授权方案 → 调用 `getProductAuthorizationDetail` 获取当前配置，修改后调用更新接口

## 跨接口组合示例

**场景**：代客户下单时指定授权方案
1. `productAuthorizationList` → 查询可用的授权方案，获取授权方案ID
2. `getProductAuthorizationDetail` → 查看授权方案的详细配置，确认包含需要的商品
3. `findOrderCustomerSku` → 传入客户ID和授权方案ID，获取客户可购商品列表
4. `createToBOrder` → 使用授权方案创建订单

**场景**：查看某商品被哪些授权方案包含
1. `productList` → 获取商品的SKU ID
2. `productAuthorizationList` → 传入 `skuId`，查询包含该商品的所有授权方案
3. `getProductAuthorizationDetail` → 查看具体授权方案的完整配置

**场景**：编辑授权方案
1. `productAuthorizationList` → 查询所有授权方案，找到需要编辑的方案ID
2. `getProductAuthorizationDetail` → 获取当前授权方案的完整配置
3. 调用更新接口 → 修改授权方案的品牌、分类或商品列表
