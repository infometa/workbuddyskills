# 客户预警

本文档覆盖客户预警明细接口，用于按预警指标查询客户列表（流失、欠款、订单锐减等）。指标字段名为 `module`。

## 应答与数据溯源（必读）

- **有数据时**：在展示列表或数字前，**必须先单独输出一句**（再换行写明细），例如：「以下数据来源于客户预警。」勿省略；**勿**在话术中写 `module`、`enabled` 或括号说明。
- **无数据时**：亦需先说明来源（如「客户预警中未查询到……」），**禁止**自动换其他报表凑数；须询问是否改查其他报表。

## 接口目录
- [customerEarlywarnList](#customerearlywarnlist) - 客户预警明细
- [queryEarlyWarnInfo](#queryearlywarninfo) - 客户预警汇总

## customerEarlywarnList

**功能**：根据指定预警指标（`module`），查询触发预警的客户列表，展示客户的订单金额、欠款、拜访等维度的关键数据。

**典型场景**
- 查找近期订单锐减的客户，及时跟进
- 找出流失客户（长期未下单）
- 查看欠款超期的客户列表
- 找出销售额不达标的客户
- 识别高退款率的客户
- 到期未拜访的客户提醒

**参数**
| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| module | STRING | 是 | 否 | 预警指标，见下表「预警指标枚举」 |
| enabled | NUMBER | 否 | 否 | 客户状态，见下 **enabled 使用规则** |
| categoryIds | NUMBER | 否 | 是 | 客户分类ID |
| departmentIds | NUMBER | 否 | 是 | 部门ID |
| regionIds | NUMBER | 否 | 是 | 客户区域ID |
| salesIds | NUMBER | 否 | 是 | 业务员ID |
| tagIds | NUMBER | 否 | 是 | 客户标签ID |

### enabled 使用规则

- 契约默认 `enabled: 1`（仅**启用**客户）。除非用户话里明确要查「全部」「含禁用」「含禁用客户」「所有客户」等——此时再传 `"enabled": 2`（全部）。
- 若用户明确只要**禁用**客户，再按需传 `"enabled": 0`；未提及上述范围时，**禁止**擅自传 `2`，避免与默认「仅启用」不一致。

## queryEarlyWarnInfo

**功能**：查询各预警指标的客户家数汇总，用于概览展示。支持指定多个指标查询，不传 `loadModules` 则返回全部启用指标的汇总数据。

> **与 customerEarlywarnList 的区别**：`customerEarlywarnList` 返回指定指标下**客户维度的明细列表**（分页）；`queryEarlyWarnInfo` 返回**指标的汇总数据**（各指标的客户家数等），不分页。

**参数**
| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| loadModules | STRING | 否 | 是 | 预警指标编码列表（不传则返回全部指标），见上表「预警指标枚举」 |

**响应数据**
- 返回类型：`LIST`（数组）
| 字段 | 类型 | 说明 |
|------|------|------|
| module | STRING | 指标编码 |
| label | STRING | 指标名称（中文，如"流失客户"） |
| count | NUMBER | 客户家数 |

预警指标枚举与 `customerEarlywarnList` 一致，见上方「预警指标枚举」表。
