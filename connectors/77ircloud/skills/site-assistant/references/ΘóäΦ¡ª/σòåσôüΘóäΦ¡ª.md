# 商品预警

本文档覆盖商品预警明细接口，用于按预警指标查询商品列表（滞销、退货多、曝光转化等）。指标字段名为 `module`。

## 接口目录
- [productEarlywarnList](#productearlywarnlist) - 商品预警明细
- [queryEarlyWarnInfo](#queryearlywarninfo) - 商品预警汇总

---

## productEarlywarnList

**功能**：根据指定预警指标（`module`），查询触发预警的商品列表，展示商品的销售、库存、访问、毛利等维度的关键数据。

**典型场景**
- 找出滞销商品，制定清库策略
- 识别退货率偏高的商品
- 找出高毛利但访客少的商品，加大推广力度
- 找出曝光高但转化率低的商品，优化商品页面
- 分析加购多但成交少的商品，排查价格或库存问题

**参数**
| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| module | STRING | 是 | 否 | 预警指标编码，见下表「预警指标枚举」 |
| brandIds | NUMBER | 否 | 是 | 品牌ID |
| categoryIds | NUMBER | 否 | 是 | 商品分类ID |
| productStatus | NUMBER | 否 | 是 | 商品状态：0=全部 / 1=非淘汰 / 2=上架 / 3=已下架 / 4=已淘汰 |
| skuIds | NUMBER | 否 | 是 | 商品ID |

**预警指标枚举（module）**
| 指标名称 | 指标编码 |
|----------|----------|
| 滞销商品 | unsalableGoodsV2 |
| 滞销新品 | newUnsoldProductsV2 |
| 订货暴跌 | orderVolumePlummeted |
| 退货多 | excessiveReturns |
| 高毛利访客少 | highGrossProfitFewVisitors |
| 曝光高转换少 | highExposureLowConversion |
| 加购多成交少 | morePurchasesFewerTransactions |
| 访问次数少 | lessVisits |
| 订货额暴涨 | salesAmountSurge |
| 周转快 | highTurnoverRate |
| 引流商品 | trafficProducts |
| 潜力新品 | potentialNewProducts |

**常见问法与 module 取值**

| 用户说法（示例） | module |
|------------------|--------|
| 滞销、卖不动、滞销商品有哪些 | unsalableGoodsV2 |
| 新品滞销 | newUnsoldProductsV2 |
| 订货暴跌、销量骤降 | orderVolumePlummeted |
| 退货多、退货率高 | excessiveReturns |
| 高毛利访客少 | highGrossProfitFewVisitors |
| 曝光高转化低、曝光高转换少 | highExposureLowConversion |
| 加购多成交少 | morePurchasesFewerTransactions |
| 访问次数少 | lessVisits |
| 订货额暴涨、销售额猛增 | salesAmountSurge |
| 周转快、动销快 | highTurnoverRate |
| 引流款、引流商品 | trafficProducts |
| 潜力新品、新品潜力 | potentialNewProducts |

**响应数据**
- 返回类型：`PAGE`（分页）
| 字段 | 类型 | 说明 |
|------|------|------|
| skuId | NUMBER | 商品ID |
| spuId | NUMBER | 商品SPU |
| productName | STRING | 商品名称 |
| productCode | STRING | 商品编码 |
| spec | STRING | 规格 |
| baseUnitName | STRING | 商品单位 |
| noSalesDay | NUMBER | 无销售天数 |
| visitCount | NUMBER | 访问次数 |
| visitCustomerCount | NUMBER | 访客数 |
| collectCount | NUMBER | 收藏数 |
| addPurchaseCount | NUMBER | 加购次数 |
| productCount | NUMBER | 订货数量 |
| productAmount | NUMBER | 订货金额 |
| buyerCount | NUMBER | 订货客户数 |
| coverRate | STRING | 转化率 |
| returnProductCount | NUMBER | 退货数量 |
| returnProductAmount | NUMBER | 退货金额 |
| returnCoverRate | STRING | 退货率 |
| returnPackageNumbers | STRING | 退货包装数量 |
| packageNumbers | STRING | 包装数量 |
| soldProfit | NUMBER | 毛利 |
| profitRate | STRING | 毛利率 |
| netSalesCount | NUMBER | 净销售数量 |
| inventoryCount | NUMBER | 库存数 |
| inventoryAmount | NUMBER | 库存金额 |
| lastGroundTime | DATETIME | 最近上架时间 |
| lastOrderTime | DATETIME | 最近订货时间 |

## queryEarlyWarnInfo

**功能**：查询各预警指标的商品条数汇总，用于概览展示。

**参数**
| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| groupBy | NUMBER | 否 | 否 | 统计维度，默认 1；1=按规格分别统计，2=多规格汇总 |
| brandIds | NUMBER | 否 | 是 | 品牌ID，按品牌筛选 |
| categoryIds | NUMBER | 否 | 是 | 商品分类ID，按分类筛选 |
| productStatus | NUMBER | 否 | 是 | 商品状态：0=全部 / 1=非淘汰 / 2=上架 / 3=已下架 / 4=已淘汰 |
| skuIds | NUMBER | 否 | 是 | 商品ID，指定商品 |

**响应数据**
- 返回类型：`LIST`（数组）
| 字段 | 类型 | 说明 |
|------|------|------|
| module | STRING | 指标编码 |
| label | STRING | 指标名称（中文，如"滞销商品"） |
| count | NUMBER | 商品条数 |

预警指标枚举与 `productEarlywarnList` 一致，见上方「预警指标枚举」表。
