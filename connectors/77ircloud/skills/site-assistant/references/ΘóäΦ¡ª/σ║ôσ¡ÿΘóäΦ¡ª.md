# 库存预警

本文档覆盖库存预警明细接口，用于按预警类型查询在库商品批次（效期临期等）。指标字段名为 `warnSetting`。

### warnSetting 判别（必读）

| 用户语义                              | warnSetting         | 说明       |
|-----------------------------------|---------------------|----------|
| **临期**、快过期、还没过期、效期预警、清仓/促销处理、要处理掉 | **quality_percent** | 与「已过期」不同 |
| **已过期**、过期商品、过期库存、到保质期已坏          | **expiration_day**  |          |
| 低于最低安全库存、缺货预警                     | min_safe_stock      |          |
| 高于最高安全库存、超储                       | max_safe_stock      |          |

「有哪些商品临期了要做促销」→ **quality_percent**，**不要**用 `expiration_day`。

## 接口目录
- [inventoryWarningList](#inventorywarninglist) - 库存预警明细
- [inventoryWarningCount](#inventorywarningcount) - 库存预警总数

---

## inventoryWarningList

**功能**：根据指定预警类型（`warnSetting`），查询库存预警列表，展示批次、仓库、数量、效期等维度的关键数据。

**典型场景**
- 查看效期临期、即将过期的在库商品
- 查看已过期的在库商品
- 按仓库、品牌、分类、批次筛选预警库存
- 按生产日期区间筛选库存
- 查询低于最低安全库存或高于最高安全库存的商品

**参数**
| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| warnSetting | STRING | 是 | 否 | 预警指标，见下表「预警指标枚举」 |
| categoryId | NUMBER | 否 | 是 | 分类ID，支持多分类筛选 |
| brandId | NUMBER | 否 | 是 | 品牌ID，支持多品牌筛选 |
| goodsName | STRING | 否 | 否 | 商品名称，模糊搜索 |
| warehouseId | NUMBER | 否 | 是 | 仓库ID，支持多仓库筛选 |
| productionDateBegin | DATETIME | 否 | 否 | 生产日期开始，与 productionDateEnd 配合使用 |
| productionDateEnd | DATETIME | 否 | 否 | 生产日期结束，与 productionDateBegin 配合使用 |
| batchNum | STRING | 否 | 否 | 批次号，精确匹配 |
| inventoryScope | STRING | 否 | 否 | 扫描范围，枚举值：ALL（全部）、TODAY（当天）、MONTH（当月） |
| status | NUMBER | 否 | 是 | 商品状态，枚举值：0（全部）、1（非淘汰）、2（上架）、3（已下架）、4（已淘汰） |

**预警指标枚举（warnSetting）**
| 指标名称 | 指标编码 |
|----------|----------|
| 过期商品 | expiration_day |
| 临期商品 | quality_percent |
| 低于最低安全库存 | min_safe_stock |
| 高于最高安全库存 | max_safe_stock |

**常见问法与 warnSetting 取值**

| 用户说法（示例） | warnSetting |
|------------------|-------------|
| 过期商品、已过期、过期库存 | expiration_day |
| 临期、临期商品、快过期、效期临期、临期促销、清仓处理 | quality_percent |
| 低于最低安全库存、安全库存不足、缺货预警 | min_safe_stock |
| 高于最高安全库存、超储、积压超上限 | max_safe_stock |

**响应数据**
- 返回类型：`PAGE`（分页）

**主字段**
| 字段 | 类型 | 说明 |
|------|------|------|
| skuId | NUMBER | 商品ID |
| spuId | NUMBER | 商品SPU |
| name | STRING | 商品名称 |
| code | STRING | 商品编码 |
| spec | STRING | 规格 |
| barCode | STRING | 商品条码 |
| batchNum | STRING | 批次号 |
| amount | NUMBER | 实际库存 |
| availableAmount | NUMBER | 可用库存 |
| expirationDate | DATETIME | 过期日期 |
| expireDay | NUMBER | 到期天数 |
| productionDate | STRING | 生产日期 |
| qualityDay | NUMBER | 保质期 |
| passStockAgeAmount | NUMBER | 超库龄接口 |
| warehouseId | NUMBER | 仓库ID |
| warehouseName | STRING | 仓库名称 |
| brandId | NUMBER | 品牌ID |
| brandName | STRING | 品牌名称 |
| categoryId | NUMBER | 分类ID |
| categoryName | STRING | 分类名称 |
| unitId | NUMBER | 单位ID |
| unitName | STRING | 单位名称 |
| lowerLimitAmount | NUMBER | 最低库存 |
| upperLimitAmount | NUMBER | 最高库存 |
| surplusCostAmount | NUMBER | 成本金额 |
| surplusCostPrice | NUMBER | 成本 |
| multiUnitList | ARRAY | 多单位列表，子字段见下 |

**multiUnitList 子字段**
| 字段 | 类型 | 说明 |
|------|------|------|
| id | NUMBER | 多单位id |
| skuId | NUMBER | skuId |
| unitName | STRING | 单位名称 |
| rate | NUMBER | 换算率 |

## inventoryWarningCount

**功能**：查询各预警类型的库存数量汇总

**参数**
| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| categoryId | NUMBER | 否 | 是 | 分类ID，支持多分类筛选 |
| brandId | NUMBER | 否 | 是 | 品牌ID，支持多品牌筛选 |
| warehouseId | NUMBER | 否 | 是 | 仓库ID，支持多仓库筛选 |
| productionRangeTime | TIME_RANGE | 否 | 否 | 生产日期范围，由 productionDateBegin 和 productionDateEnd 组成 |
| batchNum | STRING | 否 | 否 | 批次号，精确匹配 |
| status | NUMBER | 否 | 是 | 商品状态，枚举值：0（全部）、1（非淘汰）、2（上架）、3（已下架）、4（已淘汰） |
| orgId | NUMBER | 否 | 否 | 机构ID |

**响应数据**
- 返回类型：`LIST`（数组）
| 字段 | 类型 | 说明 |
|------|------|------|
| properties | STRING | 库存预警类型 |
| value | NUMBER | 数量 |

预警指标枚举与 `inventoryWarningList` 一致，见上方「预警指标枚举」表。
