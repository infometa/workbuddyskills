# 优惠券

本文档覆盖优惠券相关接口，包含优惠券新增、列表查询和效果分析。

## 接口目录
- [createCouponDefinition](#createcoupondefinition) - 新增优惠券
- [couponDefinitionsSearch](#coupondefinitionssearch) - 优惠券列表（按关键词搜索）
- [couponDiscountSummary](#coupondiscountsummary) - 优惠券效果分析

---

## createCouponDefinition

**功能**：创建一张 toB 优惠券批次（满减券或折扣券），成功后返回优惠券批次 ID。

**典型场景**
- 新建满减券（如满 10 减 1）
- 新建折扣券（如满 10 元打 9 折）
- 为指定客户、指定商品创建可用优惠券

### 参数

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| name | STRING | 是 | 否 | 优惠券名称 |
| category | STRING | 是 | 否 | 类型：`REDUCE`=满减券，`DISCOUNT`=折扣券 |
| preference | NUMBER | 是 | 否 | 优惠力度：**单位元**。满减=立减金额（如减 3 元传 `3`）；折扣=折扣值（如 `90` 表示 9 折） |
| isToB | BOOLEAN | 是 | 否 | 是否 toB 券，B 端客户券传 `true`（默认 true） |
| provideOrgs | OBJECT | 是 | 是 | 优惠券提供方（发券机构） |
| acceptOrgs | OBJECT | 是 | 是 | 优惠券消费方（可用客户/机构范围） |
| throttleAmount | NUMBER | 否 | 否 | 使用门槛金额，**单位元**（如满 10 元传 `10`）；无门槛传 `0` |
| totalCount | NUMBER | 否 | 否 | 发行数量 |
| maxPreferenceAmount | NUMBER | 否 | 否 | 最大优惠金额（仅折扣券） |
| expirationDate | OBJECT | 否 | 否 | 有效期：`expiredAfter`（领取后 N 天失效）优先；或 `effectiveFrom`/`effectiveTo` |
| product | OBJECT | 否 | 否 | 适用商品；`allProductsAvailable=true` 时忽略其余筛选 |
| countPerUser | OBJECT | 否 | 否 | 每人限领：`{ infinite, count }` |
| onlyForNewUser | BOOLEAN | 否 | 否 | 是否仅限新人，默认 false |
| additionPromotionEnable | BOOLEAN | 否 | 否 | 是否可与促销叠加，默认 false |
| remark | STRING | 否 | 否 | 使用说明 |
| sourceType | STRING | 否 | 否 | 来源，手工创建传 `NORMAL` |
| directlyDistribute | NUMBER | 否 | 否 | 发券方式：`0`=易发券（默认），`1`=直接发券 |

#### provideOrgs[] 子字段

| 参数 | 类型 | 说明 |
|------|------|------|
| allUsersAvailable | BOOLEAN | 不限制组织时传 true |
| conditionType | STRING | `ALL` / `ORG` / `REGION` |
| hierarchy | STRING | `ALL` / `HEADQUARTERS` / `BRANCH` / `STORE` |
| targetIds | NUMBER[] | 目标机构 ID 列表 |

**常用写法（发券机构）**：

```json
[{
  "allUsersAvailable": false,
  "conditionType": "ORG",
  "hierarchy": "HEADQUARTERS",
  "targetIds": [<机构ID>]
}]
```

#### acceptOrgs[] 子字段

| 参数 | 类型 | 说明 |
|------|------|------|
| allUsersAvailable | BOOLEAN | 不限制组织时传 true |
| conditionType | STRING | `ALL` / `ID` / `GRADE` / `REGION` / `TAG` |
| hierarchy | STRING | 常用 `CUSTOMER`；也可含 `BRANCH` / `STORE` 等 |
| targetIds | NUMBER[] | 客户 ID 等；全部时常用 `[-1]` |

**指定客户常用写法**：

```json
[{
  "hierarchy": "CUSTOMER",
  "targetIds": [<客户ID>],
  "conditionType": "ID",
  "allUsersAvailable": false
}]
```

按实际可用范围组装即可：指定客户用 `CUSTOMER`，指定分公司用 `BRANCH`，指定门店用 `STORE`；需要几层就传几条。

> **禁止「凑齐」**：用户或调用方**只指定了客户**时，`acceptOrgs` **只能**含 `hierarchy=CUSTOMER` + 客户 ID；**禁止**再附加 `BRANCH` / `STORE` 的 `ALL`（如 `targetIds:[-1]`）或其它未指定层级。

#### product 子字段

| 参数 | 类型 | 说明 |
|------|------|------|
| allProductsAvailable | BOOLEAN | 全部商品可用时传 true |
| productIds | NUMBER[] | 指定商品的商品 ID 列表，取 `productList.id`，如 `[88421001, 88421002]` |
| productCategories | NUMBER[] | 分类 ID，`-1` 表示全部分类 |
| productBrands | NUMBER[] | 品牌 ID，`-1` 表示全部品牌 |
| productTags | NUMBER[] | 标签 ID |

#### expirationDate 子字段

| 参数 | 类型 | 说明 |
|------|------|------|
| expiredAfter | NUMBER | 领取后几天内失效（优先） |
| effectiveFrom | DATETIME | 指定生效开始 |
| effectiveTo | DATETIME | 指定生效结束 |

### 响应数据

- 返回类型：`NUMBER`
- 含义：新建优惠券批次 ID

### 请求示例

**满减券**（满 10 减 1，领取后 7 天有效，指定商品 + 指定客户）：

> **金额单位一律为元**。满 10 元减 1 元 → `throttleAmount=10`、`preference=1`。**禁止**按「分」×100（勿写成 1000 / 100）。

```json
{
  "name": "测试满减",
  "category": "REDUCE",
  "preference": 1,
  "throttleAmount": 10,
  "totalCount": 1,
  "isToB": true,
  "onlyForNewUser": false,
  "additionPromotionEnable": false,
  "expirationDate": { "expiredAfter": 7 },
  "product": {
    "allProductsAvailable": false,
    "productIds": [88421001, 88421002]
  },
  "countPerUser": { "infinite": false, "count": 1 },
  "provideOrgs": [{
    "allUsersAvailable": false,
    "conditionType": "ORG",
    "hierarchy": "HEADQUARTERS",
    "targetIds": [<机构ID>]
  }],
  "acceptOrgs": [{
    "hierarchy": "CUSTOMER",
    "targetIds": [<客户ID>],
    "conditionType": "ID",
    "allUsersAvailable": false
  }],
  "remark": "满10元可用，仅指定商品可用，不可与其它活动叠加使用。"
}
```

    "conditionType": "ORG",
    "hierarchy": "HEADQUARTERS",
    "targetIds": [<机构ID>]
  }],
  "acceptOrgs": [{
    "hierarchy": "CUSTOMER",
    "targetIds": [<客户ID>],

## couponDefinitionsSearch

**功能**：查询优惠券列表，按关键词（优惠券名称/商品名称/商品编码）搜索。

**典型场景**
- 查找某张优惠券是否存在及其ID
- 查看当前有哪些优惠券
- 获取优惠券ID用于效果分析

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| searchKeyWord | STRING | 是 | 否 | 关键词（优惠券名称/商品名称/商品编码） |
| couponDefinitionStatus | STRING | 否 | 否 | 优惠券批次状态（PENDING：待审核，TO_BE_STARTED：未开始，IN_PROGRESS：进行中，FINISHED：已结束，EXPIRED：已失效） |
| sourceType | NUMBER | 否 | 否 | 优惠券来源 |

**响应数据**

- 返回类型：`PAGE`（分页）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | NUMBER | 优惠券ID（用于 couponDiscountSummary 的 definitionId） |
| name | STRING | 优惠券名称 |
| category | STRING | 优惠券类型（REDUCE=满减券，DISCOUNT=折扣券） |
| createTime | DATETIME | 创建时间 |
| creatorName | STRING | 创建人 |

## couponDiscountSummary

**功能**：查询单张优惠券的效果分析，包含展示量、领取量、使用量、转化率、优惠金额、订货金额、ROI等。

**典型场景**
- 分析某张优惠券的使用效果
- 查看优惠券的领取率、转化率、ROI
- 计算优惠券对订货金额的贡献

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| definitionId | NUMBER | 是 | 否 | 优惠券id，先用 couponDefinitionsSearch 获取 |

**响应数据**

- 返回类型：`OBJECT`

| 字段 | 类型 | 说明 |
|------|------|------|
| activityId | NUMBER | 活动Id |
| activityName | STRING | 活动名称 |
| activityType | STRING | 活动类型 |
| displayCount | NUMBER | 展示量 |
| receiveCount | NUMBER | 领取量 |
| usedCount | NUMBER | 使用量 |
| convertRate | NUMBER | 转化率（领取量/展示量） |
| usedConvertRate | STRING | 转化率（使用量/领取量） |
| totalConvertRate | STRING | 整体转化率（使用量/展示量） |
| discountAmount | NUMBER | 优惠金额 |
| orderAmount | NUMBER | 订货金额 |
| orderCount | NUMBER | 订单量 |
| roi | NUMBER | 投资回报比 |
| customerCount | NUMBER | 参与客户数 |
| couponCount | NUMBER | 优惠券领取量 |
| viewCustomerCount | NUMBER | 浏览客户数 |
| createTime | DATETIME | 券创建时间 |

## 跨接口组合示例

**场景**：分析某优惠券效果
1. `couponDefinitionsSearch` → 按名称获取优惠券ID
2. `couponDiscountSummary` → 传入 definitionId 获取详细效果数据

**场景**：比较满减券和折扣券的效果
1. `couponDefinitionsSearch` → 分别搜索满减券和折扣券，获取各自ID
2. 分别调用 `couponDiscountSummary` 对比 roi、convertRate 等指标

**场景**：促销活动效果 → 见 [营销/促销.md](促销.md)
