# 促销活动

本文档覆盖促销活动相关接口，包含促销活动列表查询和效果分析。

## 接口目录
- [promotionActivitiesSearch](#promotionactivitiessearch) - 促销活动列表
- [marketingPromotionActivityList](#marketingpromotionactivitylist) - 查询促销活动效果分析
- [marketingActivityList](#marketingactivitylist) - 营销活动效果分析（促销+优惠券综合）

---

## promotionActivitiesSearch

**功能**：查询促销活动列表，支持按时间范围、关键词、活动状态筛选。

**典型场景**
- 查看当前有哪些促销活动
- 按活动名称或商品名称搜索促销活动
- 获取促销活动ID用于效果分析

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明                                                              |
|------|------|------|------|-----------------------------------------------------------------|
| rangeTime | TIME_RANGE | 否 | 否 | 活动时间范围，对象包含 `startTime` 和 `endTime`，格式：`yyyy-MM-dd HH:mm:ss`    |
| key | STRING | 否 | 否 | 关键词（活动名/商品名/商品编码），模糊搜索                                          |
| promotionActivityStatus | STRING | 否 | 否 | 活动状态：PENDING（待审核）/TO_BE_STARTED（未开始）/IN_PROGRESS（进行中）/FINISHED（已结束）/CANCELLED（已作废） |
| promotionListType | STRING | 否 | 否 | 促销列表类型（toB/toC），默认toB                                           |
| tagList | STRING | 否 | 是 | 促销活动类型标签集合                                                      |

**响应数据**

- 返回类型：`PAGE`（分页）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | NUMBER | 促销活动ID（用于效果分析接口的 definitionId） |
| title | STRING | 活动名称 |
| tag | STRING | 活动类型 |
| promotionActivityStatus | STRING | 活动状态 |
| beginTime | DATETIME | 活动开始时间 |
| endTime | DATETIME | 活动结束时间 |
| createTime | DATETIME | 活动创建时间 |
| creatorName | STRING | 活动创建人 |
| own | BOOLEAN | 是否自主创建 |
| sourceType | NUMBER | 创建来源 |
| estimatedCost | NUMBER | 预估活动成本 |
| createOrgName | STRING | 制单机构名称 |
| createOrgId | STRING | 制单机构Id |

## marketingPromotionActivityList

**功能**：查询单个促销活动的效果分析，包含转化率、订货金额、ROI等核心指标。

**典型场景**
- 分析某个促销活动的效果如何
- 查看活动的参与客户数、订货金额、ROI

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| definitionId | NUMBER | 否 | 否 | 促销活动id，先用 promotionActivitiesSearch 获取 |

**响应数据**

- 返回类型：`OBJECT`

| 字段 | 类型 | 说明 |
|------|------|------|
| activityId | NUMBER | 活动Id |
| activityName | STRING | 活动名称 |
| activityType | STRING | 活动类型 |
| convertRate | NUMBER | 转化率（领取量/展示量） |
| couponCount | NUMBER | 优惠券领取量 |
| createTime | DATETIME | 券创建时间 |
| customerCount | NUMBER | 参与客户数 |
| discountAmount | NUMBER | 优惠金额 |
| displayCount | NUMBER | 展示量 |
| orderAmount | NUMBER | 订货金额 |
| orderCount | NUMBER | 订单量 |
| receiveCount | NUMBER | 领取量 |
| roi | NUMBER | 投资回报比 |
| usedCount | NUMBER | 使用量 |
| viewCustomerCount | NUMBER | 浏览客户数 |

> 注意：该接口当前仅返回 orderCount、orderAmount、discountAmount、roi 字段有实际值，其余字段为空。

## marketingActivityList

**功能**：综合营销活动效果分析（可同时覆盖促销活动和优惠券），支持按时间范围和活动ID筛选。

**典型场景**
- 查看一段时间内所有营销活动的整体效果
- 对促销活动和优惠券进行统一的效果分析

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| rangeTime | TIME_RANGE | 否 | 否 | 统计时间范围，对象包含 `startTime` 和 `endTime`，格式：`yyyy-MM-dd HH:mm:ss` |
| definitionId | NUMBER | 否 | 否 | 促销活动id/优惠券id，传入则精确查某个活动 |

**响应数据**

- 返回类型：`PAGE`（分页）

| 字段 | 类型 | 说明 |
|------|------|------|
| activityId | NUMBER | 活动Id |
| activityName | STRING | 活动名称 |
| activityType | STRING | 活动类型 |
| convertRate | NUMBER | 转化率（领取量/展示量） |
| couponCount | NUMBER | 优惠券领取量 |
| createTime | DATETIME | 券创建时间 |
| customerCount | NUMBER | 参与客户数 |
| discountAmount | NUMBER | 优惠金额 |
| displayCount | NUMBER | 展示量 |
| orderAmount | NUMBER | 订货金额 |
| orderCount | NUMBER | 订单量 |
| receiveCount | NUMBER | 领取量 |
| roi | NUMBER | 投资回报比 |
| usedCount | NUMBER | 使用量 |
| viewCustomerCount | NUMBER | 浏览客户数 |
| totalViewCount | NUMBER | 浏览次数 |
| orderAmountRate | STRING | 促销金额贡献率 |
| customerRate | STRING | 参与率 |
| orgName | STRING | 所属机构 |

## 跨接口组合示例

**场景**：分析某促销活动效果
1. `promotionActivitiesSearch` → 按名称找到活动ID
2. `marketingPromotionActivityList` → 传入 definitionId 获取效果数据

**场景**：查看本月所有营销活动表现
- 直接用 `marketingActivityList` 传本月时间范围，汇总结果

**场景**：优惠券效果 → 见 [营销/优惠券.md](优惠券.md)
