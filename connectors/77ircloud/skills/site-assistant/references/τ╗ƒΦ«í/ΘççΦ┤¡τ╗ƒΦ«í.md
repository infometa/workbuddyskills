# 采购统计

本文档覆盖采购入库商品数据统计接口，支持按供应商汇总、按商品汇总、明细列表及合计等多种维度统计。

## 接口目录
- [purchaseBySupplierReport](#purchasebysupplierreport) - 采购-按供应商汇总报表
- [productPurchaseStatisticsList](#productpurchasestatisticslist) - 采购入库商品数据统计-按商品汇总
- [supplierAndProductPurchaseStatisticsList](#supplierandproductpurchasestatisticslist) - 采购商品汇总-按供应商（分页列表）
- [purchaseDetailBySupplierTotal](#purchasedetailbysuppliertotal) - 采购商品汇总-按供应商（合计）
- [purchaseDetailReport](#purchasedetailreport) - 采购出入库明细列表
- [purchaseDetailList](#purchasedetaillist) - 采购商品明细-列表（分页）
- [purchaseDetailTotal](#purchasedetailtotal) - 采购商品明细-合计

---

## purchaseBySupplierReport

**功能**：按供应商维度汇总采购数据，展示每个供应商各商品的采购数量和金额，包含汇总统计和明细列表。

**典型场景**
- 查看某供应商的采购汇总
- 分析各供应商提供的商品及数量
- 了解整体采购订单与退单金额对比

**参数**
| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| rangeTime | TIME_RANGE | 是 | 否 | 出入库时间 |
| productInfo | STRING | 否 | 否 | 商品名称/规格/条形码，模糊搜索 |
| supplierInfo | STRING | 否 | 否 | 供应商名称/编码/联系人/电话，模糊搜索 |
| purchaseOrderCode | STRING | 否 | 否 | 采购订单/退单号，精确查询 |
| storageOrderCode | STRING | 否 | 否 | 出/入库单号，精确查询 |
| orderType | STRING | 否 | 是 | 采购订单/退单，1:采购订单, 2:采购退单 |
| warehouseIds | NUMBER | 否 | 是 | 仓库ID列表 |

**响应数据**
- 返回类型：`PAGE`（分页）
| 字段 | 类型 | 说明 |
|------|------|------|
| supplierId | NUMBER | 供应商ID |
| supplierName | STRING | 供应商名称 |
| productCode | STRING | 商品编码 |
| productName | STRING | 商品名称 |
| productSpec | STRING | 商品规格 |
| productBarCode | STRING | 商品条形码 |
| categoryName | STRING | 商品分类 |
| brandName | STRING | 商品品牌 |
| unitName | STRING | 单位 |
| totalCount | NUMBER | 合计数量 |
| totalAmount | NUMBER | 合计金额 |

**典型场景**
- 查看某段时间内各商品的采购量
- 分析采购订单与采购退单的对比
- 了解总体采购笔数和金额汇总

**参数**

|------|------|------|------|------|

| purchaseOrderCode | STRING | 否 | 否 | 采购订单/退单号，精确查询 |
| storageOrderCode | STRING | 否 | 否 | 出/入库单号，精确查询 |

## 接口选择指引

| 用户意图 | 推荐接口 |
|----------|----------|
| "各商品采购量" | productPurchaseStatisticsList |
| "某供应商采购了哪些商品（汇总）" | purchaseBySupplierReport |
| "某供应商采购了哪些商品（分页明细）" | supplierAndProductPurchaseStatisticsList |
| "采购出入库明细记录" | purchaseDetailReport 或 purchaseDetailList |
| "同一商品不同供应商价格" | supplierAndProductPurchaseStatisticsList（传 productInfo）|
| "采购退单统计" | productPurchaseStatisticsList（orderType=2）|
| "采购汇总合计数字" | purchaseDetailTotal 或 purchaseDetailBySupplierTotal |

## 接口配对说明

以下接口成对使用（入参相同，分别返回分页列表和合计）：
- `purchaseDetailList` + `purchaseDetailTotal` → 采购商品明细（按商品视角）
- `supplierAndProductPurchaseStatisticsList` + `purchaseDetailBySupplierTotal` → 采购商品汇总（按供应商视角）
