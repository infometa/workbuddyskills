# 业务员任务看板

本文档覆盖业务员任务看板相关接口，包括按业务员维度统计任务完成情况、查看客户跟进详情。

## 接口目录
- [searchSalesManagement](#searchsalesmanagement) - 业务员任务看板列表
- [searchSalesManagementCustomer](#searchsalesmanagementcustomer) - 业务员任务客户详情

---

## searchSalesManagement

**功能**：按业务员维度查询任务看板列表，展示每个业务员的跟进客户总数、已完成/待跟进数量、完成比例等核心指标。

**典型场景**
- 查看各业务员的任务完成情况排行
- 监控业务员的客户跟进进度
- 按模块（新客跟进/到期未下单/流失客户/欠款客户/下单异常等）筛选任务
- 对比上期数据，了解跟进趋势变化
- 查看某业务员负责的客户跟进概况

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| timeRange | TIME_RANGE | 否 | 否 | 时间范围 |
| currentPage | NUMBER | 否 | 否 | 当前页 |
| pageSize | NUMBER | 否 | 否 | 分页大小 |
| isIncludeZeroVisit | BOOLEAN | 否 | 否 | 是否查询未拜访数为0的数据 |
| lastTimeRange | TIME_RANGE | 否 | 否 | 上期时间范围 |
| module | STRING | 否 | 否 | 模块，可选值：newCustomerFollow(新客跟进)、orderExpiredNoOrder(到期未下单)、lossCustomer(流失客户)、overdueCustomer(欠款客户)、orderExpiredNoPayment(到期未付款)、orderOverdueNoPayment(逾期未付款)、orderException(下单异常)、orderCountRingRatioDrop(近期订单锐减)、orderVolumePlummeted(订货额暴跌)、orderSkusDrop(订货种类下降) |
| salesId | NUMBER | 否 | 否 | 业务员ID |
| salesIds | NUMBER | 否 | 是 | 业务员ID列表（权限过滤用） |

**响应数据**
- 返回类型：`PAGE`（分页）

| 字段 | 类型 | 说明 |
|------|------|------|
| customerCount | NUMBER | 跟进客户总数 |
| customerDoneCount | NUMBER | 客户已跟进数量 |
| customerWaitCount | NUMBER | 客户待跟进数量 |
| departmentId | NUMBER | 部门ID |
| departmentName | STRING | 业务员部门 |
| employeeNo | STRING | 业务员工号 |
| mobile | STRING | 业务员手机号 |
| orgId | NUMBER | 机构ID |
| orgName | STRING | 业务员机构名称 |
| proportion | NUMBER | 完成比例 |
| regionId | NUMBER | 区域ID |
| regionName | STRING | 区域名称 |
| roleId | NUMBER | 角色ID |
| roleName | STRING | 角色名称 |
| salesId | NUMBER | 业务员ID |
| salesName | STRING | 业务员名称 |

## searchSalesManagementCustomer

**功能**：按客户维度查看业务员任务详情，展示每个待跟进客户的订货情况、异常信息、客单价等详细数据。

**典型场景**
- 查看某业务员名下待跟进的客户列表
- 了解流失客户的具体订货数据（上次订货时间、订货金额等）
- 分析订货异常客户（对比上月订货金额变化）
- 查看客户的基本信息（分类、标签、结算模式、信用额度等）
- 按模块筛选查看不同类型的任务客户

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| timeRange | TIME_RANGE | 否 | 否 | 时间范围 |
| currentPage | NUMBER | 否 | 否 | 当前页 |
| pageSize | NUMBER | 否 | 否 | 分页大小 |
| isIncludeZeroVisit | BOOLEAN | 否 | 否 | 是否查询未拜访数为0的数据 |
| lastTimeRange | TIME_RANGE | 否 | 否 | 上期时间范围 |
| module | STRING | 否 | 否 | 模块，可选值：newCustomerFollow(新客跟进)、orderExpiredNoOrder(到期未下单)、lossCustomer(流失客户)、overdueCustomer(欠款客户)、orderExpiredNoPayment(到期未付款)、orderOverdueNoPayment(逾期未付款)、orderException(下单异常)、orderCountRingRatioDrop(近期订单锐减)、orderVolumePlummeted(订货额暴跌)、orderSkusDrop(订货种类下降) |
| salesId | NUMBER | 否 | 否 | 业务员ID |
| salesIds | NUMBER | 否 | 是 | 业务员ID列表（权限过滤用） |

| customerId | NUMBER | 客户ID |
| customerName | STRING | 客户名称 |

| orderAmountLastMonth | NUMBER | 上月订单金额 |

## 接口选择指引

| 用户意图 | 推荐接口 |
|----------|----------|
| "各业务员的任务跟进情况"、"看板列表" | searchSalesManagement |
| "某业务员还有多少客户待跟进" | searchSalesManagement（传 salesId） |
| "新客户跟进任务的完成排行" | searchSalesManagement（传 module + timeRange） |
| "流失客户有哪些、分别的订货情况" | searchSalesManagementCustomer（传 module=lossCustomer） |
| "某客户的订货异常详情" | searchSalesManagementCustomer（传 customerId 或 salesId） |

## 跨接口组合示例

**场景**：查看某业务员的流失客户跟进任务及详情
1. `searchSalesManagement` → 传入 salesId + module=lossCustomer，获取该业务员的任务概览
2. `searchSalesManagementCustomer` → 传入相同 salesId + module=lossCustomer，获取流失客户明细

**场景**：按业务员查看不同类型的任务客户详情
1. `searchSalesManagement` → 获取业务员ID和姓名列表
2. `searchSalesManagementCustomer` → 传入 salesId + module，获取该业务员某模块的客户明细

**场景**：跟进客户前获取客户完整信息
1. `searchSalesManagementCustomer` → 传入 customerId，获取任务相关客户数据
2. `customerList`（见客户与商机/客户.md）→ 传入 ids，获取客户基础信息和标签
