# 司机业绩统计

本文档覆盖司机配送业绩统计接口，包含汇总统计与配送明细。

## 接口目录
- [driverPerformanceTotalList](#driverperformancetotallist) - 司机业绩统计
- [driverPerformanceDetailList](#driverperformancedetaillist) - 司机业绩明细

---

## driverPerformanceTotalList

**功能**：按司机维度统计配送业绩，包含配送单数、配送金额、服务客户数等。

**典型场景**
- 查看各司机的配送业绩排行
- 分析司机的配送效率和客户覆盖情况
- 统计某机构下所有司机的业绩对比

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| rangeTime | TIME_RANGE | 是 | 否 | 统计时间 |
| driverIds | NUMBER | 否 | 是 | 司机ID列表 |

**响应数据**
- 返回类型：`PAGE`（分页）

| 字段 | 类型 | 说明 |
|------|------|------|
| driverId | NUMBER | 司机ID |
| driverName | STRING | 司机名称 |
| orderCount | NUMBER | 配送单数 |
| totalAmount | NUMBER | 配送金额 |
| customerCount | NUMBER | 配送客户数 |
| deliveryCount | NUMBER | 商品数量 |
| weight | NUMBER | 配送重量 |

**driverIds 获取说明**
- `driverId` 与员工 ID 对应，可通过 `employeeList` 接口查询员工列表获取
- 也可从发货单查询（`findDispatchBills`）的响应中获取 `driverId`

## driverPerformanceDetailList

**功能**：按发货单维度展示司机配送明细，包含发货单号、客户、商品数量、重量、金额等。

**典型场景**
- 查看某司机的逐单配送明细
- 按发货单追踪司机的配送记录
- 统计某时段内司机的配送详情

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| rangeTime | TIME_RANGE | 是 | 否 | 统计时间 |
| driverIds | NUMBER | 否 | 是 | 司机ID列表 |

**响应数据**
- 返回类型：`PAGE`（分页）

| 字段 | 类型 | 说明 |
|------|------|------|
| driverId | NUMBER | 司机ID |
| driverName | STRING | 司机 |
| createTime | DATETIME | 下单时间 |
| deliveryTime | DATETIME | 发货时间 |
| orderCode | STRING | 单号 |
| outStorageCode | STRING | 出库单号 |
| customerCode | STRING | 往来单位编码 |
| customerName | STRING | 往来单位名称 |
| contactName | STRING | 联系人 |
| contactPhone | STRING | 联系电话 |
| deliveryAddress | STRING | 配送地址 |
| productName | STRING | 商品 |
| productCode | STRING | 商品编码 |
| barcode | STRING | 商品条码 |
| spec | STRING | 规格 |
| unitId | NUMBER | 单位ID |
| unitName | STRING | 单位 |
| count | NUMBER | 数量 |
| statisticsUnitId | NUMBER | 统计单位ID |
| statisticsUnitName | STRING | 统计单位名称 |
| statisticsCount | NUMBER | 统计数量 |
| weight | NUMBER | 重量 |
| price | NUMBER | 单价 |
| amount | NUMBER | 金额 |
| warehouseName | STRING | 出库仓库 |
| plateNumber | STRING | 车牌号 |
| remark | STRING | 物流备注 |

## 接口选择指引

| 用户意图 | 推荐接口 |
|----------|----------|
| "司机配送业绩排行" | driverPerformanceTotalList |
| "某司机业绩汇总" | driverPerformanceTotalList（传 driverIds）|
| "某司机配送明细" | driverPerformanceDetailList（传 driverIds）|
| "某机构司机业绩对比" | driverPerformanceTotalList（传 orgId + rangeTime）|

## 跨接口组合示例

**场景**：查看指定司机的配送业绩
1. `employeeList` → 获取员工列表，找到目标司机的员工 ID（员工.md）
2. `driverPerformanceTotalList` → 传入 driverIds + rangeTime

**场景**：查看指定司机的配送明细
1. `driverPerformanceTotalList` → 先查看司机汇总，确定目标司机
2. `driverPerformanceDetailList` → 传入 driverIds + rangeTime，获取该司机的逐单配送明细
