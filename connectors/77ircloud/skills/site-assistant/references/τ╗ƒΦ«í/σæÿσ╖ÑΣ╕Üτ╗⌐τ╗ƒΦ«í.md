# 员工业绩统计

本文档覆盖员工销售业绩统计接口。

## 接口目录
- [salesPerformanceList](#salesperformancelist) - 员工业绩统计

---

## salesPerformanceList

**功能**:按业务员维度统计销售业绩,包含销售金额、数量、毛利、毛利率、应收、回款金额、服务客户数及新增/下单客户数。

**典型场景**
- 查看各业务员的销售业绩排行
- 分析业务员的毛利率和应收情况
- 了解某业务员服务了多少客户、新增了多少客户
- 统计下单客户数(即活跃客户数)
- 查看业务员的应收账款和回款情况
- 按商品/品牌/分类筛选特定商品的业绩表现

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| rangeTime | TIME_RANGE | 是 | 否 | 统计时间 |
| salesIds | NUMBER | 否 | 是 | 员工ID列表 |
| q | STRING | 否 | 否 | 业务员名称，模糊搜索 |
| departmentIds | NUMBER | 否 | 是 | 部门ID列表，按部门筛选 |
| skuIds | NUMBER | 否 | 是 | 商品ID列表，按商品筛选 |
| brandIds | NUMBER | 否 | 是 | 商品品牌ID列表，按品牌筛选 |
| categoryIds | NUMBER | 否 | 是 | 商品分类ID列表，按分类筛选 |
| productTagIds | NUMBER | 否 | 是 | 商品标签ID列表，按标签筛选 |
| productRange | NUMBER | 否 | 否 | 商品统计范围，0:全部商品(默认)，1:仅公有 |
| regionIds | NUMBER | 否 | 是 | 业务员区域ID列表 |

**响应数据**
- 返回类型：`PAGE`（分页）

| 字段 | 类型 | 说明 |
|------|------|------|
| salesId | NUMBER | 业务员ID |
| salesName | STRING | 业务员名称 |
| deptName | STRING | 所属部门 |
| saleMoney | NUMBER | 销售金额 |
| salesCount | NUMBER | 销售数量 |
| soldProfit | NUMBER | 毛利金额 |
| soldProfitRate | NUMBER | 毛利率 |
| receivableMoney | NUMBER | 应收账款金额 |
| receivableDecreaseMoney | NUMBER | 销售回款金额 |
| respCustomerCount | NUMBER | 服务客户数 |
| newCustomerCount | NUMBER | 新增客户数 |
| orderCustomerCount | NUMBER | 下单客户数 |

## 接口选择指引

| 用户意图 | 推荐接口 |
|----------|----------|
| "各业务员销售额排行" | salesPerformanceList（按 saleMoney 排序，默认排序）|
| "某业务员的毛利表现" | salesPerformanceList（传 salesIds）|
| "业务员新增客户排行" | salesPerformanceList（按 newCustomerCount 排序）|
| "下单活跃客户数最多的业务员" | salesPerformanceList（按 orderCustomerCount 排序）|
| "某部门本月业绩对比" | salesPerformanceList（传 departmentIds + rangeTime）|
| "某商品的销售业绩" | salesPerformanceList（传 skuIds 或 brandIds 或 categoryIds）|

## 跨接口组合示例

**场景**：查看某部门本月所有业务员的业绩对比
1. `employeeList` → 获取该部门的员工ID列表（员工部门/员工机构.md）
2. `salesPerformanceList` → 传入 salesIds + rangeTime，汇总对比各业务员业绩

**场景**：查看当前机构本月所有业务员的业绩对比
1. `getMyOrganizationUnit` → 获取当前登录机构的 orgId（组织.md）
2. `salesPerformanceList` → 传入 orgId + rangeTime，查看该机构下所有业务员业绩
