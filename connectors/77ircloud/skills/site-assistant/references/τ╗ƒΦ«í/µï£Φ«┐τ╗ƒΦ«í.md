# 拜访统计

本文档覆盖销售拜访相关的统计接口，包括拜访汇总、拜访明细、拜访计划明细及计划汇总。

## 接口目录
- [salesVisitSummary](#salesvisitsummary) - 销售拜访汇总
- [salesVisitList](#salesvisitlist) - 拜访明细(按业务员)
- [visitPlanSummary](#visitplansummary) - 拜访计划汇总
- [visitPlanList](#visitplanlist) - 拜访计划明细

---

## salesVisitSummary

**功能**：获取销售拜访的全局汇总数据，包括客户覆盖率、成单率、计划完成率等核心指标。

**典型场景**
- 了解某时间段整体拜访情况（覆盖率、成单率）
- 查看某机构或某业务员的拜访绩效概览
- 监控异常拜访数量

**参数**
| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| rangeTime | TIME_RANGE | 是 | 否 | 拜访时间 |
| saleIds | NUMBER | 否 | 是 | 业务员(员工ID) |
| departmentIds | NUMBER | 否 | 是 | 所属部门ID |
| customerStatus | NUMBER | 否 | 否 | 客户状态 |
| saleStatus | NUMBER | 否 | 否 | 业务员状态 |
| containAllOrg | BOOLEAN | 否 | 否 | 是否包含所有下属机构 |

**响应数据**
- 返回类型：`OBJECT`
| 字段 | 类型 | 说明 |
|------|------|------|
| totalCustomerNumber | NUMBER | 客户总数 |
| totalVisitCustomerNumber | NUMBER | 拜访客户数 |
| totalCoverage | STRING | 覆盖率 |
| totalNumberOfCustomer | NUMBER | 成交客户数 |
| totalOrderNumber | NUMBER | 成交订单数 |
| totalVisitOrderRate | STRING | 成单率 |
| totalAbnormalNumber | NUMBER | 异常拜访数 |
| totalPlanNumber | NUMBER | 计划拜访数 |
| totalPlanRate | NUMBER | 计划完成率 |

---

## salesVisitList

**功能**：按业务员维度展示拜访明细，包含各业务员的拜访次数、成单情况、覆盖率等。

**典型场景**
- 查看各业务员的拜访排行
- 对比不同业务员的拜访成单率
- 分析业务员的计划执行率
- 找出拜访量少或成单率低的业务员

**参数**
| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| rangeTime | TIME_RANGE | 是 | 否 | 拜访时间 |
| saleIds | NUMBER | 否 | 是 | 业务员ID |
| departmentIds | NUMBER | 否 | 是 | 所属部门ID |
| sort | SORT | 否 | 否 | 排序，默认visitNumber:desc |
| customerStatus | NUMBER | 否 | 否 | 客户状态 |
| saleStatus | NUMBER | 否 | 否 | 业务员状态 |
| containAllOrg | BOOLEAN | 否 | 否 | 是否包含所有下属机构 |

**响应数据**
- 返回类型：`PAGE`（分页）
| 字段 | 类型 | 说明 |
|------|------|------|
| salesName | STRING | 业务员 |
| salesId | NUMBER | 业务员ID |
| departmentName | STRING | 部门 |
| departmentId | NUMBER | 部门ID |
| responsibleNumber | NUMBER | 负责客户数 |
| visitNumber | NUMBER | 拜访客户数 |
| coverage | STRING | 覆盖率 |
| customerNumber | NUMBER | 成交客户数 |
| orderNumber | NUMBER | 成交单数 |
| visitRate | NUMBER | 拜访成交率 |
| orderAmount | NUMBER | 成交金额(需订单价格权限) |
| totalVisitNumber | NUMBER | 总拜访次数 |
| errorVisitNumber | NUMBER | 异常拜访数 |
| planVisitNumber | NUMBER | 计划拜访数 |
| realVisitNumber | NUMBER | 实际拜访数 |
| planRate | NUMBER | 计划完成率 |
| noVisitNumber | NUMBER | 未拜访数 |
| temporaryVisitsNumber | NUMBER | 临时拜访数 |
| orgName | STRING | 所属机构 |

---

## visitPlanSummary

**功能**:获取拜访计划的汇总统计信息,包含计划拜访总数、完成数、完成率及成交情况。

**典型场景**
- 查看所有拜访计划的整体执行情况
- 统计计划拜访的总体完成率
- 了解计划内的总体成交情况

**参数**
| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| rangeTime | TIME_RANGE | 是 | 否 | 拜访时间 |
| planId | NUMBER | 否 | 否 | 拜访计划ID，指定某个计划 |
| saleIds | NUMBER | 否 | 是 | 业务员ID |
| departmentIds | NUMBER | 否 | 是 | 所属部门ID |
| customerStatus | NUMBER | 否 | 否 | 客户状态 |
| saleStatus | NUMBER | 否 | 否 | 业务员状态 |
| containAllOrg | BOOLEAN | 否 | 否 | 是否包含所有下属机构 |

**响应数据**
- 返回类型：`OBJECT`
| 字段 | 类型 | 说明 |
|------|------|------|
| planVisitTotalNumber | NUMBER | 计划拜访数 |
| planVisitOkTotalNumber | NUMBER | 计划完成数 |
| planVisitOkTotalRate | STRING | 计划完成率 |
| orderCustomerTotalNumber | NUMBER | 成交客户数 |
| orderTotalNumber | NUMBER | 成交单数 |
| orderTotalAmount | OBJECT | 成单金额(需订单价格权限) |
| orderOkTotalRate | STRING | 成单率 |
| planVisitErrorTotalNumber | STRING | 异常拜访数 |

---

## visitPlanList

**功能**：查询拜访计划的完成情况明细，包括计划拜访客户数、实际完成情况、成交情况。

**典型场景**
- 查看某拜访计划的执行进度
- 统计某业务员的计划完成率
- 了解计划内成交情况

**参数**
| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| rangeTime | TIME_RANGE | 是 | 否 | 拜访时间 |
| planId | NUMBER | 否 | 否 | 拜访计划ID，指定某个计划 |
| saleIds | NUMBER | 否 | 是 | 业务员ID |
| departmentIds | NUMBER | 否 | 是 | 所属部门ID |
| customerStatus | NUMBER | 否 | 否 | 客户状态 |
| saleStatus | NUMBER | 否 | 否 | 业务员状态 |
| containAllOrg | BOOLEAN | 否 | 否 | 是否包含所有下属机构 |

**响应数据**
- 返回类型：`PAGE`（分页）
| 字段 | 类型 | 说明 |
|------|------|------|
| planName | STRING | 计划名称 |
| planId | NUMBER | 计划ID |
| startTime | DATETIME | 计划起始时间 |
| endTime | DATETIME | 计划结束时间 |
| salesName | STRING | 业务员 |
| salesId | NUMBER | 业务员ID |
| departmentName | STRING | 部门 |
| departmentId | NUMBER | 部门ID |
| planVisitNumber | NUMBER | 计划拜访客户数 |
| planVisitOkNumber | NUMBER | 拜访完成客户数 |
| planVisitNoneNumber | NUMBER | 未拜访客户数 |
| planVisitErrorNumber | NUMBER | 异常拜访数 |
| planVisitOkRate | NUMBER | 计划完成率 |
| orderCustomerNumber | NUMBER | 成交客户数 |
| orderNumber | NUMBER | 成交单数 |
| orderOkRate | NUMBER | 拜访成交率 |
| orderTotalAmount | NUMBER | 成交金额(需订单价格权限) |
| orgName | STRING | 所属机构 |

## 接口选择指引

| 用户意图 | 推荐接口 |
|----------|----------|
| "整体拜访情况概览" | salesVisitSummary |
| "各业务员拜访排行" | salesVisitList |
| "某业务员拜访成单率" | salesVisitList(传 saleIds)|
| "某拜访计划完成情况" | visitPlanList(传 planId)|
| "拜访计划整体执行率" | visitPlanSummary |
| "业务员临时拜访统计" | salesVisitList(关注 temporaryVisitsNumber)|
| "异常拜访分析" | salesVisitSummary/salesVisitList(关注 totalAbnormalNumber/errorVisitNumber)|

## 跨接口组合示例

**场景**:查看本月各业务员拜访概况及成交金额
1. `salesVisitSummary` → 获取整体汇总(覆盖率、成单率)
2. `salesVisitList` → 获取每个业务员的明细数据,找出表现优秀/落后的业务员

**场景**:分析拜访计划执行效果
1. `visitPlanSummary` → 查看所有计划的整体完成率
2. `visitPlanList` → 查看每个计划的详细执行情况,找出执行率低的原因
