# 订货统计

本文档覆盖订货统计相关接口，包括订单商品明细的汇总统计（支持按商品、商品+单位、客户+商品、客户+商品+单位、品牌、分类等维度）以及往来单位未出库订单金额合计。

## 接口目录
- [productOrderProductCategorySummary](#productorderproductcategorysummary) - 订单商品明细-按商品汇总
- [productAndUnitOrderProductCategorySummary](#productandunitorderproductcategorysummary) - 订单商品明细-按商品和下单单位汇总
- [customerAndProductOrderProductCategorySummary](#customerandproductorderproductcategorysummary) - 订单明细-按客户和商品汇总
- [customerAndProductAndUnitOrderProductCategorySummary](#customerandproductandunitorderproductcategorysummary) - 订单明细-按客户和商品和下单单位汇总
- [productBrandOrderProductCategorySummary](#productbrandorderproductcategorysummary) - 订单商品明细-按商品品牌汇总
- [productCategoryOrderProductCategorySummary](#productcategoryorderproductcategorysummary) - 订单商品明细-按商品分类汇总
- [buyerUnshippedAmountReport](#buyerunshippedamountreport) - 往来单位未出库订单金额合计

---

## productOrderProductCategorySummary

**功能**：按商品维度汇总订单明细，查看每个商品的订货数量、金额、出库率。

**典型场景**
- 查看各商品的订货量排行
- 分析某品牌或分类下商品的订货情况
- 筛选特定状态的订单中商品销量

**参数**
| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| currentPage | NUMBER | 否 | 否 | 当前页码，默认1 |
| pageSize | NUMBER | 否 | 否 | 每页条数，默认30 |
| rangeTime | TIME_RANGE | 是 | 否 | 下单时间范围，对象包含 `startTime` 和 `endTime`，格式：`yyyy-MM-dd HH:mm:ss` |
| toggleQueryMode | NUMBER | 是 | 否 | 查询模式，1:ADB, null:MYSQL，默认1 |
| orderStatuses | STRING | 否 | 是 | 单据状态，默认[ORDER_AUDIT_PENDING,FINANCE_AUDIT_PENDING,AUDITED,FINISHED]，AUDITED:已审核, FINISHED:已完成, CANCELLED:已取消 |
| brandIds | NUMBER | 否 | 是 | 商品品牌ID列表 |
| buyerIds | NUMBER | 否 | 是 | 往来单位ID列表，精确查某客户 |
| categoryIds | NUMBER | 否 | 是 | 商品分类ID列表 |
| skuIds | NUMBER | 否 | 是 | 商品ID列表，精确查某商品 |
| storageOutStatuses | STRING | 否 | 是 | 出库状态，FULL:全部出库, NONE:未出库, PART:部分出库 |
| orderCategorys | STRING | 否 | 是 | 订单类别，NORMAL:普通订单, GIFT:赠品订单, SAMPLE:样品订单 |
| buyerTypes | STRING | 否 | 是 | 买家类型，BRANCH:分公司, STORE:门店, CUSTOMER:客户 |
| createRole | STRING | 否 | 否 | 下单角色，SELLER:代下单, BUYER:自主下单 |
| yjdfTypes | STRING | 否 | 是 | 是否代发，TOB:是, NO:否 |
| customerTagIds | NUMBER | 否 | 是 | 客户标签ID列表 |
| customerCategoryIds | NUMBER | 否 | 是 | 客户分类ID列表 |
| salesmanIds | NUMBER | 否 | 是 | 业务员ID列表 |
| warehouseIds | NUMBER | 否 | 是 | 仓库ID列表 |
| deliveryMethodIds | NUMBER | 否 | 是 | 配送方式ID列表 |

**响应数据**
- 返回类型：`PAGE`（分页）
| 字段 | 类型 | 说明 |
|------|------|------|
| total | NUMBER | 总条数 |
| pages | NUMBER | 总页数 |
| productName | STRING | 商品名称 |
| productCode | STRING | 商品编码 |
| categoryName | STRING | 分类名称 |
| brandName | STRING | 品牌名称 |
| purchaseNumbers | NUMBER | 购买数量 |
| salePrice | NUMBER | 销售单价 |
| discountAmount | NUMBER | 优惠金额 |
| subtotal | NUMBER | 金额小计 |
| outStorageRate | NUMBER | 出库发货率 |

## buyerUnshippedAmountReport

**功能**：统计往来单位（客户）的未出库订单金额合计，按买家维度返回每个客户尚未出库的订单金额。

**典型场景**
- 查看某客户当前还有多少订单金额尚未出库
- 批量查询多个客户的未出库订单金额合计

**参数**
| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| buyerIds | NUMBER | 否 | 是 | 往来单位ID列表，指定一个或多个客户；不传则统计所有往来单位 |
| rangeTime | TIME_RANGE | 是 | 否 | 下单时间范围 |
| orderTypes | STRING | 否 | 是 | 订单类型，NORMAL:普通机构订单, PURCHASE:采购订单, ALLOTMENT:调拨单, MERCHANT:商家订单, PRE_SALE:预售订单 |

**响应数据**
- 返回类型：`ARRAY`（数组，按买家维度返回）
| 字段 | 类型 | 说明 |
|------|------|------|
| buyerId | NUMBER | 买家ID |
| unshippedAmount | NUMBER | 未出库金额合计（单位：元） |
