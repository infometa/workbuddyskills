# 销售统计

本文档覆盖订单出入库明细查询、汇总统计相关接口，按不同维度（明细、按商品、按往来）提供销售数据的查询与合计。

## 接口目录
- [findCustomerStorageBills](#findcustomerstoragebills) - 订单出入库明细
- [findCustomerTotalStorageBills](#findcustomertotalstoragebills) - 订单出入库明细-合计信息
- [findCustomerStorageBillsBySku](#findcustomerstoragebillsbysku) - 订单出入库汇总-按商品
- [findCustomerTotalStorageBillsBySku](#findcustomertotalstoragebillsbysku) - 订单出入库汇总-按商品（合计）
- [findCustomerStorageBillsByCustomer](#findcustomerstoragebillsbycustomer) - 订单销售汇总（按往来）
- [findCustomerTotalStorageBillsByCustomer](#findcustomertotalstoragebillsbycustomer) - 订单销售汇总（按往来）-合计

---

## findCustomerStorageBills

**功能**：查询订单出入库明细列表，支持按时间范围、客户、商品、往来单位、订单类型、品牌分类、业务员、区域、仓库等多维度筛选。

**典型场景**
- 查询某段时间内的出入库明细记录
- 按客户或往来单位筛选出入库单据
- 查看特定商品的出入库流水

**参数**
| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| rangeTime | TIME_RANGE | 是 | 否 | 出入库时间范围 |
| q | STRING | 否 | 否 | 商品信息（支持商品名称/编码/商品简称/条码模糊搜索） |
| buyerIds | NUMBER | 否 | 是 | 往来单位ID集 |
| buyerTypes | STRING | 否 | 是 | 买家机构类型 |
| hierarchyOrderTypes | NUMBER | 否 | 是 | 订单类型（1:分公司订单,2:门店订单,3:客户订单,4:分公司代发订单,5:门店代发订单） |
| categoryIds | NUMBER | 否 | 是 | 商品分类ID |
| brandIds | NUMBER | 否 | 是 | 商品品牌ID |
| regionIds | NUMBER | 否 | 是 | 区域ID |
| salesIds | NUMBER | 否 | 是 | 业务员ID |
| salesDepartmentIds | NUMBER | 否 | 是 | 业务员部门ID |
| billNum | STRING | 否 | 否 | 单号（支持订单/退单/出库单） |
| warehouseIds | NUMBER | 否 | 是 | 仓库ID |
| searchType | NUMBER | 否 | 否 | 搜索类型（1:全部,2:仅汇总套餐商品,默认1） |
| onlyPackageDetail | NUMBER | 否 | 否 | 是否套餐明细（1:是,2:否） |

| categoryName | STRING | 商品分类 |

## findCustomerTotalStorageBills

**功能**：查询订单销售明细的合计信息，返回单据笔数、数量、金额的汇总。

> **与 findCustomerStorageBills 的区别**：`findCustomerStorageBills` 返回明细列表（分页）；`findCustomerTotalStorageBills` 返回合计汇总数据，不分页。

**参数**（与 [findCustomerStorageBills](#findcustomerstoragebills) 一致）

**响应数据**
- 返回类型：`OBJECT`
| 字段 | 类型 | 说明 |
|------|------|------|
| billCount | NUMBER | 单据笔数合计 |
| orderCount | NUMBER | 下单数量合计 |
| orderMoney | NUMBER | 金额合计 |

| brandIds | NUMBER | 否 | 是 | 商品品牌ID |
| regionIds | NUMBER | 否 | 是 | 区域ID |
| salesIds | NUMBER | 否 | 是 | 业务员ID |
| salesDepartmentIds | NUMBER | 否 | 是 | 业务员部门ID |
| buyerIds | NUMBER | 否 | 是 | 往来单位ID集 |
| buyerTypes | STRING | 否 | 是 | 买家机构类型 |
| hierarchyOrderTypes | NUMBER | 否 | 是 | 订单类型（1:分公司订单,2:门店订单,3:客户订单,4:分公司代发订单,5:门店代发订单） |
| warehouseIds | NUMBER | 否 | 是 | 仓库ID |
| onlyPackageDetail | NUMBER | 否 | 否 | 是否套餐明细（1:是,2:否） |

**响应数据**

| 字段 | 类型 | 说明 |

## 跨接口组合示例

**场景**：查看某段时间内各客户的销售金额并获取汇总
1. `findCustomerStorageBillsByCustomer` → 传入 storageTimeBegin + storageTimeEnd，获取各客户的销售金额列表
2. `findCustomerTotalStorageBillsByCustomer` → 传入相同筛选条件，获取金额合计
