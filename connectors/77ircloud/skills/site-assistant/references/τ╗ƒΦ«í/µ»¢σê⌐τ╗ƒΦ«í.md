# 毛利统计

本文档覆盖销售毛利统计接口，分为全局汇总和三种分组汇总（按出库单、按出库单+商品、按客户+商品）。

## 接口目录
- [saleProfitSummary](#saleprofitsummary) - 销售毛利统计（全局汇总）
- [outBillSaleProfitSummary](#outbillsaleprofitsummary) - 销售毛利统计（按出库单）
- [outBillAndProductSaleProfitSummary](#outbillandproductsaleprofitsummary) - 销售毛利统计（按出库单+商品）
---

## saleProfitSummary（全局汇总）

**功能**：获取销售毛利的全局汇总数据，返回总销售金额、总成本、总毛利、总毛利率。

**典型场景**
- 快速了解某时间段的总体毛利情况
- 按客户分类或商品分类过滤查看毛利汇总
- 切换不同查询维度（按订单/订单+商品/客户+商品）查看汇总

**参数**
| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| searchType | NUMBER | 否 | 否 | 查询维度，1:按订单统计(默认), 2:订单+商品, 3:客户+商品 |
| relatedId | NUMBER | 否 | 否 | 往来单位(客户ID、分公司ID、门店ID) |
| relatedOrgType | STRING | 否 | 否 | 往来单位类型，HEADQUARTERS:总部, BRANCH:分公司, STORE:门店, CUSTOMER:客户 |
| cusCategoryIds | NUMBER | 否 | 是 | 客户分类(客户分类ID) |
| customerTagIds | NUMBER | 否 | 是 | 客户标签ID |
| categoryIds | NUMBER | 否 | 是 | 商品分类(商品分类ID) |
| brandIds | NUMBER | 否 | 是 | 商品品牌(商品品牌ID) |
| rangeTime | TIME_RANGE | 是 | 否 | 统计时间 |
| salesIds | NUMBER | 否 | 是 | 业务员ID |
| departmentIds | NUMBER | 否 | 是 | 部门ID |
| productRange | NUMBER | 否 | 否 | 商品统计范围，0:全部商品(默认), 1:仅公有 |
| q | STRING | 否 | 否 | 商品信息，名称/编码/条码模糊搜索 |
| warehouseIds | NUMBER | 否 | 是 | 出库仓库ID |

**响应数据**
- 返回类型：`OBJECT`
  | 字段 | 类型 | 说明 |
  |------|------|------|
  | salesAmount | NUMBER | 销售金额(需订单价格权限) |
  | costAmount | NUMBER | 销售成本(需成本价权限) |
  | soldProfit | NUMBER | 销售毛利(需成本价权限) |
  | profitRateResult | STRING | 毛利率(需成本价权限) |

## outBillSaleProfitSummary（按出库单）

**功能**：按出库单维度查看销售毛利明细，每行对应一张出库单（searchType=1）。

**典型场景**
- 查看每张出库单的毛利情况
- 分析哪些订单毛利率较低
- 筛选特定客户的出库单毛利

**参数**
| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| rangeTime | TIME_RANGE | 是 | 否 | 统计时间 |
| relatedId | NUMBER | 否 | 否 | 往来单位(客户ID、分公司ID、门店ID) |
| relatedOrgType | STRING | 否 | 否 | 往来单位类型，HEADQUARTERS:总部, BRANCH:分公司, STORE:门店, CUSTOMER:客户 |
| cusCategoryIds | NUMBER | 否 | 是 | 客户分类(客户分类ID) |
| customerTagIds | NUMBER | 否 | 是 | 客户标签ID |
| categoryIds | NUMBER | 否 | 是 | 商品分类(商品分类ID) |
| brandIds | NUMBER | 否 | 是 | 商品品牌(商品品牌ID) |
| salesIds | NUMBER | 否 | 是 | 业务员ID |
| departmentIds | NUMBER | 否 | 是 | 部门ID |
| productRange | NUMBER | 否 | 否 | 商品统计范围，0:全部商品(默认), 1:仅公有 |
| q | STRING | 否 | 否 | 商品信息，名称/编码/条码模糊搜索 |
| warehouseIds | NUMBER | 否 | 是 | 出库仓库ID |
| sort | SORT | 否 | 否 | 排序，默认salesAmount:desc，可选soldProfit/profitRate |

**响应数据**
- 返回类型：`PAGE`（分页）
  | 字段 | 类型 | 说明 |
  |------|------|------|
  | outStorageCode | STRING | 出库单号 |
  | orderCode | STRING | 订单号 |
  | billType | STRING | 出入库类型 |
  | orgName | STRING | 客户名称 |
  | orgCode | STRING | 客户编码 |
  | customerId | NUMBER | 客户ID |
  | salesAmount | NUMBER | 销售金额(需订单价格权限) |
  | saleAmountMomRate | STRING | 销售金额环比 |
  | saleAmountYoyRate | STRING | 销售金额同比 |
  | costAmount | NUMBER | 销售成本(需成本价权限) |
  | soldProfit | NUMBER | 销售毛利(需成本价权限) |
  | soldProfitAmountMomRate | STRING | 毛利金额环比 |
  | soldProfitAmountYoyRate | STRING | 毛利金额同比 |
  | profitRateResult | STRING | 毛利率(需成本价权限) |
  | salesName | STRING | 业务员 |
  | salesId | NUMBER | 业务员ID |
  | departmentName | STRING | 部门 |
  | cusCategoryName | STRING | 客户分类 |
  | customerTagNames | ARRAY | 客户标签名称 |
  | regionName | STRING | 区域名称 |
  | statisticsUnitName | STRING | 统计单位名称 |
  | statisticsCount | NUMBER | 统计单位数量 |
  | statisticsOrderPrice | NUMBER | 统计单位单价(需订单价格权限) |

## 接口选择指引

| 用户意图 | 推荐接口 |
|----------|----------|
| "整体毛利是多少" | saleProfitSummary |
| "每张出库单的毛利" | outBillSaleProfitSummary |
| "出库单内各商品毛利" | outBillAndProductSaleProfitSummary |
| "低毛利率商品分析" | outBillAndProductSaleProfitSummary(按profitRateResult排序) |
| "毛利环比/同比分析" | 三个明细接口(关注saleAmountMomRate/soldProfitAmountMomRate) |
| "按业务员统计毛利" | 三个明细接口(传salesIds) |

## 跨接口组合示例

**场景**:查看本月整体毛利及找出低毛利率的商品
1. `saleProfitSummary` → 获取本月整体毛利率
2. `outBillAndProductSaleProfitSummary` → 传入同时间范围，按 profitRateResult 排序，找出毛利率低的商品

**场景**:找出低毛利业务员
1. `outBillSaleProfitSummary` → 按 salesName 分组，查看各业务员的平均毛利率
2. 针对毛利率低的业务员进行培训或调整定价策略
