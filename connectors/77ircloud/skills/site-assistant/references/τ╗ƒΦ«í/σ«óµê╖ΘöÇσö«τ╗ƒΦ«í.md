# 客户销售统计

本文档覆盖按客户维度统计销售情况的接口，包含销售金额、成本、毛利、应收账款、下单频率等多维度数据分析。

## 接口目录
- [customerOutStatisticsList](#customeroutstatisticslist) - 客户销售统计详情(分页)
- [customerSellStatisticsSummary](#customersellstatisticssummary) - 客户销售统计汇总
- [customerSellStatisticsRank](#customersellstatisticsrank) - 客户销售排行
- [customerOrderReports](#customerorderreports) - 客户订单数据报表
- [customerAndProductSaleProfitSummary](#customerAndProductSaleProfitSummary) - 客户商品销售分析（按客户+商品）
- [additionalPurchaseCustomerDetailList](#additionalpurchasecustomerdetaillist) - 客户增购明细列表
- [additionalPurchaseCustomerSummary](#additionalpurchasecustomersummary) - 客户增购汇总信息
- [additionalPurchaseCustomerSummaryList](#additionalpurchasecustomersummarylist) - 客户增购统计列表
- [newCustomersOrderProductStatisticsList](#newcustomersorderproductstatisticslist) - 新客商品订货统计列表
- [newCustomersOrderStatisticsSummary](#newcustomersorderstatisticssummary) - 新客订货统计汇总

---

## customerOutStatisticsList

**功能**：按客户维度统计销售数据，支持分页查询，包含销售金额、成本、毛利、毛利率、应收账款、下单频率等完整指标，支持环比/同比分析。

**典型场景**
- 查看各客户的销售排行（按销售金额/毛利排序）
- 分析哪些客户毛利贡献最高
- 按客户分类/区域/业务员筛选销售情况
- 查看客户的应收账款和到期账款
- 分析客户下单频率和SKU数量
- 对比客户本期 vs 上期/同期的销售表现

**参数**
| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| rangeTime | TIME_RANGE | 是 | 否 | 统计时间 |
| keyword | STRING | 否 | 否 | 客户信息，名称/编码/联系人/电话模糊搜索 |
| customerIds | NUMBER | 否 | 是 | 客户ID集合，精确查询指定客户 |
| cusCategoryIds | NUMBER | 否 | 是 | 客户分类ID集合 |
| regionId | NUMBER | 否 | 否 | 所属区域ID |
| deptIds | NUMBER | 否 | 是 | 所属部门ID集合 |
| productRange | NUMBER | 否 | 否 | 商品统计范围，0:全部商品(默认), 1:仅公有 |
| placeSaleIds | NUMBER | 否 | 是 | 下单业务员ID集合 |
| placeSaleDeptIds | NUMBER | 否 | 是 | 下单业务员所属部门ID集合 |
| placeCustomerRegionIds | NUMBER | 否 | 是 | 下单客户所属区域ID集合 |
| sortBy | NUMBER | 否 | 否 | 统计维度，1:按客户统计(默认), 2:按分类统计 |
| orderBy | NUMBER | 否 | 否 | 占比计算依据，1:金额占比(默认), 2:毛利占比 |
| orderType | STRING | 否 | 否 | 订单/退单，1:订单, 2:退单 |
| isDF | BOOLEAN | 否 | 否 | 是否代发订单 |
| productCategoryIds | NUMBER | 否 | 是 | 商品分类ID集合 |

| momProfit | NUMBER | 否 | 上期毛利(需成本价权限) |

|------|------|------|------|
| orgId | NUMBER | 否 | 机构ID |

| totalCostAmount | OBJECT | 否 | 销售成本(需成本价权限) |

## 跨接口组合示例

**场景**：查看“大客户”分类下各客户的毛利统计
1. `customerCategoryList` → 获取“大客户”分类ID（基础数据/客户.md）
2. `customerOutStatisticsList` → 传入 cusCategoryIds + rangeTime

**场景**：分析某客户的销售表现
1. `customerSellStatisticsRank` → 查看该客户在所有客户中的排名
2. `customerOrderReports` → 获取该客户的详细订单数据
3. `customerSellStatisticsSummary` → 对比整体销售情况

**场景**：识别高价值客户
1. `customerOutStatisticsList` → 按 profit 排序，筛选 profitRate>20% 且 orderFrequency<30 的客户
2. 针对这些客户制定VIP服务策略

**场景**：监控客户流失风险
1. `additionalPurchaseCustomerSummary` → 查看整体增购/减购趋势
2. `additionalPurchaseCustomerDetailList` → 筛选 skuCountDecrease>0 的客户，定位减购客户
3. `customerOutStatisticsList` → 传入减购客户ID，查看其销售金额环比/同比变化
4. 结合 orderFrequency 判断客户是否趋于不活跃

**场景**：分析新客首单转化效果
1. `newCustomersOrderStatisticsSummary` → 获取新客总人数和订货金额概览
2. `newCustomersOrderProductStatisticsList` → 查看新客首单商品明细，分析热门首单商品
3. `customerAndProductSaleProfitSummary` → 对首单热门商品，按客户+商品维度进一步分析毛利贡献
