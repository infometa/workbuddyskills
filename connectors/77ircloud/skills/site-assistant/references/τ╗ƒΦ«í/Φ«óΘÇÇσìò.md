# 订退单

本文档覆盖订单与退单的综合查询接口，包括订退单列表、订退单商品明细及商品分类订货汇总。

## 接口目录
- [customerOrderAndReturnOrderList](#customerorderandreturnorderlist) - 订退单列表
- [productCustomerOrderAndReturnOrderDataList](#productcustomerorderandreturnorderdatalist) - 订退单商品明细
- [orderProductCategorySummary](#orderproductcategorysummary) - 商品分类订货汇总

---

## customerOrderAndReturnOrderList

**功能**：查询订单和退单的列表，支持多状态、多配送方式、多支付状态筛选。

**典型场景**
- 查看某段时间内的所有订单/退单记录
- 筛选特定状态（审核中/已完成）的订单
- 查看未收款的订单列表
- 分析自主下单 vs 业务员代下单的占比

**参数**
| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| createTime | TIME_RANGE | 是 | 否 | 下单时间 |
| billType | NUMBER | 否 | 否 | 单据类型，1:订单(默认), 2:退单 |
| orderStatus | NUMBER | 否 | 是 | 订单状态，默认[1,2,3,4,20]，1:待订单审核, 2:待财务审核, 3:已审核, 4:已完成, 5:已作废, 20:待收货审核 |
| containChildOrg | BOOLEAN | 否 | 否 | 包含下游机构数据，默认true |
| replaceOrder | NUMBER | 否 | 是 | 下单方式，1:代下单, 2:自主下单 |
| deliveryMethods | NUMBER | 否 | 是 | 配送方式，1:到店自提, 2:送货上门, 3:客户自定义 |
| paymentStatus | NUMBER | 否 | 是 | 收付款状态，1:未收款, 2:部分收款, 4:已收款 |
| stockOutStatus | NUMBER | 否 | 是 | 出库状态，1:未出库, 2:部分出库, 3:已出库 |
| buyerIds | NUMBER | 否 | 是 | 买家ID列表，筛选指定客户 |
| salesId | NUMBER | 否 | 是 | 业务员ID列表，筛选指定业务员 |
| regionId | NUMBER | 否 | 是 | 所属区域ID列表 |
| departmentId | NUMBER | 否 | 是 | 所属部门ID列表 |
| insteadDispatch | NUMBER | 否 | 是 | 是否代发，2:是, 0:否 |
| orderCode | STRING | 否 | 否 | 订单号，精确查询 |

**响应数据**
- 返回类型：`PAGE`（分页）
| 字段 | 类型 | 说明 |
|------|------|------|
| createTime | DATETIME | 下单时间 |
| orderCode | STRING | 单号 |
| hierarchyOrderTypesName | STRING | 单据类型（分公司订单/门店订单/客户订单等） |
| insteadDispatch | STRING | 是否代发 |
| billTypeName | STRING | 订单/退单 |
| orderStatusName | STRING | 单据状态 |
| sellerName | STRING | 所属机构 |
| buyerCode | STRING | 往来编码 |
| buyerName | STRING | 往来单位 |
| deliveryMethodName | STRING | 配送方式 |
| deliveryDate | STRING | 交货时间 |
| contactName | STRING | 收货人 |
| contactPhone | STRING | 收货人电话 |
| deliveryAddress | STRING | 收货地址 |
| salesmanName | STRING | 下单业务员 |
| regionName | STRING | 下单区域 |
| productAmount | NUMBER | 商品金额 |
| originalProductAmount | NUMBER | 商品原价金额 |
| totalDiscountAmount | NUMBER | 优惠金额 |
| totalFreight | NUMBER | 运费金额 |
| totalAmount | NUMBER | 订单金额 |
| paymentStatusName | STRING | 收付款状态 |
| remark | STRING | 下单备注 |
| createName | STRING | 制单人 |
| departmentName | STRING | 下单部门 |
| curSalesmanName | STRING | 往来当前业务员 |
| curRegionName | STRING | 往来当前区域 |
| curDepartmentName | STRING | 往来当前部门 |

## orderProductCategorySummary

**功能**：按商品分类统计订货（或退单）金额和笔数，展示各分类的占比，适合分类维度的饼图/汇总分析。

**典型场景**
- 查看各商品分类的订货金额占比
- 了解哪个分类贡献了最多订货
- 按分类分析退单情况

**参数**
| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| createTime | TIME_RANGE | 是 | 否 | 下单时间 |
| billType | NUMBER | 是 | 否 | 单据类型，1:订单, 2:退单 |
| categoryIds | NUMBER | 否 | 是 | 商品分类ID列表，筛选指定分类 |
| orderCode | STRING | 否 | 否 | 订单号 |
| buyerIds | NUMBER | 否 | 是 | 买家ID列表 |
| skuIds | NUMBER | 否 | 是 | 商品ID列表 |
| brandId | NUMBER | 否 | 是 | 商品品牌ID列表 |
| salesId | NUMBER | 否 | 是 | 业务员ID列表 |
| regionId | NUMBER | 否 | 是 | 所属区域ID列表 |
| departmentId | NUMBER | 否 | 是 | 所属部门ID列表 |
| insteadDispatch | NUMBER | 否 | 是 | 是否代发，2:是, 0:否 |
| replaceOrder | NUMBER | 否 | 是 | 下单方式，1:代下单, 2:自主下单 |
| orderStatus | NUMBER | 否 | 是 | 订单状态，1:待订单审核, 2:待财务审核, 3:已审核, 4:已完成, 5:已作废, 20:待收货审核 |
| deliveryMethods | NUMBER | 否 | 是 | 配送方式，1:到店自提, 2:送货上门, 3:客户自定义 |
| paymentStatus | NUMBER | 否 | 是 | 收付款状态，1:未收款, 2:部分收款, 4:已收款 |
| stockOutStatus | NUMBER | 否 | 是 | 出库状态，1:未出库, 2:部分出库, 3:已出库 |
| containChildOrg | BOOLEAN | 否 | 否 | 包含下游机构数据 |

**响应数据**
- 返回类型：`ARRAY`（数组）
| 字段 | 类型 | 说明 |
|------|------|------|
| categoryId | NUMBER | 商品分类ID |
| categoryName | STRING | 商品分类名称 |
| orderCount | NUMBER | 下单订货订单笔数 |
| totalAmount | NUMBER | 下单订货金额 |
| proportion | NUMBER | 下单订货金额占比 |

## 接口选择指引

| 用户意图 | 推荐接口 |
|----------|----------|
| "查订单列表" | customerOrderAndReturnOrderList |
| "查订单中的商品明细" | productCustomerOrderAndReturnOrderDataList |
| "各分类订货金额占比" | orderProductCategorySummary（billType=1）|
| "各分类退货金额占比" | orderProductCategorySummary（billType=2）|

## 跨接口组合示例

**场景**：查看某客户的全部订退单及商品明细
1. `customerList` → 获取客户ID（基础数据/客户.md）
2. `customerOrderAndReturnOrderList` → 传入客户对应的时间范围，获取订退单列表
3. `productCustomerOrderAndReturnOrderDataList` → 传入 buyerIds，获取商品明细
