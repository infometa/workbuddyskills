# 客户行为分析

本文档覆盖客户行为分析相关接口,包括客户订货行为、订货趋势、客户发展分析、地区销售统计及拉新提成统计。

## 接口目录
- [analyzeCustomerOrderBehaviorSummary](#analyzecustomerorderbehaviorsummary) - 分析客户订货行为
- [dayAnalyzeCustomerOrderTrendsSummary](#dayanalyzecustomerordertrendssummary) - 分析客户订货趋势(按天)
- [monthAnalyzeCustomerOrderTrendsSummary](#monthanalyzecustomerordertrendssummary) - 分析客户订货趋势(按月)
- [dayAnalyzeCustomerGrowthAndRankingList](#dayanalyzecustomergrowthandrankinglist) - 客户发展分析(按天)
- [monthAnalyzeCustomerGrowthAndRankingList](#monthanalyzecustomergrowthandrankinglist) - 客户发展分析(按月)
- [regionSalesList](#regionSalesList) - 地区销售统计
- [marketingFromCustomerSummary](#marketingfromcustomersummary) - 客户拉新提成统计
- [marketingFromEmployeeSummary](#marketingfromemployeesummary) - 员工拉新提成统计

## analyzeCustomerOrderBehaviorSummary

**功能**:分析客户的订货行为,包含累计订单数、累计金额、平均订单金额、平均订货间隔、退单情况、登录行为等。

**典型场景**
- 识别高价值客户(高累计订货金额)
- 找出长期未下单客户(noOrderDay 较大)
- 分析客户订货频率(avgOrderInterval)
- 按来源渠道筛选客户行为
- 查看客户登录活跃度(最近登录时间、累计登录次数)
- 分析客户加盟时间和首次订货时间

**参数**
| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| rangeTime | TIME_RANGE | 是 | 否 | 时间 |
| keyword | STRING | 否 | 否 | 搜索条件，客户名称/联系人/电话，模糊搜索 |
| sourceTypes | NUMBER | 否 | 是 | 客户来源，1:手工创建, 2:ERP同步, 3:员工拉新, 4:客户推荐, 5:微信搜索, 6:扫码注册, 7:批量导入, 8:微信直播, 9:推文分享, 10:附近商机 |
| salesName | STRING | 否 | 否 | 默认业务员(业务员名称) |
| referrerName | STRING | 否 | 否 | 推荐人(推荐人名称) |
| sellerType | NUMBER | 否 | 否 | 机构类型，0:全部(默认), 1:总部, 2:分公司, 3:门店 |
| regionIds | NUMBER | 否 | 是 | 所属区域ID集合 |
| firstOrderTimeBegin | DATETIME | 否 | 否 | 首次订货时间-开始 |
| firstOrderTimeEnd | DATETIME | 否 | 否 | 首次订货时间-结束 |
| lastOrderTimeBegin | DATETIME | 否 | 否 | 最后订货时间-开始 |
| lastOrderTimeEnd | DATETIME | 否 | 否 | 最后订货时间-结束 |
| customerIds | NUMBER | 否 | 是 | 客户ID集合 |
| sort | STRING | 否 | 否 | 排序，默认lastOrderTime:desc，支持字段：lastOrderTime, avgAmount, lastLoginTime |

**响应数据**
- 返回类型：`PAGE`（分页）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | NUMBER | 客户ID |
| customerName | STRING | 客户名称 |
| customerCode | STRING | 客户编码 |
| organizationName | STRING | 所属机构 |
| contactName | STRING | 联系人名称 |
| contactPhoneNum | STRING | 联系人电话 |
| lastOrderTime | DATETIME | 最近订货时间 |
| totalOrderCount | NUMBER | 累计订单数 |
| totalAmount | NUMBER | 累计订货金额 |
| avgAmount | NUMBER | 平均订单金额 |
| totalReturnOrderCount | NUMBER | 累计退单数 |
| totalRefund | NUMBER | 累计退货金额 |
| avgOrderInterval | NUMBER | 平均订货间隔(天) |
| noOrderDay | NUMBER | 距上次订货天数 |
| salesName | STRING | 默认业务员 |
| lastLoginTime | DATETIME | 最近登录时间 |
| loginCount | NUMBER | 累计登录次数 |
| franchiseTime | DATETIME | 加盟时间 |
| firstOrderTime | DATETIME | 首次订货时间 |
| sourceType | STRING | 客户来源(编码) |
| sourceName | STRING | 客户来源类型 |

## dayAnalyzeCustomerOrderTrendsSummary

**功能**:按天展示客户订货趋势,包含每日订单数量、金额、退单数量及平均客单价。

**典型场景**
- 查看某段时间内的每日订货波动
- 分析工作日 vs 周末订货量差异
- 监控某客户的每日订货趋势

**参数**
| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| rangeTime | TIME_RANGE | 是 | 否 | 统计时间范围 |
| sellerType | NUMBER | 否 | 否 | 客户范围，0:全部客户(默认), 1:总部客户, 2:分公司客户, 3:门店客户 |
| buyerId | NUMBER | 否 | 否 | 客户ID，指定单一客户 |
| productRange | NUMBER | 否 | 否 | 商品范围，0:全部商品(默认), 1:仅公有 |

**响应数据**
- 返回类型：`PAGE`（分页）
| 字段 | 类型 | 说明 |
|------|------|------|
| dateLabel | STRING | 日期 |
| orderCount | NUMBER | 订单数量 |
| returnOrderCount | NUMBER | 退单数量 |
| amount | NUMBER | 订单金额 |
| refund | NUMBER | 退单金额 |
| totalAmount | NUMBER | 合计金额 |
| avgAmount | NUMBER | 平均客单价 |

---

## monthAnalyzeCustomerOrderTrendsSummary

**功能**:按月展示客户订货趋势,适合中长期趋势分析,参数和返回字段与按天版本相同,dateType=2。

**典型场景**
- 查看全年各月订货金额趋势
- 分析季节性订货规律
- 对比近两年同期订货数据

**关键参数**:同 dayAnalyzeCustomerOrderTrendsSummary(内部 dateType=2)

**响应数据**
- 返回类型：同 dayAnalyzeCustomerOrderTrendsSummary

## dayAnalyzeCustomerGrowthAndRankingList

**功能**:按天统计客户增长情况(新增/开通/注册/下单客户数),也可切换为客户排行模式,支持环比分析。

**典型场景**
- 查看每日新增客户数趋势
- 统计每日下单客户数
- 分析某时间段客户增长是否达标
- 查看自主下单客户数和金额

**参数**
| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| rangeTime | TIME_RANGE | 是 | 否 | 统计时间 |
| apiType | NUMBER | 是 | 否 | 查询维度，客户排行=1, 发展分析=2(默认2) |
| sellerType | NUMBER | 否 | 否 | 卖家类型，0:全部(默认), 1:总部, 2:分公司, 3:门店, 4:客户 |
| sellerId | NUMBER | 否 | 否 | 卖家ID(分公司ID或门店ID) |
| buyerId | NUMBER | 否 | 否 | 买家ID(客户ID) |
| hierarchyOrderTypes | NUMBER | 否 | 是 | 订单层级类型，1:分公司订单, 2:门店订单, 3:客户订单 |
| keyword | STRING | 否 | 否 | 关键字(机构名称/编码) |
| customerId | NUMBER | 否 | 是 | 客户ID集合 |

**响应数据**
- 返回类型：`PAGE`（分页）
| 字段 | 类型 | 说明 |

| newCustomerCount | NUMBER | 总新增客户数 |

| indepAmount | NUMBER | 自主下单金额 |

## regionSalesList

**功能**:按地区统计订货和退单金额、笔数及占比,了解各地区的销售贡献。

**典型场景**
- 查看各地区的销售金额分布
- 分析哪个地区的退货率最高
- 了解各地区在总销售中的占比

**参数**
| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| rangeTime | TIME_RANGE | 是 | 否 | 统计时间 |
| orderType | NUMBER | 否 | 是 | 订单/退单，1:订单, 2:退单 |
| productRange | NUMBER | 否 | 否 | 商品统计范围，0:全部商品(默认), 1:仅公有商品 |
| contactRegionId | NUMBER | 否 | 否 | 地区父级ID |
| contactRegionLevel | NUMBER | 否 | 否 | 地区层级，1:全部地区(默认), 2:省, 3:市, 4:区 |
| contactRegionIds | NUMBER | 否 | 是 | 客户档案省市区地区IDs |
| ratioBy | NUMBER | 否 | 否 | 占比计算依据，1:按订单金额(默认), 2:按退单金额 |

**响应数据**
- 返回类型：`PAGE`（分页）
| 字段 | 类型 | 说明 |
|------|------|------|
| contactRegionId | NUMBER | 地区ID |
| contactRegionName | STRING | 地区名称 |
| orderCount | NUMBER | 订单数量 |
| refundCount | NUMBER | 退单数量 |
| orderAmount | NUMBER | 订货金额 |
| refundAmount | NUMBER | 退货金额 |
| totalAmount | NUMBER | 金额小计 |
| proportion | NUMBER | 占比率 |

## marketingFromCustomerSummary

**典型场景**
- 查看哪些客户(推荐人)拉新贡献最多
- 统计某代理商级别的客户拉新情况
- 查看某客户的累计提成金额

**参数**
| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| rangeTime | TIME_RANGE | 否 | 否 | 统计时间 |
| agentLevelIds | NUMBER | 否 | 是 | 代理商级别ID |
| customerId | NUMBER | 否 | 否 | 客户Id |
| customerInfo | STRING | 否 | 否 | 客户信息，姓名/编码/联系人/手机号模糊搜索 |
| sourceBussinessConsumeId | NUMBER | 否 | 是 | 客户IDs |
| categoryIds | NUMBER | 否 | 是 | 分类ID |

| enableAgentLevel | BOOLEAN | 否 | 否 | 是否启用代理商级别 |

**响应数据**
- 返回类型：`PAGE`（分页）
| 字段 | 类型 | 说明 |
|------|------|------|
| customerName | STRING | 客户姓名 |
| customerCode | STRING | 客户编码 |
| newCustomerCounts | NUMBER | 本期拉新客户数 |
| orderCustomerCounts | NUMBER | 本期下单客户数 |
| orderAmount | NUMBER | 本期订单金额 |
| royaltyAmount | NUMBER | 本期提成金额 |
| totalNewCustomerCounts | NUMBER | 总拉新客户数 |

## 跨接口组合示例

**场景**:分析近3个月客户订货趋势及地区分布
1. `monthAnalyzeCustomerOrderTrendsSummary` → 查看近3个月每月订货金额趋势
2. `regionSalesList` → 查看同期各地区销售贡献占比

**场景**:识别高价值低活跃客户
1. `analyzeCustomerOrderBehaviorSummary` → 按totalAmount倒序排序,筛选noOrderDay>30的客户
2. 针对这些客户制定激活策略

**场景**:分析员工拉新与客户增长的关系
1. `marketingFromEmployeeSummary` → 查看各员工拉新情况
2. `dayAnalyzeCustomerGrowthAndRankingList` → 对比同期新增客户数趋势
