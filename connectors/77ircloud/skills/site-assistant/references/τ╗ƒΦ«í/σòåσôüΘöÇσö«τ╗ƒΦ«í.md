# 商品销售统计

本文档覆盖商品维度的销售统计接口，分为商品维度、商品分类维度、品牌维度三个统计角度，支持环比/同比分析、SPU/SKU分组统计，以及PC端品类销售汇总统计。

## 接口目录
- [productSalesStatisticsSum](#productsalesstatisticssum) - 商品销售统计-汇总
- [productStatisticsList](#productstatisticslist) - 商品销售统计（商品维度）
- [productCategoryStatisticsList](#productcategorystatisticslist) - 商品分类销售统计（分类维度）
- [brandStatisticsList](#brandstatisticslist) - 品牌销售统计（品牌维度）
- [pcBrandCategoryStatisticSummary](#pcbrandcategorystatisticsummary) - PC端品类销售统计-汇总
- [additionalPurchaseProductDetailList](#additionalpurchaseproductdetaillist) - 商品增购明细列表
- [additionalPurchaseProductSummary](#additionalpurchaseproductsummary) - 商品增购汇总信息
- [additionalPurchaseProductSummaryList](#additionalpurchaseproductsummarylist) - 商品增购统计列表

## productSalesStatisticsSum

**功能**：统计指定时间范围内的商品销售整体汇总数据，返回销售总金额、销售数量、销售成本、销售毛利及环比指标，适合用于展示销售概览看板。

**典型场景**
- 查看本月/本周整体销售金额汇总
- 获取销售金额与上期的环比变化
- 查看整体销售毛利和毛利环比
- 按客户/业务员/分类/品牌筛选后的汇总数据
- 作为 `productStatisticsList` 的配套汇总接口（先调汇总再看明细）

**参数**
| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| rangeTime | TIME_RANGE | 是 | 否 | 统计时间 |
| keyword | STRING | 否 | 否 | 商品名称/编码/条码，模糊搜索 |
| skuId | NUMBER | 否 | 否 | 商品ID |
| productCategoryIds | NUMBER | 否 | 是 | 商品分类ID集合 |
| brandIds | NUMBER | 否 | 是 | 商品品牌ID集合 |
| customerId | NUMBER | 否 | 否 | 客户ID |
| relatedIds | NUMBER | 否 | 是 | 往来单位ID集合 |
| relatedOrgTypes | STRING | 否 | 是 | 往来单位类型，HEADQUARTERS:总部, BRANCH:分公司, STORE:门店, CUSTOMER:客户 |
| sellerId | NUMBER | 否 | 否 | 业务员ID |
| salesIds | NUMBER | 否 | 是 | 业务员ID集合 |
| warehouseIds | NUMBER | 否 | 是 | 仓库ID集合 |
| creatorIds | NUMBER | 否 | 是 | 制单人ID集合 |
| organizationIds | NUMBER | 否 | 是 | 机构ID集合 |
| hierarchyOrderTypes | NUMBER | 否 | 是 | 订单类型，1:分公司订单, 2:门店订单, 3:客户订单, 4:分公司代发订单, 5:门店代发订单 |
| storageTypes | NUMBER | 否 | 是 | 出入库类型，1:配送出库, 21:销售出库, 12:配退入库, 16:配差入库, 31:退货入库, 33:差异入库 |
| containAllOrg | BOOLEAN | 否 | 否 | 是否包含所有下属机构，默认true |
| productRange | NUMBER | 否 | 否 | 商品统计范围，0:全部商品(默认), 1:仅公有 |
| isDF | BOOLEAN | 否 | 否 | 是否代发订单 |

**响应数据**
- 返回类型：`OBJECT`
| 字段 | 类型 | 说明 |
|------|------|------|
| salesTotalAmount | NUMBER | 销售金额（需销售价权限） |
| salesTotalAmountText | STRING | 销售金额展示文本 |
| lastSalesTotalAmount | NUMBER | 上期销售金额（需销售价权限） |
| salesTotalAmountRatio | STRING | 销售金额环比（附带%） |
| upDown | STRING | 销售金额升降标识（UP/DOWN） |
| salesCount | NUMBER | 销售数量 |
| salesCountStatisticsUnit | NUMBER | 销售数量（统计单位） |
| totalCostAmount | NUMBER | 销售成本（需成本价权限） |
| totalCostAmountText | STRING | 销售成本展示文本 |
| grossTotalProfit | NUMBER | 销售毛利（需成本价权限） |
| grossTotalProfitText | STRING | 销售毛利展示文本（需成本价权限） |
| grossProfitCycle | NUMBER | 销售毛利环比（需成本价权限） |
| grossProfitCyclePercent | STRING | 销售毛利环比（附带%，需成本价权限） |
| salesBillsCount | NUMBER | 销售笔数 |
| outStorageMoney | NUMBER | 出库金额（需成本价权限） |
| inStorageMoney | NUMBER | 入库金额（需成本价权限） |

## productStatisticsList

**功能**:按商品维度统计销售情况,包含销售金额、成本、毛利、毛利率、销售数量及环比/同比,支持SPU/SKU分组统计、关键字搜索、多维度筛选。

**典型场景**
- 查看某段时间内各商品的销售排行
- 分析哪些商品毛利率最高/最低
- 按品牌或分类筛选商品销售情况
- 查看商品销售的环比和同比趋势
- 按SPU维度汇总统计商品销售
- 搜索特定商品(名称/编码/条码)的销售表现
- 分析某客户或某业务员的购买商品情况

**参数**
| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| rangeTime | TIME_RANGE | 是 | 否 | 统计时间 |
| skuId | NUMBER | 否 | 否 | 商品ID，精确查某商品 |
| skuIds | NUMBER | 否 | 是 | 商品ID集合，查询多个商品 |
| spuIds | NUMBER | 否 | 是 | SPU ID集合，按SPU查询 |
| groupType | NUMBER | 否 | 否 | 分组统计类型，1:按sku(默认), 2:按spu |
| keyword | STRING | 否 | 否 | 关键字搜索，商品名称/编码/条码 |
| productCategoryIds | NUMBER | 否 | 是 | 商品分类ID，需先用 productCategoryList 获取 |
| brandIds | NUMBER | 否 | 是 | 商品品牌ID，需先用 productBrandList 获取 |
| customerId | NUMBER | 否 | 否 | 客户ID，查询某客户的购买商品 |
| relatedIds | NUMBER | 否 | 是 | 往来单位ID |
| relatedOrgTypes | STRING | 否 | 是 | 往来单位类型，HEADQUARTERS:总部, BRANCH:分公司, STORE:门店, CUSTOMER:客户 |
| sellerId | NUMBER | 否 | 否 | 业务员ID，查询某业务员的销售商品 |
| salesIds | NUMBER | 否 | 是 | 业务员ID集合 |
| warehouseIds | NUMBER | 否 | 是 | 仓库ID集合，按仓库筛选 |
| creatorIds | NUMBER | 否 | 是 | 制单人ID集合 |
| hierarchyOrderTypes | NUMBER | 否 | 是 | 订单类型，1:分公司, 2:门店, 3:客户 |
| orderType | STRING | 否 | 否 | 订单类型(字符串)，1-分公司 2-门店 4-总部 3-客户 5-会员 |
| storageTypes | NUMBER | 否 | 是 | 出入库类型，1:配送出库, 21:销售出库, 12:配退入库, 16:配差入库, 31:退货入库, 33:差异入库 |
| organizationIds | NUMBER | 否 | 是 | 机构ID集合 |
| containAllOrg | BOOLEAN | 否 | 否 | 是否包含所有下属机构，默认true |
| productRange | NUMBER | 否 | 否 | 商品统计范围，0:全部商品(默认), 1:仅公有 |
| isDF | BOOLEAN | 否 | 否 | 是否代发订单 |
| sort | SORT | 否 | 否 | 排序，支持按销售毛利、毛利率、销售金额排序 |
| proportionType | NUMBER | 否 | 否 | 占比类型，1:金额占比(默认), 2:毛利占比, 3:统计单位数量占比 |
| regionIds | NUMBER | 否 | 是 | 区域ID |
| customerCategoryIds | NUMBER | 否 | 是 | 客户分类ID集合 |
| customerTagIds | NUMBER | 否 | 是 | 客户标签ID集合 |

**响应数据**
- 返回类型：`PAGE`（分页）
| 字段 | 类型 | 说明 |
|------|------|------|
| skuId | NUMBER | 商品ID |

| salesAmount | NUMBER | 销售金额 |

## productCategoryStatisticsList

**功能**:按商品分类维度统计销售情况,包含销售金额、毛利、占比、环比,支持分类层级穿透分析。

**典型场景**
- 查看各分类的销售占比
- 分析哪个分类销售增长最快(看环比)
- 查看某些分类的销售毛利
- 分析分类的层级结构销售表现
- 查看某分类下的叶子节点销售情况

**参数**
| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| rangeTime | TIME_RANGE | 是 | 否 | 统计时间 |
| categoryIds | NUMBER | 否 | 是 | 商品分类id，需先用 productCategoryList 获取 |
| categoryId | NUMBER | 否 | 否 | 统计分类ID，统计该分类下一级分类的数据,统计一级分类传0 |
| categoryParentId | NUMBER | 否 | 否 | 穿透父级分类ID，用于层级穿透分析 |
| categoryParentDirect | NUMBER | 否 | 否 | 穿透方向 |
| hierarchyOrderTypes | NUMBER | 否 | 是 | 订单类型，1:分公司订单, 2:门店订单, 3:客户订单, 4:分公司代发订单, 5:门店代发订单 |
| orgId | NUMBER | 否 | 否 | 机构ID |
| containAllChildOrg | BOOLEAN | 否 | 否 | 是否统计下属所有机构 |
| orgType | NUMBER | 否 | 是 | 关联业务机构类型，1:分公司, 2:门店, 3:客户 |
| relatedId | NUMBER | 否 | 否 | 客户ID(单个客户维度)，单个客户维度查询 |
| salesmanIds | NUMBER | 否 | 是 | 下单业务员ID集合 |
| warehouseIds | NUMBER | 否 | 是 | 仓库ID集合 |
| creatorIds | NUMBER | 否 | 是 | 制单人ID集合 |
| isDF | BOOLEAN | 否 | 否 | 是否代发订单 |
| productRange | NUMBER | 否 | 否 | 商品统计范围，0:全部商品(默认), 1:仅公有 |
| sortFlag | NUMBER | 否 | 否 | 排序标志，1:按销售额排序, 2:按毛利排序, 3:按数量排序 |

**响应数据**
- 返回类型：`PAGE`（分页）
| 字段 | 类型 | 说明 |
|------|------|------|
| categoryId | NUMBER | 分类ID |
| categoryName | STRING | 分类名称 |
| categoryCode | STRING | 分类编码 |
| leafFlag | BOOLEAN | 是否叶子节点 |
| salesAmount | NUMBER | 销售金额 |
| costAmount | NUMBER | 成本金额(需成本价权限) |
| profitAmount | NUMBER | 销售毛利(需成本价权限) |
| salesAmountProportionResult | STRING | 销售占比 |
| profitAmountProportionResult | STRING | 毛利占比 |
| salesTotalAmountRatio | STRING | 环比 |
| upDown | STRING | 升降标识，UP:上升, DOWN:下降 |
| salesCount | NUMBER | 销售数量 |
| salesCountProportionResult | STRING | 销售数量占比 |
| profitRate | NUMBER | 毛利率(需成本价权限) |
| lastSalesTotalAmount | NUMBER | 上期销售金额 |

**典型场景**
- PC报表页同时展示汇总指标和品牌/分类明细列表
- 按分类统计各品类的销售金额、毛利及占比
- 按品牌统计各品牌的销售情况和环比

**功能**：按商品维度查看指定客户的增购/减购明细，统计各商品在指定客户下的订货数量、金额、增减标记（增购/减购/无增减/无交易），支持首末次订货时间、减购周期分析。

## 跨接口组合示例

**场景**:查看某品牌各商品销售情况
1. `productBrandList` → 获取品牌ID(基础数据/商品.md)
2. `productStatisticsList` → 传入 brandIds + rangeTime

**场景**:查看饮料分类本月销售
1. `productCategoryList` → 获取"饮料"分类ID(基础数据/商品.md)
2. `productCategoryStatisticsList` → 传入 categoryIds + 本月时间范围

**场景**:分析某客户购买的商品分类偏好
1. `customerList` → 获取客户ID(基础数据/客户.md)
2. `productStatisticsList` → 传入 customerId + rangeTime,按销售金额排序

**场景**：监控某大客户的商品增减购变化
1. `additionalPurchaseProductSummary` → 传入 buyerIds，获取该客户整体商品增购/减购概览
2. `additionalPurchaseProductDetailList` → 传入 buyerIds，筛选 flagDecrease=1 定位减购商品
3. 对减购商品，查看 decreaseDays 判断流失风险等级
4. `productStatisticsList` → 对减购商品进一步查看整体市场销售趋势

**场景**：按分类分析某客户的商品忠诚度
1. `additionalPurchaseProductSummaryList` → 传入 buyerIds，按商品分类查看增购/减购分布
2. `additionalPurchaseProductDetailList` → 对减购分类进一步查看具体减购商品明细
3. `productCategoryStatisticsList` → 对比减购分类的市场整体表现
