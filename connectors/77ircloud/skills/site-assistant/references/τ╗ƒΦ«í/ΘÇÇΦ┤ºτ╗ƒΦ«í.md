# 退货统计

本文档覆盖退货单商品明细的汇总统计接口，支持按不同维度（商品、商品+单位、客户+商品、客户+商品+单位）进行统计。

## 接口目录
- [productReturnOrderProductCategorySummary](#productreturnorderproductcategorysummary) - 退货单明细-按商品汇总
- [productAndUnitReturnOrderProductCategorySummary](#productandunitreturnorderproductcategorysummary) - 退货单明细-按商品和下单单位汇总
- [customerAndProductReturnOrderProductCategorySummary](#customerandproductreturnorderproductcategorysummary) - 退货单明细-按客户和商品汇总
- [customerAndProductAndUnitReturnOrderProductCategorySummary](#customerandproductandunitreturnorderproductcategorysummary) - 退货单明细-按客户和商品和下单单位汇总

---

## productReturnOrderProductCategorySummary

**功能**：按商品维度汇总退货单明细，查看每个商品的退货数量、金额及入库状态。

**典型场景**
- 查看哪些商品退货量最多
- 分析特定分类或品牌下的退货情况
- 筛选特定入库状态的退货记录

**参数**
| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| createTime | TIME_RANGE | 是 | 否 | 退单创建时间 |
| toggleQueryMode | NUMBER | 否 | 否 | 查询模式，1:ADB, null:MYSQL，默认1 |
| orderStatuses | STRING | 否 | 是 | 退单状态，默认[ORDER_AUDIT_PENDING,RECEIPT_AUDIT_PENDING,AUDITED,FINISHED]，ORDER_AUDIT_PENDING:待审核, AUDITED:已审核, FINISHED:已完成, CANCELLED:已作废, SUBMIT_PENDING:待提交, RECEIPT_AUDIT_PENDING:待收货审核 |
| brandIds | NUMBER | 否 | 是 | 商品品牌ID |
| buyerIds | NUMBER | 否 | 是 | 退货方机构ID |
| categoryIds | NUMBER | 否 | 是 | 商品分类ID |
| skuIds | NUMBER | 否 | 是 | 商品ID |
| storageInStatuses | STRING | 否 | 是 | 入库状态，NONE:未入库, PART:部分入库, FULL:已入库 |
| buyerRegionIds | NUMBER | 否 | 是 | 退货方区域ID |
| salesmanIds | NUMBER | 否 | 是 | 业务员ID |
| salesmanDepartmentIds | NUMBER | 否 | 是 | 业务员部门ID |
| buyerTypes | STRING | 否 | 是 | 退货方类型，BRANCH:分公司, STORE:门店, CUSTOMER:客户 |
| deliveryStatuses | STRING | 否 | 是 | 收货状态，UNRECEIVE:未收货, RECEIVED:已收货, WAIT_RECEIVE:待收货 |
| createRole | STRING | 否 | 否 | 下单角色，SELLER:代下单, BUYER:自主下单 |
| creatorIds | NUMBER | 否 | 是 | 制单人ID |
| reasonIds | NUMBER | 否 | 是 | 退单原因ID |
| orderAuditTime | TIME_RANGE | 否 | 否 | 审核时间 |
| customerTagIds | NUMBER | 否 | 是 | 客户标签ID |
| customerCategoryIds | NUMBER | 否 | 是 | 客户分类ID |

| salesmanName | STRING | 业务员名称 |
| salesmanDepartmentName | STRING | 业务员部门 |
| buyerRegionName | STRING | 退货区域 |
| productName | STRING | 商品名称 |
| productCode | STRING | 商品编码 |
| productBarCode | STRING | 商品条码 |
| productSpec | STRING | 规格 |
| unitName | STRING | 单位 |
| auxUnitName | STRING | 辅助单位 |
| categoryName | STRING | 商品分类 |
