## 登录与认证（OAuth2）

使用 OAuth2 PKCE 浏览器授权流程，无需手动输入密码。

### 常用命令

```bash
ircloud-cli auth login        # 启动 OAuth2 授权登录
ircloud-cli auth status       # 查看当前登录状态
ircloud-cli auth logout       # 退出登录
```

### 未登录或 token 不存在的处理流程

1. 先执行 `ircloud-cli auth status` 确认登录状态
2. 若未登录，引导用户执行 `ircloud-cli auth login`，CLI 会：
   - 生成授权 URL 并在终端输出（格式：`Opening browser for authentication...` + 授权链接）
   - 启动后台 Daemon 进程监听（10 分钟超时自动退出）
   - **主进程输出授权 URL 后立即退出**（CLI 不会自动打开浏览器）
3. 获取终端输出的授权 URL，**使用浏览器工具（preview_url / open）打开该链接**
4. 授权完成后 Daemon 自动保存授权信息并退出
5. 等用户再次发起对话时告知登录已完成，重新执行原操作

友好提示话术参考：「正在启动授权登录，即将在浏览器中为您打开授权页面。」

### 账号切换

当用户需要切换账号时：
1. 执行 `ircloud-cli auth logout` 退出当前账号
2. 执行 `ircloud-cli auth login` 重新授权新账号
