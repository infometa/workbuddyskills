# outStorage - 订单出库

本文档覆盖订单出库接口，用于对订单执行出库操作。

## 接口目录
- [outStorage](#outStorage) - 订单出库（支持全量/部分出库，可同步触发发货）

---

## outStorage

**功能**：对指定订单执行出库操作（按订单号），支持全量出库或按商品明细部分出库，可同步触发发货。返回出库单号（`billNum`），无出库结果时返回 `null`。

**典型场景**
- 订单审核通过后，从仓库发货并生成出库单
- 出库同时填写物流信息，一步完成出库 + 发货
- 按商品行部分出库（分批发货）：需先通过 [订单-详情.md](订单-详情.md) 的 `findOrderDetail` 查询订单详情，获取 `orderDetails[].id`（OrderDetail 主键）及待出库数量
- **多仓分拣模式**：启用多仓分拣时，需为每行商品指定出库仓库

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明                                                  |
|------|------|------|------|-----------------------------------------------------|
| orderCode | STRING | 是 | 否 | 订单号（URL路径参数，由系统自动注入RequestBody）                     |
| warehouseId | NUMBER | 否 | 否 | 出库仓库ID，不填则使用订单默认仓库（需开启toDefaultWarehouse） |
| dispatchFlag | BOOLEAN | 否 | 否 | 是否同时发货，默认false；true时需同步填写dispatchInfo               |
| dispatchInfo | OBJECT | 否 | 否 | 发货物流参数（dispatchFlag为true时填写），详见下方dispatchInfo子表    |
| remark | STRING | 否 | 否 | 备注（最多250字符）                                         |
| otherRemark | STRING | 否 | 否 | 第三方备注（最多250字符）                                      |
| approved | BOOLEAN | 否 | 否 | 是否直接审核出库，默认false；true时出库后自动完成出库单审核                  |
| toDefaultWarehouse | BOOLEAN | 否 | 否 | 是否使用默认仓库，默认false，与warehouseId二选一                    |
| autoReception | BOOLEAN | 否 | 否 | 是否自动签收，默认false                                      |
| details | ARRAY | 否 | 是 | 出库商品明细列表（为空则全部一次出库）                               |
| details[].id | NUMBER | 否 | 否 | 订单商品明细ID（OrderDetail主键），details不为空时必填                 |
| details[].productCount | NUMBER | 否 | 否 | 当次出库数量（下单单位），details不为空时必填                          |
| details[].auxUnitCount | NUMBER | 否 | 否 | 当次辅助单位出库数量                                          |
| details[].outStoragePrice | NUMBER | 否 | 否 | 出库单价                                                |
| details[].outStorageMoney | NUMBER | 否 | 否 | 出库金额                                                |
| details[].otherRemark | STRING | 否 | 否 | 行第三方备注（最多250字符）                                     |
| details[].warehouseId | NUMBER | 否 | 否 | 出库时的商品仓库ID，开启多仓分拣模式必传（见下方「多仓分拣规则」） |
| details[].warehouseName | STRING | 否 | 否 | 出库时的商品仓库名称 |
| details[].batches | ARRAY | 否 | 是 | 批次出入库详情（管理批次商品必填）                                   |
| details[].batches[].productCount | NUMBER | 否 | 否 | 批次出入库数量，按下单单位计算 |
| details[].batches[].batchNum | STRING | 否 | 否 | 批次号 |
| details[].batches[].productionDate | DATETIME | 否 | 否 | 生产日期 |
| details[].batches[].expirationDate | DATETIME | 否 | 否 | 过期日期 |
| details[].batches[].productAuxCount | NUMBER | 否 | 否 | 辅助单位的数量 |
| details[].batches[].productAuxUnitId | NUMBER | 否 | 否 | 辅助单位id |
| details[].batches[].productAuxUnitName | STRING | 否 | 否 | 辅助单位名称 |

**dispatchInfo 发货物流参数（dispatchFlag=true 时填写）**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| dispatchMethod | NUMBER | 否 | 否 | 发货途径（1:自有物流 2:快递） |
| expressCompany | STRING | 否 | 否 | 快递公司名称，快递时填写 |
| expressNum | STRING | 否 | 否 | 快递单号，快递时填写 |
| expressCode | STRING | 否 | 否 | 物流公司编码，快递时填写 |
| plateNumber | STRING | 否 | 否 | 物流车牌号，自有物流时填写 |
| driverName | STRING | 否 | 否 | 物流司机名字，自有物流时填写 |
| carId | NUMBER | 否 | 否 | 车辆ID，自有物流时填写 |
| driverId | NUMBER | 否 | 否 | 司机ID，自有物流时填写 |
| contactName | STRING | 否 | 否 | 收货联系人，可覆盖订单原收货人 |
| contactPhone | STRING | 否 | 否 | 联系人电话，可覆盖订单原联系电话 |
| deliveryAddress | STRING | 否 | 否 | 收货地址，可覆盖订单原收货地址 |
| merchantCode | STRING | 否 | 否 | 大B与物流合作的商家编码或手机号后4位 |
| remark | STRING | 否 | 否 | 物流备注 |

**响应数据**
- 返回类型：`STRING`

| 字段 | 类型 | 说明 |
|------|------|------|
| (value) | STRING | 出库单号（billNum），出库成功返回第一个出库单的单号，无出库结果时返回null |

**调用参数示例**
```json
# 全量出库，使用默认仓库，直接审核
{"orderCode": "XH20240101001", "toDefaultWarehouse": true, "approved": true}

# 指定仓库出库并同步自有物流发货
{
  "orderCode": "XH20240101001",
  "warehouseId": 101,
  "dispatchFlag": true,
  "dispatchInfo": {
    "dispatchMethod": 1,
    "plateNumber": "粤A12345",
    "driverName": "张师傅"
  }
}

# 按商品行部分出库
{
  "orderCode": "XH20240101001",
  "warehouseId": 101,
  "details": [
    {"id": 5001, "productCount": 10},
    {"id": 5002, "productCount": 5}
  ]
}
```

**注意**
- `orderCode` 只接受以大写字母开头的订单号格式（如 `XH...`、`TO...`）
- `warehouseId` 和 `toDefaultWarehouse` 需提供其中一个，否则可能出库失败
- `approved=true` 等价于出库后立即审核出库单，适合无需二次审核的场景
- `details` 为空时默认全量出库；需分批出库时需指定明细行

**部分出库前置查询**

执行部分出库（按商品行）前，需先通过 [订单-详情.md](订单-详情.md) 的 `findOrderDetail` 接口查询订单详情，获取：
- `orderDetails[].id`：订单商品明细ID（OrderDetail 主键），对应本接口 `details[].id`
- `stockOutNumberPending`：订货单位待出库总数量，作为可出库数量的参考
- `auxUnitStockOutNumberPending`：辅助单位待出库总数量，作为辅助单位可出库数量的参考

**多仓分拣规则**

调用<site-assistant/references/仓库/仓库.md>的findInventorySettings获取系统仓库参数
当查询到系统仓库参数启用多仓分拣模式时（`enableCategoryWarehouse = true`），出库操作需遵循以下流程：

1. **检查是否启用多仓分拣**
   - 调用 `findInventorySettings` 获取库存设置
   - 查看 `enableCategoryWarehouse` 字段：
     - `true`：已启用多仓分拣，需为每行商品指定仓库
     - `false` 或未启用：使用默认仓库或 `warehouseId` 参数

2. **查询可用仓库列表**（仅在启用多仓分拣时执行）
   - 调用 `findOrderWarehouses` 查询可用仓库
   - 推荐参数：`{"status": 1, "pageSize": 500, "salesBanned": 0}`
   - 返回仓库列表供用户选择

3. **为每行商品指定仓库**
   - `details[].warehouseId` **必传**（不可省略）
   - `details[].warehouseName` 建议填写（方便用户确认）
   - 用户需逐行选择每行商品从哪个仓库出库
