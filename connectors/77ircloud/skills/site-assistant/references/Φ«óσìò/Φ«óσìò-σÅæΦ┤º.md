# createDispatchBill - 订单发货

本文档覆盖订单发货接口，用于根据出库单生成发货单。

## 接口目录
- [createDispatchBill](#createDispatchBill) - 订单发货（根据出库单生成发货单，填写物流信息）

---
## createDispatchBill

**功能**：根据销售出库单生成发货单。订单出库后，可凭出库单ID（`billId`）调用此接口填写物流信息并完成发货。无返回值。

**前置条件**
- 需先调用 `outStorage` 完成订单出库，获得出库单号（`billNum`）
- 出库单已审核（`approved=true` 或已单独审核）后才可发货
- `billId` 为进销存出库单主键 ID，需通过查询接口查找订单下的出库单列表获取

**典型场景**
- 订单出库后，单独填写物流信息并发货
- 快递发货：填写快递公司名称 + 单号
- 自有物流发货：填写车牌号 / 司机信息

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| billId | NUMBER | 是 | 否 | 销售出库单ID（URL路径参数），识别要发货的出库单 |
| dispatchMethod | NUMBER | 是 | 否 | 发货途径（1:自有物流 2:快递发货） |
| expressCompany | STRING | 否 | 否 | 快递公司名称，快递时填写 |
| expressNum | STRING | 否 | 否 | 快递单号，快递时填写 |
| expressCode | STRING | 否 | 否 | 快递公司code，快递时填写 |
| plateNumber | STRING | 否 | 否 | 物流车牌号，自有物流时填写 |
| driverName | STRING | 否 | 否 | 物流司机名字，自有物流时填写 |
| driverId | NUMBER | 否 | 否 | 物流司机ID（对应员工ID），自有物流时填写 |
| carId | NUMBER | 否 | 否 | 车辆ID，自有物流时填写 |
| contactName | STRING | 否 | 否 | 收货联系人，可覆盖订单原收货人 |
| contactPhone | STRING | 否 | 否 | 联系人电话，可覆盖订单原联系电话 |
| deliveryAddress | STRING | 否 | 否 | 收货地址，可覆盖订单原收货地址 |
| autoReception | BOOLEAN | 否 | 否 | 是否自动签收，默认false |
| freightAmount | NUMBER | 否 | 否 | 运费 |
| merchantCode | STRING | 否 | 否 | 大B与物流合作的商家编码（用于快递鸟查询物流轨迹） |
| remark | STRING | 否 | 否 | 物流备注 |
| otherRemark | STRING | 否 | 否 | 第三方备注 |

**响应数据**
- 返回类型：`VOID`（无返回）

无返回值

**调用参数示例**
```json
# 快递发货
{
  "billId": 8001,
  "dispatchMethod": 2,
  "expressCompany": "顺丰速运",
  "expressNum": "SF1234567890",
  "expressCode": "SF"
}

# 自有物流发货
{
  "billId": 8001,
  "dispatchMethod": 1,
  "plateNumber": "粤A12345",
  "driverName": "张师傅",
  "driverId": 301,
  "carId": 201
}
```

**注意**
- `billId` 为进销存出库单主键，不是出库单号（`billNum`），需先查询出库单列表获取
- 出库单必须已审核（`approved=true` 或单独审核）才可发货
- `dispatchMethod` 必填，其余字段按发货方式选填

> 发货前需先完成订单出库，请参阅：[订单-出库.md](订单-出库.md)
