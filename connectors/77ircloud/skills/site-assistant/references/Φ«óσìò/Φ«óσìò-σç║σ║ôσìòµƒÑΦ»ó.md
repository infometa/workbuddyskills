# listOrderOutStorageBills - 查询订单下的销售出库单列表

本文档覆盖订单出库单查询接口，用于查询订单关联的出库单信息。

## 接口目录
- [listOrderOutStorageBills](#listOrderOutStorageBills) - 查询订单下的销售出库单列表（获取出库单ID用于发货）

---
## listOrderOutStorageBills

**功能**：根据订单编码查询该订单下的所有销售出库单列表，返回出库单的基本信息、状态、发货状态、商品明细等。

**典型场景**
- 订单出库后，查询该订单生成了哪些出库单
- 发货前，通过订单号查找对应的出库单 ID（`billId`），用于调用 `createDispatchBill` 发货
- 查看订单出库进度（部分出库时一个订单可能对应多个出库单）
- 查看出库单的发货状态（`dispatched`）和发货单详情（`dispatchBill`）

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| orderNum | STRING | 是 | 否 | 订单编码（URL路径参数） |
| status | NUMBER | 否 | 否 | 单据状态（1:正常 -1:作废 不传查全部） |
| orderDetailIdSet | NUMBER | 否 | 是 | 订单明细ID集合（用于过滤指定商品行的出库单） |
| fillDriverExtInfo | BOOLEAN | 否 | 否 | 是否填充司机的拓展信息（默认false，目前仅在司机端使用） |
| fillStorageLocation | BOOLEAN | 否 | 否 | 是否填充储位信息 |

**调用参数示例**
```json
# 查询订单的全部出库单（含正常和作废）
{"orderNum": "XH20240101001"}

# 只查询正常的出库单
{"orderNum": "XH20240101001", "status": 1}

# 只查询作废的出库单
{"orderNum": "XH20240101001", "status": -1}
```

**使用场景参数：出库后发货**

1. 订单出库后，调用此接口获取出库单列表(listOrderOutStorageBills)：
```json
{"orderNum": "XH20240101001", "status": 1}
```

2. 从返回结果中提取 `id` 字段（即出库单主键 ID），用于发货(createDispatchBill)：
```json
{
  "billId": <出库单的id>,
  "dispatchMethod": 2,
  "expressCompany": "顺丰速运",
  "expressNum": "SF1234567890",
  "expressCode": "SF"
}
```

**注意**
- `id` 是出库单主键 ID，用于发货接口 `createDispatchBill` 的 `billId` 参数
- `billNum` 是出库单号（字符串），用于展示和识别，**不能**直接用于发货
- 一个订单可能对应多个出库单（部分出库、分仓出库场景）
- `dispatched` 为 `true` 表示该出库单已发货，`dispatchBill` 包含发货单详情
- 出库单状态 `status` 为 `0`（待审核）时，需先审核后才能发货
- `orderDetailIdSet` 用于精确定位某个商品行的出库情况，一般场景不传

> 发货流程详情参考：[订单-发货.md](订单-发货.md)；出库流程参考：[订单-出库.md](订单-出库.md)
