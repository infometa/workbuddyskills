# 退单基础数据

本文档覆盖退单查询接口，用于查看退单列表及基本信息。

## 接口目录
- [findReturnOrderPage](#findreturnorderpage) - **退单列表**：按时间/状态/客户等多维度查询退单列表
- [findReturnOrderDetail](#findreturnorderdetail) - **退单商品明细**：按时间/退单状态/商品等多维度查询退单商品明细

---

## findReturnOrderPage

**功能**：分页查询退单列表，支持按创建时间、退单状态、出库状态、收货状态、退款状态、往来单位、商品SKU、业务员等多维度筛选，返回退单完整信息。

**典型场景**
- 查看某段时间内的退单列表
- 查看指定客户的退单记录
- 查询待退单审核/待收货审核/已完成的退单
- 按退款状态筛选需退款的退单
- 按业务员查询其负责客户的退单
- 关键字搜索（退单号/制单人/商品名称）

**参数**

| 参数                  | 类型         | 必填 | 数组 | 说明                                                                                                            |
|----------------------|------------|----|----|---------------------------------------------------------------------------------------------------------------|
| createRangeTime      | TIME_RANGE | 否  | 否  | 退单创建时间范围，对象包含 `startTime` 和 `endTime`，格式：`yyyy-MM-dd HH:mm:ss`                                                |
| orderCodes           | STRING     | 否  | 是  | 退单号列表                                                                                                         |
| buyerIds             | NUMBER     | 否  | 是  | 买方机构ID列表                                                                                                      |
| buyerTypes           | STRING     | 否  | 是  | 退货方类型列表（CUSTOMER=客户/BRANCH=分公司/STORE=门店）                                                                      |
| customerCategoryId   | NUMBER     | 否  | 是  | 客户分类ID列表                                                                                                      |
| buyerRegionIds       | NUMBER     | 否  | 是  | 买方区域ID列表                                                                                                      |
| orderStatus          | STRING     | 否  | 是  | 退单状态列表，枚举值：ORDER_AUDIT_PENDING(待退单审核)/RECEIPT_AUDIT_PENDING(待收货审核)/AUDITED(已审核)/FINISHED(已完成)/CANCELLED(已作废)  |
| deliveryStatus       | STRING     | 否  | 是  | 收货状态列表（UNRECEIVE=未收货/RECEIVED=已收货）                                                                            |
| paymentStatuses      | STRING     | 否  | 是  | 退款状态列表，枚举值：WAIT_PAY(未退款)/PART_PAID(部分退款)/PAID(已退款)/PAID_CHECKING(待确认)                                         |
| skuIds               | NUMBER     | 否  | 是  | SKU ID 列表                                                                                                     |
| salesmanIds          | NUMBER     | 否  | 是  | 下单业务员ID列表                                                                                                     |
| creatorIds           | NUMBER     | 否  | 是  | 制单人ID列表                                                                                                       |
| relatedCode          | STRING     | 否  | 否  | 关联单号（原单退货对应来源订单号）                                                                                             |
| relatedCodes         | STRING     | 否  | 是  | 关联单号列表                                                                                                        |
| payPeriodTypes       | STRING     | 否  | 是  | 结算模式列表（MONTH=月结/CONSTANT=定期结算/NO_CONSTANT=不固定帐期/MONEY_BEFORE_CARGO=先款后货/CARGO_BEFORE_MONEY=货到付款/ROLLING=滚动结算） |
| storageWarehouseIds  | NUMBER     | 否  | 是  | 入库仓库ID列表                                                                                                      |
| showRefundOrder                | BOOLEAN     | 否  | 否  | 是否只显示需退款订单（true：是，false：否），如果只查询退单退款单的时候，必须传true                                                              |

## findReturnOrderDetail

**功能**：分页查询退单商品明细列表，支持按创建时间、退单状态、入库状态、收货状态、商品SKU、分类、品牌、业务员等多维度筛选，返回退单商品的完整明细信息，包含商品信息、单位、数量、金额等。

**典型场景**
- 查看某段时间内退单的商品明细
- 按商品SKU/分类/品牌筛选退单商品
- 查询特定退单状态下的退单商品
- 按业务员查询退单商品明细
- 按库存状态（入库状态/收货状态）筛选

| rangeTime                | TIME_RANGE | 是  | 否  | 退单创建时间范围                                                                      |

| relatedOrderCodeKeyWord  | STRING     | 否  | 否  | 原订单号（模糊搜索）                                                                    |
| buyerIds                 | NUMBER     | 否  | 是  | 退货方机构ID列表                                                                     |
| buyerTypes               | STRING     | 否  | 是  | 退货方类型列表（CUSTOMER=客户/BRANCH=分公司/STORE=门店）                                      |
| orderStatuses            | STRING     | 否  | 是  | 退单状态列表                                                                        |
| storageInStatuses        | STRING     | 否  | 是  | 入库状态列表（NONE=未入库/PART=部分入库/FULL=已入库）                                           |
