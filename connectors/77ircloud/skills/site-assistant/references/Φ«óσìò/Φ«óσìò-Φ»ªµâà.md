# 订单详情

本文档覆盖单个订单的详情查询接口，用于查看订单的完整信息，包括买方/卖方、商品明细、赠品、金额、收货、配送、退单、发票等。

## 接口目录
- [findOrderDetail](#findorderdetail) - **查询单个订单详情**：返回订单全部字段

**扩展文档**（仅在以下场景才需查阅）：
- 需要**查看订单列表、按条件筛选订单** → 查阅 [订单.md](订单.md)
- 需要**按商品维度查看销售明细** → 查阅 [订单.md](订单.md) 中的 `findOrderProductDetail`

> 本接口需传 `id`（订单ID），可先通过 [订单.md](订单.md) 中的 `customerOrderList` 接口查询订单列表，从返回结果中获取订单ID。

## findOrderDetail

**功能**：根据订单ID查询单个订单的完整详情，包含买方/卖方机构信息、商品明细与赠品、金额汇总、收货地址、配送状态、关联退单、发票信息等全部字段。

**典型场景**
- 查看某个订单的完整信息
- 获取订单商品明细（SKU、数量、单价、折扣、出库状态）
- 查看订单的收货地址和配送方式
- 获取订单关联的退单信息
- 查看订单备注和附件
- 查看订单发票信息（需传 `withInvoice=true`）
- 查看商品库位信息（需传 `withSkuStorageLocation=true`）
- 部分出库前的待出库数量核对：查询订单的 `stockOutNumberPending`（订货单位待出库数量）和 `auxUnitStockOutNumberPending`（辅助单位待出库数量），确认剩余待出库数量后，结合 [订单-出库.md](订单-出库.md) 的 `outStorage` 接口按商品行执行部分出库

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| buyerTypeCode | STRING | 否 | 否 | 组织层级（customer/branch/store），默认 customer |
| id | NUMBER | 是 | 否 | 订单ID |
| withInvoice | BOOLEAN | 否 | 否 | 是否附带发票信息，默认false |
| withSkuStorageLocation | BOOLEAN | 否 | 否 | 商品是否附带库位信息，默认false |

**响应数据**
- 返回类型：`OBJECT`（单个订单对象）

> ⛔ **字段级权限说明**：标记为"价格字段"的字段受权限控制，无订单价格查看权限时可能为空。
