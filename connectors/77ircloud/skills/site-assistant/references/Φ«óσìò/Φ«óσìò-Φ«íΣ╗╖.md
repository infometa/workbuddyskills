# 订单计价

本文档覆盖下单前价格预计算接口，用于在正式提交订单前获取含促销、优惠券、运费的完整报价。

## 接口目录
- [calculateOrderPrice](#calculateorderprice) - 代客户下单计算价格（含促销/优惠券/运费）

---

## calculateOrderPrice

**功能**：代客户下单前进行价格预计算，传入商品明细及下单条件，返回含促销折扣、优惠券抵扣、运费、积分抵扣后的完整报价结果。正式提交订单（`createToBOrder`）前必须先调用此接口获取计算结果。

**典型场景**
- 下单前展示订单总价、运费、促销折扣详情
- 用户选择/切换优惠券时实时更新报价
- 修改商品数量后重新计算价格

**参数**

| 参数                                | 类型 | 必填 | 数组 | 说明                                                               |
|-----------------------------------|------|------|------|------------------------------------------------------------------|
| buyerId                           | NUMBER | 是 | 否 | 订货方（客户）组织ID，可从customerList获取                                     |
| type                              | NUMBER | 是 | 否 | 业务类型，代客户下单固定传2                                                   |
| totalFreight                      | NUMBER | 是 | 否 | 运费金额，不确定时传0                                                      |
| productPriceList                  | ARRAY | 是 | 是 | 商品价格明细列表，不能为空，最多500条                                             |
| productPriceList[].skuId          | NUMBER | 是 | 否 | SKU ID，可从findOrderCustomerSku获取                                  |
| productPriceList[].multiUnitId    | NUMBER | 是 | 否 | 单位ID，取自multiUnitList中对应单位的id                                     |
| productPriceList[].productCount   | NUMBER | 是 | 否 | 商品数量                                                             |
| productPriceList[].originalPrice  | NUMBER | 是 | 否 | 商品原价，取自multiUnitList[].originalPrice                                     |
| productPriceList[].modifyFlag     | BOOLEAN | 是 | 否 | 单价是否被修改，未改价传false                                                |
| productPriceList[].productPrice   | NUMBER | 是 | 否 | 商品单价（促销或手动改价），未改价同originalPrice                                  |
| productPriceList[].productMoney   | NUMBER | 是 | 否 | 商品金额（小计）                                  |
| productPriceList[].auxUnitId      | NUMBER | 否 | 否 | 辅助计量单位ID（使用辅助单位时填写）                                              |
| productPriceList[].auxUnitNumbers | NUMBER | 否 | 否 | 辅助单位购买数量                                                         |
| productPriceList[].type           | STRING | 是 | 否 | 订单商品类型（NORMAL=普通商品 MANUAL_GIFT=手动添加的赠品 PROMOTION_GIFT=促销活动生成的赠品） |
| productPriceList[].discountRate   | NUMBER | 否 | 否 | 折扣率（0.00000000~1），1表示没有折扣                                        |
| productPriceList[].activityId     | NUMBER | 否 | 否 | 所属促销活动ID（赠品不能为空）                                                 |
| addressId                         | NUMBER | 否 | 否 | 收货地址ID，可从getCustomerDetail.deliveryAddresses获取                   |
| countryId                         | NUMBER | 否 | 否 | 收货地址-国家级区域ID                                                     |
| provinceId                        | NUMBER | 否 | 否 | 收货地址-省级行政区域ID                                                    |
| cityId                            | NUMBER | 否 | 否 | 收货地址-地级市区域ID                                                     |
| districtId                        | NUMBER | 否 | 否 | 收货地址-县级区域ID                                                      |
| deliveryAddress                   | STRING | 否 | 否 | 收货地址-详细地址                                                        |
| warehouseId                       | NUMBER | 否 | 否 | 发货仓库ID，可从findOrderWarehouses获取                                   |
| deliveryMethodId                  | NUMBER | 否 | 否 | 配送方式ID                                                           |
| deliveryDate                      | DATETIME | 否 | 否 | 交货日期                                                             |
| couponId                          | NUMBER | 否 | 否 | 优惠券ID，可结合availableCoupons结果选择                                    |
| needCoupon                        | BOOLEAN | 否 | 否 | 是否使用优惠券，传true时需同时传couponId                                       |
| fetchPoint                        | BOOLEAN | 否 | 否 | 是否获取可用积分，客户自主下单默认true，其他情况默认false                                |
| usePoint                          | BOOLEAN | 否 | 否 | 是否使用积分抵扣，默认false                                                 |
| ignorePromotion                   | BOOLEAN | 否 | 否 | 是否忽略促销，默认false                                                   |
| customFreight                     | BOOLEAN | 否 | 否 | 是否自定义运费，默认true                                                   |
| rebateAmount                      | NUMBER | 否 | 否 | 返利金额                                                             |
| orderRebateInfos                  | ARRAY | 否 | 是 | 使用返利账户信息列表                                                       |
| orderDiscountAmount               | NUMBER | 否 | 否 | 整单改价优惠金额                                                         |
| bargainFlag                       | BOOLEAN | 否 | 否 | 是否特价单                                                            |
| orderInvoice                      | OBJECT | 否 | 否 | 订单发票参数                                                           |

**响应数据**
- 返回类型：`OBJECT`

| 字段 | 类型 | 说明 |
|------|------|------|
| totalAmount | NUMBER | 商品累计金额（原价合计） |
| productTotalAmount | NUMBER | 商品小计之和（含促销，不含优惠券分摊） |
| totalFreight | NUMBER | 运费 |
| discountAmount | NUMBER | 商品优惠金额（促销） |
| orderDiscountAmount | NUMBER | 整单优惠金额（含优惠券和积分） |
| couponAmount | NUMBER | 优惠券总金额 |
| couponId | NUMBER | 使用的优惠券ID |
| point | NUMBER | 本次使用的积分数量 |
| totalPoint | NUMBER | 积分总数 |
| pointAmount | NUMBER | 积分抵扣金额 |
| rebateAmount | NUMBER | 返利金额 |
| totalWeight | NUMBER | 商品重量合计 |
| freightDesc | STRING | 运费生成来源描述 |
| presentList | ARRAY | 促销满赠信息列表 |
| availableCoupons | ARRAY | 可用优惠券列表 |
| productPriceList | ARRAY | 各商品价格计算结果列表 |
| productPriceList[].skuId | NUMBER | SKU ID |
| productPriceList[].productName | STRING | 商品名称 |
| productPriceList[].productCode | STRING | 商品编码 |
| productPriceList[].productSpec | STRING | 商品规格 |
| productPriceList[].multiUnitId | NUMBER | 单位ID |
| productPriceList[].unitName | STRING | 单位名称 |
| productPriceList[].productCount | NUMBER | 商品数量 |
| productPriceList[].productPrice | NUMBER | 商品单价（计算后） |
| productPriceList[].originalPrice | NUMBER | 商品原价 |
| productPriceList[].productMoney | NUMBER | 商品金额（小计） |
| productPriceList[].discountRate | NUMBER | 折扣率 |
| productPriceList[].promotionCategory | STRING | 促销类型（DROP/DISCOUNT/MONEY_REDUCE/PRESENT） |
| productPriceList[].description | STRING | 促销描述 |
| productPriceList[].type | STRING | 订单商品类型（NORMAL=普通商品 MANUAL_GIFT=手动添加的赠品 PROMOTION_GIFT=促销活动生成的赠品） |
