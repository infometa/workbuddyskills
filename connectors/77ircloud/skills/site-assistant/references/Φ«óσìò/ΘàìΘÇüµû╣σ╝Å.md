# 配送方式

本文档覆盖订单配送方式查询接口，用于在下单前获取买方可选的配送方式列表。

## 接口目录
- [getPermittedDeliveryMethod](#getpermitteddeliverymethod) - 查询买方可选配送方式列表

---

## getPermittedDeliveryMethod

**功能**：根据买方机构层级和机构ID，查询该买方在当前卖方体系下可使用的配送方式列表，同时标记最近一次使用的配送方式，方便下单时预选。

**典型场景**
- 代客户下单时，展示可选配送方式供用户选择
- 下单前获取配送方式ID（`deliveryMethodId`）用于计算运费
- 根据 `latestDeliveryWay` 自动回填上次使用的配送方式

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| hierarchyCode | STRING | 是 | 否 | 机构层级，枚举值：branch（分公司）/ store（门店）/ customer（客户） |
| buyerId | NUMBER | 是 | 否 | 买方机构ID，来自searchDirectUnder.id或getCustomerDetail.id |

**响应数据**
- 返回类型：`ARRAY`（数组）

| 字段 | 类型 | 说明                                                                      |
|------|------|-------------------------------------------------------------------------|
| id | NUMBER | 配送方式ID（下单时传入deliveryMethodId，计价时传入calculateOrderPrice.deliveryMethodId） |
| name | STRING | 配送方式名称（如"送货上门"、"到店自提"）                                                  |
| note | STRING | 备注描述                                                                    |
| freightPricingWay | STRING | 运费计价方式(CONFIRMED_AT_CREATE_ORDER=下单时确定/CONFIRMED_AT_DELIVERY=发货时确定)                                |
| enabled | BOOLEAN | 是否启用                                                                    |
| enableWholesale | BOOLEAN | 分销是否启用                                                                  |
| enableRetail | BOOLEAN | 零售是否启用                                                                  |
| sysDefault | BOOLEAN | 是否系统默认（系统默认不能删除）                                                        |
| deliveryWay | STRING | 配送方式类型（自提/送货上门）                                                         |
| latestDeliveryWay | BOOLEAN | 是否为该买方最近一次使用的配送方式（true时可作为默认选项）                                         |
---

## 跨接口组合示例

**场景**：代客户下单时选择配送方式
1. `searchDirectUnder` → 传入 `hierarchyCodes: ["CUSTOMER"]` 搜索客户，获取客户ID 及其机构层级
2. `getPermittedDeliveryMethod` → 传入 `hierarchyCode: "customer"`、`buyerId` 为客户ID，获取可选配送方式列表
3. 优先选取 `latestDeliveryWay: true` 的项作为默认值，将 `id` 填入 `calculateOrderPrice.deliveryMethodId` 与 `createToBOrder.deliveryMethodId`
