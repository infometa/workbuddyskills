# 订单基础数据

本文档覆盖订单查询接口，用于查看订单列表及基本信息，支持查询订单明细信息。

## 接口选择指引

| 场景 | 推荐接口 |
|------|---------|
| 查看订单列表、订单金额、订单状态（待审核/待出库等）、收货信息等**整单维度的信息** | `customerOrderList` |
| 按商品维度查看**每行商品的销售明细**（单价、数量、折扣、出库等），需要看到订单中每个 SKU 的销售情况 | `findOrderProductDetail` |

## 接口目录
- [customerOrderList](#customerorderlist) - **订单列表**：整单维度，适用于"看看有什么订单"场景
- [findOrderProductDetail](#findorderproductdetail) - **订单商品明细**：商品维度，适用于"看看某个商品卖了多少"场景

**组合场景**（涉及订单审核操作，执行前先阅读）：
- [订单-批量审核.md](订单-批量审核.md) - 查询待审核订单并批量审核

**扩展文档**（仅在以下场景才需查阅，查询普通订单列表无需读取）：
- 用户需要**查看订退单合并列表、筛选退单、查看订单中的商品明细、分析各商品分类的订货金额占比** → 查阅 [统计/订退单.md](../统计/订退单.md)
- 用户需要**按商品/品牌/分类/客户维度汇总订货数量与金额**（如各商品销量排行、某客户购买了哪些商品、同一商品不同规格的订货量） → 查阅 [统计/订货统计.md](../统计/订货统计.md)

## customerOrderList

**功能**：查询订单列表，支持按时间范围、买方/卖方、订单状态、出库/发货状态、业务员、配送方式、仓库等多维度筛选，返回订单完整信息。

**典型场景**
- 查看某段时间内的订单列表
- 查看指定客户的订单记录
- 查询待审核/待出库/待发货/待签收的订单
- 按业务员查询其负责客户的订单
- 按配送方式（自提/送货）筛选订单
- 获取订单号用于下游接口
- 关键字搜索（订单号/制单人/买家名称/商品名称）

## findOrderProductDetail

**功能**：查询订单商品明细，按商品维度查看每笔订单的下单记录，支持按时间范围、往来单位、商品、订单状态等多维度筛选，返回每行商品的完整信息（含单价、数量、金额、折扣、出库状态等）。

**典型场景**
- 查看某张订单下的商品明细
- 查看某段时间内各商品的销售明细
- 按往来单位、SKU、品牌、分类等维度筛选查看商品销售详情

## 订单查询技巧

- **有订单号** → 用 `orderCodes` 精准查询，不查全量
- **有客户名** → 用 `buyerIds` 或 `q` 参数过滤，不本地过滤
- **默认时间范围**：`rangeTime`（下单时间）是默认的时间筛选字段。当用户说"上周的订单"时，指的是**下单时间**在上周的订单。除非用户明确提到"审核时间""交货日期"等**时间范围关键词**，才使用其他时间范围参数。注意："已审核"（orderStatus=AUDITED）是订单状态，不是"审核时间"时间范围
