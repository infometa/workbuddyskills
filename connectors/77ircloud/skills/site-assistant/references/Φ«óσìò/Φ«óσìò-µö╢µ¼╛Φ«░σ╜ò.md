# 收款记录查询

本文档覆盖收款记录查询接口，用于查询订单、退单的收款记录列表。

## 接口目录
- [findPaymentRecordPage](#findpaymentrecordpage) - 分页查询订(退)单收款记录列表

---

## findPaymentRecordPage

**功能**：分页查询订单或退单的收款记录列表，按创建时间倒序排列。

**典型场景**
- 查询订单收款记录（type=1）
- 查询退单收款记录（type=2）
- 查询某段时间内的收款记录

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| type | NUMBER | 是 | 否 | 查询类型，枚举值：1(订单)/2(退单)/3(订单和退单) |
| sourceBizCodes | STRING | 否 | 是 | 来源单号列表，精确匹配订单号 |
| createRangeTime | TIME_RANGE | 否 | 否 | 创建时间范围，对象包含 `startTime` 和 `endTime`，格式：`yyyy-MM-dd HH:mm:ss` |
| auditRangeTime | TIME_RANGE | 否 | 否 | 审核时间范围，对象包含 `startTime` 和 `endTime`，格式：`yyyy-MM-dd HH:mm:ss` |
| modifyRangeTime | TIME_RANGE | 否 | 否 | 修改时间范围，对象包含 `startTime` 和 `endTime`，格式：`yyyy-MM-dd HH:mm:ss` |
| currentPage | NUMBER | 否 | 否 | 当前页码，默认1 |
| pageSize | NUMBER | 否 | 否 | 每页条数，默认50 |

**响应数据**
- 返回类型：`PAGE`（分页）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | NUMBER | 收付款记录ID |
| paymentRecordCode | STRING | 收付款单号 |
| orderCode | STRING | 订单号 |
| payMoney | NUMBER | 收付款金额 |
| payTime | DATETIME | 收付款时间 |
| paymentMethodCode | STRING | 收付款方式 |
| paymentMethodName | STRING | 收付款方式名称 |
| receiptCode | STRING | 收款单号 |
| fundSummaryId | NUMBER | 摘要ID |
| fundSummaryDesc | STRING | 摘要名称 |
| createTime | DATETIME | 创建时间 |
| modifyTime | DATETIME | 修改时间 |
| receiptPaymentBillId | NUMBER | 收付款单ID |

## 接口选择指引

| 用户意图 | 推荐接口 |
|----------|----------|
| 查询订单收款记录 | findPaymentRecordPage（type=1）|
| 查询退单收款记录 | findPaymentRecordPage（type=2）|
| 查询所有收款记录 | findPaymentRecordPage（type=3）|
