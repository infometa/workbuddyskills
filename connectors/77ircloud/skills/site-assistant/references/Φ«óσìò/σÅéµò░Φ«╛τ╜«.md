# 订单配置查询

本文档覆盖订单配置查询接口，用于获取当前组织的订单相关配置信息。

## 接口目录
- [findOrderConfiguration](#findorderconfiguration) - 查询订单配置（获取订单流程/运费/退单/自动作废等配置）

---

## findOrderConfiguration

**功能**：查询订单配置信息，返回组织的订单流程设置、运费配置、退单规则、自动作废时间、促销设置等完整配置信息。不传orgId则查询当前组织配置。

**典型场景**
- 下单前查询组织的订单配置，了解业务规则
- 查看是否开启了一键代发、直发功能
- 查询订单自动作废时间、起订金额等限制
- 了解退单流程要求和签收规则
- 查看运费模板和包邮配置

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| orgId | NUMBER | 否 | 否 | 组织ID，可选，不传默认为当前组织 |

**配送方式列表（deliveryMethods）详细说明**

`deliveryMethods` 返回当前组织配置的所有配送方式，每个配送方式包含以下字段：

| 字段 | 类型 | 说明 |
|------|------|------|
| id | NUMBER | 配送方式ID（**下单时传入 `createToBOrder.deliveryMethodId`，计价时传入 `calculateOrderPrice.deliveryMethodId`**） |
| name | STRING | 配送方式名称（如"到店自提"、"送货上门"） |
| note | STRING | 备注说明 |
| freightPricingWay | STRING | 运费计价时机：`CONFIRMED_AT_CREATE_ORDER`（下单时确认运费）/ `CONFIRMED_AT_DELIVERY`（发货时确认运费） |
| enabled | BOOLEAN | 是否启用（true:启用 false:禁用） |
| enableWholesale | BOOLEAN | 是否支持分销（批发）业务 |
| enableRetail | BOOLEAN | 是否支持零售业务 |
| sysDefault | BOOLEAN | 是否系统预置的配送方式（true:系统预置 false:自定义） |
| deliveryWay | STRING | 配送类型：`PICK_UP`（到店自提）/ `DELIVERY`（送货上门） |
| customerCategories | ARRAY | 适用的客户分类列表（null表示不限制，有值则仅对这些客户分类可见） |
| customerCategories[].customerCategoryId | NUMBER | 客户分类ID |
| customerCategories[].customerCategoryName | STRING | 客户分类名称 |

**配送方式关键字段说明**：
- **id**：配送方式主键ID，用于下单和计价接口
- **enabled**：只有 `enabled: true` 的配送方式才可在下单时选择
- **deliveryWay**：区分自提和送货，影响后续物流信息填写
- **freightPricingWay**：决定运费计算时机，`CONFIRMED_AT_CREATE_ORDER` 表示下单时确定运费，`CONFIRMED_AT_DELIVERY` 表示发货时才确定运费
- **customerCategories**：客户分类限制，如果该字段有值，则该配送方式仅对指定的客户分类可见；如果为 `null`，则对所有客户可见

**注意**
- 不传orgId参数时，默认查询当前登录组织的配置
- 返回的配置信息包含订单业务的全流程规则，可用于下单前校验和提示
- `autoDiscardOrderMinutes` 和 `notAuditAutoDiscardMinutes` 需配合使用，分别控制提交后和审核后的自动作废
- `allowYjdf` 和 `allowZF` 控制是否允许使用一键代发和直发功能
- **下单前必须从 `deliveryMethods` 中选择 `enabled: true` 的配送方式ID**
- **如果配送方式的 `customerCategories` 有值，需确认当前客户属于该客户分类才能使用该配送方式**

## 跨接口组合示例

**场景**：代客户下单前检查组织配置
1. `findOrderConfiguration` → 查询订单配置，获取起订金额、自动作废时间等限制
2. `calculateOrderPrice` → 根据配置计算订单价格
3. `createToBOrder` → 创建订单时遵守配置规则

**场景**：查询运费配置
1. `findOrderConfiguration` → 获取运费模板启用状态、包邮配置、运费说明
2. `calculateOrderPrice` → 传入运费配置计算订单总价

**场景**：下单前选择合适的配送方式
1. `findOrderConfiguration` → 查询 `deliveryMethods` 列表
2. 筛选 `enabled: true` 的配送方式
3. 根据 `deliveryWay` 区分自提/送货，根据 `freightPricingWay` 确认运费计算时机
4. 检查 `customerCategories` 是否限制当前客户
5. 将选中的配送方式 `id` 传入 `calculateOrderPrice.deliveryMethodId` 和 `createToBOrder.deliveryMethodId`

**场景**：查看退单规则
1. `findOrderConfiguration` → 获取退单流程设置、退单原因类型、是否必须按订单退货
2. 根据配置引导用户正确提交退单
