# 知识检索

铱云知识库检索，本文档覆盖知识库检索接口，用于在租户默认知识库中执行语义检索，返回相关文档切片。

## 接口目录
- [knowledgeSearch](#knowledgeSearch) - 知识库检索

---

## knowledgeSearch

**功能**：使用租户默认知识库执行语义检索，返回与查询文本相关的文档切片及其相似度分数。

**典型场景**
- 用户在 AI 助手对话框输入问题，检索知识库中相关内容
- 按场景标识过滤，限定检索范围到特定场景的文档
- 获取检索结果的相似度分数，用于前端高亮展示

**参数**

| 参数        | 类型     | 必填 | 数组 | 说明               |
|-----------|--------|----|----|------------------|
| query     | STRING | 否  | 否  | 检索文本，最大 8000 字符  |
| sceneType | STRING | 否  | 否  | 场景标识过滤，未传则不按场景过滤 |

**响应数据**：`OBJECT`

| 字段                     | 说明                              |
|------------------------|---------------------------------|
| provider               | Provider 名称                     |
| knowledgeBaseName      | 知识库名                            |
| collectionName         | Provider API 返回的知识库名            |
| count                  | 命中数                             |
| items                  | 召回项列表（SearchItem 数组）            |
| items[].id             | 分片 ID                           |
| items[].pointId        | 切片 ID（知识库下唯一）                   |
| items[].content        | 召回正文                            |
| items[].score          | 相似度                             |
| items[].rerankScore    | 重排分数                            |
| items[].docId          | 所属文档 ID                         |
| items[].docName        | 所属文档名                           |
| items[].chunkTitle     | 切片标题                            |
| items[].chunkType      | 切片类型（structured / text / faq 等） |
| items[].chunkId        | 切片顺序位次                          |
| items[].rerankPosition | 重排后位置                           |
| costMs                 | Provider 内部耗时（ms）               |
