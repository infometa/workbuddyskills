# 知识文档

铱云知识库文件，本文档覆盖知识库文件管理相关接口，支持：知识文档列表、知识库场景标识筛选。

## 接口目录
- [getKnowledgeSceneTypes](#getknowledgescenetypes) - 知识库场景标识汇总
- [listKnowledgeFileRecords](#listknowledgefilerecords) - 知识库文件记录列表

---

## getKnowledgeSceneTypes

**功能**：获取知识库下全部场景标识汇总，用于场景筛选下拉选项。

**典型场景**
- 知识文档列表页的场景标识筛选下拉数据源
- 上传文件前选择所属场景标识

**参数**
无参数

**响应数据**：`ARRAY<STRING>`，场景标识值列表

---

## listKnowledgeFileRecords

**功能**：分页查询知识库文件记录列表，支持按文件名、MIME 类型、同步状态、场景标识、上传时间范围筛选。

**典型场景**
- 查看知识库已上传的文档列表
- 按同步状态筛选待同步/已同步/同步失败的文档
- 按场景标识过滤特定场景下的文档

**参数**

| 参数          | 类型         | 必填 | 数组 | 说明                                                     |
|-------------|------------|----|----|--------------------------------------------------------|
| currentPage | NUMBER     | 否  | 否  | 当前页码，默认 1                                              |
| pageSize    | NUMBER     | 否  | 否  | 每页数量，默认 20                                             |
| syncStatus  | STRING     | 否  | 否  | pending / synced / failed                              |
| fileName    | STRING     | 否  | 否  | 文件名模糊匹配                                                |
| fileType    | STRING     | 否  | 否  | MIME 类型精确匹配                                            |
| rangeTime   | TIME_RANGE | 否  | 否  | 文件上传时间范围，需传 startTime 和 endTime，格式：yyyy-MM-dd HH:mm:ss |
| sceneType   | STRING     | 否  | 否  | 场景标识模糊匹配，忽略大小写                                         |

**响应数据**：`PAGE`

| 字段          | 类型     | 说明     |
|-------------|--------|--------|
| totalCount  | NUMBER | 总记录数   |
| currentPage | NUMBER | 当前页码   |
| pageSize    | NUMBER | 每页大小   |
| totalPage   | NUMBER | 总页数    |
| items       | ARRAY  | 文件记录列表 |

**items 元素字段**：

| 字段                | 类型       | 说明                              |
|-------------------|----------|---------------------------------|
| id                | STRING   | 文件记录 ID                         |
| tenantId          | NUMBER   | 租户 ID                           |
| orgId             | NUMBER   | 组织 ID                           |
| chainId           | NUMBER   | 业务链 ID                          |
| userId            | NUMBER   | 用户 ID                           |
| fileName          | STRING   | 原始文件名                           |
| ossKey            | STRING   | OSS 文件 Key                      |
| ossUrl            | STRING   | OSS 访问 URL                      |
| fileType          | STRING   | MIME 类型                         |
| fileSize          | NUMBER   | 文件大小（字节）                        |
| syncStatus        | STRING   | 同步状态（pending / synced / failed） |
| knowledgeBaseName | STRING   | 知识库名称                           |
| docId             | STRING   | 知识库中的 doc_id                    |
| description       | STRING   | 文件描述                            |
| sceneType         | STRING   | 场景标识                            |
| createdTime       | DATETIME | 创建时间                            |
| modifyTime        | DATETIME | 更新时间                            |
