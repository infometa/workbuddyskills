# 出入库单选商品

本文档覆盖出入库单据（其他入库单/其他出库单等）选择商品场景的查询接口：SKU查询返回商品编码/名称/规格/条码/多单位等基础信息，按需聚合库存（可用数/总库存/预购数/成本金额）与价格（成本价/实时成本价/多单位价格）信息，用于制单时挑选商品、带出成本价与库存；批次查询返回各批次的批次号、生产/过期日期、批次库存量与出库成本价，用于批次管理商品制单时挑选批次。

## 接口目录
- [findStorageBillSelectSku](#findstoragebillselectsku) - 出入库单选择商品
- [findSkuSelectBatch](#findskuselectbatch) - 出入库单选择商品批次

---

## findStorageBillSelectSku

**功能**：查询商品SKU列表（出入库单据选择商品场景）；

**典型场景**
- 创建其他入库单/其他出库单时，按关键字搜索并选择商品
- 制单时带出指定仓库的库存（可用数/总库存/预购数）和成本单价
- 按分类/品牌/标签筛选可选商品

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明                                         |
|------|------|------|------|--------------------------------------------|
| q | STRING | 否 | 否 | 搜索关键字（商品名称/编码/条码）                          |
| categoryCode | STRING | 否 | 否 | 商品分类编码                                     |
| categoryIds | NUMBER | 否 | 是 | 商品分类ID集合                                   |
| brandIds | NUMBER | 否 | 是 | 商品品牌ID集合                                   |
| tagIds | NUMBER | 否 | 是 | 商品标签ID集合                                   |
| skuIds | NUMBER | 否 | 是 | sku id集合（传了该参数时不分页，返回对应的所有sku）最多200个       |
| codes | STRING | 否 | 是 | sku商品编码集合                                  |
| warehouseId | NUMBER | 否 | 否 | 仓库ID（传此参数后按指定仓库查询库存及成本价，默认查总仓数据）           |
| skuHasBatchCountFlag | BOOLEAN | 否 | 否 | 是否标记商品有可用批次库存数（默认false）                    |
| fillStorageLocation | BOOLEAN | 否 | 否 | 是否填充库位信息（默认false）                          |
| priceStrategy | NUMBER | 否 | 否 | 价格策略（0=成本价(默认) 1=上一笔出入库审核单价）               |
| storageType | NUMBER | 否 | 否 | 出入库场景（仅其他出入库：1=入库 2=出库；priceStrategy=1时必传） |

**响应数据**
- 返回类型：`PAGE`（分页）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | NUMBER | 商品SKU ID |
| spuId | NUMBER | 商品SPU ID |
| code | STRING | 商品SKU编码 |
| shortCode | STRING | 商品SKU简称 |
| name | STRING | 商品SKU名称 |
| spec | STRING | 商品规格描述 |
| barcode | STRING | 商品主条码 |
| baseUnitName | STRING | 商品基础计量单位（库存管理单位）名称 |
| enableMultiUnit | BOOLEAN | 是否启用多单位 |
| weight | NUMBER | 商品重量 |
| origin | STRING | 商品产地 |
| qualityGuaranteePeriod | NUMBER | 商品保质期数值 |
| qualityGuaranteePeriodUnit | NUMBER | 商品保质期单位，见「保质期单位」 |
| type | NUMBER | 商品类型，见「商品类型」 |
| categoryId | NUMBER | 商品分类ID |
| skuStatus | OBJECT | sku状态 |
| skuStatus.shelfStatus | NUMBER | 上下架状态，见「上下架状态」 |
| skuStatus.status | NUMBER | 商品状态，见「商品状态」 |
| enableProductionDate | BOOLEAN | 是否启用管理生产日期 |
| availableAmount | NUMBER | 当前库存可用数（按基础单位；传warehouseId时为该仓库可用数） |
| amount | NUMBER | 当前总库存量（按基础单位；传warehouseId时为该仓库库存量） |
| preOrderCount | NUMBER | 占用预购数（按基础单位） |
| multiUnitAmount | STRING | 当前总库存量（按基础单位转大小单位） |
| costAmount | NUMBER | 当前库存成本金额 |
| costPrice | NUMBER | 实时成本单价（传warehouseId时为对应仓库成本价；priceStrategy=1时为上一笔出入库审核单价） |
| multiUnitList | ARRAY | 多单位列表 |
| multiUnitList[].id | NUMBER | 多单位ID |
| multiUnitList[].unitName | STRING | 单位名称 |
| multiUnitList[].rate | NUMBER | 换算率 |
| multiUnitList[].barCode | STRING | 该单位条形码 |
| multiUnitList[].baseStockPrice | NUMBER | 基准进货价（传warehouseId且有库存成本价时为仓库成本价按换算率折算） |
| multiUnitList[].baseWholesalePrice | NUMBER | 基准订货价 |
| multiUnitList[].surplusCostPrice | NUMBER | 实时成本单价（按该单位换算；无出入库记录时取基准进货价） |
| multiUnitList[].unitCount | NUMBER | 当前单位对应的数量 |
| auxUnitId | NUMBER | 辅助单位ID |
| auxUnitName | STRING | 辅助单位名称 |
| auxUnitRate | NUMBER | 辅助单位换算率 |

| storageLocations[].warehouseId | NUMBER | 仓库ID |
| storageLocations[].warehouseName | STRING | 仓库名称 |
| storageLocations[].name | STRING | 库位名称 |
| storageLocations[].code | STRING | 库位编码 |
| storageLocations[].status | NUMBER | 库位状态（1:启用 0:禁用） |
| storageLocations[].remark | STRING | 备注 |

## findSkuSelectBatch

**功能**：查询商品批次信息（出入库单据选择批次场景）。按商品+商品单位ID筛选，返回各批次的批次号、生产/过期日期、批次总库存量、仓库库存量、出库成本价及多单位信息。

**典型场景**
- 批次管理商品创建其他入库单/其他出库单时，按商品挑选可出入库的批次
- 查看各批次的批次总库存量、仓库库存量与出库成本价
- 核对批次是否过期（`expire`），临期/过期批次优先出库

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|---|------|------|
| skuId | NUMBER | 是 | 否| 商品SKU ID集合 |
| warehouseIds | NUMBER | 否 | 是 | 仓库ID集合（按仓库筛选批次库存） |
| unitId | NUMBER | 是 | 否 | 商品单位ID（返回的数量与成本价按该单位换算） |
| checkBatchInventory | BOOLEAN | 否 | 否 | 是否检查库存（true:只返回有库存的批次信息） |

**响应数据**
- 返回类型：`PAGE`（分页）

| 字段 | 类型 | 说明                           |
|------|------|------------------------------|
| batchNum | STRING | 批次号                          |
| productionDate | DATETIME | 生产日期                         |
| expirationDate | DATETIME | 过期日期                         |
| amount | NUMBER | 批次总库存数量（传unitId时按该单位换算并向下取整） |
| warehouseId | NUMBER | 仓库ID                         |
| warehouseName | STRING | 仓库名称                         |
| warehouseAmount | NUMBER | 仓库库存数量（传unitId时按该单位换算并向下取整）  |
| costPrice | NUMBER | 出库成本价（传unitId时按该单位换算率折算）     |
| unitId | NUMBER | 商品基础单位ID（传unitId时返回所传单位ID）   |
| unitName | STRING | 商品基础单位名称                     |
| skuId | NUMBER | 商品SKU ID                     |
| expire | BOOLEAN | 是否过期（过期日期早于当天）               |
| multiUnitList | ARRAY | 多单位列表                        |
| multiUnitList[].id | NUMBER | 多单位ID                        |
| multiUnitList[].unitName | STRING | 单位名称                         |
| multiUnitList[].rate | NUMBER | 换算率                          |
| multiUnitList[].barCode | STRING | 该单位条形码                       |
| multiUnitList[].baseStockPrice | NUMBER | 基准进货价                        |
| multiUnitList[].baseWholesalePrice | NUMBER | 基准订货价                        |
| auxUnitId | NUMBER | 辅助单位ID                       |
| auxUnitName | STRING | 辅助单位名称                       |
| auxUnitRate | NUMBER | 辅助单位换算率                      |
| multiUnitAmount | STRING | 当前总库存量（按基础单位转大中小单位）          |

## 枚举

### 商品状态

| key | value | 说明 |
|-----|-------|------|
| 正常 | 1 | 正常商品 |
| 停采 | 2 | 停止采购 |
| 淘汰 | 3 | 淘汰商品 |
| 停售 | 4 | 停止销售 |

### 商品类型

| key | value | 说明 |
|-----|-------|------|
| 普通商品 | 1 | 普通商品 |
| 套餐商品 | 2 | 套餐商品 |

### 保质期单位

| key | value | 说明 |
|-----|-------|------|
| 天 | 1 | 天 |
| 个月 | 2 | 个月 |
| 年 | 3 | 年 |

### 上下架状态

| key | value | 说明 |
|-----|-------|------|
| 上架 | 1 | 上架 |
| 下架 | 2 | 下架 |

### 价格策略

| key | value | 说明 |
|-----|-------|------|
| 成本价 | 0 | 取库存成本价 |
| 上一笔出入库审核单价 | 1 | 取该仓库上一笔其他出入库单据的审核单价（需同时传warehouseId、storageType） |

### 出入库场景

| key | value | 说明 |
|-----|-------|------|
| 入库 | 1 | 其他入库场景 |
| 出库 | 2 | 其他出库场景 |
