# 仓库基础数据

本文档覆盖仓库查询接口，用于查看仓库列表及基本信息。

## 接口目录
- [findOrderWarehouses](#findorderwarehouses) - 查询可用仓库列表（下单/新建客户选仓专用，支持跨机构权限放行）
- [findWarehouses](#findwarehouses) - 查询仓库列表（通用，仅限当前机构内）
- [findInventorySettings](#findinventorysettings) - 获取库存设置（查询当前库存相关配置）
- [findInventorySettingsByKey](#findinventorysettingsbykey) - 获取指定Key的库存设置

---

## findOrderWarehouses

**功能**：下单选仓专用接口（走 acl 权限放行路径），查询当前机构有权限使用的仓库列表，支持按关键词、状态、禁售标记等条件筛选。

**典型场景**
- 创建订单时选择发货仓库

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| q | STRING | 否 | 否 | 关键词搜索，按仓库名称或编码模糊匹配 |
| status | NUMBER | 否 | 否 | 仓库状态过滤，1:启用 0:禁用；不传查所有 |
| salesBanned | NUMBER | 否 | 否 | 禁售状态过滤，1:禁售 0:非禁售；不传查所有 |
| type | NUMBER | 否 | 否 | 仓库类型过滤，1:成品仓 2:退货仓 3:不良品仓 4:加工仓 |
| orgId | NUMBER | 否 | 否 | 指定机构ID，orgIds和orgId是[与]的关系 |
| orgIds | NUMBER | 否 | 是 | 指定机构ID列表，orgIds和orgId是[与]的关系 |
| hierarchyCode | STRING | 否 | 否 | 机构类型，可选值：STORE(门店) / BRANCH(分公司) |
| warehouseNames | STRING | 否 | 是 | 仓库名称列表，精确匹配仓库名称 |
| skuIds | NUMBER | 否 | 是 | 关联商品ID列表，查询关联了指定商品的仓库 |
| notCheckWarehousePermission | BOOLEAN | 否 | 否 | 不校验仓库权限，默认false |
| currentPage | NUMBER | 否 | 否 | 当前页码，默认1 |
| pageSize | NUMBER | 否 | 否 | 每页条数，默认20 |

**响应数据**
- 返回类型：`PAGE`（分页）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | NUMBER | 仓库ID（用于下游接口如创建订单传 warehouseId） |
| code | STRING | 仓库编码 |
| name | STRING | 仓库名称 |
| type | NUMBER | 仓库类型（1:成品仓 2:退货仓 3:不良品仓 4:加工仓） |
| contactName | STRING | 联系人名称 |
| contactPhone | STRING | 联系人电话 |
| provinceId | NUMBER | 省ID |
| provinceName | STRING | 省名称 |
| cityId | NUMBER | 市ID |
| cityName | STRING | 市名称 |
| districtId | NUMBER | 区域ID |
| districtName | STRING | 区域名称 |
| status | NUMBER | 仓库状态（1:启用 0:禁用） |
| address | STRING | 仓库地址 |
| orgId | NUMBER | 机构ID |
| orgName | STRING | 所属机构名称 |
| salesBanned | NUMBER | 是否禁售仓库（1:是 0:否） |

## findWarehouses

**功能**：通用仓库列表接口（限当前机构内），查询本机构下的仓库数据，适用于仓库管理配置场景。

**典型场景**
- 查看本机构下所有仓库的配置信息
- 按状态、类型、名称筛选仓库

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| status | NUMBER | 否 | 否 | 仓库状态过滤，1:启用 0:禁用；不传查所有 |
| salesBanned | NUMBER | 否 | 否 | 禁售状态过滤，1:禁售 0:非禁售；不传查所有 |
| q | STRING | 否 | 否 | 关键词搜索，按仓库名称或编码模糊匹配 |
| type | NUMBER | 否 | 否 | 仓库类型过滤，1:成品仓 2:退货仓 3:不良品仓 4:加工仓 |
| warehouseNames | STRING | 否 | 是 | 仓库名称列表，精确匹配 |
| skuIds | NUMBER | 否 | 是 | 关联商品ID列表 |
| currentPage | NUMBER | 否 | 否 | 当前页码，默认1 |
| pageSize | NUMBER | 否 | 否 | 每页条数，默认20 |

**响应数据**
- 返回类型：`PAGE`（分页）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | NUMBER | 仓库主键ID |
| name | STRING | 仓库名称 |
| code | STRING | 仓库编码 |
| type | NUMBER | 仓库类型（1:成品仓 2:退货仓 3:不良品仓 4:加工仓） |
| status | NUMBER | 仓库状态（1:启用 0:禁用） |
| salesBanned | NUMBER | 是否禁售（1:是 0:否） |
| orgId | NUMBER | 所属机构ID |
| orgName | STRING | 所属机构名称 |
| address | STRING | 仓库地址 |
| contactName | STRING | 联系人名称 |
| contactPhone | STRING | 联系人电话 |
| provinceName | STRING | 省名称 |
| cityName | STRING | 市名称 |
| districtName | STRING | 区域名称 |

## findInventorySettings

**功能**：获取库存设置，查询当前机构（或指定机构）的库存相关配置，包括超库存订货/出库、电子面单、批次管理、签收设置等。

**典型场景**
- 查看当前库存管理配置（如是否允许超库存订货、是否开启批次管理等）
- 确认电子面单、库位管理等功能是否启用

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| orgId | NUMBER | 否 | 否 | 组织ID，不传默认为当前组织 |

**响应数据**
- 返回类型：`OBJECT`（对象）

| 字段 | 类型 | 说明                                                        |
|------|------|-----------------------------------------------------------|
| allowOrderCountOverStockEnum | STRING | 超库存订货枚举（ALLOW:允许 FORBID:禁止 PROMPT:允许并提示）                  |
| allowOrderCountOverStock | BOOLEAN | 是否允许超库存订货（兼容字段，allowOrderCountOverStockEnum.PROMPT 也表示允许） |
| allowOutStorageCountOverStock | BOOLEAN | 是否允许超库存出库                                                 |
| yjdfDefaultWarehouseId | NUMBER | 一键代发默认仓库ID                                                |
| orderWithWarehouseSpecified | BOOLEAN | 是否指定订货仓库（是否根据订货方配置的仓库确认库存）                                |
| allowOrderDeliveryOverStock | BOOLEAN | 是否允许超订货出库                                                 |
| openElectronicSheet | BOOLEAN | 是否开启电子面单                                                  |
| electronicSheetConfig | STRING | 各服务商电子面单配置项（JSON字符串）                                      |
| overPurchaseInStorage | BOOLEAN | 是否允许超采购订货入库                                               |
| enableBatch | NUMBER | 启用批次管理（0:关闭 1:开启）                                         |
| receivingAll | BOOLEAN | 是否必须全部签收                                                  |
| enableEditExpirationDate | NUMBER | 允许编辑过期日期（0:禁用 1:启用）                                       |
| calculateCostByWarehouse | NUMBER | 按照仓库计算成本（0:否 1:是）                                         |
| createOrderMustSpecifyWarehouse | NUMBER | 下单必须指定仓库（0:禁用 1:启用）                                       |
| storageBillStatisticType | NUMBER | 库存单据统计类型（1:按原出入库时间 2:按作废时间）                               |
| allowOutStoragePendingAudit | NUMBER | 允许出库待审核（0:禁用 1:启用）                                        |
| driverMustSubmitAttach | NUMBER | 司机端送达必须提交附件（0:禁用 1:启用）                                    |
| enableStorageLocation | BOOLEAN | 是否启用库位管理                                                  |
| enableCategoryWarehouse | BOOLEAN | 是否启用多仓分拣                                                  |
| allowModReceiveDifference | BOOLEAN | 是否允许修改签收差异数量                                              |

## findInventorySettingsByKey

**功能**：根据设置Key值查询指定的库存设置项，返回该Key对应的Value值。

**典型场景**
- 判断特定库存配置是否开启（如批次管理、库位管理）
- 获取某个配置项的值

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| key | STRING | 是 | 否 | 设置Key值，路径参数 |
| orgId | NUMBER | 否 | 否 | 组织ID，不传默认为当前组织 |

**响应数据**
- 返回类型：`OBJECT`（对象）

| 字段 | 类型 | 说明 |
|------|------|------|
| property | STRING | 设置的Key值 |
| value | STRING | 设置的Value值 |
| createTime | STRING | 创建时间，格式：yyyy-MM-dd HH:mm:ss |
