# 销售入库单

本文档覆盖销售入库单查询接口，用于查看由销售订单产生的入库单。

## 接口目录
- [searchSellInStorageBills](#searchsellinstoragebills) - 销售入库单列表

---

## searchSellInStorageBills

**功能**：查询由销售订单产生的入库单列表，支持按时间范围筛选。

**典型场景**
- 按时间范围查看销售入库单列表
- 追踪销售订单的入库进度
- 查看入库单的审核状态

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| createTime | TIME_RANGE | 是 | 否 | 入库时间范围 |

**响应数据**
- 返回类型：`PAGE`（分页）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | NUMBER | 入库单ID |
| billNum | STRING | 单据号 |
| status | NUMBER | 单据状态（-1=作废，0=待审核，1=已审核） |
| orderType | NUMBER | 入库单据类型 |
| type | NUMBER | 入库单据类型 |
| orderNum | STRING | 关联业务订单号 |
| sourceId | NUMBER | 入库来源ID（客户或会员） |
| sourceName | STRING | 入库来源名称 |
| warehouseId | NUMBER | 入库仓库ID |
| warehouseName | STRING | 入库仓库名称 |
| warehouseCode | STRING | 入库仓库编码 |
| creatorId | NUMBER | 制单人ID |
| creator | STRING | 制单人 |
| approverId | NUMBER | 审核人ID |
| approverName | STRING | 审核人 |
| approveTime | DATETIME | 审核时间 |
| createTime | DATETIME | 创建时间 |
| modifyTime | DATETIME | 修改时间 |
