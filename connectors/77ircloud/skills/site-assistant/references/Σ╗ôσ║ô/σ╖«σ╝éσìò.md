# 差异单查询

## 接口目录
- [searchDifferenceOrders](#searchdifferenceorders) - 差异单列表

---

## searchDifferenceOrders

**功能**：差异单列表，差异单是在签收过程中产生的（实际收货数量与发货数量不一致时生成），支持按时间范围查询。

**典型场景**
- 查看某段时间内产生的差异单
- 跟进差异单的处理状态
- 核对差异明细（差异数量、差异原因等）

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| rangeTime | TIME_RANGE | 否 | 否 | 差异单时间范围|

**响应数据**
- 返回类型：`PAGE`（分页）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | NUMBER | 差异单ID |
| orderNum | STRING | 差异单号 |
| targetId | NUMBER | 往来ID |
| targetName | STRING | 往来名称 |
| targetCode | STRING | 往来编码 |
| status | NUMBER | 差异单状态（0=待确认，1=已确认） |
| differenceMoney | NUMBER | 差异金额 |
| differenceReason | STRING | 差异原因 |
| originOrderNum | STRING | 原始订单号 |
| receivingBillNum | STRING | 签收单号 |
| storageBillNum | STRING | 出库单号 |
| storageBillId | NUMBER | 关联出库单ID |
| creatorId | NUMBER | 制单人ID |
| creator | STRING | 制单人 |
| createTime | DATETIME | 创建时间 |
| auditorId | NUMBER | 审核人ID |
| auditor | STRING | 审核人 |
| auditTime | DATETIME | 审核时间 |
| targetType | NUMBER | 往来类型 |
