# 库存管理

本文档覆盖库存相关查询接口，包含商品库存查询、库存汇总统计。

## 接口目录
- [searchInventoriesWithSku](#searchinventorieswithsku) - 按总仓维度搜索商品库存（分页查询SKU库存）
- [searchWarehouseInventories](#searchwarehouseinventories) - 按分仓维度搜索商品库存
- [searchInventoriesSummary](#searchinventoriessummary) - 库存列表上方合计（库存汇总统计）

---

## searchInventoriesWithSku

**功能**：按总仓维度分页搜索商品库存，返回SKU级别的库存信息，包含商品详情和库存数据。

**典型场景**
- 查询某个商品的当前库存情况
- 查看指定仓库的商品库存
- 需要获取商品的总库存量、可用库存、预购数等信息
- 库存盘点和库存查询

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| skuIds | NUMBER | 否 | 是 | 商品SKU ID列表，用于筛选指定商品的库存 |
| warehouseId | NUMBER | 否 | 否 | 仓库ID，查询指定仓库的库存；不传则查询总仓库存 |
| currentPage | NUMBER | 否 | 否 | 当前页码，默认1 |
| pageSize | NUMBER | 否 | 否 | 每页数量，默认20 |

**响应数据**
- 返回类型：`PAGE`（分页）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | NUMBER | 库存ID |
| skuId | NUMBER | 商品SKU ID |
| spuId | NUMBER | 商品SPU ID |
| code | STRING | 商品SKU编码 |
| name | STRING | 商品SKU名称 |
| unitId | NUMBER | 商品基础单位ID |
| unitName | STRING | 商品基础单位名称 |
| status | NUMBER | 商品状态（1:正常 2:停采 3:淘汰） |
| amount | NUMBER | 当前总库存量（按基础单位） |
| availableAmount | NUMBER | 当前库存可用数（按基础单位） |
| preOrderCount | NUMBER | 占用预购数（按基础单位） |
| multiUnitAmount | STRING | 当前总库存量（按基础单位转大小单位） |
| multiUnitAvailableAmount | STRING | 当前库存可用数（按基础单位转大小单位） |

**组合示例**：查询"某商品在指定仓库的库存" → 先用 `findOrderWarehouses` 获取仓库ID，再用 `searchInventoriesWithSku` 传 `skuIds` + `warehouseId`

## searchWarehouseInventories

**功能**：按分仓维度分页搜索商品库存，返回每个仓库的库存信息，包含仓库详情和库存数据。

**典型场景**
- 查询某商品在各分仓的库存分布
- 按仓库维度查看商品库存明细
- 了解某个仓库的商品库存情况
- 库存调拨和仓库间的库存对比

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| skuIds | NUMBER | 否 | 是 | 商品SKU ID列表，用于筛选指定商品的库存 |
| warehouseId | NUMBER | 否 | 否 | 仓库ID，查询指定仓库的库存 |
| warehouseIds | NUMBER | 否 | 是 | 仓库IDs，多仓库筛选 |
| categoryId | NUMBER | 否 | 否 | 商品类别ID |
| categoryIds | NUMBER | 否 | 是 | 商品类别ID列表，多分类筛选 |
| q | STRING | 否 | 否 | 搜索关键字（商品名称/编码/条码/商品简称） |
| orgIds | NUMBER | 否 | 是 | 机构id列表，按机构筛选 |
| minInventoryCount | NUMBER | 否 | 否 | 库存数最小值 |
| maxInventoryCount | NUMBER | 否 | 否 | 库存数最大值 |
| minAvailableCount | NUMBER | 否 | 否 | 可用数最小值 |
| maxAvailableCount | NUMBER | 否 | 否 | 可用数最大值 |
| minPreOrderCount | NUMBER | 否 | 否 | 预购数最小值 |
| maxPreOrderCount | NUMBER | 否 | 否 | 预购数最大值 |
| minCostPrice | NUMBER | 否 | 否 | 成本价最小值 |
| maxCostPrice | NUMBER | 否 | 否 | 成本价最大值 |
| minCostMoney | NUMBER | 否 | 否 | 成本金额最小值 |
| maxCostMoney | NUMBER | 否 | 否 | 成本金额最大值 |
| excludeZeroInventoryProduct | BOOLEAN | 否 | 否 | 是否排除0库存商品（true:排除 false:不排除） |
| enableProductionBatch | NUMBER | 否 | 否 | 是否开启批次库存（1:开启 0:未开启） |
| skuStatus | NUMBER | 否 | 是 | sku状态值列表，按状态筛选 |
| currentPage | NUMBER | 否 | 否 | 当前页码，默认1 |
| pageSize | NUMBER | 否 | 否 | 每页数量，默认20 |

**响应数据**
- 返回类型：`PAGE`（分页）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | NUMBER | 库存ID |
| warehouseId | NUMBER | 所属仓库ID |
| warehouseName | STRING | 所属仓库名称 |
| warehouseCode | STRING | 所属仓库编码 |
| skuId | NUMBER | 商品SKU ID |
| spuId | NUMBER | 商品SPU ID |
| code | STRING | 商品SKU编码 |
| name | STRING | 商品SKU名称 |
| shortCode | STRING | 商品SKU简称 |
| barCode | STRING | 商品主条码 |
| unitId | NUMBER | 商品基础单位ID |
| unitName | STRING | 商品基础单位名称 |
| spec | STRING | 商品规格描述 |
| categoryId | NUMBER | 商品品类ID |
| brandId | NUMBER | 商品品牌ID |
| brandName | STRING | 商品品牌名称 |
| status | NUMBER | 商品状态（1:正常 2:停采 3:淘汰） |
| amount | NUMBER | 当前总库存量（按基础单位） |
| availableAmount | NUMBER | 当前库存可用数（按基础单位） |
| preOrderCount | NUMBER | 占用预购数（按基础单位） |
| salesBannedCount | NUMBER | 禁售数（按基础单位） |
| onOrderCount | NUMBER | 在途量（按基础单位） |
| costPrice | NUMBER | 出库成本单价 |
| surplusCostPrice | NUMBER | 当前成本单价 |
| costAmount | NUMBER | 当前成本金额 |
| multiUnitAmount | STRING | 当前总库存量（按基础单位转大小单位） |
| multiUnitAvailableAmount | STRING | 当前库存可用数（按基础单位转大小单位） |
| multiUnitPreOrderCount | STRING | 占用预购数（按基础单位转大小单位） |
| multiUnitSalesBannedCount | STRING | 禁售数（按基础单位转大小单位） |
| multiUnitOnOrderCount | STRING | 在途量（按基础单位转大小单位） |
| upperLimitAmount | NUMBER | 库存上限 |
| lowerLimitAmount | NUMBER | 库存下限 |
| transferTransitQuantity | NUMBER | 转仓在途数 |
| purchaseTransitQuantity | NUMBER | 采购在途数 |
| inTransitQuantity | NUMBER | 在途数量 |
| statisticsUnitRate | NUMBER | 统计单位换算比率 |
| statisticsUnitName | STRING | 统计单位名称 |
| amountStatisticsUnit | STRING | 当前总库存量（统计单位） |
| availableAmountStatisticsUnit | STRING | 当前库存可用数（统计单位） |
| preOrderCountStatisticsUnit | STRING | 占用预购数（统计单位） |
| recordStarted | BOOLEAN | 是否已经开始产生出入库流水记录 |
| storageLocations | OBJECT | 库位信息 |

**组合示例**：查询"某商品在各分仓的库存" → 先用 `findWarehouses` 获取仓库列表，再用 `searchWarehouseInventories` 传 `skuIds` 查看各仓库的库存明细

## searchInventoriesSummary

**功能**：查询库存列表上方的合计数据，返回汇总的库存统计信息，包括总成本金额、总库存量、总可用数等。

**典型场景**
- 在库存列表页面顶部显示汇总数据
- 统计指定分类/仓库/机构的库存总量
- 查看库存的成本金额汇总
- 按条件筛选后的库存合计统计

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| categoryId | NUMBER | 否 | 否 | 商品类别ID，按分类筛选 |
| categoryIds | NUMBER | 否 | 是 | 商品类别ID列表，多分类筛选 |
| q | STRING | 否 | 否 | 搜索关键字，商品名称/编码/条码 |
| warehouseId | NUMBER | 否 | 否 | 仓库ID，按仓库筛选 |
| warehouseIds | NUMBER | 否 | 是 | 仓库IDs，多仓库筛选 |
| orgIds | NUMBER | 否 | 是 | 查询的机构id列表，按机构筛选 |
| skuStatus | NUMBER | 否 | 是 | sku状态值列表，按状态筛选 |
| amount | OBJECT | 否 | 否 | 库存数，支持范围查询，见下方范围参数说明 |
| preOrderCount | OBJECT | 否 | 否 | 预购数，支持范围查询，见下方范围参数说明 |
| availableAmount | OBJECT | 否 | 否 | 可用库存数，支持范围查询，见下方范围参数说明 |
| costPrice | OBJECT | 否 | 否 | 成本价，支持范围查询，见下方范围参数说明 |
| costAmount | OBJECT | 否 | 否 | 成本金额，支持范围查询，见下方范围参数说明 |
| isWarehouseSummary | BOOLEAN | 否 | 否 | 是否分仓数据查询，默认false总仓查询，true分仓查询 |
| searchPlans | STRING | 否 | 否 | 筛选方案json字符串，高级筛选条件 |

### 范围参数说明

以上 `OBJECT` 类型的范围查询参数，通过 JSON 对象传递 `min`（最小值）和 `max`（最大值）：

```json
{
  "amount": {"min": 10, "max": 100},
  "preOrderCount": {"min": 1, "max": 50},
  "availableAmount": {"min": 5, "max": 200},
  "costPrice": {"min": 10.5, "max": 99.9},
  "costAmount": {"min": 100, "max": 10000}
}
```
**响应数据**
- 返回类型：`OBJECT`

| 字段 | 类型     | 说明 |
|------|--------|------|
| costAmount | NUMBER | 总成本金额 |
| totalAmount | NUMBER | 总库存量 |
| availableAmount | NUMBER | 总库存可用数 |
| preOrderAmount | NUMBER | 总预购数 |
| salesBannedAmount | NUMBER | 不可售数（按基础单位） |
| onOrderAmount | NUMBER | 在途量（按基础单位） |
