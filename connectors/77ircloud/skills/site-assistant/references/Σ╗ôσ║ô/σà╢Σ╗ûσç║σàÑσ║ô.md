# 其他出入库

其他入库单和其他出库单的列表与详情查询。其他出入库用于记录非订单/非采购业务产生的出入库（如盘盈入库、报损出库、差异单产生的出入库等），支持按单号/制单人/往来单位搜索，按单据状态、仓库、单据类型、商品、创建/修改/审核时间等多维度筛选。


## 接口目录
- [findOtherStorageTypes](#findotherstoragetypes) - 其他出入库原因列表
- [searchOtherInStorageBills](#searchotherinstoragebills) - 其他入库单列表
- [otherInStorageBillDetail](#otherinstoragebilldetail) - 其他入库单详情
- [searchOtherOutStorageBills](#searchotheroutstoragebills) - 其他出库单列表
- [otherOutStorageBillDetail](#otheroutstoragebilldetail) - 其他出库单详情

---

## findOtherStorageTypes

**功能**：查询其他出入库单据的自定义类型列表。

**典型场景**
- 新增其他入库单前获取入库类型（ioType=1）
- 新增其他出库单前获取出库类型（ioType=2）
- 查看机构当前配置的全部出入库原因及启用状态

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| ioType | NUMBER | 否 | 否 | 类别，1=入库类型，2=出库类型 |
| status | NUMBER | 否 | 否 | 状态，1=启用，2=禁用 |

**响应数据**
- 返回类型：`PAGE`（分页）

| 字段 | 类型 | 说明                |
|------|------|-------------------|
| id | NUMBER | id                 |
| name | STRING | 名称 |
| code | STRING | 类型编码              |
| ioType | NUMBER | 类别（1=入库 2=出库）     |
| status | NUMBER | 状态（1=启用 2=禁用）     |

## searchOtherInStorageBills

**功能**：分页查询其他入库单列表。

**典型场景**
- 按单号/制单人/往来单位名称搜索其他入库单
- 按单据状态（待审核/已审核）筛选
- 查看某段时间内创建/审核的其他入库单
- 按仓库、单据类型、商品筛选其他入库单

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| q | STRING | 否 | 否 | 搜索关键字（单号/制单人/往来单位名称） |
| status | NUMBER | 否 | 否 | 单据状态，-1=作废，0=待审核，1=已审核 |
| createTime | TIME_RANGE | 否 | 否 | 创建时间范围 |
| modifyTime | TIME_RANGE | 否 | 否 | 修改时间范围 |
| approveTime | TIME_RANGE | 否 | 否 | 审核时间范围 |
| typeIds | NUMBER | 否 | 是 | 出入库单据类型ID集合（其他出入库自定义类型） |
| warehouseIds | NUMBER | 否 | 是 | 仓库ID列表 |
| skuIds | NUMBER | 否 | 是 | 商品ID集合，返回明细中包含任一商品的单据 |
| orderNums | STRING | 否 | 是 | 来源业务单号列表（如差异单号） |
| relatedIdQuery | NUMBER | 否 | 否 | 往来单位ID（客户/供应商） |
| showOrgInfo | BOOLEAN | 否 | 否 | 是否显示单据所属机构信息 |

**响应数据**
- 返回类型：`PAGE`（分页）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | NUMBER | 其他入库单ID |
| billNum | STRING | 单据号 |
| typeId | NUMBER | 单据类型ID |
| typeName | STRING | 单据类型名称（其他出入库自定义类型） |
| warehouseId | NUMBER | 仓库ID |
| warehouseName | STRING | 仓库名称 |
| status | NUMBER | 单据状态（-1=作废 0=待审核 1=已审核） |
| creatorId | NUMBER | 制单人ID |
| creator | STRING | 制单人名称 |
| approverId | NUMBER | 审核人ID |
| approverName | STRING | 审核人姓名 |
| approveTime | DATETIME | 审核时间 |
| createTime | DATETIME | 创建时间 |
| modifyTime | DATETIME | 修改时间 |
| totalCount | NUMBER | 总数量 |
| totalMoney | NUMBER | 总金额（成本金额合计） |
| baseWholesalePriceTotal | NUMBER | 下单单位基准订货价合计 |
| orderNum | STRING | 来源业务单号（差异报损出库时关联差异单） |
| relatedType | NUMBER | 往来单位类型（3=客户 7=供应商 8=商家） |
| relatedId | NUMBER | 往来单位ID |
| relatedName | STRING | 往来单位名称 |
| discardReason | STRING | 作废原因 |
| orgId | NUMBER | 单据所属机构ID（showOrgInfo=true 时返回） |
| orgCode | STRING | 单据所属机构CODE（showOrgInfo=true 时返回） |
| orgName | STRING | 单据所属机构名称（showOrgInfo=true 时返回） |

## otherInStorageBillDetail

**功能**：根据ID查询其他入库单详情，包含单据基础信息、商品明细（含批次信息）与单据备注列表。

**典型场景**
- 查看某张其他入库单的完整信息（单据头+商品明细）
- 查看明细的成本价/成本金额、批次号、生产日期
- 修改/审核/作废前先确认单据内容

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| id | NUMBER | 是 | 否 | 其他入库单ID |
| fillStorageLocation | BOOLEAN | 否 | 否 | 是否填充库存位置 |
| detailSortRule | NUMBER | 否 | 否 | 明细排序规则，0=按下单排序，2=按库位排序 |

**响应数据**
- 返回类型：`OBJECT`

单据头字段与 [searchOtherInStorageBills](#searchotherinstoragebills) 响应一致，另包含：

| 字段 | 类型 | 说明 |
|------|------|------|
| contents | ARRAY | 商品明细列表 |
| contents[].id | NUMBER | 明细ID |
| contents[].skuId | NUMBER | SKU ID |
| contents[].spuId | NUMBER | SPU ID |
| contents[].code | STRING | SKU编码 |
| contents[].shortCode | STRING | SKU简称 |
| contents[].name | STRING | SKU名称 |
| contents[].count | NUMBER | 单据执行单位数量 |
| contents[].baseCount | NUMBER | 基础单位数量 |
| contents[].unitId | NUMBER | 单据执行单位ID |
| contents[].unitName | STRING | 单据执行单位名 |
| contents[].baseUnitId | NUMBER | 基础单位ID |
| contents[].baseUnitName | STRING | 基础单位名 |
| contents[].unitRate | NUMBER | 多单位换算比例 |
| contents[].spec | STRING | 规格描述 |
| contents[].barCode | STRING | SKU主条码 |
| contents[].unitBarcode | STRING | 单据执行单位对应条码 |
| contents[].imgUrl | STRING | 商品主图 |
| contents[].remark | STRING | 备注 |
| contents[].costPrice | NUMBER | 成本价（按实际下单单位） |
| contents[].costMoney | NUMBER | 成本金额（costPrice*count） |
| contents[].baseWholesalePrice | NUMBER | 下单单位基准订货价 |
| contents[].baseWholesalePriceTotal | NUMBER | 下单单位基准订货价小计 |
| contents[].batchContents | ARRAY | 批次号信息（启用批次管理时返回） |
| contents[].batchContents[].id | NUMBER | 批次明细ID |
| contents[].batchContents[].batchNum | STRING | 批次号 |
| contents[].batchContents[].productionDate | DATE | 生产日期 |
| contents[].batchContents[].expirationDate | DATE | 过期日期 |
| contents[].batchContents[].count | NUMBER | 批次库存数量 |
| billRemarks | ARRAY | 单据备注列表 |
| billRemarks[].id | NUMBER | 备注ID |
| billRemarks[].content | STRING | 备注内容 |
| billRemarks[].creator | STRING | 创建人名称 |
| billRemarks[].createTime | DATETIME | 创建时间 |

## searchOtherOutStorageBills

**功能**：分页查询其他出库单列表。参数与 [searchOtherInStorageBills](#searchotherinstoragebills) 完全一致。

**典型场景**
- 按单号/制单人/往来单位名称搜索其他出库单
- 按单据状态（待审核/已审核）筛选
- 按来源业务单号（如差异单号）追溯差异报损出库单
- 按仓库、单据类型、商品筛选其他出库单

**参数**

参数与 [searchOtherInStorageBills](#searchotherinstoragebills) 一致（q、status、createTime、modifyTime、approveTime、typeIds、warehouseIds、skuIds、orderNums、relatedIdQuery、showOrgInfo）。

**响应数据**
- 返回类型：`PAGE`（分页）

字段与 [searchOtherInStorageBills](#searchotherinstoragebills) 响应一致，仅 `id` 为其他出库单ID。

## 跨接口组合示例

**场景1**：查某仓库本月待审核的其他出库单并逐张审核
1. `findWarehouses` → 获取仓库ID（见 仓库/仓库.md）
2. `searchOtherOutStorageBills` → 传入 warehouseIds + status=0 + createTime 本月范围
3. `otherOutStorageBillDetail` → 逐张确认明细
4. `approveOtherOutStorageBill` → 审核确认无误的单据（见 其他出库-管理.md）

**场景2**：按差异单号追溯差异报损出库单
1. `searchDifferenceOrders` → 查询差异单获取差异单号（见 仓库/差异单.md）
2. `searchOtherOutStorageBills` → 传入 orderNums=[差异单号]
3. `otherOutStorageBillDetail` → 查看出库明细
