# 出入库明细（库存流水）

本文档覆盖库存出入库流水查询接口，用于查看商品的每一次出/入库明细记录，包含数量、成本、结余及关联单据信息；批次出入库明细按批次维度查询流水，额外包含批次号、生产日期、过期日期及批次结余信息。

## 接口目录
- [findStorageRecords](#findstoragerecords) - 出入库明细（库存流水）
- [findSkuBatchesRecords](#findskubatchesrecords) - 批次出入库明细（批次库存流水）

---

## findStorageRecords

**功能**：查询商品出入库流水明细，记录每一次出库/入库的数量、成本、结余及关联业务单据。支持按时间范围、仓库、商品、出入库类型、单号等多维度筛选。

**典型场景**
- 查询某商品在指定仓库的出入库流水
- 按出入库类型（入库/出库）筛选流水记录
- 按单号（订单号/出入库单号）追踪某笔业务对应的流水
- 核对某商品的结余数量、成本单价、成本金额变动
- 出入库盘点与成本核算

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明                              |
|------|------|----|------|---------------------------------|
| rangeTime | TIME_RANGE | 是  | 否 | 出入库时间范围                         |
| q | STRING | 否  | 否 | 搜索关键字（单号/商品名称/编码/条码/商品简称）       |
| orderNumOrBillNum | STRING | 否  | 否 | 单号（同时匹配出入库单号和订单号）               |
| queryWarehouseIds | NUMBER | 否  | 是 | 仓库查询ID集合                |
| skuIds | NUMBER | 否  | 是 | 商品skuId集合                       |
| storageType | NUMBER | 否  | 否 | 出入库类型（1=入库 2=出库），见「出入库类型」      |
| billTypes | NUMBER | 否  | 是 | 出入库单据类型，见「出入库单据类型」             |
| stockCountRange | NUMBER_RANGE | 否  | 否 | 库存单位数量 |
| surplusCountRange | NUMBER_RANGE | 否  | 否 | 结余库存数量 |
| surplusCostPriceRange | NUMBER_RANGE | 否  | 否 | 结余库存成本价 |
| relatedId | NUMBER | 否  | 否 |  往来单位ID                        |
| querySurplusCountFromWarehouse | BOOLEAN | 否  | 否 | 是否按分仓结余查询（true:按分仓结余 false:按总仓结余） |
| fillBillRemark | BOOLEAN | 否  | 否 | 是否填充单据备注，默认false                |
| showIOStorageReason | BOOLEAN | 否  | 否 | 是否返回出入库原因，默认false，仅其他出入库单据类型有值  |

| surplusCostPrice | NUMBER | 结余成本单价                                        |
| surplusCostMoney | NUMBER | 结余成本金额                                        |
| billNum | STRING | 出入库单据编号                                       |

## findSkuBatchesRecords

**功能**：查询批次商品的批次维度的出入库流水明细，每条记录对应某商品某批次的一次出/入库，包含批次号、生产日期、过期日期及批次结余信息。支持按时间范围、仓库、商品、出入库类型、单号、批次号、生产日期范围等多维度筛选。

**典型场景**
- 查询某批次商品的出入库流水（先进先出/批次追踪）
- 按生产日期范围筛选批次流水，核对临期/过期批次
- 查看某商品各批次的剩余数量与成本结余
- 按批次核对出入库与批次结余盘点

## 跨接口组合示例

**场景1**：查询某商品在指定仓库的出入库流水
1. `findWarehouses` → 获取仓库ID
2. `findStorageRecords` → 传 `skuId` + `warehouseId` + `rangeTime`，获取该商品的流水明细

**场景2**：按出入库类型筛选入库流水并核对结余
1. `findStorageRecords` → 传 `storageType=1`（入库）+ `rangeTime`，获取入库流水列表，查看 `surplusCount`/`surplusCostPrice` 结余变化

**场景3**：按单号追踪某笔订单对应的出入库流水
1. `findStorageRecords` → 传 `orderNumOrBillNum`（订单号或出入库单号），获取该单据触发的流水明细

**场景4**：按批次追踪某商品的出入库与批次结余
1. `findSkuBatchesRecords` → 传 `skuIds` + `batchNum`，获取该商品指定批次的流水明细，查看 `surplusCount` 批次结余与 `expirationDate` 效期

**场景5**：筛选指定生产日期范围内的临期批次流水
1. `findSkuBatchesRecords` → 传 `productionDateRangeTime`（生产日期范围）+ `skuIds`，获取该生产日期区间的批次流水，核对 `expirationDate` 临期情况
