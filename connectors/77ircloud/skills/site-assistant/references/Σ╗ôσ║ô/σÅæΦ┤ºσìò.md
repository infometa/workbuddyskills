# 查询发货单列表

## 接口目录
- [findDispatchBills](#findDispatchBills) - 查询发货单列表

---

## findDispatchBills

## 功能说明

查询发货单列表，支持多种查询条件：
- 按订单号查询（批量）
- 按发货单号查询
- 按出库单 ID 查询
- 按状态筛选（待发货/已发货/作废）
- 按签收状态筛选

返回发货单的完整信息，包括物流信息（快递/自有物流）、签收状态、差异单信息、客户签名等。

## 参数

### Query 参数

| 参数                    | 类型         | 必填 | 数组 | 说明                                 |
|-----------------------|------------|----|----|------------------------------------|
| orderNums             | STRING     | 否  | 是  | 订单号列表（批量查询）                        |
| dispatchIds           | NUMBER     | 否  | 是  | 发货单主键 ID 列表                        |
| dispatchBillNums      | STRING     | 否  | 是  | 发货单号列表                             |
| outStorageBillIds     | NUMBER     | 否  | 是  | 出库单 ID 列表                          |
| status                | NUMBER     | 否  | 否  | 发货单状态：-1=作废，0=待发货，1=已发货            |
| receivingStatus       | NUMBER     | 否  | 否  | 签收状态：-1=作废，0=待签收，1=已签收             |
| withCustomerSignature | BOOLEAN    | 否  | 否  | 是否填充客户签名信息，默认 false                |
| fillDriverExtInfo     | BOOLEAN    | 否  | 否  | 是否填充司机拓展信息，默认 false                |
