# 销售出库单

本文档覆盖销售出库单查询接口，用于查看由订单（分公司、门店、客户订单）产生的出库单。

## 接口目录
- [searchOutStorageBills](#searchoutstoragebills) - 销售出库单列表

---

## searchOutStorageBills

**功能**：分页查询由订单产生的销售出库单列表，支持按单号/往来名称模糊搜索、出库时间范围筛选、出库单号精确匹配。

**典型场景**
- 按出库单号精确查找出库单
- 查看某段时间内的出库单列表及出库进度
- 按往来名称关键词搜索出库单

**参数**

| 参数           | 类型         | 必填 | 数组 | 说明                      |
|--------------|------------|----|----|-------------------------|
| q            | STRING     | 否  | 否  | 搜索关键字，按单号/往来名称模糊匹配      |
| createTime   | TIME_RANGE | 是  | 否  | 出库时间范围                  |
| billNums     | STRING     | 否  | 是  | 出库单号列表，精确匹配多个出库单号       |
| orgIds       | NUMBER     | 否  | 是  | 往来组织ID集合（客户/门店/分公司ID列表） |
| warehouseIds | NUMBER     | 否  | 是  | 仓库ID列表                  |

**响应数据**
- 返回类型：`PAGE`（分页）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | NUMBER | 出库单ID |
| billNum | STRING | 出库单号 |
| createTime | DATETIME | 出库时间 |
| orderCreateTime | DATETIME | 订单创建时间 |
| warehouseName | STRING | 出库仓库名称 |
| warehouseId | NUMBER | 出库仓库ID |
| billType | NUMBER | 单据类型 |
| subBillType | NUMBER | 单据类型子类型（101=代发门店订货出库，102=代发分公司订货出库） |
| yjdfChainId | NUMBER | 一键代发chainId（仅一键代发场景有值） |
| billTypeName | STRING | 出库类型名称 |
| targetName | STRING | 往来名称（出库对象名称） |
| targetType | NUMBER | 往来机构类型（1=分公司，2=门店，3=客户，4=总部，5=会员，6=游客，7=供应商） |
| targetId | NUMBER | 往来机构ID |
| status | NUMBER | 单据状态（-1=作废，0=待审核，1=已审核） |
| orderMoney | NUMBER | 单据金额 |
| creator | STRING | 制单人 |
| orderNum | STRING | 关联单号（关联的订单号） |
| printNumber | NUMBER | 打印次数 |
| orderCount | NUMBER | 下单数量-合计 |
| orderTotalNums | NUMBER | 下单笔数-合计 |
| targetBindSortingName | STRING | 往来单位关联的分拣线路名称 |
| approveTime | DATETIME | 出库确认时间 |
