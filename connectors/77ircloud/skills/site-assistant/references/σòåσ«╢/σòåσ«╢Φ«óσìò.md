# 商家订单

本文档覆盖商家订单列表页相关接口：司机查询、分拣车辆查询、商家订单列表查询。

## 接口目录
- [employeeList](#employeelist) - 员工/司机列表查询
- [searchSortingCars](#searchsortingcars) - 分拣配送车辆列表查询
- [merchantOrderList](#merchantorderlist) - 商家订单列表查询

---

## employeeList

**功能**：查询员工列表，商家订单页常用 `types=[2]` 筛选司机，用于按司机维度筛选或关联车辆。

**典型场景**
- 获取启用状态的司机列表
- 按司机 ID 筛选商家订单或关联车辆

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| status | NUMBER | 否 | 否 | 状态，1=启用，0=禁用 |
| types | NUMBER | 否 | 是 | 员工分类，1=业务员，2=司机，3=采购员，4=财务，5=分拣员，6=经营管理者 |
| q | STRING | 否 | 否 | 名称/手机号/工号/账号 |
| departmentId | NUMBER | 否 | 否 | 部门ID |
| regionIds | NUMBER | 否 | 是 | 区域ID列表 |

**响应数据**
- 返回类型：`PAGE`（分页）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | NUMBER | 员工ID |
| name | STRING | 员工名称 |
| userName | STRING | 登录账号 |
| assoOrgName | STRING | 所属组织名称 |
| employeeNumber | STRING | 工号 |
| departmentName | STRING | 部门名称 |
| departmentId | STRING | 部门ID |
| position | STRING | 职位 |
| mobile | STRING | 手机号 |
| email | STRING | 邮箱 |
| status | NUMBER | 状态（1=启用，0=禁用） |
| system | BOOLEAN | 是否系统账号 |
| hierarchyCode | STRING | 机构层级（HEADQUARTERS=总部等） |
| tenantId | NUMBER | 租户ID |
| orgId | NUMBER | 所属机构ID |
| type | NUMBER | 员工类型 |
| typeNames | ARRAY | 员工类型名称列表（如「业务员」「司机」） |
| roleIds | ARRAY | 角色ID列表 |
| roleNames | ARRAY | 角色名称列表 |
| regions | ARRAY | 负责区域列表 |
| regions[].id | NUMBER | 区域ID |
| regions[].name | STRING | 区域名称 |
| createTime | DATETIME | 创建时间 |
| modifyTime | DATETIME | 修改时间 |

## searchSortingCars

**功能**：查询分拣配送车辆列表，商家订单页用于按车辆/车销仓库筛选订单。

**典型场景**
- 获取启用状态的车辆列表
- 按司机 ID 查询其负责车辆
- 获取车销仓库 ID（`warehouseId`，`openWarehouse=1` 时有效）

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| status | NUMBER | 否 | 否 | 车辆状态，1=启用 |
| keyword | STRING | 否 | 否 | 搜索关键词（模糊匹配车辆名称/编码） |
| driverId | NUMBER | 否 | 否 | 司机ID |
| openWarehouse | NUMBER | 否 | 否 | 是否开启车销仓库（1=开启，0=未开启） |

**响应数据**
- 返回类型：`PAGE`（分页）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | NUMBER | 车辆ID |
| name | STRING | 车辆名称 |
| code | STRING | 车辆编码 |
| status | NUMBER | 车辆状态（1=启用） |
| openWarehouse | NUMBER | 是否开启车销仓库（1=开启，0=未开启） |
| remarks | STRING | 车辆备注 |
| driverId | NUMBER | 司机ID |
| driverName | STRING | 司机名称 |
| routeId | NUMBER | 线路ID |
| routeName | STRING | 线路名称 |
| warehouseId | NUMBER | 车销仓库ID |
| warehouseName | STRING | 车销仓库名称 |
| loadWeight | STRING | 载重量 |
| createTime | DATETIME | 创建时间 |
| modifyTime | DATETIME | 修改时间 |

## merchantOrderList

**功能**：查询商家订单列表，返回买方、商家、金额、审核/签收/付款状态及关联客户订单号等信息。

**典型场景**
- 查询某时间段内的商家订单列表
- 按商家筛选订单（如某平台商家的全部订单）
- 查看待付款/已付款/已作废的商家订单
- 查看商家订单与客户订单的关联关系（`yjdfRelatedCode`）
- 查看供应商审核状态及签收进度
- 获取带系统备注的作废订单记录（传 `withRemarks=true`）

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| rangeTime | TIME_RANGE | 是 | 否 | 下单时间范围，映射为 `createTimeBegin` / `createTimeEnd` |
| orderKeyWord | STRING | 否 | 否 | 订单关键字（单号/制单人/买家） |
| orderCodes | STRING | 否 | 是 | 商家订单号列表 |
| sellerIds | NUMBER | 否 | 是 | 商家ID列表 |
| buyerIds | NUMBER | 否 | 是 | 买方ID列表 |
| orderStatus | STRING | 否 | 是 | 单据状态：AUDITED=已审核，FINISHED=已完成，CANCELLED=已作废 |
| signStatus | STRING | 否 | 是 | 签收状态：NONE=待签收，PART=部分签收，FULL=已签收 |
| paymentStatus | STRING | 否 | 是 | 付款状态：UN_PAID=未付款，PAID=已付款 |
| orderSource | STRING | 否 | 是 | 订单来源：WEB=网页，APP=APP |
| supplierAuditStatus | STRING | 否 | 是 | 供应商审核状态：NONE=无需审核，CONFIRMED=已确认 |
| dxMode | STRING | 否 | 是 | 代发模式：DELIVER_BY_MERCHANT=商家发货，DELIVER_BY_CURRENT_ORG=当前机构发货 |
| yjdfType | STRING | 否 | 否 | 代发类型，ZF=直发 |
| warehouseIds | NUMBER | 否 | 是 | 发货仓库ID列表 |
| creatorIds | NUMBER | 否 | 是 | 制单人ID列表 |
| isClose | BOOLEAN | 否 | 否 | 是否关闭 |
| withRemarks | BOOLEAN | 否 | 否 | 是否附带备注列表，为 true 时返回 `orderRemarks` |

## 接口选择指引

| 用户意图 | 推荐接口 |
|----------|----------|
| "司机列表" / "查司机" | employeeList（types=[2]，status=1） |
| "车辆列表" / "分拣车辆" | searchSortingCars（status=1） |
| "商家订单列表" / "平台商家订单" | merchantOrderList |
| "某商家的订单" | merchantOrderList（传 sellerIds） |
| "商家订单付款状态" | merchantOrderList（查看 paymentStatus） |
| "商家订单关联的客户订单" | merchantOrderList（查看 yjdfRelatedCode） |
| "作废商家订单的备注" | merchantOrderList（withRemarks=true，orderStatus=CANCELLED） |

## 跨接口组合示例

**场景**：查看某司机负责车辆相关的商家订单
1. `employeeList` → `types=[2]`、`status=1` 获取司机 ID
2. `searchSortingCars` → 传 `driverId` 获取车辆及 `warehouseId`
3. `merchantOrderList` → 传 `warehouseIds` + 时间范围查询商家订单

**场景**：查看本月某商家的未付款订单及关联客户订单
1. `merchantOrderList` → 传 `sellerIds` + `paymentStatus=["UN_PAID"]` + 时间范围
2. 从 `yjdfRelatedCode` 获取关联客户订单号，必要时用 `customerOrderList` 进一步查询
