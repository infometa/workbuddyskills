# 商家退单

本文档覆盖平台商家退单查询接口，用于查看由客户退单自动生成的商家退单列表，支持按时间、商家、退款状态等维度筛选。

## 接口目录
- [merchantReturnOrderList](#merchantreturnorderlist) - 商家退单列表查询

---

## merchantReturnOrderList

**功能**：查询商家退单列表，返回买方、商家、退单金额、退款状态及关联的客户退单/商家订单/原客户订单等信息。多数商家退单由客户退单（CR 单号）自动生成。

**典型场景**
- 查询某时间段内的商家退单列表
- 按商家筛选退单记录
- 查看待退款/部分退款/已退款的商家退单
- 追溯商家退单与客户退单、商家订单、原客户订单的关联关系
- 获取退单自动生成备注（传 `withRemarks=true`）

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| rangeTime | TIME_RANGE | 是 | 否 | 退单创建时间范围，映射为 `createTimeBegin` / `createTimeEnd` |
| keyWord | STRING | 否 | 否 | 搜索关键字（单号/商家/商品编码/名称/条形码/制单人） |
| sellerIds | NUMBER | 否 | 是 | 商家ID列表 |
| orderStatus | STRING | 否 | 是 | 退单状态，见下方枚举 |
| paymentStatuses | STRING | 否 | 是 | 退款状态，见下方枚举 |
| receiveStatus | STRING | 否 | 是 | 收货状态（NONE/PART/FULL） |
| lowerReturnOrderCode | STRING | 否 | 否 | 关联客户退单号（CR 开头） |
| withRemarks | BOOLEAN | 否 | 否 | 是否附带备注列表 |
| withDetails | BOOLEAN | 否 | 否 | 是否附带商品明细 |
| withAttachments | BOOLEAN | 否 | 否 | 是否附带附件列表 |

**枚举说明**（与 ydp-web `order-aggregation` swagger 一致）

退单状态 `orderStatus`：

| 值 | 说明 |
|----|------|
| SUBMIT_PENDING | 待提交 |
| ORDER_AUDIT_PENDING | 待订单审核 |
| RECEIPT_AUDIT_PENDING | 待收货审核 |
| AUDITED | 已审核 |
| FINISHED | 已完成 |
| CANCELLED | 已作废 |
| INITIALIZED | 已初始化 |

退款状态 `paymentStatuses` / `paymentStatus`：

| 值 | 说明 |
|----|------|
| WAIT_PAY | 待退款 |
| PART_PAID | 部分退款 |
| PAID_CHECKING | 退款核对中 |
| PAID | 已退款 |

收货状态 `receiveStatus`：

| 值 | 说明 |
|----|------|
| NONE | 未收货 |
| PART | 部分收货 |
| FULL | 已收货 |

退货/收货状态 `deliveryStatus`（买方视角为退货，卖方视角为收货）：

| 值 | 说明 |
|----|------|
| UNRETURN | 未退货 |
| RETURNED | 已退货 |
| UNRECEIVE | 未收货 |
| WAIT_RECEIVE | 待收货 |
| RECEIVED | 已收货 |

退单来源 `orderSource`：APP、POS、WEB、WECHAT、YDH_MIG

退单类型 `orderType`：MERCHANT=商家退单，NORMAL=普通退单，PURCHASE=采购退单 等

**响应数据**
- 返回类型：`PAGE`（分页）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | NUMBER | 商家退单ID |
| orderCode | STRING | 商家退单号（如 MR000000-260622-00003） |
| orderType | STRING | 退单类型（MERCHANT=商家退单） |
| buyer | OBJECT | 买方机构信息 |
| seller | OBJECT | 商家信息 |
| orderStatus | STRING | 退单状态 |
| receiveStatus | STRING | 收货状态 |
| deliveryStatus | STRING | 退货/收货状态 |
| orderSource | STRING | 退单来源 |
| createId | NUMBER | 制单人ID |
| createName | STRING | 制单人 |
| productTotalAmount | NUMBER | 商品小计总额 |
| otherAmount | NUMBER | 其它费用 |
| orderTotalAmount | NUMBER | 退单金额 |
| orderRemarks | ARRAY | 退单备注列表（withRemarks=true 时有值） |
| paymentStatus | STRING | 退款状态 |
| receivableAmount | NUMBER | 应收应付金额 |
| relatedCode | STRING | 关联商家订单号（MA 开头） |
| lowerReturnOrderCode | STRING | 关联客户退单号（CR 开头） |
| lowerReturnStorageBillNum | STRING | 关联客户退货入库单号（CI 开头） |
| originalOrderCode | STRING | 关联原客户订单号（CA 开头） |
| sourceBuyerName | STRING | 原订单买方名称 |
| sourceCreatorName | STRING | 原订单制单人 |

## 接口选择指引

| 用户意图 | 推荐接口 |
|----------|----------|
| "商家退单列表" / "平台商家退单" | merchantReturnOrderList |
| "某商家的退单" | merchantReturnOrderList（传 sellerIds） |
| "商家退单退款状态" | merchantReturnOrderList（传 paymentStatuses 或查看 paymentStatus） |
| "商家退单关联的客户退单" | merchantReturnOrderList（查看 lowerReturnOrderCode） |
| "商家退单关联的商家订单" | merchantReturnOrderList（查看 relatedCode） |
| "商家退单关联的原订单" | merchantReturnOrderList（查看 originalOrderCode） |

## 跨接口组合示例

**场景**：根据客户退单追溯完整链路
1. `merchantReturnOrderList` → 从 `lowerReturnOrderCode` 找到客户退单号
2. 从 `relatedCode` 找到关联商家订单，用 `merchantOrderList` 查询商家订单详情
3. 从 `originalOrderCode` 找到原客户订单，必要时用 `customerOrderList` 进一步查询
