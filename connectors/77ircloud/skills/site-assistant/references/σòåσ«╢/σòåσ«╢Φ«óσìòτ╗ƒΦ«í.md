# 商家订单统计

本文档覆盖商家订单统计页（`/merchant/order/statistics`）相关接口：按商品明细维度查询商家订单/退单统计列表，以及汇总单据笔数、数量、金额。

## 接口目录
- [merchantOrderStatisticsList](#merchantorderstatisticslist) - 商家订单统计明细列表
- [merchantOrderStatisticsSummary](#merchantorderstatisticssummary) - 商家订单统计汇总

---

## merchantOrderStatisticsList

**功能**：按商品明细维度分页查询商家订单与商家退单统计数据，支持按时间、商家、商品、单据状态、发货状态、收付款状态等筛选。列表同时包含 MA（商家订单）与 MR（商家退单）明细行，退单数量/金额为负值。

**典型场景**
- 查看某时间段商家订单商品明细统计
- 按商家筛选订单/退单明细
- 按商品分类、品牌筛选
- 区分商家订单与商家退单（`orderType` 或响应 `billType`）
- 追溯关联客户订单号（`originalOrderCode`）与客户退单号（`relatedMemberCode` 为 CR 开头时）

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| rangeTime | TIME_RANGE | 是 | 否 | 下单时间范围，映射为 `createTimeBegin` / `createTimeEnd`（毫秒时间戳字符串） |
| keyWord | STRING | 否 | 否 | 商品信息，名称/编码/简称/条形码 |
| merchantInfo | STRING | 否 | 否 | 商家信息，名称/编码/联系人/电话 |
| orderCode | STRING | 否 | 否 | 单号模糊匹配（商家订单 MA / 商家退单 MR） |
| deliveryInfo | STRING | 否 | 否 | 收货人/收货电话 |
| orderType | STRING | 否 | 否 | 订单/退单：`1`=商家订单，`2`=商家退单，全部不传 |
| categoryIds | NUMBER | 否 | 是 | 商品分类 ID 列表 |
| brandIds | NUMBER | 否 | 是 | 商品品牌 ID 列表 |
| orderStatus | NUMBER | 否 | 是 | 单据状态，见下方枚举（全选时可不传） |
| deliveryStatus | NUMBER | 否 | 是 | 发货状态，见下方枚举 |
| paymentStatus | NUMBER | 否 | 是 | 收付款状态，见下方枚举 |
| productRange | NUMBER | 否 | 否 | 商品统计范围，0=全部商品（默认），1=仅公有 |
| currentPage | NUMBER | 否 | 否 | 当前页码 |
| pageSize | NUMBER | 否 | 否 | 每页数量 |

**枚举说明**（报表接口使用数字魔法值，与 `order-aggregation` 字符串枚举不同）

单据状态 `orderStatus`：

| 值 | 说明 |
|----|------|
| 1 | 待订单/退单审核 |
| 2 | 待财务审核 |
| 3 | 待收货审核 |
| 4 | 已审核 |
| 5 | 已完成 |
| 6 | 已作废 |

发货状态 `deliveryStatus`：1=未发货，2=部分发货，3=已发货

收付款状态 `paymentStatus`：1=未收款/未付款，2=部分收款/部分付款，4=已收款/已付款

订单/退单 `orderType`：`1`=商家订单，`2`=商家退单

响应 `billType`：1=商家单，2=商家退单

**响应数据**
- 返回类型：`PAGE`（分页）

| 字段 | 类型 | 说明 |
|------|------|------|
| detailId | NUMBER | 商家订单明细 ID |
| billType | NUMBER | 单据类型，1=商家单，2=商家退单 |
| orderCode | STRING | 单号（MA/MR 开头） |
| orderStatusName | STRING | 单据状态名称 |
| createTime | DATETIME | 下单时间 |
| sellerId | STRING | 商家 ID |
| sellerName | STRING | 商家名称 |
| companyName | STRING | 客户名称 |
| productName | STRING | 商品名称 |
| productCode | STRING | 商品编码 |
| barCode | STRING | 商品条码 |
| spec | STRING | 规格 |
| categoryName | STRING | 商品分类 |
| brandName | STRING | 商品品牌 |
| unitName | STRING | 单位 |
| productCount | NUMBER | 数量（退单为负） |
| price | NUMBER | 单价 |
| money | NUMBER | 金额（退单为负） |
| orderMoney | NUMBER | 整单金额 |
| type | STRING | 商品类型（NORMAL/MANUAL_GIFT/PROMOTION_GIFT） |
| typeBooleanName | STRING | 是否赠品 |
| signNumbers | NUMBER | 已签收数量 |
| pendingSignNumbers | NUMBER | 待签收数量 |
| contactName | STRING | 收货人 |
| contactPhone | STRING | 收货电话 |
| deliveryAddress | STRING | 收货地址 |
| relatedMemberCode | STRING | 关联单号（CA 客户订单 / CR 客户退单） |
| originalOrderCode | STRING | 关联原客户订单号（CA 开头） |
| originalBuyerName | STRING | 往来单位名称 |
| originalBuyerCode | STRING | 往来单位编码 |
| originalAvgPrice | NUMBER | 原单均价 |

## merchantOrderStatisticsSummary

**功能**：在与列表相同的筛选条件下，汇总单据笔数、数量合计、金额合计。页面顶部「合计」区域使用此接口。

**典型场景**
- 获取当前筛选条件下的单据笔数、数量、金额汇总
- 与 `merchantOrderStatisticsList` 配合：列表看明细，汇总看合计

**参数**

与 `merchantOrderStatisticsList` 筛选参数相同（无需 `currentPage` / `pageSize`）。

**响应数据**
- 返回类型：`OBJECT`

| 字段 | 类型 | 说明 |
|------|------|------|
| billNums | NUMBER | 单据笔数 |
| totalNums | NUMBER | 数量合计（含退单负数量） |
| totalAmount | NUMBER | 金额合计（含退单负金额） |

## 接口选择指引

| 用户意图 | 推荐接口 |
|----------|----------|
| "商家订单统计" / "商家订单报表" | merchantOrderStatisticsList + merchantOrderStatisticsSummary |
| "商家订单统计合计" / "笔数金额汇总" | merchantOrderStatisticsSummary |
| "某商家订单商品明细" | merchantOrderStatisticsList（传 merchantInfo 或结合商家筛选） |
| "商家退单统计" | merchantOrderStatisticsList（orderType=2 或 billType=2） |
| "商家订单 MA 单" | merchantOrderStatisticsList（orderType=1） |

## 跨接口组合示例

**场景**：统计页查明细后跳转订单详情
1. `merchantOrderStatisticsList` → 从 `orderCode` 获取 MA/MR 单号
2. 商家订单（MA）用 `merchantOrderList`（传 orderCodes）查详情
3. 商家退单（MR）用 `merchantReturnOrderList` 查详情
4. 从 `originalOrderCode` 追溯原客户订单，必要时用 `customerOrderList`

**场景**：页面完整加载
1. `merchantOrderStatisticsSummary` → 获取 billNums / totalNums / totalAmount
2. `merchantOrderStatisticsList` → 分页加载商品明细列表
