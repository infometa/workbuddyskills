# 组织机构基础数据

本文档覆盖组织机构查询接口，用于查看分公司、门店、客户等下属机构列表及基本信息。

## 接口目录
- [getMyOrganizationUnit](#getmyorganizationunit) - 查询当前登录机构自身信息
- [searchDirectUnder](#searchdirectunder) - 查询下属组织机构列表（支持分公司/门店/客户）

> 收货地址相关接口请查阅 [收货地址.md](收货地址.md)

---

## getMyOrganizationUnit

**功能**：查询当前登录账号所属机构的详细信息，无需传参，返回本机构的名称、编码、地址、业务员、仓库等完整信息。

**典型场景**
- 查询当前机构自身的基本信息（名称、编码、地址）
- 获取当前机构的默认仓库ID/名称
- 查询当前机构所属的业务员、区域信息
- 获取当前机构的联系人和收货地址列表
- 确认当前账号归属的机构类型（分公司/门店/客户）

**参数**

无需传参，接口自动读取当前登录 Token 对应的机构信息。

**响应数据**

- 返回类型：`OBJECT`

| 字段 | 类型 | 说明 |
|------|------|------|
| id | NUMBER | 机构ID/组织ID |
| tenantId | NUMBER | 租户ID |
| chainId | NUMBER | 层级id |
| name | STRING | 机构名称 |
| code | STRING | 机构编码 |
| hierarchyCode | STRING | 机构类型（BRANCH:分公司 / STORE:门店 / CUSTOMER:客户） |
| status | NUMBER | 状态（1:启用 0:禁用） |
| parentId | NUMBER | 所属上级机构ID |
| parentName | STRING | 所属上级机构名称 |
| parentHierarchyCode | STRING | 所属机构层级编码 |
| regionId | NUMBER | 所属区域ID |
| regionName | STRING | 所属区域名称 |
| salesId | NUMBER | 业务员ID |
| salesName | STRING | 业务员名称 |
| contactPhone | STRING | 主联系人电话 |
| provinceName | STRING | 省份名称 |
| cityName | STRING | 城市名称 |
| districtName | STRING | 区名称 |
| warehouseId | NUMBER | 默认仓库ID |
| warehouseName | STRING | 默认仓库名称 |
| memo | STRING | 备注 |
| userName | STRING | 账户名称 |
| userStatus | NUMBER | 账户状态 |
| employee | OBJECT | 当前登录员工信息 |

## searchDirectUnder

**功能**：查询当前登录机构的下属组织机构列表，支持按机构类型、关键词、区域、业务员等条件筛选，支持跨层级查询。

**典型场景**
- 创建订单时选择往来单位
- 查询当前账号下所有客户列表
- 查询指定分公司下的门店列表
- 根据机构名称/编码搜索组织
- 获取机构ID用于下游接口（如创建订单时传入 buyerId）

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| hierarchyCodes | STRING | 否 | 是 | 机构类型过滤，枚举值：BRANCH(分公司) / STORE(门店) / CUSTOMER(客户)；不传则按登录账号层级默认返回直属下级 |
| ids | NUMBER | 否 | 是 | 组织id列表，可选，精确查询指定机构，最多100个 |
| q | STRING | 否 | 否 | 关键词搜索（名称/编码），按机构名称、编码、联系人、联系方式字段模糊匹配 |
| status | NUMBER | 否 | 否 | 状态过滤（1:启用 0:禁用） |
| parentId | NUMBER | 否 | 否 | 父级机构id（查询指定上级机构的下属机构） |
| showCrossLevels | BOOLEAN | 否 | 否 | 是否跨层级查询所有下属机构（true则查全路径下游，false则仅查直属下级） |
| includeUppers | BOOLEAN | 否 | 否 | 是否包含当前机构自身（true则包含，false则不包含） |
| regionIds | NUMBER | 否 | 是 | 区域id列表 |
| salesIds | NUMBER | 否 | 是 | 业务员id列表 |
| tagIds | NUMBER | 否 | 是 | 客户标签id列表 |
| codes | STRING | 否 | 是 | 机构编码列表 |
| contactName | STRING | 否 | 否 | 联系人名称 |
| contactPhone | STRING | 否 | 否 | 联系人手机号码 |
| settlementOrgFlag | NUMBER | 否 | 否 | 结算客户查询标识（0:默认查询所有 1:只查询结算客户） |

**响应数据**

- 返回类型：`PAGE`（分页）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | NUMBER | 机构主键ID（用于下游接口如创建订单传 buyerId） |
| name | STRING | 机构名称 |
| code | STRING | 机构编码 |
| hierarchyCode | STRING | 机构类型（BRANCH/STORE/CUSTOMER） |
| status | NUMBER | 状态（1:启用 0:禁用） |
| parentName | STRING | 所属上级机构名称 |
| parentId | NUMBER | 所属上级机构id |
| regionName | STRING | 所属区域名称 |
| contactName | STRING | 联系人 |
| phoneNum | STRING | 联系电话 |
| address | STRING | 详细地址 |
| areaAddress | STRING | 省市区组合地址 |

## 跨接口组合示例

**场景**：为某个客户创建订单
1. `searchDirectUnder` → 传入 `hierarchyCodes: ["CUSTOMER"]`、`includeUppers: false`、`status: 1`、`q: "客户名称"`，按名称搜索获取启用的客户ID
2. `createToBOrder` → 将 客户ID 传入 buyerId

**场景**：查询某分公司下所有门店
- `searchDirectUnder` → 传入 `hierarchyCodes: ["STORE"]`、`parentId` 为分公司ID、`showCrossLevels: false`
