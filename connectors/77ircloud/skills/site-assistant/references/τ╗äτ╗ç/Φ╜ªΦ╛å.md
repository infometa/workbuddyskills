# searchSortingCars - 分页查询分拣配送车辆列表

本文档覆盖分拣配送车辆查询接口，用于查询车辆信息及车销仓库。

## 接口目录
- [searchSortingCars](#searchsortingcars) - 分页查询分拣配送车辆列表（支持按司机/车销仓库筛选）

---

**功能**：分页查询分拣配送车辆列表，支持按关键词、状态、司机、车销仓库等条件过滤。

**典型场景**
- 查询所有可用车辆，用于发货时选择配送车辆
- 按司机 ID 查询其负责的车辆（`driverId`）
- 查询开启了车销仓库的车辆（`openWarehouse=1`），获取车销仓库 ID 用于出库

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| keyword | STRING | 否 | 否 | 搜索关键词（模糊匹配车辆名称/编码） |
| status | NUMBER | 否 | 否 | 车辆状态 |
| driverId | NUMBER | 否 | 否 | 司机ID（过滤指定司机负责的车辆） |
| openWarehouse | NUMBER | 否 | 否 | 是否开启车销仓库（1:开启 0:未开启） |

**响应数据**

- 返回类型：`PAGE`（分页）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | NUMBER | 车辆ID |
| name | STRING | 车辆名称 |
| code | STRING | 车辆编码 |
| status | NUMBER | 车辆状态 |
| openWarehouse | NUMBER | 是否开启车销仓库（1:开启 0:未开启） |
| remarks | STRING | 车辆备注 |
| driverId | NUMBER | 司机ID |
| driverName | STRING | 司机名称 |
| routeId | NUMBER | 线路ID |
| routeName | STRING | 线路名称 |
| warehouseId | NUMBER | 车销仓库ID |
| warehouseName | STRING | 车销仓库名称 |
| loadWeight | STRING | 载重量 |
| createTime | DATETIME | 创建时间 |
| modifyTime | DATETIME | 修改时间 |


**注意**
- `warehouseId` 为车销仓库 ID，可用于出库时指定仓库（仅 `openWarehouse=1` 的车辆有效）
