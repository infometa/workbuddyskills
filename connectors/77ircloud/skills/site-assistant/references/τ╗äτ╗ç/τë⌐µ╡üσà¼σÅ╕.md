# listLogisticsCompanies - 查询物流公司列表

本文档覆盖物流公司查询接口，用于获取物流公司的详细信息。

## 接口目录
- [listLogisticsCompanies](#listlogisticscompanies) - 查询物流公司列表（按ID/名称/编码过滤）

---

**功能**：按条件查询物流公司列表，返回物流公司的 id、名称、编码、官网、电话等信息。支持按 ID、名称、编码列表过滤，不传任何参数则返回全部。

**前置说明：如何获取当前组织可用的物流公司 ID**

当前组织启用的物流公司 ID 集合，需先调用 `getSettings` 接口查询 `logisticsTracking` 设置项获得。
参考：[site-assistant/references/组织/设置.md](./设置.md) 中的 `logisticsTracking` 说明。

`getSettings` 返回示例：
```json
{
  "logisticsTracking": {
    "enabled": true,
    "ids": [5, 17, 47, 207, 2, 30, 16, 27, 480],
    "ext": [
      { "id": 17, "customerName": "1230" },
      { "id": 30, "customerName": "334111" },
      { "id": 47, "customerName": "11 老" },
      { "id": 480, "customerName": "3333" }
    ]
  }
}
```

- `ids`：当前组织启用的所有物流公司 ID 列表
- `ext`：有自定义名称的物流公司（`customerName` 为组织自定义别名）

**典型场景**
- 发货前查询可用物流公司及其编码，用于填写 `expressCode`
- 展示物流公司下拉列表供用户选择
- 根据组织 `logisticsTracking.ids` 过滤，仅展示该组织启用的物流公司

**推荐调用流程**
1. 先调用 `getSettings {"properties": ["logisticsTracking"]}` 获取当前组织启用的物流公司 ID 列表（`logisticsTracking.ids`）
2. 再调用 `listLogisticsCompanies {"ids": [...]}` 传入 ID 列表，获取物流公司详情（name、code 等）

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| ids | STRING | 否 | 是 | 物流公司ID列表，从 `getSettings` 的 `logisticsTracking.ids` 获取 |
| names | STRING | 否 | 是 | 物流公司名称列表（按名称过滤） |
| codes | STRING | 否 | 是 | 物流公司code列表（按编码过滤） |

**响应数据**

- 返回类型：`ARRAY`（数组）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | NUMBER | 物流公司ID |
| name | STRING | 物流公司名称 |
| code | STRING | 物流公司编码（发货时填入 `expressCode`） |
| site | STRING | 官网地址 |
| phone | STRING | 联系电话 |

**注意**
- `logisticsTracking.ext` 中的 `customerName` 是组织对该物流公司的自定义别名，优先用于展示
- 发货时 `expressCode` 填写物流公司的 `code` 字段值
- 若 `logisticsTracking.enabled` 为 `false`，表示当前组织未启用物流跟踪，无需查询物流公司
