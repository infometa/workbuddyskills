# getSettings - 查询系统设置

本文档覆盖系统设置查询接口，用于按需查询组织的各项配置信息。

## 接口目录
- [getSettings](#getsettings) - 查询系统设置（按需查询设置项，支持物流跟踪/价格显示/库存展示等）

---

**功能**：按需查询系统设置项，通过 `properties` 参数指定要返回的设置项名称列表；不传则返回全部设置。

**典型场景**
- 查询当前组织支持的物流公司（`logisticsTracking`）
- 判断是否开启了分公司层级（`branchOffice`）
- 获取商品价格显示方案，了解客户侧能看到什么价格（`productPriceDisplayType`）
- 获取库存展示方式（`invoicingShow`）
- 判断是否启用多部门订货（`enableMultiDepartmentOrdering`）
- 获取客户联系人必填规则（`customerMainContactsFillSetting`）
- 获取拜访纪要模版（`crmVisitFormTemplate`）

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| properties | STRING | 否 | 是 | 要查询的设置项名称列表，可选，不传返回全部；建议按需传入减少数据量 |

**可用 properties 枚举值**

| 枚举值 | 说明                                      |
|------|-----------------------------------------|
| `logisticsTracking` | 物流跟踪设置（支持的物流公司信息（包含id））                 |
| `branchOffice` | 分公司设置（是否开启分公司）                          |
| `systemName` | 系统名称设置（自定义各层级机构显示名称）                    |
| `invoicingShow` | 库存展示：0=不展示，1=展示数量，2=展示有无                |
| `allowTouristProductPrice` | 是否允许游客查看商品价格（true/false）                |
| `touristProductAuthorizations` | 游客商品授权方案                                |
| `printSetting` | 打印设置                                    |
| `crmVisitFormTemplate` | 拜访纪要模版                                    |
| `customerMainContactsFillSetting` | 客户联系人必填：0=无校验，1=姓名电话地址都必填，2=仅姓名电话必填     |
| `crmVisitSubmitCheckSetting` | 拜访记录必填项设置                               |
| `crmVisitUploadImageSetting` | 拜访记录上传图片要求设置                            |
| `defaultMall` | 默认浏览商城设置                                |
| `openmallTourist` | 开放商城浏览（游客相关）                            |
| `aloneMiniApp` | 独立机构小程序设置                               |
| `productPriceDisplayType` | 商品价格显示方案（0:不显示 1:只显市场价 2:只显订货价 3:两种都显示） |
| `enableMultiDepartmentOrdering` | 是否启用多部门订货                               |
| `openCustomerSignature` | 是否开启客户电子签名                              |
| `enableMallDeliveryAddress` | 是否允许下游在商城修改收货地址                         |
| `quantityScale` | 数量小数位                                   |
| `priceScale` | 价格小数位                                   |

**响应数据**

- 返回类型：`OBJECT`

| 字段 | 类型 | 说明 |
|------|------|------|
| branchOffice | OBJECT | 分公司设置（是否开启分公司） |
| systemName | OBJECT | 系统名称设置（自定义各层级机构的显示名称） |
| invoicingShow | NUMBER | 库存展示方式（0:不展示 1:展示数量 2:展示有无） |
| allowTouristProductPrice | BOOLEAN | 是否允许游客查看商品价格（true:允许 false:不允许） |
| touristProductAuthorizations | OBJECT | 游客商品授权方案 |
| printSetting | OBJECT | 打印设置 |
| crmVisitFormTemplate | OBJECT | 拜访纪要模版 |
| customerMainContactsFillSetting | NUMBER | 客户联系人必填设置（0:无校验 1:姓名电话地址都必填 2:仅姓名电话必填） |
| crmVisitSubmitCheckSetting | OBJECT | 拜访记录必填项设置 |
| crmVisitUploadImageSetting | OBJECT | 拜访记录上传图片要求设置 |
| aloneMiniApp | OBJECT | 独立机构小程序设置 |
| mallSetting | OBJECT | 商城浏览设置（默认进入商城、品牌显示等） |
| enableTouristLookMall | BOOLEAN | 是否允许游客浏览商城（默认true） |
| quantityScale | NUMBER | 数量小数位 |
| priceScale | NUMBER | 价格小数位 |
| productPriceDisplayType | NUMBER | 商品价格显示方案（0:不显示 1:只显示市场价 2:只显示客户订货价 3:同时显示两种价格） |
| enableMultiDepartmentOrdering | BOOLEAN | 是否启用多部门订货 |
| openCustomerSignature | BOOLEAN | 是否开启客户电子签名 |
| enableMallDeliveryAddress | BOOLEAN | 是否允许下游在商城修改收货地址 |

**注意**
- 建议按需传入 `properties`，避免返回无关设置项
- `invoicingShow` 为整数枚举，0/1/2 含义见上方表格
- `productPriceDisplayType` 决定客户在商城能看到哪种价格，创建订单前可用于确认价格逻辑
