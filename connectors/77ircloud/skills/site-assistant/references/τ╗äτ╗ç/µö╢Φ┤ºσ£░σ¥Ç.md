# 收货地址

本文档覆盖组织（机构/客户）收货地址查询接口，用于在下单前获取收货方的地址列表。

## 接口目录
- [listDeliveryAddresses](#listdeliveryaddresses) - 查询组织收货地址列表

---

## listDeliveryAddresses

**功能**：根据组织ID（机构或客户）查询其名下所有收货地址列表，返回地址的完整信息（联系人、电话、省市区、详细地址、经纬度等）。

**典型场景**
- 代客户下单时，获取该客户的收货地址列表供用户选择
- 展示客户/机构地址簿
- 查询客户默认收货地址（通过 `defaultFlag` 过滤）

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| orgId | NUMBER | 是 | 否 | 组织ID（机构或客户ID），来自 `searchDirectUnder.id` 或 `getCustomerDetail.id` |

**响应数据**

- 返回类型：`ARRAY`（数组）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | NUMBER | 收货地址ID（下单时传入 `createToBOrder.addressId`） |
| orgId | NUMBER | 所属组织ID |
| defaultFlag | BOOLEAN | 是否默认收货地址（`true` 为默认） |
| name | STRING | 收货联系人姓名（下单时传入 `contactName`） |
| phoneNum | STRING | 联系电话（下单时传入 `contactPhone`） |
| provinceId | NUMBER | 省份ID（下单时传入对应字段） |
| provinceName | STRING | 省份名称 |
| cityId | NUMBER | 城市ID（下单时传入对应字段） |
| cityName | STRING | 城市名称 |
| districtId | NUMBER | 区ID（下单时传入对应字段） |
| districtName | STRING | 区名称 |
| details | STRING | 详细地址 |
| address | STRING | 完整地址（省市区 + 详细地址拼装，可直接展示） |
| longitude | NUMBER | 经度（下单时传入 `addressLongitude`） |
| latitude | NUMBER | 纬度（下单时传入 `addressLatitude`） |
| memo | STRING | 备注 |

---

## 跨接口组合示例

**场景**：代客户下单时选择收货地址
1. `searchDirectUnder` → 传入 `hierarchyCodes: ["CUSTOMER"]` 搜索客户，获取客户ID
2. `listDeliveryAddresses` → 传入客户ID（orgId），获取收货地址列表
3. 用户选择地址后，将 `id` 作为 `addressId`，`name`/`phoneNum`/`provinceId`/`cityId`/`districtId`/`details`/`longitude`/`latitude` 填入 `createToBOrder` 对应字段
