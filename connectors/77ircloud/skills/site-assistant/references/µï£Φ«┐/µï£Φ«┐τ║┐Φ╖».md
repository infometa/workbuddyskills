# 拜访线路管理

本文档覆盖拜访线路的查询接口，包括线路列表查询、线路详情查询、线路客户列表查询。

## 接口目录
- [crmRouteSearchList](#crmroutesearchlist) - 分页查询拜访线路列表
- [crmRouteDetail](#crmroutedetail) - 获取拜访线路详情
- [crmRouteCustomerList](#crmroutecustomerlist) - 查询拜访线路客户列表

---
## crmRouteSearchList

**功能**：查询拜访线路列表，支持按关键词（业务员/线路名称/编码）模糊搜索、按状态和所属业务员筛选，支持名称/编码排序。

**典型场景**
- 查询所有拜访线路列表
- 按线路名称/编码模糊搜索特定线路
- 查询启用状态的线路
- 查询某业务员名下的拜访线路
- 获取线路ID用于后续详情查询或客户关联操作

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| q | STRING | 否 | 否 | 搜索条件，业务员/线路名称/线路编码模糊搜索 |
| status | NUMBER | 否 | 否 | 线路状态，0=禁用，1=启用 |
| targetSalesId | NUMBER | 否 | 否 | 所属业务员ID |
| sort | SORT | 否 | 否 | 线路名称：name；线路编码：code |

**响应数据**
- 返回类型：`PAGE`（分页）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | NUMBER | 线路ID |
| name | STRING | 线路名称 |
| code | STRING | 线路编码 |
| status | NUMBER | 线路状态（0:禁用 / 1:启用） |
| remarks | STRING | 备注 |
| customerTotalCount | NUMBER | 客户合计数量 |
| salesId | NUMBER | 所属业务员ID |
| salesName | STRING | 所属业务员名称 |

---

## crmRouteDetail

**功能**：根据ID获取拜访线路详情，返回线路基础信息、所属业务员以及关联客户列表。

**典型场景**
- 查看某条拜访线路的完整信息
- 查看线路下关联的所有客户及拜访顺序
- 为修改线路或调整客户关联做准备

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| id | NUMBER | 是 | 否 | 线路ID |

**响应数据**
- 返回类型：`OBJECT`

| 字段 | 类型 | 说明 |
|------|------|------|
| id | NUMBER | 线路ID |
| name | STRING | 线路名称 |
| code | STRING | 线路编码 |
| status | NUMBER | 线路状态（0:禁用 / 1:启用） |
| remarks | STRING | 备注 |
| customerTotalCount | NUMBER | 客户合计数量 |
| salesId | NUMBER | 所属业务员ID |
| salesName | STRING | 所属业务员名称 |
---

## crmRouteCustomerList

**功能**：查询指定拜访线路下关联的客户列表，返回关联记录ID、客户信息及拜访顺序，支持按客户名称/编码排序。

**典型场景**
- 查看某条拜访线路下关联的所有客户
- 获取线路客户的关联记录ID，用于修改/删除关联客户
- 核对线路下客户的拜访顺序

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| routeId | NUMBER | 是 | 否 | 线路ID |

**响应数据**
- 返回类型：`LIST`（列表）

| 字段 | 类型 | 说明 |
|------|------|------|
| routeId | NUMBER | 线路ID |
| id | NUMBER | 关联记录ID |
| customerId | NUMBER | 客户ID |
| sort | NUMBER | 拜访顺序 |
| customerCode | STRING | 客户编码 |
| customerName | STRING | 客户名称 |
| customerStatus | NUMBER | 客户状态（0:禁用 / 1:启用） |
| customerCategoryName | STRING | 客户分类名称 |
| regionName | STRING | 区域名称 |
| deliveryAddressDetail | STRING | 收货联系详细地址 |
| deliveryName | STRING | 收货联系人 |
| deliveryPhone | STRING | 收货联系人电话 |
| provinceId | NUMBER | 省份ID |
| cityId | NUMBER | 城市ID |
| districtId | NUMBER | 区ID |

## 跨接口组合示例

**场景1**：查看某业务员的拜访线路及客户
1. `crmRouteSearchList` → 传入 `q`（业务员名称）或 `targetSalesId` 查询线路列表
2. `crmRouteDetail` → 传入线路ID，查看该线路关联的客户及拜访顺序
