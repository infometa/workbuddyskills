# 拜访业务操作

本文档覆盖拜访记录的新建接口，包括客户拜访线上记录与商机拜访线上记录的创建。

## 接口目录
- [saveCustomerOnlineVisit](#savecustomeronlinevisit) - 新建客户拜访线上记录
- [saveBusinessOnlineVisit](#savebusinessonlinevisit) - 新建商机拜访线上记录

---

## saveCustomerOnlineVisit

**功能**：新建客户线上拜访记录（线上访谈场景）。

**典型场景**
- 业务员对客户进行线上拜访时创建拜访记录
- 填写拜访纪要
- 上传拜访相关附件（门头照、陈列照等）

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明                                  |
|------|------|------|------|-------------------------------------|
| summary | STRING | 否 | 否 | 拜访记录纪要/拜访记录,json字符串,具体可查看跨接口组合示例/场景2 |
| listAttachment | FILE | 否 | 是 | 附件列表                                |
| listAttachment.filePath | STRING | 是 | 否 | 文件路径 |
| listAttachment.groupType | NUMBER | 是 | 否 | 附件类型，0=其他，1=门头照，2=陈列照，3=非图片附件        |
| customerId | NUMBER | 是 | 否 | 客户ID                                |

**响应数据**
- 返回类型：`VOID`（无返回值）

---

## saveBusinessOnlineVisit

**功能**：新建商机拜访记录。

**典型场景**
- 业务员拜访商机客户时创建拜访记录
- 上传拜访相关附件（门头照、陈列照等）

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明                                  |
|------|------|------|------|-------------------------------------|
| summary | STRING | 否 | 否 | 拜访记录纪要/拜访记录,json字符串,具体可查看跨接口组合示例/场景2 |
| listAttachment | FILE | 否 | 是 | 附件列表                                |
| listAttachment.filePath | STRING | 是 | 否 | 文件路径 |
| listAttachment.groupType | NUMBER | 是 | 否 | 附件类型，0=其他，1=门头照，2=陈列照，3=非图片附件        |
| businessId | NUMBER | 是 | 否 | 商机ID                                |

**响应数据**
- 返回类型：`NUMBER`（新建拜访记录ID）

## 跨接口组合示例

**场景1**：新增客户/商机的拜访记录
1. `getSettings` -> 根据site-assistant/references/组织/设置.md，获取crmVisitFormTemplate设置项值
2. `customerList` -> 获取客户id（客户拜访时）；`registerAuditList` -> 获取商机id（商机拜访时）
3. `saveCustomerOnlineVisit` / `saveBusinessOnlineVisit` -> 根据1获取到的crmVisitFormTemplate模版，拼接拜访纪要，并保存；客户拜访用`saveCustomerOnlineVisit`传customerId，商机拜访用`saveBusinessOnlineVisit`传businessId
4. 拜访纪要格式为：[{"fieldKey":"summary","fieldName":"拜访概要","fieldContent":"11"}]，fieldKey和fieldName均为crmVisitFormTemplate模版里面的数据，fieldContent为用户填写对应的记录
