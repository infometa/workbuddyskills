# 拜访计划-普通

本文档覆盖普通拜访计划的查询接口，包括计划列表查询、计划详情查询。

## 接口目录
- [visitPlanSearchList](#visitplansearchlist) - 拜访计划列表
- [visitPlanDetail](#visitplandetail) - 获取拜访计划详情

---
## visitPlanSearchList

**功能**：拜访计划列表。

**典型场景**
- 查看某业务员的拜访计划列表
- 查看某客户的拜访计划
- 按计划状态筛选（进行中/已结束/已作废等）
- 查询某时间段内的拜访计划

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|----|------|------|
| startTimeRange | TIME_RANGE | 是  | 否 | 计划开始时间范围 |
| q | STRING | 否  | 否 | 模糊搜索，支持计划名称、业务员名称、关联的客户名称 |
| statusList | NUMBER | 否  | 是 | 计划状态集合，0=未开始，1=进行中，2=已结束，3=已延期，4=已作废 |
| salesIds | NUMBER | 否  | 是 | 业务员ID集合 |
| customerIds | NUMBER | 否  | 是 | 客户ID集合 |
| sort | SORT | 否  | 否 | 排序，起始日期：startTime；创建时间：createTime |

**响应数据**
- 返回类型：`PAGE`（分页）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | NUMBER | 计划ID |
| name | STRING | 计划名称 |
| type | NUMBER | 计划类型（0:常规 / 1:周期 / 2:预警） |
| status | NUMBER | 计划状态（0:未开始 / 1:进行中 / 2:已结束 / 3:已延期 / 4:已作废） |
| summary | STRING | 计划内容 |
| discardReason | STRING | 作废原因 |
| startTime | DATETIME | 计划开始时间 |
| endTime | DATETIME | 计划结束时间 |
| createTime | DATETIME | 创建时间 |
| salesId | NUMBER | 关联业务员ID |
| salesName | STRING | 业务员名称 |
| customerIds | NUMBER | 关联客户ID集合 |
| businessIds | NUMBER | 关联商机ID集合 |
| expectCount | NUMBER | 计划数量 |
| visitedCount | NUMBER | 已拜访数量 |
| creator | STRING | 创建人 |

---

## visitPlanDetail

**功能**：根据ID获取拜访计划详情，返回计划基础信息、关联客户/商机/业务员信息、计划统计数量。

**典型场景**
- 查看某条拜访计划的完整信息
- 查看计划关联的客户/商机明细
- 查看计划执行进度（计划数量/已拜访数量）

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| id | NUMBER | 是 | 否 | 计划ID |

**响应数据**
- 返回类型：`OBJECT`

| 字段 | 类型 | 说明 |
|------|------|------|
| id | NUMBER | 计划ID |
| name | STRING | 计划名称 |
| type | NUMBER | 计划类型（0:常规 / 1:周期 / 2:预警） |
| status | NUMBER | 计划状态（0:未开始 / 1:进行中 / 2:已结束 / 3:已延期 / 4:已作废） |
| summary | STRING | 计划内容 |
| discardReason | STRING | 作废原因 |
| startTime | DATETIME | 计划开始时间 |
| endTime | DATETIME | 计划结束时间 |
| createTime | DATETIME | 创建时间 |
| salesId | NUMBER | 关联业务员ID |
| salesName | STRING | 业务员名称 |
| expectCount | NUMBER | 计划数量 |
| visitedCount | NUMBER | 已拜访数量 |
| customerVOList | OBJECT | 客户信息列表 |
| customerVOList.id | NUMBER | 客户ID |
| customerVOList.name | STRING | 客户名称 |
| customerVOList.visitStatus | NUMBER | 拜访状态，0=待拜访，1=拜访中，2=已完成，3=拜访异常 |
| customerVOList.address | STRING | 地址 |
| businessVOList | OBJECT | 商机信息列表 |
| businessVOList.id | NUMBER | 商机ID |
| businessVOList.name | STRING | 商机名称 |
| businessVOList.address | STRING | 地址 |
| businessVOList.visitStatus | NUMBER | 拜访状态，0=待拜访，1=拜访中，2=已完成，3=拜访异常 |
| creator | STRING | 创建人 |
