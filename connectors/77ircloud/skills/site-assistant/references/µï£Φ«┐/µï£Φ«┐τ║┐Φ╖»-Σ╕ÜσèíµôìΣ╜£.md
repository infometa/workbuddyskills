# 拜访线路业务操作

本文档覆盖拜访线路的创建、修改接口，以及线路关联客户的批量保存、修改、删除接口。

## 接口目录
- [createCrmRoute](#createcrmroute) - 创建拜访线路
- [updateCrmRoute](#updatecrmroute) - 修改拜访线路
- [batchSaveCrmRouteCustomers](#batchsavecrmroutecustomers) - 批量保存客户关联
- [updateCrmRouteCustomer](#updatecrmroutecustomer) - 修改关联的客户信息
- [deleteCrmRouteCustomer](#deletecrmroutecustomer) - 删除关联的客户信息

---

## createCrmRoute

**功能**：创建拜访线路，需要管理拜访线路权限。创建成功后返回线路ID。

**典型场景**
- 为业务员创建一条拜访线路（如按区域、客户群体规划走访线路）
- 创建时指定线路名称、编码、状态、所属业务员

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| name | STRING | 是 | 否 | 线路名称，最大50个字符 |
| code | STRING | 是 | 否 | 线路编码，最大20个字符 |
| status | NUMBER | 是 | 否 | 线路状态，0=禁用，1=启用 |
| remarks | STRING | 否 | 否 | 备注，最大50个字符 |
| salesId | NUMBER | 是 | 否 | 所属业务员ID |

**响应数据**
- 返回类型：`NUMBER`（新建线路ID）

---

## updateCrmRoute

**功能**：修改指定拜访线路，需要管理拜访线路权限。

**典型场景**
- 调整线路名称、编码、备注
- 变更线路所属业务员
- 启用/禁用线路

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| id | NUMBER | 是 | 否 | 线路ID |
| name | STRING | 是 | 否 | 线路名称，最大50个字符 |
| code | STRING | 是 | 否 | 线路编码，最大20个字符 |
| status | NUMBER | 是 | 否 | 线路状态，0=禁用，1=启用 |
| remarks | STRING | 否 | 否 | 备注，最大50个字符 |
| salesId | NUMBER | 是 | 否 | 所属业务员ID |

**响应数据**
- 返回类型：`VOID`（无返回）

---

## batchSaveCrmRouteCustomers

**功能**：为指定拜访线路批量保存客户关联，每项包含客户ID和配送顺序。

**典型场景**
- 为新建的拜访线路一次性关联多个客户
- 批量调整线路下客户的拜访顺序（重新保存整条线路的客户列表）
- 批量替换线路关联的客户

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| routeId | NUMBER | 是 | 否 | 线路ID |
| routeCustomers | OBJECT | 是 | 是 | 客户关联列表|
| routeCustomers.customerId | NUMBER | 是 | 否 | 客户ID |
| routeCustomers.sort | NUMBER | 否 | 否 | 配送顺序，0-999的整数 |

**响应数据**
- 返回类型：`VOID`（无返回）

---

## updateCrmRouteCustomer

**功能**：根据关联记录ID修改指定拜访线路下关联客户的信息（当前仅支持修改配送顺序）。

**典型场景**
- 调整某个客户在线路中的拜访顺序
- 修正误设的配送顺序

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| routeId | NUMBER | 是 | 否 | 线路ID |
| id | NUMBER | 是 | 否 | 关联记录ID |
| sort | NUMBER | 是 | 否 | 配送顺序，0-999的整数 |

**响应数据**
- 返回类型：`VOID`（无返回）

---

## deleteCrmRouteCustomer

**功能**：根据关联记录ID删除指定拜访线路下关联的客户信息。

**典型场景**
- 将某个客户从拜访线路中移除
- 线路调整时清理不再拜访的客户

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| routeId | NUMBER | 是 | 否 | 线路ID |
| id | NUMBER | 是 | 否 | 关联记录ID |

**响应数据**
- 返回类型：`VOID`（无返回）

---

## 跨接口组合示例

**场景1**：新建一条拜访线路并关联客户
1. `customerList` → 获取客户ID（见客户与商机/客户.md）
2. `createCrmRoute` → 创建拜访线路，获取线路ID
3. `batchSaveCrmRouteCustomers` → 传入线路ID和客户列表，批量关联客户并设置拜访顺序
