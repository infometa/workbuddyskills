# 拜访管理

本文档覆盖拜访记录的查询接口，包括客户/商机拜访记录列表查询。

## 接口目录
- [visitSearchList](#visitsearchlist) - 客户拜访记录列表

---

## visitSearchList

**功能**：查询客户、商机拜访记录列表，支持按时间范围、状态、客户/商机、业务员等多维度筛选，支持分页。

**典型场景**
- 查看某段时间内的拜访记录
- 按拜访状态筛选（待拜访/拜访中/已完成）
- 按拜访类型筛选（线上拜访/实地拜访）
- 查询某业务员的拜访记录
- 查询某客户/商机的拜访记录
- 查看异常拜访记录
- 查看带附件/点赞/评论的完整拜访记录

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明                                   |
|------|------|----|------|--------------------------------------|
| createTimeRange | TIME_RANGE | 是  | 否 | 创建时间范围                               |
| q | STRING | 否  | 否 | 搜索条件，模糊搜索                            |
| queryComments | STRING | 否  | 否 | 拜访评论搜索                               |
| summary | STRING | 否  | 否 | 拜访纪要搜索                               |
| status | NUMBER | 否  | 否 | 记录状态，0=待拜访，1=拜访中，2=已完成               |
| type | NUMBER | 否  | 否 | 记录类型，0=线上拜访，1=实地拜访                   |

| customerStatus | NUMBER | 否  | 否 | 客户状态，0=禁用，1=启用                       |

## 跨接口组合示例

**场景1**：查看某客户的拜访记录详情
1. `customerList` → 获取客户ID（客户与商机/客户.md）
2. `visitSearchList` → 传入 customerIds + createTimeRange 查询拜访记录列表
