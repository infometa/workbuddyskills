# 拜访计划-周期

本文档覆盖周期拜访计划任务（按周循环的拜访计划）的查询接口，包括任务列表查询、任务详情查询。周期计划按固定星期（如每周一、三、五）循环生成拜访计划。

## 接口目录
- [visitPlanCycleJobSearchList](#visitplancyclejobsearchlist) - 周期计划任务列表
- [visitPlanCycleJobDetail](#visitplancyclejobdetail) - 获取周期计划任务详情

---
## visitPlanCycleJobSearchList

**功能**：周期计划任务列表，支持关键词、状态、时间范围筛选，支持排序。

**典型场景**
- 查看某业务员的周期拜访计划任务
- 按状态筛选周期任务（进行中/已作废等）
- 查询某时间段内生效的周期任务

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| startTimeRange | TIME_RANGE | 是 | 否 | 计划开始时间范围 |
| q | STRING | 否 | 否 | 模糊搜索，支持计划名称、业务员名称、关联的客户名称 |
| status | NUMBER | 否 | 否 | 计划状态，0=未开始，1=进行中，2=已结束，3=已延期，4=已作废 |
| sort | SORT | 否 | 否 | 排序，起始日期：startTime；创建时间：createTime |

**响应数据**
- 返回类型：`PAGE`（分页）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | NUMBER | 周期计划任务ID |
| name | STRING | 计划名称 |
| type | NUMBER | 关联类型（0:关联线路 / 1=关联客户/商机） |
| status | NUMBER | 计划状态（0:未开始 / 1:进行中 / 2:已结束 / 3:已延期 / 4:已作废） |
| summary | STRING | 计划内容 |
| discardReason | STRING | 作废原因 |
| startTime | DATETIME | 计划开始时间 |
| endTime | DATETIME | 计划结束时间 |
| createTime | DATETIME | 创建时间 |
| salesId | NUMBER | 关联业务员ID |
| salesName | STRING | 业务员名称 |
| customerIds | NUMBER | 关联客户ID集合 |
| businessIds | NUMBER | 关联商机ID集合 |
| expectCount | NUMBER | 计划数量 |
| visitedCount | NUMBER | 已拜访数量 |
| cycleInfo | OBJECT | 周期信息 |
| cycleInfo.week | STRING | 周期星期集合，MON/TUE/WED/THU/FRI/SAT/SUN |
| routeInfo | OBJECT | 关联的线路信息 |
| routeInfo.name | STRING | 线路名称 |
| creator | STRING | 创建人 |

## visitPlanCycleJobDetail

**功能**：根据ID获取周期计划任务详情，返回任务基础信息、周期星期、关联线路信息及统计数量。

**典型场景**
- 查看某周期任务的完整配置（星期、线路/客户）
- 查看周期任务生成的计划执行进度

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| id | NUMBER | 是 | 否 | 周期计划任务ID |

**响应数据**
- 返回类型：`OBJECT`

| 字段 | 类型 | 说明 |
|------|------|------|
| id | NUMBER | 周期计划任务ID |
| name | STRING | 计划名称 |
| type | NUMBER | 关联类型（0:关联线路 / 1=关联客户/商机） |
| status | NUMBER | 计划状态（0:未开始 / 1:进行中 / 2:已结束 / 3:已延期 / 4:已作废） |
| summary | STRING | 计划内容 |
| discardReason | STRING | 作废原因 |
| startTime | DATETIME | 计划开始时间 |
| endTime | DATETIME | 计划结束时间 |
| createTime | DATETIME | 创建时间 |
| salesId | NUMBER | 关联业务员ID |
| salesName | STRING | 业务员名称 |
| expectCount | NUMBER | 计划数量 |
| visitedCount | NUMBER | 已拜访数量 |
| cycleInfo | OBJECT | 周期信息 |
| cycleInfo.week | STRING | 周期星期集合，MON/TUE/WED/THU/FRI/SAT/SUN |
| customerVOList | OBJECT | 客户信息列表 |
| customerVOList.id | NUMBER | 客户ID |
| customerVOList.name | STRING | 客户名称 |
| customerVOList.code | STRING | 客户编码 |
| customerVOList.address | STRING | 地址 |
| businessVOList | OBJECT | 商机信息列表 |
| businessVOList.id | NUMBER | 商机ID |
| businessVOList.name | STRING | 商机名称 |
| businessVOList.address | STRING | 地址 |
| routeInfo | OBJECT | 线路信息 |
| routeInfo.id | NUMBER | 线路ID |
| routeInfo.name | STRING | 线路名称 |
| routeInfo.code | STRING | 线路编码 |
| routeInfo.status | NUMBER | 线路状态（0:禁用 / 1:启用） |
| routeInfo.customerTotalCount | NUMBER | 线路客户合计数量 |
| routeInfo.salesName | STRING | 线路所属业务员名称 |
| creator | STRING | 创建人 |
