# 商城-场景分类页

本文档覆盖场景分类页相关接口，包含场景分类页列表搜索和场景分类页详情查询。

## 接口目录
- [customPageSearch](#customPageSearch) - 查询场景分类页列表（分页，默认筛选场景分类页）
- [customPageDetailSearch](#customPageDetailSearch) - 场景分类页详情（加载页面数据）

---

## customPageSearch

**功能**：查询场景分类页列表，支持分页，默认查询场景分类页类型（types=[2]）。

**典型场景**
- 需要获取场景分类页列表数据

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| currentPage | NUMBER | 否 | 否 | 当前页码，默认1 |
| pageSize | NUMBER | 否 | 否 | 每页条数，默认20 |
| forListPage | BOOLEAN | 否 | 否 | 是否仅查询列表，默认true |
| loadPageData | BOOLEAN | 否 | 否 | 是否加载页面数据，默认false |
| types | NUMBER | 否 | 是 | 类型数组，1=自定义页面,2=场景分类页，默认[2] |

**响应数据**
- 返回类型：`PAGE`（分页）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | NUMBER | ID |
| title | STRING | 页面标题 |
| type | NUMBER | 类型（1=自定义页面,2=场景分类页） |
| enabled | NUMBER | 是否发布（0=草稿,1=已发布） |
| groupId | NUMBER | 页面分组ID |
| viewedCount | NUMBER | 浏览人数 |
| creatorId | NUMBER | 创建者ID |
| creatorName | STRING | 创建者名字 |
| modifierId | NUMBER | 修改者ID |
| modifierName | STRING | 修改者名字 |
| createTime | DATETIME | 创建时间 |
| modifyTime | DATETIME | 修改时间 |

## customPageDetailSearch

**功能**：查询场景分类页详情，返回包含页面配置数据的完整信息。

**典型场景**
- 查看某个场景分类页的详细配置数据
- 获取场景分类页的页面数据（pageData）进行渲染

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| loadPageData | BOOLEAN | 否 | 否 | 是否加载页面数据，默认true |
| groupId | STRING | 是 | 否 | 页面分组ID |

**响应数据**
- 返回类型：`PAGE`（分页）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | NUMBER | ID |
| title | STRING | 页面标题 |
| type | NUMBER | 类型（1=自定义页面,2=场景分类页） |
| pageData | STRING | 页面配置JSON字符串，需解析后使用，结构详见下方说明 |
| enabled | NUMBER | 是否发布（0=草稿,1=已发布） |
| groupId | NUMBER | 页面分组ID |
| viewedCount | NUMBER | 浏览人数 |
| creatorId | NUMBER | 创建者ID |
| creatorName | STRING | 创建者名字 |
| modifierId | NUMBER | 修改者ID |
| modifierName | STRING | 修改者名字 |
| createTime | DATETIME | 创建时间 |
| modifyTime | DATETIME | 修改时间 |

### pageData 字段 JSON 结构说明

`pageData` 为 JSON 字符串，需解析使用。其结构示例如下：

```json
{
  "headerTitle": "页面标题",
  "floors": [
    {
      "id": 0,
      "type": "POSTER_IMAGE",
      "detail": "",
      "stableId": "0.5544602301330444",
      "defaultShow": true
    },
    {
      "id": 1,
      "type": "PRODUCT_CATEGORY",
      "detail": {
        "categoryId": [2273127019675488, 2273127020282496, 2273127021111360],
        "displayStyle": "SPU",
        "classfiedMode": 0,
        "productFields": ["name", "unit", "price", "code", "barcode", "spec", "stock"],
        "showCategoryId": []
      },
      "stableId": "0.2828295724616142",
      "defaultShow": true
    }
  ]
}
```

**关键字段说明**：
- `headerTitle` - 页面标题顶栏文字
- `floors` - 楼层配置数组，每项代表一个组件楼层
  - `floors[].type` - 楼层类型，`POSTER_IMAGE`=海报图片轮播，`PRODUCT_CATEGORY`=商品分类楼层
  - `floors[].detail` - 楼层详细配置（JSON对象），不同 `type` 结构不同
  -   - 当 `type=PRODUCT_CATEGORY` 时，`detail.categoryId` 为商品分类ID数组，`detail.showCategoryId` 为商品展示分类ID数组
  -   - **取哪个字段取决于商品参数设置**：先调用 `productSetting` 查询 `enabledShowCategory`（是否启用展示分类），
  -   - 如果 `enabledShowCategory` 为 `false`（未启用展示分类），取 `detail.categoryId`（商品分类）
  -   - 如果 `enabledShowCategory` 为 `true`（已启用展示分类），取 `detail.showCategoryId`（商品展示分类）
  -   - `detail.displayStyle` - 商品展示粒度，`SPU`=按SPU展示商品，`SKU`=按SKU展示商品
  - `floors[].defaultShow` - 是否默认展示

**AI 使用指引**：当需要获取页面中配置的商品分类信息时，先调用 `productSetting` 查询 `enabledShowCategory` 开关状态（见商品/参数设置.md），再从 `pageData.floors` 中找到 `type=PRODUCT_CATEGORY` 的楼层：
- `enabledShowCategory=false` → 读取 `detail.categoryId`（商品分类ID列表）
- `enabledShowCategory=true` → 读取 `detail.showCategoryId`（商品展示分类ID列表）

## 跨接口组合示例

**场景**：查看某个场景分类页的详情
1. `customPageSearch` → 获取场景分类页列表，找到目标页面的 `groupId`
2. `customPageDetailSearch` → 传入 `groupId` 获取该页面的完整配置数据（含 `pageData`）

**场景**：获取场景分类页中配置的商品列表
1. `productSetting` → 查询 `enabledShowCategory` 开关状态（见商品/参数设置.md）
2. `customPageDetailSearch` → 获取 `pageData` JSON 字符串
3. 从 `pageData.floors` 中找到 `type=PRODUCT_CATEGORY` 的楼层：
   - `enabledShowCategory=false` → 取 `detail.categoryId`（商品分类ID列表）
   - `enabledShowCategory=true` → 取 `detail.showCategoryId`（商品展示分类ID列表）
4. 将分类ID转换为编码：
   - 商品分类（categoryId）→ `productCategoryList` 获取分类编码
   - 商品展示分类（showCategoryId）→ `productShowCategoryList` 获取展示分类编码
5. `productList` → 传入对应编码查询该分类下商品（见商品/商品.md）
