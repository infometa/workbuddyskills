# 下游机构资金配置

本文档覆盖下游机构资金配置查询接口，用于查看下游机构（客户/门店/经销商等）的资金相关参数，包括信用额度、账期等。


## 接口目录
- [getDownOrgConfigList](#getdownorgconfiglist) - 查询下游机构资金配置列表

---

## getDownOrgConfigList

**功能**：查询下游机构的资金配置信息，返回各下游机构的信用额度（含可用/占用）、账期、结算机构等配置。

**典型场景**
- 批量查询多个下游机构的资金配置
- 按额度占用计算方式筛选（下订单占用/出库占用）
- 查看下游机构的账期类型和结算模式

**参数**
| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| downOrgIds | NUMBER | 是 | 是 | 下游机构ID列表，个数限制 1-100 |
| typeEnum | STRING | 否 | 否 | 占用额度计算方式：`ORDER`=下订单占用，`STOCK`=出库占用 |

**响应数据**
- 返回类型：`ARRAY<DownOrgFundConfigVO>`
| 字段 | 类型 | 说明 |
|------|------|------|
| downOrgId | NUMBER | 下游机构ID |
| downOrgType | STRING | 下游机构类型：`BRANCH`(分公司)、`STORE`(门店)、`CUSTOMER`(客户)、`HEADQUARTER`(总部)、`MERCHANT`(商家)、`SUPPLIER`(供应商) |
| createId | NUMBER | 创建人ID |
| createName | STRING | 创建人名称 |
| settlementOrgId | NUMBER | 结算机构ID |
| settlementOrgName | STRING | 结算机构名称 |
| overdueOrderExempt | NUMBER | 销售回款风险下单控制：`1`=跟随系统，`0`=始终不限制 |
| creditAccount | OBJECT | 信用额度信息，见下方 |
| creditAccount.limitQuota | NUMBER | 信用额度（为空表示不限制信用额度） |
| creditAccount.availableQuota | NUMBER | 可用额度（可能为空） |
| creditAccount.useQuota | NUMBER | 占用额度 |
| payPeriod | OBJECT | 账期信息，见下方 |
| payPeriod.payPeriodType | STRING | 账期类型：`MONEY_BEFORE_CARGO`(先款后货)、`MONTH`(月结)、`NO_CONSTANT`(不固定账期)、`CONSTANT`(固定账期)、`CARGO_BEFORE_MONEY`(先货后款)、`ROLLING`(滚动) |
| payPeriod.payPeriodTypeName | STRING | 账期类型中文名称 |
| payPeriod.billDay | STRING | 账单日（多少天后，非具体日期） |
| payPeriod.repaymentDay | NUMBER | 还款日（多少天后，非具体日期） |
| payPeriod.repaymentDate | STRING | 还款日期（具体时间，需传 `fundMoneyCalculateFlag` 才返回） |
| payPeriod.payPeriodMoney | NUMBER | 账期金额（需传 `fundMoneyCalculateFlag` 才返回） |
| payPeriod.futurePayPeriodMoney | NUMBER | 未来账期金额 |
