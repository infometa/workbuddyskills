# 账号转账单

本文档覆盖银行账户转账单相关的查询接口。账号转账单用于记录企业内部不同银行账户之间的资金划转流水。

## 接口目录
- [bankAccountTransferList](#bankaccounttransferlist) - 账号转账单列表查询

---

## bankAccountTransferList

**功能**：查询银行账户转账单列表，支持按转账时间/制单时间/审核时间范围、单据状态、转账账户、制单人等多维度筛选。

**典型场景**
- 查询某时间段内的账户转账记录
- 按转账状态（待审核/已审核/已作废）筛选转账单
- 查询某银行账户（转入或转出）的转账流水
- 查询某制单人创建的转账单

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| transferTimeRange | TIME_RANGE | 否 | 否 | 转账时间范围 |
| createTimeRange | TIME_RANGE | 否 | 否 | 制单时间范围 |
| auditTimeRange | TIME_RANGE | 否 | 否 | 审核时间范围 |
| billCodeLike | STRING | 否 | 否 | 单号模糊搜索 |
| billCodeList | STRING | 否 | 是 | 单号列表 |
| status | STRING | 否 | 是 | 状态：UN_CONFIRM=待审核、CONFIRMED=已审核、CANCEL=已作废 |
| transferBankAccountIds | NUMBER | 否 | 是 | 转账账户ID列表（同时搜索转入和转出账户） |
| createIds | NUMBER | 否 | 是 | 制单人ID列表（最多10个） |
| withAttachments | BOOLEAN | 否 | 否 | 是否附带查询附件列表 |
| sort | STRING | 否 | 否 | 排序，格式：字段:排序方式，例如transferTime:asc，支持transferTime、createTime、auditTime |

**响应数据**
- 返回类型：`PAGE`（分页）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | NUMBER | 转账单ID |
| billCode | STRING | 转账单号 |
| status | STRING | 状态：UN_CONFIRM=待审核、CONFIRMED=已审核、CANCEL=已作废 |
| money | NUMBER | 转账金额 |
| transferTime | DATETIME | 转账时间 |
| createTime | DATETIME | 创建时间 |
| modifyTime | DATETIME | 修改时间 |
| auditTime | DATETIME | 审核时间 |
| cancelTime | DATETIME | 作废时间 |
| createId | NUMBER | 制单人ID |
| createName | STRING | 制单人名称 |
| auditId | NUMBER | 审核人ID |
| auditName | STRING | 审核人名称 |
| cancelId | NUMBER | 作废人ID |
| cancelName | STRING | 作废人名称 |
| cancelDesc | STRING | 作废原因 |
| remark | STRING | 备注 |
| outBankAccount | OBJECT | 转出银行账户（见下表） |
| inBankAccount | OBJECT | 转入银行账户（见下表） |

**outBankAccount / inBankAccount 字段**

| 字段 | 类型 | 说明 |
|------|------|------|
| bankAccountName | STRING | 账号用户名 |
| bankName | STRING | 开户银行 |
| end4BankCardNum | STRING | 银行卡号 |
