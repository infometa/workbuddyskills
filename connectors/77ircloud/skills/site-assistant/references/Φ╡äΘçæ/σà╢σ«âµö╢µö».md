# 其它收支

本文档覆盖其他应收单和其他应付单的查询接口。其他收支用于记录非订单产生的往来收支流水（如往来收支、日常收支），支持按时间、状态、机构、业务员等多维度筛选。

## 接口目录
- [otherReceivableBillList](#otherreceivablebilllist) - 其他应收单列表查询
- [otherPayableBillList](#otherpayablebilllist) - 其他应付单列表查询

---

## otherReceivableBillList

**功能**：查询其他应收单列表，支持按制单时间/修改时间范围、单据状态、收款状态、业务类型等多维度筛选。

**典型场景**
- 查询某时间段内的其他应收记录
- 按单据状态（未审核/已审核/作废）筛选应收单
- 按收款状态（未收款/部分收款/已收款）筛选
- 查询往来收支或日常收支类应收单
- 查询某业务员或部门名下的应收流水

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| createTimeRange | TIME_RANGE | 否 | 否 | 制单时间范围|
| modifyTimeRange | TIME_RANGE | 否 | 否 | 修改时间范围|
| keyword | STRING | 否 | 否 | 搜索关键字（单号/往来编码/往来名称） |
| otherReceivableBillCode | STRING | 否 | 否 | 其他应收单号 |
| otherReceivableBillCodes | STRING | 否 | 是 | 批量单号查询（单个单号时此参数不生效） |
| sourceBillCodes | STRING | 否 | 是 | 产生其他收支的原始单号列表（例如采购单） |
| otherReceivableBillType | STRING | 否 | 否 | 交易类型：OTHER_RECEIVABLE=其他应收、OTHER_PAYABLE=其他应付 |
| otherReceivableBusinessTypes | STRING | 否 | 是 | 业务类型：DEALINGS=往来收支、DAILY=日常收支 |
| searchStatuses | NUMBER | 否 | 是 | 单据状态：0=未审核、1=已审核、-1=已作废 |
| searchPaymentStatuses | NUMBER | 否 | 是 | 收款状态：0=未收款、1=部分收款、2=已收款 |
| sort | STRING | 否 | 否 | 排序，格式：otherReceivableBillCode:desc，支持单号、应收类型、单据状态、收款状态、应收金额 |

**响应数据**
- 返回类型：`PAGE`（分页）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | NUMBER | 其他应收单ID |
| otherReceivableBillCode | STRING | 其他应收单单号 |
| otherReceivableBillType | STRING | 单据类型：OTHER_RECEIVABLE=其他应收、OTHER_PAYABLE=其他应付 |
| otherReceivableBusinessType | STRING | 业务类型：DEALINGS=往来收支、DAILY=日常收支 |
| otherReceivableBillCostTypeId | NUMBER | 应收费用类型ID |
| otherReceivableBillCostTypeName | STRING | 应收费用类型名称 |
| status | STRING | 单据状态：WAIT_AUDIT=未审核、ALREADY_AUDIT=已审核、DISCARD=作废 |
| paymentStatus | STRING | 收款状态：WAIT_COLLECTION=未收款、PART_COLLECTION=部分收款、COLLECTION=已收款 |
| hasWaitAuditPaymentRecord | BOOLEAN | 是否存在待审核收款记录 |
| payableMoney | NUMBER | 应收金额 |
| paidMoney | NUMBER | 已收金额 |
| unPaidMoney | NUMBER | 未收金额 |
| unConfirmMoney | NUMBER | 未确认金额 |
| paymentOrgId | NUMBER | 付款方机构ID |
| paymentOrgType | STRING | 付款方机构类型 |
| paymentOrgName | STRING | 付款方机构名称 |
| paymentOrgCode | STRING | 付款方机构编码 |
| paymentOrgRegion | STRING | 付款方机构区域名称 |
| paymentSalesId | NUMBER | 付款机构所属业务员ID（仅往来类型为客户时有数据） |
| paymentSalesName | STRING | 付款机构所属业务员名称 |
| paymentSalesRegionId | NUMBER | 付款机构所属区域ID |
| paymentSalesRegionName | STRING | 付款机构所属区域名称 |
| paymentSalesDepartmentId | NUMBER | 付款机构所属部门ID |
| paymentSalesDepartmentName | STRING | 付款机构所属部门名称 |
| receiptOrgId | NUMBER | 收款方机构ID |
| receiptOrgType | STRING | 收款方机构类型 |
| receiptOrgName | STRING | 收款方机构名称 |
| receiptOrgCode | STRING | 收款方机构编码 |
| otherOrgId | NUMBER | 交易对手ID |
| otherOrgType | STRING | 交易对手机构类型 |
| otherOrgName | STRING | 交易对手机构名称 |
| otherOrgCode | STRING | 交易对手机构编码 |
| otherDownFlag | BOOLEAN | 与当前机构关系（false=上游，true=下游） |
| otherOrgSalesName | STRING | 交易对手所属业务员名称 |
| otherOrgRegionId | NUMBER | 交易对手区域ID |
| otherOrgRegion | STRING | 交易对手区域名称 |
| dealingsOrgId | NUMBER | 与当前机构发生交易的往来机构ID |
| dealingsOrgType | STRING | 往来机构类型 |
| dealingsOrgName | STRING | 往来机构名称 |
| dealingsOrgCode | STRING | 往来机构编码 |
| createTime | DATETIME | 制单时间 |
| modifyTime | DATETIME | 修改时间 |
| billAuditTime | DATETIME | 单据审核时间 |
| billDiscardTime | DATETIME | 单据作废时间 |
| createId | NUMBER | 制单人ID |
| createName | STRING | 制单人名称 |
| billAuditorId | NUMBER | 单据审核人ID |
| billAuditor | STRING | 单据审核人 |
| billDiscardOperatorId | NUMBER | 单据作废人ID |
| billDiscardOperator | STRING | 单据作废人 |
| discardRemark | STRING | 作废备注 |
| remark | STRING | 备注 |
