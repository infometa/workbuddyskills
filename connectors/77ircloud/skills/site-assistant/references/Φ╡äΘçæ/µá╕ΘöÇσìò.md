# 核销单

本文档覆盖核销单相关的查询接口。核销单用于记录应收/应付款项的核销流水，支持多种核销类型（应收收款核销、应付付款核销、预收冲应收等），支持按时间、状态、核销类型等多维度筛选。

## 接口目录
- [writeOffBillList](#writeoffbilllist) - 核销单列表查询

---

## writeOffBillList

**功能**：查询核销单列表，支持按核销时间/制单时间/更新时间范围、核销类型、核销方式（手动/自动）、单据状态等多维度筛选。

**典型场景**
- 查询某时间段内的核销记录
- 按核销类型筛选（如应收收款核销、应付付款核销）
- 查询手动或自动生成的核销单
- 按单据状态（待审核/已审核/已作废）筛选
- 查询某往来机构的核销流水

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| writeOffTimeRange | TIME_RANGE | 否 | 否 | 核销时间范围 |
| createTimeRange | TIME_RANGE | 否 | 否 | 制单时间范围 |
| modifyTimeRange | TIME_RANGE | 否 | 否 | 更新时间范围 |
| keyword | STRING | 否 | 否 | 搜索关键字 |
| writeOffBillCode | STRING | 否 | 否 | 核销单号 |
| sourceBillCode | STRING | 否 | 否 | 来源业务单号（出库单、收款单号、付款单号等） |
| sourceBillRelatedCode | STRING | 否 | 否 | 关联的订单 |
| paymentOrgName | STRING | 否 | 否 | 付款方名称 |
| paymentOrgCode | STRING | 否 | 否 | 付款方编码 |
| writeOffBillIds | NUMBER | 否 | 是 | 核销单ID列表 |
| writeOffSummary | STRING | 否 | 是 | 核销类型列表（见枚举说明） |
| writeOffGenerateMode | STRING | 否 | 否 | 核销方式：MANUAL=手动、AUTO=自动 |
| status | NUMBER | 否 | 是 | 状态：UN_CONFIRM=待审核、NORMAL=已审核、CANCEL=已作废 |
| writeOffMoney | OBJECT | 否 | 否 | 核销金额范围（min / max） |
| otherOrgIdList | NUMBER | 否 | 是 | 往来单位ID列表 |
| searchPlans | STRING | 否 | 否 | 筛选方案JSON字符串 |
| sort | STRING | 否 | 否 | 排序，格式：字段名称:desc，例如targetOrgId:desc |

**核销类型（writeOffSummary）枚举值**

| 值 | 说明 |
|---|---|
| PRE_RECEIPT_2_RECEIVABLE | 预收冲应收 |
| PRE_PAYMENT_2_PAYABLE | 预付冲应付 |
| PAYABLE_2_RECEIVABLE | 应付抵冲 |
| RECEIVABLE_2_PAYABLE | 应收抵冲 |
| RECEIVABLE | 应收收款核销 |
| PAYABLE | 应付付款核销 |
| PRE_RECEIPT_RETURN | 预收退款核销 |
| PRE_PAYMENT_RETURN | 预付退款核销 |
| SALE_RETURN | 销售退款核销 |
| PURCHASE_RETURN | 采购退款核销 |
| ORDER_REFUND | 订单退款核销 |
| PURCHASE_REFUND | 采购订单退款核销 |
| DIFF_RETURN | 差异退款核销 |
| OTHER_RECEIVABLE | 其他收入收款核销 |
| OTHER_PAYABLE | 其他支出付款核销 |
| BUYER_ORDER_RETURN | 要货退单退款核销 |
| BUYER_ORDER_REFUND | 要货单退款核销 |
