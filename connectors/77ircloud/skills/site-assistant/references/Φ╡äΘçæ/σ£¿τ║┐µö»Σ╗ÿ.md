# 在线支付

本文档覆盖在线支付查询接口，用于获取当前机构下客户可用的线上支付配置，包括各支付产品商户号、启用的支付方式、收款对象范围等信息。

## 接口目录
- [paymentChannelsSearch](#paymentchannelssearch) - 获取客户启用的在线支付

---

## paymentChannelsSearch

**功能**：查询当前机构下已配置的支付通道列表，按支付产品类型分组返回。每条通道包含商户号、通道状态、支持的买家支付方式及终端、收款对象限制等配置。

**典型场景**
- 查询当前机构启用了哪些线上支付通道（易宝、银联商务、微企付等）
- 查看某支付通道支持哪些买家支付方式（微信、支付宝、快捷支付等）及适用终端
- 确认支付通道对分公司/门店/客户的收款对象范围配置
- 对比不同商户号的通道启用状态与优先级

**参数**

无必填参数，按当前登录机构上下文返回可用支付通道。

**响应数据**
- 返回类型：`OBJECT`
- 按支付产品类型分组，各分组字段为数组，无数据时为 `null`

| 字段 | 类型 | 说明 |
|------|------|------|
| cmbAggregations | ARRAY | 招行聚合支付通道列表 |
| weixinSpecialMerchants | ARRAY | 微信特约商户列表 |
| aliSpecialMerchants | ARRAY | 支付宝特约商户列表 |
| ccbAggregations | ARRAY | 建行聚合支付通道列表 |
| yeepayMerchants | ARRAY | 易宝支付通道列表 |
| tenmseMerchants | ARRAY | 微企付通道列表 |
| wechatB2BMerchants | ARRAY | 小程序B2b支付通道列表 |
| kryWalletMerchants | ARRAY | 客如云钱包通道列表 |
| ohMerchants | ARRAY | OH支付通道列表 |
| shouqianbaMerchants | ARRAY | 收钱吧通道列表 |
| chinaumsMerchants | ARRAY | 银联商务通道列表 |

**支付通道对象（各分组数组元素）**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | NUMBER | 支付通道ID |
| payChannelType | STRING | 支付通道类型（WX_SPECIAL_MCH=微信特约商户，YEEPAY=易宝支付，TENMSE=微企付，WECHAT_B2B=小程序B2b支付，KRY_WALLET=客如云钱包，SHOUQIANBA=收钱吧，CHINAUMS=银联商务） |
| payChannelName | STRING | 支付通道名称 |
| merchantAccountCode | STRING | 商户号 |
| payChannelPriority | NUMBER | 支付通道优先级，数值越大优先级越高 |
| status | STRING | 通道状态（ENABLE=启用，DISABLE=停用） |
| isCurrentOrgCreate | BOOLEAN | 是否当前机构创建 |
| businessList | ARRAY | 支付方式业务配置列表 |
| receiptTargetConditions | ARRAY | 收款对象设置列表 |
| version | STRING | 通道版本（DEFAULT_VERSION=默认版本，NEW_VERSION=新版本） |
| merchantName | STRING | 商户名称 |
| merchantDivideAccountFlag | STRING | 商户分账标识（ENABLE=启用，DISABLE=停用） |

**businessList 元素**

| 字段 | 类型 | 说明 |
|------|------|------|
| paymentChannelBusinessId | NUMBER | 支付通道业务ID |
| paymentChannelId | NUMBER | 支付通道ID |
| buyerPayModeCode | STRING | 买家支付方式编码（1=微信支付，2=支付宝，9=收款码，10=商家扫码，11=付款码，51=快捷支付，53=个人/企业网银，60=微企付，80=客如云钱包，110=银联支付，111=微信支付(B2b)） |
| buyerPayModeName | STRING | 买家支付方式名称 |
| useTerminal | STRING | 使用终端（MINI_PROGRAM=小程序，WEB=网页，APP=APP，SUBSCRIPTION=订阅） |
| merchantFeePercent | NUMBER | 商户手续费率 |
| useTerminalName | STRING | 使用终端名称 |
| status | STRING | 业务状态（ENABLE=启用，DISABLE=停用） |

**receiptTargetConditions 元素**

| 字段 | 类型 | 说明 |
|------|------|------|
| allUsersAvailable | NUMBER | 是否所有用户可用（1=是，0=指定限制） |
| conditions | ARRAY | 收款对象条件列表 |
| conditions[].conditionType | STRING | 条件类型（ALL=全部，SPECIFIED_LIST=指定列表） |
| conditions[].targetIds | ARRAY | 指定对象ID列表（conditionType=SPECIFIED_LIST 时有值） |
| conditions[].targetNames | ARRAY | 指定对象名称列表 |
| orgType | STRING | 收款对象机构类型（BRANCH=分公司，STORE=门店，CUSTOMER=客户） |
| paymentChannelId | NUMBER | 支付通道ID |

## 接口选择指引

| 用户意图 | 推荐接口 |
|----------|----------|
| "有哪些支付通道" / "启用的支付通道" | paymentChannelsSearch |
| "易宝/银联/微企付配置" | paymentChannelsSearch（查看对应分组字段） |
| "支持微信/支付宝支付吗" | paymentChannelsSearch（查看 businessList） |
| "支付通道收款对象范围" | paymentChannelsSearch（查看 receiptTargetConditions） |

## 跨接口组合示例

**场景**：确认客户下单时可用的线上支付方式
1. `paymentChannelsSearch` → 获取 status=ENABLE 的通道及其 businessList 中 status=ENABLE 的支付方式
2. 结合 `receiptTargetConditions` 确认目标机构类型（分公司/门店/客户）是否在收款范围内
