# 银行账户

本文档覆盖银行收款账户相关接口，包括收支明细、账户汇总及全部账户总汇总。

## 接口目录
- [bankAccounts](#bankaccounts) - 银行账户列表查询
- [bankAccountFlowDetail](#bankaccountflowdetail) - 银行账户收支明细
- [bankAccountSearchSummary](#bankaccountsearchsummary) - 银行账户收支汇总（按账户）
- [bankAccountStatisticsSummary](#bankaccountstatisticssummary) - 所有银行账户收支总汇总

---

## bankAccounts

**功能**：查询企业银行收款账户列表，支持按账户状态、账户类型、开户银行、银行账号等条件筛选，可选填充账户当前余额。

**典型场景**
- 查询所有可用的线下/线上银行账户
- 获取账户列表供收款单选择使用
- 查看指定机构下的银行账户及其当前余额

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| fillAccountBalance | BOOLEAN | **是** | 否 | 是否填充账户当前余额 |
| status | STRING | 否 | 否 | 账户状态（ENABLE=启用，DISABLE=停用） |
| bankName | STRING | 否 | 否 | 开户银行名称 |
| bankCardNum | STRING | 否 | 否 | 银行账号 |
| type | STRING | 否 | 否 | 账户类型（OFFLINE=线下支付，ONLINE=在线支付） |
| currentQueryOrgId | NUMBER | 否 | 否 | 当前查询对象机构ID |
| sellerIds | NUMBER | 否 | 是 | 所属机构ID列表 |

**响应数据**
- 返回类型：`ARRAY`

| 字段 | 类型 | 说明 |
|------|------|------|
| id | NUMBER | 记录ID |
| customCode | STRING | 账号编码 |
| bankAccountName | STRING | 账号用户名 |
| bankName | STRING | 开户银行 |
| bankCardNum | STRING | 银行卡号 |
| status | STRING | 账户状态（ENABLE=启用，DISABLE=停用） |
| type | STRING | 账户类型（OFFLINE=线下支付，ONLINE=在线支付） |
| initialBalance | NUMBER | 初始余额 |
| accountBalance | NUMBER | 账户当前余额（fillAccountBalance=true 时有值） |
| createId | NUMBER | 制单人ID |
| createName | STRING | 制单人姓名 |
| receiptTargetConditions | ARRAY | 收款对象设置列表 |
| receiptTargetConditions[].bankAccountId | NUMBER | 银行账户ID |
| receiptTargetConditions[].allUsersAvailable | NUMBER | 是否所有用户可用（1=是，0=指定限制） |
| receiptTargetConditions[].orgType | STRING | 收款对象机构类型 |

## bankAccountFlowDetail

**功能**：查询银行收款账户的逐笔收支明细记录，展示每笔交易的时间、金额、对手方等信息。

**典型场景**
- 查看某账户某时间段内的所有收支记录
- 找出某对手方机构的收付款记录
- 按支付方式筛选收支明细
- 查看带期初期末余额的收支详情

**参数**
| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| rangeTime | TIME_RANGE | 是 | 否 | 对账时间范围，对象包含 `startTime` 和 `endTime`，格式：`yyyy-MM-dd HH:mm:ss` |
| sellerIds | NUMBER | 否 | 是 | 所属机构IDs |
| bankAccountIds | NUMBER | 否 | 是 | 账户ids |
| fundSummaryIds | NUMBER | 否 | 是 | 支付摘要id |
| paymentMethods | STRING | 否 | 是 | 支付方式 |
| tradeCounterPartyOrgIds | NUMBER | 否 | 是 | 往来单位ids |

**响应数据**
- 返回类型：`PAGE`（分页）
| 字段 | 类型 | 说明 |
|------|------|------|
| customCode | STRING | 账户编码 |
| bankAccountName | STRING | 账户名称 |
| bankCardNum | STRING | 银行账号 |
| bankName | STRING | 开户银行 |
| createName | STRING | 制单人 |
| orgId | NUMBER | 所属机构ID |
| orgName | STRING | 所属机构名称 |
| paymentMethodCode | STRING | 结算方式编码 |
| paymentMethodName | STRING | 结算方式名称 |
| endingBalance | NUMBER | 期末结余 |
| otherOrgName | STRING | 交易对手机构名称 |
| paymentCode | STRING | 支付单号 |
| paymentStatus | STRING | 支付状态 |
| paymentTime | DATETIME | 支付时间 |
| realTradeMoney | NUMBER | 收入（为负数时，表示支出） |
| remark | STRING | 备注 |
| salesName | STRING | 业务员名称 |
| summary | STRING | 支付摘要 |

## bankAccountSearchSummary

**功能**：按账户维度汇总银行账户的期初/期末余额、本期收入/支出情况。

**典型场景**
- 查看各银行账户的收支汇总
- 了解各账户的期末余额
- 对比不同账户的本期收入

**参数**
| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| rangeTime | TIME_RANGE | 是 | 否 | 支付时间范围，对象包含 `startTime` 和 `endTime`，格式：`yyyy-MM-dd HH:mm:ss` |
| sellerIds | NUMBER | 否 | 是 | 所属机构IDs |

**响应数据**
- 返回类型：`PAGE`（分页）
| 字段 | 类型 | 说明 |
|------|------|------|
| bankAccountName | STRING | 账户名称 |
| bankCardNum | STRING | 银行卡号 |
| bankName | STRING | 开户银行 |
| beginningBalance | NUMBER | 期初余额 |
| customCode | STRING | 账户编码 |
| endingBalance | NUMBER | 期末余额 |
| expenseMoney | NUMBER | 本期支出 |
| incomeMoney | NUMBER | 本期收入 |
| initialBalance | NUMBER | 初始余额 |

---

## bankAccountStatisticsSummary

**功能**：获取所有银行账户的收支总汇总，返回合并后的期初金额、实收总额、实际收款/退款金额。

**典型场景**
- 查看所有银行账户的资金总量
- 了解本期实际收款和退款情况
- 按账户或支付方式筛选汇总

**参数**
| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| rangeTime | TIME_RANGE | 是 | 否 | 支付时间范围，对象包含 `startTime` 和 `endTime`，格式：`yyyy-MM-dd HH:mm:ss` |
| sellerIds | NUMBER | 否 | 是 | 所属机构IDs |

**响应数据**
- 返回类型：`OBJECT`
| 字段 | 类型 | 说明 |
|------|------|------|
| beginningBalance | NUMBER | 期初金额 |
| realTradeMoney | NUMBER | 实收金额 |
| receiptRealTradeMoney | NUMBER | 实际收款金额 |
| refundedRealTradeMoney | NUMBER | 实际退款金额 |

## 接口选择指引

| 用户意图 | 推荐接口 |
|----------|----------|
| "每笔收支明细" | bankAccountFlowDetail |
| "各账户收支汇总" | bankAccountSearchSummary |
| "所有账户总收款" | bankAccountStatisticsSummary |
| "某账户本期余额" | bankAccountSearchSummary（查 endingBalance）|

## 跨接口组合示例

**场景**：查看本月各银行账户收支情况及总体资金状况
1. `bankAccountStatisticsSummary` → 获取所有账户实收总额和退款总额
2. `bankAccountSearchSummary` → 查看各账户的期末余额分布
