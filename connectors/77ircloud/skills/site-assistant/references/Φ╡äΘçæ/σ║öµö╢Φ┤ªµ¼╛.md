# 应收账款

本文档覆盖应收账款相关接口，包括汇总概览、按客户明细统计和按商品维度明细。

## 接口目录
- [orgReceivablesSummary](#orgreceivablessummary) - 应收账款汇总
- [orgReceivablesList](#orgreceivableslist) - 应收账款客户明细
- [skuReceivables](#skureceivables) - 应收账款商品明细
- [orderReceivableList](#orderreceivablelist) - 应收账款明细列表（按订单分组）
- [orderReceivableStatistics](#orderreceivablestatistics) - 应收账款明细金额合计（按订单）
- [skuReceivableStatistics](#skureceivablestatistics) - 应收账款列表金额汇总（按商品维度）
- [receivableSourceTypeSubtypeSearch](#receivablesourcetypesubtypesearch) - 应收汇总按来源类型和子类型列表查询
- [receivableSourceTypeSubtypeStatistics](#receivablesourcetypesubtypestatistics) - 应收汇总按来源类型和子类型统计
- [billPreReceiptList](#billprereceiptlist) - 占用明细列表查询
- [billPreReceiptStatistics](#billprereceiptstatistics) - 占用明细统计

---

## orgReceivablesSummary

**功能**：获取应收账款的全局汇总数据，包含期初/期末应收、本期实收、本期收款、欠款客户数等核心指标。

**典型场景**
- 了解当前总体应收账款情况
- 查看本期收款完成情况
- 统计欠款客户总数

**参数**
| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| rangeTime | TIME_RANGE | 是 | 否 | 统计时间，对象包含 `startTime` 和 `endTime`，格式：`yyyy-MM-dd HH:mm:ss` |
| debtOrgFlag | BOOLEAN | 否 | 否 | 是否查询欠款单位，true=仅查欠款客户 |
| buyerTypes | STRING | 否 | 是 | 买家类型（BRANCH:分公司，STORE:门店，CUSTOMER:客户） |
| buyerIds | NUMBER | 否 | 是 | 往来单位ID集合 |
| salesId | NUMBER | 否 | 否 | 业务员ID |
| sellerOrgId | NUMBER | 否 | 否 | 卖家单位ID |
| paymentRegionIds | NUMBER | 否 | 是 | 付款方所属区域IDs |
| customerCategoryIds | NUMBER | 否 | 是 | 客户分类ids |
| tagIds | NUMBER | 否 | 是 | 客户标签ids |
| payPeriodTypeEnums | STRING | 否 | 是 | 结算模式，可选值：MONTH(月结)、CONSTANT(定期结算)、NO_CONSTANT(不固定帐期)、MONEY_BEFORE_CARGO(先款后货)、CARGO_BEFORE_MONEY(货到付款)、ROLLING(滚动结算) |

**响应数据**
- 返回类型：`OBJECT`
| 字段 | 类型 | 说明 |
|------|------|------|
| beginningReceivableMoney | NUMBER | 期初应收合计 |
| debtOrgCount | NUMBER | 欠款客户数合计 |
| endingReceivableMoney | NUMBER | 期末应收合计 |
| exemptMoney | NUMBER | 本期优惠合计 |
| availableMoney | NUMBER | 当前可用总额 |
| realTradeMoney | NUMBER | 本期实收合计 |
| receivableDecreaseMoney | NUMBER | 本期收款合计 |
| receivableIncreaseMoney | NUMBER | 本期应收合计 |

**典型场景**
- 查看哪些商品的应收账款最多
- 按商品维度统计应收账款情况

**参数**
| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|

| buyerTypes | STRING | 是 | 是 | 买家机构类型，可选值：HEADQUARTERS(总部)、BRANCH(分公司)、STORE(门店)、CUSTOMER(客户)、SUPPLIER(供应商)、MERCHANT(平台商家) |

| sourceBillType | STRING | 业务类型，可选值：RECEIPT(收款单)、PAYMENT(付款单)、SALE_ORDER(销售出库)、RETURN_ORDER(退货入库)、FREIGHT(运费) 等 |
| sourceBillRelatedCode | STRING | 关联单号 |
| sourceBillMoney | NUMBER | 来源订单金额 |
| sourceBillBuyerOrgId | NUMBER | 来源单据结算人ID |
| sourceBillBuyerOrgName | STRING | 来源单据结算人名称 |
| endingReceivableMoney | NUMBER | 期末应收 |
| receivableIncreaseMoney | NUMBER | 本期应收 |
| receivableDecreaseMoney | NUMBER | 本期收款 |
| skuCode | STRING | 商品编码 |
| skuName | STRING | 商品名称 |
| shortCode | STRING | SKU简称 |
| skuSpec | STRING | 规格 |
| unitId | NUMBER | 单位ID |
| unitName | STRING | 单位名称 |
| unitQuantity | NUMBER | 出库数量 |
| unitPrice | NUMBER | 商品单价 |
| paymentOrgName | STRING | 往来单位名称 |
| paymentOrgCode | STRING | 往来单位编码 |
| orderOrgName | STRING | 下单客户名称 |
| orderOrgCode | STRING | 下单客户编码 |
| otherReceivableBillCostTypeName | STRING | 收支类型名称 |
| remark | STRING | 备注 |

## orderReceivableList

**功能**：按订单维度分页查询应收账款明细，包含来源单据信息、往来单位、各应收金额及核销情况。

**典型场景**
- 查看某客户/机构的应收账款明细（按订单维度）
- 统计各订单的应收增加、减少及期末应收
- 查询指定时间段内的逾期欠款与核销情况

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| dateRange | TIME_RANGE | **是** | 否 | 对账时间范围 |
| sellerOrgId | NUMBER | **是** | 否 | 所属机构OrgID |
| keyword | STRING | 否 | 否 | 搜索关键字（往来单位编码/名称/联系人/联系电话），模糊搜索 |

| buyerTypes | STRING | 否 | 是 | 买家类型列表（SUPPLIER/HEADQUARTER/BRANCH/STORE/CUSTOMER） |
| sort | STRING | 否 | 否 | 排序，格式：字段:desc，支持 beginningReceivableMoney/receivableIncreaseMoney/receivableDecreaseMoney/endingReceivableMoney |

**响应数据**
- 返回类型：`PAGE`（分页）

| 字段 | 类型 | 说明 |
|------|------|------|
| sourceBillCode | STRING | 来源单据编码 |
| sourceBillType | STRING | 来源单据类型 |
| sourceBillTypeName | STRING | 来源单据类型名称 |
| sourceBillSubTypeId | STRING | 来源单据子类型ID |

| sourceBillRelatedCode | STRING | 来源单据关联订单 |

| receivableRecordId | NUMBER | 应收记录ID |
| endingReceivableMoney | NUMBER | 期末应收 |
| receivableIncreaseMoney | NUMBER | 应收增加金额 |
| receivableDecreaseMoney | NUMBER | 应收减少金额 |
| receivableExemptMoney | NUMBER | 本期优惠金额 |
| writeOffMoney | NUMBER | 已核销金额 |

- 按支付方式统计收款情况
- 分析指定买家/卖家的来源类型收款分布

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| dateRange | TIME_RANGE | **是** | 否 | 支付时间范围 |
| sellerIds | NUMBER | 否 | 是 | 卖家机构ID列表 |
| buyerIds | NUMBER | 否 | 是 | 买家机构ID列表 |
| buyerTypes | STRING | 否 | 是 | 买家机构类型列表（SUPPLIER/HEADQUARTER/BRANCH/STORE/CUSTOMER） |
| paymentRegionIds | NUMBER | 否 | 是 | 付款方所属区域ID列表 |

**响应数据**
- 返回类型：`PAGE`（分页）

| 字段 | 类型 | 说明 |
|------|------|------|
| sourceTypeId | NUMBER | 业务类型ID |
| sourceTypeName | STRING | 业务类型名称 |
| subTypeName | STRING | 子类型名称 |
| receivableMoney | NUMBER | 应收金额 |
| receiptMoney | NUMBER | 收款金额 |
| sourceBillMoney | NUMBER | 原始来源金额 |
| paymentMethodCode | STRING | 支付方式编码 |
| paymentMethodName | STRING | 支付方式名称 |
| otherReceivableCostTypeId | NUMBER | 其他应收费用类型ID |
| otherReceivableCostTypeName | STRING | 其他应收费用类型名称 |
| incomeType | NUMBER | 收入支出类型（1：收入，-1：支出） |

**前置接口**
- `receivableSourceTypeSubtypeStatistics`：同筛选参数的汇总合计 → 可联动展示列表与总计

**前置接口**

## billPreReceiptList

**功能**：查询预收款占用明细分页列表，追踪各单据占用预收款余额的明细记录，支持按应收/应付维度、单据类型、往来单位等筛选。

**典型场景**
- 查看某单据（订单/退单等）占用了多少预收款
- 查询某往来单位当前的余额占用明细
- 按时间范围查看应收或应付的占用记录

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| timeRange | TIME_RANGE | **是** | 否 | 时间范围 |
| queryType | NUMBER | **是** | 否 | 查询类型，1=应收占用明细，2=应付占用明细 |
| hasPreReceiptMoney | BOOLEAN | **是** | 否 | 是否只查询占用金额>0的数据 |
| preReceiptTypes | NUMBER | 否 | 是 | 业务类型，1=余额，2=订单收款 |
| sourceBizTypes | STRING | 否 | 是 | 单据类型，枚举：ORDER/RETURN_ORDER/FUND_ACCOUNT/OTHER_RECEIVABLE/OTHER_PAYABLE/PURCHASE_ORDER/PURCHASE_RETURN_ORDER/WRITE_OFF/RECEIPT_ACCOUNT/BUYER_ORDER/BUYER_RETURN_ORDER/BALANCE_TOP_UP/MERCHANT_ORDER/MERCHANT_RETURN_ORDER |
| sourceBizCodes | STRING | 否 | 是 | 来源单号列表 |
| receiptCodes | STRING | 否 | 是 | 收付款单号列表（余额时为-1） |
| otherOrgIds | NUMBER | 否 | 是 | 往来单位ID列表 |
| otherOrgTypes | STRING | 否 | 是 | 往来单位类型列表（SUPPLIER/HEADQUARTER/BRANCH/STORE/CUSTOMER） |
| sort | STRING | 否 | 否 | 排序，格式：createTime:desc 或 createTime:asc |

**响应数据**
- 返回类型：`PAGE`（分页）

| 字段 | 类型 | 说明 |
|------|------|------|
| sourceBizCode | STRING | 单号 |
| receiptCode | STRING | 收/付款单号 |
| preReceiptType | NUMBER | 业务类型（1：余额，2：订单收款） |
| preReceiptMoney | NUMBER | 占用金额 |
| writeOffMoney | NUMBER | 已核销金额 |
| otherOrgId | NUMBER | 往来机构ID |
| otherOrgName | STRING | 往来单位名称 |
| otherOrgType | STRING | 往来机构类型 |
| createTime | DATETIME | 创建时间 |

## billPreReceiptStatistics

**功能**：统计预收款占用明细的汇总金额，返回预收余额、占用总额和可用余额，支持与 `billPreReceiptList` 相同的筛选维度。

**典型场景**
- 查看某往来单位当前预收余额与占用情况
- 汇总某时间段内应收或应付的占用总额
- 判断当前可用余额是否充足

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| timeRange | TIME_RANGE | **是** | 否 | 时间范围 |
| queryType | NUMBER | **是** | 否 | 查询类型，1=应收占用明细，2=应付占用明细 |
| hasPreReceiptMoney | BOOLEAN | **是** | 否 | 是否只查询占用金额>0的数据 |
| preReceiptTypes | NUMBER | 否 | 是 | 业务类型，1=余额，2=订单收款 |
| sourceBizTypes | STRING | 否 | 是 | 单据类型，枚举：ORDER/RETURN_ORDER/FUND_ACCOUNT/OTHER_RECEIVABLE/OTHER_PAYABLE/PURCHASE_ORDER/PURCHASE_RETURN_ORDER/WRITE_OFF/RECEIPT_ACCOUNT/BUYER_ORDER/BUYER_RETURN_ORDER/BALANCE_TOP_UP/MERCHANT_ORDER/MERCHANT_RETURN_ORDER |
| sourceBizCodes | STRING | 否 | 是 | 来源单号列表 |
| receiptCodes | STRING | 否 | 是 | 收付款单号列表（余额时为-1） |
| otherOrgIds | NUMBER | 否 | 是 | 往来单位ID列表 |
| otherOrgTypes | STRING | 否 | 是 | 往来单位类型列表（SUPPLIER/HEADQUARTER/BRANCH/STORE/CUSTOMER） |

**响应数据**
- 返回类型：`OBJECT`

| 字段 | 类型 | 说明 |
|------|------|------|
| preBalanceMoney | NUMBER | 预收余额 |
| preReceiptMoney | NUMBER | 占用总额 |
| availableMoney | NUMBER | 可用余额 |

**前置接口**
- `billPreReceiptList`：查询占用明细列表 → 与本接口共享筛选参数，可联动使用
