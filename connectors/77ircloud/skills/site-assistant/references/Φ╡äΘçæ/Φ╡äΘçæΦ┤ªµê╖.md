# 资金账户

本文档覆盖资金账户余额查询接口，用于查看系统内各类资金账户（余额账户、返利账户等）的余额情况。

## 接口目录
- [fundReceiptAccountSummary](#fundreceiptaccountsummary) - 资金账户总余额
- [receiptAccountOrgStatistics](#receiptaccountorgstatistics) - 资金账户列表（按机构）
- [receiptAccountFlowStatisticsV2](#receiptaccountflowstatisticsv2) - 资金账户收支列表（金额汇总）
- [receiptAccountFlowStatisticsSearchV2](#receiptaccountflowstatisticssearchv2) - 资金账户收支汇总列表
- [receiptAccountFlowSearchV2](#receiptaccountflowsearchv2) - 资金账户收支明细列表

---

## fundReceiptAccountSummary

**功能**：查询系统资金账户的总余额及各子账户的余额情况，支持按账户类型和往来单位筛选。

**典型场景**
- 查看当前资金账户总余额
- 了解余额账户和返利账户各自的余额
- 按往来单位查询其资金账户余额
- 按账户类型筛选查看余额

**参数**
| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| otherOrgIds | NUMBER | 否 | 是 | 往来单位ID列表 |
| otherOrgTypes | STRING | 否 | 是 | 往来单位类型列表 |
| currentPage | NUMBER | 否 | 否 | 当前页码 |
| pageSize | NUMBER | 否 | 否 | 每页数量 |

**响应数据**
- 返回类型：`OBJECT`
| 字段 | 类型 | 说明 |
|------|------|------|
| accounts | ARRAY | 账户列表 |
| accounts[].accountBalance | NUMBER | 账户余额 |
| accounts[].accountName | STRING | 账户名称 |
| accounts[].fundAccountAccountType | STRING | 账户类型 |
| balanceAccountBalance | NUMBER | 资金账户余额 |
| totalBalance | NUMBER | 所有账户合计 |
| rebateAccountBalance | NUMBER | 返利账户余额 |

---

## 接口选择指引

| 用户意图 | 推荐接口 |
|----------|----------|
| "资金账户总余额" | fundReceiptAccountSummary（查 totalBalance）|
| "余额账户余额" | fundReceiptAccountSummary（查 balanceAccountBalance）|
| "返利账户余额" | fundReceiptAccountSummary（查 rebateAccountBalance）|
| "某客户的资金账户余额" | fundReceiptAccountSummary（传 otherOrgIds）|

## receiptAccountOrgStatistics

**功能**：按机构维度统计资金账户余额，返回每个机构的账户合计及各账户明细（累计收款、占用金额、已核销、可用余额）。

**典型场景**
- 查看各往来单位的资金账户余额汇总
- 按机构类型（门店/客户等）筛选查看账户余额
- 查看某机构下各账户（现金账户/返利账户）的收款、占用、核销及可用余额明细
- 筛选有占用金额的机构账户

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| ids | NUMBER | 否 | 是 | 账号ID集合 |
| otherOrgIds | NUMBER | 否 | 是 | 往来单位ID列表 |
| otherOrgTypes | STRING | 否 | 是 | 往来单位类型列表，枚举：SUPPLIER/HEADQUARTER/BRANCH/STORE/CUSTOMER/VOID/MERCHANT |
| accountTypeIds | NUMBER | 否 | 是 | 往来单位账户类型ID列表 |
| enable | BOOLEAN | 否 | 否 | 是否启用 |
| fundAccountAccountType | STRING | 否 | 否 | 账户类型，CASH_ACCOUNT=现金账户，REBATE_ACCOUNT=返利账户 |
| hasPreReceiptMoney | BOOLEAN | 否 | 否 | 是否有占用金额 |
| sort | STRING | 否 | 否 | 排序，格式：totalBalance:desc |
| currentPage | NUMBER | 否 | 否 | 当前页码 |
| pageSize | NUMBER | 否 | 否 | 每页数量 |

**响应数据**
- 返回类型：`PAGE`（分页）

| 字段 | 类型 | 说明 |
|------|------|------|
| otherOrgId | NUMBER | 账户机构ID |
| otherOrgType | STRING | 账户机构类型（SUPPLIER/HEADQUARTER/BRANCH/STORE/CUSTOMER/VOID/MERCHANT） |
| totalBalance | NUMBER | 账户合计 |
| accountDetails | ARRAY | 机构资金账户明细列表 |
| accountDetails[].id | NUMBER | 账户ID |
| accountDetails[].otherOrgType | STRING | 账户机构类型 |
| accountDetails[].otherOrgId | NUMBER | 账户机构ID |
| accountDetails[].receiptType | STRING | 收付款类型（RECEIPT=收款，PAYMENT=付款） |
| accountDetails[].totalMoney | NUMBER | 累计收款总额 |
| accountDetails[].preReceiptMoney | NUMBER | 当前占用金额 |
| accountDetails[].writeOffMoney | NUMBER | 已核销金额 |
| accountDetails[].balanceMoney | NUMBER | 可用余额 |
| accountDetails[].accountTypeId | NUMBER | 账户类型ID |
| accountDetails[].accountName | STRING | 账户名称 |
| accountDetails[].enable | BOOLEAN | 是否开启 |

## receiptAccountFlowStatisticsV2

**功能**：查询指定时间范围内账户余额变动的汇总统计，返回期初余额、收入、支出、期末余额的合计数据（单个汇总对象，非分页）。

**典型场景**
- 查看某时间段内资金账户的整体收支汇总
- 统计现金账户或返利账户的期初/期末余额变化
- 按买家类型或机构ID筛选查看收支统计

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| rangeTime | TIME_RANGE | **是** | 否 | 制单时间范围 |
| buyerTypes | STRING | 否 | 是 | 买家类型列表，枚举：HEADQUARTER/BRANCH/STORE/CUSTOMER |
| buyerIds | NUMBER | 否 | 是 | 买家机构ID列表 |
| receiptType | STRING | 否 | 否 | 交易类型，RECEIPT=收款，PAYMENT=付款 |
| accountTypeIds | NUMBER | 否 | 是 | 账户类型ID列表 |
| checkPermission | BOOLEAN | 否 | 否 | 是否需要权限校验，默认true |
| sort | STRING | 否 | 否 | 排序，格式：createTime:desc |
| currentPage | NUMBER | 否 | 否 | 当前页码 |
| pageSize | NUMBER | 否 | 否 | 每页数量 |

**响应数据**
- 返回类型：`OBJECT`

| 字段 | 类型 | 说明 |
|------|------|------|
| accountTypeId | NUMBER | 账户类型ID |
| accountTypeName | STRING | 账户名称 |
| fundAccountAccountType | STRING | 账户类型（CASH_ACCOUNT=现金账户，REBATE_ACCOUNT=返利账户） |
| beginningBalanceMoney | NUMBER | 期初账户余额 |
| inComeMoney | NUMBER | 收入金额 |
| expendMoney | NUMBER | 支出金额 |
| endingBalanceMoney | NUMBER | 期末账户余额 |
| canDownRecharge | BOOLEAN | 下游自主充值是否启用 |

## receiptAccountFlowStatisticsSearchV2

**功能**：按机构维度分页查询账户余额变动统计，每行显示一个机构+账户组合的期初、收入、支出、期末余额。

**典型场景**
- 查看各机构在某时间段内的资金账户收支统计
- 对比不同机构的期初/期末余额变化
- 按机构类型或业务员筛选资金账户收支

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| rangeTime | TIME_RANGE | **是** | 否 | 制单时间范围 |
| buyerTypes | STRING | 否 | 是 | 买家类型列表，枚举：HEADQUARTER/BRANCH/STORE/CUSTOMER |
| buyerIds | NUMBER | 否 | 是 | 买家机构ID列表 |
| receiptType | STRING | 否 | 否 | 交易类型，RECEIPT=收款，PAYMENT=付款 |
| accountTypeIds | NUMBER | 否 | 是 | 账户类型ID列表 |
| sort | STRING | 否 | 否 | 排序，格式：createTime:desc |
| currentPage | NUMBER | 否 | 否 | 当前页码 |
| pageSize | NUMBER | 否 | 否 | 每页数量 |

**响应数据**
- 返回类型：`PAGE`（分页）

| 字段 | 类型 | 说明 |
|------|------|------|
| otherOrgId | NUMBER | 往来单位ID |
| otherOrgType | STRING | 账户机构类型 |
| otherOrgTypeName | STRING | 账户机构类型名称 |
| otherOrgCode | STRING | 交易对手机构编码 |
| otherOrgName | STRING | 交易对手机构名称 |
| otherOrgRegion | STRING | 账户机构所属区域 |
| accountTypeId | NUMBER | 账户ID |
| accountTypeName | STRING | 账户名称 |
| salesName | STRING | 业务员名称 |
| beginningBalanceMoney | NUMBER | 期初账户余额 |
| inComeMoney | NUMBER | 收入金额 |
| expendMoney | NUMBER | 支出金额 |
| endingBalanceMoney | NUMBER | 期末账户余额 |

## receiptAccountFlowSearchV2

**功能**：分页查询账户余额流水明细，每行为一条收支记录，包含来源单号、机构、账户、收支金额、余额快照、摘要及操作人信息。

**典型场景**
- 查看某时间段内所有账户的资金流水明细
- 按机构或账户类型筛选流水记录
- 追溯某笔收支的来源业务单据
- 查看账户余额的逐笔变动

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| rangeTime | TIME_RANGE | **是** | 否 | 制单时间范围 |
| buyerTypes | STRING | 否 | 是 | 买家类型列表，枚举：HEADQUARTER/BRANCH/STORE/CUSTOMER |
| buyerIds | NUMBER | 否 | 是 | 买家机构ID列表 |
| receiptType | STRING | 否 | 否 | 交易类型，RECEIPT=收款，PAYMENT=付款 |
| summaryIds | NUMBER | 否 | 是 | 摘要ID列表 |
| accountTypeIds | NUMBER | 否 | 是 | 账户类型ID列表 |
| sort | STRING | 否 | 否 | 排序，格式：createTime:desc |
| currentPage | NUMBER | 否 | 否 | 当前页码 |
| pageSize | NUMBER | 否 | 否 | 每页数量 |

**响应数据**
- 返回类型：`PAGE`（分页）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | NUMBER | 流水ID |
| flowCode | STRING | 流水单号 |
| sourceBillCode | STRING | 来源业务单号 |
| sourceBillRelateCode | STRING | 关联源事件业务单号（多个用','间隔） |
| otherOrgId | NUMBER | 账户机构ID |
| otherOrgType | STRING | 账户机构类型 |
| otherOrgTypeName | STRING | 账户机构类型名称 |
| otherOrgCode | STRING | 交易对手机构编码 |
| otherOrgName | STRING | 交易对手机构名称 |
| otherOrgRegion | STRING | 账户机构所属区域 |
| accountTypeId | NUMBER | 账户ID |
| accountTypeName | STRING | 账户名称 |
| balanceMoneyChange | NUMBER | 收支金额（正为收入，负为支出） |
| incomeMoney | NUMBER | 本期收入 |
| expenseMoney | NUMBER | 本期支出 |
| balanceMoney | NUMBER | 账户余额（本次流水后） |
| summaryId | NUMBER | 摘要ID |
| summaryDesc | STRING | 摘要描述 |
| createId | NUMBER | 制单人ID |
| createName | STRING | 创建人名称 |
| createTime | DATETIME | 创建时间 |
| sourceBillCreateTime | DATETIME | 业务单据时间 |
| remark | STRING | 备注 |

## 跨接口组合示例

**场景**：查看当前所有资金账户的余额构成
1. `fundReceiptAccountSummary` → 不传筛选参数，获取 totalBalance（总计）、balanceAccountBalance（余额账户）、rebateAccountBalance（返利账户）及 acounts 数组中每个子账户的余额

**场景**：查看某门店本月资金账户的收支明细及汇总
1. `receiptAccountFlowStatisticsV2` → 传入 buyerTypes=[STORE] + 本月时间范围，获取期初/期末/收入/支出合计
2. `receiptAccountFlowSearchV2` → 传入相同参数，获取逐笔流水明细
