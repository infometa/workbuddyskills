# 应付账款

本文档覆盖应付账款相关接口，包括汇总概览和按供应商的明细统计。

## 接口目录
- [orderPayOrgSummary](#orderpayorgsummary) - 应付账款汇总
- [orderPayableOrgList](#orderpayableorglist) - 应付账款供应商明细
- [downOrgViewOrderPayableSearch](#downorgvieworderpayablesearch) - 应付账款明细列表（按入库）
- [downOrgViewOrderPayableStatistics](#downorgvieworderpayablestatistics) - 应付账款明细统计（按入库）
- [downOrgViewSkuPayables](#downorgviewskupayables) - 应付账款列表（按商品维度）
- [downOrgViewSkuPayablesStatistics](#downorgviewskupayablesstatistics) - 应付金额汇总（按商品维度）

---

## orderPayOrgSummary

**功能**：获取应付账款的全局汇总数据，包含期初/期末应付、本期应付、本期付款、占用金额等核心指标。

**典型场景**
- 了解当前总体应付账款情况
- 查看本期付款完成情况
- 统计占用金额总额

**参数**
| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| rangeTime | TIME_RANGE | 是 | 否 | 统计时间，对象包含 `startTime` 和 `endTime`，格式：`yyyy-MM-dd HH:mm:ss` |
| sellerIds | NUMBER | 否 | 是 | 供应商ID集合 |
| buyerOrgId | NUMBER | 否 | 否 | 买家ID |
| keyword | STRING | 否 | 否 | 搜索关键字，供应商编码/名称/联系人/联系电话 |

**响应数据**
- 返回类型：`OBJECT`
| 字段 | 类型 | 说明 |
|------|------|------|
| beginningReceivableMoney | NUMBER | 期初应付合计 |
| endingReceivableMoney | NUMBER | 期末应付合计 |
| preReceiptMoney | NUMBER | 占用金额合计 |
| realTradeMoney | NUMBER | 本期付款合计 |
| receivableIncreaseMoney | NUMBER | 本期应付合计 |

## orderPayableOrgList

**功能**：按供应商维度展示应付账款明细，包含期初/期末应付、本期应付、本期实付、占用金额等字段。

**典型场景**
- 查看各供应商的应付账款明细
- 找出应付金额最大的供应商
- 查询指定供应商的账款情况
- 了解供应商的区域分布

**参数**
| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| rangeTime | TIME_RANGE | 是 | 否 | 统计时间，对象包含 `startTime` 和 `endTime`，格式：`yyyy-MM-dd HH:mm:ss` |
| sellerIds | NUMBER | 否 | 是 | 供应商ID集合 |
| buyerOrgId | NUMBER | 否 | 否 | 买家ID |
| keyword | STRING | 否 | 否 | 搜索关键字，供应商编码/名称/联系人/联系电话 |

**响应数据**
- 返回类型：`PAGE`（分页）
| 字段 | 类型 | 说明 |
|------|------|------|
| beginningReceivableMoney | NUMBER | 期初应付 |
| contactName | STRING | 联系人 |
| contactPhone | STRING | 联系电话 |
| endingReceivableMoney | NUMBER | 期末应付 |
| paymentOrgType | STRING | 往来类型（SUPPLIER:供应商，HEADQUARTERS:总部，BRANCH:分公司，STORE:门店，CUSTOMER:客户） |
| paymentOrgCode | STRING | 供应商编码 |
| paymentOrgName | STRING | 供应商名称 |
| salesName | STRING | 供应商所属业务员名称 |
| preReceiptMoney | NUMBER | 占用金额 |
| realTradeMoney | NUMBER | 本期实付 |
| receivableIncreaseMoney | NUMBER | 本期应付 |
| exemptMoney | NUMBER | 本期优惠 |
| availableMoney | NUMBER | 预付款余额 |
| regionName | STRING | 区域名称 |

## downOrgViewOrderPayableSearch

**功能**：从买家视角按订单维度分页查询应付账款明细，包含来源单据信息、往来单位、各应付金额及核销情况。

**典型场景**
- 查看本机构需向各上游卖家支付的账款明细
- 按来源单据类型筛选应付明细
- 统计各订单的逾期金额和核销情况

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| rangeTime | TIME_RANGE | **是** | 否 | 对账时间范围 |
| buyerOrgId | NUMBER | 否 | 否 | 买家机构ID，默认当前机构 |
| sellerTypes | STRING | 否 | 是 | 卖家类型列表（SUPPLIER/HEADQUARTER/BRANCH/STORE/CUSTOMER/VOID/MERCHANT） |
| sellerIds | NUMBER | 否 | 是 | 卖家机构ID列表 |
| keyword | STRING | 否 | 否 | 搜索关键字（往来单位编码/名称/联系人/联系电话） |
| sort | STRING | 否 | 否 | 排序，格式：endingReceivableMoney:desc |
| currentPage | NUMBER | 否 | 否 | 当前页码 |
| pageSize | NUMBER | 否 | 否 | 每页数量 |

**响应数据**
- 返回类型：`PAGE`（分页）

| 字段 | 类型 | 说明 |
|------|------|------|
| sourceBillCreateTime | DATETIME | 来源单创建时间 |
| sourceBillCode | STRING | 来源单据编码 |
| sourceBillType | STRING | 来源单据类型（RECEIPT/PAYMENT/SALE_ORDER/RETURN_ORDER/FREIGHT/DIFFER_STOCK_IN/ORDER_PAYABLE/OTHER_RECEIVABLE/OTHER_PAYABLE/PURCHASE_ORDER_IN/PURCHASE_RETURN_OUT/BUYER_ORDER_PAYABLE/BUYER_RETURN_ORDER_PAYABLE/PURCHASE_ORDER_PAYABLE/PURCHASE_RETURN_ORDER_PAYABLE/ORDER_IN/REFUND_OUT/PRE_RECEIPT/PRE_PAYMENT） |
| sourceBillTypeName | STRING | 来源单据类型名称 |
| sourceBillRelatedCode | STRING | 来源单据关联订单号 |
| sourceBillSubTypeId | STRING | 来源单据子类型ID |
| sourceBillSubTypeName | STRING | 来源单据子类型名称 |
| sourceBillMoney | NUMBER | 来源订单金额 |
| receivableIncreaseMoney | NUMBER | 应收增加金额 |
| receivableDecreaseMoney | NUMBER | 应收减少金额 |
| endingReceivableMoney | NUMBER | 期末应收 |
| writeOffMoney | NUMBER | 已核销金额 |
| unWriteOffMoney | NUMBER | 未核销金额 |
| receivableExemptMoney | NUMBER | 本期优惠金额 |
| exemptAmount | NUMBER | 优惠金额 |
| realTradeAmount | NUMBER | 实收金额 |
| preReceiptMoney | NUMBER | 预收金额 |
| payPeriodMoney | NUMBER | 逾期金额 |
| incomeType | STRING | 收支类型（INCOME：收入，EXPENSE：支出） |
| fundAccountTypeId | STRING | 资金账户类型ID |
| receivableRecordId | NUMBER | 应收记录ID |
| sourceBillBuyerOrgId | NUMBER | 来源单据结算人ID |
| sourceBillBuyerOrgName | STRING | 来源单据结算人名称 |
| paymentOrgName | STRING | 往来单位名称 |
| paymentOrgCode | STRING | 往来单位编码 |
| orderOrgName | STRING | 下单客户名称 |
| orderOrgCode | STRING | 下单客户编码 |
| otherReceivableBillCostTypeName | STRING | 其他应收费用类型名称 |
| remark | STRING | 备注 |

**前置接口**
- `downOrgViewOrderPayableStatistics`：同筛选参数的金额汇总 → 可联动展示列表与总计
