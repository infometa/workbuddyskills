# 订单收款统计

本文档覆盖订单收款统计相关接口，包括明细列表查询和汇总数据统计。

## 接口目录
- [orderFundStatisticsDetail](#orderfundstatisticsdetail) - 订单收款统计列表
- [orderFundStatisticsSummary](#orderfundstatisticssummary) - 订单收款统计汇总数据

---

## orderFundStatisticsDetail

**功能**：按订单/退单维度分页查询收款统计明细，包含订单信息、往来单位、应收/已收/待收金额、付款状态等字段。

**典型场景**
- 查看某时间段内所有订单的收款明细
- 按付款状态筛选（未支付/部分支付/已支付）
- 按业务员、客户、区域等维度统计订单收款情况
- 查询指定订单号的收款详情

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| rangeTime | TIME_RANGE | **是** | 否 | 下单时间范围 |
| orderCode | STRING | 否 | 否 | 单号，精确搜索 |
| buyerTypes | STRING | 否 | 是 | 往来单位类型列表（HEADQUARTER/BRANCH/STORE/CUSTOMER） |
| buyerIds | NUMBER | 否 | 是 | 往来单位ID列表 |
| salesIds | NUMBER | 否 | 是 | 业务员ID列表 |
| salesDepartmentIds | NUMBER | 否 | 是 | 业务员部门ID列表 |
| regionIds | NUMBER | 否 | 是 | 区域ID列表 |
| cusCategoryIds | NUMBER | 否 | 是 | 客户分类ID列表 |
| settlementOrgIds | NUMBER | 否 | 是 | 结算客户ID列表 |
| warehouseIds | NUMBER | 否 | 是 | 发货仓库ID列表 |
| paymentStatus | STRING | 否 | 是 | 付款状态列表（UN_PAID/PART_PAID/PAID_CHECKING/PAID/IN_PAY/FAIL） |
| orderStatus | NUMBER | 否 | 是 | 订单状态列表（SUBMIT_PENDING/ORDER_AUDIT_PENDING/FINANCE_AUDIT_PENDING/SUPERIOR_AUDIT_PENDING/AUDITED/FINISHED/CANCELLED） |
| returnOrderPaymentStatuses | STRING | 否 | 是 | 退单付款状态列表（WAIT_PAY/PAID/PART_PAID/PAID_CHECKING） |
| returnOrderStatuses | NUMBER | 否 | 是 | 退单状态列表（SUBMIT_PENDING/ORDER_AUDIT_PENDING/RECEIPT_AUDIT_PENDING/AUDITED/FINISHED/CANCELLED） |
| orderTradeTypes | NUMBER | 否 | 是 | 交易类型列表（1：订单，2：退单） |
| currentPage | NUMBER | 否 | 否 | 当前页码 |
| pageSize | NUMBER | 否 | 否 | 每页数量 |

**响应数据**
- 返回类型：`PAGE`（分页）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | NUMBER | ID |
| orderCode | STRING | 订单号 |
| createTime | DATETIME | 下单时间 |
| orderTradeType | NUMBER | 交易类型（1：订单，2：退单） |
| orderStatus | NUMBER | 订单状态 |
| orderStatusDesc | STRING | 订单状态描述 |
| buyerId | NUMBER | 往来单位ID |
| buyerName | STRING | 往来单位名称 |
| buyerCode | STRING | 往来单位编码 |
| buyerType | STRING | 往来单位类型（HEADQUARTER/BRANCH/STORE/CUSTOMER） |
| buyerContactName | STRING | 联系人 |
| buyerPhone | STRING | 联系电话 |
| settlementOrgId | NUMBER | 结算客户ID |
| settlementOrgName | STRING | 结算客户名称 |
| productTotalAmount | NUMBER | 订货金额 |
| totalFreight | NUMBER | 运费金额 |
| payableAmount | NUMBER | 应收金额 |
| paidAmount | NUMBER | 已收金额 |
| unPaidMoney | NUMBER | 待收金额 |
| paymentStatus | NUMBER | 付款状态 |
| paymentStatusDesc | STRING | 付款状态描述 |
| salesmanName | STRING | 业务员名称 |
| warehouseId | NUMBER | 仓库ID |
| warehouseName | STRING | 仓库名称 |
| businessModelType | NUMBER | 买家机构经营模式 |
| logisticsCode | STRING | 物流编码 |

**前置接口**
- `orderFundStatisticsSummary`：同筛选参数的汇总金额 → 可联动展示列表与总计

## orderFundStatisticsSummary

**功能**：对 `orderFundStatisticsDetail` 列表的金额进行整体汇总，返回应收总计、订单应收、退单应退、已收总计、待收总计、订货金额和运费合计。

**典型场景**
- 配合 `orderFundStatisticsDetail` 在列表顶部展示汇总金额
- 快速掌握某时段内订单收款的整体情况
- 统计订单与退单的应收金额差异

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| rangeTime | TIME_RANGE | **是** | 否 | 下单时间范围 |
| orderCode | STRING | 否 | 否 | 单号 |
| buyerTypes | STRING | 否 | 是 | 往来单位类型列表（HEADQUARTER/BRANCH/STORE/CUSTOMER） |
| buyerIds | NUMBER | 否 | 是 | 往来单位ID列表 |
| salesIds | NUMBER | 否 | 是 | 业务员ID列表 |
| salesDepartmentIds | NUMBER | 否 | 是 | 业务员部门ID列表 |
| regionIds | NUMBER | 否 | 是 | 区域ID列表 |
| cusCategoryIds | NUMBER | 否 | 是 | 客户分类ID列表 |
| settlementOrgIds | NUMBER | 否 | 是 | 结算客户ID列表 |
| warehouseIds | NUMBER | 否 | 是 | 发货仓库ID列表 |
| paymentStatus | STRING | 否 | 是 | 付款状态列表（UN_PAID/PART_PAID/PAID_CHECKING/PAID/IN_PAY/FAIL） |
| orderStatus | NUMBER | 否 | 是 | 订单状态列表 |
| returnOrderPaymentStatuses | STRING | 否 | 是 | 退单付款状态列表（WAIT_PAY/PAID/PART_PAID/PAID_CHECKING） |
| returnOrderStatuses | NUMBER | 否 | 是 | 退单状态列表 |
| orderTradeTypes | NUMBER | 否 | 是 | 交易类型列表（1：订单，2：退单） |
| currentPage | NUMBER | 否 | 否 | 当前页码 |
| pageSize | NUMBER | 否 | 否 | 每页数量 |

**响应数据**
- 返回类型：`OBJECT`

| 字段 | 类型 | 说明 |
|------|------|------|
| totalPayableAmount | NUMBER | 应收金额总计 |
| totalOrderPaybleAmount | NUMBER | 订单应收 |
| totalReturnOrderPaybleAmount | NUMBER | 退单应退 |
| totalPaidAmount | NUMBER | 已收金额总计 |
| totalUnPaidMoney | NUMBER | 待收金额总计 |
| totalProductTotalAmount | NUMBER | 订货金额 |
| totalFreight | NUMBER | 运费 |

**前置接口**
- `orderFundStatisticsDetail`：查询订单收款明细列表 → 与本接口共享筛选参数，可联动使用
