# 返利账户充值

本文档覆盖返利账户相关的三个接口：返利账户配置列表查询、返利账户摘要列表查询、返利账户充值执行。前两个查询接口均支持独立查询；其返回的 `typeId`、`id` 等字段可作为充值接口 `rebateAccountIncreaseAmount` 的参数来源，充值还需配合组织机构查询获取 `otherOrgId`。

## 接口目录

- [findRebateAccountDefinitionPage](#findrebateaccountdefinitionpage) - 查询返利账户配置列表
- [findRebateAccountSummaryList](#findrebateaccountsummarylist) - 查询返利账户摘要列表
- [rebateAccountIncreaseAmount](#rebateaccountincreaseamount) - 返利账户充值

---

## findRebateAccountDefinitionPage

**功能**：查询返利账户配置列表，返回当前机构已启用的返利账户配置及对应 `typeId`。

**典型场景**
- 查询当前机构启用的返利账户配置
- 查询返利账户的启用状态、能否充值、能否为负、能否支付订单等属性

**参数**

| 参数     | 类型      | 必填 | 数组 | 说明            |
|--------|---------|----|----|---------------|
| name   | STRING  | 否  | 否  | 账号名称（默认不传）    |
| enable | BOOLEAN | 否  | 否  | 是否启用（默认 true） |

**响应数据**
- 返回类型：`PAGE`（分页）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | NUMBER | 账号ID |
| orgId | NUMBER | 机构ID |
| tenantId | NUMBER | 租户ID |
| chainId | NUMBER | 链路链ID |
| name | STRING | 账号名称 |
| accountType | STRING | 账号类型（REBATE_ACCOUNT 返利账号） |
| code | STRING | 账户编码，目前使用 typeId 填充 |
| typeId | NUMBER | 账户编码（type_id 实际值） |
| enable | BOOLEAN | 是否启用 |
| canPayOrder | BOOLEAN | 能否支付订单 |
| canRecharge | BOOLEAN | 能否充值 |
| enableNegative | BOOLEAN | 能否为负 |
| description | STRING | 账号说明 |
| canDownRecharge | BOOLEAN | 下游自主充值 |
| canPayPreOrder | BOOLEAN | 能否支付预售订单 |

## findRebateAccountSummaryList

**功能**：查询返利账户摘要列表，返回当前机构已启用的「充值摘要」列表。

**典型场景**
- 查询当前机构启用的返利充值摘要
- 按摘要名称筛选充值摘要

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| name | STRING | 否 | 否 | 摘要名称 |
| enable | BOOLEAN | 否 | 否 | 是否启用（默认 true） |

**响应数据**
- 返回类型：`ARRAY`（数组）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | NUMBER | 摘要ID |
| orgId | NUMBER | 机构ID |
| tenantId | NUMBER | 租户ID |
| chainId | NUMBER | 链路链ID |
| name | STRING | 摘要名称 |
| accountType | STRING | 账号类型（REBATE_ACCOUNT 返利账号） |
| summaryType | STRING | 摘要类型（RECHARGE_REBATE_SUMMARY 充值摘要） |
| enable | BOOLEAN | 是否启用 |
| createTime | STRING | 创建时间 |
| modifyTime | STRING | 修改时间 |

## rebateAccountIncreaseAmount

**功能**：为指定往来单位的返利账户充值，将 `amount` 加到其返利账户余额上。常用摘要场景，需配合 `findRebateAccountDefinitionPage` 获取 `accountTypeId`、`findRebateAccountSummaryList` 获取 `summaryId`，并通过组织机构查询获取 `otherOrgId`。

**典型场景**
- 为客户返利账户充值（如促销返利、活动奖励、人工调整余额）
- 为门店、分公司返利账户充值

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| accountTypeId | NUMBER | 是 | 否 | 账号类型ID（来源：`findRebateAccountDefinitionPage` 返回的 `typeId`） |
| otherOrgId | NUMBER | 是 | 否 | 往来单位ID（来源：`searchDirectUnder` 返回的 `id`，其 `hierarchyCodes` 与 `otherOrgType` 对应） |
| otherOrgType | STRING | 是 | 否 | 往来单位类型（默认 `CUSTOMER`，与 `searchDirectUnder` 的 `hierarchyCodes` 同源：`BRANCH` 分公司 / `STORE` 门店 / `CUSTOMER` 客户） |
| amount | NUMBER | 是 | 否 | 充值金额 |
| summaryId | NUMBER | 是 | 否 | 摘要ID（来源：`findRebateAccountSummaryList` 返回的 `id`） |
| remark | STRING | 否 | 否 | 备注 |

**响应数据**
- 返回类型：`VOID`（无响应数据）

## 跨接口组合示例

**场景**：为某客户返利账户充值 100 元

1. `findRebateAccountDefinitionPage` → 不传参（内部固定 `accountType=REBATE_ACCOUNT`、`enable=true`、`closePage=true`），从返回结果中取启用账户的 `typeId` 作为 `accountTypeId`
2. `findRebateAccountSummaryList` → 不传参（内部固定 `accountType=REBATE_ACCOUNT`、`summaryType=RECHARGE_REBATE_SUMMARY`、`enable=true`），从返回结果中取启用摘要的 `id` 作为 `summaryId`
3. `searchDirectUnder`（参考：[组织/组织.md](../组织/组织.md)）→ `hierarchyCodes=["CUSTOMER"]` 配合关键词查询客户，从返回结果中取客户的 `id` 作为 `otherOrgId`，并取其 `hierarchyCode` 作为 `otherOrgType`（默认 `CUSTOMER`）
4. `rebateAccountIncreaseAmount` → 传入 `accountTypeId`、`otherOrgId`、`otherOrgType="CUSTOMER"`、`amount=100`、`summaryId` 执行充值

> **默认值说明**：`rebateAccountIncreaseAmount` 接口的 `otherOrgType` 在大部分场景下为 `CUSTOMER`，调用方可以默认传 `CUSTOMER`，无需再额外调用接口反查。当充值对象为门店或分公司时，对应调用 `searchDirectUnder` 时将 `hierarchyCodes` 改为 `["STORE"]` 或 `["BRANCH"]`，并把 `otherOrgType` 设为 `STORE` / `BRANCH`。
