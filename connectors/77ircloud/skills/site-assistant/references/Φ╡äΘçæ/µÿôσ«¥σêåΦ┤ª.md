# 易宝分账

本文档覆盖易宝支付分账相关查询接口，对应 PC 端资金模块：分账跟踪表、分账明细、分账应分商品明细，以及设置中心的分账规则查询。

页面路径参考：`/bankroll/split_account_list`（跟踪表）、`/bankroll/split_account_detail`（分账明细）、`/bankroll/ledger_account_products_detail`（应分商品明细）。

## 接口目录
- [divideAccountRecordSearch](#divideaccountrecordsearch) - 分账跟踪表
- [divideAccountRecordDetailSearch](#divideaccountrecorddetailsearch) - 分账明细
- [divideReceivableSearch](#dividereceivablesearch) - 分账应分商品明细列表
- [divideReceivableStatistics](#dividereceivablestatistics) - 分账应分商品明细汇总
- [yeepayDivideAccountRuleSearch](#yeepaydivideaccountrulesearch) - 查询分账规则

---

## divideAccountRecordSearch

**功能**：查询易宝分账跟踪表，按收款维度展示待分账/处理中/已完成的分账记录，支持穿透到分账明细。

**典型场景**
- 查询某时间段内待分账或失败的分账记录
- 按订单号/收款单号定位分账跟踪记录
- 查看待分账金额、分账方、往来单位

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| rangeTime | TIME_RANGE | 是 | 否 | 收款时间范围 → `payTimeStart` / `payTimeEnd` |
| keyword | STRING | 否 | 否 | 订单号/收款单号 |
| status | STRING | 否 | 否 | 跟踪表状态：WAIT_DIVIDE_ACCOUNT/UNFINISHED/COMPLETE/FAIL/CANCEL |
| withDetail | BOOLEAN | 否 | 否 | 是否携带分账明细（列表默认 true） |
| currentPage | NUMBER | 否 | 否 | 当前页码 |
| pageSize | NUMBER | 否 | 否 | 每页数量 |

**响应数据**：`PAGE`，主要字段 `billCode`、`receiptCode`、`billOrgName`、`payMoney`、`status`、`divideAccountStatus`、`pendingDivideMoney`、`headDivideOrgName`

## divideAccountRecordDetailSearch

**功能**：查询分账明细列表，展示每笔分账请求下各接收方的分账金额与状态。支持按创建时间、交易时间、收款时间、计划分账时间筛选（页面切换时间类型）。

**典型场景**
- 查看分账成功/失败明细
- 按分账请求号或收款单号查询
- 从跟踪表穿透查询（传 `keyword` 或 `recordId`）

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| rangeTime | TIME_RANGE | 否 | 否 | 时间范围（字段名随时间类型：createTimeStart/End、tradeTimeStart/End、payTimeStart/End、scheduleDivideAccountStartTime/EndTime） |
| keyword | STRING | 否 | 否 | 分账请求号/收款商户号/订单号/收款单号 |
| status | STRING | 否 | 否 | WAIT_DIVIDE/PROCESSING/FAIL/SUCCESS/FAIL_REPEAT/CANCEL |
| tradeType | STRING | 否 | 否 | DIVIDE_ACCOUNT（分账）/DIVIDE_ACCOUNT_RETURN（归还）/DIVIDE_ACCOUNT_COMPLETE（完结） |
| recordId | NUMBER | 否 | 否 | 分账记录 ID |

## divideReceivableSearch

**功能**：按商品维度查询分账应分明细，展示订单/退单维度的应分金额。

**典型场景**
- 查看某商家/商品的分账应分金额
- 按订单号、收款单号追溯应分记录
- 配合 `divideReceivableStatistics` 查看汇总

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| rangeTime | TIME_RANGE | 是 | 否 | 交易时间 → `createTimeStart` / `createTimeEnd`（最长 1 个月） |
| billKeyword | STRING | 否 | 否 | 订单/退单/收款单/供货方单号 |
| skuKeyword | STRING | 否 | 否 | 商品编码/名称/条形码 |
| merchantIds | NUMBER | 否 | 是 | 商户 ID 列表 |
| relateTradeTypes | NUMBER | 否 | 是 | 交易类型 |

**响应数据**：`PAGE`，主要字段 `billCode`、`productName`、`productCode`、`divideReceivableAmount`、`relateTradeTypeName`

---

## divideReceivableStatistics

**功能**：与应分商品明细列表相同筛选条件下的金额汇总。

**响应数据**：`OBJECT`

| 字段 | 说明 |
|------|------|
| orderDivideReceivableAmount | 订单应分 |
| cancleDivideReceivableAmount | 订单应退 |
| returnDivideReceivableAmount | 退单应退 |
| totalDivideReceivableAmount | 合计金额 |

## yeepayDivideAccountRuleSearch

**功能**：查询易宝分账规则配置（设置中心 `subAccountSetting`），返回各商户号下的供应商分账、平台商家分账及利润分账规则。

**典型场景**
- 查询某易宝商户号的分账规则是否开启
- 获取供应商直发分账、利润分账规则明细

**参数**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| profitSharingChannel | STRING | 否 | 固定传 `YEEPAY`（默认） |
| withRule | BOOLEAN | 否 | 是否返回规则明细，默认 true |
| partyAccountCode | STRING | 否 | 主商户号 |
| currentPage | NUMBER | 否 | 页码 |
| pageSize | NUMBER | 否 | 每页数量 |

**响应数据**：`PAGE`，`activityType` 含 SUPPLIER_DIVIDE_ACCOUNT（供应商分账）、MERCHANT_DIVIDE_ACCOUNT（平台商家分账）；`divideAccountRules` 为规则明细列表。

## 接口选择指引

| 用户意图 | 推荐接口 |
|----------|----------|
| 易宝分账跟踪表 | divideAccountRecordSearch |
| 易宝分账明细 | divideAccountRecordDetailSearch |
| 易宝分账应分商品 | divideReceivableSearch + divideReceivableStatistics |
| 易宝分账规则 | yeepayDivideAccountRuleSearch（profitSharingChannel=YEEPAY） |

## 跨接口组合示例

**场景**：从跟踪表查到失败分账，再查明细原因
1. `divideAccountRecordSearch` → 筛选 status=FAIL，获取 `receiptCode`
2. `divideAccountRecordDetailSearch` → 传 keyword=receiptCode，查看失败明细及 remark
