# 应收账龄分析

本文档覆盖应收账龄分析接口，用于按机构维度查询应收账款的账龄分布情况，包括期初/期末应收、收支变动及各时间段的已核销/未核销金额。

## 接口目录
- [receivableAgingAnalysis](#receivableaginganalysis) - 应收账龄分析列表

---

## receivableAgingAnalysis

**功能**：按机构分页查询应收账龄分析数据，每行包含一个往来机构的应收汇总（期初、增减、期末、实收、优惠）、账户余额明细，以及按当月/上月/2月/3月/6月/9月/12月/1年前等时间维度分段的已核销和未核销金额，用于分析应收账款的回款情况和逾期风险。

**典型场景**
- 查看各客户/门店当前期末应收及逾期账期金额
- 分析某时间段内哪些客户有长期未核销的应收款（账龄风险排查）
- 筛选欠款单位，查看其账龄分布
- 按业务员维度统计其负责客户的应收账龄情况
- 查看某机构的预收余额与可用余额

## 接口选择指引

| 用户意图 | 推荐接口 |
|----------|----------|
| "查看客户账龄/逾期情况" | receivableAgingAnalysis |
| "哪些客户有长期未还款" | receivableAgingAnalysis（查 oneYearAgoUnWriteOffMoney > 0） |
| "某客户的期末应收金额" | receivableAgingAnalysis（查 endingReceivableMoney） |
| "筛选欠款客户" | receivableAgingAnalysis（传 debtOrgFlag=true） |
| "某业务员负责客户的账龄" | receivableAgingAnalysis（传 salesIds） |
