# 银联分账

本文档覆盖银联商务分账相关查询接口，对应 PC 端资金模块：分账跟踪表、分账应分明细、分账应分商品明细、分账账单，以及设置中心的分账规则查询。

页面路径参考：`/chinaums/split-tracking`（跟踪表）、`/chinaums/split-account-by-order`（应分明细）、`/bankroll/ledger_account_products_detail_v2`（应分商品明细）、`/chinaums/split-bill`（分账账单）。

## 接口目录
- [divideAccountRecordPage](#divideaccountrecordpage) - 分账跟踪表
- [divideReceivableV3Search](#dividereceivablev3search) - 分账应分明细列表
- [divideReceivableV3Statistics](#dividereceivablev3statistics) - 分账应分明细汇总
- [divideReceivableSkuV3Search](#dividereceivableskuv3search) - 分账应分商品明细列表
- [divideReceivableSkuV3Statistics](#dividereceivableskuv3statistics) - 分账应分商品明细汇总
- [divideBillsSearch](#dividebillssearch) - 分账账单列表
- [divideBillsStatistics](#dividebillsstatistics) - 分账账单汇总
- [chinaumsDivideAccountRuleSearch](#chinaumsdivideaccountrulesearch) - 查询分账规则

---

## divideAccountRecordPage

**功能**：查询银联分账跟踪表（V3），按收款记录维度展示客户订单/商家订单关联的分账进度，支持跳转应分明细。

**典型场景**
- 查询某时间段银联分账跟踪记录
- 按客户订单号/商家订单号/收款单号搜索
- 筛选应分数据异常记录（divideDataStatus）

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| rangeTime | TIME_RANGE | 是 | 否 | 创建时间 → `createTimeStart` / `createTimeEnd` |
| keyword | STRING | 否 | 否 | 订单号/商家订单号/收款单号 |
| receiptCode | STRING | 否 | 否 | 收款单号 |
| otherOrgIds | NUMBER | 否 | 是 | 往来单位 ID |
| currentPage | NUMBER | 否 | 否 | 页码 |
| pageSize | NUMBER | 否 | 否 | 每页数量 |

**响应数据**：`PAGE`，主要字段 `billCode`（客户订单）、`merchantOrderCode`、`receiptCode`、`divideDataStatus`、`divideStatus`、`dividedAmount`

## divideReceivableV3Search

**功能**：按订单维度查询银联分账应分明细（页面默认「按订单」Tab），展示商家订单/退单等业务类型的应分金额。

**典型场景**
- 查看商家订单维度的应分/已分金额
- 按付账方、收账方、分账状态筛选
- 从跟踪表穿透（传 keyword=商家订单号）

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| rangeTime | TIME_RANGE | 是 | 否 | 时间范围（字段名由 timeRangeType 决定） |
| timeRangeType | STRING | 否 | 否 | sourceBillCreateTime/orderCreateTime/orderAuditTime/scheduleDivideAccountTime/divideCompleteTime |
| keyword | STRING | 否 | 否 | 订单号/商家订单号/收款单号 |
| headDivideAccountIds | NUMBER | 否 | 是 | 付账方商户账号 ID |
| dividePayeeAccountIds | NUMBER | 否 | 是 | 收账方商户账号 ID |
| divideStatuses | STRING | 否 | 是 | NOT_DIVIDED/PARTIALLY_DIVIDED/DIVIDED/NOT_NEED_DIVIDED |
| relateBusinessTypes | STRING | 否 | 是 | MERCHANT_ORDER/MERCHANT_RETURN_ORDER 等 |
| withDetails | BOOLEAN | 否 | 否 | 是否加载商品明细 |

---

## divideReceivableV3Statistics

**功能**：应分明细列表相同筛选条件下的应分/已分金额汇总。

**响应**：`totalDivideAmount`（应分汇总）、`totalDividedAmount`（已分汇总）

---

## divideReceivableSkuV3Search

**功能**：按商品 SKU 维度查询分账应分商品明细。

**典型场景**
- 查看某商品在各商家订单中的应分金额
- 按商品编码/名称筛选应分记录

**参数**：与应分明细类似，额外支持 `productKeyword`（商品名称/编码/条形码）

---

## divideReceivableSkuV3Statistics

**功能**：应分商品明细相同筛选条件下的金额汇总。

---

## divideBillsSearch

**功能**：查询银联分账账单列表，按账单周期汇总付账方与收账方之间的应分金额。

**典型场景**
- 查看待分账/分账成功/分账失败的账单
- 按账单号、付账方、收账方筛选
- 按计划分账日期或分账完成日期查询

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| rangeTime | TIME_RANGE | 是 | 否 | 创建时间或计划分账/完成时间（页面 timeType 切换） |
| billSerialNumber | STRING | 否 | 否 | 账单号 |
| headDivideAccountIds | NUMBER | 否 | 是 | 付账方商户账号 ID |
| dividePayeeAccountIds | NUMBER | 否 | 是 | 收账方商户账号 ID |
| dividedStatus | STRING | 否 | 是 | 1~8，见下方枚举 |

**账单分账状态 dividedStatus**：1=待分账，2=无需分账，3=待抵充，4=已抵充，5=分账中，6=分账失败，7=分账成功，8=发起分账失败

---

## divideBillsStatistics

**功能**：分账账单列表相同筛选条件下的汇总统计。

**响应**：`billCount`、`totalAmount`、`waitingDivideAmount`、`finishedDivideAmount`、`failedDivideAmount`

---

## chinaumsDivideAccountRuleSearch

**功能**：查询银联商务分账规则（设置中心 `subAccountSettingV2`），按银联商户号返回平台商家分账规则。

**参数**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| profitSharingChannel | STRING | 否 | 固定传 `CHINAUMS`（默认） |
| withRule | BOOLEAN | 否 | 是否返回规则明细 |
| partyAccountCode | STRING | 否 | 银联主商户号 |

**响应**：`activityType=MERCHANT_DIVIDE_ACCOUNT` 为平台商家分账；`divideAccountRules` 含利润分账规则。

## 接口选择指引

| 用户意图 | 推荐接口 |
|----------|----------|
| 银联分账跟踪表 | divideAccountRecordPage |
| 银联分账应分明细 | divideReceivableV3Search + divideReceivableV3Statistics |
| 银联分账应分商品明细 | divideReceivableSkuV3Search + divideReceivableSkuV3Statistics |
| 银联分账账单 | divideBillsSearch + divideBillsStatistics |
| 银联分账规则 | chinaumsDivideAccountRuleSearch |

---

## 跨接口组合示例

**场景**：从跟踪表追溯应分明细与账单
1. `divideAccountRecordPage` → 获取 `merchantOrderCode`
2. `divideReceivableV3Search` → keyword=商家订单号，查看应分明细
3. 从应分明细 `billSerialNumber` → `divideBillsSearch` 查对应账单
