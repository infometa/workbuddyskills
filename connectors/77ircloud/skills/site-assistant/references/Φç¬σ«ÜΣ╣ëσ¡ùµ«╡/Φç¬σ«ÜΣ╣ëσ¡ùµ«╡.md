# 自定义字段与元数据定义

本文档覆盖业务对象元数据定义查询接口，用于获取对象的基本信息、字段定义。当需要了解某个业务对象（如客户、商品、订单）有哪些自定义字段、字段的 apiName 与类型、选项值时使用本接口；并说明如何在支持 `searchPlans`（高级筛选）的列表接口中，用自定义字段构造筛选条件。

## 接口目录
- [getUseMetadata](#getusemetadata) - 获取业务对象自定义字段定义
- [searchPlans 高级筛选](#searchplans-高级筛选用自定义字段查询) - 用自定义字段构造列表高级筛选条件
- [irObjects 自定义字段提交](#irobjects-自定义字段提交) - 在提交类接口中写入自定义字段值

---

## getUseMetadata

**功能**：按业务对象 apiName 查询其自定义字段定义，返回对象基本信息、自定义字段。

**典型场景**
- 查询某业务对象（客户/商品/订单等）有哪些自定义字段及其 apiName、类型
- 获取自定义下拉字段的选项值（value/label），用于筛选或录入时的取值校验

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|---|------|------|
| objectApiName | STRING | 是 | 否 | 业务对象apiName |

**响应数据**
- 返回类型：`OBJECT`

| 字段 | 类型 | 说明                                                           |
|------|------|--------------------------------------------------------------|
| name | STRING | 对象名称                                                         |
| objectApiName | STRING | 对象apiName                                                    |
| status | BOOLEAN | 对象是否启用                                                       |
| describe | STRING | 对象描述                                                         |
| fields | ARRAY | 字段定义列表                                                       |
| fields[].apiName | STRING | 字段apiName                                                    |
| fields[].label | STRING | 字段显示名称                                                       |
| fields[].type | STRING | 字段类型，见下方「字段类型说明」                                             |
| fields[].helpText | STRING | 字段帮助文本                                                       |
| fields[].defaultValue | STRING | 默认值                                                          |
| fields[].required | BOOLEAN | 是否必填                                                         |
| fields[].enabled | BOOLEAN | 是否启用                                                         |
| fields[].dataSource | STRING | 数据来源（USER_INPUT:用户输入 SYSTEM_GENERATED:系统生成）                  |
| fields[].authorization | STRING | 权限（READWRITE:读写 READONLY:只读 INVISIBLE:不可见）                   |
| fields[].options | ARRAY | 下拉选项列表（SelectField/MultiSelectField/ReferenceField 等选择类字段返回） |
| fields[].options[].value | STRING | 选项值（筛选/录入时传此值）                                               |
| fields[].options[].label | STRING | 选项名称                                                         |
| fields[].options[].active | BOOLEAN | 选项是否启用                                                       |
| fields[].options[].selected | BOOLEAN | 是否默认选中                                                       |
| fields[].maxLength | NUMBER | 最大长度/整数位位数（文本类、数值类字段返回）                                      |
| fields[].scale | NUMBER | 小数位数（DoubleField 返回）                                         |
| fields[].dateFormat | STRING | 日期格式（DateField/DateTimeField 返回，如 yyyy-MM-dd、yyyy-MM-dd HH:mm）                |

**字段类型说明（fields[].type 常见值）**

| type | 说明 |
|------|------|
| TextField | 单行文本 |
| MultilineTextField | 多行文本 |
| LongField | 整数 |
| DoubleField | 小数 |
| DateField | 日期 |
| DateTimeField | 日期时间 |
| BoolField | 布尔 |
| SelectField | 单选下拉 |
| MultiSelectField | 多选下拉 |
| EmailTextField / PhoneTextField / WebsiteTextField | 邮箱 / 电话 / 网址 |

**使用说明**
- **选项取值**：选择类字段用于筛选或录入时，必须传 `options[].value`（实际值），不得传 label。

## 支持自定义字段查询的 searchPlans 高级筛选

### 传入形态

`searchPlans` 的值是**条件数组序列化后的 JSON 字符串**，每个元素形如 `{"key": 字段apiName, "value": 条件值}`：

```json
[
  {"key": "c_1l8cmej", "value": {"min": 10, "max": 100}},
  {"key": "c_1j1rsvr", "value": {"startTime": "2025-01-01 00:00:00", "endTime": "2025-01-31 23:59:59"}}
]
```

- **key**：字段 apiName，必须与元数据定义完全一致（含前缀）。自定义字段来自 `getUseMetadata`。
- 多个条件之间为 **AND** 关系。

### value 按字段类型取值

| 字段类型 | value 形态                                                                                         | 说明                                                 |
|------|--------------------------------------------------------------------------------------------------|----------------------------------------------------|
| SelectField / MultiSelectField | 选项 value(String) 数组，如 `["2349638062275040"]`                                                     | 单选也传数组；必须传 `options[].value`，不得传 label；命中任一即匹配（IN） |
| LongField / DoubleField | `{"min": 10, "max": 100}`                                                                        | min/max 可只传其一；闭区间（>= min、<= max）                   |
| TextField / MultilineTextField / EmailTextField / PhoneTextField / WebsiteTextField / SerialNumberField | 字符串                                                                                              | 模糊匹配（LIKE）                                         |
| DateField / DateTimeField | 固定按 **TIME_RANGE** 类型格式：`{"startTime": "yyyy-MM-dd HH:mm:ss", "endTime": "yyyy-MM-dd HH:mm:ss"}` | 与 TIME_RANGE 参数输入完全一致，见下方「日期条件」                    |
| BoolField | `true` / `false`                                                                                 |                                                    |
| ReferenceField | 不支持检索  | 不支持检索|

### 日期条件（DateField / DateTimeField）

时间类型的查询**固定按 TIME_RANGE 类型处理**：value 传 `startTime`/`endTime` 时间字符串，与 TIME_RANGE 参数（见 [必读规范.md](../必读规范.md)）的输入**完全一致**，两者均必填：

```json
{"startTime": "2025-01-01 00:00:00", "endTime": "2025-01-31 23:59:59"}
```

## irObjects 自定义字段提交

**参数**：`irObjects` 是 `{字段apiName: 值}` 结构化对象，key 必须与元数据定义的自定义字段 apiName 完全一致.
**可提交字段**: dataSource = USER_INPUT && authorization = READWRITE

```json
{
  "irObjects": {
    "c_memo": "重点客户",
    "c_height": 180,
    "c_level": "2",
    "c_birthday": "2024-01-02"
  }
}
```

### value 按字段类型转换校验

| 字段类型 | 值                                  |
|------|------------------------------------|
| TextField / MultilineTextField / EmailTextField / PhoneTextField / WebsiteTextField / SerialNumberField | 字符串 |
| LongField | 整数                                 |
| DoubleField | 数字                                 |
| BoolField | `true` / `false`                   |
| SelectField | `options[].value`（必须传选项值，不得传 label） |
| MultiSelectField | `options[].value` 数组（逐项校验；传单个值亦可）  | 
| DateField / DateTimeField | **按字段定义的 `dateFormat` 格式  |
