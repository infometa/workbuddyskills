# 客户导出接口

本文档覆盖客户导出相关接口，支持按多种筛选条件异步导出客户列表数据。

## customerConditionsExport - 客户列表按条件导出

### 接口描述
按条件导出客户列表数据，支持多种筛选条件和导出类型。

### 筛选条件获取指引

**重要：当用户要求按照客户分类、客户标签、业务员、区域进行筛选导出时，必须先查询对应的ID，再调用本接口。**

#### 查询客户分类ID
- **查阅路径**：`../客户与商机/客户.md` → `customerCategoryList` 接口
- **说明**：调用 `customerCategoryList` 获取全量客户分类列表
- **返回字段**：`id`（分类ID）、`name`（分类名称）
- **使用方式**：根据用户提供的分类名称，找到对应的 `id`，然后传入本接口的 `customerCategoryIds` 参数

#### 查询客户标签ID
- **查阅路径**：`../客户与商机/客户.md` → `customerTagList` 接口
- **说明**：调用 `customerTagList` 获取全量客户标签列表
- **返回字段**：`id`（标签ID）、`name`（标签名称）
- **使用方式**：根据用户提供的标签名称，找到对应的 `id`，然后传入本接口的 `tagIds` 参数

#### 查询业务员ID
- **查阅路径**：`../员工部门/员工.md` → `employeeList` 接口
- **说明**：调用 `employeeList` 查询员工列表，可按姓名、手机号、工号搜索
- **返回字段**：`id`（员工ID）、`name`（员工名称）、`mobile`（电话号码）
- **使用方式**：根据用户提供的业务员名称，找到对应的 `id`，然后传入本接口的 `salesIds` 参数

#### 查询区域ID
- **查阅路径**：`../客户与商机/地区.md` → `regionList` 接口
- **说明**：调用 `regionList` 获取全量客户区域列表
- **返回字段**：`id`（区域ID）、`name`（区域名称）
- **使用方式**：根据用户提供的区域名称，找到对应的 `id`，然后传入本接口的 `regionIds` 参数

### 调用示例

**场景**：导出"重要客户"分类下的客户
1. 调用 `customerCategoryList` → 找到"重要客户"分类的 `id`
2. 调用本接口 `customerConditionsExport` → 传入 `customerCategoryIds=[分类ID]`

**场景**：导出带有"VIP"标签的客户
1. 调用 `customerTagList` → 找到"VIP"标签的 `id`
2. 调用本接口 `customerConditionsExport` → 传入 `tagIds=[标签ID]`

**场景**：导出业务员"张三"负责的客户
1. 调用 `employeeList` → 找到"张三"的 `id`
2. 调用本接口 `customerConditionsExport` → 传入 `salesIds=[业务员ID]`

**场景**：导出"朝阳区"区域的客户
1. 调用 `regionList` → 找到"朝阳区"区域的 `id`
2. 调用本接口 `customerConditionsExport` → 传入 `regionIds=[区域ID]`

### 请求参数

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|

| customerCategoryIds | NUMBER | 否 | 是 | 根据客户分类id批量查询客户信息，需先用 customerCategoryList 获取 |
| regionIds | NUMBER | 否 | 是 | 区域id数组，需先用地区列表获取 |
| status | NUMBER | 否 | 否 | 客户状态（0:禁用 1:启用） |
| userNames | STRING | 否 | 是 | 用户名数组 |
| salesIds | NUMBER | 否 | 是 | 业务员id集合，需先用员工列表获取 |
| tagIds | NUMBER | 否 | 是 | 客户标签数组，需先用 customerTagList 获取 |
| sourceType | NUMBER | 否 | 是 | 客户来源数组 |
| userStatus | NUMBER | 否 | 否 | 账号状态 |
| contactName | STRING | 否 | 否 | 联系人名称 |
| contactPhone | STRING | 否 | 否 | 联系人手机号码 |
| referrerIds | NUMBER | 否 | 是 | 推荐人id数组 |
| routeIds | NUMBER | 否 | 是 | 配送线路id数组 |
| logisticsCode | STRING | 否 | 否 | 物流编码 |
| payPeriodTypes | STRING | 否 | 是 | 结算模式数组（MONTH:月结，CONSTANT:定期结算，NO_CONSTANT:不固定账期，MONEY_BEFORE_CARGO:先款后货，CARGO_BEFORE_MONEY:货到付款，ROLLING:滚动结算） |
| certStatus | NUMBER | 否 | 否 | 认证状态 |
| bindQyWechat | BOOLEAN | 否 | 否 | 是否绑定企业微信 |
| createRangeTime | TIME_RANGE | 否 | 否 | 创建时间范围，需传 startTime 和 endTime，格式：yyyy-MM-dd HH:mm:ss |
| franchiseRangeTime | TIME_RANGE | 否 | 否 | 加盟时间范围，需传 startTime 和 endTime，格式：yyyy-MM-dd HH:mm:ss |

### 响应数据

- 返回类型：`OBJECT`

| 字段 | 类型 | 说明 |
|------|------|------|
| key | STRING | 任务标识 |
| name | STRING | 任务名称 |
| type | NUMBER | 任务类型（1:导出 2:导入） |
| status | NUMBER | 任务状态（0:已加入 1:等待执行 2:执行中 3:成功 4:失败） |
| progress | NUMBER | 进度（执行中时有效） |
| read | NUMBER | 已读状态(已完成下有效)（0:未下载 1:已下载 2:过期） |

### 使用场景
当需要按特定条件筛选并导出客户数据时使用此接口。接口会返回一个异步任务信息，可通过任务标识查询导出进度和下载结果。

### 注意事项
1. 该接口为异步导出，返回的是任务信息而非直接的导出数据
2. 需要通过返回的key值查询任务状态和下载导出的文件
3. 导出类型type=0为原有逻辑导出，type=1为按客户列表批量修改模板导出
4. 支持多种筛选条件组合，包括基础信息、时间范围、状态等
