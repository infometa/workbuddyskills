# 退单导出接口

本文档覆盖退单导出相关接口，支持按多种筛选条件异步导出退单列表数据。

## 接口目录
- [returnOrderListExport](#returnOrderListExport) - 退单列表导出

---

## returnOrderListExport - 退单列表导出

### 接口描述
按条件导出退单列表数据，支持丰富的筛选条件，包括创建时间、退单状态、出库状态、收货状态、退款状态、客户、商品SKU、业务员等。

### 参数

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| createTime | TIME_RANGE | 否 | 否 | 退单创建时间范围，对象包含 `startTime` 和 `endTime`，格式：`yyyy-MM-dd HH:mm:ss` |
| orderCodes | STRING | 否 | 是 | 退单号列表 |
| buyerIds | NUMBER | 否 | 是 | 买方机构ID列表 |
| buyerTypes | STRING | 否 | 是 | 退货方类型列表（CUSTOMER=客户/BRANCH=分公司/STORE=门店） |
| customerCategoryId | NUMBER | 否 | 是 | 客户分类ID列表 |
| buyerRegionIds | NUMBER | 否 | 是 | 买方区域ID列表 |
| orderStatus | STRING | 否 | 是 | 退单状态列表，枚举值：ORDER_AUDIT_PENDING(待退单审核)/RECEIPT_AUDIT_PENDING(待收货审核)/AUDITED(已审核)/FINISHED(已完成)/CANCELLED(已作废) |
| stockOutStatus | STRING | 否 | 是 | 出库状态列表，枚举值：NONE(未出库)/PART(部分出库)/FULL(全部出库) |
| deliveryStatus | STRING | 否 | 是 | 收货状态列表（UNRECEIVE=未收货/RECEIVED=已收货） |
| paymentStatuses | STRING | 否 | 是 | 退款状态列表，枚举值：WAIT_PAY(未退款)/PART_PAID(部分退款)/PAID(已退款)/PAID_CHECKING(待确认) |
| skuIds | NUMBER | 否 | 是 | SKU ID 列表 |
| salesmanIds | NUMBER | 否 | 是 | 下单业务员ID列表 |
| creatorIds | NUMBER | 否 | 是 | 制单人ID列表 |
| storageBillNumList | STRING | 否 | 是 | 出库单号列表 |
| lowerReturnOrderCode | STRING | 否 | 否 | 下游退单单号 |
| lowerReturnOrderCodes | STRING | 否 | 是 | 下游退单单号列表 |
| relatedCode | STRING | 否 | 否 | 关联单号（原单退货对应来源订单号） |
| relatedCodes | STRING | 否 | 是 | 关联单号列表 |
| vehicleOrderCode | STRING | 否 | 否 | 关联车销单号 |
| vehicleOrderCodes | STRING | 否 | 是 | 关联车销单号列表 |
| payPeriodTypes | STRING | 否 | 是 | 结算模式列表（MONTH=月结/CONSTANT=定期结算/NO_CONSTANT=不固定帐期/MONEY_BEFORE_CARGO=先款后货/CARGO_BEFORE_MONEY=货到付款/ROLLING=滚动结算） |
| storageWarehouseIds | NUMBER | 否 | 是 | 入库仓库ID列表 |

### 响应数据

- 返回类型：`OBJECT`

| 字段 | 类型 | 说明 |
|------|------|------|
| key | STRING | 任务标识 |
| name | STRING | 任务名称 |
| type | NUMBER | 任务类型（1:导出 2:导入） |
| status | NUMBER | 任务状态（0:已加入 1:等待执行 2:执行中 3:成功 4:失败） |
| progress | NUMBER | 进度（执行中时有效） |
| read | NUMBER | 已读状态(已完成下有效)（0:未下载 1:已下载 2:过期） |

### ID类型参数获取途径

退单导出接口中有多个需要传入ID的筛选参数，以下是各ID的获取方式：

| ID参数 | 说明 | 获取方式 |
|--------|------|----------|
| buyerIds | 买方机构id | 通过 `searchDirectUnder` 接口查询（见[组织/组织.md](../组织/组织.md)），按 `hierarchyCodes` 筛选机构类型 |
| customerCategoryId | 客户分类id | 通过 `customerCategoryList` 接口查询客户分类列表 |
| buyerRegionIds | 买方区域id | 通过 `regionList` 接口查询区域列表（见[客户与商机/区域.md](../客户与商机/区域.md)） |
| skuIds | 商品SKU id | 通过 `productList` 接口查询（见[商品/商品.md](../商品/商品.md)），获取返回的 `id` 字段 |
| salesmanIds | 下单业务员id | 通过 `employeeList` 接口查询员工信息（见[员工部门/员工.md](../员工部门/员工.md)） |
| creatorIds | 制单人id | 通过 `employeeList` 接口查询（见[员工部门/员工.md](../员工部门/员工.md)） |
| storageWarehouseIds | 入库仓库id | 通过 `findWarehouses` 接口查询（见[仓库/仓库.md](../仓库/仓库.md)） |
