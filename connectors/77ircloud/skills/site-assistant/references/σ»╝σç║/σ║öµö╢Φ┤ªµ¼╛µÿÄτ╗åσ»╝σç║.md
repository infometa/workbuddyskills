## skuReceivablesExport - 应收账款明细导出-按商品维度

**功能**：按条件导出应收账款明细（按商品维度）数据，包含商品信息、来源单据、应收财务数据等字段。接口会返回一个异步任务信息，可通过导出任务进度查询接口轮询获取导出结果。

**典型场景**
- 按买家机构导出应收账款商品维度明细
- 异步导出后通过任务进度查询下载文件

**参数**
| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| rangeTime | TIME_RANGE | 是 | 否 | 对账创建时间范围 |
| buyerTypes | STRING | 是 | 是 | 买家机构类型 |
| buyerIds | NUMBER | 是 | 是 | 买家机构ID集合 |

**响应数据**
- 返回类型：`OBJECT`
| 字段 | 类型 | 说明 |
|------|------|------|
| key | STRING | 任务标识 |
| name | STRING | 任务名称 |
| type | NUMBER | 任务类型（1:导出 2:导入） |
| status | NUMBER | 任务状态（0:已加入 1:等待执行 2:执行中 3:成功 4:失败） |
| progress | NUMBER | 进度（执行中时有效） |
| read | NUMBER | 已读状态（0:未下载 1:已下载 2:过期） |
