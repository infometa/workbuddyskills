# 导出任务查询接口

## 接口目录
- [exportTaskProgress](#exportTaskProgress) - 导出任务进度查询

### 接口描述
查询异步导出任务的执行进度和结果。通过导出接口返回的key值来查询任务状态，当任务完成时可获取文件下载地址。

### 请求参数

#### Path参数

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| taskKey | STRING | 是 | 否 | 任务标识（导出接口返回的key字段） |

### 响应数据

- 返回类型：`OBJECT`

| 字段 | 类型 | 说明 |
|------|------|------|
| key | STRING | 任务标识 |
| name | STRING | 任务名称（导出文件名） |
| type | NUMBER | 任务类型（1:导出 2:导入） |
| status | NUMBER | 任务状态（0:已加入 1:等待执行 2:执行中 3:成功 4:失败） |
| progress | NUMBER | 进度（执行中时有效，0-100） |
| read | NUMBER | 已读状态（0:未下载 1:已下载 2:过期） |
| result | OBJECT | 结果描述（成功或失败时存在） |
| result.message | STRING | 结果消息（如"导出成功"） |
| result.filePath | STRING | 文件下载地址（任务成功时返回） |
| result.ossPreview | STRING | OSS预览地址 |
| result.extra | STRING | 额外信息 |
| businessType | NUMBER | 业务类型 |

### 任务状态说明

#### 任务执行中（status = 0/1/2）
当任务尚未完成时，返回示例：
```json
{
    "code": 200,
    "message": "操作成功",
    "data": {
        "key": "cabaedfc-6e25-4c30-a55a-9ab18c795e81",
        "name": "客户dh列表导出_20260414100000.xlsx",
        "type": null,
        "status": 0,
        "progress": 0,
        "read": null,
        "result": null,
        "businessType": null
    }
}
```

#### 任务完成（status = 3）
当任务成功完成时，返回示例：
```json
{
    "code": 200,
    "message": "操作成功",
    "data": {
        "key": "cabaedfc-6e25-4c30-a55a-9ab18c795e81",
        "name": "客户dh列表导出_20260414100000.xlsx",
        "type": 1,
        "status": 3,
        "progress": 100,
        "read": 0,
        "result": {
            "message": "导出成功",
            "filePath": "https://oss-img.dinghuo123.com/liteJob/34579128/ABCD.xlsx",
            "ossPreview": null,
            "extra": null
        },
        "businessType": 1100012
    }
}
```

### 使用场景
在调用导出接口（如客户导出、商品导出、订单导出等）后，系统会返回一个任务key。使用该接口轮询查询任务执行进度，当status=3时表示任务完成，可从result.filePath获取文件下载地址进行下载。

### 注意事项
1. **轮询机制**：需要定期调用此接口查询任务状态，建议间隔2-5秒
2. **状态判断**：
   - status = 0/1/2：任务尚未完成，继续轮询
   - status = 3：任务成功完成，可下载文件
   - status = 4：任务失败，查看result.message了解失败原因
3. **文件下载**：任务成功后，通过result.filePath字段获取的文件地址下载导出文件
4. **进度显示**：progress字段在任务执行中时有效，范围0-100，表示完成百分比
5. **任务时效**：导出的文件可能有有效期限制，read=2表示文件已过期
