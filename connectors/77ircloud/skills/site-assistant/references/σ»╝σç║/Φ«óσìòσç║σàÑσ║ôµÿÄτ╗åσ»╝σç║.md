# 订单出入库明细导出

本文档覆盖订单出入库明细及相关汇总数据的导出接口。导出接口以异步任务方式执行，调用后会返回一个任务标识（`key`），可通过导出任务进度查询接口轮询获取导出结果。

## 接口目录
- [exportCustomerStorageBills](#exportCustomerStorageBills) - 订单出入库明细-导出
- [exportCustomerStorageBillsBySku](#exportCustomerStorageBillsBySku) - 订单出入库汇总（按商品）-导出
- [exportCustomerStorageBillsByCustomer](#exportCustomerStorageBillsByCustomer) - 订单出入库汇总（按往来）-导出

---

## exportCustomerStorageBills - 订单出入库明细-导出

**功能**：按条件导出订单出入库明细数据。接口会返回一个异步任务信息，可通过导出任务进度查询接口轮询获取导出结果。

**典型场景**
- 导出某段时间内的出入库明细
- 按客户、商品、业务员等条件筛选后导出

**参数**
| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| rangeTime | TIME_RANGE | 是 | 否 | 出入库时间范围 |
| q | STRING | 否 | 否 | 商品信息（支持商品名称/编码/商品简称/条码模糊搜索） |
| buyerIds | NUMBER | 否 | 是 | 往来单位ID集 |
| buyerTypes | STRING | 否 | 是 | 买家机构类型 |
| hierarchyOrderTypes | NUMBER | 否 | 是 | 订单类型（1:分公司订单,2:门店订单,3:客户订单,4:分公司代发订单,5:门店代发订单） |
| categoryIds | NUMBER | 否 | 是 | 商品分类ID |
| brandIds | NUMBER | 否 | 是 | 商品品牌ID |
| regionIds | NUMBER | 否 | 是 | 区域ID |
| salesIds | NUMBER | 否 | 是 | 业务员ID |
| salesDepartmentIds | NUMBER | 否 | 是 | 业务员部门ID |
| billNum | STRING | 否 | 否 | 单号（支持订单/退单/出库单） |
| warehouseIds | NUMBER | 否 | 是 | 仓库ID |
| searchType | NUMBER | 否 | 否 | 搜索类型（1:全部,2:仅汇总套餐商品,默认1） |
| onlyPackageDetail | NUMBER | 否 | 否 | 是否套餐明细（1:是,2:否） |

**响应数据**
- 返回类型：`OBJECT`（异步任务信息）
| 字段 | 类型 | 说明 |
|------|------|------|
| key | STRING | 任务标识 |
| name | STRING | 任务名称 |
| type | NUMBER | 任务类型（1:导出 2:导入） |
| status | NUMBER | 任务状态（0:已加入 1:等待执行 2:执行中 3:成功 4:失败） |
| progress | NUMBER | 进度（执行中时有效） |
| read | NUMBER | 已读状态（0:未下载 1:已下载 2:过期） |

## exportCustomerStorageBillsBySku - 订单出入库汇总（按商品）-导出

**功能**：按商品维度导出订单出入库汇总数据。异步任务方式，返回任务信息。

**典型场景**
- 导出各商品的出入库汇总数据
- 按商品分类或品牌筛选后导出

**参数**
| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| rangeTime | TIME_RANGE | 是 | 否 | 出入库时间范围 |
| q | STRING | 否 | 否 | 商品信息（支持商品名称/编码/商品简称/条码模糊搜索） |
| categoryIds | NUMBER | 否 | 是 | 商品分类ID |
| brandIds | NUMBER | 否 | 是 | 商品品牌ID |
| regionIds | NUMBER | 否 | 是 | 区域ID |
| salesIds | NUMBER | 否 | 是 | 业务员ID |
| salesDepartmentIds | NUMBER | 否 | 是 | 业务员部门ID |
| buyerIds | NUMBER | 否 | 是 | 往来单位ID集 |
| buyerTypes | STRING | 否 | 是 | 买家机构类型 |
| hierarchyOrderTypes | NUMBER | 否 | 是 | 订单类型（1:分公司订单,2:门店订单,3:客户订单,4:分公司代发订单,5:门店代发订单） |
| warehouseIds | NUMBER | 否 | 是 | 仓库ID |

**响应数据**
- 返回类型：`OBJECT`（异步任务信息，字段同 `exportCustomerStorageBills`）

| buyerIds | NUMBER | 否 | 是 | 往来单位ID集 |
| buyerTypes | STRING | 否 | 是 | 买家机构类型 |
| hierarchyOrderTypes | NUMBER | 否 | 是 | 订单类型（1:分公司订单,2:门店订单,3:客户订单,4:分公司代发订单,5:门店代发订单） |
| billTypes | STRING | 否 | 是 | 订单类型 |

**响应数据**
- 返回类型：`OBJECT`（异步任务信息，字段同 `exportCustomerStorageBills`）

## 导出任务进度查询

所有导出接口返回的 `key` 字段即为任务标识，可通过导出任务进度查询接口（`exportTaskProgress`）轮询获取导出结果。

详见 [导出任务查询](./导出任务查询.md)。
