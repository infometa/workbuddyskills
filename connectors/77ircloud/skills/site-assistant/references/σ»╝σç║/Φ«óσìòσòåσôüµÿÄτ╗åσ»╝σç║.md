# 订单商品明细导出

本文档覆盖订单商品明细导出接口。导出接口以异步任务方式执行，调用后会返回一个任务标识（`key`），可通过导出任务进度查询接口轮询获取导出结果。

## 接口目录
- [exportOrderProductDetail](#exportorderproductdetail) - 导出订单商品明细

---

## exportOrderProductDetail - 导出订单商品明细

**功能**：按条件导出订单商品明细数据。接口会返回一个异步任务信息，可通过导出任务进度查询接口轮询获取导出结果。

**典型场景**
- 导出某段时间内的订单商品明细
- 按业务类型、单据状态等条件筛选后导出

**参数**
| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| rangeTime | TIME_RANGE | 是 | 否 | 下单时间范围 |
| deliveryDate | TIME_RANGE | 否 | 否 | 交货时间范围 |
| financeAuditTime | TIME_RANGE | 否 | 否 | 财务审核时间范围 |
| orderCodeKeyWord | STRING | 否 | 否 | 订单号（模糊搜索） |
| buyerIds | NUMBER | 否 | 是 | 往来单位 |
| buyerTypes | STRING | 否 | 是 | 业务类型，枚举值：BRANCH(分公司)/STORE(门店)/CUSTOMER(客户) |
| buyerRegionIds | NUMBER | 否 | 是 | 下单区域ID列表 |
| buyerLogisticsCode | STRING | 否 | 否 | 物流编码 |
| customerCategoryIds | NUMBER | 否 | 是 | 客户分类ID列表 |
| customerTagIds | NUMBER | 否 | 是 | 客户标签ID列表 |
| orderStatuses | STRING | 否 | 是 | 单据状态，枚举值：ORDER_AUDIT_PENDING(待订单审核)/AUDITED(已审核)/FINANCE_AUDIT_PENDING(待财务审核)/FINISHED(已完成)/CANCELLED(已作废)，默认查询全部（排除CANCELLED） |
| storageOutStatuses | STRING | 否 | 是 | 出库状态，枚举值：NONE(未出库)/PART(部分出库)/FULL(全部出库) |
| createRole | STRING | 否 | 否 | 下单角色，枚举值：BUYER(买方)/SELLER(卖方) |
| yjdfTypes | STRING | 否 | 是 | 代发类型，枚举值：NO(非代发)/TOB(代发) |
| skuIds | NUMBER | 否 | 是 | SKU ID列表 |
| categoryIds | NUMBER | 否 | 是 | 商品分类ID列表 |
| brandIds | NUMBER | 否 | 是 | 商品品牌ID列表 |
| salesmanIds | NUMBER | 否 | 是 | 下单业务员ID列表 |
| salesmanDepartmentIds | NUMBER | 否 | 是 | 下单业务员部门ID列表 |
| deliveryMethodIds | NUMBER | 否 | 是 | 配送方式ID列表 |
| warehouseIds | NUMBER | 否 | 是 | 发货仓ID列表 |
| creatorIds | NUMBER | 否 | 是 | 制单人ID列表 |
| deliveryInfo | STRING | 否 | 否 | 收货信息（收货人/收货电话） |

**响应数据**
- 返回类型：`OBJECT`（异步任务信息）
| 字段 | 类型 | 说明 |
|------|------|------|
| key | STRING | 任务标识 |
| name | STRING | 任务名称 |
| type | NUMBER | 任务类型（1:导出 2:导入） |
| status | NUMBER | 任务状态（0:已加入 1:等待执行 2:执行中 3:成功 4:失败） |
| progress | NUMBER | 进度（执行中时有效） |
| read | NUMBER | 已读状态（0:未下载 1:已下载 2:过期） |

---

## 导出任务进度查询

所有导出接口返回的 `key` 字段即为任务标识，可通过导出任务进度查询接口（`exportTaskProgress`）轮询获取导出结果。

详见 [导出任务查询](./导出任务查询.md)。
