# 商品导出接口

本文档覆盖商品导出相关接口，支持按多种筛选条件异步导出商品列表数据。

## 接口目录
- [productExport](#productexport) - 商品列表导出

---

## productExport - 商品列表导出

### 接口描述
按条件导出商品列表数据，支持多种筛选条件和导出模版类型。

### ID类型参数获取途径

商品导出接口中有多个需要传入ID的筛选参数，以下是各ID的获取方式：

| ID参数 | 说明 | 获取方式 |
|--------|------|----------|
| categoryIds | 商品分类id | 调用 `productCategoryList` 获取全量商品分类列表（树形结构），根据分类名称找到对应 `id`（见[商品/商品.md](../商品/商品.md)） |
| tagIds | 商品标签id | 调用 `productTagList` 获取全量商品标签列表，根据标签名称找到对应 `id`（见[商品/商品.md](../商品/商品.md)） |
| brandIds | 商品品牌id | 调用 `productBrandList` 获取全量商品品牌列表，根据品牌名称找到对应 `id`（见[商品/商品.md](../商品/商品.md)） |

### 请求参数

#### Query参数

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| type | NUMBER | 否 | 否 | 导出模版（1:商品列表模版 2:批量修改模版），默认1 |
| q | STRING | 否 | 否 | 搜索关键字（商品名称/编码/简码/条码/规格） |
| categoryCode | STRING | 否 | 是 | 商品类别编码 |
| inStock | BOOLEAN | 否 | 否 | 是否有库存（true:有库存 false:无库存） |
| statuses | NUMBER | 否 | 是 | sku状态 |
| shelfStatuses | NUMBER | 否 | 是 | 商品上架状态，1=上架,2=下架,0=无效 |
| types | NUMBER | 否 | 是 | 商品类型（1:普通商品 2:套餐商品） |
| tagIds | NUMBER | 否 | 是 | 商品标签 |
| categoryIds | NUMBER | 否 | 是 | 商品分类 |
| brandIds | NUMBER | 否 | 是 | 商品品牌 |
| codes | STRING | 否 | 是 | 商品编码 |
| imageExists | NUMBER | 否 | 否 | 商品图片（1:全部 2:有图 3:无图） |

### 响应数据

- 返回类型：`OBJECT`

| 字段 | 类型 | 说明 |
|------|------|------|
| key | STRING | 任务标识 |
| name | STRING | 任务名称 |
| type | NUMBER | 任务类型（1:导出 2:导入） |
| status | NUMBER | 任务状态（0:已加入 1:等待执行 2:执行中 3:成功 4:失败） |
| progress | NUMBER | 进度（执行中时有效） |
| read | NUMBER | 已读状态（0:未下载 1:已下载 2:过期） |

### 使用场景
当需要按特定条件筛选并导出商品数据时使用此接口。接口会返回一个异步任务信息，可通过任务标识查询导出进度和下载结果。

### 注意事项
1. 该接口为异步导出，返回的是任务信息而非直接的导出数据
2. 需要通过返回的key值查询任务状态和下载导出的文件
3. 导出模版类型type=1为商品列表模版，type=2为批量修改模版，默认1
4. 支持多种筛选条件组合，包括关键字搜索、分类、品牌、标签、库存状态等
5. 查询库存信息默认开启（queryInventories=true）
