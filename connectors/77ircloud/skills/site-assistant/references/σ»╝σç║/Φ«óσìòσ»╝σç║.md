# 订单导出接口

本文档覆盖订单导出相关接口，支持按多种筛选条件异步导出订单列表数据。

## 接口目录
- [orderListExport](#orderlistexport) - 卖方订单列表导出

---

## orderListExport - 卖方订单列表导出

### 接口描述
按条件导出卖方订单列表数据，支持丰富的筛选条件，包括订单状态、时间范围、买家/卖家信息、配送信息等。

### 参数

| 参数 | 类型 | 必填 | 数组 | 说明                                                                                                         |
|------|------|------|------|------------------------------------------------------------------------------------------------------------|
| createRangeTime | TIME_RANGE | 是 | 否 | [必填] 下单时间范围，对象包含 `startTime` 和 `endTime`，格式：`yyyy-MM-dd HH:mm:ss`，时间跨度不超过1年。当用户只说"订单"的时间时，默认指此字段           |
| deliveryDate | TIME_RANGE | 否 | 否 | 交货日期范围，对象包含 `startTime` 和 `endTime`，格式：`yyyy-MM-dd HH:mm:ss`                                               |
| orderKeyWord | STRING | 否 | 否 | 订单关键字（单号/制单人/买家）                                                                                           |
| orderDetailKeyWord | STRING | 否 | 否 | 商品关键字（编码/名称/条形码）                                                                                           |
| orderCodes | STRING | 否 | 是 | 订单号列表                                                                                                      |
| buyerIds | NUMBER | 否 | 是 | 买方ID列表，最多50个，需先用customerList获取客户ID                                                                         |
| buyerRegionIds | NUMBER | 否 | 是 | 买方区域ID列表                                                                                                   |
| customerCategoryId | NUMBER | 否 | 是 | 客户分类ID列表                                                                                                   |
| settlementOrgIds | NUMBER | 否 | 是 | 结算单位ID列表                                                                                                   |
| buyerLogisticsCode | STRING | 否 | 否 | 买方物流编码                                                                                                     |
| orderStatus | STRING | 否 | 是 | 单据状态列表，枚举值：ORDER_AUDIT_PENDING(待审核)/AUDITED(已审核)/FINANCE_AUDIT_PENDING(待财务审核)/FINISHED(已完成)/CANCELLED(已取消) |
| stockOutStatus | STRING | 否 | 是 | 出库状态列表，枚举值：NONE(未出库)/PART(部分出库)/FULL(全部出库)                                                                 |
| stockOutApprovedStatus | STRING | 否 | 是 | 出库审核状态列表                                                                                                   |
| deliveryStatus | STRING | 否 | 是 | 发货状态列表，枚举值：NONE(未发货)/PART(部分发货)/FULL(全部发货)                                                                 |
| signStatus | STRING | 否 | 是 | 签收状态列表，枚举值：NONE(待签收)/PART(部分签收)/FULL(已签收)                                                                  |
| orderSortingStatus | STRING | 否 | 是 | 分拣状态列表                                                                                                     |
| paymentStatus | STRING | 否 | 是 | 付款状态列表，枚举值：UN_PAID(未付款)/PART_PAID(部分付款)/PAID(已付款)                                                          |
| isClose | BOOLEAN | 否 | 否 | 是否关闭，true:已关闭，false:未关闭                                                                                    |
| isPrint | BOOLEAN | 否 | 否 | 是否已打印，true:已打印，false:未打印                                                                                   |
| orderType | STRING | 否 | 是 | 订单类型列表，枚举值：NORMAL(普通订单)/PURCHASE(采购订单)                                                                     |
| orderCategorys | STRING | 否 | 是 | 订单类别列表                                                                                                     |
| yjdfStatuses | STRING | 否 | 是 | 代发状态列表，枚举值：PENDING(待代发)/COMPLETED(已代发)                                                                     |
| createRole | STRING | 否 | 否 | 下单方式，枚举值：SELLER(代下单)/BUYER(自主下单)                                                                           |
| orderSource | STRING | 否 | 是 | 订单来源列表                                                                                                     |
| salesmanIds | NUMBER | 否 | 是 | 业务员ID列表                                                                                                    |
| creatorIds | NUMBER | 否 | 是 | 制单人ID列表                                                                                                    |
| deliveryMethodIds | NUMBER | 否 | 是 | 配送方式ID列表，1:到店自提，2:送货上门                                                                                     |
| warehouseIds | NUMBER | 否 | 是 | 发货仓库ID列表                                                                                                   |
| payPeriodTypes | STRING | 否 | 是 | 结算模式列表                                                                                                     |
| invoiceStatusList | STRING | 否 | 是 | 发票状态列表                                                                                                     |
| tradeStatus | NUMBER | 否 | 是 | 收款状态列表，枚举值：1(未收款)/2(部分收款)/3(已收款)/4(待退款)                                                                    |
| zfException | BOOLEAN | 否 | 否 | 是否存在直发异常                                                                                                   |
| stockOutApproved | BOOLEAN | 否 | 否 | 出库待审核                                                                                                      |

### 响应数据

- 返回类型：`OBJECT`

| 字段 | 类型 | 说明 |
|------|------|------|
| key | STRING | 任务标识 |
| name | STRING | 任务名称 |
| type | NUMBER | 任务类型（1:导出 2:导入） |
| status | NUMBER | 任务状态（0:已加入 1:等待执行 2:执行中 3:成功 4:失败） |
| progress | NUMBER | 进度（执行中时有效） |
| read | NUMBER | 已读状态（0:未下载 1:已下载 2:过期） |

### ID类型参数获取途径

订单导出接口中有多个需要传入ID的筛选参数，以下是各ID的获取方式：

| ID参数 | 说明 | 获取方式 |
|--------|------|----------|
| buyerIds | 买方机构id | 通过 `searchDirectUnder` 接口查询（见[组织/组织.md](../组织/组织.md)），按 `hierarchyCodes` 筛选机构类型 |
| settlementOrgIds | 结算单位id | 通过 `searchDirectUnder` 接口查询，传入 `settlementOrgFlag: 1` 只查询结算客户 |
| deliveryMethodIds | 配送方式id | 通过 `findOrderConfiguration` 接口查询 `deliveryMethods` 列表（见[订单/参数设置.md](../订单/参数设置.md)） |
| customerCategoryId | 客户分类id | 通过 `customerCategoryList` 接口查询客户分类列表，或通过 `customerList` 查询客户时获取 `customerCategoryName` 对应的分类ID |
| warehouseIds | 发货仓id | 通过 `findWarehouses` 接口查询（见[仓库/仓库.md](../仓库/仓库.md)） |
| creatorIds | 制单人id | 通过 `employeeList` 接口查询（见[员工部门/员工.md](../员工部门/员工.md)） |
| salesmanIds | 业务员id | 通过 `employeeList` 接口查询员工信息（见[员工部门/员工.md](../员工部门/员工.md)） |
| buyerRegionIds | 区域id | 通过 `regionList` 接口查询区域列表（见[客户与商机/区域.md](../客户与商机/区域.md)） |
