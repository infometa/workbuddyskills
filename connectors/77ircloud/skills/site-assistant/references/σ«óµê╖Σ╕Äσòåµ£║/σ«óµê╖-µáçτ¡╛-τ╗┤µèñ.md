# 客户标签维护

本文档覆盖客户标签关系的批量维护接口，用于给一批客户批量打标签或移除标签。获取标签列表请查阅 [客户.md](客户.md) 中的 `customerTagList`。

## 接口目录
- [customerTagRelationBatch](#customertagrelationbatch) - 批量更新客户标签关系

---

## customerTagRelationBatch

**功能**：对一批客户批量添加或移除标签，一次请求同时处理新增和删除。

**典型场景**
- 运营批量给一批客户打上"重点客户"标签
- 清理一批客户上已过期的活动标签
- 同时替换客户的标签（去掉旧标签 + 加上新标签）
- 智能标签匹配后将推荐标签写入客户（结合 `customerTagList` 筛选 `useScene=1` 的 AI 标签）

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| customerIds | NUMBER | 是 | 是 | 客户ID列表，可从 customerList 获取 |
| addTagIds | NUMBER | 否 | 是 | 新增的标签ID列表，无则传空数组。标签ID从 customerTagList 获取 |
| deleteTagIds | NUMBER | 否 | 是 | 移除的标签ID列表，无则传空数组。标签ID从 customerTagList 获取 |

**响应数据**
- 返回类型：`OBJECT`

| 字段 | 类型 | 说明 |
|------|------|------|
| successCount | NUMBER | 批量操作成功条数 |
| items | ARRAY | 失败的数据列表 |
| items[].id | STRING | 失败项的唯一标识 |
| items[].name | STRING | 失败项的名称 |
| items[].errorMsg | STRING | 失败原因 |

**前置接口**
- `customerTagList`（客户标签列表）→ 获取标签ID。注意筛选 `useScene=1` 可获取 AI 可用标签
- `customerList`（客户列表）→ 获取客户ID及其已有标签

## 跨接口组合示例

**场景**：将一批"近30天未下单"的客户打上"流失风险"标签
1. `customerList`（客户.md）→ 按条件筛选获取客户ID列表
2. `customerTagList`（客户.md）→ 获取"流失风险"标签ID
3. `customerTagRelationBatch` → 传入 customerIds + addTagIds=[标签ID]

**场景**：替换某客户分类下所有客户的标签（去掉旧标签，指定新标签）
1. `customerCategoryList`（客户.md）→ 获取客户分类ID
2. `customerList`（客户.md）→ 传入 customerCategoryIds 获取客户ID列表
3. `customerTagList`（客户.md）→ 获取新旧标签各自的ID
4. `customerTagRelationBatch` → 传入 customerIds + addTagIds + deleteTagIds

**场景**：智能标签匹配后为用户推荐已有 AI 标签
1. `customerTagList` → 筛选 `useScene=1` 的标签，解析 `definition` 和 `module` 字段
2. 用客户预警数据 + 标签规则匹配 → 产出推荐标签 ID 列表
3. 取客户已有标签（`customerList.customerTags`）→ 去重排除
4. `customerTagRelationBatch` → 传入 customerIds + addTagIds=[推荐标签ID]
