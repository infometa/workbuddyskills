# 区域与地区基础数据

本文档覆盖区域查询接口。区域是被多个业务模块共用的公共枚举数据，包括客户预警、员工筛选等场景均需先获取区域ID。

## 接口目录
- [regionList](#regionlist) - 客户区域列表

---

## regionList

**功能**：获取客户区域列表，支持按组织ID筛选，返回区域树形结构信息。

**典型场景**
- 用户指定区域时，获取区域ID
- 结合 customerEarlywarnList 的 regionIds 筛选客户预警
- 结合 salesPerformanceList 的 regionIds 筛选员工业绩
- 结合 employeeList 的 regionIds 筛选员工
- 创建商机/客户时选择所属区域

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| orgId | NUMBER | 否 | 否 | 组织ID，表示要查询该组织的区域，不传则查询当前租户 |

**响应数据**
- 返回类型：`ARRAY`（数组）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | STRING | 区域ID |
| name | STRING | 区域名称 |
| parentId | NUMBER | 上级区域ID |
| level | NUMBER | 区域层数 |
| defaultFlag | BOOLEAN | 默认区域标志（true=默认区域） |
| leafFlag | BOOLEAN | 叶子结点区域标志（true=叶子节点，无子区域） |
| parentIds | STRING | 分类节点链路（区域层级路径） |
