# 商机管理

本文档覆盖商机相关的查询接口，包括商机列表查询与审核。商机是待注册客户的预存档案，通过审核后可转化为正式客户。

## 接口目录
- [registerAuditList](#registerauditlist) - 商机列表（待审核/已审核商机查询）
- [getMerchantDetail](#getmerchantdetail) - 商机详情（查看单个商机完整信息）

---

## registerAuditList

**功能**：查询商机（待注册客户）列表，支持按手机号/联系人/审核状态/商机来源/分配机构/员工等多维度筛选。

**典型场景**
- 查看待审核的商机列表
- 查询某员工拉新的商机记录
- 按来源（扫码注册/员工拉新等）筛选商机
- 查看已分配机构的商机
- 按审核状态筛选（待审核/审核通过/审核拒绝）

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明                                                                                     |
|------|------|------|------|----------------------------------------------------------------------------------------|
| q | STRING | 否 | 否 | 关键字（联系人/手机号码），模糊搜索                                                                     |
| contactPhone | STRING | 否 | 否 | 手机号码，精确搜索                                                                              |
| status | NUMBER | 否 | 否 | 审核状态，0=待审核，1=审核通过，2=审核拒绝                                                               |
| statusList | NUMBER | 否 | 是 | 审核状态列表，支持多状态筛选                                                                         |
| sourceType | NUMBER | 否 | 是 | 商机来源列表，1=手工创建，2=ERP同步，3=员工拉新，4=客户推荐，5=微信搜索，6=扫码注册，7=批量导入，8=微信直播，9=推文分享，10=附近商机，11=商机搜索 |
| relationOrgId | NUMBER | 否 | 否 | 分配机构ID，按分配机构筛选                                                                         |
| employeeId | NUMBER | 否 | 否 | 员工ID，按负责员工筛选                                                                           |
| displayFilter | BOOLEAN | 否 | 否 | 是否只显示自己的，默认false（显示全部），true=只显示自己创建的                                                   |
| currentPage | NUMBER | 否 | 否 | 当前页码，默认1                                                                               |
| pageSize | NUMBER | 否 | 否 | 每页条数，默认20                                                                              |

**响应数据**
- 返回类型：`PAGE`（分页）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | NUMBER | 商机ID |
| name | STRING | 公司名称 |
| contactName | STRING | 联系人 |
| contactPhone | STRING | 联系电话 |
| contacts | ARRAY | 联系人列表 |
| contacts[].id | NUMBER | 联系人ID |
| contacts[].contactName | STRING | 联系人 |
| contacts[].contactPhone | STRING | 联系电话 |
| contacts[].main | BOOLEAN | 是否主要联系人 |
| contacts[].sortOrder | NUMBER | 排序 |
| address | STRING | 联系地址 |
| registerTime | DATETIME | 注册时间 |
| status | NUMBER | 审核状态（0:待审核 / 1:审核通过 / 2:审核拒绝） |
| parentId | NUMBER | 上级机构ID |
| relationOrgId | NUMBER | 分配机构ID |
| relationOrgName | STRING | 分配机构名称 |
| regionId | NUMBER | 区域ID |
| regionName | STRING | 区域名称 |
| sourceTypeName | STRING | 商机来源 |
| referrerId | NUMBER | 推荐人ID |
| referrerName | STRING | 推荐人名称 |
| warehouseId | NUMBER | 仓库ID |
| warehouseName | STRING | 仓库名称 |
| authorizationId | NUMBER | 商品授权方案ID |
| authorizationName | STRING | 商品授权方案名称 |
| customerCategoryId | NUMBER | 客户分类ID |
| customerCategoryName | STRING | 客户分类名称 |
| priceMode | NUMBER | 价格模式 |
| priceLevelId | NUMBER | 价格等级ID |
| priceLevelName | STRING | 价格等级名称 |
| score | NUMBER | 商机评分 |
| fundInfo | OBJECT | 结算模式信息 |
| fundInfo.payPeriodType | STRING | 账期类型（MONTH:月结 / CONSTANT:定期结算 / NO_CONSTANT:不固定帐期 / MONEY_BEFORE_CARGO:先款后货 / CARGO_BEFORE_MONEY:货到付款 / 滚动结算:ROLLING） |
| fundInfo.billDay | STRING | 结算周期（定期结算的结算周期） |
| fundInfo.repaymentDay | NUMBER | 付款期限/付款日（定期结算的付款期限 / 月结的付款日） |
| employeeId | NUMBER | 员工ID |
| employeeName | STRING | 员工名称 |

## getMerchantDetail

**功能**：查询单个商机的完整详细信息，包括基础信息、地区信息、推荐信息、机构分配、仓库授权、客户分类、价格信息、结算模式等所有字段。

**典型场景**
- 查看某个商机的完整信息，用于审核前详细评估
- 查看商机的结算模式和价格配置
- 审核通过后查看转化为客户前的完整档案

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| id | NUMBER | 是 | 否 | 商机ID，路径参数，要查询的商机ID |

**响应数据**
- 返回类型：`OBJECT`

| 字段 | 类型 | 说明 |
|------|------|------|
| id | STRING | 商机ID |
| name | STRING | 公司名称 |

| contactPhone | STRING | 联系电话 |
| contacts | ARRAY | 联系人列表 |

| referrerType | NUMBER | 推荐人类型（0:无推荐人 / 1:员工 / 2:客户） |

| relationOrgId | NUMBER | 分配机构ID |
| relationOrgName | STRING | 分配机构名称 |
| regionId | NUMBER | 区域ID |
| regionName | STRING | 区域名称 |
| warehouseId | NUMBER | 仓库ID |
| warehouseName | STRING | 仓库名称 |
