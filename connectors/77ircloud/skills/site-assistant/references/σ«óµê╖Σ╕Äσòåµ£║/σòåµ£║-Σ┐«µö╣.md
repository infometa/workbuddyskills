# 商机-修改

本文档覆盖修改商机的接口，用于更新已创建的商机档案信息。

## 接口目录
- [updateRegisterAudit](#updateregisteraudit) - 修改商机

---

## updateRegisterAudit

**功能**：修改已有商机的基本信息，包括公司名称、联系人、区域、仓库、客户分类、业务员、商机评分等。

**典型场景**
- 修改商机名称或联系人信息
- 调整商机负责区域
- 更换负责业务员
- 更新商机评分

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明                           |
|------|------|------|------|------------------------------|
| id | NUMBER | 是 | 否 | 商机ID                         |
| name | STRING | 否 | 否 | 公司名称/商机名称                    |
| contacts | OBJECT | 否 | 是 | 联系人列表                        |
| contacts[].contactName | STRING | 否  | 否  | 联系人，最多20个字符                  |
| contacts[].contactPhone | STRING | 是  | 否  | 联系电话，格式：1开头的11位数字            |
| contacts[].main | BOOLEAN | 是  | 否  | 是否主要联系人,有且仅有一个是true          |
| contacts[].sortOrder | NUMBER | 否  | 否  | 排序，正整数，从0开始，越小优先级越高，main通常为0 |
| regionId | NUMBER | 否 | 否 | 商机区域ID                       |
| warehouseId | NUMBER | 否 | 否 | 仓库ID                         |
| customerCategoryId | NUMBER | 否 | 否 | 客户分类ID                       |
| employeeId | NUMBER | 否 | 否 | 业务员ID                        |
| score | NUMBER | 否 | 否 | 商机评分                         |

**响应数据**
- 返回类型：`OBJECT`

| 字段 | 类型 | 说明 |
|------|------|------|
| id | NUMBER | 商机ID |

**前置接口**
- `registerAuditList`：查询商机列表（客户与商机/商机.md）→ 获取商机ID

**注意事项**
1. `id` 为必填项，其余字段均按需传入（只传需要修改的字段即可）
2. 不需要修改的字段不传值，不会覆盖原有数据
3. 如需修改商机状态（审核通过/拒绝），需使用审核状态更改接口

## 跨接口组合示例

**场景**：修改商机的负责业务员和评分
1. `registerAuditList` → 查询商机列表，获取商机ID
2. `updateRegisterAudit` → 传入 id + employeeId + score 进行修改
