# 单据选客户

本文档覆盖客户选择接口：支持按名称、编码、联系人、分类、标签、区域、业务员、客户来源等多种条件筛选客户，返回客户基本信息及其 ID，供创建/编辑各类业务单据时选择客户使用。

## 接口目录
- [findAclCustomers](#findaclcustomers) - 单据选客户

## findAclCustomers

**功能**：查询客户列表，支持按名称、编码、联系人、分类、标签、区域、业务员、客户来源等多种条件筛选，返回客户基本信息及其 ID。

**典型场景**
- 创建客户调价单时查询客户信息，客户名称/编码 → customerId（作为 `customerSinglePriceBillSave` 的 `targets`）
- 批量调价 Excel 中根据客户编码列批量解析 customerIds

## 跨接口组合示例

**场景**：创建客户调价单
1. `findAclCustomers`（本接口）→ 客户名称/编码解析为客户ID
2. `customerQuotationSkuList`（见 商品/客户调价单.md）→ 选品取 skuId 与单位价格列表
3. `customerSinglePriceBillSave` / `customerSinglePriceBillAudit` → 创建并审核调价单
