# 客户基础数据

本文档覆盖客户主体相关的查询接口，包含客户列表、客户分类、客户标签。新建客户请查阅 [客户-新增.md](客户-新增.md)。

## 接口目录
- [customerList](#customerlist) - 客户列表（按名称/编码/分类/标签/区域/业务员等筛选）
- [getCustomerDetail](#getcustomerdetail) - 根据客户ID查询客户详情
- [customerCategoryList](#customercategorylist) - 客户分类列表
- [customerTagList](#customertaglist) - 客户标签列表
- [listRuleCategoryIds](#listrulecategoryids) - 获取会员级别设置的分类

---

## customerList

**功能**：查询客户列表，支持按名称、编码、联系人、分类、标签、区域、业务员、客户来源等多种条件筛选。

**典型场景**
- 查找某个客户是否存在及其ID
- 查看某分类下的客户
- 用户提到客户名称但需要其ID时
- 查询客户的账号状态、所属区域、业务员等信息
- 按加盟时间范围筛选客户
- 按推荐人、配送线路、物流编码筛选客户

## getCustomerDetail

**功能**：根据客户组织ID查询客户详情，返回客户的完整信息包括收货地址、联系人、财务信息等。

**典型场景**
- 创建订单前获取客户的默认收货地址、联系人等信息用于自动填充
- 查看客户的完整资料（分类、标签、财务信息等）
- 获取客户信用额度 / 占用额度 / 可用额度（`fundInfo`）
- 获取客户的默认仓库、默认业务员等配置信息（参考场景）

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| id | NUMBER | 是 | 否 | 客户组织ID，路径参数，可从 customerList 获取 |
| handleAddress | BOOLEAN | 否 | 否 | 是否处理详细地址转换（拼接省市区信息），默认false |
| fillMembershipInfo | BOOLEAN | 否 | 否 | 是否返回会员信息，默认false |

**响应数据**
- 返回类型：`OBJECT`

| 字段 | 类型 | 说明 |
|------|------|------|
| id | NUMBER | 客户ID（用于下游接口） |
| name | STRING | 客户名称 |
| code | STRING | 客户编码 |
| status | NUMBER | 状态（1:启用 0:禁用） |
| hierarchyCode | STRING | 机构层级（固定为CUSTOMER） |

| salesDepartmentId | NUMBER | 业务员部门ID |

| customerCategoryId | NUMBER | 客户分类ID |
| customerCategoryName | STRING | 客户分类名称 |
| customerTags | ARRAY | 客户标签列表 |
| customerTags[].id | NUMBER | 标签ID |
| customerTags[].name | STRING | 标签名称 |
| deliveryAddresses | ARRAY | 收货地址列表 |
| contacts | ARRAY | 联系人列表 |
| contacts[].id | NUMBER | 联系人ID |
| contacts[].name | STRING | 联系人名称 |
| accountInfo | OBJECT | 账户信息 |
| accountInfo.id | NUMBER | 账户ID |
| accountInfo.userName | STRING | 用户名 |
| accountInfo.status | STRING | 账户状态（0禁用 1正常） |
| **warehouseId** | NUMBER | **客户所属仓库ID（默认仓库）** |

## customerCategoryList

**功能**：获取客户分类列表，支持按组织ID筛选，返回分类完整信息包括折扣率、起订金额等。

**典型场景**
- 用户提到客户分类名称时，获取其ID
- 结合 customerList、customerOutStatisticsList 等按分类筛选
- 创建客户/商机时选择客户分类
- 查看客户分类的折扣率和起订金额配置

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| orgIds | NUMBER | 否 | 是 | 组织ID列表，最多300个组织ID |

**响应数据**
- 返回类型：`ARRAY`（数组）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | NUMBER | 分类ID |
| name | STRING | 客户分类名称 |
| defaultFlag | BOOLEAN | 是否默认（true=默认，false=非默认） |
| discountRate | NUMBER | 客户折扣率（BigDecimal类型） |
| orderLimitMoney | NUMBER | 订单起订金额（BigDecimal类型） |

**参数**

**响应数据**
- 返回类型：`ARRAY`（数组）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | NUMBER | 标签ID |
| name | STRING | 标签名称 |

## listRuleCategoryIds

**功能**：查询已配置会员级别的客户分类ID列表。用于识别哪些客户分类已经关联了会员规则。

**典型场景**
- 新建客户时，判断某客户分类是否支持会员功能
- 设置客户会员时间（`memberStartTime`/`memberEndTime`）前，确认该客户分类已配置会员规则

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| name | STRING | 否 | 否 | 名称模糊匹配 |
| customerCategoryId | NUMBER | 否 | 否 | 客户/会员类别ID |
| customerCategoryIds | NUMBER | 否 | 是 | 客户/会员类别ID列表 |
| status | NUMBER | 否 | 否 | 会员规则状态，1=有效，2=失效 |
| statusList | NUMBER | 否 | 是 | 状态列表（IN查询） |

**响应数据**
- 返回类型：`ARRAY`（数组）

| 字段 | 类型 | 说明 |
|------|------|------|
| (item) | NUMBER | 已设置会员规则的客户分类ID |

## 跨接口组合示例

**场景**：查询某分类下客户的销售统计
1. `customerCategoryList` → 获取分类ID
2. `customerOutStatisticsList`（见统计/客户销售统计.md） → 传入 cusCategoryIds + rangeTime

**场景**：查询某客户分类的客户预警
1. `customerCategoryList` → 获取分类ID
2. `customerEarlywarnList`（见预警/客户预警.md） → 传入 cusCategoryIds + module
