# 商机-新增

本文档覆盖创建商机的接口，用于在系统中录入待注册客户的预存档案。商机创建后可通过审核流程转化为正式客户。

## 接口目录
- [createMerchant](#createmerchant) - 创建商机（录入客户预存档案）

---

## createMerchant

**功能**：创建商机（待注册客户），录入公司名称、联系人、地区、价格方案、结算模式等信息，创建后进入待审核状态。

**典型场景**
- 手工录入新的商机信息

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明                                                                                               |
|------|------|----|----|--------------------------------------------------------------------------------------------------|
| name | STRING | 否  | 否  | 公司名称/商机名称                                                                                        |
| contacts | OBJECT | 是  | 是  | 联系人列表                                                                                            |
| contacts[].contactName | STRING | 否  | 否  | 联系人，最多20个字符                                                                                      |
| contacts[].contactPhone | STRING | 是  | 否  | 联系电话，格式：1开头的11位数字                                                                                |
| contacts[].main | BOOLEAN | 是  | 否  | 是否主要联系人,有且仅有一个是true                                                                                        |
| contacts[].sortOrder | NUMBER | 是  | 否  | 排序，正整数，从0开始，越小优先级越高，main通常为0                                                                               |
| sourceType | NUMBER | 否  | 否  | 商机来源类型，默认1(手工创建)，1=手工创建，2=ERP同步，3=员工拉新，4=客户推荐，5=微信搜索，6=扫码注册，7=批量导入，8=微信直播，9=推文分享，10=附近商机，11=商机搜索 |
| provinceId | NUMBER | 否  | 否  | 省份ID，需先用 regionList 获取地区ID                                                                       |
| cityId | NUMBER | 否  | 否  | 城市ID                                                                                             |
| districtId | NUMBER | 否  | 否  | 区县ID                                                                                             |
| details | STRING | 否  | 否  | 详细地址                                                                                             |
| longitude | NUMBER | 否  | 否  | 经度，用于地图定位                                                                                        |
| latitude | NUMBER | 否  | 否  | 纬度，用于地图定位                                                                                        |
| regionId | NUMBER | 否  | 否  | 商机区域ID，分配负责区域                                                                                    |
| referrerId | NUMBER | 否  | 否  | 推荐人ID，客户推荐时填写                                                                                    |
| referrerType | NUMBER | 否  | 否  | 推荐人类型                                                                                            |
| warehouseId | NUMBER | 否  | 否  | 仓库ID，指定发货仓库                                                                                      |
| authorizationId | NUMBER | 否  | 否  | 商品授权方案ID，指定可订购商品范围                                                                               |
| customerCategoryId | NUMBER | 否  | 否  | 客户分类ID，需先用 customerCategoryList 获取分类ID                                                           |
| priceMode | NUMBER | 否  | 否  | 定价方式                                                                                             |
| priceLevelId | NUMBER | 否  | 否  | 价格等级ID                                                                                           |
| recentOrderPriceStatus | NUMBER | 否  | 否  | 开启最近订货价，0=关闭，1=开启                                                                                |
| score | NUMBER | 否  | 否  | 商机评分                                                                                             |
| fundInfo | OBJECT | 否  | 否  | 结算模式信息，包含账期信息                                                                                    |
| fundInfo.payPeriodType | STRING | 否  | 否  | 账期类型，MONTH=月结，CONSTANT=定期结算，NO_CONSTANT=不固定帐期，MONEY_BEFORE_CARGO=先款后货，CARGO_BEFORE_MONEY=货到付款    |
| fundInfo.billDay | STRING | 否  | 否  | 结算周期，定期结算的结算周期                                                                                   |
| fundInfo.repaymentDay | NUMBER | 否  | 否  | 付款期限/付款日，定期结算的付款期限 / 月结的付款日                                                                      |

**响应数据**
- 返回类型：`OBJECT`

| 字段 | 类型 | 说明 |
|------|------|------|
| id | NUMBER | 商机ID（创建成功返回，用于后续审核操作） |

**前置接口**
- `regionList`：获取地区列表（基础数据/地区.md）→ 获取 provinceId/cityId/districtId
- `customerCategoryList`：获取客户分类列表（基础数据/客户.md）→ 获取 customerCategoryId
- `listRuleCategoryIds`：获取商品授权方案列表 → 获取 authorizationId

**注意事项**
1. contacts是必填项，支持多联系人录入，通过 `contacts` 字段传入联系人列表，每个联系人包含姓名、电话、是否主要联系人、排序，至少有一个主联系人，电话是必填
2. 联系人姓名最多支持 20 个字符
3. 商机创建后默认状态为"待审核"（status=0）
4. 结算模式为嵌套对象，需同时传递 `fundInfo.payPeriodType` 等子字段
5. 来源类型默认填1(手工创建)，如用户指定其他来源类型需根据实际情况填写
6. 当用户只填写了联系电话时，名称字段使用联系人电话的值，此时新增商机传值仅传"name"、"contacts"、"sourceType"，最小传值示例：{"contacts":[{"contactPhone":"18566778899","main":true,"sortOrder":0}],"name":"18566778899","sourceType":1}

## 跨接口组合示例

**场景**：员工拉新创建商机
1. `createMerchant` → 传入 sourceType=3(员工拉新)、referrerId=员工ID
2. `registerAuditList` → 查看员工拉新的商机列表

**场景**：客户推荐创建商机
1. `createMerchant` → 传入 sourceType=4(客户推荐)、referrerId=推荐人ID
2. `registerAuditList` → 筛选 sourceType=4 查看推荐商机
