# 员工基础数据

本文档覆盖员工相关基础查询接口。

## 接口目录
- [employeeList](#employeelist) - 员工基本信息列表（按姓名/手机/工号搜索）
- [findOrderEmployees](#findorderemployees) - 查询业务员列表（下单选择业务员专用）
- [employeeSettingById](#employeesettingbyid) - 查询员工新客默认设置（查看员工的新客配置）

---

## employeeList

**功能**：查询员工（业务员、司机、采购员、财务、分拣员、经营管理者）列表，支持按姓名、手机号、工号、账号、分类类型、部门、状态搜索。

**典型场景**
- 用户提到某业务员名称时，获取其员工ID
- 查询某区域的员工
- 需要员工ID用于下游统计（如 salesPerformanceList、salesVisitList）

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| q | STRING | 否 | 否 | 名称/手机号/工号/账号，模糊搜索 |
| departmentId | NUMBER | 否 | 否 | 部门ID |
| status | NUMBER | 否 | 否 | 状态，1=启用，0=禁用；不传查所有 |
| types | NUMBER | 否 | 是 | 员工分类集合，1=业务员；2=司机；3=采购员；4=财务；5=分拣员；6=经营管理者 |
| regionIds | NUMBER | 否 | 是 | 区域ID数组，按区域筛选员工，需先用 regionList 获取 |

**响应数据**
- 返回类型：`PAGE`（分页）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | NUMBER | 员工ID |
| name | STRING | 员工名称 |
| mobile | STRING | 员工电话号码 |
| status | NUMBER | 状态（1=启用，0=禁用） |
| assoOrgName | STRING | 所属组织名称 |
| employeeNumber | STRING | 工号 |
| departmentName | STRING | 部门名称 |
| departmentId | STRING | 部门ID |
| position | STRING | 职位 |
| 手机号 | STRING | mobile |
| email | STRING | 邮箱 |
| roleIds | NUMBER | 员工角色ID集合 |
| roleNames | STRING | 员工角色名称 |
| typeNames | STRING | 员工类型名称 |

## findOrderEmployees

**功能**：下单选择业务员专用接口（走 acl 权限放行路径），查询当前机构有权限访问的员工列表，支持按姓名/手机/工号/账号关键词搜索及状态筛选。

**典型场景**
- 创建订单时选择负责业务员，获取其员工ID传入 salesmanId

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| q | STRING | 否 | 否 | 关键词搜索，按员工编码、姓名模糊匹配 |
| status | NUMBER | 否 | 否 | 员工状态过滤，1:启用 0:禁用；不传查所有 |

**响应数据**
- 返回类型：`PAGE`（分页）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | NUMBER | 员工ID（用于下游接口如创建订单传 salesmanId） |
| name | STRING | 员工姓名 |
| userName | STRING | 账号 |
| mobile | STRING | 手机号 |
| status | NUMBER | 状态（1:启用 0:禁用） |
| assoOrgName | STRING | 所属机构名称 |
| orgId | NUMBER | 所属机构ID |
| hierarchyCode | STRING | 机构层级（HEADQUARTERS:总部 BRANCH:分公司 STORE:门店） |
| employeeNumber | STRING | 工号 |
| departmentId | NUMBER | 部门ID |
| departmentName | STRING | 部门名称 |
| position | STRING | 职位 |
| typeNames | ARRAY | 员工类型名称列表（如业务员、司机） |

## 跨接口组合示例

**场景**：创建订单时选择业务员
1. `findOrderEmployees` → 传入 `status: 1`、`q: "业务员姓名"`，获取业务员ID
2. `createToBOrder` → 将业务员ID传入 salesmanId（订单/订单.md）

**场景**：查询某业务员的销售业绩
1. `employeeList` → 按姓名找到员工ID
2. `salesPerformanceList`（见统计/员工业绩统计.md） → 传入 salesIds + rangeTime

**场景**：查询某业务员的拜访情况
1. `employeeList` → 获取员工ID
2. `salesVisitList`（见统计/拜访统计.md） → 传入 saleIds + rangeTime

## employeeSettingById

**功能**：根据员工ID查询该员工的新客默认设置，包括区域、仓库、商品授权方案、客户分类、价格等级、定价类型、价格记忆、结算模式等配置信息。用于查看业务员拉新时新客户的默认配置。

**典型场景**
- 查看某业务员的新客默认配置（仓库、授权方案、价格等）
- 审核商机前查看推荐员工的新客设置
- 核对业务员的新客价格策略和结算模式
- 创建客户时参考员工的新客默认配置

**参数**

| 参数 | 类型 | 必填 | 数组 | 说明 |
|------|------|------|------|------|
| employeeId | NUMBER | 是 | 否 | 员工ID，路径参数，要查询的员工ID |

**响应数据**
- 返回类型：`OBJECT`

| 字段 | 类型 | 说明 |
|------|------|------|
| id | NUMBER | 设置ID |
| employeeId | NUMBER | 员工ID |
| employeeName | STRING | 员工名称 |
| regionId | NUMBER | 区域ID |
| regionName | STRING | 区域名称 |
| warehouseId | NUMBER | 仓库ID |
| warehouseName | STRING | 仓库名称 |
| authorizationId | NUMBER | 商品授权方案ID |
| authorizationName | STRING | 商品授权方案名称 |
| customerCategoryId | NUMBER | 客户分类ID |
| customerCategoryName | STRING | 客户分类名称 |
| priceLevelId | NUMBER | 价格等级ID |
| priceLevelName | STRING | 价格等级名称 |
| priceMode | NUMBER | 定价类型（1:成本价 / 2:基准订货价 / 3:分销订货价） |
| recentOrderPriceStatus | BOOLEAN | 价格记忆（是否开启最近订货价） |
| fundInfo | OBJECT | 结算模式信息 |
| fundInfo.payPeriodType | STRING | 账期类型（MONTH:月结 / CONSTANT:定期结算 / NO_CONSTANT:不固定帐期 / MONEY_BEFORE_CARGO:先款后货 / CARGO_BEFORE_MONEY:货到付款 / 滚动结算: ROLLING） |
| fundInfo.billDay | STRING | 结算周期（定期结算的结算周期） |
| fundInfo.repaymentDay | NUMBER | 付款期限/付款日（定期结算的付款期限 / 月结的付款日） |

**前置接口**
- `employeeList`：查询员工列表 → 获取员工ID
- `findOrderEmployees`：查询业务员列表 → 获取业务员ID

**后续接口**
- `createMerchant`：创建商机（客户与商机/商机-新增.md）→ 使用员工的新客默认配置
- `createCustomer`：创建客户（客户与商机/客户-新增.md）→ 参考员工的新客设置

**注意事项**
1. **employeeId 为路径参数**，不是请求体参数
2. 如果员工没有配置新客默认设置，可能返回空或默认值
3. 该接口主要用于查看业务员拉新时新客户的默认配置
4. 结算模式为嵌套对象，包含账期类型、结算周期、付款期限等子字段
5. 定价类型枚举值：1=成本价，2=基准订货价，3=分销订货价

## 跨接口组合示例（补充）

**场景**：查看业务员新客配置并创建商机
1. `employeeList` → 查询业务员列表，获取员工ID
2. `employeeSettingById` → 查看该业务员的新客默认设置（仓库、授权、价格等）
3. `createMerchant` → 创建商机时参考员工的新客配置（warehouseId/authorizationId/priceLevelId等）
4. `auditMerchant` → 审核通过商机（客户与商机/商机-审核.md）

**场景**：核对业务员的新客价格策略
1. `findOrderEmployees` → 查询下单业务员列表
2. `employeeSettingById` → 查看业务员的新客定价类型（priceMode）和价格等级（priceLevelId）
3. 确认价格策略是否符合业务要求
