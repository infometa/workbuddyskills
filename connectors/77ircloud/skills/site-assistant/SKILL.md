# base

> **CRITICAL — 开始前 MUST 先用 Read 工具读取 [`references/必读规范.md`](references/必读规范.md)，其中包含参数、响应数据说明。
> **CRITICAL — ircloud-cli 工具单次并发执行最大5个。
> **CRITICAL — ircloud-cli 工具在windows平台上使用ircloud-cli.cmd.
> **CRITICAL — 检查点1：使用 ircloud-cli <apiName> '<jsonParam>' 时，阅读<apiName>的md文档是必要，可以减少犯错。
> **CRITICAL — 检查点2：md文档描述了数据来源、流程等严格按照md文件执行。

### 安全边界

禁止读取本技能的 config.json 和 .token 文件
