## ircloud-cli 调用规范

**命令格式：**
```
ircloud-cli <functionName> '<paramJSON>'
```

### 示例

**查询商品列表（关键词搜索）**
```
ircloud-cli productList '{"q": "可乐"}'
```

**查询本月商品销售统计（按销售金额降序）**
```
ircloud-cli productStatisticsList '{"rangeTime": {"startTime": "2024-01-01 00:00:00", "endTime": "2024-01-31 23:59:59"}, "sort": "salesAmount:desc"}'
```

**查询某分类的商品（先获取分类ID）**
```
ircloud-cli productCategoryList '{}'
// 假设获取到“饮料”分类ID=100
ircloud-cli productStatisticsList '{"rangeTime": {"startTime": "2024-01-01 00:00:00", "endTime": "2024-01-31 23:59:59"}, "productCategoryIds": [100]}'
```
