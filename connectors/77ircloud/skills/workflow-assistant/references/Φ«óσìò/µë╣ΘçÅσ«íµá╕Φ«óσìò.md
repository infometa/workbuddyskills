# 场景：批量审核订单

**适用意图**：用户说"帮我审核一下XX客户的订单"、"把某段时间内的待审核订单全部通过"、"批量审核本月订单"

**所用接口**
- `customerOrderList`（参考：[site-assistant/references/订单/订单.md](../../../site-assistant/references/订单/订单.md)）
- `orderAudit`（参考：[site-assistant/references/订单/订单-批量审核.md](../../../site-assistant/references/订单/订单-批量审核.md)）

---

## 执行步骤

### 第一步：确定筛选条件
需要向用户确认（若未提供）：
- **时间范围**：审核哪段时间内的订单（必填，跨度不超过1年）
- **客户范围**：是所有客户还是指定客户（若指定，先用 `customerList` 获取 buyerIds）

### 第二步：查询待审核订单
> [customerOrderList](../../../site-assistant/references/订单/订单.md)

**调用参数示例**：
```json
{
  "rangeTime": {"startTime": "2024-01-01 00:00:00", "endTime": "2024-01-31 23:59:59"},
  "buyerIds": [...],
  "orderStatus": ["ORDER_AUDIT_PENDING"]
}
```
- `rangeTime` 为 TIME_RANGE 类型，传 `startTime` 和 `endTime`（格式 `yyyy-MM-dd HH:mm:ss`），时间跨度不超过1年
- `orderStatus` 按需传入：仅审核订单时传 `["ORDER_AUDIT_PENDING"]`；若还需进行财务审核，则传 `["ORDER_AUDIT_PENDING", "FINANCE_AUDIT_PENDING"]` 同时获取待订单审核和待财务审核的订单
- 记录返回结果中每条订单的 `id` 字段（**非 orderCode**）
- 使用 `--page-all` 自动翻页获取全部数据，禁止自行编写循环脚本逐页拉取

### 第三步：分批提交审核
将收集到的所有订单 `id` 列表，**每批不超过10个**，循环调用：
> [orderAudit](../../../site-assistant/references/订单/订单-批量审核.md)

### 第四步：汇报结果
- 收集所有批次返回的失败ID列表
- 若失败列表为空：向用户报告全部审核成功，说明共审核了多少笔
- 若有失败ID：告知用户哪些订单审核失败（可结合第二步查到的 orderCode 映射），建议用户手动处理

---

## 注意事项

- `ids` 必须是订单**主键ID**（整数），不是订单号字符串
- 每批最多10笔，超出必须分批，不可一次传入超过10个
- 若用户未指定时间范围，应主动询问，不可随意假设时间范围
- 若订单数量很多（如超过100笔），需告知用户审核进度
