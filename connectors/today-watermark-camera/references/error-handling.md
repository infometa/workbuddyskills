# 错误处理参考

本参考文档补充 `photo-assistant` 的常见错误处理。任何情况下都必须遵守 MCP OAuth 身份和工具返回的照片可见范围。

## 认证错误

- Access Token 过期时由 WorkBuddy 自动刷新，Agent 不处理或展示令牌。
- Refresh Token 失效或连接被撤销时，引导用户回到 WorkBuddy 重新连接“今日水印相机”。
- 当前用户、团队及 `caller_user_id` 均来自 MCP OAuth 鉴权上下文，不接受用户手工指定。

## 参数错误

- `department_ids` 在所有工具中都是字符串数组，例如 `["123"]`。
- 所有时间范围统一使用 `start_time` / `end_time`，格式为 `2006-01-02 15:04:05`。
- `export_photos.max_count` 是本次任务的导出总量上限，不是分页大小。
- 历史导出列表使用 `offset` / `limit` 分页，并根据 `has_more` 判断是否继续。

## 权限与空结果

- 权限不足或可见范围为空时，直接说明当前账号无权查看或当前筛选范围无数据。
- 不得通过更换团队、用户或部门参数绕过权限。
- 非 VIP 团队可能只可见最近 91 天，以工具返回的实际时间范围为准。

## 超时与上游错误

- `search_photos` 优先使用较小的 `page_size` 分批查询，并正确传递 `last_page_cond`。
- 上游超时、限流或暂时不可用时，说明当前状态并建议稍后重试，不编造照片、统计结果或下载地址。
- 导出为空时不要生成虚假任务；异步导出提交成功后，由下载列表展示进度。
