# 企业画像到目标买家

这一工作流把企业画像、目标买家筛选和后续入池衔接起来，以实际查询结果和操作回执为准。

1. 查企业基本资料和产品；缺少主营产品、目标国或买家类型时标“待确认”。
2. 按采购角色分组，而不是按产品数量机械拆分。同一买家类型可合并产品，不同类型分别搜索。
3. 用产品英文词、国家、真实展会 ID 搜索。翻页同时更新页码和游标；对候选抽查公司简介、产品关系和采购角色。
4. 同行搜索可帮助识别直接竞争者，但制造商也可能是零部件的买家，不能按单个标签排除。
5. 给出候选依据和不确定项。用户纠偏先用于本轮；只有服务端具备画像写入工具且用户明确要求长期生效，才更新长期偏好。
6. 要入 WorkBuddy 场景中的小元线索池时，按 `lead-pool.md` 去重并执行入池；只有收到成功回执才报告已入池。
