# 线索池业务字段参考

以下是业务语义目录，用于字段映射、查询、显示和回写检查，不指定 WorkBuddy 的数据库、表数量或内部 ID 格式。真实存储字段以服务端契约为准。

## 接口事实

| 业务字段 | 原接口来源／含义 |
|---|---|
| 线索ID | id，不能为空 |
| 买家CDPID、联系人ID | companyCdpId、purchaserContactId，工具间关联 |
| 买家公司名称、买家公司简介 | buyerCompany、companyProfile |
| 买家国家 | buyerCountry |
| 产品类别T1、产品类别T2 | t1、t2 |
| 需求意向、关注产品 | recentTrend、格式化的 productList |
| 买家类型、买家特征 | buyerType 原值、buyerTag |
| 报名参展展会、需求时间 | exhibitionName、lastConsolidatedTime |
| 企业键、来源、唯一去重键 | 当前授权企业、真实线索来源、企业范围内稳定去重标识 |

企业画像名称与买家公司名称是两个不同对象，不能混写。联系方式从授权详情获取，普通摘要字段不承担联系人权限。

## AI 匹配

AI匹配分、AI原始分、反馈扣分为数值；AI匹配等级为高／中／低；核心匹配通过为布尔值。另保留 AI匹配理由、评分明细（逐维分值与证据）、线索明确MOQ、评分权重版本、企业画像版本、画像企业名称、运行上下文ID、AI处理时间，以及用于验证企业上下文的标识。评分不能由一段生成文案替代。

## 用户反馈和跟进

- 是否匹配：待确认、✅ 匹配、❌ 不匹配。
- 不匹配原因：产品名称不匹配、产品类别不匹配、买家类型不匹配、国家不匹配、MOQ不匹配、买家标签不匹配、买家简介不匹配、需求意向不匹配、需求已过期、线索质量低、重复线索、其他。
- 反馈说明、反馈人、反馈时间。
- 跟进状态：未跟进、已联系、已回复、已转化、关闭；另有跟进备注。

这些字段属于用户业务记录，接口事实刷新和重新评分不得覆盖它们。

## 解锁与系统追踪

是否解锁（未解锁／已解锁，初始未解锁）、解锁人、解锁时间、解锁方式、解锁推送消息ID／展示回执。WorkBuddy 界面操作与对话指令分别记录来源，但汇入同一成功状态。

系统记录首次入池时间、最近更新时间、首次推送时间、最近推送时间、推送次数、最近推送批次ID、推送消息ID，以及授权的 WorkBuddy 会话／用户上下文。跨企业记录拒绝写入；当前会话只是业务投递上下文，不能代替企业权限。

## 字段类型与检查

规范化字段类型可包括 text、long_text、number、checkbox、person、datetime、single_select、multi_select。映射具体数据库类型由服务端完成。新增字段可按已批准契约补齐；类型冲突、主键缺失和必需选项缺失均报告，不自行转换。历史字段版本的迁移须按管理员明确授权执行，不因更新 Skill 自动迁移。
