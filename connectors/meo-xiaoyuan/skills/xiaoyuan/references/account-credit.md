# 企业账户、Credit 余额与平台充值

## 企业 Key 与平台入口

WorkBuddy 的小元连接器采用企业 API Key。Key 获取入口为 https://xyconsole.tradechina.com/key ：进入“出海精灵·小元 → Key与平台 → 复制 API Key”，在 WorkBuddy“连接器管理 → 出海精灵·小元 → 配置”中填写并保存。密钥只在配置表单处理，不要求用户粘贴进聊天。平台控制台入口可使用 https://xyconsole.tradechina.com/ ；专用充值或询盘登录链接以服务端返回为准，不能把 Key 页面当充值页。

服务端从 Key 解析企业、Credit 账户和权限。不要要求用户再填内部企业或账本标识。连接器未启用／工具不可见时，引导用户信任并启用；仅诊断连接时调用 xiaoyuan_ping。

## 余额查询

用户主动询问余额，或查询、解锁、触达操作返回余额不足时，调用 xiaoyuan_get_company_credit_balance。按真实结果显示当前可用 Credit、单位与账户状态；冻结、已用或有效期等只有返回了才展示。不将未知余额当 0，不猜人民币兑换比例，不在每次业务前自动查余额。

## 充值与继续原任务

1. 用户要求充值或余额不足时，读取余额／账户工具返回的充值入口，或调用实际提供的充值入口工具。
2. 只交付本企业的有效链接；金额、套餐、币种、支付方式和链接有效期取真实返回值。没有返回入口时，给平台控制台并说明需要在那里打开充值，不编造专用路径、租户参数或价格。
3. 由用户在平台确认金额并支付；打开链接或用户说“已付款”都不作为已到账证明。
4. 用户回来要求继续时，重新查余额；有订单查询工具则核对订单状态。未到账按回执解释，不代用户重复创建支付。
5. 到账后先查原任务／原询盘状态；只有仍待处理才继续原操作。业务范围未变且原授权仍有效时沿用，费用或范围改变时再确认。

## 询盘解锁余额不足

REJECTED_CREDIT_INSUFFICIENT 表示该次未开通，可能是余额不足或账户停用。保持待解锁状态，转余额／账户查询；充值或账户恢复后，回查询盘是否仍在可解锁时段，再重试同一询盘。平台生成幂等标识并在同一事务中扣费和开通；小元不自行扣点、生成替代扣费键或承诺退款。若时段已过，按实际状态处理。

企业小元 Credit、企业自有 WhatsApp 通道费用和邮件服务费用属于不同计费上下文；除非服务端明确统一计费，不将它们混为同一个余额。

## 异常

企业 Key 的 401/403：更新连接器配置；余额不足：引导充值并核对；账户停用：按实际原因联系平台处理；未知扣费结果：先查原回执与余额，不重复扣款。不向用户展示密钥、内部账本 ID 或其他企业信息。
