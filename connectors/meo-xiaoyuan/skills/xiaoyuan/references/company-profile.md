# 企业画像、产品主图与手册

## 读取与增量更新

先通过企业基本信息、产品列表和用户提供资料了解企业。用户确认的业务目标需要保存资料时，使用企业画像写入工具；先读现值，只传本次有来源且经授权的字段，不用空值清空其他资料，也不把全部现值重新覆盖。保存后回读核对，只有布尔受理结果不足以证明所有字段已生效。

原企业接口的业务字段对应如下；实际参数按当前工具契约传递：

| 字段 | 内容与语言 |
|---|---|
| companyName / companyNameEn | 企业中文名／英文名 |
| advantage | 有依据的英文公司亮点介绍 |
| adProducts | 英文产品关键词，多值逗号分隔 |
| productTags / briefInfo | 主营产品标签（保留原文）／企业简介 |
| businessModel / employees / yearFounded | 经营模式／规模／成立年份，年份为整数 |
| address / email / phone / website / whatsapp / faceBook / linkedIn | 已确认企业联系资料，地址按业务需要使用英文 |
| targetMarket / targetRole | 英文目标市场／采购角色；用户展示用中文 |
| cooperationCondition | 有来源的买家认证或合作条件 |

只保存正式企业画像，不混入买家公司的档案；企业上下文与版本必须一致。同步失败记录并说明未确认的部分，不阻塞不依赖这些字段的只读研究。

## 产品主图

首次触达任务缺产品主图时一次性索取；有已授权的有效主图则复用。每个企业维护一张当前主图，记录企业、素材标识和更新时间；支持本地文件或公开可访问图片 URL，实际支持格式以接口为准。用户更换主图时按授权同步替换当前素材和索引，避免引用旧路径；旧素材清理由服务端按已授权保留策略完成，不在客户端直接删除文件。不跨企业取图，不以占位图冒充。后端返回 imageDefaulted=true 时明确说明使用平台默认图。内部路径不作为业务信息展示。

## 产品手册

使用企业最新且用户授权的 PDF 产品手册；多份时按明确日期／版本选最新，同一内容以 SHA-256 去重。上传保存能力对接企业 saveCatalog 业务，参数为实际文件；后传会替换企业当前手册，按用户授权处理。成功后记录手册标识和哈希；缺文件则不上传，不编造。保存与任务图片上传是两个动作，不能互相替代。

## 纠偏与持续理解

本轮纠偏即时用于搜索和推荐；用户希望长期生效时将偏好保存到正式画像并保留版本。线索“不匹配”及原因留在线索池中，不用一次反馈静默重写整个企业画像。
