# 维度可达性声明（yj-fin-bank）

本文件说明本技能各数据维度的可达性，以及缺失时的标准措辞。核心：可用维度正常用并就近标注；不可达维度如实标"待补充核验"，绝不编造。

## 二、不可达维度（如实标注，绝不编造）

| 维度 | 状态 | 缺失时标准措辞 |
|---|---|---|
| 工商登记 / 股权结构 | 本技能无专库 | "受数据可得性限制，权属与工商登记信息待补充核验" |
| 司法冻结 / 查封 / 诉讼 | 本技能无专库 | "受数据可得性限制，权属限制与涉诉情况待补充核验" |
| 央行征信 / 企业及个人征信 | 本技能无专库 | "受数据可得性限制，征信与信用记录待补充核验" |
| 一级市场融资库 | 本技能无专库 | "受数据可得性限制，历史融资与轮次信息待补充核验" |
| 非上市主体财务 | 本技能无专库 | "受数据可得性限制，标的财务数据待补充核验" |
| 银行授信意向 / 各行报价 | 本技能不对接银行 | "银行方案须来自用户上传询价结果，无则标待用户补充" |
| 公网检索 | 网关受限 | "以用户上传材料与可及研报、公告旁证为准" |

## 三、铁律（不可违反）

1. **缺即如实"带待补充"**：不阻塞出报告，也不假装用"其他来源"把空缺填成"查过的样子"。
2. **绝不假设**：不假设无诉讼、无冻结、无不良征信、无股权瑕疵。
3. **绝不倒推**：不按金额倒推轮次、不按区间倒推参数、不虚构银行利率或授信意向。
4. **绝不编造**：不编造股东名册、持股比例、银行报价、还款能力。
5. **主动交叉验证（强制）**：关键数字（利率、抵押率、占比、DSCR 参数等）以 ≥2 独立源交叉核对；业务材料主张与独立源不一致处显式标注差异。
6. **来源就近标注**：每个数字标注来源类型与基准日；估算与假设单列标明"假设"。

## 四、用户材料优先原则

接入数据用于**旁证与交叉验证**；融资分析的核心依据（借款主体资料、财务报表、申贷材料、担保物权证、银行询价结果）以**用户上传材料**为准，标注 `[用户提供]` 或 `[项目方材料]`。二者不一致时，显式标注差异，不静默取其一。
