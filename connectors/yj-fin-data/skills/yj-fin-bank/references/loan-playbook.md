# 债权融资结构分析实操手册（参考）

本文件为「银行信贷与项目贷款 · 融资结构分析」技能的执行参考，提供品种对比、材料清单、增信工具箱、比选维度、退回原因与测算模板。所有口径为通用实务框架，具体以经办银行最新制度与监管规定为准；涉及授信审批与法律登记事项，以持牌机构意见为准。本技能仅做结构诊断与方案比对参考，不做对外对接或谈判促成。

取数口径：行业利率（LPR）、可比主体融资条款区间、政策工具条件等，优先以用户上传材料为主，辅以  可及的研报/公告/行情财务旁证交叉核对；工商登记、司法、征信、银行报价等不可达维度一律标"受数据可得性限制，待补充核验"，不编造。

## 一、融资品种对比

| 品种 | 适用用途 | 期限 | 还款来源 | 担保偏好 | 注意点 |
|---|---|---|---|---|---|
| 流动资金贷款 | 日常经营周转、铺货、发薪 | 一般 ≤ 1 年（可循环） | 经营性现金流 | 抵押/保证为主 | **严禁流入固投、股权、房地产** |
| 项目贷款 | 新建产能、产线、基建 | 3–15 年 | 项目自身现金流 | 项目资产抵押 + 股东担保 | 需资本金 ≥ 20%–30%，可研与批复齐全 |
| 并购贷款 | 股权收购 | 一般 ≤ 5–7 年 | 标的企业现金流 + 收购方支持 | 资产抵押 + 股权质押 | 并购交易合规、标的估值合理 |
| 融资租赁 | 设备购置、盘活存量资产 | 1–5 年 | 设备收益/经营现金流 | 租赁资产本身 | 关注 IRR 与表内表外影响 |
| 银行承兑汇票/信用证 | 贸易支付、供应链 | 6 个月–1 年 | 贸易回款 | 保证金 + 信用 | 真实贸易背景，防空转 |
| 科技贷/信用贷 | 轻资产科技企业 | 1–3 年 | 经营现金流 + 政府风险补偿 | 信用/弱担保 | 多在白名单或政策性风险池内 |
| 政策性工具 | 设备更新、科技创新、绿色 | 视政策 | 项目现金流 | 政策性担保 | 再贷款、专项再贷款、政府性融资担保 |

**组合原则**：用途单一则单一品种；多用途并存给组合，标清晰度量与先后顺序；项目贷前先确认资本金到位。

## 二、融资主体与交易类型定位（前置，防错配）

报告开篇先锁死主体性质与交易类型，防债权/股权错配、授信品种错配导致方法/条款口径失真。

| 层 | 典型定位 | 方法取向 |
|---|---|---|
| ① 主体性质 | 国企/上市公司/民企/科技型轻资产/重资产 | 决定增信可得性与综合成本 |
| ② 交易类型 | 流贷/项目贷/并购贷/融资租赁/科技贷/票据/政策性工具 | 决定品种、期限与合规边界 |
| ③ 还款来源结构 | 经营性现金流/再融资/股东支持 | 决定 DSCR 测算口径 |
| ④ 对标参照 | 同类主体、同品种市场条款 | 决定比选基准 |

**易混淆点防错**：流贷误用于固投/股权、项目贷误用于日常周转、债权融资误述为股权融资，均须显式纠正并标注正确口径。

## 四、增信工具箱（按成本与可得性排序）

1. **抵押**：房产、土地使用权、机器设备。成本最低、银行最认；受估值折扣率（抵押率）约束。
2. **质押**：应收账款、股权、存单/国债、知识产权。应收款质押需确权与回款账户监管。
3. **保证**：集团内母公司、关联企业、第三方担保公司；政府性融资担保机构费率低、准入有门槛。
4. **信用贷/弱担保**：科技型企业进入白名单或政策性风险补偿池后可得，利率通常高于抵质押。
5. **政策性工具**：设备更新贷款、科技创新再贷款、绿色低碳工具、政府性融资担保——单列申请，标注门槛与额度上限。

**替代逻辑**：银行嫌抵押不足时，依次评估「加保证人 → 加质押 → 进政策性担保/白名单 → 降额度或缩短期限」。不空许，只给可得性判断。

## 五、银行方案比选七维与综合成本

比选维度（固定七项）：

| 维度 | 关注点 |
|---|---|
| 利率 | LPR±bps，固定/浮动，重定价周期 |
| 期限 | 授信期、提款期、还本节奏 |
| 担保要求 | 抵押物、保证人、质押比例 |
| 放款节奏 | 提款条件、分批放款、账户监管 |
| 综合成本 | 利率 + 担保费 + 评估费 + 过桥 + 顾问费 |
| 提前还款 | 是否允许、违约金 |
| 交叉违约 | 其他债务违约是否触发本条加速 |

**综合成本归一化**：把利率与各项费用年化到「实际年化融资成本」再排序，避免被低表面利率误导。示例口径：

```
实际年化 ≈ 利息支出 + 担保费 + 评估费 + 过桥利息 + 顾问费
          ────────────────────────────────────────────
                          年均用信余额
```

输出对比表 + 综合成本由低到高排序，给出首选与备选。**本模块只做结构比对参考**：银行报价须来自用户上传的各行询价结果，本技能不提供银行对接，不做谈判促成、不替客户去谈；具体授信以经办银行审批为准。

## 六、常见退回原因与对策

| 退回原因 | 对策 |
|---|---|
| 用途不清晰/不合规 | 用途落到具体场景与合同，流贷与项目贷严格分离 |
| 还款来源弱（DSCR 不足） | 补强现金流测算、引入股东支持、拉长期限或降额度 |
| 担保不足 | 上增信工具箱，组合抵押+保证+政策性担保 |
| 财务不规范（两套账/纳税异常） | 规范报表与纳税，提供审计版财务 |
| 行业受限（产能过剩/涉房/高污染） | 换合规表述、切入政策鼓励子项、或寻政策性通道 |
| 资本金比例不足（项目贷） | 先补足自有资金，再申报 |
| 关联交易复杂 | 穿透披露、说明定价公允性 |

## 七、还款测算模板

**核心指标 DSCR（债务偿付覆盖率）**

```
DSCR =（EBITDA − 税金 − 资本性支出）÷ 当年还本付息额
```

- 基础情景 DSCR ≥ 1.3 → 安全
- 压力情景（收入 −20% 或 利率 +100bp）DSCR ≥ 1.0 → 底线

## 八、合规红线速查

- 不虚构用途、不伪造流水与报表骗贷（绝对红线）。
- 流贷不得用于固定资产、股权投资、房地产（监管硬约束）。
- 担保/抵质押须依法登记，不承诺未经登记的效力。
- 不替代授信审批、法律意见、审计；重大融资建议聘财务顾问/律师。
- 综合成本必须含隐性费用，不得只报表面利率。
- 敏感财务数据按保密要求处理，不外发。
- 本技能只做结构诊断与方案比对参考，具体授信以经办银行审批为准，不做对外对接或谈判促成。
