# 科创板可转债发行条件自查清单

> 法规版本基准：《上市公司证券发行注册管理办法》（中国证监会令第206号，2023年2月17日公布施行）。该办法第九条同时废止《科创板上市公司证券发行注册管理办法（试行）》（证监会令第171号），科创板上市公司再融资（含可转债）统一适用本办法。
> 配套规则：上海证券交易所《上市公司证券发行上市审核规则》及科创板相关指引（含2026年2月优化再融资一揽子措施）。
> **时效声明：本清单所列条文为撰写时有效版本，法规可能修订；请以最新监管原文核验，不保证现行有效。自查结论不构成法律意见或监管认定。**

## 使用方式

本清单供发行人、保荐机构及中介机构**自行对照**使用。逐项填入标的情况后，在"自查结果"列勾选**满足 / 缺口 / 待核实**三态之一；存在任一"缺口"或"待核实"项时，综合结论不得判为"整体满足"。负面清单项触发即提示为"缺口"，但仍应完整列示全部项。

**板块与主体类型定位（前置）**：本清单仅适用上交所科创板上市公司。主板"连续三年盈利 + ROE 均值不低于 6%"门槛**仅约束主板**，科创板不适用，自查时不得误加。标的板块与代码以披露文件为准；跨板对比或误称时显式标注适用层级。

## A. 通用条件（第13条第(一)至(三)项）

| 判定项 | 法定要求 | 自查要点 |
|---|---|---|
| A1 组织机构 | 具备健全且运行良好的组织机构 | 自查是否存在治理失效、三会运作异常、内控重大缺陷；存在则提示"缺口" |
| A2 可分配利润 | 最近三年平均可分配利润足以支付公司债券一年的利息 | 测算：近三年可分配利润算术平均 ≥ 拟发行债券年利息额；不足或亏损提示"缺口" |
| A3 资产负债结构 | 具有合理的资产负债结构和正常的现金流量 | 结合行业均值判断；异常高杠杆、持续大额净流出且无合理解释的，提示"缺口"或"待核实" |

## B. 板块差异化（第13条第(四)项）

| 判定项 | 法定要求 | 自查要点 |
|---|---|---|
| B1 主板盈利/ROE门槛 | 交易所主板上市公司向不特定对象发行可转债：最近三个会计年度盈利，且加权平均净资产收益率平均不低于6%（净利润以扣非前后孰低者为计算依据） | **仅适用于交易所主板**。科创板公司不适用此项，自查时不得误加。若标的主板上市，须按此测算三年 ROE 均值与盈利情况（本案不适用） |

## C. 附加条件

### C1 向不特定对象发行（须同时满足第9条第(二)至(五)项、第10条）

| 判定项 | 法定要求 |
|---|---|
| C1-1 | 现任董事、监事和高级管理人员符合法律、行政法规规定的任职要求 |
| C1-2 | 具有完整的业务体系和直接面向市场独立经营的能力，不存在对持续经营有重大不利影响的情形 |
| C1-3 | 会计基础工作规范，内部控制制度健全且有效执行；财务报表编制和披露符合准则；最近三年财务会计报告被出具无保留意见审计报告 |
| C1-4 | 除金融类企业外，最近一期末不存在金额较大的财务性投资 |
| C1-5（负面） | 擅自改变前次募集资金用途未作纠正，或未经股东大会认可 |
| C1-6（负面） | 上市公司或其现任董监高最近三年受到证监会行政处罚，或最近一年受到交易所公开谴责，或因涉嫌犯罪被司法机关立案侦查、涉嫌违法违规被证监会立案调查 |
| C1-7（负面） | 上市公司或其控股股东、实际控制人最近一年存在未履行向投资者作出的公开承诺的情形 |
| C1-8（负面） | 上市公司或其控股股东、实际控制人最近三年存在贪污、贿赂、侵占财产、挪用财产或破坏社会主义市场经济秩序的刑事犯罪，或存在严重损害上市公司利益、投资者合法权益、社会公共利益的重大违法行为 |

### C2 向特定对象发行（须满足第11条负面清单）

| 判定项 | 法定要求 |
|---|---|
| C2-1 | 擅自改变前次募集资金用途未作纠正，或未经股东大会认可 |
| C2-2 | 最近一年财务报表编制披露重大违规；最近一年审计报告被出具否定意见或无法表示意见；保留意见所涉事项的重大不利影响尚未消除（涉及重大资产重组的除外） |
| C2-3 | 现任董监高最近三年受到证监会行政处罚，或最近一年受到交易所公开谴责 |
| C2-4 | 上市公司或其现任董监高因涉嫌犯罪被立案侦查、涉嫌违法违规被立案调查 |
| C2-5 | 控股股东、实际控制人最近三年存在严重损害上市公司利益或投资者合法权益的重大违法行为 |
| C2-6 | 最近三年存在严重损害投资者合法权益或社会公共利益的重大违法行为 |

## D. 可转债专项禁止（第14条）

| 判定项 | 法定要求 |
|---|---|
| D1 | 对已公开发行的公司债券或者其他债务有违约或者延迟支付本息的事实，仍处于继续状态 |
| D2 | 违反《证券法》规定，改变公开发行公司债券所募资金用途 |

## E. 募集资金用途（第12条 + 第15条）

| 判定项 | 法定要求 |
|---|---|
| E1 | 符合国家产业政策和有关环境保护、土地管理等法律、行政法规规定 |
| E2 | 除金融类企业外，本次募集资金使用不得为持有财务性投资，不得直接或间接投资于以买卖有价证券为主要业务的公司 |
| E3 | 项目实施后，不会与控股股东、实际控制人及其控制的其他企业新增构成重大不利影响的同业竞争、显失公平的关联交易，或严重影响公司生产经营的独立性 |
| E4 | **科创板上市公司发行证券募集的资金应当投资于科技创新领域的业务**（第12条第(四)项） |
| E5 | 可转债募集资金不得用于弥补亏损和非生产性支出（第15条） |

## F. 科创属性披露与审核关注

| 判定项 | 要点 |
|---|---|
| F1 | 科创板上市公司应当充分披露科研水平、科研人员、科研资金投入等相关信息（第40条）；募集说明书应以投资者需求为导向，充分揭示风险，募集资金主要投向主业 |
| F2 | 交易所审核关注：募投项目准备与进展情况、实施能力储备、预计实施时间与整体进度计划；募集资金投向不得用于持有交易性金融资产、借予他人、委托理财等财务性投资和类金融业务（上交所审核规则/审核问答口径） |
| F3 | 再融资间隔期等程序性要求：按未盈利标准上市且尚未盈利的科技型上市公司，前次募集资金基本使用完毕或未改变投向的，前次募集资金到位日6个月后可启动再融资程序（2026年2月上交所优化再融资一揽子措施）；存在破发情形但运作规范的公司，可通过竞价定增、发行可转债等方式合理融资 |

## 自查规则

1. 存在任一负面清单项触发（C1-5 至 C1-8、C2 各项、D1、D2），对应发行方式下该项自查结果即提示"缺口"，并完整列示全部项。
2. 信息缺失无法判定时，该单项自查结果为"待核实"，综合结论为"信息不足"。
3. 向不特定对象发行与向特定对象发行适用不同的附加条件（C1 vs C2），自查前须确认拟发行方式；未指明时按两种方式分别自查。
4. 本清单为自查参考框架，非法律意见或监管认定；最终以交易所审核问询与证监会注册结论为准。
