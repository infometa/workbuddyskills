# 单份自包含 HTML 自查报告结构模板（hu-fin-kcb）

交付物为**单份自包含 HTML**（SVG/CSS 内联，不外链本地资源，双击可开），非 Markdown、非 PDF。章节顺序如下：

## 一、头部一句自查结论

只给唯一综合结论（整体满足 / 存在缺口 / 信息不足），不展开三档。

## 二、标的基本信息（含板块定位）

- 名称、代码（如有）、板块（标注 ① 科创板 层级，并显式排除主板 ROE 门槛误加）
- 自查日期、数据来源、拟发行方式（向不特定对象 / 向特定对象 / 两者分别）

## 三、逐条对照表

表格列：`判定项 | 法定要求 | 标的情况 | 自查结果 | 依据条款`。
- 每项自查结果三态：满足 / 缺口 / 待核实
- 关键数字就近标注来源类型与基准日；缺口与差异显式标注
- 不可达维度写"受数据可得性限制，XX 待补充核验"

## 四、综合自查结论

整体满足 / 存在缺口 / 信息不足（存在待核实项时不得判整体满足）。

## 五、缺口清单与整改方向

对"缺口"或"待核实"项给出可执行的补充材料方向或整改线索；不含确定性监管结论。

## 六、特别事项与自查声明

列示资料限制、期后事项、未决合规事项；声明本框架为条件自查参考，非法律意见、非监管认定，最终以交易所审核问询与证监会注册结论为准。

本报告由祜·Care 与 Gangtise 合作开发，属测试技能，仅供科创条件自查复盘与参考。本报告不构成任何投资建议，据此决策风险自担。如有优化建议或业务咨询，请联系 13386019198。

- 字体：`"Microsoft YaHei","PingFang SC","Noto Sans CJK SC",sans-serif`
