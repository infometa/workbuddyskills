# 价值类型定义与适用场景

评估结论必须锚定**唯一**价值类型；不同价值类型的结论不可直接比较或混用。Step 0 未锁定价值类型时，不得进入测算。

| 价值类型 | 定义 | 典型适用场景 | 参数取向 |
|---|---|---|---|
| 市场价值 | 自愿买方与自愿卖方在各自理性行为、未受强迫下的交易价值 | 资产转让、出资入股、财报目的 | 取公开市场可比案例与成交区间 |
| 投资价值 | 对具有特定投资目标的特定投资者而言的价值 | 战略并购、特定投资人收购 | 含协同效应，须列明协同假设与数值 |
| 清算价值 | 被迫出售或快速变现条件下的价值 | 破产清算、强制处置 | 快速变现系数，通常低于市场价值 |
| 在用价值 | 资产作为持续经营组成部分、不对外出售的价值 | 持续经营企业内的资产组 | 按资产对整体收益的贡献测算 |
| 残余价值 | 资产在寿命终了或拆除状态下的净回收价值 | 报废处置、设备残值 | 扣除拆除与处置成本 |
| 公允价值 | 市场参与者在计量日有序交易中的脱手价格 | 金融资产计量、会计准则口径 | 优先取可观察输入值 |

## 选用纪律

1. **一项评估只锚定一种价值类型**；确需并列（如同时给市场价值与清算价值），须分别给基准日、方法、区间，不得合并成一个区间。
2. **价值类型一经选定，参数取值须一致**：如投资价值可含协同，市场价值不得含特定投资人协同。
3. **区间半宽**统一控制在 ±10%~22%；超出须说明是数据质量还是方法局限所致。
4. **流动性较弱者**（二手设备、非上市股权、受限资产）作锚时须显式计入流动性折让（0.40–0.70）并说明依据。
