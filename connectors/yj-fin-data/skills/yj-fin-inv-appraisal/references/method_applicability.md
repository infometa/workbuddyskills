# 三类基本方法的适用条件与交叉验证规则

## 一、成本法

- **适用**：可再生、可复制的资产（设备、房地产、在建工程、可重建资产组）。
- **前提**：能可靠估算重置成本与各类贬值（实体性、功能性、经济性）。
- **不适用**：收益主要来自无形资产或商誉、重置成本无法可靠取得、资产已无替代用途且收益流可测。
- **公式**：`评估值 = 重置成本 × 成新率 − 功能性贬值 − 经济性贬值`
- **关键参数**：现行购置价、运杂安装费、已使用年限、尚可使用年限、观察法损耗打分。

## 二、市场法

- **适用**：存在活跃交易市场、能取得可比案例（房地产、金融资产、二手设备、上市公司股权）。
- **前提**：≥3 个可比案例，且案例的交易情况、交易日期、区域因素、个别因素均可修正。
- **不适用**：标的特征独特无可比、市场极不活跃、案例信息不足以做因素修正。
- **公式**：`比准价格 = 案例成交价 × 交易情况修正 × 交易日期修正 × 区域因素修正 × 个别因素修正`
- **收敛**：多个比准价格取中位数或均值，并说明离散程度。

## 三、收益法

- **适用**：有独立、可预测收益流的资产（企业、无形资产、收益性房地产）。
- **前提**：收益期、预期收益额、折现率三者均可合理估算。
- **不适用**：收益流无法独立于其他资产、未来收益不可预测、缺乏可靠折现率依据。
- **公式**：`评估值 = Σ 预期收益_t / (1+折现率)^t + 终值折现`
- **关键参数**：收益期（法定寿命/经济寿命/合同期）、折现率（WACC 或行业风险收益率）、终值假设。

## 四、交叉验证强制规则

1. **企业价值、房地产、无形资产**：原则上须采用**两种以上**方法，并以权重或区间收敛。
2. **单一方法**：须在报告中显式说明为何无法采用第二种方法（数据不足 / 市场不活跃 / 资产特征限制）。
3. **差异处理**：各方法差异 > 20% 须说明原因（数据质量、假设差异、方法局限），**不得强行平均**掩盖分歧。
4. **收敛纪律**：先给**单一中性基准**，区间 = 基准 ×(1±半宽)，半宽控制在 **±10%~22%**；禁用保守/中性/进取三档大跨度并列。

## 五、参数来源纪律

- 市场参数（折现率、贬值率、案例价）须有来源与基准日，就近标注（`[研报]` / `[公告]` / `[行情/财务]` / `[用户提供]`）。
- 不可达维度（工商、司法、一级融资、非上市财务）如实标注"受数据可得性限制，…待补充核验"，**不凭记忆填数、不补估数**。
- 假设参数单列标明"假设"，并在敏感性观察中体现其影响（折现率 ±1%、成新率 ±10% 等）。
