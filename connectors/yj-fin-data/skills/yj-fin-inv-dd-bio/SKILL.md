# 生物医药股权投资尽调分析方法论

## 〇、原生取数入口

本技能优先调用以下已注册原生工具取数，并按来源标签就近标注：

- `yj-fin-data（knowledge_search）`：研报 / 观点 / 纪要 / 内部报告（向量检索，取论点与结论片段）——行业背景、可比研究、监管动态旁证。
- `yj-fin-data`：A/港/美股日K、财务三大表、估值分位、题材指数与成分股——可比上市公司财务与估值倍数、交易价格。
- `yj-fin-data（fetch_document）`：读取 / 解析用户上传及数据文件（BP/工商/财报/合同），核心依据以用户上传为准，标 `[用户提供]`。
- **可比公司与行业背景分析由本技能基于 `yj-fin-data` 取数自行完成**：用 `securities_search` 定位可比上市公司 → `knowledge_search`/`fetch_document` 取研报与公告 → `financial_*`/`quote_*`/`valuation_analysis` 取财务行情估值，自行做一页通 / 同业对比 / 投资主线梳理。**不调用任何外部 agent 工具**；标的自身数据以用户上传为准，缺失即标"待补充核验"，绝不虚构。

不可达维度（工商 / 司法冻结 / 一级融资 / 非上市财务 / 公网检索）本技能无专库，照 `references/data-sources.md` 标"待补充核验"，绝不编造。

取数铁律：① 先 `securities_search` 解析带交易所后缀的标准代码，再调对应工具；② 研报 / 纪要 / 观点 / 公告一律经 `knowledge_search` / `fetch_document` / `meeting_summary_list` / `domestic_chief_opinion_list` / `management_discussion` / `qa_list` 实取，不得凭记忆填空；③ 遇 `UNAUTHORIZED`（云极账号未授权）即停，引导用户在连接器里完成授权，绝不编造数据。

## 一、定位与边界

面向生物医药（创新药 / Biotech / 细胞与基因治疗 / 医药商业化平台）的**一级市场投前尽调与投研分析方法论**。覆盖管线进展与临床数据解读、机制与竞品对标、监管路径、财务前瞻建模、峰值销售测算，以及两分法 rNPV（风险修正净现值）估值。

**重要边界**：本技能产出的是**分析框架与复盘参考，非执业评估报告、非法律或监管意见、不构成投资建议**。凡涉及医疗与投资结论，一律只作分析意见呈现，不给确定性买卖或交易建议；凡涉及监管资格、合规结论，一律改写为"条件自查框架，非法律/监管意见"。工商/股权/专利权属等本技能无专库维度，以用户上传材料与可及公开来源交叉核验，缺失如实标注"待补充核验"。

## 二、何时触发

- 用户需要对 Biotech / 创新药企做融资前尽调、BP 穿透、Pre-IPO 估值判断（不绑定具体标的）；
- 需要解读临床数据：双抗 / ADC / TCE / 小分子靶向的读出、机制、峰值；
- 需要测算临床试验读出时间、基于 SOC 的稳赢门槛（HR / mPFS / mOS 阈值）、HR 漂移与非比例风险；
- 需要分子机制、on-target 毒性、同靶点竞品对标；
- 需要人群覆盖、去重与峰值销售测算；
- 需要两分法估值（已商业化 DCF + 在研逐试验 rNPV）、出海净捕获率、一级市场对账；
- 需要公司财务前瞻建模（收入桥 / P&L / IFRS-NonIFRS 还原）、商业化与集采降价判断；
- 需要非药生物医学技术（IIT / 转化应用 / IST / 特许医疗）商业化路径辨析；
- 关键词：创新药、投研、生物制药、管线、临床数据、靶点、ADC、双抗、TCE、rNPV、DCF、峰值销售、两分法、出海授权、BD 收入分层、Pre-IPO、投前尽调、BP 穿透、下一轮可比、退出镜像、股东治理、IP 权属、数字自洽。

## 三、工作流（前置闸门 + 四问脊柱）

### Stage 0 — 标的所处环节定位（前置闸门，不可跳过）

动手分析前，先锁死**标的在生物医药价值链的哪一层**，防止把"靶点/分子"误写成"疗法/方案"导致 TAM、可比公司、估值方法三处连锁失真。生物医药领域按下述四层框架映射（源技能缺失，按 §0.1 标准回补）：

| 层 | 生物医药典型对象 | 方法取向 |
|---|---|---|
| ① 靶点 / 分子 | 新靶点、单机制分子、技术平台（ADC 连接子、双抗平台） | 平台价值 / 授权交易口径 |
| ② 候选药物 / 模组 | 单一在研分子、某适应症候选药 | 逐试验 rNPV |
| ③ 在研管线 / 终端 | 公司多条管线组合、单一已上市产品 | 管线组合 rNPV + 已商业化 DCF |
| ④ 疗法 / 方案 | 多产品组合疗法、商业化方案、平台型公司 | 组合估值 + 收入桥 |

**定位卡五字段（缺任一项须补完）**：精确子领域标签（禁写大类，须写到环节）／价值链位置（上游·中游·下游·系统）／市场数据口径（靶点级·分子级·管线级，明确用哪层）／可比公司对标层（同层对标）／估值方法指引（匹配该层的估值逻辑）。

**易混淆点防错（强制）**：若标的存在常见误称，显式标注——「易混淆点：X 常被误称为 Y；本报告按 Z（第 N 层）口径，市场规模/可比公司/估值方法均据此」。

**判定输入**：用户上传材料 + 官网/BP 产品词 + 可及研报/公告 + 行业标签；泛词与产品实质冲突时**以下游产品实质为准**。不依赖外部工商库。

| **Q3** | 谁在做？（竞争与机制） | 分子机制竞品对标、竞争格局、管线追踪 | `molecular_mechanism_comp.md`（对标前先过 `heme_registry.md` 机制性毒性硬卡） |
| **Q4** | 数据可信吗？（证据分级） | 信息源三级分级、时点核验、置信度标识、边界情形 | `source_whitelist.md`、`edge_case_protocols.md` |
| **操作** | 怎么交付？ | 交付偏好、自审、边界声明 | `delivery_selfaudit.md` |

**致命陷阱**：把所有资产按"峰值 × 单一系数"折算，会忽略已商业化与在研的风险结构差异；把不同试验的 PoS 用一个全局系数替代，会掩盖价值驱动来源。逐试验 rNPV + 四问脊柱是更诚实的拆法。

### 主动交叉验证纪律（§0.1②，强制）

- 对关键数字（HR、mPFS、ORR、入组数、读出时间、财务数字）用 **≥2 个独立源**交叉验证；业务材料主张与独立源不一致处显式标注差异（来源分级标签）。
- 缺口一律写"受数据可得性限制，…待补充核验"，**绝不静默编造或按金额倒推**。
- 取数以 `yj-fin-data（knowledge_search）` / `yj-fin-data（fetch_document）` / `yj-fin-data` + 用户上传材料 + 可及研报/公告为主；**绝不重新引入外部工商/一级融资硬依赖**。
- 禁用"探活 / 未连通 / 故障 / 兜底 / 已降级"等故障词；缺口一律写"受数据可得性限制，…待补充核验"。

### 估值精度纪律（§0.1③，强制，仅含估值章节的技能适用）

凡涉及 RNPV / 估值数字，须叠加以下规则（放正文句或表头列，标题不写"单中性/不进倍数"等自我方法标签括号）：

- **单一中性基准 + 窄幅可谈区间**：先给一个中性基准值，区间 = 基准 ×(1±半宽)，半宽控制在 **±10%~22%**；禁用保守/中性/进取三档大跨度并列当估值结论。
- **非上市股权流动性折让**：非上市/受限权益作锚时，须显式计入流动性折让（0.40–0.70）并说明依据。
- **剔除情绪与题材溢价**：不得以题材热度、市场情绪、政策预期单独上调估值。
- **收入三档情景化**：财务前瞻须给保守/中性/进取三档（base / bear / bull），以情景呈现而非确定性点估计。
- 边界：本纪律是方法论规则，不输出为对具体标的的买入/卖出建议，与文末"不构成任何投资建议"声明一致。

## 四、核心能力（按四问脊柱重组）

### Q1 有效吗——临床证据层

- **读出时间与稳赢门槛** → `clinical_readout_framework.md`：读出时间推算（入组规模/事件数/入组速度/额外随访；OS 需 65–70% 死亡事件成熟，PFS 比 OS 早 6–12 月，ORR 最快）；SOC 对标四层门槛（及格/优秀/稳赢/梦幻，针对具体对照臂定制）；HR 漂移与非比例风险、时间对齐比较、平台期风险。
- **方案翻译 / 统计 / 监管** → `protocol_stat_regulatory.md`：方案术语表、α 分配与成熟度、IIT→NDA/FDA 资格、DDI 机制（CYP3A / HLA-B*5801）。
- **非药技术商业化路径** → `cn_regulatory_pathway.md`：四条路径辨析（IIT / 转化应用 / IST / 特许医疗）+ 818 号令逐条硬卡（第二十条 / 第三十四条 / 第四十九条），结论为**条件自查框架，非法律/监管意见**；乐城价格锚（官方公示 12–19 万区间）。
- **非上市公司治理与 IP 权属核验** → `source_whitelist.md`：法定代表人 vs 团队页、专利发明人、权利人沿革、主体换壳、国资出资路径，以用户上传材料 + 公开公示交叉核验，本技能无专库时标待补充核验。
- **管线论文监督**：PubMed / 顶刊检索、ASCO / ASH / AACR / ESMO 会议动态。

### Q2 值多少——估值与定价层

- **两分法 rNPV 估值** → `valuation_rnpv.md`：
  - Part A（已商业化/临床已成功）：收入 DCF，Σ[收入×经营利润率]/(1+r_comm)^t，r_comm≈10–11%，PoS≈0.90–0.95。
  - Part B（在研，逐试验）：rNPV_trial = PoS_trial × Σ[峰值年化×爬坡衰减]/(1+r_pipe)^(t−今年)，r_pipe≈12%。
  - PoS 逐项填写：阶段基准（Ph1 7–10% / Ph2 16–20% / Ph3 55–65% / BLA 90%）+ 资产/靶点/机制调整（验证机制 +、First-in-class 监管激励 +、难治异质 −）；每个试验 PoS **必须写依据**。
  - 出海/全球两口径：对外授权 → royalty（12–19%）+ 里程碑 PV；保留全球权 → 净捕获率（默认 55%，暴露为敏感性变量）。
  - **一级市场对账三步（必做，rNPV 不能直接当投前估值）**：① 下一轮可比；② 历史投资人锚；③ 退出镜像。三步任一显著偏离都要在报告里显式说明成因。
  - **融资额 × 稀释反算硬卡**：新股东持股 = X ÷ (投前 + X)，二者不可同时讨价还价。
- **估值口径命名纪律**：rNPV 下界/基准档、谈判中枢/可谈区间、上会建议价**三类必须分列成独立行并各自标注口径名与取数路径**；不同口径的数不得直接相减、求均值或并列成同一行。
- **公司财务前瞻建模** → `financial_forecast_model.md`：收入桥（自有产品+授权/里程碑+海外分成+其他管线，逐项枚举）；净利润（毛利+研发+销售+行政+财务；IFRS 与 Non-IFRS 还原）；出海授权交易结构；期权 vs 基础分离、base/bear/bull 敏感性。
- **峰值销售测算** → `peak_sales_model.md`：标签人群 → 去重 → 方案接受率 → 份额 → 净价 → 峰值；韦恩图分流；医保时间差。
- **财报比率 / 经营质量横向对比** → `financial_analysis.md`：净利率恒等式三层分解、基准带法、倍数法失真降权、四维评分卡。

### Q3 谁在做——竞争与机制层

- **分子机制与竞品对标** → `molecular_mechanism_comp.md`：ADC / 双抗 / TCE 结构拆解、on-target 毒性三通路、裸抗占位有效性、双抗 AND-gate；同靶点竞品对标维度（分子形式 / Fc 段 / 选择性 / 安全性排序）。
- **竞争格局分析**：适应症靶点分布、在研管线进度比较、市场份额、差异化护城河；股东结构与治理分析以用户上传材料 + 公开公示交叉核验，本技能无工商专库时标待补充核验。

### Q4 数据可信吗——证据分级层

- **信息源三级分级** → `source_whitelist.md`：
  - 一级：CT.gov / EU CTIS / ChiCTR / FDA / NMPA-CDE / EMA / 交易所披露 / 公司官网 / 顶刊（NEJM / Lancet / JCO / Blood / Nature Medicine）/ 大会摘要（ASCO / AACR / ESMO / ASH）/ Reuters / Bloomberg。
  - 二级：券商研报、主流财经媒体、医院招募帖——需标注来源。
  - 三级：公众号、雪球大 V、投资论坛——必须标注"自媒体来源" + 交叉验证 + 无法验证标 🔴。
  - **时点核验**：搜索索引常误标年份，财务数字以公告董事会审议日为准。
- **业绩会原文检索**：交易所公告 + 公司官网 IR + 官方回放为官方渠道；逐字稿需标注媒体实录口径；优先抓管理层问答。

## 五、交付偏好

1. **结论先行**：第一屏给出判断（推进 / 带条件推进 / 不推进）+ 三个最关键数字 + 最大风险点，再展开论证。
2. **成稿格式**：HTML 单文件优先（内联样式、无外部依赖、可打印）；可归档或对外发送。
3. **结构**：分章节、编号列表、关键数据一律用表格；不允许大段纯文字堆数字。
4. **计算**：详细分步拆解，每个假设与来源都要标，给敏感性区间；假设多次调整显式呈现。
5. **免责边界**：涉及医疗与投资结论一律标注为分析意见，不给确定性买卖/投掷建议。
6. **信息缺失**：无法确认的信息明确标"待核实"，不编造、不推测，并给出验证建议。
7. **审计可见**：数字自审的结果（发现几处、改了什么、哪些复核无误）写进报告的方法论局限章节。

## 十、生成流程（脚本）

本技能的结构化分析经脚本组装为**单份自包含 HTML 报告**（内联图表引擎，离线可打开、双击即用）：

1. 取数 + 用户材料 + 外部核验结论 → 组装报告输入 JSON：`company`（标的/主体名）、`ic_conclusion`（头部一句结论）、`kpi`（概览指标卡）、`sections`（各章节的 `blocks`）、`charts`（图表数据）。
2. `python3 scripts/generate_report.py --data <input.json> --output-dir <dir>` 生成单文件 HTML（文件名 `{主体}_生物医药投前尽调.html`）。
3. 成稿后对照 `references/output-and-pitfalls.md` 逐条核查排版与成文纪律（表格列纪律、禁自曝取数能力、来源就近标注）。

> 渲染器与本技能自包含：图表引擎 `scripts/assets/echarts.min.js` 随包分发、由脚本**内联**进产物，报告运行时零外部请求。
