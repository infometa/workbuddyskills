## 一、核心财务指标

### 1. 盈利能力
| 指标 | 计算方式 | 解读 |
|------|----------|------|
| 毛利率 | (营收-成本)/营收 | 产品竞争力 |
| 净利率 | 净利润/营收 | 整体盈利能力 |
| ROE | 净利润/股东权益 | 股东回报率 |
| ROA | 净利润/总资产 | 资产使用效率 |

### 2. 研发投入
| 指标 | 计算方式 | 解读 |
|------|----------|------|
| 研发费用率 | 研发费用/营收 | 创新投入力度 |
| 研发费用同比增长 | YoY | 研发投入增速 |
| 研发管线数量 | 直接统计 | 管线丰富度 |

### 3. 现金流
| 指标 | 解读 |
|------|------|
| 经营现金流 | 主业造血能力 |
| 现金及等价物 | 资金储备 |
| 现金流消耗速度 | 烧钱速度（月均消耗） |

### 4. 估值指标
| 指标 | 适用场景 |
|------|----------|
| 市值 | 同行业比较 |
| P/S (市销率) | 收入阶段公司 |
| EV/Revenue | 企业价值比较 |
| P/E (市盈率) | 盈利阶段公司 |

## 一·B 经营质量横向对比框架：MNC 基准法

### B.1 净利率恒等式与三层分解
```
净利率 ≡ 毛利率 − S&M% − R&D% − 其他经营费率% ± 非经常项
```
**三层价值分解**：
| 层 | 变量 | 回答的问题 |
|---|---|---|
| **L1 单位经济性** | 毛利率 | 每卖 1 元产品留下多少？ |
| **L2 经营效率** | S&M% / R&D% / 管理费率 | 钱花得是否有效率？ |
| **L3 收入结构** | 创新药占比 / 海外占比 / BD 经常性占比 | 收入的质量与可持续性 |

🔴 **纪律：不要从净利率直接下结论。** 先按恒等式拆到三层，逐层与基准带比较，再归因。

### B.2 基准带法：先建带，再定锚
1. **建可比组基准带**：选取成熟药企可比组，计算三项核心中位数带：C&G&A%、R&D%、Net Margin%。
2. **异常值剔除规则**：超级周期驱动、并购整合失真、业务结构本质不同者不与纯药企同带。
3. **单点对标锚**：为标的另找"业务结构最相似"的一两家作参照，须写明相似点与不相似点。

### B.3 倍数法三大失真机制与降权规则
| 失真 | 机制 | 处理 |
|---|---|---|
| **PE 被一次性授权首付款污染** | 分母含不可持续项目，PE 假性偏低 | 剔除非经常项后再看；或直接降权 PE |
| **PB 被累计亏损侵蚀** | 未盈利 biotech 净资产极薄 → PB 虚高且无信息量 | 未盈利/微净资产公司**禁用 PB** |
| **研发资本化 vs 费用化口径不可比** | 会计政策不同 → 跨公司不可比 | 对比前统一口径，或标注口径差异 |

**结论**：对中国创新药企横向对比，PE/PB 只作低权重参考；主力工具为「**质量分 ÷ 调整后 PS**」性价比框架或两分法 rNPV。

### B.4 四个反直觉判据
1. **R&D% 倒 U 型**：良性高投入 = 有收入支撑的全球 III 期布局；恶性高投入 = 收入基数过小。同是 35% 的 R&D%，含义完全不同。
2. **创新药占比非越高越好**：真正判据是「**创新药增量能否对冲存量下滑**」。
3. **海外收入占比是与 MNC 决定性差距的第一来源**：定价 + 毛利率 + S&M 效率三重机制。
4. **毛利率异常低是商业模式信号**：显著低于同业可能证伪"创新药企"标签（典型：License-in 净额分成模式）。

### B.5 四维经营质量评分卡
四个维度各 25 分、合计 100（权重默认等权，可调）：
| 维度 | 考察点 |
|---|---|
| **商业化质量** | 核心品种增速、放量结构 |
| **销售管理质量** | S&M% 水平 + 同比改善幅度 |
| **研发管理质量** | R&D% 在倒 U 上的位置、管线转化效率 |
| **收入结构质量** | 创新药占比、海外占比、BD 经常性占比 |

**纪律**：① 每项分数必须附理由，可回溯到 B.1–B.4 判据；② 评分是**排序与沟通工具**，不是估值输入——估值仍走 rNPV；③ 跨期复评用同一套锚点。

### B.6 横向对比报告结构模板
```
① 矩阵全景（公司 × 指标，同源同期同口径）
② 与基准带的差距分解（按 L1/L2/L3 三层归因）
③ 四维评分卡
④ PS 交叉验证（质量分 ÷ 调整后 PS）
⑤ 结论与诚实边界（异常值原因、口径差异、数据缺口）
```

### B.7 基准快照（⚠️ 会过期，使用前必须核对报告期）
- **MNC 基准带**：C&G&A% ~27.5%（区间 20–34%）｜R&D% ~25%（18–40%）｜Net Margin% ~14%（−10%~36%）。
- 国内毛利率排序、海外收入占比、四维评分卡排序：**仅作分析对照锚点**，报告期更新后应刷新；若与最新报告期差超过一个报告期，**宁可现场重算**，不引用本节具体数字。

## 二、创新药公司特殊分析

### 1. 管线价值评估
```
管线价值 = Σ(适应症市场 × 成功概率 × 峰值市占率 × 权益比例)
```

### 2. 里程碑事件追踪
| 阶段 | 里程碑 | 价值影响 |
|------|--------|----------|
| 临床前 | IND批准 | 初步验证 |
| I期 | 完成安全剂量爬坡 | 概念验证 |
| II期 | 初步疗效数据 | 重大拐点 |
| III期 | 达到主要终点 | 商业化临近 |
| 上市 | NDA/BLA批准 | 商业化开始 |

### 3. 竞争格局分析维度
- 靶点分布（热门/差异化）
- 临床进度（领先/跟随）
- 疗效数据（安全性/有效性）
- 商业化能力（销售网络）
