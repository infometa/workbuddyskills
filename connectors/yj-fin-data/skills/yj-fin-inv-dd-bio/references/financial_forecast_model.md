# 公司财务前瞻建模框架

> **适用**：任何 license-out 型创新药公司的公司级收入与利润前瞻。
> **本质**：把 `peak_sales_model.md` 的"产品峰值"作为**输入**，叠加授权/分成/其他管线，外推成多年收入与净利润。
> **与 financial_analysis.md 的分工**：本文件做**前瞻建模**（未来收入/利润分拆与拐点）；`financial_analysis.md` 做**已实现财报的比率解读**。

---

## 一、收入桥（Revenue Bridge）—— 5 类分项必须逐条枚举

公司总收入 = Σ 以下分项，建模时**不得合并隐藏**，每项单独给 base / bear / bull：
1. **自有产品收入（中国，本币）**：按产品逐一建模。
2. **授权 / 里程碑收入（License & Milestone）**：一次性或阶段性确认，与"分成"区分。
3. **海外销售分成（Royalty / Profit Share）**：license-out 资产海外商业化后，按合同比例确认分成收入。
4. **其他管线产品收入**：非核心所有获批/在售产品，逐条给峰值与渗透率。
5. **（期权类，默认不含入 base）**：见第六节。

> ⚠️ **穿透性检查清单（必须逐项核对）**：
> - [ ] 是否漏算**核心药的海外收入**？
> - [ ] 是否漏算**组合疗法中"搭档药"的独立收入**？
> - [ ] 上述两项若用户追问，必须**显式回答"已计入 / 未计入"并说明原因**。

## 二、净利润 / P&L 预测框架

自下而上构建利润表：

```
毛利     = 总收入 × 毛利率（创新药 Biotech 稳态 ~78–85%，医保后下行）
研发费用  = 历史趋势外推 + 新管线增量
销售及营销 = 历史趋势外推，但销售费用率随规模经营杠杆下降
行政开支  = 平稳增长
财务收益  = 现金储备利息（大额现金为正时）
```

**IFRS 与 Non-IFRS 还原**：
```
Non-IFRS 归母 = IFRS 归母 + 对海外合作方股权损失分摊 + 股份支付（SBC） + 汇兑损益
```

## 三、出海 / 授权交易结构（通用模板）

海外 partner 式 license-out 结构：
- **首付款（Upfront）**：签约即收。
- **里程碑（Milestone）**：最高可达数十亿，按监管/销售节点触发。
- **销售分成（Royalty）**：低双位数（low-teens %），净销售口径。

建模要点：首付款 / 历史里程碑 → 已计入历史年度；未来仅计**新增里程碑 + 分成**。

### 3.1 收入质量分层：三类 BD 收入，三种估值待遇
| 类型 | 时点特征 | 可持续性 | 估值处理 |
|---|---|---|---|
| **首付款** | 签约时一次性 | 🔴 **不可持续** | **不计入经常性盈利**，单列一次性项目 |
| **里程碑款** | 触发条件达成时确认 | 🟠 阶段性 | 按**概率加权的期权**处理，**不做年化外推** |
| **销售分成** | 随终端销售持续确认 | 🟢 **可持续且质量最高** | **唯一可给予经常性估值倍数**的 BD 收入 |

**铁律**：看到"BD 收入同比 +146%、占营收 18%"这类表述时，**必须先拆解再估值**。销售分成也有口径差异——"终端销售额"与"公司实际确认的供货价/分成收入"是两回事，跨节引用须标明口径。

## 四、组合疗法收入归属原则

- **主导药归因**：联用方案中，收入多"打包进主导药"。
- **搭档药独立增量触发条件**：仅当搭档药**单独获批 + 单独定价 + 单独销售**时，才产生独立收入线（多落在 2028+，属期权）。
- **PoS 按适应症区分**：同一搭档药不同适应症成功率差异大，期权表须**按适应症分别给 PoS 与增量**。

---

## 五、模型校准护栏

1. **市场体量反校**：中国单药峰值 ≫ 该适应症中国 IO 总市场时，份额假设必错。
2. **份额校准规则**：医保后拥挤市场，单药赢线份额 8–14%、冷肿瘤 4–9%；勿用理想值。
3. **净价下行**：随医保续约，净价乘数应可下修至 0.7–0.85×。
4. **敏感性区间**：每项给 base / bear / bull。

---

## 六、期权 vs 基础分离原则

- **base case**：仅含已获批 + 高确定性在研（PoS 高）+ 已结构化的授权/分成。
- **期权 / optionality**：早研、海外（未合作伙伴化）、联用搭档药独立收入、新适应症——**单独建表**，作 bull 上行，不污染 base 拐点。

## 九、集采 / 强制性降价的影响判断

### 9.1 份额方向性：守成者 vs 挑战者
| 角色 | 特征 | 集采的净影响 |
|---|---|---|
| **守成者** | 该品种份额高（如 >30%） | 🔴 **净负面**——降价损失大于以量换价收益 |
| **挑战者** | 份额低（如 <10%） | 🟢 **净正面**——以价换份额，等于"借政策完成准入" |

分析一家公司时须把品种**逐个判定角色**，**不得**给出"集采对公司是利好/利空"的笼统结论。

### 9.2 毛利率冲击恒等式
```
新毛利率 = 1 − 原COGS绝对额 / (原收入 × (1 − 降幅))
```
实战量级：原毛利率 77.1%、降价 50% → 新毛利率 **54.2%**。大幅降价不是"少赚一点"，而是**换一套商业模式**——真正问题是**结构切换速度能否跑赢侵蚀速度**。须在报告中声明本式为静态测算。

### 9.3 出清/准入事件的信息核查纪律
集采、医保谈判类事件是**谣言高发区**。核查三问：
1. **发文主体**——国家联采办还是省级/联盟集采？
2. **文件状态**——正式文件，还是预期/征求意见/媒体报道？**未发布的文件不得作为测算输入**。
3. **品种范围**——是否真的包含所分析的品类。
处理：核查发现不实时，在报告中**单列澄清框**写明"该组数据不实、本报告不采用"。
