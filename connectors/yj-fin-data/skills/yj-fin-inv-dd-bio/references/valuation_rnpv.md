# 估值框架：两分法 rNPV（已商业化 DCF + 在研逐试验 rNPV）

> 适用：创新药企 EV / 股权价值测算。核心思想——**资产状态不同，估值方法不同**：
> - **Part A（已商业化 / 临床已成功资产）**：用收入 DCF 折现，残差风险低。
> - **Part B（仍在开发的临床）**：用 rNPV，**成功率按单个试验填写**，逐试验折现。
>
> **估值精度纪律（§0.1③，强制）**：凡输出估值数字，须叠加——单一中性基准 + 窄幅 ±10%~22% 区间；非上市股权计流动性折让（0.40–0.70）；剔除情绪与题材溢价；财务前瞻含保守/中性/进取三档情景。本纪律是方法论规则，不输出为对具体标的的买卖建议。

---

## 一、为什么分两部分

| 资产状态 | 风险特征 | 估值法 | 折现率 | 成功率处理 |
|---|---|---|---|---|
| 已上市 / 临床已读出成功 | 残差退市+竞争风险 | 收入 DCF | 10~11% | PoS≈0.90~0.95 |
| 注册 III 期在研 | 主要剩批准后风险 | rNPV | 12~15% | PoS 按阶段+资产填 |
| 早研 I/II 期 | 高失败+长周期 | rNPV（小权重） | 12~15% | PoS 低（8~25%） |

**致命陷阱**：把所有资产都按"峰值×单一系数"折算，会忽略"已商业化"与"在研"的风险结构差异，且无法暴露"价值由哪些试验、哪些 PoS 驱动"。逐试验 rNPV 是更诚实的拆法。

---

## 二、Part A — 已商业化资产（收入 DCF）

```
资产价值 = Σ_t [ 收入_t × 经营利润率 ] / (1 + r_comm)^t
```

- **收入路径**：以最近实际年报为锚，按医保放量/新适应症爬坡外推至峰值，再缓慢衰减（专利悬崖）。
- **经营利润率**：单产品约 30~40%（毛利 80%+ 扣 SG&A/管理费）；组合公司取合并口径。
- **PoS**：取 0.90~0.95（仅残差退市/集采超预期降价风险）。
- **折现率 r_comm**：10~11%（已获批，近无临床风险）。

## 三、Part B — 在研逐试验 rNPV（核心）

### 3.0 节点构建前置双硬卡（构建任何 Part B 节点前必须先过）

**硬卡 A：机制全景枚举 checklist（防"单机制窄化"）**
在把任何资产在某适应症中的价值锚定为某条机制轴之前，**强制枚举该分子全部已知靶点/机制轴**，并逐条判定"是否适用于当前适应症"：
- [ ] 该分子的完整靶点清单是什么？
- [ ] 每条轴在该适应症的适用性：逐条标注「适用/不适用/待验证」+ 一句理由。
- [ ] 是否存在「FLT3 非依赖」式的旁路贡献？（多激酶/多通路药物必须专门问）
- [ ] 联用伙伴药各自贡献哪条轴？
- [ ] 交付物"机制"节以**全景表**呈现（轴 × 适应症适用性 × 证据 × 置信度），不得只写单轴。

**硬卡 B：权益/分成事实核查硬卡（防"权益误设"，出海/全球节点必过）**
建模任何海外/全球节点**之前**，先用一手来源核验该资产在目标区域的**权益归属事实**：
- [ ] 核验来源（按优先级）：公司年报管线表（权益列）→ 交易所公告 → 交易公告（首付/里程碑/royalty 结构）→ 公司官网管线页。
- [ ] 产出三列清单：**区域 × 权益持有方 × 分成结构**（自建 / royalty ~x% / 里程碑 / 混合）。
- [ ] 明确每个 Part B 节点落在清单的哪一行；无对应权益依据的节点**不得创建**。

```
rNPV_trial = PoS_trial × Σ_t [ 峰值年化现金流_t × 爬坡/衰减因子 ] / (1 + r_pipe)^(t − 今年)
```

- **峰值年化现金流**：= 标签人群 × 份额 × 净价，或海外用 royalty/净捕获口径。
- **爬坡/衰减因子**：上市年起 3 年爬坡至峰值，持平 ~10 年，之后 5~6 年衰减至 15%~20%。
- **上市年**：按试验当前阶段+入组/随访时长推算读出时间+监管审评（NDA ~1y，BLA/FDA ~1.5y）。
- **r_pipe**：基准 12%，早研/高不确定可上探 15%。
- **PoS_trial：必须逐项填写**，不得用全局单一系数替代。

### 标准 PoS 基准（按阶段，来自 BIO/Informa 行业统计）
| 阶段 | → 获批基准 PoS |
|---|---|
| Ph1 | 7~10% |
| Ph2 | 16~20% |
| Ph3 | 55~65% |
| BLA/NDA 审评中 | 90% |
| 已获批/商业化 | 95% |

### 资产/靶点/机制调整（加在基准上，需在交付物注明理由）
- **机制已被验证**：+5~15%
- **First-in-class 且有监管激励**（孤儿药/儿童罕见病/单臂可批）：+5~15%
- **难治异质人群**：−5~10%
- **联用/早期（Ph1）**：取低值 8~15%

> 每个试验的 PoS 必须写在交付物里并给依据——这是 rNPV 比"峰值×系数"更严谨的地方。

## 四、出海 / 全球权益的两种处理

### 4.1 铁律：peak 一律 =「归公司净捕获」，capture 恒 = 1.0（防双重打折）
| 情形 | 公司实际到手 | peak_rev 写法（capture=1.0） |
|---|---|---|
| 对外授权 | 低双位数 royalty（~20~22%）+ 累计里程碑 | peak = ex-China 毛峰值 × **royalty 运行率** |
| 保留全球权、自建/未来合作 | 净捕获 ~40~60% 毛利后净额 | peak = ex-China 毛峰值 × **净捕获率**（默认 55%，暴露为敏感性变量） |

- 净捕获率 55% 隐含"自建美国商业化"；若改为 20~25%（纯 royalty 路线），全球价值缩水 2~3 倍——**必须在交付物标注此假设**。

### 4.2 节点必含「地理」字段
每个 Part B 节点**必须带地理标记**：`中国` / `海外` / `全球`。规则：中国单区域试验阳性 ≠ 自动获得海外峰值；海外需伙伴另行启动全球 III 期，否则不得计入海外节点或仅以小概率期权计入。

## 五、汇总与 EV 桥

```
EV    = Part A + Part B
权益值 = EV − 净现金（现金−有息债）
隐含空间 = 权益值 / 当前市值 − 1
```

**非上市股权流动性折让**：非上市/受限权益作锚时，须显式计入流动性折让（0.40–0.70）并说明依据；rNPV 结构性高于交易价（含执行/融资稀释/地缘折价），不得直接当投前估值。

## 六、校准护栏

### 6.1 市值对账自动化护栏（硬触发规则）
算出 EV/权益值后，须与可比对标（下一轮可比/退出镜像）对比：
- **EV / 对账基准 > 1.5×** → 强制自查：全球净捕获率是否过高？ex-China 峰值是否过胖？PoS 是否整体偏松？是否把"中国 III 期阳性"误算成全球捕获？
- **EV / 对账基准 < 0.7×** → 检查是否漏计已商业化资产、或海外/组合疗法收入未计入。
- **0.7× ~ 1.5×** → 视为合理区间，说明 gap 的**分析含义**。

### 6.2 两分法防双计 checklist（强制）
每个适应症只能落在 **A 或 B 一处**：
- [ ] 已获批/商业化中适应症 → **仅 Part A**
- [ ] 在研/未批适应症 → **仅 Part B**
- [ ] 组合疗法：只在主导药节点计一次，搭档药节点不再重复计
- [ ] 节点表加一列"所属分部 A/B" + "地理"，交付前逐行核对无重叠

### 6.3 其他单位/时点铁律
1. **单位铁律**：金额统一为"亿 RMB"；USD 百万($M) → 亿 RMB = $M/100 × 汇率（常见错误：直接 ×7.1 漏掉 /100，导致放大约 100 倍）。
2. **时点核验**：财务数字以交易所公告董事会审议日为准，搜索索引常误标年份。
3. **rNPV ≠ 市值**：中国 biotech 普遍含"执行/融资稀释/地缘"折价，模型值结构性高于交易价。

## 七、交付物标准

- 单份自包含 HTML，SVG/CSS 内联，无外部依赖。
- 必含：
  - **估值对账卡**：EV、股权值、对标基准、隐含上行，四数同屏，并标注触发状态。
  - Part A 表、Part B 逐试验表（**含 PoS 列+依据+地理字段+所属分部 A/B**）。
  - **三档情景敏感性**（保守/中性/进取）：折现率 / 全球 PoS 乘数 / 净捕获率或经营利润率，下游数值实时重算。
  - 🟢🟡🔴 局限与待核实。
- 交付前跑一遍 **§6.2 防双计 checklist**，确认无适应症跨 A/B 双计、组合疗法不重复计。
