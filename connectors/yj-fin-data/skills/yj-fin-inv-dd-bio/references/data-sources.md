# 维度可达性声明（yj-fin-inv-dd-bio）

本文件说明本技能各数据维度的可达性，以及缺失时的标准措辞。生物医药尽调的核心证据（临床数据、监管状态、财务数据）以**用户上传材料 + 可及公开来源（CDE/ FDA/ 交易所公告/ 顶刊）**为主，本技能不提供工商、司法、一级融资、专利权属等外部专库。

## 二、不可达维度（如实标注，绝不编造）

| 维度 | 状态 | 缺失时标准措辞 |
|---|---|---|
| 工商登记 / 股权结构 | 本技能无专库 | "受数据可得性限制，权属与工商登记信息待补充核验" |
| 司法冻结 / 查封 / 诉讼 | 本技能无专库 | "受数据可得性限制，权属限制与涉诉情况待补充核验" |
| 一级市场融资库 | 本技能无专库 | "受数据可得性限制，历史融资与轮次信息待补充核验" |
| 非上市主体财务 | 本技能无专库 | "受数据可得性限制，标的财务数据待补充核验" |
| 专利权属登记簿 | 本技能无专库 | "受数据可得性限制，专利权属与权利人沿革以用户上传材料为准" |
| 公网检索 | 网关受限 | "以用户上传材料与可及研报、公告旁证为准" |

## 三、铁律（不可违反）

1. **缺即如实"带待补充"**：不阻塞出报告，也不假装用"其他来源"把空缺填成"查过的样子"。
2. **绝不假设**：不假设无诉讼、无冻结、无权属瑕疵。
3. **绝不倒推**：不按金额倒推轮次、不按区间倒推参数。
4. **绝不编造**：不编造权属、交易案例、财务数据、可比公司。
5. **来源就近标注**：每个数字标注来源类型与基准日；估算与假设单列标明"假设"。

## 四、用户材料优先原则

接入数据用于**旁证与交叉验证**；分析的核心依据（BP、管线页、财务资料、专利证书、授权协议）以**用户上传材料**为准，标注 `[用户提供]` 或 `[项目方材料]`。二者不一致时，显式标注差异，不静默取其一。

## 五、临床数据特别口径（本技能专属）

- 临床终点（HR / mPFS / mOS / ORR）、试验设计、读出时间，以**用户上传材料 + CDE / FDA / 顶刊 / 大会摘要**为权威源；自媒体/会议转写口径一律降一级并交叉验证。
- topline 仅披露方向、缺 HR/mOS 绝对值时，自动标"数值待大会交叉验证"，峰值改用区间而非点估计，不得用 topline 做精确推导。
- 监管状态（受理/优先审评/获批）以官方登记为准，未披露状态标"待核实"，不推测。
