# 去 AI 化 + 排版与成文纪律（hu-inv-dd-bio）

## 一、去 AI 化硬禁词（命中即改）

- **过程痕迹**：作为 AI 助手 / 根据公开信息 / 建议进一步核实 / 值得关注。
- **工具与系统内词**：skill 名、Reportlab、tyc、zerone、云极、Stage 0、定位闸门、markitdown、docx、xlsx、脚本名、biotech-clinical-monitor（其他技能名）。
- **故障词**：未连通 / 故障 / 会话异常 / 兜底 / 已降级 / 探活。
- **内部指代**：朋友点名 / 核心痛点；与既往报告对照（"上一版误判"）一律不写。
- **数据缺失** → 自然措辞"受数据可得性限制，…待补充核验"，不写"故障 / 未连通"。
- **禁自曝取数能力**：不写"本技能可调用 / 无公开机构库可调用 / 机构库 / 上下游三库"。

## 二、标题禁"主名＋括号方法标签"

标题用自然成句名词，不写"主名（方法标签）"式自贴括号。方法论与质量要求放正文句、表头列或表尾批注。

- **可保留的括号**：仅客观归属型，如 `(A股)` `(海外)` `(公司公告)`。
- **必删的括号**：分级处理 / 不进倍数 / 单中性 / 赋值+依据+证据强度 / 口径治理 等自我方法说明。

## 三、排版与成文纪律（九项，交付前逐条过）

1. **列表项独立成行**：`①②③`／`1. 2. 3.` 等并列项不得用分号或全角空格串接在同一行，每项独立成行或成 bullet（防断号、防粘连）。
2. **一段一要点**：一个段落只承载一个核心观点；多个独立要点各自独立成段／bullet／单元格，禁止"一坨"长段；单元格内禁止用 `+` 串接多个长项。
3. **生成期整段重复自查**：同一内容只写一次；"风险／真实痛点／机遇"等收尾段严禁整段复制两遍，交付前通读查重。
4. **空格与分隔符**：中文并列项写 `A/B/C`、`A·B`（不带空格）；中文语境下 `→` `-` `+` `–` `—` 两侧不带空格（如 `整机-国资主机厂`、`32亿元→2026E`）；纯英文 compound（`EV-Sales`、`2025-11`）保持原样。
5. **特殊 Unicode／装饰符**：优先用 ASCII（写 `10^-7` 而非 `10⁻⁷`、`<=` 而非 `≤`）；不用 `✓`/`✔` 等装饰符号，改用文字（「属实」「是」）。
6. **禁自创伪专业空壳名词**：凡"专业名＋调整／展宽／溢价／折损"结构，先给数值＋来源再命名；无数值支撑的一律改为「待量化，不计入」或直接删除。
7. **约量词不悬空**：「约／大约／左右／近乎」后必须紧跟具体数字（如「约 12 亿元」），禁止「市场规模约—」这类残句。
8. **通篇中文**：正文与表格统一中文；英文术语（PS、ADC、Pre-A 等）可保留但须置于中文语境，不得整句英文残留。
9. **无残留物**：不得出现占位符（`__`／`TBD`／裸「待补」）、半截自我修正残句；同一数字在不同位置口径一致；标题下必须有内容，不留孤立标题或空区块。

## 四、不适用清单（PDF 专属，勿迁移、勿回退）

- 分页／页码／页眉页脚（HTML 无页；且成稿闸门明令"无长页脚"）；
- 封面页：本报告不设封面，版式为「头部一句结论＋概览 → 各模块 → 风险与结论 → 文末声明」；
- 多册分册（摘要／正文／附件分册）：输出归一为**单份 HTML**；
- reportlab／两端对齐 `TA_JUSTIFY`：HTML 无此概念，且属禁词；
- 反引号包裹中文 → ■：浏览器可正常回落渲染，非问题。

## 五、常见坑位（生物医药域专属）

1. **临床数据用代称补全**：topline 缺 HR/mOS 时，不得自行补精确值；标"待大会交叉验证"，峰值用区间。
2. **稳赢门槛套通用值**：四层阈值（及格/优秀/稳赢/梦幻）必须针对具体对照臂定制，不得套用通用值。
3. **rNPV 与交易价混同**：rNPV ≠ 投前估值；须过下一轮可比/历史投资人锚/退出镜像三步对账，并显式说明差额成因（流动性折价、执行风险、地缘）。
4. **口径三档混用**：rNPV 下界/基准档、谈判中枢/可谈区间、上会建议价须分列，不得直接相减或并列。
5. **USD→RMB 放大 100 倍**：`$M → 亿RMB = $M/100 × 汇率`，漏 `/100` 会放大约 100 倍。
6. **非药路径越级主张**：IIT 严禁收费、转化应用收费主体为医疗机构、公司直接向患者收费无合法通道；不得把"院内收费×针数"直接计公司营收。
7. **信息缺失臆断**：工商/司法/专利权属不可达维度一律标待补充，绝不写"无诉讼""无权属瑕疵"。
