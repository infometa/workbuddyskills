# 信息源分级白名单（三级分级）

> 原则：自媒体不是禁用，而是必须标注来源并与官方/权威来源交叉验证后方可纳入结论；无法验证的标注 🔴 待核实。
> 平台约束：本技能运行于通用数据环境，不提供工商、司法、一级融资、专利权属等外部专库；此类维度以**用户上传材料 + 可及公开来源（交易所公告/招股书/监管公示）**交叉核验，缺失如实标注"待补充核验"。

## 六、三级来源（自媒体/社群，⚠️ 需标注+交叉验证）

以下来源**可用但须严格遵守**：
1. **明确标注**"自媒体来源"或"社群来源"。
2. **交叉验证**：与一级/二级来源比对，一致方可纳入结论；不一致则标注冲突。
3. **无法验证**的标注 🔴 待核实，不得作为事实陈述。

### 仍禁止
- ❌ 无法溯源的"据说"、"内部消息"、"传闻"
- ❌ 伪造或明显 AI 生成无出处的内容
- ❌ Wikipedia 作为引用来源（仅作初步了解）

---

## 七、数据验证优先级

1. **一级（首选）**：监管机构公告、临床试验官网、公司官方公告、顶刊/会议摘要
2. **二级**：权威期刊论文、券商研报（标注）、主流财经媒体、医院招募帖（标注）
3. **三级**：自媒体/社群（标注+交叉验证，否则 🔴）
4. **谨慎使用**：其他来源，需交叉验证

> **交叉验证铁律**：任何关键数字（HR、mPFS、ORR、入组数、读出时间）若仅见于三级来源，必须找到一级/二级来源佐证，否则不得写入结论，只能以"据XX（自媒体）称，待官方确认"形式呈现。

## 八、时间 / 日期核验（时点核验）

> **核心原则：引用任何"历史业绩/财报数字/读出时间"前，先核验披露时点，再决定是否引用。** 搜索索引与自媒体常**误标年份**，直接照搬会污染整轮分析。

### 1. 港交所董事会审议日为准（港股财报节奏）
- 港股年报 / 半年报以**董事会审议日**为真实披露日，常滞后于自然季末。
- **动作**：引用半年报/年报前，先确认该期是否已发布；未发布则以**卖方共识前瞻**为锚，并在结论中显式标注"以共识为锚，披露后回填"。

### 2. 读出时间 / 会议窗口核验
- 临床读出时间须区分"数据读出（会议/公报）"与"监管动作（FDA PDUFA / NMPA 获批）"，两者时点不同。
- 会议窗口（ASCO 6月 / ESMO 9月 / ASH 12月）只决定"读出披露窗口"，不等于"数据成熟日"。

### 3. 时点标注硬规范
- 所有财务/临床数字必须带**发布日期或时期标签**（如"2025A"、"2026E（共识锚）"）。
- 对"未来事件"（读出、获批、审议日）明确给**区间 + 锚定时点**，避免写成已发生。

## 九、检索策略分层表

> **用法**：开工前按任务类型领一套检索组合，**跑满再开始分析**。不要边分析边补检索（会漏，且容易被已有结论带偏）。

### 9.1 四类任务的检索组合
| 任务类型 | 第一落点（一级源，必查） | 关键词组合 | 必查的"反直觉"检索项 |
|---|---|---|---|
| **临床读出** | CT.gov / EU CTIS / ChiCTR + 会议摘要库 | `<药物代号> <适应症>` / `<NCT号>` / `<申办方> phase <I/II/III>` | ① 同适应症的历史失败试验；② 试验的**历史版本**；③ 次要终点与亚组 |
| **估值建模** | 年报/中报管线表（权益归属权威）+ 交易所披露 + 公司 IR | `<公司> 管线 权益` / `<公司> license out agreement` | ① **合作方年报里的同一笔交易**；② 已终止/已退回的授权；③ 里程碑条款触发条件原文 |
| **竞品对标** | 同一级临床源 + FDA/EMA 说明书 + 顶刊/会议 | `<靶点> <分子形式>` / `<靶点> head-to-head` | ① **已终止项目**；② 早期数据缺失的竞品；③ 剂量-毒性悬崖数据 |
| **治理/股东** | 交易所披露（权益披露/公告原文）+ 公司章程 + 董事会构成公告 + 用户上传工商/专利材料 | `<公司> 权益披露` / `<公司> 关联交易` / `<控股股东> 持股` | ① **历史要约/私有化记录**；② 一致行动人关系；③ 关联交易定价依据 |

### 9.2 通用纪律
- **双轨检索**：公司名（含多变体）+ 核心药物代号，两组都要跑满。
- **代号勘误防漏**：检索前先确认正确代号体系。
- **先广后深**：先跑宽口径确认信息全景，再针对具体数字下钻。
- **检索记录留痕**：关键结论旁标注"检索式 + 检索日期"，便于他人复现与后续复查。

## 十、管理层口径偏差硬卡

> 触发条件：管理层在**电话会/业绩会/纪要中口头评价竞品、引用市场数字、或陈述自家进度**时启用。二级信源（会议口径）与一级信源（公告原文）不一致时，以一级为准，偏差本身作为信息记录。

### 10.1 三条强制动作
1. **交叉验证**：管理层对竞品的任何具体表述，必须回**竞品方公告原文/监管记录**核对后才可引用；查不到原文的标 🟡 存疑，不得写入结论层。
2. **偏差双记录**：发现偏差时在交付物并列呈现——「管理层口径（转写原文）vs 一级信源（出处）」，并标注偏差方向。
3. **市场数字降级**：管理层引用的市场规模/TAM/预测一律标 🟡 存疑并附第三方口径对照，**禁止直接进估值输入**。

### 10.2 判读纪律
- 偏差本身是信息：系统性贬低竞品 → 立场提醒；系统性抬高自家 → 预期管理提醒。不因偏差否定其余内容，但该条表述降级为 🟡。

## 十一、非上市公司治理与 IP 权属核验（BP 尽调专用）

> **触发条件**：标的是**未上市主体**（BP、融资材料、FA 初筛阶段）。上市公司有年报/招股书可直接读，非上市公司只能靠**用户上传材料 + 公开公示**交叉。
> **核心风险**：BP 里的「关键人」名单常与工商登记、专利发明人对不上——通常指向实控人结构、代持、或权属待过户。
> **平台约束**：本技能不提供工商/专利权属专库；缺此维度时如实标注"受数据可得性限制，权属/专利沿革待补充核验"，**绝不假设无瑕疵、绝不按金额倒推轮次**。

### 11.1 三组必查的不一致
| 不一致 | 典型形态 | 追问方向 |
|---|---|---|
| **法定代表人 ≠ BP 列为 C 位的人** | BP 团队页写董事长/CEO 是 A，工商法定代表人是 B，而 B 恰是核心专利发明人 | 谁实际掌权？A 与 B 的关系（雇佣/顾问/代持）？投资者尽调函发给谁？ |
| **专利发明人 ≠ BP 团队页** | 核心专利发明人含 B/C/D，BP 只列 C 一人 | 其余发明人是否还在职？其所属主体是否另有公司（竞业/同业竞争）？ |
| **专利权人与 BP 主体不一致** | 专利当前权利人是关联/远景公司，不是拟融资主体 | 是否已转让进主体？转让对价？属**资产注入未完成**（投前估值须扣） |

### 11.2 专利沿革必查项（以用户上传专利证书 + 公开同族查询）
1. **专利申请权转移时间点**：若核心专利在**融资前 12 个月内批量发生权利人变更**，属典型"装资产"动作——按公允价还是零对价转入要看清楚，影响投前估值确认；
2. **原权利人历史**：追到上一手，核查是否存在**对价支付凭证**；
3. **同族与地域**：中国专利 vs PCT/海外同族，判断出海权益是否真在自己手里；
4. **发明人分散度**：10 件专利发明人跨 5 个主体 = 权属风险，须签 IP 转让协议 + 发明人雇佣/顾问协议。

### 11.3 股权/治理的"换壳"信号
- **短期内核动机变更**（10 天内两次法定代表人变更 + 国资股东退出/进入）：先核实是**规范化整改**还是**为融资重排股权结构**（国资背书换手，需问清是否带对赌、回购、优先清算等条款）；
- **国资股东进出的估值含义**：国资背书可给 **10–30% 溢价**，但**不构成价格支撑**——若伴随对赌/回购条款，溢价部分应被条款风险抵消，估值上不做加法。
