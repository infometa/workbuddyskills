# 临床读出时间与稳赢门槛分析框架

> 适用场景：用户给出某项临床试验（截图/编号/NCT），要求"读出时间"与"需要什么数据才能赢"。

---

## 一、读出时间推算模板（4 步）

1. **定位试验参数**：阶段（Ph2/3）、设计（几臂、对照类型）、入组规模、启动/首例时间、主要终点（PFS/OS/RFS/ORR）、登记库 Primary Completion Date。
2. **判定事件数需求**：
   - OS 终点通常需累积 **65%~70% 死亡事件**才成熟。
   - PFS 终点事件累积更快，读出一般比 OS 早 **6~12 个月**。
   - ORR 终点只需 ≥2 次扫描确认（约 3~4 个月随访），读出最快。
3. **估算入组速度**：中国多中心入组通常 **15~18 个月**完成；"无药可治"的迫切人群可压缩到 9~12 个月；抢患者严重的热门靶点会拖慢。
4. **叠加额外随访**：最后入组患者需随访至达到事件数。给出**区间**而非点估计，并标注关键会议窗口（ESMO 9~10 月、ASCO 6 月、AACR 4 月）——中国 biotech 常憋到 LBA 再放。

**输出格式示例**：
```
2025-06 启动 → 2026-Q4 完成入组(999例) → 2027-Q1~Q2 累积足够OS事件 → 首次读出
最晚不迟于 2027-H2；撞 ASCO 2027 公布可能性高
```

## 二、基于 SOC 的稳赢门槛法（四层阈值）

先把"对手牌面"摆成对照基准表（方案 / 中位OS / 中位PFS / ORR / 身份），再给出分层目标：

| 层级 | 含义 | 典型阈值（以OS主要终点为例） |
|------|------|------------------------------|
| **及格线** | 统计显著，但仅追平现有SOC | HR ≤0.80，mOS ≥对照+2月 |
| **优秀线** | 明确临床获益，有差异化 | HR ≤0.70，mOS ≥对照+4月 |
| **稳赢线** | 超越最强竞品，确立 best-in-class | HR ≤0.65，mOS ≥对照+5~6月 |
| **梦幻线** | 改变实践指南级别 | HR ≤0.55，mOS ≥对照+8月 |

**关键原则**：
- 阈值必须针对**具体对照臂**定制，不能套用通用值。
- 主要终点是 PFS 时，用 PFS-HR 和 mPFS 双标尺；是 OS 时用 OS-HR。RFS/ORR 同理。
- 若试验有**历史阳性锚点**，门槛要相应抬高（市场会拿它做参照）。

## 三、HR 漂移与非比例风险（NPH）解释清单

当随访延长后 HR 从低位漂移到高位，**不等于疗效衰减**。标准解释话术：
1. **NPH 本质**：Cox 模型隐含"比例风险"假设，但免疫治疗的瞬时 HR 随时间变化——早期强分离，晚期尾部收敛。
2. **绝对获益才是真金**：HR 漂移时，ΔmPFS 往往几乎不变——中位数随随访右移但差值稳定。
3. **历史先例佐证**：KEYNOTE-189、CheckMate 227、IMpower150 均有类似漂移，+0.10~0.18 属常态。
4. **时间对齐比较**：拿早期 PFS-HR 对标后期 OS-HR 是跨时间截面的非法比较。
5. **平台期风险**：KM 曲线尾部进入平台期后，两组瞬时风险→1，累积 HR 单调递增趋向 1，终值数字会变差，需预警。

## 四、三臂 / 双主要终点 / α 分配解读

- **三臂设计价值**：Arm A(全联) vs Arm B(部分联) vs Arm C(对照) 可直接拆解出"增量贡献"。
- **双主要终点**：OS+PFS 均为主要终点时，需分别通过 α 控制；PFS 阴性不必然 OS 阴性。
- **α 分配与期中分析**：期中分析消耗少量 α，绝大部分留给最终分析。期中未达显著 ≠ 最终不达显著。
- **成熟度与 HR 摆动**：小样本次要终点 α 被压到极严，早期 HR 噪声极高，不能当真值。

---

## 五、锚点数据（II 期）与外推纪律

- 有 II 期强锚点 → III 期是"验证复现"，成功概率更高。
- 无正式 II 期 → 缺少中期锚点，门槛偏保守，市场只能外推其他分子数据。
- 外推时必须标注**人群/方案差异**，禁止跨试验硬减。

## 七、Topline 数据置信度降级协议（自动触发）

当公告仅披露 topline（OS 阳性/PFS 阳性方向，但 **HR / mOS / mPFS 绝对值缺失**）时，强制以下动作：
1. **自动标 🔴「数值待大会交叉验证」**：明确标注"仅 topline，无 HR/mOS"，不得用 topline 做精确 HR 比较或精确峰值推导。
2. **估值降级处理**：该节点 PoS 用保守值，峰值用区间而非点估计，待全文回填后上调。
3. **单区域外推性声明**：若试验为中国单区域，必须注明"海外需伙伴另行全球 III 期，不得自动等同全球捕获"。
4. **已知事实记录**：topline 已确认的方向性事实可写入，但缺失数值一律留空待补。
5. **回填触发**：大会摘要/口头报告发布后，自动重算该节点，并标注"已脱离 topline 降级状态"。

## 八、置信度标识（贯穿所有输出）

- 🟢 高：官方出处（CT.gov/监管/公司公告/顶刊），数据新鲜。
- 🟡 中：多方印证但非直接官方（如券商研报引用、会议摘要）。
- 🔴 低：单一来源或待核实（自媒体需标注+交叉验证）。

## 九、数据门槛设计进阶规则

### 9.1 内部对照锚优先原则
定义门槛参照系时，**三层锚点按序选取**：① 内部锚（同分子不同线数/方案自身历史数据）；② SOC 锚（当前标准治疗，1L 与 2L+ 分开）；③ 最强竞品锚（已有 III 期数据的同类机制在位者）。三条锚各自独立设档，禁止混用；联合疗法第一判据永远是"超越内部锚"。

### 9.2 线数匹配硬规则 + 混合人群读法
- **一线数据绝不能用二线锚评判，反之亦然**。
- **混合人群三条读法纪律**：① 优先看 DoR / 治疗时长；② 要求线数分层表；③ 两种禁止的比较：拿一线/混合 ORR 比 2L 数据（系统性高估），比纯 1L 数据（系统性低估）。

### 9.3 里程碑生存率反推法（随访不足时的可比桥梁）
适用：大会只公布 ORR + 6 个月 PFS 率，无 mPFS/mOS。用已公开 mPFS 锚点反推里程碑生存率：
- 指数分布近似：S(t) = exp(−ln2 × t / mPFS)。KN407 mPFS 6.4 月 → 6 个月 PFS 率 ≈ 52%；HARMONI-6 mPFS 11.14 月 → ≈ 69%。
- **三档门槛**（以 6 个月 PFS 率为例）：不及格 <锚−10pct / 及格 ±10pct / 理想 ≥锚+5pct / 梦幻 ≥锚+15pct。
- **局限（必标）**：指数假设忽略生存曲线平台/拖尾；免疫治疗长拖尾使真实 6 个月 PFS 率**高于**指数反推值，反推锚应作"下界"理解。门槛是**定性判读框架**，须在交付物诚实边界声明。

### 9.4 ORR 陷阱清单（哪些瘤种 ORR 不能代言 OS）
| 瘤种/场景 | 陷阱 |
|---|---|
| **SCLC** | ORR 极高（化疗即 60–70%），ORR 与 OS 几乎脱钩 |
| **HCC** | ORR 与 OS 弱相关；TME 复杂 |
| **单维 ORR 对比** | 公司材料只比 ORR 不比 PFS/OS = 误导 |
| **PFS 短而 OS 长的组合** | 单药两极分化时中位 PFS 数学上不延长，需看 OS + 敏感性分析 |
