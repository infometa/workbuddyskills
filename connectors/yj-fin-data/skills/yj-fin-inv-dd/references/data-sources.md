# 维度可达性声明（yj-fin-inv-dd）

本文件说明本技能各数据维度的可达性，以及缺失时的标准措辞。

## 二、不可达维度（如实标注，绝不编造）

| 维度 | 状态 | 缺失时标准措辞 |
|---|---|---|
| 工商登记 / 股权结构 / 实控人 | 本技能无专库 | "受数据可得性限制，股权结构与工商登记信息待补充核验" |
| 司法冻结 / 查封 / 诉讼 | 本技能无专库 | "受数据可得性限制，权属限制与涉诉情况待补充核验" |
| 一级市场融资库 | 本技能无专库 | "受数据可得性限制，历史融资与轮次信息待补充核验" |
| 非上市主体财务 | 本技能无专库（除非用户上传） | "受数据可得性限制，标的财务数据待补充核验" |
| 知识产权登记簿 | 本技能无专库 | "受数据可得性限制，IP 清单与权属以用户上传材料为准" |
| 公网检索 | 网关受限 | "以用户上传材料与可及研报、公告旁证为准" |

## 三、铁律（不可违反）

1. **缺即如实"带待补充"**：不阻塞出报告，也不假装用"其他来源"把空缺填成"查过的样子"。
2. **绝不假设**：不假设无诉讼、无冻结、无权属瑕疵、无未决索赔。
3. **绝不倒推**：不按金额倒推轮次、不按区间倒推参数、不编造股东名册与持股比例。
4. **绝不编造**：不编造可比公司、交易案例、财务数据、融资轮次与投资方。
5. **来源就近标注**：每个数字标注来源类型与基准日；估算与假设单列标明"假设"。
6. **主动交叉验证**：关键数字用 ≥2 独立源交叉，不一致显式标注差异，缺口"待补充核验"。

## 四、用户材料优先原则

接入数据用于**旁证与交叉验证**；尽调的核心依据（BP/业务材料、财务报表、重大合同、股权与工商材料）以**用户上传材料**为准，标注 `[用户提供]` 或 `[项目方材料]`。二者不一致时，显式标注差异，不静默取其一。
