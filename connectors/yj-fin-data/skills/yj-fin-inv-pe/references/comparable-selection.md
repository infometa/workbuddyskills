# 模块三 · 可比公司对比

> 本行尾注的「一级轮次主锚 / 二级参照上限 / VC 兜底」仅为**本文档内部给模型的思路引导**，是内部工具注释；**禁止搬到报告成稿模块标题或其括号**。成稿中该模块标题用自然成句名词（实例：`三、可比参照`），「分级处理/不进倍数/不跨层混锚/VC 兜底」等一律落在可比表内「链层角色/与标的差异」列或正文句，不写进标题括号。

**核心原则**：对 VC/成长期公司，"光比二级意义不大"——最相关锚是同三级细分赛道 + 同阶段(±1轮) + 同地域的近期一级轮次；二级乘数只作市场参照/sanity check/估值上限，绝不做唯一基准。一级二级都不足再走 VC 法兜底。

## 现实约束(重要)
本技能**无专门一级融资库**（原"执中 company_financing"）。因此"一级可比轮次表"改为一级**轮次公共信息 + 二级可比公司**两条腿，规则如下：
1. **一级事件取数**：从  研报/纪要/观点/投融资报道 + 公司公告/官方披露 + 用户上传融资材料里提取同赛道公司的近期轮次。凡金额/投后估值/投资方可由上述可靠来源佐证的纳入；**无可靠来源的一级事件不臆造，标"公开披露有限，一级可比轮次待补充"**。
2. **无可靠一级数据时**，转用(a)二级可比公司财务乘数 (b)同赛道研报给的一级估值中枢区间交叉，形成估值参照，并**在报告以自然措辞说明局限**："受公开披露与数据源可得性限制，一级可比轮次数量有限，估值以二级可比与行业研报中枢交叉为主，待补充一级案例验证"。
3. **判定原则不变**：同价值链层 + 同三级细分(强匹配，非"fintech"式泛化) + 同阶段(±1) + 同地域(国内/海外分列，不混估值体系) + 近 2–3 年。

## 二级(上市)参照/上限
- 一筛剔除：ST/*ST、跨界转型、营收规模差>10x、业务结构差>60%；二筛按四维相似度锁 ≤8 家。
- **可比乘数适用性守卫(强制)**：先看可比**当前是否已盈利**——PE 适用性仅对稳定/盈利下行公司；对 TTM-PE 为负、PB 明显畸高(如 >20x)、主要靠题材/算力/国产稀缺叙事而非盈利驱动的标的(典型如市梦率级大涨的未盈利芯片/算力股)，其高 PS/高 PB 属"情绪/稀缺溢价"，**不是可持续 PS 定价基准**：
  - 此类标的**不得直接进 PS/PE 可比池或充当一级上限参照**；
  - 若确需呈现，**单列为"题材/情绪参照(不进倍数)"**，并显式标注"其 PS/PB 显著高于其或同业可持续盈利水平、反映稀缺/叙事溢价，仅作天上限之外的市场情绪提示，不参与基准与区间推导"；
  - **能进 PS 基准的**，应当是可独立产出、盈利或接近盈亏平衡、PS 与盈利水平能相互印证的标的；从这类二级 PS 向一级(成长期、未上市)做**流动性/确定性折让**(通常一档区间，如按其二级 PS 的约 1/3~1/2)后再进区间，避免直接拿二级顶点给一级顶格。
- 乘数：TTM-PE / 扣非PE / PS / PB / PEG / EV-EBITDA / EV-Sales(经 `yj-fin-data` 行情财务 or 公告 + 研报盈利预测)。EV = 市值 + 归母净负债。
- **价值链层守卫**：引入不同层公司时单列"参照(不进倍数)"并显式标注"仅产业链参照，不参与估值倍数测算"；倍数池只放同层。

## 估值指标与统计
一级隐含倍数(若有)与二级乘数**分别**剔除 ±3×IQR 极值，各算均值/中位数/上四分位/下四分位 4 组口径，输出乘数统计表供模块四。

## 二级可比取数路径（yj-fin-data MCP）
1. `securities_search` 解析目标与候选；用 `sector_constituents`/`concept_securities`/`securities_search` 自建可比名单，再 `financial_income`/`balance`/`quote_daily`/`quote_daily_hk`/`valuation_analysis`/`earnings_consensus` 逐个拉取营收/净利/ROE/增速/PE/PB/PS/市值自行计算（不依赖任何 agent 结论工具）。
2. 降级：`sector_search` + `sector_constituents` 取板块成分股挑 3–5 家；或 `concept_search`/`concept_securities` 按题材取。
3. 毛利率/净利率须 `financial_income` 实拉（目标 + 每家 peer 并发）；EV-EBITDA/EV-Sales 由市值+净负债(`financial_balance`)+利润客户端算。
4. 字段口径见上方匹配度/运营对标表的字段定义（revenue/revenue_growth/net_profit/net_margin/gross_margin/roe/pe/market_cap 等）。

## 运营对标
近3年营收CAGR、综合毛利率、研发费率、净利率、资产负债率、合同负债增速(用于模块四(二)打分)。

## VC 法兜底(主锚不足时)
一级/二级均不足(pre-revenue/极早/无披露)：
- Scorecard：以近期一级中位倍数为基准按相对差异 ±调整；或 Barbell/情景给悲观/中性/乐观，注明"主锚不足，采用 VC 法兜底"。

## 自检
- [ ] 可比层与定位卡一致(同层优先)；不同层已单列不参与倍数。
- [ ] 可比乘数适用性：未盈利/PB畸高/题材驱动的标的未直接进 PS/PE 池或作一级上限；确需呈现已单列"题材参照(不进倍数)"；能进 PS 的已按二级向一级做折让。
- [ ] 一级数据无可靠来源已如实标注，未臆造轮次/金额/估值。
- [ ] 乘数均附来源行。
