# 排版约束与踩坑清单（成稿前核对）

>## 硬禁规则（成稿生成或自检时**命中即返工**，不进入措辞宽限）
>- **① 报告开场禁"读前须知/基于…/请以就近…做复核"式整句免责**。"这是一份基于《公司 B轮业务材料》＋公告/研报等公开口径交叉的案头区间估算，非实地尽调。请以各数据点就近来源标注与原文为准做复核。"这一句（及任何"这是基于XX材料的案头估算/非实地尽调/请以…为准做复核"同结构开场句）**成稿正文不得一字出现**——此文末固定句承担复核与免责定位。若确需告知"基于什么、没做过什么、读者可自行复核"，只在**开头正文一句内以自然短句顺手带过**（如"本报告基于项目方材料与公开口径的案头整理"，不放大段、不加'请以…为准'的叮嘱式收尾），不再开独立整句提醒(读前须知)。
>- **② 一切模块/小节标题禁"主名＋括号内自贴方法/口径标签"**。"融资与里程碑（材料口径＋可溯源事件）""敏感度对照（对合计系数整体滑动）""核心假设与边界（本案头估算成立的条件）""结论（决策语气）"等——凡标题右侧括号装的是"口径怎么来/系数怎么滑/假设成立条件/写作语气"这类**自我方法说明**，一律把括号连同内容删掉，标题只留包络名（融资与里程碑/敏感度对照/核心假设与边界/结论），该括号内的说明压进该节正文首句或表首/表脚。括号仅允许客观归属型(如 `(A股)/(海外)/(公司公告)`)。
>两条命中任一并修改到位后才能交付。

交付物是一个自包含 HTML 分析报告，投研成品，非工作日志。结构规整、来源可溯、通篇中文、无工具痕迹。

## 排版约束（单份 HTML）
- 多用表格/要点与卡片，**禁大段无分段文字**；单文件内按头部结论 + 定位卡 + 四模块 + 风险结论组织。
- 自包含：图表用内联 ECharts 绘制（五维雷达 + 可比柱/条，见 `scripts/generate_report.py` 从同目录 `assets/echarts.min.js` 读取并内联），**不要外链任何本地资源**；双击 `.html` 即可在浏览器正常显示。
- 字体用系统中文栈：`"Microsoft YaHei","PingFang SC","Noto Sans CJK SC",sans-serif`，无需渲染/CJK 专项处理。
- 结论与估值关键句拆短（每段 <~4 行），便于屏幕阅读；标题层级清晰（h2/h3 对应 Stage0 与四模块）。
- 全部正文统一中文；英文术语(PS/ASIC/Pre-A 等)保留但放入中文语境，不整句英文残留；引号/来源行规范。
- 🔴 **表格列纪律（横向稀缺、纵向免费）**：表格只放**短字段**，逐列声明型别——数字/短标签列用 `num`（不折行、保小数点对齐），**散文列用 `txt`（可折行）**；串长超过约 20 字的文本（差异说明、来源出处、方法口径、调整理由）**不进表格列**，改放表下注解卡片（`.peer-note` / `.table-note`），在**纵向**展开。理由：报告容器实际可用宽度约 950px，横向塞散文会把整表撑成上千像素、顶破页面；纵向空间免费。宽表靠容器 `overflow-x:auto`（`<div class="tbl-wrap">`）承接滚动，不要靠"不折行"硬撑。**别把来源/方法写回表格列**——"表下注解"与"表格列"是两处，写错位置等于把已修的溢出缺陷重新引入。

## 去 AI 化(交付物禁现词)
- 过程痕迹：作为 AI 助手 / 根据公开信息 / 建议进一步核实 / 值得关注。
- 工具与系统内词：pe-vc-analyst、skill 名、yj-fin-knowledge/data/file、Reportlab、Stage0 定位卡、"数据暂缺"外的流程词。
- 故障词：未连通 / 故障 / 会话异常 / 兜底 / 已降级。
- 内部指代：朋友点名 / 核心痛点 → (此类不应出现于面向第三方的产出)。
- 与既往报告对照("上一版误判""已纠正")一律不写——只陈述当前结论本身。
- 数据缺失 → 自然措辞："受公开披露与数据可得性限制，…待补充核验"（不点工具名，不写"故障"）。
- **禁自曝取数能力词**：报告中**不得出现**"本技能可调用 / 无公开机构库可调用 / 机构库 / 执中 / 天眼查 /  文件库 / 上下游'三库' / 单库/多库"等描述"我靠某库取数、某库不存在"的能力型表述。凡欲解释某维度缺失，只允许按上一条自然措辞一句带过（"受数据可得性限制，股权结构/司法/融资明细待补充核验"），不说明内部数据源为何不提供、不出现内部工具/级联词。

**适用范围分流**：本节(禁现词)是"命中即改"的硬约束，可全文检索后直接修订；一旦命中即改，不进下面的"五检"。五检只兜词级之外的文风问题，须懂业务的人通读判断，无唯一对错。成稿按"先查词 → 再做五检"顺序执行。

## 去"自我引用/黑箱"观感（数据边界 + 复核路径）
被第三方评审反复点破两类问题：① 数据全部标同一个来源等于"自己引自己/黑箱"，外部无法验证关键 PE/PB、单产、糖价来源；② 估值最核心参数(初始基准、五维系数)无推导路径。为此成稿必须做到：
- **数据"身份/来源感"随就近标注给，不用"读前须知"固定开场段**：读者想知道"基于什么材料、哪些没做尽调、某个数字能不能自己再查"，由三处自然承担——①每个数据点就近给来源性质(材料中转述/公开口径/作者估算)与"失败不编"纪律注明，②关键硬数(乘数/价/单产/占比…)给时间点+量纲+一句可自行复核通道，③报告开头不再单设"基于…／请以就近…复核"式固定提醒句；结论区可用一句自然陈述点明"系根据项目方材料/转述与可及公开口径整理的案头区间估算·非实地尽调"（不必塞进每个开头），读者要的复核与免责统一由**文末那条固定声明**收口。**不做**"数据边界（读前须知）：本分析以项目方材料…为主的"固定长范文开场——那正是让读者即感"又是模板"的 AI 腔。实质纪律(何种材料/含不含尽调/给复核路径/失败不编/免责不收散弹自吹)一条都不能省，省的是将它做成独立大段模板句的**形式**。
- **数据源品牌词当"来源标签"而非"独立印证"**：报告署名/数据主体统一用"祜·Care及Gangtise合作股权投研"（正文紧凑标签用「及」）。但正文不得把它暗示成某个可与"报告作者"对立的独立第三方判官（读者一旦发现标别人名字其实是作者自己，信任即崩）。做法：该署名品牌并入正文/表脚就近来源标注与**文末固定声明收口**，不再在成稿底部设独立长页脚（"本报告｜署名｜数据源清单｜单位 RMB"式长页脚一律不生成，见下）；凡数据点存在可公开复核的通道（带代码的交易所行情、带编号的研报/公告、官方发布的单产/价），就在该来源标签后就近补一句复核途径（如"取公开行情区间快照，复核请以行情实时为准"），让读者能自行再查而不是只能信这句话。
- **凡乘数/单产/价格/占比等"读者会去查证"的硬数字**：给时间点与量纲（如"报告日附近(2026-06~09)区间""PE-TTM 口径"），并在来源后给一句"若需复核，可据此自行检索对应公开口径"，杜绝"无从下手的黑箱感"。

## 文风自检(五检·成稿期使用)——防"模板感/AI 腔"的成稿体检

词级禁现清单解决"像不像机器拼的"；本五检解决"太整齐、太模板、太安全"的高层文风问题，需要逐条通读判断。

- [ ] **去重复卖点**：结论 / 概况 / 头部一句结论(IC)不得对同一卖点逐字复讲第二遍。同一事实(如"自我造血 xx 万 + 多管线 + 上市近端")在这三处职责应不同——IC 只留最硬一句、概况表格只列事实、结尾结论聚焦决策语气，不排比复述。
- [ ] **去悬浮对冲**：每处"为加分但仍有待……"之类的"先扬后抑"切忌空对冲。优点(附数字/事实)与不确定性(附具体指标或里程碑)应分开、各自落到可证伪对象，不做纯修辞对冲。
- [ ] **去形容词判断句**：结论句一句话 ≤1 个形容词；"稀缺 / 纵深 / 有弹性 / 抗周期"等无界评价词全文 ≤2 处。概览/结论不写堆叠形容词的定性句。
- [ ] **去流程词泄漏**：成品不得出现面向读者的"元解释"括号/自指，如"(可落点)(做说明)(口径说明)(相对区间内打分)"等推理过程词——直接陈述内容本身。
- [ ] **标题禁"主名＋括号方法标签"式写法**：报告模块/小节标题须为自然成句的名词或自足短语，禁止把方法论/质量标签贴在主名后的括号里自证，如"市场规模与产业分工（口径治理）""融资热度（赛道冷热）""估值测算（单中性＋窄幅可谈区间）""五维护目打分（赋值＋依据＋证据强度）"这类写法一律改掉。方法论与质量要求（口径治理、冷热、赋值依据证据强度、系数校准、可谈区间等）写进正文句、表头列或表尾批注，不放进标题括号。凡章节名里出现"(…)"先判断括号内容是"定位性修饰"(如实属客观归属：`(A股)`、`(海外)`、`(案头可比)`，可保留)还是"自我贴方法标签"(分级处理/不做跨层/不进倍数/单中性/赋值+依据+证据等，一律删)。两者都不是时删或移正文。示例：`三、可比参照（分级处理，不做跨层混锚）`——括号为方法自述，删，标题留`三、可比参照`；其"分级/链层不混锚/不进倍数"以可比表内「链层角色」列或正文句说明。
  **（本族易漏的具名变体·命中即删不可放行）**：`融资与里程碑（材料口径＋可溯源事件）`→标题`融资与里程碑`；`敏感度对照（对合计系数整体滑动）`→`敏感度对照`；`核心假设与边界（本案头估算成立的条件）`→`核心假设与边界`；`结论（决策语气）`→`结论`。这些"括号在自述口径来源/滑法/成立前提/写法语气"的，一律按上删括号留包络名，说明压进该节正文/表首/表脚。切勿因括号内容"说得有理"而当作可保留的定位性修饰。
- [ ] **来源标签降密(可选豁免，不删纪律)**：同一数字在正文已附来源后再次出现，不必每处重复贴 `[来源]`；含数关键句/估值区仍须保留来源。此条不与"关键数据须附来源"冲突——简介/概览的豁免是"降密",不是"删来源"。

## 踩坑清单(实战沉淀，逐项自检)
- [ ] 工商/股权/IP 字段有权威来源——不因"数据库无源"而编出精确注册资本/持股比例（精确小数多来自幻觉）。
- [ ] 融资轮次从事件判断，不按金额倒推默认轮次；无来源则写"未明确/待补充"。
- [ ] 司法/股权冻结维度持续无数据时，在风险处明确"待人工核验"，**不假设"无诉讼无冻结"**。
- [ ] 未用 fenced code 承载中文（需则用正文段落/表格）。
- [ ] 估值/结论关键句已拆短。
- [ ] `.html` 无未闭合标签/占位符残留，调试后浏览器能正常打开、中文正常显示（本地自包含、无外链）。
- [ ] 通篇中文、无工具名、无故障词、无英语整句残留。
- [ ] 所有乘数/调整项/来源行齐全，无裸数据。
- [ ] **估值参数有推导与敏感度**：五维护目逐项有"依据 + 证据强度(高/中/低)"，且已给合计系数±档敏感度对照表——防止只给一个"乘得正好"的系数制造伪精确。
- [ ] **凡点出假设超现实必重算**：正文若有"某参数显著高于现实(单产/糖价/出成率等)"，必须给出该参数下修后的同口径量纲差距与对估值所处逻辑层的对应；禁用纯口头折减。
- [ ] 远期参照行不放「具体点位最大值」（如"远期 30–40 亿"会留下锚定印象）：结论若走期权/底价逻辑，进取备注只给「大致量级区间 + 假设来源（BP归母×大致倍数）」，注明系计划兑现的示意值、非独立预测，不给读者可反推上沿的具体数。
- [ ] 开头无"数据边界（读前须知）：…"固定范文段——每个数据身份(材料/转述/估算)随就近来源标签给出、关键硬数带时间快照与就近可复核途径、结论以一句自然话点"案头/区间估算、非实地尽调"；祜·Care及Gangtise合作股权投研仅作署名并入文末固定声明、不设长页脚（无"署名｜数据源清单｜单位 RMB"页脚行）、正文不当「独立裁判」。
- [ ] 报告没有出现"本 skill"内部词在成品里。
- [ ] **数值口径全文自洽**：封面结论一句 / 头部 KPI / 正文估值结论表 / 结尾结论四处，其中性基准、投前、投后、出让%、区间必须完全一致；任一值修订后，在全文对关键数值（投前/投后/各轮估值/出让%/区间）做一遍**全文搜索扫描**，清掉所有残余的旧口径数字（本次曾封面用"55/投后58.5/6%/47-63"、正文却用"59/62.5/5.6%/50-68"两套并存，易被当结论不可信）。
- [ ] **BP 时间轴/融资矩阵的"轮次-估值"对应**：若可对 PDF 按几何（x0/x1 列）+阅读顺序还原版面，先做**列对齐**判定每个估值归属哪一轮，别只因"卡片未见逐轮标签"就判定"未标注对应"而整体下移一档错配（本次曾把 A22.5/B40/C55/D62 的时间轴误读成 B22.5/C40/D55-62，进而把 C 轮的 55 当 D 轮主锚，D 轮实为 62）。融资轮-估值归属错误会直接污染估值主锚。
- [ ] **"集团合并财务表" 与 "分产品/分线拆分表"分开精读**：引用某一年的"某产品线/某业务线营收"时，必须查该产品线自己那行（含其年份单元格），勿与合并总数张冠李戴，且校验"合并 = 各分项之和"（本次把柔性线 2029 的 15.9 亿错标到 2028；实际 2028 柔性线=12.5 亿、同年合并 16.1 亿=COF约3.6+柔性12.5 才自洽）。凡写"某年某线跳增至 XX 亿"，先加总校验合并并把年份逐格核一遍。

## 结构落地参考（交付单份 HTML）
单一成品：`{公司}_股权投资分析.html`（封面式头部 + 一句结论 + Stage0 定位卡 + 四模块 + 风险与结论；无 A/C 分册、无 FA 建议）。
文件名 "{公司}" 为标的简称占位；用浏览器自查渲染即可，无 PDF/渲染/CJK 专项步骤。

**头部结构必含两项**（避免封面即被质疑"黑箱/无推导"）：
1. **一句 IC**：只给唯一结论档与可谈区间，不用三档；给区间即可，不必展开敏感度（敏感度放模块四表）。
2. **开头不设"读前须知/数据边界"独立块**（强制，曾误把固定范文当开场模板）：报告开头与结论区**均不**再以"数据边界（读前须知）：本分析以…为主的…流转长句"作为固定免责开场——此类加标签、逐字复用模板的"读前须知"段正是被评审点名的那份 AI 感来源。边界事实改用三处**就近、自然**方式交代 (数据身份随就近来源标签、复核途径随关键硬数、结论以一句自然陈述点明"系根据项目方材料与公开口径整理的区间估算·非实地尽调")，不再单开大段模板句。**开场正文不得以固定"基于…／请以…为准做复核"式整句收尾开篇**：即使一句交代取材后即刻进入分析，也**不追加"请以各数据点就近来源标注与原文为准做复核"这类叮嘱式提醒句**——复核以就近来源通道呈现即可，不命令读者去复核。读者要知道"基于什么、边界到哪、哪些需自行尽调"由就近来源标注 + 结论自然句承担，不是靠一段高签名的"读前须知"。
- "祜·Care及Gangtise合作股权投研"仅作**本报告分析者/合作署名**，正文用紧凑标签「及」就近标注即可，不在正文重复长全称、不当作能自动证明数值的"独立裁判"。**成稿底部不设独立长页脚**：不生成"本报告｜署名(分析/署名)｜数据源与可复核公开通道：…｜单位：RMB；口径注释均随文给出"这样一整行长页脚。真实数据源与可复核公开通道改正文就近给：数据点处以 `[来源标签/紧凑品牌]` + 一句可自行复核的公开通道/时间快照呈现，密集落在对应表格脚注。
- **文末统一声明（强制固定款 · 各版本文末唯一收口）**：报告最末只保留固定句，一字不改，前面不再有任何长页脚/来源清单/单位行——

## 去 AI 化增补 + 数据纪律(星驰空天外部评审后)
- **自创"伪专业空壳名词"模式**：给一个未量化/未定义的量起专业名再拿去展宽区间或下结论（如"再计入同向工程风险级差"），属"看起来专业"的硬 AI 腔，禁；凡要展宽必须先给数值+来源。
- **"约/大约/左右/近乎"后必须紧跟具体数字，禁悬空**（星驰曾留"…约—核心差异"缺数字残句）。交付前逐处检查所有约量词后是否立即可复核成数。
- **精确全量/年度数字凡来自模型记忆、未在会话内建档复核的**（如"2025 年入轨卫星 377 颗""总市场 2.83 万亿"），不得仅挂"[行业研报/产业公众号]"工具/厂商标签冒充已取数快照；须补注"公开转述口径，本会话未建档复核"，或降为量级/趋势表述并给出可复核通道让其自证。
- **"待补充核验"表述必须区分三种成因**，不得一律含糊：①本会话所用数据环境未挂载对应库(工商/司法/专利…)且公网受限→写"所载数据环境无对应库、未能独立核验，需补齐XXX快照复核"，别让读者以为"能查没查"；②公开检索已尝试未获→写"已尝试查证 XX 渠道、未获取"；③确为暂缓待做→才写"待补充"。
- **交付物完整性自查**：无处于半截状态的自我修正残句("约—/中位…核心差异")、无占位符、无同一个数字在不同位置口径打架。
