# 模块二 · 行业深度分析（严格八点框架）

标签以行研( 研报/纪要/观点)为独立源核心。**所有市场规模/口径均须引用 Stage0 定位卡的"市场数据口径"与"价值链层"**，禁止把上游芯片/模组当下游设备。

### 数据来源与出处(强制，防"行业数据偏项目方")
- 行业数据**严禁仅依赖项目方 BP**。核心口径至少 2 个独立来源交叉( 研报 + 纪要/观点/垂直线索 + 监管/统计原文 + 公司公告)。
- 每条数据带标签：`[项目方-BP]` / `[研报]` / `[纪要]` / `[观点]` / `[公告]` / `[监管原文]`。
- 冲突以独立来源为准，差异用 `[[红]]…[[/红]]` 标出。**禁止**整段只写 BP 内容、把项目方叙事当客观事实、只写大类。
- 检索建议(多轮定向，勿一把梭)：行业全景 → 国产/海外玩家名单 → 逐家份额/技术 → 与高端差距/壁垒；语句多替换，`yj-fin-data` 的 `knowledge_search`（研报/纪要/观点/公告，按 `start_date`/`end_date` 换词检索）+ `yj-fin-data` 的 `meeting_summary_list` / `domestic_chief_opinion_list` / `management_discussion` 多轮定向；日期用当前年份。

## 第 1 点 · 赛道细分 + 技术准入壁垒
- **三级细分赛道**精准定义(例：`国内载人 eVTOL 整机 - 国资主机厂双构型量产赛道`)，给一级/二级/三级归属、产业链环节、代际位置。
- **技术准入壁垒**：产品相关的审定链路(适航 TC/PC/AC、药械注册、车规认证等)、目标等级、必要国标/行标与认证周期；指出壁垒对"新进入者"与"本项目"分别意味着什么。

## 第 2 点 · 上中下游产业链、卡脖子、国产化水平
上游(材料/核心部件/设备)/中游(整机集成，本项目所在环节)/下游(应用与客户 to G/B/C)。逐项列对外依赖高、国产化早期的**卡脖子环节**；给整体国产化率判定 + 本项目供应链复用/自主可控亮点。

## 第 3 点 · 国内外规模 + 近3年增速 + 未来3年空间 + 增长约束
- **TAM 口径治理(强制)**：市场规模引用定位卡口径(芯片级/模组级/设备级)，禁止混用；TAM/SAM/SOM 三级均注口径与来源。
- 国内外双口径(国内亿元/海外美元)，多源交叉(≥2 独立源)。
- 近三年(最近可得)规模与同比增速，标 CAGR；未来三年给区间(E 值)而非单点。
- **增长约束(3–5 条)**：限制放量的真实约束(认证周期、基建节奏、支付验证、补贴退坡等)。

## 第 4 点 · 融资热度 + 估值体系 + 主流机构 + 冷热判断
- 融资热度：近三年赛道融资事件数量/金额趋势、峰值与拐点。
- 估值体系：说明赛道实际估值逻辑(pre-revenue 禁 PE，多用 PS/EV-Sales、按订单储备×单值、可比远期乘数等)，列代表案例估值。
- 主流机构：活跃 GP/产业方/地方政府基金(仅作竞争格局梳理，来自行研线索 + 用户给定，不作投资人对接推荐)。
- 冷热判断：概念热 vs 量产兑现、分化特征、对融资窗口的含义。
- **一级事件本身(金额/估值/投资方)无可靠来源→显式标注待补充，不按金额倒推轮次**(见 data-sources D6)。

## 第 5 点 · 海内外格局 + 集中度
主要玩家分层(全球/国内，已商业化/取证中/研发期)，列代表企业、状态、份额、技术代差；集中度(CR4/CR5 或四分位)；与模块一"核心优势"联动，点本项目差异化卡位。

## 第 6 点 · 扶持政策 + 合规门槛
国家级/地方级扶持政策按月与文号；合规硬门槛(审定+运行+数据/安全备案等)；说明政策红利对本项目的实质影响(如国资优先通道缩短认证周期)。

## 第 7 点 · 机遇 / 风险 / 真实痛点
- 机遇：政策/需求/技术/国产化四条各 1–2 点。
- 风险：政策/市场/技术/竞争/安全五类。
- **真实痛点(3–5 条)**：产业一线"说出但难解"硬约束(认证周期长、订单多为意向非刚性、现金流依赖持续融资等)。

## 第 8 点 · 对标本项目优劣评判核心指标 + 国产化纵深
站在投资人/FA 视角给评判"本项目 BP 是否值得投"的核心指标清单(~8 项，每项一句话"好/差"标准)，如取证/注册进度、订单真实性(意向vs锁定vs预付款)、国资/主机厂成色与供应链复用、技术壁垒、可控性、商业模式与毛利路径、融资节奏与估值、团队治理。**国产化竞争纵深**定向深挖：全球(高端被谁垄断、壁垒在哪)、国产分档梯队(中端/中高端/高端突破，列定位[芯片/模组/设备]、产品、客户、已知份额，无源标"未公开/估算")、应用分布、与高端差距(量化+根因)、替代拐点、**落到本项目在梯队里的位置**。
