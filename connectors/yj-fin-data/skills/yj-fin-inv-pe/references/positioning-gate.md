# Stage 0 · 实体价值链定位闸门（细则）

根治一类高频硬伤：把上游芯片/模组公司误当下游设备/系统公司（如把"编码器芯片模组商"写成"编码器设备商"），导致市场规模、可比公司、估值方法三处连锁失真。本阶段在写任何分析**之前**执行，产出**定位卡**，被下游四模块强制引用。

## 一、为什么需要这道闸门
复盘案例：某"编码器芯片/光栅尺芯片模组"企业被泛化高频词带偏写成"编码器设备商"，结果：① 市场规模套用设备级 TAM（量级远大于芯片级），份额潜力被高估数倍；② 可比公司选了设备/自动化公司（而非芯片设计公司），估值倍数失准；③ 估值法套设备集成商逻辑(PE/EV-EBITDA)而非芯片设计商(PS/PEG/DCF)。三处失真同源——写报告前没有锁死"标的在价值链哪一层"。

## 二、判定框架（自上而下四层）
| 层 | 典型形态 | 示例 |
|---|---|---|
| 1. 芯片/核心元器件 | 半导体、IC、传感器芯片、光栅尺芯片 | 编码器芯片、光栅尺芯片 |
| 2. 模组/组件 | 芯片+外围组成的功能模组 | 编码器芯片模组、光栅尺模组 |
| 3. 设备/终端 | 整机、仪器、终端设备 | 编码器、光栅尺、测量仪器 |
| 4. 系统/方案 | 软硬一体解决方案 | 产线测量系统、工业软件平台 |

## 三、判定输入（交叉比对，以下游产品实质为准）
- 企业全称 + 官网/BP 产品词（技术/产品表述）；
- 研报/纪要/观点（ 检索）里对它的定性（若上市/有公开报道看公告主营）；
- 用户上传的工商经营范围（如有）。
**关键防错**：泛词(如"编码器")与工商/产品实质(如"编码器芯片/模组")冲突 → 以下游产品实质为准，不被泛词带偏。

## 四、定位卡（下游强制引用，缺失即阻断）
| 字段 | 说明 | 示例 |
|---|---|---|
| 精确子行业标签 | 禁只写大类"半导体"，须到环节 | 编码器芯片/光栅尺芯片设计 |
| 价值链位置 | 上游(芯片)/中游(模组)/下游(设备)/系统 | 上游(芯片设计) |
| 市场数据口径 | 芯片级/模组级/设备级 TAM，明确用哪层 | 芯片级 |
| 可比公司对标层 | 同层（芯片对芯片、模组对模组） | 芯片设计公司 |
| 估值方法指引 | 匹配层的估值逻辑 | PS/PEG/DCF(高研发轻资产) |

**下游四模块显式引用定位卡字段**，不得自行重定义行业/口径；模块二 TAM 口径、模块三可比层、模块四估值法须与定位卡一致，不一致以定位卡为准重写。

## 五、易混淆点防错（强制标注）
标的存在常见误称时，报告内写一句区分：
> 「易混淆点：X 常被误称为 Y；本报告按 Z（价值链第 N 层）口径，市场规模 / 可比 / 估值均据此。」

并建议一句话区分：设备(如编码器)是终端器件，芯片(如编码器芯片)是其内部核心，二者 TAM、玩家、估值逻辑不同。
