# 模块一 · 企业基础画像（字段规范与差异红标）

目标一句话：在"企业自述"与"独立可得证据"之间交叉验证，差异一律红色标注，凡本技能拿不到硬证据的工商/司法维度如实写明"待补充"，不假设。

## 差异红色标注约定（全局通用）
- Markdown 中用 `[[红]]…[[/红]]` 包裹需标红内容。
- 仅当"业务材料提炼"与"独立提炼/旁证"不一致才标红；一致填「一致」。标红处附一句话说明差异性质。

## 0. 股东/股权（含穿透方向）
- 目标把股权穿透到可理解的实体：股东(自然人/机构)→持股基金/SPV→管理人(GP)/出资方，以识别实控人与实际控制结构。
- 数据来源：已上市/有公告企业从公告、管理层讨论、研报股权结构、投资者问答旁证；未上市无公告企业 → 依用户上传材料(章程/工商截图)。**本技能无专职工商库时，凡无可靠来源的持股比例/名册不得臆造**，写"股权结构待补充(建议提供工商登记/章程)"。
- 融资历史轮次(天使/Pre-A/A/B/C…)须从融资事件实际判断，无法确认写"未明确"，**禁止按金额倒推默认轮次**。

## 1. 基础信息 4 列表格（强制）
第1列基础信息项，第2列业务材料提炼，第3列独立提炼，第4列差异(红)。

| 基础信息 | 业务材料提炼 | 独立提炼/旁证 | 差异 |
|---|---|---|---|
| 注册地 | BP 所述 | 公告/官网/登记地线索 | 一致/`[[红]]差异[[/红]]` |
| 成立时间 | BP 所述 | 公开成立信息 | 同上 |
| 实控人/创始人 | BP 所述 | 旁证或用户提供材料 | 同上 |
| 核心团队背景 | BP 所述履历 | 研报/公开披露/用户材料 | 同上 |
| 知识产权(专利/软著/资质) | BP 所述 | 研报/公告/官网可核明细 | 同上 |

无独立旁证时，"独立提炼"列填来源(如 `[公告]` / `[用户提供]` / `[研报]`)或"暂无独立源"并标红提示待补；**不填未经验证的精确数值**（参考踩坑：精确小数往往来自幻觉）。

## 2. 工商与风险维度
- 股权结构、司法、行政处罚、经营异常、投融资史、子公司布局：已上市的从公告/披露旁证；**可公开得不充分且无用户材料时 → 进入 01 风险提示的"待核验清单"，不假设"无诉讼无冻结"**。
- **司法风险核验（强制纳入 01）**：关注"作为被告 + 股权冻结"这类信号——股权冻结常对应未决诉讼的财产保全，是偿债与股权稳定性的直接风险证据。本技能无司法库时明确标注司法维度缺数据、建议人工核验（见 data-sources.md D4）。
- 客户集中度等，若得自研报/公告则引用；无源写"待核实"，>某阈值(如 50%)的集中要单独提示其含义。

## 3. 财务维度（按可得性分流）
- 已上市标的：公告（`yj-fin-data` 的 `fetch_document` 取公告原文、`management_discussion` 取半年报/年报管理层讨论-财务绩效、`qa_list` 取投资者问答）、yj-fin-data 财务数值、券商研报营收/盈利测算（`yj-fin-data` 的 `knowledge_search` 取研报/纪要/观点片段，投研线索用 `meeting_summary_list`/`domestic_chief_opinion_list`；**不调用 `agent_one_pager`/`agent_investment_logic` 等未暴露的 agent 工具**）。
- 未上市标的：优先用户上传报表→CAS 标准化（见 `financial-standardization.md`）；仅线索级口径则标 "[线索口径，未经审计]"，不冒充经审计报表。
- 不规范原始报表：执行 CAS 标准化，输出【原始 VS 标准化对比表】(见 financial-standardization.md)，每项调整附原因与金额。

## 4. 行业维度及市场规模（简版，详版在模块二）
- **三级细分赛道精准定义**：格式 `[地域][一级行业][二级环节] - [阶段/材料/技术] 赛道`，禁只写大类。
- 市场规模三段(必写)：TAM(总量+口径+来源) → 能否切入&凭什么(SAM，结合核心优势论证可服务市场) → 切进去多大归它(SOM，份额假设+敏感性)。口径须匹配 Stage0 定位卡。

## 5. 核心优势维度
逐项：核心技术壁垒 / 商业模式 / 商业化阶段(研发期·小批量试产·规模化营收盈利·稳定盈利) / 下游应用 / 客户集中度 / 竞争格局 / 政策与监管。判据尽量锚定独立证据；仅来自 BP 而无第三方支撑的断言语，标「来源：企业自述，待验证」。

## 自检

- [ ] 差异已按规则红标并说明。
- [ ] 股权穿透到可理解实体；本技能取不到的写"待补充"，未按金额倒推轮次。
