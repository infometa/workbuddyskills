# CAS 财务标准化清洗 + 会计调整（模块一·财务参考）

## 统一口径：CAS（中国企业会计准则）
用户上传的非规范原始报表统一调整为 CAS 三张表口径。常见非规范报表与调整方向：

| 原始报表类型 | 特征 | 调整方向 |
|---|---|---|
| 民间简易利润表 | 仅"收入-支出=利润" | 拆营收/成本/费用/营业外，补折旧摊销 |
| 税务申报表 | 增值税口径、含税 | 剔除增值税还原不含税营业收入 |
| 管理报表/内部账 | 收付实现制 | 调权责发生制，补应计项 |
| 代账公司报表 | 科目合并、往来不清 | 分拆关联方往来，还原真实经营数据 |

## 强制财务修正项

### 1. 研发费用
- 研究阶段费用化；开发阶段满足资本化条件者可资本化。**为可比研发费率，通常将已资本化支出还原为费用化口径**。
- 研发费率 = 研发费用(费用化口径)/营业总收入。分级：
  - >30%：研发驱动型 → 以 PS 为主
  - 10–30%：技术型 → PEG/EV-EBITDA 辅助
  - <10%：商业化成熟 → PE 适用
- 明细若只有总额，按行业比例拆(人工约60%/材料20%/其他20%)并注明为估计拆分。

### 2. 非经常性损益剔除
剔除政府补助(区分资产相关→递延收益分期、收益相关→可计入当期；大额一次性补助从净利润剔除单列)、股权激励费用(公允价值计入管理费)、偶发营业外收支、非主业投资收益。**扣非净利润 = 净利润 − 上述剔除合计**。

### 3. 关联交易还原
股东往来借款从负债分离为关联方借款；老板个人开支(私车/家支)剔除还原管理费；关联购销价偏离市场>20%按市场价还原；资金占用费还原。

### 4. 税务差异核对
增值税申报收入 vs 账面收入差异以申报为基准还原；统一不含税口径；高企/双软免税单独列示。

### 5. 未盈利企业运营指标标准化（扣非净利润为负时重点）
常用可比指标：营收结构(分产品/分客户占比，用于 PS 细分乘数)、综合毛利率、研发费率、销售费率、管理费率、人均创收(营收/员工)、在手订单、合同负债增速(需求景气)。
