# 一级股权投资财务分析专项手册

> 本手册是 `references/financial_ratios.md`（通用比率）与 `references/industry_analysis.md`（行业框架）
> 的**一级市场补丁包**。通用部分解决"报表说了什么"，本手册解决公开市场的比率框架回答不了的四个问题：
> 这份报表能不能信 / 还能烧多久 / 真实盈利是多少 / 投进去会变成什么样。

---

## 一、一级市场与二级市场 FDD 的八个根本差异

| # | 差异 | 上市公司做法 | 一级市场做法 |
|---|---|---|---|
| 1 | 数据来源 | 定期报告（审计、统一口径、监管穿透） | 尽调资料包（管理层报表 / 审计报告 / BP / 银行流水），**质量由对方配合度决定** |
| 2 | 期间可比性 | 年报序列清晰、会计政策强制披露 | 常见"月报 + 季报 + 年报"混用、会计政策中途变更、**跨期重述不披露** |
| 3 | 主体边界 | 合并范围稳定 | 关联方众多、代持常见、合并范围可能随融资安排变动 |
| 4 | 分析目标 | 判断贵不贵、质地好不好 | 判断**能不能活**、会不会被稀释、有哪些必须写进 SPA 的坑 |
| 5 | 现金流权重 | OCF 是交叉验证工具 | OCF 就是**生死线**（Runway 决定交易窗口） |
| 6 | 估值锚 | 市场价格 + 可比倍数 | 投前/投后条款 + 优先清算 waterfall + 反稀释 |
| 7 | 会计调整 | 基本不需要 | **必须做**：管理层 EBITDA → DD EBITDA |
| 8 | 失效后果 | 误判 → 股价波动 | 误判 → 本金不可回收 |

**结论**：公开市场的比率可以直接用；一级市场的每一个比率都要先问一句"这个数字的口径是什么、谁编的、能不能被外部凭证佐证"。

## 二、资料完备度门槛

拿到资料后**先做门槛判断**，不要急着算比率。三张表 + 月度现金流缺任一项，本技能的结论都要相应降级并在报告中标注。

### 2.1 资料请求清单（Request List）

| 优先级 | 资料 | 用途 | 拿不到时的替代 |
|---|---|---|---|
| P0 | 最近 3 年审计财务报表（含附注） | 全部分析的基石 | 审阅意见 + 银行流水 + 纳税申报表交叉 |
| P0 | 最近 12–24 个月管理层财务报表（含月报） | Runway、季节性 | 用季度报，但跑道精度下降到 ±2 月 |
| P0 | 最近 12 个月**银行流水**（主要账户） | 收入回款核实、体外循环识别 | 无替代——这一项拿不到应视为重大红旗 |
| P0 | 股权结构表与历轮融资文件（TSA/SHA） | 稀释、优先清算、反稀释 | 用户上传工商材料 + 访谈（劣后，条款仍需文件佐证） |
| P1 | 近 2 年纳税申报表 | 收入第三方佐证、税务合规 | 电子税务局截图（可作弱证据） |
| P1 | 收入明细表 / 合同台账 | 集中度、收入确认政策验证 | 前十大客户访谈 |
| P1 | 关联方清单与往来余额表 | 资金占用、利益输送 | 科目明细账"其他应收/其他应付"倒查 |
| P1 | 社保公积金缴纳台账 | 欠缴补提 | 按工资总额估算（保守） |
| P2 | 月度经营数据（产量/耗电/发货/订单） | 产能与销量交叉验证 | 访谈 + 现场盘点 |
| P2 | 单位经济数据（CAC / LTV / 留存） | 单位经济章节 | 由财务数据反推毛利口径的近似值 |

### 2.2 可靠性分级

| 等级 | 来源 | 权重 | 使用限制 |
|---|---|---|---|
| A | 已审计财报（含附注） | 1.0 | 可直接使用 |
| B | 已审阅 / 第三方审阅 | 0.85 | 可用于比率，重要科目仍需凭证 |
| C | 管理层报表 | 0.6 | **必须**用银行流水与纳税申报表交叉验证 |
| D | BP 预测 / 预算 | 0.3 | 只能作为"管理层会不会打脸"的参照，**绝不能作为估值基数** |

> 报告须在可靠性评级章节自动标注每张表的来源等级；落到 C / D 档时，报告中要有相应提示，不能让它看起来和 A 档一样可信。

## 三、收入：一级市场最容易失真的科目

### 3.1 Run-rate 的正确用法

Run-rate = 最近一期累计收入 × 12 / 累计月数。

- 它是**规模指标**，不是业绩承诺。
- 三种典型误用：① 拿收入最高的单月年化；② 用含一次性大单的期间年化；③ 把签约定单（backlog）当已实现收入。
- 与之配套要看：**月度收入的月份序列**（是否集中在期末）、**同期合同负债/预收变动**（是否有提前确认）。

### 3.2 收入确认政策必须写进报告

| 判据 | 要点 |
|---|---|
| 总额法 vs 净额法 | 贸易/SaaS 代理业务是否能自主定价、是否承担存货风险——判定不同，收入规模可能相差数倍 |
| 时点 vs 时段 | 验收单/上线报告/阶段里程碑缺一不可 |
| 销售退回与质保 | 是否计提、计提比例与历史退货率是否匹配 |
| 渠道压货 | 用"收入增速 vs 应收账款增速 vs 经销商库存"三角验证 |

### 3.3 收入真实性的外部证据排位

1. **银行流水中标注客户名 + 金额的收款记录**（最强）
2. 纳税申报表销售额 / 增值税发票开具额
3. 客户回函与合同台账
4. 管理层收入明细（最弱）

三者出现系统性背离时，认定为收入真实性疑点，必须在报告中单列，而不是用"存在一定不确定性"这种说法糊过去。

## 四、QoE：管理层 EBITDA → DD EBITDA

一级市场上，卖方给的 EBITDA（或净利润）往往是"调整过的经营性净利润"，其调整方向与买方需要的内容相反。做 DD 桥时逐项检查：

| 调整方向 | 常见项目 | 是否应加回 |
|---|---|---|
| 利润偏高 | 股东/家族成员超额薪酬、关联方高价销售带来的毛利、一次性政府补助、研发资本化、利息资本化 | **扣减** |
| 利润偏低 | 一次性开办费、IPO 中介费、股份支付、历史合规欠缴补提、诉讼和解 | 若属一次性可加回，但需证据 |
| 口径差异 | IFRS 16 租赁费用重分类、社保公积金按应缴口径重算、关联方租金按市价重算 | 按 DD 口径统一，**并说明重算方式** |

原则：**加回的项目必须搬运件证据；没有证据的调整项一律不做。**一份调整桥的价值不在它把 EBITDA 调高还是调低，而在于每个数字都可以追溯到凭证。

## 五、净债务桥（Net Debt Bridge）

| 项目 | 是否计为债务 | 备注 |
|---|---|---|
| 银行借款（短/长） | 是 | 报表科目 |
| 一年内到期非流动负债 | 是 | 报表科目 |
| 租赁负债 | 是 | 新准则 |
| 股东借款 | **按条款** | 无还款期限、无利息、劣后于银行债务 → 通常按类债务处理；有明确次级协议 → 可作权益 |
| 未付并购对价 / Earn-out | 是 | 触发条件已满足即应按负债计 |
| 优先股 / 可转债 | **按条款** | 带强制赎回、带固定收益回报 → 类债务；否则按权益 |
| 应付票据（已贴现、已背书未终止确认） | 是 | 常有遗漏 |
| 对外担保 | **不计入债务，单列或有负债** | 但要测算最大风险敞口 |

优先股/可转债性质判定依赖于具体条款，必须由人工在资料中标注 `是否类债务=true/false`。

## 六、现金流、Burn 与 Runway

1. **净消耗口径统一**：单月净消耗 = −(经营活动现金流净额 + 投资活动现金流净额)，**不含筹资活动**——把融资流入算进来等于把"还能烧多久"改成"还能融多少"，是两个问题。
2. **平均窗口**：近 3 月与近 6 月都要看。3 月灵敏、6 月平稳；两者背离代表消耗正在加速或减速。
3. **Runway = 期末现金余额 / 平均单月净消耗**。触发窗口：
   - < 6 个月：**高风险**，需要重新审视交易结构（分期、兜底、过桥）
   - 6–12 个月：需要把融资节点写进条款
   - > 18 个月：通常不必就现金流单独行动
4. **现金余额为负**：意味着已在用透支/关联方垫款维持，**跑道指标失去意义**，优先核实是否拖欠工资、税款、供应商货款。
5. **用最近一期余额，不要用上年年报余额**。判断今天的跑道要用月度现金流表或最近一期资产负债表里的现金，年报余额可能已经过去 9 个月。

## 七、单位经济（Unit Economics）

适用：订阅、SaaS、消费、平台型标的。制造业可以不适用，但应看单台/单位产能的贡献毛利。

| 指标 | 健康线 | 说明 |
|---|---|---|
| 毛利率（单客/单品） | 视业态 | 低于 20% 时，规模放大通常不会让销售费用率下降 |
| LTV / CAC | ≥ 3x | 低于 3x 意味着增长是"买来的" |
| CAC 回收期 | ≤ 24 个月 | 与 Runway 联合判断：回收期 > Runway 必然出于融资压力 |
| 月流失率 | < 2%（企业）/ < 5%（消费） | 折算成年流失会比较难看，这正是该算的原因 |
| NDR | > 100% | 低于 100% 说明存量客户在萎缩，新增必须越来越快才能维持增长 |

注意：**这些指标来自管理层提供的数据**，必须与银行回款、合同台账交叉验证后再用。若仅有毛利率可信，就只写毛利率，其余标注"数据未获佐证"。

## 八、交易结构里会改变财务判断的条款

| 条款 | 对财务判断的影响 |
|---|---|
| 优先清算权（1x / 参与型） | 参与型会先回收本金再按比例参与分配，普通股股东在中等倍数退出时可能一分钱拿不到 |
| 反稀释（加权平均 / 全棘轮） | 全棘轮下后续低价融资会把老投资人（含本轮）稀释得极重 |
| 赎回权 | 若约定 IPO 时间表未实现可赎回，则优先股在会计与估值上应更接近**负债** |
| 对赌 / 业绩承诺 | 历史完成率是重要的信用证据；要逐期核对承诺值与实际值 |
| 拖卖权 / 随售权 | 影响退出路径的可控性 |
| ESOP 扩池顺序 | 投前扩池 vs 投后扩池，对老股东的稀释差异显著；稀释测算必须区分两者 |
| 分期交割与里程碑 | 现金流紧张时，这是买方的核心保护手段 |

报告的稀释测算严格按 **[（原比例 ×(1−新池占比)）×（1−投资人占比）]** 计算，即"先扩池再稀释"。

## 九、中国境内标的的高频雷区

1. **体外循环**：收入走私人账户/关联公司，成本与费用才入账。识别信号：其他应收款异常、"其他应付"长期挂账、老板个人卡大量与供应商/客户往来。
2. **代持与影子股东**：工商登记与实际权益不符，常见于员工持股与早期投资人。
3. **社保公积金欠缴**：几乎普遍存在，需在盈利调整桥中补提，并在 SPA 中做相应扣减或预留。
4. **票据与供应链融资**：已贴现未终止确认的票据实质是债务，常有遗漏。
5. **增值税票与收入背离**：开票额长期低于申报收入 → 隐性收入漏税。
6. **母子公司/兄弟公司资金池**：资金占用体现在"其他应收款"，关联方清单常常不完整。
7. **VIE / 协议控制**：境外融资架构下境内实体利润通过服务费转移，需核实关联定价与外汇合规。
8. **政府补助与税收返还的持续性**：一次性补助必须剔除，但可持续性退税要看政策文件而不是历史惯例。
9. **环保/安全生产/土地性质瑕疵**：在生产型标的中往往是比财务数字更致命的交割先决条件。

## 十、交付边界（不可逾越）

1. **不出"值多少钱"的结论**。本手册只回答"按这个价格，倍数是多少"、"历史上这些条款造成的后果是什么"。估值判断需要独立的可比分析与商业模式判断。
2. **不替代现场核查**。电表、仓储、发货单、人员访谈——证据链中的每一环都不在框架能力范围内。
3. **不做 NA (Normalized Earnings) 的乐观假设**。管理层预测只能作为对照。
4. **缺什么写什么**。任何拿不到的数据一律在报告中标注为缺口，禁止用行业均值、估计值、模型推测来填充——一级市场的决策容错率远低于二级市场，隐藏缺口比暴露缺口危险得多。
5. **信贷/投资建议豁免**。报告结尾必须保留"仅供内部研究参考 · 不构成投资建议"。
