# 财务比率与财务尽调指标分析框架

## 概述

本文件定义财务尽调报告中使用的全部财务比率、专业 FDD 指标、计算公式、数据来源字段及解读标准。所有指标均基于用户上传的财务报表科目（或可及研报旁证）计算；凡旁证无法取得可靠数值者，标注"待补充核验"而非臆造。

---

## 一、盈利能力指标

### 1.1 毛利率
- **公式**: 毛利率 = (营业收入 - 营业成本) / 营业收入 × 100%
- **解读**: > 60% 强定价权; 30-60% 正常; < 20% 低附加值或竞争激烈

### 1.2 净利率
- **公式**: 净利率 = 净利润 / 营业收入 × 100%
- **解读**: 行业差异大，应与行业均值对比；趋势下滑比绝对值更值得关注

### 1.3 ROE（净资产收益率）
- **公式**: ROE = 归母净利润 / 期初期末平均归母净资产 × 100%
- **解读**: > 15% 优秀; 10-15% 良好; < 8% 偏低；杜邦分解三因子

### 1.4 ROA（总资产收益率）
- **公式**: ROA = 净利润 / 期初期末平均总资产 × 100%
- **解读**: 反映资产使用效率，重资产行业偏低

### 1.5 ROIC（投入资本回报率）
- **公式**: ROIC = NOPAT / (有息负债 + 净资产) × 100%
- **NOPAT** = 净利润 + 利息费用 × (1 - 所得税率)
- **解读**: 衡量企业核心经营资产的真实回报率，排除融资结构影响。ROIC > WACC 表明企业在创造经济利润。

### 1.6 杜邦分析
- **公式**: ROE = 净利率 × 资产周转率 × 权益乘数
- **分解**:
  - 净利率 = 净利润 / 营业收入（盈利能力）
  - 资产周转率 = 营业收入 / 平均总资产（运营效率）
  - 权益乘数 = 平均总资产 / 平均净资产（财务杠杆）

## 二、盈利质量指标（Quality of Earnings, QoE）

### 2.1 扣非净利润占比
- **公式**: 扣非净利润占比 = 扣非净利润 / 净利润 × 100%
- **解读**: > 80% 盈利可持续性强; 50-80% 存在一定非经常性损益依赖; < 50% 主营业务盈利能力存疑

### 2.2 经营现金流 / 净利润（利润含金量）
- **公式**: OCF / 净利润
- **解读**: > 1.2 优秀; 0.7-1.2 正常; 0.5-0.7 利润含金量不足; < 0.5 利润可能虚增

### 2.3 收现比
- **公式**: 收现比 = 销售商品、提供劳务收到的现金 / 营业收入
- **解读**: > 110% 优秀（含税因素）; 90-110% 正常; < 90% 需关注应收账款回收风险

### 2.4 非经常性损益 / 净利润
- **公式**: 非经常性损益净额 / 净利润 × 100%
- **解读**: 反映利润受一次性因素影响的程度，比率越高，利润可预测性越差

### 2.5 经营活动现金流 / 营业收入
- **公式**: OCF / 营业收入
- **解读**: 衡量每元收入实际转化为经营现金的能力，剔除了营运资本变动和净利润口径差异的影响

## 三、偿债能力指标

### 3.1 资产负债率
- **公式**: 资产负债率 = 负债合计 / 资产总计 × 100%
- **解读**: 因行业而异；制造业 < 60% 稳健，房地产 / 公用事业可 > 70%

### 3.2 净负债率
- **公式**: 净负债率 = (有息负债合计 - 货币资金) / 净资产 × 100%
- **有息负债合计** = 短期借款 + 长期借款 + 应付债券 + 一年内到期的非流动负债
- **解读**: > 100% 表明有息负债超过净资产与现金之和

### 3.3 流动比率
- **公式**: 流动比率 = 流动资产合计 / 流动负债合计
- **解读**: > 2 充足; 1-2 正常; < 1 短期偿债压力

### 3.4 速动比率
- **公式**: 速动比率 = (流动资产 - 存货) / 流动负债
- **解读**: > 1 良好; 排除存货变现不确定性

### 3.5 现金比率
- **公式**: 现金比率 = 货币资金 / 流动负债
- **解读**: 最严格的短期偿债能力指标；< 0.2 需关注流动性风险

### 3.6 利息保障倍数
- **公式**: 利息保障倍数 = (利润总额 + 利息费用) / 利息费用
- **解读**: > 5 安全; 2-5 关注; < 2 风险较高

### 3.7 现金利息保障倍数
- **公式**: 现金利息保障倍数 = (OCF + 利息费用 + 所得税) / 利息费用
- **解读**: 以现金流替代会计利润，更能反映实际付息能力

### 3.8 有息负债率
- **公式**: 有息负债率 = (短期借款 + 长期借款 + 应付债券 + 一年内到期的非流动负债) / 资产总计 × 100%

---

## 四、营运能力指标

### 4.1 存货周转率 / 周转天数
- **公式**: 存货周转率 = 营业成本 / 平均存货; 周转天数 = 365 / 存货周转率
- **解读**: 周转天数上升通常意味着滞销风险或备货策略变化

### 4.2 应收账款周转率 / 周转天数
- **公式**: 应收账款周转率 = 营业收入 / 平均应收账款; 周转天数 = 365 / 应收账款周转率
- **解读**: 周转天数拉长反映客户付款能力下降或公司主动放宽信用政策

### 4.3 应付账款周转率 / 周转天数
- **公式**: 应付账款周转率 = 营业成本 / 平均应付账款; 周转天数 = 365 / 应付账款周转率
- **解读**: 周转天数缩短可能反映对供应商议价能力减弱

### 4.4 总资产周转率
- **公式**: 总资产周转率 = 营业收入 / 平均总资产

### 4.5 固定资产周转率
- **公式**: 固定资产周转率 = 营业收入 / 平均固定资产

### 4.6 现金转换周期（Cash Conversion Cycle, CCC）
- **公式**: CCC = 存货周转天数 + 应收账款周转天数 - 应付账款周转天数
- **解读**: CCC 为正当企业需要投入营运资本支撑运营；CCC 为负表明企业占用上下游资金。CCC 拉长意味着营运效率下降或对上下游议价能力减弱。

---

## 五、成长能力指标

### 5.1 营业收入增长率
- **公式**: (本期营业收入 - 上期营业收入) / 上期营业收入 × 100%

### 5.2 净利润增长率
- **公式**: (本期净利润 - 上期净利润) / 上期净利润 × 100%

### 5.3 归母净利润增长率
- **公式**: (本期归母净利润 - 上期归母净利润) / 上期归母净利润 × 100%

### 5.4 扣非净利润增长率
- **公式**: (本期扣非净利润 - 上期扣非净利润) / 上期扣非净利润 × 100%
- **解读**: 排除非经常性损益后的真实增长

### 5.5 经营性现金流增长率
- **公式**: (本期经营活动现金流净额 - 上期经营活动现金流净额) / 上期经营活动现金流净额 × 100%

### 5.6 净资产增长率
- **公式**: (期末净资产 - 期初净资产) / 期初净资产 × 100%

---

## 六、现金流质量指标

### 6.1 自由现金流（FCF）
- **公式**: FCF = 经营活动现金流净额 - 资本开支（购建固定资产、无形资产和其他长期资产支付的现金）
- **解读**: 持续为正表明企业具备自我造血能力；连续 2 年为负需关注融资可持续性

### 6.2 FCF 利润率
- **公式**: FCF 利润率 = 自由现金流 / 营业收入 × 100%

### 6.3 资本开支强度
- **公式**: 资本开支强度 = 资本开支 / 经营活动现金流净额 × 100%
- **解读**: > 80% 处于扩张期；< 40% 以维持性投资为主

### 6.4 现金满足投资比
- **公式**: 经营活动现金流净额 / (资本开支 + 存货增加 + 现金股利)

### 6.5 现金到期债务比
- **公式**: 经营活动现金流净额 / 本期到期债务

---

## 七、营运资本指标（Net Working Capital, NWC）

### 7.1 净营运资本（NWC）
- **公式**: NWC = 经营性流动资产 - 经营性流动负债
- **经营性流动资产** = 应收账款 + 存货 + 预付款项 + 其他经营性流动资产
- **经营性流动负债** = 应付账款 + 合同负债 + 预收款项 + 其他经营性流动负债

### 7.2 NWC / 营业收入
- **公式**: NWC / 营业收入 × 100%

### 7.3 NWC 变动 / 营业收入变动
- **公式**: ΔNWC / Δ营业收入
- **解读**: > 1 意味着收入增长以更大比例的营运资本投入为代价。

---

## 八、调整后 / normalized 盈利指标

### 8.1 Normalized EBIT
- **公式**: 营业利润 + 非经常性损失 - 非经常性收益 + 异常费用调整
- **用途**: 剔除非经常性、非经营性项目后的可持续经营利润，是估值与同业对比的合理基础。

### 8.2 Normalized EBITDA
- **公式**: Normalized EBIT + 折旧 + 摊销
- **用途**: 加回非现金支出后的可持续经营现金流近似值，常用于 EV/EBITDA 估值。

### 8.3 Adjusted Net Profit
- **公式**: 净利润 - 非经常性损益净额 ± 会计政策变更影响 ± 一次性资产减值（非持续性）

---

## 九、估值指标（来自用户上传财报 + 可及旁证）

### 9.1 PE（TTM）
- **来源**: 用户上传材料 / 行情财务数值（标注时点快照）
- **解读**: 需与行业均值和历史分位对比

### 9.2 PB（MRQ）
- **来源**: 用户上传材料 / 行情财务数值

### 9.3 PS（TTM）
- **来源**: 用户上传材料 / 行情财务数值

### 9.4 PEG
- **来源**: 用户上传材料 / 行情财务数值
- **解读**: < 1 估值偏低; > 2 估值偏高

### 9.5 企业倍数（EV/EBITDA）
- **来源**: 推算字段
- **解读**: EV = 市值 + 归母净负债

### 9.6 历史分位
- **来源**: 用户上传材料 / 可及研报旁证
- **解读**: < 30% 低位; 30-70% 中位; > 70% 高位

---

## 十、每股指标

### 10.1 EPS（每股收益）
- **字段**: 基本每股收益 / 稀释每股收益

### 10.2 BPS（每股净资产）
- **公式**: 归母净资产 / 总股本

### 10.3 每股经营现金流
- **公式**: 经营活动现金流净额 / 总股本

### 10.4 每股自由现金流
- **公式**: 自由现金流 / 总股本

---

## 十一、风险监控专项指标

### 11.1 商誉 / 净资产
- **公式**: 商誉 / 归属母公司所有者权益 × 100%
- **解读**: > 30% 构成商誉减值风险信号

### 11.2 在建工程 / 固定资产
- **公式**: 在建工程 / 固定资产 × 100%
- **解读**: 长期（> 2 年）高企可能意味着延迟转固或虚增资产

### 11.3 短期借款 / 货币资金
- **公式**: 短期借款 / 货币资金
- **解读**: > 1 表明货币资金不足以覆盖短期借款，存在再融资压力

### 11.4 应收账款增速 - 收入增速
- **公式**: 应收账款同比增长率 - 营业收入同比增长率
- **解读**: > 10 个百分点构成中等级别风险信号

### 11.5 存货增速 - 收入增速
- **公式**: 存货同比增长率 - 营业收入同比增长率
- **解读**: > 15 个百分点构成存货积压风险信号

### 11.6 对外担保 / 净资产
- **公式**: 对外担保余额 / 净资产 × 100%
- **解读**: > 10% 需高度关注或有负债风险

## 十二、综合财务评分模型

### 评分维度与权重

| 维度 | 权重 | 子指标 |
|------|------|--------|
| 盈利能力 | 20% | 毛利率、净利率、ROE、ROA、ROIC |
| 偿债能力 | 15% | 资产负债率、流动比率、利息保障倍数、有息负债率 |
| 营运能力 | 15% | 存货周转率、应收账款周转率、总资产周转率、CCC |
| 成长能力 | 15% | 收入增长率、净利润增长率、经营性现金流增长率、扣非净利润增长率 |
| 现金流质量 | 20% | 经营性现金流/净利润、自由现金流、收现比、现金到期债务比 |
| 盈利可持续性 | 15% | 扣非净利润占比、毛利率稳定性（标准差）、收入增速波动性 |

### 评分标准
- 每个比率按行业分位数评分：> 75 分位 5 分; 50-75 分位 4 分; 25-50 分位 3 分; 10-25 分位 2 分; < 10 分位 1 分
- 综合得分 = 各维度加权平均
- 评级标准: ≥ 4.0 优秀; 3.0-4.0 良好; 2.0-3.0 一般; < 2.0 较弱

## 同比口径纪律（动笔前必读）

两条都是静默缺陷：不报错、不崩溃，只是报告里的数字与措辞错了（例如 6.90% 与 1.30% 看起来都「像」增速），人工通读极难发现。

### ① 增长率序列的末元素若是 CAGR 汇总行，不是最新一期同比
多年复合增速常作为 CAGR 汇总行追加在增长率序列末尾。因此凡「同比 / 增速 / 较上年」语义的取值，一律用**最新一期同比行**（按年份精确命中），不要用汇总行兜底；只剩 CAGR 汇总行时落空，绝不用汇总值兜底。

### ② 同比基准必须是「上年同期」，不能取错位期间
最新一期是中报/季报时，上年同期应取上一年同期中报/季报，不能取上一年年报；拿年报当上年同期会把季节性科目的环比变化说成同比变化。杜邦序列与比率序列同序同长且带日期，归因分析写「ROE 较上年…个百分点」必须取上年同期。
