# 实地核查与舞弊识别清单

> 本清单是自动化财务分析（比率/趋势/风险扫描）之外的第二道防线。报表分析发现"疑点"，实地核查负责"证实或证伪"。
> 财务尽调不是审计：不出具真实公允意见、通常不函证不盘点，主要依靠审阅、分析性程序与访谈。正因可靠性弱于审计，
> 交叉印证（报表 ↔ 单据 ↔ 实物 ↔ 资金流水 ↔ 税务记录）是尽调质量的核心。

## 一、收入真实性：六要件交叉印证

真实的一笔销售收入，应同时具备以下六项证据，缺一即构成疑点：

| #   | 要件          | 核查方法                                 | 造假信号                                       |
| --- | ------------- | ---------------------------------------- | ---------------------------------------------- |
| 1   | 购销合同      | 抽查大额收入对应合同，核对定价、账期条款 | 合同要素残缺、签署时间倒填、框架合同无订单支撑 |
| 2   | 销售发票      | 与增值税开票系统记录核对                 | 开票金额与账面收入长期存在无法解释的差异       |
| 3   | 资金回款      | 银行对账单逐笔追踪回款                   | 回款集中于期末、金额整齐、第三方代付           |
| 4   | 验收/物流单据 | 出库单、运费单、签收单与收入确认时点匹配 | 有收入无物流、运费与销量不配比                 |
| 5   | 纳税申报表    | 申报收入与账面收入核对                   | 报表收入远高于纳税申报收入                     |
| 6   | 实际缴纳税款  | 完税凭证                                 | 高利润低缴税且无法用优惠政策解释               |

**分析性程序补充**：收入增速 vs 应收增速、收现比趋势、第四季度收入占比异常、毛利率显著偏离同业——任一异常均应触发上述六要件抽查。

## 二、成本真实性：五要件

1. **投入产出配比**：原材料购进与消耗量、产成品产量之间的配比关系是否符合工艺（BOM）；
2. **进项发票**：主要原材料采购具备增值税进项发票；
3. **预付款逻辑**：紧俏/大宗原材料采购通常需要预付款，账面全无预付反而可疑；
4. **付款周期**：对供应商付款周期是否正常，长期异常拖欠或异常快付都值得追问；
5. **入库单据**：有仓管人员签字、含数量金额的入库单。

## 三、产能与经营真实性

- 新建项目是否按期完工、是否正常满负荷生产；
- **耗能配比核查（关键）**：分月耗电、耗水、耗煤与产量的配比关系——产量可以编造，电表很难；
- 仓储与运输能力是否与申报的销量匹配；
- 设计产能 vs 实际产量的差异及原因；
- 现场"望闻问切"：生产排班饱满度、装卸频率、员工情绪与工位饱和度、管理层能否清晰讲述战略与经营史、
  现金流结构对战略的支撑度。

**实地尽调强度参考**（"魔鬼藏在细节处"）：见过 90% 以上股东和管理层、连续在企业 5-6 天、走访 7 个以上部门、
面谈 4 家以上客户、调研 3 家同业或竞争对手、准备 20 个以上关键问题、早上 8 点到厂观察真实开工状态。

## 四、资金流水核查

**正常的货款回收特征**：
- 客户多采用票据背书等常规结算方式；
- 收付款日期无规律、金额零散（真实商业往来天然如此）；
- 资金到账后在账户有正常停留；
- 每笔流转均在银行对账单上有迹可循。

**典型资金舞弊模式**：
1. **定期存单质押**：账面大额货币资金实际已质押受限，"存贷双高"是最经典的信号；
2. **票据背书贴现套现**：通过关联方开票-背书-贴现形成虚假资金流；
3. **踩会计时点挪用**：期末资金归位、期初转出，资产负债表日的余额真实但全年被占用；
4. **体外资金循环**：自有资金流出体外再以"回款"名义流回，伪造收入闭环。

## 五、表外项目清单

| 项目                 | 核查要点                                        | 风险含义                         |
| -------------------- | ----------------------------------------------- | -------------------------------- |
| 对外担保             | 担保余额/净资产比（>10%高度关注）、被担保方资质 | 或有负债，关联担保常伴随利益输送 |
| 已抵押/质押资产      | 受限资产占总资产比例                            | 资金链紧张的先行信号，处置受限   |
| 票据贴现与背书       | 贴现规模与频率                                  | 隐性融资，融资性贸易温床         |
| 银行授信额度         | 总额度、已用比例、剩余额度                      | 剩余授信是短期偿债的隐性缓冲     |
| 未执行完毕的重大合同 | 履约义务与潜在损失                              | 或有支出                         |
| 未决诉讼与仲裁       | 涉诉金额、预计负债计提                          | 败诉的现金流冲击                 |
| 经营租赁承诺         | 租赁负债完整性                                  | 表外杠杆                         |

## 六、会计政策与税务核查

- 近 3 年会计政策重大变更（收入确认、折旧年限、减值假设）及其利润影响量化；
- 近 3 年会计师事务所变更记录——临近重大交易更换审计机构是经典预警信号；
- 审计报告意见类型及强调事项段；
- 税收优惠依赖度（优惠到期的利润冲击）、汇算清缴状态、关联交易的税务安排。

## 七、按企业性质差异化的风险画像

| 企业类型 | 高发风险                                                   |
| -------- | ---------------------------------------------------------- |
| 上市公司 | 市值管理驱动的利润平滑、大股东质押与资金占用、商誉减值择时 |
| 民营企业 | 公私账户混同、体外循环、实控人个人负债牵连、家族关联交易   |
| 合资企业 | 股东方转移定价、技术许可费/管理费的利益输送                |

## 八、报告撰写要求

- 结论须量化表达（"应收账款中账龄 2 年以上占 18%，按同业计提标准少提坏账约 X 亿元"），拒绝空泛定性；
- 善用图表与对比表，重点结论加粗突出；
- 区分"已证实的事实""有线索未证实的疑点"与"建议进一步程序"三个层级；
- 报告须经质量控制复核后提交，存在分歧意见时应一并呈报决策者。
