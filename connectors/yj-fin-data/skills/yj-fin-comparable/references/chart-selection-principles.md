# 可比公司看板图表选择原则

## 核心前提

**N = 3-5 家可比公司**，横截面数据（同一时点），非时间序列。所有图表选择服务于这个前提。

## 第一原则：图表类型服务于数据，不服务于多样性

"避免单调柱状图集合"是错误目标。正确目标是"每个指标用最能传达其信息的图表类型"。如果 5 个指标的最佳图表都是横柱，就用 5 张横柱——不要为了视觉多样性牺牲语义正确性。

## 各指标的图表选择决策树

### 规模类（营业收入 / 净利润）

**判断：横向柱状图 (hbar)**

- 绝对值差异通常较大，横向柱天然适合读公司名（左→右阅读习惯）
- 按值排序后，排名一目了然
- 极端值处理：若最大值超出次大值 100 倍以上，仍可用——线性柱说了真话

### 质量类（毛利率 / 净利率 / ROE）

**判断：线性圆点图 (dot)**

- 关键理由：这些指标可能有极端离群值
  - 净利率: 50.5% vs -57.1%
  - ROE: 差异可从负到正
- **对数柱是错误的**：对 N=5 的小样本，对数柱把 10 倍差距压成 ~1.3 倍视觉，柱子长度与数值不成比例，比不画图更误导
- **线性圆点图的优势**：极端值自然飘到区域边缘，空白本身就是信息——"这家公司跟同业不在一个量级"
- 均值虚线 + 交替底色 + 数值标注：三要素叠加，圆点图信息密度高于柱状图

### 估值类（总市值 / PE(TTM)）

**判断：垂直柱状图 (vbar)**

- 跨公司对比，无序列关系。禁止折线图（折线暗示时间序列）
- 竖柱适合"谁估值高/谁市值大"的直觉对比
- 目标公司亮色高亮，快速定位
- 极端值处理：若 PE 出现 399 倍这种极端值，竖柱能清晰传达——399 倍的柱子高度远高于 42 倍，差异一目了然

### 双维度交叉（PE × 营收增速）

**判断：气泡散点图 (scatter)**

- 唯一能展示两个维度关系的图表
- X=PE / Y=增速 / 气泡=总市值
- 回答"增长是否被合理定价"
- N=5 时散点稀疏但有价值——能看到增长-估值的匹配程度
- 若数据不足（<2 家），自动跳过

## 禁止的图表选择

| 图表类型 | 禁止场景 | 原因 |
|----------|---------|------|
| 折线图 (line) | 跨公司横截面数据 | 折线连接离散公司，暗示序列关系/时间顺序，语义错误 |
| 对数柱 (log bar) | N < 10 的小样本 | 对数扭曲柱长，视觉比例 ≠ 真实比例，误导性大于信息量 |
| 饼图 | 任何投研场景 | 人眼不擅比较角度，对 3-5 项完全无法有效对比 |

## 设计检查清单

生成报告前，自检以下问题：

- [ ] 有无将折线图用于横截面数据？
- [ ] PE 图表是否用了线性刻度（非对数）？
- [ ] 圆点图是否包含均值虚线？
- [ ] 散点图数据是否足够（≥2 家公司有 PE 和营收增速）？
- [ ] 图表分组是否正确（规模对比/盈利质量/估值对比）？
- [ ] 图表卡片 padding ≥ 18px（SVG 有呼吸空间）？
- [ ] 增速指标是否只出现在散点图 X 轴，不单独成图？
