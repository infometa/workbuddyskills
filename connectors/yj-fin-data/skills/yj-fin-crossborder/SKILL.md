# 跨境融资路径参考

## 〇、原生取数入口

本技能优先调用以下已注册原生工具取数，并按来源标签就近标注：

- `yj-fin-data（knowledge_search）`：研报 / 观点 / 纪要 / 内部报告（向量检索，取论点与结论片段）——行业背景、可比研究、监管动态旁证。
- `yj-fin-data`：A/港/美股日K、财务三大表、估值分位、题材指数与成分股——可比上市公司财务与估值倍数、交易价格。
- `yj-fin-data（fetch_document）`：读取 / 解析用户上传及数据文件（BP/工商/财报/合同），核心依据以用户上传为准，标 `[用户提供]`。

不可达维度（工商 / 司法冻结 / 一级融资 / 非上市财务 / 公网检索）本技能无专库，照 `references/data-sources.md` 标"待补充核验"，绝不编造。

取数铁律：① 先 `securities_search` 解析带交易所后缀的标准代码，再调对应工具；② 研报 / 纪要 / 观点 / 公告一律经 `knowledge_search` / `fetch_document` / `meeting_summary_list` / `domestic_chief_opinion_list` / `management_discussion` / `qa_list` 实取，不得凭记忆填空；③ 遇 `UNAUTHORIZED`（云极账号未授权）即停，引导用户在连接器里完成授权，绝不编造数据。

## 一、定位与边界

为持有境内资产、希望从境外资本市场融资的企业或项目方，提供"境内资产 → 境外资本"的**路径框架与合规要点参考**。把监管口径、路径比选、资产适格、合规门自查组织成一套可阅读、可复核的结构化参考，而非代办执行。

重要边界：本技能仅提供**框架与要点参考，非法律/外汇/证券/跨境合规意见**，不替代律师事务所、会计师事务所、金融机构及主管部门的专业判断；所有具体申报、登记、发行、结算动作须由具备资质的执业机构与主管部门完成，并以主管部门最新口径与执业机构意见为准。

## 二、何时触发

- 用户需要比选跨境融资路径、做跨境合规自查或梳理出海融资结构；
- 出现关键词：跨境融资、境外发行、境外发债、熊猫债、境外上市、借壳上市、跨境ABS、资产代币化、跨境担保、QFLP、QDLP、境外SPV、数据出境、安全评估、标准合同备案、保护认证、外汇登记、外债登记、跨境结算、CIPS、MT700、跨境资金池、NRA、FT账户、出海融资；
- 输入形态：① 用户上传 BP/发行方案/权属与财务材料；② 用户仅以文字描述出海融资意图。

## 三、工作流（四模块一次跑通，前置定位不可跳）

### Step 0 — 主体与交易类型定位（前置闸门，不可跳过）

选路径之前先锁死**主体属性与交易类型**，防境外/境内、股权/债权路径错配导致路径比选、适格结论、合规门三处连锁失真：

| 维度 | 典型取值 | 路径取向 |
|---|---|---|
| ① 主体属性 | 境内企业/境内资产持有方/红筹/境外主体 | 决定备案与持股结构形态 |
| ② 交易类型 | 股权融资/债权融资/结构化(ABS·代币化)/通道(QFLP·QDLP) | 决定监管适用与发行方式 |
| ③ 资金方向 | 引资入境/资产出境融资 | 决定外汇与证券门侧重 |
| ④ 合规前置 | 是否涉数据出境/是否涉外汇登记/是否涉境内备案 | 决定四重合规门权重 |

易混淆点防错（强制）：若标的存在常见误称（如把"结构化融资"按"纯股权融资"口径比选，或把"红筹"按"纯境内企业"口径处理），显式标注——「易混淆点：X 常被误按 Y 口径；本框架按 Z 口径，路径比选与合规门均据此」。

判定输入：用户上传材料 + 资产/主体描述 + 可及研报与公告旁证；泛称与资产实质冲突时以资产实质为准。

### Step 0.5 — 主动交叉验证纪律（强制，不降级）

对关键数字（融资规模、评级、周期、费率、占比等）用 ≥2 独立源交叉验证；业务材料主张与独立源不一致处显式标注差异来源；缺口一律写"受数据可得性限制，XX 待补充核验"，**绝不静默编造、绝不按金额倒推轮次、绝不编造股东名册**。

交叉验证以 数据工具取数与用户上传材料为主；不可达维度（工商/司法/一级融资/外汇台账）照 `references/data-sources.md` 标待补充。**禁止**出现"探活/未连通/故障/兜底/已降级"等故障词。

### 模块一 · 五条跨境融资路径比选

逐项论证并对比五条路径（境外发债/境外上市/跨境ABS与代币化/跨境担保/QFLP·QDLP）：比选维度为资产属性（现金流/权属/估值）、主体资质（评级/规模/合规）、周期与成本、监管确定性、投资人接受度。证券化与代币化路径优先评估现金流稳定性与境内备案可行性。输出路径比选结论（含推荐路径与依据），不代办任何发行动作。

### 模块二 · 资产适格性评估

核查四项条件并逐项给结论：权属清晰（已登记）/ 有稳定现金流 / 估值合理 / 规模足够。每项标"满足/待补材料/不适用"，缺证维度标"受数据源限制待补充核验"，不臆造确权结论。

### 模块三 · 四重合规门自查（风险闸门）

任何跨境项目须同时过四道门，任一不过即项目暂停——本模块为自查清单与要点说明，非监管/法律意见：

| 门 | 合规要点 | 主管/依据（须核实最新版） |
|---|---|---|
| 外汇门 | 跨境资金流动合规、外债/担保/发行登记 | 外汇局；《外汇管理条例》《跨境担保外汇管理规定》 |
| 数据门 | 数据出境安全评估/标准合同备案/保护认证 | 网信办；《数据出境安全评估办法》《促进和规范数据跨境流动规定》 |
| 证券门 | 境内备案 + 境外合规发行 | 证监会 + 境外监管；《境内企业境外发行证券和上市管理试行办法》 |
| 境外法门 | 辖区证券法、AML、税务 | 境外监管；需境外律师确认 |

常见失败模式：只盯境外发行合规，漏掉数据出境与外汇登记。交付前必查四门齐备，但不替代持牌律师/监管判断。

### 模块四 · 结构与结算要点参考（非操作代办）

- 境外架构（参考）：辖区选择（香港/新加坡等）、SPV 与跨境持股/持有结构示意，仅作框架说明，结构合法性由境外律师确认。
- 跨境结算工具（参考）：CIPS/SWIFT/MT700 信用证/跨境人民币双向资金池/NRA·FT 账户的特点与适用，实际操作须由持牌金融机构完成。
- 周期排期（参考非承诺）：路径比选 2–4 周、适格评估 2–4 周、境内备案 4–8 周（前置）、SPV 设立 4–8 周、数据出境 4–12 周（常最长）、外汇合规 2–4 周、法律架构 4–8 周、发行执行 8–16 周、结算设计 2–4 周；整体常达 6–12 个月甚至更长，须提前规划。

- 所有数字必须可溯源：就近标注来源类型与基准日；估算与假设单列并标明"假设"。

## 八、生成流程（脚本）

本技能的结构化分析经脚本组装为**单份自包含 HTML 报告**（内联图表引擎，离线可打开、双击即用）：

1. 取数 + 用户材料 + 外部核验结论 → 组装报告输入 JSON：`company`（标的/主体名）、`ic_conclusion`（头部一句结论）、`kpi`（概览指标卡）、`sections`（各章节的 `blocks`）、`charts`（图表数据）。
2. `python3 scripts/generate_report.py --data <input.json> --output-dir <dir>` 生成单文件 HTML（文件名 `{主体}_跨境融资路径分析.html`）。
3. 成稿后对照 `references/output-and-pitfalls.md` 逐条核查排版与成文纪律（表格列纪律、禁自曝取数能力、来源就近标注）。

> 渲染器与本技能自包含：图表引擎 `scripts/assets/echarts.min.js` 随包分发、由脚本**内联**进产物，报告运行时零外部请求。
