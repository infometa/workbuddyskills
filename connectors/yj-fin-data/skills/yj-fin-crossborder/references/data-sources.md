# 维度可达性声明（yj-fin-crossborder）

本文件说明本技能各数据维度的可达性，以及缺失时的标准措辞。

## 二、不可达维度（如实标注，绝不编造）

| 维度 | 状态 | 缺失时标准措辞 |
|---|---|---|
| 工商登记 / 股权结构 | 本技能无专库 | "受数据可得性限制，权属与工商登记信息待补充核验" |
| 司法冻结 / 查封 / 诉讼 | 本技能无专库 | "受数据可得性限制，权属限制与涉诉情况待补充核验" |
| 一级市场融资库 | 本技能无专库 | "受数据可得性限制，历史融资与轮次信息待补充核验" |
| 非上市主体财务 | 本技能无专库 | "受数据可得性限制，标的财务数据待补充核验" |
| 外汇登记 / 外债台账 / 跨境担保登记 | 本技能无专库 | "受数据可得性限制，外汇登记状态待补充核验，以外汇局与执业机构为准" |
| 公网检索 | 网关受限 | "以用户上传材料与可及研报、公告旁证为准" |

## 三、铁律（不可违反）

1. **缺即如实"带待补充"**：不阻塞出报告，也不假装用"其他来源"把空缺填成"查过的样子"。
2. **绝不假设**：不假设无诉讼、无冻结、无权属瑕疵、已登记合规。
3. **绝不倒推**：不按金额倒推轮次、不按区间倒推参数。
4. **绝不编造**：不编造权属、交易案例、财务数据、可比公司、股东名册。
5. **来源就近标注**：每个数字标注来源类型与基准日；估算与假设单列标明"假设"。

## 四、用户材料优先原则

接入数据用于**旁证与交叉验证**；跨境融资分析的核心依据（BP/发行方案、权属文件、财务报表、合同文本、备案与登记材料）以**用户上传材料**为准，标注 `[用户提供]` 或 `[项目方材料]`。二者不一致时，显式标注差异，不静默取其一。
