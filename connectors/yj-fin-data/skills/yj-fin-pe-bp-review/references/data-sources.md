# 维度可达性声明（yj-fin-pe-bp-review）

本文件说明本技能各数据维度的可达性，以及缺失时的标准措辞。

## 二、不可达维度（如实标注，绝不编造）

| # | 维度 | 状态 | 缺失时标准措辞 |
|---|---|---|---|
| D6 | 工商登记 / 股权穿透 / 实控人 / 股东名册 | 本技能无专库 | "受数据可得性限制，股权结构待补充核验"；不假设、不编造比例 |
| D7 | 司法冻结 / 查封 / 诉讼 / 失信 | 本技能无专库 | "受数据可得性限制，司法维度待核验补充"；绝不假设无诉讼无冻结 |
| D8 | 非上市主体财务 | 本技能无专库 | 用户给报表→标注口径；仅口头规模→标"项目方口径，未经审计" |
| D9 | 公网检索（WebSearch/WebFetch） | 网关受限 | "以用户上传材料与可及研报、公告旁证为准" |

## 三、铁律（不可违反）

1. **缺即如实"带待补充"**：不阻塞出报告，也不假装用"其他来源"把空缺填成"查过的样子"。
2. **绝不假设**：不假设无诉讼、无冻结、无权属瑕疵。
3. **绝不倒推**：不按金额倒推轮次、不臆造轮次/投资方。
4. **绝不编造**：不编造股东名册、股权比例、财务数据、可比公司。
5. **主动交叉验证**：关键数字（市场规模/增速/财务/技术指标）用 ≥2 独立源交叉；BP 主张与独立源不一致处显式标注差异，不静默取其一。
6. **来源就近标注**：每个数字标注来源类型与基准日；估算与假设单列标明"假设"。

## 四、用户材料优先原则

接入数据用于**旁证与交叉验证**；评审的核心依据（BP 正文、财务报表、技术参数、签约材料）以**用户上传材料**为准，标注 `[用户提供]` 或 `[项目方材料]`。二者不一致时，显式标注差异，不静默取其一。
