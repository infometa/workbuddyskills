# 五查十六项取证规范（资信核验自查）

本文件为"五查十六项"逐项的取证方法论。工商/股权/涉诉/失信/执行等维度本技能不可达，一律以用户上传材料与可及官方披露为准，缺口标"待补充核验"，绝不假设无记录。

## 总表
| 查什么 | 项数 | 解决的问题 | 红线可能落点 |
|---|---|---|---|
| 查主体 | 3 项 | 它是谁？还在不在？谁说了算？ | 吊销/注销、频繁变更 |
| 查资格 | 3 项 | 有没有资格干这件事？干得动吗？ | 资质缺失/被吊销 |
| 查信用 | 4 项 | 有没有官司？欠不欠钱？被罚过没？ | 失信/限高/破产 |
| 查过往 | 3 项 | 以前干得怎么样？口碑如何？ | 欠薪/暴雷/烂尾 |
| 查关联 | 3 项 | 跟谁绑在一起？风险会不会传导？ | 关联方失信、互保联保 |

## 逐项规范

### 一、查主体（3 项）
1. **存续状态**：是否存续/在业，有无吊销、注销、经营异常。到哪里查：用户上传营业执照 + 公示系统（用户上传或可及公开披露）。坑：用简称或商业平台名替代权威主体。
2. **基本信息**：成立日期、注册资本认缴与实缴、经营范围。到哪里查：用户上传营业执照 + 公示系统。坑：把认缴当实缴。
3. **法定代表人及变更**：法人是谁，近 1 年变更频次。到哪里查：用户上传股权结构 + 公示系统。坑：频繁变更预示控制权不稳。

### 二、查资格（3 项）
4. **资质许可**：从事业务所需资质/许可是否齐全有效。到哪里查：用户上传资质证书 + 主管部门公开信息。坑：资质过期或超范围经营。
5. **履约能力基础**：是否具备干这件事的资源与业绩。到哪里查：用户上传业绩证明 + 研报旁证。坑：用意向替代已落地能力。
6. **备案/审批**：特定业务是否完成备案或审批。到哪里查：用户上传批文 + 公开披露。坑：未完成即视为具备。

### 三、查信用（4 项，红线密集）
7. **涉诉记录**：按案由分类，逐条含案号 + 平台 + 日期。到哪里查：用户上传裁定/公告 + 裁判文书网（用户上传或可及公开披露）。坑：只查公司不查实控人。
8. **被执行与失信**：公司/法定代表人/实控人三线并查，含终本与限高。到哪里查：用户上传执行信息 + 执行信息公开网/信用中国（用户上传或可及公开披露）。坑：未回溯历史名称。
9. **行政处罚**：含文号、机关、事由、金额。到哪里查：用户上传处罚决定 + 信用中国（用户上传或可及公开披露）。坑：把"未检索到"写成"不存在"。
10. **经营异常与严重违法失信**：列入/移出情况。到哪里查：用户上传 + 公示系统/信用中国。坑：忽视已移出但仍存隐患记录。

### 四、查过往（3 项）
11. **历史履约**：过往项目交付与付款行为。到哪里查：用户上传合同/结算凭证 + 公开舆情线索。坑：用承诺替代证据。
12. **欠薪/暴雷/烂尾**：负面履约事件。到哪里查：用户上传说明 + 舆情线索（标待官方验证）。坑：舆情当事实定级。
13. **口碑与舆情**：行业评价与负面事件。到哪里查：研报/纪要/观点（）+ 舆情线索（标待官方验证）。坑：采信传闻作事实。

### 五、查关联（3 项）
14. **股权穿透与实控人**：逐层穿透至最终受益人。到哪里查：用户上传股权结构 + 公示系统。坑：停在表层股东不穿透。
15. **关联方失信与互保联保**：关联企业集群、已失信主体、互保联保。到哪里查：用户上传 + 公开披露。坑：忽视风险传导。
16. **对外担保与质押冻结**：对外担保余额、股权质押冻结。到哪里查：用户上传财报/公告 + 公开披露。坑：担保余额超承受力未预警。

## 检索通道分级（自查口径）
- **A 级（官方，结论以此为准）**：公示系统、执行信息公开网、信用中国、裁判文书网、四库一平台、AMAC——以用户上传材料或可及公开披露核验。
- **B 级（商业平台，仅线索）**：商业信用平台结果仅作定位线索，附表标明用途，不当官方无记录证明。
- **C 级（舆情，仅预警）**：舆情检索结果仅作线索并标"待官方渠道验证"，不得直接入表定级。

## 七大检索陷阱
1. 主体名称混淆（简称/曾用名/集团内多主体）
2. 工商/司法维度静默假设无风险
3. "未检索到"等同"不存在"
4. 只查公司不查法人/实控人三线
5. 不改历史名称回溯
6. 舆情当事实入表
7. 商业平台"暂无风险"当官方无记录
