# 输出纪律与常见坑位（融资主体资信核验）

本文件为成稿纪律，适用于 SKILL.md 输出契约落地的所有文本。下列禁词清单中的词**仅在本文件作为"不可写入内容"的说明出现**，正文与交付物中不得出现。

## 一、去 AI 化禁词清单（正文中禁用）

严禁在交付物正文中使用：总而言之、综上所述、值得注意的是、需要指出的是、不难看出、由此可见、总体而言、此外、另外、首先其次、值得一提的是、可以说、显而易见、可想而知、毋庸置疑、从某种程度上、在一定程度上、总的来说、值得一提的是。

严禁自我方法标签括号：标题不写"主名（方法标签）"，如"资信核验（Step 0 闸门）"。方法论质量放正文句、表头列或表尾批注，不进标题。

## 二、排版与成文纪律（九项，逐条过）

1. 列表项独立成行，一条一行，不复用长段落堆砌。
2. 一段一要点，不把多个结论塞进一段。
3. 生成期整段重复自查：严禁把同一整段复制两遍（常见坑：开头摘要与正文首段逐字重复）。
4. 空格/分隔符合拢：中文之间用 A/B/C、A·B 形式；箭头 `→`、连字符 `-`、加号 `+`、波浪号 `–` `—` 两侧无空格；英文复合词原样（如 `yj-fin-data`）。
5. 特殊 Unicode/装饰符优先 ASCII：指数用 `10^-7` 非 `10⁻⁷`；比较用 `<=` 非 `≤`；禁用 `✓ ✔` 等装饰勾，用文字"满足/缺口/命中"。
6. 禁自创伪专业空壳名词：先给数值与来源再命名，不凭空造"XX 系数""XX 模型"名词。
7. 约量词不悬空："约 X"后必跟具体数字，不写"约较高""约较大"。
8. 通篇中文为主，专有工具名保留原文。
9. 无残留物：不得出现 `__` 占位、裸 `TBD`、孤立"待补"无说明；不得有孤立标题无正文。

## 三、不适用清单（PDF 专属，勿迁移到 HTML 产物）

以下为 PDF 渲染纪律，本技能交付物为单份自包含 HTML，不适用：分页控制、页码、封面页、三册分册、reportlab 调用。HTML 产物用内联 SVG/CSS 实现版式，不外链本地资源。

## 四、领域坑位（资信核验特有）

1. 主体臆测：未获准确全称与统一社会信用代码即开核验，用简称或商业平台名替代权威主体。必须 Step 0 先锁死主体全称与代码。
2. 工商/司法维度静默假设无风险：不可达维度须标"待补充核验"，绝不写"未发现违规/无诉讼"充当无风险证明。
3. "未检索到"写成"不存在"：须写明检索关键词与日期，不得把未查到等于无记录。
4. 红线被降级：命中失信/限高/破产等红线一律"不合作"，不得因利润高/关系硬/领导催而降级。
5. 舆情当事实：舆情仅作线索并标"待官方渠道验证"，不得直接入表定级。
6. 商业平台"暂无风险"当官方无记录：官方渠道（A 级）优先，商业平台仅作线索。
7. 三分结论模糊：结论只能是"可合作/谨慎/不合作"，禁止"基本可行""建议进一步了解"等模糊表述。
