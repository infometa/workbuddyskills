# 单 HTML 报告结构模板（融资主体资信核验）

交付物为单份自包含 HTML（SVG/CSS 内联，双击可开，不外链本地资源）。六章骨架：

```
<!doctype html>
<html lang="zh-CN">
<head><meta charset="utf-8"><title>{主体}资信核验报告</title>
<style>/* 内联：标题层级、表格边框、待核黄底高亮、红线红底、声明灰底 */</style></head>
<body>
  <h1>{主体全称} 资信核验报告</h1>
  <p class="lead">核验结论：（可合作 / 谨慎 / 不合作）— 资信核验自查参考，非法律/司法判定</p>

  <h2>一、核验概况</h2>
  <!-- 主体全称+统一社会信用代码、交易角色、核验级别与用途、基准日、已检索渠道清单 -->

  <h2>二、主体与资格</h2>
  <!-- 工商基础、法定代表人及变更、股权结构与实控人、资质许可、履约能力 -->

  <h2>三、信用与涉诉</h2>
  <!-- 涉诉（案由+案号+平台+日期）、被执行与失信（三线）、行政处罚（文号+机关+事由+金额）、经营异常 -->

  <h2>四、过往与口碑</h2>
  <!-- 历史履约、付款结算证据、舆情（标待官方验证）、走访 -->

  <h2>五、关联与传导</h2>
  <!-- 关联企业、关联方失信、对外担保余额、股权质押冻结、传导路径 -->

  <h2>六、核验结论与处置</h2>
  <!-- 三分结论、红线命中、谨慎项前置条件与增信、不合作项中止建议 -->

  <h2>附表</h2>
  <!-- 五查十六项核验表 + 检索留痕台账（渠道/关键词/日期/结果/证据编号） -->

  <footer>本报告由祜·Care 与 Gangtise 合作开发，属测试技能，仅供融资主体资信核验复盘与参考。本报告不构成任何投资建议，据此决策风险自担。如有优化建议或业务咨询，请联系 13386019198。</footer>
</body>
</html>
```

注意：未核实项标 `【待核：具体说明】` 并黄底高亮；红线命中红底强标；涉诉/执行/处罚须含案号/文号+来源+日期，三项缺一即不合格。
