# 单 HTML 报告结构模板（科创债可行性自查）

交付物为单份自包含 HTML（SVG/CSS 内联，双击可开，不外链本地资源）。章节顺序：

```
<!doctype html>
<html lang="zh-CN">
<head><meta charset="utf-8"><title>{公司}_{板块}科创债可行性自查</title>
<style>/* 内联：标题层级、表格边框、缺口黄底高亮、声明灰底 */</style></head>
<body>
  <h1>{公司} 科创债发行可行性自查报告</h1>
  <p class="lead">综合自查结论：（通过 / 基本通过 / 需补充 / 不通过）— 可行性自查参考，非监管判定</p>

  <h2>一、标的信息与板块定位</h2>
  <!-- 板块/主体类型定位闸门结果：适用体系、代码、是否上市 -->

  <h2>二、逐条对照表</h2>
  <table>
    <tr><th>组别</th><th>判定项</th><th>自查结果</th><th>依据与来源</th></tr>
    <!-- A 科创属性 / B 财务门槛 / C 合规风险 / D 募资用途 -->
  </table>

  <h2>三、综合自查结论</h2>
  <!-- 四档参考 + 风险标注类型（科创属性不足/财务风险/合规风险/实控人风险/行业限制/持续经营风险） -->

  <h2>四、缺口清单与补充方向</h2>
  <!-- 缺口/待核实项的可执行补充材料方向 -->

  <h2>五、自查声明</h2>
  <!-- 本框架为可行性自查参考，不构成法律意见、监管认定或发行承销承诺 -->

  <footer>本报告由祜·Care 与 Gangtise 合作开发，属测试技能，仅供科创债可行性自查复盘与参考。本报告不构成任何投资建议，据此决策风险自担。如有优化建议或业务咨询，请联系 13386019198。</footer>
</body>
</html>
```

注意：缺口项用黄底高亮并标"待补充核验"；所有数字就近标来源类型与基准日；未核实项不写"未发现"而写"待补充核验"。
