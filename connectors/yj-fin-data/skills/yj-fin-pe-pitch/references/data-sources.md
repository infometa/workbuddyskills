# 维度可达性声明（yj-fin-pe-pitch）

本文件说明本技能各数据维度的可达性，以及缺失时的标准措辞。本技能核心是"路演准备与自检"——主要基于**用户提供的项目材料（BP/讲稿）**做结构梳理与问答准备；需要 benchmarking（市场规模/竞品参数/可比口径）时引用可及研报/公告/行情旁证。外部库缺失维度如实标"待补充核验"，不阻塞出准备报告。

## 二、不可达维度（如实标注，绝不编造）

| 维度 | 状态 | 缺失时标准措辞 |
|---|---|---|
| 工商登记 / 股权结构 | 本技能无专库 | "受数据可得性限制，权属与工商登记信息待补充核验" |
| 司法冻结 / 查封 / 诉讼 | 本技能无专库 | "受数据可得性限制，权属限制与涉诉情况待补充核验" |
| 一级市场融资库 | 本技能无专库 | "受数据可得性限制，历史融资与轮次信息待补充核验" |
| 非上市主体财务 | 本技能无专库 | "受数据可得性限制，标的财务数据待补充核验" |
| 公网检索 | 网关受限 | "以用户上传材料与可及研报、公告旁证为准" |

## 三、铁律（不可违反）

1. **缺即如实"带待补充"**：不阻塞出报告，也不假装用"其他来源"把空缺填成"查过的样子"。
2. **绝不假设**：不假设无诉讼、无冻结、无权属瑕疵。
3. **绝不倒推**：不按金额倒推轮次、不按区间倒推参数。
4. **绝不编造**：不编造权属、交易案例、财务数据、可比公司、股东名册。
5. **主动交叉验证**：关键数字（市场规模、收入、毛利率、客户集中度、融资额/估值）用 ≥2 个独立来源交叉核对；项目方材料主张与独立源不一致处显式标注差异来源标签，缺口"待补充核验"。
6. **来源就近标注**：每个数字标注来源类型与基准日；估算与假设单列标明"假设"。

## 四、用户材料优先原则

接入数据用于**旁证与交叉验证**；路演准备的核心依据（BP 主张、产品参数、客户与财务口径、融资方案）以**用户上传材料**为准，标注 `[用户提供]` 或 `[项目方材料]`。二者不一致时，显式标注差异，不静默取其一。
