# 维度可达性声明（yj-fin-inv-dd-report）

本文件说明本技能各数据维度的可达性，以及缺失时的标准措辞。

## 二、不可达维度（如实标注，绝不编造）

| 维度 | 状态 | 缺失时标准措辞 |
|---|---|---|
| 工商登记 / 股权结构 | 本技能无专库 | "受数据可得性限制，权属与工商登记信息待补充核验" |
| 司法冻结 / 查封 / 诉讼 | 本技能无专库 | "受数据可得性限制，权属限制与涉诉情况待补充核验" |
| 一级市场融资库 | 本技能无专库 | "受数据可得性限制，历史融资与轮次信息待补充核验" |
| 非上市主体财务 | 本技能无专库 | "受数据可得性限制，标的财务数据待补充核验" |
| 实时法规 / 监管规则现行条文 | 本技能无实时法规库 | "规则引用为基线提示，请以最新监管原文核验，不保证现行有效" |
| 公网检索 | 网关受限 | "以用户上传材料与可及研报、公告旁证为准" |

## 三、铁律（不可违反）

1. **缺即如实"带待补充"**：不阻塞出报告，也不假装用"其他来源"把空缺填成"查过的样子"。
2. **绝不假设**：不假设无诉讼、无冻结、无权属瑕疵、无重大违法。
3. **绝不倒推**：不按金额倒推轮次、不按区间倒推参数。
4. **绝不编造**：不编造股权比例、处罚结论、交易案例、财务数据、可比公司。
5. **来源就近标注**：每个数字标注来源类型与基准日；估算与假设单列标明"假设/未经审计"。
6. **主动交叉验证**：关键数字以 ≥2 独立源交叉核对，不一致显式标注差异来源；缺口一律"待补充核验"，不使用"探活/未连通/故障/兜底/已降级"等故障词。

## 四、用户材料优先原则

接入数据用于旁证与交叉验证；尽调的核心依据（招股书草稿、底稿目录、合同清单、财务报表、访谈纪要）以用户上传材料为准，标注 `[用户提供]` 或 `[项目方材料]`。二者不一致时，显式标注差异，不静默取其一。
