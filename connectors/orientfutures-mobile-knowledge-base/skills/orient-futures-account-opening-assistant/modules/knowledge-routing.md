# 个人普通期货业务知识路由

## 1. 先过范围门

完整执行 [范围与安全](safety-and-fallback.md)。所有非个人主体业务、基金、资管、特殊品种权限业务在此之前结束，不检索、不澄清流程、不以“已审核”绕过。

允许任务才提取：首次开户/已在其他公司开户/已有东证账户/已提交申请，个人开户或存量管理的环节，所问材料/时间/计算/故障。只问会改变答案的必要条件，不索取敏感信息。

普通个人“怎么交易期货、怎么开始、怎么买卖、我想参与、第一步呢”沿用明确期货上下文按开户注册路径处理；纯“开仓是什么”转百科。已有账户/已申请仅答当前环节，不重复登记。不得为交易参与意图查询策略或给品种/方向/时点建议。

## 2. 可检索知识范围

| 个人允许主题 | 本轮目录定位方向 |
| --- | --- |
| 开户方式、材料、手机流程、验证码/照片/视频/证书/回访、审核与交易编码、模拟账户、密码和资料维护 | 期货开户与账户管理中的个人相关最窄记录 |
| 银期签约、支持银行卡、结算账户、入出金、可取资金与资金安全 | 银期签约与资金管理中的个人相关最窄记录 |
| 手续费/一手保证金公式、普通交易规则、登录/下单界面提示、结算单 | 期货交易规则与费用中的个人相关最窄记录 |

不读取特殊品种权限或基金业务正文。前三类中混有法人、基金或权限说明时只提取能够独立成立的个人普通业务片段，不照搬整篇。没有可分离片段不回答具体事实。不得依赖本地 references/knowledge，发布包不携带这些历史资料。

## 3. 生产 MCP 链路

1. `knowledge_base_list_books({})` 取得本轮集合，匹配 orient-futures-business-guide；键仅作匹配提示，不可跳过发现。
2. `knowledge_base_get_book_toc({book_key, root?, depth?})`；root 只用本轮节点键，depth 1～6。用标题/大小定位最窄允许记录。
3. `knowledge_base_get_section_content({book_key, section, view, max_bytes})`；section 原样字符串保留零/斜杠，self 读取本节，subtree 仅用于必要完整子主题；max_bytes 1000～200000，正文不传 depth。
4. 核对书目/章节/主题/非空正文。oversized 下钻或 self；不能把正文省略当无知识。只读失败原参数最多一次重试，失败不换相似内容补齐。
5. 保留 provenance、标题路径和检索键于内部，对外统一来源，不显示工具或章节。固定排除电话与公司入口无需假装检索成功。

完整契约见 [接口参考](../references/api-spec.md)。

## 4. 个人事实核验

- 材料按本轮知识区分身份证原件、正反面照片、证件照、签名照和银行卡网点，不凭常识补齐。
- 手机开户只答其所问路径；常见故障可说明审核资料列出的排查步骤，但不认定用户实际故障。
- 密码区分交易密码、资金密码、监控中心密码；不得索要任何密码。
- 签约时间与入出金时间分别说明；支持银行、户名/银行卡条件只按正文，不默认当前全覆盖。
- 可取资金/费用冻结只说明一般机制，不判断实际账户资金异常。
- 费用先 [三层口径](fees-and-margin.md)，保留公式和变量，不读公司公示页面、不用示例当个人费率。
- 夜盘/集合竞价只按知识一般规则说明，不补造具体品种当前交易时段或权限门槛。
- 资料含自有 APP 操作时执行 [入口规则](answer-and-conversion.md)，只有个人允许业务才能显示智达 APP 入口。

## 5. 合并与时效

稳定业务说明、时效规则、正文原例、常见原因与个人状态分开。资料没有现行依据不能称最新标准；不存在实时状态工具，不自动转调用假接口。

复合问题逐项先过门：允许个人部分最小检索，通用定义可转百科，明确行情数据可转综合查询且只回客观值，排除部分只电话句。互不相干的成功分支可保留，不从失败/排除分支引入材料、入口或解读。
