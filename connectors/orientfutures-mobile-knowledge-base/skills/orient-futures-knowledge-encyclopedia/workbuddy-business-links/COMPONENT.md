# 核心业务链接交付规则

业务规则与入口数据由 skills/docs 的唯一业务源生成。目录维护 ID、完整标签、原始地址、用途、启停和版本；业务 Skill 保留各自的场景条件。显示入口不表示读取公司参数、提交申请、完成开户、下载或安装成功。

## 唯一交付路径

四类核心入口统一调用知识 MCP 的 `business_links_show`，以独立 MCP App 在本轮回答内容流中交付。Skill 只提交 `action_ids`，可省略 `catalog_version` 使用当前目录；正式工具 Schema 是可用 ID 与版本的依据。不传文案、URL、HTML、任意跳转参数或自行构造的证据。

- `company_fee_schedule`：公司手续费标准查询入口。
- `company_margin_parameters`：公司保证金参数查询入口。
- `individual_pre_account_opening`：自然人预开户信息登记与后续流程入口。
- `zhida_app_download`：东方证券期货智达APP下载或打开入口；该 ID 的用途包括打开和使用 APP 办理业务。

模型正文不再复制这些入口的 Markdown、裸地址或 HTML；知识服务不自动提供开户行动卡，Dashboard 不承担这些入口的展示。工具未注册、调用失败或组件不可用时，说明入口暂时无法展示，不重新启用旧 Markdown 路径。其他经核验的非目录资料链接仍按普通 Markdown 输出；不得将核心目录入口归为“其他链接”来绕过本规则。

仅展示固定入口时不调用知识检索、行情查询或网页读取工具；允许且必须调用专门的链接展示工具。知识正文查询失败不妨碍独立入口展示。解释材料、条件、步骤、时间或费用等业务事实，仍必须有本轮审核正文支持。

## 触发和位置

1. 公司手续费/保证金入口按主答 Skill 的现有规则选择：只涉及一项只给对应 ID，同时涉及两项可在一个组件中批量展示。先解释，再调用组件；不从官网取数、不把公示标准等同于个人实际标准。
2. 回答实际引导用户下载、打开或使用东方证券期货自有 APP 办理业务，或用户明确索要该 APP 入口时，在相关说明之后展示一次 `zhida_app_download`。首次介绍及关键步骤使用完整名称“东方证券期货智达APP”。银行 APP、监控中心开户云、独立微信小程序、企业微信不触发此入口，不互相改名。
3. 预开户由开户助手判断：默认自然人；实际参与/开户注册意图或明确个人标准且未开户/未说明有账户时，按源条件展示。已有账户、已提交申请、非自然人期货开户、未确认适用的基金业务、拒绝引导时不主动展示。拒绝后只有用户重新表达开户意愿或主动索要适用入口才恢复。
4. 预开户入口在全部正文、风险/隐私提示、来源和其他入口之后调用；之后不再追加正文或链接。需要多个入口在末尾一起展示时，在一个组件批量提交，服务端把预开户排到组件最后。服务端只能排序组件内部，整篇回答位置仍需实际会话验收。
5. 复合问题由主答 Skill 汇总入口，同一回答同一入口只交付一次，不让多个 Skill 各自追加。新一轮用户主动索要同一入口可再次展示。图表放在正文前的 Dashboard，链接组件出现在各自说明之后，不计入 Composer 次数。

## 失败、压缩和完成检查

在本轮任务检查点保留所需 ID、理由、预定位置、已调用 ID、返回的 `delivery_id` 和状态。跨压缩仍是同一轮：恢复已核验正文与链接状态，不重复查询、不因上下文压缩再次展示成功或结果未知的入口。

工具返回 `state=prepared` 只说明入口已准备，不能证明宿主可见；组件本地 `rendered` 也不能证明用户已看到或点击。缺少可见性证据时保持未知，不通过反复调用来获取“成功感”。组件重复收到相同交付通知不会追加第二份链接，但宿主重复工具调用产生的多个内容块无法由组件删除，因此模型也不得重发成功或结果未知的调用。

组件采用统一业务入口卡片：展示“东方证券期货”品牌文字、目录中的完整链接标签和用途说明，以及跳转图标；整张卡片可点击，每项只保留一个语义链接。不展示“查看完整地址”、裸地址或地址输入框。单项卡片利用宿主的最小展示空间，文字换行或错误提示出现时按内容增高；多项在宽屏分两列、窄屏纵向排列，预开户仍排最后。打开由用户点击触发；打开请求失败时，同一组件保留原链接并提示稍后再次点击重试。组件按实际内容高度通知宿主，最终容器高度受宿主限制。显示失败不重新画图或取数，也不输出第二套模型链接。对用户只说明具体失败，不暴露目录、接口和内部状态。

结束前核对本轮应交付的入口是否已调用、无遗漏/不适用入口、APP 不重复、预开户是否在末尾且之后没有正文。无法确认真实显示时不声称用户已看到；不得承诺宿主绝不漏显。所有对外数据来源统一为“数据来源：东方证券期货”，内部知识及采购来源只供核验。
