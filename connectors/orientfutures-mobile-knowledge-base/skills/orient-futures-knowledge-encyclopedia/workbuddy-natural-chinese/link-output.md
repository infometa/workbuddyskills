# 客户链接与表达层边界

核心业务目录入口由 `workbuddy-business-links` Component 交付。自然中文整理只调整链接前的普通说明，不生成、复制、恢复或改写核心入口的 Markdown、URL 或 HTML，不触发第二次工具调用。预开户组件之后不得因润色追加正文。

普通非目录资料链接保留已经核验的完整显示文字和原始地址，使用正常 Markdown；不得把核心目录入口当作普通链接绕开唯一交付路径。无法确认名称或用途时不编造，不替换相似网址。

业务模块负责是否展示及位置；表达层不改变开户主体、已开户、已申请、拒绝引导等条件，不把 prepared 或模型文字当作实际显示回执。
