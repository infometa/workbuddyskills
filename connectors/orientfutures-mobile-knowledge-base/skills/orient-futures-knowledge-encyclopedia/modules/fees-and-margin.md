# 范围前置

先执行 [回答与合规边界](answer-and-boundaries.md)。被排除业务不能借费用概念或演算绕行；账户所属主体而非提问者身份决定范围。公司公示标准的“公司”字样本身不等于公司账户。

# 保证金与手续费三层口径

本模块按业务源明确区分交易所/合约码表、公司公示、个人实际标准，不能互换。普通手续费或保证金问题不自动扩展为个人咨询，不追问是否已开户。

## 路由

| 问题 | 处理 |
| --- | --- |
| 保证金是什么、为什么变化、三层标准有什么区别 | 通过知识 MCP 解释相关概念，随后附相关公司官网入口 |
| 某一明确实际合约的码表保证金率 | 执行 `contract-query.md`，查询同一合约本轮实际返回的多头、空头保证金率和保证金算法 |
| 东证期货公司某品种手续费/保证金是多少、在哪里看 | 直接给下方对应固定入口，不读取页面、不输出公司数值，仅调用 `business_links_show`，不调用内容查询工具 |
| 手续费怎么算、一手保证金怎么算、需要多少钱 | 转 `orient-futures-account-opening-assistant` 解释公式和变量，并附相关公司官网入口；本 Skill 仅补其需要的实际合约码表参数 |
| 明确询问我的/个人/账户实际手续费或保证金 | 转开户助手；已开户则客户经理/正式账户渠道，未开户或未说明有账户则先开户后咨询客户经理；不推断个人标准 |

计算意图优先于泛化公式知识路由；不能因出现“怎么算”就只给通用概念或公司链接。个人意图仅在明确表达时触发，其他保证金/手续费问题不默认追问账户或推开户。

## 固定公司查询入口

- `company_fee_schedule`（通过业务链接组件展示）
- `company_margin_parameters`（通过业务链接组件展示）

涉及保证金或手续费且不是只问个人实际标准时，默认在直接答案之后附相关链接；只问一项只给一个，同时问两项或三层口径时可给两个。固定入口可以由主答 Skill 展示，无需反复路由。公司入口不是内部知识来源，不受隐藏书目/章节的规则限制。

只展示链接，不通过 MCP、网页访问、下载、解析或模型记忆读取、复述页面参数，不声称已经查询公司标准。这是公司页面内容的边界，不是行情 MCP 码表取数禁令。没有返回的手续费字段不能凭空构造；当前未确认行情 MCP 的合约手续费字段。

## 合约码表参数

先搜索确认唯一实际合约，再取 `futures_get_instrument_info`。需要补字段时用 `quote_list_parameter_options(domain=futures, parameter=fields, usage=instrument_list)` 发现实际可用值，再精确按同一市场和代码调用 `futures_list_instruments`。

已知字段方向为 `long_margin_ratio`、`short_margin_ratio`、`margin_type`；它们是发现提示，不是绕过运行时目录的承诺。只使用本轮响应实际存在、非空、编码与比例含义明确的原值；不猜乘除 100 的转换、不把多空合并为一个率，不把保证金算法枚举猜成中文。

展示时明确“合约码表参数”，保留对象、返回时间和来源；无时间不得称为最新交易所规则。不能把它们称为公司公示标准或个人账户实际标准。缺字段只说明该合约本次未返回该项，不能以“保证金一律不查”为由跳过其他已授权数据。

复合问题合并知识、码表与入口，已核验分支保留；开户助手判断入口适用性。所有非个人主体账户业务及基金、资管、特殊品种权限办理先转开户助手的范围门，不在本模块解释流程/公式或提供任何业务入口；适用的自然人“点击进入云开户”由开户助手放在整份答案最后，公司标准链接在它之前。

按共享业务链接 Component 调用 `business_links_show`，只传所需 ID；不输出核心入口 Markdown，也不把公司查询入口放到预开户组件之后。
