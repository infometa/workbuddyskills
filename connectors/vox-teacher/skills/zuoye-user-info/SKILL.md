# 一起作业教师信息查询

你已连接 **vox-teacher** 连接器（MCP，OAuth 授权后自动携带登录凭证）。当用户想了解自己在一起作业的信息时，按以下流程执行。

## 何时使用本技能

- 「查一下我在一起作业的信息」「我是谁」→ 主流程
- 「我的授权还有效吗」「绑定状态怎么样」→ 只走第 1 步
- 其它工具报「会话已过期」→ 走第 4 步引导

## 执行流程

1. **查授权状态**：调用 `get_auth_status`（无参数）。
   - 返回「授权状态：有效」→ 继续
   - 工具报错或返回失效提示 → 直接跳到第 4 步

2. **查教师信息**：调用 `get_user_info`（无参数，默认聚合双源）。
   - 返回教师信息 → 进入第 3 步组织答复
   - 返回「会话已过期」→ 跳到第 4 步
   - 想指定单一数据源时可传 `source` 参数：`"washington"`（教学维度）/ `"ucenter"`（资料维度）/ `"all"`（聚合，默认）

3. **组织答复**（面向用户的话术要点）：
   - 开头一句人话：「您是王老师，教数学，在某某小学带 3 个班」——从返回中提取 real_name/subject/school_name/clazz_count 自然成句
   - 数据源差异说明（仅当用户追问）：信息来自 washington（教学维度）与 ucenter（资料维度）两个系统
   - 不要罗列全部原始字段；用户追问细节时再展开

4. **会话失效引导**（固定话术）：
   > 您在一起作业的登录已过期。请在左侧【连接器】中找到 **vox-teacher**，点击「重新连接」，用手机验证码或账号密码重新登录后，再让我查一次就好。

   注意：不要反复重试失效的工具调用；引导后停止本轮操作，等用户重连完成。

## 响应格式说明（重要）

接口返回为 ALPS MapMessage JSON：`{"success": true/false(布尔), "info": "...", "user": {...}}`。

- **`success` 是布尔值**，不是字符串——判断成功看 `success == true`
- 错误信息在 `info` 字段
- `user` 若嵌套在 `data` 下也能取（两种形态都兼容）

## 边界（不要做的事）

- 本技能只读，不提供任何修改/写入操作；用户要求改数据时说明暂不支持
- 不要向用户索要或展示密码、完整手机号等敏感信息
- 工具返回的 user_id 等原始字段可以直接说（非敏感），但不要输出任何 cookie/令牌类内容
- 查询班级/作业/学情等业务数据 → 改用 `vox-teacher-api` 技能（fetch_as_user 通用查询），本技能只管身份与授权状态

## 排障提示

- `get_auth_status` 报「无法确认身份」→ 连接器未连接，走第 4 步话术
- `get_user_info` 报「地址未配置」→ 服务端配置问题，回复用户「服务正在配置中，请稍后再试」并停止
- `get_user_info` 报「washington 会话已过期」但 ucenter 正常（或反之）→ 单一数据源会话异常，如实告知用户「部分信息暂时无法获取」，可建议重新连接
- 返回数据缺字段（如没有 subject）→ 有什么说什么，缺的字段不要编造

## 环境说明

当前连接的是**生产环境**（`https://mcp.17zuoye.com`，网关 → `www.17zuoye.com` / `ucenter.17zuoye.com` 双源查询）。生产环境无固定验证码，登录走真实短信验证码或账号密码。
