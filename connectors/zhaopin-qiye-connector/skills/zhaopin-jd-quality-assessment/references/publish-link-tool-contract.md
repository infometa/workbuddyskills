# 职位发布草稿链接｜Connector Tool 契约

## 依赖与用途

此能力依赖当前会话实际已安装、认证并暴露的智联招聘企业 Connector：`zhaopin-qiye-connector`。依据用户提供的 Connector 包（版本 `1.0.1`）中 `skills/zhaopin-jd-generation/references/jd-generation-implementation.md` 的已实现契约，Tool 名称为 `generateJobRedirectLink`。

它将最终 JD 暂存为 RD 职位发布表单草稿，并返回跳转链接。它**不创建职位、不发布职位、不代表审核通过**。最终表单仍须由用户在 RD 页面核对并主动确认。

## 调用前提

必须同时满足：

1. 当前会话实际可调用该 Tool；不可因本文件存在而假设可用。
2. 用户已确认职位标题与最终版 JD。
3. JD 正文已经清除评分、内部备注、待确认项、模型推断与其他非发布内容。

本 Skill 的公开描述已声明：最终 JD 生成后会自动创建预填发布草稿。因此，只要最终 JD 已生成且 Connector 可用，就应调用 Tool；最终发布仍必须由用户在 RD 页面自行确认。标题或正文不满足前提时，不能调用或虚构链接。

## 调用参数

仅传递以下必填对象，且不得添加其他字段：

```json
{
  "request": {
    "title": "用户已确认的职位标题",
    "description": "用户已确认的最终JD正文"
  }
}
```

| 字段 | 约束 |
| --- | --- |
| `request.title` | 已确认的职位标题；最长 200 字符。 |
| `request.description` | 最终、可用于发布的 JD 正文；10–10000 字符。 |

调用前检查长度和内容。标题或正文不满足约束时，说明具体问题并请用户修正；不截断、不替换、不调用。

## 结果与异常

| Tool 结果 | 用户可见处理 |
| --- | --- |
| 返回有效 `url` 与 `expireAt` | 在最终 JD 后展示“前往智联招聘核对发布草稿”的链接与有效期；说明草稿已生成、职位尚未发布。 |
| 返回 `code` | 不向用户展示；它不是职位编号、发布凭证或成功状态。 |
| 无 `url`、调用失败或链接到期 | 紧跟最终 JD 如实说明未生成可用发布链接；保留最终 JD，允许用户稍后重新运行。 |
| 未认证、无权限或 Tool 不可用 | 说明当前会话无法生成草稿链接；不猜测认证状态、不提供手写链接。 |

此链接是本 Skill 已声明的“定稿 JD 后自动生成发布草稿”工作流的功能性后续步骤，不能用于营销导流。它默认展示在最终 JD 后，不得与职位实际发布混同。
