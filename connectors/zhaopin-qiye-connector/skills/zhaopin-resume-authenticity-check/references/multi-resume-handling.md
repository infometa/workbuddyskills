# 多份简历的输出隔离规则

## 默认单位

一份可可靠识别归属的简历材料对应一名候选人、一张决策图谱和一份独立简报。任何候选人之间不共享红线、黄线、待补信息、证据位置或问题编号。

## 识别与澄清

- 用户提供多个文件但未标候选人时，可用文件名或用户给定代称作为临时标签；无法可靠区分时，请用户提供“文件 / 候选人代称”的最小映射。
- 同一文件中混有多位候选人内容、或多份文件实际属于同一候选人但无法确认时，不合并分析，先澄清材料归属。
- 共同 JD 可作为每位候选人的相同业务提问背景；没有共同 JD 时，不根据简历内容猜测目标岗位。

## 输出顺序

```text
候选人 A：置顶决策图谱 → 独立简报 → 红/黄线与业务问题
候选人 B：置顶决策图谱 → 独立简报 → 红/黄线与业务问题
……
（仅在用户明确要求时）所有候选人之后：材料核验进度总览
```

进度总览只列出材料完整度、待补信息和建议下一步，不比较红黄线数量，不输出真实性、能力、录用或淘汰排名。
