# 简历核验决策图谱规范

## 目标

用一张可独立阅读的图谱先呈现本轮核验优先级与行动路径，正文再提供每个判断的证据和问题。图谱的价值是快速决策，不是用视觉放大风险。

## 固定构图

```text
┌───────────────────────────────────────────────────────────┐
│ 候选人代称 · 目标岗位 · 当前材料范围                         │
├────────────┬────────────┬────────────┬─────────────────────┤
│ 🔴 红线级   │ 🟡 黄线级   │ 🧩 待补信息  │ 🔵 业务面试提问       │
│ 数量        │ 数量        │ 数量        │ 数量                │
├───────────────────────────────────────────────────────────┤
│ 材料线索 → 事实冲突门 → 红/黄线分流 → 最小核验问题 → 人工复核 │
├───────────────────────┬───────────────────────────────────┤
│ 本轮优先核验           │ 业务面试方向（仅作为最后一步）       │
├───────────────────────────────────────────────────────────┤
│ 仅供人工核验准备，不构成真实性或招聘结论                     │
└───────────────────────────────────────────────────────────┘
```

## 指标卡片的布局硬规则

顶部四张指标卡片必须采用**四列等宽卡片网格**；每张卡片是一个不可拆分的独立容器，内部仅包含本指标的图标、标签和数值。禁止把四个标签放在一层、四个数值放在另一层后再叠加定位。

```text
┌────────────────┐  ┌────────────────┐  ┌────────────────┐  ┌────────────────┐
│ 🔴 红线级核验   │  │ 🟡 黄线级核验   │  │ 🧩 待补信息     │  │ 🔵 业务面试提问 │
│                │  │                │  │                │  │                │
│     0 项       │  │     7 项       │  │     3 项       │  │     6 题       │
└────────────────┘  └────────────────┘  └────────────────┘  └────────────────┘
```

- 标签与数值都在各自卡片的水平中心线内；数值必须位于标签正下方，不得放在卡片左侧、卡片间隙或其他卡片中。
- 四张卡片的上边、下边、标题基线和数值基线必须对齐；卡片之间保留等距间隙。
- 每张卡片的数值都使用完整格式，如 `0 项`、`7 项`、`6 题`；禁止将单位、数值、图标拆散为浮动文本。
- 卡片宽度不足以容纳标签时，缩短标签文案或减小字号；不得让文字越界、重叠或覆盖相邻卡片。
- 视觉产物生成后，只有在能保证每一个图标、标签、数值均位于对应卡片边界内时才输出；否则跳过视觉图谱，退回 Markdown 决策看板。

## 画布、安全区与流程区

- 标题、材料范围和目标岗位只允许出现一次，固定放在画布顶部安全区；标题和首行文字距画布上边缘至少保留一个标题行高度，不能裁切。
- 四张指标卡片中的“图标 + 标签 + 数值”作为一个整体，使用卡片中心点进行水平与垂直居中；同一行的四组内容必须共享同一标签基线和数值基线。
- 流程区只能包含五个流程节点和四段箭头：`材料线索 → 事实冲突门 → 红黄线分流 → 最小核验问题 → 人工复核`。禁止在流程箭头上、节点之间或画布右侧插入标题、悬浮说明、图例、工具提示或重复摘要。
- 所有文字必须属于顶部安全区、指标卡片、流程节点、优先事项卡片或底部结论之一；不存在“自由漂浮”的文字层。
- 若生成器无法保证上述安全区、中心锚点和容器归属，回退为 Markdown 决策看板。

## 视觉语言

- 使用深色或中性背景、清晰的浅色卡片、留白和单一强调色，保持专业招聘产品风格。
- `🔴` 仅表示关键事实直接冲突的优先核验；`🟡` 仅表示待澄清；`🔵` 仅标识业务面试方向。不得使用“高危”“造假”“欺诈”等标签。
- 红线/黄线卡片最多显示编号与短摘要。完整材料事实、合理解释和问题必须留在正文表格中，避免将候选人细节塞进图片。
- 图谱所有数字、编号、摘要和“无红线”结论必须能回指正文；没有依据的装饰性指标、分数、置信度或雷达图一律不用。
- “待补信息”只统计确实影响当前核验或业务提问、且正文已列出的最小补充项；不得为了视觉平衡重复计入黄线项。

## 生成失败的回退

若当前对话不能生成可靠视觉产物，或图中文字无法确保准确，跳过图谱，直接输出模板中的 Markdown 决策看板；不声称图谱已生成或已下载。
