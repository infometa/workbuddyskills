# 异常与恢复

| 场景 | 处理方式 |
| --- | --- |
| OAuth 失效或 401 | 引导用户在 WorkBuddy 重新连接，等待浏览器授权完成后重新调用账号工具 |
| 权限不足 | 说明缺少的 OAuth 或账号权限，不调用其他工具绕过 |
| 积分不足 | 展示当前余额和预计积分，引导用户前往 NovAI 处理，不重复提交 |
| 确认令牌缺失、过期或参数变化 | 重新预估并再次取得用户确认 |
| `CANVAS_REVISION_CONFLICT` | 重新读取画布，基于最新 revision 生成新的操作 |
| 幂等冲突 | 检查是否错误复用了其他业务的 Key；同一业务重试必须保持原参数 |
| 任务仍在处理中 | 按规定间隔继续查询，不重复创建任务 |
| 查询超时 | 返回现有任务 ID；后续继续查询原任务 |
| 可重试失败 | 先确认退款状态，用户要求后重新预估并调用重试工具 |
| 不可重试失败 | 返回公开错误码和可操作说明，不暴露内部响应 |
| 结果地址过期 | 重新查询成功任务获取新地址，不重新生成和扣费 |
| 素材不存在 | 重新调用 `material_list`，确认素材属于当前账号且类型正确 |

任何网络超时都不能直接解释为生成失败。先使用原任务 ID或幂等键查询已有结果，确认没有创建成功后才能考虑重试。
