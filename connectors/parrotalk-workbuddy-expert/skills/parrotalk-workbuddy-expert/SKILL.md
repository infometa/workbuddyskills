# 语鹦企服专家连接器

## 用途

用于查询当前连接器账号的身份信息与有效期，并在对话前确认登录态是否可用。

## 工具

### get_user_info

查询当前登录用户的账号信息。

- 参数：无
- 返回字段：
  - `user_id`：用户唯一标识
  - `phone`：脱敏手机号
  - `status`：账户状态，`active` 表示正常
  - `expire_at`：账户有效期，格式 `YYYY-MM-DD`
  - `login_valid`：登录态是否有效
  - `checked_at`：校验时间
- 示例：

```json
{
  "user_id": "u_3f2a...",
  "phone": "138****8000",
  "status": "active",
  "expire_at": "2099-12-31",
  "login_valid": true,
  "checked_at": "2026-10-17 14:00:00"
}
```

### ping

检查 MCP 服务是否可用，无参数。

## 认证与错误处理

- 首次连接时 WorkBuddy 会自动打开浏览器完成手机号验证码登录，登录后凭证由客户端保存。
- access_token 过期时客户端会自动使用 refresh_token 续期，无需用户操作。
- 服务端返回 401：登录态失效，引导用户重新连接连接器。
- 服务端返回 403：账户已过期或被停用，提示用户联系管理员续期，重新登录无法解决。
- 账户默认有效期为 `2099-12-31`。

## 使用建议

- 用户询问“我是谁”“账号什么时候到期”“登录是否正常”时，调用 `get_user_info`。
- 不要向用户展示完整手机号之外的敏感凭证；工具返回的手机号已脱敏。
