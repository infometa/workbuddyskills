# AIRA（校管家）连接器使用指引

AIRA 是校管家教培管理系统对外的 AI 助手。用户在 WorkBuddy 里绑定本连接器时，会跳转校管家登录页完成 OAuth 授权；授权成功后，AI 能以「该用户在校管家里的身份和权限」查询机构经营数据，看不到权限之外的数据。

## 能回答什么

工具按业务域分组，常用的能力如下：

- **排课与课次**：查排课汇总（某段时间各校区排了多少节、应到多少人）、课次明细（某节课的班级、老师、教室、点名情况）、班级的课程安排。高频问题：「最近 10 天排了多少节课」「下周三三年二班有什么课」。
- **学员与班级**：查学员档案、在读班级、剩余课时/学费、出勤记录；查班级名单、班级信息。
- **收费与财务**：查交费流水、欠费学员与欠费金额、剩余学费汇总。高频问题：「本月还有哪些学员欠费」。
- **线索（招生）**：查线索列表、跟进记录、最近 N 天未跟进的线索、线索来源与转化。
- **老师业绩**：老师课时业绩、业绩排名（可按月/按校区，是否跨校区由机构开关决定）。
- **待办**：查当前用户的待办任务列表（用户说标题时，先从列表里匹配出待办 ID 再操作）。
- **报表**：机构配置的 BI 报表查询。

## 使用要点

1. **数据权限跟着登录人走**：用户能看到的数据 = 他在校管家系统里的权限范围。查询结果为空时，先考虑是权限或校区范围没覆盖，不要反复换参数硬试。
2. **时间参数用绝对日期**（如 2026-10-01），用户说「上周」「本月」时先换算成日期区间再调用；统计类工具一般有开始/结束时间参数，默认区间以工具描述为准。
3. **校区参数**：多数查询支持传校区 ID 列表，不传则查当前用户全部可操作校区；用户点名校区时优先传校区过滤，避免整机构扫描。
4. **结果里同时有 ID 和名称**：向用户展示用名称字段；需要继续追问细节（如查某班级明细）时用 ID 传参。
5. **一次一个意图**：工具是细粒度的，先查列表再查详情，不要指望一个工具同时返回汇总加明细。
6. **单次请求 30 秒超时**：不要并发扇出大量工具调用；大时间范围查询建议先按月或按校区拆分。

## 答不了什么

写操作（排课、调课、收费、改档案等）当前不对 WorkBuddy 开放，本连接器只读。用户要改数据时，引导他登录校管家系统或联系机构管理员。
