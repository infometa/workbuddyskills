# 万兴剧厂 CLI 功能介绍与使用指南

**万兴剧厂 ReelMate CLI** 是万兴剧厂的命令行创作工具，配合 Agent 工具使用：您用一句话提出需求，Agent 工具通过命令直接在剧厂里完成剧本、图片和视频创作。

## 注册与登录

- 如果您未使用过万兴剧厂，请先完成账号注册；若已有账号，请先在网页登录。
  - 请通过以下地址完成登录注册：<https://www.reelmate.cn/home>
- 使用 CLI 前会确认登录态：本机已登录则直接使用当前账号，尚未登录时再引导登录。网页登录不等于 CLI 已登录。

## 核心功能

1. **制片工坊**：面向短剧制作的成片批量生产，走「建项目 → 导入剧本 → 资产生成 → 拆分镜出片」四环节标准流程，适合按剧本、剧集维度批量出片。
   - **上传剧本，资产/分镜专家 Agent 自动化执行，告别繁琐点击**：CLI 串联制片工坊短剧 Agent，自动化执行
     - 项目创建 + 剧本上传
     - 角色、场景、道具资产提取 + 图片批量生成
     - 分镜视频提示词 + 多剧集视频批量生成
   - **智能回填提示词，代理图片/视频批量生产，提效满分**
     - 上传资产提示词 / 视频提示词 / 资产图等已有生产素材，CLI 完成资产库和剧集分镜整理，批量回填到剧厂制片工坊项目，帮您完成图片、视频规模化后链路生产。
2. **无限画布**：面向灵感创作，进入万兴剧厂的画布页面进行操作，完成后续的生图、生视频节点。
   - **一句话灵感写剧本**：说出您的创意，智能规划故事结构与剧情内容，交付专业剧本文件，并放到画布区，可后续继续进行图片、视频等创作。

## 支持的剧目类型与画幅

- 剧目类型：国内仿真人剧、海外仿真人剧、2D/3D 动漫
- 画面画幅：9:16 竖屏、16:9 横屏

## 计费说明

剧厂能力调用按积分计费。Agent 任务完成后会展示可核对的积分消耗与当前余额，积分流水明细可前往剧厂 Web 产品页查看。

## 怎么开始？

直接在对话里说出明确需求即可，例如：

- 「帮我生成一个穿越古代的爆款女频甜宠短剧剧本，20 集」
- 「这是我的 20 集剧本，帮我走制片工坊完成资产清单提取并生成资产图」
