# HITL 呈现

有限选项怎么画给用户看。问什么、列全、分步仍只认 [_hard-gate.md](_hard-gate.md)。本页不发明选项，不改 CLI。

Skill zip 不能自带弹窗。本回合工具列表里有结构化多选题工具就调用；没有、调用失败、或用户反馈选择面板不可见，走文末回退列表。用户已经在对话里答完则直接采用，不重复询问。按工具是否可用探测，不按「现在是 Claude / Cursor / Codex」或模型名分叉。等价工具换了名字仍算可用。

## 探测顺序

1. 用户本回合已经用序号或展示名答完当前确认项：直接采用，不再弹窗，也不再铺列表。
2. 本回合能调用结构化多选题工具且用户未反馈面板不可见：只走弹窗。不要先在对话里再铺一遍同一份选项。这条只约束选项画法，不免除下一节的交付物。
3. 否则用回退列表。

已知宿主工具名（只作对照，不是项目事实）：Cursor `AskQuestion`，Claude Code `AskUserQuestion`。Codex 通常没有，走回退。

## 交付物

选择器只替代有限选项怎么画（例如确认/修改、模型展示名）。场景点名必须交给用户的深链和摘要必须写在**用户可见的最终回复正文**里，和确认问句同一条可见消息。例如 `hitl.asset-list-confirm` 只交 `deeplink asset-confirm` 的 `data.href`，不要求在对话里列出角色/场景/道具名单；`hitl.asset-result-confirm` 交 `deeplink project` 的 `href`，要看图时再交本轮 `deeplink asset` 的 `href`（拆资产看图用 `deeplink asset-result`）；`deeplink credits` 的积分明细不得代替项目页；`hitl.shot-result-confirm` 交项目页/首集链接 `href`。禁止只放进选择器题干、工具结果、推理或折叠块。缺交付物不得提问确认。

## 选择器

每个确认项一道题。`label` / 选项文案只用展示名。推荐项把展示名放进选项，后缀只加 `（推荐）`；宿主若要求推荐项排第一，把它放到 options 第一位，其余项仍全在。不要叠 `(Recommended)`，不要加选择框。

选项的 `id` 用展示名或序号。不要把 `uk_id`、`id`、`ai_model_mark`、`generate_image_type`、模板 ID 或其它提交标识写进 `id`、`label` 或说明。

单选是默认。需要多选时（例如指定若干角色存主体）才打开宿主多选；没有多选能力时改回退，让用户写名称列表。

互不影响的项放进同一次表单，例如：创作模式（若本步要问）+ 剧目类型 + 画面比例；风格 + 题材 + 角色构图 + 图片模型；模型确认后的画幅 + 分辨率（+ 时长或模板，若本步已允许）。上游会改下游枚举时仍分步，先弹上游，确认后再弹下游。用户改选上游后丢掉旧下游，按新结果重弹。

只剩 1 个有效项时复述该展示名请用户确认继续，不要伪造第二项凑选项数。宿主要求至少 2 项才能调用时，该确认项改走回退。

项目名称、自定义提示词、`needs_input` 的自由文本字段不要调用选择器。是/否或「确认 / 修改」这类有限项可以。

选完后把**展示名**交给对应 `--set`。团队一步流和 AI拆分镜工作流模版例外：按本次条目映射回字符串 `uk_id` 或 `workflow_id` 提交，不能把名称交给 `prompt_ukid`；同名项保留独立序号，用描述或语言模型帮助区分。用户选了宿主自带的 Other / 其它：填的是某个展示名或序号则采用；否则按无效重问，不要把 Other 当新选项提交。

拆分镜的模板确认项按 [模板合并与选择](gui-script-video-storyboard.md#模板合并与选择) 保留分组和顺序；该项的推荐标记不触发重排，文本回退采用该页的逐行格式。

## 上限

风格、题材等长目录必须仍列全。调用因选项数或字数被拒绝时：只把**该确认项**改走回退，或拆成「风格 1/2」「风格 2/2」两问，两页合起来仍覆盖当次全部有效项。禁止为塞进弹窗丢掉选项，或收成「是否使用推荐配置」。

宿主单次问题数不够时，拆成多次选择器调用，不要因此改回推荐包。

## 回退列表

无选择器、选择器不可用、用户反馈选择面板不可见、或该确认项超出宿主上限时使用。不要反复调用用户看不到的面板，不把沉默视为确认。不要用 Markdown 有序列表或无序列表（`-` / `*`）。

每个选项写成 `(N) 展示名`。同一确认项的全部可选项默认写在同一行，选项之间用间隔号 `·` 隔开（两侧各一空格）。确认项标题各自独占一行。推荐项只在名称后加 `（推荐）`。用户回复序号或展示名都算选中；无效序号时提示后按同一列表重选。

回退列表必须写在本回合对用户可见的最终回复正文里，和确认问句同一条可见消息。禁止只写在推理、计划、过程摘要、折叠块、`<details>` 或要点开「用时」才能看到的区域。宿主把中间步骤收拢时，未展开也必须能看见完整 `(N)` 列表。

禁止把列全选项收成「请确认是否按默认配置执行」或只复述推荐包。可以先复述将采用的展示名，但同一条可见消息里仍须带完整回退列表。

选项本身不得写在本页。画幅、风格、题材、构图、模型等只用来自 [_hard-gate.md](_hard-gate.md) 对应当次命令的展示名，目录多了就多列、少了就少列，禁止把记忆或本文示例当成枚举。

```
<确认项标题>
(1) <展示名> · (2) <展示名>（推荐） · (3) <展示名>
```
