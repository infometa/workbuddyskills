# 系统标准高频对象目录

以下对象只用于形成运行时探索候选。它们不是当前租户已启用对象的清单，也不证明当前用户有权访问，更不代表表中列出了对象的全部字段。

| 业务域 | 对象技术名称 | 中文名称 | 典型用途 |
| --- | --- | --- | --- |
| 组织主数据 | `User` | 人员 | 负责人、申请人、审批人、项目成员等人员引用 |
| 组织主数据 | `Department` | 部门 | 人员归属和管理关系 |
| 组织主数据 | `Organization` | 组织 | 业务责任、核算或经营主体 |
| 往来与存货 | `Customer` | 客户 | 销售、应收、收入和收款相对方 |
| 往来与存货 | `Vendor` | 供应商 | 采购、应付、成本和付款相对方 |
| 往来与存货 | `Contact` | 联系人 | 客户或供应商等对象的联系人明细 |
| 往来与存货 | `Product` | 存货 | 采购、销售和履约标的 |
| 项目执行 | `Project` | 项目 | 业务与财务的项目归集主体 |
| 项目执行 | `ProjectMember` | 项目团队 | 项目成员及其项目内关系 |
| 项目执行 | `WorkTask` | 快捷任务 | 日常或项目相关任务执行 |
| 项目执行 | `Timesheet` | 工时记录单 | 按人员、项目和任务登记工时 |
| 合同 | `ArContract` | 应收合同 | 面向客户的应收合同业务 |
| 合同 | `ApContract` | 应付合同 | 面向供应商的应付合同业务 |
| 销售 | `SalesContract` | 销售合同 | 销售约定及后续执行依据 |
| 销售 | `SalesOrder` | 销售订单 | 销售履约与交付安排 |
| 销售 | `GoodsIssue` | 发货通知单 | 销售发货安排与执行 |
| 采购 | `PurReq` | 请购单 | 采购需求申请 |
| 采购 | `PurContract` | 采购合同 | 采购约定及后续执行依据 |
| 采购 | `PurOrder` | 采购订单 | 采购履约与到货安排 |
| 采购 | `GoodsReceipt` | 采购到货单 | 采购到货记录 |
| 收入与应收 | `RevenueConfirmation` | 收入确认单 | 记录收入确认业务事实 |
| 收入与应收 | `Invoice` | 销售发票 | 记录销售开票事实 |
| 收入与应收 | `Receipt` | 收款单 | 记录实际收款业务 |
| 支出与应付 | `PurchaseInvoice` | 采购发票 | 记录采购发票事实 |
| 支出与应付 | `PaymentApplication` | 付款申请单 | 发起和审批付款申请 |
| 支出与应付 | `Payment` | 付款单 | 记录实际付款业务 |
| 费用 | `ReimburseApply` | 申请单 | 费用发生前的业务申请 |
| 费用 | `Reimburse` | 报销单 | 费用报销及其明细 |
| 借还款 | `Loan` | 借款单 | 员工借款业务 |
| 借还款 | `Repayment` | 还款单 | 员工还款业务 |
| 财务核算 | `Voucher` | 凭证 | 记录财务核算凭证 |

使用目录时：

1. 先按用户问题选择一个或多个候选对象，不把目录条目直接写成查询事实或固定范围。
2. 使用 qiqi 的对象发现能力确认当前租户是否提供候选对象。
3. 使用元数据确认字段、明细表、外键、枚举和可执行动作。
4. 同一自然语言概念对应多个对象时，先说明业务阶段差异再选择。
5. 未发现对象时继续按业务关键词探索；仍未确认时报告未知，不得根据本目录猜测对象存在。
