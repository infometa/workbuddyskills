# 公共字段与数据表达

## 公共字段的稳定语义

公共字段可能出现在多个对象中，但不保证每个对象都提供。使用前以当前元数据为准。

| 字段 | 稳定语义 | 判断边界 |
| --- | --- | --- |
| `createdTime` | 记录形成的时间点 | 不等同于业务归属日期。 |
| `businessDate` | 业务事实归属的自然日 | 不应由创建时间或当前日期替代。 |
| `isChangeBill` | 当前记录是否属于变更单据 | 只有支持变更业务的对象才有意义。 |
| `srcObjectType` / `srcObjectId` | 来源记录的对象类型与稳定 ID | 两者共同表达来源，不证明来源记录已完成。 |
| `billStatus` | 单据当前状态 | 通过业务动作推进，不直接改写。 |
| `projectId` / `project` | 记录归属或关联的项目 | 是否存在及位于主表或明细，以元数据为准。 |

创建时间、来源、审计、状态和计算结果通常属于系统控制信息。除非当前能力明确要求，不主动构造或写入。

## 引用、枚举与空值

- 引用使用稳定 ID 表达记录关系。名称只产生候选；名称重复时必须消歧。
- 枚举使用当前元数据返回的真实值，不用显示文本、翻译或其它租户的值代替。
- `null` 表示没有值或未知值，必须原样保留。不要把它改成空字符串、零、`false` 或当前日期。
- 主对象、明细和附件之间的关系必须来自元数据或记录返回，不根据常见字段名猜测。

## 层级与树形关系

组织、任务、分类等业务对象可能通过父级引用形成树形结构。根节点、父节点、子节点、祖先和后代都是由当前记录的稳定引用关系确定的结构角色，而不是名称、显示顺序或同属一个项目的推论。

- 先通过当前元数据和记录返回确认父级字段、根节点规则及关联方向。
- 不假设任意对象都支持层级，不根据名称相似或编号前缀推断父子关系。
- 层级汇总、状态传递、权限继承和删除影响均属于业务规则；当前能力或记录未明确时，不自行递归计算或推断。

## 时间字段语义

业务时间字段可能表达：

- `date`：一个业务自然日。
- `dateTime`：时间线上的精确时间点。
- `time`：一天中的时刻，本身不包含日期。
- `yearMonth`：一个自然月。
- `year`：一个自然年。

Agent 应读取当前字段元数据中的时间描述，按当前字段描述的外部格式传递；不得输入 Unix 秒或毫秒，也不得自行做整数与日期字符串换算。

字段元数据没有声明时间语义，或显式给出不支持的语义时，应报告元数据不足或错误，不猜测格式。时间值为 `null` 时保持 `null`。

## 公共关联集合

- 附件集合承载与主记录或明细记录关联的文件事实。
- 评论集合承载与记录关联的沟通事实。
- 其它明细或关联集合的真实名称、字段和可写性由当前元数据决定。

附件名称、附件 ID、存储索引和临时访问链接含义不同，不得互换。附件 ID 只能在已确认的业务记录范围内使用，存储索引不是公共寻址凭据。Foundation 只定义事实边界；附件如何列出、签出链接和上传由 qiqi 附件命令负责。
