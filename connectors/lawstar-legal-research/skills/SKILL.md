# 法律之星法规检索

通过「法律之星 MCP」连接法律之星法规库（www.law-star.com），为用户提供 6 个只读检索工具。用户问"查一下 XX 的规定 / XX 法第 X 条的原文 / 列一下 XX 相关法规 / 核验这段法条引用"时调用本连接器工具，**不要凭模型记忆硬编法条、也不要先去搜索引擎**。

## 认证与凭证

- 连接器已自动注入 API Key（请求头 `Authorization: Bearer <key>`），无需用户手动配置。
- 凭证失效时接口返回鉴权错误，请提示用户「连接器凭证失效，请断开连接器后重新填写有效的 API Key 并保存」。Key 每次调用消耗用户积分，仅在需要时调用，能合并查询的合并到批量工具。
- 积分用尽时，提示用户前往法律之星开放平台（`https://open.law-star.com/guide`/）充值以获取更多积分。
- 覆盖范围：**仅中国大陆法**。美国法、港澳台及其他法域、裁判文书、企业信息、合同起草等超出本工具范围，明确告知用户后转其他渠道。

## 六个工具一览

| 工具 | 用途 | 单次计费 |
|---|---|---|
| `law_semantic_search` | 按意思找最相关法条（单组） | 按次 |
| `law_article_recognition` | 批量语义检索（一次 ≤5 组） | 按组 |
| `law_semantic_clause` | 已知"法规名+条号"取单条原文 | 按次 |
| `law_law_reference` | 批量取多部法规指定条款（一次 ≤5 组） | 按组 |
| `law_statute_list` | 按标题/地域/部门列法规清单 | 按次 |
| `law_hallucination_check` | 核验 AI/文书中的法条引用真伪（一次 ≤5 组） | 按组 |

## 工具详情

### 1. law_semantic_search — 语义检索法律条文

自然语言描述一个法律问题，返回最相关的法条（最多 10 条）。

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| text | string | ✅ | 语义检索文本。涉及罪名统一为"XX罪"（如"受贿罪量刑"）；保留完整法律概念（如"未签劳动合同二倍工资"）；不擅自缩写/改写用户术语 |
| area | string | ✅ | 法规适用地域。**一次只传一个地域**（"全国"或"北京"）；多地域须多次调用，勿写"北京 上海" |
| keyword | string | - | 法规标题关键词（可选），多个用空格分隔（AND）。拿不准是否为法规名时不传 |
| timeliness | string | - | 传"是"只查现行有效；不传查全部 |

示例：`text: "受贿罪量刑", area: "全国", timeliness: "是"`

返回每条含 title（法规标题）/ tiao（条号）/ content（原文）/ depName / issueDate / effectiveness / score（相似度）。

### 2. law_article_recognition — 批量语义检索法条

一次识别/检索多个语义问题（≤5 组），只查一条也要用数组。

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| queries[].text | string | ✅ | 语义检索文本（同 law_semantic_search 的 text 规则） |
| queries[].area | string | ✅ | 每个查询项一个地域组合；多地域拆成多项 |
| queries[].keyword | string | - | 标题关键词过滤（可选） |
| timeliness | string | - | 全局参数：传"是"只查现行有效 |

示例：`queries: [{ text: "受贿罪量刑", area: "全国" }, { text: "诈骗罪怎么判", area: "全国" }]`

返回按 queryIndex 分组，每组含 results 列表。

### 3. law_semantic_clause — 按法规名+条号取单条原文

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| text | string | ✅ | 法律名称（中文），如"刑法""民法典" |
| tiao | string | ✅ | 条号，中文或数字均可（"第十条"或"10"） |
| checkTime | string | - | 校验时间 `yyyyMMdd`（如 20230601）：返回该时点正在生效的版本；不传返回现行有效版本 |

示例：`text: "刑法", tiao: "第十条"`

多条查询请改用 `law_law_reference`。

### 4. law_law_reference — 批量法条查询

一次取多部法规的指定条款（≤5 组），按组计费。

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| queries[].text | string | ✅ | 法律名称（中文） |
| queries[].tiao | string | ✅ | 条号（中文/数字） |
| checkTime | string | - | 全局参数，同 law_semantic_clause |

示例：`queries: [{ text: "民法典", tiao: "第二条" }, { text: "刑法", tiao: "第三条" }]`

返回按 queryIndex 分组。

### 5. law_statute_list — 法规列表查询

按标题关键词精确匹配法规（返回前 10 条）。地方具体事项检索无结果时，可先用本工具按地域定位法规名，再用 law_semantic_clause 取原文。

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| title | string | ✅ | 关键词，完整或部分法规名（"民法典""反不正当竞争"） |
| depName | string | - | 地域或部门名（"北京市""国务院""最高人民法院"）；留空查全部 |

返回每条含 id / title / depName / issueDate / effectiveDate / effectiveness / category（效力级别）。

### 6. law_hallucination_check — 批量核验法条引用

核验 AI 生成或文书中的法条引用是否真实（≤5 组）。双路线：① keyword+tiao 精确查原文比对；② keyword+text 在法规内语义找最接近条文。

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| queries[].keyword | string | ✅ | 法规标题关键词（"民法典""刑法"） |
| queries[].tiao | string | ✅ | 引用的条号 |
| queries[].text | string | ✅ | 待核验的条文正文（AI 生成内容） |

返回按 queryIndex 分组，每组含 exactMatch（真实原文）与 semanticMatch（语义最接近条文，含 score），供逐条比对。

## 调用纪律

- **能并则并**：单组工具按次计费、批量工具按组计费；多个问题合并进一次批量调用帮用户省积分。
- **批量 ≤5 组**：超过 5 组必须分批。
- **地域一次一个组合**：多地域拆分到多组查询或多次调用。
- **时效**：用户要现行规定传 `timeliness: "是"`；要历史版本（比如做法律研究、对比立法变迁、历史裁判文书或案例中引用的旧版法规时）不传（或按 checkTime 查历史时点）。
- **呈现**：直接输出法条原文；标注时效（现行有效/已失效/已修改）与发布机关/日期；多条按效力级别排序；语义结果附相似度。遇已失效/修改的法条必须点名并给出现行版本。
- **多条命中排序**：法律 > 行政法规 > 部门规章 > 司法解释 > 地方性法规；同级现行有效在前。

## 错误场景与处理

| 场景 | 处理 |
|---|---|
| 鉴权失败（401/凭证无效） | 提示用户重新填写 API Key（连接器设置里断开重连） |
| 参数校验错误（必填缺失/格式错） | 对照上表补全参数后重试；area/checkTime 注意格式 |
| 检索无结果 | 检查是否地域过窄；建议先用 law_statute_list 定位法规名，再按条号取原文 |
| 超时/网络异常 | 告知用户稍后重试，不要伪造数据 |

## 边界

- 本工具只返回检索材料，不等同于法律意见；用户要据此做决策（回函、诉讼等）时提示与执业律师复核。
- 穷举式检索（"把所有讨论 X 的规定列出"）超出单次返回上限，无法保证穷举。
- 接口调用按用户有日限流：当日触发限流后将于次日 0 点自动恢复，正常使用不会触发限流，不得采取高频次、大规模的数据抓取行为。
