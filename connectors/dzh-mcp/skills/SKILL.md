# 大智慧DZH MCP连接器 Skill
> 重要：本Skill对应WorkBuddy MCP连接器`dzh-mcp`，该MCP Server对外提供行情、新闻、公告、研报、财务等证券查询工具。

## 前置约束（全部工具统一生效）
1. 鉴权：使用 WorkBuddy OAuth2 授权获取访问权限；鉴权失败、凭证过期，直接提示用户检查 MCP 连接器凭证配置，禁止自行重试调用。
2. 限流：大智慧行情接口存在QPS限制，禁止循环高频批量调用工具。
3. 参数约束：枚举入参**必须传入枚举字符串字面量，禁止传入中文、数字、Java枚举对象**。
4. 股票代码规范：必须使用大智慧标准代码格式，如`SH600000`、`SZ000001`、`HK00669`、`OF519666`、`DCJD2609`，不能仅输入6位数字。
5. 时间格式：时间类参数严格遵循接口定义格式（K线/指标为`yyyyMMdd-HHmmss`，交易日为`yyyyMMdd`），格式错误返回空数据集。
6. 复权标记：`split` 全局约定 `0`=不复权，`1`=前复权，`2`=后复权；默认值各工具不同，见对应参数表（K线类默认`0`，技术指标默认`1`）。
7. 行筛选：`start` 为行偏移，负数表示从末尾向前取（如`-20`取最新20条）；技术指标工具的`start`为起始行号，`0`/`1`/空均表示从第1行开始。
8. 工具命名：工具名源自后端接口，含拼音缩写与接口编号（如`Ffjgrg`=卖方研报、`TbGg`=公告、`LhbGpmx`=龙虎榜个股明细、`Gsjs`=公司简况），完整含义见各工具标题与功能描述；只能调用本文档列出的工具。
9. 合规：本连接器数据仅供参考，不构成投资建议；回答涉及具体标的时应在末尾附股市风险提示（如“以上内容仅供参考，股市有风险，投资需谨慎。”）。

## 错误处理（AI 应对策略）

大智慧接口返回后，AI 必须按下表判断并处理异常场景，**禁止**向用户暴露底层错误码、堆栈或内部地址：

| 场景 | 表现 | AI 应对策略 |
|------|------|-------------|
| 鉴权失败 / 凭证过期 | 鉴权错误 | 直接提示用户检查 MCP 连接器凭证配置；禁止自行重试调用 |
| 股票代码格式错误 | 空数据集或报错 | 检查代码是否为大智慧标准格式（`SH600000`/`SZ000001`/`HK00669`/`OF519666`/`DCJD2609`），补全市场前缀后重查 |
| 时间格式错误 | 返回空数据集 | 时间参数严格按文档格式（`yyyyMMdd-HHmmss` / `yyyyMMdd`），修正后重查 |
| 枚举参数非法 | 参数校验失败 | 枚举必须使用文档列出的字面量（如`period`、`operator`、`split`），禁止传中文或数字 |
| 限流（QPS） | 请求被拒绝/节流提示 | 避免循环高频批量调用；如需重试，间隔一段时间后再试 |
| 网络超时 | 请求超时 | 提示用户“数据源暂时不可用，请稍后重试”，禁止无间隔反复重试 |
| 空结果（数据不存在） | 返回空数据集 | 向用户说明“暂未查询到相关数据”，并给出可能原因（代码错误、新股无历史数据、非交易日等） |

通用原则：
- 查询结果为空 ≠ 工具报错：先确认代码、时间、参数是否合理，再决定如何向用户解释。
- 不暴露底层实现细节：用用户能理解的话解释（如“该指标暂时无法获取，请稍后重试”）。
- 只呈现客观数据，不基于结果做投资建议。

### getQuoteKline - 获取A股K线行情数据

**功能描述**：提供A股股票的K线行情数据查询能力，支持分钟、日、周、月、季度、半年、年多周期K线，支持不复权、前复权、后复权切换。

**参数说明**：

| 参数名 | 类型 | 必填 | 描述 |
|------|------|:----:|------|
| stockCode | `string` | ✅ | 大智慧标准股票代码，例如：SH600000 |
| period | `string` | - | K线周期枚举，默认`DAY_1`；允许值：`MIN_1`(1分钟),`MIN_5`(5分钟),`MIN_15`(15分钟),`MIN_30`(30分钟),`MIN_60`(60分钟),`DAY_1`(1天),`WEEK_1`(1周),`MONTH_1`(1月),`SEASON_1`(1季度),`HALFYEAR_1`(半年),`YEAR_1`(1年) |
| beginTime | `string` | - | 开始时间，格式严格`yyyyMMdd-HHmmss` |
| endTime | `string` | - | 结束时间，格式严格`yyyyMMdd-HHmmss` |
| start | `string` | - | 行筛选偏移，例如`"-10"`表示取最新10条；负数代表从末尾向前取 |
| count | `number` | - | 最大返回行数，≥0，默认100 |
| split | `string` | - | 除权标记；`0`=不复权，`1`=前复权，`2`=后复权，默认`0` |

**调用示例**：

- 查询SH600000最新20根日线K线：调用`getQuoteKline`，`stockCode="SH600000",period="DAY_1",start="-20"`
- 查询SH600000指定时间范围前复权日线：调用`getQuoteKline`，`stockCode="SH600000",period="DAY_1",beginTime="20250801-000000",endTime="20250825-150000",split="1"`
- 查询SH600000最近30根30分钟K线：调用`getQuoteKline`，`stockCode="SH600000",period="MIN_30",start="-30"`
