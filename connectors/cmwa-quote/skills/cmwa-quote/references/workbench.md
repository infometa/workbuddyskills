# 询价报价（workbench）

> ⛔ **对外口径**：`ui://...` 资源地址、MCP / MCP App / AppBridge / 沙箱 / token 等术语仅供内部理解，
> **禁止出现在给用户的文字里**。对用户只说「询价列表」「下方面板」「询价报价」。

> 文件名保持 `workbench.md`（工具名 `openWorkbench`、资源地址 `ui://cmwa-quote/workbench` 均为代码标识符，不改）；
> **对用户的中文表述统一为「询价报价」**。

## 询价报价（MCP Apps UI 资源）

询价报价是后端 MCP 暴露的 **UI 资源**（`ui://cmwa-quote/workbench`，MIME `text/html;profile=mcp-app`）。

**只有 `openWorkbench` 关联了这个资源**，所以**只有调它才会打开询价报价**：

| 时机 | 动作 |
|---|---|
| **本对话首次**问询价 | 调 `openWorkbench` → 打开一扇 |
| **已打开过**之后再问询价 | 调 `queryTraderQuote` → **只回表格**，**结尾问一句「需要我再次打开询价报价吗？」** |
| 用户回答「要 / 打开」 | 调 `openWorkbench` → 打开一扇 |
| 用户回答「不用」 | 什么都不做，**不要再追问** |
| 用户**明确**说「打开询价报价 / 我要填报价」 | 调 `openWorkbench` → 打开一扇 |

> ⚠️ **`queryTraderQuote` 不带页面。** 它只查数据，不会再渲染面板。
> ⚠️ **重复调 `openWorkbench` 会多开一扇**（每次调用都是一扇新的，不会复用）。
> 所以「打开」只在「首次」或「用户明确要」时做；**问一句 ≠ 打开**，必须等用户回应。

打开后**页面会自己取数**（`boot()` 自动拉一次，顶栏还有「刷新」按钮），
**AI 不需要**为了填首帧数据额外再调一次查询 —— 那会一次交互开出两扇。

> 对用户表述：**「询价列表已显示在下方面板中」**。不要给出资源地址、面板 URL、实例 ID。

## 页面点按钮（AppBridge）

页面内嵌后，用户点「刷新 / 提交报价 / 导出」时，页面通过 AppBridge 反向调 MCP 工具，token 由 WorkBuddy 自动带，全程无本地服务、无手动 token。

> ✅ 这两个动作调的 `queryTraderQuote` / `exportExcel` 都**不带页面**，
> 所以**页面刷新、提交报价、点导出都不会再开新面板**。

## 页面能力

- **查询**：打开即自动拉取，顶部「刷新」重拉（调 `queryTraderQuote`）。
- **筛选**：吸顶 chips（全部 / 待报价 / 已报价）。「待报价」= `inquiryState === '询价中' && quoteStat === 'N'`。
- **报价**：待报价明细填报价数字框 + 备注框，「提交报价」走 `bathInsertTraderQuote`。
- **导出**：走 `exportExcel`。

## 券商身份（高级设置）

券商身份 4 字段（traderWechatId / traderId / traderDept / deptId）由用户在页面「高级设置」填写，随报价合并提交。

> 对用户表述：**「券商信息」**，不要列字段名。

## 输出原则

- 页面渲染后，查询/报价/提交结果由页面自身 toast 反馈，AI 不必复述；
- **不要**为了「同步最新数据」重复调 `openWorkbench`（页面自己会刷新）；
- **已打开过**时，用户再问询价 → **回表格**（见 `references/query.md`），
  不要用「见下方询价报价」把用户推回面板；
- 仅在页面渲染失败等异常时才向用户说明；
- 说明异常时只给业务结论 + 建议动作（如「请重启客户端后重试」），
  **不要**解释缓存、跨域、授权链路等机制。
