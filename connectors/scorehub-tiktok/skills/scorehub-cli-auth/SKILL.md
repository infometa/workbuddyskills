# ScoreHub TikTok 达人营销

连接用户已授权的 TikTok Shop 店铺，用于达人筛选、画像评估、联盟经营分析与小范围建联。

## 认证与连接

- 本连接器采用连接前置认证：WorkBuddy 在启动 MCP 前先完成浏览器授权。用户会看到 ScoreHub 登录页，需输入密码登录、**选择要授权的店铺**、点击授权。
- 每次授权只绑定一个店铺；账号、店铺、国家与绑定品牌由本地代理持久化，跨重启有效。
- 授权范围由 ScoreHub 授权页决定，主要覆盖达人搜索与表现数据读取、店铺联盟经营数据读取、建联消息发送。
- 实现契约见 `packages/mcp-server/docs/PREAUTH_CLI.md`（仓库内，不对终端用户展示）。

## 可用工具

远端工具由服务端动态发现，**调用前以 `tools/list` 的返回为准**，不要凭记忆假设工具名或参数。以下两个是固定本地工具：

### authorize — 检查或重新发起授权

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | :--: | --- |
| force | boolean | 否 | 清除当前本地凭证并重新登录，用于切换账号 |
| switch_shop | boolean | 否 | 在当前账号下打开店铺选择页，无需重新登录 |

`force` 与 `switch_shop` 不可同时为 true。

### status — 查询连接状态

无参数。返回当前登录账号、授权店铺、店铺国家、绑定品牌与连接状态。

## 使用场景

| 用户说 | 建议动作 |
| --- | --- |
| 「帮我找一批适合我店铺品类的 TikTok 达人」 | 先确认已授权，再调用远端达人搜索工具 |
| 「换一个店铺看看」 | `authorize` 且 `switch_shop: true` |
| 「我现在连的是哪个店铺」 | `status` |

## 常见错误与恢复

| 现象 | 处理 |
| --- | --- |
| 提示「未授权，请先调用 authorize」 | 引导用户重新连接或在对话中调用 `authorize`；不要伪造达人数据 |
| 提示「授权已失效」 | 本地凭证已自动清除，引导用户重新授权 |
| 切换店铺后数据仍来自旧店铺 | 先 `status` 确认绑定店铺，必要时用 `switch_shop` 重选 |
| 远端工具列表为空 | 多为网络或远端暂不可用，稍后重试；不要用旧数据冒充实时结果 |
| 参数、配额或限流错误 | 原样说明错误类型，不要反复重试触发限流 |

## 注意事项

- 所有结论以工具实际返回为准，禁止编造达人名单、GMV、订单、邮件或建联结果。
- 发送消息、发起邀约等有副作用的操作，执行前需与用户确认对象和内容。
- 不要在回复中输出 access_token、refresh_token，或授权 URL 里的 state / code_challenge。
