# 素材准备指南（references/material-prep.md）

适用版本：AI-HIVE Connector 1.1.4
更新日期：2026-08-21

> 本指南告诉 agent：针对每个用户场景，该引导用户准备哪些素材、什么规格、怎么拍/选、常见坑。
> 场景已按经验归纳排序（各节标注常见度）。素材上限以 `list_models` 实时返回为准。

## 〇、先判断要不要素材（一句话分流）

- **文生**（纯文字出图/出视频）：不用素材，重点是写好 prompt（风格/主体/构图/镜头）。
- **参考生**（要主体或风格一致）：需要参考图/视频/音频 —— 本指南重点。
- **编辑**（改图 / 视频编辑）：需要原图/原视频 + 明确修改指令。

## 一、通用素材硬约束

| 项 | 当前 Connector 规范 |
|---|---|
| 图片格式 | jpeg / jpg / png / webp，单文件 ≤10MiB |
| 视频格式 | mp4 / webm / mov，单文件 ≤100MiB |
| 文档格式 | pdf / txt / md / csv / json / docx / xlsx，单文件 ≤10MiB |
| 音频素材 | mp3 / wav，单文件 ≤15MiB；上传成功后返回 `mediaType=AUDIO` |
| 命名与引用 | 上传后按类型和顺序编号；图片放入 `imageMediaIds`，视频放入 `videoMediaIds`，音频1、音频2……放入 `audioMediaIds`，首尾帧使用对应单值字段 |

> 413 表示文件过大，应压缩、裁剪或拆分；类型不支持时转换为上表格式。外部音频只有在当前模型配置明确支持参考音频及该素材组合时才提交。真实人脸需用户具有合法授权，并可能受平台内容政策限制。

### 分模型素材能力参考

下表保留模型能力层面的素材数量参考，但真正提交前必须同时满足 Connector schema、客户端大小限制及 `list_models` 返回的当前模型配置。外部参考音频、Prompt 声音描述与 `params` 原生声音开关分别处理，不互相替代。

| 模型 | 图片能力参考 | 视频能力参考 | 音频能力参考 | 当前执行要求 |
|---|---|---|---|---|
| Seedance 2.0 | ≤9 张 | ≤3 段 | ≤3 段 | 参考音频不能作为唯一参考输入；须按当前模型配置配合参考图片或视频 |
| Seedance 2.5 | ≤30 张 | ≤10 段 | ≤10 段 | 编辑或延长的源视频放入 `videoMediaIds`；音频职责与组合以运行时配置为准 |
| H3 (MiniMax) | 约 ≤9 张 | 约 ≤3 段 | 约 ≤3 段 | 数量、时长和组合限制以 `list_models` 的当前模型配置为准 |

## 二、常见用户场景（用于决定素材引导优先级）

> 以下场景按经验归纳，仅供 agent 判断素材引导重点；实际可用模型以 `list_models` 为准。

| 场景 | 主要素材类型 | 主力模型 |
|---|---|---|
| 动漫 / 二次元 | 角色/风格参考图 | GPT Image 2 / Seedream / Nano Banana |
| 营销 / 海报广告 | 产品图/品牌元素 | GPT Image 2 / Nano Banana |
| 影视 / 分镜视频 | 首帧图/参考视频/参考音频/分镜图 | Seedance 2.5 / H3 / HappyHorse |
| Q版 / 潮玩手办 | 原型/风格参考图 | GPT Image 2 / Seedream |
| 人像 / 写真 | 人像参考（注意合规） | GPT Image 2 / Nano Banana |
| 国风 / 古风 | 风格/题材参考图 | Seedream / GPT Image 2 |
| 电商 / 产品图 | 产品白底图 | GPT Image 2 / Nano Banana |
| 图片编辑 / 改图 | 原图 + 修改指令 | GPT Image 2 / Nano Banana |

> 引导要点：
> 1. **出图是主力需求**，素材准备核心是**参考图**。
> 2. **动漫 / 国风**类批量出图用户关注**主体/风格一致性**（见第四节）。
> 3. **影视/分镜视频**是视频入口，参考生视频成功率偏低，引导先易后难（先文生/图生建立信心，再上参考生）。

## 三、按场景的素材清单（按常见度排序）

### 1. 动漫 / 二次元
- 需要：角色参考图（保人设一致）+ 风格参考图（保画风）；批量出图用角色三视图
- 规格：角色图清晰、正面/侧面/背面齐全；风格图色调统一
- 怎么准备：先定一个「主角色锚点图」，后续同角色都引用它；画风向同一张风格图对齐
- 坑：每张角色图人设不一致 → 批量出图像换头；风格图杂乱 → 画风漂移

### 2. 营销 / 海报广告
- 需要：产品图 / 品牌元素（logo）；文案大字在 prompt 里写清
- 规格：产品图高清、主体完整、白底或易抠；logo 矢量或高清 PNG
- 怎么准备：把「主标题 + 副标题 + 卖点」三段文案先写好，交给 prompt 排版
- 坑：产品图有杂物/反光；文案没给全 → 海报缺字或乱排版

### 3. 影视 / 分镜视频
- 需要：首帧图（图生视频）/ 参考视频（迁移运镜）/ 参考音频（音色、节奏或 BGM）/ 分镜图或关键帧（多镜头）
- 规格：首帧高清、主体明确；参考视频画面稳定、≤30s；参考音频为 MP3/WAV 且 ≤15MiB；分镜图推荐线稿
- 怎么准备：图生视频先发「最清晰的一张概念图/首帧」；多镜头用关键帧按序传入；参考音频按音频1、音频2……说明各自职责
- 坑：先确认模型是否支持外部参考音频及输入组合；Seedance 2.0 不把音频作为唯一参考输入；分镜图文字过多会带偏剧情

### 4. Q版 / 潮玩手办
- 需要：原型参考图（人物/形象）+ 风格锚点（Q 版/盲盒手感）
- 规格：原型图主体清晰；风格图统一（同一系列盲盒用同一张风格锚点）
- 怎么准备：做系列时固定一张「风格锚点图」，只换主体
- 坑：风格锚点不一致 → 同系列不像一套

### 5. 人像 / 写真
- 需要：人像/造型参考图（注意合规：真实人脸需授权，平台可能拦截）
- 规格：证件照用正面、清晰、光线均匀的人像；写真给造型/服装参考
- 怎么准备：先确认授权；不放心就改卡通/虚拟人物
- 坑：上传未授权真人脸 → 被拦截；光线杂乱 → 写真崩

### 6. 国风 / 古风
- 需要：风格参考（青绿山水/工笔/汉服）+ 题材参考
- 规格：风格图色调统一；题材图（如汉服形制）清晰
- 怎么准备：固定一张「画风锚点图」，批量出同风格
- 坑：风格图混杂（又水彩又工笔）→ 画风不稳

### 7. 电商 / 产品图
- 需要：1 张产品白底图（高清、主体完整、无遮挡、无反光）
- 规格：≥1024px、白底或易抠背景
- 坑：低分辨率 / 反光 / 背景难抠

### 8. 图片编辑 / 改图
- 需要：原图 + 一句明确修改指令（改色/换风格/保布局精修）
- 规格：原图高清；指令写清「改哪、改成什么、保留什么」
- 坑：指令模糊（「改好看点」）→ 结果不可控

## 四、批量出图（重度/复购用户）的主体一致性素材

动漫、国风等批量出图用户是复购主力，核心是「一套素材反复用、保持同一角色/画风」：

- **角色锚点**：一张主角色图（或三视图）作为固定锚点，所有同角色任务都引用同一编号。
- **风格锚点**：一张固定风格图，保证同一系列画风统一。
- **编号引用**：上传后按顺序编号（图1/图2…），prompt 里用「图1 的角色 + 图2 的风格」明确分工。
- **多视图**：角色三视图（正面/侧面/背面）分开传，prompt 注明各自用途。
- 坑：中途换锚点图 → 角色/画风漂移；一套图风格不一 → 系列感断裂。

## 五、agent 引导话术（按场景，可直接用）

- 动漫头像：「发我一张你最喜欢的角色图当锚点，再发一张想要的画风参考。」
- 营销海报：「发我一张清晰的产品图 + 把主标题/副标题/卖点文字发我。」
- 影视分镜视频：「先发我一张最清晰的概念图当首帧；要多镜头就把分镜图按顺序发我。」
- 参考音频视频：「发我 MP3/WAV 音频，并说明它是音色、节奏还是 BGM 参考；我会先确认模型支持和组合要求。」
- Q版潮玩：「发我原型图 + 一张你想要的 Q 版/盲盒风格参考。」
- 人像写真：「发我一张正面清晰的人像（注意需本人授权）；不放心就帮你做成卡通风。」
- 国风：「发我一张你想要的画风参考（比如青绿山水/工笔），题材我一并出。」
- 电商主图：「发我一张高清、白底或好抠图的产品图。」
- 图片编辑：「发我原图 + 说清要改哪里、改成什么、哪些保留。」
