# 提示词优化参考（Prompt Optimization）

适用版本：AI-HIVE Connector 1.1.4 / `@infimind-next/ai-hive-mcp`（不锁版本，npx 运行时自动拉取最新）
资料来源：OpenAI / Anthropic / Google 官方提示工程指南 + Midjourney / Seedance / Runway 社区最佳实践（2025–2026，多源交叉验证）

## 一、通用原则（2026 共识）
- **具体胜于花哨**：明确指令 > "魔法词"。写清角色/任务/约束/格式，比堆术语有效。
- **结构化 > 段落**：用 Role / Task / Context / Constraints / Output format 分块，降低歧义。
- **负向约束**：直接写"不要什么"（no text / 无抖动 / 不变形）比"希望别出现"更可靠。
- **少样本**：格式/风格要精确时，给 2–5 个示例（few-shot）提升一致性。
- **长素材置顶、指令置底**：大段参考资料放前面，真正的问题/指令放最后（Anthropic 实测质量可 +30%）。
- **冷静直接**：对推理模型，"CRITICAL!"/"YOU MUST" 反而降效；清晰陈述即可。
- **迭代优化**：评测 → 调约束 → 再生成，而非一次写完美。
- 常用框架：RTF（Role-Task-Format）、CO-STAR、RISEN。

## 二、图像提示词公式（5 层，跨源验证）
**主体（具体：年龄/材质/动作）→ 环境（时间/地点/天气）→ 风格/媒介（写实/动漫/油画/Studio Ghibli/Kodak Portra）→ 灯光（黄金时刻/轮廓光/50mm·85mm）→ 技术（比例/8K/负向）**
- **角色一致性**：写一段约 30 字角色锚点，在多张图里**原样复用**，不要改写。
- 单图提示词建议 ≤60–80 词；过长模型会忽略或混淆。
- 负向词统一：no text / no extra limbs / no blur / no watermark。

## 三、视频提示词公式（跨源验证）
**主体 + 动作 + 环境 + 运镜 + 氛围 + 时长**
- 运镜词表：dolly in/out（推拉）、pan（横移）、tracking（跟拍）、orbit（环绕）、crane（升降）、handheld（手持）、FPV（第一人称）、low-angle（低角度）。
- **首尾帧顺序**：运镜 → 主体动作 → 环境运动 → 氛围 → 落点。
- **必加约束**：运镜 ≤2–3 个组合；加"画面流畅稳定 / 无抖动无闪烁"（稳定）；加"面部稳定不变形、五官清晰"（人物）；模糊词换精确词（"好看"→"赛博朋克暗调霓虹反光"）。
- **慢而连续 > 快动作**：慢动作成功率远高于高速运动。
- 单镜头 ≤1–2 个动作，单一连续场景。

## 四、Agent 编排（秀肌肉的关键）
- **零素材准备**：agent 联网搜索参考 → generate_image/video → 再加工，用户无需准备任何素材。
- **工具映射**：明确告诉 agent 何时用哪个工具（搜索 vs 生成 vs list_models 取模型）。
- **步骤链**：归类 → 取参考 → 生成 → 迭代 → 汇总。
- **兜底**：工具报错时重试 / 经 list_models 换备选模型。

## 五、一个"复杂精确"范例提示词的解剖
`[目标] → [联网搜参考] → [5 层规格 + 风格锚点生成] → [运镜/动作规格 + 约束] → [输出格式]`
具体范例见 `connector-meta.json` 的 `examples_zh` / `examples_en`。
