# Wan 3.0 提示词公式

## 选公式

- 基础 T2V：`主体 + 场景 + 运动`。
- 进阶 T2V：`主体细节 + 场景细节 + 运动细节 + 镜头语言 + 光影 + 氛围 + 声音`。
- I2V：`运动过程 + 状态变化 + 运镜 + 声音`。首尾帧外观不重复描述。
- R2V：`素材职责声明 + @参考对象 + 场景/动作关系 + 运镜 + 声音`。
- 多镜头：`总体设定 + 镜头1[起止秒] + 镜头2[起止秒] ... + 一致性约束 + 声音连续性`。

## 参考素材指代

各媒体类型独立编号，并按上传顺序映射：

```text
@图片1 只提供商品几何比例、颜色、包装文字和部件位置，全片生效。
@图片2 只提供台面材质与环境光，图中其他物品不进入画面。
@视频1 只提供人物动作节奏，不继承其中的服装与背景。
@音频1 只提供音色；台词内容以提示词引号内文本为准。
```

同一素材不要承担互相冲突的职责。需要锁定商品正面和侧面时，说明它们属于同一商品，而不是两件商品。

## I2V

首帧：从已有状态开始，描述接下来发生什么。

首尾帧：只描述两帧之间的连续过程、主体轨迹、状态变化和镜头运动。不要重新描述首帧与尾帧的构图、外观、颜色或位置。

## 多镜头

- 时间段连续、无重叠、无空档，总和等于 duration。
- 每镜头只承担一个叙事目标；镜头间写清主体、商品、服装、场景与光线保持一致。
- 需要硬切时明确“切至”；需要连续运镜时明确“镜头连续移动至”。
- 用户要单镜头时，写“生成单镜头，一镜到底”，再描述稳定机位或连续轨迹。

示例骨架：

```text
总体设定：同一人物、同一服装、同一场景，暖色自然光连续。
镜头1[0-4秒]：中景固定机位，人物完成一个明确动作。
镜头2[4-8秒]：镜头缓慢推近至特写，动作自然延续。
镜头3[8-12秒]：侧向跟拍，主体在画面中的位置连续。
声音：环境音贯穿；对白在指定镜头内出现，前后音量连续。
```

## 声音

- 人声：`说话者 + "原文" + 情绪 + 语调 + 语速 + 音色 + 口音`。
- 音效：`音源材质 + 行为 + 结果声音 + 环境`。
- 音色参考与台词写在同一句：`@图片1 用轻快的声音说："..."，音色参考 @音频1。`
- `audio=false` 时不要在提示词里要求对白、旁白、BGM 或音效。
