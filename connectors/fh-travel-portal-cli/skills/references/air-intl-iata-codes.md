# IATA 展示映射回退表

> 加载时机：解析 `intl_shopping` / `intl_multi_shopping` 超大结果，且服务端返回的
> `cityList/airwayList` 不能提供完整中文展示名时。`scripts/air_intl_parse_shopping.py` 会读取本表，
> 无需在脚本中重复维护映射。

## 使用纪律

- 本表只用于展示；不得用这里的代码构造 `fromCity/toCity/airIdList` 等 API 入参。
- 查询代码仍只来自 `air_city`（scope=INTERNATIONAL）、本地城市缓存、本次 MCP 返回或受控业务配置。
- 服务端 `cityList/airwayList` 的真实名称优先于本表；本表只为缺失名称提供回退。
- 未收录的代码原样显示，禁止猜测中文名。
- 某些旧展示数据把 `legs[].airline` 写成出发机场与到达机场的拼接码；真正航司优先取
  服务端航司字段/字典，兼容旧数据时才从航班号前缀回退。
