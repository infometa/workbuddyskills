# 国际能力边界与降级说明

> 加载时机：用户要求国际核价、差旅政策、申请单、成本中心、乘机人证件、创单、支付、
> 出票或退改签时。这些能力当前**未在 MCP 暴露**，本文件规定降级口径。

## 当前可用（只读）

- 城市/机场码检索（公共 `air_city`，scope=INTERNATIONAL）、国籍代码检索（`intl_nationality`）。
- 组合查询 `intl_shopping`、多程/自由组合 `intl_multi_shopping`、全舱 `intl_shopping_all_cab`。
- 退改/行李规则 `intl_rule`。

## 当前不可用（未暴露，禁止伪造）

- 下单前实时验价与库存确认。
- 企业基础配置、差旅政策校验、申请单列表与匹配、渠道预订限制。
- 乘机人与证件查询（含护照）。
- 创单、支付、出票；改签与退票。

上述能力当前未进 `tools/list`，调用必然失败。
用户提出这些诉求时：

1. 不得伪造调用，不得把「没有政策工具」解释为「政策通过」。
2. 如实说明当前只能完成「查询 → 比较 → 选舱位 → 生成下单页跳转」，
   验价、政策校验、乘机人资料和下单都在飞鹤 portal 页面内完成。
3. 按 `air-intl-sso-forward.md` 拼下单页跳转 URL，把已选 `serialNumber + 舱位 priceId` 带过去，
   让用户在已登录的 portal 页面继续。
4. 需要完整政策/申请单合规结论的国际订单，只能引导用户在 portal 完成，不得声称
   本流程已对齐参考业务流程。
