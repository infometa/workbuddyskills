# 服装电商创作方法

## 服装主图与参考图设计

先明确用户要卖什么、图用在哪里、哪些商品特征必须保留，再安排视觉。淘宝服装主图优先让消费者看清完整商品；用户未指定时可建议方图、干净背景和一张初稿。

用以下顺序组织成一段提示词：

1. **用途和主体**：淘宝商品主图、模特展示或平铺；服装品类、颜色和已知材质。
2. **保留清单**：版型、领口、袖长、衣摆、口袋、纽扣、印花和可见工艺。存在参考图时以实际可见特征为依据，不能凭空补成分或品牌。
3. **构图**：正面、三分之四侧面、半身或全身；商品在画面中的位置，完整展示哪些关键部位，保留多少背景。
4. **材质和光线**：面料应出现什么细节，光源位置、软硬度及阴影。
5. **背景**：颜色、场景、道具及与主体的关系。道具不能遮住待展示部位。
6. **允许改变和避免内容**：允许调整背景或姿态；不改变商品款式，不额外添加品牌、促销文字或水印。

示例表达：“左前方大面积柔光，领口和肩线清晰，黑色棉布仍能看见细织纹，衣摆有少量自然褶皱”，比“极致高级、8K大片”更具体。材质词必须与用户信息相符：棉布用柔和漫反射与细织纹；缎面可用连续柔亮高光；针织保留针目；牛仔保留斜纹和明线。未知材质就描述可见纹理，不冒充检测结论。

已有商品印花或 Logo 且用户要求保留时，要写“保留原图图案，不新增文字或标识”，避免“无任何 Logo”与保留要求冲突。用户没有提供品牌、面料成分、防晒率等事实时，不编造商品卖点。若需要准确排版，建议把文字作为后期独立排版步骤，不保证生图文字逐字准确。

## 自由换衣

按用户已说明的角色标记素材：服装图、模特图、风格参考图、细节图。用户说“第一张衣服穿到第二张人身上”，已足够确定前两张角色，不必再次问。

提示词同时写两份保留条件：

- 服装：颜色、版型、长度、图案、领口、袖口和关键工艺；仅允许随人物体型产生合理的透视、贴合、褶皱与阴影。
- 模特：用户要求保留的面容、发型、姿态、体型、背景和构图。不能保证模型逐像素保持不变。

明确边缘和遮挡关系，如“手臂与衣物遮挡自然，衣领贴合颈部，肩线与人物姿态一致”。若目标是同一指定人物而未提供模特图，先索取该图；若只是写方案，可以标注“模特形象待定”。不要把生成一个新人物说成对指定人物完成换衣。

## 智能修图需求

先把要求写成“保留清单”和“修改清单”。例如只调整衣服颜色时，保留版型、织纹、人物和背景，修改衣服主色；涉及商品实物一致性时，让用户核对结果。

当前 MCP 没有专用蒙版、消除、精确2倍放大、服装转3D等接口。用户要求“除选区外像素完全不变”时，应说明通用生成不能保证；可提供具体修图操作描述，或在用户同意后尝试参考图重绘并说明其限制。不能因为胶囊名称叫“消除笔”就调用一个不存在的工具，也不能悄悄将精修换成整图重绘。

## 视频创作

先区分两种目标：

- **文生视频**：没有商品参考图，适合概念展示；不能承诺对应某件实物商品。
- **图生视频**：以用户提供的主图或模特图为依据，强调保留款式、颜色、图案、人物和背景中要求不变的部分。

提示词顺序为“主体和保留条件 → 连贯动作 → 镜头运动 → 环境光线 → 时长节奏 → 避免内容”。5秒视频通常只安排一个连续动作和一个主要镜头运动，例如轻微转身配合缓慢推进。避免短时间内安排走秀、换装、场景切换和多个特写。

可以给出0—1秒建立画面、1—4秒展示、4—5秒停留的节奏建议，但这只是创作指引，不能承诺逐帧精确执行。服装展示应避免图案漂移、款式突然变化、不合理拉伸或过度运镜遮挡商品。

当前工具接入视频自由创作，不含独立配音、配乐、字幕、剪辑、首尾帧或视频参考参数。用户需要这些内容时，可写后期建议或脚本，并明确未执行；不要把它们作为不存在的结构化字段提交。

## 交付前检查

- 是否给出了可复制的完整提示词，而不是只有提问或抽象标签？
- 是否把假设与用户给定事实分清，避免修改商品关键属性？
- 用户要求只写方案时，是否保持为方案，没有创建付费任务？
- 是否存在“保留原图印花”同时“去掉所有图案”等冲突？
- 真实生成的规格是否来自用户要求与当前工具，而非将建议值当作强制值？
- 是否只将工具真实返回的完成结果标记为已生成？
